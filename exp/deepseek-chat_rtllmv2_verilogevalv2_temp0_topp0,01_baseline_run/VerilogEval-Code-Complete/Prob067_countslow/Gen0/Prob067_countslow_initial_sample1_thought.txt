To implement a decade counter with the specified requirements:
1. Use a synchronous reset that sets the counter to 0 when active
2. The counter should only increment when slowena is high
3. The counter should wrap around from 9 back to 0
4. The output q should be a 4-bit register representing the count value (0-9)

The design will:
- Use a synchronous always block triggered on positive clock edge
- First check reset condition (highest priority)
- Then check slowena condition to determine if we should increment
- Implement wrap-around logic when count reaches 9
