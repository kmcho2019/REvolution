To implement this functionality, we need a finite state machine (FSM) with a counter that counts 4 clock cycles. The FSM will have two states:
1. SHIFT_ENABLED: Outputs shift_ena=1 and counts down from 3 to 0
2. SHIFT_DISABLED: Outputs shift_ena=0 and stays here until reset

On reset, we enter SHIFT_ENABLED state and start counting. After 4 cycles (when counter reaches 0), we transition to SHIFT_DISABLED state where shift_ena remains 0 until next reset.
