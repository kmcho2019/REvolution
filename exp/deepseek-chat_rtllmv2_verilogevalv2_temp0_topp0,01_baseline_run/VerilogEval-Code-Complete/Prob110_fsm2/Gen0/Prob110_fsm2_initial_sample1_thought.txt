The problem describes a simple Moore state machine with two states (OFF and ON), two inputs (j and k), and one output (out). The state transitions are:
- From OFF: stays OFF if j=0, goes to ON if j=1
- From ON: stays ON if k=0, goes to OFF if k=1
The output is 0 in OFF state and 1 in ON state. The reset is asynchronous and active-high, forcing the state to OFF.

I'll implement this using:
1. A state register to hold current state (OFF or ON)
2. Combinational logic for next state based on current state and inputs
3. Output logic based on current state
4. Asynchronous reset handling
