The thermostat needs to control three outputs (heater, aircon, fan) based on four inputs (mode, too_cold, too_hot, fan_on). The logic is:
1. In heating mode (mode=1), turn on heater when too_cold=1
2. In cooling mode (mode=0), turn on aircon when too_hot=1
3. The fan should be on whenever either heater or aircon is on, or when fan_on=1
4. Heater and aircon should never be on simultaneously
