To implement Conway's Game of Life on a 16x16 toroidal grid, we need to:
1. Handle the toroidal wrapping for neighbor calculations
2. Count live neighbors for each cell (including wrapped neighbors)
3. Apply the game rules to determine next state
4. Update the state synchronously on clock edges

The key challenges are:
- Calculating neighbors with wrap-around
- Efficiently counting neighbors for all 256 cells
- Applying the rules in parallel for all cells

We'll:
1. Create a function to calculate neighbor count for any cell (x,y)
2. For each cell, apply the rules based on neighbor count
3. Update the entire grid synchronously
