To implement Rule 90 cellular automaton:
1. Create a 512-bit register to hold the current state (q)
2. On each clock edge:
   - If load is high, load data into q
   - Otherwise, compute next state using Rule 90:
     - For each bit, next state is XOR of left and right neighbors
     - Handle boundary conditions (q[-1] and q[512] as 0)
3. Use non-blocking assignment for synchronous behavior
