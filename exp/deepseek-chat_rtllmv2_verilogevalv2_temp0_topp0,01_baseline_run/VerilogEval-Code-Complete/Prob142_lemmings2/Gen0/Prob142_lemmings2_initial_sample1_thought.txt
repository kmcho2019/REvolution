To model the Lemming's behavior, we need a Moore state machine with four states:
1. WALK_LEFT: Lemming is walking left.
2. WALK_RIGHT: Lemming is walking right.
3. FALL_LEFT: Lemming is falling (previously was walking left).
4. FALL_RIGHT: Lemming is falling (previously was walking right).

The state transitions are as follows:
- From WALK_LEFT: 
  - If ground=0, transition to FALL_LEFT.
  - If bump_left=1, transition to WALK_RIGHT.
- From WALK_RIGHT:
  - If ground=0, transition to FALL_RIGHT.
  - If bump_right=1, transition to WALK_LEFT.
- From FALL_LEFT/FALL_RIGHT:
  - If ground=1, transition back to the previous walking state.

Outputs:
- walk_left is 1 in WALK_LEFT state.
- walk_right is 1 in WALK_RIGHT state.
- aaah is 1 in FALL_LEFT or FALL_RIGHT states.

The reset (areset) initializes the state to WALK_LEFT.
