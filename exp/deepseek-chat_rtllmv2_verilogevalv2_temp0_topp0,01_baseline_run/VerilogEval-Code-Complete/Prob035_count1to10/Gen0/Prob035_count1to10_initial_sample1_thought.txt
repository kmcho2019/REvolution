To create a decade counter that counts from 1 to 10 (inclusive), we need to:
1. Use a 4-bit register since we need to count up to 10 (1010 in binary)
2. Implement synchronous reset that sets the counter to 1 when active
3. Increment the counter on each clock edge, wrapping back to 1 after reaching 10
4. The counter should only change on positive clock edges
