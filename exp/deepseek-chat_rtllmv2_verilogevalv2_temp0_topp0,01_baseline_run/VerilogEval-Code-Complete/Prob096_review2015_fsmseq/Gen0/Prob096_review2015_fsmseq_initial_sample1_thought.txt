To detect the sequence 1101 in a bit stream, we can use a Moore finite-state machine (FSM) with 5 states:
1. IDLE: Initial state, no bits matched.
2. S1: First '1' detected.
3. S11: '11' detected.
4. S110: '110' detected.
5. FOUND: '1101' detected (final state).

The FSM transitions between states based on the input bit. Once in the FOUND state, it stays there until reset. The output start_shifting is 1 only in the FOUND state.
