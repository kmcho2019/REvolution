To implement 8 D flip-flops with active high asynchronous reset, we need to:
1. Create a module with clock (clk), 8-bit data input (d), asynchronous reset (areset), and 8-bit output (q)
2. Use always block triggered by positive edge of clk or positive edge of areset
3. When areset is high, reset all outputs to 0
4. Otherwise, on positive clock edge, pass input d to output q
