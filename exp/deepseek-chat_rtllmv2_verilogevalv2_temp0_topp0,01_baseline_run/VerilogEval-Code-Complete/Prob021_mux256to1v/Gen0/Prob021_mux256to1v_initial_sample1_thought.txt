To implement a 256-to-1 multiplexer with 4-bit wide inputs, we can treat the 1024-bit input as 256 consecutive 4-bit chunks. The selection input (sel) will determine which 4-bit chunk to output. Since each 4-bit chunk is offset by 4 bits from the previous one, we can calculate the output by selecting bits [sel*4+3 : sel*4] from the input vector.
