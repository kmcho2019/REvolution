To design a 4-bit priority encoder, we need to check the input bits from the most significant bit (bit[3]) to the least significant bit (bit[0]) and output the position of the first '1' encountered. If no '1' is found, we output 0. 

The approach is:
1. Use a case statement to check the input patterns in order of priority (from highest bit to lowest).
2. For each case, assign the corresponding position value (3 for bit[3], 2 for bit[2], etc.).
3. The default case (all zeros) will output 0.
