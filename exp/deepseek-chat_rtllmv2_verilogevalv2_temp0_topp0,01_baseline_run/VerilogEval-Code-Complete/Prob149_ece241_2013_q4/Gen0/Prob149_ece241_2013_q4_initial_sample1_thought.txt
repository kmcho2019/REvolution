The problem describes a water level control system with three sensors and four outputs controlling flow rates. The system needs to track both current water level and previous level to determine flow rate adjustments. We'll implement this as a state machine with four states corresponding to the water levels (Above s3, Between s3-s2, Between s2-s1, Below s1). The state transitions will depend on current sensor readings and previous state. Outputs will be determined by both current state and whether we're transitioning from a lower level (which requires supplemental flow).

Key points:
1. Four states representing water levels
2. State transitions based on sensor inputs
3. Outputs depend on current state and transition direction
4. Reset initializes to "Below s1" state with all outputs active
5. Supplemental flow (dfr) activates when transitioning from lower level
