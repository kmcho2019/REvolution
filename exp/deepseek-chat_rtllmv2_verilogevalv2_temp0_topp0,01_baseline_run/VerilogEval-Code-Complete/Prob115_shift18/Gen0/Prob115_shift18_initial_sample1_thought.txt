To design a 64-bit arithmetic shift register with synchronous load and variable shift operations, we need to:
1. Use a clocked always block to synchronize all operations.
2. When load is high, directly load the input data into the register.
3. When ena is high and load is low, perform the selected shift operation:
   - For left shifts (amount=00 or 01), shift left by 1 or 8 bits, filling with zeros.
   - For right shifts (amount=10 or 11), perform arithmetic right shift by 1 or 8 bits (sign-extended).
4. Maintain the current value if neither load nor ena is active.
