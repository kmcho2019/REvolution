To detect signed overflow in 2's complement addition, we need to check if the addition of two numbers with the same sign produces a result with the opposite sign. Specifically:
1. If both inputs are positive (MSB=0) and the result is negative (MSB=1), overflow occurred
2. If both inputs are negative (MSB=1) and the result is positive (MSB=0), overflow occurred
The overflow flag should be set in these cases only.
