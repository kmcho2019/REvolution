To detect the sequence "101" with overlapping sequences, we need a Mealy FSM with 3 states:
1. State S0: Initial state, waiting for the first '1'.
2. State S1: Received '1', waiting for '0'.
3. State S2: Received '10', waiting for '1'. When '1' is received here, output z is asserted.

The FSM transitions between these states based on the input x. Since it's a Mealy machine, the output z depends on both the current state and input. The FSM should reset asynchronously on the negative edge of aresetn.
