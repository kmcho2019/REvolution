To model the Lemming's behavior, we need a finite state machine (FSM) with multiple states and transitions based on inputs. The key states are:
1. WALK_LEFT: Lemming walks left.
2. WALK_RIGHT: Lemming walks right.
3. FALL: Lemming falls (aaah!).
4. DIG: Lemming digs.
5. SPLATTER: Lemming splatters and stops all actions.

Transitions:
- From WALK_LEFT/WALK_RIGHT: 
  - If ground=0, transition to FALL.
  - Else if dig=1, transition to DIG.
  - Else if bumped, switch direction.
- From DIG:
  - If ground=0, transition to FALL.
- From FALL:
  - If ground=1, transition back to previous walking state.
  - If fall duration >20 cycles when ground=1, transition to SPLATTER.
- SPLATTER is a terminal state until reset.

We'll also need a counter to track fall duration.
