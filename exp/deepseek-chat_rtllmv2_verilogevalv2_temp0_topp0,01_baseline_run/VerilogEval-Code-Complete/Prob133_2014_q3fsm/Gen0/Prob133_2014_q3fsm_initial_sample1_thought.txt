The FSM needs to track two main things: 
1. The current state (A or B)
2. Within state B, we need to count how many times w=1 occurs in a 3-cycle window

We'll use a 3-bit shift register to track the last 3 values of w. When in state B, we'll shift in the current w value each clock cycle. After every 3 cycles, we'll count how many 1's are in the shift register and set z accordingly. We'll use a counter to track when 3 cycles have passed.

States:
- A: Initial state, waits for s=1
- B: Active state, monitors w for 3-cycle windows

The shift register and counter will be reset when entering state B.
