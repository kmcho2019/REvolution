To design a finite state machine (FSM) for serial communication reception, we need to:
1. Detect the start bit (0) after the idle state (1)
2. Sample 8 data bits (LSB first)
3. Verify the stop bit (1)
4. Output the received byte and assert 'done' when stop bit is correct
5. Handle reset condition
6. If stop bit is missing, wait until a 1 is seen before looking for next start bit

The FSM will have these states:
- IDLE: waiting for start bit
- START: detected start bit, prepare to receive data
- DATA: receiving 8 data bits
- STOP: checking stop bit
- ERROR: missing stop bit, waiting for line to return to idle (1)

We'll use a counter to track which data bit we're receiving.
