To implement a 4-bit shift register that can also act as a down counter, we need to handle two operations:
1. Shift operation: When shift_ena is high, shift in the input data from MSB and shift out the LSB.
2. Count operation: When count_ena is high, decrement the current value by 1.

The operations are mutually exclusive (as per problem statement), so we can use simple if-else conditions to handle them. The register updates on the positive edge of the clock.
