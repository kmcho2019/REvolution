The design requires a 32-bit shift register for branch history tracking with two main operations:
1. Normal prediction update: shift in predict_taken when predict_valid is high
2. Misprediction recovery: restore history from train_history concatenated with train_taken when train_mispredicted is high
Misprediction has higher priority than normal prediction. The register should be asynchronously reset to 0 on areset.

Implementation approach:
- Use a 32-bit register to store the history
- On reset, clear the register
- On clock edge:
  - First check for misprediction (highest priority)
  - Then check for normal prediction
  - Otherwise maintain current state
- Output the current history register value
