The problem requires implementing a finite state machine (FSM) with 4 states (A, B, C, D) that acts as an arbiter with priority. The FSM has the following behavior:
1. State A is the default state when no requests are present
2. Transitions from A to B when r[0]=1 (highest priority)
3. Transitions from A to C when r[0]=0 and r[1]=1
4. Transitions from A to D when r[0]=0, r[1]=0, and r[2]=1
5. States B, C maintain their state while their respective request is high
6. Outputs g[0], g[1], g[2] are active in states B, C, D respectively

I'll implement this using:
1. Binary encoding for states (A=00, B=01, C=10, D=11)
2. Two always blocks - one for state transitions and one for state storage
3. Continuous assignments for outputs based on current state
