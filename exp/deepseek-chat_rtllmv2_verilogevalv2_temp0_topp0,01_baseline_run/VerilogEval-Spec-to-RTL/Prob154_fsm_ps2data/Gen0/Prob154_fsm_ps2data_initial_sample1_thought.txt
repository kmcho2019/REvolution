The design requires a finite state machine (FSM) with three states:
1. IDLE: Waiting for the first byte with in[3]=1
2. BYTE2: Received first byte, waiting for second byte
3. BYTE3: Received second byte, waiting for third byte

The FSM transitions:
- From IDLE to BYTE2 when in[3]=1
- From BYTE2 to BYTE3 unconditionally on next byte
- From BYTE3 back to IDLE unconditionally on next byte (and asserts done)

We'll need:
1. A 3-bit state register
2. A 24-bit shift register to accumulate bytes (new bytes shift in from left)
3. Done signal asserted when in BYTE3 state and receiving new byte
4. Synchronous reset to IDLE state
