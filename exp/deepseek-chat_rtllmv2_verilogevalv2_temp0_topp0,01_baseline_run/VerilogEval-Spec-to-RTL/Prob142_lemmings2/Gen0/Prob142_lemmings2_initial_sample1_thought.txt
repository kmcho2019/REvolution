To implement the Lemming's behavior, we need a Moore state machine with four states:
1. WALK_LEFT: Lemming is walking left (output walk_left=1)
2. WALK_RIGHT: Lemming is walking right (output walk_right=1)
3. FALL_LEFT: Lemming is falling but was previously walking left (output aaah=1)
4. FALL_RIGHT: Lemming is falling but was previously walking right (output aaah=1)

The state transitions are as follows:
- On reset, start in WALK_LEFT
- In walking states (WALK_LEFT/WALK_RIGHT):
  - If ground=0, transition to corresponding fall state
  - If bumped on current walking side, switch direction
- In falling states (FALL_LEFT/FALL_RIGHT):
  - Stay in fall state while ground=0
  - When ground=1, return to corresponding walking state
- Bump inputs are ignored during falling states
