To implement the Moore state machine with one-hot encoding, we need to:
1. Decode the current state from the 4-bit state input
2. Determine the next state based on current state and input 'in'
3. Generate the output based solely on current state (Moore machine)
4. Use one-hot encoding properties to simplify logic equations

For state transitions:
- From A: next state is A when in=0, B when in=1
- From B: next state is C when in=0, B when in=1
- From C: next state is A when in=0, D when in=1
- From D: next state is C when in=0, B when in=1

For output:
- Output is 1 only when in state D (4'b1000)
- Output is 0 for all other states
