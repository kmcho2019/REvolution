To implement the Moore state machine's combinational logic portion, we need to:
1. Create a case statement that checks the current state (2-bit input)
2. For each state (A, B, C, D), determine the next state based on the input 'in'
3. Assign the output based on the current state (output is 1 only in state D)

The state encoding is given as:
A = 2'b00
B = 2'b01
C = 2'b10
D = 2'b11
