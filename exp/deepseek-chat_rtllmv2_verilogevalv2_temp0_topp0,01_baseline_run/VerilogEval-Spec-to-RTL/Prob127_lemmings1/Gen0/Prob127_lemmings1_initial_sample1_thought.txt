The problem requires implementing a Moore state machine with two states (WALK_LEFT and WALK_RIGHT) that controls a Lemming's movement direction. The state transitions are:
1. When in WALK_LEFT state and bump_left is asserted, transition to WALK_RIGHT
2. When in WALK_RIGHT state and bump_right is asserted, transition to WALK_LEFT
3. If both bumps occur simultaneously, the Lemming should still switch directions
4. The areset signal should asynchronously reset the state to WALK_LEFT

The outputs walk_left and walk_right are directly derived from the current state.
