The problem requires implementing a Moore state machine with two states (OFF and ON) that transitions based on inputs j and k. The output (out) depends solely on the current state. The state transitions are:
1. In OFF state (out=0):
   - If j=0, stay in OFF
   - If j=1, transition to ON
2. In ON state (out=1):
   - If k=0, stay in ON
   - If k=1, transition to OFF
The reset (areset) is asynchronous and active-high, forcing the state to OFF.

I'll use a simple two-state encoding (1'b0 for OFF, 1'b1 for ON) and implement the state transitions with combinational logic for the next state and sequential logic for the state register.
