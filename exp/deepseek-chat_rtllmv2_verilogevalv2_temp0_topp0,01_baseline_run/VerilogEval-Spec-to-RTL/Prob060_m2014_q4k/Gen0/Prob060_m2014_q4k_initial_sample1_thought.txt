To implement a 4-bit shift register with synchronous active-low reset, we'll need:
1. Four D flip-flops connected in series
2. The first flip-flop takes the 'in' input
3. Each subsequent flip-flop takes the output of the previous one
4. All flip-flops share the same clock and reset signals
5. The output 'out' comes from the last flip-flop
6. On reset (resetn=0), all flip-flops should synchronously clear to 0
