To implement a module with 8 D flip-flops that reset to 0x34 on synchronous reset and trigger on negative clock edge:
1. Create a parameter for the reset value (8'h34)
2. Use an always block triggered on negative edge of clk
3. Inside the always block, check for synchronous reset (active high)
4. If reset is asserted, assign the reset value to q
5. Otherwise, pass the input d to output q
