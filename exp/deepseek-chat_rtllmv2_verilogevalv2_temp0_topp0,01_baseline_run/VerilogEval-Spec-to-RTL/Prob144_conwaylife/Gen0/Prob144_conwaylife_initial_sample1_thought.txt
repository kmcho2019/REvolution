To implement Conway's Game of Life on a 16x16 toroidal grid, we need to:
1. Handle the load signal to initialize the state
2. For each cell, calculate its 8 neighbors with wrap-around (toroidal) behavior
3. Count the number of live neighbors for each cell
4. Apply the game rules to determine the next state
5. Update the state synchronously on each clock edge

The key challenges are:
- Implementing toroidal neighbor calculations
- Efficiently counting neighbors for all 256 cells
- Applying the rules in parallel for all cells

We'll use generate blocks to create neighbor counters for each cell, and modular arithmetic for the toroidal wrapping.
