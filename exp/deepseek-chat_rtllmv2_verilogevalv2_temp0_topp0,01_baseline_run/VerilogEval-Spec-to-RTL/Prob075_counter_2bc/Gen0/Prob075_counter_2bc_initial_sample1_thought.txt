The design requires a 2-bit saturating counter with the following behavior:
1. Asynchronous reset (areset) sets the counter to 2'b01
2. On clock edge:
   - If train_valid=1 and train_taken=1, increment counter (saturate at 3)
   - If train_valid=1 and train_taken=0, decrement counter (saturate at 0)
   - If train_valid=0, maintain current counter value
The counter should update only on positive clock edges.
