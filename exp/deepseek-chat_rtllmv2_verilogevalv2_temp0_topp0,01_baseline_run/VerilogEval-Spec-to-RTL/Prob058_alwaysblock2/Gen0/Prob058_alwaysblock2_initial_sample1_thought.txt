To implement an XOR gate three different ways:
1. Using a continuous assign statement for out_assign (combinational logic)
2. Using an always_comb block for out_always_comb (combinational logic)
3. Using an always_ff block for out_always_ff (sequential logic with clocked flip-flop)
The first two methods will produce identical combinational logic, while the third will produce a sequential circuit where the output is registered on the clock edge.
