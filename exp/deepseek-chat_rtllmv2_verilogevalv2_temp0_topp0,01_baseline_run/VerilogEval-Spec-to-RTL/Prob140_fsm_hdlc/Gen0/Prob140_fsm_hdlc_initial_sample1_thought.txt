To implement the HDLC framing decoder, we'll create a Moore FSM with states representing the count of consecutive 1s seen. The states will be:
- STATE_0: Initial state (0 consecutive 1s)
- STATE_1: 1 consecutive 1
- STATE_2: 2 consecutive 1s
- STATE_3: 3 consecutive 1s
- STATE_4: 4 consecutive 1s
- STATE_5: 5 consecutive 1s (potential discard case)
- STATE_6: 6 consecutive 1s (flag case)
- STATE_ERR: 7+ consecutive 1s (error case)

The FSM transitions between states based on the input bit:
- If in STATE_5 and next bit is 0, output disc and return to STATE_0
- If in STATE_5 and next bit is 1, move to STATE_6
- If in STATE_6 and next bit is 0, output flag and return to STATE_0
- If in STATE_6 and next bit is 1, move to STATE_ERR
- Any state with 7+ 1s stays in STATE_ERR until a 0 is seen

Outputs are registered to ensure they last one full cycle.
