To implement this finite-state machine (FSM), we'll follow these steps:
1. Define a 3-bit state register to hold the current state (y[2:0])
2. Create combinational logic for next state calculation based on current state and input x
3. Implement synchronous reset that sets state to 000 when reset is high
4. Create output logic that sets z based on current state (1 for states 011 and 100, 0 otherwise)
5. Update state register on positive clock edges
