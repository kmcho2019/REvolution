To implement a 4-bit binary counter with a period of 16:
1. Use a 4-bit register to store the current count value
2. On each positive clock edge:
   - If reset is high, set the count to 0
   - Otherwise, increment the count by 1
3. The counter will naturally wrap around from 15 (4'b1111) back to 0 (4'b0000)
4. Output the current count value through q
