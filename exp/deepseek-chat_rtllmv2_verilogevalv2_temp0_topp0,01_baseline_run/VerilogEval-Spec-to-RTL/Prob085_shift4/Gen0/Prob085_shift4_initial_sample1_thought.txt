To implement a 4-bit shift register with the specified functionality, we need to consider the following:
1. Asynchronous reset (areset) should immediately set all bits of q to 0 when asserted.
2. Synchronous load (load) should load data[3:0] into q on the next clock edge.
3. Synchronous enable (ena) should perform a right shift (with q[3] becoming 0) on the next clock edge.
4. Load has higher priority than enable when both are asserted.
5. All synchronous operations occur on the positive clock edge.

The implementation will use an always block sensitive to posedge clk or posedge areset for the asynchronous reset. Inside the always block, we'll check areset first, then load, then ena in priority order.
