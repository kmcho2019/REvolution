The parallel-to-serial converter will work as follows:
1. On reset, clear all registers and outputs
2. When new 4-bit parallel data arrives (when counter reaches 3):
   - Load the parallel data into a shift register
   - Reset the counter to 0
   - Set valid_out high
3. For each clock cycle:
   - Output the MSB of the shift register
   - Left shift the register to bring next bit to MSB position
   - Increment counter
   - Keep valid_out high only for first cycle after load
4. The counter cycles through 0-3 to track which bit is being output
