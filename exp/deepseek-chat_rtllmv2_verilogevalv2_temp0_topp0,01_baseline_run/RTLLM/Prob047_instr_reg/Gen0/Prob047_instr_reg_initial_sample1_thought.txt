The instruction register needs to store instructions from different sources based on the fetch control signal. We'll use two 8-bit registers (ins_p1 and ins_p2) to hold the instructions. On each clock edge, we'll check the reset signal first. If not reset, we'll update the appropriate register based on the fetch signal. The outputs will be derived from these registers: ins gets the top 3 bits of ins_p1, ad1 gets the bottom 5 bits of ins_p1, and ad2 gets the full ins_p2 value.
