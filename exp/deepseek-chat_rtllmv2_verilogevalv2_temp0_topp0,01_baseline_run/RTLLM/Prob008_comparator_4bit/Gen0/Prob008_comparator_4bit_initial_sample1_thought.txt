The 4-bit comparator can be implemented by performing a bitwise comparison starting from the most significant bit (MSB) to the least significant bit (LSB). The comparison logic follows these rules:
1. If A[3] > B[3], A is greater (A_greater=1)
2. If A[3] < B[3], A is less (A_less=1)
3. If A[3] == B[3], move to the next lower bit and repeat the comparison
4. If all bits are equal, A is equal to B (A_equal=1)

This approach avoids actual subtraction and instead uses hierarchical bit comparisons for better efficiency in hardware.
