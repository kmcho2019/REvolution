To implement the accumulator module, we need to:
1. Use a counter to track how many valid inputs we've received (0-3)
2. Accumulate the sum of 4 consecutive valid inputs
3. Reset the counter and sum when we reach 4 inputs
4. Output the accumulated sum and assert valid_out for one cycle when 4 inputs are received
5. Handle reset conditions properly

The key is to use a 2-bit counter to track input count and a 10-bit register to hold the accumulated sum (since 4x8-bit = 10-bit max).
