Refactor the combinational logic by using continuous assign statements and combinational functions instead of an always block.
This approach replaces the procedural block with purely declarative logic, potentially improving clarity and synthesis efficiency.
Two functions are defined: one for next_state, which takes the current state and input to return the next state; another for output, which returns the output value for the current state.
The output and next_state are then assigned by calling these functions.
This also eliminates the need for default assignments and reduces the chance of inferred latches by construction.
