I will implement the combinational logic using a 4x2-bit lookup table (LUT) style approach for next_state and a separate 4-bit vector for output. This uses the current state as an index to select the next states and output based on the input bit.

Specifically, I'll create arrays containing the next_state for input=0 and input=1 for each state, as well as an output vector per state. Then, using the current state and input, I will select the correct next_state and output by indexing into these arrays.

This approach modularizes the combinational logic into simple data structures and indexing, which synthesizes efficiently and is easy to extend. It also avoids multiple if-else or case statements, making the design concise and elegant.

Since the output depends only on the current state (Moore machine), out is selected directly from an array indexed by state. Next_state depends on both state and input, so two arrays for next_state are used and input selects between them.
