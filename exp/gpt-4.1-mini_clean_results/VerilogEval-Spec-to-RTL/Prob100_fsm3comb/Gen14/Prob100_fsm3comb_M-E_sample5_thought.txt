Implement the next_state logic and output logic using combinational always @* block with a case statement to clearly separate each state's behavior. This approach uses a direct mapping for each state and input condition, improving readability and making it easier for synthesis tools to optimize the multiplexer logic. The output is assigned inside the same combinational block based solely on the current state, consistent with Moore FSM design.
