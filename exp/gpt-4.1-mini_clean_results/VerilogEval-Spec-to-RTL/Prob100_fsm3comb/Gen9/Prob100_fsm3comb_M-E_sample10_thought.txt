I will implement the Moore state machine's combinational logic using a lookup approach with a packed array (memory) representing the state transitions and outputs. The current 2-bit state and input bit will be concatenated to form a 3-bit index, used to index the transition table.

This approach mimics a small ROM for the FSM transitions and outputs, simplifying future modifications and potentially enabling easier formal verification or test insertion.

The transition table entries store the concatenated next_state and output bit (3 bits total), and combinational logic extracts them accordingly. This structure can improve clarity and maintainability and may optimize logic by enabling shared decoding paths.

The state encoding remains unchanged (A=00, B=01, C=10, D=11).
