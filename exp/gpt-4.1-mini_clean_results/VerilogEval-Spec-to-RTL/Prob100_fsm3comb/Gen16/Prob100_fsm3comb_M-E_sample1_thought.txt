Implement the Moore state machine by expressing next_state as a combinational function of the current state and input using continuous assignments and bitwise logic rather than a case statement. This approach directly encodes the next_state bits from the current state bits and input, potentially reducing logic levels and improving synthesis optimization. The output is similarly assigned with a simple combinational expression. This style avoids always blocks altogether, favoring purely combinational assign statements that may result in smaller and faster logic for such a simple FSM.
