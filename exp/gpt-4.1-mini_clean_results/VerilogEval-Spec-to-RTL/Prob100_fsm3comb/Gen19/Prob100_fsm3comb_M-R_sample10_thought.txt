Refactor the module to use a combinational always block with a case statement for next_state and output logic instead of continuous assignments with nested ternary operators. This approach groups all logic within an always @(*) block, making the state transition and output logic clearer and potentially easier for synthesis tools to optimize by sharing logic. The output is directly set based on state inside the same block for Moore machine behavior. Using a case statement improves readability and maintainability, especially if the state machine grows. Outputs are declared as reg to support procedural assignment inside the always block.
