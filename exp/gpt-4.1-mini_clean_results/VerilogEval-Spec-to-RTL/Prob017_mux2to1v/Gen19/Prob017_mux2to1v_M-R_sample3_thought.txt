Refactor the code to implement the 100-bit 2-to-1 multiplexer using a single vectorized conditional assignment instead of multiple 2-bit mux module instantiations. Since the select signal is common and all bits are selected simultaneously, using a single `assign out = sel ? b : a;` simplifies the design, reduces intermediate signals and logic overhead, and improves power, area, and performance by enabling the synthesis tool to optimize the mux as one unit. This change retains the same functionality but with a cleaner and more efficient code structure.
