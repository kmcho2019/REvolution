Implement a simple ripple-carry adder using the built-in '+' operator in Verilog, which synthesizers typically optimize well. The sum is computed by adding 'a' and 'b' as signed 8-bit numbers, and the overflow is detected by checking if the sign of the sum differs from the sign of the inputs when both inputs have the same sign. This drastically simplifies the code by removing manual carry and propagate logic while keeping correct functionality for signed overflow detection.
