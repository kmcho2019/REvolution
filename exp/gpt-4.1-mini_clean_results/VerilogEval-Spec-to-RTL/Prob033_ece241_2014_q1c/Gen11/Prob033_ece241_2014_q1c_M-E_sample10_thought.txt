Implement a signed 8-bit adder using Verilog's built-in addition operator, leveraging the signed typecasting to simplify overflow detection.

The sum is computed by casting inputs to signed 8-bit values and performing addition, allowing natural two's complement behavior.

Detect overflow by checking if the sign of the result does not match the expected sign from the addition of two signed operands:

- Overflow occurs if both inputs have the same sign but the sum has a different sign.

This approach avoids manual carry and propagate/generate signal management, resulting in a concise and efficient design.

This solution exploits Verilog's signed arithmetic features to simplify implementation while correctly detecting signed overflow.
