To simplify the design, I will implement the 8-bit signed adder using the built-in Verilog addition operator, which automatically performs 2's complement addition. The sum output will be the 8-bit result of the addition. Overflow detection for signed addition can be done by checking if the sign bits of inputs are the same but differ from the sign bit of the result. This approach avoids explicit carry computations and makes the code much simpler and more concise while maintaining correct overflow detection.
