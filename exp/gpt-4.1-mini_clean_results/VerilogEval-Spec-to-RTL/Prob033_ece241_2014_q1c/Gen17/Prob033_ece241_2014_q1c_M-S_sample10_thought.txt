To simplify the design, implement the 8-bit adder using a single-level full adder addition with the built-in '+' operator in Verilog, which inherently supports 2's complement addition and provides the carry out as the 9th bit.

This approach eliminates explicit propagate/generate and carry-lookahead logic, drastically reducing code complexity and area while maintaining correct functionality.

Overflow detection can be done by checking if the sign bit of the inputs and output violate the signed overflow rules: overflow occurs if the sign bits of a and b are the same but differ from the sign bit of the sum.

This yields a concise, efficient design using native Verilog arithmetic and simple bitwise operations for overflow detection without manual carry chain logic.
