Fuse the modularity and clarity of the ripple-carry FullAdder with the efficiency of propagate/generate signals for carry-lookahead from the first example. 

Specifically:
- Define a FullAdder module that computes sum and propagate/generate signals internally.
- In TopModule, instantiate 8 FullAdders in a generate loop, each receiving carry-in and outputting carry-out, sum, and propagate/generate signals.
- Implement a simple carry-lookahead carry chain using the propagate/generate signals to compute carries in parallel (carries computed as c[i+1] = g[i] | (p[i] & c[i])), avoiding ripple carry delay.
- Compute sum bits inside each FullAdder using the carry-in for that bit.
- Calculate overflow as XOR of carry-in and carry-out at MSB, following signed overflow detection.
- This solution retains the structural modularity and clean interface of a ripple adder, but replaces slow ripple carry chain with faster carry-lookahead logic.
- Avoid unused signals by directly using the FullAdder’s sum output.
- This fusion balances speed, area, power, and code readability for an optimized 8-bit signed adder with overflow detection.
