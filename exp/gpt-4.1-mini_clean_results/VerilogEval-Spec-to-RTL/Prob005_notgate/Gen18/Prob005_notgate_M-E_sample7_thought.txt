Implement the NOT gate functionality in TopModule using a parameterizable unary operator module that can be extended to other unary operations in the future. The unary operator module takes an input signal and a parameter specifying the operation (in this case, inversion). This design introduces configurability and reusability by using a generate-if statement and parameters, allowing easy extension beyond just a NOT gate. While slightly more complex, it provides a scalable architecture for unary operations with clear separation of concerns and maintainable code. The TopModule simply instantiates this generic UnaryOp module with the inversion parameter.
