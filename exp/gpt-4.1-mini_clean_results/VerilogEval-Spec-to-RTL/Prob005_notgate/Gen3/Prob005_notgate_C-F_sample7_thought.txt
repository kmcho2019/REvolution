Fuse the advantages of both examples by using a continuous assignment for combinational logic (as in Example 1) while adopting the explicit assign statement style instead of a gate primitive. This combines clarity, simplicity, and synthesis friendliness. Unlike Example 2, avoid using reg and always blocks, which are unnecessary here. Unlike Example 1’s gate primitive, using an assign statement is more portable and clearer for tooling and readability. The output will be declared as wire by default (no reg), minimizing area and power by enabling synthesis tools to infer an optimal inverter implementation without overhead.
