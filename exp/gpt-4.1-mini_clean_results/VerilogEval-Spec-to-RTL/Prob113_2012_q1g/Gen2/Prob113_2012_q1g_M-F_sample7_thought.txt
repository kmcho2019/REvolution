The problem stems from incorrectly mapping the input vector x[3:0] to the Karnaugh map addressing scheme. The K-map rows are indexed by x[2]x[3], and columns by x[0]x[1], but the previous code reordered bits as {x[2], x[3], x[0], x[1]}, which mixes the row bits order.

Since the K-map rows are given by x[2] (MSB) and x[3] (LSB) in that order, the 2-bit row index should be {x[2], x[3]} (not {x[3], x[2]} or swapped). The column index is {x[0], x[1]} with x[0] as MSB and x[1] as LSB.

Thus the LUT address should be constructed as:

    addr = {x[2], x[3], x[0], x[1]}

With the bits in the correct order.
