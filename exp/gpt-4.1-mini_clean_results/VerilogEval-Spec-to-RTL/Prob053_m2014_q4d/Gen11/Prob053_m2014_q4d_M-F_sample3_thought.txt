Remove the initial block initializing 'out' since synthesis tools often ignore it, leading to mismatches in simulation vs. hardware behavior. Since the specification forbids a reset signal, we rely on the flip-flop power-up state being undefined, which matches typical FPGA/ASIC hardware behavior. This aligns the RTL with realistic synthesis output, avoiding false mismatches. The code otherwise remains the same with the XOR combinational logic feeding the D input of the positive-edge triggered flip-flop.
