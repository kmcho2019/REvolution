Implement the flip-flop output as an internal state register and compute the XOR output combinationally. The flip-flop captures the current input XOR the stored state on each clock edge, while the output is a wire directly driven by the XOR of 'in' and the stored state. This separates the sequential storage from output logic, emphasizing the XOR gate outside the flip-flop and making the code explicitly show the XOR as combinational logic feeding the flip-flop.
