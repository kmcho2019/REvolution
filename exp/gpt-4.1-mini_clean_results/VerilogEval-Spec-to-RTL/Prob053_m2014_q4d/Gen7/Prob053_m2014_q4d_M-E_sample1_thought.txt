Instead of directly using the output register as both the D input and the output, create an internal wire that represents the XOR of 'in' and the current flip-flop output. Then use a separate register to store the flip-flop output. This decouples the combinational XOR calculation from the storage element, making the design clearer. The output port is driven by this register. No reset is used, so initial value of the register is undefined as per spec.
