Instead of directly using a single flip-flop with the XOR, implement the same functionality by using a small register to hold the previous output value and a combinational block to compute the XOR input. The D flip-flop input is generated in a separate always_comb block, making the design structurally clearer. The output is registered in a flip-flop that samples the XOR result on the rising edge of clk. This approach splits combinational and sequential logic explicitly and can help with readability and synthesis optimization.
