Combine the modular clarity of explicit gate instantiation with the efficiency of using the built-in nor primitive. Instead of defining separate OrGate and NotGate modules (Example 1) or just directly instantiating a nor primitive (Example 2), create a custom NOR gate module built from the nor primitive itself. Then instantiate this custom NOR module within TopModule. This approach fuses hierarchical clarity and reusability with optimal PPA, enabling easier expansion or replacement of the NOR gate internals later if desired, while still using a single primitive internally for minimal delay and area.
