Implement the decoding using parallel comparisons combined with a priority encoder style approach. Create a set of one-hot wires where each represents whether the input code matches one of the recognized scancodes. Then use these one-hot signals to generate the output digit and valid bit via combinational logic. This approach avoids the explicit case statement, uses simple comparisons and multiplexing, and may be more scalable and conceptually clear. The valid signal is asserted if any match is found. The output is selected by encoding the matched position. This style clearly separates detection (matching) and output generation, which might help synthesis tools optimize the design efficiently.
