Implement a small combinational decoder using a case statement within a combinational always block to directly assign both the output digit and the valid flag simultaneously. This approach centralizes the decoding logic, making it easy to read and modify. By using a single always block that sets a temporary register for both outputs, we avoid multiple comparisons scattered throughout the code. When the input code matches a known scancode, the corresponding digit and valid flag are assigned; otherwise, both outputs default to zero.
