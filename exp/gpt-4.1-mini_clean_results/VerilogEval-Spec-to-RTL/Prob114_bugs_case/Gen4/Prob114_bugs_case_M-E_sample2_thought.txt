Implement the decoder using a priority encoder style approach with a series of parallel comparisons encoded into a single 4-bit output and a valid bit. Instead of a large ROM or a big case statement, use a parallel combinational logic block that matches the input code against each scancode and sets a corresponding bit in a 10-bit one-hot vector. Then encode that one-hot vector into a 4-bit binary output. This removes large ROM usage and keeps logic compact and explicit. The valid output is just whether any bit in the one-hot vector is set. This approach is synthesizable, easy to optimize, and reduces unnecessary decoding logic.
