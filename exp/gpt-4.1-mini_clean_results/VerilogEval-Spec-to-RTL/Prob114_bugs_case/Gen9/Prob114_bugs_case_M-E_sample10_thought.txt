Implement the decoder using a combinational always block with a packed array (lookup table) that holds the scancodes indexed by digit values 0 to 9. Iterate through the array to find if the input code matches any stored scancode. If matched, output the corresponding digit and assert valid; otherwise, output zero and deassert valid. This approach centralizes the scancode storage and lookup logic, making it easy to scale and modify. It also avoids redundant comparisons for valid signal generation by combining detection and output in a single loop.
