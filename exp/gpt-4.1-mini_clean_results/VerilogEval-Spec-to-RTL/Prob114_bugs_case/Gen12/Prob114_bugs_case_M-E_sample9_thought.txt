Implement the decoder using a combinational one-hot encoder style with parallel comparisons to each known scancode. Generate a vector of flags where each bit corresponds to a known key press. Then encode the position of the set bit into the 4-bit output using a priority encoder, and derive valid from whether any bit in the flags vector is set. This approach trades a small amount of area for straightforward parallel decoding without a large case statement, and makes valid assignment trivial by checking if any input code matched.
