Instead of directly using XOR/XNOR operators, implement the parity function by explicitly counting the number of high inputs and determining if that count is even or odd. Since all inputs are one-bit, we can sum them as integers (0 or 1) and then check the parity bit of the sum.

Sum a, b, c, d as integers → total count ranges from 0 to 4. The parity is even if total count[0] bit is 0. So:

- Compute sum = a + b + c + d (2-bit number)
- q = 1 if sum is even, else q=0
- Because sum can be up to 4 (3 bits to represent 0..4), but max sum is 4, 3 bits suffice.

Check parity: q = ~ (sum[0]) (sum[0] is LSB, indicating odd/even)

This approach realizes the same logic but via adder and parity check, rather than direct XOR/XNOR.

The design uses combinational addition and bit checking.
