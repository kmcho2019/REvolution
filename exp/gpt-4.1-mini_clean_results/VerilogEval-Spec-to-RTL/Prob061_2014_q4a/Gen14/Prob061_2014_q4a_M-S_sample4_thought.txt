To simplify the solution while maintaining the same functionality, I will combine the conditional assignments directly inside a single always block triggered by the clock edge. Since the current design only updates Q when either L or E is asserted, and otherwise holds the value, this minimal sequential logic is already quite simple.

Removing the separate combinational assignment for Q_next and directly encoding the priority in sequential logic reduces code lines and complexity, but doesn't change functionality.

This results in a very straightforward implementation with no additional logic or registers, only a single flip-flop with a simple priority scheme.
