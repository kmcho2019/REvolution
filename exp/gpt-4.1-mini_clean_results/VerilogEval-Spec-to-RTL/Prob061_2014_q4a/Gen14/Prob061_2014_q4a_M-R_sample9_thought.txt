Refactor the design to use a combinational next-state signal and a clock-enabled register update to separate combinational logic from sequential logic. This approach defines the next value of Q in a separate combinational always block, and the sequential always block simply updates Q on clk's positive edge. This separates the muxing logic from the register update, making the logic explicit and easier to modify or extend. We keep the same priority: load (L) > shift (E) > hold. The sequential block updates Q only when either L or E is asserted, thus implicitly enabling the clock for the register, similar to the original code but more explicit in the code structure.
