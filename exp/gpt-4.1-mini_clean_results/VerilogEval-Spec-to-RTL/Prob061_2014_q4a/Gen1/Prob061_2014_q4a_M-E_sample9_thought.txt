Implement the one-bit stage as a register with a combinational multiplexing logic that chooses the next state input based on L and E signals. Use a single always block triggered on the rising edge of clk, where the next state value is determined by priority: if load (L) is asserted, next state is R; else if enable (E) is asserted, next state is w; otherwise retain current Q value.
