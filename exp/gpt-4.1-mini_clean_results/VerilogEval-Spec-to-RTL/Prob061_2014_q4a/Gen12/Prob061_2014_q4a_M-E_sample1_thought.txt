Instead of using a single clock enable, implement a priority-based if-else structure within a single always block triggered by the positive edge of clk. When load (L) is asserted, the register Q immediately takes the value of R. Otherwise, if enable (E) is asserted, Q shifts in the value from w. If neither L nor E is asserted, Q retains its previous value. This approach uses no explicit clock enable signal, simplifying the clock path and making the logic straightforward. Additionally, it maintains clarity and guarantees that loading has priority over shifting.
