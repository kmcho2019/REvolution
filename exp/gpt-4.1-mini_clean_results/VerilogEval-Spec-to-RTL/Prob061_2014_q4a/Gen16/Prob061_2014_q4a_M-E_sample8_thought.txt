Implement the shifting and loading operation by explicitly defining the next state of Q with a combinational always block and then updating Q on the clock's rising edge. This separates next-state logic from sequential logic, which is a common design pattern that enhances readability and scalability. The next state defaults to Q (holding its value), changes to R if load (L) is asserted, or shifts in w if enable (E) is asserted and load is not active. This also clearly shows the priority order between load and shift.
