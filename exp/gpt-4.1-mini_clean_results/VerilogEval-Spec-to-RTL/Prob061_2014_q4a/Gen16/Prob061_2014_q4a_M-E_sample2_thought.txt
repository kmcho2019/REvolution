Implement a module that uses an asynchronous reset style for loading the register with value R when L is asserted, otherwise on each clock edge if E is asserted it shifts in w; if neither is asserted, Q holds its value. Instead of prioritizing with nested if-else, use combinational logic to select the next value based on L and E, and register that value on the clock edge.
