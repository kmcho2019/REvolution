Implement the TopModule with a single always block triggered on the positive clock edge, using an if-else priority structure: if load (L) is asserted, load R into Q; else if enable (E) is asserted, shift in the w value; else hold Q. This single-block synchronous design eliminates the need for separate combinational next-state logic and conditional register updates, which simplifies timing and reduces control overhead. The holding behavior is implicitly handled by not changing Q when neither L nor E is high, making the code concise and synthesis-friendly.
