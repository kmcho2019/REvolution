Refactor the design to use an explicit data register and a separate combinational always block for the mux operation. This separates combinational logic and sequential logic more clearly: one always block computes the next value of Q based on control inputs, and another updates Q on the clock edge. This approach avoids using wires for muxing and clock enable, instead uses an if-else inside the clocked always block with priority given to load, then shift enable. It preserves the same functionality but expresses the logic differently, making the flow explicit and easy to follow.
