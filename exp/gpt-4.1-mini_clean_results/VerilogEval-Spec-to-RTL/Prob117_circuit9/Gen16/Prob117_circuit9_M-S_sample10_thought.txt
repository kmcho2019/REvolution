Since the state progression is mostly an increment modulo 7 starting from 4, and input a forces the state back to 4, we can simplify the next-state logic by using arithmetic operations. On each clock rising edge, if a=1, reset q to 4; else increment q modulo 7, where modulo 7 means if q==6, next is 0, else q+1. This avoids a large case statement and uses simple arithmetic and comparison, reducing logic complexity.
