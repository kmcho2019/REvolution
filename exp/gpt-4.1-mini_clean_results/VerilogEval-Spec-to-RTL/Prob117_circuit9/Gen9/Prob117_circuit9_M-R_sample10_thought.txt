Refactor the design to use a combinational continuous assignment with a function to determine the next state, and a synchronous always block only to update the state register q. This separates the next state logic into a function that returns the next value of q based on current inputs. Using a function improves readability and modularity.

The main difference is that instead of a combinational always block, the next state is computed by a function called inside the sequential always block, making the design more concise and clear while preserving the same behavior.
