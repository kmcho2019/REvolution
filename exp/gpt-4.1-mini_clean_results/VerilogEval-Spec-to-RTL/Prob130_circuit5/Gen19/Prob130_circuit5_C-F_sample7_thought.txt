To fuse the best qualities of both examples, the solution will implement a clean, area- and power-efficient 4-to-1 multiplexer for c=0..3 using a case statement. For c≥4, q outputs 4'hF. This avoids the wide concatenation and shifting overhead of example 1, and avoids multiple gating AND/OR trees from example 2.

To reduce switching power, inputs will be gated by their select signals before muxing, but instead of ORing multiple gated inputs, the mux will be implemented via a case statement that assigns q directly, minimizing unnecessary transitions on unselected inputs.

The select signal will be clamped to 4 bits but only values 0..15 are valid anyway. For c≥4, default output 4'hF is used.

This design merges example 1's indexing concept clarity (mapping c values to outputs with a default) with example 2's power-conscious gating and a clean case statement implementation for area efficiency and straightforward synthesis.

The result is a minimal logic combinational block, with reduced switching on inputs, no large shifts or multiplications, explicit default output for out-of-range c, and easy-to-understand and synthesize code.
