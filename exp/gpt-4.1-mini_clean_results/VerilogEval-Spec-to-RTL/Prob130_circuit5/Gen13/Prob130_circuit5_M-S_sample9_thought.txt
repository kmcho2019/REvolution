Simplify the design by using a straightforward combinational `case` statement on input `c` to select the output `q`. This eliminates the need for multiple equality comparisons and bitwise masking, reducing logic and improving clarity.

The functionality is:
- c == 0: q = b
- c == 1: q = e
- c == 2: q = a
- c == 3: q = d
- otherwise: q = 4'hF

This approach directly assigns q based on the value of c, minimizing logic complexity and improving readability.
