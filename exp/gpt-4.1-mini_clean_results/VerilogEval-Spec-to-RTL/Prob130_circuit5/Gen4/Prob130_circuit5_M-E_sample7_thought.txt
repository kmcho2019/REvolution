A novel architectural idea is to use a small combinational truth table encoded via a case statement based on input c. Instead of packing inputs into a single vector and shifting, we can explicitly map each c value to the corresponding input or constant output. For values of c from 0 to 3, q outputs b, e, a, d respectively; for 4 and above, output 4'hF.

This approach leverages a case statement which is clear, synthesizes directly into a multiplexer and a comparator, and avoids any variable shifting or arithmetic. This can improve readability and ensure efficient hardware implementation by letting the synthesis tool generate an optimal mux tree.

The logic will be purely combinational, with no latches or flip-flops, and uses straightforward input-output mapping with constant fallback for out-of-range values.
