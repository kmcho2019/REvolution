Implement the 4-bit priority encoder using a parallel multiplexer and priority mask approach. First, create a mask that indicates which bits have higher priority bits set. Then use a priority logic expression to select the position of the first '1' bit by comparing input bits with the mask. This method avoids chained AND-NOT logic and uses bitwise operations and simple multiplexing to determine priority efficiently. Finally, encode the bit index to 2-bit output. If input is zero, output zero.
