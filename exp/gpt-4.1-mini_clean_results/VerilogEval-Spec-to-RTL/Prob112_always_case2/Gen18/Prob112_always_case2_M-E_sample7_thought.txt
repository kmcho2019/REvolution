Implement the 4-bit priority encoder using a combinational always block with a case statement that matches the input vector against one-hot patterns starting from the highest priority bit (bit 0) to the lowest (bit 3). This way, the synthesis tool can easily infer a priority encoder from the case structure. If none of the bits are set, the default output is zero. Using a case statement provides clarity and helps synthesis optimize area, timing, and power better than multiple AND/NOT gate combinations. The priority is explicitly encoded by the order of cases, enabling compact and efficient logic generation.
