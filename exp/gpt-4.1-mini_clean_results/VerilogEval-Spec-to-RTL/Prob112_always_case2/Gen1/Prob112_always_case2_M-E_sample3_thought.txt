Implement the priority encoder by using a combinational binary search approach: first check the upper half of the input bits; if any bit in the upper half is set, output a position with the high bit set and recurse into that half; otherwise, output the low half position. This avoids sequential if-else chains and uses bitwise operations and concatenation to determine the highest priority bit. The priority remains from MSB (bit 3) down to LSB (bit 0). If no bits are set, output zero.
