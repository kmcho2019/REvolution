Implement the 4-bit priority encoder using nested conditional (ternary) operators directly in a continuous assignment for the output. This approach uses combinational logic with a simple priority check from bit 0 to bit 3. If bit 0 is set, output 0; else if bit 1 is set, output 1; else if bit 2 is set, output 2; else if bit 3 is set, output 3; otherwise output 0. This design is compact, easy to understand, and minimizes logic levels compared to masking with multiple inverted signals.
