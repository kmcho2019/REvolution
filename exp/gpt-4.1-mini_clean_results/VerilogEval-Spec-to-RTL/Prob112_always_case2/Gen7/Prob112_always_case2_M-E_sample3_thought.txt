Implement the priority encoder using a combinational always block with a casez statement to directly map the input vector to the output position. The casez pattern treats 'z' and '?' as don't-cares, allowing for a concise and synthesis-friendly priority encoding: higher priority bits are matched first by specifying input patterns with '1' at the desired priority bit and '?' in the lower bits. This approach is compact, easy to read, and lets the synthesis tool generate optimized priority encoding logic, potentially improving area, power, and timing metrics. If no bits are set, the output defaults to zero.
