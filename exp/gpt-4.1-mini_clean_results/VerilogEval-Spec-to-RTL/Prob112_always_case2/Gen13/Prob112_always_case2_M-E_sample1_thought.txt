Implement the priority encoder by using a chained conditional operator (ternary operator) to directly encode the position of the first set bit starting from the lowest bit. This approach uses a purely combinational assignment without intermediate signals or a case statement. It effectively checks each bit in order, outputting the corresponding position when a bit is found set; if no bits are set, output zero. This technique is compact and synthesizes efficiently into minimal logic, suitable for small input widths while avoiding multiple intermediate wires.
