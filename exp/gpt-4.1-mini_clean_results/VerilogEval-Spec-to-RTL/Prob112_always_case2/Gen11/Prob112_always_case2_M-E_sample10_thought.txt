Implement the 4-bit priority encoder using a simple combinational logic that directly encodes the output position by checking each bit in priority order using if-else statements. Start checking from the highest priority bit (bit 3) down to bit 0, and assign the corresponding position output as soon as a '1' is detected. If no bit is set, output zero. This approach is straightforward, easy to understand, and synthesis tools will optimize the cascade into efficient combinational logic. It eliminates the need for intermediate signals and a case statement.
