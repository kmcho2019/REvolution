Combine the explicit priority mask signals from Example 1, which isolate the first set bit clearly and reduce glitches, with a simple if-else priority selection inside a combinational always block, avoiding priority case constructs. This fusion improves synthesis friendliness, reduces intermediate signals, and minimizes logic depth by using straightforward conditional logic. The output defaults to zero when no bits are set. This method is efficient, clear, and synthesizes to minimal logic with good power and performance characteristics, especially suitable for a small 4-bit input.
