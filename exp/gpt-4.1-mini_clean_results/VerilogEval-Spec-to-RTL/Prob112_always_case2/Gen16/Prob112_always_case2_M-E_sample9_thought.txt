Implement the 4-bit priority encoder using a casez statement that matches the input vector with bit patterns where the highest priority '1' bit is identified by the position of the lowest index bit set. The casez statement enables a compact and readable priority encoding by matching from the most significant input pattern down to the least. This approach simplifies the priority encoder design by directly mapping input patterns to position outputs, allowing the synthesis tool to optimize the logic efficiently. Additionally, by using casez with masked bits, the design naturally defaults to zero when no bits are set.
