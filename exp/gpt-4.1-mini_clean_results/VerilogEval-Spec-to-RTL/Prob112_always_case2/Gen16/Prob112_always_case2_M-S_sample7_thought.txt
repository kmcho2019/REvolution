Simplify the priority encoder by directly using a combinational casez statement on the input vector. This removes the need for individual priority bit select signals and explicit masking logic. The casez statement matches the input pattern with the highest priority bit set first, assigning the corresponding position. It is a concise and clear way to implement a priority encoder, and synthesis tools typically optimize this pattern efficiently. Default output is zero when no input bits are set. This approach reduces gate count and logic depth, making the design simpler and cleaner while maintaining functionality.
