Refactor the priority encoder by replacing explicit combinational gate logic with a single combinational always block using a `casez` statement. This approach is synthesis-friendly, compact, and lets the synthesis tool infer optimized priority encoding logic internally. The `casez` allows using a pattern matching syntax where ‘z’ acts as a wildcard, simplifying detection of the first high bit with priority from LSB to MSB. This improves readability, reduces explicit intermediate signals, and potentially optimizes timing and area by leveraging synthesis tool capabilities.
