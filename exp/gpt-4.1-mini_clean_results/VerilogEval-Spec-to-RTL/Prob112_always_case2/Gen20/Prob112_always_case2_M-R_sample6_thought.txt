Refactor the priority encoder by replacing the combinational always block and casez statement with a single continuous assignment using a nested conditional (ternary) operator. This approach directly encodes the priority by checking input bits in order from lowest to highest, producing the output position accordingly. The intermediate priority selection signals are still generated to clarify the priority order, but output logic is now purely combinational with an assign statement. This reduces the use of a procedural block, making the design more concise and still easily synthesizable. It also preserves the default zero output when no input bits are set.
