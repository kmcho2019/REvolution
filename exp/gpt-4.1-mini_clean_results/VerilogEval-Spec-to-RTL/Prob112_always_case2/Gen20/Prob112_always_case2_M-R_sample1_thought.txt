Refactor the priority encoder by replacing the always block and intermediate priority signals with a continuous assignment using a priority-encoded conditional (ternary) operator chain. This approach maintains the priority from bit 0 to bit 3 but removes explicit intermediate wires, making the code more concise and purely combinational with assign statements. The output will be directly driven by a combinational expression that encodes the position of the first high bit or zero if none are set. This enhances readability and may help synthesis tools optimize for a compact combinational logic implementation without explicit priority masks.
