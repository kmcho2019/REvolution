Use a simple combinational approach leveraging a casez statement with a wildcard pattern to match the input and output the position of the first set bit. This avoids explicit individual bit masking and priority signals by directly encoding the priority in the matching order of the casez statement. The casez statement will check from the highest priority (lowest index) pattern to the lowest, thus selecting the first bit that is set. If none of the bits are set, output zero. This approach is concise and clear, and synthesizes efficiently.
