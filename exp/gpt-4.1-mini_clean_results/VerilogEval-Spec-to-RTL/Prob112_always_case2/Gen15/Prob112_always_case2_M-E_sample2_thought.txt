Implement the 4-bit priority encoder using a small combinational always block with a priority-encoded case statement. Instead of explicit one-hot signals, use an always @(*) block that checks the inputs in order of priority, assigning the output position as soon as the first high bit is detected. If none are set, output zero. This approach is straightforward, maps well to typical priority encoder hardware, and uses a reg output type with combinational logic, offering a clean and readable alternative implementation without extra signals.
