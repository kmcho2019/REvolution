Implement the 4-bit priority encoder using a combinational always block with if-else statements, checking the input bits from highest priority (bit 3) to lowest (bit 0). Although the problem states priority encoder outputs the first high bit, the example interprets the first '1' from lowest index bit, so we check bits from 0 to 3 in ascending order. The if-else chain immediately assigns the output position once a '1' is found, otherwise outputs zero if no bits are set. This approach is simple, intuitive, and easy to verify while ensuring a minimal combinational path since the synthesis tool can optimize the priority logic efficiently.
