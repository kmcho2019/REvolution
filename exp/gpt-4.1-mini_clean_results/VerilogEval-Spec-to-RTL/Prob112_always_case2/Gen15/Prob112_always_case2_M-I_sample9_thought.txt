The original solution is functionally correct and clear but involves multiple inversions and AND gates to create masked signals, which can introduce unnecessary logic depth and switching power. To improve PPA (power, performance, area), I will remove the explicit masking logic and implement the priority encoder using a simple if-else ladder in a combinational always block. This approach reduces logic levels (no need for multiple inversions and AND gates per bit) and minimizes glitching since only one condition is true per output. It is also very succinct and maps efficiently to hardware. If the input is zero, output zero, otherwise output the index of the first set bit starting from LSB (bit 0). This is a standard and optimized approach for small priority encoders.
