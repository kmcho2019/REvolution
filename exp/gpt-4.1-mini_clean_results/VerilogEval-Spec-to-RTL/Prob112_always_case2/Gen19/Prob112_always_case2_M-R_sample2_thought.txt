Refactor the priority encoder to a purely behavioral combinational block using an always_comb block and a priority `casez` statement. This approach leverages synthesis tools' priority encoder recognition capabilities, which can optimize the logic better than explicit AND/NOT gate chains. The `casez` matches input patterns with wildcards, allowing a compact specification of priority from LSB to MSB. The output defaults to zero when no bits are set, satisfying the requirement. This style improves readability, maintains explicit priority, and facilitates efficient logic synthesis for better PPA metrics.
