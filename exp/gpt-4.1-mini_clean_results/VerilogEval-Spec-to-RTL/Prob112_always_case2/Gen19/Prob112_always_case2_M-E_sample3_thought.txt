Implement the 4-bit priority encoder by treating the input as a 4-bit number and outputting the index of the least significant set bit (lowest bit with a 1) directly by priority from bit 0 to bit 3. The design will use a single continuous assignment with a nested ternary operator based on the input vector's bits, which effectively encodes the priority order without intermediate wires. This creates a concise, readable, and efficient priority encoder without extra logic for one-hot signals.
