Implement the priority encoder using a combinational bitwise mask and a binary priority encoder by detecting the leftmost set bit starting from the MSB (bit 3) down to bit 0. The position output will encode the index of the first '1' bit found from the MSB side to the LSB side. This approach naturally prioritizes the highest index bit, which is often more common in priority encoder definitions. When no bits are set, the output is zero by default.

This design uses simple continuous assignments and combinational logic without procedural blocks. It first identifies which input bits are set, then applies a parallel priority encoding strategy using combinational logic and a series of nested ternary operators to select the highest priority bit index. This allows the synthesis tool to generate optimized priority mux logic without explicit sequential constructs.

The output pos has the index of the most significant set bit; if none set, output zero.
