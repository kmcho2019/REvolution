Implement the 4-bit priority encoder using a parallel combinational logic approach by directly mapping the input bits to the output using conditional (ternary) operators in a continuous assignment. This avoids always blocks and case statements, relying on the priority encoded in the order of conditional evaluation. The encoder outputs the position of the lowest index bit set to 1. If none are set, output zero. This style produces minimal logic depth, is easy to read, and synthesizes into efficient combinational gates.
