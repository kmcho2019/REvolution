Implement the 4-bit priority encoder using a simple combinational logic approach with nested if-else statements inside an always_comb block. The logic sequentially checks each bit from the highest priority (bit 0) to the lowest (bit 3), and outputs the index of the first bit set. If none are set, output zero. This approach avoids masking logic and makes the priority explicit and easy to follow, reducing potential glitches by using mutually exclusive conditions.
