Implement the 4-bit priority encoder using a single combinational always block with a priority-ordered case statement, which directly encodes the first active bit from MSB to LSB. This approach relies on behavioral constructs rather than explicit AND/NOT gates, allowing synthesis tools to optimize logic for area and timing better. By using a casez statement, we can compactly specify the priority of inputs, improve readability, and reduce logic depth and power by minimizing redundant signal generation. If no input bits are set, output zero.
