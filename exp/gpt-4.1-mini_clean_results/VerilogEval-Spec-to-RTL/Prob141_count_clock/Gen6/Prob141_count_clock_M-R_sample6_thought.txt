Refactor the design to use purely combinational logic to compute the next state values and synchronous registers to hold the current time. This separates combinational next-state logic from sequential state updates, improving clarity and potentially synthesis optimization. The pm flag, hours, minutes, and seconds registers update on the clock edge with synchronous reset and enable. Increment logic is done combinationally by building next_ss, next_mm, next_hh, and next_pm signals, then loading them into registers on clk. This approach preserves the 12-hour BCD clock behavior and pm toggle at 11→12 while making the control flow clearer and easing timing by removing nested function calls inside always block.
