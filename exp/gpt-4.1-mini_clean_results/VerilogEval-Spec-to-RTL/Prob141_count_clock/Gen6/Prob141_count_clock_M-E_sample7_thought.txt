Implement the clock counters using fully binary counters internally for seconds, minutes, and hours to simplify increment and rollover logic. Convert these binary values into BCD only for output by using combinational binary-to-BCD converters. This approach reduces BCD carry complexity inside the counters and consolidates complexity into conversion modules. The hour counter cycles 1 to 12; increment pm bit whenever the hour rolls from 11 to 12. On reset, initialize all counters to represent "12:00 AM". Use synchronous reset and update counters on positive clock edge when ena is high. This binary counting architecture simplifies the increment logic and can improve timing and clarity, while still presenting the required BCD outputs for hh, mm, ss.
