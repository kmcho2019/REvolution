Implement a Mealy FSM that detects the 1101 pattern using a shift register approach and encodes states as one-hot to simplify output logic. Use a 4-bit shift register to track the last 4 bits received for pattern detection, avoiding explicit multi-step matching states. After detecting the pattern, assert shift_ena for 4 cycles using a shift counter. Then enter counting state until done_counting is high, followed by done state until ack is received. Use synchronous reset and positive edge clocking. Outputs are mostly Mealy-type signals except done which is registered on entering the done state.
