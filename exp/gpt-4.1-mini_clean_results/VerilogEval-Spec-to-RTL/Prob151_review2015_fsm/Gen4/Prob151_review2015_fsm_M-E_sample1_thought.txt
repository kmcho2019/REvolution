Implement a Mealy-style FSM with distinct states: IDLE, SHIFT, COUNTING, and DONE. 

Use a separate 4-bit shift register dedicated only to detecting the start pattern 1101 continuously as data streams in. When the start pattern is detected, the FSM immediately transitions from IDLE to SHIFT state.

In the SHIFT state, assert shift_ena and count four shift cycles with an internal 2-bit counter (shift_count). During these four cycles, the FSM stops updating the pattern detector register to prevent interference between delay bit loading and pattern detection.

After completing four shifts, transition to COUNTING and assert counting output. The FSM remains here until done_counting input goes high.

Upon done_counting, transition to DONE and assert done output until ack input goes high.

After ack, return to IDLE and resume pattern detection by re-enabling the pattern shift register updates.

This approach cleanly separates pattern detection (IDLE), delay bit loading (SHIFT), counting wait (COUNTING), and done notification (DONE), using a dedicated pattern detection register that only operates in IDLE state, and a shift counter that controls exactly four shift cycles. The outputs are assigned combinationally based on the current state, simplifying output timing. Synchronous reset initializes all registers and FSM state to IDLE.

This design avoids mixing pattern detection and delay bit loading in the same register and clearly defines when pattern detection is active, ensuring robust timing and correct output alignment.
