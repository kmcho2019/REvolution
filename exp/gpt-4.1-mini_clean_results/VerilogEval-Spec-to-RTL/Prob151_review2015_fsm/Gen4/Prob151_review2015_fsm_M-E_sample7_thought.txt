Implement the FSM as a Moore machine with explicitly separate pattern detection logic using a dedicated 4-bit shift register and a pattern matched flag. The FSM states will be:

- IDLE: searching for the 1101 pattern by shifting in data continuously.
- LOAD: after detecting 1101, shift_ena asserted for exactly 4 cycles to shift in delay bits.
- WAIT_COUNT: assert counting, wait for done_counting signal.
- SIGNAL_DONE: assert done, wait for ack.
  
Use a shift register that always shifts in the data on every clock (except reset), continuously checking for the 1101 pattern. This decouples pattern detection from FSM state transitions.

Use a 2-bit shift counter to count the 4 cycles in LOAD state.

All outputs are registered (to avoid glitches) and updated synchronously on clock based on current state.

The FSM state register and shift counter are synchronous with reset.

This modular approach clearly separates the pattern detection data path from FSM control path, ensuring clean, glitch-free control signals and easy state management.
