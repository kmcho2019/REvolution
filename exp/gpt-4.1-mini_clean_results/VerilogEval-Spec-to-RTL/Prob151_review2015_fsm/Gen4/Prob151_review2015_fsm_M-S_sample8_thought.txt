Use a simple, enumerated single register FSM for clarity. Always shift in input bits to a 4-bit pattern register each clock cycle to continuously detect the start pattern 1101. When detected, transition to a SHIFT state where shift_ena is asserted for exactly 4 cycles (counting with a small counter). Then move to COUNTING state where counting is asserted and wait for done_counting input to go high. Afterward, assert done and wait for ack before returning to IDLE and resuming pattern detection.

This approach ensures continuous pattern detection without restricting shifts to a single state, simplifies state logic, and cleanly controls shift_ena timing. The outputs are registered based on state, and the synchronous reset brings the FSM to IDLE and clears registers. The design is straightforward and avoids separate registers for states or pattern detection.
