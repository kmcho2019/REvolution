Implement a finite state machine with the following states:
- IDLE: looking for the 1101 pattern by shifting in serial data bits
- SHIFT: after detecting 1101, enable shift_ena for exactly 4 cycles to shift in the delay bits
- COUNTING: assert counting output and wait for done_counting signal
- DONE: assert done output and wait for ack to return to IDLE

Use a 4-bit shift register to detect the 1101 pattern. On each clock, shift in data bit into this register.
When the shift register matches 1101 (binary), transition from IDLE to SHIFT.
In SHIFT, assert shift_ena for 4 cycles (count with a 3-bit counter).
Then transition to COUNTING, assert counting until done_counting is high.
Then transition to DONE, assert done until ack is high.
On synchronous reset, return to IDLE.

All outputs are 1-bit registers, updated synchronously.
