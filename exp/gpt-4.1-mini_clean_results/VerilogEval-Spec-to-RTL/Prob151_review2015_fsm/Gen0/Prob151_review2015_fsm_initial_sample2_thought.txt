Implement a finite state machine with the following states: IDLE (searching for pattern 1101), SHIFT (shifting in 4 bits while asserting shift_ena), COUNTING (asserting counting until done_counting is high), DONE (asserting done and waiting for ack). Use a 4-bit shift register to detect the pattern 1101 on the serial data input, updated every clock cycle. Upon detecting 1101, move to SHIFT state for exactly 4 clock cycles, then move to COUNTING, then to DONE, and finally back to IDLE on ack. The synchronous reset resets the state machine and shift register.
