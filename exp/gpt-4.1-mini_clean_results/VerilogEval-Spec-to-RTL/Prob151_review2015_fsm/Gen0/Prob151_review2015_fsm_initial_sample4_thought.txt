Implement a synchronous FSM with the following states:
- IDLE: looking for pattern 1101 on incoming data stream using a 4-bit shift register.
- SHIFT: once 1101 detected, assert shift_ena for 4 cycles to shift in 4 bits.
- COUNTING: assert counting while waiting for done_counting signal.
- DONE: assert done to notify user timer ended, wait for ack input.
On synchronous reset, go back to IDLE. Use a 4-bit shift register to detect the pattern 1101 on data input.
