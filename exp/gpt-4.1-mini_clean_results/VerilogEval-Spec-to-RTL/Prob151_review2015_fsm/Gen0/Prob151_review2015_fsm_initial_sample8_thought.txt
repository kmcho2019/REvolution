Implement a synchronous FSM with states representing: searching for the 1101 pattern by shifting in bits and checking, then a shift state for exactly 4 cycles asserting shift_ena, then a counting state asserting counting and waiting for done_counting, then a done state asserting done and waiting for ack. On reset, go to initial searching state. Use a 4-bit shift register to detect the start pattern 1101. Carefully control the outputs based on state and the 4-cycle shift counter.
