Implement a finite state machine with these states:

- IDLE: searching for the 1101 pattern by shifting in data bits serially.
- SHIFT: once pattern 1101 detected, assert shift_ena for exactly 4 clock cycles to shift in duration bits.
- COUNTING: assert counting and wait for done_counting input to go high.
- DONE: assert done output and wait for ack input to go high, then return to IDLE.

Use a 4-bit shift register to detect the 1101 pattern in IDLE. All sequential logic triggered on posedge clk with synchronous active-high reset.
