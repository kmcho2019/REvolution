Implement a finite state machine with the following states:
- IDLE: looking for the pattern 1101 in serial data input
- SHIFT: after detecting 1101, assert shift_ena for exactly 4 cycles to shift in 4 bits
- COUNTING: assert counting, wait until done_counting input goes high
- DONE: assert done, wait for ack input to go high, then return to IDLE

Use a 4-bit shift register to detect the pattern 1101 serially. 
Use a 2-bit counter to count 4 cycles during SHIFT state. 
All state transitions happen synchronously on posedge clk with synchronous reset.
