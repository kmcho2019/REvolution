Simplify the FSM by reducing the number of explicit pattern-match states for detecting "1101" into a shift register that keeps the last 4 input bits and checks the pattern in one step. This removes the multiple SEARCH states and replaces pattern detection with a single combinational check. Also, combine the shift counter with a small 2-bit register and keep state encoding minimal (only four states): IDLE (searching pattern), SHIFT (shifting 4 bits), COUNT (waiting for done_counting), DONE (waiting for ack). Outputs are assigned based on state. This reduces state machine complexity and number of states while maintaining all functionality.
