To improve the PPA of the original FSM, apply one-hot state encoding to reduce the combinational logic in the next state and output logic, thereby improving timing (lower critical path delay) and reducing switching power. One-hot encoding typically enables faster state transitions at the cost of slightly more flip-flops, which for this small FSM is acceptable.

Additionally, integrate a clock enable signal for the shift counter so it increments only during SHIFT, minimizing unnecessary toggling. Keeping synchronous reset and the Moore output style preserves clarity and correctness.

This approach increases flip-flop count marginally but simplifies and speeds up combinational logic, thus improving timing and power with minimal area impact. Outputs remain purely combinational from state signals. Also, the FSM uses a single always_ff block for state and shift_count update for clean synchronous logic.

Overall, this enhances timing and reduces power by simplifying combinational paths and gating register toggling, fitting well with the original functional requirements.
