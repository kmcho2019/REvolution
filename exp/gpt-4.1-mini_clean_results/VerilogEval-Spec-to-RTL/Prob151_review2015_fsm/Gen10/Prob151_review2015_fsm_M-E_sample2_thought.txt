Implement the FSM with a Mealy-style output for shift_ena driven directly by a shift counter and a pattern detector using a 4-bit shift register that shifts in data each cycle. Use a simple 3-bit state machine for high-level control: IDLE (search pattern), SHIFT_DELAY (shift 4 bits), WAIT_COUNT (wait done_counting), WAIT_ACK (assert done, wait ack). The pattern detection is performed by comparing the lower 4 bits of the shift register to the pattern 1101 at each clock cycle to start the timer. The shift_ena output is asserted only during the SHIFT_DELAY state for 4 cycles using a 3-bit counter. Use synchronous reset. Outputs are mostly Mealy (shift_ena from counter and state), others are Moore style for simplicity. This reduces complexity by embedding pattern detection into a shift register instead of multiple states and handles shift cycles with a separate counter and minimal state machine stages.
