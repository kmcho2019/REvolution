Use a Moore FSM with distinct states for pattern detection using a dedicated 4-state sequence detector that recognizes '1101' serially on each clock. Once the pattern is detected (on the last bit), transition to a SHIFT_4_BITS state where shift_ena is asserted for exactly 4 cycles, controlled by a 3-bit counter. After shifting, enter a COUNTING state asserting counting, waiting for done_counting to go high, then move to DONE asserting done and waiting for ack. The state machine resets synchronously on reset. All outputs depend only on the current state for glitch-free signaling. This approach cleanly separates pattern detection from the main FSM states, avoids ambiguous pattern detection timing, and ensures precise output timing.
