Implement the FSM using a Moore-style approach with a dedicated 4-bit shift register to continuously track the incoming serial bits and detect the pattern 1101 immediately when it appears. Use the shift register to detect the pattern on every clock cycle without waiting for full state transitions, enabling immediate response. Once the pattern is detected, transition to a SHIFT state where we count exactly 4 cycles using a simple 2-bit counter to enable shift_ena, shifting in the delay duration bits. After these 4 cycles, go to COUNTING state and assert counting output until done_counting is asserted. Then go to DONE state asserting done output until ack is received, then return to IDLE and resume pattern detection.

Use synchronous reset and positive edge clocking for all sequential logic. Separate the combinational next-state and output logic from sequential state update. Outputs are pure functions of the current state. The shift register and shift counter are updated every clock cycle as needed. This approach gives a clean modular FSM with precise control over pattern detection and shifting cycles, ensuring outputs align correctly with states and timing.
