To optimize the FSM for better PPA, the main strategy is to simplify state encoding and reduce combinational logic complexity. Using one-hot encoding for states can improve timing (WNS) because each state bit directly enables output and transitions, reducing decoding logic delay. Although one-hot uses more flip-flops, this small FSM's area increase is negligible and usually improves clock frequency and reduces critical path delay.

Also, reduce shift_count toggling by enabling it only during SHIFT state and holding otherwise. This is done by using a load or enable signal on the counter instead of resetting it every cycle outside SHIFT.

Finally, outputs remain simple combinational functions of one-hot state bits, yielding faster output decoding.

- Change to one-hot state encoding with 7 flip-flops for 7 states.
- Add a shift_count enable to increment only during SHIFT.
- Keep synchronous reset active high.
- Keep combinational next_state logic simple.
