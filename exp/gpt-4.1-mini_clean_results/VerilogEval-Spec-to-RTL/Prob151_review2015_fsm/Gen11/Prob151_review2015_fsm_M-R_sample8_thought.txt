Refactor the FSM by implementing a Moore FSM with one-hot encoding to simplify the output logic and state decoding, removing the need for a next_state variable. Use a single always_ff block for state transitions with synchronous reset and counters, and implement outputs using continuous assign statements derived directly from the one-hot state bits. This approach improves clarity of output signals by directly tying them to state bits and eliminates the separate combinational next-state logic block. The shift counter is kept as a separate register incremented only in the SHIFT state, reset otherwise. This style is common in FPGA designs and can improve synthesis and timing due to simpler decoding logic.
