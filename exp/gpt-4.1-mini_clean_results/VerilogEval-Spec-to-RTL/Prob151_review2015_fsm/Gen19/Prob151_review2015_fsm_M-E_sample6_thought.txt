Implement a Moore FSM with five states: SEARCH (pattern detection), SHIFT_BITS (shift 4 bits), COUNTING (wait for done_counting), DONE (assert done and wait for ack), and RESET. Instead of using a 4-bit shift register for pattern detection, use sequential states representing partial matches of the pattern 1101. On each clock, transition through these partial match states based on input data, allowing overlap detection. When full pattern is detected, transition to SHIFT_BITS where shift_ena is asserted for 4 cycles counted by a 3-bit counter. Then transition to COUNTING, asserting counting until done_counting is high. Afterward, go to DONE state asserting done, waiting for ack before going back to SEARCH. All outputs depend only on state, ensuring clean Moore FSM behavior, simplifying timing and improving output stability. The FSM uses explicit pattern matching states instead of a shift register.
