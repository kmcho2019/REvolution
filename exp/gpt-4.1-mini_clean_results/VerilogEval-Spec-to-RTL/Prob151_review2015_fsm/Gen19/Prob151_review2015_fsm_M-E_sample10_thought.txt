Use a one-hot encoded FSM with separate one-hot states for each pattern match step and shifting cycle, implemented in a fully registered style with outputs registered for glitch-free operation. The pattern detector is integrated into the FSM via sequential states for each pattern bit. Instead of multiple SHIFT states, implement a 2-bit shift counter register that counts the four shift cycles while in a SHIFT state. After shifting, transition to COUNT and DONE states. Outputs are registered and asserted based on state and shift counter. This reduces the number of states by leveraging a small counter and uses one-hot encoding to simplify next state logic and improve timing.
