Implement a Moore FSM with one-hot encoding for each state to maximize timing performance at the expense of some area. Use a 3-bit shift register to detect the pattern 1101 in a streaming fashion by shifting in each new data bit and comparing the register to the pattern. When the pattern is detected, transition to a SHIFT state where a 3-bit shift counter counts exactly 4 cycles of asserting shift_ena. Then move to a COUNT state asserting counting output and wait for done_counting input. Upon done_counting high, assert done output in the DONE state and wait for ack input before returning to the initial SEARCH state to detect the pattern again. All outputs are Moore-style, driven purely by the state. Reset synchronously returns the FSM and counters to initial states. Using one-hot encoding simplifies next-state decoding and output logic, improving timing, and the shift register simplifies pattern detection without requiring multiple sequential states dedicated to pattern partial matching.
