Implement a 5-state Moore FSM using one-hot encoding for clear and fast state decoding. Use a 4-bit shift register to detect the pattern 1101 serially on every clock cycle, enabling immediate detection including overlapping sequences without complex state transitions. When the pattern is detected, transition to the SHIFT state, where a 4-bit counter counts clock cycles to assert shift_ena exactly 4 times. After shifting, move to COUNT state, asserting counting output until done_counting input is high. Then go to DONE state, asserting done output until ack input is high, after which the FSM returns to initial state to detect the pattern again. All state registers and counters have synchronous active-high reset. Outputs are generated solely by state registers (Moore machine), minimizing glitches. This architecture cleanly separates pattern detection from FSM states, reduces combinational logic complexity, and supports immediate overlapping detection by using a shift register for the pattern input.
