Simplify the FSM by reducing the number of states to the minimum needed to detect the "1101" pattern in a sequence. Use a 2-bit counter for the 4-bit shift phase and a simple state machine with only 5 states: SEARCH (pattern detection), SHIFT (shift 4 bits), COUNT (wait done_counting), DONE (assert done, wait for ack). Pattern detection can be done with fewer states by remembering partial matches implicitly and resetting on mismatch. Outputs are assigned combinationally from state, with synchronous active-high reset and positive-edge clocking. This simplification reduces state count and logic while preserving clear behavior.
