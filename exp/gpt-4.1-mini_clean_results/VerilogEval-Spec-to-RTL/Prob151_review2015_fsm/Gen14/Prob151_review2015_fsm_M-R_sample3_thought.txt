Refactor the FSM by separating the pattern detection into a dedicated 4-bit shift register and using a simpler FSM with fewer states. This modularizes the pattern detection logic outside the FSM, allowing the FSM to focus on controlling the sequence after the pattern is detected.

Key points of the refactoring:
- Use a 4-bit shift register to serially shift in data each clock cycle.
- Detect the pattern "1101" by comparing the shift register content.
- FSM states: IDLE (waiting for pattern), SHIFT (shift_ena asserted for 4 cycles), COUNT (waiting for done_counting), DONE (assert done until ack).
- Use a 2-bit shift counter (as in original) inside the FSM to track 4 cycles of SHIFT state.
- Outputs are assigned with `assign` statements based on FSM state for clearer timing and potential better synthesis.
- State encoding done via localparam for readability; state register updated synchronously.
- This structure may improve clarity, modularity, and could ease synthesis optimizations by decoupling pattern detection from control FSM.
