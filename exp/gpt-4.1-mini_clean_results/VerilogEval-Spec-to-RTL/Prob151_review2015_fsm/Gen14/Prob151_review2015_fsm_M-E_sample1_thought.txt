Implement the FSM using a Moore machine style with explicit pattern matching via a 4-bit shift register. The shift register holds the last 4 data bits; when it matches the start pattern (1101), the FSM moves to a shift phase.

Use a 3-state FSM:

- IDLE: continuously shift input data into a 4-bit shift register, waiting for the pattern.
- SHIFT: enable shift_ena output for exactly 4 cycles, tracked via a 3-bit counter, shifting in duration bits.
- COUNT_WAIT: assert counting output while waiting for done_counting input to go high.
- DONE_WAIT: assert done output, wait for ack input, then return to IDLE.

Use synchronous reset and a single always_ff block for state, counters, and shift register updates.

Derive outputs purely from the current state for clarity. This centralized data path approach simplifies pattern detection and decouples FSM logic from complex partial pattern states, improving maintainability while fully satisfying the requirements.
