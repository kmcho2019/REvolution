Refactor the FSM by using a one-hot encoded state machine with a registered next_state update and purely combinational logic for next_state determination. Instead of a large case statement, use individual state flags and conditions to control transitions, which can ease synthesis and improve timing by simplifying combinational logic paths. The shift counting is still unfolded into four separate shift states but represented as individual one-hot state bits. Outputs are generated by simple OR-reduction of the state bits. This structure reduces logic depth in the next-state combinational block and enables easier optimization.
