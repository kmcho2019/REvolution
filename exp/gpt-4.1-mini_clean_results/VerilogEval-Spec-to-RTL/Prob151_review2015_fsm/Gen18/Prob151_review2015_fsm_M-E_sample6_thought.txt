Implement the FSM using a shift register to detect the pattern 1101 continuously on the serial input 'data'. Once the pattern is detected (shift register equals 4'b1101), transition to a SHIFT state where a 3-bit shift_counter counts 4 cycles to enable shift_ena. Then move to COUNT state waiting for done_counting, followed by DONE state asserting done until ack is asserted. Use one-hot encoding for states to simplify combinational logic and reduce critical path delays. Synchronous active-high reset sets the FSM to IDLE. Outputs are asserted based on state for glitch-free Moore outputs. This approach uses a dedicated pattern detector via shift register instead of separate pattern matching states, simplifying the FSM states and possibly improving clarity and scalability for longer patterns.
