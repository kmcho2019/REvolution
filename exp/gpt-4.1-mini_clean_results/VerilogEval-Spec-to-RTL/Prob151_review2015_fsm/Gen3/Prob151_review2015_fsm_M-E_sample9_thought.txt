Use a Moore FSM with five states: SEARCH, SHIFT0, SHIFT1, SHIFT2, SHIFT3, COUNTING, and DONE, where the SHIFT states correspond to each of the four shift cycles needed to load the delay bits.

Implement an explicit 4-bit pattern shift register only in SEARCH and SHIFT states to detect the pattern 1101 and to shift in the 4 delay bits exactly once each clock cycle during SHIFT states. This avoids continuously shifting data during COUNTING and DONE states, preventing overlap or pattern confusion.

The pattern shift register updates during SEARCH and SHIFT states only. Upon detecting 1101 in SEARCH, transition to SHIFT0. Each SHIFT state asserts shift_ena for exactly one clock cycle, sequentially from SHIFT0 to SHIFT3.

After SHIFT3, transition to COUNTING state, asserting counting output until done_counting goes high.

When done_counting is received, transition to DONE, assert done output until ack is asserted, then return to SEARCH state.

Outputs (shift_ena, counting, done) are registered and based on current state, ensuring stable output signals synchronized with FSM.

This approach cleanly separates pattern detection, shifting, counting, and done notification phases with explicit states, removing counters and complex timing logic for shifting. It also prevents pattern detection from interfering during counting and done phases.

Reset synchronously sets FSM to SEARCH and clears pattern shift register and outputs.

This explicit state progression clarifies timing and avoids ambiguity, aligning outputs precisely with each phase.
