Implement a Moore FSM that uses a 4-bit shift register to detect the pattern "1101". 
The shift register continuously shifts in incoming bits, and pattern detection is done by comparing the register contents to "1101". 
When the pattern is detected, move to a SHIFT state that asserts shift_ena for 4 cycles using a 2-bit counter.
After shifting, transition to a COUNT state asserting counting until done_counting is received.
Then go to DONE state asserting done until ack is asserted, then return to IDLE searching again.
Using a shift register for pattern detection simplifies the FSM to fewer states and offloads pattern matching logic, improving modularity.
All outputs are purely combinational functions of the current state.
Synchronous active-high reset initializes the FSM and counter.
