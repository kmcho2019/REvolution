Implement a Mealy FSM that uses a 4-bit shift register to detect the "1101" pattern in serial data. On each clock cycle, the shift register shifts in the new data bit. The FSM monitors this register directly to detect the start pattern, avoiding multiple search states. Once the pattern is detected, the FSM moves to a SHIFT state where shift_ena is asserted for 4 cycles controlled by a dedicated 3-bit shift counter.

After shifting, it enters COUNT state asserting counting, waiting for done_counting to be asserted. Then it moves to DONE state asserting done until ack is received, after which it resets to idle and restarts detection.

The outputs depend on the FSM state. The synchronous reset clears the FSM state, the shift register, and counters. This approach separates pattern detection (via the shift register) from the FSM states, resulting in fewer states and simpler transition logic compared to explicit pattern matching in states.

This leads to a compact, modular design:
- Shift register for pattern detection
- FSM with four states: IDLE (waiting for pattern), SHIFT (shift delay bits), COUNT (wait counting), DONE (done ack)
- Shift counter counts precisely 4 cycles of SHIFT asserting shift_ena
- Output signals derived from state

This structure should be easy to understand, efficient, and support overlapping pattern detection due to the continuous shifting.
