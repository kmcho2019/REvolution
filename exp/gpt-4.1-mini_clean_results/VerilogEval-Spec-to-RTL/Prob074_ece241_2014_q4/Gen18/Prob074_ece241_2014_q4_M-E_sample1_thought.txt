Implement the FSM by explicitly modeling the three D flip-flops as always blocks triggered on the positive clock edge, with a synchronous reset signal that initializes all flip-flops to zero. Instead of using a separate initialization register or relying on initial blocks, encode an internal reset using a simple power-on-reset counter that holds reset active for a few clock cycles after startup, ensuring defined initial states without an input reset port. The combinational logic for each flip-flop's D input is computed directly before the clock edge, with the gates implemented as separate wires. The final output is assigned as a NOR of the flip-flops' outputs. This approach separates reset logic cleanly and guarantees stable startup behavior while maintaining FSM correctness and simplicity.
