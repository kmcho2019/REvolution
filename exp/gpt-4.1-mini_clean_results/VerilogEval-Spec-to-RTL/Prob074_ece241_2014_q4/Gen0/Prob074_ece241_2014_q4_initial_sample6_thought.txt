Implement three D flip-flops each storing one bit. On every positive clock edge, update each flip-flop's value according to the specified logic:

- d1 = x XOR q1
- d2 = x AND (~q2)
- d3 = x OR (~q3)

Then, compute z = NOR(q1, q2, q3). Initialize q1, q2, q3 to zero on reset (assumed at start).

Since no explicit reset input is given, we can initialize the flip-flops to zero using an initial block.
