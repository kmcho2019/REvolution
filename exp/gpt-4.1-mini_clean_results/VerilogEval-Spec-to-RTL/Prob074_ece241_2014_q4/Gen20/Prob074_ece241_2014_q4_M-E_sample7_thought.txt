Implement the design by explicitly modeling three D flip-flops with asynchronous active-low reset inputs, directly driven by a global asynchronous reset signal initialized at simulation start via an initial block. The combinational logic for each gate (XOR, AND, OR) uses the current flip-flop outputs (or their complements) as the second input along with 'x'. The flip-flop inputs are driven by the gate outputs. On each positive clock edge, if reset is not asserted, the flip-flops capture these gate outputs; otherwise, they reset asynchronously to zero. The output z is a NOR of the three flip-flop outputs. This approach clearly separates combinational and sequential logic, ensures immediate initialization to zero at simulation time 0 via the async reset, and matches the problem's assumption that flip-flops start at zero before the FSM begins.
