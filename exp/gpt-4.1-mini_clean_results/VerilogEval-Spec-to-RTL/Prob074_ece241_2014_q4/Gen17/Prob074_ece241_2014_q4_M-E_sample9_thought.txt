Instead of using separate flip-flops for each gate output, implement a single 3-bit register that holds all three flip-flop states. Compute the three D inputs as bits of a bus, where each bit corresponds to the output of XOR, AND, and OR gates respectively with the input `x` and the respective previous output bits. Then update the 3-bit register at the positive clock edge. Finally, produce output `z` as the NOR of all bits of this register. Initialize the 3-bit register to zero using a synchronous reset signal internally generated as active during the very first clock after simulation starts (using a simple reset synchronizer). This avoids relying on initial blocks and models the reset behavior in synthesis-compatible style without an external reset input. This approach consolidates all flip-flops into one vector for cleaner logic and easier state handling.
