Implement the three D flip-flops with synchronous reset to zero at start using an initial block to set flip-flops to zero for simulation correctness, since the problem states they start reset to zero. Use simple combinational assignments for the D inputs with the described logic: XOR uses current flip-flop output as second input, AND and OR use complemented flip-flop outputs as second inputs. On each positive clock edge, update the flip-flops with these computed D inputs. The output z is the NOR of the three flip-flop outputs. This keeps the design simple, clear, and matches the problem behavior.
