Implement the 100-bit reversal by using a recursive divide-and-conquer approach via a parameterized module BitReverseN. 
- BitReverseN takes an N-bit input and outputs an N-bit bit-reversed vector.
- For N=1 (base case), it outputs the input directly.
- For larger N, it splits the input into two halves, recursively reverses each half, then swaps their positions to complete the bit reversal.
- This approach structurally mirrors the recursive definition of bit reversal and requires no indexing arithmetic beyond splitting.
- The top module instantiates BitReverseN with N=100 to perform the entire bit reversal in a single hierarchical module.
- This is a scalable, elegant solution that can be reused for other sizes and emphasizes modularity and recursion over loop generate.
