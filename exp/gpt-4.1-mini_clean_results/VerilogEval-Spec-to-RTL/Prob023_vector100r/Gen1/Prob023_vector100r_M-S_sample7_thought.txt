Since the input and output are vectors of the same width, the bit reversal can be achieved concisely by assigning the output to the input vector indexed in reverse order using the part-select with a decrementing index. Verilog supports vector slicing with a decrementing range, so simply assigning out = in[0 +: 100] reversed as out = in[99:0] reversed as out = in[0+:100] reversed to out = in[99:0] reversed. The simplest way is out = in mirrored by indexing [0:99] in reverse as [99:0].
