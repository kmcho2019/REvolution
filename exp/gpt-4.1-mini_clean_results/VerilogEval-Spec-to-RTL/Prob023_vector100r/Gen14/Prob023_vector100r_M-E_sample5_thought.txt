Implement the bit reversal using a sequential approach with a shift register and a counter inside a clocked process. The idea is to serially shift input bits into a shift register from LSB to MSB over 100 clock cycles, effectively reversing the bits in time rather than all at once combinationally.

The module takes the 100-bit input and, upon a start signal (or immediately if combinational), on each clock cycle shifts in one bit starting from in[0] up to in[99]. The bits are loaded into a register by shifting left, so after 100 cycles, the register contains the reversed bits of the input.

Output is registered, and a valid flag indicates completion. This approach trades latency for simpler logic, reduces combinational fanout, and can improve timing and power by pipelining the operation.

For simplicity, we'll create a module with an input clock and start signal, output valid signal, and output the reversed bits once done.

This also introduces stateful sequential logic, which is a novel architectural approach compared to fully combinational methods.
