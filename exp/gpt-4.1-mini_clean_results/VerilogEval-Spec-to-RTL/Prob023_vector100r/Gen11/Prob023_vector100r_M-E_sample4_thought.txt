Instead of using a function or a generate loop, implement the bit reversal with a for-generate construct that directly assigns each bit of the output to the corresponding reversed input bit. This explicitly creates parallel combinational assignments for each bit pair, which synthesis tools can optimize easily. The TopModule simply instantiates this BitRevN module with a parameter N=100.

This approach uses explicit generate blocks to map bits, making the design structurally clear and can sometimes produce more straightforward netlist connections in synthesis. It is fully combinational and parameterized for any input width.
