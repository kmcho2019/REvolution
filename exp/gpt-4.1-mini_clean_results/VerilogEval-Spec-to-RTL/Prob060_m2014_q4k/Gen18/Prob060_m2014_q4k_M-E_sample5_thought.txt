Implement a 4-bit shift register directly as a single always block using a 4-bit register vector to hold the entire shift register state. On each clock rising edge, if resetn is low, synchronously reset the entire register to zero. Otherwise, shift in the input bit into the least significant bit position, shifting the existing bits left by one. The output is assigned to the most significant bit of the shift register vector.

This approach avoids multiple instantiated DFF modules and uses a compact and efficient register vector, which can synthesize to an optimized shift register structure with minimal logic overhead.

It also ensures synchronous active-low reset behavior by resetting the whole vector in one step inside the always block, simplifying control logic and reducing instance count.

This design is minimal, efficient, easily readable, and offers clean reset and shift semantics.
