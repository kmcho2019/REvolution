I will refactor the 4-bit shift register to use a single always block with a 4-bit register vector instead of four separate D flip-flop instances. This approach condenses the logic into a behavioral shift register, reducing module instantiation and improving code compactness and readability. The synchronous active-low reset is still handled inside the always block on the positive clock edge. The output is assigned to the MSB of the shift register.

This structural change keeps the functionality identical while changing the coding style from modular DFF instantiation to a compact behavioral register shift.
