I will implement the 4-stage shift register as a single 4-bit register and perform the shifting operation inside an always block on the positive clock edge. The synchronous active-low reset will clear all bits of the register simultaneously. This approach uses a vector register instead of individual flip-flop modules and leverages concatenation and bit-slicing to implement the shift register behavior. This method is more compact and idiomatic in Verilog and emphasizes behavioral modeling rather than structural instantiation.

This approach:
- Uses a single 4-bit register for the entire shift register state.
- Implements synchronous active-low reset in one place.
- Performs shifting and loading logic concisely in a single always block.
- Outputs the last bit of the shift register as 'out'.
- Maintains the same interface and timing semantics as requested.
- Provides a clean and scalable solution that can easily be extended.
