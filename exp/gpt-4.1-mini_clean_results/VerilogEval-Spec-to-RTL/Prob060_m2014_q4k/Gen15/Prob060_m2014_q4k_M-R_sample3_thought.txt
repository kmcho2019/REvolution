Refactor the 4-stage shift register to use individual flip-flop registers rather than a vector register. Each stage is represented by a separate reg, shifting data stage by stage on the clock edge with synchronous active-low reset. This makes the shift register stages explicit, improving code readability for beginners and easing debug visibility. The output is assigned from the last stage register. All flip-flops update in the same always block with non-blocking assignments for correct synchronous behavior. This approach trades a bit of compactness for clarity, avoiding vector concatenation and making each shift step explicit.
