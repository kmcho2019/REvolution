I will implement the 4-stage shift register using a single 4-bit register vector instead of four separate flip-flops. The 4-bit register will shift in the new input bit on each clock's positive edge. The synchronous active-low reset will clear all bits in the register to zero. This approach reduces the number of explicit modules instantiated, simplifies wiring, and allows the synthesis tool to optimize the register as a vector. The output will be the most significant bit of the shift register to maintain the same interface.

This approach:
- Uses one vector register to implement four shift stages.
- Keeps synchronous active-low reset.
- Simplifies code by avoiding explicit DFF instantiations.
- Potentially improves area and power due to optimized vector register implementation.
- Outputs the last shifted bit as the output.
