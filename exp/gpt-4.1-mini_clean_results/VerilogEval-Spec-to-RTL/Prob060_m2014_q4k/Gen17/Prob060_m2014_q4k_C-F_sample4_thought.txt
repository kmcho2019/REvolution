Combine the modular clarity and explicit per-flop synchronous active-low reset of the DFF_SR module from Example 1 with the compact, single-vector shift register implementation from Example 2 to create a hierarchical yet efficient design.

The fusion strategy is:

- Retain the dedicated DFF_SR module for clear, reusable, and explicit synchronous active-low reset behavior on each flip-flop.
- Implement the ShiftReg module with a single vector register for the shift register state, but clock the vector through the DFF_SR modules instead of separate reg bits. This means:
  - Internally, instantiate four DFF_SR flip-flops (in a generate loop) which are chained to shift the input.
  - Maintain modular reset logic per flip-flop for clearer reset synthesis and debug.
- By doing so, the design gains:
  - Modular, reusable DFF building blocks with explicit reset, improving testability and tool friendliness.
  - A clean, concise parameterized shift register interface.
  - Potentially better power and area optimization opportunities by giving synthesis tools explicit flip-flop reset control while also using vector logic in ShiftReg.
  - Enhanced clarity for the reset mechanism alongside the structural organization from Example 1.
- The TopModule remains a simple wrapper instantiating this ShiftReg with WIDTH=4.

This fusion yields a well-structured, scalable, and clear shift register with synchronous active-low reset, blending modular clarity and succinct vector usage, optimizing for synthesis, power, area, and maintainability.
