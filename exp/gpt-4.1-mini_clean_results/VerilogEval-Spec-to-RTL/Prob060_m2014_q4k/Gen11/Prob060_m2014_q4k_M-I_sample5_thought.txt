To optimize the shift register for better power efficiency without changing its synchronous active-low reset behavior or output timing, I will add a clock enable (ce) signal that is driven by whether the input bit differs from the last bit in the register or any internal state changes.

This clock enable will prevent unnecessary toggling of flip-flops when the input is the same as the last shifted out bit, minimizing transitions and thus dynamic power. Since the shift register always shifts in the input bit, if the input bit does not cause a state change, the shift register can hold its current state.

Implementation details:
- Add a clock enable signal to the always block, which is asserted only when the shift register content would change (i.e., when the input bit differs from shift_reg[0], since shifting in the same bit as the LSB means no bit changes).
- The reset condition stays synchronous and active-low.
- The output remains the MSB of the shift register.
- This approach reduces switching activity and dynamic power with negligible area overhead.
- The design remains simple, clean, and synthesizable.

This small enhancement leverages a clock enable to reduce toggling when input is stable and matches the shifted-out bit, achieving better power efficiency without affecting performance or area noticeably.
