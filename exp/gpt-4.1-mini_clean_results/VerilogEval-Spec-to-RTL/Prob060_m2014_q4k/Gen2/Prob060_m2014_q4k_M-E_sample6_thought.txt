Implement the 4-stage shift register using a 4-bit shift register vector instead of separate flip-flops, but update it by concatenation in a single always block to make the code more concise. Also, keep the synchronous active-low reset and positive-edge clock. 

This vectorized approach allows compact representation and easy scalability if the shift register length changes. Output is the MSB of the shift register, representing the oldest bit shifted in. The shift register content is shifted left with the new input at LSB each clock cycle.
