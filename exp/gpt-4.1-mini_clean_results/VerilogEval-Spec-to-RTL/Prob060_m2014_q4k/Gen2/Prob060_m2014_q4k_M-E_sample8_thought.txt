Instead of a simple linear shift register, implement the 4-stage shift register using a single 4-bit register that rotates bits left on every clock cycle, where the input bit feeds into the least significant bit position. On reset, the register is cleared to zero. This circular shift approach reuses the register as a rotation buffer and provides the same shifting behavior. The output is taken from the most significant bit, which corresponds to the last stage of the shift register. This reduces the number of sequential assignments and uses a concise vector operation, potentially improving readability and enabling efficient synthesis for shift/rotate primitives.
