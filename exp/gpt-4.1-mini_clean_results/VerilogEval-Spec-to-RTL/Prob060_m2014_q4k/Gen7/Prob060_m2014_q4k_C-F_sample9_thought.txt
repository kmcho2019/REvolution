Combine the compact, vector-based shift register of Example 1 with the modular clarity and explicit reset logic of Example 2's individual DFF instances by implementing a parameterized ShiftReg module that internally instantiates a generate loop of DFF submodules chained together. This fusion preserves:

- The clean vectorized interface and output assignment from Example 1 for simplicity.
- The explicit synchronous active-low reset and positive-edge clocking handled inside each DFF for clear timing and reset behavior.
- Modularity and clarity, aiding debugging and potential reuse of the DFF primitive.
- Scalability through a parameterized WIDTH, easily adapting shift register size.
- Single-bit connectivity between DFFs to explicitly show data flow and ease timing analysis.

The TopModule simply instantiates the ShiftReg with WIDTH=4. This approach enhances maintainability, synthesis control, and code readability while keeping the register compact and efficient.

Additionally, non-blocking assignments ensure correct sequential behavior, and synchronous active-low reset is consistently used. This fusion leverages both approaches' strengths, balancing modularity with vector handling.
