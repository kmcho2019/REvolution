Implement the 4-bit shift register using a single 4-bit register vector inside one always block triggered on the positive clock edge. Use synchronous active-low reset to clear the entire register when reset is asserted. Shift input data in at each clock cycle by concatenating the input with the upper 3 bits of the register. Output the least significant bit of the register as the final output. This approach reduces module instantiation overhead, simplifies the design, and is more synthesis-friendly while maintaining the exact same functionality.
