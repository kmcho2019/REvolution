To simplify the design, I will implement the 4-bit shift register using a single 4-bit register instead of four separate DFF modules. The shift register will shift in the input bit at each clock cycle on the positive edge, with synchronous active-low reset clearing the entire register to zero.

Key points:
- Use a single always block triggered by posedge clk.
- On resetn low, clear the 4-bit register to zero synchronously.
- Otherwise, shift left by one, inserting the new input bit at LSB.
- Output the MSB of the shift register as the output.
- This approach reduces module instantiations and wiring, making the code more concise and efficient while maintaining functionality.
