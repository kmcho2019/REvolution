Fuse the modular clarity and explicit DFF instances from Example 1 with the compact and efficient vectorized shift register approach from Example 2, but enhance modularity by creating a reusable DFF module with parameterized synchronous active-low reset and a generate loop to instantiate exactly four DFFs in a chain.

This way:

- Each flip-flop is an instantiated module, aiding clarity, reusability, and potential for targeted optimizations at the DFF level.
- The shift register stages are implemented using vectorized internal wiring for clean connections and compact code.
- Synchronous reset is handled once per DFF module, ensuring reset fanout is localized and scalable.
- Using a generate block to instantiate the DFF array reduces manual wiring errors and is easily scalable.
- The 'TopModule' interface remains minimal, instantiating a separate ShiftReg module built on modular DFFs.
- This fusion ensures modular design, concise code, and clear reset and clock semantics, enabling good PPA and maintainability.
