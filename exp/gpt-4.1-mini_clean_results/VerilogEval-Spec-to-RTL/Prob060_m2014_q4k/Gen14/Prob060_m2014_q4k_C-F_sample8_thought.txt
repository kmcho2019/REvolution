I will create a 4-bit shift register using a single 4-bit register vector updated synchronously on the positive clock edge, incorporating an active-low synchronous reset. This consolidates all flip-flops into one always block, reducing area by enabling register packing and simplifying the design, while maintaining clarity.

Key points of the fusion strategy:
- Use one always block with a 4-bit register vector instead of multiple separate DFF module instantiations, which reduces area and may improve synthesis optimization.
- Keep synchronous active-low reset semantics with non-blocking assignments for correct simulation and synthesis.
- Output the last bit of the shift register as the module output.
- This approach merges the modular reset behavior and clarity of the separate DFFs with the area and performance benefits of a vectorized register.
- The code remains clean, easy to understand, and fully meets the requirements.
