We need to create a module with a 100-bit input vector and three 100-bit output vectors. For out_both, each bit (except the last) is the AND of the bit and its left neighbor; the last bit is zero. For out_any, each bit (except the first) is the OR of the bit and its right neighbor; the first bit is zero. For out_different, each bit is 1 if the bit differs from its left neighbor, with wrap-around from bit 0 to bit 99.
