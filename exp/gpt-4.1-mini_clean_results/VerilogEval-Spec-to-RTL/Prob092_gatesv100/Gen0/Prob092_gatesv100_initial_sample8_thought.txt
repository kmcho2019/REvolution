For out_both: For bits 0 to 98, set out_both[i] = in[i] & in[i+1]. For bit 99, set out_both[99] = 0 as it has no left neighbor.

For out_any: For bits 1 to 99, set out_any[i] = in[i] | in[i-1]. For bit 0, set out_any[0] = 0 since it has no right neighbor.

For out_different: Since the vector is wrapped for this one, for each bit i, its left neighbor is (i+1) mod 100. So out_different[i] = in[i] ^ in[(i+1) mod 100].
