We need to process a 100-bit input vector to produce three 100-bit outputs based on neighbors:

1. out_both[i] = in[i] & in[i+1], except out_both[99] = 0 because in[99] has no left neighbor.
   Note: "Neighbour to the left" means the bit with a higher index (to the left in index ordering).
   So for bit i, neighbour to the left is in[i+1] for i < 99. out_both[99] = 0.

2. out_any[i] = in[i] | in[i-1], except out_any[0] = 0 because in[0] has no neighbour to the right.
   "Neighbour to the right" means the bit with a smaller index. So for i>0, out_any[i] = in[i] | in[i-1].
   out_any[0] = 0.

3. out_different[i] = in[i] ^ in[left_neighbor], where left_neighbor wraps around:
   left neighbor of in[0] is in[99], and for others it is in[i+1].
   So out_different[0] = in[0] ^ in[99]
   For i in 1..99, out_different[i] = in[i] ^ in[i-1]

Implement the logic with appropriate bit-slicing and indexing.
