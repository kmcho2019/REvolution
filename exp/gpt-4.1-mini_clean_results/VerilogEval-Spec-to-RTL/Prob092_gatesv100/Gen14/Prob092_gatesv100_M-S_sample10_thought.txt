We can use vector shifting and bitwise operations directly to simplify all outputs without explicit indexing. For out_both, shift the input vector left by one and AND with the original, then zero out the MSB. For out_any, shift the input vector right by one and OR with the original, then zero out the LSB. For out_different, XOR the vector with a one-bit left-rotated version of itself, which we can create by concatenation. This approach removes explicit slicing and uses concise vector operations.
