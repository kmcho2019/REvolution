We can simplify by using consistent indexing and vector shifts without explicitly splitting assignments. For out_both, shift the input right by 1 bit and AND with the original, then set the highest bit to zero. For out_any, shift left by 1 and OR with original, then set lowest bit zero. For out_different, use XOR of the input with a rotated version where the MSB is concatenated to the rest. This avoids multiple assignments and uses clean vector operations.
