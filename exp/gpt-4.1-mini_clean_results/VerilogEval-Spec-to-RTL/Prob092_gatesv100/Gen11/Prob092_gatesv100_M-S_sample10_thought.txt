Use direct bitwise operations and avoid explicit masks by setting the bits that have no neighbor directly to zero after calculation using simple concatenation. For out_both, AND the input with the input shifted right by one and set the MSB to zero by concatenation. For out_any, OR the input with the input shifted left by one and set the LSB to zero similarly. For out_different, XOR the input with the input rotated left by one bit. This removes the need for explicit masking and makes the logic clearer and simpler.
