Instead of directly using bit-slice operations for neighbors, use explicit bit-index looping inside a generate block to individually assign each output bit. This approach clarifies the neighbor relationships per bit and explicitly handles boundary conditions. For out_both, each bit except the last depends on in[i] and in[i+1]. For out_any, each bit except the first depends on in[i] and in[i-1]. For out_different, wrap-around means the left neighbor of bit 0 is bit 99, so use modular indexing explicitly. This gives clear, readable logic and can be adapted easily for variable widths.
