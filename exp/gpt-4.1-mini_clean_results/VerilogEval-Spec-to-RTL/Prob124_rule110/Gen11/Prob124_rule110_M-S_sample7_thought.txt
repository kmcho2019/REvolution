Simplify the design by directly computing next state bits inside a single always block without using a generate loop or intermediate wires.  
Use a zero-padded temporary vector inside the always block to handle boundary conditions, then update all cells in a for-loop.  
This reduces the code size and complexity by avoiding multiple continuous assignments and external wires, while still maintaining full parallel update and synchronous load.  
It is easy to read, synthesizable, and minimal.
