Use a shift register style approach by storing the current state in a 512-bit register and separately maintaining a 514-bit padded version of the state with zeros on both ends. At each clock cycle (if not loading), we update the padded register by shifting in the new bits derived from the updated state, so that we avoid repeated concatenations every cycle. Then compute the next state using three aligned slices from the padded register: left, center, and right neighbors. This decouples the padding from the main register and allows incremental updates, potentially simplifying timing and resource usage.
