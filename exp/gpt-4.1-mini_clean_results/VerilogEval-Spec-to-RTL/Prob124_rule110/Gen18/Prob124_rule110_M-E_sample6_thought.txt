Implement the 512-cell Rule 110 automaton as a single 512-bit shift-register-style state stored in a register. On each clock cycle, the entire 512-bit vector updates simultaneously by computing each cell's next state in parallel, using a fully combinational next-state logic block.

To handle neighbor bits (left and right neighbors for each cell), we treat the vector q as circularly bounded with zero padding at the boundaries, i.e., assume q[-1] = 0 and q[512] = 0.

The next state logic is computed in a combinational always block (or continuous assignment) that constructs three shifted vectors:
- left_shifted = {q[510:0], 0}  (left neighbor of each cell)
- right_shifted = {0, q[511:1]} (right neighbor of each cell)

Then, for each cell i:
- left = left_shifted[i]
- center = q[i]
- right = right_shifted[i]

Apply Rule 110 logic using the Boolean formula:
    next_q[i] = (~left & center) | (center ^ right);

On a clock edge:
- If load is high, q loads from data input.
- Else, q updates with next_q.

This approach uses one large 512-bit register and one combinational block for next state, simplifying control logic and minimizing inter-block connections.

The design is straightforward, easy to understand, and effective for moderate performance. It trades off modularity for simplicity and may have a longer combinational path but is easy to pipeline or optimize later.

Advantages:
- Single block, no inter-block boundary logic needed.
- Simple zero boundary conditions easily implemented.
- Fully combinational next-state logic in a single vector operation.
- Reduced wiring complexity.

Disadvantages:
- Potentially larger combinational delay due to 512-bit wide logic.
- Less modularity for partial updates or hierarchical design.

This is a clean baseline implementation to show a different architectural approach.
