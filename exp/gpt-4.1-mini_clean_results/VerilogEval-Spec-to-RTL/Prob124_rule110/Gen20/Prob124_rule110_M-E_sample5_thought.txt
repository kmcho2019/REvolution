Implement the Rule 110 cellular automaton with a two-stage pipeline to improve timing and modularity.

1. Create a 512-bit state register holding the current state.
2. Use a combinational module to compute the next state based on current state bits and zero boundary conditions.
3. To reduce combinational depth, break the next state calculation into two pipeline stages:
   - Stage 1: Extract and register the neighbors for each cell (left, center, right) in a 3-bit vector per cell.
   - Stage 2: Compute the next state bit from the registered neighbor triplet using a small LUT (case statement).
4. The first stage latch (neighbors) holds the neighbor data; the second stage latch stores next state.
5. Loading new data immediately updates the state register, resetting the pipeline.
6. This approach balances combinational depth over two clock cycles, enhancing timing without major area penalty.
7. Boundary conditions are handled by zero-padded concatenations as before.

This 2-stage pipeline is novel for this simple cellular automaton, providing a clear data flow separation from neighbor extraction to next state computation.
