Implement the full 512-bit Rule 110 cellular automaton in a single synchronous module using a fully combinational next-state calculation for all 512 cells at once. To handle boundaries, pad the current state with zeros on both sides, then compute each next state bit according to the Rule 110 truth table.

The next state of each cell depends on three bits: left neighbor, center, and right neighbor.

Use a direct combinational formula to compute all 512 next states in parallel. At each clock cycle:

- If load is high, load the data input into the state register.
- Else, update the state register with the computed next state.

This approach avoids complex multi-block boundary wiring and leverages the synthesis tool's ability to optimize a large combinational expression. The design is straightforward, easy to verify, and uses zero padding for boundaries implicitly.

The combinational logic uses the simplified boolean formula for Rule 110:

next = (~left & center) | (center ^ right)

which matches the given truth table.

This monolithic design may increase combinational path but eliminates inter-block wiring and registers, simplifying timing and easing routing complexity.
