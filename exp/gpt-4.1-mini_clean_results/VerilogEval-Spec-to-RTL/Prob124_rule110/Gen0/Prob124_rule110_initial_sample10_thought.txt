Implement a 512-bit register q to hold the current state of the cellular automaton. On each clock's positive edge:

- If load is high, load q with data.
- Otherwise, compute the next state for each cell according to Rule 110.

Since q[-1] and q[512] are assumed zero, treat cells outside the array as zero.

For each cell i in 0..511, determine left, center, right bits as:
  left = q[i+1] if i<511 else 0
  center = q[i]
  right = q[i-1] if i>0 else 0

Use these bits as the address into the Rule 110 truth table (3-bit input), mapping to the next state bit. Implement this update logic combinationally and store the next state in q on the clock edge.
