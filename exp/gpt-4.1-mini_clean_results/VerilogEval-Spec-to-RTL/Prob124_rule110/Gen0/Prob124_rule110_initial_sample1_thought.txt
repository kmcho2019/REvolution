Implement a 512-bit shift register representing the cellular automaton state (q). On each clock cycle, if load is high, load the 512-bit input data into q. Otherwise, update each cell of q according to Rule 110 using the 3-bit neighborhood formed by q[i+1] (left), q[i], and q[i-1] (right), treating out-of-range indices as 0. The next state for each cell is computed in combinational logic using the given truth table, then registered at the clock edge.
