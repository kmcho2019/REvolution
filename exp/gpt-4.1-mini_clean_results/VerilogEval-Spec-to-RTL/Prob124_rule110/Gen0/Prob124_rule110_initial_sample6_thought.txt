We will implement a 512-bit register q to hold the current state of the cellular automaton. On each positive clock edge, if load is high, q is loaded with the input data. Otherwise, the next state of q is computed according to Rule 110 applied to every cell in parallel. The neighbors outside the array are considered 0. For each cell i, the left neighbor is q[i+1] (or 0 if i=511), the center is q[i], and the right neighbor is q[i-1] (or 0 if i=0). Using these, we compute the next state of each cell based on the rule table. This next state vector is then assigned to q on the next clock edge.
