Implement a 512-bit wide register `q` representing the cellular automaton state. On each clock's positive edge, if `load` is high, load the input `data` into `q`. Otherwise, update each cell of `q` based on the Rule 110 lookup. For the update, determine the three-bit pattern formed by the left neighbor (q[i+1], or 0 at the boundary), the current cell (q[i]), and the right neighbor (q[i-1], or 0 at the boundary). Use the given Rule 110 truth table to assign the next state of the cell. This can be done efficiently by mapping the 3-bit pattern to the output bit using a combinational function or a small ROM implemented by case statements. Assign the updated state back to `q` synchronously.
