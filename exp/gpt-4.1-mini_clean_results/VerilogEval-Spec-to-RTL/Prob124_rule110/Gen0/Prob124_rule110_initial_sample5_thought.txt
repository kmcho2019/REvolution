Implement a 512-bit register q to hold the state of the cellular automaton. On each positive clock edge:
- If load is high, load q with data.
- Otherwise, update q based on Rule 110 applied to each cell.
Since the boundaries outside the 512 cells are 0, the neighbors for the edge cells are zero.
For each bit i, the next state depends on q[i+1], q[i], and q[i-1], with out-of-bound neighbors treated as 0.
Implement the logic combinationally to calculate the next state bits and register them in q at each clock cycle.
