Implement the byte-reversal by explicitly assigning each output byte in a continuous assignment statement using concatenation. This approach uses wires only, avoiding procedural blocks and reg outputs. It is fully combinational, with explicit wiring for each byte, which can help synthesis tools better optimize and minimize area and power by avoiding registers and loops.

The output is declared as wire and assigned using a single assign statement that concatenates input bytes in reverse order.

This solution is straightforward, easy to understand, and may provide better synthesis results in some tools by giving them direct structural information.
