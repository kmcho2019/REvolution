Refactor the synchronous reset D flip-flop by separating combinational next-state logic from the sequential state update. Implement a combinational always block to determine the next value of q based on inputs d and r, and a sequential always block triggered by clk to update q with that next state. This approach clearly delineates combinational decision-making from state storage, improves code readability, and is a common RTL coding style. The behavior and functionality remain identical.
