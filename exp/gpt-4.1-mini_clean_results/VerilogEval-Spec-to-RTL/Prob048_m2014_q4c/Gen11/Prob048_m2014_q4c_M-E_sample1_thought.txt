Implement the synchronous reset D flip-flop using two always blocks: one for the synchronous reset signal generation and one for the D flip-flop itself. The first always block creates an internal reset signal that is asserted synchronous with clk and reset input r. The second always block updates the output q on the rising edge of clk, setting q to 0 when the internal reset is asserted; otherwise, it samples the input d. This modular approach separates the reset logic from the flip-flop, making the design more modular and explicit, which can aid readability and potential future extensions.
