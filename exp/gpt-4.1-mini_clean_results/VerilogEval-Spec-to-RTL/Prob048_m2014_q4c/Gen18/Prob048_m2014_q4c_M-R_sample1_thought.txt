Since the core functionality is a D flip-flop with synchronous reset, I will implement it by modeling the register update with a temporary wire that encodes the logic of the reset and data input, and then assign that value to q inside an always block. This splits the combinational mux logic from the sequential storage. This approach keeps the synchronous reset behavior but structures the design as combinational logic feeding the next state register. This is a stylistic change that does not affect behavior.
