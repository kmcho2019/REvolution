Fuse the clean separation of mux and register from Example 1 with the straightforward synchronous reset handling from Example 2 by embedding the reset mux logic directly into the always block. This removes the extra combinational mux wire, reducing combinational path depth and minimizing switching nodes for power saving, while keeping the code clear and concise. The always block will conditionally assign 0 to q if reset is asserted, else assign d, thus combining clarity and optimality for performance, power, and area.
