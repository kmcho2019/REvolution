Implement a counter that counts from 0 to 999 using a linear feedback shift register (LFSR)-inspired approach combined with a modulo operation to wrap around. Instead of a straightforward binary count and equality comparison, use an arithmetic approach that increments the counter and then subtracts 1000 whenever it equals or exceeds 1000, leveraging an arithmetic comparator. This removes the need for a bitwise equality check and partial comparisons.

- Use a 10-bit register q for the counter.
- On each clock cycle, compute q_next = q + 1.
- If q_next reaches 1000 or more, wrap around by subtracting 1000, effectively performing modulo operation.
- Implement synchronous reset to zero.
- This design employs only one arithmetic comparator and subtraction which can be optimized by synthesis tools.
- It also provides a clean pipeline friendly structure, reducing logic duplication.
