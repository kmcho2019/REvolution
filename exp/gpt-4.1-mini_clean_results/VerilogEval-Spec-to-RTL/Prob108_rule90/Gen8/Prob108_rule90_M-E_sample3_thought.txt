Implement the 512-cell Rule 90 cellular automaton as a single 512-bit shift register storing the current state. On each clock, the next state is computed by XORing each cell's left and right neighbors, assuming zero padding on the boundaries. Instead of partitioning into blocks, the next state for all bits is computed in a fully combinational manner by shifting the stored register left and right (adding zeros at boundaries), and XORing the results. The result is registered on the rising clock edge. On load, the entire state loads the input data in one cycle. This approach simplifies boundary handling, eliminates inter-block signals, and centralizes logic for clean, flat implementation. It uses vector shift operators for concise next state logic.
