Implement the entire 512-cell Rule 90 automaton as a single 512-bit shift register with combinational logic that computes the next state by XOR-ing the left and right neighbors for all bits simultaneously. To handle boundaries, assume the cells outside the array are zero. On each clock cycle, the module either loads the full 512-bit state from input when load=1, or updates the state according to Rule 90. Instead of dividing the array into smaller blocks, the next state is computed directly by shifting the register left and right by one bit with zero padding on the edges, and XORing those two shifted vectors. This approach minimizes module instantiation and keeps the design compact and flat, relying on vector slicing and bitwise operations for clarity and efficiency.
