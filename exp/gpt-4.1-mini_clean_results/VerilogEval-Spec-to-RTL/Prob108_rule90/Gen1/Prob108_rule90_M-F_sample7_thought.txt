Separate the combinational next-state logic into an always @(*) block using blocking assignments (=) to compute next_q from the current q. Then, in an always @(posedge clk) block, update q with next_q or load data if load is asserted, using non-blocking assignments (<=). For boundary cells, treat neighbors outside the range as zero. This coding style improves synthesis compatibility by cleanly separating combinational and sequential logic, avoids loops inside sequential blocks, and uses appropriate assignment types.
