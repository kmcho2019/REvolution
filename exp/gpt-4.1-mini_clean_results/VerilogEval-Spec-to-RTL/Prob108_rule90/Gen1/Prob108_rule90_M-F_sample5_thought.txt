To correctly implement Rule 90 on a 512-bit vector with zero boundary conditions, calculate the next state for each cell i as the XOR of q[i-1] and q[i+1]. For boundary cells, use zero for out-of-range neighbors (q[-1] and q[512]). This can be done by forming two shifted versions of q, padded with zeros: one shifted left (right neighbors) and one shifted right (left neighbors). Specifically, concatenate 0 at LSB for left neighbors, and 0 at MSB for right neighbors, then XOR these two vectors to get the next state. Load data into q when load is high; otherwise update q with this next state on each clock edge.
