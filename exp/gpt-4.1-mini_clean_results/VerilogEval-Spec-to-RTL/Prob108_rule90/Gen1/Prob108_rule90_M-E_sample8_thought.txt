Instead of using a for-loop and combinational logic to compute the next state, instantiate a 512-bit shift register that holds the current state. On each clock cycle, if load is asserted, load the register with the input data. Otherwise, compute the next state by XORing the 512-bit register left-shifted by 1 (with a zero inserted at LSB) and right-shifted by 1 (with zero inserted at MSB), thus directly applying Rule 90 using bitwise operations. This approach leverages bitwise shifts and XOR, making the design more efficient and avoiding loop constructs altogether.
