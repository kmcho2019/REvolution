Refactor the design to store the entire 512-bit state in a single register and compute the next state combinationally using continuous assign statements. On each positive clock edge, update the register with the next state or load new data. This simplifies the hierarchy by eliminating the 64-bit block modules and boundary wiring logic, since we can handle boundary conditions with zero-padding directly in the combinational logic. This approach reduces module instantiations and boundary signal passing at the cost of a larger combinational XOR network. The code becomes simpler and easier to maintain, while still fully synchronous and functionally equivalent.
