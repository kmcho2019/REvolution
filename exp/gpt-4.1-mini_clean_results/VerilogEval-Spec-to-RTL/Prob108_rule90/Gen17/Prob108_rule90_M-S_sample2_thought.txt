Implement a single 512-bit register that holds the current state. On each clock cycle (if not loading), compute the next state by applying Rule 90: each cell is the XOR of its left and right neighbors, with zero assumed outside the boundaries. This eliminates modular blocks and boundary wiring complexity by directly computing the next state vector from the current state vector, using simple bit shifting and XOR operations. Loading directly sets the state to input data. This straightforward approach reduces code complexity, area, and improves clarity while preserving functionality.
