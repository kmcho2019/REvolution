Instead of computing each next state bit individually using neighbor access and conditional logic, this design forms two shifted versions of the current state vector: one shifted left by one (with zero filled in the LSB), and one shifted right by one (with zero filled in the MSB). Since XOR is bitwise and associative, the next state q_next can be calculated as the bitwise XOR of these two shifted vectors. This approach leverages vector-level operations, minimizing explicit per-bit conditional logic and potentially improving timing. The boundary zero conditions are naturally handled by zero-filling in the shifted vectors. The sequential block either loads the input data or updates q with q_next on each clock edge.
