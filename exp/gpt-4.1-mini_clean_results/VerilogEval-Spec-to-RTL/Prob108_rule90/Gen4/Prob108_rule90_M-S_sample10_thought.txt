Implement the entire 512-bit Rule 90 state as a single register vector. On each clock cycle, compute the next state for all 512 cells in combinational logic using a generate loop. For each cell, its next state is the XOR of its immediate neighbors, treating outside boundaries as zero. The load signal directly loads the entire 512-bit state. This simple, fully combinational next-state computation with a single always block reduces module hierarchy and inter-block signaling, simplifying the design while maintaining exact functionality.
