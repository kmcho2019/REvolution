Instead of partitioning into fixed blocks, implement the entire 512-cell Rule 90 automaton using a single shift register-based approach with a circular buffer concept and combinational logic that uses bitwise XOR with left and right shifted versions of the stored state. To handle boundaries as zero, explicitly mask the leftmost and rightmost neighbor bits so that the out-of-range neighbors appear as zero. On each clock cycle, compute the next state entirely in combinational logic from the current state and update the register. When load is asserted, directly load the input data into the register. This approach leverages wide bitwise operations and shifts, resulting in a concise and efficient implementation with minimal control complexity and no inter-block communication overhead.
