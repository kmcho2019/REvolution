This partitioning enables improved placement and shorter routing paths.

Additionally, we'll implement a clock enable (`update_enable`) signal that only updates the state when load is asserted or on subsequent clock cycles, minimizing unnecessary toggling on idle cycles. This approach reduces dynamic power by preventing constant updates when the state is static.

The boundary conditions remain the same (neighbors outside the range are zero). The sequential logic is updated on the positive clock edge, loading new data when `load` is high or advancing the state when `update_enable` is true.

This hierarchical and conditional update approach aims to improve timing by reducing combinational fanout and lowering power via clock gating, while keeping the area overhead minimal.
