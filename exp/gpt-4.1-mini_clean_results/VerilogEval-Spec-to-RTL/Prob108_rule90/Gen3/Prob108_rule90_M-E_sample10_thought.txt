Instead of computing the next state for all 512 cells in a single combinational step, split the 512-cell automaton into 8 blocks of 64 cells each. Implement a small 64-bit Rule 90 updater module that processes its block with zero boundary inputs at the block edges (except for inter-block boundaries). Then, connect these blocks in a chain, passing the boundary cells between adjacent blocks at each clock cycle to correctly compute the neighbors. On each clock edge, the blocks update their states simultaneously. Loading the entire 512-bit state sets all blocks in parallel. This hierarchical and modular approach can improve manageability and may facilitate pipelining or partial reconfiguration in future enhancements.
