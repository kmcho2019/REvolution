To simplify the design while maintaining functionality, I will implement the entire 512-bit Rule 90 cellular automaton as a single module without splitting it into blocks. This eliminates the complexity of managing inter-block boundaries and multiple module instantiations.

- The entire 512-bit state will be stored in a single 512-bit register.
- On each clock edge:
  - If `load` is high, load `data` directly into the state.
  - Else, compute the next state for all 512 cells in parallel.
- Boundary conditions assume `q[-1] = 0` and `q[512] = 0`.
- Next state for each cell `i` is `q[i-1] ^ q[i+1]` with the boundaries as zero for the first and last cell.
- Use a generate block to compute the next state bits combinationally.
- Assign the updated state back to the register using nonblocking assignment.

This approach greatly simplifies wiring and logic while preserving the exact Rule 90 update logic and the interface.
