Simplify the design by removing the modular 64-bit blocks and directly implementing the entire 512-bit Rule 90 logic in one always block. This reduces hierarchical complexity and eases understanding. The next state for each bit can be computed using simple combinational logic with boundary conditions of zero at the edges. On each clock, if load is asserted, load the input data; otherwise update the state according to Rule 90 by XORing the left and right neighbors (zero outside boundaries). This single-register vector implementation minimizes overhead while preserving the exact functionality.
