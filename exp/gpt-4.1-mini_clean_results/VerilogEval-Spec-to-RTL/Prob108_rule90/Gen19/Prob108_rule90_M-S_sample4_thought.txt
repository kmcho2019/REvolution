Simplify the design by using a fully vectorized approach: the next state of the 512-bit array is the XOR of the current state shifted left by 1 and shifted right by 1, padding zeros at the boundaries. This completely eliminates per-bit generate loops and inter-block boundary wiring. On each clock cycle, if load=1, load data; else update q to the next state computed as (q << 1) ^ (q >> 1) with zeros at the ends. This greatly reduces wiring complexity and area while maintaining the exact Rule 90 update logic.
