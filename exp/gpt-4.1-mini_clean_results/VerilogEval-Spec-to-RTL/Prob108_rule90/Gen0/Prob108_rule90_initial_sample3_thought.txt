Implement a 512-bit register q to hold the current state of the cellular automaton. On each positive clock edge, if load is asserted, load q with the input data. Otherwise, update q based on Rule 90: for each cell, calculate the XOR of its left and right neighbors. Treat q[-1] and q[512] as zero, so the edge cells only XOR with their single neighbor and zero. This can be done with bitwise operations: shift q left and right by one bit with zero padding and XOR the results to get the next state.
