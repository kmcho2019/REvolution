Implement a 512-bit shift register holding the current state of the cellular automaton. On each clock cycle, if load is high, load the register with the input data. Otherwise, update each bit according to Rule 90: the next state of each cell is the XOR of its left and right neighbors, assuming boundaries q[-1] and q[512] are zero. The next state calculation is combinational from the current state, and the state updates on the positive clock edge.
