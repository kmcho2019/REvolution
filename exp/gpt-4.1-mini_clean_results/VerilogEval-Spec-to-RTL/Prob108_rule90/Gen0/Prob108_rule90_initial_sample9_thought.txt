Implement a 512-bit register q to hold the current state of the cellular automaton. On each positive clock edge, if load is asserted, load q with the input data. Otherwise, update q to the next state according to Rule 90: each bit of q is the XOR of its immediate left and right neighbors, with boundary neighbors considered zero. This requires careful handling of the boundary bits q[0] and q[511]. The output q is always the current state.
