Instead of splitting the 512-bit state into 8 blocks and passing boundary signals between them, implement the entire 512-bit Rule 90 automaton as one unit. Use a single 512-bit register to hold the current state and calculate the next state by XORing the left-shifted and right-shifted current state, padding zero on both ends as per the boundary conditions.

On each clock cycle, if load is high, load the input data; otherwise update state with the computed next state.

This simplification reduces module hierarchy and inter-block wiring, leading to cleaner, easier-to-understand code without changing functionality.
