Implement the 512-bit Rule 90 cellular automaton as a single 512-bit shift register with combinational logic that computes the next state for all cells simultaneously. Use a combinational block to compute the next state as the XOR of the left and right neighbors of each cell, treating the boundary neighbors as zero. On each clock edge, if load is asserted, load the input data; otherwise update the register with the computed next state. This flat approach avoids breaking into blocks and instead relies on vectorized operations for simplicity and compactness.
