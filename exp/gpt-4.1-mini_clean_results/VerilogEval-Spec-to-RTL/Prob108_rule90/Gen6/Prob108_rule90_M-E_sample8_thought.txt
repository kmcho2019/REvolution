Implement the entire 512-bit Rule 90 automaton as a single register with combinational logic computing the next state in one step. To handle boundary cells, prepend and append a zero bit (off state) to the current 512-bit state, producing a 514-bit vector with 0 at both ends. Then compute the next state as the XOR of the left and right neighbors by indexing this 514-bit vector. This approach leverages vector slicing and XOR operations, avoiding multiple modules or complicated inter-block boundary passing. Loading the initial state is done by direct register assignment on load. This single large combinational block simplifies logic and control, making the design concise and conceptually clear.
