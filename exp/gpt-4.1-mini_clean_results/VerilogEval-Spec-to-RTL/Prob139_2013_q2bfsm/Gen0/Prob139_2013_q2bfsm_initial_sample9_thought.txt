Design an FSM with states to track the described behavior:

- State A: Reset state; FSM stays here while resetn=0.
- State B: After resetn=1, output f=1 for one clock cycle, then move on.
- States C0, C1, C2: Monitor the pattern 1,0,1 on input x over three clock cycles.
  - C0: Waiting for first '1' on x.
  - C1: Waiting for '0' on x after seeing first '1'.
  - C2: Waiting for second '1' on x after '0'.
- State D: Output g=1 for one clock cycle after pattern detected, then move to state E.
- State E: Monitor y for up to two clock cycles while g=1.
  - If y=1 within two clock cycles, stay in state E with g=1 permanently.
  - Else, move to state F with g=0 permanently.
- State F: g=0 permanently until reset.

All state transitions occur on positive clock edges. The reset is synchronous and active low.

Outputs f and g are registered outputs, updated on clock edges according to the state.

Use a parameterized encoding of states for clarity.

Implement the logic in always blocks:
- State register and synchronous reset.
- Next state combinational logic.
- Output combinational logic based on current state.

This approach cleanly separates state transitions and output logic, ensuring correct synchronous behavior.
