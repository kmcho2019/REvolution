Design a synchronous FSM with states representing the described behavior:
- State A: Reset state, output f=0, g=0.
- On reset release, transition to state B, output f=1 for one clock cycle.
- Then transition to state C, monitor x for the sequence 1,0,1 over three cycles using a sub-sequence detector.
- When sequence detected, move to state D, output g=1 and start monitoring y for up to 2 cycles.
- If y=1 within these 2 cycles, stay in state D indefinitely with g=1.
- If y!=1 after 2 cycles, move to state E, g=0 permanently.
- Reset brings back to state A.
Implement FSM and sequence detection using state registers and counters.
