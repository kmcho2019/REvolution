Implement a finite state machine (FSM) with several states to track the required behavior. Use synchronous active-low reset to initialize to state A. After reset is deasserted, output f=1 for one cycle, then monitor x for the pattern 1,0,1 over three clock cycles. When pattern detected, set g=1 and start monitoring y for up to two cycles. If y=1 within two cycles, keep g=1 permanently; else clear g to 0 permanently. Outputs f and g are registered signals updated on clock edge. FSM states: A (reset state), F_set (output f=1 one cycle), X1 (waiting for first x=1), X2 (waiting for x=0), X3 (waiting for x=1), G_monitor (g=1, monitoring y), G_hold (g=1 permanently), G_clear (g=0 permanently).
