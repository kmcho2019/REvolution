Design a FSM with distinct states representing the required behavior:
- State A: reset state, outputs f=0, g=0
- State B: after reset is de-asserted, output f=1 for one cycle
- States C0, C1, C2: monitoring x input for sequence 1,0,1 respectively
- State D: set g=1, monitor y for up to 2 cycles
- State E: g=1 permanently (success)
- State F: g=0 permanently (failure)

Transitions:
- On reset (active low), FSM goes to A.
- From A, when resetn is high, go to B (set f=1 one cycle).
- From B, go to C0.
- In C0, if x=1, go to C1 else stay in C0.
- In C1, if x=0, go to C2 else back to C0 (looking for sequence again).
- In C2, if x=1, go to D else back to C0.
- In D, start counter for 2 cycles, g=1:
  - If y=1 at any of these cycles, go to E (permanent g=1).
  - If counter expires without y=1, go to F (permanent g=0).
- E and F are terminal states until reset.

Outputs:
- f=1 only in B for one cycle.
- g=1 in D, E; 0 otherwise.

Implement synchronous reset logic and output assignments.
