Design a synchronous FSM with states as follows:
- State A: initial state after reset (f=0, g=0)
- After reset deasserted, go to State B: output f=1 for one cycle
- Then go to State C: monitor x input for the 3-bit pattern 1,0,1 over three clock cycles
- If pattern matched, move to State D: set g=1 and monitor y for at most two clock cycles
- If y=1 within two cycles, go to State E: g=1 permanently
- If y != 1 in two cycles, go to State F: g=0 permanently
Outputs f and g depend only on the state.
All sequential logic triggered on posedge clk.
resetn is synchronous active low, so on clk edge if resetn=0, go to State A.
