Implement the FSM using a clear 1-hot encoding with states representing each required phase explicitly:
- A (Reset state)
- F_PULSE (output f=1 for one cycle after reset de-asserted)
- WAIT_FOR_PATTERN (waiting to detect x sequence 1,0,1)
- G_PULSE (output g=1 for one cycle after pattern detected)
- MONITOR_Y_0 (monitor y for first cycle with g=1)
- MONITOR_Y_1 (monitor y for second cycle with g=1)
- G_ON (g=1 permanent)
- G_OFF (g=0 permanent)

Use a shift register of 3 bits to detect the x sequence 101. Only check for the pattern after at least 3 x samples have been shifted in. To do this, maintain a sample count from zero and start pattern matching only after count >= 3.

For y monitoring, transition through MONITOR_Y_0 and MONITOR_Y_1 states on successive cycles, checking y each time. If y=1 at any time, move to G_ON; if no y=1 after MONITOR_Y_1, move to G_OFF.

Outputs f and g are driven combinationally based on the current state only (Moore outputs). Reset is synchronous active low, transitioning to state A immediately.

This approach makes the FSM states and output assignments very explicit, easy to follow and verify timing, avoiding off-by-one mistakes by careful state sequencing.
