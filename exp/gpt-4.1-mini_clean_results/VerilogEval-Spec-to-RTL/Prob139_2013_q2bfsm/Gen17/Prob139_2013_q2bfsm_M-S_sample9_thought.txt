Implement a simple Moore FSM with clearly defined states and outputs, all updated synchronously on the clock edge with synchronous active-low reset.

- Use one state register, no separate next_state variable.
- Use a 3-bit shift register to sample and track last 3 x inputs in a single always block.
- Outputs f and g depend solely on the current state.
- Upon reset (resetn=0), state = A; outputs f=0, g=0.
- After resetn is deasserted (goes high), at next clock pulse output f=1 for exactly one cycle (state B).
- Then move to monitoring state (C) where x inputs shift in each clock cycle.
- When 3-bit x pattern equals 3'b101, move to state D where g=1 for one cycle.
- Then go to state E where g=1 is held and y input is sampled for up to 2 cycles.
- If y=1 detected within these 2 cycles, move to state F where g=1 held permanently.
- Else, after 2 cycles with no y=1, move to state G where g=0 held permanently.
- Use a small counter in E to count y-monitoring cycles.
- All operations done in a single always block for simplicity and precise timing alignment.
- Inputs x and y are sampled directly each cycle (no extra registers).
- This simplified approach matches specification behavior and avoids timing ambiguities by updating states and outputs only on clock edge.
