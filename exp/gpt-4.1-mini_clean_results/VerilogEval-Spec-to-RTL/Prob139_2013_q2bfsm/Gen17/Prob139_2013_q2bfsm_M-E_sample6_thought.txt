Implement a fully Moore-style FSM with explicit states reflecting each phase: reset hold, f pulse, x pattern detection (with separate states for detecting each bit of the sequence "1", then "0", then "1"), g pulse, and y monitoring with cycle counting. Inputs x and y are sampled synchronously on each clock. Transition between the x pattern detection states happens only when the corresponding input bit matches, otherwise it resets the pattern detection. This explicit approach avoids ambiguity in pattern matching and timing.

For y monitoring, count cycles after g pulse; if y=1 within two cycles, transition to a permanent g=1 state; else after two cycles transition to permanent g=0 state.

Outputs f and g are driven solely by the current state (Moore outputs), ensuring output changes are synchronous and predictable.

This approach avoids shift registers and combinational pattern detection, reducing off-by-one timing errors by spreading pattern detection over several states, each requiring matching input at the clock edge.

Synchronous active low reset keeps FSM in initial state with outputs zero, and after reset release FSM moves to f pulse state.

This explicit state-by-state matching ensures clarity and correctness of output timing and input monitoring.
