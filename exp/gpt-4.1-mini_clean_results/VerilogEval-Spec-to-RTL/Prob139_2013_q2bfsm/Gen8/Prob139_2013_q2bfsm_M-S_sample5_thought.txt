Implement a simple synchronous FSM using parameters for state encoding (Verilog-2001 compatible). Use a single sequential always block triggered on posedge clk, with synchronous active-low reset. Track the FSM states, a pattern step counter for detecting x=1,0,1 pattern, a counter for monitoring y within 2 cycles, and outputs f and g as registered signals. The output f is pulsed high exactly one clock cycle after reset release, then the FSM monitors x for the pattern. Once matched, g is set high while monitoring y for up to 2 cycles. If y=1 occurs within 2 cycles, hold g=1 indefinitely; else, hold g=0 indefinitely. Keep the code straightforward, avoid SystemVerilog constructs, and use only reg and parameter for states.
