Simplify the FSM by explicitly defining each state to clearly separate the phases:

- State A: Reset state while resetn=0.
- State F_PULSE: One cycle asserting f=1 after reset de-asserted.
- States to detect the x pattern (1,0,1) sequentially, using distinct states instead of pattern_step variable:
  - WAIT_1: wait for x=1
  - WAIT_0: after seeing x=1, wait for x=0
  - WAIT_1_FINAL: after x=0, wait for x=1 (final)
- Once pattern matched, move to MONITOR_Y state where g=1 and monitor y input for up to two cycles.
- If y=1 within two cycles, go to G_ON_PERM (g=1 permanently).
- Else go to G_OFF_PERM (g=0 permanently).

This state-based approach eliminates pattern_step counters and complex backtracking.

Use a single cycle counter in MONITOR_Y to track up to two cycles.

Outputs f and g depend only on state (Moore machine).

Use synchronous active-low reset to go to A state.

This clear and explicit FSM is easier to understand, debug, and verify.
