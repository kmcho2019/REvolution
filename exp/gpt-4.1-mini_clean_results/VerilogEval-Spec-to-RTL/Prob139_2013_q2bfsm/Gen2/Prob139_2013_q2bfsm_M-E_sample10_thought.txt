Implement the FSM with a minimal number of states by using internal shift registers and counters instead of separate states for pattern detection and y monitoring. After reset, assert f=1 for one cycle. Then continuously sample x into a 3-bit shift register each clock cycle to detect the pattern 1-0-1. Upon detecting this pattern, set g=1 and start a 2-cycle timer to monitor y. If y=1 occurs within these two cycles, keep g=1 permanently. Otherwise, clear g=0 permanently. Use a synchronous active-low reset. This approach reduces the state count drastically, simplifies transitions, and offloads pattern detection to registers and counters, leading to a cleaner and more concise design.
