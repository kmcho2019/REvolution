Implement the FSM using separate always blocks for state and outputs to improve clarity and correctness. Use synchronous active-low reset and positive clock edge triggering. 

Architecture:
- Define explicit states with a localparam enum.
- Use one always block to update state on clock edge with synchronous reset.
- Use another always block to compute outputs combinationally from the state.
- Use a 3-bit shift register updated each clock cycle to capture the last three x inputs.
- After reset release, output f=1 for exactly one cycle.
- Then monitor the shift register for pattern 1,0,1; when detected, set a flag that triggers moving to the g pulse state.
- Output g=1 for one cycle, then hold g=1 while monitoring y for at most 2 cycles.
- Use a small counter to track how many cycles have passed since g=1 pulse.
- If y=1 is detected in that window, g=1 permanently; else g=0 permanently.
- This approach separates combinational and sequential logic, avoids mixing next-state and output logic, and strictly controls timing.
- Inputs are sampled synchronously each clock cycle.

This modular design ensures robust, timing-correct FSM and output control that precisely matches the problem specification.
