Use a Mealy FSM approach to minimize state count and tightly couple output timing to input changes, while retaining synchronous active-low reset. Encode the core states as follows:

- IDLE: Waiting for reset release. f=0, g=0.
- PULSE_F: On first cycle after resetn=1, f=1 for one cycle.
- WAIT_PATTERN: Monitor the input sequence x for the pattern 1,0,1 using a 2-bit pattern tracker (tracking which element of the pattern matched last).
- SET_G: In the cycle after detecting pattern, output g=1 for one cycle.
- MONITOR_Y: g=1, count cycles (up to 2). If y=1 at any time, go to PERM_G_ON, else after two cycles without y=1, go to PERM_G_OFF.
- PERM_G_ON: g=1 permanently until reset.
- PERM_G_OFF: g=0 permanently until reset.

Outputs f and g are Mealy outputs that depend on state and inputs, but because f is only one cycle after reset and g is triggered by pattern detection and y monitoring, outputs are set combinationally in FSM transitions for exact cycle alignment.

Pattern detection is performed by tracking how many elements of the pattern 1,0,1 have matched so far and advancing this tracker on each clock according to input x, with failure resetting the tracker.

The FSM transitions and output changes all occur on clock edges with synchronous active-low reset.

This approach reduces state count to 7 states but uses a pattern index variable to detect the pattern, avoids needing a shift register, and aligns output pulses tightly with transitions, suitable for low-latency control signals like f and g.
