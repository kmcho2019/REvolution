Implement a Moore FSM with explicit state-based outputs, ensuring outputs reflect the current state rather than next_state.

Key ideas:

1. Use explicit states:
   - RESET_STATE: Stay while resetn=0, outputs f=0, g=0.
   - F_PULSE_STATE: Assert f=1 for exactly one cycle after reset release, g=0.
   - PATTERN_WAIT_STATE: Monitor the input x for the exact 3-cycle sequence 1,0,1.
   - G_PULSE_STATE: Assert g=1 for exactly one cycle after pattern detection, f=0.
   - Y_MONITOR_STATE: Keep g=1 and monitor y input for up to two cycles. Track elapsed cycles with a small counter.
   - G_ON_STATE: Keep g=1 permanently until reset.
   - G_OFF_STATE: Keep g=0 permanently until reset.

2. Use a 3-bit shift register to store recent x samples during PATTERN_WAIT_STATE. Shift in new x each cycle, then compare to pattern 3'b101.

3. Use a 2-bit counter to track y monitoring cycles in Y_MONITOR_STATE.

4. Outputs f and g are assigned purely as a function of the current state (Moore outputs).

5. On synchronous active-low reset (resetn=0), FSM goes to RESET_STATE and outputs f=0, g=0.

6. The f=1 pulse occurs only once in F_PULSE_STATE, immediately after reset release.

7. Pattern detection occurs continuously in PATTERN_WAIT_STATE with each clock shifting in x.

8. After detecting the pattern, g=1 one cycle in G_PULSE_STATE, then transition to Y_MONITOR_STATE to monitor y.

9. In Y_MONITOR_STATE, if y=1 detected within 2 cycles, transition to G_ON_STATE (g=1 permanently). Else, after 2 cycles without y=1, transition to G_OFF_STATE (g=0 permanently).

10. All sequential logic triggered on clk posedge; synchronous reset checked inside clocked block.

This structure cleanly separates state and output logic, avoids using next_state for output assignment, and uses a shift register for pattern detection, making the design straightforward and robust.
