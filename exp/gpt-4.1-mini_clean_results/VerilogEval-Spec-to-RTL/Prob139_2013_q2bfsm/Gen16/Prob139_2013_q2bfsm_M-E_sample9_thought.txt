Implement a Moore FSM with clearly defined states and outputs driven solely by the current state. Use synchronous active-low reset to set the FSM to the initial state A where f=0 and g=0. After reset release, move to state B for one clock cycle where f=1. Then enter a dedicated pattern detection phase for x input: instead of shifting in a register and detecting pattern asynchronously, use explicit states to match each bit of the sequence 1,0,1 on consecutive clock cycles. That is, have states waiting for first '1', then '0', then '1' in sequence. When the full sequence is matched, transition to state D where g=1 for one cycle. Next, enter a y-monitoring phase with states E0 and E1 to represent each cycle waiting for y=1 (with g=1 maintained). If y=1 is detected at any cycle, move to state F with permanent g=1; else if two cycles expire without y=1, move to state G with permanent g=0. This approach fully synchronizes pattern detection and output assertion with FSM state transitions, avoids combinational pattern detection, and eliminates off-by-one errors. All outputs depend only on current state, ensuring stable output timing. Inputs x and y are sampled synchronously at clock edges and influence only state transitions. This design ensures robust operation with minimal complexity.
