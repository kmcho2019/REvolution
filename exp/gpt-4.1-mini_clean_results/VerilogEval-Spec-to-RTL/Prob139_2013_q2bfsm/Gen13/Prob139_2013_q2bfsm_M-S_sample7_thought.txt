Implement a simple Moore FSM with clear, sequential states reflecting the problem steps: 
- Stay in state A during reset (f=0,g=0).
- On release of reset, move to state B where f=1 for one cycle.
- Then monitor the input x for the pattern 1,0,1 using a small substate counter.
- When pattern detected, move to state D to set g=1 for one cycle.
- Then move to state E where g=1 continuously and monitor y for up to two clock cycles.
- If y=1 during these two cycles, move to state F (g=1 permanently).
- Else move to state G (g=0 permanently).
Use synchronous active-low reset.  
Outputs f and g are driven only by current state for simplicity and correctness.
This simpler state sequence and explicit pattern checking reduces complexity and avoids subtle bugs.
