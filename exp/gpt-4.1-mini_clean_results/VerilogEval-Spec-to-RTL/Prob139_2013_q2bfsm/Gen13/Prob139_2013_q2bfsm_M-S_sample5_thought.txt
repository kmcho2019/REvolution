Simplify the FSM by using a straightforward set of states: 
- Stay in A while resetn is low, ensuring outputs are zero.
- When resetn deasserts, move to B to output f=1 for one cycle.
- Then monitor x input over three cycles using a 3-bit shift register.
- When pattern 101 is detected in the shift register, assert g=1 for one cycle in state D.
- In E, monitor y input for up to two cycles while keeping g=1.
- If y=1 detected, go to F (g=1 permanently); else go to G (g=0 permanently).
Outputs f and g are purely Moore (depend only on current state).
Shift register for x is updated only in C to track pattern.
Reset is synchronous active low and FSM stays in A as long as resetn=0.
This approach ensures clarity and correctness with minimal states and logic.
