Implement a simple Moore FSM with clear states: 
- A: reset state with f=0, g=0, stays here while resetn=0. 
- B: one cycle f=1 pulse right after resetn=1. 
- C: monitor x input with a 3-bit shift register until pattern 101 detected. 
- D: assert g=1 for one clock cycle right after pattern detection. 
- E: monitor y input for up to 2 cycles with g=1; if y=1, stay g=1 permanently; else g=0 permanently. 
- F: permanent g=1 state. 
- G: permanent g=0 state.

The resetn input is synchronous active low and gating is explicit in state transitions.

Outputs f and g depend only on state for simple timing.

This design avoids complicated counters by using a simple 2-bit counter for y monitoring.

This is a straightforward, clear FSM matching the specifications with fewer states and simpler logic.
