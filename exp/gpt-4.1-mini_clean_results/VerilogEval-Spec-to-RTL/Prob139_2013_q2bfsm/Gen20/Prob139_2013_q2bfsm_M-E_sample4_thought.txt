Implement a Moore FSM with explicit synchronous active-low reset handling by including resetn directly in the sequential state update logic. 

Use one-hot encoding for states to simplify state transition logic and make output assignments straightforward and less error-prone.

Structure the FSM as follows:
- Stay in state A while resetn is low.
- Upon resetn de-assertion (high), on the next clock edge transition from A to B where output f=1 for exactly one cycle.
- Then move to state C to continuously monitor the input x.
- Use a 3-bit shift register to capture the last three x values synchronously in state C.
- When the pattern 1,0,1 is detected in the shift register, transition to state D to output g=1 for one cycle.
- Then move to state E where g remains 1, and start a 2-cycle countdown to detect if y=1.
- If y=1 is detected within 2 cycles, move to state F where g remains 1 permanently.
- If y is not detected within 2 cycles, move to state G where g=0 permanently.
- All outputs are registered and assigned based on state signals (Moore outputs).
- The pattern detection and y monitoring counters are implemented with registers updated synchronously.

This approach ensures clean separation of synchronous reset, simple one-hot FSM transitions, Moore outputs, and precise timing for f and g signals, fulfilling the specification with minimal risk of off-by-one or reset timing errors.
