Simplify the FSM by focusing on clearly defined states and minimal registers:

- Use synchronous active-low reset to force FSM to state A with outputs f=0 and g=0.
- On reset release (resetn=1), move to B, output f=1 for exactly one cycle.
- Then monitor input x every cycle, using a 3-bit shift register continuously updated to detect the pattern 1,0,1.
- Upon detecting pattern 101 in x, output g=1 for one cycle (state D).
- Then monitor y input for up to two cycles (state E), keeping g=1:
  * If y=1 detected in that window, transition to state F (g=1 permanently).
  * Else after 2 cycles with y=0, transition to state G (g=0 permanently).
- In states F and G, outputs are held indefinitely until reset.
- The 3-bit shift register for x updates every cycle except during reset.
- Use Moore outputs for f and g depending only on the current state.
- Keep the design straightforward, clear, and easily verifiable.

This ensures timing correctness and simpler logic with no ambiguous or conditional register resets.
