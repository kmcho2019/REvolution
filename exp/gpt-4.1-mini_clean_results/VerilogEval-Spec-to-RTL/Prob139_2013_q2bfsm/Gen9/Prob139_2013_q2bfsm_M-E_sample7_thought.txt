Implement the FSM with clearly separated combinational and sequential logic, using a Moore state machine where outputs depend only on the current state.

Key architectural differences:

- Encode states with a simple binary encoding and clearly define all transitions.

- Use a 3-bit shift register to sample and detect the x pattern (1,0,1). Update it every cycle once reset is deasserted, starting from zero at reset.

- Outputs f and g are registered signals assigned based on current state only, ensuring outputs are stable during each clock cycle.

- For the "monitor y for at most two clock cycles" after setting g=1, explicitly count the cycles with a y_monitor counter.

- If y=1 is detected within these two cycles, transition to a permanent "g=1" state.

- If not, transition to a permanent "g=0" state.

- After reset is deasserted, produce a single-cycle pulse f=1, then move to pattern detection state.

- Output g=1 only during states that require it, including the permanent g=1 state.

- All state transitions and registers updated on posedge clk with synchronous active-low reset.

This approach separates pattern detection shift register from FSM state logic, ensures output timing correctness by basing outputs solely on the current state, and cleanly handles the y input monitoring window.
