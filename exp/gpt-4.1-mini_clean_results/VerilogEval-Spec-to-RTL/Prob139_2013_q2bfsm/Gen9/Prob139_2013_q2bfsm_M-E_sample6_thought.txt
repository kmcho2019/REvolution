Implement the FSM as a Mealy machine with minimal states and explicit pattern detection using a shift register. Use these key ideas:

- Use synchronous active-low reset to return to initial state S0.
- After reset de-asserted and on the next clock edge, assert f=1 for one cycle and move to state S1.
- Use a 3-bit shift register (pattern_reg) to track the last three x inputs.
- After asserting f=1, keep shifting in x each cycle.
- When pattern_reg matches "101" (3'b101), assert g=1 on the next cycle and enter a monitor state to observe y.
- In the monitor state, start a 2-cycle countdown (timer).
- If y=1 occurs within 2 cycles, latch g=1 permanently.
- Otherwise, after 2 cycles without y=1, clear g to 0 permanently.
- Maintain outputs f and g as registered outputs (Moore style) for timing clarity.
- All state transitions and outputs update on positive clock edge.

This approach simplifies pattern detection with a shift register, separating output f and g timing cleanly, and makes the two-cycle y monitoring straightforward and cycle-accurate. The FSM states are minimal:

- S0: Reset state, waiting for resetn de-assert
- S1: Assert f=1 (one cycle), then go to S2
- S2: Shift x into pattern_reg, check for pattern
- MONITOR_Y: g=1, monitor y for up to 2 cycles
- G_ON: g=1 permanently
- G_OFF: g=0 permanently

This clear structure reduces corner cases and aligns precisely with the timing requirements.
