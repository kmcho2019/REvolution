Simplify the FSM by using straightforward states to represent each phase explicitly:

- Use a clear sequential set of states:  
  A (reset state),  
  F_PULSE (f=1 for one cycle after resetn de-asserts),  
  MONITOR_X (look for pattern 1,0,1 on input x),  
  G_ON_MONITOR_Y (g=1 and monitor y for up to two cycles),  
  G_ON_PERM (g=1 permanently),  
  G_OFF_PERM (g=0 permanently).

- For pattern detection on x, keep track of which pattern bit we expect next and progress step-by-step. Reset progress if input doesn't match expected pattern bit.

- For y monitoring, use a simple 2-cycle counter starting at 0 upon entering G_ON_MONITOR_Y. If y==1 in this window, go to G_ON_PERM; otherwise, after two cycles go to G_OFF_PERM.

- Outputs f and g depend only on current state (Moore FSM).

- Use synchronous active-low reset: FSM stays in A while resetn is low, transitions to F_PULSE on first clock with resetn high.

This simpler approach reduces complexity, easier to follow and verify while meeting all functionality requirements.
