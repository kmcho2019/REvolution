Implement the FSM using a Mealy style approach where outputs depend on current state and inputs directly. Use explicit states reflecting each step of the problem, and embed the x-sequence detection as explicit states rather than a shift register. This avoids ambiguity of sampling timing and simplifies detection. 

The states are:
- A_RESET: reset asserted, outputs f=0,g=0
- PULSE_F: first cycle after reset de-asserted, f=1, g=0
- WAIT_X1: waiting for first '1' in x sequence
- WAIT_X0: waiting for '0' after seeing '1'
- WAIT_X2: waiting for final '1' to complete 1-0-1 pattern
- MONITOR_Y_1: g=1, first cycle monitoring y
- MONITOR_Y_2: g=1, second cycle monitoring y
- HOLD_G1: g=1 indefinitely after detecting y=1 within 2 cycles
- HOLD_G0: g=0 indefinitely after y=0 in both cycles

At each clock, state updates synchronously on posedge clk with synchronous active low reset. Outputs f and g are combinational functions of current state (Moore), except f pulsed for one cycle only in PULSE_F. 

This approach avoids shift-register timing mismatches by explicitly advancing through pattern states only on correct x inputs. Monitoring y is controlled via two sequential monitor states with counters implicit in state transitions, ensuring correct timing.

This design strictly matches the problem specification and timing requirements.
