Implement a simple FSM using standard Verilog (no enums), with a small state encoding using parameters. Use a synchronous active-low reset to start in state A. After reset is deasserted, output f=1 for one clock cycle, then monitor x input to detect the sequence 1,0,1 over successive clock cycles. Once detected, output g=1 and start a two-cycle timer to monitor y. If y=1 occurs within two cycles, maintain g=1 permanently; otherwise, set g=0 permanently. Outputs and state updates occur on the rising clock edge.
