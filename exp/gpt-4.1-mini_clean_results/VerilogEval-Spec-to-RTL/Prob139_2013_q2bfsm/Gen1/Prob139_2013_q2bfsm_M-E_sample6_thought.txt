Use a Moore-type FSM with an explicit state for each stage of the process, incorporating output registers for f and g to precisely control output pulse durations.

Key ideas:

- Define states as:  
  A: reset state, f=0, g=0  
  B: output f=1 for exactly one cycle after reset release  
  C1: waiting for x=1  
  C2: waiting for x=0 after x=1 detected  
  C3: waiting for x=1 after 1,0 detected  
  D: g=1, monitor y for up to 2 cycles  
  E: permanent g=1  
  F: permanent g=0

- After reset is released (resetn=1), FSM goes to B for one cycle asserting f=1.

- After B, FSM starts detecting the sequence on x input over states C1-C3.

- Once sequence 1,0,1 detected, transition to D, set g=1 and start a 2-cycle timer.

- If y=1 at any cycle in D, go to E (permanent g=1); if y!=1 after 2 cycles, go to F (permanent g=0).

- Use a small cycle counter for timing the 2 cycle waiting in D.

- Outputs f and g registered; f is asserted only in B and cleared next cycle; g asserted in D and E, cleared in F and A.

- Use synchronous reset active low.

This modular approach clearly separates output timing and input sequence detection, reducing off-by-one errors and improving clarity.
