Simplify the FSM by using a clear sequence of states that directly model the required behavior:

- State A (IDLE): on reset or when resetn=0, FSM stays here, f=0, g=0.
- State B (F_PULSE): after resetn=1, on next clock move here, f=1 for exactly one cycle, then move to monitoring x pattern.
- State C (X_PATTERN): shift in x synchronously every cycle; stay here until pattern 1,0,1 is detected in three successive x samples.
- State D (G_ON_START): one-cycle state that sets g=1 right after detecting the pattern (g=1 starting this cycle).
- State E (Y_MONITOR): with g=1, monitor y for two cycles. If y=1 at any cycle during these two cycles, go to G_ON_PERM; else after 2 cycles without y=1 go to G_OFF_PERM.
- State F (G_ON_PERM): g=1 permanently until reset.
- State G (G_OFF_PERM): g=0 permanently until reset.

This approach clearly sequences outputs and states, aligns output timing with state transitions, and avoids complex conditional logic or shift register clears in combinational blocks.

Implementation details:

- Use a 3-bit shift register updated on every clock in X_PATTERN state to track last 3 x samples.
- Detect pattern in synchronous logic by checking shift register.
- Outputs f and g are Moore outputs depending only on current state.
- Use a y_counter to count 2 cycles in Y_MONITOR.
- Use synchronous, active low reset.
- All state transitions and output changes happen on positive clock edge.

This results in a simpler, more robust FSM matching the problem specification.
