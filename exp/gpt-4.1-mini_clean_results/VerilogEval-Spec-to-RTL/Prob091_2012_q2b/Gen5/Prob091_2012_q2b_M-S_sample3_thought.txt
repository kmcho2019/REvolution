Since the FSM uses one-hot encoding and only a few transitions affect Y1 and Y3, we can directly express Y1 and Y3 as simple assignments without defining intermediate signals for each state or input complements. Y1 is simply y[0] & w (state A active and input w=1), and Y3 is ((y[1] | y[2] | y[4] | y[5]) & ~w), directly encoding the transitions to state D. This removes intermediate signals, simplifying the code while preserving the same logic.
