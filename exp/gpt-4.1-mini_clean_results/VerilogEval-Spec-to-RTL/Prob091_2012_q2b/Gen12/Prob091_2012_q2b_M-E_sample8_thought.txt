A novel architectural idea is to represent each next state input (Y1 and Y3) as a sum-of-products expression derived from all possible current states that transition into those states. Instead of a separate combinational module, we implement the logic inside the TopModule using parameterized one-hot bit indices and intermediate signals, improving clarity and maintainability. We also encode the next state logic as functions returning the next input signal for each flip-flop, encapsulating FSM transition knowledge as local functions to enhance readability and scalability.
