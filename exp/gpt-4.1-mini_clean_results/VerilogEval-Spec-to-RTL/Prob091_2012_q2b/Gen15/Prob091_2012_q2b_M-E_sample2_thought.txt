Implement the FSM output logic by encoding the state bits as inputs directly and using combinational logic expressions derived from the state transitions.

Instead of instantiating gate modules, write a purely combinational always_comb block that computes Y1 and Y3 from y and w using Boolean expressions derived from the state diagram and one-hot encoding.

This design uses localparams for state bit indices for readability, but relies on simple combinational Verilog with continuous assignments to keep the design minimal and synthesizable.

Specifically:

- Y1 is high when the next state is B (bit 1) after input w=1 from A (bit 0).
- From the state transition, Y1 = y[A] & w.

- Y3 is high when next state is D (bit 3).
  Observing the transitions that lead to D:
    - From B on w=0 → D
    - From C on w=0 → D
    - From E on w=0 → D
    - From F on w=0 → D

So, Y3 = (y[B] | y[C] | y[E] | y[F]) & ~w.

This maps exactly to the given logic, but expressed directly with continuous assign statements, making the design simple and clean without extra module overhead.
