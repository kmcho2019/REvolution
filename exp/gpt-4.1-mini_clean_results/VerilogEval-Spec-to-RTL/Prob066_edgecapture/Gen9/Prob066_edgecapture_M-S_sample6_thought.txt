To simplify the design while maintaining functionality, combine the detection of falling edges and the output update in one straightforward always block triggered on the clock's positive edge.

On reset, synchronously clear the output and initialize the stored previous input to the current input to prevent false detections immediately after reset.

On each clock cycle, detect bits where input changed from 1 to 0 by comparing previous input with current input, and latch these bits in the output using a bitwise OR to retain captures until reset.

This approach removes unnecessary intermediate registers and complex operations, keeping only essential state: previous input and the captured output, implemented clearly in a single always block.
