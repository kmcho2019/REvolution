To simplify the design, use a single register to store the previous input value and another register to latch the detected falling edges. On each clock cycle, detect falling edges by comparing the previous input with the current input (bitwise 1-to-0 transitions). Then latch these falling edges by ORing them into the output register. The output register holds all detected falling edges until a synchronous reset clears it. Output directly driven by this register avoids redundant registers and eliminates transient glitches. This approach is concise, efficient, and easy to verify.
