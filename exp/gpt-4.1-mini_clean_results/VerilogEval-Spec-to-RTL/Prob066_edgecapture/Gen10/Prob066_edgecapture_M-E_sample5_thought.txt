Implement a bit-by-bit edge detector by comparing each input bit with its stored previous value using a shift register of flip-flops, but instead of storing the entire previous input vector, we store only a 32-bit "falling edge capture" register and a 32-bit "previous input" register. On each clock, detect bits that transitioned from 1 to 0 by comparing the current and previous inputs, and set the corresponding bits in the capture register. The capture register holds all detected falling edges until reset clears it. This modular approach uses two registers: one for previous input and one for latched falling edges. It eliminates continuous OR operations on the output by updating capture bits only on detected transitions.
