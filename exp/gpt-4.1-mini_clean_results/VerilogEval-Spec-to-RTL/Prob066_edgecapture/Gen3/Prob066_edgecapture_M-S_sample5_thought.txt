The problem reduces to detecting a falling edge (1 to 0) on each bit of the 32-bit input. We can achieve this by storing the previous input value and comparing it to the current input on each clock cycle. When a bit transitions from 1 to 0, we set the corresponding bit in the output register and keep it latched until reset clears it. The design uses a simple synchronous reset and a single always block triggered on the positive clock edge.
