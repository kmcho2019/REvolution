Instead of tracking previous input bits to detect falling edges, we can implement a state machine per bit that tracks whether the bit was previously high and not yet captured. When a bit transitions from 1 to 0, if that bit was previously high, we set the corresponding bit in the capture register. Once captured, the bit remains set until reset.

To do this efficiently, we define a "state" register that marks bits currently "high but not yet captured". On each clock cycle:

- If reset: clear capture and state registers.
- Else:
    - Update state bits: for each bit, if input is 1 and capture bit is 0, set state bit to 1 (meaning this bit is currently "armed" to detect a falling edge).
      If input is 0 or capture bit is 1, clear that state bit.
    - Detect falling edges as bits that were "armed" (state == 1) but now input is 0.
    - Set capture bits for those detected falling edges.

This approach doesn't store the previous input explicitly; instead, it tracks which bits have been "armed" by seeing them high while not yet captured, and then latches capture when those bits go low. This is a novel state-machine approach to the problem.

This also ensures that once a bit is captured, it stays latched until reset, and no prior input initialization issues arise since the state is cleared on reset and updates based on current input and capture.

Finally, output is assigned directly from the capture register.
