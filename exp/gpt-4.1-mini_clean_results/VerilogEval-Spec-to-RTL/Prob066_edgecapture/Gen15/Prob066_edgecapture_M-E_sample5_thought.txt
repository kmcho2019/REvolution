Instead of storing the entire previous input vector, implement a 32-bit shift register for each input bit that holds a 2-bit history (previous and current input states). On each clock, shift in the current bit, and detect a falling edge when the two-bit history is "10" (previous 1, current 0). Once detected, latch the corresponding output bit high until reset. This localizes edge detection per bit using a small history register rather than a single vector, offering clear separation of history and detection logic.
