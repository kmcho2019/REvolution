Instead of storing the entire previous input vector, maintain a 32-bit register that marks which bits have already detected a falling edge. On each clock cycle, detect falling edges by comparing the current input with the delayed version of the input stored in a shift register or FIFO of depth one. Then, update the output bits by OR’ing with any newly detected falling edges, thus preserving previous detections. Initialize the output register and input history register to zero on reset, ensuring a clean start. This approach separates detection (comparing current and previous input) from the latched output (which accumulates detected falling edges). It ensures that once a falling edge is detected on any bit, that bit in output remains set until reset.
