Instead of storing the entire previous input and detecting falling edges with combinational logic, use a 32-bit register to hold a "falling edge detection" flag per bit as soon as a falling edge occurs. On each clock cycle, compare the current input bit with the stored delayed version of that bit to detect a falling edge (1 to 0). When detected, set the corresponding bit in the output register, which is then latched until reset. The design separates the input registering and output flagging steps but still uses synchronous logic only, ensuring clarity and no combinational feedback. This approach can help isolate the timing of detection and output flag updates.
