To correctly detect a falling edge on each bit from 1 to 0, we need to compare the current input with the input from the previous clock cycle. Therefore, we must store the previous input in a dedicated register.

The previous solution failed because it updated the "armed" register with the current input in the same clock cycle, losing the ability to compare with the previous input.

Improved approach:

- Use a register `prev_in` to hold the previous cycle's input.
- On each positive clock edge:
  - If reset, clear `prev_in` and `out`.
  - Else, detect falling edges by checking bits where `prev_in` is 1 and current `in` is 0.
  - Set those bits in `out` and keep them latched.
  - Update `prev_in` with current input for next cycle.

This correctly captures 1->0 transitions and latches them until reset.

This method is simple, clear, and meets the specification.
