Store the previous input value in a register and on each clock edge compare it with the current input. If any bit changes from 1 to 0 (falling edge), set the corresponding bit in the output register. Keep the output bits set until reset is asserted synchronously. To avoid any ordering issues, use a single always block and update prev_in and out carefully so that out is computed from the old prev_in value before updating prev_in to the new input.
