Use a 32-bit register to store the output latch that holds falling edge detections. To detect the 1->0 transition, first register the current input `in` in a pipeline register `curr_in`. Then, compare the previous cycle's registered input `curr_in` with the new input `in` on each clock edge to detect falling edges. This pipeline stage delays input by one clock cycle, so detection logic compares `curr_in` (previous cycle's input) and `in` (current input) within the same clock edge. On detection of a falling edge (bit was 1 in `curr_in` and is 0 in `in`), latch the bit in the output register using OR logic, preserving all previously detected edges until reset. This method avoids ambiguity by capturing input in a registered pipeline stage before detection and makes the output update synchronous and glitch-free.
