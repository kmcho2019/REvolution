To detect a falling edge from 1 to 0 on each bit of the 32-bit input vector, store the previous value of the input on each clock cycle. Then, compare the current input with the previous input: if previous bit was 1 and current bit is 0, that bit should be captured. The output is a 32-bit register where bits are set to 1 once such a falling edge is detected and remain set until reset is asserted synchronously.
