To detect a 1-to-0 transition on each bit of the 32-bit input vector, store the previous input value in a register. At each clock's positive edge, compare the previous input bits with the current input bits. For each bit, if the previous value was 1 and the current value is 0, set the corresponding output bit to 1. Once a bit of the output is set, it remains 1 until reset is asserted. On synchronous reset, clear the output register to 0.
