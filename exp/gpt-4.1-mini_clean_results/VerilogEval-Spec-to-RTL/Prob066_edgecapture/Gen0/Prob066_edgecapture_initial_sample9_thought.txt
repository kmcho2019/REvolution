To detect when any bit transitions from 1 to 0 between consecutive clock cycles, store the previous input in a register. On each clock edge, compare the previous input to the current input and detect 1-to-0 transitions by checking prev_bit == 1 and current_bit == 0. For each bit, if such a transition is detected, set the corresponding bit in the output register to 1 and keep it until reset. On synchronous reset, clear the output register.
