Instead of directly storing the previous input and performing edge detection every cycle, I will use a one-bit register per input bit to track the "captured" falling-edge events separately. On each clock, I detect if a bit fell from 1 to 0 by comparing the current input bit to a registered previous input bit. When such a falling edge is detected, I set the corresponding bit in the output register. The output register holds the captured events and only resets when a synchronous reset occurs. This approach cleanly separates edge detection from event capture, improving clarity and maintainability. The previous input is updated each cycle for future comparisons.
