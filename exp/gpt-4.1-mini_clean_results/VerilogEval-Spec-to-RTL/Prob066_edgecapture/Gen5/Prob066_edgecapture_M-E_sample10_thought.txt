Use a single 32-bit register to hold the previous input sample and another 32-bit register to accumulate detected falling edges. On each clock, synchronously update the previous input register with the current input. Then, in the same clock cycle, detect falling edges by checking bits that were 1 in the previous input but 0 in the current input. Immediately set these bits in the output register via OR operation to latch the detection until reset. This approach keeps logic simple and correct by first sampling the previous input, then performing edge detection and accumulation in the same cycle without timing ambiguity.
