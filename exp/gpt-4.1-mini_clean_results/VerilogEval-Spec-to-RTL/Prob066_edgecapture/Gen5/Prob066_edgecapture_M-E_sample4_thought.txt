Use a shift register approach to remember the previous input value and detect falling edges by comparing the delayed input with the current input. Instead of storing the entire previous input, we can register the input each clock cycle and compare it directly to the current input. For capturing the falling edge event, keep a latch register that sets bits where a falling edge is detected and holds them until reset. This avoids explicit combinational wires by embedding the detection logic inside a sequential block, and the reset will clear both the latch and the previous input register. This approach is fully synchronous, simple, and relies only on sequential logic without separate combinational signals.
