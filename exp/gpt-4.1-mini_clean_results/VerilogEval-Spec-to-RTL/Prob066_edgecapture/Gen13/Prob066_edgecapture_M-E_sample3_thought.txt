Implement a two-stage register pipeline to detect falling edges: store the input in two sequential registers (`in_d1` and `in_d2`). A falling edge for each bit occurs when `in_d2` bit is 1 and `in_d1` bit is 0, indicating a 1-to-0 transition from one cycle to the next. Use a capture register `out` that latches any detected falling edges and holds them until reset. This pipelined approach clarifies the edge detection timing by explicitly comparing delayed versions of the input signal, potentially avoiding initialization and timing issues in previous designs.
