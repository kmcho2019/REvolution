Refactor the design by splitting the sequential storage of the previous input and the output register. We keep a register `prev_in` to store the input from the previous clock cycle, updated on each clock edge. Then, the detection of 1->0 transitions is done combinationally by comparing `prev_in` and the current `in`. The output register `out` is updated only on the clock edge, setting bits where the falling edge is detected and keeping previously latched bits until reset. This separation clarifies the data flow and timing: `prev_in` always holds the prior cycle’s input and is used combinationally to detect transitions before updating the output in the clocked process.
