To simplify the design, store the previous input in a register, detect falling edges as the bits that transition from 1 to 0, and latch these falling edges into a capture register that holds the information until reset. The output directly reflects this capture register. All sequential logic is in one always block triggered on the positive clock edge with synchronous reset. No separate wire is necessary; the falling edge detection can be done inside the always block using non-blocking assignments and the previous input register.
