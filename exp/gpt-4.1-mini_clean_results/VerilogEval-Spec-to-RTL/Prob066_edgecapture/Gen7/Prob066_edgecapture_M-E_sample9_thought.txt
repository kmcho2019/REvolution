Implement a shift-register approach by storing the previous input in a register `prev_in`. On each clock edge, compare `prev_in` (input from previous cycle) with the current input `in`. Detect falling edges where a bit was 1 in `prev_in` and is 0 in `in`. Use a separate output register `out` to latch these detected falling edges and hold them until reset. This method explicitly captures previous cycle inputs for comparison and ensures the output holds all detected falling edges. The synchronous reset clears both `prev_in` and `out`.
