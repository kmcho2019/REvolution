Use a single clocked always block with a two-stage shift register approach to detect falling edges synchronously. On each clock edge, store the current input and the previous input in separate registers. Compare the previous input bit to the current input bit inside the always block to detect falling edges (1->0 transitions). Once a falling edge is detected on a bit, latch that bit in the output register which holds all detected falling edges until reset. This method keeps all operations synchronous, avoids combinational glitches, and eliminates intermediate combinational wires, ensuring robust and reliable edge capture.
