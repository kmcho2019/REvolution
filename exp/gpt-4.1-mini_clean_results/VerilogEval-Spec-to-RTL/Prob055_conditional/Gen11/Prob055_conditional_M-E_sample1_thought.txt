I will implement the minimum finder by directly evaluating all four inputs in a single combinational always block without using submodules. The approach is to first initialize the output to the first input and then compare and update it sequentially with each of the other inputs using if conditions. This flattened and sequential style within a single always_comb block reduces the use of multiple comparison blocks, potentially lowering area and power by avoiding duplicated comparison logic seen in hierarchical min2 instantiations. It also keeps the code simple and easy to understand while producing the correct minimum value.
