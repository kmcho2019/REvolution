Instead of using pairwise comparisons with conditional operators, this design uses a simple priority-based selection logic that iteratively checks each input against the current minimum candidate. Starting with the first input as an initial minimum, it compares with the second input; if the second is smaller, it updates the minimum. This process continues sequentially through inputs c and d. This approach reduces the design to a single combinational always_comb block with sequential if-statements, ensuring clarity and synthesizability. It may produce slightly longer combinational paths than the two-stage tree but is still efficient for four inputs. This method offers a straightforward implementation and can be easily extended or parameterized.
