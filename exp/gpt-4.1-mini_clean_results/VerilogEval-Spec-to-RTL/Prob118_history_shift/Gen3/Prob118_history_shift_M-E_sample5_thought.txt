Implement the global history register update by using a single sequential always block triggered on clk and asynchronous reset. On reset, clear the history to zero. On each clock edge, check first if train_mispredicted is asserted, and if so load the combined corrected history ({train_history[30:0], train_taken}). Otherwise, if predict_valid is asserted, shift left the history and insert predict_taken at LSB. If neither is asserted, hold the history. This approach merges the combinational and sequential logic into a single always block for simplicity and reduces the logic to only update on clock edges, avoiding separate combinational logic and potentially making synthesis simpler.
