I will implement the 32-bit global history register using an explicit shift register approach by storing each bit separately in an array (reg [0:31] history_bits). On each clock edge, I will asynchronously reset all bits to zero when areset is asserted. For updates, I will prioritize train_mispredicted over predict_valid as required. If a misprediction occurs, I will load the branch history by shifting in train_taken at the youngest bit (history_bits[0]) and loading the older bits from train_history. Otherwise, if a prediction is valid, I shift the entire history by one bit to the left (towards older history) and insert predict_taken into history_bits[0]. If neither event happens, I hold the state.

Finally, predict_history output is assigned by concatenating the bits from history_bits[0] (youngest) to history_bits[31] (oldest). This implementation explicitly models each bit to make the history behavior very clear and allow easy extensions. The asynchronous reset and update logic are split clearly within the always block triggered on clock and reset edges.
