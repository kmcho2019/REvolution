Implement the 32-bit global history as a shift register updated only when needed, using a synchronous process with an enable signal derived from the inputs. Use a single sequential always block with asynchronous reset that prioritizes misprediction rollback by directly loading the concatenated branch history and actual outcome. If no rollback, on a valid prediction, shift the predicted bit in. Otherwise, maintain the current state. Assign the output from the registered history. This approach eliminates combinational next state logic and uses an enable to avoid unnecessary updates, potentially reducing power.
