Implement a 32-bit shift register to keep global branch history. On positive edge of clock: if asynchronous reset (areset) is asserted, reset history to zero. Else if misprediction (train_mispredicted) is asserted, load history with {train_history[31:1], train_taken}, which is the history before the mispredicted branch concatenated with the actual result of that branch. Else if a prediction is valid (predict_valid), shift in predict_taken from LSB side. The output predict_history is the current history register value. Misprediction takes precedence over prediction if both occur simultaneously.
