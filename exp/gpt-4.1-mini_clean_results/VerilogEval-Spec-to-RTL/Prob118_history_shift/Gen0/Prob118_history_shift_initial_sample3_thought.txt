Implement a 32-bit global history register updated on the positive clock edge. The register asynchronously resets to zero when areset is high. On each clock edge, if a misprediction (train_mispredicted) occurs, load the history with train_history concatenated with train_taken. If not, and if predict_valid is high, shift the register left by one bit and insert predict_taken at bit 0 (LSB). The output predict_history reflects the current register value. Misprediction has priority over prediction if both signals are high simultaneously.
