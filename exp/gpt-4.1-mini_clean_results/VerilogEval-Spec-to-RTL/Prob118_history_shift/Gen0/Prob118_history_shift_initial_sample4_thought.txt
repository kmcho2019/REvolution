Implement a 32-bit shift register holding the global branch history. On positive clock edge, asynchronously reset the register to zero if areset is asserted. On each clock, if train_mispredicted is high, load the register with {train_history, train_taken} to rollback history due to pipeline flush. Else if predict_valid is high, shift the history left by one and insert predict_taken as the LSB. Output the current history as predict_history. Misprediction update takes precedence over prediction update.
