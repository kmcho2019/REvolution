Implement a 32-bit shift register for the global branch history. On positive clock edge, if areset is asserted, reset history to 0 asynchronously. Else if a misprediction occurs, load the history with {train_taken, train_history[31:1]} (train_history concatenated with train_taken, so that train_taken is the newest bit at LSB side). If misprediction and prediction happen at the same time, misprediction takes precedence. Else if prediction is valid, shift the current history right by one bit and insert predict_taken into the LSB. Output the current history as predict_history.
