Implement a 32-bit shift register representing the global branch history. On the rising clock edge, if asynchronous reset is asserted, reset the history to zero. Else, if a misprediction occurs (train_mispredicted=1), load the history with {train_history, train_taken} (the actual post-misprediction history). Else if a valid prediction occurs (predict_valid=1), shift in the predicted branch direction predict_taken from the LSB side, shifting history left by one bit and inserting predict_taken at bit 0. Output the current history to predict_history. Misprediction load has priority over prediction update.
