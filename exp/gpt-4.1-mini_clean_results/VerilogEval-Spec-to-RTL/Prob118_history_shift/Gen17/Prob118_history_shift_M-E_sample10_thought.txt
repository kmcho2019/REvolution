I will implement the 32-bit global history register using a shift register built from a reg array for explicit bit-wise operations. Instead of using a simple concatenation for the shift, I will manually shift bits with a loop in combinational logic to clearly separate shifting logic. To handle mispredictions, I will first update the history register with the rollback history (train_history plus train_taken) before applying any new predictions in the next cycle. This two-step approach will be managed via internal state flags that detect misprediction and prediction events separately, enabling precise control and better observability of update timing. This design uses a finite state machine (FSM) style with an intermediate 'rollback' state to separate misprediction recovery and prediction update, giving more explicit control flow and potentially improving debug and testability. The asynchronous reset clears the history to zero as usual.
