Refactor by implementing the history register as a shift register with a clock enable signal that activates only when an update is required (either a prediction or a misprediction). Use a synchronous reset instead of asynchronous reset combined with a flip-flop with enable. The misprediction still has priority by multiplexing the input data before the shift register. This approach reduces unnecessary toggling of the register by gating updates to only when valid events occur, potentially saving dynamic power. The design uses an always block triggered only on the positive clock edge for synchronous logic, and asynchronous reset is handled by a separate asynchronous reset input asynchronously clearing the register.
