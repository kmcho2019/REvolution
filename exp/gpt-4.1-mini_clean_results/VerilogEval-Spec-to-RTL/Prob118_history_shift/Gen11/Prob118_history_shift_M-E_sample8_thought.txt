Implement the global history as a 32-bit register updated on each clock edge with asynchronous reset. Instead of handling the updates purely in sequential logic, use combinational logic to compute the next state based on input conditions. Prioritize the misprediction update by using a mux to select between the misprediction load value and the shifted-in prediction value or the current state. This separation improves clarity and modularity of the design, allowing easier extension and potential for better synthesis optimizations.
