Implement the 32-bit global history as a shift register using a synchronous process triggered on the positive clock edge with asynchronous reset. For each clock cycle, determine the next state of the history register by first checking if a misprediction rollback occurs (train_mispredicted = 1). If so, load the corrected history formed by concatenating train_history[31:1] with train_taken as the LSB. Otherwise, if a valid prediction occurs (predict_valid = 1), shift in predict_taken as the new LSB. If neither event occurs, hold the current state. This approach avoids combinational multiplexers for next state logic by embedding all decisions within the sequential block, reducing combinational switching. Output the internal register directly as predict_history. This design prioritizes rollback over prediction updates implicitly via if-else sequencing and keeps asynchronous reset simple and explicit.
