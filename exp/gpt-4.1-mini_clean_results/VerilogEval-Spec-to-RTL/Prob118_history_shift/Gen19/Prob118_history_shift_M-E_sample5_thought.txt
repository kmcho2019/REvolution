I will implement the 32-bit global history as a circular shift register using a 5-bit pointer to track the youngest branch bit's position, avoiding large multi-bit shift operations each cycle. On each prediction, we update only the bit at the pointer position with predict_taken and advance the pointer. On misprediction, we directly load the corrected history and reset the pointer to zero. This reduces combinational shift logic and simplifies updates to a single bit write and pointer increment, potentially improving timing and power by localizing state changes. The asynchronous reset clears both the history and pointer. predict_history output is provided in logical order with predict_history[0] as the youngest branch bit by reading history bits starting from the pointer position.
