Implement the 8-bit shift register with Q[7] as the MSB (shift_reg[7]) and shift right on enable, shifting in S at Q[7]. This way, the oldest bit shifts down towards Q[0]. To map inputs A,B,C (as a 3-bit number) to the selected bit, invert the index by subtracting it from 7, so that ABC=000 selects Q[7], ABC=001 selects Q[6], ..., ABC=111 selects Q[0]. This requires a 3-bit subtraction and then using the result to select the bit from the shift register. The subtraction can be done combinationally as (7 - {A,B,C}) = ~{A,B,C} + 1, allowing us to use an 8-to-1 multiplexer with the inverted index. This differs from the example by reversing the shift direction and accessing bits in reversed order.
