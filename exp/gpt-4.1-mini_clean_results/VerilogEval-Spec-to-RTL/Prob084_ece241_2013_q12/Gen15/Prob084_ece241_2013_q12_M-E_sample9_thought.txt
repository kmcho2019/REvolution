Implement the 8-bit shift register as a single 8-bit vector register Q. On each rising clock edge, if enable is high, shift the register left by one bit, inserting the serial input S into the least significant bit Q[0]. This means Q[7] holds the oldest bit, Q[0] the most recent.

For random access, directly index the Q vector using the 3-bit input {A,B,C} as an address to select the output bit Z. This method leverages vector indexing and enables the synthesis tool to optimize the multiplexer efficiently.

This architecture minimizes code size and allows easy scalability, using a single vector for the flip-flops and simple indexing for output selection, improving timing and area compared to individual flip-flops and case muxes.
