Implement an 8-bit shift register using 8 D flip-flops connected in series, with S as the serial input to Q[0]. On each positive clock edge, if enable is high, shift the bits. The outputs Q[0] to Q[7] hold the stored bits. Use the inputs A, B, and C as a 3-bit binary select to choose which Q[i] bit is routed to output Z via an 8-to-1 multiplexer.
