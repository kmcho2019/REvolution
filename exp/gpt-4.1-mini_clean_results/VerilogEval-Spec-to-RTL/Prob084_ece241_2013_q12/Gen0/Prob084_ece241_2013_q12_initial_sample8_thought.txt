Implement an 8-bit shift register with synchronous active-high enable. The shift register shifts in the input S on each clock when enable is high. The outputs Q[0] to Q[7] represent the stored bits with Q[0] as the first shifted-in bit (MSB). Use the 3 inputs A, B, C as a 3-bit select input to a multiplexer that chooses one of Q[0]...Q[7] to output on Z. The multiplexer output changes combinationally based on A, B, C.
