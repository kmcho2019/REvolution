Implement an 8-bit shift register using 8 D flip-flops that shift in serial data S on each clock when enable is high. The outputs of the flip-flops are Q[0] to Q[7], where Q[0] holds the most recently shifted-in bit. To implement random access read, use A, B, C as a 3-bit address to select one of the 8 flip-flops outputs via an 8-to-1 multiplexer, driving output Z. All sequential logic triggers on the rising edge of clk. The shift occurs only when enable is high.
