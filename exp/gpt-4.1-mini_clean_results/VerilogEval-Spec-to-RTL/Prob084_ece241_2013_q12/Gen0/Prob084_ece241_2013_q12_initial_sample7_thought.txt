Implement an 8-bit shift register using 8 D flip-flops connected in series, where S is the input to Q[0]. On each positive clock edge, if enable is high, the register shifts in the new S bit, shifting bits towards Q[7]. To implement random access read, use the 3-bit input ABC as a selector for an 8-to-1 multiplexer to output Z from the corresponding Q[ABC] bit.
