Implement an 8-bit shift register using D flip-flops with synchronous enable and input S. On each positive clock edge, if enable is high, shift in the bit S at Q[0], shifting the rest down to Q[7]. For output Z, use the 3 inputs A, B, and C as a 3-bit binary index to select one of the Q[0..7] bits via an 8-to-1 multiplexer.
