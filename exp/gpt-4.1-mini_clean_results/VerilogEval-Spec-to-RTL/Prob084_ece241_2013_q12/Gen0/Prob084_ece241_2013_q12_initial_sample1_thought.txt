Implement an 8-bit shift register with synchronous enable, where the input S is shifted into Q[0] on each clock edge when enable is high. The outputs Q[0] to Q[7] represent the memory bits. Use A, B, C as a 3-bit address to select one of the 8 bits from Q[0..7] and output it on Z. This selection can be done with a simple 8-to-1 multiplexer.
