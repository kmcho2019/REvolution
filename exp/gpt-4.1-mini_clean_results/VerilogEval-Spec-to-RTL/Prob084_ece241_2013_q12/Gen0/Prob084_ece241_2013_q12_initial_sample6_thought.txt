Implement an 8-bit shift register using eight D flip-flops triggered on the rising edge of clk. When enable is high, shift in the input bit S into Q[0], shifting previous contents towards Q[7]. For output Z, implement an 8-to-1 multiplexer controlled by inputs A, B, C, to select one of the Q[0]..Q[7]. This realizes a memory with shift-in write and random access read.
