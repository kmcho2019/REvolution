Fuse the best aspects of both examples by maintaining the compact, efficient 8-bit shift register using a single reg vector with synchronous enable, and the concise combinational multiplexer using direct vector indexing with {A,B,C}. To reduce switching activity and power, implement clock gating internally so the clock enables only when shifting is needed, which prevents unnecessary toggling in the shift register flip-flops when enable is low. This maintains the simple architecture and code clarity while improving power efficiency without sacrificing performance or area. The output multiplexer remains a continuous assignment to maintain minimal logic and delay.
