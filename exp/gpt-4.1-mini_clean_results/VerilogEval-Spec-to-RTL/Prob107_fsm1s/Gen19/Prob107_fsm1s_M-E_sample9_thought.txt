I will implement the FSM using an enumerated type for state encoding to improve code readability and clarity. The two states B and A will be defined as local parameters. The state will be stored in a reg variable, and a single synchronous always block will handle both state transition and output generation (Moore output derived directly from the state). The reset is synchronous and active high, as required.

This approach focuses on clear symbolic state names and consolidates the logic into a single always block for compactness, while maintaining the synchronous reset semantics and simple output logic.
