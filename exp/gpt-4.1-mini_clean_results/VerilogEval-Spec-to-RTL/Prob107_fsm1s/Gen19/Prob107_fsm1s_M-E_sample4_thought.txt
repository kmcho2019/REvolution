Instead of encoding states as binary 0 or 1, I use a 2-bit register with one-hot encoding: state_B = 2'b01 and state_A = 2'b10. This allows output to be assigned directly from the state bits without case statements.

For synchronous active-high reset, I will synchronously load the state register with state_B. The next state logic will be implemented using simple combinational logic expressions derived from the FSM table, eliminating case statements. 

Output will be assigned directly from the bit representing state_B, reflecting Moore machine behavior. This approach can improve clarity and potentially performance by enabling simpler combinational logic and straightforward output decoding, trading off with a slightly wider state register.
