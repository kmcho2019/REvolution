The FSM has only two states and the output depends solely on the state. Instead of defining explicit state names and a next_state signal, we can directly store the current state bit in a register and update it synchronously on each clock edge with the reset condition. The next state logic is a simple inversion of the input when in state B and maintains or switches based on input. Since the output is 1 in state B (state=0) and 0 in state A (state=1), we can use the state bit directly for output by inverting it. This simplification removes unnecessary wires and localparams, reducing code complexity while preserving functionality.
