Implement the FSM using a one-hot encoded state register with two flip-flops, one per state (B and A). Use a combinational always block to generate the next state signals based on current state and input, then synchronously update the state registers on the clock edge with active-high reset. The output is derived from the one-hot encoding by assigning 'out' high when in state B (i.e., the B flip-flop is set). This approach avoids using a binary-encoded state and demonstrates an alternate encoding scheme that can simplify the next-state logic and support easier extension to more states if needed.
