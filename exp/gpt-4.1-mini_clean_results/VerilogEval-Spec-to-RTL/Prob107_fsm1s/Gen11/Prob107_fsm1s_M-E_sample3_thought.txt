Implement the Moore FSM using one-hot encoding with two flip-flops, one for each state. Use synchronous active-high reset to initialize to state B (one-hot encoded as 2'b01). The next state logic is implemented as combinational logic directly driving the one-hot state bits, avoiding a case statement. The output is generated by a combinational logic that asserts 'out' high when in state B (state bit 0 is set). This approach trades a slightly larger state register for very simple next-state logic and clear state representation, making the design straightforward and potentially easier to modify or extend.
