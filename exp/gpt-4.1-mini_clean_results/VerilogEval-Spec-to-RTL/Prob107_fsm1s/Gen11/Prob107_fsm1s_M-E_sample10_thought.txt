Implement the two-state Moore FSM using a one-hot state encoding instead of binary encoding. This means using two flip-flops, each representing one state. Only one flip-flop is active (high) at a time. This encoding simplifies next-state logic to combinational gate-level transitions, which can improve timing and allow parallel evaluation of states.

The synchronous active-high reset sets the FSM to state B (state B flip-flop high, state A flip-flop low).

Output is combinationally assigned from the one-hot encoded state B flip-flop. Since the FSM is Moore, output depends only on current state.

This architectural change trades one flip-flop for simpler next-state logic and potentially faster clock frequency due to reduced logic depth. It is also more scalable for FSMs with more states.
