Implement the Moore FSM using a single always_ff block that updates both the state and output registers synchronously on the clock edge. The output is registered (instead of combinational) which slightly increases latency but can improve timing and glitches in some scenarios. The reset is synchronous and active-high, setting state and output to their reset values. The next state and output logic are encoded directly within the sequential always block using if-else conditions, eliminating the need for a separate combinational block or continuous assignments.
