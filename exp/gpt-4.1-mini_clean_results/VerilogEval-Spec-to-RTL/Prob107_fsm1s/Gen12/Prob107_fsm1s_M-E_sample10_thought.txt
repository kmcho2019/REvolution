Implement the state machine using an explicit registered output to hold the Moore output instead of deriving it directly from the state register. Use two separate registers: one for the state and one for the output. This separates the output logic from the state encoding and can make timing and synthesis optimizations easier, especially in some FPGA architectures. The FSM state transitions and output updates happen synchronously at the clock edge with active-high synchronous reset initializing the state and output.
