Use one-hot encoding for the two FSM states by defining two separate flip-flops representing states A and B. On reset, set B active and A inactive synchronously. Transition logic uses combinational logic on these one-hot state bits and input to determine next states. Output is assigned combinationally from the current states, with out=1 if in state B, else 0. This approach avoids enums and single-bit state variables and makes state decoding explicit.
