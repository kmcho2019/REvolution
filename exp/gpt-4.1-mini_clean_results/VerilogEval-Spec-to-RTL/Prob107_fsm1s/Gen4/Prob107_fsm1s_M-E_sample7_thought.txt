Use two one-hot encoded state flip-flops instead of a single-bit state variable: one flip-flop for state B and one for state A. On reset, B is set to 1 and A to 0. Next state logic uses combinational assignments for both state bits based on input and current state. The output is taken directly from the B state flip-flop since output is 1 in B and 0 in A, matching the state encoding. This approach provides explicit one-hot encoding, which can simplify debugging and synthesis tools may optimize it well.
