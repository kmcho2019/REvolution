Use a one-hot state encoding with two flip-flops to represent states A and B individually. On reset, set the B state flip-flop. The next state logic is implemented by toggling states based on input, eliminating the need for a next_state variable. Output is directly driven by the B state flip-flop (out = 1 if in state B, else 0). This architecture can provide faster state decoding at the expense of an extra flip-flop, potentially improving performance in FPGA implementations where one-hot encoding is preferred. Synchronous reset remains active-high.
