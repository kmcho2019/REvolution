The FSM has only two states and a simple output directly related to the state. We can further simplify by:

- Using a single state register with synchronous active-high reset.
- Deriving output directly from the state register via a continuous assignment rather than an always block.
- Computing the next state in a straightforward combinational always block using a simple ternary operator.
- Removing the separate next_state register by updating state directly with next state logic in the sequential block.

This approach reduces code complexity and resource usage while maintaining the same functionality and synchronous reset.
