Use a single always block driven by the clock and synchronous reset to implement both state updates and output assignment together. Represent states as a 1-bit register where the output is directly derived by the state bit itself (out = ~state). The encoding is inverted: state 0 means A (out=0), state 1 means B (out=1). The next state logic is implemented inside the sequential block using a case statement with conditions on input, eliminating the need for a separate next_state register or combinational block. This approach minimizes code lines and merges output logic into the sequential logic while maintaining clear synchronous reset and Moore output behavior.
