Since the FSM has only two states and the output depends only on the current state, we can merge the state register and output into a single flip-flop to represent state directly by the output signal. The output 'out' can serve as the state variable, with '1' representing state B and '0' representing state A.

On each clock edge, on reset, set 'out' to 1 (state B). Otherwise, update 'out' according to the next state logic derived directly from 'out' and 'in'.

This removes the need for separate state and next_state signals and combinational blocks, simplifying the design to a single always block with only the state register and output combined.
