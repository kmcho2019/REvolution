I will refactor the FSM implementation by separating the next-state combinational logic from the sequential state register update. This approach enhances readability and aligns with common FSM design practices. Specifically, I will:

1. Use a separate combinational always block to compute the next state based on the current state and input.
2. Use a synchronous always block to update the current state with the next state on the clock edge.
3. Keep the output as a continuous assignment to reflect Moore FSM output based on the current state.
4. Maintain the active-high synchronous reset.

This modular separation often helps synthesis tools optimize timing better and makes the design easier to understand and maintain.
