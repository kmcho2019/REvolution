Since there are only two states with a single-bit state register and a simple input-driven transition, we can simplify the next state logic using a single XOR operation, exploiting the fact that in state B (0), the next state flips if input=0, and in state A (1), the next state flips if input=0 as well (from the FSM). The output is the inverse of the state. This reduces the ternary operator to a simple XOR, minimizing combinational logic and making the design concise and efficient.
