Implement the Moore FSM using a one-hot style encoding with a 2-bit register where only one bit is set at a time to represent the current state. Use a case statement for next-state logic to make the FSM explicitly state-driven, improving readability and potentially synthesis robustness. The synchronous reset will force the FSM into the 'B' state (encoded as 2'b01). The output will be a combinational signal derived from the state register, assigning output high only in the 'B' state. This architectural change avoids explicit inversion or nested ifs, uses 2-bit one-hot state encoding, and cleanly separates state and output logic, which may improve synthesis tool inference and debugging clarity.
