Implement the Moore FSM with a one-hot encoding scheme using two flip-flops to represent states A and B explicitly. Use synchronous active-high reset that sets the machine to state B. The next-state logic is directly derived from the input and current state signals by assigning the next state in a combinational always block with simple AND/OR logic. The output is registered as well, making the FSM fully synchronous with registered outputs to reduce glitches. This architecture trades off slightly more area (2 flip-flops) for potentially improved timing and output stability by registering the output.
