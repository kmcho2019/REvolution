Implement the Moore FSM by encoding states in a one-bit register, but instead of a separate next_state signal, compute the next state inline in the sequential block using a simple if-else construct. Output is driven combinationally from the state bit, as before. The synchronous reset is retained. This approach reduces the number of always blocks and signals, combining next state calculation and state update, which simplifies control logic and can lead to slightly reduced logic and potential improvements in area. The output remains purely combinational from the state, ensuring a Moore machine behavior.
