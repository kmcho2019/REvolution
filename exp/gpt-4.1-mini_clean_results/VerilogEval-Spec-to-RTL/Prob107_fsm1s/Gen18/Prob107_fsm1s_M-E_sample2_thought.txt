Implement the FSM using a single always_ff block where both the next-state logic and output are registered together. Instead of separate next-state logic, combine the output as a registered signal updated synchronously with the state, leveraging the fact that in a Moore machine output depends only on the current state. This approach reduces combinational logic outside the always_ff block and ensures all outputs and state updates are synchronized to the clock. Additionally, use explicit state constants with an enumerated type for clarity.
