I will implement the Moore FSM using one-hot encoding for the two states, with separate flip-flops for states A and B. State B is represented by B=1 and A=0; state A is represented by A=1 and B=0. On reset, B is set to 1 and A to 0 synchronously. The next state logic will be done by combinational logic that determines which state flip-flop to enable based on current inputs and current states. The output will be assigned from the state B flip-flop since out=1 when in B, else 0. This architectural choice explicitly separates state registers and makes the FSM transitions very clear with minimal combinational decoding logic.
