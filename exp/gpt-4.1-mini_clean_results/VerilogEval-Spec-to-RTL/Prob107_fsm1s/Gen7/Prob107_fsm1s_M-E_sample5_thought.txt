An alternative approach is to encode the two states with one bit and combine the output logic into the state register update process, making output a registered (synchronous) signal. This transforms the Moore FSM into a form where the output is registered and only changes on clock edges, potentially reducing glitches on the output at the expense of one-cycle latency. 

The design uses:
- A synchronous active-high reset to initialize the state and output.
- Next state and output logic are computed together in the sequential always block, eliminating a separate combinational output block.
- The combinational next state logic is folded inside the sequential block.
- Output changes only on clock edges, improving output signal stability (less glitching).

This approach is useful when output glitch reduction is desired, and one cycle output latency is acceptable. It is still a Moore FSM since output depends solely on the current registered state, just that output is stored as a register.

This design trades immediate combinational output for a registered output, potentially simplifying timing closure at the cost of output latency.
