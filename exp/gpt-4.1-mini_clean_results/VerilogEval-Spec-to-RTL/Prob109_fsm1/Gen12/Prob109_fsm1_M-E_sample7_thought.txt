Instead of explicitly encoding states with parameters, I will use a single flip-flop for state storage where the state bit itself doubles as the output since the output matches the state encoding in this Moore machine. To separate next-state logic cleanly, I will define the next state using Boolean expressions directly derived from the state diagram. The output is assigned directly from the state register without a separate combinational block. The asynchronous reset will clear the state flip-flop to represent state B (logic 1). This minimalistic design reduces code verbosity and synthesizes to minimal hardware.
