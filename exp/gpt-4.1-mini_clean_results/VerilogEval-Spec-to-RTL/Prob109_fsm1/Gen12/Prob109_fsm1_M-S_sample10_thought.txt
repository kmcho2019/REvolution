The FSM has only two states, so we can represent the state with a single bit where state=1 for B and state=0 for A. Since the Moore machine output is just the current state, we can drive output directly from the state register. We can simplify the next-state logic by using a straightforward if-else inside the always block. Asynchronous reset sets the state to B (1). This eliminates the separate combinational block and nested ternaries, resulting in a cleaner and easier-to-read implementation.
