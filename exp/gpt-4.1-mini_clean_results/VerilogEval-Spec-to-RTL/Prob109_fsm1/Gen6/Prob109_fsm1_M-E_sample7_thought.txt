I will implement the Moore FSM using a two-bit one-hot state encoding for clarity and explicit state representation. Each state will be represented by a separate flip-flop (state_A and state_B), simplifying next state logic since only one flip-flop is active at a time. The asynchronous reset will clear state_A and set state_B directly, ensuring the machine resets into state B. Output logic will be combinational, depending only on which one-hot state is active. The one-hot approach improves readability and can be beneficial for certain synthesis tools or timing optimizations, especially with simple FSMs like this.
