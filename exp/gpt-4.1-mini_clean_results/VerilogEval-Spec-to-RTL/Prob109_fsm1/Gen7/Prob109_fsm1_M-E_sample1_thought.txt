Implement the Moore machine using a one-hot encoding scheme with two flip-flops for states A and B. This approach uses separate registers for each state and decodes the output directly from the state registers, avoiding an explicit output register. The asynchronous reset will clear all state bits except B, which will be set to 1. The state transitions are implemented in combinational logic driving the next state signals. This method makes the design more scalable for FSMs with more states and provides explicit clarity on which state is active. Since output is Moore style and depends solely on the state, it is assigned combinationally from the one-hot state signals.
