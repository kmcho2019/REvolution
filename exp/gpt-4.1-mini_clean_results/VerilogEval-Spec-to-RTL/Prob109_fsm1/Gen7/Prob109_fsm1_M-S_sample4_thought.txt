Since the FSM only has two states, we can represent the state directly as a single-bit register without a separate next_state variable. The next state logic can be integrated inside the clocked always block with simple if-else statements, removing the combinational block and simplifying the design. The output is directly assigned from the state as before.

This reduces the number of always blocks and intermediate signals, making the design more concise while preserving the original functionality and asynchronous reset behavior.
