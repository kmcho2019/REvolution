Implement the Moore FSM using a one-hot state encoding style with two flip-flops (state bits), where state A is represented as 2'b01 and state B as 2'b10. This allows simpler next-state logic using bitwise operations without a case statement. Asynchronous reset initializes the FSM to state B (2'b10). The output is derived directly from the state bits by decoding which state is active. This approach increases state register count from one to two bits but can simplify combinational logic and explicitly separate the states for clarity.
