Since the FSM is simple with only two states and output equals the state, we can simplify by encoding the state directly in the output register. This way, we don't need a separate state register and output logic; the output itself holds the state. On each clock, update output as the next state. The asynchronous reset sets output to '1' (state B). The next state logic is simplified by the expression: next_state = out ^ (~in), same as before, but now directly updating output. This eliminates the separate state variable and combinational logic, reducing code size and making it more direct, yet functionally identical.
