Since the FSM has only two states, I will simplify the design by using a single-bit binary state encoding instead of one-hot. I will represent state B as 0 and state A as 1. The next state logic and output logic will be implemented with simple Boolean expressions using the current state and input. Asynchronous reset will set the state to B (0). This reduces flip-flop count to one and minimizes combinational logic, simplifying the design while preserving the specified functionality.
