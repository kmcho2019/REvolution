Implement the Moore FSM using a one-hot encoding style with two flip-flops representing each state separately. Use asynchronous reset to set the FSM to state B by asserting the B flip-flop and clearing A. Next state logic will be done using combinational logic assigning next values for A and B flip-flops individually. The output is assigned combinationally based on which flip-flop is set. This method simplifies next-state decoding and output logic, and explicitly separates state bits, providing clear visibility and potentially easier timing closure in some synthesis flows.
