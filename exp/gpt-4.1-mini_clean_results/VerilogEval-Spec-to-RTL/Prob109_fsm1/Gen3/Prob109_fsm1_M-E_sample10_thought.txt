Implement the Moore machine using a single always block with asynchronous reset and synchronous state update. Represent states with a one-bit register, but invert the encoding: 1 for A, 0 for B. Output is generated by a combinational assign statement reflecting the current state (out = 0 for B, 1 for A). The state transitions are described as:

- From B (0): in=0 -> A (1), in=1 -> B (0)
- From A (1): in=0 -> B (0), in=1 -> A (1)

This encoding and output assignment invert the original definition but maintain the same functionality. Using assign for output saves flip-flops and potentially reduces logic. Combining state update and next state logic in one always block also reduces code complexity.
