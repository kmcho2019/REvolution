I will implement the Moore FSM using a one-hot encoding approach with two flip-flops, each representing a state (A and B). This simplifies the next state logic to straightforward combinational logic, where only one flip-flop is set at a time. The asynchronous reset will clear state A and set state B. The output will be driven by the state flip-flops directly, reflecting the Moore machine output. This approach leverages one-hot encoding to optimize for simple next-state decoding logic and explicit state signal clarity.
