I will implement the Moore FSM using a two-bit one-hot encoded state representation, where each bit represents a unique state. This approach simplifies next state logic to bitwise operations, which can be efficiently implemented in hardware.

Key features of this design:
- One-hot encoding for two states: state[1] = B, state[0] = A.
- Asynchronous reset sets state to B (state[1] = 1, state[0] = 0).
- Next state logic computed inside a combinational always block for clarity.
- State register updated asynchronously on reset or synchronously on clock edge.
- Output generated directly by the state register bit for state B.
This approach offers a different architectural style than binary encoding and expresses the state as individual bits representing each state directly.
