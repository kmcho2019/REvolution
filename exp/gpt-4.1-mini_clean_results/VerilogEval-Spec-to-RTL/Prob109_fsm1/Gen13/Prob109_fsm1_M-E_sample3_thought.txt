To create a different architectural approach, I will explicitly define the state encoding with parameters, use a combinational always block for next state logic, and a sequential always block for state register update. The output will be registered separately to emphasize Moore output behavior. The asynchronous reset will clear the state register to B, and the output will update synchronously on clock. This separates state and output registers, differing from the previous combined approach and illustrating a classic two-process FSM design.
