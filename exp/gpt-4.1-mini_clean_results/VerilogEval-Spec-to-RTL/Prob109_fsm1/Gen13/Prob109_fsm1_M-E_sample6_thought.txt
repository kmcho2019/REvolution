Instead of using a single-bit state encoding with XOR logic, this design uses an explicit two-state one-hot encoding with two flip-flops representing states A and B. Only one flip-flop is set at a time, representing the active state, which can simplify state decoding logic and potentially improve timing in some FPGA architectures. The asynchronous reset initializes the machine to state B by setting only the B flip-flop. The next-state logic is implemented with explicit combinational logic that matches the FSM transitions directly. The output is driven by the active state flip-flop for B, reflecting the Moore output. This approach trades minimal logic for a clear structural separation of states and may ease integration with tooling expecting one-hot states.
