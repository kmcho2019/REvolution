We can implement the FSM using a one-hot encoding style, where each state is represented by a separate flip-flop. This approach uses two flip-flops: one for state A and one for state B. On asynchronous reset, the B flip-flop is set and A cleared, representing the initial state B. State transitions are performed by combinational logic determining which flip-flop to set next based on the current state and input. The output is driven directly by the B flip-flop since B corresponds to output 1 and A corresponds to output 0. This method explicitly models the states in flip-flops, making state decoding and output assignment straightforward and modular, and potentially simplifying future expansions.
