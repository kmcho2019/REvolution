The FSM has only two states (A=0 and B=1) and a simple next-state logic. We can eliminate the combinational next-state calculation by directly updating the state in the sequential always block using if-else statements for clarity. The output is simply the state value since it's a Moore machine. Using if-else instead of nested ternary operators improves readability and synthesis friendliness without changing behavior. The asynchronous reset remains to initialize state B.
