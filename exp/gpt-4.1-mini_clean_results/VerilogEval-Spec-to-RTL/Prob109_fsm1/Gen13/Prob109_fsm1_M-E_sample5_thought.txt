Implement the Moore FSM using a two-bit one-hot encoding style where only one bit is set to represent each state. State B will be encoded as 2'b10 and state A as 2'b01. This approach can simplify decoding logic and make the output logic explicit. The next-state logic is implemented using a combinational always block that determines the next state from the current state and input. The state register is updated on the clock edge with asynchronous reset to initialize to state B (2'b10). The output is determined solely by the current state bits, producing 1 for state B and 0 for state A.
