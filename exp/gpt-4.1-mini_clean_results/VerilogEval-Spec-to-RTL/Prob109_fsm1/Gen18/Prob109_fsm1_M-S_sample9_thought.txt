The FSM has only two states A and B, with output equal to the current state. Since output = state and states are one bit, we can use the input and current state directly in next-state logic without defining localparams or intermediate wires. The next state is simply state ^ ~in, so we can assign this directly inside the always block without a separate wire.

Also, since the output is equal to the state, and state is a reg, assign output to state directly. This removes the need for extra logic or assignments.

This results in a minimal and straightforward implementation with only a single always block for state updates, asynchronous reset, and direct output assignment.
