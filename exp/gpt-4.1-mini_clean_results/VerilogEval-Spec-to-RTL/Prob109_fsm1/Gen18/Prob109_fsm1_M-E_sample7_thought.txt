To implement the same two-state Moore FSM with asynchronous reset, I will use a one-hot encoding for states instead of a single bit. This means that state A and state B will each have a dedicated flip-flop. One-hot encoding often simplifies next state logic, can improve timing by eliminating decoding, and eases extensibility to larger FSMs.

Specifically:
- Use two flip-flops, state_A and state_B, where state_A=1 indicates state A and state_B=1 indicates state B.
- Asynchronous reset will set state_B=1 and state_A=0 to reset into state B.
- Next state logic will be:
  * If currently in B and input is 0, go to A.
  * If currently in B and input is 1, stay in B.
  * If currently in A and input is 0, go to B.
  * If currently in A and input is 1, stay in A.
- Output depends only on current state: output=state_B (because output is 1 in B and 0 in A).
  
This approach makes the next-state logic very straightforward, and the output assignment is a simple wire from state_B. The use of two flip-flops instead of one bit makes the FSM implementation clearer and more modular, which is advantageous for scaling or formal verification.
