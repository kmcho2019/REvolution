I will implement the FSM using a one-hot state encoding with two flip-flops, one for each state (A and B). This approach simplifies the combinational next-state logic, using clear assignments of state bits based on inputs. The asynchronous reset will set the B state flip-flop to high and A to low. The output will be driven by the B state flip-flop directly, as it corresponds to output 1, while A corresponds to output 0. This method trades minimal additional flip-flop area for clearer state logic and potentially better synthesis optimization and timing.
