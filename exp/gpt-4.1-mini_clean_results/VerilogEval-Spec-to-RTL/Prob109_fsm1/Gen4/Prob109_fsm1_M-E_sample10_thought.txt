Implement the Moore FSM using a binary state encoded as a flip-flop that directly represents the output, but instead of using a separate combinational next-state logic block, encode next state logic inside a single always block with asynchronous reset. Use a single always @(posedge clk or posedge areset) block for both state transition and output update by assigning output directly from the state flip-flop. This removes the separate next_state register and next-state combinational always block, simplifying the design further while keeping asynchronous reset and preserving the Moore machine properties.
