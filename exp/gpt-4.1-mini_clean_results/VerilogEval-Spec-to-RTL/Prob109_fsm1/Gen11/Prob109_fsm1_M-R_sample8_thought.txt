To refactor the FSM, I will separate the combinational next-state logic from the sequential state register logic, using two always blocks: one combinational to compute next_state based on current state and input, and one sequential with asynchronous reset to update the state. The output remains the current state since it's a Moore machine. This structure is a classical FSM style, which improves code readability and makes the design more modular. The state encoding and asynchronous reset behavior remain unchanged.
