Refactor the FSM by using a two-process style: one always block for asynchronous reset and state update, and a purely combinational continuous assignment for the next state. The output is derived by a simple assign statement directly from the state since output depends only on state (Moore machine). This avoids the function and the output always block, making the design more straightforward and possibly easier for synthesis tools to optimize. The asynchronous reset remains in the always block. State encoding remains the same.
