We can simplify by directly assigning the output as the current state register and updating the state with simple next-state logic. Since the state output matches the state encoding, we can eliminate the explicit output register and use the state register as output. The next state is B (1) if the input is 0 or if already in B and input is 1, otherwise A (0). This logic reduces to the expression: next_state = state | ~in. Implementing asynchronous reset directly sets state to B (1).
