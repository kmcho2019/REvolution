Implement the FSM using one-hot encoding for states with two flip-flops, each representing one state (A and B). The asynchronous reset will set the machine into state B by asserting its flip-flop and deasserting A's. The next state logic is derived from the inputs by enabling only one state flip-flop at a time. The output is combinational and directly driven by the state flip-flop corresponding to B, since output=1 for B and 0 for A. This approach simplifies output logic by eliminating the output register and achieves clear state definition, easy state decoding, and fast combinational output generation. Additionally, asynchronous reset is cleanly applied to the one-hot encoded state register, ensuring deterministic initialization.
