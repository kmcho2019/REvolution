Implement the Moore FSM using one-hot encoding for the two states, where each state is represented by a separate flip-flop. The asynchronous reset will set the machine to state B by setting the corresponding state bit. Next-state logic will be encoded in a combinational block deciding the set/reset of each state bit. The output will be assigned directly from the one-hot encoded B state flip-flop since output is 1 in state B and 0 in state A. This architecture allows clear separation of states and potentially easier expansion to more states.
