Implement the Moore FSM using one-hot encoding for the states, which uses two flip-flops for state representation, making the next-state and output logic very simple and explicit. Use a synchronous process for state transitions with asynchronous reset to initialize to state B. Define outputs as combinational signals derived directly from the state registers. This one-hot approach reduces combinational logic complexity and makes FSM debugging and state decoding easier, especially as FSM size scales.
