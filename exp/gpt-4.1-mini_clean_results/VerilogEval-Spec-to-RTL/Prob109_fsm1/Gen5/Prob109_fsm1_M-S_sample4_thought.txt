Since the FSM has only two states encoded as one bit and the output directly corresponds to the state, we can simplify by merging the next state and output logic together and removing the separate next_state register. We can update the state directly using the input and current state in the sequential block. This eliminates the combinational next_state always block, reducing complexity and making the design more compact without changing behavior.

We keep the asynchronous reset to state B and assign the output directly from the state register. This simplification preserves the Moore machine behavior with minimal logic.
