This time, I will use a two-bit one-hot encoding for the states (A and B) to demonstrate a different architectural style, trading off area for clarity and possibly easier timing in some technologies:

- State B will be encoded as 2'b10, and state A as 2'b01.
- The FSM state register is a 2-bit register with asynchronous reset to state B.
- Next state logic will be purely combinational, using a combinational always block.
- The output will be a combinational signal assigned directly from the one-hot state encoding, emphasizing the Moore machine output depending only on the state.
- This approach allows the FSM transitions and output logic to be easily extended or modified and may be clearer to some engineers.
