The given design is already minimal and optimized with a simple XOR next-state logic and asynchronous reset. To further improve power and timing (PPA), I propose to add a clock enable (ce) signal that disables state transitions when the input does not cause a state change. This avoids unnecessary toggling of the state register and reduces switching power.

Since the FSM has only two states and a simple transition condition, the clock enable can be derived by comparing next_state with current state. If they are equal, no state change is needed, so clk enable is deasserted.

This reduces unnecessary clock toggling and saves power without affecting functionality or timing, since state updates only occur when needed.

No changes are needed for output logic, which is already combinationally dependent on state.

Overall:
- Add clk enable = (next_state != state)
- Use clk enable to gate state update
- Keep asynchronous reset as is
- Keep state encoding and output logic unchanged

This optimization is simple, synthesizable, and effective for power savings with minimal impact on timing and area.
