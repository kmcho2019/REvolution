Separate the state register and output signal for clarity and potentially improved synthesis optimizations. Use a dedicated state register and a combinational always block to compute next state. The output depends solely on the current state (Moore output). This explicit separation makes the FSM more readable, may improve timing by isolating sequential and combinational logic, and provides a clearer optimization path for synthesis tools. The asynchronous reset sets the state to B (encoded as 1). This structure is still minimal, with only one bit state, so area overhead is minimal. It also allows easier insertion of clock gating or clock enables in the future for power optimization.
