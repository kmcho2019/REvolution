I will implement the FSM using two one-hot encoded state bits instead of a single binary bit. This means:

- Use two flip-flops, one representing state A and the other representing state B.
- The asynchronous reset will set the FSM to state B by activating only the B state bit.
- Next state logic will be implemented combinationally using simple gates derived from the state transitions.
- Output will be assigned combinationally from the one-hot state bits, making it clear and scalable for larger FSMs.
- This one-hot encoding can simplify next-state logic for certain synthesis tools and improve timing by reducing logic depth, albeit at a slight area cost.

This approach is structurally different, more explicit, and potentially better for timing in some flows.
