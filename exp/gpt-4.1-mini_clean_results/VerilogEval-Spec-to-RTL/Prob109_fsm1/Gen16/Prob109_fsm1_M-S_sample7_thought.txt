Since the FSM has only two states, it can be efficiently encoded as a single bit: 0 for state A and 1 for state B. The output is directly the state bit because output=1 for B and 0 for A. The next state logic simplifies to toggling the bit or holding it depending on input as per the diagram. The asynchronous reset sets the state to B (1). This reduces the number of flip-flops and combinational logic, improving area and power without changing functionality.
