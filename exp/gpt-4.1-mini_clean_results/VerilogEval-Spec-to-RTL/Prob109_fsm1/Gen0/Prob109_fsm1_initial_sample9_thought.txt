Implement a Moore machine with two states A and B, represented by one bit: 0 for A and 1 for B. On async reset high, state is set to B (1). On each clock edge, state transitions based on input 'in' according to the diagram:

- From B (1): if in=0, next state = A (0); if in=1, next state = B (1)
- From A (0): if in=0, next state = B (1); if in=1, next state = A (0)

Output depends on current state (Moore machine): output = 1 if in state B, else 0.
