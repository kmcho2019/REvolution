To improve PPA, reduce the combinational logic and flip-flop area by encoding the output directly as a registered signal combined with the state. Since the output depends only on state, we can combine state and output into a single register where the output bit is the state bit itself. This reduces output assignment logic. Also, explicitly removing default cases in combinational logic can minimize logic synthesis overhead. Use blocking assignments in purely combinational blocks to help synthesis tools optimize better. Since the FSM is simple, this approach preserves functionality and reduces area and slight dynamic power by reducing logic gates and toggling.
