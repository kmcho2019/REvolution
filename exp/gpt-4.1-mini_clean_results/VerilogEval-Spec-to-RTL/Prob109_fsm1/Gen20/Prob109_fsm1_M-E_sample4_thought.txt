I will implement the Moore FSM using a two-bit state encoding with one-hot style for clarity, even though only two states are present. This approach allows the output to be generated directly from the state register bits without combinational logic. To further differ from the example, I will:

- Use an explicit next-state combinational block with a case statement for readability.
- Define two state bits: state_A and state_B, mutually exclusive, representing states A and B.
- Asynchronously reset the machine to state B by setting state_B=1 and state_A=0.
- Use the fact that output = 1 when in state B, 0 when in state A; output = state_B.
- Use nonblocking assignments for all sequential logic.
- This architecture emphasizes explicit one-hot encoding and a combinational next-state block, which may improve debug clarity and is a different design style from the previous example.

Though slightly more verbose, this design keeps the FSM behavior the same while offering a clear separation of states and outputs.
