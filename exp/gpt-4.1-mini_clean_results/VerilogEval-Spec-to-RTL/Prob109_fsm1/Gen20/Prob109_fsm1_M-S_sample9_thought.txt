The FSM has only two states encoded as a single bit, and output equals the state value. The next state depends on current state and input with a simple logic. To simplify:

- Represent states implicitly by the output signal itself, no need for a separate state register.
- Use a single always block with asynchronous reset to update the output.
- Calculate next state directly inside the always block with simple if-else or ternary logic.
- Since output equals state, we can assign output as reg updated on clock and reset.
- Avoid separate wires or localparams; just treat output as state register, which simplifies code and keeps functionality intact.
