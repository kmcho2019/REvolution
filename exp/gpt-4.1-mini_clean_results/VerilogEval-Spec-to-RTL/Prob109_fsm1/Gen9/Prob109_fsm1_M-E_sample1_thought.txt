Implement the FSM as a two-bit encoded state register, where the states A and B are encoded as 2-bit one-hot codes (A=2'b01, B=2'b10). Use asynchronous reset to initialize to B (2'b10). The next state logic is computed using combinational logic optimized for one-hot state encoding. The output is a Moore output derived from the decoded current state: output is 1 when in state B, else 0. This approach uses one-hot encoding for clearer state decoding and could benefit designs where one-hot style FSMs are preferred for timing or synthesis tool advantages.
