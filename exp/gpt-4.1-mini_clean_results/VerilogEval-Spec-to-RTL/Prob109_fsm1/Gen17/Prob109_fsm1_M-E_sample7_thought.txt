I will implement the Moore FSM using a one-hot encoding style with two flip-flops, one for each state (A and B). The state bits will be mutually exclusive, and asynchronous reset will set the FSM into state B by asserting the B flip-flop and de-asserting the A flip-flop. The combinational next-state logic will be implemented using simple logic equations derived from the state transitions. The output will be derived from the state register (specifically, the B flip-flop) to produce the required output. This approach offers a more explicit representation of each state, which can simplify certain forms of analysis or synthesis optimizations and gives a clear view of state membership.
