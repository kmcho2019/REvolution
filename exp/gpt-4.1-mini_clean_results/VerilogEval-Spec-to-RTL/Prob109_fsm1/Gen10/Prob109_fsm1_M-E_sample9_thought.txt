Instead of encoding the state as a single bit, I will use an explicit two-bit one-hot state encoding where one flip-flop represents state A and another represents state B. Only one flip-flop is set at a time, indicating the current state. This approach clarifies state assignments and transitions, and the output is directly driven from the "B" state flip-flop since output is '1' in B and '0' in A. The asynchronous reset sets the B state flip-flop high and A low. Next state logic is implemented with combinational logic derived from the transition table, updating the flip-flops accordingly on the clock edge.
