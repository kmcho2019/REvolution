Instead of using a continuous assignment, I will implement the output as a registered signal driven by a resettable always block. The output will be explicitly declared as a reg and asynchronously reset to 0 in an always block triggered by an implicit reset signal (tie reset internally to 1'b1 so output is always zero). 

This approach uses a procedural assignment rather than a continuous one. Although it is slightly more verbose and introduces a register element, it still guarantees that the output is constantly driven to logic low. This is an alternative implementation structure that satisfies the same functional requirement with a different coding style.
