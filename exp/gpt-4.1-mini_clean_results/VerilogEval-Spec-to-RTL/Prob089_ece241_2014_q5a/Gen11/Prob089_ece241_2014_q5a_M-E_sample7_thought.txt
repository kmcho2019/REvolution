Implement the 2's complement serial complementation as a two-state Moore FSM with an explicit registered "carry" flag that indicates whether the least-significant '1' bit has been encountered yet. Before the first '1' bit in the input, the output equals the input bit (copying the LSBs). Once the first '1' is detected (carry set), subsequent bits are inverted. 

Use asynchronous reset to initialize the carry flag to 0. On each clock, sample the input and update the carry: if carry is 0 and input is 1, set carry to 1; if carry is 1, it remains 1. Output logic depends only on the registered carry and input to maintain Moore behavior.

This approach simplifies the FSM into a single "carry" bit that tracks when to start bit inversion, avoiding separate state encodings, and makes the logic straightforward and easy to understand. It also keeps Moore outputs strictly dependent on registered signals for timing consistency.
