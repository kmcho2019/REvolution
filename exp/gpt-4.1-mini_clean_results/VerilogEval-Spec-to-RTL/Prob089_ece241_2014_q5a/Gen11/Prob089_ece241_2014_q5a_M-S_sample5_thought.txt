Implement a two-state Moore FSM with asynchronous reset that directly samples input x and updates state on the clock edge without extra registers. The output depends only on the current state and input. Simplify by merging input sampling and state transitions, and compute output combinationally from the registered state and immediate input, avoiding an extra input register.

This reduces the number of registers and keeps output logic simple while preserving correct 2's complement behavior on the serial input stream. The FSM starts in state S0 (waiting for the first '1'), then transitions to S1 (inverting bits) after the first '1' is seen, outputting either x or ~x accordingly. Asynchronous reset forces the FSM back to S0.

This approach reduces complexity by removing the input register and relying on the current input x directly for output computation.
