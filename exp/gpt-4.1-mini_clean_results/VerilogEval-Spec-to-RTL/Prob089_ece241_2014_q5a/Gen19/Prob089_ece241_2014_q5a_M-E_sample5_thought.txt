Implement a two-state Moore FSM that delays the input bit by one clock cycle using a register, and controls the output as follows: the machine starts in the WAIT_FOR_ONE state where the output z is zero until the first '1' bit arrives (this design chooses to output zero initially to clearly separate the states). Once a '1' is detected on the input x (LSB of the number), the FSM moves to INVERT_REST state. In INVERT_REST state, the output z is the inverted delayed input bit, reflecting the bitwise NOT of the remaining bits after adding one (2's complement). The delayed input register ensures stable output for Moore output requirements. Reset asynchronously sets the FSM back to WAIT_FOR_ONE state and clears the delay register. This approach separates the first addition of one bit from the inversion of the following bits and cleanly implements the serial 2's complement computation.
