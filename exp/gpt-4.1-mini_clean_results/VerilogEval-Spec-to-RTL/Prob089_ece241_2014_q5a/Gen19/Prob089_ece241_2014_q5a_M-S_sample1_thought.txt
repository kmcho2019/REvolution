Use a single register that serves both to capture input bit and track if the first '1' bit has been encountered, leveraging the Moore output directly from this register. On async reset, clear this register. On clock edge, update it by OR-ing the current value with input x, so it latches '1' once encountered and stays there. Output is then simply the register XORed with input, producing the 2's complement output. This eliminates the separate x_reg and simplifies the design to a single state register.
