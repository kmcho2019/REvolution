Implement the serial 2's complementer as a two-state Moore FSM: before the first '1' bit is seen, output the input bit unchanged; after the first '1' bit is detected, output the inverted input bit (achieving bitwise inversion plus adding 1). Use a state register that tracks if we've encountered the first '1'. Use asynchronous reset to initialize. Sample input on clock edge and update state accordingly.
