Implement the 2's complement serial converter as a Moore FSM with three states that explicitly track the carry propagation during the inversion process. The states are IDLE (reset state), WAIT_FOR_LSB (waiting to receive the first '1' bit to start inversion), and INVERTING (once the first '1' is found, invert subsequent bits). Use one hot encoding for states for clarity and ease of debugging. 

The asynchronous reset will initialize the FSM to IDLE state. When reset deasserts, the FSM waits for the input bit stream. The first '1' encountered in the input stream switches the FSM from WAIT_FOR_LSB to INVERTING, outputting the same '1' bit. After that, the FSM outputs inverted bits of subsequent inputs until reset is asserted again. The output depends only on state and input (Moore output defined by state and input). The output z is registered to maintain Moore FSM property with synchronous output update.

This architecture explicitly models the carry of the 2's complement operation as FSM states and uses one-hot encoding for explicitness and potential speed improvements due to simpler next-state logic.
