Implement a two-state Mealy FSM that outputs the 2's complement serially without explicitly registering the input, thereby minimizing registers. 

- Use two states: WAIT (haven't seen the first '1' yet) and INVERT (have seen the first '1').
- Output `z` is generated combinationally as follows: 
  - In WAIT state, output equals input `x` (copy input bits).
  - In INVERT state, output is inverted `x` (bitwise complement).
- The next state transitions asynchronously on input `x` and current state:
  - From WAIT to INVERT on seeing the first '1'.
  - Remain in INVERT afterward.
- Implement state register with asynchronous reset.
- This Mealy output logic reduces registers to one for state only and removes input sampling register.
- The output depends on current input and state, which aligns with a Mealy machine, potentially giving one-cycle less latency.
- The asynchronous reset sets FSM back to WAIT immediately.
- This architecture uses minimal resources and is conceptually straightforward.

Though Mealy output slightly differs from requested Moore style, it is a valid alternative design, prioritizing minimal registers and immediate output updating.
