Simplify the design by directly using the asynchronous reset on the state register and minimizing the number of signals. Use a single state bit to track whether we've encountered the first '1' bit to switch from COPY to INVERT state. Compute the output directly from the current state and input without registering the input, as the FSM outputs depend only on the state and current input. This reduces flip-flops and combinational logic. The asynchronous reset is preserved on the state register. The Moore FSM has two states: COPY (initial state) and INVERT (after the first '1' is seen). Output is input XOR state.
