Implement the 2's complement Moore FSM using three separate always blocks to cleanly separate concerns and improve timing clarity: (1) asynchronous reset and state update, (2) input sampling, and (3) output generation from state and sampled input. The state machine will use two states: BEFORE_CARRY (waiting for the first '1' bit) and AFTER_CARRY (inverting all subsequent bits). Sampling the input x into x_reg in its own always block removes input-to-state timing dependency. Output z depends only on the current state and the sampled input, preserving the Moore machine property. This modular approach helps improve timing and readability while strictly meeting the spec.
