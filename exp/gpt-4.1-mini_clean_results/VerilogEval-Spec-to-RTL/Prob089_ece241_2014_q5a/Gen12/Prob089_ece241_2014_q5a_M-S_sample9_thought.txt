Implement the two-state Moore FSM without an explicit registered input to reduce flip-flops and simplify the design. Use only the state register to track whether the first '1' bit has been seen. Output is directly x XOR state bit (which indicates inversion). This removes the extra input register and inversion_bit register by encoding inversion_bit as the FSM state itself. Use asynchronous reset to initialize the state. This reduces complexity, area, and power while maintaining the Moore FSM behavior and functionality.
