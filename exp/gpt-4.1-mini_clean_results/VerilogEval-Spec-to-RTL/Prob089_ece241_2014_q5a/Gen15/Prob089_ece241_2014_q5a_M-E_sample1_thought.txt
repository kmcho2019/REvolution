Implement the 2's complement serial converter as a Moore FSM with three explicit states encoded in a 2-bit state register for clarity and future extensibility: IDLE (waiting for reset release), COPY (copy input bits until the first '1' bit is seen), and INVERT (invert remaining bits after the first '1'). On the asynchronous positive edge reset, return to IDLE. When reset is deasserted, transition to COPY to start processing. The output z depends solely on the current state and input x: output equals x in COPY state and inverted x in INVERT state. IDLE outputs zero. The state transitions and output logic are combinational, with the state register updated on clock edge or async reset. This approach makes states explicit, with a clear initialization phase, and keeps the FSM fully Moore style and synchronous except for async reset.
