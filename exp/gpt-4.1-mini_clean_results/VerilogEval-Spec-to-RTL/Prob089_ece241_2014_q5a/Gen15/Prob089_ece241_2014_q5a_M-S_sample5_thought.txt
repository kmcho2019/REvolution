Use a two-state Moore FSM with asynchronous reset to produce serial two's complement output.

- States:
  S0: Before first '1' bit found; output input bit directly.
  S1: After first '1' bit; output inverted input bit.

- Register the state only; output depends on current state and current input x.

- Since output depends only on state and input x, and the FSM is Moore type (output only depends on state), output can be registered and updated on clock edge along with state.

- To keep design simpler, update output z synchronously with state at clock edge using current input x and state.

- Asynchronous reset sets FSM to S0 and output z to 0.

This eliminates the need for registering input separately and the next_state signal, reducing logic complexity while maintaining correct functionality.
