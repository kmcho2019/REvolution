Implement a Moore FSM with two states: BEFORE_CARRY and AFTER_CARRY. Initially, the machine is in BEFORE_CARRY state, where it copies the input bit to output z. When the first '1' bit is encountered on input x, the FSM transitions to AFTER_CARRY state. In this state, the FSM outputs the inversion of the input bits, thus completing the 2's complement by adding one to the number.

Sample input x in a register for stable Moore output. Use asynchronous reset to initialize the FSM to BEFORE_CARRY. The output z is generated combinationally from the registered input bit and the current state.

This approach uses explicit named states with a one-bit state register, clear state transitions, and a combinational output depending only on current state and registered input, satisfying Moore FSM requirements. This provides clear separation of state machine logic and output logic, distinct from the previous solution's direct XOR with state.

Additionally, using a parameter for states enhances readability and extensibility.
