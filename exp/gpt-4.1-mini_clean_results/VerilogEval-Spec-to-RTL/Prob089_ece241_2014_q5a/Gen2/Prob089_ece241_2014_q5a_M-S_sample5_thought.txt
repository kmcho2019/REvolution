The essential logic of the 2's complement serial converter is to output the input bit until the first '1' is seen, then output the inverted bits thereafter. This requires only one state bit: before the first '1' and after.

We can implement this with a single state register bit (e.g., 'seen_one'), set when the first '1' is detected. The output can be computed combinationally from 'seen_one' and 'x' but since output must be Moore (registered) and synchronous, we register output on clk.

Using a single register 'seen_one' simplifies state and next state logic. The asynchronous reset sets 'seen_one' to 0. On each clock, if not reset, 'seen_one' becomes 1 when input is 1 or remains 1. The output z is registered to keep Moore FSM behavior, outputting x if not seen_one else ~x.

This simplification reduces the state machine from two states to a single bit, with straightforward logic and minimal code.
