Implement the two's complement serial converter as a simple FSM with two states: before and after the first '1' bit is seen. Since the output should be a Moore machine output (dependent only on state), register the output so it updates synchronously on the clock edge based on the current state and input. Use asynchronous reset to initialize the FSM. This eliminates combinational output logic, making the output a straightforward registered signal reflecting the FSM state and input at the previous clock cycle. This simplification ensures correct timing and functional behavior without extra combinational logic.
