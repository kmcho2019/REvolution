Implement a purely Moore state machine for the serial two's complement conversion that decouples output from the direct input dependency.

Use two states:

- S0 (Waiting): still looking for the first '1' bit (the LSB '1' that starts the two's complement negation)
- S1 (Inverting): after the first '1' is found, output the inverted bits

The output 'z' depends only on the current state and the current input stored in a register.

To achieve purely Moore behavior:

- Register the input bit on every clock cycle.
- The output depends on the registered input bit and the state.
- By registering input, output logic depends solely on registered inputs and state (all synchronous).

This removes direct combinational dependency on asynchronous inputs, stabilizes outputs, and preserves Moore output definition.

Steps:

1. Register input bit x each clock cycle into reg x_reg.
2. The FSM state transitions at posedge clk or async reset.
3. Output z is synchronous, depending on state and x_reg.
4. When in S0, output equals x_reg.
5. When in S1, output equals inverted x_reg.

This makes output stable and aligned with the input bits previously registered, meeting the Moore output criteria.

Asynchronous reset clears state to S0 and x_reg to zero.

This approach ensures correct timing and that output depends purely on internal registered signals and states, avoiding glitches and mismatches.

The design accepts arbitrary length input streams, resets cleanly, and outputs 2's complement bits serially as per the requirement.
