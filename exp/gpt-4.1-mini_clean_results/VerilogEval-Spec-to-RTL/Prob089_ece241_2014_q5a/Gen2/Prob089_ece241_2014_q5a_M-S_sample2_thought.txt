Implement a simple Moore FSM with two states: WAIT (before the first '1' is seen) and INVERT (after the first '1'). On each clock cycle, register the input bit x, then produce output z solely based on the current state and the registered input from the previous cycle. 

- In WAIT state: output the input bit (registered from previous cycle). If that bit is '1', transition to INVERT.
- In INVERT state: output the inverted registered input bit.
- Use asynchronous reset to initialize the state to WAIT and output to 0.
- Output depends only on the state and the registered input (which is considered part of the FSM state), making it a Moore FSM.
- This approach reduces the number of registers and keeps output generation simple and synchronous.

This ensures the output is aligned with the FSM states and inputs in a straightforward way.
