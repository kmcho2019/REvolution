We can simplify the design by merging the next state and output logic directly in one always block without a separate next_state variable. Since the FSM is just two states and the Moore output depends only on the state, we can implement the state update and output generation together.

On asynchronous reset, set state and output to 0. On each clock edge, update state based on the input and current state, and update output accordingly.

This reduces the code size and complexity, avoiding separate combinational logic, while preserving functionality.
