To optimize the design for better power, performance, and area (PPA), remove the extra register on the input `x` and use `x` directly in the FSM combinational logic. This reduces one flip-flop and the additional input-to-register path latency, improving timing and reducing power.

Also, integrate `inversion_bit` as a combinational function of the current state, eliminating the separate inversion_bit register. Since the FSM has only two states (COPY=0 and INVERT=1), `inversion_bit` can be derived as (state == INVERT), which simplifies logic and reduces area.

Maintain the asynchronous reset on state only for quick reset response.

Thus, the FSM only stores the state as a 1-bit register. Next state logic depends on `state` and input `x`. Output `z` is directly computed as x XOR inversion_bit (with inversion_bit = state).

This preserves the Moore FSM property: output depends only on current state and input (x), with no additional registers. The input is not registered, reducing latency and power. The logic is simpler and more compact.

This approach should slightly reduce area (one less flip-flop), improve timing by removing input reg stage, and reduce dynamic power due to fewer registers toggling.
