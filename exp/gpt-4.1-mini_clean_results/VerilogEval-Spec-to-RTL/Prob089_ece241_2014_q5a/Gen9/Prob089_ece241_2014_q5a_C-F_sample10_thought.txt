Fuse the clarity and enumerated state approach from Example 1 with the simplicity and minimal registers of Example 2 to create a clean, efficient Moore FSM for serial two’s complement. 

Specifically:
- Use an enumerated type for the two states (COPY and INVERT) for readability and explicitness.
- Keep a single state register representing whether inversion is active, minimizing flip-flops.
- Sample input x into a register (x_reg) on the clock with asynchronous reset, to stabilize input and align with Moore FSM principles.
- Combine next-state logic into a simple combinational block using the registered input, with straightforward transitions.
- Generate output combinationally as z = x_reg XOR (state == INVERT), ensuring the output depends only on the FSM state and registered input, meeting Moore output property.
- Use asynchronous reset on all registers for reset responsiveness as specified.
- This design balances readability, clarity, area, power, and timing by separating input sampling, state transition, and output generation cleanly, and leverages the advantages of both prior designs.
