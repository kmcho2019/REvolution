Implement the 2's complement serial converter as a Moore FSM with two states: BEFORE_FIRST_ONE and AFTER_FIRST_ONE.

- The FSM starts in BEFORE_FIRST_ONE state after asynchronous reset is deasserted.
- The output Z in BEFORE_FIRST_ONE state is simply equal to the input bit X, effectively copying bits until the first '1' is found.
- Upon encountering the first '1' (LSB 1), the FSM transitions to AFTER_FIRST_ONE state.
- In AFTER_FIRST_ONE state, the output Z is the inverted input bit (X'), representing the 1's complement of the rest of the bits.
- The output depends only on the current state and input, maintaining Moore FSM style.
- To maintain Moore FSM properties strictly, output Z will be registered synchronously with the clock and asynchronously reset.
- The input is used directly without registering to minimize flip-flops.
- The asynchronous reset initializes the FSM state and output Z to zero.
- The state register and output register update on the positive clock edge or asynchronous reset.
- This approach uses only two flip-flops: one for FSM state and one for registered output.
- The direct use of input X avoids extra input registers, reducing area and latency.
- The output is registered for glitch-free output and proper sequencing.
