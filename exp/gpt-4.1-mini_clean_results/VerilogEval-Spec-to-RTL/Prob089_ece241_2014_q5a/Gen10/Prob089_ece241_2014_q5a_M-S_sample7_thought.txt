The two-state Moore FSM can be simplified by combining state and output logic directly in a single state register and using only one always block for both sequential state and output updates. Since the output depends only on whether the first '1' bit has been seen or not, we can use a single bit register that holds whether we have encountered the first '1'. Before that, output is 0; once the first '1' is seen, output that '1' and then output inverted bits. This eliminates the combinational always block and next_state variable, reducing complexity while preserving function.
