Implement the serial 2's complementer as a Moore FSM with three states: IDLE, COPY, and INVERT. On reset release, the FSM starts in COPY state, copying input bits to output until it detects the first '1' bit in input x; then it transitions to INVERT state, outputting the inverted input bits thereafter to complete 2's complement operation. The output z depends only on the current state (Moore output) and is registered synchronously with the clock.

Use an asynchronous reset that puts the FSM into IDLE state with output zero. When reset deasserts, move to COPY state immediately. In IDLE, output zero, no valid data processed. This clearly separates reset condition from active operation. 

The output is registered and depends only on the current state:

- IDLE state: z=0
- COPY state: z = x
- INVERT state: z = ~x

This design aligns strictly with Moore FSM definitions, cleanly separates reset handling, and makes explicit the waiting-for-start vs. copying vs. inverting stages. It can gracefully handle arbitrarily long inputs and stops processing when reset is asserted again.
