Combine the minimalistic state encoding and asynchronous reset style from Example 1 with the clean separation of combinational and sequential logic and explicit next-state computations from Example 2. 

Key fusion points:
- Use a single bit state encoding (`inversion_active`) as in Example 1 for minimal hardware.
- Sample input (`x_reg`) on clock to stabilize input and maintain Moore output dependency on registered signals.
- Compute next state and registered input combinationally before updating both registers on clock.
- Asynchronous reset initializes state and sampled input.
- Generate Moore output purely combinationally as XOR of registered input and state for fast, glitch-free output.
- Maintain clean, separate always blocks for combinational next state/next input calculation and sequential state/input update.
- Avoid registered output for lower latency and simpler design, output is purely combinational on registered signals.
- This fusion balances clarity, minimal area, good timing, and correct asynchronous reset behavior.

This design avoids the multiple always blocks for output register, removes extra output register latency, and combines input sampling and state update in a disciplined two-block FSM style. It is a strictly Moore FSM with robust asynchronous reset and stable output.
