Implement the 2's complement Moore FSM with a single always block that both updates state and samples input, using only one registered input signal. The output is directly driven as a combinational function of the current state and the registered input, matching Moore semantics. By merging input sampling and state update, and using only one state register and one input register, the design is simplified while preserving behavior. Asynchronous reset sets the FSM to initial state and input to zero.
