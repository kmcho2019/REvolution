Implement the 2's complement serial converter FSM as a Moore machine with three states: IDLE, PASS (copy bits until the first '1' is found), and INVERT (invert all subsequent bits). Use a state register to hold the current state and a registered output 'z'. The asynchronous reset initializes the FSM to IDLE and output zero. On release of reset, the FSM starts processing bits on each clock cycle. The output depends solely on the current state and input bit: in IDLE, output zero; in PASS, output input bit as-is; in INVERT, output inverted input bit. This clear state distinction explicitly separates waiting, copying, and inverting phases and may be easier to extend. All sequential logic is in a single always block triggered on posedge clk or posedge areset, while combinational next state and output logic is computed in a separate always_comb block.
