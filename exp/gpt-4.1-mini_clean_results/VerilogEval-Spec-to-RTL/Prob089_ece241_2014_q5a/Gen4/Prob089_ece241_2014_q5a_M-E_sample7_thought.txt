Implement the serial 2's complementer using a three-state Moore FSM that explicitly tracks whether we have not yet seen any '1' bits, are currently outputting the first '1' bit (which acts as the starting point of the 2's complement), or are in the inversion phase where all subsequent bits are inverted. On reset, the FSM goes to the initial WAIT state (no output). On release of reset, it waits for the first '1' bit. When the first '1' is seen, it outputs a '1' and transitions to the INVERT state, where the output is the inverted input bits. This explicitly models the carry-in of the two's complement addition as state, making the design easily extensible for debug and clear in operation. The output depends only on the current state, making it a Moore machine. The output register is updated synchronously on clock with asynchronous reset. This design separates concerns and states more explicitly than the two-state design.
