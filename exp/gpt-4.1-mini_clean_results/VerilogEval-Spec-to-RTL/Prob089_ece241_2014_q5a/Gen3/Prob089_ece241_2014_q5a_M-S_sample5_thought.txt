Use a minimal two-state Moore FSM with asynchronous reset, where the state itself indicates whether we have encountered the first '1' bit. Initialize in COPY state (no inversion, output = x), transition to INVERT state upon seeing the first '1' input bit (then output is inverted). The output depends only on the current state and the input: z = x when in COPY, z = ~x when in INVERT. Register state and output synchronously, with asynchronous reset clearing the state and output. This avoids storing an extra inversion bit by directly encoding inversion in the state. The output can be registered synchronously on clock edge using state and input, preserving Moore behavior with output depending only on state.
