Implement the 2's complement serial converter as a Mealy FSM to leverage direct input dependency in output, thereby reducing the number of states and potentially output latency. Use two states: an initial state before the first '1' is detected where output z equals input x (passing zeros), and a second state after the first '1' is detected where the output z is the inversion of x. Use asynchronous reset to initialize the FSM. The output z is combinational and depends on current state and input x, while the state updates on the clock edge with asynchronous reset. This Mealy approach simplifies the FSM, potentially reduces state bits, and provides a different output timing compared to the Moore FSM.
