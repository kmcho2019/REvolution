We implement a Moore FSM with three states to perform the serial 2's complement operation on input bits starting from the LSB:

- WAIT_START: waiting for reset de-assertion to begin processing (output always 0).
- PASS_THROUGH: before the first '1' (LSB) is encountered, the output directly copies input bits (z = x).
- INVERT_BITS: after the first '1' bit has been output, subsequent bits are inverted (z = ~x).

On asynchronous reset assertion, the machine goes to WAIT_START with output 0. When reset is released, the FSM starts in PASS_THROUGH state. Upon seeing the first '1' input bit, it transitions to INVERT_BITS state. The output is registered on clock edges (Moore output), depending only on the current state.

This architecture uses a 2-bit registered output to represent the output z, registered only from the current state, making the output purely Moore. The output logic is implemented with a simple combinational function of the state and input. We use a three-state FSM which is more explicit in the control flow and does not rely on a separate inversion bit.

The output is registered synchronously to clk but reset asynchronously, fully adhering to the positive-edge triggered flip-flop behavior with asynchronous reset requirement.
