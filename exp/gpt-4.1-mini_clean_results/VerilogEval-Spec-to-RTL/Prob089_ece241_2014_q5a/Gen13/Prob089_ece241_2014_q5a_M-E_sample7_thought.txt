Implement the 2's complement serial converter as a two-state Moore FSM with explicit states representing whether the first '1' bit has been encountered or not. Instead of registering the input separately, sample input 'x' directly in the sequential block to decide state transitions, and register the output bit 'z' in the state machine to produce a fully registered synchronous output (except for asynchronous reset). The FSM state encoding will include both the FSM status and the output bit, so only one state register is needed. This reduces combinational logic on the output path, as output 'z' is stored in a flip-flop and changes only on clock edges, enhancing timing and glitch immunity. Asynchronous reset initializes the FSM to "waiting for first 1" state and output zero.
