Implement the 2's complement serial converter as a Moore FSM using three states that explicitly represent the progress of the operation: WAIT_FOR_START, PASS_THROUGH, and INVERT_BITS. On reset deassertion, the FSM starts in WAIT_FOR_START. It waits until it detects the first '1' bit in input x, outputs that bit unchanged (PASS_THROUGH state), and then transitions to INVERT_BITS state, where it outputs the inverted input bits, implementing the +1 addition of the 2's complement.

This explicit three-state FSM approach simplifies reasoning about the output behavior, as the Moore output depends only on the current state and stored input bit. The output is registered (Moore output) driven from a state-dependent stored bit and the current input. Asynchronous reset is handled on the flip-flops, with synchronous state transitions on the clock's positive edge.

This design avoids storing the inversion bit separately by encoding it in the FSM states, simplifying the output logic. Also, we register the input x synchronously to clean the input signal and align it with state transitions, enabling proper Moore output timing.

The output z is registered (Moore output) and updated on the clock edge, ensuring output stability during the clock period.
