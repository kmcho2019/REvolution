Implement the serial 2's complementer as a Moore FSM with three states to explicitly track whether the first '1' bit has been encountered and to explicitly handle reset behavior:

- States:
  - IDLE: during asynchronous reset (waiting for reset release), output is zero.
  - COPY: pass input bits as-is until the first '1' bit is detected.
  - INVERT: invert all subsequent bits after the first '1'.

- The FSM starts in IDLE when reset is asserted. When reset is released, it goes to COPY.

- The output `z` depends only on the current state and the registered input bit, ensuring Moore output.

- Use a 2-bit state register with one-hot encoding for clarity and robustness.

- Sample input `x` on clock edges to stabilize input.

- Asynchronous reset forces state and input registers to known states immediately.

- Output logic: in IDLE output zero, in COPY output input as-is, in INVERT output inverted input.

This explicit state encoding clarifies the FSM operation and cleanly handles asynchronous reset. The one-hot style makes it easy to add or modify states if needed.
