A different approach is to implement the serial 2's complementer as a Moore machine with three states to explicitly handle each phase:

- STATE_ZERO: initial state before any '1' is seen; output equals input bit.
- STATE_ONE: first '1' has been encountered; output equals input bit (the first '1' passes unchanged).
- STATE_INVERT: after the first '1', invert all subsequent bits.

This separates the "before first 1" and "at first 1" to clarify output timing.

Upon reset release, start in STATE_ZERO. On input 'x':
- If in STATE_ZERO and x == 0, output x, stay in STATE_ZERO.
- If in STATE_ZERO and x == 1, output x, move to STATE_ONE.
- If in STATE_ONE, output x (the first '1'), then move to STATE_INVERT.
- If in STATE_INVERT, output inverted x and stay.

Output depends only on state and current input; since this is a Moore machine, output is combinationally assigned from state and input, stored in output register on clock edge.

This explicit three-state solution improves state clarity and meets all requirements.

Asynchronous reset initializes the FSM to STATE_ZERO with output 0.

This design separates next state and output logic combinationally, updating registers on clock and reset edges, enhancing readability and potentially better for synthesis.
