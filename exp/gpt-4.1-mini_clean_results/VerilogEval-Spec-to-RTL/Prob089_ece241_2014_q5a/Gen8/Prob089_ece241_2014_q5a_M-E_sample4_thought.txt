Design a two-state Moore FSM that processes input bits serially to produce the 2's complement output without registering the input explicitly. Instead, sample the input bit 'x' directly in the state transition logic at the clock edge, and use a single state register. The state encodes whether the carry (the first '1' bit) has been encountered. The output 'z' is registered and updated each clock cycle according to the current FSM state and the current input. Use asynchronous reset to initialize both the state and output registers. This approach reduces registers by eliminating an explicit input register, capturing input directly in the sequential logic, and registers output to balance timing and synchronize output changes with the clock.
