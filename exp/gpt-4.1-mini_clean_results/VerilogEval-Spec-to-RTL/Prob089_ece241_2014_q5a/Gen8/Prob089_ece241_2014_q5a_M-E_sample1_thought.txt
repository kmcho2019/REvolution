Implement the serial 2's complementer as a two-state Moore FSM but encode the output explicitly as a registered output bit that depends solely on the state, and compute the final output combinationally. 

The FSM will have two states:

- S0 (COPY): output 0, meaning bits are passed through as is.
- S1 (INVERT): output 1, meaning bits are inverted.

The FSM transitions from S0 to S1 when the first '1' bit is seen on input x, and then stays in S1 for all subsequent bits.

The output z is generated by XOR-ing the input bit x with the registered output bit associated with the current state. Since this depends only on the state (for output bit) and input (for XOR), the output is Moore with respect to state.

Implement three always blocks:

1. Asynchronous resettable state register.
2. Combinational next state logic based on current state and input.
3. Combinational output logic: z = x ^ output_bit (where output_bit is 0 in S0, 1 in S1).

This structure keeps output logic combinational and outputs stable one clock cycle after state update, strictly Moore FSM. It also simplifies output logic by keeping the output_bit as a constant per state (0 or 1), which is assigned in a combinational block.

This is a novel approach since the output z is purely combinational logic from current input and state output_bit, which itself depends only on the state, satisfying Moore FSM definition.

The reset asynchronously initializes the FSM to S0 state (COPY).

This design handles arbitrary length inputs and produces 2's complement serial output starting from LSB.
