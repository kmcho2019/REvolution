Implement a serial 2's complementer Moore FSM using three states to explicitly represent the processing phases: IDLE (waiting for reset release), COPY (copy input bits until first '1'), and INVERT (invert subsequent bits). On asynchronous reset, the FSM goes to IDLE. When reset is released, the FSM moves to COPY state, copying input bits (least significant bits first) until it sees the first '1', then transitions to INVERT state to output inverted bits. This design uses an explicit state register and a combinational output function based only on the current state and input, ensuring Moore outputs. The asynchronous reset cleanly initializes state. Output z is a registered output updated on clock edge for stable timing. The design avoids registering the input, reducing flip-flop count and potential clock-to-output delay, instead using the raw input in output and next-state logic. This approach clarifies operation phases and preserves correctness while slightly simplifying registers.
