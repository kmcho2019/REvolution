Implement a three-state Moore FSM to handle the serial 2's complement conversion more explicitly.

- States:
  IDLE: reset state, waiting for reset de-assertion.
  COPY: copy input bits (least significant bits) to output until the first '1' is found.
  INVERT: after the first '1' is encountered, output the inversion of subsequent input bits.

- Operation:
  On asynchronous reset, the FSM goes to IDLE state and outputs zero.
  When reset is de-asserted, the FSM goes to COPY state to process input bits.
  In COPY, output equals input bit x. If x is '1', transition to INVERT state.
  In INVERT, output equals inverted input bit x.

- Registers:
  Store current state in a register.
  Register input bit x to stabilize output and for state transition decisions.
  Output z is registered (Moore machine) and depends only on the current state.

This design separates the reset handling explicitly, ensuring no output except zero during reset (IDLE), thus defining clear input-to-output timing boundaries. It also uses a three-state FSM for more explicit state control and enhances output stability by registering output z synchronously.

This approach differs from the previous two-state solution by adding an explicit IDLE state and registering the output, improving timing and clarity.
