Implement the 2's complement Moore FSM by defining three states to explicitly track the processing of input bits: WAIT_FOR_LSB, COPY_BITS, and INVERT_BITS. The FSM starts in WAIT_FOR_LSB on reset and waits for the least significant bit (LSB) input. Upon receiving the LSB bit, the output z equals x directly (copy the LSB), then it transitions to COPY_BITS state.

In COPY_BITS, the FSM outputs bits equal to input x as is until the first '1' bit is encountered, which is output directly and triggers the FSM to move to INVERT_BITS state.

In INVERT_BITS, the FSM outputs the bitwise inverted input (x̅), effectively performing the bitwise inversion part of the two's complement after the first '1' bit.

The FSM outputs z combinationally based only on the current state and input x (Moore machine output depends on state), ensuring one clock cycle latency from input to output. The asynchronous reset resets the FSM to WAIT_FOR_LSB state immediately.

This design clearly separates the process into three well-defined states, improving clarity and explicitness of the 2's complement operation in serial input. It avoids registering input x, thus reducing latency. The output z logic is purely combinational from state and input x.

Use an enumerated type for states to improve code readability.
