Implement the 2's complement Moore FSM with a single state register holding a two-state machine: before the first '1' bit (carry not started) and after it (carry started). Instead of registering the input separately, directly use the input 'x' in the state transition, but generate the output 'z' registered on the clock for a fully synchronous Moore output. The FSM transitions asynchronously reset and uses synchronous state update on clk posedge. This design has only two always blocks: one for state and output update synchronously on clk posedge with asynchronous reset, and one combinational block for next state logic. Output 'z' is registered to strictly follow Moore FSM definition and improves output timing stability. The architecture minimizes registers to state and output, no input register, simplifying datapath while meeting spec.
