Implement a two-state Moore FSM that explicitly tracks whether the first '1' bit (the least significant set bit) of the input stream has been encountered. Before the first '1', output matches input; after encountering the first '1', the output bit toggles with each input bit, effectively performing bitwise inversion plus carry addition for 2's complement. 

The FSM states are:
- S0: Waiting for first '1' in input; output = input
- S1: After first '1' found; output = inverse of input

The state transitions:
- From S0 to S1 when input bit is '1'
- Stay in S1 thereafter

Output depends solely on the state and input bit (Moore machine).

Implement asynchronous reset to set FSM to S0 and output accordingly.

This architecture clearly separates the FSM logic, uses minimal registers (one state bit), and directly reflects the 2's complement carry logic on serial input.
