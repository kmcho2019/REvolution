Implement the serial 2's complement as a Moore FSM with three states: IDLE (waiting for reset release), SEARCHING (looking for the first '1'), and FLIPPING (after the first '1' is found). Use a 2-bit state register to encode these states. On reset, go to IDLE with output zero. When reset is released, start in SEARCHING. While searching, output bits equal to input bits (copy input). Once the first '1' is detected, transition to FLIPPING and output the inverted bits thereafter. This clean state encoding explicitly separates the "copy bits" phase and "flip bits" phase and outputs based on current state, preserving Moore semantics. Asynchronous reset and positive edge clocking are maintained.
