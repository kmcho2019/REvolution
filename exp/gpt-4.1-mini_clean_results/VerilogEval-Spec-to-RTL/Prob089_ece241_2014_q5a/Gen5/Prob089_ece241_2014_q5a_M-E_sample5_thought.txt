This design implements the 2's complement serial complementation using a three-state Moore FSM:

- States: WAIT_RST (waiting for reset release), FIND_ONE (copy input until first '1' is found), and INVERT (invert input bits after first '1').
- On asynchronous reset assertion, the machine goes to WAIT_RST and output z is zero.
- When reset is released, the machine starts processing bits: 
   - In FIND_ONE, output z equals input x until the first '1' bit is found (which marks the addition of +1 in 2's complement).
   - On detecting the first '1', transition to INVERT, outputting inverted bits thereafter.
- Using a three-state FSM cleanly separates the idle state from the processing states, improving design clarity and avoiding output glitches immediately after reset.
- Output is registered (Moore output) and updated on the clock's positive edge.
- The asynchronous reset is active-high, immediately forcing the machine to WAIT_RST state and output zero.
