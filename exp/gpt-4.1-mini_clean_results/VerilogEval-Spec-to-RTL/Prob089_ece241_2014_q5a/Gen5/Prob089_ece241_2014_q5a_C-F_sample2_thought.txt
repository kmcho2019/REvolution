Fuse the clarity and simplicity of Example 2’s direct state encoding for inversion with the strict Moore FSM output discipline and separate registered output of Example 1 to achieve clean timing, minimal logic, and clear separation of state and output.

Strategy:
- Use two states: COPY (0) and INVERT (1), where INVERT indicates inversion started.
- Register state asynchronously reset to COPY.
- Register output bit separately on clock edge, reset to 0.
- Compute next state combinationally from current state and input x.
- Output register depends only on current state, ensuring Moore FSM property.
- Final output z is registered output bit XORed with current input x on the clock edge to align output with state and input synchronously.

This combines Example 2’s minimal state logic with Example 1’s explicit inversion_bit and output register separated from state to ensure outputs depend only on state and are synchronized. The output calculation is made synchronous, eliminating Mealy timing hazards. The XOR with input inside the registered output update block achieves the required serial 2’s complement output.

This fusion ensures:
- Moore FSM correctness.
- Minimal logic and area.
- Clear synchronous timing on outputs.
- Proper asynchronous reset handling.
- Minimal power by avoiding combinational output logic dependent on inputs.

The result is a compact, efficient, and clean FSM design for the serial 2's complement conversion.
