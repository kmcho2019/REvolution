Implement a simple two-state Moore FSM with states COPY and INVERT encoded as 1 bit, tracking whether the least-significant '1' bit has been seen. On reset, set state to COPY and output z=0. After reset release, output input bit x while in COPY state until first '1' is detected, then move to INVERT state and output inverted x thereafter. Integrate next-state and output logic directly in the sequential always block to reduce logic and remove the separate next state combinational block, simplifying the design while maintaining correct functionality.
