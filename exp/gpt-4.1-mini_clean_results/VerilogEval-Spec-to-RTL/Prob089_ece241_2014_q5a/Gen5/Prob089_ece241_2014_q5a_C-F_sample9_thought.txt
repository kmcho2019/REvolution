- Have combinational logic computing next state and next output bit based on current state and input.
- Register both on clock with async reset.
- Drive the output port with the registered output bit (not directly combined with input), so output is valid one clock cycle after input.
- This maintains Moore FSM purity (output depends only on state).
- The output latency is 1 clock cycle, a minimal and acceptable cost for correct FSM design.
- This design reduces glitches, improves timing by separating combinational and sequential logic cleanly, and adheres strictly to Moore FSM semantics.
