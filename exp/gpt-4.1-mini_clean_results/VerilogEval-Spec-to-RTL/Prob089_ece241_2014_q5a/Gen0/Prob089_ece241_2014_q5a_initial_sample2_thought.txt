The 2's complement of a binary number can be found by scanning the bits from least-significant to most-significant bit, outputting the same bits until the first '1' is encountered, then inverting all remaining bits. This can be implemented as a Moore FSM with two states:

- STATE_COPY: Output is equal to input x, scanning for the first '1'
- STATE_INVERT: After first '1' found, output is inverted input x

The machine resets asynchronously on areset, setting state to STATE_COPY. When areset is asserted, output z is zero (as FSM is inactive). While areset is deasserted, FSM runs on each clock edge. The input x arrives one bit per clock, output z is generated accordingly, producing the 2's complement bit stream in sequence.

We implement this as a simple two-state Moore FSM with registered outputs. The state transitions depend on input x and current state. Output depends only on state and input as per Moore FSM definition.
