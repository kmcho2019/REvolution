Implement a Moore FSM to compute the 2's complement serially. The input bits arrive LSB first. The 2's complement is obtained by copying bits unchanged until the first '1' is encountered, then inverting all subsequent bits. We need two states: BEFORE_ONE (copy bits until first 1), and AFTER_ONE (invert bits after the first 1). On each clock cycle, output depends only on the current state and input. The FSM is reset asynchronously by areset, which also stops the operation by holding output at 0. After reset release, FSM starts from BEFORE_ONE state. The output z is registered, so output changes on clock edge.
