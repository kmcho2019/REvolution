To design a serial 2's complement Moore FSM, we leverage the standard method of two's complement: copy the bits until the first '1' is encountered, then invert subsequent bits. The FSM has two states: COPY (before the first '1') and INVERT (after the first '1'). On each clock cycle:

- If in COPY state:
  - Output z = x
  - If x == 1, transition to INVERT state
  - Else remain in COPY

- If in INVERT state:
  - Output z = ~x
  - Stay in INVERT

On asynchronous active-high reset (areset), return to COPY state.

This design outputs the 2's complement bit serially starting from the LSB.

Use a state register triggered on the positive edge of clk and asynchronously reset by areset.
