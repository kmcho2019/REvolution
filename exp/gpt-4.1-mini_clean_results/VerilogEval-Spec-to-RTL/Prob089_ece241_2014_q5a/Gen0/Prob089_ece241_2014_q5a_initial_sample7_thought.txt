To implement a 2's complementer as a serial Moore state machine, we need to process the input bits starting from the least significant bit (LSB). The 2's complement operation can be done by scanning bits from LSB to MSB and:
- Copy all bits up to and including the first '1' bit directly to the output.
- After the first '1' bit is encountered, invert all subsequent bits.

This suggests a two-state Moore machine:
- State 0 (Before first 1): output = input bit, stay in State 0 until input bit == 1.
- State 1 (After first 1): output = inverted input bit, stay in State 1.

The asynchronous reset (areset) initializes the machine in State 0. The machine processes one bit per clock cycle, outputs the processed bit, and stores the state for the next cycle.

The state machine output depends only on the state, so output is combinational logic from state and input. We update state on every clock cycle based on the input and current state.

When reset is asserted, the machine resets to initial state and stops processing (output undefined or 0). When reset is deasserted, it begins processing input bits, producing the 2's complement serially on output z.

The design uses asynchronous reset on the flip-flops.
