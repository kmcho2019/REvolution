Implement the serial 2's complementer as a Moore FSM with three signals combined in a single always block triggered on the positive edge of the clock and asynchronous reset. Instead of separating input sampling and state updates, directly use the input x to compute the next state and output combinationally inside the clocked block. Use a two-bit state variable representing whether we have seen the first '1' bit (carry-in of the two's complement addition). Initially, the FSM is in the "copy" state where output equals input. Once the first '1' bit is detected, move to the "invert" state where output equals inverted input. The output is registered and updated synchronously with the clock, preserving Moore output style. This approach avoids separate input registers, simplifying logic and reducing latency while keeping asynchronous reset and positive edge triggering.
