Implement the 6-to-1 multiplexer using a combinational continuous assignment with a concatenated vector of all data inputs indexed by the select signal. This approach treats the six 4-bit data inputs as a 24-bit vector, and uses the select value to extract the correct 4-bit chunk. If the select is greater than 5, output zero. This can be done by checking the select value range and conditionally assigning the output using a ternary operator.
