To improve PPA, I will remove the combinational always block and use a continuous assignment with a conditional operator for multiplexer functionality. This approach uses a pure wire assignment which may help synthesis tools generate more optimized multiplexing logic by directly mapping to hardware multiplexers without inferred latches or registers. It can reduce both area and power due to simpler logic structure, and potentially improve timing by eliminating extra logic from the always block. Additionally, using a continuous assignment improves code clarity for purely combinational logic.
