Refactor the 6-to-1 multiplexer to use a continuous assign statement with a conditional (ternary) operator chain instead of an always block and case statement. This approach directly expresses combinational logic and can be more concise. It eliminates the need for an output reg and explicit sensitivity list while maintaining the same functionality. The output will be a wire assigned from the chained conditional expressions selecting the data input based on sel, with a default of zero for out-of-range sel values.
