Optimize the 6-to-1 4-bit multiplexer by using a continuous assignment with a combinational ternary operator chain instead of an always block with case statement. This can help synthesis tools generate more efficient logic with potentially reduced area and power, as the mux logic is expressed more compactly. Also, defining the output as wire eliminates the reg requirement, simplifying the inferred hardware. We keep the default output zero for out-of-range sel values.
