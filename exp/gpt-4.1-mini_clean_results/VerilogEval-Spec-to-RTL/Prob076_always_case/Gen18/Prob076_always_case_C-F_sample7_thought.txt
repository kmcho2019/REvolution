Combine the clarity, synthesis-friendliness, and straightforwardness of the always @(*) case-based mux from Example 1 with the neat function abstraction from Example 2 by defining a dedicated combinational function that covers all cases (0 to 5) and defaults to zero. Then use a simple continuous assignment of the output to the function result, eliminating redundant range checks outside the function. This preserves minimal logic, clean readable code, and explicit default coverage. It improves maintainability by encapsulating mux logic in a function, and improves power and area by avoiding repeated condition checks and splitting logic. The continuous assignment facilitates easy combinational mapping while keeping output a wire, suitable for pure combinational logic and synthesis.
