Implement the 6-to-1 multiplexer using a continuous assignment with a nested ternary operator (?:) chain instead of an always block. This method creates a purely combinational logic using assign statements. It results in concise, readable code that can be efficiently synthesized by modern tools. Also, for out-of-range selector values (sel >= 6), assign zero to the output. This approach avoids the use of reg types and always blocks, showcasing an alternative architectural style for combinational multiplexers.
