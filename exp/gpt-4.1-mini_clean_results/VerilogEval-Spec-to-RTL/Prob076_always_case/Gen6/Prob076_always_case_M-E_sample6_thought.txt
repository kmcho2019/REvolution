Implement the 6-to-1 multiplexer using a single continuous assignment with a nested conditional (ternary) operator. This approach removes the need for a procedural always block and a reg output. The sel input is checked sequentially for values 0 through 5, and the matching data input is assigned to out; if none match, out is 0. This style is concise, purely combinational, and synthesizes efficiently into mux logic.
