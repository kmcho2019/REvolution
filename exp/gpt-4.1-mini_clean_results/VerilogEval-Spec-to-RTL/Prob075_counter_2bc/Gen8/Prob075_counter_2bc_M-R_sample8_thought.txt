Refactor the design by implementing the next state logic using combinational continuous assignments (`assign`) instead of an always block with a case statement. Use explicit increment and decrement signals derived from the input conditions to compute the next state using saturating arithmetic. This approach simplifies the logic by leveraging the numeric nature of the counter, reduces verbosity, and separates the combinational increment/decrement logic clearly from the sequential state register.
