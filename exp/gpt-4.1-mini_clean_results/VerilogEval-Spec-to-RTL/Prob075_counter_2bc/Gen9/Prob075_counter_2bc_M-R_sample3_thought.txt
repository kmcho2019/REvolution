Refactor the design by separating the next state combinational logic from the state register update. Implement a synchronous always block that only updates the state when train_valid is asserted, otherwise holding the current state. Use an asynchronous reset to initialize the state to 2'b01. The combinational logic for next_state computes the saturating increment or decrement based on train_taken. This separation improves readability and may allow synthesis tools to optimize logic better, as next_state is purely combinational and registered separately. It also clarifies the conditions under which state changes.
