Implement the 2-bit saturating counter with straightforward increment and decrement logic by checking boundary conditions directly on the 2-bit counter. On areset, asynchronously reset state to 2'b01. On train_valid, increment the state if train_taken and state is less than 3, decrement if not train_taken and state is greater than 0, otherwise keep the same state. This eliminates the need for a wider temporary variable and complex saturation checks, simplifying the design while preserving correct functionality.
