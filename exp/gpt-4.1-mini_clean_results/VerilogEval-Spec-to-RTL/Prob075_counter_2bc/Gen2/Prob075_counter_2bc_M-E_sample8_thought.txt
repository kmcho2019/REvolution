Implement the 2-bit saturating counter using an explicit next_state wire computed combinationally outside the sequential block, then register it on the positive clock edge or asynchronously reset. The next_state calculation uses arithmetic addition and subtraction with saturation done via min/max functions implemented using Verilog comparisons and ternary operators. This separation of combinational logic and sequential logic improves clarity and may help synthesis tools optimize the datapath. The asynchronous reset sets state to 2'b01 as specified. This approach also explicitly holds the state unchanged when train_valid is low by driving next_state to current state. Using a separate combinational block for next_state makes the design modular and easier to maintain or extend.
