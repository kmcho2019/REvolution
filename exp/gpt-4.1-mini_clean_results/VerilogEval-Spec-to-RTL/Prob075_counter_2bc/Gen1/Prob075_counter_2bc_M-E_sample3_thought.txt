Use a two-bit counter updated synchronously on clk, with an asynchronous positive-edge reset using a separate reset signal registered on its rising edge. To implement the saturating counter, calculate the next state combinationally: if train_valid is high, add 1 if train_taken is high (max at 3), subtract 1 if train_taken is low (min at 0); else hold the current state. The asynchronous reset sets the counter immediately to 2'b01. This approach cleanly separates reset logic and counter update logic and uses the ternary operator to keep the combinational logic compact.
