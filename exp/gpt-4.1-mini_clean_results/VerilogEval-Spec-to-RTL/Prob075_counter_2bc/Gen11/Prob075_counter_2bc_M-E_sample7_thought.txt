Implement the two-bit saturating counter as an arithmetic counter with explicit saturation logic rather than FSM states. On each clock edge (with asynchronous reset), if train_valid is asserted, increment the counter if train_taken is 1 (capped at 3), or decrement if train_taken is 0 (floored at 0). If train_valid is 0, keep the current counter value. Use asynchronous positive edge reset to set the counter to the weakly not-taken state (2'b01). This approach leverages arithmetic operations combined with saturation conditions, which can simplify the logic and potentially reduce combinational path complexity.
