Implement the 2-bit saturating counter using arithmetic operations with min/max saturation, rather than explicit state enumeration. On each clock edge, if train_valid is asserted, increment the counter by 1 if train_taken is 1, or decrement by 1 if train_taken is 0, saturating at 3 and 0 respectively. This allows concise logic using addition and subtraction combined with boundary checks. The asynchronous positive-edge reset sets the counter to 2'b01 (weakly not-taken). This approach uses simple arithmetic and comparisons, and the output is directly driven by the counter register.
