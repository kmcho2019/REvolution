Implement the saturating counter using arithmetic operations with saturation logic instead of a case statement. On each clock edge (or asynchronous reset), compute the next state by incrementing or decrementing the current state based on train_valid and train_taken, saturating the result within 0 and 3. Use an enable signal to update the state only when train_valid is asserted, minimizing toggling when the state does not change. This approach simplifies combinational logic and reduces switching activity by only updating state when necessary.
