Implement the saturating counter using a numeric 2-bit register with arithmetic increment/decrement controlled by train_valid and train_taken signals. Use separate combinational logic to calculate the next counter value with saturation at boundaries (0 and 3). Implement the asynchronous positive edge reset by using a flip-flop with asynchronous reset directly on the register. The output state directly reflects the register value. This arithmetic approach uses simple addition and subtraction with saturation, providing a clean, compact, and intuitive design without explicit state enumeration.
