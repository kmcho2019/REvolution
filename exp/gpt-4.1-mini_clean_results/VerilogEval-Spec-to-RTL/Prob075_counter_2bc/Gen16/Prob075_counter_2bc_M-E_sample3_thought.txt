Use a simple arithmetic saturating counter approach with an explicit increment and decrement logic instead of case statements. Implement the saturating logic in a purely arithmetic manner: increment when train_valid & train_taken; decrement when train_valid & ~train_taken. The counter is 2 bits wide, saturating between 0 and 3. Use asynchronous positive edge reset to set state to 2'b01. To save power and avoid unnecessary toggling, only update the state when train_valid is high and the computed next state differs from the current state. This reduces state register toggling. This design is minimal in logic, easy to understand, and synthesizes efficiently without explicit FSM state encodings.
