Implement the saturating counter using a small finite state machine (FSM) with four explicit states representing each counter value (0 to 3). Transition between states occurs on the clock edge when train_valid is asserted: move to the next higher state if train_taken=1 and not already at 3, move to the next lower state if train_taken=0 and not at 0, else stay in the same state. Use an asynchronous reset to set the state to 2'b01. This FSM-based approach emphasizes clarity and state transitions explicitly rather than arithmetic operations, which can simplify debugging and formal verification.
