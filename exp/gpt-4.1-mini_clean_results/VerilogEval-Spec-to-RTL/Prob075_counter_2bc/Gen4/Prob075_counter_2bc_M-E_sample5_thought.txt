Implement the 2-bit saturating counter by first calculating the next state using arithmetic operations with saturation logic before the clocked block. Use a combinational expression to clamp the increment or decrement result between 0 and 3. Then update the registered state synchronously with the clock and asynchronously reset the state to 2'b01. This approach uses a single always block triggered on clk and areset, with a simple arithmetic-based next state calculation outside the sequential block, improving clarity and possibly timing by eliminating the case statement and reducing combinational logic levels.
