Refactor the saturating counter by separating the combinational next-state logic from the sequential state update logic. Calculate the next counter value in a combinational always block or with a continuous assignment, then update the counter state register on the clock's positive edge or asynchronous positive edge reset. This improves code clarity by isolating state transition logic and helps synthesis tools optimize increment/decrement and saturation conditions more effectively.
