Implement the saturating counter using a registered increment/decrement enable and a next state computed by saturating arithmetic in a separate combinational block. Use an enable signal to update the counter only when train_valid is asserted, and compute the next state by adding or subtracting one with saturation at 0 and 3. The asynchronous reset clears the state to 2'b01. This separation cleanly isolates combinational next state logic from sequential state update and enables simpler synthesis and potential clock gating optimizations.
