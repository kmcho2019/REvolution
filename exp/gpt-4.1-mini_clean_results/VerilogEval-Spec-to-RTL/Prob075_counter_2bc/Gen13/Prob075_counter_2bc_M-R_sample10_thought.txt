Refactor the two-bit saturating counter using an explicit next_state register updated in a combinational always block instead of combinational wires. This makes next_state calculation more visible and easier to extend for future states or modifications. The sequential always block will update state on clk/areset edges using the precomputed next_state. The update_enable logic is moved inside the sequential block as a conditional assignment, avoiding the extra wire comparator outside. This retains the same saturation and reset semantics, with asynchronous positive edge reset to 2'b01, but structures the design as a small Moore FSM style with explicit next_state logic. This enhances readability and separation of combinational and sequential logic without changing behavior or efficiency.
