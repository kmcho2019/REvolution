Implement a 2-bit saturating counter with asynchronous active-high reset (areset). On the positive edge of clk or areset, if areset is asserted, reset the counter to 2'b01 (weakly not-taken). Otherwise, if train_valid is asserted, increment the counter if train_taken is 1 (up to max 3), decrement if train_taken is 0 (down to min 0), else hold the value. Output the current counter value on state.
