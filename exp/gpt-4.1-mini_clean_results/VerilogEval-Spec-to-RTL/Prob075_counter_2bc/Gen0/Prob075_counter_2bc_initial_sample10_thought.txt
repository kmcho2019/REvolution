Implement a 2-bit saturating counter with asynchronous positive edge reset. On the positive edge of clk, if areset is asserted, reset the counter to 2'b01. Otherwise, if train_valid is high, increment the counter if train_taken is 1 (capped at 3) or decrement if train_taken is 0 (capped at 0). If train_valid is 0, hold the counter value. Output the current counter value on state.
