Implement the saturating counter as a one-hot encoded state machine with four flip-flops representing the counter values 0,1,2,3. On each training cycle (train_valid=1), move the one-hot '1' up or down in the vector depending on train_taken. On reset, set the state to represent 2'b01, which is the second state (index 1). This approach avoids explicit arithmetic and uses shift register style state encoding, making increment and decrement operations simple bit shifts with saturation at either end. Output the 2-bit counter value by decoding the one-hot state. This design is straightforward, easy to verify, and provides a novel state representation contrasting with the binary counter approach.
