Implement the saturating counter using a small state machine with explicit state encoding for the four counter values (0 to 3). The state machine transitions conditionally on train_valid and train_taken signals. On each clock edge (with asynchronous positive-edge reset), the state either increments, decrements, or stays the same, implemented by a 2-bit register. This approach uses a combinational next_state calculation via a simple always_comb block with a case-like structure done through if-else branches for clarity. The asynchronous reset initializes the state to 2'b01. This structure enhances readability and separates the combinational next state logic from sequential state update logic.
