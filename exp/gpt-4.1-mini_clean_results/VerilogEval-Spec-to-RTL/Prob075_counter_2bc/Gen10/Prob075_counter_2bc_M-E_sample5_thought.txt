Implement the saturating counter using an explicit enable signal for state updates, derived from train_valid, to reduce unnecessary state toggling and potentially enable clock gating downstream. The counter update is performed inside a synchronous always block triggered on clk or asynchronous areset. The next state is calculated inside the sequential block using nonblocking assignments and a simple saturating increment/decrement logic to minimize combinational complexity. This approach avoids separate combinational logic and keeps all logic inside one always block, simplifying the design. The asynchronous reset forces the state to 2'b01 as required.
