Implement the 2-bit saturating counter as a small synchronous state machine with explicit next state encoding in a case statement to make the behavior very clear and easy to optimize. The asynchronous reset is implemented using a posedge-sensitive async reset. When train_valid=0, hold the current state. When train_valid=1, increment or decrement state with saturation at 0 and 3 by directly encoding next state for each case, avoiding arithmetic and comparisons. This explicit enumeration reduces combinational complexity and may improve synthesis friendliness and timing. The explicit state transitions also facilitate easy verification and debugging. The register updates the state at each clock edge or resets asynchronously.
