The original design effectively detects positive edges on each bit with a double register stage, which adds one cycle latency for pedge output but consumes power due to registers updating every cycle regardless of input changes. To optimize power, we can reduce toggling in the output register by only updating pedge when an edge is detected (non-zero edge_detect), effectively gating the pedge register clock enable with the edge_detect signal. Similarly, for prev_in, while harder to gate clock due to sequential dependency, we can replace it with an enable-based update only when input changes, reducing unnecessary toggling.

This approach reduces dynamic power by minimizing switching on pedge and prev_in registers when input or edges don't change, with negligible impact on timing or area. The latency remains one cycle from edge occurrence to pedge high. Overall, we trade minor extra logic for clock enables (which synthesis tools map to gated clocks or mux-based enables) for better power efficiency without degrading performance or area significantly.
