Instead of storing the entire previous input vector and comparing it to the current input, this design uses a shift-register style approach where the previous input is pipelined through a single register stage. The positive edge detection is performed by detecting bits that are '0' in the stored previous input and '1' in the current input, similar to a rising edge detection. However, to reduce logic at the output stage and keep the output stable for one cycle after detection, the design registers the detection result and outputs it synchronized to the clock. This approach emphasizes minimal combinational logic and leverages synchronous pipelining to produce the delayed edge detect signal, thereby ensuring the output pedge is the registered result of the edge detection from the previous cycle. It is a simple, clean alternative architecture that still meets the requirement that pedge updates one cycle after a 0-to-1 transition.
