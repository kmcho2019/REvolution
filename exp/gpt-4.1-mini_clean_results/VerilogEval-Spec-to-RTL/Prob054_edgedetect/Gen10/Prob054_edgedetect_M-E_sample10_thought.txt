Implement a parallel positive edge detection by storing the previous input in a register and computing `pedge` as a separate combinational output signal based on current and previous inputs. This approach uses a combination of a registered previous input and a continuous assign statement to generate the output signal combinationally, avoiding sequential logic on the output register. 

Key points:
- Use a synchronous process to register the previous input.
- Use a continuous assignment to detect rising edges for each bit by comparing previous and current inputs.
- The output `pedge` will reflect the positive edge detection immediately (combinationally) after the clock updates the `prev_in` register on the next cycle.
- This design decouples storage of the input history from edge detection logic, potentially making timing more straightforward in some flows.
- `pedge` output changes combinationally within a clock cycle after `prev_in` updates, so `pedge` is stable and valid one cycle after the input transition.

This design meets the requirement: `pedge` is asserted exactly one clock cycle after a 0-to-1 input transition on each bit, with clear separation of state and logic.
