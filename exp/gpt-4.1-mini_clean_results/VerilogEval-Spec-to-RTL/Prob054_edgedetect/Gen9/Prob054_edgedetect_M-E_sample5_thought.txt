An alternative approach is to use a combinational edge detection followed by a one-cycle pulse register. Instead of directly registering the detected edges from previous inputs, we can compute the edge combinationally from current input and a registered previous input, then register the detected edge into `pedge` to produce a one-cycle pulse.

This approach:
- Separates the edge detection logic (combinational) from the output pulse register.
- Uses two registers: one for `prev_in` to hold previous inputs, and one for `pedge` to hold the pulse output.
- The combinational logic detects which bits have transitioned from 0 to 1 by comparing current `in` and `prev_in`.
- On every clock edge, update `prev_in` and update `pedge` with the combinationally detected edge, ensuring the pulse output happens exactly one cycle after the transition.
- The output `pedge` is synchronous and cleanly timed, with no glitches.
- This style clarifies the edge detection and output pulse generation stages separately.

This modular separation may help in debugging, adding more complex edge detection logic later, or timing analysis since the edge detection is purely combinational and outputs a stable signal that registers into `pedge`.
