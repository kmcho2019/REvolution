Implement the edge detection by storing the previous input in a register, but instead of a single always block, separate the state update and output logic into two always blocks. The first always block samples the input and stores it in a register `prev_in`. The second always block derives `pedge` from the current `in` and `prev_in` at each clock edge. This separation can improve timing and clarity by isolating data storage and combinational logic evaluation.

`pedge` is assigned with a non-blocking assignment in the second always block synchronously, so the output is registered and valid one clock cycle after a 0-to-1 transition.

This modular structure can aid synthesis tools in optimization and aid debugging. The edge detection logic remains the bitwise comparison of `~prev_in & in`, but the separation enhances design flexibility.

Overall:
- Two always blocks: one for capturing input, one for computing edge
- Registers for both previous input and output
- Simple logic in the output block
- `pedge` is a registered output, valid one cycle after edge
