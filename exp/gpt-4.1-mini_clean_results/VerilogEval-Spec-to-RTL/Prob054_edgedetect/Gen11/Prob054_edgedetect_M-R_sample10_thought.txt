Refactor the design by explicitly registering the previous input first and then using a separate always block to register the output edge signal based on the registered previous input. This two-step sequential process clearly separates the sampling of inputs and generation of output pulses, avoiding combinational logic in between. It retains the same functional behavior, i.e., pedge is set one cycle after a 0-to-1 transition, but by splitting into two sequential always blocks the design is easier to follow for some verification flows and synthesis tools.
