A simpler approach is to store only the previous cycle's input in an 8-bit register and then compare it with the current input. A positive edge on any bit occurs when the previous input bit was 0 and the current input bit is 1. This reduces storage from 2 bits per input bit to 1 bit, halving the register count and simplifying the logic. The output pedge can be generated combinationally as (previous_in == 0 & current_in == 1), which directly detects the rising edge with minimal hardware.
