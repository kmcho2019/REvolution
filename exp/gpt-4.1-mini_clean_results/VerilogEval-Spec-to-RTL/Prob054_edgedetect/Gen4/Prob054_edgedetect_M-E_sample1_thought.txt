Instead of storing the entire previous input vector, we can use a shift register approach where the input is delayed by one clock cycle, and the positive edge detection is done by comparing the delayed input and current input outside the always block using continuous assignment. The delayed input is stored in a register updated every clock. The pedge output is then registered synchronously by another register to provide the output one cycle after the edge is detected. This splits the design into two stages: delay input register and edge detect + output register. This pipelined style clarifies data flow, avoids combinational logic inside the always block beyond register updating, and provides clear stage separation which can be beneficial for timing and debugging.
