Instead of using a register to store the previous input, I will implement a two-stage shift register pipeline for the input signals. At each clock cycle, the first stage captures the current input, and the second stage captures the previous input. Then, I will compare the two pipeline stages: a positive edge is detected when the second stage is 0 and the first stage is 1. The pedge output will be registered and updated every cycle, producing a pulse one cycle after the 0-to-1 transition. This approach separates the previous input storage into a dedicated pipeline and demonstrates an alternative architectural style.
