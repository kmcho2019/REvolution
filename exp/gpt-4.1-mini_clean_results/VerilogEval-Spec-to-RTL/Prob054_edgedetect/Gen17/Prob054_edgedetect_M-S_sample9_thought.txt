Simplify the design by storing only the previous input vector (8 bits) in a single register instead of 2-bit shift registers per bit. On each clock edge, update this previous vector and generate the pedge output combinationally as the bitwise AND of the inverted previous input and current input, i.e., pedge = ~prev_in & in. This effectively detects 0-to-1 transitions and outputs the detection one cycle after the transition, as required. This approach uses fewer registers (8 vs 16 flip-flops) and simpler logic while preserving functionality.
