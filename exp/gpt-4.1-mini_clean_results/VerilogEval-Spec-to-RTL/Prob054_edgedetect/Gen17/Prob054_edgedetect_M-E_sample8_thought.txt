Instead of tracking each bit with a 2-bit shift register, use a single register to store the previous 8-bit input vector. On each clock cycle, compare the current input vector with the stored previous input. For each bit, a positive edge occurs if the previous bit was 0 and the current bit is 1. According to the requirement, the pedge output should be set one cycle *after* the 0-to-1 transition, so register the pedge result to output it delayed by one cycle.

This approach uses only two 8-bit registers: one to hold the previous input and one to hold the delayed pedge output. It is simple, area-efficient, and clearly separates the edge detection and output delay stages, which aids timing closure and simplifies logic. The output pedge is registered, reducing glitching and ensuring synchronous output timing.
