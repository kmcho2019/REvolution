Implement a single 8-bit register to store the previous input sample. On each clock edge, update this register with the current input value. The positive edge detection output pedge is generated by checking where the previous input bit was 0 and the current input bit is 1. Since the output pedge must be set the cycle after the transition, we simply output the detected edges using the stored previous input and current input on each cycle. This approach uses only one register instead of two, saving area, and simplifies the design while maintaining the required one-cycle latency.
