To simplify the design while maintaining functionality, store only the previous input vector (8 bits) in a single register instead of using an array of 2-bit shift registers. At every clock cycle, compare the previous input and the current input vectors bitwise to detect a 0-to-1 transition. The pedge output is asserted when the previous bit was 0 and the current bit is 1, with the output registered at each clock cycle. This reduces register usage by half and simplifies the logic, making the design more area and power efficient.
