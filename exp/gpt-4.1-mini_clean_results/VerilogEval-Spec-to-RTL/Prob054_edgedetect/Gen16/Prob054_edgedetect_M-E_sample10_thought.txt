Use a single 8-bit register to hold the previous input sample. At every clock edge, compare the current input with the stored previous input to detect a 0-to-1 transition bit-wise. This comparison is done by ANDing the complement of the previous input bits with the current input bits. Since the output pedge should be delayed by one cycle after the transition is detected, store the detected transition bits in a register and output them in the next clock cycle.

This approach uses minimal storage (only one 8-bit register for previous input and one 8-bit register for delayed pedge output) and simple bitwise operations. It improves area by reducing storage, and registering pedge output breaks combinational paths, which benefits timing. The design is straightforward and easily scalable.
