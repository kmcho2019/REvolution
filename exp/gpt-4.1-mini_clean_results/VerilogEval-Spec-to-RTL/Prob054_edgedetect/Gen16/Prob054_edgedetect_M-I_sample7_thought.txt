To improve PPA, reduce register usage by storing only the previous input vector (1 bit per bit) instead of a 2-bit shift register per bit. This halves flip-flop count and reduces area and power. Detect positive edges by comparing current input and previous stored input: pedge = (~prev_in) & in.

To improve timing, register the pedge output, breaking long combinational paths and easing timing closure.

Use consistent non-blocking assignments in sequential logic. Keep the design fully synchronous.

This approach simplifies logic, reduces area and power, and can improve timing (wns).

Summary:
- Use one 8-bit register to hold previous input.
- Compute pedge combinationally, then register pedge on clk.
- Output pedge registered, stable one cycle after the edge detection.
