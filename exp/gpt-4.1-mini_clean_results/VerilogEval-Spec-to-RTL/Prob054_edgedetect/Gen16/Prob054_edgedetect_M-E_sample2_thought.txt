Instead of using registers to store both current and previous inputs, use a single register to hold the previous input only. On each clock edge, compare the current input to the stored previous input inside a sequential block, and update the output pedge within the same clock cycle using non-blocking assignments. This makes pedge registered, reflecting the detected positive edge on the next cycle after transition without requiring explicit combinational logic. This approach provides clean synchronization of the output and can simplify timing by generating a registered output signal directly from sequential logic.
