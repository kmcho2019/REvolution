Refactor the design by splitting the edge detection combinational logic and the output registering into two stages explicitly. Instead of computing pedge inside the always block using prev_in and current input directly, compute the edge detection combinationally using an assign statement for an intermediate wire that detects the positive edges. Then register this intermediate signal to generate the pedge output. This approach clarifies the pipeline: first detect edges combinationally, then register the detection to produce pedge output in the next clock cycle. The previous input storage remains in a register updated each cycle.
