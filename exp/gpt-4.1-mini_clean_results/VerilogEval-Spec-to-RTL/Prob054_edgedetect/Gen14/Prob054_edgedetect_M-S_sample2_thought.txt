Store the previous input vector in a register and directly register the positive edge detection (0->1) in one always block. This combines the two stages into a single clocked block, reducing code and pipeline stages while maintaining correct functionality. The output pedge will still be asserted one cycle after the input transitions from 0 to 1 on any bit. This reduces complexity and register usage slightly at the cost of slightly longer combinational path, which should be acceptable for small 8-bit width.
