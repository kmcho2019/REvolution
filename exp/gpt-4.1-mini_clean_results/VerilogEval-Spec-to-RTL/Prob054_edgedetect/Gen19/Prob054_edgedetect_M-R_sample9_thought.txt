Refactor the design by using a single register to hold the previous input state and using an always block to update this register on each clock edge. The positive edge detection is then done combinationally by comparing the current input with this previous state within a continuous assignment. This approach reduces register usage by removing the separate current_in register and relies on the previous input stored synchronously. The output pedge is asserted one cycle after the 0-to-1 transition by design.
