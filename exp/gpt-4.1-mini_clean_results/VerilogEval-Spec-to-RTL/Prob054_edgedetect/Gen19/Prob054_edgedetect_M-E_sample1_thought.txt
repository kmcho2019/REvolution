Instead of storing the previous input sample, use a one-hot edge detection approach by registering a delayed version of each bit of the input and then comparing it with the current input. Specifically, use a shift register that delays the input by one clock cycle. The positive edge detection output `pedge` will be generated when the delayed input bit was 0 and the current input bit is 1. This achieves the desired one-cycle latency and simplifies edge detection logic by focusing on the transition between the delayed and current input. This design emphasizes explicit data delay and comparison for clarity and modularity.
