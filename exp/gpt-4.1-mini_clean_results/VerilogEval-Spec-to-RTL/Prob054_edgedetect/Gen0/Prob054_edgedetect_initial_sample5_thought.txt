To detect a 0 to 1 transition on each bit of the input vector, I will first register the input vector to keep the previous value. Then, on each clock edge, I will compare the previous and current input bits. If the previous bit was 0 and the current bit is 1, it means a positive edge occurred for that bit. Since the output should be set the cycle after this transition, I will register this detection and output it in the next clock cycle.
