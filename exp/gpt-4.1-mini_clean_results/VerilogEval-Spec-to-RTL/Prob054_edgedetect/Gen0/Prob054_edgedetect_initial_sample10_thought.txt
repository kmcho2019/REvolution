To detect a rising edge for each bit of the 8-bit input vector 'in', we need to store the previous value of 'in' at each clock cycle. Then, the output 'pedge' for each bit will be set high if the previous value was 0 and the current value is 1. Since the output should be set the cycle after the transition, we will register the detection and output it in the next clock cycle. This means we'll have two registers: one to hold the previous input, and one to hold the detected rising edges delayed by one cycle.
