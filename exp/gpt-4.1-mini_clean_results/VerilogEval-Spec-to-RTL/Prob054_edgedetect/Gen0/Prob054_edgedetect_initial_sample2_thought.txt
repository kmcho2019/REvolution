To detect a positive edge (0 to 1 transition) for each bit of the 8-bit input vector, we need to store the previous cycle's input. On each clock, compare the previous input to the current input: if previous bit was 0 and current bit is 1, we mark that as a positive edge detected for that bit. Since the output pedge should be set the cycle after the 0 to 1 transition occurs, we can register this detection to output in the next cycle. Therefore, we'll use two registers: one to store previous input and one to store pedge output. On every clock edge, we update previous input with the current input, and set pedge output with whether there was a positive edge on previous cycle.
