To detect a 0 to 1 transition on each bit of the 8-bit input vector, we need to store the previous value of the input bits. On each clock cycle, we compare the current input bits with the stored previous bits. A positive edge (0 to 1 transition) on a bit happens if the previous bit was 0 and the current bit is 1. We generate a pedge output that is set one cycle after the transition is detected, which means pedge is assigned the detected edges of the previous cycle. To implement this, we use a register to store the previous input and another register to store the detected edges, which is output in the next cycle.
