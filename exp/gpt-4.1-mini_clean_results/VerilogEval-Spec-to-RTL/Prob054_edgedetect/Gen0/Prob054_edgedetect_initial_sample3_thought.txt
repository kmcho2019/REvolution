To detect a 0-to-1 transition (positive edge) on each bit of an 8-bit input vector, we can store the previous input value in a register on every clock cycle. By comparing the stored previous value to the current input, we identify where the bit changed from 0 to 1. The output 'pedge' bits are set to 1 one cycle after this transition is detected, so we register the detected edges again before output.
