Instead of storing the previous input vector and comparing it directly with the current input, use a two-stage shift register per bit that delays the input signal by one clock cycle twice. The first stage captures the current input, the second stage captures the input from the previous clock cycle. Comparing these two delayed values allows detection of a 0-to-1 transition on the previous cycle. The output pedge is generated from these two delayed signals, thus inherently producing the delayed output one cycle after the transition. This approach pipelines the detection and makes the positive edge output logic explicit through two registers.
