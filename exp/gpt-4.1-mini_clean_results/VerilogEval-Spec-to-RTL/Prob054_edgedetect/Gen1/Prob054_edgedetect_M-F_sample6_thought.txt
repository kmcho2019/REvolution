To ensure that the output pedge is set exactly one cycle after a 0-to-1 transition on any bit of the input vector, we need to properly pipeline the detection logic. The key is to keep prev_in registered from the previous cycle, then perform the detection combinationally by comparing the current input with prev_in. The detection result is then registered in pedge on the current clock edge. This approach ensures pedge is asserted one cycle after the transition. We avoid registering the detection in a separate register inside the always block to prevent extra delay.
