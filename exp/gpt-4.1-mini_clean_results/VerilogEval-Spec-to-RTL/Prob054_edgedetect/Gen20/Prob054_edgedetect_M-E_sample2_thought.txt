Instead of using a delayed register and combinational logic to detect edges, implement a two-stage pipeline with two registers capturing the input at consecutive clock cycles. Then, detect the positive edge by comparing the two registered inputs: if the earlier cycle was 0 and the next cycle is 1 for each bit. Output `pedge` is set in the cycle after the positive edge detection, i.e., on the third cycle for the respective transition. This approach breaks down the edge detection into explicit sequential storage stages, highlighting temporal difference between samples and producing the output from the second difference register. This can be useful for timing clarity or easier formal verification.
