An alternative approach is to implement the edge detection using a shift register style per bit: we maintain a 2-bit history for each input bit over two clock cycles, stored in a register vector. On each clock, we shift in the current input bit; then, we check if the two-bit history changed from '01' (previous cycle 0, current cycle 1). If so, output the pedge as 1 for that bit in the following cycle. This approach gives a conceptual time window explicitly, and the 2-bit register history can be useful for extensions like multi-cycle edge detection or glitch filtering.
