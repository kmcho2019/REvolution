Use a simple register to store the previous input vector (8 bits) on each clock. Then, compare the previous and current inputs bit-wise to detect 0-to-1 transitions. The pedge output will be the bit-wise result of (~prev_in) & in, but output delayed by one clock cycle. This delay can be implemented by registering the edge detection output so that pedge is asserted exactly one cycle after the actual 0-to-1 transition. This approach uses minimal state (only one register holding previous input), simple combinational logic, and a register stage to delay the edge output, improving timing and reducing combinational path length.
