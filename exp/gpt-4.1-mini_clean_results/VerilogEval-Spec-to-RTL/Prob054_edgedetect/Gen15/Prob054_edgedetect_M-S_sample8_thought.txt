Use a single always block to simplify the design by combining previous input capture and edge detection within one clock cycle.  
- Store the previous input in a register.  
- On each clock edge, detect the 0->1 transitions by comparing current input with previous input.  
- Assign the pedge output the detected edges immediately in the same clock cycle (pedge is registered), satisfying the requirement to output the pulse one cycle after the transition.  
This reduces the design from two always blocks plus a combinational wire to a single always block with minimal logic, maintaining clear functionality and minimal area while simplifying the code.
