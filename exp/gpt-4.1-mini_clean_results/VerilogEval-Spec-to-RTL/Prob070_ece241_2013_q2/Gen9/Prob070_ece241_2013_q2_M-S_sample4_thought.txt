Since only three numbers (2, 7, 15) produce logic 1, and the rest produce 0, and the numbers 3,8,11,12 never occur, we can directly implement minimal sum-of-products and product-of-sums expressions derived from these minterms.

Define the inputs as a 4-bit vector {a,b,c,d} with a as MSB and d as LSB.

Minimal SOP expression for out_sop is the OR of the minterms for decimal 2 (0010), 7 (0111), and 15 (1111):

  - minterm for 2 (a=0,b=0,c=1,d=0): a' b' c d'
  - minterm for 7 (a=0,b=1,c=1,d=1): a' b c d
  - minterm for 15 (a=1,b=1,c=1,d=1): a b c d

So,

  out_sop = a' b' c d' + a' b c d + a b c d

Minimal POS expression for out_pos is the AND of sums that exclude these minterms, leading to:

  out_pos = (a + b + c + d') (a + b' + c' + d) (a' + b + c + d)

This code implements these minimal expressions straightforwardly.

This implementation ensures correct minimal SOP and POS outputs as specified.
