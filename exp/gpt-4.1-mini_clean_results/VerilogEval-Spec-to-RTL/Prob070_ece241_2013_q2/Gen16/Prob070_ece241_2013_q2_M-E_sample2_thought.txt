To meet the requirement for minimal sum-of-products (SOP) and product-of-sums (POS) forms, we first analyze the function with inputs as a 4-bit vector (a,b,c,d), where 'a' is MSB and 'd' LSB.

- The output is 1 for decimal inputs 2 (0010), 7 (0111), and 15 (1111).
- It is 0 for 0,1,4,5,6,9,10,13,14.
- Inputs 3,8,11,12 never occur and can be treated as don't-cares.

By Karnaugh map analysis considering these don't-cares, the minimal SOP and POS expressions can be derived:

**Minimal SOP:**
out_sop = a c d + a b d + a' b c' d

which corresponds to:
- a c d (covers 15)
- a b d (covers 7)
- a' b c' d (covers 2)

**Minimal POS:**
out_pos = (a + b + d') (a + b' + c + d) (a' + b + c' + d)

This covers all zeros and don't-cares in minimal product of sums form.

The implementation will be purely combinational, directly using these expressions for out_sop and out_pos without equality checks or enumerations.

This satisfies minimal logic form and covers all required cases.
