First, understand the decimal values corresponding to the 4-bit inputs (a,b,c,d) where a is MSB and d is LSB.

Decimal value = 8*a + 4*b + 2*c + d

The outputs are 1 when input equals 2, 7, or 15:
- 2 = 0010 (a=0,b=0,c=1,d=0)
- 7 = 0111 (a=0,b=1,c=1,d=1)
- 15= 1111 (a=1,b=1,c=1,d=1)

Outputs are 0 when input is 0,1,4,5,6,9,10,13,14.

Inputs 3,8,11,12 never occur.

We'll derive minimal sum-of-products (SOP) and product-of-sums (POS) expressions for the output being 1 at these inputs.

Step 1: Write minterms for output=1 (2,7,15):

m2: a=0,b=0,c=1,d=0 => a'b'cd'
m7: a=0,b=1,c=1,d=1 => a'b c d
m15: a=1,b=1,c=1,d=1 => a b c d

Step 2: Minimize SOP:

Group m7 and m15: b c d (since a differs)
m2 remains separate.

SOP minimal: out_sop = b c d + a' b' c d'

Step 3: Write maxterms for output=0 (0,1,4,5,6,9,10,13,14):

maxterms correspond to input combinations where output=0:

0: 0000 => a+b+c+d
1: 0001 => a+b+c+d'
4: 0100 => a+b'+c+d
5: 0101 => a+b'+c+d'
6: 0110 => a+b'+c'+d
9: 1001 => a'+b+c+d'
10: 1010 => a'+b+c'+d
13: 1101 => a'+b'+c+d'
14: 1110 => a'+b'+c'+d

Step 4: Minimize POS:

From grouping, minimal POS is (a + b + d) (a' + c + d')

So final expressions:

out_sop = b c d + a' b' c d'

out_pos = (a + b + d)(a' + c + d')
