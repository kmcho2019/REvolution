Implement the 4-bit shift register and down counter using a single 4-bit register that stores the current value. When shift_ena is high, shift left by one bit and load the input data into the MSB. When count_ena is high, decrement the register by 1 using arithmetic subtraction. To avoid prioritization conflicts when both enables are active, give priority to shift_ena and do not decrement during shift. This choice is valid since behavior when both are high is unspecified. Use a combinational next value logic to separate next state calculation from register update.
