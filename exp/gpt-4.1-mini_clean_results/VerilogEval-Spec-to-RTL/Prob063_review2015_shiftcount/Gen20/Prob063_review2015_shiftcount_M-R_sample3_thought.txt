Refactor the design by separating the combinational next-state logic from the sequential update logic. Compute the shifted value and the decremented value as separate wires using continuous assignments. Then, use a single clocked always block to update the register `q` based on the enable signals. This improves readability and modularity, allowing easier debugging and potential further optimizations. For the decrement operation, use the built-in subtraction operator (`- 1`) for clarity and synthesis friendliness, since the explicit ripple borrow logic is now handled outside the always block. The shifting remains MSB-first with data shifted into the LSB. The don't-care case of both enables asserted is still not prioritized.
