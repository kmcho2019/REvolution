To fix this, we maintain a 4-bit register `q` that on `shift_ena` shifts in the serial `data` at the MSB, shifting the existing bits to the right by one (q[3:1] <- q[2:0], q[3] <= data).

On `count_ena`, instead of decrementing the bits literally, interpret `q` as a 4-bit binary number and subtract 1 from it, which can be done using normal arithmetic `q <= q - 1`.

Because we only do one operation per clock cycle (either shift or count), and never both, this works fine.
