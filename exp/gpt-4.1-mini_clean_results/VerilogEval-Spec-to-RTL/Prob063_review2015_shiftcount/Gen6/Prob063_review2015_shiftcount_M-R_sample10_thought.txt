Implement combinational logic that calculates the next value of the shift register `q` based on the control inputs.

- If `shift_ena` is asserted, shift left by one bit and insert `data` at the least significant bit.
- Else if `count_ena` is asserted, decrement the current value.
- Else hold the current value.

Then register this next value on the positive clock edge.

This approach keeps the sequential block simple, possibly improving synthesis tool optimization opportunities and separating combinational and sequential logic cleanly.
