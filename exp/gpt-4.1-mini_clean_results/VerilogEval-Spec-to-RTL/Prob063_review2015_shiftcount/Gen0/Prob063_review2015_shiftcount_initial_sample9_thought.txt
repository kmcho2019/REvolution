Implement a 4-bit register that updates on the positive clock edge. When shift_ena is high, shift the register left by one bit, shifting in the input data at the MSB. When count_ena is high (and shift_ena is low), decrement the 4-bit register value by one. If both are high, behavior does not matter, so priority can be given arbitrarily (here, shift_ena has priority). Output the current value of the register on q.
