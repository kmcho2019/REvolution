Implement the 4-bit register directly with synchronous updates on the clock edge. When shift_ena is high, shift in the data bit at the MSB and shift existing bits toward LSB. When count_ena is high, decrement the register value by one (with natural wrap-around). If neither control is active, hold the current value. Since both enable signals will not be active simultaneously, priority handling is not needed. This keeps the code simple with only one always block and no separate next-state variable.
