Implement the shift register and down counter using two separate always blocks for clarity and potential easier optimization by synthesis tools. Use a register to hold the current value and on each clock edge, update it either by shifting in the MSB when shift_ena is high or by decrementing when count_ena is high. If neither enable is asserted, hold the value. Because both shift_ena and count_ena are never asserted simultaneously, the two always blocks will never compete to update q, but to avoid latches or multiple drivers, update q only in one always block that reacts to a combined control signal. Internally, use a mux to select next value based on the control signals for a clean separation of logic. This design separates combinational calculation of next value and the sequential register update, which can improve readability and optimization.
