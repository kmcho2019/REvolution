I will implement the 4-bit register using a shift and decrement operation inside a single always block triggered on the rising clock edge. Instead of separate combinational next-state logic, the logic will be directly embedded in the sequential block using if-else conditions to decide whether to shift or decrement. For shifting MSB-first, I will shift the register left by one bit and input the data into LSB (since the MSB is shifted out). For decrementing, I will implement a subtract-by-one using a ripple borrow subtraction done explicitly using bitwise operations, avoiding the subtraction operator. This saves area by reducing the use of generic arithmetic operators. No explicit reset logic will be used; the register will initialize to 0 by Verilog simulation default. This approach keeps the logic compact with minimal combinational gates and straightforward control, facilitating direct hardware synthesis and easier debugging.
