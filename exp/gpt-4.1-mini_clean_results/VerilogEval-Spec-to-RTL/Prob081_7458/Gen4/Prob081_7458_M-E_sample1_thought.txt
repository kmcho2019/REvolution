Instead of using intermediate wires for the AND gates, implement the two output functions directly using nested ternary (conditional) operators in continuous assign statements. This approach combines the AND-OR logic into a compact expression for each output, which can reduce code verbosity and possibly improve readability for some. It also mimics the structure of a multi-input multiplexer, selecting the output based on input combinations. This style can be preferred when signals are simple and when prioritizing conciseness.
