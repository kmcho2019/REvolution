Refactor the design by separating the combinational shift logic from the sequential register update. Create a combinational function that computes the shifted value based on the current value of q, the amount, and shift direction. Then, in the clocked always block, update the register q with the shifted value when enabled or load data when load is high. This approach improves clarity by clearly separating combinational shift logic and sequential state update, making the code easier to read and potentially easier for synthesis tools to optimize. The shift function uses a single combinational block with a case statement, avoiding repetitive concatenations in different always blocks.
