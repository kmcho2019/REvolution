Implement the 64-bit arithmetic shift register with synchronous load and enable using a single always block. On each clock edge, if load is asserted, load the input data; else if enable is asserted, perform the shift specified by amount in one step without breaking the shift into two stages. Use a simple case statement to cover all four shift cases, doing left shifts by 1 or 8 bits, and arithmetic right shifts by 1 or 8 bits with sign extension. This approach simplifies the design by avoiding separate combinational stages and directly updating the register, keeping the code clear and minimizing combinational complexity while preserving functionality.
