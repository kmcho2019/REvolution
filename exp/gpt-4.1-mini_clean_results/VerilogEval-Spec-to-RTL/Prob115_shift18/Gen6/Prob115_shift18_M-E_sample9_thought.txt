Implement the arithmetic shift register with a single combinational barrel shifter that handles all four shift modes (left 1, left 8, right 1, right 8) in one stage. This reduces the combinational logic depth and simplifies timing by avoiding staged shifts. The barrel shifter uses multiplexers to select between no shift, left shifts, and arithmetic right shifts by dynamically replicating sign bits for right shifts. On each clock edge, if load is asserted, load data directly; else if ena is asserted, update q with the shifted result. This approach is straightforward, efficient, and minimizes the critical path by using a single combinational shift operation and avoids multi-stage shifting.
