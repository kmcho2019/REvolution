Refactor the design by moving the shift and load operations into combinational logic assigned to an intermediate wire, then update the output register synchronously with a single always block.

This structure cleanly separates combinational shift/load logic from the sequential register update, improving readability and modularity.

Key steps:
- Use a combinational block or continuous assignment to compute the next value of the shift register.
- Use an always block triggered by clk to update q with the computed next value.
- When load is high, next value is data.
- When ena is high and load is low, next value is shifted data.
- Otherwise, next value is the current register value to hold state.
- Shift operations are same as before: left shifts fill with 0, right shifts replicate sign bit.
- The control signals (amount) are used similarly to choose shift direction and amount.

This style separates the combinational and sequential parts, which can improve synthesis clarity and make it easier to insert or modify logic between stages in future.
