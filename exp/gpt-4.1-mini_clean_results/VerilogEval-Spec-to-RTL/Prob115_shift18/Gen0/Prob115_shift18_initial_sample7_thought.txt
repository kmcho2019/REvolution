Implement a 64-bit register that can synchronously load input data or shift its current content based on the control signals. On each rising clock edge: 
- If load is high, load the input data into the register.
- Else if ena is high, shift the register contents left or right by 1 or 8 bits as specified by amount.
For left shifts, shift in zeros from the right. 
For right shifts, perform an arithmetic shift right (shift right with sign extension), replicating the MSB for the shifted-in bits. 
Output q always reflects the current contents of the register.
