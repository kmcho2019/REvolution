Refactor the shift register by separating the next-state combinational logic from the register update. Use an intermediate wire `next_q` computed with combinational assignments based on load, enable, and shift control signals. This avoids mixing data path logic inside the clocked always block. 

- Use a combinational always_comb (or always @*) block to compute the shifted value based on `q`.
- Load data has highest priority; if load is active, `next_q` is `data`.
- If enable is active without load, `next_q` is the shifted value selected by direction and amount.
- If neither load nor enable is active, hold the current value.
- Register `q` updates on the rising edge of `clk` with `next_q`.
- This structure improves readability by explicitly separating combinational and sequential logic.
- It also can help synthesis tools with clarity on state vs combinational logic.

The shift operation remains the same two-stage approach:
- Stage 1 shifts by 0 or 8 bits.
- Stage 2 shifts by 0 or 1 bit.
- Arithmetic right shift sign-extends properly.
