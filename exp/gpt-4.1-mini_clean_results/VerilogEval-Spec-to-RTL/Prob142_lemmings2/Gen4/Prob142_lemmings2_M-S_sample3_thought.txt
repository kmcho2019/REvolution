Use a 3-state FSM to track the Lemming's state: WALK_LEFT, WALK_RIGHT, and FALLING. Store the walking direction in the state for walking states. On async reset, start at WALK_LEFT. 

On each clock edge:
- Update delayed ground to detect edges.
- If falling and ground comes back (rising edge or ground=1), resume walking in stored direction.
- If walking and ground lost (falling edge or ground=0), enter FALLING state.
- If walking and bumped (either side), flip walking direction immediately.
- Ignore bumps while falling.

All outputs are derived directly from current state (Moore).

This keeps next state logic and state update in one always block to avoid mismatches, and removes extra walking_dir register by encoding direction in states. Edge detection is done via one delayed ground register. This reduces complexity and preserves exact required behavior.
