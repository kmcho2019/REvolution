Represent the FSM state with a 2-bit register encoding four states combining direction and falling status: 00=walk_left, 01=walk_right, 10=fall_left, 11=fall_right. Update state synchronously on the clock with asynchronous reset to walk_left (00). Direction flips only when walking and bumped (either bump_left or bump_right). When ground=0, transition to falling state preserving direction. When ground=1 and falling, return to walking state keeping direction. Outputs are derived directly from state bits, which simplifies logic and uses a single register for state.
