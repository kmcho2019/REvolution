Refactor the FSM by separating the state bits into two distinct registers: a falling flag and a direction flag, each as one-bit registers. Use a single always block for sequential logic with asynchronous reset, but implement the next-state logic as separate combinational assignments for falling and direction. This separates concerns, clarifies the effect of bumps and ground on each bit, and simplifies state updates.

Key points:
- falling is set/reset based on ground signal only; no effect from bumps.
- direction changes only when not falling and on bump inputs.
- If bumped on left or right (or both) while walking, direction flips accordingly.
- Use continuous assignments for outputs directly from registers.
- Maintain Moore outputs derived directly from state bits.
This approach eliminates the packed state vector and uses separate signals, making each control signal explicit and easy to track.

The functional behavior remains identical, but modularizes the logic by state bits rather than encoded 2-bit state vectors.
