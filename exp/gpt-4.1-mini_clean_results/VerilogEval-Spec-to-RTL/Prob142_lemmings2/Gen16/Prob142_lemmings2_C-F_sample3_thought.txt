- Implement asynchronous active-high reset initializing to WALK_LEFT.
- Separate the state update into two steps inside a single always block for simpler logic and improved critical path:
  - Update falling first based on ground transitions (falling when ground=0, not falling when ground=1).
  - Update direction only when walking (not falling) and bumped.
- Combine bump direction updates with minimal logic, flipping direction if both bumps or setting direction accordingly if one bump.
- Retain Moore outputs directly from state bits.
