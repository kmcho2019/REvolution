- Asynchronously reset direction to walk left and falling to 0.
- On each clock edge, first update falling based solely on ground: 
  - If currently falling and ground returns, stop falling.
  - If currently not falling and ground disappears, start falling.
- Update direction only if not falling. 
  - If bumped on left, direction becomes right.
  - If bumped on right, direction becomes left.
  - If both bumps simultaneously, direction flips.
- Ignore bumps during falling or during the cycle when ground changes.
- Outputs directly reflect the current falling and direction registers.
- This separation creates cleaner, minimal combinational logic and registers, reducing critical path and making the design easier for synthesis to optimize.
- Using separate reg signals for falling and direction aligns well with low toggle rates, and is intuitive and maintainable.
- This approach keeps FSM Moore-style outputs and asynchronous reset behavior consistent with requirements.
