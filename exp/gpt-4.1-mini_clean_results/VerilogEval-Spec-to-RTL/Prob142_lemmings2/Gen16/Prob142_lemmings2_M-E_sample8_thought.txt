Implement the FSM using an enumerated type for states representing walking left, walking right, and falling states in each direction. This cleanly separates direction and falling state as distinct states instead of encoding them in bits. The FSM will asynchronously reset to walking left. On bumps while walking, it switches directions; on losing ground, it transitions to falling in the same direction; on regaining ground, it resumes walking in the previous direction. The outputs derive directly from the current state, making it a Moore machine. This approach improves readability and state clarity by explicitly naming each state instead of packing information into bits.
