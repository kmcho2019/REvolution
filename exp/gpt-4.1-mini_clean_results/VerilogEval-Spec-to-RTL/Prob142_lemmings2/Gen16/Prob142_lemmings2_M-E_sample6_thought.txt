Implement the FSM using three one-hot style state signals for clarity: walk_left, walk_right, and falling. 

- Use explicit states encoded as separate flip-flops rather than bit-fields; this improves readability and avoids bitwise operations.
- On reset, initialize to walk_left.
- While walking, if bumped left, transition to walk_right; if bumped right, transition to walk_left; if bumped both sides, toggle direction.
- If ground is lost, enter falling state, storing current direction in a separate direction register.
- While falling, ignore bump inputs; once ground returns, resume walking in the stored direction.
- Outputs correspond directly to these state signals (Moore machine).
- Use synchronous reset for direction and falling, but asynchronous reset for initial conditions, preserving the asynchronous reset requirement for the overall FSM.
- This approach separates direction logic from falling logic, emphasizing modularity and making it easier to extend or modify behavior.
- Non-blocking assignments used for sequential logic; combinational logic uses always @(*) blocks.
