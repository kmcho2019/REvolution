Fuse the structured and explicit 2-bit combined state encoding (falling + direction) and clear case-based next state logic from Example 1 with the simplicity and minimalism of Example 2's sequential-only logic style. 

Use a single 2-bit state register with asynchronous reset. Compute next_state combinationally with a concise case statement, handling all transitions cleanly:
- When walking, bumps flip direction as specified.
- When falling, bumps ignored.
- ground controls transition between falling and walking.
- On ground disappearance, falling state set, direction preserved.
- On ground reappearance, return to walking in previous direction.
- Bumps in the same cycle as ground transitions do not affect direction.

Use a Moore FSM with outputs decoded from state bits directly.

This fusion brings:
- Clear FSM semantics aiding synthesis and timing.
- Minimal combinational logic to reduce critical path.
- Single always block for sequential logic with async reset.
- Readable code combining explicit state encoding and concise logic.

Thus, the solution balances readability, correctness, and PPA improvements beyond the previous examples.
