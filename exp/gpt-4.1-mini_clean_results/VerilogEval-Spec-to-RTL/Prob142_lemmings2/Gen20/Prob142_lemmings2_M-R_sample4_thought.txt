Refactor the original 2-bit Moore FSM by explicitly encoding the state bits as separate registers (falling and direction) rather than a combined 2-bit state vector. This clarifies the logic and uses two separate D flip-flops, each updated by simple combinational logic derived from inputs and current state.

- Use two registers: falling and direction.
- The falling register updates asynchronously on areset and synchronously on clk.
- The direction register updates only when not falling and on bumps.
- The next value of falling depends only on ground and current falling.
- The next value of direction depends on bump signals only if not falling and ground present.
- Outputs are combinationally decoded from these two registers.

This style uses separate registers instead of a vector and simple conditional logic assignments, improving clarity by explicitly showing how falling and direction signals update. It also matches Moore FSM behavior by separating state bits and output decoding.

No asynchronous resets on direction register (only areset sets both to initial state), ensuring proper initialization. This structure also fits well with synthesis tools and allows simple combinational assignments for next state values without a single combined vector always block.
