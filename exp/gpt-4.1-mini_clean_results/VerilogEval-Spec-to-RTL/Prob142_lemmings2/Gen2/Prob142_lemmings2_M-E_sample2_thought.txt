Implement a three-state Moore FSM: WALK_LEFT, WALK_RIGHT, and FALLING. The states encode both direction and walking/falling status explicitly:
- WALK_LEFT: walking left
- WALK_RIGHT: walking right
- FALLING: falling (keep direction info internally)

Store direction separately as a reg that only updates on transitions from WALK_LEFT or WALK_RIGHT states, ignoring bumps during falling.

FSM transitions:
- From WALK_LEFT:
  - If ground=0, transition to FALLING (store direction=left)
  - If bumped (left or right), go to WALK_RIGHT
- From WALK_RIGHT:
  - If ground=0, transition to FALLING (store direction=right)
  - If bumped (left or right), go to WALK_LEFT
- From FALLING:
  - If ground=1, return to WALK_LEFT or WALK_RIGHT based on stored direction
  - Else remain in FALLING, ignoring bumps

This approach cleanly encodes direction in the state and direction variable, and strictly ignores bumps during falling. Also, bumps concurrent with ground transitions don't affect direction because ground changes take precedence.

Outputs:
- walk_left = 1 if state == WALK_LEFT
- walk_right = 1 if state == WALK_RIGHT
- aaah = 1 if state == FALLING

Async reset places FSM into WALK_LEFT state.
