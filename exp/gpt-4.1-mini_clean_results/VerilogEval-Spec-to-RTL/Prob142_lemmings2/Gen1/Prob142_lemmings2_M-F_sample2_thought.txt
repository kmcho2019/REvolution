The main problem is that bumps occurring on the same cycle that ground falls (from 1 to 0) or rises (from 0 to 1) should be ignored for direction switching. The original code switches direction immediately if bumped and ground is still high, but the problem states bumps simultaneous with ground disappearing or reappearing should not change direction.

To fix this, add edge detection on the ground signal to identify transitions: falling edge (ground=1→0) and rising edge (ground=0→1). On these transition cycles, ignore bump inputs for direction switching.

The updated FSM logic:

- If ground=0 (falling or already falling), transition to FALLING, ignoring bumps.
- If ground=1 and currently FALLING, transition to the previously saved walking direction, ignoring bumps.
- Only when ground=1 and no ground edge transition occurs (steady ground), handle bumps to switch direction.

Implement ground_edge detection by registering ground and comparing current and previous ground in a separate register. This allows ignoring bumps exactly when ground changes state.
