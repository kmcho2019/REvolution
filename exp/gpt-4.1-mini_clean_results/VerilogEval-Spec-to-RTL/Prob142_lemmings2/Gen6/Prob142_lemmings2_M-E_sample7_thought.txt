Use a three-state FSM encoded as a 2-bit state variable to explicitly represent all Lemming conditions: WALK_LEFT, WALK_RIGHT, and FALLING. The FALLING state remembers the last walking direction internally using an additional register `last_direction`.

- States:
  - 2'b00: WALK_LEFT
  - 2'b01: WALK_RIGHT
  - 2'b10: FALLING (with direction stored in last_direction)
- On reset, state = WALK_LEFT.
- Transitions:
  - From WALK_LEFT or WALK_RIGHT:
    - If ground == 0, transition to FALLING state, save current walking direction in last_direction.
    - Else if bumped, change walking direction accordingly:
      * bump_left: walk right
      * bump_right: walk left
      * both bumps: flip direction
    - Else remain in the same walking state.
  - From FALLING:
    - If ground == 1, transition back to walking state indicated by last_direction.
    - Else remain FALLING.
    - Bumps ignored in FALLING state.
- Outputs:
  - aaah = 1 if in FALLING state
  - walk_left = 1 if in WALK_LEFT state
  - walk_right = 1 if in WALK_RIGHT state

This explicit enumeration of states allows easy state decoding and scalable FSM extension, keeps the walking direction tightly coupled to states, and isolates the falling behavior cleanly. This design meets Moore FSM and asynchronous reset requirements.
