Refactor the FSM by explicitly defining a two-bit state encoding with four states: WALK_LEFT, WALK_RIGHT, FALL_LEFT, FALL_RIGHT. The least significant bit encodes direction (0=left,1=right), the MSB encodes falling (1=falling,0=walking). The FSM transitions synchronously on clk with asynchronous reset, but now next_state is computed combinationally using a separate always block. Bump inputs only affect direction in walking states, not in falling states. When falling, the state waits until ground returns to resume walking in previous direction. Outputs are generated by state decoding combinationally, making it a Moore machine with explicit state registers. This approach clearly separates next-state logic and output logic and encodes direction and falling in one state reg, preserving the original behavior but with a classic FSM style.
