Simplify the FSM by encoding only the walking direction in a single bit, and track falling as a separate bit register. Use two state bits: one for direction (0=left, 1=right) and one for falling (0=walking, 1=falling). On each clock cycle (with async reset), update falling state based on ground, and update direction only when walking and bumped on either side. This reduces state handling complexity and next-state logic while keeping outputs as Moore outputs depending only on these two bits.
