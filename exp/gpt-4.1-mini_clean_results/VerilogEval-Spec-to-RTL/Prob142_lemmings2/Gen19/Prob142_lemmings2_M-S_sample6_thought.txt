Simplify the FSM by using a single bit to represent direction (0 = left, 1 = right) and a separate falling bit as an internal signal instead of a full 2-bit state. Use a single register for direction and a falling flag. On bumps (while walking and grounded), flip or set the direction accordingly. On ground loss or regain, update the falling flag. Outputs are directly derived from these signals. This reduces state complexity and uses straightforward combinational logic with minimal registers while preserving the same behavior.
