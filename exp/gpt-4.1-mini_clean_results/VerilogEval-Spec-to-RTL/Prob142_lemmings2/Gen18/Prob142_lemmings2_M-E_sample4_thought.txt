Implement a Moore FSM using one-hot encoding with three explicit states to represent walking left, walking right, and falling (which includes both directions internally). This approach uses separate states for walking left and right, and a single falling state that stores direction in a register for resuming after falling.

Key points:
- Use 3 one-hot states: WALK_LEFT, WALK_RIGHT, FALL.
- When walking left or right, bump_left or bump_right flips direction accordingly.
- If ground drops to 0, transition to FALL state, saving direction in a separate register.
- While falling, bumps do not affect direction.
- When ground returns to 1, transition back to walking state stored in direction register.
- Asynchronous active-high reset sets FSM to WALK_LEFT and direction=0.
- Outputs are Moore style: walk_left and walk_right reflect walking states; aaah indicates falling state.
- This separates state (walking/falling) and direction info clearly, and uses simple combinational next-state logic with one-hot encoding for clarity and quick state decoding.
