Implement the function f by treating the inputs as a 3-bit vector and using a combinational always block with a case statement. This method defines f by directly matching the input patterns where f=1 from the truth table, making the code easy to extend and visually clear.

The inputs x3, x2, x1 are concatenated into a 3-bit vector {x3,x2,x1}, and f is assigned within the case statement according to the truth table entries that produce 1. For all other inputs, f is 0 by default.
