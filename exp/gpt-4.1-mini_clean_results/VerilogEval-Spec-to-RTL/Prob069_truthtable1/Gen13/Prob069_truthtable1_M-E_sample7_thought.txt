A novel architectural approach is to implement the truth table using a small ROM-like behavior with a combinational lookup table indexed by the 3-bit input formed from {x3, x2, x1}.

We treat the inputs as a 3-bit vector and encode the output function as a constant 8-bit vector (truth table stored as a parameter).

We then use the input vector as the index to select the corresponding output bit from the stored vector.

This method mimics a small LUT, which is a common hardware technique.

The design uses:
- a wire vector [2:0] for concatenated inputs,
- a localparam with the 8-bit truth table,
- and a continuous assignment to select the bit.

This approach is different from gate-level or logic equations: it is table-driven and highly scalable for larger truth tables.

It also shows a concise combinational design style without decomposing into gates or explicit logical expressions.

This solution may introduce a slight increase in hardware if the synthesis tool maps it to a multiplexer tree or memory-based LUT, but it provides a clean and clear approach for arbitrary functions.
