Implement the FSM using one-hot state encoding to simplify next-state and output logic. This encoding uses four flip-flops, each representing one state, which often results in faster combinational paths and easier synthesis of asynchronous reset. Use an asynchronous reset to set the FSM to state A (one-hot encoded as 4'b0001). The next state logic is implemented as combinational logic that determines the next state flip-flop activation based on the current state and input. Output is derived from the active state flip-flop D. This approach trades area for potentially improved speed and power due to reduced combinational logic complexity.
