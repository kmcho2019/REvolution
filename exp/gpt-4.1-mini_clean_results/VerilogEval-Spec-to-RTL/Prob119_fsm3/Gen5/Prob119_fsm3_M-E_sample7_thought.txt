Implement the FSM using a one-hot encoding scheme for the states to potentially simplify and speed up next-state decoding logic. Use a single always block triggered on the positive edge of clk and asynchronous reset for both state updates and output register update. The output is registered (instead of purely combinational) to reflect Moore behavior, updating on each clock cycle based on the current state. Next state logic is implemented as combinational logic within the always block using case statements based on the one-hot encoded state and input. This approach trades minimal area overhead for clarity and possible timing improvements due to simpler decoding.
