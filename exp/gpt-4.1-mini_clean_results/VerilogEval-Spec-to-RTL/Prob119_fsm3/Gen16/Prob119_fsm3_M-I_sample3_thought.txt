To improve PPA (timing, power, area), I will use one-hot state encoding to simplify next-state logic and potentially reduce switching activity and glitching in combinational logic. One-hot encoding maps each state to a single bit, making state decoding and next-state logic simpler and faster in FPGA or ASIC implementations. This can improve timing and reduce glitches, lowering dynamic power.

I will keep the asynchronous reset as requested. The output logic is simplified directly from the one-hot encoded state bits. Next-state logic is implemented with straightforward combinational expressions rather than case statements, to further simplify logic and reduce area.

Overall, this approach trades a slightly wider state register (4 bits instead of 2) for simpler combinational logic that can run faster, use less power from glitches, and have smaller area in some technologies due to simpler decoding logic.
