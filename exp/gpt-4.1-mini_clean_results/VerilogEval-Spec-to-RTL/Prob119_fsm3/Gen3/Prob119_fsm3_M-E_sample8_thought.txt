Implement the FSM using one-hot encoding for the states to simplify next state logic and potentially improve timing for small state machines. Use four flip-flops (one per state), each representing one state. The asynchronous reset sets the FSM to state A (i.e., state A flip-flop is set to 1, others cleared). The output is assigned combinationally based on the current state (only high in state D). The next state logic is implemented using combinational always block deriving next state signals from current state signals and input. On clock edge, the FSM state registers are updated accordingly.
