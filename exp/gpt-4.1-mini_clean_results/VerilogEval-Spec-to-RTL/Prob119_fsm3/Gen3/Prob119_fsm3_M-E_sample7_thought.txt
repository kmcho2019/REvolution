Implement the four-state Moore FSM using a one-hot encoding scheme, where each state is represented by a single bit in a 4-bit register. This eliminates the need for encoding/decoding logic and can simplify the next state logic as it becomes a set of boolean equations rather than a case statement. Use combinational logic to calculate the next state bits directly from the current state bits and the input. Implement the asynchronous active-high reset by forcing state A bit high and others low on reset. The output is derived solely from the state D bit. This architecture may increase register count but can improve timing and clarity for small state machines.
