Implement the Moore FSM using one-hot state encoding instead of binary encoding. This means each state is represented by a separate flip-flop. This can reduce combinational logic complexity at the cost of more flip-flops. Use asynchronous active-high reset to initialize the FSM to state A by setting only state_A flip-flop high. Next-state logic is implemented using combinational logic directly driving the next state signals. The Moore output is generated combinationally based on the current active state. This approach can improve timing by simplifying next-state decoding and making state registers easier to map in some FPGAs.
