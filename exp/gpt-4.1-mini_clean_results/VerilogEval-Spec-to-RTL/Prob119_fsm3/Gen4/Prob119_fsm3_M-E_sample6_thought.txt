Implement the FSM using one-hot encoding with four separate flip-flops, each representing one state. The asynchronous reset will clear all state bits except the A state bit, ensuring the FSM starts in state A. The next state logic is encoded as combinational logic that sets the appropriate state flip-flop next. The output is derived purely combinationally from the current state bit for D. This approach may increase area compared to binary encoding but can reduce combinational logic depth and simplify state decoding.
