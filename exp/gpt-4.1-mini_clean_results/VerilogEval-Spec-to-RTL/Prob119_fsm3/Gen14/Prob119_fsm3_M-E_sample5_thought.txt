Implement the FSM using a separate synchronous process for state updates triggered by the clock and asynchronous reset, and a purely combinational next-state and output logic block. Encode states as 2-bit localparams but use a single always_comb block for next state and output, then register the next state in a separate always block. This separation keeps logic clean and modular, improves readability, and reflects typical FSM coding style. The output remains Moore style, only dependent on the current state.
