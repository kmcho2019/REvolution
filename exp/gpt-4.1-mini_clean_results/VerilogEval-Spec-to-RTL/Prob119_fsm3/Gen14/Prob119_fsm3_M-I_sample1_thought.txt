To improve PPA, I will implement the FSM with one-hot encoding to potentially reduce the state decoding logic complexity, which can improve timing and reduce power by reducing glitches on state transitions. One-hot encoding uses four flip-flops for the four states, activating exactly one flip-flop per state. The asynchronous reset will clear all bits except state A. The output depends only on state D, which is a single flip-flop, so the output logic is straightforward. This change trades a slight area increase for better timing and power efficiency due to simpler combinational next state logic and less switching activity on unused bits.
