Implement the FSM using one-hot state encoding for the four states, with separate flip-flops for each state bit. Use combinational logic to determine the next state signals based on the current state and input. The output is derived by directly checking the active state bit for state D. Asynchronous reset clears all state bits except the bit for state A. This approach simplifies state decoding and can improve performance in some synthesis tools by reducing state decoding logic.
