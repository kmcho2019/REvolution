Use one-hot state encoding with four 1-bit flip-flops representing each state (A, B, C, D). The asynchronous reset sets the A flip-flop. On each clock edge, the FSM updates the next state flip-flops based on input 'in' and current one-hot encoded state. Output is assigned combinationally from state D flip-flop. This architecture simplifies next state logic by directly mapping state bits without binary encoding.
