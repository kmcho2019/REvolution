Implement the Moore FSM using one-hot encoding for states to simplify decoding logic and potentially improve speed on FPGA architectures. Use a separate always block for the state register with asynchronous reset. The next state logic is encoded with combinational logic that directly sets one-hot bits based on input and current state. The output is derived directly from the active state bit for state D. This approach uses a one-hot style to reduce combinational complexity and allows clearer state decoding.
