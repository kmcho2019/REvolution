To improve PPA, separate the output logic from the next state logic to enable better timing optimization and cleaner synthesis. Use non-blocking assignments in the combinational blocks where appropriate to avoid simulation-synthesis mismatches, although in purely combinational blocks blocking is acceptable, here separating output into a dedicated always block and making output registered (Moore FSM) ensures clean timing. Also, keep asynchronous reset in state register for correct reset behavior. By explicitly registering output based on state, we reduce combinational path length and help timing. The FSM encoding remains binary for minimal area. This approach balances timing, power, and area improvements.
