Refactor the FSM by combining the next state and output logic into a single combinational always block that computes both simultaneously, and drive the output using a continuous assignment from the registered state. This reduces the number of always blocks and uses the Moore output property that depends only on the current state to generate the output via assign statement, simplifying the design. The asynchronous reset and state register remain unchanged with the posedge-triggered always block. This structure makes the output combinational logic minimal and clearer by deriving output directly from state encoding.
