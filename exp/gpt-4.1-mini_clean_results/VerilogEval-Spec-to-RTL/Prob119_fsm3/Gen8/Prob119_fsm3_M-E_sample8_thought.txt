Implement the FSM using one-hot state encoding for potentially improved synthesis results on certain FPGA architectures. Use a single always block triggered on the positive edge of clk and asynchronous reset to update the one-hot encoded state register. The next-state logic and output logic are combined inside this sequential block using if-else constructs based on current state and input, avoiding separate combinational blocks. This approach reduces combinational logic by embedding next state transitions directly into the sequential process and uses simple assignments for the output based on the one-hot state signals, adhering to Moore machine behavior.
