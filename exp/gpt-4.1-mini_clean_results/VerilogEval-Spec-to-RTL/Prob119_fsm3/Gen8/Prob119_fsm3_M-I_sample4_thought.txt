To improve PPA, we target slightly better timing and power by using one-hot state encoding to reduce combinational logic complexity and fanout in next-state logic. One-hot typically improves timing as each state is a single flip-flop and next state decoding is simpler, trading minimal area increase (4 FFs for 4 states vs 2 bits binary).

We maintain the asynchronous reset, preserving functionality, and keep the Moore output style.

Output logic is simplified to directly check the D state flip-flop.

The one-hot encoding simplifies next-state logic to combinational gates with fewer transitions.

This approach typically yields faster clocks (better WNS/TNS), slightly higher area, and possibly better power due to reduced glitching in next state logic.

We will:
- Use 4 flip-flops, one per state (A,B,C,D)
- Encode states as 4 bits with exactly one hot bit set
- Implement next state logic with minimal combinational logic from input and current state bits
- Maintain asynchronous reset to set state to A (A=4'b0001)
- Moore output = D state bit
