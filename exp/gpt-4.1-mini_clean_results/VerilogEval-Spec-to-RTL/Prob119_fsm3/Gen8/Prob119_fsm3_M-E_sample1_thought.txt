Implement the FSM using an enumerated type (SystemVerilog enum) for state encoding to improve readability and safety. Use a synchronous reset instead of asynchronous reset by synchronizing the async reset signal with the clock to prevent metastability issues. Separate next state and output logic into an always_comb block with a case statement for clear combinational logic and explicit non-blocking assignments inside the sequential always block for state update. Output is registered to reduce glitches and aligns with Moore FSM style. This approach enhances clarity, reliability, and clean separation of combinational and sequential logic.
