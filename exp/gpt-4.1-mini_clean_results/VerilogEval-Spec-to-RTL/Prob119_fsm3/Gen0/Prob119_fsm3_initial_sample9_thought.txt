Implement a Moore FSM with four states (A, B, C, D) encoded as 2-bit state variables. Use a sequential always block triggered on the posedge of clk and asynchronous posedge areset to update the current state. On reset, state is set to A. The next state logic is combinational and depends on the current state and input 'in'. The output is combinational, depends only on the current state as per Moore machine. Output is 1 only in state D, else 0.
