Implement the FSM using one-hot state encoding, which assigns a separate flip-flop for each state, simplifying next state and output logic by using direct signals rather than encoded values. Use a single always block for both asynchronous reset and state update triggered on the posedge of clk or areset. Use combinational logic expressed via assign statements to calculate next states for each flip-flop based on the current state and input. The output signal is derived directly from the state D flip-flop. This approach trades a slightly larger area for simpler and potentially faster logic paths and very clear state representation.
