Implement the FSM using one-hot state encoding for clarity and ease of debugging, despite the area overhead for only four states. Use a single always block triggered on the positive edge of the clock and asynchronous reset, combining next state and state register update for compactness. The output is registered and updated in the same always block to preserve Moore behavior. This structure simplifies timing and keeps all sequential logic in one place, potentially easing timing closure. The asynchronous reset immediately forces the machine to state A with output zero. Using one-hot states can improve state decoding speed and facilitate easier state identification in debugging tools.
