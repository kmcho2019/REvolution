Refactor the FSM by implementing the next state and output logic using combinational functions instead of always blocks. The state register remains a posedge-triggered asynchronous reset flip-flop. This approach cleanly separates the combinational logic (next_state and output functions) from the sequential state register, promoting readability and functional decomposition. This style also simplifies simulation and formal verification by using pure functions for combinational logic.
