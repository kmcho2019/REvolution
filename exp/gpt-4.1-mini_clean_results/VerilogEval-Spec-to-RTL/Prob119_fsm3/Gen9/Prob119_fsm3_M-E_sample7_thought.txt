Implement the FSM using one-hot encoding with four flip-flops, each representing a state. The asynchronous reset directly clears all state bits except the bit representing state A, which is set. Next state logic is computed combinationally using a case statement based on current state and input. Output is also a combinational wire derived from the one-hot encoded state signals. This one-hot approach simplifies decoding logic and output assignment, provides potentially better timing at the cost of slightly more flip-flops, and distinctly separates state bits for clarity.
