Implement the FSM using a one-hot state encoding for the four states, each represented by a single flip-flop. Use asynchronous reset to clear all states except state A, which will be set on reset. Compute next state signals combinationally using combinational logic for one-hot transitions. Output is derived directly from the state D flip-flop. This approach can improve timing by simplifying next-state logic and makes state decoding very straightforward.
