Implement the Moore FSM with a single always block that handles both next state and state transitions, using a one-hot encoding scheme to reduce combinational logic complexity and potentially improve timing. Use asynchronous reset directly on the state flip-flops. The output is registered inside the FSM block to maintain Moore behavior explicitly rather than via a combinational assignment, enhancing clarity on output timing.
