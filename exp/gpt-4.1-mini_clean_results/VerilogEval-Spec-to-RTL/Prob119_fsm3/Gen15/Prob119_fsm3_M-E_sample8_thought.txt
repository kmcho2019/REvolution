Implement the FSM using one-hot encoding for states, which can improve performance by simplifying next state decoding and reducing combinational logic depth. Use a single always_ff block triggered on the positive edge of the clock and asynchronously reset using the asynchronous reset signal. Compute next states using combinational assignments with separate signals for each state bit to keep logic clear. The output is generated purely from the current state (Moore machine), specifically asserted when in state D.
