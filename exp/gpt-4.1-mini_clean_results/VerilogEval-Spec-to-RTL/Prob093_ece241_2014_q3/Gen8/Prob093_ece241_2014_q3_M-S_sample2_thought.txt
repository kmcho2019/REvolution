We must implement TopModule with inputs c, d and outputs mux_in[3:0], where mux_in corresponds to the four columns of the given K-map indexed by ab = 00, 01, 11, 10.

Each mux_in bit is a function of c and d only, no other logic gates allowed, only 2-to-1 multiplexers can be used inside TopModule to generate these functions.

From the K-map columns:

- For ab=00 (mux_in[0]): Values for cd = 00,01,11,10 are: 0,1,1,1.
  This corresponds to the function: mux_in[0] = d + c d' = d + c & ~d
  This simplifies to mux_in[0] = d | (c & ~d)
  We can implement this using mux2 with sel=d:
    mux_in[0] = d ? 1 : c

- For ab=01 (mux_in[1]): All zeros → assign 0 directly.

- For ab=11 (mux_in[2]): Values 0,0,1,0 at cd = 00,01,11,10.
  This is c & d.

- For ab=10 (mux_in[3]): Values 1,0,1,1 at cd = 00,01,11,10.
  This corresponds to c + d' (c OR NOT d):
    Implement d' by mux2(sel=d, in0=1, in1=0)
    Then mux_in[3] = mux2(sel=d, in0=c, in1=1), which is c + d'

Thus the functions are:

mux_in[0] = mux2(sel=d, in0=c, in1=1'b1)
mux_in[1] = 1'b0
mux_in[2] = mux2(sel=c, in0=1'b0, in1=d)
mux_in[3] = mux2(sel=d, in0=c, in1=1'b1)

This uses minimal mux2 instances, no extra gates, meets K-map exactly.

We implement only the required inputs c, d and outputs mux_in[3:0].
