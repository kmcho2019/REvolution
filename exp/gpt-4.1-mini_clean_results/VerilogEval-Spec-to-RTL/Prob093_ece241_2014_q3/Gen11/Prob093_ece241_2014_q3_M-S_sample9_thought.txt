Implement the module TopModule with inputs c and d, and outputs mux_in[3:0] representing the four inputs to the 4-to-1 mux selected by {a,b}. The module does not have a and b inputs because they are only selectors outside this module.

For each fixed ab value (0 to 3), mux_in[ab] equals the function output of the K-map for inputs c and d.

We use only 2-to-1 multiplexers and one 4-to-1 multiplexer as per problem constraints.

Because only 2-to-1 multiplexers and one 4-to-1 multiplexer are allowed, no other logic gates like NOT are allowed, so inversion (~d) must be replaced by a 2-to-1 mux.

We implement all mux_in bits as hierarchical 2-to-1 muxes controlled by c and d.

To keep it simple:

- For each mux_in[i], implement the function as a two-level mux tree using c and d as selectors.

- No direct logic operations; inversion replaced by mux logic.

- The mux_in outputs correspond exactly to the K-map columns (for ab=00,01,11,10).

This approach keeps the design fully compliant, simple, and uses minimal 2-to-1 muxes.
