The key to solving this problem is strictly using only multiplexers—modeled here as 2-to-1 muxes implemented with ternary operators—and no logic gates such as negation (~). Each mux_in[i] corresponds to a column (ab = 00, 01, 11, 10) of the Karnaugh map indexed by c and d.

Step 1: Extract each column vector from the Karnaugh map:

ab=00 (mux_in[0]): cd=00:0, 01:1, 11:1, 10:1
ab=01 (mux_in[1]): 0,0,0,0
ab=11 (mux_in[2]): 0,0,1,0
ab=10 (mux_in[3]): 1,0,1,1

Step 2: For each column, implement its 4-value function of c and d using a hierarchy of 2-to-1 muxes controlled by c and d, without any logic gates or inversion. Each 4-value function f(c,d) can be decomposed as:

f = c ? f_c1 : f_c0
where f_c1 and f_c0 depend on d:
f_cx = d ? val1 : val0

So, f = c ? (d ? a : b) : (d ? c : d)

Step 3: For each mux_in[i], write its value for c and d, then express as muxes:

- mux_in[0]:
  cd=00:0, 01:1, 11:1, 10:1
  For c=0 (cd=00 or 01): d=0->0, d=1->1
  For c=1 (cd=10 or 11): d=0->1, d=1->1
  So mux_in[0] = c ? 1'b1 : d

- mux_in[1]: always 0, directly assign 0

- mux_in[2]:
  cd=00:0, 01:0, 11:1, 10:0
  For c=0: d=0->0, d=1->0
  For c=1: d=0->0, d=1->1
  mux_in[2] = c ? d : 1'b0

- mux_in[3]:
  cd=00:1, 01:0, 11:1, 10:1
  For c=0: d=0->1, d=1->0
  For c=1: d=0->1, d=1->1
  So for c=0, output depends on d: d=0->1, d=1->0 => this is NOT d (but negation not allowed)
  We must implement this without negation:

  Since negation of d is not allowed, replace the 2-input mux controlling d with a mux that selects between 1 and 0, controlled by d:

  For c=0: mux_in[3] = (d == 0) ? 1 : 0 = d ? 0 : 1

  For c=1: always 1

  So mux_in[3] = c ? 1 : (d ? 0 : 1)

All mux_in bits expressed using only multiplexers (ternary operators) without negation or logic gates. This satisfies the constraints.

Note: Using d ? 0 : 1 is a mux selecting between constants 0 and 1 controlled by d, not a logic gate.

Final expressions:

mux_in[0] = c ? 1 : d

mux_in[1] = 0

mux_in[2] = c ? d : 0

mux_in[3] = c ? 1 : (d ? 0 : 1)

This matches the Karnaugh map precisely and respects the use of only multiplexers.
