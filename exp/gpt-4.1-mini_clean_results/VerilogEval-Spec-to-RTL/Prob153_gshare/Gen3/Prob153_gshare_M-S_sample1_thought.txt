Simplify the design by removing combinational read of train PHT entry and instead directly read it inside the clocked block to avoid simulator warnings. Initialize PHT and global history synchronously with reset, using a simple for-loop.

Use the following priority and update rules on each clock edge:

- On reset, clear global history and initialize PHT entries.

- On clock edge:
  - If training is valid:
    - Read current PHT entry for the train index.
    - Update PHT entry with saturating counter update using actual taken.
    - If mispredicted, restore global history to the training history (highest priority).
    - Else if no mispredict and prediction valid, update global history with predicted taken.
    - Else keep global history unchanged.
  - Else if no training but prediction valid, update global history with predicted taken.
  - Else keep global history unchanged.

Make all outputs purely combinational based on the current PHT and global history registers.

This approach reduces combinational complexity, relies only on synchronous reads, and ensures training takes precedence for global history updates, matching spec requirements.
