Simplify the gshare predictor by eliminating speculative and committed global history registers and input registration. Instead, maintain a single global history register (ghr) updated only on the clock edge. On prediction, outputs use the current ghr and PHT entry combinationally, reflecting the predictor state before updates. On training, update the PHT and, if mispredicted, restore ghr to the given train_history. Priority is given to training updates on ghr. This keeps timing straightforward: prediction outputs reflect current state; updates happen at clock edge; no input registering or speculative history needed. Initialization sets all counters weakly not taken (01). This cleaner design reduces complexity, avoids subtle timing ordering issues, and still fully complies with the specification.
