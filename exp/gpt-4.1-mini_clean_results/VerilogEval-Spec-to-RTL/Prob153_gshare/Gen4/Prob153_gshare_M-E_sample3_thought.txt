Implement a dual-ported gshare branch predictor architecture using explicit combinational reads and registered synchronous writes, separating prediction and training logic for clarity.

Key ideas:
1. Maintain a 7-bit global history register (GHR) updated only on clock edges.
2. For prediction:
   - Compute index as predict_pc XOR GHR.
   - Combinationally read the 2-bit saturating counter from PHT at that index.
   - Predict taken if MSB of counter is 1.
   - Output the current GHR as predict_history.
3. On a positive clock edge:
   - If train_valid:
     * Update the saturating counter at index (train_pc XOR train_history) according to train_taken.
     * If train_mispredicted, restore GHR to train_history.
     * Else if no misprediction and predict_valid, update GHR by shifting left and inserting the predicted bit.
     * If neither training nor prediction valid, GHR remains unchanged.
   - Else if no training but predict_valid, update GHR by shifting left and inserting the predicted bit.
4. To handle simultaneous prediction and training, training update to GHR takes priority.
5. Implement PHT as a reg array; combinational read is done directly for prediction.
6. Implement synchronous write for PHT updates on clock edge.
7. Initialize PHT entries to weakly taken (2'b10) and GHR to zero asynchronously on areset.
This design explicitly separates combinational reads (for prediction) from synchronous writes (for training), updates global history carefully according to priority, and avoids ambiguity and timing glitches.
