- Compute prediction index and predicted counter combinationally from current GHR and predict_pc.
- Output predict_taken and predict_history as registered signals, capturing the current GHR and PHT state only when predict_valid is asserted.
- On clock edge:
  - First update the PHT if training valid, using train_pc and train_history.
  - Update GHR with priority:
    1. If train_valid & train_mispredicted, rollback GHR to train_history.
    2. Else if train_valid, update GHR to train_history.
    3. Else if predict_valid, update GHR speculatively with predicted taken bit.
    4. Otherwise hold GHR.
- Use an always_comb block to drive combinational outputs for prediction.
- Keep asynchronous reset for GHR and PHT.
- This structure clearly separates combinational and sequential logic, and ensures that prediction output reflects the branch history and PHT state before any update in the cycle, while updates happen at clock edge respecting the priority.
