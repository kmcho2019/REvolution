Implement a gshare predictor with a single global history register (GHR) and a 128-entry pattern history table (PHT) of 2-bit saturating counters.

For prediction:
- Index into PHT using XOR of predict_pc and current GHR.
- Output prediction bit and current GHR (before update).
- On next clock, update GHR speculatively by shifting in predicted bit if no training misprediction.

For training:
- Update PHT entry indexed by train_pc XOR train_history with the actual branch outcome.
- If misprediction, restore GHR to train_history (recover correct history).
- Else if training valid and no misprediction, update GHR by shifting in train_taken.
- Training GHR update has priority over prediction update.

Perform all updates on positive clock edge; asynchronous reset clears PHT and GHR.

Keep combinational logic for prediction outputs outside clocked block to simplify timing and avoid mixing combinational and sequential logic in the same always block. This reduces complexity and keeps functionality intact.
