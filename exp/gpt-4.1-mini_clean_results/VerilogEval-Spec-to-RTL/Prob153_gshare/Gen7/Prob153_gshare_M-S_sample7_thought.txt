Implement a straightforward single-cycle gshare predictor with synchronous PHT (128x2-bit saturating counters) and a single global history register (GHR) updated on each clock edge.

Key simplifications:
- Use one global history register (`ghr`) representing the speculative branch history used for prediction.
- On `predict_valid`, compute the PHT index by XORing the current `ghr` and `predict_pc`.
- Output the prediction and current `ghr` immediately (combinationally), without pipeline registers or delays.
- On the clock edge:
  - If `train_valid`, update the corresponding PHT entry using `train_pc` and `train_history`.
  - If the training indicates a misprediction, restore `ghr` to `train_history` (recover history).
  - Else if `predict_valid` (and no misprediction), update `ghr` by shifting in the predicted outcome.
- Training updates take precedence over prediction updates to `ghr`.
- Initialize all PHT counters to weakly taken for neutral start.

This approach has no pipeline delay, outputs reflect the current state, and updates are synchronous on the clock edge. It matches the functional requirements while being easier to understand and verify.
