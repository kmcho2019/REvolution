Simplify by separating combinational reads from sequential logic:

- Make combinational indices and PHT entry reads as wires outside the always block.
- Use a combinational prediction bit derived from the PHT entry for GHR update.
- On posedge clk or areset:
  - If reset: initialize GHR and PHT.
  - Else:
    - If training valid and mispredicted: recover GHR to train_history.
    - Else if training valid and not mispredicted: update PHT entry with train_taken.
    - Else if predict valid and no concurrent mispredicted training: update GHR by shifting in predicted bit based on current GHR.
    - Else keep GHR.
- For prediction outputs:
  - Capture predict_history_reg (the GHR value used for prediction) when predict_valid is asserted.
  - predict_taken is derived from PHT entry indexed by predict_pc XOR predict_history_reg.
- Initialize PHT entries to weakly not taken (2'b01).
- Avoid declaring wires inside always blocks and indexing memory in procedural blocks; instead, do PHT reads combinationally outside the always block.

This keeps the functionality and timing as specified, but with clearer, simpler code.
