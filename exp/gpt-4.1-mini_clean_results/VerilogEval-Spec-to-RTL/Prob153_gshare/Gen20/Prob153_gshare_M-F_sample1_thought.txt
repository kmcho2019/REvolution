To fix the speculative global history (ghr_spec) update and better align with the problem spec and timing requirements, I will:

1. Maintain two global histories:
   - `ghr_committed`: the committed history after training updates (represents the "true" global history).
   - `ghr_spec`: the speculative global history used to make predictions.

2. Update the PHT table synchronously on training, using the `train_index` and `train_taken`.

3. Handle `ghr_spec` updates carefully considering priority:
   - When training valid and mispredicted, recover `ghr_spec` to the provided `train_history`.
   - When training valid but no misprediction, update `ghr_committed` by shifting in `train_taken`, but **do NOT update** `ghr_spec` in this cycle (keep speculation unchanged).
   - When no training or after training is handled, if prediction valid and no training, update `ghr_spec` by shifting in the predicted bit (from the PHT at `predict_index`).
   - When both training (regardless of misprediction) and prediction happen in the same cycle, training update takes precedence; i.e., update `ghr_spec` only per training (recover or hold), ignoring prediction update.

4. Output `predict_taken` combinationally using PHT content indexed by XOR of `predict_pc` and `ghr_spec`.

5. Output `predict_history` as the current speculative history (`ghr_spec`), reflecting history used to produce the prediction.

6. Initialize PHT entries to weakly not taken (2'b01) for consistency.

7. On reset, clear both histories.

This scheme guarantees that speculative history correctly tracks predicted branches and is recovered on mispredictions, with priority given to training updates over speculative prediction updates in any cycle where both co-occur. This aligns with the problem's timing diagram and interface requirements.

Additionally, reading PHT entries combinationally from registers ensures predictions see current PHT state before training updates take effect (since training updates are synchronous).

The code will also carefully use non-blocking assignments for sequential logic and separate combinational logic for outputs.
