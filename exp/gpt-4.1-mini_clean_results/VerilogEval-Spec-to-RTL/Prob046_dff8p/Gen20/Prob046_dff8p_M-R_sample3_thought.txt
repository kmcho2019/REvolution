Refactoring idea:
- Instead of a single always block for all 8 bits, implement the flip-flops using an array of individual always blocks—one per bit—each handling one bit of the vector.
- This uses a generate loop to instantiate 8 similar always blocks for each flip-flop.
- Maintain the negative-edge clock triggering and synchronous reset behavior.
- This structure offers clear visibility of per-bit DFF behavior while still producing the same functionality.
- Use non-blocking assignments and parameterize reset value to keep code clean and reusable.
