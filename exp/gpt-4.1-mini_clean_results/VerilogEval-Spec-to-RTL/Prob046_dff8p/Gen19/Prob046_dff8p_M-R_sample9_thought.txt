Refactoring idea:
Instead of using an always block sensitive to the negative edge of clk, create a negative-edge clock signal by inverting clk internally and use a positive edge triggered always block on this inverted clock. This avoids using negedge clk directly and achieves the same functionality. Also implement synchronous reset within the always block as specified. This approach provides the same behavior but demonstrates an alternative style of handling negative edge triggering through an internally generated inverted clock signal.
