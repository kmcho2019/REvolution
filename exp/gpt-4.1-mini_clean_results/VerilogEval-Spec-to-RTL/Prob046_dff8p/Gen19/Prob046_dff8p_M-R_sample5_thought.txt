Refactor the design by removing the explicit clock enable signal and instead implement the synchronous reset and data load logic directly inside the negedge-triggered always block with a conditional ternary operator style assignment. This keeps the functionality but simplifies the control logic by integrating the reset and data load conditions into a single assignment, removing the need for an explicit ce signal.

To reduce toggling, the code won't use an explicit clock enable; however, this is a straightforward approach preferred for clarity and compactness.

This refactoring provides equivalent functionality with a simpler always block structure and no extra combinational enable logic.
