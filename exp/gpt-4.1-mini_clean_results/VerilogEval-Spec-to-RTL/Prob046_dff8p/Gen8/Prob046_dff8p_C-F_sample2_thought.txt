Fuse the clarity and modularity of Example 1's individual bit DFFs with synchronous reset loading a fixed reset value and Example 2's efficient vectorized register approach. 

Strategy:
- Implement a parameterized single-bit synchronous-reset D flip-flop module triggered on negedge clk, with the reset value hardcoded inside the module (removes the need to pass reset_val input, saving power and area).
- In TopModule, instantiate 8 of these DFFs using a generate loop, each with the corresponding input bit and output bit, passing clk and reset uniformly.
- Each DFF internally uses the hardcoded reset value bit from 0x34. This means the reset value is not a port, but constant inside the DFF, reducing interconnect toggling and enabling better optimization.
- This maintains the modular clarity and testability of separate DFF instances, but avoids passing a reset vector input, combining power and area savings of Example 2 with the modularity and ease-of-debugging of Example 1.

Benefits:
- Modular design allows easy per-bit testing and modification.
- Avoiding reset_val input ports reduces switching activity and area.
- Hardcoding reset constant inside the DFF module lets synthesis tool optimize constant load paths.
- Using negedge clk and synchronous reset matches requirement exactly.
- Clear separation of functionality for each DFF improves readability and maintainability.
