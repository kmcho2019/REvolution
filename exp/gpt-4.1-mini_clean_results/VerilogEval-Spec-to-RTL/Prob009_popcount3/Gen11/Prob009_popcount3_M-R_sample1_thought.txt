The original design uses a direct addition expression to count the population of bits. To refactor while keeping the core idea, I will replace the addition with a procedural `always_comb` block that uses a simple loop to count the number of '1's in the input vector. This approach explicitly iterates over each bit and increments a counter, which is then assigned to the output. This maintains purely combinational logic, is functionally equivalent, but shows an alternative coding style using procedural constructs instead of continuous assignment.
