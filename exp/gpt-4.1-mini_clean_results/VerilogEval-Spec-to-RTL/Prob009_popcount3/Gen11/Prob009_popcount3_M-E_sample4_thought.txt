Instead of directly summing the bits, we can implement the population count using a small combinational logic tree with explicit bitwise operations. For three input bits, the count can be found by combining pairwise sums and carries. We first XOR two bits to get a partial sum and AND two bits to find the carry, then add the third bit similarly. This creates a ripple-like adder explicitly in logic gates. This approach illustrates bitwise logic use without the '+' operator.
