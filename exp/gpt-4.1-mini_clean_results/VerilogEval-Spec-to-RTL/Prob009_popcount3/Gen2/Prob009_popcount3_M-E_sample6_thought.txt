Instead of summing the input bits with arithmetic addition, use explicit combinational logic to compute the population count. For 3 bits, the count of ones can be encoded with two output bits:

- out[1] = 1 if at least two input bits are high (i.e., the majority function for 3 bits)
- out[0] = 1 if an odd number of input bits are high (i.e., parity of the three inputs)

This approach uses simple logic expressions (AND, OR, XOR) without any addition operators, potentially reducing the logic depth and power consumption. The design is fully combinational and minimal in gate count.

This direct boolean logic implementation is novel compared to addition-based solutions and can reduce area by avoiding arithmetic operators and intermediate wider buses.
