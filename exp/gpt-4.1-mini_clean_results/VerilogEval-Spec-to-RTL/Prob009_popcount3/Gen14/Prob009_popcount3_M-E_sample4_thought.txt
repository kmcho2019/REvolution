Implement the population count using a small combinational tree of adders by first performing pairwise addition of bits and then combining results. Specifically, compute partial sums of the first two bits, then add the third bit, all using bitwise concatenations and simple arithmetic. This approach explicitly uses intermediate wires and staged addition, contrasting with direct summation in a single statement, while achieving the same result. This structure could map well to a ripple carry adder style with minimal logic for 3 bits.
