To fuse the strengths of both examples, we aim for a design that is minimal, clear, and potentially more optimal for synthesis.

From Example 2, the continuous assignment style emphasizes clarity and simplicity by avoiding registers and always blocks, improving readability and synthesis friendliness.

- Implement the output bits explicitly using simple gate-level boolean expressions from Example 1 (parity and majority).

- For output port, bundle the two bits into a 2-bit vector `out` for clear interface.
- This approach combines gate-level minimalism (Example 1) and code clarity / simplicity (Example 2).
