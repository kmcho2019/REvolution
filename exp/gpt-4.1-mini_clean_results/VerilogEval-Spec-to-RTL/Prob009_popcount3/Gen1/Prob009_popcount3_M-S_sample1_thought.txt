Since the input is 3 bits, the population count (number of '1's) can be computed simply by summing the bits. Instead of summing individually, use the reduction operator to count the bits more concisely: apply a bitwise OR reduction to get a binary count of '1's. However, reduction OR only tells if any bit is 1, not the count. Instead, use the reduction add operator '+' across the bits by casting to integer or use the built-in population count operator if available. Since Verilog doesn't have a built-in popcount, stick with the sum of bits but use the concatenation and addition in a simpler expression. The original is already simple, but writing as a sum of bits is minimal.
