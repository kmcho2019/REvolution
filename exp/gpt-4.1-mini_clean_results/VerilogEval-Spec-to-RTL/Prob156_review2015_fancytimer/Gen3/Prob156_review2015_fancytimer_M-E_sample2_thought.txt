I will implement a well-structured FSM with the following states: IDLE, DELAY_LOAD, COUNTING, and WAIT_ACK.

- IDLE state: continuously shift in data bits into a 4-bit pattern register to detect the start pattern 1101.
- Once pattern 1101 is detected, transition to DELAY_LOAD state, where the module shifts in 4 delay bits (MSB first) serially into a 4-bit delay register.
- After the delay is fully loaded, move to COUNTING.

Counting method:

- Instead of using nested counters, I will implement a single 20-bit cycle counter that counts total cycles from 0 up to (delay + 1) * 1000 - 1.
- To generate count output, which indicates how many 1000-clock blocks are remaining, I will compute the remaining count by integer division of remaining cycles by 1000. This can be done by tracking the upper bits of the cycle counter, or via a small combinational division since delay is 4 bits.
- To avoid complex division hardware, I will keep track of cycles elapsed and compute remaining count as delay - (elapsed 1000-blocks). This can be done by counting how many 1000-clock blocks have elapsed with an additional small counter.
- Outputs: 
   - counting=1 in COUNTING state,
   - done=1 in WAIT_ACK state,
   - count outputs remaining blocks (delay down to 0) during counting, otherwise don't-care (will output zero).

- After counting is done, transition to WAIT_ACK, asserting done and waiting for ack to be asserted.
- On ack, return to IDLE and reset all registers.

Synchronous reset active high.

All logic updated on posedge clk.

This design uses a simple FSM, a 4-bit shift register for pattern detection, a 4-bit delay register for delay, a 10-bit microcounter counting up to 999, and a 4-bit block counter counting from 0 to delay+1.

The block counter increments each time microcounter reaches 999. Counting finishes after block counter reaches delay + 1. Count output is computed as (delay + 1) - block_counter.

This cleanly matches the specification and prevents off-by-one errors.

We ignore data input except in IDLE and DELAY_LOAD states as required.

The structure guarantees the exact count duration and proper signaling.
