Simplify approach by using a clear FSM with 4 states (IDLE, DELAY_LOAD, COUNTING, DONE) and synchronous logic only.

- Pattern detection: use a 4-bit shift register that shifts left, input bit at LSB, so bits arrive MSB-first; detect "1101" (pattern: bit3=1, bit2=1, bit1=0, bit0=1).
- Delay load: shift delay bits into a 4-bit register MSB-first (shift left, input at LSB).
- Counting: Use two counters:
  - A 10-bit cycle_counter counting from 0 to 999 (counts clock cycles per block).
  - A 4-bit block_counter counting down the number of 1000-cycle blocks (initialized to delay+1).
- Output count = current block_counter - 1 during counting, shows how many blocks remain (starting from delay).
- During IDLE, pattern detection runs, ignoring delay and counting.
- During DELAY_LOAD, shift in delay bits only.
- During COUNTING, no data input used.
- DONE signals end, waits for ack before returning to IDLE.
- Reset clears all registers and starts in IDLE.

This is a clean, minimal, and functionally correct design meeting spec and easy to understand.
