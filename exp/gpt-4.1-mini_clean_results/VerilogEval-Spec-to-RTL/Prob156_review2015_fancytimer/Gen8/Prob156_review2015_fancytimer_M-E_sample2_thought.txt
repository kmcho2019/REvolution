Implement a Moore-style finite state machine with clear, enumerated states for better control and clarity: SEARCH, LOAD_DELAY, COUNTING, and DONE.

Key design ideas:
- Use a 4-bit shift register always shifting in input data at each clock cycle for pattern detection and delay loading.
- In SEARCH state, shift in data and check for the pattern 1101 in the last 4 bits.
- When pattern detected, transition to LOAD_DELAY, where next 4 bits are shifted in serially MSB first into a separate delay register.
- Once 4 delay bits loaded, transition to COUNTING.
- In COUNTING, implement two counters:
  * A 10-bit cycle counter (0 to 999) counting clock cycles.
  * A 4-bit delay counter initialized to delay + 1 ticks, counting down each 1000 cycles.
- The `count` output reflects the current remaining delay counter value during each 1000-cycle tick, starting at the loaded delay and decrementing after each 1000-cycle interval.
- When counting completes (delay counter reaches zero after the last 1000-cycle interval), transition to DONE.
- DONE state asserts `done` output, and waits for `ack` input to transition back to SEARCH.
- The synchronous reset initializes state and counters properly.
- Outputs `count`, `counting`, and `done` are stable and reflect state.
- The design ignores input data except during SEARCH and LOAD_DELAY states as required.

This approach simplifies pattern detection by continuously shifting input data in SEARCH state, cleanly separates loading delay bits, and uses clear Moore FSM states with explicit counters and outputs for robust timer operation.
