Implement a 5-state FSM: IDLE, MATCH, READ_DELAY, COUNT, and DONE.

- IDLE: shift in input bits into a 4-bit shift register each clock to detect pattern 1101. When matched, transition to READ_DELAY.

- READ_DELAY: shift in next 4 bits MSB first into a delay register. Use a 3-bit counter to count delay bits received. After 4 bits read, move to COUNT.

- COUNT: implement a two-level countdown:

   1) `block_count` from delay down to 0 representing remaining blocks of 1000 cycles.

   2) `cycle_counter` counts from 0 up to 999 clock cycles.

- Output `count` as the current value of `block_count`.

- After counting the last 1000-cycle block (block_count == 0 and cycle_counter == 999), transition to DONE.

- DONE: assert done=1 and wait for ack=1 to return to IDLE.

- During COUNT, counting=1, otherwise 0.

- Reset all counters and registers on synchronous reset.

Key points:

- Delay bits are shifted MSB first: each new bit goes into LSB, shift left by 1.

- Counting is (delay + 1) blocks of 1000 cycles each; initialize block_count to delay plus one.

- Outputs count the current remaining block_count.

- pattern register only updates in IDLE.

This architecture cleanly separates pattern detection, delay loading, counting, and completion acknowledgment. It also ensures precise timing and output synchronization as specified.
