Implement a Moore-style FSM with these main states: SEARCH, LOAD_DELAY, COUNTING, DONE_WAIT.

- SEARCH: Shift incoming bits into a 4-bit shift register MSB-first (new bit enters at LSB). Continuously compare this shift register to 4'b1101. Once matched, transition to LOAD_DELAY.

- LOAD_DELAY: Serially shift in 4 delay bits MSB-first into a 4-bit delay register. Use a 3-bit counter to track bits loaded. After all 4 bits are loaded, transition to COUNTING.

- COUNTING: Use a 14-bit counter to count clock cycles up to total_count = (delay + 1) * 1000 cycles. Precompute total_count from delay once loading finishes. 

  - Maintain an auxiliary "remaining_ticks" register initialized to delay. 

  - Every 1000 cycles, decrement remaining_ticks. The output count is the current remaining_ticks, which stays stable for exactly 1000 cycles. For delay=0, counts 1000 cycles showing count=0 the whole time.

- DONE_WAIT: When counting completes, assert done=1 and counting=0, count output don't care (set to zero). Wait here until ack=1, then transition back to SEARCH.

- Reset synchronously resets all registers and FSM to SEARCH.

This approach:

- Separates pattern matching from delay loading clearly.

- Uses a single large cycle counter to handle timing precisely, avoiding off-by-one errors.

- Computes and stores total_count upfront for a clean countdown.

- The count output reflects the number of 1000-cycle blocks remaining, exactly as required.

- Transitioning to DONE_WAIT only after counting finishes keeps done asserted until acknowledged.

- Uses a Moore FSM so outputs depend only on states, reducing timing risks.

- Pattern detection shifts in MSB first, matching problem statement.

Overall, this method improves timing accuracy, output stability, and clean state transitions, ensuring exact timing and output behavior.
