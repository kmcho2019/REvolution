Simplify the design by avoiding division and multiplication operations which are problematic in hardware. Use two counters:

1. A 10-bit "cycle_counter" counting from 0 to 999 to count clock cycles within each "tick" (1000 cycles per tick).

2. A 4-bit "tick_counter" counting from 0 up to delay_reg (the delay value).

This way, the total counting time is (delay + 1) * 1000 cycles: for each tick, count 1000 cycles, then decrement the ticks left.

The count output shows the current tick count remaining, stable for each 1000 cycles.

Implement a 2-bit FSM with states: SEARCH (looking for 1101 pattern), LOAD_DELAY (shift in 4 bits MSB first), COUNTING (count down), and DONE_WAIT (assert done until ack).

Pattern detection and delay loading done by shifting in MSB first.

Reset is synchronous active high.

This approach is straightforward, synthesizable, and ensures precise timing and stable outputs.
