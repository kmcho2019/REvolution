Implement a simple FSM with these states: SEARCH, LOAD_DELAY, COUNTING, DONE.

- SEARCH: Shift data bit into a 4-bit shift register each clock; when it matches 1101, move to LOAD_DELAY.
- LOAD_DELAY: Shift in next 4 bits MSB first as delay. Use a 3-bit bit counter from 0 to 3 for loading. After loading delay, transition to COUNTING.
- COUNTING: Use two counters:
    - a 10-bit cycle counter counting down from 999 to 0 (for 1000 cycles per block).
    - a 4-bit block counter initialized to delay+1, counting down blocks.
  On each cycle counter zero, decrement the block counter.
  When block counter reaches zero and cycle counter reaches zero, transition to DONE.
  Output count = block counter - 1 (since blocks count from delay+1 down to 1).
- DONE: Assert done=1, wait for ack=1, then return to SEARCH.

This approach avoids division, uses simple counters, and cleanly separates delay loading and counting logic. All signals updated synchronously at posedge clk with synchronous reset.
