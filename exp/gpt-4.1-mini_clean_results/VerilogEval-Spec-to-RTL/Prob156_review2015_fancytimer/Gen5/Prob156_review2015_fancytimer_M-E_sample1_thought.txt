Use a Mealy-style FSM with 5 states: IDLE, WAIT_DELAY, COUNT, DONE, WAIT_ACK.

- IDLE: continuously shift in serial bits into a 4-bit pattern register, updating on every clock. Detect the start pattern '1101' as soon as the pattern register matches.

- WAIT_DELAY: shift in the 4 delay bits MSB-first, loading one bit per cycle into delay_reg, starting from bit 3 down to bit 0. Use a counter to track how many bits have been loaded.

- COUNT: Implement a two-level timer with two counters: tick_counter (for delay) and cycle_counter (for 1000 cycles per tick). 

    * tick_counter counts down from delay_reg to zero.

    * cycle_counter counts from 0 to 999 for each tick.

- The count output shows the current tick_counter (remaining delay) and is stable for exactly 1000 cycles, decrementing after each 1000 cycle block.

- Transition from COUNT to DONE after the last tick_counter reaches zero and completes 1000 cycles.

- DONE: assert done=1 and counting=0, count output is don't care (set to zero). Wait for ack=1.

- WAIT_ACK: waits for ack input to be asserted to transition back to IDLE.

- In IDLE state, data input shifts the pattern register left, inserting the new bit at LSB, always checking for 1101 pattern.

- In WAIT_DELAY, the delay bits are shifted into delay_reg MSB first: first bit goes to delay_reg[3], second to [2], ... last to [0].

- All outputs and internal registers reset synchronously on reset.

This approach separates pattern detection from delay loading clearly and uses down counters for intuitive counting. Using a WAIT_ACK state makes the done/ack handshake explicit and clean.

This design ensures precise timing alignment for counting and outputs exactly the behavior specified.
