Simplify the design by using a straightforward FSM with the four states: SEARCH, LOAD_DELAY, COUNT, and WAIT_ACK.

- Use a 4-bit shift register to detect the start pattern '1101' in SEARCH state by shifting in 'data' every clock.
- Once detected, transition to LOAD_DELAY, where we load 4 bits serially (MSB first) into delay_reg.
- Then transition to COUNT, counting down `(delay + 1) * 1000` cycles using a single 14-bit counter (since max is 16*1000=16000 < 2^14).
- The output `count` is computed by dividing the remaining cycles by 1000 (integer division). For example, remaining cycles 0..999 => count=0, 1000..1999 => count=1, etc.
- When the counter reaches zero, assert done and wait for ack in WAIT_ACK before returning to SEARCH.

This avoids complicated double counters or segment/cycle counters, and counting can be done in one counter.

Outputs:
- `count` = remaining segments, starting at `delay`
- `counting` asserted only in COUNT state
- `done` asserted only in WAIT_ACK state

Use synchronous reset and all logic on posedge clk.

This approach is simpler, easier to verify, and matches the required behavior and timing precisely.
