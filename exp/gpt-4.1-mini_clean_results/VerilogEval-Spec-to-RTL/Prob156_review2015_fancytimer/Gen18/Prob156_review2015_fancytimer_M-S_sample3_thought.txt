Implement a straightforward FSM with four states: SEARCH, LOAD_DELAY, COUNT, WAIT_ACK. 

- Use a 4-bit shift register for pattern detection with newest bit at MSB: shift in `{data, pattern_shift[3:1]}` each cycle in SEARCH state.
- Upon detecting the pattern 1101, transition to LOAD_DELAY where 4 bits are shifted into a 4-bit delay register MSB-first (newest bit at MSB) by shifting delay right and inserting `data` at MSB: `delay <= {data, delay[3:1]}`.
- After loading 4 delay bits, move to COUNT state.
- In COUNT state, maintain two counters: 
  - `segment_counter` from `delay+1` down to 0 (counts 1000-cycle segments),
  - `cycle_counter` counts down from 999 to 0 for each 1000-cycle segment.
- Output `count` shows the current remaining segment count (delay down to 0, each held for 1000 cycles).
- After all segments counted, assert `done` and wait for `ack`.
- On `ack`, reset back to SEARCH.
- Use synchronous reset.
- Keep all sequential logic in one clocked always block for clarity and to avoid multiple conflicting assignments.
