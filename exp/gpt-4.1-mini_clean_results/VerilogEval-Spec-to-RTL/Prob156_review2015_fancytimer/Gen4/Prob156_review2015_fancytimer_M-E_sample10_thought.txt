Implement a Moore-style FSM with five states: IDLE, DETECT, LOAD, COUNT, and WAIT_ACK.

- In IDLE, shift in serial bits to detect the pattern 1101 using a 4-bit shift register.
- When pattern detected, transition to LOAD to shift in 4 bits (MSB first) as the delay value. Use a 4-bit shift register where the incoming bit is shifted into the MSB position (shift right) to capture MSB first.
- After loading delay, initialize a 16-bit cycle counter for counting up to 1000 clock cycles, and a 4-bit remaining counter for delay+1.
- Enter COUNT state where for each 1000 cycle interval, decrement remaining count. Output count = remaining-1 during each 1000-cycle interval (so that when remaining is N, count outputs N-1 during those 1000 cycles).
- When remaining counter reaches zero after counting, transition to WAIT_ACK state, assert done=1, counting=0, and wait for ack=1 to return to IDLE.
- During COUNT, count output shows the current remaining value minus one, counting=1, done=0.
- During other states, counting=0, done=0, count=don't care (we use zero).
- Synchronous reset returns system to IDLE and clears all counters.
- This design cleanly separates input pattern detection from delay loading and counting, ensures correct MSB-first delay load by shifting bits into MSB on each clock, and explicitly counts (delay+1)*1000 cycles.
