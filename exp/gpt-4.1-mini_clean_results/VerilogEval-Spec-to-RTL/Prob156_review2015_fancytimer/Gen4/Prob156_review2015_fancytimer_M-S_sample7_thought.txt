Implement a straightforward FSM with four states: SEARCH, LOAD_DELAY, COUNTING, DONE.  
- SEARCH: shift in data bits continuously to detect pattern 1101.  
- LOAD_DELAY: shift in exactly 4 bits MSB-first into delay_reg.  
- COUNTING: count exactly (delay + 1)*1000 cycles, with two counters:  
    * cycle_counter counts 0..999 for the 1000 cycles per tick,  
    * tick_counter counts down from delay to 0 (inclusive), representing remaining ticks.  
  During COUNTING, output counting=1, done=0, and count=remaining tick (tick_counter), which starts at delay (not delay+1).  
- DONE: counting=0, done=1, wait for ack to go back to SEARCH.

Key simplifications and fixes:  
- Initialize tick_counter = delay (not delay+1) at the start of COUNTING.  
- When cycle_counter hits 999, if tick_counter > 0, decrement tick_counter and reset cycle_counter.  
- When tick_counter == 0 and cycle_counter == 999, counting finishes; next cycle goes to DONE.  
- Output count = tick_counter only during COUNTING; otherwise don't care (set to 0).  
- Update pattern_shift only in SEARCH state.  
- Use synchronous reset to initialize all regs.  

This approach reduces complexity, clarifies tick counting logic, and fixes off-by-one in count and timing.
