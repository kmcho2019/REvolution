Implement a four-state FSM with states: IDLE (search for pattern), LOAD (shift in delay bits MSB first), COUNT (count timer cycles), and WAIT_ACK (indicate done and wait for ack).

Use a 4-bit shift register for pattern detection, shifting in the 'data' bit each clock and comparing to 4'b1101 to start loading delay bits. Once pattern detected, stop pattern shifting and enter LOAD state.

In LOAD, shift in the next 4 bits of delay MSB first (shift register shifts left each cycle with new bit inserted at LSB), using a 2-bit bit counter (0-3) to track loaded bits. After 4 bits, compute total count cycles = (delay + 1) * 1000.

In COUNT, use a 16-bit cycle counter counting down from total cycles to zero. Each clock, decrement cycle counter; when it hits zero, move to WAIT_ACK.

Output 'count' is the current delay countdown value, changing every 1000 cycles:  
- When counting, `count` is the integer division of remaining cycles by 1000 minus 1 (e.g., at start count=delay, decreases every 1000 cycles).  
- When not counting, 'count' is don't-care (set to zero for synthesis simplicity).

Output 'counting' asserted during COUNT state, 'done' asserted only in WAIT_ACK state.

In WAIT_ACK, wait for ack=1, then reset FSM to IDLE and resume pattern detection.

All state changes and counters update on the positive clock edge with synchronous active-high reset.

This approach centralizes cycle counting as a single down-counter, avoids nested counters, and cleanly separates pattern detection, loading, counting, and waiting states for clarity and correctness.
