I will simplify the design by implementing a straightforward FSM with clear states and single always block for all synchronous logic to avoid register update conflicts:

- Use a 4-bit shift register to continuously shift in the serial input in the SEARCH state.
- Upon detecting the pattern `1101`, transition to LOAD_DELAY to shift in exactly 4 delay bits (MSB first) using a 3-bit counter.
- Once delay bits are loaded, move to COUNTING state, using a 10-bit cycle counter (counts 0 to 999) and a 4-bit block counter initialized to delay+1.
- Each time cycle counter reaches 999, decrement block counter by 1.
- Output count = current block counter - 1 (to show remaining blocks), counting asserted during counting.
- When counting finishes (block counter zero and cycle counter reached 999), assert done and wait in DONE state.
- On ack from user, return to SEARCH and reset all.
- All outputs and registers updated synchronously on clk rising edge.
- When not counting, count output is 0 (don't care).
- This single always block approach prevents conflicts and simplifies the logic.
