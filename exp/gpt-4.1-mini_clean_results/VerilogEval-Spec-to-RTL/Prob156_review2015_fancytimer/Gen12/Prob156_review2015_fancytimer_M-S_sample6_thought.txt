Implement a simple FSM with these four states: SEARCH, LOAD_DELAY, COUNTING, DONE.

- SEARCH: Shift in data bits into a 4-bit shift register each clock to detect the pattern 1101.
- Once pattern detected, transition to LOAD_DELAY.
- LOAD_DELAY: Shift in 4 delay bits MSB first into a 4-bit register over 4 cycles.
- After loading delay, initialize counters for counting:
    - A 10-bit cycle counter counts 0 to 999 cycles.
    - A 4-bit block counter initialized to (delay+1).
- COUNTING: Each clock increments cycle counter.
    - When cycle counter reaches 999, decrement block counter and reset cycle counter.
    - Continue until block counter is zero and cycle counter is 999 (finished full count).
- DONE: Assert done=1, counting=0, count is don't care.
    - Wait for ack=1 before transitioning back to SEARCH.

Outputs:
- counting=1 during COUNTING, 0 otherwise.
- count shows current block counter minus 1 (remaining delay blocks) during counting.
- done=1 only in DONE state.

All registers update synchronously on the positive clock edge with synchronous active-high reset.  
Shift pattern and delay bits only updated in SEARCH and LOAD_DELAY states respectively, ignoring data input in other states.

This approach uses only a single always block for all sequential logic and a combinational block for next state, ensuring simplicity and clarity.
