Implement a 5-bit shift register to track the last 4 data bits plus the new bit, so that pattern detection (1101) can be done by examining bits [4:1] each cycle, shifting in data at bit 0. This approach allows pattern detection on every clock with a single shift.

Use a 4-state FSM: SEARCH, LOAD, COUNT, WAIT_ACK.

In SEARCH state, continuously shift data into the 5-bit register and check bits [4:1] for the 1101 pattern; once detected, move to LOAD.

In LOAD state, shift in 4 bits MSB first into a 4-bit delay register, using a 3-bit counter for the bits loaded.

When LOAD is done, initialize a cycle counter (10 bits) to 0 and a block counter (5 bits) to delay+1.

In COUNT state, count clock cycles; every 1000 cycles, decrement block counter until 0.

Output 'count' as the block counter minus 1 during counting; output 'counting' high only in COUNT state; done is asserted in WAIT_ACK.

In WAIT_ACK, keep done asserted and wait for ack; once ack is received, return to SEARCH.

Avoid mixing counter initialization with state transitions by explicitly resetting counters in the transition clock cycle.

Use synchronous reset and trigger all sequential logic on clk posedge.

This architecture cleanly separates pattern detection with a wider shift register, uses explicit bit indexing for pattern match, and clean counter management for accurate timing.
