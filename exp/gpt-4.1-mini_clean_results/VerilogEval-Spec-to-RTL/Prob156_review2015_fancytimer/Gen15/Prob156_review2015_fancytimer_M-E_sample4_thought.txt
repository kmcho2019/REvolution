Use a more modular approach with a clearly pipelined input processing:

- Implement a serial pattern detector that tracks the last 4 bits shifted in and outputs a pulse when pattern 1101 detected.
- After detection, disable pattern detection and enter a delay load phase, shifting in exactly 4 bits MSB first to form the delay value.
- Once delay loaded, start a counting phase:
  - Use a 14-bit counter for counting from (delay+1)*1000 down to 0.
  - Also maintain a 4-bit block counter for the upper nibble of the countdown, which represents the remaining blocks (delay down to 0), stable for 1000 cycles each.
- When counting finishes, assert done and wait for ack.
- After ack, reset internal state and resume pattern detection.

This way, pattern detection is completely separated from counting and delay loading, avoiding timing confusion.

Synchronous reset and all state changes happen on posedge clk.

Outputs:
- counting asserted only during counting phase.
- done asserted only after counting done and before ack.
- count outputs the current remaining block (delay down to 0), stable for 1000 cycles each during counting; don't-care otherwise.
