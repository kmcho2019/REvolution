Implement a finite state machine with these states:
1) SEARCH: Shift in serial bits and look for pattern 1101.
2) LOAD_DELAY: Shift in next 4 bits (MSB first) as the delay value.
3) COUNTING: Count down (delay+1)*1000 cycles. Output the current remaining delay count in count[3:0]. counting=1 during this state.
4) DONE: Assert done=1, wait for ack=1 before transitioning back to SEARCH.

Use a shift register or small history register to detect the 1101 pattern on data. Use synchronous reset to initialize. Use a cycle counter to count 1000 clock cycles per delay unit. Each 1000 cycles decrements the remaining delay counter.

Only read serial data during SEARCH and LOAD_DELAY states. During COUNTING and DONE ignore data input.

Outputs:
- counting = 1 in COUNTING state else 0.
- count = current remaining delay (4 bits).
- done = 1 in DONE state else 0.

The remaining delay is initialized to delay input, and decremented every 1000 clock cycles until 0.
