Implement a finite state machine (FSM) with states to detect the start pattern (1101), shift in the 4-bit delay value MSB first, count the specified number of clock cycles in blocks of 1000 cycles per delay decrement, signal done when finished, and wait for acknowledgment before resetting to search state. Use a 4-bit shift register to detect the start pattern by shifting in bits on each clock. After detection, shift in delay bits MSB first. Then count (delay + 1) * 1000 cycles, decrementing the remaining count every 1000 cycles. Output the remaining delay on count output during counting and assert counting output. When done, assert done output and wait for ack to return to initial pattern detection. All synchronous logic triggers on posedge clk and synchronous active-high reset. When not counting, count output is don't-care (I will output zero). Implement all signals as requested.
