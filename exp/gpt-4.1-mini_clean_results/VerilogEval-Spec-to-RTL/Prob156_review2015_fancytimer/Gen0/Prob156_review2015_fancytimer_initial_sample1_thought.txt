Implement a synchronous state machine with these states: SEARCH for the pattern 1101, SHIFT_DELAY to shift in 4 bits for delay, COUNT where the timer counts down in blocks of 1000 cycles, and DONE where the module waits for ack. Use a 4-bit shift register to detect the pattern 1101. When found, move to SHIFT_DELAY state to capture 4 bits MSB first into delay[3:0]. Then move to COUNT state where we count (delay+1)*1000 cycles, decrementing count every 1000 cycles and outputting the remaining delay count. When done counting, assert done and wait in DONE state until ack is asserted, then return to SEARCH. The count output is valid only during COUNT; otherwise it's don't care. Implement synchronous reset and state transitions on posedge clk.
