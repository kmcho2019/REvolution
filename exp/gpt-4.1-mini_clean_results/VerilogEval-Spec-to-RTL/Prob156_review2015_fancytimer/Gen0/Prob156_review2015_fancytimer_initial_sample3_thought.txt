Implement a finite state machine with states: SEARCH (looking for pattern 1101), READ_DELAY (shift in 4 bits delay), COUNT (counting down the timer), DONE (assert done, wait for ack). Use a shift register to detect pattern 1101 serially. When pattern detected, shift in next 4 bits as delay MSB first. Counting state uses an internal counter to count 1000 cycles per delay step, decrementing delay after each 1000 cycle count. The count output reflects the current delay value during counting. When done counting, assert done and wait for ack to reset to SEARCH state. Use synchronous active-high reset to initialize FSM and registers.
