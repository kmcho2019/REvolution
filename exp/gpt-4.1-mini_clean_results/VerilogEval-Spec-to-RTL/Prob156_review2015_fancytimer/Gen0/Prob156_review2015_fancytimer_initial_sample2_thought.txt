Implement a finite state machine with these states: SEARCH for the start pattern 1101; READ_DELAY to read the 4-bit delay value MSB first; COUNT to count down the timer; DONE to indicate completion and wait for ack. Use a shift register or individual bits to detect the 4-bit start pattern by shifting in 'data' each clock. In SEARCH, shift in each data bit and check if the last 4 bits equal 1101. Upon detection, transition to READ_DELAY, shift in 4 bits as delay[3:0] MSB first. Then move to COUNT where a cycle counter counts 1000 clock cycles per count, and a remaining count from delay down to zero decrements every 1000 cycles. Output counting=1 and count=remaining count during this phase. After counting finishes, move to DONE, assert done=1, wait for ack=1, then return to SEARCH. During RESET, initialize all states and registers.
