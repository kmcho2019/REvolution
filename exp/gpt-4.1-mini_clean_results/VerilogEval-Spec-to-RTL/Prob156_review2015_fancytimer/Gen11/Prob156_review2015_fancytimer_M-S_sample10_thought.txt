Implement a straightforward FSM with four states: SEARCH (for pattern 1101), LOAD_DELAY (shift in 4 MSB-first bits), COUNTING (count delay+1 blocks of 1000 cycles), and DONE_WAIT (assert done and wait for ack). Use a 4-bit shift register to detect the start pattern during SEARCH and load delay bits MSB first in LOAD_DELAY. In COUNTING, have a 10-bit cycle counter counting 0 to 999, and a 5-bit block counter counting down the remaining blocks. The count output shows the current remaining block value, stable during each 1000-cycle block. When done, assert done and wait for ack to restart. Synchronous reset initializes the FSM.
