Refactor the FSM to use traditional Verilog style with `parameter`-defined states instead of SystemVerilog enums. Use a single always block for synchronous state and outputs to simplify design and avoid conflicts.

Pattern detection is done by a 4-bit shift register that shifts in new data bits on every clock during SEARCH state. When the pattern 1101 is detected, move to LOAD_DELAY.

During LOAD_DELAY, shift in 4 delay bits MSB-first into the delay register, counting how many bits have been loaded. Then transition to COUNT.

COUNT state uses two counters: a 10-bit cycle_counter counts 0 to 999 for each segment, and a 4-bit segment_counter counts down (delay + 1) segments. The `count` output reflects the number of full 1000-cycle segments remaining.

After all segments finish counting, assert done and wait in WAIT_ACK state for ack to be high before returning to SEARCH.

All state transitions and output updates happen in synchronous always block with positive edge clock and synchronous reset.

Avoid explicit casts or SystemVerilog features for broad Verilog-2001 compatibility.

This approach keeps the original functionality intact while making the code compatible with simpler Verilog environments.
