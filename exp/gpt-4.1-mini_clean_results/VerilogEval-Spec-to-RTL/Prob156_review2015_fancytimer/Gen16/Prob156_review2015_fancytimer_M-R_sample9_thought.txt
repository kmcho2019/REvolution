Refactor the design by implementing a one-hot style FSM with clearly separated synchronous state updates and combinational next-state logic, simplifying pattern detection and counting logic.

Key improvements:

1. **Pattern Detection Using Shift Register:**  
   Shift pattern bits in MSB-first by shifting left and inserting data at LSB. Check for pattern 4'b1101 after each new bit. Hold pattern register only in SEARCH state; clear in other states.

2. **Delay Loading:**  
   Load 4 delay bits MSB-first similarly by shifting left on each clock during DELAY_LOAD state, counting bits loaded with a small counter.

3. **Counting Timer:**  
   Implement two counters:  
   - A 10-bit cycle_counter counts clock cycles from 0 to 999 per tick.  
   - A 5-bit tick_counter counts down the (delay+1) ticks.

   On every 1000 cycles (cycle_counter == 999), decrement tick_counter and update output count to tick_counter - 1, which corresponds to the remaining "delay" value for the next 1000 cycles.

   To avoid off-by-one errors, decrement tick_counter at cycle_counter == 999, then reset cycle_counter at next clock.

4. **Stable Count Output:**  
   The output count is updated only on tick boundaries and stable in between.

5. **Clear Inputs During Counting:**  
   During counting and later states, no longer sample data or update pattern/delay registers.

6. **FSM Structure:**  
   Use a parameter-based encoding for states, with one always_ff block for state and registers, and one always_comb for next state and outputs.

7. **Synchronous reset:**  
   All registers reset synchronously.

This structure improves clarity and correctness, avoids complex prev_state dependency, and fixes off-by-one counting and pattern detection issues.
