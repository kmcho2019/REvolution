Implement the FSM using a one-hot encoding approach where each state is represented by a separate flip-flop. This approach uses six flip-flops, one per state, simplifying next-state logic because transitions become direct assignments between state bits. The output `z` is driven high only when the FSM is in states E or F. Use synchronous reset to initialize the FSM to state A. Next state logic is implemented combinationally with `always @*` blocks assigning the next state bits based on the current state and input `w`.
