I will implement the FSM using a one-hot encoding scheme, where each state is represented by a separate flip-flop bit. This approach simplifies the next-state logic to combinational logic that directly drives the one-hot state bits. The output z will be driven combinationally based on which state bits are set. This encoding can improve clarity and potentially speed at the cost of more flip-flops. The state register will be updated synchronously with non-blocking assignments. The reset condition will set the A state bit to 1 and all others to 0.
