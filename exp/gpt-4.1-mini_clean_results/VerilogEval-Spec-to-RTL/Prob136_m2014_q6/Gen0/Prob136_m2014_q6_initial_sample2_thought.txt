Implement a finite state machine (FSM) with six states A-F encoded as 3-bit values. On each positive clock edge, if reset is asserted, transition to state A. Otherwise, transition based on the input w according to the given state diagram. The output z depends on the current state and input w, following the conditions provided by the transitions (not all transitions specify output explicitly, so assume z=0 unless stated). Since the only states with output z=1 are E and F when the input conditions are met, z will be driven accordingly.
