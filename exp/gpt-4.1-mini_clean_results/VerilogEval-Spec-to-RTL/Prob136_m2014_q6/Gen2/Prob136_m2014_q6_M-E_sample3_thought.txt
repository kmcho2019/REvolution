Implement the FSM using one-hot encoding for states, representing each state as a separate flip-flop bit. This reduces the decoding logic for next state transitions, as next state signals can be assigned more directly from current states and input w. The output z will be combinational logic based on the one-hot encoded state bits. State registers update on clock edge and reset asynchronously to state A. This approach trades increased area for potentially faster timing and simpler next state logic.
