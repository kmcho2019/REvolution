Implement the FSM using a one-hot encoding scheme for the six states to simplify combinational next-state logic. Represent each state by a unique bit in a 6-bit state register. At each positive clock edge, update the current state to the next state or reset to A. Derive the next state directly from the current one-hot state and input w using combinational logic.
