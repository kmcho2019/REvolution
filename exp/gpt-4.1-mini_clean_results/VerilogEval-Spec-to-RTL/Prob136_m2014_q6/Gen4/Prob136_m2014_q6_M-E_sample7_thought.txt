Instead of using a binary-encoded state machine, implement the FSM using one-hot encoding with six flip-flops representing states A through F. Each clock cycle, only one state flip-flop is asserted. Next state logic is described by combinational logic for each state output based on the current states and input w. Output z is asserted high if the state is E or F. This one-hot encoding can reduce the combinational logic complexity at the cost of more flip-flops.
