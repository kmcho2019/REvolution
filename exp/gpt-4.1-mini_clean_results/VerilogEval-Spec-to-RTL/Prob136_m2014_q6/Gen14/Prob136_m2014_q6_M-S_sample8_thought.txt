To simplify the design, I will use a single always block triggered on the positive edge of clk to update both the state and output. Instead of separate combinational assignments for next state and output, I'll encode next state and output within the sequential block using a case statement, which reduces the number of always blocks and logic duplication. This approach keeps the FSM clear, reduces code lines, and maintains synchronous logic structure. The state encoding and transitions remain the same for clarity.
