I will implement the FSM using a Moore machine style with an enumerated type for states and a combinational always block for next-state and output logic. This approach separates combinational next-state and output calculation inside one always block sensitive to inputs and current state, and uses synchronous reset and state update on the clock's positive edge. The output z will be driven directly by the state inside the combinational block. Using a case statement makes the state transitions explicit and readable. This style is more traditional and clearly separates sequential and combinational logic.
