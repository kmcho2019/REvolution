Implement the FSM using one-hot encoding for the six states, represented by six flip-flops. The next state logic is done with a combinational always block using a case statement for clarity and easy synthesis optimization. The output z is asserted only when the machine is in states E or F. Using one-hot encoding simplifies next state decoding and can improve timing at the cost of some area. The state register is updated synchronously on the positive clock edge with asynchronous reset for robust initialization.
