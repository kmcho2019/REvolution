Implement a 4-bit decade counter using a combinational next-state logic and a synchronous process. The next value of the counter will be computed combinationally: if slowena is high, the counter increments unless it is 9, where it wraps to 0; otherwise, it holds its current value. The synchronous always block on posedge clk performs the reset or updates the count from the computed next state. This separates next state calculation from state register updates, providing clear modular design.
