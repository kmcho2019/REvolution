Implement the decade counter using a state machine with one-hot encoding of the count values. The 10 states correspond to the counts 0 through 9. On each clock when slowena is high, transition to the next state, wrapping back from 9 to 0. Use synchronous reset to go back to the initial state representing count 0. Output q is encoded by decoding the one-hot state to a 4-bit binary count. This avoids direct arithmetic and comparison on q, instead relying on state transitions, which can simplify combinational logic and enable clear state visualization.
