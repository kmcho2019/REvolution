Implement the decade counter as a single 4-bit register q that increments by 1 on each clock cycle when slowena is high, wrapping back to 0 after 9. Use synchronous reset to clear q to zero. The counting logic can be done using simple arithmetic: if q is 9 and slowena is high, reset to 0; otherwise if slowena is high, increment by 1; if slowena is low, hold the current value. This approach avoids an explicit state machine, simplifying logic and reducing area and power. q is both the state and output register.
