Implement the decade counter using a one-hot encoded 10-bit register where only one bit is high to represent the current count from 0 to 9. On each clock cycle when slowena is high, rotate the 'hot' bit to the next position, wrapping around from bit 9 back to bit 0. This approach simplifies the next-state logic to a single rotate operation, avoiding explicit addition and comparison. The synchronous reset sets the one-hot register to the initial count state (bit 0 high). The output q is generated by encoding the one-hot vector back to a 4-bit binary count using a priority encoder.
