Implement the decade counter using a 4-bit register `q` that counts from 0 to 9, but drive the counter increment logic using a small finite state machine (FSM) encoded in a separate next-state combinational block. The FSM will have a single state variable which is the current count, and we explicitly check if `q == 9` to reset to 0, otherwise increment. However, instead of embedding the increment logic directly in the always block triggered by clk, use a combinational next-state signal `q_next` that determines the next count value based on `slowena` and current `q`. The synchronous always block only updates `q` with `q_next` or resets it on synchronous reset. This approach separates the combinational next-state logic from the sequential update, enhancing clarity and enabling easier insertion of additional logic in the future without cluttering the sequential block. It also improves testability and can simplify formal verification by cleanly separating next state calculation from state update.

Moreover, the counter will hold its current state when `slowena` is low by assigning `q_next = q` in that case, thus effectively pausing the counting. The synchronous reset sets `q` back to 0 on the rising edge of clk.

This architectural separation improves maintainability and can aid in synthesis optimizations by clearly defining combinational and sequential domains.
