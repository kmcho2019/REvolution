Implement the decade counter using a ring counter approach with one-hot encoding across 10 flip-flops represented in a 10-bit register. On each clock cycle with slowena high, rotate the '1' bit to the next position, representing counts from 0 to 9. A synchronous active-high reset sets the register back to the initial state representing count zero. The output q is decoded from the one-hot register by identifying which bit is set, effectively converting the one-hot count back to a binary count. This approach showcases an alternative architectural style using one-hot encoding and bit rotations rather than binary addition.
