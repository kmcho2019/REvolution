Implement the decade counter as a state machine encoded in a 4-bit register that counts from 0 to 9 and then wraps around. Instead of computing next state with a conditional expression, use a synchronous process with an internal enable signal derived from slowena. The counter increments only when enable is asserted and reset is low; on reset, it synchronously resets to zero. This approach uses a single always block for both reset and count logic, minimizing combinational logic and improving simplicity.
