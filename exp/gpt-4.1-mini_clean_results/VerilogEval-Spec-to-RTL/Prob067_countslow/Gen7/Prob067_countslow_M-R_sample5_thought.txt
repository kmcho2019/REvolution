Refactor the decade counter by separating the next-state combinational logic from the sequential state register. Compute the next value of the counter (`next_q`) using a combinational always block based on the current count, reset, and slowena signals, and then register this value on the clock edge. This separation improves code clarity by explicitly distinguishing between combinational and sequential parts, but retains the same behavior: synchronous reset, gated counting by slowena, and wrap-around from 9 to 0.
