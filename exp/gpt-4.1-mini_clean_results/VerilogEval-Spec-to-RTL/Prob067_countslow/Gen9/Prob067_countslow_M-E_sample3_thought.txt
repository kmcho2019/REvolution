Implement the decade counter using a combinational next-value logic with a registered counter. On every positive clock edge, if reset is asserted, the counter is cleared to zero. Otherwise, if slowena is high, the counter updates to the combinationally calculated next value. The next value is calculated by checking if the current count is 9; if so, wrap to 0, else increment by 1. This approach cleanly separates the combinational next state logic from the sequential register update, making it easy to extend or modify while keeping the design synchronous and efficient.
