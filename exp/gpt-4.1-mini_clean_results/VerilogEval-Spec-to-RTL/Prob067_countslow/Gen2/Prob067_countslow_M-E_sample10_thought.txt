Implement the decade counter using a combinational next-state logic with a 4-bit register q. On each positive clock edge, if reset is asserted, synchronously reset q to 0. Otherwise, when slowena is high, update q to next value. The next value is 0 if q is 9, else q+1. By using a separate combinational signal for next value, we separate combinational increment logic from register update, which can enhance clarity and allow better synthesis optimization.
