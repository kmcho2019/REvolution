Implement the decade counter using a one-hot encoding approach for the count value, represented by a 10-bit register. Only one bit is high at a time, corresponding to the current count (0 through 9). On each slowena high clock cycle, rotate the one-hot bit to the next position. On reset, the 0th bit is set high. The 4-bit binary output q is generated by a priority encoder converting the one-hot register to the binary count. This approach simplifies the modulo operation to a rotate operation and uses a one-hot register for counting.
