Implement the decade counter as a register that holds the count, but instead of using explicit if-else conditions, use a combinational next-state logic that calculates the next value based on current count and slowena. Use a 4-bit wire next_q that increments the count modulo 10 when slowena is high, else holds the current value. On synchronous reset, set q to zero. This approach separates the combinational next-state logic from the sequential register update, enhancing readability and modularity.
