Implement the decade counter using a state machine style with a next-state logic variable. Maintain a register `q` to hold the count and a combinational signal `next_q` to compute the next count value. On each clock edge, if reset is asserted, reset `q` to 0. Else, if `slowena` is high, update `q` to `next_q`, otherwise hold `q`. The next state `next_q` is assigned combinationally by incrementing `q` if less than 9, or rolling over to 0. This separates combinational and sequential logic more explicitly and allows easy modifications or expansions later (such as adding states or outputs). The synchronous reset and the pause functionality are preserved.
