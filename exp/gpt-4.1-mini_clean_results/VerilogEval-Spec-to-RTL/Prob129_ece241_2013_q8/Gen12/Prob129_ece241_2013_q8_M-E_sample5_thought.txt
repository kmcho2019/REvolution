Implement the Mealy FSM with three states encoded as a 2-bit binary state variable, using a case statement for clear next-state logic. The asynchronous reset is triggered on the negative edge of aresetn and resets the FSM to the initial state. The output z is asserted combinationally only when the current state is S2 and the input x is 1, indicating detection of "101". This implementation uses a compact state machine with explicit case-based transitions and a Mealy output condition, supporting overlapping sequences. The design maintains clarity and synthesizability, with asynchronous reset and synchronous state update on the positive edge of clk.
