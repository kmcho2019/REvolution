I will implement the Mealy FSM using a single always block to combine next state logic and output assignment for concise control flow. The states will be encoded as one-hot to use three flip-flops (one per state) for clarity, ensuring exactly three states as required.

The asynchronous reset is triggered on the negative edge of aresetn and will clear all state flip-flops.

The FSM will:
- Start in S0 (no bits matched).
- Go to S1 on input '1'.
- Go to S2 on seeing "10".
- Output 'z' will be asserted whenever the sequence "101" is detected, i.e., when in S2 and input x is '1'.

One-hot encoding allows for direct next state assignment with minimal combinational logic, easy overlapping sequence detection, and clear state transitions, while still respecting the 3-state constraint.

The Mealy output 'z' will be set within the sequential block, depending on current state and input, to reflect immediate detection.

This approach differs architecturally from previous encoding and separates states explicitly for clarity.
