Use a Mealy FSM with three states to detect the sequence "101" in an overlapping manner, but change the state encoding and the state transition approach:

- State 0 (IDLE): no partial match
- State 1 (FOUND_1): matched the first '1'
- State 2 (FOUND_10): matched '10'

In this version, encode states with one-hot style in a 3-bit vector (but only 3 states) for clarity and explicitness. The transitions are:

- From IDLE: if x=1 -> FOUND_1; else remain in IDLE
- From FOUND_1: if x=0 -> FOUND_10; else remain FOUND_1 (since multiple '1's could start sequence)
- From FOUND_10: if x=1 -> output z=1 and go to FOUND_1 (overlapping sequence detection); else go to IDLE

Asynchronous reset is active low and negative edge triggered. Output z is combinational depending on state and input.

The one-hot style encoding eases synthesis optimizations and can improve performance in some techs.
