Implement the Mealy FSM using one-hot state encoding with three flip-flops representing each state explicitly. Use separate always blocks for synchronous state updates with async negative-edge reset and combinational logic for next state and output. This approach simplifies state decoding logic and can speed up state transitions since each state is represented by a dedicated flip-flop, potentially improving timing at some area cost. Overlapping sequence detection is naturally handled by transitions. The output `z` is asserted combinationally when the "101" sequence is recognized.
