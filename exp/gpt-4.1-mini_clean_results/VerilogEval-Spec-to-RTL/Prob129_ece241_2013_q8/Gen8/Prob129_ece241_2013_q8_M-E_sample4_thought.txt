Implement a 3-state Mealy FSM that detects the sequence "101" using one-hot encoding for states to potentially simplify logic and reduce glitches. Use asynchronous negative edge reset to initialize the states. The FSM states represent how many bits of the pattern "101" have been matched so far: S0 (no match), S1 (matched '1'), S2 (matched "10"). The FSM transitions by inspecting the current input and current states, and the output z is asserted in the transition to indicate detection on the '1' that completes "101". Since it's a Mealy machine, output depends on both state and input. One-hot encoding uses 3 bits, but with only 3 states, this is manageable and can reduce combinational logic depth. All sequential logic uses non-blocking assignments, and the output is combinational.
