Implement the Mealy FSM with a single always block triggered on posedge clk and negedge aresetn to handle both state transitions and output in one sequential process, using encoded states as parameters. The FSM will use a 2-bit state register with three states representing how much of the "101" sequence has been matched. The output z will be asserted immediately upon detecting the final sequence bit (Mealy output), allowing overlapping by reusing detected partial sequences in the next states. The asynchronous negative edge reset will synchronously set the FSM to the initial state. The code will be structured for clarity and minimal logic.
