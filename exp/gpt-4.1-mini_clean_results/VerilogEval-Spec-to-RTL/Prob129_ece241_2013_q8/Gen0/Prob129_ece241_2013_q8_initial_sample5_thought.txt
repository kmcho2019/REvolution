Design a 3-state Mealy FSM to detect the sequence "101" on input x with output z asserted when the sequence is detected. Use states to represent the progress of the sequence:

- S0: initial state, waiting for '1'
- S1: received '1', waiting for '0'
- S2: received "10", waiting for '1' to complete "101"

On each clock posedge, update state according to x. Output z is set on transitions that complete the sequence (when in S2 and x=1). The FSM supports overlapping sequences, so after detection, state transitions account for possible overlapping next inputs.

Implement asynchronous negative-edge reset (aresetn), so FSM resets to S0 when aresetn goes low.

All sequential logic triggers on posedge clk, except for async reset triggered on negedge aresetn.
