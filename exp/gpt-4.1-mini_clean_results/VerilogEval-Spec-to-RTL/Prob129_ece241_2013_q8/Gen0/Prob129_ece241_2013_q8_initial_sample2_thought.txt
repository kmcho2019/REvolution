Implement a 3-state Mealy FSM to detect the sequence "101" on input x. The states will track the progress of the pattern:
- S0: no bits matched
- S1: matched '1'
- S2: matched '10'

On each clock's positive edge, transition states based on x, output z = 1 only when sequence "101" is completed at the current input. The reset (aresetn) is an asynchronous negative edge reset, so state is cleared to S0 when aresetn is 0, regardless of clock. Overlapping sequences are supported by appropriate state transitions.
