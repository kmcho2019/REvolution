Implement a 3-state Mealy FSM to detect the "101" sequence on input x. The states track how much of the sequence "101" has been matched so far. On each clock edge, based on the current state and input x, transition to the next state and update output z accordingly. The output z is asserted (logic-1) when the sequence "101" is recognized. The FSM supports overlapping sequences, meaning after detecting the sequence, it should continue from an appropriate state to detect new occurrences. The asynchronous reset is negative edge triggered, so on negedge of aresetn, the FSM resets to initial state. All sequential logic is on positive clock edge.
