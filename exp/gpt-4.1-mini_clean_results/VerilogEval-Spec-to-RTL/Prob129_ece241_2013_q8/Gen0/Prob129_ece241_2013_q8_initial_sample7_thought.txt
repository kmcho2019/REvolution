Implement a 3-state Mealy FSM to detect the overlapping sequence "101" on input x. The states represent the progress in matching the sequence:
- S0: initial state, no match yet
- S1: detected '1'
- S2: detected "10"

On each clock positive edge, update state based on input x. On detecting the full sequence "101", assert output z=1 for that cycle. Use asynchronous negative-edge reset (aresetn) to reset the state to S0. The output is combinational, dependent on the current state and input.
