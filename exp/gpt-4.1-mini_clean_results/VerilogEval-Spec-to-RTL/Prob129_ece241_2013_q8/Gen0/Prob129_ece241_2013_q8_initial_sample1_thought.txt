Implement a 3-state Mealy FSM to detect the overlapping "101" sequence on input x. The states represent the progress in matching the pattern: 
- S0: initial state (no match),
- S1: matched '1',
- S2: matched '10'.

On each clock rising edge, the FSM transitions based on the current state and input x. When the sequence "101" is recognized, output z is asserted for that cycle. The FSM supports overlapping sequences and has an asynchronous negative edge reset (aresetn). All sequential logic triggers on the positive clock edge.
