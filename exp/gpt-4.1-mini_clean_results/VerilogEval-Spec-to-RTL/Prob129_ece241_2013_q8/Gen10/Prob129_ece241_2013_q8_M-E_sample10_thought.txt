Use a one-hot encoding FSM with 3 states where each state indicates the partial recognition progress of the sequence "101". The FSM transitions on the positive clock edge with asynchronous negative-edge reset. To implement the Mealy output behavior, generate the output z combinationally based on the current state and the input x, asserting z when the sequence "101" is detected at the current input. Overlapping sequences are handled by proper state transitions that allow the FSM to stay in or move to states that remember past inputs. This approach trades minimal state-bit width for simplicity in state transition logic and may improve timing by leveraging one-hot encoding while preserving a clean separation of state register, next state logic, and combinational output logic.
