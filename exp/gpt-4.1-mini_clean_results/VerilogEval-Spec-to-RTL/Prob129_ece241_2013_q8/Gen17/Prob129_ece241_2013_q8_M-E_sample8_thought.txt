I will design a Mealy FSM with three states encoded as 2-bit registers, but instead of encoding states as binary numbers, I will encode them in one-hot style using 3 bits for clarity and simplicity, despite the problem only allowing 3 states (3 bits suffice). This makes the next-state and output logic very straightforward.

The states represent how much of the "101" pattern has been matched:
- S0: initial state, no match yet (one-hot 001)
- S1: matched '1' (one-hot 010)
- S2: matched "10" (one-hot 100)

The FSM transitions:
- From S0, if x=1, go to S1; else remain in S0.
- From S1, if x=0, go to S2; if x=1, remain in S1.
- From S2, if x=1, output z=1 (pattern detected), and go to S1 (for overlapping detection); else go to S0.

The output z is Mealy type: high when in S2 and input x=1, indicating detection of "101".

The asynchronous reset is triggered on the negative edge of aresetn (active low), immediately setting state to S0.

This one-hot style FSM is easy to decode and can have very fast logic transitions, potentially improving timing and making next-state logic clearer and compact. Using 3 bits for state is still minimal for 3 states and allowed by the problem since only the number of states matters, not the number of bits. All sequential logic is positive-edge triggered on clk.
