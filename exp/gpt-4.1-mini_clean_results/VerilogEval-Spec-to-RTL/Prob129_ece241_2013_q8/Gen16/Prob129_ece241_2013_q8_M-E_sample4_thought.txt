Implement the Mealy FSM with three states using one-hot encoding for simplicity, where each state is represented by a single flip-flop. Use the asynchronous negative edge reset to initialize to the initial state. The output z is asserted combinationally based on the current state and input, which fits the Mealy model. The FSM transitions directly on input x, and overlaps sequences by proper state transitions. This one-hot encoding reduces decoding logic complexity and may improve timing at the cost of slightly more flip-flops. Output is computed separately in a combinational always block for clarity.
