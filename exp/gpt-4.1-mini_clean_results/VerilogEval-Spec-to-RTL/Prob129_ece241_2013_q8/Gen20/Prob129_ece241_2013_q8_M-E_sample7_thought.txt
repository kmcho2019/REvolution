Use a one-hot encoded Mealy FSM with 3 states implemented as individual flip-flops for clarity and fast decoding. The FSM asynchronously resets on the negative edge of aresetn. The states correspond to detecting partial progress in matching "101": S0 (waiting for '1'), S1 (matched '1'), and S2 (matched "10"). State transitions are done by enabling only the appropriate state bit each clock cycle. The output z is asserted combinationally when the FSM is in state S2 and input x is 1, indicating the full "101" sequence detected with overlapping sequences properly handled by transitioning back to S1. Using one-hot encoding simplifies the next-state logic to just combinational expressions for each state bit, which can be more efficient in some FPGA architectures, and keeps the design conceptually clean and easy to verify.
