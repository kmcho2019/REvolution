Implement the Mealy FSM using one-hot state encoding with exactly three states representing the progress in matching "101". This will simplify next-state logic by using separate state flip-flops, potentially improving timing at the cost of slightly more area. 

The FSM states are:
- S0: initial state, no bits matched yet.
- S1: detected '1'.
- S2: detected '10'.

On each clock edge (with asynchronous negative edge reset), update the state flip-flops accordingly. The output z is combinational, asserted only when in state S2 and input x=1 (detecting the final '1' of the "101" sequence). Overlapping sequences are handled by properly transitioning back to S1 after detection, enabling immediate recognition of new sequences starting with '1'.

This approach separates each state into its own bit, making next-state logic expressions straightforward. The asynchronous reset clears all states to zero, and the FSM starts in S0. All sequential logic is positive-edge clocked as required.
