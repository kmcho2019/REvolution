Implement the FSM with one-hot encoding using three flip-flops for each state to potentially improve speed by simplifying decoding logic. Use a single combinational always block for both next-state and output logic to tightly integrate Mealy output with state transitions. The asynchronous reset remains negative-edge triggered on all state flip-flops. The FSM states represent partial sequence matches: IDLE (no match), STATE_1 (matched '1'), STATE_10 (matched "10"). The output z asserts when the next input bit completes "101". Overlapping detection is naturally supported by state transitions that loop back correctly. This architectural change trades minimal area increase for potentially faster clock frequency and cleaner Mealy output integration.
