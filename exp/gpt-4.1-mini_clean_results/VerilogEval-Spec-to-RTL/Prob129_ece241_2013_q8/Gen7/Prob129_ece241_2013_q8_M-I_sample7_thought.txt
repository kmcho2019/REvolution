To improve PPA, convert the FSM to a one-hot encoding which can reduce combinational logic depth and potentially improve timing. Since we have only 3 states, one-hot uses 3 flip-flops but often benefits timing in FPGA and some ASIC flows. We'll keep the asynchronous negative-edge reset as required. To minimize power, the one-hot encoding reduces logic switching complexity. We'll also separate state register update (sequential) from next-state and output logic (combinational) clearly with non-blocking assignments in sequential block and blocking in combinational block for clarity and better synthesis. The overlapping sequence detection is maintained using the Mealy output logic. This change should reduce critical path delay and slightly improve timing at the cost of minimal area increase.
