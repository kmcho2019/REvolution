To optimize the existing 3-state Mealy FSM for sequence "101" detection, focus on improving timing and power without increasing area significantly. 

Improvements:
1. Separate output logic (z) from next-state logic by assigning it in a dedicated always block sensitive only to current state and input. This reduces combinational path depth and helps timing.
2. Keep the state encoding binary since only 3 states (2 bits) are needed—binary encoding is minimal area.
3. Use non-blocking assignments consistently in sequential logic and blocking assignments in combinational logic for coding style clarity.
4. Remove redundant default case assignments by covering all states explicitly.
5. Output z should only be asserted exactly when the sequence "101" completes, ensuring minimal switching.
6. Keep the asynchronous negative edge reset for fast reset.

These changes can reduce critical path delay by separating output logic, maintain low power by limiting z switching, and keep area minimal.
