Implement the Mealy FSM with 3 states encoded using one-hot encoding to potentially improve timing by simplifying state decoding. Use a separate combinational always block for output logic that directly depends on the current state and input. Handle the asynchronous negative-edge reset in the state register. The FSM transitions track partial matches of the sequence "101", and the output z is asserted when the sequence is recognized, allowing overlapping sequence detection. The one-hot encoding clarifies states and can improve synthesis results in some technologies.
