Implement the Mealy FSM with three states encoded as two-bit registers, but separate the next state logic and output logic into two distinct combinational always blocks for clarity and potentially better synthesis optimization. Use a synchronous positive edge clock with a negative edge asynchronous reset as specified.

The FSM states:
- S0: initial state, waiting for '1'
- S1: detected '1', waiting for '0'
- S2: detected '10', waiting for '1' to complete '101'

When the "101" sequence is detected, output z is asserted for one cycle.

For overlapping sequences, after detecting "101", transition back to S1 because the last input '1' could start a new sequence.

The output z is purely combinational and depends on current state and input.

This separation can improve clarity and may help with synthesis tools optimizing the logic more effectively.

Also, use non-blocking assignments for sequential logic and blocking assignments for combinational logic as a best practice.
