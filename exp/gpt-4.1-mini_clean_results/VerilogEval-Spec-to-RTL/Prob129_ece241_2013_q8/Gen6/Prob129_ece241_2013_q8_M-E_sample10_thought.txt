Implement a Mealy FSM with 3 states to detect the sequence "101" on input x, asserting output z on the last input of the sequence. Use an encoding that explicitly represents the number of matched bits and the expected next bit. The FSM transitions on posedge clk and asynchronously resets on negedge aresetn.

State meanings:
- S_IDLE: no bits matched yet, waiting for '1'.
- S_1: matched '1', waiting for '0'.
- S_10: matched "10", waiting for final '1' to complete sequence.

To enable overlapping detection, transitions after matching "101" will consider that the last '1' can be the start of a new sequence. Output z is asserted only during the clock cycle when the last '1' in the sequence is input (Mealy style).

All synchronous logic is clocked on posedge clk with an asynchronous negative edge reset on aresetn.
