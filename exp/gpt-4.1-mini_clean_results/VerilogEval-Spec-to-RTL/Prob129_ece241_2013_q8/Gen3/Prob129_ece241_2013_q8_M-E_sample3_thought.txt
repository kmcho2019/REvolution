Implement a 3-state Mealy FSM that detects the sequence "101" on input x, but this time encode states as one-hot signals (3 bits) for clarity and possible FPGA efficiency. The states are:
- S0: no match yet
- S1: matched '1'
- S2: matched '10'

The FSM output z goes high on the clock cycle when the last input bit completes "101". Since it is Mealy, z depends on both state and input. The negative-edge asynchronous reset directly resets the state flip-flops.

On detecting "101" (in S2 with input x=1), output z=1 and transition back to S1 to allow overlapping detection. Use one-hot style state registers updated on posedge clk or negedge aresetn. The combinational logic sets next states and output.

This different architectural style uses explicit one-hot signals rather than an enumerated type, showcasing an alternative coding style.
