Implement the Mealy FSM using one-hot state encoding with three flip-flops, each representing one state. The FSM asynchronously resets on the negative edge of aresetn. The next state and output logic are computed in a single always_comb block for clarity. The output z is asserted when the FSM detects the sequence "101" on the input x, and overlapping sequences are supported. The one-hot encoding simplifies decoding and can potentially reduce combinational logic depth.
