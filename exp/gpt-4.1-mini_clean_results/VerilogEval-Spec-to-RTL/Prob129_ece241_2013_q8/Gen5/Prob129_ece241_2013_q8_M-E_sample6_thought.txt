Implement a 3-state Mealy FSM for the sequence "101" using a different state encoding and transition logic:

States:
- S0: no relevant bits matched yet
- S1: last input was '1' (potential start of sequence)
- S2: last inputs were "10"

Transitions:
- S0:
  - if x=1: go to S1
  - else: stay in S0
- S1:
  - if x=0: go to S2
  - if x=1: stay in S1 (still a potential start)
- S2:
  - if x=1: output z=1 (sequence "101" detected), go to S1 (to detect overlapping)
  - else: go to S0

Output z is Mealy type, combinationally derived from current state and input.

Use a synchronous process on posedge clk and async negative edge reset aresetn to update state.

Use non-blocking assignments in sequential always block and blocking assignments in combinational logic for clarity.

This design differs by using a different state naming and encoding, and separating output generation explicitly from next-state calculation.
