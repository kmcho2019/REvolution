To improve the PPA metrics of the existing FSM design, the following optimizations are considered:

1. State Encoding Optimization:
   The original design uses binary encoding with 2 bits for 3 states. Since there are only three states, one-hot encoding is a good choice to reduce combinational logic complexity and potentially increase maximum clock frequency (improving timing slack).
   
2. Simplify Next-State and Output Logic:
   With one-hot encoding, state decoding is simpler because each state is represented by a single bit, reducing logic depth and switching activity.

3. Retain Mealy Machine Style:
   Keep the output z combinational and dependent on current state and input, which helps timing and output latency.

4. Maintain asynchronous active-low reset on the state registers.

One-hot encoding will use 3 flip-flops (slightly more area) but often improves timing slack significantly and can reduce dynamic power due to simplified combinational logic. For such a small FSM, the area overhead is minimal, and the PPA can improve overall.

Summary: Change state encoding to one-hot, refactor combinational logic accordingly, and keep the same FSM behavior and interface.
