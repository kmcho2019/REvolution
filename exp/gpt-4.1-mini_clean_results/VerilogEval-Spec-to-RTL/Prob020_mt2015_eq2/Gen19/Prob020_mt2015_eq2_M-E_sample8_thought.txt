Instead of using the built-in equality operator, I will explicitly implement the equality check using bitwise XOR and NOR gates. Specifically, for each bit of A and B, I will XOR the bits, then NOR the result of these XORs to produce the final output. This approach shows the underlying logic explicitly and may be instructive in hardware design courses or when a gate-level representation is desired.

The logic is:
- For each bit pair A[i], B[i], compute bit_xor = A[i] ^ B[i]
- If both bits are equal, bit_xor is 0.
- For all bits, OR the XOR results; if any bit differs, OR will be 1.
- Finally, output z = ~ (OR of all bit_xor results), so that z = 1 only when all bits are equal.

This method explicitly shows how equality can be implemented with basic logic gates.
