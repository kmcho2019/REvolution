Instead of using the direct equality operator, I will implement the equality check by explicitly comparing corresponding bits and combining the comparison results using AND gates. This approach breaks down the equality into bitwise comparison of A[1] with B[1] and A[0] with B[0]. The output z is asserted only if both pairs of bits match.

This method:
- Shows explicitly how equality can be built from bit-level comparisons.
- Is functionally equivalent to the equality operator but gives clear gate-level intuition.
- Might be useful for educational purposes or when explicit control of bitwise comparison is needed.

The module remains minimalistic but demonstrates an alternative architectural approach without using the '==' operator.
