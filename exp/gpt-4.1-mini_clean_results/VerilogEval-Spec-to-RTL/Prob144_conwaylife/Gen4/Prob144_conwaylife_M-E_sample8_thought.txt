Implement the 16x16 toroidal Game of Life using a line-buffering approach and a finite state machine that processes one row per clock cycle over multiple clock cycles. Instead of computing all next states in parallel, this design reads three consecutive rows at a time, sliding across columns with wrap-around to calculate neighbor sums per cell sequentially. The next states for an entire row are stored in a shift register and written back into a dual-port RAM representing the grid. On the next clock cycle, the FSM advances one row down, updating that row's states based on neighbors. Loading initializes the entire RAM with the input data. This approach trades off latency (taking 16 cycles per generation) for reduced combinational complexity and hardware reuse, reducing area and improving maximum clock frequency while maintaining the exact toroidal neighbor rules.
