Implement the 16x16 toroidal Game of Life using a line-based approach to reduce complexity: store the current grid in a 2D register array for clearer indexing. On each clock, if load is high, load the input data into the 2D grid synchronously. Otherwise, compute the next state row by row, using three rows at a time (previous, current, next) to calculate neighbors with wrap-around indexing. This reduces memory and logic complexity compared to fully combinational neighbor sum across the whole grid at once.

To handle wrap-around:
- Rows wrap modulo 16.
- Columns wrap modulo 16.

For neighbor summation:
- For each cell, sum the 8 neighbors by accessing the three rows (previous, current, next) and the three columns (left, current, right), wrapping indices as needed.
- Apply the rules as given.

Finally, flatten the 2D state back into a 256-bit vector for output. This approach minimizes multiplications in indices (uses shifts and modulo), confines neighbor sum to a small local window, and distributes logic per row, improving clarity and possibly synthesis results.
