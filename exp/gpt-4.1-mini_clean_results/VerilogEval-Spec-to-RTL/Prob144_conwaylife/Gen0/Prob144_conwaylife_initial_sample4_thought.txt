Implement a 16x16 toroidal Game of Life cell update in Verilog. On each clock edge, if load is high, load the input data into q. Otherwise, compute the next state of each cell based on neighbor counts. The neighbor count for each cell is the sum of its eight neighbors, considering wrap-around at edges. Update rules are: 
- 0 or 1 neighbors: cell=0
- 2 neighbors: cell unchanged
- 3 neighbors: cell=1
- 4+ neighbors: cell=0

Store the current state in a 256-bit register and update it every clock cycle. Implement neighbor counting with wrap-around using modular arithmetic. Output the current state as q.
