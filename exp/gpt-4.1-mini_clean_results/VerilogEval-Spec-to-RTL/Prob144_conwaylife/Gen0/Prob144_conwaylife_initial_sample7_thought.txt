Implement a 16x16 toroidal Game of Life on a 256-bit vector. On each clock edge, if load is high, load the input data into the state q. Otherwise, calculate the next state of each cell based on its 8 neighbors using toroidal wrapping. The neighbors' indices wrap around edges by modulo 16 in both row and column directions. For each cell, count live neighbors; apply the rules:

- If neighbors < 2 => cell dies (0)
- If neighbors == 2 => cell stays the same
- If neighbors == 3 => cell becomes alive (1)
- If neighbors > 3 => cell dies (0)

Implement the neighbor count using combinational logic and assign next state accordingly. Update q every clock on positive edge.
