Implement a 16x16 toroidal Game of Life-like cellular automaton with synchronous load and update each clock. Store the current state in a 256-bit register `q`. On `load` high, load the input `data` into `q`. Otherwise, compute the next state of each cell based on the number of alive neighbors (considering wrap-around) and apply the update rules as given. Use a combinational process to compute next state from current `q`. Represent the 2D grid as a 1D vector, mapping row-major order with wrap-around indices for neighbors.
