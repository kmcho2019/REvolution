Implement a 16x16 toroidal Game of Life on a 256-bit vector. On a load signal, synchronously load the input data to q. Otherwise, at each clock cycle, compute the next state of each cell according to the rules given, based on the count of alive neighbors wrapping around the edges. Since the input and output are 256-bit vectors, represent the board as a 2D array (16x16) internally for clarity, compute next state, then flatten back to the 256-bit output. The neighbors count is done by checking all 8 neighbors with wrap-around using modulo arithmetic for indices.
