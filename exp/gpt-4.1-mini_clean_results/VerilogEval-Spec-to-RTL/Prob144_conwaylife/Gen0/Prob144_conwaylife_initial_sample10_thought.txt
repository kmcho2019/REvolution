Implement a synchronous 16x16 Game of Life toroidal grid update module. On a positive clock edge, if load is high, load input data into the grid state q. Otherwise, compute the next state of each cell based on its 8 neighbors using wraparound indexing for toroidal addressing. For each cell, count alive neighbors, then apply the rules:

- 0-1 neighbors: cell dies (0)
- 2 neighbors: cell stays the same
- 3 neighbors: cell becomes alive (1)
- 4+ neighbors: cell dies (0)

Implement neighbor counting with modular arithmetic using 4-bit indices and wraparound. The grid is stored in a 256-bit vector q with rows packed sequentially. The update is performed combinationally and then registered on the next clock edge.
