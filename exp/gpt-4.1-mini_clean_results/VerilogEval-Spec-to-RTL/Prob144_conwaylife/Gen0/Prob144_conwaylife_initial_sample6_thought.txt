Implement a 16x16 grid game of life on a toroidal surface using a 256-bit vector to represent the grid. On each clock cycle, if load is high, load the input data into q synchronously. Otherwise, compute the next state of each cell based on the given neighbour rules. Use modular arithmetic to wrap indices for neighbours. To compute neighbour count for each cell, iterate over all 8 neighbours using wrap-around indexing, sum their states, and apply the update rules:
- 0-1 neighbours: cell dies (0)
- 2 neighbours: cell remains same
- 3 neighbours: cell alive (1)
- 4+ neighbours: cell dies (0)
The implementation uses combinational logic to compute the next state vector from the current state vector, then registers it on the clock edge.
