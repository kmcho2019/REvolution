To improve PPA (Performance, Power, Area), reduce the large combinational logic that computes the entire grid update in one clock cycle by pipelining the neighbor counting and update over multiple clock cycles. We can process one row per clock cycle, storing the intermediate state in a temporary register array. This reduces critical path delay since only one row's neighbors are counted each cycle, lowering combinational fan-in and logic depth.

- Introduce a row counter to process rows sequentially.
- On load, load entire grid at once.
- When not loading, each clock cycle updates one row of the grid in a temporary register.
- After 16 cycles, the entire grid updates.
- Use a separate register to accumulate the next grid state.
- This pipeline spreads computation and reduces peak power and area by reusing neighbor logic.
- Maintain toroidal wraparound logic.
- Output q is updated only after all rows are computed.
