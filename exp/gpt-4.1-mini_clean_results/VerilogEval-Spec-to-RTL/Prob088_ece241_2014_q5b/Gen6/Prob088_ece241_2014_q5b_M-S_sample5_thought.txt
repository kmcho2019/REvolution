Since the FSM has only two states and uses one-hot encoding, it can be implemented with two state bits where only one bit is set at a time. The asynchronous active-high reset initializes the FSM to state A (state bits = 2'b01). The next-state logic and output can be derived directly from the current state and input using simple combinational logic without case statements. This approach simplifies the design and reduces unnecessary case constructs, keeping the asynchronous reset and positive-edge clock intact.
