Implement the Mealy FSM with true one-hot encoding using two flip-flops, one for each state: state_A and state_B. On asynchronous reset, state_A=1 and state_B=0. State transitions are encoded so that only one flip-flop is set at a time, ensuring one-hot. The next state logic uses combinational logic to drive the two state bits exclusively. Outputs depend on current state and input x per Mealy logic. This structure enhances clarity and strict adherence to the one-hot requirement, simplifying state decoding and making timing predictable.
