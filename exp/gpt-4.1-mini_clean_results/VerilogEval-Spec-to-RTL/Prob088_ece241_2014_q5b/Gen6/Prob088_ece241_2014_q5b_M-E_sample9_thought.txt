Implement the Mealy FSM using explicit one-hot encoding with two state flip-flops (A and B). The asynchronous reset sets A=1 and B=0. The state transitions and output are realized with simple combinational logic on the one-hot state bits and input x, which reduces logic depth. The output z is generated combinationally based on current state and x per the given truth table. Using one-hot encoding simplifies next-state logic to only simple AND/OR gates without a case statement. This straightforward approach strictly follows the problem's one-hot requirement and asynchronous reset semantics.
