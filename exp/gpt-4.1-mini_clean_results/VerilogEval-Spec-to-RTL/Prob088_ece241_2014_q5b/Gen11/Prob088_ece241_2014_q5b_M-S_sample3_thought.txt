Since the FSM has only two states, and one-hot encoding for two states typically uses two flip-flops with only one bit high at a time, we can simplify the state representation by using a 2-bit register where each bit corresponds directly to one state. Using two flip-flops as per one-hot encoding:

- state[0] = 1 means state A
- state[1] = 1 means state B

On reset, we set state to 2'b01 (state A active). Only one bit is set at a time, ensuring one-hot property.

Next state logic and output (Mealy) are encoded combinationally based on current state and input.

This approach removes the need for a separate next_state register by directly driving the state flip-flops using combinational next state logic inside the sequential block. It keeps asynchronous active-high reset and positive clock edge triggering. Using non-blocking assignments in the sequential block and blocking assignments in combinational logic maintains clarity.

This explicit one-hot style with two bits matches the problem requirement clearly, is still simple, and the logic is straightforward to follow.
