Since the FSM has only two states and the problem states "implement using a one-hot encoding," the simplest one-hot encoding uses two flip-flops representing states A and B. However, the original solution's next-state logic can be simplified by removing redundant terms.

Observing the transitions:
- From A: next_A = stay in A if x=0; else go to B
- From B: always stay in B

This means that if currently in B, stay in B (state_B = 1), and state_A = 0.

Thus, next_A = state_A & ~x;  
next_B = ~next_A (since the FSM must be either in A or B)

Using this logic, the next state signals can be simplified to a complement pair, which reduces logic and improves readability. The rest remains the same with asynchronous reset and Mealy output logic.

This approach preserves the one-hot encoding, meets the spec, and reduces complexity while keeping clear logic separation.
