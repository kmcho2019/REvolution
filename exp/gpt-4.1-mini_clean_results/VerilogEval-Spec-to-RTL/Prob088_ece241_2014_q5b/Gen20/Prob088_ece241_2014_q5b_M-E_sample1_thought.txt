Implement the two-state Mealy FSM with a fully one-hot encoded two-bit register, where each bit explicitly corresponds to a state: state_A = 2'b01 and state_B = 2'b10. On asynchronous active-high reset, the FSM initializes to state A (2'b01). 

The next-state logic is derived combinationally from current state and input `x`: from A, transition to B if x=1, stay otherwise; from B, always remain in B. This explicit two-bit one-hot encoding simplifies state decoding and makes FSM extension easier.

The Mealy output `z` is generated combinationally based on current state and input according to the FSM: z=1 if in A and x=1, or in B and x=0; else 0. The one-hot encoding allows easy output decoding using bit-wise operations.

This design emphasizes clarity and scalability, trading minimal bit-width for explicitness, maintaining asynchronous reset and positive-edge clocked state register.
