Implement a strict two-bit one-hot FSM encoding with separate flip-flops for state_A and state_B. On reset, state_A is 1 and state_B is 0. Next state logic transitions from A to B when x=1, and stays in B thereafter. State transitions and output z are computed combinationally. The output z depends on both state and input (Mealy): z=1 when in A and x=1, or in B and x=0. Use asynchronous active-high reset on both state bits. This design follows classic one-hot FSM style with explicit mutually exclusive states and clean combinational next state and output logic.
