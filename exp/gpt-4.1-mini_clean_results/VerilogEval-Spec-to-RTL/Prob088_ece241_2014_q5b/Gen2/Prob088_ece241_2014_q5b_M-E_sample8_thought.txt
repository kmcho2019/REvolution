Implement the Mealy FSM with proper one-hot encoding using two flip-flops, one for each state (A and B). The asynchronous active-high reset clears the B state flip-flop and sets A state flip-flop on reset. On each clock edge, transition the states according to input x: remain in A if x=0, else move to B. Once in B, remain in B regardless of x. The Mealy output is combinationally generated from the current state and input as specified. Using one-hot encoding simplifies the next-state logic and output generation to simple gate-level expressions, potentially improving timing and clarity.
