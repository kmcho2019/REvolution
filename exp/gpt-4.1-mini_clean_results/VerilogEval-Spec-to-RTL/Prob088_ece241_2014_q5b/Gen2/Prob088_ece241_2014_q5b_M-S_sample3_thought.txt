Since there are only two states, a single bit is sufficient for the one-hot encoding: '1' for state A and '0' for state B (or vice versa). Using a single-bit register reduces complexity and area. The asynchronous reset sets the FSM into state A ('1'). The next state and output logic can be directly derived from state and input x, with simple combinational logic expressions without case statements, further simplifying the code while preserving the original Mealy FSM functionality.
