Implement the Mealy FSM using true one-hot encoding by representing each state as a separate flip-flop bit. Use separate registers for each state's bit, with asynchronous reset forcing the state A flip-flop high and state B low. Next-state logic will be expressed with combinational logic for each state's flip-flop input, derived from current states and input x. The output z will also be derived combinationally from the one-hot state bits and input x. This approach eliminates state encoding comparisons, leading to simpler and clearer one-hot logic.
