Implement the Mealy FSM with explicit one-hot encoding using separate state flip-flops for states A and B. Use a sequential always block with asynchronous active-high reset to maintain state bits. Then compute next state and output signals using combinational logic based on the current one-hot state bits and input x. This explicit one-hot approach simplifies next state and output logic, improves clarity, and matches the requirement of one-hot encoding more directly. The asynchronous reset directly sets the A state flip-flop, clearing others.
