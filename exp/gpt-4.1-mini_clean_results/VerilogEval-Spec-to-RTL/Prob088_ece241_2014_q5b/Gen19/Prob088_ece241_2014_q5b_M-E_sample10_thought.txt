Implement the two-state Mealy FSM using a one-hot encoded state register with two flip-flops. Instead of assigning next state as a vector, use explicit combinational next state signals for each state bit to clearly separate combinational and sequential logic. The output z is directly derived as the AND of being in state A and input x, or state B and inverse of x, reflecting the Mealy output conditions. The asynchronous reset clears both state bits except state A to ensure one-hot reset to A. This structure emphasizes explicit next state logic and output combinational logic, which can improve clarity and help synthesis.
