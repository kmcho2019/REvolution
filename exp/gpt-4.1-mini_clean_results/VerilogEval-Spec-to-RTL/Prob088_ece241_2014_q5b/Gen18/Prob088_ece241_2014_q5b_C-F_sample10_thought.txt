Fuse the compactness and simplicity of encoding the FSM states as a single 2-bit one-hot register from Example 1 with the explicit and clear next-state logic expressions from Example 2. This hybrid approach uses a 2-bit one-hot state register but defines next_state signals explicitly for each state bit, improving readability and synthesis friendliness. The asynchronous active-high reset initializes state A. The output logic remains combinational Mealy, dependent on current state and input x, with the minimal boolean expression z = x when in A, else ~x when in B. This design balances concise RTL, clarity in next-state logic, and efficient one-hot encoding for better maintainability and potentially improved PPA.
