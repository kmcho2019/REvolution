Since the FSM has only two states, using one-hot encoding with two flip-flops is inefficient. Switching to binary encoding with a single state bit reduces area and potentially power. The reset remains asynchronous active-high. The Mealy output is directly derived from the current state and input, as before. State transitions are simplified with a single bit register, improving critical path and area. The asynchronous reset is maintained on the state register. This reduces flip-flop count and combinational logic complexity while preserving functionality.
