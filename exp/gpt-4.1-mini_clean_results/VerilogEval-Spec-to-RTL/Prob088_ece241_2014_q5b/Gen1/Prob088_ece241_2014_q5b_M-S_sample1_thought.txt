Use a single-bit one-hot state encoding (state_A) since there are only two states: A (state_A=1) and B (state_A=0). This reduces state register width and simplifies next-state logic. Next state is simply state_A <= (state_A && ~x) || (~state_A && 0), which simplifies to state_A = (state_A && ~x). Output z is 1 when in A and x=1, or in B and x=0, expressed compactly. Asynchronous reset sets state_A to 1 (state A).
