Implement the Mealy FSM using an enumerated parameter for the two one-hot states encoded as a 2-bit register. Use a single always block with asynchronous reset for state update. The next state logic and output z are computed combinationally within the same always block by decoding the one-hot encoded state vector. This approach leverages a 2-bit state register where only one bit is set at a time (one-hot), but packs the state bits into a vector to make the code cleaner and slightly more scalable. The asynchronous reset sets state to A (01). The output z is assigned directly based on current state and input x, following the Mealy FSM rules. This structured method cleanly separates next state and output logic, and uses one-hot encoding as requested.
