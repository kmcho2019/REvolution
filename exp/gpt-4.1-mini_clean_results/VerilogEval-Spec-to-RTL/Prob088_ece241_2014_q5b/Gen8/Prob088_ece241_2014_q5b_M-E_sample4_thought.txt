Use a single 2-bit register to hold the one-hot state encoding where bit 0 represents state A and bit 1 represents state B. On asynchronous reset, load the register with 2'b01 for state A. Implement the next state and output logic combinationally using a priority encoder style: the next state is directly assigned by combinational logic depending on current state and input x. The output z is generated as a combinational function of current state bits and input x, following the Mealy FSM specification. This method keeps one-hot encoding in a 2-bit vector, making state manipulation and updates clear and concise while maintaining asynchronous reset semantics and minimal logic gates.
