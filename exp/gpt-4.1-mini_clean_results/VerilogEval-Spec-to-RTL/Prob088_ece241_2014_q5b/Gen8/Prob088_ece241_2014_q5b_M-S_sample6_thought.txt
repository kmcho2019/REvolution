The FSM has only two states, so we can simplify the one-hot encoding by using a 2-bit register with one-hot style, but encoded as a single bit since only two states exist (A=0, B=1). This reduces flip-flop count from two to one without losing clarity, as one bit can represent a one-hot state in this case (state_A=~state_bit, state_B=state_bit). We will keep asynchronous active-high reset, reset to state A (0).

Next state logic and output can be derived directly from the current state bit and input:

- next_state = (state == A && x == 1) ? B : B if state==B else A
  From diagram, once in B, always in B.

So,

- next_state = state | x  (since from A if x=1 then B, else A; from B always B)

Output z (Mealy):

- In A: z = x

- In B: z = ~x

So z = (state) ? ~x : x

This reduces hardware: 1 flip-flop instead of 2, simpler logic, while still representing states one-hot encoded since only one bit is asserted at a time.

This solution simplifies the design while preserving the original functionality and reset behavior.
