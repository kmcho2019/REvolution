Simplify the one-hot FSM implementation by using a 2-bit state register with only one bit set at a time (one-hot). Use a single always block with asynchronous reset for state updates. Compute next states directly without inversions by encoding states as state = 2'b01 for A and 2'b10 for B. The next state logic is straightforward: stay in A if x=0, go to B if x=1; once in B, stay in B regardless of x. Output z is combinational and directly derived from current state and input, matching Mealy outputs. This reduces code complexity and avoids unnecessary inversions or redundant signals.
