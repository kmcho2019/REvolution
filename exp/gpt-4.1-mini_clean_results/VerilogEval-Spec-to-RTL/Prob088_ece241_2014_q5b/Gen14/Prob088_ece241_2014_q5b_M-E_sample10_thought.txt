Implement the two-state Mealy FSM with one-hot encoding using two flip-flops: state_A and state_B. Only one flip-flop is asserted at a time, representing the current state. On asynchronous reset, state_A is asserted (state A). 

Define next state logic explicitly for each state:
- From state A: next state is A if x=0, else B if x=1.
- From state B: stay in B regardless of x.

Output z depends on both current state and input x per Mealy specification:
- z=0 when in A and x=0
- z=1 when in A and x=1
- z=1 when in B and x=0
- z=0 when in B and x=1

This approach uses two flip-flops for clarity and strictly one-hot coding, directly encoding state transitions and outputs as combinational logic, with asynchronous reset and positive edge clock trigger for the flip-flops.
