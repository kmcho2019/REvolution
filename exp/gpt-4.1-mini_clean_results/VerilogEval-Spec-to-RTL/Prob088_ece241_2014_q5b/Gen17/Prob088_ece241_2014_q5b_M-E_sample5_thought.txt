Use two flip-flops representing one-hot states A and B, but encode the FSM by defining the next state for each flip-flop explicitly without deriving one from the other. Implement asynchronous active-high reset to initialize the FSM in state A. The output z is Mealy-type and depends on current state and input x as follows: when in A, z = x; when in B, z = ~x. The next-state logic is defined with clear conditions:

- state_A next = state_A & ~x
- state_B next = (state_A & x) | state_B

This direct next state logic avoids computing any complement of signals to reduce logic depth. The output is combinationally generated from state and input. This approach cleanly separates state registers and logic, making the design easy to understand and efficient.
