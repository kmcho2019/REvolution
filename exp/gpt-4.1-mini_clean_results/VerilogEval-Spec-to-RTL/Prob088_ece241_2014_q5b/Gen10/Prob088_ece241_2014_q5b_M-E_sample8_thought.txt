Use a full two-flip-flop one-hot encoding for states A and B to explicitly represent each state with its own flip-flop, simplifying state decoding and making the FSM structure very clear. On asynchronous active-high reset, state_A is set to 1 and state_B is cleared to 0.

Define the next state and output logic in a single always_comb block: 
- From state A: if x=0, remain in A; if x=1, transition to B.
- From state B: always remain in B regardless of x.
Output z is a Mealy output: 
- z=1 when transitioning from A on input x=1 or remaining in B with x=0.
- z=0 otherwise.

This approach matches strict one-hot encoding conventions and makes state transition and output logic very explicit. The output z is combinational and based on current state and input, preserving Mealy behavior. This design uses two flip-flops, which is acceptable for small FSMs where clarity and explicitness are preferred, and it separates state encoding cleanly.
