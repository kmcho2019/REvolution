Implement the FSM with explicit two-bit one-hot encoding for the two states: state_A and state_B. Only one of them is high at a time to represent the current state. On asynchronous reset, state_A is set high and state_B low. Next state logic uses combinational always block to determine next states based on input x and current states. Since it is Mealy, output z depends on current state and input x combinationally. This clear separation of states with two flip-flops strictly follows the one-hot encoding requirement.
