Use two flip-flops for true one-hot encoding: state_A and state_B. State A is represented by state_A=1 and state_B=0; state B by state_A=0 and state_B=1. On reset, set state_A=1 and state_B=0. Next state logic is straightforward: from A, if x=1 go to B, else stay in A; from B, always stay in B. Output z is combinational and depends on current state and x as per Mealy machine. Using one-hot encoding with explicit two flip-flops simplifies state decoding and keeps logic clear.
