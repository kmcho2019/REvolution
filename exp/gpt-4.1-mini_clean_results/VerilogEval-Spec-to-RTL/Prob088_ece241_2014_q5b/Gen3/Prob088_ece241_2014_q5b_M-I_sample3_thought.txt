Implement the FSM using true one-hot encoding with two flip-flops: one for state A (state_A) and one for state B (state_B). On reset, state_A=1 and state_B=0. Since only two states exist, these two signals will always be complementary (one-hot). This approach simplifies the next-state and output logic, potentially improving timing by reducing combinational depth. 

Asynchronous active-high reset remains per specification. The next-state logic uses combinational always block with blocking assignments for clarity. Output z is generated combinationally as a Mealy output depending on current state and input x. 

Although area increases by using two flip-flops, the logic is simpler and timing can be improved, which may benefit power by reducing glitching and switching activity in complex combinational logic.
