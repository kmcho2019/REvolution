Implement the FSM with one-hot encoding using a 2-bit state vector instead of separate registers for each state. Encode state A as 2'b01 and state B as 2'b10. Use asynchronous active-high reset to initialize the FSM to state A. Compute next state and output in a single combinational always block for compactness. The output z is Mealy type and depends on both current state and input x. Use non-blocking assignments for sequential logic triggered on the positive edge of clk or asynchronous reset. This approach reduces the number of state registers from two separate flip-flops to a 2-bit register, maintaining one-hot encoding but with potentially simpler and more scalable code.
