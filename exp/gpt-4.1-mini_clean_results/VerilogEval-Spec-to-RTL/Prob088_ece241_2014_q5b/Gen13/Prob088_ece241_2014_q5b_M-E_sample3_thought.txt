Implement the two-state Mealy FSM with explicit one-hot encoding by using two state bits: state_A and state_B, where only one bit is set at a time. Initialize asynchronously to state_A. The next state and output logic follow from the state transitions:

- From state_A: if x=0 stay in A, if x=1 go to B.
- From state_B: always remain in B.

The output z depends on current state and input x as described.

Use an always_ff block with async reset for state registers, and combinational logic for next state and output z. This approach explicitly shows the one-hot encoding with two bits rather than using a single bit inversion, making the state encoding and transitions clear and explicit.
