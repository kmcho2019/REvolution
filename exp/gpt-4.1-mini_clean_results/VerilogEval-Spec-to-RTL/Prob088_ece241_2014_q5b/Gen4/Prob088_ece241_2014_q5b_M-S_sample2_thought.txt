The FSM has only two states and one-hot encoding means using two state bits, one-hot encoded. We can represent state A as 2'b01 and state B as 2'b10. 

The asynchronous active-high reset initializes the FSM to state A. On each clock edge, state updates to next state. 

Next state logic: 
- From state A, if x=1 move to state B else remain in A 
- From B, always remain in B.

Output z (Mealy output) depends on current state and input: 
- z=1 if (state==A and x==1) or (state==B and x==0)
- else z=0

To simplify, use combinational assignments without case statements, keep next state and output logic concise. Use two flip-flops for states to fulfill one-hot encoding. 

This maintains correctness, simplifies combinational logic and meets the one-hot and asynchronous reset specification.
