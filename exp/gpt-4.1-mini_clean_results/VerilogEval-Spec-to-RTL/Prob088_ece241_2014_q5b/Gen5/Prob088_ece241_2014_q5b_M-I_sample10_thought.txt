The current solution uses one-hot encoding with two flip-flops, but actually it encodes the FSM states using a single 1-bit reg (binary encoding), which is already optimal for this 2-state FSM.

To further improve power and area:

- Use a combinational continuous assignment for output z instead of an always block, reducing logic and inference complexity.
- Merge next state and output logic into simpler boolean expressions.
- Explicitly declare state as a 1-bit reg for clarity.
- Keep asynchronous active-high reset as specified.

This reduces combinational logic area, power due to simpler output logic, and slightly improves timing by reducing inferred muxes. The design remains clean, minimal, and correct.
