The FSM has only two states with one-hot encoding: state A and state B. Instead of storing only state A and inferring B, store both states explicitly using two flip-flops (one-hot encoding). This simplifies the next-state and output logic since each state bit corresponds directly to one state. The asynchronous reset sets the FSM to state A (state_A=1, state_B=0). State transitions and output are straightforward with fewer logic operators: next_state_A = state_A & ~x, next_state_B = ~next_state_A, and output z = state_A & x | state_B & ~x. This version uses two state bits explicitly, which slightly increases area but simplifies comprehension and may reduce logic depth.
