Since the FSM only has two states (A and B) and one-hot encoding requires one flip-flop per state, we must keep two state bits. However, given the small FSM, we can represent the state with two bits directly (one-hot encoded) and simplify next state and output logic. We can use two flip-flops: state_A and state_B with exactly one hot at a time. The reset sets state_A=1 and state_B=0. The next state logic can be encoded simply: from A to A if x=0, else to B; from B to B regardless of x. The output is Mealy: z = 1 when (A,x=1) or (B,x=0). This approach clarifies one-hot state encoding explicitly, keeps the asynchronous reset, and simplifies combinational logic while preserving function.
