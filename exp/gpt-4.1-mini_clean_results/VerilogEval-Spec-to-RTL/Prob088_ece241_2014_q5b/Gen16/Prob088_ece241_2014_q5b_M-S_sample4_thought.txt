The FSM has only two states, so we can simplify the one-hot encoding by using a single bit `state_A` to represent state A (1) or B (0). The next state logic is straightforward: stay in A if input `x` is 0; else move to B. Once in B, always remain there regardless of `x`. The output `z` depends on both state and input `x` as a Mealy output. Using asynchronous active-high reset sets state to A. We can write the next state and output logic directly inside a single always block with asynchronous reset, which reduces code lines and complexity by avoiding extra wires and continuous assignments. This approach maintains functionality and clarity while simplifying the code.
