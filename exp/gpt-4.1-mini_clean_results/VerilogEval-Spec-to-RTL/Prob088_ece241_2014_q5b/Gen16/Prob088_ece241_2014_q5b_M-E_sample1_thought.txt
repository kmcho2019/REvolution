Implement the two-state Mealy FSM with one-hot encoding using two separate state bits, state_A and state_B, where only one bit is high at any time. The asynchronous active-high reset sets state_A high and state_B low. The next state logic transitions state_A to itself if x=0, otherwise moves to state_B; state_B remains at state_B regardless of input. The output z depends combinationally on both the current state and input x according to the Mealy FSM: z= x when in state A, and z= ~x in state B. This fully one-hot explicit encoding with two flip-flops clarifies state representation and transition, suitable for educational clarity and straightforward formal verification.
