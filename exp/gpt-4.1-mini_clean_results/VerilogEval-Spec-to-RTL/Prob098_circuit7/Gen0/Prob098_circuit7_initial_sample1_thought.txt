The output q is updated only at the positive edge of clk. From the waveform, q changes based on the input a at the previous clock edge. Specifically, q holds its value if a=0 at the clock edge and toggles (from 1 to 0) when a=1 at the clock edge. Initially q=0 at first clock edge (time 15ns). 
Checking carefully: at 15ns, a=0 and q=1, so it seems that when a=0 q is set to 1, when a=1 q is set to 0.
Actually at 15ns, a=0 and q=1; at 35ns, a=1 and q=1; at 45ns, a=1 and q=0. So q is set to 1 when a=0, set to 0 when a=1.

Thus q = ~a at the positive edge of clk.

We will implement q as a flip-flop that captures the inverted value of input a on each posedge of clk.
