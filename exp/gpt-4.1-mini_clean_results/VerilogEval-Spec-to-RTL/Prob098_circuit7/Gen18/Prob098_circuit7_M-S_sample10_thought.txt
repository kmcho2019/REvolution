The output q at each rising clock edge is just the negation of the input a at that time, stored in a flip-flop. Thus, a single D flip-flop with its input connected to the inverted input 'a' suffices. Since the inverter is a simple combinational gate, we can directly assign the negated input to the register in the always block without extra modules or wires. This reduces code complexity to just one always block implementing the flip-flop with the D input as ~a.
