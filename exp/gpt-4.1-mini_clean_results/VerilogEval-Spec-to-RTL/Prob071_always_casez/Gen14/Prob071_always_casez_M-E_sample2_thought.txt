Implement the priority encoder by leveraging the built-in Verilog function $clog2 and a binary search approach with priority encoding done through a small combinational hierarchy. Specifically, divide the 8-bit input into two 4-bit halves, determine if any bit is set in the lower half. If yes, encode the position within that half; otherwise, encode the position in the upper half and add an offset of 4. This reduces the priority encoding logic depth compared to a linear chain. If no bits are set, output zero.
