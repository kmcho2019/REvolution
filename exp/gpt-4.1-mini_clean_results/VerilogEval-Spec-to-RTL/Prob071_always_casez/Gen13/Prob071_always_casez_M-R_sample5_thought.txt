Refactor the priority encoder from a function-based implementation to a purely combinational assign statement using a casez statement that matches the input vector against masks representing the first set bit. This keeps the same LSB priority and the same output when no bits are set, but replaces the function with a direct combinational logic style. The casez statement checks bit patterns from least to most significant bit with a wildcard 'z' in unused bits to detect the first high bit more structurally. This form is easy to understand, synthesizable, and avoids the chained ternary operators by leveraging pattern matching.
