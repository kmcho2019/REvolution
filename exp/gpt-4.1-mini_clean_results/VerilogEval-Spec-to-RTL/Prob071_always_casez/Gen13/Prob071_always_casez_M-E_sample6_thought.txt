Implement the priority encoder by scanning the input bits from least significant bit (bit 0) to most significant bit (bit 7) inside a combinational always block using a for-loop. Once the first set bit is detected, record its index and stop checking further bits. If no bits are set, output zero. This approach uses simple sequential checking logic with a break mechanism to reduce unnecessary comparisons. It is straightforward, easy for synthesis tools to optimize, and naturally prioritizes the lowest index set bit.
