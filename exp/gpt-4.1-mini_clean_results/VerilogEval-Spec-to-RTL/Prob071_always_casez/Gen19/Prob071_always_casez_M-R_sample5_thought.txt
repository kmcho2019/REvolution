Refactor the priority encoder to use a chain of continuous assign statements with the conditional (ternary) operator instead of an always block. This combinational logic approach implements the same priority logic by directly encoding the priority from LSB to MSB through nested ternary operators. The output is a wire, not a reg, simplifying the interface and making the logic transparent and concise.

This style improves readability by using parallel assignments, maintains combinational behavior, and leverages the synthesizer's optimization of nested ternary operators into priority encoder hardware. It also avoids procedural blocks, which some designers prefer for pure combinational logic.

Functionally, it is equivalent but stylistically distinct, clearly showing priority from LSB to MSB in a single assign statement.
