Implement a priority encoder using a parallel one-hot mask and a priority encoding lookup table. First, create a one-hot mask vector where each bit is set only if the corresponding input bit is high and all lower bits are zero (i.e., it is the first active bit). Then encode this one-hot vector using a combinational case statement that directly maps the one-hot position to its index. This approach minimizes the logic depth by performing the zero-check in parallel for all bits at once, avoiding hierarchical conditionals or recursion, and it is easily scalable and synthesis-friendly.
