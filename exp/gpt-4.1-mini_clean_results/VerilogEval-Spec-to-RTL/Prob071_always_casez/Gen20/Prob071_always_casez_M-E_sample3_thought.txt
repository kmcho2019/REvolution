Implement the priority encoder using a for-loop inside a combinational always block to scan the input bits from LSB to MSB. As soon as the first set bit is found, record its index and exit the loop. If no bits are set, default the output to zero. This method produces clear sequential logic for the priority encoder and easily scales to different widths. It offers straightforward control of the search process and can be optimized by synthesis tools into efficient priority encoder logic. The always block ensures all logic is combinational and the output updates correctly on any input change.
