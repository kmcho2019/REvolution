Implement the priority encoder using a parallel combinational logic approach: generate a one-hot encoded vector representing the positions of set bits, mask out higher bits based on priority (from LSB to MSB), then encode the resulting masked vector to a binary position using a priority encoding combinational function. This approach avoids nested if-else chains and uses bitwise operations and reduction operators, potentially enabling efficient synthesis with minimal logic depth. Specifically:

1. Compute a mask indicating bits set at or below each bit position.
2. Use this mask to isolate the least significant set bit.
3. Convert this one-hot vector to a 3-bit position via a simple binary encoding by checking each bit.
