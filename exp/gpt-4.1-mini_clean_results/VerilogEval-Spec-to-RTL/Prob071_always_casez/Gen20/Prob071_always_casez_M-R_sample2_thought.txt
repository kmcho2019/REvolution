Refactor the priority encoder by replacing the hierarchical nested if-else function with a set of parallel conditional (ternary) operators, using a single continuous assignment. This eliminates the function entirely and uses combinational logic built directly from simple ternary operators chained to check bits from LSB to MSB. If no bits are set, output zero. This approach preserves the binary search priority behavior implicitly by checking bits sequentially, is easy to read, and is synthesis friendly. It also potentially allows better logic optimization in synthesis tools and simpler combinational logic without explicit nested functions.
