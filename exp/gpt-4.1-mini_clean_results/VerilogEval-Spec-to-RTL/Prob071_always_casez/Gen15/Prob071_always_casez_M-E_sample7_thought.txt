Implement the priority encoder using a "one-hot to binary" encoding approach. First, create an 8-bit one-hot vector where only the least significant '1' bit in the input is set and all others cleared. This can be achieved by masking the input with its two's complement (in & (~in + 1)), which isolates the lowest set bit. Next, encode this one-hot vector into a 3-bit binary position output.
