Refactor the priority encoder to use an always_comb block with a casez statement on the input vector to detect the lowest set bit in one pattern-matching operation. This approach replaces the chained ternary conditional assignment with a more compact and readable casez, which directly matches patterns with a single '1' bit starting from LSB upwards. If no bits are set, default to zero. The always_comb block preserves combinational logic semantics while providing clear structure and potentially better synthesis optimizations due to pattern matching, which can also improve maintainability.
