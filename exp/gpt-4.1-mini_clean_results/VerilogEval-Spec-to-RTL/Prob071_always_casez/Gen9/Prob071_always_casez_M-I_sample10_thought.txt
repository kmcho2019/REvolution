To improve PPA, especially delay and power for the 8-bit priority encoder, I will implement the priority encoder using a binary tree approach that reduces the long chain of multiplexers. This approach partitions the input into halves, encodes each half recursively, and selects the lower half's result if it contains any high bits; otherwise, it selects the upper half's result with an offset. This reduces the critical path and switching activity compared to the linear mux chain, leading to improved timing and potentially lower power for small inputs. The output will still be zero if no bits are high.
