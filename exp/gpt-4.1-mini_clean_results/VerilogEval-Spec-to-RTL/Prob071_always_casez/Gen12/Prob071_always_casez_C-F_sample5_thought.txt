This isolates the lowest set bit efficiently. Then encode this one-hot output into a binary position using a compact combinational logic (e.g., a small case statement or arithmetic operation). This fusion yields minimal logic depth, enabling efficient synthesis and better PPA metrics, while maintaining readability and functional correctness. If no bits are set, output zero.

This approach avoids a long priority chain of checks and relies on a simple bit manipulation and small encoder, which is a common and high-performance priority encoder pattern.
