Refactor the priority encoder using continuous assign statements and bitwise operations to generate one-hot signals for each input bit, then use a priority encoding scheme to find the least significant set bit index. This approach eliminates the if-else chain and always block, resulting in a combinational logic implementation that is more suitable for synthesis and potentially better for timing and area. We encode the position by checking each bit with a priority mask, so when the first bit is detected, the corresponding output is assigned. If no bits are set, output zero.
