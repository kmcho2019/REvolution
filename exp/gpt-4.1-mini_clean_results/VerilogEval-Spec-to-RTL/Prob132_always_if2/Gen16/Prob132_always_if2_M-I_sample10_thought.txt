Maintain a single combinational always block with default assignments to prevent latches, but simplify the logic by combining conditions where possible. Since `keep_driving` only changes when `~arrived` is true, otherwise it is zero, and `shut_off_computer` is directly tied to `cpu_overheated`, we can write direct assignments to these outputs using continuous assignments instead of always blocks for better synthesis and power optimization. This reduces unnecessary toggling and removes always blocks for purely combinational signals, improving area and power.
