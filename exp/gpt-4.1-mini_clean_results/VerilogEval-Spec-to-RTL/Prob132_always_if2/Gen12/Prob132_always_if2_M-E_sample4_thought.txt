Instead of using always blocks, implement the logic using continuous assignments for combinational outputs. This approach leverages the simplicity of assign statements to directly drive the outputs without any procedural block, which inherently prevents latch inference and results in clearer, more concise code. The outputs remain reg types to comply with the original interface, but are driven by internal wires assigned via continuous logic, which are then registered. This structure separates combinational logic from output registers, potentially simplifying downstream modifications like adding clocked elements.
