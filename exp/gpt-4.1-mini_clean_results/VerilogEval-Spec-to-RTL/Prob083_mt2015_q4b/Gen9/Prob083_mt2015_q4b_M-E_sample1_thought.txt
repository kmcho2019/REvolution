Implement the output z as a 2-to-1 multiplexer controlled by the input y. When y=0, output z is the inverted value of x; when y=1, output z is set to 1. This matches the waveform: z=1 when y=1 (regardless of x), and when y=0, z=1 only if x=0 (i.e., z = ~x). This approach uses a simple mux structure combining inversion and constant 1, illustrating a different hardware perspective than a direct XNOR, while still achieving the same truth table.
