The original implementation uses a continuous assignment with bitwise XNOR. To refactor with the same functionality but a different structure, I will implement the logic inside a combinational always block that drives a reg output. This approach explicitly shows combinational logic using procedural assignment, which is functionally equivalent but stylistically different. It may help in scenarios where procedural blocks are preferred for ease of extending functionality. This also makes the output a reg type instead of wire, but the logic remains purely combinational.
