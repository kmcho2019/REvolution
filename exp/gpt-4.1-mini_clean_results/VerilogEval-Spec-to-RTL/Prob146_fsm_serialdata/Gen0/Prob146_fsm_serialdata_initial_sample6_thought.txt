I will implement a finite state machine with these states: IDLE, START, DATA, STOP, WAIT_STOP. In IDLE, the FSM waits for the start bit (0). Once start bit is detected, it moves to DATA state to shift in 8 data bits (LSB first). Then it moves to STOP state and checks for a stop bit (1). If stop bit is correct, it outputs the byte and asserts done for one cycle, then returns to IDLE. If stop bit is incorrect, it enters WAIT_STOP state until it finds a stop bit (1) to resynchronize, then goes back to IDLE. The reset is synchronous active high. `out_byte` is valid only when `done` is high.
