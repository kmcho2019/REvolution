Implement an FSM with states: IDLE, START, DATA, STOP, WAIT_STOP. 
- IDLE: Wait for start bit (in=0).
- START: Confirm start bit, then begin capturing data bits.
- DATA: Shift in 8 data bits, LSB first.
- STOP: Check stop bit (should be 1).
  - If stop bit correct: output data, assert done, return to IDLE.
  - Else: move to WAIT_STOP.
- WAIT_STOP: Wait until line goes high (stop bit detected), then go to IDLE.
Use a bit counter for data bits. Use synchronous reset to go to IDLE. 
At each done assertion, out_byte is valid.
