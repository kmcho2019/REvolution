Implement a finite state machine with the following states: IDLE, START, DATA, STOP, and WAIT_STOP. The FSM waits for the start bit (0) from the idle line (1). After detecting the start bit, it collects 8 data bits LSB first on subsequent clock cycles, then checks for the stop bit (1). If stop bit is correct, output the collected byte and assert done. If stop bit is missing, enter WAIT_STOP state and wait for the line to go to 1 (stop bit) before returning to IDLE. Synchronous reset returns FSM to IDLE. out_byte is valid only when done is high.
