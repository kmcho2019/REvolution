Design a finite state machine (FSM) with the following states: IDLE, START, DATA, STOP, WAIT_STOP. In IDLE, wait for the start bit (0). On detecting a start bit, move to START and then immediately to DATA to receive 8 data bits LSB first. Store these bits in a shift register or register one by one each clock. After receiving 8 bits, move to STOP to check the stop bit (1). If the stop bit is correct (1), assert done and output the received byte, then return to IDLE to wait for the next start bit. If the stop bit is not correct (0), move to WAIT_STOP state, in which the FSM waits until it sees a stop bit (line=1) before returning to IDLE to look for the next start bit. The reset synchronously returns the FSM to IDLE, clears done and out_byte. The FSM transitions happen on the positive edge of clk.
