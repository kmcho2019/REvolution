Design a finite state machine with these states: IDLE (line high, waiting for start bit), START (detecting start bit 0), DATA (receiving 8 data bits LSB first), STOP (checking the stop bit is 1), and ERROR (waiting for a stop bit if the stop bit was incorrect). The FSM transitions on clock edges with synchronous reset. When a correct byte is received (stop bit = 1), output the byte and assert done for one clock cycle. If stop bit is incorrect, enter ERROR and wait until a stop bit (logic 1) is found before returning to IDLE.
