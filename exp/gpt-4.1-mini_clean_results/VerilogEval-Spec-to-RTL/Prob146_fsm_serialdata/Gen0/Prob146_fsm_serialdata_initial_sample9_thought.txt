Design a FSM with the following states: IDLE (line idle, waiting for start bit), START (confirmed start bit), RECEIVE (shift in 8 data bits, LSB first), STOP (check the stop bit). When reset is asserted, the FSM returns to IDLE. On IDLE, wait for in == 0 (start bit). On START, confirm in still 0, then move to RECEIVE. In RECEIVE, shift in the 8 data bits on each clock cycle, counting bits received. After 8 bits, go to STOP. In STOP, check if in == 1 (stop bit). If yes, output the assembled byte and assert done for one cycle, then go back to IDLE. If no stop bit detected (in != 1), stay in STOP until in == 1, then return to IDLE. This handles the error condition of missing stop bits by waiting until a stop bit is found before starting again.
