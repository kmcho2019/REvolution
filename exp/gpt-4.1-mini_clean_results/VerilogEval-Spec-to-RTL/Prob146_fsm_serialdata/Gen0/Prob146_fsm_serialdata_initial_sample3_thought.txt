Implement a finite state machine with the following states: IDLE (waiting for start bit 0), RECEIVE (collecting 8 data bits LSB first), STOP (checking for stop bit 1). On reset, go to IDLE. In IDLE, wait for a 0 start bit. When detected, move to RECEIVE state and shift in 8 bits from the input each clock cycle. After 8 bits received, move to STOP state and check if stop bit is 1. If stop bit is 1, output the byte, assert done, and return to IDLE. If stop bit is 0 (error), stay in STOP state until a 1 is detected (stop bit), then return to IDLE without asserting done. The output byte is valid only when done is asserted, otherwise don't-care. The done pulse is one clock wide, synchronous with the clock. The reset is synchronous and active high.
