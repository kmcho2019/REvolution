The design is an FSM with four main states: IDLE (waiting for start bit), RECEIVE (receiving the 8 data bits), STOP (checking for the stop bit), and WAIT_STOP (waiting for the stop bit if the received stop bit was incorrect). 

- IDLE: line is idle at 1, wait for start bit 0.
- RECEIVE: shift in 8 bits, LSB first.
- STOP: check the stop bit (should be 1).
    - If correct, assert done and output data.
    - If incorrect, go to WAIT_STOP.
- WAIT_STOP: wait until stop bit 1 appears to reset and look for a new start bit.

A counter keeps track of the number of received data bits (0 to 7). Output done is asserted for one clock cycle when a byte is received correctly.

Synchronous active-high reset sets the FSM to IDLE.

The input bit stream is sampled at each clk rising edge.

The 8-bit out_byte is valid when done is high.
