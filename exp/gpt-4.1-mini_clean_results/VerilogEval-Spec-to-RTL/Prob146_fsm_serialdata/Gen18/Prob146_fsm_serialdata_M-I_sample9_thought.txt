To improve timing and power, implement the FSM with one-hot encoding to simplify next-state logic and speed up the transition decision. Separate the shift register update into its own always block to shorten the critical path, updating only when receiving data bits. Update the done signal only when a valid stop bit is detected and hold it until next start bit detection to reduce toggling power. Introduce a ready flag to latch the done and output byte to prevent unnecessary updates outside valid byte reception. Synchronous reset clears all state and flags. This approach balances timing, power, and area by easing combinational paths and reducing output toggling.
