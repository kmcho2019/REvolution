Implement the FSM with five one-hot encoded states to clearly separate functionality and reduce combinational logic complexity. Sample the start bit only when the line goes from idle (high) to low, then sample each data bit in subsequent clock cycles. Shift incoming bits into the shift register by placing the new bit in the highest position and shifting down, since the protocol is LSB first and we receive bits serially. After collecting 8 bits, verify the stop bit. If the stop bit is correct (logic high), latch the byte and pulse done for one cycle. If incorrect, enter a "wait for idle" recovery state before restarting. Use synchronous reset to initialize all registers. This approach keeps control logic simple, uses one-hot FSM to minimize combinational overhead, and clearly delineates states to reduce glitching and toggling, possibly improving timing and power.
