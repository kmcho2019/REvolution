The main issue was incorrect bit shifting direction: the problem requires LSB first transmission, so the incoming bit should be placed into the lowest bit, and existing bits shifted toward the MSB. The original code shifted bits in the opposite direction, reversing the byte.

Additionally, the bit_count transition condition was slightly off. Since we count bits from 0 to 7 for eight bits, the FSM should move to STOP state after receiving the 8th bit, i.e., when bit_count == 7 and current bit is sampled.

Also, to ensure proper synchronization, the START state acts as a single-cycle wait after detecting the start bit, no bit shifts happen there.

In the STOP state, if the stop bit is correct (in == 1), assert done and output the byte. If the stop bit is wrong, go to WAIT_STOP state where the FSM waits until in == 1 to resynchronize.

The done signal is asserted for exactly one clock cycle immediately after successful reception.

All sequential logic is synchronous with synchronous reset.

  - The correct is: `data_reg <= {in, data_reg[7:1]};` is MSB first.
