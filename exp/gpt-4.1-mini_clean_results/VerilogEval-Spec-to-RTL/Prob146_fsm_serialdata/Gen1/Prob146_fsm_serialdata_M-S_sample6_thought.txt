Use a simple FSM with three states: IDLE, RECEIVING, and WAIT_STOP.  
- IDLE: Wait for start bit (in == 0).  
- RECEIVING: Shift in 8 data bits, LSB first, one bit per clock cycle. After receiving 8 bits, check the stop bit (in == 1). If valid, output data and assert done. If invalid, go to WAIT_STOP.  
- WAIT_STOP: Wait until in == 1 (stop bit found), then return to IDLE.  

This approach samples one bit per clock cycle, so start bit is detected immediately, data bits captured sequentially with proper LSB-first shift, and stop bit checked directly after data. Synchronous reset moves to IDLE, clears outputs. This is a simpler, clean design with minimal states and straightforward logic.
