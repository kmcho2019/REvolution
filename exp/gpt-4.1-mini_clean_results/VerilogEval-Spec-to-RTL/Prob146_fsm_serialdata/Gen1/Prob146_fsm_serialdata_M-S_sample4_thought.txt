Use a simple FSM with three states: IDLE (wait for start bit 0), RECEIVE (shift in 8 data bits LSB first), STOP (check stop bit 1). When reset, return to IDLE. In IDLE, wait for in==0 (start bit). In RECEIVE, shift in bits by shifting left and placing the new bit at LSB to keep bit order correct. After 8 bits, go to STOP. In STOP, check if in==1 (valid stop bit); if so, output the assembled byte, assert done for one cycle, then return to IDLE. If stop bit is not 1, stay in STOP until it becomes 1. Keep done low otherwise. This minimal FSM simplifies the start bit confirmation and ensures correct bit ordering.
