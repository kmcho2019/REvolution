Implement the FSM using a binary-encoded three-state machine to minimize area and power. The FSM states are IDLE (waiting for start bit), RECEIVE (collecting 8 data bits), and STOP (checking the stop bit). Use a bit counter to track the number of received bits. On detecting the start bit (a low input when idle), clear the bit counter and start shifting bits LSB first into a data register as they arrive each clock cycle. After 8 bits, move to STOP state and check if the stop bit is high. If valid, assert done for one cycle and present out_byte; if invalid, wait in STOP until the line goes idle again (high) before returning to IDLE. Use synchronous reset to clear all registers. This approach reduces flip-flop count, uses a binary FSM encoding for compactness, and simplifies done signal generation by asserting it only when a correct stop bit is received. The data shift is done using a right-shift with the new bit loaded into the MSB position, which aligns with receiving LSB first from the input stream. The design uses synchronous logic only with no combinational loops, facilitating timing closure.
