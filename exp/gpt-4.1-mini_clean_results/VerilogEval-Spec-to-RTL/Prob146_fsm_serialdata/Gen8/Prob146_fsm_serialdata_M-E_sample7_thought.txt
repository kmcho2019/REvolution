Implement a Moore-style FSM with binary encoded states and use a separate bit counter and shift register. The FSM waits in IDLE state for the line to go low indicating a start bit, then transitions to a READ_BITS state where it samples the next 8 bits on consecutive clock cycles. After reading the 8 data bits, it transitions to CHECK_STOP state to verify the stop bit. If the stop bit is valid (high), it asserts done for one clock cycle and outputs the received byte. If invalid, it goes to a RECOVER state where it waits for the line to go high (idle) before restarting. The data is shifted LSB first by shifting the previous bits right and loading the new bit into the MSB position at each cycle during bit reading. All registers use synchronous active-high reset. The done signal is registered and pulses high only one clock cycle immediately after receiving a valid stop bit. This structure uses binary state encoding for area and power efficiency and explicit states for clarity, with minimal combinational logic in outputs, and no unnecessary toggling of outputs outside done pulses.
