Implement a three-state FSM with explicit bit sampling synchronized on clk, using a shift register that shifts in the serial bits from LSB to MSB. Instead of updating counters and registers every clock cycle, use a separate data enable signal to minimize switching. After detecting a start bit, we shift in each bit for 8 cycles, then sample and check the stop bit. If stop bit is correct, latch the data and assert done for one cycle. On stop bit error, wait in an error recovery state until line goes idle (logic 1) before accepting the next start bit. Reset synchronously clears all registers. The done signal pulses high exactly one cycle when data byte reception completes with a valid stop bit. The FSM transitions only on clock edges and input bit sample, ensuring minimal glitching and clear timing. This design separates bit sampling from FSM state changes to improve timing and reduce glitches.
