Implement the UART byte receiver FSM with three states encoded in a binary style (IDLE=0, RECEIVE=1, WAIT_STOP=2) to reduce flip-flop count and simplify logic. Use a bit counter to track received bits and a shift register to accumulate data bits. The start bit detection transitions from IDLE to RECEIVE. During RECEIVE, data bits are shifted in LSB first on each clock. After 8 bits, transition to a STOP_CHECK state to verify the stop bit. If the stop bit is valid (1), assert done for one cycle and output the byte. If invalid, move to WAIT_STOP until the line goes high (idle) before returning to IDLE. done is a one-cycle pulse synchronized with stop bit validation. All registers and signals are clocked synchronously with reset. The shift register shifts right inserting the incoming bit at MSB to implement LSB-first reception. This design simplifies state logic, reduces area via binary encoding, and cleanly handles error recovery.
