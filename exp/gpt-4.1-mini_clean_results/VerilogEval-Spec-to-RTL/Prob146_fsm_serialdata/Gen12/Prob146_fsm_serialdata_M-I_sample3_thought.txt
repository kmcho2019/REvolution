To improve the PPA metrics while preserving functionality, I will:
- Change FSM state encoding from one-hot (4 flip-flops) to binary encoding (2 bits) to reduce area and power.
- Add clock enables to the bit counter and shift register to reduce switching when not receiving data.
- Optimize the done signal so it only updates when asserted or cleared, avoiding unnecessary toggling.
- Implement the data shift register to shift in LSB first by shifting right and placing the serial input at MSB as before but with clear comments.
- Maintain a synchronous active-high reset.
- Preserve the FSM structure: IDLE waits for start bit (0), RECEIVE collects 8 bits, STOP checks stop bit (1), WAIT_STOP waits for line idle.
- Keep done asserted for exactly one clock cycle when a valid stop bit is detected.

This will reduce flip-flop count (from 4 to 2 for FSM), lower toggle rates on bit_count and data_shift registers, and minimize done toggling, improving power and area and potentially timing.
