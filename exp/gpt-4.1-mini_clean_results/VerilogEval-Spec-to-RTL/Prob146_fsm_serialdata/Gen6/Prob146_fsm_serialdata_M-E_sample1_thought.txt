This design uses a two-process FSM: one synchronous always block for state and registers updates and a separate combinational always block to compute next state and outputs. It encodes states in one-hot for simpler decoding and potentially improved timing. The FSM idles waiting for the start bit (0). Once detected, it samples 8 data bits LSB first using a counter. After receiving 8 bits, it checks the stop bit. If the stop bit is valid (1), it asserts done and outputs the byte. If invalid, it enters a recovery state where it waits for the line to return to idle (1) before going back to idle state. The done signal is asserted for exactly one cycle and is only driven when a byte is successfully received. All registers update synchronously on clk with synchronous reset. This separation of combinational next state logic may improve synthesis timing and code clarity. One-hot state encoding can help timing on some FPGAs or synthesis tools. The data shift uses bit insertion at LSB position (shift_reg <= {shift_reg[6:0], in}) to follow LSB-first convention.
