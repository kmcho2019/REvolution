Use a simple FSM with three states: IDLE (waiting for start bit), RECEIVE (shifting in 8 data bits), and STOP_WAIT (checking stop bit and handling error). On reset, go to IDLE. On IDLE, wait for start bit (0). In RECEIVE, shift in bits LSB first for 8 cycles. In STOP_WAIT, if stop bit is 1, assert done and output byte, then return to IDLE; if stop bit is 0, stay in STOP_WAIT until in=1 (stop bit) is seen, then return to IDLE without asserting done. Use only necessary registers, separate next state combinational logic from sequential logic for clarity and potential better synthesis. Only assert done for one cycle when a valid byte is received.
