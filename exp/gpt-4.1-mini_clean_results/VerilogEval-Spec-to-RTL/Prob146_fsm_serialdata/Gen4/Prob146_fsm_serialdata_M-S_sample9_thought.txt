Simplify the FSM by using fewer states and avoiding the explicit next_state variable. Use a minimal state encoding with only three states: IDLE (waiting for start bit), RECEIVE (shifting in 8 data bits), and WAIT_STOP (checking stop bit and error recovery). Combine the CHECK_STOP logic into the WAIT_STOP state by branching immediately after receiving the last data bit. Keep done asserted for one cycle upon a valid byte reception. Shift data bits LSB first by shifting right and inserting new bits at MSB to simplify concatenation. All logic in a single always block synchronous to clk and reset. This reduces state complexity and code size while preserving functionality.
