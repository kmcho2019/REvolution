Implement the receiver FSM using one-hot state encoding for potentially better timing on FPGAs. Introduce a stable sampling approach by sampling bits only on the rising edge of clk after detecting the start bit, assuming the input bits align with clk edges. Use a shift register to accumulate received bits (LSB first). Use a bit counter to track received bits. The FSM states: IDLE (wait for start bit=0), RECEIVE_BITS (shift in 8 bits), VERIFY_STOP (check stop bit=1), ERROR_RECOVERY (wait for line to return to idle=1). Assert done for one cycle right after a correct stop bit is detected and latch out_byte synchronously. Use synchronous active-high reset. This design has clearly separated states in one-hot coding and explicitly handles erroneous stop bits before restarting reception, improving clarity and potential timing paths.
