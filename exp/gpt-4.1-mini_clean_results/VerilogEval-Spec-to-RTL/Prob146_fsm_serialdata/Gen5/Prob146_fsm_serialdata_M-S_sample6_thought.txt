Simplify the FSM by reducing the number of states and integrating the stop bit check into the data receiving logic. Use a single always block with synchronous reset. Detect start bit in IDLE, receive 8 data bits by shifting in on each cycle, then check stop bit immediately. If stop bit is correct, output data and assert done for one cycle, then return to IDLE. If stop bit is wrong, stay in an error recovery state that waits until input line goes back to 1 (stop bit), then return to IDLE. This approach reduces the state machine to three states: IDLE, RECEIVE, and WAIT_STOP, with fewer transitions and simpler logic, maintaining full functionality.
