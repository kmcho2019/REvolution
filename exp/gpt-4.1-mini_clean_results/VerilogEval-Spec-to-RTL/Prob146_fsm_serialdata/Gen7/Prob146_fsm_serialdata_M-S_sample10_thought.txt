Simplify the FSM by removing the explicit next_state logic and combine it into a single sequential always block with a simple state register update and output logic. Use a 3-bit bit counter to track received bits and a shift register to capture data. The done signal pulses when a valid stop bit is detected. In case of stop bit error, wait until line is high before accepting a new start bit. This keeps functionality but reduces code lines and complexity by having only one always block for sequential logic and simple combinational decisions inside it.
