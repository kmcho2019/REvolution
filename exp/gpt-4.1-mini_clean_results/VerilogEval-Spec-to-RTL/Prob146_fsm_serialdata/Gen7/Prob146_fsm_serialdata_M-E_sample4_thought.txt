Implement a Moore FSM with explicit four states encoded with one-hot to improve timing and clarity: IDLE, START_WAIT, DATA, and STOP_VERIFY.

- IDLE: Wait for line to go low (start bit).
- START_WAIT: Wait 1 clock cycle to sample middle of start bit (for basic debouncing).
- DATA: Shift in 8 data bits (LSB first) on each clock cycle.
- STOP_VERIFY: Check if stop bit is 1, if yes output done pulse and byte; if no, stay in STOP_VERIFY until line returns high, then go back to IDLE.

This approach separates start bit validation by one cycle delay to reduce false start detection glitches and simplifies state transitions.

The shift register and bit counter update only in DATA state, reducing unnecessary toggling. The done signal is a registered one-cycle pulse generated in STOP_VERIFY state upon valid stop bit detection.

The one-hot FSM state encoding allows fast decoding and may improve timing at slight area cost.

Synchronous active-high reset initializes all state and registers.

All registers updated on positive edge of clk.
