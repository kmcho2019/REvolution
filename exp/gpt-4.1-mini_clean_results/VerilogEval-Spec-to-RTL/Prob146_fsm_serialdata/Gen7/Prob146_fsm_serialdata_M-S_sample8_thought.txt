Simplify the FSM by using a single always block with synchronous reset for both state transitions and data processing. Use a straightforward binary state encoding with three states (IDLE, RECEIVE, STOP), merging WAIT_STOP into STOP state logic for handling invalid stop bits by looping until a valid stop bit is detected. Shift data LSB first during RECEIVE. Assert done only when a valid stop bit is detected, and output the received byte. This reduces the number of states and removes the next_state combinational logic, making the design simpler while maintaining the required functionality.
