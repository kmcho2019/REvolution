Implement a serial byte receiver FSM with a binary encoded state machine and an explicit bit sampling counter. Use three states: IDLE (line idle high, waiting for start bit), RX_DATA (shift in 8 bits, LSB first), and CHECK_STOP (verify stop bit). The design samples the input bit at each clock cycle without any clock enable gating to keep simplicity. A bit counter tracks how many data bits have been received. On detecting a start bit (in == 0 while in IDLE), transition to RX_DATA and reset bit counter and data register. Shift bits into an 8-bit shift register by placing the incoming bit at LSB and shifting data right. After 8 bits, move to CHECK_STOP, if stop bit (in == 1) is detected output done=1 and latch output data byte. If stop bit invalid (in == 0), remain in a WAIT_STOP state until line goes idle (in == 1), then go back to IDLE. done is pulsed high for one cycle when a valid stop bit is detected, and out_byte is valid on done cycle. Reset is synchronous active-high, resetting state, registers, and counters. The code is fully synchronous and uses a compact 2-bit state encoding for minimal area and power.
