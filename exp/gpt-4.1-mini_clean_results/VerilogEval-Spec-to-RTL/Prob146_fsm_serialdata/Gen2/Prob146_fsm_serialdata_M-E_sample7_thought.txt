Instead of a simple 4-state FSM, implement a Moore FSM with explicit separate states for Start detection, Data Bit Sampling, Stop bit verification, and Error Recovery. Use a shift register to collect the data bits serially, but use a bit index counter to track received bits.

- IDLE: Wait for line to go low (start bit). Stay in IDLE if line is 1.
- START: Confirm start bit still low on the next clock (to avoid glitches). If low, move to DATA.
- DATA: Shift in data bits LSB first, increment bit index from 0 to 7.
- STOP_CHECK: Sample stop bit, if 1, set done and output the byte, return to IDLE. If 0, go to ERROR_WAIT.
- ERROR_WAIT: Wait until line returns to idle (1), then return to IDLE.

By having the START state, it filters out glitches or line noise before shifting in data bits. This approach helps in more robust start bit detection.

The done signal is asserted for one cycle on the clock after receiving a correct stop bit, and out_byte is updated at the same cycle.

Synchronous reset initializes all FSM states and registers.

This solution uses explicit states for clarity and robustness in start bit sampling.
