Implement a clean UART receiver FSM that samples bits synchronously at each clock edge, assuming the input clock is already synchronized with the bit rate (i.e., one clock per bit). The module remains simple and robust:

- IDLE state: wait for start bit (in == 0). Once detected, move to RECEIVE.
- RECEIVE state: receive 8 data bits (LSB first) by shifting them into a shift register.
- STOP state: verify the stop bit is '1'.
  - If valid, output the byte, assert done for one clock cycle, then return to IDLE.
  - If invalid, stay in STOP until a valid stop bit is detected (line == 1).
  
Key points:
- The shifting direction: since LSB is sent first, we shift right, inserting the new bit into MSB is wrong; instead, shift left by 1 and input bit at LSB: `shift_reg <= {in, shift_reg[7:1]}` puts new bit at MSB (wrong). Correct is: `shift_reg <= {in, shift_reg[7:1]}` is MSB first; to get LSB first, shift right: `shift_reg <= {shift_reg[6:0], in}`.
- We'll shift right, inserting the incoming bit at the MSB (bit 7)? No, to get LSB first, the first bit received goes into bit 0, next into bit1, etc.
- So shift right and insert incoming bit at MSB means bits arrive MSB first, which is not the case.
- Instead, shift left and insert incoming bit at LSB: `shift_reg <= {in, shift_reg[7:1]}`; this inserts input at MSB again.
- Alternatively, shift left and insert at LSB: `shift_reg <= {shift_reg[6:0], in}` puts the new bit at LSB, shifting existing bits up; this captures LSB first correctly.
  
Hence, for LSB-first serial data reception, shift left and insert bit at LSB: `shift_reg <= {shift_reg[6:0], in};`

- done is asserted exactly one cycle after valid stop bit detection.
- out_byte is updated at the done cycle with the received byte.
- Synchronous reset initializes all registers.
- The FSM is 3-state: IDLE, RECEIVE, STOP.
- Use a 3-bit counter for counting the 8 data bits.
- The FSM output signals and state transition are cleanly separated.

This approach assumes the input clock is the baud rate clock, so one bit per clock cycle, with sampling aligned at clock edges.

This straightforward approach meets the requirements cleanly and is robust and easily testable.
