Use a minimal FSM with three states encoded in two bits: IDLE, RECEIVING, and WAIT_STOP. In IDLE, wait for the start bit (0). On detecting start, transition to RECEIVING where we shift in data bits (LSB first) with a 4-bit bit counter. After 8 data bits, expect the stop bit (1). If stop bit is correct, output the data and assert done for one clock cycle, then return to IDLE. If stop bit is wrong, enter WAIT_STOP state until a stop bit (1) is detected, then return to IDLE. Use a simple left-shift operation to accumulate bits LSB first: `shift_reg <= {in, shift_reg[7:1]}` (this shifts right, MSB <- in), but for LSB first reception, we should shift left and insert new bit at LSB: `shift_reg <= {in, shift_reg[7:1]}` is actually right-shifting; instead, use `shift_reg <= {shift_reg[6:0], in}`. The synchronous reset clears all states. The done signal pulses high one cycle when a byte is correctly received. This is a clear, simple, and efficient FSM that reduces flags and control logic compared to the previous solution.
