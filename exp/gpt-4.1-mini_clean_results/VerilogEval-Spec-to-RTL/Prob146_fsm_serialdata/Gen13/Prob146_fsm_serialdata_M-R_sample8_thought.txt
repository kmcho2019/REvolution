Refactor the FSM using binary-encoded states instead of one-hot to reduce flip-flop count and combinational logic complexity. Implement the FSM with a Mealy style to generate the done signal combinationally rather than registering it, reducing toggling on done. Use a single always block for state and bit counter update to simplify timing. Shift data bits in by left-shifting and inserting the new LSB bit at LSB position to keep data ordering correct (LSB first). The FSM transitions and outputs are expressed clearly with a state register and combinational next state logic. Synchronous reset still used. This approach reduces area and power by fewer state bits and removes the need to register done, while keeping the same functionality.
