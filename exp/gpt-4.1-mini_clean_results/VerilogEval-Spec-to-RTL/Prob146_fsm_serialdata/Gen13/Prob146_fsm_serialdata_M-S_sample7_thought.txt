Simplify the FSM by using binary encoding with three states: IDLE, RECEIVE, and STOP_WAIT. In IDLE, wait for the start bit (0). In RECEIVE, shift in the 8 data bits LSB first using a simple shift-left register, incrementing a 3-bit counter. Then transition to STOP_WAIT to check the stop bit. If stop bit is valid (1), output the byte and assert done; otherwise, stay in STOP_WAIT until the line returns to idle (1) before going back to IDLE. Use synchronous reset and nonblocking assignments for clarity. Keep done asserted for one clock cycle when a byte is successfully received. This approach reduces the number of states and logic while retaining correct serial byte reception and stop bit verification.
