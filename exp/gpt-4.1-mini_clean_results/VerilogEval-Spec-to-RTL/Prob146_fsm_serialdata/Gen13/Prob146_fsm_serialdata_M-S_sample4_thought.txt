Use a minimal FSM with three states: IDLE (waiting for start bit), RECEIVE (shifting in 8 data bits), and STOP (checking the stop bit).

Shift in data LSB first by shifting right and inserting the new bit at the MSB.

Count bits using a 3-bit counter only in the RECEIVE state; reset counter outside RECEIVE.

Assert done and update out_byte only when a valid stop bit (1) is detected.

If stop bit invalid (not 1), wait in STOP state until line goes idle (in == 1) before returning to IDLE.

This simplification reduces the number of states and removes the ERROR_WAIT state, merging its behavior into STOP.

Use synchronous reset to initialize all registers.

This approach keeps the design easy to understand with minimal control logic and meets all functional requirements.
