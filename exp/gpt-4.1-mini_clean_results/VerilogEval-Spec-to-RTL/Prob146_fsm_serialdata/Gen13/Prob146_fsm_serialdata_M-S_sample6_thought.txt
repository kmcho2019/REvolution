After 8 bits, go to STOP state to check for a valid stop bit (1). If stop bit is correct, output the received byte, assert done for one cycle, and return to IDLE. If the stop bit is invalid (not 1), stay in WAIT_STOP until the line returns idle (1). Use synchronous reset and simple sequential logic triggered on the clock's positive edge. Keep the design minimal by combining state and counter updates in one always block and merging done and output updates directly in the FSM logic.
