Implement the serial byte receiver using a Moore FSM with five states: WAIT_START, READ_BITS, WAIT_STOP, ERROR_RECOVERY, and OUTPUT. Use a shift register shifting bits left to accumulate the LSB first data as they arrive. The bit counter counts bits received (0 to 7). On detecting the start bit (0), transition from WAIT_START to READ_BITS. After reading 8 bits, transition to WAIT_STOP to verify the stop bit (1). If stop bit is valid, assert done for one cycle and output the byte, then go back to WAIT_START. If stop bit is invalid, enter ERROR_RECOVERY state and wait until line goes idle (1) to reset FSM. Use synchronous reset for all registers. This approach clearly separates phases, aligns data shifting with input bit order, and uses a state output register to simplify timing and signal stability.
