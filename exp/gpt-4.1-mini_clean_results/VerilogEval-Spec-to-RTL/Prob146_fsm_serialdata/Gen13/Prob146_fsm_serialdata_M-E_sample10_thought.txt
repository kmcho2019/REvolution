I will implement the serial byte receiver FSM using a simple three-state approach with explicit start, data, and stop bit handling. Instead of shifting bits right, I'll shift bits in from LSB to MSB by left-shifting and placing the new bit at LSB, matching the LSB-first serial protocol naturally. The bit counter will count from 0 to 7 for the data bits, then on the 9th bit check the stop bit. 

To robustly handle stop bit errors, I'll add a recovery state that waits until the line is idle (logic 1) before detecting the next start bit. The done signal will be a single-clock pulse generated when a valid stop bit is detected. 

The design will feature:
- States: IDLE (waiting for start bit), DATA (receiving 8 bits), STOP (checking stop bit), RECOVERY (waiting for idle line after stop bit error)
- A left-shift register with the serial input placed at LSB to reflect the LSB-first protocol naturally
- A bit counter counting received data bits
- Synchronous active-high reset
- Done pulse with out_byte valid only on that cycle

This approach uses natural left-shift to align bits in ascending order from LSB, avoids unnecessary shifting complexities, and isolates error recovery cleanly. The FSM uses 2-bit binary encoding for minimal overhead.
