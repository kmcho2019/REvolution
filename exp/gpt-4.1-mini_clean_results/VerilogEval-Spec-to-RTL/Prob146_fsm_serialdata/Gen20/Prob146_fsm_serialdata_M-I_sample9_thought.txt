To optimize the solution for better power, performance, and area while preserving correctness, the main changes are:

1. **Shift Register Direction**: Shift right and insert new bit at MSB (`shift_reg <= {in, shift_reg[7:1]}`) is already efficient for LSB-first serial data. We keep it, but simplify logic by updating shift and bit counter only when needed.

2. **Gate done signal toggling**: Instead of clearing `done` each cycle in the always block, generate `done` as a pulse only when a valid stop bit is detected by using a separate combinational signal that clocks `done` high for one cycle. This avoids toggling done unnecessarily.

3. **Reduce combinational logic depth in next_state logic**: Implement next_state logic with a more straightforward style to reduce logic levels.

4. **Combine synchronous logic into one always block**: Keep single always block for registers but minimize combinational logic inside it.

5. **Clear shift register only at IDLE and reset** to avoid extra toggling.

6. **Use explicit enable signals for bit counter and shift register** updates.

7. **Minimize output port toggling** by updating `out_byte` only when a valid byte is ready.

These changes will reduce switching activity on outputs, simplify logic, and reduce critical path delays, improving overall PPA.
