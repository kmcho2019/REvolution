Simplify the FSM by reducing state count and logic: use three states—IDLE (waiting for start bit), RECEIVE (shift in 8 data bits), and STOP (check stop bit). Use a 3-bit bit counter that increments only during RECEIVE state. Shift the incoming bit into the LSB of a data register, since data is LSB-first. On detecting a valid stop bit (logic 1), assert done for one cycle and latch out_byte. If stop bit is invalid (logic 0), stay in STOP until line returns to idle (logic 1) before returning to IDLE. Use synchronous reset to initialize registers. This reduces states and next-state logic complexity, while keeping behavior intact.
