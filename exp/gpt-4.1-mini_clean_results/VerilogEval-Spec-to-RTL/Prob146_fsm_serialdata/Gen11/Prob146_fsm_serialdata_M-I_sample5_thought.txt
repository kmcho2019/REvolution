To optimize the existing FSM design for better PPA (performance, power, and area), we apply these improvements:

1. Add explicit enable signals to `bit_cnt` and `data_shift` registers to avoid unnecessary toggling when not receiving bits (only update in READ_BITS).
2. Modify the done pulse generation so it directly pulses upon detecting a valid stop bit without combining with output logic unnecessarily.
3. Use one-hot state encoding to simplify next-state decoding logic and potentially improve timing by reducing critical path logic complexity.
4. Simplify data shifting by shifting in the incoming bit into the least significant bit (LSB) position directly instead of MSB, since the protocol sends LSB first; this reduces bit manipulation.
5. In RECOVER state, stay only while line is low; this gates toggling more effectively.
6. Combine reset handling cleanly with all registers synchronous active-high reset.
7. Use fewer case statements and simpler logic for next state to reduce combinational path length.
   
These changes reduce the switching activity on registers outside of the receive phase and reduce combinational logic depth, improving timing slack, lowering power, and possibly shrinking area by simpler logic. The interface and functionality remain unchanged.
