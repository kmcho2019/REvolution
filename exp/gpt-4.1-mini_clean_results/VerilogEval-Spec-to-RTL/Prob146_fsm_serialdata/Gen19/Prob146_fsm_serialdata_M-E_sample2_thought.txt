Implement a Moore FSM with five states (IDLE, START_DETECT, RECEIVE, STOP_CHECK, RECOVER) encoded one-hot for clearer timing and logic separation. The FSM waits for a start bit (0), then shifts in data bits LSB first into a shift register using a counter to track 8 bits received. After receiving 8 bits, it transitions to STOP_CHECK and validates the stop bit (1). If valid, it asserts done for one clock cycle and outputs the byte; if invalid, it moves to RECOVER where it waits until the line returns to idle (1) before going back to IDLE. Use separate always blocks for state transition, data shifting/counter, and output signaling to reduce combinational complexity per block and improve timing. Synchronous reset initializes the FSM. The done signal pulses only for one clock cycle on successful stop bit detection.
