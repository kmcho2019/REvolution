To improve performance and power without increasing area significantly, I will change the FSM encoding from binary (2-bit) to one-hot with 4 states. One-hot encoding reduces the combinational logic complexity and can improve timing by simplifying next-state logic. Done will still be asserted for one cycle only and generated synchronously inside the sequential block. The shift register update and bit counter increment will be gated with an enable signal active only in the RECEIVE state to avoid unnecessary toggling. The bit counter remains binary for minimal area, but we gate its update. The FSM states become 4-bit one-hot, which simplifies decoding and next-state logic. The input bit will be latched only when shifting data to improve timing margin. This should yield faster clock operation and lower power by reducing toggles and logic depth.
