Simplify the FSM by encoding states as a 2-bit binary variable rather than one-hot to reduce flip-flop count and combinational logic complexity. Use a single always block with a case statement to handle state transitions, which simplifies next state logic and improves readability. Implement a simple bit counter to track received data bits and shift the incoming bits into an 8-bit register LSB-first. Generate the `done` signal and output the byte only when a valid stop bit is detected. If the stop bit is incorrect, the FSM will stay in a wait state until the line returns to idle (logic 1). Use synchronous reset and update all sequential logic on the clock’s positive edge. This design keeps the same functionality but with simpler state management and cleaner logic.
