I will implement a Moore FSM that samples the incoming serial bit stream to detect the start bit by waiting for a '0' on the input line in the IDLE state. Once detected, I will shift in the data bits serially (LSB first) into a shift register over 8 clock cycles in the DATA state, counting them with a bit counter. After receiving 8 bits, the FSM will transition to the STOP state to check the stop bit, which must be '1'. If the stop bit is correct, the FSM will output the data byte and assert done for one clock cycle. If the stop bit is incorrect, the FSM transitions to an ERROR state to wait for the line to return to idle (in == 1) before resuming normal reception. This approach cleanly separates concerns, has clear state transitions, and implements a synchronous active-high reset. Done is generated as a one-clock-cycle pulse aligned with the valid output.
