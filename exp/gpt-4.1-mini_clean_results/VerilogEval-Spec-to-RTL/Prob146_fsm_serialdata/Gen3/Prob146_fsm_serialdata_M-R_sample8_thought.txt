Refactor the FSM as a Mealy machine by combining state registers and next-state/output logic into a single always block, reducing the number of always blocks and improving code compactness. Use explicit localparams for state encoding and a single shift-left operation with insertion at LSB for LSB-first data reception. The FSM will still have four states (IDLE, RECEIVE, STOP_WAIT, ERROR_WAIT) but outputs (done and out_byte) update immediately upon the valid stop bit detection. This approach simplifies synchronization of done and out_byte signals, keeping done asserted exactly one cycle after the stop bit validation, with synchronous reset. The refactor improves readability by centralizing logic and removing separate combinational logic, aligning outputs with state transitions tightly.
