Use a two-process FSM design with a registered state and a separate combinational next-state logic block for better synthesis and timing. The FSM will have four states: IDLE (waiting for start bit), DATA (shifting in 8 LSB-first data bits), STOP (checking the stop bit), and WAIT_STOP (waiting for the stop bit to return after error). The data bits will be shifted into a shift register each cycle during DATA state. The done signal is registered and asserted only for one cycle when a valid stop bit is detected. To reduce toggling on done, it will be set only when asserting and cleared on the next cycle. The module resets synchronously to IDLE and clears outputs. This approach separates combinational and sequential logic, enabling more efficient synthesis and potentially improved timing and power characteristics.
