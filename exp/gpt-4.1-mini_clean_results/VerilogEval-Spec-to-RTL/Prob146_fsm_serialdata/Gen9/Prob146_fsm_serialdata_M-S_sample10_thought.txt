Implement a simpler FSM with three states: IDLE, READ, and WAIT_STOP. In IDLE, wait for the start bit (0). In READ, shift in 8 data bits LSB first, counting bits with a simple counter. After 8 bits, transition to WAIT_STOP to check the stop bit (1). If stop bit is valid, output data and pulse done for one cycle, then return to IDLE. If stop bit invalid, stay in WAIT_STOP until line goes high (idle), then back to IDLE. Use a single always block for state, counters, and output registers with synchronous reset, minimizing separate always blocks. Only update bit counter and shift register during READ state with an enable flag. Keep state encoding minimal and outputs simple. This reduces complexity and resource usage while preserving protocol correctness and functionality.
