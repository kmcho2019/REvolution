To improve PPA, we optimize the FSM by using one-hot state encoding to simplify next state logic and reduce combinational delay, and add enable signals for the shift register and counter to reduce switching activity. The done signal is gated and only asserted on valid stop bits, avoiding unnecessary toggles. We also combine always blocks where possible to reduce flip-flop usage and simplify reset logic. The shift register loading is done with a simple shift-left inserting LSB first bit, minimizing logic depth. WAIT_STOP now only monitors the input without unnecessary counter or shift register activity, reducing toggles. Overall, the improvements aim for faster state transitions, less switching, and smaller area with maintained correctness.
