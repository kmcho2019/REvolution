Refactor the FSM to a Mealy-type design with clearer separation of state register, next state, and outputs. Use an explicit shift register and bit counter updated only when enabled, driven by a clock enable signal derived from the FSM state and conditions. Compute `done` and `out_byte` as registered outputs updated only when a valid stop bit is detected. Use combinational logic with `assign` where suitable for next state and control signals to simplify the always blocks and improve readability. This also cleanly separates state transitions, data reception, and output generation, potentially aiding synthesis optimization.
