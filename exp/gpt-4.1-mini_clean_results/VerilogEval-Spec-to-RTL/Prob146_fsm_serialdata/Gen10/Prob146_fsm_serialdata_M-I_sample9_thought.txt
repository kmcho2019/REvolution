To improve PPA (performance, power, area) while preserving functionality, I will use a one-hot encoded FSM for simpler and faster state decoding, which can improve timing (tns and wns). One-hot FSMs tend to reduce combinational logic depth for state transitions, benefiting performance especially in small FSMs. Also, I will introduce an enable signal for the shift register and bit counter to reduce unnecessary toggling and power consumption by updating them only when needed (i.e., during data reception). This gating reduces switching activity and power use. The done signal will remain asserted only one clock cycle. The overall state machine is simplified to four states with a single always block for sequential logic and a combinational block for next state and outputs. This approach balances power savings with a minor area increase due to one-hot state encoding, which is acceptable given the small FSM size. I will also optimize the data shifting to be clearly shifting in LSB first by shifting right and inserting `in` at the MSB, which matches the serial bit order.

The FSM states are encoded with one-hot style signals, and state register and next-state logic uses simple combinational logic. Clock gating is done by controlling when `bit_count` and `data_shift` update using enables. The reset remains synchronous active-high. This design should improve timing and power, with minimal impact on area.
