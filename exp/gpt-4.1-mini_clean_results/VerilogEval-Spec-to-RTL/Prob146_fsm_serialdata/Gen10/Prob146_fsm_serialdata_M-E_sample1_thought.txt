Use a one-hot encoded FSM with distinct states for IDLE, START_BIT_CHECK, DATA_RECV, STOP_BIT_CHECK, and WAIT_FOR_IDLE recovery. Sample each bit on the rising clock edge synchronously. Implement a bit counter for the 8 data bits and a shift register that shifts in the received bit from the serial input into the LSB position, since data is LSB-first. At each clock cycle in DATA_RECV state, shift the input bit into the data register (left-shift would place the newest bit into the LSB). Once 8 bits are received, transition to STOP_BIT_CHECK state where the stop bit is checked. If stop bit is 1, output the data byte, assert done for one cycle, and go back to IDLE. If stop bit is invalid (not 1), transition to WAIT_FOR_IDLE state, where the FSM remains until it detects the line goes idle (logic 1) before trying to receive the next byte again. Reset synchronously sets FSM to IDLE, clears counters, and output registers. The done signal pulses high for exactly one clock cycle after valid stop bit detection. By separating START_BIT_CHECK and WAIT_FOR_IDLE states, the design can explicitly synchronize on edges and minimize glitches. One-hot state encoding simplifies combinational logic at some area cost but improves clarity and timing. This design also uses a clock enable for counters and shift registers to minimize toggling when not receiving data.
