Implement a Mealy-style FSM with one-hot state encoding for faster state decoding. The FSM will sample the input bitstream synchronously with the clock and use an 8-bit shift register that shifts in the incoming bit LSB first during the data bit phase. The states are: IDLE (waiting for start bit), START (confirming start bit is low), DATA (reading 8 data bits), STOP (checking for valid stop bit), and WAIT_STOP (if stop bit invalid, wait for line to become idle). The done signal is asserted combinationally immediately when the stop bit is detected as valid (Mealy output), so done pulse is one clock cycle long without requiring a registered pulse. The design uses a bit counter with an enable signal only active during DATA state to reduce switching activity. The state transitions and outputs are combined to minimize logic depth, and the done signal is generated purely from state and input signals with no extra registers. This approach reduces critical path length and toggling by using one-hot states and conditional registers enabling, which can improve timing and power simultaneously. Synchronous active-high reset initializes all registers and states.
