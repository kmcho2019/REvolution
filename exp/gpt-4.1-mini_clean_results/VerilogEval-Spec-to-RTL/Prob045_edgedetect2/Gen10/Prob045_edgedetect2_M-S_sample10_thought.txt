Instead of using a 2-bit shift register per bit, store only the previous input vector (8 bits) in a single register. On each clock edge, compare the current input vector with the stored previous input vector using bitwise XOR. The XOR result naturally indicates which bits have changed since the last cycle. Assign this XOR result directly to the output anyedge, so anyedge is asserted one clock cycle after a bit transition. This simplifies the design by reducing storage to one 8-bit register and eliminates the need for per-bit shift registers.
