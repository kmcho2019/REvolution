To improve PPA, consolidate the eight individual single-bit registers into a single 8-bit register to hold the previous cycle's input vector. Then, in a single always block triggered on clk's rising edge, calculate the edge detection for all bits in parallel using a bitwise XOR between the current and previous input vectors. This reduces the number of always blocks and flip-flops, lowers switching activity by minimizing register count, and improves area efficiency by leveraging vector operations instead of multiple scalar registers. The output is registered, producing the "anyedge" output delayed by one clock cycle after the transition, as required.
