A novel approach is to implement the edge detection purely combinationally by storing the previous input vector in a register and then computing the XOR between the current and stored previous input vectors in a combinational block. The result of XOR is then registered in a separate output register. This two-stage register pipeline (one register to hold previous input and one to hold the edge detection result) ensures that the output anyedge is valid exactly one cycle after the input changes. This approach consolidates storage and logic into vectorized registers and uses two always blocks, minimizing register count and logic complexity while improving area and power efficiency.
