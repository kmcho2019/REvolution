Instead of using a 2-bit shift register per bit, store only the previous input value in a single 8-bit register. On each clock edge, compute which bits have changed by XORing the current input with the stored previous input. To meet the requirement that the output `anyedge` is high exactly one cycle after the input change, register the edge detection result into another 8-bit register. This creates a one-cycle delay between detecting the edge and asserting the output. The design thus uses two 8-bit registers: one to hold the previous input, and one to hold the delayed edge detection result, simplifying the storage and logic.
