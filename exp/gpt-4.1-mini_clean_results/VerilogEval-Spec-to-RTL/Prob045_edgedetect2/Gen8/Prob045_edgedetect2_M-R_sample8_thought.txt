Instead of using an array of 2-bit shift registers per bit, maintain a single 8-bit register to hold the previous input sample on each clock cycle. Then, detect edges by XORing the current input with the previous input. Since the output must be asserted one cycle after the transition, we register the XOR result into an output register. This approach simplifies storage, reduces register count, and cleanly separates combinational edge detection from synchronous output generation.
