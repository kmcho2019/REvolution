Instead of using a 2-bit shift register per bit to detect edges, maintain a single 8-bit register that stores the previous cycle's input vector. On each clock edge, compare the current input vector to the stored previous vector using bitwise XOR to detect which bits changed. To satisfy the requirement that the output `anyedge` is asserted one cycle after the input edge, register the XOR result into an output register, effectively delaying the detection by one cycle. This approach uses minimal registers (just two 8-bit registers) and simple logic, making the design clean, resource-efficient, and easy to understand.
