Instead of storing the previous input and then generating the edge detection signal with two registers, we can implement a pipeline with a single register for previous input and directly generate the anyedge output in the next clock cycle by comparing the current input with the registered previous input. By registering the previous input and then combinationally comparing with the current input, the edge detection result naturally corresponds to edges that happened in the last clock cycle. We then register this result to produce the output, ensuring anyedge is high exactly one cycle after the input changes. This reduces unnecessary intermediate registers and keeps the design minimal and clear.
