Instead of explicitly storing the entire previous input and then performing a bitwise XOR, use a shift register approach where the input is stored in a 2-stage pipeline. By delaying the input by one cycle in one register and then by another cycle in a second register, we can detect an edge by comparing these two delayed versions. Specifically, if the bit in the earlier delayed input is different from the next cycle's delayed input, that indicates an edge occurred one cycle earlier. Then, output this edge detection at the next clock cycle as required. This double buffering approach detects edges based on two previous samples and naturally produces the output one cycle after an edge occurs.
