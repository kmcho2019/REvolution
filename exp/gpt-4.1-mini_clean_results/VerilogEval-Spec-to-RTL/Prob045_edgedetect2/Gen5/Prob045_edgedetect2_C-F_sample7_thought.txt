Fuse the clarity and minimal register use from Example 1 with the slightly improved power idea of updating the previous input register only when a change occurs to reduce unnecessary switching. Use a single always block for the sequential logic to store the previous input only when it differs from the current input (enabling clock gating potential), and a separate always block to compute the anyedge output by XORing the current and previous inputs. This maintains registered output timing one cycle after the edge detection while optimizing power by minimizing toggling in the previous input register.
