To detect any edge (rising or falling) on each bit of the 8-bit input vector, we need to compare the current input bits with their previous cycle values. We will store the previous input in a register on each positive clock edge. Then, anyedge will be set high for bits where the previous input differs from the current input, indicating a transition occurred in the last cycle. Since the output should be set the cycle after the transition, we will register the detected edge signal and output it on anyedge.
