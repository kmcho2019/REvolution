To detect any edge on each bit of the 8-bit input vector, store the previous cycle's input in a register. On each clock edge, compare the current input with the previous stored input; if different, it means an edge occurred on that bit. The output anyedge will be set to 1 for bits where the input bit changed from the previous cycle, and 0 otherwise. The output will reflect edges detected on the previous clock cycle (delayed by one cycle).
