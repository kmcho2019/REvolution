To detect any edge (rising or falling) on each bit of the input vector, we need to store the previous state of the input bits in a register on each clock cycle. Then, by comparing the current input vector with the stored previous input vector, we can identify changes on any bit. The output anyedge should then be set to 1 for the cycle after the edge is detected, meaning the output is updated based on the edge detected during the previous clock cycle. Therefore, we register the edge detection result one cycle delayed.
