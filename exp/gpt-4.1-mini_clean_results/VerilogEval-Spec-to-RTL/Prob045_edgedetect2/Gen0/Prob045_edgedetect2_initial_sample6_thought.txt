To detect any edge (rising or falling) for each bit in the 8-bit input vector, we need to compare the current input with the input from the previous clock cycle. We store the previous input in a register and on each clock edge, we check which bits have changed by XORing the current input with the previous input. The result of this XOR is stored in the output anyedge on the next clock cycle, meaning anyedge will be asserted for one clock cycle immediately after a change is detected.
