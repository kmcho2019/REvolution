A novel approach is to implement edge detection by using a Gray code counter technique per bit. Since a Gray code changes only one bit at a time, we can compare the current input bits to a Gray code encoded previous state and detect edges by observing changes in each bit after conversion. However, since the input is arbitrary and not sequential, an easier alternative is to use a pair of flip-flops per bit to detect edges indirectly: by delaying the input twice and XORing the two delayed versions, we can detect edges with a pipeline latency of two cycles. This structure uses shift registers and combinational logic to produce the output one cycle after input changes, and is architecturally distinct from the direct XOR with previous input. The advantage is it can be extended easily to more complex temporal filtering or multiple clock domains.
