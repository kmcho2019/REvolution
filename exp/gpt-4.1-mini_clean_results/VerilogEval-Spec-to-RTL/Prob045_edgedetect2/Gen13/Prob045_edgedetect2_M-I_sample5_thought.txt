Optimize the design by storing only the previous input sample in a single 8-bit register instead of using an array of 2-bit shift registers. Then, detect edges by XORing the current input with the previous input, which indicates any bit transitions. Since the output must be asserted one cycle after the edge, register the XOR result in a pipeline register. This reduces area by halving the register count, lowers power by minimizing flip-flop toggles, and simplifies timing paths for better performance.
