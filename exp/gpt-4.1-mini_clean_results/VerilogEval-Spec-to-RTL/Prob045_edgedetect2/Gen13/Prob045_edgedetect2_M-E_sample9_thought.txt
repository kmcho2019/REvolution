Instead of storing the entire previous input vector and XORing it with the current input, we can detect edges on each bit independently using individual flip-flops that store the last state of each input bit. We then compute the edge detection output by comparing the stored state and the current input bit, generating a 1 on any change. To demonstrate a different architectural style, I will use a generate loop to instantiate 8 single-bit edge detectors, each as a separate always block with a registered previous input bit and output logic. This modular approach highlights a per-bit edge detection scheme while still producing the same correct output delayed by one clock cycle.
