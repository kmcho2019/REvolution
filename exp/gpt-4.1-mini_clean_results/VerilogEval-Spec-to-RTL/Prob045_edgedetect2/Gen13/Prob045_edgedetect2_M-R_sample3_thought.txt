To refactor while preserving functionality, I will use a single 8-bit register to store the previous input vector rather than separate single-bit registers per bit. The edge detection will then be done using a combinational XOR between the current input and this stored previous input. This XOR result is registered (latched) on the positive clock edge to produce the one-cycle delayed output indicating edges. This approach consolidates all per-bit previous value registers into one vector register, reducing register count and improving synthesis optimization potential. The logic is clearer by separating the combinational edge detection (XOR) from the sequential registering of the output edge vector.
