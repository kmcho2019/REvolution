Refactor the design to use a single 8-bit register to hold the previous input vector and compute the edge detection entirely using combinational logic (bitwise XOR) followed by registering the result. This eliminates the need for multiple submodules and multiple always blocks. The edge detection output is then simply the registered XOR of current input and previous input vectors. This vectorized approach reduces register count and complexity, uses just one always block, and simplifies the design while preserving functionality. Using a single register and XOR vector operation improves area and power efficiency by packing logic more effectively and reducing clocked elements.
