Instead of using a 2-bit shift register per bit, store the entire previous input vector in a single 8-bit register. On each clock, compare the current input vector with the stored previous vector using bitwise XOR. The output anyedge will be this XOR result delayed by one cycle, which matches the requirement to assert anyedge exactly one cycle after an input bit changes. This simplifies the design by reducing storage to a single register and producing anyedge as a registered XOR output, ensuring correct timing and minimal logic.
