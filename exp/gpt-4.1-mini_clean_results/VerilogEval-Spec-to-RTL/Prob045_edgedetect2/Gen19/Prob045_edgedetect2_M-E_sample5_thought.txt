Use a single register to hold the previous input vector sampled on each clock edge. Then in a synchronous always block triggered by clk, compare the current input with the stored previous input using XOR to detect changes. Store this XOR result in the output register anyedge on the next clock cycle. This approach uses just one register for previous input storage and directly registers the detected edges, making anyedge a fully synchronous output and ensuring the edge signal is stable and aligned with the clock, while keeping the design simple and minimizing logic stages.
