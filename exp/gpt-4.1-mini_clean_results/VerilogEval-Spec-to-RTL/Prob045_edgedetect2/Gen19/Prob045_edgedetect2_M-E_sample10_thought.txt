Use a single register to store the previous input sampled at each clock edge, then compare the current input directly with this registered previous input inside a synchronous process to generate the anyedge output. Specifically, on each clock edge, anyedge is updated to the XOR of the current input and the previous input stored in a register, so anyedge reflects bit changes from the previous cycle in the current cycle (one cycle after the transition). This eliminates the need for a two-stage input pipeline and performs edge detection and output registration atomically in one clocked process, simplifying the design and ensuring synchronous outputs.
