Implement edge detection by storing only the previous input value in a register and then detecting changes by XORing the current input with this registered previous input at the clock edge. To ensure the output anyedge is asserted one cycle after the input edge, use a two-stage pipeline for the edge detection signal: first generate an immediate XOR result combinationally, then register it on the next clock cycle to produce anyedge. This approach reduces register usage (only one register for previous input instead of two) and cleanly pipelines the edge detection output to achieve the one-cycle delay requirement.
