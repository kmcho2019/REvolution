We can refactor the edge detection by storing the previous input vector in a single 8-bit register updated on the positive edge of the clock. Then, the edge detection is done by a bitwise XOR between the current input and the stored previous input, which generates a combinational signal. To align with the requirement that output anyedge should be asserted one clock cycle after the input change, we register this XOR result in an 8-bit output register. This vectorized approach reduces the number of always blocks from many to just one, simplifies the design, and enhances resource sharing, potentially improving area and power without affecting functionality.
