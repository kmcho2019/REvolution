To improve PPA, I will consolidate the eight individual 1-bit registers for previous input bits into a single 8-bit register. This reduces register count and logic duplication, lowering area and power. Edge detection can be done by a single vectorized XOR between the current 8-bit input and the previous stored vector, all inside one always block. This approach keeps the output registered one cycle after the edge occurs. The single always block also helps synthesis optimize clock gating and reduce toggle rate. This reduces dynamic power and area while maintaining the original functional behavior and timing performance.
