To refactor the design while preserving the functionality, we can use a vectorized approach where the previous input sample is stored in an 8-bit register and the edge detection is performed by bitwise XOR of the current input vector with the stored previous vector. Then, the output anyedge is registered to be one cycle delayed after the change is detected. This approach reduces the number of registers from 8 scalar ones to a single vector register and performs XOR in combinational logic, improving area and power efficiency. The sequential logic now consists of only two registers: one to store the previous input and one for the output, resulting in a cleaner and more compact RTL structure.
