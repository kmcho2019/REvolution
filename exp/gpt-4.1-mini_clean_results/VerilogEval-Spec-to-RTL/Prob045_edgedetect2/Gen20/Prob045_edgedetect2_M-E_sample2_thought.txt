Instead of using two pipeline registers and XORing them, implement a single register to hold the previous cycle input, and detect edges by XORing the current input and the previous input synchronously inside the clocked always block. Assign the edge detection output anyedge synchronously at the clock edge. This eliminates the combinational block and ensures that the anyedge output is registered, producing a stable, glitch-free, one-clock-cycle delayed pulse indicating any transition on each input bit.
