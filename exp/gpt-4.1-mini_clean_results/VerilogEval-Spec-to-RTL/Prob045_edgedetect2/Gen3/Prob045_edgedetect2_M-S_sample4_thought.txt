Instead of using a 2-bit shift register per input bit, maintain only one register to hold the previous input vector. On each clock edge, compare the current input vector with the stored previous input vector using bitwise XOR to detect edges per bit. Then, update the previous input register with the current input. The anyedge output is assigned to this XOR result, which naturally reflects edges that occurred on the previous clock cycle. This approach reduces register count, simplifies the logic, and meets the requirement that anyedge is high one cycle after the edge occurs.
