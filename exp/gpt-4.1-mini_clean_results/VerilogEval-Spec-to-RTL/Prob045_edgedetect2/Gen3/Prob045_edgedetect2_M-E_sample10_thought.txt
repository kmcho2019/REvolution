Instead of directly XORing the current input with the delayed input, implement a two-stage pipeline that first stores the current input and detects changes by comparing it to the previous stage's stored value. Then, register the detected edges in a separate output register. This separation allows a clean pipeline approach with clear data flow and can ease timing by spreading logic across two registers. The output anyedge will thus be asserted one clock cycle after an input bit transition is detected by the XOR of current and previous values.
