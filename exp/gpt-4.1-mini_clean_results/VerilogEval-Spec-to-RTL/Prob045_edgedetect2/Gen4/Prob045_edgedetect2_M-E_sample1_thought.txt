Instead of storing the entire previous input and comparing all bits simultaneously, we can create a set of 8 single-bit flip-flops each tracking one bit of the input. For each bit, the output anyedge bit is generated by XORing the current input bit with the stored flip-flop output from the previous cycle. To align the output edge detection one cycle after the transition, we register the XOR result in a pipeline flip-flop. This creates a 2-stage pipeline: one storing the previous bit value, the next storing the detected edge, thus outputting edge detection delayed by one clock cycle.
