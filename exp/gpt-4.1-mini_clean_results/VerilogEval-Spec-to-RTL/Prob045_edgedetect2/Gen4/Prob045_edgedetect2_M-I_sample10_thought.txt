To improve power efficiency, add an enable signal for updating the prev_in register and the anyedge output only when any bit of the input changes. This reduces unnecessary toggling of registers when input remains constant, thereby saving dynamic power without affecting performance or area significantly. The detection of any change is done via a combinational OR of the XOR result. The overall timing path remains one XOR plus register stage, keeping critical path low. This optimization trades a small amount of combinational logic for reduced switching activity in registers.
