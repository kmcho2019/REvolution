To simplify the design, we can avoid creating separate submodules and instead use a single 8-bit register to store the previous input vector. Then, on every clock's positive edge, we perform a bitwise XOR between the current input vector and the stored previous input vector to detect edges. This produces the anyedge output vector, indicating edges per bit delayed by one clock cycle. This vectorized approach is concise, uses a single always block, and maintains the required functionality with less code and complexity.
