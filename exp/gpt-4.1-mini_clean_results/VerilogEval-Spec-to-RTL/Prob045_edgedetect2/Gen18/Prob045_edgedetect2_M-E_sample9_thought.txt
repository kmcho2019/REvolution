Instead of storing the entire previous input vector, we can implement a small shift register pipeline that delays the input by one clock cycle. By comparing the current input to the delayed version, we can detect any edges. This approach explicitly models the delay using a 2-stage pipeline of registers: the first stage captures the current input, the second stage holds the previous input. This provides flexibility to extend pipeline stages if needed and separates input sampling from edge detection. The edge detection is computed combinationally by XORing the first and second stage registers, and then registered again to ensure output is stable and aligned with the clock. This three-register pipeline offers clean timing and can be extended or optimized further while maintaining clarity.
