To simplify the edge detection module, we can eliminate the separate one-bit submodules and instead store the entire previous 8-bit input vector in a single register. Then, in one always block, compute the bitwise XOR between the current input and the previous input to detect any edges for all bits simultaneously. This reduces complexity and area by using a single vector register and combinational XOR, while maintaining the requirement that the anyedge output reflects edges detected one clock cycle after they occur.
