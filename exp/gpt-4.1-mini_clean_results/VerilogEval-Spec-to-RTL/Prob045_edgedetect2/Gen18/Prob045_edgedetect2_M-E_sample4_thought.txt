Implement a single 8-bit shift register that captures the previous cycle's input vector. Use a combinational XOR between the current input vector and this delayed vector to detect any edge on each bit. Then, register the XOR result on the next clock cycle to produce the output anyedge. This approach separates edge detection into a combinational stage and a pipeline register stage, enabling the output to be the delayed edge detection as required. This architecture uses minimal registers and cleanly pipelines the detection result, potentially improving timing and area by leveraging vector operations rather than per-bit modules.
