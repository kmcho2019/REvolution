Instead of using separate 2-bit shift registers per bit, store the entire 8-bit input vector from the previous clock cycle in a single 8-bit register. On every clock edge, compare the current 8-bit input vector with the stored previous input vector using a bitwise XOR operation. The XOR result identifies all bits where edges occurred in the previous cycle. Then, register the XOR result into a one-clock-cycle delayed output register, so that the output `anyedge` reflects edges that happened in the prior cycle as required. This approach reduces storage to a single 8-bit register for previous input and a single 8-bit output register, simplifying design and reducing area while meeting the timing requirement.
