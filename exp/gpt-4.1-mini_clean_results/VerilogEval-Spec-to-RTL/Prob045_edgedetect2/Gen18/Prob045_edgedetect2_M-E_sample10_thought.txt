To detect any edge per bit in a compact and efficient manner, we can store the entire 8-bit previous input in a single register and perform a vectorized XOR with the current input inside one always block. This XOR will reveal which bits have changed. To delay the detection output by one cycle, we register the XOR result before output. This approach uses only two 8-bit registers, minimizing flip-flops and logic duplication. It also offers potential power and area benefits by consolidating logic and state storage. Additionally, it is simpler to read and maintain compared to multiple single-bit modules.
