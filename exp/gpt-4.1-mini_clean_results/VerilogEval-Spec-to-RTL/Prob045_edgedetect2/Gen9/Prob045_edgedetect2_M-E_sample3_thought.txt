Use a shift register approach for each bit to track the last two samples of the input bits. At every clock edge, shift in the current input into a 2-bit register per bit. Then, compare the two stored bits to detect any edge (bit changes). Output anyedge as 1 when the stored two bits differ, reflecting an edge detected in the previous clock cycle. This approach uses an array of 2-bit registers, avoiding explicit XOR, yet achieving the same edge detection delayed by one clock.
