The existing solution is already minimal and efficient: a single register delays the input, and XOR detects changes. To improve PPA (performance, power, and area) further, consider adding an enable signal for the delay register to update only when input bits change. This reduces unnecessary register toggling, lowering dynamic power while not impacting performance or area significantly. The enable can be generated by comparing the current input and delayed input vector and only updating the delay register and anyedge output when at least one bit changes. This clock gating technique reduces switching activity internally, improving power without adding much area or affecting timing.
