Store only the previous input vector in a single 8-bit register and compare it directly to the current input to detect edges. The output anyedge for each bit is the XOR of the previous and current input bits, indicating a change. Because the previous input is updated on the clock edge, anyedge naturally asserts one cycle after the input transition as required. This reduces storage from 2 bits per input bit to 1, simplifies logic, and maintains functionality.
