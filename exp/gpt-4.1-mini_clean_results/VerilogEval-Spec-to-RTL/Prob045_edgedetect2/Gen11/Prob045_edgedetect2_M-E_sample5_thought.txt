Instead of storing the entire previous input vector and XORing it directly with the current input, we can implement parallel edge detectors for each bit by using a one-bit shift register per bit to delay the input by one clock cycle. Then, edge detection per bit is performed using XOR between the current and delayed bit. To implement this in a novel way, we can instantiate eight individual 1-bit edge detector submodules inside TopModule. Each submodule contains a single-bit register to store the previous bit, making the structure more modular and explicit. This architectural approach enhances readability, modularity, and potential for scalability or modification per bit.
