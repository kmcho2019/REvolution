A novel approach is to implement a two-stage pipeline to detect edges. In the first stage, we latch the current input. In the second stage, we compare the latched input from the previous cycle with the latched input from the cycle before that using XOR to detect edges. The advantage of this approach is that it explicitly stages the registers so that the anyedge output changes one cycle after the edge is detected, meeting the timing requirements. This pipelined approach also makes timing of the output explicit. The design uses two registers to store input history and a combinational XOR to detect transitions.
