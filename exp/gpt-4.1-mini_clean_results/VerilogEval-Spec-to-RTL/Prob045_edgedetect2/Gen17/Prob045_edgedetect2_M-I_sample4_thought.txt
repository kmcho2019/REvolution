To optimize the original design for better performance, power, and area, we can eliminate the 2-bit shift register per bit and instead maintain only a single 8-bit register holding the previous input sample. This simplifies the storage to one register instead of eight 2-bit registers, reducing area and power. Edge detection can then be done by XORing the current input and previous input bits, producing the anyedge output one cycle after the transition. The design is straightforward, more compact, and efficient, and still meets the requirement that anyedge is asserted one cycle after an input bit changes.
