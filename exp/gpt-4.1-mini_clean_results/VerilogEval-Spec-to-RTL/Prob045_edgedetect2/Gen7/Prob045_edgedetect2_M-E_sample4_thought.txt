Store the previous input vector in a single 8-bit register and compare it with the current input vector on each clock cycle. The XOR between the current and previous inputs will yield a vector where bits that have changed are set to 1, indicating edges occurred on those bits in the current cycle. To generate the `anyedge` output one cycle after the transition, register the XOR result in an 8-bit output register. This approach is simpler, uses fewer registers, and easily meets the timing by pipelining the detection through the output register.
