Instead of using flip-flops per bit or submodules, implement a single 8-bit register that stores the previous input vector. On each clock cycle, XOR the current input vector with the stored previous input vector to produce the anyedge vector. The anyedge output is registered one cycle later by storing this XOR result in an output register. This approach uses just two 8-bit registers: one for previous input and one for delayed edge detection output, reducing flip-flop count and consolidating logic. This vectorized method simplifies the design, potentially improves area and power by leveraging wider registers, and maintains clear timing for one-cycle delayed edge reporting.
