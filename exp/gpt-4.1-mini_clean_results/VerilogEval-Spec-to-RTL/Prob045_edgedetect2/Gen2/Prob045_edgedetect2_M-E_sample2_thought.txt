Instead of storing the entire previous input vector and performing a bitwise XOR in one clock cycle, we can use individual flip-flops to capture each input bit and its delayed version. By cascading two registers for each bit, the first register captures the current input, and the second register captures the delayed input (previous clock). Then, for each bit, comparing the two registers directly indicates if an edge occurred one cycle before, enabling the output to be set at the next clock cycle. This approach conceptually pipelines the edge detection, separating input sampling and edge detection into two stages, which may be helpful for timing or power gating individual bits independently.
