Implement a shift register of depth two for each bit of the input vector, storing the current and previous input samples in a 2-bit shift register. By comparing these two stored samples, we can detect edges when the bits differ. To meet the requirement that anyedge is high exactly one cycle after the input changes, we produce the output as the XOR of the two stored bits in the shift register, which naturally reflects edges from the previous cycle. This approach uses a 2-bit shift register per bit and generates the output directly from stored bits without needing an extra register stage for output, thus providing a clear and pipelined solution.
