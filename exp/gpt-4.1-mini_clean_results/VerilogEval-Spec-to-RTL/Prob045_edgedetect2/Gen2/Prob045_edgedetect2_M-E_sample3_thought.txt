Instead of storing the entire previous input vector, implement a small shift register for each bit that tracks the last two states of the input bit. On each clock, shift in the current bit. Then, detect if the two stored states differ (indicating an edge). Because the output is based on comparing these two consecutive states, the output will be valid one cycle after the input changes. This approach explicitly uses 2-bit shift registers per input bit and compares them for edge detection, providing a fresh architectural perspective.
