A novel architectural approach is to use a single 8-bit register to store the previous clock cycle's entire input vector and perform the edge detection in a fully vectorized manner. This design avoids separate modules or flip-flops per bit and uses only one always block triggered on the clock's positive edge. The XOR operation between the current input and the stored previous input vector produces the edge detection bits, which are registered and output the cycle after the input transition. This reduces logic duplication and maximizes hardware sharing, potentially improving area and power efficiency. To emphasize the separation between detection and output timing, a pipeline register stage for anyedge is explicitly used, making the design easily extendable.
