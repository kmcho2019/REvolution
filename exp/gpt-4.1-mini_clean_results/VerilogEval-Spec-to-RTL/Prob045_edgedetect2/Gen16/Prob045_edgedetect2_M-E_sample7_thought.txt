Instead of directly XORing the current and previous inputs, implement an edge detection by using two registers: one to hold the current input and another to hold the previous input sample. Then compare these registers bit-by-bit in combinational logic to generate the edge detect output. This approach separates the data storage from the edge detection logic, making it clearer. We will use an intermediate wire to represent the edge detection result (current vs previous input), and register the output anyedge on the next clock cycle. This makes the output anyedge valid one cycle after the input change, satisfying the timing requirement.
