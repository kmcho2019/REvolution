To correctly infer a level-sensitive D latch in synthesis tools like Yosys, avoid explicitly assigning the output to itself in an always @(*) block, which suggests combinational logic but with feedback. Instead, use an always block sensitive to changes in 'd' or 'ena', and assign 'q' only when 'ena' is high. When 'ena' is low, leave 'q' unassigned in the always block so the latch inference is clear and tools infer the memory element properly. This approach ensures synthesizability and correct latch behavior without the non-synthesizable `q = q;` statement.
