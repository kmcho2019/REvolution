Implement the D latch by using an always block that is sensitive to the enable signal only. Inside the block, use a blocking assignment to latch the input "d" into "q" only when "ena" is high. When "ena" is low, no assignment is made, thus inferring a latch as the output "q" holds its previous value. This style uses minimal sensitivity and leverages the fact that incomplete assignments infer latches naturally, which should be recognized well by synthesis tools. Using blocking assignments inside an always block with only the enable in the sensitivity list is a classic and clear way to describe a transparent latch.
