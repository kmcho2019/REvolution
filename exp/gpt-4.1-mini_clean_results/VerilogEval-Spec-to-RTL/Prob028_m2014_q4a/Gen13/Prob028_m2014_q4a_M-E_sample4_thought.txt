Implement the D latch using a level-sensitive always block triggered only on changes of the enable signal, rather than using an always @(*) block. Store the data input d in q when the enable (ena) signal is high, and maintain q otherwise by simply not updating it (no else branch). Use a non-blocking assignment (`<=`) to indicate sequential behavior, which can still infer a latch because the always block is sensitive only to ena changes. This approach is different from the common combinational always block latch inference pattern and may offer better synthesis tool compatibility.
