To avoid synthesis issues caused by the always @* block with nonblocking assignments, the D latch can be implemented using a procedural always block that is sensitive only to `ena` and `d` signals. Using blocking assignments (`=`) within such a level-sensitive always block is a common and synthesis-friendly style to infer latches. This approach allows synthesis tools to infer the latch transparently when `ena` is high and to hold the previous value when `ena` is low, without confusing the tools or generating unknown primitives. The output `q` is declared as a reg and updated only when `ena` is active, otherwise it retains its value, naturally inferring a latch.

This refactoring maintains the original functional behavior but uses a more canonical latch inference style that synthesis tools widely support.
