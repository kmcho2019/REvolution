To improve synthesis compatibility and avoid the synthesis tool looking for a missing vendor-specific latch primitive, I will rewrite the latch using an edge-sensitive always block triggered on changes to ena or d with a non-blocking assignment. This style better guides synthesis tools to infer a latch by updating q only when ena is high; otherwise, q retains its value implicitly. Avoiding the explicit self-assignment `q = q;` and using non-blocking assignments inside the always block enhances clarity for the synthesizer. This method is widely accepted by synthesis tools to infer a D latch without vendor-specific primitives and without requiring explicit latch cell definitions.
