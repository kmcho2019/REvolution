To improve synthesis compatibility and avoid unsupported latch primitives, rewrite the D latch using non-blocking assignments and an always block sensitive only to the enable signal and the data signal changes. Use a posedge of 'ena' for the sensitivity list if possible or use level sensitivity correctly but with non-blocking assignments. Since the latch is level-sensitive on 'ena', we keep the sensitivity list as 'ena or d' but use non-blocking assignment (<=) instead of blocking assignment (=). This style is better recognized by synthesis tools and helps avoid generating unsupported primitive cells. The behavior remains the same: when ena=1, q follows d; when ena=0, q holds its last value.
