Implement the D latch by using an always block triggered only on changes of the enable signal. Inside the block, when enable goes high, assign q to d (transparent mode). When enable is low, retain the previous value of q by explicitly assigning q to itself. Using a non-blocking assignment ensures proper sequential behavior and avoids combinational loops. This style leverages the enable signal as the latch trigger and helps synthesis tools infer a level-sensitive latch more reliably.
