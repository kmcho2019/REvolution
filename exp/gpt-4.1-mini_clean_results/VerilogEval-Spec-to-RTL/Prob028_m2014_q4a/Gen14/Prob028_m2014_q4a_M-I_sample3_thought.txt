To improve synthesis compatibility and PPA, use a clocked process to describe the D latch behavior explicitly by making the enable signal the gate for the latch and using non-blocking assignments. This approach uses an asynchronous latch style with sensitivity to both ena and d but assigns q only when ena is high, avoiding inference issues seen in purely combinational always blocks. This style tends to be better recognized by synthesis tools, producing a reliable inferred latch without relying on unknown primitives. Additionally, using non-blocking assignments is a good practice even in latches for better simulation and synthesis consistency.
