Implement the D latch by modeling it with an always block sensitive only to the enable signal and data input, using nonblocking assignment to a reg q. When enable is high, q follows d (transparent). When enable is low, the latch holds its previous value by not updating q. This is a classic style that synthesis tools recognize well as a latch since the output updates only when enable is asserted, and otherwise retains its value, inferred by the conditional assignment inside the always block.

This approach uses a level-sensitive latch inference style with a simple conditional statement inside the always block, ensuring clean synthesis mapping to standard latch cells. The output q is declared as a reg driven directly by the always block, simplifying the design. This method avoids tricky feedback assignments and provides an easily synthesizable D latch.
