I will implement the D latch using two always blocks to explicitly separate the transparent and hold behaviors. The first always block is sensitive to the enable signal and data input and will set the output q when enable is high. The second always block is sensitive only to enable going low, and it holds the previous value by not changing q. Both blocks will use blocking assignments to ensure synthesis tools infer the latch correctly. This explicit separation clarifies latch behavior and helps synthesis tools like Yosys avoid generating unknown cells by clearly describing level-sensitive latch functionality.
