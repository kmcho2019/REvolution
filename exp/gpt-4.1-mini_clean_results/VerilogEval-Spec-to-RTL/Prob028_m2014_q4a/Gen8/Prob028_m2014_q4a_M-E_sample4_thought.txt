Implement the D latch by using an always block with a sensitivity list only on the enable signal. When the enable (ena) is high, the latch is transparent and the output q follows the input d; when enable is low, q holds its previous value. To explicitly model the latch behavior and improve synthesis compatibility, use blocking assignments (`=`) inside the always block, assign q = d when ena is high, and omit else assignment so q retains its value implicitly. Also declare q as reg output.

This approach differs from the prior by only being sensitive to ena changes (and ignoring d changes directly) and relies on the blocking assignment behavior in a level-sensitive always block to infer a latch. This is a commonly supported latch inference style that synthesis tools can recognize and map easily to a D latch primitive.
