Implement the D latch using an always block sensitive only to the enable signal `ena`. Use an internal register to hold the state when `ena` is low, and update the output `q` when `ena` is high based on `d`. This approach creates a latch by sampling `d` only when `ena` is asserted, while holding the previous value otherwise. The sensitivity on `ena` ensures minimal triggering events, and using non-blocking assignments clarifies sequential semantics. This style can improve latch inference in some synthesis tools by separating enable control from data input.
