Use a conditional continuous assignment inside a combinational always block with a temporary register to mimic a latch behavior. The idea is to maintain a stored value in a reg variable updated only when the enable is high, and the output q follows this register continuously. This avoids incomplete assignments and explicitly models the latch holding behavior by updating the stored value only when enabled. The latch is inferred because when enable is low, the stored value reg does not change, thereby implicitly holding the last state. This style avoids multiple driver issues and uses a single always block sensitive to d or ena.
