Implement a 4-digit BCD counter using four 4-bit registers for each digit. On each clock, increment the ones digit; when it rolls over from 9 to 0, enable increment on the tens digit, and so forth for hundreds and thousands digits. The ena output is a 3-bit signal that indicates when the tens, hundreds, and thousands digits should increment. The reset is synchronous and active-high, which clears all digits to zero on the clock edge.
