Refactor the 4-digit BCD counter by implementing the counter increment logic inside an always block that increments only the ones digit every clock cycle and uses sequential carry propagation to increment higher digits. Instead of computing next digit values combinationally and assigning them to registers directly, this approach updates digits in a procedural style with explicit carry propagation. The enables (`ena`) are generated based on carry flags registered in the same clock cycle, reflecting when each digit increments. Reset is synchronous active-high. This style more closely mimics a ripple-carry counter and leverages the procedural style for clarity, differing from the original combinational next-state logic.
