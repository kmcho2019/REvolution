I will refactor the 4-digit BCD counter by using a single 16-bit register to hold all digits and implementing the increment logic with combinational logic to generate the next state, then register it on the clock edge. This approach avoids nested if-else by computing all digit increments and rollovers using arithmetic and conditional logic in parallel.

The enable signals will be generated by comparing the relevant digits in the registered count rather than multiple chained conditions, simplifying combinational logic.

This structure separates the combinational next-state logic from the sequential register update, which can improve clarity and potentially improve timing by reducing sequential nested condition chains inside the always block.

Reset remains synchronous active high and affects the entire 16-bit register. Each BCD digit is handled individually within the packed 16-bit register.
