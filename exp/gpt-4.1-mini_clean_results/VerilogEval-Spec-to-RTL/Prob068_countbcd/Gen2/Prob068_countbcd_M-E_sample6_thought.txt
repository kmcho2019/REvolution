Implement the 4-digit BCD counter using a single 16-bit register to hold all digits. On each clock, increment the entire BCD number by 1, but implement a BCD increment function that handles digit-wise increments and carry propagation combinationally within the always block. Generate the ena signals by detecting whether the increment caused the respective digit to roll over from 9 to 0 (i.e., when that digit increments). This avoids using multiple carry registers and simplifies the logic to a single increment operation. The ena bits correspond to when the tens, hundreds, and thousands digits increment (i.e., when the ones digit overflows ena[0], and so on). Use a combinational function to compute the next BCD value and which digits increment, then apply synchronous update. This approach centralizes the increment and carry logic, ensures correct carry propagation, and cleanly produces the ena signals.
