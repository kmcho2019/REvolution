I will implement the 4-digit BCD counter using a single 16-bit register to hold all digits concatenated, and perform increments digit-by-digit using a separate combinational function that computes the next BCD digit and carry out. This function-based approach modularizes the increment logic and avoids deeply nested if statements.

In each clock cycle, the ones digit increments by 1; if it rolls over from 9 to 0, a carry is generated to increment the tens digit, and so forth up to thousands.

Enable signals for digits [3:1] will be generated based on whether the lower digit generated a carry, indicating the higher digit should increment. These enables are combinational outputs derived from the carry chain.

The synchronous reset clears the entire 16-bit counter to zero.

This modular approach:
- Encapsulates the BCD increment logic clearly in a function.
- Flattens the counting logic to reduce critical path delay by avoiding nested ifs.
- Keeps enable generation clean and closely related to the carry signals.
- Uses non-blocking updates for correct synchronous behavior.
