I will simplify the design by using a single 16-bit register for the BCD counter and performing the increment in a more straightforward manner. The ones digit always increments by one each clock cycle, and if it rolls over (reaches 9 and increments), it triggers the increment of the tens digit, and similarly for hundreds and thousands.

I will generate the enable signals as simple combinational signals that indicate when the previous digit is at 9, which tells the next digit to increment.

To reduce complexity, I will perform the increment with simple if-else blocks checking for digit rollovers without using a function or extra temporary registers. This will make the code easier to read and synthesize, while preserving the correct synchronous reset and sequential increment behavior.

This approach removes the nested function and intermediate 5-bit carry signals, and uses basic BCD incrementing logic which is simpler and more intuitive.
