I will simplify the BCD counter by handling the four digits separately as 4-bit registers and using straightforward ripple carry logic. On each clock edge (with synchronous reset), the ones digit increments; if it overflows (from 9 to 0), the tens digit increments, and so on for hundreds and thousands. The enable outputs will simply indicate when the lower digit reached 9, signaling that the next digit increments. This approach removes the increment function and nested local variables, resulting in clear, maintainable code with minimal complexity while keeping the synchronous reset and positive clock edge triggering.
