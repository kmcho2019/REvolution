I will implement the 4-digit BCD counter as a single 16-bit binary counter internally, incremented every clock cycle. Then, I will use a dedicated combinational logic block to convert this 16-bit binary count value into the 4 BCD digits. 

This binary counting plus binary-to-BCD conversion technique is a novel architectural idea compared to digit-by-digit counting with carry propagation in BCD directly.

Advantages of this approach:
- Simple synchronous increment of a single binary counter register.
- Clear separation between counting and BCD conversion.
- Enable signals for each digit can be generated by detecting when each digit changes from the previous clock cycle, meaning when that digit "rolls over" (like from 9 to 0).
- This avoids multiple chained increments and complex carry logic in the sequential path.
- Binary to BCD conversion is done combinationally using a classic Double Dabble (shift and add 3) algorithm implemented in a combinational function.

Key steps:
1. Use a 16-bit binary counter to count from 0 to 9999 decimal (0x270F hex).
2. On each clock edge, increment the binary counter or reset it to zero.
3. Convert the binary count to BCD digits using combinational logic.
4. Determine the enable signals by comparing the previous BCD value with the current BCD value for digits 1, 2, and 3: enable if digit increments.
5. Synchronous reset clears the binary counter.
   
This solution is quite different architecturally from the example, moving complexity to combinational logic but simplifying sequential logic.
