Use a single 16-bit register to hold the BCD count, representing four digits. On each clock, increment the ones digit. If it overflows from 9 to 0, set an enable signal to increment the next digit. Repeat this carry logic sequentially for tens, hundreds, and thousands digits. The ena signals indicate when the upper three digits should increment, directly reflecting these carry events. This approach uses simple ripple carry logic with straightforward digit extraction and concatenation in the clocked block. Reset clears the entire counter and disables all enables synchronously.
