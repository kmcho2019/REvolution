Implement the 4-digit BCD counter by storing each digit in a register and handling increments with ripple carry logic at each clock edge. Increment the ones digit every clock cycle. If a digit rolls over from 9 to 0, generate a carry that enables the next digit to increment. Assign the carry signals directly to the ena output bits to indicate when each upper digit should increment. Use non-blocking assignments for clean sequential logic. Reset all digits and ena signals synchronously on active-high reset. Output q is concatenation of the digits.
