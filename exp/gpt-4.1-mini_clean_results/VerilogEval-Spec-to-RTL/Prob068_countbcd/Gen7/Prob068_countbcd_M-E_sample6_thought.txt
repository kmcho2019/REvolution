Implement the 4-digit BCD counter as a single 16-bit register representing all digits together, and perform increment and rollover using combinational logic that checks each digit sequentially. Use a single enable chain computed inside the clocked process, avoiding separate per-digit enable wires from the outside, but expose enable outputs for digits 1 to 3 indicating when each upper digit increments. 

On each clock, if not reset, increment the entire 16-bit BCD number by 1 using digit-wise ripple carry with explicit carry signals inside the sequential block, and simultaneously set the enable outputs based on carry propagations within the register update.

This approach encapsulates carry and enable signal generation inside the clocked block for better timing predictability, reduces combinational logic in enable signals, and keeps power low by updating digits only when needed internally. It also limits combinational depth outside the always block to a simple assignment from the internal enable registers. This design is structurally different by moving all logic inside the sequential block rather than splitting combinational enables from sequential updates.
