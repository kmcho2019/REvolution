Refactor the 4-digit BCD counter using a single 16-bit BCD value and synchronous logic to extract and update digits in a clocked always block. Instead of combinational carry detection from current digits, perform the increment in a ripple fashion inside the clocked block: increment the ones digit, if it wraps from 9 to 0 assert an enable for the tens digit increment, and similarly ripple the carry up digits sequentially. Capture these carry increments as ena outputs synchronously, indicating which upper digits incremented at this clock edge. By folding the carry logic inside the clocked process and using variables to hold intermediate states, the carry and enable signals accurately represent digit increments aligned with the clock, ensuring correct BCD counting and ena signaling. Output q is constructed from the updated digits each clock.
