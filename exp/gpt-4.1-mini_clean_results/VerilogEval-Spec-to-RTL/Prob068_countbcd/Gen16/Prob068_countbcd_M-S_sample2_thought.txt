To simplify the design, I will eliminate the bcd_inc function and implement the BCD increment and carry propagation directly and clearly using basic comparisons and arithmetic within the sequential always block. The increment logic will be straightforward: increment the ones digit; if it rolls over from 9 to 0, increment the tens digit; if tens rolls over, increment hundreds; and so forth.

The enable signals can be generated as simple comparisons to 9 for the lower digits without cascading conditions for simplicity, since their function is to indicate when the next digit increments.

This approach reduces nested function calls and intermediate variables, simplifying the code while preserving the core functionality and synchronous reset behavior.
