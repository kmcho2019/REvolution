I will implement the 4-digit BCD counter using a single 16-bit register representing all four digits together. At each clock, I will increment this 16-bit value by 1 in BCD format by adding 1 to the least significant digit and properly propagating the carry using a combinational function that increments each digit and resets digits after 9.

The enables will be generated by checking when the lower digit(s) have reached 9 at the current clock edge before incrementing (i.e., carry conditions). This way, the enable signals become straightforward combinational signals derived from the current value of q, reflecting when each upper digit will increment at the next clock cycle.

This method avoids nested if statements for incrementing digits in sequential logic, instead using a combinational BCD increment function. It simplifies the design and supports a more parallel update of digits with clearer carry propagation.

Synchronous reset sets q to 0. All logic updates at the rising clock edge.
