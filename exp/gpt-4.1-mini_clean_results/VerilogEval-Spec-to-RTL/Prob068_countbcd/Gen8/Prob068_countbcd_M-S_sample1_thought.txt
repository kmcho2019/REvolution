I will simplify the 4-digit BCD counter by using four separate 4-bit digit registers, each incremented sequentially with carry propagation. This removes the need for a function and nested blocking assignments, simplifying the code and making the logic more readable.

The enables (ena) for upper digits will directly reflect when the lower digit equals 9, signaling the next digit to increment on the next cycle.
