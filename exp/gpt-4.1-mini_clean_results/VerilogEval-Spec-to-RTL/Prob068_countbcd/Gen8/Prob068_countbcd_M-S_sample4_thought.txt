To simplify the 4-digit BCD counter, I will combine the four 4-bit digits into a single 16-bit register and implement the counter logic sequentially within a single always block. The carry propagation will be done step-by-step inside the block, using simple conditional checks, avoiding separate enable signals for counting digits. The ena output will be directly generated based on the counter state to indicate when each upper digit should increment.

This approach reduces the number of registers and removes separate digit registers, making the code shorter and easier to read while maintaining the exact behavior of the original design.

Synchronous reset and positive-edge clock triggering are preserved.
