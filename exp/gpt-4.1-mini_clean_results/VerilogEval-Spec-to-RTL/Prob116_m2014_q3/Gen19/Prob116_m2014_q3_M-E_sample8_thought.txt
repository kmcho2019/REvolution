Instead of decoding Gray code to binary and using a case statement, implement the function f directly by expressing it as a sum of minterms derived from the K-map, using the Gray-coded inputs as-is. We analyze the map and identify which minterms yield f=1 and encode these as combinational logic expressions with the original x bits.

This approach avoids the Gray-to-binary decoding step entirely. It leverages the original Gray-coded bits directly in logic expressions formed by AND/OR/NOT operations.

We generate the simplified sum-of-products by enumerating input combinations from the K-map, setting don't-cares to 0 (to keep logic minimal).

This results in straightforward combinational logic that can be expressed as boolean expressions in continuous assignments or in an always block with minimal logic depth.

Benefits:
- Eliminates Gray decoding XOR gates, simplifying logic.
- Direct use of original bits may simplify expression.
- Logic style is clear and easy to verify.
