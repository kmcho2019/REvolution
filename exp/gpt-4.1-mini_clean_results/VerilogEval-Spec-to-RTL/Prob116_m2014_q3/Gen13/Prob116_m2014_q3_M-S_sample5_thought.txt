The original solution uses explicit intermediate wires for each bit, which adds verbosity but no functional benefit. Since the input bits can be directly indexed, and the logic expression is simple, we can write the logic for output f directly using input bits without intermediate wire assignments.

The simplified approach directly expresses f as:

This reduces code lines and improves readability while maintaining the same functionality.
