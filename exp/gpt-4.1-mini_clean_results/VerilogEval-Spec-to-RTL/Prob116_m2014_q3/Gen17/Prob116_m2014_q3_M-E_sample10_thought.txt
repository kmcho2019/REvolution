Implement the Karnaugh map function by using a ROM-style lookup table stored as a localparam array indexed directly by the 4-bit input vector in the problem's bit order (x1 to x4 mapped explicitly). 

Instead of Gray-to-binary conversion, interpret the problem's Karnaugh map with inputs reordered to match the input vector bits directly, then assign don't-cares ('d') to zeros for simplicity.

This LUT-based approach encapsulates the logic in a concise combinational array indexing operation, yielding a clean and easily modifiable design. It avoids decoding logic and case statements, simplifying synthesis.

The design is fully combinational and synthesizable.
