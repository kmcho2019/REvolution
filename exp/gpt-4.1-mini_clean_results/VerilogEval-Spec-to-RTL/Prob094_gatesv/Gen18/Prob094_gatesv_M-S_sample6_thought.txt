Simplify the code by using vectorized bitwise operations with shifts instead of explicit per-bit assignments. This reduces code size and complexity while preserving functionality. For out_both, shift input left by 1 and AND with input, setting last bit to zero. For out_any, shift input right by 1 and OR with input, setting first bit to zero. For out_different, perform XOR of input with a left-shifted (rotated) version of input for wrap-around difference. This approach maintains clarity and fully combinational logic with minimal code.
