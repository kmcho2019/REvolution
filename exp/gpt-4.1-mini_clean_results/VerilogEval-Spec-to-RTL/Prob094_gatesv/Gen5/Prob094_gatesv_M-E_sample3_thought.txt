Leverage bitwise vector operations and shift operators to compute the outputs compactly. For out_both, shift the input left by one and bitwise AND with the original input, with the highest bit invalid, so mask that bit off. For out_any, shift the input right by one and bitwise OR with the original input, masking off the lowest bit. For out_different, since the neighbor to the left wraps around, create a rotated version of the input (left rotation by 1) and XOR with the original input. This vectorized approach reduces explicit per-bit assignments and efficiently uses vector operations, leading to concise and elegant code.
