Use vector operations and bitwise shifts to assign all outputs in a compact and simple way:

- out_both: bits 0..2 = in[0..2] & in[1..3], bit 3 = 0.
- out_any: bits 1..3 = in[1..3] | in[0..2], bit 0 = 0.
- out_different: use XOR between in and in rotated left by one, directly on 4-bit vectors.

This avoids multiple separate assigns and explicit indexing, simplifying the code while preserving the logic.
