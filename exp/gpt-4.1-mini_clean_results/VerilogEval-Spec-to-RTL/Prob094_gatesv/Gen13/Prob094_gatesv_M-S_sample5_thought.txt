Use vector slicing and bitwise operators to simplify the logic without explicit per-bit assignments. For out_both, AND the input vector with itself shifted left by one bit, setting the highest bit to zero. For out_any, OR the input vector with itself shifted right by one bit, setting the lowest bit to zero. For out_different, XOR the input vector with a left-rotated version to handle wrap-around in one operation. This keeps the design concise, readable, and efficient.
