For out_both, for each bit except the highest (index 3), we check if both that bit and the bit to its left (index+1) are 1. out_both[3] will be 0 since no neighbor to the left.

For out_any, for each bit except the lowest (index 0), we check if either that bit or the bit to its right (index-1) are 1. out_any[0] will be 0 since no neighbor to the right.

For out_different, each bit compares to its left neighbor, with wrap-around. So bit i is compared with (i+1)%4. The bit is set if they differ.
