Implement the countdown timer using a shift register approach instead of a binary down-counter. Load the 10-bit 'data' input into a shift register when 'load' is high, representing the remaining count as a one-hot pulse moving through the register. On each clock cycle without loading, shift the register right by one bit, simulating countdown by moving the 'active' bit toward zero. The terminal count 'tc' is asserted when the shift register is all zeros, indicating the count has elapsed. This approach uses a single 10-bit register (one D flip-flop vector) and exploits shift register behavior for countdown, offering a distinct architectural idea.
