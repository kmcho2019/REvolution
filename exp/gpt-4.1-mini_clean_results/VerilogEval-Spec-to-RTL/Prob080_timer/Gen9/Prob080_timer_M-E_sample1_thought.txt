Implement the timer using an explicit enable signal and a single 10-bit register for the counter. When load is high, the counter loads the input data. When load is low and the counter is not zero, the counter decrements by 1 on each clock edge. The terminal count output is driven by detecting whether the counter is zero. This approach leverages a clock-enabled style inside the always block without separate combinational next-state logic, using conditional statements directly in the sequential block to minimize combinational logic and keep the code intuitive and concise. The counter stops decrementing upon reaching zero until it is loaded again.
