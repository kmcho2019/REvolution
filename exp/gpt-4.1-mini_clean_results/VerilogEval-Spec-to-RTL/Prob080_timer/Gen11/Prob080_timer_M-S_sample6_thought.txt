Simplify the design by integrating the next-state logic directly inside a single always block triggered by the clock, eliminating the separate wire for next_counter. On each clock edge, check if load is high to load the counter; otherwise, if the counter is nonzero, decrement it by one; else hold zero. The terminal count output is assigned directly by comparing the counter to zero. This reduces code size and complexity while preserving functionality and adhering to the single D flip-flop constraint.
