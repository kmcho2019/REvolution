Use a single flip-flop to implement a one-bit enable signal that indicates whether the counter should decrement. Combine this enable with a combinational 10-bit counter that holds the countdown value. At each clock edge, if load is high, synchronously load the counter with data and reset enable to 1 to allow counting down. When the counter reaches zero, disable the enable flip-flop to stop decrementing. The terminal count output reflects whether the counter has reached zero. This separates counting enable control (1-bit flip-flop) from the 10-bit down-counter logic, ensuring only one flip-flop holds state.
