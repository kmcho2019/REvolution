Implement the countdown timer using a single 10-bit register that stores the counter, but instead of decrementing directly, use a simple combinational trick: latch the decremented value into a temporary wire only if the counter is not zero and load is low, otherwise load the input data. Then update the register on each clock edge with this computed next value. The terminal count output is asserted when the counter reaches zero. This separates the next-state logic clearly but still uses only one 10-bit D flip-flop register for state storage.
