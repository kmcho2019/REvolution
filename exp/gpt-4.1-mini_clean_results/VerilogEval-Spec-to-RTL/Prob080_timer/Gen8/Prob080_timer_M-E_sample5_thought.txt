Implement the timer using a single 10-bit register that directly stores the current count. On each positive clock edge, check if load is asserted; if so, load the counter with the new input data. If load is not asserted and the counter is not zero, decrement the counter by one. When the counter reaches zero, it stays at zero until reloaded.

To keep it single-register and simple, all logic is embedded inside one always block, avoiding separate combinational next-state logic. The terminal count signal is asserted by comparing the register to zero. This approach emphasizes direct sequential state updates without explicitly separating combinational next-state logic.
