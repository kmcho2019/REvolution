Use a single always block triggered by the positive clock edge that updates the counter register directly. If load is asserted, load the counter with the input data; else if the counter is not zero, decrement it by 1; otherwise, hold it at zero. Since the count can only change at clock edges and the counter is stored in a single register, this satisfies the single flip-flop storage constraint. The terminal count output is assigned combinationally based on whether the counter is zero. This approach eliminates the intermediate next_counter wire, simplifying the design while preserving all functionality.
