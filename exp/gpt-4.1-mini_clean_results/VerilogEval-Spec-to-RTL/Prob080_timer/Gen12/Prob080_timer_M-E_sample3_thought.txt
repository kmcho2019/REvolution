Implement the countdown timer using a single 10-bit shift register instead of a binary down-counter. At load time, load the input data as a one-hot encoded pulse position within the shift register: the bit at position (data-1) is set to 1 and all others 0. At each clock cycle (when load=0), shift the register right by one bit. The terminal count (tc) output is driven by the least significant bit of the shift register, which becomes 1 exactly after "data" clock cycles. This approach uses a single shift register register (D flip-flop array) as the timer state and only a single bit output to signal terminal count.
