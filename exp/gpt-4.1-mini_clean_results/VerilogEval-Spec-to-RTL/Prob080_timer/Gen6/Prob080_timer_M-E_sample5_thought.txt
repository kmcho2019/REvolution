Implement the countdown timer using a single register that stores the current count. When load=1, synchronously load the data input into the register. When load=0 and the counter is not zero, decrement the register by 1. The terminal count (tc) output is asserted when the register reaches zero. The design uses only a single always @(posedge clk) block to update the register, complying with the single D flip-flop process constraint. The subtraction and loading are done inside the sequential block for a clean, atomic update, eliminating the combinational next-state logic wires.
