Fuse the strengths of both examples by implementing the next counter value calculation combinationally using a wire instead of a reg. Additionally, to improve power efficiency, add an enable signal for updating the counter only when the counter is non-zero or when loading new data. This effectively gates the register load, preventing toggling when the counter is zero and load is low.

This approach combines clean separation of combinational and sequential logic, single-register state holding, and reduced switching activity for better PPA while strictly using only one clocked register as required.
