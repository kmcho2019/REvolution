Refactor the timer logic by embedding the load and decrement behavior inside a single always block that explicitly checks conditions sequentially rather than using a combinational assignment for the next state.

The counter register is updated on the positive edge of the clock, where:
- If load is asserted, the counter loads the input data.
- Else if the counter is non-zero, decrement it by one.
- Otherwise, hold zero.

This approach keeps all state updates and logic inside the sequential block without intermediate combinational wires, which can be beneficial for clarity in some coding styles and can simplify debugging.

The terminal count output `tc` remains a continuous assignment detecting when the counter reaches zero.

This change preserves the one-register requirement and the overall function while illustrating an alternative coding style that uses explicit sequential logic control flow rather than a combinational operator for next state.
