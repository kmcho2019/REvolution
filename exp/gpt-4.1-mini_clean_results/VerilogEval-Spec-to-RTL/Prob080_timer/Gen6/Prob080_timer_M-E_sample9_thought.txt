Implement the countdown timer using a single-bit state register as a "borrow" indicator and a 10-bit combinational decrementer. The state register holds whether the counter is active (counting down) or stopped (reached zero). On each clock, if load=1, the counter is loaded with the input data and the active flag is set. If load=0 and active, the combinational logic decrements the counter. When the counter reaches zero, the active flag is cleared, and the terminal count (tc) output asserts. This design uses only one flip-flop for the active signal, while the 10-bit counter is purely combinational logic derived from input and previous active state, emphasizing the single flip-flop constraint in a novel way.
