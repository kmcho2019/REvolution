Refactor the countdown timer to separate the next state logic into a combinational always block and the state update into a sequential always block. This approach keeps the same functionality but uses a two-step style: first computing the next counter value combinationally based on current state, then updating the register on the clock edge. This increases code clarity by clearly distinguishing combinational and sequential logic, which is a common best practice. The output terminal count is still assigned by comparing the register to zero.
