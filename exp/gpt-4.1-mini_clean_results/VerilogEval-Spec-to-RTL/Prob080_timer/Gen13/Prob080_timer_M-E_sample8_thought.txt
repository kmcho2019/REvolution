Implement the timer using an internal register for the counter that is updated directly in the sequential block with conditional logic: if load is high, load the counter with the input data; else if the counter is not zero, decrement it by 1; otherwise, keep it at zero. The terminal count output is asserted when the counter reaches zero. This approach avoids explicit combinational next state logic and directly encodes the state transition in a single always block with a single 10-bit register, fulfilling the single D flip-flop requirement (one register capturing 10 bits as a unit).
