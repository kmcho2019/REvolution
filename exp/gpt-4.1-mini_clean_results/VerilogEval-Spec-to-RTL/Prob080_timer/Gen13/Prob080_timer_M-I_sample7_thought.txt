To improve PPA, I will add a clock enable signal so that the counter register only updates when load=1 or the counter is not zero (counting down). This will reduce unnecessary toggling in the register, lowering dynamic power consumption. The logic for next_counter remains the same, but the always block uses an enable condition to avoid clocking the register unnecessarily. This selective update also simplifies the counter behavior when zero: the register holds its state without toggling. This approach maintains the same functional correctness while improving power and potentially area due to reduced switching.
