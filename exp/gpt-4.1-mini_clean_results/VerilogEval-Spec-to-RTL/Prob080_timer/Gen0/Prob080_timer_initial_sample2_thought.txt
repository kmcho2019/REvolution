Implement a 10-bit down-counter with a single D flip-flop for its least significant bit and combinational logic for the remaining bits. On each clock's positive edge, if load is asserted, load the counter with the input data; otherwise, if the counter is not zero, decrement it by one. The terminal count output (tc) asserts when the counter reaches zero and remains asserted until reload. The design uses a D flip-flop for bit 0, while the higher bits are updated combinationally.
