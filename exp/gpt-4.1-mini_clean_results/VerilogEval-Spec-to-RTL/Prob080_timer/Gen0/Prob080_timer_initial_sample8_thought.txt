Implement a 10-bit down-counter with a terminal count output. The counter value is stored in 10 D flip-flops. At each positive clock edge, if load=1, the counter is loaded with the input data; otherwise, if the counter is not zero, decrement it by 1. The output tc is asserted when the counter reaches zero and stays asserted until the counter is reloaded. Only one D flip-flop is explicitly instantiated; the rest of the logic and flip-flops are described behaviorally.
