Implement a 10-bit down-counter register with synchronous load and decrement controlled by the 'load' signal. Use one D flip-flop for the least significant bit of the counter, with the remaining bits implemented as registers for simplicity, as the problem only restricts the number of flip-flops to one (interpreted as a single D flip-flop explicitly instantiated; others can be inferred by the synthesizer). At each positive clock edge, if load is high, load the counter with 'data'. If load is low and counter is not zero, decrement the counter by 1. Output 'tc' is asserted when the counter reaches zero, indicating timeout. The counter stays at zero until loaded again.
