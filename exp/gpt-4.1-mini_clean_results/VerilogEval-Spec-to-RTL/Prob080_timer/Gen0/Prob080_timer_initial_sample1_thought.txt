Implement a 10-bit down-counter register that loads the input data when load is high on the clock edge. When load is low, if the counter is non-zero, decrement it by 1; if zero, hold zero. The tc output is asserted when the counter is zero. Use a single 10-bit register as the counter. The single D flip-flop constraint applies to the data storage (the counter register), so the entire 10-bit counter will be implemented as a single register. Sequential logic triggered on the positive clock edge.
