Implement the countdown timer as a single 10-bit register holding the current count, updated on each clock edge. Instead of computing the next count combinationally, store a flag indicating if the counter is active (not zero). When load=1, load the counter with the input data and set active flag if data!=0. When load=0 and active, decrement the counter by 1; if it reaches zero, clear active. The terminal count output is driven by whether the counter is zero (count done). This approach uses a single register to hold the count and an active flag to track counting status, enabling the counter to halt automatically at zero until reloaded.
