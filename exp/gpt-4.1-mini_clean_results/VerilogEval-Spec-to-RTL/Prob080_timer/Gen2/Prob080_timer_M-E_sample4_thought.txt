Implement a countdown timer using a single-bit stateful D flip-flop to track whether the timer is active (counting down) or not, combined with a purely combinational down-counter implemented with ripple borrow logic. The 10-bit counter is stored in combinational logic, with its "state" implicitly represented by the stored counter value. Since only one D flip-flop is allowed, we use it to hold the "timer active" status, and build a 10-bit down-counter using combinational logic that decrements the input data only when the timer is active.

At each clock:

- If load=1, load the data into a combinational register (a wire) for the next counter value and set the flip-flop active.

- If load=0 and timer active (flip-flop=1), decrement the counter combinationally.

- When counter reaches zero, clear the active flip-flop.

Output tc is the inverse of active flip-flop (1 when counter reached zero).

This uses only one flip-flop (the active flag), while the 10-bit counter is implemented as combinational wires fed by either input data or decrement logic. The combinational storage simulates the counter state passing through the active flip-flop as an enable flag.

This approach complies with the requirement of only one D flip-flop for sequential logic, demonstrating a novel architecture separating count storage from sequential state via a single bit.
