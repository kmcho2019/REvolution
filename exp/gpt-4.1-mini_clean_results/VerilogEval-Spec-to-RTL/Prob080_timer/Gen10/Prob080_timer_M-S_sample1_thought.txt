Simplify the timer logic by using a single always block triggered on the positive clock edge that directly updates the counter register. On each clock cycle, if load is high, load the input data; otherwise, if the counter is not zero, decrement it by one; if zero, hold zero. The terminal count output is driven directly by checking if the counter is zero.

This removes the explicit else branch that writes zero again, as the register naturally holds its value without extra assignment, reducing the code slightly while preserving behavior. This remains a single 10-bit register implementation with synchronous updates and a simple combinational output.
