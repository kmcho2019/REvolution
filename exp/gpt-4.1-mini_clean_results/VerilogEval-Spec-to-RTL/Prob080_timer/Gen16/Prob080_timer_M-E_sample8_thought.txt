Implement the countdown timer using a 10-bit register to hold the current count value and a single D flip-flop to store whether the timer is running or stopped. When load is asserted, load the input data into the counter and set the running flag to 1. On each clock edge, if running is set and load is low, decrement the counter; when the counter reaches zero, clear the running flag to stop the count. The output terminal count (tc) is asserted when the counter hits zero and the timer is stopped. This separates the running state and counter, providing explicit start/stop control and avoiding continuous counting when counter is zero.
