Refactor the design by implementing the countdown timer as a finite state machine (FSM) with two states: IDLE (counter at zero) and COUNT (counting down). Use a single 10-bit register to hold the count and a 1-bit register for state. On each clock, if load=1, load the counter and enter COUNT state. If in COUNT state and load=0, decrement the counter until it reaches zero, then transition to IDLE. The tc output is asserted when in IDLE state. This approach uses the two registers together to maintain the functionality while separating counting and terminal count detection into distinct states, still using a single clocked process, but showing a different structural style than pure combinational logic for next_count.
