Refactor the timer by splitting the logic into a combinational next-counter value signal and a single D flip-flop register holding the counter. Use an always block for the flip-flop only, and compute next counter value with combinational logic outside. This clarifies the load and decrement conditions distinctly. The terminal count output 'tc' is still assigned based on whether the counter is zero. This refactor keeps the same one vector register (single D flip-flop holding 10 bits) but separates the combinational logic from sequential logic for cleaner design style.
