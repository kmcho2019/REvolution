Implement the countdown timer using a single 10-bit D flip-flop register, but derive the next counter value using a conditional ternary operator directly in the sequential always block. If load is high, load the counter with the input data. Otherwise, decrement the counter only if it is not zero. The terminal count output (tc) is asserted when the counter reaches zero. This approach avoids a separate combinational always block, simplifying the design and maintaining the one flip-flop constraint.
