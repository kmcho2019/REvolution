Implement the down-counter by storing the counter value as the current value plus 1 when loading, so that after the first decrement it will match the loaded value. On each clock edge, if load is asserted, set the counter to data+1, else if the counter is nonzero, decrement it by 1. This allows the counter to reach zero exactly after 'data' clock cycles. Output tc is asserted when counter is zero. This technique avoids direct loading the data as-is and may slightly simplify timing of load vs decrement decisions, creating a novel approach different from typical direct load schemes.
