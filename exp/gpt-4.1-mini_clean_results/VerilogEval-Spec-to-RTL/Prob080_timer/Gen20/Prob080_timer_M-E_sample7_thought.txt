Implement the timer using a one-hot style approach inside a single 10-bit shift register acting as a down-counter. On loading, the shift register is loaded with a binary encoding of the count value by setting a '1' in the position corresponding to the count duration, with zeros elsewhere (e.g., load = 1: position data bit is set to 1). At each clock cycle when not loading, the '1' bit shifts right (towards LSB), representing the countdown progress. When the '1' reaches the LSB, it indicates terminal count and stops shifting until the next load. This approach uses a single register (10 bits of one D flip-flops) and shift logic to represent the counter in a different form. The terminal count output is asserted when the '1' is at the LSB or when the register is zero (no '1's). This design exploits shift register logic instead of arithmetic subtraction, simplifying the decrement operation and meeting the single D flip-flop constraint by implementing the entire 10-bit register as a single shift register with combinational load logic.
