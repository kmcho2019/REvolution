Implement the TopModule as a fully combinational circuit directly computing all three outputs from the 4-bit input using reduction operators in one module, with no intermediate modules or parameterization.

This design:
- Eliminates any module hierarchy and redundancy.
- Uses simple, direct assignments, minimizing logic and synthesis complexity.
- Ensures the fastest, lowest-area, and lowest-power implementation since each output is generated once from the same input vector using native reduction operators.
- Is highly readable and maintainable due to its straightforwardness.
