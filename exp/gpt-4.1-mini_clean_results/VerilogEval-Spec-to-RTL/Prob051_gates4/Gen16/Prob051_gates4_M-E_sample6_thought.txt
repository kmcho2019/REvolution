Implement the 4-input AND, OR, and XOR gates using continuous assignments with built-in Verilog reduction operators on the input vector. Declare the outputs as wires instead of regs and directly assign the outputs in a purely structural, declarative manner. This approach leverages Verilog's native vector reduction operators (&, |, ^) which synthesize efficiently to balanced gate trees. The design is minimal, succinct, and highly synthesis-friendly, ensuring optimal timing, power, and area. No procedural code or loops are needed, so the implementation is clear and elegant.
