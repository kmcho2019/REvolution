To provide a structurally different implementation while keeping the output always driven high, I will use an always block with a reg output instead of a continuous assign statement. This involves declaring the output as a reg and assigning it a constant value inside an always block that is sensitive to no signals (i.e., always @(*)). Since the output is a constant, this is functionally equivalent but stylistically distinct. Although this might synthesize to the same minimal hardware, it demonstrates a different coding style.
