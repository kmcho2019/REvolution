Introduce a simple FSM with three states: IDLE, RUN, and DONE. On synchronous reset, transition to RUN state and enable shift_ena for exactly 4 clock cycles using a 2-bit cycle counter that counts from 0 to 3. After the 4 cycles, move to DONE state where shift_ena is 0. 

To support enabling shift_ena on detecting a proper bit pattern, introduce an input signal `pattern_detected` (assumed provided externally). When in DONE or IDLE, if pattern_detected is asserted, transition to RUN state again and enable shift_ena for 4 cycles. This reuses the same cycle counter.

This approach decouples shift_ena generation from reset and pattern detection logic, centralizing timing control in RUN state with a counter. shift_ena is high only in RUN state for 4 cycles. The FSM handles multiple activations triggered by reset or pattern_detected inputs.

If pattern_detected is not provided, this module can easily be extended by adding that input and hooking up the pattern detection logic outside this module.

All logic is synchronous with positive edge clock and synchronous active-high reset. Outputs are registered to avoid glitches.

This is a clean and extendable FSM-based control to drive shift_ena for exactly 4 cycles on reset or on demand, with straightforward state and counter management.
