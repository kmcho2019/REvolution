Implement a 4-bit down-counter that triggers shift_ena for exactly 4 cycles upon reset or upon a detected pattern trigger. Instead of using a shift register, the design uses a loadable counter with the following features:

- On synchronous reset (active high), load the counter with 4.
- On detection of the specific bit pattern (represented by a simple input signal `pattern_detected` which should be modeled inside the module or assumed as an input for extensibility), also reload the counter with 4.
- The counter counts down on each clock cycle when its value is non-zero.
- shift_ena is asserted whenever the counter is non-zero.
- When the counter reaches zero, shift_ena deasserts and remains low until reset or next pattern detection.
- For this task, since no pattern input is specified, I will internally assume pattern detection tied to zero (no detection), so the only trigger is reset.
- The code is structured so adding pattern detection is easy; this makes the design flexible.
- This is a novel architecture compared to a shift register approach; it uses a down-counter with enable controlled by either reset or pattern detection.

This design ensures exactly 4 cycles of shift_ena assertion following reset or pattern trigger, and then shift_ena remains low.
