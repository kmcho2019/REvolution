Use a simple 3-bit counter that triggers on either reset or a pattern detection signal to enable shift_ena for exactly 4 cycles. On reset (synchronous active high), the counter initializes to 4. Whenever a pattern is detected, reload the counter to 4 as well. On each clock cycle, the counter counts down if nonzero. shift_ena is asserted whenever the counter is not zero.

This avoids a complex FSM by treating both reset and pattern detection as triggers that load the counter, keeping the design minimal and straightforward.

To simplify and since no pattern detection input is given, we add a single input `pattern_detected` to demonstrate how the pattern triggers the shift_ena. This input should be asserted for one clock cycle when the pattern is detected.

All sequential logic runs on the posedge clk with synchronous reset.
