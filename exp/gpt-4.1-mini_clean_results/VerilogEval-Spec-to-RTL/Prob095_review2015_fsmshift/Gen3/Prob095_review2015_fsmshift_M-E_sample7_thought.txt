Implement a two-state FSM with an enable counter. The FSM starts in an INIT state after reset, where shift_ena is asserted for exactly 4 cycles (counting down a 3-bit counter), then transitions to an IDLE state where shift_ena is deasserted. In the IDLE state, if the bit pattern is detected (pattern_detected input added to interface), the FSM transitions back to the INIT-like behavior by enabling shift_ena for 4 cycles again. This means both reset and pattern detection trigger a 4-cycle enable period. All logic is synchronous to clk with active-high synchronous reset. This approach clearly separates states and counts the enable duration exactly, fulfilling the requirements. Since the original interface does not include pattern_detected, we can embed pattern detection inside the module by simulating it internally for demonstration or keep it external with an added input port for correctness.
