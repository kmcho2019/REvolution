Implement the FSM using a one-hot encoding style with five state flip-flops instead of a binary-encoded 3-bit register. Use synchronous reset to set the FSM to the initial state (S0). The next-state logic will be combinational, driving the next active state flip-flop based on current states and input x. Output z is driven directly by detecting active states S3 or S4. This approach simplifies state decoding logic and could improve timing at the expense of slightly increased register count.
