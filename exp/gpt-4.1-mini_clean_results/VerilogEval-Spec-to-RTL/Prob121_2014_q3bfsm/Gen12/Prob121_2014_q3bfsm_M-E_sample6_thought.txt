Implement the FSM using a Moore machine style with separate combinational logic blocks for next state and output, but encode the states as an enumerated type (using a typedef enum) for enhanced readability and synthesis friendliness. Also, separate the output logic into a dedicated combinational always block driven solely by the current state. Use nonblocking assignments consistently for sequential logic and blocking assignments for combinational logic. This approach clearly segregates concerns, leverages SystemVerilog features for readability, and simplifies modifications. The synchronous reset sets the state to the initial enum value. This structure aids clarity, ease of debugging, and is synthesis-compatible with modern tools.
