To improve PPA, optimize state encoding by moving from binary to one-hot encoding. One-hot encoding typically improves timing due to simpler next-state logic and fewer logic levels, which reduces critical path delay (improving WNS and TNS). It may increase area slightly but benefits speed and power by reducing glitches in state transitions. Also, restructure next state logic to use simple combinational logic without case statements to further reduce logic depth. Keeping output logic combinational and dependent only on state bits remains effective. Use blocking assignments in combinational blocks and non-blocking in sequential. Maintain synchronous active-high reset. This approach balances improved speed and power, with a modest area increase, suitable given the original metrics.
