To simplify the FSM design while maintaining functionality, I will use binary encoding for the 5 states since 3 bits suffice to represent states 000 to 100. This reduces the number of flip-flops from 5 to 3, decreasing area and complexity. The next state and output logic will be implemented in a single combinational always block for clarity. The synchronous reset will set the state to 3'b000. The output z depends only on present state and is combinationally generated. Using binary encoding simplifies the design and is easier to read and verify.
