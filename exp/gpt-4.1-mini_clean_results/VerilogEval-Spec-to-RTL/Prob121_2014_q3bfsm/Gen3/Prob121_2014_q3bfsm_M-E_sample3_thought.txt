Implement the FSM using a one-hot encoding approach for states and a single always block that combines both next state logic and output logic. Encode each state as a separate bit in a 5-bit vector, which allows direct mapping of output z to the state vector and simplifies output logic. The synchronous reset clears all state bits except the initial state bit. The next state logic is written explicitly with simple if-else and case statements, avoiding functions, to provide clarity and potentially better synthesis optimization.
