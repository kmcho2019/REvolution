Implement the FSM using one-hot encoding with 5 flip-flops representing each distinct state, which can simplify the next-state logic by using explicit state bits and reduce decoding complexity. Use a combinational block to compute next state based on current one-hot state bits and input x. The synchronous active-high reset will clear all state bits except the bit for the initial state (000). Output z is assigned combinationally from the active one-hot state bits corresponding to states with output 1. This approach trades a slightly larger register size for simpler and potentially faster next-state logic and clearer state representation.
