To improve PPA (Timing, Power, Area), I will switch to one-hot encoding of the states. Although it uses more flip-flops (5 FFs vs 3), one-hot encoding typically simplifies next-state logic and speeds up critical paths because only one bit changes per state transition, reducing logic levels in combinational next-state logic and output decoding. This can reduce timing slack and power due to simpler logic gates. Also, registering the output z (instead of purely combinational) reduces glitching and dynamic power on output switching. I will implement synchronous reset as before, use one-hot state registers, have combinational next state and output logic, and non-blocking assignments for sequential logic. This should improve timing (better WNS, TNS), reduce glitches and dynamic power, and keep area modest despite extra FFs.
