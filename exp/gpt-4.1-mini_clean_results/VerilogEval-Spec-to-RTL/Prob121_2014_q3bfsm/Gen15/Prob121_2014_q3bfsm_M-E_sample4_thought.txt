Implement the FSM by encoding the states using a 3-bit register without using localparams for states, instead encoding states directly as constants within combinational logic for next state. Use one always block triggered on the positive edge of clk to handle both synchronous reset and state updates, but embed the next state and output logic inside this block with non-blocking updates for state and a registered output z. The output z is generated based on the registered state directly after the state update, ensuring output is synchronous with the state. This approach tightly couples state and output logic, which may help in simple pipeline timing or registers reuse in some flows.
