Implement the FSM using a one-hot state encoding approach with 5 state flip-flops, each representing one state. This encoding can simplify the combinational next state and output logic by avoiding binary decoding, and can help with fast and low-glitch state decoding. Use synchronous reset to initialize the state flip-flops, with only the first state flip-flop asserted at reset.

Define next state logic by directly computing the next state bits from the current one-hot state bits and input x, using combinational assignments. The output z is asserted when the FSM is in either of the two states corresponding to the original states 011 or 100, so simply assign z to the OR of the respective state flip-flops.

This structure reduces the complexity of combinational next state logic and explicitly separates each state as one-hot flip-flops, providing clear state identification and easy expansion, while maintaining synchronous reset and positive edge clocking.
