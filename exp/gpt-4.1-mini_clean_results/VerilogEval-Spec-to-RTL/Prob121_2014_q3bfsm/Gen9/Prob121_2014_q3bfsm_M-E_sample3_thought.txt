Implement the FSM using a one-hot encoding scheme for the five states to simplify next state and output decoding logic. Each state is represented by a dedicated flip-flop, making next state logic simple combinational logic with fewer logic levels. The output z is a combinational OR of the two states where z=1, reducing output logic complexity. The synchronous active-high reset initializes the FSM to the state 000 (encoded as only the first flip-flop set). This approach increases the number of flip-flops but may reduce combinational logic delay, improving timing performance.
