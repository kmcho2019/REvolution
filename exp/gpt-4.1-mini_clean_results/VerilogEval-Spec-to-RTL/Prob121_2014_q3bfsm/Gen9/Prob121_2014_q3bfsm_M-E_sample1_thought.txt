Implement the FSM using one-hot encoding for the state representation to simplify next state decoding and potentially improve timing by reducing combinational logic complexity. Represent each state as a single-bit flag in a 5-bit register, where exactly one bit is '1' to indicate the current state. The next state logic will be a simple combinational always block that sets only one bit based on the current state and input x. The output z will be directly assigned from the two states (S3 and S4) that produce output 1, leveraging the one-hot encoding. The state register update uses synchronous active-high reset to the initial state S0.
