Implement the FSM using a Mealy machine style by combining the next-state and output logic into a single always block triggered on the clock's positive edge. The output 'z' is registered and updated synchronously with state transitions rather than being purely combinational. This approach reduces combinational logic delay on 'z' and aligns output updates with state changes. State encoding uses localparams with a 3-bit register, synchronous active-high reset to state 000. This design simplifies timing by registering outputs and state in the same clock domain and avoids separate combinational output logic.
