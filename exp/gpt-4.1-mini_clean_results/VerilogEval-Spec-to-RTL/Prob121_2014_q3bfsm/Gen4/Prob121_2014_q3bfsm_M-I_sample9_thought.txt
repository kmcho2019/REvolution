To optimize the FSM for better power and timing (PPA), I will use one-hot encoding for the 5 states, which can reduce the combinational logic complexity for next state and output decoding, thus improving timing. Although one-hot uses more flip-flops (5 vs 3), the simpler next-state logic and fewer glitches can improve power by reducing switching in combinational logic. Also, I will combine next-state and output logic in a single always block, using non-blocking assignments properly, and make output logic purely combinational based on state. The synchronous reset is retained as required.
