Implement the FSM using one-hot encoding instead of binary encoding for states to simplify next state logic by using individual flip-flops per state. Use synchronous reset to clear all state flip-flops except the reset state. Compute the next state signals in combinational logic based on current one-hot state and input x. Output z is asserted when the FSM is in state 011 or 100, which correspond to specific one-hot bits. This approach exploits one-hot encoding to flatten logic and reduce decoding complexity, trading area for potentially faster timing and simpler state transition logic.
