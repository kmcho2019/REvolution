Implement the FSM using a single always block for both state update and output logic to tightly couple output generation with the current state, minimizing separate logic blocks. Use an explicit 3-bit register for state and decode the next state using a function that encapsulates the transition logic for better modularity and readability. Output z is assigned inside the same always block, making the design simple and synchronous with the clock. This approach emphasizes simplicity, all-in-one state and output update per clock cycle, and functional encapsulation of transition logic.
