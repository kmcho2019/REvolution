To optimize for better PPA, apply one-hot state encoding which simplifies next state decoding logic and reduces critical path delays, thus improving timing (tns and wns). One-hot encoding replaces binary 3-bit state with 5 flip-flops, each representing one state. This increases area slightly but can reduce logic levels in next-state logic, improving max frequency. Next state and output logic become simpler, reducing combinational depth. The synchronous reset sets state bits accordingly. Output z is a simple OR of the two states that produce output 1. This strategy typically improves timing metrics at the cost of slightly larger area, which is acceptable given the low original area. The code will be structured clearly with separated next state and output logic for readability and maintainability.
