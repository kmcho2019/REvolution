Implement the FSM using a one-hot encoding style for the states stored in five flip-flops (each representing one state). Use synchronous reset to set the FSM to the initial state (000). The next-state logic is implemented combinationally by decoding the current one-hot state and input x to set the next state signals accordingly. The output z is combinationally generated by OR'ing the state bits corresponding to output=1 states. This approach trades increased register count for potentially simpler next-state logic and can yield benefits in certain FPGA architectures with one-hot state machines.
