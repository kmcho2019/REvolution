Implement the FSM using a single always block triggered on the positive clock edge for both state update and output assignment. Use a simple reg to hold the state (3 bits) without named constants. Next state logic and output are embedded within the sequential block to reduce code size and complexity. Reset synchronously clears the state to 3'b000. Output z is asserted only when state is 3'b011 or 3'b100, using a simple equality check inline.
