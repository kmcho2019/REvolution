To optimize PPA, I will implement one-hot state encoding to simplify next state decoding and potentially improve timing by reducing combinational logic levels. Since we have only 5 states, a 5-bit one-hot register is used instead of a 3-bit binary encoded register. 

The FSM output z depends only on the present state, so I will separate output logic from next-state logic for clarity and better synthesis. The synchronous reset is preserved. This should reduce combinational complexity and glitches, improving timing and potentially reducing power. The area will increase moderately due to wider state register but can be offset by timing and power improvements.

I will also use non-blocking assignments in sequential logic and blocking assignments in combinational logic, following standard practice.
