Implement the FSM using a one-hot encoding approach to represent each state with a separate bit in a 5-bit state vector. This encoding often improves speed by simplifying next-state logic at the cost of extra flip-flops. On the positive clock edge, synchronously reset the one-hot state to the encoding for state 000. The next-state logic is implemented combinationally with simple if-else conditions on the one-hot state bits and input x. The output z is generated by a combinational OR of the one-hot bits corresponding to states 011 and 100, where output is 1. This architectural choice emphasizes simplified next-state logic and potentially faster synthesis results.
