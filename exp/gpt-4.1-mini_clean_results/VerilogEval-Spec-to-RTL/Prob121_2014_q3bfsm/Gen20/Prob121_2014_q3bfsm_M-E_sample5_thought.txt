Implement the FSM using a Moore machine style with an enumerated state type encoded as an integer (instead of localparams), leveraging a one-hot output assignment logic via a binary vector condition.

The approach:
1) Use a reg [2:0] to hold the state, with integer constants defined as `parameter`.
2) Implement synchronous reset and sequential state update on the rising clock edge.
3) Use a combinational block with a case statement for the next state logic.
4) Implement the output z as a combinational continuous assignment expression, based purely on the current state, to reduce always block usage.
5) This design simplifies output logic by avoiding an always block for output, relying on assign for output combinational logic, which may reduce gate count.
6) Add a default state transition fallback for robustness.
7) This approach also minimizes flip-flops (one 3-bit register) and outputs logic, offering a minimalistic, clean, and efficient FSM implementation.
