Implement the FSM using a single always block that contains both the sequential state update with synchronous reset and a combinational case statement to determine the next state and output. This approach integrates the next state and output logic in one always block triggered on the clock's positive edge, reducing separate combinational logic and ensuring all logic is synchronous. The output is registered, changing only on clock edges, which might simplify timing and reduce glitches. Using a case statement for both next state and output within the same block improves readability and aligns with a Moore FSM style. State encoding is still 3 bits with localparams for clarity.
