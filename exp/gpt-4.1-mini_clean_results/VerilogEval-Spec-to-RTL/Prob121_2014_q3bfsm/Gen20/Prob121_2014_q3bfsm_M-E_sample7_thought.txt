Implement the FSM using a one-hot encoding scheme where each state is represented by a separate flip-flop, making the state registers wider but simplifying the next-state logic and output logic to direct combinational logic. This approach reduces the decoding complexity and may improve timing by enabling easier mapping to FPGA LUTs or simple gates. The synchronous reset clears all state bits except the initial state bit. The next state logic is implemented as combinational logic generating the next state bits based on the current one-hot state and input x. The output is a combinational logic depending directly on the one-hot state signals. This approach contrasts with binary encoding, trading register width for simplified combinational logic.
