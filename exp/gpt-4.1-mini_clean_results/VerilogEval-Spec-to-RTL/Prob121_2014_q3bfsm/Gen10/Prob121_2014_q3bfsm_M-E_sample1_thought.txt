Implement the FSM using one-hot state encoding for clearer state representation and possibly improved synthesis results on certain FPGAs. Use a single always block triggered by the clock edge to handle both synchronous reset and state transitions. The next state is computed via combinational logic encoded as a function of the one-hot state bits and input x, followed by state updates. The output z is generated inside the same always block based on the current one-hot state. This approach avoids separate next-state registers and output logic, simplifying the design with one always block.
