Implement the FSM using a one-hot state encoding scheme to potentially improve timing by simplifying combinational decoding logic. Define each state as a separate bit in a 5-bit register. The synchronous reset initializes the FSM to state S0 (bit 0). The next-state logic is implemented combinationally, setting only one bit corresponding to the next state based on current state and input x. The output z is a combinational OR of the bits corresponding to states S3 and S4. This approach simplifies next-state logic since only one bit is set high at a time, improving timing at the cost of a few more flip-flops, which is acceptable for this small FSM.
