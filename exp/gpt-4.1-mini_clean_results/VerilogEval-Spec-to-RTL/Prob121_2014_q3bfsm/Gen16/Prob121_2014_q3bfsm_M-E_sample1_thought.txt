Implement the FSM using a binary encoded state stored in a 3-bit register as before, but instead of a dedicated combinational always block for next state logic, use a function that computes the next state based on the current state and input `x`. Similarly, compute the output `z` as a simple combinational assignment using a Boolean expression derived from the state bits instead of a case statement. This approach reduces the size of the combinational logic blocks by avoiding large case statements and can lead to more compact and potentially faster logic. The synchronous reset is kept active-high and triggers state to 0. The function approach encapsulates next-state logic and keeps the module readable. The output is defined combinationally outside always blocks, declared as a reg updated from state bits for synthesis friendliness.
