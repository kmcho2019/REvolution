Refactor the next-state logic by explicitly enumerating each state's next state as one-hot encoded next-state vector signals using ternary operators. Instead of multiple separate `wire` assignments for each next state, create a 10-bit `next_state` vector and assign each bit based on current state and inputs. Then derive the required next-state indicators (e.g., B3_next) by selecting the respective bit from `next_state`. Outputs remain directly derived from current state bits. This approach centralizes the next-state calculation in a single vector assignment, improving readability and making the logic more compact without changing functionality.
