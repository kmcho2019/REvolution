Instead of individually assigning each next state output, implement a combinational next_state vector (10 bits), where each bit corresponds to a next-state one-hot encoding. Then derive the requested output signals by indexing this vector. This approach centralizes next-state logic in a vector, simplifying modification and debugging.

For the combinational next_state logic:
- Use conditional expressions (ternary operators) to cleanly encode state transitions based on current state bits and inputs.
- Encode transitions using the one-hot encoding scheme explicitly, without intermediate wires for each next state.
- Outputs are derived from next_state bits and current state bits as specified.

This modular next_state vector approach improves clarity and scalability, enabling easier extension or modification of the FSM. It also reduces redundancy by computing all next states in a single vector, then extracting specific signals.

The outputs `done`, `counting`, and `shift_ena` are based on current states per Moore machine definition, so they are derived directly from the current state vector. Next-state signals (like B3_next) are derived from next_state bits.

This gives a clean, fully combinational description of next state and output signals while maintaining explicit one-hot style and avoiding repetitive logic.
