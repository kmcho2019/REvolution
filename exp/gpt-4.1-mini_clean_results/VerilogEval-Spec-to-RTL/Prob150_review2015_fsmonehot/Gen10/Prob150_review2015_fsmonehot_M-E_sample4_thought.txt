Implement the next-state and output logic by explicitly enumerating all next states as one-hot bits, each defined by a separate Boolean equation derived directly from the current state and inputs. Instead of using intermediate signals for next states coming from each state separately, create explicit equations for each next state bit based on OR-ing all transitions to that state. This allows straightforward tracing of all transitions that lead to a particular next state.

Outputs are assigned directly from the current state, consistent with Moore FSM behavior. This approach emphasizes an explicit, symmetrical style for next-state logic, listing all next states from all source states in a single assignment per next state bit, enhancing clarity and completeness without intermediate wires. The design is purely combinational and ready for synthesis.
