Instead of directly writing next-state logic as multiple OR terms, exploit the one-hot encoding by expressing the next state as a combination of mutually exclusive conditions, using intermediate signals representing each state's next-state condition. This enables a more readable structure: define each next-state signal as a single equation derived from current state and inputs, then assign output signals from current states as per Moore machine requirements.

We explicitly define next state signals for all states (S, S1, S11, S110, B0, B1, B2, B3, Count, Wait). The chain of states B0 to B3 is handled with simple shift of one-hot signals since the FSM always progresses sequentially. For states S, S1, S11, S110 we encode transitions based on input 'd' precisely. Similarly for Count and Wait states, we use 'done_counting' and 'ack' signals respectively.

Outputs are asserted based only on current state bits (shift_ena for B0-B3, counting for Count, done for Wait). Finally, next state output signals (B3_next, S_next, etc.) correspond exactly to the next state one-hot bit signals. This approach improves clarity and modularity by separating next-state definitions for all states before selecting outputs.
