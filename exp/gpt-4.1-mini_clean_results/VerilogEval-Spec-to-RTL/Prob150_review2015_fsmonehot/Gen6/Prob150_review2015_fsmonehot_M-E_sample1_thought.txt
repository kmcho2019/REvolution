Instead of directly encoding next states using ORs of multiple current states, compute intermediate signals representing conditions to enter each next state, taking advantage of the mutually exclusive one-hot encoding. This approach introduces explicit enable signals for next states from current states combined with inputs, making the code more modular and potentially easier to extend or modify. Outputs are defined purely by the current state as per Moore FSM semantics. The next state signals correspond to asserted next states, directly mapping to the FSM diagram conditions. This approach clearly separates state decoding, next state generation, and output logic combinationally.
