Use one-hot encoded states to derive next-state logic by explicitly enumerating each state's possible transitions and outputs as separate combinational assignments. Implement each next-state bit as a function of current states and inputs with minimal logic sharing, favoring clarity over minimalism. Define next-state outputs (B3_next, S_next, etc.) as direct assignments to the one-hot state bits that will be active in the next cycle. Similarly, outputs (done, counting, shift_ena) are asserted only in the states as specified. This approach gives fully decomposed next-state assignments per bit and makes the code easy to read and maintain.
