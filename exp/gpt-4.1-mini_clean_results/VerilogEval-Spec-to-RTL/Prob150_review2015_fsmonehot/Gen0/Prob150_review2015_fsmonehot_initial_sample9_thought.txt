Implement combinational next-state and output logic for the given Moore machine with one-hot encoded states. Each next-state signal is asserted when the FSM moves into the corresponding state, based on current state and inputs (d, done_counting, ack). Outputs (shift_ena, counting, done) are asserted based on the current state according to the specification. The inputs are single bit except state (10 bits one-hot). We implement combinational logic only, deriving next states by inspection for the given encoding and transitions.
