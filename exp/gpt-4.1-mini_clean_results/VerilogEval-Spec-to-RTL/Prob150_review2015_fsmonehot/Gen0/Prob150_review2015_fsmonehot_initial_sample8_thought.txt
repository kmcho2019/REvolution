Implement combinational next-state and output logic of a Moore FSM with given states one-hot encoded in a 10-bit vector `state`. Inputs are `d`, `done_counting`, and `ack`. The next state is a 10-bit one-hot vector with only one bit asserted for the next state.

We decode the current state from the one-hot `state` input bits:

S=state[0], S1=state[1], S11=state[2], S110=state[3], B0=state[4], B1=state[5], B2=state[6], B3=state[7], Count=state[8], Wait=state[9].

Next-state logic by state:

- From S: if d=0 next S, if d=1 next S1
- From S1: if d=0 next S, if d=1 next S11
- From S11: if d=0 next S110, if d=1 next S11
- From S110: if d=0 next S, if d=1 next B0
- From B0: always next B1
- From B1: always next B2
- From B2: always next B3
- From B3: always next Count
- From Count: if done_counting=0 next Count, else next Wait
- From Wait: if ack=0 next Wait, else next S

Output signals:

- shift_ena asserted in B0, B1, B2, B3 next state
- counting asserted in Count next state
- done asserted in Wait next state

We will implement combinational logic to compute next state bits and outputs using the given input signals and current state vector.

Finally, output signals indicating which state will be next are produced by decoding next state bits.

This is a purely combinational module with inputs `state`, `d`, `done_counting`, `ack` and outputs next state bits and outputs.
