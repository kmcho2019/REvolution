Implement next-state logic and output logic for the Moore FSM using one-hot encoding for the states. Inputs are d, done_counting, ack; outputs are shift_ena, counting, done. 

Next states:
- For states S, S1, S11, S110: next state depends on d.
- For B0, B1, B2, B3: next state is the next B state (B1, B2, B3, Count) unconditionally.
- For Count: stays in Count if done_counting=0; moves to Wait if done_counting=1.
- For Wait: stays in Wait if ack=0; moves to S if ack=1.

From one-hot current state (state[9:0]), generate next state signals (B3_next, S_next, S1_next, Count_next, Wait_next).

Output logic (Moore machine) sets shift_ena=1 for B0, B1, B2, B3; counting=1 for Count; done=1 for Wait.

Express next-state signals as logic expressions by inspecting transitions with current state signals and inputs.
