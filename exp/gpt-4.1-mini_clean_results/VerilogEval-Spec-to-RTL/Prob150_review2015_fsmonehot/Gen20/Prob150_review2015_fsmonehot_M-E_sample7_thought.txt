Implement the combinational next-state and output logic using explicit case statements over the current one-hot encoded state bits for clarity and ease of understanding. Instead of writing direct equations, decode the current state by checking which bit is set, then compute all next state signals as outputs accordingly based on the transitions and inputs.

This approach decouples the logic from equation factoring and enables straightforward modification or extension. It also neatly groups next-state assertions, making it clear which next state is enabled per current state and input conditions.

Finally, output signals done, counting, and shift_ena are directly assigned based on the current state as defined. This method also helps avoid complex Boolean expressions and can be efficiently synthesized since one-hot states are mutually exclusive.

All outputs (B3_next, S_next, S1_next, Count_next, Wait_next, done, counting, shift_ena) are declared combinational and assigned with a combinational always @(*) block.
