Use explicit one-hot encoding decoding to identify the current state, then use a case statement on the one-hot encoding (decoded to an enumerated state index) to directly specify the next state bits and outputs. This approach models the next state as a one-hot vector calculated combinationally by a parallel mux-style structure, generating the required next state signals and outputs cleanly. This differs by using a combinational always block with a case on the current state instead of direct boolean equations, improving clarity and extensibility while meeting the specification.
