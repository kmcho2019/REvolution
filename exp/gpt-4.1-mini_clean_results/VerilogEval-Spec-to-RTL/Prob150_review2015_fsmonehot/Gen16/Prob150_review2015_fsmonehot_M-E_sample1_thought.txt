Use one-hot encoding to identify the current state, then generate next-state signals by explicitly enumerating transitions based on the current state and inputs. Each next state output is asserted when the next state of the FSM corresponds to that state, derived by applying the transition conditions directly. Outputs (done, counting, shift_ena) are asserted based purely on the current state bits since this is a Moore machine. This approach maximizes clarity and straightforward traceability of each transition and output signal from the FSM diagram.
