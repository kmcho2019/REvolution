Implement the XNOR gate by using only NAND gates, leveraging the fact that NAND is a universal gate. The XNOR function can be composed using a combination of NAND gates as follows:

1. Compute intermediate signals: 
   - nand_ab = NAND(a, b)
   - nand_a_a = NAND(a, a) which is NOT a
   - nand_b_b = NAND(b, b) which is NOT b
   - nand_nand_a_b = NAND(nand_a_a, nand_b_b) which is NAND(NOT a, NOT b)
2. Final output: XNOR = NAND(nand_ab, nand_nand_a_b)

This method avoids using any NOT, AND, or OR gates explicitly and only uses NAND gates, illustrating the universality of NAND gates for logic synthesis.
