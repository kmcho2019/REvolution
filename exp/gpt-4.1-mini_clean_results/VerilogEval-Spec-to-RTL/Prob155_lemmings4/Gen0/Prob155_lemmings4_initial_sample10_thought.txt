Design a Moore FSM with the following states: WALK_LEFT, WALK_RIGHT, FALLING_LEFT, FALLING_RIGHT, DIGGING_LEFT, DIGGING_RIGHT, SPLATTERED.

- WALK_LEFT and WALK_RIGHT represent walking states; outputs walk_left=1 or walk_right=1.
- FALLING_LEFT and FALLING_RIGHT represent falling states; output aaah=1.
- DIGGING_LEFT and DIGGING_RIGHT represent digging states; output digging=1 and walking direction.
- SPLATTERED state outputs all 0 permanently until reset.

Transitions:
- From WALK states: 
    - If ground=0, go to FALLING state matching current direction.
    - Else if dig=1, go to DIGGING state matching current direction.
    - Else if bump_left or bump_right is 1 (either side), flip walking direction.
- From DIGGING states:
    - If ground=0, go to FALLING state matching current direction.
    - Otherwise, keep digging.
- From FALLING states:
    - Increment a fall counter each clock while falling.
    - If ground=1, check counter:
        - If >20, go to SPLATTERED.
        - Else return to WALK state matching direction.
    - While falling, ignore bump or dig inputs.
- SPLATTERED: no outputs, no transitions except reset.

Outputs depend on current state, consistent with Moore FSM style.

Implement synchronous positive-edge clock state and counter updates, async positive edge reset to WALK_LEFT and clear fall counter.

Fall counter resets on leaving FALLING states.

Encode states in an enum or parameter block for clarity.
