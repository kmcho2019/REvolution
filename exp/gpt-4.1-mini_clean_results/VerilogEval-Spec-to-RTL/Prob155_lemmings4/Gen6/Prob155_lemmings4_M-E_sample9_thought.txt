Implement the Lemmings FSM using a single enumerated state variable that combines both mode and direction into one 4-bit state, encoding walking left/right, digging left/right, falling left/right, and splattered states explicitly. This avoids separate direction and mode registers and clarifies outputs as simple state matches. The states are:

- WALK_L, WALK_R
- DIG_L, DIG_R
- FALL_L, FALL_R
- SPLAT (no direction)

On bumps, the FSM switches walking direction only if currently walking and not falling or digging. Digging can only start when walking on ground. Falling overrides both digging and bumping, and falling direction is maintained from prior state. The fall timer counts cycles only during falling, saturating at max 31. If fall timer >20 upon landing, transition to SPLAT. 

This architecture uses a single state variable encoding both direction and activity, simplifying output logic and prioritizing the events explicitly in a neat case statement. The asynchronous reset sets the FSM to WALK_L state with fall timer cleared.

Advantages:
- Single state variable reduces complexity of direction/mode interaction.
- State machine is fully enumerated, easing debugging and synthesis.
- Moore outputs become simple comparisons.
- Fall timer logic cleanly embedded in falling states.
- Bump handling updates walking states only.
- Dig command honored only when walking on ground.
- Transition priorities (fall > dig > bump) clearly implemented.

This approach is novel compared to separate mode/direction registers and allows compact, understandable logic with minimal extra registers.
