Use a combined state/direction encoding in a single 3-bit register to reduce separate signal handling and simplify transitions. The three bits encode both mode and direction:  
- bit2: mode (00 = walk, 01 = dig, 10 = fall, 11 = splat)  
- bit1: direction (0 = left, 1 = right) - only meaningful in walk/dig/fall modes  
- bit0: reserved (unused for simplicity, or can be used later)  

This encoding enables compact next-state logic by directly switching modes and directions in a single register update.  

For fall timing, use a 5-bit timer incremented only while falling. Upon ground landing, check if timer >20 to splat. Timer resets otherwise.  

All inputs are synchronized to the clock to avoid glitches. Digging starts only when walking on ground. Priority: fall > dig > bump.  

Use synchronous reset to initialize state to walking left mode.  

Outputs are decoded directly from state bits: walking direction, digging, falling, or splatted (all zero).  

This architectural approach minimizes separate direction register and consolidates FSM state into one reg, reducing logic fanout and improving clarity.
