Optimize the FSM for better Power, Performance, and Area (PPA) by:

1. Combining `state` and `dir` into a single 3-bit register `state_dir`:
   - Encoding direction as the LSB of the state to reduce the number of registers and mux complexity.
   - This merges direction and state, simplifying next-state logic and possibly reducing muxes and flip-flops.

2. Factoring out common assignments in the next-state logic to reduce combinational complexity.

3. Gating the fall_count counter update to only increment when actually falling, preventing unnecessary toggling.

4. Reducing fall_count max saturation logic using simple saturated increment to minimize logic depth.

5. Using enumerated states with direction embedded:
   - e.g., WALK_LEFT = 3'b000, WALK_RIGHT = 3'b001, FALL_LEFT = 3'b010, FALL_RIGHT = 3'b011, DIG_LEFT = 3'b100, DIG_RIGHT = 3'b101, SPLAT = 3'b110 (direction irrelevant).

6. Outputs derived directly from combined state bits, eliminating separate `dir` signal.

7. Maintain asynchronous positive edge reset.

8. Keep Moore FSM style and preserve all original behavior and priorities.

This reduces state and direction register count from 2 + 1 = 3 bits to a single 3-bit register representing combined state and direction, simplifying next state and output logic and reducing overall logic and potentially the critical path.

Also, output assignments are simplified based on combined state codes.

This approach yields better PPA due to simpler FSM encoding and reduced registers and muxing complexity.
