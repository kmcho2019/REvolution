Represent the FSM states as WALK_LEFT, WALK_RIGHT, DIG, FALL, SPLAT to directly encode both walking direction and action in the state, removing the separate direction register. This reduces complexity by eliminating the separate direction signal and simplifies direction updates on bumps.

Make state transitions clear and direct: from WALK_LEFT or WALK_RIGHT, switch direction on bumps, fall if ground lost, or dig if dig input is asserted. From DIG, fall if ground lost, else stay digging. From FALL, count fall duration and transition to SPLAT if fall duration exceeds 20 upon landing, else resume previous walk direction stored in the state. SPLAT is terminal.

Use a 5-bit counter for fall duration that increments only in FALL and resets elsewhere.

Moore outputs derive straightforwardly from current state: WALK_LEFT/WALK_RIGHT for walking outputs, DIG state for digging output, FALL state for aaah.

Asynchronous reset sets FSM to WALK_LEFT with fall_timer zero.

This approach avoids multiple signals for direction and simplifies next-state logic, yielding clearer, more compact code with identical behavior.
