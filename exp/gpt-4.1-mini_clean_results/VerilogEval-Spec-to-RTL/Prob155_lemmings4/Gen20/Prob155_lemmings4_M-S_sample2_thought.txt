We can simplify the FSM by directly encoding the walking direction in a single bit and only changing it on bumps during walking, avoiding nested ternary expressions. We keep the 2-bit mode and 5-bit saturating fall timer as before but initialize next state variables at the top to current values to reduce code repetition. The fall timer increments only when falling, and resets otherwise. Outputs are simple Moore signals from the mode and direction bits. The asynchronous reset remains. This minimal approach keeps all behavior intact with less complexity and clearer code.
