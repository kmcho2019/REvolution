Implement the FSM with a single 3-bit state register encoding combined mode and direction states. This encoding represents walking left/right, digging left/right, falling left/right, plus a splat state ignoring direction.

The states:
- WALK_LEFT (3'b000), WALK_RIGHT (3'b001)
- DIG_LEFT (3'b010), DIG_RIGHT (3'b011)
- FALL_LEFT (3'b100), FALL_RIGHT (3'b101)
- SPLAT (3'b110)

Direction is implicitly part of the state encoding, removing the separate direction register.

Use a 5-bit fall timer counting cycles in falling states; when exceeding 20 cycles and ground returns, transition to SPLAT.

FSM transitions are prioritized in combinational logic: 
1. If ground=0 (fall priority), switch to falling state in the current direction; start/increment fall timer.
2. If dig=1 and on ground walking, move to dig state matching direction.
3. If bumped while walking and on ground, reverse direction and remain walking.
4. If ground returns while falling, if fall timer > 20, splat; else resume walking in falling direction.
5. While digging, if ground disappears, transition to falling in dig direction.

Outputs are generated from the state bits: walking states enable walk_left or walk_right, digging states enable digging, falling states enable aaah, splat state disables all outputs.

Use synchronous reset active high for simplicity and clarity.

This tightly encoded FSM reduces registers from 4 to 2 (state and fall timer), removes the separate direction register, and simplifies logic for output and state updates. It also handles the splat state as a distinct final state without direction, making outputs simpler.
