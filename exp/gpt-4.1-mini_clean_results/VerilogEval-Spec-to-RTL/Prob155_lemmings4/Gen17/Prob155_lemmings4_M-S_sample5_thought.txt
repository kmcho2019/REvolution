Use a single bit state to encode direction (0=left,1=right) and a 2-bit state for mode: WALK, DIG, FALL, SPLAT. In combinational logic, prioritize transitions: if falling (ground=0) then FALL, else if digging requested and on ground then DIG, else WALK with bump-triggered direction changes. Use a single always block to update state, direction, and fall timer synchronously with clear reset. The fall timer increments only during FALL state and resets otherwise. Outputs are simple combinational expressions of state and direction. This reduces state and register count, uses fewer variables, and simplifies next-state logic while preserving all behavior and priority.
