Use a straightforward always block to compute next state and next fall count with clear priorities (fall > dig > bump).  
Remove separate direction logic by embedding direction in the state name, making output logic trivial.

Use synchronous reset for clarity since asynchronous reset complicates logic; handle asynchronous reset with synchronous assignments if necessary.
