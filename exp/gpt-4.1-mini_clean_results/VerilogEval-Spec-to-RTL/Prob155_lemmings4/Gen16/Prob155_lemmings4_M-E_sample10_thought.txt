Implement the Lemmings FSM using a single 3-bit state register encoding both mode and direction, with the following states:

- 0: walk left
- 1: walk right
- 2: dig left
- 3: dig right
- 4: fall left
- 5: fall right
- 6: splat (direction irrelevant)

This compact encoding allows easy combination of mode and direction in one register. The FSM transitions and outputs are based on these states.

Use a synchronous positive-edge reset (areset) to initialize to walk left state.

Maintain a separate 5-bit fall_timer register that increments while falling, resets otherwise.

Transition priority is fall > dig > bump, enforced in combinational next-state logic.

Update direction only on bumps while walking. During dig and fall, direction is fixed.

On hitting ground after falling, splat if fall_timer > 20; otherwise resume walking in the same direction.

Digging ends and falling begins if ground disappears.

Outputs are decoded combinationally from the current state (Moore outputs).

This approach minimizes state registers and logic while maintaining clarity and full functionality.
