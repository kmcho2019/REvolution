Instead of using a single combined FSM state to encode all behaviors, separate the direction and mode (walking, digging, falling, splatting) into two independent state registers for cleaner modularity. Use one 2-bit state machine to track the mode (WALK, DIG, FALL, SPLAT), and a single bit to track direction (left or right). On each clock, update the mode with strict priority fall > dig > walk or splat. Use a separate fall timer counter that increments only during FALL mode and triggers SPLAT when threshold exceeded. Bumps only affect direction when in WALK mode and ground present, and are ignored during FALL, DIG, or SPLAT. This separation simplifies handling logic and allows independent updates, resulting in clear and maintainable code. Outputs depend purely on mode and direction (Moore outputs).
