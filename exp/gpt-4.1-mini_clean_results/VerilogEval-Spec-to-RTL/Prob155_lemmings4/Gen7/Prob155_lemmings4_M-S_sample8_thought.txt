Use a simpler FSM with three states: WALK, DIG, and FALL (combine SPLAT as a terminal state). Use one direction bit and a fall counter.  
On bump in WALK, directly set direction based on bump inputs: if bump_left, walk right; if bump_right, walk left; if both, toggle direction.  
Prioritize fall detection first, then dig command only when walking on ground. While digging, ignore bump and dig inputs until ground lost.  
When falling, increment fall timer until landing; if timer > 20, enter SPLAT state where all outputs are zero.  
Avoid unnecessary register updates by only updating direction or timer when changed.  
This reduces control signals and simplifies case handling while keeping all required behavior.
