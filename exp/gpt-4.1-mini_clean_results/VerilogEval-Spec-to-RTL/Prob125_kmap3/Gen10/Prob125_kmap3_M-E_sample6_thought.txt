Implement the Karnaugh map logic using a 4-to-1 multiplexer controlled by inputs 'a' and 'b', selecting among precomputed values based on 'c' and the don't-care 'd'. Specifically:

- Use (a, b) as the select inputs of the MUX (2 bits).
- For each selection, assign the output based on the Karnaugh map values for given c and d.
- Exploit the 'd' (don't-care) values to assign convenient constants in the multiplexer inputs.
- This approach modularizes the function, making it clear and efficient by representing the function as a lookup table using a MUX.

This is a novel structural approach compared to sum-of-products or factored expressions, and it leverages the truth table interpretation directly.
