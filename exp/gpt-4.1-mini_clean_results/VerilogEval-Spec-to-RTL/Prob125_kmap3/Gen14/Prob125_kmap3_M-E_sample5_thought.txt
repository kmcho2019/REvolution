Implement the Karnaugh map function using a multiplexing approach, treating inputs 'a' and 'b' as select lines to a 4-to-1 multiplexer that outputs values based on the (a,b) combination, and then use 'c' to choose between two precomputed values. Since 'd' is don't-care, ignore it.

Specifically:
- Treat 'a' and 'b' as a 2-bit select input: sel = {a,b}
- For c=0, output values based on row cd=00 and 01 entries.
- For c=1, output values based on row cd=10 and 11 entries.
- Since d is don't care, assign values accordingly.
- This modular approach abstracts the logic into two multiplexers in hierarchy, which can ease gate-level optimizations and provide a clear mapping from Karnaugh table to code.
