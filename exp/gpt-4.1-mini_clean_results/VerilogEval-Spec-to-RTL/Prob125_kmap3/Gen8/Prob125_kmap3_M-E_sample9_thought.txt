Implement the logic function using a 4-to-1 multiplexer (MUX) that selects the output based on inputs c and d, which index the rows of the Karnaugh map, and use combinational logic for the selected row's column outputs based on a and b. Since d is a don't-care, the MUX input values for d=0 or d=1 can be chosen arbitrarily where the Karnaugh map has don't-cares.
