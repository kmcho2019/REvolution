Implement the Karnaugh map logic using a multiplexing approach controlled by variables 'a' and 'b'.

- Use 'a' and 'b' as select lines to choose one of four predefined outputs based on 'c' (and ignore 'd' since it's don't-care).
- For each combination of 'a' and 'b', define the output as a function of 'c' that matches the Karnaugh map entries.
- This technique leverages a 4-to-1 multiplexer structure, promoting clarity and structured logic decomposition.
- This approach provides a novel architecture compared to pure combinational sum-of-products, reducing direct logic gates and demonstrating modular design.
