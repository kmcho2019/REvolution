A JK flip-flop can be directly implemented using the toggle behavior when both inputs are 1, and otherwise setting or resetting Q based on J and K. Since the problem only requires a single-bit output Q and synchronous update on the rising clock edge, the simplest approach is to explicitly code the cases inside a clocked always block using if-else statements. This removes the need for logic equations and makes the behavior immediately clear and easy to understand while maintaining exact functionality.
