Implement a JK flip-flop that updates output Q on the positive edge of clk according to the JK truth table:
- If J=0 and K=0, retain previous Q (Qold)
- If J=0 and K=1, reset Q to 0
- If J=1 and K=0, set Q to 1
- If J=1 and K=1, toggle Q
The Q output should be updated synchronously at each positive clock edge.
