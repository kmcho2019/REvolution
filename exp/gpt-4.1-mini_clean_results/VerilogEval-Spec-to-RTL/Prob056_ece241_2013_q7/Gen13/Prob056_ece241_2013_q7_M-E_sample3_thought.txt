Implement the JK flip-flop using an explicit case statement within a synchronous always block triggered on the positive clock edge. This approach clearly maps each (J,K) combination to the next state, explicitly following the truth table. Such an implementation enhances code readability and maintainability while ensuring the logic remains correct and synthesizable.

Instead of using a combinational expression, the case statement approach explicitly encodes the behavior and can help synthesis tools optimize or verify state transitions clearly. It also allows easy extension in the future, such as adding asynchronous reset or preset signals if desired.

The output Q is declared as a reg since it is assigned in a sequential always block.
