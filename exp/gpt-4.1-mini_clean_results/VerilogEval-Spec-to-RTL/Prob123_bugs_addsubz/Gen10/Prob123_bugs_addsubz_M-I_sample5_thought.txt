To improve power, performance, and area (PPA), I will unify addition and subtraction into a single adder-subtractor block using the input do_sub as a control signal. This avoids duplicating logic by computing only one arithmetic operation per cycle, reducing power consumption and area. The subtraction will be implemented using two's complement by conditionally inverting the second operand and adding one, controlled by do_sub. The zero flag will be updated in the same combinational block by checking if the output is zero. This unified approach reduces combinational delay and logic duplication, improving performance, power, and area compared to the previous solution that instantiated separate adder and subtractor modules.
