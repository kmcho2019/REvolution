Instead of using a case statement, implement the adder-subtractor by performing the addition with b conditionally complemented and an added carry-in, effectively using one adder for both operations. This is done by XOR-ing b with do_sub to complement it when subtracting, and adding do_sub as the carry-in to complete two's complement subtraction. This approach simplifies the logic and makes it more uniform. The zero flag is set by explicitly comparing the result to zero.
