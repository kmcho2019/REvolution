To provide a new architectural approach different from the conditional operator or case statement, I will implement the adder-subtractor using a single adder with operand B conditionally inverted and the carry-in set accordingly, which is a classic two's complement subtraction technique.

- For subtraction (do_sub=1), invert B and set carry-in to 1 for a-b = a + ~b + 1.
- For addition (do_sub=0), use B directly and carry-in=0.
- This approach allows the arithmetic to be done in one addition operation.
- The zero flag will be set using a reduction NOR operator (~|out) for efficient zero detection.
- The entire logic will be implemented in combinational always block, ensuring no latch inference.
- This is a classic adder-subtractor implementation style and differs from the previous direct conditional assignment.
- Use intermediate signals for clarity and potential re-use in more complex designs.
