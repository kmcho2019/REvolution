I will implement the adder-subtractor in a single always block using a conditional XOR on the b input and adding the carry-in as do_sub. This is a classic method to combine addition and subtraction using one adder by exploiting two's complement: subtraction a - b = a + (~b + 1). Here, the b input bits are XORed with do_sub, effectively inverting them if subtraction is desired, and do_sub serves as the carry-in. This saves logic by not duplicating add and subtract logic. Then, the zero flag is assigned correctly using an explicit else clause to cover all cases. This approach differs from the previous modular and dual-adder designs by consolidating into a single combinational adder with conditional operand negation.
