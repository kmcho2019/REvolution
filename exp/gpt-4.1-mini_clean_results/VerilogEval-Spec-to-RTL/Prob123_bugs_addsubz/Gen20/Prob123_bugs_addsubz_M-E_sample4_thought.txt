Instead of using a two's complement approach with conditional inversion and carry-in, I will build an explicit 8-bit adder and an 8-bit subtractor using separate combinational logic blocks and select the output using a mux controlled by do_sub. This modular approach clarifies the operations and allows independent verification of each arithmetic operation. The zero flag will be computed by directly checking the final output for zero, ensuring that the flag is updated correctly. Although this approach duplicates some logic and may use more resources, it improves design clarity and correctness, explicitly separating addition and subtraction paths.
