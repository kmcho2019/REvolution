I will simplify the logic by using the built-in Verilog operators for addition and subtraction directly with an if-else statement inside a combinational always block. This removes the intermediate wires and separate full adder expression, making the code easier to read while maintaining the same functionality.

For the zero flag, I'll retain the reliable reduction NOR operator (~|out) to detect when the output is zero.

This minimal approach reduces complexity without sacrificing correctness or synthesizability.
