Since the output is declared as a single bit but the inputs are 8-bit vectors, an alternative approach is to select a single bit position from either `a` or `b` based on `sel`. For example, fix the output to be the least significant bit (bit 0) of the selected input vector. This preserves the 1-bit output port while implementing a meaningful 2-to-1 mux: when sel=0, output the LSB of `a`; when sel=1, output the LSB of `b`.
