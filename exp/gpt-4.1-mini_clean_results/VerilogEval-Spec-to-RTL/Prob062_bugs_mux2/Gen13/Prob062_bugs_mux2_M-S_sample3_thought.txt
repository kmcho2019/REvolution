Since the output is a single bit, the 8-bit inputs must be combined accordingly to produce one bit. A 2-to-1 mux for scalar output selects one bit from either input `a` or input `b` based on `sel`. The simplest way is to select a specific bit (for example, bit 0) from `a` or `b`. Using a continuous assignment with the ternary operator makes the code simple and clear.
