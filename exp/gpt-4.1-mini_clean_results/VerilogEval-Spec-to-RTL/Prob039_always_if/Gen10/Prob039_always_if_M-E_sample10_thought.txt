Implement the 2-to-1 mux selection using a procedural always_comb block for the out_always output and a parallel assign statement for out_assign. To add novelty, internally create a single intermediate signal that represents the selected input (a or b) based on sel_b1 and sel_b2 conditions. Then use this intermediate signal to drive both outputs: out_assign via continuous assignment and out_always updated inside the always_comb block. This approach separates the combinational logic from output assignments and clearly illustrates the difference between continuous assignment and procedural assignment, while also avoiding duplicated selection logic.
