Create a 2-to-1 multiplexer that selects between inputs a and b based on the condition that both sel_b1 and sel_b2 are true. Implement the logic once by computing an intermediate select signal using an AND gate, and then use this select signal in two different ways: first, in a continuous assignment using the select signal; second, in a procedural always block where the select signal determines the output via a case statement. This approach introduces an explicit select signal and uses a case statement to showcase an alternative procedural style.
