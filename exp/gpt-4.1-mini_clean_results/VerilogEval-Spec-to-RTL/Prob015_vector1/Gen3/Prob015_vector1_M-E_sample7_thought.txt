Instead of directly assigning the slices of the input vector to the outputs, this alternative approach uses an always_comb block with a temporary 8-bit register for each output. The block explicitly extracts each byte by bit-wise shifting and masking. Although functionally equivalent, this approach illustrates a behavioral style using procedural assignment within a combinational always block, which some designers prefer for clarity or for future extensibility (e.g., adding conditional logic). The outputs remain wires driven by these registers to ensure combinational semantics.
