Implement the TopModule without an intermediate module by using always_comb block with concatenation and slicing. This approach demonstrates an alternative style using behavioral combinational logic instead of continuous assignments. The input 16-bit vector is split into out_hi (upper byte) and out_lo (lower byte) inside an always_comb block triggered by any input change. This shows a different architectural style, while still producing purely combinational logic with clear separation of output byte extraction, which is synthesizable and straightforward.
