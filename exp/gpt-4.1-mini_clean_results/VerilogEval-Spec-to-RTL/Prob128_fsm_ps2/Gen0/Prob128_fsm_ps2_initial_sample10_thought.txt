Implement a synchronous FSM with states: IDLE, BYTE2, BYTE3. Initially, in IDLE, discard bytes until a byte with in[3]=1 is received, which marks the first byte of a message. Then go to BYTE2 state to accept the second byte, then BYTE3 for the third byte. After the third byte is received, assert done for one clock cycle and return to IDLE to search for the next message start. Reset synchronously brings FSM back to IDLE and clears done.
