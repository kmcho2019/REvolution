Implement a FSM with four states: IDLE, BYTE1, BYTE2, BYTE3. Initially, FSM is in IDLE state discarding input bytes until a byte with in[3]=1 is seen. Once that byte is detected, move to BYTE1 state to mark the first byte of the message. Next clock cycle move to BYTE2 to accept the second byte, then BYTE3 for the third byte. After receiving the third byte, assert done for one clock cycle, then return to IDLE and repeat the process. The reset signal synchronously sets FSM to IDLE and clears done.
