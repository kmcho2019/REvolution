Implement a FSM with four states: IDLE, BYTE1, BYTE2, BYTE3. Initially, in IDLE, discard bytes until a byte with in[3]=1 is received, transition to BYTE1 state (counting the first byte). Then move to BYTE2 and BYTE3 on each clock cycle receiving new bytes. After receiving the third byte (BYTE3 state), assert done for one clock cycle and then return to IDLE, ready to search for the next message. Reset is synchronous active high and sets FSM back to IDLE with done de-asserted.
