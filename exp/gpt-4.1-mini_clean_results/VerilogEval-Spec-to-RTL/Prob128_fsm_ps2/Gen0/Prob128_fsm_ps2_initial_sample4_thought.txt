Design a FSM with states to track message reception: IDLE (searching for first byte), BYTE2 (received first byte), BYTE3 (received second byte). On reset, go to IDLE. On each clock, if in IDLE, wait for in[3]=1 to identify start of message and move to BYTE2. On BYTE2, accept next byte and move to BYTE3. On BYTE3, accept next byte, then assert done for one cycle and return to IDLE. The done signal is asserted for one clock cycle immediately after the third byte is received.
