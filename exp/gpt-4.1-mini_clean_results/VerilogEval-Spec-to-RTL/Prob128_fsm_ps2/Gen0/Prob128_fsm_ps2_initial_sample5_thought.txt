Implement an FSM with states to track the position in the 3-byte message: WAIT_FOR_START, BYTE2, BYTE3.
Initially, the FSM waits for a byte with in[3] = 1 to start a message.
Upon receiving the first byte, transition to BYTE2, then BYTE3 for subsequent bytes.
After the third byte, assert done for one clock cycle, then return to WAIT_FOR_START to look for the next message.
Use synchronous reset to reset the state and done signal.
