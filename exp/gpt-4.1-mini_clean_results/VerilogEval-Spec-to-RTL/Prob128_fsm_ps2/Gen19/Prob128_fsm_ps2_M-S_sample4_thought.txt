Eliminate the explicit count variable by using a 2-bit shift register that shifts in a 'start' signal when a byte with in[3]=1 is detected, indicating the first byte. The register tracks how many bytes have been received by shifting in ones each cycle. When the shift register reaches 3 (3'b111), the done signal is asserted one cycle after receiving the third byte and then the register is cleared. This reduces explicit state and conditions, using shift and simple logic only.
