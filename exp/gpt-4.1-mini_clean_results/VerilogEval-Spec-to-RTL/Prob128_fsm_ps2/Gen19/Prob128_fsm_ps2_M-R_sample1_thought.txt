Refactor the design to use an explicit two-state FSM encoding: IDLE (waiting for start byte) and COUNTING (counting bytes within a message). A 2-bit counter will track how many bytes have been received after detecting the start byte. The done signal will be registered and asserted in the cycle immediately after receiving the third byte. Instead of using a single count register with mixed logic, separate state and count registers improve code clarity and modularity. The done signal is driven from a registered condition. This explicit FSM structure aids readability and maintainability, with the same power, performance, and area characteristics.
