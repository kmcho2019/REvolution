Refactor the design by implementing an explicit state machine with three states: IDLE (waiting for a start byte), BYTE2 (received first byte, waiting for second), and BYTE3 (received second byte, waiting for third). Transition between states based on input bytes. Use a combinational always block for next state logic and done signal generation, and a sequential always block for state register and synchronous reset. The done output is asserted for one cycle after the third byte is received. This structure clarifies FSM behavior and separates combinational and sequential logic for readability and potential ease of formal verification.
