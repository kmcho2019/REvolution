The PS/2 mouse message detection requires tracking three bytes per message, starting with a byte having in[3]=1. Instead of a counter, we can use a simple 2-bit state machine representing the byte position within a message: IDLE (waiting for start byte), BYTE2, BYTE3. When in IDLE, check for start byte (in[3]=1); if detected, move to BYTE2. Then sequentially advance states with each clock, asserting done immediately after receiving the third byte and returning to IDLE. This reduces logic and registers by avoiding explicit counters and done timing logic. The done signal is asserted synchronously right after the third byte, meeting requirements simply and clearly.
