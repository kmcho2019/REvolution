Implement a three-state FSM with an explicit state encoding: IDLE, BYTE1, BYTE2. In IDLE, wait until a byte with in[3]=1 arrives, then transition to BYTE1. Upon receiving a byte in BYTE1, move to BYTE2. Upon receiving a byte in BYTE2, signal done for one cycle and return to IDLE. This approach uses a state machine instead of a counter for clarity and separation of byte tracking. The done output is asserted synchronously right after the third byte and cleared otherwise. Synchronous reset sets the state back to IDLE. This structure clearly models the message boundary detection, is easy to extend, and is robust to glitches on the input.
