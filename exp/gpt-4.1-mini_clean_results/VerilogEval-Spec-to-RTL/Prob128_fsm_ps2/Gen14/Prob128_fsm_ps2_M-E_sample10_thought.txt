Implement a three-state FSM (IDLE, BYTE1, BYTE2) to track message progress. Start in IDLE state, waiting for a byte with in[3]=1 (start of message). Upon seeing it, move to BYTE1 state; next byte advances to BYTE2; after BYTE2, signal done and return to IDLE. This FSM explicitly represents message byte positions, making the logic clearer and separating state transitions cleanly. The done output is registered and asserted for one clock cycle immediately after the third byte is received. Use synchronous reset and positive edge clock triggering.
