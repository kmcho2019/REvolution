Implement the FSM using explicit state encoding with three states: IDLE, BYTE2, BYTE3. In IDLE, wait for a byte with in[3]=1 to mark the start of a message. On detecting this start byte, transition to BYTE2 state, then BYTE3 state on subsequent bytes. After receiving the third byte, assert done for one cycle and return to IDLE. Use a one-hot style state encoding via localparams for clarity. This approach provides clear state transitions without counters, making the FSM fully explicit, easing timing analysis, and potentially improving debuggability. done is asserted only one cycle right after receiving the third byte. The reset is synchronous and active high, clearing state and done signal. This solution trades the 2-bit counter for a clearly defined three-state FSM.
