Use a single 2-bit counter to track bytes received in the current message. When reset, counter clears to zero. On each clock, if counter is zero and in[3] is 1, start a new message by setting counter to 1. If counter is non-zero, increment it. When the counter reaches 3, assert done for one cycle and reset counter to zero. Keep done assertion inside the same always block to minimize logic. This minimal approach keeps functionality intact with less branching and simpler logic.
