Use a simple 2-bit counter to track bytes received in a message, resetting to 0 on reset or when a start byte (in[3]=1) is detected while not in a message. Increment the counter each cycle when inside a message, asserting done for one cycle immediately after the third byte is received (when count reaches 3). Keep all logic in a single always block for simplicity, with done cleared by default each cycle except when asserting done. This minimal FSM meets the requirements with less branching.
