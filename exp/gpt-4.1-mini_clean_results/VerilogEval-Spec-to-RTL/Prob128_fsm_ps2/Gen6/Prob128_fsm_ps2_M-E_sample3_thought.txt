Instead of using a multi-state FSM, use a counter that increments only when a valid message byte is received. First, wait until a byte with in[3] = 1 arrives, which is the start of the message. Set the counter to 1 at that point. For each next byte (regardless of in[3]), increment the counter until it reaches 3. When counter hits 3, assert done for one cycle and reset the counter to zero. This counter-based approach simplifies state encoding, reduces control logic, and eases extensibility. Reset synchronously clears the counter and done signal.
