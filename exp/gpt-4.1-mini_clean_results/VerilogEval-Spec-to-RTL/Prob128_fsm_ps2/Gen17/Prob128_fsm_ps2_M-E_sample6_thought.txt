Implement a three-state FSM: IDLE (waiting for start byte), BYTE2 (waiting for second byte), BYTE3 (waiting for third byte). Transition from IDLE to BYTE2 on detecting in[3]=1, then progress through BYTE2 and BYTE3 states on each clock cycle regardless of input byte content. Assert done for one cycle immediately after receiving the third byte, then return to IDLE. Use synchronous reset and register outputs. This explicit FSM approach separates state transitions clearly and provides clean control over message boundary detection.
