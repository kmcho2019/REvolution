Use a counter-based approach with a valid start byte latch: When reset is active, clear the counter and done signal. On each clock cycle, if a valid start byte (in[3]=1) is detected and we are not already inside a message, latch that we are inside a message and reset the counter to 1. While inside a message, increment the counter each clock cycle when valid data arrives. When the counter reaches 3 (meaning three bytes received), assert done for one cycle and clear the inside-message flag to restart the search. This method uses a counter plus a flag rather than explicit FSM states, simplifying logic and making transitions more explicit.
