Implement a three-state FSM using an enumerated state variable to clearly separate the phases: IDLE (waiting for the first byte with in[3]=1), BYTE2 (waiting for the second byte), and BYTE3 (waiting for the third byte). On reset, go to IDLE. When in IDLE and in[3]=1, move to BYTE2. On BYTE2, move to BYTE3 on next byte, and on BYTE3, assert done for one cycle and return to IDLE. This explicit FSM approach increases code clarity, making it easier to modify or extend, and keeps done synchronous and single-cycle.
