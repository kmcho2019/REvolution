Implement the FSM using a simple 2-bit binary counter that counts the bytes of the current message after detecting the start byte (in[3] == 1). The FSM starts in an IDLE state waiting for a start byte; when it detects in[3] == 1, it moves to BYTE1 state (count=1), then sequentially increments the count for BYTE2 and BYTE3 states. The done signal is asserted in the cycle immediately after receiving the third byte, i.e., when count reaches 3. The done output is generated combinationally from the counter value. This approach minimizes state encoding complexity and leverages a small counter rather than explicit state encoding, simplifying the design and potentially saving area. All logic is synchronous with synchronous reset.
