Implement a binary-encoded FSM with three states, tracking the byte position within a message: WAIT_FOR_START (looking for in[3] == 1), BYTE2, and BYTE3. Use a single always block with synchronous reset and clock edge to update state and output done. The done signal will be asserted for one cycle immediately after the third byte is received, which is when the FSM moves from BYTE3 state back to WAIT_FOR_START. Done is driven as a registered output, assigned inside the sequential block. This design uses fewer flip-flops and clear binary encoding, simplifying the hardware.
