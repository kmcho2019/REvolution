Use a simple 2-bit counter to track bytes in the message and a done signal that is asserted immediately after receiving the third byte. Reset synchronously clears both count and done. By keeping the done signal assertion simple and directly tied to count reaching two (indexing from 0), we reduce logic complexity. The counter increments only when inside a message; otherwise, it waits for a byte with in[3]=1 to start counting. Done is cleared by default every cycle to ensure a one-cycle pulse. This straightforward approach minimizes state bits and logic.
