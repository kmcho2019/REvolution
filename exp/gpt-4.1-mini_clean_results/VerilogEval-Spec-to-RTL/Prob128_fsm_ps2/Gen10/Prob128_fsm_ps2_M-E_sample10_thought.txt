Implement the FSM using explicit named states to clearly distinguish between searching for the start byte, collecting the second byte, and collecting the third byte. Use a 2-bit state register with states: IDLE (waiting for a start byte), BYTE2 (received first byte), BYTE3 (received second byte). When reset, start in IDLE. Upon detecting in[3]=1 in IDLE, move to BYTE2. Then sequentially move to BYTE3 and back to IDLE. Assert done only in the cycle after BYTE3 is received. This explicit state encoding improves clarity and makes it easy to extend or modify if needed.
