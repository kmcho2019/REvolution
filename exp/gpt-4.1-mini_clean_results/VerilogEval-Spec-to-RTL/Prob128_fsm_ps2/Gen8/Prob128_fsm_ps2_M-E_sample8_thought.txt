Implement a counter-based FSM using a single 2-bit register to track the byte count of the current message. When a byte with in[3]=1 is detected, reset the counter to 1 indicating the first byte of a message. For subsequent bytes, increment the counter. When the counter reaches 3, assert done and reset the counter to 0 to look for a new message. This approach treats the counter as both the state and progress indicator, simplifying state logic without explicit named states. The done output is asserted for one cycle immediately after the third byte.
