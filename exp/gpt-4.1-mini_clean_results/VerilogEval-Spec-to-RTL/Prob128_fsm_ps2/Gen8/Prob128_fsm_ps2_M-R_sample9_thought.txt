Refactor the FSM by using an explicit state machine with three states to represent the number of bytes received: IDLE (waiting for start byte), BYTE2 (received first byte), and BYTE3 (received second byte). Use separate registers for state and a done flag. The done signal is asserted when transitioning from BYTE3 back to IDLE (after receiving the third byte). This structure clarifies the FSM states, separates combinational next-state logic and output logic from sequential state updates, and avoids toggling done when not needed.
