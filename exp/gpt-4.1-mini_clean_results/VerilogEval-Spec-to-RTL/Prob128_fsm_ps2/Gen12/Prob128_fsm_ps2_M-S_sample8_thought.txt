Since the done signal is only a single-cycle pulse after receiving the third byte, we can use a 2-bit counter that resets to 0 on reset and whenever we detect the start byte (in[3]=1) to indicate the first byte of a message. We increment the counter on each valid byte and assert done immediately when the counter reaches 3, then reset the counter. We can combine this logic into a simple always block with minimal conditionals to reduce complexity while keeping the same functionality.
