Refactor the FSM by explicitly defining states using a parameterized enumerated type, making the design more readable and scalable. Use a 2-bit state register to represent three states: IDLE (waiting for start byte), BYTE2 (second byte received), BYTE3 (third byte received). The done signal is registered and asserted for one cycle right after receiving the third byte. This approach separates state encoding and output logic clearly. The synchronous reset still initializes the state to IDLE and done to 0. This state machine structure enhances clarity while maintaining the same functionality and timing as before.
