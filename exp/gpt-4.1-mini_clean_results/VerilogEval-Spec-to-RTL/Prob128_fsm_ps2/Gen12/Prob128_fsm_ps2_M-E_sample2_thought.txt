Use a 2-bit state machine with explicit named states: IDLE (waiting for a byte with in[3]=1), BYTE2 (received first byte, now expecting second byte), and BYTE3 (expecting third byte). On reset, go to IDLE. On each clock, if in IDLE and in[3]=1, transition to BYTE2; if in BYTE2, go to BYTE3; if in BYTE3, signal done and return to IDLE. done is asserted for one cycle immediately after receiving the third byte. This FSM with explicit states improves clarity and separates the detection and counting logic, also making the code easy to extend or modify.
