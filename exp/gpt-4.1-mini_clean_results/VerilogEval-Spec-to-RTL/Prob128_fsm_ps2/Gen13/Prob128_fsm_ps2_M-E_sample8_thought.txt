Implement a three-state FSM to track message reception: IDLE, BYTE1, BYTE2. The FSM starts in IDLE and waits for a byte with in[3]=1 (start of a message). Upon detecting this, it transitions to BYTE1 state and stores that the first byte has been received. On the next clock, it transitions to BYTE2, then on the following clock it completes the third byte reception and asserts done for one cycle. If during BYTE1 or BYTE2 a byte with in[3]=1 is detected, it treats that byte as a new message start and restarts the sequence, ensuring synchronization to the new message boundary. Reset synchronously returns FSM to IDLE. This approach uses explicit states rather than a simple counter, which improves clarity on the message boundary logic and immediate restart on mid-message start byte detection.
