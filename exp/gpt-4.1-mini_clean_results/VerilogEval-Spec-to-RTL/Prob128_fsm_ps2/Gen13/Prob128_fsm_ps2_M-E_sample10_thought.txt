Implement a three-state FSM (IDLE, BYTE2, BYTE3) using explicit state encoding to track the message byte count. Start in IDLE, wait for a byte with in[3] = 1 to signal the first byte of a message, then transition to BYTE2 and BYTE3 on each received byte. After BYTE3, assert done for one clock cycle and return to IDLE. Synchronous reset brings FSM back to IDLE and clears done. This explicit FSM is clear and easily extensible.
