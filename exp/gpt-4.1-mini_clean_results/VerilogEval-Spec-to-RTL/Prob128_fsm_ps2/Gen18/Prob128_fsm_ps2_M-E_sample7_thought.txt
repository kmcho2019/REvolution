Implement a 4-state FSM: IDLE, BYTE1, BYTE2, BYTE3. Initially in IDLE, discard bytes until one with in[3] = 1 is found, then transition to BYTE1. On next cycles, transition through BYTE2 and BYTE3 states, counting the three bytes explicitly. Assert done signal combinationally (high) only on the cycle where BYTE3 is received, then transition back to IDLE for resynchronization. Use synchronous reset to set state to IDLE. This explicit state approach improves readability and modularity, and avoids counting arithmetic. done is registered and set high only for one cycle right after BYTE3 byte reception.
