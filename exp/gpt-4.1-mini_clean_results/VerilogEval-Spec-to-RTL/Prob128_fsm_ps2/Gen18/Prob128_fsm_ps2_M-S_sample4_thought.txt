Simplify the FSM by using a 2-bit counter that counts from 0 to 3. When count=0, wait for a start byte (in[3]=1). Upon detecting it, increment count each cycle until the third byte is received (count=3). Assert done for one cycle right after the third byte (when count==3), then reset count to 0 to wait for the next message. This approach uses fewer signals and no extra enable gating, making the logic straightforward and minimal while meeting all specs. The done pulse is cleanly generated synchronously. Reset is synchronous active high.
