Implement a simple three-state FSM that explicitly tracks the position in the message: IDLE (waiting for start byte), BYTE2 (second byte), BYTE3 (third byte). The FSM transitions to BYTE2 upon receiving a byte with in[3] = 1, then to BYTE3 on the next byte, and back to IDLE after BYTE3 while generating a done pulse. This explicit state encoding avoids counters and reduces complexity, providing clear and intuitive control flow. The done signal is asserted only for one clock cycle immediately after the third byte is received. Reset synchronously brings the FSM back to IDLE and clears done. This approach uses an enumerated state type for clarity, one-hot style states for minimal decoding, and clean state transitions with non-blocking assignments, improving readability and maintainability.
