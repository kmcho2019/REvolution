Use a single 2-bit counter to track byte positions within a message, with a simple FSM embedded in the counter logic. When count is zero, wait for in[3]=1 to start a message. Increment count on each subsequent byte. Assert done for one cycle immediately after the third byte (count == 2), then reset count to zero. Keep done registered and cleared by default each cycle. This minimizes logic and state, using just a counter and done register without extra state variables or complex conditionals.
