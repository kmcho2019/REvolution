Use a three-state FSM encoded as a 2-bit state register to track message reception: IDLE (waiting for start byte), BYTE2 (received first byte, expecting second), and BYTE3 (received second byte, expecting third). On each clock cycle, if reset is asserted, go to IDLE and clear done. Otherwise, in IDLE, if in[3] is 1, move to BYTE2. In BYTE2 and BYTE3, accept the byte regardless of in[3]. After BYTE3, assert done for one cycle and return to IDLE. This state-based approach explicitly encodes the message byte position, avoids counters, and clearly separates state transitions, making the FSM more modular and potentially easier to extend or verify.
