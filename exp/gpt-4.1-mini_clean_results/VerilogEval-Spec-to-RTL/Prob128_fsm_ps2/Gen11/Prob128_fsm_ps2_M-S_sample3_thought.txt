Use a single 2-bit counter to track the current byte number in the message, starting at zero. When reset, clear count and done. When count is zero, start counting only if in[3] is set (indicating start of message). Increment count each cycle until count reaches 2 (third byte). At that point, assert done for one cycle and reset count to zero, ready to detect the next message. Default done to zero each cycle. This approach keeps the FSM minimal and simple.
