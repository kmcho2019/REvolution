Instead of a multi-bit state machine, we can implement this FSM using a simple byte counter and a flag to indicate whether we are currently inside a message. When in[3] is detected and we are not inside a message, we start the message and set the counter to 1. For each subsequent byte, we increment the counter until it reaches 3, at which point we assert done for one cycle and reset the message flag and counter. This approach uses minimal control logic and can be efficiently implemented with simple registers and combinational logic.
