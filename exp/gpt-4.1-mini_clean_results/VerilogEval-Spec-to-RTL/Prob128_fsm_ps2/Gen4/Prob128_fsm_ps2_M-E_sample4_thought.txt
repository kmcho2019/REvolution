Implement the FSM using a binary encoded two-bit state machine that counts the bytes received after detecting the start byte (in[3]=1). Use a simple counter to track the byte number within the 3-byte message. When in[3]=1 and the FSM is idle, start the message (state 1). Increment state with each clock to track byte 2 and 3. Assert done for one cycle immediately after receiving the third byte. Keep reset synchronous and active high. Implement the done signal purely combinationally from state and input to minimize latency and register count.
