Instead of a classic FSM with explicit states, use a simple byte counter and a start-of-message detection flag. The counter increments when a byte is accepted as part of a current message. We begin accepting bytes only after detecting a byte with in[3] = 1, which marks the start of a message. Once three bytes have been counted, assert done for one cycle and reset the counter and start flag. This approach eliminates multiple FSM states, simplifying the design to a counter and a flag while maintaining the same behavior. The synchronous reset clears the state and counter.
