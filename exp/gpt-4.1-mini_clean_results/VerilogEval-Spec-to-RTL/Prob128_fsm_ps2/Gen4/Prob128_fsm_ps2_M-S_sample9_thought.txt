Use a single 2-bit counter to track the byte number within a message. When reset, or when not currently receiving a message (counter=0), wait for a byte with in[3]=1 to start counting bytes. Increment the counter each clock cycle while counting a message. Assert done for one cycle immediately after the third byte (counter=3), then reset counter back to 0 to look for the next message. This avoids explicit conditions by relying on the counter and in[3] check to start new messages, keeping the design minimal and synchronous.
