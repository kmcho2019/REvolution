Use a counter-based FSM that increments on every received byte. Start counting only when a byte with in[3]=1 is detected, marking the start of a message. The counter goes from 1 to 3 to track the three bytes. When count reaches 3, assert done for one cycle and reset the count back to zero, ready to detect the next message start byte. Synchronous reset sets counter and done to zero. This approach uses a simple counter instead of named states.
