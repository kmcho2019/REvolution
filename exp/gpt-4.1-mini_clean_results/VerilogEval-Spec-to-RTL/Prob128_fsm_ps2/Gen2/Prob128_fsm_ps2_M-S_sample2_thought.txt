Use a simple 2-bit counter to track how many bytes of the current message have been received, starting counting at the byte with in[3]=1. When reset is asserted synchronously, reset the counter to zero (meaning searching for start). On each clock, if currently searching (count=0), check if in[3]=1 to start a message (count=1). Otherwise, if counting bytes 1 or 2, increment count. When count reaches 3 (third byte received), assert done for one cycle and reset count to zero (back to searching). This straightforward approach avoids explicit FSM states and clearly aligns done timing to the cycle immediately after the third byte.
