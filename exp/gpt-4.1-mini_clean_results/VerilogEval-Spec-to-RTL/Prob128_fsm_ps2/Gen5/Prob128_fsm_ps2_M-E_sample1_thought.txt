Use a counter-based approach with a single register to track byte position within a message. Start counting only when a byte with in[3]=1 is detected, indicating the first byte of a 3-byte message. Increment the counter each clock cycle to track second and third bytes. When the counter reaches 3, assert done for one cycle and reset the counter to 0 to search for a new message start. On reset, clear the counter and done. This eliminates explicit FSM states and uses a simple byte counter, making the design compact and easy to extend.
