Refactor the FSM to use a single always block with synchronous reset that updates both state and done signals together. Instead of a separate combinational block for next_state, compute next state inside the sequential block using a case statement. This reduces the number of always blocks and makes the FSM state transition and output logic fully synchronous and compact. The done signal is asserted one cycle after the third byte, as before. This structure improves code clarity and may help synthesis tools better optimize the FSM as a single block.
