We can simplify the FSM by using a single counter that counts how many bytes of a message have been received after detecting the start byte (in[3]=1). 

- When in[3]=1, reset the count to 1.
- Otherwise, if count is between 1 and 2, increment the count.
- When count reaches 3, assert done in the next cycle and reset count to 0.
- If count is 0, we are searching for the start byte.

This eliminates explicit states and uses a simple counter to track byte positions, reducing state encoding and simplifying logic. The done signal is asserted one cycle after the third byte is received.

Reset synchronously sets count and done to zero.
