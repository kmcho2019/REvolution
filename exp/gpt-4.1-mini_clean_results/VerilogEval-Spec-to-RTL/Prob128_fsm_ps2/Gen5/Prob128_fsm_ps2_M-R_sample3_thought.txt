Refactor the design by implementing an explicit three-state FSM using named states to improve clarity. The FSM states are: IDLE (waiting for the start byte with in[3]=1), BYTE2 (received first byte, expecting second), and BYTE3 (expecting third byte). Transitions occur on each clock cycle with the input byte received. The done signal is asserted for one cycle immediately after the third byte is accepted. Use synchronous reset to initialize the FSM. This explicit state encoding clarifies control flow compared to the previous counter-based design while maintaining the same functionality.
