Use a simple 2-bit counter to track how many bytes of the message have been received after detecting the start byte (where in[3]=1). When not in a message, wait for in[3]=1 to start counting from 1. Increment the count each byte received and assert done one cycle after the third byte (count == 3). Reset synchronously sets count and done to zero. This approach eliminates explicit FSM states and uses just a counter and simple logic.
