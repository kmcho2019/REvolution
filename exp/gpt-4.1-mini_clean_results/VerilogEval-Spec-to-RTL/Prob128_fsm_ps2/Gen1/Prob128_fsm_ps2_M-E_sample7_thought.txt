Instead of explicitly encoding states for each byte, implement a simple counter that increments only when a message is detected. Use the property that the first byte has in[3] = 1 to reset the counter to 1, indicating start of message. Then increment the counter for subsequent bytes. When the counter reaches 3, assert done in the next cycle and reset the counter to 0 to search for the next message. This approach uses a single register (counter) instead of multiple FSM states, simplifying the design and making it easy to extend.
