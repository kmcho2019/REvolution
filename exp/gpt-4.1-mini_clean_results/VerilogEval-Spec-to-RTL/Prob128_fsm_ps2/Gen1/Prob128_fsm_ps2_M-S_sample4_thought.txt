Use a simple 2-bit state variable with states IDLE (waiting for byte with in[3]=1), COUNT1 (received first byte), COUNT2 (received second byte). On reset, go to IDLE. In IDLE, if in[3]=1, start counting message bytes. After receiving the third byte (COUNT2 + next byte), assert done for one cycle, then return to IDLE. Assert done only for one cycle immediately after third byte is received.
