Use a 2-bit counter to track how many bytes have been accepted in the current message. The module waits for a byte with in[3]=1 to start a message (counter=1). Then, on each next byte, increment the counter. Once the counter reaches 3 (third byte received), assert done synchronously for one clock cycle and reset the counter to zero, ready to detect the next message. If a byte with in[3]=1 is received while counting bytes 2 or 3, treat it as the start of a new message (reset counter to 1). This approach avoids multiple FSM states and uses a simple counter and combinational logic, improving clarity and making done timing explicit and synchronous.
