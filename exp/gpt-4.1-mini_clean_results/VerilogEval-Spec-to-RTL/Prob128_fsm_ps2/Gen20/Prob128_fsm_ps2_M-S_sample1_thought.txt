Simplify the FSM by using a single 2-bit counter without extra enable signals. The counter will count bytes within a message: zero means searching for start byte, 1 and 2 track subsequent bytes. On detecting in[3] = 1 while in count 0, start counting bytes. After receiving the third byte (count 2), assert done for one cycle and reset counter to zero. Remove the enable gating to reduce combinational logic and keep logic straightforward while maintaining synchronous reset and done pulse timing.
