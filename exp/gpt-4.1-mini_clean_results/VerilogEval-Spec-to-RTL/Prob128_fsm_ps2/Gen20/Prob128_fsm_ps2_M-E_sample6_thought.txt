Implement a three-state FSM to track the byte position within the PS/2 message, explicitly encoding states for WAIT_START, BYTE_2, and BYTE_3. On reset, the FSM goes to WAIT_START, discarding input bytes until it finds one with in[3]=1. When this start byte is detected, move to BYTE_2, then to BYTE_3 on the next cycles. After receiving BYTE_3, assert done for one cycle and return to WAIT_START. The done signal is generated combinationally based on the current state and input clock, ensuring a one-cycle pulse immediately after the third byte is received. This approach uses explicit states rather than a counter, improving clarity and allowing easier extension. The reset is synchronous active-high, and all state transitions occur on the positive clock edge.
