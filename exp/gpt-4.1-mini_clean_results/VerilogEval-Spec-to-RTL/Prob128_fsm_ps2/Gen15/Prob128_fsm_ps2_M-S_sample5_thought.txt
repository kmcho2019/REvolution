Implement a straightforward 2-bit counter FSM without extra enable gating. Use the counter to track the byte position within a message: 0 means searching for a start byte (in[3] == 1), 1 and 2 for subsequent bytes. On reset, clear the counter and done. On each clock cycle, if at state 0, check if current byte is a start byte to move to state 1; if inside message, increment the counter. When the counter reaches 2 (third byte), assert done for one cycle and reset counter to 0. Done is asserted only in the cycle immediately after the third byte is received, and is 0 otherwise. This keeps the logic simple, removes the enable gating, and maintains the same behavior.
