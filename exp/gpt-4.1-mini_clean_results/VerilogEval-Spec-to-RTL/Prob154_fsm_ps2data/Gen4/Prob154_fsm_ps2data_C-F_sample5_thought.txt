Create a compact, power-efficient FSM with three states encoded in 2 bits: WAIT_SYNC, BYTE2, BYTE3. Store each received byte in dedicated 8-bit registers only when valid, minimizing toggling by clock enabling registers only on active states. Keep done as a combinational output asserted exactly one cycle immediately after the third byte is received, simplifying timing. Concatenate byte1, byte2, and byte3 into out_bytes registered synchronously but only updated when done is asserted, reducing switching on out_bytes bus. Synchronous active-high reset clears all registers and state. This fusion balances clarity, timing, power, and area by isolating done combinational logic, using minimal register enables, and ensuring outputs are stable and valid exactly when done is high.
