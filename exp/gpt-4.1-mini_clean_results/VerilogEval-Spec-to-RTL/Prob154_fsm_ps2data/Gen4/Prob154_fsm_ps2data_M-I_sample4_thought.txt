To optimize the existing design for better PPA (performance, power, area), we focus on reducing unnecessary toggling and simplifying logic without losing clarity or functionality:

- Add clock enables to the byte registers so they update only when required, preventing redundant toggling and saving power.
- Move the done signal to a one-cycle pulse generated by a small register, avoiding continuous assignments that toggle unnecessarily.
- Simplify the out_bytes assignment by registering only once when done is asserted; outside that, hold its value to avoid glitches and reduce toggling.
- Use a one-hot state encoding for FSM for potentially faster state decoding and simpler next state logic.
- Keep synchronous reset and non-blocking assignments for good design practice.
- Separate combinational next state logic and sequential registers cleanly for better timing.
- The interface and FSM behavior remain unchanged to keep functional correctness.
