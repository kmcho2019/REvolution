Fuse the strengths of both solutions by using separate byte registers for minimal toggling and clarity (from Example 2), a clean synchronous FSM with simple state transitions (from Example 1 and 2), and streamline done and out_bytes assignment for minimal logic and improved timing.

- Use three explicit 8-bit registers byte1, byte2, byte3 to store incoming bytes, reducing unnecessary toggling.
- FSM with three states: WAIT_SYNC, BYTE2, BYTE3 (similar to Example 2), using 2-bit binary encoding.
- Wait in WAIT_SYNC until in[3]==1 to mark start of message and store first byte.
- Then move to BYTE2 and BYTE3 storing subsequent bytes.
- Assert done for exactly one cycle immediately after third byte is stored.
- Update out_bytes only when done is asserted by concatenating the three byte registers.
- Reset synchronously clears all registers and signals.
- Use non-blocking assignments consistently.
- This design combines the clearer datapath register partitioning and simpler done assertion and state machine from both, optimizing toggling and timing.
