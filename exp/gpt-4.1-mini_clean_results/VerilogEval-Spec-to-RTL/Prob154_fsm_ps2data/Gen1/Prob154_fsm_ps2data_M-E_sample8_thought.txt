Implement a simple FSM with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
- Start in IDLE state, discard bytes until an input byte with in[3] == 1 is received, then save it as byte1 and transition to BYTE2.
- Capture the next input byte as byte2 in BYTE2 state and transition to BYTE3.
- Capture the next input byte as byte3 in BYTE3 state, then concatenate byte1, byte2, and byte3 into a 24-bit shift register and assert 'done' for one clock cycle.
- Transition back to IDLE to search for the next message.
- Use a single 24-bit shift register updated in each of the BYTE states to store incoming bytes shifted in, reducing separate byte registers.
- The synchronous reset initializes FSM and registers.
- 'done' is asserted for exactly one cycle immediately after the third byte is received.
- The output out_bytes is updated simultaneously when done is asserted.
