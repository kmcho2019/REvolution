Simplify the FSM by using a single state counter from 0 to 3: 0 means searching for start byte, and 1,2,3 indicate how many bytes have been received. When at 0, discard bytes until in[3] == 1 to start a message. At counts 1 and 2, store bytes; at count 3, capture the third byte, output the 24-bit message, assert done, then reset count to 0. This eliminates separate state names and uses a simple counter for sequencing. Use synchronous reset. Update done and out_bytes only on the third byte reception cycle.
