Implement a synchronous FSM with three states: IDLE, BYTE1, BYTE2. Initially in IDLE, discard bytes until we see a byte with bit 3 set (in[3] == 1). Then store that byte as byte1 and go to BYTE1 state. Then store subsequent bytes as byte2 and byte3, moving through states. When byte3 is stored, assert done in the next clock cycle and output the 24-bit message concatenating the three stored bytes (byte1 as MSB, byte2 middle, byte3 LSB). done is high only in the cycle immediately after the third byte is stored, otherwise low. Synchronous reset clears state and outputs. Sequential logic triggered on rising edge of clk.
