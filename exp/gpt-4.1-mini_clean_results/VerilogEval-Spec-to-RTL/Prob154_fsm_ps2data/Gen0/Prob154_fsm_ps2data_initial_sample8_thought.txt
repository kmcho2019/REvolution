Implement a simple FSM with three states: IDLE (discard bytes until in[3] is 1), BYTE2 (store second byte), BYTE3 (store third byte). On reset, state returns to IDLE. The output message is stored in a 24-bit register. When the third byte is received, assert done for one cycle and output the 3-byte message with the first byte in bits [23:16]. The done and out_bytes are combinational outputs updated on the clock edge along with state and registers.
