Use a three-stage shift register to accumulate incoming bytes once the start byte condition (in[3] = 1) is detected. The FSM only needs two states: SEARCH (waiting for start byte) and COLLECT (collecting bytes). When in SEARCH, bytes are discarded until a byte with in[3]=1 arrives, which starts message capture by shifting that byte into the MSB position of a 24-bit shift register and moving to COLLECT state. Then, on each subsequent clock cycle in COLLECT state, shift in the new byte at LSB, shifting the previously stored bytes up. After receiving the third byte (total 3 bytes shifted in), assert done for one cycle while out_bytes presents the full 24-bit message. Then return to SEARCH state. This approach leverages a shift register datapath for simplicity and compactness and a minimal FSM with only two states, reducing state logic. The synchronous reset clears the FSM and shift register. The done signal is a one-cycle pulse immediately after the third byte is received.
