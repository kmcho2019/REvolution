Use a simple 2-bit state FSM with three states: WAIT (looking for sync byte with in[3]=1), BYTE2, and BYTE3. On seeing the first sync byte, capture it and move to BYTE2 and BYTE3 states capturing subsequent bytes. Assert done and output concatenated bytes only on the cycle the third byte is received. Use minimal registers: store the three bytes in a shift register fashion (shift left and insert new byte) for simplicity. Reset synchronously clears state and registers. Keep done high for only one cycle immediately after the third byte arrives. This approach simplifies register usage by using one 24-bit shift register for the message instead of separate byte registers.
