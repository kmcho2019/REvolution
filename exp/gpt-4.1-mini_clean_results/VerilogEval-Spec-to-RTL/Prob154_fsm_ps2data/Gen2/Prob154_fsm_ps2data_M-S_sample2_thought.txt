Use a simple 2-bit counter to track how many bytes of the current message have been captured, starting only when a byte with in[3]=1 is seen.  
On reset, clear the counter and done signal.  
When in[3]=1 and count=0, accept this byte as the first byte and set count=1.  
For count=1 and 2, store incoming bytes as second and third bytes respectively, incrementing count each clock.  
When count reaches 3 (i.e., the third byte received), assert done and output the concatenated 24-bit message in the same clock cycle.  
After that, reset count and done to zero to prepare for next message.  
This approach avoids explicit FSM states and extra cycles for done, aligning done and valid out_bytes timing as required.  
All logic is synchronous and triggered on positive clock edge with synchronous reset.
