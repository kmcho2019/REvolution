Use a shift register approach to accumulate bytes only after detecting a start byte (with in[3] = 1). The FSM has two states: SEARCH and RECEIVE. In SEARCH state, discard bytes until detecting a start byte. When detected, shift in the byte into a 24-bit shift register and move to RECEIVE state. In RECEIVE, shift in subsequent bytes until 3 bytes total are collected, then assert done for one cycle and output the 24-bit message. After done, return to SEARCH. This approach simplifies the data path by using a single shift register instead of separate byte registers and keeps done assertion synchronized with message completion.
