Use a simple 2-bit counter to track the message byte index starting from the byte where in[3]=1.  
When reset, clear the counter and done.  
On each clock, if count=0, wait for a byte with in[3]=1 to start the message, capturing it as byte1 and increment count.  
When count=1 or 2, capture incoming bytes as byte2 and byte3.  
When the third byte is captured (count=2), output the concatenated message and assert done in the same cycle, then reset count to 0.  
This approach uses minimal state and logic, all synchronous with positive edge clock and synchronous reset, meeting all requirements.
