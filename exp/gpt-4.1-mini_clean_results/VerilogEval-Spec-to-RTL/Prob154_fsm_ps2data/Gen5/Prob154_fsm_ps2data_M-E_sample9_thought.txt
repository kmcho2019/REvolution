Use a 4-state FSM with explicit states for IDLE, BYTE1, BYTE2, and DONE signaling. The FSM waits in IDLE state until it sees a byte with in[3] = 1, which marks the first byte of a message. On detection, it stores the byte and moves to BYTE1 state to collect the second byte, then BYTE2 state to collect the third byte. After receiving the third byte, it moves to DONE state where it asserts the done signal for exactly one clock cycle and outputs the concatenated 24-bit message formed by the three bytes in the correct order. On the next clock cycle, FSM returns to IDLE to wait for the next message. Synchronous active-high reset initializes the FSM to IDLE and clears all outputs. The done and out_bytes outputs are registered to ensure stable outputs only when done is asserted. Using explicit DONE state cleanly separates the done assertion and output update from byte capturing states, avoiding combinational dependencies within byte capture states. This approach facilitates easier timing closure and simpler control, with minimal combinational logic and clear separation of data capture and output signaling.
