Refactor the FSM to use one-hot encoding for clarity and potentially better synthesis optimization. Separate the output logic from the state register updates by using a registered done signal and an explicit message byte counter to track how many bytes have been collected after the start byte is detected. Use a 2-bit counter instead of multiple states and load bytes into a shift register only when actively capturing a message. Done is asserted for one cycle immediately after collecting three bytes. This structure separates combinational next-state logic from sequential state updates and makes the design more modular.
