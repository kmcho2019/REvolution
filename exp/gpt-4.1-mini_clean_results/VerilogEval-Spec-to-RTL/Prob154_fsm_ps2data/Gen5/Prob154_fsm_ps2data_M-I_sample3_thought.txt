To optimize the original design for better PPA:

- Introduce enable signals to the byte registers so they update only when needed, reducing unnecessary toggling and power.
- Register the done signal only when asserted, holding zero otherwise, to minimize output toggling and dynamic power.
- Split the sequential logic into separate always blocks for state and registers to improve timing clarity and allow better synthesis optimizations.
- Use a 2-bit binary FSM as before for area and simplicity.
- Keep synchronous active-high reset.
- Maintain the done signal asserted for exactly one cycle right after the third byte is received.
- Update out_bytes only when done is asserted, holding previous value otherwise.
- This fine-grained clock enable approach and logic separation will reduce power and possibly improve timing with minimal area overhead.
