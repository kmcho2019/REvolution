Simplify the FSM by using a single 2-bit counter to track the number of valid bytes collected. Use a 24-bit shift register that shifts in each byte when in the message collection phase. When a start byte is detected (in[3] = 1) and count=0, load it as the most significant byte in the shift register and increment count. For subsequent bytes, shift in the new byte at lower positions. When the third byte arrives (count=2 before increment), assert done and output the assembled 24-bit message in the shift register. Reset count and done accordingly. This approach reduces registers to one 24-bit shift register and a small counter, minimizing complexity while preserving all timing and functional requirements.
