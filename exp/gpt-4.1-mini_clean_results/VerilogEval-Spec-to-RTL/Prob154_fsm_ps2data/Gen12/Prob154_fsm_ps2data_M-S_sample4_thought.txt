Simplify by using a single 2-bit counter that tracks the number of message bytes received: 0 means searching for first byte with in[3]=1, 1 and 2 mean collecting second and third bytes. Store incoming bytes directly into a 24-bit register by shifting bytes left by 8 bits on each new byte. When the third byte is received, assert done for one cycle. This approach eliminates manual byte positioning by just shifting the register and inserting the new byte in the lowest 8 bits, simplifying code and reducing explicit concatenations.
