Refactor the FSM to use a Mealy machine style where outputs (done, out_bytes) are assigned combinationally based on current state and input, while the state transitions remain synchronous. This removes the separate next_* signals and instead calculates outputs directly in combinational logic, making done a combinational output asserted immediately when the third byte is seen. The state machine uses a 3-bit counter for byte counting to track progress more explicitly, allowing clearer sequential data capture with shift registers. This structure provides a clearer separation of combinational outputs and synchronous state updates without the extra next-state registers.
