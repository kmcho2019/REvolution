Implement the FSM using a one-hot encoded state machine with four states: IDLE, BYTE1, BYTE2, and BYTE3. In IDLE, discard all input bytes until we find a byte with in[3]=1, then latch it as byte 1 and move to BYTE2. In BYTE2 and BYTE3 states, latch successive bytes as byte 2 and byte 3 respectively. After receiving byte 3, assert done for one clock cycle and output the concatenated 24-bit message (byte1 as MSB). This approach makes the state encoding explicit and improves clarity, also allowing easy extension. Use separate 8-bit registers for each byte to minimize glitching and avoid overwriting the entire 24-bit register every cycle. The done signal pulses one cycle immediately after the third byte is latched. The synchronous reset clears state and registers.
