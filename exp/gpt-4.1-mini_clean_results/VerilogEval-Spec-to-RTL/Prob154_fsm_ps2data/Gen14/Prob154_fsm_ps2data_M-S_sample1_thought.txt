Simplify the FSM by using a single 2-bit counter to track the received byte position after synchronization byte detected (in[3]=1). Use a single always block with synchronous reset that updates the message bytes by shifting in each new byte only after synchronization is found. The done signal asserts immediately after receiving the third byte. This approach reduces explicit states and relies on a counter, avoiding separate next-state logic and explicit state names. The output bytes are stored by shifting left 8 bits and concatenating the new byte to the lower 8 bits. This reduces the complexity of the datapath and FSM control without changing the protocol or interface.
