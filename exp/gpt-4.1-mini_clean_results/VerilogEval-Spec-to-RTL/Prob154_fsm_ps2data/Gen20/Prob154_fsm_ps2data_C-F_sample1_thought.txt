Fuse the clean and minimal 2-bit binary FSM structure with a streamlined datapath that uses a 3-byte shift register to capture the message bytes, minimizing toggling and complexity. 

Key elements of the fusion:
- Use the FSM states WAIT_SYNC, BYTE2, BYTE3 for clarity.
- When in WAIT_SYNC, discard bytes until in[3] = 1, then capture the first byte.
- Use a 3-byte shift register where new bytes shift in at the lowest byte each cycle to reduce multiplexing logic.
- Assert done for exactly one cycle immediately after receiving the third byte.
- Use synchronous active-high reset.
- Update the 24-bit output register only when needed and minimize toggling by shifting bytes instead of partial writes to different byte lanes.
- Maintain simple combinational next-state logic, improving synthesis friendliness.
- This approach reduces datapath muxing, glitched transitions on done, and increases readability.
