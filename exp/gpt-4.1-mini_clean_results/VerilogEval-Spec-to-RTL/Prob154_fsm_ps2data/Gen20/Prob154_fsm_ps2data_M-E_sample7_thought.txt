Implement the FSM with four states: IDLE, GOT_SYNC, GOT_BYTE2, GOT_BYTE3. Use a shift register of 24 bits to accumulate incoming bytes when synchronized. When detecting a sync byte (in[3] == 1), reset the shift register and start accumulating bytes by shifting in each new byte. After three bytes are collected, assert done for one cycle and output the shifted 24-bit message. This approach minimizes conditional loading by always shifting bytes into the register once synchronized, reducing logic complexity and potentially improving timing and area by using a simple shift register approach. The done signal is asserted one cycle after the third byte is shifted in. Reset is synchronous active high. This design cleanly decouples synchronization detection and byte accumulation and uses simple state progression.
