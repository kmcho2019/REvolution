Implement the FSM using a 3-bit shift register to store incoming bytes in a sliding window fashion. Start in an IDLE state waiting for in[3] to be set, indicating the first byte of a message. Once detected, shift in this byte and proceed to capture two more bytes consecutively, shifting each in on the next clock. After the third byte is shifted in, assert done for one cycle and output the concatenated 24-bit message in the order received (oldest byte as highest byte). This approach leverages a simple shift register to hold bytes, reducing the number of explicit registers and eliminating complex state transitions. Use a 2-bit state machine with states IDLE, BYTE_2, BYTE_3 and synchronous active-high reset. The done signal is generated combinationally when the FSM reaches BYTE_3 state. This design is compact and clear, handling the boundary detection and message assembly with minimal logic.
