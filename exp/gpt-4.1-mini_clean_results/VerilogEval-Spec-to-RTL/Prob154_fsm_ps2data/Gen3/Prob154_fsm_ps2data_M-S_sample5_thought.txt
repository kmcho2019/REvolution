Use a simple 2-bit state FSM with three states: IDLE (searching for start byte), BYTE2 (second byte received), BYTE3 (third byte received). Store bytes as they arrive after detecting the start byte (in[3]=1). When the third byte is received, output concatenated 24-bit message and assert done for one cycle. Then return to IDLE. Implement all logic synchronously on clk with synchronous reset. Keep code simple by combining byte storage in one shift register and assert done/output only when complete message formed.
