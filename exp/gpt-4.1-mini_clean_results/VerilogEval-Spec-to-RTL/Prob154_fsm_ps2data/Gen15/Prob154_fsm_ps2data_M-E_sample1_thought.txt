Implement the FSM using an explicit byte counter from 0 to 2 that increments only after a valid start byte is detected. When in byte 0, the FSM checks if in[3] is set to mark the start byte and captures it; otherwise, it stays waiting. For bytes 1 and 2, it captures the bytes sequentially. Once the third byte is captured, the FSM asserts 'done' for one cycle, presenting the assembled 24-bit message. To simplify and avoid state encoding, the byte counter alone represents the state. On reset, all outputs and counters are cleared synchronously. Use a 24-bit shift register where each new byte shifts the older bytes to lower positions, simplifying data handling and allowing easy assembly of bytes in the proper order.
