Implement the FSM with an explicit 4-state encoding: IDLE (waiting for start byte where in[3] = 1), BYTE1, BYTE2, BYTE3. Use a 3-byte shift register (24-bit) that shifts left and inserts the new byte at the right end each time we accept a byte. On detecting the start byte (in[3]=1) in IDLE, load the first byte, transition to BYTE1, then capture next two bytes in subsequent states. After the third byte, output done is asserted for one cycle, and FSM returns to IDLE to search for the next message. The out_bytes are always updated as the shift register changes, ensuring out_bytes[23:16] is byte1, [15:8] byte2, and [7:0] byte3. Use synchronous active high reset. This design cleanly separates states, uses a shift-based capture for easy scalability, and done is a single-cycle pulse right after the full message capture.
