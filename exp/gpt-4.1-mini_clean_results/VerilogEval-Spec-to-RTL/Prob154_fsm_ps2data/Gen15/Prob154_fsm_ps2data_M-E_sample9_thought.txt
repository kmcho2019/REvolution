Use a 3-state FSM with states IDLE, BYTE2, BYTE3, but implement a shift register approach to accumulating the 3-byte message. When a byte with in[3]=1 is received in IDLE, it is stored as the most significant byte of out_bytes. Subsequently, each incoming byte shifts the message left by 8 bits, inserting the new byte in the lowest 8 bits. After receiving the third byte (state BYTE3), the done signal is asserted for one cycle along with the valid 24-bit message in out_bytes. This approach simplifies data handling by treating out_bytes as a shift register, minimizes conditional logic by always shifting on valid states, and uses a clean synchronous reset. done is asserted only once per message at the end. The FSM cycles back to IDLE after completing one message reception.
