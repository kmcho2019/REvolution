Combine the clarity and explicit byte-wise loading from Example 2 with the partial byte update enable signals and done gating from Example 1 for better timing, power, and code cleanliness.

Key improvements in fusion:
- Use byte load enable wires derived from the FSM state and input to control when each byte is loaded, minimizing toggling in out_bytes registers by updating only the relevant byte lanes each cycle.
- Drive done signal only when the third byte is loaded, defaulting done to zero otherwise, to reduce switching.
- Keep FSM next state logic purely combinational and clean.
- Employ synchronous active-high reset.
- Use a simple 2-bit binary FSM with states WAIT_SYNC, BYTE2, BYTE3.
- Separate done signal update and partial byte loading controlled via enables for clear logic and better optimization.
- This fusion minimizes switching and mux complexity, improves timing margins by reducing logic in the critical path, and enhances code readability and maintainability.
