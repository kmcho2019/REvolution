Implement a simple 4-state FSM to explicitly model searching, receiving byte 1, byte 2, and byte 3 of a message. Use a shift register approach to accumulate the bytes in order, shifting existing bytes left by 8 bits and inserting the new byte at the least significant byte on each valid receipt. The FSM remains in SEARCH state until a byte with in[3]=1 is found, which begins the message collection. Once the third byte is received, assert done for one cycle with the accumulated out_bytes valid. Use synchronous reset and update done and out_bytes in the same clock edge, making done a pulse signaling new valid message ready. This architectural variation uses a shift-left concatenation to build the 24-bit message, contrasting with previous byte-by-byte fixed-position assignments.
