Implement a 4-state FSM to explicitly separate idle, first, second, and third byte reception states for clearer state transitions and easier debugging. Use a shift register style approach to accumulate the 3 bytes: on each valid byte, shift the bytes left and insert the new byte in the least significant byte position. The FSM waits in IDLE state until it detects the start byte (in[3]=1), then sequentially collects the next two bytes. The done signal is asserted in the cycle after the third byte is latched, ensuring out_bytes is valid at done assertion. Use synchronous reset and non-blocking assignments throughout. This approach trades a slightly larger FSM state encoding for a simple, consistent data accumulation scheme and clearer done timing.
