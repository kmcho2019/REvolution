Implement a 3-state FSM (WAIT_SYNC, BYTE2, BYTE3) using 2-bit binary encoding. Use combinational byte load enable signals to update only the corresponding byte slices in out_bytes, minimizing unnecessary register toggling for power efficiency. Assert done exactly for one cycle immediately after receiving the third byte. Reset is synchronous active-high, clearing state and outputs. Keep the FSM next-state logic purely combinational. This fusion merges the explicit load enables and done gating of Example 1 with the simplicity and clarity of Example 2, yielding a design that balances timing, power, and readability.
