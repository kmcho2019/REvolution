Use a two-stage FSM with a byte counter register and an output shift register. The FSM starts in an IDLE state and waits until it sees a byte with bit 3 set. Upon detecting this start byte, it transitions to a RECEIVING state where it shifts in three bytes into a 24-bit shift register, with the first received byte shifted into the highest byte. A separate 2-bit counter tracks the number of bytes received. When three bytes have been collected, the FSM asserts done for one cycle and outputs the assembled 24-bit message in the specified byte order. After signaling done, it returns to IDLE to find the next message. The reset synchronously initializes the state, counter, shift register, and done signal.
