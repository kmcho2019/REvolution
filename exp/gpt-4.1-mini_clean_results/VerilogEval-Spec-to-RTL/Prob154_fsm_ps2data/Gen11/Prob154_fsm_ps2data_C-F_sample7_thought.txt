Fuse the compact binary-encoded FSM of Example 1 with the direct shift-register style byte storage of Example 2 to get the best of both: minimal state bits, simple state transition logic, and efficient byte capture without redundant byte registers.

Key improvements:

- Use 2-bit binary FSM encoding for minimal state bits (WAIT_SYNC=0, BYTE2=1, BYTE3=2).
- Employ a 24-bit shift register (out_bytes) that shifts in the input byte directly each cycle of message reception, matching the correct byte order.
- Enable loading into out_bytes only when receiving bytes of a message to minimize unnecessary toggling and reduce power.
- Assert done only in the cycle immediately after the third byte is loaded.
- Use synchronous active-high reset and non-blocking assignments for clarity and robust timing.
- Separate combinational next-state logic from sequential logic.
- Keep outputs stable and update only when necessary, reducing glitches and power.

This fusion yields a clean, minimal, power-efficient, and easily scalable solution with low area and good timing properties.
