To optimize power and slightly improve timing, avoid updating out_bytes unnecessarily on every clock cycle. Update out_bytes only when we actually capture a byte. Also, keep done asserted only for one cycle immediately after the third byte is received by using a separate register that is cleared in the next cycle. This avoids toggling done unnecessarily. The FSM state encoding is minimal and efficient, so leave it unchanged. These changes reduce switching activity on the 24-bit register and done output, improving power with minimal complexity increase. The reset logic and synchronous operation remain the same.
