Implement a three-state FSM explicitly named IDLE, BYTE1, BYTE2 to improve readability. In IDLE, the FSM waits for a byte where in[3]=1. Upon detection, this byte is saved as byte 1 and the FSM transitions to BYTE1. Then, in BYTE1 state, the next byte is stored as byte 2, and the FSM moves to BYTE2. In BYTE2 state, it captures the third byte, concatenates all three bytes into out_bytes in the required order, asserts done for one cycle, and returns to IDLE. This approach uses three dedicated registers to hold each byte separately and concatenates them only when done is asserted, keeping output stable during done assertion only. Reset clears all registers and sets FSM to IDLE. This architectural choice separates byte storage and FSM control clearly.
