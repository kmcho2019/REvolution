Implement a three-state FSM using one-hot encoding to explicitly represent each message byte reception phase: IDLE (waiting for sync), BYTE2 (second byte), BYTE3 (third byte). Use a shift register for message assembly that shifts in each received byte only when in the message-receiving states, discarding bytes until the first byte's in[3] bit is set.

The FSM transitions:
- IDLE: stay until in[3] is 1, then move to BYTE2, store the first byte.
- BYTE2: capture second byte and move to BYTE3.
- BYTE3: capture third byte and output done signal for one cycle, then go back to IDLE.

The 24-bit output register concatenates the three bytes in order received, arranged as out_bytes[23:16]=byte1, [15:8]=byte2, [7:0]=byte3. The shift register approach simplifies datapath logic by automatically shifting in bytes as FSM advances. done is a one-cycle pulse after third byte reception.

The synchronous reset clears state and registers. Use non-blocking assignments and positive edge clocking.

This approach differs by using one-hot FSM with a simple shifting register to hold bytes, simplifying logic for byte storage and improving clarity of state-dependent byte acceptance.
