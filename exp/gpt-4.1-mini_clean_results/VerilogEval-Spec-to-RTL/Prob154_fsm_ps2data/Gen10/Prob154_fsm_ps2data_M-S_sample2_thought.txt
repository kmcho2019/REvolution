Use a simple 2-bit state counter to track how many bytes of the current message have been captured. Wait in state 0 until a byte with in[3] = 1 arrives, capturing it as byte 1 and moving to state 1. Then capture next two bytes as byte 2 and byte 3 in states 1 and 2. When the third byte is captured, concatenate all three bytes and assert done. Reset sets all registers to zero. This eliminates intermediate byte registers by storing each incoming byte directly into a 3-byte shift register as we progress, reducing complexity.
