Implement the FSM using explicit states with three states: IDLE (waiting for start byte), BYTE2 (receive second byte), BYTE3 (receive third byte). Use a shift register (24-bit) as a sliding window buffer that shifts in the incoming byte at each message byte reception. When a start byte (in[3]=1) is detected in IDLE, shift it into the upper 8 bits of the buffer and move to BYTE2. Then for BYTE2 and BYTE3 states, shift in bytes into the lower bits of the buffer. Once the third byte is received, assert done for one cycle and output the buffer. This approach uses a single 24-bit shift register rather than separate registers, simplifying the datapath and easing data concatenation. The done signal is generated synchronously right after receiving the third byte. Synchronous reset clears state and buffer. This clear state-driven FSM aids readability and avoids counting logic, reducing complexity.
