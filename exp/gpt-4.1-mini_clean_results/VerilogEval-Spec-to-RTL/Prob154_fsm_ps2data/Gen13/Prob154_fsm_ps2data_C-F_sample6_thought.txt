Fuse the efficient state encoding and done signaling from Example 1 with the simpler shift-register style of byte storage from Example 2. Use a 2-bit state counter to track message byte receipt. Instead of shifting the full 24-bit register every cycle (which may cost power and area), selectively update only the needed byte positions with explicit byte registers. This keeps logic small and fast. On receipt of the first byte (with in[3]=1), store it in the highest byte register; then capture the next two bytes in middle and lowest bytes respectively. On the third byte, concatenate all three bytes into out_bytes and assert done for one cycle. This reduces wide concatenation logic at every clock and minimizes switching by updating only when needed, combining simplicity, power efficiency, and clarity.
