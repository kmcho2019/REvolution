Implement a Moore-type FSM with explicit states: IDLE (looking for start byte with in[3]=1), BYTE1 (store first byte), BYTE2 (store second byte), and BYTE3 (store third byte).  
Use three separate 8-bit registers to store each byte as they arrive, simplifying the capture and assignment.  
Assert done on the clock cycle after the third byte is captured, and concatenate the three bytes into out_bytes in the order specified.  
Keep out_bytes stable only when done is asserted; otherwise, drive it to zero (or any value) to reduce switching.  
Use synchronous active-high reset, and update done and state signals properly with non-blocking assignments.  
This design improves clarity by separating byte registers and uses a state machine that explicitly handles each byte, making the design easy to maintain and verify.
