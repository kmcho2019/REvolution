Compute the equality of every pair from the inputs a, b, c, d, e. Since there are 5 inputs, we have 5x5=25 pairs. For each pair (x, y), output bit is 1 if x equals y, else 0. Equality of bits can be computed as ~(x ^ y). The output bits will be ordered from (a,a) at the top (bit 24) down to (e,e) at bit 0 as per the example. We'll index output bits by pairs in the order (a,a), (a,b), (a,c), (a,d), (a,e), (b,a), ..., (e,e).
