The module will create a 5x5 matrix of comparisons between inputs a, b, c, d, e. 
Each bit in the 25-bit output corresponds to comparing two of these inputs: if they are equal, the output bit is 1, else 0.
The bits are ordered with the first operand changing slowly (rows), and the second operand changing fast (columns).
Use the expression ~(x ^ y) (XNOR) to determine equality of each pair of bits.
