To improve the existing fully unrolled implementation in terms of power and area, I will exploit the symmetry of the pairwise equality matrix: (x,y) and (y,x) yield the same XNOR result. By computing each unique pair only once and assigning both symmetric outputs from that single computation, we avoid redundant logic and reduce gate count.

Specifically:
- Compute and assign all diagonal elements (where inputs are compared to themselves).
- For pairs where row > column, compute the XNOR once.
- For symmetric pairs (row < column), assign outputs directly from the corresponding symmetric pair (row > column) output.

This approach maintains the same output bit mapping as the original solution for clarity and traceability, while reducing the number of XNOR gates by nearly half (from 25 to 15), thus lowering switching power and area.

The output vector indexing remains unchanged for easy verification and comparison to the original design.
