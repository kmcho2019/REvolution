Instead of using nested loops and indexing the output bits directly, another approach is to explicitly concatenate the results of all pairwise comparisons in a fixed order from (a,a) down to (e,e). We define a localparam array for the inputs and systematically compute each pair's equality using the XNOR operator, which directly gives 1 if bits are equal. This avoids complex indexing arithmetic and improves code readability. The output bits are assigned from most significant (a,a) to least significant (e,e) by concatenating the results in the right order.
