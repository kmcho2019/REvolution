Use an array of inputs and a nested generate loop only for generating the pairwise comparisons in a structured manner, which improves scalability and maintainability while preserving exact bit ordering. The bit indexing is carefully calculated so that out[24] corresponds to (a,a), out[23] to (a,b), ..., down to out[0] for (e,e) — counting rows from a to e and columns from a to e, output bits ordered row-wise from highest to lowest. The design also uses the fact that comparison with self is always 1, so those bits are assigned constant 1.

This approach merges explicit control, clarity, scalability, and minor area optimization by hardwiring diagonal bits.
