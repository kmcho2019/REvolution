Simplify the FSM by using binary encoding with a 3-bit state register representing the number of matched bits of "1101" so far. This reduces the number of flip-flops from 5 to 3. The FSM transitions through states 0 to 4, where state 4 means the full sequence is matched and start_shifting should be set permanently. Once detected, stay in this state until reset. The synchronous reset remains active high. This approach trades off a slight increase in next-state logic complexity for significant area savings and simpler state representation, while maintaining the required behavior.
