Implement the sequence detector using a Moore FSM with an explicit "found" output register that is set and latched when the sequence "1101" is detected. Use a one-hot encoding for states to simplify the next state logic and allow clearer state transitions. The FSM will have five states corresponding to the progression of matched input bits. The start_shifting output will be a registered signal set upon detection, remaining asserted until synchronous reset clears it. This approach separates output logic into a register, reducing combinational output glitching and providing a clear indication of detection status.
