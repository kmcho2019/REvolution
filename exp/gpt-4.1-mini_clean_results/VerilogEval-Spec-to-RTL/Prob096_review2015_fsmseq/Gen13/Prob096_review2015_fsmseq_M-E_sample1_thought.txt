Implement the sequence detection using a Moore FSM with a single-bit output register. Instead of binary encoding for states, encode states as 3-bit values but only store one bit for the output signal, which is asynchronously set when the sequence is detected and latched indefinitely. To make the design distinct, use a state encoding that encodes the length of the matched prefix and implement the FSM as a Mealy machine to allow earlier output assertion (though output will still latch permanently on detection). Use a registered output and keep the FSM combinational next state logic simple with a unique transition table. Reset clears both state and output synchronously. This approach simplifies output logic by decoupling it into a register, giving flexibility for timing and avoiding combinational output logic, differing from the previous approach.
