Refactor the FSM using binary-encoded states instead of one-hot encoding to reduce flip-flop count and area. Implement the state register and next-state logic using an always block for sequential state updates and combinational logic for next state, but now with a binary state vector. The output `start_shifting` is asserted when the FSM reaches the "detected" state and held high thereafter until synchronous reset. This structure provides a compact and clear FSM implementation, trading off some performance for reduced area and power. The sequence detection logic and synchronous reset behavior remain unchanged.
