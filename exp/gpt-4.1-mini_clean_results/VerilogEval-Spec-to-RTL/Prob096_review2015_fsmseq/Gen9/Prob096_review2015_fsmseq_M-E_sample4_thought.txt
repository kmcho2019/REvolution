Implement the FSM using a sequence detection approach based on shifting the input bits into a 4-bit shift register and checking for the target pattern '1101'. The FSM itself is simple: once the sequence is detected, the output signal start_shifting is set and latched high until reset. The shift register updates every clock cycle synchronously. This approach avoids explicit state enumeration and relies on data storage and combinational comparison, simplifying state tracking. The output is registered to ensure synchronous assertion and clean timing.
