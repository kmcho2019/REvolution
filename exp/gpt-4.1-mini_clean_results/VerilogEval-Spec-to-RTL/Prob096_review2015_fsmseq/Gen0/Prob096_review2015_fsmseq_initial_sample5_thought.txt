Implement a finite state machine (FSM) to detect the sequence 1101 on the input data stream.
Use states to represent partial matches:
- S0: No match yet
- S1: matched '1'
- S11: matched '11'
- S110: matched '110'
When the next input bit completes the sequence 1101, output start_shifting is set to 1 and stays asserted until reset.
Reset is synchronous active high and clears FSM and start_shifting.
