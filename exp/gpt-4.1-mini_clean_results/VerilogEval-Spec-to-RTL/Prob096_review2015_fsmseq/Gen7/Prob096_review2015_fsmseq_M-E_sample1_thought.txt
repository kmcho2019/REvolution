Implement the FSM using one-hot encoding for clarity and potential timing benefits. Each state will be represented by a single bit in a state register. The states correspond to the amount of matching of the sequence "1101". Use a synchronous process to update the state and the output. Once the sequence is detected, latch start_shifting to 1 indefinitely until reset. This one-hot encoding simplifies next state logic by directly setting state bits based on input and current state, potentially improving timing and making it easier to modify or extend.
