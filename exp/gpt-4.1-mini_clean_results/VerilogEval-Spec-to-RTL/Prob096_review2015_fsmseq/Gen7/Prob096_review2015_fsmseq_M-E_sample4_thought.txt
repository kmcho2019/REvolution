Implement the sequence detector using a Moore FSM encoded in one-hot style with five flip-flops—one for each sequence prefix state plus the detected state. Each state register bit indicates if the FSM is currently in that state. This simplifies next-state logic to simple AND/OR expressions and can improve timing at the cost of some area. Once the final sequence "1101" is detected, the FSM sets and holds the output start_shifting high by staying in the detected state until a synchronous reset returns it to the initial idle state. This one-hot encoding eases path balancing in high-frequency designs and yields clear combinational logic for transitions based on the current data bit.
