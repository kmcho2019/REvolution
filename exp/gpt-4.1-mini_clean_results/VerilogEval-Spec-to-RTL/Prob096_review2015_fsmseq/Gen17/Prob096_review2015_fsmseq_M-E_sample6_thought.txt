Implement the FSM using one-hot encoding for the states to simplify next-state decoding and possibly improve timing in some FPGA or ASIC flows. Each state will be represented by a single bit set high. The FSM will have a separate output register that latches start_shifting once the sequence "1101" is detected, and remains set until reset. The next-state logic is a combinational always block with clear one-hot transitions. Use synchronous active-high reset to clear states and output. This approach separates output logic cleanly and uses one-hot states to simplify combinational logic.
