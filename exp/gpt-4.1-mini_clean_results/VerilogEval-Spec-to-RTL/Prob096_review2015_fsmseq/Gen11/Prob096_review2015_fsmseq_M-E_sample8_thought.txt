Implement the sequence detector as a Mealy machine instead of a Moore machine to reduce the number of states needed. The Mealy FSM will assert start_shifting combinationally when the last input bit completes the '1101' sequence, and then latch start_shifting to '1' in a separate register that stays set until reset. This separates the sequence detection from output latching, minimizing states and allowing immediate detection without waiting for a clock edge. Use synchronous active-high reset. The state machine tracks partial matches only, resetting appropriately on mismatches, and the output latch ensures start_shifting stays high indefinitely after detection.
