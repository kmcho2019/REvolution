Refactor the FSM implementation by encoding the states as a one-hot encoded register and implementing the next state logic with combinational assignments rather than a case statement. Use a set of wires for the next state signals, then register them on the clock edge with synchronous reset. This approach clarifies the state transitions by expressing next states explicitly and can be easier to read and synthesize in some tools. The output remains combinational, driven by the active one-hot state corresponding to the final matched sequence. This structure trades off a slightly larger register count (5 bits vs. 3) for simpler next state combinational logic expressed in straightforward Boolean expressions.
