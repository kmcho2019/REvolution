Implement the sequence detector using a Moore FSM with one-hot encoding for simplicity and speed. Each state corresponds to how many bits of the sequence "1101" have been matched so far. The FSM transitions on each clock cycle depending on the input bit to track partial matches. Once the sequence "1101" is detected, the FSM enters a final state that continuously asserts the output start_shifting. The output remains high until a synchronous reset clears the FSM back to the initial state. This one-hot encoding allows for simple next state logic using combinational assignments and minimal decoding logic for the output, favoring faster timing at a modest area cost.
