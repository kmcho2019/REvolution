Simplify the FSM by using a 2-bit state register encoding only the necessary partial matches. Since the sequence is fixed ("1101"), fewer states can track progress effectively: e.g., no match, matched '1', matched "11", matched "110". When the final bit '1' is found after "110", assert start_shifting and latch it until reset. Use a single always block with synchronous reset, update state and output simultaneously. This reduces complexity by combining state and output logic, removing the need for a separate next_state signal and extra state for the sticky condition, as output can be registered directly once detected.
