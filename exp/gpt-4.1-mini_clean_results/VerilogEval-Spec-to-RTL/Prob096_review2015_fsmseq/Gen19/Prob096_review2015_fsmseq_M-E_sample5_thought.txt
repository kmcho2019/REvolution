Implement the sequence detector using a Moore FSM encoded with one-hot states for potentially faster state decoding and simpler combinational logic. Use four states corresponding to the partial matches of the sequence "1101" plus an additional "done" state to latch start_shifting. Use synchronous active-high reset. To keep the design simple, use two always blocks: one sequential for state transitions and reset, and one combinational for next-state logic based on current state and input. Make the output a registered signal that is set when the sequence is detected and held until reset. This approach trades off a slightly larger state register size for potentially faster clock rates and straightforward output timing.
