Refactor the FSM by encoding the states with a one-hot style approach using a 5-bit register where each bit corresponds to one state. This allows next state logic to be implemented with combinational assigns rather than a case statement, making the logic more explicit and potentially more suitable for synthesis optimization. The output is derived from the dedicated final state bit. The synchronous reset clears the one-hot state to the initial state. The overall FSM logic remains functionally identical but is restructured to use continuous assignments for next state and outputs.
