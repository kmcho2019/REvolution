Implement the sequence detector using a Mealy FSM for immediate response to the current input bit, minimizing the number of states needed. The FSM will track how many bits of "1101" have been matched so far and output start_shifting as soon as the final bit of the sequence is recognized. To create a sticky output (stays high after detection), latch start_shifting in a flip-flop with a synchronous reset. This approach uses fewer states (only 4 states) and a Mealy output that depends on state and input, which can detect the sequence more promptly and simplify output logic by using a dedicated output register to maintain the asserted output until reset. The synchronous reset clears both state and output. The FSM encodes states with 2 bits, representing the prefix matched so far, and the output register ensures stable, glitch-free, sticky output.
