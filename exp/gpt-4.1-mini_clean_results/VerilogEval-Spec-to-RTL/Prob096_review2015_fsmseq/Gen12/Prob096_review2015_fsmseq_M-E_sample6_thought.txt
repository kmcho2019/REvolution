Instead of using one-hot encoding, implement the FSM with a binary-encoded state machine with four states representing how much of the "1101" pattern has been matched so far. The states will be:

- S0: no match yet
- S1: matched '1'
- S2: matched "11"
- S3: matched "110"
- S4: matched "1101" (final sticky state)

The output `start_shifting` will be driven high once the sequence is detected and remains high until reset. After detection, the FSM transitions to a sticky final state that ignores further inputs. The FSM is synchronous with a positive edge clock and synchronous active-high reset.

The design uses binary encoded states to reduce flip-flop count (3 bits), which saves area and power at some potential timing cost compared to one-hot. The next state logic is combinational, and all sequential logic uses non-blocking assignments. This approach balances area and power efficiency with simplicity and clear state progression.

The output logic is a simple comparison to the final state. No clock gating is used here; the state machine continues to operate, but in the final sticky state it simply remains there, minimizing complexity.

This FSM handles overlapping sequences correctly by transitioning according to the last matched prefix to enable sequence detection in a continuous bit stream.
