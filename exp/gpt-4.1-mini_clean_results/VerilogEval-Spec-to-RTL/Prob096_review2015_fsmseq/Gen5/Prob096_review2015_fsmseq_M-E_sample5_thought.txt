Implement the FSM using a single register to store the last 4 bits of input data shifted in at each clock cycle.
Compare this 4-bit window with the target sequence '1101' (binary 4'b1101).
When a match is found, set start_shifting to 1 and hold it until reset.
This approach avoids explicit multiple FSM states by encoding the sequence in a shift register.
Reset synchronously clears both the shift register and start_shifting.
