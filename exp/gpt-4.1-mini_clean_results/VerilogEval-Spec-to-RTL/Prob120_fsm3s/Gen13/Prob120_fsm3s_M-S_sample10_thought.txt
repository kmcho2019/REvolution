To simplify the FSM, I will implement the next state logic and output using a combinational always block with a case statement for clarity and minimal logic. This approach eliminates multiple OR conditions and explicit bitwise logic, making the design easier to read and maintain while maintaining exact functionality.

The state encoding remains 2-bit using localparams for clarity. The state register is updated synchronously on the clock with an active-high reset.

The output is assigned based on the current state within the same combinational always block or by a simple continuous assignment, as it depends only on the state (output = 1 only in state D). This reduces the number of signals and logic needed.

This simplified approach strikes a good balance between clarity and synthesizability, ensuring minimal combinational complexity and easily understood FSM behavior.
