I will implement the Moore FSM using a one-hot state encoding to minimize combinational decoding logic, which can improve timing and power by simplifying state comparisons. The next-state logic and output will be done using a combinational `always_comb` block with a `case` statement over the one-hot encoded states and input. The state register with synchronous reset is a single always block triggered on posedge clock. The output will be directly assigned from the registered state signals to avoid extra combinational logic. This approach improves readability, reduces logic complexity, and facilitates easier extension to larger FSMs.
