Implement the FSM using a one-hot encoded state register with four flip-flops, each representing one state (A, B, C, D). Use a synchronous active high reset to set state A. The next state logic and output logic are done in an always_comb block using a case statement on the current state. This approach increases flip-flop count but often simplifies the combinational logic and can improve timing since only one bit flips per state transition. The Moore output depends solely on state D. This architectural change contrasts with binary encoding by exploiting one-hot encoding advantages.
