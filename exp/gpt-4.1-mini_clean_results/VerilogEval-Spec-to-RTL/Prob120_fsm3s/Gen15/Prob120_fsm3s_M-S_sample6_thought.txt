To simplify the FSM implementation, I will use a single combinational always block with a case statement for next state logic instead of multiple boolean expressions. This will make the code easier to read and maintain, reducing the complexity of next state calculations without affecting functionality.

The synchronous reset and state register update remain the same for clarity and synthesis friendliness. The output will be assigned combinationally based on the current state, consistent with a Moore FSM.

Overall, this approach reduces the combinational logic complexity while preserving the exact behavior of the original FSM.
