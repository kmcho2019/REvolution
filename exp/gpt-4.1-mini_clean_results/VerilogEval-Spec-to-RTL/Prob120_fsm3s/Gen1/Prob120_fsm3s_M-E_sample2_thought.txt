Implement the FSM using one-hot encoding for the four states (A, B, C, D) with a 4-bit state register, where only one bit is set per state. On reset, activate state A. The next state logic uses combinational logic on the current state and input to determine the next state encoding. The output is combinational and depends only on the current state, being 1 for state D and 0 otherwise. This avoids enums and uses simple bit vectors for state representation.
