Implement the FSM using one-hot encoding instead of binary encoding. Each state is represented by a dedicated flip-flop bit, which can simplify next-state logic to mostly combinational AND/OR logic with the input. On reset, activate the A state flip-flop. The output is high only when the D state flip-flop is set. This approach may improve timing by reducing the decoding logic complexity, while still meeting synchronous reset and Moore output requirements.
