Implement the Moore FSM using an enumerated type for state encoding for better readability and maintainability, supported by SystemVerilog syntax. The next state and output logic will be split into two distinct always_comb blocks: one for next state logic based on current state and input, and another for output logic solely dependent on the current state. This explicitly enforces Moore FSM principles and can ease verification and synthesis optimizations.

The state register will be updated synchronously on the positive clock edge with a synchronous active-high reset returning to state A.

Using enumerated states improves code clarity and self-documentation, and separating output logic can potentially improve output timing by decoupling output path from input-dependent next state logic.

Note: This approach assumes SystemVerilog support for typedef enum and always_comb; if only Verilog-2001 is allowed, slight modifications are necessary.
