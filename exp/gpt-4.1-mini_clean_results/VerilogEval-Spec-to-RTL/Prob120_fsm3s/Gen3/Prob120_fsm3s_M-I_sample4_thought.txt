To optimize for power, area, and potentially performance, replace the one-hot state encoding with binary encoding, which uses fewer flip-flops (2 bits for 4 states) and reduces toggling activity. The next state logic will be implemented as combinational logic using binary-coded states. Outputs remain Moore type and depend only on the current state. The reset is synchronous active high, setting the FSM to state A (00). This change reduces area and dynamic power by halving the number of flip-flops and simplifying logic, and may improve maximum clock frequency due to simpler next-state decoding.
