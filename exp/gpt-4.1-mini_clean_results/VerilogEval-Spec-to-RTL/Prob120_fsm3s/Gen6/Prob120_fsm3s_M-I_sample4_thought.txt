To improve PPA, switch the FSM encoding from binary (2-bit) to one-hot encoding. This often reduces combinational logic complexity and critical path delay, improving performance (lower WNS/TNS). Also, one-hot encoding can reduce switching activity on combinational inputs, potentially lowering power. With only four states, one-hot encoding cost in area is minimal. Implement next-state logic with clear one-hot case statements, keeping synchronous reset and non-blocking assignments. Output is asserted when in state D (one-hot bit 3). This approach balances clear, fast logic with low area and power suitable for this 4-state FSM.
