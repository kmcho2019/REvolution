Implement the FSM using one-hot encoding for the states to simplify next-state logic and allow fast decoding of outputs. Represent each state as a single bit in a 4-bit register, where only one bit is set at a time. Use a synchronous reset to set the FSM to state A (one-hot bit 0). Next-state logic is implemented using combinational logic in an always_comb block, explicitly defining next-state bits based on the current state bits and the input. Output logic is a pure combinational assignment that checks if the current state is D (bit 3). This approach reduces complexity in decoding states and can optimize for fast transitions and low logic depth.
