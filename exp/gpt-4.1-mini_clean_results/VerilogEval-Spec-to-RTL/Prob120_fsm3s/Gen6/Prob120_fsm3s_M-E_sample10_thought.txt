Implement the Moore FSM using one-hot encoding for the states instead of binary encoding. Each of the four states will be represented by a separate flip-flop bit. The next state logic will be directly derived from the current state bits and input, which simplifies decoding and can lead to faster state transitions at the cost of slightly more registers. The output will be directly driven by the D state bit, as only state D produces output 1. The synchronous reset will clear all state bits except the initial state bit representing state A.
