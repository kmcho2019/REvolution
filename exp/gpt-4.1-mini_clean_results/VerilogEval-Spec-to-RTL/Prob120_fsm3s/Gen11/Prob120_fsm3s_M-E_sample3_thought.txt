Implement the Moore FSM using a one-hot encoding scheme for the four states, with four state flip-flops instead of two bits. This increases state register width but simplifies next-state logic to AND/OR gates, possibly improving timing. The synchronous active-high reset clears all states except A, and output logic is simply the D state flip-flop. The next state logic uses combinational logic directly from the one-hot encoded state registers and input signal, avoiding case statements and providing a different architectural style from binary encoded FSM.
