I will refactor the FSM implementation by using a one-hot encoding for states instead of binary encoding. This changes the state register from 2 bits to 4 bits, each representing one state, which can sometimes improve timing by simplifying the combinational logic at the cost of a small area increase. The next state and output logic will be expressed via `assign` statements rather than inside an always block, making the design more combinational-style and declarative. The synchronous reset will still be used in the sequential state register. This alternative structure demonstrates a different style while preserving the Moore FSM behavior and the same state transitions and output logic.
