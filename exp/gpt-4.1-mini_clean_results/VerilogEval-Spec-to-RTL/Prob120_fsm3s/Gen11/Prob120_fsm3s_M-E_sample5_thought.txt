I will implement the FSM using one-hot encoding instead of binary encoding. Each state is represented by a single bit, which simplifies the next-state logic to simple combinational equations without a case statement. The FSM registers are then a set of flip-flops, each corresponding to one state, with only one flip-flop set at a time. This can potentially improve timing by reducing decoding logic. The synchronous reset will set the FSM to state A by setting its flip-flop to 1 and others to 0. The Moore output is asserted whenever the FSM is in state D. The combinational next-state logic will be expressed using Boolean equations derived directly from the state transition table. This approach offers a different architectural style that can be beneficial in certain synthesis tools and may improve power or performance by reducing logic depth.
