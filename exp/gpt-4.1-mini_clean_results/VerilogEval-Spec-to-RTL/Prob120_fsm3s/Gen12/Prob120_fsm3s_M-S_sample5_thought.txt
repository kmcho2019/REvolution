I will simplify the FSM by using a synchronous always block for next-state logic and a simple case statement for output logic. The states will remain encoded as 2-bit binary values. The next state will be determined inside the always block using a case statement with clear transitions for each input value, which reduces the combinational logic complexity compared to separate boolean equations. The output will be assigned using a continuous assignment, since it is purely a function of the current state (Moore output). This approach keeps the design clear, concise, and functionally equivalent while lowering logic complexity.
