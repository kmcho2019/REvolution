I will implement the FSM using a fully sequential style with an enumerated type for the states for clarity. The next state and output will be computed within a single sequential always block triggered by the clock to simplify timing and reduce combinational logic delay. The output will be a registered output, typical for a Moore machine, updated after state transitions. The synchronous reset will initialize the state and output to known values. Using enumerated states improves readability. This style combines state register, next state logic, and output logic in one always block, avoiding separate combinational blocks, which can help synthesis tools optimize the design and may reduce glitches and power consumption.
