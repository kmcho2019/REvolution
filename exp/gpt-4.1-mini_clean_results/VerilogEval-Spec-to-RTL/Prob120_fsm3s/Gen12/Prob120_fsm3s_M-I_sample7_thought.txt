To optimize the FSM for better PPA:

- Use one-hot encoding for the states to reduce the critical path delay in next-state logic, improving performance by enabling simpler combinational logic and potentially better timing.

- Implement the next-state and output logic using case statements for clarity and potential synthesis optimization.

- Add a state register enable signal that enables updating the state only when input changes could cause a state transition, potentially reducing power by minimizing unnecessary toggling.

- Keep the synchronous active-high reset.
