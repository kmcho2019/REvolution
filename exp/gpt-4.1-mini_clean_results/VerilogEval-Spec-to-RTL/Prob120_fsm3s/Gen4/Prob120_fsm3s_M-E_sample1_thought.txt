Implement the FSM using one-hot encoding for the states, with each state represented by a 4-bit register where only one bit is set at a time. The synchronous active high reset will set the FSM to state A (represented by 4'b0001). The next state logic will be implemented combinationally using case statements based on the current one-hot state and input, directly producing the next one-hot state vector. The Moore output is generated combinationally from the current state by checking which bit is set. Using one-hot encoding simplifies next state decoding at the cost of wider state registers but can reduce combinational logic depth.
