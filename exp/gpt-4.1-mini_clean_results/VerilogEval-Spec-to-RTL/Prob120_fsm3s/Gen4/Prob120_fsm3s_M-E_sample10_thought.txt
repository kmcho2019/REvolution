Implement the FSM using a one-hot state encoding rather than binary encoding, where each state is represented by a separate flip-flop. This simplifies the next-state logic because transitions can be expressed as direct assignments to the state bits without decoding. Use combinational logic to define the next state signals from the current state bits and input. The output is driven by the state D flip-flop. Synchronous reset sets the FSM to state A (one-hot) by activating only the A flip-flop. This approach can simplify state decoding and potentially improve timing at some area cost.
