I will implement the Moore FSM using one-hot state encoding to simplify next-state and output logic. Each state will be a separate flip-flop bit, which can reduce combinational logic complexity and potentially improve timing. The synchronous reset will clear all states except A. The next-state logic will be defined using a combinational always block with a simple if-else structure based on the input, and the output will be directly assigned from the D state flip-flop. This design enhances clarity and may optimize power by limiting toggling logic, while remaining functionally equivalent.
