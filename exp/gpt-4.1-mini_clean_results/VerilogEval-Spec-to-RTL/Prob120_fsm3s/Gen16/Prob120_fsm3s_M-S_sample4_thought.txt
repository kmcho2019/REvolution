To simplify the FSM while maintaining full functionality, I will:

- Use the same 2-bit state encoding for clarity and minimal flip-flops.
- Combine the next-state logic and output logic inside a single combinational always block for simplicity.
- Implement the synchronous reset and state update in a straightforward sequential always block.
- Use a reg type output signal updated in the combinational block to keep the design self-contained without continuous assignment.
- Maintain a default case for safe synthesis.
  
This approach reduces the number of separate always blocks and lines of code, making the code simpler and easier to follow while preserving all specified behavior.
