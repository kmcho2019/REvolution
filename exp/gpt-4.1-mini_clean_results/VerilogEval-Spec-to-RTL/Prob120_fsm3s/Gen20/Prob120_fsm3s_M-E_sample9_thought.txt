I will implement the FSM using an enumerated type for the state encoding with a single always block that includes both the next-state logic and output logic, storing the output as a registered signal. The output will update synchronously with the state, truly reflecting a Moore machine with registered outputs. This approach unifies the FSM logic and output assignment, which may simplify timing analysis and reduce glitches on the output by avoiding combinational output logic. The synchronous reset is kept to initialize the state and output to known values at reset. This style trades off some explicit separation for a compact and cohesive implementation of state transitions and outputs.
