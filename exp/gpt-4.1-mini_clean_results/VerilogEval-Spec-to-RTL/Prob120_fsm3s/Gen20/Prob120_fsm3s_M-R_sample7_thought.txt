I will refactor the design by moving the next state logic and output logic into a combinational always block instead of using continuous assignments. The state register update remains synchronous with the clock and reset. Using a combinational always block with a case statement for next state logic increases code clarity and eases modification or expansion of the FSM later, while maintaining the same functionality. The output will also be generated inside a combinational always block consistent with a Moore FSM style, assigned based solely on the current state. This approach complements typical synthesis tool flows and is very clear for designers, without changing the encoded states or synchronous reset behavior.
