To simplify the FSM implementation, I will use an always_comb block with a case statement for next state logic instead of multiple boolean equations. This approach is straightforward, easier to read, and compact for a small FSM with only four states. The state encoding remains a 2-bit localparam set for clarity. The state register and synchronous active-high reset logic remain unchanged.

For the output, since it depends only on the current state, I will keep a simple continuous assignment that outputs 1 only when in state D.

This reduces combinational logic complexity, makes the code more maintainable, and is functionally identical to the original.
