To simplify the FSM implementation, I will use a single combinational always block with a case statement for next state logic, which improves readability and conciseness compared to multiple boolean expressions. The state register and synchronous reset remain the same to ensure correct behavior. The output is defined using a simple continuous assignment as it depends only on the current state (state D). This approach reduces complexity by avoiding separate bit-wise next_state assignments and clarifies the FSM logic without changing functionality.
