To improve PPA, switch from binary encoding (2-bit) to one-hot state encoding. One-hot typically reduces combinational logic complexity for next_state decoding and output logic, improving timing (WNS), possibly lowering power by simpler logic gates, though with slightly higher area due to more flip-flops. However, since the FSM has only 4 states, the area overhead is minimal. The simpler next state logic and output combinational logic reduce critical path delay. Additionally, output is directly assigned combinationally from the one-hot state bits, simplifying the output logic. Maintain synchronous active-high reset. Use non-blocking assignments in sequential logic and blocking in combinational logic for clarity.
