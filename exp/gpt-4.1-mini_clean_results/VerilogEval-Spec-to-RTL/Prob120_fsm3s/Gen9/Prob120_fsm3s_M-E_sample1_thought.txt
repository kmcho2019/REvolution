Implement the FSM using one-hot encoding for states rather than binary encoding. Use a 4-bit state register with each bit representing one state (A, B, C, D). This encoding often allows faster state decoding and simpler next-state logic, especially when the number of states is small. Next-state logic is implemented in a combinational always block using case statements, with synchronous reset forcing the FSM to state A. Output is a Moore type, depending only on the current state (D). Using one-hot encoding can increase area but may improve timing by simplifying decoding logic.
