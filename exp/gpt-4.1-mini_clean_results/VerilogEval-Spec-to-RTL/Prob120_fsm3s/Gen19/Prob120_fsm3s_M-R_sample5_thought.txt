Refactor the FSM to use a 4-bit vector for one-hot state encoding and implement the next-state and output logic using combinational always blocks with a state vector instead of separate one-hot signals. This simplifies the code by grouping states into a single register and uses a synchronous reset to initialize to state A (encoded as 4'b0001). The output is assigned combinationally from the state vector. This approach keeps the one-hot encoding but improves readability and maintains the same functionality.
