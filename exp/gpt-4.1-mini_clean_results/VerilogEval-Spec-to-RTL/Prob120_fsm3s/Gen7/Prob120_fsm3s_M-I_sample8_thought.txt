To improve the PPA of the given FSM, we can apply one-hot state encoding instead of binary encoding. One-hot encoding can reduce combinational logic complexity and potentially improve timing (TNS, WNS) by making next state decoding simpler and faster, though it uses more flip-flops (area might increase slightly). Given only four states, the area overhead is minimal. We keep the synchronous reset and separate combinational logic for next state and output. Also, explicitly initialize outputs and next_state to current state and current output to avoid redundant default assignments. This typically reduces logic depth and glitches. Blocking assignments remain appropriate for combinational logic.
