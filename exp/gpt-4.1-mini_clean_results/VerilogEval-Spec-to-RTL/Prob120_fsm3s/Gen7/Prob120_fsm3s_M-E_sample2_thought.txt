I will implement the Moore FSM using a one-hot encoding approach for the four states, which simplifies next-state logic by encoding each state as a separate flip-flop. This approach trades a slight increase in area for simpler combinational next-state and output logic, potentially improving timing by reducing critical path complexity. The next-state logic will be described explicitly using combinational logic derived from input and current state signals. The synchronous active-high reset will set the state to A (one-hot encoded). The output signal will be driven directly from the D state flip-flop, aligning well with a Moore FSM output. All sequential logic is triggered on the positive edge of the clock.
