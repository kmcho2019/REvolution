Implement a Moore FSM with four states A, B, C, D encoded as two bits. The FSM has synchronous active high reset to state A on clock's positive edge. The state transition logic is combinational based on current state and input 'in'. Output is combinational and depends only on current state. State encoding can be: A=2'b00, B=2'b01, C=2'b10, D=2'b11.
