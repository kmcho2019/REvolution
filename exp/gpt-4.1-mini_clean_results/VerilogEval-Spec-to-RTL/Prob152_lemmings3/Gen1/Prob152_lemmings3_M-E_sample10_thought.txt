Use a three-bit state register encoding direction (left or right) and mode (walking, falling, digging) separately. Store the walking direction in a dedicated bit, which never changes during fall or dig, so outputs depend on direction and mode fields. The FSM transitions prioritize fall over dig over direction switch. On reset, set direction left and mode walking. On bump inputs, if walking and grounded, toggle direction. When ground is lost, switch mode to falling but keep direction. When digging command is given while walking and grounded, switch mode to digging. When ground disappears while digging, switch to falling mode, retaining direction. When ground returns while falling, mode returns to walking with stored direction. Outputs derive from current mode and direction bits. This separation allows concise logic and avoids separate states for each mode/direction combination.
