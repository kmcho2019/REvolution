Instead of encoding the entire state (walking/falling/digging + direction) in one register, separate the concerns into multiple smaller state variables:

- A 2-bit "mode" state: 00=walking, 01=falling, 10=digging
- A 1-bit "direction" state: 0=left, 1=right

This modular separation improves readability and simplifies state transitions.

Additionally, track stable ground conditions explicitly by storing ground's previous value.

The FSM transitions are computed based on the current mode, direction, and input signals, following the precedence:

fall > dig > bump.

Bump handling during walking is done explicitly:

- If bump_left and bump_right: toggle direction
- Else if bump_left only: walk right
- Else if bump_right only: walk left
- Else no change

Because mode and direction are separate registers, the logic is straightforward.

Outputs are assigned combinationally from mode and direction.

The asynchronous reset sets the mode to walking and direction to left.

This approach improves modularity and could facilitate easier expansion or modification of behavior in the future.
