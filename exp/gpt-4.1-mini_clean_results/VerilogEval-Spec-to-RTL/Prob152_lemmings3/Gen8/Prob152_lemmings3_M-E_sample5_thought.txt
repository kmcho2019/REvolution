Implement the FSM with two separate registers: one for direction (1 bit: 0=left, 1=right) and one for mode (2 bits: WALK=0, FALL=1, DIG=2). This decouples direction from behavior states and simplifies the logic.

Direction changes occur only when walking and bumped; bumps while falling or digging are ignored. Direction flips based on bump inputs according to the problem spec.

The mode transitions based on inputs and precedence:
- If ground=0 and mode!=FALL => FALL mode
- else if mode=WALK and dig=1 => DIG mode
- else if mode=DIG and ground=0 => FALL mode
- else if mode=FALL and ground=1 => WALK mode (direction preserved)
- else mode stays the same

Reset initializes direction=left and mode=WALK.

Outputs:
- walk_left = walking mode & direction=left
- walk_right = walking mode & direction=right
- aaah = falling mode
- digging = digging mode

This approach is modular, clearly separates direction and mode, and cleanly implements precedence and direction change rules.
