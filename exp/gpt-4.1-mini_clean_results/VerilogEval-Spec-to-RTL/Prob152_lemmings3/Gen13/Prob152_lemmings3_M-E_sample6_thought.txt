Separate the FSM into two independent registers: one tracking the walking direction (left/right) and another tracking the mode (walking, falling, digging). This orthogonal state representation simplifies updates since the direction changes only when walking and bumped, and mode changes according to ground and dig inputs. The reset sets direction to left and mode to walking.

At each clock edge, with async reset:

1. If falling and ground returns, mode switches to walking (direction unchanged).
2. Else if mode is walking:
   - If ground is lost, mode switches to falling.
   - Else if dig=1, mode switches to digging.
   - Else if bumped, direction flips according to bump inputs.
3. Else if mode is digging:
   - If ground lost, mode switches to falling.
   - Otherwise, continue digging.

Outputs are generated by combining mode and direction:

- walk_left: walking mode and direction left
- walk_right: walking mode and direction right
- aaah: falling mode
- digging: digging mode

This split simplifies combinational logic and makes the FSM more modular and readable. The direction is only updated when walking and bumped. The mode transitions are straightforward. Using separate registers aids debug and synthesis optimization by reducing encoded state complexity.
