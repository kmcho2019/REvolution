To optimize PPA, reduce state encoding bits and combinational logic depth. Use one-hot encoding for modes (walk, fall, dig) since we have only 3 states and tools typically optimize one-hot FSMs well. Keep direction bit separate for clarity and minimal logic. Rework the always block to update mode signals separately as flip-flops for each state, reducing logic in next state decoding. This can improve timing (less combinational logic), possibly lower power (fewer transitions), and marginally reduce area by simpler decoding logic. Also, use synchronous reset instead of asynchronous if allowed, to simplify reset logic and timing, but since spec requires asynchronous reset, keep it. Keep the Moore FSM style and priority logic unchanged for correctness.
