Model the FSM with an enumerated single state register encoding both mode and direction in one 3-bit state: two bits for mode (walk/dig/fall) and one bit for direction (0=left,1=right). On each clock edge (with async reset), update state following priority: if ground=0, go to falling state keeping direction; else if dig=1 and currently walking, start digging; else if walking and bumped, change direction accordingly. When falling, ignore bumps and dig commands; when digging, continue until ground lost, then fall. Outputs are decoded from the current state bits. This tightly couples mode and direction and clarifies logic by explicitly enumerating all states.
