Use a single 3-bit state encoding in a Moore FSM to represent all modes and directions combined. Define states explicitly: WALK_LEFT, WALK_RIGHT, DIG_LEFT, DIG_RIGHT, FALL_LEFT, FALL_RIGHT. The direction is embedded in the state encoding. On each clock cycle, update the state based on the input conditions, prioritizing fall > dig > bump direction change. Outputs are directly derived from the current state. The asynchronous reset sets the state to WALK_LEFT. This approach makes the FSM easier to visualize as a state diagram and enables straightforward output logic without separate mode and direction registers.
