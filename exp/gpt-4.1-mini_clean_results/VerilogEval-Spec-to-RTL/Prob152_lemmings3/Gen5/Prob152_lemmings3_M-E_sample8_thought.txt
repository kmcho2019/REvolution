Implement the FSM using a single 3-bit state register that encodes both the direction and behavior in one combined state. Use explicit encoding for six states: walking left, walking right, falling left, falling right, digging left, and digging right. 

This combined encoding eliminates the need for separate direction and behavior registers and simplifies the output logic. Transition conditions use state and inputs directly to determine the next state.

Priority of transitions is preserved by order of checks: falling overrides digging, which overrides bump-induced direction change.

Bumps only cause direction change when walking on solid ground (ground=1 and not falling/digging). Falling or digging states ignore bumps.

The output signals are derived from the current state: walk_left and walk_right active only in walking states; aaah active in falling states; digging active in digging states.

Reset asynchronously sets state to walking left.

This approach reduces complexity by having one state variable and clear combined states, simplifying combinational next state logic and output assignments.
