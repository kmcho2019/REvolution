Use two separate one-bit registers: one for direction (left=0, right=1), and one 2-bit register for the mode (walk=2'b00, fall=2'b01, dig=2'b10). This separates concerns and simplifies direction updates and mode transitions.

Direction updates occur only when walking and on ground, and bumps trigger direction flips. By separating direction and mode, direction is updated only when relevant, avoiding mixing with mode logic.

For the mode FSM:
- Falling mode activates immediately when ground drops, regardless of digging or bump.
- Digging mode starts only if dig=1 while walking and on ground, and stops when ground disappears, transitioning to fall.
- Walking mode resumes when ground reappears from falling or digging.
- Direction changes when bump occurs only during walking on ground; bumps ignored otherwise.

Outputs derive from the mode and direction registers:
- walk_left = walking mode && direction==0
- walk_right = walking mode && direction==1
- aaah = falling mode
- digging = digging mode

This modular split allows cleaner next-state logic, enables direction flip with minimal state assignments, and keeps mode transitions clear. The asynchronous reset initializes to walking left (direction=0, mode=walk).

This approach provides flexibility and explicitness in the control logic, possibly simplifying synthesis and verification.
