Use a single 2-bit state register encoding all three states: walking left, walking right, and falling. Digging can be treated as a transient substate only valid while walking on ground with the dig input asserted, so track it with a separate digging flag that is cleared when falling or ground is lost. Update state on clock edge with asynchronous reset. State transitions give priority to falling, then digging, then bump direction changes. Outputs are directly derived from the state and digging flag. This reduces the register count and conditional complexity compared to separate mode and direction bits.
