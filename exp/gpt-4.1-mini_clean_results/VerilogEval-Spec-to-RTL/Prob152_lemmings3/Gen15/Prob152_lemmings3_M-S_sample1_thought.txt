Use a 2-bit state encoding to simplify the FSM: 1 bit for direction (0=left, 1=right) and 1 bit for mode (0=walking, 1=falling/digging). Since falling and digging differ only in the output and transitions can be distinguished by inputs, combine them into one mode bit to reduce complexity.

State bit 1: mode (0 = walking, 1 = not walking [falling or digging])  
State bit 0: direction (0 = left, 1 = right)

Use a separate flag for digging, stored in a register, to distinguish digging from falling during non-walking mode.

On reset, start walking left (mode=0, direction=0, digging=0).

Next state logic:  
- If walking and ground lost → mode=1 (not walking), digging=0 (falling).  
- If walking and dig asserted → mode=1, digging=1.  
- If walking and bump detected → switch direction.  
- If in falling/digging and ground regained → mode=0 (walking), digging=0.  
- If digging and ground lost → switch to falling (digging=0).  
- Otherwise hold state.

Outputs decode from mode, direction, and digging flags: walk_left/right only when walking, aaah when falling (mode=1 and digging=0), digging when mode=1 and digging=1.

This reduces state encoding to 2 bits plus a single digging flag, simplifying combinational logic and outputs while maintaining full functionality. Moore outputs depend only on registered state and digging flag.
