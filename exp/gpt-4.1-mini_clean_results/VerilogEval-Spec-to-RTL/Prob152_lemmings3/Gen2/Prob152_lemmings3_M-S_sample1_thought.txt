Simplify the FSM by encoding direction and activity directly in one 2-bit state: one bit for direction (0=left,1=right), and one bit for activity (0=walking, 1=falling or digging). To distinguish falling vs digging, use a separate digging flag.

Handle priority in next state logic: if no ground, fall; else if digging requested and currently walking on ground, start digging; else if bumped and walking, switch direction; else remain in current state.

Store direction and activity explicitly in the state register and a digging flag register.

Outputs:
- walk_left: walking and direction=left
- walk_right: walking and direction=right
- aaah: falling (ground=0 and not digging)
- digging: digging flag

Reset initializes walking left.

This removes multiple states for each combination, uses simple logic, and still is a Moore FSM with outputs depending only on current registers.
