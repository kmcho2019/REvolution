Simplify the FSM by combining state and direction into one state register with three states each having a direction: WALK_LEFT, WALK_RIGHT, FALL_LEFT, FALL_RIGHT, DIG_LEFT, DIG_RIGHT. This eliminates a separate direction register and complex direction update logic.

Transitions become simpler:  
- When walking left or right, if ground is lost, go to falling state with same direction.  
- If digging command occurs on ground, go to digging state in current direction.  
- When bumped while walking, flip direction accordingly: bump_left means walk right, bump_right means walk left, bump both means flip direction.  
- Falling transitions back to walking when ground returns.  
- Digging transitions to falling if ground lost, otherwise stays digging.  
- Bumps and dig commands ignored while falling or digging.

Outputs are directly based on current state (6-state encoding). Reset goes to WALK_LEFT.

This reduces registers and conditionals by encoding direction in state, yielding simpler next-state logic with fewer conditions.
