To optimize PPA (power, performance, area) while preserving behavior, I propose:

1. Merge the prev_ground register with state logic by using a simple edge-detect combinational signal derived from current and previous ground signals, but since prev_ground is needed for stable_ground detection, keep prev_ground register but add an enable so it only updates when ground changes. This reduces toggling flip-flops and lowers power.

2. Simplify bump direction logic: replace multiple if-else with a concise expression that toggles direction if bump_left or bump_right is high, in a single line, avoiding nested conditions.

3. Avoid redundant assignments in combinational block for next_dir when direction is unchanged, by assigning next_dir only when a change is necessary. This reduces glitches and unnecessary switching.

4. Remove the default next_dir assignment to dir to avoid unnecessary toggling (next_dir only assigned when needed).

5. Use one-hot encoding for states to reduce decoding logic and improve timing. Since only 3 states exist, use 3 bits with only one bit set per state.

6. Combine direction and state update logic into a single always block to reduce register stage and improve timing.

7. Implement enable for prev_ground register update: update only if ground differs from prev_ground.

This approach reduces power by lowering register toggling, simplifies combinational logic to improve timing, and slightly reduces area by avoiding extra logic for complex bump conditions.

Overall, we keep asynchronous reset and output logic intact, preserving functional correctness.
