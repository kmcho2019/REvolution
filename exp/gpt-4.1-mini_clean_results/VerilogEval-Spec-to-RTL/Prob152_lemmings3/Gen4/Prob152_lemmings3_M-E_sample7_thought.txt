Implement the FSM with three main signals: a 2-bit state (WALK, FALL, DIG), and a 1-bit direction (0=left,1=right). Use only one clocked always block triggered on posedge clk and posedge areset for state and direction updates to ensure synchronous updates with asynchronous reset.

To handle ground changes precisely without using delayed versions that cause latency or complexity, store the previous ground level in a register updated each cycle at clock edge, allowing simple edge detection by comparing current and previous ground signals inside the synchronous block.

Prioritize conditions in this order inside the synchronous block:

- If areset, go to WALK and direction left.
- Else if currently WALKING:
  - If ground just fell (prev_ground=1 and ground=0), transition to FALLING, keep direction.
  - Else if dig=1 and ground=1 (on ground and commanded to dig), transition to DIGGING.
  - Else if bumped (bump_left or bump_right), invert direction (regardless of both bump bits) if no ground edge occurred.
- Else if FALLING:
  - If ground just rose (prev_ground=0 and ground=1), transition to WALKING, keep direction.
- Else if DIGGING:
  - If ground=0 (fell off while digging), transition to FALLING.
  - Else remain digging.

While falling or digging, bumps have no effect.

Outputs are assigned combinationally from current state and direction.

This approach avoids asynchronous logic for ground edge detection, only depends on synchronous sampling of ground, and guarantees FSM outputs update aligned with clock edges, minimizing glitches and synchronization issues. Using a single always block avoids state and direction desync.

This is a pure Moore FSM with synchronous state transitions and all outputs purely derived from state and direction signals.

This clear priority and synchronous edge detection simplifies reasoning and should match expected behavior in all timing scenarios.
