Use a 2-bit state encoding to represent mode only (00=walk, 01=fall, 10=dig), and keep direction as a separate 1-bit register. This separates concerns and simplifies the next state logic by handling mode and direction updates independently. Direction changes only when walking and bumped, falling and digging do not affect direction. Mode changes according to ground and dig inputs with clear priority. On reset, initialize to walk left. Outputs are simply decoded from mode and direction signals. This separation reduces complexity while preserving correct behavior.
