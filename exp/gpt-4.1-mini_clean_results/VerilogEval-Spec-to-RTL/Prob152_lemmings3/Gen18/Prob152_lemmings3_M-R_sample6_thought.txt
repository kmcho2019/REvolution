I will refactor the FSM by encoding all the state information (mode and direction) into a single 3-bit state vector, which merges mode and direction bits. This reduces register count and simplifies state updates. The walking states will have direction encoded as the LSB, falling and digging states will have direction retained from the prior walking state. I will implement the next state logic combinationally in a separate always block, and outputs as simple decode signals. This avoids separate direction register, improves clarity and reduces multiplexing logic. The asynchronous reset initializes to walking left as state 3'b000. This approach keeps the same priority and behavior but has a more compact and efficient state encoding.
