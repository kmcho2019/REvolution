The design is a Moore FSM with the following states:

- WALK_LEFT: walking left on ground
- WALK_RIGHT: walking right on ground
- FALL_LEFT: falling while originally walking left
- FALL_RIGHT: falling while originally walking right
- DIG_LEFT: digging while walking left on ground
- DIG_RIGHT: digging while walking right on ground

Transitions:
- From WALK states:
  * If ground==0, go to FALL with same direction
  * Else if dig==1, go to DIG with same direction
  * Else if bumped (bump_left or bump_right), switch direction
  * Else remain in current walk state
- From FALL states:
  * If ground==1, go back to WALK with the original direction
  * Else remain FALL
- From DIG states:
  * If ground==0, go to FALL with the original direction
  * Else remain DIG

During FALL and DIG, bumps and dig signals are ignored. During FALL, aaah=1. During DIG, digging=1. The outputs walk_left and walk_right are set according to the walking direction in WALK and DIG states (walking or digging direction), and 0 during FALL. On asynchronous posedge areset, state goes to WALK_LEFT.

Implementation notes:
- Use a reg for state and next_state
- Define symbolic states with parameters
- Implement asynchronous reset with posedge areset
- Moore outputs depend only on state
