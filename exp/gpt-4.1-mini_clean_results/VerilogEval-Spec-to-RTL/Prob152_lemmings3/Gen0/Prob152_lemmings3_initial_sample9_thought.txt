We model the Lemming behavior using a Moore finite state machine with three main states:

- WALK_LEFT: Lemming walks left.
- WALK_RIGHT: Lemming walks right.
- FALL: Lemming is falling (aaah! is asserted).

We add a digging flag to indicate whether the Lemming is currently digging.

Transitions and outputs:
- On reset, go to WALK_LEFT, digging = 0.
- If ground=0, transition to FALL regardless of bump or dig, digging is cleared (can't dig while falling).
- If currently FALL and ground=1, transition back to the walking state before the fall, digging=0.
- If ground=1 and not falling:
  - If dig=1 and not currently digging, start digging.
  - If digging and ground=0 (falls off while digging), go to FALL and clear digging.
  - If not digging, respond to bump_left and bump_right to switch direction.
- While falling or digging, bumps have no effect on direction.
- Outputs depend only on state and digging flag:
  - walk_left is 1 when in WALK_LEFT and not falling and not digging.
  - walk_right is 1 when in WALK_RIGHT and not falling and not digging.
  - aaah is 1 when in FALL state.
  - digging is 1 when digging flag is set.

Use asynchronous positive edge reset. Use a "prev_walk_state" register to remember the direction before falling to return to after fall.

FSM states encoded with localparams for clarity.
