Implement a Moore FSM with three main states: WALK_LEFT, WALK_RIGHT, and FALLING, plus a DIGGING sub-state active only when walking and dig=1. The output signals correspond to states: walk_left=1 when walking left (including digging), walk_right=1 when walking right (including digging), aaah=1 when falling, and digging=1 when digging.

On reset, state is WALK_LEFT and not digging. On each clock cycle:
- If areset is asserted, reset state.
- Else, if ground=0 and not currently falling, transition to FALLING, clear digging.
- Else if currently falling and ground=1, return to previous walking direction state (saved before falling), digging=0.
- Else if digging is active:
  - If ground=1, continue digging.
  - Else ground=0, transition to FALLING, digging=0.
- Else if walking (not digging) and dig=1 and ground=1, start digging in current walking direction.
- Else if walking (not digging) and bump left or bump right:
  - switch walking direction.
- Else remain in current state.

Bumps and dig signals are ignored while falling or digging (except dig initiates digging only when walking and ground=1).

All outputs are functions of the state (Moore machine).

Use a reg to save previous walking direction before falling to restore after fall.

Implementation includes:
- State encoding with parameters.
- Registers for state, next_state, digging flag, saved walking direction.
- Asynchronous reset on posedge areset.
- Outputs combinationally derived from state and digging flag.
