Implement the Lemming FSM by combining direction and behavior into a single 3-bit state to simplify control and ensure all conditions are handled in a flat state transition table. Use explicit states encoding direction and behavior (WalkLeft, WalkRight, FallLeft, FallRight, DigLeft, DigRight). This avoids separately tracking direction and state, simplifying next-state logic.

Transitions prioritize falling > digging > bumping per spec:
- If no ground, transition to falling state preserving direction.
- If digging requested on ground while walking, transition to digging state preserving direction.
- If bumped while walking on ground, switch to walking in opposite direction.
- While falling or digging, bump signals are ignored.
- After falling, return to walking same direction.
- After falling from digging, continue walking original direction.
- Async reset initializes state to WalkLeft.

Outputs are directly derived from the current state. This fully explicit FSM state encoding removes the need for a previous ground register or stable ground detection, by carefully ordering transitions and ignoring bumps/digs during falling/digging. This approach trades a few more states for simpler, straightforward logic with clean priority handling.
