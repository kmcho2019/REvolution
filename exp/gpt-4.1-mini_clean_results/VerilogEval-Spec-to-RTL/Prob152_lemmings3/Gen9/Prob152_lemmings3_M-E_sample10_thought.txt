Use a single encoded state register combining direction and mode into one 3-bit state variable to simplify state handling. Define states explicitly: walk-left, walk-right, fall-left, fall-right, dig-left, dig-right. On reset, go to walk-left. On each clock, update state with priority: if ground lost, transition to fall state maintaining direction; if falling and ground regained, transition back to walk state with same direction; if walking on ground and dig=1, go to dig state in current direction; if walking and bumped, switch walking direction; if digging and ground lost, switch to fall state; else remain in current state. Outputs are derived combinationally from state: walk_left or walk_right for walking states, aaah for fall states, and digging for dig states. This explicit state encoding avoids separate mode and dir registers, improving clarity and potentially synthesis quality.
