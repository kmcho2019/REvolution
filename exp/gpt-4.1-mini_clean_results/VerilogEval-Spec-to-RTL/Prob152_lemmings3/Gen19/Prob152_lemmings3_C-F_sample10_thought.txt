Fuse the compact 2-bit FSM encoding from Example 1 (direction + walk/fall) and the explicit DIG state from Example 2 by extending state to 3 bits: 1 bit direction + 2 bits mode (WALK, FALL, DIG).

This approach keeps minimal and orthogonal state encoding:
- direction bit: 0=left,1=right
- mode bits: 00=walk, 01=fall, 10=dig

The FSM prioritizes transitions as:
1) Fall if no ground (dig canceled)
2) From fall to walk when ground returns
3) From walk to dig if dig=1
4) From walk, bump changes direction
5) From dig, fall if no ground, else continue digging

Using a 3-bit state (direction + 2-bit mode) integrates digging cleanly into FSM instead of a separate flag, reducing state management complexity and easing synthesis.

Combinational next-state logic uses blocking assignments and clear priority in an if-else ladder to minimize logic depth.

Outputs derive from state bits ensuring only one of walk_left, walk_right, aaah, digging is asserted at a time.

Asynchronous reset sets to walking left, no dig/fall.

This fusion improves clarity by consolidating all modes in one state variable and reduces register count, improves power by fewer registers and simpler state transitions, and improves performance via concise prioritized next-state logic.
