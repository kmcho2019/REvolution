Simplify the FSM by using a single 3-bit state encoding to represent direction (left/right), mode (walking/falling), and digging status. This eliminates the separate digging register, reducing complexity and register count. Use combinational logic with clear priority: fall > dig > bump direction switch. Update the state synchronously with asynchronous reset. Outputs are directly decoded from the state bits, keeping the code compact and readable while preserving all specified behavior.
