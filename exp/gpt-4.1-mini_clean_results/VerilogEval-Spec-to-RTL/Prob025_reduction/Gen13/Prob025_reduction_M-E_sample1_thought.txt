Compute the parity by serially XOR-ing each bit in a procedural always_comb block, accumulating the parity bit step-by-step using a for-loop. This sequential folding approach over the input vector within a combinational process gives a simple, clean structure without intermediate wires or hierarchical modules. It demonstrates a different style by using procedural code and iteration instead of parallel XOR tree or reduction operator, while maintaining purely combinational logic. The parity output is assigned from the accumulated parity register after processing all input bits.
