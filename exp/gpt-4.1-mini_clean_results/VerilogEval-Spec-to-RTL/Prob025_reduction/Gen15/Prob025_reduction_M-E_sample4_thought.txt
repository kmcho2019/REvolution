Instead of using the built-in reduction XOR operator, I will implement the parity calculation using a simple chain of XOR gates in a sequential manner within a combinational always block. This approach leverages a for-loop to sequentially XOR each bit of the input vector, accumulating the parity bit. 

This method demonstrates how to manually implement an XOR tree using a procedural block, which is a clear and educational alternative to the reduction operator. It also avoids module instantiations and shows how to use combinational logic with registers for intermediate results, which some designers might prefer for clarity or customization. 

The final parity output is computed combinationally and reflects even parity as the XOR of all bits.
