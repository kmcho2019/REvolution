Refactor the hierarchical recursive XOR tree into a simpler flat structure by explicitly instantiating the HalfXor modules in a fixed two-level XOR tree without recursion or generate loops. This approach preserves the hierarchical modularity but removes the recursive complexity, making the design easier to read and verify while still balancing XOR operations for clarity.

Specifically:
- First level: XOR pairs of input bits via HalfXor modules (4 instances, each handling 2 bits).
- Second level: XOR the four outputs from the first level using two HalfXor modules.
- Final parity: XOR the two outputs from the second level using one HalfXor module.

This fixed structure is simple, synthesizable, and visually shows the stepwise reduction of XOR without using a parameterized recursive module or generate loops.

This refactoring keeps modularity by using HalfXor modules, but trades parameterization and recursion for straightforward, explicit instantiation and wiring.
