Instead of using the XOR reduction operator directly, I will implement the parity calculation by explicitly XORing the bits in a hierarchical pairwise manner. This breaks down the 8-bit input into pairs, XORs each pair, then XORs the results, reducing the critical path in a balanced way. While the built-in reduction operator likely maps to a similar structure, this manual approach makes the logic levels explicit and shows how parity can be computed structurally. This design is fully combinational and still minimal but demonstrates a different architectural style for parity calculation.
