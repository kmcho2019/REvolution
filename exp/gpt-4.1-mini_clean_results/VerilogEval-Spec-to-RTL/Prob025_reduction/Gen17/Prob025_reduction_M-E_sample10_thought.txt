Implement the even parity generator for an 8-bit input using a single always_comb block and a simple parity calculation algorithm. Instead of hierarchically XORing pairs or using generate statements, perform a bitwise XOR reduction using a for-loop that iterates through each bit of the input vector and accumulates the parity bit.

This approach uses behavioral Verilog for clarity and ease of modification, and models the parity as a simple combinational process. It also allows for easy scalability to other input widths by adjusting the loop range.

This design is fully synthesizable, minimal in logic gates, and easy to understand while differing structurally from both recursive and flat XOR-tree implementations.
