Implement the logic function described by the given Karnaugh map. The Karnaugh map is for inputs a, b, c, d arranged as cd (rows) and ab (columns) with specified output values. The map alternates outputs in a checkerboard pattern. Observing the pattern, the output is 1 whenever (a XOR b XOR c XOR d) is 1. So, the output can be implemented as the XOR of all four inputs.
