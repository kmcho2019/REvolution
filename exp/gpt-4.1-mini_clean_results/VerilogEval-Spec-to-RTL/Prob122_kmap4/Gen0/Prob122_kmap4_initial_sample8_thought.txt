The Karnaugh map defines the output for each combination of inputs a, b, c, d. The map is a 4x4 grid with rows labeled by cd and columns by ab. From the map values, the output is 1 when the sum of bits a,b,c,d is odd, because the pattern alternates 0 and 1 in a checkerboard fashion. This pattern corresponds to the parity of the 4 inputs. Therefore, the output can be implemented as the XOR of all inputs a, b, c, and d.
