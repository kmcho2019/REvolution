The Karnaugh map represents an XOR parity function of all four inputs. Since XOR is associative and commutative, the entire function can be implemented as a single chained XOR of all inputs. Instead of balancing the XORs into two pairs, the simpler implementation is just to XOR all four inputs directly in one line. This reduces the code complexity and lines without changing the function or performance, as synthesis tools typically handle multiple-input XORs efficiently.
