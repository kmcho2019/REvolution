Fuse the combinational next-state logic from Example 1 with the synchronous output update from Example 2 to optimize clarity, timing, and output gating. Specifically, compute next_state combinationally (to keep clear separation of combinational and sequential logic), but update state and outputs synchronously on the clock edge, generating outputs based on current state and input for Moore outputs asserted for one full cycle after detection. 

This fusion:
- Retains the simple 3-bit saturating counter state encoding.
- Uses combinational logic for next_state calculation, ensuring minimal critical path in sequential logic.
- Registers outputs synchronously only once per cycle after state update to reduce glitches.
- Asserts disc, flag, and err one cycle after detection in a classic Moore FSM manner.
- Enables concise logic and clean separation between next-state logic and output logic.

This design balances simplicity, timing closure, and power efficiency with straightforward code maintainability.
