Implement a Moore FSM using one-hot encoding to explicitly track each count of consecutive ones from 0 to 7, plus an error state. This state encoding simplifies output decoding and may improve timing by reducing decoding complexity.

Maintain a 1-bit register for previous input to help detect zero following a sequence of ones.

Use combinational logic to define the next state based on the current one-hot state and the current input bit. On input 1, advance the one-hot to the next state representing one more consecutive 1, except for error state where it remains until reset or zero input.

Detect disc, flag, and err signals from the current state and the current input, asserting outputs registered synchronously one cycle after detection as Moore outputs.

Reset initializes the FSM to the zero consecutive ones state and prev_in to 0.

This design emphasizes clarity and potentially better timing by using one-hot states, trading off some area for simpler decoding and logic.
