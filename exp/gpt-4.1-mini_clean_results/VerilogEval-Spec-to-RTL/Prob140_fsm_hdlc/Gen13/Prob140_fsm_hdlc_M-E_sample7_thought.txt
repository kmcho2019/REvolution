Implement a Moore FSM with explicit named states representing the count of consecutive ones seen so far (S0 to S7, where S7 represents error state). On input 0, the FSM resets back to S0, otherwise it transitions from state Si to Si+1. Output signals are set based solely on the current state, with disc asserted in S5 (waiting for zero input), flag asserted in S6 (waiting for zero input), and err asserted in S7 and beyond (7 or more ones).

This approach emphasizes readability and explicit states rather than arithmetic counting. The outputs are purely based on the current state, which fits the Moore FSM definition strictly. State transitions occur synchronously on clock edge, with synchronous reset initializing the FSM to S0. This architectural style clarifies the behavior and state transitions for the HDLC bit stuffing decoding logic.
