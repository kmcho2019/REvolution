Outputs will be assigned based on the updated count and input, preserving the one cycle delay of the Moore FSM by using the previous count value. To maintain this one cycle delay with a single always block, outputs will be assigned using the count value before updating it, so outputs correspond to the state of the FSM one cycle ago.

This simplification reduces code complexity and signal usage while retaining functionality and synchronous behavior.
