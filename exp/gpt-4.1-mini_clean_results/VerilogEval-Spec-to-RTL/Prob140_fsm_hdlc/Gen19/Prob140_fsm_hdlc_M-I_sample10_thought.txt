To optimize the original design for better performance, power, and area (PPA), replace the saturating 3-bit counter with an explicit FSM encoding states 0 to 7 (seven consecutive ones count plus error state) as separate states. This eliminates arithmetic increment and comparison logic in combinational path, reducing logic depth and improving timing.

Also, add a clock enable signal for the count register to avoid unnecessary state transitions and switching when saturated at error state (7 or more ones). This lowers dynamic power.

Outputs (disc, flag, err) remain one-cycle pulses as Moore outputs, updated synchronously.

This FSM approach:
- Simplifies combinational next-state logic to minimal state transitions
- Eliminates saturating increment and numeric comparisons
- Allows easy addition of clock gating for the saturated error state
- Retains clarity and correctness of original logic
- Expected to improve worst negative slack (WNS) and reduce power slightly due to reduced switching

The FSM states represent number of consecutive ones counted:
- S0: 0 consecutive ones
- S1: 1 consecutive one
- ...
- S6: 6 consecutive ones
- S7: Error state (7 or more consecutive ones)

Transitions update count state accordingly, and disc, flag, err asserted on the cycle after detecting respective patterns as per HDLC framing rules.
