Implement a Moore FSM with explicit named states that track the number of consecutive ones seen so far (from zero up to 6 or more). Each state corresponds to a count of consecutive ones. The FSM transitions between these states based on the current input bit. When a zero is seen after exactly five ones, assert `disc` on the next clock cycle; after six ones followed by zero, assert `flag`; and if seven or more ones occur, assert `err`. This explicit FSM avoids counters and clarifies state transitions, producing synchronized one-cycle delayed output signals per Moore FSM style, with synchronous reset initializing to the zero-ones state.
