Refactor the design to implement an explicit Moore-type FSM with named states representing the count of consecutive 1s (0 to 7+ saturated). This approach replaces the saturating counter with an enumerated state machine for clarity and better state encoding control. We will:

- Define states S0 through S7+ representing 0 to 7+ consecutive ones.
- On reset, start at S0 (previous input zero).
- On input 'in' = 1, move to next state unless saturated at S7+.
- On input 'in' = 0, reset state to S0.
- Outputs are assigned based on the current state and next input to detect disc, flag, and err conditions.
- Use one synchronous always block for state transitions.
- Use combinational logic to assign outputs (Moore outputs) based solely on current state.
- Outputs are registered one clock cycle after condition occurs.
- This explicit FSM style helps synthesis tools optimize state encoding and output logic, possibly improving timing and area, and keeps power similar by avoiding arithmetic operations.
