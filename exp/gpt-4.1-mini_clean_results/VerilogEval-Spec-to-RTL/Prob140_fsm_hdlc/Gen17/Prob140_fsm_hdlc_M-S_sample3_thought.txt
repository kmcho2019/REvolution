Simplify the FSM by using a 3-bit counter to track consecutive ones (0 to 6), avoiding explicit enumerated states. The state is just the count of consecutive ones, updated each cycle. 

- On input bit `in` = 1, increment the counter (unless it is already 6, then signal error).
- On input bit `in` = 0, reset counter to zero.
- Use simple logic to generate outputs based on the count and current input:
  - `disc` when a zero follows exactly 5 ones (i.e., counter == 5 and in == 0).
  - `flag` when a zero follows exactly 6 ones (counter == 6 and in == 0).
  - `err` when counter attempts to increment beyond 6 (i.e., 7 or more ones consecutively).

Outputs are Moore type, so they are registered and asserted for one cycle after detection, no combinational feedback on outputs.

This approach reduces state encoding complexity and combinational logic, improving timing and area without losing functionality.

Synchronous reset initializes the counter to zero, mimicking that the previous bit was zero.
