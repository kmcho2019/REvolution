Simplify the FSM by using a single 3-bit state variable representing the count of consecutive ones (0 to 7+). Use states 0-5 for counting ones, and special output states indicated by particular counts combined with the current input, rather than separate explicit states for disc, flag, and error.

Implement outputs (disc, flag, err) purely as combinational signals depending on the current state and input conditions:

- disc output is asserted when the previous count was 5 consecutive ones and current input is 0 (meaning the stuffed zero to discard).
- flag output is asserted when the previous count was 6 consecutive ones and current input is 0 (flag detected).
- err output is asserted when count reaches 7 or more (7 consecutive ones).

This approach avoids extra states dedicated to outputs, reducing state encoding complexity and next state logic. The FSM resets to count zero on reset (behaving as if previous input was zero). Outputs are Moore-type (only depend on current state and input), stable and synchronous with one cycle delay by registering outputs after state update.

This leads to cleaner and more compact code with fewer states and simpler logic, still meeting all specifications.
