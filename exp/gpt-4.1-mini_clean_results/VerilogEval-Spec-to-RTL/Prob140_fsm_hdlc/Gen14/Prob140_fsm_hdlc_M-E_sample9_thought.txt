Implement a Moore FSM with explicit states tracking the count of consecutive ones from 0 to 7+, but use a simpler state numbering scheme and include flags for discarding, flag detection, and error within the states themselves instead of separate output states.

The FSM has states S0 to S7 representing 0 to 7 consecutive ones counted. When a zero is seen, the FSM transitions back to S0 or to special output states to produce disc, flag, or err signals one cycle later.

To produce the one-cycle output pulses, outputs are asserted in the states that follow the detection of the condition (disc, flag, error). For example:
- After seeing 5 consecutive ones and a zero, output disc next cycle (disc_state).
- After 6 consecutive ones and a zero, output flag next cycle (flag_state).
- Upon seeing 7 or more ones consecutively, transition to error state (err_state) and assert err output.

This approach uses fewer special states (only 3: disc_state, flag_state, err_state) plus count states S0 to S6, for a total of 10 states, encoded with 4 bits. The main difference is states explicitly represent count or output conditions, minimizing the number of transitions and simplifying output logic.

Combinational next_state logic is implemented as a straightforward case on current state and input bit, but this time using a 2D approach that groups logic by current state with an if-else inside to improve readability.

Synchronous reset places the FSM in S0 state. Outputs disc, flag, err are combinational signals derived solely from the current state to produce synchronous one-cycle pulses after condition detection.

This design provides a clean, easy-to-understand FSM that still meets all functional requirements but uses a different state organization and next-state implementation style.
