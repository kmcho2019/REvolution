Fuse the clarity of explicit Moore FSM states with the simplicity and efficiency of a saturating 3-bit counter, enhancing state visibility while keeping the output logic combinational and outside the clocked block to reduce sequential logic load and improve timing.

Specifically:

- Use a 3-bit state register representing the count of consecutive ones (0 to 7), like a saturating counter.
- Compute next state combinationally outside the always block to minimize sequential logic complexity.
- Derive Moore outputs (`disc`, `flag`, `err`) combinationally from the current state and input, then register them synchronously for a one-cycle output delay, ensuring stable and glitch-free outputs.
- Use non-blocking assignments for all sequential logic.
- Synchronously reset state and outputs to zero (state=0 meaning no preceding 1s).
- This fusion provides clear state visibility, minimal and fast combinational logic, correct one-cycle delayed Moore outputs, and synchronous reset, resulting in improved timing and clean modular design.
