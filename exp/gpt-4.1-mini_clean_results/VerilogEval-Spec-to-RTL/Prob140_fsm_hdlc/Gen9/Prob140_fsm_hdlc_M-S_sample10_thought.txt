Simplify the FSM by keeping just the count of consecutive ones in a single register (3 bits for 0 to 7+). Instead of tracking previous input separately, store the count of consecutive 1s as state and derive outputs based on the current input and current state only.

On each clock edge:
- If input=0, reset count to 0.
- If input=1 and count <7, increment count (saturate at 7).

Outputs:
- disc = 1 when previous count was 5 and current input is 0 (i.e., count resets to 0 after input=0, but count was 5 before)
- flag = 1 when previous count was 6 and current input is 0
- err = 1 when count >= 7 (saturated at 7)

We can register the count and also store previous count to compare with current input to generate disc and flag.

Outputs are asserted for one cycle after the condition is detected (on the clock cycle after seeing the zero that follows 5 or 6 consecutive 1s).

This eliminates the need to track previous input explicitly as a separate register, making the design simpler and easy to understand.
