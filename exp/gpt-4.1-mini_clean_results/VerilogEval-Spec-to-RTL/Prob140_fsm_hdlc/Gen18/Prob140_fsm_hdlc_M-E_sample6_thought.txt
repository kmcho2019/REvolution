Implement the HDLC framing FSM using explicit named states representing the count of consecutive ones detected (from 0 up to 7+). Transition between states based on the input bit, and output disc, flag, and err signals as Moore outputs depending solely on the current state. The states encode the number of consecutive ones seen so far. On input zero, the FSM resets to the initial state representing zero ones. On input one, the FSM moves to the next state incrementing the consecutive ones count, saturating at the error state for 7 or more ones. This explicit FSM approach clearly models the framing conditions, with synchronous reset and one-cycle output pulses on condition detection.
