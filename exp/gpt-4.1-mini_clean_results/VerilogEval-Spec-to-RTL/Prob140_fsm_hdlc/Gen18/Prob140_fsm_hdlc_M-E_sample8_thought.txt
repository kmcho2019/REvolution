Implement a Moore FSM with explicit states tracking the number of consecutive 1s seen, from zero up to seven or more. Use an enumerated state variable to represent the count of consecutive 1s, transitioning on each clock cycle based on the input bit. Outputs (disc, flag, err) are determined solely by the current state, ensuring Moore-type output behavior. On reset, initialize to the state representing zero previous ones (as if previous input was 0). This approach is state-based rather than counter-based, allowing clear state transitions and direct encoding of conditions for discard (after five 1s followed by 0), flag (six 1s followed by 0), and error (seven or more consecutive 1s). The outputs are asserted for exactly one clock cycle after detecting the sequence, fulfilling the synchronous output and Moore FSM requirements.
