Implement a 7-state Moore FSM that explicitly tracks the number of consecutive ones seen, ranging from 0 to 6 or more (error). Each state represents the count of consecutive ones. The FSM transitions are defined as follows: on input '1', it moves to the next higher count state unless already in error; on input '0', it resets to state 0 but outputs disc or flag signals based on the previous count. This explicit state encoding allows straightforward detection of disc (after exactly five ones followed by zero), flag (exactly six ones followed by zero), and err (seven or more ones continuously). Outputs are asserted in the clock cycle after the triggering event, satisfying the Moore FSM condition. Synchronous reset returns FSM to state 0 (no consecutive ones). This approach trades a small increase in state encoding for more intuitive state transitions and simple combinational output logic.
