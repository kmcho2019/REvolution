Use a shift register approach to track the last 8 bits seen, so the FSM can detect the sequences by directly matching the pattern in the shift register. This differs from counting consecutive ones with states.

Implement a synchronous 8-bit shift register that shifts in the input bit each clock.

- disc: assert when the pattern "111110" (6 bits) just shifted in (i.e., exactly 5 consecutive ones followed by a zero), which corresponds to the bit sequence "0111110" ending at the current bit.

- flag: assert when the pattern "01111110" (8 bits) is matched in the shift register, which is the HDLC flag.

- err: assert when there are 7 or more consecutive ones, i.e., the shift register contains "1111111" starting at any position (detecting seven consecutive 1s).

To meet the "outputs asserted for a full cycle after detecting the condition" requirement, outputs are registered on the next clock cycle after combinational detection from the shift register contents.

Resetting puts the shift register to 0, effectively acting as if prior input was zero.

This architecture shifts the complexity from a count-based FSM to pattern matching on the shift register contents, making it easy to detect exact sequences by combinational logic and removing the state machine complexity.

Advantages:
- Simple, parallel pattern detection logic.
- Easy to extend or modify patterns.
- Cleanly separates pattern detection and output timing logic.
- Moore output style: outputs registered one cycle after detection.

This alternative solution uses a bit-shifting window to recognize patterns rather than counting consecutive ones with states.
