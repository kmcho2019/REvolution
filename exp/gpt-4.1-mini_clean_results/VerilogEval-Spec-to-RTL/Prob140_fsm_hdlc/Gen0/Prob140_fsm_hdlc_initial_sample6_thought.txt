Design a Moore FSM with states tracking the number of consecutive 1s seen after a zero. On reset, start in the "zero" state. For each input bit, update the state to reflect how many consecutive 1s have been seen. Detect when a zero follows exactly five 1s to assert 'disc'. When a zero follows six 1s, assert 'flag'. When the count exceeds six 1s (7 or more), assert 'err'. Outputs are asserted for one full clock cycle after the pattern is detected, consistent with Moore FSM behavior. States: S0 (zero last), S1..S6 (count consecutive ones 1..6), S7+ (error). On input=0, state goes to S0 if not error, else remain error. On input=1, increment state or go to error if above 6. Outputs depend on current state and input from previous cycle.
