Implement a Moore FSM with states representing how many consecutive 1s have been seen after a leading 0. Start in S0 (no consecutive 1s seen, last bit 0 assumed after reset). For each incoming bit, update the state and outputs according to the sequence rules:

- S0: expecting 0 or 1; if 1, move to S1 (one 1 seen).
- S1: if 1, go to S2; else back to S0.
- ...
- S5: (five consecutive 1s seen)
  - if next bit is 0: means "bit stuffed 0", output disc=1 next cycle, go to S0
  - if next bit is 1: sixth 1 in a row, so the bit pattern so far is 0111111
    wait to see next bit:
    - if next is 0: sequence is 01111110 flag, output flag=1 next cycle, go to S0
    - if next is 1: error (7+ 1s), output err=1 next cycle, stay in error state or S6+

Because it's Moore, outputs depend on current state only, so to output disc, flag or err for the *cycle after* the condition occurs, the FSM must be designed so these outputs are asserted in the state after the input that triggered the sequence.

To implement this cleanly, use extra states to handle the outputs:

- States S0 to S5 track count of consecutive 1s.
- State S5_0 indicates after seeing 5 ones and a zero (for disc output)
- State S6 indicates 6 consecutive ones detected, wait for next bit:
  - if next bit 0 => flag
  - if next bit 1 => error
- States SFlag, SDisc, SErr are output asserting states for one cycle.

This FSM tracks input bits, and asserts disc, flag, or err outputs for one clock cycle starting from the cycle after the detected sequence.

Reset puts FSM in S0, output zero.

Implement synchronous reset, positive edge clock.
