Design a Moore FSM with states representing the count of consecutive 1s seen so far (0 to 6). On each clock, input bit 'in' is checked:
- If 'in' is 0, reset state to 0 (as a zero breaks the chain).
- If 'in' is 1, increment the count of consecutive 1s, up to 6 or beyond.
Outputs depend only on the current state:
- disc is asserted when exactly 6 consecutive 1s have been seen and next input is 0 (detecting inserted zero after 5 ones),
- flag is asserted when the pattern 01111110 (6 ones followed by 0) is detected, meaning the previous state was 6 ones, input zero,
- err is asserted if 7 or more consecutive 1s occur.

However, the problem requires the outputs to be asserted for one full cycle starting on the clock after the condition is detected. This means outputs are based on the previous state's recognition of a pattern. We can achieve this by updating output signals in a separate register after the FSM updates state.

We'll design states as count of consecutive ones seen (0 to 6), and an "err" state if >=7 ones.

On receiving zero input, if the previous count was 5 ones (state 5) and now a 0, disc is asserted next cycle.

On receiving zero input, if the previous count was 6 ones (state 6) and now a 0, flag is asserted next cycle.

On receiving 1 input, if count was 6, the next is 7 or more ones, err asserted next cycle.

Since the outputs depend on previous state's pattern, outputs registers will be updated accordingly each cycle.

Implement synchronous active high reset to state 0.
