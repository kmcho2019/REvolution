Implement a Moore FSM with states counting consecutive 1s. On each clock cycle, update state based on input bit. Key points: 
- On reset, start in state with no previous ones (s0).
- Track count of consecutive ones up to 7+ for error.
- When reaching exactly 5 consecutive ones followed by a 0, assert 'disc' next cycle.
- When reaching exactly 6 consecutive ones followed by a 0, assert 'flag' next cycle.
- When reaching 7 or more consecutive ones, assert 'err' next cycle.
- Since outputs are Moore-type, outputs depend only on the current state.
- Outputs (disc, flag, err) are asserted for one cycle beginning after detecting corresponding pattern.
- Store outputs in registers updated synchronously with the state.
