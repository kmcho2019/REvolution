We design a Moore FSM that tracks how many consecutive 1s have been seen since the last zero. States represent counts of consecutive 1s from 0 to 6 and an error state for 7 or more. On reset, the state is 0 (no consecutive ones). For each input bit:
- If input is 0, state resets to 0 (since we saw a zero)
- If input is 1, increment the count of consecutive ones (up to error state if 7+)

We use states:
 S0: last bit was 0 or at reset (count=0)
 S1: 1 consecutive 1
 S2: 2 consecutive 1s
 ...
 S5: 5 consecutive 1s
 S6: 6 consecutive 1s (possible flag end)
 S7: error state (7 or more 1s)

Outputs depend on the state after the last input:

- To detect "0111110" (5 ones then 0), after seeing S5 state, if next input is 0, in next cycle disc=1.
- To detect "01111110" (6 ones then 0), after S6 state, if next input is 0, in next cycle flag=1.
- To detect error, if in S7 state, err=1.

We implement the FSM with synchronous state update on clk posedge. Outputs are registered and asserted for one full cycle after detection.

We track current state and next state. Outputs disc, flag, err depend only on current state.

States and transitions:
- On input=0: go to S0, outputs depend on previous state (the one before input).
- On input=1: advance state by one count, saturate at S7.

We encode states as 3-bit values from 0 to 7.

Outputs:
- disc=1 if previous input led to state S5 and current input=0 (means the zero after five 1s)
- flag=1 if previous input led to state S6 and current input=0 (zero after six 1s)
- err=1 if current state is S7 (error state)

Because outputs are based on previous input plus current input, we produce the outputs one cycle later as per Moore FSM definition. We therefore generate outputs based only on current state.

To manage outputs timing, we set outputs for one cycle when we enter states corresponding to detected conditions.

Implementation details:
- On reset, state=0.
- On each clock, update state.
- Outputs assigned combinationally from current state.

Because we must assert disc and flag only on the clock after detecting the pattern, we set outputs when the FSM is in the states corresponding to the patterns with the input that follows zero.

Specifically:
- disc = 1 when FSM was in S5 and input=0, so after transition to S0 from S5 with input=0, we assert disc one cycle later when FSM is in S0 but we remember the previous state was S5 and input=0.

To keep output timing clean, we can add extra output registers that store the output signals for one cycle when the condition is met.

To simplify, we store previous state and previous input and use them in output logic.

Thus:
- Register current state
- Register previous input
- On reset, previous input=0, state=0
- On each clock, update state and previous input
- Outputs computed as:

  disc = (prev_state == S5 && prev_input == 1 && curr_input == 0)
  flag = (prev_state == S6 && prev_input == 1 && curr_input == 0)
  err = (current_state == S7)

Since outputs are synchronous, we register them as well.

Final solution: FSM with states 0-7, tracking previous input to detect disc and flag, err asserted when in error state.
