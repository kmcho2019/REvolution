Implement a Moore FSM to count consecutive 1s seen on the input `in`. The FSM states represent the count of consecutive 1s since last 0, from 0 to 7+. On receiving a 0, the count resets to 0 (idle state). When in state with 5 consecutive 1s, seeing a 0 means the next bit should be discarded (`disc` asserted next cycle). When in state with 6 consecutive 1s, seeing a 0 means a `flag` condition (01111110) detected, so assert `flag` next cycle. If 7 or more consecutive 1s detected, assert `err`. All outputs are asserted for one clock cycle after the detected condition, per Moore FSM style (outputs depend on current state only). Synchronous reset sets FSM to state 0 (as if previous input was 0).
