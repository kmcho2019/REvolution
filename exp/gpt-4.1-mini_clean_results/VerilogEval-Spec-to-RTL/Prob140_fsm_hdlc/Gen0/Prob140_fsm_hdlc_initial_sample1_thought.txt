Implement a Moore FSM that counts consecutive ones in the input stream to detect the specific sequences:

- When a zero is received, reset the count of consecutive ones.
- States represent how many consecutive ones have been seen so far (0 to 6).
- If after five consecutive ones a zero arrives, it means a disc signal should be asserted next cycle.
- If after six consecutive ones a zero arrives, it means a flag signal should be asserted next cycle.
- If a seventh one or more is seen, assert err signal.
- Outputs disc, flag, and err are generated based on the current state and next input.
- On reset, state is zero ones counted, equivalent to previous bit zero.

The FSM transitions on each clock cycle based on input bit 'in'. Outputs are asserted for one cycle after detecting the condition.
