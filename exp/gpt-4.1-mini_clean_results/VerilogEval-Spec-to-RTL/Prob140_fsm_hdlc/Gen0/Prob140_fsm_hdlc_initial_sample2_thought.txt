Implement a Moore FSM that tracks the number of consecutive 1s seen in the input stream, starting from an implicit prior 0 on reset. The FSM states represent the count of consecutive 1s (0 to 6). On input 0, the FSM resets to state 0. On input 1, the FSM moves up states counting consecutive 1s. At state 5 (five consecutive 1s) and input 0, this means a stuffed zero bit that must be discarded (disc asserted next cycle). At state 6 (six consecutive 1s) and input 0, this signals a flag (01111110) detected (flag asserted next cycle). At state 6 and input 1, the count exceeds 6 consecutive ones, which signals an error (err asserted next cycle). Outputs are registered and asserted for one cycle after the event, consistent with Moore FSM behavior.
