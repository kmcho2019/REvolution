Design a Moore FSM that tracks the number of consecutive 1s seen after a preceding 0. On reset, the FSM is in a state indicating the previous input was 0 and no 1s counted. For each new bit, we move through states counting consecutive 1s. Outputs (disc, flag, err) depend solely on the current state, asserting them for one cycle after detecting their corresponding pattern. Specifically:

- States 0 to 5 represent counting 0 to 5 consecutive 1s.
- When at state 5 (five consecutive 1s) and input=0, assert disc next cycle (the stuffed zero to discard), transition to state 0.
- When at state 6 (six consecutive 1s) and input=0, assert flag next cycle (full flag pattern 01111110), transition to state 0.
- When at state 7 or more (7 or more consecutive 1s), assert err next cycle, stay in error state.
- On input=1, increment the count state until error is reached.
- On input=0, reset count to 0 if no special condition applies.

The outputs depend only on state (Moore), so outputs will be registered signals updated synchronously.
