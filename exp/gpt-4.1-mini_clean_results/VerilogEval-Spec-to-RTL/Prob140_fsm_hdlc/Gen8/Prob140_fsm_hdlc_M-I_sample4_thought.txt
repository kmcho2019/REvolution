Optimize the FSM by reducing the state encoding from 4-bit arbitrary codes to a 3-bit binary count of consecutive ones seen (0 to 6), with two additional special states for discarding and error. This more compact encoding reduces the state register size and logic complexity.

Rework the next state logic to use simple arithmetic increment and reset based on input and count of consecutive ones. The special states SD (discard) and SE (error) are signaled when the pattern is detected, and we return to counting from zero or one accordingly.

Outputs are generated by checking the current state: disc on SD, flag on state 6 with in=0, err on SE. This keeps outputs purely Moore type and synchronous.

This binary count FSM reduces combinational complexity, area, and power while maintaining the same cycle-latency outputs and synchronous reset behavior. It simplifies the state machine by directly counting ones, avoiding large case statements.
