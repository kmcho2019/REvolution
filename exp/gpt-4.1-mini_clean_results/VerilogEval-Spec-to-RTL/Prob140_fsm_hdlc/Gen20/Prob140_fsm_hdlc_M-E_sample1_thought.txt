Implement a Moore FSM with explicit states representing the count of consecutive ones, using one-hot encoding for simplicity and clarity. Each state corresponds to having seen 0, 1, 2, ..., up to 7 or more consecutive ones. Transitions depend on the input bit: if input is 1, move to the next higher count state; if 0, reset to zero count.

Outputs are asserted based solely on the current state, one cycle after the sequence is recognized. For example, the disc output is asserted when the FSM was in the state of 5 consecutive ones and the next input was 0 (the zero inserted after 5 ones), so the disc output is raised in the state corresponding to having just seen that zero bit after 5 ones. Similarly, flag is asserted in the state after seeing exactly 6 ones followed by a 0 input. Error is signaled when seven or more consecutive ones are observed.

This explicit state FSM clarifies the decoding process, aligns naturally with Moore FSM style, and eases formal verification and future extensions. The synchronous reset sets the FSM to the "zero ones" state. The FSM transitions and output assignments are all synchronous on clock edges, guaranteeing outputs are asserted for exactly one cycle after detecting the sequences.
