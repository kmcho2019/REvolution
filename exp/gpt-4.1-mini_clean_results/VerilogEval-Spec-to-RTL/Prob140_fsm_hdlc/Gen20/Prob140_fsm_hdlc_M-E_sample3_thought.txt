Implement a Moore FSM explicitly with states representing how many consecutive 1s have been seen, from zero up to seven or more. Each state transitions on input 'in' and sets outputs disc, flag, and err based on the current state only, asserting outputs for one clock cycle following the detection event. The FSM resets synchronously to the zero-ones state, treating the previous input as zero. This state-encoded approach provides clear visibility into each count and simplifies output logic by associating outputs directly to states, rather than counting in a register and decoding. The design fully meets synchronous reset and output timing requirements.
