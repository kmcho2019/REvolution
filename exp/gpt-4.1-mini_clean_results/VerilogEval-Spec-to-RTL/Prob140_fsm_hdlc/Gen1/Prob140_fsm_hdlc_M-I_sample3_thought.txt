To strictly implement a Moore FSM that detects the HDLC framing sequences with correct one-cycle delayed output assertion:

- Define states as counts of consecutive ones (0 to 7+).
- On reset, go to state 0 (previous bit zero).
- On input=0, reset state to zero ones.
- When detecting 5 ones followed by zero, assert disc for one full next cycle.
- When detecting 6 ones followed by zero, assert flag for one full next cycle.
- When detecting 7 or more consecutive ones, assert err for one full next cycle.
- Use Moore FSM outputs determined only by the current state.
- Because outputs are to be asserted *starting the clock cycle after* the pattern, define two extra "output states" after detecting these conditions:
  - For disc: after 5 ones + zero, transition to DISC state that asserts disc=1 for one cycle, then return to 0.
  - For flag: after 6 ones + zero, transition to FLAG state that asserts flag=1 for one cycle, then return to 0.
  - For err: upon detecting 7+ ones, transition to ERR state that asserts err=1 for one cycle, then stay or return based on input.
- This makes outputs purely Moore (based on state).
- Avoid output assignment dependent on input in synchronous block.
- State transition logic handles recognition and moves to output states accordingly.
- After output states, FSM returns to initial counting states based on input.
- This guarantees outputs asserted for exactly one cycle beginning on the cycle after detection.
