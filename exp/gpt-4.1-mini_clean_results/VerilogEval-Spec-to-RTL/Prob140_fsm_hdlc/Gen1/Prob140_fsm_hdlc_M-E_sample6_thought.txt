Implement a Moore FSM that counts consecutive ones up to 6 and an error state for 7+. The state will represent the count of consecutive ones seen so far. Outputs disc, flag, and err depend solely on the current state.

To meet the requirement that outputs assert one full cycle *after* the sequence detection, we design the FSM states to represent "count of ones *and* output condition pending." Specifically, after detecting the conditions (zero after 5 ones, zero after 6 ones, or 7+ ones), the FSM transitions into dedicated "output assertion" states where the corresponding output is asserted for one full clock cycle.

This way, outputs are Moore type (depend only on current state), and output signals are asserted for exactly one cycle after the condition is detected.

States:

- S0 to S6: counting consecutive ones 0..6.
- S5D: output disc = 1 for one cycle (zero after five 1s detected)
- S6F: output flag = 1 for one cycle (flag detected)
- S7E: error state, output err = 1 (7 or more ones)
  
State transitions:

- From S5: if input=0 → go to S5D (assert disc next cycle); if input=1 → S6
- From S6: if input=0 → S6F (assert flag next cycle); if input=1 → S7E (error)
- From S7E: if input=0 → S0; else stay S7E
- From S5D and S6F: output states; next state always S0 regardless of input (outputs asserted for one cycle)
- From other states: count ones or reset to zero on input zero

On reset: state = S0.

This approach cleanly separates output assertion states from counting states and ensures outputs are asserted one full cycle *after* detection, implementing a true Moore FSM with clean timing.
