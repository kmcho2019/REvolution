Refactor the FSM by splitting the count and FSM logic cleanly, using a registered counter for consecutive ones, and a simple 1-hot style state encoding with explicit flags for output assertions. Instead of a multi-state FSM, use a counter and combinational logic to detect disc, flag, and error conditions, and register outputs on the next clock cycle for correct timing.

Key points in refactor:
- Maintain a synchronous counter for consecutive ones (0 to 7 max).
- When input is zero, examine the count to decide if disc (count==5), flag (count==6), or no output.
- If count >=7 at any time, assert error starting on the next clock cycle and hold it until input zero.
- Outputs are generated as registered signals that become high exactly one cycle after the triggering sequence.
- Outputs are mutually exclusive.
- Use synchronous reset to initialize all registers.
- This approach decouples detection from output signaling, improves clarity, and guarantees Moore outputs asserted one cycle after detection, satisfying timing requirements.
