Design a Moore FSM with explicit states representing counts of consecutive ones from 0 to 7+. The FSM transitions on each input bit, incrementing the count on '1' (up to a saturated "error" state for 7+ ones) or resetting on '0'. 

Outputs (disc, flag, err) are tied solely to the current state, making the FSM Moore-type, so outputs are stable throughout the state and effectively appear one cycle *after* detecting the relevant input pattern.

Specifically:

- States S0 to S6 represent counts of 0 to 6 consecutive ones.
- State S5 means we've seen exactly 5 consecutive ones; on next input:
  - If input=0: disc = 1 (one cycle), then go to S0.
  - If input=1: advance to S6.
- State S6 means exactly 6 consecutive ones; on next input:
  - If input=0: flag = 1 (one cycle), then go to S0.
  - If input=1: error condition arises, move to S7.
- State S7 is error state (7 or more consecutive ones), err=1 asserted indefinitely until reset or input=0.
- On input=0 from any count state, FSM returns to S0.
- On reset, FSM initializes to S0 (pretending previous bit was zero).

Outputs are asserted by state encoding itself (disc = 1 only in S0 if previous input sequence matched disc condition, etc.) which yields outputs automatically delayed by one cycle from input transitions, satisfying the spec.

This FSM cleanly separates state logic and outputs, avoids combinational output logic on input, and inherently aligns outputs one cycle after detecting patterns, meeting the Moore FSM and timing requirements.

The code uses an enum for states for clarity and a synchronous state register updated on clk with reset. Outputs are simple combinational functions of the current state.
