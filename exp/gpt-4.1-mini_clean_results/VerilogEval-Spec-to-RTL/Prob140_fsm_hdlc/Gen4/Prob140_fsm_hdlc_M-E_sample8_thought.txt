Instead of encoding each count of consecutive 1s as distinct states, this design uses a binary counter that increments when consecutive 1s are detected and resets to zero on a zero input. We track the count of consecutive 1s in a 3-bit register (0 to 7+). The FSM is Moore-type; outputs depend only on the current count and the incoming bit sequence.

To detect the required conditions (disc, flag, err), we need to identify transitions from counts with 5 or 6 ones followed by a zero input, which correspond to the special sequences:

- disc: detecting a zero immediately after exactly 5 ones (count = 5 followed by 0)
- flag: zero immediately after 6 ones (count = 6 followed by 0)
- err: count >= 7 (7 or more ones in a row)

We implement this by storing the current count of consecutive ones and, on every clock edge, checking the incoming bit:

- If input bit is 1: increment count (max 7)
- If input bit is 0: check count:
    - if count==5 -> disc=1 on next cycle
    - if count==6 -> flag=1 on next cycle
    - reset count to 0

For the outputs to be synchronous and one cycle delayed, we register output signals based on previous count and input conditions.

The error condition (count==7) can be signaled immediately in the same cycle as count updates.

This approach simplifies state handling by using a counter instead of multiple explicit states, and the logic is clean and efficient.

The outputs disc, flag, err are registered signals asserted for one full cycle after the corresponding event is detected.

The reset sets count to zero and outputs to zero.

This design meets synchronous, Moore-type FSM behavior, and meets all specification constraints.
