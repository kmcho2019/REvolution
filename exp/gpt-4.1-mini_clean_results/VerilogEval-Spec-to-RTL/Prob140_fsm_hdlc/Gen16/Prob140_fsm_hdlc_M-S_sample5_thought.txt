Simplify the FSM by using a single state variable that counts the number of consecutive ones (0 to 7+). Use a 4-bit counter-like state: S0 to S7 (with S7 representing 7 or more ones/error). Outputs are derived combinationally from the current state and input, thus avoiding separate output states.

The FSM counts consecutive ones until hitting 5 or 6, where the appropriate disc or flag conditions are recognized when a zero follows. The error state corresponds to 7 or more ones in a row.

Implement outputs as Moore outputs depending only on state, with an additional combinational signal derived from the previous state and current input to detect disc and flag conditions at the correct timing (one cycle after the pattern). The one-cycle pulse outputs are ensured by the delayed detection via states and transitions.

This approach uses fewer states (8 states only) with simpler next state logic based on counting consecutive ones, reduces the state encoding width and logic, and maintains correct behavior and output timing.

Reset initializes to S0 (no previous ones), synchronous active-high.

Outputs:
- disc is high one cycle after seeing 5 consecutive ones followed by a zero,
- flag is high one cycle after seeing 6 consecutive ones followed by zero,
- err is asserted whenever 7 or more consecutive ones detected.

This greatly reduces FSM complexity while preserving functionality and output timing.
