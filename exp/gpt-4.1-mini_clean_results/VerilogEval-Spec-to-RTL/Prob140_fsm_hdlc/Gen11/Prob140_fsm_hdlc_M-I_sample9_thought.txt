The existing design uses a saturating 3-bit counter and always updates the outputs every cycle, which causes unnecessary toggling and power consumption.

To improve Power and Performance:

- Implement a Moore FSM with explicitly named states representing the count of consecutive 1s (0 through 6+).
- Only update the output flags (disc, flag, err) when the corresponding conditions occur (on state transitions) rather than every cycle, reducing switching activity.
- Use a registered "state" and "next_state" to minimize combinational logic depth.
- Add an enable condition so the state only advances on input changes relevant to counting consecutive ones.
- Outputs remain asserted for exactly one cycle after the event is detected (as required).
- This explicit FSM encoding can reduce glitches, improve timing, and limit output toggling.

This approach yields a clear, low-glitch Moore FSM, only updating outputs on specific states, and reduces toggling by keeping outputs low otherwise, improving overall PPA.
