Implement a Moore FSM with explicit states representing the number of consecutive 1s seen so far (from 0 to 7 or error). Each clock cycle, based on the input bit, the FSM transitions to the appropriate next state. The FSM outputs (disc, flag, err) depend solely on the current state, ensuring Moore-type behavior.

- States 0 to 5 count consecutive 1s.
- State 6 corresponds to having seen 6 consecutive ones.
- State 7 is an error state for 7 or more consecutive ones.
- After seeing a zero following 5 ones (state 5 + zero input), disc is asserted.
- After seeing a zero following 6 ones (state 6 + zero input), flag is asserted.
- If a 7th one is detected (from state 6 + input=1), err is asserted.

This approach models the problem as an FSM with 8 states and cleanly separates state transition and output logic, which is good for synthesis and debugging. Outputs are registered and asserted for one full cycle after detection, as required.

Reset places the FSM in state 0 (as if last input was zero).
