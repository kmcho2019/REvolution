I will implement the HDLC framing FSM as a one-hot encoded Moore state machine with explicit states representing the count of consecutive ones from 0 to 6, plus an error state for 7 or more ones. Each state corresponds to the number of consecutive '1's seen.

The transitions:
- On input=0, move to state S0 (zero consecutive ones).
- On input=1, move from state Si to Si+1 if i<6.
- From state S6, input=1 goes to error state.
- From error state, input=1 stays in error; input=0 resets to S0.

Outputs:
- disc is asserted when transitioning from state S5 on input=0 (i.e., a zero after five ones).
- flag is asserted when transitioning from state S6 on input=0 (a zero after six ones).
- err is asserted in the error state.

Outputs are registered and asserted for one clock cycle starting the cycle after the condition occurs, consistent with a Moore FSM.

One-hot encoding with individual state bits allows simpler next-state logic (only one bit set) and straightforward output decoding, at the cost of more flip-flops but potentially faster transitions and clearer logic.

Synchronous active-high reset initializes to state S0 (zero previous ones).
