Refine the Moore FSM by explicitly enumerating states for counts 0 to 7 consecutive ones, where state 7 represents error (7 or more ones). This eliminates saturation and simplifies error detection.

To meet the output timing requirement (outputs asserted exactly one cycle after detection), add dedicated "output" states that are entered immediately after detecting the required sequences (5 ones + 0, 6 ones + 0), and transition back to count 0 on the next clock. This cleanly separates detection from output signaling.

Outputs depend only on current state (Moore), no input-dependent latches needed.

State machine outline:
- States 0 to 6: count of consecutive ones so far.
- If input is 0 in state 5, transition to DISC state, assert disc=1.
- If input is 0 in state 6, transition to FLAG state, assert flag=1.
- If input is 1 in state 6, transition to ERR state, assert err=1.
- DISC, FLAG, ERR states are single-cycle output assertion states, then transition to state 0.
- Input 0 always resets count to 0 states.

This explicit state encoding and output states ensure correct one-cycle delayed outputs as required, fully Moore outputs dependent only on current state, and synchronous reset to state 0.

This approach simplifies output logic, avoids output latches, and cleanly separates detection and output assertion timing.
