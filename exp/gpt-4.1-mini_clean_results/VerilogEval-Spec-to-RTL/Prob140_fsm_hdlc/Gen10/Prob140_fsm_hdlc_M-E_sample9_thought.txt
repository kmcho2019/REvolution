Implement a sequential FSM that tracks the count of consecutive 1s (0 to 7+) using a 3-bit counter and a small status logic. The FSM will be Moore type, with outputs generated solely from the current state (count).

Use one-hot style output signal assertions based on the count and incoming bits:

- When exactly six consecutive 1s followed by a 0 appear, output 'flag' on the next cycle.
- When exactly five consecutive 1s followed by a 0 appear, output 'disc' on the next cycle (the zero after the five 1s, which must be discarded).
- When count reaches 7 or more, output 'err' continuously while consecutive 1s continue.

On reset, start in count=0 (previous bit assumed 0).

The FSM logic increments count on '1' input; resets count to 0 on '0', except if the count equals 5 or 6 and input is 0, then output accordingly.

Outputs are registered to assert for one full clock cycle after detection.

This architecture simplifies FSM into a counter plus condition outputs, avoiding complex state names. It uses a 3-bit count and a separate output register for disc, flag, and err signals to ensure proper timing.

This approach prioritizes simplicity and clarity, as well as easy extensibility.
