Implement a Moore FSM with one-hot encoding to reduce combinational decoding complexity and improve timing. 

Use 8 states representing the count of consecutive ones from 0 up to 7 or more (error state). Each state is a separate flip-flop to simplify next-state decoding.

Track the current run length of consecutive ones with one-hot states: S0 means zero ones counted, S1 means one consecutive one, ..., S6 means six consecutive ones, and S7 means error (7+ consecutive ones).

On input '0', the FSM transitions to S0 from any state except error which stays or resets to S0 on zero.

On input '1', the FSM moves to the next higher one-hot state (S0→S1, S1→S2, ..., S6→S7). From error state, remain in error on '1'.

Outputs:

- disc: assert when the input zero follows state S5 (5 consecutive ones), indicating a stuffed zero to discard.

- flag: assert when the input zero follows state S6 (6 consecutive ones), indicating a valid flag boundary.

- err: assert when the FSM enters the error state S7.

Since this is Moore, outputs depend only on the current state and current input.

To have outputs asserted for one cycle after detection, we register outputs. Use synchronous reset to initialize to S0 and deassert outputs.

This one-hot FSM reduces logic depth because next state logic is a simple shift register like transition; output logic is simplified to a few one-hot state checks.

The implementation uses a shift register style FSM and output logic based on the current state and input.

This approach improves timing by reducing state decoding complexity and simplifies error detection by directly encoding error in S7 state.
