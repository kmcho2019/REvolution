This often simplifies combinational logic for next states and outputs. Use separate combinational logic blocks with assign statements for next state and outputs. The one-hot FSM will still count consecutive ones from S0 to S7. Synchronous reset initializes the state and outputs to zero. This approach clarifies the state transitions and can potentially reduce critical path delay by making next-state logic simpler (one-hot next states) and using continuous assignments instead of a case statement. It keeps all FSM logic explicit and nicely separated.
