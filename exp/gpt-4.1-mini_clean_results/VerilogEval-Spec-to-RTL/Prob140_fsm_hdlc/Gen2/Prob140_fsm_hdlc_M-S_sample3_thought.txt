Implement a simpler FSM that tracks the count of consecutive ones seen so far after the last zero, from 0 up to 6, plus an error state for 7 or more. On each clock cycle, the state updates synchronously with the input bit:  
- If input=1, increment count (capped at error state 7).  
- If input=0, reset count to 0.  

Outputs are Moore style and asserted one cycle after the condition:  
- disc is asserted for one cycle when transitioning from 5 consecutive ones to zero (detect zero-stuffed bit).  
- flag is asserted for one cycle when transitioning from 6 consecutive ones to zero (detect flag 01111110).  
- err is asserted continuously when in error state (7 or more consecutive ones).  

Track previous state to detect these transitions. This approach avoids complicated state enums and aligns output timing naturally.
