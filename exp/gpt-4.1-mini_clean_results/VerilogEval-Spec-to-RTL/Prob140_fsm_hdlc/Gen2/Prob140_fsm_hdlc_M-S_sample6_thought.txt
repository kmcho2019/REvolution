Implement the same Moore FSM using simple `reg [3:0]` state encoding without SystemVerilog enums. Define localparams for states to improve readability. Use a state register and next_state combinational logic. On synchronous reset, go to S0.

In the sequential block, update state and outputs. Outputs are asserted based on the current state to ensure they are active for a full cycle *after* the detection event.

The FSM counts consecutive ones up to 6, has separate states to assert outputs disc (discard), flag, and err (error), each held for one full clock cycle. From error state, it stays unless a zero resets the count.

This simpler Verilog-2001-compatible code preserves all functionality and timing without SystemVerilog features.
