Use a Moore FSM that tracks the count of consecutive ones from 0 to 6. On each clock cycle:

- If input is 0, reset count to 0.
- If input is 1 and count < 6, increment count.
- If input is 1 and count = 6, saturate at 6.

Outputs are based solely on state (Moore):

- disc is asserted for one cycle immediately after the FSM leaves state 5 due to a zero input.
- flag is asserted for one cycle immediately after the FSM leaves state 6 due to a zero input.
- err is asserted immediately when input=1 in state 6 (7 or more ones).

To implement outputs one cycle *after* detection, use a single register per output to latch disc and flag signals whenever a zero input is received in state 5 or 6, respectively. Then these outputs are asserted for exactly one cycle. err is combinationally asserted in state 6 with input=1.

This yields minimal complexity, fully Moore outputs, clean timing, and meets all specification.
