I will implement the Moore FSM explicitly with states representing the count of consecutive 1s (0 to 7+). Outputs `disc`, `flag`, and `err` depend only on the current state to comply with Moore FSM style.

Key ideas:
- Use states S0 to S7+ representing 0 to 7+ consecutive 1s.
- Detect the patterns on state transitions and set outputs accordingly in the *next* clock cycle (Moore output).
- When a zero is received after 5 consecutive ones (state S5 + input 0), output `disc`=1 in the next cycle.
- When a zero is received after 6 consecutive ones (state S6 + input 0), output `flag`=1 in the next cycle.
- When reaching or remaining in error state (7 or more ones), assert `err`=1.
- Outputs are de-asserted otherwise.
- On synchronous reset, the FSM returns to S0 assuming previous input was zero.
- Store the next state and outputs in registers; outputs update synchronously with state.
This architecture cleanly separates state transition and output logic as per Moore FSM style, ensuring outputs assert exactly one cycle after detecting the conditions.
