Implement a classical Moore finite state machine that tracks the number of consecutive ones received. The FSM will have states representing counts of consecutive ones from 0 up to 6 or more (with a special error state). The transitions depend on the current input bit:

- On input '0', the FSM resets the count to zero.
- On input '1', the FSM moves to the next count state.

The outputs disc, flag, and err depend only on the current state, not inputs (Moore output):

- disc is asserted when the previous state was count=5 and input=0 (i.e., just after seeing 5 consecutive ones and a zero, meaning the zero inserted after five ones is to be discarded).
- flag is asserted when the FSM just recognized the flag sequence (01111110), i.e. a zero after six consecutive ones. This means the FSM reached count=6 and now got zero input.
- err is asserted when there are 7 or more consecutive ones (i.e., state count >= 7). We will have an error state for 7 or more ones.

Since outputs must be asserted one full cycle *after* detecting the sequences, outputs are generated from the current state alone.

We encode the states as follows:

- S0: 0 consecutive ones
- S1..S5: 1 to 5 consecutive ones
- S6: 6 consecutive ones
- ERR: error state for 7 or more consecutive ones

Transitions:

- From S0..S5:
  - input=0: go to S0
  - input=1: go to next S state (S1..S6)
- From S6:
  - input=0: go to S0
  - input=1: go to ERR
- From ERR:
  - input=0: go to S0
  - input=1: stay in ERR

Outputs (asserted in state):

- disc: asserted in S5 (because input=0 from S5 means zero inserted after 5 ones)
- flag: asserted in S6 (input=0 after 6 ones, the zero that ends a flag)
- err: asserted in ERR

Because outputs reflect previous cycle inputs, this satisfies the output delay requirement.

Initialize the FSM at reset to S0 (count zero).

This clean, classic FSM approach correctly tracks the sequences and produces the required outputs in a synchronized and Moore-type fashion.
