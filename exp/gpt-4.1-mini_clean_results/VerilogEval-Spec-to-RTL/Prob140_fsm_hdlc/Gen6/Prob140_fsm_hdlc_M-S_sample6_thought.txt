Use a single counter to track consecutive ones (0 to 7+). On input=0, reset count to 0. Detect disc when count is 5 and input=0, flag when count is 6 and input=0, and error if count reaches 7 or more. Implement Moore FSM behavior by registering the counter and outputs; outputs are asserted one cycle after detection by assigning outputs from the previous cycle's state and input conditions.

This avoids an explicit multi-state FSM, using just a simple counter and combinational checks for outputs. It simplifies state encoding, next-state logic, and output logic, while preserving synchronous reset and output timing. This approach retains the correct timing and functional behavior with much simpler logic.
