To improve the PPA (timing, power, and area) of the FSM, we focus on the following:

1. State Encoding:
   Use one-hot encoding for the FSM states instead of binary encoding.
   - One-hot encoding often leads to simpler next state logic (each state is a flip-flop).
   - It can reduce combinational logic depth, improving timing (better slack).
   - Potentially increases area (more flip-flops), but the states are only 8, so area overhead is minimal.
   
2. Output Logic Simplification:
   In one-hot encoding, checking a state is just checking a flip-flop bit, which is simpler and faster.
   Outputs depend on previous state and inputs; to keep Moore FSM semantics and synchronous outputs, we will:
   - Store current state (one-hot)
   - Store previous input and previous state (one-hot)
   - Compute disc and flag based on previous state and inputs.
   - err asserted when in error state (S7).
   
3. Minimize glitches:
   Use registered signals only, avoid combinational outputs tied to inputs to reduce glitches and power.

4. Reset Logic:
   Use synchronous active high reset, as required.

This approach improves timing slack and efficiency due to simpler combinational logic, slightly more flip-flops, but the overall power and timing tradeoffs are beneficial. Area might increase slightly but is acceptable for the gain in timing and power reduction.
