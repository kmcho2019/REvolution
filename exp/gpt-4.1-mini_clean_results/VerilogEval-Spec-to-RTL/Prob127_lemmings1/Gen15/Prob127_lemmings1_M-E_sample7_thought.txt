Implement the Lemmings FSM as a Moore machine using a 2-bit encoded state to explicitly represent walking left and walking right states for clarity and extensibility. Use a synchronous reset (areset asserted synchronously at the clock edge) instead of asynchronous to improve timing and simplify reset distribution.

The FSM state will be explicitly encoded as:
- 2'b00: walk_left
- 2'b01: walk_right

Upon bump_left or bump_right, state transitions are as follows:
- If bump_left is asserted, next state is walk_right (2'b01)
- If bump_right is asserted, next state is walk_left (2'b00)
- If both bumps asserted, toggle state (if walk_left -> walk_right; if walk_right -> walk_left)
- If no bumps, hold current state.

The priority for state transition will be:
1. If both bumps: toggle
2. Else if bump_left: walk_right
3. Else if bump_right: walk_left
4. Else hold state.

Outputs walk_left and walk_right are derived directly from the current state bits.

This design uses explicit state encoding and synchronous reset for improved timing stability and clearer FSM structure. This approach also easily scales to more complex states if needed.
