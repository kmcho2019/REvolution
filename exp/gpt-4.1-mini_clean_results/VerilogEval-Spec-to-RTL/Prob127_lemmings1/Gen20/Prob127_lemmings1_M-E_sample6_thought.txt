Implement the Lemmings FSM using a one-hot state encoding with two flip-flops representing walk_left and walk_right states. The asynchronous positive edge reset initializes the state to walk_left. On each clock edge, if bump_left or bump_right is detected, the machine transitions to the opposite walking state. This direct representation avoids state encoding bits and simplifies output logic as the state flip-flops themselves serve as outputs. The next state logic uses simple combinational logic detecting bumps and controlling state flip-flops accordingly, resulting in clear, structurally distinct FSM implementation with explicit one-hot encoding and clean asynchronous reset behavior.
