Implement the Lemmings FSM using a one-hot encoding approach with two flip-flops representing each direction state explicitly: one flip-flop asserts walk_left and the other asserts walk_right. On a reset, walk_left is set active. The FSM transitions are triggered by bump signals on clock edges, and asynchronous reset is respected. The next state logic is split into two independent next state signals, each computed combinationally based on the current state and bump inputs. This architecture clearly separates state bits, making output assignment trivial and improving readability. The transitions directly set the active walk direction flip-flop based on bumps, with simultaneous bumps toggling the active direction, and no simultaneous assertion of both outputs.
