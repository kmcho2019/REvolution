Implement the FSM with two explicit states represented by a localparam enumeration to improve clarity. Instead of toggling the state when bumped, explicitly assign the state based on which bump signal is asserted: if bump_left is 1, transition to walk_right; if bump_right is 1, transition to walk_left. This approach avoids potential glitches from simultaneous bumps by letting bump_left take priority if both are asserted at once (or vice versa based on design). The asynchronous positive edge reset sets the FSM to walk_left as required. Outputs are Moore outputs derived directly from the current state. This state assignment approach ensures immediate direction changes on bump assertion without edge detection or toggling.
