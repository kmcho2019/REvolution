Implement the FSM with an enumerated two-state type for clarity: LEFT and RIGHT. On asynchronous reset, the state is initialized to LEFT (walk_left=1). On each rising clock edge, if either bump_left or bump_right is high, the FSM transitions to the opposite state. Otherwise, it remains in the current state. Outputs are assigned combinationally from the current state in a Moore fashion. This clear state enumeration improves readability and correctness without edge detection or previous signal storage.
