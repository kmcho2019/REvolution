Implement a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. On reset, the state is WALK_LEFT. On each clock edge, if bump_left or bump_right is asserted (or both), switch direction accordingly: if bumped on left, go to WALK_RIGHT; if bumped on right, go to WALK_LEFT. If both bumps asserted, the machine will switch direction anyway (from current state). Outputs walk_left and walk_right are derived from current state (Moore outputs).
