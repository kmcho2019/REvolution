Implement a Moore finite state machine with two states: WALK_LEFT and WALK_RIGHT.
- On areset (asynchronous positive edge), state resets to WALK_LEFT.
- On each clock rising edge, if bump_left or bump_right is high, state toggles.
- If bumped on left or right or both, switch direction.
- Outputs are derived from the state: walk_left=1 if in WALK_LEFT, walk_right=1 if in WALK_RIGHT.
