Implement a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. On areset (async posedge), reset to WALK_LEFT. On each posedge clk, if bumped on left or right, change direction accordingly:
- If bumped on left (bump_left==1), go to WALK_RIGHT
- If bumped on right (bump_right==1), go to WALK_LEFT
- If bumped on both sides, still switch directions.
Outputs walk_left and walk_right indicate the current state.
