Implement a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. The output walk_left is 1 when in WALK_LEFT state, walk_right is 1 when in WALK_RIGHT state. On each positive clock edge, if areset is asserted asynchronously (positive edge triggered), the state is reset to WALK_LEFT. If bump_left or bump_right (or both) are asserted, the FSM changes its state to the opposite direction. Otherwise, it holds the current state.
