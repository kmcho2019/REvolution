Implement the Lemmings FSM using one-hot state encoding with two flip-flops, each representing one state (walk_left and walk_right). This approach eliminates state decoding logic since outputs are directly driven by the state flip-flops. The next state logic uses simple combinational logic with boolean equations derived from bump inputs and current active state. Asynchronous positive-edge reset initializes the walk_left flip-flop, ensuring immediate reset behavior. This method simplifies output generation and next state combinational logic, potentially reducing gate count for output drivers and improving readability by tying outputs directly to the one-hot states. It also fits well in FPGA architectures with flip-flops and can facilitate easier debugging by making states explicit in registers.
