Represent the state as a 1-bit register indicating direction (0 for walk_left, 1 for walk_right). Update the state on the positive edge of clk or asynchronously reset to 0 (walk_left). To simplify the next state logic, set the next state to be the XOR of the current state with the OR of bump_left and bump_right, so any bump causes direction inversion, which covers all cases including both sides bumped.
