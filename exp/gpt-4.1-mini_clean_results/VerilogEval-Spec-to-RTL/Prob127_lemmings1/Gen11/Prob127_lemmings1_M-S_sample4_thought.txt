Use a single always block triggered on the positive edge of clk and asynchronous positive edge of areset to update the state. Instead of separate next_state combinational logic, incorporate next state logic directly in the sequential block, simplifying the design further. Since outputs are Moore and directly depend on the current state, assign them as simple continuous assignments from the state. This merges state update and next state logic in one block, reducing code complexity while maintaining the same behavior and asynchronous reset.
