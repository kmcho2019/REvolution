Implement the Lemmings FSM using one-hot encoding with two flip-flops representing the states walk_left and walk_right. The asynchronous reset sets the machine to the walk_left state by setting the walk_left flip-flop and clearing walk_right. The next state logic uses combinational gates that, on any bump (left, right, or both), flips the walking direction by deasserting the current state and asserting the other. The outputs directly mirror the state flip-flops, preserving the Moore FSM principle. This approach demonstrates an alternative FSM encoding and logic style.
