Implement the Lemmings FSM as a Moore machine using a two-bit state vector representing direction explicitly, and compute the next state combinationally with an always_comb block. Instead of updating state inside the sequential block based on complex conditions, compute next_state first using combinational logic: if any bump input is asserted, next_state becomes the opposite direction; otherwise, next_state remains current state. This approach cleanly separates combinational and sequential logic, improving clarity and making it easy to add features later. Also, the asynchronous reset is handled by the sequential block. Outputs are simply derived from the current state. This design will enhance readability and maintainability.
