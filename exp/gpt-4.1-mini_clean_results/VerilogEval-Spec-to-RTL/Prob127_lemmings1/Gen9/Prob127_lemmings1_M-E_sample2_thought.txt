Model the FSM with two explicit states defined as parameters: WALK_LEFT and WALK_RIGHT. Use a register to hold the current state, asynchronously reset to WALK_LEFT. On each clock edge, check bump inputs: if any bump input is asserted (bump_left or bump_right), toggle the walking direction; if no bump, remain in the same state. Outputs are one-hot encoded from the state. This approach treats any bump as a toggle regardless of which side, simplifying state transition logic differently from the example.
