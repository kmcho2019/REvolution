Implement the FSM with an explicit two-state encoding using a localparam for clarity, and separate the next state combinational logic and state register update. The Moore FSM will have one bit of state: 0 for walking left and 1 for walking right. The next state logic simply toggles the state if either bump_left or bump_right is asserted. The asynchronous reset sets the state to walk_left. Outputs are assigned in a separate combinational always block based on current state to emphasize Moore output behavior.
