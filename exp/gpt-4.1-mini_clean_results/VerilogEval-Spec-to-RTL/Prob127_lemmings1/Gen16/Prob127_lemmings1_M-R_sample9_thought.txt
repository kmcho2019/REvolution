Refactor the FSM by encoding the state as a register and directly calculating next_state using a simple conditional (if-else) statement in a combinational always block instead of a single boolean expression. This explicitly distinguishes all input conditions, making the logic clearer and potentially easier for synthesis tools to optimize. Also, output assignments remain combinational continuous assignments based on the current state. The asynchronous positive edge reset and synchronous state update on posedge clk are kept. This approach provides the same functionality with clearer control flow.
