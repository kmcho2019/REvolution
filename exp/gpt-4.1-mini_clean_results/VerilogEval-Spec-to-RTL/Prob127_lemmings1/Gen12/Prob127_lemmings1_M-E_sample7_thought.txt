Implement the Lemmings FSM using one-hot encoding of the two states with two state bits, walk_left and walk_right, as flip-flops. On reset, walk_left is set to 1 and walk_right to 0. On each clock edge, the next state is determined by bump signals: if bump_left is detected, walk_right is asserted and walk_left cleared; if bump_right is detected, walk_left is asserted and walk_right cleared; if both bumps occur, the states flip. This approach avoids explicit next-state variables by combining state and output in registers directly, resulting in a minimalist, hardware-friendly one-hot FSM style.
