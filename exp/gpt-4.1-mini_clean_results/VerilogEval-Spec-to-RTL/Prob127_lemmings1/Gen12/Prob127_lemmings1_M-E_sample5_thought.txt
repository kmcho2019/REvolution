Implement the Lemmings FSM with an explicit two-state enumeration (LEFT=0, RIGHT=1) and store the state in a register. On each clock edge (with asynchronous reset active high), decide the next state as follows: If either bump_left or bump_right is high, invert the state (switch directions); otherwise, hold the current state. This simplifies the logic to toggling the direction whenever there is any bump, regardless of side. Since bump_left and bump_right can be both high, toggling covers the behavior that bumps on both sides invert direction. The outputs are driven by decoding the state as a Moore FSM.
