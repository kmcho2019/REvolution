Model the direction state as a 1-bit register where '0' indicates walking left and '1' walking right. On each clock edge with asynchronous reset, the Lemming changes direction based on bumps: if bumped on left only, set direction to right; if bumped on right only, set direction to left; if bumped on both sides, force walking left (0) as a tie-break rule instead of toggling. This differs from the original toggle-on-both approach. This creates a Moore FSM with clear next state logic using simple if-else conditions for better readability and an alternate design behavior on simultaneous bumps.
