Implement the Lemmings FSM as a one-hot encoded two-bit state register instead of a single bit. This means having two flip-flops, one representing walking left and one walking right, with mutually exclusive active states (one hot). The asynchronous positive edge reset sets the machine to walk_left state by activating only the corresponding flip-flop. Next state logic is a combinational block that determines which of the two states should be active based on bump inputs and current state.

When bumped on left, switch to walk_right; when bumped on right, switch to walk_left; when bumped on both, switch to the opposite state. Otherwise, remain in current state. Outputs directly derive from the one-hot state bits. This architectural approach clarifies state encoding and could allow easier future extension to multi-state FSMs. It still uses Moore outputs and the same asynchronous reset behavior.
