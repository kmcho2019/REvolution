Implement the Lemmings FSM using a single-bit state register representing walking direction, but derive the next state directly from current state and bump inputs without a case statement. Use combinational logic with bitwise operators: if the current state is WALK_LEFT (0), switch to WALK_RIGHT (1) if bump_left is asserted; if current state is WALK_RIGHT (1), switch to WALK_LEFT (0) if bump_right is asserted. Use a synchronous reset (active high) to initialize to WALK_LEFT on reset asserted asynchronously. Outputs are assigned directly from the state using continuous assignments to simplify logic and reduce sequential output logic. This approach reduces code complexity and explicitly models the state transitions via boolean expressions, making it easier for synthesis tools to optimize.
