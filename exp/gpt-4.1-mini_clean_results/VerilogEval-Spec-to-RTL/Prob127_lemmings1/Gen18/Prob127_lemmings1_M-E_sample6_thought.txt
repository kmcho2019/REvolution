Implement the Lemmings FSM by encoding the two states as a single bit and using an intermediate bump signal that combines bump_left and bump_right inputs. The main idea is to use a simple XOR-based next state logic: if the Lemming is bumped on either side (or both), the state flips; otherwise, it remains the same. This logic corresponds to next_state = state ^ bump_occurred, where bump_occurred = bump_left | bump_right. The FSM uses a positive-edge asynchronous reset to initialize the state to walking left. The Moore outputs directly decode the current state. This approach minimizes combinational logic and uses simple boolean operations, improving clarity and potentially reducing area and power consumption.
