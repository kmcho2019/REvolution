Represent the walking direction with a single bit state: 0 for walking left and 1 for walking right. On reset, set state to 0. On each clock edge, if bumped on the left, set state to right (1); else if bumped on the right, set state to left (0); else keep current state. If both bumps are high, prioritize bump_left and set state to right, which effectively switches direction as required. This removes toggle logic and directly sets state based on bumps, simplifying the FSM.
