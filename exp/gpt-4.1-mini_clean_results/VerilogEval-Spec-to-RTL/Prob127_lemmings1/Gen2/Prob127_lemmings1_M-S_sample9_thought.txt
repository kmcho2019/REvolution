Use a single-bit state register with 0 representing walking left and 1 walking right. On async reset, set state to 0 (walk_left). On clock edge, if bump_left=1 and bump_right=0, set state to 1 (walk_right). If bump_right=1 and bump_left=0, set state to 0 (walk_left). If both bumps are 1, toggle state. Otherwise, keep the state unchanged. Outputs are derived directly from the state.
