I will implement the FSM using a one-hot encoding with two separate flip-flops representing the two states: WALK_LEFT and WALK_RIGHT. This allows direct and simple output assignments from the state bits themselves, simplifying output logic to just the stored state bits. The FSM transitions will be explicitly controlled by setting and clearing these state flip-flops based on bump inputs. The asynchronous reset will set the FSM to the WALK_LEFT state by asserting the corresponding flip-flop and clearing the other. This architecture uses two flip-flops instead of one but provides clearer state representation and can be beneficial for timing or readability in certain flows.
