Implement a simple two-state Moore FSM with asynchronous positive edge reset, encoding walk_left as state 0 and walk_right as state 1. On each clock, if reset is asserted, force state to 0 (walk_left). Otherwise, if bumped on left or right, switch state accordingly: bump_left or bump_right being 1 causes a state toggle (since bump_left means walk right and bump_right means walk left, so toggling state achieves this). This avoids complex boolean expressions by simply toggling state on any bump input. Outputs are direct state decoding.
