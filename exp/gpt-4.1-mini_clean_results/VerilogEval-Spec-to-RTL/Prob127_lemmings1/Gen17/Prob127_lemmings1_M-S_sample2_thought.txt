The FSM has only two states, so represent the state by a single bit where 0 means walk_left and 1 means walk_right. On each clock edge (or async posedge reset), update state according to the bump inputs:

- If bumped on both sides, toggle the state.
- Else if bumped on left only, set state to 1 (walk_right).
- Else if bumped on right only, set state to 0 (walk_left).
- Else hold the current state.

This logic can be expressed using simple conditional (if-else) statements, which are straightforward and yield minimal combinational logic. This approach reduces the previous complex boolean expression to an intuitive conditional structure that is easy to understand and synthesize efficiently. Outputs are directly derived from state as a Moore FSM.
