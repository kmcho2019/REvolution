Use a straightforward state machine with a single-bit state to represent walking direction: 0 for walk_left and 1 for walk_right. Implement asynchronous positive edge reset to initialize to walk_left. Update the state on each clock edge by toggling it whenever any bump occurs (left, right, or both), as bump on either side causes direction change. This simplifies next_state logic to toggling state if bump_left or bump_right is asserted; otherwise, keep the current state. Outputs directly map to state with no additional logic.
