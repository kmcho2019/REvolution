Implement the FSM as a one-hot encoded Moore machine with two state bits to explicitly represent walking left and walking right states. Use asynchronous active-high reset to initialize the state to walk_left (state[0]=1). On each clock edge, check bump inputs to determine if a direction switch is required: if either bump_left or bump_right is asserted, transition to the opposite direction state. This simplifies next state logic to a small combinational block that selects between holding the current state or switching to the other state based on bump signals. Outputs directly reflect the one-hot state bits, which makes logic for walk_left and walk_right trivial. This one-hot encoding improves clarity and may improve timing by avoiding negations in the state encoding.
