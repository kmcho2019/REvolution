Use a one-hot encoded two-bit state register to represent the walking direction, with one flip-flop per state. The asynchronous reset initializes the lemming to walk left by setting the left state bit high and the right state bit low. On each clock cycle, if any bump input is detected, the FSM toggles the state bits, effectively switching direction. This toggle approach simplifies next state logic by using XOR with the combined bump signal. Outputs are directly assigned from the one-hot encoded state bits, maintaining a Moore FSM. This architecture uses simple combinational logic for next state and makes explicit the state bits, offering an alternative FSM encoding style.
