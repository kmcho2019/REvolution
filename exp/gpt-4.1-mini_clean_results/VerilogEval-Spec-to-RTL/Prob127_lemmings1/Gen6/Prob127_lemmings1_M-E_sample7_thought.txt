Use a single-bit state register representing walking direction: 0 for walk_left and 1 for walk_right. On an asynchronous reset, set the state to 0 (walk_left). On each clock's positive edge, update the state by XORing the current state with the OR of bump_left and bump_right inputs. This way, any bump (left, right, or both) flips the walking direction. Outputs are generated directly by decoding the state: walk_left = ~state, walk_right = state. This is a compact and elegant way to capture the required switching behavior with minimal logic.
