Implement the Lemmings FSM as a one-hot state machine with two flip-flops representing each walking direction separately. Use asynchronous reset to set the lemming walking left by default. When bump inputs are detected, simultaneously enable transitions by clearing the current state's flip-flop and setting the other state’s flip-flop. This approach improves clarity by explicitly showing separate states as individual bits, facilitates quick state toggling via simple combinational logic, and adheres to a Moore machine design with outputs driven directly from the state flip-flops.
