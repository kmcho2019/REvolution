Fuse the clarity and explicit Moore output style of Example 1 with the minimal and direct output encoding from Example 2. Use a single-bit state (0=walk_left, 1=walk_right) with asynchronous positive edge reset setting state to walk_left. On each clock edge:

- If both bump_left and bump_right are asserted, toggle the state.
- Else if bump_left is asserted, set state to walk_right.
- Else if bump_right is asserted, set state to walk_left.
- Else hold the current state.

Generate Moore outputs via simple combinational assignments using the state bits directly (`walk_left = ~state`, `walk_right = state`) for minimal combinational logic, thereby minimizing area and power. This approach keeps outputs explicit, clear, and consistent with Moore FSM design. The asynchronous reset is maintained for compliance but note this could be changed if synthesis or timing goals dictate. This fusion ensures readability, minimal logic, low area, and straightforward timing.
