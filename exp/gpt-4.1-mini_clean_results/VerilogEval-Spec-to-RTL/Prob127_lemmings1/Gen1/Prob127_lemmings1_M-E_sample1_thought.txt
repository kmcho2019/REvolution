Implement the FSM using a single flip-flop as state storage (1 bit state), since only two states exist.
- State bit = 0 means walking left; 1 means walking right.
- On asynchronous positive edge reset, state bit is set to 0 (walk left).
- On each clock rising edge, if bump_left or bump_right is high, toggle the state bit.
- Outputs are directly derived from the state bit: walk_left = ~state, walk_right = state.
This approach uses minimal logic, no enums, and simple signal assignments.
