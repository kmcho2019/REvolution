Implement the Lemming FSM using a single-bit state register where 0 represents walking left and 1 represents walking right.
- Use asynchronous positive edge reset (areset) to set the state to 0 (walk left).
- On each clock positive edge, update the state by XOR-ing the current state with the OR of bump_left and bump_right inputs. This effectively toggles the state whenever either or both bump signals are asserted.
- Output signals walk_left and walk_right are derived directly from the current state bit: walk_left is high when state=0, walk_right is high when state=1.
This approach avoids enums and extra variables, using combinational logic and simple bit operations for concise, synthesizable design.
