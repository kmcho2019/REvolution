Use a simple 1-bit state to represent the current walking direction (0 for left, 1 for right). On each clock edge (with asynchronous active-high reset), update the state by directly setting it to walk right if bumped on left, or walk left if bumped on right. If bumped on both sides, invert the current state. This logic covers all cases while being very simple, ensuring immediate and clear direction changes without toggling or edge detection.
