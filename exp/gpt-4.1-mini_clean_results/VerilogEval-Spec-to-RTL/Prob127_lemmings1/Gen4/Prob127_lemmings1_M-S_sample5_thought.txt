Implement the FSM with simple reg states encoded as 1-bit values instead of enums, using a straightforward two-state machine. Use separate always blocks: one for asynchronous reset and state update on clock, and one combinational block for next state logic. Output signals (walk_left, walk_right) are derived directly from the current state in a combinational block, making it a Moore machine. This approach uses only Verilog-2001 compatible constructs and simplifies the design by avoiding SystemVerilog enums or typedefs.
