Implement the decade counter using a one-hot encoding scheme with a 10-bit register, where each bit represents a count state from 1 to 10. On each clock cycle, the one-hot vector shifts left to move to the next count, and when the last bit (representing 10) is set, it resets back to the first bit (representing 1). The 4-bit binary output q is generated by decoding which one-hot bit is active. This approach trades off a wider register and some combinational decoding logic for simplified state transitions (just a shift with wrap-around) and a straightforward synchronous reset. It also avoids arithmetic adders and comparators entirely.
