Implement the decade counter using a one-hot encoded state machine with 10 flip-flops, each representing a count from 1 to 10. On every clock edge, the active one-hot bit shifts to the next position, wrapping back to the first after the tenth. The synchronous reset activates the first flip-flop (count = 1). The output q is generated by encoding the one-hot state into the corresponding binary count using combinational logic. This approach separates state encoding from output decoding, potentially improving timing by avoiding arithmetic operations. The design uses a shift-register style state update with synchronous reset and a simple combinational binary encoder.
