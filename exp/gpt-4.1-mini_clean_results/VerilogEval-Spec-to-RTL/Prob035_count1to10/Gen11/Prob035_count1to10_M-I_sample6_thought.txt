To further improve PPA, use a 4-bit Gray code counter to reduce switching activity, which can lower dynamic power due to fewer bit transitions per count. However, the output q must still show binary counting from 1 to 10. So, implement the counter internally in Gray code and decode it to binary output. The synchronous reset sets the counter to Gray code of decimal 1. The rollover detection can be done on the binary output or on Gray code matching. This approach slightly increases combinational logic area but reduces toggling, improving power with minimal impact on timing. Since it's a small counter, the overhead is minor, and the power saving outweighs the cost.
