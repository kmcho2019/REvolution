Instead of using a straightforward binary counter with a comparator, I will implement the decade counter as a ring counter with a one-hot encoding of the values 1 through 10. Each state corresponds to a one-hot position in a 10-bit register. On each clock cycle, the '1' bit rotates to the next position, effectively cycling through 10 unique states. To produce the 4-bit output q, I will encode the current one-hot position into a binary number from 1 to 10. This approach avoids a comparator and adder in the sequential logic, potentially simplifying timing and reducing switching activity as only one bit changes in the register per cycle. Synchronous reset sets the one-hot register to state 1 (bit 0 set). The one-hot register is 10 bits, and the output q is generated combinationally via a priority encoder of the one-hot bits plus 1 to represent the count. This design trades off a wider register for simpler next-state logic and a clean state transition.
