Implement the decade counter by using a ring counter style approach with a 10-bit one-hot encoded shift register. Only one bit is set at a time, representing the current count from 1 to 10. On each clock, the 'hot' bit shifts left by one position, wrapping from the 10th bit back to the 1st bit. The 4-bit output q is generated by encoding the position of the hot bit into a binary count (1 to 10). On synchronous reset, the first bit is set (count = 1). This approach eliminates addition and direct numeric comparison, simplifying combinational logic at the expense of a wider register and an encoder, potentially improving timing by reducing complex arithmetic paths.
