Implement the decade counter as a state machine with explicit states from 1 to 10 encoded as 4-bit values. Use a synchronous active-high reset to set the state to 1. On each clock cycle, increment the state, and when the count reaches 10, wrap back to 1. Instead of combinational equality checks, use a simple conditional comparison to decide when to wrap. This approach emphasizes clarity and explicit state progression while avoiding extra logic for combinational detection, potentially making synthesis map well for FPGA or ASIC standard-cell libraries by clearly defining state transitions. The counter output q directly represents the current state.
