Refactor the decade counter by separating the next state logic into a combinational always block and then updating the register in a sequential always block. This decouples state transition logic from state storage, improving code readability and making the design style more modular. The next state logic can use a simple case or if statement to reset to 1 when count reaches 10, else increment. The synchronous reset remains active high. This approach still uses natural binary encoding and the same counting sequence but structures the code differently without using wire for condition detection outside the always block.
