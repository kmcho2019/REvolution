Refactor the decade counter by using a synchronous always block only for the state updates and implementing the next-state logic with a ternary operator directly inside the sequential block, eliminating the separate combinational always block and the intermediate next_q register. The detection of terminal count (10) is done by comparing q with 4'd10. This approach simplifies the code by reducing the number of always blocks and variables, while maintaining synchronous reset and counting behavior. The output q remains a 4-bit register. This style is concise and synthesizable.
