Implement a synchronous decade counter using a combinational next-state logic block and a registered state variable. On each clock's positive edge, if reset is asserted, load 1 into the state; otherwise, transition to the next state. The next state is computed by incrementing the current count unless it is 10, in which case the next state wraps to 1. This separates combinational next state calculation from the sequential register update, which may aid timing clarity.
