Instead of using a straightforward binary counter with a comparison to 10, implement the decade counter as a simple finite state machine (FSM) with states representing the count values 1 through 10. On each clock edge, the FSM moves to the next state; after state 10 it returns to state 1. The synchronous reset sets the state to 1. This approach avoids explicit arithmetic and comparison logic, potentially reducing combinational logic delay, and provides clear state transitions.
