Implement the decade counter as a one-hot encoded 10-bit shift register with a single bit set to '1' representing the current count state. The register shifts the '1' bit to the next position on each clock cycle, wrapping from the 10th state back to the 1st. The output q is derived by decoding the one-hot state back to a 4-bit binary count from 1 to 10. This architecture simplifies the rollover logic to checking if the last bit is set and shifting back to the first bit, avoids binary addition and comparison, and can improve timing by distributing combinational logic and making state transitions simpler. The synchronous active-high reset sets the register to the first state. This approach highlights an alternative state encoding, demonstrating flexibility in design choices for decade counters.
