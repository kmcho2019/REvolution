Refactor the decade counter by removing the explicit combinational always block and instead using a continuous assignment to define the next state. The synchronous process remains responsible for updating the state on the clock edge with reset. This approach simplifies the design by separating combinational logic outside the always block, which can improve readability. The counter logic remains the same: if q is 10, next state is 1, otherwise increment by 1. This also demonstrates a clear distinction between combinational and sequential logic using continuous assignment and synchronous always block.
