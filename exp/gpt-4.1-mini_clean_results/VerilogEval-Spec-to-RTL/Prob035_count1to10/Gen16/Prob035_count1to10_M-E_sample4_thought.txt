Implement the decade counter using a binary-coded decimal (BCD) approach with a synchronous reset and a conditional wrap from 10 back to 1. Instead of a combinational next-state logic block, the counter will be updated directly inside the sequential always block triggered by the clock, which makes the design more straightforward. The reset will synchronously set the count to 1, and on each clock cycle, the counter will increment if less than 10; otherwise, it wraps to 1.

To detect the decimal 10, use a simple equality comparison (q == 4'd10) for clarity, trading off a tiny amount of combinational logic for code simplicity. This is a different architectural style than separating combinational next state and sequential logic.

This approach provides a minimalistic and clean code style, easy to understand and verify, and utilizes only one always block for sequential logic, eliminating next state signals. It also emphasizes a synchronous reset inside the same sequential block.
