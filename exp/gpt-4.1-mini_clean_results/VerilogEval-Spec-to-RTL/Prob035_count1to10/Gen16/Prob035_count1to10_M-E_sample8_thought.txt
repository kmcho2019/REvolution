Implement the decade counter as a simple finite state machine (FSM) with a 4-bit register holding the current state, which directly represents the count value. On each clock cycle, if reset is asserted, the counter state resets synchronously to 1. Otherwise, the state transitions to the next count by incrementing the current state by one, except when it reaches 10, in which case it wraps back to 1. Instead of detecting 10 via combinational logic, the module uses an equality check to determine when to wrap around. The output q is driven directly from the state register. This approach treats the counter as an explicit FSM state variable rather than relying on combinational next-state logic separated from state register updates.
