To implement a decade counter counting from 1 to 10 with synchronous reset to 1, I will:

- Use a 4-bit register `q` to hold the current count.
- On each clock edge, if reset is asserted, set `q` to 1.
- Otherwise, increment `q`. When `q` reaches 10, reset it back to 1.
- To simplify the wrap detection, instead of checking bit patterns, I will use a numerical comparison `if (q == 10)`.
- Use non-blocking assignment inside a single always block triggered on the positive clock edge to keep the design concise.
- This approach minimizes the combinational logic by embedding all logic inside sequential logic, simplifying timing and potentially reducing the critical path.
- By avoiding a separate combinational block, the control logic is straightforward and easy to synthesize.
- This architectural style is very common and robust for counters.
