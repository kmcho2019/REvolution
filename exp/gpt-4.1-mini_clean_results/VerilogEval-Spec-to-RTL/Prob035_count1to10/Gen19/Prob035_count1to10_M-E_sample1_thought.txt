I will implement the decade counter using a case statement inside a synchronous always block that triggers on the positive clock edge. On reset, the counter will synchronously load 1. On each clock cycle, the counter will increment by 1 until it reaches 10, after which it wraps to 1 again.

This approach uses a state machine style explicit enumeration of counter states, avoiding arithmetic operations like addition for next state. This can reduce logic complexity for some synthesis tools by mapping each state to a case branch. Also, the counter is represented as a 4-bit register, and the reset and counting are handled in the same always block for simplicity.

This design trades combinational next-state logic for a straightforward state transition via a case statement, providing a clear, deterministic counting sequence. It is a purely sequential design that could be beneficial in environments where arithmetic incrementers are costly or when timing predictability is important.
