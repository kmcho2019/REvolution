Implement the decade counter as a one-hot encoded state machine with 10 flip-flops representing states 1 through 10. On each clock, the active state shifts to the next one-hot flip-flop, and after state 10, it wraps back to state 1. The synchronous reset sets the state to state 1. The output q is generated by decoding the one-hot state into its binary count value. This approach avoids arithmetic operations for next state computation, potentially reducing combinational logic delay and simplifying state transitions.
