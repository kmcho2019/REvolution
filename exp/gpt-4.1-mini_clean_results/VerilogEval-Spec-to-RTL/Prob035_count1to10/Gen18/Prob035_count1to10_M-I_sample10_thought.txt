2. Add an enable signal that disables counting (holds count stable) when reset is asserted or when the count reached 10 and is about to wrap. This reduces unnecessary toggling in the counter register, lowering dynamic power.

3. Keep the synchronous reset logic simple by combining it with enable in the sequential block to avoid extra logic in combinational paths.

4. Use minimal combinational logic for next state: if reset asserted, set 1; else if count is 10, wrap to 1; else increment by 1.
