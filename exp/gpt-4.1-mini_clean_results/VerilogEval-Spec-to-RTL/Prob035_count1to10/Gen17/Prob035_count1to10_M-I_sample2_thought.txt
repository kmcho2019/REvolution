To improve PPA, especially timing and power, we can register the output q instead of computing it combinationally. This eliminates the combinational adder on the output path, reducing critical path delay. The internal count register can count from 1 to 10 directly, simplifying logic by using comparison with 10 for reset. On reset, count is set to 1. On reaching 10, count resets to 1 on next clock cycle. Registering q means output updates synchronously, aligning with clock and reducing glitches, which also saves power. Area remains minimal with only a slight addition of a registered output instead of a combinational one.
