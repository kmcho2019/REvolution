Implement the decade counter as a one-hot encoded state machine with 10 states, each representing count values 1 to 10. On each clock cycle, the 'hot' bit shifts to the next position, wrapping around after state 10 back to state 1. The output 'q' is decoded from the one-hot state by a priority encoder. This approach uses a shift-register style state machine instead of binary counting and avoids arithmetic operations. The synchronous reset initializes the state to the one-hot encoding of count 1. This design leverages simple shift logic for state transitions and combinational logic to encode the count output.
