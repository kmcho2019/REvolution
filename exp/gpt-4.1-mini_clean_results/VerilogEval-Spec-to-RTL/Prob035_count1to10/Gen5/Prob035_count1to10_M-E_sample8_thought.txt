Implement the decade counter using a ring-counter style one-hot encoding internally for the count states from 1 to 10, then convert that one-hot state back to a 4-bit binary output q. The one-hot register will have 10 bits, each representing one count state. On each clock edge, the one-hot bit rotates to the next position, resetting back from the 10th bit to the first. This approach uses shift logic rather than binary addition and comparison, potentially improving power by having only one bit toggling each cycle. The reset synchronously sets the one-hot to the first position corresponding to count 1. The final 4-bit output q is encoded from the one-hot position using a combinational priority encoder that maps the active one-hot bit to its corresponding count value (1 to 10).
