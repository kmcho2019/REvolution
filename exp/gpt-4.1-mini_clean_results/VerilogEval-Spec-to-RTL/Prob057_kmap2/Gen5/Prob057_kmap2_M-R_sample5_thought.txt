The original design decomposed the output into four partial functions based on {c,d}, then used a one-hot mux selecting among them. To refactor while keeping the core idea, I will implement the multiplexer as a single-case statement inside a combinational always block with a 2-bit selector formed by {c,d}.

This differs from the original by combining all logic into a single always_comb block with a case statement instead of separate wire assignments and one-hot muxing. The partial functions remain the same, but I will compute them inside the case branches.

This structural change enhances code compactness and centralizes the logic selection, making it easier to read and modify while preserving the same logical operation and inputs/outputs.
