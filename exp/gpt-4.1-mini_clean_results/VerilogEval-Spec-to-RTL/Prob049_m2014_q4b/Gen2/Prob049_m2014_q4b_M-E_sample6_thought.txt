Implement the asynchronous reset D flip-flop by using a latch-based two-stage design. The first stage is an asynchronous reset latch that holds a reset flag when ar is asserted; the second stage is a positive-edge triggered flip-flop that samples input d only when reset is not active. When ar is high, the output q is asynchronously forced low via the reset latch stage. This approach explicitly separates the reset detection and data storage, demonstrating a latch plus flip-flop hybrid structure still functionally equivalent to a simple async reset DFF, but architecturally distinct.
