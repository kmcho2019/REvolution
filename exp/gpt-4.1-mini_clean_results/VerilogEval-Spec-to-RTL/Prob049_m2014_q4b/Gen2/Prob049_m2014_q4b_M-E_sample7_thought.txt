Implement the asynchronous reset by using a combinational assignment to an internal reset signal synchronized to the clock domain via a gated latch, then feed that reset into a synchronous D flip-flop. This achieves the asynchronous reset effect without directly using asynchronous reset in the always block. This approach uses a two-stage scheme: an asynchronous latch capturing the reset, combined with a synchronous flip-flop using that reset signal. It is a novel architectural idea to emulate asynchronous reset behavior with synchronous logic and an asynchronous latch, which might be useful in certain timing or toolflow environments.
