Implement the asynchronous active-high reset by first checking the reset condition in the always block triggered on posedge clk or posedge ar. If reset is asserted (ar=1), asynchronously clear q to 0 immediately. Otherwise, at the positive clock edge, latch the input d into q. This standard approach clearly separates asynchronous reset and synchronous data capture. To provide a new architectural idea, encapsulate the D flip-flop behavior with async reset into a separate submodule named DFF_AsyncReset, then instantiate it inside TopModule. This enhances modularity and code reuse while maintaining correct asynchronous reset behavior.
