Implement the asynchronous reset by creating an internal reset-activated latch stage before the main positive-edge triggered D flip-flop. The asynchronous reset directly forces this latch output to 0 whenever asserted. On the rising clock edge, the D input is latched into the flip-flop only if the reset latch output is not active (i.e., reset not asserted). This two-stage design separates the reset path from the data path, with the asynchronous reset effect realized via a transparent latch and the synchronous data latch via a flip-flop, which can clarify timing and possibly aid certain synthesis flows.
