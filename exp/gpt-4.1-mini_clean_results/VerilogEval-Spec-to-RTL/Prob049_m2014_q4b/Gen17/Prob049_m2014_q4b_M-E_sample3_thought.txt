To provide a novel architectural approach, implement the asynchronous reset as a separate asynchronous reset synchronizer that forces the flip-flop output to zero when asserted, and the D flip-flop itself will be purely synchronous. This decouples the reset logic from the flip-flop data path and can help when integrating with tools or flows that expect strictly synchronous flip-flops. The reset signal asynchronously drives the output directly via a combinational multiplexer-like logic, multiplexing between 0 (reset active) and the DFF output. This technique essentially creates an asynchronous reset behavior without having an asynchronous reset inside the always block, by using asynchronous muxing on output. This is a more "combinational async reset" style architecture.
