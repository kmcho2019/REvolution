Implement the asynchronous reset by separating reset logic into a combinational signal that forces the flip-flop output to zero when active, using a gated enable style. Specifically, create an enable signal that is active only when reset is not asserted, and drive the flip-flop input accordingly. Use a single always block sensitive only to the positive edge of the clock, but asynchronously clear the flip-flop output by leveraging a latch-enabled reset-driven mux on the data input. This design uses synchronous logic only with asynchronous effect achieved by data gating rather than adding asynchronous reset to the always block sensitivity list, showing an alternative architectural approach that may help in tools that prefer single-edge triggered always blocks.
