Implement the asynchronous reset functionality by using two always blocks: one purely asynchronous that immediately sets the output to zero when reset is asserted, and another synchronous that updates the output with the input data on the rising edge of the clock only if reset is not active. This approach decouples the asynchronous reset action and the synchronous data update clearly, using separate always blocks to enhance readability and potentially better synthesis mapping on some tools. The asynchronous reset block is sensitive only to the reset, while the synchronous block is sensitive only to the clock.
