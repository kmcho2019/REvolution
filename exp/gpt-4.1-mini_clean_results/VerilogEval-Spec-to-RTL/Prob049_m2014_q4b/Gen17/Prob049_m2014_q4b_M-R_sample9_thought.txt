Refactor the asynchronous reset D flip-flop using a single always block triggered only on the positive edge of the clock, combined with a separate asynchronous reset path implemented by a direct asynchronous assign statement that forces the output to zero when reset is asserted. This can be achieved by using an internal register to hold the data, and using a continuous assignment on the output that reflects zero when reset is active, otherwise the register value. This structure separates the asynchronous reset effect from the clocked data latching, without mixing both in a single always block sensitivity list.
