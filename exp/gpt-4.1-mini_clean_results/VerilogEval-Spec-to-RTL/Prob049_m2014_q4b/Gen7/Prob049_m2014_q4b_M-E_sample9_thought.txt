Implement the asynchronous reset by forcing the flip-flop output to zero through a combinational gate controlling the D input to the internal flip-flop. This approach uses a synchronous D flip-flop with a synchronous reset emulated by gating the input with the asynchronous reset signal. The asynchronous reset asynchronously clears the output by overriding the data input before the clock edge, providing the same functionality but architecturally distinct from direct asynchronous reset in the sensitivity list.
