A different architectural idea is to implement the asynchronous reset using two separate always blocks: one asynchronous block that immediately sets the output q to zero when ar is asserted, and another synchronous block that updates q on the positive edge of clk using the input d when ar is not asserted. This approach clearly separates asynchronous reset behavior from the synchronous data capture, making the design modular and explicit. Although synthesis tools generally infer the same hardware, this approach may improve code readability and debugging for complex designs.
