Implement the asynchronous reset by using an explicit reset signal inside the always block sensitive only to the positive clock edge, but asynchronously clear a register that directly drives the output 'q'. Use a separate always block sensitive to 'ar' (asynchronous reset) to force the register to zero immediately when reset is asserted. This splits the asynchronous and synchronous logic into two always blocks: one asynchronous block for reset forcing and one synchronous block for data loading. The output q is directly driven by the register. This architecture models asynchronous reset behavior while keeping data latch logic cleanly synchronous.
