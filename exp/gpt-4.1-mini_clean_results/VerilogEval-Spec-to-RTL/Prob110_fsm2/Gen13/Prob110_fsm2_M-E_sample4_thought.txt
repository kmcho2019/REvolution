Implement the FSM using an explicit two-bit one-hot style state encoding with two flip-flops representing the OFF and ON states individually. Each flip-flop indicates whether the machine is in that state, and only one flip-flop is high at a time. Use synchronous reset for state initialization to OFF. The next-state logic will be written combinationally with clear if-else statements for readability and straightforward mapping. The output is driven from the ON state flip-flop directly, preserving the Moore machine property. This approach trades the minimal bit encoding for architectural clarity and explicit state representation, which can help with debug and formal verification.
