Implement the Moore FSM using a two-bit state encoding with explicit symbolic states, where one bit represents the current state and the other is unused (kept zero) to demonstrate extensibility for future states. Use a combinational always block with if-else statements instead of case to determine the next state, providing a stylistic variation from the typical case approach. Synchronize the state register on the rising edge of clk with asynchronous active-high reset to OFF state. Generate the output by a registered output signal updated synchronously with the state, emphasizing strict Moore semantics (output depends only on state, output changes registered to avoid glitches).
