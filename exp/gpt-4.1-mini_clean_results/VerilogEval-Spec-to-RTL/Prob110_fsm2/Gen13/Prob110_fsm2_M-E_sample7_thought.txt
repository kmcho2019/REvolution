Implement the FSM using separate combinational next-state logic and registered state with asynchronous reset, clearly separating combinational and sequential parts. Represent the two states with a 1-bit state register, define parameters for clarity (OFF=0, ON=1), and explicitly write the next-state combinational logic in a separate always block to improve readability. Output is assigned as a function of the registered state (Moore output). This approach is modular, easy to debug, and common in FSM designs.
