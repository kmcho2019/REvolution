Implement the FSM using a one-bit state register representing OFF=0 and ON=1, with next-state and output logic embedded in a single always block triggered by clock and asynchronous reset. Use a case statement for clearer state transitions. The output is registered (Moore output) inside the state register block, which may slightly increase latency but ensures stable outputs synchronized to the clock. This approach uses minimal resources (1-bit state and output), simple and explicit code, and the registered output improves glitch immunity.
