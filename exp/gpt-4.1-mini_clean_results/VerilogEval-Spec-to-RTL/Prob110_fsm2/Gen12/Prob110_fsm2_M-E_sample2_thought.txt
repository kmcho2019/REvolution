I will implement the Moore FSM using one-hot state encoding instead of binary encoding. This means each state will be represented by a separate flip-flop: one for OFF and one for ON. Only one flip-flop is asserted at a time. This can improve synthesis results on certain technologies and make the next-state logic very simple combinational logic (AND/OR gates), potentially improving timing.

The asynchronous reset will clear both flip-flops and then set the OFF flip-flop. The state transitions will be done by combinational logic derived from the current state flip-flops and inputs j and k.

The output will be directly connected to the ON state flip-flop, preserving the Moore FSM principle.

This architectural shift trades one state register bit for two flip-flops with simpler next-state logic and explicit one-hot encoding.
