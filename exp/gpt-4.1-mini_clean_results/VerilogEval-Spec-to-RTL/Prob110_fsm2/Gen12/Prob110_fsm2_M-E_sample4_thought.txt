I will implement the FSM as a Mealy machine internally to determine the next state and output together in one combinational block. However, I will still provide a Moore-style output by registering the output in a separate flip-flop that is updated synchronously with the state. This approach uses two registers: one for state and one for output, so the output updates on the clock after the state update, maintaining Moore output behavior.

I will encode the two states as a single bit and explicitly describe the asynchronous reset in the state register block, while the output register will synchronously follow the state register.

This design separates state and output registers but combines the next state and output logic in one combinational block, slightly different from the classical Moore FSM style but still functionally equivalent. It can be useful when output needs to be registered separately for timing or glitch reduction.

Non-blocking assignments will be used in sequential blocks and blocking assignments in the combinational block.
