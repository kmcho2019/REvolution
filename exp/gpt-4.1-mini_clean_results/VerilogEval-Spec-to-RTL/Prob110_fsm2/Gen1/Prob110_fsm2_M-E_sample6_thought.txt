Use one-hot encoding for the two states, represented as a 2-bit register where only one bit is set at a time (OFF = 2'b01, ON = 2'b10). Implement asynchronous active-high reset to the OFF state. On every clock edge, update the state based on input j or k and current state. Since output is Moore, derive it directly from the one-hot encoded state bits (output = ON state's bit). This approach simplifies state decoding and can be efficient in some FPGA architectures.
