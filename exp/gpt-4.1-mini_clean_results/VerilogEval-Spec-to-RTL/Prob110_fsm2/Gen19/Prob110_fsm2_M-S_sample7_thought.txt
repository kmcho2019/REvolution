The FSM has only two states, so we can use a single bit to represent the state. Since the output directly corresponds to the state, we can assign 'out' as the state bit itself, avoiding the explicit comparison. We can implement the next state logic directly in the clocked always block, which reduces complexity by eliminating the separate next_state signal and combinational block. The asynchronous active-high reset is kept as required. This simplification reduces code lines and keeps functionality unchanged.
