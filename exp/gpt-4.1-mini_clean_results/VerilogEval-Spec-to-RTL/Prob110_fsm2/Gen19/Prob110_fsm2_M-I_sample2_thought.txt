To improve PPA, separate the combinational next-state logic from the sequential state and output registers. Use non-blocking assignments consistently. Compute next_state combinationally in one always_comb block, and update state and output synchronously in the clocked always block with asynchronous reset. Set the output based on the registered current state (Moore output), not on next_state, which enables better timing and clarity. This separation can help synthesis tools optimize timing and power by isolating combinational logic from sequential registers. The state encoding remains a single bit for area efficiency.
