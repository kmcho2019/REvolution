I will implement the two-state Moore FSM using a single bit state flip-flop as before but invert the sense of the state: let the state bit 1 represent OFF and 0 represent ON. This way, the asynchronous reset sets state to OFF by driving it to 1. The next state logic will be rewritten accordingly: from OFF (state=1), if j=1 go to ON (0), else remain OFF (1); from ON (0), if k=1 go to OFF (1), else remain ON (0). The output logic will be tied to the inverted state bit, outputting 1 when state=0 (ON). This inverted encoding and logic provide a fresh perspective and reduce some logic by using negation on the state bit directly for output. The asynchronous reset remains active-high and asynchronous.
