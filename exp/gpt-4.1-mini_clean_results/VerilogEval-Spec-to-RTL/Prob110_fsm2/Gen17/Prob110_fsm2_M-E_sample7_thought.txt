Implement the FSM using one-bit state encoding, where state = 0 represents OFF and state = 1 represents ON. Use an always block with synchronous reset for the state register to simplify timing and minimize asynchronous reset complexity. Separate combinational always block determines next state and output based on current state and inputs using a case statement for clarity. This design keeps outputs registered for a fully synchronous Moore FSM, reducing glitches and improving timing predictability.
