Implement the FSM using one-hot state encoding with two flip-flops for the OFF and ON states. Use asynchronous reset to clear both state bits and set OFF state bit. State transitions are controlled by enabling the appropriate flip-flop on the clock edge based on inputs j and k. The output is simply the ON state bit. This approach explicitly represents states with flip-flops, enabling easier state decoding and potentially more readable timing in larger FSMs, at the cost of one extra flip-flop.
