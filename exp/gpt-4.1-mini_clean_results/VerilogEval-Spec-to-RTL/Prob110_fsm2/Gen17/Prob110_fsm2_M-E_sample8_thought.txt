Implement the two-state Moore FSM using one-hot encoding instead of a single-bit state. With one-hot encoding, each state is represented by a separate flip-flop, simplifying next-state logic to simple AND/OR operations. This can potentially improve timing by reducing the complexity of combinational logic in next-state calculation. Also, make the output logic directly driven from the ON state's flip-flop output, which removes the need for a decoder and simplifies output logic. The asynchronous reset is applied to both state flip-flops, ensuring the OFF state is set on reset. This approach may increase area slightly due to an extra flip-flop but can improve timing and power by simplifying logic and avoiding combinational comparison for clock enable.
