To implement the two-state Moore FSM with asynchronous reset, I will use a two-bit one-hot encoding for states instead of a single-bit binary encoding. Here, OFF will be represented as 2'b01 and ON as 2'b10. This approach simplifies the next state logic to pure combinational logic using only input signals and current one-hot encoded states without a case statement.

I will implement the next-state logic as combinational logic based on the present one-hot state and inputs j and k. The state register will be updated synchronously with asynchronous reset.

For output logic, since the machine is Moore type, the output depends only on the state. It can be assigned as a simple OR-reduction of the ON state bit.

This architectural change allows a clean and explicit representation of states and next state signals, facilitating easier scalability to more states if needed and demonstrates an alternative to binary encoding.
