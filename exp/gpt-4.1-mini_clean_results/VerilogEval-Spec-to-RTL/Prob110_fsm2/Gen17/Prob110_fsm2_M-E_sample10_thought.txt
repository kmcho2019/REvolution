Implement the FSM using an explicit next_state combinational logic block separated from the state register update block, ensuring clarity in synthesis and easy debugging. Use a 2-bit state encoding with symbolic parameters (OFF=2'b00, ON=2'b01) and store the output in a registered output signal to emphasize the Moore machine behavior. The output is updated synchronously with the state, which makes timing predictable. Asynchronous reset is still supported. This approach cleanly separates combinational and sequential logic, enhancing readability and facilitating timing analysis tools.
