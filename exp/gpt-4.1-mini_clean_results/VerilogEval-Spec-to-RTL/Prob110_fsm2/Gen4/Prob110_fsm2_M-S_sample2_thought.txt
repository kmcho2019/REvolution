Since the FSM only has two states and the output directly corresponds to the state, use 'out' as the state register. On asynchronous reset, set 'out' to 0 (OFF). At each clock edge, update 'out' by selecting j when in OFF and k when in ON, leveraging the fact that the next state is just a mux between inputs based on the current state. This simplification removes conditional branching and directly expresses next state logic with a single assignment.
