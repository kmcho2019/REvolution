Implement a Moore FSM with two states: OFF (output 0) and ON (output 1).
Use an asynchronous active-high reset (areset) to set state to OFF.
On each clock edge, if reset is not asserted:
- In OFF state: transition to ON if j=1, otherwise stay OFF.
- In ON state: transition to OFF if k=1, otherwise stay ON.
Output depends only on the current state (0 for OFF, 1 for ON).
