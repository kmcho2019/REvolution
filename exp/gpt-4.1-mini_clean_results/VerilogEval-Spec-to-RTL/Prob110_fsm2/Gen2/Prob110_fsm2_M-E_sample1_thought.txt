Implement the Moore FSM using a one-bit state register where state=0 represents OFF and state=1 represents ON. Use synchronous reset logic by asynchronously clearing the state register with an active-high reset but update next state logic in the clock domain. The next state is determined using a single always_ff block combining both asynchronous reset and synchronous state updates, thereby reducing separate combinational always blocks. Output is assigned as the state value itself, simplifying output logic. This yields a minimalistic and clean design differing from explicit case statements.
