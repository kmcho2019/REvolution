Implement the Moore FSM using a one-hot encoding style with two separate flip-flops representing the OFF and ON states respectively. Use asynchronous reset to clear both state bits. The next state logic will be purely combinational and the output is directly derived from the ON state flip-flop (which represents being in the ON state). This approach avoids using a binary state encoding and instead uses a one-hot state encoding, potentially simplifying logic and improving clarity in hardware representation.
