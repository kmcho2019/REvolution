Implement the FSM using one-hot state encoding and separate always blocks for next state and output logic. Use a synchronous reset for the state register but detect the asynchronous reset with a separate asynchronous always block to force the state to OFF immediately. The Moore output is generated from the state registers, and the next state is decided in a combinational always block based on the inputs and current state. This approach clearly separates state register update, next state logic, and output logic, while also demonstrating a one-hot FSM implementation to differ from the binary encoding style.
