I will implement the Moore FSM using an explicit enumerated state encoding with two-bit states to improve clarity, although only two states are needed. I will encode OFF as 2'b00 and ON as 2'b01. This allows easy extensibility if needed. The FSM state register and combinational next state logic are separated, with synchronous reset behavior modeled by using asynchronous reset to force the state to OFF (2'b00). The output is assigned based on the state using a combinational assignment that maps state OFF to 0 and ON to 1. The next state is determined by the inputs j and k according to the specified transitions. This approach uses a parameterized style and leverages a case statement for next-state logic to explicitly show state transitions for future scalability.
