Implement the Moore FSM with an encoded two-bit state register to explicitly represent both states as separate bits (OFF=2'b00, ON=2'b01). Use a synchronous always block without combinational continuous assignments. The next state and output are computed inside a single always block triggered on the clock and asynchronous reset. The output is registered alongside the state for clean Moore semantics. This approach uses registered output instead of combinational output, which might reduce glitches and improve timing on output transitions.
