Implement the Moore FSM using a single-bit state register, with explicit enumerated parameters for OFF=0 and ON=1, and use an always_comb (combinational always block) for next state and output logic based on current state and inputs. Use a single always block for the state register with asynchronous active-high reset. The output is driven directly from the registered state (since output depends only on state). This approach is minimal in terms of state width, explicit in combinational next-state logic (using if-else), and very clear.
