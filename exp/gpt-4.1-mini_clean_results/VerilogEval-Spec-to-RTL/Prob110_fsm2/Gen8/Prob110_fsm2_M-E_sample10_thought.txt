Implement the Moore FSM with an explicit two-bit state encoding instead of encoding state in the output directly. Use a synchronous reset for the state register but asynchronously clear it by combining areset with clk inside the always block (through if statement for asynchronous reset simulation). The two states OFF and ON are encoded as 1'b0 and 1'b1 respectively in a single-bit state register, separate from the output 'out'. The output is purely combinational and depends only on the current state, consistent with a Moore machine. Next state logic is in a separate combinational always block. This separation enhances clarity and scalability and explicitly models state as a separate reg, improving readability and making the design more extensible to future states.
