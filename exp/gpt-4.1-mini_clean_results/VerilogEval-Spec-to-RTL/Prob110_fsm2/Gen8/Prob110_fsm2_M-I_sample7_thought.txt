To optimize the given Moore FSM for better Power, Performance, and Area (PPA), I will register only the state and implement the output as a combinational signal derived directly from the current state. This reduces the output's clock-to-out delay, improving performance. It also reduces power since no extra flip-flop toggling for the output occurs, and area is saved by removing one register.

I will keep the asynchronous active-high reset for the state register as required. The combinational next-state logic remains the same.

This approach yields a simpler and more efficient design:
- Only one register (state)
- Output combinationally driven by state (Moore output)
- Asynchronous reset for state
- Non-blocking assignments in sequential logic
