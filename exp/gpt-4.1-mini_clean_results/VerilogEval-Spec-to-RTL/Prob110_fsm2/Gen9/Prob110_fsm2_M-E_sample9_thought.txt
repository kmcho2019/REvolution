Implement the two-state Moore FSM with explicit state encoding using a 1-bit state register distinct from the output. Use two parameters (OFF=1'b0, ON=1'b1) to improve code readability. The output is combinationally derived directly from the current state, enforcing Moore behavior. Use synchronous reset (areset) to asynchronously clear the state register to OFF, implemented via an asynchronous reset signal on the always block. The state update logic is split into a sequential always block for state register and a combinational always block for next state logic, improving clarity and maintainability. This clear separation of concerns benefits larger FSM scaling and debugging.
