Since the FSM has only two states and the output equals the state, we can encode the state directly in the output `out`. We can implement the next state logic directly in the sequential always block without a separate combinational block. The asynchronous reset sets `out` to 0 (OFF). On each clock edge, `out` updates based on the current state and inputs according to the state transitions. This eliminates the extra `next_out` signal and reduces the code while maintaining the same functionality and behavior.
