Since the output is directly the state itself (0 for OFF, 1 for ON), we can use the state register as the output register, avoiding a separate output register. Thus, output can be assigned directly from the state signal. 

Keep the asynchronous active-high reset and next state logic, but remove the extra 'next_state' register by computing and updating the state in a single always block. This makes the design simpler with fewer signals while preserving functionality and synthesis friendliness.

Use the state register as the output signal by assigning 'out = state;' continuously. This eliminates the output register and the corresponding non-blocking assignment, simplifying the code and reducing registers.
