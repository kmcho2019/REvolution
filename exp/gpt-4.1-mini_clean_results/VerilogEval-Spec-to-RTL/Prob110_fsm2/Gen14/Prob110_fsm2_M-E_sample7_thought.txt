Implement the Moore FSM using a two-bit encoded state with explicit state parameters OFF=2'b00 and ON=2'b01 to allow easy future extensibility. Use a synchronous active-high reset for the state register instead of asynchronous reset for improved power and timing robustness.

Encode output as a separate registered signal updated on the clock, decoupling output logic from state encoding. This separates concerns and clearly models the Moore FSM output as a registered output based on the current state.

Use a simple combinational block to determine next state and output_next signals from current state and inputs. On each clock, synchronously update the state and output registers.

This approach is a classic FSM style favoring synchronous resets and output registers, improving timing predictability and power consumption by avoiding asynchronous resets and reducing glitches on the output signal.
