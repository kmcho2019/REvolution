Implement the FSM using one-hot encoding with two flip-flops representing OFF and ON states. Use separate always blocks for state registers and next state logic with combinational outputs. Employ synchronous active-high reset instead of asynchronous reset to improve timing predictability. The output is registered (Moore output) and driven solely by the ON state flip-flop. This approach simplifies state decoding, avoids combinational output glitches by registering outputs, and uses synchronous reset to ease timing closure in ASIC flows.
