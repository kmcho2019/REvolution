Implement the Moore FSM using a one-hot encoding with two flip-flops, each representing one state (OFF and ON). Use asynchronous reset to initialize the FSM to the OFF state. Instead of encoding states as a single bit, explicitly store each state in a separate register bit. Next state logic is handled combinationally with clear direct assignments, and the output depends on the ON state flip-flop only. This approach provides clear state separation, potentially easing timing closure on certain FPGA architectures, and highlights state transitions explicitly.
