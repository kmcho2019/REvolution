The FSM only requires a single-bit state to differentiate OFF and ON. The next state depends solely on one input depending on the current state (j when OFF, k when ON). We can implement the next state logic and output in a compact way by using a single register that directly captures the updated state on each clock. By using a simple conditional assignment for next state and output, the design can be shortened and simplified without losing clarity or correctness. The asynchronous reset is kept as is to meet the specification.
