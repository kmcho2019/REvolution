This design implements the two-state Moore FSM by explicitly separating the next-state combinational logic from the state register. The next state is computed in a combinational always block based on current state and inputs, then registered on the clock edge with asynchronous reset. The output logic is a simple assignment from the registered state. This separation improves clarity and may aid synthesis tools in optimizing timing paths. Additionally, using an enumerated typedef for state encoding enhances code readability and maintainability.
