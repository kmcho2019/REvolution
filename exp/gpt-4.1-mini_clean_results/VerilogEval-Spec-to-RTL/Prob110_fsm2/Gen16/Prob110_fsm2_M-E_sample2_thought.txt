Implement the Moore FSM by encoding state as a one-bit register where OFF=0 and ON=1. Use a synchronous reset inside the clocked process for simplicity (and to reduce asynchronous reset complexity). Implement next-state logic using direct combinational logic equations instead of a case statement. Separate the output logic completely from the sequential block as a purely combinational function of the state register, ensuring glitch-free stable Moore output. This approach reduces output latency and output glitches, as output changes only on state updates, simplifying timing and reducing dynamic switching.
