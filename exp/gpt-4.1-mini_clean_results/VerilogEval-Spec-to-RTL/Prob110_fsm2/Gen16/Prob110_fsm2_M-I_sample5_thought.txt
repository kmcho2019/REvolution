To improve PPA, separate the next-state combinational logic from the state register update to aid synthesis tools in optimization, potentially improving timing (performance). Also, add a clock enable signal that only enables the state register update when a state transition can occur, reducing unnecessary toggling and dynamic power. The FSM transitions only happen on input changes when in the respective states, so gating the clock enable in this manner minimizes switching without adding complexity. This approach keeps area overhead minimal (one additional signal) while improving power and potentially performance.
