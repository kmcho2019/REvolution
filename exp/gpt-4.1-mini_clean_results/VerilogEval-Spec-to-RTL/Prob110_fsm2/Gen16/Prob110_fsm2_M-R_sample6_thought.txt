Refactor the FSM by explicitly separating next-state combinational logic and the state register update in two always blocks. This clearer separation improves code readability, synthesis tool friendliness, and aligns with common FSM design style. The asynchronous reset is kept on the sequential always block. The output remains a Moore output directly derived from the current state. This style uses a combinational always block to calculate next_state based on current state and inputs, and a sequential always block to update state on clock or reset.
