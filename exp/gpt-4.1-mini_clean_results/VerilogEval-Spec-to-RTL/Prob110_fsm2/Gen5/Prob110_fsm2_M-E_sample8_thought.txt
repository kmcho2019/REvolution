Implement the Moore FSM with a two-bit state encoding, explicitly defining two distinct states as 2'b01 and 2'b10. Use a separate combinational always block to compute the next state based on the current state and inputs, and an output always block that sets the Moore output based only on the current state. The state register uses asynchronous active-high reset. This approach separates next state logic from state register logic and the output generation, making the FSM structure very clear and modular. The output register is also registered (still Moore), maintaining timing consistency.
