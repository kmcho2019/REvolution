Implement the FSM using a two-bit state encoding with parameterized state names for clarity, even though only two states exist; the unused bit can be used to simplify extension or debugging. Use separate combinational always blocks to determine the next state and output signals, and then register the next state on the clock edge with synchronous reset. This approach separates next state logic and state register update for modularity. The output is generated from the state signal (Moore output). This explicit separation of combinational and sequential logic can improve readability, testability, and synthesis optimizations in some tools, especially when scaling up to more complex FSMs.
