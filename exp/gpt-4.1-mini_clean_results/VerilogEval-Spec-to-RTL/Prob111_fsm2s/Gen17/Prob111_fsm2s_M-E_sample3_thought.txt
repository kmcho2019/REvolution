Instead of using a single-bit state, we can implement the FSM with a two-bit state register encoding the states explicitly as 2'b00 for OFF and 2'b01 for ON, leaving the other encodings unused. The next state and output will be derived from this 2-bit register. This approach adds explicit state encoding and may facilitate easy extension to more states later. The output will be assigned combinationally based on the state to keep the Moore machine property. For the next-state logic, a simple combinational always block with if-else conditions is used. The synchronous reset sets the state explicitly to OFF (2'b00). This method also demonstrates a structural style for FSM design without using localparams, showing a different, more explicit encoding and control flow.
