Implement the Moore FSM using a one-hot encoded state register with two flip-flops: one for OFF and one for ON. This approach provides explicit clarity for state membership and can improve synthesis for certain technologies by allowing simpler decoding and state transitions. Use synchronous reset to clear both state bits and set OFF state bit. Compute the next state bits combinationally from current state bits and inputs, then update the state bits synchronously. Generate the output directly from the ON state bit since it's one-hot encoded, simplifying output logic to a simple wire assignment. This architecture differs by explicitly representing states as flip-flops rather than encoding in a single bit, which can aid testability and debug.
