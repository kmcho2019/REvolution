Implement the two-state Moore FSM using a one-hot encoding with two registers, one for each state (OFF and ON). This approach uses separate flip-flops to represent each state, which can simplify the combinational next-state logic and make state decoding trivial. The output can be directly driven by the ON state register. Use synchronous active-high reset to initialize the FSM to the OFF state. Next state logic will enable toggling between the two one-hot state registers based on inputs j and k.
