Implement the Moore FSM using a single always_ff block that combines both state update and output assignment. Instead of using separate state and output signals, encode the output directly as the state variable itself. Here, the state bit doubles as the output, since OFF=0 (out=0) and ON=1 (out=1). This eliminates the need for a separate output logic assignment. The next state is computed using a ternary operator inside the always block, providing a compact and efficient single-process FSM with synchronous reset.
