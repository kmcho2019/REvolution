Implement the Moore FSM with an enumerated type for states (OFF and ON) to improve code readability and maintainability. Use a two-process style: one combinational block determines the next state and output based on the current state and inputs, and one sequential block updates the state on the rising edge of clk with synchronous reset. The output is registered and follows the state as required for a Moore machine, but output is updated from the current state before state transition to emphasize the Moore output property. This separation of next state/output logic from state update better illustrates the FSM structure.
