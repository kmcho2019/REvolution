Implement the FSM by encoding the states as a 1-bit register but use the output register driven directly by the current state (Moore output). Use combinational logic inside the sequential always block to determine the next state based on the inputs and current state, thus avoiding a separate next_state signal and combinational always block. This minimizes the number of signals and simplifies the design. Reset synchronously sets the FSM to OFF state and output to 0. Using blocking assignments within the sequential block ensures clear step-by-step updates for state and output in the same clock cycle, maintaining a true Moore machine with output reflecting the present state.
