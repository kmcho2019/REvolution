Implement the Moore FSM using one-hot encoding with two flip-flops to represent the OFF and ON states separately. Use separate registers for each state bit, making the next-state logic simple by using direct assignments conditioned on inputs j and k. Output is generated directly from the ON state bit. This approach yields a clear mapping from states to registers, simplifies debugging as each state has its own flip-flop, and aligns with FSM synthesis tools that support one-hot encoding. Reset will synchronously clear the ON state and set the OFF state, ensuring the machine starts in the OFF state.
