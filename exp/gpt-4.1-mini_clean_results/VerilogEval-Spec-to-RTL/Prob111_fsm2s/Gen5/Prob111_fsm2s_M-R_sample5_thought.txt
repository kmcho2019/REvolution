Implement the Moore FSM using one-hot encoding for the two states with two flip-flops instead of a single-bit binary encoding. This approach uses two state bits (OFF and ON), where only one bit is set at a time. State transitions are encoded with combinational logic and assigned to the next-state registers. The synchronous reset initializes to the OFF state. The output is generated directly from the ON state bit. This refactoring provides explicit state bits, a different structural style, and may help some synthesis tools optimize or improve timing.
