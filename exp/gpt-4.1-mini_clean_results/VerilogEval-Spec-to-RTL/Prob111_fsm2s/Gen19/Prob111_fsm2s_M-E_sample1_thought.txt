Implement the Moore FSM using two always blocks to separate the state register update and next-state combinational logic explicitly. Use a two-bit state register with one-hot encoding for clarity and potential speed benefits. One always block will synchronously update the state on the clock edge with reset, while the other combinational block computes the next state based on the current state and inputs j and k. The output will be a simple combinational assignment from the current state. This approach improves modularity and eases future FSM modifications while leveraging one-hot encoding's simple decoding.
