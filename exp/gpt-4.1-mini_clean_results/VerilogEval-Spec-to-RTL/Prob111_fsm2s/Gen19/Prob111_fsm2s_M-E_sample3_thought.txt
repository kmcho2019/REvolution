Instead of using a single-bit state register, implement the FSM with two one-hot encoded flip-flops (one for OFF, one for ON), and use combinational logic to compute the next states. This approach can sometimes improve timing by reducing logic depth for state decoding and output generation, as outputs can be directly connected to state bits. The synchronous reset will force OFF state to 1 and ON state to 0. The output is simply the ON bit. This also allows clear and explicit state encoding, potentially making the FSM easier to debug or extend.
