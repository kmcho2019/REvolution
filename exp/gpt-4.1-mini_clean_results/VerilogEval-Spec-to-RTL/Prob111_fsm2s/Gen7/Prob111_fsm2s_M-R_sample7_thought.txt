I will refactor the FSM by implementing the next state logic and output logic inside a combinational always block instead of using continuous assignments. This approach explicitly separates the combinational logic for next state and output, which can improve readability and ease FSM extension. The synchronous reset and state update remain in a clocked always block, preserving the Moore FSM behavior. The state variable will remain one bit encoded.

This style is common and straightforward, showing the FSM as a classic pattern with clearly delineated combinational and sequential parts.
