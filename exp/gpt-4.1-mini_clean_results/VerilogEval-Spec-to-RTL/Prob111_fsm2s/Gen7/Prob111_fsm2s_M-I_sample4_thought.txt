To improve PPA, reduce combinational logic between state and output by assigning output directly from the registered state instead of next_state. This avoids using the combinational next_state signal for output assignment, reducing combinational path delay and potential glitches. Keeping output dependent only on the registered state ensures a true Moore output with minimal logic. Also, combine synchronous reset handling for state and output registers in a single always block with non-blocking assignments for clarity and synthesis friendliness. The state encoding remains 1-bit for minimal area, and separating next state logic combinationally preserves clarity and timing predictability.
