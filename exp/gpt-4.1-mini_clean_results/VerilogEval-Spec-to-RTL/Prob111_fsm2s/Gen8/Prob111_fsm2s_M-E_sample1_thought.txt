Implement the Moore FSM using a one-hot encoding style with two state flip-flops (OFF and ON) instead of a single binary-encoded state. Use combinational logic to determine the next state signals directly, and use synchronous logic to update the one-hot state registers on the rising edge of clk with synchronous reset. Derive the output directly from the state registers (output is high when ON state is active). This design uses two flip-flops for the state, simplifying next-state logic and clearly separating OFF and ON states, which can potentially improve timing and simplify debugging. The output is assigned combinationally from the state registers ensuring Moore semantics.
