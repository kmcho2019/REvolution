Implement a Moore state machine with two states: OFF and ON. 
- OFF state output is 0, ON state output is 1.
- On synchronous reset (active high), go to OFF state.
- Transitions:
  - From OFF, if j=1, go to ON; else stay in OFF.
  - From ON, if k=1, go to OFF; else stay in ON.
The output depends solely on the current state.
