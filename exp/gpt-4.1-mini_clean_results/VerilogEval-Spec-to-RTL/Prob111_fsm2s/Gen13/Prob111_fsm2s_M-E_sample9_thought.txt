Use a single always block driven by the clock that implements both state transitions and output assignment together, storing the output in a register. Encode the two states in a 1-bit register where 0 represents OFF and 1 represents ON. The synchronous reset clears the state to OFF and output to 0. The output is updated only on clock edges, ensuring it represents the Moore machine output for the current state. This approach combines state and output registers for a compact implementation without separate combinational blocks.
