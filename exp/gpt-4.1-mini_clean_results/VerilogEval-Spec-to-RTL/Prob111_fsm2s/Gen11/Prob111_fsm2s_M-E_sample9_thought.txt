Implement the FSM using a single always block that combines both the state update and output logic, utilizing a register to hold both the state and output as a 2-bit vector. The first bit represents the state (OFF or ON), and the second bit directly holds the Moore output. This encapsulates state and output together, avoiding a separate output assignment. On synchronous reset, set state to OFF and output to 0. This approach tightly couples state and output, providing a compact and alternative architectural style for a Moore FSM.
