Instead of using a single bit to represent the state, use an enumerated parameter type for clarity and extensibility. Implement the state machine with a separate combinational block for next-state logic and output logic to clearly separate combinational logic from sequential logic, which is a classic FSM coding style. This approach improves readability and maintainability, making the state and output assignments explicit. The output is assigned solely based on the current state (Moore machine). The synchronous reset sets the state to OFF.
