We can simplify by removing the for-loop and using direct combinational logic for next_state based on the current active states and input. Since the FSM is one-hot encoded, we can define next_state bits as the OR of all conditions that lead to that state. This avoids looping and case statements, resulting in clearer and more concise code.

For outputs, we keep the bitmask logic unchanged, as it is simple and efficient.

This approach:
- Uses direct Boolean expressions for next_state bits.
- Is purely combinational and straightforward.
- Maintains support for multiple simultaneous active states.
- Minimizes code size and complexity without changing behavior.
