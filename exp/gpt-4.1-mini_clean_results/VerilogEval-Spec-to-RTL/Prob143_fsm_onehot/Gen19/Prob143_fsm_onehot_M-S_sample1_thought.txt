Since the input state is one-hot encoded and multiple states can be active simultaneously, the next_state outputs can be generated by simply OR-ing the transitions that lead to each next state from any currently active state given the input. Instead of writing lengthy expressions for each next_state bit, we can precompute the next state masks for input=0 and input=1 conditions, then select the corresponding mask based on 'in' and AND it with the current state vector to find which next states are active. The result is the OR of these next states.

This can be efficiently done by defining two 10x10 transition matrices (one for in=0, one for in=1), where each row corresponds to the current state and each column to the next state. The next_state vector is the bitwise OR of the rows corresponding to active current states.

Since this is combinational logic and 'state' can have multiple bits set, we compute the next_state by OR-ing the rows indexed by active states (a matrix multiplication in Boolean algebra).

To avoid loops, we can implement the matrix multiplication by using bitwise operations: next_state = OR over all (state[i] ? trans[in][i] : 0).

This simplifies the design, reduces repetitive code, and is scalable if the FSM changes. Outputs are computed simply by masking current states as before.

This approach maintains full functionality with minimal logic and easier modification.
