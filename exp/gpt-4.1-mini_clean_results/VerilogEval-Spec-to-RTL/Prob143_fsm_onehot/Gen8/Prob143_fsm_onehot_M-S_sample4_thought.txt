The state machine's combinational next-state logic can be simplified by leveraging the input signal to select between two straightforward next-state vectors. Since all transitions on input '0' go to S0 except from S5 and S6 (which go to S8 and S9), and on input '1' most transitions move forward sequentially except from S7 which stays or goes to S0, we can construct next_state by selecting between two vectors derived from the current state and input.

We can achieve this by:
- Creating two next-state masks for input=0 and input=1.
- Using the input bit to select between these masks.
- Using simple AND and OR operations without enumerating every transition individually.
  
The outputs can remain computed by simple ORing of current state bits, since only S7, S8, and S9 produce outputs.

This approach:
- Reduces the number of explicit logical OR expressions.
- Uses concise bit-vector assignments with masking.
- Remains fully combinational and supports multiple active states.
- Maintains clear mapping to FSM behavior.

This yields a simplified, elegant, and efficient implementation.
