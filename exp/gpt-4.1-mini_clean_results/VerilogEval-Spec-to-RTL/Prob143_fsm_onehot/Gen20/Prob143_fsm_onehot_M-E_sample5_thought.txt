Use a modular decode-and-encode approach: First decode each active one-hot state into separate wires, then compute next states and outputs by logically combining these decoded states with the input signal.

This approach breaks down complex conditions into simple building blocks:
- Decode current states into individual signals (one per state bit).
- For each next_state bit, OR together the transitions from all contributing current states, each ANDed with input or ~input as needed.
- Outputs are also computed from decoded states using straightforward ORs.

This explicit decode-then-encode structure improves readability and modularity, making it easier to verify and extend. It also clearly separates the per-state next-state logic and output logic, enabling easier static timing analysis and potential pipelining later.

The combinational logic uses intermediate wires for each state's activation and next state contribution, avoiding large OR trees directly on inputs and outputs, potentially reducing synthesis tool complexity and helping optimization.

The logic still supports multiple active current states, correctly merging next states and outputs.

Overall, this approach makes the design more structured and explicit without loops or registers, providing clean, maintainable, and fully combinational logic suitable for synthesis.
