Refactor the combinational next_state logic from an always block with a for-loop to a purely declarative style using continuous assignments and intermediate wires.

Specifically:
- Create individual wires for each next_state bit representing whether that bit should be set.
- For each next_state bit, assign it as the OR of all possible transitions from current active states, controlled by the input.
- This approach eliminates loops and case statements in procedural blocks, enabling synthesis tools to better optimize parallelism and minimize logic depth.
- The output logic remains a simple reduction OR of masked current states.
- This approach enhances clarity by explicitly listing transitions per next_state bit and may improve synthesis results by exposing parallelism more directly.
- Since the FSM is relatively small, this unrolled combinational logic is manageable and aligns well with one-hot state encoding style.

Overall, this refactoring maintains the same logic but changes from iterative procedural to parallel combinational style for next_state, aiming for simpler, flatter logic and potentially better PPA results.
