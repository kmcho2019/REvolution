This solution implements the FSM transitions and outputs by first expanding the state input vector into individual booleans representing active states. Then, it calculates next_state bits by combining these booleans with input conditions, using bitwise ORs of state-based conditions that lead to the same next state. Outputs are computed explicitly with conditions matching their defined states. The design utilizes intermediate wires to express transitions clearly and modularly.

Advantages:
- Using intermediate wires for current states enhances readability and modularity.
- Next states are computed as ORs of conditions grouped by next state, facilitating easy modification or debugging.
- Outputs are assigned combinationally with explicit logic referencing current state bits, matching specification.
- The solution is fully combinational and straightforward, enabling easy synthesis and verification.
- Supports multiple active current states by OR-ing all possible transitions.
- No use of always blocks or registers, consistent with combinational next state and output logic.
