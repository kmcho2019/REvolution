Instead of directly ORing all transitions, decompose the next state computation by iterating over each current state and input value pair, generating an intermediate "candidate" next state vector for each possible state. Then combine all these candidate vectors with a bitwise OR to form next_state. This modular approach uses intermediate one-hot vectors representing the next states from each current state for both input=0 and input=1, and finally aggregates them. The outputs are computed similarly, by ORing the states where outputs are active. This approach emphasizes clarity and modularity, which can be easily extended or modified. It also allows simple addition or modification of transitions by editing local blocks.
