Refactor the next_state combinational logic to use parallel assign statements without a procedural block. Instead of iterating through states in an always block, explicitly compute each bit of next_state as an OR of all possible transitions from any active current state with the given input. 

This approach transforms the next_state computation into purely combinational assign statements, improving clarity and potentially allowing synthesis tools to better optimize logic parallelism and reduce latency.

The output logic remains bitwise masking and reduction to generate out1 and out2 signals.

This refactor:
- Eliminates the always block and loop,
- Uses clear explicit combinational assignments for each next_state bit,
- Maintains support for multiple active states in input,
- Enhances readability by listing transitions directly,
- Facilitates easier debugging and synthesis optimization.
