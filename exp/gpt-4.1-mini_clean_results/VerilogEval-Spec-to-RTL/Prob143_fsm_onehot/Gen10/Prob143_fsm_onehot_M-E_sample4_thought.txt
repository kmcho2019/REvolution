Instead of iterating over each active state to set next_state bits, I will exploit parallel bitwise operations to generate next_state bits directly based on the current states and input.

For each next state Si, I will define a logic expression that ORs together all possible current states and input conditions leading to Si.

This approach creates explicit equations for next_state bits as combinational functions of 'state' and 'in', enabling the logic to be fully parallel, potentially reducing critical path delay and simplifying synthesis.

Outputs will be computed similarly by combining the current state bits responsible for asserted outputs.

This method avoids loops or case statements and is more straightforward in hardware, leveraging the one-hot encoding.

The module remains combinational, suitable for synthesis. It naturally supports multiple active states since next_state bits are ORs of all triggering conditions.

This structural style also clarifies which states drive each next_state bit and output, aiding maintainability.
