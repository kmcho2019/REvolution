Since each state has only two possible next states depending on input 'in', and all outputs are zero except for states 7, 8, and 9 with fixed outputs, we can directly express next_state bits as combinational logic using simple ORs of the relevant current state bits.

By unrolling the for-loop and case statements into straightforward combinational assignments, we reduce complexity and improve readability. Also, outputs can be directly assigned by OR-ing the active states that assert them.

This fully combinational approach avoids loops and registers, making the logic simpler and equally correct for multiple simultaneous active states.
