I will refactor the design by replacing the always_comb block with purely combinational continuous assignments using assign statements. Each next_state bit will be computed directly as a combination of current states and input without intermediate partial vectors. This avoids multiple intermediate signals and reduces the number of assignments. Outputs will be directly assigned by ORing the relevant state bits masked by their output values. This structure improves clarity, reduces the number of signals and logic levels, and better exploits parallelism for synthesis tools. It also inherently supports multi-hot states since each next state bit and output depends on the corresponding current states combinationally.
