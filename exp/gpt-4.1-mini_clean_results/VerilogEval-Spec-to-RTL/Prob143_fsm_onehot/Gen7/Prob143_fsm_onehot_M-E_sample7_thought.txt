This solution implements the combinational next_state and output logic using explicit parallel logic assignments without loops or case statements, favoring direct boolean expressions derived from the state machine transitions.

The key idea is:

- Since the state machine is one-hot encoded and multiple states can be active, we compute each next_state bit as the OR of all transitions leading to that state from any current active states under either input=0 or input=1.
- For example, next_state[0] is the OR of all states that transition to S0 on in=0 plus those that transition to S0 on in=1 (if any).
- This direct approach produces flat combinational logic with minimal logic levels and no iterative constructs, facilitating better synthesis optimization and clarity.
- Outputs are generated by simple OR gates over relevant state bits.
- This approach makes the combinational logic fully parallel and easily extendable, avoiding loops, case statements, and intermediate variables.
- The design still handles multiple active states since all terms are ORed together.
- The logic expressions closely follow the given state transition table, and the outputs are assigned straightforwardly from the state bits.

This approach is well-suited to synthesis tools for efficient hardware implementation and gives transparent next state and output logic.
