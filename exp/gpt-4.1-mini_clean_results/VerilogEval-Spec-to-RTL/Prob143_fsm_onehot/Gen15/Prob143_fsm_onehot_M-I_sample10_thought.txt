To improve the PPA of the existing design, the next_state logic can be refactored to reduce logic depth and fan-in by avoiding iterative accumulation of next_state bits within a for-loop. Instead, compute each next_state bit as a direct OR of conditions checking all current active states that can transition into it given the input.

This creates parallel combinational logic for each next_state bit, enabling synthesis tools to optimize for minimal delay and area by better logic sharing and reduced multiplexing complexity.

The outputs remain computed as masked reductions on the current state for minimal overhead.

This approach eliminates the loop and multiple conditional updates, reducing the complexity of the next_state generation logic, thus improving timing and potentially lowering power due to fewer switching nodes and simpler gating logic.

The code will explicitly compute next_state[0] to next_state[9] by OR-ing all active states that lead to that next state given the input.

This trades some code verbosity for better synthesis results, as experienced from the feedback on priority chains and fan-in.

Overall, this approach should improve timing and power with minimal area impact while keeping the design fully combinational and straightforward.
