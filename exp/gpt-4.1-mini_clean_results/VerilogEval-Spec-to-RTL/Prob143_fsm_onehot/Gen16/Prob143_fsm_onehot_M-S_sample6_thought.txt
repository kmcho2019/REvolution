Simplify the logic by removing the for-loop and replacing it with direct combinational assignments for each possible current state bit. Since the FSM uses one-hot encoding, each next state depends on which single state bit is set, and the input bit, so next_state can be computed by a straightforward set of ORed conditions per bit. This avoids loops and complex accumulation and results in clearer, more direct combinational logic that synthesis tools can easily optimize. The outputs remain determined by fixed masks and can be assigned with simple reduction OR expressions on the current state bits. This keeps functionality intact but reduces code complexity and improves readability.
