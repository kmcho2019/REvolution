Simplify the design by using a single always_comb block with parallel assignments and avoid repeated if statements by directly encoding next state and output logic as combinational expressions. Since the current state can have multiple active bits, next_state bits are the OR of all transitions for each active state bit combined with the input. Outputs out1 and out2 can be computed as ORs of state bits with their associated output values without multiple conditional overwrites. This reduces code redundancy, clarifies the logic, and keeps functional correctness.
