Instead of writing out each next state condition explicitly with large bit masks, use a loop with a parameterized state index and encode the transition and output behavior in arrays. The module will iterate over all possible states, check if each is active, and, depending on input and the current state index, set the corresponding bits in the next_state vector and accumulate the outputs. This design uses for-generate and indexed assignment inside a combinational always block, making it scalable and easier to maintain. The output values for each state are stored in small arrays for quick lookup.
