Instead of encoding each state's next state logic individually with many OR gates, use a loop-like construct via generate or a vectorized approach with a parallel mux: for each active state bit, select the next state from a pre-defined lookup table (indexed by state number and input). Accumulate all these possible next states using bitwise OR. For outputs, combine the output conditions for all active states using bitwise OR. This approach treats the state transitions and outputs as simple parallel operations over the one-hot vector, allowing concise and scalable logic without large multi-input gates.
