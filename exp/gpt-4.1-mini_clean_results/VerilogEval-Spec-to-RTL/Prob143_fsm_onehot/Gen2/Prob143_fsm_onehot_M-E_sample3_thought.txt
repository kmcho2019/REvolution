Instead of iterating through each state bit and accumulating transitions and outputs, use vectorized logic expressions for each next_state bit and output signal. Since the state is one-hot encoded but multiple bits can be set simultaneously, the next_state vector can be computed as the OR of the next states resulting from each active current state combined with the input signal. By precomputing each next_state bit as a combination of the current states and the input, the logic is flattened and easily optimized by synthesis tools. Outputs can be similarly computed by OR'ing the states that activate them. This approach avoids loops and case statements and relies solely on boolean expressions, potentially reducing logic depth and improving area and power.
