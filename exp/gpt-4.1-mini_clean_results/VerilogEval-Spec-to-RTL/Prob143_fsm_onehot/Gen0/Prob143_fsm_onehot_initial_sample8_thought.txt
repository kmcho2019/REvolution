Implement the combinational next state logic and output logic for the given one-hot encoded FSM. The next_state bits are set according to the current active states in "state" and the input "in". Since the input "state" can have multiple bits set (indicating multiple active states), we compute next_state as the OR of next states for each active current state. The outputs (out1, out2) are asserted only for states S7 (out2=1) and S8 (out1=1); since multiple states can be active, outputs are the OR of the outputs of all active states. The outputs are zero for all other states.
