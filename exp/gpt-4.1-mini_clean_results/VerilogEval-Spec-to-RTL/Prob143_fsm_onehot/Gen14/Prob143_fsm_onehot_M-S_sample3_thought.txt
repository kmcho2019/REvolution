Simplify the implementation by using flat combinational expressions for all next_state bits without hierarchical grouping. Since the FSM has only 10 states and the logic is straightforward, the impact on fan-in is minimal and can be handled efficiently by synthesis tools.

Directly encode each next_state bit as the OR of all current states that transition into it on the given input condition. Outputs are directly assigned by checking the relevant states without intermediate signals or localparams.

This approach keeps the code minimal, easier to read and maintain, while fully preserving functionality and supporting multiple active current states.
