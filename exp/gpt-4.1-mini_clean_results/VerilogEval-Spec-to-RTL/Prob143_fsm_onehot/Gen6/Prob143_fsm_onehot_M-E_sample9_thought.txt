To implement the combinational next state and output logic for a one-hot encoded FSM with potentially multiple active current states, I will use a per-state approach that generates partial next state vectors based on the input and current state, and then combine them using bitwise OR. This approach treats each active current state as independently producing its contribution to next_state, which aligns well with one-hot encoding and supports multiple simultaneous active states. For outputs, I will directly encode the output bits from states that produce them. This modular and parallel approach simplifies logic replication for each state and can improve clarity and ease of optimization by synthesis tools.
