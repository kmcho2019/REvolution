We simplify the design by removing the explicit loop and using parallel assignments for each next_state bit, directly combining the contributions from all current states for each next state. This avoids the complexity of incremental OR inside a loop and makes the combinational logic clearer and possibly more efficient for synthesis. 

Since the machine is one-hot encoded with only 10 states, writing direct combinational logic for next_state bits is straightforward and improves readability. 

Outputs are kept as simple bitwise ORs of current states as before.

This approach retains full functionality and support for multiple active states, while reducing control logic overhead and simplifying the code.
