Since the FSM uses one-hot encoding and the current state input may have multiple bits set, each bit of next_state can be computed as a sum of mutually exclusive conditions where each active current state bit, combined with the input, determines a unique next state bit. The outputs are also simple OR combinations of certain state bits. We can simplify the code by using case-like conditions implemented via boolean expressions without enumerating every OR term, grouping the logic so that each next state bit directly depends on the input and a small subset of current state bits, thus reducing code size and improving readability while preserving functionality.
