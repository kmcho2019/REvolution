The given FSM is one-hot encoded, and multiple states can be active at once. Instead of a loop or case, this design implements next_state as a purely combinational vector computed by summing the contributions of all states independently, using bitwise operations.

For each state Si active (state[i]=1), the next state depends on input "in". We encode the transitions as bitmasks added together:

- For input=0, all transitions that go to Sx when input=0 are ORed together, masked by the active states.
- For input=1, similarly.

Thus, next_state can be computed as:
 next_state = (state & zero_input_mask) for input=0 states + (state & one_input_mask) for input=1 states

Since next_state bits correspond to the state indices, we can create a combinational function for each next_state bit that ORs all the states that transition there given the input.

Outputs are defined for certain states only, so output signals can be computed as ORs of current states with corresponding outputs. Because multiple states may be active, outputs are 1 if any such state is active.

This approach uses no loops or always blocks, only combinational bitwise logic assignments, improving clarity and potentially speed since synthesis tools can parallelize logic better without a for loop or case. It cleanly separates the logic for next_state computation and outputs, and leverages the power of bitwise operators to encode transitions succinctly.

This method is fully combinational and works correctly when multiple current states are active simultaneously.
