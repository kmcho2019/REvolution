Use a one-hot encoding for the FSM states with four states (A, B, C, D). Each state is represented by a single bit. This simplifies the output logic since grant outputs directly map to state bits. Implement synchronous active-low reset on the clock edge to initialize the FSM to state A. Use a combinational always block for next state logic with priority checks for requests when in A state and hold conditions in granted states B, C, D. Outputs g are generated combinationally by assigning grant bits according to the current state, exploiting one-hot encoding to directly drive grant signals, enhancing clarity and potentially easing synthesis of output logic.
