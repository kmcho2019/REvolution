To optimize the existing FSM for better Power, Performance, and Area (PPA):

1. Performance:
   - Maintain the 2-bit state encoding since it is already minimal.
   - Use non-blocking assignments in sequential always block (already done).
   - Separate combinational logic clearly to avoid combinational loops or unintended timing bottlenecks.

2. Power:
   - Register outputs 'g' to reduce glitches and switching noise.
   - Introduce a clock enable (ce) signal for the state register, activating flip-flops only when the state changes. This reduces unnecessary toggling, as the FSM often stays in the same state.
   - To generate ce, compare current and next state signals.

3. Area:
   - The current FSM is already compact.
   - No additional encoding or logic simplification appears beneficial.
   - Using a single always_comb block for next state and output logic helps with synthesis efficiency.
   
By registering the outputs and gating the state register clock via clock enable, we reduce power consumption with minimal impact on performance and no area penalty. The change also stabilizes outputs and can improve timing margins by breaking combinational paths from state to output signals.
