Since the FSM has only four states and the output grants correspond directly to each state (one for idle and one for each device grant), we can simplify the state encoding to 2 bits. Using 2-bit binary encoding for the states (A=00, B=01, C=10, D=11) minimizes flip-flop usage and simplifies the design.

The priority and next-state logic remain the same:
- State A (00): If any request is asserted, go to highest priority granted state (B for r[0], C for r[1], D for r[2])
- State B (01): Stay if r[0] stays asserted, else go back to A
- State C (10): Stay if r[1] stays asserted, else go back to A
- State D (11): Stay if r[2] stays asserted, else go back to A

Outputs can be derived combinationally from state encoding:
- g[0] = 1 if state == B (01)
- g[1] = 1 if state == C (10)
- g[2] = 1 if state == D (11)

This encoding reduces state register bits from 3 to 2 and slightly reduces combinational logic complexity while maintaining all FSM functionality and synchronous active-low reset.
