Use a 3-bit one-hot state encoding for the three grant states and use the all-zero state for the idle state A. This makes the output logic trivial, as each grant signal directly maps to a state bit. This can simplify the combinational output logic to just driving `g` from state bits.

Implement the FSM with the following states:

- A (idle): state = 3'b000
- B (grant device 0): state = 3'b001
- C (grant device 1): state = 3'b010
- D (grant device 2): state = 3'b100

Priority encoding is done in next-state logic: from idle state A, choose device 0 if r[0] is set, else device 1 if r[1] set, else device 2 if r[2] set, else stay idle. From any grant state, stay there as long as that request remains asserted, else transition back to idle.

Synchronous active-low reset forces idle state (A).

Outputs g are directly assigned from state bits, simplifying the output logic.

This one-hot encoding reduces logic levels on output and simplifies debugging and future extensions at the slight cost of one extra state bit.
