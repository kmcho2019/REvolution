Fuse the strengths of both examples by using a minimal 2-bit binary state encoding for the FSM states to reduce flip-flop count and area, improving power and area metrics while maintaining clarity and good performance:

- Use 2 bits to encode the four states:
    - 2'b00: A (idle)
    - 2'b01: B (grant device 0)
    - 2'b10: C (grant device 1)
    - 2'b11: D (grant device 2)
  
- This reduces the number of flip-flops from 3 to 2, thus reducing area and switching power.

- Maintain synchronous active-low reset to idle (A).

- Implement next-state logic in a combinational always block with a case statement on current state, respecting the priority of requests (r[0] > r[1] > r[2]).

- Output grants (g[2:0]) derived combinationally from the current state and input requests, consistent with the FSM behavior:
  - In state A, no grants (g=3'b000).
  - In states B, C, D, grant to device 0, 1, or 2 respectively.

- When a device is granted access, it stays granted as long as its request bit remains asserted; else FSM transitions back to idle.

- Using a binary encoding simplifies flip-flop count and generally reduces combinational logic area.

- Deriving outputs from state bits with a small combinational decoder reduces output toggling compared to one-hot outputs directly connected.

- Use blocking assignments in combinational logic and non-blocking in sequential logic, following best practices.

This fusion balances area and power improvements from binary encoding with the clarity and correctness of one-hot style next-state and output logic, resulting in a compact, efficient FSM implementation.
