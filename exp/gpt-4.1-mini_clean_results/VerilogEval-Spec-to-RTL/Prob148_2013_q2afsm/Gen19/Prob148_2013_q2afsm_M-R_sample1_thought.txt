Refactor the FSM by encoding states as a 2-bit binary instead of one-hot to reduce flip-flops and area. Assign states as:

- 2'b00: A (idle)
- 2'b01: B (grant device 0)
- 2'b10: C (grant device 1)
- 2'b11: D (grant device 2)

Use separate always blocks for state register and combinational next state logic, but implement outputs using continuous assignments to make output logic clearer and remove the always block for output.

The grant outputs `g` are decoded from the binary state using combinational logic with priority: only one grant bit asserted depending on the state, matching the active grant state. Reset behavior remains synchronous and active-low.

This refactor reduces flip-flop count, simplifies output generation, and maintains the same FSM functionality and priority scheme.
