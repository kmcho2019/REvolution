Refactor the FSM by using an enumerated type for states to improve code readability and maintainability. Use a single always block that contains both the synchronous state update and the combinational next-state and output logic to consolidate control flow. Outputs (grants) will be registered inside the always block alongside state updates to simplify timing and ensure outputs change synchronously.
