Use a binary-encoded FSM with two bits for the states:  
- 2'b00 = A (idle)  
- 2'b01 = B (grant device 0)  
- 2'b10 = C (grant device 1)  
- 2'b11 = D (grant device 2)  

Use synchronous active-low reset to state A.  
Next-state logic implements priority and holding grant while request is asserted, else returns to idle.  
Outputs `g` are assigned combinationally from the current state to activate the single grant bit accordingly.  
This reduces register count from 3 to 2 and simplifies logic while maintaining the same behavior.
