Implement the FSM with a binary-encoded state machine using 2 bits to represent the four states (A=2'b00, B=2'b01, C=2'b10, D=2'b11). Use a synchronous always block with a case statement for next state logic to clearly express priority and transitions. The output grants g will be combinationally assigned based on the current state. This approach minimizes flip-flop count, reduces state register width, and keeps the state transitions straightforward and easily modifiable. The synchronous active-low reset resets the FSM to state A.
