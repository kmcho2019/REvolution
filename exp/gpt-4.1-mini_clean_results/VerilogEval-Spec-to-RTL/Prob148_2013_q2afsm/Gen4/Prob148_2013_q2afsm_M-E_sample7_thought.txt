I will implement the FSM using binary encoding with 2-bit state registers to reduce area and possibly power compared to one-hot encoding. This compact encoding saves flip-flops and simplifies the next-state logic. The synchronous reset is active-low, as specified. To clearly separate concerns, I will use three always blocks: one sequential block for the state register, one combinational block for next state logic, and one combinational block for output logic. The outputs (g) will be assigned via a combinational always block to allow easy future modifications. Priority for grant assignment is given in the next state logic by checking request bits r[0], r[1], then r[2], in that order, ensuring device 0 has the highest priority. States A, B, C, and D will be encoded as 2'b00 to 2'b11, respectively. This approach yields a simple, efficient FSM design with minimal register count and straightforward combinational logic.
