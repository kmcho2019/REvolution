Implement the FSM using a binary-encoded state machine with four states (A, B, C, D) encoded as 2-bit values.  
State encoding:
- A (idle)   = 2'b00
- B (grant 0) = 2'b01
- C (grant 1) = 2'b10
- D (grant 2) = 2'b11

The next-state logic prioritizes requests in state A using a priority encoder: if r[0] is asserted, go to B; else if r[1], go to C; else if r[2], go to D; else remain A.

From grant states, stay in the state as long as the corresponding request remains asserted, else go back to A.

Output g is combinationally derived from the current state: only the grant corresponding to the current state is asserted (g[0] in B, g[1] in C, g[2] in D, none in A).

Use a synchronous active-low reset to initialize to A.

This binary encoding reduces flip-flop count to 2 and is a common approach for FSMs with four states, balancing logic complexity and area efficiently.
