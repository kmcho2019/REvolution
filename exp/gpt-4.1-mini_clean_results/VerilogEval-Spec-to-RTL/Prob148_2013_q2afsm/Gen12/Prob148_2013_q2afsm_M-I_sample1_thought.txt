To improve power, area, and timing (PPA), we will switch from one-hot encoding to a binary encoding of states using just 2 bits since there are 4 states (A, B, C, D). This reduces the number of flip-flops from 3 to 2, decreasing area and power. It also simplifies the state register and potentially improves timing due to fewer registers toggling.

State encoding (binary):
- A = 2'b00 (idle, no grant)
- B = 2'b01 (grant device 0)
- C = 2'b10 (grant device 1)
- D = 2'b11 (grant device 2)

Next state and output logic follow the original FSM rules with priority: device 0 > device 1 > device 2 when in idle (state A). When granted, stay in that state if the corresponding request remains; else return to idle.

Output g[2:0] is combinational based on current state:
- In B (01): g = 3'b001
- In C (10): g = 3'b010
- In D (11): g = 3'b100
- In A (00): g = 3'b000

Reset remains synchronous active low, resetting to state A (2'b00).

Use separate always blocks for sequential state update and combinational next state logic. Outputs will be assigned combinationally based on state.

This encoding reduces flip-flop count from 3 to 2, and should improve timing slack and power consumption while maintaining functional correctness.
