Implement the FSM using one-hot encoding for states to simplify output logic and potentially improve timing by reducing decoding logic. Use separate always blocks for state registers with synchronous reset, combinational next state logic, and combinational output logic. The state is encoded as a 4-bit one-hot register with four states: A, B, C, D. Assign outputs directly based on state bits without functions. This approach clarifies the grant outputs since only one bit of the state is high at a time, mapping naturally to grant signals, and avoids decoding functions. The priority logic in next state is handled explicitly with cascading if-else checks on requests r[0], r[1], and r[2].
