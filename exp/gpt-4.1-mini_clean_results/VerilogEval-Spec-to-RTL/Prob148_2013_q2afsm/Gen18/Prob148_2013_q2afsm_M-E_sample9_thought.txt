Use a binary-encoded FSM with 2 bits to represent the four states: A=00 (idle), B=01 (grant device 0), C=10 (grant device 1), and D=11 (grant device 2). This reduces the number of flip-flops from 3 to 2, saving area and potentially reducing power.

Implement synchronous active-low reset to state A.

Next state logic will be combinational using priority encoding to select grant state from requests when in idle, or to maintain grant state if the corresponding request persists; otherwise, return to idle.

Outputs g[2:0] will be generated by combinational logic based on the current state to assert grant signals only for the granted device.

This binary FSM approach lowers the number of flip-flops, minimizing area and toggling, which improves power and possibly performance due to reduced combinational complexity.

The design uses separate always blocks for the sequential logic (state update) and combinational next state logic as required, and outputs are generated via combinational assignments from state encoding.
