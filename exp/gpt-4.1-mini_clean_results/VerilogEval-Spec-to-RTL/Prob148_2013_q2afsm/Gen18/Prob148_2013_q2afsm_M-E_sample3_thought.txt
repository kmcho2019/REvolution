Implement the FSM using binary encoding for states to minimize flip-flop count (2 bits). Use a case statement in a combinational always block for next state logic and output generation based on the current state and input requests with priority logic embedded. Implement synchronous active-low reset in a separate sequential always block. Outputs g[2:0] are assigned in the combinational block based on the granted device per state. This binary encoding reduces area, and using a case-based next state logic clarifies state transitions and improves synthesis optimization possibilities.
