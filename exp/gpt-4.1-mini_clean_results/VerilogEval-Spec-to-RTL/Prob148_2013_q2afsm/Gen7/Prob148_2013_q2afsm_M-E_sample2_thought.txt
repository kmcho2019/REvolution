I will encode the FSM states using a 3-bit one-hot encoding to simplify state decoding and output logic, potentially improving synthesis optimization. The state flip-flops will be implemented with synchronous active-low reset. Next-state logic will be expressed with combinational logic that explicitly checks priority requests and current state. The outputs (grants) will be combinational and directly derived from the one-hot state bits for clarity and minimal logic delay. This design approach prioritizes clarity and synthesis friendliness through one-hot encoding, which can help with timing by reducing the logic depth in state decoding and output generation.
