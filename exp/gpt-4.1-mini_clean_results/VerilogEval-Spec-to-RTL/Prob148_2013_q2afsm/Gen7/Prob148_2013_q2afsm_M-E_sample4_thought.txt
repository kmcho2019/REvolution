Implement the FSM using a one-hot encoding scheme with four flip-flops representing states A, B, C, and D. Each state corresponds to one bit set high, enabling clearer next-state logic and potentially faster decoding.

- State flip-flops: 4 bits, one-hot encoding (A=0001, B=0010, C=0100, D=1000).
- On synchronous active-low reset, state A is activated.
- Next-state logic expressed in terms of one-hot state signals and inputs r, reflecting priorities:
  * From A: if r[0] -> B; else if r[1] -> C; else if r[2] -> D; else remain in A.
  * From B: stay in B if r[0], else go to A.
  * From C: stay in C if r[1], else go to A.
  * From D: stay in D if r[2], else go to A.
  
Outputs g are directly assigned from the state bits:
- g[0] = B state bit
- g[1] = C state bit
- g[2] = D state bit

This one-hot encoding simplifies output logic to direct mapping and makes the next-state logic straightforward, which can benefit timing and ease debugging.
