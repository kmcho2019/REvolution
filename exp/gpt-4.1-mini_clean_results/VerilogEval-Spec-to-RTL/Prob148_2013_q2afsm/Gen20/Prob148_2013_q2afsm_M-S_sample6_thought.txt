Simplify the FSM by merging states and using a single always block for both state transitions and outputs. Since each grant state corresponds directly to the granted device, we can store the grant index in the state itself (2 bits), using 0 for idle (no grant). This allows setting outputs directly from the state without separate output logic. We maintain synchronous active-low reset. This reduces the number of state encodings and logic branches while keeping the prioritization intact.
