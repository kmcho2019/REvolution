Use a binary-encoded FSM with four states (A=2'b00, B=2'b01, C=2'b10, D=2'b11) to reduce flip-flop count to 2 bits. Encode the priority selection logic combinationally: from idle (A), select grant state according to priority r[0], r[1], r[2]. In grant states B, C, D, remain as long as the respective request remains asserted, else return to idle (A).

Implement synchronous active-low reset to A. Use one always block for next state combinational logic and one for state register. Generate outputs g combinationally from current state: g=3'b001 for B, g=3'b010 for C, g=3'b100 for D, else 3'b000.

This binary encoding reduces FF count from 3 to 2, reduces area and power. Priority and outputs remain clean and clear. Separate next state logic and state register maintains good FSM design structure.
