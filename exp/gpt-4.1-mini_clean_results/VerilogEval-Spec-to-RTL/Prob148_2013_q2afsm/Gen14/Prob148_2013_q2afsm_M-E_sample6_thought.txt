This implementation will use a binary-encoded 2-bit state register instead of one-hot encoding to reduce area and possibly improve timing and power.

We define four states:
- A = 2'b00 (Idle, no grant)
- B = 2'b01 (grant device 0)
- C = 2'b10 (grant device 1)
- D = 2'b11 (grant device 2)

At each clock edge (posedge clk), with synchronous active-low reset, we update the state.

Next state logic:
- If in state A (idle), pick grant based on request with priority: device 0 > device 1 > device 2.
- If in grant state B, stay there if r0=1; else return to A.
- If in grant state C, stay there if r1=1; else return to A.
- If in grant state D, stay there if r2=1; else return to A.

Output logic sets g[i]=1 only for the granted device's state.

Using a binary-encoded FSM reduces flip-flop count (2 bits instead of 3) and makes output decoding explicit through a combinational always block with blocking assignments.

Separate always blocks are used for state register update and next state combinational logic, per good practice.
