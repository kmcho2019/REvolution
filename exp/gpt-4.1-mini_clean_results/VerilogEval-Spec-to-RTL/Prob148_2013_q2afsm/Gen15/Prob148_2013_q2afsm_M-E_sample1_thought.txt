Use binary encoding for states to minimize flip-flops and simplify state register size. Represent states A, B, C, D with 2-bit codes. Implement the next-state logic and output logic in separate always blocks: one combinational always block for next state decoding based on current state and requests, and one sequential always block for state updates with synchronous active-low reset. Outputs g are generated in a combinational always block based on the current state. This approach reduces area by using fewer flip-flops while still keeping the FSM logic clear and easy to follow.
