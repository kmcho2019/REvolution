The FSM only needs to distinguish among four states (A, B, C, D), so encoding the states with a 2-bit binary code instead of one-hot simplifies the state register and reduces logic complexity.

Assign states:
- 2'b00: A (idle)
- 2'b01: B (grant device 0)
- 2'b10: C (grant device 1)
- 2'b11: D (grant device 2)

Next-state logic:
- From A: choose highest priority request device:
  if r0=1 -> B; else if r1=1 -> C; else if r2=1 -> D; else stay A
- From B: stay in B if r0=1 else go to A
- From C: stay in C if r1=1 else go to A
- From D: stay in D if r2=1 else go to A

Outputs are combinationally derived from the state:
- g0=1 if state == B
- g1=1 if state == C
- g2=1 if state == D

Use synchronous active-low reset to go to state A. This binary encoding reduces flip-flop usage and simplifies output logic compared to one-hot encoding.
