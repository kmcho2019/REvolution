To improve PPA, we focus on reducing combinational logic delay and minimizing toggling.

Improvements:
1. Use one-hot state encoding (4 flip-flops) instead of 2-bit binary encoding. 
   This can improve timing by simplifying next-state logic and outputs to simple combinational AND/OR gates, thus lowering critical path delay.

2. Implement the grant outputs directly as the state flip-flops, removing extra decoding logic:
   - Each grant output corresponds directly to one one-hot state flip-flop.

3. Simplify next-state logic by using minimal combinational logic for each state individually, leveraging the one-hot nature.

4. Keep synchronous active-low reset.

This will slightly increase area due to 4 bits for state (instead of 2), but can reduce critical path delay and power due to simpler combinational logic and fewer logic levels on outputs.

Clock gating or other power optimizations are not implemented here as they require more complex infrastructure.

Overall, these changes trade a bit of area for improved timing and potentially reduced power by simpler logic.
