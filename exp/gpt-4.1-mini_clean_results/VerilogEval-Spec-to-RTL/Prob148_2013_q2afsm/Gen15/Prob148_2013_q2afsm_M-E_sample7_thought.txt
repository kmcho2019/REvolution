Implement the FSM using one-hot state encoding for clarity and simple combinational logic, which can sometimes improve timing by reducing decoding complexity. The four states (A, B, C, D) will be represented as 4-bit one-hot registers. Use separate always blocks for state flip-flops and next-state logic. The outputs (g) are driven directly by the one-hot encoded states: g[0] = B, g[1] = C, g[2] = D. The synchronous active-low reset initializes the FSM to state A. This approach results in straightforward next-state logic reflecting the priority system and allows easily interpretable output generation from state bits, trading off a few more flip-flops for potentially improved timing and maintainability.
