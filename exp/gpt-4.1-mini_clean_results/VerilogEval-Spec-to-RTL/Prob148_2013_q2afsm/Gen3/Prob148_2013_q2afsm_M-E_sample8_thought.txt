I will encode the FSM states using a one-hot scheme with four flip-flops to improve clarity and potentially reduce combinational logic delays. The synchronous active-low reset will initialize the FSM to state A. The next-state logic will be implemented using combinational logic that directly drives each state's next activation based on current state and input requests, respecting priority (r[0], r[1], r[2]). The grant outputs will be generated by a combinational always block that decodes the one-hot state into the grant signals, separating output logic for better modularity. This approach highlights different architectural techniques and provides clean separation of state, transition, and output logic.
