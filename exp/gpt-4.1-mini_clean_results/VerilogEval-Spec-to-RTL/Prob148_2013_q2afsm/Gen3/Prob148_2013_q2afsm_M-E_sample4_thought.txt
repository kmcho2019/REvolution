I will implement the FSM using binary encoding with 2-bit state registers to reduce area and power. To handle the arbitration priority cleanly, I will encode the states as A=00, B=01, C=10, D=11, and derive output grants based on state values. The next state logic will be fully combinational and use if-else priority checking on input requests r[0], r[1], r[2]. The synchronous reset is active low and resets to state A (00). The outputs (g) will be assigned via continuous assignments based on the current state to keep logic simple and transparent. This binary encoding reduces register and combinational logic size while preserving clear priority-based state transitions, potentially improving area and power without sacrificing timing.
