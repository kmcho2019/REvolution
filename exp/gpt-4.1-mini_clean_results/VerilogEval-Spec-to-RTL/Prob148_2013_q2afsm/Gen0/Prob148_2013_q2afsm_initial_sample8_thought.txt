Implement a 4-state FSM: states A, B, C, and D. State A is idle with no grants, B grants device 0, C grants device 1, D grants device 2. On reset (active-low synchronous), FSM goes to A. From A, based on priority and requests, transition to B, C, D or stay in A. From B, stay in B if r0=1 else go back to A; from C, stay in C if r1=1 else go to A; from D, stay in D if r2=1 else go to A (even though D state transitions were not explicitly mentioned, by symmetry and priority rules, we add it). Output g is based on state: g0=1 in B, g1=1 in C, g2=1 in D, else 0. Use one always block for sequential state update, one for combinational next-state logic. Use continuous assignments for output g.
