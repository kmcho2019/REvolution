Implement a 4-state FSM with states A, B, C, and D. On reset (active-low synchronous), go to state A. In state A, depending on input requests r[2:0], transition with priority: device 0 (r[0]) to B, device 1 (r[1]) to C, device 2 (r[2]) to D, or stay in A if no requests. In B, grant g0=1 and stay in B if r[0] is still asserted, else go back to A. Similarly in C, grant g1=1 and stay if r[1] is asserted else back to A. For D, no grants are given (g=0), and if r[2] is still asserted stay in D else back to A. Outputs are combinational based on the current state. Use separate always blocks for state register and next state logic.
