Implement a 4-state FSM with states A, B, C, and D encoded as 2-bit values. On synchronous active-low reset, go to state A. In state A, check requests with priority: if r[0]=1, go to B; else if r[1]=1, go to C; else if r[2]=1, go to D; else remain in A. In state B, grant g=001 and stay in B while r[0]=1, otherwise return to A. In state C, grant g=010 and stay in C while r[1]=1, else return to A. In state D, grant g=100 and stay in D while r[2]=1, else return to A. Outputs are combinational from current state. Use separate always blocks for state flip-flops and next-state logic.
