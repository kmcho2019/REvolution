Implement a 4-state FSM with states A, B, C, D representing no grant (A), grant to device 0 (B), grant to device 1 (C), and grant to device 2 (D). The FSM transitions on clock positive edge with synchronous active-low reset. On reset, state goes to A. In state A, decide next state based on requests r[2:0] with priority 0 > 1 > 2. In grant states B, C, D, grant remains active as long as corresponding request is asserted; otherwise, transition back to A. The outputs g[2:0] reflect which device has the grant (only one bit high or all zero). Use two always blocks: one for next state logic (combinational), one for state register (sequential). Outputs are assigned combinationally from the current state.
