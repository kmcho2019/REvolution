I will implement the FSM with four states: A, B, C, and D. State A is the idle state with no grants. B corresponds to granting device 0 (g[0]=1), C corresponds to granting device 1 (g[1]=1), and D corresponds to granting device 2 (g[2]=1). The priority is device 0 > device 1 > device 2. On reset (active low, synchronous), the FSM goes to state A. The state transitions follow the request inputs r[2:0]. The FSM remains in the grant state as long as the corresponding device keeps requesting. If the request ceases, it returns to A to arbitrate again. I will use an always block for the state flip-flops (posedge clk), synchronous reset, and another always block for next-state logic. The output g is assigned combinationally based on the current state.
