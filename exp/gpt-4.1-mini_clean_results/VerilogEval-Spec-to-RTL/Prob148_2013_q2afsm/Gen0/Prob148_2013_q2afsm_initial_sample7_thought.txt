Implement a 4-state FSM with states A, B, C, D encoded by 2-bit state registers. Use synchronous active-low reset to reset state to A. On each clock edge, the state transitions according to inputs r[2:0] based on the priority arbiter logic. From A, grant is given to device 0 if r0=1, else device 1 if r1=1, else device 2 if r2=1, else remain in A. States B, C, D represent grants to devices 0, 1, 2 respectively and maintain grant while the corresponding request remains asserted; otherwise, return to A. Outputs g[2:0] represent grants, with one-hot encoding matching the state B (g0=1), C (g1=1), D (g2=1). Use separate always blocks for state update and next state combinational logic. Outputs are assigned by a continuous assignment reflecting the current state.
