Design a three-state FSM (states A, B, C, and D) with 2-bit encoding. On synchronous reset, state resets to A. On each clock edge, transition based on input r and current state per given priority: device 0 (r[0]) highest, device 1 next, device 2 lowest. Grant outputs g are combinational based on state: in B g=001, in C g=010, in D g=100, otherwise 000. Implement state transitions with a combinational always block and state updates with a sequential always block on posedge clk. Synchronous active-low reset resets to state A.
