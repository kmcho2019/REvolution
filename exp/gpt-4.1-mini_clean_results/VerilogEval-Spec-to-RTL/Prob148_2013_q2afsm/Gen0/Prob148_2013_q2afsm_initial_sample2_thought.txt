Implement a 4-state FSM with states A, B, C, D. State A is the idle state (no grants), states B, C, D correspond to grants for device 0, 1, and 2 respectively. On reset (synchronous, active low), go to state A. In state A, check requests in priority order (r[0], r[1], r[2]) to decide next state. In grant states, remain in that state if request of that device is still asserted; otherwise, return to state A. Outputs g set based on the grant state. Use separate always blocks for state registers and combinational next-state logic, and continuous assignment for outputs.
