Implement the FSM with a one-hot state encoding where each state is represented by a bit in a 4-bit register. This avoids binary decoding and can simplify next-state and output logic. The four states are A (0001), B (0010), C (0100), and D (1000). The synchronous active-low reset sets state A. The next state logic is encoded in a combinational block that uses priority logic on the inputs to select the next state directly from the one-hot encoded current state. Outputs g are generated by directly mapping the state bits to grant bits, aligning grants to the matching state bits. This approach uses two always blocks: one for the state register and one combinational for next state, and uses continuous assignments for output. The one-hot encoding can make state decoding and output assignment more straightforward.
