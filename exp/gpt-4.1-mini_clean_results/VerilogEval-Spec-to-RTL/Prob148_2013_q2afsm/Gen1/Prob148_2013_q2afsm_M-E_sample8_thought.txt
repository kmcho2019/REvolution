I will implement the FSM with a one-hot encoding scheme using four flip-flops, one for each state A, B, C, and D. State A is the idle state with no grants, and states B, C, D grant device 0, 1, and 2 respectively. On reset (active low, synchronous), the FSM goes to state A. The priority logic will be encoded in the next-state combinational logic, checking requests with priority 0 > 1 > 2 only when in state A. For states B, C, D, the FSM remains in the grant state as long as the corresponding request remains asserted; otherwise, it returns to A. The grant outputs g[2:0] are directly driven by the one-hot state register bits corresponding to B, C, and D. This approach avoids state encoding decisions and simplifies output logic by directly mapping states to output signals.
