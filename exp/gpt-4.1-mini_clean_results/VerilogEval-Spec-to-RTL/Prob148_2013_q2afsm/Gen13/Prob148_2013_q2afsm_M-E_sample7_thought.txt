Implement the FSM using one-hot encoding with four flip-flops, each representing one state (A, B, C, D). This simplifies output logic because the grant signals can be directly derived from the state flip-flops.

States:  
- A: no grants, represented by one-hot bit 0001  
- B: grant device 0, 0010  
- C: grant device 1, 0100  
- D: grant device 2, 1000  

On reset, activate state A. The next state is determined based on the priority of requests during state A: if r[0] asserted, move to B; else if r[1], move to C; else if r[2], move to D; else remain in A.

When in a grant state (B, C, or D), stay there as long as the respective r[i] is high; otherwise, return to A.

Outputs g are assigned directly from the grant states, using the one-hot encoding to drive grants, which reduces logic complexity.

Use synchronous active-low reset for state initialization. Separate always blocks for state register and next state combinational logic as per the instruction.
