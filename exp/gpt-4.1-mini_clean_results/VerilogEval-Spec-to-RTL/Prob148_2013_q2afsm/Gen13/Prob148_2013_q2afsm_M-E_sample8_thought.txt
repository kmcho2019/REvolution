This solution uses a binary-encoded FSM with 2 bits representing the four states: A, B, C, D. The encoding is arbitrary but distinct:

- A = 2'b00 (idle state)
- B = 2'b01 (grant device 0)
- C = 2'b10 (grant device 1)
- D = 2'b11 (grant device 2)

Using binary encoding reduces the number of flip-flops (2 instead of 3 in one-hot). Outputs g are generated via a combinational logic block, mapping the current state to the grant signals.

The next state logic implements the requested priority:

- In idle (A), the next state is selected based on the highest priority request: r[0] first, then r[1], then r[2]; if none, remain in A.

- In grant states (B, C, D), the FSM stays in the same state as long as the associated request bit remains asserted; otherwise, it returns to idle (A).

Reset is synchronous and active low, resetting state to A (idle).

This approach simplifies the FSM state register, and the combinational next-state logic includes a priority check and state transition. The outputs are derived separately, ensuring clarity and easy modifications.

This encoding can help reduce area and dynamic power since fewer flip-flops switch. Also, the binary encoding may help timing by reducing register fanout.
