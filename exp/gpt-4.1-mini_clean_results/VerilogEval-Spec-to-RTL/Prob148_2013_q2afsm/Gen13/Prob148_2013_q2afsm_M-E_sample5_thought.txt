Implement the FSM using one-hot encoding for states A, B, C, and D, which simplifies output logic by directly associating each state's register bit with the grant outputs. Use a separate always block for the state register with synchronous active-low reset. Compute the next-state signals combinationally with priority encoded in the logic: in state A, check requests in order r[0], r[1], r[2] to determine next granted state, otherwise remain in A. In each granted state, stay if the corresponding request remains asserted; else return to A. The grants g[2:0] are assigned directly from the one-hot state registers (except A which grants none). This approach minimizes combinational logic for outputs and leverages one-hot simplicity.
