- Use a 2-bit binary state encoding since the FSM has only 4 states (A-D). This reduces flip-flop count from 3 to 2, decreasing area and dynamic power.

- Encode states as:
  - A = 2'b00 (idle)
  - B = 2'b01 (grant device 0)
  - C = 2'b10 (grant device 1)
  - D = 2'b11 (grant device 2)

- Implement the next state logic with clear priority: 
  - In idle, grant highest priority requesting device.
  - In granted state, stay granted if request persists; else return to idle.

- Outputs are combinationally decoded from state bits, which avoids unnecessary flip-flops driving the outputs.

- Use synchronous active-low reset to idle state.

- Separate always blocks for sequential (state register) and combinational (next state logic).

- Use blocking assignments in combinational always block and non-blocking in sequential block, following best practices.

This approach reduces flip-flops from 3 to 2 (area, power gain), simplifies output logic by decoding grant signals from state, and keeps the clear priority logic from both examples, leading to better overall PPA without sacrificing clarity or correctness.
