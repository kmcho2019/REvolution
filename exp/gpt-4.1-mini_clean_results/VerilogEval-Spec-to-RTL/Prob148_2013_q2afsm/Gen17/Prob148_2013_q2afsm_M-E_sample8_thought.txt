Use a binary encoded FSM with 2-bit state encoding to minimize flip-flop count and reduce area and power consumption.

Assign states as follows:
- A (Idle): 2'b00
- B (Grant device 0): 2'b01
- C (Grant device 1): 2'b10
- D (Grant device 2): 2'b11

Implement synchronous active-low reset that returns to state A.

The FSM next-state logic:
- In state A:
  - If r[0] == 1, go to state B
  - Else if r[1] == 1, go to state C
  - Else if r[2] == 1, go to state D
  - Else remain in state A
- In grant state B:
  - Stay in B if r[0] == 1; else go back to A
- In grant state C:
  - Stay in C if r[1] == 1; else go back to A
- In grant state D:
  - Stay in D if r[2] == 1; else go back to A

Outputs g[2:0] are combinationally derived from the state, where only one g bit is high corresponding to the granted device, zero otherwise.

Separate always blocks for state register and combinational next-state logic.

Use non-blocking assignment in the sequential always block and blocking in the combinational block.

This binary encoding reduces flip-flop count and should help timing and power without sacrificing clarity.
