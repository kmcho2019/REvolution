I will fuse the best practices from both examples by using separate always blocks for: 
1) synchronous state register with active-low reset, 
2) combinational next-state logic based on priority request signals, and 
3) combinational output logic solely for the grant signals. 

This separation clarifies the design, potentially improves timing and synthesis results, and makes the output logic purely combinational with no coupling to next-state logic. States will be encoded as 2-bit localparams with a minimal size for area efficiency. Priority logic remains straightforward with if-else conditions in the next-state block. Outputs are assigned in a dedicated always block for clarity and optimal mapping. The grant signals reflect the current state, not the next state, ensuring stable output behavior within each cycle.
