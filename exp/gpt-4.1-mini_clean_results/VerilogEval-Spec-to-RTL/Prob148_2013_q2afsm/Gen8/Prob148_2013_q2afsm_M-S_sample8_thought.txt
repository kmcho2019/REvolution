The FSM only needs to track which device currently has the grant or whether it is idle. Since only three devices are involved, and the priority order is fixed, we can encode the states minimally as 2 bits, just like before. To simplify, we can inline the output logic directly into the always blocks by using continuous assignments that depend only on the state bits, eliminating the explicit output always block. The next state logic is kept straightforward, prioritizing r[0] then r[1] then r[2] when idle, and holding grant states if requests persist. The synchronous active-low reset is retained. This keeps the design simple, compact, and easy to follow without unnecessary separation of combinational blocks.
