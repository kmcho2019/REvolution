I will implement the FSM using one-hot state encoding to simplify output logic and potentially improve timing by minimizing state decoding complexity. Each state will be represented by a single flip-flop bit. The next-state logic will prioritize requests by checking r[0], r[1], and r[2] in that order within combinational logic. The output grants g will be directly driven by the current one-hot state bits, enabling straightforward and glitch-free output encoding. The reset will synchronously clear all state bits except the state A bit. This approach reduces combinational decoding overhead and can improve synthesis optimizations for timing at a small area cost.
