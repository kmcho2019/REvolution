Implement the FSM using one-hot encoding for states to simplify output logic and state decoding. Use three separate registers for states A, B, C, D represented as one-hot bits. State transitions and output grants are directly derived from the active state bits. Use synchronous active-low reset. Use combinational always blocks for next state logic and output logic, and a sequential always block for state update. Grant outputs can be directly tied to the state bits, as each granted state corresponds to one grant bit being high. This architecture removes the need for decoding functions and keeps the FSM fast and easy to understand.
