To improve power and area, switch from one-hot encoding to binary state encoding, which reduces flip-flop count from 3 to 2. This also reduces switching activity and area. 

For timing, the binary FSM has smaller register count and simpler flip-flops, potentially improving timing slack. The next-state logic will encode states as 2 bits:

- A = 2'b00 (idle)
- B = 2'b01 (grant device 0)
- C = 2'b10 (grant device 1)
- D = 2'b11 (grant device 2)

The outputs g[2:0] will be assigned based on state: g=3'b001 for B, 3'b010 for C, 3'b100 for D, and 3'b000 for A.

The state transitions remain the same logic. Synchronous active-low reset sets state to A (2'b00).

Use separate always blocks for state flip-flops and next-state logic as requested.

This encoding reduces register count and combinational logic size, lowering power and area, and should improve timing.
