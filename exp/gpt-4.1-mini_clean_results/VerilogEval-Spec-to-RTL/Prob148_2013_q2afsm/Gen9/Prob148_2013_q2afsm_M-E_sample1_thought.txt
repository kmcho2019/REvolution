Implement the FSM with one always block for synchronous state update including active-low reset, and another always block for both next state and output logic combined to minimize logic duplication. Use a 3-bit one-hot encoded state register (A, B, C, D) to simplify output generation (each state directly maps to one grant signal). Outputs are assigned from the current state bits directly, eliminating the need for separate decoding logic. This approach makes the grant outputs purely combinational from the state bits, simplifying the design and potentially improving timing and power by reducing combinational logic depth.
