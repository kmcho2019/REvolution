Implement the same logic function from the K-map but using a small truth table ROM-like structure with a case statement for all input combinations. This is a novel architectural approach compared to direct logic expressions.

Inputs a,b,c form a 3-bit vector used as a case selector. For each input combination, the case outputs the corresponding result from the Karnaugh map. This approach can be useful for small functions as a lookup table style implementation and is functionally equivalent but structurally different from the direct OR gate logic.
