Implement the K-map function using a priority encoder style approach: since the output is 1 for all input combinations except when a=0, b=0, c=0, the only zero input is when all are zero. So the output can be implemented as 'out = a + b + c' or equivalently as 'out = !(~a & ~b & ~c)'.

To demonstrate a novel architecture, we will implement this by detecting the zero input condition explicitly using a 3-input NAND gate feeding into an inverter. This approach explicitly realizes the zero condition as an intermediate signal, then inverts it to get the output.

This approach uses basic gates to implement the logic as out = NOT (NOT a AND NOT b AND NOT c), showing an inversion of the zero condition, giving an easy way to detect the "all zeros" input.
