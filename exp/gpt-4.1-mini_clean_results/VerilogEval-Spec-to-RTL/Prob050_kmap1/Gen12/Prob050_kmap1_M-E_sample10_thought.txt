The function output is zero only when all inputs are zero, and one otherwise. This can also be realized as the negation of the AND of the inverted inputs: out = NOT(NOT a AND NOT b AND NOT c). Using De Morgan’s law, this is equivalent to a OR b OR c, but implementing it structurally using NAND gates to illustrate a different architecture. 

The design will:
- Invert each input using NOT gates
- AND the inverted inputs using a 3-input AND gate
- Invert the output of the AND using a NOT gate (or use a NAND gate with all inputs inverted)

This approach shows a different structural perspective using gates not used previously, emphasizing the NAND-NOT-AND logic decomposition of the function.

The implementation will define small gate modules for NOT, AND3, and NAND, then instantiate and wire them inside TopModule.
