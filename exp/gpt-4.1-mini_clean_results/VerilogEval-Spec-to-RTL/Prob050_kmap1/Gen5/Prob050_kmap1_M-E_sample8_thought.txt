Implement the logic by using a multiplexer (MUX)-based approach: treat inputs b and c as select signals for a 4-to-1 MUX whose inputs depend on a. From the K-map, output is 0 only when a=0 and b=c=0; for all other combinations output is 1. So, the MUX inputs can be designed accordingly: for select bc=00, output a (which is 0 when a=0); for other bc inputs, output 1. This demonstrates an alternative structural method using multiplexers rather than basic gates or direct expressions.
