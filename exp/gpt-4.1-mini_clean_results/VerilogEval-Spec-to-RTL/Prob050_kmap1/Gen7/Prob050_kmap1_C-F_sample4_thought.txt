The Karnaugh map outputs 0 only for input combination a=0, b=0, c=0, and 1 elsewhere. Thus, the function is the OR of inputs a, b, and c (out = a | b | c). The direct continuous assignment as in Example 2 provides minimal area and power, with no timing penalty.

Example 1 uses structural modules (inverters and NAND3) to implement the same logic but introduces overhead from multiple module instantiations, increasing area and power.
