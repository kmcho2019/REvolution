Instead of using continuous assignments, implement the TopModule using a sequential always block triggered on any change of the input vector. Store the input vector into a reg outv inside the always block, and also assign individual output bits o0, o1, and o2 from outv. This method leverages a small internal register, which could be useful if the outputs need to be sampled or synchronized downstream. The outputs are registered versions of the input bits, providing a slightly different architectural approach.
