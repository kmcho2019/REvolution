Use a generate block to assign individual bits of the input vector to separate output bits in a scalable way. The module will assign the 3-bit output directly from the input and then, inside a generate-for loop, connect each bit of the input vector to corresponding single-bit outputs named o0, o1, and o2 by using an array of outputs internally and mapping to the scalar outputs at the end. This approach avoids explicit submodule instantiation and makes the bit splitting pattern extensible. It also cleanly separates assignment logic while keeping the top-level interface flat.
