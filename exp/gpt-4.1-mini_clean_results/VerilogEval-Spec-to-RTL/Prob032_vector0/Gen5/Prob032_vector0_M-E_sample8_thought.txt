Implement the output splitting using a small always_comb procedural block instead of continuous assignments. In this approach, assign the output vector outv from the input vector vec inside the always_comb block. Then individually extract bits from outv to drive o0, o1, and o2. This design introduces a slight structural hierarchy and enables easy future extension for combinational logic within the block if needed, while maintaining the same functionality. It also demonstrates an alternative coding style for bit-splitting.
