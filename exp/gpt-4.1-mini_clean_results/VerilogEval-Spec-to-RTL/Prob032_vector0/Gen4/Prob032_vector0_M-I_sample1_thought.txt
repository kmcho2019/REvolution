To optimize for better PPA, I will replace the concatenated assignment of individual bits with explicit one-to-one assignments for o0, o1, and o2 from the input vector. This can help synthesis tools reduce unnecessary concatenation logic and slightly improve area and power. The outv output will still be directly assigned from vec to preserve minimal logic and routing. The explicit per-bit assignments also improve clarity on which bit maps to which output, following the spec strictly (o0 from bit 0, o1 from bit 1, o2 from bit 2).
