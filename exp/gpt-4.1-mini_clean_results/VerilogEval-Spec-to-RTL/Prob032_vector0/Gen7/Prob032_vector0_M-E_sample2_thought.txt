Use a generate block inside TopModule to assign each bit of the input vector to both the corresponding bit in outv and the separate outputs o0, o1, and o2. Instead of a separate submodule, leverage an array of outputs inside the module to hold the split bits, and then assign each output port from this array. This approach keeps all logic self-contained in TopModule, promotes scalability if more bits are added, and avoids additional module instantiations. The generate-for construct also demonstrates a parameterized style that can be easily extended.
