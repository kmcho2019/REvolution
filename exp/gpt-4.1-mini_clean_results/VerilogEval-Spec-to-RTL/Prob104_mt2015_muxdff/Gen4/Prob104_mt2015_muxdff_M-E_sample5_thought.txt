Implement the 2:1 multiplexer using an explicit always_comb block (always @(*)). Inside this block, select between `r_in` and `q_in` based on `L` and store the result in a reg `mux_out`. Then, use an always @(posedge clk) block to register `mux_out` into the output `Q`. This separates combinational mux logic and sequential logic using always blocks instead of continuous assignments, providing clearer modeling of combinational mux and sequential flip-flop.
