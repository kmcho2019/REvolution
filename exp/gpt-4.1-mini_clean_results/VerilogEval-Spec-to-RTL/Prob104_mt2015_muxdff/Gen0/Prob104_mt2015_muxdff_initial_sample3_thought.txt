The TopModule will implement a single bit flip-flop with synchronous load functionality. It takes inputs clk, L (load enable), q_in (the current stored value), and r_in (the new value to load). On the rising edge of clk, if L is asserted, the output Q will be loaded with r_in; otherwise, it will retain q_in. Internally, this can be factored into a 2:1 multiplexer to select between q_in and r_in based on L, followed by a D flip-flop clocked by clk that stores the selected value.

We implement the multiplexer and flip-flop behavior directly in this module. The output Q reflects the flip-flop output.
