Implement the FSM next state and output logic using a small ROM-like lookup table embedded as a combinational array indexed by concatenation of present state and input. This replaces multiple equality comparisons with a single vector lookup, which can simplify the logic and make scaling to more states easier. 

Specifically:
- Concatenate present state y[2:0] and input x into a 4-bit address.
- Define a 7-bit constant vector storing next_state[2:0], Y0 (same as next_state[0]), and output z for each address.
- Extract next_state and output signals by slicing the vector based on the address.
- This architecture clearly separates the combinational logic, avoids multiple equality checks, and can be synthesized as a ROM or LUT.
- Output Y0 is the LSB of next_state, directly from the lookup.
- Output z comes from the table as well.

This approach allows concise and easily extendable FSM encoding and can improve timing by using a single-level lookup rather than multiple conditionals.
