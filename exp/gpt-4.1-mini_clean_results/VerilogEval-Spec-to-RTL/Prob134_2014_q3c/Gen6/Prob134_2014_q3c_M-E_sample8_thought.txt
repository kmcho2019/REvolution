Implement the FSM next state and output logic using a simple synchronous state register and combinational next state logic expressed with continuous assignments instead of functions. Encode the present state using a 3-bit register. On each clock edge, update the state based on input x and current state y. The outputs Y0 and z are derived directly from the registered next state and present state respectively. This approach models a conventional Moore machine style with an explicit clocked state register inside the module, making the module fully self-contained, synchronous, and suitable for timing-driven synthesis.
