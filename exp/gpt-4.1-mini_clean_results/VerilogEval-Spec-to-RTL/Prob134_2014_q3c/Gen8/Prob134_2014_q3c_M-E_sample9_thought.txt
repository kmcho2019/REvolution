Implement the FSM using a two-dimensional lookup table encoded as registers or wires inside the module. The present state and input x serve as indices to this table, directly yielding the next state and output z. This approach uses a combined next_state_output vector to encapsulate both the next state and output in a single lookup, minimizing conditional statements and allowing synthesis tools to implement the FSM efficiently as a ROM or combinational LUT. The output Y0 is extracted as the least significant bit of the next state. Using a packed 4-bit vector per entry reduces complexity and improves scalability.
