Implement the FSM next state logic using a lookup table stored in a combinational read-only memory (ROM) style approach: a function that takes the concatenation of present state and input to index into a precomputed next state vector. This reduces code complexity and improves modularity. The output z can be computed using a simple bit pattern match or minimized combinational logic based on state bits. Y0 remains the LSB of the next state.

We keep all logic combinational except that the next state is purely combinational, as the present state is externally provided (input y). No internal state registers needed, making this purely combinational next-state logic module.

This approach is scalable for larger FSMs as well by just adjusting the ROM table content. It also avoids multiple case comparisons, replacing them with a single vector lookup indexed by {y, x}.

For z, note that z=1 only when y=011 or y=100. From the bits:

- 3'b011 = y[2]=0,y[1]=1,y[0]=1
- 3'b100 = y[2]=1,y[1]=0,y[0]=0

Expressed as logic:

z = (~y[2]&y[1]&y[0]) | (y[2]&~y[1]&~y[0])

This is a straightforward minimized expression, avoiding equality comparisons.

Overall, this method uses a compact combinational logic with a lookup table and optimized output, reducing code complexity and potential gate count.
