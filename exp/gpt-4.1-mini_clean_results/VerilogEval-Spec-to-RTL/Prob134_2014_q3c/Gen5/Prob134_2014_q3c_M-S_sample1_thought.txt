Simplify the design by implementing next state and output z logic using continuous assignments with conditional (ternary) operators instead of a combinational always block. This eliminates the need for a reg variable and always block, reducing complexity while preserving exact FSM behavior. The present state input y and input x combinationally determine next state Y and output z. Output Y0 is the LSB of the next state Y. Output z depends only on the present state y. This approach maintains readability, synthesizability, and direct logic mapping.
