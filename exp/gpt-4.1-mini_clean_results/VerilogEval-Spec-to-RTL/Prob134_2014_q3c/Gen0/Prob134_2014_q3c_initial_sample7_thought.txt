Implement a synchronous FSM with a 3-bit state register (Y) updated on the rising edge of clk. The next state logic depends on the current state (y) and input x, as per the provided table. Output z is combinationally derived from the current state and input based on the table, and Y0 is the LSB of the next state. The module updates the state each clock cycle, outputs z, and assigns Y0 accordingly.
