The FSM has only 5 valid present states out of 8 possible 3-bit patterns, and the next states plus output z are fully specified for those states. We can simplify by encoding next state and output directly using a combinational case statement indexed by present state y and input x, avoiding multiple equality checks. For invalid states, the next state can default to 000 and output z to 0. This approach uses a single combined 4-bit vector {y, x} for indexing, reducing complexity and improving readability and synthesis friendliness.
