I will implement the FSM using an explicit combinational always block with a case statement on the present state and input `x` combined as a 4-bit selector. This approach directly maps the present state and input to the next state and output signals simultaneously. Outputs will be registered as combinational assignments derived from the next state and present state, not stored in registers to keep the combinational behavior.

This method offers straightforward decoding logic without a separate function, making it easy to visualize the transitions. Output `Y0` is derived directly from the next state LSB, and `z` is assigned in the same always block, simplifying dependencies. The use of a single always block with a combined select signal (state + input) may aid logic synthesis in merging related logic, possibly improving area and timing. It also provides a simple and compact FSM description without any redundant logic.

The clock input is unused here since outputs depend only on current inputs, consistent with a combinational next state and output logic module.
