Instead of using a combinational case statement directly on the input state y, treat y as the current state stored in a register inside the module. Implement a synchronous FSM with an internal state register that updates on clk's rising edge, driven by the input x. The module interface provides the current state as input y for external visibility, but internally y is stored in a register. The next state logic uses a combinational function to determine the next state based on the current internal state and x. Output z depends on the present internal state. Output Y0 is the least significant bit of the next state. This way, the external input y acts as a "load" signal to initialize or override the FSM state asynchronously; otherwise, the FSM proceeds on its own clock.
