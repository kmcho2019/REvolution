Implement the FSM by encoding the output z as a combinational function of the present state y, and next state Y as a 3-bit vector selected from a set of registered possible next states pre-stored in ROM-like combinational logic. Use a parallel array of next states for x=0 and x=1 cases indexed by present state y, and select the next state based on x. Then derive Y0 and z as outputs accordingly. This separates the next state logic into a small memory lookup and uses indexing and multiplexing to implement next state selection.
