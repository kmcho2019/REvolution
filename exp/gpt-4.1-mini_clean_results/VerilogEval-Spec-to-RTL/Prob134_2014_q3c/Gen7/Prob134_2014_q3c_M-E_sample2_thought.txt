Implement the FSM using a one-hot encoded next state signal represented directly as a 5-bit vector, where each bit corresponds to one of the five states (000 to 100). This reduces the decoding logic needed for next state logic and output determination. 

Use combinational logic with explicit assignments to define the next state bits based on the current state input y and input x. Since y is a 3-bit input representing the current state in binary, decode it into one-hot internally.

Output z is derived directly from the present state y by checking if y corresponds to states 3'b011 or 3'b100, as per the original spec.

The output Y0 is the least significant bit of the next state encoded back from the one-hot next state vector. We first determine the next state's binary code from the one-hot vector, then assign Y0 accordingly.

This approach:
- Avoids function-based next state logic, simplifying hardware mapping.
- Exploits one-hot style logic to simplify next state combinational logic.
- Uses explicit combinational assignments, improving clarity and synthesis friendliness.
- Keeps the interface unchanged.
