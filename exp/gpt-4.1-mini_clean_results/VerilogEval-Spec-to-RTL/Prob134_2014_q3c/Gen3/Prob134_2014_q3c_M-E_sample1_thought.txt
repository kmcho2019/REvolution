Implement the FSM as a fully combinational function using a small ROM-like lookup table indexed by the concatenation of present state y and input x. This table directly outputs the next state and z. This avoids complex case statements and simplifies logic to table lookups, which can be easily optimized by synthesis tools.

Concretely:
- Form an address = {y, x} (4 bits).
- Use a combinational ROM function (via a case statement on 4 bits) that returns {next_state[2:0], z} packed in 4 bits.
- Extract next_state and z from this ROM output.
- Assign Y0 to next_state[0].

This approach creates a compact and elegant solution that is modular, easy to maintain, and can be scaled easily if the FSM grows. It also makes adding states or modifying transitions simpler by updating the ROM table.

Although using a ROM lookup increases explicit logic size slightly compared to a minimal case statement, it is conceptually clean and maps well to LUT-based synthesis in FPGAs or ROM-based logic in ASICs.

The module interface is preserved, and clk remains unused, but is retained as specified.
