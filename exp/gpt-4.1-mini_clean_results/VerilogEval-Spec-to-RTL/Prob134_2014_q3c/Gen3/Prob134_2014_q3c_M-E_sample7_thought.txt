Implement the FSM logic by encoding the next state and output z using a compact 2D lookup table (array) indexed by the current state y and input x. The lookup table holds the concatenation of the next state and output z bits. This approach unifies next state and output logic into a single simple combinational lookup, reducing the explicit conditional branching and improving clarity. Output Y0 is extracted from the stored next state bits. This technique is scalable, clean, and synthesizable for small FSMs.
