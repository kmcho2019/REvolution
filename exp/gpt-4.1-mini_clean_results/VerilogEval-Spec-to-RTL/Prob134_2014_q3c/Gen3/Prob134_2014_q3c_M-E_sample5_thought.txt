Instead of a combinational always block with case statements, use separate combinational functions to determine the next state and output z. These functions map the present state y and input x to the next state and output. Then instantiate a simple combinational logic block that calls these functions to produce the outputs. This modular approach enhances readability, maintainability, and reusability. The output Y0 is derived from the next state returned by the function. No clocked logic is included since the state is externally given.
