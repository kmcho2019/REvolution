To optimize the existing clean solution for better power and area, I will remove the use of Verilog functions and replace them with a single combinational always block using a case statement. This allows synthesis tools to better optimize logic sharing and potentially reduce area. I will implement both next state and output z computation in one always_comb block to share logic and minimize redundant decoding of present state. Also, I will explicitly handle the default state as 000, same as before.

This approach keeps the output Y0 as the LSB of the next state. It simplifies the combinational logic into one block instead of separate function calls, which can slightly reduce gate count and switching activity. Overall, this change maintains functional correctness while allowing better synthesis optimization for PPA improvements.
