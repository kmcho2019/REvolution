Treat the FSM as a purely combinational logic block where the present state is directly given by the 3-bit input y, and next state and output z are derived combinationally from y and x. Compute the next state based on the input y and x according to the given table. Then output Y0 as the LSB of that next state. Output z depends solely on present state y. No internal state register or clocked logic is needed since y already represents the present state externally.
