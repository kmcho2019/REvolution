Implement the FSM by encoding the present state and input in a single 4-bit vector (concatenation of state y and input x). Use a combinational always block with a case statement to directly assign the next state and output z. Then, register the next state y on the rising edge of clk to create a synchronous FSM. This approach uses a sequential process for state updates and a combinational process for next state and output logic, which is a common and clear FSM design style, different from the previous purely combinational approach. The output Y0 is extracted as the lowest bit of the registered next state. This method improves clarity, eases debugging, and facilitates future FSM expansions.
