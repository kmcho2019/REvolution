To simplify the FSM implementation while maintaining functionality, avoid explicit one-hot decoding and ternary conditions by directly using combinational logic expressions for the next state bits and output z derived from the FSM table. Each next state bit and output z can be expressed as simple Boolean equations using the current state bits and input x.

This removes intermediate wires and equality checks, reduces logic complexity, and keeps the code concise and efficient. The direct Boolean expressions are intuitive and optimize the design for smaller area and potentially better power without sacrificing readability or correctness.

Finally, assign Y0 directly as the LSB of the next state.
