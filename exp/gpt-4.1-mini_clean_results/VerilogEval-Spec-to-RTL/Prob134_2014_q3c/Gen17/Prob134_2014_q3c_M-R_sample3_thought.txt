Refactor the FSM logic by using a `case` statement on the present state `y` to directly compute the next state and output. This eliminates multiple one-hot decoders and uses a simple combinational block with a case for all valid states, mapping inputs and outputs per the table.

Advantages:
1. Single combinational block using case improves readability and synthesis tools often optimize case statements efficiently.
2. No explicit one-hot intermediate wires, reducing net count and potential switching.
3. Logic mapping is clearer and easy to verify.
4. Use of continuous assignments for outputs from the combinational block keeps the design clean.

The interface and behavior are unchanged; the next state and output logic are refactored for simpler, more compact combinational implementation.
