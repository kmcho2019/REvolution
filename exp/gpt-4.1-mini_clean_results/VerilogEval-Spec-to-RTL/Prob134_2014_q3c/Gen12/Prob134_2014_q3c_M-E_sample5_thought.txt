Implement the FSM using a small synchronous state register and a combinational next-state logic encoded as a ROM lookup table. The state register stores the current 3-bit state; the next state is determined by concatenating the current state and input x to form a 4-bit address used to index a precomputed next state vector and output z in a lookup table.

This approach encapsulates the FSM logic in a compact, easily extensible form, avoids multiple equality checks, and cleanly separates state and output logic. The output Y0 is extracted as bit 0 of the next state.

This ROM-like implementation uses a combinational always block or continuous assignments to define next state and output for all state/input combinations, returning default values for unused states to ensure safe operation.
