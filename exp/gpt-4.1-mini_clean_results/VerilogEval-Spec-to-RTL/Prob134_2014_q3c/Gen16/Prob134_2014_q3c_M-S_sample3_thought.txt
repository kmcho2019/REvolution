To simplify the design, avoid one-hot decoding and instead directly encode next state bits and output logic as Boolean functions of present state y[2:0] and input x. Using simple combinational logic expressions derived from the FSM table can eliminate the need for equality comparators and intermediate signals. This reduces logic complexity and area without changing behavior. The output Y0 is simply the next state's LSB, and output z depends on just two present states. This direct Boolean encoding will make the code concise and efficient.
