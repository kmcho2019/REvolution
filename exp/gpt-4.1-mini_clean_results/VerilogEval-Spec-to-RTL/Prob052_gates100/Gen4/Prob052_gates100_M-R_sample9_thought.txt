Refactor the design to use continuous assignment statements with Verilog's built-in reduction operators (&, |, ^) directly on the 100-bit input vector. This eliminates the explicit always block and the for loop, making the code more concise and idiomatic.

Using reduction operators allows synthesis tools to optimize the logic more effectively, potentially improving timing, area, and power metrics while preserving purely combinational behavior.

The outputs are declared as wire (default for outputs without reg), and each output is assigned directly by the corresponding reduction operator applied to the input vector.
