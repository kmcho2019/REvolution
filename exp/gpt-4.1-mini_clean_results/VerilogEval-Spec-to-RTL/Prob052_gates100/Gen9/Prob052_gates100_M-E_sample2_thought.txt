Implement a fully balanced binary tree reduction for all 100 inputs by padding the input vector to 128 bits (the next power of two), with zeros for AND and XOR padding and ones for OR padding, so as not to affect the logical results.

This enables a uniform recursive reduction using generate loops in log2(128)=7 stages, where each stage halves the number of signals by performing pairwise logical operations.

Padding:
- For AND: pad with 1 (neutral for AND) to avoid zeroing output.
- For OR: pad with 0 (neutral for OR) to avoid falsely asserting output.
- For XOR: pad with 0 (neutral for XOR) to maintain correct parity.

We build three reduction trees (AND, OR, XOR) simultaneously but re-use the same tree structure (indices) for clarity and scalability.

This approach:
- Avoids irregular group sizes and special handling of leftovers.
- Provides uniform and scalable structure for any input width (power-of-2 rounded).
- Balances fan-in perfectly at every stage with only 2-input gates.
- Results in predictable logic depth (7 stages).
- Enables straightforward extension for more inputs with minimal code change.

Intermediate signals are arrays of wires for each level, from 128 bits down to 1 bit final output.
