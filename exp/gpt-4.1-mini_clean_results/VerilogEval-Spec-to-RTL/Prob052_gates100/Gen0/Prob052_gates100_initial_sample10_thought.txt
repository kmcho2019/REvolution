Implement a combinational module TopModule with a 100-bit input vector `in`. The outputs are:
- out_and: reduction AND of all bits in `in` using the reduction AND operator (&).
- out_or: reduction OR of all bits in `in` using the reduction OR operator (|).
- out_xor: reduction XOR of all bits in `in` using the reduction XOR operator (^).

Using Verilog reduction operators simplifies this logic.
