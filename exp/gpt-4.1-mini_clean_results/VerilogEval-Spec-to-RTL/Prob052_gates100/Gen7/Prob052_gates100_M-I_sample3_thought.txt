To optimize the design for better power, performance, and area (PPA), I will replace the explicit loop-based combinational logic with Verilog’s built-in reduction operators (&, |, ^). These operators map efficiently to balanced gate trees during synthesis, improving timing by reducing logic depth and fan-in, lowering switching activity and glitch generation which helps power, and reducing overall gate count to save area.

This change keeps the outputs purely combinational without using registers or always blocks, leading to cleaner, more compact code that synthesizes to optimized logic.

The interface remains unchanged, and outputs are declared as wire by default (not reg) since continuous assignments are used. This style is simpler and directly conveys combinational intent.

Overall, this approach yields better PPA with the same correct functionality.
