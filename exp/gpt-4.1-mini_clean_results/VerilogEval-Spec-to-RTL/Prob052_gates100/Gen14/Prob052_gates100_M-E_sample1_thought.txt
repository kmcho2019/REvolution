Implement a purely structural design using a hierarchical tree of two-input gates to compute the 100-input AND, OR, and XOR functions. This approach uses a binary tree of small 2-input gates, progressively reducing the 100 inputs down to a single output for each function. The binary tree structure ensures balanced logic depth, which helps optimize timing and scalability.

This approach explicitly instantiates arrays of 2-input gates, avoiding reduction operators or procedural blocks. It demonstrates a clean modular design that could map directly to actual gate primitives or simple logic cells. The hierarchy reduces the fan-in of each gate to 2, simplifying synthesis, and can improve timing and area through balanced gate trees.

Outputs are final nodes of each reduction tree. Padding inputs with constant values (1 for AND, 0 for OR and XOR) to make the number of nodes a power of two simplifies the binary tree construction.
