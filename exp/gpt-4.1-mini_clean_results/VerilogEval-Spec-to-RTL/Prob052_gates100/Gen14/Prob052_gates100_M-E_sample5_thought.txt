Implement the 100-input AND, OR, and XOR using a fully hierarchical, 10-level 2-input tree reduction approach, which forms a straightforward balanced binary tree.

Each of the 100 inputs will be reduced pairwise in successive stages until a single output bit is obtained for each logic function.

Since 100 is not a power of two, handle the leftover odd inputs by promoting them to the next level without combination.

This approach ensures:
- Uniform 2-input gate fan-in, optimal for timing and synthesis.
- Simple and systematic code using a parameterizable generate loop and recursive reduction.
- Minimal logic depth (~log2(100) ≈ 7 stages).
- Small fan-in gates reduce power and glitches.

The code will:
- Create arrays for each level’s intermediate wires for AND, OR, XOR.
- On each level, combine pairs of the previous level’s results.
- Odd unpaired signals are propagated directly to the next level.
- Continue until only one wire remains, assigned to the outputs.

This approach differs from the earlier solution by strictly using 2-input reductions at every level, which is hardware-friendly and simple to analyze timing-wise.
