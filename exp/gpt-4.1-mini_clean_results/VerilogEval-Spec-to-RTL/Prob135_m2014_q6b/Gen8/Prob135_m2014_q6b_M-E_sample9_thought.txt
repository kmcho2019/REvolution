Instead of explicit decoding and a complex boolean expression, this design uses a simple combinational block with a case statement to directly implement the next state bit y[1] based on the current state y and input w. This approach maps the FSM states to next y[1] values by enumerating each relevant state transition, which enhances readability and matches the FSM behavior exactly without intermediate decoded signals. The output Y1 is assigned directly to the current y[1] bit, as required. This method is straightforward, easy to extend or modify for other bits, and reduces redundant logic by relying on direct pattern matching.
