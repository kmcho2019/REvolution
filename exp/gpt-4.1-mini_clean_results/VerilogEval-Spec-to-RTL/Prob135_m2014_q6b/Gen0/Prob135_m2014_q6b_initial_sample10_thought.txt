Implement a state machine with states A to F encoded as 3-bit values from 000 to 101.
Use the input 'w' as the control input for the transitions.
From the given state transition table, determine the next state y_next based on current y and w.
We only implement the logic for y_next[1] (the middle bit of the next state).
Output Y1 is just y[1].
Use a combinational always block to compute y_next[1] from current state and input w.
