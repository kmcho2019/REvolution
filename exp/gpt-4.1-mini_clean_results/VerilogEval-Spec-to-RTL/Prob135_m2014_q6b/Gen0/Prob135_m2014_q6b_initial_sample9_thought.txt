Implement a 3-bit state register y representing states A-F with codes 000 to 101. The next state depends on the current state y and input w according to the FSM transitions. We will only implement the next-state logic for bit y[1]. For all other bits, we do not specify logic (they can hold their current value or be zero). Output Y1 is assigned to y[1]. The design assumes synchronous updates on the positive clock edge. Since the clock is not specified, we will add a clock and reset for proper sequential logic.
