Implement a finite state machine (FSM) with states A-F encoded as 3-bit y values (000 to 101). The input w and current state y define the transitions. We only implement the next state logic for y[1] bit of the next state (y_next[1]). The output Y1 equals the current y[1] bit. We'll create combinational logic for y_next[1] based on current y and w, and assign Y1 = y[1].
