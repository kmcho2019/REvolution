Refactor by using a single always block triggered on the positive edge of clk and areset to directly implement asynchronous reset and synchronous logic without an intermediate next state register. Within this block, first check for asynchronous reset; if not active, check the synchronous signals load and ena with load having priority, then perform the corresponding assignment to q. This simplifies the design by removing the combinational next_q logic and consolidates all sequential assignments, keeping the same functionality but improving code compactness.
