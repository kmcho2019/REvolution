Implement the shift register using a 4-bit register that always shifts right on each clock when ena is asserted, but incorporate a priority multiplexer before the register input to select either the load data or shifted data, with load taking precedence over ena. This approach keeps the always block clean by assigning the next state to a variable first, then loading it in one assignment. Asynchronous reset clears the register immediately. This method separates the combinational logic from the sequential logic, improving clarity and potentially aiding synthesis.
