Fuse the clear modular next-state logic from Example 1 with the concise asynchronous reset and synchronous update from Example 2. Use a combinational always block to determine the next value of the shift register, giving load priority over enable, and preserving current state otherwise. Then implement the register update in a sequential always block with posedge clk and posedge areset for asynchronous reset. This cleanly separates combinational decision logic from sequential storage, improving readability and synthesis friendliness, while keeping minimal and efficient logic.
