Implement the shift register using a one-hot encoded state machine approach that selects the register update source via multiplexers controlled by load and enable signals. Use a synchronous process for loading and shifting, and implement the asynchronous reset using a separate asynchronous reset signal for the register. The right shift can be implemented by directly wiring the shifted bits with zero inserted at MSB. This approach uses minimal combinational logic by embedding the priority selection inside multiplexers and avoids explicitly defining next-state variables. The asynchronous reset uses a separate reset signal to the register for direct asynchronous clear, improving reset latency.
