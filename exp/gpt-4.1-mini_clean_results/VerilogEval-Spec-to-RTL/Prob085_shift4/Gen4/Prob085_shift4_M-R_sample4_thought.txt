Refactor the design by separating the next state logic into a combinational always block and updating the register `q` in a synchronous always block triggered by `clk` and asynchronous `areset`. The combinational block computes `next_q` based on the priority: reset handled asynchronously, load has highest priority, then enable causes shift, else retain value. This improves code readability by distinctly separating combinational next state logic from synchronous register update.
