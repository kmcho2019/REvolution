Implement a 4-bit right shift register with asynchronous active-high reset. On reset, the register clears to zero. On each clock's positive edge, if load is asserted, load the 4-bit input data into the register. If load is not asserted but ena is asserted, shift the register right by one bit, inserting zero at the MSB. If neither load nor ena is asserted, retain the current value. Since load has higher priority than ena, check load first. The asynchronous reset is triggered on the positive edge of areset signal.
