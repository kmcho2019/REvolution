Implement the shift register using a single always block sensitive to both the positive clock edge and the positive asynchronous reset. Inside the always block, prioritize the asynchronous reset first, then check synchronous load and enable conditions. The shifting operation is performed directly on the register without using an intermediate next state variable. The shift is implemented by concatenating zero with the upper bits of the register, and the priority of load over enable is enforced via if-else constructs. This approach is compact, directly associates state updates with clock/reset, and avoids extra combinational logic blocks.
