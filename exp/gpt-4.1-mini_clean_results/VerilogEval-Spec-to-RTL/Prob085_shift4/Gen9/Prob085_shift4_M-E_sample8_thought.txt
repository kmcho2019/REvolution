Implement the shift register using a concatenation approach inside the sequential logic: on every clock edge (or asynchronous reset), the register is updated either by loading the input data (if load is high), or shifting right by concatenating a zero at MSB and dropping the LSB (if ena is high and load is low), or holding the current value otherwise. The asynchronous reset is implemented as an asynchronous active-high reset (level-sensitive) that clears the register immediately when asserted. This approach directly uses concatenation in the sequential assignment and avoids intermediate combinational wires, providing a clean and compact design with clear priority between load and shift.
