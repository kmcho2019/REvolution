Implement the 4-bit shift register using individual flip-flops with parallel load and synchronous enable signals. Use the asynchronous reset to clear all flip-flops. On every clock edge, if reset is asserted, clear the register. Otherwise, if load is asserted, load the input data directly. If load is not asserted but enable is, shift the register right by one bit, inserting zero at the MSB. This approach explicitly models each bit update and prioritizes load over enable directly in the sequential logic without a separate next-state combinational block.
