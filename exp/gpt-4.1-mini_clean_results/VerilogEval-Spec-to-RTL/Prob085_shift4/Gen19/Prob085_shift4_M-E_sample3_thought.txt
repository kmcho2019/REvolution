Use a single always block triggered on posedge clk and posedge areset to implement the asynchronous reset within the same block. Inside the block, check the asynchronous reset first. If not in reset, handle synchronous load and enable signals with priority given to load over enable. For the shift operation, use a simple shift-right assignment by concatenating 1'b0 with the upper bits of the register. This approach combines asynchronous reset and synchronous control in one always block for a compact and readable design without using separate combinational logic for next state.
