Implement the 4-bit right shift register using four separate flip-flops, each representing one bit of the register. Use asynchronous reset with level-sensitive active-high signal so that if areset is asserted, all flip-flops clear immediately. On the rising edge of clk, if load is active, directly load the data bits into each flip-flop. Else if ena is active, perform right shift by assigning each bit from its left neighbor, with the MSB forced to zero. If neither load nor ena is active, hold the current value. This granular approach exposes each flip-flop explicitly and makes control signals very clear, while maintaining correct priority between load and ena.
