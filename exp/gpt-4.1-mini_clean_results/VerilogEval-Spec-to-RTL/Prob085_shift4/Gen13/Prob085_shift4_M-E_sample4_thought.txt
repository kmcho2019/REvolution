Implement the shift register using a set of individual flip-flops for each bit, updating each bit individually inside a single always block. On asynchronous reset, clear all bits. On the clock's positive edge, if load is asserted, load data directly; else if enable is asserted, shift bits right by assigning each bit from the previous higher bit, and insert zero at MSB. This bit-wise approach avoids using concatenations or intermediate next_q variables and directly expresses the shift logic. Priority of load over enable is naturally enforced by the if-else structure.
