Use a combinational logic approach inside the clocked always block that first evaluates a priority encoded next state for the shift register. On each clock edge or asynchronous reset, the shift register updates. If reset is asserted, clear the register. Otherwise, if load is asserted, load the input data. Else if ena is asserted, shift right by one position inserting zero at the MSB. If none of these, keep the current state. This approach explicitly computes the next state before the register update, enabling clear separation of combinational and sequential logic and easy extension.
