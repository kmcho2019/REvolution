Use a 4-bit shift register implemented as a set of four D flip-flops with a one-hot style load and shift control encoded in combinational logic. Instead of directly concatenating and shifting the register, compute the next state bits individually for each flip-flop. The asynchronous reset clears all flip-flops to zero immediately. On each positive clock edge, if reset is not asserted, check if load is asserted: if so, load data bits into respective flip-flops. Else if enable is asserted, shift right by assigning q[i] to q[i+1] with MSB assigned 0. This bitwise next state calculation provides clear separation of control logic per bit and maintains the priority of load over enable.
