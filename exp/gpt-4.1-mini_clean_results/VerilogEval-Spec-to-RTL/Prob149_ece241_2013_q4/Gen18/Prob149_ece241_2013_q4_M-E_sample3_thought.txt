Implement a finite state machine (FSM) representing the four water level states explicitly: BELOW_S0, BETWEEN_S1_S0, BETWEEN_S2_S1, ABOVE_S2. On each clock cycle, decode the sensor inputs to the new water level state. Compare the new state to the current state to determine if the water level is rising, falling, or steady. Use a registered current state and previous state for this comparison. The outputs fr0, fr1, fr2 depend solely on the current state and represent nominal flow valves. The supplemental valve dfr is asserted if the level is rising (new state > current state). On reset, set the FSM state to BELOW_S0 and outputs to all ones as per the requirement. This state-machine approach cleanly separates the level decoding, state transitions, and output generation, improves timing clarity, and makes output logic directly dependent on FSM states and transitions.
