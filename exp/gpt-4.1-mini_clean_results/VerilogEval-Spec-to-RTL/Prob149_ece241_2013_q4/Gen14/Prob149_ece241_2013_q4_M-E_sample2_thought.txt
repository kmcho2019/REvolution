Use a simple state machine with four states representing the water level zones: BELOW_S0, BETWEEN_S0_S1, BETWEEN_S1_S2, ABOVE_S2.

On each clock cycle, decode the sensor input s into one of these four states by matching the valid sensor patterns. If the pattern is invalid, treat it as BELOW_S0.

Keep a register 'last_stable_state' that stores the water level state before the most recent change. Whenever the water level state changes, update this register to the previous state.

Generate the nominal flow outputs fr0, fr1, fr2 directly from the current state.

Generate the supplemental flow output dfr by comparing current state to last_stable_state: if the water level is higher than last_stable_state (i.e., rising), set dfr high; otherwise low.

Use synchronous reset to initialize the system as if water has been below s0 for a long time (state BELOW_S0 with all flow outputs asserted).

This approach cleanly captures the previous stable water level before the last sensor transition by updating the 'last_stable_state' only when a change is detected, ensuring dfr reflects increases relative to that previous stable state.
