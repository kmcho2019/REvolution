The module monitors the 3-bit sensor input s representing water levels from low to high (s[0] lowest sensor, s[2] highest). Based on the sensor inputs and previous level, it controls flow rate outputs fr2, fr1, fr0 for nominal flow and dfr for supplemental flow.

Key points:
- When all sensors asserted (s=3'b111), water is above the highest sensor, so flow is zero (all outputs 0).
- When no sensors asserted (s=3'b000), below lowest sensor, maximum flow (fr2, fr1, fr0, dfr all 1).
- Intermediate states:
  - s=3'b011 (s[0] and s[1] asserted) => between s[2] and s[1], nominal flow fr0 only.
  - s=3'b001 (s[0] only asserted) => between s[1] and s[0], nominal flow fr0, fr1.
- Supplemental flow (dfr) should be asserted if the level has risen compared to the previous "last sensor change" level. This requires remembering the previous sensor pattern at the last sensor change.
- The state machine resets to "below lowest sensor" state (all sensors zero, all outputs 1).
- On each clock, if sensor input changes, update the stored last sensor state.
- Supplemental flow is enabled if the previous sensor state is "lower" than the current sensor state. Here "lower" means the previous sensor bits represent a lower water level than current.
- The flow outputs are set according to current sensor state (nominal flow), and dfr is set if flow level has risen.

Implement a simple synchronous logic with a register to hold previous sensor input at the last change. On each clock:
- If reset, set prev_s=3'b000 and outputs all 1.
- Else if s changes, update prev_s.
- Compute nominal flow and supplemental flow accordingly.

Define water level order by the number of sensors asserted from lowest to highest (higher sensor bits mean higher level):
- Use integer comparison of sensor bits or use their encoded meaning.

Outputs:
- fr0 asserted when flow rate includes fr0 in nominal flow.
- fr1 asserted when nominal flow includes fr1.
- fr2 asserted when nominal flow includes fr2.
- dfr asserted if current level > previous level.

Handle the reset and logic in a synchronous always block.
