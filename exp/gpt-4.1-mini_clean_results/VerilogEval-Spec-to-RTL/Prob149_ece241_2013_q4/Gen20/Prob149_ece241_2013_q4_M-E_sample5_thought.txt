Implement a finite state machine with explicit states representing the water level ranges, and store the previous stable water level state in a register. On each clock, update the current water level based on sensor inputs and compare it with the previous level. Use an enumerated type for states to avoid confusion in ordering.

The supplemental flow valve (dfr) is asserted only if the current level is strictly higher than the previous level, indicating a rising water level.

Outputs fr0, fr1, fr2 are combinationally derived from the current state per the nominal flow rate table, ensuring clarity and separation of concerns.

The previous level is updated only on a stable sensor input, and reset initializes the system to the lowest water level (no sensors asserted) with all valves open.

This architecture simplifies level detection by directly decoding sensor inputs to a state, comparing previous and current states to assert dfr, and cleanly separating combinational output logic from sequential state storage.
