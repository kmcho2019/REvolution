Simplify the design by representing water levels as one of four discrete states based directly on sensor inputs, using a simple combinational check.

Track the previous water level state in a register and detect a "rising" event as the current level being strictly higher than the previous level. Since sensor states change infrequently, this approach approximates "the level previous to the last sensor change" by sampling levels synchronously.

Map the nominal flow rates straightforwardly from the current level as per the table.

The supplemental flow valve (dfr) opens only if the current level is higher than the previous level.

On synchronous reset, set the previous level and outputs to the lowest level with maximum flow.

This approach reduces complexity by:

- Using simple enum states for levels.
- Using a single register for previous level.
- Comparing levels to determine rising.
- Assigning outputs combinationally based on current level and rising flag.

No extra functions needed, minimal logic, clear mapping, easy to verify.
