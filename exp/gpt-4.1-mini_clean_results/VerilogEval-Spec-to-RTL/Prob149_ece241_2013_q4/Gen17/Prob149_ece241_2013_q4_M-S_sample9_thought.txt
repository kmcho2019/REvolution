Simplify by tracking only the current and previous water level states as a 2-bit code representing sensor thresholds. On each clock cycle, update previous level to current level before capturing the new current level decoded from sensors. The supplemental flow valve (dfr) is asserted if the new water level is strictly higher than the previous water level, indicating the level rose. The nominal flow outputs (fr2, fr1, fr0) are driven directly by the current stable level using simple combinational logic. Use a synchronous active-high reset to initialize both levels to "below s0" state with all flow outputs asserted, ensuring correct start state. This approach keeps the design minimal while satisfying the requirements for flow rate and supplemental valve control.
