Fuse the area and power efficiency of binary encoding with the performance and clarity of one-hot FSM design by employing a Gray code state encoding. Gray code reduces the number of bit toggles between successive states, lowering dynamic power compared to binary encoding while keeping the state register width minimal (3 bits). Use synchronous active-high reset and separate always blocks for next state logic and state registers. Implement output logic combinationally with a continuous assignment for simplicity and minimal delay. This approach balances power, area, and performance effectively by minimizing flip-flop count, reducing switching activity, and maintaining clear, structured FSM logic.
