I will simplify the FSM implementation by using 2-bit encoding for states since 6 states can fit into 3 bits, but using 2 bits only is insufficient, so I'll keep 3-bit but simplify naming. I will also merge output logic into the combinational always block to reduce the number of always blocks, using one combinational block for both next_state and output, and one sequential block for state update. This reduces complexity while preserving functionality and synchronous reset.
