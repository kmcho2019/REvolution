Implement a synchronous FSM with states A, B, C, D, E, F encoded as 3-bit values. On every positive clock edge, if reset is asserted, the state goes to A. Otherwise, the next state logic is determined combinationally from the current state and input w. Output z is 1 only in state E; otherwise, z=0. Use one always block for state register, one always block for next state logic. Use continuous assignment for output z.
