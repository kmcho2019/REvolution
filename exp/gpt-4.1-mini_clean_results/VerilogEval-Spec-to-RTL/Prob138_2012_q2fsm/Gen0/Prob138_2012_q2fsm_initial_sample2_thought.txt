Implement a finite state machine with six states (A-F) encoded as 3-bit registers. The state register updates synchronously on the positive clock edge with synchronous active-high reset to state A. The next state logic is described in a separate always block as a combinational process based on the current state and input w. The output z is combinational and is '1' only in state E, '0' otherwise. Use a continuous assignment for z for simplicity.
