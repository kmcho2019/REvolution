I will implement a Moore FSM with states A, B, C, D, E, F encoded as 3-bit registers.
- Use one always block triggered on posedge clk to update current state on synchronous reset or next state.
- Use another always block combinationally to compute next state based on current state and input w.
- Use a continuous assignment for output z, since only state E and F produce output 1, others 0.
- The reset is synchronous active high and resets to state A.
