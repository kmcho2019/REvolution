Implement a 6-state FSM with states A-F encoded in 3 bits. On synchronous reset, state goes to A. Use one always block for state flip-flops triggered on the positive clock edge with synchronous reset. Use another always block to implement the combinational next-state logic based on current state and input w, as per given state transitions. Assign output z = 1 only in state E; otherwise z = 0. Output z is implemented using continuous assignment for simplicity.
