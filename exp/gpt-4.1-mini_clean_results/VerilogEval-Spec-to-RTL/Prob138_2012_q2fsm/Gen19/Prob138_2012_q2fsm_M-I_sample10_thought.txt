To optimize the FSM for better PPA (timing, power, and area), I will simplify the state register update logic by removing the conditional update enable, ensuring a consistent register update every clock cycle. This can help reduce combinational path delay and improve timing since gating clock or state updates can add delay. For area, the original 3-bit binary encoding is already efficient, so I will keep it. For power, I will keep output logic as a continuous assignment, minimizing additional gates or registers. The synchronous reset remains. This approach simplifies the state register while maintaining clarity and good coding style, which should improve timing with minimal impact on power or area.
