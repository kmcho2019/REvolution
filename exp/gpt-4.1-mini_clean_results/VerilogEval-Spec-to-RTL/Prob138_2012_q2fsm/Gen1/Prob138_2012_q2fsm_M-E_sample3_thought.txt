Implement the FSM using one-hot encoding with 6 bits for each state, simplifying decoding and reducing the chance of state encoding mismatch. The state register is a 6-bit register with one bit per state (A-F). On reset, state A bit is set. The next state logic is combinational and selects the next state based on the input and current one-hot state using separate always blocks. Output z is asserted only when in state E, implemented via a continuous assignment directly checking the state bit corresponding to E.
