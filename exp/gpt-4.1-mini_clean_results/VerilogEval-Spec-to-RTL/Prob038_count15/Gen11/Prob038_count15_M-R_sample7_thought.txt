Refactor the 4-bit binary counter by separating the next-state combinational logic from the sequential register update. Implement a combinational always block that calculates the next counter value by incrementing the current counter by one, handling the reset condition synchronously in the sequential always block. This separation improves readability and modularity while preserving the synchronous reset and increment behavior. The increment operation uses simple addition instead of bitwise toggling, which maintains clarity and synthesis friendliness.
