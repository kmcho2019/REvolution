Refactor the 4-bit binary counter by separating the combinational next-state logic from the synchronous state register update. This is done by computing the next count value in a combinational always block and updating the register in a sequential always block on the clock edge. The synchronous reset logic is integrated into the state register update block. This separation improves readability and aligns with common coding styles in FSM and counter design, making the design easier to modify or extend in the future.
