Refactor the synchronous 4-bit counter by splitting the increment logic into a separate combinational block and using a register only for the current state storage. Instead of incrementing inside the always block directly, compute the next state in a combinational always block based on the current state and reset, then update the current state synchronously. This separates combinational and sequential logic for clearer design partitioning, which is beneficial for readability and potential future modifications (like adding enable signals or different counting modes). The functionality and synchronous reset behavior remain unchanged.
