Fuse the modular clarity and enable-driven toggle approach of Example 1 with the clean separation of combinational next-state logic and synchronous update from Example 2. Specifically, implement the enable signals combinationally as in Example 1 to reduce unnecessary toggling on higher bits (which saves power), but compute the next state bits using XOR toggles conditioned on enable signals within a single always block to improve timing and area efficiency. Also, maintain synchronous active-high reset. This combined approach aims to reduce switching power by toggling only when needed, improve timing by consolidating logic in one always block using efficient XOR increments, and keep the design clean and modular without redundant logic or registers.
