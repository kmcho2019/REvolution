Refactor the 256-to-1 4-bit multiplexer by implementing the hierarchy with parameterized generic modules for N-to-1 muxes, using a recursive generate structure to build the 3-level hierarchy automatically instead of manually instantiating each stage.

- Define a generic 4-bit wide N-to-1 mux module parameterized by N (power of two), which selects a 4-bit input from a packed input bus.
- Use recursion via generate blocks in the top module to instantiate:
  - 16-to-1 muxes at stage 1, each handling 16 inputs (4 bits each) from the large input bus.
  - Then 4-to-1 muxes at stage 2 to select among outputs of stage 1.
  - Then a final 4-to-1 mux at stage 3 selecting among stage 2 outputs.
  
This recursive/generic approach:
- Improves code reuse and scalability.
- Avoids manual unpacking and packing of buses between stages.
- Uses direct indexing with part-selects and arithmetic to route inputs efficiently.
- Keeps the design combinational with `assign`, no always blocks, no intermediate arrays.
- Uses localparams for clarity of stage widths.

This structure keeps the original idea but changes the implementation style to be more generic and compact, facilitating easier adjustments for other mux sizes in the future.
