Simplify the 256-to-1, 4-bit multiplexer by directly indexing the input vector using a single continuous assignment without hierarchical mux modules. Since the 1024-bit input vector packs 256 4-bit inputs contiguously, we can compute the starting bit index as sel * 4 and select the corresponding 4-bit slice. This approach significantly reduces code complexity, requires no intermediate wires or submodules, and is fully combinational.
