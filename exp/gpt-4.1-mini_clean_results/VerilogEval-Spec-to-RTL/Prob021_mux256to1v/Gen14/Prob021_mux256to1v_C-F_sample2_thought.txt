Fuse the clarity and modularity of the hierarchical approach in Example 1 with the PPA advantages of direct indexing in Example 2. Use a three-stage hierarchical mux:

- Stage 1: 16 instances of a clean 16-to-1 4-bit mux implemented using `always @(*)` and case statements for explicit combinational logic, selected by sel[3:0].
- Stage 2: 4 instances of 4-to-1 4-bit mux using the same style, selected by sel[5:4].
- Stage 3: A final 4-to-1 4-bit mux, selected by sel[7:6].

Instead of unpacking inputs into 256 wires (which increases area and switching), slice the input vector directly at each stage using indexed part-selects for efficient logic. This avoids large wire arrays but retains modularity.

This fusion preserves:

- Hierarchical mux stages for improved timing and synthesis friendliness.
- Explicit combinational blocks for clear synthesis inference.
- Avoidance of unpacked arrays to reduce area and power.
- Parameterized, generate-based instances for code compactness and scalability.

This solution balances performance, power, and area by leveraging indexing and hierarchical muxing, making it superior to flat direct indexing (which may impact timing) and fully unpacked arrays (which increase area/power).
