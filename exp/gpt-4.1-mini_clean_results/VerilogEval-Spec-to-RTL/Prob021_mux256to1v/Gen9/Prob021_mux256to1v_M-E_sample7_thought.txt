Implement the 256-to-1, 4-bit-wide multiplexer as a fully hierarchical tree of 2-to-1 multiplexers built from continuous assignments, splitting the 8-bit selector into 8 stages.

At each stage, use the next bit of sel to choose between two 4-bit inputs, gradually reducing 256 inputs down to one output.

To realize this, first split the 1024-bit input into 256 4-bit words using a packed array, then construct a chain of 8 levels of multiplexers, each level selecting between two inputs from the previous level based on a bit of sel.

This approach generates a balanced binary mux tree, which can improve performance and scalability by evenly distributing mux fan-in.

It also clarifies the mux hierarchy and can be efficiently inferred by synthesis tools.

Use generate loops to construct each mux level wire array and avoid explicit case statements.

The output from the final level is the 4-bit output `out`.
