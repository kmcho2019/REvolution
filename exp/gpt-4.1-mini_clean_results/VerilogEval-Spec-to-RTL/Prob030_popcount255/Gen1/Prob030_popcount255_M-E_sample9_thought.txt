Implement the population count using a hierarchical adder tree approach: split the 255-bit input into 32 groups (31 groups of 8 bits and one group of 7 bits), compute the population count of each group using small parallel counters (e.g., 8-to-4-bit or 7-to-3-bit popcount modules), then sum all these partial counts using a balanced binary adder tree to produce the final 8-bit output.
