Implement the 255-bit population count using a fully balanced binary tree of adders starting from individual bits, avoiding fixed chunk modules. 

Specifically:
- Break the input into 255 single bits (1-bit wide inputs).
- Use a parameterized generic recursive popcount module that takes N 1-bit inputs and sums them with a balanced binary tree of adders, recursively pairing and adding sums until a single sum remains.
- This recursive module is purely combinational, parameterized by the number of bits N. It reduces complexity by uniform treatment of inputs rather than fixed-width chunk modules.
- At each recursive level, adjacent inputs are paired and summed using adders of appropriate width, padding the last input if the count is odd (without adding extra bits to the input vector, but conceptually treating the unpaired bit as is).
- The output width is computed as ceil(log2(N+1)) bits.
- The top-level module instantiates this recursive popcount module with N=255 inputs, outputting an 8-bit result (since max count is 255).
- This approach simplifies hierarchy, uses a generic implementation that can handle any number of input bits, and can be optimized by synthesis tools for parallelism.
- The design avoids separate LUT-based small chunk modules and instead relies on recursive summation of single-bit inputs, leveraging the synthesis tool's adder optimization.
- This is a clean, highly parameterizable, minimalistic solution that emphasizes a balanced tree of adders from bits directly.

This novel design contrasts with the chunk-based LUT approach by uniformly handling bits and recursive summation, allowing easier scalability and straightforward parameter changes for different input sizes.
