Implement a hierarchical popcount by splitting the 255-bit input into 85 groups of 3 bits each. Each 3-bit group is popcounted directly using a small lookup table or combinational logic, outputting a 2-bit partial sum (since max 3 ones = 3 in decimal fits in 2 bits). Then sum these 85 partial sums in a multi-stage adder tree using fixed-size adder modules, carefully chosen to minimize bit widths and adder complexity. This approach breaks down the large popcount into many small, very simple partial popcounts and a balanced summation tree, simplifying the combinational logic for each step. The final result fits into 8 bits (max 255 ones). This 3-bit chunk approach avoids bigger adders inside popcount blocks and uses only small, uniform building blocks, potentially reducing complexity and improving regularity and ease of synthesis.
