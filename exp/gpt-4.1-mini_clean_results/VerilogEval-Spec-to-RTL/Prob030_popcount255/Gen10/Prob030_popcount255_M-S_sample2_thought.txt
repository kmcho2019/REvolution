Instead of a recursive structure, implement the population count by directly summing all bits in a straightforward reduction using a for-loop inside an always_comb block. This approach is simpler and more readable, avoids generating multiple module instances, and is fully synthesizable. The result is an 8-bit count output, as needed for 255 bits. This reduces code size and complexity at the expense of possibly longer combinational paths, but satisfies the simplicity requirement.
