I will refactor the decade counter into a two-process style: a combinational next-state logic block and a sequential state register block. The combinational block computes the next value of the counter based on the current count and reset. The sequential block updates the counter on the positive clock edge.

This approach separates combinational logic from sequential updates, enhancing clarity and making it easier to integrate additional features such as enable signals. The synchronous reset still takes priority by forcing the next state to 0. This structure also clearly depicts the state machine style design, common in complex counters or FSMs.
