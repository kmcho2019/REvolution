Implement the decade counter using a 4-bit register that increments by one on each clock edge. When the counter reaches 9, the next increment resets it to zero. This is done using simple arithmetic and a conditional operator for wrap-around, which simplifies the logic compared to explicit state enumeration. The reset is synchronous active-high, setting the counter to zero on reset. This approach is straightforward, efficient, and synthesizes into a small, fast design with minimal logic depth.
