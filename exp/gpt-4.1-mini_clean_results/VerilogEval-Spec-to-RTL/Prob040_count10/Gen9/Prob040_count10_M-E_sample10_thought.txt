I will implement the decade counter using a simple 4-bit binary counter with a conditional synchronous reset when the count reaches 10. Instead of computing the next state combinationally before the register update, I will update the counter directly inside a single sequential always block triggered on the positive clock edge. The logic will increment the counter by one each clock cycle if reset is not asserted. When the counter reaches the terminal count (decimal 9), on the next increment it will reset to zero synchronously. The reset input will synchronously clear the counter to zero regardless of the current count. This approach keeps the logic minimal and contained in a single process, suitable for small counters and easy to understand.
