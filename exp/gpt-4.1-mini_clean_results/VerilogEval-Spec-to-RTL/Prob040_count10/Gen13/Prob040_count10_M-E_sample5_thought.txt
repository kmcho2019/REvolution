Implement the decade counter using a binary-coded decimal (BCD) incrementer with a combinational block that detects when the count reaches 9 and resets it to zero on the next cycle. To add novelty, use an always_ff style synchronous process for state update with a blocking assignment in the combinational next-state logic, emphasizing explicit use of arithmetic and conditional assignment without a separate next state register. This design integrates next-state computation and state update succinctly within a single sequential always block with synchronous reset, making the code compact and easier to maintain. The counter counts 0 through 9 inclusively and wraps around to 0 on the next clock edge after 9.
