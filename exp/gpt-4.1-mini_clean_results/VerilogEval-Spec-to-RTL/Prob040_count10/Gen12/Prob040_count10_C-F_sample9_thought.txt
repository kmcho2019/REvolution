Fuse the clarity and explicitness of the case-statement approach with the simplicity and minimal combinational logic of the increment-and-compare method. Implement the decade counter by incrementing the 4-bit register each clock cycle and reset to zero upon reaching 9, using a conditional assignment inside a single clocked always block. Add a default case fallback to catch invalid states, inspired by the case approach, by checking if the counter exceeds 9 and resetting to zero. This hybrid approach ensures robust fault tolerance, clear logic for synthesis, minimal combinational complexity for improved timing, and easy future extensibility. It also keeps synchronous active-high reset. This solution thus balances safety, simplicity, and efficiency.
