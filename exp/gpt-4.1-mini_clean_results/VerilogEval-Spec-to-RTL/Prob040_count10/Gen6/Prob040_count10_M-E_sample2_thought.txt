Implement the decade counter using a ring counter approach with a 10-bit one-hot encoded shift register to represent each count state from 0 to 9. On each clock cycle, rotate the '1' bit to the next position. The 4-bit binary output is generated by decoding the position of the '1' in the ring. On synchronous reset, set the ring to have the first bit high (representing count 0). This method reduces switching on the output q by avoiding binary addition and comparison logic and provides a different architectural perspective from a binary counter.
