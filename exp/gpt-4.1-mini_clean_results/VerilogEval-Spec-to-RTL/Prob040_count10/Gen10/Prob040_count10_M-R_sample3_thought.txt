Refactor the decade counter by separating the combinational next-state logic from the sequential register update. This means using a combinational always block (or continuous assignment) to calculate the next count value based on the current count, then updating the count in a synchronous always block triggered by the clock. This structure clearly distinguishes combinational and sequential logic, which can improve code readability and maintainability. The synchronous reset is still respected. This approach follows a classic Moore FSM style with separate state transition logic.
