Implement the decade counter using a one-hot encoding approach instead of a binary count. The counter will have 10 flip-flops, with only one set to '1' at any time representing the current count from 0 to 9. On each clock cycle, the '1' bit rotates to the next flip-flop, and when it reaches the last position, it wraps back to the first flip-flop. The output q is derived by decoding which one-hot bit is set into a 4-bit binary count. This design uses shift-register style counting and a decoder, providing an alternative architectural style and clear sequential state transitions.
