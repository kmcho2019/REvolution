Implement the decade counter using a 4-bit binary counter with a clear terminal count detection. Instead of computing the next state combinationally, use an always block triggered by the clock edge where the counter increments on each clock cycle unless it reaches 9, in which case it resets to 0 on the next cycle. The synchronous reset clears the counter to 0. This approach integrates both counting and wrapping logic within the sequential block, minimizing combinational logic outside the register update. This style is concise and leverages condition checks inside the sequential block for a clean design.
