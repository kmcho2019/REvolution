I will implement the decade counter using a single always block with synchronous reset and a simple state update that increments the counter until it reaches 9, then wraps back to 0. Instead of explicitly using a combinational next state variable, the counter state (q) is updated directly within the sequential block. This approach simplifies the code by merging next-state logic and state update in one process, which can reduce the area and slightly optimize timing by minimizing combinational logic stages between registers.
