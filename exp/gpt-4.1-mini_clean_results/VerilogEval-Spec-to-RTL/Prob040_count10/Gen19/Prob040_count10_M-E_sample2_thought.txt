Implement the decade counter using a 4-bit register and an asynchronous combinational next-state logic block that calculates the next count value based on the current count, but update the register synchronously on the clock edge. The counter resets synchronously to zero when reset is asserted. Instead of comparing to 9 to wrap, this design uses an arithmetic check on the 4-bit value and uses conditional logic for counting and wrap-around. This approach separates combinational next state calculation from sequential update, which can clarify timing and potentially aid synthesis tools in optimizing the design.
