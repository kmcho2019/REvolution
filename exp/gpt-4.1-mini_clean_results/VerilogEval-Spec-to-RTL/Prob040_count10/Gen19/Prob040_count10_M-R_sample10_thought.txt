Refactor the decade counter by separating the next-state logic from the state register update. Implement the next state as a combinational logic block using an always @* block, and update the q register synchronously in a separate always @(posedge clk) block. This separation improves code clarity and synthesis friendliness, while maintaining the same counting and synchronous reset behavior. Also, detect the terminal count through combinational logic and use that to reset the count to 0, otherwise increment by 1. This approach keeps the design simple and structurally clear without changing functionality.
