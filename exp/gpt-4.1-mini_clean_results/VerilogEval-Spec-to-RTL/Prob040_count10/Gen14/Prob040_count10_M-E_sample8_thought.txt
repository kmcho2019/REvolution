Implement the decade counter by explicitly coding the next state logic in a separate combinational always block that calculates the next count value, wrapping back to zero after 9, and updating the state register synchronously on the clock edge. Use a non-blocking assignment for state update and separate combinational logic for next state to improve readability and possible synthesis optimizations.
