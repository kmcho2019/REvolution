Refactor the decade counter by separating the combinational next-state logic from the sequential state register update. Use a wire to compute the next value of the counter based on the current value and reset, then update the register inside an always block on the rising clock edge. This structure improves code clarity by clearly defining next state logic separately from state storage, and facilitates easier modifications or extensions. The functional behavior remains the same: a synchronous active-high reset resets the counter to zero, and the counter counts from 0 to 9, wrapping back to 0.
