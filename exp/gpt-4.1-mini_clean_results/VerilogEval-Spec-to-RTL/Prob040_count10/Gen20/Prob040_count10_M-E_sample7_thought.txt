Implement the decade counter using a combinational next-state logic and a registered state, but separate the combinational and sequential logic into two always blocks. The sequential block updates the counter on the positive clock edge with synchronous reset. The combinational block computes the next state by incrementing the current state and rolling over to zero after 9. This clean separation enhances modularity and clarity, helps synthesis tools optimize the design, and enables easier modifications such as changing the counting sequence later.

Additionally, use non-blocking assignments only in the sequential block and blocking assignments in the combinational block, following best RTL coding practices.
