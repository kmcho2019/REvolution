Implement the decade counter using a synchronous up-counter with modulo 10 wrap-around by checking if the next incremented value exceeds 9. The counter will increment on each clock cycle if reset is not asserted; otherwise, it will be synchronously reset to zero. Instead of separating next-state logic into a separate signal, the increment and wrap-around logic is embedded directly within the sequential block for a compact design. The counter rolls over by setting q back to zero when it reaches 9. This approach reduces combinational logic outside the clocked block, potentially improving timing for designs sensitive to combinational path length.
