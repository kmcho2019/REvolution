Implement the decade counter using an up-counter that increments on every clock cycle and uses modulo arithmetic via a combinational circuit to reset after 9. Instead of explicitly checking if q==9 before incrementing, use an intermediate next count value that is (q+1) mod 10, implemented by a combinational function. On the positive clock edge, if reset is asserted, q is reset to 0; otherwise, q is loaded with the computed next count. This separates combinational next-state logic from the sequential register update, which can improve clarity and can help with certain synthesis optimizations. The counter output is still 4 bits wide, and the synchronous reset is active high.
