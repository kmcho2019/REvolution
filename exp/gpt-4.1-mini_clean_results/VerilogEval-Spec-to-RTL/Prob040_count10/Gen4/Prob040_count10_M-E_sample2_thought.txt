Implement the decade counter by using a ring counter approach with one-hot encoding internally to reduce decoding logic. Use a 10-bit one-hot register where each bit corresponds to a count value from 0 to 9. At each clock, the 'hot' bit shifts to the next position; when it reaches the last bit (representing count 9), it cycles back to the first bit (representing count 0). The output q is generated by encoding the current one-hot position to a 4-bit binary count. The reset synchronously sets the one-hot register to the first bit (count 0). This approach separates state representation from output encoding, avoiding explicit addition and allowing a potentially faster and cleaner hardware implementation for counting.
