Implement the decade counter using a one-hot encoding scheme where only one of the 10 bits is '1' at any time, representing the current count. The 4-bit output 'q' is decoded from the one-hot register using a priority encoder logic. The one-hot register shifts its '1' bit to the next position each clock cycle, wrapping from position 9 back to 0. This approach uses a shift-register style counter with synchronous reset. Although using a 10-bit one-hot register is larger than a 4-bit binary counter, it allows very simple next-state logic (just a shift and wrap) and potentially reduces switching on internal combinational logic. The 4-bit binary output is decoded combinationally from the one-hot register via a case statement or equivalent priority logic.
