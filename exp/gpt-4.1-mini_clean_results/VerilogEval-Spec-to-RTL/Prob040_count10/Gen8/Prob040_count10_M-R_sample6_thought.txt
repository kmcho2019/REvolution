To refactor the decade counter while maintaining the same functionality, I will implement it using a two-process style: a combinational next-state logic and a sequential register update. This structure separates combinational logic from sequential logic, which is common in RTL design for clarity and potential synthesis benefits.

Specifically:
- Create a 4-bit register q to hold the current count.
- Create a 4-bit wire next_q which is computed combinationally from q.
- next_q will increment q by 1 modulo 10 (i.e., reset to 0 when q is 9).
- The always block triggered on the posedge of clk will update q with next_q or reset q to 0 if reset is high.
  
This style is helpful to easily extend or modify state transitions and makes the design modular and readable. It also separates the combinational logic for next state from the sequential update logic.
