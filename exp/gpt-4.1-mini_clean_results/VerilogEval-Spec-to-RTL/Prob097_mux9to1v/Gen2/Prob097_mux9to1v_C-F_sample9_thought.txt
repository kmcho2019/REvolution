Combine the clarity and straightforwardness of the case statement approach with the compactness of indexing an array of inputs. Use an internal wire array for inputs a through i, then implement the output as a combinational always block with a case statement for sel=0..8 selecting the corresponding array element. For default cases (sel=9..15), assign all ones. This fusion keeps code readability, explicitness, and easy extensibility, while leveraging the array for neatness and avoiding repeated variable names in the case statement. It also uses a registered output (reg) for possible better synthesis results and easy debugging.
