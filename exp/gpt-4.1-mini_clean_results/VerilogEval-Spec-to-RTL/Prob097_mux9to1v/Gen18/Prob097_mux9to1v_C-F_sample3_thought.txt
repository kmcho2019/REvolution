Fuse the clarity and structured case statement control from Example 1 with the efficiency and simplicity of the continuous assignment approach from Example 2 by using a combinational always block with a case statement operating on an array of inputs.

This fusion:

- Uses an input array for clean, indexed access, improving maintainability.
- Employs an always @(*) combinational block with a case statement to explicitly enumerate all valid sel cases, giving synthesis tools clear mux control and aiding optimization.
- Outputs a constant 16'hFFFF for sel values 9 to 15, minimizing logic.
- Uses blocking assignments inside the always block for straightforward combinational logic.
- Keeps the output as reg for procedural assignment clarity.
- Improves synthesis friendliness by explicit selection, enabling optimized mux tree generation.
- Avoids the large conditional operator expression that may cause deeper mux logic.
- Allows clear defensive default and easily scalable to more inputs.
- Balances power, performance, and area by giving explicit mux structure for synthesis and maintaining simple combinational logic.

This approach blends maintainability, synthesis optimization, and code clarity better than the prior examples.
