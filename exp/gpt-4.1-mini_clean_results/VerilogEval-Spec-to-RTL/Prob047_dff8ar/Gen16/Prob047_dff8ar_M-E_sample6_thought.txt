Implement the 8-bit asynchronous reset D flip-flop register using an array of 8 individual single-bit D flip-flop modules. Each single-bit DFF has its own asynchronous active-high reset, positive-edge clock triggering, and output bit. The TopModule instantiates 8 of these single-bit DFFs, connecting each bit of input d to the corresponding DFF and collecting their outputs into the 8-bit output q.

This bit-sliced architecture emphasizes explicit bit-level modularity and fine-grained control, making it easy to extend or modify individual bit flip-flops independently. It may be beneficial when individual bits require different reset behaviors or enable signals in future modifications. It also improves readability by separating each bit's storage element explicitly.

The asynchronous reset is preserved at each single-bit DFF level with sensitivity to areset and clk edges. This approach trades off slightly more verbose code for explicitness and clear modularity.
