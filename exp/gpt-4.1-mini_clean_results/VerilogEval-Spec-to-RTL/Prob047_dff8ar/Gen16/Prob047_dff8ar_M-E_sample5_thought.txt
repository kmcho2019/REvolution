Implement the 8-bit register as 8 individual D flip-flops with asynchronous resets inside a generate-for loop to emphasize explicit separate flip-flop structures. Each flip-flop is independently reset and clocked. This design highlights the bitwise control and modularity while avoiding an extra module instantiation, making the design straightforward and clear.

The asynchronous reset and clocking will be done within the same always block for each bit using a generate loop. This approach can be useful when each bit might later be extended with bit-specific control or features, providing clear bit-level separation.

The TopModule thus contains only the generate loop inside itself, without additional sub-modules.
