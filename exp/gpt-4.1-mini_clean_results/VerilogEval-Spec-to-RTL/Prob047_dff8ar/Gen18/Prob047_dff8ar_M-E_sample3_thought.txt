I will design the TopModule by instantiating eight individual single-bit D flip-flops with asynchronous active-high reset. Each flip-flop will be a separate module to improve modularity and ease debugging per bit. This approach contrasts vectorized implementations by focusing on a fully structural style with explicit per-bit instances, enabling potential selective bit-level enhancements in the future. The asynchronous reset will be handled in each flip-flop using the sensitivity list on clk and areset. The top-level module will instantiate these eight DFFs using a generate loop for concise code, maintaining clarity while avoiding code repetition.
