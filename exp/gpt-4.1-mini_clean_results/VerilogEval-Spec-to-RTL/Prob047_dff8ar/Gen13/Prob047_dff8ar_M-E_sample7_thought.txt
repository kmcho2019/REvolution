Implement the 8-bit register as an array of eight individual single-bit D flip-flop modules with asynchronous resets. Each single-bit DFF module contains an always block with asynchronous reset and positive edge clock triggering. The TopModule instantiates these eight DFF modules in a generate loop, connecting each bit of input and output individually.

This design maximizes modularity and reusability by building on single-bit DFF submodules, while providing clear bitwise instantiations. It also demonstrates structural design style, which can help in certain verification or formal environments to clearly see individual flip-flop boundaries. Asynchronous reset is preserved per bit. This approach differs from a vectorized register in example 1 by emphasizing structural composition.
