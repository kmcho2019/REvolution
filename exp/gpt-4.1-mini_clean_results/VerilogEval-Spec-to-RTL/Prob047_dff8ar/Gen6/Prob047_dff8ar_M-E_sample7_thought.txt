Implement the TopModule using eight individual D flip-flops, each with its own asynchronous reset and clock input. Instead of writing a vectorized register, create a small DFF module with async reset for a single bit. Then instantiate eight of these modules inside TopModule, connecting each bit of the 8-bit input and output separately.

This per-bit modular approach promotes clarity and facilitates bit-wise control or future extension per bit. Although it might consume slightly more area, it improves testability and reusability of the single-bit DFF module. The asynchronous reset and positive-edge clock triggering remain as specified.
