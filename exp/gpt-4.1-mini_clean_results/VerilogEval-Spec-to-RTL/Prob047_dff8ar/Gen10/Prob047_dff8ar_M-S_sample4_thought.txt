To simplify the design and reduce area and power overhead, I will implement the 8-bit register with a single always block using a vectorized register. This approach will maintain the asynchronous active-high reset functionality while triggering on the positive edge of the clock for all bits simultaneously.

This method uses fewer lines of code, avoids module instantiation overhead, and should produce the same functionality: asynchronously reset all bits to zero and synchronously load the input data on clk's rising edge. It is a common and efficient pattern in RTL coding for multi-bit flip-flop arrays with asynchronous reset.
