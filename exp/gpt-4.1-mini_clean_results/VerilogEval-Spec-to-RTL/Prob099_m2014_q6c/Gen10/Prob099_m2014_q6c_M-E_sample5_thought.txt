Instead of directly decoding Y2 and Y4 from the current state bits and input w, implement a small combinational logic block that explicitly enumerates all transitions leading to states B and D. Use separate intermediate signals for clarity, then OR them to produce outputs Y1 and Y3. This approach allows straightforward addition of future states if needed.

Specifically:
- For Y1 (next state B): active when current state is A (y[0]) and w=0.
- For Y3 (next state D): active when current state is B, C, D, E, or F (y[1] to y[5]) and w=1.

By explicitly listing the conditions as separate terms, this design is very readable and modular.
