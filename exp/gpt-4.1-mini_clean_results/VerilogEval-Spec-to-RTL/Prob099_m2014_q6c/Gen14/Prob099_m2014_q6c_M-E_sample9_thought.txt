Create a combinational always block that decodes the current one-hot state and input w to produce outputs Y1 and Y3. Y1 corresponds to next state signal y[1] (state B) and Y3 corresponds to next state signal y[3] (state D). Instead of direct assignments, use case statements on the current state vector y, checking which bit is set, and then determine outputs based on the transition table. This architectural style makes it very explicit and easy to extend or modify.
