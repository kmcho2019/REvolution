Instead of directly deriving the next state signals from the current one-hot encoded state and input, I will implement a small combinational block that decodes the current state from the one-hot code, determines the next state based on the input `w`, and then encodes the next state back into one-hot form. From this next state one-hot vector, I will assign outputs `Y2` and `Y4` which correspond to the bits for states B (`y[1]`) and D (`y[3]`) respectively. This approach creates a more systematic state transition logic block that can be easily extended or modified, and cleanly isolates the combinational next-state logic from output assignments.
