Implement a combinational next-state decoder using an explicit case statement for each current state bit set in the one-hot input vector y. For each state (A to F), define the next state bits based on input w and output the next state bits Y2 (for B, y[1]) and Y4 (for D, y[3]). This approach directly uses the one-hot current state input and produces the desired next-state bits through a combinational case analysis, making the logic clear and scalable. The outputs Y2 and Y4 correspond exactly to the next-state signals of B and D respectively.
