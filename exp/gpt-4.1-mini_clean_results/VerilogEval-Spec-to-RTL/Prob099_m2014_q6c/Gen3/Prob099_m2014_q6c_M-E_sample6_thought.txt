Instead of directly using combinational expressions by inspecting the state bits, implement the next-state decoding using a small combinational decoder that maps the current one-hot state and input w to the next-state signals. This allows us to clearly show the translation from current state and input to next state outputs.

We will create explicit logic equations for Y2 and Y4 corresponding to y[1] (B) and y[3] (D), derived from the transition table:

- Y2 (next state C, y[2]) is asserted when:
    - From state B (y[1]) and w=0
    - From state F (y[5]) and w=0

- Y4 (next state D, y[3]) is asserted when:
    - From state B (y[1]) and w=1
    - From state C (y[2]) and w=1
    - From state E (y[4]) and w=1
    - From state F (y[5]) and w=1

Express these equations explicitly in code.

This approach keeps the one-hot encoding and explicitly shows how next states are derived combinationally from current states and input.
