The FSM has the following behavior:
- State A: wait for s=1 to move to state B. Output z=0 here.
- State B: repeatedly check w for exactly 3 clock cycles, counting how many times w=1.
  After counting 3 cycles, output z=1 if exactly two of the three were 1, else 0.
  Then reset the 3-cycle count and w count to repeat this check indefinitely.
  
Implementation idea:
- Use two states: A and B.
- Use a 2-bit counter to count the number of clock cycles in state B (0 to 2).
- Use a 2-bit register to count the number of w=1 occurrences during these 3 cycles.
- On the 4th cycle (count == 3), output z=1 if w_count == 2, else 0.
- On reset, go to state A and clear all counters and outputs.
- s is only checked in state A.
- The output z is registered and updated one cycle after counting the three w inputs.

This minimizes states and logic.
