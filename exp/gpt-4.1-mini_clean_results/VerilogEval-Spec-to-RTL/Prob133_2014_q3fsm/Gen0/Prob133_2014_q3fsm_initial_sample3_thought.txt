Implement a FSM with four states: A (reset state), B0, B1, B2 to track the three cycles in state B while counting the number of times w=1. 
- Start in state A on reset.
- In state A, stay if s=0, move to B0 if s=1.
- In states B0, B1, B2:
  - Count how many times w=1 in these three cycles.
  - After the third cycle (in B2), output z=1 if exactly two of the three w inputs were 1, else z=0.
  - Then return to B0 to start counting next three cycles.
Use a 2-bit counter to track how many times w=1 in the current 3-cycle window.
Implement synchronous reset and synchronous state and output updates.
