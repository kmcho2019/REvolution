We have a FSM starting in state A. When s=0, stay in A; when s=1, go to B.
In state B, we look at w for the next three clock cycles, counting how many times w=1.
After three cycles, if exactly two of the w inputs were 1, output z=1 for one cycle; else z=0.
Then repeat the 3-cycle counting again in state B.
We can implement this with:
- State A and state B
- In state B, have a 2-bit counter for the 3 cycles (0 to 2)
- A 2-bit counter or register to count how many times w=1 in these 3 cycles
- After 3 cycles, generate z accordingly for one cycle and reset the counters for the next 3 cycles.
- Reset is synchronous and active high.
All logic triggered on posedge clk.
Output z is asserted for one cycle after the counting is done.
