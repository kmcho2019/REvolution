Implement an FSM with states A, B0, B1, B2, and B3, where:
- A is the reset state, waiting for s=1 to transition to B0.
- B0 to B2 track how many of the 3 w inputs have been 1 so far.
- At each clock in B states, we check w, move to next state, and increment count if w=1.
- After 3 cycles (at B3), output z=1 if exactly two w=1's were detected; else z=0.
- Then return to B0 to start a new 3-cycle counting.
- s is ignored in B states.
- reset is synchronous and active high.
- Use one-bit register(s) to count number of w=1s seen in the 3-cycle window (0,1,2 or 3).
- States can be encoded with 3 bits to track state and count.
