Implement a FSM with minimal states: start in state A waiting for s=1; once s=1, move to state B. In state B, count three consecutive clock cycles of w input, counting how many times w=1. After collecting three samples, check if exactly two are ones, then output z=1 for one cycle; otherwise z=0. Then restart the 3-cycle counting process, staying in state B. Reset synchronously brings FSM to state A with z=0. Use a 2-bit counter to count cycles and a 2-bit accumulator to count number of ones in w within the current 3-cycle window.
