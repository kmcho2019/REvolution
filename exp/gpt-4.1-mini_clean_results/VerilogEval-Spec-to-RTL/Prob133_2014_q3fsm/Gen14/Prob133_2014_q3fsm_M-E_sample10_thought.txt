Implement a two-state FSM (A and B) but use a 3-bit shift register to sample the last three w values in state B. After shifting in the current w each cycle, count the number of 1s by simple combinational logic (e.g., summing the bits with adders) when the shift register has collected three samples (on the third cycle).

Output z will be asserted for one cycle in the clock cycle after the 3rd sample is taken, if exactly two of the three samples were 1.

This approach avoids using an accumulator counter for w, replacing it with a shift register plus a combinational population count (popcount) over 3 bits.

We keep only two states, minimizing complexity. The counter is implicit via a 2-bit cycle counter counting from 0 to 2 (3 cycles).

Reset synchronously returns to state A and clears all registers.

This architecture decouples sampling and counting, potentially making combinational logic more straightforward and enabling easy observation of the w pattern in the shift register. It also allows the FSM output to be determined directly by popcount combinational logic.

The output z is registered and delayed one cycle after the 3rd sample, consistent with the spec.
