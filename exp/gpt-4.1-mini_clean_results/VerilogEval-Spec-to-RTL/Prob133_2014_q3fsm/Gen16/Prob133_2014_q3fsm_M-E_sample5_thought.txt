Implement the FSM using a single state register that indicates if we're in state A or B, plus two counters: one to count the number of cycles (0 to 2) and one to count the number of times w=1 during the current 3-cycle window. When in state A, the FSM waits for s=1 to transition to state B. In state B, on each clock the w count and cycle count increment. At the end of 3 cycles, the FSM checks if the w count is exactly 2 and sets z=1 in the next cycle, otherwise z=0. Then the counters reset and counting begins again. The output z is registered and aligned to the cycle after the 3-cycle window. This solution uses no explicit separate states for counting cycles other than the state A/B flag and counters, minimizing state complexity and explicitly pipelining the output.
