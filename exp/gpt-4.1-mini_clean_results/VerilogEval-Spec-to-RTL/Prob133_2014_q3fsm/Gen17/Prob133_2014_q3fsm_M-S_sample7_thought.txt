Simplify the FSM by eliminating the next-state signals and using direct state updates inside the clocked process. Use a two-bit counter to track the three cycles (0,1,2), and a 2-bit register to accumulate the number of w=1 occurrences. Update these counters only in state B, and reset them when returning to A. Output z is asserted one cycle after completing the 3-cycle window if exactly two w's were 1. This removes the separate combinational next_* logic and reduces code complexity while maintaining all required functionality.
