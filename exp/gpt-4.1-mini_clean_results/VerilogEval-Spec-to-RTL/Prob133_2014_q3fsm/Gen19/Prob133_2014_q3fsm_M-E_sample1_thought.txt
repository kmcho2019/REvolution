Use a three-state FSM to explicitly track each of the three clock cycles when in state B, avoiding counters. State A waits for s=1. Upon s=1, transition to state B0, which represents the first cycle of monitoring w. Then transition sequentially through states B1 and B2 on subsequent clocks, each time accumulating the count of w=1 in a small register. After B2, compare the total number of times w=1 in the three cycles and set z accordingly for one cycle, then return to B0 to start a new 3-cycle window. 

This approach uses states themselves as cycle counters, eliminating explicit cycle counters. The w-accum register is 2 bits to count 0 to 3. Output z is registered and active for exactly one clock cycle after the third cycle evaluation. Reset returns to A. This clear state-based design simplifies logic and reduces complexity in arithmetic and control logic, trading a few more states for straightforward sequencing and easy verification.

Advantages:
- FSM state encodes cycle count, removing extra counters.
- Output z is registered and asserted for one cycle only after 3 inputs have been observed.
- Small 2-bit register accumulates count of w=1 in each of the three cycles.
- Only synchronous active-high reset.
- Simple and clear state transitions and output logic.
