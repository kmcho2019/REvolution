The FSM has two states: A and B. State A waits for s=1 to transition to B. State B samples input w for 3 cycles, counting the number of ones using a 2-bit counter. After the 3rd sample, if exactly two w's were 1, output z=1 for one cycle; else z=0. Then repeat counting again in B. We can simplify by combining the counting and cycle tracking into one counter for cycles and using a small register for count of w=1 occurrences. Use minimal state bits and straightforward synchronous logic with clear sequential updates and simple combinational next state logic.
