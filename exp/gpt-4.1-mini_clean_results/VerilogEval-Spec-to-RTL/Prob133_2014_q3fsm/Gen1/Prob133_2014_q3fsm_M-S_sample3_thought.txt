We start in state A, waiting for s=1. After s=1, we enter state B where we count how many times w=1 over 3 clock cycles. Instead of multiple B states, use a 2-bit counter to track which cycle of the three we're on. We accumulate w_count synchronously. After 3 cycles, output z=1 if w_count == 2 else 0 for one clock cycle, then restart counting from 0 for the next 3 cycles.

This design uses only two states: A (waiting for s) and B (counting w in groups of 3 cycles). A 2-bit cycle counter (0 to 2) tracks which cycle we are on within the group of 3. A 2-bit w_count increments on w=1 each cycle. Output z is asserted synchronously on the cycle after the third counted input.

Synchronous reset sets state to A, clears counters and output z.

This approach reduces states and ensures stable, glitch-free output.
