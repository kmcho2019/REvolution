Simplify the FSM by using a single 3-bit shift register to track the last three w inputs once in state B. The FSM starts in state A; it transitions to state B on s=1. In state B, on every clock cycle, shift in the current w into a 3-bit register. After the first three cycles in state B, output z=1 if exactly two bits of the 3-bit register are 1, else 0. This eliminates the need for separate counting logic and multiple states for each counting cycle, reducing states to just two: A and B. Reset synchronously returns to A, clears outputs and counters. This approach is simpler, uses fewer states and less logic while preserving functionality.
