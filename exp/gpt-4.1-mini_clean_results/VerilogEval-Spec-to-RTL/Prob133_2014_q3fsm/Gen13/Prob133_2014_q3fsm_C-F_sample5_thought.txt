Fuse the minimal two-state FSM design with the power-aware counter enable approach. Keep two states (A and B) and synchronous reset. In state A, wait for s=1 to enter B.

In state B, maintain separate 2-bit counters for cycle count (0 to 2) and w count (accumulating how many times w=1 in the 3-cycle window). Update counters only when in state B to avoid unnecessary toggling in state A.

At the end of each 3-cycle window (cycle_cnt == 2), assert output z = 1 in the next clock cycle if exactly two w=1 events occurred in that window (w_accum + current w == 2). Otherwise, output zero. Then reset counters for the next window.

This approach optimizes power by gating counter updates to state B only, simplifies combinational logic by using small counters and direct addition with the 1-bit w, and maintains minimal area with only 2 states and small registers.

Output z is registered synchronously and cleared in state A to avoid glitches. The logic is clear, minimal, and efficient for PPA while meeting the problem requirements.
