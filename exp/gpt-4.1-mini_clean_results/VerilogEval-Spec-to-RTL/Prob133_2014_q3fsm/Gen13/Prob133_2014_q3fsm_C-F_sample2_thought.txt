Fuse the clarity and simple arithmetic accumulation from Example 1 with the power-saving register update strategy and packing from Example 2.

Use two states: A and B.

In state A:
- Keep output z=0.
- Wait for s=1 to transition to B.

In state B:
- Use separate 2-bit cycle counter and 2-bit w_accum registers for clearer, faster arithmetic and simpler logic.
- Update cycle counter and w_accum only in state B to reduce toggling and save power.
- When cycle counter reaches 2 (indicating 3 cycles: 0,1,2), compute z based on whether w_accum plus current w equals 2.
- Output z one cycle later, by holding it in a registered signal.

Pack cycle counter and w_accum separately (not in a single register) to keep fast combinational logic for adding w.

Use synchronous reset active high.

This approach combines:
- Minimal state count (2 states).
- Simple arithmetic logic (no packed addition in combinational path).
- Power reduction by updating counters only in state B.
- Registered delayed output to avoid combinational critical path on z.
- Clear, simple, and maintainable code.

This fusion should yield better timing (short combinational paths), lower power (registers update only in B), and small area (minimal states and small counters).
