Optimize the FSM by removing the explicit next state logic and merging it into a single always_ff block for synchronous logic. This reduces the logic needed for next state calculations and eases synthesis optimization. Also, move the z output register to be driven by a delayed 'z_gen' signal, computed combinationally at the end of the 3-cycle window, thus decoupling output logic from state transitions. Additionally, use an enable signal for counters to avoid unnecessary counting in state A. This reduces switching activity (power) and logic complexity. Keep state encoding minimal and counters 2-bit wide as before. These changes will slightly improve timing by reducing combinational logic depth, save power by gating counters, and reduce area by removing duplicated combinational assignments.
