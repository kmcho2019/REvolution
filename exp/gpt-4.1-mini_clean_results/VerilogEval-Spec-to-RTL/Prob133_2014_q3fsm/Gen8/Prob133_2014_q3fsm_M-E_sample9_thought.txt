Implement the FSM with three states: A (wait for s=1), B (count w=1 occurrences over three cycles), and C (output z based on counted w=1s). In state B, use a 2-bit counter to track how many cycles have elapsed and a 2-bit register to accumulate the number of w=1 inputs. After the third cycle in state B, transition to state C where output z is asserted if exactly two w=1s were counted. On the next clock cycle in state C, reset counters and return to state B for the next window. This approach explicitly separates counting and output states, improving clarity and ensuring z is output exactly one cycle after processing the 3-cycle window. Synchronous reset initializes all states and registers.
