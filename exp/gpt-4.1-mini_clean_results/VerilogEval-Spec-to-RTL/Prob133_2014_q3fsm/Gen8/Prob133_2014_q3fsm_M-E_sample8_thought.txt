Implement the FSM with three states: A (wait for s=1), B1, B2, and B3 representing the three cycles of the w input window in state B. Upon entering B1, reset a 2-bit counter to count how many times w=1 in the current 3-cycle window. On each clock in B1, B2, and B3, accumulate w into the counter. After B3, transition back to B1 for the next window, and simultaneously set output z to 1 if the accumulated count equals 2, otherwise 0. This design uses more explicit FSM states to represent each cycle of the window instead of counters, trading state count for simpler logic per state and output timing directly coupled to states. This approach ensures z is produced immediately after completing counting in the 3rd cycle state and allows simple next-state logic without arithmetic inside combinational blocks.
