Implement a 4-state FSM to explicitly represent each of the three sampling cycles and the output cycle, which simplifies output timing and state transitions.

- States: A (wait for s=1), B1 (sample w #1), B2 (sample w #2), B3 (sample w #3), then output cycle B_out.
- On reset, start in A.
- In A, ignore w; move to B1 when s=1.
- In states B1 to B3, sample w and accumulate the count of w=1 in a 2-bit register.
- After B3, in B_out state, output z=1 if the accumulated count is exactly 2, else 0.
- Then, restart from B1 to sample the next 3 cycles continuously.
- Use synchronous active-high reset, positive-edge clocking.
- This approach eliminates combinational additions on each cycle and separates sampling from output.
- The accumulated count register only updates in sampling states.
- Output z is registered in a dedicated output state, enabling clean timing and easier timing closure.
- This uses more states but simplifies the control and potentially eases timing and debugging.
