Implement the FSM using three states: A (waiting for s=1), B (collecting w inputs for 3 cycles), and C (output z=1 or 0 in the next cycle). 

- In state A, wait for s=1 to transition to B.
- In state B, maintain a 2-bit counter for cycles (0 to 2) and a 2-bit register that counts how many times w=1 occurred.
- On the third cycle in B (cycle counter = 2), transition to state C and calculate whether z should be 1 based on the count of w=1.
- In state C, output the registered z (1 if exactly two w's were 1 in previous 3 cycles, 0 otherwise), then transition back to B to start the next 3-cycle window.
- Reset synchronously to state A, zero counters and z.
- Output z is registered in state C, stable for one cycle.
- This three-state FSM separates counting and outputting phases, simplifying the control logic and making output timing explicit.
