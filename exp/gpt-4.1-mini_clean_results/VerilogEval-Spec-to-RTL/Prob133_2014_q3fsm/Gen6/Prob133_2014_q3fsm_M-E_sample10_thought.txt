Use only two main states: A (waiting for s=1) and B (counting windows). In state B, maintain a 2-bit cycle counter (0 to 2) to count the three w input cycles and a 2-bit accumulator to count how many times w=1 in the current window. On each clock in state B, increment the cycle counter and add w to the accumulator. When the cycle counter reaches 2 (end of window), evaluate if the accumulator equals 2 and assert z in the next cycle (one-cycle delayed output). Then reset the counter and accumulator for the next window and continue in state B. This approach avoids encoding each cycle of the window as a separate state and instead uses registers as counters, reducing the number of FSM states and potentially simplifying the combinational logic.
