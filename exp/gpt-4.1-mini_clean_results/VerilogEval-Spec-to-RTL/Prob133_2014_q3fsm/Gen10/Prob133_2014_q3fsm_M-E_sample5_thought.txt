Instead of using separate counters or packed registers, we can design a 5-state FSM that explicitly tracks the three clock cycles after entering state B, storing the count of w=1 occurrences as it progresses. This approach avoids arithmetic in combinational logic by encoding the partial count in the states themselves, which naturally sequence through counting cycles and accumulating w counts.

The FSM states represent:
- A: waiting for s=1 to start
- B0: first cycle checking w, 0 w=1 so far
- B1: second cycle, 1 w=1 so far
- B2: second cycle, 0 w=1 so far
- B3: third cycle, accumulated count + current w

After the third cycle, the FSM outputs z=1 if exactly two w=1 were counted; otherwise 0, and then restarts the 3-cycle counting in B states.

This method uses state encoding to implicitly hold cycle count and partial w count, eliminating separate counters and additions, potentially simplifying combinational logic and improving timing and power. The output z is registered and asserted for a single cycle immediately following the third input of w.

We keep reset synchronous and active high. All sequential logic is on the posedge of clk.
