Refactor the FSM by clearly separating state transitions, counting, and output logic. Implement a Moore-style FSM where output `z` depends only on the current state (with a dedicated state to assert `z=1`), and avoid complex counting logic inside states.

Key ideas:

1. Use a 5-state FSM: 
   - A: wait for s=1
   - B0, B1, B2: sample w for 3 cycles, counting how many times w=1
   - Z: output assert cycle for z=1 if exactly two w=1's counted; else z=0

2. Maintain a 2-bit counter that increments synchronously when in states B0-B2.

3. At the end of B2, transition to state Z where output z=1 if count==2 else z=0.

4. After state Z, go back to B0 to begin next 3-cycle sampling window.

5. Reset synchronously clears state, counter, and z.

6. Output `z` is registered and driven directly by the FSM state (z=1 only in state Z).

This approach simplifies output timing—output z depends only on state Z, eliminating the need for separate output registers or combinational logic for z. Counting w=1 is clean and synchronous. Using explicit states for output enables exact timing control and easier verification.

This design is easy to understand, synthesizes well, and meets the requirement that z is asserted in the cycle immediately following the 3-cycle w sampling window.
