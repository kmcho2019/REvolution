Implement the FSM using three states: A (waiting for s=1), C0, C1, and C2 representing the three cycle windows in state B. Use a counter for the number of 'w=1' occurrences accumulated during these three cycles. Transition from A to C0 on s=1. In states C0, C1, and C2, accumulate w counts and progress to the next state on each clock. After C2, output z=1 if exactly two w=1 occurred during the window, else 0, then return to C0 to continue counting the next window. This approach explicitly models each cycle of the 3-cycle window as a separate state, avoiding separate counters and simplifying the logic. The output z is registered and only asserted one cycle after the 3rd w input, matching the requirement. Synchronous reset returns to A state and clears counters and output.
