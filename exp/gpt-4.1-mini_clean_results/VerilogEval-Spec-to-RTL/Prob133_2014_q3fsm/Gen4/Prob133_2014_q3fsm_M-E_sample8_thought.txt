Implement the FSM using a Mealy machine approach with minimal states: a reset/wait state A and a counting state B.
In state A, wait for s=1 to transition to B. In state B, count the number of cycles up to three using a 2-bit counter.
Simultaneously accumulate the count of w=1 in a 2-bit register.
After the third cycle, immediately output z=1 if exactly two w's were detected; otherwise 0.
Then reset counters and continue counting the next three cycles.
Use synchronous reset and update all registers on the posedge of clk.
This approach outputs z in the same cycle as the third w input is processed, yielding a Mealy style immediate output without delaying z to the next cycle.
