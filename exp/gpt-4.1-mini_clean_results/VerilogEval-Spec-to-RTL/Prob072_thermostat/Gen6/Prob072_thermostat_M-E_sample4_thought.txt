Instead of directly assigning outputs using boolean expressions, I will use a small finite state machine (FSM) to explicitly represent the operational states of the thermostat: IDLE, HEATING, and COOLING. The mode and temperature inputs determine state transitions. In each state, outputs for heater, aircon, and fan are assigned accordingly. The fan is turned on not only when heating or cooling but also if the user explicitly requests it. This state-machine approach is more extensible and clearly separates control logic from output logic.
