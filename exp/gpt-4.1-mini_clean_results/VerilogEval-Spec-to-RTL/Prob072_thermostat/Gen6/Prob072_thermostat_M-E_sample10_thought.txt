Implement a stateful thermostat controller using a simple 2-bit state machine to explicitly represent OFF, HEATING, and COOLING states. The state machine transitions based on mode and temperature inputs, controlling heater, aircon, and fan outputs accordingly. This approach encapsulates control logic into distinct states, enhancing clarity and potential extensibility. The fan output depends on the state (heater or aircon active) or the user fan_on input. Although this uses sequential logic, it helps explicitly capture system modes, making debugging and future extensions easier.
