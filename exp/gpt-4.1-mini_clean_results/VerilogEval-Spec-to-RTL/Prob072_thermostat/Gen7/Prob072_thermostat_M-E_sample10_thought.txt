To present a different architectural style, I will implement the thermostat controller as a purely combinational always block using an if-else statement to determine outputs based on mode and temperature inputs. This approach clearly sequences the control logic by prioritizing mode and temperature conditions, making the control flow explicit and easy to follow. The fan output will be assigned inside the same block to ensure synchronous updates of outputs. This style also allows easy future extension (e.g., adding hysteresis or more states) by modifying the conditional branches. Although functionally equivalent to the previous solution, this approach demonstrates an alternate coding paradigm using procedural assignments in combinational logic.
