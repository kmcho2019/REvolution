Implement the thermostat controller as a small combinational state machine encoded with local parameters to improve readability and clarity. Define two states representing heating and cooling, and select the active mode using a state register that immediately follows the input mode (but combinationally, since no clock is given). This approach models mode selection explicitly, making future extension easier.

Then, depending on the current state, turn on the heater or air conditioner based on temperature flags. The fan output is derived as the OR of the heater, air conditioner, and user fan request signals. This explicit state encoding adds abstraction and helps in easier verification and potential feature extensions, while maintaining simple combinational logic.

The code shows how to define these states as local parameters and use a combinational always block with a case statement to assign outputs accordingly.
