The FSM is unnecessary for this simple thermostat control as outputs depend directly on input conditions. A purely combinational design using straightforward boolean logic will simplify the implementation, reduce area, and lower power consumption. Heater turns on only in heating mode when it's too cold, aircon turns on only in cooling mode when it's too hot, and the fan turns on if either heater or aircon is active or if the user explicitly requests it. This directly maps the specification in clear boolean expressions without registers or states.
