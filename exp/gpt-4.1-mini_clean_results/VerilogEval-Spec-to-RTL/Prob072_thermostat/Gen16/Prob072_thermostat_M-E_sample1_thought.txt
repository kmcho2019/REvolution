I will implement the thermostat controller using a single always_comb block with if-else statements to explicitly control the heater, aircon, and fan outputs. This approach groups the logic by mode, making it clear which conditions are checked in heating or cooling mode.

Specifically:
- Use an always @(*) block to describe combinational logic.
- In heating mode (mode=1), heater is on if too_cold, aircon off.
- In cooling mode (mode=0), aircon is on if too_hot, heater off.
- Fan is on if heater or aircon are on, or if the user requests fan_on.
- Outputs are declared as reg and assigned inside the always block.

This style improves readability by grouping mode-based logic, facilitates later extension with state or timing if needed, and maintains purely combinational behavior.
