I will implement the thermostat controller using a purely combinational assign-based approach without intermediate wires or procedural blocks. This direct assignment approach simplifies the design by computing outputs in a single step using boolean expressions that combine the inputs. Specifically:

- heater is asserted only when mode=1 (heating) and too_cold=1.
- aircon is asserted only when mode=0 (cooling) and too_hot=1.
- fan is asserted if either heater or aircon is on, or if fan_on is set by the user.

This structural approach emphasizes conciseness and minimal logic latency, avoids reg declarations, and fits well for synthesis targeting combinational logic modules. It's clean and straightforward, easy to verify, and still meets all specifications.
