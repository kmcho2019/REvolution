Implement the thermostat controller using an explicit combinational always block that evaluates mode first, then within each mode decides which device to turn on. Use temporary reg variables for heater and aircon inside the always block and then assign outputs accordingly. The fan is controlled by turning it on if either heater or aircon is on, or fan_on is asserted. This style highlights the decision-making flow and can be easily extended for more complex state-based logic if needed.
