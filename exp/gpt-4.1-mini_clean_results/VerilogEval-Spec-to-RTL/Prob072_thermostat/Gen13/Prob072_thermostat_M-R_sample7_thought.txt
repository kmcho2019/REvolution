Refactor the thermostat controller to use an always_comb block instead of continuous assignments. This approach encapsulates all combinational logic in a single procedural block, improving code readability for those familiar with sequential-style logic and potentially aiding certain synthesis tools to infer combinational logic more clearly. 

Inside the always block, outputs heater, aircon, and fan are assigned based on the input conditions using if-else statements, explicitly separating heating and cooling mode behavior. The fan output is driven by whether heater or aircon is active or if the user requests the fan, consistent with the original logic.

This restructuring maintains identical functionality but shifts from purely declarative continuous assignments to a procedural combinational style.
