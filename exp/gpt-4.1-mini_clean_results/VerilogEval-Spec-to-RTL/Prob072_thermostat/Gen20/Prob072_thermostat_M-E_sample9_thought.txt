I will implement the thermostat controller using a combinational always block and internal registers to explicitly represent the decision-making process. This approach allows easy future extensions, such as adding hysteresis or state-based logic if needed. The always block triggers on any input change and sets heater, aircon, and fan outputs accordingly. The fan is turned on when either heater or aircon is active, or when the user requests it via fan_on. This method is functionally equivalent to continuous assignments but structured differently for clarity in sequential style coding.
