Implement the thermostat controller using a combinational always block with an intermediate state logic. Use if-else branches to prioritize turning on the heater in heating mode when too_cold is asserted, else the air conditioner in cooling mode when too_hot is asserted. The fan output is derived from a separate register that is set if either heater or aircon is on or fan_on is asserted. This approach emphasizes readable, sequential-like code in combinational logic for clarity and potential future extensibility.
