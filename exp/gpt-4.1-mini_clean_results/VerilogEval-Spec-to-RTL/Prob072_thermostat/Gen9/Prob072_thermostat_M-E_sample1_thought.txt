Implement the thermostat controller using a single always_comb block that explicitly sets all outputs based on the current mode and temperature conditions. This approach uses a combinational process for clearer step-by-step control flow. The heater and aircon signals are mutually exclusive by design, and the fan is turned on if the heater or aircon is active or the user explicitly requests the fan. Using an always block with explicit conditions can improve readability and facilitates future extensions such as adding hysteresis or safety features if needed.
