I will implement the thermostat controller using a combinational always block with if-else statements for clarity and explicit priority handling. Inside the block, I will first set all outputs to zero by default, then selectively enable the heater in heating mode when too cold, or the air conditioner in cooling mode when too hot. The fan output will be set whenever the heater or aircon is active, or whenever the user manually requests the fan to be on. This approach uses a procedural block to clearly express mutually exclusive control logic, improving readability and facilitating easier modifications. It also avoids intermediate wires, reducing resource usage.
