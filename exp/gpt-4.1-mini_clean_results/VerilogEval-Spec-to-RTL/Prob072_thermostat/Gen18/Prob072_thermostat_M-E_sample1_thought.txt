Implement the thermostat controller using an always_comb block with explicit priority and intermediate signals for clarity. The heater is enabled only in heating mode when too_cold is asserted; the aircon is enabled only in cooling mode when too_hot is asserted. The fan is controlled by a separate logic that checks if either heater or aircon is active or if fan_on is asserted. This approach allows future extensions more easily, such as adding hysteresis or modes, and clearly separates the decision process for each output.
