Implement the thermostat controller using a 2-bit state encoded internally to represent the current system state: 00 = off, 01 = heating, 10 = cooling. Outputs heater and aircon are driven based on state and inputs. The fan output is driven by the state being heating or cooling, or the user fan_on input. This introduces a minimal state machine approach (combinational next state logic) even though sequential logic is not strictly required, illustrating a different architectural style.
