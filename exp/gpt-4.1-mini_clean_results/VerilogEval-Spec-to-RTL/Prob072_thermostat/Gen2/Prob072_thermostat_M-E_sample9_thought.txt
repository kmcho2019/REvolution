Implement the thermostat controller using a priority-encoded always_comb block to explicitly prioritize the outputs and improve scalability for future extensions. Use a single always_comb block to set heater, aircon, and fan signals based on mode and temperature inputs. This approach centralizes the logic in one procedural block, which can make adding future functionality (like hysteresis or override signals) more straightforward, while still maintaining simple combinational logic. The fan output is asserted whenever the heater or aircon is active, or the user explicitly requests the fan.
