Combine the clarity and synthesis-friendliness of a case statement with the data-driven approach of a ROM array. Implement the lookup as a combinational function that uses a case statement internally to return the mapped 16-bit value for the 3-bit input. This merges explicit mapping (helpful for synthesis and readability) and removes reliance on a wire array which may generate multiple continuous assignments, thus potentially improving synthesis optimization for both area and power. Using a function also encapsulates the logic cleanly and allows easy reuse or modification.
