Instead of using a decoder and masking, implement the output as a read-only memory (ROM) modeled by an array indexed by the 3-bit input `a`. The ROM is initialized with the given 16-bit constants corresponding to each value of `a`. Since the module is combinational, we can model this ROM with a combinational read from a constant lookup table implemented with a function or a case statement. This approach provides a clean and efficient direct lookup mechanism.
