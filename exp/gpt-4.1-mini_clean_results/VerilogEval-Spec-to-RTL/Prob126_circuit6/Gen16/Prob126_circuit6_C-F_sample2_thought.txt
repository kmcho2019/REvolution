To fuse the strengths of both examples, implement a combinational ROM-like lookup using a localparam array indexed by the 3-bit input. This approach leverages the clarity and simplicity of indexed access from Example 1's concise mapping but uses an array for cleaner syntax and better synthesis optimization, as hinted in Example 2. Using a packed constant array removes explicit conditional logic, which can reduce switching activity, area, and improve performance by enabling the synthesis tool to implement a single multiplexer or ROM structure instead of chained if-else or ternaries. This design is fully combinational, easy to read, and synthesizes efficiently.
