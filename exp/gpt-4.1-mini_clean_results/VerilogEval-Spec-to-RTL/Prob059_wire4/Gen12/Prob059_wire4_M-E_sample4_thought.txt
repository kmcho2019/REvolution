Use a single always_comb block to drive all outputs from the inputs simultaneously using continuous procedural assignments, thereby centralizing the signal routing in one place. This approach abstracts the wiring logic into one procedural block, which can improve readability for some designers by grouping all output assignments together. It also uses nonblocking assignments to conceptually represent parallel signal driving, though in this purely combinational case, blocking assignments would also be fine. This design avoids extra module instantiations and uses only one procedural block to define all output signals as simple combinational wire outputs assigned from inputs.
