Instead of using continuous assignments, we can implement the direct wire connections using an always_comb block with registered outputs. While this introduces a combinational logic block, it explicitly models the combinational data flow using procedural assignments, which can be beneficial for certain synthesis flows or simulation tools. Each output is assigned inside the always block directly from the input signals, preserving the functional behavior but structuring the design differently. This approach also enables easy extension if more complex logic or conditional assignments are later required.
