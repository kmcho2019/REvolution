Instead of muxing bytes directly before the flip-flops, instantiate 16 individual D flip-flops each with its own byte-enable control. Use the byte enables to gate the input data or hold the old data at the flip-flop input itself. This way, each bit's next value is conditionally chosen using a ternary operator inside the clocked always block, effectively creating fine-grained per-bit enables derived from the 2-bit byte enable signals. The synchronous active-low reset zeroes all bits. This approach maps each flip-flop explicitly and illustrates per-bit conditional loading while still using a single always block.
