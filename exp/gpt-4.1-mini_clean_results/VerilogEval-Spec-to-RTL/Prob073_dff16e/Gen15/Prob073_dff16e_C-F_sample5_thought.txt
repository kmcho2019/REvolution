Fuse the clarity and modular byte-level enable update from Example 2 with the single 16-bit register approach from Example 1 for better timing and simpler output logic.

Specifically:
- Use a single 16-bit register `q` to avoid duplicating storage and combinational output assignment.
- Implement byte enables by creating byte-level write masks applied to the new data `d` and old register value `q`.
- On each clock, synchronously reset `q` when resetn is low.
- When not resetting, update only bytes enabled by `byteena` by masking the input `d` for enabled bytes and preserving the others.
- This approach maintains conditional byte updating while removing the separate byte registers and the combinational concatenation.
- Benefits: cleaner logic, improved timing due to a single always block, power optimized by selective register update per byte, area efficient by using a single 16-bit register without intermediate registers or combinational outputs.

This fusion balances clarity, timing, power, and area better than either original solution.
