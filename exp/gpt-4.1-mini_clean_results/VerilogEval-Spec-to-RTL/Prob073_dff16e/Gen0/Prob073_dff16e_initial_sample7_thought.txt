Implement a 16-bit register using 16 D flip-flops triggered on the positive clock edge.
Synchronous active-low reset sets the output to 0 when resetn is low at the clock edge.
Byte enables control which bytes get updated:
- If byteena[1] is high, update q[15:8] with d[15:8].
- If byteena[0] is high, update q[7:0] with d[7:0].
For bytes not enabled, retain the current q value.
