Implement a 16-bit register composed of 16 D flip-flops triggered on the rising edge of clk. On each clock edge, if resetn is low, synchronously reset the entire 16-bit register to 0. Otherwise, update the register bits based on the byte-enable signals: if byteena[1] is high, load d[15:8] into q[15:8]; if byteena[0] is high, load d[7:0] into q[7:0]. This selective update allows partial byte writes.
