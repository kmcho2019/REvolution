Implement a 16-bit register using 16 D flip-flops triggered on the positive edge of clk. The synchronous active-low reset clears the entire register to 0. Use the 2-bit byteena signal to selectively update the upper byte (bits 15:8) and lower byte (bits 7:0) of the register with the corresponding bits from input d. If a byteena bit is 0, retain the previous value for that byte.
