Implement a 16-bit register made of 16 D flip-flops. On each positive clock edge, if resetn is low, reset the output q to zero synchronously. If resetn is high, update q selectively based on byteena bits: if byteena[1] is set, load the upper byte q[15:8] from d[15:8]; if byteena[0] is set, load the lower byte q[7:0] from d[7:0]; otherwise hold the previous value. This achieves partial byte write enable functionality.
