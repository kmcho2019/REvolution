Implement 16 D flip-flops with synchronous active-low reset triggered on the positive clock edge. On resetn == 0, clear all flip-flops to zero. On each clock edge, update the flip-flops with input d based on the byte enables: if byteena[1] is 1, update the upper byte q[15:8] with d[15:8]; if byteena[0] is 1, update the lower byte q[7:0] with d[7:0]. If the corresponding byteena bit is 0, retain the previous value of that byte.
