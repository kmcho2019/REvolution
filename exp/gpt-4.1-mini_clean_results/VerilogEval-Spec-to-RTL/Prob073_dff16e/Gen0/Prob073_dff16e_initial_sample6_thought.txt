Implement a 16-bit register composed of 16 D flip-flops. On each positive edge of clk, if resetn is low (synchronously), reset the register output q to 0. Otherwise, update q selectively according to byteena: if byteena[1] is high, update the upper byte q[15:8] with d[15:8]; if byteena[0] is high, update the lower byte q[7:0] with d[7:0]; if the respective byteena bit is low, retain the previous value of that byte.
