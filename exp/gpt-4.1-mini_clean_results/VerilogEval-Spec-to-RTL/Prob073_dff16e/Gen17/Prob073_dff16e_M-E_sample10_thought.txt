Implement the 16-bit register as a single 16-bit register but use a write mask derived from byteena to selectively update bytes. On the clock's positive edge, if resetn is low (synchronously active-low reset), clear the entire register. Otherwise, update only the bytes enabled by byteena by merging the new input data and existing register contents using a masked write approach. This reduces the number of registers and the complexity of output concatenation, and shows how partial update can be done within a single always block with masking.
