Implement the 16 D flip-flops as a single 16-bit register that always updates on the positive clock edge. Use byte enables to selectively write bytes by using a masked write data vector: each byte of the input data is ANDed with its byte enable bit (replicated 8 times), and the retained data comes from the old register masked by the inverse of byte enables. On a synchronous active-low reset, the register clears to zero. This approach uses bitwise operations to generate the next state in one combinational expression without branching, resulting in simpler RTL with potentially fewer gates and improved synthesis optimizations.
