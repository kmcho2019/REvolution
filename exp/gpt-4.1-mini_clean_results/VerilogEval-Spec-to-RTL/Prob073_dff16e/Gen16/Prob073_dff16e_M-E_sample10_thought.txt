Implement the entire 16-bit register as a single 16-bit register `q_reg`. On each positive clock edge, if resetn is low (active-low synchronous reset), reset the entire register to zero. Otherwise, update `q_reg` by selectively replacing bytes based on `byteena` signals: for each byte enable bit set, load the corresponding byte from input `d`; for each byte not enabled, retain its old value. This can be done by masking and combining bytes inside a single always block. This single-register approach simplifies control logic and keeps the entire state in one register, avoiding multiple always blocks.
