Implement the 16-bit register as two separate 8-bit registers (upper and lower bytes), each with its own byte-enable controlled update. On the rising edge of clk, synchronously reset when resetn is low, else update each byte only if its byteena bit is asserted. This decouples the byte updates and can help synthesis tools create optimized byte-level enables, potentially improving timing and reducing power by isolating switching activity per byte. This byte-split design also simplifies selective writes and makes the code clearer and easier to maintain.
