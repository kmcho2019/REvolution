Use an array of 16 individual D flip-flops implemented as a generate loop to model each bit separately. Inside the always block triggered by the clock edge, handle the synchronous active-low reset and selectively update each bit based on its belonging byte enable. This means bits 0-7 update only if byteena[0] is set, bits 8-15 update only if byteena[1] is set, otherwise retain the old value. This bit-wise fine control is more verbose but clearly demonstrates how each bit updates independently and can be useful for understanding or extending to partial bit enables in future. The byte enables are used directly to gate the write enable of each flip-flop, minimizing unnecessary updates.
