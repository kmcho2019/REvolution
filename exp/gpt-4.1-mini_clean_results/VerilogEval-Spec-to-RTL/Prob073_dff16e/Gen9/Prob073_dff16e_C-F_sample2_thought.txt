Fuse the modular clarity of Example 1's separate byte registers with the efficiency and minimal toggling of Example 2's masking approach by implementing a single 16-bit register `q` updated in one always block with synchronous active-low reset. Use explicitly generated byte-enable masks to conditionally update each byte within `q`, preserving bytes that are not enabled. Additionally, add a clock enable signal derived from byte enables to avoid unnecessary updates and toggling when both bytes are disabled, thus improving power efficiency. Output `q` is registered directly, avoiding combinational concatenation to reduce glitching and improve timing. This hybrid approach combines clear, byte-wise control with minimized toggling and simpler logic, delivering better performance, power, and area tradeoffs.
