Instead of a single 16-bit register, implement 16 individual D flip-flops, each with its own write enable signal derived from the byte enables. Each flip-flop updates on the positive edge of clk only if resetn is asserted; otherwise, they synchronously reset to 0. The write enable for each bit is determined by which byte it belongs to and the corresponding byteena bit. This fine-grained approach explicitly instantiates each DFF for clarity and shows explicit clocked behavior per flip-flop.
