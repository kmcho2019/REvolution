Use a single 16-bit register for all D flip-flops and update it within one always block triggered by the positive edge of clk. On each clock edge, if resetn is low, synchronously reset the entire 16-bit register to zero. Otherwise, update each byte selectively by merging the new input data and the old register value using the byte enable bits as masks. This is done by combining the existing q register with the new d input through bitwise operations based on byteena signals, avoiding multiple always blocks and enabling clean and compact code. This approach can also facilitate easier optimization by synthesis tools and reduces code complexity.
