Implement all 16 D flip-flops as a single 16-bit register updated in one always block on the positive edge of clk. On each clock, if resetn is low (synchronous reset), clear the entire register. Otherwise, update only the bytes enabled by byteena. To do this, create a new next state value for q by merging the old q and input d according to byteena bits: when byteena[x] is 1, update that byte from d; otherwise, retain the old byte from q. This approach centralizes the logic, reduces code duplication, and could lead to better synthesis optimization and timing since only one always block handles the updates.
