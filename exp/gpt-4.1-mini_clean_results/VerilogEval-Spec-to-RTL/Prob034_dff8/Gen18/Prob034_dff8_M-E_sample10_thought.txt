Instead of using a single vector register and an always block, I will explicitly instantiate eight separate D flip-flop modules, each handling one bit of the input `d`. This modular approach enhances clarity on a per-bit basis and can be useful for designs requiring individual bit control or analysis. Each DFF module will be parameterized for reusability and triggered on the positive edge of the clock, connecting each bit of `d` to each flip-flop input and output to corresponding bits in `q`.
