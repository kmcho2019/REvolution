Instead of using a single 8-bit register and a single always block, I will instantiate eight individual D flip-flop modules, each handling one bit of the input 'd' and outputting one bit of 'q'. This modular approach isolates each bit's storage element, which can be beneficial for clarity, hierarchical design, and potential bit-level customization in the future.

Each DFF module is triggered on the positive edge of 'clk', and the TopModule connects all 8 DFFs together to form the 8-bit register.

This method explicitly shows the 8 D flip-flops instantiated as separate components rather than using a vector register. It also makes it easy to add reset or enable signals later if desired.
