To improve power efficiency without altering the functional behavior, add an enable signal internally that triggers the update of the register only when the input `d` changes compared to the current output `q`. This reduces unnecessary toggling in the flip-flops and can save dynamic power since the flip-flops only capture new data when needed. The enable is derived from a simple comparison `d != q`, which has minimal area overhead.

This optimization does not affect area significantly since the comparator is small and included in the combinational logic feeding the enable; the critical path remains largely the same, and the logic complexity is minimal. There is no change in timing constraints since the enable is combinational and checked at the clock edge. This improvement yields lower power usage with minimal overhead.
