Instead of using a single 8-bit register updated at once, I will implement the 8 D flip-flops individually with separate always blocks. Each flip-flop will store one bit of the input independently on the positive edge of the clock. This modular approach clearly reflects that 8 separate flip-flops are instantiated, which can sometimes improve clarity in designs where each bit needs independent control or monitoring. While this might increase code verbosity, it explicitly models individual flip-flops instead of a vector register. This approach might be useful for fine-grained control or instrumentation in more complex systems.
