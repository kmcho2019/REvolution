Implement the 2-to-1 multiplexer using a continuous assignment but invert the selection logic to demonstrate an alternative approach: use sel as an active-low select signal inside a conditional operator. This means when sel=0, select b; when sel=1, select a, then invert sel before selection to match the original requirement. This approach uses basic gates explicitly to highlight low-level synthesis mapping and maintain minimal logic depth. Output remains a wire, making the design fully combinational and maximizing synthesis tool optimizations.

- Use a continuous assignment with an inverted sel to select inputs.
- Output is a wire driven by the assign statement.
