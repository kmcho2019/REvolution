Refactor the 2-to-1 multiplexer to use an always_comb procedural block instead of a continuous assignment. This approach keeps the functionality intact but changes the structure to a procedural block that infers combinational logic. Using always_comb (SystemVerilog) or always @(*) (Verilog) ensures synthesis tools interpret it as combinational. This style might be preferred in codebases that favor procedural descriptions or where more complex logic could be easily added later. The ports remain wires, and output is declared as reg since it is assigned inside always. This demonstrates an alternative clean, synthesizable style for combinational mux logic.
