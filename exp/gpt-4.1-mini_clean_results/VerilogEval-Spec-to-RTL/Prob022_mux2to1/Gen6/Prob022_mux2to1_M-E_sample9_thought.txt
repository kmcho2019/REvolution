Implement the 2-to-1 multiplexer using a behavioral always block triggered by changes on inputs a, b, or sel. Use a procedural assignment to a reg type output within the always block, with an if-else statement selecting between a and b based on sel. This approach demonstrates a clockless procedural style suitable for synthesis, which can help with tool familiarity and readability in some contexts, while yielding identical hardware as the continuous assign method.
