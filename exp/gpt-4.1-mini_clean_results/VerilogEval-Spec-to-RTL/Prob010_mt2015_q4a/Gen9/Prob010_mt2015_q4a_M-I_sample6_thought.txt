The original implementation directly uses z = (x ^ y) & x, which is functionally correct but involves an XOR gate followed by an AND gate. This can be simplified logically to z = x & ~y, reducing the logic complexity by eliminating the XOR.

Using z = x & ~y:
- Reduces gate count (no XOR needed).
- Likely lowers switching activity and dynamic power.
- Slightly reduces area.

Since functionality is preserved, this is an optimal improvement for better power and area without impacting performance or clarity. The improved code will implement z = x & ~y with clear comments noting equivalence to the original formula.

This approach retains correctness, optimizes PPA (power, performance, area), and keeps the design minimal and clear.
