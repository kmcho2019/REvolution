Instead of directly mapping each next state bit to the OR of all transition conditions, we can implement next_state logic by encoding the transitions per input as separate intermediate signals for each current state, then use these to generate next_state outputs. This approach clarifies the separation of input-based transitions and may help in further logic optimization or pipelining by isolating transitions per input value. For output, since it's Moore, output depends only on current state D; we generate it directly from the state input. The one-hot encoding allows easy direct mapping of states.
