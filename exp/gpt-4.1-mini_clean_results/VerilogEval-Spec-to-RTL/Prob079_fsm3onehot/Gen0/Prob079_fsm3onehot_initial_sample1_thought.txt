Implement a combinational module that, given the current one-hot encoded 4-bit state and a single input bit, produces the next state and output based on the provided state transition table and output logic. Since states are one-hot encoded, each bit in `state` corresponds to one state (A-D). For each state and input value, specify the next state encoding. The output depends only on the current state (Moore machine output). Use combinational logic (always @*) or continuous assignments to implement this.
