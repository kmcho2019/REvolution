An alternative approach to implement the next_state logic is to explicitly encode the transition conditions for each state and input combination using conditional (ternary) operators. Since this is combinational logic for a one-hot encoded FSM, we can define next_state as a 4-bit vector where only one bit is set depending on current state and input.

For each current state and input, assign the corresponding next state bit to 1 and others to 0. This approach directly reflects the state table logic without using multiple ORs and ANDs, improving readability. The output remains driven by state D.

This approach avoids expression factoring but uses explicit conditions per state, making it straightforward to verify correctness and easy to modify if the FSM changes. It also potentially yields clear hardware during synthesis as a priority mux.

- Use combinational logic with conditional expressions for next_state bits.
- For each state (one-hot), check input and assign one-hot next_state.
