Instead of using multiple intermediate signals for logic factoring, we can directly write the next state logic using if-else style in a combinational always block to express the next_state bits explicitly based on the current state and input.

This approach enumerates the transitions per state cleanly with a case statement, which some synthesis tools optimize well, potentially leading to better readability and easier future extension.

The output logic is a simple assignment: output is high only in state D (one-hot bit 3).

By avoiding extra intermediate wires and using a behavioral combinational block, we gain clarity on how each bit of next_state depends explicitly on the current state and input, which can sometimes help synthesis to optimize transitions.

This is a different architectural style than pure assign-based logic with intermediate signals.
