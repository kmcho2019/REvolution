To implement the Moore FSM with one-hot encoding, use a case statement inside a combinational always block to explicitly describe next_state based on the current state and input. This method groups transitions clearly by state, improving readability and modularity. The output is assigned separately from state since it's solely based on the current state and independent of input.

This architectural idea centralizes all next_state logic in a single combinational always block rather than using distributed assign statements. This structure is intuitive for FSM description, easy to extend or modify, and commonly used in FSM design. It still uses one-hot encoding and directly maps the transition table.

The output logic is implemented as a simple combinational assignment from the state bits, consistent with Moore machine semantics.
