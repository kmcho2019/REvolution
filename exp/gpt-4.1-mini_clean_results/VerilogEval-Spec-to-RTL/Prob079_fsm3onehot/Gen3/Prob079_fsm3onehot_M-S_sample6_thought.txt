Leverage the one-hot property to combine terms more compactly. Notice that next_state[0] activates only for A and C when in=0, and next_state[3] only activates for C when in=1, so it can be directly assigned as C & in. For next_state[1], it is active for B with in=1 and for A and D with in=1, so (A|B|D)&in. For next_state[2], it activates for B and D when in=0. Since outputs correspond exactly to D, assign out = D. This results in minimal, clear expressions with fewer terms.
