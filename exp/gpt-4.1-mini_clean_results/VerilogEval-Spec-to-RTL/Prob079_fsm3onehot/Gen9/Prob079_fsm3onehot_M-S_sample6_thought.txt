Since the state encoding is one-hot, only one state bit is set at a time. We can directly express next_state bits using simple AND/OR of input and state bits without intermediate wires. For example, next_state[0] is active when in=0 and (state A or state C), so next_state[0] = ~in & (state[0] | state[2]). Similarly for other bits, writing expressions directly is simpler and reduces intermediate signals.

The output depends only on state D bit, so assign out = state[3].

This approach removes all intermediate wires and uses direct expressions, simplifying the design while keeping logic clear and functionally equivalent.
