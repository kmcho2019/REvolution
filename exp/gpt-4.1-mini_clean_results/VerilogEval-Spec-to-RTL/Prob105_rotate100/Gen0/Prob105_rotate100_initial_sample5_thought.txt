Implement a 100-bit register that can be loaded synchronously from the 100-bit input data on a high load signal. On each clock edge, if load is low, check ena; if ena is 2'b01 rotate right by one bit, if ena is 2'b10 rotate left by one bit, else retain the current register value. For rotation, connect the shifted-out bit back into the opposite end to achieve rotation. Output q is the current register contents.
