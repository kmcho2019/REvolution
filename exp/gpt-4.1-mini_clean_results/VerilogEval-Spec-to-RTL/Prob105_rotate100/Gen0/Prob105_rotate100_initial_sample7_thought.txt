Implement a 100-bit register with synchronous load and rotate operations. On the rising edge of clk, if load is high, load the input data directly into the register. If load is low, check the enable bits to decide rotation: ena=2'b01 rotates right by one bit, ena=2'b10 rotates left by one bit, and ena=2'b00 or 2'b11 hold the value (no rotation). The rotation operation wraps the shifted-out bit around. Output q reflects the current register value.
