Implement the 100-bit rotation using a combinational rotate-left and rotate-right function applied to the current register value, selecting the next state based on the ena signal inside the clocked process. Use a wire for the rotated versions computed outside the clocked block, and then a multiplexer inside the sequential block chooses which value to load into q (load data, rotate left, rotate right, or hold). This separates the combinational rotation logic from the sequential register logic, improving modularity and readability.
