Use vector concatenation to implement the rotation operations, which is more concise and generally synthesizes to efficient logic. On load, synchronously load the input data. For rotation, use ena to decide:

- When ena = 2'b01, rotate right by one bit: new q = {q[0], q[99:1]}
- When ena = 2'b10, rotate left by one bit: new q = {q[98:0], q[99]}
- When ena = 2'b00 or 2'b11, hold q unchanged.

This avoids loops and conditional indexing, simplifying the code and improving synthesis quality while preserving exact functionality.
