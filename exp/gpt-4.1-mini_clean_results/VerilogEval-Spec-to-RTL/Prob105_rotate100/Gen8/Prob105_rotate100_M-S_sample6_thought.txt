Simplify the rotation by using vector concatenation for left and right rotations instead of bitwise loops. This approach expresses rotations as simple slices and concatenations, which leads to cleaner, more concise, and more synthesis-friendly code with potentially improved timing and area.

Specifically:
- For right rotation by one bit, assign q <= {q[0], q[99:1]}.
- For left rotation by one bit, assign q <= {q[98:0], q[99]}.
- For load, assign q <= data.
- For no rotation, keep q unchanged.

This fully synchronous design with load and ena signals respects the original interface and functionality but eliminates the explicit for-loop and intermediate variables, making the logic more efficient and clearer.
