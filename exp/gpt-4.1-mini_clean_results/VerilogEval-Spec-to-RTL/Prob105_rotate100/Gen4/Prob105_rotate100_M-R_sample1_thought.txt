Refactor the design to use a combinational always block to compute the next state of the register (next_q) based on inputs, and a synchronous always block to update q. This separates combinational logic from sequential state update, improving code clarity and easing simulation debugging. The combinational block uses a case statement on ena, with load having the highest priority, to determine the next value. If no rotation or load is active, next_q holds the current value of q to avoid unnecessary toggling. This approach preserves the same behavior but restructures the code for better readability and potential synthesis tool friendliness.
