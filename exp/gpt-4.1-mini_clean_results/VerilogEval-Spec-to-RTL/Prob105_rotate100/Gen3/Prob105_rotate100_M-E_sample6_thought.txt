Implement the 100-bit rotator as a shift register with a one-bit circular buffer pointer that tracks the logical start of the rotated data. On synchronous load, the register is loaded with the input data and the pointer is reset to zero. On rotation right, decrement the pointer modulo 100; on rotation left, increment the pointer modulo 100. The output q is generated by reading the stored 100-bit data starting at the pointer position, wrapping around at the end. This approach avoids physically shifting bits every clock, instead performing logical rotation via the pointer index, which may reduce switching activity and improve timing.
