Implement the 100-bit rotator using two separate 100-bit registers for left and right rotated values, computed combinationally from the current state q. On each clock edge:

- If load is asserted, q loads the input data.
- Else if ena indicates rotate left (2'b10), q updates to the precomputed left rotation.
- Else if ena indicates rotate right (2'b01), q updates to the precomputed right rotation.
- Otherwise, q holds its value.

This approach separates rotation logic from storage and uses parallel computation of rotated versions, potentially enabling easier pipelining or logic optimization by synthesis tools.
