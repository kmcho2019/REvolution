Implement the 100-bit rotator using a one-hot 3-to-1 mux inside the always block that determines the next state. This mux selects between loading new data, rotating left, rotating right, or holding the current state.

To achieve rotation, use explicit bit slicing and concatenation but in a slightly different form: perform rotation by splitting the vector into two parts and swapping their order, avoiding explicit indexing of the last and first bits in the concatenation.

This approach:
- Decouples the next state logic into a single assignment using a case statement with the enable signal,
- Prioritizes load over rotation,
- Holds the current value when no enable,
- Uses clear, non-redundant register assignments to reduce unnecessary toggling,
- Maintains synthesis friendliness by using only standard Verilog operators and a single always block.

Thus, the module is simple, elegant, and functionally equivalent but structurally distinct from typical concatenation of bits for rotation.
