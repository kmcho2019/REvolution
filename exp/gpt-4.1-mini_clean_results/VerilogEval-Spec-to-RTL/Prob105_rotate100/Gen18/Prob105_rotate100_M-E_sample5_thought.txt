Implement the 100-bit rotator using a 100-bit shift register with a simple rotate feedback path controlled by an internal state machine encoded by ena bits. Use a single always block triggered on the rising edge of clk that first checks load; if load is high, the register synchronously loads the input data. Otherwise, if ena indicates rotation, perform either a left or right rotation by directly shifting the bits and rotating the bit shifted out into the other end. If ena is 00 or 11, hold the current value. This approach uses explicit procedural logic inside a single always block and avoids combinational generate loops, making the design potentially easier for synthesis tools to optimize for timing and power. The logic is compact and sequentially executed, improving readability and possibly reducing glitching.
