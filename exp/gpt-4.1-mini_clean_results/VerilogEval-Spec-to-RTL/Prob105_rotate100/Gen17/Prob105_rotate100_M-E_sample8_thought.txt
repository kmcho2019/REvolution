Implement the 100-bit rotator using a shift register array with a single always block. At each clock edge, synchronously load when load is high; otherwise, if ena indicates rotation, update the register by rotating left or right by one bit. Use separate temporary signals for rotated values computed inside the always block to avoid multiple combinational assignments and to reduce fanout. The module will have a single always @(posedge clk) block that selects the next state based on load and ena. This approach avoids generate loops, uses direct bitwise operations inside the sequential block, and ensures clear synchronous logic for better synthesis and readability.
