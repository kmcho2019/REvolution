Implement the rotator using a synchronous approach where the rotate logic is split into distinct cases: loading data, rotating left, rotating right, or holding the current value. However, instead of a single combined ternary assignment, use a case statement driven by a 3-bit selector derived from {load, ena} signals. This creates clear, explicit control flow for each operation. The rotation logic uses concatenation to wrap-around bits accordingly. This approach improves code clarity by isolating operation decisions while remaining fully synchronous and synthesizable.
