Implement the 100-bit rotator using a 2-bit direction control that selects a 3-way mux to update the register q on each clock edge: load data when load is high; else if ena indicates rotate left, rotate q left by one; else if ena indicates rotate right, rotate q right by one; else hold the current value. To achieve this, precompute the left-rotated and right-rotated versions of q and select the next state based on ena, thereby making the update logic cleaner and explicit. This approach clearly separates load, rotate left, rotate right, and hold states with a multiplexer-based next-state logic.
