Implement the 100-bit rotator using a parallel load register combined with multiplexers on each bit to select whether to load, rotate left, rotate right, or hold current value. For rotation, compute the rotated bit for each position individually by carefully wiring the bit shifted out from the opposite end. Use a single always block triggered on the rising edge of clk for synchronous behavior. This approach explicitly calculates the next state for each bit based on the ena signals, avoiding a case statement and emphasizing combinational logic for rotation selection.
