Implement a byte receiver FSM with the following states:

- IDLE: line idle high; wait for start bit (0)
- RECEIVING: receive 8 data bits, sampling input each clock cycle; count bits received
- STOP_BIT: check if stop bit == 1
- ERROR_WAIT: if stop bit incorrect, wait here until line is high again (stop bit detected) before next byte

Use a shift register to collect the bits in LSB-first order by shifting right and placing new bit at MSB end.

The 'done' signal will be a synchronous one-cycle pulse asserted in the STOP_BIT state only when stop bit is correct.

All logic synchronous with the clock and with a synchronous active-high reset.

This approach consolidates done logic, avoids multiple drivers, and clearly separates states and data collection.
