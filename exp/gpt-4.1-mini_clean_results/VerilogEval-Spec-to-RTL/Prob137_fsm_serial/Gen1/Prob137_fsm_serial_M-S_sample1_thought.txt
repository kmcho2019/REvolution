Implement a simple FSM with three states: IDLE (line idle, waiting for start bit 0), DATA (receive exactly 8 data bits, counting from 0 to 7), and STOP (check stop bit 1). On reset, go to IDLE. In IDLE, wait for input to go low (start bit). In DATA, shift in data bits LSB first on each clock and increment bit counter. When 8 bits are received, move to STOP. In STOP, if stop bit is 1, assert done for one cycle and go back to IDLE. If stop bit is 0, stay in STOP until stop bit 1 appears to resynchronize. The done signal is one clock cycle pulse indicating successful byte reception. This is a straightforward FSM that matches the protocol without unnecessary complexity.
