Implement a simple FSM with three states: IDLE (waiting for start bit 0), RECEIVE (count 8 data bits), and STOP_WAIT (if stop bit incorrect, wait for stop bit = 1). Use one always block triggered on posedge clk with synchronous reset. Maintain a bit counter for the 8 data bits during RECEIVE. When bit_count reaches 8, the next bit is the stop bit: if it's 1, assert done high for one cycle and go back to IDLE; if 0, go to STOP_WAIT until stop bit 1 seen. Generate done as a one-cycle pulse directly in the sequential block, avoiding multiple drivers and simplifying logic.
