On reset, go to IDLE. In IDLE, wait for start bit (0). On detecting start bit, transition to RECEIVE state and start bit counter. In RECEIVE, increment bit counter and shift in bits each cycle. When 8 bits received, transition to STOP_WAIT. In STOP_WAIT, wait for stop bit (1). If stop bit correct, assert done for one cycle and go back to IDLE. If stop bit incorrect, remain in STOP_WAIT until a stop bit (1) is detected.

This approach cleanly separates combinational and sequential logic, ensuring 'done' is generated only synchronously and for one cycle, avoiding conflicting drivers.
