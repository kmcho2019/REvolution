Implement a FSM with clearly separated states: IDLE (waiting for start bit), DATA (counting and capturing 8 data bits), STOP (checking stop bit), and RECOVER (waiting for stop bit if invalid). Use a shift register that shifts right, loading the new bit into MSB, to accumulate LSB-first data (since first received bit is LSB). The done signal is asserted synchronously for one cycle exactly when a valid stop bit is detected. The FSM uses a state register and bit counter updated in a single clocked always block with synchronous reset. The done signal is set in a separate always block triggered on the main FSM state and input, ensuring glitch-free output. This approach cleanly separates state, data capture, and output generation while using classic right shift to assemble data LSB-first.
