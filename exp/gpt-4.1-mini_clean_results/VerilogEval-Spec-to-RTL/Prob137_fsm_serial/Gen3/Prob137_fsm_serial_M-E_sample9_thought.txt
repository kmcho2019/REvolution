Implement an FSM with five states: IDLE (waiting for line high), START (detected start bit 0), RECEIVE (collecting 8 data bits with a counter), STOP_CHECK (checking the stop bit), and ERROR_WAIT (waiting for line to return to idle after a framing error). Use a shift register to store the received data bits but do not output it, only detect valid bytes. The done signal pulses high for one clock cycle immediately after confirming a correct stop bit. Use a separate next_state combinational logic block for cleaner timing and easier modification. The synchronous reset forces the FSM to IDLE and clears counters. This design differs by using a shift register for data bits (even if not output) and a distinct error wait state to recover from framing errors.
