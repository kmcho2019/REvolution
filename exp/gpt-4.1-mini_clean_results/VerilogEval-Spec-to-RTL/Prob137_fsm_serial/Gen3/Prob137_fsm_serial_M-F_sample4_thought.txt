To do this, assert done in the cycle when the FSM is still in STOP and stop bit == 1, and then move back to IDLE next cycle. This can be done by generating done in the sequential block when stop bit is detected correctly, and then clear done immediately after.

4. Since the problem doesn’t specify sampling multiple clocks per bit (no oversampling), we assume bits arrive synchronized to the clk edges, so no extra start bit validation delay is needed.

5. Keep synchronous reset and clocked FSM transitions.
