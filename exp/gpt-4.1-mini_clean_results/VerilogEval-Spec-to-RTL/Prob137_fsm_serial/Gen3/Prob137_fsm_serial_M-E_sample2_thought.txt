To robustly detect a serial byte with start bit, 8 LSB-first data bits, and a stop bit, I propose a precise bit-sampling FSM driven solely by the input clock.

Key ideas:
- Use four states: IDLE, RECEIVE, STOP, WAIT_STOP.
- IDLE waits for a stable start bit (in==0). Only transition if a start bit is confirmed for one clock cycle, eliminating false triggers.
- RECEIVE shifts incoming bits into an 8-bit register from LSB side (i.e., data_shift <= {in, data_shift[7:1]} is MSB-first, so instead shift left and put new bit into LSB: data_shift <= {in, data_shift[7:1]} reversed means we need data_shift <= {in, data_shift[6:0]} or data_shift <= {data_shift[6:0], in}). For LSB-first, shift data_shift left by one and put new bit in LSB, so data_shift <= {data_shift[6:0], in}.
- Count exactly 8 bits received, then move to STOP.
- In STOP, check if the stop bit is 1. If yes, assert 'done' for one cycle and move back to IDLE.
- If stop bit is 0 (invalid), move to WAIT_STOP state, where FSM stays until a valid stop bit (1) arrives, then returns to IDLE.
- 'done' is asserted as a registered pulse for exactly one clock cycle immediately after a valid stop bit is detected.
- The FSM uses synchronous reset active high.
- This approach avoids any double counting or timing ambiguity and clearly separates states for invalid stop bit handling.
