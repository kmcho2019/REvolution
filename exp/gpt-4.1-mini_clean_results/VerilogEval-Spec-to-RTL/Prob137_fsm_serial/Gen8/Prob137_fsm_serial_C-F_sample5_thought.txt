Optimize power by resetting bit counter and shift register only in IDLE and WAIT_STOP states, avoiding unnecessary toggling during RECEIVE. Keep done and state registers updated synchronously on clock edges with active-high synchronous reset.

Use typedef enum for states to improve code readability and enable better tool optimization.

This design is clean, explicit, and efficient: it clearly separates next-state and output combinational logic from state and datapath sequential logic, handles all edge cases, aligns the shifting direction with the protocol, and generates the done pulse correctly. This fusion provides a robust, easily maintainable, and well-structured FSM for serial byte detection with start and stop bits.
