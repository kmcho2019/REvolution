Implement a Mealy FSM that continuously samples bits and transitions states based on the input bit timing. The FSM has five states: IDLE (waiting for start bit 0), DATA (shifting in 8 bits LSB first), STOP_CHECK (verifying stop bit 1 and asserting done immediately as output is Mealy), ERROR (detected framing error, waiting for stop bit to resync), and WAIT_IDLE (waiting for line to return to idle, i.e., logic 1, before next start).

Use a shift register to accumulate received bits by shifting in the new input bit into the LSB, preserving LSB-first order naturally.

Done is asserted combinationally as part of the STOP_CHECK state's output condition (Mealy output), so it can be a wire rather than a register.

Reset clears all registers and returns FSM to IDLE synchronously.

This approach reduces the done signal to a pulse aligned with the stop bit input, eliminates done register toggle overhead, and tightly couples output to input transitions for immediate response. It also uses a separate ERROR state that waits explicitly for the stop bit to resync, preventing premature restart after framing errors.

This design prioritizes minimal latency on done pulse and avoids unnecessary register updates by making done combinational, leveraging Mealy outputs for efficient state indication.
