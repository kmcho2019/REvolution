- Update the shift register and bit counter only in the DATA state (enables implicit clock gating, reducing switching power).
- Generate the done pulse synchronously in the STOP state when a valid stop bit (1) is detected.
- Maintain synchronous active-high reset to ensure clean and predictable initialization.
- Avoid code duplication by grouping reset/clear operations for bit_count and shift_reg in states other than DATA.
- Minimize done toggling by asserting done only when valid stop bit is detected and clearing it otherwise.
- Keep combinational next state logic separated and clean using a single always @(*) block with clear case statement.
