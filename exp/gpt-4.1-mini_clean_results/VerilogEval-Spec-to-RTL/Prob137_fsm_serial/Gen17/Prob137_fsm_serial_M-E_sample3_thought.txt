Implement the byte detection FSM using one-hot state encoding for clarity and timing efficiency. Introduce explicit sampling counters to wait for the middle of each bit period assuming the bit stream is synchronous to the clock (bit rate = clk rate). Use a shift register to accumulate bits LSB first by directly assigning the incoming bit to the corresponding bit index based on bit count. Generate the 'done' output as a single-cycle pulse when a complete and correct frame (start bit 0, 8 data bits, stop bit 1) is detected. Handle framing errors by transitioning to a dedicated ERROR state, which waits for the line to return idle (logic 1) before returning to IDLE, thus ensuring robust resynchronization. Reset all relevant registers synchronously. This approach clarifies state purpose, decouples timing and bit indexing, and improves error handling.
