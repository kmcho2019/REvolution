Implement the serial byte frame detection using a one-hot encoded FSM with five states: IDLE, START_BIT, DATA_BITS, STOP_BIT, and ERROR_WAIT. This explicitly tracks each phase of byte reception, improving readability and ease of debugging.

In the IDLE state, the line is expected to be idle (logic 1). When a start bit (0) is detected, transition to START_BIT, where we confirm the start bit presence at the next clock cycle before proceeding to DATA_BITS.

In DATA_BITS, use a right-shifting shift register that shifts in the input bit at MSB, capturing LSB first by placing the incoming bit at MSB and shifting towards LSB, effectively reversing the bit order over time (to illustrate a different approach). Increment a bit counter until 8 bits are received.

Then transition to STOP_BIT, where we check if the stop bit is high (1). If yes, output a one-cycle done pulse and return to IDLE. If the stop bit is low (framing error), transition to ERROR_WAIT, where the FSM waits until a stop bit (1) is detected on the input line before returning to IDLE.

Use synchronous active-high reset. Separate combinational and sequential always blocks for clarity and synthesis friendliness. Generate done as a registered single-cycle pulse upon successful stop bit detection.

This approach uses one-hot FSM encoding for potentially simpler state decoding in hardware and demonstrates an alternative shifting direction and explicit start bit validation state to increase robustness.
