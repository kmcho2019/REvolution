Refactor the FSM by separating the next-state and output logic from the sequential state update for better clarity and easier modification. Implement a combinational always block to compute the next state, done signal, bit counter, and shift register values based on the current state and input. Use a synchronous always block only to register these signals on the positive clock edge and handle reset.

This approach separates combinational and sequential logic clearly, enhancing readability and potential for optimizations. The done output remains registered for one cycle when a valid stop bit is detected. The data shift register and bit counter update only when needed, reducing unnecessary toggling. The same 4 states and binary encoding are kept for minimal state bits.

This refactoring keeps the same functionality but improves modularity and maintainability.
