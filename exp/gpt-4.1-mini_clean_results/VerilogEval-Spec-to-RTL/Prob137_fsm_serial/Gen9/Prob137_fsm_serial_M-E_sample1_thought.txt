Implement a binary-encoded FSM with four states to reduce flip-flop count and switching activity compared to one-hot encoding, improving area and power. Use an 8-bit shift register shifting in the serial bit at the LSB to receive data LSB-first. Maintain a 3-bit bit counter incremented only when receiving data bits. The done signal is generated combinationally as a single-cycle pulse when the FSM transitions out of the STOP_CHECK state with a valid stop bit.

Upon reset, the FSM returns to IDLE. In IDLE, the FSM waits for a start bit (0). Then it proceeds to RECEIVE state, shifting in data bits and incrementing the bit counter. After receiving 8 bits, it moves to STOP_CHECK state to verify the stop bit (1). If the stop bit is correct, done is pulsed, and the FSM returns to IDLE. If the stop bit is invalid, it transitions to a WAIT_STOP state to wait until a valid stop bit is seen before returning to IDLE. The done pulse is generated combinationally, avoiding extra register toggling.

This architecture reduces register count and switching by encoding states in binary, generating done combinationally, and gating shift register and counter updates strictly to the RECEIVE state. The FSM reset is synchronous and active-high.
