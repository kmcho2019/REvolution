Refactor the FSM by implementing a Moore-style state machine with explicit one-hot encoded states to simplify state decoding, making done output logic purely combinationally derived from the state. Use separate always blocks: one synchronous always block for state and data registers update, and one combinational always block for next state logic only. Implement the shift register to shift in bits with LSB-first (shift left) by inserting the incoming bit at LSB and shifting existing bits towards MSB, aligning naturally with the protocol description. Use a bit counter for the number of data bits received and clear it only on reset or when transitioning back to idle. The done signal is asserted combinationally only when in the CHECK_STOP state and the stop bit is correct, simplifying output timing and reducing flip-flops for done. This approach uses one-hot states for easier expansion, aligns shift direction with protocol LSB-first, and cleanly separates output generation from state updates, making the design clearer and potentially easier for synthesis tools to optimize.
