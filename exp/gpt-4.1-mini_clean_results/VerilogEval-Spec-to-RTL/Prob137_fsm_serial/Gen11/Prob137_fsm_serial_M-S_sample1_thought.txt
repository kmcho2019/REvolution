Implement a simple FSM with three states (IDLE, RECEIVING, ERROR) using one-hot encoding for clarity and minimal combinational logic. The FSM detects the start bit (0), then counts 8 data bits by incrementing a counter, ignoring their values (since only byte framing matters), and finally checks the stop bit (1). If the stop bit is valid, done is asserted for one cycle; if invalid, the FSM enters ERROR state until a valid stop bit is detected to resynchronize.

Use a small counter for data bits. Shift register and data storage are omitted since data content is not requested. The done signal is synchronous and pulses one cycle after a valid stop bit.

This simpler FSM uses fewer states and less logic, improving readability and maintainability while preserving the required functionality.
