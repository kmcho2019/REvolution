Implement the FSM with a binary encoded state machine using four defined states: IDLE, START_WAIT, RECEIVE, and STOP_CHECK. Use a separate shift register that shifts in the input bits with the LSB first by inserting the new bit at bit 0 and shifting left. On detecting a start bit (logic 0), transition from IDLE to START_WAIT for one clock cycle to synchronize sampling, then go to RECEIVE, shifting in 8 data bits over 8 cycles. After receiving 8 bits, move to STOP_CHECK to verify the stop bit is logic 1. If the stop bit is incorrect, stay in STOP_CHECK and wait until a valid stop bit is detected before returning to IDLE. The done output pulses high for one clock cycle immediately after a valid stop bit is received. Use synchronous active-high reset to initialize state and registers. This approach adds an explicit START_WAIT state for one cycle delay after start bit detection to improve synchronization and maintain robustness in the data capture timing.
