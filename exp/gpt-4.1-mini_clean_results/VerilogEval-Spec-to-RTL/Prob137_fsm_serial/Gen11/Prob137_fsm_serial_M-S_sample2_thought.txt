Simplify the FSM by merging the CHECK_STOP and WAIT_STOP states into a single STOP_WAIT state that verifies the stop bit and waits for a valid stop bit if an error occurs. This reduces the number of states from 4 to 3, simplifying the state machine and logic.

Also, since the problem only requires signaling when a byte is correctly received (done pulse), the shift register storing data bits can be omitted to reduce area and toggling. Only a bit counter is needed to count 8 data bits.

Generate the done pulse for one clock cycle when a valid stop bit is detected. Maintain synchronous reset.

The simplified FSM states:  
- IDLE: wait for start bit (0)  
- RECEIVE: count 8 data bits  
- STOP_WAIT: verify stop bit (1); if invalid, wait here until stop bit seen  

This reduction keeps functionality while cutting complexity.
