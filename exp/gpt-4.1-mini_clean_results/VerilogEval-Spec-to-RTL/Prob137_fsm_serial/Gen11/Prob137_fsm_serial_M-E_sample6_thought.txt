Use a simple state machine with three states: IDLE, RECEIVING, and STOP_WAIT. Instead of counting bits with a counter, use an 8-bit shift register to accumulate bits, and use a separate 3-bit counter to track the number of bits received.

Detect the start bit by waiting for an input low (0) in IDLE. Once start bit is detected, move to RECEIVING and shift in bits on every clock, incrementing the bit count. After receiving 8 data bits, transition to STOP_WAIT state to check the stop bit.

If the stop bit is high (1), output 'done' high for one cycle and return to IDLE. If not, remain in STOP_WAIT state until a high is detected on input, indicating the stop bit is correctly received (line returns idle). Only after seeing the stop bit does the FSM return to IDLE.

Implement synchronous active-high reset.

To simplify logic, integrate done output as a one-cycle pulse asserted when the stop bit check succeeds. To maintain clarity and reduce flip flop usage, perform all sequential operations (state, shift register, counter, done) in a single always block.

This architecture clearly separates receiving bits, verifying stop bit, and waiting for stop bit if invalid. The state machine is minimal and counters/shifters are straightforward. The done pulse timing is natural and synchronized with state transitions.
