Simplify the FSM by using binary-encoded states instead of one-hot to reduce state register size and combinational logic complexity.

Use a 3-bit state encoding with states: IDLE=0, RECEIVE=1, CHECK_STOP=2, WAIT_STOP=3.

Implement a shift-left shift register that shifts in the incoming bit at LSB to capture LSB-first serial data, which simplifies the shifting logic.

Update the bit counter only in the RECEIVE state and reset it otherwise to reduce toggling.

Assert the done signal synchronously for one clock cycle when a valid stop bit (1) is detected in CHECK_STOP state.

Use synchronous reset to initialize all registers.

This simplification reduces the FSM state size, lowers combinational logic complexity, and uses a more straightforward shift register approach while keeping the required functionality intact.
