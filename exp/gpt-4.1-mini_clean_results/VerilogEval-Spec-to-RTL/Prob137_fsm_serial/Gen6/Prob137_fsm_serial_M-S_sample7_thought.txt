Use a binary-encoded FSM with four states to detect the start bit, receive 8 data bits LSB-first by shifting them into a register, check the stop bit, and handle invalid stop bits by waiting for a valid one. Combine all sequential logic (state, counters, data shift register, and done pulse) into a single always block to simplify the design. Generate the done pulse for one cycle immediately after validating the stop bit. Keep synchronous reset active-high. This reduces complexity and number of always blocks while preserving functionality.
