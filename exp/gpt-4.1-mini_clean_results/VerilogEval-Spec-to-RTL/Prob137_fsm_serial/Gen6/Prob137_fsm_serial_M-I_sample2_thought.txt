To improve PPA metrics, I will switch from one-hot FSM encoding to binary encoding, which reduces the number of flip-flops used for state storage, thus reducing area and power. This is possible because the FSM has only 4 states.

I will also optimize the done signal generation by registering it so that it is stable and asserted for exactly one clock cycle, reducing glitches and unnecessary toggling.

Additionally, I will keep shifting data bits only in the RECEIVE state (clock enable for shift register) to reduce toggling and power.

This approach reduces area by reducing state register bits from 4 to 2, potentially reduces dynamic power by less switching in state registers and done signal, and maintains or improves timing by simplifying next state logic.

The behavior and functionality remain unchanged.
