Implement the serial byte receiver FSM with a three-state design: IDLE, RECEIVING, and WAIT_FOR_STOP, using a counter to track bit position. Instead of shifting bits into a register, only track the bit index because the problem only requires signaling 'done' when a byte is correctly received. When a start bit (0) is detected in IDLE, transition to RECEIVING and increment the bit counter on each clock, expecting eight data bits. After receiving 8 bits, check the stop bit in WAIT_FOR_STOP. If the stop bit is 1, assert done for one cycle and return to IDLE. If the stop bit is incorrect (0), stay in WAIT_FOR_STOP until a stop bit (1) is seen, then return to IDLE.

Use a synchronous reset to initialize the FSM and counter. The done signal is asserted only for one clock cycle when a valid byte reception is confirmed. This design simplifies logic by not storing the data bits, focusing solely on byte framing verification, reducing datapath complexity and area, while maintaining clarity and correctness.

The FSM encoding will be binary, and outputs will be registered. State transitions and output logic are combined in one synchronous always block for minimal latency and simplicity.
