Refactor the FSM to use a Moore-style implementation with a single always block for all sequential logic: state, counters, data register, and done. Use an enumerated type for states for better readability. The `done` signal is asserted in the STOP_VALID state for exactly one clock cycle. Instead of separate always blocks, combine all sequential updates in one to simplify clock domain logic and potentially improve timing. Implement data shifting using a left shift with the new bit inserted at LSB. The next state logic is calculated combinationally using a separate always_comb block (Verilog-2001 style with always @*). This refactoring enhances clarity by clearly separating combinational next-state logic and sequential updates, removing redundant resets of data_reg and bit counters in multiple places by centralizing the reset logic. Also, provide a clearer signal naming and comments to ease maintenance.
