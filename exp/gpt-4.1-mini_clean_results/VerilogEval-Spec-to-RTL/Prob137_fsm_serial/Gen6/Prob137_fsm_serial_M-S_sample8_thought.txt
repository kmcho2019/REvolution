To simplify the FSM while maintaining the required functionality, use a binary-encoded state machine instead of one-hot encoding to reduce flip-flop usage and combinational logic complexity. Use a 2-bit state variable to represent four states: IDLE, RECEIVE, STOP, and ERROR. Shift in the serial bits LSB first into an 8-bit register during RECEIVE. Use synchronous reset. The done signal pulses high for one clock cycle when a correct stop bit is detected after 8 data bits are received. Keep the error recovery by waiting in ERROR state until a stop bit is detected before returning to IDLE. This yields a smaller and simpler FSM with less state flip-flops, simpler next state logic, and simpler sequential logic.
