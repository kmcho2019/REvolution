Implement an FSM with these states: IDLE (line idle high, waiting for start bit 0), DATA (receiving 8 data bits), STOP (expecting stop bit 1), and WAIT_STOP (if stop bit incorrect, wait until line returns to 1). The key is to sample each bit on the rising clock edge, progressing through the data bits with a separate bit counter from 0 to 7. After all data bits are received, move to STOP state to check the stop bit. Only after confirming stop bit = 1, assert done for one cycle, then go back to IDLE. If stop bit incorrect, go to WAIT_STOP until line is 1 again, then back to IDLE. Use a simple state machine with a bit counter and synchronous reset, no complex typedef enums to ensure maximum Verilog compatibility. This design separates the sampling of data bits and the stop bit cleanly with explicit states.
