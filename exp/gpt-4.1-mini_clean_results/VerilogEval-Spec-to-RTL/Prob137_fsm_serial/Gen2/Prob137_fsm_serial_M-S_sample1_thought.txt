Use a simple 4-state FSM: IDLE (waiting for start bit=0), RECEIVE (shift in 8 data bits LSB first), STOP (check for stop bit=1 and assert done for one cycle), and ERROR (wait for stop bit=1 if stop bit was incorrect).

On reset, go to IDLE. In IDLE, detect start bit (in=0), move to RECEIVE and reset bit count. In RECEIVE, shift bits right (data_reg <= {in, data_reg[7:1]}) so first bit received ends in data_reg[0] (LSB first). Increment bit count each clock; after 8 bits, move to STOP.

In STOP, if stop bit (in=1) correct, assert done for one cycle, then return to IDLE. If stop bit incorrect, go to ERROR state.

In ERROR, wait until line goes high (stop bit=1) before going back to IDLE.

All outputs and state changes happen synchronously on posedge clk with synchronous reset. done is asserted high only for one clock cycle immediately after receiving a correct stop bit.

This approach uses minimal states and straightforward shift logic, avoiding confusion and ensuring correct byte framing detection.
