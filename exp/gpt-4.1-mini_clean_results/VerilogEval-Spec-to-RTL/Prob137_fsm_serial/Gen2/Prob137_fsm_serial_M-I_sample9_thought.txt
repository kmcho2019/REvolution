To optimize the existing FSM design for better PPA (performance, power, area), consider the following improvements:

1. **State Encoding:** Use one-hot encoding for the FSM states. This often leads to faster state decoding and shorter combinational paths, improving timing (tns and wns) in FPGA and ASIC flows.

2. **done Signal Handling:** Currently, done is assigned inside the state register always block, which mixes control and output logic. Move done generation to a separate combinational block driven by the FSM state and input. This can reduce combinational path delay and glitches on done.

3. **Shift Register Implementation:** Instead of a full 8-bit parallel shift with bit rearrangement, use a traditional right shift (`shift_reg <= {in, shift_reg[7:1]}`) that places the incoming bit in the MSB, which is simpler and commonly used in UART receivers (to keep LSB first). This also aligns with typical UART logic and reduces combinational logic complexity.

5. **Use localparam for states:** Explicitly define one-hot encoded states with localparam to keep synthesizability and readability.

This redesign leads to cleaner output logic, improved timing by using one-hot encoding, and slight power savings by gating counters and done signal logic.
