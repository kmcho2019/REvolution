Implement a Moore FSM with explicit start, data, and stop bit phases, driven by a 4-bit counter that tracks the entire frame length (start bit + 8 data bits + stop bit = 10 bits). The FSM idles waiting for a start bit (logic 0), then on each clock cycle samples the input serial bit.

Shift received data bits into an 8-bit register, LSB first, by shifting in the input bit at LSB while shifting existing bits left. After receiving all data bits, check the stop bit.

If the stop bit is valid (logic 1), assert done for one clock cycle, then return to idle. Otherwise, enter an error recovery state where the FSM waits until the input line returns to idle (logic 1) before accepting another start bit.

Use a single 4-bit counter (bit_idx) to indicate which bit is being sampled (0 = start bit, 1..8 = data bits, 9 = stop bit). This simplifies control logic and aligns counting and bit sampling.

The done signal is registered and asserted only when a valid stop bit is detected. The FSM transitions and outputs are synchronous with the clock.

This approach merges bit counting and FSM states to minimize registers and logic, relying mainly on the bit_idx and a simple state variable. The error recovery state waits until the line goes idle (logic 1) before resuming reception, preventing false triggers.

Synchronous active-high reset initializes all registers.
