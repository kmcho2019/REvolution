Implement a Moore-type FSM with binary encoded states to minimize area. The FSM will operate as follows:

- IDLE: Wait for a start bit (0).
- DATA: On start bit detection, receive 8 data bits, shifting them into a shift register LSB first (right shift the register, input bit in MSB).
- STOP: After 8 bits, expect a stop bit (1).
- ERROR: If stop bit is missing, enter ERROR state and wait until a stop bit (1) is detected on the line before going back to IDLE.

The done output is a registered pulse asserted for one cycle immediately after detecting a correct stop bit (when leaving STOP state with a valid stop bit). done is synchronous and only asserted in that cycle.

Shifting the data with input bit loaded into MSB while shifting right preserves LSB-first order in the shift register (since the first bit is least significant, it ends in bit 0 after 8 shifts).

By encoding FSM states in binary (2-bit), we reduce area compared to one-hot and slightly increase combinational complexity in next state logic.

Counters and shift register are updated only when needed. done is a single cycle pulse in STOP state on successful frame detection.

Synchronous active-high reset clears all registers.

This design emphasizes minimal area and clean, well-defined state transitions and signal timing.
