Simplify the FSM by using a single always block with a compact state machine using a 2-bit state register. Use a counter to track received bits and a shift register to store them, shifting in LSB first by shifting right and placing new bits at MSB. Reset registers only on reset or when going idle to minimize redundant clearing. Generate a single-cycle done pulse when a valid stop bit is detected. Wait for a valid stop bit if an incorrect one is found before returning to idle. This reduces lines of code and maintains all required functionality with minimal complexity.
