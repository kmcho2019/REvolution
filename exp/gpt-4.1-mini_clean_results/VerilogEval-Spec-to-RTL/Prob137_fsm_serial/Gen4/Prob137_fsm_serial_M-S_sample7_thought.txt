Simplify the FSM by using just three states: IDLE (waiting for start bit), RECEIVE (receiving 8 data bits plus the stop bit), and WAIT_STOP (waiting for stop bit if invalid). Combine data bits and stop bit counting into a single counter from 0 to 8, where counts 0-7 represent data bits and 8 represents stop bit. When counter reaches 8, check stop bit validity. If valid, pulse done and return to IDLE; if invalid, go to WAIT_STOP until line returns to 1. This reduces state and counter logic and uses a single counter with less code, maintaining the same behavior.
