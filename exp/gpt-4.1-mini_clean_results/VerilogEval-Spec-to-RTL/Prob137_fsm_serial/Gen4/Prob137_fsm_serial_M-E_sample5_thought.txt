Use a bit-sampling FSM that detects the start bit, then counts input bits and samples each bit at the clock edge, storing bits in a shift register LSB first by shifting right and inserting the new bit at MSB. After 8 bits are received, the FSM checks the stop bit. If stop bit is valid (1), the FSM asserts a one-cycle done pulse and returns to idle. If the stop bit is invalid (0), the FSM stays in a "wait_stop" state where it ignores incoming bits until a stop bit (1) is detected, then returns to idle. 

Key architectural differences:
- Shift right the data register and insert new bit at the MSB side, so data bits build from LSB first order by shifting right.
- Use a 4-state FSM but encode as one-hot to reduce logic and potentially improve timing.
- Combine the bit counter with the state machine such that the count only increments during data receive.
- done pulse is generated in the sequential block for exactly one clock.
- Synchronous active-high reset.
- The FSM advances states on positive edge clock and based on input bit values and counters.
- The stop bit is checked immediately after receiving 8 data bits.
