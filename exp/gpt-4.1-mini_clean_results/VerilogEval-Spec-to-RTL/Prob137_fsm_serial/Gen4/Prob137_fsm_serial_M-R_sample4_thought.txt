Refactor the FSM by separating the next-state and output logic into a combinational always block, and the state register updates into a sequential always block. This makes the design clearer and can improve synthesis optimization by isolating combinational paths. The done signal is generated as a registered output synchronized with the state transition. The bit counter increments only when in the DATA state with an enable signal, which is also defined combinationally. This separation enhances readability and potentially performance without changing functionality.
