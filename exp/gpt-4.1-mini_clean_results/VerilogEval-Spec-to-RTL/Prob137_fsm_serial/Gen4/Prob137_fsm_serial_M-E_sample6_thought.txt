Implement a Moore FSM with explicit states for each phase: IDLE, START, DATA_BITS (with a counter), STOP_CHECK, and ERROR_WAIT. Use one-hot encoding for states to potentially improve timing on some FPGAs. The FSM samples the input bit on each clock edge:

- IDLE: line must be high (1). Wait until a start bit (0) is detected to move to START.
- START: Verify start bit is still low on next clock to avoid glitch. Then move to DATA_BITS.
- DATA_BITS: Receive 8 bits serially, LSB first, count bits with a 3-bit counter.
- STOP_CHECK: Check if input is high (stop bit). If yes, assert done for one cycle and return to IDLE.
- ERROR_WAIT: If stop bit is invalid, wait here until input is high (line idle) before returning to IDLE.

The done signal is registered and asserted for exactly one clock cycle after a valid stop bit. The state encoding is one-hot for clarity and to potentially aid synthesis timing. All registers and counters reset synchronously.

This design separates start bit validation step (START state) for robustness, uses a dedicated ERROR_WAIT state to handle invalid stop bits, and uses explicit states for clarity.
