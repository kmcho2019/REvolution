Implement an FSM that samples the input serial data stream directly synchronized to the clock without using a shift register. Use explicit states for IDLE, START, DATA (counting bits), STOP, and ERROR. On detecting a start bit (0), move to DATA state and count 8 bits, shifting in bits into an 8-bit register with LSB first by inserting at LSB and shifting right. After receiving all data bits, check the stop bit (1) in the STOP state. If the stop bit is correct, assert the done pulse for one cycle and return to IDLE; otherwise, go to ERROR state. In ERROR, wait until the line returns to idle (1) before going back to IDLE.

The done output is asserted only one clock cycle at the STOP state when stop bit is correct. All registers and state transitions occur synchronously on the positive clock edge with synchronous reset.

This architecture separates the data reception clearly, keeps the data bits in a shift register oriented for LSB first, and explicitly manages framing errors by waiting in an ERROR state. The done pulse is precisely timed in STOP state. This approach keeps all logic in a single sequential always block with no combinational next state logic, simplifying timing and ensuring glitch-free operation.
