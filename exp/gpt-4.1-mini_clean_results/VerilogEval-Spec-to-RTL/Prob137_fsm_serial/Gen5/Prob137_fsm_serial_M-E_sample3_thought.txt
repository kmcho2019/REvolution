Implement a Moore FSM with 5 binary-encoded states representing: IDLE (line idle, waiting for start bit), START (start bit detected, prepare to receive data), DATA (receiving 8 data bits, counting from 0 to 7), STOP_CHECK (checking the stop bit), and ERROR_WAIT (waiting for a valid stop bit after stop bit error). Instead of shifting bits into a register, simply count the data bits received since the data is not stored or needed for done signal. The FSM transitions at every positive edge clock, synchronously reset active high.

The done output is a registered signal asserted for one cycle when a byte with correct stop bit is received. This FSM approach reduces register usage by not storing the data byte itself and uses binary encoding for fewer state bits, making it area and power efficient. The STOP_CHECK state verifies the stop bit; if valid, done pulses high and FSM returns to IDLE. If invalid, FSM transitions to ERROR_WAIT and stays there until the input line goes to 1 (stop bit), then returns to IDLE.

This approach assumes data bits are not needed beyond detection of correct framing. If data bits storage were required, the design would need a shift register or parallel load mechanism. The done signal indicates successful byte reception per the specification.
