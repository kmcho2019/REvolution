To improve the design's PPA metrics, we will switch from one-hot state encoding to binary encoding, reducing flip-flop count and area while maintaining timing. The binary FSM will use only 2 bits for states instead of 4. 

We will keep done signal pulse generation in the STOP state as before. The data register and bit counter logic remain mostly unchanged but implemented cleanly with binary encoding.

This approach reduces flip-flops and simplifies combinational logic, lowering area and potentially power, with minimal impact on timing. It keeps synchronous reset and positive edge clocking.

Summary of improvements:
- Change FSM encoding from one-hot (4 flip-flops) to binary (2 flip-flops).
- Update next state and output logic accordingly.
- Keep done pulse active-high only for one cycle after correct stop bit.
- Maintain same FSM states and transitions, just with binary codes.

This yields a smaller, lower power design with comparable timing.
