Implement a finite state machine with the following states: IDLE, START, DATA (8 bits), STOP, and ERROR. 
- IDLE: Wait for start bit (0).
- START: Confirm start bit is 0, then move to DATA.
- DATA: Shift in 8 data bits (LSB first).
- STOP: Check stop bit (1). If correct, assert done for one cycle and return to IDLE.
- ERROR: If stop bit not correct, wait in ERROR until line returns to 1 (stop bit), then go back to IDLE.

Synchronous reset clears FSM to IDLE and clears done output.
The done signal is asserted for one clock cycle when a correct byte is received (stop bit detected correctly).
