Implement a finite state machine with the following states:
IDLE: Wait for a start bit (0) while line is idle (1).
START: Confirm the start bit.
DATA: Shift in 8 data bits, one per clock cycle, LSB first.
STOP: Check the stop bit (should be 1). If correct, assert done for one cycle; if stop bit is incorrect, enter a WAIT_STOP state.
WAIT_STOP: Wait until the input line becomes 1 (stop bit), then return to IDLE to look for the next start bit.

The FSM advances on each clock cycle after detecting the start bit. done is asserted only for one clock cycle when a valid byte reception completes with a proper stop bit. Synchronous active-high reset initializes the FSM to IDLE state and clears done.
