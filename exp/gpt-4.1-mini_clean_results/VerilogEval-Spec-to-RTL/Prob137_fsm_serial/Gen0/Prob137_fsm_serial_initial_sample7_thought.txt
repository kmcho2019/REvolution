Implement a finite state machine (FSM) with the following states: IDLE (line is idle, waiting for start bit), RECEIVE (counting 8 data bits), STOP_WAIT (waiting for stop bit if incorrect stop bit detected), and DONE (indicate byte received correctly). On reset, FSM goes to IDLE. The FSM transitions:

- IDLE: wait for start bit (0). When in=0, move to RECEIVE state and start counting bits.
- RECEIVE: shift in data bits, count 8 bits.
- After 8 data bits, check stop bit. If stop bit (in=1), signal done (done=1 one clock cycle) and return to IDLE.
- If stop bit is incorrect (in=0), move to STOP_WAIT state.
- STOP_WAIT: wait until in=1 (stop bit seen), then go back to IDLE.

Since the data bits themselves are not explicitly used or output, only the done signal is generated. The done signal is asserted for one clock cycle upon successful reception of a full byte with proper start and stop bits.

Synchronous reset resets the FSM state and counters.

This FSM runs on posedge clk.
