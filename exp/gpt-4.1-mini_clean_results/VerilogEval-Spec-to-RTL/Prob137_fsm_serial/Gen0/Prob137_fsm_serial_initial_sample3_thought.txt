Implement an FSM with these states: IDLE (line is idle high), START (start bit detected as 0), DATA (receiving 8 data bits), STOP (expecting stop bit 1), WAIT_STOP (wait for stop bit if incorrect stop bit received). On reset, go to IDLE. In IDLE, wait for start bit 0. On detecting start bit, move to DATA and shift in 8 bits (LSB first). Then check stop bit: if 1, assert done for one clock cycle and go back to IDLE; if 0, go to WAIT_STOP, stay there until stop bit = 1, then go to IDLE. 'done' output pulses high one clock cycle at correct stop bit reception.
