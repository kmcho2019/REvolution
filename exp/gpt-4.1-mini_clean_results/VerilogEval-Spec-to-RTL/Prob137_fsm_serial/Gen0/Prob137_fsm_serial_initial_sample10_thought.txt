Implement a finite state machine with the following states: IDLE (line idle, waiting for start bit), START (verify start bit), DATA (collect 8 data bits), STOP (check for stop bit). The line is normally high when idle. On detecting a start bit (0), move to DATA state and shift in 8 data bits (LSB first). Then move to STOP state; if stop bit is 1, assert done for one cycle and return to IDLE. If stop bit is 0 (invalid), stay in STOP state until a 1 is observed (valid stop bit), then go to IDLE. Use a counter to count the 8 data bits. The done output is asserted high for one clock cycle after a valid stop bit is received.

Use synchronous reset to go to IDLE state and clear counters and done signal.
