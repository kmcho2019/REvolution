Design a simple serial receiver FSM that samples bits on the clock edge assuming oversampling is handled externally or data is stable at clock. Use a one-hot encoded FSM with five states for clarity: IDLE, START, DATA_BITS (with a data bit counter), STOP, and ERROR_RECOVERY.

In IDLE, wait for a falling edge indicating a start bit (transition from 1 to 0). Then move to START state to confirm start bit is still 0, providing some robustness. After receiving 8 bits, transition to STOP state and check if the stop bit is 1. If yes, assert done for one clock cycle; if no, transition to ERROR_RECOVERY state, where the FSM waits for a stop bit (line=1) before returning to IDLE.
