Refactor the FSM to use a binary-encoded state machine with fewer states: IDLE (waiting for start bit), RECEIVE (collecting 8 data bits using a bit counter), STOP_CHECK (checking the stop bit), and ERROR (waiting for line idle after framing error). Use a 2-bit state encoding and a 3-bit bit counter to track the received bits instead of one-hot states. Implement the data accumulator as a shift register enabled only during RECEIVE state. The done signal is asserted for one clock cycle at the successful stop bit detection. All registers update synchronously on posedge clk with synchronous reset. This reduces flip-flop count, simplifies next state logic, and consolidates bit reception into a loop controlled by the bit counter, improving area and power efficiency while maintaining the original protocol handling.
