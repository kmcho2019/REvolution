Implement a parameterized synchronous-reset vector DFF module that supports a clock enable (clk_en) input to reduce unnecessary toggling and dynamic power. The clk_en will enable the register to update only when the input data changes or reset is asserted.

In TopModule, instantiate this vector DFF module, and generate the clk_en signal by comparing current stored value q with input d (or assert during reset). This approach leverages modular design, reduces switching activity for power saving, keeps code concise, and maintains synchronous reset and positive edge clocking for all bits. The vector module keeps logic simple, scalable, and synthesis-friendly.
