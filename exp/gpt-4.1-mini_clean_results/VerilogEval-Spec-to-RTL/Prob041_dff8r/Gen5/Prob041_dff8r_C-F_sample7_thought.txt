Fuse the modular clarity of a dedicated DFF module with the area and power efficiency of a single always block handling all 8 bits as a vector register. Implement a single vectorized always block inside TopModule that performs synchronous active-high reset and positive edge clock triggering for the entire 8-bit register. This removes module instantiation overhead, simplifies wiring, and reduces power by minimizing redundant reset logic, while retaining clear and concise RTL code. The single DFF module is omitted since the functionality is straightforward and better optimized when vectorized.
