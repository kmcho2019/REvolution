Implement the TopModule using eight individual 1-bit D flip-flops with synchronous reset, each implemented as a separate instance of a simple DFF module with synchronous reset. Instead of a vectorized register, this modular per-bit approach allows independent instantiation and can facilitate bit-wise enable or test extensions in the future. The synchronous reset logic clears each flip-flop's output to zero on the rising edge of clk if reset is high. This design clearly separates each bit's register, making the structure explicit and easily extensible.
