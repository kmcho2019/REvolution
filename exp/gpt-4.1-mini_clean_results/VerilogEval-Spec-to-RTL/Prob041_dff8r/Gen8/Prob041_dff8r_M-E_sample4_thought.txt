Implement the 8-bit register as a single 8-bit shift register with synchronous reset. On each clock edge, if reset is high, the entire register is cleared; otherwise, the input vector is loaded into the register simultaneously (parallel load). This approach uses one always block, no enable signals, and demonstrates a clean, efficient parallel-load shift register structure. Although functionally equivalent to a vector register, organizing it as a shift register with parallel load conceptually highlights the synchronous reset and loading behavior, offering an alternative architectural perspective.
