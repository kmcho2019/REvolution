To improve power efficiency, add a clock enable (ce) signal internally that only updates the register outputs when input data differs from the current stored data or when reset is asserted. This reduces unnecessary toggling and switching activity, lowering dynamic power. The synchronous reset remains active-high and synchronous to clk as required. The vector DFF module is modified to include clock enable logic. This maintains the simple, modular structure while improving power without impacting area or performance significantly.
