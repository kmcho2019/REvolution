To fuse the best of both examples, we combine the modular clarity and reusability of a parameterized synchronous reset DFF module (from Example 1) with the power-saving advantage of updating the register only when the input data or reset changes (from the power optimization insight).

Specifically:

- Implement a parameterized vector DFF module with synchronous reset and clock enable input. The clock enable (ce) only enables the register update when needed, reducing unnecessary switching.

- Inside TopModule, add logic to generate the clock enable signal, which is asserted only when the input data changes from the current output q or when reset is asserted.

- This avoids unnecessary register updates if inputs are stable, lowering dynamic power.

- Retain the clean modular structure with a single vector register update for better synthesis optimization.

This design balances modularity, clear hierarchy, and power efficiency without complicating the reset or clock logic. The synchronous reset remains active-high, and all DFFs trigger on the positive edge of clk, meeting the specification fully.
