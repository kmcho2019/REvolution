Implement a TopModule using a single always block that describes 8 parallel D flip-flops with synchronous reset on the positive clock edge. Instead of the conventional approach where the entire 8-bit register resets to zero synchronously, we apply a mask so that each bit resets independently when reset is high; otherwise, each bit loads the corresponding input bit. To make the design architecturally different, the reset condition will use a conditional operator inside the assignment to combine synchronous reset and data loading elegantly. This single-block approach preserves timing clarity and minimizes logic while being structurally different from vector register or individual DFF instantiations.
