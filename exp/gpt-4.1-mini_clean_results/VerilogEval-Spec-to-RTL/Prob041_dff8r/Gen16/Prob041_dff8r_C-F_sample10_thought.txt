Fuse the modular clarity of instantiating a reusable single-bit DFF module with the efficiency of implementing the entire 8-bit register in a single always block with synchronous reset inside a parameterized vector DFF module.

Specifically:
- Define a simple reusable single-bit DFF module for clarity and possible future reuse.
- Implement a parameterized vector DFF module that uses a single always @(posedge clk) block with synchronous reset, updating the entire vector register simultaneously. This minimizes area and power by avoiding multiple instantiations and enables the synthesizer to optimize register packing.
- Internally, map this vector DFF to use the single-bit DFF module structurally for testability and hierarchy if needed, but combine logic into a single always block to gain area and power efficiency.
- The TopModule simply instantiates this vector DFF with WIDTH=8.

This hybrid approach combines:
- Modularity and testability from single-bit DFF module,
- Area and power efficiency from a single vector always block synchronous reset design,
- Clean parameterized interface allowing scalability beyond 8 bits without code duplication,
- Best synthesis friendliness and readability.

Thus, we preserve strong modular design principles and improve area/power over multiple instantiations by consolidating logic at the vector level.
