To optimize power without impacting functional correctness, implement data gating by comparing the current input data with the stored output q inside the always block. Update q only when reset is active or when input data d differs from the current stored value q. This approach prevents unnecessary toggling and switching activity when the data remains unchanged, thereby reducing dynamic power. The synchronous reset is preserved, and all flip-flops remain triggered on the rising clock edge.

This single always block design maintains area efficiency and timing simplicity while achieving lower power consumption via selective register updates.
