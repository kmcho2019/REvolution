Implement a fully combinational design using bitwise comparison to generate one-hot signals for each arrow key without using a procedural block. Use four direct assign statements that compare the entire 16-bit scancode to each constant scancode value for the arrow keys. This avoids the overhead of a case statement and intermediate registers, and enables direct logic minimization by synthesis tools. The outputs are asserted high if and only if the scancode matches exactly the arrow key scancode, otherwise they are low. This structure is minimal, efficient, and very straightforward.
