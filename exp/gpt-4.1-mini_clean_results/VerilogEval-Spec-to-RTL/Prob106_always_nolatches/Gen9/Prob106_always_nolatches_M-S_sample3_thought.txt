Since the scancode input is always 16 bits and the arrow keys are defined by fixed two-byte values, we can simplify the decoding by directly comparing the entire 16-bit input against each full scancode using simple continuous assignments. This removes the need for an always block or intermediate reg signals and reduces the code size. Each output will be asserted if scancode matches its corresponding value, otherwise zero. This approach is concise, clear, and fully combinational with minimal logic.
