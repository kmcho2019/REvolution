Instead of using a combinational always block, I will implement the decoder using a combinational function that maps the 16-bit scancode to a 4-bit output vector, where each bit corresponds to one arrow direction. This approach isolates the decoding logic cleanly in a function, which is reusable and easy to test. The function returns a 4-bit vector encoding which arrow key is pressed (only one bit set at a time or zero if none). The outputs are then assigned by indexing into the returned vector. This method also supports easy extension and keeps the main module body clean.
