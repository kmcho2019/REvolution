Instead of using an always block with conditionals or continuous assigns, I will implement a small combinational lookup using a one-hot encoded vector generated from comparing the entire 16-bit scancode to the four known arrow key scancodes. This vector will then directly drive the four outputs. This approach creates a compact and clear mapping using parallel equality checks combined into a single vector, which is then split to the outputs. It can also help synthesis tools optimize comparison and output logic in parallel, preserving purely combinational logic. This architecture also cleanly separates the key detection logic (a vector of matches) from the output assignments.
