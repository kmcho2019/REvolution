Instead of using an always block or direct if-else chains, I will implement the detection using a combinational function that takes the scancode as input and returns a 4-bit one-hot encoding of the arrow keys. This function encapsulates the decoding logic separately, improving modularity and readability. The output ports are then assigned directly from the bits of the function result. This functional approach simplifies future expansion (e.g., adding more keys) by modifying only the function. It also clearly separates combinational logic from I/O port assignments without using reg outputs. The module will use continuous assignments for outputs and a function for decoding.
