To optimize for better PPA, I will use a combinational case statement on the entire 16-bit scancode. This reduces multiple nested condition checks into a single level, which may help synthesis tools generate minimal logic. Also, since only one arrow output can be active at a time, I will encode the outputs into a 4-bit vector internally and then assign each output from it. This can reduce switching power by consolidating logic and ensure mutual exclusivity clearly. The code remains purely combinational, with no registers or latches, keeping latency minimal.
