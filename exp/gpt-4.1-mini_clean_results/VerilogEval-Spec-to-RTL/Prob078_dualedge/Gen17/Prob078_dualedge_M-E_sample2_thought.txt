Implement a dual-edge triggered flip-flop by sampling the input `d` on one clock edge using a flip-flop, then using a toggle flip-flop clocked on the opposite edge that latches the sampled data from the first flip-flop and toggles output `q` only if input `d` changed since last sample. By combining data and toggle logic, this approach uses a state machine-like technique with two flip-flops and an XOR to detect data changes. The output `q` toggles on both edges, effectively capturing input changes on both edges without using a latch or a mux. This structure avoids transparent latches, only uses synchronous registers with clean sensitivity lists, and can be mapped easily to FPGA primitives.
