To simplify the dual-edge triggered flip-flop implementation, I will merge the logic into a single module without separate PosEdgeFF and NegEdgeFF submodules. The module will sample the input on both clock edges by using two always blocks inside the same module: one triggered on posedge clk and one triggered on negedge clk, each updating a different register. Then, the output will be selected by a simple mux based on the clock level, just as before. This reduces hierarchy and makes the code more concise while maintaining the same behavior and synthesis friendliness.
