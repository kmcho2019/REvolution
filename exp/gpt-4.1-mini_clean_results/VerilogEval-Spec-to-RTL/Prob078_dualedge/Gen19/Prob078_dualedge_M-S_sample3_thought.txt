Use a single flip-flop clocked on the positive edge and sample the input `d` twice per clock cycle by leveraging a fast internal clock running at twice the frequency. Since FPGAs typically don't provide a built-in double-frequency clock, simulate this by using a toggling clock generated from the input clock and a latch-like register. 

However, since generating a double-frequency clock inside the design is generally not feasible and outside of the problem scope, instead, implement the dual-edge behavior by using only two flip-flops clocked on opposite edges and combine their outputs using a simple XOR with the clock signal to select the right value. But to simplify further than the original solution, merge the positive and negative edge-triggered flip-flops into a single always block with the clock and inverted clock in the sensitivity list — which is illegal in Verilog but can be mimicked with two always blocks clocked on posedge and negedge respectively, assigning the same register. 

This can be simplified by:

- Using only one reg `q` updated on both edges by two always blocks.
- Since both always blocks update the same reg, the synthesizer will generate two FFs internally, but the code is cleaner.
- Output is just that register, no mux or latch needed.

This maintains dual-edge triggered functionality and reduces module complexity by avoiding multiple modules and mux logic.
