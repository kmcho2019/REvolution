A simpler implementation can be done by using a single positive-edge triggered flip-flop that captures the input on the rising edge, and then an additional register that captures this data on the falling edge by clocking it with the inverted clock. Then, mux their outputs based on the clock level. This eliminates defining separate modules and uses only two always blocks inside a single module, which is simpler and more compact. The functionality remains the same, emulating a dual-edge triggered flip-flop by toggling data capture on both edges.
