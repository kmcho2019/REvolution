Instead of using two flip-flops clocked on opposite edges, we can use a single positive-edge triggered flip-flop running at double the clock frequency. Since true double-frequency clocks are often impractical or costly, we can generate an internal double-frequency enable signal by XORing the clock with a delayed version of itself (or using both clock edges in a generated enable). Then, a positive-edge triggered flip-flop with clock enable triggered at double the clock frequency will effectively sample the input on both edges of the original clock.

In FPGA, we can implement this by creating an internal clock enable signal toggling at both edges of the original clock (e.g., a pulse at both edges), then use a standard flip-flop triggered by the clock and gated with this clock enable to sample the input on both edges. The output is just the FF output.

This approach uses only one flip-flop and no output multiplexer, reducing area and power and avoiding glitches from muxes. The key is generating the double-edge enable signal cleanly from the original clock.

Implementation details:
- Use a small always block triggered on clk and on clk inverted (e.g., posedge and negedge) to create a clock enable pulse toggling every half cycle.
- Use a synchronous FF triggered on posedge clk but enabled only when the enable signal is high.
- This is a synchronous enable signal that fires twice per clock cycle, effectively emulating a dual-edge triggered FF.
