Instead of using the replication operator directly in a continuous assignment, we can implement the sign-extension using a procedural block. We'll store the extended value in a reg type output, and in an always_comb block we will create the sign-extended 32-bit output by concatenating the 8-bit input with 24 copies of the sign bit. This approach demonstrates the same functionality with a different style, making it clear that this is combinational logic driven by input changes. This also makes the sign extension more explicit and potentially more readable for some designers.
