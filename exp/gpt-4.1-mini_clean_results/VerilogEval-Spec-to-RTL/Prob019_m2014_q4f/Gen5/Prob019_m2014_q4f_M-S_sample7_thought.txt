The logic out = in1 & ~in2 can be implemented directly using a single NAND gate by taking advantage of De Morgan's law. Specifically, out = in1 & ~in2 = ~(~in1 + in2). Therefore, using a NAND gate with inputs ~in1 and in2, followed by an inverter, yields the same result but increases gate count. To simplify, we can write the expression in behavioral Verilog as out = in1 & ~in2, which synthesis tools will map efficiently to minimal gates. Thus, the simplest code is a direct assign statement with no intermediate wires or gate instantiations.
