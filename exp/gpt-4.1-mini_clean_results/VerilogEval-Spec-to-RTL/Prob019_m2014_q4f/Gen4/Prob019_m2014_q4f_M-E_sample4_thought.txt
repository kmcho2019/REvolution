Implement the logic using a NAND gate followed by an inverter. Since the input 'in2' to the AND gate has a bubble, the equivalent logic is in1 AND NOT in2. This can be rewritten as NOT(NOT in1 OR in2) using De Morgan's law, or more simply, as NAND(in1, in2) followed by an inverter on the output. This approach uses a NAND gate first and then inverts the output, which is a different structural implementation than explicitly inverting the input. It clearly shows an alternative way to realize AND with a bubble on in2, while keeping the combinational logic simple and explicit.
