Implement the logic using a multiplexer (MUX) where in2 acts as the select signal with a bubble (inverted). Since out = in1 & ~in2, we can realize this as: if in2=0 (after inversion, meaning select=1), output in1; else output 0. Using a 2-to-1 MUX controlled by in2, output is in1 when in2=0, else 0.
