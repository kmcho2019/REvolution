A different way to implement the same logic is to use De Morgan's theorem to transform the AND gate with a bubbled input into an equivalent NOR gate with one input inverted differently. Specifically, since out = in1 & ~in2, by De Morgan: out = ~(~in1 | in2). So we can implement the circuit using a NOR gate with inputs ~in1 and in2. This achieves the same function with a different internal structure.
