Implement the 5-bit maximal-length Galois LFSR using a combinational next-state function that computes the entire next 5-bit vector at once, then registers it synchronously on the rising clock edge. The taps are at bit positions 5 and 3 (1-based), corresponding to bits q[4] and q[2]. The feedback bit is the current LSB q[0]. For bits with taps, their next value is current bit XOR feedback; for bits without taps, the next value is simply the bit shifted right. The reset sets q to 5'b00001 synchronously. This vectorized approach groups logic, reduces individual bit assignments, and improves code clarity.
