Implement the 5-bit maximal-length Galois LFSR with taps at bit positions 5 and 3 using a single vector register and calculate the next state entirely in combinational logic before registering it. On each positive clock edge, if reset is high, load the register with 5'b00001. Otherwise, compute the next state by shifting the current register to the right by one bit and conditionally XORing the feedback bit (which is the current LSB q[0]) with the tap bits at positions 5 and 3 (q[4] and q[2]). This approach centralizes next state logic in a combinational block, improving readability and potentially easing timing optimization.
