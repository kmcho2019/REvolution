Implement the 5-bit maximal-length Galois LFSR using a separate combinational function to compute the next state of the entire register on each clock edge. The LFSR state will be held in a 5-bit register 'q'. On each positive clock edge (with synchronous active-high reset), the next state is calculated by shifting right and applying the XOR taps at bits 5 and 3. This approach reduces read-after-write hazards and clarifies next state logic by separating combinational and sequential logic. The reset state is set to 5'b00001 as required.
