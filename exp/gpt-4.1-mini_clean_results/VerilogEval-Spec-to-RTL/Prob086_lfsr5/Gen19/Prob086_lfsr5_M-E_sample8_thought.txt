I will implement the 5-bit maximal-length Galois LFSR using a combinational feedback calculation outside of the sequential logic to clearly separate the feedback logic from the register update. The feedback bit will be computed as the XOR of the tapped bits with the least significant bit of the register (q[0]). Then, on each rising clock edge, if reset is not active, the shift register will shift right, and the new feedback bit will be loaded into the most significant bit position. This style uses a single vector assignment with concatenation, making the code concise and clear while still fully synchronous and resettable.
