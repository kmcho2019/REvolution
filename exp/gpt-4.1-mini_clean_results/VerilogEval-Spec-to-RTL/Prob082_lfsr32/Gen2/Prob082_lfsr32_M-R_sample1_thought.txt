Refactor by computing the next state of the LFSR in a combinational logic block using a local wire for next_q. The feedback bit is taken from the current q[0]. For each bit position, compute its next value by shifting right and XORing with the feedback if it is a tap position (bits 31, 21, 1, 0 in zero-based index). Then update q synchronously in a single non-blocking assignment inside the always block. This avoids declaring wires inside always blocks and multiple partial assignments to q, resulting in clear, synthesizable code.
