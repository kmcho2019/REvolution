Implement the 32-bit Galois LFSR by shifting the register right by one bit each clock cycle. Use the LSB as the feedback bit. For each tapped bit position, if the feedback bit is 1, flip that bit in the shifted result by XORing it with 1; otherwise, leave it unchanged. This conditional XOR per tap can be implemented by updating the shifted register bits with feedback mask applied only on taps. On synchronous reset, initialize q to 32'h1. This approach directly follows the Galois LFSR behavior without combining all tap bits into a single feedback.
