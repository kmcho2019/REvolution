Implement a synchronous 32-bit Galois LFSR that shifts right on each rising clock edge. On reset, initialize q to 32'h1. On each clock edge when not resetting, take the output bit q[0] as the feedback bit. For each bit from 31 down to 1, if the bit is tapped (positions 31, 21, 1), XOR q[i-1] with the feedback bit; otherwise, just shift q[i-1] to q[i]. The LSB q[0] simply takes the old q[1] without XOR. This cleanly follows the standard Galois LFSR right-shift logic with the given taps. Implement the next state as a combinational vector, then update q on the clock edge.
