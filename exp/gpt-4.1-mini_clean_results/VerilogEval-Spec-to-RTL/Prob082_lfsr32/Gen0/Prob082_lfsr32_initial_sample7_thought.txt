Implement a 32-bit Galois LFSR shifting right. On each clock rising edge, if reset is asserted synchronously, set q to 32'h1. Otherwise, compute the feedback bit by XORing q[0] with the tapped bits q[31] (bit 32), q[21] (bit 22), q[1] (bit 2), and q[0] (bit 1). In a Galois configuration, only bits with taps are XORed with the LSB before shifting right. So q[31] gets q[0] XOR q[31], q[21] gets q[0] XOR q[21], q[1] gets q[0] XOR q[1], and other bits shift right unchanged from the bit above. Implement this logic in a clocked always block.
