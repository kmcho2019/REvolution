Implement a 32-bit Galois LFSR shifting right. On each positive clock edge, if reset is active, set q to 1. Otherwise, calculate the next input bit as the XOR of q[0] and the taps at bits 31, 21, 1, and 0 (since indexing starts at 0). For a Galois LFSR, each tapped bit is conditionally XORed with the LSB output bit. This means that for each tapped bit, if the LSB (q[0]) is 1, that bit is toggled on the next cycle. The bits shift right by one position each cycle, and the MSB gets the XOR input bit. The untapped bits shift right without modification.
