Implement a one-hot encoding approach where we generate a 2-bit vector representing motor and ringer outputs. If ring is low, both outputs are zero. If ring is high, depending on vibrate_mode, either the motor bit or ringer bit is set to 1. Then assign motor and ringer outputs by decoding this 2-bit vector. This approach abstracts the logic and clarifies the exclusive output activation in a single vector, which could be beneficial if outputs need to be extended or monitored as a group.
