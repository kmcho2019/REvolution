The functionality can be combined into a single output assignment using a simple 2-bit vector output that encodes ringer and motor signals mutually exclusively. By packing both outputs into a 2-bit wire and assigning the outputs from bits of this vector, we reduce the number of assign statements and logic expressions. The logic is the same: when ring=0, both outputs are 0; when ring=1, exactly one output is 1 depending on vibrate_mode. Using a vector and a single assignment reduces verbosity and complexity while preserving exact behavior.
