A different architectural idea is to treat the ring input as an enable signal and use a priority encoder style approach. If ring is 0, both outputs are 0. If ring is 1, then we check vibrate_mode: if vibrate_mode=1, motor=1 and ringer=0; else motor=0 and ringer=1. We can implement this logic purely using conditional (ternary) operators directly assigning outputs. This avoids intermediate wires, and clearly expresses mutually exclusive outputs in a priority manner, which is easy to understand and synthesizes efficiently. The design is purely combinational and ensures that only one output is ever on when ring=1.
