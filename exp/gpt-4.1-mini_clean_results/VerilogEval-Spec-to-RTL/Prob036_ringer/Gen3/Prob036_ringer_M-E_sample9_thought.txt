An alternative approach is to encode the output signals as a 2-bit vector, where bit 1 represents the motor and bit 0 represents the ringer. When ring is high, depending on vibrate_mode, only one bit is set: motor if vibrate_mode=1, else ringer if vibrate_mode=0. When ring is low, both are zero. This simplifies the assignment into a single assign statement using bit concatenation. Then ringer and motor outputs are extracted from this vector. This style leverages vector operations and can be concise and clear.
