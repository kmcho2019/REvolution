Implement the design using a combinational always block with an if-else statement for clear control flow. This approach uses a procedural assignment inside an always block triggered by any change in inputs (ring or vibrate_mode). Inside, if ring is low, both outputs are zero. If ring is high, then if vibrate_mode is active, motor is enabled; otherwise, ringer is enabled. This ensures mutual exclusivity and is easy to extend or modify. Outputs are declared as reg to hold assigned values inside the always block.
