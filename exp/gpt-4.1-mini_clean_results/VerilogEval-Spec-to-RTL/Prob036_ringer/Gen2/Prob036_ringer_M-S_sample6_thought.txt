Since the ringer and motor outputs are mutually exclusive and controlled by a single input 'ring' and the mode signal 'vibrate_mode', we can simplify the implementation by directly using an if-else style conditional operator within continuous assignments. This eliminates the need for explicit inversion and separate AND gates by encoding the selection in a single ternary expression per output.

Specifically, assign 'ringer' to ring when not in vibrate mode, otherwise 0. Assign 'motor' to ring when in vibrate mode, otherwise 0. This approach yields the same functionality but reduces logical operations and improves code conciseness.
