Implement the control logic using a simple priority encoder style with a small finite state machine (FSM). The FSM will be combinational with an intermediate wire indicating the selected output. The FSM will prioritize turning on the motor if vibrate_mode is active and ring is on; otherwise, it will turn on the ringer when ring is active. If ring is low, both outputs remain off.

The FSM approach introduces a one-hot encoded intermediate signal which can be easily extended if more modes are added later. This design also demonstrates stateful thinking while remaining combinational for this simple case, making it a scalable and modular approach.

Summary:
- Use combinational logic FSM encoding priority for motor or ringer
- One-hot intermediate wire to select output
- Outputs driven from the FSM signal ensuring exclusivity and zero outputs when ring=0
