Implement a simple dual-port RAM with synchronous write and read operations, using a parameterized array of depth 8 and width 6. Initialize RAM to zeros on an active-low reset by clearing the entire array inside a synchronous reset block. Support simultaneous read and write on different ports by updating RAM on write enable and outputting read data registered on read enable, otherwise output zero. This approach uses two clocked always blocks for simplicity and clarity without combinational reads, easing synthesis and debugging while fulfilling the requirements.
