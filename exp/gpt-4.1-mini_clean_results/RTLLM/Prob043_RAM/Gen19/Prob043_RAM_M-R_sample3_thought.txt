Refactor the dual-port RAM by:

- Using asynchronous reset (negedge rst_n) to clear RAM contents and read_data in an always block.
- Splitting write and read operations into separate always blocks sensitive to posedge clk.
- Using a registered read output (read_data) updated synchronously on clk when read_en is active, else cleared.
- Implementing write operation on posedge clk gated by write_en.
- RAM initialized to zero on reset by an asynchronous reset block.
- Avoid combinational read port to reduce glitches and better timing predictability.
- Keep the depth and width parameters, and use $clog2(DEPTH) for address widths.
