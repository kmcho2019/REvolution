Implement the dual-port RAM with synchronous read and write ports, both triggered on the rising clock edge to ensure timing predictability and easier integration into synchronous designs.

Key points of this architecture:
- Use registers to hold output data (read_data), updated on the clock edge when read_en is active, to provide stable, glitch-free read data.
- During reset (!rst_n), clear the entire RAM memory to zeros using a generate-for loop inside a synchronous reset block for all memory locations.
- Write operation occurs synchronously on the clock edge if write_en is asserted, writing write_data to write_addr.
- Read operation occurs synchronously on the clock edge if read_en is asserted, loading read_data with RAM at read_addr; otherwise, read_data is cleared to zero.
- This synchronous read approach eases timing closure in FPGA/ASIC by avoiding combinational read paths and potential glitches.
- Use fully parameterized width and depth with address width computed using $clog2.
- The RAM is implemented as a reg array [WIDTH-1:0] RAM [0:DEPTH-1].
- Use non-blocking assignments in all sequential logic for proper synthesis behavior.
- The design supports concurrent read and write operations at different addresses or the same address; read during write to the same address will read the previous data before write completes (read-during-write behavior is defined as returning old data).
