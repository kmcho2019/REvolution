Implement a fully synchronous dual-port RAM with separate read and write ports, both synchronous to the clock, and including synchronous reset to zero the output register and the memory contents on reset.

Key points of this approach:
- Use a register array sized exactly DEPTH and WIDTH.
- On reset (active low), synchronously clear all RAM contents to zero in a for-loop inside a single always block triggered on clk and rst_n.
- Write operations occur synchronously on the rising edge of clk when write_en is asserted.
- Read operations are synchronous: on the rising edge of clk when read_en is asserted, the RAM at read_addr is registered into read_data.
- If read_en is not asserted, read_data is cleared to zero.
- This fully synchronous approach ensures the read data is registered, reducing glitches and improving timing closure.
- The reset synchronizes memory clearing, which is clear but adds latency to initialization. This might be suitable for ASICs or FPGA flows requiring explicit synchronous reset behavior.
- Address widths use $clog2(DEPTH) for flexibility and correctness.
- This solution differs from combinational read by registering the read output, improving timing and power characteristics.

This architecture provides predictable timing and simple control FSM-free design with clean synchronous reset and clock domain logic.
