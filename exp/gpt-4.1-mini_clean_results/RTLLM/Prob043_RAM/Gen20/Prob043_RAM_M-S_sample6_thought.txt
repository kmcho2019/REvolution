To simplify the design while maintaining functionality, I will:

1. Implement synchronous write and read operations within a single always block, triggered on the rising edge of clk and negative edge of rst_n.
2. On reset, initialize the entire RAM array to zero using a for-loop.
3. When write_en is asserted, write the write_data to the RAM at write_addr.
4. When read_en is asserted, synchronously read the RAM at read_addr into a registered output read_data; otherwise, clear read_data to zero.
5. Use minimal addressing width based on DEPTH.
6. Avoid asynchronous reads or additional combinational logic for simplicity.

This approach is straightforward, easy to understand, and guarantees synchronous reads and writes with explicit reset initialization, fulfilling the requirements without extra complexity.
