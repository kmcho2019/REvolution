Implement a simple dual-port RAM with synchronous reset and synchronous read and write operations. Use a straightforward reg array sized by DEPTH and WIDTH. Initialize all locations to zero on reset using a for-loop. On each clock edge, if write_en is active, write data to the specified write_addr; if read_en is active, read data from read_addr into read_data; else output zero. Use minimal address width based on DEPTH for addressing. This keeps the design simple, synchronous, and easy to understand.
