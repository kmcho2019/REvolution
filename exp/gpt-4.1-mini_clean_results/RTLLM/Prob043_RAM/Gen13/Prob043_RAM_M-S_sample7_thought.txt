Implement a simple synchronous dual-port RAM with separate read and write ports. The RAM has 8 locations each 6 bits wide, initialized to zero on reset using a loop inside a single always block triggered on clock and reset. The write operation occurs when write_en is high on the rising edge of clk. The read operation returns the data at read_addr when read_en is high; otherwise, output zeros. Both read and write addresses use 3 bits (log2(8) = 3). This straightforward design keeps the read_data output registered to avoid combinational output and ensures predictable timing and easy synthesis.
