Implement a dual-port RAM with separate clocked read and write ports using synchronous read and write. On reset (active-low), asynchronously clear the read_data output register to zero but do not clear the RAM contents to avoid a costly reset loop. Instead, initialize RAM to zero using an initial block for simulation and synthesis convenience.

Use parameters WIDTH=6 and DEPTH=8 with address width = $clog2(DEPTH). Model RAM as a reg array with DEPTH entries, each WIDTH bits wide.

For dual-port operation:
- Writing is synchronous: on posedge clk, if write_en, write write_data into RAM at write_addr.
- Reading is synchronous as well: on posedge clk, if read_en, load read_data with RAM content at read_addr, else output zero.

This synchronous read approach ensures stable outputs with registered data, improving timing predictability and avoiding combinational read paths. The read_data output register holds last valid data or zero when read_en is low.

This design allows simultaneous read and write to different addresses in the same clock cycle.

No RAM clearing on reset avoids long reset times and large reset logic. Instead, read_data is cleared on reset to avoid glitches on output.

This approach differs from the combinational read style and demonstrates synchronous read/write with a simple asynchronous reset on read_data only.
