I will implement a synchronous dual-port RAM with separate read and write ports, both synchronized to the clock with registered outputs for better timing predictability and consistent read latency. 

Key ideas:
- Use parameterized address width based on DEPTH.
- Implement synchronous reset that zeroes the RAM contents using a generate-for loop inside an asynchronous reset block.
- Separate always blocks for writing (on clk posedge) and reading (on clk posedge) to support registered read data.
- When read_en is low, output zero on read_data; otherwise, output the registered RAM data at read_addr.
- This approach trades off one cycle of latency on read but improves timing closure and allows predictable data output.
- The reset initializes RAM synchronously, with a simple for loop for clarity and synthesis friendliness.
- The design supports simultaneous read and write operations at different addresses in the same cycle.

This synchronous-read RAM with registered output and synchronous reset supports robust, cycle-aligned data access suitable for FPGA or ASIC implementation.
