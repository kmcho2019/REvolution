Use a simple synchronous dual-port RAM with a single reg array sized by DEPTH and WIDTH. Initialize memory to zero on reset using a for loop. Perform synchronous write on clock edge when write_en is high. Perform synchronous read on clock edge when read_en is high and output the read data through a registered output. Clear read_data to zero when read_en is low. This approach keeps the design straightforward and fully synchronous without combinational gating.
