Implement a fully synchronous dual-port RAM with independent read and write ports, both clocked by clk, and synchronous reset that clears the output read_data register but does not reset the entire memory array (to avoid large reset overhead). Initialize the RAM to zero using an initial block (simulation friendly, synthesis tools may map it to memory init). Use separate always blocks for write and read operations. The read operation updates a registered read_data output on the clock edge when read_en is asserted, otherwise outputs zero. This approach ensures predictable timing for both read and write, with minimal reset impact on RAM contents and clean separation of logic for clarity.
