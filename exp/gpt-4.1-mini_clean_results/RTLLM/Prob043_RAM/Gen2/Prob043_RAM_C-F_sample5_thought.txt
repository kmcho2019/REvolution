Fuse the strengths of both examples by implementing a synchronous reset that initializes the entire RAM array to zero efficiently without long reset latency by using a generate-for loop within an always block triggered by posedge clk or negedge rst_n. Use synchronous write at the positive clock edge gated by write_en. For reading, implement a synchronous read: capture read_addr and read_en on the clock edge and output read_data registered at clk edge, which improves timing, reduces combinational path delay, and stabilizes read_data output by avoiding direct combinational reads that cause glitches. When read_en is low or rst_n is asserted, output zero. This approach balances read latency (1 cycle) against better timing and power due to gating and registered outputs. The parameterization uses correct address widths derived from DEPTH. The RAM array uses reg [WIDTH-1:0] RAM [0:DEPTH-1] with initialization on reset. The synchronous read/write allows truly simultaneous dual-port operations.
