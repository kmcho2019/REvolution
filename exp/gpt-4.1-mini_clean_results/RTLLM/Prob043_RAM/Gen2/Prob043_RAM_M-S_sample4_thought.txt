Implement a simple synchronous dual-port RAM with parameterized WIDTH and DEPTH. Use a single reg array indexed by the write and read addresses. On reset, synchronously clear all RAM contents to zero using a for loop. On each clock edge, if write_en is asserted, write the input data at write_addr. Also on the same clock edge, if read_en is asserted, output the data at read_addr; otherwise output zero. This keeps the read_data registered and synchronous, simplifying timing and avoiding combinational read complexity.
