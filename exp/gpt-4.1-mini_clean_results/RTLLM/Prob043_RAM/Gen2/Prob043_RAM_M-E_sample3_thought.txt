Implement the dual-port RAM with synchronous read and write operations using clocked always blocks. On active-low reset, synchronously clear all RAM contents to zero. The RAM is a 2D reg array of 8 entries, each 6 bits wide. Write operation occurs on the rising edge of clk when write_en is high, storing write_data at write_addr. Read operation also occurs synchronously on clk's rising edge when read_en is high, capturing the data at read_addr into a registered output read_data. If read_en is low, output zero. This synchronous read adds a cycle latency but reduces glitches and improves timing stability for the read port. The dual-port nature allows simultaneous read and write at different addresses without conflict.
