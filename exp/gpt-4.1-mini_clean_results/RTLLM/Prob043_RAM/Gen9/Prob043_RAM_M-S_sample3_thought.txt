Simplify the dual-port RAM by removing the initial block for RAM zeroing and handling reset by synchronously clearing the output register read_data only, not the RAM contents. Use synchronous write on clk when write_en is active. Use a registered read output updated synchronously on clk when read_en is active; otherwise, output zero. This approach keeps the design simple, ensures data is cleared after reset, and supports simultaneous read/write with minimal logic.
