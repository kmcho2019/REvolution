Refactor the RAM module to use a synchronous read operation instead of a combinational read block, registering the read output data on the positive edge of the clock. This approach reduces the combinational read path delay, improving timing closure. Use non-blocking assignments in both read and write always blocks. Keep RAM initialization via an initial block to set all locations to zero. When read_en is low, maintain the previous read_data value instead of forcing it to zero to reduce unnecessary toggling and power consumption. Also, perform reset synchronously for read_data, zeroing it only on reset assertion.
