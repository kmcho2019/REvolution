Implement a synchronous dual-port RAM with parameterized WIDTH and DEPTH using a small register array. On reset (active-low), initialize all RAM locations to zero in a synchronous reset block. The write operation occurs synchronously on clk when write_en is high. The read operation is synchronous and registered: on clk rising edge, if read_en is high, read_data is updated from RAM at read_addr; else read_data outputs zero. This approach simplifies the design by keeping both read and write operations synchronous, avoids combinational read logic, and maintains straightforward control signals while meeting the requirements.
