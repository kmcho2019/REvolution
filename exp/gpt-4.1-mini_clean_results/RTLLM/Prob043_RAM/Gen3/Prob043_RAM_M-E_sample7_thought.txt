Use a single synchronous always block to handle both read and write operations for a dual-port RAM with depth 8 and width 6. The RAM array is sized exactly to DEPTH (8 locations), not 2^WIDTH, aligning the array size with the address bits (3-bit addresses). On reset (active low), initialize the RAM contents to zero using a for loop over DEPTH to reduce initialization overhead. Write occurs when write_en is asserted, writing write_data to write_addr. Read occurs when read_en is asserted, reading from read_addr and updating a registered read_data output; otherwise, read_data holds its previous value to reduce output toggling and dynamic power. This architecture uses a single clock domain and an asynchronous reset for simplicity and efficiency while enabling concurrent read and write on the same clock edge.
