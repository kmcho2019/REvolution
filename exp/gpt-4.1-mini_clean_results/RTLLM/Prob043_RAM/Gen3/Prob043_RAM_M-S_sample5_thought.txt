Define the RAM array with size equal to DEPTH (8 locations) each of WIDTH (6) bits, matching the interface address widths. On asynchronous reset, clear all DEPTH memory locations to zero. On the positive clock edge, if write_en is asserted, write write_data into RAM at write_addr. Similarly, on the same clock edge, if read_en is asserted, read data from RAM at read_addr into read_data; otherwise, hold read_data at zero. This simplification avoids the unnecessarily large 64-entry RAM and separate resets for each element, reducing area and reset complexity while maintaining synchronous dual-port behavior.
