Implement the dual-port RAM using two separate always blocks for read and write operations, both synchronous to clk and rst_n. The RAM array is sized exactly to DEPTH entries of WIDTH bits. On reset, all memory locations are initialized to zero using a synchronous reset inside the write always block. The write always block performs the write when write_en is high. The read always block performs the read operation synchronously on clock when read_en is high, outputting the data to a registered output read_data; if read_en is low, read_data is cleared to zero. This design uses synchronous read, providing a registered read_data output that helps stabilize timing and reduces glitching on the output. The address width is set precisely to cover DEPTH entries using $clog2(DEPTH). This architecture prioritizes simplicity, fully synchronous operation, and glitch-free stable registered read output.
