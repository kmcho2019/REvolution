Implement a dual-port synchronous RAM with fully synchronous reset and separate always blocks for read and write to clearly separate operations. Initialize RAM contents on reset inside the synchronous reset block rather than using an initial block, ensuring synthesis compatibility. The RAM is a 2D reg array sized by DEPTH and WIDTH. On reset, all memory locations are zeroed using a for loop. Write operations happen synchronously on clk if write_en is active. Read data is registered synchronously on clk when read_en is high; otherwise, it outputs zero. This approach uses fully synchronous logic to improve predictability and is friendly for FPGA/ASIC flows, avoiding combinational read output glitches and supporting proper reset initialization.
