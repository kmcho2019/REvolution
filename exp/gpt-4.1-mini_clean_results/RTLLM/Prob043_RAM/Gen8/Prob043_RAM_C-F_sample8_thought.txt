Fusion Strategy:

1. Use parameterized address width derived from DEPTH using $clog2(DEPTH), for minimal and clean addressing logic.

2. Initialize RAM contents to zero using an initial block:
   - This avoids expensive synchronous reset logic that writes zeros to all memory locations on every reset.
   - Most synthesis tools for FPGA and ASIC support initial block initialization for small RAMs.
   - This reduces toggle power and improves timing during reset.
   - The rst_n signal remains in the interface for external control but is not used internally to clear RAM.

3. Implement synchronous write on the positive clock edge gated by write_en.

4. Implement synchronous read:
   - Register read_data output on the clock's positive edge, with read_en gating.
   - This improves timing predictability and output stability compared to purely combinational read.
   - On reset (rst_n low), clear read_data register to zero.
   - When read_en is low, read_data is zeroed, reducing unnecessary toggling and power on the output.

5. Keep the code clean, readable, and synthesizable with proper comments.

This approach combines Example 1’s use of initial block for RAM content initialization (saving reset-time toggling and logic) and Example 2’s synchronous read_data output register for better timing and output stability. It respects the active-low reset input but does not use it for RAM reset, instead only for read_data output register reset, maintaining correct external reset functionality.

The design supports concurrent read and write operations on the same clock cycle.

Summary:
- RAM initialized to zero at elaboration via initial block.
- Synchronous write with write_en gating.
- Synchronous read output with read_en gating and output cleared on reset or when read_en is low.
- Clean and efficient dual-port RAM meeting all given specifications.
