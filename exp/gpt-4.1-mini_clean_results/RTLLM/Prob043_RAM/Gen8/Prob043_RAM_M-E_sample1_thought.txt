Implement a synchronous dual-port RAM with parameters for WIDTH and DEPTH. The RAM is a register array initialized to zero on an asynchronous active-low reset, so that the memory is instantly cleared without clock delay. The write port operates synchronously on the rising edge of clk, writing data when write_en is asserted. The read port outputs registered data synchronously on clk rising edge if read_en is asserted; otherwise, it outputs zero. This registered read data approach avoids combinational read logic, improving timing stability and enabling easier pipelining. Both ports operate independently allowing simultaneous read and write. The address width is parameterized by clog2(DEPTH). This architecture balances reset speed, timing stability, and clear output gating.
