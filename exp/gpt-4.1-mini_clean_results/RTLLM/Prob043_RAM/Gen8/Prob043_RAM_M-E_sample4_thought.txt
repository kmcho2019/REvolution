Implement the dual-port RAM as a synchronous memory with separate always blocks for read and write operations both triggered on the positive edge of clk or asynchronous reset (negedge rst_n). On reset, use a generate-for loop in an initial block to initialize the RAM array to zero before simulation to reduce runtime reset overhead. The RAM size is defined as DEPTH with WIDTH-bit words. Write operations update RAM on clk edge if write_en is high. Read operations sample RAM content into a registered output read_data on clk edge if read_en is high; otherwise, read_data holds its last value, avoiding unnecessary toggling when not reading. Asynchronous reset clears read_data immediately. The addresses are of size $clog2(DEPTH). This approach registers the read data for better timing and power efficiency and ensures stable output when read_en is inactive.
