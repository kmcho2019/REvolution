Implement a fully synchronous dual-port RAM with separate read and write ports sharing the same clock and reset. Initialize the RAM at reset by explicitly setting all entries to zero using a synchronous reset loop, ensuring deterministic start-up. The read operation is synchronous, storing the read data in a register that updates on the clock edge only when read_en is asserted; otherwise, it holds the previous value. This avoids output glitches and provides stable read data output. The write operation occurs on the same clock edge when write_en is high. Use an address width parameter computed from DEPTH for proper sizing. This approach prioritizes output data stability and easy timing analysis, trading off a one-cycle read latency for robustness and clarity.
