To improve PPA, I will implement registered reads synchronized to clk with synchronous reset for both RAM initialization and read_data output. This breaks the long combinational path on reads and avoids glitches, improving timing (TNS/ WNS) and reducing power due to more stable output. I keep the write logic synchronous as is. Also, I will use non-blocking assignments consistently and explicitly define the address width parameter for clarity. This balances read latency with reliable and efficient timing, suitable for higher clock frequencies.
