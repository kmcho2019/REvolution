Fuse the best ideas from both examples for an optimal dual-port RAM design:

1. Use parameterized WIDTH and DEPTH for scalability and appropriate address width with $clog2(DEPTH).
2. Declare RAM as reg array sized exactly by DEPTH and WIDTH.
3. Implement synchronous reset to initialize all RAM locations to zero using a for loop on posedge clk and !rst_n, ensuring ASIC and FPGA synthesis compatibility with a known reset state.
4. Write operations are synchronous on posedge clk gated by write_en.
5. Use combinational read (continuous assignment) gated by read_en to enable zero-latency read with simultaneous read/write capability.
6. Output read_data is a wire, avoiding unnecessary registered output toggling, which reduces power when read_en is low.
7. The RAM array is reset synchronously and kept minimal in area.
8. The design supports simultaneous read and write at independent addresses with no read/write conflicts.
9. Keep code clean, readable, and fully parameterized for easy future scaling.

This fusion balances performance (zero latency read), reset clarity, power efficiency, and code simplicity.
