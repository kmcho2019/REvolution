To simplify the design while maintaining all functionality, use the minimal address width based on DEPTH for both read and write addresses, and implement a single always block triggered by the clock and reset that handles both reset initialization and write operations. On reset, all RAM locations are cleared to zero using a for loop. For reads, use a separate always block that outputs read_data synchronously on clk; if read_en is asserted, output the stored data at read_addr, else output zero. This avoids combinational read logic, simplifying timing analysis and making the design fully synchronous and straightforward, which is easier to understand and synthesize.
