Implement a dual-port RAM with 8 entries of 6 bits each using synchronous write and asynchronous read for lower read latency. On reset (active low), initialize the RAM contents to zero using an initial block for simulation and synthesis friendliness without causing large reset switching activity. The write port writes on clk's rising edge when write_en is high. The read port outputs data combinationally when read_en is asserted; otherwise, outputs zero. This removes the read_data register, making read data available immediately without clock delay, allowing simultaneous read and write with separate ports.
