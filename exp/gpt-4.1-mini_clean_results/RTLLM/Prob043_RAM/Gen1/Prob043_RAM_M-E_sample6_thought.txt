Implement a dual-port synchronous RAM with an asynchronous reset that initializes all memory locations to zero using an initial block. Use a single always block triggered on the positive edge of the clock for both read and write operations. Separate the read and write addresses for simultaneous access. Read data is output combinationally to reduce latency by using a read enable gated read port (multiplexed output) rather than registered output. This minimizes register stages on the read path and stabilizes read_data at 0 when read_en is low.
