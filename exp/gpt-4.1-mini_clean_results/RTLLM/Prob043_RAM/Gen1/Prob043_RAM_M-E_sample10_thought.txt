Implement a synchronous dual-port RAM with parameterized WIDTH and DEPTH. The RAM is an array of WIDTH-bit registers indexed by DEPTH-sized addresses. On reset, memory initializes to zero using a generate-for loop and synchronous writes only update RAM when write_en is high at clock edge. For reads, instead of using a separate always block with a register, use a combinational read data output that reads from the RAM asynchronously but gated by read_en; if read_en is low, output zero. This approach reduces read latency to zero and avoids extra register and reset logic on the read_data output. Write and read ports operate independently and simultaneously, ensuring true dual-port behavior. The address width is calculated by clog2 of DEPTH. This also avoids clearing the read_data register when read_en is low, reducing toggling and power.
