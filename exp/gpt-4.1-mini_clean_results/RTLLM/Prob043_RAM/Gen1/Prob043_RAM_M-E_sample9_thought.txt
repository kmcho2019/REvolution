Implement a dual-port RAM with synchronous write and asynchronous read ports to allow truly simultaneous read and write without read latency. The RAM depth is 8, width 6 bits, with all memory locations initialized to zero at reset via a synchronous reset that only clears internal registers, leaving the memory contents unchanged at reset (instead, use an initial block for initialization, synthesizable in most tools). The read port is asynchronous and enabled by read_en; when disabled, read_data outputs zero. Write operations occur synchronously on the rising clock edge with write_en. This approach reduces read latency, eliminates the read_data output register, and initializes memory efficiently.
