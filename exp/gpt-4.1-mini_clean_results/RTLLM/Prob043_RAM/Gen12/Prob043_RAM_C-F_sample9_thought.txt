Key points of fusion:
- Use a parameterized RAM array sized exactly by DEPTH and WIDTH, avoiding oversized arrays.
- Implement synchronous write on posedge clk with write_en.
- Reset RAM synchronously on negedge rst_n to all zeros, using a for-loop for synthesis-friendly RAM initialization.
- Provide a combinational read output: when read_en is high, output RAM[read_addr]; else output zeros to avoid glitching and unnecessary toggling.
- Use minimal address width ($clog2(DEPTH)) for both read and write addresses.
- Keep read_data as a continuous assignment rather than a registered output for zero read latency.
- The reset is synchronous to clk, triggered on negedge rst_n, ensuring safe reset domain crossing and avoiding asynchronous resets that can cause metastability or unpredictable initialization in SRAM inference.
- Code style is clean, well-commented, and synthesizable for ASIC and FPGA flows.

This combination balances performance (zero read latency), power (read gating), and area (minimal addressing and RAM size) while ensuring reliable synchronous reset initialization for the RAM contents.
