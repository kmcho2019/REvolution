Implement a simple synchronous dual-port RAM with separate read and write ports. Use a 2D register array sized by DEPTH and WIDTH. On reset (active low), clear all memory locations to zero via a for-loop. On each clock edge, if write_en is active, write write_data to write_addr. If read_en is active, synchronously read data from read_addr into a registered output read_data; otherwise, read_data outputs zero. This straightforward approach meets functionality requirements with minimal complexity.
