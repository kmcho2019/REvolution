Implement a synchronous dual-port RAM with separate clocked read and write ports to support simultaneous read and write operations without conflict or combinational read outputs. Use independent always blocks for read and write processes triggered on the positive edge of clk and with asynchronous active-low reset.

On reset, the entire RAM initializes to zero via a for loop inside the write always block to ensure synthesis compatibility.

The write port uses write_en to write write_data into RAM at write_addr.

The read port uses read_en to enable reading RAM at read_addr and register the output read_data synchronously to clk, providing stable registered data output one clock cycle after read_en and read_addr are set.

When read_en is low, the read_data output holds its last value (no clearing to zero), to reduce output toggling and glitches.

This approach trades off a 1 clock cycle read latency for stable registered output and simpler synthesis, suitable for designs needing synchronized data capture. The read and write address widths are set based on DEPTH using $clog2.

The RAM array is sized DEPTH x WIDTH, matching the specification.

This design avoids combinational read from RAM, which can be beneficial in certain FPGA and ASIC flows, and registers the output for timing closure.

Overall, this design supports fully independent dual-port RAM behavior with synchronous reset and registered read output.
