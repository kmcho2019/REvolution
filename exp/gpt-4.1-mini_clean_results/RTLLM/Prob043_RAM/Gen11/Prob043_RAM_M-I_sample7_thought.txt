The original solution implements a synchronous reset for the entire RAM, which can cause a power spike and longer reset time. To improve Power and Performance without area penalty:

1. Remove the synchronous reset that clears the entire RAM array on reset. Instead, rely on power-on initialization (or external reset sequence) since initializing the entire memory synchronously is costly.

2. Make the read operation registered rather than combinational to balance timing closure and avoid timing-sensitive combinational read paths. This adds one clock cycle latency on read but improves timing robustness.

3. Retain gated read enable so when read_en is low, the read_data register outputs zero, lowering unnecessary toggling on outputs (improves power).

4. Keep the write synchronous as is.

This tradeoff reduces reset power spikes and improves timing, while keeping the design simple, robust, and minimal area.

Summary of changes:
- Remove synchronous reset logic that clears the RAM.
- Add a read process triggered on clk & rst_n that registers read_data.
- When read_en=0, read_data is 0.
- Address width remains based on DEPTH.
