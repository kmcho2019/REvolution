Implement the dual-port RAM with an asynchronous reset that immediately clears all memory locations to zero at the negative edge of rst_n, using a generate loop with separate always blocks for each RAM location to allow parallel initialization, which can be more efficient in FPGA fabric. Use a registered read_data output updated synchronously on the clock's positive edge when read_en is asserted, and drive it to zero when read_en is low. This approach provides stable and glitch-free read output with one-cycle latency. Writes are synchronous and happen on posedge clk when write_en is high. The address width is calculated by clog2 of DEPTH. This design enables true dual-port operation and avoids combinational read paths, which helps timing closure and reduces glitches on read_data output.
