Implement a simple synchronous dual-port RAM with parameterized WIDTH and DEPTH. Use a reg array sized by DEPTH and WIDTH. On reset, synchronously clear all memory elements to zero using a for-loop. For write operations, write data synchronously when write_en is asserted. For reads, synchronously register read_data at the clock edge when read_en is high, else clear read_data to zero. This approach avoids combinational read complexity and ensures consistent timing with a registered output. The address width is determined by clog2(DEPTH). This simple design keeps read and write operations independent and concurrent.
