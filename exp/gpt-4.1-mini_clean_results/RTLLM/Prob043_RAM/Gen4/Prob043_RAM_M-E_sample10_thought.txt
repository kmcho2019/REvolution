I will implement the dual-port RAM with separate always blocks for read and write operations, both synchronous with the clock and with an active-low synchronous reset for output registers only. The RAM array itself will be initialized once asynchronously via an initial block, which is synthesizable in many FPGA tools and simpler for zero-initialization in this small size. The write operation will happen on posedge clk when write_en is high, storing write_data to RAM at write_addr. The read operation will also occur synchronously: when read_en is high on posedge clk, the RAM content at read_addr is loaded into a registered output read_data. When read_en is low, the output register retains its previous value instead of clearing to zero, to avoid unnecessary toggling and improve power efficiency. The RAM array itself is not cleared after reset because it is initialized once at startup, simplifying the reset logic. Address widths match DEPTH size to minimize decoder size. This design avoids zeroing outputs when not reading (reducing toggling), uses synchronous read for stable read data, and supports simultaneous read and write operations on independent ports.
