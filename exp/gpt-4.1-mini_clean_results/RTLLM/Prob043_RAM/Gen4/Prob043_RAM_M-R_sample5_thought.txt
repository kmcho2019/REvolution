Refactor the design by using an explicit asynchronous reset to initialize the RAM content via a reset process that clears memory locations, and separate synchronous write and registered read logic. The read data output will be registered on the clock to reduce combinational toggling and improve timing. The read enable will gate the registered output, outputting zero otherwise. This structure clearly separates reset, write, and read operations in dedicated always blocks, improving code clarity and ensuring synthesis compatibility with synchronous RAM inferred blocks. The address widths are properly sized to DEPTH, and initialization is done asynchronously.
