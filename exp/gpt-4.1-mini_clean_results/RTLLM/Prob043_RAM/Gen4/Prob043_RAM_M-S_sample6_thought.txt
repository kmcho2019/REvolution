Implement the dual-port RAM as a simple synchronous RAM with separate always blocks for write and read operations. Initialize the RAM on reset by clearing all locations to zero. On each positive clock edge, if reset is active, clear RAM contents and output register; otherwise, perform write if write_en is asserted and perform read if read_en is asserted. Read data output is registered to maintain stable output and reduce glitches. Use minimal complexity without initial blocks or combinational reads.
