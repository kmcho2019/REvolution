Implement a dual-port RAM with synchronous read and write ports, where both read and write operations occur on the rising edge of clk. On reset (!rst_n), the RAM content is initialized to zero using a for loop inside an always block triggered by the negative edge of rst_n, enabling asynchronous reset of RAM contents. The read_data output is registered and updated only when read_en is asserted, otherwise it retains its previous value (no clearing to zero). This reduces unnecessary toggling on read_data output and eliminates combinational read data glitches. Both read and write addresses are WIDTH-bit wide to address DEPTH memory locations. The asynchronous reset allows faster initialization of the memory contents on reset, and synchronous read makes timing more predictable with a one clock cycle read latency.
