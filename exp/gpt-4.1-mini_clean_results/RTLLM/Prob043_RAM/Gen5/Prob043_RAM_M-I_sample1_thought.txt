To improve the original design's PPA (performance, power, area), I will change the read logic from combinational to synchronous with registered output. This will break the critical combinational path caused by direct RAM array access, improving timing (WNS and TNS). It also helps reduce switching activity by updating read_data only when read_en is asserted, thus saving power. To avoid increasing reset latency too much and reduce toggling at reset, I will initialize the RAM asynchronously using an initial block instead of synchronous reset clearing. This approach is commonly supported for FPGA RAM initialization, reduces power on reset, and avoids long reset cycles. The write operation remains synchronous on clock and gated by write_en. The read output will be registered and updated only when read_en is high; otherwise, the output holds its previous value instead of zeroing out, further reducing toggling. Address widths are derived from DEPTH using $clog2 for scalability. This approach optimizes timing and power without significant area impact.
