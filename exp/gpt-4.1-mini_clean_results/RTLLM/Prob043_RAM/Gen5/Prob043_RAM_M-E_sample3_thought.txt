Implement the dual-port RAM with separate always blocks for write and read, both synchronous to clk and with synchronous reset. Use a reg array with parameterized WIDTH and DEPTH. On reset, clear all RAM locations using a for loop inside the write always block. For read, use a separate always block with synchronous reset and read enable gating: when read_en is high, update read_data with RAM content at read_addr; else clear read_data to zero. This approach uses synchronous read operation, adding one cycle latency but improving timing robustness by registering the output data. This also maintains independent read and write ports allowing simultaneous operations.
