Use a single synchronous always block triggered by clk and rst_n to handle both reset initialization and read/write operations. On reset, clear all RAM entries and the read_data output. When not resetting, write to RAM if write_en is asserted, and update read_data from RAM if read_en is asserted; otherwise, clear read_data. This merges read and write logic into one always block and avoids combinational reads, simplifying control while maintaining dual-port functionality and proper initialization.
