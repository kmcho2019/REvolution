Implement a synchronous dual-port RAM with separate read and write ports. Use a two-dimensional reg array for the RAM with 8 locations (depth), each 6 bits wide. On reset (active low), initialize all RAM contents to zero. Write operation updates RAM at write_addr on write_en asserted at clock's rising edge. Read operation captures the data at read_addr on read_en asserted at clock's rising edge. If read_en is low, output zero on read_data. This provides simultaneous read and write capability with independent enables and addresses.
