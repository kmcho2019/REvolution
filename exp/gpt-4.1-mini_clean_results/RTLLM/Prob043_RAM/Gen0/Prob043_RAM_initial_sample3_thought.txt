Implement a dual-port RAM with separate read and write ports operating synchronously on the clock. The RAM depth is 8 with 6-bit data width. The RAM array is defined with 2^WIDTH locations, but only the first DEPTH locations (0 to 7) are valid. On reset, all RAM locations are cleared to 0. Write operations occur on the positive clock edge if write_en is asserted, writing data to write_addr. Read operations occur similarly on the positive clock edge if read_en is asserted, outputting read_data from read_addr. If read_en is deasserted, read_data outputs 0. Both read and write operations can proceed concurrently.
