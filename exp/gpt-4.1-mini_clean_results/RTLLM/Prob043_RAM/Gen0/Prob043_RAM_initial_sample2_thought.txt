Implement a dual-port RAM with separate read and write ports, synchronous reset, and initialization of all locations to zero on reset. The RAM has depth 8 and width 6 bits. The RAM array is reg [WIDTH-1:0] RAM [0:DEPTH-1]. The write and read addresses are 3 bits wide (to address 8 locations). Write operation occurs on posedge clk if write_en is high, read operation similarly on posedge clk if read_en is high. On reset, RAM is zeroed and read_data is cleared.
