Implement a dual-port RAM module with a parameterized width (6) and depth (8). The RAM array has DEPTH entries, each WIDTH bits wide. On reset, initialize all memory to zero. The write operation occurs on the rising edge of clk when write_en is asserted, writing write_data into RAM at write_addr. The read operation occurs on the rising edge of clk when read_en is asserted, reading RAM at read_addr into the read_data output register. If read_en is deasserted, read_data is cleared to zero. Both operations are synchronous and can occur simultaneously.
