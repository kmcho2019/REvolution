Implement a 4-bit Fibonacci LFSR with a parallel feedback calculation using a parameterized feedback polynomial tap mask, allowing easy reconfiguration. The LFSR state is stored in a 4-bit register updated on every rising clock edge. The reset is synchronous and active-high, initializing the LFSR to a non-zero seed to avoid lock-up at zero.

Key novel architectural points:
1. Parameterizable taps: Define a parameter `TAPS` that encodes which bits participate in feedback XOR, making the design flexible.
2. Use a generate loop with a for-loop and a reduction XOR to compute feedback from tapped bits, improving scalability.
3. Implement feedback calculation as a function to encapsulate the XOR of tapped bits.
4. Output the current LFSR state directly as the output.
5. Provide a simple testbench that applies reset, clocks the LFSR for 20 cycles, and prints the output to observe pseudo-random sequence generation.

This design is clean, scalable for other bit widths with minor changes, and emphasizes modularity and reusability.
