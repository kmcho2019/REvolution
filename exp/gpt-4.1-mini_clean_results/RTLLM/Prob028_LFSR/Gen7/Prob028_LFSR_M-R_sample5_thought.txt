Refactor the 4-bit LFSR implementation by using a combinational always block to compute the next state from the current state and feedback, then register the next state synchronously on the clock edge with a synchronous reset. 

This approach:
- Separates next-state logic and state register update clearly, aiding understanding and potential modifications.
- Uses synchronous reset only for simpler timing on many FPGA architectures.
- Declares the output as a register driven by the state register for a conventional synchronous style.
