Implement a 4-bit LFSR using a parallel-feedback approach with a simple combinational logic block computing the next state in one cycle, rather than shifting bit by bit manually. The feedback is still the inverted XOR of bits 3 and 2 of the current state.

To add variation from the typical shift-left approach, implement the state update as a next-state function that maps the current state bits directly to the new bits. This allows expression of the LFSR as a small FSM with explicit next-state logic, making it easier to analyze and potentially optimize.

Use an asynchronous active-high reset that sets the state to a non-zero seed (e.g., 4'b1001) to avoid lock-up.

The module outputs the current state as `out`. On each clock edge, the state updates per the combinational next state function.

This design demonstrates an alternative architectural perspective on LFSR implementation by emphasizing next-state combinational logic rather than explicit bit shifting.
