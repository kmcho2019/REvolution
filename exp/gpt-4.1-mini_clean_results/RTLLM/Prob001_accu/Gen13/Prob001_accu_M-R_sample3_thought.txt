Refactor the design by implementing a simple finite state machine (FSM) with two states: ACCUMULATE and OUTPUT. The FSM transitions from ACCUMULATE state, accumulating incoming valid data, to OUTPUT state when four valid inputs are collected. In OUTPUT state, the accumulated sum is assigned to data_out and valid_out is asserted for one clock cycle. Then, it returns to ACCUMULATE state. This structure improves clarity by explicitly representing the accumulation phase and the output phase separately. Also, register updates happen within defined states, which could help synthesis tools optimize control flow.
