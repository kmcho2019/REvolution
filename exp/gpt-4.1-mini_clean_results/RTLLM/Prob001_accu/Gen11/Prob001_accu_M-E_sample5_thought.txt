Implement a serial accumulator using an internal shift register that collects four 8-bit inputs before summation. On each valid_in, shift the incoming data into a 4-entry array. When the 4th data arrives, compute the sum of the four stored values in a combinational block, and output the result with a one-cycle valid_out pulse. This separates data accumulation (in a small FIFO) from sum calculation, allowing summation only once per 4 inputs, potentially reducing critical path during input cycles. Use a 2-bit counter to track how many valid inputs have been collected. Reset logic is synchronous active low.
