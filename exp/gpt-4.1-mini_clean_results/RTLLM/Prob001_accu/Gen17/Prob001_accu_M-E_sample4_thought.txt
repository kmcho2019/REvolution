Implement a two-stage accumulation approach using two registers: one to accumulate the sum of incoming data sequentially, and another to count the number of valid inputs received. Instead of waiting to add all four inputs together at once, each valid_in data_in is added immediately to an accumulator register in every clock cycle where valid_in is high. When the count reaches 4, output the accumulated sum and assert valid_out for one cycle, then reset the accumulator and count to zero to start a new accumulation cycle.

This approach simplifies the logic by using only a single accumulator register and counter, updating them atomically every valid data input. It cleanly separates counting and accumulation and emits the output synchronously with the last valid input. Reset logic ensures that the registers start from zero on reset. The accumulator width is 10 bits to accommodate sums up to 4 * 255 = 1020, fitting within 10 bits comfortably.

This design trades off a slight addition operation every cycle with valid input for simplicity and minimal logic. The 1-cycle valid_out pulse correctly flags each output with exactly 4 accumulated inputs. No extra enable signals are required other than valid_in itself.
