Refactor the design by implementing a simple finite state machine (FSM) with two states: IDLE and ACCUMULATE. Use a synchronous process to accumulate data and count inputs only when valid_in is asserted and the FSM is in ACCUMULATE state. When 4 inputs are accumulated, output the sum, assert valid_out for one cycle, then return to IDLE. This structure clearly separates the accumulation phase and output phase, improving readability and maintainability. The accumulator and counter updates occur synchronously inside the FSM, and valid_out is generated based on FSM state transition. The addition remains combinational, but managed inside the FSM. This approach avoids using combinational logic outside always blocks and explicitly handles data accumulation control via states.
