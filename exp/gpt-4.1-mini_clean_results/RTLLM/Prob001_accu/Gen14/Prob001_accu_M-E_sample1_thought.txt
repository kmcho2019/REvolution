Use a shift register approach to store the last four valid data inputs and a separate accumulation register. On each valid_in pulse, shift the new data into a 4-entry FIFO (implemented as a small array), accumulate the sum by adding the newly input data and subtracting the oldest data removed from the FIFO. This sliding window accumulator approach avoids a multi-stage adder summing all four data each time and keeps updates local. When four data inputs are collected (count==4), output the accumulated sum in data_out, pulse valid_out for one cycle, and then continue accumulating for next four inputs.

This method uses the property that the sum of four numbers in the FIFO can be maintained incrementally by sum += new_data - old_data, enabling efficient accumulation. The counter tracks how many valid inputs have been received, and output is generated each time four data inputs have been accumulated. It ensures a one-cycle valid_out pulse, with data_out valid only at that time.

This approach is novel compared to simple add-and-reset designs and can be more efficient for streaming or overlapping accumulation windows, although in this problem we accumulate in strict groups of four. The design is synchronous with an active low reset, uses non-blocking assignments, and minimal combinational logic.
