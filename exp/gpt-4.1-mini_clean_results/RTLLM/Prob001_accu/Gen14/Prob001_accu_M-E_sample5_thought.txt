Instead of a single accumulator and counter, use a small 4-entry register array to store each incoming valid data and accumulate them only when the 4th valid input arrives. This allows capturing and storing the 4 input data values explicitly, which may help debugging and future feature extensions (e.g., outputting individual values). On the 4th valid input, sum all four registers combinationally and output the result with a valid_out pulse. The registers and counter reset after output. This approach separates storage and accumulation, and uses combinational summation only once per 4 inputs.
