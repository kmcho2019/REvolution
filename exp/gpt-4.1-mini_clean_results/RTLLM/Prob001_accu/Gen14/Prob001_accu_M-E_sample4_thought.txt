Instead of accumulating the input data one by one in a single accumulator register, the design can use a small FIFO-like shift register (4 registers) to hold the four incoming valid data_in values, then perform a parallel addition once all four data are collected. This approach separates data collection and summation, which can be helpful if the addition operation is complex or if we want to pipeline the summation step. 

Implementation details:
- Use a 2-bit counter to track how many valid inputs have been received.
- On each valid_in, shift data_in into a 4-entry register array.
- When the 4th data is received, perform addition of all four entries to produce data_out and assert valid_out.
- Reset counter and repeat.
- This architecture provides clear separation of data capture and sum logic, potentially enabling pipelining or reuse in more complex scenarios.

The output valid_out lasts only 1 cycle immediately after summation.

The data_out is 10-bit to cover max sum (4 * 255 = 1020 fits in 10 bits).
