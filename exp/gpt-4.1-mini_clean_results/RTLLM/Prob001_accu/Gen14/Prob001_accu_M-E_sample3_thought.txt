Use a shift register style accumulation where each incoming valid data is added to the accumulator, and a separate counter tracks the number of valid inputs. Once 4 valid inputs are accumulated, the output sum and a valid_out pulse are produced. Additionally, latch the incoming data first to remove timing ambiguity and separate accumulation logic. The output valid_out is registered to ensure a one-cycle pulse after the 4th data input is processed. This modular approach cleanly separates data input capturing, accumulation, and output signaling.
