Use a shift-register style accumulation: maintain a 4-entry FIFO (shift register) to store the last 4 valid inputs and sum them only when the 4th input arrives. On each valid_in, shift data_in into the FIFO and increment count. When count reaches 4, sum the 4 stored values and output the result along with valid_out pulse. This approach separates data storage from summation, making timing paths simple, and enables easy extension if accumulation length changes. The sum is computed combinationally from the FIFO entries, ensuring correct output timing and a clean one-cycle valid_out pulse.
