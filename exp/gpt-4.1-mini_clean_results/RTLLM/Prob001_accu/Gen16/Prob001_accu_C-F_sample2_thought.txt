Accumulate the first three inputs progressively in the accumulator. On receiving the 4th input (when count is 3), add data_in to the accumulator to produce the final sum, output data_out and assert valid_out for one cycle. Then reset accumulator and count for the next accumulation.

By accumulating only the first three inputs and adding the 4th input directly in the output assignment, the design avoids adding data_in twice in the same cycle and reduces combinational logic delay on non-output cycles, which enhances timing.

Also, default valid_out to 0 at each clock edge ensures a clean single-cycle valid pulse.

This fusion optimizes timing by minimizing critical path delay, lowers power by gating updates to valid_in cycles, and maintains minimal area with just a 10-bit accumulator and 2-bit counter.
