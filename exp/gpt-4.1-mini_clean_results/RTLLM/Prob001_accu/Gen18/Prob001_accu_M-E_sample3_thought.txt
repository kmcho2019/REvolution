Use a two-stage pipeline approach to accumulate four valid input data values. In the first stage, accumulate the first two valid inputs into a 9-bit partial sum register. In the second stage, once two more valid inputs are received, add them together and then add this second partial sum to the first partial sum to produce the final 10-bit accumulated sum. This breaks the addition into smaller parts and may help timing by shortening the critical path in the accumulation process.

Track the count of valid inputs with a 3-bit counter to know which input number is being processed (0 to 3). When the count reaches 3 (meaning 4 inputs accumulated), output the final sum, assert valid_out for one cycle, and reset the counter and partial sums. Use synchronous reset and ensure valid_out pulses only for one cycle.

This design reduces addition width at each step (accumulating pairs of 8-bit inputs to 9-bit partial sums), which can improve timing, and also clearly separates data accumulation from output generation, providing a neat pipeline structure and possibly better timing and clarity.
