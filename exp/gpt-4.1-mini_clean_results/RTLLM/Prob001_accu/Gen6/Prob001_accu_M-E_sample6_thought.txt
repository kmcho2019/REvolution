Implement the accumulator using a shift-register style approach: store each of the four input data samples in an array on valid input cycles. Once the fourth sample is stored, sum all four stored values in a combinational block and register the result for output with a one-cycle pulse of valid_out. This separates storage and accumulation, simplifying the timing of addition by performing the sum in one cycle only when needed, and avoids adding new input to an accumulator every cycle, potentially reducing switching activity and critical path length.
