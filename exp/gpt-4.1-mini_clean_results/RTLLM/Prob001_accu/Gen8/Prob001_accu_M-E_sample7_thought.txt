Instead of accumulating all four inputs in a single register and resetting after the fourth input, this design uses a small shift register array to store the four incoming 8-bit inputs. When the fourth valid input arrives, it performs a parallel addition of all four stored inputs simultaneously using a combinational adder tree, and outputs the result in one cycle. This allows the accumulation logic to be purely combinational, and registers hold the individual inputs, simplifying the control logic. The valid_out signal is asserted for one cycle right after the fourth valid input is received. After output, the shift registers are cleared to prepare for the next batch. This approach may help timing by separating storage and addition stages and supports pipelining the adder tree if needed.
