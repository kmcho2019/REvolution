Refactor the design using a simple Finite State Machine (FSM) with two states: IDLE and ACCUMULATE. When valid_in is asserted, move to ACCUMULATE state and start accumulating inputs. Keep a 2-bit counter to count how many valid data have been received. Once 4 valid data are accumulated, output the sum, assert valid_out for one cycle, then reset and return to IDLE waiting for new inputs. Use combinational logic for next state and outputs, and sequential logic for state and registers. This approach cleanly separates state control and accumulation logic, enhancing readability and modularity.
