Implement a fully combinational adder tree accumulating four 8-bit inputs stored in a small FIFO-like shift register, updating only when valid_in is high. On each valid input, shift the new data into a 4-entry register array. Use a 4-count counter to track valid inputs. When count reaches 4, output the sum of all four stored inputs simultaneously using a combinational addition tree, assert valid_out for one cycle, then reset counter and clear registers. This approach separates storage and addition clearly, enabling immediate sum calculation from stored inputs, which can reduce register toggle activity compared to accumulating partial sums. Reset is synchronous with active low rst_n. The data_out width (10 bits) fits max sum of four 8-bit numbers (max 4*255=1020). This solution trades slightly higher area for clearer separation of input buffering and summation logic, which may aid timing and verification.
