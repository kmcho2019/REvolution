Implement a design using a shift register style approach: store the incoming valid data_in samples in a 4-element 8-bit register array whenever valid_in is high. Maintain a 2-bit counter to track the number of valid inputs stored. Once the counter reaches 4, sum all four stored inputs in a separate combinational block and output the sum together with valid_out asserted for one cycle. Then reset the counter to zero and clear the registers. This separates data storage from summation, keeping the accumulation logic only active on the valid output cycle, potentially easing timing and power since addition only occurs once per 4 inputs rather than every cycle.
