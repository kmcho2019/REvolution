Implement a simplified 3-cycle floating-point multiplier pipeline with clear stage separation and minimal control signals. On reset, all registers clear. 

Cycle 0: Extract sign, exponent, mantissa, and special flags (zero, inf, NaN) from inputs. Compute initial exponent sum and sign XOR.

Cycle 1: Multiply mantissas combinationally and register product.

Cycle 2: Normalize the product if MSB set, adjust exponent, extract rounding bits (guard, round, sticky), perform round-to-nearest-even, handle rounding overflow.

Output result handling: 
- Special cases: NaN, Inf, zero, and invalid operations (Inf*0 => NaN).
- Overflow => Inf, Underflow or zero exponent => zero (no subnormals supported).
- Else normal result.

This simpler pipeline uses a 3-bit counter to track stages, registers only required signals at each stage, avoids complicated flags or multiple pipeline signals for special cases by handling in final stage. Rounding and normalization are done in the last cycle only, not mixing multiple steps.

No complicated functions or separate combinational functions; logic is straightforward and clear for maintenance.
