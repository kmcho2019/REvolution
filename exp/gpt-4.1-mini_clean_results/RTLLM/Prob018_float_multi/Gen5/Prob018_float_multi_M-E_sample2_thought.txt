Implement the 32-bit IEEE-754 floating-point multiplier as a pipelined four-stage design, where each pipeline stage completes a part of the multiplication. This pipeline architecture allows high throughput with one result per cycle after initial latency.

Stage 1: Input decode and special-case detection
- Extract sign, exponent, and mantissa from inputs.
- Detect special cases (NaN, infinity, zero).
- Prepare mantissas with implicit leading bit for normals or zero for subnormals.

Stage 2: Mantissa multiplication and exponent addition
- Multiply the 24-bit mantissas (including implicit bit) to get a 48-bit product.
- Add exponents, subtract bias (127).
- Compute sign XOR.
- Pass forward special cases info and intermediate results.

Stage 3: Normalization and rounding preparation
- Normalize the 48-bit product mantissa (shift right by one if top bit not set and adjust exponent accordingly).
- Extract guard, round, and sticky bits for rounding.
- Handle edge cases: exponent overflow, underflow.

Stage 4: Final rounding and packing
- Perform round-to-nearest-even rounding using guard/round/sticky bits.
- Adjust exponent if rounding causes mantissa overflow.
- Handle special cases by overriding output appropriately.
- Pack sign, exponent, and mantissa to output format.

The pipeline registers between stages store all intermediate signals needed for the next stage. This structure enables continuous operation with high throughput.

This design differs from FSM approaches by using pipeline stages explicitly and handles special cases in parallel with the data path. The pipeline stages are simple combinational functions registered at clock edges.

The implementation includes:
- Dedicated pipeline registers between stages.
- Explicit special case propagation.
- Correct zero detection with exponent==0 and fraction==0.
- Support for all IEEE-754 special cases (NaN, Inf, Zero).
- Proper rounding and normalization.
