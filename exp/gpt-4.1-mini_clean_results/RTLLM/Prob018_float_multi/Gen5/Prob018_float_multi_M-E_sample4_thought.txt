Implement a fully pipelined 5-stage IEEE-754 single-precision floating-point multiplier to maximize throughput and minimize combinational delay per clock cycle. Each pipeline stage operates on registers that hold partial results, breaking down the complex floating-point multiply into manageable sequential steps:

1. **Stage 1 (Input Capture & Decode):** Extract sign, exponent, mantissa from inputs; handle zero and special cases early. Extend mantissa to 24 bits with implicit leading 1 for normal numbers. Determine if inputs are NaN, infinity, or zero and register these flags.

2. **Stage 2 (Multiply Mantissas):** Multiply 24x24 mantissas to get 48-bit product; simultaneously calculate combined sign and preliminary exponent sum (subtracting bias).

3. **Stage 3 (Normalize Product):** Detect whether the product’s leading bit is at bit 47 or 46 (to detect if we need a shift and exponent increment). Shift mantissa accordingly and extract guard, round, sticky bits for rounding.

4. **Stage 4 (Rounding):** Perform round-to-nearest-even using guard, round, and sticky bits. If rounding causes mantissa overflow, shift mantissa right and increment exponent.

5. **Stage 5 (Pack & Special Cases):** Check special cases and overflow/underflow; produce final IEEE-754 result accordingly.

This pipeline offers one result per cycle after latency of 5 cycles. Using pipeline registers improves clock frequency and cleanly separates complex logic, enabling easier verification and synthesis. Special case detection is done early and forwarded throughout pipeline stages to simplify final packing.

The design avoids multiple assignments to the same register in one clock by assigning pipeline registers only once per stage, ensuring clear data flow. The sticky bit is computed efficiently using OR reduction of lower bits. The exponent calculations are done with signed arithmetic using 10-bit registers for safety. No FSM is needed; the pipeline runs continuously, processing input operands each cycle (if valid input is provided each cycle). This is suitable for high-throughput floating-point multiplication.

Reset initializes pipeline registers to default zero values.
