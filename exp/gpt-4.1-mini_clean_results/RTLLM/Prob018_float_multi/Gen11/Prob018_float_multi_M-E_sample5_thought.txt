Implement a fully combinational IEEE-754 single-precision floating-point multiplier that computes the result in a single clock cycle. 

Key points:
- On every clock edge, the module samples inputs and immediately outputs the multiplication result.
- No internal pipeline stages or counters; the design relies on combinational logic for extracting fields, detecting special cases, multiplying mantissas, exponent calculation, normalization, rounding, and packing the output.
- The mantissa multiplication is a 24x24-bit combinational multiplier producing a 48-bit product.
- Exponent is added with bias correction.
- Normalization checks the most significant bits of the product to determine shift.
- Rounding follows round-to-nearest-even using guard, round, and sticky bits.
- Special cases (zero, infinity, NaN) are handled with priority.
- This design trades longer combinational path (lower max frequency) for minimal latency and simpler control logic.
- Reset is asynchronous and simply clears the output.
- Output is registered to hold the result stable between clock cycles.
- This single-cycle approach is suitable where latency is critical and clock frequency can be kept moderate.

This approach contrasts with the cycle-counted FSM pipeline by having no intermediate registers or cycle counting, simplifying timing analysis and integration in simpler systems.
