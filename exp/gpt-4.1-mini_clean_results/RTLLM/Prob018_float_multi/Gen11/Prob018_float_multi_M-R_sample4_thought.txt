Refactor the design to implement the IEEE-754 single-precision floating-point multiplier as a multi-cycle sequential module using a small finite state machine (FSM) controlled by the `counter` register. On each clock cycle, the module extracts fields, handles special cases, performs mantissa multiplication, normalization, rounding, and final assembly step-by-step. This spreads the complex combinational logic across multiple clock cycles, improving timing and allowing easier debugging and scaling.

Key points of refactoring:
- Use the 3-bit `counter` as a cycle/state controller for sequential processing.
- Use `reg` variables for intermediate signals (`a_mantissa`, `b_mantissa`, `a_exponent`, `b_exponent`, `a_sign`, `b_sign`, `product`, etc.) updated synchronously.
- Perform field extraction and special case detection on cycle 0.
- Execute mantissa multiplication on cycle 1.
- Normalize and calculate exponent on cycle 2.
- Perform rounding, assemble final result, and output on cycle 3.
- Use `assign` for simple combinational extractions but mainly sequential logic for stepwise processing.
- Maintain synchronous reset clearing the counter and output.
- This multi-cycle approach reduces combinational path length and allows easier future pipelining or extension.

This approach trades throughput for higher frequency and clearer control logic.
