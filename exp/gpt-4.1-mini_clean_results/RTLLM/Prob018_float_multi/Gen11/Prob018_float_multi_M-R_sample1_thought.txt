Refactor the floating-point multiplier by splitting the logic into pipeline stages using a simple FSM with the 3-bit counter to sequence the operations over multiple clock cycles. This enables partial computations per cycle, reduces combinational path delay, and uses synchronous registers to hold intermediate signals. We will:

- Use the counter to sequence: cycle 0 input extraction and special case detection; cycle 1 multiplication and exponent calculation; cycle 2 normalization and rounding; cycle 3 output assembly and registration.
- Replace large combinational always @* block with registered intermediate signals for better timing.
- Use assign statements for simple continuous logic (e.g., sign XOR).
- Use internal registers for mantissas, exponents, signs, special flags, product, normalized mantissa, exponent, and rounding bits.
- Final output registered on cycle 3.
- On rst, counter resets to 0 and output zero.
  
This structure maintains the same IEEE-754 IEEE single precision multiplication algorithm and rounding scheme but is implemented as a small pipelined FSM with explicit multi-cycle sequencing and registered intermediate signals, improving timing and structural clarity.
