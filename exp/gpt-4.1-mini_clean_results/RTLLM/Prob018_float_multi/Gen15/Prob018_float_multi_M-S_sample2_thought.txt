Simplify the float_multi module by using a straightforward FSM-based multi-cycle approach with explicit cycle counter for sequencing the steps. 

Key simplifications:
- Use a 3-bit counter to step through input capture, multiplication, normalization, rounding, and output stages sequentially to spread combinational complexity across cycles, reducing critical path.
- Keep internal signals as specified: a_mantissa, b_mantissa, product, exponent, sign registers, rounding bits, and exponent width expanded to 10 bits.
- Extract input fields and detect special cases in cycle 1.
- Multiply mantissas in cycle 2.
- Normalize, round, adjust exponent in cycle 3.
- Finalize output in cycle 4.
- Use simpler rounding logic (round to nearest even).
- Handle special cases by generating predefined outputs when detected.
- Output the final z result synchronized with clk.
- Reset synchronously on rst.

This approach yields simpler combinational logic per cycle, easier timing closure, and reduces overall complexity while maintaining IEEE-754 correctness and the specified internal signals.
