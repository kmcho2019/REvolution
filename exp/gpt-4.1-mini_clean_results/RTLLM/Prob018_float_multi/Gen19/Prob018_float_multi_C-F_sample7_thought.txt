The cycle breakdown:

- Cycle 0: Extract fields, detect special cases, prepare mantissas (with implicit leading bits), compute sign.

- Cycle 1: Multiply mantissas (24x24), sum exponents with bias adjustment, register product.

- Cycle 2: Normalize product, calculate rounding bits (guard, round, sticky), adjust exponent accordingly.

- Cycle 3: Apply rounding to nearest even, handle exponent overflow/underflow, special cases output, register final result.

- Then cycle resets to 0 for next operation.

This organization balances latency (4 cycles) and synthesis performance, clarity, and correctness.
