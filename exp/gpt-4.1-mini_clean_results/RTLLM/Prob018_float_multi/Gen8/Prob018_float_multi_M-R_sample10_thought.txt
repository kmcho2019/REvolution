Refactor the design into a combinational pipeline stage logic driven by an explicit cycle counter state machine rather than multiple always blocks for each pipeline stage. The operation proceeds step-by-step on the clock using a 3-bit counter to sequence through input decode, multiplication, normalization, and rounding/output stages. Internal signals hold intermediate values updated each cycle based on the counter, which controls which computation happens.

Key points of refactor:
- Use a 3-bit counter driven by clk and rst to control pipeline stages (0 to 4).
- Extract inputs and special case detection in counter=0 cycle.
- Perform mantissa multiplication and exponent addition in counter=1 cycle.
- Normalize product and extract rounding bits at counter=2.
- Round and prepare output at counter=3.
- Output stable for one cycle (counter=4), then back to idle.
- Use combinational assignments with registers updated synchronously based on counter.
- Use blocking assignments inside combinational always block to reflect sequential operations for clarity.
- Keep internal exponents 10-bit to safely handle overflows.
- Handle special cases explicitly during output stage.
- Avoid multi-stage registers but keep all intermediate signals in registered variables.
- Output result updated only at the end stage.
- This style improves cycle-controlled clarity and shows a direct FSM approach instead of pipelined parallelism, making timing and debugging simpler at cost of throughput.

This refactor retains full IEEE 754 compliance, normalization, rounding-to-nearest-even, and all special case handling, but structures control as a small finite state machine with explicit pipeline cycle counter instead of separate pipeline stages.
