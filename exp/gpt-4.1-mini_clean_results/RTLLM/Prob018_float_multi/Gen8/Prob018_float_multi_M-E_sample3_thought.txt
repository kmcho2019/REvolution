Implement a combinational 32-bit IEEE-754 floating-point multiplier with internal sequential control via a simple 3-bit counter for a latency of 3 cycles, focusing on minimal pipeline stages. This design uses a finite state machine (FSM)-like approach driven by the counter that sequences extraction, multiplication, normalization, rounding, and output generation.

Key architectural ideas:
- Use the counter to sequence through stages explicitly rather than pipelining all stages at once.
- Perform sign, exponent extraction, and special case detection in cycle 1.
- Compute mantissa multiplication and initial normalization in cycle 2.
- Final normalization, rounding, and output formatting happen in cycle 3.
- Outputs are registered to ensure timing consistency with the clock.
- Sticky bit is generated by OR-reducing shifted out bits.
- Rounding uses round to nearest even, following IEEE rounding rules.
- Handle special cases like zero, infinity, and NaN explicitly.
- Keep exponents as 10-bit internally (to allow for adjustments and detect overflow/underflow), mantissas 24-bit including implicit leading bit.
- Use registers for all internal signals to simplify timing and make it a controlled multi-cycle design, minimizing the combinational path at each clock cycle.
- Reset clears all registers and resets counter.
This approach avoids deep pipeline and complex combinational logic per cycle, trading throughput for simpler control and possibly reduced area/power. It uses a clear FSM cycle counter-based design.

This novel approach clearly sequences steps, minimizes complexity per cycle, and is straightforward for synthesis and verification.
