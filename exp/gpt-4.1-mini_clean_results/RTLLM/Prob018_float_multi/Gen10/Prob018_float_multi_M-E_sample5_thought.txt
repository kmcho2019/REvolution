Implement the 32-bit IEEE-754 floating-point multiplier as a fully combinational multiplier followed by a registered output. 

Key points of this approach:
- Inputs and output synchronized by clk and rst, but the multiplication computation is combinational within one clock cycle.
- Extract sign, exponent, and mantissa fields combinationally on every clock, then perform:
  1) Special case detection (zero, infinity, NaN) combinationally.
  2) Mantissa multiplication (24x24 bits) combinationally.
  3) Exponent addition with bias adjustment combinationally.
  4) Normalize the mantissa output by checking the top bits.
  5) Apply round-to-nearest-even using guard, round, sticky bits.
  6) Handle overflow, underflow, and special cases combinationally.
- Register the final output 'z' on the clock edge to create a synchronous interface.
- This architecture reduces pipeline complexity, eases timing closure at low frequencies, and fits designs where latency of one clock cycle is acceptable.
- Internal intermediate signals are purely combinational; the sequential logic only registers inputs and outputs.
- This approach contrasts with multi-cycle or multi-stage pipeline by relying on combinational logic depth within one clock cycle.
- Uses internal 50-bit multiplication and rounding logic.
- Special cases are prioritized in output logic.
- No internal counters or staged registers except input and output registers.
- Suitable for applications requiring one-cycle latency multiplier without pipeline overhead.

This simple but effective design is a clean, well-structured combinational multiplier with synchronous interface.
