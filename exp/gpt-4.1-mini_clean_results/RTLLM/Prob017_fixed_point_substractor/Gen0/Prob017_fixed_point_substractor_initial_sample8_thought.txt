Implement a parameterized fixed-point subtractor module with inputs and output of N bits, where Q bits represent the fractional part. The inputs use two's complement fixed-point representation. The subtraction is done by analyzing the signs of inputs a and b. If signs are the same, perform straightforward subtraction; if signs differ, perform addition of absolute values and set sign accordingly. Handle the zero result by clearing the sign bit. The internal register res holds the intermediate result, which is then assigned to output c.
