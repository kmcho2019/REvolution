The module fixed_point_subtractor will take two N-bit fixed-point inputs with Q fractional bits each and produce an N-bit fixed-point output that is their subtraction (a - b). To handle fixed-point subtraction precisely:

- Extract sign bits of a and b.
- If signs are the same, subtract magnitudes directly.
- If signs differ, add magnitudes and determine sign of result by comparing magnitudes.
- Use an internal register to store the intermediate result.
- Explicitly clear the sign bit if the result is zero to avoid negative zero.
- Since inputs and outputs are in two's complement, subtraction and addition operations can be done at the raw bit-level, but the logic for sign handling and magnitude comparison has to consider two's complement representations.
- Magnitude comparison is done by comparing absolute values.
- Output result in two's complement format.

We implement the logic in combinational always block for immediate subtraction result, with parameters Q and N to define the fixed-point format.
