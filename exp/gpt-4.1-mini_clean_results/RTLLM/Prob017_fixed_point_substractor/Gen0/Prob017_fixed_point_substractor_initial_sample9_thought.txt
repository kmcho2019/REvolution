Implement a parameterized fixed-point subtractor module that takes two N-bit fixed-point inputs with Q fractional bits. The subtraction operation handles sign and magnitude explicitly: if inputs have the same sign, subtract magnitudes and keep the sign; if different signs, add magnitudes and determine the result sign based on which operand has the larger absolute value. The result register stores the outcome, and when the result is zero, the sign bit is forced to zero. The fixed-point format is signed with the MSB as sign bit.
