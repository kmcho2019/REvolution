Refactor the fixed_point_subtractor to use purely combinational `assign` statements instead of an `always` block. This simplifies the code by relying on Verilog's signed arithmetic and removes explicit two's complement manipulations by interpreting inputs and intermediate signals as signed numbers.

Key points:
- Declare inputs and internal signals as signed to naturally handle sign and magnitude.
- Extract sign bits for logic decisions, but perform arithmetic directly on signed values.
- For same sign inputs: result = a - b.
- For different sign inputs: result = a + b (since b is negative or positive, addition of signed values naturally implements the correct behavior).
- For zero result, explicitly set sign bit to zero.
- Use parameterized widths and signed declarations to maintain fixed-point precision and bit widths.
- The output is assigned directly from the computed signed result, ensuring correct fixed-point subtraction behavior.
- This approach is clearer, synthesis-friendly, and easy to read.
