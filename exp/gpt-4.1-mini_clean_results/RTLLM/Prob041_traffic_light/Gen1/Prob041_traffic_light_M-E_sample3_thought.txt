Use a Moore finite state machine with four states: idle, red, yellow, and green. Use a single 8-bit down counter to time the current state's duration. On reset, move to idle and initialize the counter for red time (10 cycles). From idle, immediately transition to red. In each state, count down every clock cycle. When count reaches zero, transition to the next state with the appropriate time preset: green (60), yellow (5), red (10). When in green state and the pedestrian button is pressed, if remaining count is greater than 10, shorten it to 10 by loading counter with 10. Outputs are directly derived from the current state, no separate registers needed for outputs. This avoids conflicting assignments. Pedestrian light is implicit as per problem statement. This cleanly separates state transitions and counter update in one always block triggered on clock and reset. The counter is only updated inside this block to avoid multiple drivers.
