Implement the traffic light as a Moore FSM with four states to better separate the transitions and output assignments: IDLE, RED, GREEN, and YELLOW. Use an 8-bit down counter for timing. On reset, go to IDLE for one clock cycle, then RED. For pedestrian button logic, on GREEN state, if a request is received and remaining green time is more than 10, immediately shorten the green counter to 10; otherwise, leave it unchanged. Use registers to store outputs (red, yellow, green), the current state, and the counter. The counter reload values correspond to the state durations. Transitions occur when the counter reaches zero. Outputs update synchronously. This modular state division improves clarity, allows easier output control, and separates initialization from normal operation.
