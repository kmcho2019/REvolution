Implement the traffic light controller using a Moore FSM with explicit states encoding both the light color and timing phase.  
Use a separate 8-bit down counter that reloads based on the current state duration, enabling clear timing control.  
Integrate the pedestrian button by dynamically adjusting the green state's counter reload value: if a request is detected during green and the current counter is above 10, reset it to 10 to shorten the green phase.  
Store outputs directly tied to the state encoding to eliminate the need for additional registers tracking previous outputs.  
The state machine has four states: IDLE (init), RED, GREEN, YELLOW, with well-defined durations.  
Use synchronous reset and synchronous state/counter updates for clean timing.  
Assign the output clock as the current counter value for external monitoring.  
This approach cleanly separates timing, state transitions, and output signaling with minimal combinational complexity.
