Implement a finite state machine with states idle, s1_red, s2_yellow, and s3_green, which represent red, yellow, and green traffic light states, respectively. Use a counter (cnt) to count down the duration in each state. The initial count for each state is 10 for red, 5 for yellow, and 60 for green as specified. The state transitions occur when the counter reaches zero. The pedestrian button shortens the remaining green time to 10 if it's greater than 10; otherwise, it remains unchanged. The outputs red, yellow, and green represent the current light status. The previous states of these signals are kept in p_red, p_yellow, and p_green to detect edges for counter reload. The output clock is the current count value.

The first always block handles the next state and output signal logic based on the current state and counter. The second always block handles the counter decrement and reload logic including handling the pedestrian request as specified. The third always block registers the outputs red, yellow, and green from their next values p_red, p_yellow, and p_green. This approach ensures proper timing, state transitions, and output control.
