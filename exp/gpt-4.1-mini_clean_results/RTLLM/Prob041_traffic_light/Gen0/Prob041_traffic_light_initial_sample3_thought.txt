Implement a finite state machine (FSM) with four states: idle, s1_red, s2_yellow, and s3_green. The FSM cycles through these states with respective timing counts of red=10, green=60, yellow=5 (note: these counts correspond to the problem description, except that idle is a reset/init state).

The counter (cnt) counts down each clock cycle and triggers state transitions when it reaches zero. The pedestrian pass_request only affects green state by shortening the remaining green time to 10 cycles if it is currently more than 10.

The outputs red, yellow, green are registered signals updated at each clock, and their next state values (p_red, p_yellow, p_green) are assigned combinationally based on the current state. The counter is reloaded on state transitions or when pass_request conditions apply.

Follow the problem's recommended design and signal names exactly.

Note: Although the problem describes s1_red as lasting 3 clocks in the example implementation, the timing for red/yellow/green are specified as 10/5/60 clock cycles respectively, so I will use these values in the actual implementation as required.
