Implement a finite state machine (FSM) with four states: idle, s1_red, s2_yellow, s3_green. The state transitions depend on the counter `cnt` counting down. The `cnt` is loaded with different values for each state: red = 10, yellow = 5, green = 60. When a pedestrian pass_request is asserted during green state and the counter is above 10, shorten the green time to 10. The previous output values are stored in registers p_red, p_yellow, p_green and assigned to outputs. The output clock is assigned the current counter value.
