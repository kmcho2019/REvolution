To improve PPA (Power, Performance, Area) while preserving correctness, the main optimization targets are:

1. Avoid combinational timer decrement each cycle in next-state logic to reduce critical path and power. Instead, decrement the timer synchronously inside the clocked always block; combinational logic will only decide next state and possible timer reloads.

2. Move pedestrian button check into the synchronous block, updating the timer register directly to avoid combinational conditional assignments of next_timer. This prevents unnecessary combinational timer comparisons on every cycle.

3. Drive output signals combinationally from state as before, minimizing output registers and glitches.

4. Use an explicit timer reload mechanism only at state transitions, reducing unnecessary timer reload toggling.

5. Reduce combinational logic complexity in next-state logic by separating timer=0 condition for state transitions from regular state maintenance.

Overall, these changes aim to reduce combinational logic depth and toggling by pushing timer decrement and pass_request logic into synchronous domain, which can reduce power and improve max frequency without area increase.

The finite state machine remains 2-bit encoded as before for minimal area.

The outputs and clock assignment are unchanged.

The design remains fully synchronous with asynchronous active-low reset.
