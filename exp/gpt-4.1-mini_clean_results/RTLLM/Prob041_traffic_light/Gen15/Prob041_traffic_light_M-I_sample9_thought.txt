To optimize the existing design for better PPA while preserving functionality:

1. **Reduce counter width to exactly 7 bits** (already done, no change needed).
2. **Use synchronous reset only** to avoid asynchronous reset complexities, which can sometimes improve timing and power in real silicon; since input rst_n is active low async, convert it into sync internally.
3. **Minimize flip-flops for output signals** by deriving them purely combinationally from state (already done).
4. **Remove unnecessary next_ped_shortened updates in every state; instead, only reset or set when needed.**
5. **Optimize counter decrement:** decrement only when cnt > 0 and state active, avoiding needless toggles.
6. **Merge the ped_shortened flag logic into a small state machine or simple latch with enable signals**, to reduce toggling.
7. **Use a parameter for counter width and state encoding**, improving maintainability.
8. **Drive output clock directly from counter register without a separate always block**, changing it to a continuous assignment.
9. **Simplify logic by combining some signals and removing redundant assignments.**

This should yield improved timing (due to synchronous reset and simplified logic), reduced power (less toggling), and similar or smaller area.

Note: Since the requirement states rst_n is async active low, we implement a synchronizer for rst_n internally to avoid async resets throughout.
