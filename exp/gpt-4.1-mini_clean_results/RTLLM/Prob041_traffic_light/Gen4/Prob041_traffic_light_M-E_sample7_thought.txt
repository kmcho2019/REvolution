Implement a Moore FSM with four states: idle, red, green, yellow. The idle state initializes the machine and immediately transitions to red. Use an 8-bit counter counting down the time in each state. The state durations are fixed except green, which can be shortened if a pedestrian request occurs. To handle pedestrian requests, monitor the green timer countdown and clamp it to 10 cycles if remaining green time exceeds 10 cycles when pass_request is asserted. Unlike the example, outputs are registered on every clock edge and kept in separate p_red, p_yellow, p_green registers before assigning to outputs. The counter updates and state transitions are handled in a single always block synchronous to clock and async reset. The design separates output logic from state and counter logic, emphasizing registered outputs and a direct state transition logic without extra flags.
