Implement a Moore FSM with four states: idle, red, green, and yellow, and a dedicated countdown counter per state duration. On reset, start from idle, quickly move to red. The counter counts down every clock cycle when in an active state. The state transitions when the counter reaches zero. The pedestrian button is monitored only in green state: if pressed and remaining green time is more than 10, clamp it to 10 cycles immediately. Use registered outputs updated synchronously with the clock. Store previous light states to detect state changes and reload counters accordingly. This approach cleanly separates state transitions and timing, and leverages explicit state encoding and output registers for clarity and stable output timing.
