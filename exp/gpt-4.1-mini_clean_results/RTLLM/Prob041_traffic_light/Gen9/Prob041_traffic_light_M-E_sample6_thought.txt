Implement the traffic light controller using a single always block with a combined state machine and timer counter. Instead of counting down every clock cycle, preload the timer on each state transition. Introduce a flag to indicate if the green time has been shortened due to a pedestrian request to prevent repeated shortening. On pass_request during green state, if remaining time > 10, reset timer to 10 and set the flag. When timer reaches zero, transition states accordingly. Outputs are directly decoded from the current state. This approach integrates timer and FSM tightly, simplifies control logic, and prevents multiple shortenings within the same green phase.
