Refactor the traffic light FSM using a synchronous state machine with explicit registered state and outputs. Use a combinational always block to compute the next state and next timer value, but move the output signals to registered outputs updated in the clocked process instead of combinational assignments. Implement the pedestrian shortening by clamping the timer register inside the clocked block when conditions apply, rather than in combinational logic. Use separate registers for the outputs, making the design more modular and suitable for synthesis tools that prefer registered outputs. This structure improves timing predictability by having registered outputs and state transitions while preserving the FSM logic and behavior.
