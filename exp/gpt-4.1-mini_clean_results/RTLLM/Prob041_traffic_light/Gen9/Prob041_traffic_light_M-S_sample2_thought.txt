Use a simple binary-encoded state machine with three states representing red, yellow, and green lights. Use a synchronous always block for state transitions and a separate synchronous block for the counter. The counter counts down and triggers state changes when it reaches zero. When in green state and pedestrian button is pressed, the counter is forced to max 10 if it was above 10, effectively shortening the green duration. Outputs are registered and updated synchronously with the state. This approach simplifies state handling by using binary encoding and clear, separate logic for counter and state transitions while preserving all functionality.
