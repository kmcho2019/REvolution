I will implement the traffic light controller as a Mealy state machine with explicit countdown timers per state stored in separate registers to clearly separate each phase duration, instead of sharing one timer register. The pedestrian button shortening logic is integrated into the green state timer by dynamically adjusting the green time countdown if pass_request occurs and remaining green time is greater than 10. This avoids permanently overriding the timer and simplifies timing. The states will cycle in order RED -> GREEN -> YELLOW -> RED. Outputs are registered and updated combinationally from the current state. The internal timers decrement each clock when active, and transition triggers are synchronous. This approach improves clarity by decoupling state and timing, makes pedestrian shortening straightforward by capping the remaining green timer, and maintains simple combinational output logic. The counter output reflects the active state's timer value, and reset initializes the state to RED and timers to their respective phase durations.
