Refactor the traffic light controller to use a Moore FSM implemented with a single always block for state transitions and output registers, and a separate always block for the timer countdown and reload logic. Use `assign` statements for outputs driven combinationally from the state. This approach avoids multiple combinational always blocks and consolidates sequential logic, improving code clarity and easing synthesis. The timer update logic will handle shortening green time upon pedestrian request by clamping the timer in the countdown block. This design uses synchronous reset and explicitly defines outputs combinationally from state, separating sequential and combinational logic more clearly.
