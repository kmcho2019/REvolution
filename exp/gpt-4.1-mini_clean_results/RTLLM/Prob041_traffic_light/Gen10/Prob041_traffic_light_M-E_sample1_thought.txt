Implement a classic Moore state machine with enumerated states using a binary-encoded 2-bit state register. Use a down counter that reloads with the appropriate duration at each state transition. The state machine cycles through GREEN -> YELLOW -> RED -> GREEN, with durations 60, 5, and 10 cycles respectively. The pedestrian button, when pressed during green state and the remaining green time is more than 10, causes the counter to be shortened to 10. State transitions occur when the counter expires. Outputs red, yellow, green are generated combinationally based on the current state. The counter and state registers update synchronously at each clock rising edge or reset asynchronously. This approach keeps the control logic clear, uses binary-encoded states to save area, and supports the pedestrian shortening logic efficiently without complicated one-hot logic.
