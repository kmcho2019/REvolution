Implement the traffic light controller as a Moore finite state machine where each state represents a traffic light color phase with a preset countdown value. The internal counter counts down synchronously. On each clock, if pass_request is asserted during the green state and the counter is above 10, force the counter to 10 to shorten green time. State transitions occur when the counter reaches zero, moving from green to yellow, yellow to red, and red back to green. To retain previous light states (p_red, p_yellow, p_green), use flip-flops that latch outputs at each clock, separate from combinational next-state logic. This architecture separates the state machine, counter, and output registers, improving modularity and ensuring outputs change only on clock edges, enhancing timing predictability and clarity. The outputs red, yellow, green are registered versions of p_red, p_yellow, and p_green respectively. The counter and state update occur synchronously, and the counter reloads with the appropriate time for each state. The pedestrian request logic modifies the counter in green state only, making it easy to track the timing. This approach uses explicit previous output registers as requested.
