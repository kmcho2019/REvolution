Refactor the traffic light controller to use a classic Moore finite state machine with a binary-encoded `state` register and a separate combinational block to determine `next_state`. The internal counter (`cnt`) counts down synchronously, but the load values depend on state transitions. The pedestrian request logic is handled by adjusting the counter load during green state to shorten green time if the request arrives and remaining time is greater than 10. Outputs `red`, `yellow`, and `green` are registered for glitch-free output. The state machine cycles through s1_red, s3_green, and s2_yellow states with corresponding timers. This structure separates state transition, counter update, and output logic, improving clarity and modularity while preserving functionality.
