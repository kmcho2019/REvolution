Implement the traffic light controller as a Moore state machine with four states: IDLE, RED, GREEN, and YELLOW. Use an 8-bit countdown timer (cnt) to time each state duration. On reset, move to RED state with 10 cycles. The GREEN state lasts 60 cycles by default but can be shortened to 10 cycles if a pedestrian button is pressed and remaining green time is more than 10. Transitions occur when cnt reaches zero. The outputs red, yellow, and green are directly driven by the current state (Moore outputs). This approach cleanly separates state encoding, output logic, and timing, simplifying control and making outputs glitch-free. The pedestrian request logic is handled by dynamically adjusting cnt in the GREEN state without extra flags, ensuring straightforward timing control.
