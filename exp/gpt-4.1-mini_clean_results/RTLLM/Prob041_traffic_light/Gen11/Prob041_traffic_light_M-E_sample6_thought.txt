Implement a Moore state machine with explicit states for each light color, using a counter that counts up to the state's duration instead of counting down. The state machine transitions occur when the counter reaches the predefined max count for that state. The pedestrian button logic is handled by dynamically adjusting the green state's max count (threshold), shortening it if the pass_request is asserted and the green time remaining exceeds 10 cycles. We keep previous light outputs in registers updated on clock edges to match the requirement for p_red, p_yellow, p_green. The internal counter counts up from zero to the duration per state, and resets on state transition. This approach improves readability by counting forward, uses simple state-transition logic, and cleanly integrates the shortening green time logic within the counting block. The outputs red, yellow, green reflect the previous p_red, p_yellow, p_green as per specification.
