Implement a Moore-type finite state machine with four states: IDLE, RED, GREEN, YELLOW, each associated with their fixed timing durations. Use a down-counter that reloads the state's duration at each transition and decrements every clock cycle. To handle the pedestrian button, add logic that monitors the green state timer and, upon a press, truncates the green timer to 10 if remaining time is greater than 10. Store the "pedestrian shorten" request in a flag that resets when leaving green. Output signals are generated directly from the current state, and the current counter value is exposed. This structure cleanly separates states and timer logic, is easy to extend, and maintains synchronization between state transitions and timer countdown. The IDLE state initializes the system and immediately transitions to RED.
