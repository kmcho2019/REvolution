Use a single synchronous always block with a state machine and a countdown timer. On reset, start with red state and set the timer. On each clock, decrement the timer. If a pedestrian request is detected during green and remaining green time is more than 10, shorten it to 10. When timer expires, switch to the next state and load its corresponding time. Derive the outputs directly from the current state and assign the timer value to the output clock. This reduces signal duplication and logic complexity.
