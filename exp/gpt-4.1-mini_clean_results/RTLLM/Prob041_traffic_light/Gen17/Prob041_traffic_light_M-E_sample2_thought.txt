Design a Mealy-type traffic light controller with explicit state encoding for red, yellow, and green phases using a 2-bit state register and an 8-bit counter for timing.  
On reset, initialize to red state with a counter of 10.  
The counter counts down every clock cycle when enabled. State transitions occur when the counter reaches zero.  
Pedestrian requests are handled by dynamically shortening the green phase timer if the remaining green time exceeds 10 cycles. This is checked combinationally; if the condition is met, the counter is immediately updated to 10, effectively shortening the green phase.  
The outputs (red, yellow, green) are registered synchronously from the state for stable outputs.  
This approach separates state transitions and timer control, incorporates pedestrian requests as a combinational check modifying the counter, and uses synchronous outputs for glitch-free signals.  
Using an 8-bit counter simplifies integration with the output and meets problem requirements.  
The code structure has:  
- One synchronous always block for state and output update.  
- One synchronous always block for counter update with pedestrian logic embedded.  
- Next-state logic combinational block determining transitions based on current state and counter.  
This architecture is simple, modular, easy to understand, and meets the timing and behavioral requirements.
