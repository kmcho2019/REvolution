Refactor the traffic light controller by splitting the state machine and counter logic more cleanly into separate always blocks: one synchronous block for state transitions and counter reloads, another synchronous block for counter decrement only when enabled, and combinational blocks for output assignments and next state decisions. Use explicit enable signals to gate counter decrement to reduce unnecessary toggling. Also, use a registered version of pass_request to synchronize it, and implement outputs directly from the state rather than through next-state signals, simplifying output logic. This approach improves clarity, reduces combinational path lengths, and can help performance and power.
