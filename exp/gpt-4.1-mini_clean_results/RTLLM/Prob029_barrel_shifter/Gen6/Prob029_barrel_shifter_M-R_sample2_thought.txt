Refactor the barrel shifter to use a single always_comb block that successively applies the shifts controlled by each bit of `ctrl`, instead of separate generate loops. This approach consolidates the combinational logic in one procedural block, improving readability and traceability of the shifting process. 

Within the always block:
1. Start with the input assigned to an intermediate register.
2. Conditionally apply the shift-by-4 rotation if `ctrl[2]` is high.
3. Then conditionally apply shift-by-2 rotation if `ctrl[1]` is high.
4. Lastly, conditionally apply shift-by-1 rotation if `ctrl[0]` is high.
5. Assign the final shifted value to the output.

This method avoids using generate loops and multiplexers explicitly, making the logic linear and straightforward. The output remains purely combinational with no registers or clock dependence.
