Implement the barrel shifter using explicit stages of 8 parallel 2-to-1 multiplexers, each stage conditionally rotates the input by 4, 2, or 1 bit according to the respective control bit. Start from the input and pass it through three stages sequentially:

- Stage 0: if ctrl[2] is set, rotate left by 4 bits.
- Stage 1: if ctrl[1] is set, rotate left by 2 bits on the result of Stage 0.
- Stage 2: if ctrl[0] is set, rotate left by 1 bit on the result of Stage 1.

Each stage uses an array of mux2X1 modules that select between the unshifted input and the shifted input at that stage, controlled by the appropriate bit of ctrl. This satisfies the requirement of using mux2X1 multiplexers and staged shifting and ensures synthesizable, modular, and clear design.
