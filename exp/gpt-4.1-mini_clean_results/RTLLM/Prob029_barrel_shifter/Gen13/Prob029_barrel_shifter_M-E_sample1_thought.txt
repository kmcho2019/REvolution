Implement the barrel shifter using a single combinational always block that applies conditional rotate-left shifts in sequence. Starting with the input, we conditionally rotate it by 4 bits if ctrl[2] is set, then rotate the intermediate result by 2 bits if ctrl[1] is set, and finally rotate by 1 bit if ctrl[0] is set. Each rotation stage is applied sequentially within the combinational block, and the resulting value is assigned to the output. This method avoids explicit mux arrays and uses simple bit manipulations and if conditions to achieve the shift controlled by each bit of `ctrl`. It is compact, easy to understand, and requires no extra modules.
