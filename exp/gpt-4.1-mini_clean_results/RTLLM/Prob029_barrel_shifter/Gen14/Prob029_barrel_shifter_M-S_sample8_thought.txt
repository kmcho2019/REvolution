Implement the barrel shifter using three stages of conditional shifts by 4, 2, and 1 bits respectively, applied sequentially. Each stage uses a simple 2-to-1 multiplexer logic implemented with the mux2X1 module for each bit to select between the shifted and unshifted input based on the corresponding control bit. This structural approach reflects the hardware design with clear stage separation while keeping the code concise and easy to understand.
