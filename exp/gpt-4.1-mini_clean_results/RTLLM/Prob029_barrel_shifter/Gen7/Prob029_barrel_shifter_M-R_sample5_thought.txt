Refactor the barrel shifter to implement each shift stage explicitly using 2-to-1 multiplexers. Define a `mux2X1` module and use it to select, bit by bit, between the unshifted input and the rotated input for each shift amount (4, 2, and 1 positions) based on the respective control bit. 

The design will be purely combinational with continuous assignments connecting each stage’s output to the next. This adheres closely to the original requirement of staged multiplexers controlling each shift and avoids the sequential rotate function approach.

Thus:
- Stage 1 shifts by 4 bits if ctrl[2] is high.
- Stage 2 shifts by 2 bits if ctrl[1] is high.
- Stage 3 shifts by 1 bit if ctrl[0] is high.

Each stage uses an array of 8 `mux2X1` instances, producing the next intermediate vector. The final stage output drives the module’s output port.

This makes the dataflow and mux-based shifting explicit and testbench friendly.
