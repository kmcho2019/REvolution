We can simplify the design by eliminating the explicit `mux2X1` submodule and instead using a conditional operator directly in the code for each bit shift stage. This keeps the logic clear and modular without needing separate mux instances. The left rotation logic remains the same: at each stage, if the corresponding control bit is high, we rotate by that stage's amount; otherwise, we keep the input unchanged. The three stages correspond to shifts by 4, 2, and 1 bits respectively, applied sequentially.
