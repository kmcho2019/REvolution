Implement an 8-bit barrel shifter that rotates the input bits based on a 3-bit control signal. The shifting is done in stages, each corresponding to a bit in `ctrl`. For each stage, a set of 8 2-to-1 multiplexers selects between the current intermediate value and the value rotated by the stage's shift amount (1, 2, or 4). The `mux2X1` module is used for the multiplexers. This approach allows efficient rotation by any amount from 0 to 7 bits.
