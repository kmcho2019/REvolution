Implement an 8-bit barrel shifter that rotates the input bits based on the 3-bit control signal `ctrl`. The shifting is done in three stages corresponding to shifting by 4, 2, and 1 positions respectively. Each stage uses an array of 8 mux2X1 multiplexers to select either the shifted bit or the original bit based on the control bit for that stage. The output from one stage feeds into the next. The mux2X1 module takes two 1-bit inputs and selects between them based on a single-bit select signal.
