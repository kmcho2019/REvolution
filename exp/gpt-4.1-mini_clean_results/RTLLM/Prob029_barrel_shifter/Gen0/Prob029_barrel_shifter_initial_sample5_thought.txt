Implement a barrel shifter that rotates an 8-bit input by an amount specified in the 3-bit ctrl signal. The shifting is done in 3 stages corresponding to shifts by 4, 2, and 1 bits. Each stage uses a set of 8 mux2X1 modules to select between the original bit and the bit shifted by that stage amount, based on the ctrl bit for that stage. The output from one stage feeds into the next stage. The mux2X1 module is a simple 2-to-1 multiplexer with a select signal.
