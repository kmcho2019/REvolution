Implement the 8-bit barrel shifter using a compact, generate-based structural approach. Define a single 2-to-1 multiplexer submodule (`mux2X1`) that selects between two bits based on a select signal. Then, for each stage controlled by bits of `ctrl` (4, 2, and 1-bit rotations), use the multiplexers to select either the original bit or the rotated bit from the previous stage. This cascaded mux structure efficiently realizes the barrel shifter function structurally while keeping the code simple and matching the problem's requirements.
