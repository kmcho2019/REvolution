Implement the 8-bit barrel shifter as a three-stage rotation by 4, 2, and 1 bit(s) using the `mux2X1` module. For each stage, create 8 multiplexers that select between the original bit and the bit shifted by the stage amount, controlled by the corresponding control bit. Chain the stages by connecting the output of one stage as input to the next, ensuring modularity and clarity. This keeps the design structured with explicit multiplexers while avoiding complexity by using generate loops.
