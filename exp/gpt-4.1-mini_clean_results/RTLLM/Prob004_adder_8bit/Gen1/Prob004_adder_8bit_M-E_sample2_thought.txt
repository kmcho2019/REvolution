Implement an 8-bit adder using a ripple-carry approach but express it using explicit combinational logic without instantiating a separate full adder module. For each bit, calculate sum as the XOR of the two inputs and the carry-in, and generate carry-out using the carry generate (G = A & B) and propagate (P = A ^ B) signals. Carry-out for bit i is G_i OR (P_i AND carry_in_i). This logic is implemented directly for each bit in a single always_comb block (or continuous assignment). This approach avoids module instantiation and demonstrates bit-level carry propagation via combinational logic equations.
