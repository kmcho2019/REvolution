Instead of explicitly computing the borrow chain from a subtraction, I will implement a hierarchical bit-level comparison using bitwise logic in a tree-like structure:

1. Per bit compare:
   - For each bit, determine if A[i] > B[i], A[i] == B[i], or A[i] < B[i] with simple combinational logic.
   
2. Hierarchical comparison:
   - Start from the MSB (bit 3) down to LSB (bit 0).
   - If A[3] > B[3], then A > B regardless of lower bits.
   - Else if A[3] == B[3], proceed to compare bit 2.
   - Continue this logic down to bit 0.
   
3. Outputs:
   - A_greater: output 1 if any MSB bit comparison finds A[i]>B[i] and all higher bits are equal.
   - A_less: output 1 if any MSB bit comparison finds A[i]<B[i] and all higher bits are equal.
   - A_equal: output 1 if all bits are equal.

This tree structure avoids subtraction and borrow logic entirely, using just bitwise comparisons cascaded with AND and OR gates. It creates a priority chain that naturally encodes the comparator outputs in combinational logic, inherently mutually exclusive.

This is a classic comparator approach using bitwise priority evaluation. It's clear, combinational, and synthesizes efficiently.

No sequential logic; purely combinational logic with hierarchical multiplexing of bit comparisons.
