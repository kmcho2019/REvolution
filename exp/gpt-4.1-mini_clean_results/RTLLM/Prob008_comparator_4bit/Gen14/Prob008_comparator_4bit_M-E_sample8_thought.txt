I will implement the 4-bit comparator by explicitly performing the subtraction A - B using full subtractors for each bit, generating borrow signals in a ripple fashion. This allows direct determination of the borrow out (final borrow), which indicates if A < B.

The subtraction difference bits will also be used to check if the result is zero (all difference bits are zero) to detect equality.

If borrow out = 1, then A < B.

If borrow out = 0 and difference is zero, then A = B.

If borrow out = 0 and difference is not zero, then A > B.

The outputs will be mutually exclusive by design.

This architecture is straightforward, structurally clear, and directly models subtraction, which helps in understanding and debugging. Although ripple borrow has a longer critical path than borrow lookahead, for 4 bits it is minimal and easy to synthesize.

I will define a parameterized full subtractor module internally and instantiate 4 of them in cascade. Then outputs are derived from the final borrow and the difference bits.
