Implement the 4-bit comparator using a ripple borrow subtractor architecture in pure combinational logic. Construct a 4-bit subtractor (A - B) bit by bit using full subtractor logic: each bit produces a difference and a borrow out based on A, B, and the borrow in. At the end, if the final borrow out is 1, it means A < B (borrow needed). If borrow out is 0 and the difference is zero, then A == B. If borrow out is 0 and difference is non-zero, then A > B. This directly implements the problem's subtraction and borrow-based comparison requirement without using arithmetic operators. The outputs are mutually exclusive by construction.
