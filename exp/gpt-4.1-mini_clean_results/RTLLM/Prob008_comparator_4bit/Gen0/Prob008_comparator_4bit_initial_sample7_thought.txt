Implement a 4-bit comparator by performing a combinational subtraction (A - B) using bit-level subtractors with borrow propagation. The subtraction result and borrow will determine the output signals. If borrow is 1, A < B. If borrow is 0 and result is zero, A = B. If borrow is 0 and result is nonzero, A > B. Outputs are mutually exclusive.
