Perform a 4-bit subtraction A - B using bit-level full subtractors to get the difference bits and borrow signals.
- Use combinational logic for each bit to generate difference and borrow_out.
- The final borrow_out indicates if A < B (borrow_out == 1).
- If no borrow and difference is zero, A == B.
- If no borrow and difference != 0, A > B.
Outputs A_greater, A_equal, and A_less are mutually exclusive.
