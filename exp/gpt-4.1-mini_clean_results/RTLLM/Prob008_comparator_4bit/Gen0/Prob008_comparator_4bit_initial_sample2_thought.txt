Implement a 4-bit comparator module using a combinational subtractor that calculates A - B with borrow generation. Each bit subtraction is done with full subtractor logic, cascading borrow from LSB to MSB. After computing the difference and final borrow out, set outputs:
- A_less = final borrow (borrow out = 1 means A < B)
- A_equal = all difference bits zero (difference == 0)
- A_greater = not borrow and difference != 0 (means A > B)
Ensure outputs are mutually exclusive.
