Implement a 4-bit comparator using a 4-bit subtraction (A - B) in combinational logic. We will instantiate four 1-bit subtractors that compute the difference bit-by-bit with borrow propagation. The borrow out of the last subtractor indicates if a borrow occurred (meaning A < B). If no borrow occurs and the subtraction result is non-zero, A > B. If the subtraction result is zero, A == B. Finally, output signals will be mutually exclusive.
