To optimize the 4-bit comparator for better performance and area, I will eliminate the borrow-lookahead chain and use direct bitwise comparison starting from the MSB to the LSB. This approach cascades comparison decisions per bit without explicit borrow signals, reducing logic depth and gate count, which can improve delay and area. Equality is computed as before using reduction XNOR.

The logic per bit:
- If A[i] > B[i], then A > B.
- Else if A[i] < B[i], then A < B.
- Else compare next bit down.

Outputs are mutually exclusive by construction.

This structure is common for small-bitwidth comparators and can synthesize to efficient comparator primitives in most tools.
