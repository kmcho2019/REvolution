Implement a 4-bit comparator by explicitly performing a 4-bit subtraction A - B using a combinational ripple borrow subtractor constructed from 1-bit subtractor blocks. Each 1-bit subtractor produces a difference bit and a borrow-out. The final borrow-out from the most significant bit indicates if A < B (borrow = 1) or A >= B (borrow = 0).

- If borrow_out = 1 → A_less = 1
- If borrow_out = 0 and difference != 0 → A_greater = 1
- If difference == 0 → A_equal = 1

This approach directly follows the problem description emphasizing subtraction and borrow generation, uses modular bit-level subtractors, and ensures outputs are mutually exclusive. It also makes the comparator structurally clear and easy to extend.
