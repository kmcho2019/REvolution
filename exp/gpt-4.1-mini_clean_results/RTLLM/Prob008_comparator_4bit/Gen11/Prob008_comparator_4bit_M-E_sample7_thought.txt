Implement the 4-bit comparator purely based on bitwise comparison results from MSB to LSB in combinational logic without performing subtraction or borrow calculations explicitly.

Idea:
- For each bit position from MSB to LSB, compare bits A[i] and B[i].
- Define three vectors indicating whether A[i] > B[i], A[i] == B[i], and A[i] < B[i].
- To determine the overall comparison, start from the MSB:
    * If A[3] > B[3], then A_greater=1.
    * Else if A[3] < B[3], then A_less=1.
    * Else (A[3] == B[3]), check the next bit.
- Repeat down to LSB.
- If all bits equal, A_equal=1.
- This logic can be implemented with combinational priority logic, using a chain of bit-level comparisons combined with mux-style conditional selections.
- Outputs A_greater, A_equal, and A_less are mutually exclusive by construction.
- This approach avoids subtractor and borrow logic, relying solely on hierarchical bitwise comparisons.
