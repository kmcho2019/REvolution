A novel architectural approach is to directly implement the 4-bit comparator by cascading bitwise comparisons from the most significant bit (MSB) to the least significant bit (LSB), using combinational logic that propagates decision signals (greater, less) down the bit positions without performing explicit subtraction or borrow calculations.

Key ideas:
- For each bit position i from 3 down to 0:
  - If A[i] > B[i], then A is greater regardless of lower bits.
  - If A[i] < B[i], then A is less regardless of lower bits.
  - If A[i] == B[i], then decision depends on lower bits.
- We encode this logic recursively in combinational logic using generate blocks or cascaded mux logic.
- At the end, if all bits equal, A_equal is asserted.
- Outputs A_greater, A_less, A_equal are mutually exclusive by construction.

This approach treats the comparator as a prioritized comparator starting from MSB, leading to minimal logic depth and straightforward output signals without borrow or subtraction logic. It also naturally aligns with typical comparator behavior in hardware.

The implementation uses generate blocks to build this priority chain, which is compact and clearly shows the cascading comparison logic.
