Refactor the comparator_4bit to use a priority-based per-bit comparison approach rather than explicitly modeling the borrow chain. 

Idea: The comparator can be implemented by checking each bit from MSB to LSB:
- If A[i] > B[i], then A is greater.
- Else if A[i] < B[i], then A is less.
- Else continue to next bit.

This naturally prioritizes the most significant differing bit, making the borrow logic implicit without ripple chains.

Advantages:
- Eliminates the borrow chain logic and borrow propagation signals.
- Simplifies the combinational logic using straightforward bitwise comparisons and priority encoding.
- Outputs remain mutually exclusive by construction.
- Easier for synthesis tools to optimize priority logic.
- Can be implemented cleanly using continuous assignments and conditional operators.

The equality output remains a simple equality check (A == B). 

This approach keeps the core behavior but restructures logic for clarity and potentially improved timing, since it avoids ripple borrow chain delay.
