We can simplify the 4-bit comparator by using reduction operators and direct bitwise comparisons without explicitly defining propagate and generate signals. 

Specifically:
- Use a simple subtraction result with full 4-bit subtraction to find if A < B via borrow out.
- Use bitwise equality check with reduction AND of (A ^ B) to determine equality.
- Define A_less if borrow out from (A - B) is set (meaning A < B).
- Define A_equal if all bits match.
- Otherwise, A_greater if not less and not equal.

This approach removes intermediate signals and borrow propagation logic, relying on subtraction borrow output and equality checks in a straightforward manner.

All outputs remain mutually exclusive and combinational.
