To simplify the 4-bit comparator design while preserving functionality, I will:

- Remove the explicit borrow chain signals and instead perform a direct subtraction of A - B to get a 5-bit result including borrow.
- Use the subtraction result directly to determine A_greater, A_equal, and A_less:
  - A_less is set if the subtraction result's MSB (borrow) is 1.
  - A_equal is set if the 4-bit difference is zero.
  - A_greater is set if neither borrow nor zero difference.
- Implement the equality check with a single vector comparison instead of per-bit XNOR and balanced AND tree.
- Avoid generate loops for simplicity.
- Use only combinational continuous assignments.

This reduces code and signal count while keeping mutually exclusive output encoding as required.
