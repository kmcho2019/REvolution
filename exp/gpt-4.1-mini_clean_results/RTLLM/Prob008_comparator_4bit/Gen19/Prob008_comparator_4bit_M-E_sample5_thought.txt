Implement the 4-bit comparator by explicitly constructing bit-level comparator units for each bit of A and B. Each bit-level comparator outputs signals indicating whether at that bit A is greater than, equal to, or less than B.

Then, cascade these bit-level comparators from the most significant bit (MSB) to the least significant bit (LSB). The higher bit's comparison result has priority: if higher bit comparator outputs decisive result (A_greater or A_less), lower bits are ignored.

This results in combinational logic that mimics how humans compare binary numbers bitwise: check MSB first, if equal check next bit, and so forth.

Finally, the outputs A_greater, A_equal, A_less are produced by combining the bit-level outputs accordingly:

- If any higher bit comparator says A_greater, output A_greater.
- Else if any higher bit comparator says A_less, output A_less.
- Else if all bits equal, output A_equal.

This approach demonstrates a multi-level bitwise comparator structure without subtractors or borrow logic, giving clear traceability and a different structural style from borrow lookahead.

Outputs are mutually exclusive by construction.
