I will implement the 4-bit comparator using a bitwise hierarchical comparison approach without explicitly performing subtraction or borrow chain calculation.

The idea is:

1. Compare bits from the most significant bit (MSB) down to the least significant bit (LSB).
2. For each bit position:
   - If A[i] > B[i], then A is greater regardless of lower bits.
   - If A[i] < B[i], then A is less regardless of lower bits.
   - If A[i] == B[i], proceed to check the next lower bit.
3. If all bits are equal, then A equals B.

This approach uses conditional logic and priority to determine comparison results in combinational logic, implemented via cascading multiplexers (or mux-style logic) starting from MSB.

Outputs are mutually exclusive by construction because as soon as a difference is found, the result is determined immediately without further comparison.

This method directly models the comparator behavior and avoids borrow chains or subtraction logic, which can be useful for certain synthesis tools and might reduce overall logic depth.

No sequential logic is used, purely combinational.

This architecture is easy to extend to wider bit-widths and has balanced logic per bit since decisions are made bit by bit from MSB down.

I will implement it by creating signals for each bit indicating if A is greater or less at that bit (comp_bit_gt, comp_bit_lt), then combine them hierarchically.

Finally, A_equal is high if all bits are equal.
