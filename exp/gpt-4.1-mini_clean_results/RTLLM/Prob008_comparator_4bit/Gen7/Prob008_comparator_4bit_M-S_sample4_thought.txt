Simplify the 4-bit comparator by directly performing the subtraction A - B in combinational logic using the '-' operator, then check the sign of the result and whether the result is zero.

- Use an intermediate 5-bit signed subtraction result = {1'b0, A} - {1'b0, B} to detect borrow via the sign bit.
- If result is zero, then A_equal = 1.
- If result is positive (no borrow and non-zero), then A_greater = 1.
- If result is negative (borrow), then A_less = 1.

This avoids explicit borrow propagate/generate logic, significantly reduces complexity and code size while keeping outputs mutually exclusive and correct for unsigned 4-bit inputs. It is fully combinational, synthesizable, and efficient for small bit-widths.
