I will implement the 4-bit comparator using a bitwise hierarchical comparison approach. Instead of performing subtraction or borrow lookahead logic, the comparator will use individual 1-bit comparators for each bit, starting from the most significant bit (bit 3) down to the least significant bit (bit 0). Each 1-bit comparator will produce signals indicating if A > B, A = B, or A < B for that bit alone. Then, a combinational priority logic will aggregate these bit-level results to form the overall comparator outputs.

The comparison logic works as follows:
- At the highest bit (bit 3), if A[3] > B[3], then A > B overall.
- Else if A[3] < B[3], then A < B overall.
- Else, look at bit 2 and so on down to bit 0.
- If all bits are equal, then A == B.

This method mirrors a cascade of conditional decisions from MSB to LSB, implemented as combinational logic with priority encoding. This approach avoids subtraction and borrow logic entirely, uses only simple bitwise comparison and priority muxing, and is naturally modular and scalable.

Outputs are mutually exclusive by construction. The hierarchy ensures only one of the outputs is asserted based on the first bit difference.

This is a classical comparator architecture, clear and efficient for small bitwidths, with straightforward combinational logic that synthesis tools can optimize effectively.
