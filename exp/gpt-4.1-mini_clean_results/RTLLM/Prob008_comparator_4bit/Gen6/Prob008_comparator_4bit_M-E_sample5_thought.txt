New architectural idea:

- Instead of generating a borrow chain, implement the comparison by directly comparing each bit pair starting from the MSB to the LSB.
- For each bit position i, determine if A[i] > B[i], A[i] < B[i], or equal. Use these bit-level comparisons to generate signals indicating whether A is greater or less at that bit.
- Use a priority encoder style logic to combine these bit-level comparisons: The highest bit that differs determines the comparison outcome.
- For example, if A[3] > B[3], then A > B regardless of lower bits; if A[3] == B[3], check bit 2, and so on.
- This approach avoids a borrow chain and subtraction logic, using simple bitwise comparisons and priority logic.
- Equality is true only if all bits are equal.
- The outputs are mutually exclusive since only one of greater, equal, or less can hold.
- This implementation is fully combinational, easily scalable, and conceptually intuitive.
