Refactor the 4-bit comparator by explicitly calculating the subtraction (A - B) at the bit level using a ripple borrow subtractor structure with combinational logic. This approach uses chained borrows (borrow_in, borrow_out) from least significant bit (LSB) to most significant bit (MSB), computing each difference bit and borrow bit explicitly.

- Generate borrow at each bit as: borrow_out = (~A_bit & B_bit) | ((~A_bit | B_bit) & borrow_in)
- The borrow chain propagates from LSB to MSB.
- The final borrow_out indicates if A < B.
- If borrow_out is 0 and result != 0, then A > B.
- If result == 0, then A == B.
- Use bitwise XOR for difference bits.
- Outputs A_less, A_equal, A_greater remain mutually exclusive.
- Use `assign` statements for pure combinational logic without intermediate signals for generate/propagate.
- This structure offers a clear, explicit bit-level subtraction view as an alternative to borrow-lookahead signals.
