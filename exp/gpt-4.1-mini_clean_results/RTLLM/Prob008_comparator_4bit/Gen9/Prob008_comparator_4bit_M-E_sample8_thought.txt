Implement a 4-bit comparator by creating individual 1-bit comparator cells for each bit, which produce signals indicating if A[i] > B[i], A[i] == B[i], or A[i] < B[i]. Use these bit-level outputs in a hierarchical priority logic: higher bits take precedence over lower bits. The final outputs (A_greater, A_equal, A_less) are derived by combining these bit-level indicators such that only the most significant differing bit determines the result. This approach relies purely on combinational logic, no subtraction or borrow chain, leading to clear, modular, and easy-to-follow logic.

Key points:
- Create a simple 1-bit comparator for each bit.
- For each bit from MSB to LSB, evaluate if A > B, A == B, or A < B.
- Overall comparison is decided by the highest bit where A != B.
- If all bits equal, then A_equal is high.
- Outputs are mutually exclusive.

This architecture models the comparator as a priority encoder over bitwise comparisons, differing from the borrow-lookahead subtraction method.
