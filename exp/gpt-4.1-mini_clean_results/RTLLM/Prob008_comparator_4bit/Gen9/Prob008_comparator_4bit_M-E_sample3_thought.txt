Implement the 4-bit comparator by explicitly computing the subtraction result (A - B) with borrow generation at each bit. The borrow signals propagate from LSB to MSB similar to a ripple borrow subtractor, but we will compute all borrows in parallel using combinational logic (no clocked logic).

- For each bit i:
  - Calculate borrow_out[i] based on A[i], B[i], and borrow_in[i].
  - borrow_in[0] = 0 (no initial borrow)
- After computing borrows for bits 0 to 3, borrow_out[4] is the final borrow indicating if A < B.
- The difference (diff) bits themselves can be used to detect if the result is zero to check equality.
- The outputs are mutually exclusive:
  - A_less = borrow_out[4]
  - A_equal = (diff == 0)
  - A_greater = (~A_less & ~A_equal)

This approach explicitly implements a ripple borrow subtractor at gate-level in combinational logic, giving clear insight into the borrow logic and difference bits without shortcut borrow lookahead. It also uses only bitwise operations and basic combinational logic, making it simple and educational while still synthesizable.

This solution contrasts with the previous borrow lookahead approach by using direct borrow chain equations and difference bits rather than balanced trees or carry-lookahead logic.
