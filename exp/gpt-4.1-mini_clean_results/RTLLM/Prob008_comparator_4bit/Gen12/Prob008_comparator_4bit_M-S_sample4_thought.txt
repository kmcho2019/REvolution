Implement the 4-bit comparator using a simple 4-bit subtractor without explicitly constructing the borrow chain. Use the subtraction result and the borrow output to determine the relationship between A and B. If borrow is 1, A < B; if borrow is 0 and result is non-zero, A > B; if result is zero, A = B. This approach directly follows the problem description and reduces complexity by leveraging Verilog's built-in subtraction and checking the borrow implicitly through the carry-out of the subtraction.
