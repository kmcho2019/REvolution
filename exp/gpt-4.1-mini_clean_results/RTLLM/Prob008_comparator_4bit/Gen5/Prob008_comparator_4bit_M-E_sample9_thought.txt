New Approach Using Parallel Bitwise Comparison with Priority Encoding:

- Instead of a borrow chain from a subtractor, perform direct bit-by-bit comparisons from the MSB to LSB.
- For each bit position, determine if A[i] > B[i], A[i] < B[i], or A[i] == B[i].
- Using a priority encoder style logic, the highest significant bit where A and B differ determines the result.
- If at the highest differing bit A[i] > B[i], then A > B; if A[i] < B[i], then A < B.
- If all bits are equal, then A == B.
- This avoids carry/borrow chains and subtraction logic entirely, reducing critical path and simplifying combinational logic.
- Outputs are mutually exclusive by construction.
