To optimize the original design, I will explicitly implement a 4-bit subtractor with borrow chains. This matches the problem description that compares A and B via subtraction and borrow detection.  
The subtractor uses full subtractors at each bit: diff = A - B - borrow_in, borrow_out generated accordingly.  
If the final borrow_out = 1, then A < B. If borrow_out = 0 and result ≠ 0, A > B. If result == 0, A == B.  
This approach consolidates the borrow generation and reduces redundant equality checks, resulting in potentially better area and power efficiency. The comparator outputs are mutually exclusive by construction.  
No registers are used, so the logic remains purely combinational.
