To simplify the 4-bit comparator while maintaining correct functionality:

- Use straightforward bitwise equality detection using XNOR operators.
- Perform a simple subtraction (A - B) using the minus operator in a combinational expression.
- Detect borrow by checking if A < B using a direct comparison, which is synthesizable.
- Assign outputs based on the comparison results:
  - A_less = (A < B)
  - A_equal = (A == B)
  - A_greater = (A > B)

This avoids manual borrow generate/propagate signals and balanced trees, reducing complexity and code size while relying on synthesis tools to optimize subtraction and comparison logic effectively.

Outputs remain mutually exclusive because only one of the three comparisons is true for any input pair.
