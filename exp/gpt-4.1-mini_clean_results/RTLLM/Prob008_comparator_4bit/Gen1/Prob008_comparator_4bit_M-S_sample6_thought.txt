Instead of performing full subtraction with borrow chain, compare bits directly from MSB to LSB.
- At each bit, if A[i] > B[i], then A > B.
- If A[i] < B[i], then A < B.
- If bits are equal, continue to next less significant bit.
- If all bits equal, then A == B.
This approach uses simple combinational logic with priority checking, resulting in simpler and faster comparator with mutually exclusive outputs.
