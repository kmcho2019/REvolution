The previous approach incorrectly handled the borrow propagation by concatenating borrow and A bits for subtraction, which is invalid. To fix this, implement a 4-bit subtractor using bit-level full subtractors that correctly propagate borrow signals.

Each 1-bit full subtractor computes difference and borrow out given inputs: A bit, B bit, and borrow in. This allows accurate borrow tracking across bits.

- For bit 0, borrow_in is 0.
- For bits 1 to 3, borrow_in is the borrow_out from the previous bit.

After the chain:

- If the final borrow_out is 1, A < B.
- If borrow_out is 0 and difference is zero, A = B.
- If borrow_out is 0 and difference is non-zero, A > B.

This way, we correctly implement subtraction at bit level with proper borrow propagation and derive the outputs accordingly.
