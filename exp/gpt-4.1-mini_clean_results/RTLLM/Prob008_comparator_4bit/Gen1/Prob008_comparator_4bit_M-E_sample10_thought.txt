Instead of performing subtraction with a ripple borrow chain, implement the 4-bit comparator using a bit-level priority encoding logic that directly compares each bit starting from the MSB down to the LSB:
- For each bit, check if A[i] > B[i], or A[i] < B[i].
- If at any bit A[i] > B[i], then A > B regardless of lower bits.
- If at any bit A[i] < B[i], then A < B regardless of lower bits.
- Only if all bits are equal, A == B.
This approach uses parallel combinational logic to evaluate the bits simultaneously and combine their comparisons using priority logic, avoiding subtraction and borrow propagation.
Outputs A_greater, A_equal, A_less remain mutually exclusive.
