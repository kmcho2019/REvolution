To simplify the comparator design while preserving correct functionality, I will directly compare bits from MSB to LSB to decide the relation without explicitly computing the borrow chain.

- For each bit from MSB to LSB, if A[i] > B[i], then A > B; if A[i] < B[i], then A < B.
- If all bits are equal, then A == B.
- This removes the need for borrow logic and separate equality signals.
- Outputs are mutually exclusive as exactly one condition is true.

This approach results in simpler combinational logic with fewer intermediate signals and no borrow chain, improving clarity and reducing gates.
