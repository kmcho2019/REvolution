I will implement the 4-bit comparator by performing a bit-by-bit subtraction using full subtractor logic (difference and borrow outputs) for each bit, chained from LSB to MSB. This will yield the borrow out from the MSB stage indicating whether A < B. The difference vector will help determine if A != B (i.e., difference is non-zero). If no borrow out and difference vector is non-zero, A > B. If difference is zero and no borrow out, then A == B.

This approach uses explicit bit-level subtractors rather than borrow-lookahead logic and directly leverages the subtraction concept as requested, making the logic fully combinational.

Outputs are assigned mutually exclusively:

- A_less = borrow_out (borrow out from MSB)
- A_equal = (difference == 0) and (borrow_out == 0)
- A_greater = not A_less and not A_equal

This design is intuitive, easy to verify, and synthesizes well using combinational subtractor primitives or gates.
