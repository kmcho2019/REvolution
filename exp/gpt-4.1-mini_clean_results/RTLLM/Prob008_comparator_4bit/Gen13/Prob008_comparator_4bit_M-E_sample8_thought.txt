Instead of explicitly performing subtraction or ripple borrow chains, this design compares each bit of A and B directly from the most significant bit (MSB) down to the least significant bit (LSB) using combinational logic.

- For each bit position i from 3 down to 0:
  - If A[i] > B[i], then A > B.
  - If A[i] < B[i], then A < B.
  - If A[i] == B[i], check the next lower bit.

- This cascading bitwise comparison can be implemented via a priority encoder style logic.

- Equality is simply the AND of all bits being equal (bitwise XNOR of all bits).

- The outputs are mutually exclusive: A_greater if first differing bit shows A > B, A_less if first differing bit shows A < B, else A_equal.

This direct bitwise comparison eliminates the need for subtraction or borrow chains, providing a potentially faster comparator with a short and simple critical path for 4 bits.
