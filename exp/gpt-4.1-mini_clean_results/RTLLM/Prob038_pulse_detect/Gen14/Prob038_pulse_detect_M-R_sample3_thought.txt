Refactor the pulse detection to use a simple finite state machine (FSM) with explicit states representing the sequence of the pulse pattern (0->1->0). This FSM moves through states on each clock cycle checking the input signal and asserting data_out only when the pulse completes (return to 0 after a 1 following an initial 0). 

Using a state machine separates the control logic from data storage, making the pulse definition clearer and easier to extend or debug. data_out is combinationally assigned based on the state, while state updates are synchronous with the clock and reset.

This approach is functionally equivalent to the shift-register method but uses a sequential logic structure for clarity and modularity.
