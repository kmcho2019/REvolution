Implement pulse detection using a simple 3-state Moore FSM where the output data_out is asserted only in the final "pulse detected" state for one clock cycle. The FSM tracks transitions: IDLE (data_in=0) → HIGH (data_in=1) → PULSE_END (data_in=0 after HIGH). When reaching PULSE_END, data_out is set high for one clock cycle, then FSM returns to IDLE. This ensures output is synchronous to the clock and registered, reducing glitches and improving timing closure. The output data_out is registered and only asserted at the PULSE_END state, which corresponds exactly to the 0→1→0 pulse pattern ending. The module includes asynchronous reset and clean state transitions with a simple 2-bit state register.
