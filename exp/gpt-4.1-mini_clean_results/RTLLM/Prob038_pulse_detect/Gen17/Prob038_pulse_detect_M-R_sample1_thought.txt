Refactor the pulse detection by implementing a simple 3-state finite state machine (FSM) to track the pulse pattern: waiting for rising edge (0 to 1), then waiting for falling edge (1 to 0), and output data_out when the falling edge is detected. This approach replaces direct delay registers with explicit states, making the detection logic more modular and easier to extend. The output data_out is generated as a registered signal synchronized with the clock, and the current and previous data_in values are stored in a dedicated register. This structured FSM approach improves code readability and testability while preserving the original functionality.
