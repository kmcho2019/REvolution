Refactor the pulse detection FSM to use one-hot style states with an explicit pulse output register updated synchronously. The state register updates on clock edges, and data_out is assigned from a pulse_detected register that is set only when the exact pattern 0->1->0 is completed. Separate the state transition logic in a synchronous always block and generate data_out from a pulse_detected register cleared at each cycle except when the pulse is detected. This avoids combining next state and output logic in a single combinational block and clarifies the pulse detection timing.
