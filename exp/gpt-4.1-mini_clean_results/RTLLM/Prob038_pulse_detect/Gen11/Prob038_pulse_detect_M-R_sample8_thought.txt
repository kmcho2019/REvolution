Refactor the pulse detector FSM to use an explicit Moore state machine with synchronous state transitions and outputs, moving the pulse detection output signal to be a registered Moore output that depends solely on the current state. This simplifies the combinational logic since output depends only on the state, improving clarity and potentially synthesis results. The output data_out will be asserted for one cycle when the FSM enters the LOW state, corresponding to the end of the pulse pattern "0->1->0". The next state logic is implemented in a combinational always block, and the output logic uses a synchronous always block. This structure improves readability and separates state transition and output logic clearly.
