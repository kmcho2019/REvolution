Implement the pulse detection using a simple two-bit state register without typedef enum to reduce complexity. Use three states encoded as 2'b00 (waiting for 0), 2'b01 (waiting for 1), and 2'b10 (waiting for 0 to complete the pulse). When the pulse pattern 0->1->0 is detected, assert data_out for one cycle, then return to the initial state. The combinational next-state logic and output signal are implemented directly in the sequential always block to simplify the design.
