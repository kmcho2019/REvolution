Simplify the pulse detection FSM by using a 2-bit state register that directly encodes whether we are waiting for a rising edge, a falling edge (end of pulse), or idle. Use a synchronous process with nonblocking assignments to update state and output together, avoiding a separate next_state logic block. Output data_out is set to 1 only in the clock cycle when a 1->0 transition is detected, otherwise 0. This reduces code lines and complexity while maintaining the correct pulse detection.
