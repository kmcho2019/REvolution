I will implement a three-state finite state machine (FSM) to detect the pulse pattern 0→1→0. The FSM states will be IDLE (waiting for 0), HIGH_DETECTED (when a rising edge 0→1 is detected), and LOW_DETECTED (when the following falling edge 1→0 is detected).

- Initially, the FSM is in IDLE, expecting data_in = 0.
- When data_in changes from 0 to 1, FSM transitions to HIGH_DETECTED.
- When data_in returns to 0, FSM transitions to LOW_DETECTED, this completes the pulse detection, so data_out is asserted high for one clock cycle.
- After that, FSM returns to IDLE to wait for the next pulse.

Using this explicit FSM clarifies pulse detection logic, is easy to verify, and data_out is a one-cycle pulse synchronized with clk at pulse completion. The FSM state and data_out will be synchronous to clk with synchronous reset. This structured FSM approach is easy to extend or modify if pulse detection criteria change.
