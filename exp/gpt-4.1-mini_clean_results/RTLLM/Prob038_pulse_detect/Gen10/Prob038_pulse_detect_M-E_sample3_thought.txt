This design uses a simple finite state machine (FSM) to explicitly track the pulse detection process. The FSM has four states: IDLE (waiting for data_in to go high), HIGH (detected data_in=1), LOW_END (detected the falling edge completing the 0-1-0 pattern), and DONE (output asserted).

On each clock cycle, the FSM transitions based on the current input data_in:
- From IDLE, if data_in=1, go to HIGH.
- From HIGH, if data_in=0, go to LOW_END (completing the pulse pattern).
- LOW_END asserts data_out=1 for one clock cycle, then transitions back to IDLE.
- If at any point the input deviates from the expected pattern, the FSM returns to IDLE.

This FSM approach explicitly models the detection of the pulse edge sequence "0->1->0" over consecutive cycles, matching the problem's requirement. The data_out signal is asserted for exactly one cycle at the end of the pulse (when the last 0 is detected).

The reset initializes the FSM to the IDLE state and clears the output.

This method is stateful, easy to understand, and robust to any signal glitches or longer low periods, because it only asserts data_out at the exact pulse end cycle.
