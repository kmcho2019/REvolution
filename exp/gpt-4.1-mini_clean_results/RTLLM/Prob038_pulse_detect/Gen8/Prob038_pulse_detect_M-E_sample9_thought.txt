Instead of using a shift register to track the last three values of data_in, we implement a simple finite state machine (FSM) with four states representing the progression through the pulse pattern "0 -> 1 -> 0". The states are:

- IDLE: Waiting for data_in to be 0 (initial condition).
- WAIT_FOR_HIGH: data_in was 0, now waiting for a '1'.
- WAIT_FOR_LOW: data_in was 1, now waiting for a '0' to complete the pulse.
- PULSE_DETECTED: Pulse "010" detected; output data_out=1 for one cycle.

At every clock, the FSM transitions based on data_in. When the pulse completes, data_out is asserted high for one cycle and then returns to 0. This method explicitly models the detection sequence, making it easier to extend for more complex patterns if needed.

This FSM approach is elegant, synthesizable, and separates state management from output logic, leading to clear and maintainable code.
