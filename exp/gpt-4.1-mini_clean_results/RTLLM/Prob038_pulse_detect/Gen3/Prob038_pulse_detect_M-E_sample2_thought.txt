Implement the pulse detection using a finite state machine (FSM) that explicitly tracks the pulse pattern states: IDLE (waiting for 0), WAIT_FOR_HIGH (after 0, waiting for 1), and WAIT_FOR_LOW (after 1, waiting for 0). When the FSM observes the sequence 0 -> 1 -> 0 on consecutive clock cycles, it asserts data_out = 1 for exactly one clock cycle at the end of the pulse, then returns to IDLE to detect subsequent pulses. This explicit FSM approach provides clear state progression and easy extensibility.
