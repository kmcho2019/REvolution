Use a simple finite state machine (FSM) with states representing the progress of detecting the pulse pattern 0->1->0.
- State 0: waiting for data_in to be 0 (start or reset state)
- State 1: detected first 0, waiting for data_in = 1 (rising edge)
- State 2: detected 0->1, waiting for data_in = 0 (falling edge) to complete pulse
At the transition from State 2 to State 0 (when data_in goes back to 0), output data_out=1 for one cycle to indicate pulse detected.
data_out is otherwise 0.
Reset initializes state to 0 and data_out to 0.
