Implement a 3-state FSM to detect the exact 3-cycle pulse pattern 0→1→0:
- State IDLE: waiting for data_in=1 (rising edge start).
- State HIGH: data_in=1 last cycle, now expecting data_in=0 in next cycle.
- State PULSE_END: data_in=0 at the 3rd cycle, pulse detected, output data_out=1 for one cycle, then return to IDLE.

This FSM ensures data_out pulses high exactly at the end of the full 3-cycle pattern. The FSM transitions only if the input sequence matches exactly; any deviation resets the FSM. This guarantees correct detection for patterns like 01010 and output like 00101.
