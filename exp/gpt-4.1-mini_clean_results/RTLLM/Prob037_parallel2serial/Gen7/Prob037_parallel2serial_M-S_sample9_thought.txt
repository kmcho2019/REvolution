Use a 2-bit counter to track which bit of the input to output, without shifting the data register. On each clock cycle, output the bit at position (3 - cnt) of the input data 'd', starting from MSB to LSB. Assert valid_out = 1 only when outputting the MSB (cnt == 0), indicating the start of a new 4-bit transmission. Increment cnt each cycle, wrapping back to 0 after 3. On reset, clear the counter and valid_out. This approach eliminates the shift register and reduces switching activity by directly indexing the input bits for serialization.
