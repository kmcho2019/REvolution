Implement the parallel-to-serial converter using a 2-bit index counter to select bits directly from the input data register instead of rotating or shifting the data. On reset, the counter and valid_out are cleared. On each clock cycle, if the counter reaches 3, new data is loaded into an internal register, the counter resets to 0, and valid_out is set high to indicate the first MSB bit output. Otherwise, the counter increments, valid_out is deasserted, and the output bit is taken from the internal register indexed by (3 - counter), ensuring MSB to LSB serialization without shifting or rotating data. This approach reduces switching activity since data does not change between cycles, only the selection index changes. It also simplifies data path logic and keeps timing clean.
