Implement a shift-register based parallel-to-serial converter that captures the 4-bit input data into an internal register at the start of each 4-cycle serialization period. Use a 2-bit counter to keep track of the bit being output. On reset, clear the counter and data register. When the counter reaches 3 (last bit), load the new parallel data into the shift register and reset the counter to zero; otherwise, shift the data register left by one bit each clock cycle. The serial output `dout` is always the MSB of the shift register. `valid_out` is asserted only for the cycle when the MSB bit is output (i.e., when counter is zero). This approach reduces glitches by stabilizing the data within a register and serializing via shifting, while valid_out clearly signals when the new serial sequence starts.
