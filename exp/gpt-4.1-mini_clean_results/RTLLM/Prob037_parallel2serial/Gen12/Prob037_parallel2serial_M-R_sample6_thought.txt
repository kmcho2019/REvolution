Refactor the design by implementing a simple FSM with two states: IDLE and SHIFT. When in IDLE, the module loads the input parallel data into a register and sets the valid_out signal high, outputting the MSB. Then, it transitions to SHIFT state and outputs the next 3 bits one per cycle while shifting the data register left by one bit on each clock. The counter tracks the bit position from 0 to 3. This approach uses an internal data register instead of direct input indexing, separating the data loading phase and shifting phase, enhancing clarity and extensibility. The valid_out signal is asserted only when a new 4-bit parallel data is loaded and the first MSB bit is output.
