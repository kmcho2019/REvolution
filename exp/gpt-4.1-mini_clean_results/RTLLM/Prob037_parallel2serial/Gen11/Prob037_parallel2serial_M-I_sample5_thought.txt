To optimize for power and timing, avoid rotating the entire 4-bit register every cycle, which causes switching on all bits. Instead, load the parallel data into a register once, then use a 2-bit counter as a pointer to output the bits serially from MSB to LSB without shifting the data register. This reduces toggling on data bits significantly and simplifies the data path. valid_out is set high only when the first bit (MSB) of a new data word is output (cnt == 0). On reset, initialize registers properly.
