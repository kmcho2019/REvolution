Implement the design using a shift register that loads the 4-bit parallel input at once when the counter reaches 3, and then shifts out the MSB to LSB serially on each clock cycle. The counter counts from 0 to 3, and the valid_out signal is asserted only during the cycle when new data is loaded (cnt == 3). This indicates that dout holds the most significant bit of the freshly loaded data. Between loads, the shift register shifts left by one bit, moving the next bit into MSB position for output. This approach uses an explicit data register to hold the data being serialized and aligns the valid signal exactly with output of the MSB of each parallel word.
