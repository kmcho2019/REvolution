Implement a shift-register-based parallel-to-serial converter with a 4-bit register `data` that loads new input `d` only at the end of the 4-bit transmission (when counter = 3). The counter counts from 0 to 3, tracking which bit to output. At each clock, `dout` outputs the MSB of `data`, then the register shifts left by one, moving the next bit into MSB position. `valid_out` is set high for 4 consecutive cycles to indicate serial data output availability, beginning immediately after loading new data. On reset, counter and data clear. This approach isolates input sampling from output timing, avoids glitches from input changes mid-stream, and provides a valid signal covering all serialized bits.
