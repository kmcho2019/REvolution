Implement a simple shift register for the 4-bit data that loads the new parallel input at cnt == 3 (end of previous transmission). The output bit dout is always the MSB of this shift register. On each clock cycle, if cnt == 3, load the new data and reset cnt to 0, setting valid_out=1 to indicate the first valid bit. Otherwise, shift the data left by one bit (MSB to LSB) and increment cnt, setting valid_out=0 because only the first bit output in the cycle of 4 bits is marked valid_out=1 per the problem statement. Reset asynchronously clears registers. This maintains the specified behavior with minimal complexity.
