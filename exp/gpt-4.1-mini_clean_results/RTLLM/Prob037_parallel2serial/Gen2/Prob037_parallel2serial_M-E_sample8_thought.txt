Implement the parallel-to-serial converter using a shift register that loads new parallel data only when the previous 4-bit sequence has been fully serialized. Use a 2-bit counter (cnt) to track the bit position being output (0 to 3). On reset, initialize counter and shift register to zero. When cnt reaches 3, load new parallel input into the shift register, set valid_out=1 to indicate the start of serialization, and output the MSB of the loaded data (bit 3). For subsequent cycles (cnt=1 to 3), shift left the register by 1 bit (dropping the MSB) and output the new MSB each cycle, with valid_out=0. This design guarantees that the output is held stable for a whole serialization period before loading new data, prevents data sampling glitches, and asserts valid_out only on the first output bit of each 4-bit word.
