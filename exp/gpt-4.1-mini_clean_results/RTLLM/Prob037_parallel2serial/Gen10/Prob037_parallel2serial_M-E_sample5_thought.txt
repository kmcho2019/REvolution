Instead of shifting the entire data register, store the 4-bit input data into a register and use a 2-bit counter as an index to select which bit to output serially. The counter counts from 0 to 3, and at count 0, load new parallel data and assert valid_out for a single cycle to signal new valid serial output starting with MSB (bit 3). On subsequent cycles, valid_out is deasserted, and the output bit is selected by indexing the data register with (3 - cnt), preserving MSB-first output order. This approach reduces switching activity by avoiding shifting operations, minimizes power consumption, and simplifies timing paths since no shifting logic is required—only a multiplexer implemented by bit indexing.
