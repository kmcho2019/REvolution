Replace the shift register with a simple data register holding the input data and a 2-bit counter that indexes which bit to output. On reset, clear registers. When the counter reaches 3 (last bit), load new input data and set valid_out high indicating the MSB is available. For other cycles, increment the counter, output the bit indexed by (3 - cnt) to maintain MSB to LSB order, and set valid_out low. This removes the need for shifting logic and reduces switching, resulting in a simpler, area-efficient design that retains the original functionality.
