Use a 2-bit counter to track which bit of the 4-bit parallel input to output serially from MSB to LSB. On reset or after outputting all 4 bits, load the input data into a register and start from the MSB (bit 3). On each clock cycle, output the bit indexed by the counter, assert valid_out only on the first bit (MSB), then increment the counter. When counter reaches 3 (last bit), reload input on next cycle. This approach avoids shift registers and state machines, simplifying logic while meeting the requirement.
