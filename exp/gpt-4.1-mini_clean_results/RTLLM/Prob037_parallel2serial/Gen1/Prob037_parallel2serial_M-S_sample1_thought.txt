Use a 2-bit counter to track which bit of the 4-bit input to output serially, starting from MSB (bit 3) down to LSB (bit 0). On reset, clear the counter and outputs. When the counter is 0, load the input data into a register and set valid_out = 1, outputting the MSB. On subsequent cycles (counter 1 to 3), shift the output bit index down by one and set valid_out = 0. Increment the counter each clock cycle modulo 4. This approach directly indexes bits from the stored data without complex shifting or rotation.
