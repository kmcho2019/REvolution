Fuse the best features of both designs by using a 4-bit shift register to hold the parallel data and a 2-bit counter to track the serialized bits output. On reset, clear registers and outputs. When the counter reaches 3 (the last bit output), load new parallel input into the shift register, set valid_out high to indicate the first valid bit, and output the MSB. For subsequent cycles, shift the register left (dropping the MSB), increment the counter, output the current MSB, and clear valid_out.

This approach cleanly separates load and shift phases, outputs MSB-first, and asserts valid_out only once per 4-bit serialization cycle. Using a shift register and counter instead of multiplexers simplifies timing and reduces power by limiting toggling to meaningful shifts and load events. Output dout is directly assigned from the MSB of the shift register for minimal combinational delay. This design balances clean logic, minimal switching, and clear timing paths for improved PPA.
