Simplify the design by eliminating the shifting operation. Store the parallel input in a register only when starting a new 4-bit output sequence. Use a 2-bit counter as an index to select the bit from the stored register, outputting bits from MSB to LSB. Set valid_out high only for the cycle when new data is loaded, otherwise low.
