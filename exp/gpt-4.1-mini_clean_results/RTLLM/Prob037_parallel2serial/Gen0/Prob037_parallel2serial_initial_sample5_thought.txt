Implement a synchronous module with a 4-bit data register and a 2-bit counter. On reset, initialize data to 0 and counter to 3 so that new input data can be loaded immediately. On each clock cycle, if the counter is 3, load the input data into the register, output the MSB on dout, set valid_out to 1, and reset counter to 0. For other counts, shift the data register left by one bit with MSB wrapping to LSB, output the MSB as dout, increment counter, and set valid_out to 0. This sequence outputs the 4 bits from MSB to LSB serially with valid_out high only for the first bit.
