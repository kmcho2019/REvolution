Implement a parallel to serial converter with a 4-bit shift register and a 2-bit counter to track the current bit output. On reset (rst_n=0), clear the counter and data register. When the counter reaches 3, load the input parallel data into the data register, reset the counter to 0, and set valid_out to 1 to indicate the MSB is on dout. Otherwise, shift the data register left (MSB shifted out to LSB), increment the counter, output the MSB on dout, and set valid_out to 0.
