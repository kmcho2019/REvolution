Use a 4-bit register 'data' to hold the parallel input bits and a 2-bit counter 'cnt' to track the current bit being output. On reset (active low), initialize counter and data to zero. On each clock cycle, if cnt == 3, load 'data' with input 'd', reset cnt to 0, and set valid_out to 1. Otherwise, increment cnt, shift 'data' left circularly by 1 bit (MSB rotated to LSB), and set valid_out to 0. The serial output dout is always the MSB of 'data'.
