Implement a stateful module with a 4-bit register to hold the data and a 2-bit counter to track the current bit output. On reset, initialize the counter and data register. On each clock cycle, output the MSB of the data register as dout. When the counter reaches 3, load new parallel data into the data register, reset the counter to 0, and set valid_out to 1. For other counts, shift the data register left by one (rotating the MSB to LSB as described), increment the counter, and set valid_out to 0.
