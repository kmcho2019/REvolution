Implement a synchronous parallel-to-serial converter with a 2-bit counter (cnt) to track the current output bit position. On every clock cycle, if reset is active, reset cnt and load the 4-bit input d into a shift register. Set valid_out to 1 only when cnt is 0, indicating the first MSB is output. On subsequent cycles (cnt=1 to 3), shift data left to bring the next bit to the MSB position and increment cnt. When cnt reaches 3 (last bit), reload data with input d and reset cnt to 0 for the next parallel input.
