Implement a simple shift-register approach without bit rotation: 

- Use a 4-bit shift register `data_reg` to hold input data.
- Use a 2-bit counter `cnt` to track how many bits have been shifted out (from 0 to 3).
- On reset, initialize `cnt` and `data_reg` to zero.
- When `cnt` is 0, load `data_reg` with the new 4-bit input `d`.
- Each clock cycle, output the MSB (bit 3) of `data_reg` as `dout`.
- Then shift `data_reg` left by 1 bit, filling LSB with zero.
- Set `valid_out` = 1 whenever `cnt` is in [0..3] (since serial bits valid during these 4 cycles).
- Increment `cnt` modulo 4 each clock cycle.
- This ensures for every 4 cycles, 4 bits from input `d` are shifted out MSB to LSB, valid_out signals the serial output validity.
- The loading at cnt=0 guarantees parallel input is loaded fresh every 4 cycles and output bits start from MSB.

This approach is straightforward, uses no bit rotation, and matches the timing and valid_out requirements precisely.
