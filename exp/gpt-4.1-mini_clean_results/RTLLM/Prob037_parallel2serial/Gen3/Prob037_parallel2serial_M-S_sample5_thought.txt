Use a 2-bit counter that counts from 0 to 3 to index which bit of the input parallel data to output serially. On each clock cycle, output the bit at position (3 - cnt) of input d, from MSB to LSB. Set valid_out high during all 4 output cycles to indicate valid serial data. When the counter reaches 3, reset it to 0 on next clock to start a new 4-bit output sequence. On reset, clear counter and outputs. This avoids internal data shifting and stores no internal register, simplifying the design.
