Refactor the parallel-to-serial converter to use a simple finite state machine (FSM) with two states: IDLE (waiting to load new data) and SHIFT (serializing bits). On reset, start in IDLE with all registers cleared. When in IDLE, load the parallel input into a shift register, output the MSB, assert valid_out=1, and move to SHIFT state. In SHIFT state, shift the register left by one bit on every clock, output the next MSB, keep valid_out=0, and increment a 2-bit counter. When the counter reaches 3 (all 4 bits serialized), return to IDLE to load new data again. Use registers for state, counter, and shift register, and use combinational logic for outputs (dout, valid_out). This separates control flow and output logic cleanly and uses explicit states rather than encoding logic solely by the counter value.
