Instead of rotating the data register, store the parallel input into a shift register that shifts out bits from MSB to LSB. Use a 2-bit counter to track the bit index being output, starting from 0 to 3. On reset, initialize counter and shift register to zero. When the counter reaches zero, load the shift register with the new parallel input data 'd' and set valid_out to 1 indicating the first valid serial bit output (MSB). On each subsequent clock cycle, shift the shift register left by one bit, increment the counter, set valid_out to 0, and output the MSB as dout. Once the counter reaches 3 (LSB output), on the next cycle the process repeats with new data loaded. This avoids circular rotation and reduces switching activity by shifting only the valid bits.
