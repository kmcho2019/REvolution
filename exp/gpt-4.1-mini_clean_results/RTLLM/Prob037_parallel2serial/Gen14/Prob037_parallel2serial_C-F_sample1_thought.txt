Fuse the strengths of both examples by using a data register to latch the input parallel data only once every 4 cycles, minimizing reliance on stable input d during serialization, while using a 2-bit counter to index bits from MSB to LSB. This ensures stable output data and reduces toggling compared to rotating the data every cycle. The valid_out signal is asserted only on the cycle when new parallel data is loaded (cnt==3). The output dout is selected directly by indexing the registered data with the counter, providing clean MSB-to-LSB serialization without shift or rotate operations. This balances data stability, low switching activity, small area, and simple control logic for good PPA.
