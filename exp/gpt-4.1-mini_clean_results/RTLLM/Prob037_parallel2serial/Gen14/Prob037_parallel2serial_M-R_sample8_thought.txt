Refactor the design to use a 4-bit shift register internally to hold the parallel data, which is loaded on every fourth clock cycle. A 2-bit counter tracks the bit position from 0 to 3. On reset or when the counter reaches 3 (indicating the last serial bit), the parallel input 'd' is loaded into the shift register, valid_out is asserted, and the MSB of the shift register is output as dout. On subsequent cycles, the shift register is shifted left by one bit (MSB discarded), counter incremented, valid_out deasserted, and the MSB of the shifted register output serially. This matches the original approach described in the problem statement using a register and shift operation, but structured with an internal data register and using synchronous logic for both data and control signals.
