Implement the parallel-to-serial converter using a shift register approach. On reset, load the 4-bit parallel input into an internal register. At each clock cycle, output the MSB of this register and then shift it left by one bit (MSB shifted out, LSB filled with 0). A 2-bit counter tracks the number of bits output (0 to 3). The valid_out signal is asserted high only at the first cycle after loading new data (when counter is 0), indicating that the MSB of the newly loaded parallel data is being output. When the counter reaches 3 (last bit output), on the next clock cycle the data register is reloaded with the input parallel data, and the process repeats. This design serializes the input bits MSB first using a simple shift register, and valid_out indicates valid data at the beginning of each 4-bit serial sequence.
