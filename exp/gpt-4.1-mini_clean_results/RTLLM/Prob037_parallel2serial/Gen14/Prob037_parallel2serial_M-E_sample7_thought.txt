Implement a parallel-to-serial converter using a data register that loads the 4-bit input 'd' only when the entire 4 bits have been serialized (i.e., after outputting the last bit). Use a 2-bit counter to track which bit to output next, counting from 0 to 3. On reset, clear counter and data register. On each clock cycle, output the MSB of the data register as dout, then shift the data register left by one bit with zero padding (or simply shift out the MSB). When the counter reaches 3 (last bit), load new parallel data 'd' into the data register and reset the counter. Set valid_out high exactly when new data is loaded and the MSB is output, indicating valid serial data output on that cycle. This method avoids direct indexing and relies on a shift register holding the current data bits for serialization.
