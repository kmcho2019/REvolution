Use a parallel load register to store the input data and a counter to index which bit to output, without shifting the data register. On reset, clear the registers. On each clock cycle, output the bit from the loaded data at the position indexed by the counter, starting from MSB (bit 3) down to LSB (bit 0). When the counter reaches 3 (outputting LSB), load the new parallel input into the register and reset the counter to 0. The valid_out signal is asserted high only for the cycle when new data is loaded and the MSB bit is output, indicating the availability of valid serial output. This approach avoids shifting, reduces switching activity, improves power efficiency, and simplifies timing by using a multiplexer to select bits directly by index.
