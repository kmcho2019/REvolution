Simplify by removing the shifting operation and instead use a 2-bit counter as a bit selector. Load the 4-bit parallel data into a register only when all bits have been serialized (counter = 3), then output bits in order from MSB to LSB by indexing using the counter. valid_out is asserted only when new parallel data is loaded (once every 4 cycles), indicating the serial output bit is the MSB of the new data. This approach avoids shifting the data register every cycle, reduces toggling, and keeps logic minimal.
