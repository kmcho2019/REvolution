Refactor the design by separating the loading and shifting logic into a two-state finite state machine (FSM). The FSM alternates between LOAD and SHIFT states: in LOAD state, parallel data is loaded into a register and valid_out is asserted; in SHIFT state, the register shifts left, outputting bits serially and deasserting valid_out. The counter increments in the SHIFT state to track output bits, and when it reaches 3, the FSM returns to LOAD state. The serial output is assigned combinationally from the MSB of the shift register. This structure clarifies the control flow and avoids mixing counter and load logic, making the code more modular and readable.
