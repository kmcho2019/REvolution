Use a parallel data register to store the 4-bit input and a 2-bit counter to index through the bits without shifting the data. On reset, clear the counter and valid_out. When the counter reaches 0, load the new parallel data into a register and set valid_out high for one cycle to indicate new valid serial output. On each clock cycle, output the bit indexed by (3 - counter) from the stored data register, output MSB first. Increment the counter each cycle modulo 4. This avoids shifting data, reducing switching and power, and uses a simple multiplexer to select the output bit, enhancing timing and area efficiency.
