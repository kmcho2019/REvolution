Instead of shifting the data register every cycle, keep the input data fixed in a 4-bit register and use a 2-bit counter as a bit index to select the output bit. On every clock, output the bit indexed by the counter starting from the MSB (bit 3) down to the LSB (bit 0). When the last bit is output (counter == 3), load new parallel data and reset the counter to 0. The valid_out signal is asserted for one cycle exactly when new data is loaded and the MSB is output. This avoids shifting, reduces switching activity and power, and simplifies timing paths.
