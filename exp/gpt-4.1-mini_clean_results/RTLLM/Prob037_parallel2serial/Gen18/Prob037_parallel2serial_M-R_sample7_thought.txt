Refactor the design by using a shift register to hold the parallel input data and a counter to track the number of bits shifted out. On reset or after all bits are shifted out (counter reaches 4), the shift register is loaded with input d, the counter resets to 0, and valid_out is set high. Each clock cycle shifts the register left by one, outputs the MSB, increments the counter, and sets valid_out low except when loading new data. This approach emphasizes data shifting explicitly rather than bit indexing, making the serialization process clearer and modular.
