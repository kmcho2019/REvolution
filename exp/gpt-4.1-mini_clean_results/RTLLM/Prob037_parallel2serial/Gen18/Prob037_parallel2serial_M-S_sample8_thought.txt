Use a 2-bit counter to track which bit of the stored parallel data to output serially. On reset or when the counter reaches 3 (last bit output), load the input parallel data into a register. Each clock cycle, output the bit indexed by the counter from MSB to LSB and assert valid_out only when outputting the MSB (when counter is 0). This eliminates shifting data around, simplifies control, and maintains the required valid_out signaling.
