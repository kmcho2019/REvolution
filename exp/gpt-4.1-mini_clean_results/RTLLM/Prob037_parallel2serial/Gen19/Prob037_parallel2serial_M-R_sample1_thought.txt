Refactor the design to use a state machine approach with explicit states representing the bit position to output. On reset, the module starts in an IDLE state. When the counter reaches 3 (last bit sent), the module loads the new parallel input into a shift register and sets the counter to 0, starting the serial output sequence. Instead of indexing the bit combinationally, shift the data register right each cycle to output the MSB directly. The valid_out is asserted for 1 cycle when new data is loaded, indicating the serial output is valid. This shifts the data register logically, simplifying the output logic and separating data loading from shifting.
