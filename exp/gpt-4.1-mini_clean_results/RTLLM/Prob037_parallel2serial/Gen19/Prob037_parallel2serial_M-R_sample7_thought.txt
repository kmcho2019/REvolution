Refactor the module to use a state machine with two states: LOAD and SHIFT. On LOAD state, the 4-bit parallel data `d` is loaded into a shift register. Then, in SHIFT state, the register shifts left each cycle, outputting the MSB bit serially. A 2-bit counter tracks the output bit index. The valid_out signal is asserted only when a new data is loaded (LOAD state). This approach separates loading and shifting explicitly, makes the FSM clearer, and uses a shift register for serialization instead of index-based bit selection.
