The counter counts from 0 to 3, tracking how many bits have been output. `valid_out` is asserted only when the first bit (MSB) is output, i.e., when `cnt` is zero. On reset, clear registers. On the last bit output (`cnt == 3`), reload the shift register with the new input data and reset the counter.

This structure separates the data storage from the input port, reduces glitching on `dout` caused by combinational indexing of asynchronous input `d`, and uses synchronous logic to control output, making the output stable and predictable.
