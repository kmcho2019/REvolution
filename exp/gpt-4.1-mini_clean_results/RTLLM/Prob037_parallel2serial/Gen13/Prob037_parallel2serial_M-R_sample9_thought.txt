Refactor the design by separating the state and the output logic: use a 2-bit counter (cnt) as a pointer indexing the bits of the loaded data instead of shifting the data register. On every cycle, when cnt is 0, load data with input d and set valid_out=1; for cnt=1 to 3, increment cnt and output the next bit with valid_out=0. This avoids shifting the data and only increments the counter, reducing switching activity on the data register. Use a simple state machine controlled by the counter. The serial output dout is assigned combinationally as data[3 - cnt], corresponding to MSB first output. This approach preserves functionality but changes the structure to use a pointer-based output rather than circular shifting.
