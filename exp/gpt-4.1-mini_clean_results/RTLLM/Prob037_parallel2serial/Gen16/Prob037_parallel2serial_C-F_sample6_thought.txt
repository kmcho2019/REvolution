To fuse the best ideas from both examples: use an internal 4-bit register to latch the input `d` only when the counter completes a full cycle (cnt == 3). This reduces input switching activity and glitches on output since `d` is stable during serialization, improving power and timing. Use a 2-bit counter to index bits from the internal register (not directly from input `d`), outputting from MSB to LSB by `data[3 - cnt]`. Assert `valid_out` only on the cycle when the MSB is output (cnt == 0) to indicate the start of a new serial sequence. Reset logic is synchronous for better timing closure. This approach maintains minimal area (only one register plus 2-bit counter), reduces switching by decoupling input changes from serialization, and simplifies output logic by combining shift-register stability with indexed bit output from the stable register.
