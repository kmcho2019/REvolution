Implement the parallel-to-serial converter using a 4-bit shift register that loads the input data 'd' when the counter reaches 3 (end of the current serialization). On each clock cycle, output the MSB of the shift register as 'dout', set 'valid_out' to 1 only when the MSB is output (i.e., at counter == 0), then shift the register left by one bit on every cycle. The 2-bit counter increments from 0 to 3, controlling both when to load new parallel data and when to assert valid_out. This architecture localizes all bit manipulations within a shift register and separates control logic cleanly.
