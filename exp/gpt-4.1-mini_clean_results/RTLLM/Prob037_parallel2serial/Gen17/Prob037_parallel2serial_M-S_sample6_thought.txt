Use a 2-bit counter to track the bit position from MSB to LSB. Register the parallel input data at the start of each 4-bit serialization cycle (when counter is 0). Output the corresponding bit from the registered data on each clock cycle, from MSB to LSB, asserting valid_out only during these four output cycles. This eliminates shifting by indexing bits directly, and registers input data once per cycle to reduce combinational input dependency, simplifying timing and logic.
