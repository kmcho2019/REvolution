Instead of using a single register with a concatenation operation, implement the right shifter as an array of flip-flops where each bit is updated explicitly by shifting the previous bit to the right. On each clock edge, the MSB receives the new input bit d, and each subsequent bit receives the value from the bit above it. This bitwise assignment clearly reflects the right-shift behavior in sequential logic and makes the dataflow explicit. Initialize the register to zero using an initial block. This approach is a structural and explicit shift, which may help with visualization and debugging, and can also be beneficial for certain synthesis tools that better recognize serial shifting when described this way.
