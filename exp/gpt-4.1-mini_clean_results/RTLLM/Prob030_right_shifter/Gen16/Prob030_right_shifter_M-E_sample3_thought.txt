Implement the right shifter using a shift register approach that combines the right-shift and input bit insertion in a single clocked always block without separate combinational logic. On each rising clock edge, the register q is shifted right by one bit, and the input d is assigned directly to the most significant bit q[7]. This approach uses a single statement with bit concatenation and bit slicing to create the next state for q, enhancing code compactness and readability. Initialization is done in an initial block to zero the register for simulation.
