Implement a multi-bit synchronizer by using a handshake approach where data and enable signals are first captured and held stable in clk_a domain, then a pulse is generated on clk_b domain after synchronizing the enable through a two-stage synchronizer. Instead of directly outputting data when enable is high, use an explicit load pulse derived from synchronized enable signals to latch the data into the clk_b domain output register. This load pulse is generated by detecting rising edge of the synchronized enable (two-stage delay). This guarantees data is latched only once per enable assertion, preventing multiple loads during the enable window. The data captured in clk_a domain remains stable because data_en is stable for at least 3 clk_b cycles and data_in changes infrequently. This avoids combinational mux on the output register, improving timing robustness. Asynchronous resets clear all registers.
