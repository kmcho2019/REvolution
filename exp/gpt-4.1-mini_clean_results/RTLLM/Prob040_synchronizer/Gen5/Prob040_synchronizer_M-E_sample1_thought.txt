Use a handshake-based multi-bit synchronizer approach with a small FIFO buffer to safely transfer and synchronize data from clk_a to clk_b domain.

- In clk_a domain:
  - Sample data_in and data_en when data_en is high and data_in stable.
  - Store data_in into a simple 1-depth FIFO register and assert a "valid" signal.
- In clk_b domain:
  - Use a two-stage synchronizer to synchronize the "valid" signal into clk_b domain.
  - Once valid is detected in clk_b, latch the FIFO data into output register dataout.
  - De-assert the FIFO "valid" signal only after the data has been latched, creating a handshake.
- Use asynchronous resets per domain.
- This handshake FIFO method provides robust synchronization avoiding direct data crossing, since data_in changes slowly.
- The data_en signal is used to load data into FIFO; FIFO valid is synchronized to clk_b for data output enable.
- Data output only updates in clk_b domain after two clk_b cycles delay of the valid signal, ensuring stable sampling.
