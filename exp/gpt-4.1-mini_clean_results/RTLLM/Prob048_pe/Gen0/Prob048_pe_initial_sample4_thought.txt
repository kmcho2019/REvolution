Implement a 32-bit multiplying accumulator named "pe". The module has inputs clk, rst, a, and b, and output c. The internal register c stores the accumulation result. On a positive edge of clk or rst, if rst is high, clear c to 0, else multiply a and b and add the result to c. Since a*b can be up to 64 bits, but output c is 32 bits, truncate or wrap the accumulated value to 32 bits by storing only the lower 32 bits. The multiplication and addition are done in a synchronous always block.
