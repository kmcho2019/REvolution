To offer a novel architectural solution, implement the MAC using a 32-bit accumulator that saturates on overflow to prevent wrap-around issues typical in fixed-width arithmetic. This approach avoids using a 64-bit accumulator, saving register area, and simplifies output port width to directly match the accumulator register size. The multiplication result is truncated to 32 bits by taking the lower 32 bits, then added to the accumulator with saturation logic:

- On reset, accumulator resets to zero.
- On each clock cycle, multiply a and b, truncate to 32 bits (lower bits), then add to accumulator.
- If addition overflows, the accumulator saturates at the maximum 32-bit unsigned value (all ones, 0xFFFFFFFF).
- Output c is the accumulator value.

This design is simpler, area-efficient, and safer for fixed-width 32-bit accumulation where overflow wrap-around is undesirable. Saturation logic adds a minor complexity but greatly improves robustness. This design targets unsigned inputs for clarity; signed inputs would require signed saturation logic.

Optional extensions include support for signed inputs and adjustable saturation bounds, but the basic version is demonstrated here.
