Implement a 64-bit internal accumulator register to fully capture the multiplication result and accumulation without overflow. Since a 32-bit by 32-bit multiplication results in a 64-bit product, a 64-bit accumulator ensures no loss of information due to overflow during accumulation.

At each clock cycle, multiply the inputs `a` and `b` to get a 64-bit product, then add it to the 64-bit accumulator. The accumulator can be reset synchronously with `rst`. To comply with the 32-bit output width for `c`, the lower 32 bits of the accumulator are exposed as the output. This preserves the lower part of the accumulation and allows downstream logic to process partial sum or use overflow detection externally if necessary.

The multiplication and accumulation happen in a single always block triggered on the positive edge of the clock or reset signal, ensuring synchronous reset and accumulation.

This approach prioritizes correctness and maximum precision in accumulation over area or power, accepting that the output width is truncated to 32 bits, which is consistent with the specified output port size.

Additional notes:
- Output `c` is declared as reg and updated synchronously with the accumulator.
- The code uses non-blocking assignments for sequential logic.
- This design is straightforward, easy to understand, and optimal for accuracy within given output width constraints.
