To implement a serial-to-parallel converter that collects 8 serial bits and outputs them in parallel with the first bit received as the most significant bit, I propose the following approach:

- Use a 4-bit counter `cnt` to count the number of valid serial bits received.
- Use an 8-bit shift register `shift_reg` that shifts in the incoming serial bit at the MSB side on each valid input, pushing existing bits towards the LSB.
- On each clock cycle when `din_valid` is asserted, shift the new bit into the MSB position, shifting the current bits towards LSB.
- When 8 bits have been received (i.e., `cnt` reaches 7 on zero-based counting), latch the shift register contents into the output `dout_parallel` and assert `dout_valid` for exactly one clock cycle.
- Reset the counter and shift register after outputting.
- Synchronous active low reset `rst_n` initializes all registers.
  
This approach naturally aligns the first received serial bit to the MSB of the output and the last received bit to the LSB, satisfying the requirement. The use of the MSB shift-in direction simplifies bit ordering. The 4-bit counter covers counting from 0 to 7 (8 bits).

This design also ensures a one-cycle valid output pulse when the parallel data is ready.
