Use a straightforward shift register approach triggered directly by din_valid to shift bits into an 8-bit register from MSB to LSB. A 4-bit counter counts the number of bits shifted in. When 8 bits have been received, output the parallel data and set dout_valid for one cycle. Use a synchronous reset. This design does not require an explicit state machine; the logic is simplified by only reacting when din_valid is high, making it easier to verify and integrate.
