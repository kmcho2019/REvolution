Use a simple 8-bit shift register that shifts in the serial input bit on each valid clock cycle, but shifting the bits left so that the first serial bit received ends up at the MSB of the register after 8 bits. Use a 4-bit counter to count how many bits have been received. When the count reaches 7 (meaning 8 bits total received), output the shift register as parallel output and assert dout_valid for one cycle. The counter and shift register reset asynchronously on rst_n. This approach uses minimal control logic and no explicit state machine, relying solely on counter and synchronous shift logic.
