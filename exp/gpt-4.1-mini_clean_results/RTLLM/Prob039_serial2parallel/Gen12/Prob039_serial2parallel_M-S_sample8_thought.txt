Simplify the design by using a single 8-bit register that shifts in the serial data MSB-first on each valid input. Use a 4-bit counter to track how many bits have been received. Once 8 bits are collected (counter reaches 7), output the current shift register value and assert dout_valid for one cycle. Reset all registers synchronously on rst_n. This approach removes redundant concatenation for output, directly outputting the shift register contents when full. The logic remains clear, minimal, and fully synchronous.
