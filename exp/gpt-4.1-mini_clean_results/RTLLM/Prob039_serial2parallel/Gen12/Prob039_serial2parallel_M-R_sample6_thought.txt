Refactor the design to use a state machine with two states: IDLE and COLLECT. In IDLE, wait for a valid serial input and start collecting bits. In COLLECT state, shift each incoming serial bit into an 8-bit shift register from MSB to LSB by shifting left and inserting the new bit at LSB, ensuring the first bit received ends up at the MSB after 8 inputs. Use a 4-bit counter to count received bits. When the counter reaches 7 (total 8 bits collected), output the parallel data with dout_valid asserted for one cycle, then return to IDLE. Synchronous reset clears all registers and state. This structure clearly separates waiting and data collection phases and uses left shifting for natural MSB-first bit placement.
