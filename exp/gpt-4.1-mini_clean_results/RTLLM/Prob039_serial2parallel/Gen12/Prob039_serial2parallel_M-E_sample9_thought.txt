Implement a synchronous shift register that shifts in the serial input bit at the MSB position whenever din_valid is asserted. Maintain a 4-bit counter to count the number of valid bits received. When the counter reaches 8 (i.e., after 8 bits have been shifted in), latch the contents of the shift register into the output register dout_parallel and set dout_valid high for one clock cycle.

Key idea differences:
- Separate shift register and output register clearly.
- Shift register always updates when din_valid is high, shifting bits left to right to keep the first received bit at dout_parallel[7].
- When 8 bits received, transfer shift register content to dout_parallel and pulse dout_valid for a single cycle.
- Reset all registers synchronously on rst_n.
- dout_valid pulse length is one clock cycle to simplify interfacing.

This approach ensures stable, glitch-free output and clear timing for downstream logic without simultaneous shift and output latch in the same cycle.
