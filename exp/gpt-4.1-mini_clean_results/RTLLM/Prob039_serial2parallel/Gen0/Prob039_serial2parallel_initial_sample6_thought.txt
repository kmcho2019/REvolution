The module uses a 4-bit counter to count the number of valid serial bits received. Each time din_valid is high on a rising clock edge, the incoming serial bit is shifted into an 8-bit register from the MSB to the LSB position. When the counter reaches 8, the parallel output is updated, and dout_valid is asserted for one clock cycle to indicate valid parallel data output. The counter and data register reset asynchronously with active-low rst_n.
