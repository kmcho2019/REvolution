Refactor the serial-to-parallel converter using a state machine approach with two states: IDLE and SHIFT. Use a 4-bit counter to track the number of valid bits received. On each valid serial input, shift the accumulated bits left and insert the new bit at the LSB. Once 8 bits have been collected (counter reaches 8), output the parallel data and assert dout_valid for one clock cycle, then return to IDLE to wait for the next data sequence. This clarifies control flow, avoids subtle counting/reset issues, and cleanly separates data accumulation from output signaling.
