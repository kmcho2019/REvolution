Implement a purely counter-driven shift register without using a state machine. On each rising clock edge, if din_valid is asserted, shift din_serial into an 8-bit register from MSB to LSB, using a 4-bit counter to track how many bits have been shifted in. When the count reaches 7 (meaning the 8th bit was just shifted in), output the parallel data and set dout_valid high for one cycle. Then reset the counter for the next byte. This synchronous design is simple and efficient, directly aligning with the problem requirements and avoiding complexity.
