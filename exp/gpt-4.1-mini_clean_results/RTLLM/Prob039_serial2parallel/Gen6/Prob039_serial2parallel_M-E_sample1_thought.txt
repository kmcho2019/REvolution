Implement the design using a 4-bit counter that increments only when din_valid is high. Instead of shifting bits into a register, use an 8-bit register where each bit position corresponds directly to the count index; that is, when the first bit arrives (count=0), store it in bit 7 (MSB), second bit in bit 6, ..., eighth bit in bit 0 (LSB). This can be done by assigning the serial input bit to the bit position (7 - cnt) in the parallel register. When the counter reaches 7 (after the eighth bit), assert dout_valid and output the full 8-bit data in dout_parallel. This approach avoids shifting altogether, making the bit placement explicit and clear.
