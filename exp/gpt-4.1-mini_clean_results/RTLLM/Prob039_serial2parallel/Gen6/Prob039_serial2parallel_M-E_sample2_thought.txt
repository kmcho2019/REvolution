Use a shift register that shifts in the serial data MSB first on each valid input, and maintain a 4-bit counter counting the number of valid bits received. When 8 bits have been received, output the entire shift register as dout_parallel and assert dout_valid for exactly one clock cycle. Instead of updating dout_valid asynchronously or resetting it separately, generate dout_valid based on the counter reaching 8, and clear the counter and shift register synchronously. This design avoids mixing combinational and sequential logic by making all state updates synchronous and uses a dedicated state to indicate data ready. The first bit received is shifted into the MSB side, so the serial bits are placed from MSB to LSB in dout_parallel as required.
