Use a single 3-bit counter to count the number of valid input bits received (from 0 to 7). On each valid input, shift the existing data left by one and insert the new bit at LSB, so that the first bit ends up in MSB after 8 bits. When the counter reaches 7, output the parallel data and assert dout_valid for exactly one clock cycle. Use synchronous reset to clear all registers. This approach is simple, uses minimal registers, and clearly aligns bit order with the problem statement.
