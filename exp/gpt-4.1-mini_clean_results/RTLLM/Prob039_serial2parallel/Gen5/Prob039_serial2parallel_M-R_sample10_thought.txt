Refactor the design to use a finite state machine (FSM) with two states: IDLE and LOAD. In the IDLE state, the module waits for din_valid to start shifting data. When din_valid is asserted, it moves to LOAD state, where it shifts the serial data into the shift register on every valid input. A 4-bit counter tracks how many bits have been received. Once 8 bits are collected, the module asserts dout_valid for one clock cycle and outputs the parallel data, then returns to IDLE to wait for the next data. This FSM approach separates control and data path clearly and uses synchronous reset and clock, maintaining the MSB-first bit order by shifting left and inserting new bits at the LSB.
