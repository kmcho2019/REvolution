Use a shift register approach where on each valid input, the serial bit is shifted into the register from MSB side to LSB side. This directly builds the parallel output in the correct bit order (MSB first). A 3-bit counter counts the number of bits received. When 8 bits have been shifted in, output the register and assert dout_valid for one clock cycle, then reset the counter. This simplifies the design by using a shift register instead of indexed assignments, reducing logic and maintaining functionality.
