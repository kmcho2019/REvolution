Refactor the design to use a shift register approach instead of indexing bits directly. On each valid serial input, shift the existing bits left by one and insert the new bit at LSB. This naturally builds the 8-bit parallel word from MSB to LSB as bits arrive. The 4-bit counter still tracks the number of bits received. When the count reaches 8, assert the output valid signal and present the shifted register as the parallel output. This approach simplifies data assembly using shift operations, removes the need to address specific bits, and clearly shows the serial-to-parallel conversion as a shift process.
