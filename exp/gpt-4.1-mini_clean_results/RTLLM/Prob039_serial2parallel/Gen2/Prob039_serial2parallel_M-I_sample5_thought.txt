To strictly follow the problem specification, use a 4-bit counter for counting received bits. The serial bits should be shifted into an 8-bit shift register from MSB to LSB so that the first received bit is at dout_parallel[7] and the last at dout_parallel[0]. We increment the counter only when din_valid is high, and once 8 bits are collected (counter reaches 7), output the parallel data, set dout_valid for one clock cycle, and reset the counter to 0 to start next accumulation. Use synchronous reset for all registers. Keep dout_valid asserted for exactly one cycle upon completion. This design meets specs and is efficient with minimal logic.
