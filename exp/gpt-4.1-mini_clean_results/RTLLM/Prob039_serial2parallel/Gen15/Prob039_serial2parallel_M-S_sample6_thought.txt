Implement a simple serial-to-parallel converter using a shift register that shifts in the serial input bit at the MSB on each valid input. Use a 4-bit counter to count from 0 to 7 the number of received bits. When the 8th bit arrives (counter == 7), latch the current shift register content to the parallel output and assert dout_valid for one cycle. Reset counter and shift register on active low reset. This design keeps the bit ordering and control logic straightforward and minimal.
