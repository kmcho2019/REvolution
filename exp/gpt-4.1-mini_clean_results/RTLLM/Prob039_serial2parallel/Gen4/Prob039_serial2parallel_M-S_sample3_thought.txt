Use a simple 8-bit shift register that shifts left by one on each valid input bit, inserting the new serial bit at the least significant bit position. A 3-bit counter tracks the number of bits received (0 to 7). Once 8 bits are collected (counter reaches 7), output the parallel data and set dout_valid high for one clock cycle. Then reset the counter and shift register for the next byte. This design keeps the serial data order with the first bit received at MSB and last at LSB, uses minimal logic, and synchronous reset.
