Implement the serial-to-parallel converter by directly placing each incoming serial bit into the corresponding bit position of the 8-bit output register, rather than using a shift register. Use a 4-bit counter to count how many bits have been received (from 0 to 7). On each valid input bit, store it at bit position (7 - cnt) in dout_parallel, so the first received bit goes to the MSB and the last to the LSB. After receiving 8 bits (when cnt reaches 7), assert dout_valid for one clock cycle and then reset the counter to zero, preparing for the next 8-bit frame. This approach eliminates shifting and makes bit placement explicit and clear, ensuring proper bit order. The entire design remains synchronous and uses reset to initialize registers.
