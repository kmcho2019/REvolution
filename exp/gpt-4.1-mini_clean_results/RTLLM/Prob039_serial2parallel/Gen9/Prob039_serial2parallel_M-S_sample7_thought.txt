Shift the incoming serial bit directly into the output register from MSB to LSB on each valid input, without needing a separate bit-reversal function or shift register. Use a 4-bit counter to track the number of bits received, decrementing from 7 to 0, so the first bit fills the MSB, the second bit the next MSB, and so on.
