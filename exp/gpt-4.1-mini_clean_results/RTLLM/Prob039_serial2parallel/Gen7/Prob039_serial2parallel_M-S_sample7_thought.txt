Use a single 8-bit shift register shifting in the serial bit at the MSB side on every valid input, and a 4-bit counter incrementing with each valid bit. When the counter reaches 7 (meaning 8 bits received, counting from 0), output the shifted register as dout_parallel and assert dout_valid for one clock cycle. After outputting, reset the counter and shift register. The design keeps all state updates synchronous and simplifies logic by directly using the counter value to generate dout_valid and data output.
