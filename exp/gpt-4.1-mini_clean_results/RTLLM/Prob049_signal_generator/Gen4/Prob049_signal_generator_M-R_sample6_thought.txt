Refactor the triangle wave generator by separating the next-state logic from the state registers for clarity. Instead of mixing state updates and output updates in one always block, use a combinational always block to calculate the next state and next wave value based on the current state and wave. Then update the state and wave registers synchronously on the clock edge.

This approach:
- Uses two registers: `state` (direction flag) and `wave`.
- Computes `next_wave` and `next_state` combinationally.
- Assigns the registers in a single synchronous always block.
- Enhances readability by isolating the combinational decision logic.

This structure aligns with typical FSM coding styles and helps separate combinational and sequential logic cleanly.
