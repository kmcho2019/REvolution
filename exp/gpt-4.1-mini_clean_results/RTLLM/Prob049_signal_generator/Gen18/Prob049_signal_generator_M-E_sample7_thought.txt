Implement the triangle wave generator using a single 6-bit counter to represent the wave value with an embedded direction bit in the MSB.

- Use a 6-bit register "counter" where bits [4:0] represent the 5-bit wave value, and bit [5] serves as the direction flag (0: increment, 1: decrement).
- On each clock cycle, increment or decrement the 5 LSBs based on the direction bit.
- When the lower 5 bits reach 31, set direction to decrement.
- When the lower 5 bits reach 0, set direction to increment.
- This approach eliminates a separate state register, embedding state info within the counter itself, simplifying the design.
- On reset, initialize the entire counter to 0 (wave = 0, direction = 0).
- Output wave directly from bits [4:0] of the counter.
- This leverages single register update and simple arithmetic with a direction bit, resulting in a compact, elegant design.

This method offers a novel architectural twist by encoding direction and value together, reducing state management overhead while satisfying all requirements.
