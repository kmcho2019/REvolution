Implement the triangle wave generator using a single 6-bit counter that counts from 0 to 62, and then derive the 5-bit wave output by mapping counts 0 to 31 linearly upwards and counts 32 to 62 linearly downwards to produce the decrementing slope. This eliminates the need for a separate state register.

The counter resets at 0 and increments on each clock cycle. The wave output equals the counter value when counting up (0 to 31) and equals (62 - counter) when counting down (32 to 62). When the counter reaches 62, it wraps back to 0.

This architecture simplifies the control logic by using a single counter, removes the explicit state, and implements the waveform shape via arithmetic mapping, making the design concise and elegant.
