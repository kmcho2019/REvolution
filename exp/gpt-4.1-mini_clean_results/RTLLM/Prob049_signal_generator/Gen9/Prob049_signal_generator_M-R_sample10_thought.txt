Refactor the design by integrating the state (direction) and wave update into a single always block controlled by a 1-bit state register. Use a simple state machine with two states (0: increment, 1: decrement) inside one synchronous always block triggered on the clock and reset. This reduces the number of always blocks and the redundant conditional checks by evaluating both wave and state updates atomically. The wave register increments or decrements based on the current state. When wave reaches boundary values (0 or 31), the state toggles to change direction. This approach simplifies control flow, reduces comparisons, and keeps all logic synchronous and clean.
