Simplify the design by removing the case statement and using a single bit state (direction) to decide whether to increment or decrement the wave register. Update both the wave and state registers on each clock edge in a straightforward if-else structure. This reduces the code size while preserving the same behavior and synchronous reset. The wave increments until it reaches 31, then the state changes to decrement mode; it decrements until it reaches 0, then the state flips back to increment mode.
