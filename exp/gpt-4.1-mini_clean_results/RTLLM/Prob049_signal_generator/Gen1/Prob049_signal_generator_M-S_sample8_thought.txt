Use a single 5-bit register "wave" and a direction bit "dir" to indicate counting up or down. On reset, initialize wave to 0 and dir to 0 (counting up). On each clock edge, increment wave if dir=0, decrement if dir=1. When wave reaches 31, set dir=1 to count down; when wave reaches 0, set dir=0 to count up. This removes the need for a state variable, simplifying logic while preserving behavior.
