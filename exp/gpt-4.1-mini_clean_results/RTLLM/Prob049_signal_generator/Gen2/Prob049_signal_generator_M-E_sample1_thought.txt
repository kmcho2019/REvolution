Instead of using an explicit state register to track increment or decrement direction, this design uses a direction signal derived from the waveform value and a toggle flag. The wave value increments until reaching the maximum (31), then the direction toggles to decrement until it reaches zero, toggling the direction again. This is implemented using a combinational comparison to determine when to reverse direction, eliminating the need for a dedicated state register. The direction is stored as a single-bit register that toggles when wave hits the boundaries. This simplifies the control logic and clearly separates the direction control from the waveform count. The wave updates every clock cycle synchronized with clk and reset.
