Use a simpler approach by combining state and wave updates in a single always block without a separate next_wave combinational signal.  
Store the state bit indicating direction (0: increment, 1: decrement), update wave directly each clock cycle based on state.  
On reaching boundaries (0 or 31), toggle state and update wave accordingly.  
Reset asynchronously sets both wave and state to zero.  
This reduces combinational complexity, removes an extra always block, and keeps clear synchronous updates with minimal logic.
