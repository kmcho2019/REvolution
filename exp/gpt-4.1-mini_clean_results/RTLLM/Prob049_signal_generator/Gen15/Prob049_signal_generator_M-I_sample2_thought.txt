To optimize the existing triangle wave generator for better performance, power, and area (PPA) without changing functionality:

1. Eliminate the combinational next_wave logic to reduce combinational path length and simplify timing. Instead, compute next wave value and update state in a single synchronous always block.
2. Use a synchronous state machine with a 1-bit state register (direction).
3. Use simple conditional checks to increment or decrement wave inside the clocked block, toggling the direction when hitting boundaries.
4. This approach removes a combinational block, potentially reducing critical path and logic depth.
5. It may slightly reduce switching activity by updating wave only once per cycle without additional combinational logic.
6. Code remains clear, and meets asynchronous active-low reset and cycle boundaries specification.

This yields a minimal and efficient design with straightforward synchronous logic and minimal combinational complexity.
