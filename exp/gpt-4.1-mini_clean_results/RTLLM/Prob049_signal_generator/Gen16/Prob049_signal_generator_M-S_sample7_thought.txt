Use a straightforward synchronous always block triggered on posedge clk and negedge rst_n. Use a 1-bit state register to track direction (0: increment, 1: decrement) and a 5-bit wave register to store the waveform. On reset, clear both to 0. On each clock edge, if state is 0, increment wave until it reaches 31, then switch state to 1; if state is 1, decrement wave until it reaches 0, then switch state back to 0. This removes combinational next-state logic and conditional register updates for a simpler, easy-to-understand design that meets all functional requirements.
