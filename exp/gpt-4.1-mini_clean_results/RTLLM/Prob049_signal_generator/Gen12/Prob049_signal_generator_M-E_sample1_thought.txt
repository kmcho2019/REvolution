Use a direction bit to control whether to increment or decrement the wave value. On each clock cycle, if not reset, update wave by adding or subtracting 1 according to direction. When wave reaches 31, set direction to decrement (0), and when wave reaches 0, set direction to increment (1). This approach uses a single direction bit as state and updates it synchronously inside one always block, making the code concise and easy to understand. No separate next-state logic is needed; all state updates happen sequentially. This architecture simplifies the logic and makes the waveform generation intuitive.
