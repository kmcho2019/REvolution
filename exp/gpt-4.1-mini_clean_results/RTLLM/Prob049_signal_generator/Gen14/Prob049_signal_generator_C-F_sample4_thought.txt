Fusion strategy:

Combine the clarity and modular reasoning from Example 2 with the compactness and minimal always block usage from Example 1.

- Use a single always block triggered by posedge clk and negedge rst_n, simplifying timing and reducing register-to-register delay.
- Use a 1-bit state register named 'state' as direction indicator (0=up,1=down), explicitly updating it alongside the wave register within the same block for tight control and minimal latency.
- On reset, initialize wave to 0 and state to 0 (increment mode).
- Within the always block:
  - If state is 0 (increment):
    - Increment wave by 1.
    - If wave reaches 31 after increment, flip state to 1.
  - If state is 1 (decrement):
    - Decrement wave by 1.
    - If wave reaches 0 after decrement, flip state to 0.
- This approach ensures wave value updates and state transitions happen atomically on the same clock edge, minimizing glitch and combinational path.
- Avoid unnecessary holding assignments; the wave simply increments or decrements and state flips exactly when boundary is hit, avoiding redundant logic.
- This design balances timing, power, and area efficiency with code simplicity and readability.
