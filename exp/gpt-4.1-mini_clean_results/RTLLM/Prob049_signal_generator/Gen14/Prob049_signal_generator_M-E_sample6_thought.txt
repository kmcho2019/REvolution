Implement the triangle wave generator using a 2-bit state register explicitly encoding the two states: increment and decrement. Use this state to control whether the wave value increases or decreases. On reset, initialize state and wave to zero. On each clock cycle, depending on the state, update wave accordingly and switch state when wave hits boundary values (0 or 31). This approach matches the originally requested use of a state register and a case statement to clearly represent the waveform direction FSM.
