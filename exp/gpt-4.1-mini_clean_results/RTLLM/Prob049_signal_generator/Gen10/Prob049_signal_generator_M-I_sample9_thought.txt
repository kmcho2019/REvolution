To improve PPA, integrate the state and wave update logic into a single always block to eliminate redundant comparisons and simplify control logic. Instead of using two always blocks, use a single state register (direction) and update wave accordingly. Avoid unnecessary updates by checking boundary conditions before increment/decrement, so wave changes only when needed. This reduces switching activity (power) and simplifies control logic (area). Using a single always block may also improve timing by reducing combinational fanout and dependency. Non-blocking assignments are kept for correct sequential logic.
