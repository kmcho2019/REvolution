Use a single always block with a simple if-else structure instead of a case statement for state control. Keep the state bit to indicate direction (0 for increment, 1 for decrement). Update wave and state in the same block on clock edge or reset. On reset, initialize wave and state to zero. When incrementing, increase wave until 31, then flip state to decrement; when decrementing, decrease wave until 0, then flip state to increment. This reduces control logic complexity while maintaining the same functionality.
