To optimize for better PPA (timing, power, and area), I will:
1. Merge the combinational logic into the sequential always block to reduce combinational logic levels and area.
2. Calculate next wave directly within the clocked process to eliminate the separate next_wave register and combinational always block.
3. Update wave only when it changes (avoid re-writing same value), reducing unnecessary toggling and saving dynamic power.
4. Keep state toggle logic minimal and directly embedded within the sequential block for clarity and speed.
5. Use asynchronous active-low reset as specified for fast initialization.

This results in a minimal, clean implementation with fewer registers and logic gates, less toggling, and a tighter critical path.
