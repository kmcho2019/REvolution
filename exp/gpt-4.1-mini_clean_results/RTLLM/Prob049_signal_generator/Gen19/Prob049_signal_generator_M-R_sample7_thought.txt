Refactor the design by using a two-process approach with a clearly defined state machine encoded as a localparam, and use synchronous reset instead of asynchronous reset for simplicity and consistent timing. Use a single always block triggered on posedge clk, and implement wave and state updates together, eliminating the intermediate next_wave register. The next wave value is calculated inside the always block with a case statement on the state, and the state toggling logic is embedded after wave update. This reduces combinational dependencies and simplifies the design. The output wave is registered as required.
