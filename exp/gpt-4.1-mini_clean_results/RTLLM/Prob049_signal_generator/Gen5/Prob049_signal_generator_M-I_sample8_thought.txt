To optimize the original design for better performance, power, and area, separate the state update and wave update into two always blocks triggered by the clock edge. This allows the synthesis tool to better pipeline the logic and improve timing. Additionally, update the wave register each clock cycle according to the current direction state, and update the state only when wave reaches the boundary values. This separation reduces combinational dependencies and switching activity, leading to improved PPA. Also, use non-blocking assignments consistently for synchronous logic. The resulting code maintains the exact functionality but is cleaner and more optimized for synthesis.
