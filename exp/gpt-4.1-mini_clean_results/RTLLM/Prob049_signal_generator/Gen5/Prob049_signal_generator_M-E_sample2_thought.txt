Implement the triangle wave generator using a single 5-bit register 'wave' and a direction flag 'dir'. Instead of using an explicit state machine with separate state and next_state variables, we will use a direction bit that toggles when the waveform reaches either boundary (0 or 31).

On each clock cycle:
- If dir is 0, wave increments by 1.
- If dir is 1, wave decrements by 1.
- When wave reaches 31, dir flips to 1 to start decrementing.
- When wave reaches 0, dir flips back to 0 to start incrementing.

This approach simplifies control logic by combining state and output update in one always block, reducing combinational logic and registers used, while maintaining functionality. The direction bit toggling is driven directly by the boundary conditions of the wave.

On reset, both wave and dir are cleared to 0.

This design is compact and synthesizes efficiently.
