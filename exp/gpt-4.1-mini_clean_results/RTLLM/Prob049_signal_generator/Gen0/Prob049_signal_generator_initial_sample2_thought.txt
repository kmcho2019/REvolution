Implement a module named signal_generator with clk and rst_n inputs and a 5-bit wave output. Use a 1-bit state register to control whether wave is incrementing (state=0) or decrementing (state=1). On reset, set state and wave to 0. On each clock edge, update wave according to state: increment if state=0, decrement if state=1. Switch state when wave reaches the bounds (0 or 31).
