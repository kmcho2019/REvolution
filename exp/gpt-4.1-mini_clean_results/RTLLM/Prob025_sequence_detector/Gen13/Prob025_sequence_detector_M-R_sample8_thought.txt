I will refactor the sequence detector FSM by using binary state encoding instead of one-hot encoding to reduce the number of flip-flops and combinational logic area. The FSM will be structured with a single synchronous always block for both state transition and output logic (Moore-type output), removing the asynchronous reset from outputs to simplify timing. The reset remains synchronous active low. Next state logic will be calculated in a combinational block separately, using a case statement on binary-encoded states. The output signal `sequence_detected` will be asserted for one cycle when the FSM reaches the final state. This restructuring improves area and power efficiency while keeping the same functional behavior.
