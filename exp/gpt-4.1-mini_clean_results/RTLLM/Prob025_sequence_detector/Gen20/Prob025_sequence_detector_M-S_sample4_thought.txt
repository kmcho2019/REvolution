To simplify the sequence detector, I will implement the FSM using a single always block with a case statement for state transitions and output logic. This reduces the complexity by combining next state and output logic in one place. The reset will be synchronous and active high, matching the problem description. The output signal will be a registered Moore output asserted only in the final detection state (S4). State encoding will remain binary encoded with minimal bits for simplicity. This approach is straightforward, easy to read, and efficient without nested ternary operators or separate combinational logic blocks.
