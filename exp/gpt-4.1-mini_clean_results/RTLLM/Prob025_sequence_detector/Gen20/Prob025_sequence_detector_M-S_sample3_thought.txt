To simplify the sequence detector while maintaining correct functionality, I will:

1. Use a binary-encoded FSM instead of one-hot to reduce the number of flip-flops and simplify state representation.

2. Implement a Mealy machine where the output `sequence_detected` is asserted combinationally based on the current state and input, thus avoiding an extra register for output and simplifying output logic.

3. Use synchronous active-low reset to initialize the FSM to IDLE.

4. Maintain overlapping sequence detection by carefully defining next state transitions.

This approach reduces area by using fewer flip-flops and simplifies the output logic, making the design easier to understand and potentially improving timing by reducing combinational complexity.
