Refactor the sequence detector FSM to use a one-hot encoding style for the states implemented as separate registers rather than an enumerated type. Use a synchronous reset with an active-low reset signal directly in the always block. The next state logic and output logic will be combined in a single always block with case statements for clarity. Also, implement the output signal as a registered signal asserted for one clock cycle when the sequence is detected (on entering the final state). This style provides clear signal assignments, slightly simpler state handling, and a direct reset without inverting signals internally.
