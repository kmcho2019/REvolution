To implement a sequence detector for "1001" differently, I will use a binary-encoded Moore FSM with 4 states corresponding to the detection progress. The states represent how many bits of the sequence have been matched so far. Transitions depend on the current input bit and previous state. The output sequence_detected will be asserted in the state representing full match (i.e., after the last bit "1" is received). The FSM will have synchronous active-low reset.

The states:
- S0: no match (initial)
- S1: detected '1'
- S2: detected '10'
- S3: detected '100'
- S4: detected '1001' (output asserted)

The transitions are designed to handle overlapping sequences by transitioning appropriately to the correct state if partial sequence prefixes appear within the input bitstream.

This design uses binary encoding (3 bits) to reduce flip-flop count and combinational complexity. The Moore FSM output is synchronous and asserted only in the detected state, simplifying output timing.

Reset clears the FSM to the initial state (S0).
