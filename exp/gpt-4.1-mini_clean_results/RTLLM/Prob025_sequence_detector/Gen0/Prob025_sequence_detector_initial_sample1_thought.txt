Implement a Moore finite state machine with five states (IDLE, S1, S2, S3, S4) to detect the 4-bit sequence "1001". The FSM advances state when the expected bit in the sequence is matched; otherwise, it transitions appropriately to allow overlapping detection. The output sequence_detected is asserted for one clock cycle when the sequence is fully detected (state S4). The FSM is synchronous with the clock and is reset asynchronously by the active-high reset signal reset_n (low active, so reset when reset_n is 0).
