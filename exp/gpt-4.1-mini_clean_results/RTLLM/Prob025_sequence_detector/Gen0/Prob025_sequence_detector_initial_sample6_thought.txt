Implement a synchronous FSM that detects the sequence 1001 on the input data_in. The FSM has five states: IDLE, S1, S2, S3, and S4, corresponding to detecting each bit of the sequence. On each clock edge, depending on the current state and the input bit, the FSM transitions accordingly. When the final state (S4) is reached, sequence_detected is asserted high for one clock cycle. On an active high reset (reset_n is active low, so reset_n=0 means reset), the FSM returns to IDLE.
