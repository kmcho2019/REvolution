Implement the sequence detector using a Moore FSM with enumerated states representing the number of bits matched so far, from 0 to 4. Each state encodes how many bits of the target sequence "1001" have been matched in order. On each clock cycle, the FSM transitions to the next appropriate state based on the input bit. The output `sequence_detected` is asserted synchronously (one clock cycle after detection) when the FSM reaches the final state (4 bits matched). Use an asynchronous active-low reset to initialize the FSM to the idle state. This approach leverages clean state naming and transitions that handle overlapping sequences inherently, facilitating straightforward understanding and efficient synthesis.
