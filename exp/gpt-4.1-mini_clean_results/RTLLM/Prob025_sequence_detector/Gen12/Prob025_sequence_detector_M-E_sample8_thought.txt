I will implement the 4-bit sequence detector (for sequence "1001") using a binary-encoded FSM with minimal states and a Mealy machine approach. This will detect the sequence in a streaming fashion, allowing overlapping sequences. The states will represent the current match progress (0 to 3 matched bits). The next state depends on the current state and the input bit, with transitions designed so that the detector efficiently handles overlaps without redundant states. The output sequence_detected will be a combinational signal asserted high whenever the last input bit completes the sequence "1001".

This binary encoding reduces flip-flop count and combinational logic complexity compared to one-hot. The FSM transitions and output will be synchronous to clk with a synchronous active-low reset (reset_n). The output will be asserted for one cycle exactly when the sequence is detected, based on the current state and input bit.

This approach optimizes area and power while maintaining clear FSM logic and fast detection.
