Refactor the sequence detector FSM to use binary-encoded states instead of one-hot encoding. This reduces the state register width from 5 to 3 bits. The next state logic is implemented with a combinational always block, but the output `sequence_detected` is generated using a continuous assignment (assign) for a clear Moore output style. The reset is still asynchronous active-low, but the FSM is coded with a single always block handling both state updates and asynchronous reset. This approach reduces state bits and uses a binary encoding while maintaining the same FSM behavior and overlapping detection.
