I will refactor the sequence detector FSM by using a binary-encoded state machine instead of one-hot encoding to reduce the number of flip-flops. This involves defining state parameters as binary values, encoding states with fewer bits, and using combinational logic in an always_comb block for next-state and output calculations. The output `sequence_detected` will be asserted high for one clock cycle when the FSM reaches the final detection state. I will use synchronous active-low reset (`reset_n`) to initialize the state machine to IDLE. This structure can be easier to understand and is commonly used for compact FSM implementations.
