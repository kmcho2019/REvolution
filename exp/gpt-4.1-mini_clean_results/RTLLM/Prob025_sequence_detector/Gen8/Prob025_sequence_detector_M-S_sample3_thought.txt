Implement a Moore FSM with five clearly defined states: IDLE, S1, S2, S3, and S4. Each state corresponds to the number of matched bits of the target sequence "1001". On each clock edge, the FSM transitions synchronously based on the input bit and current state. The output `sequence_detected` is asserted only in the S4 state, making the output synchronous and glitch-free. The reset is active low (`reset_n`), synchronously resetting the FSM to IDLE state. Overlapping sequences are naturally handled by proper state transitions. This approach simplifies the logic, aligns with the problem specification, and ensures stable detection.
