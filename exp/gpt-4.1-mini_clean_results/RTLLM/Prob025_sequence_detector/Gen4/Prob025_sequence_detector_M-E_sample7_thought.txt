Implement the sequence detector FSM using a binary-encoded state machine for minimal state bits. Use a Moore machine design with an output register to assert `sequence_detected` for one clock cycle when the sequence "1001" is detected. The FSM transitions through states representing the matched prefix of the sequence. The reset is synchronous and active low (`reset_n`), and output is updated on the clock edge together with the state to avoid glitches. The FSM handles overlapping sequences by proper state transitions, e.g., after detection it returns to the appropriate intermediate state rather than just IDLE. This binary-encoded approach minimizes resources compared to one-hot and is straightforward for synthesis, while keeping output timing clear and stable.
