Implement the sequence detector using a Mealy FSM with 5 states and explicit state encoding. Instead of only tracking matched bits, use the current state to represent how many bits have matched in sequence "1001". The FSM transitions on each clock cycle depending on data_in, possibly reusing partial matches to enable overlapping detection without backtracking. The output sequence_detected is asserted combinationally when the last bit of the sequence is matched (in a Mealy manner), allowing immediate detection in the same cycle as receiving the final bit. Reset is synchronous active low (`reset_n`), clearing the state to IDLE. This approach may reduce output latency by leveraging Mealy output and avoids registering the output, which can be helpful in some designs.
