To simplify the sequence detector FSM for the "1001" sequence while maintaining functionality, I will:

- Use a more compact 3-bit state encoding with just IDLE, S1, S2, and S3 states.
- Implement next state logic directly in a combinational always block with straightforward conditions.
- Generate the output `sequence_detected` combinationally from the current state and input to avoid an additional register stage.
- Retain a synchronous active-low reset for clean initialization.
  
This reduces the number of always blocks and removes the registered output stage, resulting in cleaner and simpler code with the same behavior.
