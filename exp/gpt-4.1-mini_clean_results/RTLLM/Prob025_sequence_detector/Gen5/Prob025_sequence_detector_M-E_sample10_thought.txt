To detect the 4-bit sequence "1001", we can implement a Mealy finite state machine (FSM) with 4 states, each representing how many bits of the sequence have been matched so far. Unlike the previous approach with 5 states, this FSM uses minimal states by encoding only the sequence progress.

The states:

- S0: No bits matched yet.
- S1: Matched '1'
- S2: Matched '10'
- S3: Matched '100'

Transitions depend on the current input bit, and the output signal `sequence_detected` is asserted combinationally (Mealy style) when the input bit completes the sequence (i.e., transitions from S3 to S1 on input '1').

We use synchronous active-low reset to initialize the state to S0.

This architecture supports overlapping sequences naturally (e.g., the last '1' of "1001" can be the first '1' of a new sequence).

The output `sequence_detected` is combinational and asserted exactly when the sequence "1001" is detected at the current input.

The implementation avoids typedef enums for better compatibility and uses parameter-based state encoding and a Mealy FSM style for immediate output assertion.
