Implement the sequence detector using a Moore finite state machine with one-hot encoding for the states to simplify next-state logic and enhance timing performance in FPGA implementations. Each state corresponds to one bit in a state register, enabling quick decoding and simpler state transitions. The FSM transitions sequentially through states representing partial matches of the sequence "1001". When the final state is reached, the output signal is asserted high for one clock cycle. A synchronous active-high reset initializes the FSM to the IDLE state. By using one-hot encoding, the combinational next-state logic becomes a set of simple AND/OR expressions derived from input bits and current states, improving clarity and speed. The output is registered and driven purely by state signals, ensuring glitch-free assertion.
