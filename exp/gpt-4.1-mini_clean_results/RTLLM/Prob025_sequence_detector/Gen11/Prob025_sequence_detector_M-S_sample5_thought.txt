Implement a simple Moore FSM with five states encoded as binary values to detect the 4-bit sequence "1001". The FSM progresses through states IDLE -> S1 -> S2 -> S3 -> S4 as matching bits are received. On detecting the full sequence in S4, output `sequence_detected` is asserted for one clock cycle. Use synchronous active-low reset (`reset_n`) as specified to initialize the FSM to IDLE. The output depends only on the current state (Moore machine), ensuring clean assertion. Transitions allow overlapping sequences without extra complexity. This approach uses binary encoding instead of one-hot for simplicity, reducing logic size while maintaining clarity and correctness.
