Refactor the FSM to use a one-hot encoded state machine represented as separate state bits instead of enums. Implement the next-state logic combinationally with `assign` statements and update state registers on the clock edge. This approach avoids SystemVerilog typedefs, simplifying tool compatibility. The output `sequence_detected` is driven combinationally based on current state and input to immediately flag detection, and synchronous reset is applied with an active-low reset. This structure clearly separates state encoding, combinational next-state logic, and sequential state update, improving readability and synthesis friendliness while preserving the detection behavior.
