Keep the existing approach of storing the previous value of input 'a' in a register to detect edges. Since the outputs need to be synchronous pulses on the next clock cycle and then return to zero until a new edge appears, directly deriving rise and down as combinational outputs from current and delayed input is already simple and minimal. To simplify further, we can keep the outputs as registered signals updated each clock cycle, explicitly setting them to 1 on an edge and 0 otherwise. This uses two output registers but reduces combinational logic and keeps outputs cleanly synchronous and one-cycle wide.
