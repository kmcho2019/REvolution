A simpler approach is to store the previous value of input "a" in a register and on every clock cycle compare it with the current value. A rising edge occurs if previous "a" was 0 and current "a" is 1; a falling edge occurs if previous "a" was 1 and current "a" is 0. This eliminates the FSM and uses straightforward registers and combinational comparison. Outputs rise and down are set high for one clock cycle when their respective edges are detected and otherwise low, fully synchronized to clk with reset support.
