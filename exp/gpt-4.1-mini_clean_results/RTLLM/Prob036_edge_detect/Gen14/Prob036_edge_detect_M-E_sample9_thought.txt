Instead of using a state machine or explicitly storing the previous state in a separate variable, use a simple two-flip-flop synchronizer chain to sample the input signal "a" on every clock edge. Then detect edges by comparing the latest sampled value with the previous sampled value. The rise signal is asserted when the previous value is 0 and the current value is 1, and the down signal is asserted when the previous value is 1 and the current value is 0. Both rise and down outputs are registered and asserted for exactly one clock cycle synchronized to clk. This approach is simple, robust, and clean, avoiding any explicit FSM and using minimal registers.
