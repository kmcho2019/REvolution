Use a single register to store the previous value of input 'a' for edge detection. On each positive clock edge, compare the current 'a' with the previous value to detect rising (0->1) and falling (1->0) edges. When a rising edge is detected, set the output 'rise' to 1 and keep it high until the next rising edge appears, which clears it back to 0. Similarly for 'down' on falling edges. This behavior can be implemented by toggling a latch on each detected edge and driving the output from that latch. Reset initializes all registers to zero.
