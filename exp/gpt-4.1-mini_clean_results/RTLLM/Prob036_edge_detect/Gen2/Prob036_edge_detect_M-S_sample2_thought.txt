Use a single flip-flop to store the previous value of input 'a', then on each clock edge compare the current input with the stored previous value to detect edges. Generate the rise and down signals as one-cycle pulses immediately following the detected edge, avoiding a multi-stage synchronizer since 'a' is slowly changing (assuming it is synchronous or stable with respect to clk).
