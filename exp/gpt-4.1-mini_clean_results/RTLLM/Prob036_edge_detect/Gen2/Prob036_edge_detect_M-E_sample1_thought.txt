Instead of storing the previous input and comparing it directly to detect edges, I will implement a small state machine with two states reflecting the last sampled value of 'a'. The state machine transitions between states when 'a' changes and flags the detected edge on the output signals. The outputs 'rise' and 'down' will be asserted for exactly one clock cycle on the next clock after detecting the corresponding edge. This approach separates edge detection from input sampling explicitly via states, making the design conceptually clearer and easy to extend for more complex edge conditions or filtering if needed.
