Refactor the edge detection by registering the rise and down signals explicitly as flip-flops, rather than using continuous assignments. Keep the previous value of 'a' in a register, compare it with the current 'a' inside the always block on clock edge, and update rise and down registers accordingly. This ensures rise and down outputs are synchronous registered pulses that go high for exactly one clock cycle when an edge is detected, then go low until the next edge. This approach still uses minimal logic but expresses the outputs as registered signals, which can be beneficial for timing and glitch reduction in some design flows.
