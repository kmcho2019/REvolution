Combine the simplicity and minimal register usage of Example 1 with the fully registered, glitch-free outputs of Example 2 to achieve both minimal logic and stable, synchronous outputs. 

Specifically, register the previous input signal "a" as in Example 1 to detect edges via comparison, but instead of driving rise and down signals combinationally, register these outputs. On the clock following the detected edge, set rise or down to 1 for exactly one clock cycle, then automatically clear them. This approach ensures that outputs are synchronous pulses without glitches, suitable for downstream logic, while maintaining a minimal number of registers and simple logic for edge detection.

The design:
- Registers previous input 'a' in a_d.
- On each clock, compare current 'a' with a_d.
- If rising edge detected (a_d=0, a=1), set rise_reg = 1.
- If falling edge detected (a_d=1, a=0), set down_reg = 1.
- After being set, rise_reg and down_reg are cleared on the next clock cycle unless a new edge is detected.
- All outputs are registered, synchronized with clk.
- Asynchronous active-low reset clears registers.

This fusion strategy provides reliable one-clock-cycle pulses on rise and down, synchronous to clk, leveraging minimal extra logic beyond the original single delayed register.
