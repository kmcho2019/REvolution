A simpler approach is to register the input signal "a" on each clock cycle and compare it with its previous value to detect edges. If the previous value was 0 and the current is 1, that's a rising edge; if the previous was 1 and current is 0, that's a falling edge. The outputs rise and down are asserted for exactly one clock cycle immediately after the edge is detected. This eliminates the FSM and uses only a single register for the previous state, making the design minimal, clean, and efficient.
