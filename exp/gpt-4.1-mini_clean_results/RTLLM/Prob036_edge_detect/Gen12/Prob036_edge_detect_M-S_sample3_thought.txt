A simpler approach to edge detection is to store the previous value of input "a" in a register and compare it to the current "a" on each clock edge. If the previous value is 0 and current is 1, it's a rising edge; if previous is 1 and current is 0, it's a falling edge. Then, set the corresponding output signals rise or down to 1 for one clock cycle after detecting the edge, else 0. This approach requires only one flip-flop to store the previous state and straightforward combinational comparison logic, reducing complexity while ensuring synchronous, glitch-free outputs.
