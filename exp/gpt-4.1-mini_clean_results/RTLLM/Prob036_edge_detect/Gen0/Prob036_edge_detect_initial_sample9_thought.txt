To detect edges of a signal 'a' synchronized with clock 'clk', we store the previous value of 'a' in a register 'a_d'. On each clock, if 'a' transitions from 0 to 1, we set 'rise' to 1 for one clock cycle, and similarly if 'a' transitions from 1 to 0, we set 'down' to 1 for one clock cycle. Both 'rise' and 'down' signals are synchronous to 'clk' and reset asynchronously with active-low reset 'rst_n'.
