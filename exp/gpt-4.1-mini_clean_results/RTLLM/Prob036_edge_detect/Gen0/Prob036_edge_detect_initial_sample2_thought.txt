To detect edges, store the previous value of input 'a' in a register updated at each clock cycle. On each positive clock edge, compare the current 'a' with the previous 'a'. If previous 'a' is 0 and current 'a' is 1, a rising edge is detected; if previous 'a' is 1 and current 'a' is 0, a falling edge is detected. The outputs 'rise' and 'down' are set to 1 for exactly one clock cycle following the detection and cleared afterward. The asynchronous reset (active low) clears previous 'a', 'rise', and 'down' on reset.
