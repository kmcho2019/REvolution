To detect edges on the input signal 'a', we need to store the previous value of 'a' at each clock cycle. On the next clock, if the previous value was 0 and current is 1, it's a rising edge, so we set 'rise' to 1 for one clock cycle. If the previous value was 1 and current is 0, it's a falling edge, so we set 'down' to 1 for one clock cycle. Both 'rise' and 'down' should be 1 only for one clock cycle following the detection. Using a synchronous process sensitive to clk and asynchronous reset (active low) to implement this.

Key steps:
- Register previous value of 'a'.
- On each clock, compare previous and current 'a' to generate rise or down.
- Use an always block sensitive to clk and rst_n.
- Output signals are pulsed high for one clock cycle on the detected edges.
