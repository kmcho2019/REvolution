To detect edges on signal 'a', store its previous value in a register. On each positive clock edge, compare the current 'a' with the stored previous value. If previous is 0 and current is 1, set 'rise' to 1 for one clock cycle; if previous is 1 and current is 0, set 'down' to 1 for one clock cycle. Both 'rise' and 'down' outputs are synchronous to clk and reset on rst_n. This way, the edge indication signals pulse high for exactly one clock cycle following the detected edge.
