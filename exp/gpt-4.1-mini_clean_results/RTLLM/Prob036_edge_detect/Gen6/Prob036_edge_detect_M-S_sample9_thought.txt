Use a single flip-flop to store the previous state of 'a' on each clock edge, then compare the current 'a' with the stored previous value to detect rising and falling edges. This eliminates the need for a two-flip-flop synchronizer assuming 'a' is already clock-domain aligned or changing slowly, as specified. The outputs 'rise' and 'down' are registered signals set to 1 on the clock cycle after the edge detection and cleared in the next cycle, fulfilling the requirement to hold until the next edge appears. This reduces complexity by removing the synchronizer stage and uses simple sequential logic to store outputs.
