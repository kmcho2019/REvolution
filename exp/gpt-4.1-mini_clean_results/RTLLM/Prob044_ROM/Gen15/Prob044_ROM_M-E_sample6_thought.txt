Implement the ROM with a combinational read using a continuous assignment to dout from a combinational function that returns the data corresponding to the input address. This approach avoids using an always block or a reg type output by making dout a wire driven by a function that implements a case statement for known initialized addresses and defaults others to zero. This method is clear, synthesizable, and enables the synthesis tool to infer ROM content directly from the case statement without the need for explicit memory declaration. This can be advantageous for small ROMs or when you want explicit control of the mapping without large memory arrays.
