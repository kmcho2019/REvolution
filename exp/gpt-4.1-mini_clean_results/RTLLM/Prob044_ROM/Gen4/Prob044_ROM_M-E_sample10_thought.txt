To implement the ROM without using a reg array and an always block, use a function that returns the constant data for each address. This approach stores the ROM contents as a case statement inside a pure combinational function, enabling direct combinational assignment of dout from the function output. This method can improve area and timing by inferring ROM as combinational logic or optimized multiplexers rather than a large reg array. It is also clean and easy to scale by adding more case entries. The uninitialized addresses return zero by default.
