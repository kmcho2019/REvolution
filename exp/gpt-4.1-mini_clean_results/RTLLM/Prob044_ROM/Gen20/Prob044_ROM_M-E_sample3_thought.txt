Implement the ROM as a function inside the module instead of using a memory array. The function takes the address as input and returns the corresponding 16-bit data. The function will be called combinationally in an assign statement to drive the output. This approach avoids using a memory array, which can be beneficial for very small ROMs or when the data is sparse and explicitly known at design time. The function can be easily extended to cover all 256 addresses by either a large case statement or a default value for addresses not explicitly listed. This also makes the ROM content completely synthesizable as combinational logic with no inferred memory blocks, potentially reducing area in some technologies.
