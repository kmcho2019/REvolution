Implement the ROM as a pure combinational logic with a case statement instead of an array lookup. This approach uses a combinational always block that outputs a constant data word based on the input address using a large case statement, encoding only the initialized locations explicitly and defaulting the rest to zero. This eliminates the need for a memory array and initial block, making the design fully combinational and potentially more suitable for small ROM contents or tools that optimize large case statements into ROM primitives or LUTs. It also guarantees fully defined outputs for all addresses without undefined contents.
