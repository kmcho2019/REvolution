To provide a distinct architectural approach, implement the ROM as a purely combinational logic using a case statement inside a combinational always block rather than using a memory array. This approach explicitly enumerates the output for each address. While less scalable for large ROMs, it clearly shows the read-only data mappings and avoids using an initialized memory array. This method is synthesizable for small ROMs and infers combinational logic. It also makes the ROM content easy to visualize and modify without an initialization block. Unspecified addresses default to zero. This approach may lead to larger combinational logic but clearly demonstrates ROM behavior without memory arrays.
