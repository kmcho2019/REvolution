To improve the original ROM module for better PPA, I will implement a synchronous read design with a clock input and registered output. Synchronous reads often yield better maximum frequency and timing closure on FPGAs due to predictable memory access patterns. I will also add a clock enable input to gate reads, reducing unnecessary toggling and saving power. The memory will still be initialized in the initial block. Using a synchronous read interface better leverages block RAM primitives and reduces combinational path delay. This balances performance, power, and area optimally.
