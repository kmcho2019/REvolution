Implement the ROM as a parameterized memory module using a function to encapsulate the ROM contents. The function rom_data takes an address as input and returns the corresponding 16-bit data constant. This approach eliminates the need for an explicit memory array and initialization block by representing the ROM contents as a combinational function. The output is assigned continuously from the function result. This method is fully synthesizable and may allow synthesis tools to optimize ROM contents more efficiently. The memory size and contents can be easily expanded by modifying the function's case statement.
