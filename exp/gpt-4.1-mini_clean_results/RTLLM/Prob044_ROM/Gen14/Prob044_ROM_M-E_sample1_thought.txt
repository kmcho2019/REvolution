Implement the ROM using a combinational function that encapsulates the address decoding and data output instead of an array-based memory. This function maps each address to its corresponding data value using a case statement, which explicitly defines the stored values for addresses 0 to 3 and outputs zero for all other addresses. This approach saves memory initialization and infers a purely combinational logic block, which can lead to simpler logic synthesis and potentially faster reads without explicit RAM inference. It is especially suitable when only a few addresses hold meaningful data. The dout output is assigned continuously from this function, ensuring combinational read-only behavior.
