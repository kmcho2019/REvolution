Implement the ROM using a combinational function that maps the 8-bit address to the corresponding 16-bit data using a case statement instead of a memory array.  
This approach eliminates the need for a reg array and initial block, reducing area and potentially improving synthesis by inferring a ROM as logic rather than block RAM.  
Since only a few addresses are explicitly defined, this sparse ROM implementation is compact and fast.  
It is purely combinational and synthesizable, providing an alternative architecture that explicitly defines data outputs per address, which can be easier to optimize for some synthesis tools.
