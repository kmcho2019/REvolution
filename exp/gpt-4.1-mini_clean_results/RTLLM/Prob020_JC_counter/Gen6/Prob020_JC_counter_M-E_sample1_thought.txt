Instead of directly shifting and inserting the negation of Q[0], the Johnson counter can be modeled as a rotating shift register where the next input bit is explicitly decided based on the current pattern's lowest bit. Here, we implement the logic so that on each clock edge, the register shifts right by one bit, and the new MSB is set to Q[0] XOR 1 (which is equivalent to inserting the inverse of Q[0]). We implement this using a combinational signal for next state calculation before registering it on the clock edge. This makes the logic explicit and allows easier extension or modification in future.
