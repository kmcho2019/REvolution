To refactor the Johnson counter implementation while preserving the core logic, we can separate the combinational next state logic from the sequential state update logic. Instead of directly updating Q within an always block, define a wire for the next state value based on the current Q. Then update Q with this next state in a synchronous always block triggered by clk and rst_n. This improves code clarity by making next state computation explicit and aligns with common FSM design patterns. The asynchronous reset remains as specified.
