A Johnson counter is effectively a shift register where the new MSB is the inverse of the current LSB. The previous design used an explicit wire for the next MSB and a concatenation for the next state, which is clean but slightly verbose.

To simplify, we can directly assign Q in the always block by shifting right and inserting the inverted LSB at the MSB without intermediate wires. This reduces code lines and keeps functionality identical.

The asynchronous active-low reset behavior is maintained, and the logic remains purely synchronous with asynchronous reset, which is standard.

This version minimizes code complexity without changing the behavior, which meets the requirement to simplify while preserving functionality.
