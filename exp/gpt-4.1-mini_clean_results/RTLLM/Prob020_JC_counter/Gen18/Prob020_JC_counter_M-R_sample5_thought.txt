Refactor the Johnson counter to use a combinational next-state logic via an intermediate wire and a synchronous register update. Instead of directly assigning Q within the always block with concatenation, compute the next value of Q in a separate wire 'next_Q' based on the current Q and the feedback logic. Then, update Q on the clock edge or reset condition. This separation can improve code readability and help some synthesis tools optimize the design. The reset logic remains the same, and the Johnson counter sequence behavior is preserved.
