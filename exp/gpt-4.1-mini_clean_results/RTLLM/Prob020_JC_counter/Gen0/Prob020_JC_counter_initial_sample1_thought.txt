Implement a 64-bit Johnson counter that on each clock rising edge (or reset falling edge) updates the 64-bit register Q as follows:
- On reset (active-low), Q is set to 0.
- Otherwise, if Q[0] is 0, shift Q right by 1 bit and insert 1 at the MSB (Q[63]).
- If Q[0] is 1, shift Q right by 1 bit and insert 0 at the MSB.
This effectively produces the Johnson counting pattern extended to 64 bits.
