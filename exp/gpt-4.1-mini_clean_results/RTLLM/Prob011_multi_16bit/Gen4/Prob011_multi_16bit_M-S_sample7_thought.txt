Implement a basic shift-and-add multiplier with minimal control logic by directly using a 16-bit counter for iterations and a register pair for the multiplicand and multiplier. On start, load inputs into registers and clear the accumulator. For each cycle, check the least significant bit of the multiplicand register; if set, add the multiplier (appropriately shifted) to the accumulator. Then shift the multiplicand right and multiplier left by one bit. The done signal is asserted when the counter reaches 16, indicating multiplication is complete. Reset logic clears registers and flags on active-low reset or when start is inactive. This approach reduces complexity by avoiding multiple done flag states and separate registers for shifted multiplier extension, keeping the shift count and control straightforward.
