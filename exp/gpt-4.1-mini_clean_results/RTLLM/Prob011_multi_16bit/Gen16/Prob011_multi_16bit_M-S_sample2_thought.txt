Implement the 16-bit unsigned multiplier with a simple shift-and-add approach using a single shift counter (i) from 0 to 16.

- On reset, clear all registers and flags.
- When start is asserted, load multiplicand (areg) and multiplier (breg) registers and clear the product register (yout_r).
- For i from 1 to 16, check the (i-1)th bit of areg; if set, add (breg shifted left by i-1) to yout_r.
- Increment i each clock cycle while start is active.
- When i reaches 16, set done flag high for one cycle.
- When i is 17, clear done and i, waiting for next start.
- Use synchronous logic triggered on posedge clk or negedge rst_n.
- This approach avoids FSM, using straightforward counters and combinational bit checks for addition.
- Use simple registers for inputs and outputs, maintaining clean and concise code.
