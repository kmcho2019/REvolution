Implement a straightforward shift-and-accumulate multiplier using a shift count register `i` (0 to 16) to control the operation. On `start`, load the multiplicand and multiplier into registers. Each clock cycle, check the current bit of the multiplicand; if it's 1, accumulate the shifted multiplier in the product register. Increment `i` each cycle until 16 bits are processed. The done signal is asserted when `i` reaches 16. Use synchronous logic with asynchronous active-low reset. This approach keeps the logic minimal and matches the requested control signals and functionality exactly.
