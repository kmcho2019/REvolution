Implement a straightforward shift-and-add multiplier using a single 5-bit counter to track progress. On reset or idle (no start), clear all registers. When start is asserted, load the multiplicand and multiplier into registers. Each clock cycle, check the least significant bit of the multiplier register: if it is 1, add the multiplicand to the accumulator. Then shift the multiplier right by one bit and shift the accumulator left by one bit (or equivalently shift the combined partial sum and multiplier) to prepare for the next bit. After processing all 16 bits, assert done for one cycle. This approach uses minimal state and control logic and maintains clear functionality.
