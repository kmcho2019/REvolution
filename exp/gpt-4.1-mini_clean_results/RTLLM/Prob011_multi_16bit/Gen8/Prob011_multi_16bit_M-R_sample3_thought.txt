Refactor the design by introducing a simple finite state machine (FSM) with three states: IDLE, RUN, and DONE. The FSM controls the multiplication sequence more explicitly. The shift count, registers, and done flag updates happen synchronously in the RUN state. Use combinational logic to decode the FSM state and control signals, and separate the registers to update only when enabled. This structure improves readability and clearly separates control and datapath. Instead of tightly coupling counter increment with start, the FSM controls the start and done transitions. The core shift-and-add operation remains unchanged.
