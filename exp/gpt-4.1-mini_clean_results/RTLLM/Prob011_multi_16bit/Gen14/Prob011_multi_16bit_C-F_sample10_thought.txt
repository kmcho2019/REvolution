Fuse the strengths of both designs by combining clear, simple control logic from the count-based design (Example 2) with the optimized shift-and-add update and start/reset handling from the FSM-based design (Example 1).

Key improvements:
1. Use a 5-bit shift count as the main controller without explicit FSM states, simplifying logic and easing synthesis.
2. Store multiplicand and multiplier at start; maintain product register holding accumulator in upper half and multiplier bits in lower half.
3. On each cycle, conditionally add shifted multiplicand only if LSB of multiplier is 1, then shift right by 1.
4. Generate done flag exactly at count 16 and keep it asserted until reset or new start.
5. Reset all registers synchronously on rst_n low.
6. Implement clock enable gating by updating product register only during multiplication (count in 1 to 16) to reduce power.
7. Use non-blocking assignments consistently and clearly separate data path and control signals.
8. Output done combinationally from done register and yout from product register.

This approach yields a compact, power-aware design with clean, maintainable code and no explicit FSM states, combining clarity and efficiency.
