I will implement a 16-bit unsigned multiplier using a shift-and-add approach controlled by a simple FSM with three states: IDLE, BUSY, DONE. Instead of shifting both multiplicand and multiplier registers every cycle, I'll only shift the multiplier register right each cycle and use the LSB of the multiplier to decide whether to add the multiplicand (properly shifted) to the accumulating product.

The multiplicand will be stored once at the start in a 32-bit register aligned to the left, avoiding shifting it every cycle. The product register accumulates partial sums.

The shift count register counts from 0 to 16 for 16 bits processed.

Control signals:
- When start is asserted and the FSM is in IDLE, load registers and move to BUSY state.
- On every clock in BUSY, check multiplier LSB; if 1 add shifted multiplicand to product.
- Shift multiplier right by 1 each cycle.
- When count reaches 16, assert done flag and move to DONE state.
- Waiting for start to be deasserted moves back to IDLE.

This FSM-based design simplifies control, avoids multiple register shifts, and clearly separates operational phases. The done flag is asserted for one cycle.

This approach is straightforward and easy to verify, and may be better for power by avoiding unnecessary shifting of multiplicand each cycle.
