Refactor the design by implementing a simple finite state machine (FSM) with two states: IDLE and BUSY. The FSM manages the multiplication process step-by-step, making control clearer and modular. The multiplication is performed over 16 cycles, shifting and accumulating bits of the multiplicand one at a time.

Key changes:
1. Use an FSM for start/done control, which improves clarity and control flow.
2. Hold multiplicand, multiplier, and accumulator in registers updated every clock cycle during BUSY state.
3. Instead of separate counters and done flag logic, state transitions manage these signals, simplifying control.
4. Avoid multiple nested conditions inside a single always block by splitting them logically.
5. Use explicit combinational logic for next state and output signals, improving readability and synthesis friendliness.

This approach preserves the core shift-and-accumulate multiplication logic but structures the control more cleanly, which may help in debugging and future modifications.
