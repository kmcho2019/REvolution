Implement a shift-and-accumulate 16-bit unsigned multiplier using a simple counter `i` for the current bit position from 0 to 16. On reset or when `start` is low, reset all registers and counter. When `start` is asserted, load multiplicand and multiplier into registers and increment the bit counter each clock. For each bit position `i` (1 to 16), if the corresponding bit of `areg` (multiplicand) is 1, add `breg` shifted left by `i-1` to the accumulator `yout_r`. Set `done` when counting reaches 16, reset done at 17, and reset count at 0. This approach directly implements the problem description without extra FSM states or packing multiplicand and multiplier into one register, simplifying control logic and keeping registers and operations straightforward.
