Implement a sequential multiplier using shift and accumulate. Use a register 'i' to count the bits processed. On reset, clear all registers. When start is asserted, load inputs into registers and proceed through 16 cycles. Each cycle checks the bit of 'areg' at position i-1; if set, adds 'breg' shifted by i-1 to the product register. Set done flag when i reaches 16, clear at 17. Output the product register.
