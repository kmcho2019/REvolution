Implement a sequential 16-bit multiplier using shift-and-accumulate approach. Use a 5-bit counter to track the current bit index for multiplication steps. On reset, clear all registers. When start is asserted, load multiplicand and multiplier into registers. On each clock cycle while counting from 1 to 16, check if the corresponding bit of multiplicand is 1, if so add the shifted multiplier to the accumulator. After 16 cycles, set done flag. Clear the done flag on the 17th cycle. Output the accumulator as the product.
