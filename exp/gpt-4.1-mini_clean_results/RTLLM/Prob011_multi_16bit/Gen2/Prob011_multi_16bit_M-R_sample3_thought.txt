Refactor the design by implementing an explicit finite state machine (FSM) with three states: IDLE, RUN, and DONE. On start, load inputs and begin processing bits one by one each clock cycle in RUN state. Use combinational logic to decide whether to add the shifted multiplier to the accumulator based on the current bit of the multiplicand. Once all bits are processed, transition to DONE, assert done flag, then return to IDLE. This approach centralizes control logic, reduces conditional resets, and separates FSM from datapath, improving clarity and maintainability.
