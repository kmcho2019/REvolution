Use a straightforward iterative shift-and-accumulate approach controlled by a 5-bit counter. Load inputs at i=0, then on each cycle (1 to 16), check the least significant bit of the multiplicand register to decide whether to add the shifted multiplier to the accumulator. Shift the multiplicand right and multiplier left each cycle. Reset all registers on reset or when start is deasserted. Generate done flag when i reaches 16. This approach simplifies control logic without separate cases and avoids unnecessary register holds by using default non-blocking assignments.
