Implement the 16-bit unsigned multiplier as an iterative shift-and-add multiplier using a single 16-bit shift register for the multiplier and a 32-bit accumulator for the product.

Instead of shifting both multiplicand and multiplier each cycle, keep the multiplicand constant and shift the multiplier right. On each cycle, if the LSB of the multiplier is 1, add the multiplicand shifted by the current bit position to the accumulator.

Control logic uses a 5-bit counter to track the number of processed bits (0-16). When counter is 0 and start is asserted, load registers. On cycles 1 to 16, process one bit per cycle, shifting the multiplier right each time.

The done flag is asserted when the counter reaches 16, cleared when the counter resets or on reset.

This approach avoids a wide shifter for the multiplicand, reduces shifting complexity, and isolates the adder operation to a fixed multiplicand shifted by bit position, thus simplifying data paths.

The 32-bit accumulator holds the partial sum, updated only when the multiplier bit is 1.

Reset clears all registers. Start must be high to progress multiplication; if start goes low mid-operation, multiplication resets.

Outputs are the final 32-bit product and the done flag.

This design is simple, clear, and resource efficient, with a predictable latency of 16 cycles per multiplication.
