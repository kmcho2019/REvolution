To improve PPA, especially timing and power, revert to the original specification: use two separate 8-bit registers ins_p1 and ins_p2, each capturing instructions from different sources independently. This separation simplifies output logic by directly assigning outputs from the respective registers without extra source state decoding, reducing critical path muxing. Both registers update only when their respective fetch code matches, minimizing unnecessary toggling and power. The reset asynchronously clears both registers. Outputs ins and ad1 derive from ins_p1, ad2 derives from ins_p2, always reflecting the latest loaded values, which simplifies combinational logic and improves timing. This approach increases area slightly but benefits power and timing, achieving a better overall PPA tradeoff.
