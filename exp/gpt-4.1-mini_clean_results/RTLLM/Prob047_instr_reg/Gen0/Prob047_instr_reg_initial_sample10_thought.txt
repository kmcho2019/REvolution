Implement a module named instr_reg with synchronous reset and clock. Use two 8-bit registers ins_p1 and ins_p2 to store instruction inputs conditionally based on fetch signal. When rst is low, clear both registers. On each clock rising edge, if fetch is 2'b01, load data into ins_p1; if fetch is 2'b10, load data into ins_p2; otherwise retain previous values. Outputs ins and ad1 are derived from ins_p1 (high 3 bits for ins and low 5 bits for ad1), and ad2 is assigned directly from ins_p2.
