Implement a single 8-bit instruction register that captures the input data whenever the fetch signal is either 2'b01 or 2'b10. Instead of two separate registers ins_p1 and ins_p2, use one register and a small selector logic to update and route outputs. Store the latest instruction from fetch=01 in a dedicated register (ins_p1), but for fetch=10, store the data directly into ins_p2 as a separate 8-bit register. This minimizes duplicated logic by only using one clocked block for ins_p1 and one for ins_p2 with clear clock enables, and employs a combinational multiplexer for outputs. Reset is synchronous active-low for better timing closure. This architecture centralizes and simplifies state updates and makes outputs and data flow explicit and decoupled, improving maintainability and clarity.
