Use a single 8-bit register to store the instruction and a 1-bit flag to indicate the source: 0 for fetch=2'b01 and 1 for fetch=2'b10. On reset, clear both. On clock edge, if fetch is 2'b01 or 2'b10, update the register and set the flag accordingly. Derive outputs directly based on this flag: if source is 0, output ins and ad1 from the register and zero ad2; if source is 1, output ad2 from the register and zero ins and ad1. This reduces the selector to one bit and simplifies output logic while fulfilling the requirements.
