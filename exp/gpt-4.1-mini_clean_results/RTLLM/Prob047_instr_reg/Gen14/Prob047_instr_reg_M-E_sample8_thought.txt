Implement the instruction register as a single 8-bit register with a 2-bit selector that determines which instruction source updates it. Instead of separate registers ins_p1 and ins_p2, use one main instruction register with an internal state to track the source. When fetch is 2'b01, store data and tag it as source 1; when fetch is 2'b10, store data and tag as source 2. Outputs ins and ad1 come from the stored instruction only if it was fetched from source 1; otherwise they hold zero. The ad2 output always reflects the data if the last fetch was from source 2; otherwise zero. This reduces register usage, combines logic for power saving, and clearly reflects source-dependent outputs without separate registers.
