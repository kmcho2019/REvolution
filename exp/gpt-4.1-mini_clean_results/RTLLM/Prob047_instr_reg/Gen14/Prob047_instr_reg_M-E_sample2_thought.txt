Instead of using two separate 8-bit registers ins_p1 and ins_p2, use a single 8-bit register (instr_reg) to store the currently fetched instruction. Maintain an 8-bit register (src_sel) that remembers the latest fetch source (1 or 2). On each clock edge, if reset is active low, clear both registers. If fetch is 1 or 2, load data into instr_reg and record the fetch source in src_sel. Outputs ins and ad1 are derived from instr_reg only when the last fetch source is 1; otherwise, ins and ad1 are zeroed. The ad2 output shows the instr_reg content only when the last fetch source is 2; otherwise, ad2 is zero. This approach stores only one instruction register and uses a selector register to distinguish the source, simplifying state and output logic while providing clear separation of outputs depending on fetch source.
