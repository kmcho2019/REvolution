Implement a single 8-bit instruction register with an internal 2-bit state machine to track the source of the loaded instruction. On each positive clock edge, if reset is asserted (active low), reset the internal register and state. Otherwise, load the instruction from `data` only when `fetch` is either 2'b01 or 2'b10, and update the state accordingly. The outputs `ins` and `ad1` are derived from the instruction when fetched from the first source (fetch=01), while `ad2` outputs the instruction only when fetched from the second source (fetch=10); otherwise, `ad2` is zero. This approach uses a combined register and state to keep track of source and data, simplifying storage and avoiding two separate registers, which may reduce area and power while maintaining clear separation of output fields based on fetch state.
