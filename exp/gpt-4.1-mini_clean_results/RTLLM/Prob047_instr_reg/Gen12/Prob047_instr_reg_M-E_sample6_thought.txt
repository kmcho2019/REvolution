Use two separate 8-bit registers ins_p1 and ins_p2 to store instructions fetched from different sources as specified (fetch=01 and fetch=10). On reset (active low), both registers are cleared. On each rising clock edge, update ins_p1 if fetch is 01, and ins_p2 if fetch is 10, otherwise hold values. Outputs ins and ad1 always come from ins_p1 since it holds the main instruction (from register source), while ad2 always outputs the full 8-bit value stored in ins_p2 (from RAM/ROM source). This design cleanly separates the two instruction sources physically and logically, simplifying output assignment and enabling straightforward debugging and extension. It also avoids extra state variables and is fully synchronous with minimal combinational logic.
