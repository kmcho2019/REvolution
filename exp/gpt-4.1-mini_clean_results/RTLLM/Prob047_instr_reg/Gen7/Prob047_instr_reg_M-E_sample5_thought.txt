Implement the instruction register using synchronous reset and a single clocked always block that uses a decoded fetch enable signal to update only the relevant register. Instead of two separate registers, use a small state machine to select and latch incoming data into a common 8-bit register and a valid flag per source, enabling output multiplexing. Outputs ins and ad1 decode from the latched data only if ins_p1 is valid, otherwise they remain zero; ad2 outputs ins_p2 data only if valid. This approach consolidates control flow, allows efficient gating, and eases debugging by using validity bits. It also avoids asynchronous resets, promoting better synthesis and timing closure.
