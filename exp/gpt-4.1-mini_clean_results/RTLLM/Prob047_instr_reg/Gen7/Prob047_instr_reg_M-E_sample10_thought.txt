Implement the instruction register using two always blocks: one with synchronous active-low reset to independently update ins_p1 and ins_p2 registers based on the fetch signal. This modularizes control flow and separates data paths, which can help in timing closure and debugging. Using synchronous reset ensures reset behavior is aligned with the clock, enhancing timing predictability. Each always block updates one register only if its corresponding fetch signal is active, otherwise holds its previous state. Outputs ins and ad1 are derived from ins_p1, and ad2 from ins_p2, assigned continuously outside the always blocks. This design favors modular register update and synchronous reset style, providing a clear structure and potentially better integration with synchronous design flows.
