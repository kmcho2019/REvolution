Implement a single always block synchronous design with a synchronous active-low reset. Use a 2-bit register to hold the fetch state from the previous cycle, enabling instruction updates only when the fetch matches the expected pattern to avoid glitches. Store both instructions in a single 16-bit register (ins_packed), splitting it logically into two 8-bit halves for ins_p1 and ins_p2. This saves area by using one register variable and simplifies the code. Outputs are decoded from ins_packed accordingly. This method improves power efficiency by updating registers only on valid fetch and reduces area by consolidating storage.
