Use a synchronous active-low reset and implement a single always block that updates a combined 16-bit register holding both instructions (ins_p1 and ins_p2) as adjacent fields. This minimizes register count by packing both instructions into one register, potentially improving area. On reset, clear the entire combined register. On fetch==2'b01 or 2'b10, update only the respective 8-bit half (upper or lower), retaining the other half by masking and merging with the new data. The outputs are derived by splitting this combined register. This packing approach reduces register count and provides clear logic separation, while synchronous reset simplifies timing closure. The selective update logic uses bit masking within the single register write operation for efficient hardware implementation.
