Implement the instr_reg module using a single synchronous always block with a synchronous active-low reset. Use an internal 2-bit state register to remember which instruction register was last updated, and update only the targeted register based on fetch. Instead of holding both registers with independent always blocks, this approach consolidates logic, improving resource sharing. The outputs extract fields dynamically from ins_p1 and ins_p2 as per requirement. This design also includes an enable signal derived from fetch to avoid unnecessary register updates, minimizing switching activity.
