Use a single 8-bit register with a one-hot encoding inside to track which instruction source was last loaded, avoiding two separate registers. On each clock, if rst is low, clear the register and source indicator. If fetch is 01, load data into the register and set source indicator to 1; if fetch is 10, load data and set source indicator to 2; else retain previous. Outputs ins and ad1 are derived only when the source indicator is 1 (instruction from first source), otherwise zeroed. The output ad2 is assigned as the register content if the source is 2, else zero. This approach saves area by using a single register with control logic, and clearly differentiates outputs based on instruction source.
