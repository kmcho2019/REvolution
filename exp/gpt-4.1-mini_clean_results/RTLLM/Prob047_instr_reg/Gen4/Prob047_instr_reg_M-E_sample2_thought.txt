Use a single 8-bit register 'instr_reg' to hold the last loaded instruction regardless of source. To differentiate which source's data is currently valid, store a 1-bit flag 'source_sel' that remembers whether the instruction was loaded from source 1 (register) or source 2 (RAM/ROM). On reset, clear both. On each clock edge, if fetch == 2'b01 or 2'b10, update the instruction register with data and set source_sel accordingly. Outputs ins and ad1 derive from instr_reg only if source_sel indicates source 1; otherwise, ins and ad1 are zero. Output ad2 outputs instr_reg only if source_sel indicates source 2; otherwise, ad2 is zero. This approach reduces storage to a single register and uses a flag to track instruction source, simplifying the design and providing explicit indication of which source's instruction is currently held.
