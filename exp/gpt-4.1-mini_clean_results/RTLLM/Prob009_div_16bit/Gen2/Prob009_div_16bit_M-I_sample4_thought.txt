Implement a fully combinational divider module that performs a bit-serial division similar to a restoring divider algorithm adapted for combinational logic. Use two registers a_reg and b_reg updated combinationally with inputs A and B respectively. Maintain remainder and quotient registers updated in a second combinational always block. At each iteration from the highest bit to the lowest, concatenate the current remainder with the next dividend bit, extract the upper bits equal to divisor width for comparison. If the extracted bits are greater or equal than the divisor, subtract divisor from them and set the corresponding quotient bit to 1, otherwise 0. Update remainder accordingly by combining the subtraction result with the lower bits of the previous concatenation. Assign final quotient and remainder outputs after processing all bits. This strictly follows the problem description and ensures the use of two always blocks as requested.
