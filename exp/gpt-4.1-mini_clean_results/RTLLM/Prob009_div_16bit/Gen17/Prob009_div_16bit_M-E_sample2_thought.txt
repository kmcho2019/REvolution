Implement the 16-bit by 8-bit division in a fully combinational way using two always @* blocks as specified:
1. Use the first always @* block to capture inputs into internal registers a_reg and b_reg.
2. Use the second always @* block to perform the division algorithm iteratively inside a for loop:
   - Initialize remainder with the top 8 bits of a_reg.
   - For each bit from the 9th bit down to LSB in a_reg, concatenate that bit to the current remainder shifted left by 1.
   - Compare remainder with b_reg: if remainder ≥ divisor, set quotient bit to 1, subtract divisor from remainder; else quotient bit = 0.
3. Store the quotient bits into a 16-bit register and remainder into a 16-bit register (although only lower 8 bits of remainder are valid).
4. Assign outputs result and odd from the registers.

This design follows the problem's instructions with two combinational always blocks, mimics the classic restoring division algorithm, and carefully tracks remainder width and bit concatenation. It is distinct from the earlier wire/generate implementation.
