Implement the 16-bit by 8-bit division purely combinationally using two always blocks as requested. The first always block acts as a simple input latch (though combinational) for A and B to registers a_reg and b_reg, ensuring stable inputs inside the module. The second always block performs the division by an iterative process modeled with a for-loop and procedural statements:

- Initialize remainder to zero.
- Iterate from the highest bit of the dividend down to the lowest:
  - Shift remainder left by 1 and bring down the current dividend bit.
  - Compare remainder with divisor (b_reg).
  - If remainder >= divisor, subtract divisor and set the corresponding quotient bit to 1.
  - Otherwise, quotient bit is 0.
  
This mimics the classic restoring division algorithm but done combinationally inside an always block. The quotient bits are built from MSB to LSB during the iteration. This approach respects the requirement of using two always blocks, keeps logic combinational, and is straightforward to understand and verify. The remainder is zero-extended to 16 bits as output "odd". The module handles all bits in the order specified.

This structure should be easy for synthesis tools to infer combinational division logic and meets the problem's style and constraints.
