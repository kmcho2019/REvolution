Implement the division by simulating a sequential long division algorithm fully in combinational logic, but using two separate always blocks as requested. The first always block latches inputs into internal registers (a_reg for dividend, b_reg for divisor) on any change in inputs, preparing stable inputs for the next block. The second always block performs the division by iteratively extracting the top bits of the current remainder aligned with divisor width, comparing with the divisor, setting the current quotient bit accordingly, and updating the remainder by concatenating the subtraction result with the next bit of the dividend. This process is unrolled combinationally with a loop from MSB to LSB to handle all bits of the dividend. The quotient and remainder registers are updated accordingly. This approach closely follows the problem statement, using input latching and an explicit separation of logic across two always blocks.
