Instead of the classic restoring division approach, implement a combinational "non-restoring" style division focusing on the problem description: 

- Start with the upper bits of the dividend matching divisor width (8 bits).
- For each iteration, compare this partial remainder with the divisor.
- If greater or equal, subtract divisor, quotient bit = 1; else quotient bit = 0.
- Then concatenate the subtraction result (or partial remainder if no subtraction) with the next highest dividend bit (from left to right), effectively shifting the partial remainder left by 1 bit and bringing down the next bit.
- Repeat until all 16 dividend bits have been processed.

- Use two always @(*) blocks as requested:
  - The first block simply registers inputs A and B to internal regs a_reg and b_reg combinationally.
  - The second block performs the division in a purely combinational manner.

- Represent the partial remainder as an 8-bit reg.
- In each iteration:
  - Compare partial remainder with divisor.
  - Determine quotient bit.
  - Update partial remainder accordingly.
- Because the divisor is 8-bit, and the partial remainder is 8 bits (matching divisor width), this satisfies the problem's requirement of using the divisor width for partial remainder.

- To extract the "highest remaining 1-bit" after subtraction for concatenation, since the process is iterative, just left shift remainder and bring down the next dividend bit (as a natural operation in division).

- Output quotient is 16 bits, remainder is 16 bits (with only lower 8 bits valid).

This approach strictly follows the problem statement's method of using divisor-width pieces and concatenations, implemented in pure combinational logic with two always blocks, meeting all problem constraints and producing a fully functional design.
