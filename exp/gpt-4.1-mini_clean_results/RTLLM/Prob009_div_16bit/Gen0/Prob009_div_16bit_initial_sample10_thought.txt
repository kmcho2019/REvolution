Implement a combinational 16-bit division by 8-bit divisor using shift-subtract method. First, latch inputs A and B into registers a_reg and b_reg in an always_comb block. Then in another always_comb block, initialize quotient and remainder variables and iterate from the highest bit of A down to 0, shifting remainder and bringing down bits from A. At each iteration, compare the upper bits of the current remainder with divisor b_reg: if remainder >= b_reg, subtract b_reg from remainder and set quotient bit to 1; else set quotient bit to 0. This process replicates the restoring division approach in combinational logic with two always blocks as requested.
