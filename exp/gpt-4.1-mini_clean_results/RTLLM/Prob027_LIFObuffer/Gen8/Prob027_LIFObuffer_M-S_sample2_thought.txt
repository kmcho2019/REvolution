Use a straightforward synchronous reset to initialize the stack memory and stack pointer in a single always block. Use a 2-bit stack pointer since DEPTH=4. On push (RW=0), if not full, store data and increment SP; on pop (RW=1), if not empty, decrement SP and output popped data. Flags EMPTY and FULL are combinationally derived from SP. Clearing stack memory on reset is done in a simple loop inside the always block, reducing complexity and removing the generate block. This keeps the design clean, functionally equivalent, and simpler.
