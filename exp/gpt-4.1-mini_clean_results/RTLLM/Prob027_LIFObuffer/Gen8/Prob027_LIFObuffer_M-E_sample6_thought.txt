Implement the LIFO buffer with the stack pointer (SP) pointing to the next free slot (empty position), ranging from 0 (empty) to 4 (full). Push operations store data at stack_mem[SP] and increment SP; pop operations decrement SP first, then read data from stack_mem[SP]. This pointer scheme aligns well with unsigned logic avoiding negative indices and simplifies flag generation: EMPTY when SP==0, FULL when SP==4.

The buffer uses synchronous logic for all state changes. On reset, SP is cleared to 0, stack memory zeroed, and dataOut cleared. On a push (RW=0) and if not full, dataIn is written to stack_mem[SP], and SP is incremented. On a pop (RW=1) and if not empty, SP is decremented, then dataOut gets stack_mem[SP]. When EN is low, no operations occur.

This approach decouples push/pop data timing: dataOut is updated only on pop, reflecting the newly popped top item. It also cleanly separates SP update and memory access, making it easy to synthesize with unsigned arithmetic. Flags are simple combinational signals derived from SP. The synchronous reset also zeroes memory for clean initialization. This design improves clarity, avoids signed pointers, and uses the conventional stack pointer convention common in software and hardware stacks.
