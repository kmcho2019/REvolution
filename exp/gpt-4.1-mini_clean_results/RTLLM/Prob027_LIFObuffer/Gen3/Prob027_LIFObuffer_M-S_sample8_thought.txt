Simplify by removing unnecessary internal next-state variables and directly updating registers with nonblocking assignments. Use a 2-bit stack pointer counting down from 4 to 0 to indicate how many entries are occupied (full when SP=4, empty when SP=0). Push decrements SP and writes data at SP-1; pop reads data at SP and increments SP. On reset, initialize SP to 0 (empty) and zero memory. Update EMPTY and FULL flags directly from SP. dataOut updates only on pop. This reduces variable usage and pointer complexity, making the code easier to read and synthesize.
