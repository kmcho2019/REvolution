Implement the LIFO buffer using a stack pointer (SP) that counts upward from 0 to 4, where 0 indicates empty and 4 indicates full. Push operations write data at the current SP index and then increment SP, while pop operations decrement SP and output data at the new SP position. This approach uses SP as the count of stored elements rather than the index of the top element, simplifying boundary checks and making flag generation intuitive: EMPTY when SP=0 and FULL when SP=4. Use a synchronous always block with non-blocking assignments for sequential logic. The dataOut register updates only on pop. On reset, initialize SP to 0 and clear stack memory in parallel. Flags EMPTY and FULL are combinational signals based on SP. This method ensures clear and maintainable code with minimal combinational logic and a straightforward SP scheme.
