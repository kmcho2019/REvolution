This new design will implement the 4-entry, 4-bit wide LIFO buffer as a circular stack indexed by a pointer that counts the number of entries currently stored (count). Instead of decrementing the stack pointer from 4 down to 0, the count will increase on push and decrease on pop, making the logic more intuitive and slightly simpler.

Key ideas:
- Use a count register indicating how many entries are currently stored, ranging from 0 (empty) to 4 (full).
- Use count as the write index for push operations and (count-1) as the read index for pop operations.
- On push (RW=0), if not full, write dataIn to stack_mem at index count, then increment count.
- On pop (RW=1), if not empty, decrement count first and read dataOut from stack_mem at index count-1.
- This approach avoids SP decrements and the tricky pointer arithmetic of the previous design.
- Flags EMPTY and FULL derive directly from count == 0 or count == 4.
- On reset, count set to 0 and stack_mem zeroed.
- All operations occur on the rising clock edge with EN active.
- Memory clearing on pop is not necessary and skipped for lower power.
- dataOut updates only on pop to reduce unnecessary toggling.
This alternative pointer handling improves readability and eases formal verification while keeping the architecture simple and efficient.
