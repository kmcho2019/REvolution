Implement the 4x4-bit LIFO buffer using an explicit 4-entry array (stack_mem) and a 3-bit stack pointer (SP) that points to the next free position. On reset, clear the stack memory and set SP to 0 (empty). On push (RW=0), store dataIn at stack_mem[SP] if not full, then increment SP. On pop (RW=1), decrement SP if not empty, then output stack_mem[SP]. This approach allows direct indexed access without shifting, minimizes power by updating only the accessed memory location, and keeps dataOut registered on pop. EMPTY and FULL flags are combinationally derived from SP. The stack pointer counts from 0 (empty) to 4 (full). This straightforward stack implementation improves timing and power by avoiding wide shifts.
