Implement the LIFObuffer as a circular stack with a top pointer (TP) that points to the current top element index. Instead of counting the number of elements, use TP to index the top entry, and a counter (Count) to track how many elements are stored (0 to 4). On reset, Count is zero (empty), TP is set invalid (e.g., 3'b111). For a push (RW=0), if not full, increment Count, move TP forward modulo 4, and store dataIn at TP. For a pop (RW=1), if not empty, output dataOut from TP, clear that location, decrement Count, and move TP backward modulo 4. EMPTY and FULL flags compare Count to zero and capacity (4). This approach mimics a circular buffer stack, avoids pointer underflow/overflow issues by carefully controlling TP wrap-around, and keeps dataOut synchronized with the last pushed item. Clearing popped locations helps debugging and may reduce glitches. The pointer arithmetic is modulo 4, keeping the logic simple and consistent.
