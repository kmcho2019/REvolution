Refactor the original design to separate the synchronous control logic and memory update logic for clearer structure and to use combinational logic for next state and memory indexing before the clock edge.

Key changes:
1. Use a combinational always block to compute next_SP, push/pop enables, and dataOut_next.
2. Use a sequential always block to update SP, dataOut, and stack_mem synchronously.
3. Represent SP counting upward from 0 (empty) to 4 (full) to simplify address calculation (push at SP, pop from SP-1), removing the subtraction operation.
4. Implement separate push and pop flags combinationally and gate memory writes and dataOut update accordingly.
5. Memory write on push only; read dataOut on pop only.
6. Use synchronous reset to initialize SP and stack_mem.
7. Derive EMPTY and FULL flags combinationally from SP.

This structure separates combinational decision making and synchronous updates, improving readability and potentially timing by avoiding inline arithmetic during clocked assignments.
