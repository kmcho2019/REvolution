Implement the LIFO buffer using a traditional stack pointer that increments on push and decrements on pop, with the stack pointer indicating the number of valid entries in the stack (0 when empty, 4 when full). The stack memory is an array of 4 entries. On write (push), data is stored at the current SP index and SP is incremented. On read (pop), SP is decremented and the output data is taken from the element just popped. Reset initializes SP to 0 and clears stack memory. This approach uses a simple and intuitive stack pointer that counts the number of items, and the empty/full flags are based directly on SP. The dataOut register updates only on pop operation. The stack memory is cleared on reset using a for loop. This design keeps all operations synchronous and cleanly separates push and pop with clear conditions.
