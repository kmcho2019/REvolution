Implement the 4x4 LIFO buffer using a fully synchronous design with a stack pointer (SP) that points to the next free position for push operations. The SP ranges from 0 (empty) up to 4 (full). On push, dataIn is stored at stack_mem[SP], then SP is incremented. On pop, SP is decremented, and dataOut is updated with the value at stack_mem[SP-1]. This approach contrasts with decrementing SP on push. 

This design will:

1. Use synchronous active-high reset to clear memory and set SP to 0 (empty).
2. Use separate push and pop enables derived from RW, EN, and status flags to avoid invalid operations.
3. Only push when not full, pop when not empty.
4. Update dataOut only on pop, holding the last popped data otherwise.
5. Clear stack_mem entries during reset only, no clearing during pop to reduce power.
6. Compute EMPTY and FULL flags combinationally based on SP.
7. Use blocking assignments within a synchronous always block for clarity and correct sequential behavior.
8. Add comments to clarify pointer semantics (SP points to next free slot).
9. Use a 3-bit SP (0 to 4) for easy comparison.
10. Initialize stack_mem to 0 on reset via a for loop.

This "SP-as-next-free" pointer scheme offers a clean intuitive push/pop operation and easy full/empty detection.
