Implement the LIFO buffer using an upward-counting stack pointer where SP points to the next free location for push. On reset, SP is set to zero indicating an empty stack. For push (RW=0), when not full, store dataIn at stack_mem[SP] and increment SP. For pop (RW=1), when not empty, decrement SP and output the value at stack_mem[SP]. EMPTY and FULL flags are combinationally derived from SP (EMPTY when SP=0, FULL when SP=4). dataOut holds the last popped value or retains its value when not popping. Stack memory is initialized during reset with a generate block for clarity and to avoid sequential reset loops. This upward counting SP is more intuitive and clear for future extensions.
