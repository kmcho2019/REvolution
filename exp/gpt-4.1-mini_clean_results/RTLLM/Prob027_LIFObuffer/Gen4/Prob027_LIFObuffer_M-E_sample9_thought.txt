Implement the 4x4-bit LIFO buffer using a small memory array of 4 registers, each 4 bits wide, and a 3-bit stack pointer (SP) that points to the next free location for push or the top element for pop. The stack pointer starts at 0 when empty and increments on push, decrements on pop. On a push (RW=0), if not full, dataIn is stored at stack_mem[SP], and SP increments. On a pop (RW=1), if not empty, SP decrements first, then the data at stack_mem[SP] is read to dataOut, and that memory location is cleared. EMPTY is asserted when SP==0; FULL when SP==4. All updates are synchronous with Clk and gated by EN. On reset, SP and all memory locations are cleared. This indexed memory approach avoids wide shift operations and reduces switching, improving power and timing over shift-register implementations.
