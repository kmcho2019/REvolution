Refactor the LIFO buffer implementation to use a register array to hold the stack entries and a 3-bit stack pointer (SP) indexing the array, avoiding shift registers. On a write (push), if not full, decrement SP and write dataIn into stack_mem[SP-1]. On a read (pop), if not empty, output stack_mem[SP] and increment SP. This approach uses direct indexed memory accesses rather than shifting. Flags EMPTY and FULL are combinationally derived from SP. Also, update dataOut synchronously on pops; on reset, initialize SP to 4 and clear stack_mem. This structure improves timing by avoiding wide shifts and simplifies the logic to indexed memory operations.
