Implement the LIFO buffer using a push pointer (PP) that starts from 0 and increments on each push, and decrements on each pop, with the stack pointer indicating the current number of stored elements. The stack_mem array holds the data entries. On write (push) operations, dataIn is stored at the current PP position, then PP increments if not full. On read (pop), PP decrements if not empty, and dataOut outputs the data from the decremented position. The EMPTY and FULL flags are generated from the PP value (0 means empty, 4 means full). On reset, PP is cleared and memory zeroed. This approach uses an incrementing stack pointer representing the fill count, which simplifies reasoning by treating PP as a count of current entries. The buffer operations occur only when EN is high, with simultaneous push and pop prohibited. DataOut updates only on pop, otherwise holding its value. The stack_mem is cleared synchronously during reset using unrolled assignments for clarity and timing.
