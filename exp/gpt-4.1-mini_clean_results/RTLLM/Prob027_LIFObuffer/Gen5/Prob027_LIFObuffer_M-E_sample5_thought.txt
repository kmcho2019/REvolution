Implement the LIFO buffer using a conventional upward-counting stack pointer (SP) starting at 0 for empty and incrementing on push. The buffer array holds 4 entries indexed by SP. On push (RW=0), if not full, dataIn is stored at stack_mem[SP], then SP increments. On pop (RW=1), if not empty, SP decrements first, and dataOut is set from stack_mem[SP-1]. This approach treats SP as the count of stored elements, making FULL when SP=4 and EMPTY when SP=0. The dataOut register updates only on pop. The stack memory is not cleared on pop to save toggling, but on reset, the entire stack is cleared synchronously. Flags FULL and EMPTY are combinational based on SP. The reset clears SP and stack memory to zero. EN gates all operations. This design is intuitive and simplifies push/pop pointer logic compared to decrementing SP, improving readability and maintainability.
