Implement a synchronous LIFO buffer with a 4-entry deep stack memory and a stack pointer initialized to 4 (empty). On reset, clear memory and set SP to 4. On each clock rising edge, if enabled, perform push if RW=0 and not full by decrementing SP and writing dataIn to stack_mem[SP-1], or perform pop if RW=1 and not empty by outputting stack_mem[SP] and incrementing SP after clearing stack_mem[SP]. Update EMPTY and FULL flags based on SP (empty when SP==4, full when SP==0).
