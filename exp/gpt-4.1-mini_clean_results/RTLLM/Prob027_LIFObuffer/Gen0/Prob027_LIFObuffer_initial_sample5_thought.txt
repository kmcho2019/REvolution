Implement a 4-depth, 4-bit wide stack memory with a stack pointer initialized to 4 indicating empty. On reset, clear all memory and set SP to 4. On each clock edge with EN active, perform write if RW=0 and not full by decrementing SP and storing dataIn. Perform read if RW=1 and not empty by outputting the top data, clearing that memory location, and incrementing SP. Update EMPTY when SP == 4 and FULL when SP == 0.
