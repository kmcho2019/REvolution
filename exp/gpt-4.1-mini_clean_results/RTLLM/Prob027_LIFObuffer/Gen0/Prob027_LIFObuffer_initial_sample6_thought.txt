Implement a synchronous stack-based LIFO buffer with a 4-entry, 4-bit wide memory. The stack pointer (SP) starts at 4 (empty). On write (RW=0), if not full, decrement SP and write dataIn at new SP. On read (RW=1), if not empty, output data at SP and clear it, then increment SP. On reset, clear memory, set SP to 4. Update EMPTY (SP==4) and FULL (SP==0) flags accordingly.
