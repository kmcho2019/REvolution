Implement a 4-entry 4-bit wide LIFO stack using an array and a stack pointer initialized to 4 to indicate empty. On reset, clear the stack memory and set SP to 4. On each clock when enabled, for write (RW=0) if not full, decrement SP and write dataIn into that position. For read (RW=1) if not empty, output data from SP location, clear it, and increment SP. Update EMPTY and FULL flags based on SP values (4 means empty, 0 means full).
