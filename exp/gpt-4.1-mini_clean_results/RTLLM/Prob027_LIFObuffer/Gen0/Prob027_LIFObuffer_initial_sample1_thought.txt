Implement a 4-entry, 4-bit wide stack memory with a stack pointer initialized to 4 indicating empty. On reset, clear memory and set SP=4. On each clock with EN high, if RW=0 (write) and not full, decrement SP and write dataIn to stack_mem[SP-1]. If RW=1 (read) and not empty, output dataOut from stack_mem[SP], clear that location, and increment SP. Update EMPTY and FULL flags based on SP value.
