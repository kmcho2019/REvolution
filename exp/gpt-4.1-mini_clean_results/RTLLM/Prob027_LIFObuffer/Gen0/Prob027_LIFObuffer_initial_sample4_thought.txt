Implement a 4-entry stack (each 4 bits wide) using an array and a stack pointer (SP) that points to the current empty position. SP initialized to 4 means empty stack. On write, if not full, decrement SP and write data at stack_mem[SP-1]. On read, if not empty, output data at stack_mem[SP], clear it, and increment SP. EMPTY is high when SP == 4, FULL is high when SP == 0. Operations happen on rising clock edge when EN is high. On reset, clear all memory, set SP to 4.
