Implement a 4-entry stack with a 4-bit data width. Use a 3-bit stack pointer (SP) starting at 4 to indicate an empty stack (since indices are 0 to 3). On reset, clear memory and set SP=4. On write (RW=0), if not full, decrement SP and write data. On read (RW=1), if not empty, read dataOut from stack_mem[SP], clear that location, then increment SP. Update FULL when SP==0 and EMPTY when SP==4. Operations occur only when EN=1.
