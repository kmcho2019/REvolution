Implement the LIFObuffer using a stack pointer that increments on push and decrements on pop, starting from zero (empty stack) to four (full stack). Use a one-hot approach for EMPTY (SP == 0) and FULL (SP == 4) flags. The stack memory is a 4x4-bit array indexed by SP for push and SP-1 for pop to maintain LIFO order. On write (push), dataIn is stored at the current SP location, and SP increments. On read (pop), SP decrements first, then dataOut is updated with the value at SP-1. This design uses synchronous logic and separates push and pop logic clearly by adjusting SP before the operation, ensuring clean data flow. Reset initializes SP to zero and clears all stack memory. EN gates all operations. This approach offers intuitive SP behavior and clearer push/pop semantics.
