To improve PPA while keeping the design functionally correct:

- Replace the 3-bit SP that counts number of elements with a 2-bit pointer (0-3) that points to the next free slot, along with a separate count register for size, enabling simpler pointer wraparound and size tracking for full/empty flags. This can reduce the bit-width and arithmetic complexity.

- Use a circular stack pointer and a counter for tracking the number of elements, which can reduce logic for full/empty flag generation and pointer update.

- Perform push by writing dataIn at the current pointer, then increment pointer and increment count.

- Perform pop by decrementing pointer and decrementing count, and updating dataOut from memory at the popped pointer.

- Clear stack_mem entries and dataOut on reset to avoid undefined states, but only clear stack_mem in a way that synthesis tools can optimize (e.g., using a generate loop or unrolled resets).

- Add write enable (wen) for memory to gate writes and reduce unnecessary toggling.

- Output EMPTY and FULL flags combinationally from count.

- Use non-blocking assignments correctly to avoid race conditions.

- This approach enables smaller and more predictable control logic and may improve maximum frequency and reduce area slightly.

This subtle refactoring keeps power low by gating writes, maintains clear reset behavior, and may improve timing due to simplified pointer management.
