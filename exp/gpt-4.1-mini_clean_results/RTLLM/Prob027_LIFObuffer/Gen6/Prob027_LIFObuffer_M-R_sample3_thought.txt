Refactor the LIFO buffer to use a 4-entry register array for the stack memory instead of a wide shift register. Use a 3-bit stack pointer (SP) to track the top of stack position, where SP indicates the next free position (from 0 to 4). On push (RW=0), if not full, store dataIn at stack_mem[SP], increment SP. On pop (RW=1), if not empty, decrement SP and output stack_mem[SP-1]. This eliminates shifting and provides direct indexed access to memory, improving timing and power. Use synchronous reset to clear stack and SP. EMPTY and FULL flags are combinational from SP value. The output dataOut is registered and updated only on pop. This structure is more scalable and synthesis-friendly, avoids wide data shifts, and makes the design more modular.
