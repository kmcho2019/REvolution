Implement the LIFO buffer using a stack pointer (SP) that points directly to the current top element in the stack (instead of the next free slot). The SP value ranges from 0 (empty) to 3 (full), where SP=-1 indicates empty state. 

On reset, SP is initialized to -1, indicating empty. On a push operation (RW=0), if not full, SP is incremented, and dataIn is stored at stack_mem[SP]. On a pop operation (RW=1), if not empty, dataOut is assigned stack_mem[SP], then SP is decremented. 

EMPTY flag is high when SP == -1, FULL flag is high when SP == 3. 

This design updates SP and stack_mem in a single synchronous always block to maintain consistency and avoid race conditions, and dataOut is updated combinationally from stack_mem at SP during a pop (or registered synchronously, whichever fits timing better). This also reduces complexity of address calculations and improves readability by using SP as the top-of-stack pointer.

To avoid negative indices in the SP (since Verilog unsigned reg cannot be negative), use a signed 3-bit register for SP and check for SP == -1 as empty. Alternatively, use a 3-bit unsigned SP and define SP=3'd0 as empty with a separate valid flag, but for clarity and intuitive understanding, a signed SP is used here.

This approach centralizes stack pointer and memory logic in one always block, improving timing, simplifies flag generation, and makes indexing straightforward (stack_mem[SP]) on push and pop operations.
