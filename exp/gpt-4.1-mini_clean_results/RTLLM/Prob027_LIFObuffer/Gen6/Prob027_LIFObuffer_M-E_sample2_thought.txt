Implement the LIFO buffer using a 4-entry 4-bit memory array (stack_mem) indexed by a 3-bit stack pointer (SP) that counts the number of valid entries. The SP points to the next free location for push (write) and the last valid entry for pop (read). On reset, SP is set to 0 (empty) and memory is cleared. On push (RW=0) with EN, if not full, dataIn is written to stack_mem[SP], then SP increments. On pop (RW=1) with EN, if not empty, SP decrements first, then dataOut is read from stack_mem[SP]; the popped memory location is cleared to 0. The EMPTY flag is asserted when SP == 0, and FULL when SP == 4. This indexed memory approach eliminates expensive shifts, reduces switching activity, and improves timing and power efficiency. Output dataOut is registered synchronously during pop operations.
