Implement the LIFObuffer as a circular stack with a 3-bit pointer that counts the current depth of the stack (0 to 4). The stack pointer (SP) counts how many elements are currently stored, rather than directly pointing to an address. Push writes at the current top index (SP), then increments SP. Pop decrements SP, then outputs data from the new SP location.

This approach keeps SP as a stack depth counter, simplifying the logic for empty/full detection (EMPTY when SP==0, FULL when SP==4).

The circular buffer index is managed by modulo addressing, but since max depth is 4, modulo 4 arithmetic is straightforward with 2-bit addresses for memory.

To align with the 4-depth buffer, use a 2-bit "top index" pointer to track where the next push/pop happens. The "SP" counts the number of stored elements (0-4). The memory is indexed by the top pointer or top pointer - 1 modulo 4 depending on push or pop.

On push (RW=0), write dataIn at top index, increment SP (if not full), increment top index modulo 4.

On pop (RW=1), decrement SP (if not empty), decrement top index modulo 4, read data from new top index.

All operations occur on the rising clock edge when EN is high and Rst low.

Advantages:
- Clear, simple management of empty/full states.
- Top index only 2 bits with modulo 4 addressing simplifies memory access.
- SP as stack depth simplifies flag logic.
- DataOut updated only on pop.
- Memory locations not cleared on pop to save power.
- Memory and pointers reset on Rst.
