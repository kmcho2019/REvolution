Implement the LIFObuffer with a bottom-up approach using a stack pointer (SP) that points to the next free slot in the 4-entry stack. On reset, SP is initialized to 4, indicating an empty stack. Push operations (RW=0) decrement SP first (if not full) and write dataIn into stack_mem[SP]. Pop operations (RW=1) read dataOut from stack_mem[SP] (if not empty) and then increment SP, effectively removing the top element. Clearing stack memory on pop is done for clarity but can be optimized out if desired. EMPTY is high when SP equals 4; FULL is high when SP equals 0. This approach treats the stack growing "downwards" from address 3 to 0, making pointer arithmetic intuitive and aligning with typical stack pointer behavior. All operations occur synchronously on the rising edge of Clk when EN is asserted, with reset asynchronously clearing the stack and resetting SP. dataOut updates only on pop operations, ensuring stable output during idle or push cycles. This design cleanly separates pointer movement from data storage and ensures simple flag logic and safe memory indexing.
