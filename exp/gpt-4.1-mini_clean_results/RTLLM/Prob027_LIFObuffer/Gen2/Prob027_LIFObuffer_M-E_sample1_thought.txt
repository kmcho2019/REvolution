Use a stack pointer (SP) that points to the next free location in the buffer (0 when empty, 4 when full). On reset, set SP to 0 and clear the stack. On a write (push), store dataIn at stack_mem[SP] and increment SP if not full. On a read (pop), decrement SP if not empty and output the data from stack_mem[SP-1]. Update EMPTY and FULL flags combinationally based on SP. This approach avoids pointer arithmetic and memory indexing in the same clock cycle, and keeps dataOut updated only during pop operations. Separate the output register update for clarity and better timing.
