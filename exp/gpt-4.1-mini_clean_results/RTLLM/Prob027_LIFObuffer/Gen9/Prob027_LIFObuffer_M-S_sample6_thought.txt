Simplify the LIFO buffer by using an unsigned 3-bit stack pointer (SP) pointing to the next free position in the stack memory (0 to 4). When SP is 0, the buffer is empty; when SP is 4, the buffer is full.

On reset, SP is set to 0 and stack_mem cleared.

On a write (RW=0) and not full, dataIn is stored at stack_mem[SP], then SP increments.

On a read (RW=1) and not empty, SP decrements, and dataOut is assigned stack_mem[SP].

This approach avoids signed arithmetic and negative pointer values, simplifying comparisons for FULL and EMPTY flags.

The dataOut register is updated synchronously on pop, and push does not affect it.

Memory clearing on pop is omitted for simplicity and reduced toggling.

This solution maintains all specified functionality with reduced pointer logic complexity and clearer indexing.
