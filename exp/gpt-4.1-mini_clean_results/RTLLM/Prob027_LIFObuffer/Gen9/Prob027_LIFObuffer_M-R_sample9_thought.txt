Refactor the LIFObuffer by using an explicit 4-entry register array (stack_mem) and a 3-bit stack pointer (SP) counting the current number of entries. On each clock edge (when EN=1 and not reset), perform push (RW=0) or pop (RW=1) operations by incrementing or decrementing SP and storing or outputting data accordingly. This avoids shifting wide registers, reducing switching activity and improving timing. The dataOut register updates only on a successful pop. EMPTY and FULL signals are combinationally derived from SP. Reset clears stack_mem and sets SP to 0 (empty). Using a memory array indexed by SP for push/pop is more explicit and synthesis-friendly.
