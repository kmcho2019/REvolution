Implement the 4-entry LIFO buffer using a decrementing stack pointer that points to the top valid element's index rather than the count of elements. 

- Initialize SP to -1 (3'd7 used to indicate empty) to denote an empty stack.
- On push (RW=0), increment SP and write dataIn at stack_mem[SP].
- On pop (RW=1), read stack_mem[SP], output it, then decrement SP.
- EMPTY when SP == 3'd7 (no elements), FULL when SP == 3'd3 (max index).
- On reset, clear SP to empty state and zero out memory.
- Keep dataOut registered and updated only on pop.
- Use explicit boundary checks to prevent overflow and underflow.
- This approach uses SP as an index rather than element count, simplifying addressing for push/pop and avoiding arithmetic offsets.
- EMPTY/FULL flags derive from SP and are combinational for immediate status.
- Reduce toggling by updating stack_mem only on push, and dataOut only on pop.
- Use non-blocking assignments and synchronous reset.
