Simplify the LIFObuffer by removing separate push and pop address wires and instead directly use the stack pointer (SP) as the index for push and pop operations. Since SP counts down from 4 (empty) to 0 (full), push writes at SP-1 and pop reads at SP, but we can manage SP updates and memory indexing with simple expressions inline. Combine push and pop enables directly within the always block under enable (EN). Use a single always block with synchronous reset to clear the stack and set SP to 4. Update dataOut only on pop. Flags EMPTY and FULL are combinational based on SP. The code is more concise by avoiding extra wires and addressing calculations, making it easier to understand and slightly reducing resource usage while preserving all functionality.
