Refactor the LIFObuffer to use a single synchronous always block for all sequential logic including stack pointer, dataOut, and stack memory updates, and use continuous assignments for EMPTY and FULL flags. Instead of computing next state signals separately, directly update the state inside the clocked always block based on RW, EN, and Rst. The stack pointer will be implemented as an integer index counting how many elements are currently in the stack (0 = empty, 4 = full), making push increment SP and pop decrement SP. The stack memory will be treated as a classic stack array with push writing at SP and pop reading from SP-1. This approach aligns more closely with a typical stack pointer scheme, simplifies the pointer management, and makes the logic straightforward with fewer intermediate signals. Initial reset clears the memory and sets SP to zero. The outputs are updated synchronously.
