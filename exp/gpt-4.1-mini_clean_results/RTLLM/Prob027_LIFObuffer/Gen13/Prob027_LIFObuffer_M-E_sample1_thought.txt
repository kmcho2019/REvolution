Use a descending stack pointer (SP) starting from 3 down to -1 to indicate stack positions, making the top of stack at SP index.

- Initialize SP to -1 on reset indicating empty stack.
- For push (RW=0), if not full (SP < 3), increment SP by 1 and write dataIn to stack_mem[SP+1].
- For pop (RW=1), if not empty (SP >= 0), read dataOut from stack_mem[SP] then decrement SP.
- Update EMPTY when SP is -1 and FULL when SP is 3.
- Clear only dataOut on reset to avoid overhead of clearing entire memory, assuming stale data in stack_mem is acceptable.
- DataOut is registered and updated only on valid pop operations, retains previous value otherwise.
- Use a synchronous process to update SP and dataOut on clock edge with enable gating.
- This approach simplifies push/pop logic by directly indexing stack_mem with SP and offers intuitive stack top management.
