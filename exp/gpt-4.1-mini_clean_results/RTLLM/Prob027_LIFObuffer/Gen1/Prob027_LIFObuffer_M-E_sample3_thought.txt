Use SP as an index to the current top of the stack, initialized to -1 (represented as 3'b111) meaning empty stack. On a write (push), increment SP first, then write dataIn to stack_mem[SP], if not full. On a read (pop), read dataOut from stack_mem[SP], then clear stack_mem[SP] and decrement SP, if not empty. EMPTY when SP == -1, FULL when SP == 3 (max index). This approach avoids confusion by letting SP always point to the current top item or be -1 when empty. All operations occur on rising edge when EN is high. On reset, SP is set to -1 and all memory cleared. This design uses signed comparison of SP with -1 and 3, implemented with 3-bit unsigned with -1 as 3'b111.
