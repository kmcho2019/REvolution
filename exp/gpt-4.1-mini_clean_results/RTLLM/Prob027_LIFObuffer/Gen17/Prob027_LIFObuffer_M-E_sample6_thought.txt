I will implement the 4-entry, 4-bit wide LIFO buffer using a top-down approach where the stack pointer (SP) points to the current top-of-stack location (0 to 3), or indicates empty/full conditions explicitly.

Instead of counting down from 4 to 0 like before, I'll design SP as a 2-bit pointer that increments on push and decrements on pop, with EMPTY indicated by SP == 0 and FULL by SP == 4 (using a 3-bit SP to represent 0-4 range).

Key differences:
- Use an explicit 3-bit SP ranging from 0 to 4 (number of items in stack).
- On push (RW=0), write dataIn to stack_mem[SP], then increment SP.
- On pop (RW=1), decrement SP, then read stack_mem[SP-1] to dataOut.
- On reset, SP=0 and all memory cleared.
- Only perform push if not full; only perform pop if not empty.
- EN enables operation; if EN=0, hold state.
- Flags EMPTY and FULL derived directly from SP.
This approach treats SP as a count of stored items, rather than an index, simplifying logic for push/pop and indexing.

This design is intuitive, easy to verify, and results in clean push/pop operations with minimal pointer arithmetic. It also cleanly separates pointer update and memory access.
