Implement a straightforward synchronous stack with a 2-bit stack pointer (SP) counting the current number of entries (0 to 4). On push, if not full, write dataIn at stack_mem[SP], then increment SP. On pop, if not empty, decrement SP and output data from stack_mem[SP-1]. Reset sets SP to 0 and clears dataOut. EMPTY and FULL flags are simple combinational checks on SP. This reduces pointer arithmetic complexity (no counting down or subtraction), uses intuitive push/pop semantics, and simplifies code by separating push and pop logic clearly. Also, avoid clearing the entire memory on reset for simplicity, just reset SP and dataOut. This keeps the design minimal and functional as requested.
