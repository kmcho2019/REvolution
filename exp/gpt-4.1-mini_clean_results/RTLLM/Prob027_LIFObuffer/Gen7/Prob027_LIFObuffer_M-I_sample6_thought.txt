To improve PPA and avoid the costly 16-bit shift operations on each push/pop, implement the LIFO buffer as a simple 4-entry 4-bit memory array indexed by a 3-bit stack pointer (SP). The SP will indicate the current top of stack position. On reset, SP is set to 4 indicating empty buffer. On push (RW=0), if not full, decrement SP and write dataIn into stack_mem[SP]. On pop (RW=1), if not empty, read data from stack_mem[SP] to dataOut and then increment SP, clearing that memory location for clarity. This indexed memory approach removes the need for wide shifts, reducing switching activity and improving timing. Flags FULL and EMPTY are combinationally driven by SP (FULL when SP==0, EMPTY when SP==4). The design ensures only one memory location is accessed per cycle, and dataOut is registered only on pop operations, reducing output glitches and timing complexity.
