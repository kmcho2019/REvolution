Refactor the fixed_point_adder to use continuous assignments (`assign`) instead of an always block for combinational logic. This change improves readability and helps synthesis tools optimize dataflow more effectively. The core functionality remains:

- Compute absolute values via conditional operator wires.
- Use signed arithmetic directly on inputs for sign comparison and arithmetic.
- Perform addition or subtraction depending on sign bits.
- Detect and saturate overflow for addition of same-sign operands.
- Set the result sign accordingly.
- Force positive sign for zero result.

This approach reduces inferred registers and leverages dataflow style, which can improve timing and reduce complexity. It also clearly separates magnitude and sign computations, simplifying the design and ensuring correctness with parameterized bit widths.
