Implement a parameterized fixed-point adder that correctly handles signed fixed-point addition by interpreting inputs as signed two's complement numbers with N bits total and Q fractional bits.

Key points and architecture:

- Inputs `a` and `b` are N-bit two's complement fixed-point numbers.

- Interpret inputs as signed integers; addition can be done directly on signed values.

- Extract sign bits to detect sign difference.

- To satisfy the problem's requirement for "absolute value" operations:

  1. When signs are the same, simply add the two signed inputs normally.

  2. When signs differ, perform subtraction of absolute values:

     - Compute absolute values of `a` and `b` via two's complement inversion if negative.

     - Compare absolute values.

     - Subtract smaller absolute from larger absolute.

     - Assign result sign as sign of the operand with larger absolute value.

- The internal register `res` stores the final result as an N-bit two's complement fixed-point number.

- Overflow is implicitly handled by the fixed bit-width two's complement arithmetic. Saturation is not implemented but can be added if desired.

This approach leverages two's complement arithmetic properties, uses absolute value computation via two's complement, and reconstructs the signed output accordingly.

This satisfies the problem's requirements of:

- Handling signs correctly.

- Adding or subtracting absolute values depending on signs.

- Using fixed-point representation with Q fractional bits.

- Maintaining output width N bits.
