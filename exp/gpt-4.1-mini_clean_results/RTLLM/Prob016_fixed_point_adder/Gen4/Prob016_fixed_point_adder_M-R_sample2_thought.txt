Refactor the fixed_point_adder to use purely continuous assignments and internal combinational logic wires instead of always blocks. This will eliminate the need for an internal `res` register as a procedural variable, instead expressing the logic through intermediate signed wires. 

The approach:
- Define signed wires for input operands (`a_signed`, `b_signed`).
- Compute absolute values using signed comparisons and conditional operators.
- Use combinational logic to determine whether to add or subtract absolute values based on sign bits.
- Calculate the final signed result as a wire.
- Assign the fixed-point sum to output port `c` as a continuous assignment.
- Keep the module fully parameterized with clear parameter defaults.
- This approach improves synthesizability, clarity, and removes procedural blocks while preserving the exact arithmetic behavior.
- Overflow is implicitly managed by fixed bit widths and signed arithmetic.
- The internal register `res` is conceptually replaced by the wire `res` to avoid multiple procedural assignments.
