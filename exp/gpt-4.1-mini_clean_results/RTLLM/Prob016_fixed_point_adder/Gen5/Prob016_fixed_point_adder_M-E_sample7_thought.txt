Implement the fixed-point adder by explicitly computing absolute values and signs of inputs, then performing addition or subtraction on the absolute values based on the input signs. Specifically:
1. Extract the sign bits (MSBs) of inputs `a` and `b`.
2. Compute absolute values by inverting bits and adding one if negative.
3. If signs match, add the absolute values and restore the common sign.
4. If signs differ, subtract the smaller absolute value from the larger one and assign the sign of the operand with larger magnitude.
5. If the subtraction yields zero, set sign to positive.
6. Use a wider internal register to handle overflow during addition.
7. After computation, truncate or saturate the result back to N bits.
This approach closely follows the problem requirements, ensuring precise control of sign bits, correct absolute value operations, and proper fixed-point handling based on parameters Q and N.
