Leverage the natural two's complement addition for fixed-point numbers without explicit absolute value calculation. Simply add the inputs as signed values. Overflow detection can be done by comparing input signs and output sign. If overflow occurs, saturate to the max or min value representable. This approach inherently respects fixed-point precision defined by Q and N, as both inputs and output share the same format.

Internal register `res` stores the intermediate result, and the output `c` mirrors `res`. This simplifies logic by relying on built-in signed arithmetic and overflow detection, omitting manual magnitude comparisons or sign manipulations.
