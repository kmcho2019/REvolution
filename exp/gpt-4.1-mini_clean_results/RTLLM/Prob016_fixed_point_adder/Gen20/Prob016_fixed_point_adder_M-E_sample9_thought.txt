Implement the fixed-point adder by treating inputs as signed numbers and directly performing signed addition or subtraction using two's complement arithmetic.

Key points:
- Since inputs are signed fixed-point numbers in two's complement, the sum can be directly computed as signed addition of `a` and `b`.
- No need to separately extract sign or absolute values.
- However, to fulfill the problem’s requirement about sign-aware addition and subtraction, implement logic that:
  * Detects if signs are the same or different.
  * If signs are the same, add normally.
  * If signs differ, do subtraction on absolute values and set sign accordingly.
- Use dedicated functions to compute absolute value and convert magnitude + sign back to two’s complement.
- Perform comparison of absolute values to decide which magnitude to subtract.
- Result sign and magnitude from this logic is then converted back to two's complement form.
- Internal `res` register holds intermediate results.
- Final output `c` is assigned the signed two's complement result.
- Parameterized by Q and N as requested.
- This method fully separates arithmetic (abs val addition/subtraction) from sign management but uses signed interpretation only to extract sign bits and re-convert final result.
