Simplify the fixed-point adder by leveraging two’s complement arithmetic directly, which inherently supports signed addition and subtraction. This avoids explicit sign and magnitude extraction, absolute value calculations, and manual sign restoration.

1. Treat inputs as signed values using SystemVerilog's signed types.
2. Perform addition directly on signed inputs.
3. Assign the lower N bits of the result to output c.
4. The fixed-point precision (Q) remains implicit, as fixed-point addition aligns fractional bits.
5. Handle overflow naturally via two's complement wrap-around behavior.

This approach maintains fixed precision and sign correctness, greatly reducing complexity while ensuring correct arithmetic results for fixed-point addition.
