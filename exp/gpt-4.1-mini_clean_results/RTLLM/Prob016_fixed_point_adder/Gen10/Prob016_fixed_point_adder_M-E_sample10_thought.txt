Implement the fixed-point adder by leveraging two's complement addition directly, then adjusting for sign and overflow by analyzing input signs and the sum's MSB.

Key points of the new design:
- Use signed arithmetic since inputs are two's complement fixed-point numbers.
- Perform simple addition of inputs a and b as signed values (using the signed keyword).
- Detect if signs of a and b are the same (meaning addition), or differ (effectively subtraction).
- When signs are equal, the sum is a straightforward addition; just output sum truncated to N bits.
- When signs differ, the sum is effectively a subtraction, but since it is done in two's complement, the sign of the result naturally emerges.
- To handle overflow, detect overflow conditions from input signs and output sign (using overflow detection for signed addition).
- Saturate the output to the maximum positive or negative representable value on overflow.
- Use parameterization for total bit width N and fractional bits Q, but no special fractional handling is required within addition since Q just defines how to interpret the bits.
- Implement all logic combinationally with an internal register 'res' holding the final result before output.
- This architecture relies on two's complement arithmetic and overflow detection rather than explicit absolute value manipulation, simplifying the hardware while preserving fixed-point semantics.
