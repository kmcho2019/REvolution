Implement a parameterized fixed-point adder for signed fixed-point numbers represented in two's complement. The module compares the sign bits (MSB) of inputs a and b. If both have the same sign, their absolute values are added, and the result's sign is set accordingly. If signs differ, the operation becomes subtraction of the smaller absolute value from the larger one, and the sign of the result follows the operand with the larger absolute value. Absolute values are obtained by checking the MSB and, if negative, taking two's complement. The result is then formed by setting the sign bit and the magnitude. Overflow is handled by fitting the result back into N bits as two's complement. The internal register res holds the intermediate result before assigning to output c.
