Implement a parameterized fixed-point adder module with parameters Q (fractional bits) and N (total bits). Inputs a and b are N-bit fixed-point numbers with the MSB as the sign bit. The module performs addition or subtraction depending on the sign bits:

- If a and b have the same sign, add their absolute values and assign the sign bit accordingly.
- If they have different signs, subtract the smaller absolute value from the larger one. The result's sign bit is positive if a >= b, else negative.
  
To perform absolute value operations, mask out the sign bit and compare magnitudes. Handle zero results by setting the sign bit to 0 (positive). The result is stored in an internal register res and output as c.

No external libraries are required, all operations done via bitwise and arithmetic operations considering signed fixed-point values.
