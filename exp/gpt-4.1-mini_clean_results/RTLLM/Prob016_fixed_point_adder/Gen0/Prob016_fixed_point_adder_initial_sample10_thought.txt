Implement a fixed-point adder that supports parameterized bit widths and fractional precision. The adder performs addition or subtraction based on operand signs (MSBs). When signs are equal, add absolute values and retain the sign. When signs differ, subtract the smaller absolute value from the larger, and assign the sign based on the operand with the larger magnitude. Use unsigned operations for absolute value calculations and handle the sign bit explicitly. The result is stored in a register and output accordingly. Ensure the output width matches the input width, including fractional bits.
