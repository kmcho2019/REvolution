Implement a parameterized fixed-point adder that operates on N-bit signed fixed-point numbers with Q fractional bits. The sign is determined by the MSB (two's complement). To add:

- When a and b have the same sign (MSB equal), add their absolute values and assign the same sign to the result.
- When signs differ, subtract the smaller absolute value from the larger absolute value, assign the sign of the operand with the larger absolute value.
- Since inputs are in two's complement, we need to obtain absolute values carefully.
- Use two's complement negation to get the absolute value if the sign bit is set.
- The output is N-bit signed fixed-point number with same Q fractional bits.
- Use a register to store intermediate result.
- Handle overflow by truncating to N bits (automatic by width).
- The final result is in two's complement form, so convert back from absolute value and sign to two's complement output.
