Implement the 3-bit comparator by using a subtractor-inspired combinational logic that computes the difference between A and B without performing full arithmetic subtraction. Instead, evaluate the bits starting from the most significant bit using a priority encoder style approach:  
- If A[i] > B[i], output A_greater=1;  
- Else if A[i] < B[i], output A_less=1;  
- Else proceed to the next bit.  
Equality is simply when all bits are identical. This approach avoids explicit equality checks on all bits separately and directly encodes the comparison into combinational priority logic, ensuring mutual exclusivity and minimal delay.  
This bit-by-bit priority encoding is novel compared to direct boolean equations and utilizes conditional assignment (`assign` with chained ternary operators) to express the decision tree clearly and efficiently.
