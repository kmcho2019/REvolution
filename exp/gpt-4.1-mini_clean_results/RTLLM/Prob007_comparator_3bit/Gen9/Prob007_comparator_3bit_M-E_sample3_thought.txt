Implement a comparator using the arithmetic subtraction approach to directly determine the relative order of A and B. Calculate the difference (A - B) as a 4-bit signed value (using an unsigned subtraction with an extended bit for sign). Then, use the sign bit of the result to detect if A < B, and zero detection for equality. Finally, derive A_greater by exclusion for mutual exclusivity. This approach leverages arithmetic logic to produce a clean and uniform comparator without nested conditional checks and can be easily extended to wider bit widths.
