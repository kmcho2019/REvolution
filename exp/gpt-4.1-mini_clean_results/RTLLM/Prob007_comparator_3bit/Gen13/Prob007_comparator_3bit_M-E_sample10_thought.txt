I will implement the 3-bit comparator by performing a direct numeric comparison using subtraction logic, without explicitly checking bitwise equality or constructing hierarchical comparison signals. 

The idea is:

1. Treat inputs A and B as unsigned 3-bit numbers.
2. Subtract B from A using combinational logic: diff = A - B.
3. Inspect the result: 
   - If diff is zero, then A == B.
   - If diff is positive (most significant bit of diff is 0 and diff != 0), then A > B.
   - If diff is negative (most significant bit of diff is 1), then A < B.
4. Use these conditions to set mutually exclusive output signals.
5. This approach leverages two's complement subtraction properties for compact, elegant logic.
6. No intermediate equality signals required; logic is succinct and intuitive.
7. The design is purely combinational, suitable for synthesis, and the output encoding is guaranteed mutually exclusive.

This subtraction-based approach offers a different perspective than bitwise comparison and is scalable to wider comparators.
