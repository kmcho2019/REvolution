Instead of building the comparator from bitwise equality and hierarchical greater-than logic, a novel approach is to use the subtraction operation concept: compute the difference A - B as an unsigned subtraction and use the borrow or sign bit to determine the relative magnitudes.

For 3-bit unsigned inputs, the subtraction can be done using a 4-bit adder (adding A and the two's complement of B). However, since this is combinational logic, we can express the logic purely in terms of comparison without an actual adder implementation.

Key idea:
- If A == B, then A_equal = 1.
- Else, compare bits from MSB to LSB:
  - If A > B, then A_greater = 1.
  - Else, A_less = 1.

Instead of multiple separate equality and greater-than checks, we use a simple arithmetic operation and deduce outputs:

1. Calculate the 3-bit difference (A - B) with borrow detection.
2. If difference == 0, A_equal = 1.
3. If no borrow generated (meaning A >= B), and difference != 0, then A_greater = 1.
4. If borrow generated, then A_less = 1.

To implement borrow detection and difference combinationally without a full adder chain, create a simple subtractor with carry/borrow signals.

This approach reduces combinational logic depth by evaluating the arithmetic relationship directly, which is scalable and clean.

This also ensures mutually exclusive outputs naturally since:
- borrow=0 & diff != 0 => A_greater=1,
- borrow=0 & diff=0 => A_equal=1,
- borrow=1 => A_less=1.
