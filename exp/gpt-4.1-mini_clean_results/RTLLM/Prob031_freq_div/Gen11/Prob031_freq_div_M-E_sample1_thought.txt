To implement the frequency divider with a novel architectural idea, I will use a single shared counter clocked by the 100 MHz input to simultaneously generate all three output clocks by decoding this counter value. This approach reduces resource usage and potentially eases timing by centralizing counting logic.

Design details:
- Use a single up-counter counting from 0 to 99 (to cover the highest division factor).
- CLK_50 toggles at half period of 50 MHz, i.e., every 1 input clock cycle, achieved by toggling when counter LSB changes.
- CLK_10 toggles every 5 input clock cycles (half period of 10 MHz).
- CLK_1 toggles every 50 input clock cycles (half period of 1 MHz).
- Outputs are generated by comparing counter value and toggling output clocks accordingly.
- Reset synchronously clears counter and output clocks.
- This method uses combinational logic to generate the output toggles based on the counter, which reduces the number of registers and separate counters.
- This also simplifies timing and power by minimizing switching registers and uses only one counter.

This approach efficiently uses a single counter and minimal toggling logic for all frequencies.
