To create a superior solution, we fuse the clarity and modularity of the first example (with explicit next-state combinational logic) and the simplicity and compactness of the second example (with fewer always blocks).

Key fusion ideas:
1. Use combinational logic for next-state calculations of counters and toggling signals (from Example 1). This improves readability, separates state update from next-state logic, and eases potential formal verification.
2. Combine all synchronous logic into a single always block on CLK_in and RST (from Example 2). This reduces clock domain crossings, eases timing optimization, and simplifies the sequential logic.
3. Use minimal counter widths for area efficiency (both examples).
4. Keep asynchronous reset for robust initialization.
5. Toggle CLK_50 every clock cycle by simply inverting it in sequential logic, as in Example 1 and 2.
6. Use parameters for the toggle thresholds for clarity and easy adjustments.

This fusion balances modularity, simplicity, and synthesizability, making the design clear and efficient while minimizing code complexity and resource usage.

The final design will have:
- A single synchronous always block with asynchronous reset for all registers.
- Two combinational always blocks computing next-state values for cnt_10/CLK_10 and cnt_100/CLK_1.
- CLK_50 toggled directly on the clock edge.
