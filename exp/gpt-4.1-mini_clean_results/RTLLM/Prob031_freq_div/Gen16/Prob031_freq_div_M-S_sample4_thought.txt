Simplify the frequency divider by using a single always block with one set of counters and toggling logic for all three outputs. Since CLK_50 is just toggling every input clock, it can be handled with a simple flip-flop in the same block. The counters for 10MHz and 1MHz clocks can be incremented and checked in the same block with straightforward conditional toggling. This reduces code duplication and keeps the design compact while maintaining the same functionality and asynchronous reset behavior.
