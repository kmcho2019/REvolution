Refactor the frequency divider to use a single always block for all counters and outputs, leveraging a more compact and centralized counting scheme. Instead of separate always blocks, use a combined counter-driven approach with synchronous reset and counters that track the count modulo necessary values for toggling each output clock. This approach reduces code duplication and consolidates control flow, while maintaining the same frequency division ratios.

The 50MHz clock toggles every cycle (divide by 2), so it can be implemented by a simple toggle driven by a 1-bit counter or a bit of a global counter. The 10MHz and 1MHz clocks are toggled when their counters reach half the division factor minus one, so we use counters that increment each clock and reset on toggle, toggling the respective clock output accordingly. This centralized approach simplifies state management and enhances readability with fewer always blocks, while preserving functionality.
