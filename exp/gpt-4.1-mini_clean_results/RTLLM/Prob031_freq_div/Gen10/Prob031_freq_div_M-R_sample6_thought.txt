The original design uses separate always blocks with counters and toggling for each output clock. To refactor, I will implement the frequency division using a single always block with one wider counter that increments every CLK_in cycle. Each output clock signal will be generated by comparing or deriving toggling signals from this master counter.

Specifically:
- Use a single 7-bit counter counting from 0 to 99 for the highest division (for CLK_1).
- CLK_50 toggles every 1 count (divide by 2), so we can derive it by toggling on the LSB of the counter.
- CLK_10 toggles every 5 counts (divide by 10), so we toggle CLK_10 when the lower 4 bits of the counter reach the correct value.
- CLK_1 toggles every 50 counts (divide by 100).

This approach reduces resource usage by having a single counter and combinational logic to generate outputs. It also makes it easier to manage and scale frequency dividers.

The reset remains asynchronous and active-high. All outputs are registered.

This style improves area and potentially power by minimizing counters and toggle registers, trading a bit more combinational logic for counters decoding. It keeps clarity and synchronous design.
