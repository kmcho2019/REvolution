Instead of using separate counters with individual always blocks for each output frequency, I will implement a single 7-bit counter that increments on every CLK_in rising edge and resets on RST. This counter's current value will directly determine the outputs by comparing it against preset toggle points.

The division approach is based on counting cycles and toggling the output clock signals at specific counts to achieve the desired frequencies.

- For 50 MHz output (divide by 2): toggle CLK_50 every 1 cycle (i.e., counter LSB toggles at every clock).
- For 10 MHz output (divide by 10): toggle CLK_10 every 5 cycles.
- For 1 MHz output (divide by 100): toggle CLK_1 every 50 cycles.

Using the single counter reduces resource usage and improves synchronization among outputs since all are derived from the same counter base.

This approach ensures simple combinational logic for toggle detection and efficient resource use, and all output clocks are synchronous with input clock and each other.
