Simplify the design by using a single always block for synchronous logic including asynchronous reset, without separate combinational next-state blocks. Implement the counters and output toggles directly within that always block. This reduces code size and complexity while preserving all functionalities.

Specifically:
- CLK_50 toggles every clock cycle (divide by 2).
- A 3-bit counter counts 0 to 4 for CLK_10 toggle.
- A 6-bit counter counts 0 to 49 for CLK_1 toggle.
- On reset, outputs and counters initialize to zero.

This approach is straightforward, clear, and fully functional, suitable for most FPGA or ASIC uses.
