Implement the frequency divider by using separate always blocks for each output clock signal. Each block will have its own counter and toggle logic with synchronous reset. This modular approach isolates the clock domain division logic, potentially improving readability and synthesis optimization. Counters will count half the period of the desired output frequency, toggling the output when reaching the terminal count. This also uses minimum bit-width counters based on the maximum counts required. By separating logic, the critical path for each clock divider is minimized and can be optimized independently.
