Instead of using separate counters for each output frequency, implement a single up-counter that increments on each rising edge of CLK_in. Then generate each divided clock by comparing the counter value with specific thresholds corresponding to half periods of each desired frequency. When the counter matches the threshold, toggle the output clock and reset the counter for that clock's domain. Use separate counters for each frequency domain but within one always block, or alternatively, implement all counters and toggles in separate always blocks triggered on CLK_in to keep them modular. This approach simplifies control logic and makes it easier to extend or modify division factors.
