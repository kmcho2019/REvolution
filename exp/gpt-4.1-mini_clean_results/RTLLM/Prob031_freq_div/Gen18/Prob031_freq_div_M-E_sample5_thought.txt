Implement a frequency divider using a single shared 7-bit counter that counts from 0 to 99, representing a full cycle for the slowest clock (1MHz). Generate all output clocks by toggling them at appropriate counts within the same always block. Specifically, toggle CLK_50 every 1 count (divide by 2), toggle CLK_10 every 5 counts (divide by 10), and toggle CLK_1 every 50 counts (divide by 100). This approach reduces the number of counters and resources by using one counter with multiple toggle conditions, resulting in compact logic and better synchronization between the output clocks since all toggle decisions happen in one clock domain and one process.
