Implement a freq_div module that takes CLK_in and RST as inputs.
Generate CLK_50 by toggling a register on every positive edge of CLK_in unless RST is active.
Generate CLK_10 by using a 3-bit counter cnt_10 that counts up to 4; when it reaches 4, toggle CLK_10 and reset counter.
Generate CLK_1 by using a 6-bit counter cnt_100 that counts up to 49; when it reaches 49, toggle CLK_1 and reset counter.
Reset all outputs and counters to 0 when RST is active.
