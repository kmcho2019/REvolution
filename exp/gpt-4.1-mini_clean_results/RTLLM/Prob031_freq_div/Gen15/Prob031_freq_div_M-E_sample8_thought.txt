Implement a frequency divider using a single shared counter and a multiplexer-like approach to generate all output clocks. The counter will count from 0 to 99 (for 100 input cycles) and generate toggles for CLK_50, CLK_10, and CLK_1 based on the current counter value. 

- CLK_50 toggles every 1 input clock cycle (divide by 2) by toggling at every count's LSB change.
- CLK_10 toggles every 5 input cycles: toggle when count reaches 4 and 9 (to produce a 50% duty cycle 10MHz output).
- CLK_1 toggles every 50 input cycles: toggle when count reaches 49.

This way, a single 7-bit counter drives all the output clocks, ensuring synchronous relationships between outputs and using minimal counters. The toggle points are carefully selected to produce accurate frequencies and duty cycles. 

This approach reduces resource usage by sharing the counter and logic, simplifies the design, and keeps synchronous reset and toggling. The outputs are updated combinationally from the counter value for precision and synchronous updates. Non-blocking assignments are used for flip-flops.

The code uses one always block triggered by CLK_in and RST, updating the counter and toggling the clocks accordingly.
