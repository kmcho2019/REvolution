Implement a 64-bit subtractor using the built-in Verilog subtraction operator for clean, concise code. The subtraction (A - B) is naturally expressed as A + (~B + 1), but using '-' operator synthesizes optimized hardware (adder/subtractor internally).

For overflow detection, implement the classic signed overflow detection formula: overflow occurs when the sign bits of A and B differ, and the sign bit of the result is different from A's sign bit.

This approach leverages synthesis tools' ability to optimize subtraction with carry logic, simplifying code and making it portable and easy to maintain. It avoids manually implementing carry lookahead logic or ripple borrow chains.

The overflow detection logic uses bitwise operations to clearly identify positive and negative overflow cases, ensuring correctness for signed 64-bit subtraction.

Overall, this design is compact, easy to understand, and relies on synthesis tools for performance optimization, suitable for high-precision signed arithmetic with minimal code complexity.
