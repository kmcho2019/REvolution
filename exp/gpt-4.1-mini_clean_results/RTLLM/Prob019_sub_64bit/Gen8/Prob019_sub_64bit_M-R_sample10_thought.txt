Refactor the 64-bit subtractor to use a single-line continuous assignment for subtraction using Verilog’s built-in arithmetic operator, which infers an adder in synthesis tools. This approach simplifies the code by avoiding explicit ripple-carry adder instantiation and chains of full adders, resulting in more concise, readable code.

Overflow detection logic remains the same: compare the sign bits of inputs and result to detect overflow in signed subtraction.

This refactoring maintains the exact functionality but leverages synthesizable high-level operators, allowing synthesis tools to optimize the adder implementation internally (possibly better than manual ripple-carry adder) and making the code simpler and easier to maintain.
