Implement a fully pipelined 64-bit ripple carry adder divided into 16 stages, each processing 4 bits. Each stage holds registered inputs and carry-in, performs 4-bit addition, and registers the sum and carry-out to feed the next stage in the subsequent clock cycle. This fine-grained pipelining reduces combinational path delay significantly compared to wider slices.

The enable signal i_en propagates through pipeline registers, indicating when the outputs are valid. The final 65-bit sum is assembled at the output stage from all 16 sum registers and the last carry-out bit.

Reset clears all pipeline registers and disables the output enable. The pipeline advances only when i_en is asserted, with all pipeline registers updated at each clock edge.

This architecture simplifies timing at each stage (4-bit adders), ensures consistent pipeline depth, and cleanly tracks valid data with an enable pipeline register.
