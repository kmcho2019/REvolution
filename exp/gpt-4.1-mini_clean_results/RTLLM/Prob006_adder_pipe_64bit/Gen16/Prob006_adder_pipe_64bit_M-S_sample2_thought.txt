Implement the 64-bit ripple carry adder as a 4-stage pipeline, each stage adding 16 bits with registered sums and carry. This reduces pipeline stages while keeping a reasonable balance between complexity and throughput. On each clock cycle with i_en asserted, stage 0 latches the input operands and starts addition with carry_in=0. Subsequent stages add their 16-bit slices plus carry propagated from the previous stage.

Pipeline registers hold partial sums and carry signals. The output result is assembled from all sum segments plus the final carry. The output enable is pipelined to indicate valid result timing.

Reset clears pipeline registers and disables output enable. This structure simplifies the pipeline while maintaining correctness and synchronization.
