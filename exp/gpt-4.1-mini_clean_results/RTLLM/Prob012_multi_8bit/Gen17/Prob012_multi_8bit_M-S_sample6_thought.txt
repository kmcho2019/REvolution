I will implement the 8-bit multiplier using a simple combinational shift-and-add approach without generating all partial products explicitly or using an adder tree. Instead, I will iterate over each bit of the multiplier B, and if the bit is set, add the multiplicand A shifted by the bit index to an accumulator. This will be done combinationally using a for-loop inside an always_comb block, producing a straightforward and compact design that still correctly computes the 16-bit product.
