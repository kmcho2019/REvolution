Implement a simple combinational 8-bit multiplier using the classic shift-and-add method:
- Initialize a 16-bit product to zero.
- Iterate over each bit of multiplier B.
- For each bit set in B, add the multiplicand A shifted by the bit index to the product.
- This approach uses a straightforward generate loop without partial product arrays or multiple adders.
- Keeps the design minimal and easy to understand while ensuring correctness and combinational behavior.
