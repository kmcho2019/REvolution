Implement an 8-bit multiplier using a sequential shift-and-add approach with a simple FSM:  
- Use a clocked process to iteratively process each bit of B.  
- Maintain a 16-bit register for the product, initialized to zero.  
- For each bit in B (starting from LSB), if the bit is 1, add the multiplicand A (appropriately shifted) to the product.  
- Shift the multiplicand left by one bit in each iteration.  
- Use an internal counter to track which bit of B is being processed.  
- Once all bits are processed, output the product.  
This approach trades latency for lower combinational complexity and smaller area, suitable for resource-limited environments.
