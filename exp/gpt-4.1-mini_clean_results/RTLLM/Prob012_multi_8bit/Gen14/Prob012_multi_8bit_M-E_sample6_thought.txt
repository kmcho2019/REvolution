I will implement an 8-bit combinational multiplier using a simple iterative shift-and-add approach fully unrolled in combinational logic:

- Start with a 16-bit accumulator initialized to zero.
- For each bit of the multiplier B (from LSB to MSB), if the bit is set, add the multiplicand A shifted left by that bit index to the accumulator.
- This models the classic manual multiplication algorithm.
- The addition is done directly by chaining partial sums as in a ripple through each bit of B.
- This approach is straightforward and avoids generating all partial products upfront and summing them with a tree.
- The code uses a for-generate loop to accumulate sums conditionally based on B bits.
- This method is purely combinational and easy to understand and synthesize.
