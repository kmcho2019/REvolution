Implement the 8-bit multiplier as a sequential shift-and-add multiplier using a simple FSM inside an always block triggered by a clock and reset. The multiplicand A and multiplier B are loaded into internal registers. Each clock cycle processes one bit of the multiplier B starting from the least significant bit: if the bit is 1, the multiplicand shifted by the current bit index is added to the partial product. The multiplicand is logically shifted left by 1 after each cycle. The process repeats until all 8 bits are processed, then the final product is assigned to the output. This design uses a small finite state machine and iterative addition, trading off latency for reduced combinational logic complexity and potentially lower area and power. The module is purely combinational (no clock) since no clock is specified, so the iteration is unrolled via a for-loop within a combinational block, simulating the sequential shift-and-add approach without actual clocking.
