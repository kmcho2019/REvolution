The original solution uses a combinational balanced adder tree that results in multiple large 16-bit adders in series, which can increase critical path delay and power. To improve PPA:

- I will implement a sequential shift-and-add multiplier using a finite state machine (FSM) and a single adder. This approach uses iterative logic over 8 clock cycles.
- This drastically reduces area by reusing one adder and storage registers rather than 8 parallel adders.
- Power is lowered because only one addition and one bit check occur each cycle; the switching activity is controlled.
- While latency increases (8 cycles), this is often acceptable for low-power or area-constrained designs.
- The design will have inputs A and B latched, a start signal, and a done signal to indicate completion.
- The output product is available after done goes high.

This approach offers a good balance: drastically reduced area and power at the cost of latency and control logic, suitable for many real-world applications.
