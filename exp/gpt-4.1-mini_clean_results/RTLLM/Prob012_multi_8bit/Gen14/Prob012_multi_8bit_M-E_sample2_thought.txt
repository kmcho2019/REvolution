Implement an iterative combinational multiplier using a procedural for-loop inside an always_comb block:
- Initialize product to zero.
- For each bit in B (from LSB to MSB), if that bit is set, add A shifted left by the bit index to the product.
- Use a single always_comb block to do the summation iteratively, which clearly reflects shift-and-add multiplication.
- This method avoids generating multiple wires and summation trees, trading off parallelism for simpler code that is easy to understand and verify.
- The design remains purely combinational, and synthesizers will unroll the loop to hardware.
