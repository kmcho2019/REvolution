To improve PPA from the given combinational multiplier, I will use a sequential shift-and-add algorithm implemented in a synchronous design with an FSM or counter. This reduces the combinational critical path drastically by performing one addition and one shift per clock cycle, spreading computation over multiple cycles. This significantly improves timing (critical path reduced to a single adder and shift per cycle), reduces power due to reduced switching in combinational logic, and area by using a single adder reused iteratively instead of multiple parallel adders.

The design will have inputs A and B latched internally, a 16-bit accumulator initialized to zero, and iterate 8 times over bits of B. For each bit in B, if the bit is set, the multiplicand (shifted appropriately by iteration count) is added to the accumulator. The multiplicand is shifted left by one bit on each iteration (or equivalently the accumulator is updated properly). After 8 cycles, the product is ready and output is valid.

This implementation is a classic shift-and-add multiplier using a state machine or counter, trading latency for much better PPA metrics.
