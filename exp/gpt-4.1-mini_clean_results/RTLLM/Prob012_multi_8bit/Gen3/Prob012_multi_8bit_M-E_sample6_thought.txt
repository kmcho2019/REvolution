Implement an iterative sequential multiplier using an always block and a shift-and-add algorithm controlled by a simple finite state machine. Instead of fully combinational logic, the module will perform multiplication over 8 clock cycles: each cycle examines one bit of the multiplier (B). If the bit is set, the current multiplicand (A) shifted appropriately is added to an accumulator (product). The multiplicand is left-shifted each cycle to align with the bit position, and the multiplier is shifted right to process the next bit. The product register will accumulate the result. This design simulates classical manual multiplication in hardware with fewer adders, trading latency for simplicity and potentially smaller area. For pure combinational usage, the design can be clocked by an external clock and start signal (not specified here), or a synchronous reset and enable can be added as needed. For the current task, the implementation uses combinational always blocks with a for-loop unrolled to explicitly perform the shift-and-add steps combinationally within a single cycle.
