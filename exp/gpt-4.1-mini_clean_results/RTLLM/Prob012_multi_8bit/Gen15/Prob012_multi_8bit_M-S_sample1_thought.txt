Implement a straightforward combinational 8-bit multiplier using shift-and-add without a balanced adder tree.  
For each bit of the multiplier B, if the bit is set, add the multiplicand A shifted by that bit position to the product.  
This approach directly sums partial products sequentially in a single expression using a simple for-generate loop, reducing code complexity at the cost of a longer combinational path.  
The design is purely combinational and easy to understand, suitable where simplicity is prioritized over maximum performance.
