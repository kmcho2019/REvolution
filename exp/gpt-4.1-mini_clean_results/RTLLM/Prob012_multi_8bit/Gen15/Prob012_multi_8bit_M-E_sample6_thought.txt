Implement the 8-bit multiplier using an iterative shift-and-add approach inside an always_comb block, without generating all partial products upfront.

The idea:
- Initialize the product register to zero.
- Iterate over each bit of the multiplier B in a for loop.
- For each bit, if the bit is set, add the shifted multiplicand (A shifted left by the bit index) to the product.
- This approach directly sums contributions without storing partial products separately.
- This method keeps the code simple and minimizes wire usage by only accumulating the sum progressively.
- The entire operation is combinational, so the final product is ready when inputs change.

This design differs from the parallel partial-product generation with a balanced adder tree by performing the additions iteratively in a single combinational block, preserving the shift-and-add concept in a straightforward manner.
