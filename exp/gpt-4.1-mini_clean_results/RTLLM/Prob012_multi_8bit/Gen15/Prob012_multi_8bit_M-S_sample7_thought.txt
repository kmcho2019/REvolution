Implement a simple combinational 8-bit multiplier using the classic shift-and-add approach:
- For each bit of B, if that bit is set, add A shifted left by the bit index to an accumulating product.
- Perform all additions in a single combinational always block with a for-loop.
This approach trades a longer combinational critical path for a straightforward, easy-to-understand implementation with fewer signals and no adder tree, reducing code complexity while maintaining full functionality.
