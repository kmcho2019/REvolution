Implement a purely combinational multiplier using an iterative shift-and-add approach with an explicit bit-wise process. The idea is to simulate the classic multiplication algorithm by scanning each bit of multiplier B from LSB to MSB. For each bit set to 1, we add the multiplicand A shifted left by the bit index to an accumulator. We achieve this with a generate loop that builds partial sums sequentially without storing arrays. Each partial sum is based on the previous sum plus the shifted multiplicand if the corresponding bit of B is set, otherwise just the previous sum. This approach leverages a chain of intermediate sums in wires, following the shift-and-add concept clearly and succinctly without using arrays or separate partial products. The final accumulated sum corresponds to the full 16-bit product.
