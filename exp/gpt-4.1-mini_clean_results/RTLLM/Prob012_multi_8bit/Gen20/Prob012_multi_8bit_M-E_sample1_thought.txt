Implement a sequential 8-bit multiplier using an iterative shift-and-add algorithm controlled by a simple state machine and a counter. The multiplicand (A) is loaded into a register, and the multiplier (B) is scanned bit by bit in each clock cycle. If the current bit of B is 1, the multiplicand (appropriately shifted) is added to an accumulating product register. The multiplicand is shifted left by one after each cycle to align with the next multiplier bit. This approach uses minimal combinational logic per cycle, trading throughput for a compact and efficient hardware implementation, suitable for resource-limited environments.
