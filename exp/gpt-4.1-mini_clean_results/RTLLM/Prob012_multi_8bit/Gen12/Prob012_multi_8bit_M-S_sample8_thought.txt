Implement a straightforward combinational 8-bit multiplier using the classic shift-and-add approach:
- Initialize the product to zero.
- For each bit in multiplier B, if that bit is set, add A shifted by the bit index to the product.
- Use a simple for-loop in a combinational always block (or a generate loop) to accumulate partial products.
This keeps the design simple, compact, and easy to understand, while preserving full functionality without extra adder trees.
