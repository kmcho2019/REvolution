Implement the 8-bit multiplier using a sequential shift-and-add approach controlled by a finite state machine (FSM).  
- Use a register to hold the multiplicand (A) and another for the multiplier (B).  
- Use a 16-bit accumulator to accumulate the partial sums (product).  
- On each clock cycle, check the least significant bit of the multiplier register: if it's 1, add the multiplicand register to the accumulator.  
- Shift the multiplicand left by 1 and shift the multiplier right by 1 at each cycle, progressing through all 8 bits.  
- Use a counter to track the number of processed bits.  
- Output the accumulator as the product once the process completes.  
- Provide a synchronous start input and done output signals to manage the operation's timing.  
This sequential design uses fewer resources than a fully combinational one and allows for trade-offs between area and latency. It also models a classical shift-and-add multiplier in hardware.
