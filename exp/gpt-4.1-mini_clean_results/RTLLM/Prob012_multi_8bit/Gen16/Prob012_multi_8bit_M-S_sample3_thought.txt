Implement a fully combinational 8-bit multiplier using a simple for-loop to accumulate shifted multiplicand values for each bit of the multiplier.  
- Initialize a 16-bit accumulator to zero.  
- For each bit of B, if the bit is set, add A shifted left by the bit index to the accumulator.  
- This straightforward shift-and-add method avoids multiple parallel partial products and summation stages, simplifying the code while maintaining correct functionality.  
- The design is clear and synthesizable, with moderate complexity and no additional generate blocks or arrays.
