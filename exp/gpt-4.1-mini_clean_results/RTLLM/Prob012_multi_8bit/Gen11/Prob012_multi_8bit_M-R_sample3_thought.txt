Refactor the 8-bit multiplier as a procedural combinational block using an always_comb block and a for-loop to accumulate the shifted multiplicand into a register variable. This approach sequentially adds shifted values of A based on each bit of B without using a generate block or an array of partial products, making the design easier to read and maintain. It retains the shift-and-add multiplication principle but expresses it in a single procedural block rather than summing separate wires.
