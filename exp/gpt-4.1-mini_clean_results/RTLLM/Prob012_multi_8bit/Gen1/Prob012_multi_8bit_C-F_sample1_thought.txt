Combine the clarity and simplicity of the second example with the explicit tracking of the shifted multiplicand from the first. Use a combinational always block with a loop over the bits of B. For each bit, if set, add the current shifted multiplicand (starting as A and shifted left each iteration) to the product. This avoids performing a separate shift by i bits each time, reducing logic complexity and potentially lowering critical path length and power compared to shifting A inside the loop as in example two. The shifted multiplicand approach also mirrors the manual multiplication algorithm directly, improving readability and conceptual alignment with the problem statement.

This fusion:
- Uses a 16-bit reg variable for accumulating the product.
- Starts with shifted_A initialized to A zero-extended to 16 bits.
- Adds shifted_A to the result if B[i] is high.
- Shifts shifted_A left by one bit each iteration.
- Assigns the result to output product.
  
This combines the best of both: the structured shift-and-add procedure (Example 1) and straightforward loop with minimal shifting overhead (Example 2).

This combinational implementation is clean, synthesis-friendly, and will generate efficient hardware with a single wide adder reused through the add operations in synthesis tools. It also balances complexity and understandability well.
