Implement the 8-bit multiplier using a procedural always_comb block that iterates over each bit of the multiplier B. For each bit set in B, the multiplicand A is shifted left by the bit index and added to an accumulator (product). This simulates the classic shift-and-add multiplication algorithm in a clear sequential manner within combinational logic. Unlike the previous balanced tree of adders, this approach uses a simple loop and an accumulator register to sum partial products, making the logic straightforward and intuitive. The module is purely combinational, with no sequential elements or blocking assignments, ensuring synthesis compatibility. This method is resource-efficient and clearly maps to the standard manual multiplication process, and can be easily understood and verified.
