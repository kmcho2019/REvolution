Implement the 8-bit multiplier using an iterative sequential approach within an always block, simulating the classical shift-and-add multiplication algorithm step-by-step in combinational logic. For each bit of the multiplier B (from LSB to MSB), if the bit is 1, add the multiplicand shifted by the bit position to an accumulating product register. This is done in a single combinational always block using a for-loop, producing the product in one cycle. This approach clearly models the shift-and-add procedure, is intuitive, and uses basic arithmetic and shifts only, without generating all partial products in parallel or using large adder trees.
