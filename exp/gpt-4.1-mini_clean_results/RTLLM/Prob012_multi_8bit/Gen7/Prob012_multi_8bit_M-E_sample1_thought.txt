Implement the 8-bit multiplier using an iterative, sequential shift-and-add method controlled by a simple clocked process:
- Use a register to accumulate the product.
- At each clock cycle, check the least significant bit of the multiplier.
- If it is 1, add the current multiplicand value to the product accumulator.
- Shift the multiplicand left by one bit after each iteration.
- Shift the multiplier right by one bit to move to the next bit.
- Repeat the above for 8 cycles.
This approach simulates the classic manual multiplication algorithm and allows a simple FSM or counter to control the operation.
Since the user did not specify a clock or reset, I will include them for proper sequential behavior.
The product output is valid after 8 cycles.
This design trades off latency for low area and power since only a single adder is used.
