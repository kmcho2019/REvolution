Implement an 8-bit multiplier using the classic shift-and-add method. For each bit in the multiplier B (from LSB to MSB), check if the bit is 1; if yes, add the current multiplicand (shifted accordingly) to the product. The multiplicand is shifted left by one bit after processing each bit of B. This can be done in a combinational always block or a for-generate loop to produce the final product in a purely combinational manner.
