Implement an 8-bit multiplier using the classic shift-and-add algorithm. Initialize the product to zero, then iterate through each bit of the multiplier B. If the current bit of B is 1, add the current multiplicand (shifted accordingly) to the product. After checking each bit, shift the multiplicand left by one for the next bit. This can be done combinationally by looping through bits of B and accumulating partial sums shifted as necessary. The final result is a 16-bit product.
