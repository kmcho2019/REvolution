Implement the 8-bit multiplier using an iterative shift-and-add process within a sequential logic block. The design uses a simple FSM: at each clock cycle, it checks the least significant bit of B; if set, adds the current value of A shifted appropriately to the running product. Then shifts B right by one and A left by one to prepare for the next bit. After 8 cycles, the multiplication is complete and the result is available. This approach uses minimal combinational logic, reduces critical path delay, and optimizes area since only a single adder is reused over 8 cycles. This design requires a clock and start signal to control operation, with a done signal indicating completion.
