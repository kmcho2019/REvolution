I will implement the 8-bit multiplier using an iterative shift-and-add algorithm in a purely combinational manner without generating all partial products simultaneously. The design will iterate over the bits of the multiplier B from least significant bit to most significant bit. For each set bit, the multiplicand A shifted appropriately will be added to an accumulator representing the product. This will be implemented using a simple for-loop inside an always_comb block. This approach is intuitive and maps closely to the manual multiplication process, using minimal resources and ensuring no redundant partial product computations. The combinational block will output the 16-bit product result.
