I will implement the 8-bit multiplier as a sequential shift-and-add multiplier using a simple finite state machine. Instead of generating all partial products and summing them in parallel, this design uses a clock and iterates through each bit of the multiplier B. On each clock cycle, if the current bit of B is 1, it adds the multiplicand A shifted appropriately to the accumulating product register. The multiplicand is shifted left at each iteration, simulating the shift-and-add multiplication algorithm step-by-step.

This approach:
- Uses a sequential process controlled by a clock and a counter.
- Requires fewer hardware resources (smaller area) since additions are performed serially.
- Outputs the product after 8 cycles.
- Uses input registers for A and B to stabilize inputs during operation.
- Includes a start signal and a done output signal to indicate multiplication completion.

This is a classic shift-and-add multiplier approach, trading off latency for area savings, suitable for designs where resource constraints matter more than throughput.
