Instead of a direct counter comparing against (freq - 1), implement a down-counter that reloads from freq on every toggle. This design counts down from freq to zero, and when zero is reached, toggles wave_out and reloads count with freq again. This approach removes the need for subtraction (freq - 1), using only equality to zero for toggle detection.  

If freq is zero, the counter halts and the output holds steady, preventing toggling at zero frequency. This also allows the possibility of easily changing freq dynamically without glitches since reload happens synchronously on zero count. The reload-and-count-down style provides a clean and intuitive finite state machine-like behavior for generating the square wave.

This method:
- Uses a synchronous down-counter to zero with reload on toggle.
- Has a clean toggle condition based solely on zero count.
- Avoids subtraction of 1, simplifying the logic.
- Holds wave_out steady when freq = 0 by gating the counter enable.
- Employs non-blocking assignments for synthesizable and reliable sequential logic.
- Starts with count initialized to zero (or freq) on reset to define a known starting state.
