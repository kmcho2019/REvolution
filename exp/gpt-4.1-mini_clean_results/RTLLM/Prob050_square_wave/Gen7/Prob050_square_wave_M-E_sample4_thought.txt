Implement the square wave generator using a down-counter that loads the freq value and counts down to zero. When the counter reaches zero, the wave_out signal toggles and the counter reloads with the freq value. This approach eliminates the need for subtracting freq - 1 by counting down directly from freq, simplifying the comparison to zero.

Additionally, the design omits an explicit reset signal, initializing wave_out and count to zero on simulation start. If freq is zero, the counter is disabled and wave_out stays constant.

This countdown approach provides a more intuitive flow: each cycle decrements count; when zero is reached, toggle output and reload count, producing a square wave toggling every freq clock cycles.
