Implement a square wave generator using a countdown timer approach instead of a counting-up counter. On each clock cycle, decrement a countdown register initialized to freq. When countdown reaches zero, toggle the output wave and reload the countdown with freq again. This reduces the comparison logic to checking for zero, simplifying the combinational logic. 

Additionally, implement an asynchronous active-high reset for immediate initialization. If freq is zero, freeze the output wave and keep countdown at zero, effectively disabling toggling.

This approach uses fewer comparators and simpler control logic, which may improve timing and reduce power by minimizing toggling of internal signals. The countdown logic also naturally handles the toggling interval without needing an explicit count-to-(freq-1) comparison.
