I will implement the radix-2 divider using a classic restoring division algorithm with a well-defined FSM: IDLE, RUN, and DONE states. 

- When opn_valid is asserted and module is idle, inputs are latched. If signed division, inputs are converted to absolute values and signs saved. 
- A 17-bit shift register is initialized with the dividend shifted left by one bit (to allow one extra bit for shifting), quotient bits accumulated in lower bits and remainder in upper bits.
- A counter tracks 8 division iterations.
- Each cycle:
  - Shift left the remainder-quotient register by 1 bit.
  - Subtract the divisor from the remainder.
  - If subtraction is non-negative, set quotient LSB = 1, keep the subtraction result as remainder.
  - Else, restore the old remainder and set quotient LSB = 0.
- After 8 cycles, apply sign correction for quotient and remainder if signed division.
- Division by zero case: quotient = max unsigned (0xFF), remainder = dividend (signed or unsigned as per sign input).
- Handshaking is done via res_valid (output) and res_ready (input). res_valid asserts when division is done, cleared when res_ready and no new operation requested.
- Reset clears state and outputs.
  
This approach simplifies tracking remainder and quotient with a single shift register and an FSM to handle multi-cycle division, fully synchronous and suitable for synthesis.

I will precisely map bits of the shift register: 
- bits [16:8] remainder (9 bits, upper bit used for carry/borrow during subtraction),
- bits [7:0] quotient.

In each cycle, we left shift shift_reg by 1 and perform subtraction trial on the remainder part.

The module interface includes res_ready input to handle handshake, as hinted.

This fully synchronous FSM radix-2 divider will be clear, robust, and easy to verify.
