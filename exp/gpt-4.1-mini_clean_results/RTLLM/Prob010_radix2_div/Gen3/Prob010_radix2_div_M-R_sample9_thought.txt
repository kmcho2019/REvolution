Refactor the radix-2 divider to a clean state machine with separate states IDLE, CALC, and DONE. Use registers to hold absolute values of dividend and divisor, signs, and the shift register.

The division iterations will be done in CALC state, iterating 8 times shifting and subtracting. The result validity flag is set in DONE state and cleared when starting a new operation.

Use assign statements for some combinational signals like subtraction result and borrow flag. Use synchronous logic for state transitions and register updates.

By explicitly managing states, code readability and control flow clarity improve. Sign correction is done once division completes, before asserting res_valid.

This method also separates data path and control path cleanly, making simulation and synthesis clearer and more robust.

This avoids combinational always @(*) blocks with internal regs for subtraction and borrow; instead, perform subtraction as continuous assignment from current remainder and divisor_abs.

The 17-bit SR holds remainder (9 bits) and quotient (8 bits). At each cycle, we shift left by 1, subtract divisor_abs from remainder, update quotient bit based on borrow.

Result is output as {remainder[7:0], quotient[7:0]} in a single 16-bit register after sign correction.
