Implement a synchronous radix-2 divider using a 17-bit shift register SR holding remainder (upper 9 bits) and quotient (lower 8 bits). On opn_valid (and not busy), capture inputs, compute absolute values (if signed), initialize SR with dividend_abs shifted left by 8, divisor_abs, and start counter. Each clock cycle, shift SR left by 1, subtract divisor_abs from the remainder part; if subtraction is non-negative, update remainder and set quotient bit to 1, else keep remainder and set quotient bit to 0. After 8 cycles, adjust quotient and remainder signs based on input signs if signed division, then assert res_valid with combined result. Manage handshake signals to allow new operations after result consumption. Declare all regs/wires at module level, perform calculations in sequential logic without declaring variables inside always blocks. This simpler approach keeps design clear, correct, and synthesizable.
