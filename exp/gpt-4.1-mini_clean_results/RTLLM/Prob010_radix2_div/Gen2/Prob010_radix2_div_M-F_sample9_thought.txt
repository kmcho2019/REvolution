To fix the syntax errors, all temporary variables used inside the always block must be declared at the module level, not inside the procedural block. We separate combinational calculations from sequential updates by using wire and reg variables properly.

The design keeps the main iterative division in a single clocked always block with registers declared upfront. Intermediate calculations such as shifted SR, subtraction results, and borrow flags are done using wires or assigned before sequential updates.

We use a 17-bit register SR to hold remainder (upper 9 bits) and quotient (lower 8 bits). At each cycle, we shift SR left by 1, then subtract divisor_abs from the remainder portion; if no borrow, we update remainder and set quotient bit to 1, else keep remainder and quotient bit 0.

Sign handling is done by storing operand signs at start, performing unsigned division on absolute values, then correcting quotient and remainder signs at the end.

Finally, we manage res_valid and working flags to synchronize start and completion of operations and ensure result consumption before starting new division.

This way, the design is synthesizable, clear, and free of syntax errors.
