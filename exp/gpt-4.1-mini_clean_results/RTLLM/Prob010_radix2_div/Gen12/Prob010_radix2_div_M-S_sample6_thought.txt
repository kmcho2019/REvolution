Implement a straightforward radix-2 restoring division with a simple synchronous process triggered on opn_valid.  
On opn_valid, capture inputs, compute absolute values and sign flags if signed division is selected.  
Use a 17-bit shift register SR to hold remainder (upper 9 bits) and quotient (lower 8 bits).  
Perform 8 iterations of shift-subtract per clock cycle: shift left SR by 1, subtract divisor from remainder.  
If subtraction succeeds (no borrow), update remainder and set quotient bit to 1, else restore remainder and set quotient bit to 0.  
After 8 iterations, apply sign corrections to quotient and remainder if signed mode.  
Output 16-bit result with remainder in upper 8 bits and quotient in lower 8 bits.  
Use a simple counter for iteration and a valid flag.  
Keep code readable, avoiding variable declarations inside always blocks and complex FSM; manage process flow via start flag and counter.  
Reset and result valid signals handled cleanly.
