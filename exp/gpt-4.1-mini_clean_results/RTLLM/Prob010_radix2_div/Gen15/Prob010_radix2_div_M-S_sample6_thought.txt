Implement a straightforward radix-2 restoring divider for 8-bit signed/unsigned inputs with synchronous operation and clear state control:

- Use a simple FSM with IDLE, RUN, DONE states.
- On opn_valid in IDLE, latch inputs, compute absolute values for signed operation, initialize a 17-bit shift register with remainder=0 and quotient=abs(dividend).
- On each clock cycle in RUN, perform one step of radix-2 restoring division:
  * Shift left the combined remainder and quotient.
  * Subtract divisor from remainder; if no borrow, keep remainder result and set quotient bit to 1; else restore remainder and set quotient bit to 0.
- After 8 iterations, in DONE state, fix sign of quotient and remainder if signed operation.
- Output result with remainder in upper 8 bits, quotient in lower 8 bits.
- Provide res_valid output only in DONE.
- Reset clears all states.
This approach reduces complexity by avoiding multiple always blocks, complex concatenations, and uses a clean FSM with minimal registers.
