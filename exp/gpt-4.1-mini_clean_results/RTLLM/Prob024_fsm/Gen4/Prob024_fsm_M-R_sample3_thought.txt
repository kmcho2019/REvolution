Refactor the Mealy FSM to use an explicit Moore-style registered state machine with next-state and output registers. Implement the next-state and output logic in a single always_comb block to separate combinational logic, and update state and output synchronously on clock. This improves timing predictability by making MATCH registered rather than purely combinational, while maintaining the same detection behavior and continuous overlapping detection. This style also cleanly separates combinational and sequential logic and can improve synthesis tool friendliness and ease of timing closure.
