Implement the Mealy FSM using a shift register approach that captures the last 5 bits of input on each clock edge, and compare the stored bits against the target pattern "10011" to generate MATCH. This simplifies the FSM design by avoiding explicit state encoding; instead, the state is represented implicitly by the shift register contents. To enable continuous and overlapping detection, the shift register slides on every clock cycle, continuously comparing the current 5-bit window with the sequence. RST synchronously clears the shift register and resets MATCH. This architecture trades off state machine complexity for a simple shift register and combinational comparator, easing design and verification.
