Refactor the FSM to use a binary encoded state machine instead of one-hot encoding to reduce the number of flip-flops and simplify synthesis. Separate the next state logic and output logic clearly: calculate next state and MATCH as pure combinational signals from the current state and input. Register only the state on the clock edge and generate MATCH as a registered output synchronized to the clock, thus avoiding conflicting combinational and sequential assignments. Also, default next_state to current state to prevent unintended resets. This clean separation and binary state encoding improve clarity, synthesis friendliness, and efficiency, while preserving the Mealy FSM semantics and supporting overlapping detection.
