I will implement the Mealy FSM detection circuit using one-hot state encoding for simplicity and clarity. The FSM will have six states representing each prefix of the detected sequence "10011". The state transitions and output MATCH logic will be implemented in a single always block that triggers on the positive edge of CLK or when RST is asserted. This approach uses explicit state registers for each state bit, reducing decoding complexity and potentially improving timing by minimizing combinational logic depth.

The MATCH output will be registered and asserted synchronously when the FSM reaches the final state and the input bit matches the final bit of the sequence (which is '1'), as per Mealy behavior. This allows immediate output update with input.

Supporting continuous input and loop detection is handled by the state transitions designed to move to the correct prefix state upon mismatched input, enabling overlapping pattern detection.

This approach cleanly separates reset logic, next state, and output generation inside one sequential block, ensuring synchronous operation and easy testability.
