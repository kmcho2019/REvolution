I will implement the Mealy FSM detection circuit by using a case statement inside a single always block for the next-state and output logic together, keeping the state transitions and output assignments tightly coupled. The output MATCH will be a registered output that updates synchronously with the clock to avoid glitches on the output signal, which can be beneficial in some hardware implementations.

The states will be encoded as localparams, and the state and next-state logic will reside inside the always @(posedge CLK or posedge RST) block with synchronous reset. This approach improves readability by using a clear and structured case statement while preserving the Mealy output behavior by updating MATCH on the clock edge based on the current state and input. The design supports continuous input stream with overlapping sequence detection.
