To simplify the Mealy FSM detection for the sequence 10011 with continuous and overlapping detection, I will use a single always block triggered on the clock and reset. The state will be encoded in binary using a 3-bit register with states representing how many correct bits in the sequence have been matched so far. On each clock, the FSM transitions based on the current input and state, allowing overlaps by transitioning to intermediate states accordingly. The MATCH output will be a registered signal set to 1 only when the last input matches the final bit of the sequence in the correct state; otherwise, it remains 0. This reduces combinational complexity by merging next-state and output logic in a single synchronous process, improving clarity while preserving all functionality.
