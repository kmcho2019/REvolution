Implement the Mealy FSM using a shift register approach combined with a parallel comparator for sequence detection. The FSM state represents how many bits of the target sequence have been matched so far, but rather than explicit state encoding, use a shift register of length 5 that shifts in input bits every clock. Then, the MATCH output is generated whenever the content of the shift register matches the pattern "10011". This approach simplifies the FSM to a shift register plus comparator, supporting overlapping and continuous input detection naturally, and avoids explicit multi-state coding. MATCH is asserted synchronously at the clock edge when the sequence is detected.
