Implement a Mealy FSM with states representing the progress through the sequence "10011". Each clock cycle checks the input IN and transitions accordingly to the next state or an appropriate fallback to allow overlap detection. The MATCH output is combinational and asserted when the FSM reaches the final state on seeing the last '1' in the sequence. The FSM is synchronous with asynchronous reset, updating state on positive clock edge. The output MATCH is 1 only when the last input '1' completes the sequence.
