Implement a Mealy FSM to detect the sequence 10011 on a single input bit. The FSM will have states representing how much of the sequence has been matched so far. On each clock cycle, the FSM transitions based on the current input bit. When the last bit of the sequence is matched, the output MATCH is asserted for one clock cycle. The FSM supports overlapping detection, allowing continuous input sequences where the pattern can be detected multiple times (e.g., 100110011). The FSM is synchronous with asynchronous reset (RST), and MATCH is deasserted on reset or when no match occurs.
