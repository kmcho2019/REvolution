Implement a Mealy FSM that detects the sequence 1,0,0,1,1 on input IN. The FSM advances through states representing how much of the sequence has matched so far. On matching the full sequence at the current IN input (fifth bit '1'), output MATCH is asserted for one clock cycle. The FSM supports overlapping detection (loop detection) by transitioning to appropriate intermediate states after a match. Use synchronous reset and output MATCH in the same clock cycle as input IN that completes the sequence.
