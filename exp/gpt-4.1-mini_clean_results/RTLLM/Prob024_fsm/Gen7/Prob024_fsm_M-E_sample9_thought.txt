Use a Mealy FSM with six states, each representing how many bits of the pattern "10011" have been matched so far. The FSM transitions on each clock cycle with the input bit IN. On reaching the final state indicating that the full sequence "10011" has been matched, the MATCH output is asserted in the same clock cycle.

To support overlapping detections and looping, after a full match, the FSM transitions to a state representing the longest proper prefix of the pattern that is also a suffix (i.e., partial match of "11" at the end), so that detection can continue seamlessly.

The MATCH output is generated combinationally based on the current state and input, characteristic of a Mealy FSM.

This approach ensures continuous detection with minimal states, clear next state logic, and immediate assertion of MATCH when the pattern is detected.
