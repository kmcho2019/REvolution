Use a purely synchronous Mealy FSM with one-hot style state encoding in a shift-register approach to track sequence progress. The FSM state represents how many bits of the sequence "10011" have been matched so far. The next state is updated synchronously at each clock edge based on the current input, and the MATCH output is driven combinationally from the next state and current input. This approach ensures MATCH is asserted exactly when the full sequence is matched on the last input bit. Overlapping detection is naturally supported by proper next state transitions reflecting the sequence prefix overlaps.
