Implement the Mealy FSM using a one-hot state encoding to simplify next state logic and improve clarity. Each state corresponds to a specific point in the sequence detection progress of "10011". The FSM transitions on each clock cycle with input IN and updates MATCH combinationally based on the current state and input, asserting MATCH exactly when the last bit of the sequence is detected. Overlapping patterns are supported by carefully designing transitions to previous states representing partial matches. This approach simplifies logic expressions and can facilitate timing optimizations.
