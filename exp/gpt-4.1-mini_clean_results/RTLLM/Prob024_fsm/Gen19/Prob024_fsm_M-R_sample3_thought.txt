Refactor the FSM to use an always_comb block for next_state and output logic, and an always_ff block for synchronous state update and output register. This way, the output MATCH is registered (synchronous Mealy style) to reduce glitches on output, which is a common design practice. The next state and MATCH combinational logic are separated clearly in an always_comb block with case statements for better readability and maintainability. The state encoding and transitions remain the same, still supporting overlapping detection of sequence 10011 with MATCH asserted on last input bit of the sequence.
