I will refactor the FSM implementation to use an explicit binary-encoded state machine instead of one-hot encoding. This means encoding the five states (S0 to S4) as a 3-bit state variable, which reduces flip-flop count and can help minimize logic complexity. The next state and output logic will be implemented with combinational `always @(*)` using a `case` statement for clarity.

MATCH remains a Mealy output, asserted when the machine is in state S4 and input IN is 1.

This approach improves area efficiency and modularity of the FSM while preserving continuous overlapping detection of the sequence "10011".
