I will implement the Mealy FSM using a shift register style approach internally to track the recent history of inputs and state transitions. Instead of explicitly enumerating states as a binary or one-hot encoded FSM, I will use a 3-bit shift register to hold the last three inputs and a separate 2-bit state register to track the progress in matching the prefix "100" before the final '11' tail.

This hybrid approach lets me maintain a compact state encoding while incorporating input history for efficient overlapping sequence detection.

Key points:
- Use a 3-bit shift register to hold recent inputs for easier detection of the "100" prefix in the sequence.
- Use a 3-bit state register encoding the progress through the sequence "10011" (to track how many bits matched).
- The MATCH output is asserted when the last two bits match the ending "11" with the previous prefix detected.
- The logic supports overlapping sequences naturally as inputs shift in every clock.
- Synchronous reset initializes the FSM and shift register.

This approach blends shift-register input buffering with a small FSM state machine for simplicity and good performance.
