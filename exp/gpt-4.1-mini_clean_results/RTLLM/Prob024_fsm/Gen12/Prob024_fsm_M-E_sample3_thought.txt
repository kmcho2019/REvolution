Implement the Mealy FSM as a Moore machine with an additional output combinational logic to generate MATCH signal, but track the input sequence using a shift register that holds the last 5 input bits. On each clock, shift in the current IN bit; then use combinational logic to compare the shift register content with the pattern 10011 and set MATCH accordingly. This approach removes explicit FSM states and relies on a small shift register plus pattern matching logic, simplifying state encoding and making the design more data-driven while supporting continuous and overlapping detection. The synchronous reset clears the shift register and MATCH output. This novel architectural idea leverages pattern matching via shift registers instead of state machines, reducing control complexity.
