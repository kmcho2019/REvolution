To simplify the odd frequency divider, use a single counter that increments on the positive edge of the input clock. Since NUM_DIV is odd, count from 0 to NUM_DIV-1. Toggle the output clock (clk_div) whenever the counter reaches the halfway point (floor(NUM_DIV/2)) or the terminal count (NUM_DIV-1), and then reset the counter. This produces a divided clock with roughly 50% duty cycle by toggling twice per full count cycle. Using one counter and one toggle signal reduces complexity and avoids dual-edge logic. The reset initializes counter and output clock. This approach still achieves frequency division by an odd number with good duty cycle and simpler logic.
