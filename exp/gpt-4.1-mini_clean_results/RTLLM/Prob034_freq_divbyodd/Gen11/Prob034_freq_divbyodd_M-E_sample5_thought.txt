An alternative approach to divide an input clock by an odd number is to use a single counter that counts clock edges from 0 to NUM_DIV - 1. Since NUM_DIV is odd, we cannot achieve a 50% duty cycle perfectly, but we can approximate it by generating an output clock that toggles at specific counter values to produce a symmetrical waveform as much as possible.

Here's the approach:

1. Use a single counter that increments on every rising edge of the input clock and resets after reaching NUM_DIV - 1.

2. The output clock `clk_div` toggles twice within one counting period to produce a clock frequency divided by NUM_DIV. The toggling points are:

   - When the counter equals floor(NUM_DIV/2), toggle `clk_div`.
   - When the counter equals NUM_DIV - 1, toggle `clk_div`.

3. This toggling creates a divided clock with period NUM_DIV input clock cycles and a duty cycle approximating 50%, which is the best achievable with an odd divisor.

4. The active low reset initializes the counter and `clk_div` output.

This method uses only one counter and one output register, simplifying the design and making it easy to understand and implement. It avoids the complications of having two counters and combining their outputs.

The code includes a compile-time check that NUM_DIV is odd, a parameter for NUM_DIV defaulting to 5, and uses `$clog2` for counter width calculation.
