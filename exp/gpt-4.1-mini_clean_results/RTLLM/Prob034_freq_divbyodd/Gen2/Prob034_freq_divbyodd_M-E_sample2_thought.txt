To reliably divide an input clock by an odd number, we can generate a symmetrical waveform by toggling the output clock at precise counts corresponding to the odd divisor's half cycles.

Key idea:
- Use a single up-counter that counts from 0 to NUM_DIV-1 repeatedly.
- Toggle the output clock at counts equal to half the divisor (floor(NUM_DIV/2)) and at the end of the full count (NUM_DIV-1).
- This toggling creates an output clock with a frequency 1/NUM_DIV of the input clock and a near 50% duty cycle even for odd divisors.
- Since toggling happens on a single clock edge (posedge clk), the output will be properly synchronized.
- The output clk_div toggles twice per full input clock cycle period * NUM_DIV, producing the desired frequency division by an odd number.

Advantages:
- Simpler than dual-edge counters and avoids mismatched phase problems.
- Only one counter and output register needed.
- Toggles output at defined counter values to create balanced waveform.
- Proper reset initializes output clock low and counter zero for deterministic startup.

This approach generates an accurate frequency divider for odd divisors using a single counter and well-defined toggle points.
