Refactor the design to use a single always block on the positive edge to maintain counters and clock dividers, but internally simulate the negative edge counter by sampling the clock with a small delay or using a generated delayed version, which is not synthesizable; so instead, implement a synchronous state machine with a single counter and a state variable that tracks the phase to generate the divided clock output for odd division.

The idea is:

- Use a single counter counting from 0 to NUM_DIV-1 at posedge clk.
- Use a state register to toggle clk_div at counts representing the edges to produce a 50% approximate duty cycle for the odd division.
- Generate clk_div by toggling when counter reaches zero, and toggling again when the counter reaches HALF_DIV count.
- This produces a duty cycle close to 50% for odd division.

This avoids using negedge clock domain, simplifies timing, and keeps the design single-clocked.

Also implement synchronous active-low reset and a compile-time oddness check using generate block.

This structure reduces complexity and can ease timing closure and reduce glitches.
