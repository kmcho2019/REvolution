Refactor the ALU to use a single combinational always block with a case statement for result selection and flag calculations, instead of computing all results in parallel with wires and a big multiplexer. This allows only relevant logic to activate per operation, potentially reducing power and improving timing by avoiding unnecessary calculations. Intermediate values for carry and overflow are computed within the always block only when needed. Outputs are assigned from registers updated in this block. This RTL style balances clarity and control flow with synthesis friendliness. The flag output is set to 'z' (high-impedance) when not SLT/SLTU to match the original spec. Shift amounts are taken from a[4:0]. The LUI operation uses upper 16 bits of 'a' concatenated with 16 zeros as specified.
