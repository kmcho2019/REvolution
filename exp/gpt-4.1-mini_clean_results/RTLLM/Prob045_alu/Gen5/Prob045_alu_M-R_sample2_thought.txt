Refactor the ALU to use continuous assignments and intermediate wires instead of an always block. Compute all possible operation results in parallel and then select the final output and flags using a combinational multiplexer based on `aluc`. This approach leads to a more structural, datapath-like design where operations occur in parallel and the output mux selects the desired result. Carry and overflow flags are computed for arithmetic operations only and zero/negative flags derive from the selected result. The `flag` output is set to the comparison results or high impedance as before. This structure simplifies combinational logic visibility and can assist synthesis and formal tools with easier reasoning about concurrent operations.
