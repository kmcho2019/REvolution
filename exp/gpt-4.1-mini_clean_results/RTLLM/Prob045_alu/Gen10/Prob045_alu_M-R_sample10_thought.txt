Refactor the ALU design to use continuous assignments and combinational logic with intermediate wires instead of an always block. Compute each operation result in a separate wire, then select the final result and flags using a combinational mux based on the opcode. This approach clearly separates the computation and selection logic, improving code modularity and readability. It also uses signed versions of inputs for arithmetic comparisons. Carry and overflow signals are computed only for relevant operations, defaulting to zero otherwise. The flag is set explicitly for SLT and SLTU, and zero, negative, and overflow outputs are derived from the selected result. This style enables better combinational logic inference with less reliance on blocking assignments.
