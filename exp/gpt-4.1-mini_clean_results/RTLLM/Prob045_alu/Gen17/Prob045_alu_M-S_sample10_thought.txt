Simplify the ALU by using a single always_comb block with a case statement to select the operation, directly assigning the outputs inside the case branches. Calculate carry and overflow only for ADD/SUB variants; for other operations, these flags are zero. Compute the SLT/SLTU flags inside the same block and set the flag output accordingly. Use signed arithmetic for comparisons and arithmetic shifts. Derive zero and negative flags from the result outside the always block. This approach keeps the design clear and easily readable with less intermediate signals while preserving functionality.
