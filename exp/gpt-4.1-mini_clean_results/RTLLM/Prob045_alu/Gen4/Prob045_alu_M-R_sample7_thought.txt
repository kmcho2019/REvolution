Refactor the ALU as a single combinational always block with a case statement selecting the operation by `aluc`. Compute result and flags inside the always block, storing result in a reg variable and flags in reg variables as well. Then assign these regs to outputs outside the always block. This approach keeps the design straightforward and synthesizable, closely matching typical textbook ALU implementations, and clearly shows how each operation affects carry and overflow. The flag output is set to 'z' (high-impedance) for non-SLT/SLTU ops by using a tri-state assign with continuous assignment outside the always block, so `flag` behaves exactly as specified. This refactor trades parallel combinational logic for a muxed combinational block, improving readability of the operation selection while retaining combinational behavior.
