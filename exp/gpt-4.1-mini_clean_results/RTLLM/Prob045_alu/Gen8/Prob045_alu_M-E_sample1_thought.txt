Implement the ALU using a two-stage approach to minimize redundant parallel computations and improve clarity:

1. Decode the `aluc` opcode first to identify the operation type.
2. Perform only the necessary arithmetic or logical computation in a single combinational always block:
   - Use a single adder/subtractor unit for ADD, ADDU, SUB, SUBU by reusing an arithmetic module with a control signal.
   - Use a separate combinational block for logical and shift operations.
   - Use conditional shifts with variable or fixed shift amounts based on the opcode.
3. Generate flags (carry, overflow, negative, zero, and flag) precisely for the executed operation.
4. For SLT and SLTU, compute the comparison and assign `flag` accordingly; otherwise set it to high impedance `'z'`.
5. Avoid driving the `r` output as high impedance; instead, assign zero for undefined opcodes.
6. Use signed/unsigned casting only where necessary to ensure MIPS semantics.
7. Encapsulate the arithmetic operation in a small internal function for clarity and reuse.

This design limits combinational logic to only what is needed per operation, reduces power by avoiding computing all possible ops in parallel, and clarifies flag computations by associating flags only with the relevant operations. It also respects the original requirement that `flag` is 'z' except for SLT/SLTU.

The design remains fully combinational and suitable for synthesizable MIPS ALU implementation.
