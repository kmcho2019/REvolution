Implement a combinational ALU that performs arithmetic, logical, shift, and set operations based on the 6-bit opcode (aluc). The module outputs the 32-bit result and flags indicating zero, carry, negative, overflow, and a special flag for SLT/SLTU. For arithmetic, use 33-bit addition/subtraction to detect carry. Overflow is detected for signed addition/subtraction. For shifts, use lower 5 bits of 'a' as the shift amount for variable shifts. For LUI, output is {b[15:0], 16'b0} as per MIPS convention (corrected to load upper immediate from b). The flag output is high-impedance ('z') except for SLT and SLTU, where it signals set condition. Default outputs 'z' on unmatched opcode.
