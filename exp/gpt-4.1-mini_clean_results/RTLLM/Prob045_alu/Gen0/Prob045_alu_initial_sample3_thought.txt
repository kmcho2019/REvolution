Implement an ALU module that supports the specified MIPS-ISA operations based on the aluc opcode. Use parameters for the opcodes. Decode the opcode in an always @* block with a case statement. For each operation, compute the result accordingly. Handle carry and overflow for arithmetic instructions. For SLT and SLTU, output the flag as 1 if condition is true, otherwise 0. For other instructions, flag is high impedance 'z'. The zero flag is set if the result is zero. Negative is set if the result MSB is 1. The carry is generated only from add and subtract operations; for other instructions, it is 0. Overflow is set for signed add/sub operations. For shift instructions, use appropriate bits of 'a' as shift amount or for shift instructions with immediate shift amount, use b[4:0]. For LUI, place b in upper 16 bits with lower 16 zero. If opcode is unrecognized, set output to high impedance 'z'.
