Implement a combinational ALU module with parameters defining each MIPS ALU opcode. The module takes two 32-bit operands `a` and `b`, and a 6-bit control opcode `aluc`. Internally, signed and unsigned versions of the inputs and the result are used to properly handle arithmetic and comparison operations. The `always @*` block performs the operation specified by `aluc`. Special cases include handling carry out for addition and subtraction, overflow detection for signed arithmetic, and setting the `flag` output only for SLT and SLTU operations (high-Z otherwise). Shift amounts are derived from `a[4:0]` or `b[4:0]` depending on the instruction. The outputs `zero`, `carry`, `negative`, and `overflow` are derived from the final result and operation. If `aluc` is not recognized, the result outputs `z` for all bits. This design covers all requested operations with correct behavioral semantics and status flags.
