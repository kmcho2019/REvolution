Implement a combinational ALU module with 32-bit inputs a and b, and a 6-bit control signal aluc. Use a case statement to select the operation based on aluc. Calculate the result r and additional status signals: zero (r==0), negative (r[31]), carry (for addition/subtraction), overflow (for addition/subtraction), and flag (for SLT and SLTU). For SLT and SLTU, flag is set to 1 or 0 based on comparison; for other operations flag is high-Z. Use signed operations for overflow detection and signed comparisons for SLT. Shift operations use lower 5 bits of 'a' as shift amount. LUI loads b's lower 16 bits shifted left by 16. Default output is high-Z.
