Use a simple two-cycle buffering scheme: store the first valid 8-bit input in a register; when the second valid 8-bit input arrives, form a 16-bit output with the first input in the upper 8 bits and the second input in the lower 8 bits. The output valid_out and data_out are registered and appear exactly one cycle after the second valid input arrives. If valid_in arrives during the output cycle, start storing it as a new first input for the next output. This approach requires only a small state tracking (a single flag), avoids complex FSMs, and meets the timing requirements clearly and simply.
