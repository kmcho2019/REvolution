Implement a two-stage FIFO-like buffering approach with a simple state machine to manage the data input and output timing:

- Use two 8-bit registers: `first_data` to store the first arriving valid input, and `second_data` to store the second arriving valid input.
- Use a state flag `waiting_second` to indicate whether the module is waiting for the second input.
- When the first valid input arrives (valid_in=1 and waiting_second=0), store it in `first_data` and set `waiting_second=1`.
- When the second valid input arrives (valid_in=1 and waiting_second=1), store it in `second_data` and set `output_ready=1`.
- On the next clock cycle after `output_ready=1`, output the concatenated data `{first_data, second_data}` on `data_out` and assert `valid_out=1`.
- Then clear `waiting_second` and `output_ready` to prepare for new input.
- If valid_in=0, just hold current state.
- On reset, clear all registers and flags.

This method uses a minimal FSM concept and separates data capture from output generation clearly, ensuring `valid_out` and `data_out` are asserted only in the cycle after receiving the second valid input, matching the timing requirements precisely. It also inherently handles consecutive data pairs without ambiguity.
