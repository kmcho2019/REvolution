Use a simple toggle-based approach without explicit FSM states. The module stores the first valid 8-bit input in a register and sets a flag indicating that one byte is stored. When the next valid input arrives, concatenate the stored byte (as higher 8 bits) and the new byte (lower 8 bits) into a 16-bit register, assert valid_out in the following clock cycle, and clear the flag. This way, the module alternates between storing the first byte and outputting the concatenated result on every pair of valid inputs. The output data and valid_out are registered and generated one cycle after the second valid input as required. Reset clears all internal registers and flags.
