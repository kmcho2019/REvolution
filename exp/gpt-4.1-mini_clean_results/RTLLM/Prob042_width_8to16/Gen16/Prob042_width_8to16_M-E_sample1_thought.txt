Implement a simple two-state FSM to handle input bytes. In the IDLE state, when a valid_in arrives, store it in a register and transition to WAIT state without generating output. In the WAIT state, upon receiving the second valid_in, concatenate the stored byte (high bits) with the new input (low bits) and assert valid_out and data_out in the *next* clock cycle via a registered pipeline stage. This separates the output assertion by one cycle from the second input arrival, meeting the timing requirement. After outputting, return to IDLE. Reset clears all registers and resets state. This approach cleanly separates input buffering and output generation, preventing combinational feedback and ensuring a single-cycle latency after both inputs.
