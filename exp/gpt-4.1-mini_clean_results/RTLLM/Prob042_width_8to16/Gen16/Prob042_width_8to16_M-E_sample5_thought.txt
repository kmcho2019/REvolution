Implement a design using a simple single-bit flag to track whether the first byte has been stored. When a valid input arrives and the flag is clear, store the first byte in a register and set the flag. On the next valid input when the flag is set, concatenate the stored byte with the current input byte and output the 16-bit data and assert valid_out in the following clock cycle. Then clear the flag. This approach avoids explicit FSM states by using a flag and pipelined output registers to ensure valid_out and data_out are delayed one cycle after the second input arrives. It keeps the design simple and meets timing requirements without complex state machines.
