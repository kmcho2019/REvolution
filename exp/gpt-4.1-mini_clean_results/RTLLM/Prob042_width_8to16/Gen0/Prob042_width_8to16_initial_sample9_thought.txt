Implement a stateful data width converter that collects two consecutive 8-bit valid inputs before outputting a single 16-bit concatenated data with a valid flag in the next clock cycle. Use a register (data_lock) to store the first 8-bit input when valid_in is high and a flag to indicate the first data has been stored. Upon the next valid_in, concatenate the stored first 8-bit data as the higher byte and the new 8-bit input as the lower byte to form data_out. The valid_out signal will be asserted in the next clock cycle after the second 8-bit data arrives. On reset, clear all registers and flags.
