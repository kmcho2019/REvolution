Use a flag to indicate whether the first 8-bit data has been stored. On each valid_in, if flag is 0, store the data_in in an 8-bit register (data_lock) and set flag to 1, indicating that the first data is stored and waiting for the second. On the next valid_in, when flag is 1, concatenate the stored data_lock (higher 8 bits) and current data_in (lower 8 bits) to form data_out and assert valid_out in the next clock cycle. After output, reset flag to 0 for the next conversion. valid_out and data_out are registered outputs, updated on clock edge, valid_out asserted only when two valid data inputs have been received consecutively.
