Use a flag register to track if the first 8-bit data has been received. On each valid input, if the flag is 0, store the data in a temporary register (data_lock) and set the flag. If the flag is 1 and valid_in is high, concatenate the previously stored data (higher 8 bits) with the current input (lower 8 bits), register this output in data_out, assert valid_out in the next clock cycle, then reset the flag for the next pair. On reset, clear data_out, valid_out, data_lock and flag.
