Implement a two-stage storage and output scheme: when a valid 8-bit input arrives, store it in a register (data_lock). Use a flag to track whether this is the first or second input. When the second valid 8-bit data arrives, concatenate the previously stored data_lock (higher 8 bits) with the new data_in (lower 8 bits) and output this 16-bit data along with asserting valid_out in the next clock cycle. The valid_out and data_out are registered outputs, appearing one clock cycle after the second input arrives. On reset, clear all registers and flags.
