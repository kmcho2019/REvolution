Implement a two-stage data latch using a flag to track when the first 8-bit data is stored. On each valid_in, if the flag is not set, store the 8-bit data in data_lock and set the flag. If the flag is set and a new valid_in arrives, concatenate data_lock (higher 8 bits) and data_in (lower 8 bits) to form 16-bit data_out and set valid_out on the next clock cycle. Reset clears all registers. The output valid_out and data_out are registered and delayed by one cycle after the second data_in arrives.
