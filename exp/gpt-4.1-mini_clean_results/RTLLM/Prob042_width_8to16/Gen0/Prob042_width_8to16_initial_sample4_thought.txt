Use a flag to track whether the first 8-bit data has arrived and is stored. On each clock, if reset is active, clear all registers and outputs. When a valid input arrives and the flag is not set, store the input in data_lock and set the flag. When another valid input arrives and the flag is set, concatenate data_lock (higher 8 bits) and current data_in (lower 8 bits) to data_out, set valid_out high for one cycle, then clear the flag to wait for new data. valid_out and data_out are generated one cycle after receiving the second input due to the synchronous register update.
