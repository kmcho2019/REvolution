Use a simple 1-bit flag to track if the first byte has been received and stored. On each valid_in, if the flag is clear, store the input byte in a register and set the flag. If the flag is set (meaning this is the second byte), concatenate the stored byte and current byte, and set a valid_out flag to be asserted in the next clock cycle. In that next clock cycle, valid_out is asserted and data_out holds the concatenated 16-bit value. Then clear the flag to prepare for the next pair. This approach uses only registers and simple control logic without an explicit FSM, directly fulfilling the timing requirement that output valid_out and data_out are generated one cycle after the second input arrives.
