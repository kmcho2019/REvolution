Use a simple toggle flag to indicate if the first byte has been received and stored. On each valid_in, if the flag is clear, store the byte in data_lock and set the flag. If the flag is set, concatenate the stored byte (as high 8 bits) and current input byte (as low 8 bits), store it in a register, assert valid_out in the next cycle, clear the flag, and update data_out accordingly. This approach ensures valid_out and data_out assert one cycle after two valid inputs, with minimal state and straightforward logic.
