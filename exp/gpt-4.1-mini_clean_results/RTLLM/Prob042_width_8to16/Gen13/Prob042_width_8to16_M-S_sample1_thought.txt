Use a simple state flag (data_lock) and a register to store the first 8-bit input. On each valid input, if no first byte is stored, save it and set data_lock. If the first byte is stored, on next valid input, concatenate stored and new byte, and produce valid_out and data_out in the next cycle. Update outputs and flags in a straightforward synchronous always block without extra intermediate registers, ensuring valid_out is asserted only one cycle after the second input. Clear all registers on reset. This reduces complexity by using only necessary state registers and registers for output signals.
