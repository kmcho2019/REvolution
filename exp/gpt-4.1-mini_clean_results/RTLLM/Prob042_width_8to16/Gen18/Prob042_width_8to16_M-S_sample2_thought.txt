Use a simple register to store the first valid 8-bit input and a 1-bit flag to indicate whether the first byte has been stored. When the first valid input arrives, latch it and set the flag. When the second valid input arrives, concatenate the stored byte (high 8 bits) and current input (low 8 bits), register the output, assert valid_out one cycle later, then clear the flag to prepare for the next pair. valid_out and data_out are generated in the clock cycle after the second input. Reset clears all registers. This avoids FSM complexity and extra output pipeline registers.
