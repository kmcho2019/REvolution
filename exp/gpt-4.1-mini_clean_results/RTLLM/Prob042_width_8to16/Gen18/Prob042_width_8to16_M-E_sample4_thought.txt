Use a simple two-cycle buffering and output register approach without explicit FSM encoding.

- On each valid input byte, store it in an internal 8-bit register `buffered_data`.
- Maintain a flag `has_first_byte` indicating whether the buffer holds the first byte.
- When a second valid byte arrives and `has_first_byte` is set, concatenate the buffered byte (high 8 bits) and the current input (low 8 bits), and register this 16-bit value in `data_out`.
- Assert `valid_out` on the clock cycle after the second byte arrives (i.e., `valid_out` is registered together with `data_out`).
- If only one byte arrives and no second byte arrives yet, the module waits without producing output.
- On reset, clear all internal registers and outputs.
- This approach inherently implements the required output delay and width expansion without explicit FSM states, relying on registered signals and a simple flag for buffering.

This method is clean, easy to understand, fully synchronous, and synthesizable.
