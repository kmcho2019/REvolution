Use a simple two-stage state machine with a state bit that toggles between waiting for the first and second valid input. When a valid 8-bit input arrives:

- If in the "waiting for first byte" state, store the data in a register (data_lock) and move to "waiting for second byte" state.
- If in the "waiting for second byte" state, combine the stored byte and current input into a 16-bit data_out register and assert valid_out in the *next* cycle.
  
To generate valid_out and data_out in the cycle *after* receiving the second valid input, introduce a pipeline register to hold the concatenated output and a flag indicating its validity. This pipeline register and flag are clocked out one cycle later, producing the output signals synchronized to the clock.

On reset, clear all registers and outputs. Use only positive edge clocking and non-blocking assignments to avoid timing hazards.

This approach cleanly separates input data capturing, state progression, and output generation. It also guarantees valid_out and data_out appear exactly one cycle after the second valid input, as required.

No clearing of data_out when invalid is necessary; data_out simply holds the last output data. valid_out is asserted for exactly one cycle upon valid output generation.
