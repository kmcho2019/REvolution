Use a simple 1-bit flag register to track if the first valid 8-bit data byte has been received and stored. On every clock edge, if valid_in is high, check the flag: if clear, store the byte in a register and set the flag; if set, concatenate the stored byte with the current input and update data_out, assert valid_out on the next clock cycle, then clear the flag. Reset clears all registers. This straightforward approach meets the timing and output valid requirements with minimal state logic.
