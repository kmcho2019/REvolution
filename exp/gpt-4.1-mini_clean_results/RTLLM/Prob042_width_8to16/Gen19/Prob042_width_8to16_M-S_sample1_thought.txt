Use a simple register to store the first incoming valid 8-bit data and a flag to indicate its presence. When the first valid input arrives, store it and set the flag. On the second valid input, concatenate the stored data (high 8 bits) and current input (low 8 bits) and produce the output signals valid_out and data_out in the *next* clock cycle. To achieve this, store the concatenated result and valid_out flag in registers at the second input cycle, then output them on the following cycle. Reset clears all registers and flags. This approach cleanly separates input capture, output generation, and output staging without complicated next-state signals.
