Use a simple two-state approach with one register to hold the first byte. On each valid_in:

- If no data is stored (flag=0), store data_in in data_lock and set flag=1.
- Else (flag=1), output concatenation {data_lock, data_in} in the next clock cycle by registering data_out and valid_out. Clear flag=0.

Delay the output by one clock cycle after receiving the second byte by using output registers that are updated one cycle after concatenation is captured. This avoids extra output valid signal staging.

On reset, clear all registers.

This approach is minimal and meets the requirement:
- valid_out and data_out update one clock cycle after the second valid input.
- The first received 8-bit data is placed in the higher 8 bits.
- If only one valid input is received, the output waits for the next input to complete the 16-bit data.
