Use a shift-register approach that accumulates two consecutive 8-bit inputs into a 16-bit register. On each valid input, shift the existing 8 bits to the lower half and place the new input in the upper half. A counter keeps track of how many valid inputs have arrived: when the count reaches 2, output valid_out and data_out in the next clock cycle, then reset the count. This removes explicit FSM states and simplifies timing by registering outputs one cycle after the second data arrives. The valid_out signal is asserted only for one cycle immediately following the concatenation. Reset clears all registers. This architecture cleanly pipelines data concatenation and output generation.
