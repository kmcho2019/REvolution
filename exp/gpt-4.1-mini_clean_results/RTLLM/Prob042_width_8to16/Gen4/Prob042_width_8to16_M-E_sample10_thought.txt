Implement the design using a toggle flag to indicate whether the first 8-bit data has been stored. On each valid input, if the flag is cleared, store the input data in a register and set the flag; if the flag is set, concatenate the stored data as the upper byte with the current input data as the lower byte, output the 16-bit data and assert valid_out for one clock cycle. Use an output register pipeline stage to delay valid_out and data_out assertion to the cycle after receiving the second byte, as required. This approach uses minimal states, simple registers, and avoids explicit FSM states, improving clarity and potentially synthesis friendliness.
