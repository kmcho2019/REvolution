Use a simple toggle flag to remember if the first byte is stored. On each valid_in:
- If no first byte stored, save the input byte to a register.
- Else, concatenate stored byte (high 8 bits) with current byte (low 8 bits) and output valid_out and data_out in the next clock cycle.
This approach uses minimal state and registers, directly updating output registers with a one-cycle delay after receiving the second byte.
On reset, clear all registers.
