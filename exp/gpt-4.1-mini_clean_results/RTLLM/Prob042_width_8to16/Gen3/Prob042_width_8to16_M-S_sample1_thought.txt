Use a single register to store the first 8-bit input data and a flag to track if it is stored. When a valid input arrives and no first data is stored, latch it and set the flag. When the second valid input arrives, concatenate the stored data and current input and output them along with valid_out asserted in the next cycle. valid_out and data_out are registered outputs, updated only after two valid inputs are received. This approach uses minimal registers and logic, without a separate output register, and retains the required one-clock-cycle delay for valid_out and data_out after the second input.
