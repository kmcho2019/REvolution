Implement a simple single-bit flag to remember if the first 8-bit input has been received and stored. When `valid_in` is asserted, if the flag is not set, store the input in a register and set the flag. If the flag is already set, concatenate the stored data (as the higher 8 bits) with the current input (as the lower 8 bits), and in the *next* clock cycle assert `valid_out` with the concatenated 16-bit data. Clear the flag after outputting to prepare for the next data pair. This avoids complex FSM states and ensures that `valid_out` and `data_out` appear exactly one cycle after the second valid input arrives, meeting the timing and correctness requirements in a simple and clear manner.
