Use a simple state machine with two states to handle the 8-bit to 16-bit width conversion:

- State IDLE: Waiting for the first valid 8-bit input.
  When valid_in is asserted, store this input in a register (data_lock) and move to state WAIT_SECOND.

- State WAIT_SECOND: Waiting for the second valid 8-bit input.
  When valid_in is asserted, concatenate the stored data_lock (higher 8 bits) and the current input (lower 8 bits) into a 16-bit output register (data_out_reg).
  Assert a valid output flag (valid_out_reg) in the next clock cycle.
  After outputting, return to IDLE state to process the next pair.

The valid_out and data_out signals are registered outputs driven by the valid_out_reg and data_out_reg respectively.

This state machine cleanly separates the two data input phases, avoids flag toggling confusion, and guarantees the output valid signal is asserted one cycle after receiving the second input.

On reset, all registers and state are cleared.

This approach provides clear sequential control and timing behavior for width conversion.
