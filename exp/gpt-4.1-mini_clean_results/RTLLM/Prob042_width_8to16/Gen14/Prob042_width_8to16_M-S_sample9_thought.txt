Implement a simple toggle-based approach to collect two consecutive valid 8-bit inputs. Use a 1-bit flag (e.g., `data_lock_valid`) to indicate whether the first byte has been stored. On arrival of a valid input, if no data is locked yet, store it and set the flag; if data is already locked, concatenate the stored data and current input to form the 16-bit output and assert valid_out in the next cycle. Clear the flag after outputting. This avoids FSM complexity and meets the timing and functional requirements.
