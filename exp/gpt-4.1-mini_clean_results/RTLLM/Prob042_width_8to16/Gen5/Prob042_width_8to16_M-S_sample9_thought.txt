Use a simple 1-bit flag to indicate when the first 8-bit input has arrived and is stored. On each valid input:

- If the flag is clear, store the input in a register and set the flag.

- If the flag is set, concatenate the stored data (high 8 bits) with the new input (low 8 bits), register the output data and valid_out signals in the next clock cycle, then clear the flag.

This straightforward approach avoids an explicit FSM, reducing complexity and ensuring outputs appear exactly one clock cycle after the second input. On reset, clear all registers. This meets the requirement while keeping the design minimal and easy to synthesize.
