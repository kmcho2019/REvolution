Refactor the design to strictly separate sequential and combinational logic, and avoid mixing register assignments inside combinational blocks.

1. Use a localparam two-state FSM (`IDLE`, `WAIT_SECOND`) with a reg for `state`.
2. Store the first valid input in a register `data_lock` only in the sequential always block.
3. Use an output valid and output data register (`valid_out`, `data_out`) updated on the clock edge.
4. Introduce a register `pending_output` to hold the concatenated data ready to be output next cycle.
5. When the second valid input arrives, concatenate stored first byte and current byte into `pending_output`, assert a flag `pending_valid`.
6. In the next clock cycle, transfer `pending_output` and `pending_valid` to the output registers `data_out` and `valid_out`, producing outputs exactly one cycle after the second input.
7. On reset, clear all registers.
8. This approach cleanly aligns output generation one cycle after receiving two inputs, matches spec, and avoids combinational feedback of registers.
