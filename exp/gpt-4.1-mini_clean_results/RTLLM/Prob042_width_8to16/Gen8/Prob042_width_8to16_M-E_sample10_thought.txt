Use a two-stage pipeline approach with a small internal state machine represented by a 1-bit flag to indicate whether the stored byte is waiting for its pair. When a valid input arrives and the flag is 0, store it in a register and set the flag. When the next valid input arrives and the flag is 1, concatenate the stored data (upper 8 bits) and the new input (lower 8 bits) to produce a 16-bit output. However, do not assert valid_out immediately; instead, introduce a one-cycle latency by registering the output and valid_out signals, so the output and valid_out appear exactly one clock cycle after the second data input. On reset, clear all registers and flags. This structure cleanly separates data collection and output timing, ensuring valid_out pulses only once per output, exactly one cycle after two inputs are received. It also ensures that partial inputs (single byte waiting) do not produce output prematurely. The use of a flag reduces complexity and keeps the design easily synthesizable.
