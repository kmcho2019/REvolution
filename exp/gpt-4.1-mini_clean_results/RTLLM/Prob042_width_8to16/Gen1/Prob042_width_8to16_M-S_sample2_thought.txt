Use a single flag to remember if the first 8-bit data is stored. On each valid input, if the flag is 0, store the input and set the flag. If the flag is 1, store the second data, then in the next cycle output the concatenation of the two stored inputs with valid_out asserted. Use a register to hold the concatenated output and a valid flag to produce outputs one cycle after receiving the second input. Reset clears all registers and flags.
