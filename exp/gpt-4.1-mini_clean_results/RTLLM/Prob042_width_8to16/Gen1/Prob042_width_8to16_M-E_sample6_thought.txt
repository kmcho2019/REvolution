Use a simple two-state finite state machine (FSM) to track whether the first byte has been received. When the first valid input arrives, latch it into a register and transition to the "WAIT_SECOND" state. Upon receiving the second valid input, combine it with the stored first byte to form the 16-bit output. The output valid and data registers are updated at the next clock cycle after the second input is received, fulfilling the timing requirement. The FSM then returns to the initial "WAIT_FIRST" state for the next conversion cycle. Outputs remain deasserted until a pair of valid inputs is received. On reset, all states and registers clear.
