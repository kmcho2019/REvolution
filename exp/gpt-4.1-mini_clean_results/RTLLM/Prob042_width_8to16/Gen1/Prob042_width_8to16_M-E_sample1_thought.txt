Use a two-stage pipeline approach with an explicit state machine to control the data concatenation and output timing. On receiving the first valid 8-bit input, store it and move to a "waiting for second input" state. On receiving the second valid input, capture it and move to an "output valid" state in the next clock cycle. In this "output valid" state, assert valid_out and provide the concatenated 16-bit data_out, placing the first input in the upper 8 bits and the second input in the lower 8 bits. Then return to the initial state to repeat the process. This approach cleanly separates data capturing and output generation across clock cycles, guaranteeing that valid_out and data_out are generated exactly one clock cycle after receiving the second data input, as required. All registers and state are reset synchronously on rst_n deassertion.
