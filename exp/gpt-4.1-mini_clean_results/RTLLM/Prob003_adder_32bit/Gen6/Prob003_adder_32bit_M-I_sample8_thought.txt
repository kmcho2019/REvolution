To improve the original design's performance and reduce carry propagation delay, we implement a hierarchical carry-lookahead logic inside the 16-bit CLA block rather than a ripple carry style within the block. This is done by computing group generate and propagate signals for 4-bit groups, then combining them to compute carries in parallel.

- Divide the 16-bit block into four 4-bit groups.
- Calculate generate and propagate at bit and group levels.
- Compute carry signals for each bit using carry-lookahead equations.
- This reduces carry computation delay within the 16-bit block, making it a true carry-lookahead adder.
