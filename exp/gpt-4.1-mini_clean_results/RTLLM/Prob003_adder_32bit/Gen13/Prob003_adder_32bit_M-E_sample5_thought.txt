Design a 32-bit carry-lookahead adder using four 8-bit CLA blocks in a hierarchical manner, where each 8-bit block computes its own block propagate (P) and generate (G) signals. A top-level 4-bit CLA carries out carry-lookahead logic on these four P and G signals to quickly compute the carry-in for each 8-bit block. This approach reduces logic depth by using smaller CLA blocks and a fast 4-bit CLA for inter-block carry computation, improving speed relative to the simple two 16-bit blocks design. 

Implementation details:
- Implement an 8-bit CLA module producing sum, carry-out, and block P/G.
- Implement a 4-bit CLA module for the block-level carry lookahead (generates carries into each 8-bit block).
- The top-level 32-bit adder instantiates four 8-bit CLAs for input segments and one 4-bit CLA for block carries.
- Use the initial carry-in = 0.
- Carefully handle input/output indexing for the required [32:1] interface.
- This hierarchical approach balances fanout and logic depth for better performance and modularity.
