Design a 32-bit carry-lookahead adder using four 8-bit CLA blocks in a hierarchical structure. Each 8-bit CLA block calculates sum bits, generate (G), and propagate (P) outputs. The top-level 32-bit adder combines these group generate and propagate signals to produce carries between the 8-bit blocks using a 4-bit carry-lookahead logic. This hierarchical design reduces carry computation delay compared to a flat 16-bit CLA and minimizes the length of carry chains.

The 8-bit CLA block implements carry-lookahead logic internally using generate and propagate signals and directly computes all carry signals inside. It outputs group generate and propagate signals for the block. The top module collects these signals from the four 8-bit blocks and computes carries for the next block using a small 4-bit carry-lookahead unit.

This approach improves performance by breaking the 32-bit adder into smaller blocks with fast carry-lookahead and hierarchical carry propagation between blocks. It also improves modularity, makes the design scalable, and keeps the code clean and parameterizable with clear signal naming. Inputs and outputs maintain the 1-based indexing as requested.
