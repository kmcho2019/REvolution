Implement a hierarchical 32-bit carry lookahead adder composed of four 8-bit CLA blocks. Each 8-bit CLA block generates sum, block propagate (P), and block generate (G) signals. The top-level module uses a 4-block CLA tree to generate carry signals for each 8-bit block using fast carry-lookahead logic at the block level. This reduces the carry chain length from 32 to 4 and speeds up carry propagation significantly compared to a two-block or single-block linear carry chain. The indexing is kept as [N:1] as required.

Each 8-bit CLA computes carries internally using basic carry lookahead (c[i] = g[i] | (p[i] & c[i-1])) for 8 bits. The top-level combines the four blocks by computing carries into each block using the block propagate and generate signals in a CLA manner.

This structure balances complexity, speed, and modularity while illustrating hierarchical carry lookahead principle.
