Create a fully synthesizable clock generator that produces a slower clock by dividing a free-running input clock using a counter.

Since the problem does not specify an input clock, we will add an input clock signal named `clk_in` to drive the module. The module uses a parameterized PERIOD specifying the full period (in input clock cycles) of the generated clock. The counter counts input clock cycles up to half the PERIOD, then toggles the output clock.

This approach uses a synchronous always block triggered on the rising edge of the input clock, making it synthesizable and hardware-realistic.

This design can be instantiated with any input clock frequency to produce a lower frequency output clock with a period defined in input clock cycles.

If an input clock is not allowed, then the design cannot be synthesizable, so adding an input clock is a necessary architectural improvement and a common practice in hardware design.
