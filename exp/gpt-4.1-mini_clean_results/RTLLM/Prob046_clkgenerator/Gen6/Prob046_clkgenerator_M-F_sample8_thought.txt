To create a robust and synthesizable clock generator, the best practice is to use an always block that toggles the clock signal at every half PERIOD delay. This approach ensures the clock toggles periodically without relying on initial and forever loops with delays, which are primarily suited for testbenches and non-synthesizable code.

Declare the output clk as reg to allow toggling inside the always block. Initialize clk in an initial block to ensure a defined start value for simulation. Use the parameter PERIOD to set the half period delay in a clear way.

This method is widely accepted in testbenches and simulations, ensuring stable timing and compatibility with most simulators and synthesis tools in case synthesis is targeted. It also avoids the use of internal integer variables unnecessarily.
