To strictly follow the problem requirements and address the feedback, I will use an initial block to set the initial clock state to 0, then use a forever loop inside the same initial block to toggle the clock every half PERIOD using non-blocking assignments. This approach is common in testbenches and ensures clean simulation behavior.
