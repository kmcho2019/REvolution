To generate a periodic clock without recursion and without using an always block with delay, I will use an initial block combined with an infinite loop inside it. This loop will toggle the clock signal every half PERIOD using nonblocking assignment and delay statements. This approach is simulation-only, straightforward, and avoids recursion and synthesis issues.

Specifically:
- Declare clk as a reg output.
- Initialize clk to 0 in an initial block.
- Inside the same initial block, create an infinite while(1) loop.
- In each iteration, wait for half the PERIOD and toggle clk using nonblocking assignment (clk <= ~clk).
- This creates a clean, infinite square wave clock for simulation purposes.

This approach is commonly used for testbenches and clock generators in simulation, avoids recursion, and is syntactically simple.
