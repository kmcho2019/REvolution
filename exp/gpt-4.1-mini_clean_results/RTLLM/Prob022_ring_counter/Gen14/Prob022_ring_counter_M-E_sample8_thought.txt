Implement the ring counter using an integer index that keeps track of the current "high" bit position (0 to 7). On reset, set the index to 0. On each clock rising edge, increment the index modulo 8. The output vector is then generated by setting only the bit at the current index to 1 (one-hot encoding).

This avoids any slicing or concatenation operations on the vector and uses simple integer arithmetic and bitwise shifting for output generation. The output is combinationally derived from the index, keeping the internal register small and simplifying the logic.
