To avoid using slice concatenation inside the always block, we can store the position of the '1' bit as a 3-bit index instead of an 8-bit vector. On reset, we initialize this index to 0 (pointing to LSB). On each clock rising edge, we increment the index modulo 8. The output vector is then generated combinationally by assigning a single high bit at the current index position using a left shift. This removes the need for slice concatenation and array slicing in sequential logic, simplifies the design, and still fulfills the ring counter requirements.
