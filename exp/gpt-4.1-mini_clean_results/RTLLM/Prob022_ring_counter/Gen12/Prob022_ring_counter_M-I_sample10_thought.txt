To avoid the synthesis tool limitation about assigning the entire vector at once, replace the combinational case statement by directly updating the output vector sequentially within the clocked always block. Since exactly one bit is set per cycle, we can implement the one-hot output as a rotate-left shift register starting from 8'b0000_0001 at reset. This approach uses a single 8-bit reg updated on clock edges, avoiding the need for a separate position variable and combinational decoding, thus simplifying the logic and improving PPA.

On reset, out is initialized to 8'b00000001. On each clock rising edge, out rotates left by one bit (MSB goes to LSB), cycling the single '1' through the bits. This approach is compact, efficient, and fully supported by synthesis tools without array slice assignment issues.
