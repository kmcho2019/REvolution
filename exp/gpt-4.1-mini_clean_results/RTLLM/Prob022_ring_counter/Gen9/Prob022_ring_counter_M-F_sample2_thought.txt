To avoid tool limitations with assigning to vector outputs from a combinational always block, implement the entire ring counter state and output update in a single sequential always block triggered by clock and reset. Keep `out` as a reg and update it directly on the rising clock edge or reset. Initialize `out` to have the LSB set on reset, then shift left by one bit on each clock cycle, wrapping the MSB back to the LSB by checking if the shifted out bit is set. This removes the need for a separate index and a combinational decoding block, and avoids vector assignments outside of a clocked always block, which is better supported across tools.
