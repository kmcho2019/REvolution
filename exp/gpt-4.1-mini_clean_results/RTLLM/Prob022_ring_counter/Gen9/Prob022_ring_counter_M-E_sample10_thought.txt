Implement the 8-bit ring counter using a shift register approach instead of a position counter. On reset, initialize the 8-bit register to have only the LSB set. On each rising clock edge, perform a circular left shift of the register value, moving the '1' bit one position left and wrapping it from MSB back to LSB. This directly models the ring counter behavior with a register that holds the entire one-hot vector and updates itself on each clock cycle.

This approach simplifies the design by keeping the entire state in one register and doing a bitwise rotation on each clock, removing the need for position counters or combinational encodings. It naturally ensures only one bit is set at any time and cycles through all 8 positions.
