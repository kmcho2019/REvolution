To avoid the tool limitation with assigning the entire output vector in a combinational always block, refactor the design so that the output `out` is updated synchronously inside the clocked always block along with the index. Instead of maintaining a separate index, directly rotate the bit pattern stored in `out` on each clock cycle. On reset, set `out` to 8'b0000_0001. On every rising clock edge (when reset is low), shift the `out` register left by 1 bit and wrap the MSB around to the LSB to achieve the ring counter behavior. This approach keeps all output assignments inside a single synchronous always block, avoiding combinational assignments to `out` and working around the tool’s limitation.
