Instead of using a shift register and bit concatenation, implement the ring counter by storing the current active bit position as a 3-bit index (0 to 7). On reset, initialize the index to 0. On each clock cycle, increment the index modulo 8 to cycle through positions. The output is generated combinationally by assigning a one-hot output with only the bit at the current index set. This approach avoids array slicing or concatenation on the register and maintains a clean, synthesizable design.
