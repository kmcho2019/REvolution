Use a 3-bit counter to represent the current active bit index instead of storing the full 8-bit vector in a register. On each clock, increment the index modulo 8. Then use a combinational block to decode the index into a one-hot 8-bit output signal, with only one bit set high corresponding to the index. On reset, the index is reset to zero, which corresponds to the LSB bit set in the output. This architecture separates state storage (3-bit index) and output decoding (combinational), avoiding direct register assignments to multi-bit outputs, and improving clarity and tool compatibility.
