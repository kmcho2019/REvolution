Implement the ring counter using a 3-bit binary state register representing the position index (0 to 7) of the single set bit. On each clock rising edge, increment the index modulo 8, wrapping around from 7 back to 0. The output vector is then generated combinationally by decoding the state index into a one-hot 8-bit vector with only the bit at the current index set high. This approach separates state from output decoding and avoids direct bit-shifting of the output register, providing clarity and easy scalability.
