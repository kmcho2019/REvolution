Refactor the design to separate the state representation (using a 3-bit index to track the active bit position) from the output encoding (using a continuous assignment to generate the one-hot 8-bit output). On reset, the index is set to 0. On each clock edge, the index increments modulo 8 to cycle through the positions 0 to 7. The output is then assigned combinationally as a one-hot vector with a single bit set at the position indicated by the index. This approach cleanly separates state and output logic, avoids complex shift operations inside an always block, and is fully synthesizable and compatible with all Verilog tools.
