Use a simple 8-bit register to hold the one-hot state of the ring counter. On reset, initialize the output to 8'b00000001. On each clock rising edge, shift the output left by one bit. If the MSB is set before shifting, wrap it around to the LSB by setting bit 0 to 1. This removes the need for concatenation and uses only basic shift and conditional logic, simplifying the code while maintaining the required cyclic behavior.
