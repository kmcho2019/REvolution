To avoid unsupported concatenation assignments in the always block, implement the ring counter by tracking the index of the active bit (0 to 7) in a register. On each clock edge, increment the index modulo 8, wrapping back to 0 after 7. Use a continuous assignment to output a one-hot vector with a single bit set at the current index. On reset, the index is cleared to 0, corresponding to LSB set. This approach sidesteps direct bit rotation by managing the active bit position, making the code synthesis-friendly and easy to understand.
