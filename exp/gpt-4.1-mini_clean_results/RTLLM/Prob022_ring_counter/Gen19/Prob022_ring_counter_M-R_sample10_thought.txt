To avoid vector assignments and slices that cause tool errors, I will implement the ring counter as a one-hot encoded 3-bit state machine representing the current active bit position (0 to 7). Instead of storing the entire 8-bit output as a register, I store the current position index (0-7) in a 3-bit register. On each clock cycle, I increment the position modulo 8, cycling through 0 to 7. The output `out` is then combinationally assigned as `1 << position`.

This approach eliminates direct vector concatenation and slicing in sequential logic and uses a simple integer counter for state. The output is generated by a straightforward shift operation on the position, which is an expression, not a register assignment.

This design is fully synthesizable, easy to simulate, and avoids the assignment issues reported.
