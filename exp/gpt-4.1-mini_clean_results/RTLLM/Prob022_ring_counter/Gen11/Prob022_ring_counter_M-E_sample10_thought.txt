Instead of rotating the entire vector, use a 3-bit index (position) register to indicate which bit should be high in the 8-bit output. On reset, set the index to 0 (corresponding to the LSB). On each clock rising edge, increment the index modulo 8. The output is generated combinationally by decoding the index into a one-hot 8-bit vector with only the indexed bit set high. This avoids bit-slice rotations and concatenations in always blocks, ensuring compatibility with strict synthesis tools.
