To simplify and avoid array slicing or concatenation for rotation, maintain the position of the single set bit as an integer index from 0 to 7. On reset, set the index to 0. On each clock, increment the index modulo 8. The output `out` is then assigned using a one-hot encoding by left-shifting `1` by the current position. This avoids vector slicing and concatenation entirely and uses simple arithmetic and shift operations compatible with all tools.
