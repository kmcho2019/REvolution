Instead of rotating the bits directly, I will implement the ring counter by maintaining an index (0 to 7) that points to the current active bit. On each clock cycle, the index increments modulo 8. The output is then generated by encoding this index as a one-hot signal using a case statement or a shifting operation. This approach uses a simple integer counter as the state machine and produces the one-hot output on the fly, which can avoid the tool limitations related to direct vector rotations or concatenations.
