To simplify and avoid multiple conflicting bit assignments, maintain the ring counter state in a single 8-bit register `out`. On reset, assign `out` to have only the LSB set (`8'b00000001`). On each rising clock edge (when not resetting), update `out` by rotating its bits left by one position, effectively moving the single high bit to the next position in the cycle. This can be done by concatenating the shifted bits in a single nonblocking assignment, which is synthesizable and straightforward.
