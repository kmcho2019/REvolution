The root problem is that multiple individual bits of the same register were assigned in parallel with non-blocking assignments inside a single always block, which violates Verilog semantics for procedural assignments.

To fix this, assign the entire 8-bit register 'out' in one single non-blocking assignment statement. This can be done by performing a rotation through concatenation:

- On reset, set out to 8'b00000001.
- Otherwise, rotate the bits left by one position with wrap-around by assigning:
  out <= {out[6:0], out[7]};

This single assignment updates 'out' atomically and is synthesizable and supported by all tools.

This approach preserves the one-hot circulating bit behavior of the ring counter and eliminates the issue of partial bit assignments.
