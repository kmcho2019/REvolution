Use a simple 8-bit register to hold the one-hot ring counter state. On reset, set the register to 1 (LSB high). On each clock rising edge, rotate the single '1' bit by shifting left by one and wrapping around the MSB back to LSB. To avoid unsupported slicing or concatenation, implement the rotation explicitly with conditional logic: if the current output is 10000000, next state is 00000001; otherwise, shift left by one. This avoids using vector concatenations and maintains the ring counter functionality in a straightforward way.
