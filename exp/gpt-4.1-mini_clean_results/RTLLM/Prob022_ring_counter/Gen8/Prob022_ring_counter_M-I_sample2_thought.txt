To resolve the elaboration failure caused by indexed bit assignment inside a combinational always block, avoid procedural assignment to a single bit of a reg vector. Instead, derive the output directly from the position register using a shift operation, which is synthesizable and supported by all tools. Specifically, set `out = 8'b1 << position;` in a combinational block or directly assign it in a continuous assignment if possible. This simplifies the logic and ensures only one bit is high, rotating each clock cycle.
