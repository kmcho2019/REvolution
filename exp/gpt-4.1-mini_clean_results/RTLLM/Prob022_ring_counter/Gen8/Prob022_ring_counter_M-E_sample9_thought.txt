Implement the ring counter by maintaining an integer index pointer that indicates the position of the set bit (from 0 to 7). On reset, initialize the index to 0, corresponding to the LSB set. On each clock rising edge, increment the index modulo 8 to cycle through the positions. The output `out` is generated combinationally from the index by using a one-hot decoder (1 << index). This approach avoids any bit-slice concatenation or vector rotation, only using an integer state and a shift operation in a combinational assignment, which should be supported by all simulators.
