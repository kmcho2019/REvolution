To avoid assigning the entire output vector inside a sequential always block (which some tools reject), we can separate the position tracking from the output generation. We keep a 3-bit position register updated on clock and reset inside an always block, but generate the output combinationally using a continuous assign statement outside the always block. This way, 'out' is driven by a wire assigned with a left-shifted 1 based on 'position', and only 'position' is a reg inside the always block. This circumvents tool restrictions on vector assignments within sequential logic blocks.
