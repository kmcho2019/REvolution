Keep the same design idea of using a 3-bit index that cycles from 0 to 7 on each clock edge to represent which bit is set. Instead of using an always block to assign the output bit by bit, implement the output `out` as a combinational continuous assignment using the shift operator: `out = 1 << index;`. This avoids the bit-select assignment inside an always block, which can cause tool issues. The index updates in a sequential always block triggered by clock and reset. This approach preserves the logic, is synthesizable and avoids the assignment to vector bits inside always blocks that caused problems.
