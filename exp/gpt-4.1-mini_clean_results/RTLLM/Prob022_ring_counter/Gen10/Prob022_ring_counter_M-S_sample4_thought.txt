Use a single 8-bit register 'out' to hold the ring counter state directly. On reset, set 'out' to have the LSB high (8'b00000001). On each rising clock edge (if not reset), rotate the bits of 'out' to the left by one position, moving the single high bit to the next position. This eliminates the need for an index and avoids variable bit indexing inside always blocks, which can cause elaboration issues. The code is straightforward, synthesizable, and clear.
