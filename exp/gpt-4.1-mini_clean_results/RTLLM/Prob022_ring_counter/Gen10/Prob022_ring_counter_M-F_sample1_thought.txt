To avoid tool limitations with entire vector assignments, implement the ring counter by treating the output as an 8-bit register but update it bit-by-bit using a for-loop or individual bit assignments inside the clocked always block. Since the counter always has only one bit set, we can store the current position as an integer index and generate the output vector combinationally. This way, the 'out' output can be driven by a vector generated from the index, avoiding direct vector assignment in the sequential block. The index can be updated synchronously, and the output is always a single bit set according to the index position, thus avoiding tool issues with vector assignments.
