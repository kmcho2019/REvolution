A novel approach to achieve a fractional divide-by-3.5 frequency divider with near 50% duty cycle is to use a time-multiplexed clock enable scheme combined with a toggle flip-flop, synchronized to the input clock edges, without relying on asynchronous edges toggling.

1. **Use a modulo-7 counter counting on the positive edge of clk:**  
   The counter runs from 0 to 6, representing 7 input clock cycles for a full output period.

2. **Generate two clock enable pulses (pulse_4 and pulse_3) within the 7-cycle window:**  
   - For 4 cycles: Enable output toggle at count 0 (start of period)  
   - For 3 cycles: Enable output toggle at count 4

   These clock enable pulses indicate when to toggle the output clock to create uneven high and low durations (4 cycles high, 3 cycles low).

3. **Use a toggling flip-flop `clk_div` that changes state on the enabled input clock edges:**  
   This flip-flop toggles only when the enable pulse is asserted, effectively creating the fractional division.

4. **Introduce a 50% duty cycle correction by generating two toggles spaced by half clock cycle:**  
   - Use the positive edge to toggle clk_div when enabled.  
   - Use the negative edge to toggle another register `clk_div_n` when enabled.  
   - Finally, combine these two toggles with a simple OR or XOR to form the final output.

5. **However, to simplify and avoid asynchronous toggling, create a half-cycle delayed version of `clk_div` using a flip-flop clocked on negative edge:**  
   This achieves a phase shift of half clock period.

6. **Output clock is generated by OR-ing `clk_div` and its half-cycle delayed version:**  
   This creates the fractional division with improved duty cycle and uniform output frequency.

7. **Reset asynchronously sets both flip-flops and counter to zero.**

This method avoids toggling at different clock edges with different counters; instead, it uses a single positive edge counter and uses negative-edge clocked delay flip-flop for phase shift, ensuring glitch-free operation and a stable fractional output. It also eliminates the need to sample counters on negedge, improving timing robustness.

Overall, the output clock frequency equals input clock frequency divided by 3.5, with uniform period and near 50% duty cycle, suitable for FPGA/ASIC implementation.
