Improve the fractional clock divider by explicitly generating both clock phases (`clk_pos` and `clk_neg`) within the same synchronous clock domain using the main counter, avoiding sampling on the negative clock edge which introduces timing uncertainties.

Specifically:
- Use the 3-bit counter counting from 0 to 6 (7 states) on posedge clk.
- Generate `clk_pos` high for counts 0..3 and low for 4..6.
- Generate `clk_neg` as the phase-shifted version delayed by half a clock cycle by mapping counts offset by 3 (mod 7). That is, `clk_neg` is high for counts 3..6 and low for 0..2 (mod 7).
- This creates a half-cycle shifted version of `clk_pos` synchronized to the same clock edge without relying on negedge sampling.
- OR `clk_pos` and `clk_neg` to generate the fractional output clock with a more uniform duty cycle and correct timing.
- Use synchronous reset for all registers for better timing and synthesis friendliness.
  
This removes glitches, ensures all logic is synchronous, and tightly controls timing and duty cycle for a robust fractional clock divider.
