I will implement the fractional frequency divider for division by 3.5 (7/2) using a single clock domain with a phase accumulator approach.

Key idea:
- Use a fixed-point phase accumulator that increments by a fractional step each input clock cycle.
- The increment corresponds to 2 (for division by 3.5 → output frequency = clk / 3.5 → output toggles every 3.5 input clocks, so increment = 2 for a 1-bit accumulator).
- The phase accumulator is a modulo-7 counter with fractional increments to generate an output toggle every 3.5 input clocks on average.
- The output toggles when the accumulator overflows its MSB bit.
- This naturally creates a fractional division, smoothing the uneven cycles.

To achieve this in pure RTL:
- Represent the accumulator with enough bits to cover the fractional step: for division by 3.5, we can use a 4-bit accumulator.
- Increment the accumulator by a constant (2 in a 4-bit space to represent 0.5 cycles).
- Toggle output when accumulator crosses half of the modulo.
- This approach produces a clock of frequency clk/3.5 and provides uniform period and better duty cycle.

Advantages:
- Single clock domain (posedge clk)
- No negedge clocks
- No separate counters; only a phase accumulator and output toggle
- Simple and clean design with no glitches from clock domain crossing
- Easily scalable for other fractional divisions by changing increment and modulus

This approach uses a known DDS (Direct Digital Synthesis) style fractional divider technique, suitable for fractional division with smooth output.

I will implement this with:
- 4-bit accumulator to cover 7 steps with fractional increment
- Modulo wrap at 7 (using % 7)
- The output toggles each time the accumulator crosses the halfway point (which corresponds to half the modulo)
