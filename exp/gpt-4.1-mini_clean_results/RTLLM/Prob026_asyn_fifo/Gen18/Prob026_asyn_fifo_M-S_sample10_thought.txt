Implement an asynchronous FIFO with parameterized WIDTH and DEPTH, using a modular approach with the following key components:

- A dual-port RAM submodule for storage, instantiated as required.
- Separate read and write pointers in Gray code for synchronization across clock domains.
- Two-stage synchronizers for crossing pointers between write and read clock domains.
- Full and empty signals generated by comparing synchronized Gray pointers with the standard rule:
  * Empty when read pointer equals synchronized write pointer.
  * Full when write pointer's next value equals read pointer with top two bits inverted.
- Pointers are maintained in binary internally for addressing the RAM (lower bits).
- Write and read operations gated by full and empty signals.
- The design uses minimal combinational logic and avoids extra buffering or unnecessary conversion functions inside sequential blocks.
- Reset signals are asynchronous active low.
This simplification avoids storing extra binary pointer registers and keeps pointer management clean and straightforward.
