Design an asynchronous FIFO with parameterizable WIDTH and DEPTH using a more modular approach, but differ architecturally by explicitly separating pointer increments and synchronization with handshake signals to help clarify logic.

Key points of this novel design:

1. Use a dual-port RAM submodule for storage, as required, with independent clocks and enables.
2. Maintain write and read pointers as Gray code counters directly rather than binary counters converted to Gray.
3. Provide separate modules for:
   - Write pointer controller (increments Gray-coded pointer on valid write request when not full).
   - Read pointer controller (increments Gray-coded pointer on valid read request when not empty).
   - Two-stage synchronizers for crossing Gray-coded pointers between clock domains.
4. Pointer addresses for RAM access are extracted directly by converting Gray-coded pointer to binary address in each domain using gray-to-binary conversion inside the write/read pointer modules.
5. Use Gray-coded pointer comparison logic for empty and full flags:
   - Empty if read pointer equals synchronized write pointer.
   - Full if write pointer equals read pointer with MSB and next MSB inverted (classic FIFO full condition).
6. This approach maintains Gray-coded pointers at all times, avoiding binary to Gray conversion functions outside pointer counters.
7. The write pointer and read pointer controllers also output the binary address for RAM access.
8. Synchronizers for cross-domain pointer synchronization are generic and reusable.
9. All reset signals are active low asynchronous resets.
10. Data output registered after reading RAM at rclk, gated by renc.
11. Clear handshake and enable logic to control reading and writing.
12. FIFO parameters WIDTH and DEPTH are used throughout consistently.

This architecture clarifies pointer control logic by keeping pointers Gray-coded internally and generating binary addresses within the pointer controllers, helping simplify the main FIFO module control.
