Implement an asynchronous FIFO using a modular approach with clear separation of concerns:

- A parameterized dual-port RAM submodule for storage.
- Separate write and read pointer counters in binary form clocked by their respective clocks.
- Conversion of binary pointers to Gray code for synchronization.
- Two-stage synchronizers crossing read pointer into write clock domain and write pointer into read clock domain.
- Full and empty flags are generated by comparing the synchronized Gray pointers in the respective domains.

Addressing scheme:
- The FIFO depth is parameterizable (e.g., 16).
- The pointers are PTR_WIDTH = ADDR_WIDTH + 1 bits wide to detect full/empty conditions.
- The lower ADDR_WIDTH bits of binary pointer select the RAM address.
- For full detection: write pointer equals read pointer with MSB and MSB-1 bits inverted.
- For empty detection: read pointer equals write pointer.

Key details:
- Reset signals are synchronous inside each clock domain.
- Write enable asserted only when not full and winc is high.
- Read enable asserted only when not empty and rinc is high.
- The RAM is synchronous with independent clocks for write and read.
- Read data is output registered at the read clock domain.
- Provide all modules in one file: dual-port RAM, synchronizers, and FIFO top module.

This approach ensures robust asynchronous FIFO design with proper synchronization and simple pointer logic.
