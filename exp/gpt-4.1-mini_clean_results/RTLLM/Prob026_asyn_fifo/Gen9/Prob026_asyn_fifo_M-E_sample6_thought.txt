Implement an asynchronous FIFO with parameterized width and depth using a clean modular approach with these key differences:
1. Use separate binary write/read pointers, with Gray-coded pointers for synchronization.
2. Store pointers in binary form internally; use Gray code only for synchronization crossing clock domains.
3. Pointer synchronization uses double-flip-flop synchronizers with separate modules for clarity.
4. Full and empty conditions are detected by comparing Gray-coded pointers with the classic asynchronous FIFO rules:
   - Empty when read_gray == write_gray synchronized to read clock domain.
   - Full when write_gray == (read_gray synchronized to write clock domain) with MSBs inverted (as per problem).
5. Use a synchronous dual-port RAM submodule instantiated inside; addresses come from pointer LSB bits.
6. Separate read and write controllers increment pointers only if FIFO is not full/empty respectively.
7. Output data from RAM is registered on read clock when read enable is asserted.
8. Encapsulate Gray<->binary conversion functions in separate utility module for cleanliness.
9. FIFO interface and signals as required.

This architecture decouples pointer logic, pointer synchronizers, and dual-port RAM cleanly, ensuring easy debug and maintainability.
