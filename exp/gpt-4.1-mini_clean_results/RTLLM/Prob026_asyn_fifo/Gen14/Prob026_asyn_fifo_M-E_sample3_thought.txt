Implement an asynchronous FIFO with parameterizable WIDTH and DEPTH using a circular pointer approach, but encode pointers in Gray code for crossing clock domains to avoid metastability.

The design uses:

1. A dual-port RAM submodule for storage, instantiated as specified.
2. Write and read pointers are maintained as binary counters for RAM addressing.
3. Pointers are converted to Gray code for synchronization between clock domains.
4. Two-stage synchronizers are used to capture the opposite domain pointer Gray codes safely.
5. The full and empty conditions are detected by comparing the Gray-coded write and read pointers in their respective domains with the standard full/empty logic:
   - Full if write pointer is one step ahead of read pointer, considering MSB bits inversion.
   - Empty if pointers are equal.
6. The RAM addresses use the lower bits of the binary pointer (ignoring MSB).
7. The write pointer increments on wclk domain on valid write request if FIFO not full.
8. The read pointer increments on rclk domain on valid read request if FIFO not empty.
9. Synchronizers are encapsulated in a generic module for Gray-coded vectors.
10. Binary-to-Gray and Gray-to-binary conversions are implemented as pure functions outside the main module.
11. Signals are carefully declared before usage to avoid implicit nets.
12. The code includes comments and clean modularity.

This approach keeps pointer registers purely binary in their own clock domain, but pointer crossing is always Gray-coded and synchronized via 2-stage registers. It leverages standard asynchronous FIFO design principles with explicit dual-port RAM and clear pointer crossing logic.
