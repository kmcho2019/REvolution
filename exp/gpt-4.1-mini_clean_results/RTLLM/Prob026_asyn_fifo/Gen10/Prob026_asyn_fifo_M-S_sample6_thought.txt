Implement an asynchronous FIFO with parameterizable width and depth using a dual-port RAM submodule and Gray-coded pointers for asynchronous read/write domain crossing.  
- Use binary counters for read/write pointers and convert to Gray code for synchronization across clock domains.  
- Synchronize pointers with two-stage flip-flops.  
- Determine full and empty conditions by comparing Gray-coded pointers as per spec.  
- Use lower bits of binary pointers as RAM addresses.  
- Keep the design simple by inlining Gray code conversion functions and synchronization registers directly in the FIFO module.  
- Instantiate the dual-port RAM submodule with independent clocks, addresses, enables, and data ports.  
- Provide stable read data output registered on read clock.  
This yields a clean, concise asynchronous FIFO with minimal modules and straightforward logic.
