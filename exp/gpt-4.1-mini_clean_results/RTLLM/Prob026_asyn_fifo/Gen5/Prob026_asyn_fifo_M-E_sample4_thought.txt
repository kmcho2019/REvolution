Implement an asynchronous FIFO with parameterizable WIDTH and DEPTH using an explicit binary counter pointer scheme combined with Gray code pointer synchronization, but with these differences:

- Use exactly PTR_WIDTH-bit pointers (no extra MSB), since DEPTH is power-of-two and use standard FIFO full/empty detection by comparing write and read pointers with wrapped conditions.
- Generate Gray code pointers from binary pointers and synchronize the opposite domain's Gray pointer with two-stage synchronizers.
- The write and read pointers increment only when FIFO is not full or empty, respectively.
- The full condition is detected when the write pointer next value equals the read pointer with the MSB inverted (indicating "one full" cycle difference).
- The empty condition is simply equality of synchronized pointers.
- The FIFO uses a dual-port RAM submodule instantiated separately with write/read clocks, enables, addresses, and data ports.
- Use dedicated synchronizer modules for pointer synchronization.
- The write and read addresses for RAM are directly the binary pointers (no Gray to binary conversion on RAM address).
- On resets, pointers initialize to zero.
- Read data is output registered on the read clock and read enable.
- The design is cleanly partitioned into:
  * Pointer increment logic
  * Gray code conversions
  * Pointer synchronizers
  * Full/empty flag combinational logic
  * Dual-port RAM instantiation

This approach contrasts with the previous one by using PTR_WIDTH-bit pointers with MSB toggling logic for full detection (instead of extra bit pointers), by directly using binary pointers as RAM addresses, and fully cleanly separating synchronizers and Gray conversions. It ensures simplicity, scalability, and clear full/empty detection with minimal pointer width. The design is ready for any DEPTH = power-of-two parameter.
