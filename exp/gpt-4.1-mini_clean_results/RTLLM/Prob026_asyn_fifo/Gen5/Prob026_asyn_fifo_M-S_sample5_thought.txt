Implement a parameterized asynchronous FIFO with a modular approach that contains:
- A dual-port RAM submodule for storage with independent read/write clocks and enables.
- Write and read pointer counters in binary updated on respective clocks and increments gated by full/empty flags.
- Binary-to-Gray and Gray-to-binary conversions for pointer synchronization and stable crossing of clock domains.
- Two-stage synchronizers for transferring Gray-coded read pointer into write clock domain and write pointer into read clock domain.
- Full and empty flag logic derived from Gray-coded pointers comparing MSBs and lower bits per standard asynchronous FIFO design.
- Use only essential modules and logic to keep the code straightforward and readable, minimizing submodule overhead while maintaining clear separation of concerns.
