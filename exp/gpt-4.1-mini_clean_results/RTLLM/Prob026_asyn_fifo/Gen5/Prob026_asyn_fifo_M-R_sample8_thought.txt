Refactor the asynchronous FIFO code by separating pointer increment and gray code conversions into combinational logic using `assign` statements instead of updating these in synchronous `always` blocks. This makes pointer calculations more transparent and reduces the use of procedural assignments. The dual-port RAM remains a separate module, but the pointer synchronization and status flag logic use explicit registers only for synchronizing cross-domain Gray pointers, while binary-to-gray and gray-to-binary conversions are now implemented as pure functions called in combinational assignments. This approach simplifies the pointer logic, clarifies signal dependencies, and better matches typical asynchronous FIFO styles, while preserving the asynchronous pointer crossing, empty/full detection via Gray code, and usage of lower bits for RAM addressing.
