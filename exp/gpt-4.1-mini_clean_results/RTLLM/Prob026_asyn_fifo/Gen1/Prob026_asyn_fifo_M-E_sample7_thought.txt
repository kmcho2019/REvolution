Create an asynchronous FIFO using a dual-port RAM submodule with parameterizable width and depth. The design will use binary counters as read and write pointers internally, but exchange Gray-coded pointers across clock domains for safe synchronization. Instead of holding the synchronized Gray pointers in registers only, this solution will first convert pointers to Gray code in the respective clock domains, then use two-stage synchronizers for the Gray pointers crossing domains. The RAM address inputs will use the lower bits of the binary pointers (after conversion from Gray code to binary for synchronized pointers). Full and empty detection will use the Gray pointers: FIFO is empty when read and write Gray pointers are equal; FIFO is full when the write pointer's Gray code equals the read pointer's Gray code with MSB and second MSB inverted. The difference from the previous solution is to explicitly separate pointer generation and synchronization logic in separate modules for clarity, and to implement the synchronizers as parameterized reusable modules. Also, the dual-port RAM submodule will be instantiated as a pure behavioral model with blocking read for read port for simplicity and to support reading data on address change without explicit read enable—this reduces the need to gate read enables, simplifying timing in the read clock domain. The write enable still gates the write operations. The outputs will update synchronously in respective clock domains. Reset logic is synchronous with active-low resets. This architectural approach modularizes synchronization and clarifies pointer conversions, helping maintain robust and clean design for asynchronous FIFO operation.
