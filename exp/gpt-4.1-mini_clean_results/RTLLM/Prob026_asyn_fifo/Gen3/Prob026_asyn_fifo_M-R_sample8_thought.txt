Refactor the asynchronous FIFO to emphasize structural clarity by separating pointer management, pointer synchronization, and full/empty detection more explicitly, and using combinational logic (`assign`) where appropriate instead of `always` blocks for pointer comparisons.

Key changes:
- Use separate binary counters for read and write pointers with simple increment logic in their clock domains.
- Perform Gray code conversion combinationally with functions but assign Gray codes in always blocks.
- Synchronize pointers across clock domains using two-stage synchronizers as before, but separate synchronization logic into distinct always blocks.
- Use `assign` statements for full and empty conditions based on Gray code pointers, computed combinationally.
- Control write/read enable signals within respective clock domains with gating on full/empty signals.
- Use blocking assignments inside combinational functions and `assign` for combinational signals; use non-blocking in sequential always blocks.
- The dual-port RAM remains a submodule with the same interface.
- Read data output is registered on read enable in read clock domain.

This approach enhances modularity and clarity, reduces sequential logic for pointer comparisons, and cleanly separates synchronous and combinational parts, maintaining the functional behavior while improving code structure.
