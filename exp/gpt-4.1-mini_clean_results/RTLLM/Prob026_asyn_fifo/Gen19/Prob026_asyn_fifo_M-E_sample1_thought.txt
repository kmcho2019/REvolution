I will implement an asynchronous FIFO using the classical Gray-coded pointer approach with full and empty detection by comparing Gray pointers. However, the architecture and code structure will differ from the example by:

- Using separate binary and gray registers for read and write pointers.
- Instantiating a dual-port RAM submodule for storage as requested.
- Synchronizing pointers by 2-stage flip-flops in the opposite domain to avoid metastability.
- The full condition is detected when the write pointer’s next Gray code equals the read pointer Gray code with the two MSB inverted, matching the classical async FIFO condition.
- The empty condition is detected when the read pointer Gray equals the synchronized write pointer Gray.
- The RAM address for write and read are taken from the lower bits of the binary pointer.
- Write and read pointers increment only if FIFO not full/empty and respective increment enable.
- Data read from RAM is registered only when read enable is asserted.
- Resets are synchronous to respective clocks (active low) to simplify pointer logic.
- The RAM module supports independent clocks and write/read enables.
- Overall code uses non-blocking assignments in sequential logic and combinational assignments otherwise.
- Use of functions for Gray-to-binary and binary-to-Gray conversion.
- Clear separation of modules and signal naming for readability.

This design fulfills the requirements with a different structure and naming conventions, emphasizing clear separation and synchronous resets.
