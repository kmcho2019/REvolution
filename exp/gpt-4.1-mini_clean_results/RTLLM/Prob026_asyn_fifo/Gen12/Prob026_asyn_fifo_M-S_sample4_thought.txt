Implement a straightforward asynchronous FIFO with parameterizable width and depth by instantiating a dual-port RAM submodule and managing write and read pointers with Gray code. Use simple always blocks for pointer increments and two-stage synchronizers for pointer crossing clock domains. Determine full and empty conditions by comparing Gray-coded pointers as per the described rules. The RAM read data is registered on the read clock domain when reading is enabled. This approach maintains all required functionality but avoids extra modules and complex functions, relying on concise inline Gray code conversions and pointer synchronization.
