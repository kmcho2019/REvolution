Implement the asynchronous FIFO with a separated modular approach and an explicit pointer crossing module:
- Dual-port RAM submodule for data storage.
- Separate write controller with a binary counter for the write pointer and a Gray code pointer generated on-the-fly.
- Separate read controller with a binary counter for the read pointer and Gray code pointer similarly generated.
- Dedicated pointer synchronization modules for crossing clock domains (rptr in write domain, wptr in read domain), each implemented as two-stage synchronizers.
- Instead of using complicated pointer comparison, implement full and empty detection by comparing Gray code pointers in write and read domains, following the classical approach:
  - FIFO full: when the write pointer's MSBs are the inverse of read pointer's MSBs and lower bits are equal.
  - FIFO empty: when write and read pointers (in Gray) are equal.
- Gray code pointers width is ADDR_WIDTH+1 to cover the extra MSB for full detection.
- Addresses to RAM are extracted from the binary part (lower bits) of write and read pointers.
- Writes increment only when FIFO not full and winc is asserted.
- Reads increment only when FIFO not empty and rinc is asserted.
- The design includes synchronous reset (active low) for each clock domain independently.
This structure is clean, explicit, modular, and easy to verify/debug.
