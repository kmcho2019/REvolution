Implement the asynchronous FIFO with a clean structure by keeping separate binary read and write pointers that increment on their respective clocks when enabled. Convert these pointers to Gray code for cross-domain synchronization using simple 2-stage flip-flop synchronizers. Use Gray code pointer comparison to generate full and empty flags, following the described condition (full when MSB and second MSB bits differ, rest match; empty when pointers equal). Use lower bits of the binary pointers for RAM addressing. Instantiate a dual-port RAM submodule with separate clocks and enables. Keep Gray code conversions inline and simple for clarity. Parameters WIDTH and DEPTH are configurable with DEPTH a power of two. The resets are active low and local to each clock domain. This approach simplifies pointer logic, synchronization, and control signals while maintaining all functional requirements.
