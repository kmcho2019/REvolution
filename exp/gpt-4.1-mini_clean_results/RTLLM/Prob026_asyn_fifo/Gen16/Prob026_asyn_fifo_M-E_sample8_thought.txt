I will implement an asynchronous FIFO with the required parameterizable width and depth using a clean modular approach:

1. **Dual-Port RAM**: A separate behavioral module storing the FIFO data with independent read/write clocks.
2. **Binary Counters for Pointers**: Maintain separate binary read/write pointers for internal addressing.
3. **Gray Code Pointers for Synchronization**: Convert binary pointers to Gray code before cross-clock-domain synchronization.
4. **Two-Stage Synchronizers**: For synchronizing read pointer into write clock domain and write pointer into read clock domain.
5. **Pointer Increment Logic**: Increment pointers only when enable signals are asserted and FIFO is not full/empty.
6. **Empty and Full Detection**: Compare synchronized Gray pointers with special logic to detect full/empty based on Gray code pointer relationships.
7. **Read/Write Addressing**: Use lower bits of binary pointers for RAM addressing.
8. **Output Registering**: Output read data on the read clock domain synchronized to valid read enable.
9. **Reset Handling**: Separate asynchronous resets for read and write sides.
10. **Modular Design**: Separate submodules for synchronizers and RAM for clarity.

This approach improves separation of concerns, ensures proper metastability mitigation with double flop synchronizers, and uses Gray code for reliable pointer crossing. The full and empty detection logic aligns with the problem statement about MSB and next MSB inversion for full condition.
