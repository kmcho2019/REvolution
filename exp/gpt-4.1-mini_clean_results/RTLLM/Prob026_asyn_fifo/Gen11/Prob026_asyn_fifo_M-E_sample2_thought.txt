Implement an asynchronous FIFO with parameterized width and depth using a modular approach that includes:

- A dual-port RAM submodule for storage with independent read and write clocks and enables.
- Separate write and read pointer counters in binary that are converted to Gray code for synchronization across clock domains.
- Use separate two-stage synchronizers implemented as shift registers to bring Gray pointers into the opposite clock domains.
- For full and empty detection, implement functions to convert Gray code to binary to check pointer equality and full condition per the classic FIFO full logic:
  * Empty when write pointer equals read pointer.
  * Full when the MSBs (2 upper bits) of the write pointer are the inverse of the read pointer’s MSBs and the remaining bits are equal.
- The read and write pointers for RAM addressing are derived from the binary pointers truncated to $clog2(DEPTH).
- Pointer increments occur only when not full (write) or not empty (read) and their increment signals are asserted.
- Reset is synchronous on the respective clocks.
- Implement Gray code and binary conversion functions for clarity and reuse.
- The design uses non-blocking assignments with explicit registers for synchronization and pointer increments.
- Provide all modules within one file for clarity: main FIFO, dual-port RAM, synchronizers.
- The data output is registered on the read clock and updated only when read increment and not empty.
- This approach highlights explicit Gray-to-binary conversions in empty/full logic for explicit correctness checking, while maintaining a clean modular design.

This approach differs from the example by focusing on Gray-to-binary decoding for comparison instead of only Gray pointer comparisons, potentially easing debug and verification.
