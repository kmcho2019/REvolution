This design implements an asynchronous FIFO with parameterized width and depth using a modular approach to clearly separate functional blocks. The FIFO uses a dual-port RAM submodule for storage, with independent write and read pointers managed in binary form and converted to Gray code for synchronization across clock domains.

Key novel aspects:
- Separate dual-port RAM as a submodule instantiated within the FIFO.
- Write and read pointers are maintained as binary counters internally.
- Write and read pointers are converted to Gray code before synchronization across clock domains.
- Two-stage synchronizers capture the Gray-coded pointers from one clock domain to another.
- Full and empty flags are generated by comparing synchronized pointers in Gray code according to the specified conditions:
  - FIFO empty when write pointer equals read pointer.
  - FIFO full when write pointer is one step ahead of read pointer with upper bits inverted.
- The design uses functions to convert between binary and Gray code.
- The RAM address is derived by converting Gray pointers back to binary and taking the lower bits.
- Read data output is registered on the read clock domain.
- Write and read increment signals only increment pointers when not full or empty, respectively.

This modular and clearly separated architecture ensures robust asynchronous operation, proper metastability handling via two-stage synchronizers, and clean full/empty detection based on Gray-coded pointers, while maintaining parameterizable depth and width.
