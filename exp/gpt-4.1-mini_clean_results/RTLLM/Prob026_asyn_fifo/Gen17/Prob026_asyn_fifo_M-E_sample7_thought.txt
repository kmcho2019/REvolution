Implement an asynchronous FIFO with parametrizable width and depth using a modular structure as requested, but with a different architectural approach:

- Use a single gray code pointer for write and read pointers with an additional bit for the wrap-around detection (PTR_WIDTH = $clog2(DEPTH)).
- Use binary pointers internally for RAM addressing (lowest PTR_WIDTH bits).
- Implement a dedicated synchronizer module for cross-domain pointer synchronization with two-stage flip-flops (reusable for both read-to-write and write-to-read synchronization).
- The dual-port RAM module is instantiated as specified, with synchronous read and write clocks and enables.
- Empty and full signals are derived purely from comparing synchronized gray pointers as follows:
  * FIFO is empty when read pointer equals the synchronized write pointer.
  * FIFO is full when the next write pointer (incremented binary) Gray code equals the read pointer with MSB bits inverted (indicating wrap-around).
- The module uses nonblocking assignments for synchronous logic, and all resets are active low asynchronous.
- Read and write enable signals are gated with full and empty flags.
- Read data is updated on the read clock when read enable is asserted.
- The new approach emphasizes clarity with separate pointer synchronization module and explicit pointer conversions.
