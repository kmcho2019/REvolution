I will implement the asynchronous FIFO using a unified pointer scheme with Gray-coded read and write pointers for safe crossing between clock domains. 

However, instead of double-flop synchronizers for the entire Gray pointer, I will implement bit-by-bit synchronizers on the binary pointer synchronized through multiple stages, then convert to Gray on the local domain to slightly simplify synchronization and allow flexible pipeline stages. 

The FIFO depth and width are parameterizable. The dual-port RAM submodule is instantiated with separate read/write clocks and enables.

The full and empty flags are generated by comparing the synchronized Gray pointers. The empty condition is when read and write pointers are equal, and the full condition uses the classical asynchronous FIFO full detection where the MSB and next MSB of the write pointer are inverted relative to the read pointer, and the rest bits are the same.

The write/read controllers only increment pointers when not full/empty and push/pop are requested.

Read data is registered on the read clock domain after the RAM read enable. Reset signals are active-low and synchronous to each clock domain.

This new architecture emphasizes bitwise synchronization of binary pointers before Gray code conversion on destination clock domains, which can reduce metastability and simplify pointer comparison logic. The code is cleanly modular, with a clear data flow from push/pop requests to dual-port RAM memory access and flag generation.
