Implement an asynchronous FIFO with parameterizable WIDTH and DEPTH using a circular buffer approach backed by a dual-port RAM. Instead of synchronizing full binary pointers, synchronize only the Gray-coded read pointer into the write clock domain and the Gray-coded write pointer into the read clock domain using dedicated two-stage flip-flop synchronizers. Maintain binary write and read pointers locally to drive RAM addresses and pointer increments. Use Gray code for safe cross-domain pointer comparisons.

Full condition is detected in the write clock domain by comparing the Gray-coded write pointer to the Gray-coded synchronized read pointer with inverted MSB bits, signaling wrap-around. Empty is detected in the read clock domain by comparing Gray-coded read pointer to synchronized Gray-coded write pointer.

RAM address inputs are the lower bits of binary pointers; data writes and reads are enabled only when not full/empty, respectively. Data output is registered on the read clock when a read is performed.

The dual-port RAM module is a separate submodule with independent clocks and write/read enables, parameterized by WIDTH and DEPTH.

This approach keeps the pointer synchronization logic clean and localized, with minimal registers and clear separation of clock domains. Pointer arithmetic is done in binary domain internally but Gray coding ensures safe pointer crossing. The FIFO depth can be any power of two, and the pointer widths adjust accordingly.

Module and signal names are explicit and follow best practices for readability and maintainability.
