Implement an asynchronous FIFO with parameterizable width and depth. Use a dual-port RAM submodule for storage. Maintain write and read pointers in binary and convert them to Gray code for pointer synchronization across clock domains. Synchronize the read pointer into the write clock domain and the write pointer into the read clock domain using two-stage synchronizers. Use the Gray-coded pointers to generate full and empty flags: empty when pointers are equal, full when write pointer is one ahead of read pointer with the top bits inverted. Access the dual-port RAM using the lower bits of the binary pointers. Manage resets, increments, and pointer increments on respective clocks. Output data from RAM on read clock domain.
