Implement an asynchronous FIFO with parameterizable width and depth using a dual-port RAM submodule for storage. The FIFO manages independent read and write clocks and resets, synchronizes pointers across clock domains using two-stage synchronizers, and represents pointers in Gray code to avoid metastability and simplify full/empty detection. Use binary pointers internally, convert them to Gray code for pointer exchange. The RAM is addressed by the lower bits of the pointers converted back to binary. The full condition is when the write pointer is one cycle ahead in the Gray code domain considering MSBs inversion, and empty when pointers match. Provide all described modules, signals, pointer synchronization, and control logic within one top-level `asyn_fifo` module and the `dual_port_RAM` submodule.
