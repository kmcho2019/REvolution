Implement an asynchronous FIFO with configurable depth and width using Gray code pointers and dual-port RAM. The FIFO consists of a dual-port RAM module for data storage, write and read pointer controllers with Gray code conversion, and synchronizers to safely cross clock domains. The write and read pointers are maintained in Gray code and binary forms. Synchronizers use two-stage flip-flops for metastability mitigation. The full and empty flags are generated by comparing synchronized Gray-coded pointers. The RAM is accessed with lower bits of the binary pointers. Writes and reads occur on respective clock edges when enabled and conditions permit.
