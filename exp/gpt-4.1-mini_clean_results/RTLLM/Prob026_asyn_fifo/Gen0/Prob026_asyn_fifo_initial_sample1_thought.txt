Implement an asynchronous FIFO using a parameterized dual-port RAM module for storage. The read and write pointers are maintained in binary and converted to Gray code for synchronization and pointer comparison. Synchronize the read pointer into the write clock domain and the write pointer into the read clock domain using two-stage flip-flops to avoid metastability. Use Gray code pointers to detect empty and full conditions: empty when read and write pointers are equal; full when the write pointer is one full cycle ahead with the two highest bits inverted. Use Gray-to-binary and binary-to-Gray conversion functions. Access RAM with the lower address bits of the binary pointers. Instantiate the dual-port RAM module, implement write/read controllers, pointer synchronizers, and status logic as described.
