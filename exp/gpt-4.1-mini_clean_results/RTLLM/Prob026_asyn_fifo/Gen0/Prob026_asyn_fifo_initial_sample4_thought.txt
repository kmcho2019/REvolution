Implement an asynchronous FIFO with parameterized depth and width. The FIFO uses a dual-port RAM submodule for data storage with separate read/write clocks and enables. The read and write pointers are managed in binary and converted to Gray code for synchronization and to reduce metastability issues. Two-stage synchronizers transfer pointers across clock domains. The FIFO full and empty conditions are detected using Gray code pointer comparisons. Write and read pointers are incremented upon valid write/read enables, with resets clearing pointers. The RAM uses the lower address bits of the Gray code pointers for actual memory addressing. This modular design ensures clean asynchronous operation between write and read clock domains.
