Implement an asynchronous FIFO module using parameterized WIDTH and DEPTH. The design instantiates a dual-port RAM submodule to handle data storage with separate write and read clocks, enables, addresses, and data ports. The write and read pointers are maintained in binary and converted to Gray code for synchronization across clock domains. Two-stage synchronizers are used to cross read pointer into write clock domain and write pointer into read clock domain. The full and empty conditions are detected by comparing Gray-coded pointers as per the specified rules. The FIFO outputs include data read out, full and empty flags. Write and read increments cause pointer advances synchronized properly with resets.
