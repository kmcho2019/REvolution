Implement an asynchronous FIFO with parameterizable WIDTH and DEPTH using a dual-port RAM for storage. Write and read pointers are managed and converted to Gray code to safely synchronize across clock domains. Two-stage synchronizers are used to transfer pointers between domains. Full and empty flags are generated based on the Gray-coded pointer comparison as specified. The RAM is accessed by binary addresses extracted from the Gray-coded pointers. The design is modularized with a dual-port RAM submodule and the main asyn_fifo module managing pointers, synchronization, and control signals.
