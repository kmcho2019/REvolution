This design implements an asynchronous FIFO using parameterized WIDTH and DEPTH. The FIFO uses a dual-port RAM submodule for storage, with separate read and write clocks. Instead of storing full binary pointers and converting to Gray code on every cycle, the design maintains Gray-coded pointers directly and derives binary addresses by converting Gray code only for RAM addressing. This reduces pointer width usage and simplifies synchronization.

The dual-port RAM module supports separate write and read clocks with independent enables, addresses, and data.

Two-stage synchronizers transfer read pointer into the write clock domain and write pointer into the read clock domain for metastability protection.

The full and empty flags are generated by comparing Gray-coded pointers as follows:

- Empty when read pointer equals synchronized write pointer.

- Full when write pointer is one ahead of read pointer in Gray code with MSBs inverted (typical asynchronous FIFO full condition).

To implement the pointer increment, the FIFO uses Gray code increment logic directly without converting back and forth excessively, simplifying hardware.

The read and write controllers increment pointers only if the FIFO is not empty/full and the respective increment signals are asserted.

RAM addresses come from the lower bits of the binary-converted pointers.

The read data output registers the RAM data on a valid read enable.

The design cleanly separates pointer management, synchronization, RAM instantiation, and flag generation for clarity and modularity.
