Implement the asynchronous FIFO using separate binary write and read pointers that are converted to Gray code for cross-clock domain synchronization. The full and empty flags are generated by comparing synchronized Gray-coded pointers.

Key differences in this design:
- Use full-width Gray-coded pointers with an extra MSB bit (PTR_WIDTH = $clog2(DEPTH) + 1) to differentiate full/empty conditions.
- The RAM address inputs are obtained by converting Gray-coded pointers back to binary, using only the lower bits.
- Synchronize pointers using explicit 2-stage flip-flop synchronizers implemented as separate always blocks, avoiding instantiating submodules.
- Incorporate explicit separate modules for binary-to-Gray and Gray-to-binary conversion functions, improving clarity.
- Write and read pointers increment on valid winc and rinc signals, but only when FIFO is not full or empty, respectively.
- Provide asynchronous resets (active low) for both read and write domains.
- Implement RAM as a synchronous dual-port RAM with separate clocks, and synchronous read and write enables.
- Use the extra MSB in the Gray-coded pointers to detect full condition by checking if write pointer is one lap ahead of read pointer.
- Empty is detected simply when read and write pointers are equal.

This solution focuses on clarity and direct pointer manipulation:
- All synchronization is done with dedicated registers in always blocks.
- Gray code conversion is done with explicit functions.
- RAM addresses are derived from pointer's binary counterparts.
- FIFO parameterized by WIDTH and DEPTH, with DEPTH power-of-two ensured.
- Overall, the code is fully self-contained and easy to verify.

The read data output is registered on the read clock domain for stable data access.

The design fulfills all problem requirements with a different architecture approach.
