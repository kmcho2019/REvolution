Implement an asynchronous FIFO with parameterizable width and depth using:

- Dual-port RAM as a separate module (with separate clocks, enables, addresses, data ports).
- Use binary write and read pointers extended by one bit for full/empty detection.
- Convert these pointers to Gray code for synchronization crossing clock domains.
- Synchronize the Gray-coded pointers across clock domains with two-stage synchronizers.
- Store pointers in binary for address generation by taking the lower bits.
- Use a combinational function for Gray-to-binary and binary-to-Gray conversion.
- Generate full and empty flags by comparing Gray-coded pointers:
  - Full when write pointer next equals read pointer synchronized with MSBs inverted.
  - Empty when read pointer equals write pointer synchronized.
- Increment pointers on write/read enables if not full/empty.
- Output read data registered on the read clock when read enable is asserted.
- Modularize pointer synchronization separately for clarity.
- Carefully handle reset conditions with asynchronous active-low resets.

This approach cleanly separates pointer logic, synchronization, and RAM interface, and strictly follows asynchronous FIFO guidelines with proper pointer synchronization and full/empty detection.
