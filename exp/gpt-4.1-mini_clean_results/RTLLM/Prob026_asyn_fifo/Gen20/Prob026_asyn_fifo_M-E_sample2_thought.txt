Implement an asynchronous FIFO with parameterizable width and depth using a modular design:

- The FIFO uses a dual-port RAM submodule for data storage.
- Write and read pointers are maintained in binary and converted to Gray code for synchronization.
- Instead of using a two-stage pointer synchronizer as separate registers, implement generic two-stage synchronizer modules instantiated for both read pointer into write domain and write pointer into read domain.
- Pointer synchronization is implemented by a separate synchronizer module to improve modularity and reuse.
- Full and empty conditions are detected by comparing Gray-coded pointers directly.
- Write and read pointers increment only on write/read increments and only if FIFO not full/empty respectively.
- The FIFO provides data output registered on the read clock domain.
- Use localparam to derive address and pointer widths.
- The RAM address is taken as the lower bits of the binary pointer converted from Gray pointer.
- Avoid buffering full and empty flags explicitly in flip-flops; instead, derive combinationally but gating pointer increments by full/empty conditions for robust operation.
- Synchronizers for crossing clock domains consist of two flip-flops.
- Implement a parameterized dual-port RAM with behavioral modeling, synchronous write and read.
- Gray-to-binary conversion is done with a function.
- Design emphasizes modularity and clear separation of concerns.

This approach offers a clean separation of synchronizers as reusable modules, avoids mixing pointer and synchronization logic, and uses Gray code pointer comparisons for full/empty detection following the specification rules.
