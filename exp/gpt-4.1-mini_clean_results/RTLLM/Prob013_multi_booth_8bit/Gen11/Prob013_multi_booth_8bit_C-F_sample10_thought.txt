To fuse the best ideas from both examples and fully implement a true Radix-4 Booth multiplier for 8-bit inputs, we combine:

1. True Radix-4 Booth encoding processes two bits per cycle, halving iteration count to 8 cycles instead of 16.
2. Use an explicit FSM (IDLE, BUSY, DONE) for clean state control and ready signaling.
3. Sign-extend inputs to 17 bits (because radix-4 Booth uses an extra appended bit to multiplier for encoding).
4. Implement Radix-4 Booth recoding logic to derive the partial multiple for each 2-bit group of multiplier bits plus an appended zero bit.
5. Accumulate the partial products into a signed product register shifted properly each cycle.
6. Use only synchronous reset on the clock edge for synthesis friendliness.
7. Avoid $signed casts inside always blocks by declaring all registers as signed.
8. Output the final product registered and assert ready for one cycle to signal completion.
9. Keep clean non-blocking assignments and avoid latch inference.
10. This design reduces iteration count from 16 to 8, improving performance by halving multiplication time.
11. The module interface and signal naming follow the original specification.

The main complexity is implementing the Radix-4 Booth recoding which examines bits (2*i+1, 2*i, 2*i-1) from the multiplier (with a zero appended bit) to decide which multiple of multiplicand to add (0, ±1, ±2). We implement a small function for this and accumulate the shifted partial sum accordingly.

This yields a synthesis-friendly, truly Radix-4 Booth multiplier with faster operation and proper ready signaling.
