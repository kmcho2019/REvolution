This new design implements an 8-bit Radix-4 Booth multiplier as a sequential datapath without an explicit FSM; instead it uses a simple counter to manage operation cycles. The multiplicand and multiplier inputs are loaded on reset with sign extension.

Key novel points:
- The multiplier register is extended by 2 extra bits at LSB side (multiplier[1:0]) to simplify radix-4 Booth recoding directly from 3 bits at a time (bits [1:0] plus a shifted-in zero).
- On each cycle, the 3 LSB bits of the multiplier register are decoded to determine the partial product using radix-4 Booth encoding. Partial products include multiples of multiplicand: 0, ±1, ±2.
- The partial product is added to a 32-bit accumulator (enough width to avoid overflow during intermediate steps).
- The multiplier register is arithmetically shifted right by 2 bits each cycle to process the next radix-4 digit.
- A 3-bit counter counts from 0 to 4 (since for 8-bit inputs, Radix-4 requires ceil(8/2)=4 steps).
- The module asserts 'rdy' when computation is done and outputs the lower 16 bits of the accumulator.
- This design separates combinational Booth partial product logic (with a function) from sequential accumulation and shifting, simplifying verification.
- It uses signed arithmetic with explicit sign extension, and a dedicated function to calculate the Booth code product, improving clarity.
- No FSM; the control is implicit with the counter and ready flag, reducing overhead.
- Using 32-bit accumulator allows safe addition and shifting without overflow.
- On reset, the module loads inputs and clears accumulator and counter; then performs 5 cycles of operation (0 to 4), and asserts ready.
- This approach is compact, easy to follow, and optimizes sequential hardware usage for radix-4 Booth multiplier.

This is a clean, function-based radix-4 Booth implementation focused on clarity and correctness.
