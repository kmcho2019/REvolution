I will refactor the design by implementing a Moore FSM with explicit state registers and next-state logic separated into dedicated always blocks for clarity. The partial product accumulator and multiplier shift logic will be handled in a single sequential block, while the Booth decoding logic will be implemented as a separate combinational function but invoked in a procedural way for clearer pipelining. 

Instead of variable shifts of the partial product, I will accumulate the partial product shifted appropriately by shifting the multiplicand left by 2*iteration count before addition. This reduces variable shifting on the accumulator side.

The multiplier will be shifted arithmetically right by 2 bits on each cycle, but this time using a separate sequential process for clarity.

Outputs (product and ready) will be registered only in the DONE state, and the multiplicand, multiplier, accumulator, and counter will be stored in registers and updated explicitly based on FSM states.

This reorganization enhances modularity, separates combinational and sequential logic more clearly, and makes ready and output signals update only in the DONE state, keeping outputs stable. The reset synchronously initializes all registers. The multiplier register is sign-extended and appended with one zero LSB for Booth encoding.

The FSM states will be IDLE, CALC, DONE.  
- In IDLE, waits for reset to be deasserted, initializes registers.  
- In CALC, performs multiplication steps (5 steps for 8-bit radix-4 Booth).  
- In DONE, output is valid and ready is asserted until reset.

The code will use non-blocking assignments inside sequential always blocks and continuous assignment (`assign`) for simple wires (e.g., Booth bits extraction). This separation and explicit FSM improve readability and maintainability while keeping the same core algorithm and interface.

This refactor retains the original radix-4 Booth logic and output width but structures control and datapath distinctly and cleanly.
