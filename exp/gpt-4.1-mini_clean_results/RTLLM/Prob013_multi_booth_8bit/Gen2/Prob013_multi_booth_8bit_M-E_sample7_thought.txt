Implement the Radix-4 Booth multiplier as a finite state machine with the following approach: 

- On reset, sign-extend the inputs to 16 bits, load the multiplier into a 17-bit register with an appended zero bit for Booth encoding, and initialize an accumulator to zero. 

- Use a 3-bit counter to iterate four times, each time extracting 3 bits (overlapping) from the multiplier register to determine the Booth encoding group.

- Decode the Booth encoding to get the multiplicand multiples (-2, -1, 0, 1, 2) and shift them accordingly based on the current iteration.

- Accumulate the partial products into the accumulator.

- After four cycles, assign the lower 16 bits of the accumulator to the product output and set the ready signal high.

Variables and registers needed (all declared outside always block) are used inside the sequential always block. This avoids syntax errors related to variable declarations inside procedural blocks.

This architecture performs multiplication in 4 clock cycles (plus reset), cleanly separates decoding logic via a function, and efficiently uses sign-extensions and shifting to implement Radix-4 Booth multiplication.
