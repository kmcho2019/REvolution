To simplify the implementation while maintaining functionality:

- Use synchronous reset only on the positive clock edge.
- Remove signed declarations and use unsigned registers, handling sign-extension manually where needed.
- Combine multiplicand and multiplier into a single 32-bit shift register that holds the partial product and multiplier bits, commonly used in Booth multipliers.
- Process one bit per clock cycle (radix-2 approach, not full radix-4) for simplicity.
- On reset, load multiplicand and multiplier with sign extension.
- On each cycle, based on the LSB of multiplier portion, add or subtract the multiplicand from the partial product.
- Shift the combined register right arithmetically each cycle.
- Use a 5-bit counter for 16 cycles.
- When counter reaches 16, output the product and assert ready.
- This approach significantly reduces complexity and code size while correctly implementing signed multiplication via Booth algorithm basics.
