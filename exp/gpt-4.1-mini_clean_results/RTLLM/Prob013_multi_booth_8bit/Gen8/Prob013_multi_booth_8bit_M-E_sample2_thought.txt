Implement an 8-bit Radix-4 Booth multiplier using a sequential finite state machine with asynchronous reset. On reset, sign-extend the inputs into 16-bit registers: multiplicand and multiplier (stored together with an extra bit for Booth encoding). Use a 5-bit counter to track steps, processing two multiplier bits per cycle. At each cycle, extract a 3-bit booth code from multiplier bits (including a trailing bit for encoding), decode it to ±0, ±1, or ±2 times multiplicand, shift appropriately, and accumulate to the partial product register. After 4 cycles (since radix-4 processes 2 bits per cycle for 8-bit multiplier), set ready high and output the product. Variables and signals are declared at module level, avoiding illegal declarations inside procedural blocks. The design uses asynchronous reset and synchronous data updates on clock edges.
