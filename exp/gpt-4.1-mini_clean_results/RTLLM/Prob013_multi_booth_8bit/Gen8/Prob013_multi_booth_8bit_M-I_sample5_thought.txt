To properly implement an 8-bit Radix-4 Booth multiplier according to the problem statement while preserving its structure and interface:

- The original solution treated multiplier bits one by one, which is a bit-serial multiplication, not radix-4 Booth.
- Radix-4 Booth encoding groups the multiplier bits in overlapping 3-bit groups (including an extra bit), effectively encoding 2 bits per cycle, reducing iterations roughly by half.
- We'll implement a sequential Radix-4 Booth multiplier with 4 cycles (since 8 bits → 4 radix-4 steps).
- On reset, sign-extend multiplicand and multiplier to 16 bits.
- Use a 5-bit counter (ctr) to count from 0 to 7 (total 8 bits processed 2 bits at a time → 4 cycles).
- The algorithm uses a modified multiplier register shifted right by 2 bits each cycle to process next Booth slice.
- For each cycle:
  - Extract a 3-bit group (bits: current LSB, next bit, and an extra bit from previous iteration or zero) for Booth encoding.
  - Determine partial product multiple of the multiplicand based on Booth encoding:
    - 0: 0
    - 1: +M
    - 2: +2M
    - 3: -2M
    - 4: -M
    - Others: 0
  - The partial product is shifted left by 2*ctr to align the bits correctly.
- Accumulate partial products into the product register.
- After 4 cycles, multiplication completes; set ready signal.
- This approach respects the problem's requirements (16-bit product, clocked logic, reset, ready signal).
- All registers are declared at module level with proper synchronous reset.
- The code uses non-blocking assignments to avoid race conditions and is fully synthesizable.
- This radix-4 Booth implementation reduces cycles from 16 to 4 and uses proper encoding logic.
