Implement an 8-bit Radix-4 Booth multiplier module named multi_booth_8bit. The module uses synchronous operation with clk and reset signals. On reset, extend inputs a and b to 16-bit signed values and load them into multiplicand and multiplier registers. Use a 5-bit counter to count from 0 to 16. During each clock cycle when reset is low and counter < 16, shift multiplicand left by 1, check multiplier bit at position ctr; if it is 1, add multiplicand to product p. Increment counter each cycle. When counter reaches 16, set ready signal rdy to 1 to indicate multiplication done.
