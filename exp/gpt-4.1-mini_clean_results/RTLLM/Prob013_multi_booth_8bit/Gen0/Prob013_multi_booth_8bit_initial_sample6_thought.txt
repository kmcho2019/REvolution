Implement a synchronous 8-bit multiplier using a radix-4 Booth algorithm with a shift-accumulate approach. On reset, extend inputs a and b to 16-bit signed values and initialize the multiplier and multiplicand registers. Use a 5-bit counter for up to 16 steps. On each clock cycle, if not finished, shift the multiplicand left by one and if the multiplier bit at current counter is 1, add multiplicand to the product. Once done, set ready signal. This approach follows the provided behavior and signals completion via rdy.
