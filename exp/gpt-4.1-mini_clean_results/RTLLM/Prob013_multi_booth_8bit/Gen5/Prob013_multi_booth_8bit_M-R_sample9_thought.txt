Refactor the Radix-4 Booth multiplier by implementing a simple finite state machine (FSM) with two states: IDLE and CALC. On reset, the inputs are sign-extended and loaded, the ready signal is cleared, and the multiplier register is prepared with the appended zero. In CALC state, for each cycle, decode the 3 Booth bits using a combinational function, update the accumulator with the partial product, shift the multiplier register right arithmetically by 2, and increment the counter. Once four cycles are done, output the product and assert ready, then return to IDLE. This modular FSM structure cleanly separates the input loading and computation phases and uses combinational Booth decoding functions instead of always blocks. The code uses a clocked FSM with minimal combinational logic outside clocked blocks.
