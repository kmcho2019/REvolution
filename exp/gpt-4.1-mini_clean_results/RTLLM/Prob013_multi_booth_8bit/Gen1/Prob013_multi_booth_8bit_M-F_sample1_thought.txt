Implement a true Radix-4 Booth multiplier for 8-bit inputs by processing the multiplier bits in overlapping groups of 3 bits (including an extra bit) each cycle. Radix-4 reduces the number of iterations to 4 (instead of 8 for bit-by-bit). The Booth encoding for each 3-bit group determines how much to add or subtract the multiplicand shifted accordingly:

- The multiplier is sign-extended by 1 bit and appended by a 0 bit at LSB (to get (2 * n + 1) bits for n=8 => 17 bits).
- At each cycle (for i = 0 to 3), examine bits [2*i+1 : 2*i-1] of the extended multiplier to get the Booth code.
- Based on the Booth code (000 to 111), calculate the partial product addition or subtraction of multiplicand times 0, 1, 2, -1, or -2 accordingly.
- Accumulate the partial products shifted by 2*i bits (because each group covers 2 bits).
- Use a state machine with 4 cycles to do the 4 partial products.
- Use signed arithmetic by sign-extending inputs to 16 bits.
- On reset, initialize all registers and clear ready.
- On normal operation, each clock cycle process one Booth group; after 4 cycles, set rdy = 1 and output the result.
- The product p is 16-bit because the product of 8-bit signed numbers fits in 16 bits.
- Keep multiplicand and multiplier extended to signed 16 bits for arithmetic.
- Implement all arithmetic with proper sign extension and 2’s complement handling for the multiplicand multiples.
- This corrects the previous code’s errors: no shifting of multiplicand itself, proper Booth radix-4 encoding, fewer cycles (4 instead of 16), and accurate ready signaling.

This design avoids synthesis issues by using synchronous registers and combinational decoding of Booth digits, fitting the specification and optimized for FPGA or ASIC flow.
