To optimize the radix-4 Booth multiplier implementation for better performance, power, and area (PPA), the following improvements are made:

1. **Proper Radix-4 Booth Encoding**: The original solution acts like a radix-2 multiplier by examining one multiplier bit per cycle and shifting multiplicand by one bit per iteration. Radix-4 Booth encoding examines two bits (plus a previous bit) per cycle, reducing iterations by half (from 16 to 8). This reduces cycle count and power.

2. **Registers and Widths**: Use 17 bits for multiplier (including one appended zero bit) to correctly extract 3 bits for Booth recoding. Sign-extend inputs properly.

3. **Booth Recoding**: Implement Booth recode logic to generate partial multiplicand multiples: -2, -1, 0, +1, +2 times multiplicand per cycle, using simple combinational logic and adders, reducing additions.

4. **Shift Amount**: The partial product is shifted by two bits per cycle to reflect radix-4 grouping.

5. **Synchronous FSM with IDLE and CALC states**: On reset, load inputs; in CALC state, perform 8 iterations.

6. **Ready Signal**: Assert ready when multiplication completes.

7. **Nonblocking assignments and clean separation of control and datapath**.

These changes significantly reduce cycle count (8 vs 16), thus saving power and improving throughput. Using radix-4 partial products reduces additions, and shifting partial product by 2 bits each cycle reduces shifting overhead. The code is fully synchronous with clean state handling.

Overall, this provides a true radix-4 Booth multiplier with improved PPA while preserving the interface.
