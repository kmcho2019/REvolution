Refactor the original radix-4 Booth multiplier by implementing an explicit state machine with three states: IDLE, CALC, and DONE. This clarifies the operation phases and enables better control of the ready signal and register updates.

Key refactoring points:
- Use an explicit state register to control the multiplication process, making the start and ready signaling clearer.
- Separate combinational Booth partial product generation from the sequential accumulation and shifting, improving code clarity.
- Calculate the Booth code in a dedicated combinational block, with registered multiplicand and multiplier.
- Shift the multiplier right logically by 2 bits each cycle and update the step counter in the sequential block.
- Use synchronous reset and non-blocking assignments consistently.
- Keep accumulator width and output the 16 LSBs as the product.
- The ready signal is asserted only in the DONE state.
- Inputs (a, b) are latched at the start of multiplication to avoid timing glitches.
- This structuring improves timing predictability, eases debugging, and provides a clean separation of concerns.

The core radix-4 Booth algorithm remains intact, including the sign extensions, the 3-bit Booth recoding window, and accumulation of partial products shifted by 2*step. The difference is the explicit FSM and combinational separation of booth partial product calculation.

This approach is more modular and typically synthesizes better due to the controlled state transitions and simpler combinational logic per clock cycle.
