Implement a simplified 8-bit Radix-4 Booth multiplier by using a straightforward sequential algorithm without a separate booth_decode function or complicated partial multiple shifting. Instead, process the multiplier bits one pair at a time (two bits per cycle), using simple addition/subtraction of multiplicand multiples shifted by count*2 bits.

Keep the multiplicand and multiplier sign-extended and stored in registers. At each clock cycle, extract the two bits from the multiplier to decide which multiple of the multiplicand to add or subtract.

Use a 5-bit counter to run for 8 cycles (since 8 bits / 2 bits per cycle = 4 cycles; but radix-4 requires half the cycles, so 4 cycles suffice). After the last cycle, output the 16-bit product and assert the ready signal.

To reduce complexity, implement the Booth encoding logic inline with a simple case statement based on the two multiplier bits plus an appended zero bit, avoiding a separate function. Avoid variable shifts by accumulating the partial sum with pre-shifted multiplicand multiples.

Keep the ready flag to signal completion. Use synchronous reset to initialize registers and start the process.

This approach is simpler, with less combinational logic per cycle, easier to understand and implement, while still meeting functionality requirements.
