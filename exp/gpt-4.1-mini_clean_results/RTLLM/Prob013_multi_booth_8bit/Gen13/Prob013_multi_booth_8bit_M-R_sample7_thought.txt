I will refactor the radix-4 Booth multiplier to separate the control state machine from the datapath more clearly and reduce combinational complexity inside the clocked process. Instead of computing the Booth code and partial product inside the always block, I will use combinational logic (`assign`) for the Booth recoding and partial product generation, while the sequential block only updates registers (accumulator, multiplier, step, ready).

Key points:
- Use a simple 3-state FSM: IDLE (waiting for reset or input), RUN (performing steps), DONE (holding result).
- Inputs 'a' and 'b' will be loaded into internal signed registers upon reset.
- The Booth recoding 3 bits and partial product are computed in continuous combinational logic.
- On each clock cycle during RUN, accumulator is updated by adding precomputed partial product shifted by 2*step.
- The multiplier is shifted right arithmetically by 2 bits each cycle in a registered way.
- The 'rdy' signal is asserted only in DONE state.
- This structure improves code readability, separates combinational from sequential logic, and may help with timing by isolating combinational paths.
- The multiplier extension and sign extension are handled at input loading.
- Use non-blocking assignments in sequential always block; combinational assigns outside.

This approach keeps the radix-4 Booth algorithm logic intact but organizes code with a FSM and clearly separates combinational parts (Booth code, partial product) from sequential updates, which is a good practice for synthesis and debugging.
