Refactoring idea:

- Use an explicit FSM with four states: IDLE, LOAD, RUN, DONE to clearly separate initialization, computation, and completion phases.
- Perform sign-extension of inputs and multiplier preparation (with appended zero LSB) in the LOAD state rather than at reset.
- Keep the multiplier and multiplicand as separate registers with fixed widths.
- Implement the Booth partial product generation as a combinational function outside the sequential always blocks.
- Use a 5-bit counter to count 5 iterations (each processes 2 bits radix-4).
- On each RUN cycle, add the shifted partial product to the accumulator and shift the multiplier register arithmetically by 2 bits.
- Use non-blocking assignments in the sequential block.
- Output the product and ready signal only in the DONE state, holding them stable.
- Avoid variable shifts by performing shift left by 2*iteration using simple shift by constant (iteration * 2).
- Separate next state logic combinationally.
- Reset synchronous only.
- This structure improves readability, modularity, and clarity while maintaining the same radix-4 Booth logic.
