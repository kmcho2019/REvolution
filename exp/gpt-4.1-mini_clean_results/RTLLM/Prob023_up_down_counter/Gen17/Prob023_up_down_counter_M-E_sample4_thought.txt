Implement the counter using an arithmetic approach with a signed 16-bit intermediate variable that either adds +1 or -1 depending on the up_down input. This approach avoids separate combinational next_count logic by embedding the arithmetic directly in the synchronous block, simplifying the design. 

By declaring the counting direction as a signed value (+1 or -1), the code becomes succinct and clear, and it naturally supports increment and decrement in a single arithmetic operation. The synchronous block handles reset, counting direction, and updating the count in one place, improving readability while keeping the design fully synchronous and synthesizable.

This design also eliminates the need for a separate combinational always block, which might reduce combinational logic delay at the cost of some code compactness.
