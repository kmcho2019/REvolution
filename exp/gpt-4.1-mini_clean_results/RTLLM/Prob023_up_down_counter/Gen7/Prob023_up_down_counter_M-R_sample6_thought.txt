Refactor the up_down_counter by separating the combinational increment/decrement logic from the synchronous register update. Use an intermediate wire `next_count` to hold the next value, computed combinationally using a conditional operator based on `up_down`. Then, update the `count` register synchronously on the rising clock edge or reset. This separation improves code clarity by explicitly defining the next state computation and then registering it, which is a common and clear design pattern. The functionality remains identical but the structure shows a clear dataflow from combinational next-state logic to sequential state update.
