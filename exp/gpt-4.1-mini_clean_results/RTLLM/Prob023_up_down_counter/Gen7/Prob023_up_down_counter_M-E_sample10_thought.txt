Implement the 16-bit up/down counter using a single always block with an explicit if-else structure inside the sequential logic. Instead of a separate combinational next_count signal, directly update the `count` register inside the clocked process. This approach simplifies the design by folding the combinational and sequential logic together, reducing wire usage.

The module resets synchronously on the rising edge of `clk` when `reset` is asserted, setting the count to zero. Otherwise, it increments or decrements `count` by 1 depending on the `up_down` input. This version relies solely on sequential logic, making it straightforward for synthesis tools.

This design trades off explicit next-state combinational logic for minimal code complexity and direct clarity in the always block. The always block uses non-blocking assignments for proper register inference and synchronous behavior.

Key points:
- Use one always @(posedge clk) block for reset and counting.
- If reset is high, set `count` to zero.
- Else increment or decrement `count` depending on `up_down`.
- No separate combinational wire.
- Non-blocking assignment to avoid race conditions.

This method is a classical approach, easy to understand and synthesize, with a minimalistic code footprint.
