Refactor the up_down_counter to use a continuous assignment for the next count calculation combined with a clocked always block for the register update. 

Specifically, calculate the next count value using an assign statement and a conditional (ternary) operator. Then, inside the sequential always block triggered by clk's rising edge, update the count register or reset it synchronously. 

This approach reduces the number of always blocks, simplifies the combinational logic to a single line, and showcases how Verilog's assign statements can cleanly express simple combinational logic.
