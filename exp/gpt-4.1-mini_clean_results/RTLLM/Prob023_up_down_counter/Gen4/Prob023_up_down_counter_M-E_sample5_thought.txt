Implement the 16-bit up/down counter using a parameterized module with a separate increment and decrement function encoded as combinational logic. Use a localparam to set the width, making it reusable. The always block synchronously updates the count using a combinational next_count signal calculated based on the up_down input. This design clarifies the separation between combinational logic (next_count calculation) and sequential logic (count register update), improving code readability and synthesis tool inference. The synchronous reset clears the count to zero. Non-blocking assignments ensure correct sequential behavior.
