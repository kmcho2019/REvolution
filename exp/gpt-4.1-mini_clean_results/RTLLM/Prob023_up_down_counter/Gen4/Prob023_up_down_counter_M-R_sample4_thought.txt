Refactor the synchronous up/down counter by separating the next-state logic from the state register update. Compute the next count value combinationally using an assign statement based on the current count, reset, and up_down signals, and then update the count register synchronously at the clock edge. This separation improves code readability by clearly distinguishing combinational and sequential parts, makes it easier to add features like enable signals, and maintains synthesizability. The counter still uses synchronous reset and non-blocking assignments for proper sequential behavior.
