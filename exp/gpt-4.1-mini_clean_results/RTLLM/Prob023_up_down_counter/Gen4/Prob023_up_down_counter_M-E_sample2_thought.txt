Implement a 16-bit up/down counter with synchronous reset using a combinational next-count calculation and a registered count update. On each rising clock edge, if reset is asserted, set count to zero. Otherwise, calculate the next count value based on up_down input: if up_down is high, add one; if low, subtract one. Then update count with this next value. This modular approach separates next state logic from state register update, improving code clarity and making it easier to extend the design.
