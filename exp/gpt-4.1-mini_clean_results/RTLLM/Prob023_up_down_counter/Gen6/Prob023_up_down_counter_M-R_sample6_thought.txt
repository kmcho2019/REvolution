Refactor the up/down counter by separating the next state logic from the state register. Use a combinational always block to compute the next count value based on the current count, reset, and up_down inputs. Then update the count register in a sequential always block on the rising edge of clk. This structural separation improves code readability and mimics a finite state machine style with distinct combinational and sequential blocks, while preserving the same synchronous reset and count update behavior.
