Implement the 16-bit up/down counter using a two-process approach: one process to handle synchronous reset and clock enabling, and a separate combinational logic block to calculate the next count value. This method explicitly separates the state update from the next state logic, improving readability and modularity. Instead of using a ternary operator inside the always block, pre-calculate the next value with a combinational always block and then register it synchronously. This architecture allows easier extension, such as adding enable or overflow flags later, and can be beneficial for formal verification or testbench modularity. The counter uses unsigned arithmetic and leverages natural wrap-around behavior. Reset remains synchronous.
