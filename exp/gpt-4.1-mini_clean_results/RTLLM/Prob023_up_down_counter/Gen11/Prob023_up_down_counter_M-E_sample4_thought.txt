Implement the up/down counter using an explicit signed offset value (`+1` or `-1`) assigned in a combinational block based on the `up_down` signal, and then add this offset to the current count inside the synchronous clocked block. This separates the direction logic from the counting logic for clarity and may facilitate easier modifications for more complex increment/decrement steps in the future. The reset remains synchronous. This design highlights the distinction between control signal decoding and data path update, making the code modular and scalable.
