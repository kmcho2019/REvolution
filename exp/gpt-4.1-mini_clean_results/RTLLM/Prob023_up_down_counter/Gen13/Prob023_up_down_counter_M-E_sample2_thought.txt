Implement the 16-bit up/down counter using a single synchronous always block with a case statement that handles the three possible states: reset, increment, and decrement. Instead of a separate combinational block, integrate the counting logic inside the synchronous block, but add saturation logic to prevent overflow/underflow. That is, when incrementing at maximum value (16'hFFFF), the count stays at 0xFFFF, and when decrementing at zero (16'h0000), the count stays at zero. This approach prevents wrap-around and is a design variant that might be useful for saturating counters in control applications. The synchronous reset sets the count to zero immediately. This method avoids separate next-state registers and uses conditional logic inside a single always block to achieve counting and saturation, differentiating from common wrap-around counters.
