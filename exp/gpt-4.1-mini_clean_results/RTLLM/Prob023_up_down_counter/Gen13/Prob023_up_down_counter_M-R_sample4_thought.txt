Refactor the synchronous up/down counter by separating the next state logic into a combinational always block and the state update into a synchronous always block. This two-process style separates combinational calculation from sequential state update, which is a common RTL design pattern that improves code readability and eases formal verification. Instead of using the conditional operator directly inside the clocked always block, calculate the next counter value combinationally based on `up_down` and assign it to a register on the clock's rising edge. This approach explicitly shows the separation between the counter's next value calculation and the actual state update, enhancing clarity and maintainability without changing functionality.
