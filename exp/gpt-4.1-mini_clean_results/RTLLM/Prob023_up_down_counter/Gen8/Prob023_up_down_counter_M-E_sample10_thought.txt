Implement the 16-bit up/down counter using a combinational adder and a registered previous count. Instead of directly incrementing or decrementing in the always block, calculate the next count combinationally using a ternary operator selecting between adding 1 or subtracting 1, then update the count on the rising clock edge with synchronous reset. This separates combinational arithmetic from sequential logic, improving code readability and possibly aiding synthesis optimizations.
