Implement the 16-bit up/down counter using a single 16-bit register for the count and a combinational next-state logic inside the clocked process:

- Use a single 16-bit register `count_reg` to hold the counter value.
- On each clock rising edge, synchronously reset `count_reg` to zero if `reset` is active.
- Otherwise, conditionally increment or decrement the entire 16-bit register based on the `up_down` signal.
- This approach uses a single arithmetic operation which is typically optimized by synthesis tools into an adder/subtractor.
- It simplifies the logic, reduces register count, and likely improves timing by eliminating ripple carry between bytes.
- The output `count` is directly assigned from `count_reg`.
- Overall, the design is cleaner, more efficient, and simpler, facilitating synthesis and optimization.
