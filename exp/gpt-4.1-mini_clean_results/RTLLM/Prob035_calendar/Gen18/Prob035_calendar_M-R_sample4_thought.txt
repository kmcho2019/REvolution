Refactor the calendar module by separating the combinational next state logic from the synchronous state update logic to improve clarity and modularity. Instead of computing all next values inside a single always block, use continuous assign statements to compute the next seconds, minutes, and hours based on the current counter values. Then use a single always block with synchronous reset to update the registers on the clock edge. This structure makes combinational logic and sequential logic distinct, which can improve readability and help synthesis tools optimize better. It also uses simple logic equations for rollovers instead of nested if-else statements.
