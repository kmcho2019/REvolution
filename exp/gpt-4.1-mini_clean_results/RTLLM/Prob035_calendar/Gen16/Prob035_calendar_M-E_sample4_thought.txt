Implement the perpetual calendar using a single always block triggered on posedge CLK and posedge RST. This approach centralizes the logic and reduces redundant evaluations, potentially improving timing by minimizing dependencies between separate always blocks.

Within the single always block:
- On reset, clear Hours, Mins, and Secs to zero.
- Otherwise, increment Secs by 1 each clock.
- If Secs overflows (reaches 60), reset it to 0 and increment Mins.
- If Mins overflows (reaches 60), reset it to 0 and increment Hours.
- If Hours overflows (reaches 24), reset it to 0.

Use 6 bits for Secs and Mins (0-59), and 5 bits for Hours (0-23).

This structure resembles a ripple counter inside a single always block, which simplifies clock-to-output paths and keeps counter increments tightly coupled. It improves synthesis optimizations and reduces switching power by performing minimal conditional checks per clock.
