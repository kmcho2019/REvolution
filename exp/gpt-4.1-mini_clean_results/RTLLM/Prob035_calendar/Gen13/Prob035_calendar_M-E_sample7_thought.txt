Implement the perpetual calendar using three separate always blocks, each responsible for one time unit: seconds, minutes, and hours. Each block triggers on posedge CLK or posedge RST. The seconds block increments seconds from 0 to 59 and resets to 0 on overflow. The minutes block increments only when seconds overflow from 59 to 0, and wraps at 59. The hours block increments only when both minutes and seconds overflow from 59 to 0, and wraps at 23. This modular separation allows simpler logic per block and better pipelining or timing optimization. Use nonblocking assignments and handle asynchronous reset properly in each block.
