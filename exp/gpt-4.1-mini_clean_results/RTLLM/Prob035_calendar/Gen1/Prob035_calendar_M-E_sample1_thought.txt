Implement the perpetual calendar using a single always block triggered on posedge CLK or posedge RST. Combine the logic for seconds, minutes, and hours counters within that block to ensure synchronized update and simple cascading. On each clock tick, if reset is asserted, clear all counters to zero. Otherwise, increment seconds; if seconds wrap from 59 to 0, increment minutes; if minutes wrap from 59 to 0 together with seconds, increment hours; if hours reach 23 and both minutes and seconds wrap, reset hours to zero. Using a single always block reduces clock fanout and guarantees atomic updates to all time fields in a single cycle.
