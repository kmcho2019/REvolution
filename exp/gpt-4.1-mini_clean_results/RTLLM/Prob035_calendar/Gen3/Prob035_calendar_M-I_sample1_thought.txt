To optimize the original single always block design for better PPA, especially timing and power, we separate the counters into three always blocks as originally requested. Each block updates one time unit (Secs, Mins, Hours) triggered on posedge CLK or RST. This modular approach reduces combinational logic depth on the critical path for each counter, improving timing. It also limits unnecessary toggling: minutes update only when seconds wrap, hours update only when minutes and seconds wrap, lowering dynamic power. Using non-blocking assignments ensures proper sequential updates. This design matches the problem specification precisely, improving timing with minor area overhead while maintaining low power.
