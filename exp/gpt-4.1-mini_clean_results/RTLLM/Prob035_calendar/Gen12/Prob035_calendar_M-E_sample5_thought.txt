Implement the calendar using a single always block with synchronous reset to simplify logic and improve timing. Use a single always block triggered on posedge CLK only, and a synchronous reset inside it. This avoids asynchronous reset timing issues.

Introduce a carry propagation approach:
- Increment seconds on every clock cycle; when seconds roll over (reach 60), reset to 0 and generate a carry to minutes.
- On the same clock, if carry from seconds, increment minutes; if minutes roll over (reach 60), reset to 0 and generate a carry to hours.
- On the same clock, if carry from minutes, increment hours; if hours roll over (reach 24), reset to 0.

This avoids multiple always blocks, eases timing analysis, and ensures all counters update atomically in one clock cycle.

Additionally, use a parameter to define maximum counts for reusability and code clarity.

Use non-blocking assignments for sequential logic. Hours remains 5 bits, Mins and Secs 6 bits.

This design is modular, efficient, and more power-friendly by centralizing counter logic.
