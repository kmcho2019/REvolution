Implement a frequency divider module named freq_diveven that divides the input clock frequency by an even number specified by the parameter NUM_DIV. The module uses a 4-bit counter to count input clock cycles. When the counter reaches half of NUM_DIV minus one, the counter resets and toggles the output clock signal clk_div. Resetting asynchronously clears the counter and output clock. This effectively divides the input clock frequency by NUM_DIV, assuming NUM_DIV is an even number.
