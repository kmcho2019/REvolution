Implement a frequency divider module named freq_diveven that divides the input clock by an even number specified by the parameter NUM_DIV. The module uses a 4-bit counter (cnt) to count clock cycles up to NUM_DIV/2 - 1. On each clock cycle, cnt increments until reaching this threshold, then resets and toggles the output clock_div signal. Reset (rst_n) asynchronously clears cnt and clk_div.
