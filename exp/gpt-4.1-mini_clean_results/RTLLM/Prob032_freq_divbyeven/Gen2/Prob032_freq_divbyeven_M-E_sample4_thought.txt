Implement the frequency divider by using a counter that counts clock cycles up to half of the division factor (NUM_DIV/2). Each time the counter reaches this midpoint, toggle the output clock and reset the counter. This way, the output clock period equals NUM_DIV input clock cycles, achieving frequency division by an even number. Using a 4-bit counter with asynchronous active-low reset initializes both counter and output to zero. The toggling on half counts ensures a 50% duty cycle and clean output clock.
