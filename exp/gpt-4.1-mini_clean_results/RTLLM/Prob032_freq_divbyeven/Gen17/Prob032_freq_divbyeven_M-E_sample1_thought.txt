Implement the frequency divider using a single counter that counts from 0 up to NUM_DIV-1 and toggles clk_div exactly when the counter reaches half of NUM_DIV. This approach uses a full-cycle count instead of counting half cycles and toggling at the halfway point.

Specifically:
- The counter counts from 0 to NUM_DIV-1.
- When the counter reaches NUM_DIV/2 - 1, clk_div is set high.
- When the counter reaches NUM_DIV - 1, clk_div is set low and counter resets.
This generates a square wave with 50% duty cycle and frequency divided by the even number NUM_DIV.

This approach effectively simulates a simple up-counter with output clock being high for half the counts and low for the other half.

Additional features:
- Parameter NUM_DIV validated at runtime to be an even number >= 2.
- Counter width automatically derived from NUM_DIV.
- Synchronous active-low reset.
- clk_div initialized to 0 on reset.
