Implement the counter using a single always block triggered on the positive clock edge with synchronous reset. Use the valid_count signal as an enable condition inside the always block to update the counter only when counting is valid, thus avoiding unnecessary combinational logic for next-state calculation outside the clocked process. The counter increments until it reaches 11, then wraps back to 0. This simplifies the logic by embedding the count wrap condition and increment logic directly within the sequential block, which can improve timing by reducing combinational path complexity. This design also uses non-blocking assignments for correct synthesis behavior.
