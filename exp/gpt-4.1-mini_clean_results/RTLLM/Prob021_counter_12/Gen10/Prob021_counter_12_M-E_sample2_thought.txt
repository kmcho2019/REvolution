Implement a 4-bit modulo-12 counter using a combinational next-state logic separate from the sequential always block to clearly separate state update and next-state calculation. The counter increments only when valid_count is high; otherwise, it holds the current value.

Key points:
- Use an internal register 'count_reg' to hold the current state.
- Use a combinational always block to compute 'next_count' based on 'count_reg' and 'valid_count'.
- If reset (active low) is asserted, the output resets to zero.
- When 'count_reg' reaches 11 and counting is enabled, wrap back to zero.
- The output 'out' is assigned directly from 'count_reg' for clean separation.
- This approach makes it easy to modify or extend next-state logic and improves readability.
