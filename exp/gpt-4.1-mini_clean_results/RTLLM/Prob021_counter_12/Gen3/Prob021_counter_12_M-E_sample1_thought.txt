Implement the counter with a combinational next-state logic and a registered output. Use a synchronous active-low reset to clear the count. The next count value is computed based on the current output and the valid_count signal: if valid_count is 0, the next state remains the same as the current state (holding the count); if valid_count is 1, the count increments and wraps around to 0 after reaching 11. This separates combinational logic from state storage, enhancing readability and enabling easier modifications like extending counting range or adding additional control signals.
