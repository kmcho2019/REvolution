Implement a modulo-12 counter using a binary up-counter and a conditional reset to zero when the count reaches 12 (decimal). Instead of checking for 11, detect count == 12 (4'b1100) to roll over, thus counting from 0 to 11 inclusively. Use a synchronous active-low reset and a clock enable driven by valid_count to ensure the counter increments only when valid_count is asserted, pausing otherwise. This design explicitly uses a clock enable to gate counting, which avoids unnecessary toggling inside the register when valid_count is low, improving power efficiency. The rollover condition is implemented as a comparator on count == 12, leveraging synthesis-friendly equality checks. The reset sets the counter to zero asynchronously (active low). The counter output is a 4-bit register reflecting the current count value.
