Implement the counter as a synchronous up-counter with an explicit enable signal driven by valid_count. Instead of using a separate next-state logic block, directly update the count within a single sequential always block triggered by the clock and reset signals. On reset (!rst_n), reset the count to zero. On each rising clock edge, if valid_count is high, increment the count; when the count reaches 11 (decimal), wrap back to zero. Use a single non-blocking assignment block for clarity and compactness. This approach simplifies the code by combining counting and reset in one place without separate combinational logic.
