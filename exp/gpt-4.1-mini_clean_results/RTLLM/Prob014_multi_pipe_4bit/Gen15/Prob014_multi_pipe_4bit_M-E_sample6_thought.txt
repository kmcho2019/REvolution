Implement a 4-bit unsigned multiplier with two-stage pipeline registers as follows:

- Stage 1: Instead of generating all partial products for all bits simultaneously, use a generate block to create partial products for the lower half bits (bits 0 and 1) of the multiplier and sum them together, registering their intermediate sum. This reduces the number of partial product sums per stage.

- Stage 2: Similarly, generate partial products for the upper half bits (bits 2 and 3) of the multiplier, sum them together, and add that result to the registered sum from stage 1, finally registering the output product.

This approach splits the multiplication into two halves of partial products, each partial sum registered at a pipeline stage, ensuring balanced pipeline stages and reducing the long combinational path of summing all four partial products at once.

All arithmetic is done using zero-extended multiplicand (by adding 'size' zeros at MSB side) for alignment.

Reset is asynchronous active low. Registers and output are zeroed on reset.

This structure provides a clean two-level pipelined multiplier with balanced computational complexity per stage and matches the problem requirement.
