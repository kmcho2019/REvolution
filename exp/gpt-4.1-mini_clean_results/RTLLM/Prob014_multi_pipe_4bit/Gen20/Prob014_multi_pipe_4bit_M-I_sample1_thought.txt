Improve the existing 4-bit pipeline multiplier by addressing timing and resource usage without changing the specified two pipeline register stages. Key improvements:

- Instead of registering all partial products separately (which can lead to large register arrays and synthesis issues), perform a partial sum tree in the first pipeline stage to reduce the number of operands for the second stage addition.
- Specifically, group partial products pairwise and register their sums at stage 1, so stage 2 only sums two registered operands instead of four.
- Maintain the extension of the multiplicand with size zeros on MSB side.
- Use non-blocking assignments consistently.
- Keep asynchronous active-low reset for all registers as required.
- This reduces combinational logic depth in stage 2, improving timing.
- Keeps pipeline stages and functionality as requested.
