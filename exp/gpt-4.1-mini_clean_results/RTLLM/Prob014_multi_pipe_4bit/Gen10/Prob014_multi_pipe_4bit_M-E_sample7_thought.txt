Implement a fully pipelined 4-bit unsigned multiplier using two pipeline stages as requested, but with a novel approach:

- Stage 1: Generate all partial products combinationally and register them in a single vector (concatenated partial products). This avoids using an array of registers and reduces register complexity.
- Stage 2: Use an adder tree implemented combinationally on the registered partial products from Stage 1, then register the final summed result.

Details:
- Extend multiplicand by prepending 'size' zero bits (high-order bits) to get 2*size bits.
- For each multiplier bit i, partial product = (mul_b[i] ? ext_mul_a << i : 0).
- Concatenate partial products into a single wide vector and register them at Stage 1.
- In Stage 2, implement a balanced binary adder tree to sum partial products combinationally from the Stage 1 register output.
- Register the final product output at Stage 2.
- Use parameter `size = 4`.
- Reset asynchronously active-low, zero all registers on reset.
- This approach uses two pipeline registers, complies with the problem statement, and balances register usage and combinational complexity.
- The balanced adder tree reduces critical path compared to a simple linear adder loop.

This method differs from the prior approach by packing partial products in a vector register at stage 1, and performing a balanced combinational sum in stage 2.
