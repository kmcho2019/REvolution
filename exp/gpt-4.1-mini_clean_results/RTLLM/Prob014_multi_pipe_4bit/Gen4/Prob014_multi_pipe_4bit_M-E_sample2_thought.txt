Implement a 4-bit unsigned pipelined multiplier using a classical shift-and-add approach with two pipeline stages of registers:

1. Input Extension: Extend multiplicand and multiplier by size bits with zeros at the MSB, as requested.

2. Partial Product Generation: Instead of generating all partial products combinationally at once, generate one partial product per clock cycle using the LSB of the current multiplier register.

3. Pipeline Stages:
   - Stage 1: Registers store the multiplicand, current multiplier, and the intermediate sum (accumulated partial products).
   - Stage 2: Registers store the final accumulated sum (the final product).

4. Operation:
   - On reset, clear all registers.
   - On each clock edge, if reset is inactive:
       a) Extract the LSB of the multiplier register to decide if multiplicand shifted by current bit is added to the accumulator.
       b) Shift multiplier register right by one (effectively moving to next bit).
       c) Shift multiplicand left by one (prepare for next partial product position).
       d) Accumulate partial sums.
   - After size clock cycles, the accumulator will have the final product.

5. Outputs:
   - The output register holds the final product updated at the second pipeline stage.

This approach introduces a controlled pipelined multiplication over multiple cycles but since the problem requests two pipeline registers to store intermediate values and process, this two-level pipeline with partial product accumulation matches that well:

- Stage 1 register: holds multiplicand, multiplier, and partial sum.
- Stage 2 register: holds final multiplication result.

This design differs from the fully combinational partial-product adder tree and meets the two-register pipelined design requirement, with clear synchronous behavior and reset handling.

The final code is fully synchronous, includes parameterization, and properly extends inputs, performs partial product computation, and updates output synchronously.

This approach is a classic iterative multiplier pipelined into two stages with registers, different from the adder tree approach.
