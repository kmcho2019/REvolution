To improve timing (reduce critical path delay) and power efficiency, the multiplication summation will be split into multiple pipeline stages. Instead of adding all 8 partial products in one combinational step, we implement a balanced adder tree across several pipeline registers:

- Stage 1: Generate and register 8 partial products (16-bit each).
- Stage 2: Pairwise add these 8 partial products to get 4 sums, register the results.
- Stage 3: Add pairs of the 4 sums to get 2 sums, register the results.
- Stage 4: Add the final 2 sums to get the product, register output.

This creates a 5-stage pipeline (including input sampling stage), with enables shifted accordingly.

Advantages:
- Each addition stage involves 16-bit additions with only two operands, significantly shortening critical path per clock cycle.
- Pipelined registers inserted between stages break long combinational paths, enabling higher frequency operation.
- Power reduced due to fewer operands summed simultaneously and lower glitch propagation.
- Output enable is generated by shifting the input enable signal through a 5-bit shift register to align with pipeline latency.

This approach balances timing, power, and area efficiently while keeping the design fully synchronous and easy to understand.

Reset is asynchronous active low for all registers.

Output is zero when output enable is low.
