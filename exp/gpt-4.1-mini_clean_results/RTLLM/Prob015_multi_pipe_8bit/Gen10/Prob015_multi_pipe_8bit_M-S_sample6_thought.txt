Implement a simple two-stage pipeline multiplier for unsigned 8-bit inputs, with minimal control logic to reduce complexity. 
Stage 1 registers the inputs and input enable. Stage 2 computes all partial products in combinational logic and sums them in one step, registering the final product and output enable. 
Output is gated by the registered enable. This keeps the pipeline depth minimal and code simple, while ensuring correct enable propagation and valid output timing.
