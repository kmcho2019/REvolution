Implement an 8-bit unsigned multiplier using pipelining to increase throughput. The design registers inputs and the input enable signal, then generates partial products by ANDing the multiplicand with each bit of the multiplier. These partial products are then summed in a pipelined manner across several clock cycles, with each pipeline stage registering intermediate sums to create a pipeline. The final sum is registered as the multiplication output and is valid only when the pipelined input enable signal reaches the output stage. The output enable signal is derived from the last bit of the pipelined enable register indicating valid output data. The reset signal clears all registers.
