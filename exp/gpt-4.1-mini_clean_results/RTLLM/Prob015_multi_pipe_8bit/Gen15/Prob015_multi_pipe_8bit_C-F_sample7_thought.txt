Fuse the 4-stage pipeline structure and balanced partial product addition from Example 1 with the simplicity and strict control of input sampling and enable gating from Example 2. 

Fusion Strategy:
- Use a 4-stage pipeline to maximize throughput and timing performance.
- Propagate mul_en_in through a 4-bit shift register pipeline to track data validity at each pipeline stage.
- Sample mul_a and mul_b only when mul_en_in is asserted to reduce toggling.
- Generate all 8 partial products combinationally from registered inputs.
- Use a balanced multi-stage adder pipeline to sum partial products in smaller groups:
  * Stage 1 sums partial_products[0..2]
  * Stage 2 sums partial_products[3..5]
  * Stage 3 sums partial_products[6..7]
  * Stage 4 sums the three intermediate sums into final product.
- Update each pipeline register only when the corresponding stage’s enable bit is high to minimize unnecessary switching.
- Output enable derived from MSB of enable pipeline.
- Output product is zeroed if output enable is low.
- Use non-blocking assignments in sequential blocks and combinational always for output mux.
- This design balances timing and power by pipelining addition and gating registers with valid enables, while keeping code clarity and simplicity.

This fusion yields a design with low latency (4 cycles), high throughput (1 multiplication per cycle), improved timing from balanced adds, and reduced power from selective register enabling.
