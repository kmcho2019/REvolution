Fuse the structured multi-stage partial sum pipeline of Example 1 with the clean input sampling and enable handling of Example 2 to design a balanced 4-stage pipelined unsigned 8-bit multiplier.

Fusion Strategy:
- Use a 4-stage pipeline for mul_en_in signal to track data validity through the pipeline and derive mul_en_out.
- Sample inputs (mul_a, mul_b) only when mul_en_in is asserted, keeping registers updated with valid inputs.
- Generate all 8 partial products combinationally from registered inputs as shifted multiplicand masked by multiplier bits.
- Divide the partial products summation into three balanced groups (0..2, 3..5, 6..7) to reduce the addition fan-in per stage and improve timing.
- Register sums at each pipeline stage only if the corresponding mul_en_pipe bit is active to reduce switching.
- Final stage adds the three partial sums to produce the final product registered and output.
- Output product is valid only when mul_en_out (MSB of enable pipeline) is asserted; otherwise, output zero.
- Use synchronous reset to clear registers.
- This fusion preserves the clean input/enable control of Example 2 and the timing-friendly multi-stage summation of Example 1, improving max clock frequency and reducing critical path delay, while keeping power and area balanced.

This design offers:
- Clean data and enable path control.
- Balanced pipeline with moderate latency (4 cycles).
- Reduced combinational complexity per stage for better timing.
- Controlled switching by updating registers only on valid enables.
- Clear output enable synchronization.
