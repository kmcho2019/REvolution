The traffic light controller will be implemented as a finite state machine with three main states: red, yellow, and green. The state transitions are controlled by a counter that counts down from preset values (10 for red, 5 for yellow, 60 for green). When the pedestrian button is pressed during green light, if remaining time is >10 cycles, it shortens to 10 cycles. The outputs are synchronized with the clock and reset signals. The design follows these key principles:
1. State machine with clear transitions
2. Counter logic with conditional shortening
3. Synchronous output generation
4. Proper reset handling
