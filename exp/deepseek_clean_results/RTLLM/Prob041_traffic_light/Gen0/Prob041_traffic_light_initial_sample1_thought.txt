The traffic light controller will be implemented as a finite state machine with three main states: red, yellow, and green. The design will:
1. Use a counter to track the duration of each light state
2. Implement the pedestrian request logic that shortens green time to 10 cycles if pressed when remaining time >10
3. Maintain proper light sequencing with specified durations (60 green, 5 yellow, 10 red)
4. Handle reset conditions properly
5. Output both the light states and current counter value

The state transitions will occur when the counter reaches zero, and the pedestrian request will modify the counter during green phase if conditions are met.
