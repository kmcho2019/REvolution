The traffic light controller will be implemented as a finite state machine with four states: idle, red, yellow, and green. The state transitions are controlled by a counter that counts down clock cycles for each state. The pedestrian button (pass_request) will modify the green light duration if pressed during green phase. The outputs will be synchronized to the clock and reset signals.

Key points:
1. State machine with idle, red (10 cycles), yellow (5 cycles), and green (60 cycles) states
2. Pedestrian button shortens green to 10 cycles if pressed during green phase with >10 cycles remaining
3. Counter logic handles state timing and special cases
4. Outputs are registered for clean transitions
5. Reset initializes to idle state
