The traffic light controller will be implemented as a finite state machine with three main states: red, yellow, and green. The system will:
1. Use an 8-bit counter to track timing for each state
2. Implement state transitions based on counter values (10 for red, 5 for yellow, 60 for green)
3. Handle pedestrian requests by shortening green time to 10 cycles if remaining time >10
4. Maintain proper light pairing (lane and sidewalk lights are complementary)
5. Reset to red state with 10-cycle count when reset is active

The design uses sequential logic for state transitions and combinational logic for output generation.
