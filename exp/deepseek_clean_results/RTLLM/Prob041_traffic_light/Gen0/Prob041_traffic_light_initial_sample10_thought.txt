The traffic light controller will be implemented as a finite state machine with three main states: red, yellow, and green. The system will:
1. Use an 8-bit counter to track timing for each state
2. Implement the normal timing sequence (60 cycles green, 5 yellow, 10 red)
3. Handle pedestrian button interrupts by shortening green time to 10 cycles if remaining time > 10
4. Maintain proper light pairing (lane and sidewalk lights are opposites)
5. Include reset functionality
6. Output the current counter value for monitoring

The design will use sequential logic for state transitions and counter management, with combinational logic for next-state determination and output generation.
