The traffic light controller will be implemented as a finite state machine with three main states: red, yellow, and green. The system will:
1. Use an 8-bit counter to track timing for each state
2. Implement state transitions based on counter values (10 for red, 5 for yellow, 60 for green)
3. Handle pedestrian button press by shortening green time to 10 if remaining time > 10
4. Maintain proper light pairing (lane and sidewalk lights are opposites)
5. Reset to initial state when rst_n is low

Key considerations:
- State transitions occur when counter reaches 0
- Pedestrian request only affects green light duration
- Output signals are registered to avoid glitches
- Counter is reloaded appropriately for each state
