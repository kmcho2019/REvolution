Refactoring Strategy:
1. State Machine: Convert the enum-based state machine to a binary-encoded one using parameters for better synthesis control.
2. Output Logic: Move from procedural assignments to continuous assignments (assign) for the light outputs, making them purely combinational functions of the state.
3. Counter Logic: Simplify the counter management by separating the pedestrian request handling from the main counter logic.
4. Structure: Use two always blocks (state register + counter) and assign statements for outputs, reducing sequential logic complexity.

Key Changes:
- Binary state encoding replaces enum for explicit control
- Outputs become continuous assignments based on state
- Pedestrian logic moved to separate conditional block
- Counter reset logic simplified with case statement
- Maintains same functionality but with cleaner structure
