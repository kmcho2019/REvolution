Refactored Approach: Combinational State Machine with Unified Control Logic

Key Refactoring Changes:
1. Converted the state machine to use combinational logic for next state determination
2. Implemented output generation through continuous assignments (assign)
3. Unified counter control into a single always block
4. Simplified pedestrian request handling with immediate effect
5. Used parameterized durations for better maintainability

Structural Improvements:
- State transitions now determined purely by combinational logic
- Outputs generated through assign statements for better timing
- Counter logic consolidated into one always block
- Pedestrian request handled synchronously with priority
- Clear separation between control and output logic
