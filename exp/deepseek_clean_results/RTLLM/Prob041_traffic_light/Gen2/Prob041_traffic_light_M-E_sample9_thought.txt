Here's a novel approach using a time-wheel architecture for the traffic light controller:
1. Instead of separate counters for each state, implement a single time wheel that rotates through all states
2. Use a shift register to represent the time wheel, where each bit position corresponds to a clock cycle
3. The pedestrian request triggers a special "fast-forward" mode that jumps to the minimum green time
4. State outputs are derived directly from the current position in the time wheel
5. This eliminates the need for explicit state machines and counters, reducing logic complexity

Key advantages:
- Single unified timing structure simplifies control logic
- Pedestrian request handling becomes just a position adjustment in the wheel
- Easily scalable to add more timing patterns
- Reduced state transition logic
