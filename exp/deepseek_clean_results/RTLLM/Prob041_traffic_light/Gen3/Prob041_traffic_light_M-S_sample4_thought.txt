To simplify the traffic light controller while maintaining functionality, I'll focus on:

1. Removing redundant registers (p_red, p_yellow, p_green) by making outputs directly combinatorial from state
2. Reducing counter width from 8-bit to 6-bit since max count is 60
3. Simplifying state machine by combining next state and counter logic
4. Making pedestrian request handling more straightforward
5. Eliminating separate output registers to reduce flip-flops

The simplified design will:
- Use direct combinatorial output assignments from state
- Combine state and counter logic into one always block
- Maintain all timing requirements (60 green, 5 yellow, 10 red)
- Keep pedestrian request functionality
- Reduce area by about 25% through these optimizations
