Novel Architecture Idea: Time-Sliced State Machine with Dynamic Duration Adjustment

Key Innovations:
1. Time-Sliced Operation: Instead of using a single counter, we'll implement separate time slices for each state, making timing control more precise and independent.
2. Dynamic Duration Adjustment: The green duration adjustment will be handled through a separate process that monitors the pedestrian request and adjusts the remaining time slice.
3. State Duration Registers: Each state will have its own duration register that can be dynamically modified when needed.
4. Predictive State Transition: The next state will be determined one cycle in advance to ensure smooth transitions.
5. Output Pre-Calculation: Light outputs will be pre-calculated based on the next state to avoid glitches during transitions.

Advantages:
- More precise timing control
- Clean separation of timing and state logic
- Easier to modify durations dynamically
- Reduced combinatorial paths
- Better handling of asynchronous requests
