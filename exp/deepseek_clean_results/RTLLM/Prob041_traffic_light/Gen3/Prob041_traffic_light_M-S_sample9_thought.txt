The simplified traffic light controller will maintain the same functionality but with reduced complexity through:
1. Removing intermediate registers (p_red, p_yellow, p_green) and directly assigning outputs from state
2. Using a 6-bit counter instead of 8-bit since max count is 60
3. Simplifying the counter logic by removing redundant conditions
4. Combining state transition and output logic where possible
5. Maintaining all original functionality including pedestrian request handling
6. Keeping the same state machine structure but with cleaner implementation
