To simplify the traffic light controller while maintaining functionality, I'll make these key changes:

1. Use binary encoding for states (2 bits) instead of one-hot (3 bits) since we only have 4 states
2. Remove redundant output hold conditions since states are mutually exclusive
3. Simplify counter logic by directly loading next state's count
4. Combine output assignments into the state transition logic
5. Remove unnecessary default state handling
6. Keep the same timing parameters but simplify their usage

The simplified design will:
- Maintain identical functionality
- Reduce state machine complexity
- Minimize redundant logic
- Keep the same interface
- Improve readability while maintaining performance
