To simplify the traffic light controller while maintaining functionality, I'll focus on:

1. Removing redundant registers (p_red, p_yellow, p_green) by making outputs directly combinatorial from the state
2. Reducing counter width from 8-bit to 6-bit since max count is 60
3. Simplifying state transition logic by combining counter reload with state transitions
4. Making pedestrian request handling more straightforward
5. Removing unnecessary idle state since we immediately transition to s1_red

The simplified design will:
- Use minimal registers (just state and counter)
- Have cleaner state transitions
- Maintain all original timing requirements
- Keep the same pedestrian request behavior
- Reduce area while preserving functionality
