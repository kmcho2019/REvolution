Refactoring Strategy:
1. State Machine Restructuring: Convert the sequential always block state machine to a combinational next-state logic with registered state storage
2. Counter Logic Separation: Move counter logic to a separate always block for better modularity
3. Output Generation: Use continuous assignments for outputs to simplify the design
4. Pedestrian Logic: Implement as a separate combinational block for clarity
5. Parameterization: Keep timing parameters but make them more explicit
6. Reset Handling: Maintain synchronous reset but make it more visible in the code structure

Key Improvements:
- Clear separation of state transition logic from counter logic
- More modular design with distinct functional blocks
- Easier to modify individual components
- Maintains same functionality while improving readability
- Better alignment with synchronous design practices
