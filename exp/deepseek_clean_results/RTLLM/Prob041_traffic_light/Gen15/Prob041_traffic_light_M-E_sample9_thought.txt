Novel Architecture: Predictive Time-Division State Machine with Dynamic Counter Adjustment

Key Innovations:
1. Predictive Counter Adjustment: Instead of checking pedestrian request every cycle, we predict the next state transition point when request arrives
2. Time-Division State Encoding: Combine state and counter into a single "time remaining" value, reducing state transitions
3. Dynamic Thresholds: Implement adaptive timing where pedestrian requests dynamically adjust the state thresholds
4. Early Transition Detection: Special logic detects when to initiate state transitions before counter reaches zero
5. Unified Counter-State: Eliminate separate state register by encoding state in counter value ranges

Advantages:
- Reduced logic complexity by merging state and counter
- Faster response to pedestrian requests through predictive adjustment
- More efficient implementation with fewer registers
- Clear separation of timing parameters and control logic
- Better scalability for adding more states or timing parameters
