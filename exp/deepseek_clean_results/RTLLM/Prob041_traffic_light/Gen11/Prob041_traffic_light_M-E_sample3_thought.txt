Novel Architecture:
1. Time-Division Counter: Instead of separate counters for each state, use a single counter that counts continuously and derives state from counter ranges. This reduces logic complexity.
2. Priority-Based State Machine: Implement a priority encoder for state transitions where pedestrian requests have higher priority than normal operation.
3. Dynamic Timing Adjustment: Use combinational logic to dynamically adjust the counter thresholds based on pedestrian requests.
4. Output Encoding: Use binary encoding for states to minimize area while maintaining readability.
5. Predictive Counting: The counter starts counting down from the next state's duration during the last cycle of current state, enabling seamless transitions.

Key Benefits:
- Reduced logic complexity with single continuous counter
- Immediate response to pedestrian requests
- Efficient state encoding
- Predictive counting eliminates transition delays
- Easier timing closure with simpler counter logic
