Refactoring Strategy:
1. State Encoding: Replace enum with explicit binary encoding for more direct control over state representation.
2. Output Logic: Use continuous assignments (assign) for outputs instead of procedural blocks to simplify and potentially improve timing.
3. Counter Logic: Combine state transition and counter logic into a single always block for more compact implementation.
4. Pedestrian Logic: Maintain the same functionality but implement with ternary operators for conciseness.
5. Structure: Use two always blocks (state+counter, next_state) and continuous assignments for outputs.

Key Changes:
- Binary state encoding (00:IDLE, 01:RED, 10:YELLOW, 11:GREEN)
- Outputs driven by continuous assignments based on current state
- Combined counter and state transition logic
- Simplified pedestrian request handling with ternary operator
- More compact implementation while maintaining same functionality
