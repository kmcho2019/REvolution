Refactoring Strategy:
1. State Encoding: Replace enum with binary encoding for more explicit control over state representation.
2. Output Logic: Use continuous assignments (assign) for outputs instead of procedural blocks for simpler combinatorial logic.
3. Counter Logic: Maintain the same counter behavior but express it more concisely.
4. Pedestrian Logic: Keep the same functionality but implement it in a more streamlined way.
5. Structure: Use two always blocks (state transition and counter) plus continuous assignments for outputs.

Key Changes:
- Binary state encoding (00:IDLE, 01:RED, 10:YELLOW, 11:GREEN)
- Outputs driven by continuous assignments based on current state
- Simplified counter reset conditions
- More compact state transition logic
- Same timing parameters and pedestrian behavior
