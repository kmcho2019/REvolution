Refactoring Strategy:
1. State Machine: Convert the enum-based state machine to a binary-encoded one using parameters for better synthesis control.
2. Output Logic: Move from procedural assignments to continuous assignments (assign) for combinational outputs.
3. Counter Logic: Keep the counter management similar but simplify the state transition conditions.
4. Pedestrian Logic: Maintain the same behavior but express it more concisely.
5. Structure: Use two always blocks (sequential for state/counter, combinational for next state) plus assign statements for outputs.

Key Changes:
- Binary state encoding replaces enum for explicit control
- Output signals become wire types assigned via continuous assignments
- Next state logic moves to a separate combinational block
- Counter logic remains similar but with simplified expressions
- Maintains same functionality with different implementation style
