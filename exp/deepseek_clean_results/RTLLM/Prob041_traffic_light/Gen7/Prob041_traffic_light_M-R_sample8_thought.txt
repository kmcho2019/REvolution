Refactoring Strategy:
1. State Encoding: Replace enum with binary encoding for more explicit control and potential area savings.
2. Output Logic: Use continuous assignments (assign) for outputs instead of procedural blocks for simpler combinational logic.
3. Counter Management: Combine counter logic with state transitions into a single always block for more compact implementation.
4. Pedestrian Logic: Keep the same functionality but implement with ternary operators for conciseness.
5. Structure: Use two always blocks (state register + combined logic) and assign statements for outputs.

Key Changes:
- Binary state encoding (00=IDLE, 01=RED, 10=YELLOW, 11=GREEN)
- Outputs driven by continuous assignments based on state
- Combined counter and transition logic
- Simplified pedestrian request handling with ternary operator
- Removed next_state variable by computing directly
