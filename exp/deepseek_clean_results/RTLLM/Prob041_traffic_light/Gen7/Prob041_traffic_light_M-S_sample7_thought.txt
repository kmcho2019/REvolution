To simplify the traffic light controller while maintaining functionality, I'll make these key optimizations:
1. Replace one-hot encoding with binary encoding (2 bits) for the state machine to reduce area
2. Remove parameterization since timing values are fixed per requirements
3. Simplify counter logic by directly using required values (60,5,10)
4. Combine light output assignments with state transitions
5. Remove unnecessary intermediate registers
6. Implement basic pedestrian request handling without additional parameters

The simplified design will use minimal resources while meeting all functional requirements:
- 60 cycles green, 5 yellow, 10 red
- Pedestrian request shortens green to 10 if >10 remains
- Proper light pairing (lane vs sidewalk implied)
- Reset functionality
