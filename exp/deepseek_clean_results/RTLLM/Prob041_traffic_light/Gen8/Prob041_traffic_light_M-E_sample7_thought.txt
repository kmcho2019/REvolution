Novel Architecture: Hierarchical State Machine with Time-Sliced Counting
1. Concept: Implement a two-level state machine where the top level handles major states (red, yellow, green) and the bottom level handles time management.
2. Innovation: Use a time-sliced approach where the counter is managed separately from state transitions, allowing more flexible timing control.
3. Pedestrian Handling: Implement a priority-based interrupt system for pedestrian requests that can preempt the normal timing sequence.
4. Output Control: Use combinatorial output logic based on current state for minimal latency.
5. Optimization: Implement a configurable timer module that can be reused for different states, reducing redundant logic.

Key Features:
- Separates timing logic from state transitions
- Implements priority-based pedestrian request handling
- Uses parameterized timing for flexibility
- Optimized counter management with early termination
- Clear separation of concerns between timing and state control
