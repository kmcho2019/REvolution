Refactoring Strategy:
1. State Machine Restructuring: Convert the sequential always block state machine to a combinational always block + sequential state register for clearer separation of next-state logic
2. Output Logic: Move from continuous assignments to registered outputs for better timing
3. Counter Logic: Separate the counter decrement logic from state transitions for modularity
4. Pedestrian Logic: Extract the green time reduction logic into a separate always block for clarity
5. Parameter Usage: Keep parameterized timing values but make them localparams since they shouldn't change

Key Benefits:
- Clear separation of combinational and sequential logic
- Better timing with registered outputs
- More modular design with distinct functional blocks
- Maintains same functionality while improving code structure
