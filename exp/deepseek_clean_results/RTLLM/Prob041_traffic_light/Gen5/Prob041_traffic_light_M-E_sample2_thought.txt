Here's a novel architectural approach using a time-sliced design with parallel counters:
1. Instead of a single counter, maintain separate counters for each light state (red, yellow, green)
2. Use a priority encoder to determine which counter is active
3. Implement a "time banking" system where pedestrian requests can borrow time from green phase
4. Use one-hot encoding for states to simplify decoding logic
5. Add hysteresis to pedestrian requests to prevent rapid toggling

Key innovations:
- Parallel counters reduce critical path by eliminating counter reload logic
- Time banking allows more flexible pedestrian request handling
- One-hot states enable simpler output generation
- Hysteresis prevents request bouncing
