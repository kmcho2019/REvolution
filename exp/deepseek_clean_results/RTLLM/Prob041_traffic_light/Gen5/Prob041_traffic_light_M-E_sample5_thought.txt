New Architecture Idea:
1. Unified Counter Approach: Instead of separate counters for each state, use a single continuous counter that wraps around, with state transitions based on counter thresholds.
2. Time Slot Allocation: Divide the entire cycle (75 clocks) into fixed slots where each state occupies its designated time window.
3. Priority-based Pedestrian Handling: Implement a priority encoder that forces state transition to yellow if pedestrian request comes during green time with >10 clocks remaining.
4. Predictive State Machine: The next state is determined by comparing the counter value against predefined thresholds rather than counting down per state.

Key Benefits:
- Reduced logic complexity by eliminating multiple counter resets
- More deterministic timing behavior
- Easier to modify timing parameters
- More efficient pedestrian request handling
