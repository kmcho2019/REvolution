Based on the PPA metrics and feedback, I'll optimize the design with these improvements:

1. One-hot encoding for state machine: This will improve timing performance by reducing decode logic, though it slightly increases area.
2. Counter optimization: Implement a parallel load counter to reduce ripple delay and improve timing.
3. Output encoding: Use 2-bit encoding for traffic lights since only one is active at a time.
4. Power gating: Add clock gating for the counter when not in use.
5. State machine simplification: Remove IDLE state since it immediately transitions to S1_RED.

The optimized design will:
- Improve timing performance (reduce TNS/WNS)
- Reduce power consumption
- Maintain similar area while improving performance
- Keep the same functionality
