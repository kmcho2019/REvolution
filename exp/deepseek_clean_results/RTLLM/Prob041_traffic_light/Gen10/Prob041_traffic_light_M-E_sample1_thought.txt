Novel Architecture: Time-Priority Encoder with Dynamic State Adjustment
1. Instead of fixed state durations, implement a dynamic duration system where each state has a base duration but can be adjusted based on external inputs
2. Use a priority encoder to handle multiple concurrent requests (pedestrian button + normal operation)
3. Implement a "time banking" system where unused green time can be carried over to the next cycle
4. Separate the timing logic completely from the state machine for better modularity
5. Use a "time remaining" counter that's independent of the state transitions

Key Innovations:
- Dynamic duration adjustment based on real-time conditions
- Priority-based request handling
- Time banking for more efficient light cycles
- Decoupled timing and state logic for better maintainability
- Predictive state transitions based on time remaining
