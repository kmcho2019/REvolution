Novel Approach: Time-Sliced State Machine with Dynamic Duration Adjustment

This design introduces a novel approach by:
1. Using a time-sliced state machine where each state has its own dedicated counter
2. Implementing dynamic duration adjustment through parallel comparison logic
3. Separating the pedestrian request handling into an independent process
4. Using a unified counter that automatically adjusts based on both state and requests
5. Implementing a priority encoder for state transitions

Key innovations:
- Each state maintains its own duration parameters
- Pedestrian requests are processed asynchronously without disrupting state flow
- Counter adjustments happen in a single clock cycle for better timing
- State transitions are determined by a priority-based system
- Output generation is completely decoupled from state logic
