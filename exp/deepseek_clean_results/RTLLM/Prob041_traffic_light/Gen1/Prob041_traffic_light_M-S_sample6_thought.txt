The simplified solution maintains the same functionality but reduces complexity by:
1. Using a single always block for state and counter management
2. Eliminating intermediate registers (p_red, p_yellow, p_green)
3. Directly assigning outputs based on current state
4. Simplifying the pedestrian request logic
5. Using clearer state transition conditions
The timing requirements remain: 60 cycles green, 5 yellow, 10 red, with pedestrian request shortening green to 10 if >10 remains.
