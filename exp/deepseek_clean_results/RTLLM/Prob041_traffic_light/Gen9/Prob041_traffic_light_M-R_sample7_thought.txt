Refactoring Strategy:
1. State Machine Restructuring: Convert the sequential always block state machine to a combinatorial always block for state transitions with a separate sequential block for state registration. This improves timing analysis and makes the state transitions more explicit.
2. Counter Logic: Move counter logic to a separate always block for better modularity and clearer timing control.
3. Output Generation: Use continuous assignments (assign) for outputs to make them purely combinatorial and easier to analyze.
4. Pedestrian Logic: Isolate the pedestrian request handling in the green state for better readability.
5. Parameter Usage: Keep parameters but make them more descriptive.

Key Improvements:
- Clear separation of combinatorial and sequential logic
- More modular design with distinct blocks for state, counter, and outputs
- Explicit state transition conditions
- Maintains same functionality while improving code structure
