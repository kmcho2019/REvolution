Novel Architecture: Time-Remaining Counter with Parallel State Tracking
1. Dual-Counter Approach: Maintains both a time-remaining counter and a phase-duration counter for better pedestrian request handling
2. Priority-Based Request Handling: Uses a request latch to ensure pedestrian requests are processed exactly once per cycle
3. Predictive State Transition: Pre-calculates next state to simplify timing logic
4. Output Encoding: Uses one-hot encoding for light outputs to simplify combinatorial logic
5. Dynamic Timing Adjustment: Allows runtime modification of timing parameters through the counter system
6. Early Transition Detection: Special logic detects when to start transition sequence based on both counters

Key Innovations:
- Parallel counters enable more sophisticated timing adjustments
- Request latching prevents multiple adjustments during same green phase
- Predictive state calculation simplifies transition logic
- One-hot outputs reduce decode complexity
- Runtime-configurable timing parameters
