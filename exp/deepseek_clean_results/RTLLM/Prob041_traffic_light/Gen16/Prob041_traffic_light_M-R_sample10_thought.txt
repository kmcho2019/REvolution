Refactoring Strategy:
1. State Encoding: Convert to one-hot encoding for potentially better timing and readability
2. Counter Logic: Move counter logic to a separate always block for cleaner separation of concerns
3. Output Generation: Use continuous assignments for outputs to make them more explicit
4. Pedestrian Logic: Implement as a separate combinational block for clarity
5. State Transitions: Use explicit next-state logic with a single state register update
6. Parameter Organization: Group related parameters for better maintainability

Key Changes:
- One-hot state encoding improves readability and potentially timing
- Separated counter logic from state transitions
- Explicit next-state calculation before register update
- Combinational pedestrian logic block
- Continuous assignments for all outputs
- More modular structure while maintaining same functionality
