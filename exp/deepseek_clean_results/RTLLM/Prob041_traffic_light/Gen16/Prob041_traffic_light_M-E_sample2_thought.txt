Novel Architecture Idea: Time-Sliced State Machine with Predictive Counter
1. Instead of a simple state machine, implement a time-sliced approach where each state has its own dedicated counter
2. Use a predictive counter that pre-calculates the next state's timing requirements
3. Implement a priority-based pedestrian request handling system that can interrupt the current timing
4. Use a shadow counter for pedestrian requests to avoid timing glitches
5. Separate the timing logic from state transitions for better modularity
6. Implement a "time banking" system where unused green time can be carried over to the next cycle

Key Innovations:
- Predictive counter reduces state transition latency
- Shadow counter ensures smooth timing during pedestrian requests
- Time banking allows for more flexible traffic flow control
- Modular design separates timing and state logic for better maintainability
