Refactoring Strategy:
1. State Encoding: Convert the enum-based state machine to a binary-encoded one with parameters for better synthesis control.
2. Output Logic: Move from procedural assignments to continuous assignments (assign) for combinational outputs.
3. Counter Logic: Keep the same counter behavior but express it more concisely.
4. Pedestrian Logic: Maintain the same functionality but implement it in a more streamlined way.
5. Structure: Use two always blocks (sequential for state/counter, combinational for next state) plus continuous assignments for outputs.

Key Changes:
- Binary state encoding replaces enum for explicit control
- Outputs become continuous assignments based on state
- Next state logic simplified and moved to combinational block
- Counter logic remains similar but more compact
- Same pedestrian request handling but more integrated
