Refactoring Strategy:
1. State Encoding: Use binary encoding for states instead of enum for more explicit control and potential area savings.
2. Output Logic: Replace registered outputs with combinational logic using assign statements for simpler implementation.
3. Counter Management: Keep the same counter logic but move it to a separate always block for clarity.
4. Pedestrian Logic: Maintain the same behavior but implement with continuous assignments.
5. Structure: Use two always blocks (state transition and counter) plus combinational logic for outputs.

Key Changes:
- Binary state encoding (00: IDLE, 01: RED, 10: YELLOW, 11: GREEN)
- Combinational output logic using assign statements
- Simplified state transition logic
- Same counter behavior but more modular implementation
