Refactoring Strategy:
1. State Machine: Convert the always-block state machine to a purely combinational implementation using assign statements
2. Counter Logic: Move counter logic to a single always block with clearer transition conditions
3. Output Generation: Use continuous assignments for outputs to simplify the design
4. Pedestrian Logic: Implement the pedestrian request handling as a separate combinational condition
5. Reset Handling: Maintain synchronous reset but simplify the initialization

Key Changes:
- Eliminated next_state register by using direct combinational assignments
- Simplified counter logic by separating state transition conditions
- Used continuous assignments for all outputs including state signals
- Made pedestrian request handling more explicit
- Reduced sequential logic to just the counter and current state
