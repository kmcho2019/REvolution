Here's a novel approach using a time-based state machine with parallel processing:

1. Instead of a single counter, use separate down-counters for each light duration (red, yellow, green)
2. Implement a priority-based state machine where the pedestrian request can preempt the normal cycle
3. Use a "time bank" concept where remaining green time is stored when interrupted
4. Add a small FSM to manage pedestrian requests separately from main light control
5. Use one-hot encoding for states to optimize timing

Key innovations:
- Parallel counters eliminate the need to reload values on state transitions
- Pedestrian request handling becomes atomic and doesn't interfere with main timing
- Time banking allows for more flexible interruption handling
- One-hot encoding improves timing at minimal area cost
