Refactoring Strategy:
1. State Encoding: Replace enum with binary encoding for more explicit control and potential area savings.
2. Output Logic: Move to continuous assignments (assign) instead of procedural blocks for simpler combinational logic.
3. Counter Management: Keep the same counter logic but make it more explicit with separate load and decrement conditions.
4. Pedestrian Logic: Maintain the same functionality but express it more concisely.
5. Structure: Use two always blocks (sequential for state/counter, combinational for next state) plus continuous assignments for outputs.

Key Changes:
- Binary state encoding (00: IDLE, 01: RED, 10: YELLOW, 11: GREEN)
- Outputs driven by continuous assignments based on state
- Next state logic in combinational always block
- Clear separation between state transition and counter management
- Same pedestrian request handling but more concise expression
