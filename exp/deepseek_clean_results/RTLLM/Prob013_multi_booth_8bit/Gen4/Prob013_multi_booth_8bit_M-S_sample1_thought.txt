To simplify the Radix-4 Booth multiplier while maintaining functionality, I'll focus on:

1. Reducing state machine complexity by using a simple counter-based approach
2. Eliminating redundant registers and precomputed values
3. Using direct arithmetic operations instead of case statements
4. Properly sizing the counter (4 bits for 8-bit Radix-4)
5. Maintaining correct sign extension throughout
6. Simplifying the ready signal logic

The key simplifications:
- Remove the explicit state machine and use counter value directly
- Compute partial products on-the-fly instead of precomputing
- Reduce register usage by combining operations
- Maintain proper shifting and sign extension
- Keep the core Booth algorithm intact
