Here's a novel pipelined Radix-4 Booth multiplier design with optimized state machine control:

1. Two-Stage Pipeline Architecture:
   - Stage 1: Booth encoding and partial product generation
   - Stage 2: Accumulation and shifting
   This improves throughput and timing closure

2. Optimized State Machine:
   - 3 states (IDLE, COMPUTE, DONE)
   - Uses explicit state transitions for better synthesis control

3. Efficient Partial Product Handling:
   - Pre-computes all possible partial products (A, 2A, -A, -2A)
   - Uses multiplexer-based selection to reduce critical path

4. Smart Resource Sharing:
   - Single adder/subtractor unit reused for all operations
   - Shared shift registers with enable signals

5. Early Completion Detection:
   - Additional logic to detect early termination cases
   - Dynamic ready signal generation

Key Innovations:
- Pipelined architecture enables higher clock frequencies
- Explicit state machine improves synthesis results
- Pre-computation reduces combinational path delay
- Resource sharing minimizes area
- Early termination saves power
