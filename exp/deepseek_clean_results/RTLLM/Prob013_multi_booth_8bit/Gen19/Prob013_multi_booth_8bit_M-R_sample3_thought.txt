Refactored Radix-4 Booth Multiplier Design:

1. Key Changes:
   - Separated combinational and sequential logic for better timing
   - Used continuous assignments for arithmetic operations
   - Implemented explicit state tracking (IDLE, CALC, DONE)
   - Simplified shift operations using dedicated registers
   - Reduced register width where possible

2. Improvements:
   - Clearer separation of control and datapath
   - More efficient state transitions
   - Reduced critical path by pre-computing possible additions
   - Better clock gating potential

3. Maintained Functionality:
   - Same Radix-4 Booth algorithm
   - Identical I/O behavior
   - Preserved synchronous reset
   - Same 8-bit to 16-bit sign extension
