Simplified Radix-4 Booth Multiplier Design:

1. Core Optimization:
   - Reduce register usage by combining multiplier and multiplicand operations
   - Eliminate separate previous bit tracking by examining 3 bits at once
   - Simplify control logic with direct counter comparison

2. Streamlined Operation:
   - Single always block handles all operations
   - Direct Booth encoding without separate state tracking
   - Simplified arithmetic with immediate shift operations

3. Efficient Implementation:
   - Maintain only essential registers (product, counter)
   - Combine multiplicand and multiplier examination in single step
   - Use simple counter for iteration control
   - Generate ready signal directly from counter

Key Improvements:
- Reduced register count by eliminating prev_bit
- Simplified case statement by examining current 3 bits
- Maintained correct Radix-4 Booth encoding
- Cleaner state machine with direct counter
- Reduced area and power by minimizing registers
