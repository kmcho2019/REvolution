Refactored Radix-4 Booth Multiplier Design:

1. Key Changes:
   - Separated combinational and sequential logic for better timing
   - Used continuous assignments for arithmetic operations
   - Restructured control flow with explicit state encoding
   - Optimized register usage by combining related operations

2. Improvements:
   - Reduced critical path by moving arithmetic to combinational logic
   - Clearer state transitions with one-hot encoding
   - More efficient resource utilization
   - Maintained same Radix-4 Booth algorithm functionality

3. Implementation Approach:
   - Use continuous assignments for arithmetic operations
   - Explicit state machine for control flow
   - Parallel calculation of possible operations
   - Multiplexing based on Booth encoding
   - Simplified counter logic
