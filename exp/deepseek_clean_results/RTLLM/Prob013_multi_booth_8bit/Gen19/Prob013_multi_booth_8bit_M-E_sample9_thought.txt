Novel Pipelined Radix-4 Booth Multiplier with Early Termination:

1. Architectural Innovation:
   - 2-stage pipeline: Booth encoding (stage1) and accumulation (stage2)
   - Early termination detection for zero/one patterns
   - Parallel partial product generation

2. Key Features:
   - Stage1: Processes 2 bits per cycle with Booth encoding
   - Stage2: Accumulates partial products with carry-save adder
   - Zero detection skips unnecessary cycles
   - Sign extension optimization with dynamic width

3. Performance Benefits:
   - Higher throughput with pipelining
   - Reduced latency for special cases
   - Better timing closure with stage separation

4. Implementation Details:
   - Separate always blocks for pipeline stages
   - Carry-save adder reduces critical path
   - Dynamic shift amount based on iteration
   - Early rdy signal for zero/one cases
