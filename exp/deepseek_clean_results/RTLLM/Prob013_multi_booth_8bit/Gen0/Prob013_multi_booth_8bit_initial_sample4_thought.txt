To implement an 8-bit Radix-4 Booth multiplier, we need to:
1. Sign-extend the 8-bit inputs to 16 bits for proper arithmetic operations
2. Use a 5-bit counter (since we need 4 iterations for 8 bits in Radix-4)
3. Implement the Booth algorithm by examining 3 bits at a time (current bit and previous bit)
4. Perform arithmetic shifts and additions/subtractions based on the Booth encoding
5. Generate the ready signal when multiplication is complete
6. Handle reset condition to initialize all registers

The key steps are:
- On reset: Initialize registers with sign-extended inputs
- During operation: Examine 3-bit groups of the multiplier
- Perform appropriate operations based on Booth encoding (00/11: no op; 01: add multiplicand; 10: subtract multiplicand)
- Shift multiplicand and multiplier appropriately
- Update product register
- Set ready signal when done (after 4 iterations for 8 bits)
