To refactor the Radix-4 Booth multiplier while maintaining the same core algorithm, I'll make these key changes:

1. **Combinational Logic Conversion**:
   - Replace the always blocks for partial product selection with assign statements
   - Make the Booth encoding purely combinational

2. **State Machine Restructuring**:
   - Explicitly define states (IDLE, CALC, DONE) for clearer control flow
   - Use a state register instead of just a counter

3. **Output Logic Separation**:
   - Move product accumulation to a separate always block
   - Make ready signal generation more explicit

4. **Optimized Shifting**:
   - Pre-compute all shifted versions of multiplicand
   - Use barrel shifter style selection for partial products

5. **Simplified Control**:
   - Reduce control logic complexity by separating data path and control path
   - Make reset behavior more explicit

This refactoring maintains the same Booth algorithm but improves readability and potentially synthesis results by making the design structure more explicit and separating concerns.
