Simplified Radix-4 Booth Multiplier Design:

1. Key Simplifications:
   - Remove explicit state machine (use counter directly for control)
   - Eliminate separate next-state registers (direct assignments)
   - Reduce pre-computation (calculate multiplicand shifts on demand)
   - Simplify Booth encoding logic (direct case statement)

2. Maintained Functionality:
   - Still implements Radix-4 Booth algorithm
   - Preserves all required I/O behavior
   - Keeps synchronous reset and clocking

3. Optimization Focus:
   - Fewer registers and wires
   - Less combinational logic
   - Clearer data flow
   - Same 8-bit input to 16-bit output conversion
