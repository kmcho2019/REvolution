Simplified Radix-4 Booth Multiplier Design:

1. Key Optimizations:
   - Reduced counter width to 2 bits (since we only need 4 steps for 8-bit Radix-4)
   - Combined multiplier and prev_lsb into single register
   - Simplified case statement to only essential operations
   - Eliminated redundant default case
   - Used direct assignment for ready signal

2. Maintained Functionality:
   - Preserves Radix-4 Booth algorithm
   - Keeps all required I/O behavior
   - Maintains synchronous reset and clocking

3. Benefits:
   - Fewer registers (saves area)
   - Simpler control logic (better timing)
   - Clearer state progression
   - Same 8-bit to 16-bit conversion
