Simplified Radix-4 Booth Multiplier Design:

1. Core Optimization:
   - Reduce register usage by directly using inputs and accumulating product
   - Eliminate separate multiplicand and multiplier registers
   - Use a single 3-bit counter (for 4 iterations) instead of state machine

2. Streamlined Operation:
   - Single always block handles all operations
   - Direct Booth encoding from current multiplier bits
   - Simplified arithmetic by pre-calculating multiplicand multiples

3. Efficient Implementation:
   - Pre-compute +1x and +2x multiplicand values
   - Use simple case statement for Booth encoding actions
   - Minimal control logic with just counter and ready flag

Key Improvements:
- Reduced register count by eliminating intermediate storage
- Simplified control to just a counter
- Maintained correct Radix-4 Booth encoding
- Same 4-cycle operation but with cleaner implementation
