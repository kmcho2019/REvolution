To simplify the Radix-4 Booth multiplier while maintaining functionality:

1. Reduce State Machine Complexity:
   - Eliminate separate states (IDLE/COMPUTE/DONE) and use a simple counter-based approach
   - Use the counter directly to control the multiplication process

2. Simplify Booth Encoding:
   - Keep only the essential Booth encoding cases (0, ±1, ±2)
   - Combine similar cases to reduce logic

3. Streamline Register Usage:
   - Use a single accumulator register for the product
   - Combine multiplier and multiplicand handling

4. Optimize Control Logic:
   - Use counter value directly for completion detection
   - Simplify reset logic to initialize all registers in one block

Key simplifications:
- Removed explicit state machine
- Reduced register usage
- Simplified control flow
- Maintained correct Radix-4 Booth algorithm
- Kept same interface and functionality
