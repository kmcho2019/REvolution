Parallel Pattern Matching with Bit History:
1. Instead of a traditional FSM or shift register, use a history buffer that tracks the last 3 bits plus current input
2. Implement parallel comparators for all possible sequence starting points (overlapping detection)
3. Key innovations:
   - Eliminates explicit state transitions by treating all sequence positions equally
   - Uses a sliding window technique to detect the pattern at any alignment
   - Implements early termination when impossible patterns are detected
   - Reduces power by only activating full comparison when potential start is seen
4. Benefits:
   - Constant-time detection regardless of sequence position
   - Lower dynamic power from reduced switching activity
   - Simpler control logic than traditional FSM
   - Naturally handles overlapping sequences
5. Reset behavior clears the history buffer and output
