To simplify the sequence detector while maintaining functionality, we can:
1. Remove explicit state encoding and use simple state transitions
2. Combine state and output logic into a single always block
3. Use a counter-like approach to track sequence progress
4. Make output purely combinational based on current state
5. Keep reset behavior simple by returning to initial state

The key insight is that we only need to track our progress through the 4-bit sequence, so we can represent this with 4 states plus an idle state. The output is high only when we reach the final state and the correct bit is received.
