Refactoring Strategy:
1. Convert the state machine to a one-hot encoded style for better readability and potential timing improvements
2. Move combinational logic to continuous assignments (assign statements) where possible
3. Separate the state transition logic from the output generation for clearer code structure
4. Maintain the same hybrid approach (3-bit shift register + state machine)
5. Keep all functional behavior identical to original implementation

Key Changes:
- One-hot state encoding (IDLE and WAIT_FOR_LAST_1 states)
- Combinational next_state logic moved to assign statements
- Output generation also moved to assign
- Shift register remains sequential (needs always block)
- Improved modularity by separating state transition conditions
