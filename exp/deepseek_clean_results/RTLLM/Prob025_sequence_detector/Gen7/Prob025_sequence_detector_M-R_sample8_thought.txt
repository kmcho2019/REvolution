I'll refactor the shift-register based implementation while maintaining the same functionality but with a different structure. The key changes will be:

1. Replace the always block with continuous assignments for the shift register
2. Use a more explicit bit-wise shift operation
3. Maintain the parallel comparison but make it more visible in the code

Advantages of this refactoring:
- More transparent shift operation using explicit bit assignments
- Eliminates the always block which can sometimes cause simulation mismatches
- Shows alternative way to implement sequential logic with assigns
- Maintains all the original PPA benefits while being more explicit
