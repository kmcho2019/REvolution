Refactoring Strategy:
1. Convert the sequential logic to a more combinatorial style using continuous assignments
2. Maintain the same hybrid approach (shift register + FSM) but express state transitions as Boolean equations
3. Use `assign` statements for output and next-state logic where possible
4. Keep the same 3-state FSM but encode it differently for clarity
5. Benefits:
   - More explicit combinatorial logic visibility
   - Potential for better synthesis optimization of parallel paths
   - Maintains same functionality with different implementation style
   - Easier to modify individual logic components
6. Tradeoffs:
   - Slightly less readable for those used to procedural FSM descriptions
   - Requires careful handling of registered outputs
