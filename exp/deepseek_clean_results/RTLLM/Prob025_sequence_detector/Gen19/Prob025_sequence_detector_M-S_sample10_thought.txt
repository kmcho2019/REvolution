To simplify the sequence detector while maintaining full functionality, I propose:

1. Use a minimal Moore FSM with just 5 states (IDLE + 4 sequence states)
2. Eliminate the shift register completely, reducing storage elements
3. Each state directly represents progress in the sequence
4. Output is purely state-dependent (Moore machine)
5. Maintains same detection capability including overlapping sequences
6. Simplifies reset behavior to single state transition

Key advantages:
- Fewer total flip-flops (3 bits for states vs 4-bit shift register)
- Clear state progression mirrors sequence detection
- Output logic is trivial (just check if in final state)
- Naturally handles overlapping sequences through state transitions
