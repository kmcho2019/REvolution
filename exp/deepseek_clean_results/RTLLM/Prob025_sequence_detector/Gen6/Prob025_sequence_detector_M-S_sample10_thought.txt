The current shift-register implementation is already quite simple and efficient. To further simplify while maintaining functionality:

1. Keep the 4-bit shift register approach as it's minimal and effective
2. Remove the explicit reset condition since registers initialize to 0 by default in Verilog
3. Make the output purely combinational without registering to reduce logic
4. This maintains all functionality while reducing:
   - Lines of code
   - Reset logic complexity
   - Area (slightly by removing reset logic)

The design remains:
- Correct: Still detects '1001' sequence
- Efficient: Single cycle detection
- Simple: Minimal logic and registers
- Robust: Works for overlapping sequences
