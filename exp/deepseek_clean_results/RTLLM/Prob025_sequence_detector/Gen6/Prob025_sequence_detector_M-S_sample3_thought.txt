To simplify while maintaining the required state machine approach, we'll implement a Moore FSM with minimal states. The key simplifications are:
1. Remove unnecessary IDLE state since we can start detecting immediately
2. Combine state transitions into a single always block
3. Use binary encoding for states to reduce logic
4. Directly assign output based on current state
5. Maintain clear state progression matching the sequence bits

The FSM will have 4 states representing progress through the sequence (S0-S3). The output is high only in S3 when the full sequence is detected. Each state transition depends on the current state and input bit.
