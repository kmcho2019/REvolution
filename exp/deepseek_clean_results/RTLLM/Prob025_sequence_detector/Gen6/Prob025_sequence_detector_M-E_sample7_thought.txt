Here's a novel approach using a bit-pattern history tracking method with minimal state storage:

1. Instead of storing all 4 bits or using a traditional FSM, track only the relevant pattern progression
2. Use a 2-bit state register to represent pattern matching progress:
   - 00: No matching progress (IDLE)
   - 01: First '1' matched
   - 10: '10' matched
   - 11: '100' matched
3. Implement combinatorial next-state logic that:
   - Advances state only when next expected bit arrives
   - Resets to IDLE on mismatch
4. Output detection occurs when in state '11' (100 matched) and next bit is '1'
5. This approach uses fewer registers than shift register method (2 vs 4 bits)
6. Handles overlapping sequences naturally

Advantages:
- Reduced register count (50% fewer bits than shift register)
- Minimal comparison logic
- Efficient power usage (only relevant state transitions)
- Maintains single-cycle detection capability
- Clear reset behavior
