To refactor this sequence detector while maintaining the same functionality, I'll implement these key changes:

1. **Explicit State Machine Encoding**:
   - Use named states (IDLE, S1, S2, S3) instead of bitmask tracking
   - This makes the state transitions more readable and maintainable

2. **Separate Combinational and Sequential Logic**:
   - Split the FSM into two always blocks (next state logic and state register)
   - This is a classic FSM implementation pattern that's widely recognized

3. **Output Logic Optimization**:
   - Make sequence_detected purely combinational based on current state and input
   - This reduces register usage while maintaining correct functionality

4. **Parameterized States**:
   - Use parameters for state values for better code readability
   - Makes state values easily modifiable if needed

- Be functionally equivalent to the original (detecting 1001)
- Have clearer state machine structure
- Use standard FSM implementation patterns
