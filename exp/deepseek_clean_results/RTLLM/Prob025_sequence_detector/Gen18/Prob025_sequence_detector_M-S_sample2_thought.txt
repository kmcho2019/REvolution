I'll simplify the implementation by:
1. Using a minimal state machine approach instead of shift register
2. Reducing the number of states by tracking only necessary sequence progress
3. Combining state transitions and output logic into a single always block
4. Using binary encoding for states to save area

The simplified FSM will have:
- IDLE: initial state
- GOT1: received first '1'
- GOT10: received '10'
- GOT100: received '100'
Output is asserted only when in GOT100 state and receiving '1'
