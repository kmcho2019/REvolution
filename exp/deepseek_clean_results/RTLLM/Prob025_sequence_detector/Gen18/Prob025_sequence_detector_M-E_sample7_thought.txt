Here's a novel approach using a binary decision tree structure instead of a traditional FSM or shift register:

1. Decision Tree Concept: Implement the sequence detection as a binary decision tree where each level corresponds to checking one bit of the sequence
2. Parallel Evaluation: Each clock cycle evaluates all possible partial matches simultaneously
3. Memory Elements: Use flip-flops to store partial match progress at each decision level
4. Output Logic: Combine the final level decisions to generate the detection signal

Advantages:
- Naturally handles overlapping sequences
- Clear correspondence between hardware and sequence pattern
- Easily extensible to longer patterns
- No need for explicit state encoding
- Each bit comparison is isolated, potentially better for timing
