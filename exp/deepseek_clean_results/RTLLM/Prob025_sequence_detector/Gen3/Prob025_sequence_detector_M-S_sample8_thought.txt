To simplify the sequence detector while maintaining functionality:
1. Use binary state encoding instead of one-hot to reduce flip-flop usage (4 states only need 2 bits)
2. Combine state transitions and output logic into a single always block
3. Remove the default case since all states are explicitly handled
4. Simplify state transitions by directly assigning next state based on current state and input
5. Output is only high when in S3 state and input is 1 (final sequence bit)
