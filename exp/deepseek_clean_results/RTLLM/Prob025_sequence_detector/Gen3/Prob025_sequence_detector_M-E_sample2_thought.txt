This solution implements a shift register-based sequence detector that trades off some area for potentially better timing and simpler control logic. Instead of using a traditional FSM, we:
1. Use a 4-bit shift register to store the last 4 input bits
2. Compare the shift register contents with the target pattern (1001) in parallel
3. Generate the output when the pattern matches
4. Reset clears the shift register
This approach eliminates complex state transitions and reduces the critical path to just a comparator, while using slightly more registers than an FSM implementation.
