Simplification Strategy:
1. Reduce the state machine to just track progress of the sequence without separate IDLE state
2. Use a 3-bit counter to track matching progress (0-3 bits matched)
3. Reset counter to 0 when wrong bit is detected
4. Set output high when counter reaches 3 and next bit completes sequence
5. Benefits:
   - Eliminates separate state variable
   - Uses simple counter instead of shift register
   - Fewer comparisons needed per cycle
   - Maintains same detection capability
   - Lower power from reduced switching
   - Smaller area from simpler logic
