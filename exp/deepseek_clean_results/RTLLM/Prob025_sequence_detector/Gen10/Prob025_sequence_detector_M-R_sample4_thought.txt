To optimize the design for better PPA (Power, Performance, Area), I'll implement the following changes:
1. Change state encoding from one-hot to binary (3 bits for 5 states) to reduce area and power
2. Restructure the FSM to use continuous assignments (assign) for next_state logic instead of always block
3. Keep Moore-style output but make it directly dependent on state encoding
4. Maintain same sequence detection behavior (1001) and reset functionality
5. Simplify state transitions by combining some conditions where possible
6. Use Gray-like state encoding to minimize switching activity between adjacent states
