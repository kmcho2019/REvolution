To implement a sequence detector for the pattern "1001", we'll use a Moore finite state machine (FSM) with 5 states: IDLE (initial state), S1 (first '1' detected), S2 (next '0' detected), S3 (next '0' detected), and S4 (final '1' detected). The FSM will transition between these states based on the input bit (data_in) at each clock edge. The output sequence_detected will be high only in state S4. The reset signal will synchronously return the FSM to the IDLE state.
