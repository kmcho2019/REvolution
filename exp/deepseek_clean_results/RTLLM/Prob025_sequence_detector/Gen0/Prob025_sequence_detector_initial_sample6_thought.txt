To implement a sequence detector for the pattern "1001", we'll use a Moore-type finite state machine (FSM) with 5 states:
1. IDLE - initial state, waiting for first '1'
2. S1 - received '1' (first bit)
3. S2 - received '10' (first two bits)
4. S3 - received '100' (first three bits)
5. S4 - received '1001' (complete sequence)

The FSM transitions between states based on the current state and input bit. When in S4 state, the output sequence_detected is asserted. The machine returns to IDLE on reset.
