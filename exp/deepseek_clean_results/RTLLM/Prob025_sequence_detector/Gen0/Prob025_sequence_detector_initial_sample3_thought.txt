To implement a sequence detector for the pattern "1001", we'll use a Moore finite state machine (FSM) with 5 states:
1. IDLE: Initial state, waiting for first '1'
2. S1: Got '1', waiting for '0'
3. S2: Got '10', waiting for '0'
4. S3: Got '100', waiting for '1'
5. S4: Got '1001' (sequence detected)

The FSM transitions between states based on the current state and input bit. Output is high only in S4 state. On reset, returns to IDLE state.
