I'll refactor the sequence detector using an explicit state machine approach instead of the shift register implementation. This provides better visibility into the detection process and makes the state transitions more explicit. The key changes are:

1. Replace shift register with explicit state transitions
2. Use enumerated states for better readability
3. Maintain the same detection logic (1001 pattern)
4. Keep the same reset behavior and output timing
5. State transitions will directly mirror the shift register behavior but be more explicit

Advantages:
- More maintainable and debuggable state machine
- Clear state transition documentation
- Same functionality with different implementation style
- Easier to modify for different sequences
