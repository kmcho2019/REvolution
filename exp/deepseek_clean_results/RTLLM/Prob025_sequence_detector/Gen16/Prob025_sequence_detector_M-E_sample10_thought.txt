Here's a novel approach using a binary decision tree structure instead of a traditional FSM or shift register:

1. Decision Tree Concept: Instead of tracking state, we'll implement a tree of decisions that evaluates the sequence in parallel at each clock cycle. This eliminates sequential state transitions.

2. Parallel Evaluation: The design will evaluate all possible sequence positions simultaneously by checking the current and previous bits against the target pattern.

3. Edge Detection: We'll use edge detection on the input stream to identify potential sequence starts, reducing unnecessary comparisons.

4. Efficient Matching: By structuring the logic as a balanced binary tree, we minimize the critical path while maintaining full pattern matching capability.

Key Advantages:
- No explicit state machine or shift registers needed
- Parallel evaluation reduces timing critical path
- Naturally handles overlapping sequences
- Lower power consumption due to reduced switching activity
- Scalable to longer patterns with minimal impact on timing
