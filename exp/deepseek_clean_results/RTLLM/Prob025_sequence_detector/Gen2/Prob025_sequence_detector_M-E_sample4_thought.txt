Instead of using a traditional Moore FSM, I'll implement a shift register approach combined with parallel comparison. This method uses a 4-bit shift register to store the last 4 input bits and compares them in parallel with the target sequence "1001". The output is asserted when there's an exact match. This approach eliminates the need for explicit state transitions and simplifies the control logic, though it uses slightly more registers. The reset behavior clears the shift register and output.
