Here's a novel approach using a shift register and pattern matching instead of a traditional FSM:

1. Use a 4-bit shift register to store the last 4 input bits
2. Continuously compare the shift register contents with the target pattern (1001)
3. The output is asserted when the pattern matches
4. Reset clears the shift register
5. This approach eliminates explicit state transitions and reduces the design to simple sequential logic

Advantages:
- More compact implementation
- Easier to modify for different patterns
- No need to define and manage states explicitly
- Naturally handles overlapping sequences
- Clear relationship between input history and detection
