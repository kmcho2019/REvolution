Instead of using a traditional FSM with explicit states, we'll implement a shift register-based sequence detector with parallel matching. This approach uses a 4-bit shift register to store the last 4 input bits and compares them in parallel to the target sequence (1001). The benefits are:
1. Simpler implementation with fewer states
2. Easier to modify for different sequence lengths
3. More efficient for longer sequences
4. Clear relationship between input history and detection

The shift register shifts in new bits on each clock edge, and we simply check when the register content matches our target pattern. Reset clears the register to all 0s.
