Instead of using a traditional FSM with explicit states, we'll implement a shift register-based sequence detector with parallel comparison. This approach uses a 4-bit shift register to store the last 4 input bits and compares them in parallel with the target sequence (1001). The key advantages are:
1. Simpler implementation with fewer states
2. Easier to modify for different sequence lengths
3. More efficient for longer sequences
4. Clear relationship between stored bits and detection logic

The shift register will shift in new bits on each clock edge, and the comparison logic will check for a match with 1001. The reset will clear the shift register. This method eliminates the need for complex state transitions while maintaining the same functionality.
