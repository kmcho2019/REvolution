For a novel approach, I'll implement a shift-register based sequence detector instead of a traditional FSM. This alternative architecture:
1. Uses a 4-bit shift register to store the last 4 input bits
2. Compares the shift register contents with the target pattern (1001) in parallel
3. Eliminates explicit state transitions, reducing control logic
4. Provides immediate pattern matching without sequential state progression
5. Still maintains synchronous operation with clock and reset
6. Offers simpler verification since the matching logic is purely combinational
