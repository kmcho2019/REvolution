To improve the PPA metrics while maintaining the same functionality, I'll implement these key changes:

1. **One-Hot State Encoding**: This reduces glitching and improves timing by having only one bit active at a time. It simplifies the next-state logic since each state transition depends on fewer conditions.

2. **Registered Output**: Instead of continuous assignment, we'll register the output to reduce glitching power and improve timing by breaking the critical path.

3. **Simplified Next-State Logic**: By using one-hot encoding, we can express each state transition as a simple condition without complex case statements.

4. **Clock Gating Implicit**: One-hot encoding naturally reduces switching activity since only one state bit changes at a time.

These changes should improve timing (reduce WNS), lower power consumption, and maintain similar area efficiency while keeping the same sequence detection behavior.
