Simplification Strategy:
1. Eliminate the state machine entirely by using only a shift register
2. Use a 4-bit shift register to directly capture the sequence pattern
3. Compare the shift register contents with the target pattern (1001) each cycle
4. Reset behavior clears the shift register
5. Benefits:
   - Eliminates state machine logic completely
   - Simplifies control flow to just shift and compare
   - Maintains same detection capability (including overlapping sequences)
   - Reduces area by removing state transition logic
   - Easier to understand and verify
6. Trade-off:
   - Slightly larger shift register (4 bits vs 3 bits)
   - No power savings from state-dependent operation
   - Still meets all functional requirements
