To refactor the sequence detector, I'll implement a Mealy machine instead of Moore machine for more efficient detection. The key changes are:
1. Use a simpler state encoding with fewer states (only 4 states needed)
2. Combine state transition and output logic in a single always block
3. Use binary state encoding instead of enum for better synthesis
4. Make output directly dependent on current state and input (Mealy style)
5. Use non-blocking assignments for state transitions
6. Keep the same module interface and functionality

The state machine will now have:
- IDLE: waiting for first '1'
- GOT1: received '1' (first bit)
- GOT10: received '10'
- GOT100: received '100'
Output goes high when in GOT100 state and next input is '1'
