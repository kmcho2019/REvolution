To simplify the sequence detector while maintaining functionality, I'll:

1. Use a minimal Mealy FSM with only necessary states (4 states + IDLE)
2. Eliminate the shift register to reduce area
3. Implement direct state transitions based on input bits
4. Output detection immediately when the full sequence is matched
5. Maintain the same reset behavior

Advantages:
- Fewer registers (only state bits instead of 4-bit shift register)
- Simpler combinational logic (state transitions vs parallel comparison)
- Same detection latency (4 cycles)
- Lower power since only state transitions consume power
