Refactoring Strategy:
1. Convert the state machine to use explicit state encoding with parameters for better readability
2. Replace the shift register with a 2-bit version since we only need to track the last 2 bits ("10" pattern)
3. Use continuous assignments for combinational logic where possible
4. Separate the sequential and combinational logic into distinct always blocks
5. Key improvements:
   - More readable state definitions using parameters
   - Reduced shift register size (2 bits instead of 3)
   - Clear separation of state transitions and output logic
   - Maintains same functionality and timing characteristics
   - Potentially better for synthesis due to explicit state encoding
