2. **Direct Pattern Matching**: Since the pattern is fixed and known (1001), we can optimize the detection logic to only check for this specific sequence without generic comparison logic.

3. **Simplified State Machine**: Implement a compact Moore machine with just 4 states (plus IDLE) that directly corresponds to each bit of the pattern we're matching.

4. **Registered Output**: Maintain the registered output for clean timing, but simplify the detection logic by making it purely state-based.

- Use only 3 flip-flops (state encoding)
