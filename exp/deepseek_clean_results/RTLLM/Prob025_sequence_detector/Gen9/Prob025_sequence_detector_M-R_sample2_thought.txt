I'll implement the sequence detector using a Mealy-style finite state machine (FSM) instead of the shift register approach. The key differences will be:

1. Explicit state encoding with named states (IDLE, S1, S2, S3, S4)
2. Mealy machine output (sequence_detected depends on both state and input)
3. State transitions based on input pattern matching
4. Same reset behavior but implemented through state transitions

Advantages of this refactoring:
- More explicit state machine representation
- Potentially lower power since state only changes when relevant bits are detected
- Clearer transition conditions in the code
- Output depends directly on current state and input (Mealy behavior)
