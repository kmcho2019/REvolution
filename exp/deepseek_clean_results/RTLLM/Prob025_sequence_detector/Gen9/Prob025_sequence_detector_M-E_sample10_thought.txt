I'll implement a novel "delayed comparison" approach that eliminates the need for a full shift register. The key ideas are:

1. Instead of storing all 4 bits, we'll track the necessary partial matches with minimal state
2. Use a 3-bit state register to remember the relevant history:
   - bit 0: remembers if we saw '1' (first bit)
   - bit 1: remembers if we saw '10' (first two bits)
   - bit 2: remembers if we saw '100' (first three bits)
3. Only update state when relevant to the target sequence
4. Output detection occurs when we have '100' state and current input is '1'

Advantages:
- Reduced storage (3 bits vs 4 bits in shift register)
- Conditional state updates save power
- Simpler comparison logic
- Maintains single-cycle detection capability
