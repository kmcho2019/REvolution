I'll implement a thermometer-style comparator that:
1. First calculates the difference between A and B using subtraction
2. Encodes the difference into a thermometer code (one-hot)
3. Decodes this into the three output signals
Key advantages:
- Uses arithmetic for direct magnitude comparison
- Thermometer encoding naturally ensures mutual exclusivity
- Simple decoding logic
- Easily scalable to wider bit widths
- Avoids complex priority encoding trees
The subtraction result's sign bit directly indicates the relationship between A and B.
