Instead of using direct comparison operators, we'll implement a hierarchical bit-wise comparison approach that:
1. First compares the MSBs (A[2] and B[2])
2. Only if they're equal, we proceed to compare the middle bits (A[1] and B[1])
3. Only if those are equal, we compare the LSBs (A[0] and B[0])
This creates a priority-encoded comparison that potentially reduces logic depth by terminating early when a difference is found in higher-order bits. The outputs are generated using a cascaded conditional structure that ensures mutual exclusivity.
