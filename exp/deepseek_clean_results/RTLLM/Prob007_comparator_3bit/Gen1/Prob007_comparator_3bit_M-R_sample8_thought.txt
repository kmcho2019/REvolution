The original implementation uses simple ternary operators for the comparisons. We can refactor this to use a more explicit bit-by-bit comparison approach while maintaining the same functionality. This alternative implementation:
1. Compares bits from MSB to LSB
2. Uses nested conditional operators for the hierarchical comparison
3. Still maintains mutually exclusive outputs
4. Makes the bit-wise comparison logic more visible in the code
The advantage is that it more clearly shows the comparison priority (MSB first) while being functionally equivalent.
