The original implementation uses three separate conditional assignments for the comparison outputs. While this is clear and straightforward, we can refactor it to use a single always block with case statements for the comparison logic. This approach:
1. Groups all comparison logic together in one procedural block
2. Uses case statements for explicit comparison state handling
3. Maintains the same functionality with mutually exclusive outputs
4. May offer better readability for some designers by showing all comparison cases explicitly
5. Still results in purely combinational logic (no registers)
