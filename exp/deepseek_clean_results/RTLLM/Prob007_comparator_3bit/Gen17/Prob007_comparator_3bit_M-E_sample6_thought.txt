Novel Architectural Idea: Bit-Serial Comparator with Early Termination

Key Concepts:
1. Bit-serial comparison starting from MSB to LSB
2. Early termination when inequality is detected
3. State machine approach using combinational logic
4. Priority encoding for comparison results
5. Minimal hardware usage by processing one bit at a time

Advantages:
- Reduced logic complexity compared to parallel comparison
- Early termination saves power when MSBs differ
- Clear priority structure (MSB has highest weight)
- Scalable to wider bit widths with minimal changes
- Efficient implementation using case statements

Operation Flow:
1. Compare MSB (bit 2) first - if unequal, determine result immediately
2. If equal, proceed to middle bit (bit 1)
3. If still equal, compare LSB (bit 0)
4. Final comparison result is determined at first point of inequality
5. Default to equality if all bits match
