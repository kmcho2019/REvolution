Refactoring Approach:
1. Maintain the same comparison logic but implement it using hierarchical bit-by-bit comparison
2. Use continuous assignments (assign) for all outputs to keep combinational nature
3. Break down the comparison into individual bit checks for better readability
4. Ensure mutual exclusivity by construction through the comparison logic
5. The hierarchical approach makes it easier to extend to wider comparators if needed

The new implementation will compare bits from MSB to LSB, with early termination when a difference is found. This matches human comparison logic while maintaining optimal PPA characteristics.
