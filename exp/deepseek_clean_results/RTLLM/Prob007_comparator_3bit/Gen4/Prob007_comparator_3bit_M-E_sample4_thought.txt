Novel Architectural Idea: Bitwise Comparison with Early Termination
1. Instead of using direct comparison operators, implement a bitwise comparison from MSB to LSB
2. Add early termination logic to stop comparison once a definitive result is found
3. Use a priority encoder style approach to determine the final result
4. This method mimics how humans compare numbers digit by digit
5. Potentially more efficient for certain technologies where comparison operators don't map well to hardware

Advantages:
- Explicit control flow may optimize better in some synthesis tools
- Early termination can save power when intermediate bits determine the result
- More transparent implementation showing the actual comparison process
- Easier to modify for custom comparison rules if needed
