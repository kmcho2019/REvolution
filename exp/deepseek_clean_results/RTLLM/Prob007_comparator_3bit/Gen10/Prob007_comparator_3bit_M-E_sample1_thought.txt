Novel Architectural Idea: Bit-Serial Comparison with Early Termination

1. Instead of parallel comparison, implement a bit-serial approach from MSB to LSB
2. Key advantages:
   - Naturally prioritizes MSB comparison (most significant bits first)
   - Early termination when inequality is detected
   - Reduced hardware complexity (sequential rather than parallel)
3. Implementation strategy:
   - Use a 3-state FSM to track comparison status (greater/equal/less)
   - Process bits sequentially, updating state only if still equal
   - Final state after all bits processed determines outputs
4. Innovations:
   - Minimal combinational logic (just 1 bit comparator per cycle)
   - State-based approach ensures mutual exclusivity inherently
   - Scales well to wider comparators (same basic structure)
5. Power/Area benefits:
   - Only one 1-bit comparator active at any time
   - No wide parallel logic
   - Simple state encoding (2 bits)
