The original solution is already optimally simple, using direct comparison operators in continuous assignments. To further simplify, we can observe that:
1. The outputs are mutually exclusive by definition (only one can be true at any time)
2. We can eliminate redundant comparisons by using a priority encoding approach
3. We can leverage that A_equal is true only when neither A_greater nor A_less is true

This reduces the comparison operations from three to two while maintaining all functionality.
