I'll implement a hierarchical bit-slice comparator that compares the numbers from MSB to LSB, terminating early when a difference is found. This approach:
1. Processes bits in order of significance (bit 2 down to bit 0)
2. Uses cascaded logic where each stage only activates if previous bits were equal
3. Reduces switching activity by avoiding full-width comparisons when possible
4. Maintains mutually exclusive outputs through priority encoding
The design uses generate blocks to create the bit-slice logic while keeping the code parameterizable.
