To simplify the comparator, we'll use direct bitwise comparison without subtraction:
1. Compare bits from MSB to LSB (priority encoding)
2. For equality, use XOR gates to check bitwise equality
3. For magnitude comparison:
   - A > B when we find the first bit where A is 1 and B is 0
   - A < B when we find the first bit where A is 0 and B is 1
This approach:
- Eliminates the subtractor, reducing area
- Has clear critical path (MSB comparison first)
- Maintains mutual exclusivity naturally
- Uses only simple gates (XOR, AND, OR)
