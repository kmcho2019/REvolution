The original implementation uses three separate ternary operators for the comparisons. While this is clear and concise, we can refactor it to use a more explicit bit-by-bit comparison approach that mirrors how a hardware comparator would typically be implemented. This makes the comparison logic more visible and might help with synthesis optimizations.

The new approach will:
1. Compare bits from MSB to LSB
2. Use nested conditional operators to implement the priority of higher bits
3. Only proceed to compare lower bits if higher bits are equal
4. Still maintain mutually exclusive outputs
5. Use a single assign statement for each output to make the priority clear
