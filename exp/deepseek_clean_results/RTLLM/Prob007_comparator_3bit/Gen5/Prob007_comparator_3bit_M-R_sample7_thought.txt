The original implementation uses three separate comparison operations. We can optimize this by:
1. First computing equality (A == B) which is the simplest comparison
2. Then using this equality result to simplify the greater/less comparisons
3. This reduces redundant logic since if A equals B, we know both greater and less are false
4. The outputs remain mutually exclusive by construction
This approach should reduce area by sharing logic between comparisons and potentially reduce power by minimizing switching activity.
