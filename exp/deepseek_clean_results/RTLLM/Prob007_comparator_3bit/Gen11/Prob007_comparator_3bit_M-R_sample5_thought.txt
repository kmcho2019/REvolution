The original implementation uses cascaded ternary operators for comparison, which creates a multi-level logic structure. We can refactor this to use a more direct arithmetic comparison approach that leverages Verilog's built-in comparison operators. This will:

1. Use simple arithmetic comparisons (>, ==) which synthesis tools can optimize well
2. Maintain the same functionality with mutually exclusive outputs
3. Reduce the logic depth by performing direct 3-bit comparisons
4. Make the code more readable and maintainable
5. Potentially improve synthesis results since tools can recognize standard comparison patterns
