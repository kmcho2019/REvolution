I'll implement a 3-bit comparator using a thermometer encoding approach that:
1. Generates a 7-bit thermometer code for each input (representing values 0-7)
2. Compares the thermometer codes bit-by-bit from MSB to LSB
3. Uses priority encoding to determine the comparison result
4. Provides inherent mutual exclusion in the outputs
5. Offers potential power savings by stopping comparison at the first differing bit

This method is unconventional for small comparators but demonstrates an interesting alternative approach that could scale better for wider comparators and has predictable timing characteristics.
