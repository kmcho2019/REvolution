Novel Hierarchical MSB-First Comparator Architecture:
1. Implement a priority-based comparison starting from MSB to LSB
2. Early termination when MSB difference is found (better timing)
3. Use cascaded 1-bit comparators with priority logic
4. Generate intermediate comparison signals for each bit position
5. Combine results with priority encoding (MSB has highest priority)
6. Power optimization by preventing LSB switching when MSB already determines result
7. Area-efficient by sharing some intermediate logic between outputs

Key Advantages:
- Better critical path (only 2 gate delays in worst case)
- Reduced switching activity (power savings)
- Still maintains mutually exclusive outputs
- More scalable for wider comparators
