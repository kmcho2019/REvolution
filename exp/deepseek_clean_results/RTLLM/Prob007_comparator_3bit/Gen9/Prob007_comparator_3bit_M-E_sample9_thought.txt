I'll implement a thermometer-style comparator that:
1. First computes the difference between A and B as a signed value
2. Uses this difference to generate a one-hot encoded result
3. Converts the one-hot encoding to the required output signals
4. Employs arithmetic comparison rather than bit-by-bit logic

Key advantages:
- Single arithmetic operation instead of multiple bit comparisons
- Naturally produces mutually exclusive outputs
- Easily scalable to wider bit widths
- More regular structure with balanced paths
- Potential for better power efficiency since only one arithmetic operation is needed
