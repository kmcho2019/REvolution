To optimize the comparator for better PPA (Power, Performance, Area), I'll implement a hierarchical bitwise comparison approach that:
1. Compares bits from MSB to LSB, stopping at the first unequal bit
2. Uses shared logic for equality detection (XOR gates)
3. Eliminates the subtractor to reduce area and power
4. Maintains mutually exclusive outputs through priority encoding
5. Provides balanced timing paths by processing all bits in parallel

Key improvements:
- No arithmetic operations (subtractor removed)
- Direct bitwise comparison reduces switching activity
- Shared XOR gates for equality check
- Priority encoding ensures only one output is active
- Smaller area footprint (no 4-bit extension needed)
- Better timing as critical path is just 2 logic levels
