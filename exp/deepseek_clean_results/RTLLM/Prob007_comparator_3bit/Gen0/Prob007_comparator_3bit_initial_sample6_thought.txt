To implement a 3-bit comparator, we need to compare each bit of the two 3-bit numbers A and B from the most significant bit (MSB) to the least significant bit (LSB). The comparison logic works as follows:
1. If A[2] > B[2], then A > B regardless of the lower bits.
2. If A[2] < B[2], then A < B regardless of the lower bits.
3. If A[2] == B[2], we move to the next bit (A[1] vs B[1]) and repeat the comparison.
4. This process continues until all bits are compared. If all bits are equal, then A == B.

The outputs A_greater, A_equal, and A_less are mutually exclusive and can be derived using combinational logic based on the bit-wise comparison.
