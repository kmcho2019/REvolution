To implement a 3-bit comparator, we need to compare the two 3-bit inputs A and B bit by bit from the most significant bit (MSB) to the least significant bit (LSB). The comparison logic can be broken down as follows:
1. If A[2] > B[2], then A > B regardless of the lower bits.
2. If A[2] < B[2], then A < B regardless of the lower bits.
3. If A[2] == B[2], we move to the next bit (A[1] vs B[1]) and repeat the same logic.
4. This process continues until all bits are compared.
5. If all bits are equal, then A == B.

The outputs A_greater, A_equal, and A_less are mutually exclusive, so we can use a priority encoder-like structure to ensure only one output is high at any time.
