1. If A[2] > B[2], then A > B regardless of the lower bits
2. If A[2] < B[2], then A < B regardless of the lower bits
3. If A[2] == B[2], we move to compare A[1] and B[1], and so on
4. If all bits are equal, then A == B
The outputs are mutually exclusive, so we'll use conditional assignments to ensure only one output is high at any time.
