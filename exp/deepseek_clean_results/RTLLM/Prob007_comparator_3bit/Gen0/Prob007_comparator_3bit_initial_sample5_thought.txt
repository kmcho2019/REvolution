To implement a 3-bit comparator, we'll compare the two 3-bit numbers A and B bit by bit from the most significant bit (MSB) to the least significant bit (LSB). The comparison logic is as follows:
1. If A[2] > B[2], then A > B regardless of lower bits
2. If A[2] < B[2], then A < B regardless of lower bits
3. If A[2] == B[2], we move to A[1] vs B[1] with the same logic
4. This continues until we reach the LSB
5. If all bits are equal, then A == B
The outputs are mutually exclusive, so we'll use conditional assignments to ensure only one output is high at a time.
