Implementing a ROM using a case statement instead of a memory array for better synthesis optimization when only a few memory locations are used:
1. Eliminate the memory array entirely since we're only using 4 locations
2. Use a case statement to directly map addresses to output values
3. Default case returns 0 for all uninitialized addresses (4-255)
4. This approach reduces area by avoiding unused memory allocation
5. Maintains same functionality but with potentially better PPA for small ROMs
