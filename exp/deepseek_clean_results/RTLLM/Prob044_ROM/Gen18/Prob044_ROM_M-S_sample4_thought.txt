Simplified ROM module with these optimizations:
1. Remove the initial block since uninitialized memory locations will default to X (don't care) in simulation and can be optimized away in synthesis
2. Use continuous assignment for output without any intermediate function calls
3. Keep the same memory structure but rely on synthesis tools to optimize unused memory
4. This reduces code complexity while maintaining identical functionality for initialized addresses
5. The simplification makes the module more readable and easier to maintain
