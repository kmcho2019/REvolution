Simplification Strategy:
1. Remove parameterization to focus on core functionality (8-bit addr, 16-bit data, 256 depth)
2. Eliminate output register for direct combinational output (simpler and sufficient for ROM)
3. Keep minimal initialization (only locations 0-3 as specified)
4. Use continuous assignment instead of always block for cleaner combinational logic

Result is a minimal ROM with:
- Direct combinational read (simplest timing path)
- Fixed size matching requirements (no unnecessary parameters)
- Clean continuous assignment style
- Maintained core functionality
