Novel Architecture: Case-Based ROM
1. Instead of using a memory array, implement the ROM as a pure combinational case statement
2. Each address maps directly to its corresponding data value in the case statement
3. Default case handles all unspecified addresses (initialized to 0)
4. Advantages:
   - Eliminates memory array overhead
   - Explicit control over each memory location
   - Potentially better synthesis for small ROMs
   - Clear visibility of all stored values in code
5. Trade-offs:
   - Less scalable for large ROMs
   - Manual entry required for each value
   - Harder to modify if many locations need updating
