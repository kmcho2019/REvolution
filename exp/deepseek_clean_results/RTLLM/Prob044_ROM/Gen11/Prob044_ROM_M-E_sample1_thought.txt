Novel Architecture: Pattern-Generating ROM with Power Modes
1. Instead of storing all data, implement a hybrid ROM that can either:
   - Output stored data (traditional ROM mode)
   - Generate patterned data on-the-fly (pattern generation mode)
2. Add power control features:
   - Sleep mode that zeros outputs
   - Address change detection to minimize switching
3. Use parameterized initialization for flexibility
4. Implement optional output registers for timing closure
5. Include pattern generation functions for common sequences

Key Benefits:
- Reduced memory footprint when patterns can be generated
- Power savings through advanced control
- Flexible initialization through parameters
- Better timing with optional output registers
