The ROM module needs to store fixed data that can be accessed via an 8-bit address. The design will use a 256x16 memory array (256 locations of 16 bits each). The initial block will pre-load specific values into the first few memory locations as examples, while the rest can remain uninitialized (defaulting to 0 or can be customized). The output dout will continuously reflect the data at the current address input addr.
