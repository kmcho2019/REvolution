Alternative ROM implementation using case statement:
1. Instead of a full memory array, use a case statement to directly map addresses to data values
2. This eliminates the need for a physical memory array when only specific addresses are used
3. Default case handles all unspecified addresses (returns 0)
4. More efficient for small ROMs as it doesn't allocate unused memory locations
5. Easier to modify specific values without affecting others
6. Potentially better synthesis results for small ROMs in some technologies
