Refactoring Strategy:
1. Replace the always block with continuous assign for cleaner combinational logic
2. Use a case statement instead of memory array for better optimization in synthesis
3. Maintain same functionality with predefined values for addresses 0-3
4. Default all other addresses to 0 for power efficiency
5. Keep the same interface (8-bit addr, 16-bit dout)
6. Remove unused memory array to save area

Key Improvements:
- More synthesis-friendly structure (case statements often optimize better)
- Explicit power optimization by defaulting unused addresses to 0
- Eliminates unnecessary memory array when only few locations are used
- Cleaner direct mapping from address to output
- Maintains same functionality while being more area-efficient
