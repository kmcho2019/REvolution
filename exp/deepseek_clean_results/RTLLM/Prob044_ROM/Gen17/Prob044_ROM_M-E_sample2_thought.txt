Novel Architectural Idea: 
1. Implement a segmented ROM architecture with address decoding to reduce power consumption by only activating the relevant memory segment
2. Use a hierarchical memory organization with 4 segments of 64 locations each (total 256 locations)
3. Each segment has its own enable signal generated from the upper 2 address bits
4. Only the enabled segment drives the output, reducing switching activity in inactive segments
5. Maintain combinational read for performance while adding power gating at the segment level
6. Initialize memory using a generate block for better scalability and cleaner code
7. Keep parameterized design for flexibility
