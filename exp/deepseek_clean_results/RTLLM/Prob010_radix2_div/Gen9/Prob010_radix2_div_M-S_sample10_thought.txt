Simplified Radix-2 Divider Design:
1. Use a single state machine with IDLE, CALCULATE, and DONE states
2. Handle signed division by converting to absolute values and correcting signs at the end
3. Implement basic radix-2 algorithm with 8 iterations
4. Combine remainder and quotient in a single shift register (SR) for efficiency
5. Use simple counter for iteration control
6. Directly output combined result when done
7. Handle division by zero with simple error code

Key Simplifications:
- Removed separate registers for abs values (compute on the fly)
- Eliminated NEG_DIVISOR by using direct comparison
- Simplified state transitions
- Combined all calculation steps into single always block
- Reduced register usage by reusing variables
