Refactored Design Approach:
1. Use continuous assignments for combinational logic where possible
2. Separate the state machine into explicit states (IDLE, CALC, DONE)
3. Use explicit wire declarations for intermediate values
4. Move sign handling to a separate combinational block
5. Simplify the shift register updates with clearer bit manipulation
6. Use parameterized states for better readability
7. Maintain same core algorithm but with cleaner structure

Key Improvements:
- More explicit state transitions
- Clearer separation of combinational and sequential logic
- Better visibility into intermediate calculations
- More maintainable code structure
- Same functionality but with improved readability
