Refactored design approach:
1. Convert to a more explicit state machine with IDLE, CALC, and DONE states
2. Use continuous assignments for combinational logic where possible
3. Separate the arithmetic operations into dedicated logic blocks
4. Improve signal naming for clarity
5. Move sign handling to a separate always block for better organization
6. Use non-blocking assignments consistently in sequential logic
7. Add explicit handling of division by zero (return max value)

Key improvements:
- Clearer state machine makes timing more explicit
- Combinational logic separated from sequential
- Better organization of sign handling
- More consistent coding style
- Added basic error handling
