Simplified radix-2 divider design approach:
1. Remove redundant registers (original_dividend/divisor storage)
2. Simplify control logic by combining cnt and start_cnt into single state
3. Streamline sign handling by computing signs on-the-fly
4. Reduce intermediate registers where possible
5. Maintain same core algorithm (non-restoring division)
6. Keep same interface and output format (16-bit result with remainder/quotient)

Key simplifications:
- Single state variable (cnt) replaces start_cnt/cnt combo
- Immediate sign computation instead of storing
- Cleaner final result handling
- Reduced register usage
- Same 8-cycle operation but with simpler control
