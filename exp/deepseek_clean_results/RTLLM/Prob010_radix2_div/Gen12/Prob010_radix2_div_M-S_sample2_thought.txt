Simplification Approach:
1. Remove state machine - use simple counter-based control
2. Combine initialization and calculation into single always block
3. Eliminate separate registers for intermediate values by computing on-the-fly
4. Handle sign conversion directly during result formation
5. Simplify division steps with straightforward shift-and-subtract
6. Maintain same interface but with minimal internal state

Key Improvements:
- No explicit state machine (just counter control)
- Fewer registers needed
- Cleaner arithmetic implementation
- Same functional behavior with less complexity
- Direct sign handling during result formation
