Refactored Design Approach: Purely Sequential with Explicit State Machine and Registered Outputs

Key Refactoring Changes:
1. Used a more explicit state machine with named states (IDLE, CALC, DONE)
2. Moved all combinational logic to separate always blocks for clarity
3. Simplified the shift register handling using concatenation
4. Added explicit output registers for better timing
5. Used parameterized state encoding for better readability
6. Separated special case handling into distinct logic blocks
7. Implemented proper ready/valid handshaking with registered outputs

Improvements:
- Clearer state transitions and conditions
- Better separation of combinational and sequential logic
- More maintainable special case handling
- Registered outputs for better timing closure
- Explicit state encoding improves readability
- Simplified shift register updates
