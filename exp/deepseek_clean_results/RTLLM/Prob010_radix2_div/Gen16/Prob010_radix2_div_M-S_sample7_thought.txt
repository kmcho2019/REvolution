Simplification Strategy:
1. Remove redundant state machine (IDLE/CALC/DONE) and use counter-based control
2. Combine sign handling into a single step at the end
3. Simplify arithmetic operations by using direct subtraction
4. Reduce register usage by computing values on the fly
5. Maintain all original functionality (signed/unsigned, divide-by-zero)

Key Changes:
- Single always block with counter-based control
- Direct subtraction instead of separate negated divisor
- Simplified quotient/remainder calculation
- Same interface and functionality with less complexity
