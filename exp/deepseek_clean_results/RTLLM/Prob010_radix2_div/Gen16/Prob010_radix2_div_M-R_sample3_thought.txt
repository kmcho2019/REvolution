Refactored Radix-2 Divider Design:
1. State machine approach: Use explicit states (IDLE, CALCULATE, DONE) for clearer control flow
2. Combinational logic: Move subtraction and comparison to combinational blocks using assign
3. Registered outputs: Keep all outputs registered for better timing
4. Explicit sign handling: Process signs separately before and after unsigned division
5. Simplified counter: Maintain 3-bit counter but with clearer increment logic
6. Better reset handling: Clear all registers on reset
7. Proper shift initialization: Initialize SR with dividend shifted left by 1 as specified
8. Division by zero: Return all zeros (consistent with original)
