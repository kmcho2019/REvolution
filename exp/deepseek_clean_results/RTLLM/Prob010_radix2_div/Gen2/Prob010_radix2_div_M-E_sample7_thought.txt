Novel architectural approach for radix-2 divider:
1. Pipelined non-restoring division algorithm with explicit state machine
2. Three-stage pipeline: Input Processing, Division Core, Output Correction
3. Dedicated sign handling unit that pre-processes inputs
4. Optimized remainder adjustment logic
5. Early termination detection for divide-by-zero cases
6. Clean separation of control and datapath logic

Key innovations:
- Explicit 3-stage state machine improves timing and readability
- Specialized sign handling unit simplifies core division logic
- Early zero-division detection prevents wasted cycles
- Optimized remainder adjustment reduces final cycle latency
- Clear separation of concerns between pipeline stages
