Simplified Radix-2 Divider Design:

Key Simplifications:
1. Single-stage implementation (removes pipeline complexity)
2. Basic non-restoring division algorithm
3. Simplified special case handling (only division by zero)
4. Direct sign handling without separate pipeline stage
5. Reduced state machine complexity (only running/idle states)

Core Operation:
1. On valid operation start:
   - Take absolute values if signed operation
   - Initialize shift register with dividend
   - Start division counter

2. Division Process:
   - Perform 8 iterations of non-restoring division
   - Each iteration: 
     * Subtract divisor from partial remainder
     * Shift result and update quotient based on carry
   - Final remainder correction if needed

3. Result Handling:
   - Apply sign correction to final quotient/remainder
   - Output valid signal when done
