Refactoring Strategy:
1. Replace registered logic with combinational where possible using assign statements
2. Convert the implicit state machine to an explicit 3-state FSM (IDLE, CALC, DONE)
3. Separate the arithmetic logic into dedicated combinational blocks
4. Make sign handling more explicit with separate signals
5. Simplify the shift register update logic
6. Maintain same interface and functionality while improving readability

Key Changes:
- Explicit state machine instead of counter-based control
- More combinational logic using assign
- Clearer separation of arithmetic operations
- Same signed/unsigned support and interface
- Simplified shift register updates
