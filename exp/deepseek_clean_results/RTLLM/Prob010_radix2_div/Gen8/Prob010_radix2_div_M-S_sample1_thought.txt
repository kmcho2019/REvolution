Simplification Strategy:
1. Remove explicit state machine and use simple counter-based control
2. Combine arithmetic operations into single always block
3. Eliminate intermediate registers where possible
4. Simplify sign handling by moving it to final result stage
5. Keep same interface and functionality but with fewer lines of code
6. Maintain clear division steps while reducing control logic

Key Changes:
- Single always block for all sequential logic
- Direct counter-based control instead of FSM
- Simplified shift register updates
- Combined arithmetic operations
- Same signed/unsigned support with cleaner implementation
