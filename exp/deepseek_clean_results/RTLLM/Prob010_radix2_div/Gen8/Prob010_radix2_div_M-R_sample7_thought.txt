Refactored Radix-2 Divider Design:

Key Refactoring Changes:
1. Separated combinational and sequential logic clearly
2. Used continuous assignments for combinational logic
3. Simplified state tracking with explicit states (IDLE, RUNNING, DONE)
4. Moved sign handling to combinational logic
5. Used explicit wires for intermediate results
6. Structured the FSM with case statement for better readability

Core Improvements:
1. Clear separation between data path and control logic
2. More modular structure with dedicated blocks for:
   - Input conditioning (absolute values)
   - Division algorithm
   - Result formatting
3. Better visibility of signal flow through named wires
4. More maintainable state machine implementation
