Novel Architecture:
1. Non-restoring division algorithm - more efficient than basic radix-2
2. Early termination when divisor is greater than remaining dividend
3. Parallel sign calculation to reduce critical path
4. Optimized state machine with only 3 states (IDLE, CALC, DONE)
5. Special handling for division by zero and minimum value (-128) cases
6. Combined remainder/quotient update in single cycle per bit

Key Innovations:
- Early termination saves cycles when possible
- Non-restoring avoids unnecessary restoration steps
- Parallel sign handling improves timing
- Compact state machine reduces control overhead
- Special case handling for robustness
