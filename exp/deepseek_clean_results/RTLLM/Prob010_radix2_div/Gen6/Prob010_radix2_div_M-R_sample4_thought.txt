Refactored Design Approach:
1. Convert to explicit state machine with 3 states: IDLE, CALC, DONE
2. Use continuous assignments for combinational logic where possible
3. Separate arithmetic operations into dedicated always blocks
4. Simplify counter logic using parameterized states
5. Make sign handling more explicit with dedicated registers
6. Improve division-by-zero handling
7. Use consistent non-blocking assignments throughout

Key Improvements:
- Clear state machine structure improves readability
- Combinational outputs via assign statements
- Dedicated arithmetic blocks for better synthesis
- Simplified counter with parameterized width
- More robust error handling
- Consistent coding style
