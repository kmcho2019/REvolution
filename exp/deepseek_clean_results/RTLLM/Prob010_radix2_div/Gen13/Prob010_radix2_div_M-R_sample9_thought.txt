Refactored Radix-2 Divider Design:
1. Use continuous assignments for combinational logic where possible
2. Separate the FSM into explicit states (IDLE, CALC, DONE)
3. Move sign calculations to dedicated combinational blocks
4. Simplify the counter to 3 bits (0-7) since we only need 8 steps
5. Use explicit wire declarations for intermediate results
6. Handle division by zero by returning max values
7. Make state transitions more explicit and readable

Key Improvements:
- Clear separation of combinational and sequential logic
- More readable state machine
- Explicit handling of special cases
- Reduced register usage
- Better timing characteristics
