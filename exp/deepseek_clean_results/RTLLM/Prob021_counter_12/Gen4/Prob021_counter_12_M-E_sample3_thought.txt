Novel Architecture: State Machine Counter with Pre-Decoded Outputs
1. Implement the counter as a finite state machine with 12 explicit states
2. Each state directly represents one count value (0-11)
3. Use one-hot encoding for state representation to simplify next-state logic
4. Implement a parallel state transition decoder that computes all possible next states
5. Use valid_count as a clock enable for the state register
6. Reset forces transition to state 0 (all other state bits cleared)

Key Advantages:
- One-hot encoding simplifies next-state logic (only 2 possible transitions per state)
- Parallel state transition computation enables faster operation
- Pre-decoded outputs eliminate output decoding logic
- Clear separation between state transition logic and output generation
- Easily extensible to non-linear counting sequences
- Reduced fan-out compared to binary counters
