Novel Architecture: State Machine Counter with Optimized Terminal Detection
1. Implement the counter as a state machine with 12 distinct states (0-11)
2. Use one-hot encoding for state representation to simplify terminal state detection
3. Optimize terminal count detection by using bitwise operations instead of full comparison
4. Implement a synchronous load mechanism for reset and wrap-around
5. Use a priority-encoded next state logic for efficient implementation
6. Separate the state transition logic from output generation for better modularity

Key Advantages:
- Faster terminal count detection using simple bitwise operations
- One-hot encoding enables simpler state transition logic
- Clear separation between control and datapath
- More power-efficient as only one state bit toggles per transition
- Easier to modify count sequence if requirements change
