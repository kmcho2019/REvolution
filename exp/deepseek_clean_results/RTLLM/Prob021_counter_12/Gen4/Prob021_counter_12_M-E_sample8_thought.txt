I'll implement a parallel load counter that pre-computes all possible next states in a combinational block. This approach:
1. Uses a 4-bit register with parallel load capability
2. Pre-computes the next count value (either increment or wrap-around) in combinational logic
3. Only updates the register when valid_count is active
4. Implements synchronous reset for better timing characteristics
5. Uses a simple equality comparison for wrap-around detection

Key advantages:
- Parallel load enables single-cycle state transitions
- Clean separation of combinational and sequential logic
- No clock gating needed (lower risk of timing issues)
- Simple, predictable timing path
- Easily extendable to different count ranges
