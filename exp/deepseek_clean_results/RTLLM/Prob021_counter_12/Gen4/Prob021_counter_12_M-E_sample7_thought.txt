This novel implementation uses a finite state machine approach with parallel load capability for the counter. Key features:

1. State machine with 12 states (0-11) encoded in 4 bits
2. Parallel load capability when reset is active (loads 0)
3. Next state logic uses a compact increment-or-wrap calculation
4. Output is registered for better timing
5. Enable (valid_count) gates the state transition logic

Advantages:
- More explicit state representation
- Easier to modify for non-linear counting sequences
- Clear separation of control and datapath
- Better timing characteristics due to simplified next-state logic
- Potential for power optimization through clock gating
