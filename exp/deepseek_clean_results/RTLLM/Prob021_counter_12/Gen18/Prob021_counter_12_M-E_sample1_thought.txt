Novel Architecture: State Machine with Pre-Decoded Outputs
1. Concept: Implement the counter as a state machine with 12 explicit states (0-11)
2. Key Features:
   - One-hot encoding for power efficiency (only one flip-flop toggles per transition)
   - Pre-decoded outputs eliminate combinational logic delay
   - State transitions are simple shift operations when counting
   - Natural wrap-around at state 11
3. Advantages:
   - Lower dynamic power (only one state bit changes per clock)
   - Faster output (directly from flops, no incrementer delay)
   - More deterministic timing (no carry chain)
   - Easier to add additional features (like pause states)
4. Trade-offs:
   - Slightly more area (12 flops vs 4 flops)
   - More complex reset logic
