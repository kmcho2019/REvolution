This design implements a parallel load counter with synchronous reset and enable. The key innovations are:

1. Parallel Load Optimization:
   - Instead of incrementing and then comparing for wrap-around, we pre-calculate the next value
   - Uses a multiplexer to select between increment or reset to 0 when reaching 11

2. Synchronous Enable:
   - Proper synchronous design without clock gating
   - Only updates the counter when valid_count is high

3. Efficient Wrap-Around:
   - Uses bit pattern matching (4'b1011) for efficient comparison
   - Next state logic is optimized for minimal gate count

4. Reset Handling:
   - Synchronous reset for better timing predictability
   - Clear reset-to-zero path for reliable initialization

This approach maintains all functionality while being more robust and timing-friendly than clock-gated solutions.
