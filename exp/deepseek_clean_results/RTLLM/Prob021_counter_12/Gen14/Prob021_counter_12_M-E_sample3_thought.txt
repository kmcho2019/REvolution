Novel Architecture Idea:
1. State Machine Approach: 
   - Implement the counter as a state machine with 12 states (0-11)
   - Each state directly maps to a count value
   - Eliminates arithmetic operations for increment/decrement

2. Synchronous Enable:
   - Uses valid_count as a synchronous enable signal
   - No clock gating for better timing characteristics

3. Optimized Wrap-Around:
   - Next-state logic uses simple state transitions
   - Reset state is hardcoded to 0
   - Final state (11) directly transitions to state 0

4. One-Hot Encoding Benefits:
   - Potentially faster state transitions
   - Simpler comparison logic (single bit check)
   - Power efficient as only one flip-flop toggles per transition

5. Additional Optimization:
   - Output is directly derived from state encoding
   - No additional output register needed
   - Clean synchronous design without timing risks
