Novel approach: State machine-based counter with explicit state encoding
1. Instead of a simple incrementer, implement as a state machine with 12 explicit states
2. Each state directly corresponds to a count value (0-11)
3. State transitions are controlled by valid_count and reset signals
4. Benefits:
   - More explicit control flow
   - Easier to modify for non-linear counting sequences
   - Potentially better timing as next state logic is simplified
   - Clear separation between control and datapath
5. Implementation uses parameterized state encoding and case statement for next state logic
