Novel approach: State machine-based counter with explicit state encoding
1. Instead of a simple binary counter, implement a state machine that explicitly handles each count value
2. Use one-hot encoding for states to potentially improve timing and power characteristics
3. Separate the state transition logic into distinct cases for better readability and optimization
4. Implement a wrap-around mechanism by explicitly checking for the max count value (11)
5. Use a case statement for state transitions which can be more efficiently synthesized for small counters

Key advantages:
- Explicit state handling makes timing paths more predictable
- One-hot encoding can reduce glitching power
- Clear separation of reset, counting, and hold states
- Potential for better synthesis optimization due to structured state transitions
