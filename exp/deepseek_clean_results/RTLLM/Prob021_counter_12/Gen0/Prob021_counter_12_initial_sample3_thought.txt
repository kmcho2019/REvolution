The design requires a 4-bit counter that counts from 0 to 11 (inclusive) and wraps around. The counter should:
1. Reset to 0 when rst_n is low (active low reset)
2. Increment on each clock cycle when valid_count is high
3. Pause counting when valid_count is low
4. Wrap around to 0 after reaching 11 (4'd11)

The implementation uses sequential logic with synchronous reset. The counter value is stored in a register (out) that updates on the rising edge of the clock. The next state logic checks the current count value and valid_count to determine whether to increment, wrap around, or hold the current value.
