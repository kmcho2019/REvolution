Novel approach: State Machine with Explicit Count Control
1. Instead of a simple counter, implement a state machine that explicitly manages counting behavior
2. Use enumerated states for better readability and control
3. Separate the counting logic into distinct states: RESET, COUNTING, and HOLD
4. Implement a dedicated wrap-around check in the COUNTING state
5. This approach provides more explicit control flow and could be easier to modify for future requirements

Key advantages:
- More transparent state transitions
- Easier to add additional states or behaviors
- Clear separation of reset, counting, and hold logic
- Potential for better timing due to simplified next-state logic
