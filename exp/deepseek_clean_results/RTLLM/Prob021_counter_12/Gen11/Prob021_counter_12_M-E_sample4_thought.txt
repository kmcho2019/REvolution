Novel Architecture: Parallel Load Counter with Precomputed Next State

Key Innovations:
1. Parallel Load Approach: Instead of incrementing and checking for wrap-around, we precompute all possible next states in parallel and select using a multiplexer
2. Optimized Wrap-Around: Uses bitwise operations for wrap-around detection (no comparator in critical path)
3. Synchronous Enable: Proper synchronous design without clock gating
4. State Encoding: Leverages one-hot encoding for the control logic to reduce switching power

Benefits:
- Critical path only contains a 2:1 mux (faster timing)
- No arithmetic operations in critical path
- Lower power due to reduced switching activity
- Clean synchronous design without clock gating issues
