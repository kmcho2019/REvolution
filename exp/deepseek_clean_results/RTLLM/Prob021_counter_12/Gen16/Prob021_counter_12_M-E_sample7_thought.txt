Novel FSM-based Counter Architecture:

1. State Encoding:
- Use one-hot encoding (12 states) for better timing and glitch-free operation
- Each state directly represents a count value (state0=0, state1=1,... state11=11)

2. Control Logic:
- Implement explicit state transitions controlled by valid_count
- Reset forces transition to state0 (count=0)
- When enabled, progresses through states sequentially
- State11 wraps back to state0

3. Advantages:
- Predictable timing paths (each state transition is simple)
- No arithmetic operations needed (just state transitions)
- Clear relationship between states and output values
- Easily extensible for more complex counting patterns
- Better for formal verification due to explicit state machine
