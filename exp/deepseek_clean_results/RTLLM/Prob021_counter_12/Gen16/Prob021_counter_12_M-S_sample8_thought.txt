To simplify the counter design while maintaining functionality:
1. Use a single always block with clear priority (reset first, then count enable)
2. Let the counter naturally wrap around from 11 (4'b1011) to 0 (4'b0000) when incrementing
3. Remove any explicit comparison logic by relying on 4-bit arithmetic overflow
4. Maintain minimal logic operations while keeping all required functionality

The key simplification is recognizing that when the 4-bit counter reaches 12 (4'b1100), it will automatically wrap to 0 due to bit overflow, eliminating the need for explicit wrap-around logic while still maintaining the 0-11 count sequence.
