Innovative FSM-based counter design with these key features:
1. One-hot encoded states (12 states for 0-11) for fast state transitions
2. Parallel state loading for instant reset (bypassing sequential counting)
3. State transition logic optimized for minimal gate delay
4. Built-in next-state prediction to eliminate comparison delay
5. Power-optimized by disabling unused state transitions when valid_count=0

Advantages:
- Faster operation (single-cycle state transitions)
- Lower dynamic power (only one state bit toggles per count)
- Clean timing paths (no arithmetic comparisons in critical path)
- Immediate reset response (parallel load capability)
- Scalable to larger counters with similar benefits
