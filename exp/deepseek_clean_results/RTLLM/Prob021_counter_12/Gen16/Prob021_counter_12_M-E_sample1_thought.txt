This design implements the counter as a finite state machine with 12 explicit states (0-11). The key differences from the standard approach are:
1. Uses one-hot encoding for state representation (12 flip-flops)
2. State transitions are controlled by a decoder that activates the next state
3. Reset clears all states except state0
4. Counting is implemented as a rotating '1' through the one-hot states

Advantages:
- Very fast state transitions (single gate delay)
- Glitch-free outputs
- Power efficient when idle (only one flip-flop toggles per count)
- Explicit state representation makes timing analysis straightforward

Trade-offs:
- Uses more flip-flops than binary encoding (12 vs 4)
- Slightly more complex next-state logic
- Reset logic is more involved
