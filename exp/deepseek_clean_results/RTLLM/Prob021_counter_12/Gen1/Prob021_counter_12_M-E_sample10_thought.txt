Instead of a conventional binary counter, we'll implement this as a state machine with 12 distinct states (0-11) using one-hot encoding. This approach:
1. Uses 12 flip-flops (one for each count value) for potentially better timing
2. Simplifies the wrap-around logic (no comparator needed)
3. Makes the valid_count gating more explicit in the state transitions
4. Still maintains synchronous reset behavior

The state transitions will be:
- Reset: All states cleared except state 0
- Counting: Current state shifts left (with wrap-around)
- Hold: Maintain current state
