The original FSM approach is unnecessarily complex for a simple counter. We can simplify this by:
1. Using a standard binary counter with wrap-around logic
2. Removing the explicit state encoding parameters
3. Implementing a simple increment-and-wrap mechanism
4. Maintaining the same control signals (rst_n and valid_count)

This approach will:
- Reduce area by eliminating the large case statement
- Improve timing by using simple arithmetic comparison
- Lower power by reducing unnecessary switching
- Maintain identical functionality
