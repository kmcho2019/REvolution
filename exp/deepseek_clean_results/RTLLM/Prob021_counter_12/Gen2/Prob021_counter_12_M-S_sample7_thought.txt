The original solution is already quite efficient, but we can simplify it slightly by:
1. Removing the explicit comparison with 4'd11 and instead using modular arithmetic
2. Combining the reset and increment logic into a single conditional statement
3. Using a simpler wrap-around mechanism by taking advantage of Verilog's automatic truncation of bits

The key insight is that since we're counting to 12 (0-11), we can use the property that (current_count + 1) % 12 will automatically wrap around when we reach 11. This eliminates the need for a separate comparison operation.
