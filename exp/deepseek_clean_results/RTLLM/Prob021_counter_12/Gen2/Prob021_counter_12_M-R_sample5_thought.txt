I'll refactor the counter using a pure combinational approach with continuous assignments. The key changes are:
1. Replace the sequential always block with continuous assignments
2. Use a wire for the output instead of a reg
3. Implement the counter logic using ternary operators in a single assign statement
4. Maintain the same functionality but with a more concise structure

This approach:
- Eliminates the need for explicit state storage
- Makes the design more compact
- Still maintains the same synchronous behavior through clock edge triggering
- Keeps all the original functionality (reset, enable, wrap-around)
