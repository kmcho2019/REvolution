Refactoring Strategy:
1. Maintain synchronous design principles by removing clock gating
2. Use synchronous reset for better consistency with standard design practices
3. Keep the efficient wrap-around logic but implement it with continuous assignment
4. Separate the combinational next-state logic from the sequential state update
5. Use a wire for next-state calculation to make the design more modular

Key Improvements:
- Eliminates gated clock issues while maintaining low power (enable still controls counting)
- Clear separation of combinational and sequential logic
- Maintains the same functionality with cleaner structure
- Potentially better timing as all logic is synchronous
