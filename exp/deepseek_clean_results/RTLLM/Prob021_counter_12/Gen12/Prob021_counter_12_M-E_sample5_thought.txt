Novel Shift Register Counter Architecture:
1. Concept: Implement the counter using a shift register with feedback logic instead of traditional binary counting
2. Benefits:
   - Reduced critical path (only 1-bit shift per cycle)
   - Lower power consumption (only one bit toggles per increment)
   - Simplified wrap-around logic
3. Implementation Details:
   - Use a 12-bit shift register where only one bit is '1' at any time
   - The '1' circulates through the register to represent counts 0-11
   - Feedback logic handles the wrap-around
   - Output encoding converts the one-hot state to binary
4. Advantages:
   - No arithmetic operations needed
   - Glitch-free outputs
   - Natural power gating when valid_count is low
