Novel FSM-based Counter Architecture:

1. Concept:
- Implement the counter as a 12-state FSM (states 0-11) instead of a binary counter
- Each state directly represents the count value, eliminating arithmetic operations
- State transitions are controlled by valid_count and reset signals

2. Advantages:
- No arithmetic operations needed (simpler combinational logic)
- Clear state transitions make timing more predictable
- Natural power gating - only the current state register toggles
- Easier to add non-linear counting sequences if needed later

3. Implementation:
- Use one-hot encoding for states (12 flip-flops) for simplest decode logic
- Next state logic depends only on current state and valid_count
- Reset forces state 0 (all flip-flops low except state 0)
- Output is derived directly from state encoding
