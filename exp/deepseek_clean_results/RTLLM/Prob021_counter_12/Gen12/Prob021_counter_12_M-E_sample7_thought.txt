Novel Architecture Idea:
1. Implement the counter as an explicit state machine with 12 states (0-11)
2. Use one-hot encoding for state representation (12 flip-flops)
3. Advantages:
   - No arithmetic logic needed (simpler critical path)
   - Natural glitch-free output (each state directly drives output bits)
   - Easy to add non-linear counting sequences if needed later
   - Clear state transitions visible in code
4. Trade-offs:
   - Uses more flip-flops (12 vs 4) but simpler combinational logic
   - Power consumption may be higher due to one-hot encoding
   - Better timing at high frequencies due to reduced combinational path

State Transition Logic:
- Reset: All states cleared except state0
- Enabled counting: Current state shifts left (with wrap-around)
- Disabled: State remains unchanged
