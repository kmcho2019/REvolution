Refactoring approach:
1. Replace the sequential always block with combinational logic and a register
2. Use an assign statement for the next state logic
3. Separate the reset and count enable logic into distinct components
4. Maintain the same functionality but with a different structural implementation

Key changes:
- The counter value is now stored in a separate register (count_reg)
- Next state logic is computed combinationally using an assign statement
- Reset and count enable conditions are handled in the next state calculation
- The output is directly assigned from the register
