Novel Architecture Idea:
1. LFSR-Style Counter: Instead of conventional binary counting, implement a custom state sequence that:
   - Uses XOR feedback for state transitions (like LFSR)
   - Specifically designed for 12 states (0-11)
   - Provides glitch-free transitions and balanced switching activity

2. Optimized State Encoding:
   - Custom 4-bit encoding where each state transition requires minimal bit changes
   - Hamming distance of 1 between consecutive states when possible
   - Special wrap-around logic from state 11 to 0

3. Power and Timing Benefits:
   - Reduced switching activity compared to binary counter
   - Shorter critical path due to simpler feedback logic
   - Maintains synchronous design principles

4. Implementation:
   - State transitions determined by optimized pattern
   - Reset forces to all-zero state
   - Counting only occurs when valid_count is high
   - No clock gating to avoid timing issues
