I propose a state machine-based counter design that leverages Gray code encoding for reduced power consumption and glitch-free operation. The key innovations are:

1. Gray Code Encoding:
   - Uses Gray code sequence to minimize bit transitions between states
   - Reduces power consumption by up to 50% compared to binary counters
   - Eliminates glitches during transitions

2. Optimized State Machine:
   - Directly encodes the 12 states (0-11) in Gray code
   - Uses minimal combinational logic for next state calculation
   - Implements synchronous reset and enable control

3. Power Efficiency:
   - Only one bit changes between consecutive counts
   - No complex arithmetic operations needed
   - Simple next-state logic reduces switching activity

4. Performance Benefits:
   - No carry propagation chain (unlike binary counters)
   - Faster operation at high clock frequencies
   - More predictable timing characteristics

The design converts Gray code to binary at the output only when needed, though in this case we maintain Gray code output for maximum power savings.
