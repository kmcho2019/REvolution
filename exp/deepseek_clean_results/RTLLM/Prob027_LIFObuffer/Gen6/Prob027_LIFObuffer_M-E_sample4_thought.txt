Novel Architecture: Circular Buffer with Dual Pointers
1. Instead of traditional stack pointer, use separate head (write) and tail (read) pointers
2. Implement as circular buffer with wrap-around logic
3. Key advantages:
   - Read and write operations can occur simultaneously when not empty/full
   - More efficient flag generation logic
   - Better timing due to separated read/write paths
   - Easier to scale to larger depths
4. Implementation details:
   - Head pointer advances during writes
   - Tail pointer advances during reads
   - Buffer full when head+1 == tail (with wrap-around)
   - Buffer empty when head == tail
   - Separate combinational logic for flags
   - Registered outputs for better timing
