Improvement Strategy:
1. Timing Optimization:
   - Remove ternary operators from flag generation to simplify critical path
   - Generate EMPTY/FULL flags combinatorially outside the always block
   - Simplify SP to 2 bits since we only need to track 0-4 (5 states)

2. Power Optimization:
   - Remove unnecessary memory clearing on pop operations
   - Add clock gating for stack memory when EN=0

3. Area Optimization:
   - Reduce SP width to 2 bits
   - Remove redundant memory initialization
   - Simplify flag logic

4. Functional Improvements:
   - Add parameter for stack depth
   - Make reset more power-efficient by only resetting necessary elements
   - Remove dataOut reset since it's not required for functionality
