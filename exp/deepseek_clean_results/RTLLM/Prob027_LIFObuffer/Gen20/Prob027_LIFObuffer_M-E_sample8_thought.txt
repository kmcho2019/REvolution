Novel Architecture Idea:
1. Use dual pointers (write_ptr and read_ptr) to track positions independently
2. Implement circular buffer addressing with modulo arithmetic
3. Use a 'count' register to track number of entries (simplifies empty/full detection)
4. Read always occurs from write_ptr-1 (LIFO behavior)
5. Separate the pointer update logic from data path for better timing
6. Use gray coding for pointers to reduce switching power
7. Implement power-optimized memory writes (only update needed locations)

Key Advantages:
- More flexible pointer management
- Easier to scale to larger depths
- Lower power due to gray coding
- Simpler empty/full detection logic
- Better timing due to separated control/data paths
