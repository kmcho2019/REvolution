Refactoring Strategy:
1. Stack Pointer Approach: Maintain the stack pointer (SP) as the primary control mechanism, eliminating explicit FSM states since SP inherently tracks buffer status.

2. Combinational Flags: Compute EMPTY and FULL directly from SP values (0 for empty, 4 for full) using continuous assignments.

3. Synchronous Memory Operations: Keep all memory writes synchronous but make dataOut combinational for immediate read access.

4. Simplified Control Logic: Use a single always block for synchronous operations (push/pop) with clear priority for reset.

5. Efficient Memory Handling: Only update memory during write operations and let SP manage the active data locations.

Key Improvements:
- More straightforward control flow using SP as the primary state indicator
- Reduced logic complexity by removing explicit FSM
- Immediate data availability through combinational output
- Clear separation of synchronous and combinational logic
- More intuitive empty/full detection
