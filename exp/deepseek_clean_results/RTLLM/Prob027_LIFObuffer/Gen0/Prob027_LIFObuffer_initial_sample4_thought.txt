The LIFO buffer will be implemented as a stack with a stack pointer (SP) tracking the top of the stack. The stack memory is an array of 4-bit registers. Key operations:
1. Reset clears the stack and sets SP to 4 (empty state)
2. Write (push) operation when not full: store data and decrement SP
3. Read (pop) operation when not empty: output data and increment SP
4. Flags are updated based on SP position (0=full, 4=empty)
All operations are synchronous to the rising clock edge when enabled.
