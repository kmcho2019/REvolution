Novel Architectural Idea: Shift Register Stack with Circular Buffer
1. Instead of using a traditional stack pointer and memory array, implement the stack using a shift register approach with circular buffer behavior
2. Use head and tail pointers to track the top and bottom of the stack
3. Implement wrap-around logic for efficient memory utilization
4. Flags are generated directly from pointer relationships
5. Reset initializes all registers to known state
6. Push operations shift data in at the head, pop operations read from the tail
7. This approach reduces memory access complexity and improves timing by eliminating arithmetic operations on the pointer

Key Advantages:
- Simplified pointer arithmetic (only increment operations)
- Better timing due to elimination of subtraction operations
- More efficient memory utilization
- Clearer full/empty conditions based on pointer relationships
- Easier to scale for deeper stacks
