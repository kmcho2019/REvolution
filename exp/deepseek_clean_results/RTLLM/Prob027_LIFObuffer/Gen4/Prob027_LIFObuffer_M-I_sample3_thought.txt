Improvement Strategy:
1. Timing Optimization: Simplify flag logic by moving EMPTY/FULL generation outside the always block and using direct comparisons to reduce critical path.
2. Power Optimization: Remove unnecessary memory clearing on pop operations and implement clock gating for the stack memory when not enabled.
3. Area Optimization: Reduce SP width to 2 bits since we only need to represent 0-4 (5 states) which can be encoded in 3 bits (already optimal). Keep as is.
4. Reusability: Add parameter for stack depth.
5. Reset Optimization: Only reset necessary registers (SP and flags) rather than all memory locations.

Key Changes:
- Move EMPTY/FULL to combinational logic
- Remove memory clearing on pop
- Add stack depth parameter
- Simplify reset logic
- Maintain same functionality while improving PPA
