Refactoring Strategy:
1. State Machine Conversion: Replace the separate stack pointer and empty_state logic with a unified 3-state FSM (Empty, Partial, Full) for clearer state management.

2. Combinational Output: Make dataOut combinational for immediate response when reading, while maintaining synchronous memory updates.

3. Simplified Flag Logic: Derive EMPTY and FULL directly from the FSM state rather than calculating separately.

4. Memory Optimization: Only update memory locations that are actually being used, reducing unnecessary writes.

5. Clock Gating: Use the EN signal to gate clock-sensitive operations more efficiently.

Key Improvements:
- Clearer state management with explicit FSM
- Faster read operations with combinational dataOut
- Reduced power consumption by minimizing memory writes
- More efficient clock utilization
- Simplified flag generation
