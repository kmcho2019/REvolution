Refactoring Strategy:
1. State Machine Conversion: Replace the stack pointer + empty_state approach with a clear 3-state FSM (EMPTY, PARTIAL, FULL) for more intuitive control flow.

2. Combinational Outputs: Convert dataOut to a combinational output that always reflects the top of stack, eliminating the need for a registered output.

3. Simplified Memory Handling: Keep stack memory writes synchronous but make reads combinational for better timing.

4. Flag Optimization: Implement EMPTY and FULL as direct outputs of the FSM state rather than computed signals.

5. Reset Optimization: Only reset the FSM state and stack pointer during reset, leaving memory initialization to happen naturally during writes.

Key Improvements:
- Clearer state transitions with explicit FSM
- Reduced latency on dataOut by making it combinational
- Simplified control logic with state-based flags
- More efficient reset implementation
- Better timing with combinational stack reads
