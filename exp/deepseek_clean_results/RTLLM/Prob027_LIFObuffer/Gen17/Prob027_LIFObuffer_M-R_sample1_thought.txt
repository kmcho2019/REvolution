Refactoring Strategy:

3. Implement memory writes using parallel assignments with pointer decoding for cleaner code
4. Move all combinational logic to continuous assignments for clarity
5. Simplify reset logic to only initialize essential elements
6. Use a packed array for stack memory to improve area efficiency

- Packed array reduces memory implementation overhead
