Novel Architecture: Circular Stack with Dual Pointers
1. Instead of traditional stack pointer, use head and tail pointers to implement a circular buffer
2. Head pointer tracks the next write position, tail pointer tracks the next read position
3. Empty condition: head == tail and not full
4. Full condition: (head + 1) % 4 == tail
5. Benefits:
   - More efficient memory utilization
   - Better timing as pointer comparisons are simpler
   - Easier to extend depth if needed
   - Clear separation of read/write paths
6. Implementation:
   - 4-entry memory array
   - 2-bit head and tail pointers
   - Combinational flag logic for better timing
   - Parallel memory initialization during reset
