Improvement Strategy:
1. Timing Optimization: Simplify flag logic by moving EMPTY/FULL generation outside the always block and using direct comparisons to reduce critical path.
2. Power Optimization: Remove unnecessary memory clearing on pop operations and implement clock gating for stack memory when not enabled.
3. Area Optimization: Reduce SP width to 2 bits since we only need to represent 0-4 (0b00-0b100), and use one-hot encoding for better synthesis.
4. Reusability: Add parameter for stack depth to make design more flexible.

Key Changes:
- Move EMPTY/FULL to combinational logic
- Remove stack_mem clearing on pop
- Reduce SP to 2 bits with one-hot encoding
- Add stack depth parameter
- Optimize reset to only clear necessary elements
