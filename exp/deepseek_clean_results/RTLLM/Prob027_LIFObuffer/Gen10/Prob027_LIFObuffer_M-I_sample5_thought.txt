Improvement Strategy:
1. Timing Optimization:
   - Separate flag generation logic for read/write operations to eliminate conditional comparisons
   - Simplify op_valid signal by breaking into separate read/write enable signals
   - Register flag outputs to break critical path

2. Power Optimization:
   - Remove unnecessary stack memory clearing during reset
   - Add enable condition for dataOut register updates
   - Use 2-bit stack pointer encoding (0-3) with empty state detection

3. Area Optimization:
   - Reduce stack pointer width from 3 to 2 bits
   - Implement memory initialization with for-loop
   - Share comparison logic between EMPTY and FULL flags

Key Changes:
1. New 2-bit stack pointer with empty state detection (SP=4 encoded as SP=3 with empty flag)
2. Separate always blocks for read and write operations
3. Optimized flag generation with registered outputs
4. Reduced memory switching during reset
