Refactoring approach:
1. Replace the empty_state register with direct SP-based empty detection (SP == 0)
2. Use continuous assignments for all combinational logic (flags and output)
3. Split the sequential logic into separate always blocks for:
   - Stack pointer control
   - Memory write operations
   - Output register
4. Simplify FULL detection using SP == 3
5. Make memory operations more explicit with separate conditions

Benefits:
- Clearer separation of combinational and sequential logic
- More straightforward empty/full detection
- Easier timing analysis with separate always blocks
- Reduced register usage by eliminating empty_state
- More explicit memory write operations
