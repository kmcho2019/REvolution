Novel Architecture Idea: Sign-Magnitude Subtraction with Early Sign Determination

1. Instead of using signed arithmetic, process numbers in sign-magnitude format for more explicit control
2. Determine result sign early based on input magnitudes and signs
3. Perform magnitude subtraction separately using unsigned arithmetic
4. Implement magnitude comparison logic to handle underflow cases
5. Use parameterized bit widths for both integer and fractional parts
6. Include overflow/underflow detection flags
7. Optimize for synthesis by using only unsigned operations after sign resolution

Key Advantages:
- Explicit sign handling avoids signed arithmetic synthesis issues
- Early sign determination simplifies magnitude processing
- Clear separation of sign and magnitude logic
- Built-in overflow/underflow detection
- More transparent fixed-point handling
