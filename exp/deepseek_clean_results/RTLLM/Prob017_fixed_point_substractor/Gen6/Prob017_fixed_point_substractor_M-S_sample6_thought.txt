Simplified design approach:

1. Remove pipeline stages and enable signal to reduce complexity
2. Perform all operations combinationally for immediate results
3. Simplify sign handling by:
   - Directly computing subtraction when signs match
   - Using addition when signs differ
4. Handle zero case by checking magnitude after operation
5. Maintain same parameterization (Q, N) for precision control

Key simplifications:
- Single always block for all operations
- No clock or enable needed (pure combinational)
- Reduced register usage
- Simplified control flow
- Same arithmetic precision maintained
