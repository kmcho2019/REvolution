Novel Architectural Approach:

1. Parallel Processing:
   - Perform both possible subtractions (a-b and b-a) simultaneously
   - Use magnitude comparison to select the correct result
   - Eliminates sequential sign checks and absolute value calculations

2. Sign Prediction:
   - Generate both possible result signs in parallel
   - Use magnitude comparison to select the correct sign
   - Reduces critical path for sign determination

3. Early Zero Detection:
   - Compare input operands for equality before subtraction
   - Bypass arithmetic operations when result is zero
   - Saves power and improves timing

4. Unified Result Selection:
   - Single multiplexer stage selects between parallel results
   - Clean separation of arithmetic and control logic
   - Easier timing closure

Key Advantages:
- All arithmetic operations happen in parallel
- Sign determination happens in constant time
- Zero case is handled without affecting critical path
- More scalable for larger bit widths
- Clear separation of datapath and control logic
