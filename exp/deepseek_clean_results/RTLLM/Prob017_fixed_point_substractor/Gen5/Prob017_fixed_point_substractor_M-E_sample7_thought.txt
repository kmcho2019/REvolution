Novel Architectural Approach: Sign-Magnitude Based Fixed-Point Subtractor

Key Innovations:
1. Sign-magnitude representation for more intuitive sign handling
2. Explicit magnitude comparison for precise result sign determination
3. Separate fractional and integer part processing for Q precision control
4. Zero detection with priority encoding for clean zero results

Operation Flow:
1. Convert inputs to sign-magnitude format
2. Compare magnitudes to determine result sign
3. Perform magnitude subtraction based on comparison
4. Handle special cases (zero, overflow) explicitly
5. Convert back to two's complement format

Advantages:
- More intuitive sign handling than pure two's complement
- Explicit magnitude comparison matches mathematical intuition
- Clear separation of fractional and integer processing
- Robust zero handling without special cases
- Better visibility into arithmetic operations
