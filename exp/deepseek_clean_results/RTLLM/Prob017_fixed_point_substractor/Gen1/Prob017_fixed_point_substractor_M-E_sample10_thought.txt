Here's a novel approach using two's complement arithmetic with overflow detection and correction:
1. Perform direct two's complement subtraction (a - b)
2. Detect overflow conditions by comparing the signs of inputs and result
3. Correct overflow by either saturating to max/min values or wrapping around
4. Maintain fixed-point precision by keeping all operations within N bits
5. Use parameterized width for flexibility
6. Optimize for PPA by reducing comparison operations and using simple arithmetic

Key innovations:
- Eliminates separate sign/magnitude paths
- Uses native two's complement arithmetic
- Includes overflow protection
- More efficient hardware implementation
- Better suited for pipelining
