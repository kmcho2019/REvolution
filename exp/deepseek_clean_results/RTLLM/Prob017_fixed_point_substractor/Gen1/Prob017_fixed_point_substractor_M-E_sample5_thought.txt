My novel approach focuses on using two's complement arithmetic for fixed-point subtraction, which simplifies the sign handling and magnitude comparison. The key innovations are:
1. Convert both inputs to two's complement format for unified arithmetic
2. Perform standard two's complement subtraction
3. Handle overflow/underflow by saturating to maximum/minimum representable values
4. Implement proper rounding for the fractional part (Q bits)
5. Explicit zero detection with correct sign handling

This approach eliminates complex sign comparisons and provides more predictable hardware implementation.
