Novel Architectural Approach:

1. Unified Subtraction Core: Use a single subtraction unit for all cases by properly handling sign extension and two's complement
2. Dynamic Sign Adjustment: Convert inputs to two's complement form before operation, then back to sign-magnitude
3. Overflow Prevention: Implement sign extension to N+1 bits during calculation to prevent overflow
4. Early Zero Detection: Perform zero check on inputs before arithmetic operation for optimization
5. Sign-Magnitude Conversion: Efficient conversion between sign-magnitude and two's complement representations
6. Parameterized Precision: Fully utilize Q and N parameters for flexible fixed-point operations

Key Innovations:
- Single arithmetic path reduces hardware complexity
- Two's complement conversion enables unified subtraction
- Sign extension prevents overflow without extra logic
- Early zero detection optimizes common case
- Efficient representation conversion
- Fully parameterized implementation
