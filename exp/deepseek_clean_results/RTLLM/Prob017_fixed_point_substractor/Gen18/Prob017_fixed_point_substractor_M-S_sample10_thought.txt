Simplified Architecture Idea: Unified Two's Complement Subtraction with Sign Handling

1. Use native two's complement subtraction (a - b) as the core operation
2. Simplify by removing parallel computation paths and magnitude comparison
3. Handle zero result explicitly to avoid negative zero
4. Maintain overflow detection through sign bit analysis
5. Keep parameterized bit widths for flexibility
6. Remove generate block by always using signed comparison (works for both fixed-point and integer)

Key Simplifications:
- Single subtraction path instead of parallel computations
- Eliminated magnitude comparison logic
- Removed conditional signed/unsigned comparison
- Simplified result selection logic
- Maintains all required functionality with less hardware
