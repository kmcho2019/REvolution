Novel Architectural Approach:

1. Sign-Magnitude Separation: Process sign and magnitude separately for cleaner arithmetic operations
2. Unified Subtraction Core: Use a single subtraction unit for all cases by properly conditioning inputs
3. Dynamic Sign Adjustment: Compute result sign based on both input signs and magnitude comparison
4. Efficient Zero Handling: Implement zero detection through simple bitwise OR reduction
5. Overflow Protection: Include overflow detection for edge cases
6. Optimized Datapath: Minimize parallel paths by using conditional operand inversion

Key Advantages:
- Single subtraction core reduces logic duplication
- Explicit sign handling improves clarity
- Simple zero detection maintains performance
- Overflow detection adds robustness
- Clean separation of concerns in the architecture
