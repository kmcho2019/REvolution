Novel Architectural Approach:

1. Unified Subtraction Core: Instead of separate paths, use a single subtraction unit with sign-aware magnitude processing
2. Sign-Extended Arithmetic: Perform all operations using full N-bit width with proper sign extension
3. Dynamic Magnitude Adjustment: Conditionally invert operands based on sign comparison before subtraction
4. Result Normalization: Post-process the result to ensure correct sign and zero handling
5. Efficient Overflow Handling: Use carry-out detection for overflow cases
6. Bitwise Optimization: Leverage bitwise operations for sign manipulation

Key Innovations:
- Single arithmetic path reduces hardware complexity
- Sign-aware operand preparation simplifies subtraction logic
- Dynamic magnitude adjustment handles all cases uniformly
- Post-normalization ensures correct result formatting
- Carry-based overflow detection
- Minimal control logic for better timing
