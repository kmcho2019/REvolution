Simplification Strategy:

1. Direct Subtraction: Since Verilog's signed arithmetic already handles all sign cases correctly, we can rely on the built-in subtraction operation.

2. Remove Redundant Zero Handling: The subtraction operation naturally produces correct results including zero cases, so explicit zero detection isn't needed.

3. Simplified Parameter Usage: Keep parameters but only use them for bit-width specification.

Key Simplifications:
- Eliminate separate sign handling logic (Verilog handles it)
- Remove explicit zero detection
- Maintain parameterized width for flexibility
- Single continuous assignment for clean implementation
