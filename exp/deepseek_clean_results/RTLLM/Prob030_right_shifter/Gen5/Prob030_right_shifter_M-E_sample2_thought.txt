Novel Circular Buffer Architecture:
1. Instead of physically shifting bits, maintain a fixed register and track the "start" position using a pointer
2. Use a 3-bit pointer to indicate the current MSB position (0-7)
3. On each clock cycle, decrement the pointer (with wrap-around) and store the new input at the pointed position
4. Output is generated by reading the register contents starting from the pointer position
5. Benefits:
   - Eliminates the need for physical shifting, reducing combinational logic
   - Constant-time operation regardless of shift amount
   - More efficient for larger shift registers (scalable)
   - Easier to extend for variable shift amounts
