The current implementation is already quite optimal, but we can make minor improvements:

1. Remove the initial block since synthesis tools typically handle register initialization through reset signals or power-on state
2. Use a parameter for the shift width to make the design more flexible
3. Combine the shift and assignment into a single line for better readability
4. The PPA metrics show excellent results, so we'll maintain the same basic structure while making it more maintainable

The improved version will have identical functionality but be more flexible and slightly more synthesis-friendly.
