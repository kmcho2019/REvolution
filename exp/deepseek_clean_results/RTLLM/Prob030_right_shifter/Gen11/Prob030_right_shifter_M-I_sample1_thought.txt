Improvement Strategy:
1. Timing Optimization:
   - Remove clock gating (derived clock) to eliminate timing violations
   - Use synchronous enable signal instead
   - This simplifies the clock path and improves setup/hold margins

2. Area Optimization:
   - Eliminate intermediate wire (shifted_val)
   - Perform shift operation directly in always block
   - Reduce unnecessary logic elements

3. Power Optimization:
   - Maintain synchronous design practices
   - Let synthesis tool handle clock gating if beneficial
   - Simplified logic reduces dynamic power

4. Functional Enhancement:
   - Keep same core functionality
   - Make enable signal optional (default to always enabled)
   - Cleaner, more standard implementation
