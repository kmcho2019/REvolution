Here's a novel approach using a circular buffer implementation:
1. Instead of shifting bits every cycle, we'll maintain a pointer to track the current "start" of the buffer
2. The pointer increments each cycle, effectively creating a right-shift effect without physical shifting
3. The input bit is stored in the next available position
4. Output is generated by reading the buffer starting from the pointer position
This reduces power consumption by eliminating the need to shift all bits every cycle and only toggling the necessary bits.
