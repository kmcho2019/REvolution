To implement an 8-bit right shifter, we need a register that shifts its contents right by 1 bit on each clock cycle while inserting the input bit 'd' into the MSB. The register should be initialized to 0 at startup. The operation involves:
1. Right-shifting the current value of q by 1 bit (q >> 1)
2. Concatenating the input bit d with the shifted value to form the new q value
3. Performing this operation synchronously on the rising edge of the clock
