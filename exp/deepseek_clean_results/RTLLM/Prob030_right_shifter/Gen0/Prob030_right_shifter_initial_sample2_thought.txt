To implement an 8-bit right shifter, we'll use a synchronous design that shifts bits right on each clock edge. The design will:
1. Initialize an 8-bit register 'q' to 0
2. On each rising clock edge:
   - Perform a right shift operation (q >> 1)
   - Insert the new input bit 'd' into the MSB (q[7])
3. The output 'q' will continuously reflect the current shifted value
