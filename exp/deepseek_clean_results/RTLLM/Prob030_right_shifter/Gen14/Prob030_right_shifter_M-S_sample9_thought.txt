The current implementation is already quite minimal, using a single always block with direct concatenation for the shift operation. To further simplify, we can:
1. Remove the explicit initialization of q (0) since registers default to 0 in simulation
2. Use the simpler right shift operator combined with bit insertion, though this offers no real advantage over the current concatenation approach
3. Keep the single always block structure which is optimal for this simple sequential logic

However, the current implementation is actually the most straightforward and clean solution possible. Any further "simplification" would either:
- Not actually reduce complexity (just different syntax)
- Potentially make the code less clear
- Not provide any meaningful improvement

Therefore, the current solution is already optimal and shouldn't be modified further.
