Novel Architectural Idea: Dual-Edge Triggered Shift Register
1. Utilize both clock edges to potentially double throughput
2. Implement a ping-pong buffer scheme with two 4-bit registers
3. Alternate between registers on opposite clock edges
4. Combine partial results on each full clock cycle
5. Benefits: 
   - Potential for higher throughput
   - Reduced critical path between registers
   - Natural glitch filtering due to dual-edge operation

Key Features:
- Uses posedge for upper nibble (q[7:4])
- Uses negedge for lower nibble (q[3:0])
- Combines results on each full cycle
- Maintains same functional behavior as original
