The refactored design maintains the same shift-and-accumulate multiplication algorithm but implements it with these key changes:
1. Uses binary encoded state machine (2 bits) instead of one-hot for reduced area
2. Implements shifts on-demand rather than pre-computing all shifts
3. Uses continuous assignments for combinational logic where possible
4. Simplifies the counter to 4 bits (0-15) since we only need 16 cycles
5. Separates control and datapath more clearly
6. Uses explicit state transitions for better readability

The state machine now has three states:
- IDLE: Waits for start signal
- CALC: Performs 16 cycles of shift-and-add
- DONE: Asserts done for one cycle

Key optimizations:
1. Binary encoding reduces flip-flop count
2. On-demand shifting eliminates large multiplexers
3. Continuous assignments improve synthesis
4. Simplified state machine makes timing more predictable
5. Reduced counter width saves area
