The refactored design maintains the same shift-and-add multiplication algorithm but implements it with these key changes:
1. Uses continuous assignments for combinational logic instead of always blocks where possible
2. Simplifies the state machine to just 3 states (IDLE, CALC, DONE) by merging LOAD into CALC
3. Implements the counter and shift logic using arithmetic operations in continuous assignments
4. Uses explicit bit checking for the multiplier bits instead of a counter
5. Makes done flag generation purely combinational

Key improvements:
- Reduced state machine complexity
- More efficient use of continuous assignments
- Clearer separation of combinational and sequential logic
- Simplified control flow
- More direct implementation of shift-and-add
