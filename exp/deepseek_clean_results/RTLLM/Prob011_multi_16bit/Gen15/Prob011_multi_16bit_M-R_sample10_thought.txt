Refactored design using a state machine approach with explicit states for better readability and control:
1. Replaced the counter with a 3-state FSM (IDLE, WORKING, DONE)
2. Used separate always blocks for state transitions and output logic
3. Implemented shift accumulation with explicit bit checking
4. Simplified done signal generation by tying it directly to state
5. Used non-blocking assignments consistently for registers
6. Added explicit register declarations for all storage elements

Key improvements:
- Clearer state machine structure improves maintainability
- Separate combinational and sequential logic blocks
- Explicit state transitions make timing easier to analyze
- Done signal directly reflects FSM state
- Maintains same functionality while being more structured
