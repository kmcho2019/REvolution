Simplified design approach:
1. Use a minimal state machine with only 2 states (IDLE and BUSY) to reduce complexity
2. Eliminate pre-shifted array to reduce area and power consumption
3. Implement sequential shift-and-add with a single accumulator
4. Use a 4-bit counter (0-15) to track bit positions
5. Make done flag purely combinational based on counter value
6. Simplify control logic by combining load and calculation phases

Key simplifications:
- Reduced state machine complexity
- Removed large pre-shifted array
- Single accumulator for product calculation
- Minimal control logic
- Maintains same functionality with fewer resources
