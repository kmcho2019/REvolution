Refactored design with these improvements:
1. Simplified state machine using explicit states (IDLE, RUN, DONE) instead of counter
2. Used combinational logic with assign statements where possible
3. Pre-computed shifted versions of multiplier to avoid variable shift operation
4. Simplified done flag generation
5. Reduced counter width to exactly 4 bits (0-15)
6. Added early termination to save power

Key changes:
- Explicit state machine makes control flow clearer
- Pre-shifted multiplier values eliminate variable shift critical path
- Combinational outputs reduce unnecessary registers
- Smaller counter saves area
- Early stop at i=15 (instead of 17) saves power
