2. Shift Logic: Use Example 1's pre-computed shifts but only generate needed shifts to save power

- One-hot state machine for faster decoding
- Conditional shift computation to reduce power
- Optimized counter and done signal generation
- Pipelined accumulator for better timing
- Clean separation of control and datapath
