The refactored design maintains the same shift-and-add algorithm but improves structure and efficiency by:
1. Using explicit state machine with defined states (IDLE, LOAD, CALC, DONE)
2. Replacing sequential logic with combinational where possible
3. Simplifying control logic by removing redundant conditions
4. Using 'assign' for outputs where possible
5. Optimizing the shift operation by pre-computing all possible shifted versions

Key changes:
- Explicit state machine makes control flow clearer
- Combinational output assignments reduce unnecessary registers
- Pre-computed shift values simplify the critical path
- Cleaner reset and start handling
- More efficient done flag generation
