Refactored design approach:
1. Convert the sequential logic to a more explicit state machine with 3 states (IDLE, CALC, DONE)
2. Replace the counter-based approach with a state transition approach
3. Use continuous assignments for combinational logic where possible
4. Register outputs to improve timing
5. Simplify control logic by removing redundant conditions
6. Optimize the shifter by pre-calculating all possible shifted values and selecting with a mux

Key improvements:
- Explicit state machine makes timing behavior clearer
- Registered outputs reduce glitching power
- Pre-calculated shifts eliminate variable shifter timing issues
- Simplified control logic reduces area
- Maintains same shift-and-add algorithm but with better structure
