The refactored design maintains the same shift-and-add multiplication algorithm but improves PPA through:
1. Simplified state control using explicit states (IDLE, WORKING, DONE)
2. Fixed shift amounts instead of variable shifts to reduce multiplexer complexity
3. Synchronous output registers to reduce glitching
4. Optimized counter width (4 bits) since we only need 16 steps
5. Early termination when multiplier is zero for power savings

Key changes:
- Replace counter-based control with explicit state machine
- Use fixed shift amounts (pre-calculated) instead of variable shifts
- Move output assignments to clocked always block
- Add zero detection optimization
