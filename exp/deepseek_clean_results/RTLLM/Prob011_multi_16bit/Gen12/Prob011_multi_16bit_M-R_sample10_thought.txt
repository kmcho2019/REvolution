Refactored design approach:
1. Use a simpler 2-state FSM (IDLE and RUN) to reduce complexity
2. Replace the pre-shifted array with on-demand shifting using a barrel shifter
3. Make all outputs combinational using assign statements
4. Use a down counter instead of up counter for bit position
5. Combine the LOAD and CALC states into RUN state for efficiency
6. Implement done flag as combinational output based on counter value

Key improvements:
- Reduced state machine complexity
- Eliminated large pre-shifted array
- Barrel shifter reduces combinatorial path
- Down counter simplifies termination check
- All outputs are now combinational
- Fewer registers needed
