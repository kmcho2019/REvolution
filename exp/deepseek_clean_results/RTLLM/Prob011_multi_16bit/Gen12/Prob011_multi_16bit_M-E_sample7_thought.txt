Novel Radix-4 Booth Multiplier Architecture:
1. Implement Booth encoding to reduce number of addition steps from 16 to 8
2. Use a modified Booth algorithm that examines 3 bits at a time (radix-4)
3. Incorporate a sign extension optimization for unsigned multiplication
4. Implement a compact state machine with only 3 states (IDLE, CALC, DONE)
5. Use a priority-encoded shift amount selection to minimize hardware
6. Optimize critical path by pre-computing all possible partial products
7. Include early termination when multiplier bits are exhausted

Key Advantages:
- 50% fewer addition operations than naive approach
- Reduced power consumption due to fewer clock cycles
- Smaller area from simplified control logic
- Better timing from reduced critical path
- Maintains full precision with proper sign handling
