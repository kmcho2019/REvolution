Simplified design approach:
1. Remove the explicit state machine and use a simple counter-based approach
2. Eliminate pre-computed shift values to reduce area and power
3. Use direct shift-and-add operations during calculation
4. Simplify control logic by combining conditions
5. Maintain same functionality with fewer registers and simpler logic

Key simplifications:
- Single always block for all sequential logic
- Direct shift operation during accumulation
- Simplified done flag generation
- Reduced register usage
- More straightforward control flow
