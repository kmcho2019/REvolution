   - Pre-compute shifted versions of breg in parallel to eliminate variable-width shifter
   - Pipeline the accumulator to break the critical path (shift + add)

2. Power Optimization:

   - Freeze state registers when no state change is needed
   - Use bitwise masking to reduce comparator switching

3. Area Optimization:
   - Remove redundant default case in state machine
   - Optimize counter width and comparison logic
   - Use carry-save adder during accumulation phase

1. One-hot state encoding (4 bits) for faster state transitions
