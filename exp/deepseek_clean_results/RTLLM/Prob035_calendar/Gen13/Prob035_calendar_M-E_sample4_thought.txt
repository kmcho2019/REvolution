Novel State Machine Approach:
1. Use a finite state machine to track time progression states (normal, sec_rollover, min_rollover)
2. Pre-compute all next values in combinational logic before the clock edge
3. Implement a single sequential always block for clean timing
4. Use parameterized constants for clear rollover thresholds
5. Optimize comparisons by using equality checks against constants
6. Implement output registers for clean timing on outputs

Key Advantages:
- Clear state transitions make the design more maintainable
- Pre-computation reduces critical path delay
- Single clocked process improves timing consistency
- Parameterized constants make adjustments easier
- Output registers improve timing closure
