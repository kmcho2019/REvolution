Improvement Strategy:
1. Timing Optimization:
   - Separate the counters into two always blocks to break the long combinational path
   - Pre-compute rollover conditions one cycle earlier to reduce critical path
   - Use simpler comparison logic (>= instead of == for rollover detection)

2. Power Optimization:
   - Add enable signals to reduce unnecessary register updates
   - Use clock gating for hour counter updates
   - Simplify comparison logic to reduce switching activity

3. Area Optimization:
   - Use uniform 6-bit registers for all counters
   - Share common comparison logic between minutes and hours
   - Remove redundant comparators by using subtraction

Key Changes:
1. Split into two always blocks (seconds+minutes, hours)
2. Early rollover detection
3. Enable-based updating for hours
4. Simplified comparison logic
5. Uniform bit-widths
