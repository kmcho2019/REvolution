Novel State Machine Approach:
1. Implement a finite state machine (FSM) that tracks the counting state (seconds, minutes, hours)
2. Use a single counter register with dynamic rollover values (59/23) based on current state
3. Eliminate separate counters by time-multiplexing a single counter
4. State transitions occur only when needed (at rollover points), reducing switching activity
5. Use a modulo-60 counter for seconds/minutes and modulo-24 for hours with shared arithmetic

Key Advantages:
- Single counter register reduces flip-flop count by 2/3
- State-based control minimizes unnecessary comparisons
- Dynamic rollover values eliminate redundant logic
- Clean separation of time units through state transitions
- Natural power savings from reduced switching
