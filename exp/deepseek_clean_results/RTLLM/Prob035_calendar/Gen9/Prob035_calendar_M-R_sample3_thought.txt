Refactoring Strategy:
1. Replace sequential always blocks with continuous assignments for combinational logic
2. Use a single always block for sequential elements to maintain clean clock domain
3. Simplify rollover conditions by using intermediate counters
4. Optimize bit widths - use 6 bits for seconds/minutes (0-59) and 5 bits for hours (0-23)
5. Remove redundant combinational blocks by directly calculating next values

Key Improvements:
- Continuous assignments make rollover conditions clearer
- Single always block maintains synchronous behavior
- Direct next value calculation eliminates intermediate registers
- Cleaner separation of combinational and sequential logic
- More efficient use of bit widths
