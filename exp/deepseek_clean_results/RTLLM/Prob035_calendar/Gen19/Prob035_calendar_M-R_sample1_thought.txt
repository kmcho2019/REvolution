Refactoring Strategy:
1. Use continuous assignments (assign) for combinational logic to simplify the design
2. Create next-state logic for each counter separately before registering
3. Use a single always block for sequential elements to maintain synchronization
4. Simplify rollover conditions by making them hierarchical
5. Optimize bit widths - 6 bits for sec/min (0-59), 5 bits for hours (0-23)
6. Explicitly handle all rollover cases in the combinational logic

Key Improvements:
- Clear separation of combinational and sequential logic
- Reduced register usage by calculating next states before registering
- More straightforward rollover logic with cascaded conditions
- Maintains same functionality with potentially better timing
- Easier to modify individual counter behaviors
