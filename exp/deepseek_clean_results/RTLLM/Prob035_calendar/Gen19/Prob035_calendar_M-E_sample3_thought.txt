Novel Architectural Idea: "Cascaded Counter with Predictive Rollover"

Key Innovations:
1. Predictive rollover detection - calculates next state values before they're needed
2. Single-cycle update for all counters using parallel arithmetic
3. Hierarchical carry propagation for efficient rollover handling
4. Optimized bit-width usage with no redundant bits
5. Early termination of carry chains when possible
6. Unified state update in single always block for better synthesis

Implementation Approach:
- Use intermediate next-state variables for all counters
- Calculate seconds increment first, then propagate carries to minutes/hours
- Implement rollover as arithmetic overflow (>=60 for sec/min, >=24 for hours)
- Use ternary operators for compact rollover logic
- Maintain minimal bit widths (6b for sec/min, 5b for hours)
- Reset synchronously for better timing characteristics
