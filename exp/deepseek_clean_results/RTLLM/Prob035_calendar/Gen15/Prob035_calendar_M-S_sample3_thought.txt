To simplify the calendar module while maintaining functionality, I'll:
1. Remove unnecessary Gray code conversion since it adds complexity without clear benefit
2. Use a single always block for sequential logic to make the design more straightforward
3. Keep the basic counter functionality with proper rollover conditions
4. Maintain the same 6-bit width for all counters for consistency
5. Simplify the reset logic to be more direct

Key simplifications:
- Single always block for all sequential updates
- Direct binary counting without conversions
- Clear rollover conditions without enable signals
- Minimal logic for power and area efficiency
