To simplify the perpetual calendar module while maintaining functionality, I'll implement these optimizations:
1. Use a single always block for all counter updates to reduce redundant logic
2. Remove intermediate rollover wires and compute conditions directly
3. Maintain the same counter widths (6 bits for sec/min, 5 bits for hours)
4. Simplify the update logic by using nested if-else statements
5. Keep the same reset behavior (synchronous reset)

The simplified design will:
- Still correctly count time (0-23 hours, 0-59 minutes/seconds)
- Have fewer lines of code and less logic
- Maintain the same functionality with clearer sequential progression
- Be easier to understand and verify
