To simplify the implementation while maintaining functionality, we can:
1. Use separate counters for seconds, minutes, and hours instead of a unified counter
2. Implement each counter with its own clear and increment conditions
3. Use synchronous reset for cleaner timing
4. Remove unnecessary bit extensions since 0-59 fits in 6 bits and 0-23 fits in 5 bits
5. Make the rollover logic more straightforward by checking each counter's maximum value independently

This approach simplifies the control logic and makes the design more modular while maintaining the same functionality.
