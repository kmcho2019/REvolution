Refactoring Strategy:
1. Convert the sequential logic to combinational where possible using assign statements
2. Use a single always block for all counters to reduce area and improve timing
3. Implement the counters using a more compact state representation
4. Use terminal count signals to simplify the rollover logic
5. Maintain the same functionality while improving readability and potential PPA

Key Changes:
1. Combined all counters into one always block with nested conditions
2. Used localparam for magic numbers (59, 23) to improve maintainability
3. Simplified the rollover logic by using direct comparisons
4. Removed intermediate terminal count signals since they're only used once
5. Kept the same synchronous reset behavior
