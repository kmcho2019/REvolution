I'll implement the calendar using a hierarchical state machine approach with these key innovations:

1. Unified time representation: Instead of separate counters, use a single 17-bit counter (0-86399) representing total seconds in a day
2. Time decoding: Convert the unified counter to hours, minutes, seconds using division/modulo operations implemented as combinational logic
3. State encoding: Use a compact state representation with only necessary bits
4. Optimized rollover: Single comparison for day boundary (86400 seconds)
5. Pipelined conversion: Break the large division operations into stages for better timing

This approach reduces the number of flip-flops and simplifies the control logic while maintaining clear functionality. The unified counter eliminates the need for cascaded rollover conditions between hours/minutes/seconds.
