Refactoring Strategy:
1. Replace sequential always blocks with continuous assignments (assign) for combinational logic where possible
2. Use a single always block for all sequential elements to maintain synchronous behavior
3. Simplify rollover logic by using nested ternary operators
4. Optimize bit widths - use 6 bits for seconds/minutes (0-59) and 5 bits for hours (0-23)
5. Remove redundant intermediate signals (hours_next) and merge logic
6. Maintain same functionality while reducing logic levels

Key Improvements:
- Combinational logic moved to continuous assignments
- Single always block maintains synchronous behavior
- Simplified rollover conditions using nested ternary operators
- Removed redundant combinational block
- Cleaner code structure while maintaining same functionality
