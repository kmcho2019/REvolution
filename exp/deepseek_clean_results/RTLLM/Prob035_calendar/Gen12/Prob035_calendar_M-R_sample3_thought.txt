Refactoring Strategy:
1. Use continuous assignments (assign) for combinational logic to simplify the design
2. Separate the rollover detection into dedicated wires for clarity
3. Use a single always block for sequential elements to maintain synchronous behavior
4. Implement next-state logic purely with combinational assignments
5. Optimize bit widths by keeping internal counters at minimal required width
6. Use explicit reset values for all registers

Key Improvements:
- Clear separation of combinational and sequential logic
- Reduced complexity in the always block by moving logic to continuous assignments
- More straightforward rollover conditions
- Maintains same functionality while being more readable
- Better timing due to simplified critical path
