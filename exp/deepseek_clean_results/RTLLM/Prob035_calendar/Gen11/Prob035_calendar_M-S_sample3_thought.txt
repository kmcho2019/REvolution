To simplify the perpetual calendar module while maintaining functionality, I'll:
1. Use a single always block for all timekeeping
2. Eliminate intermediate rollover wires by using direct comparisons
3. Maintain the same counter sizes (6-bit for seconds/minutes, 5-bit for hours)
4. Keep the same reset behavior
5. Use sequential if-else structure for clear priority in updates
6. Remove unnecessary hierarchical conditions by checking rollovers in order

The simplified design will:
- Still correctly count time (0-59 seconds, 0-59 minutes, 0-23 hours)
- Handle reset the same way
- Have fewer lines of code while maintaining readability
- Avoid creating extra signals that aren't reused
