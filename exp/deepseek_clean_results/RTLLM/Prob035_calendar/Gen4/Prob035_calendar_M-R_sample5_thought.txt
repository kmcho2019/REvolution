Refactored design approach:
1. Separate combinational and sequential logic for better clarity and potential timing optimization
2. Use continuous assignments for rollover flags to simplify the always block
3. Implement counters using next-state logic with clear increment conditions
4. Maintain same functionality while making the code more modular
5. Use blocking assignments for combinational logic and non-blocking for sequential
6. Keep the same bit widths (5-bit hours, 6-bit mins/secs) for consistency
7. Explicitly show the next-state calculation before the register update
