Instead of using three separate always blocks, we'll implement a unified state machine approach that:
1. Uses a single always block for all timekeeping logic
2. Implements a next-state logic that calculates all time increments in parallel
3. Uses a shared terminal count signal to simplify rollover conditions
4. Reduces comparator usage by pre-calculating terminal conditions
This approach minimizes redundant logic and reduces the critical path by:
- Sharing comparison logic between time units
- Calculating next values in parallel rather than cascading
- Using a single clock domain for all operations
