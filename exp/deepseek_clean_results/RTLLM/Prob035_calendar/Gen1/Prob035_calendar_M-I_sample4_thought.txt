To optimize the perpetual calendar module for better PPA (Power, Performance, Area), I'll implement the following improvements:

1. Performance:
   - Combine the comparison logic for minutes and hours to reduce critical path
   - Use pre-computed flags for rollover conditions to simplify timing paths

2. Power:
   - Implement clock gating for hours counter (updates only once per hour)
   - Reduce unnecessary switching by using Gray code for seconds counter

3. Area:
   - Right-size the hours counter to 5 bits (0-23)
   - Share common comparison logic between counters
   - Consolidate reset logic

- Use Gray code for seconds to minimize switching power
- Generate rollover flags in a separate always block
- Implement proper clock gating for hours updates
