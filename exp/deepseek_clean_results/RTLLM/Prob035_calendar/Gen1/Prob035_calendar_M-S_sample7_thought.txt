To simplify the perpetual calendar design while maintaining functionality, we can:
1. Use a single always block to handle all counters (seconds, minutes, hours) for better synchronization and reduced logic complexity
2. Implement sequential counting with clear priority: seconds increment first, then minutes when seconds roll over, then hours when both minutes and seconds roll over
3. Maintain the same reset behavior but consolidate the logic
4. Keep the same output bit widths (6-bit) for each counter
This approach reduces the number of always blocks and makes the rollover conditions more straightforward while maintaining identical functionality.
