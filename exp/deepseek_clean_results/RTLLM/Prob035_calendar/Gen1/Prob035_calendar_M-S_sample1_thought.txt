To simplify the perpetual calendar module while maintaining functionality, we can:
1. Use a single always block to handle all time increments, reducing state machine complexity
2. Implement a sequential update approach where seconds increment first, then minutes if seconds roll over, then hours if minutes roll over
3. Maintain the same reset behavior and rollover conditions
4. Use blocking assignments within the always block to ensure proper sequential updates
This approach reduces area by eliminating redundant comparators and simplifies control logic while maintaining the same timing characteristics.
