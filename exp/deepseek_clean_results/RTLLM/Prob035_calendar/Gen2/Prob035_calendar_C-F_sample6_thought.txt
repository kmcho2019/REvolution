Fusion Strategy:
1. Combine the area efficiency of the unified counter approach (Example 1) with the timing benefits of separate control logic (Example 2)
2. Use a single always block for sequential logic to minimize registers, but implement cleaner rollover conditions
3. Optimize bit widths - use 6 bits for seconds/minutes (0-59) and 5 bits for hours (0-23)
4. Implement explicit enable signals for each counter stage to reduce power consumption
5. Simplify comparison logic by using intermediate rollover flags

Key Improvements:
- Single always block reduces flip-flop count
- Proper bit-width optimization saves area
- Enable signals minimize switching activity
- Clean rollover logic improves timing
