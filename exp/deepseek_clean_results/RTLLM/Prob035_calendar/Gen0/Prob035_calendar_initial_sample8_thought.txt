The perpetual calendar module needs to track time in hours, minutes, and seconds. The design uses three counters (for seconds, minutes, and hours) that increment synchronously with the clock. Each counter rolls over at its maximum value (59 for seconds and minutes, 23 for hours) and triggers the next higher counter when appropriate. The reset signal initializes all counters to zero. The implementation uses three always blocks to handle each counter separately, with conditions to check when to increment or reset each counter based on the current state of the other counters.
