The perpetual calendar module needs to track time in hours, minutes, and seconds with proper rollover behavior. We'll use three separate always blocks to handle each time component (seconds, minutes, hours) with the following logic:
1. Seconds increment on every clock cycle, rolling over to 0 after 59
2. Minutes increment when seconds reach 59, rolling over to 0 after 59
3. Hours increment when both minutes and seconds reach 59, rolling over to 0 after 23
All counters reset to 0 when RST is active. Each counter is 6 bits wide to accommodate values up to 59 (for seconds/minutes) and 23 (for hours).
