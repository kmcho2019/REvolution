Novel Architecture: Cascaded Enable Counter with State Encoding
1. Use a single always block with hierarchical enable signals to minimize clock domain crossings
2. Implement a state encoding scheme where each counter only increments when its predecessor rolls over
3. Use parameterized rollover constants for flexibility
4. Optimize power by only evaluating rollover conditions when needed
5. Implement a clean reset strategy with synchronous reset for better timing

Key Innovations:
- Hierarchical enable signals reduce redundant comparisons
- Single always block improves timing closure
- State encoding minimizes combinational logic
- Parameterized design allows easy modification of time formats
- Power-optimized by gating rollover evaluations
