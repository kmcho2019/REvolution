Instead of using nested conditionals, I'll implement a finite state machine that:
1. Uses a unified counter approach with state encoding for time units
2. Pre-computes all next-state values in parallel
3. Uses a single comparison operation per counter
4. Implements carry propagation through state transitions
5. Optimizes power by only updating relevant counters

Key innovations:
- Parallel condition evaluation reduces critical path
- State encoding allows for simpler rollover logic
- Single always block maintains synchronous behavior
- Power gating concept for counter updates
- Clean separation of reset and counting logic
