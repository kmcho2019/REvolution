Refactoring Strategy:
1. Use continuous assignments for combinational logic to simplify the design
2. Implement next-state logic explicitly using wires and combinational assignments
3. Maintain sequential elements only for state storage (registers)
4. Separate combinational and sequential logic clearly
5. Optimize bit widths - use 5 bits for hours (0-23) since 6 bits are unnecessary
6. Generate rollover signals directly in the combinational logic
7. Use ternary operators for compact next-state expressions

Key Improvements:
- Clear separation between combinational and sequential logic
- Reduced register usage by calculating next states combinatorially
- More efficient hour counter implementation (5 bits vs 6)
- Simplified rollover condition logic
- Better timing potential due to parallel combinational logic
