Instead of using three separate counters, I'll implement a single unified counter that tracks total elapsed seconds (0-86399 for a full day). This approach:
1. Uses a single 17-bit counter (since 24*60*60 = 86400 requires 17 bits)
2. Eliminates cascaded rollover logic between counters
3. Reduces power by minimizing switching activity (only one counter toggles)
4. Simplifies timing paths by removing inter-counter dependencies
5. Uses division/modulo operations to decode hours, minutes, seconds
6. Implements division via lookup tables for better performance

Key features:
- Single always block for all state updates
- Pre-computed division constants for efficient decoding
- Reset initializes counter to 0
- Automatic rollover at 86400 seconds
- Output registers for stable decoded values
