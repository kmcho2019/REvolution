Novel Architecture: Parallel Counter with State-Based Rollover Control
1. Instead of cascaded counters, use parallel counting with state-based enable signals
2. Implement a 4-state FSM to control counting modes (normal, sec_roll, min_roll, hour_roll)
3. Use gray coding for state transitions to minimize switching power
4. Optimize comparisons by using pre-computed terminal count values
5. Implement output registers with clock gating to reduce dynamic power
6. Use parameterized widths for flexibility in different applications

Key Advantages:
- Parallel operation reduces critical path compared to cascaded counters
- State machine provides clean separation of control logic
- Gray coding reduces state transition power
- Clock gating on output registers saves power
- Parameterization allows easy scaling
