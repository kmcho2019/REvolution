Refactoring Strategy:
1. Use continuous assignments (assign) for combinational logic to reduce sequential elements
2. Implement rollover conditions as combinational expressions
3. Create next-state logic for each counter separately
4. Use a single always block for sequential updates to maintain synchronization
5. Simplify hour counter by treating it as a full 6-bit counter (0-23 fits in 6 bits)
6. Make reset logic more explicit by separating it from counter logic

Key Improvements:
- Combinational rollover logic reduces clock-to-q delays
- Clear separation between next-state calculation and state update
- Simplified hour counter without bit manipulation
- More modular structure while maintaining single clock domain
- Reduced power consumption by minimizing unnecessary toggles
