Refactoring Strategy:
1. Use continuous assignments (assign) for combinational logic to improve readability
2. Separate the counter logic into next-state calculation and sequential update
3. Use explicit next-state registers to make the design more modular
4. Maintain the same rollover conditions but express them more clearly
5. Keep the same bit-width optimizations (6-bit for sec/min, 5-bit for hours)
6. Use a single always block for sequential updates to maintain area efficiency

Key Improvements:
- Clear separation between combinational and sequential logic
- Explicit next-state calculation makes the design more maintainable
- Rollover conditions are calculated in combinational logic
- Single clocked always block maintains area efficiency
- Output assignments remain unchanged
