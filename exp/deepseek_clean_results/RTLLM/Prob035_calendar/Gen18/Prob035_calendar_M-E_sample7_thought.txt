Instead of using three separate counters, we can implement a single 18-bit counter that increments every clock cycle. The seconds, minutes, and hours values are then derived from this counter through decoding logic. This approach:

1. Eliminates the ripple effect between counters (better timing)
2. Reduces the number of registers needed
3. Simplifies reset logic
4. Makes rollover conditions purely combinational
5. Enables easier clock gating for power savings

Key features:
- Single 18-bit counter (enough for 24*60*60 = 86400 counts)
- Combinational decoding of time values
- Simple reset handling
- Built-in synchronization of all time components
- Efficient power management through single counter
