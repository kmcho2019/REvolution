Novel Architectural Idea:
1. Time Encoding: Represent the entire time state (hours, minutes, seconds) as a single encoded value in seconds since midnight (0-86399)
2. Unified Counter: Use a single 17-bit counter (enough for 24*60*60=86400 values) instead of separate registers
3. Decoding Logic: Convert the counter value back to hours, minutes, seconds format
4. Edge Detection: Use arithmetic comparison for rollover conditions rather than cascaded logic
5. Power Optimization: Implement clock gating when counter isn't changing (during reset)

Key Advantages:
1. Eliminates the combinational logic chain of traditional designs
2. Single counter reduces register count and simplifies timing
3. Arithmetic rollover detection is more efficient than cascaded comparators
4. Easier to extend for additional features (like day counting)
5. More power efficient as only one counter updates per cycle
