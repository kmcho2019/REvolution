Novel Architectural Approach:
1. Sign-Magnitude Conversion: Convert inputs to sign-magnitude format upfront to simplify arithmetic operations
2. Parallel Processing: Perform both possible operations (addition and subtraction) simultaneously for faster computation
3. Early Sign Determination: Compute the result sign independently before magnitude calculation
4. Optimized Magnitude Path: Use a single subtractor with swapped inputs instead of two separate subtractors
5. Efficient Overflow Handling: Implement overflow detection using carry-out bits rather than full magnitude comparison

Key Innovations:
- Eliminates sequential dependencies in the arithmetic path
- Reduces critical path by parallelizing operations
- Minimizes hardware resources through shared subtractor
- Simplifies sign handling with early determination
- Maintains full precision while being more efficient
