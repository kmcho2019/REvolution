Simplified fixed-point adder design:
1. Remove signed arithmetic complexity - use simple unsigned addition
2. Let the fixed-point format naturally handle the arithmetic
3. No need for explicit sign handling since Verilog addition works correctly for 2's complement
4. Eliminate parameter Q since it's not used in actual computation
5. Keep only essential N parameter for bit-width
6. Direct assignment of sum to output with no intermediate registers
7. Overflow detection removed for simplicity (can be added later if needed)
8. Core functionality remains identical for correct inputs
9. Reduced area and improved timing by removing signed operations
10. Maintain same interface for compatibility
