Novel architectural approach:
1. Dual-path processing: Separate positive and negative value handling into parallel paths
2. Early sign detection: Determine operation type (add/sub) before magnitude calculation
3. Sign-magnitude representation: Convert to sign-magnitude format initially for simpler arithmetic
4. Dynamic operation selection: Use multiplexers to choose between add/sub results
5. Optimized overflow handling: Detect overflow before final conversion to 2's complement
6. Resource sharing: Reuse arithmetic units between paths where possible

Key innovations:
- Parallel processing reduces critical path delay
- Early operation selection simplifies control logic
- Sign-magnitude intermediate representation makes arithmetic cleaner
- Shared resources reduce area overhead
- Optimized overflow detection prevents unnecessary conversions
