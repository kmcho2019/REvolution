Novel architectural approach: Instead of separating magnitude and sign processing, we'll use two's complement arithmetic directly while carefully managing overflow. The key innovations are:
1. Use full two's complement arithmetic without sign/magnitude separation
2. Implement overflow detection by comparing carry-in and carry-out of the MSB
3. Use parameterized bit-widths for both integer and fractional parts
4. Handle all cases (same sign, different signs, overflow) in a unified arithmetic path
5. Include optional saturation logic for overflow cases

This approach is more hardware-efficient as it:
- Eliminates separate magnitude comparison logic
- Uses native adder/subtractor properties
- Reduces control logic complexity
- Maintains fixed-point precision through proper bit alignment
