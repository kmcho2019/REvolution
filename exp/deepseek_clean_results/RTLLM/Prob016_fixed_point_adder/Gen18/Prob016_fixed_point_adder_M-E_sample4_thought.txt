Novel architectural approach using sign-magnitude representation and conditional carry handling:
1. Convert inputs to sign-magnitude format for easier magnitude comparison
2. Implement a single shared adder/subtractor unit to reduce hardware resources
3. Use a priority encoder to determine the larger magnitude when signs differ
4. Implement conditional carry handling for overflow prevention
5. Use a unified result formation block that handles all cases (same sign, different sign)
6. Optimize for PPA by minimizing redundant arithmetic units and using efficient multiplexing
7. Include explicit overflow detection that saturates results when needed

Key innovations:
- Single shared arithmetic unit for both addition and subtraction
- Early sign comparison to optimize path selection
- Priority-based magnitude comparison
- Unified result formation logic
- Built-in overflow saturation
- More efficient resource utilization than parallel arithmetic approaches
