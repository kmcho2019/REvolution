Novel architectural approach:
1. Use a unified arithmetic unit that performs both addition and subtraction in one operation by leveraging two's complement properties
2. Implement a sign-magnitude converter to handle all operations in magnitude space
3. Use a priority encoder for efficient magnitude comparison
4. Implement overflow detection through carry-out analysis rather than sign comparison
5. Optimize for PPA by:
   - Reducing arithmetic operations to a single path
   - Minimizing comparison logic
   - Using bitwise operations for sign handling
6. Include parameter validation using generate blocks
7. Implement saturation logic using multiplexers rather than conditional assignments

Key innovations:
- Unified arithmetic path reduces area
- Priority encoder enables faster magnitude comparison
- Carry-based overflow detection simplifies timing
- Sign-magnitude conversion enables simpler saturation logic
- Generate-based parameter validation ensures synthesizable checks
