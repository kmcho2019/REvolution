Refactored design approach:
1. Convert the always block to continuous assignments for combinational logic
2. Break down operations into smaller, more modular expressions
3. Use ternary operators for conditional logic
4. Maintain the same sign-aware addition/subtraction logic
5. Keep overflow handling with saturation
6. Use wire declarations for intermediate values instead of regs
7. Simplify the sign determination logic for subtraction case

Key improvements:
- More concise implementation using assign statements
- Clearer separation of arithmetic and sign logic
- Reduced register usage by using wires for intermediate values
- Maintains same functionality while being more synthesis-friendly
