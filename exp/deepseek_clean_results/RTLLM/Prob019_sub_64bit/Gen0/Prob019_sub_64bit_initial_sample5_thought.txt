To implement a 64-bit subtractor with overflow checking, we need to:
1. Perform the subtraction operation (A - B) using Verilog's arithmetic operators
2. Detect overflow by checking the sign bits of A, B, and the result:
   - Positive overflow: A is positive (MSB=0), B is negative (MSB=1), result is negative (MSB=1)
   - Negative overflow: A is negative (MSB=1), B is positive (MSB=0), result is positive (MSB=0)
3. The overflow flag should be set when either condition is true
4. Use signed arithmetic to ensure proper interpretation of negative numbers
