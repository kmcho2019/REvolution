Simplified fractional divider with 3.5x division:

1. Core Concept:
   - Use single 7-cycle counter (0-6)
   - Generate two clock phases:
     * clk_div1: High for first 4 cycles (0-3)
     * clk_div2: High for next 3 cycles (4-6)
   - Phase-shift clk_div2 by half cycle using negedge
   - Combine phases with OR for proper alignment

2. Key Simplifications:
   - Single counter for both phases
   - Direct OR combination instead of XOR
   - Clear boundary conditions
   - Reduced register usage
   - Maintains correct 3.5x division ratio

3. Implementation Details:
   - Counter increments on posedge
   - First phase generated on posedge
   - Second phase generated on negedge
   - OR operation combines phases
   - Reset initializes all signals
