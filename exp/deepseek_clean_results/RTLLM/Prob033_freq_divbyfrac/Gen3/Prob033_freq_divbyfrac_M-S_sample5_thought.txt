Simplified approach for 3.5x frequency division:
1. **Basic Concept**: Achieve 3.5x division by alternating between 3 and 4 clock cycles
2. **Single Counter**: Use a 3-bit counter to cycle through 7 states (0-6)
3. **Phase Generation**: 
   - Main phase (phase_a) toggles every 2 cycles (4-clock period)
   - Secondary phase (phase_b) toggles every 1.5 cycles (3-clock period) using negedge
4. **Output Combination**: OR both phases to create final output
5. **Reset Handling**: Initialize both phases to 0 for clean startup
6. **Simplification**: Remove unnecessary state machine and synchronization registers, relying on direct phase generation
