Refactored approach using explicit state machine and edge detection:
1. Replace counter with explicit state machine tracking 7 distinct states (0-6)
2. Generate two phase clocks using combinational logic based on state:
   - clk_phase0: High for states 0-3 (4 cycles) then 0-2 (3 cycles)
   - clk_phase180: Same pattern but offset by 180 degrees
3. Use continuous assignments for all clock generation
4. Implement state transitions synchronously
5. Reset initializes state and clocks cleanly
Key improvements:
- Clear state machine makes timing explicit
- Combinational clock generation avoids timing issues
- Symmetrical phase generation
- Simplified reset handling
- More predictable output timing
