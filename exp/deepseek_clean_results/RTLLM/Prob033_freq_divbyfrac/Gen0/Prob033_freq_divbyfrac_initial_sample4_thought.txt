To implement a fractional frequency divider (3.5x), we need to:
1. Create a counter that cycles through 7 clock periods (since 3.5x requires 2 cycles of division over 7 input clocks)
2. Generate two intermediate clocks with different duty cycles (4 and 3 input clock cycles)
3. Phase shift these intermediate clocks by half a period
4. Combine them using OR logic to create a uniform output clock
5. Use double-edge clocking (both rising and falling edges) to achieve the half-cycle precision
