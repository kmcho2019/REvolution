To implement a fractional frequency divider (3.5x), we'll use a counter-based approach with phase manipulation. The key steps are:
1. Use a 3-bit counter to count 7 clock cycles (since 3.5x = 7/2)
2. Generate two intermediate clocks:
   - clk_div1: Toggles every 4 cycles (first phase)
   - clk_div2: Toggles every 3 cycles (second phase, 180° shifted)
3. Combine these clocks using OR operation to create the final output
4. Reset logic ensures proper initialization
The result is a clock with 3.5x frequency division and balanced duty cycle.
