To implement a 3.5x fractional frequency divider, we need to:
1. Create a counter that cycles through 7 clock periods (since 3.5 = 7/2)
2. Generate two intermediate clocks with different duty cycles (4 and 3 clock periods)
3. Phase shift one intermediate clock by half a period
4. Combine them using OR operation to get the final output
5. Use double-edge clocking to handle the half-period shifts
