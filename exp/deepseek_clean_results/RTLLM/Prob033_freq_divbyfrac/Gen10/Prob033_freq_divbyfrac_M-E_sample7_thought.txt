Novel Dual-Counter Phase Blending Architecture:

1. **Core Concept**:
   - Use two independent counters (4-cycle and 3-cycle) running in parallel
   - Alternate between counters to achieve 3.5x average division
   - Blend phases using edge detection for smooth transitions

2. **Precision Timing**:
   - Primary counter handles 4-clock periods
   - Secondary counter handles 3-clock periods
   - State machine coordinates alternation between counters

3. **Phase Blending**:
   - Detect transitions in both counters
   - Generate intermediate edges at mid-points
   - Combine edges using XOR for precise fractional timing

4. **Advantages**:
   - Explicit control of both integer periods
   - Clean separation of timing domains
   - No accumulated phase error
   - Simple to extend to other fractional divisions
