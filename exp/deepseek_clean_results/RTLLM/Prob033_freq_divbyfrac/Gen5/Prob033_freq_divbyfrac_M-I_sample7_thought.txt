To correctly implement a 3.5x fractional frequency divider:
1. Use a single-edge counter that counts 7 clock cycles (3.5x division requires 2 output cycles per 7 input cycles)
2. Generate two phase-shifted clocks:
   - Phase A: high for 4 cycles, low for 3 cycles
   - Phase B: same pattern but shifted by 3.5 cycles (180°)
3. Combine these phases using OR logic to create the final output
4. Reset initializes the counter and both phases to 0
5. This approach ensures proper timing alignment and correct duty cycle
6. The counter increments only on positive edges for predictable timing
7. Phase B is generated by comparing against a shifted counter value
