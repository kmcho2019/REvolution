Refactored fractional divider with simplified logic:

1. Core Changes:
   - Replace sequential counters with combinational logic for phase generation
   - Use direct clock edge assignments instead of synchronized registers
   - Implement phase shifting through immediate assignments on both edges
   - Simplify counter logic using modulus arithmetic

2. Key Improvements:
   - Eliminate intermediate synchronization registers
   - Generate phases directly from counter values
   - Maintain same division ratio (3.5x) with cleaner implementation
   - Reduce latency in phase generation

3. Implementation Strategy:
   - Single counter running on positive edge
   - Generate phase A directly from counter
   - Create phase B by sampling counter on negative edge
   - Combine phases with continuous assignment
   - Reset initializes counter to known state

4. Advantages:
   - Fewer sequential elements
   - Reduced propagation delay
   - More predictable timing
   - Clearer relationship between counter and output phases
