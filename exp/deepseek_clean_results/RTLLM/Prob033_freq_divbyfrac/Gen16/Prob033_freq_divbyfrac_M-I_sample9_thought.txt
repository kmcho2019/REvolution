Improved design strategy for 3.5x fractional divider:

1. Maintain the 7-cycle base pattern (0-6) for correct division ratio
2. Implement proper phase shifting:
   - Phase A: 4 cycles high, 3 cycles low (counter < 4)
   - Phase B: 3 cycles high, 4 cycles low (counter >= 3)
3. Generate phase-shifted versions:
   - Original phase A on posedge
   - Phase B delayed by half cycle (using negedge)
4. Combine phases with XOR instead of OR for better duty cycle
5. Key improvements:
   - Correct 4/3 and 3/4 cycle patterns for phases
   - Proper half-cycle phase shift
   - XOR combination ensures uniform pulse width
   - Better matches 3.5x division requirement
6. Benefits:
   - Precise frequency division (3.5x)
   - 50% duty cycle output
   - Minimal hardware overhead
   - Robust reset behavior
