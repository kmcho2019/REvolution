Novel Fractional Divider Architecture:

1. **Dual-Counter Approach**:
   - Use two separate counters for precise phase control
   - Main counter (0-6) tracks overall division cycle
   - Sub-counter (0-1) manages half-cycle timing

2. **Phase-Interleaved Generation**:
   - Generate four distinct clock phases (0°, 90°, 180°, 270°)
   - Each phase contributes to specific portions of the output cycle
   - Enables smoother fractional division transitions

3. **Dynamic Pulse Width Control**:
   - Adjust pulse widths based on current division phase
   - 4-clock phase: wider pulse (2 source clocks)
   - 3-clock phase: narrower pulse (1.5 source clocks)

4. **Symmetric Phase Combination**:
   - Combine phases using XOR instead of OR
   - Better maintains duty cycle symmetry
   - Reduces output jitter

Key Innovations:
- More precise phase control with sub-counter
- Four-phase interleaving for smoother transitions
- Dynamic pulse width adjustment
- XOR combination for better symmetry
