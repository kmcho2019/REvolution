Instead of using phase-shifted versions of intermediate clocks, this solution employs:
1. Two separate counters running in parallel - one for the integer part (3x) and one for the fractional part (0.5x)
2. The integer counter creates a base 3x divided clock
3. The fractional counter adds half-cycle pulses at precise intervals to achieve the 0.5x component
4. A pulse generator creates narrow pulses at the fractional boundaries
5. The final output combines the base clock and fractional pulses using XOR logic
6. This creates a smooth 3.5x division with good duty cycle characteristics
