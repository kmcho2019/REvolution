Novel Rotating Phase Accumulator Architecture:

1. **Phase Accumulation Principle**:
   - Use a 4-bit accumulator that adds 2 (for 3.5x division) each cycle
   - Accumulator overflow creates the base divided clock edges
   - This naturally creates the 4:3 cycle alternation pattern

2. **Edge Interpolation**:
   - Detect when accumulator crosses mid-point (8)
   - Generate interpolated edges at these mid-points
   - This creates the half-cycle phase shifts needed

3. **Dynamic Duty Cycle Control**:
   - Main clock high when accumulator < 8
   - Interpolated clock high when (accumulator - 8) < 8
   - OR combination produces correct duty cycle

4. **Advantages**:
   - No separate phase counters needed
   - Self-correcting phase relationship
   - Naturally handles fractional division
   - Simple implementation with minimal logic
