Simplified fractional divider with 3.5x division:

1. Core Concept:
   - Use a single 3-bit counter to track 7 clock cycles (4+3 pattern)
   - Generate two clock phases with proper timing relationship
   - Combine phases with OR gate for final output

2. Simplifications:
   - Eliminate separate case statement for phase-shifted clock
   - Use simple comparison for both clock phases
   - Maintain same counter for both phases
   - Reduce logic complexity while preserving timing

3. Key Features:
   - clk_div1: Active for first 4 cycles (counter < 4)
   - clk_div2: Active for middle 4 cycles (counter > 0 && counter < 5)
   - OR combination creates proper 3.5x division
   - Reset initializes all signals synchronously
