Simplified Fractional Clock Divider (3.5x):

1. **Single Counter Approach**:
   - Use a 3-bit counter (0-6) to track 7 input clock cycles (3.5x division requires 2 output cycles per 7 input cycles)
   - Generate two complementary clock phases with different pulse widths (4 and 3 cycles)

2. **Dual-Edge Triggering**:
   - Create first phase (clk_a) with 4-cycle high and 3-cycle low
   - Create second phase (clk_b) with 3-cycle high and 4-cycle low, offset by half period

3. **Output Combination**:
   - OR the two phases together to create uniform 3.5x divided clock
   - This automatically handles duty cycle correction through phase overlap

4. **Simplified Control**:
   - Eliminate separate cycle selector logic
   - Directly generate output from counter states
   - Use only posedge clocking for all flip-flops
