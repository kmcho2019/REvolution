Novel fractional divider architecture using dual counters and dynamic period adjustment:

1. Core Innovation:
   - Use two independent counters (even and odd cycles)
   - Implement dynamic period switching (3/4 cycles)
   - Generate quadrature-phase clocks for smooth transitions
   - Combine phases with XOR instead of OR for better edge control

2. Key Features:
   - Alternates between 3 and 4-cycle periods naturally
   - Uses both clock edges for precise phase control
   - Quadrature clocks ensure 50% duty cycle in combined output
   - Eliminates glitches through proper phase alignment

3. Operation Principle:
   - Main counter tracks full 7-cycle period
   - Secondary counter creates 90° phase shift
   - XOR combination produces clean fractional division
   - Dynamic switching handles the 3.5x ratio precisely
