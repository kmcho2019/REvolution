This implementation uses a Moore state machine with 3 states:
1. IDLE: No edge detected
2. RISING: Rising edge detected (outputs rise=1)
3. FALLING: Falling edge detected (outputs down=1)

The state transitions are:
- IDLE -> RISING when a transitions from 0 to 1
- IDLE -> FALLING when a transitions from 1 to 0
- RISING/FALLING -> IDLE on next clock cycle

Advantages:
1. Explicit state representation makes the design more readable and maintainable
2. Easily extensible for more complex edge detection patterns
3. Clear separation of edge detection logic from output generation
4. Can add more states for special cases (like glitch filtering)
