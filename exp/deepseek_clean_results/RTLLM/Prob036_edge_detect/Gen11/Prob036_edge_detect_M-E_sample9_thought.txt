Novel state machine approach:
1. Implement a 4-state FSM that tracks the input signal transitions
2. States represent previous and current values of 'a'
3. State transitions occur on clock edges
4. Outputs are generated based on state transitions
5. Benefits:
   - More explicit state tracking
   - Easier to extend for more complex edge patterns
   - Clear separation of states and outputs
   - Potentially better timing with registered outputs
