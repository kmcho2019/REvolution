To detect edges in a signal, we need to compare the current value of the signal with its previous value. We can store the previous value in a flip-flop (register). On each clock edge:
1. For rising edge detection: if previous value was 0 and current is 1, set rise to 1
2. For falling edge detection: if previous value was 1 and current is 0, set down to 1
3. Otherwise, both outputs should be 0
The outputs should be synchronous with the clock and reset properly.
