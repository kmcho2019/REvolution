To detect edges in a signal, we need to compare the current value of the signal with its previous value. We'll use a flip-flop to store the previous value of 'a'. On each clock edge:
1. If previous 'a' was 0 and current 'a' is 1, we have a rising edge (set rise=1)
2. If previous 'a' was 1 and current 'a' is 0, we have a falling edge (set down=1)
3. Otherwise, both outputs should be 0
The outputs should be synchronous with the clock and reset properly.
