To detect edges in a signal, we need to compare the current value of the signal with its previous value. For rising edge detection, we look for a transition from 0 to 1 (current a is 1 and previous a was 0). For falling edge detection, we look for a transition from 1 to 0 (current a is 0 and previous a was 1). 

The implementation involves:
1. Creating a flip-flop to store the previous value of 'a'
2. Comparing current 'a' with the stored previous value to detect edges
3. Generating synchronous outputs 'rise' and 'down' that pulse for one clock cycle when edges are detected
4. Properly handling reset conditions
