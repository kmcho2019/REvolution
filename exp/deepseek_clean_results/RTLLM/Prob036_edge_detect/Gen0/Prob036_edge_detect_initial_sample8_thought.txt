To detect edges in a signal, we need to compare the current value of the signal with its previous value. We can store the previous value in a flip-flop (register). On each clock edge:
1. If the current value is 1 and previous was 0, we have a rising edge (set rise to 1)
2. If the current value is 0 and previous was 1, we have a falling edge (set down to 1)
3. Otherwise, both outputs should be 0
The outputs should be synchronous to the clock and reset to 0 after one clock cycle.
