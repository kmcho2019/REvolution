Instead of the traditional approach of comparing current and previous values, we can implement a state machine that tracks the input signal transitions. This approach:
1. Uses 3 states: IDLE (no edge), RISING (detected rising edge), FALLING (detected falling edge)
2. Transitions between states based on input signal changes
3. Outputs are asserted when entering the corresponding state
4. Automatically returns to IDLE state after detection
5. More robust against glitches as it requires a full clock cycle for state transitions
6. Easily extensible for more complex edge detection scenarios
