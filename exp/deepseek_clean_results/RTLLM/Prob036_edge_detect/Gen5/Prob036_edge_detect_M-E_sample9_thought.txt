Novel State Machine Approach:
1. Use a 2-bit state machine to track the input signal's behavior
2. States represent: 
   - 00: Stable low
   - 01: Rising edge detected (transient state)
   - 10: Falling edge detected (transient state)
   - 11: Stable high
3. Benefits:
   - Explicit state tracking makes the design more maintainable
   - Easier to add new features (like edge filtering)
   - Clear separation of edge detection states
   - Potential for adding hysteresis or debouncing
4. Outputs are purely combinational based on current state
5. Reset initializes to stable low state
