This solution implements a Moore finite state machine (FSM) for edge detection. The FSM has three states:
1. IDLE: No edge detected
2. RISING: Rising edge detected
3. FALLING: Falling edge detected

The advantages of this approach:
1. More extensible - can easily add more states for edge filtering or debouncing
2. Clear state transitions make the design more maintainable
3. Can be expanded to detect glitches or minimum pulse widths
4. State encoding can be optimized for power or area
5. Provides explicit state information that could be useful for debugging

The FSM transitions:
- IDLE -> RISING when a=1 and previous a=0
- IDLE -> FALLING when a=0 and previous a=1
- RISING/FALLING -> IDLE on next clock
