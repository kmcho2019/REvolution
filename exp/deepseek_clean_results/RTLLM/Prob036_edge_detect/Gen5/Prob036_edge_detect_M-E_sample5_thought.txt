State Machine Based Edge Detection:
1. Instead of simple combinatorial comparison, implement a 3-state FSM:
   - IDLE: No edge detected
   - RISING: Rising edge detected
   - FALLING: Falling edge detected
2. State transitions occur on clock edges based on input 'a' and current state
3. Outputs are registered and pulse for exactly one clock cycle
4. Advantages:
   - More robust against glitches
   - Explicit state representation makes timing easier to analyze
   - Easier to extend with additional features (like edge filtering)
5. Reset puts FSM in IDLE state
