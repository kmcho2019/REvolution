Instead of using the traditional approach of comparing current and previous values, we can implement a Moore state machine that tracks the input signal's transitions. The state machine will have three states:
1. IDLE: Initial state, no edges detected
2. RISING: Detected a rising edge
3. FALLING: Detected a falling edge

The state transitions are:
- IDLE → RISING when a changes from 0 to 1
- IDLE → FALLING when a changes from 1 to 0
- RISING → IDLE on next clock
- FALLING → IDLE on next clock

This approach is more robust against glitches and provides better control over the output pulse duration.
