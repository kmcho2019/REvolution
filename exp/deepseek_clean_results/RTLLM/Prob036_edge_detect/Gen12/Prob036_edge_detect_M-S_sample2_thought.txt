To simplify the edge detector while maintaining functionality:
1. Remove the intermediate wire and register separation
2. Use a single always block to store previous value and generate outputs
3. Make outputs directly registered to ensure clean single-cycle pulses
4. Eliminate separate combinational logic by detecting edges within the clocked block
5. Maintain same reset behavior and edge detection functionality

This approach reduces the component count while keeping the same behavior - outputs will pulse for exactly one clock cycle on each edge detection.
