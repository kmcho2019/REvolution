Instead of using the conventional delayed signal comparison method, we can implement a Moore state machine that explicitly tracks the input signal's transitions. This approach offers several advantages:

1. More explicit state representation makes the design intent clearer
2. Easier to extend for more complex edge detection patterns
3. Naturally handles metastability through registered outputs
4. Provides better visibility into the detection process

The state machine has 3 states:
- IDLE: Initial state, no edge detected
- RISE_DETECTED: Rising edge was detected
- FALL_DETECTED: Falling edge was detected

Transitions occur based on the current state and input value. Outputs are purely dependent on the current state.
