Novel approach using state machine:
1. Instead of simple edge detection, implement a 2-state FSM (IDLE, EDGE_DETECTED)
2. State transitions occur when an edge is detected
3. Outputs are asserted only in the cycle following edge detection
4. This provides better control over output timing and avoids glitches
5. The FSM naturally handles the single-cycle pulse requirement
6. Reset puts the FSM in IDLE state
