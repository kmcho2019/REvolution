Instead of using simple combinational logic, we can implement a state machine that explicitly tracks the input transitions. This provides:
1. More explicit control over edge detection behavior
2. Potential for easier modification of edge detection criteria
3. Clear state transitions that are easier to verify
4. Ability to add more complex edge detection patterns if needed in the future

The state machine will have three states:
- IDLE: No edge detected
- RISE_DETECTED: Rising edge occurred
- FALL_DETECTED: Falling edge occurred

Transitions between states are based on the current input value and its previous value.
