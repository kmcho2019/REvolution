Novel Architectural Idea: State Machine-Based Edge Detection
1. Instead of using simple delay comparison, implement a Moore state machine with 3 states:
   - IDLE: No edge detected
   - RISING: Rising edge detected (output rise=1)
   - FALLING: Falling edge detected (output down=1)
2. The state machine transitions based on current state and input signal changes
3. Outputs are purely dependent on current state (Moore machine characteristic)
4. Advantages:
   - More explicit state representation
   - Easier to extend with additional edge conditions
   - Clear separation of edge detection logic
   - Potential for adding more complex edge patterns in future
5. Reset puts the machine in IDLE state
6. State transitions happen on clock edges
