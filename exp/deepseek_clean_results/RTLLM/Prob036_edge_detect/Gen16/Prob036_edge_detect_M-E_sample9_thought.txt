Novel Architecture Idea: Double-Sampling Edge Detection with Metastability Protection

Key Concepts:
1. Double sampling the input signal to prevent metastability issues
2. Using a state machine approach for edge detection
3. Implementing a clean output pulse generation mechanism
4. Adding synchronous reset for reliable initialization

Advantages:
- More robust against metastability than simple edge detectors
- Clear state-based approach makes timing analysis easier
- Output pulses are guaranteed to be exactly one clock cycle wide
- Reset behavior is well-defined and synchronous

Implementation Approach:
1. Use two flip-flops in series for input synchronization (a_sync)
2. Implement a 3-state FSM (IDLE, RISING, FALLING)
3. Generate clean one-cycle pulses for rise/down outputs
4. All transitions happen on clock edges with proper synchronization
