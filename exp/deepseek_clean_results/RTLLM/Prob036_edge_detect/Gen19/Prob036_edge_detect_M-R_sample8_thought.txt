Refactoring Strategy:
1. Maintain the same edge detection logic but implement it using continuous assignments only
2. Eliminate the always block by using a wire with delayed assignment for a_prev
3. Use a simple delay line (two inverters) to create the previous value of 'a'
4. This approach reduces sequential elements while maintaining the same functionality
5. The design becomes purely combinational except for the implicit delay in the inverter chain

Benefits:
- Removes explicit flip-flop, reducing area
- Makes timing more predictable as it relies on gate delays
- Simplifies the design to pure combinational logic
- Maintains the same edge detection behavior
