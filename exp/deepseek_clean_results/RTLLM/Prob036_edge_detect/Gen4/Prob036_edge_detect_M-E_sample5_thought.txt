I'll implement a Moore finite state machine (FSM) for edge detection that:
1. Uses 3 states to track the input signal's behavior (LOW, HIGH, EDGE)
2. Detects both rising and falling edges in a unified manner
3. Provides glitch-free outputs synchronized to the clock
4. Has clear state transitions that make the design more robust against metastability

The state machine approach offers these advantages:
- Explicit state representation makes the design intent clearer
- Easier to extend with additional states if needed (e.g., for debouncing)
- More robust against timing issues as transitions are clearly defined
- Outputs are registered, providing better timing characteristics
