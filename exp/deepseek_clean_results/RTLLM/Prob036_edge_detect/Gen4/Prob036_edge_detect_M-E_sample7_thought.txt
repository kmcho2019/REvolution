Innovative Strategy:
1. Use a Moore state machine with 3 states to track signal transitions
2. States represent: STABLE_0 (a=0), STABLE_1 (a=1), and TRANSITION (edge detected)
3. Outputs are registered for clean timing (no combinational glitches)
4. State transitions handle all edge cases including consecutive edges
5. Benefits:
   - Explicit state representation makes behavior very clear
   - Registered outputs ensure clean timing
   - Easily extensible for more complex edge detection patterns
   - Naturally handles metastability through state encoding
