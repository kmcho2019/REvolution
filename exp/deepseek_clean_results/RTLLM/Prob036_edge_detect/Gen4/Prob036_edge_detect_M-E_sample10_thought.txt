Instead of using the traditional approach of storing the previous value, we can implement a Moore state machine that tracks the current state of the input signal. The states represent:
- STABLE_0: Input has been stable at 0
- RISING: Just detected a rising edge
- STABLE_1: Input has been stable at 1
- FALLING: Just detected a falling edge

Benefits:
1. More explicit state representation makes the design intent clearer
2. Easier to extend with additional states if needed (like debouncing)
3. Can potentially detect glitches if we add more states
4. State transitions precisely document the edge detection logic
5. More maintainable for complex edge detection requirements
