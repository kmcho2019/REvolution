Instead of using simple combinational logic, we can implement a Moore state machine with 3 states:
1. IDLE: No edge detected
2. RISING: Rising edge detected (output rise=1)
3. FALLING: Falling edge detected (output down=1)

The state machine transitions:
- From IDLE to RISING when 0→1 transition
- From IDLE to FALLING when 1→0 transition
- Always returns to IDLE on next clock

Benefits:
1. More extensible design (can easily add more states/functionality)
2. Clear separation of edge detection logic
3. Can potentially add debounce functionality later
4. Outputs are registered (better timing)
5. Explicit state encoding makes behavior very clear
