Instead of the traditional approach of storing the previous value, we can implement a Moore state machine with 3 states:
1. IDLE: No edge detected
2. RISING: Rising edge detected (output rise=1)
3. FALLING: Falling edge detected (output down=1)

The state machine transitions:
- From IDLE to RISING when a changes from 0 to 1
- From IDLE to FALLING when a changes from 1 to 0
- Always returns to IDLE on next clock cycle
This provides explicit state tracking of edge conditions and ensures outputs are only high for one clock cycle.
