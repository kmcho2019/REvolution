State Machine Based Edge Detection:
1. Use a 3-state FSM to track signal transitions (IDLE, RISING, FALLING)
2. Current state depends on previous state and input signal value
3. Output pulses are generated only during state transitions
4. Benefits:
   - More explicit control over edge detection timing
   - Easier to add features like debouncing
   - Clear separation of detection logic
   - Better for formal verification
5. The FSM will:
   - Stay in IDLE when no edges detected
   - Transition to RISING on 0->1 change
   - Transition to FALLING on 1->0 change
   - Generate single-cycle pulses on transitions
