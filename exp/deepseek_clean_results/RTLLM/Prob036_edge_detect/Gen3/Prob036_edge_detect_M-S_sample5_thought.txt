The edge detection can be implemented with even simpler logic by:
1. Removing the unused reset signal entirely to save area
2. Using a single always block for the register
3. Directly assigning the edge detection outputs without additional registers
4. The edge detection is purely combinational based on current and previous values

This maintains the same functionality while being more minimal:
- Only 1 flip-flop for state storage
- 2 simple AND gates for edge detection
- No reset logic needed since edge detection is relative
- Same timing characteristics as original
