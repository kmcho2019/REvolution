Novel Architecture: State Machine Based Edge Detection
1. Instead of using simple delay comparison, implement a Moore state machine that explicitly tracks the signal's state transitions
2. Four states: IDLE (initial state), RISING (detected 0→1), FALLING (detected 1→0), and STABLE (no recent edges)
3. State transitions occur on clock edges based on current state and input 'a'
4. Outputs are purely combinatorial functions of the current state
5. Benefits:
   - More robust against glitches
   - Explicit state tracking makes behavior more verifiable
   - Easier to extend with additional features (like edge filtering)
   - Clear separation between state tracking and output generation
