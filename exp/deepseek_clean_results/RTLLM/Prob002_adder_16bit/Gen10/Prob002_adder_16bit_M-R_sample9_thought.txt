Refactoring Strategy:
1. Maintain the same 16-bit adder functionality using two 8-bit adders
2. Simplify the 8-bit adder implementation by:
   - Using continuous assignments for both carry and sum calculations
   - Eliminating intermediate carry wires by directly computing each bit's carry
   - Combining carry and sum logic into more compact expressions
3. Keep the hierarchical structure but make the 8-bit adder more concise
4. Use direct assignment for the 16-bit adder's outputs
5. Benefit: Reduced line count while maintaining same functionality and similar PPA characteristics

Key Changes:
- Removed explicit carry array in 8-bit adder
- Combined carry and sum calculations into single expressions per bit
- Simplified top-level instantiation
- Maintained same carry propagation between 8-bit blocks
