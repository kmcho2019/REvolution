To address the array assignment limitation, I'll refactor the design using:
1. A 3-bit counter to track the current 'hot' bit position
2. A decoder to convert the counter value to one-hot encoding
3. Simple increment logic for the counter with wrap-around
4. Reset initialization to position 0 (LSB)
5. Clocked always block only for the counter, with combinational logic for output

This approach avoids direct array assignments while maintaining identical functionality. The counter tracks position numerically, and the decoder creates the one-hot output pattern.
