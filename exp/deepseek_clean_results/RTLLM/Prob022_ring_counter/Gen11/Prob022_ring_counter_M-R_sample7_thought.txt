Here's a refactored version that maintains the same functionality while avoiding the array assignment issue:

1. Instead of using a separate state register and output logic, we'll combine them into a single register
2. The output will be directly the state register, which will hold the one-hot pattern
3. State transitions will be implemented using shift operations with wrap-around
4. Reset initializes to 8'b00000001 (LSB high)
5. On each clock edge, we'll left-shift the register with wrap-around
6. This approach is more concise and avoids the array assignment problem

Advantages:
- Simpler implementation with fewer lines of code
- No need for explicit state encoding
- Output is directly the state register
- Maintains the same cyclic one-hot behavior
- Works around the simulator limitation
