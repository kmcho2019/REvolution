1. Use a more universal shift operation that works across all Verilog tools
2. Maintain the one-hot encoding property (only one bit set at a time)
3. Keep the same reset behavior (LSB set on reset)

- Using a case statement for state transitions which is universally supported
- Explicit one-hot state encoding
