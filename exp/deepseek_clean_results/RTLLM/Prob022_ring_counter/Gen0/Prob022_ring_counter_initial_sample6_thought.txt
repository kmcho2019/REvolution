To implement an 8-bit ring counter, we need a register to hold the current state. The counter should:
1. Initialize to 8'b0000_0001 when reset is high
2. On each clock edge (when not reset), rotate the single '1' to the left (with wrap-around)
3. Output the current state

The rotation can be achieved by left-shifting and OR-ing the MSB back to LSB position when needed.
