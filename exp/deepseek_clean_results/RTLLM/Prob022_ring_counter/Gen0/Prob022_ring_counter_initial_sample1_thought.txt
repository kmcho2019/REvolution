To implement an 8-bit ring counter, we need a register that shifts a single '1' bit cyclically through its 8 bits. The design should:
1. Initialize to 8'b00000001 when reset is high
2. On each clock edge (when not reset), perform a left shift operation
3. When the '1' reaches the MSB (bit 7), it should wrap around to the LSB (bit 0)
4. The output should always have exactly one '1' bit circulating through it
