To implement an 8-bit ring counter, we need a register that shifts a single '1' bit circularly through its 8 bits. The design requires:
1. A synchronous reset to initialize the counter to 8'b00000001
2. On each clock edge (positive edge), the '1' shifts left by one position
3. When the '1' reaches the MSB (bit 7), it wraps around to the LSB (bit 0)
4. The output should always have exactly one '1' bit circulating
