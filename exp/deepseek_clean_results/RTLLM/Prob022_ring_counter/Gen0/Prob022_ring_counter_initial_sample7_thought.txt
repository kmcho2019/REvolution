To implement an 8-bit ring counter, we need a register to hold the current state. The counter should:
1. Initialize to 8'b0000_0001 on reset
2. On each clock edge, rotate the single '1' left by one position
3. Wrap around from MSB to LSB to maintain the ring behavior
4. Output the current state at all times

The implementation will use a simple always block triggered by clock or reset. The state transitions can be done using a left rotate operation with wrap-around.
