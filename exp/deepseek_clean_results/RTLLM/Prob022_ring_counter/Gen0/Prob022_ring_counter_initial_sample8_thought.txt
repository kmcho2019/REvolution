To implement an 8-bit ring counter, we need a register to hold the current state. The counter should:
1. Initialize to 8'b00000001 when reset is high
2. On each clock edge (when not reset), rotate the single '1' left by one position
3. Implement wrap-around behavior so after the MSB, it returns to LSB
4. Output the current state on 'out'

The key is using a simple shift register with feedback from the MSB to LSB, maintaining exactly one '1' in the pattern.
