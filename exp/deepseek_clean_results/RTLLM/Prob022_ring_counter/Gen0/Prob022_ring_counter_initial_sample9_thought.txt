To implement an 8-bit ring counter, we need a register that shifts a single '1' bit through its 8 positions cyclically. The design requires:
1. Synchronous reset to initialize the counter to 8'b0000_0001
2. On each clock edge (posedge), the '1' should shift left by one position
3. When the '1' reaches the MSB (bit 7), it should wrap around to the LSB (bit 0)
4. The output should reflect the current state of the counter
