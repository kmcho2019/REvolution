Novel approach using a 3-bit counter with decoder:
1. Instead of direct bit shifting, use a 3-bit counter to track position
2. Decode the counter value to one-hot output
3. Counter increments on each clock, wrapping from 7 to 0
4. Reset initializes counter to 0 (LSB set)
5. Decoder converts 3-bit count to 8-bit one-hot

Advantages:
- More robust implementation (no shifting operations)
- Clear separation of position tracking and output generation
- Easier to modify sequence patterns if needed
- Better tool compatibility (simple counter + decoder)
- Maintains strict one-hot property
