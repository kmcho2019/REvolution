To implement an 8-bit ring counter with the same functionality but more simulator-friendly syntax, I'll:

1. Use an 8-bit shift register directly instead of a binary counter
2. Implement the shift operation in a single always block
3. Maintain the one-hot property by shifting a single '1' bit
4. Initialize to 8'b00000001 on reset
5. Use simple bit shifting with wrap-around for the cyclic behavior

This approach:
- Eliminates the need for binary-to-one-hot conversion
- Uses basic shift operations that are universally supported
- Maintains clear one-hot property at all times
- Simplifies the design to a single register and shift logic
- Preserves the exact same external behavior
