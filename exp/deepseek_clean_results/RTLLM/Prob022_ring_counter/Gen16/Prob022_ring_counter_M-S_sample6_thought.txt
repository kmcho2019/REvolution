To simplify the ring counter implementation while maintaining functionality:

1. Directly use an 8-bit shift register instead of a binary counter + decoder
2. Initialize to 8'b00000001 on reset
3. On each clock edge, left-shift the register with wrap-around
4. This eliminates the need for a separate counter and decoder logic
5. More efficient implementation with simpler code
6. Maintains the same one-hot cycling behavior
7. Easier to understand and maintain
