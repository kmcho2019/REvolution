Here's a novel approach using a shift register with feedback:

1. Instead of explicit state transitions, we'll use a shift register that circulates a single '1'
2. The shift register will be initialized to 8'b00000001 on reset
3. On each clock cycle, we'll shift left by 1 bit
4. When the '1' reaches the MSB, we'll detect it and wrap around by OR-ing with a feedback bit
5. This creates a continuous ring counter behavior with only one bit set at any time
6. The approach uses minimal logic and leverages Verilog's bit manipulation capabilities

Key advantages:
- More compact implementation than case statements
- Easily scalable to different counter widths
- Uses simple shift operations rather than explicit state definitions
- Maintains clear one-hot encoding
