Here's a novel approach using a shift register with feedback:
1. Instead of using a state counter, implement a pure shift register
2. The feedback path will bring the MSB back to the LSB to create the ring behavior
3. Initialize with a single '1' at reset
4. Use a synchronous reset to ensure clean initialization
5. The shift operation occurs on every clock edge
6. This approach is more hardware-oriented and directly implements the ring behavior without state decoding

This method is elegant because:
- It directly implements the ring concept through physical wiring
- Eliminates the need for a separate state counter and decoder
- Uses minimal logic (just a shift register with feedback)
- Clearly shows the cyclic nature in the hardware description
