Novel approach using a state machine with explicit state encoding:
1. Instead of simple shifting, implement as a finite state machine
2. Use a 3-bit counter to track current state (0-7)
3. Decode the counter value to one-hot output
4. Reset initializes counter to 0 (LSB set)
5. On each clock, increment counter with wrap-around
6. Separate counter and decoder provides more flexibility for future modifications

Advantages:
- More explicit state representation
- Easier to modify sequence patterns if needed
- Clear separation between state tracking and output generation
- Potential for adding more complex transitions later
- Maintains same one-hot property as shifting approach
