I'll implement the ring counter using a different approach by:
1. Using a 3-bit counter to track the current position
2. Decoding this position into a one-hot output
3. The counter increments on each clock cycle and wraps around
4. Reset initializes the counter to 0 (LSB set)
5. This approach separates the position tracking from output generation

Benefits:
- More flexible for different counter widths
- Clear separation of concerns
- Easier to modify behavior (like changing direction)
- Avoids concatenation issues in some tools
