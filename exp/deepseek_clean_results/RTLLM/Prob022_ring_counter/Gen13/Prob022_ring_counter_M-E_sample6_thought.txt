Here's an alternative approach using a binary counter with a decoder:
1. Use a 3-bit binary counter to count from 0 to 7
2. Decode the counter value to one-hot output
3. The counter automatically wraps around when reaching 7
4. Reset initializes the counter to 0, which decodes to 00000001
5. This approach separates the counting logic from the output generation
6. Benefits include:
   - Clear separation of concerns
   - Easier to modify sequence patterns if needed
   - More scalable for larger counters
   - Uses standard counter and decoder components
