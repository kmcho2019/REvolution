Novel approach using a state register with combinatorial next-state logic:

1. Instead of using shift operations, implement a state machine where each state corresponds to one active bit position
2. Use a 3-bit counter to track the current position (0-7)
3. Decode the counter value to a one-hot output using a case statement
4. On each clock edge, increment the counter (with wrap-around from 7 to 0)
5. Reset initializes the counter to 0 (LSB set)
6. Advantages:
   - More explicit state representation
   - Avoids shift operation issues
   - Clear state progression
   - Easier to modify for non-sequential patterns if needed
   - More tool-compatible implementation
