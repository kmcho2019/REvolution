To simplify the ring counter implementation while maintaining functionality:

1. Directly use an 8-bit shift register instead of a separate state counter and decoder
2. Implement simple left-shift with wrap-around behavior
3. Reset initializes to 8'b00000001 (one-hot with LSB set)
4. Each clock cycle shifts the '1' left, wrapping around when it reaches the MSB
5. This eliminates the need for a case statement and reduces the design to a single always block

The simplified approach:
- Uses only one always block for both reset and shifting
- Implements shifting with concatenation for wrap-around
- Maintains one-hot property at all times
- More efficient and easier to understand
