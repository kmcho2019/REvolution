Alternative approach using a finite state machine (FSM) with explicit state encoding:
1. Use a 3-bit counter to track the current active bit position
2. Decode this position into one-hot output using a decoder
3. Increment the counter on each clock cycle, wrapping around after 7
4. Reset initializes the counter to 0 (LSB active)
5. This approach separates the counting logic from output decoding
6. Benefits include clearer state tracking and easier modification of sequence patterns
