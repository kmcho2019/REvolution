Here's a novel approach using a shift register with feedback:
1. Instead of a counter + decoder, use a self-correcting shift register
2. The register shifts left on each clock cycle
3. Feedback logic ensures only one bit remains set
4. Reset initializes to 8'b0000_0001
5. When MSB is set, feedback wraps it to LSB
6. Self-correcting feature maintains exactly one '1' even if glitches occur

Key advantages:
- Pure shift register implementation (no counter/decoder)
- Inherently maintains one-hot property
- Self-correcting for robustness
- Simple and elegant state transitions
- No need for explicit wrap-around logic
