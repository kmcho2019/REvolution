Here's a novel approach using a circular shift register with parallel load:
1. Instead of using a counter + decoder, implement a pure shift register approach
2. Use a 8-bit register initialized to 00000001
3. On each clock edge, perform a circular left shift operation
4. The reset signal loads the initial pattern (00000001) in parallel
5. Key advantages:
   - Direct implementation of ring counter behavior
   - No need for separate counting and decoding logic
   - Simple and efficient hardware implementation
   - Clear correspondence between concept and implementation
   - Easily extendable to any width
