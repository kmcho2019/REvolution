Novel approach using a one-hot encoded state machine with explicit state transitions:
1. Instead of using shift operations, implement a state machine with 8 distinct states
2. Each state corresponds to one bit being high (one-hot encoding)
3. State transitions follow a fixed cyclic pattern
4. Reset initializes to the first state (LSB high)
5. Uses a case statement for clear state transition logic
6. More explicit state representation than shift-based approach
