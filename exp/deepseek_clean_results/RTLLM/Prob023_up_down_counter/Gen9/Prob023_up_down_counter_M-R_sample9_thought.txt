Refactoring approach:
1. Separate the combinational logic from sequential elements for better clarity
2. Use an always block only for the register (sequential logic)
3. Move the increment/decrement logic to a continuous assignment (combinational logic)
4. This creates a cleaner separation between combinational and sequential logic
5. The design becomes more modular and easier to verify/analyze

Key benefits:
- Clear separation of combinational and sequential logic
- Easier timing analysis (critical path is more visible)
- More flexible for future modifications
- Maintains same functionality while improving code structure
