Simplified Design Approach:
1. Use a single 16-bit register instead of segmented counters to reduce complexity
2. Implement straightforward increment/decrement logic based on up_down signal
3. Maintain synchronous reset functionality
4. Eliminate carry propagation logic between segments
5. Benefits:
   - Reduced area by using single register
   - Simplified timing path with no carry chain
   - Lower power consumption with less switching logic
   - Easier to understand and maintain code
   - Still meets all functional requirements
