Novel Architectural Idea:
1. Implement the counter using Gray code instead of binary to minimize switching activity
2. Use a state machine to handle the up/down transitions in Gray code space
3. Benefits:
   - Reduced power consumption due to only 1-bit changing per count
   - No combinational logic in the count output path (pure register)
   - Simplified timing as no carry chain exists
   - Natural rollover behavior at boundaries
   - Easier synchronization when crossing clock domains
4. Implementation:
   - Convert between binary and Gray code at boundaries
   - Use a simple state machine for next Gray code value selection
   - Maintain direction control through the state transitions
