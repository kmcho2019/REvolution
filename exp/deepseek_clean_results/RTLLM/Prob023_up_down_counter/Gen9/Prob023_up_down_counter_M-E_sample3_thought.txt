Novel Architectural Idea:
1. Implement the counter using Gray code encoding to minimize bit transitions
2. Use a dual-register approach: one for binary count (internal) and one for Gray code output
3. Benefits:
   - Reduced power consumption due to only 1-bit changing per count
   - Glitch-free output transitions
   - Simplified timing due to Gray code properties
   - Maintains binary counting internally for easy arithmetic operations
4. Conversion between binary and Gray code happens synchronously
5. The up/down control directly affects the binary counter, while the output shows Gray code
