Novel approach using a single arithmetic operation with wrap-around detection:
1. Instead of segmented counting or carry propagation, use a single 16-bit arithmetic operation
2. Implement wrap-around detection to prevent overflow/underflow
3. Use a parameter for maximum count value for flexibility
4. Simplify the logic to a single always block with minimal operations
5. The design will automatically wrap around when reaching limits (0 or 65535)
6. This approach reduces combinatorial logic and improves timing
7. The single arithmetic operation makes the design more straightforward and easier to optimize
