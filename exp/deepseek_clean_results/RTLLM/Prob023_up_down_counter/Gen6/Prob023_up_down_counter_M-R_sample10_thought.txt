Refactored design using a single always block with if-else structure:
1. Combine the combinational and sequential logic into one always block
2. Use a priority-encoded structure with reset having highest priority
3. Simplify the logic by directly updating the count register based on conditions
4. This approach reduces the number of intermediate signals and may improve synthesis results by making the control flow more explicit to the tools
5. The count output is directly assigned from the register
