Here's a novel approach using a parallel prefix adder structure for the counter implementation:
1. Instead of a simple increment/decrement, we'll use a carry-lookahead inspired design
2. The direction control (up_down) will generate either +1 or -1 (two's complement) as a parallel input
3. This creates a more scalable design with better timing characteristics for large counters
4. The reset is still synchronous but now clears all bits in parallel
5. The design maintains the same functionality but with potentially better timing at high frequencies
