Refactored design using continuous assignment for the counter logic:
1. Replace the always block with combinational logic for the next count value
2. Use a register to store the current count value
3. The next count is calculated as:
   - 0 when reset is active
   - current count +1 when up_down=1
   - current count -1 when up_down=0
4. The register updates on clock edges
This approach separates the combinational logic from sequential elements, potentially improving synthesis optimization.
