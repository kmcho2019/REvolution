Simplified Design Approach:
1. Replace segmented counter with a single 16-bit register for simpler implementation
2. Use direct arithmetic operations (+1/-1) based on up_down signal
3. Maintain synchronous reset functionality
4. Benefits:
   - Eliminates complex carry propagation logic between segments
   - Reduces area by using a single register instead of multiple segments
   - Simplifies timing analysis with a single arithmetic operation
   - Maintains full functionality while being more efficient
   - Easier to understand and maintain
