Simplified Design Approach:
1. Replace segmented counter with a single 16-bit register for simpler implementation
2. Use direct arithmetic operations (addition/subtraction) on the full 16-bit value
3. Maintain synchronous reset and counting behavior
4. Benefits:
   - Eliminates complex carry propagation logic between segments
   - Reduces area by using a single register instead of multiple segments
   - Simplifies timing paths with direct arithmetic operations
   - Maintains same functionality with cleaner code structure
