Refactoring approach:
1. Move all logic to continuous assignments for a purely combinational implementation
2. Use a register variable to store the current state
3. Create a next_state calculation that handles both increment and decrement
4. Update the register on clock edges using non-blocking assignment
5. This creates a more dataflow-oriented style while maintaining functionality

Key benefits:
- Eliminates always blocks for simpler structure
- Makes the data flow more explicit
- Easier to see all operations at once
- Maintains same synchronous behavior
- Still clearly separates next state logic from state storage
