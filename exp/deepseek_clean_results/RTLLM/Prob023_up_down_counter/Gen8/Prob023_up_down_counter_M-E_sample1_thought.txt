Novel Architectural Idea:
1. Divide the 16-bit counter into 4 segments of 4 bits each (4x4=16)
2. Implement each 4-bit segment as a standalone up/down counter
3. Use parallel prefix computation to handle carry/borrow propagation between segments
4. Benefits:
   - Reduced critical path by breaking the 16-bit chain into smaller segments
   - Parallel carry/borrow computation improves timing
   - Modular design allows for easier pipelining if needed
   - Better scalability for wider counters
   - Lower power consumption as only active segments toggle
