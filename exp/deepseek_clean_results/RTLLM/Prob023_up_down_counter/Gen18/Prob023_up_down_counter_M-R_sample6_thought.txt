Refactoring Strategy:
1. Simplify the arithmetic logic by using a single 16-bit adder/subtractor instead of segmented approach
2. Remove unused Gray code conversion to reduce area
3. Simplify clock gating to only depend on reset and counting direction
4. Use continuous assignment for the next count value calculation
5. Keep synchronous reset for reliable initialization

Key Improvements:
- Single arithmetic operation improves timing by eliminating carry propagation delays
- Reduced logic complexity lowers power consumption
- Cleaner code structure improves maintainability
- Maintains same functionality while being more efficient
