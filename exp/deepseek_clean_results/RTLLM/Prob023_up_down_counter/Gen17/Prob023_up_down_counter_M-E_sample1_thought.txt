Novel Architectural Idea:
1. Implement a 16-bit counter using a linear-feedback shift register (LFSR) approach for counting
2. Use XOR-based feedback logic to generate next count value
3. For up counting: Implement a standard LFSR sequence
4. For down counting: Reverse the LFSR sequence by using inverted feedback
5. Benefits:
   - Reduced combinational logic compared to traditional counters
   - Uniform delay paths for better timing closure
   - Lower power consumption due to fewer transitions
   - Inherent pseudo-random pattern useful for some applications
   - Single register implementation saves area
