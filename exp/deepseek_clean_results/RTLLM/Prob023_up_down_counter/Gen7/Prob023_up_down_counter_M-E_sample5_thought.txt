Innovative parallel prefix counter design:
1. Uses Brent-Kung adder structure for faster carry propagation
2. Implements separate increment and decrement logic in parallel
3. Uses a multiplexer to select the appropriate result based on up_down signal
4. The parallel prefix structure reduces the critical path from O(n) to O(log n)
5. Includes overflow/underflow protection by wrapping around naturally
6. Uses registered outputs for better timing closure
