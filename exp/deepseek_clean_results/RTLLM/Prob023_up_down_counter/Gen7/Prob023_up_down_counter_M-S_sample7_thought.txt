Simplification approach:
1. Remove the separate register and continuous assignment - we can directly register the output
2. Combine the increment/decrement logic into a single arithmetic operation using the up_down signal
3. Use a ternary operator to make the direction selection more concise
4. Maintain synchronous reset and clocked operation
5. This reduces the design to a single always block with direct output registration

Key benefits:
- Fewer lines of code
- No intermediate signals
- Same functionality with simpler implementation
- Maintains clear synchronous behavior
