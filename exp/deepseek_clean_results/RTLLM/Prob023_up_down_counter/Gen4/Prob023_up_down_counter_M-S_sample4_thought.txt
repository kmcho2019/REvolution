The original implementation is already quite minimal, but we can simplify it slightly by:
1. Removing redundant bit-width specifications (1'b1 is implied for single-bit operations)
2. Combining the increment/decrement operations into a single line using a conditional operator
3. Maintaining all core functionality (16-bit counter, up/down control, synchronous reset)
4. Keeping the same wrap-around behavior at boundaries
This reduces line count while preserving identical functionality.
