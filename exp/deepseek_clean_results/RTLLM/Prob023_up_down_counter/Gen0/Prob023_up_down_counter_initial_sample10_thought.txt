The design requires a 16-bit counter with synchronous reset and direction control. The counter should:
1. Reset to 0 when reset is active (synchronous to clock)
2. Increment when up_down=1 on each clock edge
3. Decrement when up_down=0 on each clock edge
4. Wrap around naturally (no explicit handling needed as Verilog will handle overflow/underflow)
The implementation uses a single always block sensitive to posedge clk for synchronous operation.
