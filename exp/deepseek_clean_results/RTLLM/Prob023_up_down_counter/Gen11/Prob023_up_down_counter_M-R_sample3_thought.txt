Refactoring Strategy:
1. Move the counter logic to combinational blocks using assign statements
2. Split the design into:
   - A register block (synchronous always block for state storage)
   - Combinational next-state logic (using assign)
3. Benefits:
   - Clear separation of combinational and sequential logic
   - Easier timing analysis (distinct paths)
   - More flexible for synthesis optimizations
   - Maintains same functionality but with cleaner structure
4. Implementation:
   - Use always block only for register updates
   - Compute next count value purely with combinational logic
   - Reset remains synchronous for consistency
   - Keep the efficient increment/decrement approach
