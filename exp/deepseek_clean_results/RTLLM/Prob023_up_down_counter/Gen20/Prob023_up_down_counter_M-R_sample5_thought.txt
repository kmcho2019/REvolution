Refactoring Strategy:
1. Simplify the design by removing the segmented approach and using a single 16-bit counter
2. Replace the always block with continuous assignments for combinational logic
3. Use a ternary operator for the up/down selection
4. Maintain synchronous reset using a register
5. Reduce logic complexity by directly computing the next count value
6. Eliminate unnecessary intermediate signals to improve timing and reduce power

Key Changes:
- Removed segmented carry logic which was overkill for a 16-bit counter
- Simplified to a single continuous assignment for the next count value
- Kept the synchronous reset for proper initialization
- Reduced gate count by using direct arithmetic operations
- Improved timing by removing hierarchical carry chains
