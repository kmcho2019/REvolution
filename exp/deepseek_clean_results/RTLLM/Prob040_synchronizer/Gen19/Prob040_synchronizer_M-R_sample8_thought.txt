The refactored design maintains the same functionality but uses a more combinational approach:
1. Uses continuous assignments for all registers instead of always blocks
2. Implements the two-stage synchronizer with explicit next-state logic
3. Combines the enable synchronization and output register updates into combinational logic
4. Uses ternary operators for reset conditions
5. Maintains the same clock domain separation but with different implementation style

Key changes:
- Replaced all always blocks with continuous assignments
- Explicit next-state logic for all registers
- Combined enable sync and output register into single expressions
- More compact representation while maintaining same functionality
- Same metastability protection with two-stage sync
- Clear separation of clock domains through assignment structure
