The refactored design maintains the same functionality but uses a different structural approach:
1. Uses a single always block for the enable synchronization chain to improve timing
2. Implements the data path with a single register update mechanism
3. Uses a registered output instead of combinational assignment for better timing closure
4. Maintains proper reset handling but combines the reset and data update logic

Key changes:
- Combined the two-stage synchronizer and data register into a single always block
- Output data is now fully registered
- Simplified the control logic by removing the intermediate dataout_reg
- The design remains functionally equivalent but with improved timing characteristics
