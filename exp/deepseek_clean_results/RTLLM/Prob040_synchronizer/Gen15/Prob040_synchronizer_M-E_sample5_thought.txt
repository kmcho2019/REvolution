FIFO-Based Gray Code Synchronizer Architecture:
1. Implement a small FIFO (depth=2) between clock domains using gray code pointers
2. Data is written to FIFO in clk_a domain when data_en is high
3. Read pointer is synchronized to clk_a domain using gray code
4. Write pointer is synchronized to clk_b domain using gray code
5. Data is read from FIFO in clk_b domain when valid data is available
6. Gray coding ensures only one bit changes at a time during pointer synchronization
7. Empty/full flags prevent data corruption

Advantages:
- Naturally handles clock frequency differences
- Built-in flow control between domains
- Robust against metastability
- Minimizes synchronization overhead
- Clear separation of clock domains
- Scalable to wider data buses

Implementation Details:
- Dual-clock FIFO with gray code pointers
- Separate reset handling for each domain
- Valid data indication for output
- Minimal synchronization stages (2FF)
- Optimized for 4-bit data width
