Refactoring Strategy:
1. Replace sequential logic with combinational where possible
2. Use continuous assignments for simpler register updates
3. Maintain same synchronization stages but express differently
4. Keep same reset behavior but implement more concisely
5. Use non-blocking assignments consistently for clocked elements

Key Changes:
- Used continuous assignments for data_reg and en_data_reg updates
- Combined the enable synchronization into a single always block
- Simplified output assignment logic
- Maintained same metastability protection
- Kept same clock domain crossing behavior

Benefits:
- More concise code while maintaining same functionality
- Clearer separation of combinational and sequential logic
- Easier to modify individual components
- Maintains same timing characteristics
- Same power and area characteristics
