The refactored design will:
1. Use continuous assignments for combinational logic where possible
2. Separate the clock domain crossing into distinct modules for better modularity
3. Use explicit register declarations for better readability
4. Maintain the same functionality while making the code structure clearer
5. Keep the same metastability protection with 2-flop synchronizer
6. Preserve the same reset behavior for both clock domains

Key changes:
- Split into two always blocks per clock domain for clearer separation
- Use explicit wire declarations for intermediate signals
- Keep the same synchronization strategy but with more visible structure
- Maintain identical timing and functionality
