To implement a 16-bit divider with an 8-bit divisor in combinational logic, we'll use a non-restoring division algorithm. The key steps are:
1. Initialize registers for the dividend, divisor, quotient, and remainder
2. For each bit (16 iterations):
   - Shift the remainder and quotient left by 1
   - Bring down the next bit from the dividend
   - Compare the current remainder with the divisor
   - If remainder >= divisor: subtract divisor and set quotient LSB to 1
   - Else: keep remainder unchanged and set quotient LSB to 0
3. After all bits are processed, the quotient and remainder will be ready

This is implemented purely in combinational logic using always blocks sensitive to input changes.
