To implement a 16-bit divider with an 8-bit divisor in combinational logic, we'll use a non-restoring division algorithm. The key steps are:
1. Initialize registers for the dividend (extended to 32 bits for intermediate calculations), divisor, quotient, and remainder
2. For each bit (16 iterations):
   - Shift the dividend/remainder left by 1 bit
   - Compare the upper bits with the divisor
   - If greater or equal, subtract divisor and set quotient bit
   - Otherwise, leave unchanged and clear quotient bit
3. After all iterations, the lower 16 bits contain the quotient and upper 16 bits contain the remainder
