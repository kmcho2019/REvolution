To implement a 16-bit divider with an 8-bit divisor in combinational logic, we'll use a non-restoring division algorithm. The key steps are:
1. Initialize registers for the dividend, divisor, quotient, and remainder
2. For each bit in the dividend (16 iterations):
   a. Shift the remainder left by 1 and bring down the next bit from the dividend
   b. Compare the current remainder with the divisor
   c. If remainder ≥ divisor: subtract divisor from remainder and set quotient bit to 1
   d. Else: keep remainder unchanged and set quotient bit to 0
3. After all bits are processed, the quotient and remainder will be ready

This is implemented purely in combinational logic using two always blocks - one for register updates and one for the division logic.
