To implement a 16-bit divider with an 8-bit divisor in combinational logic, we'll use a non-restoring division algorithm. The key steps are:
1. Initialize a 24-bit working register (16 bits for remainder + 8 bits for divisor width)
2. For each of the 16 bits:
   - Left shift the working register
   - Compare the upper 8 bits with the divisor
   - If greater or equal, subtract divisor and set quotient bit to 1
   - Else, keep value and set quotient bit to 0
3. After 16 iterations, the lower 16 bits contain the quotient and upper 16 bits contain the remainder
