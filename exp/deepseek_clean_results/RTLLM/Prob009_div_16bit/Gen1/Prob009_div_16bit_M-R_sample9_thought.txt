To refactor the divider while maintaining the same core algorithm, I'll make these key changes:
1. Replace the procedural always blocks with continuous assignments (assign statements) where possible
2. Use a generate-for loop instead of a procedural for-loop to unroll the iterations
3. Create intermediate wires for each stage of the division
4. Eliminate unnecessary registers by computing values directly
5. Maintain the same non-restoring division approach but express it structurally

The benefits of this approach are:
- Purely combinational logic remains
- Clearer data flow through explicit wiring
- Better optimization potential for synthesis tools
- More transparent operation through staged computation
