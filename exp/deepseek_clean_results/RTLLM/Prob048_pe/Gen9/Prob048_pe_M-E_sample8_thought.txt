This design implements a 2-stage pipelined MAC with carry-save accumulation for better timing:
1. Stage 1 (Multiplier Stage):
   - Computes partial products using radix-4 Booth encoding
   - Generates sum and carry vectors for carry-save addition
2. Stage 2 (Accumulator Stage):
   - Uses carry-save format for accumulation
   - Converts final result to binary only when needed
3. Key Innovations:
   - Pipelined multiplier improves clock frequency
   - Carry-save accumulation reduces critical path
   - Registered intermediate results improve timing
   - Explicit pipeline registers for clean timing closure
   - Overflow protection with saturation logic
4. Reset synchronously clears all pipeline registers
