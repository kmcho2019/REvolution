Novel Architecture: Pipelined MAC with Operand Isolation
1. Two-stage pipeline to break critical path (multiply in stage1, accumulate in stage2)
2. Operand isolation to prevent unnecessary toggles when inputs are zero
3. Early termination for zero operands to save power
4. Carry-save accumulation to reduce critical path
5. Configurable precision mode (can trade off precision for power)

Key Innovations:
- Zero-detection logic prevents multiplier activation when either input is zero
- Pipelined structure allows higher clock frequencies
- Carry-save accumulation reduces adder critical path
- Optional precision mode (commented out) for power-sensitive applications
- Explicit pipeline registers for better timing closure
