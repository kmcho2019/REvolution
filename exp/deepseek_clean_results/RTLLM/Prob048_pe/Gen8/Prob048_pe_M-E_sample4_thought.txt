Novel Architecture: Pipelined MAC with Operand Isolation
1. Two-stage pipeline design to break critical path:
   - Stage 1: Multiplication only
   - Stage 2: Accumulation
2. Operand isolation to reduce power:
   - Only update pipeline registers when new data is valid
   - Uses an implicit valid signal (when inputs change)
3. Overflow protection:
   - Saturate rather than wrap on overflow
4. Power optimization:
   - Clock gating for the accumulator register
5. Area optimization:
   - Shared pipeline register for both multiplier outputs
   - Explicit truncation to 32 bits after multiplication

Key Benefits:
- Better timing (critical path split)
- Lower power (operand isolation)
- More reliable (overflow protection)
- Clean pipeline interface
