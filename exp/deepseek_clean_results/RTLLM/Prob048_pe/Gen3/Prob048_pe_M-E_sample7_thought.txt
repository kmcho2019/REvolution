Here's a novel architectural approach for the 32-bit MAC:

1. **Pipelined Multiplier-Accumulator**: Split the operation into two pipeline stages to improve timing:
   - Stage 1: Perform multiplication (a * b)
   - Stage 2: Perform accumulation (c + product)

2. **Registered Inputs**: Add input registers to improve timing and reduce glitches
3. **Early Reset Propagation**: Handle reset in both pipeline stages
4. **Output Register**: Maintain registered output for clean timing
5. **Resource Sharing**: Reuse the adder for both accumulation and reset operations

This approach provides better timing closure while maintaining the same functionality. The pipeline allows higher clock frequencies at the cost of one extra cycle latency.
