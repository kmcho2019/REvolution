Refactored Design Idea: Parallel Comparison with Direct Assignments

This refactoring maintains the same comparison logic but:
1. Uses direct continuous assignments for all outputs
2. Eliminates intermediate wires by computing results directly in output assignments
3. Restructures the greater-than logic to show clearer bit-wise priority
4. Uses more compact XOR expressions for equality comparison
5. Maintains the same mutual exclusivity guarantee

Key Improvements:
- More readable structure with direct output assignments
- Clearer visualization of the bit priority in greater-than logic
- Slightly reduced gate count by eliminating intermediate wires
- Same logical functionality with identical PPA metrics
