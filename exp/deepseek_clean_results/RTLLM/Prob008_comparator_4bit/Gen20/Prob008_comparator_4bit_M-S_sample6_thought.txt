Simplification Strategy:
1. Remove intermediate signals and compute outputs directly from inputs
2. Use simple equality check (A == B) for equal case
3. For greater/less comparison, use arithmetic comparison (A > B) which synthesizes efficiently
4. Make outputs mutually exclusive through direct assignment

Key Benefits:
- Eliminates all intermediate wires and hierarchical logic
- Uses Verilog's built-in comparison operators for cleaner code
- Maintains same functionality with fewer gates
- Outputs remain mutually exclusive by construction
- More readable and maintainable code
