Simplification Strategy:
1. Remove hierarchical comparison logic since modern synthesis tools can optimize basic comparison operators efficiently
2. Use direct comparison operators (>, ==, <) which are more readable and let the tool optimize
3. Maintain mutual exclusivity by deriving all outputs from the same comparison results
4. Eliminate intermediate wires since they don't provide optimization benefits in this simple case
5. Rely on synthesis tool to choose optimal implementation (gate-level or subtractor-based)

Key improvements:
- Much simpler and more readable code
- Fewer lines of code while maintaining same functionality
- Let synthesis tool handle low-level optimization
- Still maintains mutually exclusive outputs
