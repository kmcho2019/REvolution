Novel Thermometer-Coded Comparator Architecture:
1. Instead of traditional bit-by-bit comparison, we'll use a thermometer encoding approach:
   - Convert each 4-bit input to a 15-bit thermometer code (1-hot positional representation)
   - Compare the thermometer codes using simple AND operations
   - This allows parallel comparison of all magnitude relationships simultaneously

2. Key advantages:
   - Eliminates carry propagation delay of subtractors
   - All bit comparisons happen in parallel
   - Simple output encoding logic
   - Scales well to wider comparators

3. Implementation details:
   - First expand each input to thermometer code
   - Use bitwise AND between inverted B and A thermometer codes for greater-than
   - Use bitwise AND between inverted A and B thermometer codes for less-than
   - Equality is simply when all bits match

4. Optimizations:
   - Shared thermometer encoding logic
   - Early termination possible for equality case
   - Balanced logic depth for all outputs
