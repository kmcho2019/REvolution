Simplified approach using direct arithmetic comparison:
1. Instead of bit-wise comparison, leverage Verilog's built-in comparison operators
2. The operators will be synthesized into efficient combinational logic
3. Outputs are mutually exclusive by construction:
   - A_equal when A exactly matches B
   - A_greater when A > B (and not equal)
   - A_less otherwise (implied when neither greater nor equal)
4. Benefits:
   - Minimal logic depth (single comparison operation)
   - Clean and readable code
   - Synthesis tools can optimize the implementation
   - Scales perfectly to any bit width
