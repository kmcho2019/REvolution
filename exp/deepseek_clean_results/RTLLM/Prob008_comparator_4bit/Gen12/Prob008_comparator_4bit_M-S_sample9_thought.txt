Simplified approach using direct arithmetic comparison:
1. Instead of bit-wise comparison, leverage Verilog's built-in comparison operators
2. The operators will be synthesized to efficient combinational logic
3. Outputs are mutually exclusive by construction
4. Benefits:
   - Much simpler and more readable code
   - Synthesis tools can optimize the implementation
   - Naturally scales to any bit width
   - Eliminates all intermediate signals from previous solution
5. The implementation directly maps to the specification requirements
