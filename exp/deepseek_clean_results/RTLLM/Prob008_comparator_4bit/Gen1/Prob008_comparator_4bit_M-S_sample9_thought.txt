The original solution uses a sequential if-else structure which creates unnecessary priority logic. We can simplify this by:
1. Using parallel continuous assignments instead of procedural blocks
2. Directly computing each output using simple logical expressions
3. Leveraging Verilog's built-in comparison operators which will synthesize efficiently
4. Making outputs mutually exclusive by construction (only one can be true at a time)

This approach will:
- Eliminate the procedural block (always @*) 
- Remove intermediate registers
- Use direct wire assignments
- Maintain the same functionality with simpler code
