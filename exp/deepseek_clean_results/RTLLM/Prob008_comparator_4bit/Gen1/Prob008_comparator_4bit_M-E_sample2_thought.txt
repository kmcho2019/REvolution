A novel approach to implement the 4-bit comparator is to use a hierarchical bit-wise comparison starting from the most significant bit (MSB). This method:
1. Compares bits from MSB to LSB, stopping at the first unequal pair
2. Uses priority encoding to determine the final result
3. Eliminates the need for full subtraction, reducing logic complexity
4. Naturally provides mutually exclusive outputs
5. Potentially offers better timing as the critical path is limited to the first unequal bit pair

The implementation will:
1. Create equality signals for each bit position
2. Generate greater/less signals for each bit position
3. Use priority encoding to select the first non-equal bit comparison result
4. Combine these signals to produce the final outputs
