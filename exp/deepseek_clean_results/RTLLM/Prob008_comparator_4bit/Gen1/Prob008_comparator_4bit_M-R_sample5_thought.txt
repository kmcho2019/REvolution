The original implementation uses an always block with if-else statements. We can refactor this to use continuous assignments (assign statements) which are more concise for combinational logic. The comparison logic remains the same:
1. A_equal is true when all bits match (A == B)
2. A_greater is true when A > B and they're not equal
3. A_less is true when neither of the above conditions are met
The outputs remain mutually exclusive by construction.
