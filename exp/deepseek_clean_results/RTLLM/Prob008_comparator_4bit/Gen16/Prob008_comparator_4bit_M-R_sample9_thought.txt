Refactoring Strategy:
1. Replace the hierarchical bitwise comparison with a subtraction-based approach as originally suggested in the problem statement
2. Use continuous assignments (assign) for all outputs instead of intermediate wires
3. Simplify the logic by:
   - Using subtraction result's sign bit (borrow) directly for less-than condition
   - Calculating equality separately for cleaner code
   - Deriving greater-than from the other two conditions
4. Maintain the same functionality while improving readability and potentially reducing logic depth

Key Changes:
- Subtraction operation becomes the core comparison mechanism
- Output logic is simplified by mutual exclusivity property
- Removal of intermediate wires makes the design more direct
