Simplified Design Idea: Priority-Encoded Comparison with Reduced Logic Levels

This optimized design:
1. Uses a priority-encoded approach starting from MSB
2. Terminates comparison as soon as a decision can be made
3. Reduces logic levels by avoiding nested XOR/AND chains
4. Uses simple bitwise operations for equality check
5. Maintains mutual exclusivity through direct logic relationships

Key Improvements:
- Eliminates cascaded logic structure
- Reduces critical path depth
- Minimizes switching activity
- Uses fewer gates while maintaining clear functionality
