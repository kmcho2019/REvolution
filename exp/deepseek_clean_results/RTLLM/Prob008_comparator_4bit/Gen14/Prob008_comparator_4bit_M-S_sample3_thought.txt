Simplified approach using direct arithmetic comparison:
1. Instead of bit-wise comparison, use arithmetic operators for cleaner implementation
2. Compare A and B directly using >, ==, and < operators
3. Let synthesis tool optimize the logic implementation
4. Benefits:
   - Reduced code complexity (single line comparisons)
   - Clearer intent and maintainability
   - Synthesis tool can choose optimal implementation (likely similar to original but more standardized)
   - Maintains mutually exclusive outputs
5. This approach leverages Verilog's built-in comparison operators which are well-optimized in synthesis tools
