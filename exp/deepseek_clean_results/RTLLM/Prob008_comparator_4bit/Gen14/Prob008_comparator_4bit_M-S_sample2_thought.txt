Simplified approach using direct arithmetic comparison:
1. Instead of bit-wise comparison, leverage Verilog's built-in comparison operators
2. The operators will automatically generate optimal logic for 4-bit comparison
3. Outputs are mutually exclusive by construction:
   - A_equal when A exactly matches B
   - A_greater when A > B (and not equal)
   - A_less otherwise (since it's the only remaining possibility)
4. Benefits:
   - Minimal code complexity
   - Synthesis tools will optimize the implementation
   - Clear and maintainable design
   - Naturally scales to any bit width
