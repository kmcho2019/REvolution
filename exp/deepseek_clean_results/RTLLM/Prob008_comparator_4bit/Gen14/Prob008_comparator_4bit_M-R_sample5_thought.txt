Refactoring Strategy:
1. Replace the hierarchical AND-OR chain with a balanced tree structure for better timing
2. Use continuous assignments (assign) exclusively for cleaner combinational logic
3. Eliminate intermediate bit-wise signals by computing comparisons on-demand
4. Maintain the same logical functionality while improving physical implementation metrics

Key Changes:
- Balanced comparison tree splits bits into upper (3-2) and lower (1-0) groups
- Direct computation of greater-than condition without separate bit_gt/bit_eq signals
- Simplified output logic that still guarantees mutual exclusivity
- Reduced signal switching by computing conditions only when needed

Benefits:
- Improved timing from balanced comparison structure
- Reduced area by eliminating intermediate vectors
- Lower power from minimized signal toggling
- Maintains same logical behavior and interface
