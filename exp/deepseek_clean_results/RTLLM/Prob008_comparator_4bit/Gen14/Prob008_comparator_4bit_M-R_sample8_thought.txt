Refactoring Strategy: Structural Optimization with Direct Assignments

1. Key Changes:
   - Replace hierarchical AND-OR chain with parallel generate blocks
   - Use direct continuous assignments for all outputs
   - Eliminate intermediate wires by combining expressions
   - Maintain mutual exclusivity through logical relationships

2. Improvements:
   - Flattened logic structure improves timing predictability
   - Reduced wire count by combining operations
   - Clearer expression of the comparison logic
   - Maintains same functionality while being more concise

3. Benefits:
   - Same logical behavior as original
   - More straightforward implementation
   - Potentially better synthesis results due to simpler structure
   - Easier to modify for different bit widths
