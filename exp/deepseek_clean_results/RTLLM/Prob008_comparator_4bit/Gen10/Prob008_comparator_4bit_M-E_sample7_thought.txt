Novel Thermometer-Coded Comparator Architecture:
1. Instead of traditional bit-by-bit comparison, we'll use a thermometer encoding approach:
   - Convert both inputs to thermometer codes (unary representation)
   - Compare the thermometer codes using simple AND/OR operations

2. Key advantages:
   - Parallel processing of all bits simultaneously
   - No carry propagation delay
   - Simple logic structure with balanced paths
   - Natural priority encoding for comparison results

3. Implementation details:
   - Generate thermometer codes for both inputs
   - Use bitwise AND between inverted B and A for greater-than
   - Use bitwise AND between inverted A and B for less-than
   - Equality is simply bitwise XNOR reduction

4. Benefits:
   - Constant delay regardless of input values
   - No hierarchical dependencies
   - Power-efficient due to parallel processing
   - Scales well to wider bit widths
