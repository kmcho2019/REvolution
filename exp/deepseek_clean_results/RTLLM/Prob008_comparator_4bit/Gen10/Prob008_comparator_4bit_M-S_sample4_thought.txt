Simplified Design Approach:
1. Key observation: The equality check (A == B) is already optimal and can be used directly
2. For magnitude comparison, we can use the entire 4-bit vectors rather than bit-by-bit comparison
3. The greater-than condition can be determined by (A > B) in one operation
4. The less-than condition is simply the inverse of greater-than when not equal
5. Benefits:
   - Eliminates all intermediate wires and hierarchical logic
   - Uses native Verilog comparison operators which synthesize efficiently
   - Maintains mutual exclusivity of outputs
   - Reduces logic depth to minimum
   - More readable and maintainable
