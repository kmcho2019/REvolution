Simplified Design Idea: Parallel Comparison with Single-Level Logic

This design simplifies the comparator by:
1. Using parallel comparison for all bits simultaneously
2. Calculating equality as a single AND operation of all bit-wise equalities
3. Determining greater/less by comparing from MSB to LSB in parallel
4. Using simple bitwise operations (XOR, AND) for efficient implementation
5. Maintaining mutual exclusivity through direct logic relationships

Key Simplifications:
- Eliminates hierarchical comparison wires (gt3, gt2, etc.)
- Uses single 4-input AND for equality check
- Implements greater/less comparison using priority-encoded OR reduction
- Reduces gate count and logic levels compared to hierarchical approach
