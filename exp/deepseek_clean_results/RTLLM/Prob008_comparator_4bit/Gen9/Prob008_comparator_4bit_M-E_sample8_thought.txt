A novel approach using a thermometer-coded comparison:
1. First create a 4-bit difference vector where each bit indicates if A > B at that position
2. Convert this to a thermometer code where all lower bits are '1' when a higher bit is '1'
3. The MSB of the thermometer code directly indicates A > B
4. Equality is determined by checking if all bits are equal
5. Less-than is the complement of greater-than and equal

Advantages:
- Uses simple AND-OR logic without arithmetic
- Thermometer encoding naturally captures the priority of higher bits
- Parallel evaluation of all bit positions
- Minimal logic depth (only 2 levels for most signals)
- Easily scalable to wider comparators
