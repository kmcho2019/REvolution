Refactored Approach: Hierarchical Bitwise Comparison
1. Concept: Break down comparison into hierarchical bit-level operations
2. Key Changes:
   - Replace parallel prefix with explicit bitwise comparison hierarchy
   - Use direct assignment statements for clarity
   - Maintain same logical function with different structural implementation
3. Benefits:
   - More intuitive bit-by-bit comparison flow
   - Explicit MSB-to-LSB priority encoding
   - Clear visibility into each comparison stage
4. Implementation:
   - First compare MSBs (bit 3), then proceed to lower bits if equal
   - Use nested conditional assignments
   - Generate outputs based on highest-priority difference found
