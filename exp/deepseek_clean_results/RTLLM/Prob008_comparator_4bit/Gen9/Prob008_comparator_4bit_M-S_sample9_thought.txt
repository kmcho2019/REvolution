Simplified Approach: Direct Subtraction with Borrow Analysis
1. Concept: Use arithmetic subtraction to determine comparison results
2. Key Changes:
   - Replace hierarchical bitwise comparisons with a single subtraction operation
   - Analyze borrow bit (equivalent to carry-out) to determine A_less
   - Check for zero result to determine A_equal
   - A_greater is derived when neither A_less nor A_equal is true
3. Benefits:
   - Significant reduction in logic complexity
   - Fewer gates and shorter critical path
   - More intuitive implementation matching the problem description
4. Implementation:
   - Perform 4-bit subtraction (A - B)
   - Use borrow (carry-out) to detect A < B
   - Check if result is zero for equality
   - Derive greater-than from the other two conditions
