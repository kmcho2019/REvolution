Optimization strategy for better PPA:
1. Replace hierarchical bit-wise comparison with direct arithmetic comparison using subtraction, which synthesis tools can optimize efficiently
2. Use the subtraction result's sign bit (borrow) and zero detection to determine comparison outcomes
3. Simplify logic by:
   - Using a single 4-bit subtractor (A - B)
   - Deriving outputs directly from the subtraction result and borrow
   - Eliminating intermediate comparison signals
4. Benefits:
   - Reduced logic depth (critical path now just through subtractor)
   - Lower power from eliminating redundant computations
   - Smaller area by leveraging synthesis tool optimizations
   - Maintains mutually exclusive outputs
