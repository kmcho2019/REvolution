Simplified approach using direct arithmetic comparison:
1. Leverage Verilog's built-in comparison operators for cleaner and more efficient implementation
2. Directly compare the 4-bit vectors A and B using >, ==, and < operators
3. Let synthesis tools optimize the underlying logic
4. Benefits:
   - Eliminates complex priority encoder logic
   - Reduces gate count and critical path
   - Maintains clear, readable code
   - Still produces mutually exclusive outputs
   - More scalable for different bit widths
