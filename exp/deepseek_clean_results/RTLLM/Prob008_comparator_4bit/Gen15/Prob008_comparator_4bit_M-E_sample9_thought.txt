Novel Approach: Bit-Sliced XOR Mask with Priority Encoder
1. Key Idea:
   - Instead of traditional subtraction or bit-wise comparison, use XOR to find differing bits
   - Create a mask that identifies the most significant differing bit position
   - Use priority encoding to determine comparison result based on MSB difference

2. Implementation Strategy:
   - First compute bitwise XOR between A and B to find differing bits
   - Generate a mask that isolates the MSB where A and B differ
   - For equal inputs, all XOR bits will be 0
   - For unequal inputs, use the mask to compare corresponding bits in A and B

3. Advantages:
   - Eliminates carry chain dependency (faster than subtraction)
   - Parallel XOR operation enables early evaluation
   - Priority encoding naturally handles magnitude comparison
   - Scales well to wider bit widths

4. Output Logic:
   - A_equal when all XOR bits are 0
   - A_greater when MSB difference has A=1 and B=0
   - A_less when MSB difference has A=0 and B=1
