Simplified Approach: Subtraction-Based Comparison
1. Concept: Use arithmetic subtraction to determine comparison results
2. Key Simplifications:
   - Eliminate hierarchical bitwise logic in favor of direct subtraction
   - Use subtraction result's sign bit (borrow) for A_less
   - Use zero detection for A_equal
   - Derive A_greater from the other two signals
3. Benefits:
   - Reduced logic complexity (only one subtractor needed)
   - Clearer implementation matching problem description
   - Maintains mutually exclusive outputs
4. Implementation:
   - Compute 5-bit difference (A - B) with explicit sign extension
   - Use MSB (sign bit) for A_less
   - Check all bits zero for A_equal
   - A_greater is when neither less nor equal
