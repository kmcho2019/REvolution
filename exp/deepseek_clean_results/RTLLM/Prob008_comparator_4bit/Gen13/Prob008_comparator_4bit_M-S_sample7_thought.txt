Simplified approach using direct arithmetic comparison:
1. Leverage Verilog's built-in comparison operators for cleaner and more efficient implementation
2. Directly compute the three comparison outputs using simple relational operations
3. Benefits:
   - Eliminates complex bit-wise comparison logic
   - Reduces gate count and critical path
   - More readable and maintainable code
   - Synthesis tools can optimize the implementation automatically
4. The outputs remain mutually exclusive by construction
