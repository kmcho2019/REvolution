Simplified approach using direct arithmetic comparison:
1. Instead of bit-wise comparison and priority encoding, use direct 4-bit arithmetic comparison
2. Compute A > B, A == B, and A < B directly using Verilog comparison operators
3. Let synthesis tool optimize the implementation
4. Benefits:
   - Much simpler and cleaner code
   - Reduced logic depth (single comparison operation)
   - Synthesis tool can choose most efficient implementation
   - Maintains mutually exclusive outputs
   - Scales easily to any bit width
