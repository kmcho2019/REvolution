Refactored Design Idea: Priority-Encoded Comparison with Parallel Logic

This refactoring maintains the same comparison logic but improves structure by:
1. Using continuous assignments (assign) for all outputs
2. Calculating bit-wise equality in parallel
3. Implementing priority comparison using nested conditional operators
4. Maintaining mutual exclusivity through direct logic relationships
5. Improving readability with hierarchical signal naming

Key Improvements:
- Eliminates intermediate wires for cleaner code
- Uses ternary operators for priority comparison
- More straightforward logic flow from MSB to LSB
- Maintains same functionality while being more concise
