Simplified Design Idea: Direct Bitwise Comparison with Priority Encoding

This optimized design:
1. Uses direct bitwise XOR for equality check (all bits equal)
2. Implements greater-than comparison using priority encoding from MSB to LSB
3. Derives less-than from the other two outputs (mutual exclusivity)
4. Eliminates redundant logic by:
   - Removing intermediate wires
   - Combining operations where possible
   - Using simpler Boolean expressions
5. Maintains same functionality with reduced logic depth and gate count

Key Improvements:
- Single AND operation for equality (same as original)
- Simplified greater-than logic with priority encoding
- Direct derivation of less-than from existing signals
- Reduced logic levels for faster operation
