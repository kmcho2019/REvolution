Optimization strategy:
1. Replace hierarchical bit-wise comparison with direct arithmetic comparison for better PPA:
   - Use simple subtraction (A - B) and examine the result's sign bit and zero condition
   - This reduces logic depth and eliminates redundant bit-wise operations
   - Synthesis tools can optimize arithmetic comparisons efficiently

2. Key improvements:
   - Single subtraction operation instead of multiple bit-wise comparisons
   - Simplified output logic using the subtraction result
   - Maintain mutually exclusive outputs
   - Better critical path (only one subtraction operation)
   - Reduced area (fewer gates needed)

3. Benefits:
   - Lower power due to reduced switching activity
   - Smaller area from simplified logic
   - Potentially better timing with shorter critical path
   - More scalable solution (works for any bit width)
