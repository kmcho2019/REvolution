The current implementation is already quite efficient, but we can simplify it further by:
1. Removing the intermediate 'equal' wire since it's only used once
2. Directly computing A_greater from the other two outputs since they're mutually exclusive
3. Using a single expression for each output without intermediate signals

This reduces:
- Number of wires from 2 to 0
- Number of operations by combining expressions
- Maintains the same functionality with mutually exclusive outputs
