Instead of using arithmetic subtraction, we can implement a hierarchical bit-wise comparator that:
1. Compares bits from MSB to LSB (priority to higher bits)
2. Uses parallel evaluation of each bit pair
3. Implements early termination when inequality is found
4. Uses a priority encoder to determine the final result

Advantages:
- No arithmetic operation needed (reduces power)
- Early termination saves switching activity
- Naturally handles the priority of higher bits
- Simple combinational logic with clear critical path
