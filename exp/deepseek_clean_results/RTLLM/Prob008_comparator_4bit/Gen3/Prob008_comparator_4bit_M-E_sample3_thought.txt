Instead of using the built-in comparison operators, we'll implement a hierarchical bit-by-bit comparison approach. This method:
1. Compares bits from MSB to LSB, stopping at the first unequal bit pair
2. Uses a priority encoder style approach to determine the relationship
3. Generates intermediate signals for each bit position
4. Combines these signals to produce the final outputs
5. Maintains mutual exclusivity by construction

Advantages:
- More transparent implementation showing the actual comparison logic
- Potentially better for synthesis optimization as it breaks down the operation
- Easier to extend to wider comparators
- Clear critical path from MSB to LSB
