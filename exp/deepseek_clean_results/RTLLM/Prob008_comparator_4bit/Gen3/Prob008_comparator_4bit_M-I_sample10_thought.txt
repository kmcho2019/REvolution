To optimize the comparator further, we'll implement a single subtraction-based approach that generates all outputs from the same operation. This reduces logic duplication and improves PPA metrics:

1. Perform a single subtraction operation (A - B) using 4-bit arithmetic
2. Extract the borrow (carry-out) and zero flags from the result
3. Derive outputs:
   - A_less = borrow (MSB of subtraction result)
   - A_equal = zero flag (all bits zero)
   - A_greater = neither borrow nor zero
This approach uses only one arithmetic operation and shares logic between outputs, reducing area and power while maintaining the same timing characteristics.
