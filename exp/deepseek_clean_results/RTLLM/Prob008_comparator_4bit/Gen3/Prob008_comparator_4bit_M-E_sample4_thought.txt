Here's a novel hierarchical comparator architecture that leverages bit-wise comparison from MSB to LSB:

1. Bit-wise Priority Comparison:
   - Compare bits from MSB (bit 3) to LSB (bit 0) sequentially
   - The first non-equal bit pair determines the comparison result
   - This mimics how humans compare numbers digit by digit

2. Early Termination:
   - The comparison stops at the first unequal bit pair
   - This reduces unnecessary switching activity in lower bits when result is already determined

3. Efficient Encoding:
   - Use a priority encoder approach where higher bits dominate
   - Only three possible states at each bit position (greater, equal, less)
   - Propagate the state until first non-equal comparison

4. Power Optimization:
   - Lower bits don't toggle when higher bits have determined the result
   - Reduced capacitance switching leads to lower dynamic power

This approach provides:
- Potentially better power efficiency for certain input patterns
- More intuitive design that matches human comparison logic
- Same worst-case timing as conventional designs
