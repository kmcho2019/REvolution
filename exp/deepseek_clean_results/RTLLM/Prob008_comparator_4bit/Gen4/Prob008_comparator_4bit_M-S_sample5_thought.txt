The current implementation uses three separate comparison operations (==, >) which creates redundant logic. We can simplify this by:
1. Using a single subtraction operation (A - B) and examining the result's sign and zero flags
2. A_equal is simply (A == B)
3. A_greater is when subtraction doesn't underflow and result isn't zero
4. A_less is when subtraction underflows (borrow occurs)
This approach reduces the logic to one arithmetic operation and simpler flag checks.
