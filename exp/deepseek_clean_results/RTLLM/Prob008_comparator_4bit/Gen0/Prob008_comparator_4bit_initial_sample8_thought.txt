The 4-bit comparator can be implemented by performing a bit-wise comparison starting from the most significant bit (MSB). The comparison logic follows these rules:
1. If at any bit position, A's bit is 1 and B's bit is 0, then A > B
2. If at any bit position, A's bit is 0 and B's bit is 1, then A < B
3. If all bits are equal, then A == B

We'll implement this by:
1. Comparing bits from MSB to LSB
2. Using intermediate signals to track the comparison state
3. Generating final outputs based on the comparison results
