The 4-bit comparator can be implemented by performing a bitwise comparison starting from the most significant bit (MSB) to the least significant bit (LSB). The comparison logic follows these rules:
1. If at any bit position, A's bit is 1 and B's bit is 0, then A > B (A_greater = 1)
2. If at any bit position, A's bit is 0 and B's bit is 1, then A < B (A_less = 1)
3. If all bits are equal, then A = B (A_equal = 1)
The outputs are mutually exclusive, so priority is given to higher bits when determining the result.
