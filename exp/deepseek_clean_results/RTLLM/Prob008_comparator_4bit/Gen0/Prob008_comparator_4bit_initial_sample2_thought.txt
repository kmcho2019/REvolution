The 4-bit comparator can be implemented by performing a subtraction operation (A - B) and analyzing the result. The key insights are:
1. If A == B, the subtraction result will be zero (A_equal)
2. If A > B, there will be no borrow and result is non-zero (A_greater)
3. If A < B, there will be a borrow (A_less)

We'll implement this using combinational logic by:
1. Performing bitwise subtraction from MSB to LSB
2. Tracking borrow propagation between bits
3. Generating outputs based on final borrow and zero result
