The 4-bit comparator can be implemented by performing a subtraction operation (A - B) and analyzing the result. The key observations are:
1. If A == B, the subtraction result will be zero (A_equal)
2. If A > B, there will be no borrow and result is non-zero (A_greater)
3. If A < B, there will be a borrow (A_less)

We'll implement this by:
1. Performing bitwise subtraction from LSB to MSB
2. Propagating borrow between bits
3. Generating final outputs based on the final borrow and zero result
