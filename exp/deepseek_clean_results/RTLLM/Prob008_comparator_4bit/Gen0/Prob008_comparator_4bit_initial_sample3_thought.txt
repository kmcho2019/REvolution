The 4-bit comparator can be implemented by performing a subtraction operation (A - B) and analyzing the result. The key observations are:
1. If A == B, the subtraction result will be 0 (A_equal)
2. If A > B, the subtraction will produce a positive result with no borrow (A_greater)
3. If A < B, the subtraction will require a borrow (A_less)

We'll implement this by:
1. Creating a 4-bit subtractor that generates a borrow-out signal
2. Using the borrow-out and zero-detect logic to determine the comparison result
3. Ensuring outputs are mutually exclusive
