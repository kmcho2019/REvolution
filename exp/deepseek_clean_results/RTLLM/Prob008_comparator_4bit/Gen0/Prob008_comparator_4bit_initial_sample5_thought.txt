The 4-bit comparator can be implemented by performing a bit-wise comparison starting from the most significant bit (MSB). For each bit position, we compare A[i] and B[i]:
1. If A[i] > B[i], then A > B overall
2. If A[i] < B[i], then A < B overall
3. If equal, move to next lower bit position
The comparison is complete when we find a bit position where A[i] ≠ B[i] or when all bits are equal.

This approach avoids actual subtraction and instead uses hierarchical comparison logic, which is more efficient in hardware.
