The 4-bit comparator can be implemented by performing a bitwise comparison starting from the most significant bit (MSB) to the least significant bit (LSB). For each bit position, we compare the corresponding bits of A and B. The comparison results propagate through the bits, and the final result is determined by the first unequal bit pair encountered from the MSB. 

The logic can be broken down as follows:
1. If A[3] > B[3], then A > B (A_greater = 1)
2. Else if A[3] < B[3], then A < B (A_less = 1)
3. Else, move to the next lower bit (A[2] vs B[2]) and repeat the comparison
4. If all bits are equal, then A == B (A_equal = 1)

This approach avoids actual subtraction and instead uses hierarchical bit comparison for efficiency.
