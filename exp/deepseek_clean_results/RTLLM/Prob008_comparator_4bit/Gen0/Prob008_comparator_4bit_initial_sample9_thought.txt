The 4-bit comparator can be implemented by performing a bitwise comparison starting from the most significant bit (MSB) to the least significant bit (LSB). The comparison logic follows these rules:
1. If at any bit position, A's bit is 1 and B's bit is 0, then A > B (A_greater)
2. If at any bit position, A's bit is 0 and B's bit is 1, then A < B (A_less)
3. If all bits are equal, then A == B (A_equal)
The outputs are mutually exclusive, so we prioritize the comparison from MSB to LSB and stop at the first unequal bit.
