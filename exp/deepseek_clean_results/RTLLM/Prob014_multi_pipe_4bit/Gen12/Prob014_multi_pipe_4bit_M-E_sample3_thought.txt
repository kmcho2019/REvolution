Novel Pipeline Architecture: Bit-Serial Accumulation with Shift-Add

1. **Bit-Serial Approach**: Instead of generating all partial products simultaneously, process one multiplier bit per clock cycle. This reduces combinational logic depth.

2. **Shift-Add Pipeline**: 
   - Stage 1: Right-shift multiplier to expose next bit while left-shifting accumulated product
   - Stage 2: Conditionally add multiplicand based on current multiplier bit
   - Final stage: Accumulate final result

3. **Pipeline Benefits**:
   - Each stage has simple, balanced logic
   - Naturally fits the 2-level pipeline requirement
   - Lower power consumption as only active bits are processed each cycle

4. **Control Logic**: 
   - Uses a counter to track bit positions
   - Clears pipeline on reset
   - Valid output appears after 4 cycles (for 4-bit inputs)
