Fixed 4-bit Pipelined Multiplier Design:

Key Fixes and Improvements:
1. **Parameter Handling**: Removed unused 'size' parameter since we're specifically implementing a 4-bit multiplier
2. **Simplified Register Structure**: Reduced pipeline registers to only what's needed between stages
3. **Clear Pipeline Separation**: Explicitly shows the two-stage pipeline with proper timing
4. **Optimized Reset Logic**: Consolidated reset handling for better synthesis
5. **Direct Width Specification**: Used explicit 4-bit/8-bit widths instead of parameterized sizes

Operation Flow:
1. First Stage (Cycle 1):
   - Generate all partial products in parallel (shifted versions of mul_a)
   - Apply multiplier bit masks
   - Store in first pipeline register

2. Second Stage (Cycle 2):
   - Sum all registered partial products
   - Output final result

Reset Behavior:
- All registers clear synchronously on active-low reset
- Pipeline naturally refills in two cycles after reset
