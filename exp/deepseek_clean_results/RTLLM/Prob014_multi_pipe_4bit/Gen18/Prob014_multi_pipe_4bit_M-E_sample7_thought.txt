Novel Architecture: Bit-Serial Pipeline Multiplier with Shift-Accumulate

Key Innovations:
1. **Bit-Serial Processing**: Processes multiplier bits sequentially rather than in parallel
2. **Single Adder Architecture**: Reuses the same adder for all partial products
3. **Shift-Accumulate Technique**: Accumulates shifted multiplicand values over cycles
4. **Variable Pipeline Depth**: Naturally extends to any bit width without structural changes

Operation Flow:
1. **Cycle 1**: Process LSB (bit 0) - add multiplicand if bit is set
2. **Cycle 2**: Shift intermediate result and process bit 1
3. **Cycle 3**: Shift intermediate result and process bit 2
4. **Cycle 4**: Shift intermediate result and process bit 3
5. **Cycle 5**: Final result available

Advantages:
- Reduced area (single adder)
- Scalable to any bit width
- Natural pipeline behavior
- Lower power consumption (only active when multiplier bit is set)
