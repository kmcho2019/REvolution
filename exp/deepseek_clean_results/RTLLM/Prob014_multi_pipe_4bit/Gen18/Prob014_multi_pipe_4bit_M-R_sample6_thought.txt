Refactored 4-bit Pipelined Multiplier Design:

Key Changes:
1. **Structural Pipeline Implementation**: Replaced procedural blocks with continuous assignments for pipeline registers
2. **Explicit Zero Extension**: Added dedicated zero-extension step for clarity
3. **Simplified Partial Product Generation**: Used bitwise AND with shifted versions of extended multiplicand
4. **Direct Register Assignments**: Eliminated intermediate wires for cleaner data flow
5. **Parameterized Zero Constants**: Improved readability with parameterized zero values

Structural Improvements:
- All pipeline stages now use continuous assignments
- Clear separation between combinational and sequential logic
- Reduced redundant zero-padding operations
- More explicit data flow through pipeline stages

Operation Flow Remains:
1. Stage 1: pp0 + pp1 (registered)
2. Stage 2: pp2 + pp3 (registered)
3. Final Output: sum of both stages
