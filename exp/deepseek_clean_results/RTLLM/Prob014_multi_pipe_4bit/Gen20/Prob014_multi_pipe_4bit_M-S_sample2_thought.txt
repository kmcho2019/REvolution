Simplified 4-bit Pipeline Multiplier Design:

Key Improvements:
1. **Single Always Block**: Combine both pipeline stages into a single always block for cleaner code
2. **Direct Output Assignment**: Eliminate intermediate stage2_sum register by directly computing final output
3. **Reduced Register Count**: Only maintain one pipeline register (stage1_sum) instead of two
4. **Maintained Functionality**: Same multiplication behavior and pipeline timing
5. **Simplified Logic**: Partial products are still computed in two stages but with less overhead

Implementation Notes:
- First stage computes sum of LSB partial products (bits 0-1)
- Second stage combines with MSB partial products (bits 2-3) directly
- Same reset behavior and timing characteristics
- Reduced register usage while maintaining performance
