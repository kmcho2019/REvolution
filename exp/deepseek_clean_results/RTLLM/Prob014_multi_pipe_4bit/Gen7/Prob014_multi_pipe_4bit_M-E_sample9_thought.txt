Novel Architecture: Bit-Serial Pipeline Multiplier with Parallel Accumulation

Key Innovations:
1. **Bit-Serial Processing**: Process one multiplier bit per clock cycle to reduce combinational logic
2. **Parallel Accumulation**: Use shift registers to accumulate partial products in parallel
3. **Two-Stage Pipeline**: First stage generates shifted multiplicand, second stage accumulates
4. **Resource Sharing**: Reuse the same adder for all accumulation steps
5. **Early Zero Detection**: Skip unnecessary additions when multiplier bit is zero

Implementation Approach:
1. Extend inputs with zeros for correct bit alignment
2. Generate shifted versions of multiplicand in first pipeline stage
3. Conditionally accumulate shifted values based on multiplier bits
4. Use registers to store intermediate results between stages
5. Final output combines all accumulated partial products

Advantages:
- Reduced combinational path compared to parallel multiplier
- Lower power consumption due to conditional accumulation
- Scalable to larger bit widths with same architecture
- Clear pipeline separation for better timing
