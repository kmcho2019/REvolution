Simplified Pipeline Multiplier Design:

Key Improvements:
1. Eliminate redundant zero-extension since 4-bit * 4-bit multiplication naturally fits in 8 bits
2. Combine partial product generation and accumulation into single expressions
3. Reduce register count by directly accumulating in pipeline stages
4. Maintain same 2-stage pipeline structure but with cleaner implementation
5. Keep same reset behavior and timing characteristics

Advantages:
- Fewer intermediate registers (reduced area)
- Same cycle timing (no performance penalty)
- Clearer data flow
- Maintains identical functionality
- Easier to verify
