Improved 4-bit Pipelined Multiplier Design:

Key Improvements:
1. **Balanced Adder Tree**: Replace linear addition with tree structure to reduce critical path
2. **Conditional Partial Products**: Only generate active partial products to save power
3. **Parameter Visibility**: Ensure 'size' parameter is properly exposed for testbench access
4. **Register Optimization**: Combine pipeline registers into a more compact structure
5. **Early Output Registration**: Register intermediate sums in first stage to improve timing

Operation Flow:
1. First Stage (Cycle 1):
   - Generate only active partial products (when mul_b[i]=1)
   - Register intermediate sums (pp0+pp1 and pp2+pp3)

2. Second Stage (Cycle 2):
   - Sum the intermediate results
   - Register final output

Reset Behavior:
- Maintain synchronous reset with all registers clearing
- More efficient reset implementation
