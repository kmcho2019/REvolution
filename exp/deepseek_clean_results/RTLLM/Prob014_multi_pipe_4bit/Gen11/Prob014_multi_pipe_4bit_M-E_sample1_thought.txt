Novel Architecture Idea: Bit-Serial Pipeline Multiplier

This design implements a bit-serial approach to pipeline multiplication, which:
1. Processes one multiplier bit per clock cycle
2. Uses a shift-and-add algorithm in a pipelined fashion
3. Reduces hardware complexity by reusing the same adder
4. Implements a 4-stage pipeline (one stage per bit)
5. Uses carry-save addition for better timing

Key Features:
- Each pipeline stage handles one bit of the multiplier
- Accumulator shifts left each cycle (implicit multiplication by 2)
- Only one adder is needed for all operations
- Carry bits are preserved between stages
- Final conversion from carry-save to binary happens in last stage
