To simplify the 4-bit pipeline multiplier while maintaining functionality:

1. Remove unnecessary extension of multiplier (mul_b) - only multiplicand (mul_a) needs extension for shifting
2. Simplify partial product generation by directly using mul_b bits (no need for registered partial products)
3. Maintain 2-stage pipeline:
   - Stage 1: Calculate all partial products and add first two (pp0 + pp1)
   - Stage 2: Add remaining partial products (pp2 + pp3) and combine with stage 1 result
4. Keep reset functionality clean
5. Reduce register usage by combining operations where possible

Key simplifications:
- Eliminate separate partial product registers
- Remove intermediate sum registers by directly chaining operations
- Simplify input handling
- Maintain same latency (2 cycles) with cleaner data flow
