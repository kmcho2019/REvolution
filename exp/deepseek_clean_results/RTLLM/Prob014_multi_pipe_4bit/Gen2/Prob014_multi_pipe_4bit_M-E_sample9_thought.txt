Novel architectural idea: Bit-serial pipeline multiplier with accumulator shift register

This approach implements a 4-bit multiplier using a bit-serial architecture with the following key features:
1. Processes one multiplier bit per clock cycle (4 cycles total)
2. Uses a shift-accumulate technique to sum partial products
3. Eliminates the need for multiple adders by reusing a single accumulator
4. Implements pipelining by registering intermediate results each cycle
5. Reduces hardware complexity compared to parallel multiplier implementations

Advantages:
- Lower area footprint (single adder instead of adder tree)
- Naturally pipelined operation
- Easily scalable to larger bit widths
- Reduced switching activity (only active when processing non-zero bits)
- Clear separation between combinational and sequential logic
