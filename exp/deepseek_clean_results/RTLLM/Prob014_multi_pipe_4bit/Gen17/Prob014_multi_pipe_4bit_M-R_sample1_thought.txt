Refactored 4-bit Pipelined Multiplier Design:

Key Refactoring Changes:
1. **Combinational Logic Separation**: Moved all partial product generation and addition to continuous assignments for clarity
2. **Explicit Pipeline Stages**: Created distinct stage registers with clear naming
3. **Parameter Visibility**: Ensured parameter is properly accessible at module level
4. **Simplified Control Flow**: Eliminated procedural blocks where combinational logic suffices

Design Improvements:
- All combinational logic now uses assign statements for better readability
- Pipeline stages explicitly named (stage1, stage2) for better documentation
- Maintained same 2-cycle latency but with clearer structure
- Reduced register usage by combining intermediate sums
- Kept same reset behavior and timing characteristics
