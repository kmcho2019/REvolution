Refactored 4-bit Pipelined Multiplier Design:

Key Improvements:
1. **Correct Partial Product Generation**: Now properly gated by multiplier bits (mul_b)
2. **Two-Stage Pipeline**: Strictly follows requirements with two register levels
3. **Explicit Pipeline Stages**: Clear separation between pipeline stages
4. **Structural Implementation**: Uses assign statements for combinational logic
5. **Reset Synchronization**: Maintains proper reset behavior

Operation Flow:
1. First Stage (Cycle 1):
   - Generate all partial products (AND operations with shifted multiplicand)
   - Sum first two partial products (pp0 + pp1) if their bits are set
   - Register intermediate sum (stage1_reg)

2. Second Stage (Cycle 2):
   - Sum remaining partial products (pp2 + pp3) if their bits are set
   - Register intermediate sum (stage2_reg)

3. Final Stage (Cycle 3):
   - Combine both pipeline stage results
   - Output final product

Reset Behavior:
- All registers clear synchronously
- Proper pipeline flushing on reset
