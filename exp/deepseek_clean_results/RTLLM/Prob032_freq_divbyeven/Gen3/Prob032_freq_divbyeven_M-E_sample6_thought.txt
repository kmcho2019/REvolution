Novel approach using a state machine instead of a simple counter:
1. Instead of counting cycles, implement a state machine that explicitly tracks the rising and falling edges of the divided clock
2. Use two states: HIGH and LOW, each lasting NUM_DIV/2 cycles
3. This makes the design more explicit about its behavior and easier to modify for different duty cycles
4. The state transitions occur at the midpoint of each half-cycle
5. Added parameter validation and automatic width calculation
6. Uses enumerated types for better code readability and maintainability
