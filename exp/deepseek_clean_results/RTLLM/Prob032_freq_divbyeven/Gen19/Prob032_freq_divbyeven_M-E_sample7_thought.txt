Novel approach using Gray code counter with edge detection:
1. Instead of a binary counter, use a Gray code counter to reduce switching activity and power consumption
2. Implement edge detection logic to toggle the output clock only when the Gray code wraps around
3. Use a parameter to specify the division factor (must be even)
4. The Gray code naturally handles the wrap-around condition without explicit comparison
5. Maintain synchronous reset for better timing characteristics
6. The design will be more power-efficient while maintaining the same functionality
