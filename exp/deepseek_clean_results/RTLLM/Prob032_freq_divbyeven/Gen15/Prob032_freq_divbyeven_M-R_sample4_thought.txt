Refactoring strategy:
1. Maintain same functionality but implement with continuous assignment for the output
2. Use combinational logic to generate the toggle signal
3. Keep the same counter structure but move the comparison logic to a separate always block
4. Generate the divided clock using an XOR operation between the toggle signal and previous output
5. This approach separates the counter logic from the output generation
6. Still maintain parameter validation and active-low reset

Key changes:
- Output generation moved to continuous assignment
- Toggle signal generated when counter reaches midpoint
- XOR operation creates clean 50% duty cycle
- Same parameter validation and counter width
- More modular design with separated counter and output logic
