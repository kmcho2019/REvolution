Novel Architecture Idea:
1. Implement a shift register based frequency divider instead of a counter
2. Use a circular shift register where the length equals NUM_DIV/2
3. The MSB of the shift register directly drives the clk_div output
4. Reset initializes the shift register to have a single '1' at LSB
5. Each clock cycle rotates the '1' through the register
6. When '1' wraps around, it toggles the output clock
7. Eliminates need for explicit counter comparisons
8. Naturally enforces even division since register length is NUM_DIV/2

Advantages:
- No arithmetic operations needed during counting
- Simple terminal condition detection (just check MSB)
- Inherently synchronous design
- Parameter validation built into register size
