Refactoring strategy:
1. Replace the sequential always block with combinational logic for counter and clock generation
2. Use continuous assignments (assign) for the output clock
3. Implement the counter as a separate always block
4. Maintain same functionality:
   - Even division checking via generate block
   - Same reset behavior
   - Identical frequency division ratio
5. Benefits:
   - Separates combinational and sequential logic clearly
   - Makes output clock generation more explicit
   - Easier to add additional combinational logic if needed
   - Maintains same synthesis results
