The refactored design will:
1. Maintain the same frequency division functionality but implement it using combinational logic with an assign statement
2. Use a counter that automatically rolls over when reaching NUM_DIV-1
3. Generate the divided clock by comparing the counter value with NUM_DIV/2
4. Keep the active-low reset functionality
5. Use the same parameter structure but implement the logic differently

Key changes:
- Replace the sequential always block with combinational assign for clk_div
- Use a separate always block just for the counter
- The counter now counts full cycles (0 to NUM_DIV-1) and rolls over
- clk_div toggles when counter is in the upper half of the count range
