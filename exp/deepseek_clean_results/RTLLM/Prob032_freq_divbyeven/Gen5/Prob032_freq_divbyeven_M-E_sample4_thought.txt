Novel architectural approach:
1. Instead of using a counter with dynamic width, use a fixed-width counter that's large enough to handle maximum expected division (16-bit in this case)
2. Implement a phase accumulator approach where we add a fixed increment value each cycle
3. Use the MSB of the accumulator as the divided clock output
4. The increment value is calculated as (2^N)/NUM_DIV where N is accumulator width
5. This creates a numerically controlled oscillator (NCO) style frequency divider
6. Advantages:
   - Fixed hardware resources regardless of division ratio
   - No need for explicit counter comparisons
   - Naturally produces 50% duty cycle for even divisions
   - Easily scalable to very large division ratios
7. Reset behavior clears the accumulator and output
