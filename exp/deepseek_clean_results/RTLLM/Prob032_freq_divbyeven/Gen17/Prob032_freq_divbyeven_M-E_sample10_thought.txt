Novel architectural idea: 
1. Instead of using a traditional counter-based approach, implement a shift register-based frequency divider.
2. The shift register will be initialized with a pattern that has exactly one '1' and the rest '0's.
3. The length of the shift register equals NUM_DIV/2, ensuring even division.
4. On each clock cycle, the '1' circulates through the shift register.
5. The output clock toggles whenever the '1' wraps around, creating a perfect 50% duty cycle.
6. Advantages:
   - Eliminates the need for comparison logic (reduces combinational path)
   - Naturally handles the division factor without arithmetic operations
   - Simplifies reset initialization
   - More power-efficient as only one bit changes per cycle
