Novel approach using Gray code counter for frequency division:

1. Instead of a binary counter, use a Gray code counter for reduced switching activity and power savings
2. Implement a parameterized even division factor with validation
3. Use a state machine approach with two states (HIGH and LOW) for the output clock
4. Transition between states when Gray counter reaches half of NUM_DIV
5. Maintain 50% duty cycle by toggling at NUM_DIV/2 intervals
6. Gray code counter automatically rolls over, simplifying control logic
7. Reset initializes both counter and state machine
8. Includes parameter validation to ensure NUM_DIV is even

Key advantages:
- Reduced power consumption due to Gray code counter
- Simplified rollover logic
- Maintains all required functionality
- Clean state-based approach for output generation
