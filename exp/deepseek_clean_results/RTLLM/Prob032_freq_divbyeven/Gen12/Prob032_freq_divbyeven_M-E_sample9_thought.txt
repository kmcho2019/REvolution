Novel approach using a down-counter with edge detection:
1. Instead of counting up, use a down-counter initialized to NUM_DIV/2
2. Detect when counter reaches zero to toggle the output clock
3. Reset counter to NUM_DIV/2 on zero detection
4. This reduces comparison logic since we only need to detect zero
5. Maintains 50% duty cycle for even division
6. Uses same interface but different internal implementation
7. More efficient as it eliminates the need for two comparison points
