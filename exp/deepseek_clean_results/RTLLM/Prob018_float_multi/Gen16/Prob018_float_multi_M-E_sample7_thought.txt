Novel pipelined floating-point multiplier design:
1. Three-stage pipeline for better throughput (Input, Multiply, Normalize/Round)
2. Early termination detection in first stage to bypass unnecessary operations
3. Optimized rounding using LSB prediction to reduce logic complexity
4. Shared exponent calculation path with overflow/underflow pre-check
5. Implicit normalization through leading-one detection
6. Power-optimized design with clock gating for idle stages
7. Reduced-width intermediate calculations where possible
