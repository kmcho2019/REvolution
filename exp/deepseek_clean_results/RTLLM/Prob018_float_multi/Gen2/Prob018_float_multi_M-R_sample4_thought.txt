Refactored design approach:
1. Convert state machine to explicit one-hot encoding for better timing
2. Replace sequential logic with combinational where possible
3. Use continuous assignments for special case detection and output formation
4. Move mantissa multiplication to a separate always block for clarity
5. Implement exponent calculation as a pure combinational path
6. Simplify rounding logic using a dedicated function
7. Add explicit handling of denormal numbers
8. Use parameters for all magic numbers

Key improvements:
- More efficient state encoding (one-hot)
- Clear separation of combinational and sequential logic
- Better timing with parallel paths
- More readable special case handling
- Explicit denormal number support
