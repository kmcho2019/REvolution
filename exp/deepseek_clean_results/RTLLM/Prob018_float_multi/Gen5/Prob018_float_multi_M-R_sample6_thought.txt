Refactoring Strategy:
1. Convert to Continuous Assignments:
   - Replace sequential logic with combinational where possible
   - Use assign statements for static computations
   - Keep pipeline control as sequential logic

2. Restructure State Machine:
   - Simplify to 2-stage pipeline (decode + execute)
   - Combine special case handling into single stage
   - Move multiplication to dedicated stage

3. Optimize Datapath:
   - Pre-compute common expressions
   - Use wider registers for intermediate results
   - Simplify rounding logic

Key Improvements:
- Reduced pipeline stages for lower latency
- More efficient use of combinational logic
- Clearer separation of control and datapath
- Maintained full IEEE-754 compliance
- Improved timing with parallel computations
