Refactoring Strategy:
1. State Machine Simplification: Replace the counter-based state machine with explicit state variables for better readability and control
2. Combinational Logic Extraction: Move all combinational logic outside always blocks using continuous assignments
3. Pipeline Optimization: Flatten the pipeline stages into separate always blocks for each stage
4. Special Case Handling: Implement special case detection as parallel continuous assignments
5. Rounding Logic: Make rounding decision purely combinational with clear conditions
6. Output Selection: Implement output selection as a priority encoder with continuous assignments

Key Improvements:
- Clear separation of pipeline stages with dedicated always blocks
- Reduced complexity in each always block by moving logic to continuous assignments
- More explicit state transitions
- Better visibility of data flow through the pipeline
- Simplified control logic
