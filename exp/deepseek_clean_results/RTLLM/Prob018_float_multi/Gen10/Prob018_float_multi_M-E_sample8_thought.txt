Novel Architecture Features:
1. Three-stage pipeline for better throughput
2. Early normalization during multiplication (Booth algorithm)
3. Combined exponent and sign processing in first stage
4. Optimized rounding using carry-save addition
5. Special case handling in parallel with computation
6. Early overflow/underflow detection

Key Innovations:
- Booth-encoded multiplier with integrated normalization
- Parallel exponent path with speculative calculation
- Carry-save rounding adder reduces critical path
- Early termination for special cases
- Optimized datapath width (only necessary bits carried between stages)
