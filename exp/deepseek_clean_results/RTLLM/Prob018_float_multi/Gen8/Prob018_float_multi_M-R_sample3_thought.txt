Refactoring Strategy:
1. State Machine Simplification: Convert the explicit 5-stage state machine to a simpler 3-stage approach (Input, Compute, Output) while maintaining the same functionality
2. Combinational Logic: Move more logic to continuous assignments (assign) where possible to improve clarity and potentially reduce latency
3. Pipeline Optimization: Merge normalization and rounding stages into the compute stage since they are closely related
4. Special Case Handling: Implement special case detection as continuous assignments for better readability
5. Register Optimization: Reduce redundant registers by using wires for intermediate values that don't need to be stored between cycles

Key Changes:
- Simplified state machine with fewer states
- More combinational logic using assign statements
- Merged related operations into single stages
- Clearer separation between sequential and combinational logic
- Reduced register usage for intermediate values
