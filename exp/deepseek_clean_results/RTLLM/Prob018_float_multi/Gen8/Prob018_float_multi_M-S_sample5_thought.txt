Simplification Strategy:
1. Reduce pipeline stages from 5 to 3 (Extract, Multiply, Output) by combining normalization and rounding
2. Eliminate redundant registers by using direct combinatorial paths where possible
3. Simplify special case handling by moving checks to the output stage
4. Use smaller intermediate registers where possible
5. Remove explicit state machine in favor of simpler sequential logic
6. Combine normalization and rounding into a single step

Key Improvements:
- Fewer pipeline stages reduce control complexity
- Smaller register footprint saves area
- Simplified state management
- Maintains all IEEE-754 functionality
- Reduced power consumption from fewer registers
