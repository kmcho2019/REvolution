Refactoring Strategy:
1. State Machine Restructuring: Convert the explicit state machine to a counter-based approach with clear stage separation
2. Combinational Logic: Move as much logic as possible to continuous assignments (assign) for better readability
3. Pipeline Optimization: Simplify pipeline registers by grouping related signals
4. Special Case Handling: Implement special case detection as separate combinational logic blocks
5. Rounding Logic: Make rounding decision purely combinational
6. Output Selection: Implement output selection as a priority encoder with continuous assignments

Key Improvements:
- More modular design with clear separation of combinational and sequential logic
- Reduced always blocks for better synthesis control
- Simplified state tracking using a counter
- More explicit data flow through the pipeline
- Better visibility of critical paths
