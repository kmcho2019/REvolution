Improvement strategy:
1. Pipeline the design into 3 stages to improve timing (reduce critical path)
2. Optimize multiplier using radix-4 Booth encoding for better area/power
3. Simplify special case handling with early termination
4. Reduce exponent width to 8 bits where possible
5. Add explicit rounding logic for better precision
6. Optimize normalization with shared control logic
7. Reduce register usage by moving some computations to next stage

Key optimizations:
- Stage 1: Input processing and special case detection
- Stage 2: Multiplication and exponent calculation
- Stage 3: Normalization, rounding, and output formatting
- Booth encoding reduces multiplier area by ~30%
- Early special case termination saves power
- Shared normalization control reduces logic
