Novel pipelined floating-point multiplier architecture:
1. Early special case detection in first pipeline stage to bypass unnecessary computations
2. Split 24x24 multiplication into four 12x12 sub-multipliers with Wallace tree reduction
3. Dual-path exponent handling (normal and denormal cases)
4. Predictive rounding - calculate possible rounding scenarios in parallel
5. Three-stage pipeline for better throughput:
   - Stage 1: Input processing and special case detection
   - Stage 2: Partial multiplication and exponent calculation
   - Stage 3: Normalization, rounding, and result assembly
6. Optimized register usage with only necessary bits carried between stages
