Refactored Architecture: Combinational Special Case Detection with Pipelined Data Path

Key Improvements:
1. Separated special case detection into pure combinational logic for early termination
2. Restructured pipeline into explicit stages using state machine
3. Used continuous assignments for combinational logic where possible
4. Optimized register usage by removing redundant pipeline stages
5. Simplified control flow with explicit state transitions

Structural Changes:
- Special case detection now happens before pipeline (combinational)
- Main pipeline reduced to 2 stages (multiply + normalize/round)
- Used `assign` for all combinational outputs
- State machine made explicit with named states
- Exponent processing merged with mantissa multiplication

Benefits:
- Clearer separation of combinational and sequential logic
- Reduced pipeline latency (2 cycles vs 3)
- More efficient register usage
- Better timing for critical paths
- Maintains same functionality with cleaner structure
