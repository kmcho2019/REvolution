Refactoring approach:
1. Replace the sequential counter-based state machine with combinational logic using assign statements where possible
2. Break down operations into smaller, more modular components
3. Use continuous assignments for operations that don't require state
4. Maintain the same 5-cycle pipeline structure but make it more explicit
5. Use parameters for state encoding instead of raw numbers
6. Simplify special case handling with priority encoders
7. Make rounding logic more explicit and modular

Key improvements:
- More readable structure with clearly separated pipeline stages
- Reduced sequential logic where possible
- Explicit state encoding for better maintainability
- More modular special case handling
- Clearer separation of normalization and rounding logic
