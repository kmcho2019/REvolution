Refactoring Strategy:
1. Combinational Logic Conversion:
   - Replace sequential pipeline with combinational logic using assign statements
   - Maintain same computation flow but without explicit state machine
   - Use intermediate wires for clarity

2. Special Case Handling:
   - Move special case detection to continuous assignments
   - Simplify control flow by prioritizing special cases

3. Exponent Calculation:
   - Compute exponent sum in one step with proper bias adjustment
   - Handle overflow/underflow as part of continuous assignments

4. Rounding Logic:
   - Implement rounding as pure combinational logic
   - Maintain IEEE-754 round-to-nearest-even rules

Key Improvements:
- Eliminates clock dependency for purely combinational operation
- Reduces latency from 3 cycles to immediate output
- Simplifies control flow while maintaining same functionality
- Makes rounding logic more transparent
