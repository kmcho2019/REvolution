Simplified floating-point multiplier design:
1. Reduce register sizes where possible (exponents to 8 bits, product to 48 bits)
2. Combine special case detection into single expressions
3. Remove redundant checks in rounding logic
4. Simplify exponent handling by using 8-bit arithmetic with overflow detection
5. Use immediate assignment for sign bit (no need to register)
6. Reduce counter states by combining operations where possible
7. Simplify NaN/infinity handling with direct assignments

Key optimizations:
- Smaller registers reduce area
- Combined operations reduce cycle count
- Simplified logic improves timing
- Direct special case handling reduces complexity
- Maintains full IEEE 754 compliance
