Novel Architecture:
1. Use Wallace Tree for efficient mantissa multiplication (faster than array multiplier)
2. Implement 3-stage pipeline with register balancing
3. Enhanced rounding with:
   - Separate rounding unit
   - Support for all IEEE-754 rounding modes
4. Early special case detection (cycle 0)
5. Dual-path normalization (handles both left and right shifts)
6. Predictive exponent adjustment

Key Innovations:
- Wallace Tree reduces critical path in mantissa multiplication
- Dual-path normalization handles more cases efficiently
- Predictive exponent adjustment prevents pipeline stalls
- Configurable rounding modes (though only round-to-nearest-even implemented here)
- Early special case detection improves throughput
