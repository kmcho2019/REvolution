The floating-point multiplier follows IEEE-754 single-precision format which consists of:
1. Sign bit (1 bit)
2. Exponent (8 bits) with bias 127
3. Mantissa (23 bits) with implicit leading 1

Key steps:
1. Extract sign, exponent, and mantissa from inputs
2. Handle special cases (NaN, infinity, zero)
3. Add exponents and XOR signs
4. Multiply mantissas (24 bits including implicit 1)
5. Normalize result (shift mantissa and adjust exponent)
6. Round result using guard, round, and sticky bits
7. Handle overflow/underflow
8. Reconstruct final 32-bit result

The implementation uses a 3-cycle pipeline:
- Cycle 1: Input processing and special case detection
- Cycle 2: Mantissa multiplication
- Cycle 3: Normalization and rounding
