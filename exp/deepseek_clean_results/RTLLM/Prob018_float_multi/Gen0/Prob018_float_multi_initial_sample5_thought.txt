The floating-point multiplier follows IEEE 754 single-precision format (32-bit). The implementation involves:
1. Extracting sign, exponent, and mantissa from inputs
2. Handling special cases (NaN, infinity, zero)
3. Adding exponents (with bias adjustment)
4. Multiplying mantissas (24-bit x 24-bit gives 48-bit product)
5. Normalizing the result (shifting mantissa and adjusting exponent)
6. Rounding using guard, round, and sticky bits
7. Handling overflow/underflow
8. Reassembling the final 32-bit result

The implementation uses a multi-cycle approach with a counter to sequence operations.
