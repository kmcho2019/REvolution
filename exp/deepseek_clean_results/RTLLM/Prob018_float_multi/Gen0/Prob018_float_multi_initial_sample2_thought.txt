The floating-point multiplier follows IEEE-754 single-precision format (32-bit) which consists of:
1 sign bit, 8 exponent bits, and 23 mantissa bits (with implicit leading 1)

Key steps:
1. Extract sign, exponent, and mantissa from inputs
2. Handle special cases (NaN, infinity, zero)
3. Add exponents (with bias adjustment)
4. Multiply mantissas (24-bit x 24-bit = 48-bit product)
5. Normalize result (shift mantissa and adjust exponent)
6. Round result (using guard, round, sticky bits)
7. Handle overflow/underflow
8. Combine sign, exponent, mantissa into final result

Implementation uses a 3-cycle pipeline:
Cycle 1: Input processing and special case detection
Cycle 2: Mantissa multiplication
Cycle 3: Normalization and rounding
