Refactored Architecture: Combinational Special Case Detection + Pipelined Datapath

Key Changes:
1. Separated special case detection into pure combinational logic
2. Restructured pipeline as explicit 3-stage shift register
3. Replaced always blocks with assign statements where possible
4. Simplified state machine using direct stage counter
5. Optimized exponent handling with early bias subtraction
6. Used explicit pipeline registers for better timing control

Improvements:
- Clearer separation of combinational and sequential logic
- More explicit pipeline structure
- Reduced register usage in some paths
- Better timing for critical paths
- More maintainable structure
