Refactored Architecture: Combinational Logic with Explicit Pipeline Stages

Key Improvements:
1. Replaced sequential always blocks with explicit pipeline registers and combinational logic
2. Separated special case detection into dedicated combinational blocks
3. Used assign statements for clearer data flow visualization
4. Restructured state machine into explicit pipeline stages with registered outputs
5. Optimized exponent handling by using 8-bit operations with overflow detection
6. Simplified mantissa multiplication by breaking into explicit partial products

Structural Changes:
- Special case detection moved to dedicated combinational block
- Pipeline stages made explicit with registered outputs
- All intermediate calculations expressed as continuous assignments
- Rounding logic simplified and combined
- Overflow/underflow detection optimized

Advantages:
- Clearer data flow through explicit combinational paths
- Better timing predictability with registered outputs
- More efficient exponent handling
- Simplified rounding logic
- Easier to modify pipeline depth
