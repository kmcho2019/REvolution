Simplification Strategy:
1. Remove pipeline stages - use single-cycle multiplication since modern FPGAs/ASICs can handle 24x24 multiplies in one cycle
2. Simplify state machine to just 3 states (IDLE, CALC, OUTPUT)
3. Reduce internal registers by calculating values combinatorially when possible
4. Remove redundant special case detection logic
5. Simplify exponent handling by using 8 bits directly (with overflow detection)
6. Combine normalization and rounding into a single step
7. Remove clock gating and one-hot encoding for simpler control logic

Key Changes:
- Single-cycle multiplier using built-in * operator
- Direct exponent calculation without intermediate registers
- Simplified state machine with clear progression
- Reduced register count by eliminating pipeline stages
- Maintain full IEEE-754 compliance with proper special case handling
