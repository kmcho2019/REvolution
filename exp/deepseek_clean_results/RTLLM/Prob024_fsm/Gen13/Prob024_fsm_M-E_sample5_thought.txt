Here's a novel approach using a shift register combined with pattern matching logic:

1. Shift Register Approach:
   - Use a 5-bit shift register to track the last 5 input bits
   - This eliminates the need for explicit state transitions and reduces control logic

2. Parallel Pattern Matching:
   - Compare the shift register contents directly with the target pattern (10011)
   - This allows for continuous detection without state machine overhead

3. Edge Cases Handling:
   - Reset clears the shift register
   - New inputs shift in on every clock edge

4. Advantages:
   - Simpler control logic compared to FSM
   - Easily extendable to longer patterns
   - Clear relationship between input history and output
   - No need to manage complex state transitions

5. Implementation:
   - 5-bit shift register (reg [4:0] history)
   - Combinational match detection
   - Synchronous reset behavior
