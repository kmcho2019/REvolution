Novel Architectural Idea: Shift Register with Parallel Matching
1. Instead of traditional FSM states, use a 5-bit shift register to track the last 5 input bits
2. Implement parallel matching logic that compares the shift register contents with target pattern "10011"
3. Use a counter to track valid sequence length for partial matches
4. Edge detection on input changes to trigger evaluation
5. Reset handling clears the shift register and counter

Key Advantages:
- Eliminates explicit state transitions by using shift register history
- Parallel comparison simplifies detection logic
- Naturally handles continuous input streams
- Easily extensible to longer patterns by increasing register size
- Clear separation between history tracking and pattern matching
