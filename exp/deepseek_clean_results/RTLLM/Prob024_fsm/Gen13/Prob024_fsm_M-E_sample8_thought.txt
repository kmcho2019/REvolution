Novel Architectural Idea: Shift Register + Parallel Comparator Approach
1. Instead of traditional FSM, use a shift register to store last 5 bits of input
2. Implement parallel comparison to detect "10011" pattern
3. Advantages:
   - Eliminates complex state transition logic
   - Naturally supports continuous detection
   - Easily extensible to longer patterns
   - Clear separation of storage and comparison logic
4. Implementation:
   - 5-bit shift register captures input history
   - Combinational comparator checks for match
   - Registered output for clean timing
   - Reset initializes shift register to all 0s
5. Benefits:
   - Simpler verification (direct pattern matching)
   - Consistent timing regardless of input sequence
   - Lower dynamic power when no matches occur
