Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding for simpler decoding logic and potentially better timing
2. Output Logic: Move MATCH generation to continuous assignment for clearer timing path
3. State Transitions: Use separate always blocks for state registers and next-state logic
4. Reset Handling: Maintain synchronous reset but simplify the reset condition
5. Continuous Detection: Keep the same detection mechanism but express it differently

Key Changes:
- One-hot state encoding (4 bits) for simpler state decoding
- Separate combinational and sequential logic blocks
- MATCH output generated directly from state and input
- Explicit state transition conditions
- Maintains same functionality with improved readability
