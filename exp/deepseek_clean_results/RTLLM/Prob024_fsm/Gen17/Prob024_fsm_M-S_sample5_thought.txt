Simplified Mealy FSM design with these optimizations:

1. State Reduction: Combine GOT1001 state into GOT1 since both transition similarly on next input (both go to GOT1 if IN=1, GOT10 if IN=0). This reduces states from 5 to 4 while maintaining functionality.

2. Direct Output Logic: Make MATCH purely combinatorial based on current state and input, eliminating need for separate state tracking of GOT1001.

3. Simplified State Encoding: Use 2-bit binary encoding for 4 states (IDLE, GOT1, GOT10, GOT100).

4. Clear State Transitions: Each state has straightforward transitions based on input value.

The key insight is that after detecting "1001", we can immediately output MATCH=1 when seeing the final "1" without needing a separate state, since the next transitions would be identical to GOT1 state.
