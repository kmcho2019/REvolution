Here's a novel approach using a shift register combined with pattern matching logic:

1. Shift Register Approach:
   - Instead of traditional FSM states, use a 5-bit shift register to track the last 5 input bits
   - This eliminates explicit state transitions and simplifies the design

2. Parallel Pattern Matching:
   - Compare the shift register contents directly with the target pattern (10011)
   - Use combinational logic to detect the match condition

3. Continuous Detection:
   - The shift register naturally handles continuous input streams
   - Each new input shifts through the register, allowing overlapping pattern detection

4. Reset Handling:
   - Clear the shift register on reset
   - Output is naturally 0 when reset is active

Advantages:
- No explicit state machine logic needed
- Simple and straightforward implementation
- Easily extensible to longer patterns
- Clear relationship between input history and output
