Novel Architectural Idea: "Sliding Window with Parallel Matching"

Key Concepts:
1. Instead of traditional FSM states, implement a 5-bit shift register to track the last 5 inputs (sliding window)
2. Use parallel comparators to detect the "10011" pattern at every clock edge
3. Add overlap detection logic to handle continuous sequences
4. Benefits:
   - Eliminates state transition complexity
   - Naturally handles continuous detection
   - Easily extensible to longer patterns
   - Parallel comparison reduces critical path compared to sequential FSM

Implementation Details:
- 5-bit shift register captures input history
- Combinational match detection compares register contents to target pattern
- Output is registered for better timing
- Reset clears the shift register
