Here's a novel approach using a shift register combined with pattern matching logic:

1. Instead of a traditional FSM, we'll use a 5-bit shift register to store the last 5 input bits.
2. The shift register updates on each clock cycle, pushing in new bits from IN.
3. Combinational logic continuously compares the shift register contents with the target pattern "10011".
4. When a match is detected, MATCH is asserted for one clock cycle.
5. This approach simplifies state management and allows for easy modification of the target pattern.

Advantages:
- More scalable for longer patterns
- Easier to modify the target sequence
- No explicit state transitions to manage
- Clear separation of storage and comparison logic
- Naturally supports continuous detection
