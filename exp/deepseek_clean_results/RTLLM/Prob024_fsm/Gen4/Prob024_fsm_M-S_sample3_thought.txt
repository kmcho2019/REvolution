To simplify the Mealy FSM while maintaining functionality:
1. Reduce the number of states by combining similar conditions
2. Use binary state encoding instead of one-hot for better area efficiency
3. Eliminate the default case since all states are explicitly handled
4. Combine state transition and output logic into a single always block for clarity
5. Maintain the same detection behavior for "10011" sequence with continuous input support

The simplified states are:
- IDLE: Initial state
- S1: Received '1'
- S10: Received '10'
- S100: Received '100'
- S1001: Received '1001'
Transitions remain similar but with more compact coding style
