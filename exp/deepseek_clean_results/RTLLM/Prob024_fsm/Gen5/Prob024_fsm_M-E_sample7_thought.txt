Here's a novel approach using a shift register combined with pattern matching logic:

1. Instead of traditional state machine states, use a 5-bit shift register to track the last 5 input bits
2. Continuously shift in new bits on each clock edge
3. Compare the shift register contents with the target pattern "10011" (binary 19)
4. Output MATCH=1 when the shift register equals the target pattern
5. Reset clears the shift register
6. This approach simplifies state transitions to simple shifting and comparison
7. Overlapping sequences are naturally handled by the shift operation

Advantages:
- More compact implementation (single register + comparator)
- Easier to modify for different patterns
- Clear relationship between input history and matching
- No complex state transition logic
