Here's a novel approach using a shift register combined with combinational pattern matching:

1. Instead of traditional state machine, use a 5-bit shift register to track last 5 inputs
2. Implement pattern matching by comparing shift register contents to target pattern
3. Add edge detection to ensure output is only active for one clock cycle
4. Use synchronous reset for better timing characteristics
5. Optimized for continuous detection with overlapping patterns

Key advantages:
- More compact implementation than FSM
- Easily extensible to detect other patterns by changing comparator
- Clear relationship between input history and output
- Efficient overlapping pattern detection
- Reduced state transitions compared to FSM approach
