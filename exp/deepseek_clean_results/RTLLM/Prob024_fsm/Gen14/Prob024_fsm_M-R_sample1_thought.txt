Refactoring Strategy:
1. Output Logic Change: Move MATCH assignment to continuous assignment (assign) for clearer combinational logic
2. State Encoding: Switch to one-hot encoding for potentially better timing at the cost of slightly more area
3. State Transitions: Restructure as parallel case statements for each state transition
4. Reset Handling: Keep synchronous reset but simplify state initialization
5. Direct State Transitions: Make each state's transition logic independent for better readability

Key Improvements:
- One-hot encoding improves timing critical paths
- Continuous assignment makes output logic more visible
- Parallel state transition structure is easier to modify
- Maintains same sequence detection behavior
- Still supports continuous input detection
