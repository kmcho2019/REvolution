Instead of using a pure FSM approach, I'll implement a hybrid solution that combines:
1. A 5-bit shift register to capture the last 5 input bits
2. A compact validator FSM that checks the shift register contents
3. Overlap detection for continuous pattern matching

Key innovations:
- Shift register maintains history of inputs (enables parallel pattern checking)
- Small FSM only needs to validate when potential match starts (reduces state transitions)
- Built-in overlap handling for continuous detection
- Output is purely combinational from pattern match (true Mealy behavior)
- Reduced state space compared to traditional FSM approach
