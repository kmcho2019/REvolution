Refactoring the Mealy FSM with these key improvements:

1. State Encoding: Keep binary encoding but make states explicit and non-overlapping for better clarity and glitch prevention.

2. Output Logic: Move the MATCH generation into the combinational always block to ensure clean timing and avoid potential glitches from separate assign statements.

3. Reset Handling: Explicitly handle reset in both sequential and combinational logic for robustness.

4. State Transitions: Simplify the transition logic by:
   - Making all state transitions explicit
   - Removing the shared state encoding
   - Adding default case for safety

- Clear 4-state binary encoding (no state reuse)
