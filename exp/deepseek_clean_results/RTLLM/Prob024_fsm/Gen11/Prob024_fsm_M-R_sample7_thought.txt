Refactoring Strategy:
1. Output Logic Separation: Move MATCH generation to a continuous assignment for clearer timing
2. State Encoding: Keep binary encoding but make states more explicit with localparam
3. Combinational Logic: Use assign statements for next_state and next_match to simplify always block
4. State Transitions: Break down into separate always blocks for state and output for better readability
5. Reset Handling: Maintain synchronous reset but simplify the logic

Key Improvements:
- Clear separation of combinational and sequential logic
- Direct assign for output makes timing more predictable
- Simplified state transition logic
- Maintains same functionality with better structure
- Easier to modify for future sequence changes
