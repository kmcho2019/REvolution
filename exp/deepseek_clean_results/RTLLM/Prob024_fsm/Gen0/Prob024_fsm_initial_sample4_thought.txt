To implement a Mealy FSM that detects the sequence "10011" in a continuous input stream, we need to design a state machine with 6 states:
1. IDLE: Initial state, waiting for first '1'
2. S1: Received '1'
3. S10: Received '1' followed by '0'
4. S100: Received '100'
5. S1001: Received '1001'
6. S10011: Received '10011' (match state)

The FSM transitions between these states based on the input IN. When in S1001 state and receiving a '1', we transition to S10011 and output MATCH=1. The FSM then returns to S1 (not IDLE) to allow overlapping detection (for continuous "100110011" input).

Reset initializes the FSM to IDLE state with MATCH=0.
