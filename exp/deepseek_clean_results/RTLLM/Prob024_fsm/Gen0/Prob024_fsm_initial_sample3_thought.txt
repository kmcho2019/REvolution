To implement a Mealy FSM that detects the sequence "10011", we need to design a state machine with 6 states:
1. IDLE: Initial state, waiting for first '1'
2. S1: Received '1' (first bit)
3. S10: Received '10'
4. S100: Received '100'
5. S1001: Received '1001'
6. S10011: Received '10011' (match state)

The FSM transitions between these states based on the input IN. The output MATCH is 1 only when we're in S10011 state and the current input is '1'. The FSM should support continuous detection by properly handling state transitions after a match.

Key points:
- Reset initializes to IDLE state
- State transitions occur on clock edges
- Output is combinational based on current state and input
- After a match, the FSM should continue detecting new sequences
