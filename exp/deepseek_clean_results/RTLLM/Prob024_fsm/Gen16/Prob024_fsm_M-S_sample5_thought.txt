Simplification Strategy:
1. State Reduction: Eliminate redundant states by recognizing that after a full match (10011), we can immediately start looking for the next pattern without needing separate states
2. Direct Output Logic: Instead of separate next_match logic, directly compute MATCH in the state transition block
3. Simplified State Encoding: Use minimal 2-bit encoding with only necessary states (IDLE, GOT1, GOT10, GOT100)
4. Combined Logic: Merge state transition and output logic into a single always block for clarity
5. Remove Redundancies: Eliminate default case since all states are explicitly handled

Key Improvements:
- Fewer state transitions
- Direct output computation eliminates intermediate signal
- Single always block for both state and output
- Maintains exact same functionality with reduced complexity
- Better timing due to simplified logic
