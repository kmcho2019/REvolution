Novel Architecture: Shift Register with Parallel Comparator
1. Instead of traditional FSM, use a 5-bit shift register to store last 5 inputs
2. Implement parallel comparison against target pattern "10011" (binary 19)
3. Add edge detection to ensure match only occurs on last '1' of pattern
4. Benefits:
   - Eliminates state transition logic complexity
   - Naturally handles overlapping sequences
   - Easily scalable to longer patterns
   - Clear timing path (single shift + compare)
5. Tradeoffs:
   - Slightly larger area due to shift register
   - But simpler control logic compensates
6. Implementation:
   - 5-bit shift register captures history
   - Comparator checks for exact pattern match
   - Edge detector ensures proper timing
