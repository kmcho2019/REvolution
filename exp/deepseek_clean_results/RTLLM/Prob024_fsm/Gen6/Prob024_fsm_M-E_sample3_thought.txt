Novel Architectural Idea: Shift Register with Parallel Matching
1. Instead of using a traditional FSM, implement a shift register that stores the last 5 input bits.
2. Use parallel comparison logic to detect the "10011" pattern in the shift register.
3. This approach eliminates complex state transitions and simplifies the design to pure combinational matching.
4. The shift register naturally handles continuous input and overlapping sequences.
5. Reset initializes the shift register to all zeros.

Advantages:
- Simpler control logic compared to FSM
- Easily extensible to longer patterns
- Clear and maintainable implementation
- Parallel matching reduces critical path compared to sequential FSM
- Naturally handles overlapping sequences
