Here's a novel approach using a shift register combined with pattern matching logic:

1. Instead of a traditional FSM, we'll use a 5-bit shift register to track the last 5 input bits.
2. The shift register updates on each clock edge, pushing new bits in from IN.
3. Combinational logic compares the shift register contents with the target pattern "10011".
4. The output MATCH is asserted when the pattern matches and the current input is '1'.
5. This approach simplifies state management and allows for easy pattern modification.
6. The shift register automatically handles continuous detection by always maintaining the last 5 bits.

Advantages:
- More scalable for different pattern lengths
- Easier to modify the target pattern
- Simpler control logic compared to FSM
- Clear separation between storage and matching logic
