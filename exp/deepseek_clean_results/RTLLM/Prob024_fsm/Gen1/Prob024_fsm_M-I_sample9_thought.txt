To optimize the Mealy FSM for better PPA metrics while maintaining correct functionality, I'll implement these improvements:

1. State Encoding: Switch from one-hot to binary encoding to reduce power consumption and area
2. Output Registering: Register the MATCH output to improve timing by breaking the combinational path
3. Logic Simplification: Optimize state transitions by sharing common conditions
4. Clock Gating: Add enable conditions for the output register to reduce unnecessary toggles
5. Remove Default Case: Since all states are covered, we can remove the default case for better synthesis

- Use binary state encoding (3 bits for 5 states)
- Have registered MATCH output with clock gating
- Maintain the same detection functionality
