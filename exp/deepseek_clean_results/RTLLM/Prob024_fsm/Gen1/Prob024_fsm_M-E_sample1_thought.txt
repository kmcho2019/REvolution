Here's a novel approach using a shift register combined with combinatorial matching logic. Instead of a traditional FSM with explicit states, we'll:
1. Use a 5-bit shift register to store the last 5 input bits
2. Continuously compare the register contents with the target pattern "10011"
3. Output MATCH=1 when the pattern matches and we're receiving the last '1'
4. The shift register automatically handles continuous detection by shifting in new bits
5. Reset clears the shift register

This approach is more hardware-oriented and eliminates explicit state transitions, instead relying on pattern matching against the shift register contents. It's particularly efficient for fixed-length patterns and allows easy modification of the target pattern.
