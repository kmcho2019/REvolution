To optimize the Mealy FSM for better PPA metrics, I'll implement these improvements:
1. Change state encoding from one-hot to binary to reduce power consumption and area
2. Register the MATCH output to improve timing by breaking the combinational path
3. Simplify state transitions by removing redundant conditions
4. Optimize the default case handling
5. Use explicit state encoding for better synthesis control

The binary state encoding will use:
- IDLE: 3'b000
- S1: 3'b001
- S10: 3'b010
- S100: 3'b011
- S1001: 3'b100

This reduces switching activity and saves area compared to one-hot encoding.
