Instead of a traditional FSM, I'll implement a shift register that stores the last 5 input bits. The pattern detection will be done by comparing the register contents to the target pattern "10011". This approach:
1. Uses a 5-bit shift register to track input history
2. Compares register contents to target pattern in parallel
3. Supports continuous detection by shifting in new bits
4. Eliminates state transition logic complexity
5. Provides inherent support for overlapping sequences
6. Reduces timing paths by making output purely combinational from register
