Novel Architecture Idea: Sliding Window with Shift Register

Instead of using a traditional FSM approach, I'll implement a sliding window detector using a shift register. This approach:
1. Uses a 5-bit shift register to track the last 5 input bits
2. Compares the register contents with the target pattern "10011" in parallel
3. Generates MATCH when the register matches the pattern exactly
4. Automatically handles continuous input and overlapping sequences
5. Has simpler control logic than FSM while maintaining similar performance

Advantages:
- Eliminates complex state transition logic
- Naturally handles overlapping sequences
- Easy to modify for different pattern lengths
- Clear and maintainable implementation
- Similar area to FSM but with potentially better timing
