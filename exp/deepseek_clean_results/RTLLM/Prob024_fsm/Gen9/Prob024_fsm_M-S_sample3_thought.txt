To simplify the FSM while maintaining functionality, I'll make these key changes:

1. State Reduction:
   - Eliminate the separate next_state register by combining state transition and storage into a single always block
   - This removes the combinational next_state logic entirely

2. Output Logic:
   - Make MATCH purely combinational (true Mealy machine) since timing constraints allow it
   - Remove output register to simplify design

3. Reset Handling:
   - Keep synchronous reset but simplify the reset logic
   - Only reset the state, output is combinational

Key simplifications:
- Eliminated next_state register and combinational logic
- Reduced to single always block
- Purely combinational output matches spec exactly
- Fewer registers overall
- Same sequence detection behavior
