Novel Architectural Idea: Shift Register with Parallel Matching

Instead of using a traditional FSM approach, we can implement the sequence detector using a shift register that stores the last 5 input bits. This allows us to:
1. Continuously shift in new input bits while maintaining history
2. Perform parallel pattern matching on the stored bits
3. Eliminate complex state transition logic
4. Enable easy modification of the target pattern if needed

Key features:
- 5-bit shift register to store input history
- Combinational matching logic that compares the register contents with "10011"
- Synchronous reset and operation
- Output is purely combinational based on current register state

Advantages:
- Simpler implementation with clear pattern matching logic
- Easily extendable to different pattern lengths
- No state encoding/decoding overhead
- Clear timing path (single clock-to-output path)
