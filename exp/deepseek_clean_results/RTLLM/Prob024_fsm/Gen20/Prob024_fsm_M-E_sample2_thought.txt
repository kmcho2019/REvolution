Novel Architecture Idea:
1. Shift Register Approach: Instead of traditional FSM states, use a 5-bit shift register to track the last 5 input bits
2. Parallel Matching: Compare the shift register contents directly with the target pattern (10011) using combinational logic
3. Edge Detection: Add logic to ensure MATCH only pulses high when a new complete pattern is detected
4. Continuous Detection: The shift register naturally handles continuous input patterns by shifting new bits in
5. Reset Handling: Clear the shift register on reset for clean initialization

Advantages:
- More scalable for longer patterns (just increase shift register size)
- Simpler to modify for different patterns (just change the comparator)
- Clear separation of storage and matching logic
- Potentially better timing as matching is purely combinational
