Novel Architecture Idea: "Sliding Window with History Buffer"

Key Concepts:
1. Instead of traditional FSM states, use a 5-bit shift register to track the last 5 input bits (window)
2. Compare the window content directly with the target pattern (10011)
3. Implement continuous detection by shifting in new bits while maintaining history
4. Use parallel comparison for immediate pattern recognition
5. Reset clears the history buffer

Advantages:
- Eliminates state transition logic complexity
- Parallel pattern matching enables single-cycle detection
- Naturally supports continuous/overlapping patterns
- Scalable to longer patterns by increasing window size
- Clear timing behavior with registered outputs
