Novel Architecture: Shift Register with Parallel Pattern Matching
1. Instead of using state transitions, we'll use a 5-bit shift register to track the last 5 input bits
2. Parallel comparison logic checks for the "10011" pattern in the shift register
3. The shift register naturally handles continuous detection by shifting in new bits
4. Output is purely combinational based on the current shift register contents
5. Reset clears the shift register to all zeros

Advantages:
- Eliminates complex state transition logic
- Naturally handles continuous patterns (overlapping sequences)
- Simple and scalable - can easily modify for different pattern lengths
- Clear timing paths with registered inputs and combinational output
- Lower power since only shift operations occur (no complex state transitions)
