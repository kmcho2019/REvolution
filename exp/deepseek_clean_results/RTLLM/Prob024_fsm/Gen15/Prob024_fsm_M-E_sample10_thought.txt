Novel Architecture Idea: Shift Register + Parallel Comparator
1. Instead of traditional FSM states, use a 5-bit shift register to store the last 5 input bits
2. Continuously compare the shift register content with the target pattern "10011" (binary 19)
3. Output MATCH is asserted when the comparator finds a match
4. Reset clears the shift register
5. Continuous detection is inherent as the shift register always contains the last 5 bits

Advantages:
- Eliminates complex state transition logic
- Simple and scalable to longer patterns
- Parallel comparison is combinational, potentially faster
- Easily modifiable for different patterns
- Clear relationship between hardware and functionality
