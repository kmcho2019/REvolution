Novel Architecture Idea:
1. Shift Register Approach: Instead of traditional FSM states, use a 5-bit shift register to track the last 5 input bits
2. Parallel Pattern Matching: Compare the shift register contents directly with the target pattern (10011) using combinational logic
3. Edge Detection: Use the clock edge to sample the input and shift the register
4. Continuous Detection: The shift register naturally handles continuous input sequences by shifting in new bits
5. Reset Handling: Clear the shift register on reset

Advantages:
- Eliminates complex state transition logic
- Simple and scalable to longer patterns
- Naturally handles continuous sequences
- Clear and maintainable implementation
- Efficient pattern matching with direct comparison
