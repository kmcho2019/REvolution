Novel Architecture: Shift Register Pattern Matcher
1. Instead of traditional FSM states, use a 5-bit shift register to track the last 5 input bits
2. Implement combinational logic to detect the "10011" pattern in the shift register
3. The shift register naturally handles continuous input and loop detection
4. Output is purely combinational based on the current shift register contents
5. Reset clears the shift register
6. Advantages:
   - No explicit state transitions to manage
   - Easily extensible to longer patterns
   - Clear relationship between input history and output
   - Reduced control logic complexity
