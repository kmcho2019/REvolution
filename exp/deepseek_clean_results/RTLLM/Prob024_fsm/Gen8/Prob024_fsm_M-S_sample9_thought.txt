To simplify the Mealy FSM while maintaining the same functionality, I'll make these key changes:
1. Remove the separate next_state register and combine state transition logic with state storage
2. Simplify the state encoding to use fewer bits (2 bits for 4 states + idle)
3. Combine output logic directly into the state transition block
4. Remove redundant default case since all states are covered
5. Use simpler state transition conditions by leveraging the Mealy output directly

The simplified state encoding will be:
- IDLE: 2'b00
- S1:   2'b01
- S10:  2'b10
- S100: 2'b11
(S1001 is implicitly detected when in S100 and IN=1)

This reduces the number of flip-flops while maintaining the same detection behavior.
