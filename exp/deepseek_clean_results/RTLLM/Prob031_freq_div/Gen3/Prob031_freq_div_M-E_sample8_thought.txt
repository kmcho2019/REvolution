Here's a novel approach using a single shared counter with different comparison points for each output clock. Instead of separate counters for each frequency division, we'll use one large counter that counts up to 99 (covering all required divisions). Each output clock will toggle when the counter reaches specific thresholds:

1. CLK_50: Toggles every cycle (effectively counting by 1)
2. CLK_10: Toggles when counter mod 10 equals 0
3. CLK_1: Toggles when counter equals 0

This approach reduces the number of flip-flops needed and shares counting logic. The counter will be 7 bits wide to count up to 99 (7'd99). Each output will be generated by comparing the counter value against specific thresholds.
