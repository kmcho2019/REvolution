Novel approach using a single unified counter with clock enables:
1. Use one large counter (100 cycles) that serves as the base for all divided clocks
2. Generate clock enables for each output frequency:
   - CLK_50: toggle every cycle (counter bit 0)
   - CLK_10: toggle when counter[1:0] == 2'b00 (every 5 cycles)
   - CLK_1: toggle when counter == 6'd0 (every 100 cycles)
3. Advantages:
   - Single counter reduces area
   - Synchronous clock enables reduce glitches
   - Unified timing simplifies STA
   - Easy to extend for more divided clocks
