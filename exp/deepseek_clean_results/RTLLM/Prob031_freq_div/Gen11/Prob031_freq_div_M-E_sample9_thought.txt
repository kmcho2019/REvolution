Instead of using separate counters for each divided clock, I'll implement a single counter that counts continuously and generates all output clocks based on its value. This approach:
1. Uses one counter running at full speed (100MHz) to minimize area
2. Generates all output clocks synchronously from this counter
3. Maintains precise phase relationships between output clocks
4. Uses bit-selection from the counter for efficient division
5. Implements glitch-free clock generation through registered outputs

The key innovation is using a single counter with carefully chosen comparison points to generate all three clocks simultaneously while maintaining deterministic phase relationships.
