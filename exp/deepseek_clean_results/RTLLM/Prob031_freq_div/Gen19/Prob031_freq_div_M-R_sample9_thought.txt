Refactoring Strategy:
1. Replace sequential logic with combinational where possible
2. Use continuous assignments (assign) for simpler clock division
3. Maintain synchronous reset behavior
4. Keep the same frequency division ratios
5. Use separate counters for better timing isolation
6. Simplify state management by using direct counter comparisons
7. Optimize counter widths for each division ratio

Key Changes:
- CLK_50 generation moved to continuous assignment with a toggle register
- Separate counters for CLK_10 and CLK_1 generation
- Explicit counter resets for each division
- More modular structure with clear separation of concerns
- Reduced register usage where possible
