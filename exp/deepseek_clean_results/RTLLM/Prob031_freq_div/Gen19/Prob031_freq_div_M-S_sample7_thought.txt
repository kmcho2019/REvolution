Simplification Strategy:
1. Remove unused parameters since they don't affect the actual logic
2. Reduce counter width from 7-bit to 6-bit (since we only count up to 99)
3. Combine all clock generation into a single always block for simplicity
4. Maintain the same toggle logic but with cleaner implementation
5. Keep synchronous reset for all registers
6. Simplify counter comparison logic by using direct values

Key Improvements:
- Reduced counter size saves area
- Single always block makes the design more compact
- Direct comparison values improve readability
- Maintains same functionality with less code
