1. For CLK_50 (divide by 2): Simply toggle a flip-flop on every input clock cycle
2. For CLK_10 (divide by 10): Use a counter that counts 5 input clock cycles (since we need to toggle every 5 cycles for a 10MHz output from 100MHz)
3. For CLK_1 (divide by 100): Use a counter that counts 50 input clock cycles (since we need to toggle every 50 cycles for a 1MHz output from 100MHz)
All outputs will be synchronous with the input clock and properly reset.
