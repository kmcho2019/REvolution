To implement a frequency divider that generates three different clock frequencies from a 100MHz input clock:
1. For CLK_50 (50MHz): Simply toggle the output every input clock cycle (divide by 2)
2. For CLK_10 (10MHz): Use a counter that counts 5 input clock cycles (since 100MHz/10MHz = 10, and we need to toggle every 5 cycles for 50% duty cycle)
3. For CLK_1 (1MHz): Use a counter that counts 50 input clock cycles (since 100MHz/1MHz = 100, toggle every 50 cycles)
Reset functionality is implemented to initialize all outputs and counters to 0.
