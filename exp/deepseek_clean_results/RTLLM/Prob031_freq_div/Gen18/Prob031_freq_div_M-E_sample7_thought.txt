Novel Architecture: Cascaded Clock Divider with Gated Counters
1. Hierarchical division: First divide by 2 (50MHz), then use that to generate 10MHz, then use 10MHz to generate 1MHz
2. Clock gating: Each stage only toggles when needed, reducing unnecessary switching
3. Minimal counters: Each stage uses just enough bits for its division ratio
4. Synchronous design: All transitions synchronized to input clock for clean timing
5. Reset synchronization: Proper reset handling for all clock domains

Key Advantages:
- Power efficient due to clock gating and hierarchical structure
- Smaller counters (1-bit, 2-bit, 3-bit vs single 7-bit counter)
- Clean clock edges aligned with input clock
- Scalable architecture for additional divisions
