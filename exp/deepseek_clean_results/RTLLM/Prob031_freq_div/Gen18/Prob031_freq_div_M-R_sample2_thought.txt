Refactoring Strategy:
1. Replace sequential logic with combinational where possible
2. Use assign statements for clock generation to simplify the design
3. Maintain separate counters for each output frequency for better isolation
4. Keep synchronous reset functionality
5. Use smaller, dedicated counters for each output to improve timing paths
6. Simplify the control logic by removing unnecessary parameters

Key Changes:
- CLK_50 generation moved to continuous assignment (assign)
- Separate counters for CLK_10 and CLK_1 generation
- Simplified reset logic
- Removed unused parameters
- Each clock domain has its own dedicated counter
