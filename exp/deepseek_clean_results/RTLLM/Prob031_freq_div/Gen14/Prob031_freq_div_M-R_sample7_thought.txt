Refactoring Strategy:
1. Replace sequential always blocks with combinational assign statements where possible
2. Use a single counter approach to generate all divided clocks (more efficient)
3. Implement clock enables using bit comparisons from the main counter
4. Maintain synchronous reset functionality
5. Use bitwise operations for clock toggling logic
6. Simplify the counter logic by using a single large counter and deriving all outputs from it

Key Changes:
- Single 7-bit counter (counts 0-99) replaces three separate counters
- Clock outputs generated by comparing specific counter bits
- Toggle logic implemented via XOR with enable signals
- More compact implementation with same functionality
- Reduced register count while maintaining clear frequency relationships
