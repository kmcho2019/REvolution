Novel Architectural Idea: 
1. Use a single unified counter approach to minimize hardware resources while maintaining all frequency outputs
2. Implement a phase-aligned output strategy where all divided clocks have deterministic phase relationships
3. Use Gray coding for the counter to reduce switching power
4. Implement a glitch-free clock switching mechanism using synchronous enables
5. Add clock gating cells for power optimization
6. Use a parameterized design for flexibility in division ratios

Key Features:
- Single 7-bit counter serves all three frequency divisions
- Gray code counter reduces switching activity
- Synchronous enables ensure glitch-free outputs
- Phase alignment between all output clocks
- Power-optimized with clock gating
