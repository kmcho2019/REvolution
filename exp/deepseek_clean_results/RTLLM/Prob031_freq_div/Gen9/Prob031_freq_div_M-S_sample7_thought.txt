To simplify the frequency divider while maintaining functionality:
1. Remove parameterization since the division ratios are fixed (2, 10, 100)
2. Use simple up-counters instead of down-counters for easier understanding
3. Combine the counter logic for 10MHz and 1MHz into single always blocks
4. Eliminate intermediate enable signals since they add complexity
5. Keep the basic toggle mechanism for clock generation
6. Maintain separate always blocks for each output clock for clear timing

This reduces the code complexity while preserving all required functionality.
