Refactoring Strategy:
1. Unified Counter Approach: Use a single counter that counts to the least common multiple (100) and derive all clock signals from this counter to reduce logic duplication.
2. Continuous Assignments: Use assign statements for all output clocks to make the toggling behavior more explicit and reduce sequential logic.
3. Parameterization: Use parameters for division factors to make the code more maintainable and configurable.
4. Synchronous Reset: Maintain synchronous reset behavior for all registers.
5. Bit Selection: Derive all clocks from different bits of the unified counter to leverage natural binary counting patterns.

This approach reduces area by sharing counter logic while maintaining clean clock generation through continuous assignments.
