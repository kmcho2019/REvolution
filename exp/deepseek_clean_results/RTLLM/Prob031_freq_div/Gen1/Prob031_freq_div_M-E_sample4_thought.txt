Here's a novel approach using a single unified counter and phase-aligned clock generation:
1. Use a single 7-bit counter (0-99) that serves all three frequency divisions
2. Generate all output clocks synchronously from this counter
3. CLK_50 toggles every counter cycle (effectively using bit 0)
4. CLK_10 toggles when counter[2:0] matches specific values
5. CLK_1 toggles when counter reaches 49
This reduces area by sharing the counter logic and ensures all clocks maintain precise phase relationships.
