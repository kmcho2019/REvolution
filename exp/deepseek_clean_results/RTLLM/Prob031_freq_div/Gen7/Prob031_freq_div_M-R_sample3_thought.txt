Refactoring Strategy:
1. Replace sequential logic with combinational where possible - Use assign statements for clock generation to simplify the design
2. Maintain same frequency division ratios but implement counters differently
3. Use synchronous reset for better timing characteristics
4. Separate counter logic from clock generation for clearer structure
5. Use parameterized constants for division factors to improve readability and maintainability

Key Changes:
- CLK_50 generation moved to simple assign statement with toggle flip-flop
- Counters now implemented with separate always blocks
- Clock generation uses combinational logic based on counter values
- Synchronous reset only on clock edges
- Parameters used for division factors
