Novel Architecture Idea: Hierarchical Clock Division with Cascaded Counters

Key Concepts:
1. Instead of independent counters, create a hierarchical structure where each slower clock is derived from the faster one
2. The 50MHz clock is generated first (divide by 2)
3. The 10MHz clock is derived from the 50MHz clock (divide by 5)
4. The 1MHz clock is derived from the 10MHz clock (divide by 10)
5. Uses Gray code counters for reduced switching activity and power savings
6. Separate always blocks for each clock domain to improve timing

Advantages:
- Reduced logic complexity (only 2 counters needed instead of 3)
- Natural synchronization between clocks
- Lower power due to Gray code counters and hierarchical structure
- Better timing closure with separate always blocks
- More scalable for additional divided clocks
