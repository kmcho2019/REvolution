Refactoring Strategy:
1. Use combinational logic with assign statements for clock generation where possible
2. Replace counter-based approach with shift registers for division factors that are powers of 2 (50MHz)
3. Maintain synchronous design principles while reducing sequential elements
4. Use bitwise operations for more efficient counter comparisons
5. Simplify reset logic by using synchronous resets only
6. Optimize counter width calculations using system functions

Key Changes:
- CLK_50 implemented as simple toggle flip-flop using XOR
- CLK_10 and CLK_1 use down-counters with terminal count detection
- All resets made synchronous for better timing
- More efficient terminal count comparisons using bitwise AND
