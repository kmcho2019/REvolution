Simplification Strategy:
1. Direct division: Use simple counters without parameterization since division factors are fixed
2. Reduced logic: Implement straightforward toggle logic for each divided clock
3. Smaller counters: Use minimum required bit-widths for counters (3-bit for 10MHz, 7-bit for 1MHz)
4. Clean reset: Maintain synchronous reset for all outputs and counters
5. Separate always blocks: Keep timing isolation between different clock domains

Key simplifications:
- Remove parameterization since requirements are fixed
- Use simple counter comparison instead of terminal count detection
- Reduce counter widths to exactly what's needed
- Keep clear, separate logic for each output clock
