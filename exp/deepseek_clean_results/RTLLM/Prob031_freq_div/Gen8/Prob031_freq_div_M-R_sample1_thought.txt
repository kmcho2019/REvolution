Refactored design approach:
1. For CLK_50: Keep the simple toggle flip-flop but implement it with an assign statement for conciseness
2. For CLK_10 and CLK_1: Use a single combined counter to reduce area and power
3. Implement clock enables instead of direct clock generation to improve timing
4. Use parameterized constants with derived values for better maintainability
5. Separate counter logic from clock generation for cleaner design
6. Use Gray code encoding for the higher counters to reduce switching power

Key improvements:
- Single counter for both CLK_10 and CLK_1 reduces area
- Clock enable approach improves timing closure
- Gray code reduces switching power
- Clear separation of counter and clock generation logic
- Parameters make division ratios easily configurable
