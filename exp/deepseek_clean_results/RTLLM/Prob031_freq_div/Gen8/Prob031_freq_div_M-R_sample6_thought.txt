Refactoring Strategy:
1. Replace sequential always blocks with combinational assign statements where possible
2. Use continuous assignments for clock generation to simplify the logic
3. Maintain the same counter-based approach but express it differently
4. Keep the same reset behavior and frequency division ratios
5. Use separate counters for each clock domain to maintain clarity

Key Changes:
- CLK_50 is now generated with a simple XOR gate instead of sequential logic
- CLK_10 and CLK_1 still use counters but with different expression
- The counters are now updated in a single always block for better synthesis grouping
- Output assignments are moved outside the always block
