Novel Architecture Idea:
1. Use a single unified counter approach to generate all three clock frequencies simultaneously
2. Implement a phase-aligned design where all output clocks transition at the same time
3. Leverage the fact that 100 is a multiple of both 10 and 2, allowing shared counting logic
4. Use a modulo-100 counter to track the complete cycle
5. Generate output clocks based on specific counter values rather than separate counters
6. This reduces hardware complexity by eliminating redundant counting logic

Key Advantages:
- Single counter reduces area compared to multiple counters
- Phase-aligned outputs can be beneficial for synchronous systems
- Shared counting logic improves power efficiency
- Simple comparison logic for each output clock
- Easily extensible to other division ratios
