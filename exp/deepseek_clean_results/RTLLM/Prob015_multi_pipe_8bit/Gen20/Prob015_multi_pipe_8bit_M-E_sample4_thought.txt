This design implements an 8-bit unsigned multiplier using radix-4 Booth encoding for partial product reduction, combined with a 3-stage pipeline for optimal performance. Key innovations:

1. **Radix-4 Booth Encoding**:
   - Reduces number of partial products from 8 to 5
   - Uses encoded multiplier bits to select between 0, ±1×, ±2× multiplicand
   - Simplifies sign extension handling

2. **Optimized Pipeline Stages**:
   - Stage 1: Input registration and Booth encoding
   - Stage 2: Partial product generation and compression
   - Stage 3: Final addition and output registration

3. **Efficient Implementation**:
   - Uses carry-save adders for partial product reduction
   - Implements sign extension handling in the encoding stage
   - Optimized register usage with minimal intermediate storage

The design maintains the same interface while improving performance through algorithmic optimization and careful pipeline balancing.
