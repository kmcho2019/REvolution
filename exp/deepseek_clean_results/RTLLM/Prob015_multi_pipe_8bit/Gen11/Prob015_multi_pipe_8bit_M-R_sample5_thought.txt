Refactoring Strategy:
1. Pipeline Restructuring:
   - Replace sequential always blocks with continuous assignments for combinational logic
   - Use explicit pipeline registers with clock enables
   - Simplify enable signal propagation

2. Logic Optimization:
   - Merge partial product generation into a single assign statement
   - Use concatenation for zero extension instead of separate bits
   - Implement adder tree with direct wiring

3. Enable Handling:
   - Replace shift register with direct stage enables
   - Use gated clock enables per stage for better power control

Key Changes:
- Converted procedural logic to continuous assignments where possible
- Simplified pipeline control with explicit stage enables
- Optimized partial product generation using bitwise operations
- Improved clock gating with per-stage granularity
- Reduced register usage by combining related signals
