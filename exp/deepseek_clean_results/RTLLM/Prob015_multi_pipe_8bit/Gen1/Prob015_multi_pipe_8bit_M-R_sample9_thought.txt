The refactored design maintains the same pipelined 8-bit multiplier concept but improves implementation clarity and timing synchronization. Key changes:
1. Separated combinational logic (partial products, additions) from sequential elements
2. Used explicit pipeline registers with proper enable signal propagation
3. Structured as a clean 4-stage pipeline (input, partial products, adder stages, output)
4. Simplified control flow with clear stage-to-stage progression
5. Used 'assign' for combinational logic where appropriate

The pipeline now properly synchronizes data and control signals:
- Stage 0: Input registration (mul_a, mul_b)
- Stage 1: Partial product generation
- Stage 2: First adder level (4 sums)
- Stage 3: Second adder level (2 sums)
- Stage 4: Final sum and output
Each stage is properly gated by the pipeline enable signal.
