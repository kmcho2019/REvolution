Here's a refactored version of the 4-bit LFSR with these key changes:

1. Separate the feedback calculation into a continuous assignment using 'assign'
2. Move the state update logic to a separate always block
3. Use non-blocking assignments consistently for the state update
4. Maintain the same functionality (XOR of bits 3 and 2, inverted feedback)
5. Keep the synchronous reset behavior but make it more explicit

The main structural changes are:
- Feedback calculation is now continuous rather than procedural
- State update is isolated in its own always block
- Clear separation between combinational and sequential logic
- Same reset initialization (4'b0001) and clocking behavior
