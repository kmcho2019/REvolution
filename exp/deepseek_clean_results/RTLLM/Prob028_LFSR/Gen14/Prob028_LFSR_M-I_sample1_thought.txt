**Optimized 4-bit LFSR with Improved PPA:**

1. **Power Optimization**: Eliminate the continuous assignment for feedback by moving it directly into the sequential block, reducing switching activity.

2. **Area Optimization**: Remove the separate wire declaration for feedback and compute it directly in the state update logic.

3. **Performance Improvement**: Maintain single-clock-cycle operation while simplifying the logic path.

4. **Reset Value Selection**: Initialize to 4'b0001 (non-zero) to ensure the LFSR doesn't get stuck in all-zero state.

Key Improvements:
- Reduced combinational logic by eliminating separate feedback wire
- Maintained same functionality with fewer logic elements
- Kept synchronous reset for better timing characteristics
- Preserved original polynomial (x^4 + x^3 + 1) with inverted feedback
- Output remains directly assigned from state register
