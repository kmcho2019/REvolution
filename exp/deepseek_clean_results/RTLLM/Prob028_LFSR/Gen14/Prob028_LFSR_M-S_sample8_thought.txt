**Simplified 4-bit LFSR with Core Functionality:**

1. **Minimalist Design**: Focus only on essential LFSR functionality - clocked shifting with feedback.
2. **Direct Feedback Implementation**: Calculate feedback directly in the shift operation without intermediate variables.
3. **Basic Reset Handling**: Simple synchronous reset to a known non-zero state (4'b0001) to prevent lock-up.
4. **Straightforward Output**: Output is simply the register state, no additional logic needed.

Key Simplifications:
- Removed any optimization considerations (PPA etc.)
- Eliminated all unnecessary comments and explanations
- Reduced to just the core shifting and feedback logic
- Maintained same polynomial (x^4 + x^3 + 1) and sequence
- Kept same reset behavior
