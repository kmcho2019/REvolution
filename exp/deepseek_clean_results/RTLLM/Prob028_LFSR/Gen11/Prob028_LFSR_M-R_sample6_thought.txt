Refactored LFSR design with simplified implementation:

1. Strictly follows original interface requirements (only clk, rst, and out ports)
2. Maintains core feedback mechanism (XOR of bits 3 and 2 with inversion)
3. Uses continuous assignment for feedback calculation
4. Implements synchronous reset to 4'b0 as specified
5. Single-edge triggering (posedge clk only) for better timing predictability
6. Simplified state update logic without self-correction (not required per spec)

Key changes:
- Removed poly_sel and gray outputs
- Simplified to single always block for state update
- Used continuous assignment for feedback
- Strict reset to 0 behavior
- Standard single-edge clocking
