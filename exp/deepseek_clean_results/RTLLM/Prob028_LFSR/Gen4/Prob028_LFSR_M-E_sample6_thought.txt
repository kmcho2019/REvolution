Novel LFSR design with parallel load capability and configurable feedback taps:
1. Add parallel load input (load_data) and load control signal (load) for initialization flexibility
2. Make feedback taps configurable via parameters for different maximal-length sequences
3. Implement optional output inversion for additional randomness
4. Use gray coding for state transitions to reduce glitches
5. Include a seed parameter for deterministic initialization
6. Add an optional output enable for bus compatibility

This enhanced LFSR provides more control over the random sequence generation while maintaining the core functionality. The configurable taps allow for different polynomial configurations, and the parallel load enables specific pattern injection.
