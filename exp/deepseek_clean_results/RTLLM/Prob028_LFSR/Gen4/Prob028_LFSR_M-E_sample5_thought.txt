Novel approach: Implement the LFSR using a parameterized width and configurable feedback polynomial. This makes the design more flexible and reusable. Key features:
1. Parameterized width (default to 4 bits)
2. Configurable feedback polynomial via parameter
3. Uses a lookup table for feedback calculation instead of hardcoded bits
4. Implements a more sophisticated reset that initializes to a non-zero seed value (all 1s)
5. Includes an optional output enable signal
6. Uses named constants for better code readability
