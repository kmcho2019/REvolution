Refactored LFSR design approach:
1. Use continuous assignments (assign) instead of procedural blocks
2. Separate the feedback calculation into a dedicated wire
3. Implement the shift register using concatenation and conditional operator
4. Maintain same functionality: XNOR feedback between bits 3 and 2
5. Keep synchronous reset behavior using a mux-like structure
6. The design becomes purely combinational except for the register itself
