To implement a 4-bit LFSR with the specified feedback mechanism:
1. Use a 4-bit register to store the current state (out[3:0])
2. The feedback is calculated as ~(out[3] ^ out[2]) (XOR of MSB and second MSB, then inverted)
3. On clock rising edge:
   - If reset is high, clear the register
   - Otherwise, shift left and insert feedback at LSB
4. The output is simply the current register state
