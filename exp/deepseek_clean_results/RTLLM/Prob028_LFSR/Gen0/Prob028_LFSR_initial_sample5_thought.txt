To implement a 4-bit LFSR with the specified requirements:
1. Use a 4-bit register to store the current state (out[3:0])
2. The feedback is calculated as ~(out[3] ^ out[2]) (XOR of MSBs then inverted)
3. On clock rising edge:
   - If reset is high, initialize register to 0
   - Else, shift left and insert feedback at LSB
4. The output is simply the current register state
