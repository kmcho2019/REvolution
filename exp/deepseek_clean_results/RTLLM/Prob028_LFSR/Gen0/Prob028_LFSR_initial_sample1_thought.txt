To implement a 4-bit LFSR with the specified requirements:
1. Use a 4-bit register to store the current state
2. The feedback is calculated as ~(out[3] ^ out[2]) (XOR of MSB and second MSB, then inverted)
3. On reset (rst high), initialize the register to 4'b0000
4. On each clock edge (when not reset), perform left shift and insert feedback at LSB
5. The output 'out' is simply the current register value
