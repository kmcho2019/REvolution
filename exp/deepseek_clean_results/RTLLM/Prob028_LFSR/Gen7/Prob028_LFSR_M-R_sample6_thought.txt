Refactoring strategy:
1. Separate the feedback calculation into a continuous assignment for clarity
2. Move the shift operation into a separate always block
3. Use non-blocking assignments for better synchronous design practice
4. Maintain the same functionality (4-bit LFSR with XOR of bits 3 and 2, inverted)
5. Keep the same reset behavior (active high, initializes to 0)
6. Add comments to explain each part of the design

Key changes:
- Feedback calculation is now a separate wire using assign
- Shift operation is clearly visible in the always block
- Non-blocking assignments for synchronous behavior
- More explicit structure while maintaining same functionality
