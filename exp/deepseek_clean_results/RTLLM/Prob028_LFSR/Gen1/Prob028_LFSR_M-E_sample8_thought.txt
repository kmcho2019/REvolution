Novel approach: Implement a 4-bit LFSR with configurable feedback taps and parallel load capability. This design:
1. Uses a parameter to define the feedback polynomial (default to given ~(out[3]^out[2]))
2. Adds a parallel load input for initialization with any seed value
3. Implements an enable signal for controlled operation
4. Uses a more efficient feedback calculation by directly computing the next state
5. Provides both registered and combinational outputs
