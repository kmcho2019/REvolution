Simplified LFSR Design:

1. Key Improvements:
   - Remove redundant bit inversion in feedback (equivalent to XOR with 1)
   - Use simpler XOR feedback directly (same polynomial)
   - Initialize to non-zero state (4'b0001) for proper LFSR operation
   - Single-line always block for maximum clarity

2. Maintained Functionality:
   - Same 4-bit pseudo-random sequence generation
   - Identical clock and reset behavior
   - Equivalent maximum-length sequence (15 states)
   - Preserved port interface

3. Benefits:
   - More efficient implementation (one less operation)
   - Clearer mathematical representation
   - Same sequence quality
   - Reduced gate count in synthesis
