**Simplified LFSR with Minimal Logic:**

1. **Key Simplifications**:
   - Remove explicit feedback calculation by directly using the XOR expression in the shift operation
   - Maintain single always block for sequential logic
   - Keep same initialization value (4'b0001) for proper sequence generation
   - Preserve the same feedback polynomial (x^4 + x^3 + 1) through equivalent operation

2. **Maintained Properties**:
   - Identical pseudo-random sequence (15 states)
   - Same reset behavior
   - Synchronous operation
   - Correct polynomial implementation (inverted XOR of bits 3 and 2)

3. **Improvements**:
   - Reduced logic operations by combining feedback into shift assignment
   - Cleaner, more readable implementation
   - Same area and timing characteristics as optimized version
