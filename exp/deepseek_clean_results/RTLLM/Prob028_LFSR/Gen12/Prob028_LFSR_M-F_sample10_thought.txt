**Simplified 4-bit LFSR with Fixed Feedback:**

1. **Fixed Feedback Polynomial**: Using a simple, proven feedback polynomial (taps at bits 3 and 2) that guarantees maximum length sequence for 4-bit LFSR (15 states).

2. **Basic Reset Logic**: Initialize to a known non-zero state (4'b0001) to prevent lock-up in all-zeros state.

3. **Direct Output**: Remove unnecessary output transformation to maintain simplest possible implementation.

4. **Synchronous Design**: Maintain clean synchronous design with clock and reset handling.

Key Improvements:
- Removes complex parity-based feedback selection
- Eliminates auto-seeding logic (not needed with proper polynomial)
- Simplifies output path
- Guarantees maximum length sequence
- More efficient implementation
- Matches original interface requirements exactly
