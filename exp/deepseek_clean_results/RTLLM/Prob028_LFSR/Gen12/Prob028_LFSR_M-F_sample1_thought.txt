**Simplified 4-bit LFSR with Fixed Feedback:**

1. **Fixed Feedback Polynomial**: Using a proven 4-bit LFSR configuration with taps at bits 3 and 2 (x^4 + x^3 + 1 polynomial) for reliable pseudo-random sequence generation.

2. **Basic Functionality**: Implements a standard LFSR with synchronous reset and clocked operation, avoiding unnecessary complexity.

3. **All-Zero State Prevention**: Initializes to a non-zero state (4'b0001) on reset to prevent lock-up, as an all-zero state would stop the LFSR.

4. **Direct Output**: Provides the raw LFSR state as output without additional transformations to maintain simplicity.

Key Improvements:
- Removes dynamic feedback complexity
- Eliminates potential timing issues from parity calculation
- Simplifies the design while meeting requirements
- Guaranteed maximum length sequence (15 states)
- More efficient implementation
