The refactored solution maintains the same triangle wave generation concept but improves the implementation by:
1. Using a single always block with cleaner state transitions
2. Separating the state transition logic from the wave update logic
3. Ensuring the wave holds its peak values (0 and 31) for one full clock cycle
4. Using more descriptive state names (UP and DOWN) for better readability
