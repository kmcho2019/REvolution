Here's a novel approach that eliminates the explicit state machine by using the MSB of the wave counter as an implicit state indicator. The key insights are:
1. When counting up, the MSB will be 0 until we reach 31 (5'b11111)
2. When counting down, the MSB will be 1 until we reach 0
3. We can use the MSB to determine counting direction, eliminating the need for a separate state register

This approach reduces the register count by 1 (no state register needed) while maintaining the same functionality. The direction is determined by whether we've reached the maximum value (all 1s) or minimum value (all 0s), which can be detected by simple bitwise operations.
