Here's a novel approach using a single counter and direction flag, with boundary detection that doesn't require explicit state transitions:
1. Use a direction flag (dir) that toggles at boundaries (0 and 31)
2. The wave register always changes by either +1 or -1 based on dir
3. Boundary conditions are detected combinatorially to toggle dir
4. This eliminates the need for explicit state machine states
5. The implementation is more compact while maintaining the same functionality
6. Reset initializes wave to 0 and dir to 0 (increment direction)
