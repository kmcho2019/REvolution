To simplify the solution while maintaining functionality, I'll:
1. Remove the explicit state machine and use the MSB of the wave counter as a direction flag
2. Implement a single always block with simple increment/decrement logic
3. Use arithmetic comparison for boundary detection
4. Maintain the same reset behavior and output range

This approach reduces:
- State machine complexity (no separate state register)
- Number of conditional checks
- Lines of code while keeping the same functionality
The wave will still cycle between 0 and 31, changing direction at boundaries.
