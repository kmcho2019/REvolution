Here's a simplified approach that maintains the triangle wave generation while reducing complexity:

1. Use a single direction bit instead of a state machine (0=up, 1=down)
2. Implement simple boundary detection to toggle direction
3. Use a single arithmetic operation for counting (either +1 or -1)
4. Reset initializes wave to 0 and direction to up (0)
5. The counting logic is simplified to: wave <= wave + (direction ? -1 : 1)
6. Boundary conditions are checked after counting to ensure proper direction change

Key simplifications:
- Eliminated complex bit manipulation in counting operation
- Direct arithmetic operation makes intention clearer
- Maintained same functionality with fewer operations
- Still properly handles boundary conditions
