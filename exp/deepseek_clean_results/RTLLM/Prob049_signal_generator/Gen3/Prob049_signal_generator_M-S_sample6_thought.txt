Here's a simplified approach that maintains the triangle wave generation while reducing complexity:

1. Use a single direction bit to control counting direction (1 for increment, 0 for decrement)
2. Implement simple boundary detection that flips the direction bit when hitting 0 or 31
3. Use a single arithmetic operation that adds either +1 or -1 based on direction
4. Reset initializes both wave and direction to 0 (counting up from 0)
5. The logic is more straightforward with fewer operations and clearer intent

Key simplifications:
- Eliminated the complex direction calculation
- Single conditional for boundary detection
- Clear arithmetic operation
- Maintains exact same waveform behavior
