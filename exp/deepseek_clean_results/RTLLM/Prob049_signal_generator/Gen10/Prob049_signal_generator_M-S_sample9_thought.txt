The original solution is already quite minimal, but we can simplify it further by:
1. Removing the explicit state register and instead inferring the state from the wave value
2. Using a single always block with simple conditional logic
3. Eliminating the case statement since we only have two states
4. Maintaining the same boundary behavior (hold at 0 and 31 for one cycle)

The key insight is that we can determine whether to increment or decrement based on whether we're at the boundaries (0 or 31) rather than maintaining a separate state variable. This reduces the number of registers and simplifies the control logic.
