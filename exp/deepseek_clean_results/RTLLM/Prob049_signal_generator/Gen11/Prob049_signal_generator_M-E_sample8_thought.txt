Innovative triangle wave generator using a signed counter approach:
1. Use a 6-bit signed counter (5-bit magnitude + sign bit) to naturally handle both increment and decrement
2. The sign bit automatically indicates direction (0=positive, 1=negative)
3. Boundary detection is simplified to checking the 5-bit magnitude only
4. The output is derived by taking the absolute value of the counter
5. Key advantages:
   - Eliminates separate direction register
   - Combines increment/decrement into single arithmetic operation
   - Boundary checks only need to examine magnitude bits
   - Natural overflow handling at boundaries
   - More efficient arithmetic implementation
