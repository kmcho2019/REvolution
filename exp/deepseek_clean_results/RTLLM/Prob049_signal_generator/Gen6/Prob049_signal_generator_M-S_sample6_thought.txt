Simplification Strategy:
1. Eliminate the state register by using the MSB of the wave counter as a direction indicator
2. Use a single always block with simple increment/decrement logic controlled by the MSB
3. Maintain the same reset behavior and output range (0-31)
4. Reduce comparator complexity by using bitwise checks for boundaries
5. Keep the same synchronous behavior with clock and reset

Key Insights:
- When wave reaches 31 (5'b11111), the next increment would naturally roll over to 0, but we want to decrement instead
- When wave is 0, we want to start incrementing again
- The MSB (wave[4]) can serve as a direction flag: 0=increment, 1=decrement
- Boundary conditions can be detected by checking specific bit patterns
