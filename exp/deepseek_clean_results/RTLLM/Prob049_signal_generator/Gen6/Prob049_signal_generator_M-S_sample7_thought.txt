The original solution is already quite efficient, but we can simplify it further by:
1. Eliminating the explicit state register since the direction can be inferred from the wave value
2. Using a single always block with simpler conditional logic
3. Maintaining the same boundary behavior (holding at 0 and 31 for one cycle)
4. Reducing the logic to just check for boundary conditions and update direction accordingly

The key insight is that when wave is 0, we must increment, and when wave is 31, we must decrement. All other cases continue in their current direction.
