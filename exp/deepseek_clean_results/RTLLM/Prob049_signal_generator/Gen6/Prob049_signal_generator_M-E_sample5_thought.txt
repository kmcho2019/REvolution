Here's a novel approach using a single counter with direction control, eliminating the explicit state machine:

1. Instead of a separate state register, we'll use the MSB of an extended 6-bit counter to implicitly track direction
2. The 5-bit wave output is derived from the lower 5 bits of this counter
3. When counting up, we'll let the counter naturally overflow into bit 5 (direction flag)
4. When counting down, we'll detect when the lower 5 bits would underflow
5. This creates a more compact implementation with fewer explicit state transitions
6. Reset initializes the counter to 0 (counting up direction)

Key advantages:
- Eliminates explicit state machine logic
- Uses counter properties to naturally handle direction changes
- More efficient implementation with fewer comparisons
- Still maintains clean 0-31 triangular waveform
