Refactoring approach:
1. Use continuous assignments for the state transitions and wave updates
2. Implement the state machine using combinational logic with always_ff for registers
3. Separate the next-state logic from the output logic
4. Use parameters for state encoding to improve readability
5. Optimize the boundary condition checks by pre-computing them

Key benefits:
- Clear separation of combinational and sequential logic
- More explicit state machine structure
- Potential for better synthesis optimization
- Maintains same functionality while being more maintainable
