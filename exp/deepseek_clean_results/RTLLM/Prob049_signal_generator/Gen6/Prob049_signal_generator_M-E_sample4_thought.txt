Here's a novel approach using a single counter with direction control, eliminating the explicit state machine:

1. Use a single 5-bit counter register that automatically toggles direction at boundaries
2. Add a direction flag (dir) that flips when hitting 0 or 31
3. Implement a more compact logic by:
   - Combining increment/decrement into one operation using the direction flag
   - Using arithmetic operations with the direction flag to determine step (+1 or -1)
4. Maintain the same synchronous reset behavior
5. Achieve the same waveform with simpler control logic

Advantages:
- Eliminates explicit state machine case statement
- More compact implementation
- Same functionality with fewer control signals
- Easier to extend to different counter widths
