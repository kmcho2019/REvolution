To simplify the solution while maintaining functionality:
1. Use a single 5-bit counter register to track the wave value
2. Add a direction flag to control increment/decrement
3. On each clock edge:
   - If in increment mode (direction=1) and not at max (31), increment
   - If at max, switch to decrement mode
   - If in decrement mode (direction=0) and not at min (0), decrement
   - If at min, switch to increment mode
4. Reset clears both counter and direction

This approach:
- Uses minimal state (just direction flag)
- Has simple arithmetic operations
- Naturally handles boundary conditions
- Maintains exact 0-31 range without extra logic
