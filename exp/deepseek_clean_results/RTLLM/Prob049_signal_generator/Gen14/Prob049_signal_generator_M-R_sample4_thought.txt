Refactoring approach:
1. Replace the always block with continuous assignments for combinational logic
2. Use a separate always block only for sequential elements (registers)
3. Simplify direction logic by making it purely combinational
4. Calculate next_wave value first, then derive direction from it
5. This separates combinational and sequential logic clearly
6. Benefits:
   - More explicit data flow
   - Easier timing analysis
   - Potentially better synthesis results
   - Clear separation of state and next-state logic
