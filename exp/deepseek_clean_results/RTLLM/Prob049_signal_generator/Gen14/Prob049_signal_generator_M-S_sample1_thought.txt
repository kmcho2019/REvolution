The design can be simplified by:
1. Using a single 5-bit counter instead of 6-bit
2. Tracking direction with just 1-bit flag
3. Eliminating the combinational always block by integrating the wave generation into the sequential block
4. Maintaining the same 0-31 range with simple increment/decrement logic
5. Reducing area by removing the 6th bit and associated logic

This achieves:
- Same functionality with fewer bits
- All logic in one sequential block
- Clear direction control
- Minimal state elements
