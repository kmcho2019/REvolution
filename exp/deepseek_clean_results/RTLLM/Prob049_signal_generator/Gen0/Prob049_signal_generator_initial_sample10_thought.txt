The triangle wave generator needs to alternate between incrementing and decrementing a 5-bit counter (wave) between 0 and 31. We'll use a state register to track whether we're currently in the increment (state=0) or decrement (state=1) phase. On each clock edge, we'll:
1. Check reset condition first (active low)
2. If not reset, examine current state:
   - State 0: increment wave until reaching 31, then switch to state 1
   - State 1: decrement wave until reaching 0, then switch to state 0
The output wave will continuously generate a triangle pattern between 0 and 31.
