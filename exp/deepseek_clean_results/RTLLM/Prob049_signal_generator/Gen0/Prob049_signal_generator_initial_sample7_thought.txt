The triangle wave generator needs to alternate between incrementing and decrementing a 5-bit counter to create a waveform that ramps up and down between 0 and 31. We'll use a state machine with two states:
1. UP state (0): increment the wave value until it reaches 31
2. DOWN state (1): decrement the wave value until it reaches 0

The module will be synchronous to the clock and have an active-low reset. On reset, both state and wave will be cleared to 0. The state transitions and wave updates will occur on positive clock edges.
