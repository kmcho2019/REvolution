The triangle wave generator will use a state machine with two states:
1. UP state (0): increment the wave counter until it reaches 31
2. DOWN state (1): decrement the wave counter until it reaches 0

We'll use:
- A state register to track current direction (up/down)
- A 5-bit wave register for the output
- Synchronous reset (active low) to initialize both registers
- Clocked logic to update state and wave value on each rising edge
