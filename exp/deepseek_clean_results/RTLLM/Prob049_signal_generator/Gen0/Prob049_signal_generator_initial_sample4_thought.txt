The triangle wave generator can be implemented using a state machine with two states:
1. UP state (0): increment the wave counter until it reaches 31
2. DOWN state (1): decrement the wave counter until it reaches 0

We'll use a 1-bit state register to track the current direction and a 5-bit wave register for the output. On each clock edge:
- If in UP state, increment wave until 31, then switch to DOWN state
- If in DOWN state, decrement wave until 0, then switch to UP state
- Reset sets both state and wave to 0
