Refactoring Strategy:
1. State Representation: Replace the direction flag with explicit state encoding (IDLE/UP/DOWN) for better readability
2. Combinational Logic: Move all next-state logic to continuous assignments for clearer separation
3. State Transitions: Implement a classic 3-state FSM (IDLE, COUNT_UP, COUNT_DOWN)

Key Improvements:

- Continuous assignments make the control flow more visible
- Separate combinational and sequential logic blocks follow better design practices
- State encoding makes the design intent clearer while maintaining efficiency
