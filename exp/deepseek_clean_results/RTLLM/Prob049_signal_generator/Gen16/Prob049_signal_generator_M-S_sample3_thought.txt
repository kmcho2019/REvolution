Simplification Strategy:

1. Single Always Block:
   - Combine state and wave updates into one always block for simpler control flow
   - Eliminate separate combinational logic for next state calculation

2. Simplified Direction Control:
   - Use wave value directly to determine direction change
   - Remove explicit direction register by using boundary conditions

3. Efficient Boundary Checks:
   - Keep simple equality checks for 0 and 31
   - Directly calculate next wave value based on current boundaries

Key Improvements:
- Reduced register count by eliminating direction flip-flop
- Simplified control logic by merging state machines
- Maintained same functionality with fewer resources
- Improved timing by reducing critical path length
