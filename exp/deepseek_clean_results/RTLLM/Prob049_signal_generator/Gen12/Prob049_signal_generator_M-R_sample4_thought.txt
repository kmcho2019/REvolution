Refactoring Strategy:
1. State Machine Transformation:
   - Replace the procedural state machine with combinational logic using assign statements
   - Maintain the same state behavior but express it through continuous assignments
   - Use a wire for next_state calculation to make the state transition explicit

2. Wave Generation Logic:
   - Move the wave increment/decrement logic to a continuous assignment
   - Use ternary operators for compact expression of the direction change
   - Keep the same boundary detection logic but express it in the assignment

3. Reset Handling:
   - Maintain synchronous reset behavior but express it through the register update
   - Use a separate always block just for the sequential elements

Benefits:
- More explicit data flow through continuous assignments
- Clear separation of combinational and sequential logic
- Potentially better synthesis optimization due to simpler always block
- Maintains identical functionality while improving code structure
