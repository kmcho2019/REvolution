Refactored design approach:
1. Use continuous assignments for the direction logic to simplify the state control
2. Implement wave increment/decrement using a single adder with direction control
3. Move boundary detection logic to combinational blocks
4. Keep the same functionality but with clearer separation of:
   - Direction control logic (combinational)
   - Wave update logic (sequential)
5. Benefits:
   - More modular design
   - Clearer separation of combinational and sequential logic
   - Potentially better synthesis optimization
   - Same timing characteristics
