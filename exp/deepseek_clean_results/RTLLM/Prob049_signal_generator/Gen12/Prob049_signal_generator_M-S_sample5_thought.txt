Simplification Strategy:

1. State Machine Reduction:
   - Eliminate explicit state register by using wave value boundaries as implicit state indicators
   - This removes the need for separate state transitions and reduces register count

2. Boundary Condition Optimization:
   - Use simple equality comparisons for clarity (wave == 31 and wave == 0)
   - While bitwise operations are efficient, direct comparisons are more readable and equally optimized by modern synthesis tools

3. Unified Logic Flow:
   - Single always block with clear increment/decrement logic
   - Direction change happens automatically at boundaries without explicit state tracking

Key Benefits:
- Removes entire state register (area savings)
- Simplifies control logic (timing improvement)
- Maintains same functionality with clearer code
- Reduced gate count while keeping same performance
