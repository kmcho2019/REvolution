Simplification Strategy:
1. Remove state variable entirely - track direction implicitly using boundary conditions
2. Use a single always block with simple increment/decrement logic
3. Detect boundaries by checking MSB (for max) and all zeros (for min)
4. Maintain same reset behavior and output waveform

Key Benefits:
- Eliminates state variable and associated logic
- Reduces conditional checks to minimum necessary
- Maintains same waveform behavior with simpler implementation
- Improves timing by removing state transition logic
