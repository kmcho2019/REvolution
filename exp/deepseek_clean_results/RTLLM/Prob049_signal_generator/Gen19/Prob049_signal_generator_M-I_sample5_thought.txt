Improvement Strategy:

1. Timing Optimization:
   - Merge the two always blocks into one to eliminate the critical path between direction and wave registers
   - Simplify the boundary detection logic by using direct comparisons
   - Remove the combinational next_wave calculation to reduce logic depth

2. Power Optimization:
   - Eliminate the separate direction register by using wave's MSB as direction indicator
   - Reduce switching activity by only updating wave when necessary

3. Area Optimization:
   - Remove the direction register entirely
   - Simplify the arithmetic operations to basic increment/decrement
   - Use more efficient boundary detection logic

Key Improvements:
- Single always block reduces timing paths
- Wave MSB as direction indicator saves a flip-flop
- Direct comparisons simplify logic
- Maintains same functionality while improving PPA
