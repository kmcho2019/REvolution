Simplified approach using a single register and direction flag:

1. Key Simplifications:
   - Use a single 5-bit counter with explicit direction control
   - Eliminate the separate 6-bit counter and inversion logic
   - Directly implement up/down counting with simple arithmetic
   - Maintain same functionality with fewer operations

2. Benefits:
   - Reduced area by using only necessary bits
   - Clearer state machine with explicit direction control
   - Eliminates unnecessary bit inversion operations
   - Maintains same waveform generation behavior
