Novel approach using bidirectional counter with explicit direction control:

1. Key Innovations:
   - Uses a single 5-bit counter with explicit direction register
   - Eliminates the need for a 6-bit counter by tracking direction separately
   - Implements arithmetic operations directly for wave generation
   - Simplifies state transitions by using comparison operations

2. Advantages:
   - More intuitive state machine with clear up/down states
   - Reduced bit width (5-bit counter + 1-bit direction vs 6-bit counter)
   - Direct arithmetic operations for better synthesis optimization
   - Clear separation between counting and direction logic
   - Easier to modify for different waveform ranges

3. Operation:
   - Direction register (dir) controls counting direction (0=up, 1=down)
   - Counter increments or decrements based on dir
   - State transitions occur at waveform boundaries (0 and 31)
   - Output is directly the counter value
