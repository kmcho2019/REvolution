Refactoring Strategy:

1. State Machine Simplification:
   - Replace the direction register with a combinational signal derived from wave's MSB
   - Eliminate separate state control logic by inferring direction from wave value
   - This reduces register count and simplifies control logic

2. Waveform Generation:
   - Use continuous assignment for next_wave calculation
   - Implement boundary detection through simple comparators
   - Maintain same increment/decrement behavior but with cleaner logic

3. Timing Improvements:
   - Reduce critical path by moving direction logic to combinational
   - Single always block for synchronous elements
   - Simplified arithmetic operations

Key Advantages:
- Fewer registers (eliminates direction flip-flop)
- Cleaner control flow with implicit state
- Reduced critical path by combining logic
- Maintains identical functionality with better PPA
