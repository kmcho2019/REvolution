Simplified approach using a single state bit and direct arithmetic:

1. Key Simplifications:
   - Use a single direction bit instead of a full counter
   - Directly compute next wave value based on current direction
   - Eliminate separate counter logic by using wave register itself
   - Maintain same functionality with fewer operations

2. Benefits:
   - Reduced logic complexity (only 1 state bit needed)
   - Clearer state transition logic
   - More efficient use of registers
   - Maintains same waveform generation behavior
