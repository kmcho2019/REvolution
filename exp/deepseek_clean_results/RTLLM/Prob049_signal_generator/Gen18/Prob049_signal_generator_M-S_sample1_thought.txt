Simplified approach using a single state bit and direct arithmetic:

1. Key Simplifications:
   - Use a single direction bit instead of a 6-bit counter
   - Directly compute next wave value based on current direction
   - Eliminate separate counter logic and continuous assignment
   - Maintain same triangle wave behavior (0-31 range)

2. Benefits:
   - Reduced register usage (1 state bit + 5 wave bits)
   - Clearer state transition logic
   - More straightforward arithmetic operations
   - Maintains same functionality with simpler implementation
