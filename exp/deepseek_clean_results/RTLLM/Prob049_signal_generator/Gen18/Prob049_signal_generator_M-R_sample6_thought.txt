Refactored design approach:
1. Maintain the same core concept of using a counter with automatic overflow handling
2. Replace the combinational always block with continuous assignments
3. Use a 5-bit counter instead of 6-bit by implementing explicit boundary detection
4. Replace the bit manipulation with arithmetic operations for clarity
5. Use a direction flag that toggles at boundaries to control increment/decrement

Key improvements:
- More explicit boundary handling makes the design intent clearer
- Continuous assignments reduce power by eliminating unnecessary always blocks
- 5-bit counter saves one flip-flop while maintaining functionality
- Direction flag makes the state transition logic more visible
