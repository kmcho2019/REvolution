Here's a novel approach using a bi-directional counter with boundary detection:

1. Instead of using a state machine or direction flag, we'll implement a self-adjusting counter that automatically reverses direction at boundaries
2. The key innovation is using arithmetic overflow/underflow detection to handle direction changes
3. We'll add a 6th bit to the counter (temporarily) to detect overflow when counting up past 31 (100000) or underflow when counting down past 0 (111111)
4. The actual 5-bit output is taken from the lower 5 bits of this extended counter
5. Reset initializes the counter to 0
6. The counting logic is simplified to a single continuous count operation that automatically wraps

Advantages:
- No explicit state machine or direction flag needed
- Boundary detection is handled naturally by arithmetic overflow
- Single continuous counting operation makes the logic very compact
- Maintains exact 0-31 range as specified
