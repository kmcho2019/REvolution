Refactored Design Strategy:
1. State Encoding: Use explicit parameterized states for better readability
2. Combinational Logic: Move next-state and output logic to continuous assignments
3. Registered Outputs: Keep only the state and wave registers in sequential block
4. Boundary Detection: Simplify using bitwise operations directly in assignments
5. Direction Control: Use a single direction flag instead of full state machine

Key Improvements:
- Clear parameter definitions for states
- Most logic moved to continuous assignments (reduces always block complexity)
- Simplified boundary detection logic
- Maintains same functionality with cleaner structure
- Potential for better synthesis optimization due to separated comb/seq logic
