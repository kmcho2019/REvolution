Refactoring Strategy:
1. State Machine Restructuring:
   - Replace the sequential always block with combinational logic for state transitions
   - Use continuous assignments for next-state logic
   - Maintain the same state encoding (0=increment, 1=decrement)

2. Waveform Generation:
   - Separate the arithmetic operations into combinational logic
   - Use a mux to select between increment/decrement operations
   - Keep boundary detection using bitwise operators

3. Synchronous Elements:
   - Use a single always block for sequential elements (state and wave registers)
   - Maintain the same reset behavior

Benefits:
- More explicit separation of combinational and sequential logic
- Potentially better synthesis results due to clearer operator boundaries
- Maintains same functionality while offering different optimization paths
