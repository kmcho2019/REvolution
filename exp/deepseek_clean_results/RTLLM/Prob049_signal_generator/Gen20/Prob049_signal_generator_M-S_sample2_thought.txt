Simplification Strategy:

1. Single Always Block:
   - Merge state and wave updates into a single always block for simpler control flow
   - Eliminate separate combinational logic for next state calculation

2. Simplified Direction Control:
   - Use direct increment/decrement with boundary checks
   - Remove separate direction register by using wave value boundaries

3. Efficient Boundary Detection:
   - Keep simple equality comparisons for max (31) and min (0) values
   - Use arithmetic operations directly in the always block

Key Advantages:
- Reduced register count by eliminating direction flip-flop
- Simpler control flow with single always block
- Maintains same functionality with less logic
- Better timing by reducing combinational paths
