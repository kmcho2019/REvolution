Novel Counter-Based Architecture:
1. Dual-Counter Approach: Use a main counter for wave generation and a secondary counter to track direction
2. Automatic Reversal: Implement direction control through counter overflow/underflow detection
3. Efficient Boundary Check: Use simple arithmetic comparison instead of bitwise operations
4. State Encoding: Eliminate explicit state register by using counter's MSB as direction indicator
5. Power Optimization: Leverage counter properties for implicit power savings at boundaries

Key Innovations:
- Direction control embedded in counter's natural behavior
- Single arithmetic comparison replaces multiple bitwise operations
- No explicit state machine - reduced control logic
- Natural power savings at waveform peaks/valleys
- Scalable design that can easily adjust amplitude
