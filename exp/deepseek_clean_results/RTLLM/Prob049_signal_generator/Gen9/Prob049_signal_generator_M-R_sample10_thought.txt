Refactoring Strategy:
1. State Machine Restructuring:
   - Replace the sequential always block with combinational logic for state transitions
   - Use continuous assignments for the state and wave updates
   - This reduces the sequential logic to just the registers

2. Output Generation:
   - Separate the combinational next-state logic from the sequential state storage
   - Make the state transitions more explicit with dedicated wires

3. Optimization Benefits:
   - Clear separation of combinational and sequential logic
   - Potentially better synthesis results as the state machine is more explicit
   - Maintains same functionality while being more readable

Key Changes:
- Use wire declarations for next_state and next_wave
- Move all logic to continuous assignments
- Keep registers only for state storage
- Boundary checks become simple continuous expressions
