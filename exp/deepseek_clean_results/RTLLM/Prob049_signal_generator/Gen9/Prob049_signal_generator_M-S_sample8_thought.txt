Simplification approach:
1. Eliminate the explicit direction register by using the wave value boundaries to implicitly determine direction
2. Use a single always block with simple boundary checks
3. Maintain same behavior:
   - Increment until 31, then decrement
   - Decrement until 0, then increment
4. Key optimizations:
   - Remove direction register completely
   - Simplify logic to just boundary checks
   - Use simple arithmetic with boundary conditions
5. Benefits:
   - Reduced register count (5-bit wave only)
   - Simpler control logic
   - Same timing characteristics
   - More efficient implementation
