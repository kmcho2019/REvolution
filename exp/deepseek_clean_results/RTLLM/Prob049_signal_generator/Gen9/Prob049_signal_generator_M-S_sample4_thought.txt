Simplification Strategy:
1. Eliminate State Machine: Remove the explicit state/direction register and instead determine direction based solely on the current wave value. This reduces register usage.

2. Direct Boundary Detection: Use simple equality comparisons for boundary checks (wave == 31 and wave == 0) which are more straightforward than reduction operators.

3. Single Update Logic: Combine increment and decrement logic into a single statement using a ternary operator based on boundary conditions.

Key Benefits:
- Removes one register (dir) completely
- Simplifies control logic to pure combinational
- Maintains same functionality with fewer components
- Easier to understand and verify
