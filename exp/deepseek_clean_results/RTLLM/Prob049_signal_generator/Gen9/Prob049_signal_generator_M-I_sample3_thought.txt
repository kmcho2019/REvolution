To optimize the design for better PPA metrics, I'll implement these improvements:
1. Eliminate the separate direction register by using the MSB of an extended counter
2. Use a single adder with signed arithmetic to handle both increment and decrement
3. Simplify boundary detection by checking only relevant bits
4. Reduce combinational logic complexity by using arithmetic overflow/underflow

Key benefits:
- Removes direction register (reduces area and power)
- Single arithmetic operation (reduces area)
- Simpler boundary detection (reduces critical path)
- Maintains same functionality with fewer resources
