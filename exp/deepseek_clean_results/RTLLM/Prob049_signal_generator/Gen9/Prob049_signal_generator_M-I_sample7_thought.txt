Optimization Strategy:
1. Critical Path Reduction: Replace the combinational next_wave calculation with registered arithmetic to break the timing path
2. State Encoding: Use one-hot encoding for better timing and simpler decoding
3. Boundary Optimization: Eliminate the one-cycle hold by immediately changing direction
4. Power Reduction: Use Gray code encoding for the wave output to minimize switching activity
5. Area Efficiency: Share arithmetic logic between increment and decrement operations

Key Improvements:
- Registered arithmetic improves timing (reduces WNS)
- Immediate direction change at boundaries increases frequency
- Gray code reduces switching power
- Shared arithmetic unit reduces area
- One-hot state machine simplifies control logic
