Refactored design approach:
1. Replace the always block with continuous assignments for combinational logic
2. Use a separate always block just for sequential elements (registers)
3. Simplify the direction control logic by:
   - Making it purely combinational based on wave value
   - Removing the direction register
4. Calculate next_wave value combinationally
5. Maintain the same boundary behavior (0 to 31 triangle wave)

Benefits:
1. Clear separation of combinational and sequential logic
2. Reduced register count (no direction register needed)
3. More transparent data flow
4. Same functionality with potentially better timing
