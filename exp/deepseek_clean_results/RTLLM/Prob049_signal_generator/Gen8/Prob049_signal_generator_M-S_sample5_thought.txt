Simplification Strategy:
1. Eliminate State Machine: Remove the explicit state/direction register and instead use boundary detection directly in the wave update logic.

2. Single Always Block: Maintain all logic in one synchronous always block for simplicity.

3. Boundary Detection: Use simple equality comparisons for max (31) and min (0) values which are easier to understand.

4. Wave Update: Combine increment and decrement logic into a single statement using ternary operator based on current direction (implied by previous operation).

Key Benefits:
- Removes the dir register, reducing area
- Simplifies control logic to just boundary checks
- Maintains same functionality with clearer code
- Potentially improves timing by reducing critical path
