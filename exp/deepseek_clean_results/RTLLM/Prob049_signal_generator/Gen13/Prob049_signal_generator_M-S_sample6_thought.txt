Simplification Strategy:
1. State Elimination: Remove the explicit state variable by using wave value boundaries as implicit state indicators
2. Unified Logic: Combine increment/decrement operations into a single expression using conditional operator
3. Boundary Detection: Use simple equality checks for min (0) and max (31) values
4. Reset Handling: Maintain synchronous reset for consistent initialization

Key Improvements:
- Eliminates state register (saves area and reduces logic levels)
- Single always block with clear, linear logic flow
- Maintains same waveform behavior with fewer operations
- Uses arithmetic operation with direction flag instead of separate add/sub
