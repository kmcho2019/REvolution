Refactoring Strategy:
1. State Machine Transformation:
   - Convert the sequential always block to combinational logic for state transitions
   - Use continuous assignments (assign) for next-state logic
   - Maintain the same state encoding (0=increment, 1=decrement)

2. Waveform Generation:
   - Separate the arithmetic operations into dedicated combinational logic
   - Use a mux to select between increment/decrement operations
   - Keep boundary detection using bitwise operators for efficiency

3. Clocked Logic:
   - Use a single always block for sequential elements only
   - Clean separation between combinational and sequential logic

Benefits:
- Clearer separation of combinational and sequential logic
- More modular design with explicit next-state logic
- Potentially better synthesis optimization opportunities
- Maintains same functionality while improving code structure
