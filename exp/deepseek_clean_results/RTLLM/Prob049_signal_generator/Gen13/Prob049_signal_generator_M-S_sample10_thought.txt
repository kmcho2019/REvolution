The design can be simplified by:
1. Using a single 5-bit counter register for both counting and output
2. Adding a direction flag to control increment/decrement
3. Eliminating separate combinational logic for wave generation
4. Handling direction changes at boundaries with simple conditions
5. Maintaining the same 0-31 range with direct register output

This achieves:
- Single always block for all logic
- No separate combinational logic
- Clear state transitions at boundaries
- Minimal resource usage
