Refactoring Strategy:
1. State Machine Restructuring: Convert the case-based state machine to an assign-based approach using combinational logic for state transitions and wave updates. This reduces the sequential logic complexity.

2. Direction Flag Optimization: Use a single direction flag (dir) instead of separate states, where 0=increment and 1=decrement. This simplifies the control logic.

3. Boundary Detection: Implement boundary checks using reduction operators for more efficient comparison logic.

4. Output Generation: Use a continuous assignment for the wave output based on the current direction and boundary conditions.

Key Benefits:
- Reduced sequential logic complexity
- More efficient boundary detection
- Clearer separation of combinational and sequential logic
- Maintains same functionality while potentially improving timing
