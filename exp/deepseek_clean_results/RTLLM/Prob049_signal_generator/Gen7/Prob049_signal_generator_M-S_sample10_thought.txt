The design can be simplified by:
1. Removing the explicit state register since the direction can be inferred from the wave value boundaries
2. Using a single always block with simpler conditional logic
3. Maintaining the same boundary behavior (hold at 0 and 31 for one cycle)
4. Reducing the logic to just:
   - Increment when not at max (31) and not decrementing
   - Decrement when not at min (0) and not incrementing
   - The direction flips automatically at boundaries

This achieves the same functionality with:
- Fewer registers (no state reg)
- Simpler control logic
- Same timing characteristics
- Reduced area
