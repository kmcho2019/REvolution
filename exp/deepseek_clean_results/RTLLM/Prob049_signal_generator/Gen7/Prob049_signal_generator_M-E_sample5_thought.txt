Innovative triangle wave generator using signed arithmetic:
1. Replace state machine with a signed counter approach
2. Use a 6-bit signed register (5-bit magnitude + sign) for the wave value
3. The increment value toggles between +1 and -1 at boundaries
4. Boundary detection is simplified to checking the MSB (sign bit) change
5. Key advantages:
   - Eliminates explicit direction flag
   - Uses arithmetic properties for natural boundary wrapping
   - Single arithmetic operation per cycle
   - More elegant boundary condition handling
   - Potential for better timing due to simpler control logic
