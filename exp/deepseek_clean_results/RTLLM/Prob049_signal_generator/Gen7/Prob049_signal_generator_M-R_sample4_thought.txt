Refactored solution using a Moore state machine with explicit state transitions:

1. Maintain the same core functionality but with cleaner state transitions
2. Separate the state transition logic from the wave update logic
3. Use a parameterized state definition for better readability
4. Ensure wave holds its peak (31) and trough (0) values for one full cycle
5. State transitions occur first, then wave updates based on new state
6. More explicit boundary conditions with no immediate wave changes during transitions

Key improvements:
- Clear separation between state logic and wave generation
- Proper waveform shape with full cycles at peaks and troughs
- More maintainable state machine structure
- No race conditions between state and wave updates
- Easier to modify or extend in the future
