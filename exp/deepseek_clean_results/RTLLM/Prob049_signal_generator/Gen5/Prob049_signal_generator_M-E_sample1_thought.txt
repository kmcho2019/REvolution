Here's an innovative approach using a reversible shift register with edge detection:

1. Instead of using arithmetic operations, we'll implement the triangle wave using a bidirectional shift register
2. The 5-bit wave register will shift left (with 0 fill) when incrementing, and shift right (with 1 fill) when decrementing
3. Direction changes are detected by monitoring the MSB and LSB:
   - When all bits are 0 (except potential LSB), we switch to increment mode
   - When all bits are 1 (except potential MSB), we switch to decrement mode
4. Reset initializes to all zeros
5. The design uses minimal arithmetic logic and instead relies on bit manipulation

Key advantages:
- No arithmetic operations needed (no adders/subtractors)
- Simple boundary detection using bit patterns
- Power efficient as only one bit changes per clock (except direction changes)
- Scalable to any bit width with same logic
