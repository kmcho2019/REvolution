Innovative Approach: Directional Counter with Boundary Detection

1. Architectural Innovation:
   - Replace state machine with a direction flag (up/down)
   - Use arithmetic operations to automatically reverse direction at boundaries
   - Eliminate explicit state transitions by computing next direction

2. Key Benefits:
   - Reduced logic levels (faster timing)
   - Single always block with simpler conditions
   - Direction automatically toggles at boundaries
   - More elegant boundary handling

3. Operation:
   - Maintain a direction register (1=up, 0=down)
   - At each clock:
     * Add +1 or -1 based on direction
     * Toggle direction when hitting 0 or 31
   - Reset initializes to 0 with upward direction

4. Advantages:
   - No case statement needed
   - Direction changes are computed rather than state-transitioned
   - More compact implementation
   - Better timing characteristics
