Simplified Approach: Single Counter with State Machine

The key simplifications are:
1. Use a single counter (wave) instead of dual counters
2. Maintain a simple state machine (just 1 bit) to track direction
3. Directly implement the specified behavior:
   - Increment when state=0 until reaching 31
   - Decrement when state=1 until reaching 0
4. Reset initializes both state and wave to 0
5. Clean boundary detection using exact comparisons (==31 and ==0)

This approach:
- Uses minimal resources (single 5-bit counter + 1-bit state)
- Matches the problem specification exactly
- Has straightforward, easy-to-verify logic
- Eliminates potential synchronization issues of dual counters
- Maintains clean synchronous design practices
