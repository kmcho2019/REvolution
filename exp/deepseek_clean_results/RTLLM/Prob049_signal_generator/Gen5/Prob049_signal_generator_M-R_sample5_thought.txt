Here's a refactored version that maintains the same core functionality but uses different implementation techniques:

1. Instead of using an always block for the counter, we'll implement it with continuous assignments
2. The direction control will be handled by a simple flip-flop that toggles at boundaries
3. The wave output will be generated using a combinational assign statement
4. Reset will initialize both the counter and direction flip-flop
5. The counter will be 5-bit (0-31) with explicit direction control

Key differences from original:
- Uses explicit direction register instead of implicit 6-bit counter
- Separates sequential and combinational logic
- Uses assign for output generation
- More traditional state machine approach while keeping efficient counting
