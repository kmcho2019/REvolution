I'll implement a novel approach using a bidirectional counter with direction control. Instead of using a separate state register, I'll:
1. Use the MSB of the wave counter as a natural direction indicator
2. When wave reaches 31 (5'b11111), the MSB is 1, so we decrement
3. When wave reaches 0 (5'b00000), the MSB is 0, so we increment
4. This eliminates the need for a separate state register
5. The direction is determined by XORing the MSB with a derived signal that detects the boundaries

This approach reduces the state machine to simple combinational logic based on the wave value itself, making it more compact and potentially faster. The reset behavior remains the same, initializing wave to 0.
