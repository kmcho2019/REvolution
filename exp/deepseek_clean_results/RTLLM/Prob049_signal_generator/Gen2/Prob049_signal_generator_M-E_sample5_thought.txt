Here's a novel approach using a bidirectional counter with direction control:

1. Instead of using a state machine to control increment/decrement, we'll use a direction flag that toggles at boundaries
2. The wave register will always count in the current direction (either +1 or -1)
3. Boundary detection will simply invert the direction flag when hitting 0 or 31
4. This eliminates the need for separate state handling and makes the logic more compact
5. The direction flag is implemented as a single register that inverts at boundaries
6. The arithmetic operation becomes simply: wave <= wave + direction, where direction is either +1 or -1 (represented as 2's complement)

Benefits:
- More compact logic with fewer conditional statements
- Single arithmetic operation for all cases
- Clear separation of counting and boundary detection
- Maintains peak values for one full cycle before changing direction
