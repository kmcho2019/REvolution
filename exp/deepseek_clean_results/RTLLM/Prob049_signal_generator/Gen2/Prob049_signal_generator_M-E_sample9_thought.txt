Here's a novel approach that eliminates the explicit state machine by using arithmetic operations and boundary detection:
1. Instead of tracking state, we'll use a direction flag that toggles at boundaries
2. The wave value will be calculated using addition/subtraction based on the direction flag
3. Boundary conditions (0 and 31) will automatically reverse the direction
4. This approach reduces control logic and leverages arithmetic operations for more efficient synthesis

Key innovations:
- Single always block with arithmetic operations
- Direction flag automatically toggles at boundaries
- No explicit state machine case statements
- More compact and potentially faster implementation
