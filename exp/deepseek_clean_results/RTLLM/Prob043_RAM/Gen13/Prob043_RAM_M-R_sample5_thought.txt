Refactoring Approach:
1. Maintain the distributed register architecture but optimize the implementation
2. Replace individual register declarations with a packed array for better readability and potential synthesis optimization
3. Use a case statement for the read multiplexer instead of ternary operators for better synthesis results
4. Implement write operations using a generate block for scalability
5. Keep the synchronous write and combinational read structure
6. Maintain the same reset behavior and output zeroing when not reading

Key Improvements:
- More scalable structure (easy to change DEPTH parameter)
- Clearer code organization
- Better synthesis patterns (case statement for mux)
- Maintains all original functionality
- Same performance characteristics but with cleaner implementation
