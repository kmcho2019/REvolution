Refactoring Strategy:
1. Replace combinational always block with continuous assign for read_data
2. Move reset handling exclusively to synchronous blocks
3. Simplify read path by removing redundant reset logic
4. Maintain separate write and read operations
5. Benefits:
   - Cleaner separation of combinational and sequential logic
   - Reduced logic in read path
   - More straightforward timing analysis
   - Maintains same functionality with clearer structure

Key Changes:
- read_data now uses continuous assign with ternary operator
- Reset only affects memory array, not read_data directly
- read_data shows memory contents immediately when enabled
- Removed unnecessary reset propagation to read path
