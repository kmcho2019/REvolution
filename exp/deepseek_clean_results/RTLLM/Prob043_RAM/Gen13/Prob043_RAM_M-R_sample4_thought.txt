Refactoring approach:
1. Keep synchronous write operation but make reset more explicit
2. Change read operation to use continuous assignment with enable gating
3. Simplify memory declaration using parameterized dimensions
4. Use blocking assignments for reset to ensure immediate clearing
5. Benefits:
   - Clearer separation of read/write paths
   - More explicit reset behavior
   - Maintains same functionality while being more readable
   - Reduced gate count by eliminating unnecessary registers
   - Better timing for read path (combinational only when enabled)
