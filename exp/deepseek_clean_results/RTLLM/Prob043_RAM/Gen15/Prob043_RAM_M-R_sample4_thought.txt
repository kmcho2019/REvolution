Refactoring approach:
1. Maintain true dual-port functionality with independent read/write paths
2. Use synchronous write operation with write_en as enable condition (better for timing analysis)
3. Keep combinational read path for simplicity and performance
4. Simplify initialization using a for-loop in initial block
5. Remove unnecessary reset logic for memory array (initial block handles initialization)
6. Benefits:
   - More standard synchronous design (no derived clocks)
   - Clearer timing constraints
   - Reduced complexity in reset handling
   - Maintains same functionality while being more synthesis-friendly
