Refactoring Strategy:
1. Use packed array for memory storage to improve area efficiency
2. Implement synchronous write operation with proper clock enable (not gated clock)
3. Make read path fully combinational for immediate data availability
4. Use continuous assignments for output control
5. Simplify reset implementation using for-loop
6. Benefits:
   - More standard synchronous design practice
   - Better area utilization with packed array
   - Cleaner separation of read/write paths
   - Maintains same functionality while being more synthesis-friendly

Key Changes:
- Memory now declared as packed array [0:DEPTH-1]
- Write operation uses proper clock enable in always block
- Read path uses continuous assignment with case statement
- Reset implemented with for-loop for cleaner code
- Output remains 0 when not reading (could be changed to Z if needed)
