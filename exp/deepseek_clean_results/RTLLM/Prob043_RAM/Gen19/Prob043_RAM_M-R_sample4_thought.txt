Refactoring approach:
1. Maintain true dual-port functionality with independent read/write paths
2. Replace clock gating with standard synchronous write operation using write_en as enable
3. Simplify initialization using a for-loop in initial block
4. Keep combinational read path but make output behavior more consistent (hold last read value when disabled)
5. Benefits:
   - More standard synchronous design for better timing analysis
   - Reduced power consumption by avoiding unnecessary output toggling
   - Clearer separation of read/write operations
   - More maintainable initialization
   - Preserves all original functionality while being more robust
