Refactoring approach:
1. Use continuous assignments for both read and write operations to simplify the design
2. Implement memory as a register array with synchronous reset capability
3. Make read operation truly asynchronous (not clock-dependent) for immediate data availability
4. Simplify write operation by removing explicit reset handling since memory will initialize to zeros
5. Use parameterized constants consistently throughout the design
6. Remove unnecessary conditional clearing of read_data when not enabled
