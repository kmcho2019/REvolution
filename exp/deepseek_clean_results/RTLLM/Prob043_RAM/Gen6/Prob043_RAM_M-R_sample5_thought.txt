Refactoring approach:
1. Keep synchronous write operation but simplify reset logic using generate block
2. Use continuous assignment for read operation (combinational)
3. Remove integer counter for reset by using parameterized for-loop
4. Separate reset and write logic into distinct always blocks for clarity
5. Benefits:
   - More modular design with clear separation of concerns
   - Eliminates integer variable, reducing simulation overhead
   - Maintains same functionality while being more maintainable
   - Still meets all original requirements with same performance
