Simplified Design Approach:
1. Remove redundant initial block and use synchronous reset for initialization (more standard practice)
2. Keep combinational read path for simplicity and area efficiency
3. Maintain synchronous write operation for timing consistency
4. Simplify memory declaration by directly using parameters
5. Remove unnecessary complexity while preserving all required functionality
6. Benefits:
   - Fewer blocks to maintain (no initial block)
   - Clear reset behavior
   - Maintains same read/write functionality
   - More standard implementation pattern
   - Reduced code complexity
