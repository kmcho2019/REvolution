Simplification Strategy:
1. Use a packed array for memory storage instead of discrete registers - more compact and easier to maintain
2. Implement synchronous write operation with standard clock and enable signal (no clock gating)
3. Make read operation purely combinational for simplicity and immediate data availability
4. Maintain separate read/write ports for true dual-port operation
5. Keep reset functionality to initialize all memory locations to 0
6. Simplify output logic - only drive read_data when read_en is active

Key Improvements:
- Removes clock gating which could cause timing issues
- Uses standard memory array declaration
- Simpler and more maintainable code structure
- Maintains same functionality with less complexity
- Better for synthesis and timing analysis
