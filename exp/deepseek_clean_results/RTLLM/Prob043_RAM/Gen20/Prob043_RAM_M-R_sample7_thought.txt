Refactoring Strategy:
1. Use packed array for memory to improve area efficiency and enable better synthesis optimization
2. Implement synchronous write operation with proper clock enable instead of clock gating
3. Make read path fully combinational for immediate data availability
4. Use continuous assignments for output control
5. Maintain same functionality while improving timing and area characteristics

Key Improvements:
- Memory array now uses packed array format (reg [WIDTH-1:0] mem [0:DEPTH-1])
- Write operation uses standard synchronous design with enable
- Read operation remains combinational but with cleaner implementation
- Output control uses simple continuous assignment
- Reset implemented with for-loop for cleaner code
