Refactoring approach:
1. Simplify memory structure by using a single always block for writes
2. Make read path truly asynchronous (combinational) without enable gate
3. Optimize reset implementation to clear memory in one cycle
4. Remove generate block in favor of simpler for-loop initialization
5. Benefits:
   - Reduced area by eliminating redundant always blocks
   - Cleaner separation of read/write paths
   - More efficient reset handling
   - Maintains same functionality while being more concise
   - Better synthesis results due to simpler control logic
