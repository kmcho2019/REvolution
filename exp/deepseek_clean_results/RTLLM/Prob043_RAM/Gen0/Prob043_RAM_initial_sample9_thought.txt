To implement a dual-port RAM with the specified requirements:
1. Create a 6-bit wide, 8-deep memory array initialized to all zeros
2. Implement synchronous write operation when write_en is high, writing data to write_addr
3. Implement synchronous read operation when read_en is high, outputting data from read_addr
4. Handle reset to clear memory and read output
5. Allow simultaneous read and write operations
6. Use non-blocking assignments for sequential logic
