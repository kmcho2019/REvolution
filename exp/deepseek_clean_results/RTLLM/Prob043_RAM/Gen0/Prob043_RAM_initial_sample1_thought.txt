To implement a dual-port RAM with the specified requirements:
1. Create a 6-bit wide, 8-location deep memory array initialized to all zeros
2. Implement synchronous write operation on positive clock edge when write_en is high
3. Implement synchronous read operation on positive clock edge when read_en is high
4. Include asynchronous active-low reset to clear memory and read_data
5. Separate the read and write ports to allow simultaneous operations
6. Maintain all outputs at zero when not enabled or during reset
