Simplified design with these key changes:
1. Removed separate read_data_reg since we can directly assign from memory
2. Simplified reset logic by initializing memory to zero in declaration
3. Combined write and read operations into single always blocks
4. Made read_data output zero when not enabled (simpler than maintaining previous value)
5. Reduced redundant logic and registers

The simplification maintains all functionality while:
- Reducing area by eliminating unnecessary registers
- Improving readability with more straightforward logic
- Keeping the same timing characteristics for critical paths
- Maintaining the same power profile for active operations
