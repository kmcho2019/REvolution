Refactoring approach:
1. Move from combinational read to registered read for better timing
2. Combine initialization and reset into a single synchronous process
3. Use parameterized address width based on DEPTH
4. Benefits:
   - Registered read improves timing closure
   - Single reset/initialization process is more maintainable
   - Parameterized address width makes the module more flexible
   - Still maintains same functionality while being more robust
   - Reduces potential glitches on read_data output
