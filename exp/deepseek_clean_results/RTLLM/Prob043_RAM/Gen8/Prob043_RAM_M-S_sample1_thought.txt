Simplification approach:
1. Remove the combinational read path and make it fully synchronous for better timing
2. Simplify reset logic by initializing memory to zero only at startup
3. Remove unnecessary read_en conditional - always output the addressed data
4. Make write operation purely synchronous without reset interference
5. Benefits:
   - More predictable timing with fully synchronous design
   - Simplified control logic
   - Reduced area by eliminating read_en logic
   - Still meets all original requirements (read/write can still happen simultaneously)
