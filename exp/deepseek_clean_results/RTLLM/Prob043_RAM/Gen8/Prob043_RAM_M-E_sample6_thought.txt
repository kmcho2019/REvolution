Novel Architecture: Distributed Pipeline RAM
1. Instead of a single memory array, implement 8 individual registers (one per address) with dedicated write logic
2. Each register has its own write enable signal derived from address decoding
3. Read operation uses a multiplexer tree for low-latency access
4. Key innovations:
   - Eliminates address decoding in write path (each register has direct enable)
   - Parallel write enables reduce critical path
   - Multiplexer-based read provides combinational output
   - Reset is distributed across registers
5. Benefits:
   - Faster write operations (no address decoder in critical path)
   - Lower power for partial writes (only target register toggles)
   - Clear physical mapping for place-and-route
   - Scalable to wider/narrower configurations
6. Tradeoffs:
   - Slightly larger area due to individual register enables
   - Read mux grows with depth (but acceptable for DEPTH=8)
