Refactoring Strategy:
1. Convert the synchronous write operation to use continuous assignment with clock gating
2. Replace the for-loop reset with individual register declarations for better synthesis control
3. Use ternary operators for both read and write paths to maintain combinational behavior
4. Implement the memory array as separate registers for better visibility and control
5. Benefits:

   - Better synthesis optimization potential with discrete registers
   - Clearer separation of read/write paths
