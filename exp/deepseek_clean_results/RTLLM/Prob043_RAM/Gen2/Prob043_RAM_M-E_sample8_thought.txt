Novel Architecture: Pipelined Dual-Port RAM with Latch-Based Output
1. Uses a two-stage pipeline for read operations to improve timing (better WNS)
2. Implements output data latching to avoid unnecessary clearing of read_data
3. Optimized reset strategy that only resets when needed
4. Separate always blocks for reset and normal operation to reduce power
5. Uses a parameterized address width calculation for better scalability
6. Implements write-through behavior for simultaneous read/write to same address
7. Output maintains last read value when read_en is low (more power efficient)
