Novel Bank-Switching Architecture:
1. Split the RAM into two identical banks (Bank A and Bank B) of 4 locations each
2. Implement a write pointer that alternates between banks on each write
3. Read operations can access either bank independently
4. Benefits:
   - Natural double-buffering prevents read/write conflicts
   - Higher effective throughput as reads can occur from one bank while writing to the other
   - Simplified timing with registered outputs
   - Built-in write protection against simultaneous same-address access
5. Implementation:
   - Use LSB of address to select bank
   - Maintain separate write pointers for each bank
   - Register outputs for clean timing
   - Reset initializes both banks and pointers
