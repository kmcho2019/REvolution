Refactoring approach:
1. Keep the dual-port functionality with independent read/write operations
2. Make read operation truly asynchronous (combinational) for better timing
3. Separate reset and write logic into distinct always blocks for clarity
4. Use parameterized constants for better maintainability
5. Remove redundant initialization since reset handles it
6. Simplify read_data output to only show memory content when enabled

Key improvements:
- Clear separation of combinational read and synchronous write paths
- More modular code structure
- Reduced redundant operations
- Better timing characteristics with asynchronous read
- Maintains same functionality while being more efficient
