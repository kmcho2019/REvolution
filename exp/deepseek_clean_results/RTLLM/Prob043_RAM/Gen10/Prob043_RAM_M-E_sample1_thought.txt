Novel Architecture: Distributed Pipelined RAM with Shadow Registers

Key Innovations:
1. Dual-phase operation: Combines the benefits of synchronous writes and asynchronous reads
2. Shadow registers: Each memory location has a shadow copy for clean read-during-write behavior
3. Pipelined output: Read data is registered for better timing closure
4. Power-optimized design: Only updates shadow registers when needed
5. Conflict resolution: Implements write-through behavior for simultaneous read/write to same address

Operation:
- Write Phase (clock edge):
  * Main memory updated on clock edge when write_en=1
  * Shadow register updated only if address matches write address
- Read Phase (continuous):
  * Always reads from shadow registers for clean data
  * Output register captures data when read_en=1

Advantages:
- Eliminates read/write conflicts
- Improves timing with registered output
- Reduces power by minimizing shadow updates
- Maintains high throughput with pipelining
- Clean interface behavior
