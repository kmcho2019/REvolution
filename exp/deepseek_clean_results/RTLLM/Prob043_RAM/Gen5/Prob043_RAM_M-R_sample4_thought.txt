Refactored design with these key changes:
1. Separated combinational and sequential logic for better timing
2. Used continuous assignment for read_data output when enabled
3. Simplified reset logic using a for-loop
4. Made read_data output zero only when not enabled (maintains previous value otherwise)
5. Combined memory initialization and write operations in one always block
6. Removed redundant else clause in read operation

The refactoring improves:
- Timing by separating combinational read path
- Power by reducing unnecessary toggles
- Readability with more concise initialization
- Maintains same functionality while being more efficient
