Refactoring approach:
1. Maintain synchronous write operation but simplify reset logic using initial block
2. Use continuous assignment for read_data with ternary operator for enable control
3. Remove integer counter in reset by using generate block for initialization
4. Benefits:
   - Clear separation of combinational read and synchronous write paths
   - More efficient reset implementation without loop variable
   - Maintains same functionality while being more concise
   - Read output remains stable when read_en is low (outputs 0)
   - Easier timing closure with pure combinational read path
