Refactored design with these key changes:
1. Separated combinational and sequential logic for better clarity
2. Used continuous assignment for read_data output when read_en is active
3. Simplified reset logic using a for-loop for memory initialization
4. Made read_data output 0 only when reset is active, otherwise maintains last value when not reading
5. Kept write operation synchronous but made read operation combinational when enabled
6. Added parameterized memory initialization for better scalability

The main improvements are:
- Reduced power consumption by not forcing read_data to 0 when not reading
- Simplified code structure with clearer separation of concerns
- More scalable initialization using for-loop
- Maintained same functionality while being more power-efficient
