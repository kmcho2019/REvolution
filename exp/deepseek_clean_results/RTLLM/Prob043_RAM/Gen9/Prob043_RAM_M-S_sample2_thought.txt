Simplification Strategy:
1. Use packed array for memory storage (more compact and standard approach)
2. Remove clock gating (potential timing issues) and use standard synchronous write
3. Simplify read path with direct combinational assignment
4. Maintain same functionality with cleaner code structure
5. Benefits:
   - More standard memory implementation
   - Better synthesis results (smaller area)
   - Clearer and more maintainable code
   - Avoids potential timing issues from clock gating

Key Changes:
- Memory now implemented as standard packed array
- Write operation uses standard synchronous always block
- Read operation simplified to single combinational assignment
- Reset implemented with for-loop (more concise)
