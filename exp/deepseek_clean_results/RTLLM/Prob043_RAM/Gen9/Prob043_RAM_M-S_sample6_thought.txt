Simplified design approach:
1. Remove the combinational read path and make it synchronous for better timing closure
2. Eliminate the for-loop during reset by relying on synthesis initialization
3. Simplify read_data handling by maintaining value when not reading
4. Reduce logic by removing unnecessary zero-clear operations
5. Benefits:
   - Single always block for both read and write operations
   - Cleaner reset implementation
   - More power efficient (less toggling)
   - Better timing characteristics
   - Maintains all original functionality
   - Reduced area from simpler control logic
