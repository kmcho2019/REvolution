Refactored Architecture: Decoupled Control with Packed Array
1. Maintain the distributed control concept but use a packed array for memory storage
2. Key improvements:
   - Replace individual registers with packed array (more area-efficient)
   - Use case statement for read mux (better synthesis results)
   - Separate write logic into continuous assignment + always block
   - Optimize reset implementation
3. Benefits:
   - Maintains true parallel read/write capability
   - Reduced area through array usage
   - Clearer code structure
   - Better synthesis optimization potential
4. Changes:
   - Write address decoding moved to continuous assignment
   - Read mux implemented as case statement
   - Reset implemented through array initialization
