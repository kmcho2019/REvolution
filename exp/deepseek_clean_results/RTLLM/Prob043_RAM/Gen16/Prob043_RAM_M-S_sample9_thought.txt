Simplified design approach:
1. Remove initial block and initialize memory directly in reset logic for cleaner synthesis
2. Use continuous assignment for read_data with simpler enable control
3. Combine reset and write operations in single always block
4. Benefits:
   - Reduced code complexity with same functionality
   - More standard initialization approach (using reset)
   - Maintains synchronous write and combinational read
   - Clear separation of concerns
   - Easier to understand and maintain
