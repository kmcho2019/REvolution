Simplified ALU Implementation with Reduced Complexity

Key Simplifications:
1. Removed separate arithmetic flags computation - now computed unconditionally for simplicity
2. Simplified barrel shifter implementation by removing shift_active signal
3. Consolidated flag assignments into direct expressions
4. Removed intermediate wires where direct assignments are clearer
5. Maintained same functionality with cleaner code structure

Structural Changes:
1. Arithmetic unit now computes all results without gating
2. Barrel shifter simplified to direct conditional assignments
3. Flag generation directly tied to operation results
4. Removed redundant intermediate signals
5. Simplified comparison logic by using direct arithmetic results
