Hierarchical ALU with Operation-Specific Modules:

Novel Architecture:
1. Modular Design:
   - Break down ALU into independent functional units (arithmetic, logical, shift, compare)
   - Each unit handles its own flag generation
   - Central controller selects appropriate unit output

2. Pipelined Flag Calculation:
   - Separate flag calculation from main operation path
   - Allows parallel flag computation with result generation
   - Reduces critical path for complex operations

3. Optimized Resource Sharing:
   - Arithmetic unit handles both signed/unsigned operations
   - Shared shift amount logic across all shift operations
   - Unified comparison logic for SLT/SLTU

4. Advanced Features:
   - Early zero detection (speculative)
   - Carry-select adder for arithmetic operations
   - Multi-stage shift operations for better timing

Benefits:
- Better timing due to parallel flag calculation
- More scalable design (easy to add new operations)
- Optimized resource utilization
- Clear separation of concerns
