Simplified ALU Design with Direct Operation Mapping:

Key Simplifications:
1. Unified Operation Selection:
   - Single always block with case statement for clear operation mapping
   - Eliminated intermediate arithmetic/logical/shift blocks

2. Optimized Flag Logic:
   - Direct flag calculation within each operation case
   - Simplified carry/overflow using native Verilog arithmetic

3. Reduced Signal Count:
   - Removed redundant internal signals
   - Used direct assignments for all outputs

4. Cleaner Implementation:
   - Consolidated shift amount selection
   - Simplified comparison operations
   - Removed high-impedance states (not needed for ALU)

Benefits:
- Clearer operation-to-code mapping
- Reduced logic levels for better timing
- More maintainable structure
- Preserved full functionality with less code
