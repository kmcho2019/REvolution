Simplified ALU Design:

Key Simplifications:
1. Combine ADD/ADDU and SUB/SUBU operations since they differ only in overflow/carry handling
2. Remove redundant flag assignments by computing them directly in the operation cases
3. Simplify shift operations by using a single shift amount selection
4. Eliminate separate negative flag computation by using r[31] directly
5. Remove default case since all operations are covered
6. Simplify zero flag by using direct comparison

Implementation Changes:
- Single case statement with combined arithmetic operations
- Direct flag assignments within each operation case
- Simplified shift amount selection
- Removed default case since all operations are defined
- Direct zero flag assignment
- Reduced register declarations where possible
