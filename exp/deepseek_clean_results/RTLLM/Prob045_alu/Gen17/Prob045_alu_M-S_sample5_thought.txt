Simplified ALU Design: "Optimized Operation Selection and Flag Generation"

Key Simplifications:
1. Replaced continuous assignments with a single case statement for cleaner operation selection
2. Eliminated intermediate operation wires by computing results directly in case statement
3. Simplified shift amount logic by using b[4:0] directly for non-variable shifts
4. Combined signed/unsigned operations where possible (ADD/ADDU, SUB/SUBU)
5. Optimized flag generation to only compute when needed
6. Reduced redundant logic by computing carry and overflow in parallel with operations

Implementation Benefits:
1. Clearer operation selection hierarchy
2. Reduced unnecessary computation when operations aren't selected
3. More efficient use of hardware resources
4. Maintains all required functionality with simpler structure
5. Better timing characteristics with single case statement
6. More maintainable code structure
