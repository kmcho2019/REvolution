The ALU design follows these key principles:
1. Use a case statement to handle all supported operations based on the aluc control signal
2. For arithmetic operations (ADD/SUB), handle both signed and unsigned versions with proper overflow detection
3. For comparison operations (SLT/SLTU), set the flag output appropriately
4. For shift operations, properly handle variable and constant shifts with arithmetic vs logical variants
5. Generate status flags (zero, carry, negative, overflow) based on the operation result
6. Use temporary 33-bit registers for arithmetic operations to properly detect carry/overflow
7. Implement LUI by shifting the immediate value to the upper half
8. Default to high-impedance for undefined operations
