The ALU design will handle 32-bit operations for a MIPS-ISA CPU. Key considerations:
1. Use signed/unsigned operations appropriately (ADD/ADDU, SUB/SUBU)
2. Implement all logical operations (AND, OR, XOR, NOR)
3. Handle shift operations (SLL, SRL, SRA) with both immediate and variable shifts
4. Implement comparison operations (SLT, SLTU) that set the flag output
5. Generate status flags (zero, carry, negative, overflow)
6. Special handling for LUI (load upper immediate)
7. Default to high-impedance for undefined operations

The design will use a case statement to select operations based on aluc, with parallel flag generation.
