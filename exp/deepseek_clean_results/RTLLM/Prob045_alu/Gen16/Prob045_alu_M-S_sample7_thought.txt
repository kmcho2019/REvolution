Simplified ALU Design:

Key Simplifications:
1. Unified arithmetic operations: Combine ADD/ADDU and SUB/SUBU by treating them as unsigned when needed
2. Simplified shift operations: Use a single shifter with multiplexed shift amount
3. Optimized flag generation: Compute flags only when needed and simplify comparison logic
4. Removed redundant computations: Eliminate separate add/sub wires and compute inline
5. Simplified default handling: Use 0 instead of high-impedance for invalid opcodes

Implementation Changes:
- Single case statement with combined operations
- Inline arithmetic operations instead of pre-computing
- Simplified shift amount selection
- Direct flag assignment for SLT/SLTU
- Common flag updates moved into each operation case
- Default result set to 0 instead of high-impedance
