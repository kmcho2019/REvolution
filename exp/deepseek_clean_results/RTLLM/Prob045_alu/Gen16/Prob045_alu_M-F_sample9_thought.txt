Optimized ALU Design with PPA Improvements:

Key Optimizations Implemented:
1. Critical Path Reduction:
   - Shared adder/subtractor logic using a single arithmetic unit with operation selection
   - Implemented barrel shifter for all shift operations to reduce variable shift delay
   - Separated flag generation from main computation path

2. Power Optimization:
   - Changed default output to 0 instead of high-impedance to reduce power
   - Optimized SLT/SLTU logic to only compare relevant bits
   - Disabled unused flag computations for logical operations

3. Area Optimization:
   - Unified arithmetic operations using a single adder/subtractor with control
   - Single barrel shifter handles all shift operations
   - Simplified comparison logic for SLT/SLTU

Implementation Changes:
- Created shared arithmetic unit with signed/unsigned control
- Implemented efficient barrel shifter with muxed shift amount
- Optimized flag generation logic to only compute when needed
- Simplified SLT/SLTU to direct comparison without full 32-bit result
- Set default outputs to 0 for power efficiency
