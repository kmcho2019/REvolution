Optimized ALU Design: "PPA-Optimized ALU with Shared Resources"

Key Optimizations:
1. Resource Sharing: Combine arithmetic operations to share adders/subtractors
2. Precomputation: Compute a+b and a-b once and reuse results
3. Power Gating: Minimize unnecessary switching with default case handling
4. Critical Path Reduction: Move flag generation outside always block
5. Area Reduction: Optimize shift amount calculation and carry logic
6. Timing Improvement: Simplify overflow detection logic

Implementation Strategy:
1. Single precomputation of a+b and a-b for reuse
2. Shared shift amount calculation for all shift operations
3. Optimized carry calculation using only MSB
4. Power-efficient flag generation with conditional assignment
5. Simplified overflow detection with shared comparators
6. Default case optimization to minimize switching
