Refactored ALU Design: "Combinational Logic with Continuous Assignments"

Key Refactoring Changes:
1. Replaced always block with continuous assignments for all operations
2. Used ternary operators for operation selection instead of case statement
3. Separated flag generation into independent assign statements
4. Precomputed common arithmetic results (sum/diff) for reuse
5. Simplified shift operations by direct bit manipulation
6. Made all outputs purely combinational without registers

Implementation Approach:
1. Each operation is implemented as a separate assign statement
2. Final result is selected via nested ternary operators based on aluc
3. Arithmetic flags are computed directly from operation results
4. Shared intermediate results (like sum/diff) reduce redundant logic
5. Maintained same functionality but with purely combinational logic
6. Improved readability by grouping related operations
