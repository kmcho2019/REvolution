Refactoring Strategy:

1. Convert to a fully combinational design using continuous assignments (assign statements)
2. Group related operations together for better readability and potential synthesis optimization
3. Use hierarchical conditional operators to reduce long chains
4. Optimize flag generation by:
   - Computing zero directly from the result
   - Simplifying overflow detection with separate expressions for ADD/SUB
   - Combining related flag conditions
5. Use intermediate wires for common computations to avoid duplication
6. Maintain identical functionality while improving structure

Key Changes:
- Replace case statement with grouped conditional operators
- Move all computations to continuous assignments
- Precompute arithmetic results once but only when needed
- Simplify flag generation logic
- Better organize operation groups (arithmetic, logical, shift)
- Improve code readability through hierarchical structure
