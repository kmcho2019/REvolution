Novel Architectural Idea: Pipelined ALU with Operation Pre-computation

Key Innovations:
1. Two-stage pipeline to improve timing closure
   - Stage 1: Pre-compute all possible arithmetic/logical results in parallel
   - Stage 2: Select the correct result based on aluc
2. Optimized flag generation:
   - Zero flag uses parallel NOR tree for faster detection
   - Overflow detection uses predictive logic
3. Dedicated shift unit with barrel shifter implementation
4. Early SLT/SLTU computation to reduce critical path
5. Resource sharing for adder/subtractor using complement-and-add approach

Advantages:
1. Better timing due to pipeline stages
2. Parallel computation reduces critical path
3. More efficient flag generation
4. Better scalability for higher frequencies
