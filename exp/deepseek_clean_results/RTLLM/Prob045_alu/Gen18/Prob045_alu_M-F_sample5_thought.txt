Optimized ALU Implementation with PPA Considerations

Key Improvements:
1. Shared arithmetic unit for ADD/SUB operations to reduce area
2. Unified barrel shifter for all shift operations with mode control
3. Gated computation paths to minimize power consumption
4. Optimized flag generation logic to only compute needed flags
5. Maintained full functionality while improving efficiency

Structural Changes:
1. Single arithmetic unit with add/sub select
2. One configurable barrel shifter for all shift operations
3. Conditional computation of arithmetic flags
4. Shared comparison logic between SLT/SLTU and subtractor
5. Power-gated unused operation paths
