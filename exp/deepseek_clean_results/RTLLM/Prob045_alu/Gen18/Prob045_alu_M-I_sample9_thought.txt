Optimized ALU Design: "Selective Computation with Hierarchical Muxing"

Key Optimization Strategies:
1. Selective computation - Only calculate needed operations based on aluc[5:4] to reduce power
2. Hierarchical multiplexing - Two-level mux structure to reduce critical path
3. Shared resources - Reuse comparators and arithmetic units where possible
4. Gated clocking - Only activate relevant computation blocks
5. Optimized flag generation - Direct flag extraction from operations

Implementation Approach:
1. Group operations by type (arithmetic, logical, shift) and compute only needed group
2. Use first-level mux to select operation group, second-level for specific op
3. Share comparator between SLT/SLTU and zero detection
4. Optimize overflow detection with parallel sign computation
5. Implement power-aware shift amount calculation
6. Maintain same interface but with better PPA characteristics
