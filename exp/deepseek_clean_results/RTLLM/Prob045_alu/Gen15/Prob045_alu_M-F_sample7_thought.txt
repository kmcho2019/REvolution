Optimized ALU Design with PPA Improvements:

Key Optimizations:
1. Timing Improvements:
   - Separated arithmetic and logical operations to reduce critical path
   - Pre-computed common arithmetic results to minimize propagation delay
   - Simplified flag generation logic

2. Power Optimizations:
   - Added operation-specific flag computation to avoid unnecessary calculations
   - Implemented power-aware default state (high-impedance) for invalid opcodes
   - Reduced redundant computations in flag logic

3. Area Optimizations:
   - Unified shift operation logic with a single shifter block
   - Shared comparison logic between SLT/SLTU operations and flag generation
   - Consolidated arithmetic flag generation

Implementation Changes:
- Reorganized case statement to group similar operations
- Added explicit signed/unsigned handling for arithmetic ops
- Optimized flag generation to only compute when needed
- Improved default state handling
- Unified shift operations with common shift amount selection
