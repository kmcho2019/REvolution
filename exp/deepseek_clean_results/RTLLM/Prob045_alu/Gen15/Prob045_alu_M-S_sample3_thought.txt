Simplified ALU Design with Minimal Complexity:

Key Simplifications:
1. Unified arithmetic operations - Treat signed and unsigned operations the same way (Verilog handles them identically at bit level)
2. Simplified flag logic - Only calculate flags when needed (carry/overflow only for ADD/SUB)
3. Consolidated shift operations - Use same shift amount selection (a[4:0]) for all shifts
4. Removed redundant intermediate calculations - Compute flags directly from results
5. Simplified parameter set - Only include essential operations
6. Optimized output assignments - Move all outputs to single always block
7. Reduced conditional logic - Use simpler expressions where possible

Major Optimizations:
- Eliminated separate signed/unsigned operations (ADDU/SUBU)
- Simplified flag generation (only set when relevant)
- Unified shift operations under common logic
- Removed redundant comparisons
- Simplified overflow detection
- Reduced gate count through expression simplification
