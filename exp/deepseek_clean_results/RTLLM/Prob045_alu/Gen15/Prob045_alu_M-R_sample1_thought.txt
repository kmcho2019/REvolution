Refactored ALU Design: "Parallel Operation with Continuous Assignments"

Key Refactoring Changes:
1. Replaced always block with continuous assignments for all operations
2. Created separate wires for each operation result
3. Used a multiplexer-style selection for final result
4. Simplified flag generation logic
5. Maintained same functionality but with purely combinational logic
6. Improved readability by separating operation calculations from result selection

Implementation Approach:
1. Calculate all possible operation results in parallel
2. Use aluc to select the appropriate result via case statement in assign
3. Generate flags directly from selected result and operation type
4. Keep special case handling (LUI) as a separate calculation
5. Maintain same parameter definitions for operation codes
6. Simplify comparison operations with direct expressions
