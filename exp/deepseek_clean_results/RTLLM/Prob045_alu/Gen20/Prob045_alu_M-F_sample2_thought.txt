Optimized ALU Implementation with PPA Improvements

Key Optimizations:
1. Arithmetic path optimization: Separated adder and subtractor paths to reduce unnecessary computations
2. Flag computation gating: Only compute flags when needed for the current operation
3. Shared logic for bitwise operations: Consolidated AND/OR/XOR/NOR operations
4. Improved barrel shifter: Used logarithmic shifting for better timing
5. Overflow logic simplification: Removed overflow computation for non-arithmetic operations

Structural Changes:
1. Split arithmetic unit into separate add and subtract paths
2. Added operation-specific enable signals for flag computations
3. Created shared logic for bitwise operations
4. Implemented more efficient barrel shifter with shared shift logic
5. Simplified overflow detection to only activate for ADD/SUB operations
