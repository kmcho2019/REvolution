I'll refactor the ALU implementation using an always_comb block instead of continuous assignments. This approach:
1. Groups all combinational logic in a single always_comb block for better readability
2. Uses case statement for operation selection which is more scalable for many operations
3. Calculates all flags and results in one place
4. Explicitly handles all cases to avoid inferred latches
5. Maintains the same functionality but with cleaner structure
6. Uses localparam for operation codes to avoid potential conflicts
