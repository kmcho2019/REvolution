Optimized ALU Design with Balanced PPA Trade-offs

Key Improvements:
1. Arithmetic Unit Optimization:
   - Combined signed/unsigned adder with controlled sign extension
   - Simplified carry/overflow logic by separating signed and unsigned paths
   
2. Zero Detection Enhancement:
   - Implemented balanced 2-level OR tree for faster zero detection
   - Reduced critical path by computing in parallel with operations

3. Unified Shifter Refinement:
   - Consolidated shift amount selection logic
   - Shared arithmetic right shift logic between SRA and SRAV

4. Flag Generation Optimization:
   - Combined SLT/SLTU comparison logic
   - Simplified overflow detection with dedicated signed operation check

5. Power Efficiency:
   - Maintained high-impedance flag output when not used
   - Reduced redundant computations in arithmetic operations

The revised design maintains the original functionality while improving timing through balanced logic structures and reducing area through better resource sharing.
