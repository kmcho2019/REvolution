Refactored design approach:
1. Maintain the same 2-stage pipeline structure (32-bit chunks) but implement combinational logic using assign statements
2. Replace sequential always blocks with register assignments in a single clocked block
3. Use explicit carry calculation for better visibility
4. Combine all register updates into one always block for cleaner code organization
5. Keep the same pipeline timing (3 cycles total latency)
6. Use continuous assignments for intermediate combinational logic where possible
7. Maintain identical interface and functionality
