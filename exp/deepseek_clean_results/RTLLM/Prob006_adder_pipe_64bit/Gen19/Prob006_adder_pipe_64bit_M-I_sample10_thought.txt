Improvement Strategy:
1. Pipeline Optimization:
   - Reduce from 4 to 3 stages (22-bit chunks) for better PPA balance
   - More balanced stage delays (22-22-20 bits vs original 16-16-16-16)
   - Fewer pipeline registers reduces area

2. Timing Improvement:
   - Wider first stage (22 bits) reduces critical path
   - Carry-select like structure for middle stage
   - Final stage handles remaining 20 bits

3. Power Reduction:
   - Fewer pipeline stages means less clock power
   - Gated registers when i_en is low
   - Simplified carry propagation

4. Functional Enhancements:
   - Clearer pipeline structure
   - Better commented code
   - More robust reset handling
