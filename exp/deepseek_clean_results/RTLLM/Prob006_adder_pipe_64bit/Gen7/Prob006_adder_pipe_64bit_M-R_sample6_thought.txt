Refactored design approach:
1. Maintain the same 2-stage pipeline structure but implement with continuous assignments for combinational logic
2. Use explicit state tracking for pipeline stages instead of implicit register updates
3. Simplify the carry-select logic by unrolling the generate block into explicit segments
4. Make the pipeline control more visible through state transitions
5. Keep the same interface and core functionality (64-bit inputs, 65-bit output with enable)

Key improvements:
- More transparent pipeline state machine
- Clearer separation between combinational and sequential logic
- Easier to modify pipeline depth if needed
- Reduced reliance on generate blocks for better readability
- Same performance characteristics (2-cycle latency)
