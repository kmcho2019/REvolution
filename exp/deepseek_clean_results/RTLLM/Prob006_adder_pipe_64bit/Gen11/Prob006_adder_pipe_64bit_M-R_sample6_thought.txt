Refactored design approach:
1. Maintain 4-stage pipeline (16 bits per stage) but flatten register structure
2. Replace sequential always blocks with continuous assignments for combinational logic
3. Use explicit pipeline registers with clear data flow
4. Separate carry chain from sum calculation for better visibility
5. Simplify enable signal propagation using shift register
6. Use parameterized width for flexibility
7. Optimize register usage by only storing needed bits at each stage

Key improvements:
- Flattened pipeline registers for better synthesis
- Explicit carry propagation between stages
- Clear separation of data and control paths
- Reduced register usage by only storing relevant bits
- Parameterized design for flexibility
- More efficient use of generate blocks
