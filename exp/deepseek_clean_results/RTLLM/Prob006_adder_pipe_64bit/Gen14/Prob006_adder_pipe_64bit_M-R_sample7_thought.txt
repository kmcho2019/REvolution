Refactored Design Approach:
1. Maintain the same 3-stage pipeline structure but implement combinational logic using assign statements
2. Replace sequential always blocks with explicit register instantiations for clarity
3. Use a separate always block just for the enable signal pipeline
4. Keep the same timing characteristics (3-cycle latency)
5. Simplify the carry propagation by using direct 65-bit addition
6. Make the pipeline stages more explicit by separating them clearly

Key Improvements:
- Clear separation of combinational and sequential logic
- More explicit pipeline stage boundaries
- Reduced complexity in the always blocks
- Maintained identical functionality and interface
- Improved readability with distinct sections for each pipeline stage
