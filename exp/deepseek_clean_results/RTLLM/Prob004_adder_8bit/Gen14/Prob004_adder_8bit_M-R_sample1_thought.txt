Refactoring approach:
1. Instead of using a generate loop, implement the ripple-carry adder using continuous assignments for each bit explicitly
2. Maintain the same full-adder logic (sum as XOR and carry as majority function)
3. Make the carry chain more visible by showing each bit's carry propagation
4. Keep the same XOR-based sum calculation but express it directly for each bit
5. The functionality remains identical but the structure is more explicit about the bit-level operations

This makes the ripple-carry propagation immediately visible in the code while maintaining the same logic and performance characteristics.
