Novel Architecture Idea: State Machine with Delayed Output
1. State-Based Approach:
   - Use a finite state machine (FSM) with 9 states (IDLE + 8 data collection states)
   - Each state represents the collection of a specific bit position
   - Eliminates explicit counter, using state transitions instead

2. Output Handling:
   - Register output data only when complete (after 8 bits)
   - Generate dout_valid for exactly one clock cycle after collection
   - Prevents glitches on output during shifting

3. Shift Mechanism:
   - Build parallel output by OR'ing shifted inputs
   - Each state accumulates its bit in the correct position
   - Clear separation between collection and output phases

Key Advantages:
- More explicit state control through FSM
- Output only changes when complete (reduces power)
- Clean one-cycle valid pulse
- Easier to modify for variable-length conversions
- Better timing for output signals
