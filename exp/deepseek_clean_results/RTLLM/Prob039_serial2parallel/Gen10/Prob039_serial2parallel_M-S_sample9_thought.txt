Simplified approach using single register and counter:
1. Eliminate state machine by using counter value directly to determine output phase
2. Use single 8-bit shift register to accumulate bits (simpler than dual-buffer)
3. When counter reaches 7 (8 bits collected), output the register contents
4. Reset counter after output and continue collecting
5. Advantages:
   - Reduced logic complexity (no state machine)
   - Fewer registers (only one 8-bit register needed)
   - Same functionality with simpler implementation
   - Better timing due to reduced logic levels
