Simplified design approach:
1. Remove the state machine since we only need to track bit count and shift data
2. Use a single always block for all sequential logic
3. Simplify counter to just track when we have 8 bits (no need for position tracking)
4. Output valid is just a pulse when counter reaches 8
5. Shift register accumulates bits on every valid input
6. Reset clears all registers
7. Parallel output updates immediately when 8 bits are collected

Key simplifications:
- Eliminated state machine (reduced to simple counter)
- Removed separate bit position tracking
- Simplified output valid generation
- Reduced number of registers
- Single always block for all sequential logic
