Here's a novel approach using a circular buffer architecture with pointer-based addressing instead of a traditional shift register:

1. Instead of shifting bits, we'll use a write pointer to track where to store the next incoming bit
2. The circular buffer allows us to write bits in any order while maintaining correct MSB-first ordering
3. A separate read pointer triggers when 8 bits are collected
4. The output is generated by reading the buffer contents in order when complete
5. This approach reduces the combinational logic of shifting and may offer better timing

Key advantages:
- Eliminates the large fan-out of shift register chains
- More flexible for variable-length conversions if needed
- Clear separation between write and read operations
- Easier to pipeline if needed for higher performance
