Improvement Strategy:
1. Timing Optimization: Eliminate the OUTPUT state to reduce state machine complexity and critical path. The parallel output can be registered directly when the last bit is received.
2. Power Optimization: Remove the intermediate valid_pulse register and generate dout_valid directly from the state machine logic.
3. Area Optimization: Simplify the bit counter logic by using a parameterized comparison.
4. Performance: Use a single always block for cleaner synthesis and better timing closure.
5. Maintainability: Keep the parameterized width but ensure all logic uses it consistently.

- Remove OUTPUT state and valid_pulse register
- Generate dout_valid combinationally when last bit is received
- Simplify counter logic with parameterized comparison
