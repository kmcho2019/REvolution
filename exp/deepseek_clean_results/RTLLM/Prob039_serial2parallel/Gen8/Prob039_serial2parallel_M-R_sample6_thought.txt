Refactored design approach:
1. Separate the counter and shift register logic into distinct always blocks for better modularity
2. Use combinational logic for dout_valid generation to make timing more explicit
3. Implement the shift operation with a concatenation that clearly shows MSB-first ordering
4. Move reset logic to its own always block for cleaner separation of concerns
5. Use non-blocking assignments consistently for all register updates
6. Make the 8-bit threshold a parameter for potential configurability
