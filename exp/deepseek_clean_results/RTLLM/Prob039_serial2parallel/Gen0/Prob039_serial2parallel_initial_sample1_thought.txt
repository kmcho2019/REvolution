The design involves creating a shift register that collects serial input bits and converts them to parallel output when 8 bits are received. Here's the thought process:
1. Use an 8-bit shift register to accumulate incoming serial bits
2. Use a 3-bit counter (since 2^3=8) to count valid input bits
3. When counter reaches 7 (meaning 8 bits received), output the accumulated bits
4. Reset the counter and shift register when reset is active
5. Generate dout_valid for one clock cycle when parallel data is ready
6. Shift in new bits only when din_valid is high
