Novel approach using a circular buffer with write pointer:
1. Instead of shifting bits, we'll use a write pointer to directly place each incoming bit in its correct position
2. The write pointer (wr_ptr) increments on each valid input and wraps around after 8 bits
3. Parallel output is registered only when we complete a full cycle (8 bits)
4. Valid signal is generated combinatorially when wr_ptr wraps around
5. This approach eliminates the shifting operation, reducing dynamic power
6. The design maintains clean synchronous operation with proper reset
