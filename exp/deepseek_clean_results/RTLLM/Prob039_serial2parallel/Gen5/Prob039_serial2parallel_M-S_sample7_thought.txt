Simplified design approach:
1. Eliminate explicit state machine - just use a counter since we only need to track 8 bits
2. Single shift register serves both for accumulation and final output
3. Counter increments only when din_valid is high
4. Output valid is simply when counter reaches 7 (0-7 counts = 8 bits)
5. Reset clears all registers and counter
6. More compact and efficient while maintaining same functionality
