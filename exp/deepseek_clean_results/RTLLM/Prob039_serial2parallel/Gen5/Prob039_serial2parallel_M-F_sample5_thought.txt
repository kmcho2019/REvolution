The corrected design implements a straightforward shift-register approach with these key improvements:

1. **Shift Register**: Uses an 8-bit register to accumulate serial bits from MSB to LSB
2. **Bit Counter**: Tracks received bits with a 3-bit counter (0-7)
3. **Output Generation**: Only updates dout_parallel when all 8 bits are received
4. **Valid Signal**: Pulses dout_valid for one cycle when output is ready
5. **Bit Ordering**: Properly implements MSB-first ordering as specified
6. **Reset Handling**: Clears all registers and counters on reset
