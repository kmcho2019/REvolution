Refactoring Strategy:
1. Simplified Counter Approach:
   - Replace one-hot encoding with a simple 3-bit binary counter for clearer bit position tracking
   - Maintain same functionality but with more straightforward logic

2. Combinational Output Assignment:
   - Use continuous assignments for outputs where possible
   - Keep sequential logic only for necessary state elements

3. Clear State Transitions:
   - Explicitly show the counting and output generation logic
   - Remove clock gating complexity for better readability

Key Changes:
- Binary counter instead of one-hot encoding
- Separate combinational and sequential logic clearly
- Maintain same interface and functionality
- Simplified control logic
- Better alignment with standard design practices
