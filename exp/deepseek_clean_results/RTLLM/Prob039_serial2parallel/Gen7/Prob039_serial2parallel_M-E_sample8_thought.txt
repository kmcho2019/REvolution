Novel Architectural Idea:
1. Use a dual-buffer ping-pong architecture to enable continuous data processing
2. Implement a write-select mechanism to alternate between buffers
3. Introduce a shadow register for parallel output to prevent glitches
4. Optimize timing by pre-decoding the counter state
5. Use a one-hot encoded counter for efficient state transitions

Key Innovations:
- Dual buffers allow simultaneous collection and output phases
- Write-select logic enables seamless buffer switching
- Shadow register ensures clean output transitions
- Pre-decoded counter signals reduce critical path
- One-hot encoding minimizes counter transition power
- Maintains full throughput with no dead cycles
