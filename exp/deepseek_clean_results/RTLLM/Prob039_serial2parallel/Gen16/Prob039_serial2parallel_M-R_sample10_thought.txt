Refactoring Strategy:
1. Simplified State Machine: Reduce to 3 states (IDLE, COLLECT, DONE) for cleaner control flow
2. Combinational Logic: Use assign statements for output signals where possible
3. Shift Register: Maintain the shift operation but simplify the control logic
4. Counter Optimization: Use a 3-bit counter (0-7) directly for bit counting
5. Output Generation: Generate dout_valid combinationally based on state and counter
6. Reset Handling: Clear all registers synchronously for better timing

Key Changes:
- Eliminated redundant OUTPUT state by combining with IDLE
- Moved dout_valid generation to combinational logic
- Simplified counter and shift register control
- Maintained same functionality with reduced state transitions
- Improved readability with separate always blocks for state and data
