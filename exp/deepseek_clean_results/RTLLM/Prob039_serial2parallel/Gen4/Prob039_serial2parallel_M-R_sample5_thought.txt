Refactored design using a more explicit state machine approach with enumerated states for better readability and maintainability. Key changes:
1. Replace counter with explicit state machine (IDLE and COLLECT states)
2. Use separate shift register and output register for cleaner data flow
3. Make all outputs registered for better timing
4. Use parameterized state encoding for flexibility
5. Explicit state transitions make the design intent clearer

Benefits:
- More readable and maintainable state machine
- Clear separation of shift and output registers
- All outputs are registered (better timing)
- Easier to modify for different parallel widths
