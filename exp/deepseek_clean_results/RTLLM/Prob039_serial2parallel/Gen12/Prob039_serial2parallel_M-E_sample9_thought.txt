Novel approach using circular buffer with dynamic pointer:
1. Instead of shifting bits, use a circular buffer with a write pointer
2. The pointer increments on each valid input, wrapping around after 8 bits
3. When pointer wraps around, the collected data is ready for parallel output
4. Advantages:
   - Eliminates the need for bit shifting, reducing combinational logic
   - Pointer arithmetic is simpler than shift operations
   - Naturally handles wrap-around without extra logic
   - Easier to extend for different parallel widths
5. Implementation:
   - 3-bit pointer tracks current write position
   - Buffer collects bits in circular fashion
   - On pointer wrap (7→0), output becomes valid
   - Reset clears both buffer and pointer
