Refactoring Strategy:
1. Counter-based approach: Use a 3-bit counter to track received bits (0-7)
2. Shift register: Implement as a circular buffer that shifts in new bits while maintaining previous values
3. Parallel capture: Store the complete 8-bit value when counter reaches 7
4. Valid signal: Generate combinatorially when counter is at 7 and din_valid is high
5. Reset handling: Clear all registers synchronously

Key Improvements:
- Simplified control logic by using direct counter comparison
- Clear separation between shift register and parallel output
- Combinational valid signal reduces critical path
- Proper synchronization of counter reset with parallel capture
- Maintains same functionality with more reliable timing
