Novel Approach: Shift Register with Pattern Matching

1. Core Concept:
   - Use a 3-bit shift register to track the last three input samples
   - Directly compare against the target pattern (3'b010) for pulse detection
   - This provides exact pattern matching with minimal state logic

2. Advantages:
   - Explicit pattern matching ensures precise detection
   - Simple extension to detect other patterns if needed
   - Clear timing relationship between input and output
   - No complex state machine transitions to manage

3. Implementation Details:
   - Shift register updates on each clock edge
   - Combinational comparison for pattern detection
   - Output registered for clean timing

4. Edge Cases Handling:
   - Reset clears the shift register
   - No false detection during initialization
   - Only matches exact 3-cycle pattern

5. Performance:
   - Fixed 3-cycle detection latency
   - Minimal combinational logic (just equality comparison)
   - Fully synchronous design with registered outputs
