I'll refactor the solution using a continuous assignment approach combined with a shift register. This eliminates the need for an always block for the output logic, making the design more concise. The key changes are:

1. Move the shift register to an always block (still needed for sequential logic)
2. Make data_out a continuous assignment that checks for the 010 pattern
3. Keep the reset logic in the always block for the shift register

Benefits:
- Clear separation of sequential (shift register) and combinational (pattern match) logic
- More concise output generation using continuous assignment
- Maintains same functionality while being slightly more readable
- Still maintains all the original PPA advantages
