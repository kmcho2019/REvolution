To improve the pulse detection, I'll refactor using a shift register approach instead of explicit state machines. This provides several advantages:

1. Shift Register Method:
   - Use a 3-bit shift register to track the last 3 cycles of data_in
   - Detect the specific pattern 010 (0->1->0) in the shift register
   - This eliminates explicit state management and simplifies the logic

2. Output Generation:
   - The output is registered to ensure clean timing
   - data_out is set when we detect the complete sequence
   - The shift register automatically handles timing alignment

3. Benefits:
   - More compact implementation
   - Easier to understand the pattern matching
   - Naturally handles the 3-cycle window requirement
   - Clear relationship between input sequence and output

4. Reset Behavior:
   - Clears the shift register and output
   - Ready to detect new pulses after reset
