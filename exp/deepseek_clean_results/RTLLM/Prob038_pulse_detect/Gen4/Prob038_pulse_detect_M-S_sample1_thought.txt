Here's a simplified approach that maintains the same functionality with less complexity:

1. Simplified State Machine:
   - Uses only 3 states instead of 4
   - Eliminates the PULSE_DETECTED state by combining it with IDLE
   - Uses direct state transitions without enum types

2. Key Improvements:
   - Removes typedef/enum complexity
   - Uses simple binary state encoding
   - Combines reset and state logic in one always block
   - Output is generated directly from state transitions

3. Advantages:
   - Fewer states means simpler logic
   - No type casting issues
   - Same precise pulse detection (010 pattern)
   - Output behavior identical to original spec
   - Easier to verify and maintain
