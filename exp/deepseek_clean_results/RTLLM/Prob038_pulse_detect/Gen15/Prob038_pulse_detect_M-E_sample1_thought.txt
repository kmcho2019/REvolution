Novel Approach: Shift Register with Pattern Matching

1. Core Concept:
   - Use a 3-bit shift register to capture the last 3 cycles of data_in
   - Directly compare against the target pattern "010" (0->1->0)
   - Eliminates need for explicit state machine

2. Advantages:
   - Simpler implementation with fewer states
   - Naturally handles minimum pulse width requirement
   - Easily extensible for longer pattern detection

3. Implementation Details:
   - 3-stage shift register (data_in_ff) captures history
   - Pattern match occurs when register equals 3'b010
   - Output pulses for one cycle when match is found
   - Reset clears all registers

4. Edge Cases Handled:
   - Continuous 1's don't trigger false detection
   - Partial patterns (like 011) don't trigger
   - Glitches shorter than 3 cycles are ignored

5. Performance:
   - Single cycle latency from pattern completion to output
   - Minimal logic resources required
   - Clear timing characteristics
