To simplify the pulse detection while maintaining functionality:

1. Remove the parameterized pulse width since the requirement specifically asks for 3-cycle (0->1->0) detection
2. Use a simple 2-bit shift register to track the last two samples
3. Directly detect the pattern when current input is 0 and previous two were 1 then 0
4. Output immediately when pattern is detected without additional registration
5. Keep minimal state (just the shift register) and simple combinational detection

This approach:
- Reduces complexity by removing unused parameterization
- Uses minimal storage (2 bits)
- Provides immediate output when pulse is detected
- Maintains clear and simple logic
- Still meets all original requirements
