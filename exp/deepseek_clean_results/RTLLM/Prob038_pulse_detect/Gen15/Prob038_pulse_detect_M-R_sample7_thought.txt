Refactored pulse detection using explicit state machine:

1. Maintain the edge detection approach but implement a proper 3-state FSM:
   - IDLE: Waiting for rising edge (0->1 transition)
   - GOT_RISE: Saw rising edge, waiting for falling edge
   - GOT_FALL: Saw falling edge, output pulse

2. Use combinational logic for state transitions and output generation
3. Separate the sequential state register from combinational next-state logic
4. Output is only high when in GOT_FALL state and immediately returns to IDLE
5. More robust than original as it explicitly tracks the required sequence
6. Clear state transitions make the design intent obvious
7. Maintains edge detection benefits while properly sequencing the pulse

Key improvements:
- Explicit state machine ensures correct sequence detection
- Only outputs at end of complete pulse (3 cycles)
- Handles back-to-back pulses correctly
- Clear separation of combinational and sequential logic
