Novel Approach: Shift Register with Pattern Matching

1. Core Concept:
   - Use a 3-bit shift register to capture the last 3 cycles of data_in
   - Directly compare against the target pattern "010" (0->1->0)

2. Advantages:
   - Eliminates complex state machine logic
   - Simple pattern matching implementation
   - Easily extensible to detect other pulse patterns
   - Reduced gate count compared to FSM approach

3. Implementation Details:
   - 3-stage shift register (data_in delayed by 2 clocks)
   - Combinational logic to detect "010" pattern
   - Registered output for clean timing
   - Asynchronous reset for all registers

4. Edge Cases Handling:
   - Proper initialization on reset
   - No false detection during initial cycles
   - Clean output pulse generation

5. Performance:
   - Single-cycle pattern detection latency
   - Minimal combinational logic delay
   - Fully synchronous design
