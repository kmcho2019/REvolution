Here's a novel approach using a finite state machine (FSM) with explicit states for pulse detection:

1. State Machine Design:
   - IDLE: Waiting for the start of a pulse (0->1 transition)
   - GOT_RISE: Detected rising edge, waiting for high signal
   - GOT_HIGH: Confirmed high signal, waiting for falling edge
   - PULSE_DETECTED: Complete pulse detected (1->0 transition)

2. Key Features:
   - Explicit state transitions make the design more readable and verifiable
   - Each state clearly represents a phase of pulse detection
   - Output is only asserted in the PULSE_DETECTED state
   - Automatic return to IDLE after pulse detection

3. Advantages:
   - More robust against glitches or metastability
   - Easier to modify for different pulse patterns
   - Clear state transitions aid in debugging
   - Can be extended for more complex patterns
