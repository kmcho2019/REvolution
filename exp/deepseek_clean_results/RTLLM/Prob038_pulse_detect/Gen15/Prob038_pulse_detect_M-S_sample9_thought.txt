To simplify the pulse detection while maintaining correct functionality, I'll use a 3-bit shift register to track the last three values of data_in. This allows us to:

1. Store the complete 3-cycle history needed for detection (0->1->0)
2. Perform pattern matching directly on the shift register contents
3. Generate the output purely combinationally when the pattern matches
4. Eliminate the need for a state machine while keeping the same behavior

The detection logic becomes a simple equality check for the 0->1->0 pattern (3'b010). The output is asserted only when this exact pattern appears in the shift register.
