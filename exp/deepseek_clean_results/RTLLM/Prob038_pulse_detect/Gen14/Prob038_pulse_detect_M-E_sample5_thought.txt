Novel pulse detection approach using edge detection:

1. Instead of tracking states or using shift registers, detect both rising and falling edges of the input signal
2. Use edge detectors to create short pulses for each transition
3. Implement a small delay (1 cycle) for the rising edge pulse
4. When a falling edge occurs while the delayed rising edge is active, we've detected our 0->1->0 pattern
5. This approach is more event-driven and may be more efficient for certain applications
6. Uses fewer registers than shift register approach while maintaining clear detection logic

Key advantages:
- Explicit edge detection makes the design intent very clear
- No need to store complete history, just relevant edge events
- Easily extensible to detect other pulse patterns
- Lower power potential as only edge events trigger logic
