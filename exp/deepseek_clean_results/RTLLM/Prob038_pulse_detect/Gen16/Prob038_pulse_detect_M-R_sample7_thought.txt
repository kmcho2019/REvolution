Refactored approach:
1. Instead of using an always block for both state and output, we'll separate the concerns:
   - Use an always block just for the history register (sequential logic)
   - Use a continuous assign statement for the combinational output logic
2. This makes the design more modular and easier to understand:
   - Sequential part clearly handles state
   - Combinational part clearly handles output generation
3. Benefits:
   - Clear separation of sequential and combinational logic
   - Output logic is purely combinational (no extra flip-flop)
   - Easier to modify output behavior without touching state logic
4. The functionality remains identical - still detects the 010 pattern
