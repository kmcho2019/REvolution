Here's a novel shift register-based approach that differs from the FSM solution:

1. Core Idea:
   - Use a 3-bit shift register to track the last 3 samples of data_in
   - Detect the specific pattern "010" in the shift register
   - Output is asserted when this pattern is detected

2. Key Features:
   - Simpler implementation than FSM (no explicit state transitions)
   - Uses bit pattern matching instead of state logic
   - Naturally handles continuous input streams
   - Easily extensible to detect different pulse patterns

3. Advantages:
   - More compact code with fewer lines
   - Clear relationship between input pattern and output
   - Lower latency (output appears immediately when pattern is detected)
   - No need for state encoding or transition logic

4. Implementation Note:
   - The shift register captures data on each clock edge
   - Output is combinatorial based on the current register contents
   - Reset clears the shift register
