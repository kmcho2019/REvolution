Simplified Approach: Direct Edge Detection

1. Core Concept:
   - Instead of storing 3 cycles, detect the falling edge (1->0 transition) that follows a rising edge (0->1 transition)
   - Only need to remember if we saw a rising edge in the previous cycle

2. Advantages:
   - Reduces storage from 3 bits to just 1 bit (saw_rise flag)
   - Eliminates shift register entirely
   - Still maintains single-cycle detection latency
   - Simpler comparison logic (just edge detection)

3. Implementation Details:
   - Single register to track if we saw a rising edge
   - Combinational logic detects falling edge when preceded by rise
   - Output pulses for exactly one cycle on falling edge detection

4. Edge Cases Handling:
   - Reset clears all state
   - No false positives during initial cycles
   - Handles continuous input streams correctly

5. Performance:
   - Minimal logic (1 register + simple combinational)
   - Lower power than shift register approach
   - Same timing characteristics as original
