Instead of using a traditional state machine, I'll implement a shift register approach that tracks the last 3 samples of data_in. This provides a more direct way to detect the 010 pattern. The key advantages are:

1. Simplicity - no complex state transitions to manage
2. Direct pattern matching - we can simply check if the last 3 samples match 010
3. Efficient implementation - shift registers are well-optimized in hardware
4. Clear timing - output is generated exactly when the pattern completes

The design will:
- Use a 3-bit shift register to store history
- Compare the register contents to 3'b010
- Generate output when match occurs
- Clear the register on reset
- Shift in new samples on each clock edge
