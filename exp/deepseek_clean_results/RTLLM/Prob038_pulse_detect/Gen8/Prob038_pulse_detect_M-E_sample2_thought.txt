This new solution implements a Moore finite state machine (FSM) with explicit states to precisely track the pulse detection sequence. The FSM has four states:
1. IDLE: Waiting for the first 0
2. GOT_0: Received first 0, waiting for 1
3. GOT_1: Received 1 after 0, waiting for 0
4. PULSE_DETECTED: Completed 0->1->0 sequence

The output is only asserted in the PULSE_DETECTED state, ensuring precise detection of the complete pulse sequence. This approach provides:
- Explicit state tracking of the exact sequence
- No false positives from partial sequences
- Clear state transitions that match the problem requirements
- Easy extensibility if pulse definition changes
