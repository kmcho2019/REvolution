Refactoring strategy for the pulse detector:

1. Simplify state machine to use binary encoding (2 bits) instead of one-hot to reduce flip-flop count
2. Use continuous assignments for output and next state logic where possible
3. Combine state transition and output logic into a single always block for clarity
4. Remove parameterization to keep the design simple and focused
5. Maintain same functionality with 0->1->0 pulse detection
6. Use explicit state names for better readability

Key changes:
- Binary state encoding (00, 01, 10)
- Output logic as continuous assignment
- Simplified state transitions with clear conditions
- Single always block for state updates
- Removed parameterization for simplicity
