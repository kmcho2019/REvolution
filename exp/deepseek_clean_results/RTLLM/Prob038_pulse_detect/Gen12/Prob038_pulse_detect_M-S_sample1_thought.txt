Simplified pulse detector design:

1. Use binary state encoding (2 bits) instead of one-hot to reduce flip-flop count
2. Remove parameterization to simplify the design (always use registered output)
3. Use standard case statement for better synthesis tool compatibility
4. Combine state transition and output logic into a single always block
5. Maintain same functionality: detect 0->1->0 pattern over 3 cycles

Key simplifications:
- Reduced from 3 states (one-hot) to 3 states (binary encoded)
- Single always block for both state and output
- No generate blocks or parameters
- Same detection behavior with less overhead
