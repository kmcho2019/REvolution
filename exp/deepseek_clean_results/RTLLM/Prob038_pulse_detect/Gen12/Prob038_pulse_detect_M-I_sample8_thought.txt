Optimization strategy for the pulse detector:

1. Switch from one-hot to binary encoding to reduce flip-flop count (3->2) while maintaining good timing
2. Simplify state transition logic using standard case statement for better synthesis optimization
3. Remove parameterized output option to reduce area overhead (focus on registered output for timing)
4. Optimize state transitions to minimize combinational logic depth
5. Maintain synchronous reset for FPGA compatibility
6. Keep output registered for better timing closure
7. Add comments for better maintainability

Key improvements:
- Binary state encoding reduces area and power
- Simplified state machine structure
- Removed unnecessary parameterization
- Cleaner code structure
- Same functionality with better PPA
