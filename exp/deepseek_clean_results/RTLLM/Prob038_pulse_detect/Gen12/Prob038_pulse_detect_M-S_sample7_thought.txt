To simplify the pulse detection module while maintaining functionality, I'll use the following approach:

1. Single-bit state tracking:
   - Instead of a 3-bit shift register, track just two previous states (previous and current)
   - This reduces the storage requirement from 3 bits to 2 bits

2. Combinational output logic:
   - Detect the pulse pattern (010) by checking:
     - Previous state was 1 (middle of pulse)
     - Current input is 0 (end of pulse)
     - The state before previous was 0 (start of pulse)

3. Simplified state update:
   - Only need to store the last two states
   - Shift operation becomes simple assignment

Benefits:
- Reduced register usage (2 bits instead of 3)
- Same functionality with simpler logic
- Maintains immediate output response
- Easier to understand and verify
