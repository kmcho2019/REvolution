The existing solution is already quite simple, but we can make it even more minimal by:
1. Removing the explicit shift register declaration and using direct bit assignments
2. Combining the pattern detection and output assignment into a single line
3. Maintaining the same functionality with fewer lines of code
4. Still preserving the clean reset behavior

Key simplifications:
- Use two 1-bit registers instead of a 3-bit vector
- Directly compute the output from current and previous states
- Eliminate the intermediate shift register variable
- Same detection logic (0->1->0) but with simpler implementation
