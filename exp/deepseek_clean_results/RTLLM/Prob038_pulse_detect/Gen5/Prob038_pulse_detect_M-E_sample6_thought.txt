Here's a novel approach using a shift register and pattern matching:

1. Shift Register Approach:
- Use a 3-bit shift register to track the last 3 values of data_in
- This provides a sliding window of the input sequence

2. Pattern Matching:
- Detect the exact sequence 010 (0->1->0) in the shift register
- This directly corresponds to the pulse definition

3. Edge-Aligned Output:
- The output is simply the match signal from the pattern detector
- This ensures data_out is high only on the cycle completing the pulse

4. Advantages:
- No explicit state machine needed
- Simple, direct implementation of the requirement
- Easily extensible to detect other patterns if needed
- Clear timing relationship between input and output
