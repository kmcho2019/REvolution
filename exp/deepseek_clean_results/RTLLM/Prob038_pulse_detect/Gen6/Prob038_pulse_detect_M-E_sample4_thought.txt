Here's a novel approach using a finite state machine (FSM) with explicit state transitions:

1. State Machine Approach:
   - Implement a 4-state FSM (IDLE, FIRST_1, SECOND_0, DETECT)
   - Tracks the exact sequence of 0->1->0 transitions
   - Outputs high only when complete sequence is detected

2. Key Features:
   - Explicit state transitions make the logic very clear
   - Each state represents a specific point in the detection sequence
   - Output is only high in DETECT state and immediately returns to IDLE

3. Advantages:
   - More flexible for future modifications (easier to change pulse criteria)
   - Clear state diagram visualization possible
   - Handles back-to-back pulses correctly
   - Explicitly shows the detection process through states

4. Synchronization:
   - All state transitions are clock-aligned
   - Proper reset handling
   - Clean separation between state transition and output logic
