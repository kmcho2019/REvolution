1. State Machine Approach:
   - Use a 3-bit shift register to track the last three input values
   - Detect the exact pattern 0-1-0 in the shift register
   - Output is high only when this pattern is detected

2. Key Improvements:
   - Always shift in new data on every clock cycle (not just when input changes)
   - Clear detection on reset
   - Output is purely combinational based on current state
   - More reliable pattern matching since we check all three bits

3. Implementation:
