Refactored Approach:

1. Shift Register Implementation:
   - Instead of explicit state machine, use a 3-bit shift register to track last 3 values of data_in
   - This directly captures the 0->1->0 sequence requirement in hardware

2. Combinational Output Logic:
   - Use assign statement to detect the specific pattern (010 in last 3 cycles)
   - This makes the output purely combinational based on current shift register state

3. Benefits:
   - More compact implementation (no explicit state transitions)
   - Clear pattern matching (shift register shows exact sequence)
   - Output is combinational with 1-cycle delay from final 0
   - Easier to verify and understand the pattern being detected
   - Naturally handles continuous operation and overlapping pulses
