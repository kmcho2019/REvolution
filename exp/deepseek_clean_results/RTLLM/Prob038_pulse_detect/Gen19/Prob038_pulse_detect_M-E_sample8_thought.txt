Novel Approach: Edge-Triggered Finite State Machine with Explicit Timing

1. Core Concept:
   - Use a state machine that explicitly tracks the rising and falling edges of the input signal
   - Implement precise timing control to ensure exactly 3-cycle detection
   - Separate edge detection from pulse qualification for cleaner design

2. Advantages:
   - More robust against glitches and metastability
   - Clear separation of edge detection and pulse qualification
   - Easier to modify timing requirements (e.g., change pulse width)
   - Better visibility into detection process for debugging

3. Implementation Details:
   - Edge detector creates one-cycle pulses for rising/falling edges
   - 3-state FSM (IDLE, RISE_DETECTED, PULSE_DETECTED)
   - Output precisely timed to the falling edge of the pulse
   - Explicit handling of all edge cases

4. Verification Points:
   - Correctly detects only 010 sequences
   - Handles minimum width pulses (exactly 3 cycles)
   - Rejects shorter/longer pulses
   - Proper reset behavior
   - Clean output timing
