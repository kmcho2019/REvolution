This refactored solution maintains the same Moore FSM concept but implements it with a more concise structure using:
1. One-hot state encoding for clearer state representation
2. Combined state and output logic in a single always block
3. Direct state transitions without separate next_state logic
4. Simplified output assignment that directly reflects the PULSE state

Key improvements:
- Reduced code complexity by eliminating the separate next_state logic
- More efficient one-hot encoding (though uses more flip-flops)
- Output directly tied to state without intermediate register
- Clearer state transition conditions in a single always block
- Maintains same functionality while being more compact
