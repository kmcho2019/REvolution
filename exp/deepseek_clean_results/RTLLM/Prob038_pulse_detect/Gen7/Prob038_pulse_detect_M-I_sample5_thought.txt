To properly detect a full pulse sequence (0->1->0 over 3 cycles), we need to:

1. Track the last three input values using a 3-bit shift register
2. Implement explicit state detection for the complete pulse pattern
3. Only assert data_out when we see the full sequence
4. Reset all state properly on reset

Key improvements:
- Use a 3-bit shift register to track current and previous two states
- Explicitly check for the 010 pattern (0->1->0 transition)
- Clearer state tracking that matches the problem requirements
- Maintains correct timing (output asserted at end of pulse)
- More robust against false positives from random transitions
