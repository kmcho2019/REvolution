To properly detect the full 0->1->0 pulse sequence, we'll implement a 3-state shift register approach:

1. Use a 3-bit shift register to track the last three samples of data_in
2. The pulse is detected when the sequence is exactly 3'b010 (0->1->0)
3. Output is asserted combinatorially when this pattern is detected
4. Reset clears the shift register
5. This approach:
   - Clearly captures the required 3-cycle sequence
   - Uses simple shift register logic
   - Provides glitch-free output
   - Is easily verifiable
   - Maintains minimal hardware complexity
