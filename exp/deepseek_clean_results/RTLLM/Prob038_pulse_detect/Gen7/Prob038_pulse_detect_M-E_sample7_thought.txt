Novel Shift Register Approach:
1. Instead of using a state machine, we'll track the last 3 input values using a shift register
2. The shift register (3 bits) will store the current and previous two input values
3. Pulse detection becomes a simple pattern match: when the shift register contains "010"
4. Output is generated combinatorially when the pattern is detected
5. This approach is more compact and leverages parallel pattern matching

Key Advantages:
- Simpler implementation with fewer states
- Direct pattern matching makes the detection criteria very clear
- Easily scalable to detect longer or different patterns
- Lower latency as detection happens in a single cycle
- Clear relationship between input sequence and output

Implementation Details:
- 3-bit shift register (history[2:0]) stores current and past two inputs
- Reset clears the history register
- Each clock shifts in the new data_in value
- Output is high when history == 3'b010
- All operations are synchronous to the clock
