To detect a pulse (0->1->0 sequence) in the input signal, we'll use a state machine with 4 states:
1. IDLE: Waiting for first 0
2. GOT_0: Received first 0, waiting for 1
3. GOT_1: Received 1 after 0, waiting for final 0
4. PULSE_DETECTED: Completed the sequence (output 1 for one cycle)

The state transitions occur on each clock edge. When we reach PULSE_DETECTED state, we output 1 for one cycle and return to IDLE state. The output is 0 in all other states.
