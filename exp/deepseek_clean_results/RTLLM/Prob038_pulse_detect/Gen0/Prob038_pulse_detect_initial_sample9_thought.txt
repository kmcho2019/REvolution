To detect a pulse (0->1->0 sequence) in the input signal, we'll use a state machine with 4 states:
1. IDLE: Waiting for first 0
2. GOT_0: Received first 0, waiting for 1
3. GOT_1: Received 1 after 0, waiting for 0
4. PULSE_DETECTED: Completed pulse sequence

The output data_out will be high for one cycle when we reach the PULSE_DETECTED state, then we return to IDLE state.
