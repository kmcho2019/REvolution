To detect a pulse (0->1->0 sequence) in the input signal, we'll use a simple state machine with 3 states:
1. IDLE: Waiting for first 0
2. GOT_0: Received first 0, waiting for 1
3. GOT_1: Received 1 after 0, waiting for final 0

The state transitions occur on each clock edge. When we complete the sequence (reach GOT_1 and see a 0), we output a 1 for one cycle and return to IDLE state.
