To detect a pulse (0->1->0 sequence) in the input signal, we'll use a state machine with 3 states:
1. IDLE: Waiting for first 0
2. GOT_0: Received first 0, waiting for 1
3. GOT_1: Received 1 after 0, waiting for final 0

The output (data_out) will be 1 only when we transition from GOT_1 back to IDLE after seeing a 0. We'll use sequential logic with clock and reset handling.
