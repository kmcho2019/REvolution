Novel Approach: Shift Register with Pattern Matching

1. Core Concept:
   - Use a 3-bit shift register to track the last three samples of data_in
   - Directly compare the shift register contents to the target pattern (010)
   - Output is asserted when the pattern matches exactly
   - No explicit state machine needed - pattern matching handles all cases

2. Advantages:
   - Simpler implementation with fewer states
   - Easily extensible to detect longer/more complex patterns
   - Clear relationship between hardware and detection logic
   - All history stored explicitly in the shift register

3. Implementation Details:
   - 3-bit shift register (stores current and previous two samples)
   - Combinational comparison for pattern matching
   - Output registered for clean timing
   - Reset clears the shift register

4. Verification Points:
   - Correctly detects 010 pattern
   - Handles overlapping patterns (e.g., 01010 produces two detections)
   - Proper reset behavior
   - Output is synchronous and glitch-free
