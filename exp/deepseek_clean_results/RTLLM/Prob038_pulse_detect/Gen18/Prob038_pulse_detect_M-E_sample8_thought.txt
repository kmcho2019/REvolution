Novel Approach: State Machine with Edge Detection

1. Core Concept:
   - Use a Moore state machine to explicitly track pulse progression
   - Detect rising and falling edges of data_in to trigger state transitions
   - Output is only asserted when the complete pulse sequence is verified

2. Advantages:
   - Explicit state tracking makes the design intention very clear
   - Edge detection provides precise timing of transitions
   - Naturally handles minimum pulse width requirements
   - Easy to modify for different pulse patterns

3. Implementation Details:
   - Three states: IDLE (waiting for start), RISE (saw rising edge), FALL (saw falling edge)
   - Edge detection using data_in and its delayed version
   - Output only asserted when falling edge occurs after rising edge
   - Clear reset behavior

4. Edge Cases Handling:
   - Properly handles glitches (quick 1-0 transitions)
   - Won't trigger on single-cycle pulses
   - Reset puts system in known state
   - Handles continuous input streams

5. Performance:
   - Fixed 3-cycle detection latency
   - Minimal combinational logic
   - Predictable state transitions
