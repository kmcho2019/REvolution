Instead of using a traditional state machine, we'll implement a shift register approach that tracks the last 3 values of data_in. This provides a more direct way to detect the 0->1->0 sequence without explicit state transitions. 

Key points:
1. Use a 3-bit shift register to store the last 3 samples of data_in
2. When the register contains "010", we have a complete pulse
3. The output is asserted only when this exact pattern is detected
4. The shift register automatically handles continuous input monitoring

This approach is simpler and more maintainable as it directly matches the required pattern without complex state transitions.
