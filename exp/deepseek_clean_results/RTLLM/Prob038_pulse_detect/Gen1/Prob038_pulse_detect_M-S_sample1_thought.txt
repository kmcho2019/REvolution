To simplify the pulse detection, we can reduce the state machine to just track the previous two values of data_in. A pulse is detected when we see the sequence 0->1->0 in the last three cycles. We'll use two flip-flops to store the previous two values, and combinatorial logic to detect the pattern.

Key simplifications:
1. Eliminate explicit state machine states
2. Use shift register to track history
3. Combinational detection of pulse pattern
4. Output is high for one cycle when pattern is detected
