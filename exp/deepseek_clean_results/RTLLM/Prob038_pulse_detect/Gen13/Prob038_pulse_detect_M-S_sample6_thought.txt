Simplified pulse detector design:

1. Reduce state machine to just 2 states (binary encoded) since we only need to track the previous two input values
2. Use shift register approach to store last two inputs (more hardware efficient than FSM)
3. Combine detection logic into simple combinatorial expression
4. Maintain same functionality: detect 0->1->0 pattern over 3 cycles
5. Output is registered to meet timing requirements

Key simplifications:
- Eliminated explicit state machine in favor of shift register
- Reduced logic to simple pattern matching
- Fewer registers (2-bit shift vs 2-bit state)
- Same detection behavior with simpler implementation
