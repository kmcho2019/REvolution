Novel approach using shift register detection:

1. Instead of traditional state machine, use a 3-bit shift register to track last 3 samples
2. Detect the specific pattern "010" in the shift register to identify pulses
3. Output is registered version of the pattern match
4. Benefits:
   - Simpler implementation with no explicit state transitions
   - Easily extensible to detect different pulse widths
   - Clear relationship between input pattern and detection
   - Lower power as only shift operations needed
5. Reset initializes shift register to all 0s
6. Output is registered for clean timing

Key differences:
- Pattern matching instead of state transitions
- Shift register provides history tracking
- More intuitive implementation
- Same functionality with different architecture
