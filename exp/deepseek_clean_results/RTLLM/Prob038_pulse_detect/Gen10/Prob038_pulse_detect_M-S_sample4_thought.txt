Simplified Approach:

1. Use a 2-bit state machine instead of a 3-bit shift register to track progress:
   - State 00: Waiting for first 0
   - State 01: Received first 0, waiting for 1
   - State 10: Received 0->1, waiting for final 0
   - State 11: Invalid state (reset to 00)

2. Output generation:
   - Only assert data_out when we're in state 10 and receive a 0
   - This precisely matches the 0->1->0 sequence requirement

3. Benefits:
   - Fewer state bits (2 vs 3)
   - Clear state transitions
   - Exactly matches the pulse detection requirement
   - Output is only high for one cycle per complete pulse
   - Handles all edge cases properly
