Based on the feedback, I'll optimize the design while maintaining the core functionality. Here's the improved approach:

1. Power Optimization:
   - Add a data_in change detector to only update the history register when needed
   - This reduces unnecessary toggling of the history register bits

2. Output Optimization:
   - Only update data_out when there's a potential state change
   - This reduces switching activity on the output signal

3. Maintained Features:
   - Keep the simple 3-bit shift register for pattern detection
   - Preserve the immediate pattern matching capability
   - Maintain reset functionality

4. Implementation Changes:
   - Add a register to store previous data_in value
   - Only shift new data when input changes
   - Only update output when history register changes
   - Keep the same detection logic (010 pattern)

This optimized version reduces power consumption while maintaining the same detection accuracy and timing characteristics.
