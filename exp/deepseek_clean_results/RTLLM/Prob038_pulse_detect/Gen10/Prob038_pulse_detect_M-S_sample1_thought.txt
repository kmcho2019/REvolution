To simplify the solution while maintaining functionality, we can:
1. Remove the shift register approach since it stores more history than needed
2. Track just the previous two states (previous and current data_in values)
3. Use combinational logic to detect when we had a 0->1 transition followed by a 1->0 transition
4. This reduces the storage from 3 bits to 2 bits while keeping the same detection capability
5. The output becomes purely combinational based on the state transitions

Advantages:
- Uses fewer flip-flops (2 instead of 3)
- Simpler comparison logic (just checking two bits instead of three)
- Maintains identical pulse detection functionality
- Same reset behavior and timing characteristics
