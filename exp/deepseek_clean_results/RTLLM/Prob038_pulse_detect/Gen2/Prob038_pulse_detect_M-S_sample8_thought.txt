The original solution uses a 3-state FSM which is correct but can be simplified to a 2-state FSM since we only need to track if we've seen the rising edge (0->1 transition). Here's the simplified approach:

1. Use just 2 states: IDLE (waiting for 0->1) and GOT_RISE (saw 0->1, waiting for 1->0)
2. Transition to GOT_RISE when we see 0->1
3. Return to IDLE and pulse output when we see 1->0 in GOT_RISE state
4. Output is 1 only when we complete the full pulse (1->0 in GOT_RISE state)
5. Reset initializes to IDLE state

This reduces the state register to 1 bit while maintaining identical functionality.
