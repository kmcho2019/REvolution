I'll implement a Moore finite state machine (FSM) with explicit states to track the pulse progression. This provides more control and visibility into the detection process compared to the shift register approach.

Key points:
1. Use 4 states: IDLE (waiting for first 0), SAW_0 (saw first 0), SAW_1 (saw rising edge), and PULSE (complete pulse detected)
2. State transitions occur based on data_in values
3. Output is only high in PULSE state
4. Clear state machine on reset

This approach is more explicit about the detection process and allows for easier modification if pulse criteria change. It also provides better debuggability as the current state is always known.
