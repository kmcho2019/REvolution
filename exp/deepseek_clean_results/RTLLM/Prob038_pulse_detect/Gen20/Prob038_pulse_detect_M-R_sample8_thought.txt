I'll refactor the solution using a shift register approach combined with combinational logic. This eliminates the explicit state machine while maintaining the same functionality:

1. Use a 2-bit shift register to track the last two values of data_in
2. Combinational logic detects the 010 pattern when:
   - Previous two cycles were '01' (shift_reg == 2'b01)
   - Current input is '0'
3. Output is asserted for one cycle when pattern is detected
4. Reset clears the shift register

Advantages:
- More compact implementation
- Eliminates state machine complexity
- Uses simple sequential elements (shift register)
- Output is purely combinational function of current and past inputs
- Easier to verify timing
- Same cycle detection as original FSM approach
