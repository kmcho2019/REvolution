Refactored Asynchronous FIFO Design:

Key Refactoring Changes:
1. Replace always blocks with continuous assignments where possible
2. Separate Gray code conversion into dedicated combinational logic
3. Simplify pointer synchronization using direct assignments
4. Move full/empty detection to combinational logic
5. Maintain same functionality but with cleaner structure

Core Improvements:
- Reduced sequential logic by using more combinational assignments
- Clear separation of pointer management and synchronization
- More explicit Gray code conversion logic
- Simplified full/empty detection without nested conditionals
- Same clock domain crossing strategy but with cleaner implementation
