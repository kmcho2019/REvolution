Simplified Asynchronous FIFO Implementation:

Key Simplifications:
1. Removed redundant continuous assignments by directly using registers
2. Combined pointer updates into single always blocks per clock domain
3. Eliminated intermediate wire declarations for next-state logic
4. Simplified full/empty detection logic by using direct Gray code comparisons
5. Reduced synchronization stages to minimum required (2 FFs)
6. Removed initial block for depth validation (should be done at instantiation)
7. Simplified parameter declarations

The simplified version maintains all core functionality while:
- Reducing lines of code
- Making the design more straightforward
- Keeping the same clock domain crossing safety
- Maintaining identical parameterization
- Preserving the same RAM interface
