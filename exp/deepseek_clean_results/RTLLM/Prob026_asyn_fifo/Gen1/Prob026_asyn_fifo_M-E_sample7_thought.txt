This design introduces a novel handshake-based synchronization mechanism between clock domains instead of Gray code pointers. Key innovations:
1. Uses a circular buffer with separate read/write pointers
2. Implements a 4-phase handshake protocol for pointer synchronization
3. Employs a token-passing scheme for full/empty detection
4. Uses a configurable depth threshold for almost-full/almost-empty signals
5. Includes error detection for metastability events

The handshake protocol ensures safe pointer transfer between domains while avoiding the complexity of Gray code conversion. The token-passing scheme provides reliable full/empty detection without the need for pointer comparison across clock domains.
