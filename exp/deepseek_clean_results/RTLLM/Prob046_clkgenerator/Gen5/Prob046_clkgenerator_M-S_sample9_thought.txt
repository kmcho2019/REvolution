Simplified clock generator design that:
1. Uses a single always block with delay-based toggling
2. Initializes clock to 0 for clean start
3. Maintains perfect 50% duty cycle
4. Uses minimal code while being fully functional for simulation
5. Eliminates potential infinite loop concerns by using proper always block structure
6. Still maintains the core functionality of generating a periodic clock signal

Note: This remains a simulation-only implementation as it uses timing delays (#). For synthesis, a PLL or counter-based approach would be needed.
