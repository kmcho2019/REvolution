Novel counter-based clock generator with these key features:

1. **Precision Timing**: Uses a counter to precisely measure half-period intervals, ensuring accurate 50% duty cycle regardless of PERIOD value.

2. **Dynamic Period Adjustment**: Allows real-time period changes by monitoring a 'period_update' signal and 'new_period' input.

3. **Glitch-Free Transition**: Implements a state machine to safely switch periods without glitches by waiting for the next clock edge.

4. **Power Efficiency**: Only toggles clock when needed and stops counter when disabled.

5. **Synthesis-Friendly**: Uses standard synchronous design patterns suitable for ASIC/FPGA implementation.

Architecture:
- 16-bit counter for wide period range
- State machine for period updates
- Synchronous reset and enable
- Registered outputs for clean timing
