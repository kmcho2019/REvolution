Novel clock generator design using a counter-based approach with these features:
1. Uses a free-running counter to track time instead of direct delays
2. Implements precise edge detection for clean transitions
3. Supports dynamic period changes during operation
4. Includes jitter-free startup and shutdown
5. Provides glitch protection during enable/disable transitions
6. Uses non-blocking assignments for better simulation behavior

Key innovations:
- Counter tracks elapsed time in clock cycles
- Edge detection ensures perfect 50% duty cycle
- Dynamic period adjustment without glitches
- Clean state machine for enable/disable transitions
- More robust simulation behavior
