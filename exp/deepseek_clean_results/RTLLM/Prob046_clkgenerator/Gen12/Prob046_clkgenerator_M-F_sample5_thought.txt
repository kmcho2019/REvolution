Simplified Clock Generator Design:
1. Revert to a simpler counter-based approach since the original requirement only needs integer period division
2. Maintain the core functionality of generating a square wave with specified PERIOD
3. Key improvements:
   - Remove unnecessary phase accumulator complexity
   - Use a simple counter that toggles clock at half-period intervals
   - Keep parameterized PERIOD for flexibility
   - Include reset functionality
4. Benefits:
   - Lower power consumption (only toggles when needed)
   - Smaller area (simple counter instead of phase accumulator)
   - Easier timing closure (simpler logic)
5. Implementation:
   - Counter counts up to PERIOD/2
   - Toggle clock and reset counter when count reaches threshold
   - Initial state set to 0
