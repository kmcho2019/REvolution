This design implements a finite state machine (FSM) approach to clock generation, which offers several advantages:
1. Explicit state tracking for better debug visibility
2. Built-in edge detection for precise timing control
3. Scalable architecture that can easily incorporate additional features like clock gating or frequency modulation
4. Avoids potential simulation artifacts by using proper non-blocking assignments
5. Uses a parameterized state counter for precise period control

The FSM has two states (HIGH and LOW) and transitions between them after counting half-period intervals. This provides a clean, verifiable implementation that clearly shows the clock generation behavior.
