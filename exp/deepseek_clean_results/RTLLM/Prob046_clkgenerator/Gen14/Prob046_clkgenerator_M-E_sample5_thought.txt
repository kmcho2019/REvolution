Novel Design Approach:
1. Use a real-time counter instead of direct delay-based toggling
2. Implement a free-running counter that wraps at PERIOD
3. Generate clock transitions at counter wrap points
4. Allows for potential future expansion (duty cycle control, clock gating)
5. More representative of actual digital clock generation circuits
6. Provides better simulation control and observability
7. Enables precise edge alignment with counter value

Key Advantages:
- More realistic digital implementation
- Visible internal counter state (for debugging)
- Easier to modify for non-50% duty cycles
- Better alignment with synchronous design practices
- More flexible for future enhancements
