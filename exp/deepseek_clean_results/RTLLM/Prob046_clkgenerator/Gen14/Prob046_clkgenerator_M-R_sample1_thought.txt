Refactored clock generator design using a different approach:
1. Instead of using an always block with delays, we'll use a continuous assignment with a periodic toggling mechanism
2. Utilize a real-time counter that increments with simulation time
3. Toggle the clock whenever the counter reaches half-period intervals
4. Maintain the same parameterization and initialization requirements
5. This approach provides deterministic behavior while avoiding potential simulation issues with delay-based always blocks

Key improvements:
- Uses continuous assignment for clock generation
- Implements time-based toggling through a counter
- Maintains 50% duty cycle
- More robust for simulation environments
- Clear and maintainable structure
