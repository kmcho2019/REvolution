Innovative counter-based clock generator design:
1. Uses a free-running counter instead of direct delay-based toggling
2. Implements edge detection on counter MSB for precise timing
3. Provides better synthesis characteristics for FPGA/ASIC implementation
4. More robust against simulation timing issues
5. Allows for easy frequency modification during operation
6. Includes automatic period adjustment for odd-numbered periods

Key features:
- Counter increments continuously at simulation time precision
- Clock toggles when counter reaches half-period value
- Counter resets after full period to prevent overflow
- Handles both even and odd periods correctly
- More realistic for hardware implementation
- Better timing control than delay-based approaches
