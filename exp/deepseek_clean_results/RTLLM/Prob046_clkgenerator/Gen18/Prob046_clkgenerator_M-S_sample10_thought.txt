Simplified clock generator using basic Verilog constructs:
1. Eliminates state machine complexity for this simple use case
2. Uses a single always block with delay-based toggling
3. Maintains parameterized period control
4. Initializes clock to 0 for predictable startup
5. Pure behavioral code for simulation (not synthesizable)
6. Half-period delay creates clean 50% duty cycle
7. Minimal implementation focused on simulation needs
