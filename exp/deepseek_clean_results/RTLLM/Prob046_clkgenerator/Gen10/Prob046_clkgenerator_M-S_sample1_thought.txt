Simplified clock generator design that:
1. Uses basic delay-based toggling for pure simulation purposes
2. Eliminates unnecessary counter logic
3. Maintains exact period timing through simple delay statements
4. Provides clean initialization
5. Focuses on simulation-only use case (acknowledging this isn't synthesis-friendly)

Key simplifications:
- Removed counter and modulo operations
- Direct delay-based toggling
- Single always block for clock generation
- Clear parameter usage for period control
