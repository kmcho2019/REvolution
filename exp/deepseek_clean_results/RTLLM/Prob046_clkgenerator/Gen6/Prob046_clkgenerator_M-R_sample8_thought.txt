1. Uses continuous assignment (assign) with delay instead of always block
2. Still maintains 50% duty cycle by toggling every PERIOD/2
3. Uses an initial block to set starting value
4. Eliminates potential simulation race conditions by separating initialization
5. Provides same functionality with different implementation style
6. Still simulation-only (uses # delays) but demonstrates alternative approach
