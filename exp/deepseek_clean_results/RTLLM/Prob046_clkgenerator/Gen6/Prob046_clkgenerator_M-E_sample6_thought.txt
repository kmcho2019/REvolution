Novel approach using a counter-based clock generator with precise edge control:
1. Use a counter that increments on every simulation timestep
2. Compare counter value against PERIOD/2 to determine toggle points
3. Reset counter after each full period for perfect periodicity
4. This method provides more precise control over clock edges compared to simple delay-based approaches
5. Allows for easy modification of duty cycle if needed
6. More robust for simulation as it's not dependent on absolute delay values
