Simplified and robust clock generator design:
1. Remove the unnecessary base_clock and counter complexity
2. Use a single always block with delay-based toggling
3. Maintain parameterized period control
4. Generate perfect 50% duty cycle by toggling every PERIOD/2
5. Initialize clock to 0 for clean startup
6. Advantages:
   - Simple and reliable implementation
   - Exactly matches PERIOD parameter
   - No potential for race conditions
   - Clear and maintainable code
   - Works consistently in simulation
7. Note: While delay-based approaches aren't synthesizable, this is appropriate for testbench clock generation
