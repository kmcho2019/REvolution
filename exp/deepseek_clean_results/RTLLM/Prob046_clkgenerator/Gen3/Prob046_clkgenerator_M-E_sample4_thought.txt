This design implements a clock generator using a simple counter-based approach with these key features:
1. Uses a free-running counter that automatically wraps around at the specified PERIOD
2. Generates the clock by comparing the counter value with half the PERIOD
3. Includes automatic period adjustment for odd periods (handles both even and odd PERIOD values correctly)
4. Uses only synthesizable constructs with no simulation-time delays
5. Implements a parameterized design that works for any positive PERIOD value
6. Includes a reset mechanism for clean initialization
7. Optimized for minimal logic and maximum frequency in synthesis

The design works by toggling the clock whenever the counter crosses the midpoint of the period, creating a precise 50% duty cycle regardless of whether the period is even or odd.
