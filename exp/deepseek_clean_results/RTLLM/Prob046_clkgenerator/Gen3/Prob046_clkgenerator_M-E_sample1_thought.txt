I'll implement a clock generator using a finite state machine approach that:
1. Uses two states (HIGH and LOW) to represent clock phases
2. Employs a counter for precise timing control
3. Includes parameterized period and duty cycle
4. Features clean synchronous reset
5. Uses non-blocking assignments for reliable state transitions

Key innovations:
- State machine ensures deterministic behavior
- Counter-based timing provides precise control
- Configurable duty cycle through parameters
- Synchronous design avoids glitches
- Scalable for different frequency requirements
