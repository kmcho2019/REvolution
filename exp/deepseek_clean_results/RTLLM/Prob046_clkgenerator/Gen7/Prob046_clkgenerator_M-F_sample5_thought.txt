Synthesis-friendly clock generator implementation:
1. Use a base clock input for synchronous operation (required for synthesis)
2. Implement a counter that increments on every positive edge of the base clock
3. Toggle the output clock when counter reaches half period
4. Reset counter after full period using synchronous logic
5. All operations are edge-triggered and synchronous
6. No simulation delays used - fully synthesizable
7. Added reset signal for proper initialization
8. Output clock is registered to avoid glitches
