Refactored clock generator using continuous assignment:
1. Uses an internal counter to track time instead of delay-based toggling
2. Generates clock using assign statement with conditional expression
3. Counter increments every time unit and resets at full period
4. Clock toggles when counter crosses half-period threshold
5. Maintains same functionality but with different implementation approach

Key advantages:
- More explicit timing control
- Avoids potential simulation issues with delay-based always blocks
- Easier to modify for additional features (like enable/disable)
- Clear relationship between counter and clock output
