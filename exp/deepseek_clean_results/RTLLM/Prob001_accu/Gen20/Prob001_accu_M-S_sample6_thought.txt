Simplification Strategy:
1. Reduce logic complexity by:
   - Removing separate accumulator and data_out registers (use single register)
   - Simplifying counter logic with direct reset after 4th input
   - Eliminating intermediate variables where possible

2. Maintain functionality with:
   - Same accumulation behavior (4 inputs summed)
   - Identical output timing (valid_out pulses after 4th input)
   - Correct reset behavior

3. Optimize for:
   - Clear, straightforward implementation
   - Minimal control logic
   - Single always block for all sequential logic
