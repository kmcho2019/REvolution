To simplify the design while maintaining functionality:
1. Replace the state machine with a simple counter to track the number of valid inputs received
2. Use a single accumulator register to store the running sum
3. Reset the accumulator and counter after every 4th valid input
4. Generate valid_out only when the counter reaches 3 (after 4 inputs)
5. Keep the same interface and functionality but with fewer states and simpler logic

Key simplifications:
- Eliminates the state machine and enum types
- Uses a 2-bit counter instead of multiple states
- Combines accumulation and output in a single always block
- Maintains same timing behavior with simpler control logic
