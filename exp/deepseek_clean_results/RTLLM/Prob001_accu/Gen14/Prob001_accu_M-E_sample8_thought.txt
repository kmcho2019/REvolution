Novel Architecture: Shift Register Accumulator with Early Output Calculation

Key Innovations:
1. Shift Register Approach:
   - Store all 4 input values in a shift register instead of accumulating
   - Enables parallel addition of all 4 values when complete
   - Allows for potential future extensions (like weighted averaging)

2. Early Sum Calculation:
   - Pre-compute partial sums in parallel with data collection
   - Final sum is ready immediately when 4th data arrives
   - Reduces critical path compared to sequential accumulation

3. Smart Valid Handling:
   - Separate input and output valid signals for clear pipeline stages
   - Output valid precisely one cycle after 4th input
   - Prevents glitches in output valid signal

Advantages:
- More flexible architecture (can access individual input values)
- Parallel computation reduces timing pressure
- Clear separation between data collection and processing phases
- Easier to verify and debug (all intermediate values visible)
