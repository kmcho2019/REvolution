To simplify the accumulator module while maintaining functionality:
1. Use a 2-bit counter to track the number of valid inputs received
2. Accumulate the input data only when valid_in is high
3. When 4 inputs are received (counter reaches 3), output the sum and reset
4. Generate valid_out only for one cycle when output is ready
5. Reset all registers on active-low reset
6. Keep the interface identical to original specification
