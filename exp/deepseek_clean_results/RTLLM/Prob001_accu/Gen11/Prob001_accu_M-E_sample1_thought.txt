Novel approach using shift register and parallel addition:
1. Instead of sequential accumulation, store all 4 inputs in a shift register
2. Use a 4-input parallel adder when all inputs are available
3. This reduces the critical path by:
   - Eliminating the chained addition dependency
   - Performing all additions in a single cycle
4. The shift register naturally handles data collection and reset
5. Valid_out is generated combinatorially when count reaches 3 (4 inputs)
