Fusion Strategy:
1. Performance Optimization:
   - Use binary counter (simpler than Gray code) with direct terminal count comparison (count == 3)
   - Keep accumulator and output register separate to allow pipelining
   - Move terminal count detection to separate always block for better timing

2. Power Optimization:
   - Gate the accumulator update with valid_in to reduce switching
   - Only update valid_out when needed (during output cycle)
   - Use registered outputs to minimize glitches

3. Area Optimization:
   - Maintain minimal 2-bit counter (sufficient for 4 counts)
   - Keep 10-bit accumulator for full range coverage
   - Share logic between accumulation and output stages

Key Improvements:
- Simplified counter logic improves timing (removes Gray code overhead)
- Separate accumulator/output registers enable better pipelining
- Valid_in gating reduces power consumption
- Clean state machine structure enhances readability and maintainability
