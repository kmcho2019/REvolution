Fusion Strategy:
1. Performance Optimization:
   - Use binary counter instead of Gray code for simpler terminal count detection (count == 2'b11)
   - Keep accumulator and output register separate to break critical path
   - Pre-compute next accumulator value to reduce adder delay

2. Power Optimization:
   - Gate accumulator updates with valid_in to reduce unnecessary switching
   - Only update valid_out when needed (during output cycle)
   - Use synchronous reset for better power characteristics

3. Area Optimization:
   - Maintain minimal 2-bit counter and 10-bit accumulator
   - Share adder between accumulation and final sum calculation
   - Simplify control logic by removing redundant registers

Key Improvements:
- Better timing through direct binary counting and pre-computation
- Lower power through conditional updates and synchronous reset
- Compact area through shared adder and simplified control
