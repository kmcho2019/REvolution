To simplify the accumulator module while maintaining functionality:
1. Remove the separate accumulator register and directly accumulate into data_out
2. Use the counter to track valid inputs and control the accumulation
3. Reset data_out to 0 when starting a new accumulation cycle
4. Generate valid_out only when 4 inputs are received
5. Keep the same 10-bit output width for overflow protection
6. Maintain asynchronous reset functionality
