To implement the accumulator module, we need to:
1. Use a counter to track how many valid inputs have been received
2. Maintain an accumulator register to sum the input values
3. Reset both counter and accumulator when reset is active
4. When 4 valid inputs are received:
   - Output the accumulated sum
   - Assert valid_out for one cycle
   - Reset the counter and accumulator for the next group
5. Use registered outputs to ensure synchronous behavior
