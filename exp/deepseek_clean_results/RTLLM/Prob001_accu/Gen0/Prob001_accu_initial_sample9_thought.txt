To implement the accumulator module, we need to:
1. Use a counter to track the number of valid inputs received.
2. Accumulate the input data into a sum register when valid_in is high.
3. When the counter reaches 4, output the accumulated sum and assert valid_out for one cycle.
4. Reset the counter and sum register when either reset occurs or after outputting the result.

The key points are:
- Synchronous design with clock and active-low reset
- 3-bit counter to count from 0 to 3 (4 inputs)
- 10-bit accumulator (8-bit inputs could sum up to 1020 max)
- Control logic for valid_out generation
