To implement the accumulator module, we need to:
1. Use a counter to track how many valid inputs we've received (0-3)
2. Accumulate the input values in a register when valid_in is high
3. When the counter reaches 3 (meaning we've received 4 inputs), output the sum and set valid_out high for one cycle
4. Reset the counter and accumulator after outputting the result
5. Handle the asynchronous reset properly
6. Use a 10-bit accumulator to handle potential overflow (4 * 255 = 1020 which fits in 10 bits)
