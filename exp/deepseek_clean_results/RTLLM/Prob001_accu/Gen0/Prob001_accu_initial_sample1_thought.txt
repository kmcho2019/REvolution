To implement the accumulator module, we need to:
1. Use a counter to track how many valid inputs we've received (0-3)
2. Accumulate the input data into a sum register when valid_in is high
3. When the counter reaches 3 (meaning we've received 4 inputs), output the accumulated sum and set valid_out high for one cycle
4. Reset the counter and accumulator after outputting
5. Handle synchronous reset properly
6. Use a 10-bit accumulator to handle potential overflow (8-bit * 4 = max 10 bits needed)
