To implement the accumulator module, we need to:
1. Use a counter to track how many valid inputs we've received (0-3)
2. Store and accumulate the input values in a register
3. When the counter reaches 3 (meaning we've received 4 inputs), output the sum and assert valid_out for one cycle
4. Reset the counter and accumulator after outputting
5. Handle the reset condition properly
6. Use 10-bit output to accommodate potential maximum sum (4*255 = 1020)
