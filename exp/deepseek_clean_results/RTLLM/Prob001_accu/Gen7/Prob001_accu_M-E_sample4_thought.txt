Novel approach using pipelined accumulation with shift register:
1. Instead of a simple counter and accumulator, use a shift register to store the last 4 inputs
2. Implement a pipelined adder tree to calculate the sum progressively
3. Use a state machine to track accumulation phases
4. Key advantages:
   - Better timing: Pipelined additions reduce critical path
   - Lower power: Only active adders consume power
   - Clear separation of data storage and computation
5. The shift register ensures we always have access to all 4 values when needed
6. The adder tree computes partial sums in each cycle, reducing final addition delay
