Instead of using a counter and sequential accumulation, we can:
1. Use a shift register to store the last 4 input values
2. Perform parallel addition of all 4 values when the shift register is full
3. This eliminates the accumulation critical path by:
   - Removing the chained addition dependency
   - Allowing all additions to happen in parallel
4. Use a simple state machine to track when we have 4 valid inputs
5. The shift register approach also enables potential future extensions like:
   - Variable accumulation window sizes
   - Access to individual input samples
6. Maintain the same interface and functionality while improving timing
