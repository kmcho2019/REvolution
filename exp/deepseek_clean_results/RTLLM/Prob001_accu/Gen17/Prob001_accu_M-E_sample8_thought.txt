Instead of using a state machine, this design employs:
1. A shift register to store the last 4 input values
2. Parallel addition of all 4 values when the 4th input arrives
3. A counter to track valid inputs
4. Immediate output calculation when 4 inputs are received

Key advantages:
- Eliminates sequential accumulation, reducing critical path
- Parallel addition improves timing (single-cycle operation)
- Shift register provides visibility of all inputs
- Simpler control logic compared to state machine
- Easily scalable to different accumulation lengths
