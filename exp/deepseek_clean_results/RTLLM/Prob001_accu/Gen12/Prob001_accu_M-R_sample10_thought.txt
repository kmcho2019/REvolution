Refactored design approach:
1. Use combinational logic for the counter and accumulator updates to simplify the always block
2. Implement the counter as a simple incrementer with reset
3. Move the accumulation logic to a separate combinational block
4. Generate valid_out directly from the counter state
5. Use continuous assignments where possible for clarity

Key improvements:
- Separates combinational and sequential logic clearly
- Uses simpler terminal count detection (count[1] & count[0])
- Moves some logic to continuous assignments
- Maintains same functionality but with cleaner structure
- Potentially better for synthesis and timing
