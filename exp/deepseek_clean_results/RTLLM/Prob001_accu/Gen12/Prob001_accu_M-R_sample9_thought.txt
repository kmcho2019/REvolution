Refactoring Strategy:
1. Separate combinational and sequential logic for better timing and clarity
2. Use continuous assignments (assign) for combinational logic where possible
3. Implement the counter and accumulator as separate always blocks
4. Generate valid_out purely combinationally based on counter state
5. Calculate the final sum in a dedicated combinational block

Key Improvements:
- Clear separation of combinational and sequential logic
- Reduced complexity in each always block
- More transparent data flow
- Maintains same functionality while potentially improving timing
