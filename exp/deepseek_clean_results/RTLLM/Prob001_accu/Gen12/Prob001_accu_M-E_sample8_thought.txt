New architectural approach:
1. Use a shift register to store the last 4 input values, enabling parallel processing
2. Implement a parallel adder tree for faster accumulation (reduces critical path)
3. Add a counter to track valid inputs and trigger output
4. Use registered outputs for better timing closure
5. Implement early reset propagation for all registers

Key advantages:
- Parallel processing eliminates sequential adder chain (better timing)
- Shift register provides visibility into all inputs (useful for debugging)
- Adder tree structure is more scalable for larger accumulation counts
- Clear separation of data path and control logic
