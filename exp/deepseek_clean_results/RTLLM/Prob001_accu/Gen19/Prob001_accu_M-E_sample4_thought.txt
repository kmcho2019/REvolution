Instead of using a state machine, this design employs:
1. A 4-stage shift register to store incoming data
2. A parallel adder tree to sum all 4 values simultaneously
3. A counter to track valid inputs
4. Registered outputs for better timing

Key advantages:
- Parallel addition reduces critical path compared to sequential accumulation
- Shift register provides data history visibility
- Counter-based approach simplifies control logic
- Output register ensures clean timing on data_out
- More scalable for larger accumulation windows
