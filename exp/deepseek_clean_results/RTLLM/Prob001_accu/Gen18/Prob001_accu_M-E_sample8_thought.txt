Instead of using a state machine, we'll implement a shift register that stores the last 4 input values. This allows:
1. Parallel accumulation of all 4 values in a single cycle when the 4th value arrives
2. Elimination of the sequential adder chain, improving timing
3. Clear visibility of all stored values for debugging
4. Potential for future extensions (like weighted averaging)

Key features:
- 4-stage shift register stores incoming values
- Parallel adder computes sum when 4 values are available
- Counter tracks valid inputs to trigger output
- Output register holds the accumulated sum
- All operations are fully synchronous
