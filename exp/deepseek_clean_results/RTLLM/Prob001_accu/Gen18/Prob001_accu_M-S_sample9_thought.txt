Simplified Design Approach:
1. Remove redundant state machine and counter - use a simple 2-bit counter to track accumulation progress
2. Single always block for sequential logic - simpler and more compact
3. Direct accumulation without next_state/next_data registers - reduces area
4. Maintain 10-bit output width for correct overflow handling
5. Clear reset behavior and synchronous operation
6. Generate valid_out only after 4th accumulation

Key Simplifications:
- Eliminated separate state machine logic
- Removed redundant counter variable
- Single always block design
- Reduced intermediate registers
- Maintained same functionality with less logic
