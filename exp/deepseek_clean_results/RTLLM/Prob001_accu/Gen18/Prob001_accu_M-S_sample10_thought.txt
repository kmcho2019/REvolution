To simplify the accumulator module while maintaining functionality:
1. Use a 2-bit counter to track received data (0-3)
2. Accumulate input data only when valid_in is high
3. Reset accumulator and counter on reset
4. Output accumulated sum and set valid_out when counter reaches 3 (4th input)
5. Clear accumulator after output
6. Single always block for cleaner implementation
7. Maintain same interface and behavior
