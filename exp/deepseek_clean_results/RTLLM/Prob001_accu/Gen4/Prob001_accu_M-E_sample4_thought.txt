Novel Architecture:
1. Use a shift register to store the last 4 input values (8-bit each)
2. Perform parallel addition of all 4 values when the 4th input arrives
3. Eliminate the accumulator register by calculating the sum only when needed
4. Use a state machine to track input count and control output generation
5. This approach:
   - Reduces critical path by replacing sequential accumulation with parallel addition
   - Lowers power by eliminating intermediate register updates
   - Simplifies control logic with explicit states
