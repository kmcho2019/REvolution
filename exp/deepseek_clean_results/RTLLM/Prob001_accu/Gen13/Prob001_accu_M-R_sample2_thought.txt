Refactored design approach:
1. Use continuous assignments for combinational logic where possible
2. Separate the counter and accumulator logic into distinct always blocks
3. Implement a simple state machine using the counter value
4. Use ternary operators for more concise conditional assignments
5. Make valid_out purely combinational based on counter state

Key improvements:
- Clear separation of combinational and sequential logic
- Reduced register updates by making valid_out combinational
- More explicit state transitions
- Simplified arithmetic by using the counter directly as state indicator
- Maintains same functionality but with cleaner structure
