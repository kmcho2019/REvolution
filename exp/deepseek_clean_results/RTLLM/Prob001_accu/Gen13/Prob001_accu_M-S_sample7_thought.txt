To simplify the design while maintaining functionality:
1. Replace the state machine with a simple counter to track the number of valid inputs received
2. Use a single accumulator register to store the running sum
3. Reset the accumulator and counter after every 4th valid input
4. Generate valid_out only when the counter reaches 4
5. Keep the same interface and timing behavior

Key simplifications:
- Eliminates complex state machine logic
- Uses straightforward counter-based approach
- Maintains same accumulation behavior
- Reduces control logic complexity
- Still meets all functional requirements
