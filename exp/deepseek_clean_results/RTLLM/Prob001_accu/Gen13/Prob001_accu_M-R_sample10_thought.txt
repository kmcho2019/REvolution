To refactor the design while maintaining the same functionality, I'll:
1. Replace the state machine with a simple counter approach
2. Use continuous assignments for combinational logic where possible
3. Separate the accumulation and output generation logic
4. Use non-blocking assignments only for sequential elements
5. Simplify the control logic by tracking the number of valid inputs

Key changes:
- Counter-based approach instead of explicit state machine
- Combinational sum calculation using continuous assignment
- Clear separation between accumulation and output generation
- Reduced sequential logic complexity
- Same timing behavior with potentially better area
