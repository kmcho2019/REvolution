Instead of using a counter and sequential accumulation, we can:
1. Use a 4-stage shift register to store the last 4 inputs
2. Implement parallel addition of all 4 values when the 4th input arrives
3. Use a simple state machine to track when we have 4 valid inputs
4. The shift register approach eliminates the long combinational path of sequential addition
5. Output the sum in one cycle after receiving the 4th input
6. Reset clears all registers and the state machine
