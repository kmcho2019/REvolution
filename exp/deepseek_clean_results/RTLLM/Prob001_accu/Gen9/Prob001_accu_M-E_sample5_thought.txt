New Architecture Idea:
1. Use a 4-entry shift register to store incoming data instead of immediate accumulation
2. Perform parallel addition of all 4 values when the shift register is full
3. This eliminates the chained addition critical path by doing all additions in parallel
4. Add pipeline registers to improve timing closure
5. Use clock gating for the shift register to reduce power when valid_in is low
6. Implement a finite state machine for clearer control flow
