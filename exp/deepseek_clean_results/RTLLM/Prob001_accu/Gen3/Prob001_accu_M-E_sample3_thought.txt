Here's a novel pipelined accumulator architecture that improves timing and power:

1. Use a 4-stage shift register to store incoming data when valid_in is high
2. Implement parallel addition of all 4 stored values when the shift register is full
3. Eliminate the traditional accumulator chain to break the critical path
4. Use a fill counter to track valid inputs and trigger output generation
5. Output logic is simplified to just the parallel adder result
6. Reset clears all registers and counters

Key advantages:
- Parallel addition breaks the sequential dependency chain
- Shift register provides natural data buffering
- Output generation is purely combinational from stored values
- Lower power as only active during valid_in cycles
- Better timing as critical path is just one adder stage
