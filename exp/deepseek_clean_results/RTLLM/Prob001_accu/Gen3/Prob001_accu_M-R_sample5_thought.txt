To optimize the design while maintaining the same functionality, I'll make these key changes:
1. Separate the counter and accumulation logic into distinct always blocks for better timing
2. Use a state machine approach with explicit states for clearer control flow
3. Implement the accumulator using a combinational adder with registered output
4. Use assign statements for simpler output logic where possible
5. Add pipeline registers to break the critical path
6. Optimize power by only updating registers when needed

The state machine will have:
- IDLE: Waiting for first valid input
- ACCUM: Accumulating inputs (1-3)
- OUTPUT: Generating output for 4th input
