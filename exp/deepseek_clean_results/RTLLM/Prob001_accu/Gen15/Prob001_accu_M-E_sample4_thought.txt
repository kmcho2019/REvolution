Instead of using a sequential accumulator, implement a shift register to store the last 4 inputs and perform parallel addition:
1. Use a 4-stage shift register to store incoming data
2. When valid_in is high, shift in new data and shift out oldest data
3. Perform parallel addition of all 4 register values when count reaches 3
4. Use combinational logic for the sum to reduce critical path
5. Generate valid_out only when we have 4 valid inputs
6. Reset clears all registers and counters

Advantages:
- Parallel addition reduces critical path compared to sequential accumulation
- Shift register approach enables potential pipelining
- Clear separation between data storage and computation
- Easier to extend for larger window sizes
- Lower power as only shifting occurs most cycles
