Here's a novel approach using a shift register and parallel addition:

1. Instead of accumulating sequentially, store the last 4 inputs in a shift register
2. When the 4th input arrives, perform parallel addition of all 4 values
3. This eliminates the long carry chain of sequential addition
4. Use a state machine to track input validity and control output generation

Key advantages:
- Parallel addition reduces critical path (better timing)
- Clear separation between storage and computation
- Easier to pipeline if needed
- More scalable for larger input counts
