Novel approach using pipelined accumulation with shift register:
1. Instead of a simple counter + accumulator, use a shift register to store the last 4 inputs
2. Implement a pipelined adder tree to calculate the sum in stages
3. Use a state machine to track accumulation phases
4. Key benefits:
   - Better timing: adder operations are distributed across cycles
   - Lower power: only necessary additions are performed
   - Clearer data flow: explicit storage of input samples
5. The shift register ensures we always have access to the last 4 values
6. The adder tree computes partial sums in each cycle
7. Valid_out is generated when the final sum is ready
