1. Perform shifts in stages where each stage corresponds to a control bit
2. First stage shifts by 4 if ctrl[2] is set
3. Second stage takes the first stage output and shifts by 2 if ctrl[1] is set
4. Final stage takes the second stage output and shifts by 1 if ctrl[0] is set
5. Use continuous assignments with explicit intermediate results
6. Maintain right rotation behavior as specified
7. All shifts are cumulative - multiple control bits can be active simultaneously

- Correctly handle all combinations of control bits

- Be more explicit about the cumulative nature of the shifts
