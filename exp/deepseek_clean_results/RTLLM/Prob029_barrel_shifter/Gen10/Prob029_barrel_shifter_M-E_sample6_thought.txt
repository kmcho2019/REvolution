Here's a novel approach using a hierarchical multiplexer tree structure instead of cascaded shifts:

1. Instead of sequential stages, we'll generate all possible shift amounts in parallel
2. Use a 3-level multiplexer tree to select the correct shift amount:
   - First level selects between 0/4 shift
   - Second level selects between 0/2 shift of the first level's result
   - Third level selects between 0/1 shift of the second level's result
3. Each shift amount is precomputed using concatenation
4. The control bits directly select the shift amount through the mux tree

Advantages:
- More balanced timing path compared to cascaded shifts
- Clear separation between shift amount generation and selection
- Easier to pipeline if needed
- More intuitive control signal interpretation
