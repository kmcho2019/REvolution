To implement an efficient 8-bit barrel shifter with proper structure and readability:

1. Use a staged approach with intermediate signals for each shift operation (4-bit, 2-bit, and 1-bit shifts)
2. Implement each shift stage using simple concatenation operations
3. Control each stage with the corresponding control bit (ctrl[2], ctrl[1], ctrl[0])
4. Use conditional operators to select between shifted and unshifted versions at each stage
5. Maintain the original functionality while improving readability and maintainability

The key improvements are:
- Clear separation of shift stages
- Proper signal naming for intermediate results
- Simple, verifiable shift operations
- No complex nested expressions
- Follows the problem specification exactly
