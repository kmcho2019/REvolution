Here's a simplified implementation that maintains correct functionality while reducing complexity:

1. Key simplifications:
   - Directly compute shifted versions in parallel
   - Single-stage selection using control bits
   - Eliminates intermediate stages by combining shifts in one step
   - Uses simple bit concatenation for shifts

2. Shift logic:
   - 4-bit shift controlled by ctrl[2]
   - 2-bit shift controlled by ctrl[1]
   - 1-bit shift controlled by ctrl[0]
   - Final output combines all active shifts in correct order

3. Benefits:
   - Fewer intermediate signals
   - Clearer relationship between control bits and shifts
   - More efficient implementation
   - Easier to verify correctness
