The original solution uses three stages with intermediate wires, which adds unnecessary complexity. We can simplify this by:
1. Removing intermediate wires and performing all shifts in a single expression
2. Using a single continuous assignment with nested conditional operators
3. Maintaining the same shift behavior (right rotation) but more concisely
4. Still clearly showing the shift amounts (4, 2, 1 bits) in the code
5. Keeping the same control signal interpretation (independent stage control)
