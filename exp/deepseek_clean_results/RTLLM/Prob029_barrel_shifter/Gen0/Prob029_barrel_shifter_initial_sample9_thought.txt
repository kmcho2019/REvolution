The barrel shifter will be implemented using a 3-stage approach where each stage handles a different shift amount (4, 2, or 1 bits). Each stage consists of multiplexers that select between the shifted and unshifted versions of the input. The control bits determine which stages are active. The shifting is implemented as a rotate operation where bits wrap around to maintain all 8 bits in the output.

1. First stage: Shift by 4 bits if ctrl[2] is set
2. Second stage: Shift by 2 bits if ctrl[1] is set (operates on result from first stage)
3. Third stage: Shift by 1 bit if ctrl[0] is set (operates on result from second stage)

The mux2X1 submodule will be used for each bit selection in all stages.
