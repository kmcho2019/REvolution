Here's a novel approach using a hierarchical multiplexer tree structure:

Key innovations:
1. Instead of cascaded stages, we use a direct selection approach where each output bit is independently selected from input bits based on the control signal
2. The shift amount is calculated by summing the weighted control bits (1*ctrl[0] + 2*ctrl[1] + 4*ctrl[2])
3. Each output bit is determined by selecting the input bit at position (i - shift_amount) mod 8
4. Uses a more mathematical approach to rotation rather than sequential stages

Advantages:
- Single-cycle operation with uniform delay for all bits
- More intuitive mapping between control signal and shift amount
- Easier to extend to larger bit widths
- Clear mathematical relationship between input and output
