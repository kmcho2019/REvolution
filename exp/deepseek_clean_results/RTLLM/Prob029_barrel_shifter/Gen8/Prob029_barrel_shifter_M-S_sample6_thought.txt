To simplify while maintaining the staged shifting approach, we'll implement a 3-stage barrel shifter where each stage corresponds to one bit of the control signal. Each stage will conditionally shift by its respective power-of-two amount (4, 2, or 1) based on the control bit. The shifts will cascade, with each stage operating on the result of the previous stage. This approach:

1. Matches the problem description exactly
2. Uses minimal hardware (just multiplexers)
3. Has clear correspondence between control bits and shift amounts
4. Processes shifts in order from largest to smallest (4, then 2, then 1)
5. Is more area-efficient than the lookup table approach
