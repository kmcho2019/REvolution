The refactored design will maintain the same functionality but implement it differently:
1. Remove the hierarchical mux2X1 module to avoid declaration conflicts
2. Use continuous assignments (assign) instead of module instances
3. Keep the 3-stage approach (4, 2, 1 bit shifts)
4. Maintain the parameterized direction control
5. Use concatenation and selection for shifting operations directly
6. Combine the stages into a single expression for better optimization

Key changes:
- Eliminate submodule hierarchy while keeping same logical structure
- Use direct bit manipulation with concatenation
- Simplify the data flow while maintaining same functionality
- Keep parameterized direction control
- Make more compact while preserving readability
