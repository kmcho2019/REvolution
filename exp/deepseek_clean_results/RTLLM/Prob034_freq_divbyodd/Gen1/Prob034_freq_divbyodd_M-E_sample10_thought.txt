Instead of using two separate counters for pos/neg edges, we'll use:
1. A single counter that counts full cycles (both edges)
2. Two toggle points at (NUM_DIV-1)/2 and NUM_DIV-1
3. A phase-shifted version of the clock to create the second toggle event
4. XOR combination of these toggles to create the final output
This reduces counter logic while maintaining precise 50% duty cycle for odd divisions.
