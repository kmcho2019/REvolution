Novel approach for odd frequency division using dual-phase generation:
1. Generate two 50% duty cycle clocks with 180° phase difference
2. Each phase uses a counter that toggles at (NUM_DIV-1)/2 and NUM_DIV-1
3. Combine the phases using OR operation to create final output
4. Key innovations:
   - Uses standard single-edge triggered logic
   - Avoids complex edge detection
   - Naturally creates correct duty cycle
   - Easier timing closure
   - More robust implementation
5. Implementation:
   - Two identical counters running on opposite clock edges
   - Each generates half of the divided clock
   - Final output combines both halves
