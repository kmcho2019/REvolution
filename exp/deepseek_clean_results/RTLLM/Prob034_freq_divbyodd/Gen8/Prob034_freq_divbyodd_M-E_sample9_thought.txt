Novel state machine-based odd frequency divider:
1. Use a 3-state FSM (IDLE, HIGH, LOW) to manage the divided clock
2. Detect both rising and falling edges of input clock using edge detectors
3. State transitions occur on both clock edges to maintain 50% duty cycle
4. Counter tracks edges until reaching (NUM_DIV-1)/2 edges for high phase
5. Uses parameterized division with NUM_DIV defaulting to 5
6. Reset initializes state and counters
7. More robust than counter-only solutions with better edge alignment
8. Explicit edge handling ensures precise timing for odd divisions
