Novel approach using a state machine and edge detection:
1. Instead of counters, implement a finite state machine that tracks the required clock edges
2. Use a toggle flip-flop that changes state based on both positive and negative edges
3. Implement edge detection logic to identify when to toggle the output
4. The state machine transitions through NUM_DIV states, toggling output at both (NUM_DIV-1)/2 and NUM_DIV-1 counts
5. This approach eliminates separate counters while maintaining precise edge alignment
6. Reset initializes the state machine to state 0 and output low
