Simplified odd frequency divider with single counter and edge detection:

1. **Single Counter Approach**: Use one counter that counts from 0 to NUM_DIV-1 on both clock edges
2. **Dual-Edge Detection**: Detect both rising and falling edges implicitly through counter behavior
3. **Symmetric Toggle Points**: Toggle output at (NUM_DIV-1)/2 and NUM_DIV-1 counts
4. **Single Output Register**: Maintain one output register that toggles at calculated points
5. **Simpler Logic**: Eliminate separate phase registers and use direct counter comparison

Key improvements:
- Single counter reduces logic complexity
- Direct toggle based on counter value
- Maintains proper 50% duty cycle for odd division
- Cleaner implementation with fewer registers
- Still meets all functional requirements
