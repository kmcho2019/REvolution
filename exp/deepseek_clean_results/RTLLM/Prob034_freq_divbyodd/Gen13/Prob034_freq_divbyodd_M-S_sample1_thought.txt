Simplified Odd Frequency Divider Design:

1. **Single Counter Approach**: Use one counter that counts on both clock edges to simplify logic
2. **Symmetric Toggle**: Toggle output when counter reaches (NUM_DIV-1)/2 and NUM_DIV-1
3. **Edge Detection**: Use both clock edges to increment counter and toggle output
4. **Reset Handling**: Maintain synchronous reset for clean initialization
5. **Parameter Check**: Keep odd number validation

Key Simplifications:
- Eliminates need for two separate counters
- Reduces register usage
- Maintains 50% duty cycle
- Simplifies control logic
- Still works for any odd divisor
