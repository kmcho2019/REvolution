Simplified odd frequency divider approach:
1. Use a single counter that counts on both clock edges to track full cycles
2. Generate two toggle signals offset by half a cycle for 50% duty cycle
3. Create divided clocks from both edges using the counter values
4. Combine the edge-divided clocks with OR operation
5. Maintain parameter validation and reset functionality
6. Key simplifications:
   - Single counter instead of two
   - Direct toggle generation from counter
   - Cleaner edge alignment
   - Reduced register usage
