Simplified Odd Frequency Divider Design:

1. **Single Counter Approach**:
   - Use one counter that counts on both clock edges (double the effective clock rate)
   - Eliminates need for separate positive/negative edge counters

2. **Simplified Toggle Logic**:
   - Toggle output when counter reaches (NUM_DIV-1)/2 and NUM_DIV-1
   - Single toggle register instead of separate ones for each edge

3. **Reduced Logic**:
   - Remove XOR/OR combination logic
   - Directly drive output from toggle register

4. **Maintained Functionality**:
   - Still achieves 50% duty cycle
   - Same division ratio as original
   - Clean reset behavior

Key Simplifications:
- Single counter instead of two
- Eliminated intermediate toggle signals
- Removed output combination logic
- Fewer registers overall
- Same clock domain for all logic
