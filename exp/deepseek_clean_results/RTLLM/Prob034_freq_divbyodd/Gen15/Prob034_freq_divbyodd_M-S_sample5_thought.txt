Simplified approach for odd frequency division:
1. Use a single counter that counts on both clock edges (dual-edge counting)
2. Toggle the output clock when counter reaches (NUM_DIV-1)/2 and NUM_DIV-1
3. Reset counter when it reaches NUM_DIV-1
4. Generate output clock directly from counter values
5. Maintain 50% duty cycle by toggling at mid-point and end of count
6. Use synchronous reset for consistent behavior
7. Keep parameter validation for odd division factor

Key simplifications:
- Eliminates separate pos/neg edge counters
- Removes intermediate clock signals
- Single always block for all logic
- Clear toggle points based on counter value
- Maintains original functionality with less code
