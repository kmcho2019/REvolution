Dual-Edge Counter with Phase Compensation:
1. Use a single counter that increments on both clock edges (dual-edge counting)
2. Generate two phase-shifted clock enables at 180° offsets
3. Combine these enables through an XOR gate to create the final output
4. The counter runs at twice the clock frequency (counting both edges)
5. Phase enables are generated when counter reaches (NUM_DIV-1)/2 and NUM_DIV-1
6. This creates perfect 50% duty cycle regardless of odd division ratio
7. Reset synchronously initializes all elements

Key Advantages:
- Single counter simplifies control logic
- Perfect 50% duty cycle guaranteed by phase symmetry
- No separate edge domains to synchronize
- Scalable to any odd division ratio
- Clear phase relationship between input and output
- Minimal logic resources required
