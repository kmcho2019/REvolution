Simplified approach for odd frequency division:
1. Use a single counter that counts on both clock edges (dual-edge counting)
2. Toggle output clock when counter reaches half-cycle points (both rising and falling)
3. Reset counter when reaching full period (NUM_DIV-1)
4. Generate 50% duty cycle by toggling at both (NUM_DIV-1)/2 and NUM_DIV-1 counts
5. Single always block for both edge processing simplifies synchronization
6. Maintain parameter validation for odd division factor
7. Use synchronous reset for consistent behavior

Key simplifications:
- Eliminates separate pos/neg edge counters
- Removes need for intermediate clocks (clk_div1/clk_div2)
- Single always block handles all edge cases
- Maintains same functionality with less code
