Novel approach for odd frequency division using a single counter and edge detection:
1. Use a single counter that counts both rising and falling edges of the input clock
2. Implement a state machine that tracks when to toggle the output clock
3. The counter runs at twice the clock frequency (counting both edges)
4. Toggle the output clock when the counter reaches (NUM_DIV-1)/2 and NUM_DIV-1
5. This creates a 50% duty cycle by precisely controlling the toggle points
6. Reset initializes the counter and output clock to known states

Key advantages:
- Single counter simplifies design
- More precise control over toggle points
- Eliminates need for separate positive/negative edge counters
- Maintains 50% duty cycle through mathematical precision
- Easier to verify and test
