Novel Single-Counter with Phase Compensation:
1. Use a single counter running at input clock rate to simplify design
2. Implement phase compensation by toggling output at both edges when needed
3. Key innovation: Calculate toggle points mathematically to maintain 50% duty cycle
   - First toggle at (NUM_DIV-1)/2 count (rising edge)
   - Second toggle at NUM_DIV-1 count (falling edge)
4. Use XOR-based phase correction to maintain proper alignment
5. Advantages:
   - Single counter reduces area and power
   - Maintains precise 50% duty cycle
   - Eliminates need for separate edge domains
   - Simpler timing analysis
