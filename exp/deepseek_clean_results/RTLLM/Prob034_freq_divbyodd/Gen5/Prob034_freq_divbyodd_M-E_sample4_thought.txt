Novel approach for odd frequency divider using edge-aligned pulse generation:
1. Instead of using two separate counters, generate precise pulses at both rising and falling edges
2. Create a main counter that counts full clock periods (0 to NUM_DIV-1)
3. Generate two control signals: one for rising edge toggle (at (NUM_DIV-1)/2) and one for falling edge toggle (at NUM_DIV-1)
4. Use these control signals to create short pulses synchronized with both clock edges
5. Combine these pulses using an SR latch to create a clean 50% duty cycle output
6. This approach ensures precise edge alignment while maintaining a simple counter structure
7. The SR latch provides glitch-free output transitions
