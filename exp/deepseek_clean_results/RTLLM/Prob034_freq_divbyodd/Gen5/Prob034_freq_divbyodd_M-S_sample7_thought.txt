Simplified approach for odd frequency divider:
1. Use a single counter that counts on both clock edges (double the counting rate)
2. Toggle the output clock when counter reaches (NUM_DIV-1)/2 and NUM_DIV-1
3. This achieves the same effect as two separate counters but with simpler logic
4. Reset initializes counter and output clock
5. Still maintains 50% duty cycle by toggling at mid-point and end of count
6. Single always block handles all operations
7. Eliminates need for separate edge-triggered counters and clock combination
8. More efficient implementation while preserving functionality
