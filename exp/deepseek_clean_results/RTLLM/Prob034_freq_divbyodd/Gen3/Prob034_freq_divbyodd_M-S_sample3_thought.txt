To simplify the odd frequency divider while maintaining functionality:

1. Single Counter Approach:
   - Use one counter instead of two, counting on both edges
   - This reduces complexity while still achieving odd division

2. Edge-Triggered Logic:
   - Toggle output at both positive and negative edges
   - Count up to NUM_DIV (not NUM_DIV-1) for simpler comparison

3. Duty Cycle Control:
   - Toggle output when counter reaches (NUM_DIV-1)/2 and NUM_DIV-1
   - This ensures proper 50% duty cycle

4. Reset Handling:
   - Synchronous reset for counter and output
   - Initialize all signals properly

The simplified version maintains the same functionality with:
- Half the number of counters
- Clearer toggle conditions
- Same output frequency and duty cycle
