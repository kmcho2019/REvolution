Novel approach for odd frequency divider:
1. Use a single counter that counts on both clock edges (dual-edge counting)
2. Implement a state machine that tracks when to toggle the output clock
3. Toggle the clock at specific counter values to achieve 50% duty cycle
4. For odd division N, the output toggles at (N-1)/2 and (N-1) counts
5. Reset initializes the counter and output clock
6. This method requires only one counter and simpler logic than the dual-counter approach
7. The dual-edge counting ensures precise timing for odd division
