To simplify the odd frequency divider while maintaining functionality, I'll implement these key changes:

1. Single Counter Approach:
   - Use one counter instead of two, counting on both edges
   - This reduces complexity while still achieving odd division

2. Simplified Toggle Logic:
   - Toggle output at both (NUM_DIV-1)/2 and NUM_DIV-1 points
   - Creates proper 50% duty cycle with single control signal

3. Edge Handling:
   - Process both clock edges in one always block
   - Eliminates need for separate edge counters and clock signals

4. Reset Handling:
   - Maintain synchronous reset functionality
   - Initialize counter and output signal properly

The simplified version achieves the same functionality with:
- 50% less counter logic
- No need for combining multiple clock signals
- Clearer and more maintainable code
