Simplified dual-counter odd frequency divider:

1. **Dual Counter Logic**: Maintain two counters (cnt_p and cnt_n) for positive and negative edges respectively, but simplify their implementation
2. **Shared Midpoint Logic**: Calculate toggle points once as parameters for cleaner code
3. **Direct Output Control**: Generate clock edges directly from counter values without intermediate flags
4. **Symmetric Reset**: Reset both counters and output synchronously
5. **Efficient OR Logic**: Combine positive and negative edge contributions directly in output generation

Key simplifications:
- Eliminates separate toggle flags
- Removes intermediate clock dividers (clk_div1/clk_div2)
- Uses direct counter comparison for output control
- Maintains required 50% duty cycle
- Reduces register usage while preserving functionality
