Refactoring approach:
1. Use a single always block for all sequential logic to simplify the design
2. Remove intermediate combinational assignments and handle all updates directly in the clocked block
3. Maintain the same functionality but with clearer state transitions
4. Keep output assignments combinational for immediate response
5. This approach reduces unnecessary combinational paths and makes the design more straightforward

Key changes:
- Single always block for register updates
- Direct handling of fetch conditions within the clocked block
- Clear reset behavior
- Same output derivation logic
- More efficient implementation with fewer intermediate signals
