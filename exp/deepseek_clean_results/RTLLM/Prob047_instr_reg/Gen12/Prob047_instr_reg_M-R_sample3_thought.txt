Refactored Design Approach:
1. Simplified single-edge triggering: Uses only positive clock edge for better timing closure
2. Direct output assignment: Uses continuous assignments for combinational outputs
3. Reduced logic complexity: Eliminates redundant priority encoder since fetch modes are mutually exclusive
4. Optimized register usage: Combines output generation with input capture in single always block
5. Cleaner reset handling: Explicit reset values for all registers

Key Improvements:
- Single clock domain (posedge) simplifies timing analysis
- Continuous assignments for outputs reduce sequential logic
- Clear separation of capture and output logic
- More efficient use of registers
- Maintains same functionality while being more synthesis-friendly
