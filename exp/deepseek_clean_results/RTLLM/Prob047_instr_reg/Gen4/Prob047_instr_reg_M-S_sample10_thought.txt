To simplify the design while maintaining functionality, I'll make these key changes:
1. Remove the separate always block for register updates and use continuous assignments with clock gating
2. Eliminate the need for two separate registers by directly assigning outputs based on fetch state
3. Use simpler conditional assignments for the outputs
4. Maintain the same interface and functionality but with fewer internal state elements

This reduces complexity by:
- Eliminating internal registers since outputs can be directly derived from inputs
- Removing sequential logic where combinational is sufficient
- Simplifying the control flow to just output assignments
- Maintaining the same external behavior with less internal state
