Innovative Architecture:
1. Dual-edge triggering: Uses both rising and falling clock edges to potentially double throughput
2. Pipelined processing: Splits instruction processing into two stages (capture and decode)
3. Dynamic source selection: Implements a priority encoder for fetch signals
4. Power gating: Automatically powers down unused register banks

Key Features:
- Rising edge captures instruction from source 1 (register)
- Falling edge captures instruction from source 2 (RAM/ROM)
- Output registers for stable decoded values
- Automatic clock gating when no fetch is active
- Priority-based fetch handling (RAM/ROM over register when both fetch signals active)

Advantages:
- Potential 2x throughput with dual-edge operation
- Better timing closure with pipelined outputs
- Reduced power consumption through smart clock gating
- More robust handling of simultaneous fetch requests
