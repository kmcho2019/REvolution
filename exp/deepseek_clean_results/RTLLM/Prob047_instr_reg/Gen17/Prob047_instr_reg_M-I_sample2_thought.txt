Improvement Strategy:
1. Timing Optimization:
   - Remove the clock enable logic to reduce gate delay before register updates
   - Simplify the conditional assignments by using separate always blocks for each register
   - Eliminate the concatenation in output assignment to reduce routing complexity

2. Power Optimization:
   - Implement true clock gating when no fetch is active
   - Make register updates more selective to reduce unnecessary switching
   - Use separate always blocks to minimize evaluation of unused conditions

3. Area Optimization:
   - Maintain simple register structure but with more efficient implementation
   - Simplify output assignments to reduce routing resources
   - Remove unnecessary logic operations

Key Changes:
- Separate always blocks for each register with direct clock gating
- Simplified output assignments without concatenation
- More selective register updates
- Removal of intermediate clock enable logic
