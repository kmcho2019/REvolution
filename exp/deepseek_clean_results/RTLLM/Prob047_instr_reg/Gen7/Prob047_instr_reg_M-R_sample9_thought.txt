Refactoring approach:
1. Use a single always block for all sequential logic to simplify the design
2. Remove intermediate combinational assignments and handle all register updates directly in the clocked block
3. Maintain the same functionality but with clearer state transitions
4. Use non-blocking assignments for all register updates to ensure proper synchronous behavior
5. Keep output assignments as simple wire connections for clarity

Key improvements:
- Eliminates unnecessary combinational paths
- More straightforward clocked behavior
- Reduced power consumption by minimizing unnecessary switching
- Better synthesis characteristics with all sequential logic in one block
- Maintains identical functionality with cleaner structure
