Novel architectural idea:
1. Implement a single unified register instead of two separate registers (ins_p1 and ins_p2)
2. Use a multiplexer-based approach to select which part of the register gets updated
3. Add output registers to improve timing closure
4. Implement clock gating for power optimization when fetch is inactive
5. Use parameterized bit slicing for better maintainability
6. Add a write enable signal derived from fetch to reduce unnecessary switching
This approach reduces area by sharing storage and improves power efficiency through clock gating while maintaining the same functionality.
