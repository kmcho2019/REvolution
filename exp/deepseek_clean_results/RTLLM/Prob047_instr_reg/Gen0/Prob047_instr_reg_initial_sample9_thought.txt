The instruction register needs to store instructions from two different sources based on the fetch control signal. We'll use two 8-bit registers (ins_p1 and ins_p2) to store these instructions. The module will:
1. Reset both registers to 0 when rst is low
2. On clock edges, update either ins_p1 or ins_p2 based on fetch signal
3. Output the high 3 bits of ins_p1 as 'ins', low 5 bits as 'ad1'
4. Output the full ins_p2 as 'ad2'
5. Retain previous values if no valid fetch signal is present
