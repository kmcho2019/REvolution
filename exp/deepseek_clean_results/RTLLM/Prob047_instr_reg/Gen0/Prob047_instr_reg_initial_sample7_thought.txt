The instruction register module needs to:
1. Store instructions from different sources in separate registers (ins_p1 and ins_p2)
2. Reset both registers to 0 when rst is low
3. Update the appropriate register based on the fetch signal
4. Split the stored instruction from ins_p1 into opcode (high 3 bits) and register address (low 5 bits)
5. Output the full instruction from ins_p2 as ad2
6. Maintain current values when no fetch operation is requested
