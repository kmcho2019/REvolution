Innovative pipelined architecture with these key features:
1. Two-stage pipeline: First stage captures instructions, second stage holds outputs
2. Output registers reduce critical path by decoupling capture and output timing
3. Separate enable signals for each pipeline stage
4. Early reset propagation through both stages
5. Output registers improve timing at the cost of 1 cycle latency
6. More robust against timing violations in high-frequency designs
7. Better clock-to-Q timing on outputs
