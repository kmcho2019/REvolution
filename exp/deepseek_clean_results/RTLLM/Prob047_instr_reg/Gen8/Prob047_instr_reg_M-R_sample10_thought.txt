Refactoring Strategy:
1. Structural Change:
   - Replace the always block with continuous assignments for register updates
   - Use ternary operators for conditional register updates
   - Maintain the same functionality but with a more dataflow-oriented style

2. Benefits:
   - More concise code with same behavior
   - Eliminates explicit always block while keeping synchronous behavior
   - Shows alternative implementation style that some designers prefer for simple registers

3. Key Points:
   - Still uses clocked registers (via procedural assignments in continuous assigns)
   - Maintains identical reset and enable conditions
   - Preserves direct output assignments
   - Same PPA characteristics expected since synthesis will produce similar hardware
