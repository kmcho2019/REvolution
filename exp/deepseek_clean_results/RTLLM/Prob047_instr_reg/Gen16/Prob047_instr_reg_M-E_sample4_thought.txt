Novel shift register approach:
1. Implement the instruction register as a shift register with parallel load capability
2. Use a single 16-bit register to store both instructions (ins_p1 and ins_p2) concatenated
3. Add a 'load' control signal derived from fetch to determine when to shift/load
4. Implement circular shifting when loading new instructions to maintain both parts
5. Outputs are derived from different segments of the unified register
6. Benefits: 
   - Single register reduces area
   - Circular shifting allows efficient updates
   - Unified storage simplifies control logic
   - Potential power savings from reduced register count
