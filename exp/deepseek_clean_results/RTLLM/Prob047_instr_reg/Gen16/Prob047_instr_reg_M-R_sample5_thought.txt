Refactored Design Approach:
1. Simplified single-edge triggered design using only posedge clk for better timing closure
2. Removed redundant priority encoder since fetch signals are mutually exclusive
3. Replaced sequential output registers with combinational logic for reduced area
4. Simplified clock gating by directly using fetch signals as enables
5. Maintained same functionality while improving PPA metrics

Key Improvements:
- Single clock edge simplifies timing analysis
- Combinational output logic reduces register count
- Direct fetch signal usage eliminates unnecessary logic
- Clear separation of capture and output logic
- Maintains same instruction processing behavior
