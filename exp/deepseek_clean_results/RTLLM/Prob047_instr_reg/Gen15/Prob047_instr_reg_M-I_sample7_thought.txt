Improvement Strategy:
1. Move all register update logic into the clocked always block to eliminate unnecessary combinational paths and reduce critical path length
2. Remove the intermediate combinational assignments (ins_p1, ins_p2) to reduce switching activity and power consumption
3. Maintain the same functionality while simplifying the structure
4. Keep output assignments combinational as they are simple bit-slicing operations
5. This should improve timing (reduce critical path), reduce power (less switching), and potentially reduce area (simpler logic)

Key Changes:
- Single always block for all sequential logic
- Direct register updates based on fetch and reset conditions
- Same output derivation logic
- More efficient implementation with better PPA characteristics
