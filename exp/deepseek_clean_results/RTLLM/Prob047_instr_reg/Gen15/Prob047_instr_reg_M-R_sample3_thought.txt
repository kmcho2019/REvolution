Refactoring Approach:
1. Structural Changes:
   - Replace the always block with continuous assignments for register updates
   - Use ternary operators for conditional updates
   - Maintain the same functionality but with a more dataflow-oriented style

2. Benefits:
   - More concise implementation
   - Clearer dataflow representation
   - Easier to see the direct relationship between inputs and register updates
   - Maintains same timing characteristics since synthesis will infer the same registers

3. Key Changes:
   - ins_p1 and ins_p2 now updated via continuous assignments
   - Reset implemented through muxing at the register inputs
   - Fetch conditions implemented through ternary operators
   - Output assignments remain direct from registers
