Refactoring approach:
1. Use a single always block for synchronous behavior to simplify the design
2. Move all register updates into the clocked always block for better timing
3. Remove intermediate combinational assignments to reduce power consumption
4. Maintain direct output assignments for clarity
5. Simplify reset logic by handling it directly in the always block

Key improvements:
- Eliminates unnecessary combinational paths
- Reduces power by minimizing switching activity
- Simplifies the design with a single always block
- Maintains same functionality with cleaner structure
- Better for synthesis as all register updates are clocked
