Novel Architecture Concept:
1. Dual-edge triggering:
   - Utilize both rising and falling edges of the clock to maximize timing margin
   - Fetch operations occur on rising edge, output updates on falling edge
   - This effectively doubles the available timing budget

2. Output pipelining:
   - Add pipeline registers for outputs to break critical paths
   - Improves timing at the cost of one additional cycle latency

3. Smart power gating:
   - Only update output registers when inputs change
   - Uses XOR-based change detection to minimize unnecessary switching

4. Optimized field extraction:
   - Pre-compute output fields during fetch to reduce output path complexity
   - Store extracted fields in dedicated registers

Key Benefits:
- Better timing closure with dual-edge operation
- Reduced output path criticality through pipelining
- Lower dynamic power through change detection
- Clean separation of fetch and output phases
