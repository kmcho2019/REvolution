Refactoring Approach:
1. Simplified single-edge design: Use only positive clock edge for all operations to improve timing closure
2. Combinational outputs: Replace registered outputs with continuous assignments for simpler logic
3. Direct fetch handling: Remove priority encoder since fetch signals are mutually exclusive
4. Efficient register usage: Maintain only necessary internal registers
5. Clear separation: Split the logic into distinct capture and output generation parts

Key Improvements:
- Eliminates timing challenges from dual-edge triggering
- Reduces area by removing redundant logic and registers
- Maintains same functionality with cleaner implementation
- Improves readability with direct assignments
- Better matches standard synchronous design practices
