Novel Architecture Concept:
1. Dual-edge triggering:
   - Utilize both clock edges to maximize timing margin
   - Fetch operations occur on rising edge, output updates on falling edge
   - This effectively doubles the timing budget for critical paths

2. Output pipelining:
   - Add a pipeline stage for outputs to break timing paths
   - Output registers updated on falling edge to separate from input capture

3. Power-aware design:
   - Use explicit output enables instead of clock gating
   - Only update outputs when fetch signals change (event-based)

4. Resource sharing:
   - Single always block for both registers with shared control logic
   - Combined reset handling for both registers

Benefits:
- Better timing closure with dual-edge operation
- Cleaner clock domain without gating logic
- Reduced power through event-based updates
- Simplified control flow with shared logic
