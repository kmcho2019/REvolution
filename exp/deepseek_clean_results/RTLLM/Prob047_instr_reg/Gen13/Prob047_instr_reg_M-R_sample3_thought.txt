Refactoring approach:
1. Use a single always block for sequential logic to simplify the design
2. Move all register updates into the clocked always block for better timing
3. Remove intermediate combinational assignments to reduce power consumption
4. Maintain direct output assignments for clarity
5. Simplify the reset logic by handling it within the always block

Key improvements:
- Single clocked always block for all sequential logic
- Eliminates unnecessary combinational paths
- More power efficient as registers only update on clock edges
- Clearer separation of sequential and combinational logic
- Maintains identical functionality while being more hardware-efficient
