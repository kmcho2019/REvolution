Novel Architectural Approach:
1. Dual-edge triggering: Capture data on both rising and falling edges of clock to maximize throughput
2. Output pipelining: Add pipeline registers for outputs to improve timing
3. Smart source selection: Use fetch signals to dynamically select which register gets updated
4. Power optimization: Only update registers when fetch signals are active
5. Compact encoding: Use a single always block for both registers with case statement

Key Innovations:
- Dual-edge operation doubles potential instruction capture rate
- Pipelined outputs improve timing closure
- Dynamic power reduction by only updating active registers
- Compact control logic using case statement
- Maintains same functionality while improving performance
