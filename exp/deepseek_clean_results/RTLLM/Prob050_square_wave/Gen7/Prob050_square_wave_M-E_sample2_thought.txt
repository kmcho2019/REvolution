This design uses a phase accumulator architecture that offers several advantages:
1. More precise frequency control through phase accumulation
2. Eliminates the need for explicit counter comparisons
3. Naturally handles frequency changes without glitches
4. Scales better for higher precision requirements

Key features:
- Uses a 16-bit phase accumulator (higher precision than required)
- Takes the MSB of the accumulator as the square wave output
- Automatically handles frequency changes by accumulating the input frequency value
- No special cases needed for freq=0 (output stays low naturally)
- Phase wrapping occurs automatically due to fixed-width arithmetic

The output frequency is (freq * clk_freq) / 2^16, providing finer control than the original 8-bit counter approach.
