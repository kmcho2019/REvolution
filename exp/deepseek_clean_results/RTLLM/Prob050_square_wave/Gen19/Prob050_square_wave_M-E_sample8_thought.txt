Novel DDS-inspired Approach:
1. Phase Accumulator: Instead of a simple counter, use a phase accumulator that adds the frequency value each cycle
2. Phase Wrapping: The accumulator naturally wraps around when it overflows, creating periodic behavior
3. MSB Toggle: Use the MSB of the accumulator as the square wave output for perfect 50% duty cycle
4. Dynamic Frequency: Frequency changes take effect immediately without glitches
5. Power Efficiency: No comparison operations needed in the critical path, reducing power

Key Advantages:
- Single arithmetic operation per cycle (addition) instead of comparison
- Perfect 50% duty cycle guaranteed by MSB toggling
- Glitch-free frequency changes
- Lower power due to simpler critical path
- Higher maximum frequency due to reduced logic depth
