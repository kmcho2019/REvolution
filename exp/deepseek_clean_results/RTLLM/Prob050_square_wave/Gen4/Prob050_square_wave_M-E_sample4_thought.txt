I'll implement a square wave generator using a phase accumulator architecture. This approach offers several advantages:
1. Uses a phase accumulator to track waveform position rather than a simple counter
2. Provides more precise frequency control and better frequency resolution
3. Enables easy future expansion to other waveform types
4. Uses addition instead of subtraction for potentially better timing
5. The phase overflow naturally triggers the square wave toggle

Key components:
- 16-bit phase accumulator (higher resolution than input freq)
- Phase increment calculated from input frequency
- Output toggles when accumulator overflows
- More efficient for high frequencies as it doesn't require full countdown
