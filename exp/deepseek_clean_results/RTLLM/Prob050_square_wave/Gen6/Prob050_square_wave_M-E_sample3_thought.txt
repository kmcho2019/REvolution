Novel Architecture: Dual-Counter Synchronized Waveform Generator
1. Instead of a single counter, use two synchronized counters (main and phase) for improved duty cycle control
2. Main counter determines the period while phase counter creates precise 50% duty cycle
3. Phase counter runs at twice the frequency of main counter for better resolution
4. Wave output toggles when phase counter reaches main counter value
5. Benefits:
   - Guaranteed 50% duty cycle regardless of frequency setting
   - Reduced glitch potential during frequency changes
   - Better frequency resolution with same counter width
   - Synchronous design avoids timing hazards
