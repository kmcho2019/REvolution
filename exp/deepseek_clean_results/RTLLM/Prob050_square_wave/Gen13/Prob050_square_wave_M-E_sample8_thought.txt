Novel Architecture: Phase Accumulator Square Wave Generator
1. Instead of using a traditional counter, implement a phase accumulator that continuously adds the frequency value
2. The MSB of the accumulator naturally becomes our square wave output
3. Benefits:
   - No explicit comparison needed (reduces combinational logic)
   - Automatically handles frequency changes smoothly
   - Scales better for higher resolution frequencies
   - More efficient hardware implementation
4. Implementation details:
   - 16-bit accumulator provides good frequency resolution
   - Output is simply the MSB of the accumulator
   - Frequency input scales the phase increment
   - No explicit counter reset logic needed
