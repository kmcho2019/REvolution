Simplification Strategy:
1. Single Clock Domain: Use only the main clk signal to simplify timing and remove gated clock logic
2. Consolidated Logic: Handle all cases (including freq=0) within a single always block
3. Direct Comparison: Remove redundant checks by directly comparing count with (freq-1)
4. Reset Behavior: Initialize wave_out to 0 and maintain this state when freq=0
5. Minimal Registers: Keep only necessary registers (count and wave_out)

Key Improvements:
- Eliminates gated clock logic
- Reduces to single always block
- Maintains same functionality with simpler code
- Better timing characteristics
- Lower power consumption
