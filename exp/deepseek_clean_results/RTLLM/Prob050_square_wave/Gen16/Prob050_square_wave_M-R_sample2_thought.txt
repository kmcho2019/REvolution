Refactoring Strategy:
1. Output Generation:
   - Replace sequential wave_out generation with combinational logic using XOR
   - This eliminates the need for a separate register for wave_out
   - Output toggles when counter wraps around

2. Counter Implementation:
   - Maintain 6-bit counter but simplify reset condition
   - Use continuous assignment for counter enable logic
   - Make counter behavior more explicit with clear condition

3. Structural Changes:
   - Move all combinational logic to assign statements
   - Keep only necessary sequential elements in always block
   - Make frequency comparison more direct

Key Benefits:
- Reduced register usage (wave_out now combinational)
- Clearer separation of combinational and sequential logic
- More explicit counter behavior
- Maintains same functionality with simpler structure
