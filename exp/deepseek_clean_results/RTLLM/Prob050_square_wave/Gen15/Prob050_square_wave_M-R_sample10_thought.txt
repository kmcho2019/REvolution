Refactoring Strategy:
1. Output Generation:
   - Replace sequential wave_out generation with combinational logic using XOR operation
   - This eliminates the need for a separate output register and reduces area

2. Counter Implementation:
   - Maintain down-counter approach but make it purely combinational
   - Use parallel load capability instead of explicit comparison
   - This reduces critical path by eliminating the comparison operation

3. Clock Gating:
   - Keep the enable logic but implement it more efficiently
   - Use continuous assignment for clearer intent

Key Changes:
- wave_out now generated directly from counter MSB (no sequential element)
- Counter implemented with parallel load when reaching zero
- Simplified control logic using continuous assignments
- More efficient clock gating implementation
