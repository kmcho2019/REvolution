Refactoring Strategy:
1. Structural Change: Convert sequential logic to continuous assignments using 'assign' statements where possible
2. State Representation: Use a single always block for sequential elements only (count and wave_out)
3. Logic Simplification: Pre-compute comparison results to reduce critical path
4. Clock Gating: Maintain power optimization but implement as a simple enable condition
5. Output Generation: Move combinational logic to continuous assignments

Key Benefits:
- Reduced sequential logic complexity (single always block)
- Clear separation of combinational and sequential logic
- Maintains identical functionality while improving readability
- Potential timing improvement by reducing always block complexity
