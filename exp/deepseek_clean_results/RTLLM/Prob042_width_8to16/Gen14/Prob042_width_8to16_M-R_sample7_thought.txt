Refactored design using a simple state machine approach with synchronous reset only:

1. State Machine Approach:
   - IDLE: Waiting for first valid input
   - GOT_FIRST: Stored first byte, waiting for second byte
   - Transitions between states based on valid_in

2. Key Improvements:
   - Pure synchronous design (no negedge rst_n) for better synthesis
   - Explicit state machine makes behavior clearer
   - Output generation logic separated from data path
   - Uses continuous assignment for output when possible

3. Benefits:
   - More predictable synthesis results
   - Clear state transitions for verification
   - Maintains same functionality while being more robust
   - Easier to extend if requirements change
