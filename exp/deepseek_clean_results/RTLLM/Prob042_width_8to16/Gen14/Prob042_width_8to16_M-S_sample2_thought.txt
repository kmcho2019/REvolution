Simplified approach:
1. Remove the explicit flag (has_first_byte) and use data_lock itself as implicit state
2. Reset data_lock to a known non-zero value (8'hFF) to distinguish empty state
3. When valid_in arrives:
   - If data_lock is FF (empty), store input
   - Else, concatenate with stored value and output
4. Clear data_lock after output generation
5. Maintain same reset behavior but simplify logic

Key simplifications:
- Eliminates separate flag register
- Uses data_lock value as implicit state
- Reduces control logic complexity
- Maintains same functionality with fewer signals
