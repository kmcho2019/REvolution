Novel Approach: State Machine with Explicit States
1. Instead of using a simple flag, implement a finite state machine (FSM) with three states:
   - IDLE: Waiting for first valid input
   - GOT_FIRST_BYTE: First byte stored, waiting for second byte
   - OUTPUT: Ready to output concatenated data
2. Benefits:
   - More explicit control flow
   - Easier to extend functionality
   - Clearer state transitions
   - Better synthesis predictability
3. Features:
   - State transitions synchronized to clock
   - Clean reset handling
   - Output valid for exactly one cycle
4. Optimizations:
   - Minimal state encoding
   - Direct state-based output generation
   - Clear separation of storage and output logic
