Refactoring Strategy:
1. Use explicit state machine with defined states (IDLE, FIRST_RECEIVED) for clearer control flow
2. Separate combinational and sequential logic blocks for better modularity
3. Use continuous assignments for outputs where possible
4. Implement next-state logic separately from output generation
5. Add explicit state transitions for all cases

Key Improvements:
- Clear state machine makes behavior more explicit
- Separation of concerns between state tracking and output generation
- Reduced complexity in always blocks
- Maintains same functionality while being more maintainable
- Better handles edge cases with explicit state transitions
