Refactored Design Approach:
1. Use explicit state machine with two states (IDLE, GOT_FIRST) for clearer control flow
2. Separate combinational and sequential logic for better synthesis results
3. Use continuous assignments for outputs where possible
4. Make state transitions more explicit
5. Maintain same functionality but with improved structure

Key Improvements:
- Clear state machine makes behavior more obvious
- Separation of combinational/sequential logic helps synthesis
- Output assignments are more straightforward
- Easier to extend or modify if requirements change
- Better match to synchronous design practices
