Refactored Design Strategy:
1. Eliminated explicit state machine in favor of a data-ready flag approach
2. Used continuous assignments for outputs where possible
3. Simplified control logic by tracking only whether we have the first byte
4. Maintained same timing behavior (2-cycle latency)
5. Improved reset handling by removing explicit initializations
6. Made data flow more explicit with clear pipeline stages

Key Changes:
- Replaced state machine with a simple flag register
- Used combinational logic for output generation
- Kept same reset behavior
- Maintained identical functionality while reducing control complexity
- Improved readability with direct assignments
