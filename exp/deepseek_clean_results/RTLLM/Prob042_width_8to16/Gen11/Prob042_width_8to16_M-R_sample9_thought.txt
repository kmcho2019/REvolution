Refactored Design Strategy:
1. Simplified state machine to a single-bit flag (reduces state encoding complexity)
2. Separated data path from control logic for clearer structure
3. Used continuous assignments for outputs when possible
4. Maintained identical functionality and timing behavior
5. Improved readability with explicit intermediate signals
6. Kept same reset behavior and output generation timing

Key Improvements:
- Single-bit state reduces synthesis complexity
- Clear separation between data storage and control
- Output assignments are more explicit
- Same cycle behavior as original
- More straightforward to synthesize and verify
