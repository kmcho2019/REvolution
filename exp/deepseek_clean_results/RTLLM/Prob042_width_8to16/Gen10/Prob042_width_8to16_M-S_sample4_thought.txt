Simplified Design Strategy:
1. Use a single buffer register to store the first byte
2. Generate outputs directly from sequential logic without intermediate wires
3. Combine control logic into a single always block
4. Maintain same functionality with minimal state tracking
5. Use non-blocking assignments for all register updates
6. Keep same reset behavior and data ordering

- Removed separate combinational logic for outputs
- Reduced to just one control flag (has_first_byte)
- Directly assign outputs in sequential block
- Simplified data flow with clearer timing
- Maintained same cycle-accurate behavior
