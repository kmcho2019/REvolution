Refactored Design Strategy:
1. Use explicit state machine with two states (IDLE, GOT_FIRST_BYTE) for clearer control flow
2. Separate combinational and sequential logic blocks
3. Use continuous assignments for outputs where possible
4. Implement next-state logic separately from state storage
5. Maintain same functionality but with more modular structure

Key Improvements:
- Clear state machine makes behavior more explicit
- Separation of combinational and sequential logic improves synthesis
- Continuous assignments simplify output generation
- Easier to extend for additional features if needed
- More maintainable structure while keeping same core functionality
