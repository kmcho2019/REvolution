Simplified and more reliable approach:

2. Eliminate dependency on specific data values for state tracking
3. Clear state management:
   - Reset clears all registers
   - First valid input stores data and sets flag
   - Second valid input concatenates and outputs
   - Output is always generated one cycle after second input
4. Simplified control logic with clear state transitions
5. More reliable for synthesis as it doesn't depend on data values
