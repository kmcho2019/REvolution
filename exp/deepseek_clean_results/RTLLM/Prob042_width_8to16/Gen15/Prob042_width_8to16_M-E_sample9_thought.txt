State Machine Approach:
1. Use a finite state machine to explicitly track the data collection state
2. Two states: WAIT_FIRST (waiting for first byte) and WAIT_SECOND (waiting for second byte)
3. First valid input transitions to WAIT_SECOND and stores the byte
4. Second valid input generates output and returns to WAIT_FIRST
5. Output registers are updated combinatorially based on current state
6. Clear state machine reset behavior

Key Advantages:
- Explicit state tracking makes the logic very clear
- Easier to verify correct behavior through state transitions
- Naturally handles non-consecutive valid inputs
- Output timing precisely matches specification
- Simple to extend for error cases or additional features
