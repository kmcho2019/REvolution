Here's a refactored solution using explicit state tracking and proper data handling:

1. We'll use a simple state machine with two states: WAIT_FIRST (waiting for first byte) and WAIT_SECOND (waiting for second byte)
2. First valid byte is stored in a register when in WAIT_FIRST state
3. When second byte arrives in WAIT_SECOND state, we concatenate the stored byte (MSB) with new byte (LSB)
4. Output valid is asserted only when two bytes are collected
5. Reset properly clears all registers and returns to initial state

Key improvements:
- Clear state machine makes behavior explicit
- Proper handling of byte ordering (first byte becomes MSB)
- No shift operations needed - direct storage and concatenation
- Easier to verify timing and functionality
- More robust handling of non-consecutive valid signals
