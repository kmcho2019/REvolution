Novel Architectural Approach:
1. Shift-register based implementation for sequential data capture
2. Two-phase operation: capture and output generation
3. Uses a single storage register and a ready flag for simpler control
4. Implements a clean handshake between input and output domains
5. Reset clears all registers completely
6. Output is generated only after two valid inputs are captured
7. First input always goes to MSB, second to LSB of output

Key Innovations:
- Single storage register reduces area compared to ping-pong buffers
- Explicit ready flag ensures correct output timing
- Simple state machine with clear transitions
- Guaranteed correct data ordering (first in = MSB)
- Minimal control logic for better timing
