Refactored Approach:
1. Simplify state machine to only track if we have the first byte or not (single bit flag)
2. Use continuous assignments for outputs where possible
3. Combine data path and control logic more tightly
4. Eliminate redundant registers (stage1_valid not needed)
5. Make valid_out purely combinational based on current state
6. Use clearer naming for intermediate signals

Key Improvements:
- Reduced state complexity (binary flag instead of 3 states)
- More direct data path with clear timing
- Combinational valid_out simplifies timing analysis
- Fewer registers reduces area
- Same functionality with simpler implementation
