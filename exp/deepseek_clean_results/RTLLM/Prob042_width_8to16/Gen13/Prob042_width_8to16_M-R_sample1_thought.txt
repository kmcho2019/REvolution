Refactored Design Strategy:
1. Replace enum-based state machine with explicit parameter definitions for better synthesis compatibility
2. Use separate always blocks for sequential and combinational logic (3-process FSM style)
3. Simplify output generation by directly assigning to registers
4. Make state transitions more explicit with dedicated next state logic
5. Maintain identical functionality while improving synthesis friendliness

Key Improvements:
- Explicit state encoding improves synthesis results
- Clear separation of state transition logic and output generation
- Reduced complexity in output assignments
- Maintains same cycle behavior with clearer state machine structure
- Better synthesis tool compatibility with parameter-based states
