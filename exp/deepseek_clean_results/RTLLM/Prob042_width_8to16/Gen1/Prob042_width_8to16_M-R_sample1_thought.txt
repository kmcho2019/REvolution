The refactored design will:
1. Use a purely synchronous reset for better synthesis compatibility
2. Implement a simple state machine with explicit states (IDLE and HAVE_FIRST_HALF)
3. Use combinational logic for output generation to potentially reduce critical path
4. Separate the state transition logic from data path for clearer implementation
5. Maintain the same functionality while improving synthesis characteristics

Key improvements:
- Explicit state machine makes the design more readable and potentially more synthesis-friendly
- Synchronous-only reset improves timing closure
- Combinational output logic may reduce critical path
- Clear separation of control and data path
