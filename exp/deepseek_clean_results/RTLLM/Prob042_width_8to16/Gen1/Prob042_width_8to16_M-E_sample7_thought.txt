Novel approach using a shift register and state machine:
1. Instead of using a simple flag, implement a 2-state FSM (IDLE, COLLECTING)
2. Use a 16-bit shift register to accumulate data
3. In IDLE state, store first byte in upper 8 bits when valid_in arrives
4. In COLLECTING state, store second byte in lower 8 bits and output
5. This approach provides better scalability for future width conversions
6. Explicit state machine makes the design more robust and easier to debug
