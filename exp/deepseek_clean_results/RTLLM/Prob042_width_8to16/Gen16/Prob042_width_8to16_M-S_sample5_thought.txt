Simplified Design Approach:
1. Use a single register to store the first byte when it arrives
2. Use a flag to indicate when we're waiting for the second byte
3. Combine all logic into a single always block for clarity
4. Generate output only when both bytes are received
5. Clear the flag immediately after output generation to prepare for next pair
6. Reset all registers and flags on active-low reset

Key Improvements:
- Single always block reduces complexity
- Clear state transitions
- Minimal control logic
- Maintains all required functionality
- Easier to understand and verify
