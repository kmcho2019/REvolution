Simplified Approach:
1. Eliminate explicit state machine to reduce complexity
2. Use a single register to store the first byte and a flag to indicate we're waiting for the second byte
3. When first valid data arrives, store it and set the flag
4. When second valid arrives (with flag set), output concatenated data and clear flag
5. Output valid only when both bytes are received
6. Maintain same reset behavior

Key Simplifications:
- Removed enum and state machine logic
- Single flag replaces state tracking
- Same functionality with less code
- Clearer data flow
- Maintains all original requirements
