The design requires a state machine that:
1. Stores the first 8-bit input in a temporary register when valid_in is high
2. Waits for the second valid input to concatenate with the stored value
3. Outputs the 16-bit concatenated data and valid_out signal on the next clock edge
4. Resets all registers when rst_n is low
We'll use a flag to track whether we have the first byte stored, and only output when we have both bytes.
