The design requires a state machine that:
1. Stores the first 8-bit input in a temporary register when valid_in is high
2. Sets a flag to indicate we have the first half of data
3. When the next valid_in occurs, concatenates the stored value with new input to form 16-bit output
4. Outputs valid_out only when both halves are available
5. Clears everything on reset

We'll use:
- A data_lock register to store the first 8-bit value
- A flag register to track if we have the first half
- Synchronous reset behavior
- Output generation on the clock edge following the second valid input
