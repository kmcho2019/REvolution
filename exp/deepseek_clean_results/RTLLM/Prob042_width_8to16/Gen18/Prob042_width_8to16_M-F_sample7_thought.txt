Improved Design Approach:
1. Replace enum-based state encoding with explicit parameter definitions for better synthesis compatibility
2. Simplify state machine to only track if we have the first byte (no need for full FSM)
3. Use registered outputs for better timing characteristics
4. Clearer separation of combinational and sequential logic
5. More robust handling of reset conditions
6. Explicit handling of all edge cases including back-to-back inputs

Key Improvements:
- More synthesis-friendly state encoding
- Simplified control logic while maintaining functionality
- Better registered outputs for timing closure
- Clear reset behavior for all registers
- Explicit handling of all input scenarios
