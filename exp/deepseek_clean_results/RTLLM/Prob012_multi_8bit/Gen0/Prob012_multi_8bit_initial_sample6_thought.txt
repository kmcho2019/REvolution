The 8-bit multiplier will be implemented using the shift-and-add algorithm. Here's the thought process:
1. Initialize a 16-bit accumulator (product) to zero
2. Iterate through each bit of the multiplier (B)
3. For each bit, if it's set (1), add the multiplicand (A) shifted by the current bit position to the accumulator
4. The multiplicand is shifted left by 1 bit in each iteration to align with the current bit position
5. After processing all 8 bits, the accumulator contains the final product
6. The output is registered to ensure synchronous operation
