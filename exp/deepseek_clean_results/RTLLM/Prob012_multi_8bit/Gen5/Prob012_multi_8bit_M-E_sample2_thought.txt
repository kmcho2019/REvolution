This implementation uses Radix-4 Modified Booth Encoding to:
1. Reduce the number of partial products by half (from 8 to 4)
2. Encode the multiplier (B) to select among 0, ±A, ±2A operations
3. Use sign extension handling for negative multiples
4. Implement a carry-save adder tree for efficient partial product summation

Key advantages:
- Fewer partial products mean smaller adder tree and better timing
- Radix-4 encoding provides inherent power savings
- Symmetric design handles both positive and negative numbers gracefully
- More efficient than basic shift-and-add for ASIC implementations
