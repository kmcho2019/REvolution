To optimize the PPA metrics, I'll implement a sequential shift-and-add multiplier that:
1. Uses a single adder and accumulator to reduce area
2. Implements clock gating to reduce power when B bits are zero
3. Processes bits sequentially to minimize switching activity
4. Uses a finite state machine for clean control flow

Key improvements:
- Sequential processing reduces area from 8 parallel adders to 1
- Clock gating on zero multiplier bits saves power
- State machine ensures clean operation with minimal control logic
- Maintains same functionality while improving PPA
