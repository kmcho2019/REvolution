This solution implements the multiplication using a sequential shift-and-add approach with an FSM controller. The key innovations are:
1. Uses a 4-state FSM to control the multiplication process (IDLE, CHECK, ADD, SHIFT)
2. Processes one multiplier bit per cycle, reducing combinational path
3. Accumulates the result in a 16-bit register
4. Shifts the multiplicand left each cycle (like pencil-and-paper multiplication)
5. Uses a bit counter to track progress through the multiplier bits
6. Fully synchronous design with proper reset handling

Advantages:
- Lower combinational complexity than parallel implementation
- Better timing closure potential
- More power-efficient as it only activates necessary logic each cycle
- Easier to pipeline if needed
- Clear separation of control and datapath
