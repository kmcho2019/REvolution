I'll implement an 8-bit multiplier using a sequential shift-and-add approach with FSM control. This design:
1. Uses a single 16-bit accumulator and 8-bit shift register
2. Implements a 4-state FSM to control the multiplication process
3. Processes one multiplier bit per clock cycle
4. Eliminates combinational adder trees by using sequential accumulation
5. Reduces area by reusing the same adder for all partial products
6. Offers better power efficiency through clock gating opportunities

Key innovations:
- State machine controlled datapath
- Single-cycle per bit processing
- Resource sharing of adder hardware
- Explicit shift-and-add algorithm in hardware
- Pipelining potential for higher throughput
