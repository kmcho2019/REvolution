Novel Architectural Idea: Bit-Serial Multiplication with Early Termination
1. Instead of processing all bits in parallel, we'll process them sequentially (LSB first) to save area and power.
2. Key innovation: Early termination when remaining multiplier bits are all zero.
3. Each cycle:
   - If current B bit is 1, add shifted A to accumulator
   - Shift A left for next potential addition
   - Shift B right to examine next bit
4. Uses a state machine to control the sequential process
5. Benefits:
   - Lower power (only active when needed)
   - Smaller area (reuses same adder)
   - Early termination optimization
   - Scalable to any bit width
