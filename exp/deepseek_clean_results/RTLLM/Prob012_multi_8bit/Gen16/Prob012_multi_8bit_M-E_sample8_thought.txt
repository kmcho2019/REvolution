Here's a novel approach using a binary tree of adders with dynamic partial product selection:

1. Instead of generating all partial products upfront, we'll generate them on-demand during the accumulation phase
2. Use a binary tree structure where each node is a conditional adder that:
   - Selects either a shifted version of A or zero based on the current B bit
   - Accumulates the result from previous stages
3. The tree structure naturally handles the shifting by passing appropriately shifted versions of A down the tree
4. Each level of the tree corresponds to a bit position in B
5. This approach minimizes intermediate storage and reduces dynamic power by only activating adders when needed

Key advantages:
- No need for explicit partial product storage
- Shifting is handled implicitly by the tree structure
- Only active adders consume power
- Naturally scalable to larger bit widths
