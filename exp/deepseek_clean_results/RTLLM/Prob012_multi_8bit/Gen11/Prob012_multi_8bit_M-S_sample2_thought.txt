To simplify the 8-bit multiplier while maintaining the shift-and-add algorithm, we'll:
1. Use a single always block with a for-loop to iterate through each bit of B
2. Accumulate the product by conditionally adding shifted versions of A
3. Eliminate the need for multiple partial product wires
4. Reduce the explicit hardware mapping while keeping the same functionality

Key simplifications:
- Single procedural block instead of parallel assignments
- Loop-based implementation reduces code duplication
- Maintains same shift-and-add algorithm but with cleaner code
- Still produces correct 16-bit product
