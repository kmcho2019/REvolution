Refactoring Strategy:
1. Shift-and-Add Implementation: Maintain the same core algorithm but implement it using a more explicit shift-and-add approach with a single always block.
2. Sequential Processing: Process each bit of B sequentially in a loop-like fashion using an always block with blocking assignments.
3. Resource Efficiency: Use a single accumulator register (product_reg) to store intermediate results, reducing the need for multiple partial product wires.
4. Clear Data Flow: Make the shifting and adding operations more visually apparent in the code structure.

Key Changes:
- Replace parallel partial product generation with sequential processing
- Use blocking assignments in always block to simulate sequential behavior
- Eliminate CSA reduction stages in favor of direct accumulation
- Maintain same interface and functionality but with clearer data flow
