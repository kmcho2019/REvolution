Refactoring Strategy:
1. Maintain identical Johnson counter behavior (shift right with MSB set based on LSB)
2. Replace procedural always block with continuous assignment for combinational logic
3. Use a separate register process for sequential elements
4. Split the logic into:
   - Combinational next-state calculation (using assign)
   - Sequential state update (using always block)
5. Benefits:
   - Clear separation of combinational and sequential logic
   - Potential for better synthesis optimization
   - More explicit data flow
   - Maintains same functionality while being more modular
