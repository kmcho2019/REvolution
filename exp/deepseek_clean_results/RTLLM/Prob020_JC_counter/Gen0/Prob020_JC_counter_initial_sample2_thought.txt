A Johnson counter is a type of ring counter where the inverted output of the last flip-flop is fed back to the input of the first flip-flop. For a 64-bit Johnson counter, we need to implement the following behavior:
1. On reset (rst_n low), clear all bits to 0
2. On each clock edge:
   - If Q[0] is 0 (counting up phase): shift right and insert 1 at MSB
   - If Q[0] is 1 (counting down phase): shift right and insert 0 at MSB
3. The counter will cycle through all states similar to the 4-bit example but extended to 64 bits
