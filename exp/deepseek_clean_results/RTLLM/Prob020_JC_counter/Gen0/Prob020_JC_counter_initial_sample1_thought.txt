The Johnson counter is a type of shift register where the inverted output of the last stage is fed back to the input of the first stage. For a 64-bit Johnson counter:
1. On reset (rst_n low), all bits are cleared to 0.
2. During normal operation (rst_n high):
   - If Q[0] is 0 (counter is in "increment" phase), we right-shift and set MSB to 1
   - If Q[0] is 1 (counter is in "decrement" phase), we right-shift and set MSB to 0
3. The counter will cycle through all states from all 0s to all 1s and back (128 states total for 64 bits)
