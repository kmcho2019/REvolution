To implement a 64-bit Johnson counter:
1. The counter operates synchronously with the clock (clk) and asynchronously resets when rst_n is low.
2. On reset, Q is cleared to all zeros.
3. During normal operation:
   - If Q[0] is 0, we right-shift Q and set the MSB to 1 (increment phase)
   - If Q[0] is 1, we right-shift Q and set the MSB to 0 (decrement phase)
4. This creates the characteristic "torsional" pattern of the Johnson counter.
