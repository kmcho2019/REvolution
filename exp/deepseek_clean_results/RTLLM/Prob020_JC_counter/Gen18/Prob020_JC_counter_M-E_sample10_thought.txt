Novel Architectural Idea: Pipelined Johnson Counter with Parallel State Generation

Key Innovations:
1. Parallel State Calculation: Instead of a simple shift operation, we pre-calculate all possible next states in parallel using combinational logic
2. Two-Stage Pipeline: Separates the state calculation from the register update to improve timing
3. Early Reset Propagation: Uses a dedicated reset path for faster initialization
4. State Prediction: Implements a lookahead mechanism that anticipates the next MSB value
5. Power Gating: Adds conditional enable logic to reduce dynamic power during stable states

Advantages:
- Better timing due to pipelining (critical path split into two stages)
- Potential power savings from conditional updates
- Maintains same functional behavior as original specification
- Scalable to larger bit widths with consistent performance
