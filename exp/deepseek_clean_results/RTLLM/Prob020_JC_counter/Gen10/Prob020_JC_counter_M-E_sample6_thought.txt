Novel Architecture: Parallel Pre-computation Johnson Counter
1. Key Idea: Instead of the traditional serial shift approach, pre-compute both possible next states (for Q[0]=0 and Q[0]=1) in parallel, then select the correct one using a multiplexer. This reduces the critical path by eliminating the feedback dependency.
2. Performance Benefit: The next state computation happens in parallel rather than waiting for Q[0] to propagate through the inversion logic.
3. Power Optimization: The parallel computation is done only once per cycle and the mux selection is simple.
4. Area Trade-off: Uses slightly more combinational logic but improves timing significantly.
5. Reset Strategy: Maintains synchronous active-low reset for consistent initialization.
