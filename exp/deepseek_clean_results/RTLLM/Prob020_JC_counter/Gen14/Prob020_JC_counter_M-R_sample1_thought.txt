Refactoring Strategy:
1. Replace the always block with continuous assignments for combinational logic
2. Use a separate register block for sequential elements
3. Split the Johnson counter logic into two parts:
   - Next state calculation (combinational)
   - State register (sequential)
4. This separation makes the design more modular and potentially easier to optimize during synthesis
5. The functionality remains identical to the original implementation

Key Changes:
- Combinational part uses assign statements
- Sequential part uses a simple always block
- Explicit separation of combinational and sequential logic
- Same reset behavior and Johnson counter operation
