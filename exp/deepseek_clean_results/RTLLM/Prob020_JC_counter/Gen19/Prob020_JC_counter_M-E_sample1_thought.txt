Novel Architectural Idea: Pipelined Johnson Counter with Parallel State Generation

Key Innovations:
1. Two-stage pipeline to improve timing performance
   - Stage 1: Calculate next state conditionally
   - Stage 2: Register the next state
2. Parallel state generation using bitwise operations instead of sequential shifts
3. Early reset propagation to both pipeline stages
4. Explicit state machine for direction control (forward/reverse counting)
5. Optimized for high-frequency operation while maintaining Johnson counter behavior

Advantages:
- Better timing closure due to pipeline
- Parallel computation reduces critical path
- Clear separation of combinational and sequential logic
- Scalable to larger bit widths
- Maintains same functional behavior as original
