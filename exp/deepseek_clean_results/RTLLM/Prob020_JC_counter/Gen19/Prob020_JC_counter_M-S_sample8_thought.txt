The original implementation is already highly optimized for a Johnson counter. The key simplifications we can make are:
1. Remove the explicit reset condition check by using a ternary operator
2. Combine the shift and inversion into a single concatenation operation
3. Maintain the same functionality with fewer lines of code

The resulting code will be functionally identical but slightly more concise. The Johnson counter behavior remains:
- On reset: clear all bits
- Normal operation: circular shift with inversion of the LSB becoming the new MSB
