Novel Architectural Idea: Parallel Segment Johnson Counter
1. Instead of a single 64-bit shift register, divide into 8 parallel 8-bit Johnson counters
2. Each segment operates independently but synchronized by common clock/reset
3. Benefits:
   - Reduced critical path length (only 8-bit shifts instead of 64)
   - Potential for better timing closure
   - Enables partial updates if needed in future extensions
4. Maintains same external behavior as monolithic version
5. Uses generate block for scalable implementation
6. Final output is concatenation of all segment outputs
