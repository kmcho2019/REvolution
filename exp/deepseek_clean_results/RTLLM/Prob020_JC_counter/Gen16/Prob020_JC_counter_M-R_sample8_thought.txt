Refactoring Strategy:
1. Replace the always block with continuous assignments for combinational logic
2. Use a separate register block for sequential elements
3. Split the functionality into:
   - Combinational next-state logic (using assign)
   - Sequential state register update
4. Maintain same Johnson counter behavior but with clearer separation of concerns
5. Keep parameterization for flexibility

Key Benefits:
- Clear separation between combinational and sequential logic
- Easier to add additional combinational logic if needed
- More explicit data flow representation
- Maintains same PPA characteristics while improving modularity
