Refactoring Strategy:
1. Replace the always block with continuous assignments for combinational logic
2. Use a separate register with clocked always block for sequential elements
3. Split the logic into clear combinational and sequential sections
4. Maintain the same functionality but with improved modularity
5. Use non-blocking assignments for the sequential part to follow good coding practices

The key insight is that the Johnson counter can be decomposed into:
- Combinational logic that calculates the next state (next_Q)
- Sequential logic that updates the state on clock edges
This separation makes the design more modular and easier to understand, while maintaining identical functionality.
