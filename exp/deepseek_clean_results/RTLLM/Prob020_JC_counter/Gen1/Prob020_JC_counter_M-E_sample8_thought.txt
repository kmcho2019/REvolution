Here's a novel approach using a parallel load technique with pattern generation:
1. Instead of sequential shifting, we'll use parallel loading for faster state transitions
2. We'll maintain two pattern registers:
   - up_pattern: Precomputed pattern for counting up (1 followed by 0s)
   - down_pattern: Precomputed pattern for counting down (0 followed by 1s)
3. On each clock cycle:
   - For counting up: Load the up_pattern shifted right by the current count
   - For counting down: Load the down_pattern shifted left by the current count
4. This reduces the critical path by eliminating the long shift chain
5. Reset initializes to all zeros as before

The key innovation is using parallel pattern loading instead of sequential shifting, which improves timing at the cost of slightly more area for the pattern registers.
