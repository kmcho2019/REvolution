To refactor the Johnson counter implementation while maintaining the same functionality, we'll make these changes:
1. Separate the combinational next-state logic from the sequential state storage
2. Use an `assign` statement for the next-state logic instead of embedding it in the always block
3. Keep the reset handling in the sequential block
4. This approach makes the design more modular and potentially easier to optimize during synthesis

The key benefits are:
- Clear separation of combinational and sequential logic
- More explicit data flow
- Potential for better synthesis optimization
- Same Johnson counter behavior (right-shift with MSB complement)
