Refactoring approach:
1. Replace the always block with continuous assignments for combinational logic
2. Use a wire for the next state calculation
3. Keep the sequential part (register update) in a separate always block
4. This separates combinational and sequential logic clearly
5. The functionality remains identical but the structure is more modular

- Register update remains synchronous
