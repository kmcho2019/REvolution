To simplify the 64-bit Johnson counter implementation while maintaining functionality:
1. Remove redundant conditional checks by using a single ternary operation for the MSB value
2. Combine the shift and MSB assignment into one operation
3. Maintain the same reset behavior (active-low synchronous reset)
4. The simplified logic will:
   - Reset to all 0s when rst_n is low
   - Otherwise perform a right shift and set MSB to ~Q[0] (inverted LSB)
This reduces the control logic while preserving the exact same functionality.
