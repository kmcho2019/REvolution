Refactoring Strategy:
1. State Representation: Replace explicit state machine with a 2-bit counter for simpler implementation
2. Shift Operation: Use bit selection instead of shift register to reduce logic complexity
3. Output Generation: Maintain same valid_out behavior but implement with combinational logic
4. Clocked Logic: Keep only the essential sequential elements (counter and data latch)

Key Improvements:
- Simpler state tracking using just a counter
- Eliminates shift register in favor of direct bit selection
- Reduces sequential elements while maintaining same functionality
- More straightforward timing paths
