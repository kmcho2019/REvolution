Simplification Strategy:
1. Remove explicit cycle counter by using the shift register itself as state indicator
2. Use a single 4-bit shift register to store data and track position
3. Generate valid_out when the shift register is fully loaded (all bits shifted out)
4. Output always comes from MSB of shift register
5. Reset initializes shift register to 0 (invalid state)

Key Simplifications:
- Eliminate separate cycle counter by using shift register state
- Reduce control logic by making valid_out simply indicate when new data is loaded
- Maintain same functionality with fewer registers and simpler control
- Shift operation becomes simpler rotation without zero padding
