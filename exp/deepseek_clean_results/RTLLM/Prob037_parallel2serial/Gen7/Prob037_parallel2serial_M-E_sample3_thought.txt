My novel approach uses a finite state machine (FSM) with four states to eliminate the need for a counter. Each state represents which bit is currently being output:
1. STATE_MSB: Output MSB (d[3]) with valid_out=1
2. STATE_B2: Output bit 2 (d[2]) with valid_out=0
3. STATE_B1: Output bit 1 (d[1]) with valid_out=0
4. STATE_LSB: Output LSB (d[0]) with valid_out=0

The FSM transitions sequentially through these states. When in STATE_LSB, it loads new data on the next cycle and returns to STATE_MSB. This approach:
- Eliminates the counter completely
- Makes the bit selection purely state-based
- Clearly shows the timing relationship between states
- Potentially reduces logic complexity by removing arithmetic operations
