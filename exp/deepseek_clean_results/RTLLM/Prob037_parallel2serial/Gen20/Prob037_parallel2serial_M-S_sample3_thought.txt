Simplification Strategy:
1. Remove explicit cycle counter by using shift register's position as implicit state
2. Use single 4-bit shift register for both data storage and state tracking
3. Generate valid_out when shift register is fully loaded (all bits shifted out)
4. Output always comes from MSB of shift register
5. Reset initializes shift register to 0

Key Improvements:
- Eliminates separate cycle counter
- Uses shift register's natural rotation as state machine
- Fewer registers and simpler control logic
- Same functionality with reduced complexity
