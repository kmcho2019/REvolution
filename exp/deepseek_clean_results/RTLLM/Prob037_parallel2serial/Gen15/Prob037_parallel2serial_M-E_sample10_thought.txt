Novel Architecture: Circular Buffer with Direct Bit Selection
1. Instead of shifting bits, maintain a circular buffer with a rotating pointer
2. Use a 2-bit counter to track current bit position (0-3)
3. Directly select the output bit using the counter as an index (d[3-cnt])
4. Load new data when counter wraps (cnt==3)
5. Generate valid_out combinatorially when counter is 0 (first bit)
6. Reset initializes counter to 0 and output to 0

Advantages:
- Eliminates shift operations, reducing power and improving timing
- Direct bit selection is more efficient than shifting
- Simple counter logic with clear state transitions
- Minimal hardware overhead (only 2-bit counter needed)
- Clean separation of control and data paths
