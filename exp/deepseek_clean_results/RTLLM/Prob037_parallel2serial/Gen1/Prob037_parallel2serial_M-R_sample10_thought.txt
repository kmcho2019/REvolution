The refactored design will:
1. Use a state machine approach instead of explicit counter
2. Implement the shift operation using pointer logic rather than physical shifting
3. Generate outputs using continuous assignments where possible
4. Optimize the valid_out generation to only toggle when needed
5. Reduce register updates by tracking position rather than shifting data

Key changes:
- Replace counter with state machine (4 states)
- Use pointer to select current bit instead of shifting
- Generate dout through continuous assignment
- Only update data register when loading new input
- Simplify valid_out logic
