Improvement Strategy:
1. Timing Optimization:
   - Replace binary counter with one-hot encoding (4 states) to simplify comparison logic
   - Eliminate the shift operation by directly selecting the current bit based on position
2. Power Optimization:

   - Simplify the data path to reduce switching activity
3. Area Optimization:
   - Replace 4-bit shift register with simple bit selection
   - Combine counter and state logic into a more compact representation

- Use one-hot state encoding (4 bits) instead of binary counter
