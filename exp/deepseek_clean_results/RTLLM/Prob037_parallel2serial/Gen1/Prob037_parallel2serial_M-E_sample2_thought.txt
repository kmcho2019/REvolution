Instead of using a traditional shift register approach, we'll implement a circular buffer technique with a pointer. The 4-bit input data is stored in a register, and we'll use a 2-bit pointer to select which bit to output. The pointer increments each cycle, wrapping around after 3. When the pointer wraps around, we load new data and assert valid_out. This approach eliminates the need for shifting operations and simply uses the pointer to directly access the current bit position.
