My novel approach uses a circular shift register combined with a state machine to eliminate the need for a separate counter. The key innovations are:
1. A 4-bit circular shift register that automatically wraps around after 4 shifts
2. A simple state machine with only two states (LOAD and SHIFT) to control the operation
3. Direct bit selection from the shift register without any multiplexers
4. Efficient valid signal generation that only toggles when needed

This approach reduces logic complexity by combining the shift and count operations into a single register, and minimizes control logic with the simple state machine. The circular shift behavior is achieved by feeding the LSB back to the MSB during shifting.
