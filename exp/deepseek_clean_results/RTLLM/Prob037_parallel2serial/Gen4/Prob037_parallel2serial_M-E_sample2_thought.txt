Novel Architecture Idea:
1. Instead of a traditional counter, use a 4-bit circular shift register with a single '1' (one-hot encoding)
2. The position of the '1' indicates which bit is currently being output
3. This eliminates the need for explicit comparison logic (cnt == 2'b11)
4. The shift register naturally wraps around, simplifying the control logic
5. Combine the data storage and bit selection into a single operation by using the shift register as a mask

Key Benefits:
- Reduced critical path (no counter comparison needed)
- Simplified control logic (automatic wrap-around)
- More power efficient (only one bit toggles in the control register)
- Smaller area (eliminates separate counter logic)
