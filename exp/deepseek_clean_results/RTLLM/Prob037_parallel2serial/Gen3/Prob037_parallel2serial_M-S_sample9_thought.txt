Simplification Strategy:
1. Remove explicit state machine - Use a simple 2-bit counter instead since we only need to track 4 states (0-3)
2. Eliminate separate load signal - Counter naturally wraps around, so we can load new data when counter is 0
3. Simplify output logic - Directly use counter to index into data register
4. Maintain same functionality - Still outputs MSB first with valid signal on first bit
5. Reduce register usage - Only need counter and data register

Key improvements:
- Fewer comparisons (only checking for counter == 0)
- Simpler control logic
- Same number of registers but cleaner implementation
- Maintains all original functionality
