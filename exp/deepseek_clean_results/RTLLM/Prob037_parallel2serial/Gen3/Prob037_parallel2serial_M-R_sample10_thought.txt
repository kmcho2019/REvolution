Refactoring Strategy:
1. Replace the case-based bit selection with a shift register approach for simpler logic
2. Make valid_out a registered output for better timing closure
3. Use continuous assignments for clearer combinational logic
4. Simplify the counter logic by using a single always block
5. Maintain the same functionality but with more efficient implementation

Key Improvements:
- Shift register eliminates need for case statement, reducing area and power
- Registered valid_out improves timing predictability
- Clear separation of combinational and sequential logic
- More efficient bit selection through shifting
- Reduced switching activity by only updating necessary registers
