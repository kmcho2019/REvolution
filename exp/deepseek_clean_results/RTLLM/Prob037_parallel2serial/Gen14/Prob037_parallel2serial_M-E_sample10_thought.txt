Novel Architecture: Circular Buffer with Pointer Tracking
1. Instead of using a state machine or shift register, implement a circular buffer approach with a pointer to track the current bit position.
2. Store the parallel input in a 4-bit register and use a 2-bit pointer to select which bit to output.
3. The pointer increments circularly (0→1→2→3→0) and automatically wraps around.
4. When pointer wraps around (from 3 to 0), load new parallel data and assert valid_out.
5. Advantages:
   - Eliminates shift operations, reducing dynamic power
   - Simpler logic with direct bit selection
   - Clear relationship between pointer value and output bit position
   - Easily scalable to wider parallel inputs
