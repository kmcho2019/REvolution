The parallel-to-serial converter will work as follows:
1. On reset, all registers are cleared and outputs are set to 0
2. When new 4-bit parallel data arrives, it's loaded into a shift register
3. A 2-bit counter keeps track of which bit is being output (0-3)
4. Each clock cycle:
   - If counter is 3 (last bit), load new parallel data and reset counter
   - Otherwise, increment counter
5. The MSB of the shift register is always output
6. After loading new data, valid_out is high for one cycle
7. The shift register rotates left each cycle to bring next bit to MSB position
