The parallel-to-serial converter will use a 2-bit counter to track which bit is being output. When the counter reaches 3 (indicating we've output all 4 bits), we'll load new parallel data and reset the counter. The valid_out signal will be high only when we're outputting the first bit (MSB) of a new 4-bit word. The data register will shift left each cycle to present the next bit at the MSB position for output.
