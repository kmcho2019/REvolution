The parallel-to-serial converter needs to:
1. Store the 4-bit parallel input when a new conversion starts
2. Output bits MSB first over 4 clock cycles
3. Generate a valid_out signal only during the first cycle of each conversion
4. Handle reset to clear all registers
5. Use a counter to track which bit is being output

Implementation approach:
- Use a 3-bit counter (0-3) to track output position
- Store input in a 4-bit shift register
- On reset, clear counter and registers
- When counter reaches 3, latch new input and reset counter
- Output MSB of shift register and shift left each cycle
- valid_out is high only when counter is 0 (first cycle of conversion)
