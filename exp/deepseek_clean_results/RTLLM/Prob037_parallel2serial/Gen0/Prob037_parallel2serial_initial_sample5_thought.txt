The parallel-to-serial converter will work as follows:
1. On reset (rst_n=0), all registers are cleared
2. When new 4-bit parallel data arrives, we store it in a shift register
3. We use a 2-bit counter to track which bit we're outputting (0-3)
4. At each clock cycle:
   - If counter is 3 (last bit), we load new parallel data and reset counter
   - Otherwise, we increment counter
5. The serial output is always the MSB of the shift register
6. The valid_out signal is high only when counter=0 (first bit of new data)
7. After outputting each bit, we left-shift the register to bring next bit to MSB position
