Here's a novel approach using a circular shift register with dynamic bit selection:

1. Instead of a state machine, we'll use a circular shift register that rotates the input data
2. The MSB is always selected as output, eliminating the need for complex multiplexing
3. A single-bit valid signal is generated when new data is loaded
4. The design uses minimal registers and logic for better PPA:
   - Only 4-bit data register needed
   - Simple 2-bit counter for tracking position
   - No complex state decoding logic
5. Key advantages:
   - Reduced switching activity (only rotates when needed)
   - Simplified control logic
   - Natural MSB-first output without additional selection logic
   - Better timing due to simpler critical path
