Novel Architecture: Circular Buffer with Direct Bit Selection
1. Instead of using a shift register, implement a circular buffer that maintains all 4 bits in their original positions
2. Use a 2-bit pointer to directly select the current output bit (0-3) from the stored parallel data
3. The pointer increments circularly (0→1→2→3→0) and automatically loads new data when wrapping around
4. Valid_out is asserted when the pointer is at position 0 (MSB output)
5. Advantages:
   - No shifting means lower power consumption
   - Direct bit selection improves timing
   - Simple pointer logic reduces area
   - Clear separation between data storage and output selection
