To simplify the design while maintaining functionality:
1. Eliminate the case statement by using direct bit selection with the counter as index
2. Remove the default case since counter will never reach invalid states
3. Combine the valid_out generation with the counter reset condition
4. Use a single always block for all sequential logic
5. Maintain the same reset behavior but simplify the assignments
6. Output bits in MSB to LSB order by using [3-cnt] indexing
