Optimization Strategy:
1. One-Hot Counter: Replace binary counter with one-hot encoding to simplify comparison logic and improve timing
2. Shared Register: Combine input and shift register to reduce area by eliminating separate load logic
3. Static Valid Signal: Make valid_out static during shift cycles to reduce switching activity
4. Clock Gating: Add conditional shifting to reduce power consumption when not actively shifting
5. Terminal Count Detection: Simplify counter logic by using direct terminal count signal

Key Improvements:
- One-hot counter reduces critical path delay by eliminating binary comparison
- Shared register implementation saves area by reusing storage elements
- Static valid signal reduces power consumption
- Conditional shifting minimizes unnecessary toggles
- Maintains same functionality while improving all PPA metrics
