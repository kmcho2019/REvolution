Novel Architecture: Circular Buffer with Pointer Tracking
1. Instead of using a state machine or shift register, implement a circular buffer approach with a pointer
2. Use a 2-bit counter as a pointer to track current output bit position
3. Store input data in a register and directly select bits using the pointer
4. Reset pointer to 0 and load new data when pointer wraps around (reaches 3)
5. Valid_out is asserted only when new data is loaded (pointer=0)

Advantages:
- Eliminates shift operations, reducing dynamic power
- Simpler logic path with direct bit selection
- Clear relationship between pointer value and output bit
- Easier to scale for different parallel widths
