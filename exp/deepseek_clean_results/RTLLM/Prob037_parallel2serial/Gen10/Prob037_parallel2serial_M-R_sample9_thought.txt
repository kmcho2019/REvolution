Refactoring Strategy:
1. Replace Gray code counter with simple binary counter for better timing and area efficiency
2. Use direct bit selection from shift register instead of shifting operation to improve timing
3. Implement counter and shift register updates using continuous assignments where possible
4. Simplify valid_out generation by directly comparing counter value
5. Maintain same functionality while reducing complexity and improving PPA

Key Changes:
- Binary counter replaces Gray code counter (simpler, better timing)
- Shift register updates are now explicit assignments rather than shifts
- Continuous assignments used for next-state logic
- Valid_out generated directly from counter comparison
- Same MSB-first serialization behavior maintained
