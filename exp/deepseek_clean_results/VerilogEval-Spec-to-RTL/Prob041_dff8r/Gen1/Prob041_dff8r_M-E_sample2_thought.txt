Instead of using a single always block for all 8 bits, we'll:
1. Use a generate block to create 8 individual D flip-flops
2. Each DFF will be explicitly instantiated with its own bit
3. This approach allows for:
   - Easier individual control of each flip-flop
   - Potential for adding per-bit features later
   - Clearer representation of the hardware structure
4. Still maintains synchronous reset functionality
