Instead of using a single always block for all 8 flip-flops, we can implement them individually using generate blocks. This approach:
1. Provides more explicit structural representation of the 8 flip-flops
2. Allows for potential individual control of each flip-flop in future extensions
3. Uses a for-loop generate construct to efficiently instantiate the 8 DFFs
4. Maintains synchronous reset functionality for each flip-flop
5. Still operates on the positive clock edge as required
