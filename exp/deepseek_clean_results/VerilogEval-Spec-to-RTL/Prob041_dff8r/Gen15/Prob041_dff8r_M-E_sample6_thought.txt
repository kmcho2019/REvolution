Here's a novel approach using a shift register implementation with synchronous reset. Instead of using standard DFFs, we'll implement the 8-bit register as a circular shift register that can also operate in parallel load mode. This provides:

1. Built-in testability: The circular shift mode can be used for scan chain testing
2. Flexibility: Can function as either a parallel register or shift register
3. Power optimization: Reduced switching activity when in shift mode
4. Area efficiency: Uses the same flip-flops for both parallel and serial operation

The design includes:
- A control signal to switch between parallel load and shift modes
- Synchronous reset that clears all bits
- All operations synchronized to positive clock edge
- Option to enable scan chain testing via shift mode
