Novel Approach: Distributed Reset Control
1. Instead of a centralized reset implementation, distribute the reset logic to each individual flip-flop
2. Use a hierarchical design with individual DFF cells controlled by a common reset signal
3. Implement each flip-flop as a separate instance for maximum flexibility in placement and routing
4. Use explicit instantiation rather than arrays for better synthesis control
5. Add optional scan chain capability for testability (commented out by default)
6. Maintain synchronous reset functionality while optimizing for clock-to-q delay

Key Advantages:
- Better physical design flexibility
- Potential for improved clock-to-q timing
- Clear separation of reset logic
- Easier to add DFT features
- More transparent to synthesis tools
