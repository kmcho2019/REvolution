Instead of using parallel DFFs, I'll implement this as a circular shift register that:
1. Uses a single 8-bit register with feedback
2. Implements synchronous reset by clearing all bits
3. Rotates the data on each clock edge when not reset
4. The output is taken from the parallel bits of the register
5. This approach demonstrates an alternative sequential implementation
6. While functionally equivalent, it shows a different architectural perspective
7. The reset clears all bits synchronously as required
8. The design remains parameterized for flexibility
