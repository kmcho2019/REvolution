To implement the TopModule with 8 D flip-flops, we'll create a module that instantiates 8 individual DFFs. Each DFF will:
1. Be triggered on the positive edge of clk
2. Have a synchronous reset (active high) that sets the output to 0
3. Pass the input d[i] to output q[i] when not in reset
The 8-bit input d will be connected to each DFF input, and the 8-bit output q will collect all DFF outputs.
