The task requires implementing an 8-bit register using D flip-flops with synchronous reset. Each of the 8 bits will have its own D flip-flop that:
1. Captures the input 'd' bit on the positive edge of 'clk'
2. Synchronously resets to 0 when 'reset' is high (also on positive edge of 'clk')
3. Outputs the stored value on 'q'
We'll implement this as a simple 8-bit register with synchronous reset functionality.
