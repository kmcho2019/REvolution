To implement the TopModule, we'll create 8 D flip-flops (one for each bit of the input/output) that all share the same clock and reset signals. Each flip-flop will:
1. Be triggered on the positive edge of clk
2. Have a synchronous reset (active high) that sets the output to 0
3. Otherwise pass the input d bit to the output q bit
We'll implement this as a simple register with synchronous reset functionality.
