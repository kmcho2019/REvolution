The task requires implementing an 8-bit register using D flip-flops with synchronous reset. Each of the 8 flip-flops will:
1. Be clocked on the positive edge of 'clk'
2. Have a synchronous reset (active high) that clears the output to 0
3. Pass the input 'd' bits to corresponding output 'q' bits when not in reset
We'll implement this as a simple 8-bit register with synchronous reset functionality.
