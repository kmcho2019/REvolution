Here's a novel approach using a shift-register style implementation with individual flip-flop control:
1. Instead of a single 8-bit register, implement as 8 chained 1-bit flip-flops
2. Each flip-flop has its own enable signal controlled by a circular shift register
3. The shift register rotates on each clock cycle, enabling one flip-flop at a time
4. This creates a "time-multiplexed" update mechanism that can save power
5. Maintains synchronous reset functionality for all bits
6. Still provides the same functional behavior as a standard 8-bit register
7. Potential power savings since only one flip-flop updates per cycle
