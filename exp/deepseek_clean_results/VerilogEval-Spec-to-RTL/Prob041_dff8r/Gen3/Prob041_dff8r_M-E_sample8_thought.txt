Here's a novel approach using a shift register implementation with synchronous reset:
1. Instead of directly mapping each bit, we'll implement the 8 DFFs as a circular shift register
2. On each clock cycle, the bits will rotate right by 1 position when not in reset
3. During reset, all bits will synchronously clear to 0
4. The input 'd' will be loaded in parallel when a special control signal is asserted (though in this simple version we'll just use it as direct input)
This creates a more interesting structure while still meeting requirements.
