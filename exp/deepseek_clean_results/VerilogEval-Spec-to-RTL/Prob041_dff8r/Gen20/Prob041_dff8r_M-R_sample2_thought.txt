Refactoring Approach:
1. Instead of using a single module with parameterized width, implement individual D flip-flops for each bit
2. Use direct instantiation of 8 DFF primitives (behavioral modeling)
3. Each DFF will have its own always block for clear separation
4. This makes the bit-level structure explicit while maintaining identical functionality
5. The approach is more verbose but shows the underlying flip-flop structure clearly

Key Changes:
- Remove parameterization and implement 8 explicit bits
- Each bit has its own always block for the DFF
- Reset logic is replicated per bit but synthesis will optimize
- Interface remains identical to original
