Innovative approach using a shift register architecture:
1. Instead of parallel DFFs, implement as a serial-in parallel-out shift register
2. Uses only one physical DFF that gets time-multiplexed for all 8 bits
3. Includes a 3-bit counter to track which bit is currently being processed
4. Reset synchronously clears both the shift register and counter
5. On each clock cycle:
   - During normal operation: shifts in one bit from input and updates corresponding output bit
   - During reset: clears all bits and resets counter
6. Advantages:
   - Reduced hardware (only 1 DFF instead of 8)
   - Lower power consumption
   - Novel approach that still meets timing requirements
   - Maintains same functional behavior from external perspective
