Refactoring Approach:
1. Instead of using an always block for the D flip-flop, implement it using continuous assignment with a ternary operator
2. Create an intermediate wire to hold the reset-muxed value before clocking
3. Use non-blocking assignment in a separate always block just for the clocked behavior
4. This separates the combinational logic (reset mux) from the sequential logic (clocked register)
5. The functionality remains identical but the structure is more explicit about the separation of combinational and sequential logic

Key Changes:
- Replace always block with assign for combinational part
- Explicit reset mux before the register
- Clear separation between combinational and sequential logic
- Maintain same parameterization and interface
