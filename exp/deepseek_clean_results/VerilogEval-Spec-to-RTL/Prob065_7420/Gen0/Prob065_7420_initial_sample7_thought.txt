The 7420 chip contains two independent 4-input NAND gates. We need to implement this functionality in Verilog:
1. First NAND gate takes p1a, p1b, p1c, p1d as inputs and outputs p1y
2. Second NAND gate takes p2a, p2b, p2c, p2d as inputs and outputs p2y
The output of each NAND gate is the logical NAND of all four inputs.
