Instead of implementing the NAND operations directly in the top module, we can create a reusable 4-input NAND submodule and instantiate it twice. This approach:
1. Promotes modular design and code reuse
2. Makes the design more scalable if we need to add more NAND gates later
3. Separates the gate functionality from the top-level wiring
4. Could allow for technology-specific implementations of the NAND gate in future
