The original solution uses a single concatenated assign statement, which is efficient but may not be the most readable for beginners. Let's refactor this to use individual assign statements for each output connection. This approach:

1. Makes each connection explicitly visible and self-documented
2. Maintains the same functionality and wire-like behavior
3. Improves readability and maintainability
4. Keeps the same optimal PPA characteristics since it's still just wire connections
5. Makes it easier to modify individual connections later if needed
