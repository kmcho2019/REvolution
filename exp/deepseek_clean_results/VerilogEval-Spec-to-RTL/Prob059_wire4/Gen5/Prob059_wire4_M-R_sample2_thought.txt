The original implementation uses an always block with procedural assignments, which is unnecessarily complex for this simple wiring task. We can simplify the design by:
1. Using continuous assignments (assign statements) instead of procedural blocks
2. Making all outputs simple wires instead of registers
3. Maintaining the exact same functionality (a->w, b->x, b->y, c->z)
4. Reducing overhead by eliminating the always block
5. Potentially improving PPA metrics by using simpler constructs
