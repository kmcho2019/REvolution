The original solution using an always block is functionally correct but not optimal for PPA. We can optimize it by:
1. Replacing the procedural always block with continuous assignments (assign statements)
2. Removing unnecessary reg declarations since we don't need storage
3. Using direct wire connections which are more efficient for simple wiring
4. This will reduce area and power by eliminating the procedural block overhead
5. Maintains identical functionality (a->w, b->x, b->y, c->z)
