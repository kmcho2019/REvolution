Let's implement this using a parameterized crossbar switch approach, where we can programmatically configure the connections. This demonstrates:

1. A configurable routing matrix that could be extended to more complex routing scenarios
2. The use of parameters to define connection patterns
3. A mux-based approach that could be expanded to support dynamic reconfiguration
4. While overkill for this simple problem, it shows how we might implement a more general solution

The crossbar uses a 2-bit configuration parameter for each output to select its input source. For our fixed connections, we hardcode these parameters.
