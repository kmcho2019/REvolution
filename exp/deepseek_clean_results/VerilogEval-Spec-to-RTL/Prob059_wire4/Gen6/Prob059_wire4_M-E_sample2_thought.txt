Here's a novel approach using a parameterized bit-vector approach to handle the connections:

1. Instead of individual assignments, we'll bundle all inputs into a 3-bit vector
2. Create a 4-bit output vector that represents all outputs
3. Use a concatenation pattern to map inputs to outputs
4. This approach demonstrates how to handle simple wiring using vector operations
5. The benefit is it shows a more scalable pattern for when there are many similar connections
6. The outputs are then unpacked from the output vector
7. This method could easily be extended to more inputs/outputs with similar patterns
