Here's a simplified approach that maintains the same functionality with fewer intermediate wires and operations:

1. Directly compare all inputs in a single expression using nested conditional operators
2. Eliminate intermediate wires by chaining comparisons
3. The logic remains functionally identical but with:
   - Fewer lines of code
   - No temporary storage wires
   - Same comparison logic compressed into one line
   - Still maintains the same two-level comparison structure (just expressed differently)
4. The synthesis result should be identical since modern tools will optimize both versions similarly
