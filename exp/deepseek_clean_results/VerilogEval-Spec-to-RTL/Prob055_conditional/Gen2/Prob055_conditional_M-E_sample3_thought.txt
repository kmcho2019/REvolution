Instead of using direct comparisons, we can implement a priority-based minimum finder that checks each bit position from MSB to LSB. For each bit position, we count how many numbers have a '0' at that bit. If exactly one number has '0', it must be the minimum. If multiple have '0', we narrow down to those candidates for the next bit. This approach may be more area-efficient for certain technologies and has a deterministic delay regardless of input values.
