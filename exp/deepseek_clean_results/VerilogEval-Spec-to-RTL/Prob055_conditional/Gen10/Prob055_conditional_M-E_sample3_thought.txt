Here's a novel approach using a parallel comparison tree with early termination:

1. Instead of hierarchical comparisons, perform all pairwise comparisons simultaneously in parallel
2. For each input, check if it's less than all other inputs using AND gates
3. Use multiplexers to select the input that satisfies all its comparison conditions
4. This approach:
   - Maximizes parallelism by doing all comparisons at once
   - Potentially reduces critical path since all comparisons happen in a single stage
   - Uses simple AND-OR logic that may synthesize efficiently
   - Maintains purely combinational behavior
   - Scales well with more inputs as the logic remains flat rather than hierarchical
