To maintain the same functionality while improving the structure, I'll implement a parallel comparison approach using nested conditional operators in a single assign statement. This achieves the same cascaded comparison logic but in a more compact form. The key benefits are:
1. Eliminates intermediate wires for cleaner code
2. Still maintains the same logical flow of comparisons (a/b → intermediate/c → intermediate/d)
3. Uses the same efficient comparison logic but expressed more concisely
4. Keeps the combinational nature of the design
