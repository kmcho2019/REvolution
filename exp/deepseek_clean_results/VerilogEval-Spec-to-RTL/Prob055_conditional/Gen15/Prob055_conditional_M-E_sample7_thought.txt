**Tournament-Style Minimum Finder Architecture**

1. **Key Idea**: Implement a tournament-style comparison network where inputs compete in pairwise matches, similar to a sports tournament bracket. This approach provides a balanced comparison structure with optimal timing characteristics.

2. **Implementation Strategy**:
   - Stage 1: Compare inputs in pairs (a vs b, c vs d)
   - Stage 2: Compare the winners from Stage 1
   - The final winner is the global minimum
   - Uses only 3 comparators arranged in a balanced tree structure

3. **Advantages**:
   - Fixed 2-level comparison depth regardless of input count (for 4 inputs)
   - Balanced critical path for better timing
   - No temporary registers or complex control logic
   - Easily scalable to more inputs by adding stages
   - Clear physical implementation with predictable routing

4. **Novel Features**:
   - Uses continuous assignment for combinational logic
   - No loops or procedural blocks
   - Pure structural implementation
   - Minimal hardware overhead
   - Deterministic propagation delay
