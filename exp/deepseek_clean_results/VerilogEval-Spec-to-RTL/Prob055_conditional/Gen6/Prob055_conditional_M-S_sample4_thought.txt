The original solution uses a two-level comparison tree which is efficient but can be simplified further. We can:
1. Use a single-level comparison by chaining ternary operators
2. This reduces the number of intermediate wires and makes the code more compact
3. The functionality remains identical as the comparisons are still done in parallel
4. The synthesis tool will still optimize the comparisons efficiently
5. This approach is more readable and concise while maintaining the same performance
