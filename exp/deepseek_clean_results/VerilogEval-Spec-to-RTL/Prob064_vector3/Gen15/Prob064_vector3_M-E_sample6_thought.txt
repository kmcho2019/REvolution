Here's a novel approach using a shift register implementation:
1. Instead of direct concatenation, we'll use a temporary 32-bit register
2. First, we'll concatenate all inputs into this register with proper padding
3. Then we'll extract the output vectors using bit-slicing
4. This approach demonstrates an alternative method that could be more flexible for future modifications
5. The shift register style makes it clear how the bits flow from inputs to outputs
6. The padding bits are explicitly added during the initial concatenation
