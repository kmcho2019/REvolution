Novel Approach: Bit-Sliced Distribution with Rotating Allocation
1. Instead of simple concatenation, distribute input bits across outputs using a rotating pattern
2. Each 5-bit input will contribute to multiple outputs in a balanced way
3. The padding bits will be distributed as well to maintain uniform output structure
4. This approach provides better signal distribution across outputs
5. The rotation pattern makes the design more resilient to localized bit errors

Implementation Details:
- Input bits are distributed in a 3-2-3 pattern across outputs
- Each 5-bit input is split into 3 bits for one output and 2 bits for the next
- The rotation continues across all inputs
- Padding bits are added at the end to fill remaining LSBs
- This creates a more balanced load across all output bits
