The refactored solution will maintain the same functionality but use a different structural approach:
1. Instead of a single concatenation and split assignment, we'll break it into two steps:
   - First create a 32-bit intermediate wire containing all inputs plus padding
   - Then assign each output by selecting the appropriate bits from this wire
2. This makes the bit selection more explicit and might be more readable for some cases
3. The approach still maintains optimal PPA characteristics since it's purely combinational
4. Added comments to clearly show the bit mapping for each output
