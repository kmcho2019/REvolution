Instead of direct concatenation, this solution:
1. Uses a temporary 32-bit register to accumulate all bits
2. Explicitly shifts and inserts each input vector into the register
3. Adds the padding bits at the end
4. Then distributes the bits to outputs using bit slicing
5. Benefits include:
   - More explicit control over bit placement
   - Easier to modify if bit ordering needs to change
   - Clear visualization of the data flow
   - Potential for pipelining if needed
