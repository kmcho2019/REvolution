Here's a novel approach using a shift register concept:
1. First, concatenate all inputs into a 30-bit temporary register
2. Add the two padding bits (1's) to create a 32-bit value
3. Then, use a barrel shifter approach to extract each 8-bit output by selecting different 8-bit windows from the 32-bit value
4. This method emphasizes the parallel extraction of output segments from a unified input representation
5. The approach showcases how to think about the problem as a data alignment/selection challenge rather than just concatenation
