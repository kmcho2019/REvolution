Instead of direct concatenation, we'll implement a bit-serial approach that:
1. Creates a 32-bit internal register by combining inputs and padding
2. Uses explicit bit selection for each output to demonstrate precise control
3. Shows an alternative way to think about the bit mapping
4. Makes the padding position very clear through separate assignment
5. Could be extended to support dynamic shifting operations in future versions

This approach demonstrates how the same functionality can be achieved through explicit bit manipulation rather than concatenation, which might be useful in more complex scenarios where bits need to be dynamically rearranged.
