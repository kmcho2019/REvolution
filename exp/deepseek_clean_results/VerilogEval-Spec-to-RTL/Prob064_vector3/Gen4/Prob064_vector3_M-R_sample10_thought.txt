The original implementation is already clean and efficient, but we can refactor it to:
1. Eliminate the intermediate wire declaration by performing the concatenation directly in the output assignments
2. Use a more compact form by combining the concatenation and padding in each output assignment
3. Maintain the same functionality while reducing the number of explicit declarations

This approach reduces the code footprint while keeping the same logical behavior. The synthesis result should be identical since modern tools will optimize both versions to the same netlist.
