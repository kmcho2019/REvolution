Here's a novel approach using a shift register concept:
1. First concatenate all inputs into a 30-bit temporary register
2. Add the two padding bits (2'b11) to make it 32 bits
3. Then treat the combined 32-bit value as a circular buffer
4. Extract the four 8-bit outputs by selecting different starting points in this buffer
5. This creates an interesting pattern where outputs overlap in a rotating fashion
6. The padding bits are automatically placed in z[1:0] due to the circular selection

Key advantages:
- Unique output pattern generation
- Potential for better resource sharing in some implementations
- Clear separation of concatenation and output generation phases
- Maintains all original requirements
