The refactored solution maintains the same core functionality but restructures the implementation to:
1. Use continuous assignments instead of procedural blocks for clearer combinational logic
2. Implement subtraction using two's complement arithmetic (a - b = a + ~b + 1)
3. Simplify the zero flag logic using a reduction NOR operation
4. Group related operations together for better readability

Key changes:
- Replaced the always block with direct assignments
- Combined the addition/subtraction into a single expression
- Used bitwise reduction for zero detection
- Eliminated the case statement in favor of conditional operator
