The core functionality remains the same (adder-subtractor with zero flag), but we'll refactor using these changes:

1. **Continuous Assignments**: Replace the always block with direct assign statements for combinational logic, which can be more readable for simple combinational circuits.
2. **Simplified Zero Flag**: Implement the zero flag using a NOR reduction operator directly in the assignment.
3. **Explicit Subtraction Logic**: Keep the two's complement subtraction approach but express it more directly in the assignment.

This refactoring maintains the same behavior while potentially improving readability and synthesis results. The continuous assignments may also lead to slightly better optimization in some synthesis tools.
