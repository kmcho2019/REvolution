The original solution uses an always block with reg outputs. We can refactor this to use continuous assignments (assign statements) instead. This approach:
1. Eliminates the need for reg declarations since we're using wire outputs
2. Makes the code more concise by using direct assignments
3. Maintains identical functionality while potentially improving readability
4. The zero detection remains a simple equality check against 0
5. The adder/subtractor selection still uses a ternary operator for compactness
