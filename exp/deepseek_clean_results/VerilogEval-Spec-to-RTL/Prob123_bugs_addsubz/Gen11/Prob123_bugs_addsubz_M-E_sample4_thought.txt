Here's a novel approach using a carry-select adder structure with early zero detection:

1. **Parallel Operation Calculation**:
   - Compute both addition and subtraction simultaneously in parallel
   - Use a multiplexer to select the correct result based on do_sub
   - This allows both operations to complete in parallel, potentially improving timing

2. **Early Zero Detection**:
   - Calculate zero flags for both operations in parallel with the arithmetic
   - Combine with the operation select to determine final zero flag
   - This eliminates the need for a separate comparator after the operation

3. **Power Optimization**:
   - The unused operation path can be power-gated in applications where do_sub is stable for long periods
   - Early zero detection reduces switching activity in the flag logic

4. **Advantages**:
   - More balanced timing path compared to conditional inversion approach
   - Zero detection happens in parallel with arithmetic
   - Clean separation of operation paths for better synthesis optimization
