The current solution can be simplified while maintaining correct functionality by:

1. Removing the intermediate wire for b_operand since it's only used once
2. Combining the conditional inversion and addition into a single expression
3. Keeping the simple zero detection logic
4. Using continuous assignments for all outputs (no need for reg types)
