This solution introduces a carry-save adder with speculative zero detection for improved performance:

1. **Parallel Arithmetic Paths**:
   - Maintain separate addition and subtraction paths in parallel
   - Use carry-save technique to reduce critical path delay
   - Select final result using do_sub as mux control

2. **Early Zero Prediction**:
   - Compute potential zero conditions for both operations simultaneously
   - Use bitwise equality comparison to predict zeros early
   - Combine with actual result to validate prediction

3. **Power Optimization**:
   - Only the selected arithmetic path's result propagates to output
   - Early prediction logic is simple and low-power
   - Uses minimal XOR gates for subtraction path

4. **Performance Benefits**:
   - Parallel paths reduce critical path compared to conditional inversion
   - Early zero detection overlaps with arithmetic operation
   - Carry-save structure enables faster addition
