The original solution uses a clever XOR-based approach for conditional inversion and a single adder with carry-in for subtraction. While efficient, we can improve readability and maintainability by:

1. Separating the arithmetic logic into distinct steps:
   - First create the properly inverted operand
   - Then perform the addition
   - Finally generate the zero flag

2. Using explicit continuous assignments for each operation instead of combining them into one line, making the logic flow clearer.

3. Maintaining the same efficient implementation (single adder, XOR inversion) but with better structural organization.

4. Keeping all the PPA advantages (same gate count, same critical path) while improving code clarity.

The refactored version will be functionally identical but more maintainable and easier to understand at first glance.
