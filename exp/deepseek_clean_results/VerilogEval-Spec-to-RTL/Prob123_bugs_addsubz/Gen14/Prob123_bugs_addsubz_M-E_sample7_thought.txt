Here's a novel approach using parallel computation and early zero detection:

1. **Parallel Computation**:
   - Compute both addition and subtraction simultaneously using dedicated paths
   - Select the correct result using a multiplexer
   - This eliminates the need for conditional inversion and carry-in logic

2. **Early Zero Detection**:
   - Check for zero condition in parallel with arithmetic operations
   - Use bitwise equality comparison on both potential results
   - Combine with operation selection to determine final zero flag

3. **Power Optimization**:
   - Only one arithmetic path is active per operation (addition or subtraction)
   - Zero detection logic is shared between both paths

4. **Performance Benefits**:
   - No carry chain dependency on operation selection
   - Zero detection happens in parallel with arithmetic
   - Clean separation of arithmetic and control logic

Key advantages:
- Potentially better timing as both paths are independent
- Clear physical implementation with separate arithmetic units
- Power savings from not computing unused inversion
- Early zero detection may help critical path
