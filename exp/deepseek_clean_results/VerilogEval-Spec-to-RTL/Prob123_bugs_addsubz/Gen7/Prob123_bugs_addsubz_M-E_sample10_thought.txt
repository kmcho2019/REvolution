Here's a novel approach using a carry-save adder structure with early zero detection:
1. Instead of using a conventional adder, implement a carry-save adder that processes addition and subtraction simultaneously
2. Use the do_sub signal to select between the two computed results
3. Implement early zero detection by checking if all sum bits would be zero before the final carry propagation
4. This approach can potentially reduce critical path delay by parallelizing operations

The key innovation is performing both operations in parallel and selecting the result, which may improve timing in some implementations. The early zero detection also provides the flag with minimal additional delay.
