Instead of computing the result and then checking for zero, we can:
1. Compute both possible results (sum and difference) in parallel
2. Select the correct result using do_sub as a mux select
3. Simultaneously compute zero flags for both operations
4. Combine the zero flags using the same select signal

Benefits:
- Parallel computation reduces critical path (sum and diff compute concurrently)
- Zero detection happens in parallel with arithmetic operations
- Single mux stage for final selection
- More efficient for timing-critical applications
- Maintains same functionality with potentially better performance
