2. out_any:
   - Set bit 0 to 0 (no right neighbor) 
   - For bits 99:1, perform OR between each bit and its right neighbor (in[99:1] | in[98:0])

3. out_different:

This implementation:
- Uses only simple bitwise operations (AND, OR, XOR)
- Requires no intermediate signals
- Maintains full functionality
