Instead of using pure combinational bitwise operations, we'll implement a shift-register based approach that:
1. Uses a single left-shift operation for all three outputs
2. Handles edge cases through conditional assignments in the shift
3. Reduces logic depth by reusing the shifted value for all three outputs
4. Implements wrap-around for out_different using circular shift

Key innovations:
- Single shift operation shared across all outputs
- Edge cases handled during shift rather than post-processing
- Circular shift for efficient wrap-around
- Reduced fan-out compared to parallel bitwise operations
