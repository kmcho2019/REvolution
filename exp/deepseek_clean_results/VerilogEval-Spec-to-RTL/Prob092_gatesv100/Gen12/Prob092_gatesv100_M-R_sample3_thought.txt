Refactoring Approach:
1. Maintain the same logical functionality while changing the implementation style
2. Replace direct bitwise operations with generate blocks for more explicit structural representation
3. Use for-loops within generate blocks to handle the bitwise operations
4. Keep the same edge case handling but make it more visible in the code structure
5. The wrap-around for out_different will be implemented using a temporary wire for clarity

Benefits:
- More scalable for larger bit widths
- Clearer separation of edge cases from the main logic
- Easier to modify individual bit operations if needed
- Maintains same PPA characteristics while being more maintainable
