An alternative approach is to implement the logic using a multiplexer-based architecture. We can observe that the output q depends on the combination of inputs c and d when either a or b is high. Specifically:
1. When a OR b is 0, q is always 0
2. When a OR b is 1, q follows the OR of c and d

This can be implemented using a 2:1 mux where:
- The select line is (a OR b)
- When select is 0, output is 0
- When select is 1, output is (c OR d)
