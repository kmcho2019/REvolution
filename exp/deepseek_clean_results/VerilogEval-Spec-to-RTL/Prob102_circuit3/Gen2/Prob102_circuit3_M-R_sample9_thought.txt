The original implementation uses a single continuous assignment with logical OR and AND operations. We can refactor this by breaking it down into intermediate signals that represent the OR operations separately, then combine them with an AND. This makes the logic more explicit and easier to modify if needed, while maintaining the same functionality.

The refactored version will:
1. Create wire 'ab_or' for (a OR b)
2. Create wire 'cd_or' for (c OR d)
3. Combine these with AND to produce q
