Refactoring Strategy: Using Bitwise Operators with Parentheses for Clarity
1. Maintain the same logical function (q = (a OR b) AND (c OR d))
2. Implement using bitwise OR and AND operators in a single continuous assignment
3. Use parentheses to explicitly show the order of operations for better readability
4. This approach keeps the implementation concise while making the logic structure visually clear
5. The functionality remains identical to the original solution
6. This style emphasizes the two-level logic structure (ORs followed by AND)
