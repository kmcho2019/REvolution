Here's a novel approach using a multiplexer-based implementation. Instead of using standard logic gates, we'll use a 4:1 mux where the select lines are combinations of a and b, and the data inputs are combinations of c and d. This provides an alternative implementation that might be more efficient in certain technologies or when integrated with surrounding mux-based logic.

The truth table shows q is true when:
1. (a=0, b=1) and (c=1 or d=1)
2. (a=1, b=0) and (c=1 or d=1)
3. (a=1, b=1) and (c=1 or d=1)

We can implement this by using a and b as select lines for a mux that chooses between different combinations of c and d.
