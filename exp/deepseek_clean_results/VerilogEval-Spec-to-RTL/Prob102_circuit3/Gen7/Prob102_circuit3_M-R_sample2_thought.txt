Refactoring Approach: Direct Logical Expression
1. The original solution uses nested ternary operators which are unnecessary for this simple logic.
2. We can simplify the implementation by directly expressing the logic as an AND of two OR operations.
3. This makes the code more readable and potentially more efficient in terms of PPA metrics.
4. The functionality remains identical: q is high only when (a OR b) AND (c OR d) are true.
5. This approach eliminates redundant conditional checks while maintaining the same truth table behavior.
