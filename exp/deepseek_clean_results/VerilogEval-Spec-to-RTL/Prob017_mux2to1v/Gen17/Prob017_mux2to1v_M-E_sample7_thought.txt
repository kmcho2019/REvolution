Here's a novel approach using bitwise operations instead of conditional statements:
1. We can use the sel signal to generate a 100-bit mask where all bits are either 0 (when sel=0) or 1 (when sel=1)
2. Then perform a bitwise AND between each input and the appropriate mask
3. Finally OR the results together to get the selected output
4. This approach demonstrates how mux functionality can be implemented purely with Boolean operations
5. It might offer better synthesis results in certain technologies or toolchains
