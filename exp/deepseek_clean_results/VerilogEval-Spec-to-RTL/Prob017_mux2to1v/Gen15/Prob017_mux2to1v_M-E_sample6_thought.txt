Here's a novel approach using hierarchical multiplexing with a tree structure:

1. Instead of a flat 100-bit mux, we'll implement a binary tree of smaller muxes
2. First level: 25 4-bit muxes (4x25=100 bits)
3. Second level: 5 5-bit muxes (5x5=25 control signals)
4. Final level: 1 mux to select between the 5 groups
5. This reduces fanout on the select signal and may improve timing in some technologies
6. The tree structure could potentially save power by localizing switching activity
7. The hierarchical approach might also allow for better placement in physical design
