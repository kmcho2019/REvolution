The core functionality remains the same (100-bit 2:1 mux), but we'll implement it using an always block with case statement instead of the ternary operator. This provides:
1. Alternative coding style that might be preferred in some coding guidelines
2. Potential for easier modification if additional selection cases are needed later
3. More explicit structure that could help with synthesis optimizations in some tools
The behavior is identical - sel=0 selects a, sel=1 selects b.
