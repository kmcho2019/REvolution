Here's a novel approach using bitwise operations and masking:
1. Instead of using a direct ternary operator, we'll create a mask based on the select signal
2. The mask will be all 0s when sel=0 and all 1s when sel=1 (100-bit wide)
3. We'll then use bitwise operations to combine inputs a and b based on the mask
4. The formula is: out = (a & ~mask) | (b & mask)
5. This approach demonstrates an alternative implementation that:
   - Shows how multiplexers can be built from fundamental logic operations
   - Might offer different synthesis optimization paths
   - Provides the same functionality but with a different structural representation
   - Could potentially have different PPA characteristics depending on the standard cell library
