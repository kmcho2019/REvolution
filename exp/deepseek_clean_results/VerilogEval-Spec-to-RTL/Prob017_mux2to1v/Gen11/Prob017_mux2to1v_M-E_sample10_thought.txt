Instead of using traditional mux structures or hierarchical approaches, we can:
1. Exploit Verilog's bitwise operators to create a more compact implementation
2. Use a mathematical approach where we treat the selection as a mask
3. The key insight is that:
   - When sel=0: out = a & ~{100{sel}} | b & {100{sel}} → simplifies to a
   - When sel=1: out = a & ~{100{sel}} | b & {100{sel}} → simplifies to b
4. This approach:
   - Eliminates explicit mux structures
   - Uses only bitwise operations which are highly optimized in synthesis
   - Creates a very dense implementation
   - Has uniform timing across all bits
   - Scales perfectly for any bus width
