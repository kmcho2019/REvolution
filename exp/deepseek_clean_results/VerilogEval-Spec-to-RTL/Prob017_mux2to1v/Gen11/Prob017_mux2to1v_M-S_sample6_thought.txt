The previous solution uses a generate loop with 10-bit chunks to reduce fanout, but for a simple 2:1 mux this may be unnecessary overhead. We can simplify by:
1. Using a single continuous assignment for all 100 bits
2. Eliminating the generate loop and grouping logic
3. Maintaining the same functionality with simpler code
4. Benefits:
   - Reduced code complexity
   - Same functionality
   - Potentially better synthesis results (depends on tool)
   - Easier to understand and maintain
