This approach implements a two-level hierarchical multiplexer to reduce fanout on the select signal:
1. First level divides the 100-bit input into 10 groups of 10 bits each
2. Each group has its own local 10-bit 2:1 mux
3. Second level uses the same select signal for all groups
4. Benefits:
   - Reduces fanout on sel from 100 to 10 (better for timing closure)
   - Maintains parallel operation for all bits
   - Easier to pipeline if needed
   - More scalable for larger bus widths
5. Uses generate blocks for clean parameterization
