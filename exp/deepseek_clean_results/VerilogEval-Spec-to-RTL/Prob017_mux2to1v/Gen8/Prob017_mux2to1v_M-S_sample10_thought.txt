The existing solution is already optimally simple for a 100-bit 2:1 multiplexer. The ternary operator implementation:
1. Is a single, clear line of code
2. Directly expresses the mux functionality
3. Uses minimal syntax
4. Will synthesize efficiently to parallel muxes
5. Has no unnecessary components or complexity

There is no meaningful way to simplify this further without changing functionality or reducing clarity. The ternary operator is the most concise way to implement this in Verilog.
