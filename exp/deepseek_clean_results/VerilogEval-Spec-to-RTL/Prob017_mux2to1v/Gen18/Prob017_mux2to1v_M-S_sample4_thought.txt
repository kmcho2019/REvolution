Simplified Design Idea: Direct Ternary Operator Implementation
1. Use a simple ternary operator for each bit to select between a and b based on sel
2. This approach eliminates the need for mask generation and reduces the logic to a single 2:1 mux per bit
3. The implementation is more straightforward and likely to be optimized better by synthesis tools
4. Reduces area by using standard multiplexer cells instead of AND-OR structures
5. Maintains the same functionality with cleaner code
