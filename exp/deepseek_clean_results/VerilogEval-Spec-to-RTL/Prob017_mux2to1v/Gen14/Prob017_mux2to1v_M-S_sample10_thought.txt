The previous solution uses a generate loop with 10 segments to manage fanout, but for a simple 2:1 mux this may be over-optimized. We can simplify by:

1. Using a single continuous assignment for all 100 bits
2. This maintains the same functionality (sel=0 chooses a, sel=1 chooses b)
3. Modern synthesis tools can handle the fanout optimization automatically
4. Removes the generate loop complexity while keeping identical behavior
5. Results in cleaner, more readable code with no functional difference
