A novel approach would be to implement the logic gates using a lookup table (LUT) style implementation. Instead of using individual gate operations, we can:
1. Treat the 2-bit input combination (a,b) as an address
2. Use a case statement to map each input combination to all output values
3. This approach centralizes the logic and may offer better optimization opportunities for synthesis tools
4. It also makes the truth table explicitly visible in the code
