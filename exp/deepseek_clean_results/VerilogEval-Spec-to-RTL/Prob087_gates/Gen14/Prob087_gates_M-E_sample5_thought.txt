Novel Approach: Bitwise Operation Vectorization
1. Instead of treating each output separately, create a 7-bit output vector where each bit represents one of the required operations
2. Use a single always_comb block to compute all outputs simultaneously for better synthesis optimization
3. Implement the logic using bitwise operations on concatenated inputs for compact representation

   - Maintains clear mapping between operations and outputs
