Simplification Strategy:
1. Directly implement all logic operations using primitive gate operations in single assign statements
2. Remove intermediate signals to reduce logic levels
3. Group operations by their logical relationships (basic gates first, then complemented)
4. Use the most straightforward implementation for each operation
5. Maintain clear separation between different operations for readability

Key Improvements:
- All operations implemented directly without intermediate signals
- Each output has exactly one gate operation
- No redundant inverters (complemented operations implemented directly)
- Clean organization with comments for clarity
