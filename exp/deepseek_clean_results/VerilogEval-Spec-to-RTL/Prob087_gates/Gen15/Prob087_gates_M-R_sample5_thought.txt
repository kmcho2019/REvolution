Refactored Approach: Individual Assign Statements with Explicit Naming
1. Instead of using a vectorized approach, we'll implement each logic operation with its own explicit assign statement
2. This makes the code more readable and self-documenting as each operation is clearly labeled
3. Each output is computed independently, which may help synthesis tools optimize each path separately
4. The functionality remains identical to the original, just organized differently

Key Benefits:
- Improved readability and maintainability
- Clear one-to-one mapping between specification and implementation
- Easier to modify individual operations without affecting others
- Still maintains all parallel computation benefits
