Refactoring Approach: Individual Assign Statements with Clear Naming
1. Instead of using a vectorized approach, we'll use separate assign statements for each output:
   - Each logic operation gets its own explicit assign statement
   - Maintains the same functionality but with more explicit individual declarations
   - Potentially improves readability and debug visibility

2. Key Changes:
   - Replace single vectorized assign with multiple discrete assigns
   - Each output has its own clearly labeled operation
   - No functional change from original implementation
   - Same parallel computation benefits

3. Advantages:
   - More readable/maintainable code
   - Easier to modify individual operations
   - Clearer mapping between output names and operations
   - Same synthesis optimization potential
   - Better for documentation and debugging
