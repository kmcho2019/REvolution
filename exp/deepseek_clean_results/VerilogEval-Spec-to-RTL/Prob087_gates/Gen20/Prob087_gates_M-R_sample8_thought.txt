Refactoring Strategy:
1. Maintain identical functionality while changing implementation style
2. Use continuous assignments (assign) for all outputs instead of direct primitive operations
3. Introduce intermediate signals for common sub-expressions
4. Group related operations together for better readability
5. Keep the same interface and logical behavior
6. Ensure all outputs are still purely combinational

Key Changes:
- All outputs now use continuous assignments
- Added intermediate signals for shared logic (like a & b)
- Grouped related operations (AND/NAND, OR/NOR, XOR/XNOR)
- Maintained same gate-level functionality
- Improved code organization while keeping same PPA characteristics
