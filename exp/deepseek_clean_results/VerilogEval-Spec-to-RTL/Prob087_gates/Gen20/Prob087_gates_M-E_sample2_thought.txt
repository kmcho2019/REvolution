Novel Approach: Hierarchical Gate Composition Using Primitive Modules
1. Instead of using direct bitwise operations, we'll build the circuit hierarchically using Verilog primitive gates:
   - Instantiate AND, OR, XOR as primitive gates
   - Derive NAND, NOR, XNOR by inverting the outputs of these primitives
   - Implement AND-NOT using an AND gate with inverted b input

2. Key Features:
   - Explicit gate-level implementation for better synthesis control
   - Clear separation of each logic function
   - Uses Verilog's built-in primitive gates for potential technology mapping benefits
   - Shows direct correspondence to physical gate implementation

3. Advantages:
   - More transparent gate-level representation
   - Easier to constrain individual gates during synthesis
   - Better for educational purposes to show actual gate composition
   - Potential for better technology mapping in some synthesis tools
