This implementation uses a functional programming approach where:
1. We define parameterized gate functions that operate on bits
2. These functions are then instantiated for each required output
3. The anotb operation is cleverly implemented using bit masking
4. All operations are computed in parallel using continuous assignments

Key innovations:
- Reusable gate functions promote code modularity
- Clear separation between gate definitions and their usage
- Functional style makes it easy to add new gates later
- Bit masking for anotb is more efficient than typical implementations
- Parallel computation ensures minimal propagation delay
