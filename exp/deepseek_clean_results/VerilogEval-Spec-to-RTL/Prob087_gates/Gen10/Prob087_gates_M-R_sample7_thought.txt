The original solution uses continuous assignments (assign statements) for each output. We can refactor this to use an always block with a case statement that computes all outputs in parallel. This approach:
1. Groups all logic operations together in a single procedural block
2. Makes it clear that all outputs are computed simultaneously from the inputs
3. Maintains the same combinational behavior while showing an alternative coding style
4. Still results in optimal synthesis as modern tools handle both styles equally well
