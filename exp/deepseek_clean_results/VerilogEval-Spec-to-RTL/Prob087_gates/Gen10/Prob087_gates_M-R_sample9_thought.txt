Here's a refactored version that maintains the same functionality but uses direct gate-level assignments instead of the LUT approach. The key changes are:

1. Replace the case statement with individual gate assignments
2. Remove the unnecessary register since this is purely combinational
3. Use Verilog gate operators directly for each output
4. Simplify the structure to be more readable and maintainable

Advantages:
- More efficient implementation (better PPA)
- Clearer mapping between requirements and implementation
- No unnecessary registers
- Each output is computed independently
- Easier to modify individual outputs if needed
