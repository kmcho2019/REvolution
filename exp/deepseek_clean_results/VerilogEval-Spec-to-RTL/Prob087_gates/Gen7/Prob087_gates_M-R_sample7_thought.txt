The original solution uses continuous assignments (assign statements) for all outputs, which is clean and straightforward. However, we can refactor it to use an always_comb block for all the outputs, which groups related logic together and makes the code more maintainable for future modifications. The functionality remains identical, but the structure changes from individual assign statements to a single procedural block.

Refactoring approach:
1. Replace all assign statements with an always_comb block
2. Group all output assignments together in the procedural block
3. Maintain the same logic operations and signal names
4. Keep the same interface and functionality
5. The PPA metrics should remain identical since this is just a structural change
