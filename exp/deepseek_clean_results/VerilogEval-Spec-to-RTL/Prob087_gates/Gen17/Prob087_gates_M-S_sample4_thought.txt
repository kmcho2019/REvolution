Simplification Strategy:
1. Directly implement all logic operations using single-stage primitive operations
2. Remove intermediate signal dependencies (like deriving nand from and) to reduce gate count
3. Use the most fundamental gate representations for each operation
4. Maintain clear one-to-one mapping between operations and outputs
5. Keep the same interface and functionality while optimizing implementation

Key Changes:
- All outputs now implemented with direct single-gate operations
- Eliminated sequential dependencies between outputs
- Each output is computed independently from inputs
- Reduced total gate count by removing unnecessary inverters
- Maintained identical functionality with simpler structure
