The original solution uses continuous assignments (assign) for each output, which is perfectly valid. However, we can refactor it to use an always block with blocking assignments for all outputs. This approach:
1. Groups all combinational logic in a single always block
2. Makes it clear that all outputs are purely combinational functions of inputs
3. Maintains the same functionality while presenting a different coding style
4. Still results in the same synthesized hardware since it's combinational logic
