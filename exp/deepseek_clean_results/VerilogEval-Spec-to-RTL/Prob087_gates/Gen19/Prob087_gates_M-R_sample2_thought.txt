The original implementation is already clean and efficient, but we can refactor it to demonstrate an alternative approach using continuous assignments with intermediate signals. The key changes are:

1. Introduce explicit intermediate signals for fundamental operations (AND, OR, XOR)
2. Derive inverted outputs directly from these intermediates
3. Group related operations together for better readability
4. Maintain the same logical functionality while showing a different structural organization

This approach makes the derivation of inverted outputs more explicit and could potentially help with synthesis optimization in some tools by clearly showing the relationship between fundamental and derived operations.
