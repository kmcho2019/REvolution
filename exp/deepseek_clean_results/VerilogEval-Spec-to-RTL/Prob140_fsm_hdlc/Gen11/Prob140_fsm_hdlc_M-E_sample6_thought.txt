Instead of using a counter, I'll implement a shift register that tracks the last 7 bits of input. This allows:
1. Direct pattern matching for all conditions (disc, flag, err) in parallel
2. No need for sequential counting logic
3. Simple state transitions based on shift operations
4. Outputs can be generated combinatorially from the shift register contents

Key innovations:
- 7-bit shift register captures exactly the window needed for all patterns
- Parallel comparators detect all conditions simultaneously
- No arithmetic operations needed (simpler timing)
- Outputs are purely combinatorial functions of the shift register
- Reset initializes shift register to all zeros (as required)
