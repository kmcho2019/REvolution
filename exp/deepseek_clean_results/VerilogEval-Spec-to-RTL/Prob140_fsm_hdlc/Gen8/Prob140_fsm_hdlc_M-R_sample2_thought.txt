Refactoring Strategy:
1. State Encoding: Replace the counter with explicit state encoding for better readability and potential synthesis optimization.
2. Output Logic: Use continuous assignments (assign) for outputs to make the combinatorial logic more explicit.
3. State Transitions: Implement a classic Moore FSM structure with separate state register and next-state logic.
4. Error Detection: Maintain the same detection logic but express it through state transitions.
5. Reset Handling: Keep synchronous reset behavior but initialize to IDLE state (equivalent to previous input being 0).

Key Changes:
- Explicit state names improve code readability
- Continuous assignments make output generation clearer
- Classic FSM structure may help synthesis tools optimize better
- Same functionality but different implementation style
- Maintains all original timing and output requirements
