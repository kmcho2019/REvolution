Simplified Design Approach:
1. State Tracking: Use a 3-bit counter to track consecutive 1s, resetting to 0 when seeing a 0.
2. Output Logic: Generate outputs directly based on counter value and current input:
   - disc: when count=5 and next bit is 0 (0111110)
   - flag: when count=6 and next bit is 0 (01111110)
   - err: when count reaches 6 and next bit is 1 (7+ consecutive 1s)
3. Reset Handling: Initialize counter to 0 (as if previous input was 0)
4. Simplifications:
   - Remove intermediate next-state registers
   - Combine counter update and output logic in single always block
   - Use simple conditional assignments for outputs
5. Timing: Maintain registered outputs for clean one-cycle assertions
