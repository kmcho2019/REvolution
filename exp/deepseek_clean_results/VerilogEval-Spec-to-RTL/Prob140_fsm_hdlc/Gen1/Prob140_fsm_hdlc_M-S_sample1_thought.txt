To simplify the HDLC framing decoder, we'll:
1. Use a 3-bit counter to track consecutive 1s instead of explicit states
2. Reset counter to 0 when seeing a 0 or when reset is active
3. Generate outputs based on the counter value and current input:
   - disc: when counter is 5 and next bit is 1
   - flag: when counter is 6 and next bit is 0
   - err: when counter reaches 7
4. Register outputs for one clock cycle
This approach reduces the state machine complexity while maintaining the same functionality.
