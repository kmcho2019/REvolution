To simplify the HDLC framing decoder, we can reduce the state machine to only track necessary information while maintaining correct functionality. Key observations:
1. We only need to count up to 6 consecutive 1s (states 0-6)
2. The error state (7+ 1s) can be detected when we're in state 6 and see another 1
3. Outputs can be generated directly from state transitions without separate registers
4. The disc output is needed only when transitioning from 5 to 6 consecutive 1s with a following 0
5. The flag output is needed when transitioning from 6 to 0 consecutive 1s
6. The err output should be active whenever we're in the error condition (7+ 1s)

Simplifications:
1. Remove output registers and generate outputs directly from state transitions
2. Combine error detection into state 6 when input is 1
3. Use simpler state encoding since we only need 0-6 states
