Here's a novel approach using a shift register and combinational logic instead of a traditional FSM. The key idea is to maintain a 7-bit shift register that tracks the last 7 input bits. We then use combinational logic to detect the patterns:

1. For disc (0111110): Check if last 7 bits match 0111110
2. For flag (01111110): Check if last 7 bits are 1111110 (with current bit being 0)
3. For err (7+ 1s): Check if we've seen 7 consecutive 1s (shift register full of 1s)

This approach eliminates explicit state transitions and instead relies on pattern matching against the shift register contents. The outputs are registered to appear in the next cycle.
