A novel approach to implement the HDLC framing decoder is to use a shift register combined with combinational pattern matching. Instead of a traditional state machine, we'll maintain a 7-bit shift register that tracks the last 7 bits received. This allows us to:
1. Detect the discard pattern (0111110) by checking bits [6:0] when a new 0 arrives
2. Detect the flag pattern (01111110) by checking bits [6:0] when a new 0 arrives
3. Detect error (7+ 1s) by checking if all 7 bits are 1

The shift register approach simplifies the design by:
- Eliminating explicit state transitions
- Making pattern detection purely combinational
- Reducing the sequential logic to just the shift register

Outputs are registered for one cycle after detection. Reset initializes the shift register to all 0s.
