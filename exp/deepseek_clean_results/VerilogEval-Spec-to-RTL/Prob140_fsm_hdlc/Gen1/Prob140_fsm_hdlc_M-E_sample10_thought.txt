Here's a novel approach using a shift register and pattern matching instead of a traditional FSM:

1. Use a 7-bit shift register to track the last 7 input bits (including current)
2. Implement parallel pattern matching on the shift register contents:
   - "0111110" (5 ones followed by 0) → disc
   - "01111110" (6 ones followed by 0) → flag
   - "01111111" (7 ones) → err
3. The shift register naturally handles the history of bits
4. Outputs are registered to appear one cycle after detection
5. Reset clears the shift register (equivalent to previous bits being 0)

Advantages:
- More direct pattern matching implementation
- Easier to extend for longer patterns if needed
- Clear separation between history tracking and pattern detection
- No explicit state transitions to manage
