To implement the HDLC framing decoder, we'll create a Moore FSM with states representing the count of consecutive 1s seen. The FSM will:
1. Start in a state representing "previous bit was 0"
2. Transition between states based on current input (0 or 1)
3. Detect sequences for disc, flag, and err
4. Output signals are registered to ensure they last one full cycle

The states are:
- S0: Initial state (or after seeing 0)
- S1: Saw 1
- S2: Saw 11
- S3: Saw 111
- S4: Saw 1111
- S5: Saw 11111
- S6: Saw 111111 (flag condition)
- S7: Saw 1111111 (error condition)

Outputs are generated based on current state and input.
