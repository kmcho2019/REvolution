To implement the HDLC framing decoder, we need a Moore FSM that tracks the number of consecutive 1s seen in the input stream. The FSM will have states representing different counts of consecutive 1s (from 0 to 7+). Based on the current state and input, we'll transition between states and generate appropriate outputs (disc, flag, err) when specific patterns are detected.

Key points:
1. States represent consecutive 1s count (0-7+)
2. Reset initializes to state 0 (as if previous input was 0)
3. Outputs are generated based on state transitions:
   - disc: when we see 0111110 (transition from 5 to 6 consecutive 1s with input 0)
   - flag: when we see 01111110 (transition from 6 to 0 consecutive 1s with input 0)
   - err: when we reach 7+ consecutive 1s
4. Outputs are registered to ensure they last one full clock cycle
