To implement the HDLC framing decoder as a Moore FSM, we need to track sequences of consecutive 1s and detect the specific patterns. The FSM will have states representing the count of consecutive 1s seen so far. The key states are:
- State 0: Initial state (or after seeing 0)
- States 1-6: Count of consecutive 1s
- State 7: Error state (7 or more 1s)

Transitions between states depend on the input bit:
- If input is 1, move to next higher state (unless already in state 7)
- If input is 0, return to state 0, but check if we came from state 5 (discard), state 6 (flag), or state 7 (error)

Outputs are generated based on current state and input:
- disc: when moving from state 5 to state 0
- flag: when moving from state 6 to state 0
- err: when in state 7

The outputs are registered to ensure they are asserted for a complete cycle.
