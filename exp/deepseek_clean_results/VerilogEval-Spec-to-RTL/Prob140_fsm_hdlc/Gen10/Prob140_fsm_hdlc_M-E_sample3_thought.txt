Instead of using a traditional state machine, we can implement a shift register that tracks the last 7 bits received. This allows us to:
1. Use parallel pattern matching to detect all conditions simultaneously
2. Simplify the state transitions to just shifting bits
3. Reduce latency by detecting patterns in parallel rather than sequentially

The key innovations are:
- 7-bit shift register to maintain history
- Combinational pattern matching on the register contents
- Output registers to ensure one-cycle assertion
- Reset initializes the shift register to all zeros
