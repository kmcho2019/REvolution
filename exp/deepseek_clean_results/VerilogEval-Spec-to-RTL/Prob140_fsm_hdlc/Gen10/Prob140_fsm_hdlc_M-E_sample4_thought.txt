Novel Architectural Idea: Shift Register with Parallel Detection
Instead of using a traditional state machine with binary encoding, we'll implement a shift register that tracks the last 7 bits of input. This allows parallel detection of all patterns simultaneously using combinational logic on the shift register contents. The approach offers:

1. Pattern Detection: By examining the shift register contents, we can detect all three patterns (disc, flag, err) in parallel without complex state transitions.
2. Timing: Parallel detection reduces critical path compared to sequential state machines.
3. Simplicity: Eliminates explicit state encoding and complex transition logic.
4. Reset Handling: Initialize shift register to all 0s to simulate previous input being 0.

The shift register will be 7 bits long to detect the maximum required pattern (7 consecutive 1s). We'll use the following detection logic:
- disc: Pattern "0111110" (5 ones followed by zero)
- flag: Pattern "01111110" (6 ones followed by zero)
- err: Pattern "01111111" (7 or more ones)
