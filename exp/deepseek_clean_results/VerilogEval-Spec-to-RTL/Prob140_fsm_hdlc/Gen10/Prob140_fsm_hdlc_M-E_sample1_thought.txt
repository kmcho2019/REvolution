Instead of using a counter, we can implement a shift register that tracks the last 7 bits received. This allows us to:
1. Detect patterns in parallel rather than sequentially counting
2. Simplify state transitions by making them dependent only on the current input
3. Reduce power consumption by eliminating the counter's frequent toggles
4. Enable early detection of error conditions (7+ 1s) without waiting for count overflow

The shift register approach provides:
- Immediate pattern recognition (no sequential counting delay)
- Lower dynamic power (only one bit changes per cycle)
- Simpler output logic (direct pattern matching)
- Easier scalability if pattern lengths need to change
