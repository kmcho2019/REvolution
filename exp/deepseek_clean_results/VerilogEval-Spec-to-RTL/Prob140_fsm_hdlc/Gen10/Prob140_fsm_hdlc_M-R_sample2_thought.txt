Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding for better timing performance and reduced switching power.
2. Output Logic: Use continuous assignments (assign) for outputs to make the code more concise and potentially reduce logic levels.
3. State Transitions: Implement next-state logic with explicit conditions rather than incrementer to improve clarity and timing.
4. Reset Handling: Maintain synchronous reset but initialize all one-hot states to the idle state (S0).
5. Optimization: Keep the same functionality but express it more directly with parallel state checks.

Key Improvements:
- One-hot encoding reduces critical path by simplifying state decode logic
- Continuous assignments make output generation more transparent
- Explicit state transitions improve readability
- Same functionality with potentially better timing characteristics
