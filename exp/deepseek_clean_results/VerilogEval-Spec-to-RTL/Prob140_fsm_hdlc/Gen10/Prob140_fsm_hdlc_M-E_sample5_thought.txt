Instead of using a counter, we'll implement a shift register that tracks the last 7 bits received. This allows us to:
1. Directly observe the bit patterns we need to detect
2. Perform parallel pattern matching on the shift register contents
3. Eliminate complex state transition logic
4. Simplify output generation by directly comparing against target patterns

Key innovations:
- 7-bit shift register maintains history (sufficient for all patterns)
- Parallel comparators detect all patterns simultaneously
- Output logic becomes simple pattern matching
- Reset initializes shift register to all 0s (as specified)
- More intuitive and easier to modify for different patterns
