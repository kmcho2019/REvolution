Instead of using a counter-based approach, we'll implement a true Moore FSM with explicit states for each condition:
1. Use one-hot encoding (7 states) to track consecutive 1s
2. Each state represents the count of consecutive 1s (0 through 6+)
3. Outputs are directly derived from state transitions:
   - disc: when transitioning from state5 to state0 (0111110)
   - flag: when transitioning from state6 to state0 (01111110)
   - err: when remaining in state6 or transitioning to state6 (01111111...)
4. Reset initializes to state0 (previous input was 0)
This approach eliminates counter logic and directly maps states to outputs.
