To simplify the solution while maintaining functionality, I'll make these key changes:

1. State Representation:
   - Replace the 3-bit counter with a minimal state machine (7 states)
   - Each state represents the count of consecutive 1s (0-6+)

2. Output Logic:
   - Generate outputs directly based on current state and input
   - Remove unnecessary intermediate registers
   - Outputs are purely combinational for immediate response

3. Optimization:
   - Eliminate the counter increment logic
   - Reduce state transitions to only necessary cases
   - Simplify output conditions with direct state checks

4. Reset Behavior:
   - Reset to initial state (equivalent to count=0)
   - Maintain synchronous reset

Key simplifications:
- Fewer total states than the counter approach
- No arithmetic operations (simpler than counter increment)
- Direct output generation without intermediate registers
- Clear state transitions based only on current state and input
