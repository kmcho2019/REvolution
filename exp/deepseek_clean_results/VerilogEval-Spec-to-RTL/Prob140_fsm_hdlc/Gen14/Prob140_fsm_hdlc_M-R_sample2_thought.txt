Refactoring Strategy:
1. State Encoding: Switch from binary counter to one-hot encoding for better timing (simpler comparators)
2. Output Logic: Move to continuous assignments (assign) for outputs to reduce sequential logic
3. State Transitions: Maintain same state progression but express as explicit one-hot transitions
4. Reset Handling: Keep synchronous reset but initialize one-hot state properly
5. Timing Optimization: Remove default output assignments to reduce unnecessary switching

Key Changes:
- One-hot state encoding (8 bits) for simpler comparison logic
- Outputs generated combinatorially via assign statements
- State transitions expressed as explicit bit manipulations
- Maintains same functional behavior but with potentially better timing
