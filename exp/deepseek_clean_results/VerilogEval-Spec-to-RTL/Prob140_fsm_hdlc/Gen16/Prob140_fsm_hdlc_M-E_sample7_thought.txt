Instead of using a counter or traditional state machine, I'll implement a shift register that tracks the last 7 bits. This allows for:
1. Parallel pattern matching - we can check all conditions simultaneously
2. Simplified logic - no need for complex state transitions
3. Early detection - we can identify patterns as soon as they occur
4. Power efficiency - only shifts when needed

Key features:
- 7-bit shift register tracks history
- Parallel comparators detect all patterns simultaneously
- Outputs are registered for clean timing
- Reset initializes to all zeros
- Only shifts when input changes state (power optimization)
