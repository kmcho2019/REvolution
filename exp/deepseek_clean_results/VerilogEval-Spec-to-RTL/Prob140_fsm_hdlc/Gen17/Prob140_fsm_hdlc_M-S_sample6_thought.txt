To simplify the solution while maintaining functionality:
1. Use a 3-bit counter to track consecutive 1s (0-7)
2. Outputs are purely combinational functions of current state and input
3. Reset initializes counter to 0 (simulating previous input was 0)
4. Counter increments on 1s, resets on 0s
5. Outputs:
   - disc: when we've seen exactly 5 consecutive 1s followed by 0
   - flag: when we've seen exactly 6 consecutive 1s followed by 0
   - err: when counter reaches 7 (indicating 7+ consecutive 1s)
6. Outputs are registered to appear one cycle after condition
