Innovative approach using shift register pattern matching:
1. Use a 7-bit shift register to track the last 7 bits (enough to detect all patterns)
2. Implement pattern matching by comparing the shift register contents to target patterns
3. Use a small state machine just to manage the shift register and outputs
4. Outputs are generated combinatorially based on shift register contents
5. Reset initializes the shift register to all zeros
6. This approach simplifies state transitions by making them dependent only on current input
7. Pattern matching becomes simple bitwise comparisons
