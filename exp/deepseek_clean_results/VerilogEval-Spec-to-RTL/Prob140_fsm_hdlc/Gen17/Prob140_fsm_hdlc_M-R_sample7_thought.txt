Refactoring approach:
1. Convert to explicit state machine with named states for better readability
2. Use combinational logic for outputs (Moore-style) to reduce flip-flop usage
3. Separate next-state logic from output logic for clearer structure
4. Use parameterized states instead of raw count values
5. Optimize state transitions to minimize logic operations

Key improvements:
- More maintainable and debuggable state machine
- Reduced sequential elements (only state register)
- Clear separation of state transition and output logic
- More explicit handling of all conditions
