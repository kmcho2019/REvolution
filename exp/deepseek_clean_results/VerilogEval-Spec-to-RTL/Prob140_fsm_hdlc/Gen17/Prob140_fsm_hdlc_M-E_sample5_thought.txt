Novel Architectural Idea: Shift Register with Parallel Pattern Matching
1. Instead of using a counter-based FSM, implement a 7-bit shift register to track the last 7 bits of input
2. Use parallel pattern matching on the shift register contents to detect all conditions simultaneously
3. Advantages:
   - Eliminates state transition logic complexity
   - All conditions can be checked in parallel for better timing
   - Easier to extend for longer patterns if requirements change
4. Output Logic:
   - Registered outputs for clean timing
   - Each output has its own dedicated matching logic
5. Reset Behavior:
   - Initialize shift register to all 0s
   - Clear all outputs on reset

Key Differences from Previous Solution:
- No explicit state machine states
- All pattern matching happens in parallel
- More scalable for pattern length changes
- Simpler transition logic (just shifting)
