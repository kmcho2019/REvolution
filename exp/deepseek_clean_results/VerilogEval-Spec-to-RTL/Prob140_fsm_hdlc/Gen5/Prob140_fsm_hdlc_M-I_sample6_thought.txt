Improved design approach:
1. Use a proper Moore machine with explicit states for each required pattern detection
2. Create distinct states to track consecutive 1s from 0 to 7+
3. Separate states for:
   - Initial/reset state (prev input was 0)
   - Counting 1s (states ONE to SIX_ONES)
   - Discard detection (after 5 ones followed by 0)
   - Flag detection (after 6 ones followed by 0)
   - Error state (7+ ones)
4. Outputs are purely based on current state
5. Reset initializes to INIT state (previous input was 0)
6. State transitions based strictly on input bits
7. Clear separation between counting states and pattern detection states

State encoding:
- INIT: initial state (prev input was 0)
- ONE to SIX_ONES: tracking 1-6 consecutive 1s
- DISC: discard state (0111110 detected)
- FLAG: flag state (01111110 detected)
- ERR: error state (7+ ones detected)
