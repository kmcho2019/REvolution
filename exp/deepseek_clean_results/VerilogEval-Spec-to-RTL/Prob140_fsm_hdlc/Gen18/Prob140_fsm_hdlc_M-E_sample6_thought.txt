Instead of using a counter-based state machine, I'll implement a shift register that tracks the last 7 bits received. This allows for:
1. Parallel pattern matching - we can check all conditions simultaneously
2. Early detection - we can identify patterns as soon as they're complete
3. Reduced logic complexity - no need for complex state transitions

Key innovations:
- 7-bit shift register maintains history of inputs
- Combinational logic checks for patterns in parallel
- Outputs are registered for clean timing
- Reset initializes the shift register to all zeros
- Special handling for the 0111110 (disc) case by looking at both current and previous states

Benefits:
- More intuitive pattern matching (direct comparison)
- No counter overflow concerns
- Easier to extend for longer patterns if needed
- Clear separation between pattern detection and output generation
