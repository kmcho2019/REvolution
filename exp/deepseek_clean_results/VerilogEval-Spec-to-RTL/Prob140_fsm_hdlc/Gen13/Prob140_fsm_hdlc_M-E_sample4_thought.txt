Shift Register Pattern Matching Approach:
1. Instead of using a counter, implement a 7-bit shift register to track the last 7 input bits (including current)
2. Compare parallel patterns simultaneously for all three conditions:
   - 0111110 (discard)
   - 01111110 (flag)
   - 01111111 (error)
3. Use registered outputs with one-cycle delay as required
4. Reset initializes shift register to all 0s (simulating previous input was 0)
5. Benefits:
   - Parallel pattern matching enables all conditions to be checked simultaneously
   - Eliminates sequential counting logic
   - Clear mapping between bit patterns and outputs
   - Easily extensible for longer patterns
   - No need for state encoding/decoding
