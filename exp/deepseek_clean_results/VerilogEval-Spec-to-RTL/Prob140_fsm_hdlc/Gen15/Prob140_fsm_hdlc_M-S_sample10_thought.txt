To simplify the solution while maintaining functionality, I'll make these key changes:

1. State Representation:
- Use a 3-bit counter (0-7) to track consecutive 1s, same as before
- This is the most efficient way to track up to 7 consecutive 1s

2. Output Logic:
- Make outputs purely combinational based on current count and input
- Remove output registers to simplify design and improve timing
- This matches Moore machine requirements (outputs depend only on current state)

3. Counter Logic:
- Keep simple increment/reset behavior
- No need for max count limit since we only care about counts up to 7

4. Reset Behavior:
- Maintain synchronous reset to count=0
- Outputs will automatically be correct after reset

Simplifications:
- Removed output registers (reduces area and improves timing)
- Simplified counter logic (no max count check needed)
- Outputs are now direct functions of state and input
- Fewer total registers (only counter remains)
