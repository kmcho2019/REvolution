Novel Architecture Idea:
1. Shift Register Approach: Instead of a counter, use a 7-bit shift register to track the last 7 input bits. This provides direct visibility into the required patterns.
2. Parallel Pattern Matching: Compare the shift register contents in parallel against the three target patterns (0111110, 01111110, 01111111).
3. Edge Detection: Use the shift register's MSB to detect when patterns complete (when new bits shift in).
4. Output Generation: Generate outputs combinatorially based on pattern matches, then register them for clean timing.
5. Reset Handling: Initialize shift register to all 0s to simulate previous input being 0.

Advantages:
- Eliminates counter comparison logic
- Parallel pattern matching enables immediate detection
- Simple to extend for longer patterns if needed
- Clear correspondence between hardware and specification
- No need to maintain separate state variables
