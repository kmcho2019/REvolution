Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding for better timing performance and simpler decode logic
2. Output Logic: Use continuous assignments (assign) for combinational outputs instead of registered outputs
3. State Transitions: Implement next-state logic with explicit conditions for each state
4. Reset Behavior: Maintain synchronous reset but initialize one-hot state properly
5. Optimization Benefits:
   - One-hot encoding reduces fan-out and improves timing
   - Continuous assignments simplify output logic
   - Explicit state transitions make the FSM behavior clearer

Key Changes:
- Replace binary state encoding with one-hot
- Move outputs to combinational logic using assign
- Make state transitions more explicit
- Keep same functional behavior but with improved timing characteristics
