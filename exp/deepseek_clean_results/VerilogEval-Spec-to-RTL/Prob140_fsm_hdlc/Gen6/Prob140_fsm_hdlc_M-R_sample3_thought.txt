The refactored solution maintains the same state machine logic but improves clarity and timing by:

1. Using explicit state transitions with assign statements for next_state logic
2. Moving output generation to combinational assign statements
3. Keeping registered outputs for proper timing
4. Using a separate always block just for state registration
5. Making the state encoding more explicit with localparams

Key improvements:
- Clear separation of combinational and sequential logic
- Direct assignment of outputs based on current state and input
- Simplified state transition logic using ternary operators
- Maintains Moore machine properties with registered outputs
