Here's a novel approach using a shift register and pattern matching:

1. Instead of a traditional state machine, use a 7-bit shift register to track the last 7 bits received
2. Compare specific bit patterns in the shift register to detect conditions:
   - disc: "0111110" pattern (bits 6:0)
   - flag: "01111110" pattern (bits 7:0, with current input as LSB)
   - err: "01111111" pattern (bits 7:0, with current input as LSB)
3. Use edge detection to ensure outputs are only asserted for one cycle
4. Reset initializes the shift register to all zeros

Benefits:
- More direct pattern matching implementation
- Easier to extend if pattern requirements change
- Clear relationship between bit patterns and outputs
- No complex state transition logic
