Improvement strategy:
1. State encoding optimization:
   - Switch from one-hot to binary encoding (4 bits for 10 states)
   - This reduces flip-flop count and combinational logic depth
2. Output optimization:
   - Encode outputs directly in state register bits
   - Eliminate separate output comparators
3. Power optimization:
   - Remove redundant default case
   - Simplify state transition logic
4. Area optimization:
   - Use minimal 4-bit state register (exactly covers 10 states)
   - Combine state and output encoding

Key changes:
- Binary state encoding (4 bits)
- Outputs encoded in state bits
- Simplified transition logic
- Removed redundant default case
- More compact implementation
