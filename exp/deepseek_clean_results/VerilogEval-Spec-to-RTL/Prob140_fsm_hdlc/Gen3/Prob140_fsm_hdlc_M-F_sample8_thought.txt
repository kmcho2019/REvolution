Here's a corrected approach that properly implements the HDLC framing detection as a Moore FSM:

1. Use a state machine to track consecutive 1s rather than a shift register:
   - States represent counts of consecutive 1s (0-7+)
   - This directly models the sequence detection requirements

2. Correct pattern detection:
   - Discard (disc) after exactly 5 consecutive 1s followed by any bit
   - Flag (flag) after exactly 6 consecutive 1s followed by 0
   - Error (err) when reaching 7 or more consecutive 1s

3. Output timing:
   - Outputs are registered to appear one cycle after detection
   - Maintain Moore machine properties (outputs depend only on current state)

4. Reset behavior:
   - Initialize to state representing "previous input was 0"
   - Clear all outputs on reset

Key improvements:
- Proper state tracking of consecutive 1s
- Accurate pattern matching for all three cases
- Correct output timing
- Clean reset behavior
