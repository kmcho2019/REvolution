To refactor the implementation while maintaining the same functionality, we'll use a continuous assignment with Boolean expressions derived from the Karnaugh map. This approach:

1. Identifies the prime implicants from the K-map to create a minimized Boolean expression
2. Uses bitwise operations to implement the logic directly
3. Eliminates the need for a case statement, potentially reducing logic depth
4. Maintains the exact same truth table as the original implementation

The K-map shows four main groupings of 1s that can be expressed as:
- ~c & ~d (top two rows when ab isn't 11)
- c & d & (a | b) (bottom right quadrant)
- ~d & a & ~b (left middle when c=0)
- d & ~c & b (top right when cd=01)
