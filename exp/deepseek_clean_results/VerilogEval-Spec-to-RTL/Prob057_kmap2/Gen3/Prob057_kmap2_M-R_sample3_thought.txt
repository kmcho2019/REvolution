To refactor the solution while maintaining the same lookup table approach, we'll:
1. Switch from using an always block with case statement to continuous assignments
2. Create a 4-bit concatenated input signal for clarity
3. Use a ternary operator chain to implement the truth table
4. This approach eliminates the need for a procedural block while maintaining direct mapping
5. The ternary operators will check each input combination in order
6. The structure remains easy to verify against the original K-map
7. Default case is handled by the final else clause
