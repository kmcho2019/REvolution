Novel Lemming State Machine Architecture:

1. Hierarchical State Design:
   - Primary states: WALKING, FALLING, DIGGING, SPLATTERED
   - Secondary direction state (LEFT/RIGHT) tracked separately

2. Event-Driven Transitions:
   - Explicit event detection (fall_start, dig_start, bump_event)
   - Clear priority ordering: fall > dig > bump

3. Smart Fall Timer:
   - Separate counter for fall duration
   - Only increments when actually falling
   - Auto-reset when not falling

4. Direction Lock:
   - Preserves direction during non-walking states
   - Only updates direction in WALKING state

5. Output Generation:
   - State-based outputs with clear conditions
   - All outputs disabled in SPLATTERED state

Key Innovations:
- Clear separation of state and direction
- Explicit event detection simplifies transition logic
- Fall timer only active when needed
- Direction preserved during interrupts
