Refactoring Strategy:
1. Use one-hot encoding for states to simplify state transitions
2. Separate direction logic from state transitions for clarity
3. Implement priority handling through nested if-else structure
4. Use combinational logic for outputs where possible
5. Explicitly handle all edge cases in state transitions

Key Improvements:
- One-hot states: WALK, FALL, DIG, SPLAT
- Direction register tracks movement separately
- Clear priority structure in state transitions
- Fall counter as separate register
- Outputs directly derived from state and direction
