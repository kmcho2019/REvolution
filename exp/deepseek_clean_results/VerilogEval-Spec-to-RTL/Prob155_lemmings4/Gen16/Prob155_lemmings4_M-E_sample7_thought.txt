Novel State Machine Architecture with Hierarchical Priority Handling:

1. Key Innovation:
   - Implement a hierarchical state machine that naturally enforces the precedence rules (fall > dig > bump)
   - Use separate states for left/right walking to simplify direction handling
   - Explicitly track falling duration with a counter

2. State Encoding:
   - WALK_L: Walking left
   - WALK_R: Walking right
   - DIG_L: Digging while previously walking left
   - DIG_R: Digging while previously walking right
   - FALL: Falling (direction preserved)
   - SPLAT: Dead state

3. Priority Handling:
   - First check for falling condition
   - Then check for dig command (only if not falling)
   - Finally handle bumps (only if walking and not digging/falling)

4. Benefits:
   - Clear separation of concerns between states
   - Natural enforcement of behavior precedence
   - Simplified direction tracking by encoding it in state
   - Explicit falling duration tracking
