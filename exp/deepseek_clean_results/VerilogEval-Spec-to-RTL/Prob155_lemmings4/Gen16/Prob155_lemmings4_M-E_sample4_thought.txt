Novel Lemming State Machine Architecture:

1. **State Encoding**: Use one-hot encoding for states to simplify transitions and make debugging easier
2. **Direction Handling**: Implement direction as a separate state machine that only updates during walking
3. **Fall Counter**: Use a synchronous clear counter that resets on any non-fall state
4. **Priority Logic**: Implement explicit priority logic in a separate combinational block
5. **State Transitions**: Break transitions into two phases - priority resolution then state update
6. **Output Generation**: Derive outputs directly from current state and direction

Key Innovations:
- One-hot state encoding improves readability and simplifies transition logic
- Separate direction state machine ensures clean direction handling
- Explicit priority logic block makes behavior more maintainable
- Two-phase transition handling ensures correct priority ordering
- Synchronous counter with clear ensures accurate fall timing
