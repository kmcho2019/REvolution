Simplified Lemming State Machine Design:

1. Clear State Encoding:
   - Use distinct states for walking, digging, falling, and splat
   - Track direction separately (left/right) to reduce state combinations

2. Priority Handling:
   - Implement fall/dig/bump priority in state transitions
   - Check falling condition first, then digging, then direction change

3. Efficient Fall Counter:
   - Only increment when actively falling (ground=0)
   - Reset when not falling or when ground returns

4. Direct Output Logic:
   - Outputs directly derived from current state
   - No complex combinational logic needed

Key Simplifications:
- Fewer state transitions by combining related conditions
- Clear priority handling through ordered checks
- Minimal state variables while maintaining all functionality
- Easier to understand and verify
