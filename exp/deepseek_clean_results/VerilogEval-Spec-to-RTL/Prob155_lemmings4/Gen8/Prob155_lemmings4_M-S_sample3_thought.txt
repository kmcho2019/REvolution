Simplified Lemming State Machine Design:

1. Key Simplifications:
   - Reduced states by combining walking and digging directions into single states with direction flags
   - Eliminated separate fall direction tracking by using current state direction
   - Simplified priority handling by checking conditions in order (fall > dig > bump)
   - Removed redundant state transitions

2. State Reduction:
   - Only 4 states: WALK, DIG, FALL, SPLAT
   - Direction (left/right) tracked separately from state
   - Digging is a substate of walking (same direction rules)

3. Efficient Logic:
   - Single always block for state and direction updates
   - Fall counter only increments when in FALL state
   - Clear priority handling through ordered if-else

4. Maintained Functionality:
   - Still handles all specified behaviors (falling, digging, bumping)
   - Preserves Moore machine properties
   - Keeps splatter condition (20+ cycle falls)
