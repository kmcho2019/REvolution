Simplified Lemming State Machine:

1. State Consolidation:
   - Only 4 states needed: WALK, DIG, FALL, SPLAT
   - Direction tracked separately from state

2. Priority Handling:
   - Fall has highest priority (ground=0)
   - Dig comes next when on ground
   - Direction change last (only when walking)

3. Fall Counter:
   - Simple counter increments while falling
   - Resets when not falling
   - Splatter when >20 cycles and ground returns

4. Bump Handling:
   - Any bump changes direction immediately when walking
   - Ignored during fall/dig states

5. Output Logic:
   - Direct mapping from state and direction
   - No complex conditions needed

Key Simplifications:
- Removed redundant states
- Clear priority order in state transitions
- Simplified bump handling
- Maintained all required functionality
