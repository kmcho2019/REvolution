Simplified Lemming State Machine Design:

1. State Reduction:
   - Combine DIG_L and DIG_R into a single DIG state since digging behavior is direction-independent
   - Use walking_left register to track direction during digging/falling

2. Priority Handling:
   - Implement clear priority order: FALL > DIG > BUMP
   - Simplify conditions by checking priorities in order

3. Counter Logic:
   - Only count when actually falling (state == FALL && !ground)
   - Reset counter when not falling

4. Output Logic:
   - Directly map states to outputs
   - aaah is active during FALL and transition to SPLAT
