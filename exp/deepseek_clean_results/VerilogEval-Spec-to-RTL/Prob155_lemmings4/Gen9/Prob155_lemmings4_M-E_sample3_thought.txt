Novel Lemming State Machine Design:

1. Hierarchical State Approach:
   - Split behavior into two parallel state machines: Movement and Action
   - Movement FSM tracks direction (LEFT/RIGHT)
   - Action FSM handles current activity (WALK/DIG/FALL/SPLAT)
   - This separation simplifies direction persistence during actions

2. Smart Counter Implementation:
   - Fall counter only active during FALL state
   - Automatic reset when leaving FALL state
   - Explicit comparison for splatter condition (>=20)

3. Strict Priority Enforcement:
   - Dedicated priority decoder that evaluates conditions in correct order
   - Prevents any priority violations in state transitions

4. Edge Case Handling:
   - Explicit checks for valid dig conditions (ground=1)
   - Direction changes only processed when in WALK state
   - Clean separation of asynchronous reset logic

5. Output Generation:
   - Moore outputs derived purely from current state
   - Direction outputs gated by WALK state
   - Clear state encoding for readability
