Simplified Lemming State Machine Design:

1. Key Improvements:
   - Maintain only 4 essential states: WALK, DIG, FALL, SPLAT
   - Track direction separately (left/right) as it persists across states
   - Strict priority handling through ordered conditions (fall > dig > bump)
   - Simplified fall counter with clear splatter condition (>=20 cycles)
   - Explicit direction preservation during falls and digs

2. State Logic:
   - WALK: Default state, handles direction changes and dig initiation
   - DIG: Active only when on ground, transitions to FALL when ground lost
   - FALL: Counts cycles until ground reappears, transitions to WALK or SPLAT
   - SPLAT: Terminal state with all outputs zero

3. Output Logic:
   - Direct mapping from state and direction to outputs
   - Clear separation between state behavior and output generation

4. Simplifications:
   - Single always block for state and direction updates
   - Minimal state transitions with clear conditions
   - No redundant state variables
