Improved Lemming State Machine Design:

1. State Encoding:
   - Use binary encoding for more efficient state representation (4 states + splat)
   - Combine left/right walking into one state with direction flag
   - Combine left/right digging into one state with direction flag

2. Fall Counter:
   - Simplify counter logic by incrementing only in FALL state
   - Reset counter when not falling or when ground is detected

3. Transition Logic:
   - Explicit priority handling (fall > dig > bump)
   - Clear separation of state transition conditions
   - Proper handling of splat condition after long falls

4. Output Logic:
   - Direct mapping from state and direction flags
   - Simplified continuous assignments

Key Improvements:
- More efficient state encoding (4 bits vs 6 bits)
- Clearer transition priority handling
- Proper splat condition implementation
- Maintains all specified behaviors
- Reduced logic complexity
