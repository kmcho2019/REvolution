Novel State Machine Architecture with Hierarchical States:

1. Key Innovations:
   - Hierarchical state grouping (GROUNDED vs FALLING)
   - Explicit state transition priority through dedicated logic
   - Separate direction tracking from action states
   - Fall timer as a separate always block for clarity

2. State Groups:
   - GROUNDED: Contains walking and digging states
   - FALLING: Contains falling states with timer
   - SPLAT: Terminal state

3. Implementation Approach:
   - Use two always blocks: one for state, one for timer
   - Track direction separately from action state
   - Explicit priority logic before state transitions
   - Clear separation of concerns between state groups

4. Benefits:
   - More intuitive state organization
   - Explicit priority handling through pre-processing
   - Easier to extend with new behaviors
   - Clear separation of timing and state logic
