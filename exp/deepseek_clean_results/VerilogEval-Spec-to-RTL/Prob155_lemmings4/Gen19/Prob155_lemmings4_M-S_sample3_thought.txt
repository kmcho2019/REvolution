Simplified Lemming State Machine:

1. **State Encoding**: Use simple binary encoding with fewer states (LEFT, RIGHT, DIG, FALL, SPLAT)
2. **Combined Logic**: Merge direction into state to eliminate separate direction register
3. **Priority Handling**: Use nested if-else to enforce fall > dig > bump priority
4. **Fall Counter**: Simplify to just count cycles while falling
5. **Output Logic**: Directly derive outputs from current state

Key Simplifications:
- Eliminated one-hot encoding complexity
- Removed separate direction tracking
- Simplified state transition logic with clear priority
- Reduced number of states
- More straightforward output assignments
