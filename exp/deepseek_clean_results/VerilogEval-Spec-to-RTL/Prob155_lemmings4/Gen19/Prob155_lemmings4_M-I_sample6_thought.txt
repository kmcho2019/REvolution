Improved Lemming State Machine Design:

1. **State Encoding**: Use one-hot encoding for better timing and simpler decoding (4 states: WALK, DIG, FALL, SPLAT)
2. **Priority Handling**: Restructure state transitions to strictly follow fall > dig > bump priority
3. **Fall Timer**: Only count when actually falling (ground=0) and reset properly
4. **Bump Handling**: Simplify direction toggle logic and ensure it only applies in WALK state
5. **Output Logic**: Maintain pure Moore outputs with clear state-based assignments
6. **Reset Handling**: Ensure all registers are properly initialized on reset

Key Improvements:
- Strict priority ordering in state transitions
- More accurate fall timer behavior
- Cleaner separation of state and direction logic
- Simplified output generation
- Better handling of edge cases
