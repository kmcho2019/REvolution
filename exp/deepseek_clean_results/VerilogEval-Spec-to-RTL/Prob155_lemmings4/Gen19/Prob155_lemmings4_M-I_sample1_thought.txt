Improvement Strategy:

1. State Machine Simplification:
   - Reduce states by tracking direction separately (LEFT/RIGHT) instead of duplicating states
   - Use fewer states: WALK, DIG, FALL, SPLAT
   - Store direction in a separate register to avoid state explosion

2. Priority Enforcement:
   - Explicitly implement fall > dig > bump priority in state transitions
   - Only check bumps when in WALK state with ground=1
   - Ignore all other inputs when falling or digging

3. Fall Counter Optimization:
   - Reset counter when entering FALL state
   - Only increment when actually falling (ground=0)
   - Check splatter condition only when ground reappears

4. Output Logic:
   - Simplify output assignments based on state and direction
   - Ensure all outputs are zero in SPLAT state
   - Clear mapping from state to outputs

5. Edge Case Handling:
   - Properly handle simultaneous bumps (switch direction regardless)
   - Ensure dig is only active when in DIG state with ground=1
   - Maintain direction after falling/digging
