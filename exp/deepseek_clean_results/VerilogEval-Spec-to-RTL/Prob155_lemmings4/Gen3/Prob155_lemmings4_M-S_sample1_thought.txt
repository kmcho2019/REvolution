To simplify the Lemming state machine while maintaining functionality, we'll:

1. Use binary state encoding instead of one-hot to reduce flip-flop usage
2. Combine walking states into one state with a direction flag
3. Explicitly handle priorities in the state transition logic:
   - Falling has highest priority
   - Digging comes next (only when grounded)
   - Direction changes are last (only when walking)
4. Simplify fall counter logic:
   - Only count when falling
   - Reset when not falling or when ground reappears
5. Make outputs directly dependent on state and direction
6. Ensure splattered state overrides all outputs

Key simplifications:
- Fewer states by combining walking directions
- Clearer priority structure in transition logic
- Reduced register usage
- More straightforward output logic
