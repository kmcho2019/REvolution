Here's a refactored solution that maintains the same core logic but simplifies the implementation:

1. Key improvements:
   - Separates direction and action states into distinct state machines
   - Uses simpler combinatorial output logic
   - More clearly implements the priority hierarchy (fall > dig > bump)
   - Simplifies fall counter handling
   - Uses clearer state encoding

2. State machine structure:
   - Main states: WALK, FALL, DIG, SPLAT
   - Direction tracking: LEFT or RIGHT (independent of main state)
   - Fall counter tracks only during FALL state

3. Output logic:
   - Pure combinatorial assignments based on current state
   - No complex saved direction logic needed
   - Clear priority encoding in state transitions

This version maintains the same behavior but is more readable and less prone to edge case errors.
