Here's a simplified approach that maintains all functionality while reducing complexity:

1. Simplified state encoding (4 states):
   - WALK_LEFT/WALK_RIGHT: Normal movement states
   - FALLING: When ground is lost
   - DIGGING: When actively digging
   - SPLATTERED: Final state after long fall

2. Key simplifications:
   - Remove saved_dir register - track direction directly in state encoding
   - Simplify output logic to directly reflect current state
   - Use a single fall counter that resets appropriately
   - Clear priority handling (fall > dig > bump) in state transitions
   - Moore machine outputs purely based on current state

3. Benefits:
   - Fewer states (4 vs previous 7)
   - No need for separate direction tracking
   - Clearer state transition logic
   - Simpler output assignments
   - Maintains all required functionality
