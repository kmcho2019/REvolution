Refactored Lemming State Machine:

1. Key Changes:
   - Remove multiple output drivers by using a single always block for outputs
   - Keep the same state machine logic but express outputs as combinational logic
   - Maintain all original functionality and priorities
   - Simplify output assignments by deriving them directly from state and direction

2. Structure:
   - Sequential always block for state transitions and direction
   - Combinational always block for outputs (Moore machine)
   - Single assignment per output to avoid conflicts

3. Benefits:
   - Clear separation of state transition logic and output logic
   - No multiple driver issues
   - Maintains identical behavior to original solution
   - More conventional Verilog style
