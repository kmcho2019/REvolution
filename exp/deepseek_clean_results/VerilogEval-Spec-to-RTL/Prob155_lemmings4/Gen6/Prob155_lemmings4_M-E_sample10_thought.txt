This solution uses a hierarchical FSM design with:
1. Two parallel state machines - one for direction (left/right) and one for action (walk/fall/dig/splat)
2. A priority encoder that evaluates conditions in the correct order (fall > dig > bump)
3. Explicit state registers for both direction and action
4. Separate counters for fall duration and splat detection
5. Clean separation of concerns between direction changes and action states

Key advantages:
- Clear separation of direction and action logic
- Easier to modify priority rules
- More modular design
- Explicit handling of all edge cases
- Simplified output generation
