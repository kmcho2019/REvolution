To fix the Lemming state machine, we need to address the key issues identified:

1. **Direction Preservation**: Add a register to store the walking direction before falling/digging, so we can return to the correct direction after these states.

2. **Fall Counter Management**: 
   - Reset counter whenever not in FALLING state
   - Only increment when actively falling (ground=0)
   - Clear when falling stops (ground=1)

3. **State Transition Priorities**:
   - Falling has highest priority (ground=0)
   - Then digging (dig=1 and ground=1)
   - Then direction change (bump signals)
   - Maintain these priorities in all states

4. **Splatter Condition**:
   - Check fall_counter > 20 only when hitting ground
   - Transition to SPLATTERED state if condition met

5. **Output Logic**:
   - Keep Moore-style outputs
   - Ensure all outputs are 0 in SPLATTERED state
   - Properly reflect current state in outputs

The fixed design will use:
- 5 states (WALK_LEFT, WALK_RIGHT, FALLING, DIGGING, SPLATTERED)
- A direction register to preserve pre-fall/dig direction
- A fall counter that properly tracks fall duration
- Clear state transition priorities
