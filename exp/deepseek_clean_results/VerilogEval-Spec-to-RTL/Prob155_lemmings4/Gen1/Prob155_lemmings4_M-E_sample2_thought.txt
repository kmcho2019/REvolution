Here's a novel approach that uses separate state machines for direction and action, decoupling these concerns for cleaner design:

1. Direction FSM (2 states):
   - LEFT: walking left
   - RIGHT: walking right
   - Changes direction only when bumped (unless falling/digging)

2. Action FSM (4 states):
   - WALKING: normal movement
   - FALLING: when ground=0
   - DIGGING: when dig=1 and ground=1
   - SPLATTERED: after long fall

Key innovations:
- Separates direction and action concerns
- Uses a fall timer that only counts during falling
- Saves direction before falling/digging
- Action FSM has priority over direction changes
- Clear state transitions based on priority (fall > dig > bump)
