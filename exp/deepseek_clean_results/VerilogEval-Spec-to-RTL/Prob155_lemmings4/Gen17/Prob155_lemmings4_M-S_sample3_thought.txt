Simplified Design Approach:
1. Use binary state encoding (4 states) instead of one-hot to reduce complexity
2. Combine direction and state into a single state variable
3. Implement clear priority order: fall > dig > bump
4. Use a counter for fall duration with synchronous reset
5. Direct output assignments based on current state
6. Handle all transitions with simple if-else structure

Key Simplifications:
- Fewer state bits (4 states vs one-hot)
- Combined direction tracking with state
- Clear priority handling in single always block
- Minimal state transition logic
- Outputs directly derived from state
