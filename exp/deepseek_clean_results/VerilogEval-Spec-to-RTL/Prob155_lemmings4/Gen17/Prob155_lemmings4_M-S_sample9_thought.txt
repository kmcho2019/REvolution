Simplified Lemming State Machine:

1. **State Encoding**: Use binary encoding with 3 states (WALK_L, WALK_R, DIGGING) plus FALLING and SPLATTER
2. **Direction Handling**: Track direction separately from state using a direction register
3. **Fall Counter**: Simple counter that increments while falling and resets otherwise
4. **Priority Logic**: Directly implement in state transitions (fall > dig > bump)
5. **Output Logic**: Generate outputs based on current state and direction

Key Simplifications:
- Reduced state encoding from one-hot to binary
- Separated direction tracking from main state
- Simplified priority logic by implementing directly in state transitions
- Removed separate combinational blocks for cleaner code
- Maintained all required functionality with less complexity
