Novel Lemming State Machine Architecture:

1. **Hierarchical State Encoding**: Use a two-level state encoding with primary states (WALK, DIG, FALL, SPLAT) and secondary direction states (LEFT, RIGHT)
2. **Event-Driven Transitions**: Implement transition conditions as separate event signals for clearer priority handling
3. **Fall Duration Tracking**: Use a dedicated fall timer that persists across state changes
4. **Direction Preservation**: Maintain direction separately during falls and digs
5. **Output Generation**: Derive outputs from both primary state and direction state

Key Innovations:
- Hierarchical states simplify direction handling and state transitions
- Explicit event signals make priority ordering more visible
- Persistent fall timer ensures accurate splatter detection
- Direction preservation ensures correct behavior after falls/digs
- Clear separation between state and direction logic improves maintainability
