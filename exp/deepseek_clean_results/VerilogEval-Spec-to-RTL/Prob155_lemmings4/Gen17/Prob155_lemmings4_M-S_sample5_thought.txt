Simplified Lemming State Machine Design:

1. State Encoding:
   - Use 3 states: WALK, FALL, DIG (SPLAT is handled as a special case)
   - Track direction separately (LEFT/RIGHT)

2. Priority Handling:
   - Single always block with clear priority order:
     1. Falling (ground=0)
     2. Digging (dig=1 and ground=1)
     3. Bumping (if neither falling nor digging)

3. Splat Condition:
   - Count fall cycles only in FALL state
   - Transition to SPLAT if fall_cycles > 20 when ground returns

4. Output Logic:
   - Direct mapping from state and direction
   - SPLAT state zeros all outputs

Key Simplifications:
- Reduced state encoding (3 main states + SPLAT condition)
- Clear priority structure in single always block
- Simplified output assignments
- Combined direction tracking with state logic
