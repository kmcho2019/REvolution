Novel Architecture Idea:
1. Hierarchical State Machine: Split behavior into two layers - movement states (LEFT, RIGHT) and action states (WALK, FALL, DIG, SPLAT)
2. Direction Tracking: Maintain direction as a separate state that persists through action state changes
3. Edge Detection: Use edge detection for ground transitions to precisely time state changes
4. Fall Timer: Implement a saturating counter for fall duration to prevent overflow
5. Priority Encoder: Use explicit priority encoding for simultaneous events (fall > dig > bump)

Key Innovations:
- Separates movement direction from actions for cleaner state transitions
- Edge detection ensures precise timing for ground-related events
- Explicit priority handling through structural coding
- Saturating counter simplifies splatter condition check
- Clear separation of concerns in state management
