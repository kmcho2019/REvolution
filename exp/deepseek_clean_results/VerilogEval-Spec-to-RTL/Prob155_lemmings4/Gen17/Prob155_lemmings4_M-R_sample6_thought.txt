Refactored State Machine with Explicit Direction Tracking:

1. Key Changes:
   - Separate direction tracking from state using an additional register
   - Simplify state encoding to focus on behavior rather than direction
   - Use continuous assignments for outputs where possible
   - Explicitly track original direction during falls and digs

2. New State Encoding:
   - WALK: Walking (direction tracked separately)
   - DIG: Digging
   - FALL: Falling
   - SPLAT: Dead state

3. Improvements:
   - Clear separation between behavior state and direction
   - Easier to maintain original direction during falls/digs
   - More straightforward priority handling
   - Reduced state space (4 states instead of 6)

4. Implementation Approach:
   - Use always block for sequential logic (state transitions)
   - Use assign for combinational outputs
   - Track direction separately with a register
   - Maintain fall counter explicitly
