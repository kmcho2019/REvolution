Refactoring Strategy:
1. Use binary encoding for states to reduce logic complexity
2. Separate state transition logic into a combinational always block
3. Use sequential always block only for state updates
4. Implement priority handling through explicit condition ordering
5. Make direction changes synchronous with state updates
6. Use continuous assignments for outputs to match Moore machine behavior

Key Changes:
- Binary state encoding: WALK=0, FALL=1, DIG=2, SPLAT=3
- Combinational next_state logic
- Explicit fall counter reset conditions
- Clear priority ordering in transition logic
- Output assignments directly from state and direction
