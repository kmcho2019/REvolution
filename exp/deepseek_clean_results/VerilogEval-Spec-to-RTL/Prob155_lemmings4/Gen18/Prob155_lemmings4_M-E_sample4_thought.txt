Novel Lemming State Machine Architecture:

1. **Hierarchical State Design**: Implement a two-level state machine with primary states (WALKING, DIGGING, FALLING, SPLATTER) and secondary direction states (LEFT, RIGHT) for cleaner separation of concerns.

2. **Event Queue System**: Use a priority encoder to handle concurrent events (fall, dig, bump) in the correct order of precedence, ensuring proper behavior when multiple events occur simultaneously.

3. **Direction Preservation**: Maintain original walking direction during falls and digging using a separate register that only updates during walking state transitions.

4. **Fall Timer with Edge Detection**: Implement a precise fall duration counter with edge detection for ground transitions to accurately determine splatter conditions.

5. **Output Generation Logic**: Simplify output generation by combining state and direction information in a structured way, with explicit handling of the splatter state.

Key Innovations:
- Clear separation of movement states and direction states
- Explicit event prioritization through dedicated logic
- Robust preservation of original walking direction
- Accurate fall duration measurement
- Clean output generation structure
