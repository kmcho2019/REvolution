Refactored State Machine with Clear Priority Handling:

1. Key Improvements:
   - Explicit priority handling: fall > dig > bump
   - Simplified state encoding with clear transitions
   - Combined direction and state in one register for compactness
   - More straightforward output logic

2. New State Encoding:
   - WL: Walking Left
   - WR: Walking Right
   - DL: Digging Left
   - DR: Digging Right
   - FL: Falling Left
   - FR: Falling Right
   - SPLAT: Dead state

3. Implementation Approach:
   - Use single always block for state transitions
   - Track direction as part of state encoding
   - Maintain fall counter explicitly
   - Use continuous assignments for outputs
   - Clear priority handling in state transitions

4. Benefits:
   - More explicit state transitions
   - Clearer priority handling
   - More compact state representation
   - Easier to verify against requirements
