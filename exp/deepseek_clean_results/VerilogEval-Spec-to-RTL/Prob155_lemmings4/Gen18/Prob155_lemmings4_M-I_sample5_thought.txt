Improved Lemming State Machine Design:

1. **State Encoding Optimization**: Simplify to 4 primary states (WALK, DIG, FALL, SPLAT) with direction as a separate register
2. **Priority Handling**: Explicitly implement the priority order (fall > dig > bump) in state transitions
3. **Fall Timer Logic**: Only increment timer when actually falling (ground=0)
4. **Bump Handling**: Properly handle simultaneous left/right bumps by toggling direction
5. **Output Logic**: Maintain Moore machine properties with outputs purely dependent on current state

Key Improvements:
- Clearer state transition logic with explicit priority handling
- More accurate fall timer behavior
- Correct handling of simultaneous bump events
- Simplified output generation
- Better separation of concerns between state and direction
