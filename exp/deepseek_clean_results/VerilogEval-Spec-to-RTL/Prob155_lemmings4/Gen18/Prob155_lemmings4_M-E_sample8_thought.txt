Novel Lemming State Machine Architecture:

1. **Parallel State Tracking**: Instead of a single state variable, use parallel state machines for movement (left/right) and action (walk/dig/fall/splatter) to simplify transitions
2. **Event Queue System**: Implement a prioritized event queue that processes inputs in the correct order (fall > dig > bump)
3. **Smart Timer**: Use a configurable timer module that automatically handles reset conditions and threshold checking
4. **State Mirroring**: Maintain shadow copies of critical states to ensure clean transitions during asynchronous events
5. **Output Matrix**: Generate outputs through a combinatorial matrix that considers both current and next states

Key Innovations:
- Parallel state tracking reduces complex nested conditions
- Event queue guarantees proper input prioritization
- Smart timer simplifies fall duration management
- State mirroring prevents glitches during transitions
- Output matrix ensures clean output generation
