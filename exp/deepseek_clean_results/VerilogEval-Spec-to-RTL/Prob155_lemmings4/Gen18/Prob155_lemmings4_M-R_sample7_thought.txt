Refactored Lemming State Machine:

1. **State Encoding**: Use explicit state parameters with one-hot encoding for clarity and simpler output logic
2. **Direction Tracking**: Maintain direction as a separate register, updated only during walking states
3. **Fall Counter**: Implement as a separate always block for better timing control
4. **Priority Handling**: Structure state transitions with explicit priority (fall > dig > bump)
5. **Output Logic**: Simplify using continuous assignments based on state bits

Key Improvements:
- Clear separation of state transitions and direction logic
- Explicit priority handling in state transitions
- Better organization of fall counter logic
- Simplified output generation
- More robust state encoding
