Improved Design Strategy:

1. State Machine Enhancement:
   - Separate WALK_LEFT and WALK_RIGHT states for clearer direction control
   - Explicit FALL state with counter for splatter detection
   - Dedicated DIG state with proper entry/exit conditions
   - Final SPLAT state that locks all outputs

2. Priority Handling:
   - Implement strict fall > dig > bump priority
   - Only process bumps when in walking states with ground=1
   - Ignore bumps during falling/digging

3. Direction Management:
   - Explicit direction switching based on bump inputs
   - Preserve direction after falling/digging

4. Fall Counter:
   - Reset when entering FALL state
   - Check splatter condition only when ground reappears
   - Count only while actually falling (ground=0)

5. Output Logic:
   - Direct mapping from state to outputs
   - All outputs zero in SPLAT state
   - Clear separation of walking directions
