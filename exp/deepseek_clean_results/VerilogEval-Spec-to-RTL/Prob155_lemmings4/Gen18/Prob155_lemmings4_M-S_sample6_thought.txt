Simplified Lemming State Machine Design:

1. **State Encoding**: Use 4 distinct states (LEFT, RIGHT, FALLING, DIGGING) plus SPLATTER for final state
2. **Priority Handling**: Implement priority through nested if-else in next-state logic (fall > dig > bump)
3. **Fall Timer**: Simple counter that increments while falling and resets otherwise
4. **Direction Logic**: Maintain direction as part of state rather than separate register
5. **Output Generation**: Directly derive outputs from current state

Key Simplifications:
- Eliminated hierarchical state encoding in favor of flat states
- Removed separate direction registers by encoding direction in state
- Simplified priority handling with direct conditional logic
- Reduced number of registers needed
- Maintained all required functionality with cleaner structure
