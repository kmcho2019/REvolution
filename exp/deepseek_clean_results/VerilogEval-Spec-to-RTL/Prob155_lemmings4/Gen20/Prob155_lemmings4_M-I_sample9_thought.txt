Improved Lemming State Machine Design:

1. **State Encoding**: Use separate states for left/right walking to simplify direction tracking and make transitions clearer
2. **Explicit Priority Handling**: Implement strict priority ordering (fall > dig > bump) through nested conditionals
3. **Direction Preservation**: Maintain direction separately during falling/digging states
4. **Splat Handling**: Clear all outputs in SPLAT state with dedicated condition
5. **Timer Optimization**: Simplify fall timer logic with direct comparison
6. **Output Generation**: Make outputs purely dependent on current state for clean Moore machine behavior

Key Improvements:
- Clear state transitions with proper priority enforcement
- Maintained direction consistency across states
- Simplified output logic
- More robust splat condition handling
- Better organization of sequential logic
