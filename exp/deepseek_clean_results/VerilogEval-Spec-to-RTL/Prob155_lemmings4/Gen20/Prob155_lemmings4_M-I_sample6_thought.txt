Improved Lemming State Machine Design:

1. **State Encoding**: Use separate states for each behavior (WALK_L, WALK_R, FALL_L, FALL_R, DIG_L, DIG_R, SPLAT) to explicitly track direction during actions
2. **Priority Handling**: Implement strict priority ordering: falling > digging > direction change
3. **Direction Preservation**: Maintain direction information during falls and digging
4. **Splat Condition**: Clear all outputs when in SPLAT state
5. **Edge Case Handling**: Properly handle simultaneous bumps and transitions between states

Key Improvements:
- Explicit direction tracking in all states
- Clear priority implementation through state ordering
- Simplified output logic with direct state mapping
- Proper handling of all edge cases
- More robust state transitions
