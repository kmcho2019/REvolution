Refactored Lemming State Machine Design:

1. **State Encoding**: Keep one-hot encoding but simplify to 3 active states (WALK, DIG, FALL) plus SPLAT
2. **Direction Logic**: Separate direction register with simpler toggle logic
3. **Priority Handling**: Use nested if-else to enforce fall > dig > bump priority
4. **Fall Counter**: Move counter increment to separate always block for clarity
5. **Output Logic**: Use continuous assignments for Moore outputs
6. **State Transitions**: Make transitions more explicit with clear conditions

Key Changes:
- Simplified state transition logic with strict priority ordering
- Separated direction logic from state transitions
- More explicit fall counter handling
- Cleaner output assignments
- Better handling of simultaneous conditions
