Novel Approach:
1. Separate the state machine into two parts: movement (left/right) and action (walk/fall/dig/splat)
2. Use a counter for fall duration that only increments during falling
3. Implement priority logic in the action state transitions (fall > dig > bump)
4. Movement state changes only occur during walking state and when bumped
5. Clear separation of concerns between movement direction and current action
6. Explicit handling of all edge cases with priority-based state transitions
