Novel Lemming State Machine Design:

1. Hierarchical State Machine Approach:
   - Split behavior into two layers: Movement (LEFT/RIGHT) and Action (WALK/DIG/FALL/SPLAT)
   - Movement state tracks direction independently from action state
   - Enables cleaner handling of direction persistence during actions

2. Event-Driven Priority System:
   - Implement explicit priority checks before state transitions
   - Fall detection has highest priority, checked first
   - Dig conditions evaluated only if not falling
   - Bump handling only in WALK state with ground

3. Smart Fall Counter:
   - Separate counter module that only increments during FALL state
   - Automatic reset when leaving FALL state
   - Splat condition checked at ground re-entry

4. Output Generation:
   - Movement outputs derived from movement state when in WALK
   - Action outputs directly from action state
   - Clear combinatorial logic with no ambiguous cases

Key Innovations:
- Decoupled movement and action states for better maintainability
- Explicit priority checking prevents race conditions
- Modular fall counter implementation
- Clear separation of concerns in state management
