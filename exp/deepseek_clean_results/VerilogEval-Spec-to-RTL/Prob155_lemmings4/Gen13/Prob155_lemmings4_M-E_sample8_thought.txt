Novel Lemming State Machine Design:

1. Split State and Direction:
   - Separate the state (walking, falling, digging, splattered) from direction (left/right)
   - Uses two registers: one for state, one for direction
   - Reduces state space complexity

2. Priority-Based Transition Logic:
   - Explicitly implements the priority order: fall > dig > bump
   - Uses nested if-else structure for clear priority handling

3. Fall Timer Optimization:
   - Timer only increments when falling and ground=0
   - Resets automatically when not falling

4. Output Generation:
   - Outputs derived directly from current state and direction
   - Simple combinational logic for clear behavior

Key Advantages:
- More intuitive state representation
- Clear priority handling in transition logic
- Reduced state encoding complexity
- Easier to modify/extend behavior
