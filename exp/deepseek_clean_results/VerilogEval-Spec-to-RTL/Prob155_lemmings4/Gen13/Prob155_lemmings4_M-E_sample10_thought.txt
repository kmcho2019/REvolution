Novel Lemming State Machine Design:

1. State Encoding Optimization:
   - Use separate state and direction registers for more modular design
   - Direction is stored independently (left/right) while state indicates behavior (walk/fall/dig/splatter)

2. Simplified State Transitions:
   - Main states: WALK, FALL, DIG, SPLATTER
   - Direction tracked separately to reduce state combinations

3. Priority-Based Logic:
   - Explicit priority handling (fall > dig > bump) in transition logic
   - Clear separation of concerns between state and direction changes

4. Fall Timer Integration:
   - Separate counter for fall duration
   - Reset timer when not falling

Key Advantages:
- More modular and easier to extend
- Clear separation between movement direction and behavior state
- Explicit priority handling makes logic more readable
- Reduced state combinations compared to combined encoding
