Revised Lemming State Machine Design:

1. State Machine Structure:
   - Maintain 5 states (WALK, DIG, FALL, SPLAT) with direction tracking
   - Explicit state transitions with clear priority enforcement

2. Priority Handling Fixes:
   - Strict ordering: FALL (ground=0) > DIG > BUMP
   - Nested conditionals to ensure proper priority
   - Separate checks for each priority level

3. Direction Switching:
   - Handle simultaneous bumps (both left and right) by always switching direction
   - Only change direction in WALK state when not falling or digging

4. Fall Counter Correction:
   - Increment counter only in FALL state when ground=0
   - Reset counter when leaving FALL state
   - Check splat condition only when ground returns (fall_counter > 20)

5. Digging Conditions:
   - Only enter DIG state from WALK when ground=1 and dig=1
   - Stay in DIG until ground=0, then transition to FALL

6. Output Logic:
   - Direct mapping from state and direction
   - All outputs zero in SPLAT state

Key Improvements:
- Clear priority enforcement through nested conditionals
- Proper handling of simultaneous bumps
- Accurate fall counter management
- Correct dig input conditions
- Maintained separation of state and direction
