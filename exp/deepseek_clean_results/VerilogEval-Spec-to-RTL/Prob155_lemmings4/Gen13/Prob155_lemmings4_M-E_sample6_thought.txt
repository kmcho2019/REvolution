Here's a novel approach using a hierarchical state machine with two main layers:
1. Primary state (walking/falling/digging/splatter)
2. Direction state (left/right)

Key innovations:
- Separates direction tracking from primary state
- Uses a dedicated "last_direction" register that persists through falls/digs
- Implements fall timer with explicit reset conditions
- Uses parallel state machines for cleaner transitions
- Employs priority encoders for input handling

The design maintains:
- Clear separation of concerns
- Explicit state preservation
- Correct priority handling (fall > dig > bump)
- Proper timer management
- Clean output generation
