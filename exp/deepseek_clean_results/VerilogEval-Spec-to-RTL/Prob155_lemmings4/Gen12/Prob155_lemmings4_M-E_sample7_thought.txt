Novel Lemming State Machine Design:

1. Hierarchical State Approach:
   - Split behavior into three main modes: WALKING, FALLING, DIGGING
   - Each mode tracks direction separately for cleaner transitions

2. Timeout Counter Integration:
   - Embed fall timer directly in FALLING state logic
   - Clear separation between timer counting and state transitions

3. Input Priority Encoding:
   - Explicit priority encoder for input handling (fall > dig > bump)
   - Prevents ambiguous transition conditions

4. State Preservation:
   - Maintain previous walking direction during falls/digs
   - Special handling for splatter condition

Key Innovations:
- Clear separation of mode and direction tracking
- Explicit input priority handling
- Integrated timeout counter with state machine
- More maintainable state transition logic
- Better matches problem's natural hierarchy
