Simplified Lemming State Machine:

1. States: Only 4 states needed (WALK, DIG, FALL, SPLAT)
2. Direction: Track separately with single bit (1=left, 0=right)
3. Priority Logic:
   - First check for falling (ground=0)
   - Then check for dig if grounded
   - Finally handle bumps if neither falling nor digging
4. Fall Counter: 
   - Count cycles only in FALL state
   - Splat if >20 cycles when ground returns
5. Outputs: 
   - Directly derived from state and direction
   - All zero in SPLAT state
6. Reset: Initialize to WALK left
