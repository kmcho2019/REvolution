2. **Separate Direction Tracking**: Maintains direction independently from state to properly preserve it during falls and digs.

3. **Simplified Output Logic**: Uses direct assignments from state registers for cleaner output generation.

4. **Consolidated Transition Logic**: Combines all state transitions into a single always block with clear priority ordering.

5. **Improved Timer Handling**: Explicitly checks timer value when ground reappears to properly implement splatter condition.

- Clearer state transition priorities
- Proper direction preservation
- Correct timer handling
- More maintainable structure
