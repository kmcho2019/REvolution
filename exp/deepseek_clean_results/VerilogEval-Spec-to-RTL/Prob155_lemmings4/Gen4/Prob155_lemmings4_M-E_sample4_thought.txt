Here's a novel approach that separates the direction and action states into orthogonal state machines, using a hierarchical FSM design:

1. **Direction FSM**: Tracks walking direction (left/right) independently
2. **Action FSM**: Handles the current action (walking/falling/digging/splat)
3. **Priority Encoder**: Resolves conflicts between actions based on precedence
4. **Fall Timer**: Counts cycles while falling, resets when not falling
5. **State Preservation**: Saves direction during non-walking actions

Key innovations:
- Orthogonal state machines reduce transition complexity
- Explicit priority encoding ensures correct behavior
- Clean separation of concerns between direction and action
- Efficient state encoding with minimal registers
- Clear handling of edge cases through modular design
