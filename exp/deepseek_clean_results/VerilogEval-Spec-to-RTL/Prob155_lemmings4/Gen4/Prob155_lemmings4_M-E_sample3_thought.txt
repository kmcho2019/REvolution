I'll implement a novel hierarchical state machine approach with these key features:

1. **Separate Direction Tracking**: Use a dedicated register to track walking direction independently of the main state, simplifying direction management during falls/digs.

2. **Explicit Priority Logic**: Implement a clear priority scheme (fall > dig > bump) using separate condition checks before state transitions.

3. **Fall Duration Tracking**: Use a counter that only increments during falls and resets when not falling, with splat detection when ground reappears.

4. **State Encoding**: Use binary encoding for compactness while maintaining readability with named parameters.

5. **Output Generation**: Derive outputs directly from current state and direction register for clean Moore-style outputs.

The architecture separates concerns:
- Direction management (left/right)
- Primary activity (walk/fall/dig/splat)
- Fall duration tracking
This makes the state transitions more explicit and easier to verify.
