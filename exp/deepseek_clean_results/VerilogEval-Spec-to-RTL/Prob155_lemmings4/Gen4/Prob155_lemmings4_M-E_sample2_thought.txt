Here's a novel approach using a hierarchical state machine with three main states (WALKING, FALLING, DIGGING) and sub-states for walking direction. Key innovations:

1. Direction is tracked separately from main state using a direction register
2. Fall duration is tracked with a counter that only increments when falling
3. State transitions follow strict priority: falling > digging > direction change
4. Outputs are purely combinational based on current state and direction
5. Splat condition is checked when ground reappears after falling

This architecture simplifies the state transitions by separating concerns:
- Main state handles falling/digging/walking
- Direction register handles left/right walking
- Fall counter is only active during falling
- All outputs are simple combinations of state and direction
