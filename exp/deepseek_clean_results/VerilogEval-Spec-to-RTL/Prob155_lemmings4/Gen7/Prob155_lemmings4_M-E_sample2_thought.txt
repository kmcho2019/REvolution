Novel approach using hierarchical state machines:

1. **Direction and Action Separation** - Use two independent state machines: one for direction (left/right) and one for action (walk/fall/dig/splat)
2. **Fall Time Tracking** - Implement a separate fall timer module that counts cycles and signals when splat condition is met
3. **Priority Encoder** - Use a priority encoder to handle the fall > dig > bump precedence explicitly
4. **State Transition Matrix** - Create a clear transition matrix for action states with all conditions
5. **Output Decoder** - Simple combinational logic for outputs based on current states

This approach provides better modularity and makes the state transitions more explicit and maintainable.
