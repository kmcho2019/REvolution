Revised Lemming State Machine Design:

1. Strict Priority Enforcement:
   - Fall condition (ground=0) checked first in all walking/digging states
   - Dig condition only considered if ground=1
   - Bump conditions only considered if neither falling nor digging

2. Simplified Direction Tracking:
   - Remove separate direction register
   - Use state encoding to implicitly track direction
   - Eliminate potential race conditions

3. Robust Fall Counter:
   - Clear counter when not falling
   - Properly handle splat condition after exactly 20 cycles
   - Only increment counter when actually falling (ground=0)

4. Complete State Transitions:
   - Explicitly handle all edge cases:
     - Falling while digging
     - Dig command while falling
     - Simultaneous bump inputs
   - Maintain digging state until ground disappears

5. Correct Output Generation:
   - Ensure outputs match problem requirements
   - All outputs zero in SPLAT state
   - Proper aaah during falling
   - Correct digging output during dig states

Key Improvements:
- Clear priority hierarchy implementation
- Simplified state management
- Accurate fall counter handling
- Comprehensive edge case coverage
- Correct output behavior in all states
