Novel approach using hierarchical state machines with parallel execution:

1. **Direction and Action Separation** - Implement two parallel state machines: one for direction (left/right) and one for action (walk/fall/dig/splat)
2. **Event-Driven Transitions** - Use edge detection on ground and dig signals for cleaner state transitions
3. **Fall Timer as Separate Module** - Encapsulate the fall counter logic in a dedicated submodule
4. **State Encoding Optimization** - Use one-hot encoding for faster state transitions and simpler decoding
5. **Output Generation** - Generate outputs combinatorially based on current state

This architecture provides better modularity and clearer separation of concerns while maintaining all required functionality.
