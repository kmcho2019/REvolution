Revised Lemming State Machine Design:

1. State Machine Restructuring:
   - Single unified state machine with clear priority handling
   - States: WALK_LEFT, WALK_RIGHT, DIG_LEFT, DIG_RIGHT, FALL_LEFT, FALL_RIGHT, SPLAT
   - Combines direction with activity for simpler transitions

2. Explicit Priority Implementation:
   - Falling has highest priority (ground=0)
   - Digging has middle priority (dig=1 & ground=1)
   - Bumping has lowest priority (only in walking states with ground)

3. Improved Fall Logic:
   - Separate fall counter that increments only when in FALL states
   - Splat condition checked only when ground returns after falling
   - Counter resets when leaving FALL states

4. Direction Persistence:
   - Direction preserved during DIG and FALL states
   - Only updated in WALK states when bumped

5. Output Generation:
   - Direct mapping from state to outputs
   - Clear conditions for each output signal

Key Fixes:
- Proper priority handling between falling, digging, and bumping
- Correct direction switching only in walking states
- Accurate fall duration counting and splat condition
- Simplified state transitions with combined direction/activity states
