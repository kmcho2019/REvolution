Simplified Lemming State Machine:

1. Combined State and Direction:
   - Single state register that encodes both behavior and direction
   - States: WALK_LEFT, WALK_RIGHT, FALL_LEFT, FALL_RIGHT, DIG_LEFT, DIG_RIGHT, SPLATTERED

2. Direct Transition Logic:
   - No separate event detection wires
   - Priority handled directly in state transition logic

3. Fall Counter:
   - Simple counter that increments when falling
   - Resets when not falling or when hitting ground

4. Outputs:
   - Directly derived from current state

Key Simplifications:
- Eliminated separate direction tracking
- Removed intermediate event detection logic
- Simplified state transitions with direct conditions
- Maintained all required functionality
