Novel Lemming State Machine Architecture:

1. Key Innovations:
   - Hierarchical state machine design with two layers:
     * Primary states (WALKING, DIGGING, FALLING, SPLAT)
     * Secondary direction state (LEFT, RIGHT)
   - Explicit priority encoder for input handling (fall > dig > bump)
   - Separate direction state machine that only updates when in WALKING state
   - Fall duration tracking with early termination optimization

2. State Transition Logic:
   - WALKING: Checks ground first, then dig, then bumps
   - DIGGING: Only active when ground=1, exits immediately on ground loss
   - FALLING: Tracks cycles, transitions to SPLAT or WALKING based on duration
   - SPLAT: Terminal state with all outputs disabled

3. Output Generation:
   - Outputs derived combinatorially from current state and direction
   - Mutual exclusion enforced by state encoding

4. Optimizations:
   - Minimal state encoding (2 bits for primary state + 1 bit for direction)
   - Single-cycle state transitions
   - Efficient fall counter with synchronous clear
   - Clear separation of concerns between movement and action states
