Refactored Lemming State Machine:

1. State Machine Restructuring:
   - Use separate always blocks for state transitions and output logic
   - Explicitly define all state transitions with clear priorities
   - Maintain walking direction as a separate register

2. Improved Direction Handling:
   - Properly handle simultaneous left/right bumps by prioritizing direction switch
   - Preserve direction during fall and dig states

3. Clear Priority Implementation:
   - Fall has highest priority (ground=0)
   - Dig comes next (when ground=1)
   - Direction change is last (when bumped)

4. Output Logic:
   - Use continuous assignments for outputs
   - Ensure outputs reflect current state and direction
   - All outputs forced to 0 in SPLAT state

5. Fall Counter:
   - Reset counter when entering fall state
   - Increment only while falling
   - Check splat condition when landing

6. Asynchronous Reset:
   - Initialize to walk left with all outputs off
   - Clear fall counter on reset
