Novel Lemming State Machine Design:

1. Unified State Encoding:
   - Combine movement and action into a single state register with orthogonal encoding
   - 3-bit state: {falling_flag, digging_flag, direction_bit}
   - Splat condition tracked separately as it's terminal

2. Time-to-Live Counter:
   - Implement a saturating counter for fall duration
   - Only increments during falling state
   - Resets when leaving falling state

3. Event-Driven Transitions:
   - Use edge detection on ground signal to precisely time state changes
   - Falling starts on ground=0, ends on ground=1
   - Digging starts on dig=1 when conditions met

4. Priority-Based State Selection:
   - Implement a cascaded priority mux for next state logic
   - Fall > Dig > Bump > Continue current action
   - Each condition checked only if higher priorities aren't met

5. Output Decoding:
   - Simple combinational logic from current state
   - Special case for splat state overrides all outputs

Key Advantages:
- Compact state representation
- Precise timing of falling transitions
- Clear priority handling through cascaded logic
- Efficient implementation with minimal registers
