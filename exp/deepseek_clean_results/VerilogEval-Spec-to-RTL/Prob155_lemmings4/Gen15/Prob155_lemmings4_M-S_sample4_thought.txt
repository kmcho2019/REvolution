Simplified Lemming State Machine Design:

1. Combined State Approach:
   - Use a single state register that encodes both action and direction
   - Eliminates separate direction tracking, reducing complexity

2. Direct Priority Handling:
   - Implement priority checks directly in state transitions
   - Fall > Dig > Bump priority handled in state machine logic

3. Minimal Fall Counter:
   - Only count while falling and ground=0
   - Reset counter when not falling or when ground=1

4. Simplified Output Logic:
   - Outputs directly derived from current state
   - No complex combinational logic needed

Key Simplifications:
- Fewer state variables (no separate direction register)
- More straightforward state transitions
- Reduced logic complexity while maintaining all functionality
- Easier to understand and verify
