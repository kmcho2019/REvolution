Here's a simplified approach that maintains all functionality while reducing complexity:

1. Single FSM approach with 4 main states: WALK, FALL, DIG, SPLAT
2. Direction tracking is separate from state, stored in a simple register
3. Priority handling is explicit in state transitions:
   - Fall has highest priority (ground=0)
   - Then dig (when ground=1)
   - Then direction change (when walking)
4. Fall counter only increments during FALL state
5. Outputs are directly derived from current state and direction
6. Splat state is terminal (until reset)

Key simplifications:
- Eliminated parallel FSMs in favor of single FSM
- Simplified direction tracking to a single bit
- Clear priority encoding in state transitions
- Direct output assignments without unnecessary gating
