Here's a simplified approach that maintains all functionality while reducing complexity:

1. Single FSM approach with combined state tracking:
   - 4 main states: WALK, FALL, DIG, SPLAT
   - Direction (left/right) stored as a separate register
   - Fall counter integrated directly into FSM

2. Key simplifications:
   - Eliminated parallel FSMs - single state machine handles all behaviors
   - Simplified direction tracking - just one register for left/right
   - Direct output assignments based on current state
   - Clear priority encoding in state transitions

3. Maintained functionality:
   - Direction preserved during falls/digs
   - Correct fall timer implementation
   - Proper splatter condition handling
   - Strict priority: fall > dig > direction change

4. Benefits:
   - Fewer state variables
   - More straightforward state transitions
   - Clearer output logic
   - Easier to verify correctness
