   - Clear separation of state transitions and output logic
   - Proper handling of fall counter with explicit reset conditions
   - More robust state transitions that account for all edge cases

2. State machine structure:
   - Maintain separate states for direction (left/right) and action (walk/fall/dig)
   - Add SPLAT state that locks all outputs
   - Explicit handling of fall counter with ground transitions

3. Priority handling:

   - Then check for dig conditions (only if not falling)
   - Finally handle bump conditions (only if walking normally)

4. Output logic:
   - Pure combinatorial assignments based on current state
   - Clear mapping from states to outputs
   - No complex saved direction logic needed

5. Fall counter:
