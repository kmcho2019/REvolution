To improve the Lemming state machine implementation, I'll make these key changes:

1. State Encoding:
   - Use one-hot encoding for states (WALK, FALL, DIG, SPLAT) for clearer state transitions
   - Track direction separately with a register

2. Simplified Logic:
   - Move all combinational logic to continuous assignments (assign statements)
   - Make state transitions more explicit with priority encoders
   - Separate the fall counter logic for clarity

3. Output Generation:
   - Derive outputs directly from current state and direction
   - Remove redundant conditions in output assignments

4. Reset Handling:
   - Clear all state variables on reset
   - Initialize to walking left state

The key improvements are:
- More explicit state transitions
- Clearer separation of combinational and sequential logic
- Better handling of priority rules (fall > dig > bump)
- Simplified output generation
