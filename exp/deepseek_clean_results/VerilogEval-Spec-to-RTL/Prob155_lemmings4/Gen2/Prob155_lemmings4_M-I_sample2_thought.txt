To improve the Lemming state machine, we'll focus on several key areas:

1. **State Encoding Optimization**: Use one-hot encoding for better timing and simpler state decoding, though it uses more flip-flops.

2. **Direction Preservation Enhancement**: Clearly track the walking direction before any state change, ensuring it's properly restored after falling/digging.

3. **Fall Counter Management**: 
   - Only count when actively falling (ground=0)
   - Reset counter when not falling or when ground reappears
   - Check splatter condition only when landing (ground transitions to 1)

4. **Priority Logic Refinement**: 
   - Falling has absolute priority
   - Digging only when grounded and not falling
   - Direction changes only when walking and not falling/digging

5. **Output Logic Simplification**: 
   - Directly derive outputs from state
   - Ensure splattered state overrides all outputs

6. **Reset Handling**: 
   - Clear all registers on reset
   - Initialize to walk left

The improved design will:
- Use one-hot state encoding
- Have cleaner state transitions
- More robust direction preservation
- Proper fall counter handling
- Clear output priorities
