To implement the Lemming behavior, we need a Moore state machine with multiple states and transitions. The key states are:
1. WALK_LEFT - walking left
2. WALK_RIGHT - walking right
3. FALL_LEFT - falling while originally walking left
4. FALL_RIGHT - falling while originally walking right
5. DIG_LEFT - digging while originally walking left
6. DIG_RIGHT - digging while originally walking right
7. SPLAT - splattered state

We also need a counter to track fall duration (20 cycles max). The state transitions follow these rules:
- Reset initializes to WALK_LEFT
- From walking states, check ground first (fall if 0), then dig input, then bump inputs
- While falling, ignore bumps and dig inputs
- Track original direction during fall/dig
- Splatter if fall duration exceeds 20 cycles when hitting ground
- Digging continues until ground disappears (then fall)
- Outputs are purely based on current state

The state machine will have synchronous transitions on clock edges with asynchronous reset.
