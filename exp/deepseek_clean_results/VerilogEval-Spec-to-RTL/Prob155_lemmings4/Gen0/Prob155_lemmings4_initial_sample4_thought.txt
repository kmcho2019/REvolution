To implement the Lemming behavior, we need a finite state machine (FSM) with multiple states and transitions. The key states are:
1. WALK_LEFT - walking left
2. WALK_RIGHT - walking right
3. FALLING - falling (ground=0)
4. DIGGING - digging (dig=1 and ground=1)
5. SPLATTERED - fell for more than 20 cycles before hitting ground

The FSM must:
- Handle direction changes when bumped (unless falling/digging)
- Transition to FALLING when ground disappears
- Transition to DIGGING when dig is asserted (only if walking on ground)
- Count fall duration and transition to SPLATTERED if >20 cycles
- Remember original direction after falling/digging
- Handle asynchronous reset to WALK_LEFT

The output logic will be purely based on the current state.
