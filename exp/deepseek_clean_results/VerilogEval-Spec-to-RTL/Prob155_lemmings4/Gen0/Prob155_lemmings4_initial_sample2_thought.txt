To implement the Lemming behavior, we need a Moore state machine with multiple states to handle walking left/right, falling, digging, and splattering. The key aspects are:

1. States:
   - WALK_LEFT: Walking left state
   - WALK_RIGHT: Walking right state
   - FALL: Falling state (when ground=0)
   - DIG: Digging state (when dig=1 and ground=1)
   - SPLAT: Splattered state (after falling >20 cycles)

2. State transitions:
   - Walking states switch direction when bumped (unless falling/digging)
   - Transition to FALL when ground=0 (highest priority)
   - Transition to DIG when dig=1 and ground=1 (if not falling)
   - Track fall duration with a counter (reset when not falling)
   - Transition to SPLAT if fall duration >20 when ground returns

3. Outputs:
   - Walk left/right based on current state
   - aaah during FALL state
   - digging during DIG state
   - All outputs 0 in SPLAT state

4. Asynchronous reset initializes to WALK_LEFT.
