To implement the Lemming behavior, we need a Moore state machine with multiple states and transitions. The key states are:
1. WALK_LEFT - walking left
2. WALK_RIGHT - walking right
3. FALL - falling (aaah)
4. DIG - digging
5. SPLAT - splattered (dead)

We'll also need a counter to track fall duration (20 cycles max). The state transitions follow these rules:
- Reset starts in WALK_LEFT
- Falling has highest priority when ground=0
- Digging comes next when dig=1 and on ground
- Bump direction changes come last
- After 20 fall cycles, landing causes SPLAT state
- All outputs are 0 in SPLAT state
- Outputs are set based on current state (Moore machine)

The state transitions must properly handle edge cases like simultaneous bumps or state change conditions.
