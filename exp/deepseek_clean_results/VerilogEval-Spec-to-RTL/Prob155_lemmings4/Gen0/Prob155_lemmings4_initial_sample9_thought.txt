To implement the Lemming behavior, we need a Moore state machine with multiple states and transitions. The key states are:
1. WALK_LEFT - walking left
2. WALK_RIGHT - walking right
3. FALL - falling (aaah)
4. DIG - digging
5. SPLAT - splattered (dead)

The state transitions are governed by:
- Bump signals change walking direction (unless falling/digging)
- Ground=0 causes falling (highest priority)
- Dig=1 causes digging (if on ground and not falling)
- Falling for >20 cycles causes splat when ground returns
- Reset initializes to WALK_LEFT

We'll need:
- A state register
- A counter for fall duration
- Output logic for each state
- Transition logic considering all conditions
