Let's implement the half adder using a novel approach based on majority and parity functions. The key insights are:

1. The sum output is equivalent to the parity (XOR) of the inputs, which can be expressed as (a + b) mod 2
2. The carry output is equivalent to the majority function of the inputs (AND)
3. We'll implement these functions using a combination of arithmetic and logical operations
4. This approach highlights the arithmetic nature of the half adder while maintaining simplicity

Benefits of this approach:
- Directly maps to the mathematical definition of binary addition
- Clearly separates the sum (parity) and carry (majority) functions
- Uses fundamental arithmetic concepts
- Easy to understand and verify
