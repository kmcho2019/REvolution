Here's a novel approach using a lookup table (LUT) implemented via a case statement. This method:
1. Treats the input combination as a 2-bit index (a,b)
2. Uses a case statement to directly map each input combination to the correct sum and cout outputs
3. Provides explicit enumeration of all possible input cases (more readable than bitwise operations)
4. Makes it trivial to modify the truth table if requirements change
5. Still synthesizes to the same optimal gates (XOR and AND) but with a different implementation style
6. Could be extended to more complex functions by simply adding more cases
