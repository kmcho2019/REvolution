This implementation uses:
1. One-hot state encoding (2 flip-flops) for potentially better timing
2. Explicit next-state logic equations derived from state transition table
3. Output derived from state bits (still Moore machine)
4. Asynchronous reset initializes to OFF state (01)

Key differences:
- Uses two state bits for one-hot encoding (OFF=01, ON=10)
- Next state logic uses direct boolean equations rather than conditional statements
- Output is OR of state bits (effectively just the second bit)
- May offer better timing due to parallel evaluation of transitions
