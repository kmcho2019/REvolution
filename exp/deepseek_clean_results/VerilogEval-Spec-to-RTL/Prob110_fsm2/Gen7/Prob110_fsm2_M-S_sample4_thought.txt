The existing solution is already quite minimal, but we can make it even simpler by:

1. Eliminating the explicit state register since we can directly compute the next state from inputs
2. Using a continuous assignment for the state transition logic
3. Maintaining the same Moore output behavior where out is simply the current state
4. Keeping the asynchronous reset functionality

This reduces the design to just a single always block and one assignment, making it extremely compact while preserving all functionality.
