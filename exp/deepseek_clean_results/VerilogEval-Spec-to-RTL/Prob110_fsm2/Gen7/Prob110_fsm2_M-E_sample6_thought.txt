Instead of using a traditional state register, we can implement the state machine using a toggle flip-flop concept where:
1. The state is represented by the output itself (Moore machine property)
2. State transitions are controlled by:
   - Set condition (j=1 in OFF state)
   - Reset condition (k=1 in ON state)
3. The output directly reflects the state without additional logic
This eliminates the need for explicit state comparisons and reduces the logic to just the essential transition conditions.
