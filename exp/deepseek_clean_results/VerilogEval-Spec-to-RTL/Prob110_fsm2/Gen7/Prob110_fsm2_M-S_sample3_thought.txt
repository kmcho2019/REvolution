The current solution is already quite minimal, but we can make it even simpler by:

1. Eliminating the explicit state register since we can directly compute the next state from inputs
2. Using a continuous assignment for the state transition logic instead of sequential always block
3. Maintaining the same behavior where:
   - Reset forces state to 0 (OFF)
   - State transitions follow the specified rules
   - Output is simply the state bit

This reduces the design to just two assignments while preserving all functionality.
