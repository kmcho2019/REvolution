This implementation uses a different architectural approach:
1. One-hot state encoding (2 flip-flops) instead of binary encoding
2. Explicit next-state logic equations derived from the state diagram
3. Output is simply the ON state flip-flop (still Moore machine)
4. Asynchronous reset clears both flip-flops (setting to OFF state)

The one-hot encoding makes state transitions more explicit and could potentially have better timing characteristics in more complex FSMs. While it uses slightly more flip-flops, the combinational logic remains simple.
