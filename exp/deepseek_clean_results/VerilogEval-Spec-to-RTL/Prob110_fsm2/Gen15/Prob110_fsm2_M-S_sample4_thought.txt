Simplification Strategy:
1. Since it's a 2-state machine, we can use a single register bit for state
2. The output is directly equal to the state (Moore machine)
3. State transitions can be expressed with minimal logic:
   - When in OFF state (0), transition to ON if j=1
   - When in ON state (1), transition to OFF if k=1
4. Asynchronous reset should set state to OFF (0)
5. No need for complex operators - simple if-else is most readable
