The state machine can be simplified by recognizing that:
1. The output is directly equal to the state (Moore machine)
2. The state transitions can be expressed more concisely using a single ternary operator
3. The asynchronous reset remains the same
4. We can eliminate the case statement since there are only two states

This reduces the logic to its minimal form while maintaining identical functionality. The state transition becomes a simple if-else based on current state and inputs.
