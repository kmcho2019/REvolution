The previous solution is already quite minimal, but we can simplify it further by:
1. Removing the intermediate state register and directly computing the output from the inputs
2. Recognizing that this is effectively a JK flip-flop with asynchronous reset
3. Using a single always block that combines state transition and output logic
4. Making the output assignment directly from the state bit (Moore machine property)
This results in an even more compact implementation while maintaining identical functionality.
