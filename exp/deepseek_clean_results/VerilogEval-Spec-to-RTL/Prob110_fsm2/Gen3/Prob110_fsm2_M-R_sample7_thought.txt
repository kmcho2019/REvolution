I'll refactor the state machine implementation while maintaining the same behavior. The key changes will be:
1. Use continuous assignments (assign) instead of procedural blocks for the next state logic
2. Eliminate the separate next_state register by computing the next state directly in the state register
3. Use a more compact state encoding with direct output assignment

This approach reduces the number of intermediate signals and combines the state transition logic directly into the state register update. The output remains purely combinational based on the current state (Moore machine).
