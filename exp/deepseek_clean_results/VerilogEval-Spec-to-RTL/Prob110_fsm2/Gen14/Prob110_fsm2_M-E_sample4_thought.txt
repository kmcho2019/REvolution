Here's a novel approach using a one-hot encoded state machine with implicit state transitions:

1. **One-Hot Encoding**: Instead of binary encoding, use one-hot for potential power and timing benefits in larger FSMs (though minimal here).

2. **Implicit State Logic**: Eliminate explicit state transitions by using the inputs directly to determine the next state.

3. **Output Generation**: Leverage the one-hot state directly as the output since it's a Moore machine.

4. **Reset Handling**: Maintain asynchronous reset but initialize to the one-hot OFF state.

This approach demonstrates an alternative implementation style that could scale better for more complex state machines while maintaining the same functionality.
