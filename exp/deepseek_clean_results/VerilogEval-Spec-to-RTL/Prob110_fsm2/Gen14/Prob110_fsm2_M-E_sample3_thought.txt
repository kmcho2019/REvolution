Here's a novel approach using a one-hot encoding scheme with two flip-flops instead of a single state register. The key innovations are:
1. Use one-hot encoding (01 for OFF, 10 for ON) which can simplify state transition logic
2. Implement the state machine using parallel logic for each state
3. Use a priority encoder style for state transitions
4. Maintain asynchronous reset functionality
5. The output is simply the second flip-flop's value

This approach may offer better timing characteristics in some technologies as the state transition logic becomes simpler AND/OR operations rather than multiplexers. It also makes the state representation more explicit in hardware.
