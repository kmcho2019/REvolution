The state machine can be simplified by recognizing that:
1. The output is directly tied to the state (Moore machine)
2. The state transitions can be expressed more concisely using a single conditional assignment
3. We can eliminate the case statement since there are only two states
4. The asynchronous reset remains straightforward

This reduces the logic to its minimal form while maintaining all functionality. The state transition becomes a simple if-else based on current state and inputs.
