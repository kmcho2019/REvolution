The original solution is already quite minimal, but we can simplify it further by:
1. Removing the localparam declarations since we only have two states that can be represented directly with 0/1
2. Combining the state register and output assignment into a single always block
3. Using implicit state encoding (0=OFF, 1=ON) which matches the output value directly

This maintains the same functionality while reducing the code size slightly. The output can be assigned directly from the state register since in a Moore machine the output only depends on the current state.
