I'll refactor the state machine implementation while maintaining the same functionality. Instead of using an always block for the state transitions, I'll implement the state machine using continuous assignments (assign statements) with a combinational next state logic and a separate state register. This approach separates the combinational logic from the sequential elements more explicitly.

Key changes:
1. Use explicit wire declarations for next_state
2. Move the state transition logic to combinational assign statements
3. Keep the output assignment the same (Moore style)
4. Maintain the asynchronous reset functionality

This refactoring makes the design more modular by clearly separating:
- Next state combinational logic
- State register (sequential element)
- Output logic
