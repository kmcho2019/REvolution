The problem requires implementing a Moore state machine with two states (OFF and ON) that transitions based on inputs j and k. The output (out) depends only on the current state. The state transitions are:
- In OFF state (out=0): stay in OFF if j=0, transition to ON if j=1
- In ON state (out=1): stay in ON if k=0, transition to OFF if k=1
The reset (areset) is asynchronous and active-high, forcing the state to OFF.

I'll use binary encoding for the states (0=OFF, 1=ON) and implement the state transitions with combinational logic for the next state and sequential logic for the state register.
