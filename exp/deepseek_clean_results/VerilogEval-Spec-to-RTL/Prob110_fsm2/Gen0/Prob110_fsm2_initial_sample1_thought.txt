The problem requires implementing a Moore state machine with two states (OFF and ON), two inputs (j and k), and one output (out). The state transitions are:
- In OFF state (out=0): stays in OFF if j=0, transitions to ON if j=1
- In ON state (out=1): stays in ON if k=0, transitions to OFF if k=1
The reset (areset) is asynchronous and active-high, forcing the state to OFF.

I'll use a simple two-state encoding (1'b0 for OFF, 1'b1 for ON) and implement the state transitions with combinational logic for next state and sequential logic for state storage.
