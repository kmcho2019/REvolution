The problem requires implementing a Moore state machine with two states (OFF and ON), two inputs (j and k), and one output (out). The state transitions are:
- In OFF state (out=0), stay in OFF if j=0, transition to ON if j=1
- In ON state (out=1), stay in ON if k=0, transition to OFF if k=1
The reset (areset) is asynchronous and active-high, resetting to OFF state.

I'll use a simple state register to hold the current state (OFF or ON) and combinational logic for next state and output. The output is purely dependent on the current state (Moore machine).
