The problem requires implementing a Moore state machine with two states (OFF and ON), two inputs (j and k), and one output (out). The state transitions are:
1. In OFF state (out=0), stay in OFF if j=0 or transition to ON if j=1
2. In ON state (out=1), stay in ON if k=0 or transition to OFF if k=1
The reset is asynchronous and active-high, setting the state to OFF.

I'll use a simple two-state FSM with combinational logic for next state and output. The state will be stored in a flip-flop with asynchronous reset.
