The problem requires implementing a Moore state machine with two states (OFF and ON) that transitions based on inputs j and k. The output (out) depends only on the current state. The state transitions are:
- From OFF: stays in OFF if j=0, moves to ON if j=1
- From ON: stays in ON if k=0, moves to OFF if k=1
The reset (areset) is asynchronous and active-high, forcing the state to OFF.

I'll use a simple two-state encoding (1'b0 for OFF, 1'b1 for ON) and implement the state transitions with combinational logic for the next state and sequential logic for the state register.
