This implementation uses a different architectural approach:
1. One-hot state encoding (2 bits) for explicit state representation
2. Separate combinational logic for next state calculation
3. Explicit state transition equations derived from truth tables
4. Maintains Moore machine property (output depends only on state)
5. Uses a dedicated output register for potential pipelining benefits

Key differences from previous solution:
- Explicit state encoding makes debugging easier
- Separates combinational and sequential logic clearly
- Potential for better timing due to separated next-state logic
- More scalable if states need to be added later
