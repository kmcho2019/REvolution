The state machine can be further simplified by recognizing that:
1. The output is identical to the state (Moore machine property)
2. The state transitions can be expressed as a simple conditional assignment without explicit state encoding
3. The asynchronous reset can directly initialize the state to 0 (OFF)
4. The entire logic can be compressed into a single always block with output assignment

This eliminates the need for a separate output assignment and makes the state transition logic more concise while maintaining identical functionality.
