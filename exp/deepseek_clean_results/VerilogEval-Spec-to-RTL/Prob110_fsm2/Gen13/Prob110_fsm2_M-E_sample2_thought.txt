Novel Architectural Idea:
Instead of using a traditional state register, we can implement this state machine using a T-flip-flop with enable. The T-flip-flop will toggle when:
1. In OFF state (Q=0) and j=1 (enable toggle)
2. In ON state (Q=1) and k=1 (enable toggle)

This approach:
- Eliminates explicit state transition logic by leveraging the T-flip-flop's natural behavior
- Reduces combinational logic to just the enable generation
- Maintains the same functionality with potentially better timing
- Uses a different architectural approach than standard state machine implementations
