The state machine can be further simplified by:
1. Recognizing the output is directly equal to the state (Moore machine)
2. Observing state transitions only depend on current state and one input each:
   - OFF->ON only needs j=1
   - ON->OFF only needs k=1
3. Using a single ternary expression for next state logic
4. Maintaining asynchronous reset for initialization

This eliminates the if-else structure and combines the transition logic into one concise expression.
