This implementation uses edge detection on the j and k inputs to trigger state changes:
1. Detect rising edges of j when in OFF state (using edge detector)
2. Detect rising edges of k when in ON state
3. The state toggles only when a valid edge is detected in the correct state
4. Asynchronous reset forces the state to OFF
This approach makes the state machine sensitive to input transitions rather than levels, which can be useful in certain applications where we want to respond to changes rather than sustained inputs.
