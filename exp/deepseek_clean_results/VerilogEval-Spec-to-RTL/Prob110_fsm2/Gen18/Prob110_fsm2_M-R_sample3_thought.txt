The refactored version will maintain the same Moore state machine behavior but implement it differently by:
1. Using continuous assignments for both state transitions and output
2. Representing the state machine as combinational logic feeding into a D flip-flop
3. Keeping the asynchronous reset functionality
4. Using ternary operators for more compact transition logic

Key changes:
- Replace the always block with assign statements
- Use a wire for the next state logic
- Feed this into a D flip-flop with async reset
- Maintain the same state encoding (0=OFF, 1=ON)
- Output remains directly tied to the state register
This approach shows an alternative implementation style while preserving identical functionality.
