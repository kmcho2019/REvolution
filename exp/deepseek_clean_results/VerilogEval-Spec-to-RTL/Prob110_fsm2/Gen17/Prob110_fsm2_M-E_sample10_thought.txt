Here's a novel approach using a one-hot encoded state machine with explicit state transitions:
1. Use one-hot encoding for states (2 bits for 2 states)
2. Implement next-state logic using bitwise operations
3. Generate output by OR-ing the state bits (since ON state is the only one with output=1)
4. Maintain asynchronous reset functionality

This approach offers:
- Clear separation of state encoding and output logic
- Potential for easier scaling if more states are added later
- Explicit state representation that's human-readable
- Same functionality but with a different implementation style
