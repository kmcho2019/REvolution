Here's a novel approach using a one-hot encoded state machine with implicit state transitions:

1. Instead of binary encoding, use one-hot encoding for states (2 bits for 2 states)
2. Implement state transitions using bitwise operations directly on the state bits
3. Use the output as a direct copy of the ON state bit
4. Leverage the asynchronous reset to initialize both state bits (OFF=01, ON=10)
5. This approach eliminates explicit state comparison logic and uses parallel bit operations

Benefits:
- Potentially faster state transitions due to parallel bit operations
- Simpler output logic (direct connection)
- More scalable if additional states are needed later
- Clear physical meaning for each state bit
