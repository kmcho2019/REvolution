Here's a novel approach using a one-hot encoding scheme with explicit state transition logic:

1. Instead of binary encoding, use one-hot encoding for states (2 flip-flops)
2. Implement explicit state transition logic with clear conditions
3. Use a separate combinational block for next state logic
4. Maintain asynchronous reset functionality
5. Output is simply the ON state flip-flop value

This approach offers:
- More explicit state transition conditions
- Potential for better timing due to simpler decoding
- Easier to extend if more states are added later
- Clear separation between state transition logic and state storage
