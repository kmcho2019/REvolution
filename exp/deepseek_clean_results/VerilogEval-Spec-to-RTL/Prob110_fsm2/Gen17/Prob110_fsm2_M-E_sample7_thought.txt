Here's a novel approach using a one-hot encoding scheme with explicit state transition logic. The key differences are:
1. Use two flip-flops to represent states in one-hot encoding (OFF=01, ON=10)
2. Implement next-state logic using direct boolean equations
3. Generate output from the state bits using a simple OR gate
4. Maintain asynchronous reset functionality

This approach eliminates the need for a case statement and might offer better timing characteristics in some synthesis scenarios since the state transitions are expressed as simple boolean operations. The one-hot encoding also makes the state transitions very explicit in the code.
