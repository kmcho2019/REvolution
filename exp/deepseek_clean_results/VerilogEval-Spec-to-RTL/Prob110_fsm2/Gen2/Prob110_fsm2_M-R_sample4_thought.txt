I'll refactor the state machine to use continuous assignments (assign statements) instead of procedural blocks (always) for the combinational logic. This approach:
1. Eliminates the need for separate next_state register
2. Uses a single always block for the state register
3. Implements state transitions and output logic purely with assign statements
4. Maintains the same Moore machine behavior and asynchronous reset

The key changes are:
- State transitions are now expressed as continuous assignments
- Output is still purely state-dependent (Moore)
- The state register remains synchronous with async reset
- The logic is more compact but functionally equivalent
