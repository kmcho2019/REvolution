Based on the feedback, we need to address two main issues:
1. Remove the initial value assignment to make it more universally synthesizable
2. Maintain the same functionality while ensuring clean register inference

The solution is to:
1. Remove the initial value assignment (let synthesis tools handle initialization)
2. Keep the same XOR feedback logic
3. Use non-blocking assignment for proper flip-flop behavior
4. Let the synthesis tool determine the initial state (which will typically be 0 for most FPGAs/ASICs)

This maintains all functional requirements while being more synthesis-friendly:
- Still positive edge-triggered
- Same XOR feedback logic
- No reset (as specified)
- Clean register inference
- Works across different synthesis tools
