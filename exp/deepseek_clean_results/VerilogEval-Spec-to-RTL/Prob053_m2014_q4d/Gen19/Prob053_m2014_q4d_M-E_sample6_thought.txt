Here's a novel approach using a clock-gated XOR feedback loop:
1. Instead of directly feeding the XOR output to the D flip-flop, we'll create a gated feedback path
2. The XOR operation will be performed combinationally outside the flip-flop
3. The flip-flop will store the result of the XOR operation only on clock edges
4. This separates the combinational logic from the sequential element explicitly
5. The architecture makes the data flow more visible and could be advantageous for certain synthesis optimizations
