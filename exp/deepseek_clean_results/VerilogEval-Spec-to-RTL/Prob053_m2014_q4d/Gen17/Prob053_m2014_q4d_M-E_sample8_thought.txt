Here's a novel approach using a T flip-flop instead of a D flip-flop:
1. The T flip-flop toggles its state when its input is 1
2. We'll use 'in' as the T input to control when to toggle
3. The flip-flop is positive edge-triggered by clk with no reset
4. This creates different behavior than the XOR feedback approach:
   - When in=1, the output toggles on clock edge
   - When in=0, the output remains the same
5. The output is simply the Q output of the T flip-flop
6. This implementation provides different functionality while still meeting the interface requirements
