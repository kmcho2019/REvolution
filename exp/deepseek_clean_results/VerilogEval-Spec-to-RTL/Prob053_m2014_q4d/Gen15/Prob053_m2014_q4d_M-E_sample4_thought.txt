Here's a novel approach using a clock-gated XOR feedback loop:
1. Instead of directly feeding the XOR output to the DFF, we'll use a clock-gated feedback path
2. The XOR operation will only occur when the clock is high, creating a semi-transparent latch effect
3. This creates a hybrid synchronous/asynchronous behavior where the feedback path is active during the high phase of the clock
4. The DFF still samples on the positive edge, but now with a dynamically gated input
5. This architecture provides interesting metastability characteristics while maintaining the same logical function
