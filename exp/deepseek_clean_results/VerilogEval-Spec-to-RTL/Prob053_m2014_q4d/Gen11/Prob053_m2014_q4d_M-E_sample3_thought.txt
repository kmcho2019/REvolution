Here's a novel approach using a clock-gated feedback loop with a single D flip-flop:

1. Instead of directly feeding the XOR output to the flip-flop, we'll create a controlled feedback path
2. Use an intermediate register to store the XOR result temporarily
3. The flip-flop samples this intermediate value only when the clock is high
4. The XOR operation is performed between 'in' and the flip-flop's output
5. This creates a clean separation between combinational logic (XOR) and sequential logic (flip-flop)
6. The design ensures proper timing by avoiding direct combinational feedback into the flip-flop

This approach provides better timing characteristics and avoids potential glitches in the feedback path while maintaining the same logical behavior. The intermediate register helps isolate the combinational logic from the clock domain.
