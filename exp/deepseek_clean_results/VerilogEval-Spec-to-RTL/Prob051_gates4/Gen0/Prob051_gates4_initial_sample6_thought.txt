To implement the TopModule, we need to create a combinational circuit that processes the 4-bit input in three different ways:
1. out_and: Logical AND of all 4 input bits
2. out_or: Logical OR of all 4 input bits
3. out_xor: Logical XOR of all 4 input bits
We can achieve this by using Verilog's bitwise operators applied to the entire input vector.
