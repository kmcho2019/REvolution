Here's a novel approach using a lookup table (LUT) implementation instead of direct logic gates:
1. Create a 4-bit input to 3-bit output LUT where each output bit represents one of the required functions
2. Pre-compute all possible 16 input combinations and their corresponding outputs
3. Use the input as an address to index into the LUT
4. Map the LUT outputs to the respective output ports
5. This approach demonstrates an alternative implementation that trades combinational logic for memory

Benefits:
- Shows a fundamentally different implementation strategy
- Illustrates how combinational logic can be implemented via memory
- Easily scalable to more complex functions
- Output timing is uniform regardless of function complexity
