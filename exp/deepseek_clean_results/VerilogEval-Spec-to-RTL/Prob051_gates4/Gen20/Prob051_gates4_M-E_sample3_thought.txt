Here's a novel approach using a lookup table (LUT) style implementation with a case statement. While this is less efficient than reduction operators for simple gates, it demonstrates an alternative architectural approach that could be useful in more complex scenarios where the logic isn't as straightforward. The case statement explicitly lists all possible input combinations and their corresponding outputs.

Key features:
1. Uses a single always block to compute all outputs
2. Explicitly defines output behavior for all 16 possible input combinations
3. Demonstrates an alternative to reduction operators
4. Could be extended to implement more complex, non-linear functions
