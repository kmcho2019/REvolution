To refactor the decade counter while maintaining the same functionality, I'll:
1. Separate the combinational next-state logic from the sequential state storage
2. Use an assign statement for the next-state calculation
3. Keep the synchronous reset and enable control
4. The combinational logic will calculate the next count value based on current state and slowena
5. The sequential block will only handle the state update

This approach makes the design more modular and potentially easier to optimize during synthesis.
