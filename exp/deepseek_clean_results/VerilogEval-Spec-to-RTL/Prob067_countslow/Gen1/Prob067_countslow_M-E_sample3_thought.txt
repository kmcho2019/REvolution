Novel approach: Implement the decade counter using a one-hot encoding scheme with shift register behavior. This provides:
1. Lower power consumption since only one bit changes per transition (except wrap-around)
2. Simpler comparison logic for wrap-around (just check the last bit)
3. Natural pause functionality by gating the shift enable
4. Reset initializes to first one-hot position
5. Each count value corresponds to a single bit position in the register
