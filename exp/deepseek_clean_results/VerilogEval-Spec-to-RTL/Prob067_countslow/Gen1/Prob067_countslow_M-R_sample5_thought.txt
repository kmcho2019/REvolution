Refactoring approach:
1. Separate the combinational next-state logic from the sequential state storage
2. Use an assign statement for the next-state calculation to make the logic more explicit
3. Keep the sequential part simple with just the register update
4. This separation makes the design more modular and potentially easier to optimize during synthesis
5. The combinational logic calculates the next count value based on current state and control signals
6. The sequential part simply updates the register on clock edges
