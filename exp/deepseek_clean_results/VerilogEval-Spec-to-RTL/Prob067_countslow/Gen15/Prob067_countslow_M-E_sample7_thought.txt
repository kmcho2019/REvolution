Novel Architecture Idea: State Machine with One-Hot Encoding
1. Instead of using a binary counter, implement the decade counter as a one-hot encoded state machine
2. Each state (0-9) is represented by a single bit in a 10-bit register
3. State transitions are simple bit shifts with wrap-around
4. Advantages:
   - Eliminates binary-to-decimal conversion logic
   - Simple terminal state detection (just check the last bit)
   - Lower switching activity (only two bits change per transition)
   - Natural power optimization since only one bit is active at a time
5. Implementation:
   - 10-bit one-hot state register
   - Simple shift-left with wrap-around for increment
   - Reset forces state to "0000000001" (state 0)
   - Output encoding converts one-hot to binary (4-bit)
