Novel Architectural Idea: State Machine with Explicit State Encoding
1. Instead of using binary counting logic, implement a 10-state finite state machine (FSM)
2. Each state explicitly represents one count value (0-9)
3. Transition between states occurs only when slowena is active
4. Synchronous reset forces the FSM back to state 0
5. Advantages:
   - More explicit state representation (easier to debug)
   - Potential for better timing as state transitions are simple increments
   - Clear separation between state transition logic and output encoding
   - Easier to modify if counting sequence needs to change
   - No complex combinational logic for decade detection
