Novel Architectural Idea: State Machine with Precomputed Next State
1. Instead of using arithmetic increment and comparison, implement a pure state machine approach
2. Precompute all next states in a combinational block for better timing predictability
3. Use a case statement for clear state transitions
4. Implement explicit clock gating through enable logic
5. Advantages:
   - Clear state transition logic that's easy to verify
   - No arithmetic operations in critical path
   - Predictable timing characteristics
   - Explicit enable handling for power optimization
   - Easily extensible if counter range needs to change
6. The state machine will cycle through 10 distinct states (0-9) and reset to 0 after 9
