Instead of a traditional binary counter, implement a pseudo-random decade counter using LFSR principles:
1. Use a 4-bit register like before, but with different state transitions
2. Implement a custom feedback polynomial that cycles through 10 states (0-9)
3. The feedback taps are chosen to create a maximal-length sequence of 10 states
4. Reset forces the counter to 0 (0000)
5. When enabled, the counter advances through the sequence using XOR feedback
6. This approach can potentially reduce power consumption as it minimizes simultaneous bit toggles
7. The sequence is carefully designed to cover all values 0-9 in order
