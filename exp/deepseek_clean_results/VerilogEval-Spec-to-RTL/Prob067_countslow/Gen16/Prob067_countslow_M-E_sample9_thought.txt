Novel Architecture Idea:
1. Use one-hot encoding (10 states) for the decade counter instead of binary counting
2. Implement as a circular shift register with enable logic
3. Advantages:
   - Eliminates need for increment logic and wrap-around detection
   - Each state transition is a simple shift operation
   - Naturally handles the 0-9 sequence without complex comparison
   - Lower power consumption since only one bit flips per transition
   - Simpler reset implementation (just set first bit)
4. Trade-offs:
   - Slightly larger area (10 flip-flops vs 4)
   - But potentially better timing and power characteristics
5. Implementation:
   - 10-bit register where only one bit is high at a time
   - Circular shift operation when enabled
   - Reset sets first bit high
