Novel Approach: State Machine with One-Hot Encoding
1. Instead of using a binary counter, implement a decade counter as a one-hot state machine
2. Each state (0-9) is represented by a single flip-flop being active
3. State transitions are controlled by simple shift operations with wrap-around
4. Benefits:
   - Eliminates binary-to-one-hot conversion for outputs
   - Simple state transition logic (just shift with wrap)
   - Natural power gating when slowena is low
   - Potentially better timing as there's no adder or comparator
   - Easier to decode individual states if needed later
5. Trade-offs:
   - Uses more flip-flops (10 vs 4 in binary)
   - But simpler combinational logic may offset this
