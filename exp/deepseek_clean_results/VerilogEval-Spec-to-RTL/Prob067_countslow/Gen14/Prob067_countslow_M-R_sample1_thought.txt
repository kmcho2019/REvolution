Refactoring approach:
1. Replace the always block with continuous assignments for combinational logic
2. Use a separate register for sequential elements
3. Split the logic into:
   - Next state calculation (combinational)
   - State register update (sequential)
4. This separation makes the design more modular and potentially more synthesis-friendly
5. The rollover detection is changed to explicit comparison with 9 (4'b1001) for clarity
6. Maintain same functionality with synchronous reset and enable
7. Potential benefits:
   - Clear separation of combinational and sequential logic
   - More explicit state transition logic
   - Easier to modify individual components
   - May help synthesis tools optimize better
