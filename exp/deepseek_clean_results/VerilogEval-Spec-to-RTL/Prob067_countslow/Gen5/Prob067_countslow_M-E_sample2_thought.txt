Novel approach: State machine implementation
1. Instead of using a binary counter, implement the decade counter as a state machine with 10 distinct states
2. Each state directly represents a digit from 0 to 9
3. Use one-hot encoding for state representation (10 flip-flops) which simplifies state transitions
4. Advantages:
   - Simple combinatorial logic for next state transitions
   - No need for comparators or adders
   - Natural progression through states
   - Easy to modify if counting sequence needs to change
5. Output q is derived from the state encoding
6. Reset initializes to state 0 (first one-hot bit set)
7. Enable (slowena) controls state progression
