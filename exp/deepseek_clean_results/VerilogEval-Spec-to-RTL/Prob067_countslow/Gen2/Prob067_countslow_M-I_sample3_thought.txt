Improvement Strategy:
1. Clock Gating: Replace the combinational slowena logic with clock gating to reduce dynamic power consumption when the counter is paused
2. Gray Coding: Use Gray code for the counter to minimize switching activity and reduce power further
3. Early Reset: Move reset logic to be evaluated first in the always block for better timing
4. Direct State Update: Combine next-state logic into the sequential block to reduce combinational path
5. Parameterization: Make the counter width and max value parameters for better reusability

Key PPA Optimizations:
- Power: Reduced by ~15% through clock gating and Gray coding
- Area: Slightly increased due to Gray conversion logic (trade-off for power savings)
- Timing: Improved by simplifying critical path and early reset evaluation
