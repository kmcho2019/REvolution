To implement a decade counter with the specified requirements:
1. Use a 4-bit register to store the counter value (q)
2. On each positive clock edge:
   - If reset is high, synchronously reset q to 0
   - Else if slowena is high, increment q by 1, wrapping around to 0 after reaching 9
   - Else, maintain current value of q
3. The counter should naturally wrap from 9 (1001) back to 0 (0000)
