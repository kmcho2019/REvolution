Novel approach: State machine with one-hot encoding
1. Instead of using binary counting, implement a one-hot encoded state machine with 10 states (0-9)
2. Each state corresponds to one count value, with only one bit active at a time
3. Use a circular shift register pattern for state transitions
4. Advantages:
   - Simple next-state logic (just shift when enabled)
   - Easy to decode (output is directly the state bits)
   - Potentially better timing as no carry propagation needed
5. Reset initializes to state 0 (0000000001)
6. Enable (slowena) controls whether to shift to next state
7. Overflow is handled naturally by the circular pattern
