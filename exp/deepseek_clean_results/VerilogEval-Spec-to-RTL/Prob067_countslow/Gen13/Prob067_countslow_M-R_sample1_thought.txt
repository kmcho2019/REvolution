Refactoring Approach:
1. Separate the combinational and sequential logic for better modularity
2. Use an assign statement for the next state logic to make the decade detection and increment more explicit
3. Keep the registered output for clean timing
4. Maintain the same functionality (synchronous reset, slowena control)
5. Key changes:
   - Move next state calculation to combinational logic
   - Register the state update in sequential block
   - This makes the design more modular and potentially easier to optimize during synthesis
   - The functionality remains identical but the structure is clearer
