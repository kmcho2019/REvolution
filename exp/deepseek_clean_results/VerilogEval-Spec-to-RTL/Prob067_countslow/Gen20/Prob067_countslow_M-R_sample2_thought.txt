Refactoring Approach: Simplified State Machine with Direct Output Assignment
1. Maintain the same decade counter functionality but simplify the implementation
2. Combine state transition and output logic into a single always block
3. Use binary counting logic instead of explicit state transitions
4. Remove redundant combinational blocks by:
   - Eliminating separate next_state logic
   - Directly assigning state to output q
5. Simplify control flow by:
   - Moving slowena check outside case statement
   - Using simple increment with wrap-around logic
6. Benefits:
   - Reduced logic complexity
   - Fewer always blocks (better synthesis)
   - Clearer relationship between state and output
   - More efficient power usage
