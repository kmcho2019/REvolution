Novel Architecture Idea:
1. Use one-hot encoding for the counter states (10 states for 0-9)
2. Implement a circular shift register with parallel load capability
3. Advantages:
   - Faster state transitions (single bit change between states)
   - Simpler combinational logic for next state
   - Enable logic becomes trivial (just gate the shift operation)
   - Reset is straightforward (load first state)
4. Implementation:
   - 10-bit register for one-hot states
   - Circular shift with wrap-around
   - Convert one-hot to binary for output
   - Synchronous reset loads initial state
   - Enable controls shift operation
