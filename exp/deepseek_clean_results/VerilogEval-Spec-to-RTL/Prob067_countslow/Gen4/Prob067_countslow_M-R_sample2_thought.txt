I'll refactor the decade counter using a combination of combinational and sequential logic blocks. The key changes are:
1. Separate the next-state logic into a continuous assignment
2. Use a dedicated register block for the state storage
3. The reset and enable logic remains synchronous but is now split into two distinct parts
4. The comparison for wrap-around is still optimized (checking bits 3 and 0)
This approach makes the design more modular and could potentially improve synthesis results by clearly separating combinational and sequential logic.
