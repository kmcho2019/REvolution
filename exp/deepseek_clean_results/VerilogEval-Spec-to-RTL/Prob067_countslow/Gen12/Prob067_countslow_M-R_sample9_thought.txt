Refactoring approach:
1. Replace the always block with continuous assignments for combinational logic
2. Use a separate always block just for sequential elements (flip-flops)
3. Split the logic into:
   - Next state calculation (combinational)
   - State register update (sequential)
4. Benefits:
   - Clear separation of combinational and sequential logic
   - Easier timing analysis and synthesis
   - More explicit about what happens on clock edges vs combinational paths
   - Maintains same functionality but with better structured code
5. The rollover detection still uses the efficient (q[3] & q[0]) check
6. The enable and reset functionality remains identical
