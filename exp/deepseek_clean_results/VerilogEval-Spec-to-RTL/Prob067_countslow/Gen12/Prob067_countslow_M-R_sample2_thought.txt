Refactoring Approach:
1. Separate the combinational logic from sequential elements for better modularity
2. Use an always block for sequential elements (register updates) only
3. Move the counter logic and wrap-around detection to combinational assign statements
4. Maintain the same functionality but with clearer separation of concerns
5. Benefits:
   - More explicit data flow
   - Easier to modify combinational logic independently
   - Potential for better synthesis optimization
   - Clearer distinction between synchronous and combinational logic
