Refactored Approach: Simplified State Machine with Combined Logic
1. Maintain the same decade counter functionality but simplify the implementation
2. Combine state transition and output logic into a single always block
3. Use direct binary counting with wrap-around instead of explicit state encoding
4. Remove redundant next_state register by directly assigning to state
5. Simplify slowena handling by making it part of the counting condition
6. Advantages:
   - Reduced logic complexity by eliminating separate next_state logic
   - More compact implementation with same functionality
   - Better timing due to simpler combinational path
   - Maintains all original requirements including synchronous reset and slowena
