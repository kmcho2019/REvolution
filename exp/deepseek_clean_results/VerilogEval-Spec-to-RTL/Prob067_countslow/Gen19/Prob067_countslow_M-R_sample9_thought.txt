Refactoring Approach: Simplified State Machine with Direct Output Assignment
1. Maintain the same decade counter functionality but simplify the implementation
2. Combine state transition and output logic into a single always block
3. Use binary counting logic with explicit wrap-around instead of case statements
4. Remove redundant next_state register by directly assigning to state
5. Output q is directly assigned from state register (no separate combinational logic)
6. Advantages:
   - Reduced logic complexity (no case statement)
   - Fewer registers (eliminated next_state)
   - More compact code while maintaining same functionality
   - Better timing due to simpler combinational path
   - Lower power from reduced switching activity
