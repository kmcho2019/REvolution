Instead of using a single always block, we'll implement this using:
1. Individual instantiation of 8 D flip-flop primitives (FDRE from Xilinx library)
2. Each flip-flop will have its own reset value based on bit position in 0x34
3. The reset values will be hardcoded in each instance
4. This approach provides better visibility and control at the individual flip-flop level
5. The negative edge triggering is implemented in each primitive instance
