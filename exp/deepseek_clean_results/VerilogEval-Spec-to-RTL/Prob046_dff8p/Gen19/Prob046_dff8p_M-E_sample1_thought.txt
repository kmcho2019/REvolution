Novel Architecture Idea:
1. Instead of individual flip-flops, use a register array approach with a single always block for better synthesis optimization
2. Implement parameterized reset value injection using bitwise masking
3. Use a negative-edge triggered clock with synchronous reset in a compact single-process style
4. Leverage Verilog's bitwise operations for reset value application
5. This approach reduces hierarchical overhead while maintaining clear functionality

Key Advantages:
- Single always block improves synthesis optimization potential
- Bitwise operations make the reset value application explicit and efficient
- Eliminates generate loop overhead
- More compact code while maintaining readability
- Easier to modify reset value (just change the parameter)
