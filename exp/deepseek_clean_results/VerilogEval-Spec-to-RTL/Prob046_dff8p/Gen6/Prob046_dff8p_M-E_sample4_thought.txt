Novel Architecture Idea:
1. Instead of using a standard register implementation, create a custom reset injection mechanism
2. Use a multiplexer-based approach where the reset value is injected only when needed
3. Implement the negative edge triggering using a clock inversion technique
4. Separate the reset logic from the data path for better synthesis optimization
5. Use a parameter for the reset value to maintain flexibility
6. This approach may offer better power characteristics when reset is inactive since the reset value isn't constantly being compared

Key Features:
- Explicit reset value injection via mux
- Clear separation of reset and data paths
- Maintains all functional requirements
- Potential for better power efficiency
- More explicit control over reset behavior
