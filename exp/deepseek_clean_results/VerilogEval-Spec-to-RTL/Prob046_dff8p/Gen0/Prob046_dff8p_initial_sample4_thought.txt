To implement an 8-bit register with synchronous reset to 0x34 (which is 8'b00110100 in binary) on negative clock edge, we'll:
1. Create 8 D flip-flops that trigger on negative edge of clk
2. Use synchronous reset (active high) that sets outputs to 0x34 when reset is asserted
3. Otherwise, pass the input d to output q
4. Each bit will be reset to its corresponding value in 0x34
