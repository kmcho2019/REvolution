To implement the TopModule with 8 D flip-flops:
1. Use negative edge-triggered flip-flops (posedge would be default, so we need to invert the clock)
2. Implement synchronous reset (active high) that sets outputs to 0x34 (binary 00110100)
3. Each flip-flop should store one bit of the 8-bit input d
4. The output q should reflect the stored values
