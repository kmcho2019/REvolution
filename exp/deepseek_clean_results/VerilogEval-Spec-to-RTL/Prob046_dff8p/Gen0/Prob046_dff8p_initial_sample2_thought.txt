To implement an 8-bit register with synchronous reset to 0x34 (which is 00110100 in binary) on negative clock edges, we'll need:
1. Eight negative-edge triggered D flip-flops
2. Synchronous reset logic that loads 0x34 when reset is high
3. The flip-flops should update their outputs only on the negative edge of clk
4. When reset is not active, the flip-flops should pass their input d to output q
