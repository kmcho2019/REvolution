To implement an 8-bit register with synchronous reset to 0x34 on negative clock edge, we'll:
1. Create 8 D flip-flops triggered on negative edge of clk
2. Use synchronous reset (active high) that sets outputs to 8'h34 when reset is asserted
3. Otherwise, pass input d to output q
4. The reset value 0x34 is 00110100 in binary
