Instead of using a single always block, we'll:
1. Instantiate 8 individual D flip-flop modules (DFF_NEG) that trigger on negative edge
2. Each DFF will have its own reset value corresponding to bit positions in 0x34
3. Create custom reset values by connecting each flip-flop's reset input to the appropriate bit of 8'h34
4. This approach demonstrates modular design and explicit bit-level control
