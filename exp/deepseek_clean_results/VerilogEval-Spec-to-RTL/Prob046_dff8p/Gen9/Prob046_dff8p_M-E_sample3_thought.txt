A novel approach using hierarchical design with individual DFF instantiations:
1. Create a basic negative-edge triggered DFF module with synchronous reset
2. Instantiate 8 of these DFFs in the TopModule, each with their own reset value bit
3. The reset values are hardwired to match 0x34 (00110100 in binary)
4. This approach demonstrates explicit structural design and allows for individual control of each flip-flop
5. The hierarchical design makes it easier to modify individual flip-flop behavior if needed
