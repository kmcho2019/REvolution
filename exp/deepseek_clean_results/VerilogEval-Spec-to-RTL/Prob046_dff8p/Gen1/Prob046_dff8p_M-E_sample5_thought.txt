Instead of using a single always block with 8-bit registers, we can implement the 8 DFFs individually for each bit. This approach:
1. Creates explicit flip-flop instances for each bit position
2. Allows for customized reset values per bit (0x34 = 00110100)
3. Uses generate block to efficiently instantiate all 8 flip-flops
4. Maintains negative edge triggering and synchronous reset
5. Provides more visibility into individual flip-flop behavior
