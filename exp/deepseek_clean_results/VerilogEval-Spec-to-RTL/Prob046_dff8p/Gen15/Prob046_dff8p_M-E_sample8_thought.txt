Novel Architectural Idea: Distributed Reset with Individual Flip-Flop Control
1. Instead of a single synchronous reset for all flip-flops, implement individual reset control for each bit
2. Use a mask pattern (0x34) to determine which bits should be set/reset during reset
3. Each flip-flop has its own reset logic based on the corresponding bit in the reset pattern
4. This approach allows for more flexible reset behavior in future modifications
5. The negative edge triggering is maintained for all flip-flops
6. The implementation uses separate always blocks for each bit to demonstrate bit-level control

Key Advantages:
- More granular control over reset behavior
- Easier to modify individual bit reset values
- Demonstrates alternative implementation style
- Maintains same functionality while showing different architectural approach
