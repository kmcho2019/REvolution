Refactoring Approach:
1. Instead of using an always block, we'll implement the flip-flops using continuous assignments with clock edge detection
2. Create a wire for the next state value that selects between reset value and input based on reset condition
3. Use non-blocking assignments in an always block to model the flip-flop behavior
4. This approach separates the combinational logic from the sequential elements, making the design more modular
5. The functionality remains identical but the structure is now more explicit about the data flow

Key Changes:
- Combines the benefits of behavioral and structural styles
- Makes the mux-like reset selection more visible
- Still maintains all original requirements (negedge clk, sync reset to 0x34)
