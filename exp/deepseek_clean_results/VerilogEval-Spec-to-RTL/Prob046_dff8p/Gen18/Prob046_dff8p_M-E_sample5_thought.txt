Novel Approach: Shift Register with Parallel Load Reset
1. Instead of individual DFFs, implement as a shift register with parallel load capability
2. Use a multiplexer at each stage to select between:
   - Normal operation (shift in new data)
   - Reset condition (load 0x34 in parallel)
3. The entire register loads the reset value in one cycle when reset is asserted
4. Still maintains negative edge triggering
5. Benefits:
   - More compact implementation than individual DFFs
   - Single-cycle reset loading
   - Clear data path visualization
   - Potential for better area optimization in synthesis
6. Reset value (0x34) is hardcoded in the mux selection logic
