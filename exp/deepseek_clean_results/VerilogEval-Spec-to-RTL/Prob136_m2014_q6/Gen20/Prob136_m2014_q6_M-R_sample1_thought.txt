I'll refactor the solution using a one-hot encoded state machine implementation. The key changes are:

1. Switch from Gray coding to one-hot encoding (better for FPGA implementations)
2. Use continuous assignments for both next-state logic and output
3. Implement the state register using a single always block
4. Maintain the same state transition behavior
5. Simplify the output logic by directly mapping to state bits

Benefits of this approach:
- One-hot encoding typically has better timing in FPGA implementations
- Each state transition can be expressed as a simple equation
- Output logic becomes trivial (just OR of specific state bits)
- Clear separation between combinational and sequential logic
