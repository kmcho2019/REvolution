The original implementation is already quite efficient, but we can simplify it slightly by:
1. Removing the default case since all states are explicitly covered
2. Using direct state comparisons for output logic instead of parameters
3. Combining the state transition and output logic into a single always block (though this is more style preference)
4. Using simpler state encoding since we don't need parameters for this small design

The simplified version maintains identical functionality while being slightly more compact.
