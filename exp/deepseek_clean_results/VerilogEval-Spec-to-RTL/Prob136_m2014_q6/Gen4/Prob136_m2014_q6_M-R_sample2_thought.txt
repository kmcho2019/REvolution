Refactoring approach:
1. Replace the always block for state transitions with continuous assignments using ternary operators
2. Use one-hot encoding for states to potentially improve timing (despite increased area)
3. Move output logic into the state register block to register the output and reduce glitching
4. Maintain the same state machine behavior but with a different implementation style

Key changes:
- One-hot encoding (6 bits) instead of binary (3 bits)
- Continuous assignments for next state logic
- Registered output to reduce glitches
- Same state transitions and output conditions
