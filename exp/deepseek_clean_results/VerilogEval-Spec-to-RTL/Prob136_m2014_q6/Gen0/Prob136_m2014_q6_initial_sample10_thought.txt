The problem requires implementing a state machine with 6 states (A-F) where each state transition depends on the input 'w'. The output 'z' is 1 when in states E or F, and 0 otherwise. 

Design approach:
1. Use a 3-bit register to represent the 6 states (A-F encoded as 000 to 101)
2. Implement combinational logic for next state transitions based on current state and input 'w'
3. Implement output logic where 'z' is high only in states E (100) and F (101)
4. Reset should initialize the state to A (000)
