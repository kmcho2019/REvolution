The problem requires implementing a finite state machine (FSM) with 6 states (A-F) and specific transitions based on input 'w'. The output 'z' depends on the current state (1 for states E and F, 0 otherwise). 

Design approach:
1. Use a 3-bit register to represent the 6 states (A-F encoded as 000 to 101)
2. Implement combinational logic for next state transitions based on current state and input 'w'
3. Implement output logic based on current state
4. Use synchronous reset to initialize the state to A (000)
