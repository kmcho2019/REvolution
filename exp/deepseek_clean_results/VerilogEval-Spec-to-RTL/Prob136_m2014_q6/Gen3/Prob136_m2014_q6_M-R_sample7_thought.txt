Refactoring approach:
1. Replace the sequential always block with continuous assignments for state transitions
2. Use a one-hot encoding scheme for better timing (each state represented by a single bit)
3. Implement next state logic using assign statements with conditional operators
4. Maintain the same output logic but express it in terms of one-hot states
5. Keep the reset functionality but implement it through a mux-like structure

Benefits:
- One-hot encoding simplifies state decoding and improves timing
- Continuous assignments make the state transitions more explicit
- Reduced fan-out on critical paths compared to binary encoding
- Clear separation of combinational and sequential logic
