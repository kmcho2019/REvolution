This solution employs one-hot encoding for the state machine to improve timing performance. Key features:
1. One-hot encoding (6 bits for 6 states) simplifies state decoding and reduces fan-out
2. Registered output 'z' to eliminate glitches and reduce power
3. Next state logic uses parallel AND-OR structure instead of case statement
4. Reset initializes to state A (000001)
5. Output is registered to align with clock edges and reduce glitching power
