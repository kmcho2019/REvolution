I'll refactor the state machine using binary encoding instead of one-hot to reduce area and power consumption. The key changes are:
1. Use binary state encoding (3 bits for 6 states)
2. Replace the combinational always block with continuous assignments
3. Keep the sequential always block for state updates
4. Maintain the same output logic
5. Use parameter instead of localparam for state definitions (syntactically equivalent but more common in practice)

This approach will reduce the number of flip-flops and potentially lower power consumption due to fewer bit toggles during state transitions.
