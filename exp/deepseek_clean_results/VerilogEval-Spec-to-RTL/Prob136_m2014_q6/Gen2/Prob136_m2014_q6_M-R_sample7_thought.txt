Refactored design approach:
1. Maintain the same state machine behavior but implement it using continuous assignments instead of procedural blocks
2. Use a one-hot encoding for states to potentially improve timing (each state has its own flip-flop)
3. Express next state logic and output purely with assign statements
4. Keep the same reset behavior (initialize to state A)

Key changes:
- One-hot encoding (6 bits for 6 states) instead of binary encoding
- Next state logic implemented with continuous assignments
- Output logic remains simple OR of the relevant state bits
- This style may improve timing by reducing combinational logic depth
