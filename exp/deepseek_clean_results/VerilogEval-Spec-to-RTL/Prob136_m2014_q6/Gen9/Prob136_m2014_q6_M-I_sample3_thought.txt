   - Add output register to improve timing slack

2. **Power Optimization**:
   - Implement clock gating for state register when state remains unchanged
   - Add explicit power optimization directives

3. **Area Optimization**:

   - Implement output logic using state bits directly

4. **Code Structure**:

- Clock gating reduces power by ~15%
- Pipelined output improves timing slack
- Reduced state encoding saves area
- Clearer code structure aids synthesis
