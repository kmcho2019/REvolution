To refactor the priority encoder while maintaining the same functionality, we can use a continuous assignment (assign) with conditional operators instead of an always block with casez. This approach will:
1. Eliminate the need for a procedural block
2. Use a cascading ternary operator structure to implement the same priority encoding logic
3. Maintain the same priority order (LSB to MSB)
4. Still output 0 when no bits are set

The ternary operators will naturally create the same priority structure as the original casez statement, checking each bit from LSB to MSB in order.
