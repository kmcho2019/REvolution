To optimize the priority encoder, we'll switch from a casez statement to an if-else cascade. This approach:
1. Checks bits sequentially from LSB to MSB
2. Stops evaluation once the first '1' is found (reducing unnecessary switching)
3. Uses simpler logic that may synthesize to fewer gates
4. Maintains the same functionality while potentially improving PPA metrics

The if-else structure naturally implements the priority encoding we need, where each condition is only evaluated if all previous conditions were false.
