To optimize the priority encoder for better PPA (Power, Performance, Area), I'll implement a tree-structured priority encoder. This approach:
1. Reduces critical path by breaking the long chain of ternary operators into a balanced tree structure
2. Minimizes unnecessary switching activity by evaluating bits in parallel groups
3. Potentially reduces area through shared logic expressions
4. Maintains the same priority encoding behavior (LSB has highest priority)

The tree structure will first check groups of bits, then narrow down to individual bits, reducing the worst-case evaluation depth from 8 to 3 levels.
