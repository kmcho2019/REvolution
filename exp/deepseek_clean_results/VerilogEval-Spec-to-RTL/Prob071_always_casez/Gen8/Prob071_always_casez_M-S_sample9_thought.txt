The current implementation uses a hierarchical approach with separate logic for upper and lower halves, which adds complexity. We can simplify this by using a single casez statement that checks each bit from least significant to most significant. This approach:
1. Directly encodes the priority behavior by checking bits in order (0 to 7)
2. Uses casez for efficient pattern matching
3. Eliminates the need for separate upper/lower half logic
4. Provides a clear and concise implementation
5. Maintains the same functionality while reducing logic complexity
