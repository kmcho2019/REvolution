The existing solution uses a hierarchical approach with separate logic for upper and lower halves, which adds unnecessary complexity. We can simplify this by using a straightforward priority encoder with a casez statement that checks each bit from least significant to most significant. This approach:
1. Directly encodes the priority behavior by checking bits in order (0 to 7)
2. Uses casez for efficient pattern matching
3. Eliminates redundant logic by handling all cases in one construct
4. Maintains the same functionality with clearer intent
