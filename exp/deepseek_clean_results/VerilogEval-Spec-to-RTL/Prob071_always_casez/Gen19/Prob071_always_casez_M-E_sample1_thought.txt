This design uses a thermometer-like encoding approach where we:
1. Create a mask that propagates the first '1' to all higher bits
2. XOR this mask with a shifted version to isolate the first set bit
3. Convert this one-hot pattern to binary

The key innovation is using bitwise operations to:
- Create a propagation effect for the first '1' (like a thermometer code)
- Use XOR to cancel out all bits except the transition point
- This results in a one-hot code that's easy to convert to binary

This approach has several advantages:
- Uses only bitwise operations (no complex logic)
- Naturally handles the all-zeros case
- Has uniform delay paths for all input patterns
- Scales well to wider inputs
