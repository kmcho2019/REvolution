A novel approach would be to use a thermometer-to-binary encoder style priority encoder. The key idea is to:
1. First generate a mask that clears all bits after the first set bit
2. Then convert this masked pattern directly to a binary position

This approach has two main advantages:
1. The masking operation can be implemented efficiently with simple bitwise operations
2. The conversion from one-hot to binary can use optimized encoding logic

The steps are:
1. Create a mask where all bits after the first '1' are cleared (using bitwise XOR and subtraction tricks)
2. Convert this one-hot-like pattern to binary using a logarithmic encoder
3. Handle the all-zero case separately
