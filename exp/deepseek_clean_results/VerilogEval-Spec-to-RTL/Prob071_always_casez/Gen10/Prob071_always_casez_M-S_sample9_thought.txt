The current implementation uses a hierarchical approach with separate logic for upper and lower halves, which adds complexity. We can simplify this by using a straightforward priority encoder with a casez statement that checks each bit from least to most significant. This approach:
1. Directly checks each bit in order (bit 0 to bit 7)
2. Uses casez for efficient pattern matching
3. Eliminates the need for separate upper/lower half logic
4. Results in cleaner, more maintainable code
5. Still maintains good timing characteristics due to the simple priority structure
