Here's a novel approach using a binary search tree structure for the priority encoder:

1. Divide the 8-bit input into progressively smaller segments
2. At each level, check the lower half first (maintaining LSB priority)
3. Recursively narrow down the position until we find the first '1'
4. Use a hierarchical decision tree that naturally implements the priority encoding
5. This approach reduces the critical path compared to linear priority chains

Key advantages:
- Logarithmic depth decision tree (3 levels for 8 bits)
- Balanced logic structure for better timing
- No need for explicit nibble checks
- Naturally handles the all-zeros case
- Easily scalable to wider inputs
