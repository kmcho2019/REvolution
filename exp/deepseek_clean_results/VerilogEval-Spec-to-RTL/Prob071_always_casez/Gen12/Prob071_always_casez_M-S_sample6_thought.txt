To simplify the priority encoder while maintaining functionality, I'll implement a direct priority encoding approach without splitting into nibbles. The key simplifications are:

1. Remove the nibble-based hierarchy since it adds unnecessary complexity for an 8-bit input
2. Use a single continuous assignment with nested ternary operators
3. Check bits sequentially from LSB to MSB (bit 0 to bit 7)
4. Default to 0 when no bits are set (using the OR reduction operator)

This approach:
- Eliminates intermediate wires
- Reduces logic levels
- Maintains clear priority encoding
- Keeps the same functionality
- Uses minimal code
