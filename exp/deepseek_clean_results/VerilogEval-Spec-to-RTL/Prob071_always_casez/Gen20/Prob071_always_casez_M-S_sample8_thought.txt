Simplified approach using a casez statement for priority encoding:

1. **Direct Pattern Matching**: Use casez to directly match bit patterns with don't cares for higher bits
2. **Priority Encoding**: The case items are evaluated in order, naturally implementing priority
3. **Compact Logic**: Single case statement replaces nested if-else structure
4. **Efficient Synthesis**: casez typically synthesizes well into optimized priority encoder logic

Advantages:
- More concise and readable code
- Eliminates hierarchical nesting
- Maintains same functionality with potentially better PPA
- Easier to modify or extend
