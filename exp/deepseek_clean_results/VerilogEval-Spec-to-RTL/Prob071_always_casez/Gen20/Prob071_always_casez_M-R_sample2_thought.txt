To refactor the priority encoder while maintaining the same functionality, I'll implement it using a casez statement within an always block. This approach:

1. Uses a more readable and maintainable case-based structure
2. Explicitly shows the priority encoding through case ordering
3. Still checks bits from LSB to MSB (0 to 7)
4. Handles the all-zeros case with a default case
5. Provides the same output behavior but with clearer intent

- Replace ternary operators with casez statement
- Use procedural always block for clarity
- Maintain same priority order (LSB first)
- Keep the same output format
