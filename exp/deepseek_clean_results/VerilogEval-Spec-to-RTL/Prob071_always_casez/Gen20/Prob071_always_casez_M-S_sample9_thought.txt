The current implementation uses a hierarchical approach with separate logic for upper and lower halves, which adds unnecessary complexity. We can simplify this by using a single casez statement that naturally implements the priority encoding behavior. The casez statement will match patterns from least significant bit to most significant bit, exactly matching our priority encoding requirement. This approach:
1. Uses a single casez statement to check all possible input patterns
2. Directly encodes the priority behavior by checking bits from 0 to 7
3. Eliminates the need for separate upper/lower half logic
4. Results in cleaner and more maintainable code
