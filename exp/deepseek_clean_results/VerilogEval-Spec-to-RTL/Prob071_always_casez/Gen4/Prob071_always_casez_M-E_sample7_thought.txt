Here's a novel approach using a logarithmic search pattern that reduces the critical path:

1. Instead of checking bits sequentially, we'll divide the 8-bit input into hierarchical groups
2. First, check if any of the lower 4 bits (bits 0-3) are set
3. If yes, focus only on those 4 bits (using the same approach recursively)
4. If not, check the upper 4 bits (bits 4-7)
5. This creates a binary search-like structure with log2(8) = 3 levels of logic
6. The approach naturally creates a balanced tree structure that reduces the worst-case delay

Advantages:
- Reduced critical path compared to linear priority encoder
- More balanced logic structure
- Potentially better for synthesis optimization
- Scales better for wider inputs (though not needed here)
