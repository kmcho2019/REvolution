Novel Crossbar Switch Architecture:
1. Instead of hierarchical muxing, implement a direct crossbar connection
2. Use a thermometer-coded selection scheme for better power efficiency
3. Leverage parallel AND-OR plane structure for reduced critical path
4. Key innovations:
   - Single-level selection logic (no hierarchy)
   - Thermometer decoding reduces switching power
   - Parallel AND-OR structure enables constant-time selection
   - Optimized for fixed 256:1 case with 8-bit select

Implementation Approach:
1. Decode 8-bit sel into 256-bit one-hot using thermometer coding
2. Create an AND plane where each input bit is ANDed with its selection bit
3. OR all AND outputs together for final selection
4. Special optimization: Use bitwise operations to avoid explicit 256 AND gates
