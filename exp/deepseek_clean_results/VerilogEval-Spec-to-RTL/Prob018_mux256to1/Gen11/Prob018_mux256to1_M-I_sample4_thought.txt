To optimize the design further, I'll implement a more power-efficient version that:
1. Uses a single temporary register for the selected group instead of maintaining all groups
2. Only activates the group selection logic when needed (reduces switching activity)
3. Maintains the balanced timing path while reducing area

The key improvements are:
- Replace the 16x16 wire array with a single 16-bit register
- Use the upper sel bits to load only the needed group into the register
- Keep the same hierarchical structure for timing benefits but with reduced resources
- This should reduce both power (less switching) and area (fewer wires)
