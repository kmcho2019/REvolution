The original solution uses a clever circular buffer approach with part-select indexing. We can maintain the same core concept but implement it more efficiently by:
1. Eliminating the explicit 512-bit circular buffer creation
2. Using a direct part-select operation on the input vector with modulo arithmetic
3. Simplifying the logic to just select the desired bit based on the selector

This refactoring reduces the hardware overhead while maintaining the same functionality. The key insight is that we can treat the 256-bit input as circular implicitly by using modulo-256 arithmetic on the selector.
