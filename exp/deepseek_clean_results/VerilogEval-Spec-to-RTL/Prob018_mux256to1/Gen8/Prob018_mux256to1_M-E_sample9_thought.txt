Instead of traditional multiplexing, we can use a barrel shifter approach where we:
1. Right-shift the input vector by the selection value (sel)
2. Mask out all bits except the LSB (which now contains our selected bit)
3. Extract the LSB as output

This approach leverages the fact that shifting the input by 'sel' positions will bring the desired bit to the LSB position. We then simply need to isolate this bit. This method is particularly efficient in hardware as modern FPGAs and ASIC libraries have optimized barrel shifter implementations.
