Instead of a direct 256-to-1 mux, we can implement a binary tree structure with three levels:
1. First level: 16x 16-to-1 muxes (each handling 16 input bits)
2. Second level: 1x 16-to-1 mux (selecting between first level outputs)
3. The 8-bit sel is split into:
   - sel[7:4] for second level selection
   - sel[3:0] for first level selections
This reduces fanout and critical path while maintaining functionality.
