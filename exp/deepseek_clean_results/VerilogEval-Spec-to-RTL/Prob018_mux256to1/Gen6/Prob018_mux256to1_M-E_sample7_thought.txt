This implementation uses a recursive binary tree structure that:
1. Divides the input into two halves at each level
2. Uses one bit of the selector at each level to choose between halves
3. Recursively narrows down the selection until reaching a single bit
4. The depth of the tree is log2(256) = 8 levels
5. This approach naturally matches the binary nature of the selector
6. Each level only requires simple 2-to-1 mux operations
7. The structure is highly regular and scales well to any power-of-two input size
