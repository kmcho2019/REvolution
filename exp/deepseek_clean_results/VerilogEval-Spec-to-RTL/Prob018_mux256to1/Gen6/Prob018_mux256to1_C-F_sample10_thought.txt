Fusion Strategy:
1. Combine the simplicity of direct indexing (Example 2) with the hierarchical efficiency of Example 1
2. Use the direct `in[sel]` syntax for clarity and let synthesis tools optimize the implementation
3. Maintain the two-level selection concept implicitly through the indexing operation
4. This approach gives:
   - Clean, readable code (like Example 2)
   - Potential for synthesis tools to implement hierarchical optimization (like Example 1)
   - Better power characteristics by reducing unnecessary switching
   - Balanced timing path through implicit hierarchy

The key insight is that modern synthesis tools can recognize and optimize direct indexing patterns into efficient hierarchical structures when beneficial, while keeping the code simple and maintainable.
