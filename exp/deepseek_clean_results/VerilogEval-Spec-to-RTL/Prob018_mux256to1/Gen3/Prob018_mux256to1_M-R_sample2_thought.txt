The original implementation uses a direct bit selection with 'assign', which is clean and efficient. For refactoring, I'll implement the same functionality using an 'always' block with a case statement. This approach:
1. Makes the selection logic more explicit and potentially more readable
2. Could be beneficial if we later need to add more complex selection logic
3. Shows an alternative implementation style while maintaining the same functionality
4. Still maintains combinational logic (no registers) as in the original
