The key simplification comes from recognizing that:
1. The flow rate outputs (fr0, fr1, fr2) are purely combinational functions of the current sensor readings
2. Only dfr needs state (previous sensor readings) to determine if water level is rising
3. We can simplify the transition detection by comparing the highest asserted sensor bit between current and previous states

This leads to a design where:
- Flow outputs are simple combinational logic
- Only prev_s needs to be stored as state
- dfr is set when current highest sensor > previous highest sensor
- Reset initializes all outputs high and assumes previous state was lowest level
