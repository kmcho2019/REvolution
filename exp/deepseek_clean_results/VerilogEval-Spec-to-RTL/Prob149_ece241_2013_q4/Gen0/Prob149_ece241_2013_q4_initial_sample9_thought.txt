To implement this water level control system, we need a state machine that tracks the current water level and the previous state to determine the appropriate flow rates. The system has four states corresponding to the water levels (Above s[2], Between s[2] and s[1], Between s[1] and s[0], and Below s[0]). The outputs (fr2, fr1, fr0, dfr) are determined based on the current state and the transition from the previous state. The state machine should update on every clock edge and reset to the Below s[0] state when reset is active.
