Here's a novel approach using a history-based state machine with direct sensor edge detection:

1. Instead of tracking just the current state, we'll maintain a history of the last two sensor readings to detect rising/falling edges
2. Use combinational logic to directly determine outputs based on current sensors and history
3. Implement a simpler state machine that only needs to track if we're in a rising condition
4. Use parallel case statements for cleaner output generation
5. Reset will initialize all history and outputs to their maximum flow state

Key innovations:
- Eliminates complex state transitions by focusing on sensor edges
- Uses history bits to directly detect rising conditions
- Simpler output logic with clear priority encoding
- More efficient implementation with fewer registers
