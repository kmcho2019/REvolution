To simplify the water level control system, we can eliminate the explicit state machine and instead directly derive the outputs from the current sensor readings and previous water level. The key observations are:
1. The nominal flow outputs (fr0, fr1, fr2) can be determined directly from the current sensor readings without needing state variables
2. The supplemental flow (dfr) only needs to track if the water level was previously lower (any sensor that was off is now on)
3. Reset should initialize all outputs to active (maximum flow) and clear any history

This approach reduces complexity by:
- Removing the state machine and state variables
- Calculating outputs directly from sensor inputs
- Using a single register to track previous sensor readings for dfr calculation
- Simplifying reset to just set all outputs high
