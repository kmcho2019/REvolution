Here's a novel approach using a history-based controller instead of a traditional state machine:

1. Instead of tracking states, we'll track the highest sensor that was previously active using a register.
2. We'll compare current sensor readings with this history to determine if the level is rising (needs supplemental flow).
3. Outputs will be generated combinatorially based on current sensors and the history.
4. The history register updates only when sensors change, making it more power-efficient.

Key innovations:
- No explicit state machine - simpler transition logic
- History-based comparison directly gives us the "previous was lower" information
- More efficient implementation with fewer registers
- Clear mapping between sensor patterns and outputs
