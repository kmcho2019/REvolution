Novel Approach: Direct Sensor-to-Output Mapping with Transition Detection

Key Innovations:
1. **Direct Output Mapping**: Eliminate explicit state machine by directly mapping sensor inputs to outputs using combinational logic
2. **Edge Detection**: Use a dedicated register to track previous sensor values for accurate transition detection
3. **Hierarchical Priority**: Implement priority encoding where higher sensors override lower ones
4. **Simplified Transition Logic**: Calculate dfr by comparing current and previous sensor readings

Advantages:
- More direct implementation of specification
- Eliminates state encoding complexity
- Clearer relationship between sensors and outputs
- More efficient resource utilization

Logic Breakdown:
- Outputs fr2, fr1, fr0 directly determined by current sensor readings
- dfr calculated by detecting when water level was previously lower (any sensor that was 0 is now 1)
- Reset forces all outputs high (maximum flow)
