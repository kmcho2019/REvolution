Simplified Approach: Direct Sensor-Based Control

Key Simplifications:
1. **Eliminate State Machine**: Instead of explicit states, directly use sensor values to determine outputs
2. **Simpler Transition Detection**: Track only previous sensor values to detect rising water levels
3. **Direct Output Logic**: Generate outputs directly from current sensor readings
4. **Maintained Functionality**: Still meets all original requirements

Logic Overview:
- Outputs fr2, fr1, fr0 are directly determined by current sensor readings
- dfr is asserted when current water level is higher than previous level
- Reset forces all outputs high (maximum flow)
- No need for state encoding or complex state transitions
