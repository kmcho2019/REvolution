Simplified approach focusing on direct sensor-to-output mapping:

1. Eliminate explicit state machine - directly use sensor inputs to determine outputs
2. Outputs can be determined purely by current sensor readings and previous level:
   - fr0, fr1, fr2 directly follow the table based on current sensors
   - dfr is set when current level is higher than previous level
3. Track only the previous sensor readings (not full state) to detect level changes
4. Reset forces all outputs high and clears history (as if coming from below lowest sensor)

Key simplifications:
- No state encoding/decoding needed
- Direct combinatorial output logic from sensors
- Only need to track previous sensors for level change detection
- Fewer registers and simpler logic
