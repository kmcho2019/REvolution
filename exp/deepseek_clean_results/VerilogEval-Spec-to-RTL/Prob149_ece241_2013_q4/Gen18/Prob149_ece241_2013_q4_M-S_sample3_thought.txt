Simplified Approach: Direct Sensor-to-Output Mapping with Edge Detection

Key Simplifications:
1. **Eliminate State Machine**: Replace with direct combinatorial logic based on sensor inputs
2. **Simplified Output Logic**:
   - fr0/fr1/fr2 directly derived from current sensor readings
   - dfr generated by detecting rising water level transitions
3. **Edge Detection**:
   - Track previous sensor state to detect rising levels
   - Only need to compare current vs previous sensor patterns
4. **Reset Handling**:
   - Forces all outputs high (maximum flow)
   - Clears previous sensor state

Behavior:
- Below s[0] (000): All outputs high (maximum flow)
- Between s[1]-s[0] (001): fr0 and fr1 high (nominal flow)
- Between s[2]-s[1] (011): fr0 high (reduced flow)
- Above s[2] (111): All outputs low (no flow)
- dfr pulses when water level rises between states
