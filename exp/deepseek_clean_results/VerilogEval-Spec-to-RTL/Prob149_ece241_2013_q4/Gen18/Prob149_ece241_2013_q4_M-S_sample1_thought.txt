Simplified Approach: Direct State Mapping with Edge Detection

1. Core Concept:
   - Use current sensor readings directly to determine water level state
   - Track previous sensor state to detect rising/falling levels
   - Implement output logic as simple combinational functions of current state

2. Key Simplifications:
   - Eliminate history buffer (only need current and previous states)
   - Direct mapping from sensor patterns to outputs using case-like logic
   - Clear separation between state tracking and output generation

3. Implementation Details:
   - Register to store previous sensor state
   - Simple rising edge detection (current > previous)
   - Outputs follow truth table directly
   - Synchronous reset forces all outputs high

4. Advantages:
   - Reduced complexity (only 1 register needed)
   - Clear, direct implementation of specification
   - Easier to verify and maintain
   - Efficient resource usage
