New architecture idea:
1. Use a priority encoder to directly determine water level from sensors
2. Track transitions separately using edge detection on sensor changes
3. Implement output logic as combinatorial functions of current level and transition direction
4. Use a dedicated register to store the previous level for accurate transition detection
5. Simplify state management by focusing on level changes rather than full state machine

Key innovations:
- Priority encoding handles sensor patterns more efficiently
- Explicit transition detection avoids state machine complexity
- Outputs are purely combinatorial functions of level and direction
- Reset puts system in maximum flow state
