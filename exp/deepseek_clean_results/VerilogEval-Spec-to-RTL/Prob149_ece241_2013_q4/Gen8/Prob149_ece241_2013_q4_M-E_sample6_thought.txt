Here's a novel approach using a finite state machine (FSM) with explicit transition tracking:

1. State Representation:
   - Use 4 explicit states instead of encoded levels for clarity
   - Each state directly represents a water level condition

2. Transition Tracking:
   - Maintain a separate register to track the direction of level change
   - Calculate direction by comparing current and previous sensor readings

3. Output Logic:
   - Generate nominal flow outputs based purely on current state
   - Calculate dfr based on the direction register (1 when rising)

4. Reset Handling:
   - Initialize to BELOW_S0 state with all outputs high

Key Advantages:
- More intuitive state representation
- Explicit direction tracking simplifies dfr logic
- Easier to debug and modify
- Better handles edge cases and invalid inputs
