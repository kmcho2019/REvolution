To simplify the solution while maintaining functionality, I'll make these key changes:

1. **Eliminate State Encoding**: Instead of using explicit state parameters, directly use sensor values to determine outputs, since the sensor pattern directly indicates water level.

2. **Simplify Rising Detection**: Track previous sensor values to detect when water level is rising (any sensor newly triggered compared to previous cycle).

3. **Direct Output Logic**: Outputs can be determined directly from current sensor values without state machine, except for dfr which needs history.

4. **Maintain Synchronous Reset**: Keep reset behavior as specified, forcing all outputs high when reset is active.

This approach removes the state machine complexity while maintaining all required functionality through direct sensor value analysis and simple history tracking.
