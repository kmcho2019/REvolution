Novel Design Approach:

1. History-Based State Machine:
   - Maintain a 2-bit history of water level trends (rising/steady/falling)
   - Use this history to make better flow rate decisions during transitions

2. Edge Detection:
   - Implement precise sensor edge detection for all three sensors
   - Track both rising and falling edges separately

3. Hierarchical Output Logic:
   - Base outputs on current sensor readings
   - Modify with history-based adjustments
   - Special handling for boundary conditions

4. Predictive Flow Control:
   - Use trend history to anticipate future levels
   - Adjust flow rates preemptively based on trends

Key Innovations:
- History tracking provides better transition handling
- Precise edge detection improves responsiveness
- Predictive element helps stabilize water levels
- Clear separation between sensor processing and control logic
