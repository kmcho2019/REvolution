Simplification Strategy:

1. **State Representation**:
   - Use binary encoding (2 bits) instead of one-hot to naturally represent water level ordering
   - States numerically correspond to their physical positions (00=below, 01=low, 10=mid, 11=above)

2. **Transition Logic**:
   - Directly map sensor inputs to states using priority encoding
   - Remove separate prev_state register by comparing current and next states

3. **Output Logic**:
   - Make fr outputs simple combinatorial functions of current state
   - Derive dfr by comparing next_state > current_state (rising water level)

4. **Reset Handling**:
   - Set state to "below" (00) during reset
   - Outputs will naturally follow from state encoding

Key Improvements:
- Fewer state bits (2 vs 3)
- Numeric state values match water level ordering
- Simpler comparison logic
- Maintains all required functionality
