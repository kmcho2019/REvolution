Improved Approach: State Machine with Proper Transition Handling

Key Improvements:
1. **Explicit State Machine**: Implement 4 distinct states corresponding to water levels
2. **Accurate Transition Detection**: Track both current and previous states to properly determine dfr
3. **Complete Output Logic**: Correctly implement all output combinations per specification
4. **Robust Reset Handling**: Ensure reset puts system in correct initial state

State Encoding:
- STATE_BELOW: Below s[0] (no sensors)
- STATE_LOW: Between s[1]-s[0] (s[0] only)
- STATE_MID: Between s[2]-s[1] (s[0] and s[1])
- STATE_HIGH: Above s[2] (all sensors)

DFR Logic:
- Assert when transitioning to a higher state
- Based on state transitions rather than direct sensor comparison

Output Logic:
- Precisely matches specification table
- Handles all possible sensor combinations
