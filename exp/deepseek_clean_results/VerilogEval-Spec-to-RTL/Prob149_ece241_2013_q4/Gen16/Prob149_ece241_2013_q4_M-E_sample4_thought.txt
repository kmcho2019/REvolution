Novel Approach: Hierarchical Priority Encoder with Edge Detection

Key Innovations:
1. **Priority-Based Sensor Encoding**: Instead of direct state encoding, use a priority encoder to determine the highest active sensor, creating a natural hierarchy
2. **Transition Detection**: Implement explicit edge detection for sensor changes to precisely control the dfr output
3. **Output Decoder**: Separate the output generation logic into a purely combinational block for clarity
4. **Reset Integration**: Handle reset as a special case that bypasses normal operation and forces all outputs high
5. **Default Handling**: Explicitly handle all possible sensor combinations with a default case

Advantages:
- More robust handling of sensor patterns
- Clear separation of level detection and output generation
- Precise transition detection for dfr control
- Easier to modify for additional sensors in the future
