Simplified design approach:

1. Direct sensor mapping:
   - Eliminate explicit state encoding since outputs directly depend on sensor values
   - Use sensor inputs to determine outputs without intermediate state variables

2. Output logic simplification:
   - fr0, fr1, fr2 can be directly derived from sensor values (truth table approach)
   - dfr can be determined by comparing current and previous sensor values for rising condition

3. Reset handling:
   - Maintain synchronous reset that forces all outputs high
   - Track only previous sensor values (not states) for simpler comparison

Key simplifications:
- Removed state machine logic entirely
- Direct sensor-to-output mapping reduces complexity
- Previous sensor tracking instead of state tracking
- Same functionality with fewer registers and simpler logic
