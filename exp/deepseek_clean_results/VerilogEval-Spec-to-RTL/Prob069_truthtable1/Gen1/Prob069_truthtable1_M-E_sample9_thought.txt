Instead of using standard logic gates, we can implement the truth table using a multiplexer structure. The key observation is that the output depends on x3 in a particular pattern:
- When x3=0, f equals x2 (regardless of x1)
- When x3=1, f equals x1

This suggests we can use x3 as the select line for a 2:1 mux where:
- Input 0 is x2
- Input 1 is x1
This implementation is functionally equivalent but uses a different architectural approach.
