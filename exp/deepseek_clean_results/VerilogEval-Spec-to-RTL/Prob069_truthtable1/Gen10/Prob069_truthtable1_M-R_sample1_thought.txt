The original implementation uses a direct combinational logic expression with assign statement. We can refactor this by:
1. Using an always block with case statement to explicitly show the truth table mapping
2. This approach makes the design more readable and maintainable as the truth table is directly visible in the code
3. The functionality remains identical but the implementation style changes
4. This style might be preferable when:
   - The truth table is more complex
   - Future modifications to the truth table are expected
   - The design needs to be more self-documenting
5. Synthesis tools will optimize this to the same logic as the original implementation
