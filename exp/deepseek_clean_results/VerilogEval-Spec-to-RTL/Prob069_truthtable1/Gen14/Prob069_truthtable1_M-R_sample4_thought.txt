Refactoring Approach: Using Case Statement in Always Block
1. Instead of using a direct logic expression with assign, we'll implement the truth table using a case statement in an always block
2. The case statement will explicitly list all input combinations and their corresponding outputs
3. This approach makes the truth table mapping more explicit and readable
4. The functionality remains identical to the original solution
5. While this uses more lines of code, it can be more maintainable for complex truth tables
6. The synthesis result should be identical as modern tools optimize case statements efficiently
