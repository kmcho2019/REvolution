Instead of using traditional AND/OR logic gates, we can implement the function using a multiplexer-based approach:
1. Observe that when x3=0, f simply follows x2 (rows 1-4)
2. When x3=1, f follows x1 (rows 5-8)
3. This means we can use x3 as a selector for a 2:1 mux:
   - When x3=0, select x2
   - When x3=1, select x1
4. This implementation has several advantages:
   - Uses only one multiplexer (typically implemented as pass transistors in CMOS)
   - Single-level logic (just the mux) for potentially faster operation
   - More regular structure that may map better to certain FPGA architectures
   - Easier to scale if we need to add more variables later
5. The mux implementation is functionally equivalent to the original truth table
