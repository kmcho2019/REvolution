A novel approach is to implement the truth table using a look-up table (LUT) style implementation with a 3-to-1 multiplexer. The key insight is that we can treat x3 as a selector that chooses between two different sub-functions:
1. When x3=0, the output depends only on x2 (f = x2)
2. When x3=1, the output depends on x1 (f = x1)

This approach reduces the logic to a simple multiplexer operation, which is efficient in both area and timing. The multiplexer effectively collapses the truth table into two simpler cases based on the value of x3.
