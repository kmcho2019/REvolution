The original implementation uses a NAND-based multiplexer structure with intermediate wires. We can refactor this to:
1. Use continuous assignments (assign) exclusively for a more compact representation
2. Eliminate the intermediate wires by combining the NAND operations into a single expression
3. Maintain the same logical function while reducing the number of lines
