A novel approach using a multiplexer-based implementation that leverages the input patterns to select the output. This method:
1. Identifies that the output depends primarily on x2 when x3=0 and on x1 when x3=1
2. Uses x3 as the select line for a 2:1 mux
3. The mux inputs are connected to x2 (when x3=0) and x1 (when x3=1)
4. This reduces the logic to a single multiplexer operation, potentially optimizing area and power
