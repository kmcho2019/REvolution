Here's a novel approach using a bitmask technique that's particularly efficient for small truth tables:

1. Instead of using a case statement or Boolean algebra, we'll treat the truth table as a bitmask
2. The output can be determined by using the input combination as an index into this mask
3. We'll create an 8-bit parameter representing all possible output values (one per input combination)
4. The input combination {x3,x2,x1} will serve as the index into this bitmask
5. This approach is compact, leverages Verilog's bit selection capability, and is easily modifiable
6. It's particularly efficient for synthesis as it maps directly to a small LUT

Advantages:
- Extremely compact implementation
- Direct mapping from truth table to implementation
- Easy to modify by just changing the bitmask
- Efficient synthesis to LUT structures
- No complex logic expressions to maintain
