Here's a novel approach using a lookup table (LUT) implemented as a case statement. This method:

1. Directly maps the truth table into a case statement for clarity
2. Makes the functionality immediately obvious from the code
3. Scales well if additional inputs are added later
4. Can be efficiently synthesized into a 3-input LUT in FPGA implementations
5. Provides explicit documentation of all cases
6. Is easily modifiable if requirements change
7. Has identical PPA characteristics to the minimal logic implementation since modern synthesis tools will optimize it to the same underlying logic
