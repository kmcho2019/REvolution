Instead of using direct boolean expressions or muxes, we can implement a hierarchical decoder structure that:
1. First decodes the x3 input to select between two sub-functions
2. Each sub-function is a simple 2-input logic function
3. The x3=0 case implements f = x2 (rows 3-4 of truth table)
4. The x3=1 case implements f = x1 (rows 6,8 of truth table)
5. This creates a clean separation of concerns and could potentially map well to certain FPGA architectures
6. The implementation uses a conditional operator for clarity
7. This approach shows how complex functions can be broken down into simpler sub-functions based on input patterns
