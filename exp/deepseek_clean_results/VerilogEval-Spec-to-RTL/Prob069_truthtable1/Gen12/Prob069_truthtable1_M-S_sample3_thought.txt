Simplified Approach: Direct Truth Table Mapping
1. The truth table shows f is true in exactly 4 cases out of 8
2. Instead of deriving a minimized Boolean expression, we can directly implement the truth table using a multiplexer-like structure
3. The simplest implementation is to use a case statement that explicitly lists all input combinations and their corresponding outputs
4. This approach is more readable and maintainable while being equally efficient in modern synthesis tools
5. The case statement will be optimized by synthesis tools to produce the same minimal logic as the Boolean expression
