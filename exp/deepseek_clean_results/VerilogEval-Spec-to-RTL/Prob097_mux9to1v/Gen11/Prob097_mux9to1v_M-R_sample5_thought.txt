I'll refactor the solution to use continuous assignments (assign statements) instead of an always block. This approach:

1. Eliminates the need for a procedural block, making it purely combinational
2. Uses a ternary operator for the selection logic
3. Maintains the same functionality with:
   - Early detection of invalid selections (sel >= 9)
   - Same output values for all cases
4. Benefits:
   - Slightly more concise code
   - No need for output register declaration
   - Potentially better synthesis results in some tools
   - Clearer dataflow representation

The structure will be:
1. First check if sel is invalid (>=9) -> output all 1's
2. Otherwise, use nested ternary operators to select the appropriate input
