Instead of using a traditional case statement, we'll implement the multiplexer using a bitwise approach with a priority encoder-like structure. Each output bit will be determined by OR-ing the selected input bit with the default condition. This approach:
1. Uses continuous assignments for each bit position
2. Implements the selection logic through bitwise operations
3. Handles the default case by OR-ing with the sel>8 condition
4. May offer better synthesis optimization opportunities for some tools
