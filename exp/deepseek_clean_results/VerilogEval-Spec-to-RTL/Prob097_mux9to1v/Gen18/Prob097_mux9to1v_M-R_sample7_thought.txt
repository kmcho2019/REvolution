I'll refactor the solution to use continuous assignments instead of procedural blocks. This approach:
1. Eliminates the need for a register (output reg) by using direct wire assignments
2. Maintains the same functionality with early invalid selection detection
3. Uses a more dataflow-oriented style while keeping the same optimization benefits

5. Still provides the same default behavior for invalid selections
