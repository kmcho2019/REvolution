Refactoring Approach:
1. Replace the always block with continuous assignments using ternary operators
2. Maintain the same functionality but express it more concisely
3. Keep the early valid_sel detection for power optimization
4. Use a cascaded ternary expression for the multiplexer logic
5. The default value (16'hFFFF) will be handled by the valid_sel check

Benefits:
- More concise implementation
- Eliminates the need for a temporary register (selected)
- Direct assignment to output without intermediate storage
- Still maintains good timing characteristics as ternary operators synthesize efficiently
