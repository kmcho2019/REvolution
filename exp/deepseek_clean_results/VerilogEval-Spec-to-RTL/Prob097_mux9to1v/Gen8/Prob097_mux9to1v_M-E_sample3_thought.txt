Novel architectural idea:
1. Instead of a flat case statement, implement a binary tree of 2-to-1 multiplexers
2. First level: 5 muxes to select between first 8 inputs (a-h)
3. Second level: 1 mux to select between the first level result and input 'i'
4. Final level: Use the MSB of sel to choose between the second level result and the default value
5. This structure provides:
   - Potentially better timing due to balanced tree structure
   - More regular layout that might be more area-efficient in some technologies
   - Clear hierarchical structure that could be pipelined if needed
6. The unused cases (sel=9-15) are handled by checking the MSB of sel
