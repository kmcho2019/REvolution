Here's a refactored version that maintains the same core functionality but with these key changes:

1. **Direct Assignment**: Replace the always block with continuous assignments for the one-hot decoder, making it purely combinational without procedural blocks.

2. **Simplified Selection Logic**: Instead of generating separate wires for each AND operation, we'll use a more compact bitwise selection approach with concatenated inputs.

3. **Parallel Output Calculation**: Maintain the parallel bit processing but express it more concisely using bitwise operations on the entire 16-bit vectors.

4. **Optimized Invalid Case Handling**: The default output ('1's for invalid selections) is handled more efficiently by combining it with the selection logic.

The refactoring achieves:
- Same functionality with fewer lines of code
- More direct expression of the selection logic
- Maintains the parallel processing benefits
- Potentially better synthesis results due to simpler structure
