Instead of using a conventional case statement, we'll implement the multiplexer using a hierarchical approach with two levels of smaller multiplexers. First, we'll use the lower 3 bits of sel to select among groups of inputs, then use the MSB of sel to choose between these groups or handle the default case. This reduces the fan-in of each multiplexer stage and may offer better power/area characteristics. For the default case (sel[3]=1), we'll simply OR the MSB with the intermediate result to force all 1's when needed.
