Here's a novel approach using a hierarchical multiplexer structure that reduces fan-in and improves timing:

1. **Two-Level Mux Structure**: 
   - First level: Three 3-to-1 muxes (each handling 3 inputs)
   - Second level: 3-to-1 mux to select from first level outputs
   - This reduces the maximum fan-in from 9 to 3, improving timing

2. **Optimized Invalid Case Handling**:
   - Use the MSB of sel to detect invalid cases (sel[3] && sel[2])
   - Gate the mux outputs when invalid cases are detected

3. **Resource Sharing**:
   - Reuse the same 3-to-1 mux logic for all first-level muxes
   - Implement as a function for cleaner code

This approach provides better timing characteristics for large input counts while maintaining clean code structure.
