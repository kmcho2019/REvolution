Novel Approach: Hierarchical Multiplexer Tree with Priority Encoding

Instead of using a flat case statement, I'll implement a hierarchical 2-level multiplexer structure that:
1. First level: Groups inputs into 3 sets of 3 inputs each (a-c, d-f, g-i)
2. Second level: Selects between the first level outputs or default value
3. Uses priority encoding to detect invalid selections early
4. Implements a balanced tree structure for better timing

Advantages:
- More scalable for larger multiplexers
- Potentially better timing due to balanced tree structure
- Clear separation of selection logic
- Early detection of invalid cases
- Reduced fan-in at each stage compared to flat case
