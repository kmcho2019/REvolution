I'll refactor the solution to use continuous assignments instead of procedural blocks, which can offer some advantages:
1. **Simpler Structure**: Using assign statements makes the code more declarative and easier to understand at a glance
2. **Potential Synthesis Benefits**: Some synthesis tools may optimize continuous assignments differently
3. **Consistent Output Type**: The output becomes a wire instead of a reg, which may be more appropriate for combinational logic

The key changes will be:
- Replace the always block with assign statements
- Use a ternary operator for the selection logic
- Maintain the same functionality and optimization points (early invalid selection detection)
- Keep the same case handling for valid selections
