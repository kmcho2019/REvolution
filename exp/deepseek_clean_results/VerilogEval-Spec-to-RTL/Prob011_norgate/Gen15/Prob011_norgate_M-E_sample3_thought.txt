Novel Approach: Hierarchical NOR Gate with Built-in Self Test (BIST)
1. Implement the basic NOR functionality using primitive gates (OR + NOT) for clarity
2. Add a built-in self-test feature that can verify the gate's functionality
3. Include an enable signal to activate/deactivate the BIST mode
4. When in BIST mode, the module automatically tests all input combinations
5. Output a 'test_pass' signal indicating if the NOR gate passed self-test
6. Maintain the original NOR functionality when not in BIST mode

This approach provides:
- Basic NOR gate functionality
- On-demand self-verification capability
- No impact on normal operation when BIST is disabled
- Immediate feedback about gate health
- Useful for reliability-critical applications
