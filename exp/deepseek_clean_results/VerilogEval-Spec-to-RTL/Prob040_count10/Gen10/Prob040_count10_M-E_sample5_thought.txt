Novel Approach: State Encoding Optimization
1. Instead of using a standard binary counter, implement a Gray code counter that changes only one bit per count transition
2. This reduces switching activity and power consumption since only one flip-flop toggles per clock cycle
3. Use a custom decade Gray code sequence (0000, 0001, 0011, 0010, 0110, 0111, 0101, 0100, 1100, 1000)
4. Implement synchronous reset that maps to the first Gray code state (0000)
5. Use a ROM-style lookup table for next state transitions to ensure correct decade counting
6. The design will have lower dynamic power while maintaining the same counting functionality

Advantages:
- Reduced power consumption due to minimal bit toggling
- Maintains same counting sequence and period
- Still uses single always block for clean sequential logic
- No glitches in output since only one bit changes at a time
