Refactored decade counter implementation with these key changes:
1. Used a single always block for both combinational and sequential logic
2. Simplified the terminal count detection by comparing directly to 9 (4'b1001)
3. Maintained synchronous reset functionality
4. Reduced logic levels by eliminating separate combinational assignments

Advantages:
- More compact implementation with same functionality
- Direct comparison to 9 is more intuitive than bitwise detection
- Single always block makes it clear all logic is synchronous
- Maintains good PPA characteristics with simpler structure
