Refactored decade counter implementation with these key changes:
1. Used a single always block for both sequential and combinational logic
2. Simplified the terminal count detection by directly comparing to 9 (4'b1001)
3. Maintained synchronous reset functionality
4. Reduced logic levels by eliminating the separate combinational block

Advantages:
- More compact implementation with same functionality
- Direct comparison to 9 is more intuitive than detecting specific bits
- Single always block reduces potential for synthesis mismatches
- Maintains same PPA characteristics while being more concise
