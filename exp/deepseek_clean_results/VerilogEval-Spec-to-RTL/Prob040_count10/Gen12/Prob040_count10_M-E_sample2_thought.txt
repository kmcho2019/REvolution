Novel approach using Gray code encoding for the decade counter:
1. Use Gray code instead of binary to reduce switching activity and power consumption
2. Implement a custom Gray code sequence for 0-9 (0000,0001,0011,0010,0110,0111,0101,0100,1100,1101)
3. Create a combinational next-state logic that transitions between Gray code states
4. Include synchronous reset functionality
5. Add a binary-to-Gray converter at the output for compatibility

Benefits:
- Reduced power consumption due to fewer bit toggles between states
- Maintains same functionality while using different encoding
- More robust against glitches in the counting sequence
- Output remains binary for compatibility with standard interfaces
