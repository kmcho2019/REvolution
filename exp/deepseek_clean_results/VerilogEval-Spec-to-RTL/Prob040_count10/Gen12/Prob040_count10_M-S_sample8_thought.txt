Simplified decade counter implementation with these key changes:
1. Remove intermediate q_next wire and directly assign next state in sequential block
2. Combine reset and count logic in a single always block
3. Maintain same terminal count detection (q == 4'b1001) for clarity
4. Reduce number of assignments and variables
5. Keep synchronous reset functionality

Benefits:
- Fewer variables and assignments
- More straightforward sequential logic
- Easier to read and maintain
- Same functionality with less code
- Still synthesizes to efficient hardware
