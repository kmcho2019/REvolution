Simplified decade counter implementation with these optimizations:
1. Combined next-state logic directly in the sequential block
2. Simplified terminal count detection using equality comparison (q == 9)
3. Maintained synchronous reset functionality
4. Reduced logic levels by eliminating intermediate wires
5. Single always block approach minimizes overhead

Advantages:
- Fewer logic levels (better timing)
- Clearer terminal count condition
- Reduced resource usage
- Maintains same functionality with simpler structure
