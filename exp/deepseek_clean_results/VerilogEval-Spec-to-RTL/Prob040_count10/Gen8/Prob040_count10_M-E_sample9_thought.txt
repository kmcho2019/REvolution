Novel LFSR-inspired decade counter design:
1. Instead of conventional binary counting, use a modified LFSR approach
2. Implement custom feedback logic to create a cycle of exactly 10 states
3. Use a 4-bit register like standard implementation but with non-linear progression
4. The sequence will be: 0000→0001→0011→0111→1111→1110→1100→1001→0010→0100→0000...
5. Advantages:
   - Potentially simpler terminal condition detection (just checking for 0100)
   - Reduced switching activity compared to binary counter (fewer bits toggle per cycle)
   - Novel state sequence that might offer better PPA in some implementations
6. Reset initializes to 0000 (same as conventional counter)
