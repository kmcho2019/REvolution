To implement a decade counter (0-9) with synchronous reset, we'll use a 4-bit register to store the count value. The counter should increment on each positive clock edge, wrapping around to 0 after reaching 9. The synchronous reset will force the counter to 0 when active. The key points are:
1. Use a 4-bit register for the counter
2. Increment on clock edge unless at 9, then wrap to 0
3. Synchronous reset overrides normal counting
4. Output the current count value
