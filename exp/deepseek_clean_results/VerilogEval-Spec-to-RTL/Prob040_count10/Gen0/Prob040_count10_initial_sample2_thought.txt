To implement a decade counter (0-9) with synchronous reset:
1. Use a 4-bit register to store the counter value since we need to count up to 9 (1001 in binary)
2. On each positive clock edge:
   - If reset is high, set counter to 0
   - Otherwise, increment counter by 1
   - If counter reaches 9, wrap around to 0
3. Output the current counter value
