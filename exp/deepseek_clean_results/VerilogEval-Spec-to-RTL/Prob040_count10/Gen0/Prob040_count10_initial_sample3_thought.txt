To implement a decade counter (0-9) with synchronous reset:
1. Use a 4-bit register to store the current count value
2. On each clock edge:
   - If reset is high, set count to 0
   - Otherwise, increment count by 1, wrapping around to 0 after 9
3. The output q directly connects to the count register
4. The counter naturally rolls over from 9 (1001) to 0 (0000) when incremented
