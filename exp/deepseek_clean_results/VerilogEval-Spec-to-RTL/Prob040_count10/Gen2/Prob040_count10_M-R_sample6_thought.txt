To refactor the decade counter while maintaining the same functionality, I'll implement it using a continuous assignment for the next state logic combined with a sequential always block. The key changes are:
1. Use a continuous assignment to calculate the next state value
2. Keep the sequential update in a separate always block
3. This separates the combinational and sequential logic clearly
4. The structure makes it easier to add additional combinational logic if needed later
5. The reset remains synchronous and active high
