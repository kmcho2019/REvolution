To refactor the decade counter while maintaining the same functionality:
1. Use combinational logic to calculate the next count value
2. Separate the sequential and combinational parts:
   - Combinational part handles the increment and wrap-around logic
   - Sequential part handles the clocked register update
3. Use an `assign` statement for the combinational next-state logic
4. Keep the synchronous reset in the sequential block
This approach makes the design more modular and potentially easier to optimize during synthesis.
