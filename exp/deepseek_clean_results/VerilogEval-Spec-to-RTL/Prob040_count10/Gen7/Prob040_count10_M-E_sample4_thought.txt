Novel Approach: State Machine with Gray Encoding
1. Instead of a binary counter, implement a state machine with Gray code encoding
2. Gray code changes only one bit per transition, reducing switching power
3. Use a 4-bit one-hot encoding for states 0-9, then convert to binary output
4. Advantages:
   - Reduced switching activity (only one bit changes per count)
   - Simple next-state logic (just shift register with wrap-around)
   - Synchronous reset maintains clean state transitions
5. Implementation:
   - 10-bit internal state register (one-hot)
   - Shift left with wrap-around for counting
   - Priority encoder to convert to 4-bit binary output
   - Reset forces state to 0000000001 (state 0)
