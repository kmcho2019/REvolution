Novel architectural idea:
1. Instead of a conventional binary counter, implement a linear feedback shift register (LFSR) style counter
2. Use a 4-bit shift register with specific feedback to create a 10-state cycle
3. The feedback pattern is designed to sequence through values 1-9 then reset to 0
4. Key advantages:
   - Eliminates adder logic, reducing critical path
   - Uses simple shift operations which are hardware-efficient
   - Feedback pattern can be optimized for minimal logic
5. The sequence is: 0001→0010→0100→1000→0001→0010→0100→1001→0001→0010→... (adjusted to count 0-9)
6. Reset forces all bits to 0 synchronously
