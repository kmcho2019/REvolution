Refactoring Strategy:
1. Maintain the same decade counter functionality (0-9 count)
2. Use continuous assignment (assign) instead of always block for combinational logic
3. Keep synchronous reset behavior but implement it with a separate always block
4. Split the design into:
   - Combinational next-state logic using assign
   - Sequential state update using always block
5. This approach makes the design more modular and potentially easier to optimize during synthesis
6. The terminal count detection remains the same (q[3] & q[0]) for efficiency

Key Benefits:
- Clear separation of combinational and sequential logic
- Potential for better synthesis optimization
- Maintains same performance characteristics
- More explicit data flow
- Easier to add additional combinational logic if needed
