Refactored decade counter implementation with these key changes:
1. Replace the sequential always block with continuous assignment using ternary operators
2. Maintain the same efficient terminal count detection (q[3] & q[0])
3. Use a wire declaration for the counter output instead of reg
4. Implement the synchronous reset and increment logic purely with combinational assignments
5. The functionality remains identical but demonstrates an alternative coding style

Benefits:
- Shows how to implement sequential logic without always blocks
- Demonstrates pure combinational implementation of state transitions
- Maintains all original functionality and optimizations
- Provides an alternative coding style that some designers prefer
- Still synthesizes to the same basic circuit structure
