Novel approach using Gray code encoding with synchronous reset:
1. Implement the counter using Gray code instead of binary for reduced switching power
2. Use a combinational binary-to-Gray converter for the output
3. Internal counting remains binary for simpler rollover logic
4. Gray code output reduces switching activity by only changing one bit per count
5. Maintain same synchronous reset functionality
6. Special case handling for 9->0 transition to ensure single-bit change

Key advantages:
- Reduced dynamic power consumption due to Gray code output
- Maintains simple internal binary counting logic
- Single-bit changes between consecutive counts
- Same reset behavior and counting sequence
