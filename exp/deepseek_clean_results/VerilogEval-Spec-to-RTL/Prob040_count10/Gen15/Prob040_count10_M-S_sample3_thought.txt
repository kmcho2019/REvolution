Simplified design approach:
1. Maintain decade counter functionality (0-9) with synchronous reset
2. Use a single always block for sequential logic
3. Simplify terminal count detection by checking for exact value 4'b1001 (9)
4. Directly increment counter and handle rollover in one step
5. Remove unnecessary intermediate logic for cleaner implementation

Key simplifications:
- Single always block with clear priority (reset first)
- Explicit check for value 9 makes intent clearer
- Direct increment with rollover handling
- Fewer logical operations than bitwise AND approach
- Maintains same functionality with simpler code
