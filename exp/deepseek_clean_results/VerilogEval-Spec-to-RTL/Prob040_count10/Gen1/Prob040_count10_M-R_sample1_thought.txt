Refactored approach using continuous assignment and combinational logic:
1. Separate the combinational next-state logic from sequential storage
2. Use an always block only for the sequential register update
3. Calculate the next count value using continuous assignment:
   - If current count is 9, next is 0
   - Otherwise increment current count
4. The register updates on clock edge with synchronous reset
This separates concerns and makes the logic more modular
