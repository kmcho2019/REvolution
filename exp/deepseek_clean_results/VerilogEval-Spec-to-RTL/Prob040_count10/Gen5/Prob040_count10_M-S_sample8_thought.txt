Simplified approach using binary counting with modulo-10 wrap:
1. Implement a standard 4-bit binary counter
2. When count reaches 9 (4'b1001), reset to 0 on next clock
3. Otherwise, simply increment the counter
4. Advantages:
   - Simpler logic with just an increment and conditional reset
   - Better timing as it uses arithmetic operations
   - More straightforward implementation
   - Maintains same functionality with less code
5. Reset still initializes to 0 synchronously
