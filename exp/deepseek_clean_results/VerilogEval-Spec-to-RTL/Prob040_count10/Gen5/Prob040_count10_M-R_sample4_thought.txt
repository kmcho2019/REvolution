Refactored decade counter implementation with these key changes:
1. Separated combinational next-state logic from sequential state storage
2. Used continuous assignments for next-state calculation
3. Maintained the same efficient terminal count detection (q[3] & q[0])
4. Kept synchronous reset functionality
5. Improved readability by separating concerns (combinational vs sequential)

Advantages:
- Clear separation of combinational and sequential logic
- Easier to add additional combinational logic if needed
- More explicit about the counter's behavior
- Maintains same PPA characteristics while being more modular
