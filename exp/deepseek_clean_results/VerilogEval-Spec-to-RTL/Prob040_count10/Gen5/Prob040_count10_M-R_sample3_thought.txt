Refactoring Strategy:
1. Structural Change: 
   - Move the counter logic to a continuous assignment (assign) for the next state
   - Keep the sequential element (register) in an always block
   - This separates combinational and sequential logic clearly

2. Logic Simplification:
   - Use a wire for the next state calculation
   - The reset condition remains synchronous but is now part of the combinational logic
   - The wrap-around condition is still detected by checking bits 3 and 0 (for 9 = 1001)

3. Benefits:
   - Clear separation of combinational and sequential logic
   - Same functionality but with potentially better synthesis results
   - Easier to modify the combinational logic independently
   - Maintains all original PPA advantages
