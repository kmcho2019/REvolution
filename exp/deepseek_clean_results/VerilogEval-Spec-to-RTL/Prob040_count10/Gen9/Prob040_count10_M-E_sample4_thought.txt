Novel Approach: Binary-to-One-Hot Decade Counter
1. Instead of using binary counting, implement a one-hot decade counter (10 states)
2. Use a circular shift register approach where only one bit is active at a time
3. Convert the one-hot encoding to binary output using a simple encoder
4. Advantages:
   - Simple state transitions (just shift operations)
   - Glitch-free outputs since only one bit changes at a time
   - Easy to decode terminal count (just check the last bit)
   - Lower power consumption in some technologies due to reduced switching
5. Reset initializes to first state (0000000001)
6. Clock edge shifts the '1' through the register, wrapping around after 10 counts
7. Special case: when reaching 1000000000, next state is 0000000001
8. Simple encoder converts one-hot to 4-bit binary (0-9)
