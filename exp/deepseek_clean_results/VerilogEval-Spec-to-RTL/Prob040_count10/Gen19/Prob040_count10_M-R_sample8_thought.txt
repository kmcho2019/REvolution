Refactoring strategy:
1. Use continuous assignment for combinational logic: 
   - Move the next state logic to an assign statement
   - This makes the code more modular and separates combinational/sequential logic
2. Simplify the terminal count detection:
   - Use direct equality comparison (q == 9) instead of bitwise AND
   - This is more readable and may synthesize more efficiently
3. Maintain same functionality:
   - Still counts 0-9 with synchronous reset
   - Same period of 10 clock cycles
4. Benefits:
   - Clear separation of combinational and sequential logic
   - More readable terminal count condition
   - Same PPA benefits as original (no additional logic introduced)
