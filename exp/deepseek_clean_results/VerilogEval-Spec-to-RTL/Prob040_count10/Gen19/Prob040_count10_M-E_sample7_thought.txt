Novel Architectural Idea: LFSR-based Decade Counter
1. Instead of using a binary counter, implement a Linear Feedback Shift Register (LFSR) that cycles through 10 unique states
2. Carefully select the feedback polynomial to ensure exactly 10 states before repeating
3. Use a custom state mapping to convert LFSR states to binary values 0-9
4. Advantages:
   - Potentially lower power due to fewer bit toggles
   - Different critical path (XOR-based instead of adder-based)
   - Novel approach that might have better PPA in certain technologies
5. Implementation:
   - 4-bit LFSR with custom polynomial (x^4 + x^1 + 1)
   - State mapping using combinational logic
   - Synchronous reset to initialize to state 0
