Novel approach: Using a shift register with feedback
1. Instead of a conventional binary counter, implement the decade counter using a 10-bit shift register
2. The shift register will have a single '1' that circulates through the bits
3. The position of the '1' represents the count value (one-hot encoding)
4. Feedback logic resets the counter by shifting the '1' back to position 0
5. Output decoder converts the one-hot state to 4-bit binary
6. Benefits: 
   - Simple sequential logic (just shifting)
   - Glitch-free outputs from the decoder
   - Easy to extend to other counting ranges
   - No arithmetic operations needed
