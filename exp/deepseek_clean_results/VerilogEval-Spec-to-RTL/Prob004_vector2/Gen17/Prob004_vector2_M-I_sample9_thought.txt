2. Using direct bit assignments instead of range selections to potentially help synthesis tools
3. Maintaining the exact same functionality while potentially reducing any minimal synthesis tool interpretation overhead

- Still perform byte-order reversal
- Have identical functionality
- Potentially save a tiny amount of area by being more explicit
- Maintain the same excellent timing characteristics
- Use the most straightforward implementation possible
