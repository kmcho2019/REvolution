Here's a novel approach using a parameterized for-loop to reverse the bytes. Instead of direct concatenation, we'll:
1. Iterate through each byte (4 iterations for 32-bit)
2. Calculate the target position for each byte (reversed order)
3. Assign each byte to its reversed position

This approach demonstrates:
- More flexible code that could be parameterized for different widths
- Shows an alternative implementation using procedural assignment
- Maintains the same zero-delay characteristic
- Could be extended to more complex reordering patterns
