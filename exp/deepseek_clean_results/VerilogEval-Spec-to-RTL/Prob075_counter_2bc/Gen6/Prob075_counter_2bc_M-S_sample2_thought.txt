Simplified Approach: Direct Arithmetic with Saturation
1. Use arithmetic operations with saturation bounds for simpler logic
2. Eliminate the separate next_state register and combinational block by combining into a single always block
3. Handle all conditions directly with arithmetic and saturation checks
4. Maintain asynchronous reset behavior
5. Simplify state transitions to basic increment/decrement operations with bounds checking

Key Advantages:
- Reduced logic complexity (single always block)
- Clearer arithmetic-based state transitions
- Fewer conditional checks (only bounds checking)
- Maintains same functionality with simpler implementation
- Better timing due to reduced logic levels
