Novel Architectural Idea: State Transition Lookup Table
1. Instead of using arithmetic operations or nested conditionals, implement the counter as a pure state machine with all transitions encoded in a lookup table
2. Use a 4-bit concatenation of {train_valid, train_taken, current_state} as the lookup address to directly output next_state
3. This approach:
   - Eliminates arithmetic logic entirely
   - Provides deterministic timing (single LUT access)
   - Makes all state transitions explicit and easily verifiable
   - Naturally handles saturation through the lookup table values
4. Reset still handled asynchronously with priority
5. The lookup table can be optimized during synthesis to minimal logic
