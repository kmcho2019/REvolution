Simplified Design Idea:
1. Use a simple 2-bit register for the counter state
2. Implement increment/decrement using arithmetic operations with saturation
3. Reset to 2'b01 as specified
4. Only update the counter when train_valid is high
5. Remove unnecessary state encoding and case statements
6. Use simple if-else conditions for saturation checks

Key Benefits:
- Reduced logic complexity by using arithmetic instead of state transitions
- Fewer lines of code while maintaining same functionality
- More straightforward implementation
- Easier to understand and verify
- Better timing due to simpler combinational logic
