The original implementation uses a case statement to handle all possible state transitions, which can be error-prone and harder to maintain. Instead, we can simplify the logic by:
1. Keeping the asynchronous reset behavior
2. Using arithmetic operations with saturation checks for increment/decrement
3. Separating the next state logic from the state register
4. Using a ternary operator for cleaner conditional logic

This approach will make the code more concise and easier to verify while maintaining the same functionality.
