Simplification Approach:
1. Remove the separate combinational next_state logic and merge it into the sequential block
2. Eliminate the intermediate wire declaration by computing next state directly in the always block
3. Maintain saturation by using simple if-else conditions
4. Keep the same reset behavior (weakly not-taken = 2'b01)
5. Reduce logic levels by combining all state transitions in one always block

Key Benefits:
- Fewer lines of code
- No intermediate signals
- Same functionality with simpler structure
- More direct representation of the state machine
- Easier to understand and maintain
