Novel Approach: State Transition Lookup Table
1. Instead of using arithmetic operations, implement the state transitions using a lookup table approach
2. Encode all possible current states and input combinations to directly output the next state
3. Use a combinational always block to implement the lookup table behavior
4. This approach eliminates arithmetic operations and replaces them with direct state mapping
5. The lookup table can potentially be optimized by synthesis tools for better PPA
6. Maintain the same asynchronous reset behavior

Advantages:
- Eliminates arithmetic operations which can be area/power intensive
- Clear mapping of all state transitions in one place
- Potential for better synthesis optimization
- Easier to modify state transition behavior if requirements change
