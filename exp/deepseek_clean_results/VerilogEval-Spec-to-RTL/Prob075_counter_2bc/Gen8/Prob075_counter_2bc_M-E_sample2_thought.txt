Novel Architectural Idea:
1. Use arithmetic operations for counter updates instead of state transitions
2. Implement saturation using comparison operations before updates
3. Combine increment/decrement logic into a single arithmetic expression
4. Use a ternary operator for compact update logic
5. Leverage Verilog's built-in arithmetic for efficient synthesis

Key Benefits:
- More compact code with fewer lines
- Better utilization of arithmetic units in modern FPGAs/ASICs
- Easier to parameterize for different counter widths
- Reduced logic depth due to direct arithmetic operations
- Clearer relationship between input conditions and counter behavior
