Simplification Approach:
1. Replace case statement with simple arithmetic operations and saturation checks
2. Use a single always block for both combinational and sequential logic
3. Maintain same reset behavior (weakly not-taken = 2'b01)
4. Simplify increment/decrement logic using +1/-1 with min/max bounds
5. Remove separate next_state register to reduce area

Key Benefits:
- Fewer lines of code
- Single always block simplifies control flow
- Arithmetic operations are more intuitive than case statement
- Still maintains all original functionality
- Likely better PPA due to simpler logic
