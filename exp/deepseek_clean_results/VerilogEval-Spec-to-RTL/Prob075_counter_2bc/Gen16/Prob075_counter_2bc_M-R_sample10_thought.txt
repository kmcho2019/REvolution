Refactoring Approach:
1. Eliminate the separate combinational block by moving next_state logic directly into the always block
2. Use case statement for state transitions instead of nested conditionals for better readability and potentially better synthesis
3. Remove localparam definitions since we're using direct 2-bit values
4. Maintain the same asynchronous reset behavior and saturation logic
5. Keep the power-efficient train_valid gating

Key Benefits:
- Reduced logic levels by flattening the state transition logic
- More readable state transitions using case statement
- Slightly reduced area by eliminating the next_state wire
- Maintains same timing characteristics while being more maintainable
