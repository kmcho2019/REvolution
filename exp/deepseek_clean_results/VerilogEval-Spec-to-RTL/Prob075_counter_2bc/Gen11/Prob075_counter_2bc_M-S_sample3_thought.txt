Simplified Design Idea:
1. Remove the explicit state encoding (S0-S3) since we can work directly with the 2-bit counter values
2. Eliminate the separate next_state register and combine the logic into a single always block
3. Use simple arithmetic with saturation checks instead of case statements
4. Maintain the same reset behavior (weakly not-taken = 2'b01)
5. Keep the core functionality: increment on taken, decrement on not-taken, hold when not training

Key Simplifications:
- Removed redundant state encoding parameters
- Combined sequential and combinational logic
- Replaced case statement with arithmetic operations
- Reduced lines of code while maintaining same behavior
- Still maintains all original requirements
