Refactoring Strategy:
1. Simplify the state transition logic by:
   - Using a single always block for sequential logic
   - Removing clock gating (minimal benefit for small state machine)
   - Implementing saturation checks with simple boundary comparisons
   - Using arithmetic operations directly in the always block

2. Improve readability by:
   - Using clear if-else structure instead of nested ternary operators
   - Grouping related conditions together
   - Adding comments for state transitions

3. Maintain functionality while reducing:
   - Combinational logic complexity
   - Unnecessary control signals
   - Potential glitches in next-state logic

Key Changes:
- Removed clock gating (simpler, minimal power impact)
- Flattened state transition logic
- Direct arithmetic in always block
- Clear boundary checks for saturation
- Maintained same reset behavior
