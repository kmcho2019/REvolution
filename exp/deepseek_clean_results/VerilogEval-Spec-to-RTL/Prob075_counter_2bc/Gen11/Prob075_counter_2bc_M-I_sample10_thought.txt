Improvement Strategy:
1. Timing Optimization:
   - Remove clock gating to eliminate its combinational delay
   - Simplify saturation logic using direct bit manipulation instead of comparisons
   - Use parallel case structure for next-state logic

2. Power Optimization:
   - Reduce switching activity by detecting no-change conditions early
   - Use bit-level operations that minimize transistor switching
   - Remove redundant logic transitions at saturation points

3. Area Optimization:
   - Simplify state transition logic using minimal gates
   - Combine related conditions to reduce logic gates
   - Remove intermediate signals where possible

Key Changes:
- Eliminated clock gating for better timing
- Simplified saturation checks using bit patterns
- Early termination for no-change cases
- More efficient increment/decrement logic
- Maintained clean asynchronous reset
