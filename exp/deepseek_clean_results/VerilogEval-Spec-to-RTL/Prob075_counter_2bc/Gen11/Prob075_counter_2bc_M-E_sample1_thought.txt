Novel Approach: State Transition Matrix with Parallel Evaluation
1. Represent the counter as a 4-state FSM with explicit state transitions
2. Use a parallel evaluation approach where all possible next states are computed simultaneously
3. Select the correct next state using a priority-encoded multiplexer
4. Implement saturation checks using simple bitwise operations instead of comparisons
5. Optimize power by gating the state transition logic with train_valid

Key Advantages:
- Parallel path evaluation reduces critical path delay
- Explicit state encoding improves readability and synthesis optimization
- Bitwise saturation checks are more hardware-efficient than comparisons
- Train_valid gating reduces unnecessary switching activity
- Clear separation of state transition logic from state storage
