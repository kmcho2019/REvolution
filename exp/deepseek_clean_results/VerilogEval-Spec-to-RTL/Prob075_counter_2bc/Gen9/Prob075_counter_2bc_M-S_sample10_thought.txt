Simplified Design Idea:
1. Remove explicit state encoding (localparams) since we're dealing with simple 2-bit values
2. Combine the combinational and sequential logic into a single always block for simplicity
3. Use arithmetic operations with saturation checks instead of case statements
4. Maintain the same reset behavior (weakly not-taken = 2'b01)
5. Keep the same functionality: increment on taken, decrement on not-taken, hold when not training

Key Simplifications:
- Eliminates separate next_state logic
- Removes case statement in favor of arithmetic operations
- Reduces code size while maintaining same behavior
- Still maintains clear asynchronous reset
