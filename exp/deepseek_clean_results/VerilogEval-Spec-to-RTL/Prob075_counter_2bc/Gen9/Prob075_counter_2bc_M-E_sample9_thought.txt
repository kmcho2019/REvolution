Novel Approach: State Machine with Explicit Transitions
1. Model the counter as a finite state machine with 4 explicit states (0-3)
2. Use a case statement for clear state transitions based on inputs
3. Implement saturation by preventing transitions beyond min/max states
4. Separate the state transition logic from state storage
5. Use a dedicated always block for reset and clocked updates

Key Advantages:
- More readable and maintainable state transitions
- Explicit handling of boundary conditions
- Easier to modify or extend state behavior
- Clear mapping between spec requirements and implementation
- Potential for better synthesis of state machine logic
