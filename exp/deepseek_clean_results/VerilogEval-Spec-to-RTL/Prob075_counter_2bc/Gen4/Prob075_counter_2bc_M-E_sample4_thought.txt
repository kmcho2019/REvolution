This implementation uses arithmetic operations with explicit saturation checks, which:
1. Uses addition/subtraction operations for state transitions
2. Implements saturation logic through simple bitwise operations
3. Combines the increment/decrement logic into a single expression
4. Uses masking to handle the train_valid condition
5. Reduces the state machine to simple arithmetic operations
The key innovation is using the train_taken signal directly in the arithmetic operation (via sign extension and masking) to handle both increment and decrement cases in one expression.
