Simplified Design Idea:
1. Use a straightforward 2-bit counter with arithmetic operations instead of state machine
2. Implement saturation by checking bounds before incrementing/decrementing
3. Use a single always block for synchronous logic with asynchronous reset
4. Simplify the logic by directly using addition/subtraction with saturation checks
5. Remove unnecessary one-hot encoding since it's not beneficial for a 2-bit counter

Key Benefits:
- Reduced logic complexity by using arithmetic operations
- Single always block makes the code more concise
- Easier to understand and maintain
- Potentially better synthesis results due to simpler logic
