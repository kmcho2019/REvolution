Novel Approach: State Machine with Explicit Transitions
1. Instead of using arithmetic operations, model the counter as a finite state machine with explicit state transitions
2. Define all possible state transitions in a case statement for clarity and potential synthesis optimization
3. Use a separate combinational block for next state calculation to improve timing
4. Implement saturation by limiting state transitions at boundaries (0 and 3)
5. Maintain asynchronous reset behavior but with more explicit state encoding

Key Advantages:
- More deterministic state transitions
- Potentially better synthesis results due to explicit state encoding
- Easier to modify or extend state behavior
- Clear mapping between requirements and implementation
- Better timing characteristics due to reduced arithmetic operations
