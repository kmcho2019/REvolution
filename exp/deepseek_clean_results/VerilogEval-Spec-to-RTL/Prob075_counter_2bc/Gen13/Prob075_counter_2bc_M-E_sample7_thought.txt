Novel Architectural Idea:
1. Instead of using a traditional saturating counter with explicit state transitions, implement a compact arithmetic-based approach that handles saturation implicitly
2. Use arithmetic operations with boundary checks to handle increment/decrement
3. Leverage Verilog's built-in arithmetic saturation by using min/max functions
4. Combine the training and taken signals into a single control signal (-1 for not taken, +1 for taken)
5. Use a single always block for both sequential and combinational logic to reduce area
6. Implement the reset value directly in the register initialization

Key Advantages:
- More compact implementation using arithmetic operations
- Implicit handling of saturation through boundary checks
- Reduced logic complexity compared to state machine approach
- Single always block simplifies the design
- Potential for better synthesis optimization due to arithmetic operations
