Instead of using standard binary counting, we can implement a thermometer-coded saturating counter:
1. Use state encoding where each bit represents a saturation level (00=0, 01=1, 11=3, 10=2)
2. This allows simpler saturation checks - MSB indicates full saturation
3. Update logic becomes simpler XOR operations for increment/decrement
4. Reset to '01' (weakly not-taken) remains the same
5. The thermometer coding makes saturation detection trivial (no comparators needed)
