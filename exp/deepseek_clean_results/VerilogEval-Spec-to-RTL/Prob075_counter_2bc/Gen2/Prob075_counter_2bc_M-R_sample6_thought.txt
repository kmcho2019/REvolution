Refactoring Strategy:
1. Replace the procedural always block with continuous assignments for the next state logic
2. Use combinational logic to calculate the next state based on current state and inputs
3. Separate the saturation logic into explicit min/max functions
4. Maintain the same asynchronous reset behavior but implement it through a mux
5. Use a register to store the state, updated on clock edges

Key benefits:
- More explicit dataflow representation
- Clear separation of combinational and sequential logic
- Easier to pipeline if needed
- Potential for better synthesis optimization
