2. Update Logic: Use the more efficient ternary operator approach from Example 1, but optimize the saturation checks:
   - For increment: Check if counter == 3 (2'b11) using bitwise AND
   - For decrement: Check if counter == 0 (2'b00) using reduction NOR
3. Power Optimization: Only update counter when train_valid is high
4. Timing Optimization: Simplify the critical path by:
   - Using bitwise operations for saturation checks instead of case statements
   - Making the increment/decrement decision parallel rather than sequential
5. Area Optimization: Maintain minimal 2-bit register and simple combinational logic

This approach should provide better timing (reduced WNS) while maintaining low power and area efficiency.
