Instead of using arithmetic operations with saturation checks, we can implement the counter as a finite state machine with explicit state transitions. This approach:
1. Uses a combinational block to calculate next state based on current state and inputs
2. Encodes all possible transitions in a truth-table style
3. Separates the state transition logic from the state register
4. May offer better optimization opportunities for synthesis tools
5. Makes the saturation behavior explicit in the transition table
