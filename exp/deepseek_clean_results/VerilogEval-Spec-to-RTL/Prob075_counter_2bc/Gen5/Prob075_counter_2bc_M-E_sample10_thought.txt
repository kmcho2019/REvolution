This solution implements the counter using bitwise operations and saturation logic. The key innovations are:
1. Uses a single always block with parallel bit operations
2. Implements saturation through bitwise masking instead of comparisons
3. Combines increment/decrement logic into a single expression
4. Eliminates the need for case statements or state definitions
5. Uses clever bit manipulation to handle all cases in parallel:
   - For increment: state + (train_valid & train_taken) but capped at 3
   - For decrement: state - (train_valid & ~train_taken) but floored at 0
   - The saturation is achieved by masking the result with 2'b11 for max and 2'b00 for min
