Optimization Strategy:
1. Replace one-hot encoding with binary arithmetic for simpler logic
2. Use arithmetic operations (addition/subtraction) instead of case statements to reduce logic depth
3. Implement saturation using min/max bounds checking
4. Consolidate reset value into a single parameter
5. Maintain the same functionality while improving timing and area

Key Improvements:
- Arithmetic approach reduces logic depth for better timing (WNS)
- Simpler logic structure reduces area
- Maintains same power characteristics while being more efficient
- Easier to verify and extend to larger counters if needed
- Single parameter for reset value improves maintainability
