Novel Architectural Idea:
1. Instead of using a traditional state machine approach, implement the counter using arithmetic operations with explicit saturation checks
2. Use a single always_ff block to combine the sequential and combinational logic, reducing the critical path
3. Implement saturation by checking bounds before arithmetic operations rather than after
4. Use bitwise operations for increment/decrement to potentially reduce logic complexity
5. Maintain the same reset behavior but implement it more efficiently within the combined always block

Key Advantages:
- Arithmetic approach may reduce logic depth compared to case statements
- Single always block reduces path between registers
- Early saturation checks prevent unnecessary arithmetic operations
- More direct implementation of the counter behavior
- Potential for better timing due to reduced logic levels
