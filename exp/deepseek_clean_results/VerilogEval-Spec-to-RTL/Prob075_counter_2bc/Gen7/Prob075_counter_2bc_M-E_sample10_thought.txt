Novel Architectural Idea: State Transition Lookup Table
Instead of using arithmetic operations and comparisons for state transitions, we can implement a lookup table approach that encodes all possible state transitions. This can potentially reduce critical path delay by converting arithmetic operations into simple table lookups.

Key features:
1. Use a 4-entry lookup table (LUT) for each possible current state (00, 01, 10, 11)
2. The LUT outputs are pre-computed next states based on train_valid and train_taken
3. This eliminates arithmetic operations and saturation checks from the critical path
4. Still maintains the same functionality but with potentially better timing
5. Asynchronous reset remains unchanged
