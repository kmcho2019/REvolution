Refactored Design Idea:
1. Replace the explicit FSM with arithmetic operations for more compact logic
2. Use continuous assignments for next_state calculation to simplify the design
3. Maintain saturation by clamping the counter value after arithmetic operations
4. Keep the same reset behavior and synchronous update logic
5. Optimize for area and power by reducing redundant logic

Key Improvements:
- More compact implementation using arithmetic operations
- Reduced logic depth by combining increment/decrement into single expressions
- Clearer saturation logic using min/max comparisons
- Fewer lines of code while maintaining same functionality
- Better potential for synthesis optimization
