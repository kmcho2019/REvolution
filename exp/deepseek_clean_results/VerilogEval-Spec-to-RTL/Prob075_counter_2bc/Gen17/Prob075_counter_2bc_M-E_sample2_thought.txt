Novel Approach: State Transition Matrix
1. Represent the counter as a 4-state FSM with explicit state encoding
2. Use a transition matrix that combines all control signals (train_valid, train_taken) into a single decision index
3. Implement next-state logic using a compact case statement that handles all possible transitions
4. Optimize for power by gating the state transitions only when train_valid is active
5. Use one-hot encoding for the state register to potentially improve timing in some technologies

Key Advantages:
- Clear separation of states and transitions
- Easily extensible to more complex prediction schemes
- Potential power savings from explicit state encoding
- More synthesis-friendly than arithmetic approaches
- Better testability with explicit state representation
