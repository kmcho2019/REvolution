This implementation uses a shift register concept with saturation control:
1. Instead of arithmetic operations, we use bit shifting with saturation
2. The counter is treated as a thermometer code where:
   - 00: strongly not-taken
   - 01: weakly not-taken
   - 10: weakly taken
   - 11: strongly taken
3. Increment/decrement operations become right/left shifts with saturation
4. Reset sets to weakly not-taken (01)
5. Saturation is handled by preventing shifts beyond boundaries
6. The implementation uses parallel logic for shift direction selection

Advantages:
- Eliminates arithmetic operations in favor of simpler shift logic
- Parallel path for increment/decrement decisions improves timing
- Saturation is naturally handled by shift boundaries
- Power efficient as only relevant bits toggle
- Area efficient with minimal logic gates
