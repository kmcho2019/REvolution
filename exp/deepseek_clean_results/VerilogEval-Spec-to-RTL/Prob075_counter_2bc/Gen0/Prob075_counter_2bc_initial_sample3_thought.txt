The design requires a 2-bit saturating counter with the following behavior:
1. Asynchronous reset (areset) sets the counter to 2'b01
2. On each clock edge:
   - If train_valid is high:
     - Increment counter (up to 3) if train_taken is high
     - Decrement counter (down to 0) if train_taken is low
   - Else maintain current counter value
The counter should be implemented using sequential logic with positive edge triggering.
