Novel Approach: LUT-Based Population Count
1. For a small 3-bit input, we can leverage a Look-Up Table (LUT) approach which maps each possible input combination directly to its population count
2. This eliminates any arithmetic operations and reduces the solution to pure combinational logic
3. The 8 possible input combinations (3 bits) can be hardwired to their corresponding counts (0-3)
4. This approach offers:
   - Constant time operation regardless of input pattern
   - No carry propagation delays
   - Potential area savings in some technologies
   - Extremely predictable timing characteristics
5. The output is simply a case statement that maps each input pattern to its count value
