Instead of using arithmetic operations, we can implement the population count as a pure combinational logic function that maps each possible 3-bit input to its corresponding count value. This approach:
1. Enumerates all 8 possible input combinations (000 to 111)
2. Directly assigns the correct output for each case
3. Uses a case statement for clear mapping
4. Has identical functionality but different implementation style
5. May have different synthesis results (though same logical function)
6. Shows an alternative way to think about the problem (truth table approach)
