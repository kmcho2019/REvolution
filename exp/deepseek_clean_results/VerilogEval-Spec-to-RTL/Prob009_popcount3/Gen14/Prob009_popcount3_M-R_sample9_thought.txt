The original solution uses a single continuous assignment with nested additions. I'll refactor this to:
1. Break down the population count into two explicit steps for better readability
2. Use an intermediate wire to store the count of lower 2 bits
3. Then add the MSB separately
4. Maintain the same functionality while making the computation stages more visible

This approach makes the design more modular and easier to understand, while keeping the same optimal PPA characteristics since synthesis tools will optimize it to the same structure.
