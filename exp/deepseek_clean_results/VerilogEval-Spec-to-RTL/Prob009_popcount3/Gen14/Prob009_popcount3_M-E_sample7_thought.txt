Novel Approach: Bit-Serial Population Count
1. Instead of parallel computation, implement a bit-serial approach that processes each input bit sequentially
2. Use a 2-bit accumulator to count the '1's over 3 clock cycles
3. Leverage a simple state machine to track the current bit position
4. Advantages:
   - Reduced combinational logic (only 1-bit adder)
   - Lower dynamic power due to reduced switching activity
   - Scalable to wider inputs with minimal changes
   - Better for timing closure in deep pipelines
5. Trade-off: Requires 3 clock cycles to complete, but enables time-multiplexing of resources
