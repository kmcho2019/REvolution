Novel LUT-Based Approach:
1. Pre-compute all possible outputs for the 3-bit input (8 cases)
2. Implement as a pure combinational LUT using case statement
3. Benefits:
   - Eliminates arithmetic logic entirely
   - Guaranteed constant-time operation regardless of input pattern
   - Potentially better for power as it avoids adder switching activity
   - Very predictable timing characteristics
   - Scales well to FPGA architectures that have native LUT resources
4. Trade-offs:
   - Slightly more verbose code
   - For larger bit-widths, this would become impractical
   - Still maintains minimal area for 3-bit case
