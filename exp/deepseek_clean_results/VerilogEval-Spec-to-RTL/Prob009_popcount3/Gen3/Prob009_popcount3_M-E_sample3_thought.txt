Here's a novel approach using a lookup table (LUT) implemented as a case statement. This method:
1. Pre-computes all possible 3-bit combinations (8 cases)
2. Directly maps each input to its population count
3. Eliminates any adder logic, potentially reducing power and area
4. Provides deterministic timing since it's just a multiplexer

While this approach uses more lines of code, it may offer better PPA for certain technologies where case statements synthesize more efficiently than adders for small input sizes.
