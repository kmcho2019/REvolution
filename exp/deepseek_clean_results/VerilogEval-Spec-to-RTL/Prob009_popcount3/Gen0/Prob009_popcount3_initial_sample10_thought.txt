To implement a population count (popcount) circuit for a 3-bit input, we need to count how many of the 3 input bits are set to '1'. The output needs to be 2 bits wide since the maximum count is 3 (which is '11' in binary).

The straightforward approach is to:
1. Examine each input bit
2. Sum up the number of '1's
3. Output the 2-bit binary representation of this sum

For a 3-bit input, the possible outputs are:
- 0 (00) when no bits are set
- 1 (01) when one bit is set
- 2 (10) when two bits are set
- 3 (11) when all three bits are set
