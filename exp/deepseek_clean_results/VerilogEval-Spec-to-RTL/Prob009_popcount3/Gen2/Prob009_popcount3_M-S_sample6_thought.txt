The current implementation is already quite minimal, but we can simplify it further by recognizing that for a 3-bit input, we can directly map each possible input combination to its corresponding population count output. This eliminates the need for any arithmetic operations and reduces the solution to a simple lookup table implemented via a case statement.

The simplification approach:
1. Enumerate all 8 possible input combinations (000 to 111)
2. For each combination, directly assign the corresponding count of '1's
3. This becomes a pure combinational mapping with no arithmetic operations
