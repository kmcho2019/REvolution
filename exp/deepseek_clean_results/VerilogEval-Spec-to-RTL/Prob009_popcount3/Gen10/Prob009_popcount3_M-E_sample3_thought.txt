Novel LUT-Based Approach:
1. Pre-compute all possible 3-bit input combinations (8 cases) and store their population counts
2. Implement as a direct combinatorial LUT using case statement
3. Optimize encoding by:
   - Using thermometer-like encoding for the outputs
   - Minimizing logic by recognizing symmetric input patterns
4. Benefits:
   - Extremely simple and clear implementation
   - Guaranteed minimal logic depth (single MUX level)
   - Easily extensible to wider inputs
   - Naturally maps to FPGA LUT resources if needed
5. Trade-off:
   - Slightly larger area than gate-level for this small case
   - But provides better regularity and predictability
