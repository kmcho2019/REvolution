The original solution uses an always block with nested if-else statements. We can simplify this by:
1. Using continuous assignments instead of procedural blocks
2. Directly expressing the logic requirements in Boolean equations
3. Making the outputs purely combinational functions of the inputs
4. Ensuring only one output is active at a time (mutually exclusive)

The simplified logic is:
- ringer = ring AND NOT vibrate_mode
- motor = ring AND vibrate_mode
This maintains all requirements while being more concise.
