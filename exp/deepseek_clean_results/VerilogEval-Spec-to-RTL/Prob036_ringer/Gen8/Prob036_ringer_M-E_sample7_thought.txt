Here's a novel approach using a multiplexer-based design:
1. Instead of separate AND gates, we'll use a 2:1 mux to select between the two output options
2. The mux select line will be the vibrate_mode input
3. The mux inputs will be: 
   - 0: ring signal (for ringer output)
   - 1: ring signal (for motor output)
4. The unused output will be grounded through the mux structure
5. This approach centralizes the control logic and makes the selection mechanism more explicit

Benefits:
- More scalable if we need to add more modes later
- Clearer selection mechanism
- Potentially better for synthesis in some technology libraries
