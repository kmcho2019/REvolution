This solution introduces a state-based approach that:
1. Uses an explicit enable signal derived from the ring input
2. Implements a priority encoder style selection between ringer and motor
3. Provides better scalability for future features (like different vibration patterns)
4. Makes the control flow more explicit and easier to modify
5. Still maintains mutual exclusivity through structural design

The key innovation is treating this as a resource allocation problem where we "assign" the ring signal to one of two outputs based on mode. This approach would make it easier to add additional modes or features later while keeping the core logic clean.
