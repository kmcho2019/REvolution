Here's a novel approach using a multiplexer (MUX) to select between the ringer and motor outputs. The key differences from the original solution are:
1. Uses a MUX to explicitly show the selection between two mutually exclusive outputs
2. Makes the selection logic more visually apparent in the code
3. Still maintains minimal area while potentially being more readable
4. The MUX approach could scale better if more modes were added in the future

The MUX will select the ringer path when vibrate_mode is 0, and the motor path when vibrate_mode is 1, with the ring signal acting as the enable for the whole system.
