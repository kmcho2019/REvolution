Novel Architecture Idea: State-Based Control with Edge Detection
1. Instead of purely combinational logic, implement a simple state machine that detects the rising edge of the 'ring' signal
2. This approach provides better noise immunity by requiring a clean transition to activate outputs
3. The state machine has only two states: IDLE and ACTIVE
4. In ACTIVE state, outputs are set based on vibrate_mode
5. This design prevents glitches that might occur in purely combinational implementations
6. The state transition happens on the positive edge of 'ring' signal
7. Outputs are mutually exclusive by design in the state machine logic

Advantages:
- More robust against input signal glitches
- Clear state transitions make debugging easier
- Maintains same functionality while being more resilient
- Can be easily extended for more complex behaviors if needed
