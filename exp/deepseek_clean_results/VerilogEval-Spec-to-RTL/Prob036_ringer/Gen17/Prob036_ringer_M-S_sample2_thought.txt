The simplest possible implementation that maintains the required functionality:
1. The ringer should be on only when ring is active and vibrate_mode is off
2. The motor should be on only when both ring and vibrate_mode are active
3. These can be directly implemented with two AND gates, one with an inverted vibrate_mode
4. No need for any additional logic or registers since this is purely combinational
5. The outputs are naturally mutually exclusive due to the vibrate_mode control
