Here's a refactored version that maintains the same functionality but with improved PPA characteristics:

1. Instead of using a 2-bit decoder, we'll implement the logic directly with basic gates
2. This eliminates the intermediate mode signal and reduces the logic depth
3. We'll use continuous assignments (assign) to make the implementation more straightforward
4. The ringer output is simply the ring signal ANDed with the inverse of vibrate_mode
5. The motor output is the ring signal ANDed with vibrate_mode
6. This approach:
   - Reduces area by using only two AND gates and one inverter
   - Improves timing by having just one gate delay for each output
   - Maintains clear functionality while being more efficient
   - Still explicitly shows the mutually exclusive nature of the outputs
7. The structure makes it immediately obvious how inputs map to outputs
