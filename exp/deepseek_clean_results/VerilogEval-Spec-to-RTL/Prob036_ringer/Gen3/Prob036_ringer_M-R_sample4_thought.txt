The original implementation uses continuous assignments with AND gates, which is already optimal. However, we can refactor it to use an always block with if-else statements to make the behavioral intention more explicit while maintaining the same functionality. This approach might be more readable for some designers as it directly maps to the problem's English description. The key benefits are:
1. Same mutual exclusivity guarantee
2. Identical PPA metrics (since synthesis will produce the same gates)
3. More explicit conditional logic structure
4. Easier to modify if additional conditions are needed later
