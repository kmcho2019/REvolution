Novel Approach: State-Based Control with Explicit Mode Handling
1. Instead of pure combinational logic, implement a simple state machine concept (without actual state registers)
2. Use a priority encoder style approach where vibrate_mode has higher priority
3. Implement as a single decision tree with nested conditions for clarity
4. Use explicit parameter definitions for mode constants to improve readability
5. Structure the logic to clearly show the decision hierarchy while maintaining minimal logic depth

Key Benefits:
- More readable than pure Boolean expressions
- Explicitly shows the priority relationship
- Easier to modify if additional modes are needed
- Maintains same efficiency as combinational solution
- Clear separation of mode selection logic
