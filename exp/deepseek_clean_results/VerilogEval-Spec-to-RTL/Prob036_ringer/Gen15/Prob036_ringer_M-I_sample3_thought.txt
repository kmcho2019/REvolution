The current implementation uses a case statement which works correctly but can be optimized for better PPA. We can:
1. Replace the case statement with simple continuous assignments to reduce area and power
2. The logic is essentially a 2:1 mux with ring as enable, so direct assignments will be more efficient
3. Remove the procedural block to eliminate any potential for unintended latches
4. Make outputs wire type instead of reg since we're using continuous assignments
5. This reduces area by eliminating the case statement logic and reduces power by minimizing switching activity
