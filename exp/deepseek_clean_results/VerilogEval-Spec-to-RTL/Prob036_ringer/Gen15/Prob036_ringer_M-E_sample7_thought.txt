Here's a novel approach using a priority encoder concept with some interesting characteristics:

1. Instead of using standard logic gates, we'll implement the functionality using a 2-bit decoder approach
2. We'll treat the vibrate_mode and ring inputs as a combined 2-bit control signal
3. This allows us to:
   - Explicitly handle all input combinations (including invalid states)
   - Potentially make the design more extensible for future features
   - Create a more structured decision-making process
4. The decoder will output a 2-bit signal where only one bit can be active
5. We'll then map these decoder outputs to the ringer and motor signals
6. This approach makes the control flow very explicit and could be beneficial for verification
7. It also provides a clear path for adding more modes in the future by expanding the decoder
