Here's a novel approach using a priority encoder concept with enable signals. The key differences are:
1. Uses a priority-based approach where vibrate_mode has higher priority
2. Implements explicit enable signals for both outputs
3. Uses a single control signal (ring) to enable the entire system
4. The architecture makes it clear that vibrate_mode overrides normal ring mode
5. This approach could be extended to include more priority levels if needed in future designs

The design works by first checking if ring is active, then using vibrate_mode to determine which output to activate. This creates a clear priority chain in the logic.
