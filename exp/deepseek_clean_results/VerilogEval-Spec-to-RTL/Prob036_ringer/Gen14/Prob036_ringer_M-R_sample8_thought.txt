Here's a refactored version using continuous assignments (assign statements) instead of an always block:

1. The logic is implemented purely with combinational assignments
2. Each output is directly assigned based on the input conditions
3. The ringer output is active when ring is high AND vibrate_mode is low
4. The motor output is active when both ring AND vibrate_mode are high
5. This approach is more concise and leverages Verilog's continuous assignment feature
6. It eliminates the need for reg declarations since we're using wire outputs
7. The functionality remains identical to the original specification
