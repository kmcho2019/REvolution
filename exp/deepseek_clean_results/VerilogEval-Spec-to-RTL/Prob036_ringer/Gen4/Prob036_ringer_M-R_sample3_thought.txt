The original implementation uses two separate assign statements with AND gates. We can refactor this to use a single always block with case statements for better readability and maintainability, while keeping the same functionality. This approach makes the control logic more explicit and could be easier to modify if additional modes are added in the future.

The refactored version will:
1. Use an always block to handle the combinational logic
2. Explicitly list all possible input combinations
3. Set default outputs to 0 for safety
4. Still maintain the same PPA characteristics since it's fundamentally the same logic
