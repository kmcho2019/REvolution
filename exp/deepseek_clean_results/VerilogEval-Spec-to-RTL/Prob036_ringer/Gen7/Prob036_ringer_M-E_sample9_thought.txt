Here's a novel approach using a multiplexer (MUX) to select between the ringer and motor outputs. The key differences from the original solution are:
1. Uses a MUX structure to explicitly show the selection between two output modes
2. Makes the mode selection logic more visually apparent in the code
3. Still maintains the same functionality but with a different implementation style
4. The MUX approach might be more scalable if additional modes were to be added later

The MUX selects the ringer path when vibrate_mode is 0, and the motor path when vibrate_mode is 1, with the ring signal acting as the enable for the entire selection.
