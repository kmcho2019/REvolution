The original solution uses continuous assignments with logical AND operations. We can refactor this to use an always block with procedural assignments while maintaining the same functionality. This approach:

1. Groups the related output assignments together in a procedural block
2. Makes the mutual exclusivity more explicit in the code structure
3. May be more readable for some designers as it shows the conditional nature more clearly
4. Maintains the same PPA characteristics since synthesis tools will optimize to the same gate-level implementation
