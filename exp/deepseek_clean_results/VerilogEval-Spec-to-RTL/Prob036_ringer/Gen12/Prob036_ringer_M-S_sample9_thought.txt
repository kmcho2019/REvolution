The solution can be significantly simplified by using continuous assignments instead of procedural blocks. The logic is straightforward:
1. The ringer should be on only when ring=1 and vibrate_mode=0
2. The motor should be on only when ring=1 and vibrate_mode=1
3. Both outputs should be 0 when ring=0 (no incoming call)
This can be implemented with simple AND operations, eliminating the need for case statements or always blocks.
