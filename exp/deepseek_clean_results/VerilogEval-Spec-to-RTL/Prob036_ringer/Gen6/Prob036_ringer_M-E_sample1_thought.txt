Here's a novel approach using a priority encoder style implementation with explicit state representation. Instead of direct combinational logic, we'll:

1. Create an internal 2-bit state that explicitly represents all possible output combinations (00, 01, 10)
2. Use the inputs to determine the next state
3. Decode the state to outputs

This makes the control flow more explicit and could be beneficial for:
- Future state additions (like different vibration patterns)
- Easier timing constraints in complex systems
- Better testability through state observation
- Potential power gating opportunities for unused states
