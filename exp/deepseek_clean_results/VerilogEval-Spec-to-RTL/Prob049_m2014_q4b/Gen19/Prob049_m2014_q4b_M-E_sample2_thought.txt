Novel Approach: Using a Gated Clock with Asynchronous Reset
1. Instead of the standard flip-flop implementation, we'll use a clock gating technique where the clock is only active when the data input changes
2. This reduces power consumption by minimizing unnecessary clock toggles
3. The asynchronous reset remains independent of the clock gating logic
4. We'll implement this using a transparent latch for clock gating combined with the flip-flop
5. The design will still maintain the same functional behavior but with potential power savings
