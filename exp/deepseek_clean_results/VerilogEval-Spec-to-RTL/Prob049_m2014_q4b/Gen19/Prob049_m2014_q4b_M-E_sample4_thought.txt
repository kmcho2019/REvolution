Novel Architectural Idea: 
1. Dual-Edge Triggered with Asynchronous Reset: Instead of standard positive edge triggering, implement a dual-edge triggered flip-flop that captures data on both rising and falling edges, while maintaining asynchronous reset functionality. This effectively doubles the data rate while using similar resources.
2. Reset Synchronization: Add a reset synchronizer to prevent metastability issues during asynchronous reset release while maintaining the asynchronous assertion property.
3. Low-Power Design: Implement data-dependent clock gating to disable clock transitions when input data hasn't changed, reducing dynamic power.
4. Scan Insertion Support: Add basic scan chain support for testability while keeping the core functionality intact.

Key Features:
- Captures data on both clock edges
- Robust reset handling with synchronization
- Automatic clock gating when data is stable
- Optional scan chain support
- Maintains asynchronous reset capability
