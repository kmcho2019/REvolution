Instead of using a standard edge-triggered flip-flop, we can implement the functionality using two level-sensitive latches in a master-slave configuration:
1. Master latch is transparent when clock is low
2. Slave latch is transparent when clock is high
3. Asynchronous reset overrides both latches when active
4. This creates edge-triggered behavior through the interaction of the two latches
5. The reset signal directly clears both latches asynchronously
