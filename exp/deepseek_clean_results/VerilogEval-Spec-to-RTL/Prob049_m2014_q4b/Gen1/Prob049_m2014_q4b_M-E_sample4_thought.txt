Here's an alternative approach using a master-slave latch configuration to implement the D flip-flop with asynchronous reset. Instead of using a single always block, we'll decompose the flip-flop into its fundamental components:
1. A level-sensitive master latch that captures the input when clock is low
2. A level-sensitive slave latch that passes the master's output when clock is high
3. Asynchronous reset that overrides both latches when active
This approach provides more explicit control over the internal timing and can be useful for certain low-power or custom timing scenarios.
