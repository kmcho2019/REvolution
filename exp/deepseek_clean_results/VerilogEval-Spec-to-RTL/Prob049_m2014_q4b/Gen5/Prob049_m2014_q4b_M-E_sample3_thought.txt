Here's a novel approach using a multiplexer-based implementation with clock edge detection:
1. Instead of using a standard always block, we'll detect the positive clock edge manually
2. Create a clock edge detector by comparing current and previous clock states
3. Use the detected edge to control a multiplexer that selects between the current state and new input
4. The asynchronous reset still has highest priority and clears the output immediately
5. This approach demonstrates an alternative way to model edge-triggered behavior without procedural blocks
