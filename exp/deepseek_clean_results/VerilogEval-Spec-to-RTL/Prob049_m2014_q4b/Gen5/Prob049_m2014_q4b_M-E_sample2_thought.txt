Novel Approach: Using a Master-Slave Latch Pair to Implement Edge-Triggered Behavior
1. Instead of using a standard flip-flop implementation, we'll construct the edge-triggered behavior using two level-sensitive latches
2. The master latch is transparent when clock is low, capturing the input
3. The slave latch is transparent when clock is high, holding the output stable
4. Asynchronous reset is implemented by forcing both latches to reset value
5. This approach demonstrates the underlying mechanism of edge-triggered flip-flops and provides more control over the timing behavior

Key Benefits:
- Explicitly shows the latch-based construction of flip-flops
- Allows potential for custom timing adjustments if needed
- Provides educational insight into flip-flop operation
- Maintains same functional behavior as standard implementation
