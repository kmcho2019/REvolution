The task is to implement a positive edge-triggered D flip-flop with asynchronous reset. The flip-flop should:
1. Store the input 'd' value on every positive clock edge (clk rising edge)
2. Immediately clear the output 'q' to 0 when the asynchronous reset 'ar' is active (high), regardless of the clock state
3. Maintain its value when neither a clock edge nor reset occurs
