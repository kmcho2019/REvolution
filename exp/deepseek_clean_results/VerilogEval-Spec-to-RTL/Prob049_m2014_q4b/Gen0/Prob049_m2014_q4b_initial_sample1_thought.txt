The task is to implement a positive edge-triggered D flip-flop with asynchronous reset. The flip-flop should capture the input 'd' on every rising edge of 'clk' and output it as 'q'. The asynchronous reset 'ar' should immediately set 'q' to 0 when asserted, regardless of the clock state. This behavior can be implemented using an always block sensitive to both the positive edge of 'clk' and the level of 'ar'.
