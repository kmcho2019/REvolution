The task is to implement a positive edge-triggered D flip-flop with asynchronous reset. Here's the design approach:
1. The flip-flop should capture the input 'd' on every positive edge of 'clk'
2. The asynchronous reset 'ar' should immediately set the output 'q' to 0 when asserted, regardless of the clock
3. When reset is not active, the flip-flop should behave normally, updating 'q' with 'd' at each clock rising edge
