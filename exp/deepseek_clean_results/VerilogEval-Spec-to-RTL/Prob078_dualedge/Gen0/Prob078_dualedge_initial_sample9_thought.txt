To implement a dual-edge triggered flip-flop using standard single-edge triggered flip-flops, we can use the following approach:
1. Use two separate flip-flops - one triggered on positive edge and another on negative edge
2. The positive-edge flip-flop captures the input on rising edge
3. The negative-edge flip-flop captures the input on falling edge
4. Use a multiplexer to select between these two flip-flops based on the current clock state
5. The output will effectively change on both clock edges
