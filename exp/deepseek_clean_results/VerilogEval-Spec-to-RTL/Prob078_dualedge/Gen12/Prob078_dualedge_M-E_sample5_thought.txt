Novel Approach: Clock Phase Sampling
1. Instead of using two separate flip-flops, we'll sample the input at a higher frequency using clock phase detection
2. Create four phase-shifted versions of the clock (0°, 90°, 180°, 270°)
3. Use these phases to capture the input state at different points in the clock cycle
4. Combine these samples to detect both rising and falling edges
5. Output the most recent stable value when either edge is detected
6. Advantages:
   - Uses only one flip-flop instead of two
   - More power efficient as it doesn't require maintaining two separate data paths
   - Better glitch immunity due to phase sampling
   - Scales better for wider data paths
