Novel XOR-based Edge Detection Approach:
1. Instead of using two separate flip-flops, detect both clock edges using an XOR-based edge detector.
2. Store the input value in a register whenever any edge (positive or negative) is detected.
3. Use the XOR of current and previous clock states to generate a pulse on both edges.
4. This approach reduces the number of flip-flops needed while maintaining dual-edge behavior.
5. The implementation is more compact and potentially more power-efficient as it uses a single storage element.
6. The edge detection logic is simple and can be optimized by synthesis tools.

Key advantages:
- Single register instead of two flip-flops
- Explicit edge detection makes the design intent clear
- Potentially lower power consumption due to reduced switching activity
- More elegant mathematical approach to edge detection
