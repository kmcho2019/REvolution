Here's a novel approach using clock phase manipulation:
1. Generate two 180° phase-shifted clocks from the input clock
2. Use these clocks to sample the input data at different phases
3. Combine the sampled values using a simple OR gate (since we're dealing with 1-bit signals)
4. This creates the effect of capturing data on both edges without using a mux

Key advantages:
- Eliminates the need for a clock-controlled mux
- Uses only basic logic operations
- Potentially lower power as it avoids clock gating complexity
- Maintains the same functionality with different implementation
