Here's a novel approach using clock gating and a single flip-flop:

1. Instead of using two separate flip-flops, we'll use a single flip-flop with a gated clock
2. Create an inverted clock signal for the negative edge detection
3. Use combinational logic to generate a pulse on both clock edges
4. The flip-flop will capture the input whenever this pulse occurs
5. This reduces the number of flip-flops needed while maintaining dual-edge behavior

Key advantages:
- Uses only one flip-flop instead of two
- Eliminates the need for output muxing
- More power efficient since only one flip-flop toggles
- Still meets the functional requirements
