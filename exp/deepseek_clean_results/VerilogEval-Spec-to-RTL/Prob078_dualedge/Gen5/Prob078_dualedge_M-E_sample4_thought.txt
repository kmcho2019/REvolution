Here's a novel approach using clock phase manipulation and a single flip-flop:

1. Generate two 180° phase-shifted clocks from the original clock
2. Use these clocks to create a pulse at both rising and falling edges of the original clock
3. Sample the input data using this pulse as an enable signal for a single flip-flop
4. This creates the dual-edge behavior while using only one flip-flop

Key advantages:
- Uses only one flip-flop instead of two (area efficient)
- Avoids explicit mux in the data path
- Novel clock manipulation approach
- Still maintains reliable synchronous design principles
