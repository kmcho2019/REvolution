The original solution uses three always blocks (two edge-triggered and one combinational). We can simplify this by:
1. Still using two edge-triggered flip-flops to capture data on both edges
2. Combining the output selection into a single continuous assignment
3. Eliminating the combinational always block by using an assign statement
4. Maintaining the same functionality with fewer constructs

This simplification reduces the number of always blocks from three to two while keeping the same behavior and timing characteristics.
