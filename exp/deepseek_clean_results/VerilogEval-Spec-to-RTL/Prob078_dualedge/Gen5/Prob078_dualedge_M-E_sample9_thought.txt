Here's a novel approach using a transparent latch-based design:
1. Instead of using flip-flops, we'll use latches which are naturally level-sensitive
2. Create two parallel paths: one active when clock is high, another when clock is low
3. Use the clock signal directly to control the transparency of the latches
4. Combine the outputs with an OR gate since only one path will be active at any time
5. This eliminates the need for explicit edge detection while maintaining dual-edge behavior

Advantages:
- Potentially lower power since latches can be more efficient than flip-flops
- Simpler clock distribution as we don't need to handle both edges explicitly
- More natural implementation of dual-edge behavior using level-sensitive elements
