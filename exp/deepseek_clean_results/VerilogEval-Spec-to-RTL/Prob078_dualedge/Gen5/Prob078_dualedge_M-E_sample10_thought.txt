Here's a novel approach using a clock phase detector and a dynamic sampling technique:

1. Instead of using two separate flip-flops, we'll use a single flip-flop with a dynamically controlled clock
2. Create a clock phase detector that generates a pulse at both clock edges
3. Use this pulse to trigger a sampling of the input data
4. The sampled data is then stored in a single flip-flop
5. This reduces the number of flip-flops needed compared to the traditional approach

Key advantages:
- Uses only one flip-flop instead of two
- More power efficient as only one flip-flop toggles
- Potentially better timing as there's no mux in the critical path
- Still fully synchronous to avoid timing issues
