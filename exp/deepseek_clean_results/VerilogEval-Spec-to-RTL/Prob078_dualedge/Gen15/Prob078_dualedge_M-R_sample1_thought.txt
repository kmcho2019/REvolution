Refactoring Strategy:
1. Maintain the same core functionality of capturing data on both clock edges
2. Replace the procedural always blocks with continuous assignments using clock edge detection
3. Use combinational logic to detect clock edges and update registers
4. Keep the same output mux structure but express it differently
5. The key insight is that we can model the flip-flop behavior using assign statements with conditional expressions that check for clock transitions

- Two wire signals to detect clock edges (pos_edge and neg_edge)
