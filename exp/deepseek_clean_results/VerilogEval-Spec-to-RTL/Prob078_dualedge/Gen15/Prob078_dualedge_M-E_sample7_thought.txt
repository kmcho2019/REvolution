Novel Design Approach:
1. Instead of using two separate flip-flops, we'll use a single flip-flop with clock phase control
2. Create a clock enable signal that toggles on every clock edge
3. Use this enable signal to trigger the flip-flop on both edges indirectly
4. This approach reduces the number of storage elements while maintaining dual-edge behavior
5. The design uses XOR-based edge detection and a toggle flip-flop to generate the enable signal

Key Advantages:
- Uses only one storage element for data (reduced area)
- Eliminates the need for output multiplexing
- Still fully synchronous and synthesizable
- Novel approach not commonly seen in textbooks
