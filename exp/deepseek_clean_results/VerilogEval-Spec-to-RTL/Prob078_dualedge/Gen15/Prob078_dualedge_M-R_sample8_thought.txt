Refactored Design Approach:
1. Maintain same dual-edge capture functionality but implement differently
2. Use continuous assignments with clock edge detection instead of procedural blocks
3. Detect clock edges by comparing current and previous clock states
4. Store the input value whenever any edge is detected
5. This approach eliminates the need for two separate flip-flops and mux
6. Uses a single register updated on any clock transition

Key Changes:
- Replaced procedural flip-flops with edge-triggered continuous assignment
- Uses clock transition detection (posedge or negedge)
- Single storage element instead of two
- More compact implementation while maintaining functionality
