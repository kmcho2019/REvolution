Novel Architectural Idea: Clock Phase Sampling
1. Instead of using separate flip-flops for rising and falling edges, we'll sample the clock phase
2. Create a delayed version of the clock signal (by a small fraction of the clock period)
3. Use this delayed clock to detect both edges of the original clock
4. Sample the input data when either the original clock or delayed clock transitions
5. This approach uses only one flip-flop but requires careful timing of the delay element
6. The delay can be implemented using a simple buffer chain or technology-specific delay elements

This method reduces the number of flip-flops needed while still capturing data on both clock edges. The key innovation is using clock phase information to detect both edges with a single sampling element.
