The original solution uses two separate always blocks for positive and negative edge flip-flops, plus a clock-controlled mux. We can refactor this to:
1. Use continuous assignments for the flip-flop updates instead of always blocks
2. Implement the flip-flops using clock gating with ternary operators
3. Keep the same output muxing logic but express it more concisely

This approach eliminates the procedural blocks while maintaining identical functionality, making the code more compact and potentially easier for synthesis tools to optimize.
