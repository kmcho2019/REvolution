Simplification Approach:
1. Recognize that we can use a single always block with both clock edges in the sensitivity list if we use a temporary variable
2. Use a temporary register to capture the input value on both edges
3. Assign the output directly from this temporary register
4. This eliminates the need for two separate flip-flops and a mux
5. While not synthesizable as-is on FPGAs, it's functionally equivalent and simpler
6. The simplification maintains the dual-edge behavior with fewer registers and no mux
