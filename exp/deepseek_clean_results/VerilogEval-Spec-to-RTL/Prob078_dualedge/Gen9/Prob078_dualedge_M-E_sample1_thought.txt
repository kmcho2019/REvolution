Novel Approach: Clock Phase Sampling with XOR Detection
1. Instead of using separate flip-flops for each edge, detect clock transitions using XOR
2. Store the previous clock value in a register
3. Use XOR to detect both rising and falling edges (any change in clock)
4. Create a pulse on any clock transition that can trigger the flip-flop
5. This approach uses only one flip-flop but still captures on both edges
6. The XOR-based edge detection is more efficient than separate flip-flops
