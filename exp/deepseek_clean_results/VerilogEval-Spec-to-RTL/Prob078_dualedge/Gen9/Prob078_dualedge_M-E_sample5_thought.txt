Novel Architectural Idea: Clock Phase Sampling with Single Flip-Flop
1. Instead of using two separate flip-flops, we'll use a single flip-flop with a clever clocking scheme
2. Create a delayed version of the clock signal to capture data at both edges
3. Use XOR-based edge detection to generate sampling pulses
4. The single flip-flop will capture data on both rising and falling edges of the original clock
5. This approach reduces hardware complexity while maintaining dual-edge functionality

Key Advantages:
- Uses only one flip-flop instead of two, reducing area
- Eliminates the need for clock inversion
- Maintains synchronous design principles
- Reduces power consumption by minimizing flip-flop count
