Novel Approach: Time-Multiplexed Sampling
1. Instead of using two separate flip-flops, we'll use a single flip-flop with a clock enable
2. Create a high-frequency sampling clock (2x the input clock frequency) using XOR-based edge detection
3. Sample the input data on both edges of this derived clock
4. The XOR gate detects both rising and falling edges of the original clock
5. This approach reduces the number of flip-flops while maintaining dual-edge behavior
6. The output is simply the sampled value from the single flip-flop
