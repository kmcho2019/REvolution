Novel Architectural Idea: Clock Phase Sampling with Single Flip-Flop

Instead of using two separate flip-flops, we can implement the dual-edge behavior using:
1. A single flip-flop triggered only on positive edges
2. A clock phase detector that samples the input on both edges
3. A multiplexer that selects between the current input (for negative edge) and the flip-flop output (for positive edge)

Key advantages:
- Uses only one flip-flop instead of two, reducing area
- Lower power consumption since only one storage element toggles
- Maintains correct functionality by sampling input directly on negative edges
- Fully synthesizable and avoids illegal sensitivity lists
