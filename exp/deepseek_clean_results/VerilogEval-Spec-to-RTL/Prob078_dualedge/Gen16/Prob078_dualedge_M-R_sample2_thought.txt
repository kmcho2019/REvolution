Refactoring Strategy:
1. Maintain the same fundamental approach of using two storage elements (one for each clock edge)
2. Replace the always blocks with continuous assignments using clock edge detection
3. Use ternary operators to create edge-sensitive behavior without procedural blocks
4. Keep the same output mux structure but express it differently
5. The key insight is that we can model edge-triggered behavior using the clock transition detection (clk & ~last_clk for posedge, ~clk & last_clk for negedge)

This approach eliminates procedural blocks while maintaining identical functionality. The edge detection happens through combinatorial logic rather than sensitivity lists.
