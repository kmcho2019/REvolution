Refactoring Approach:
1. Replace the sequential always blocks with continuous assignments using clock edge detection
2. Use clock edge-triggered expressions with ternary operators to create flip-flop-like behavior
3. Maintain the same dual-edge functionality by combining positive and negative edge captures
4. Eliminate explicit register declarations by using implicit state storage through assignments
5. Keep the same output multiplexing strategy based on clock state

- Replaced always blocks with assign statements
- Uses clock edge expressions (clk & ~clk_prev) for positive edge detection
- Uses (~clk & clk_prev) for negative edge detection
