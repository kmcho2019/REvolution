Here's a novel approach using clock phase manipulation and a transparent latch:
1. Instead of using two flip-flops, we'll use a single flip-flop and a latch
2. The flip-flop captures data on the positive edge
3. A transparent latch captures data when the clock is low (negative phase)
4. We use XOR-based edge detection to create a pulse on both clock edges
5. This pulse enables the latch during clock transitions
6. The output is selected based on which storage element was most recently updated

Advantages:
- Uses only one flip-flop instead of two, reducing area
- The latch consumes less power than a second flip-flop
- Edge detection ensures precise timing at both transitions
- More efficient for high-frequency operation
