The previous solution uses two flip-flops and a mux, which is straightforward but can be simplified. We can achieve the same dual-edge behavior with just one flip-flop and an XOR gate by leveraging the clock transition detection. Here's the simplified approach:

1. Use a single flip-flop that captures the input on every clock edge (both rising and falling)
2. The flip-flop is triggered by any change in the clock signal (using @(clk) sensitivity)
3. An XOR gate compares the current and previous clock states to detect transitions
4. The flip-flop updates only when a transition is detected, effectively capturing data on both edges

This reduces the design to just one storage element and minimal combinational logic while maintaining the dual-edge behavior.
