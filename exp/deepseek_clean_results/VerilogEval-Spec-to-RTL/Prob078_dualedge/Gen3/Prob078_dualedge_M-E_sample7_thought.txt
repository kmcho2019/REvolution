Here's an innovative approach using clock phase manipulation and a single flip-flop:
1. Generate a 2x frequency clock (clk2x) from the original clock
2. Use this higher frequency clock to sample the input on both rising and falling edges of the original clock
3. The key insight is that every edge of the original clock corresponds to a rising edge of clk2x
4. This allows using a standard single-edge triggered flip-flop while still capturing data on both original clock edges

Advantages:
- Uses only one flip-flop instead of two
- Eliminates the need for output multiplexing
- More elegant clock domain handling
- Potentially better timing characteristics
