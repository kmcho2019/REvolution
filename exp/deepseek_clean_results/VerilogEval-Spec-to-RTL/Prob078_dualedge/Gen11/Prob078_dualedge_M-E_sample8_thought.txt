Novel Approach: Clock Phase Sampling with Single Flip-Flop
1. Instead of using two separate flip-flops, we'll use a single flip-flop with a clever clocking scheme
2. Create a delayed version of the clock to sample data at both edges
3. Use XOR-based edge detection to capture transitions
4. Store the sampled value in a single flip-flop
5. This reduces area by eliminating one flip-flop while maintaining dual-edge behavior
6. The design uses only one sequential element and minimal combinational logic

Key Advantages:
- Single flip-flop reduces area and power
- No need for explicit clock inversion
- Maintains correct dual-edge behavior
- More elegant solution with fewer components
