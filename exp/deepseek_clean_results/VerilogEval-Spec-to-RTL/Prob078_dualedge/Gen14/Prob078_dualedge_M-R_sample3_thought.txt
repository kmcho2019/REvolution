Refactored Design Approach:
1. Maintain the same dual-edge capture functionality but implement differently
2. Use continuous assignments with clock edge detection instead of procedural blocks
3. Detect clock edges by comparing current and previous clock states
4. Use the edge detection to trigger data capture
5. This approach eliminates the need for separate always blocks while maintaining functionality

Key Changes:
- Replaced procedural flip-flops with combinational edge detection
- Used a single register to store the output
- Edge detection triggers immediate assignment
- More explicit about edge detection mechanism
- Still maintains the same behavior as original
