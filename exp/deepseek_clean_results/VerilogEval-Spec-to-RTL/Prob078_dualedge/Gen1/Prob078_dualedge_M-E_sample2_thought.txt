To create a reliable dual-edge triggered flip-flop without using illegal sensitivity lists, we can use a clock doubling approach combined with a standard single-edge triggered flip-flop. The key idea is to generate a virtual clock that toggles on both edges of the original clock, effectively creating a clock signal with twice the frequency. This virtual clock can then be used to trigger a standard positive-edge flip-flop, which will capture the input on both original clock edges. The implementation uses XOR feedback to create the clock doubling effect.
