To refactor the dual-edge triggered flip-flop while maintaining the same functionality, I'll use continuous assignments with clock edge detection instead of procedural blocks. The key idea is to:
1. Detect both clock edges using XOR-based edge detection
2. Use this edge detection to trigger sampling of the input
3. Maintain the sampled value until the next edge

This approach eliminates the need for separate flip-flops and a mux, instead using combinational logic with feedback to store the state. The edge detection creates pulses that act as implicit clock enables.
