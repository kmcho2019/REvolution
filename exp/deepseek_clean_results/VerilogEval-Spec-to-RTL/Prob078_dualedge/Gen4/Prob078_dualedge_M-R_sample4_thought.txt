The refactored design maintains the same dual-edge triggered functionality but improves upon the original by:
1. Eliminating the explicit clock gating logic (always @(*) block) which was causing unnecessary toggling
2. Directly using the clock and inverted clock for the respective flip-flops
3. Keeping the same mux-based output selection but making the structure more straightforward
4. Using non-blocking assignments for better synchronous design practice

This implementation reduces power by removing redundant logic while maintaining the same functionality. The flip-flops are still triggered on opposite edges, and the output selection remains clock-dependent.
