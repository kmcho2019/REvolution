A novel approach would be to implement the 8-bit 2-to-1 mux using a parameterized generate block with individual bit selection. This method:
1. Creates 8 parallel 1-bit muxes using a generate loop
2. Each bit is selected independently based on the common sel signal
3. Provides better scalability for wider buses
4. Makes the bit-level selection explicit and clear
5. Matches hardware implementation more closely with separate muxes per bit
