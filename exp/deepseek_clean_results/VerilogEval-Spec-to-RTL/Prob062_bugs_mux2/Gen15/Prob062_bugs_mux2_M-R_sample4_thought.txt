Refactored approach using conditional operator for cleaner implementation:
1. Replace the bitwise masking approach with a straightforward conditional operator
2. The ternary operator (?:) provides a more readable and concise implementation
3. Maintains identical functionality while simplifying the logic structure
4. Eliminates the need for explicit mask generation and bitwise operations
5. More intuitive mapping to hardware mux primitives in synthesis

Key improvements:
- Reduced logic operations (no mask generation or bitwise AND/OR)
- Clearer intent - directly expresses the 2-to-1 mux behavior
- Potentially better synthesis results as tools can directly recognize mux pattern
- Same functionality with simpler code structure
