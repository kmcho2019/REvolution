Novel Architectural Idea: Bitwise Parallel Selection
1. Instead of using a single ternary operator, implement independent bit-level selection
2. Each output bit is selected independently based on the same 'sel' signal
3. This approach could potentially enable better synthesis optimization for certain technologies
4. Maintains same functionality but with a different structural implementation
5. Could offer better timing characteristics in some FPGA/ASIC technologies due to parallel bit processing
6. Still maintains clean combinational logic with no timing violations
7. Preserves the same power and area characteristics as the original solution
