The original problem stems from a width mismatch between the 1-bit selector and 8-bit inputs. The simplest solution is to:
1. Keep the 8-bit output width
2. Use a straightforward conditional assignment
3. Avoid complex bitwise operations with replicated signals
4. Let Verilog handle the width matching implicitly in the conditional operator

This approach is:
- More readable
- Less prone to errors
- Functionally equivalent
- More maintainable
