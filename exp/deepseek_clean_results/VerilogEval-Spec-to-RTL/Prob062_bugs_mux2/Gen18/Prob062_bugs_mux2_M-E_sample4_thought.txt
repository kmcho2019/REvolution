Here's a novel approach using bitwise operations and a clever mathematical trick to implement the 2-to-1 mux without conditional statements:

1. Instead of using if-else or ternary operators, we'll use the fact that:
   - When sel=0: (a & ~0) | (b & 0) = a
   - When sel=1: (a & 0) | (b & ~0) = b
2. We'll create an 8-bit mask where all bits are either 0 or 1 based on the sel signal
3. The mask is generated by replicating the sel bit 8 times
4. We'll then use this mask to select between a and b through bitwise operations
5. This approach eliminates branching and uses purely combinational logic

This implementation is interesting because:
- It's branchless (no if-else)
- Uses parallel bitwise operations
- Shows how arithmetic can replace control flow
- May have better timing characteristics in some synthesis tools
