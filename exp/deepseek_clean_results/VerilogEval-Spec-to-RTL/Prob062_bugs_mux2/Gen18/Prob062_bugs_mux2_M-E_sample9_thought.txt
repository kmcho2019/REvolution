A novel approach would be to implement the 2-to-1 mux using a bitwise operation that doesn't require a conditional statement. We can:
1. Use the sel signal to create a mask where all bits are either 0 or 1
2. Perform bitwise operations to select between inputs a and b
3. This approach eliminates the need for a conditional operator and uses pure bitwise logic
4. The implementation will be functionally equivalent but structurally different from conventional mux designs
