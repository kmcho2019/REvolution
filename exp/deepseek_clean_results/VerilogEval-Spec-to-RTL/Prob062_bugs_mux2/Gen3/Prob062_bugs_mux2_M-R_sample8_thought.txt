The original issue was a width mismatch between the 1-bit output and 8-bit inputs. While the case statement solution works, we can simplify it by:
1. Using a continuous assignment with ternary operator for cleaner combinatorial logic
2. Maintaining the same 8-bit output width
3. Eliminating the need for a register since this is pure combinational logic
4. Keeping the same selection behavior but with more concise syntax
This approach:
- Removes the always block overhead
- Uses simpler syntax while maintaining functionality
- Still properly handles the 8-bit width requirement
