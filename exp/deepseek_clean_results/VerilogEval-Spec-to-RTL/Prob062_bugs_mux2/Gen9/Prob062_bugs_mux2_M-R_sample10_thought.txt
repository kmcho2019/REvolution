The original implementation uses a ternary operator for the mux selection. Let's refactor this to use an always block with a case statement instead. This approach:
1. Makes the selection logic more explicit and readable
2. Maintains the same functionality (sel=0 selects a, sel=1 selects b)
3. Provides a structure that might be more familiar to some designers
4. Could potentially allow for easier modification if more selection cases are added later
