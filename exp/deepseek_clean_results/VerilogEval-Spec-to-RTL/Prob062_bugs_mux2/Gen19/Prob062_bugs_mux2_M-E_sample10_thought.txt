Hierarchical Decoder-Based Multiplexer:
1. Instead of using direct selection logic, implement a decoder-first approach
2. First decode the select signal into one-hot encoding (2 bits for 2 inputs)
3. Then use the decoded signals to gate the input vectors
4. Finally OR all the gated signals together
5. Benefits:
   - More scalable to larger multiplexers (easily extendable to 4:1, 8:1 etc.)
   - Clear separation of control and data paths
   - Potentially better timing for large bus widths
   - More explicit implementation that shows the underlying hardware structure
6. While slightly more verbose, this approach demonstrates a different architectural philosophy
