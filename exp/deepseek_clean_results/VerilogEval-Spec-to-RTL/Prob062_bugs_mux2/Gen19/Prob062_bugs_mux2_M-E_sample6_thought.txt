Here's a novel approach using a hierarchical design with smaller muxes:
1. Instead of one large 8-bit mux, we'll implement it as 8 parallel 1-bit muxes
2. Each bit of the output is independently selected from corresponding bits of inputs
3. This approach provides better scalability and modularity
4. The selection signal is broadcast to all bit muxes
5. Each bit mux uses a simple ternary operator for clarity
6. The design naturally handles the correct bit-width output

Benefits:
- Clear bit-level operation visibility
- Easier to modify for different bit widths
- More intuitive for synthesis tools to optimize
- Better matches hardware where each bit is physically separate
