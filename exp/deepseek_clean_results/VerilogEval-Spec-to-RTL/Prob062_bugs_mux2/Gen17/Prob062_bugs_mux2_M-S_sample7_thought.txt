The current implementation is already quite simple, but we can make it even more straightforward by:
1. Using a continuous assignment with a simple bitwise operation
2. Eliminating the ternary operator in favor of a basic logical expression
3. Maintaining the same functionality with minimal syntax
4. Keeping the output width matching the input widths (8-bit)

The simplest implementation would use a single assign statement with a logical OR of two AND operations, which is the fundamental definition of a mux.
