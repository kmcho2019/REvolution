The original solution uses a continuous assignment with the reduction XOR operator, which is perfectly efficient. For refactoring, we'll implement the same functionality using an always block with a procedural approach, demonstrating an alternative coding style while maintaining identical functionality and similar PPA characteristics.

Key changes:
1. Replace the continuous assignment with an always block
2. Use a procedural for-loop to calculate the parity bit
3. Maintain the same even parity calculation (XOR of all bits)
4. Use a temporary register to accumulate the result

This demonstrates:
- Procedural vs continuous assignment styles
- Explicit bit-by-bit calculation vs reduction operator
- Same functionality with different implementation approach
