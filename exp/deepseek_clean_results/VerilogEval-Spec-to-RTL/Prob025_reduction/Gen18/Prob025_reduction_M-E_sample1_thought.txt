Here's a novel approach using a sequential state machine to compute the parity bit. Instead of using combinational logic, we'll:
1. Process each bit sequentially over 8 clock cycles
2. Maintain a running parity in a flip-flop
3. Use a counter to track bit position
4. Output the final parity after processing all bits

This approach demonstrates:
- Sequential processing alternative to combinational logic
- Potential power savings (only one bit processed per cycle)
- Different timing characteristics (latency vs throughput tradeoff)
- Useful for educational purposes to show alternative implementations
