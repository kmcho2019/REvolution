The current LUT-based solution works but is inefficient for PPA (Power, Performance, Area). We can optimize this by:
1. Replacing the 256-entry ROM with a simple XOR reduction operation
2. This eliminates the ROM area completely (from 11 um^2 to just a few XOR gates)
3. Reduces power consumption by removing unnecessary memory accesses
4. Improves performance with a shorter critical path (just the XOR tree delay)
5. Maintains the same functionality with simpler, more efficient logic
