Instead of using a standard NOT gate, we can implement the inversion using a transmission gate structure with an always-on enable. This approach:
1. Uses a PMOS/NMOS pair to create the inversion
2. The 'enable' is hardwired to always be active (1'b1)
3. When input is high, the NMOS pulls output low
4. When input is low, the PMOS pulls output high
5. This mimics CMOS inverter behavior at RTL level
