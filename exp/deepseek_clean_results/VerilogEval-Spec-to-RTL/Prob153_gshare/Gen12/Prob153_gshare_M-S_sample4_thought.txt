To simplify the gshare branch predictor while maintaining functionality:
1. Remove the generate block for PHT updates and use a single always block for updates
2. Combine prediction and training index calculations into one XOR operation
3. Simplify GHR update logic by using a single conditional expression
4. Move PHT saturation logic into the sequential block
5. Initialize PHT to weakly taken (2'b01) on reset
6. Maintain same timing behavior with PHT updates on next cycle

Key simplifications:
- Eliminated generate block in favor of simpler always block
- Reduced redundant XOR operations
- Simplified GHR update priority logic
- Maintained same prediction accuracy and timing
- Reduced overall logic complexity
