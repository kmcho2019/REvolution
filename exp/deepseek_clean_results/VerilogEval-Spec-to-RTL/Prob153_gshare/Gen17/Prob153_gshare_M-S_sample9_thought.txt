To simplify the gshare branch predictor while maintaining functionality:
1. Remove the generate block for PHT updates - use a single always block with indexed update
2. Combine PHT and GHR updates into one sequential block
3. Simplify the GHR next value logic by using a single conditional expression
4. Remove unnecessary intermediate wires for PHT updates
5. Initialize PHT to weakly taken (2'b01) on reset for better initial prediction
6. Maintain the same prediction/training priority and timing behavior

- Eliminate generate block overhead
- Reduce redundant logic for PHT updates
- Streamline GHR update logic
- Keep same critical functionality with fewer resources
