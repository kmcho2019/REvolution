Improvement Strategy:
1. Timing Optimization:
   - Pipeline the prediction path by registering the predict_index to break the critical path
   - Replace cascaded ternary with case statement for next_counter_state logic

2. Power Optimization:
   - Replace dual GHR with single GHR + misprediction recovery buffer
   - Add clock gating for PHT access when inactive

3. Area Optimization:
   - Reduce PHT size to 64 entries with 2-way indexing (7th bit selects way)
   - Simplify GHR implementation to single register
   - Share next_counter_state logic between ways

Key Changes:
- Single GHR with rollback buffer for mispredictions
- Smaller, 2-way PHT with shared update logic
- Pipelined prediction path
- Clock gating for power savings
