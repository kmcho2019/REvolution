To simplify the gshare branch predictor implementation while maintaining functionality:
1. Keep the core components: 7-bit GHR and 128-entry PHT
2. Simplify the update logic by combining training and prediction updates in a single always block
3. Remove the intermediate 'updated_counter' register since we can update PHT directly
4. Streamline the GHR update priority logic by using a single conditional structure
5. Maintain the same prediction and training interfaces
6. Keep the asynchronous reset behavior

Key simplifications:
- Direct PHT updates without temporary register
- More concise GHR update logic
- Reduced variable declarations
- Same functionality with fewer lines of code
