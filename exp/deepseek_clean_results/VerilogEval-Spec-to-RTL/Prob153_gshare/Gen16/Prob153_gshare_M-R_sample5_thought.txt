Refactoring approach:
1. Separate combinational and sequential logic for better clarity
2. Use continuous assignments for prediction logic
3. Split GHR and PHT updates into separate always blocks
4. Use functions for saturating counter updates to improve readability
5. Explicitly handle priority between training and prediction updates
6. Maintain same functionality and timing behavior

Key changes:
- Prediction logic becomes purely combinational
- PHT updates handled in separate always block
- GHR updates handled in separate always block with clear priority
- Saturating counter logic encapsulated in functions
- Same timing behavior maintained (PHT updates on next cycle)
