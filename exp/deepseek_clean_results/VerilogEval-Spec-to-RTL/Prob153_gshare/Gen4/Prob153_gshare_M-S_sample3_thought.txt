Here's a simplified approach that maintains all required functionality while reducing complexity:

1. **Single GHR Update Path**: Instead of separate paths for training and prediction, use a single always block that prioritizes training updates over prediction updates.

2. **Simplified Misprediction Handling**: When a misprediction occurs, directly set GHR to the provided train_history shifted by the actual taken bit.

3. **Combined PHT Update**: Move PHT updates into the same always block as GHR updates for clarity.

4. **Direct Prediction Outputs**: Keep prediction outputs purely combinational based on current state.

5. **Clean Initialization**: Initialize PHT to weakly taken (2'b01) and GHR to 0 on reset.

Key simplifications:
- Removed intermediate wires for counter updates
- Consolidated state updates into single always block
- Simplified misprediction recovery logic
- Maintained clear priority between training and prediction
