Novel Idea: "Speculative History Update with Delayed Commit"

Key innovations:
1. Speculative GHR updates - Predictions immediately update a speculative GHR while training maintains the architectural GHR
2. Two-phase PHT updates - Training writes go to a small buffer first, then commit to PHT next cycle
3. Misprediction recovery uses the buffered training state rather than recalculating
4. Separate prediction and training paths with minimal contention

Benefits:
- Predictions see immediate GHR updates for better correlation
- Training writes don't block predictions in the same cycle
- Simplified critical path by separating update logic
- Better timing closure with buffered writes
