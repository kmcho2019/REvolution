Here's a simplified approach that maintains functionality while reducing complexity:

1. Single GHR: Use a single global history register instead of dual GHRs, with priority given to training updates when both occur simultaneously.

2. Simplified Update Logic: Combine the prediction and training paths into a single update mechanism for the GHR, with training having priority as specified.

3. Direct PHT Access: Keep the PHT simple with synchronous updates, allowing predictions to see current state while training updates occur on next clock edge.

4. Misprediction Handling: When a misprediction occurs, immediately update the GHR with the correct historical state from training.

Key simplifications:
- Eliminated dual GHR registers
- Simplified next state logic for GHR
- Maintained correct timing behavior for PHT updates
- Kept priority handling between prediction and training
