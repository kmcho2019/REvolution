Refactored design approach:
1. Simplify PHT updates by using a single update block with address decoding instead of generate block
2. Optimize GHR update logic by reducing priority levels and using simpler muxing
3. Reduce power by only updating PHT when counter would actually change
4. Share XOR resources between prediction and training index calculations
5. Use more efficient coding style for saturating counters
6. Maintain same functionality and timing behavior while improving PPA

Key optimizations:
- Eliminated generate block for PHT updates
- Simplified GHR update logic to 2-level priority
- Added saturation checks to avoid unnecessary PHT writes
- Shared XOR resources for index calculation
- More compact state machine structure
