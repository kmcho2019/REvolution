To implement a gshare branch predictor with the given specifications, we need to:
1. Maintain a 7-bit global history register (GHR) that tracks branch outcomes
2. Use a 128-entry pattern history table (PHT) of 2-bit saturating counters
3. For predictions: XOR the PC with GHR to index into PHT, output prediction based on counter MSB
4. For training: Update PHT counters based on actual branch outcomes
5. Handle priority between training and prediction updates to GHR
6. Implement recovery of GHR state on mispredictions
7. Ensure proper reset behavior

Key considerations:
- Prediction uses current GHR and PHT state
- Training updates occur on next clock edge
- Mispredictions restore GHR to the trained state
- Training has priority over prediction updates
