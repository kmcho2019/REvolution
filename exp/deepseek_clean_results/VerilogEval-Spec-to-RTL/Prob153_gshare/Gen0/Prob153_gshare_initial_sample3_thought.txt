To implement the gshare branch predictor, we need to:
1. Maintain a 7-bit global history register (GHR)
2. Use a 128-entry PHT (2-bit saturating counters)
3. For prediction: XOR PC with GHR to get index, use PHT[index] to predict (MSB determines taken/not taken)
4. For training: XOR PC with provided history to get index, update PHT[index] based on actual outcome
5. Handle concurrent predict/train operations with proper precedence
6. Manage GHR updates - predict updates it with prediction, misprediction recovers it to train_history

Key points:
- PHT updates happen on clock edges
- GHR updates follow priority: train_mispredicted > predict_valid
- Prediction uses current PHT state, training affects next cycle
- All registers reset to 0
