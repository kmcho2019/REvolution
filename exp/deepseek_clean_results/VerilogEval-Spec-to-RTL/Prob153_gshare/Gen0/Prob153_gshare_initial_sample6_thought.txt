To implement the gshare branch predictor, we need to:
1. Maintain a 7-bit global history register (GHR)
2. Use a 128-entry PHT (2-bit saturating counters)
3. For predictions: XOR PC with GHR to get index, use PHT to predict taken/not taken
4. For training: Update PHT based on actual branch outcome, recover GHR if mispredicted
5. Handle concurrent predict/train operations with proper precedence

Key points:
- PHT updates happen at next clock edge
- GHR updates happen at next clock edge
- Training takes precedence over prediction when both occur
- Misprediction recovery restores GHR to train_history + train_taken
