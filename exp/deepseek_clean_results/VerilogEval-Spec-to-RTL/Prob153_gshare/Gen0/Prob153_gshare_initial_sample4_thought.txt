To implement the gshare branch predictor, we need:
1. A 7-bit global history register (GHR) to track branch history
2. A 128-entry PHT (2-bit saturating counters) for prediction
3. XOR-based indexing (pc XOR GHR) for PHT access
4. Two interfaces:
   - Prediction: uses current GHR to predict, updates GHR next cycle
   - Training: updates PHT and may recover GHR if mispredicted
5. Priority handling when both predict and train occur simultaneously:
   - Training takes precedence for GHR updates
   - Prediction sees pre-training PHT state

Key operations:
- On predict: output PHT[predict_pc ^ GHR], capture current GHR
- On train: update PHT[train_pc ^ train_history] based on actual outcome
- On misprediction: restore GHR to train_history << 1 | train_taken
- Clock edge behavior: update GHR based on highest priority operation
