Fusion Strategy: "Optimized Hybrid Gshare with Single GHR and Pipelined Prediction"

Key Improvements from Both Examples:
1. From Example 1: Adopt the dual GHR concept but simplify to a single GHR with rollback capability only when needed (reduces area/power)
2. From Example 2: Use clean separation of combinational/sequential logic and parameterized design
3. New Optimization: Pipeline the prediction path by registering the index to improve timing
4. Enhanced Training: Optimize PHT updates to only modify when necessary (reduces power)
5. Priority Logic: Simplify the GHR update priority logic to two cases (training misprediction vs others)

Architectural Advantages:
- Single GHR with rollback reduces area by 50% compared to dual GHR
- Pipelined prediction path improves timing closure
- Parameterized design maintains flexibility
- Power-optimized PHT updates only when counter would change
- Clear separation of prediction and training paths
