Refactored design approach:
1. Separate combinational and sequential logic for better clarity
2. Use continuous assignments for prediction outputs to reduce register usage
3. Break down PHT updates into separate always blocks for training and reset
4. Explicitly handle GHR updates with priority logic
5. Use blocking assignments for intermediate calculations to improve readability
6. Maintain same functionality and timing behavior as original

Key changes:
- Prediction outputs now directly driven by combinational logic
- PHT updates split into separate always blocks
- GHR update logic made more explicit
- Removed unnecessary intermediate registers
- Same timing behavior maintained (PHT updates on next cycle)
