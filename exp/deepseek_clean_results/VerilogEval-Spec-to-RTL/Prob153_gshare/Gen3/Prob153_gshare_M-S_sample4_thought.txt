Here's a simplified approach that maintains all required functionality:

1. **Single PHT Array**: Use a single-ported PHT since we can read current state for predictions while writing updates occur on next clock edge.

2. **Simplified GHR Update**: Remove shadow GHR and handle misprediction recovery directly by restoring the train_history when mispredicted.

3. **Priority Logic**: Implement straightforward priority where training updates (especially mispredictions) take precedence over prediction updates.

4. **Immediate Prediction**: Calculate predict_taken directly from current PHT and GHR state, while predict_history reflects the GHR used.

Key simplifications:
- Eliminated shadow GHR and dual-port complexity
- Simplified update priority logic
- Maintained correct timing for PHT updates
- Reduced state elements while preserving functionality
