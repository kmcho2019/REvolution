Here's a novel approach using a 3-state explicit FSM with state encoding optimization:
1. Instead of shift registers, implement a true 3-state Mealy machine with explicit state transitions
2. Use binary state encoding (2 bits) for minimal hardware overhead
3. Implement overlapping sequence detection by proper state transitions
4. Optimize output logic to be purely combinational based on current state and input
5. Maintain negative-edge asynchronous reset functionality

The state encoding and transitions:
- IDLE (00): Initial state, waiting for first '1'
- GOT1 (01): Received first '1', waiting for '0'
- GOT10 (10): Received '10', waiting for final '1'
Output 'z' is 1 only in GOT10 state when current input is '1'
