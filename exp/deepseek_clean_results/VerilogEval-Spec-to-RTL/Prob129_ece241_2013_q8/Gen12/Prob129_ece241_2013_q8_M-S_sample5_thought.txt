The shift register approach is already quite efficient, but we can simplify it further by recognizing that we only need to track the last two bits to detect "101". The detection condition is:
- Current input (x) is '1'
- Previous bit was '0'
- The bit before that was '1' (which we can infer from the state transitions)

We can implement this with just 2 states (plus reset state) by tracking whether we've seen the initial '1' or the subsequent '0'. The output z is asserted when we're in the 'seen 0' state and the current input is '1'.
