Instead of using a traditional FSM, we can implement the sequence detection using a 3-bit shift register that tracks the last 3 input bits. The detection logic then simply checks if the register content matches "101". 

Key advantages:
1. Eliminates explicit state transitions - simpler control logic
2. Naturally handles overlapping sequences by shifting in new bits
3. Output generation is purely combinational on the register contents
4. Maintains Mealy behavior since output depends on current input

The shift register is clocked normally, and we add the asynchronous reset to clear it. The output z is asserted when the register contains "101" (with current x as LSB).
