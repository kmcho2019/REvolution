Instead of using a shift register approach, let's implement a classic 3-state Mealy FSM:
1. State S0: Initial state, waiting for first '1'
2. State S1: Got '1', waiting for '0'
3. State S2: Got '10', waiting for '1' to complete the sequence
The output z is asserted when in state S2 and current input is '1'. This directly implements the sequence detection with overlapping recognition.
