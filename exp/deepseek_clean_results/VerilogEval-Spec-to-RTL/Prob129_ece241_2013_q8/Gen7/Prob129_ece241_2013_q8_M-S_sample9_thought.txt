The previous solution uses two registers to track the last two bits, but we can achieve the same functionality with just one register by implementing a proper 3-state Mealy FSM:
1. State S0: Initial state, waiting for first '1'
2. State S1: Got '1', waiting for '0'
3. State S2: Got '10', waiting for '1'
Output z is asserted only in state S2 when current input is '1'
This reduces the register count while maintaining the same sequence detection capability.
