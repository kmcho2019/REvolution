The current solution uses two registers to track the last two bits, but we can achieve the same functionality with a 3-state FSM:
1. State S0: Initial state, no matching
2. State S1: First '1' detected
3. State S2: '10' detected
Output z is asserted when in state S2 and current input is '1' (completing '101')
This eliminates the need for separate shift registers and directly implements the Mealy machine with minimal states.
