The existing solution is already quite minimal, but we can simplify it further by recognizing that:
1. We don't need to store the full history - just whether we're in the "10" state
2. The output can be generated directly from the current state and input
3. We can use a single bit state register (instead of 2 bits) since we only need to track if we've seen "10"

The FSM will have:
- State 0: Initial state or after seeing anything but "10"
- State 1: After seeing "10" (ready to detect final "1")

The output z is simply (state == 1) && (x == 1)
