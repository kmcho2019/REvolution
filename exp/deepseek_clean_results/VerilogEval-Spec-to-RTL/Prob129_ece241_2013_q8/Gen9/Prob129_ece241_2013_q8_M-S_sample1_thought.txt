The shift register approach is already quite efficient, but we can simplify further by recognizing that we only need to track the essential state information - whether we've seen "10" so far. Instead of storing two bits, we can use a single state bit that remembers if we're in the "10" state (waiting for a final '1'). This reduces the storage to just 1 flip-flop while maintaining the Mealy behavior. The output z is asserted when we're in the "10" state and see a new '1'.
