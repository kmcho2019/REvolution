The previous solution uses two registers to track the last two bits, but we can achieve the same functionality with just one register by implementing a proper 3-state Mealy FSM:
1. State S0: Initial state (no bits matched)
2. State S1: '1' detected
3. State S2: '10' detected
Output z is asserted when in state S2 and current input is '1'
This reduces the register count while maintaining the same functionality.
