The current solution already uses a minimal 2-bit shift register approach which is optimal for this problem. However, we can make one small simplification by:
1. Removing the explicit shift register and instead using two single-bit registers
2. Making the output purely combinational based on these registers and current input
3. This reduces the shift operation to simple register updates

The functionality remains identical - we're still detecting "101" sequences including overlaps, but now with slightly simpler register updates.
