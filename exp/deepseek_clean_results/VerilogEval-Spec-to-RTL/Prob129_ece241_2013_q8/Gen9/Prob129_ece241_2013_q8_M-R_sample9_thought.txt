The original solution uses a shift register approach. We can refactor this to explicitly implement a 3-state Mealy FSM while maintaining the same functionality. The states will represent:
1. IDLE: Waiting for first '1'
2. GOT1: Received '1', waiting for '0'
3. GOT10: Received '1-0', waiting for '1'

The output z will be asserted in GOT10 state when current input is '1'. This makes the state transitions and output logic more explicit while keeping the same sequence detection behavior.
