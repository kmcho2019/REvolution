To implement a Mealy FSM that detects the sequence "101" with overlapping sequences, we need 3 states:
1. IDLE: Initial state, waiting for first '1'
2. GOT1: Received first '1', waiting for '0'
3. GOT10: Received '10', waiting for final '1'

The output z is asserted when in GOT10 state and input x is '1'. The FSM transitions:
- From IDLE to GOT1 when x=1
- From GOT1 to GOT10 when x=0 (stays in GOT1 if x=1)
- From GOT10 to GOT1 when x=1 (output z=1), or to IDLE when x=0
- All transitions reset to IDLE when aresetn=0 (async negative edge reset)
