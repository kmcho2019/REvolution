To implement a Mealy FSM that detects the sequence "101" with overlapping sequences, we need 3 states:
1. IDLE: Initial state, waiting for the first '1'
2. GOT1: Received '1', waiting for '0'
3. GOT10: Received '10', waiting for '1'

The output z is asserted when in GOT10 state and input x is '1'. The FSM transitions between these states based on the input x. The reset is asynchronous and active-low, resetting the FSM to IDLE state.
