To implement a Mealy FSM that detects the sequence "101" with overlapping sequences, we need 3 states:
1. IDLE: Initial state, waiting for first '1'
2. GOT1: Received first '1', waiting for '0'
3. GOT10: Received '10', waiting for final '1'

The output z is asserted immediately when we receive the final '1' in GOT10 state. The FSM transitions:
- From IDLE to GOT1 when x=1
- From GOT1 to GOT10 when x=0
- From GOT10 to GOT1 when x=1 (with z=1), or back to IDLE if x=0
- Other transitions return to IDLE if the pattern breaks
