To implement a Mealy FSM that detects the sequence "101" with overlapping recognition, we need 3 states:
1. IDLE: Initial state, waiting for first '1'
2. GOT1: Received first '1', waiting for '0'
3. GOT10: Received "10", waiting for final '1'

The output z is asserted immediately when we receive the final '1' in the sequence (in GOT10 state). The FSM transitions between these states based on input x while checking for the complete sequence. The asynchronous reset initializes the FSM to IDLE state.
