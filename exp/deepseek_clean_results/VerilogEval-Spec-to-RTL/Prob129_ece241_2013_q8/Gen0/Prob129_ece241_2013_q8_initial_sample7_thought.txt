To implement a Mealy FSM that detects the sequence "101" with overlapping recognition, we need 3 states:
1. IDLE: Initial state, waiting for first '1'
2. GOT1: Received '1', waiting for '0'
3. GOT10: Received '10', waiting for '1'

The output z should be 1 only when in GOT10 state and current input x is '1'. The FSM transitions between states based on current state and input x. The reset should asynchronously return the FSM to IDLE state.
