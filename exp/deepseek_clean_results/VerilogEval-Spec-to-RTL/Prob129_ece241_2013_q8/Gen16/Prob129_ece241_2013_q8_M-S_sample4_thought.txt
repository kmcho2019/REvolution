The previous solution uses a shift register approach which is efficient but not a true FSM implementation as requested. To simplify while maintaining a proper 3-state Mealy FSM:

1. Use only 3 states to track the sequence progress:
   - S0: Initial state (no matching)
   - S1: '1' detected
   - S2: '10' detected

2. Transition between states based on current state and input x:
   - From S0: move to S1 if x=1
   - From S1: move to S2 if x=0, else stay in S1
   - From S2: move to S1 if x=1 (with output), else back to S0

3. Output z is 1 only when in S2 and x=1 (completing "101")

4. Maintain asynchronous reset functionality
