Instead of a traditional FSM, I'll implement a shift register that stores the last 3 input bits. The detection logic will continuously monitor these bits for the "101" pattern. This approach:
1. Uses a 3-bit shift register to track input history
2. Employs combinational logic to detect the pattern
3. Eliminates explicit state transitions while maintaining Mealy behavior
4. Still respects the asynchronous reset requirement
5. Naturally handles overlapping sequences by shifting new inputs in

This method reduces control complexity and may offer better timing as the pattern detection is purely combinational on the shift register contents.
