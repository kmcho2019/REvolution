The existing solution is already quite simple, but we can simplify it further by:
1. Removing the explicit state machine approach since we only need to track the last two bits
2. Using a single 2-bit shift register instead of separate flip-flops
3. Making the output purely combinational based on current and past inputs
4. Maintaining the same functionality of detecting "101" sequences including overlaps

The simplified version will:
- Use a 2-bit history register to track previous inputs
- Generate output when current pattern is "101" (hist1=1, hist0=0, x=1)
- Still support asynchronous reset
- Have identical behavior but with slightly cleaner code
