Here's a novel approach using a shift register with combinatorial detection:

1. Instead of a traditional FSM with explicit states, we'll use a 3-bit shift register to track the last 3 input bits
2. The shift register will be updated on each clock cycle
3. The output z will be combinatorial logic detecting the "101" pattern in the shift register
4. This approach eliminates explicit state transitions while maintaining the same functionality
5. The shift register provides inherent support for overlapping sequences
6. We'll still maintain the negative-edge asynchronous reset
7. This implementation uses slightly more registers (3 bits) but simpler combinatorial logic
