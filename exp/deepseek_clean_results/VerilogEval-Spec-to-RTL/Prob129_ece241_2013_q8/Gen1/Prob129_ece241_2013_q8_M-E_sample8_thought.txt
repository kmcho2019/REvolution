Here's a novel approach using a shift register combined with combinational logic to detect the "101" sequence. Instead of using a traditional state machine, we'll:
1. Use a 3-bit shift register to track the last 3 input bits
2. Compare the register contents with "101" pattern
3. Output z when the pattern matches
4. Reset clears the shift register

This approach eliminates explicit state transitions while maintaining the same functionality. The shift register naturally handles overlapping sequences by shifting in new bits while preserving previous ones.
