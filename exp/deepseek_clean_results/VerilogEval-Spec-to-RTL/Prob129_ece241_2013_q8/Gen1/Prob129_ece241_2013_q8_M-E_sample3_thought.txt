Instead of a traditional FSM, we can use a 3-bit shift register to track the last 3 input bits. The sequence "101" is detected when:
- Current bit (x) is '1'
- Previous bit (reg[0]) is '0'
- Bit before that (reg[1]) is '1'

This approach eliminates explicit state transitions by directly monitoring the shift register contents. The shift register is cleared on reset, and we only need to check the register values combinationally to assert z. This reduces the logic complexity while maintaining the Mealy behavior (output depends on current input).
