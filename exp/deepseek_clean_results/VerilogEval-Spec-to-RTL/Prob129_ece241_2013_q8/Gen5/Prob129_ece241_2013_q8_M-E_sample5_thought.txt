Let's implement a compact 3-state Mealy FSM using explicit state transitions. The states represent:
1. IDLE: Waiting for first '1'
2. GOT1: Received first '1', waiting for '0'
3. GOT10: Received '1' followed by '0', waiting for final '1'

The output z is asserted only in GOT10 state when current input is '1'. This approach directly models the sequence detection process with minimal states and clear transitions. The asynchronous reset initializes to IDLE state. Overlapping sequences are handled naturally by transitioning back to GOT1 state after a successful detection.
