Instead of using a shift register approach, let's implement a true 3-state Mealy FSM with explicit state encoding. The states will represent:
1. IDLE: Waiting for first '1'
2. GOT1: Received first '1', waiting for '0'
3. GOT10: Received '1' followed by '0', waiting for final '1'

The output z will be asserted only when in GOT10 state and current input is '1'. This approach makes the state transitions more explicit while maintaining the same functionality. The asynchronous reset will initialize the FSM to IDLE state.
