Instead of a traditional FSM, I'll implement a shift register that stores the last 3 input bits. The detection logic will then simply check if the stored pattern matches "101". This approach:
1. Eliminates explicit state transitions by using a shift register
2. Reduces the sequential logic to just the shift register
3. Makes the output purely combinational based on the stored pattern
4. Naturally handles overlapping sequences through the shift operation
5. Uses fewer registers than a typical FSM implementation
