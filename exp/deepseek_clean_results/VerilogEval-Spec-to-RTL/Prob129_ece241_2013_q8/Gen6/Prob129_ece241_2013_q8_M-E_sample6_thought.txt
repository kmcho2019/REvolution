Here's a novel approach using a shift register with parallel pattern matching:

1. Instead of traditional state transitions, we'll use a 3-bit shift register to track the last 3 input bits
2. The output z will be combinational logic comparing the shift register to "101"
3. This eliminates explicit state transitions while still detecting the sequence
4. The shift register approach naturally handles overlapping sequences
5. We maintain the same interface and reset behavior
6. This method is more hardware-oriented and may offer better PPA in some technologies

Advantages:
- No explicit state machine logic (simpler control path)
- Naturally handles overlapping sequences
- Clear relationship between input history and output
- Easily extensible to longer patterns
