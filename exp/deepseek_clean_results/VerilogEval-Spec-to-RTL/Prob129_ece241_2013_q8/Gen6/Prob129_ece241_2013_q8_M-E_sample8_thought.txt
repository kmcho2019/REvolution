Innovative Bitmask Comparison Approach:
1. Instead of using states or shift registers, maintain a 3-bit window that slides with each clock cycle
2. Use a bitmask comparison to directly check for the "101" pattern
3. Implement a circular buffer to store the last 3 bits efficiently
4. The output is asserted when the stored bits match the pattern
5. Key advantages:
   - Eliminates explicit state transitions
   - Uses minimal combinational logic
   - Naturally handles overlapping sequences
   - Clear pattern matching semantics
   - Easily extensible to longer patterns
6. The circular buffer approach reduces hardware complexity compared to shift registers
