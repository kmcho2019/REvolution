The current solution can be simplified by recognizing that we only need to track the last two bits of input to detect the "101" sequence. The output z is simply when we have "10" in history and current x is "1". We can implement this with:
1. A 2-bit shift register to track the last two inputs
2. Combinational logic for the output that checks for "10" in history and current '1'
3. Asynchronous reset to clear the shift register
This maintains the exact same functionality with minimal logic - just a 2-bit shift register and one AND gate for the output.
