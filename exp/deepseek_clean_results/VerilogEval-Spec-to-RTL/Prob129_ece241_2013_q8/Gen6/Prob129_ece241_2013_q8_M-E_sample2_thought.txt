Instead of using a traditional state machine or shift register, we can implement a binary counter that increments when we see parts of the "101" pattern. The key insight is that the sequence "101" can be represented as three distinct events:
1. First '1' (count = 1)
2. Then '0' (count = 2)
3. Then '1' (count = 3)

When count reaches 3, we detect the pattern and reset. The counter naturally handles overlapping sequences as it only resets after full detection. This approach is efficient because:
- Uses minimal states (implied by counter values)
- Naturally handles overlapping sequences
- Simple reset condition
- Output logic is straightforward (count == 3)
- More power efficient than shift register as it only toggles when pattern progresses
