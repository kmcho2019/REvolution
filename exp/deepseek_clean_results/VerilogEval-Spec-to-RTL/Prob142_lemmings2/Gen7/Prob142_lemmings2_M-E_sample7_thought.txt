Novel Architectural Idea: "Edge-Triggered Direction Control"
1. Key Insight: 
   - Separate the falling detection and direction control into parallel processes
   - Use edge detection on bump signals to simplify direction changes
2. State Representation:
   - Single bit for direction (left/right)
   - Single bit for falling status
3. Unique Features:
   - Direction changes are edge-triggered (only on rising edges of bump signals)
   - Falling state has priority and masks direction changes
   - Clean separation of concerns between falling and direction logic
4. Benefits:
   - Reduced glitching in direction control
   - More efficient power usage (only reacts to actual bump events)
   - Clearer state transition conditions
5. Reset Handling:
   - Asynchronous reset initializes to walk left
