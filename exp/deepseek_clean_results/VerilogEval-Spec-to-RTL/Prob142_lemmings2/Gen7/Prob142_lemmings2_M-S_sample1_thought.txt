Simplification Approach:
1. State Representation: Use a single state register to track both direction and falling status (2 bits total)
2. Transition Logic: Simplify by combining all conditions into a single priority-based decision tree
3. Output Logic: Make outputs direct assignments from state bits
4. Reset Handling: Keep simple asynchronous reset to walk left (00 state)

Key Improvements:
- Reduced state tracking to just 2 bits (00=left, 01=right, 1x=falling)
- Simplified transition logic with clear priority order (reset > falling > ground > bumps)
- Eliminated conditional operators in favor of direct bit assignments
- Maintained same functionality with fewer logic operations
