Novel Architectural Idea: State Encoding with Implicit Direction
1. State Representation: Use a 2-bit state encoding that combines both direction and falling status into a single state variable, eliminating the need for separate registers.
   - 00: Walking left
   - 01: Walking right
   - 10: Falling left (previous direction was left)
   - 11: Falling right (previous direction was right)
2. Transition Logic: Simplify state transitions by treating the falling state as an extension of the walking state, preserving direction information.
3. Output Logic: Derive outputs directly from state bits, making them purely combinatorial.
4. Reset Handling: Asynchronous reset initializes to walking left state (00).

Key Advantages:
- More compact state representation (2 bits instead of 1+1)
- Direction information preserved during falling
- Simplified output logic with direct state mapping
- Fewer conditional checks in transition logic
