Refactored Approach:
1. State Encoding: Use explicit state encoding with a 2-bit state register (IDLE_LEFT, IDLE_RIGHT, FALLING_LEFT, FALLING_RIGHT)
2. Next State Logic: Move all combinational logic to continuous assignments
3. State Transitions: Use separate assign statements for each state transition condition
4. Output Logic: Directly derived from state bits
5. Benefits:
   - Clearer state representation
   - Parallel evaluation of transition conditions
   - Easier to modify/extend states
   - More explicit state machine structure

Key Changes:
- Replaced separate direction/falling registers with explicit state encoding
- Moved all combinational logic to assign statements
- Maintained same behavior but with more structured approach
- Kept same asynchronous reset functionality
