Refactoring Approach:
1. State Encoding: Use a 2-bit one-hot encoding for states to make transitions more explicit
2. State Transitions: Separate state transition logic into a dedicated always block
3. Output Logic: Use continuous assignments for outputs but derive them from state bits
4. Falling Priority: Explicitly handle falling state with priority over direction changes
5. Direction Logic: Maintain direction separately but update only when not falling

Key Changes:
- One-hot state encoding for better readability and potential timing benefits
- Explicit state transition logic separated from output logic
- Falling state has clear priority in the state machine
- Direction register only updates when conditions are met (not falling)
- Outputs derived directly from state bits for clarity
