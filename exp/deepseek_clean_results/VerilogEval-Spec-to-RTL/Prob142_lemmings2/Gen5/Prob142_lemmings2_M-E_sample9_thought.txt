Novel Architectural Idea:
1. State Encoding: Use a 2-bit state encoding to represent all possible states (LEFT, RIGHT, FALLING_LEFT, FALLING_RIGHT) explicitly. This eliminates the need for a separate falling flag and makes state transitions more explicit.
2. Transition Logic: Implement a clear state transition diagram where falling states have priority over direction changes. This makes the behavior more visually traceable in the code.
3. Output Logic: Derive outputs directly from state bits, making the output generation extremely simple and fast.
4. Reset Handling: Maintain simple asynchronous reset to LEFT state.

Key Innovations:
- Explicit state encoding for all possible states (4 states total)
- Priority-based state transitions (falling takes precedence over bumps)
- Simplified output logic by directly mapping states to outputs
- More maintainable and debuggable state machine structure
