Simplified Approach:
1. State Representation: Use two separate registers - one for direction (1 bit) and one for falling status (1 bit)
2. Transition Logic:
   - Falling state has highest priority (independent of direction)
   - Direction changes only when on ground and not falling
   - Simple XOR for direction toggle when bumped
3. Output Logic:
   - Directly derived from state registers
   - No complex conditions needed
4. Reset Handling:
   - Simple async reset to walk left (direction=0) and not falling

Key Simplifications:
- Separated direction and falling state for clearer logic
- Eliminated nested conditionals by prioritizing falling state
- Used simple XOR for direction toggle
- Reduced logic operations in output assignments
