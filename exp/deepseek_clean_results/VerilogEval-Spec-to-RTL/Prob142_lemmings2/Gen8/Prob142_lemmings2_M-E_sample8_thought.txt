This solution uses a 3-state encoding to explicitly represent all possible Lemming states:
1. WALK_LEFT: Walking left (default after reset)
2. WALK_RIGHT: Walking right
3. FALLING: Falling state (stores last walking direction)

Key innovations:
1. Single always block for both state transitions and output generation (Moore style)
2. Explicit state encoding makes the FSM more readable and maintainable
3. Falling state stores the resume direction, eliminating need for separate tracking
4. Bump inputs are only processed in walking states
5. Ground transitions directly control falling state entry/exit

This approach simplifies the control logic by using explicit states and reduces the number of conditional checks compared to the flag-based solution.
