Simplified Approach:
1. State Representation: Use two separate registers - one for direction (1 bit) and one for falling state (1 bit)
2. Transition Logic:
   - Falling state has priority over direction changes
   - Direction only changes when on ground and not falling
   - Simple XOR for direction toggle when bumped
3. Output Logic:
   - Directly derived from state registers
   - No complex combinational logic needed
4. Reset Handling:
   - Async reset initializes to walk_left (direction=0) and not falling

Key Simplifications:
- Separated direction and falling state for clearer logic
- Eliminated nested conditionals in state transition
- Used simple XOR for direction toggle
- Reduced logic depth for better timing
