I'll implement a "direction-priority" state machine where:
1. The state is encoded as a combination of movement direction and falling status
2. Bump inputs have priority only when not falling
3. Direction changes are handled in a single always block with clear priority
4. Outputs are directly derived from state bits to minimize logic

Key innovations:
- Combined state encoding (direction + falling) reduces state transitions
- Explicit priority handling for bump inputs
- Minimal combinatorial logic between registers
- Outputs are simple wire assignments from state bits
- Asynchronous reset initializes to walk left
