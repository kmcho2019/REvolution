Optimization Strategy:
1. Timing Improvement:
   - Separate falling and direction logic into parallel paths to reduce critical path
   - Use simpler XOR-based direction toggle logic
   - Remove nested conditionals in state transition

2. Power Reduction:
   - Add clock gating for falling state transitions
   - Implement edge detection for bump signals to minimize unnecessary toggles

3. Area Optimization:
   - Merge output logic with state transition where possible
   - Simplify direction toggle to single XOR operation
   - Remove redundant logic paths
