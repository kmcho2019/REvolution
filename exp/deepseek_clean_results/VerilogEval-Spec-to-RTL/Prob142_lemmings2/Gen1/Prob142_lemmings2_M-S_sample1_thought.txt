To simplify the Lemming state machine, we can:
1. Reduce the number of states by combining the falling states into one FALL state and track the previous walking direction separately
2. Use a direction register to remember the walking direction during falls
3. Make the state machine more compact by using only 2 states (WALK and FALL) plus a direction bit
4. Simplify output logic by deriving it from the current state and direction

The simplified state transitions:
- WALK state:
  - If ground=0, go to FALL
  - If bumped on current walking side, change direction
- FALL state:
  - If ground=1, return to WALK state
  - Maintain direction from before falling
