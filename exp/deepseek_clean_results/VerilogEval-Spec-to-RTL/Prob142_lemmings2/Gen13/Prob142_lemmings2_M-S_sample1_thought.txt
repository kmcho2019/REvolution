Simplified Design Approach:
1. State Representation: Keep only two states (WALK/FALL) and track direction separately, as this is the minimal required representation.

2. Transition Logic:
   - Simplify bump handling: Only consider bumps when in WALK state and on ground
   - Remove redundant conditions by directly checking state and direction
   - Make fall transition purely dependent on ground signal

3. Output Logic:
   - Directly derive outputs from state and direction registers
   - No complex combinational logic needed

4. Reset Handling:
   - Maintain simple asynchronous reset to walk left state

Key Simplifications:
- Removed nested if-else conditions where possible
- Eliminated unnecessary logic operations
- Kept only essential state transitions
- Maintained clear separation between state and direction handling
