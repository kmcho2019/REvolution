Novel Design Approach:
1. State Encoding: Use a 3-state encoding (LEFT, RIGHT, FALL) to combine direction and state
2. Bump Handling: Implement priority-based bump detection (left bump has priority over right)
3. State Transitions:
   - Immediate fall detection when ground=0
   - Direction preservation during fall
   - Smart recovery to previous direction when ground returns
4. Output Logic: Direct state-to-output mapping for simpler decoding
5. Reset: Initialize to LEFT state

Key Innovations:
- Combined state and direction in single encoding
- Priority-based bump handling reduces logic complexity
- Explicit state for each direction simplifies output generation
- More intuitive state transitions
