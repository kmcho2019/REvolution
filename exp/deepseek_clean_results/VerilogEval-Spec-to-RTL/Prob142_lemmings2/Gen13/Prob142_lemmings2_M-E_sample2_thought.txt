Novel Architectural Idea:
1. State Encoding: Use one-hot encoding for states (LEFT, RIGHT, FALL_LEFT, FALL_RIGHT) to simplify output logic and potentially improve timing
2. Direction Handling: Embed direction in state encoding to eliminate separate direction register
3. Bump Processing: Register bump signals to prevent glitches and metastability
4. Fall State Memory: Maintain separate fall states to remember pre-fall direction
5. Output Logic: Direct state-to-output mapping simplifies combinational logic

Key Advantages:
- One-hot encoding reduces output logic complexity
- Registered bump inputs improve timing and reliability
- Separate fall states eliminate need for direction storage
- Clear state transitions improve maintainability
