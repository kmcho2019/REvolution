Refactoring Approach:
1. State Encoding: Use one-hot encoding for states (2 bits) instead of binary to potentially simplify output logic
2. Direction Handling: Move direction logic to combinational always block for clarity
3. Output Logic: Use continuous assignments for outputs based on state bits
4. State Transitions: Separate next-state logic from current state storage
5. Reset Handling: Keep async reset but initialize both state bits

Key Changes:
- One-hot state encoding (WALK_LEFT, WALK_RIGHT, FALL)
- Next-state logic in combinational block
- Current state stored in sequential block
- Outputs derived directly from state bits
- More explicit state transitions
