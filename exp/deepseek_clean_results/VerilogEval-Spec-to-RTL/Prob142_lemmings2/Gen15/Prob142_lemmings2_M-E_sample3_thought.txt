Novel Architecture Idea: "Direction-Priority State Machine with Edge Detection"

Key Innovations:
1. Direction Priority Handling: Instead of simple toggling, implement priority-based direction switching where simultaneous bumps favor left turns (arbitrary but consistent choice)
2. Edge Detection: Use edge detection on ground signal to precisely capture falling/rising events
3. State Encoding: Use 3 states (LEFT, RIGHT, FALL) with implicit direction encoding
4. Bump Filtering: Only process bumps when in walking states and ground is stable
5. Output Optimization: Direct state-to-output mapping for minimal logic

Advantages:
- More deterministic behavior on simultaneous bumps
- Clean separation of falling/rising edge handling
- Reduced logic complexity by combining state and direction
- Better timing due to simplified transition conditions
