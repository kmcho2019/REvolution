To simplify the Lemming's state machine, we can:
1. Reduce the number of states by combining the falling states into one (FALL) and storing the previous walking direction separately.
2. Use a single bit to track walking direction (0=left, 1=right) and another bit for falling state.
3. This reduces state encoding to 2 bits while maintaining the same functionality.
4. Output logic becomes simpler as we can decode the walking direction from the stored bit during falling.

Key changes:
- Only 3 states needed: WALK_LEFT, WALK_RIGHT, FALL
- Store walking direction during fall in a register
- Simplified output logic that checks current state and stored direction
