The original solution uses 4 states, but we can simplify this to 3 states by:
1. Combining FALL_LEFT and FALL_RIGHT into a single FALL state
2. Adding a direction register to remember the walking direction during falls
This reduces state transitions and logic while maintaining the same behavior.

Key changes:
- States: WALK_LEFT, WALK_RIGHT, FALL
- Add direction register (left=0, right=1) to track walking direction during falls
- Outputs:
  - walk_left/walk_right based on state and direction
  - aaah asserted only in FALL state
- Transitions:
  - Reset -> WALK_LEFT
  - Walking states transition to FALL when ground=0
  - FALL returns to previous walking state when ground=1
  - Walking states switch direction when bumped
