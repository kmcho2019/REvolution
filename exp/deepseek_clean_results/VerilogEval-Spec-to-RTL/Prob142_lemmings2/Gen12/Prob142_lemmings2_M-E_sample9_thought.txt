This solution uses a 3-state encoding (LEFT, RIGHT, FALLING) with an additional register to store the pre-fall direction. Key innovations:
1. Explicit state machine with 3 states for clear behavior modeling
2. Separate storage of pre-fall direction to simplify recovery from falling
3. Optimized state transitions that prioritize ground checks over bump detection
4. Output logic directly derived from state for minimal combinational delay

The state machine prioritizes ground transitions, making falling behavior atomic and preventing bump inputs from interfering during critical falling/rising transitions. This should improve timing by reducing combinational paths in the state transition logic.
