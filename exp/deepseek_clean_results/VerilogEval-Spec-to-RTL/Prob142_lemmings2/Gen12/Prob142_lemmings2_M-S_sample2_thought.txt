Simplified Design Approach:
1. State Representation: Use just 2 states (WALK and FALL) and track direction separately
2. Direction Logic: Simplify bump handling - just toggle direction when bumped on current side
3. State Transitions: 
   - Fall when ground=0 (regardless of bumps)
   - Return to walking when ground returns
4. Outputs: Directly derived from state and direction
5. Reset: Initialize to walk left

Key Simplifications:
- Removed clock gating complexity
- Simplified direction toggle logic
- Maintained all functional requirements
- Reduced control logic complexity
