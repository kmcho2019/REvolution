Novel Architecture Idea:
1. Hierarchical States: Use a main state machine for walking/falling with nested direction states
2. Edge Detection: Detect falling/rising edges of ground signal to precisely control transitions
3. Explicit Encoding: Use one-hot encoding for states to simplify output logic
4. Bump Filtering: Ignore bumps during falling/rising transitions of ground

Key Innovations:
- Edge detection ensures clean transitions between walking and falling states
- Hierarchical design separates direction logic from falling logic
- One-hot encoding makes output generation trivial
- Explicit state transitions handle all corner cases clearly
