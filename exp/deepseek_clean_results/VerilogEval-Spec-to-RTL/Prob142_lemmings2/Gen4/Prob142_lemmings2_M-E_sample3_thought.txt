Novel Architecture Idea: Direction-Priority State Machine with Edge Detection

Key Innovations:
1. Direction Priority Logic: Instead of simple toggling, implement priority-based direction switching where bump_right has higher priority than bump_left when both occur simultaneously.
2. Edge Detection for Ground: Add edge detection for the ground signal to precisely capture falling/rising transitions, making the FSM more robust to glitches.
3. State Encoding Optimization: Use a 2-bit state encoding that combines walking direction and falling state into a single register for compact representation.
4. Predictive Direction Handling: Store the next direction during falling state to prepare for resumption of walking.

Advantages:
- More deterministic behavior with direction priorities
- Better noise immunity with edge detection
- Compact state representation
- Reduced power consumption by minimizing state transitions
- Clear separation of concerns between walking and falling behaviors
