Refactoring Strategy:
1. State Representation:
   - Use one-hot encoding for states instead of binary encoding
   - This simplifies output logic and makes state transitions more explicit
2. Logic Implementation:
   - Replace case statements with parallel assign statements for state transitions
   - Use continuous assignments for outputs
3. Benefits:
   - More readable state transitions
   - Output logic becomes trivial due to one-hot encoding
   - Maintains same functionality while being more explicit
4. Structure:
   - Define states as separate parameters
   - Use assign for all combinational logic
   - Keep synchronous state updates in always block

Key Changes:
- One-hot state encoding (4 states = 4 bits)
- Parallel state transition logic using assign
- Direct output assignments from state bits
- Maintain same reset and clocking behavior
