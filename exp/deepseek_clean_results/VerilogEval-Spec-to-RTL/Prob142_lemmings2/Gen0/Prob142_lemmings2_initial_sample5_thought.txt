To implement the Lemming's behavior, we need a Moore state machine with three states:
1. WALK_LEFT: Lemming walks left (output walk_left=1)
2. WALK_RIGHT: Lemming walks right (output walk_right=1)
3. FALLING: Lemming is falling (output aaah=1)

The state transitions are:
- From WALK_LEFT:
  - If ground=0: transition to FALLING
  - If bump_left=1: transition to WALK_RIGHT
- From WALK_RIGHT:
  - If ground=0: transition to FALLING
  - If bump_right=1: transition to WALK_LEFT
- From FALLING:
  - If ground=1: transition to previous walking state (stored in a register)

The areset signal initializes the state to WALK_LEFT.
