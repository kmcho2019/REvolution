To implement the Lemming's behavior, we need a Moore state machine with four states:
1. WALK_LEFT: Lemming is walking left (output walk_left=1)
2. WALK_RIGHT: Lemming is walking right (output walk_right=1)
3. FALL_LEFT: Lemming is falling but was walking left before (output aaah=1)
4. FALL_RIGHT: Lemming is falling but was walking right before (output aaah=1)

The state transitions are:
- From WALK_LEFT:
  - If ground=0, go to FALL_LEFT
  - If bump_left=1, go to WALK_RIGHT
- From WALK_RIGHT:
  - If ground=0, go to FALL_RIGHT
  - If bump_right=1, go to WALK_LEFT
- From FALL_LEFT/FALL_RIGHT:
  - If ground=1, return to previous walking state (WALK_LEFT/WALK_RIGHT)

The asynchronous reset (areset) initializes the state to WALK_LEFT.
