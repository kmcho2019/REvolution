To implement the Lemming's behavior, we need a Moore state machine with four states:
1. WALK_LEFT: Lemming walks left (output walk_left=1)
2. WALK_RIGHT: Lemming walks right (output walk_right=1)
3. FALL_LEFT: Lemming is falling from left (output aaah=1)
4. FALL_RIGHT: Lemming is falling from right (output aaah=1)

The state transitions are as follows:
- On reset (areset), start in WALK_LEFT
- In WALK_LEFT:
  - If ground=0, transition to FALL_LEFT
  - If bump_left=1, transition to WALK_RIGHT
- In WALK_RIGHT:
  - If ground=0, transition to FALL_RIGHT
  - If bump_right=1, transition to WALK_LEFT
- In FALL_LEFT or FALL_RIGHT:
  - If ground=1, return to previous walking state
- Bump inputs are ignored while falling

The outputs are purely based on the current state (Moore machine).
