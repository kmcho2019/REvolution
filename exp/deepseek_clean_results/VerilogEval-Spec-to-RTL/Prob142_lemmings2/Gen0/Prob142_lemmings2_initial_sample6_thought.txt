To implement the Lemming behavior, we need a Moore state machine with the following states:
1. WALK_LEFT: Lemming is walking left (walk_left=1)
2. WALK_RIGHT: Lemming is walking right (walk_right=1)
3. FALL_LEFT: Lemming is falling from left (aaah=1)
4. FALL_RIGHT: Lemming is falling from right (aaah=1)

Transitions:
- Reset (areset=1) -> WALK_LEFT
- In WALK_LEFT:
  - ground=0 -> FALL_LEFT
  - bump_left=1 -> WALK_RIGHT
- In WALK_RIGHT:
  - ground=0 -> FALL_RIGHT
  - bump_right=1 -> WALK_LEFT
- In FALL_LEFT/FALL_RIGHT:
  - ground=1 -> previous walking state (WALK_LEFT/WALK_RIGHT)
  - else stay in falling state

Outputs:
- WALK_LEFT: walk_left=1, others=0
- WALK_RIGHT: walk_right=1, others=0
- FALL_LEFT/FALL_RIGHT: aaah=1, others=0
