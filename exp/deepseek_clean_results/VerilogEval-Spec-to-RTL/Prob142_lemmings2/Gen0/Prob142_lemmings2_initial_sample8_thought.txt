To implement the Lemming behavior, we need a Moore state machine with four states:
1. WALK_LEFT: Lemming is walking left
2. WALK_RIGHT: Lemming is walking right
3. FALL_LEFT: Lemming is falling (was walking left before)
4. FALL_RIGHT: Lemming is falling (was walking right before)

The state transitions are:
- From WALK_LEFT:
  - If ground=0, go to FALL_LEFT
  - If bump_left=1, go to WALK_RIGHT
- From WALK_RIGHT:
  - If ground=0, go to FALL_RIGHT
  - If bump_right=1, go to WALK_LEFT
- From FALL_LEFT/FALL_RIGHT:
  - If ground=1, return to previous walking state

Outputs:
- walk_left = 1 in WALK_LEFT state
- walk_right = 1 in WALK_RIGHT state
- aaah = 1 in FALL_LEFT or FALL_RIGHT states
