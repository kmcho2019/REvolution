To simplify the solution while maintaining functionality, I'll make these key changes:

1. Remove the separate direction register and encode both state and direction in a single 2-bit state register:
   - 00: WALK_LEFT
   - 01: WALK_RIGHT
   - 1x: FALL (direction maintained in bit 0)

2. Simplify the state transition logic by:
   - Removing explicit direction flip logic
   - Directly transitioning between walking states
   - Maintaining direction during falling

3. Make output logic purely dependent on the state register

This reduces:
- Number of registers from 2 to 1 (2-bit instead of 1+1)
- Combinational logic complexity
- Still maintains all functionality requirements
