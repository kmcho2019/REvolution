Simplified Design Approach:
1. State Representation: Use 2 states (WALK and FALL) with direction tracking
2. Bump Handling: Simplify by using XOR to toggle direction when bumped
3. Ground Handling: Clear state transitions based on ground signal
4. Output Logic: Directly derived from state and direction
5. Reset: Simple async reset to walk left
6. Remove redundant logic: Combine bump conditions into single toggle operation

Key Simplifications:
- Single direction toggle operation for both left/right bumps
- Clear state transitions with minimal conditions
- Output logic directly mirrors state and direction
- No unnecessary intermediate signals
- Maintains all specified functionality
