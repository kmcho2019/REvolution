Simplified Design Approach:
1. State Representation: Use just 2 states (WALK/FALL) and 1 direction bit
2. Transition Logic:
   - Only check bumps when in WALK state and grounded
   - Change direction immediately when bumped (no priority logic needed)
   - Fall when ground=0, resume walking when ground returns
3. Output Logic:
   - Directly derive outputs from state and direction
   - No complex combinational logic needed
4. Reset Handling:
   - Simple asynchronous reset to walk left
5. Key Simplifications:
   - Remove redundant condition checks
   - Simplify direction change logic
   - Combine state and direction updates
   - Minimal but clear state transitions
