Simplified Design Approach:
1. State Representation: Use just 2 states (LEFT and RIGHT) and track falling separately
2. Transition Logic:
   - Switch direction only when walking (ground=1) and bumped
   - Fall when ground=0, regardless of bumps
   - Resume previous direction when ground returns
3. Output Logic:
   - Directly derive outputs from state and falling status
4. Reset Handling:
   - Simple asynchronous reset to LEFT state
5. Key Simplifications:
   - Eliminate walking register by using ground directly
   - Combine state and direction into single state register
   - Minimal conditional logic for state transitions
