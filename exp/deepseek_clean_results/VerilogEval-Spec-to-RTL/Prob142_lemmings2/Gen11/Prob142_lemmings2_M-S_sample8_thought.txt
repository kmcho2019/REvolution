Simplified Design Approach:
1. State Representation: Keep just 2 states (WALK/FALL) and track direction separately, as this is the minimal needed representation.

2. Transition Logic:
   - Only change direction when in WALK state and ground is present
   - Simplify bump detection by using XOR to toggle direction when either bump occurs
   - Transition to FALL immediately when ground disappears
   - Return to WALK when ground reappears

3. Output Logic:
   - Directly derive outputs from state and direction registers
   - No complex combinational logic needed

4. Reset Handling:
   - Maintain simple asynchronous reset to initial state (walking left)

Key Simplifications:
- Removed redundant condition checks
- Used simpler direction toggle logic
- Eliminated unnecessary intermediate signals
- Maintained clear separation of state and direction logic
