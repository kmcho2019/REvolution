Refactoring Strategy:
1. State Representation: Use separate registers for direction (left/right) and falling state for clearer logic separation
2. Transition Logic: 
   - Split into parallel assignments for direction and falling state
   - Use ternary operators for more compact condition evaluation
3. Output Logic: 
   - Make outputs purely combinational based on current state
   - Use direct state decoding for better readability
4. Structure:
   - Replace always block with continuous assignments for state updates
   - Use wire declarations for intermediate state calculations

- Clearer separation of direction and falling state logic
- More readable state transitions using ternary operators
- Purely combinational output logic
- Maintains same functionality while being more explicit about state transitions
