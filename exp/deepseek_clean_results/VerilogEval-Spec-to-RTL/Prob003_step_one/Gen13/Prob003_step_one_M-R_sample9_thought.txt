The original solution uses a direct continuous assignment, which is perfectly valid. For refactoring, we'll implement the same functionality but using:
1. A procedural always block instead of continuous assignment
2. An internal register to hold the constant value
3. Explicit initialization of the register

This approach demonstrates:
- Alternative coding style while maintaining identical functionality
- Use of procedural assignment for potential future expansion
- Clear separation of declaration and assignment
- Maintains the same zero-logic overhead characteristic
