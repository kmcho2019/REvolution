The original solution uses a direct continuous assignment, which is perfectly adequate. For refactoring, we'll implement the same functionality but using a different structural approach:
1. Instead of a direct 'assign', we'll use an always block with procedural assignment
2. This demonstrates an alternative coding style while maintaining identical functionality
3. The always block will be sensitive to a dummy variable to show procedural assignment
4. The output will be declared as 'reg' type since we're using procedural assignment
5. This maintains the same PPA characteristics as the original since synthesis will optimize both to the same hardware
