The original solution is already optimal for this trivial case, but we can consider alternative implementations that might offer theoretical advantages in more complex scenarios:

1. **Parameterized Approach**: Using a parameter allows for easy modification if requirements change
2. **Explicit Wire Declaration**: Makes the design intent clearer
3. **Direct Output Assignment**: Eliminates the need for an intermediate wire
