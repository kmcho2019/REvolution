Here's a novel approach using a behavioral always block with a dummy register. While functionally equivalent, this demonstrates:
1. Using procedural assignment instead of continuous assignment
2. Implementing a constant through behavioral code
3. Showing how synthesis tools can optimize away unnecessary sequential logic
4. The register 'dummy' will be optimized away during synthesis, but shows an alternative coding style

This approach is less efficient than direct assignment but demonstrates behavioral Verilog capabilities for constant generation.
