Here's a novel approach using a minimal state machine that always outputs '1'. While this is clearly over-engineered for the simple requirement, it demonstrates an alternative architectural concept:

1. Use a simple 1-state FSM (finite state machine) that remains in its only state forever
2. The state machine's output function always produces '1'
3. This approach showcases how even constant outputs could be implemented via control logic
4. The implementation includes:
   - A state register (though only 1 state exists)
   - Next-state logic (always stays in same state)
   - Output logic (always '1')

While this consumes more area and power than the direct assignment, it illustrates how constant outputs could be part of a larger control system.
