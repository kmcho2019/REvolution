Simplified Design Approach:
1. Remove parallel computation of all shift operations to reduce area
2. Use a single always block with case statement for better readability
3. Compute shift operations only when needed (during the case selection)
4. Maintain arithmetic right shift by replicating the sign bit
5. Keep synchronous load with highest priority
6. Simplify enable logic by incorporating it directly in the case statement

Key Simplifications:
- Eliminated intermediate wires for shift operations
- Removed separate sign_bit computation
- Consolidated all logic into a single always block
- Reduced multiplexer complexity by not precomputing all shifts
