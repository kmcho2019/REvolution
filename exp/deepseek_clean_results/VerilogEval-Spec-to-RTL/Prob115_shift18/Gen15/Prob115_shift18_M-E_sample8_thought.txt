Novel Architecture: Parallel Barrel Shifter with Sign-Preserving Logic

Key Innovations:
1. **Parallel Shift Computation**: Compute all possible shift operations simultaneously and select the result using a single multiplexer, reducing critical path.

2. **Optimized Sign Handling**: For right shifts, use arithmetic shift operators directly instead of concatenation for better synthesis results.

3. **Early Amount Decoding**: Decode shift amount into one-hot control signals early to simplify the final selection logic.

4. **Load Bypass Path**: Direct load path to output register to minimize load-to-q delay.

5. **Power Gating**: Only compute shifts when enabled (ena=1), with explicit clock gating for the register.

Benefits:
- Reduced critical path through parallel computation
- Better utilization of arithmetic shift operators
- Simplified control logic
- Optimized power consumption
- Clean timing paths for synthesis
