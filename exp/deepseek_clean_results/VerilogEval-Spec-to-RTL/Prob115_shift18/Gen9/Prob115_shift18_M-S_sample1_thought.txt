Simplified Design Idea:
1. Direct Shift Implementation: Instead of complex nested conditions, implement each shift operation directly and select using a simple multiplexer structure.
2. Priority Handling: Give load operation clear priority over shifting by checking it first.
3. Arithmetic Right Shift: For right shifts, simply replicate the sign bit (MSB) when shifting.
4. Basic Structure: Use a single always block with clear priority order (load > shift) and straightforward shift operations.
5. Reduced Logic Depth: Avoid deep conditional nesting by separating shift operations into distinct cases.

Key Simplifications:
- Removed intermediate wires for shift computation
- Simplified control logic by using case statement for shift selection
- Maintained clear priority between load and shift operations
- Kept arithmetic right shift behavior with sign extension
- Reduced overall logic complexity while preserving functionality
