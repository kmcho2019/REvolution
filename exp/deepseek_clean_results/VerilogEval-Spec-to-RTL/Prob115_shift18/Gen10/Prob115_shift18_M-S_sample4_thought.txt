Simplified Design Idea:
1. Direct Shift Implementation: Instead of complex nested logic, implement each shift operation directly and select using a simple case statement.
2. Priority Handling: Give load the highest priority, then shift if enabled.
3. Arithmetic Right Shift: For right shifts, extend the sign bit (MSB) appropriately.
4. Clean Structure: Use a single always block with clear priority handling (load > shift > hold).

Key Simplifications:
- Eliminated nested ternary operators in favor of a case statement
- Removed intermediate wires for shift computation
- Directly implemented each shift case
- Simplified sign extension logic
- Maintained all functionality with clearer code structure
