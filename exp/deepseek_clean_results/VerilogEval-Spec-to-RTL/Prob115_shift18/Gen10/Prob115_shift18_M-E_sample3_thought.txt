Novel Architectural Idea: Barrel Shifter with Pre-computed Shift Options

Key Innovations:
1. **Parallel Shift Computation**: Pre-compute all 4 possible shift operations simultaneously (left1, left8, right1, right8) in parallel, then select using a single 4:1 mux. This reduces critical path compared to nested if-else.

2. **Sign Extension Optimization**: For right shifts, use a dedicated sign extension unit that only activates when needed, saving power.

3. **Clock-Gated Register Update**: Implement explicit clock gating for power savings when neither load nor ena is active.

4. **Early Amount Decoding**: Decode shift amount early into one-hot control signals for cleaner mux selection.

5. **Resource Sharing**: The left shift operations share common zero-padding logic, while right shifts share sign extension logic.

Advantages:
- Reduced critical path by parallel computation
- Lower power consumption through selective activation
- Cleaner control flow with one-hot selection
- Better timing balance between shift options
