Refactoring Strategy:
1. **Structural Changes**:
   - Replace the always block with continuous assignments for the register update
   - Separate shift operations into distinct wires for better readability
   - Use hierarchical multiplexing to reduce critical path

2. **Optimizations**:
   - Compute shift operations only when enabled (ena=1)
   - Simplify sign extension logic by pre-computing the sign bit
   - Use conditional operator for cleaner shift selection

3. **Power/Area Improvements**:
   - Remove redundant shift computations
   - Use gate-level enable control for shift operations
   - Simplify multiplexer structure

Key Changes:
- Shift operations now computed only when ena is active
- Clearer separation of shift directions
- More efficient sign extension handling
- Flatter control structure
- Maintains same functionality with better PPA potential
