Refactoring Strategy:
1. **Structural Changes**:
   - Replace combinational always block with continuous assignments (assign)
   - Merge shift logic into a single expression using ternary operators
   - Simplify control flow by directly computing shifted value based on amount

2. **Optimizations**:
   - Eliminate intermediate shifted_value register by computing directly in output assignment
   - Use arithmetic right shift operator (>>>) for cleaner implementation
   - Combine load and shift enable logic into a single expression

Key Improvements:
- More concise implementation using continuous assignments
- Direct use of Verilog's arithmetic shift operator
- Reduced intermediate signals
- Clearer expression of shift operations
- Maintains same functionality while being more readable
