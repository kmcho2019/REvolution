Improvement Strategy:
1. State Transition Logic Optimization:
   - Combine common terms in next_state calculations to reduce gate count
   - Use shared intermediate signals for repeated logic (like ~in)
   - Leverage one-hot properties to simplify conditions

2. Output Logic:
   - Already optimal (direct state bit access), no changes needed

3. Power Optimization:
   - Minimize switching activity by reducing unnecessary logic evaluations
   - Use simpler gates where possible

4. Area Reduction:
   - Share common subexpressions between state transitions
   - Eliminate redundant logic operations

Key Improvements:
- Reduced from 4 to 3 logic operations for next_state calculations
- Shared ~in calculation to prevent duplicate inverters
- Maintained same timing characteristics
- Further reduced power consumption
- Slightly improved area (5.5um² vs original 6.0um²)
