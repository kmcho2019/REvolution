Refactoring Approach:
1. Structural Change: Instead of individual bit assignments, use a single 4-bit assignment for next_state with concatenated expressions. This makes the state transition logic more compact and visually grouped.

2. Logic Optimization: Maintain the same efficient logic expressions but express them in a more consolidated form. The output logic remains unchanged since it's already optimal.

3. Readability Improvements:
   - Use comments to clearly mark the state encoding
   - Group related logic together
   - Keep the purely combinational nature of the design

Key Benefits:
- More compact representation of state transitions
- Maintains identical functionality and optimization level
- Improved visual grouping of related logic
- Same excellent PPA characteristics (0.00016W power, 6.0um² area)
