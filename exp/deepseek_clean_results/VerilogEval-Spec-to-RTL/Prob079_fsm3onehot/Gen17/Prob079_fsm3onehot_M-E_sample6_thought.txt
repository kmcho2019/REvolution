Novel Architectural Idea: State Transition Logic using Priority Encoder
1. Instead of deriving separate equations for each state bit, implement a priority encoder that:
   - First checks the current state (one-hot encoded)
   - Then applies the input condition to determine next state
   - This approach mimics a lookup table behavior but with combinational logic

2. Key Features:
   - Uses nested ternary operators to prioritize state transitions
   - Explicitly encodes the state transition rules in priority order
   - Maintains one-hot encoding properties
   - Output logic remains simple (state[3])

3. Advantages:
   - More readable and maintainable as it directly reflects the state table
   - Easier to modify if state transitions change
   - Still maintains good PPA metrics due to one-hot encoding benefits
   - Clear mapping between specification and implementation
