Novel Architectural Idea: Bitwise Parallel State Transition
1. Key Insight:
- Leverage the one-hot encoding property where only one state bit is active at a time
- Implement state transitions using bitwise operations on the entire state vector
- Use masking patterns derived from the state transition table

2. Implementation Strategy:
- Create transition masks for in=0 and in=1 cases
- Combine masks using the input as a selector
- Output logic remains simple (state[3])
- Benefits:
  - More compact representation of state transitions
  - Potential for better synthesis optimization
  - Clear visual mapping to the state transition table
  - Reduced logic depth by operating on the full state vector

3. Transition Logic:
- For in=0: A stays, B→C, C→A, D→C
- For in=1: A→B, B stays, C→D, D→B
- Encode these as bit patterns for each case
