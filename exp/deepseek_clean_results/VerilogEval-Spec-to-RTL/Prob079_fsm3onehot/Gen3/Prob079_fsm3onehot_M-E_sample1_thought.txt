Instead of using a case statement, we can leverage the properties of one-hot encoding to derive the next state using bitwise operations. Each next state bit can be computed independently based on:
1. The current state bits
2. The input 'in'
3. The transition rules

This approach:
- Computes each next_state bit in parallel
- Eliminates the need for a case statement
- May reduce area by sharing common logic
- Maintains the one-hot property by construction
- Still clearly reflects the state transition table
