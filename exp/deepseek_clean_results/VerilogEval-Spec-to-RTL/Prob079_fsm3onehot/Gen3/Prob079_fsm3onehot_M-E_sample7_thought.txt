Instead of treating each state independently, we can implement a priority-based transition scheme that:
1. Uses the one-hot encoding to create a priority chain where higher-numbered states (with higher bit positions) take precedence
2. For each state, we only consider transitions if no higher-priority state is active
3. The output is generated by a simple bitwise OR of all possible output conditions
This approach reduces logic complexity by eliminating redundant checks and leverages the natural priority in one-hot encoding
