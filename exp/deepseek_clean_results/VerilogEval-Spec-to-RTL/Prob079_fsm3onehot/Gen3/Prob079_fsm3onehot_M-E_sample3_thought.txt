Instead of using a case statement, we can implement the state transitions using bitwise operations and logical expressions that directly compute each next state bit based on:
1. Current state bits
2. Input condition
3. State transition rules

This approach:
- Eliminates the need for a case statement
- Directly computes each next_state bit in parallel
- Uses minimal logic gates for each transition
- Maintains one-hot property by construction
- Output is still simply the MSB of state (state[3])
