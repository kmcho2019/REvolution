The solution can be further simplified by observing that:
1. Each next_state bit depends on only one or two state bits due to one-hot encoding
2. The output is simply state[3], which is already minimal
3. We can eliminate redundant checks by directly mapping the state transitions:
   - next_state[0] (A) activates when current state is A or C and in=0
   - next_state[1] (B) activates when in=1 and current state is not C (since C transitions to D when in=1)
   - next_state[2] (C) activates when current state is B or D and in=0
   - next_state[3] (D) activates when current state is C and in=1
This removes any unnecessary logic operations while maintaining correctness.
