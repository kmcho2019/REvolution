Refactoring Strategy:
1. Structural Change:
- Instead of separate assign statements for each next_state bit, use a single always block with case statement
- This makes the state transitions more explicit and easier to read/maintain
- Still maintains one-hot encoding benefits

2. Logic Optimization:
- Keep the same optimized logic expressions but express them differently
- Combine the state transition conditions into case items
- Output logic remains the same (simple assignment)

3. Readability Improvement:
- The case statement clearly shows all transitions from each state
- Comments can be added to explain each transition
- Group related logic together

4. Maintain Same PPA:
- The underlying logic remains identical
- No change in gate count or critical path
- Same power and area characteristics
