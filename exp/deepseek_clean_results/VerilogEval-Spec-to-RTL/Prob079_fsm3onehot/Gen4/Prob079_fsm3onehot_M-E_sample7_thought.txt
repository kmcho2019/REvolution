Here's a novel approach using a priority encoder style implementation:
1. Instead of treating each state bit separately, we'll use a priority-based selection
2. Create a 4-to-1 multiplexer for each next_state bit where the select lines are the current state
3. The output logic remains simple as it's just the D state bit
4. This approach makes the state transitions more explicit and might be more readable

Key advantages:
- Clear mapping of each state's transitions
- Easier to modify individual state transitions
- Potential for better synthesis optimization in some tools
- More modular structure that could scale better with more states
