Novel Architectural Idea: State Transition Logic using Multiplexers
1. Instead of using separate AND/OR gates for each state transition, implement a multiplexer-based approach that directly maps the state transitions based on the input.
2. For each next_state bit, use the current state and input to select the appropriate transition.
3. This approach leverages the one-hot encoding property where only one state bit is active at a time, simplifying the mux selection logic.
4. The output logic remains simple (just state[3]) as in previous solutions.
5. Benefits:
   - More structured and scalable approach for larger state machines
   - Clear mapping from state transition table to implementation
   - Potentially better synthesis results due to regular structure
