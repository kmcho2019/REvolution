Refactoring Strategy:
1. Structural Change:
   - Replace individual bit assignments with a single vector assignment for next_state
   - Use concatenation to build the next_state vector in one operation
   - Keep the output assignment separate as it's conceptually different

2. Logic Optimization:
   - Maintain the same optimized logic expressions but express them as part of a vector
   - The concatenation order matches the one-hot encoding (bit 0 to bit 3)

3. Benefits:
   - More compact representation of the state transition logic
   - Clearer relationship between state bits in the implementation
   - Maintains all original PPA advantages
   - Easier to modify if state encoding changes
   - Still purely combinational as required

4. Readability:
   - Single assignment shows all state transitions at once
   - Comments explain each bit's purpose in the concatenation
