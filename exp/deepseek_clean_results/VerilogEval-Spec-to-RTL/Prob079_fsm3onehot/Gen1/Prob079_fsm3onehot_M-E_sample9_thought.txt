The key insight is that for one-hot encoded state machines:
1. Only one state bit is active at a time
2. Each next state bit can be computed independently by looking at specific combinations of current state and input
3. We can optimize the logic by:
   - Using bitwise operations instead of comparisons
   - Leveraging the one-hot property to simplify the logic
   - Minimizing the number of logic gates by combining terms

New approach:
- For each next state bit, determine which current states with which input values would transition to it
- Use bitwise AND with the state bits and input to detect these conditions
- The output is simply the MSB of the state (D state)
