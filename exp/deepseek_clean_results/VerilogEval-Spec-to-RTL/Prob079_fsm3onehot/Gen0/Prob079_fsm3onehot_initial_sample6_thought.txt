To implement the Moore state machine with one-hot encoding, we need to:
1. Decode the current state from the 4-bit state input
2. Determine the next state based on the current state and input
3. Generate the output based on the current state (Moore machine output depends only on state)

For one-hot encoding, each state is represented by a single bit being high. The next state logic can be derived directly from the transition table:
- From A: next_state is A (in=0) or B (in=1)
- From B: next_state is C (in=0) or B (in=1)
- From C: next_state is A (in=0) or D (in=1)
- From D: next_state is C (in=0) or B (in=1)

The output is 1 only when in state D (4'b1000).
