To implement the Moore state machine with one-hot encoding, we need to:
1. Decode the current state (one-hot encoded)
2. Determine next state based on current state and input
3. Generate output based on current state

For state transitions:
- From A: go to A if in=0, B if in=1
- From B: go to C if in=0, B if in=1
- From C: go to A if in=0, D if in=1
- From D: go to C if in=0, B if in=1

For output:
- Output is 1 only when in state D (4'b1000)
- Output is 0 for all other states
