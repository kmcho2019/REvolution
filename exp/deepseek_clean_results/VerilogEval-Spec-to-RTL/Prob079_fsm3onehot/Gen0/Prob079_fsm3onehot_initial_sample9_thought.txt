To implement the Moore state machine with one-hot encoding, we need to:
1. Decode the current state from the 4-bit one-hot encoded 'state' input
2. Determine the next state based on the current state and input 'in'
3. Generate the output based solely on the current state (Moore machine)
4. Use combinational logic to implement both state transition and output functions

The state transitions and outputs are:
- State A (0001): 
  - in=0: stay in A (0001)
  - in=1: go to B (0010)
  - output=0
- State B (0010):
  - in=0: go to C (0100)
  - in=1: stay in B (0010)
  - output=0
- State C (0100):
  - in=0: go to A (0001)
  - in=1: go to D (1000)
  - output=0
- State D (1000):
  - in=0: go to C (0100)
  - in=1: go to B (0010)
  - output=1
