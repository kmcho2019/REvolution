To implement the Moore state machine with one-hot encoding, we'll need to:
1. Decode the current state from the 4-bit one-hot encoded 'state' input
2. Determine the next state based on both the current state and 'in' input
3. Generate the output based solely on the current state (Moore machine property)

For the state transitions:
- From A: go to A if in=0, B if in=1
- From B: go to C if in=0, B if in=1
- From C: go to A if in=0, D if in=1
- From D: go to C if in=0, B if in=1

For outputs:
- Output is 1 only when in state D (1000), 0 otherwise
