To simplify while maintaining functionality:
1. Remove the separate 'prev_in' register since we can directly use the captured bits to store state
2. Each output bit should be set when either:
   - It was already set (sticky behavior)
   - The current input bit is 0 and it was 1 in the previous cycle
3. Use the captured register itself to store the previous state
4. Maintain synchronous reset behavior

This eliminates one 32-bit register while keeping all required functionality:
- Falling edge detection (1→0 transitions)
- Sticky capture until reset
- Proper reset behavior
