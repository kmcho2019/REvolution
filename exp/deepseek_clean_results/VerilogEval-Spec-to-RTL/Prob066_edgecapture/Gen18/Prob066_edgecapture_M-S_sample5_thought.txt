Here's a simplified and corrected approach:

1. Use single register to store previous input value (simpler than two-stage pipeline)
2. Compare current input directly with previous value stored in register
3. Detect falling edges when previous=1 and current=0 for each bit
4. Use OR operation to maintain sticky detection until reset
5. Reset clears both the history register and output
6. This maintains correct timing with only one register stage
7. Fewer registers means less area and power consumption
8. Still guarantees proper edge detection between consecutive cycles
