To simplify while maintaining functionality, we'll:
1. Use a single 32-bit register to store the previous input (prev_in)
2. Use another 32-bit register to store the captured falling edges (captured)
3. Detect falling edges by comparing current input with prev_in
4. Set captured bits when falling edges are detected (1→0 transitions)
5. Maintain sticky behavior - once set, captured bits stay set until reset
6. All operations are synchronous to posedge clk with synchronous reset

This approach is straightforward and clearly separates the edge detection logic from the sticky capture behavior.
