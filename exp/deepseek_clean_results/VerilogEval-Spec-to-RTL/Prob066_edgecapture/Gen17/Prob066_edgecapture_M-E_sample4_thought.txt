Here's a novel approach using a two-stage pipeline with explicit edge detection:

1. First stage: Store the previous input value in a register
2. Second stage: Detect falling edges by comparing current and previous inputs
3. Use a separate register to maintain the captured edges
4. The output is simply the captured edges register
5. Reset clears all registers synchronously

Key differences from previous solution:
- Explicit two-stage pipeline for clearer timing
- Separate registers for input history and captured edges
- Falling edge detection is isolated in its own logic stage
- Output is purely registered with no combinational path
- More modular structure that could be easily extended
