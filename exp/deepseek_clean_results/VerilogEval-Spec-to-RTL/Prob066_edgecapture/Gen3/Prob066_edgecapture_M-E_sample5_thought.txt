Here's a novel approach using a two-stage pipeline with separate edge detection and state maintenance:

1. **Dual-Register Pipeline**: 
   - First register stores the input from two cycles ago (prev_prev_in)
   - Second register stores the input from one cycle ago (prev_in)
   - This creates a stable window for edge detection

2. **Accurate Edge Detection**:
   - Detect falling edges by comparing prev_prev_in (two cycles ago) with prev_in (one cycle ago)
   - This ensures we're comparing stable values that aren't changing in the same clock cycle

3. **State Maintenance**:
   - Use a set-hold register that:
     - Sets bits when a falling edge is detected
     - Holds them until reset
   - The output register simply reflects this state

This approach eliminates timing races by ensuring we always compare stable values from different clock cycles, while maintaining the required state until reset.
