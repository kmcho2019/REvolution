Novel approach using per-bit state machines:

1. Instead of simple edge detection, implement 32 parallel mini state machines (one per bit)
2. Each state machine tracks its bit's history independently
3. States:
   - IDLE: Waiting for a '1' (initial state)
   - SAW_ONE: Saw a '1', watching for falling edge
4. Transitions:
   - IDLE → SAW_ONE when current bit is 1
   - SAW_ONE → IDLE (with output set) when current bit is 0
5. Advantages:
   - More robust than simple edge detection
   - Explicit state tracking for each bit
   - Clear separation of detection and memory
   - Easily extensible for more complex patterns
6. Implementation:
   - 32 instances of the state machine
   - Output OR-gate maintains the captured edges
   - Reset clears all state machines
