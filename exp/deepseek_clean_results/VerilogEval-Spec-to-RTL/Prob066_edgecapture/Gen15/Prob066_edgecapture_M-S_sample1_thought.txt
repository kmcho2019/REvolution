To simplify while maintaining functionality:
1. Keep the core concept of detecting 1→0 transitions using previous input storage
2. Remove unnecessary complexity by:
   - Using a single always block
   - Directly assigning the edge detection result to output
   - Letting the output naturally hold its value until reset
3. The output will automatically maintain its state (no need for explicit OR)
4. Reset will clear both storage and output registers

This achieves the same behavior with simpler logic and fewer operations.
