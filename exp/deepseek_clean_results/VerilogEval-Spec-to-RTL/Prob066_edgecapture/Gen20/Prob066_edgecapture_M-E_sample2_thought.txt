Novel approach using parallel edge detectors with latching:

1. Instead of tracking previous input, use XOR-based edge detection:
   - XOR current input with delayed version to detect any changes
   - AND with inverted input to isolate falling edges only

2. Implement a latching mechanism:
   - Each bit has its own set-reset latch
   - Falling edge sets the latch
   - Reset clears all latches

3. Key advantages:
   - More explicit edge detection logic
   - Clear separation between detection and storage
   - Each bit operates independently
   - Potentially better timing characteristics

4. Implementation details:
   - Use non-blocking assignments for all sequential elements
   - Generate statements for scalable bitwise operations
   - Output directly reflects the latched states
