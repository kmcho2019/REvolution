Novel approach using single-stage edge detection with immediate feedback:

1. **Single Register Design**:
   - Use only one register (prev_in) to store the previous input state
   - Compare directly with current input for immediate edge detection

2. **Capture with Feedback**:
   - Implement captured bits as a set of SR flip-flops
   - Each bit sets on falling edge (1→0 transition)
   - Only resets when global reset is asserted

3. **Efficient Implementation**:
   - Eliminates pipeline delay of two-stage approach
   - Each bit operates independently
   - Clear separation between edge detection and state maintenance
   - Output directly reflects the captured state

Key advantages:
- Immediate detection of transitions between consecutive cycles
- No pipeline-related timing issues
- Simple and efficient implementation
- Each bit's capture logic is completely independent
