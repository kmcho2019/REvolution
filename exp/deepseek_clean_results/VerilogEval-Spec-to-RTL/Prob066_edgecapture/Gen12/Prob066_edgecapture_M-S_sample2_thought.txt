Simplified approach with correct edge detection and capture:

1. **Direct Edge Detection**:
   - Compare current input with registered previous input
   - Detect falling edges when previous bit was 1 and current is 0

2. **Single Register Capture**:
   - Use one register to store detected edges
   - Once a bit is captured (set to 1), it stays until reset

3. **Simpler Logic**:
   - Remove separate combinational edge detection
   - Perform edge detection and capture in same always block
   - Still maintains proper per-bit isolation

Key simplifications:
- Eliminates intermediate wire for edge detection
- Combines edge detection and capture in sequential logic
- Fewer signals and simpler structure
- Maintains correct functionality
