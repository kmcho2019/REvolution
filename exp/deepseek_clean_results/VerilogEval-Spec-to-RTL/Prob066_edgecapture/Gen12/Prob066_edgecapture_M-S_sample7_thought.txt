Simplified solution with clear edge detection and capture:

1. **Single Register Approach**: Use only one register to store the captured edges, eliminating the need for a separate previous input register. We'll directly compare the current input with the registered version of itself.

2. **Immediate Capture**: When a falling edge is detected (current bit is 0, previous bit was 1), immediately set the corresponding output bit and keep it set until reset.

3. **Synchronous Reset**: Maintain synchronous reset functionality to clear all captured edges.

Key simplifications:
- Removes the separate prev_in register
- Uses the output register itself for both storage and edge detection
- Same functionality with fewer registers
- Clearer implementation of the sticky capture mechanism
