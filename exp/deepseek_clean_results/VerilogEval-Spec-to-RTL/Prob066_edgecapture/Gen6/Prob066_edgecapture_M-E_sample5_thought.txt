Novel approach using parallel edge detectors with sticky flags:

1. **Single-Stage History**: For each bit, maintain only the previous value (prev_in) to detect transitions between consecutive cycles. This simplifies the design while meeting requirements.

2. **Falling Edge Detection**: Detect when current bit is 0 and previous bit was 1 (prev_in & ~in). This directly implements the required 1-to-0 transition detection.

3. **Sticky Capture Registers**: Each bit has a dedicated sticky flag that gets set upon edge detection and only clears on reset. This ensures the output remains asserted until reset.

4. **Parallel Processing**: All 32 bits are processed independently and in parallel, with no interdependencies between bits.

Advantages:
- Minimal storage requirements (only one previous value register)
- Direct and clear edge detection logic
- Each bit's capture state is independent
- Efficient implementation with parallel processing
- Clear synchronous reset behavior
