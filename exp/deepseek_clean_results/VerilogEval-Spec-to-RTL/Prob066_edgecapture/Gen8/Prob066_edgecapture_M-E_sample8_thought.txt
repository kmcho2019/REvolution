Here's a novel approach using a two-stage edge detection pipeline with explicit state tracking:

1. Instead of just storing the previous input, we'll track both the current and two previous states (prev1_in and prev2_in)
2. We'll detect falling edges when:
   - prev2_in was 1 (two cycles ago)
   - prev1_in was 1 (last cycle)
   - current in is 0
3. This creates a more robust edge detector that requires the signal to be stable high for two cycles before a falling edge is recognized
4. The output remains latched until reset, same as before
5. Benefits:
   - More reliable edge detection (avoids glitches)
   - Still maintains all original requirements
   - Different architectural approach from the original solution
   - Better noise immunity
