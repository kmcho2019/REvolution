Refactored approach using purely combinational logic for edge detection and separate sequential elements:

1. **Clear Separation of Concerns**:
   - Use dedicated registers for previous input and captured state
   - Move edge detection to combinational assign statements
   - Keep sequential updates in always blocks

2. **Improved Timing**:
   - The edge detection now properly compares current input with the registered previous value
   - Captured state updates synchronously with proper timing

3. **Structural Simplicity**:
   - Single always block for sequential elements
   - Combinational logic outside always blocks
   - Clear data flow from input to output

Key benefits:
- Maintains identical functionality
- Better timing characteristics
- Clearer separation of combinational and sequential logic
- Easier to understand and maintain
