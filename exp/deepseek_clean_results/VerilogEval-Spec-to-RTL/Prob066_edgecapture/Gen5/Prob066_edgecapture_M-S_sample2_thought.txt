To simplify while maintaining functionality:

1. **Single Register Approach**: Instead of tracking previous input separately, we can directly use the output register to store both the captured edges and serve as memory.

2. **Edge Detection Logic**: A falling edge is detected when current input is 0 and previous output bit was 1 (indicating the input was 1 last cycle).

3. **Persistent Output**: Once a bit is set in the output register (due to a falling edge), it remains set until reset. This is achieved by OR-ing the current edge detection with the previous output state.

4. **Simplified Reset**: Only need to clear the output register on reset since we're using it for both edge detection and storage.

This approach reduces:
- Register count by half (only output register needed)
- Logic complexity by eliminating separate input history tracking
- While maintaining all required functionality
