To properly detect 1->0 transitions, we need to:
1. Store the previous input value in a register
2. Compare current input with previous input to detect transitions
3. Use combinational logic to detect when current bit is 0 and previous was 1
4. Set output bits when transitions are detected and hold them until reset
5. Implement this with:
   - A register for previous input (prev_in)
   - Combinational logic for transition detection
   - Sequential logic to maintain captured transitions
6. Use separate always blocks for combinational and sequential logic
