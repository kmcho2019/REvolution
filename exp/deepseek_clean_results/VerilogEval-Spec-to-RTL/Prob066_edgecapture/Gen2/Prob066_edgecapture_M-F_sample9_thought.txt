To properly implement falling edge detection and capture:
1. Need two registers - one to store previous input state (prev_in) and one to capture detected edges (out_reg)
2. On each clock edge:
   - Store current input in prev_in for next cycle comparison
   - For each bit, detect falling edge when prev_in is 1 and current input is 0
   - Set corresponding out_reg bit if falling edge detected or keep previous state
3. Reset should clear both registers
4. Output is the persistent out_reg that holds detected edges until reset
5. All operations synchronous to positive clock edge
