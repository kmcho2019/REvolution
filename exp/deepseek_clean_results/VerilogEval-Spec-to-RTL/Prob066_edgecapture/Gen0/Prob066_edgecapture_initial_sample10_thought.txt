To implement this module, we need to:
1. Store the previous value of the input to compare with the current value
2. For each bit, detect when it changes from 1 to 0 (falling edge)
3. Set a latch for each bit when this condition occurs
4. The latches should remain set until reset
5. The output is the collection of these latched bits

We'll use:
- A 32-bit register to store the previous input value
- 32 edge detectors (one per bit) to detect 1→0 transitions
- 32 set-reset flip-flops (one per bit) that get set on detection and reset only by the global reset
