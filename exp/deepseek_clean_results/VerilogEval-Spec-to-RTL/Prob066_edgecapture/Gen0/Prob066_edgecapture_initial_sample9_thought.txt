To implement this module, we need to:
1. Store the previous value of the input to compare with the current value
2. For each bit, detect a falling edge (1->0 transition)
3. Set a latch for each bit when its falling edge is detected
4. The latches should remain set until reset
5. Use synchronous reset for all sequential elements

We'll use:
- A 32-bit register to store the previous input value
- 32 edge detectors (one per bit)
- 32 latches (one per bit) that set on falling edge and clear on reset
