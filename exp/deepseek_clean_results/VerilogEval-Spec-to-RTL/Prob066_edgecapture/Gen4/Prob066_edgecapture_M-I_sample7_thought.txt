To correctly implement the falling edge detection and capture functionality:

1. **Single-Stage Pipeline**: For each bit, we only need to store the previous value (prev_in) to compare with the current input (in). This simplifies the pipeline while maintaining accurate edge detection.

2. **Correct Edge Detection**: A falling edge is detected when prev_in is 1 and current in is 0 (1->0 transition in consecutive cycles).

3. **Persistent Capture**: Once a falling edge is detected for any bit, its corresponding bit in the output register (out) is set and remains set until reset. This is achieved by OR-ing the current edge detection with the previous output state.

4. **Synchronous Reset**: All registers are cleared synchronously when reset is high.

This approach ensures:
- Accurate detection of 1->0 transitions
- Persistent output until reset
- Minimal hardware overhead (only one register stage per bit)
- Correct timing with synchronous operation
