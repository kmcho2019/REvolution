Simplified approach:
1. Use a single register to store the previous input value (in_prev)
2. Detect falling edges by comparing current input with previous input (in_prev & ~in)
3. Use edge_capture register to hold detected edges until reset
4. Reset clears both registers
5. Key simplifications:
   - Eliminates separate delay buffer
   - Uses direct comparison between current and previous input
   - Maintains same functionality with fewer operations
