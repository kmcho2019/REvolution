Here's a simplified approach that maintains the same functionality with less complexity:

1. Use a single register to store the previous input value (instead of two)
2. Directly compare current input with previous input to detect falling edges
3. Set output bits when falling edges are detected and hold them until reset
4. This eliminates the pipeline delay and reduces register usage by half

Key simplifications:
- Single register for input history instead of two
- Direct edge detection without intermediate pipeline stages
- Same cycle detection of falling edges
- Maintains all required functionality with less hardware
