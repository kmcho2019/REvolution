Simplified approach with direct edge detection and capture:

1. Core idea remains detecting 1-to-0 transitions (falling edges)
2. Key simplifications:
   - Eliminate separate prev_in register by using non-blocking assignment
   - Combine detection and capture in a single always block
   - Use bitwise OR to accumulate all detected transitions
3. Maintain same reset behavior (synchronous clear)
4. Output directly reflects the capture register
5. Advantages:
   - Fewer registers (only capture_reg needed)
   - Same cycle detection (no additional latency)
   - Clearer one-to-one correspondence between spec and implementation
6. Functionality identical to original: any 1-to-0 transition permanently sets corresponding bit until reset
