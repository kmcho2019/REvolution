The key requirements are:
1. Detect falling edges (1→0 transitions) on each bit
2. Capture (latch) these detections until reset
3. Output should show all bits that have ever had a falling edge since last reset

Simplified approach:
- Use a single register to store detected edges
- Each cycle, OR new falling edges with existing captures
- Reset clears all captures
- No need for separate prev_in storage - can compare directly with registered input
