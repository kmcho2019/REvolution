Here's a novel approach using a two-stage pipeline for transition detection:
1. First stage: Store the input from two consecutive cycles (current and previous)
2. Second stage: Compare these stored values to detect 1->0 transitions
3. Use a separate set of registers to maintain the captured state
4. This eliminates the race condition by properly aligning the comparison data
5. The captured state is only updated when a transition is detected, not continuously ORed
