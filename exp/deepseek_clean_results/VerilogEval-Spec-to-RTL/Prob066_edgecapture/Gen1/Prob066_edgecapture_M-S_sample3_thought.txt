To simplify while maintaining correct functionality:
1. Remove the separate prev_in register since we can use the output register itself to track the previous state
2. The output bits serve dual purpose - they both store the captured transitions and remember the previous input state
3. For each bit, set output if either:
   - It was already set (captured transition)
   - We detect a 1->0 transition (current input is 0 and previous state was 1)
4. Reset clears all outputs as before
This eliminates one register while maintaining correct transition detection.
