Here's a simplified approach that directly addresses the edge detection requirements:

1. **Single Register Storage**:
   - Instead of using a 2-bit history for each input, store only the previous value of each input bit
   - This reduces storage requirements by half while maintaining the same functionality

2. **Direct Edge Detection**:
   - Compare current input with stored previous value
   - Falling edge is detected when previous=1 and current=0

3. **Simplified Capture Logic**:
   - Each output bit becomes and stays 1 when a falling edge is detected on its corresponding input
   - Reset clears all captured states

Key improvements:
- Eliminates unnecessary shift register complexity
- Uses minimal storage (1 bit per input instead of 2)
- Clear and direct edge detection logic
- Maintains all required functionality
