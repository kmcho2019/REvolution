Refactored approach with clear separation of edge detection and capture logic:

1. **Two-Stage Edge Detection**:
   - Use two registers (prev_in and current_in) to properly capture input transitions
   - Falling edge detected when prev_in=1 and current_in=0

2. **Independent Capture Logic**:
   - Separate register (captured) maintains persistent output until reset
   - Each falling edge sets corresponding bit in captured register
   - Reset clears all captured bits

3. **Clean Timing**:
   - All state updates occur synchronously on clock edge
   - No combinational feedback loops
   - Output directly reflects captured register state

Key improvements:
- Proper edge detection with two-stage pipeline
- Clear separation between edge detection and state maintenance
- No combinational feedback or race conditions
- Output remains stable between clock edges
