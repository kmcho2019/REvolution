Novel Architectural Idea: State Machine with Direct Output Encoding
1. Instead of using a counter with arithmetic operations, implement a finite state machine with explicit state transitions
2. Each state directly corresponds to the output value (4-6,0-1)
3. Advantages:
   - Eliminates arithmetic logic (adder, comparator)
   - Simple state transitions via case statement
   - Clear mapping between states and outputs
   - Potentially better timing as no arithmetic operations in critical path
4. Behavior:
   - Reset to state 4 when a=1
   - Cycle through states 4→5→6→0→1 when a=0
   - Wrap around from 1 back to 4 (though waveform doesn't show this case)
