Novel Architectural Idea:
1. Implement a hybrid counter/register approach where the counter is conditionally frozen
2. Use a priority encoder to handle the 'a' input dominance
3. The design uses a parallel load mechanism when 'a' is high, bypassing the counter logic
4. When 'a' is low, the counter operates normally with rollover at 6
5. This approach minimizes logic depth by separating the load and count paths

Key Features:
- Parallel load path for immediate value setting (when a=1)
- Separate counting path with simple increment logic
- Priority given to 'a' input through conditional operator
- Reduced gate count compared to full state machine
- Clear separation of control and data paths
