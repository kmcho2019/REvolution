Here's a novel approach using a state machine with explicit state transitions:
1. Instead of simple increment/wrap logic, implement a 7-state FSM (states 0-6)
2. Use a parameter to define the initial state (4)
3. When a=1, maintain current state (hold)
4. When a=0, transition to next state with wrap-around
5. This approach makes the state transitions more explicit and verifiable
6. The FSM will naturally hold at state 4 when a=1 and progress through states when a=0
