Here's a novel approach using a finite state machine (FSM) with explicit state encoding:
1. Use a 3-bit state register to track the current value
2. Implement two distinct state transition behaviors:
   - When a=1: Force transition to state '100' (4)
   - When a=0: Cycle through states 4→5→6→0→1
3. Use a case statement for clear state transitions
4. This makes the state machine behavior more explicit and potentially more readable
5. The FSM approach could offer better optimization opportunities for synthesis tools
