Here's a novel approach using a finite state machine (FSM) with explicit states:

1. Instead of using arithmetic operations, we'll explicitly define each state transition
2. The FSM will have 5 states representing values 0,1,4,5,6
3. When a=1, the FSM immediately transitions to state 4 (combinational path)
4. When a=0, the FSM follows sequential transitions: 4→5→6→0→1
5. This approach eliminates arithmetic logic and uses pure state transitions

Benefits:
- More explicit state control
- No arithmetic operations needed
- Easier to modify state transitions if requirements change
- Potentially better timing as it avoids carry chains
