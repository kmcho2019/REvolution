Refactored approach using a simpler state machine with direct binary encoding:
1. Use binary encoding for states (0-4) matching output values (4,5,6,0,1)
2. Implement as a straightforward counter that holds when a=1, counts down when a=0
3. Use a single always block for cleaner sequential logic
4. Explicit state transitions with wrap-around from 1 back to 4
5. Direct state-to-output mapping (state value = output value)
