Refactored design approach:
1. Separate the combinational and sequential logic for better clarity
2. Use continuous assignment for the combinational part (a=1 case)
3. Keep the sequential part for the counter (a=0 case)
4. Use a wire for the combinational output and a register for the sequential part
5. Mux between them based on 'a' input

Key benefits:
- Clear separation of combinational vs sequential logic
- Easier to modify each part independently
- More explicit about the muxing behavior
- Maintains same functionality while being more modular
