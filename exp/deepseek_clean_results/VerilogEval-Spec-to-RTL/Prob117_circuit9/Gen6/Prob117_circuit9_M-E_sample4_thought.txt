Novel Architectural Idea:
1. Instead of a simple counter with reset, implement a state machine with explicit states for each value (0-6)
2. Use a one-hot encoding scheme for the states to potentially improve timing and power characteristics
3. Implement a next-state logic that:
   - Resets to state '4' when a=1
   - Cycles through states 4→5→6→0→1 when a=0
4. Add a state-to-output decoder that converts the one-hot state to binary output
5. This approach may offer better timing for certain technologies and clearer state visibility

Advantages:
- One-hot encoding can simplify next-state logic
- Explicit states make the design more maintainable
- Potential for better power optimization in some technologies
- Clear separation between state management and output encoding
