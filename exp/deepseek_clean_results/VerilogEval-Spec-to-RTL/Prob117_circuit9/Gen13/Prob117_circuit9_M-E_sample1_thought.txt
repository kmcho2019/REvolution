Novel Design Idea: Shift Register with Conditional Loading
1. Instead of using a counter, implement a circular shift register that:
   - Loads the value 4 (100) when 'a' is high
   - Rotates right when 'a' is low
2. Special Handling for Value 6:
   - When the shift would produce 7 (111), force it to 0 (000)
3. Benefits:
   - Eliminates arithmetic operations (no incrementer needed)
   - Uses simple bit manipulation which is area-efficient
   - Maintains the same functionality with different implementation
4. Implementation:
   - Registered output for clean timing
   - Combinational logic for next state calculation
