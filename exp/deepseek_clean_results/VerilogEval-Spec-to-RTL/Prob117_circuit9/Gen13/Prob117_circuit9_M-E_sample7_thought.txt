Novel approach using a finite state machine (FSM) with explicit state encoding:
1. Instead of using arithmetic operations, implement as a 7-state FSM (states 0-6)
2. Use one-hot encoding for state representation (7 flip-flops)
3. Next state logic becomes simple state transitions:
   - When a=1: always transition to state 4
   - When a=0: increment with wrap (4->5->6->0->1...)
4. Output is derived directly from active state
5. Benefits: 
   - Eliminates arithmetic operations
   - Simple combinatorial logic for state transitions
   - Potential power savings when holding state (only one flip-flop active)
