Refactoring Strategy:
1. Replace the procedural always blocks with continuous assignments for combinational logic
2. Separate the counter logic into distinct components:
   - A comparator for the wrap-around condition (q == 6)
   - An incrementer for the counter
   - A multiplexer for selecting between the constant 4 and counter value
3. Maintain the same synchronous behavior with a single always block for the flip-flop
4. This approach makes the logic more explicit and potentially easier for synthesis tools to optimize

The refactored version will have identical functionality but with a more dataflow-oriented style.
