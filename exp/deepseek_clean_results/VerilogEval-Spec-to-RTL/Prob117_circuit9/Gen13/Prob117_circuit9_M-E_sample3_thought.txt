Novel Architectural Idea:
1. Use a finite state machine (FSM) approach with explicit state encoding for better readability and control
2. Implement a Moore machine where outputs depend only on current state
3. Use parameterized state values for maintainability
4. Separate the state transition logic from output logic for clarity
5. Include a default case for robustness

Key Advantages:
1. More explicit state control compared to arithmetic approach
2. Easier to modify state transitions if requirements change
3. Clear separation between control and datapath
4. Better error handling with default case
5. More maintainable and debuggable structure
