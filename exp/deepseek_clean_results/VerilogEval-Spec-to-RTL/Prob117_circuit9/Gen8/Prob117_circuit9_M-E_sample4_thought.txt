Novel Architectural Idea:
1. Instead of using a standard counter approach, implement a circular shift register that holds the values 4,5,6,0,1 in sequence
2. The shift register will rotate only when 'a' is low, otherwise it holds its value
3. This approach eliminates the need for explicit comparison logic (state==6) and simplifies the increment/wrap-around logic
4. The shift register is initialized to hold the sequence [4,5,6,0,1] and rotates right when 'a' is low
5. Output is always the first element of the shift register

Advantages:
- No arithmetic operations needed (no adder)
- Simple control logic (just rotate enable)
- Naturally handles the wrap-around case without explicit checks
- Potentially better timing as it avoids the critical path of arithmetic operations
