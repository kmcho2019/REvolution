Simplified Design Idea:
1. Direct Counter Approach: Instead of a state machine, use a simple counter that:
   - Resets to 4 when 'a' is high
   - Increments (with wrap-around) when 'a' is low
2. Reduced States: Only need to track values 0-6 (3 bits), no need for one-hot encoding
3. Minimal Logic: Single always block with simple conditional assignment
4. Same Behavior: Maintains identical functionality to original specification but with fewer resources
