Refactoring approach:
1. Instead of using an always block with posedge clk, we'll implement the same behavior using combinational logic and a register
2. Use an assign statement for the next state logic
3. Separate the sequential and combinational parts explicitly
4. The functionality remains identical: reset to 4 when a=1, increment with wrap when a=0
5. This makes the design more modular and separates concerns clearly
