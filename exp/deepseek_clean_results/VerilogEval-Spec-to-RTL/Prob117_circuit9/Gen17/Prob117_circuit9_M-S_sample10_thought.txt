Simplified Design Idea:
1. The core functionality is a counter that increments when a=0 and resets to 4 when a=1
2. Instead of a full case statement, we can use a simple increment with wrap-around
3. The a=1 condition overrides the counter behavior and forces q=4
4. This reduces the logic to a simple conditional assignment and increment
5. The default case is handled naturally by the 3-bit counter wrap-around

Key Simplifications:
- Replaced case statement with simple arithmetic
- Eliminated explicit state transitions
- Reduced logic complexity while maintaining same behavior
- Still maintains all original functionality
