Novel Design Idea:
1. Shift Register Approach: Instead of a counter, use a circular shift register to represent the sequence.
2. Predefined Pattern: The sequence follows a specific pattern (4,5,6,0,1) when 'a' is low, and stays at 4 when 'a' is high.
3. Efficient Encoding: Use a 5-bit shift register where each bit represents one state in the sequence (100,101,110,000,001).
4. Dynamic Selection: The current output is selected from the shift register based on the pattern position.
5. Reset Mechanism: When 'a' is high, force the shift register to a state that always outputs 4.

Advantages:
- Eliminates arithmetic operations (no adder needed)
- Simple shift operation for state transitions
- Clear separation between reset and normal operation
