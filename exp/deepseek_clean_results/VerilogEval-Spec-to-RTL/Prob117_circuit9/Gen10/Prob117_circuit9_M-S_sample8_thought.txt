The current implementation uses a ternary operator for increment and wrap-around logic, which adds some complexity. We can simplify this by:
1. Maintaining the synchronous reset to 4 when a=1
2. For a=0, simply increment q and let it naturally wrap around when it overflows (since it's a 3-bit register)
3. This eliminates the need for explicit comparison and selection logic
4. The behavior remains identical because:
   - When q=6 and we increment, it wraps to 7 (0b111) + 1 = 0 (0b000) due to overflow
   - However, the waveform shows q going from 6 to 0, which matches this behavior
