Novel Design Approach:
1. Use a finite state machine (FSM) with explicit state encoding for better readability and control
2. Implement a 4-state FSM where:
   - State S4: q = 4 (when a=1)
   - States S5, S6, S0: represent the counting sequence when a=0
3. Use a case statement for clear state transitions
4. Separate the state transition logic from output logic
5. This approach makes the design more modular and easier to extend/modify
6. The FSM will naturally handle the wrap-around behavior when reaching state S6
