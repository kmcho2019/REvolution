Refactored Design Idea:
1. Binary Counter Approach: Instead of explicit state machine, use a counter that:
   - Resets to 4 when 'a' is high
   - Increments when 'a' is low
   - Wraps around after reaching 6
2. Combinational Logic: Use continuous assignment for the counter logic
3. Edge Detection: Implement a clock edge detector to trigger counter updates
4. Simplified Structure: Remove explicit state encoding while maintaining same behavior

Key Changes:
- Replaced state machine with arithmetic counter
- Used continuous assignment for more transparent logic
- Maintained same functionality with simpler structure
- Eliminated redundant state encoding
