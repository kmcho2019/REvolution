Novel Architectural Idea:
1. Implement a hybrid approach combining a counter with a multiplexer
2. Use a free-running 3-bit counter that increments every clock cycle
3. The output 'q' is selected between the counter value and a fixed value (4) based on input 'a'
4. The counter automatically wraps around after reaching 6
5. This approach minimizes state transitions and leverages simple arithmetic

Key Features:
- Continuous counter operation regardless of 'a' input
- Output selection via simple multiplexing
- No need for complex state transition logic
- Efficient use of arithmetic operations
- Clean separation between counting and output selection
