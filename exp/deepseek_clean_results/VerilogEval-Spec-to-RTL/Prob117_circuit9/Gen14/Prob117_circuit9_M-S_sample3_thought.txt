Simplified Design Idea:
1. Direct Counter Implementation: Instead of a state machine, use a simple counter that:
   - Resets to 4 when 'a' is high
   - Increments (with wrap-around) when 'a' is low
2. Minimal State Representation: Since we only need values 0-6, a 3-bit counter is sufficient
3. Simplified Logic: Remove unnecessary state encoding and case statements, using basic arithmetic and conditional assignment
4. Maintain Same Behavior: Preserve the exact functionality shown in the waveform
