Novel Design Idea:
1. Shift Register Approach: Instead of a counter, use a circular shift register that:
   - Holds value '4' (100) when 'a' is high
   - Rotates through a predefined sequence (4,5,6,0,1) when 'a' is low
2. Pattern Storage: The shift register stores the complete sequence pattern
3. Efficient Rotation: Uses simple shift operations rather than arithmetic
4. Single Cycle Update: Maintains same timing as original but with different implementation

This approach eliminates arithmetic operations entirely, potentially reducing power consumption and improving timing in some technologies. The shift-based implementation might be more area-efficient in certain FPGA architectures.
