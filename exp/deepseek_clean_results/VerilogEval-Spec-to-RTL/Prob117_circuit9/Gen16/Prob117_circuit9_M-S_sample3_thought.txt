Simplified Design Idea:
1. Direct Counter Implementation: Instead of using a state machine, implement a simple counter that increments when 'a' is low and resets to 4 when 'a' is high.
2. Reduced State Encoding: Use binary encoding directly for the counter since we only need values 0-6 (3 bits are sufficient).
3. Simplified Logic: Remove unnecessary state parameters and case statements, replacing with straightforward conditional increment.
4. Maintain Same Behavior: Keep the exact same functionality where:
   - 'a'=1 forces output to 4
   - 'a'=0 increments through 0-6 with wrap-around
