Alternative approach using a state machine with explicit states:
1. Instead of a counter, implement a state machine with 7 states (4-6 and 0-3)
2. When a=1, force state to 4 (synchronously)
3. When a=0, transition through states 4→5→6→0→1 (synchronously)
4. This makes the behavior more explicit and may have better timing characteristics
5. Uses case statement for clear state transitions
