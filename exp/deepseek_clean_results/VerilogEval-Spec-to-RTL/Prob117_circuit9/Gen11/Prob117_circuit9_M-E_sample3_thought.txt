Novel Architecture Idea: "Conditional Carry-Save Counter"
1. Instead of a simple incrementer with wrap-around, implement a carry-save counter that:
   - Uses a 3-bit register with carry lookahead logic
   - Has two operation modes controlled by input 'a':
     * Preset mode (a=1): forces output to 4 (100 in binary)
     * Count mode (a=0): implements a fast increment with carry propagation
2. Key innovations:
   - Parallel carry generation for faster counting
   - Direct preset wiring for the reset condition
   - Optimized logic that combines preset and count operations
3. Benefits:
   - Potentially better timing due to parallel carry logic
   - Clear separation between preset and count operations
   - More hardware-efficient implementation
