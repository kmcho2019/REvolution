This solution implements the scancode mapping using a ROM-based lookup table approach:

1. Precompute all possible 16-bit input combinations (though only 4 matter)
2. Store the arrow key mappings in a small synthesized ROM
3. Use the scancode as an address to index into the ROM
4. Output the corresponding arrow key signals from the ROM data

Key advantages:
- Extremely fast lookup time (single cycle access)
- Scales efficiently if more keys need to be supported
- Clean separation of configuration (ROM contents) from logic
- ROM typically synthesizes efficiently in modern FPGAs/ASICs
- Easy to modify mappings by changing ROM contents
- No complex decoding logic required
- Power efficient for sparse mappings (only 4 valid codes out of 64K)
