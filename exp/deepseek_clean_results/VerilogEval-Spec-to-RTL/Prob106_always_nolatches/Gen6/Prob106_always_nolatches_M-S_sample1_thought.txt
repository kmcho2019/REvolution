Here's a simplified approach that maintains functionality while reducing complexity:

1. Use a single case statement to check the entire 16-bit scancode
2. Each case directly corresponds to one of the four arrow key scancodes
3. Default case handles all other inputs (outputs remain low)
4. This approach is more readable and concise
5. Synthesis tools can optimize the case statement efficiently
6. Eliminates redundant comparisons of the first byte (0xE0) since we check the full 16-bit value
7. Fewer lines of code while maintaining the same functionality
