The original solution uses hierarchical detection and priority encoding, which adds unnecessary complexity since the scancodes are mutually exclusive. We can simplify by:
1. Directly comparing the full 16-bit scancode against each arrow key pattern
2. Assigning each output independently based on exact match
3. Removing intermediate signals since they don't provide any benefit in this simple case
4. Using simple parallel comparisons without priority logic

This results in a cleaner, more straightforward implementation that's easier to understand and maintain while being equally efficient.
