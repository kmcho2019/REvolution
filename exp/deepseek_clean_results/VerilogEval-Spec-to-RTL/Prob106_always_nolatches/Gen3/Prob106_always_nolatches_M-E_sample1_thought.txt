Here's an alternative approach using a shift register and edge detection to handle potential glitches or metastability in the scancode input. The design:
1. Uses a 16-bit shift register to capture and stabilize the scancode
2. Implements edge detection to only evaluate new scancodes when they're stable
3. Uses a priority encoder style approach to ensure only one output is active
4. Includes a simple state machine to handle the arrow key detection

This approach provides better noise immunity and more deterministic behavior compared to pure combinational logic, while still maintaining low latency.
