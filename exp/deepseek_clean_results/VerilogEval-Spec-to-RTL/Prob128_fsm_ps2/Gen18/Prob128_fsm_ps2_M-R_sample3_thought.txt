The refactored solution will:
1. Use one-hot encoding for the state machine to improve timing
2. Move state transitions and output logic to separate always blocks for clarity
3. Use explicit state names instead of numeric values for better readability
4. Implement the done signal as a continuous assignment
5. Maintain the same core functionality while potentially improving synthesis results

Key changes:
- One-hot state encoding (001, 010, 100) reduces fan-out and simplifies decoding
- Separate combinational and sequential logic blocks
- Named states instead of numeric values
- Continuous assignment for done signal
- Same synchronous reset behavior
