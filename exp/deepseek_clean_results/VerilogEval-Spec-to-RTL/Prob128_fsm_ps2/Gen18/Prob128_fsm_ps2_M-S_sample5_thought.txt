Simplified Design Approach:
1. Use a 2-bit counter to track message bytes (0=waiting, 1=byte1, 2=byte2, 3=byte3)
2. Reset counter to 0 on reset or when waiting for start byte (in[3]=1)
3. Increment counter each cycle after finding start byte
4. Generate 'done' signal when counter reaches 3 (immediately after third byte)
5. Simple state transitions with minimal logic

Key Simplifications:
- Single always block for all sequential logic
- Direct counter increment instead of shift operations
- Clear state progression with minimal conditions
- Done signal derived directly from counter value
