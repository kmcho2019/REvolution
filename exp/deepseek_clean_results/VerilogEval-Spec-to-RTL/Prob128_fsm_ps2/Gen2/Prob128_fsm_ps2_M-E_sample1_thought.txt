Here's a novel approach using a shift register and edge detection:
1. Instead of a counter, use a 3-byte shift register to track the last 3 bytes received
2. Implement edge detection for in[3] to identify potential message starts
3. When a rising edge on in[3] is detected, mark the next byte as potential message start
4. After exactly 3 bytes from the marked start, assert 'done' in the same cycle
5. The shift register naturally handles continuous byte streams and message boundaries

Key advantages:
- No explicit state machine needed
- Naturally handles overlapping messages
- Simple and robust implementation
- Done signal timing is precise (same cycle as third byte)
- Clear reset behavior
