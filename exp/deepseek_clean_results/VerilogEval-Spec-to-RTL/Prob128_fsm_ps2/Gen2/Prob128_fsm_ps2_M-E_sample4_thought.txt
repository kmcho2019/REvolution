Here's a novel approach using a shift register and counter instead of a traditional FSM:

1. Use a 24-bit shift register to store incoming bytes
2. Implement a 2-bit counter to track byte positions (0-2)
3. When counter=0, check if in[3]=1 to validate start of message
4. Increment counter for each byte received
5. When counter reaches 3 (indicating full message received):
   - Assert done signal
   - Reset counter to 0
6. Reset condition clears both shift register and counter

This approach eliminates explicit state transitions and instead uses the counter value to implicitly track message progress. The shift register provides potential future flexibility if message contents need to be processed.
