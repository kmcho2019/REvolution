To simplify the solution while maintaining functionality, we can:
1. Use a counter to track the number of bytes received in the current message (0-2)
2. Reset the counter when we see a byte with in[3]=1 (indicating start of new message)
3. Assert 'done' when the counter reaches 2 (after receiving 3 bytes)
4. The counter increments on each byte received, wrapping around after 2

This approach eliminates the explicit state machine and replaces it with a simple counter, reducing complexity while maintaining the same functionality.
