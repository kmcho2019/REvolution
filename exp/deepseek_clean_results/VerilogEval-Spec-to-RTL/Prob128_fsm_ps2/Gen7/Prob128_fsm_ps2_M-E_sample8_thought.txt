Here's a novel approach using a shift register to track the last three bytes received, combined with a state machine that validates message boundaries:

1. Instead of just counting bytes, we'll maintain a 24-bit shift register to store the last three bytes received
2. We'll use a state machine with two states: SEARCH (looking for start byte) and COLLECT (collecting message bytes)
3. When in SEARCH state, we look for in[3]=1 to transition to COLLECT
4. In COLLECT state, we count bytes and validate the message structure
5. The done signal is asserted when we have three valid bytes, with the first one having in[3]=1
6. This approach provides more visibility into the message structure and could be extended for more complex validation

The key advantage is that we maintain the complete message context, which could be useful for future extensions like message validation or processing.
