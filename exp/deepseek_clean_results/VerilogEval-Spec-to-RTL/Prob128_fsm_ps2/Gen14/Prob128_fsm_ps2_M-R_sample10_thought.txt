Refactoring Strategy:
1. State Representation: Switch from counter-based to explicit state machine with named states (IDLE, BYTE1, BYTE2, BYTE3) for better readability
2. Output Generation: Use continuous assignment for 'done' signal to simplify timing
3. State Transitions: Implement next-state logic separately from state register for clearer FSM structure
4. Reset Handling: Maintain synchronous reset but make it more explicit in state transitions
5. Power Optimization: Only update state when necessary (on valid byte reception)

Key Changes:
- More explicit FSM structure improves maintainability
- Separate combinational and sequential logic blocks
- Continuous assignment for output reduces sequential logic
- Clear state transitions improve readability
- Maintains same functionality as original
