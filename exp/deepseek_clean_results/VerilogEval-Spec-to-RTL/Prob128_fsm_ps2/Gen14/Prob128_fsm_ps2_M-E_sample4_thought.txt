Novel Architectural Idea:
Instead of using a simple counter-based approach, we'll implement a shift register that stores the last 3 bytes received. This allows us to:
1. Continuously shift in new bytes while maintaining the last 3 received bytes
2. Check for message boundaries by examining the oldest byte in the shift register (which would be the potential start of a message)
3. Use a smaller state machine (just 2 states) to track whether we're currently in a message or searching for one
4. The done signal is generated combinatorially when we have 3 valid bytes in the shift register

Advantages:
- More robust against glitches in the input stream
- Easier to extend if message format changes
- Clear separation between data storage and control logic
- Potentially better timing as the critical path is simplified
