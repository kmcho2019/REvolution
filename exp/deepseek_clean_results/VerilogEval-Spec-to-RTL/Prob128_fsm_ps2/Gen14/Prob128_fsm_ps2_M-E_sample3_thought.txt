Novel Architectural Idea: Shift Register with Boundary Detection
Instead of using a counter-based FSM, we can implement a shift register that stores the last 3 bytes received. The key insight is that we only need to check in[3] of the oldest byte in the shift register to determine message boundaries. This approach:
1. Uses a 24-bit shift register (3 bytes) that shifts in new data each cycle
2. Checks the oldest byte's in[3] bit when the register is full
3. Generates 'done' when the shift register contains a valid message (oldest byte has in[3]=1)
4. Automatically handles continuous streaming by always shifting
5. Simplifies control logic by eliminating explicit state transitions

Advantages:
- No explicit state machine needed
- Naturally handles back-to-back messages
- All boundary checking happens in parallel
- Easily extensible if message format changes
