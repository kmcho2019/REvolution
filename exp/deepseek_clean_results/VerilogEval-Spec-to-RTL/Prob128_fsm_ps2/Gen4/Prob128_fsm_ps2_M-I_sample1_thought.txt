To optimize this design for better PPA (Power, Performance, Area), I'll implement the following improvements:

1. Performance Optimization:
- Pipeline the 'done' signal generation by making it registered output only
- Simplify state transitions to reduce combinatorial logic depth

2. Power Optimization:
- Remove unnecessary signal toggling by making 'done' purely registered
- Use one-hot encoding for state machine to reduce switching activity

3. Area Optimization:
- Keep the minimal 2-bit state encoding (since one-hot would use more flops)
- Remove default state assignment since we cover all cases
