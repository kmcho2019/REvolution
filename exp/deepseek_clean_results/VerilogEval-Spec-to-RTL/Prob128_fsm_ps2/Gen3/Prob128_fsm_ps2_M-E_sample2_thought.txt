Here's a novel approach using a shift register and pattern matching:
1. Instead of tracking byte positions with a counter, we'll use a 24-bit shift register to store the last 3 bytes received
2. The shift register continuously shifts in new bytes from the input
3. We'll implement pattern matching to detect when the 3rd most recent byte has in[3]=1
4. This creates a sliding window that automatically aligns to message boundaries
5. Done is asserted whenever the window contains a complete message (after 3 bytes shifted in)

Advantages:
- No explicit state variables needed
- Naturally handles back-to-back messages
- Simple pattern matching logic
- Easily extensible if message format changes
