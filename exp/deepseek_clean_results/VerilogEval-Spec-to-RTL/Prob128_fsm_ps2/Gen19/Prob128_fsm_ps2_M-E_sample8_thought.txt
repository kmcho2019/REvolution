Instead of using a traditional state machine, we can implement a circular buffer that stores the last 3 bytes received. The key innovation is:
1. Use a 3-byte circular buffer to always maintain the last 3 received bytes
2. Implement a pattern matcher that continuously checks if the oldest byte in the buffer has in[3]=1
3. When this pattern is detected, assert 'done' immediately
4. The buffer automatically handles message boundary detection by always looking for valid start bytes
5. This approach naturally handles message streaming without explicit state tracking

Advantages:
- No explicit state machine needed
- Naturally handles back-to-back messages
- More robust against noise (can easily be extended to include CRC checks)
- Easier to scale for longer message formats
- Clear separation between storage and detection logic
