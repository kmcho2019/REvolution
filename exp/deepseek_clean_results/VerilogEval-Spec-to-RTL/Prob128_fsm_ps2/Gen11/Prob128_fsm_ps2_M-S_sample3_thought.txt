Simplification Strategy:
1. State Reduction: Use a single 2-bit counter to track message position (0=waiting, 1=byte1, 2=byte2, 3=byte3)
2. Direct Output: Generate 'done' combinatorially when counter reaches 3 (next cycle will reset)
3. Simplified Transitions: 
   - Reset clears counter
   - Counter increments when in message (non-zero state)
   - Reset to waiting state after byte3
   - Only start new message from waiting state when in[3]=1
4. Remove redundant registers: Only need the counter state

Key Simplifications:
- Eliminate separate done register by making it combinational
- Simplified state transitions with clear wrap-around
- Reduced control logic complexity
- Maintains same functionality with fewer resources
