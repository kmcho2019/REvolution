The solution can be further simplified by:
1. Recognizing we only need to track the count of bytes received in the current message (0-2)
2. Using a simple 2-bit counter that increments for each byte after the start byte
3. Resetting the counter when we see a new start byte (in[3]=1) or on reset
4. Asserting 'done' when the counter reaches 2 (meaning we've received 3 bytes total)

Key simplifications:
- Eliminate the shift register completely
- Use a simple counter that increments
- Fewer state transitions and simpler logic
- Same functionality with even less logic
