Refactoring Strategy:
1. Convert the sequential logic to use continuous assignments where possible
2. Implement the counter as a combinational next-state logic with a registered state
3. Use an explicit state encoding for better readability
4. Move the done signal generation to a continuous assignment
5. Maintain the same synchronous reset behavior

Key Changes:
- Explicit state encoding (IDLE, BYTE1, BYTE2, BYTE3) for better readability
- Next state logic implemented combinationally
- Registered state storage
- Done signal generated combinationally from state
- More modular structure while maintaining same functionality
