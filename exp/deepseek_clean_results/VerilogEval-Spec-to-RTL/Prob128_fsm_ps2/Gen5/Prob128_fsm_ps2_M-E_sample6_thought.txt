Novel Architecture Idea:
1. Instead of using a counter-based FSM, implement a 3-byte shift register to store incoming bytes
2. Continuously check for the message pattern (in[3]=1 on first byte) in the shift register
3. When a valid 3-byte sequence is detected, assert 'done' and clear the shift register
4. This approach naturally handles message boundary detection by always looking at the most recent 3 bytes
5. Benefits:
   - No explicit state machine needed
   - Naturally handles back-to-back messages
   - Simple pattern matching logic
   - Easily extensible if protocol changes
6. Reset clears the shift register and done signal
