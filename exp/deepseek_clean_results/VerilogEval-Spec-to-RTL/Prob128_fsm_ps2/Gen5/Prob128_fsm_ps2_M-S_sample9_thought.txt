The current solution can be simplified by:
1. Removing the explicit check for byte_counter == 0 since we can handle all cases with a single if-else structure
2. Combining the counter increment and done assertion logic into a single conditional block
3. Using simpler reset logic that directly assigns all values
4. Eliminating the default assignment since we can cover all cases explicitly

The key insight is that we only need to track whether we're at byte 1, 2, or 3 of a message, and the done signal is purely a function of being at byte 3. The reset condition can directly initialize everything.
