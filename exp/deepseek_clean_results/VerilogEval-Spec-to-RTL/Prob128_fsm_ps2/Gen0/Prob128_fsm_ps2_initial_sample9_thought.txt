To implement the TopModule, we need a finite state machine (FSM) that tracks the reception of three-byte messages in a PS/2 mouse protocol. The FSM will have the following states:
1. IDLE: Waiting for the first byte with in[3]=1.
2. BYTE2: Received the first byte, waiting for the second byte.
3. BYTE3: Received the second byte, waiting for the third byte.

The FSM transitions between these states based on the input bytes. When in[3]=1 is detected, it starts a new message. After receiving three bytes, it asserts 'done' for one cycle and returns to IDLE to look for the next message. The reset signal synchronously resets the FSM to the IDLE state.
