To implement the PS/2 mouse message boundary detection, we'll create a finite state machine (FSM) with three states:
1. IDLE: Waiting for the first byte of a message (in[3]=1)
2. BYTE2: Received first byte, waiting for second byte
3. BYTE3: Received second byte, waiting for third byte

The FSM transitions between these states as bytes are received. After receiving three bytes, it asserts 'done' for one cycle and returns to IDLE to look for the next message. The reset signal synchronously returns the FSM to IDLE state.
