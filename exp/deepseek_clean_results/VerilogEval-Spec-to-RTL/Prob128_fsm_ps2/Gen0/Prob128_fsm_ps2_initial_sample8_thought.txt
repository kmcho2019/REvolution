To solve this problem, we need to implement a finite state machine (FSM) that can identify the start of a PS/2 mouse message and track the receipt of all three bytes of the message. The FSM will have the following states:
1. IDLE: Waiting for the first byte of a message (in[3] = 1).
2. BYTE2: Received the first byte, waiting for the second byte.
3. BYTE3: Received the second byte, waiting for the third byte.

The FSM transitions between these states based on the input byte's in[3] bit and the current state. The 'done' signal is asserted in the cycle immediately after the third byte is received. The FSM resets to the IDLE state when the reset signal is high.
