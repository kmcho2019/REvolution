Simplification Strategy:
1. Reduce state machine to just 2 states (waiting for start byte vs. counting bytes)
2. Use a simple counter to track received bytes (0-2) within a message
3. Combine state and counter into a single 2-bit register
4. Directly assign 'done' when counter reaches 2 (third byte received)
5. Reset both state and counter on reset

Key Simplifications:
- Eliminates separate state and counter variables
- Uses simple increment for counter progression
- Minimal comparison operations (only checking in[3] and counter value)
- Single always block for all sequential logic
- Direct done signal assignment without extra logic
