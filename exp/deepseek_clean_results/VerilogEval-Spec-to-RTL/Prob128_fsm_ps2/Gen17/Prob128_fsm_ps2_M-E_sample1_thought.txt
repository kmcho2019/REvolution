Innovative Solution Concept:
1. Instead of a traditional state machine, use a shift register that captures both data and state information
2. Implement a "thermometer code" style detection where we track consecutive valid bytes
3. The shift register's bits serve dual purpose:
   - Bit 0: Valid start byte detected (in[3]==1)
   - Bit 1: Second byte received
   - Bit 2: Third byte received (triggers done)
4. This eliminates explicit state transitions and combines state tracking with data validation
5. Early termination: If we detect in[3]==1 during byte 2 or 3, we automatically reset the sequence
6. Power optimization: Only shift when receiving valid bytes or when resetting
