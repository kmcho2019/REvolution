Novel Architecture Idea:
1. Shift Register Approach: Instead of using a counter, implement a 3-byte shift register to store incoming bytes
2. Pattern Matching: Detect message boundaries by checking in[3] of the oldest byte in the shift register
3. Edge Detection: Use the shift register's state to precisely time the done signal
4. Benefits:
   - Naturally handles byte alignment without explicit state tracking
   - Easily extensible to longer message formats
   - Clear separation between data storage and control logic
   - More robust against glitches in the input stream
5. Implementation:
   - 24-bit shift register (3 bytes)
   - Control logic checks oldest byte's bit[3] when new byte arrives
   - Done signal generated when 3-byte window is valid
