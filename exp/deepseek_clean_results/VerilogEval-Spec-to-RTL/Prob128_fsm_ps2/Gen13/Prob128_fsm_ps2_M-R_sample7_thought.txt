Refactoring Approach:
1. State Encoding: Replace the counter with explicit state names for better readability
2. Output Logic: Use continuous assignment (assign) instead of combinational always block
3. State Transitions: Combine all state transition logic into a single always block
4. Reset Handling: Keep synchronous reset but simplify the initialization
5. Done Signal: Generate directly from state comparison for cleaner implementation

Key Changes:
- More readable with named states instead of counter values
- Eliminates separate combinational block by using assign
- Maintains same functionality with improved code structure
- Slightly more verbose but clearer state machine representation
