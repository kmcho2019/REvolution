Novel Architecture Idea:
Instead of using a simple counter-based approach, we'll implement a shift register that stores the last 3 bytes received. This allows us to:
1. Continuously monitor incoming bytes while maintaining history
2. Check for message boundaries in parallel rather than sequentially
3. Simplify the state machine to just track valid message detection
4. Enable potential future extensions (like message content verification)

Key Features:
- 24-bit shift register (3 bytes) with parallel loading
- Parallel detection of valid message start (byte1[3]=1)
- Single-cycle done signal generation when valid message is detected
- Reduced state complexity (only needs to track shift register contents)
- More robust against glitches in the input stream
