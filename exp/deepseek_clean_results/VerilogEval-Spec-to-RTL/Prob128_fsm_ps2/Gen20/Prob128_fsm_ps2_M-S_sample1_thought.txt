Simplification Strategy:
1. Eliminate the separate 'done' register by making it purely combinational
2. Reduce state tracking to just a 2-bit counter
3. Simplify the state transition logic to a single conditional
4. Maintain synchronous reset behavior
5. Remove unnecessary intermediate states by directly counting bytes

Key Improvements:
- 'done' is now combinational output derived from current state
- Single always block with minimal conditional logic
- Reduced register usage (only byte counter needed)
- Clear, straightforward state transitions
- Maintains identical functionality with fewer resources
