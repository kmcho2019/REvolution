The solution can be simplified while maintaining all functionality by:
1. Removing the explicit state shift operation since we only need to count to 3
2. Using a simple 2-bit counter to track byte position (00=waiting, 01=byte1, 10=byte2, 11=byte3)
3. Directly mapping counter value to done signal (done when counter==3)
4. Simplifying the reset logic by combining assignments
5. Eliminating the intermediate state variable by using counter directly

This reduces the logic to just a counter and simple comparison while maintaining the exact same behavior.
