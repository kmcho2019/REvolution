Simplification Strategy:
1. Remove the separate done register and make it purely combinational
2. Use a 2-bit counter to track message bytes (0=waiting, 1=byte1, 2=byte2, 3=byte3)
3. Generate done combinatorially when counter is 3 (just received third byte)
4. Reset counter to 0 on reset or after completing a message
5. Only advance counter when in[3] is set for the first byte, then unconditionally for next two bytes

Key Improvements:
- Eliminates one register (done) by making output combinational
- Simplifies state transitions with clear counter behavior
- Maintains identical functionality with fewer registers
- Reduces area and power with same timing characteristics
