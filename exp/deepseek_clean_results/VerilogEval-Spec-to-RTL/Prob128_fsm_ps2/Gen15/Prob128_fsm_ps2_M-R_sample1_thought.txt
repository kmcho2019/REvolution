Refactored Design Approach:
1. State Representation: Use explicit state names instead of counter values for better readability
2. Combinational Output: Make 'done' a combinational output based on current state
3. Next State Logic: Separate state transitions into clear blocks for each state
4. Reset Handling: Maintain synchronous reset but simplify state transitions
5. Direct Assignment: Use continuous assignments where possible for clarity

Key Improvements:
- More readable state machine with named states
- Combinational done signal reduces latency by one cycle
- Clear separation of state transition logic
- Maintains same functionality while being more maintainable
