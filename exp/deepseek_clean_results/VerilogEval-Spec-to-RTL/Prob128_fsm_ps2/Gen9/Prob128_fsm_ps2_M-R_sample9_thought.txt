Refactoring Strategy:
1. State Machine Restructuring: Replace the counter-based approach with explicit state encoding for better readability and maintainability.
2. Combinational Output: Use continuous assignment for 'done' signal to separate combinational and sequential logic clearly.
3. State Transitions: Make state transitions more explicit with named states instead of numeric values.
4. Synchronous Logic: Keep all sequential elements in a single always block for clarity.
5. Reset Handling: Maintain synchronous reset but make it more explicit in the state machine.

Key Changes:
- Named states (IDLE, BYTE1, BYTE2, BYTE3) instead of counter values
- Separate combinational done assignment
- Clearer state transition logic
- Maintains same functionality with improved readability
