Novel Architecture Idea:
1. Shift Register Approach: Instead of just counting bytes, maintain a 3-byte shift register to store the current message being assembled
2. Enhanced Validation: Check in[3] only when expected (byte 0 of message) but store all bytes
3. State Machine: Use explicit states for better readability and potential future enhancements
4. Early Termination: Immediately reset if we see in[3] at wrong position (invalid message)
5. Output Generation: Done is asserted only after valid 3-byte message is confirmed

Advantages:
- More robust against corrupted messages
- Maintains message history which could be useful for debugging
- Clear state transitions that match protocol expectations
- Easily extensible for additional message validation
