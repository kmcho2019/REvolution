Here's a novel approach using a multiplexer-based implementation with a gated clock technique. Instead of using a standard always block, we'll:
1. Create an internal mux that selects between the data input and reset value
2. Use the reset signal to control the mux selection
3. Implement the flip-flop behavior using a clock-gated approach where the clock is only effective when either the data changes or reset is active
This reduces unnecessary clock toggling when inputs are stable, potentially saving power.
