Instead of using a standard edge-triggered flip-flop, we can implement the functionality using two transparent latches in a master-slave configuration (pulse latch style). This approach:
1. Uses level-sensitive latches instead of edge-triggered flip-flops
2. Implements synchronous reset by gating the data input when reset is active
3. Potentially offers better PPA in some technologies due to simpler latch structures
4. Maintains the same synchronous reset behavior but with a different internal architecture
5. Uses clock inversion internally to create the master-slave timing
