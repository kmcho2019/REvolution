Novel Architectural Idea: Edge-Triggered Latch with Conditional Reset
1. Instead of using a standard D flip-flop, implement the functionality using a transparent latch with edge-triggered behavior
2. Use a combinational always block to create the latch behavior
3. The reset is still synchronous but implemented through conditional assignment
4. This approach demonstrates an alternative way to achieve flip-flop behavior using latches
5. The design maintains the same functionality but shows a different implementation perspective

Key Features:
- Uses level-sensitive latch with edge-trigger emulation
- Shows that flip-flop behavior can be built from latches
- Maintains synchronous reset functionality
