Instead of using the standard always block with posedge, we can:
1. Create a clock edge detector using XOR of current and previous clock values
2. Use this edge detection to trigger the flip-flop operation
3. Implement the D flip-flop behavior using a multiplexer that selects between:
   - The reset value (0) when reset is active
   - The input d when reset is inactive
4. The mux output is captured only on the rising clock edge
