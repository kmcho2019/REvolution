Instead of using a standard always block, we can implement the D flip-flop using gate-level primitives and a multiplexer for the synchronous reset functionality. The approach:
1. Use a NOT gate for reset inversion
2. Use an AND gate to conditionally pass the data input when not resetting
3. Feed this to a standard D flip-flop primitive (DFF)
4. This demonstrates how synchronous reset can be implemented at the gate level
