To simplify the D flip-flop implementation while maintaining the same functionality, I'll:
1. Remove the intermediate next_q register since it's unnecessary for this simple case
2. Combine the reset and data logic directly in the sequential block
3. Keep only the essential always block for the flip-flop behavior
4. Maintain the synchronous active-high reset functionality
5. Remove the initial block since it's not required for synthesis

This simplification reduces the code while preserving all required functionality:
- Single always block makes the design more compact
- Direct implementation of reset logic in the sequential block
- Same timing and behavior as original
- More typical and straightforward implementation style
