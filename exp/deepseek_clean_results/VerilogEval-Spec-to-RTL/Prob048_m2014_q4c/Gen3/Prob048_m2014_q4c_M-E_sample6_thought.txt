Here's a novel approach using a multiplexer-based implementation with explicit clock gating for the reset path. The key differences are:
1. Uses an explicit multiplexer structure instead of ternary operator
2. Implements clock gating on the reset path for potential power savings
3. Separates the data and reset paths clearly
4. Uses a local wire for the mux output before registering
5. Maintains the same functionality but with a different structural implementation
