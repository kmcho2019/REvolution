1. Introduce unnecessary logic (degrading PPA)
2. Create identical functionality with different syntax (no PPA improvement)
3. Potentially add timing paths where none exist currently

- Zero timing violations (perfect tns/wns)
- Minimal power consumption (only the switching activity of the wire itself)
