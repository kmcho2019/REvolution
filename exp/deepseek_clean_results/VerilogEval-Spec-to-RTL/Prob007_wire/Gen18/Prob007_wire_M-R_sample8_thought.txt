While the original implementation is perfectly valid, we can demonstrate an alternative structural approach that:
1. Uses a module instantiation to create the wire connection
2. Shows how this could be part of a larger hierarchical design
3. Maintains identical functionality while using different syntax
4. Illustrates how even simple connections can be implemented in multiple ways
