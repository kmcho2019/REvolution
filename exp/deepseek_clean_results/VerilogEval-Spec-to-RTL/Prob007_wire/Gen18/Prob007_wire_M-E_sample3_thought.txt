Let's implement a "delayed wire" concept where the output follows the input after a small, fixed delay. This can be useful for synchronization purposes in some designs. We'll use a simple buffer chain to create this delay. While this isn't strictly a wire anymore, it demonstrates how we can modify the basic wire concept while maintaining simplicity.

Key features:
1. Uses a chain of 2 inverters to create a small, consistent delay
2. Maintains signal polarity (two inverters = original signal)
3. Provides better noise immunity than a direct wire
4. Still very simple and small in area
