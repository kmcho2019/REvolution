Here's a novel approach that achieves the same functionality through a different architectural concept: using a finite state machine (FSM) that only has one state. While this is clearly overkill for a constant output, it demonstrates how even trivial functions could be implemented using more complex structures when needed for educational or demonstration purposes.

Key features:
1. Single-state FSM that never transitions
2. Output logic tied to the state (though only one state exists)
3. Technically implements the same functionality but through a state machine paradigm
4. Showcases how even simple functions can be framed as state machine problems

This approach is intentionally more complex than necessary to illustrate alternative design methodologies.
