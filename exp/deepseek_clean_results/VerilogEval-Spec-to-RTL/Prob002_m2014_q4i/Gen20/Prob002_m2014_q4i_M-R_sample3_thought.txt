The original implementation is already optimal for this simple case, but we can demonstrate alternative implementations that achieve the same functionality. Here are two alternative approaches:

1. Using an always block with blocking assignment (though this is less efficient for constant assignment)
2. Using a parameter with continuous assignment (though this adds unnecessary complexity)
