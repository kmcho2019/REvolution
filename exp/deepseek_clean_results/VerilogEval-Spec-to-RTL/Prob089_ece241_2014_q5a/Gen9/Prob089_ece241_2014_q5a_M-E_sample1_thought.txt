Instead of using a traditional state machine, we can implement the 2's complement operation using:
1. A flag to track when we've seen the first '1' (start_inverting)
2. The output is generated by either passing through the input (before first '1') or inverting it (after first '1')
3. The flag is set on the first occurrence of '1' and remains set until reset
4. This approach eliminates explicit state transitions and uses minimal sequential elements
5. The output is purely combinational based on the flag and input
