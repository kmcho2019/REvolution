Novel approach using shift register and bit inversion control:
1. Instead of using a state machine, implement a shift register to store the input bits
2. Use a control flag to track when we've seen the first '1' (similar to state machine approach)
3. The shift register allows us to:
   - Store the entire input sequence
   - Perform bit inversion in parallel once the first '1' is detected
4. Output is selected between:
   - Direct input (before first '1')
   - Inverted input (after first '1')
5. Reset clears the control flag and shift register
6. This approach trades off some area (for the shift register) for potentially simpler control logic

Key advantages:
- More explicit storage of input bits
- Parallel processing capability if needed for wider outputs
- Clear separation between storage and processing logic
