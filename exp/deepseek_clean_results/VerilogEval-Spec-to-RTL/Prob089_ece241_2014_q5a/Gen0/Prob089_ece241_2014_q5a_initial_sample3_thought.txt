To implement a serial 2's complementer Moore state machine, we need to:
1. Track whether we've seen the first '1' in the input stream (since 2's complement involves copying bits until the first '1' is seen, then inverting subsequent bits)
2. Use two states: STATE_COPY (before seeing first '1') and STATE_INVERT (after seeing first '1')
3. Reset asynchronously to STATE_COPY when areset is high
4. On each clock cycle, process the input bit x according to current state and update the state if needed
5. Output z is determined by current state and input x
