To implement a serial 2's complementer Moore state machine, we need to:
1. Track whether we've seen the first '1' in the input stream (since 2's complement involves copying bits until the first '1' is seen, then inverting the remaining bits)
2. Use two states: STATE_COPY (before seeing first '1') and STATE_INVERT (after seeing first '1')
3. Transition between states based on input 'x' and current state
4. Output 'z' is either a copy of 'x' (in STATE_COPY) or inverted 'x' (in STATE_INVERT)
5. Reset should initialize the state machine to STATE_COPY
