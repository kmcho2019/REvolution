To implement a serial 2's complementer Moore state machine, we need to:
1. Track whether we've seen the first '1' in the input stream (state transition)
2. After seeing the first '1', complement all subsequent bits
3. Maintain two states: STATE_SEARCH (looking for first 1) and STATE_COMPLEMENT (complementing remaining bits)
4. Reset asynchronously to STATE_SEARCH when areset is high
5. Output depends only on current state and input (Moore machine)
