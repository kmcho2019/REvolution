To implement a serial 2's complementer Moore state machine, we need to:
1. Track whether we've seen the first '1' in the input stream (starting from LSB)
2. Before seeing the first '1', output the same bits as input
3. After seeing the first '1', invert all subsequent bits
4. Use two states: STATE_PASS (before first 1) and STATE_INVERT (after first 1)
5. Reset should initialize the state to STATE_PASS
6. Output z depends only on current state and input x
