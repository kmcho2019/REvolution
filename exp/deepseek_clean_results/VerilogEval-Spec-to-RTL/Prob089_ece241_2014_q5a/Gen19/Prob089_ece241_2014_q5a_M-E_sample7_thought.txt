Novel shift register approach:
1. Instead of a state machine, use a shift register to track the position of the first '1'
2. The shift register fills with '0's until the first '1' is detected
3. After first '1', all subsequent bits are inverted
4. Early termination: stops processing when reset is asserted
5. Uses parallel logic for faster operation (single cycle delay)
6. Eliminates explicit state transitions by using the shift register content as implicit state
7. Output is generated combinationally from the shift register and input

Key advantages:
- No explicit state machine reduces control logic
- Shift register provides natural pipeline for high-speed operation
- Early termination saves power by stopping processing immediately on reset
- Parallel implementation may offer better timing in some technologies
