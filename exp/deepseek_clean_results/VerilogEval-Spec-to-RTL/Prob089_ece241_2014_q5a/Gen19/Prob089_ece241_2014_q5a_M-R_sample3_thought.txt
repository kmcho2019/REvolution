Refactored Design Strategy:

1. State Encoding: Maintain the same two states (PASS/INVERT) but represent them as explicit parameters
2. Output Logic: Use continuous assignment (assign) for the output to separate combinational logic from sequential
3. State Transitions: Keep the state transitions in a single always block for clarity
4. Reset Handling: Preserve asynchronous reset functionality
5. Moore Machine: Maintain pure Moore behavior where output depends only on state

Key Changes:
- Separated combinational output logic from sequential state logic
- Used continuous assignment for output (z) to potentially reduce logic levels
- Kept state transitions in a single always block for clarity
- Maintained same state encoding and transition logic
- Preserved all original functionality while changing implementation style

Benefits:
- Clear separation of combinational and sequential logic
- Potential timing improvement by making output path purely combinational
- Same minimal state encoding (1 bit) for smallest area
- Maintains all original functionality and performance characteristics
