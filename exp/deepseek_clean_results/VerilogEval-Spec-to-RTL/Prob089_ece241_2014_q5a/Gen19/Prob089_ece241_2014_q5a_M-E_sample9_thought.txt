Novel Approach: Bitwise Processing with Early Termination
1. Instead of a traditional state machine, use a counter to track when we've seen the first '1'
2. Maintain a 'seen_one' flag that triggers inversion of subsequent bits
3. Output logic becomes purely combinational based on current input and flag state
4. Reset clears both counter and flag
5. Advantages:
   - Eliminates explicit state transitions
   - Reduces sequential logic to just one register (seen_one)
   - Allows potential early termination optimization in future extensions
   - Simpler timing path with direct combinational output
