Refactored design approach:
1. Separate combinational and sequential logic for clearer structure
2. Use continuous assignment for output (z) to make it purely combinational
3. Maintain state transitions in sequential block
4. Keep minimal state encoding (1-bit)
5. Use non-blocking assignments for state transitions
6. Preserve asynchronous reset functionality

Key changes:
- Output z is now combinational logic based on current state and input
- State transitions remain synchronous with clock
- Clear separation between next-state logic and output logic
- Functionally equivalent but with improved modularity
