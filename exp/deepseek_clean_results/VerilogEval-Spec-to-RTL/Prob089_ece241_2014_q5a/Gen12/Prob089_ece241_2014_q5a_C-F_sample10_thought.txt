Optimized Fusion Strategy:
1. State Representation: Use single-bit state (area efficient) with descriptive names (readability)
2. Output Logic: Direct assignment (power efficient) with clear conditional behavior
3. Reset Handling: Asynchronous reset for both state and output (robust)
4. State Transitions: Minimal logic - transition only on first '1' (power efficient)
5. Code Structure: Single always block (timing optimized) with default case (synthesis safe)

Key Advantages:
- Combines the minimalism of Example 1 with the clarity of Example 2
- Output logic directly reflects the mathematical operation (clear intent)
- State names document the design intent (maintainable)
- No redundant operations (power efficient)
- Fully synchronous design except for reset (timing predictable)
