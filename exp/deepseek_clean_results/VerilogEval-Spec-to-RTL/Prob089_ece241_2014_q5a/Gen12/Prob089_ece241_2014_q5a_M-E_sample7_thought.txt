Novel Architecture Idea:
1. Instead of using traditional state machines, implement a shift register to track the position of the first '1' in the input stream
2. Use a flag to indicate when we've seen the first '1' and should start inverting bits
3. The shift register acts as a delay line, allowing us to precisely know when to start inverting bits
4. This approach eliminates explicit state transitions and instead uses the shift register content to control inversion
5. Benefits include:
   - More predictable timing due to shift register structure
   - Easier to pipeline if needed
   - Clear separation of data path and control logic
   - Potential for higher clock frequencies due to reduced combinatorial logic
6. Maintains all required functionality including proper reset behavior
