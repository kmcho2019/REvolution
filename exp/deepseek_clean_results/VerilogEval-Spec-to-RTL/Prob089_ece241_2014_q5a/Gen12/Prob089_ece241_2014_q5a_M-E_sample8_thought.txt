Innovative approach using a shift register and inversion flag:
1. Use a shift register to store the input bits until the first '1' is encountered
2. Maintain an 'invert' flag that gets set when the first '1' is seen
3. Output logic combines the current input with the invert flag
4. Reset clears both the shift register and the invert flag
5. The shift register length is parameterized for flexibility (set to 1 for minimal area)

Key advantages:
- No explicit state machine states, reducing control logic
- Shift register captures history naturally
- Parameterized design allows for area/speed tradeoffs
- Simple output logic (just XOR with invert flag)
- Asynchronous reset maintains clean initialization
