Alternative approach using a shift register:
1. Instead of a state machine, use a shift register to store the input bits
2. Track the position of the first '1' encountered
3. Once the first '1' is found, start inverting subsequent inputs
4. Use a counter to track when we've seen the first '1'
5. The shift register allows us to process the bits in parallel while maintaining serial output
6. Reset clears the shift register and counter
