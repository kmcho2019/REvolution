Here's a simplified approach for a serial 2's complement Moore machine:
1. Use just two states: SEARCH (looking for first '1') and FLIP (flipping all subsequent bits)
2. The state transitions occur immediately when the first '1' is detected
3. Output logic is purely combinatorial based on current state and input
4. No need for shift registers or counters - process each bit as it comes
5. Reset returns the machine to SEARCH state
6. Output is:
   - Same as input in SEARCH state (until first '1')
   - Inverted input in FLIP state (after first '1')
