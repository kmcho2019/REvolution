To correctly implement the 2's complementer Moore machine:
1. We need two states: PASS (initial state) and INVERT
2. In PASS state, we output the input bit unchanged until we see the first '1'
3. When we see the first '1' in PASS state, we output it unchanged and transition to INVERT state
4. In INVERT state, we invert all subsequent input bits
5. The reset should immediately return us to PASS state
6. The output should be registered to ensure clean timing
7. Key insight: The first '1' should pass through, then all following bits are inverted
