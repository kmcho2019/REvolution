New Architecture Idea:
1. Instead of a traditional state machine, use a shift register to store the first '1' position
2. Maintain a 'complement_flag' that gets set when the first '1' is detected
3. Output logic:
   - Before first '1': pass through input (z = x)
   - After first '1': complement input (z = ~x)
4. Reset behavior:
   - Clear shift register and flag on reset
   - Begin conversion when reset is released
5. Advantages:
   - Eliminates explicit state transitions
   - Uses sequential logic for flag propagation
   - Potentially simpler timing path
