Instead of using a traditional state machine, we can implement a shift register that:
1. Records all input bits until the first '1' is encountered
2. Once the first '1' is found, we enter "invert mode"
3. In invert mode, we both:
   - Output the stored bits (from before first '1) unchanged
   - Invert all new incoming bits
4. The shift register length is parameterized to handle practical bit lengths
5. This approach eliminates explicit state transitions and instead uses the shift register content to determine behavior
