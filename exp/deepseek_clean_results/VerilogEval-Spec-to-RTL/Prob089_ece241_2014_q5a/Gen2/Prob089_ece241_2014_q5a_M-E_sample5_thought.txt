Instead of using a traditional state machine, we can implement the 2's complement using:
1. A shift register to store the input bits until the first '1' is encountered
2. A flag to track whether we've seen the first '1'
3. When the flag is set, we start outputting the inverted bits while also outputting the stored bits from the shift register
4. This approach minimizes state transitions and allows for parallel processing of the stored bits
