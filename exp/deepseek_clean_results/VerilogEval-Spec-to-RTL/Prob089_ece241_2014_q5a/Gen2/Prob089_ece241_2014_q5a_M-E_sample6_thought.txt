Instead of using a traditional state machine, we can:
1. Use a flag register to track when we've seen the first '1'
2. Store this flag and use it to conditionally invert subsequent bits
3. Implement the flag as a simple DFF that gets set upon seeing the first '1'
4. The output is either a direct copy of input (before flag is set) or inverted input (after flag is set)
5. Reset clears the flag and starts fresh
This approach eliminates explicit state transitions and uses combinatorial logic based on the flag status.
