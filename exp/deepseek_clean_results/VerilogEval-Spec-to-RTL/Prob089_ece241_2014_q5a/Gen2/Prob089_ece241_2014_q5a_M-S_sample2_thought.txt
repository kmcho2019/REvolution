To simplify the 2's complementer Moore machine:
1. Recognize that we only need to track whether we've seen the first '1' or not
2. Use a single flip-flop (state bit) to represent this condition
3. Output is simply the input XOR the state bit (pass when state=0, invert when state=1)
4. State transitions:
   - Reset puts us in pass-through mode (state=0)
   - Stay in pass-through until we see first '1', then switch to invert mode (state=1)
   - Once in invert mode, stay there until next reset
5. This achieves the same functionality with minimal logic
