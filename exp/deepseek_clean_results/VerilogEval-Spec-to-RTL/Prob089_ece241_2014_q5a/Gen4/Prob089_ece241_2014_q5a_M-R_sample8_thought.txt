Refactored approach using continuous assignments and combinational logic:

1. State Representation:
   - Represent the state as a single bit (0 for PASS, 1 for INVERT)
   - Use combinational logic for state transitions and output

2. Key Changes:
   - Separate combinational next-state logic from sequential state storage
   - Use continuous assignments for output (z)
   - Maintain same state behavior but with clearer separation of concerns

3. Benefits:
   - More explicit separation of combinational and sequential logic
   - Easier to modify state transition logic independently
   - Output is purely combinational function of state and input
   - Maintains identical functionality to original

4. Reset Behavior:
   - Asynchronous reset still clears state to PASS
   - Output follows current state immediately after reset
