Instead of using a state machine, we can implement the 2's complement using a shift register that remembers whether we've seen the first '1':
1. Use a single flip-flop 'seen_one' to track if we've encountered the first '1'
2. When 'seen_one' is 0, output x directly and set 'seen_one' when x is 1
3. When 'seen_one' is 1, output ~x
4. Reset clears 'seen_one' and initializes the output
This approach eliminates explicit state transitions and reduces the logic to a single control bit.
