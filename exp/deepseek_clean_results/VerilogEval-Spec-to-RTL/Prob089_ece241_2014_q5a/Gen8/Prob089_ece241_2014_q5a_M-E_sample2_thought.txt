Instead of using a traditional state machine, we can implement the 2's complement using:
1. A shift register to remember if we've seen the first '1'
2. A flag that gets set when the first '1' is detected
3. The output is then determined by XORing the input with this flag
4. The flag propagates through the shift register to maintain the inversion state
This approach eliminates explicit state transitions and uses parallel logic for potentially better timing.
