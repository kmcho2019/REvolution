Novel architectural idea:
1. Instead of a traditional state machine, use a shift register to store the input bits
2. Implement a flag to track when the first '1' is encountered
3. Use combinational logic to determine the output based on the flag
4. The shift register provides potential for pipelining if needed later
5. Asynchronous reset clears all registers and flags

Key advantages:
- Eliminates explicit state machine logic
- Shift register allows potential for parallel processing
- Simple flag-based control reduces complexity
- Output logic is purely combinational
- Easily extensible to wider parallel implementations
