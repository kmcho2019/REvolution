Here's a novel approach using a shift register and flag-based control:
1. Use a flag to track when we've seen the first '1' (flip_flag)
2. Store the input bits in a shift register to allow processing in reverse order
3. When flip_flag is set, invert all subsequent bits
4. Output the processed bits in the original order
5. Reset clears the flip_flag and shift register
6. This approach maintains the serial nature while using minimal state
