New Architectural Idea:
1. Instead of a traditional state machine, use a shift register to store the complement flag
2. The flag propagates through the shift register when a '1' is detected
3. Each bit position in the shift register determines whether to complement the current input
4. This creates a "wave" of complement operations that follows the first '1' detection
5. Advantages:
   - Eliminates explicit state transitions
   - Naturally handles arbitrary input lengths
   - Simple implementation with just a register and XOR gates
   - Asynchronous reset clears the complement flag
