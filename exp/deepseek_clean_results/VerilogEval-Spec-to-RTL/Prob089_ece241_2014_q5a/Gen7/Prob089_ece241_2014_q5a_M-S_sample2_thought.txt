The original solution is already quite minimal, but we can simplify it further by:

1. Eliminating the explicit state parameter definitions since we only need two states (0 and 1)
2. Removing the default case since we only have two states
3. Combining the output assignment with the state transition logic
4. Maintaining the same fundamental behavior:
   - Pass through bits until first '1' is seen
   - Invert all subsequent bits (including the first '1')
   - Reset to initial state when areset is high

This reduces the code while preserving all functionality and timing characteristics.
