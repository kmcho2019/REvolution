Instead of using a traditional state machine, this implementation:
1. Uses a shift register to remember if we've seen the first '1'
2. The shift register propagates a '1' from left to right when a '1' is detected
3. Output is determined by XORing input with the shift register value
4. Reset clears the shift register
5. This creates a "wave" of inversion that follows the first '1' in the stream
6. The shift register length is parameterized (set to 1 here) to balance area and timing
