Instead of tracking just the first '1', we can maintain a running XOR operation that flips all bits after the first '1':
1. Use a 'flip' register that gets set when we see the first '1' and stays set
2. The output is simply x XOR flip
3. The flip register gets cleared on reset and toggles permanently when x is '1' while flip is '0'
This approach uses the mathematical property that 2's complement is equivalent to flipping all bits after the first '1', implemented as a serial XOR operation.
