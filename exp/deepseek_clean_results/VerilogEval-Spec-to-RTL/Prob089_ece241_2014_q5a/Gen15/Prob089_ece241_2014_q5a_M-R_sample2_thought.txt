Refactoring approach:
1. Separate combinational and sequential logic for better clarity and potential timing optimization
2. Use explicit state encoding with parameters for better readability
3. Move output logic to continuous assignment for potential timing benefits
4. Maintain same Moore machine behavior with output purely dependent on state
5. Keep the efficient 1-bit state representation but make it more explicit

- Split into two always blocks (state and output)
- Use named states instead of implicit 'invert' signal
- Continuous assignment for output
