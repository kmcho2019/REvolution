Novel approach using a shift register with inversion control:
1. Instead of tracking state, we'll use a shift register to remember when to start inverting bits
2. The key insight is that we can propagate the inversion signal through the shift register
3. When we see the first '1', we set the inversion flag which propagates through subsequent bits
4. This eliminates explicit state tracking and reduces control logic
5. The shift register approach naturally handles arbitrary-length inputs
6. Asynchronous reset clears the shift register and output
7. Output is simply the XOR of input with the inversion control signal
