Refactored design with these key changes:
1. Separated combinational and sequential logic for better modularity
2. Used continuous assignment for output (z) to potentially improve timing
3. Maintained same state machine behavior but with explicit state transitions
4. Kept asynchronous reset functionality
5. Used named states for better readability
6. Structured as a classic Moore FSM with separate next-state logic

Key benefits:
- Clear separation of combinational and sequential logic
- Output assignment is now purely combinational
- State transitions are more explicitly defined
- Maintains same PPA characteristics while being more maintainable
- Easier to modify if state machine needs to grow
