Novel architectural idea:
1. Instead of using a traditional state machine, implement a shift register to track the position of the first '1'
2. Use a flag to remember when we've seen the first '1' (MSB of the original number)
3. The shift register acts as a "wave" propagating through the bits, marking which bits should be inverted
4. This approach eliminates explicit state transitions and instead uses positional information
5. Benefits include:
   - More parallel computation (shift register updates all bits simultaneously)
   - Potential for better timing as critical path is simplified
   - Clear physical interpretation of the 2's complement operation
   - Easier to pipeline if needed for higher performance
