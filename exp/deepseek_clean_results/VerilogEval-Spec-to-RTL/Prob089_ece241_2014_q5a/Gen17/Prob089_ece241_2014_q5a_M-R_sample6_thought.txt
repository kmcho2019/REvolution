Refactored design approach:
1. Use continuous assignments (assign) for combinational logic where possible
2. Separate the state transition and output logic into distinct always blocks
3. Maintain the same two-state behavior but make it more explicit
4. Keep asynchronous reset functionality
5. Use non-blocking assignments for sequential elements

- State transition logic is separated into its own always block
- State representation remains minimal (single bit)
- Clear separation between sequential and combinational logic
