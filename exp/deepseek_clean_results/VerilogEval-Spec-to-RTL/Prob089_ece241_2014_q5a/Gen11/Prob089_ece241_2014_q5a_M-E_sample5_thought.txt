Instead of using explicit states, we can implement the 2's complementer using:
1. A flag register (invert_flag) that gets set when we encounter the first '1'
2. The output is simply the input XOR'd with the invert_flag
3. The flag remains set once it's triggered until reset
4. Asynchronous reset clears the flag and initializes the system
This approach eliminates explicit state transitions and reduces the logic to a simple XOR operation controlled by the flag.
