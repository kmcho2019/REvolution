Novel architectural idea:
1. Use a shift register to store input bits until first '1' is found
2. When first '1' is detected, freeze the shift register and start inverting subsequent bits
3. Output comes from either the shift register (before first '1') or inverted input (after first '1')
4. This approach minimizes state transitions and reduces power consumption
5. The shift register depth is parameterized to handle typical cases while preventing excessive area usage
6. Asynchronous reset clears the shift register and control logic
7. The design leverages parallel processing for better timing
