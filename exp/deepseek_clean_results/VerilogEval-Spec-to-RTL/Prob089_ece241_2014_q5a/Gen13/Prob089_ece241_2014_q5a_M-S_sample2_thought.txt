The key insight is that we can eliminate the separate 'seen' register by observing that the output 'z' itself can serve as the state indicator:
1. When z=0, we're in the initial state (haven't seen first 1)
2. When z=1, we're in the complement state (have seen first 1)
This merges the state tracking and output into a single register, reducing area while maintaining the same functionality. The state transitions remain:
- Stay in initial state (output=x) until first 1 is seen
- Then transition to complement state (output=~x) for all subsequent bits
