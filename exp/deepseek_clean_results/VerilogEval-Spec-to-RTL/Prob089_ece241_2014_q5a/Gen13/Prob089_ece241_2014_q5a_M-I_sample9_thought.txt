Improvement Strategy:
1. Combine state tracking and output into a single register to reduce area and power
2. Use a more efficient state encoding (implicit through output value)
3. Eliminate the separate 'seen' register by using the output register's value to track state
4. Maintain Moore machine properties by keeping output dependent only on current state
5. Simplify the logic to reduce critical path delay
6. Keep asynchronous reset for immediate initialization

Key Optimizations:
- Single register implementation (reduces area)
- Output directly represents state (reduces logic levels)
- State transitions determined by current output and input (simpler logic)
- No intermediate variables (cleaner timing path)
