Innovative approach using a shift register and flag:
1. Instead of traditional state machine, use a shift register to store the input bits
2. Maintain a flag to track when we've seen the first '1'
3. Output logic combines current input with the flag status
4. Asynchronous reset clears both the flag and shift register
5. Benefits:
   - No explicit state machine reduces control logic
   - Shift register enables potential pipelining
   - Flag-based control simplifies decision logic
   - Easily extensible for parallel processing
6. Trade-off: Uses slightly more area for shift register but offers better timing
