Refactoring approach:
1. Separate combinational and sequential logic for better modularity
2. Use continuous assignment for output (z) to simplify the always block
3. Keep the same state machine behavior but express it differently
4. Move output logic to a separate assign statement
5. Maintain the same efficient single-bit state representation

Key changes:
- Output z is now computed combinationally based on state
- State transitions are handled in a dedicated always block
- Clear separation between state transition logic and output generation
- Maintains same functionality and efficiency
