The solution can be simplified by:
1. Removing the explicit 'z' register since the output can be purely combinational
2. Maintaining only the essential 'invert' state register
3. The output becomes a simple XOR of input and current inversion state
4. Reset clears the inversion state
5. State transitions occur when we see the first '1' while not inverting
This reduces area by eliminating one register while maintaining the same functionality
