Innovative approach using a shift register and flag:
1. Instead of a traditional state machine, use a shift register to store the input bits
2. Track the position of the first '1' using a flag
3. Output logic becomes simple: copy bits before first '1', invert after
4. Benefits:
   - Eliminates explicit state transitions
   - Naturally handles arbitrary length inputs
   - More parallel processing capability
   - Easier to pipeline if needed
5. Tradeoffs:
   - Uses more registers than state machine approach
   - Slightly higher power due to shift register activity
   - But offers better timing for long bit sequences
