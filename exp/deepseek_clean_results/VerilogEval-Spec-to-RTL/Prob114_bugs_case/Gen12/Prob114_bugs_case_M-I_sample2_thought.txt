To optimize the design for better PPA (Power, Performance, Area), I'll implement these improvements:
1. First check validity with a single OR gate to reduce redundant comparisons
2. Use a case statement for output decoding which typically synthesizes more efficiently than ternary operators
3. Only decode the output when valid is true to save power
4. Group the case items to potentially enable better synthesis optimization
5. Default outputs to 0 to ensure clean synthesis

This approach should:
- Reduce area by sharing comparison logic
- Improve timing by simplifying the critical path
- Lower power by minimizing unnecessary switching
- Maintain the same functionality while being more synthesis-friendly
