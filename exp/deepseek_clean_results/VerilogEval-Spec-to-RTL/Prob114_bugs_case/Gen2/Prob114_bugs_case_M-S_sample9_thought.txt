The original solution uses a case statement with 10 explicit cases, which is straightforward but can be simplified. We can optimize by:
1. Using a single assignment for 'valid' based on whether the input matches any of the valid codes
2. Using a more compact encoding for the output mapping by recognizing the pattern in the scancodes
3. Combining these into simpler conditional expressions
