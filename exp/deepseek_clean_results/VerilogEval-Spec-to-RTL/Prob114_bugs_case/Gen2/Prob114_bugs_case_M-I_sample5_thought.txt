The current implementation is already quite efficient, but we can make some minor improvements:
1. Remove redundant begin/end blocks for single-statement cases to improve readability
2. Initialize outputs directly in the case statement to reduce logic levels
3. Use parallel case pragma to potentially help synthesis tools optimize better (though most modern tools handle this automatically)
4. Keep the default case simple by setting outputs to 0 at the start

These changes maintain the same functionality while making the code slightly more concise and potentially helping synthesis tools optimize further.
