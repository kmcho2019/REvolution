Here's a novel approach using a lookup table (LUT) implemented as a memory array. The key idea is:

1. Pre-store all valid scancodes and their corresponding outputs in a 256-entry memory (covering all 8-bit possibilities)
2. Initialize the memory such that:
   - Valid codes map to their respective digit values (0-9)
   - All other entries map to 0 (invalid)
3. Add a separate valid bit array that marks which codes are valid
4. The implementation becomes:
   - Direct lookup of output from code-indexed memory
   - Valid signal from code-indexed valid bit array

Advantages:
- Extremely simple sequential logic implementation
- Constant-time lookup regardless of number of valid codes
- Easy to modify/add new codes by just updating initialization
- Clean separation of data (output) and control (valid) paths
- Scales well if more codes need to be added later
