I'll refactor the solution to use continuous assignments (assign statements) instead of an always block. This approach has several advantages:

1. The logic becomes purely combinational without needing procedural blocks
2. The valid signal can be derived directly from the case matches
3. The structure becomes more declarative and potentially easier to read
4. Synthesis tools can optimize the parallel comparisons more effectively

The key changes will be:
- Replace the always block with assign statements
- Use a case expression for the output mapping
- Generate the valid signal by checking if any case matches
- This maintains the same functionality while potentially improving synthesis results
