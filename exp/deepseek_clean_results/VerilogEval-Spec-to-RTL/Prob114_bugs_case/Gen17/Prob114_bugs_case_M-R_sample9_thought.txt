To refactor this code while maintaining the same functionality, I'll use continuous assignments (assign statements) instead of an always block. This approach:

1. Eliminates the need for procedural blocks, making it purely combinational
2. Uses parallel ternary operators for each valid case
3. Combines the outputs using OR reduction of all valid cases
4. Benefits:
   - More concise representation
   - Clearer mapping between input patterns and outputs
   - Potentially better synthesis optimization as each output is directly defined
   - Maintains the same PPA characteristics since synthesis tools will optimize similarly
   - Easier to add new cases if needed
