Refactoring the 4-bit ripple-carry adder using continuous assignments instead of instantiated full adders:

1. **Structural Change**: Replace the hierarchical FullAdder instances with direct continuous assignments for sum and carry computations.
2. **Logic Optimization**: 
   - Compute each sum bit as XOR of inputs and carry-in
   - Compute each carry-out using the standard majority function
3. **Simplification**:
   - Eliminate intermediate module hierarchy (FullAdder)
   - Use direct wire assignments for all sum and carry bits
4. **Benefits**:
   - More compact representation
   - Same functionality but flatter hierarchy
   - Easier to modify for parameterized widths
5. **Maintained Features**:
   - Still ripple-carry structure
   - Same critical path characteristics
   - Identical PPA profile (same underlying logic)
