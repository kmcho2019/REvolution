The refactored solution maintains the same core functionality but implements it with a cleaner structure:

1. Use continuous assignments for outputs where possible to reduce sequential logic
2. Separate the pattern detection shift register from the main state machine
3. Use explicit state encoding for better readability
4. Implement the counter logic with clearer cycle counting
5. Use a separate always block for sequential elements
6. Make the 1000-cycle counting more precise by counting to 999

Key improvements:
- Pattern detection is now handled by a dedicated shift register
- State transitions are more clearly defined
- Counter logic is simplified and more accurate
- Output assignments are split between combinational and sequential logic
