Refactored Approach: Explicit State Machine with Clear Counting Logic

1. **State Machine Restructuring**:
   - Use explicit state encoding with meaningful names
   - Separate pattern detection, delay capture, counting, and done states clearly

2. **Cycle Counting Improvement**:
   - Use two counters: one for 1000-cycle chunks (chunk_counter) and one for tracking chunks (remaining_chunks)
   - Eliminate complex arithmetic by counting down chunks

3. **Pattern Detection**:
   - Maintain shift register for strict sequential pattern matching
   - Clear separation between pattern detection and delay capture phases

4. **Output Logic**:
   - Use continuous assignments for outputs where possible
   - Explicit count value calculation during counting phase

Key Changes:
- More readable state machine with explicit transitions
- Simplified counting logic using chunk-based approach
- Clear separation of pattern detection and timing phases
- Reduced arithmetic operations in critical paths
