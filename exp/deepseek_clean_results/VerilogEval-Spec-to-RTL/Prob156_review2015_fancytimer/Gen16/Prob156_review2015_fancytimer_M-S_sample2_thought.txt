The key simplifications are:

1. **Single Counter Approach**: Use a single counter for both pattern detection and timing, eliminating the need for multiple counters.

2. **Simplified State Machine**: Reduce to 3 states - IDLE (pattern detection), CAPTURE (get delay value), and COUNTING (active counting).

3. **Direct Cycle Calculation**: Instead of complex calculations, simply count down from (delay+1)*1000 and derive the count output from the remaining cycles.

4. **Clean Output Control**: Only update outputs when needed, keeping them stable during each state.

5. **Efficient Pattern Detection**: Use a 4-bit shift register for the 1101 pattern, clearing it after detection.

This maintains all required functionality while reducing complexity and potential error sources.
