1. **Parallel Pattern Matching**:
   - Instead of shifting bits, use combinatorial logic to detect the 1101 pattern in the last 4 received bits
   - This allows immediate detection without waiting for full shift register updates

2. **Two-Stage Timer**:
   - Implement a coarse counter for 1000-cycle intervals
   - Use a fine counter to count individual cycles within each interval
   - This reduces the size of the main counter while maintaining precision

3. **Dynamic Count Calculation**:
   - Calculate remaining time on-the-fly using the current counter values
   - Eliminates the need to store initial delay separately

4. **State Machine Optimization**:
   - Combine pattern detection and delay capture into a single state
   - Use a bit counter to track progress through both phases

5. **Output Generation**:
   - Generate count output combinatorially based on current state
   - Use registered outputs for done and counting to ensure clean transitions
