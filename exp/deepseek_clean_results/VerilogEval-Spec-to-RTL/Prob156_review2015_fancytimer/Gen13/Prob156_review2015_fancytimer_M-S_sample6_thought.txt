Simplified Approach: Single State Machine with Combined Counters

1. **Single FSM**:
   - Eliminate hierarchical states by using a single state machine with clear transitions
   - States: IDLE (pattern detection), CAPTURE (get delay), COUNT (timing), DONE (notification)

2. **Simplified Counting**:
   - Use a single 14-bit counter (enough for 15*1000=15000 cycles)
   - Derive count[3:0] directly from counter value (count = counter[13:10])
   - Eliminate separate main/sub counters

3. **Efficient Pattern Matching**:
   - Maintain 4-bit shift register for pattern detection
   - Transition to CAPTURE immediately when 1101 is detected

4. **Output Logic**:
   - counting asserted during COUNT state
   - done asserted during DONE state
   - count output valid only during COUNT state

Key Simplifications:
- Eliminates sub-FSM and separate counters
- Reduces register usage
- Simplifies state transitions
- Maintains exact cycle counting requirement
