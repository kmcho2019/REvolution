Refactored Design Approach:
1. **State Machine Restructuring**:
   - Use explicit state transitions with clear conditions
   - Separate pattern detection and delay capture into distinct phases
   - Add bit counter for precise 4-bit delay capture

2. **Timer Logic Improvement**:
   - Maintain delay value separately from countdown
   - Calculate remaining time as (delay - elapsed_seconds)
   - Use modular arithmetic for cycle counting

3. **Output Generation**:
   - Make count output purely combinational
   - Use continuous assignments for non-sequential outputs where possible
   - Clear done signal synchronously with ack

4. **Code Organization**:
   - Separate sequential and combinational logic blocks
   - Use parameters for state encoding
   - Explicit reset handling for all registers
