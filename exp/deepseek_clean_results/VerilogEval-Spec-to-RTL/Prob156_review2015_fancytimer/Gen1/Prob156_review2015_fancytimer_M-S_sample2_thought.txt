The key simplifications are:
1. Combine pattern detection and delay reading into a single shift register process
2. Use a single counter for both bit counting and timing cycles
3. Simplify state machine by removing intermediate states
4. Make count output directly reflect the current delay value during counting

Main changes:
- Single 8-bit shift register handles both pattern (first 4 bits) and delay (next 4 bits)
- Single counter handles both bit counting (0-7) and timing cycles (0-999)
- Simplified state machine with just 3 states: IDLE, COUNTING, DONE
- Direct delay value calculation for count output
