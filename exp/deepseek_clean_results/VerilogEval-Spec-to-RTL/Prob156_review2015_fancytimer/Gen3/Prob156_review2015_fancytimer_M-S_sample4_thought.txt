Here's a simplified approach that maintains all functionality while reducing complexity:

1. **Single Shift Register**: Use one 4-bit shift register for both pattern detection and delay capture, reusing it after pattern match.

2. **Simplified State Machine**: Reduce to 4 clear states (IDLE, CAPTURE, COUNT, DONE) with straightforward transitions.

3. **Combined Counter Logic**: Use a single 14-bit counter (enough for max 16*1000 cycles) with comparison logic instead of separate counters.

4. **Direct Output Control**: Drive outputs directly from state machine without additional registers where possible.

Key simplifications:
- Eliminate separate pattern and delay shift registers
- Remove intermediate bit counter by using shift register fill state
- Simplify counter logic with single counter and comparison
- Reduce state machine complexity with minimal states
