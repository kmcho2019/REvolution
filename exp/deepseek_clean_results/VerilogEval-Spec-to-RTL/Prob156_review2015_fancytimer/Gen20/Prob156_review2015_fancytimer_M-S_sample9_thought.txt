Here's a simplified approach that maintains functionality while reducing complexity:

1. **Single Shift Register**: Use a single 4-bit shift register for both pattern detection and delay value capture, eliminating separate registers.

2. **Combined Counting**: Use a single 14-bit counter (since max count is 16*1000=16000) instead of separate micro/macro counters. This simplifies the counting logic.

3. **Direct State Transitions**: Remove intermediate states and combine logic where possible. Only 4 states are needed: IDLE, CAPTURE, COUNTING, DONE.

4. **Simplified Output Logic**: Generate outputs directly from the state machine without additional registers where possible.

5. **Synchronous Reset Handling**: Clear all registers on reset in one place.

The key simplification is using a single counter and eliminating parallel structures while maintaining the same functionality.
