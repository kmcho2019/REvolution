Here's a simplified approach that maintains all required functionality:

1. **Single Shift Register**: Use a single 4-bit shift register to detect the 1101 pattern and capture the delay value sequentially.

2. **Simplified State Machine**: Reduce to just 4 states (IDLE, CAPTURE, COUNTING, DONE) with clear transitions.

3. **Combined Counter**: Use a single 14-bit counter (enough for max 16*1000 cycles) with comparison logic instead of separate micro/macro counters.

4. **Direct Output Logic**: Generate outputs directly from state and counter values without additional registers.

Key simplifications:
- Eliminated parallel pattern matching in favor of simple serial detection
- Removed separate micro/macro counters in favor of single counter
- Simplified state machine with fewer registers
- Direct output generation reduces sequential logic
