Simplified Design Approach:
1. Use a 4-state FSM: IDLE (pattern detection), SHIFT (get delay), COUNT (timer), DONE (wait for ack)
2. Pattern detection: 4-bit shift register for 1101 sequence
3. Delay capture: Fixed 4-bit shift after pattern detection
4. Counting: Main counter counts (delay+1)*1000 cycles, with count output tracking remaining blocks
5. Clear state transitions and output logic

Key Simplifications:
- Single counter for entire timing period
- Direct state-based output assignments
- Simplified delay capture using bit counter
- Clear reset conditions
- Removed redundant sub-counters
