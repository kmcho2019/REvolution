Novel Approach: Parallel Pattern Matching with Precise Cycle Counting

1. **Parallel Pattern Detection**:
   - Instead of shift register, use combinatorial logic to detect 1101 pattern in any 4-cycle window
   - More robust detection that doesn't require exact alignment

2. **Two-Phase Counter System**:
   - Primary counter counts 1000-cycle chunks
   - Secondary counter tracks current chunk (0-999)
   - Eliminates need for separate sub-counter logic

3. **Dynamic Delay Calculation**:
   - Calculate (delay+1)*1000 on-the-fly when delay is captured
   - Store total cycles needed rather than raw delay value

4. **State Machine Simplification**:
   - Combine capture and counting states for efficiency
   - Explicit cycle counting with clear termination condition

Key Innovations:
- More reliable pattern detection
- Precise cycle counting through pre-calculation
- Simplified state transitions
- Clear separation between pattern detection and timing logic
