Novel approach using a two-phase counter system:
1. Pattern detection uses a shift register with parallel comparison
2. Implement a bit counter to track exactly 4 delay bits after pattern match
3. Use a main counter that counts down from (delay+1)*1000-1 to 0
4. Derive count output directly from the main counter value (count/1000)
5. Simplify FSM with only 4 states but precise timing control
6. Use mathematical relationship to avoid separate chunk counters

Key innovations:
- Single main counter handles both cycle counting and chunk tracking
- Bit counter ensures exact 4-bit capture after pattern match
- Count output derived mathematically from remaining cycles
- Eliminates need for separate cycle and chunk counters
