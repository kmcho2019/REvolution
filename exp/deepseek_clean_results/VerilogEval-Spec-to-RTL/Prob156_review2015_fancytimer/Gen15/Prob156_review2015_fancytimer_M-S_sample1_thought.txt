Simplified design approach:
1. Use a 3-state FSM (IDLE, CAPTURE, COUNTING) - DONE state can be merged into IDLE with a done flag
2. Track pattern detection with a shift register and exact match check
3. Capture delay bits using a simple 4-bit shift with bit counter
4. Implement counting as:
   - Outer loop: delay+1 chunks (count down from delay to 0)
   - Inner loop: fixed 1000 cycles per chunk
5. Output count value only during COUNTING state
6. Use ack to directly reset to IDLE state

Key simplifications:
- Eliminate separate DONE state by using done flag
- Remove delay_reg since delay_shift can be reused
- Simplify cycle counting with direct comparison
- Reduce state machine complexity
