Refactored Design Approach:
1. **Simplified State Machine**: Use binary encoding instead of one-hot to reduce complexity. Combine pattern detection and capture states for more efficient transitions.

2. **Separate Pattern Matching Logic**: Implement pattern detection using a continuous assignment for cleaner code.

3. **Counter Optimization**:
   - Use a single 16-bit counter instead of hierarchical counters
   - Pre-calculate (delay+1)*1000 using left shifts (since 1000 = 8 + 64 + 128 + 256 + 512)
   - Maintain count output through combinational logic

4. **Output Generation**:
   - Use assign statements for outputs where possible
   - Register only necessary signals for timing

5. **Reset Handling**: Explicit reset conditions for all registers
