Here's a simplified approach that maintains all required functionality while reducing complexity:

1. **Pattern Detection**: Use a simple shift register to detect the 1101 pattern. When detected, transition to delay capture state.

2. **Delay Capture**: Shift in next 4 bits to form the delay value. No need for separate GOT_PATTERN state - can combine with delay capture.

3. **Counting Logic**: 
   - Use a single counter for both the 1000-cycle chunks and overall count
   - Track remaining chunks (delay value) separately
   - Decrement remaining chunks every 1000 cycles

4. **Output Control**:
   - count output shows remaining chunks during counting
   - done asserts when counting completes
   - waits for ack before resetting

5. **Simplifications**:
   - Remove intermediate states where possible
   - Combine related counters
   - Eliminate redundant registers
   - Use simpler comparison logic

The key insight is that we can track the counting progress by monitoring both the 1000-cycle periods and the remaining periods, rather than counting every single cycle.
