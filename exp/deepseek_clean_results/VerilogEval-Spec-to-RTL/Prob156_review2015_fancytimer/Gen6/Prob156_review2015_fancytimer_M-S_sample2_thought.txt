The key simplifications are:

1. Combine pattern detection and delay capture into a single shift register process
2. Use a single counter for both the 1000-cycle periods and total duration
3. Simplify state machine to only 3 states: IDLE, COUNTING, DONE
4. Calculate total cycles as (delay + 1)*1000 upfront
5. Output count directly from a downcounter during COUNTING state

The simplified design will:
- Detect 1101 pattern and capture next 4 bits in same shift register
- Calculate total cycles immediately after delay capture
- Use a single counter that counts down total cycles
- Output remaining periods by dividing counter value by 1000
- Maintain correct output signals with simpler logic
