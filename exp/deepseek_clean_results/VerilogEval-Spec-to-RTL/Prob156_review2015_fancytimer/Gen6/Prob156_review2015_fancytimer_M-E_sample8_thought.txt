New Architecture Idea:
1. **Dual-Stage Pattern Detection**: Use two shift registers - one for pattern detection (1101) and another for delay value capture. This separates the concerns cleanly.

2. **Hierarchical Counting**:
   - Main counter (16-bit) for total cycles
   - Sub-counter (10-bit) for 1000-cycle chunks
   - This eliminates the need for multiplication by pre-calculating the total cycles

3. **Smart State Encoding**:
   - Use one-hot encoding for states to simplify transitions
   - Add explicit WAIT_ACK state for clean handshaking

4. **Early Calculation**:
   - Compute (delay+1)*1000 immediately when delay is captured
   - Use this to initialize both counters

5. **Output Management**:
   - Maintain count output only during counting phase
   - Use registered outputs for clean timing
