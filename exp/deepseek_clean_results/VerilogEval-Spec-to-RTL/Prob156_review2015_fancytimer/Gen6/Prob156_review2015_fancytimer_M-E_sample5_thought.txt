Here's a novel approach using a parallel pattern detection scheme and a down-counter with prescaler:

1. **Parallel Pattern Matching**: Instead of shifting bits serially, we'll use a parallel comparator to detect the 1101 pattern instantly when it appears in the last 4 bits.

2. **Dual-Purpose Shift Register**: A single 8-bit shift register serves both for pattern detection and delay value capture, reducing hardware.

3. **Prescaled Down Counter**: Implement the timer using a down-counter with a prescaler to handle the 1000-cycle increments efficiently.

4. **Smart State Encoding**: Use one-hot encoding for the state machine to simplify transitions and reduce glitches.

5. **Early Pattern Reset**: Immediately reset pattern detection after capturing delay to prevent false triggers during counting.

Key innovations:
- Instant pattern detection without sequential shifting
- Shared shift register reduces area
- Prescaler makes cycle counting more efficient
- One-hot FSM for cleaner implementation
