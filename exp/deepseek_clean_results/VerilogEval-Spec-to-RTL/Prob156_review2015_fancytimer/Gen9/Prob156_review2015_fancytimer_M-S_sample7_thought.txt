Here's a simplified and corrected approach:

1. **Pattern Detection**: Use a 4-bit shift register to detect "1101". Only check for pattern when all 4 bits are filled.

2. **Delay Capture**: After pattern detection, shift in next 4 bits to form delay value. Use a 2-bit counter to track bits received.

3. **Counting Logic**:
   - Use a single counter for both timing and count output
   - Count down from (delay+1)*1000 to 0
   - Derive count output directly from counter value (count = (counter-1)/1000)

4. **State Machine**: Simplified to 4 states:
   - IDLE: Pattern detection
   - CAPTURE: Collecting delay bits
   - COUNT: Active counting
   - DONE: Waiting for ack

- Proper pattern detection timing
- Correct delay value accumulation
- Simplified counter logic
