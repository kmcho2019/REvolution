Here's a novel approach using a parallel pattern detector and a down-counter with preload capability:

1. Instead of shifting bits serially for pattern detection, use a parallel comparator that checks the last 4 bits against "1101" every cycle. This eliminates the need for a separate shift register.

2. Implement the timer as a down-counter that loads (delay+1)*1000-1 at start, then counts down to zero. This ensures exact cycle counting without separate period tracking.

3. Use a bit counter only during the delay capture phase, making the design more modular.

4. The counting output is simply the counter's active state, and done is asserted when counter reaches zero.

5. This approach reduces state machine complexity by handling counting with a single counter and using simple comparators for pattern matching.
