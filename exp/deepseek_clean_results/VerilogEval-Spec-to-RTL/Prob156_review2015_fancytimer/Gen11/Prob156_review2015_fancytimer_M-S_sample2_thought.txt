Here's a simplified solution that maintains all functionality while reducing complexity:

1. **Single Shift Register**: Use one 4-bit register for both pattern detection and delay value capture, reusing the same hardware.

2. **Simplified State Machine**: Reduce to 4 clear states (IDLE, CAPTURE, COUNT, DONE) with straightforward transitions.

3. **Efficient Counting**: 
   - Use a single 14-bit counter (0-15999) for timing, eliminating the need for separate sub-counters
   - Calculate target cycles as (delay+1)*1000 upfront

4. **Direct Outputs**: Drive outputs directly from state and counter values.

Key simplifications:
- Eliminated separate pattern and delay registers
- Removed intermediate bit counter
- Simplified counting logic with single counter
- Reduced state machine complexity
