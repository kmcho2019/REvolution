1. **Simplified State Machine**:
   - Reduce to 4 clear states: IDLE (wait for pattern), CAPTURE (get delay), COUNT (active counting), DONE (wait for ack)
   - Eliminate parallel pattern detection in favor of simple shift register matching

2. **Streamlined Counting**:
   - Use a single 14-bit counter (enough for max 16*1000 cycles)
   - Pre-calculate total cycles as (delay + 1)*1000 at capture time
   - Count down this value directly, eliminating separate coarse/fine counters

3. **Cleaner Output Logic**:
   - Generate count output by dividing remaining cycles by 1000
   - Done signal asserts when counter reaches 0
   - Clear done only on ack, return to IDLE immediately

4. **Reduced Registers**:
   - Remove unnecessary intermediate registers
   - Use minimal state encoding
