Refactored Approach: Explicit State Machine with Combinational Logic

1. **State Machine Restructuring**:
   - Convert to explicit 3-state machine (IDLE, LOAD, COUNT) with clear transitions
   - Remove intermediate DETECTED and FINISH states by combining logic

2. **Combinational Outputs**:
   - Move counting and done signals to continuous assignments
   - Makes output timing more predictable

3. **Simplified Counters**:
   - Single 14-bit counter (max 15*1000=15000 cycles)
   - Derive delay_counter from main counter value

4. **Pattern Detection**:
   - Keep shift register but add explicit pattern match signal
   - Clearer detection logic

5. **Timing Control**:
   - Calculate remaining time mathematically from counter
   - More precise cycle counting

Key Improvements:
- Fewer states for simpler transitions
- Combinational outputs for better timing
- Single counter for more accurate timing
- Clearer pattern detection logic
