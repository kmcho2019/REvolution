Novel approach using parallel pattern matching and precise cycle counting:

1. Parallel pattern detection:
   - Instead of shifting bits serially, use a 4-bit register that compares against "1101" in parallel
   - This eliminates the need for bit-by-bit shifting and makes detection immediate

2. Two-phase counting:
   - First phase: Capture delay value using a simple 4-bit shift register
   - Second phase: Use a down-counter for the delay value and a separate counter for the 1000-cycle chunks
   - The down-counter starts at delay_val and decrements every 1000 cycles

3. Cycle counting optimization:
   - Use a 10-bit counter (0-999) for the 1000-cycle chunks
   - When this counter wraps, decrement the delay counter
   - Total cycles = (delay_val + 1) * 1000 is implicitly handled by this approach

4. State machine simplification:
   - Only 3 states needed: IDLE, COUNTING, DONE
   - Pattern detection happens combinatorially in IDLE state
   - Transition to COUNTING immediately after pattern match and delay capture
   - Clear state machine after ack in DONE state

This approach reduces complexity by:
- Eliminating serial pattern matching overhead
- Using natural counter wraparound for timing
- Minimizing state transitions
