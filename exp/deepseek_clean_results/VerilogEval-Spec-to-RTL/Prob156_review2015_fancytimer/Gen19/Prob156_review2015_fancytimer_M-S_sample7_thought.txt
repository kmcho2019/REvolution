Simplified Design Strategy:

1. **Pattern Detection**:
   - Use a 4-bit shift register to detect "1101" pattern
   - Only shift when actively searching for pattern

2. **Delay Capture**:
   - After pattern match, capture next 4 bits as delay value
   - Store these bits directly without shifting

3. **Counting Logic**:
   - Use a single counter for both 1000-cycle and delay tracking
   - Count from (delay+1)*1000 down to 0
   - Output current delay value (count/1000) during counting

4. **State Machine**:
   - Simplified to 4 states: IDLE, PATTERN, CAPTURE, COUNT
   - Combine done notification and ack wait into COUNT state

Key Simplifications:
- Single counter instead of two
- Fewer states
- Direct delay value usage
- Clear state transitions
