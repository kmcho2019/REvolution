To implement this timer module, we need a finite state machine (FSM) with the following states:
1. IDLE: Waiting for the start pattern (1101)
2. SHIFT_DELAY: After detecting 1101, shift in 4-bit delay value
3. COUNTING: Counting down (delay+1)*1000 cycles
4. DONE: Assert done and wait for ack

We'll use:
- A shift register to detect the 1101 pattern
- Another shift register to capture the 4-bit delay
- A large counter for the (delay+1)*1000 cycles
- A down counter to track remaining time (count output)
- State registers for the FSM

The counting logic will:
- Load the delay value when entering COUNTING state
- Decrement count every 1000 cycles
- Transition to DONE when count reaches 0
