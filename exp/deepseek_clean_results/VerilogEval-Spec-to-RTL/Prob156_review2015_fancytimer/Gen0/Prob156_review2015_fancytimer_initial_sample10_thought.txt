To implement this timer module, we need a finite state machine (FSM) with the following states:
1. IDLE: Waiting for the 1101 pattern
2. SHIFT_DELAY: After detecting 1101, shift in 4-bit delay value
3. COUNTING: Counting down the delay cycles
4. DONE: Timer finished, waiting for acknowledgment

The FSM will:
- Use a shift register to detect the 1101 pattern
- Use another shift register to collect the 4-bit delay value
- Maintain a counter for the 1000-cycle intervals
- Output the current count value during COUNTING state
- Assert 'counting' during COUNTING state
- Assert 'done' during DONE state until 'ack' is received

The countdown logic will:
- Decrement the displayed count every 1000 cycles
- Maintain a separate counter for the 1000-cycle intervals
- Transition to DONE state when count reaches 0 and 1000 cycles complete
