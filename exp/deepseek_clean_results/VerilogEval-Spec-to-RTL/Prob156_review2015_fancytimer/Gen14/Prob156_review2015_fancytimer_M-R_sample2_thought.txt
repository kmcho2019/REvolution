Refactored Approach: Separated Pattern Detection and Counting Logic

1. **Modular State Machine**:
   - Split into two distinct processes: pattern detection and timer control
   - Pattern detection uses shift register and simple equality check
   - Timer control handles the counting and state transitions

2. **Simplified Counting Logic**:
   - Use separate counters for 1000-cycle chunks (main_counter) and chunk counting (sub_counter)
   - Clear division between cycle counting and value tracking
   - count output directly tracks remaining chunks

3. **Explicit Output Generation**:
   - Use continuous assignments for counting and done outputs
   - Clear state-based output conditions

4. **Optimized Transitions**:
   - Explicit state transition conditions
   - Clean reset handling for all registers

Key Improvements:
- Clear separation of concerns between pattern matching and timing
- More intuitive counting mechanism
- Explicit output generation
- Maintains exact same functionality but with clearer structure
