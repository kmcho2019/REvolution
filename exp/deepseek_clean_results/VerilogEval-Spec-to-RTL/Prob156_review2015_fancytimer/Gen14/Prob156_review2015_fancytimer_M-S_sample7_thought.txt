Here's a simplified approach that maintains all required functionality while reducing complexity:

1. **Single Shift Register**: Use one 4-bit shift register for both pattern matching and delay value collection, repurposing it after pattern detection.

2. **Simplified State Machine**: Reduce to just 4 states (IDLE, COLLECT, COUNT, DONE) for clearer operation.

3. **Direct Cycle Counting**: Count cycles directly without sub-counters by using the full (delay+1)*1000 range in one counter.

4. **Unified Count Logic**: Generate the count output directly from the remaining cycles calculation, eliminating separate counters.

Key simplifications:
- Eliminated parallel shift registers
- Reduced state machine complexity
- Removed sub-counter logic
- Simplified output generation
- Maintains exact same external behavior
