New architectural approach:
1. Use parallel pattern detection (1101) instead of serial shifting
2. Separate the pattern matching FSM from the timing control FSM
3. Implement a dedicated 4-bit shift register for delay value capture
4. Use a 14-bit counter for precise (delay+1)*1000 cycle timing
5. Add a prescaler to generate 1000-cycle intervals

Key innovations:
- Parallel pattern detection reduces latency and improves reliability
- Separate FSMs for cleaner state transitions
- Explicit delay value capture register
- Accurate cycle counting with prescaler
- Clear separation of pattern matching and timing phases
