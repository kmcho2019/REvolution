The refactored solution will:
1. Use separate processes for pattern detection and counting
2. Implement a more precise counter with two levels (cycle counter and 1000-cycle chunks)
3. Use continuous assignments for outputs where possible
4. Maintain clear state separation between detection, counting, and done phases
5. Properly calculate remaining time by tracking both total cycles and current chunk

Key improvements:
- Separate 4-bit pattern register and 4-bit delay register
- Use a 10-bit sub-counter for 1000-cycle chunks
- Track remaining time directly from delay register
- Clear state transitions with proper conditions
- Use assign for simpler output logic
