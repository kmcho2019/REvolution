1. **Parallel Pattern Matching**:
   - Instead of a shift register, use combinatorial logic to detect the 1101 pattern in parallel from the last 4 bits
   - This reduces latency in pattern detection

2. **Two-Stage Counting**:
   - Use a coarse counter for 1000-cycle periods
   - Use a fine counter within each 1000-cycle period
   - This ensures exact cycle counting without division operations

3. **State Machine Optimization**:
   - Simplified to 3 states with clear separation of concerns
   - Early detection of pattern completion to start delay capture immediately

4. **Output Generation**:
   - Dynamic count output that's only valid during counting
   - Precise signal timing using both counters
