Here's a simplified approach that maintains all functionality while reducing complexity:

1. Single State Machine: Use a simpler 4-state machine (IDLE, DETECT, CAPTURE, COUNT) instead of 5 states
2. Combined Counters: Use one main counter for the full (delay+1)*1000 cycles instead of separate period and count-down counters
3. Efficient Pattern Detection: Detect 1101 pattern by shifting bits and comparing directly
4. Simplified Output Logic: Generate outputs directly from state and counter values
5. Clear Reset Handling: Explicitly reset all registers

Key simplifications:
- Eliminate the separate period counter by calculating total cycles upfront
- Remove intermediate states by combining detection and capture logic
- Simplify count output by deriving from remaining cycles
- Reduce register usage by eliminating redundant counters
