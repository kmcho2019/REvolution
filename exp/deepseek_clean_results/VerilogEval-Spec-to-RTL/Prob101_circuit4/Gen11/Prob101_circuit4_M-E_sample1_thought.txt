Novel Architectural Idea: Priority-Encoded OR Gate

1. Core Concept:
   - Instead of a simple OR operation, implement a priority-based system where:
     - Input 'c' has higher priority than 'b'
     - If 'c' is 1, output is immediately 1 regardless of 'b'
     - Only when 'c' is 0 does 'b' determine the output

2. Advantages:
   - Mimics a priority encoder behavior
   - Conceptually different from standard OR implementation
   - Still functionally equivalent to b OR c
   - Demonstrates alternative thinking in logic implementation

3. Implementation:
   - Use conditional assignment based on 'c' first
   - Fall back to 'b' only when 'c' is 0
   - Completely ignores 'a' and 'd' as per requirements
