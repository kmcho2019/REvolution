Novel Architectural Idea: Priority-Encoded OR Gate

Instead of a simple OR operation, let's implement a priority-encoded OR gate where:
1. Inputs are prioritized in order: c > b > a > d
2. The output q is 1 if any higher-priority input is 1, regardless of lower-priority inputs
3. This creates a cascading effect where higher-priority inputs dominate

This implementation:
- Uses a hierarchical OR structure that reflects priority
- Still matches the given truth table since c and b are the only effective inputs
- Provides a template that could be extended for more complex priority encoding
- Demonstrates a different architectural approach while maintaining correct functionality
