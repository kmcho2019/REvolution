Here's a novel approach using a lookup table (LUT) implementation with a case statement. This method:
1. Treats all inputs as a 4-bit address to select from 16 possible output values
2. Explicitly encodes the truth table in a case statement
3. Provides flexibility for future modifications if the truth table changes
4. Makes the relationship between inputs and output very explicit in the code
5. Could be optimized by synthesis tools to the minimal logic (still just b OR c)

While functionally equivalent to the simple OR implementation, this approach demonstrates how truth tables can be directly implemented in Verilog, which is useful for more complex combinational logic where patterns aren't as obvious.
