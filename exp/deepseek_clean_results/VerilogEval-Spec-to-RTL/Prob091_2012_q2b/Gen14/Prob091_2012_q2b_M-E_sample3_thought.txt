Novel Architectural Idea: State Transition Matrix Decoder
1. **Matrix-Based Approach**: Instead of deriving each output separately, implement a transition matrix that encodes all possible state transitions. This provides a more systematic view of the FSM.
2. **Parallel Output Calculation**: Calculate all next-state bits in parallel using the current state and input, then extract only Y1 and Y3.
3. **One-Hot Validation**: Include logic to ensure the one-hot property is maintained during transitions.
4. **Lookup Efficiency**: The matrix approach makes it easier to modify or verify state transitions as it's more readable and maintainable.
5. **Resource Sharing**: Common terms in the transition equations are computed once and reused.
