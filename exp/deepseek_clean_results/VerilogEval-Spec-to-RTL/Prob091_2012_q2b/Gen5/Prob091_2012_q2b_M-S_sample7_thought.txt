   - States B, C, E, F all transition to D when w=0
   - Instead of OR'ing all these states, we can note that in one-hot encoding, only one y[i] is ever 1 at a time
   - We can simplify the OR operation to just check if any of these bits are set using a reduction OR
   - This makes the code more concise while maintaining the same functionality
