Novel Approach: State Transition Matrix
1. **Matrix-Based Logic**: Instead of deriving outputs directly from current state and input, create a transition matrix that encodes all possible state transitions.
2. **Parallel Evaluation**: Evaluate all possible next states in parallel, then select the correct one based on current state.
3. **Output Extraction**: The outputs Y1 and Y3 are simply the relevant bits from the computed next state vector.

Key Advantages:
- More scalable for larger state machines
- Clear separation between transition rules and output logic
- Easier to modify transition rules without affecting output logic
