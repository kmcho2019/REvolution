Novel Architectural Idea:
Instead of using pure combinational logic, we can leverage a lookup table (LUT) approach that encodes all possible state transitions. This method:
1. Uses the current state (y) and input (w) as an address to a pre-defined transition table
2. Stores the next state values for Y1 and Y3 in a compact ROM-like structure
3. Benefits include:
   - Easier modification of state transitions (just update the ROM contents)
   - Potential area savings in complex FSMs with many transitions
   - More regular structure that may map better to certain FPGA architectures
4. For this specific FSM, we'll implement a minimal 7-entry LUT (6 states + invalid) that outputs Y1 and Y3 directly
