Refactoring Approach:
1. **Maintain Same Logic**: Keep the exact same functional behavior as the original solution (same state transitions and outputs)
2. **Structural Change**: Instead of using continuous assignments, implement the logic using an always block with case statements for better readability and potential synthesis optimization
3. **One-Hot Encoding Exploitation**: Leverage the one-hot property more explicitly by checking individual state bits
4. **Output Assignment**: Keep outputs combinational but derive them from the next state logic rather than directly from current state

Key Benefits:
- More readable state transition logic
- Easier to modify/extend if state machine grows
- Maintains same PPA characteristics (same logic, just reorganized)
- Clear separation between state transition logic and output generation
