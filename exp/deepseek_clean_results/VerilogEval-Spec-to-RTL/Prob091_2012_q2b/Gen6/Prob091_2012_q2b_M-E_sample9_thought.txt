Novel Approach: State Transition Matrix Decoder

Instead of deriving each flip-flop input separately, we can implement a more systematic approach by:
1. Creating a state transition matrix that encodes all possible next states
2. Using the current state (y) to select the relevant row from this matrix
3. Extracting Y1 and Y3 from the selected next state

Advantages:
- More scalable for larger state machines
- Clear separation between state transition logic and output extraction
- Easier to modify if state transitions change
- Can potentially share logic between multiple flip-flop inputs
