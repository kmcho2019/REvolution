Novel Approach: State Transition Matrix
1. **Matrix-Based Logic**: Represent the state transitions as a matrix operation where each next state bit is computed based on current state and input.
2. **Parallel Computation**: Compute all next state bits in parallel using bitwise operations, then select only Y1 and Y3 outputs.
3. **Optimization Insight**: The matrix approach makes the state transitions more explicit and could potentially reveal optimization opportunities in larger state machines.
4. **Maintain One-Hot**: Ensure the one-hot property is preserved by construction.

Benefits:
- More scalable for larger state machines
- Clear separation between state transition logic and output selection
- Potential for better optimization in synthesis
- Maintains same functionality with different implementation style
