Here's a refactored version that maintains the same functionality but with these structural changes:

1. Replace the combinational priority encoder with a function for better readability and potential synthesis optimization
2. Move the state transition logic into a separate combinational always block (Mealy-style)
3. Use a sequential always block just for the state register
4. Keep the direct output assignment from state bits
5. Use localparam for state encodings for better code documentation

The key improvements are:
- Clear separation of combinational and sequential logic
- More modular design with the priority logic encapsulated in a function
- Better documentation through localparam
- Same efficient state encoding and output generation
- Maintains all original functionality and priority scheme
