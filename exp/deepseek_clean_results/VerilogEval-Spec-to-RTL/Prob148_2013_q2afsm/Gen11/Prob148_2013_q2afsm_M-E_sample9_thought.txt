This solution introduces two key innovations:
1. Dynamic Priority Rotation: Instead of fixed priorities, we rotate priorities each time we return to state A, creating a fairer arbitration scheme while maintaining the required priority order during each arbitration cycle.
2. State Compression: We encode both the current grant and priority rotation state in a compact 3-bit register, where:
   - Bit 0: Grant to device 0
   - Bit 1: Grant to device 1
   - Bit 2: Grant to device 2 and rotation state
   
The FSM operates as:
- Reset to state A (000)
- When in A: Grant to highest priority active request based on current rotation
- While granted: Maintain grant as long as request is active
- On release: Rotate priorities and return to A
- Outputs are direct decoded from the state register

This approach reduces state transitions while adding fairness through priority rotation, all within the same 3-bit state encoding.
