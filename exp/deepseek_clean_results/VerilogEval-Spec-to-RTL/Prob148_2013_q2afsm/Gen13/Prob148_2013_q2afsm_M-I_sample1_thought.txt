To optimize the PPA metrics, I'll implement the following improvements:

1. One-hot state encoding (4 bits) to improve timing by reducing state decode logic
2. Registered outputs to reduce switching activity and power consumption
3. Simplified priority encoder using casez for better synthesis
4. Separate always blocks for state transitions and output updates
5. Explicit default assignments to prevent latch inference

Key optimizations:
- One-hot encoding reduces critical path by eliminating state decoding
- Registered outputs reduce glitches and unnecessary switching
- Casez statement for priority encoder is more synthesis-friendly
- Clear separation of combinational and sequential logic
- All outputs are registered to improve timing closure
