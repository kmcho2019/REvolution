Refactoring Strategy:
1. State Encoding: Switch from one-hot to binary encoding to reduce flip-flop usage while maintaining clear state definitions
2. Output Logic: Use continuous assignments for outputs to make the grant signals more explicit and potentially reduce switching activity
3. State Transitions: Restructure the next state logic to use nested if-else instead of case for better readability and potential synthesis optimization
4. Reset Handling: Maintain synchronous active-low reset but simplify the default state assignment
5. Priority Logic: Keep the same priority order but implement it with a more structured conditional approach

Benefits:
- Reduced area from binary state encoding
- More explicit output assignments
- Cleaner state transition logic
- Maintains same functionality while potentially improving synthesis results
