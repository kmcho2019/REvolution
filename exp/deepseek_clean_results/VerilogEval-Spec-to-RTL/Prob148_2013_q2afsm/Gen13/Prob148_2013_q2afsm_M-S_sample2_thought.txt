Simplification Strategy:
1. State Encoding: Use binary encoding (2 bits) instead of one-hot (3 bits) to reduce flip-flop count
2. Priority Logic: Simplify by directly encoding priority in the state transition logic
3. Output Generation: Use combinational logic based on current state
4. Reset Handling: Keep synchronous active-low reset
5. State Transitions: Maintain same behavior but with simpler encoding

Key Improvements:
- Reduced state bits from 3 to 2
- Simplified state comparison logic
- Maintained same priority and grant behavior
- More efficient area usage
