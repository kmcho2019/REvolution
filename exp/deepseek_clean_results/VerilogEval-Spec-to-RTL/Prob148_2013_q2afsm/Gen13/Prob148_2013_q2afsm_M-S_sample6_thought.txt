Simplification Strategy:
1. State Encoding: Use binary encoding (2 bits) instead of one-hot to reduce flip-flop count
2. Priority Logic: Simplify by directly encoding priority in the state transition logic
3. Output Generation: Use combinational logic based on current state
4. Reset Handling: Keep synchronous active-low reset
5. State Transitions: Maintain same behavior but with simpler state encoding

Key Improvements:
- Reduced from 3 state bits to 2 bits (binary encoding)
- Simplified next-state logic by removing intermediate one-hot encoding
- Maintained same priority behavior and output functionality
- Reduced area and potential power consumption
