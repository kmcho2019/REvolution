Here's a novel approach using a priority encoder with state tracking:
1. Use a 2-bit state register to encode 4 states (A, B, C, D)
2. Implement a priority encoder that always evaluates requests in order (r0 > r1 > r2)
3. Use combinational logic to determine next state based on current state and requests
4. Output grants are purely combinational functions of current state
5. The FSM will naturally implement the priority system through the encoder
6. State transitions are simplified by focusing on request persistence

This approach minimizes state transitions while maintaining clear priority handling.
