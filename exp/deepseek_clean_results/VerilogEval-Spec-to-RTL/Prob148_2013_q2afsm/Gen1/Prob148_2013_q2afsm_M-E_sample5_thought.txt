Here's a novel approach using a hierarchical priority encoder combined with the FSM:

1. Instead of encoding states directly, we'll use a priority encoder to determine the highest priority request first
2. The FSM will then only need to track which device is currently granted access
3. We'll use a 2-bit state register to track:
   - 00: No grant (state A)
   - 01: Device 0 granted (state B)
   - 10: Device 1 granted (state C)
   - 11: Device 2 granted (state D)
4. The priority encoder will generate a 2-bit code representing the highest priority active request
5. The FSM will transition based on both current grant and new requests
6. Outputs will be simple decodes of the state

Key advantages:
- Separates priority logic from state transitions
- More scalable if more devices are added later
- Clear separation between request processing and grant maintenance
