Instead of a traditional FSM with explicit state transitions, we'll implement a priority-based grant generator with state tracking. The key innovations are:
1. Use a priority encoder to determine the highest priority request
2. Maintain a "locked" state when a grant is active and request persists
3. Implement a "grant_hold" register to track current grantee
4. Use combinational logic for priority resolution and sequential logic for grant tracking
5. Eliminate explicit state definitions by using the grant_hold register as state

This approach reduces state transitions and simplifies the logic while maintaining the same functionality. The priority is still enforced (r0 > r1 > r2), and grants persist as long as the request is active.
