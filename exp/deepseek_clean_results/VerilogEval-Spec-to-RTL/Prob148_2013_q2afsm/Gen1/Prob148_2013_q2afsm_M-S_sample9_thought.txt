To simplify the FSM implementation while maintaining functionality:
1. Remove the unused state D since it's not shown in the state transitions
2. Simplify state encoding to just 2 states (A, B, C) since D isn't needed
3. Keep the priority order: r[0] > r[1] > r[2]
4. Maintain synchronous reset and same output behavior
5. Simplify next state logic by removing D-related conditions
6. Keep output assignments simple and combinational

The simplified state transitions:
- Stay in A if no requests or only r[2]=1 (lowest priority)
- Go to B if r[0]=1 (highest priority)
- Go to C if r[1]=1 and r[0]=0
- From B: stay if r[0]=1, else return to A
- From C: stay if r[1]=1, else return to A
- r[2] is effectively ignored as per original spec
