This solution introduces two key innovations:
1. Hierarchical State Encoding: Uses a 3-bit encoding where the MSB indicates grant state (1) vs idle (0), and lower bits encode which device is granted. This allows simpler output logic and more direct state transitions.

2. Output Pipelining: Adds a registered output stage to:
   - Improve timing by breaking the combinational path from state to outputs
   - Reduce glitches on grant signals
   - Enable easier timing closure

The state machine logic is simplified by:
- Using the MSB as grant/idle indicator
- Encoding the granted device directly in state bits
- Implementing priority through sequential if-else structure
- Adding synchronous output registers for clean timing
