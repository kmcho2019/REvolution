This solution implements a rotating token arbitration scheme with these key features:
1. Instead of fixed priority, we implement a dynamic priority system where devices get fairer access over time
2. We compress the state representation by tracking only the current grant and last grant
3. The FSM uses a 3-bit state register:
   - 1 bit for current grant (0-2)
   - 2 bits for priority rotation tracking
4. The arbitration logic:
   - First checks if current grantee is still requesting
   - Then checks requests in rotating priority order
   - Finally falls back to fixed priority if no requests
5. Outputs are generated combinatorially from the current grant
6. Reset puts the system in idle state with no grants

Advantages:
- More balanced access over time compared to pure fixed priority
- State compression reduces flip-flop count
- Rotating priority prevents starvation of lower priority devices
- Simpler state transitions by separating grant maintenance from new arbitration
