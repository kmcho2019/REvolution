Refactoring Strategy:
1. State Encoding: Switch from one-hot to binary encoding (2 bits) to reduce flip-flop usage while maintaining clear state definitions
2. Output Logic: Use combinational always block for outputs to explicitly show grant conditions
3. State Transitions: Restructure next state logic to use nested if-else for clearer priority handling
4. Reset Handling: Maintain synchronous active-low reset but simplify state initialization
5. Output Generation: Make grant outputs explicitly dependent on current state for better readability

Benefits:
- Reduced area from 3-bit to 2-bit state encoding
- Clearer priority handling with nested conditionals
- Explicit output mapping improves code maintainability
- Maintains same functionality while being more resource-efficient
