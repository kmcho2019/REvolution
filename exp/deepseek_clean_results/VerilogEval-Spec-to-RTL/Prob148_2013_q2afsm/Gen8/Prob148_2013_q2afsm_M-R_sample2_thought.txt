Refactoring Strategy:
1. State Encoding: Switch from one-hot to binary encoding to reduce flip-flop usage while maintaining clear state definitions
2. Output Logic: Use combinational always block for outputs to explicitly show grant conditions
3. Next State Logic: Restructure priority handling using nested if-else for better readability
4. Reset Handling: Keep synchronous active-low reset but make state transitions more explicit
5. Modularity: Separate state transitions and output logic clearly

Benefits:
- Reduced area from 3-bit to 2-bit state encoding
- More explicit output generation logic
- Clearer priority handling structure
- Maintains same functionality with potentially better timing
