Refactoring Strategy:
1. State Encoding: Switch from one-hot to binary encoding to reduce flip-flop usage while maintaining readability
2. Output Logic: Use explicit continuous assignments for each grant signal to make the priority system more visible
3. State Transitions: Restructure the next state logic to use nested if-else instead of case for clearer priority expression
4. Reset Handling: Maintain synchronous active-low reset but simplify state initialization
5. Default Handling: Remove explicit default case since all states are covered

Benefits:
- Reduced area from 3-bit to 2-bit state encoding
- Clearer priority expression in the logic
- More explicit output assignments
- Maintained performance with simpler state comparisons
