This solution introduces a hierarchical FSM architecture with these key innovations:

1. Priority Encoder Pre-processing: 
   - Implement a separate combinational block to determine the highest priority request
   - Outputs a 2-bit encoded request signal (req_type) and valid flag

2. Simplified State Machine:
   - Only 3 states (IDLE, GRANT0, GRANT1, GRANT2) instead of 4
   - State transitions depend on pre-processed request information
   - Eliminates complex nested conditions in state transition logic

3. Output Generation:
   - Uses a decoder-style approach from current state
   - Outputs are registered for better timing closure

4. Advantages:
   - Separates concerns (priority handling vs state management)
   - More scalable for additional requestors
   - Clearer timing paths due to staged logic
   - Easier to modify priority scheme without touching FSM
