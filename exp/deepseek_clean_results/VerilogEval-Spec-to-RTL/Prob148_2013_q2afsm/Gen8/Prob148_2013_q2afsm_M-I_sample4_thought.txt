Improvement Strategy:
1. State Encoding: Switch from one-hot to binary encoding to reduce state bits from 3 to 2 while maintaining clear state definitions
2. Priority Logic: Restructure the priority encoder to use nested if-else for better synthesis optimization
3. Output Generation: Use combinational logic based on state rather than direct assignment to minimize unnecessary transitions
4. Reset Handling: Maintain synchronous active-low reset but simplify state initialization
5. Power Optimization: Gate output transitions to only change when necessary
6. Area Reduction: Remove default case since all states are explicitly handled

Benefits:
- Reduced state bits (2 instead of 3) saves flip-flops
- Structured priority logic improves timing
- Output gating reduces power consumption
- Clear state transitions maintain readability
- No default case reduces unnecessary logic
