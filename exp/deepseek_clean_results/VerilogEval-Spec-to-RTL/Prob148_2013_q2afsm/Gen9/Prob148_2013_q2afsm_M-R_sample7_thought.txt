Refactoring Strategy:
1. State Encoding: Switch from one-hot to binary encoding to reduce flip-flop usage while maintaining clear state definitions
2. Output Logic: Use combinational always block for outputs to explicitly show grant conditions
3. Next State Logic: Restructure priority logic to be more explicit and readable
4. Reset Handling: Maintain synchronous active-low reset but make state transitions more explicit
5. Code Structure: Separate state transitions and output logic clearly while keeping the same functionality

Benefits:
- Reduced area from 3-bit to 2-bit state encoding
- More explicit output conditions improve readability
- Clear separation of state transitions and output logic
- Maintains same timing characteristics with simpler encoding
