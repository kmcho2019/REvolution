The previous solution uses a 2-bit grant_hold register and complex priority logic. We can simplify this by:
1. Using one-hot encoding for states (A, B, C, D) which directly correspond to grants
2. Eliminating the separate priority encoder by embedding it in the state transition logic
3. Making outputs directly dependent on state (no need for separate grant_hold)
4. Simplifying the reset condition to only reset to state A
5. Using a single always block for state transitions and output generation

This reduces the logic complexity while maintaining the exact same functionality and priority scheme.
