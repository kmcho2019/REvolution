Novel Architecture Idea:
1. Rotating Priority: Instead of fixed priority, implement a round-robin priority scheme that rotates after each grant to prevent starvation
2. Compact State Encoding: Use 2-bit state encoding with an additional 2-bit priority pointer
3. Output Logic: Implement grant outputs using a combinational decoder from state and priority
4. Dynamic Priority Update: Update priority pointer only when returning to idle state
5. Efficient Transitions: Simplify state transitions by tracking current grantee rather than all possible states

Benefits:
- Fair arbitration through rotating priority
- Compact state representation (4 total bits)
- Reduced output switching activity
- Lower power consumption
- Balanced resource utilization
