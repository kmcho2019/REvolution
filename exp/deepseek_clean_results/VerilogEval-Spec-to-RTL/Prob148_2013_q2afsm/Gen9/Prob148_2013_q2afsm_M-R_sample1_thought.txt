Refactoring approach:
1. Use one-hot encoding for states (A=0001, B=0010, C=0100, D=1000) for potentially better timing and simpler decoding
2. Separate state transitions and output logic into distinct always blocks for better modularity
3. Use casez for more flexible state transition conditions
4. Make grant outputs directly dependent on state bits (one-hot advantage)
5. Explicitly list all state transitions for clarity
6. Use non-blocking assignments consistently for sequential logic
