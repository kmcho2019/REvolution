Refactoring Strategy:
1. State Encoding: Switch from one-hot to binary encoding to reduce flip-flop usage while maintaining readability
2. Output Logic: Keep direct assignment but make it explicit with case statements for clarity
3. Next State Logic: Restructure to use nested if-else instead of ternary operators for better readability
4. Reset Handling: Maintain synchronous active-low reset but make state transitions more explicit
5. Priority Handling: Implement priority logic in a more structured way using sequential checks

Benefits:
- Reduced area from 3-bit to 2-bit state encoding
- Clearer state transition logic
- Explicit output mapping
- Maintains same functionality with improved readability
