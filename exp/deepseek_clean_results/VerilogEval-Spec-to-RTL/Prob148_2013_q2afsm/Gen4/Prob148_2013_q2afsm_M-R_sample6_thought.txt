Refactored design with these key changes:

1. State Encoding: Changed to one-hot encoding for potentially better timing and simpler output logic
2. State Transitions: Split into separate always blocks for next state logic and state registers
3. Output Logic: Simplified using direct state bit assignments (one-hot advantage)
4. Reset Handling: Maintained synchronous active-low reset
5. Priority Logic: Kept same priority order but expressed differently

Key benefits:
- One-hot encoding makes output assignments trivial (each state directly maps to a grant)
- Separate always blocks improve readability and potential for synthesis optimizations
- Next state logic is more explicit and potentially easier to optimize
- Maintains exact same functionality while being more maintainable
