The problem requires implementing a finite state machine (FSM) with four states (A, B, C, D) that acts as an arbiter for three devices with priority. The FSM transitions between states based on the input signals r[2:0], where r[0] has the highest priority and r[2] the lowest. The outputs g[2:0] indicate which device is granted access to the resource.

Key points:
1. Use a 2-bit state register to encode the four states (A, B, C, D)
2. Implement synchronous reset (active-low) to initialize to state A
3. Create combinational logic for state transitions based on current state and inputs
4. Output g[i] should be 1 when in the corresponding state (B for g[0], C for g[1], D for g[2])
5. Priority order: r[0] > r[1] > r[2]

State encoding:
A = 2'b00
B = 2'b01
C = 2'b10
D = 2'b11
