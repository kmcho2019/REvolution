The problem requires implementing a finite state machine (FSM) with four states (A, B, C, D) that acts as an arbiter for three devices with priority. The FSM will transition between states based on the input signals r[2:0] and output grant signals g[2:0] accordingly. 

Key points:
1. State encoding: We'll use binary encoding for the states (A=00, B=01, C=10, D=11)
2. State transitions:
   - From A: 
     - Stay in A if no requests (r=000)
     - Go to B if r[0]=1 (highest priority)
     - Go to C if r[0]=0 and r[1]=1
     - Go to D if r=000 (though diagram shows this, it seems contradictory - assuming this is a typo and should be r[2]=1)
3. Outputs:
   - g[0]=1 in state B
   - g[1]=1 in state C
   - g[2]=1 in state D
4. Reset behavior: Active-low synchronous reset to state A

We'll implement this with:
- Two always blocks (one for state transitions, one for state storage)
- Continuous assignments for the output signals
