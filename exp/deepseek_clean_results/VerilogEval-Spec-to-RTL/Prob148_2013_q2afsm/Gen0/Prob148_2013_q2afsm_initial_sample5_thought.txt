The problem requires implementing a finite state machine (FSM) with four states (A, B, C, D) that acts as an arbiter for three requesting devices. The FSM has priority-based arbitration where device 0 has highest priority and device 2 has lowest. The FSM transitions between states based on the input signals r[2:0] and outputs grant signals g[2:0] accordingly.

Design approach:
1. Define states using localparam (A=00, B=01, C=10, D=11)
2. Use two always blocks:
   - One for synchronous state transitions (sequential)
   - One for combinational next-state logic
3. Output logic can be continuous assignments based on current state
4. Implement priority logic in next-state transitions:
   - In state A: check r[0] first, then r[1], then r[2]
   - In states B and C: stay if request continues, else return to A
5. Reset to state A when resetn is low
