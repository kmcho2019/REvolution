I'll refactor the FSM implementation to use one-hot encoding for states instead of binary encoding. This approach:
1. Uses one bit per state (A=0001, B=0010, C=0100, D=1000)
2. Simplifies output logic since each state directly corresponds to an output
3. Makes state transitions more explicit
4. Uses continuous assignments for both state transitions and outputs
5. Maintains the same functionality but with potentially better timing characteristics

The one-hot encoding eliminates the need for state decoding in the output logic, as each state bit directly controls its corresponding output.
