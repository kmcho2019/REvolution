Instead of using a traditional state machine with explicit state encoding, we can implement a priority-based arbiter using a more combinatorial approach with registered outputs. The key idea is:

1. Eliminate explicit state variables and instead track grants directly
2. Use priority encoders to determine which device gets the grant
3. Maintain grants using feedback registers
4. Implement synchronous reset functionality

Advantages:
- More direct implementation of the priority scheme
- Eliminates state encoding overhead
- Simpler transition logic
- Outputs are naturally registered
- Easier to extend to more devices

The design works by:
- Using priority logic to determine the highest priority active request
- Maintaining the current grant until the request drops
- Resetting all grants when reset is active
- Using registered outputs for better timing
