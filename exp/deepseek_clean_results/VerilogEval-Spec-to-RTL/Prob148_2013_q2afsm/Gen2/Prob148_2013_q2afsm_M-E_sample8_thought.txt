Here's a novel approach using a hierarchical priority encoder combined with the FSM. Instead of encoding states traditionally, we'll:
1. Use a priority encoder to determine the highest priority request at each cycle
2. Maintain the current grant state separately from the FSM state
3. Implement the FSM with just 2 states (IDLE and GRANTED) to track whether we're in arbitration mode
4. Use the priority encoder output directly to determine grants when in GRANTED state
5. This reduces state transitions and simplifies output logic while maintaining the same functionality

The key innovations are:
- Separating priority logic from state transitions
- Reducing state space by tracking just arbitration status
- Using combinational logic for priority resolution
- Only entering GRANTED state when needed
