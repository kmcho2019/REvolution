Here's a novel approach using a priority encoder with registered outputs:

1. Key Innovation: Replace traditional FSM with a priority encoder + state tracking
   - Use combinational logic to detect highest priority request
   - Maintain state only to track current grant holder
   - This reduces state transitions and simplifies logic

2. Advantages:
   - Fewer state transitions (only when grant changes)
   - Clearer priority implementation
   - More scalable for additional devices
   - Reduced power consumption from fewer state changes

3. Implementation Details:
   - Use a priority encoder to select highest priority request
   - Register current grant state
   - Output logic becomes simple equality comparison
   - Reset forces return to idle (no grants) state

4. Optimizations:
   - Registered outputs for better timing
   - Explicit priority encoding in combinational logic
   - Minimal state storage (only current grant)
