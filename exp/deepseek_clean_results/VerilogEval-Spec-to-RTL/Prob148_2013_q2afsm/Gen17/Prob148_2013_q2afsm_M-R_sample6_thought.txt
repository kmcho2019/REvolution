Here's a refactored version with these key changes:

1. Changed state encoding to binary (2 bits) to reduce area and power
2. Separated output logic into its own combinational block for better clarity
3. Used explicit state transitions in the next state logic
4. Maintained the same priority scheme but with more verbose condition checks
5. Kept the same three-process FSM style (state reg, next state logic, output logic)

The benefits are:
- Reduced state register size from 3 bits to 2 bits
- More explicit output decoding
- Same functionality and priority scheme
- Potentially better power characteristics due to reduced state encoding
