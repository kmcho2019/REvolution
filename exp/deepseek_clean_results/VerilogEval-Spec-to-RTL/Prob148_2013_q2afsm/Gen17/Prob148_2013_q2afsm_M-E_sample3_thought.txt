Novel Architecture Idea:
1. Priority-Embedded State Encoding: Instead of traditional binary encoding, embed the priority information directly into state codes by using the upper bits to represent the active grant (if any). This reduces output decoding logic.
2. Combined State/Output: The state register directly represents the current grant pattern, eliminating the need for separate output generation logic.
3. Early Priority Resolution: Implement the priority encoder as a separate combinational block that feeds into the state transition logic, improving timing.
4. Reset Optimization: Use synchronous reset only when needed (state A) to reduce reset fanout.

Key Benefits:
- Reduced logic levels by combining state and output
- Priority logic is pre-computed before state transition
- More efficient encoding scheme (3 bits total: 1 for state, 2 for priority)
- Clear separation of priority resolution from state transition
