Here's a novel approach that uses a hierarchical state machine with parallel state tracking:

1. Instead of a single FSM, implement three parallel mini-FSMs (one for each device) that track their own grant status
2. Use a priority encoder to resolve conflicts between active requests
3. Each mini-FSM has only two states: IDLE (no grant) and ACTIVE (grant)
4. The priority logic is centralized and determines which mini-FSM can transition
5. Outputs are generated directly from the mini-FSM states

Key advantages:
- More modular design with clear separation of concerns
- Easier to extend to more devices
- Parallel state evaluation may lead to better timing
- Explicit priority handling in a dedicated block
- Each mini-FSM is simpler with only 2 states
