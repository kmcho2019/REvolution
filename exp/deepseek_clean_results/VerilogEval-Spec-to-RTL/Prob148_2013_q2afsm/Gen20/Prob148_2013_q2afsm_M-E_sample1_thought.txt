Novel Architecture Idea: Priority-Based State Machine with Output Latching

Key Innovations:
1. State Encoding: Use binary encoding (2 bits) for states to minimize flip-flop usage while maintaining clear state distinction
2. Output Latching: Implement output registers that hold grant signals until explicitly cleared, reducing output switching
3. Priority Resolution: Use a dedicated combinational block for priority resolution, separate from state transition logic
4. State Transition Logic: Simplify by focusing only on grant persistence and return-to-idle conditions
5. Output Generation: Use registered outputs synchronized with state changes for clean timing

Benefits:
- Reduced state encoding bits (2 vs 3 in one-hot)
- Stable outputs due to latching behavior
- Clear separation of priority logic and state transitions
- Lower power from reduced output switching
- Better timing with registered outputs
