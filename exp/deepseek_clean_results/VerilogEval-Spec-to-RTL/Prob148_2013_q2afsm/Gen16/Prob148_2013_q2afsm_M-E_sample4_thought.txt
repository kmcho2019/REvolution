This solution implements a hierarchical FSM with parallel request evaluation:

1. Main FSM tracks the current grant state (A/B/C/D)
2. Parallel combinational logic continuously evaluates requests with priority
3. State transitions are determined by both current state and evaluated requests
4. Outputs are generated combinationally based on current state
5. Uses binary state encoding for compact representation

Key innovations:
- Separates request evaluation from state transitions for clearer logic
- Uses parallel priority evaluation for immediate response to requests
- Combines Mealy and Moore output styles for efficient implementation
- Binary encoding minimizes state register bits while maintaining readability
- Explicit priority logic makes the design intent clear
