Here's a refactored version that maintains the same functionality but with these structural changes:

1. Use binary encoding for states to reduce register bits from 3 to 2
2. Move output generation into a combinational always block for explicit decoding
3. Keep state transitions in a separate combinational always block
4. Maintain the same priority logic but with more efficient state encoding
5. Use continuous assign for reset handling to simplify the sequential block

Key improvements:
- Reduced state encoding bits (3→2) saves area and power
- Explicit output decoding prevents unnecessary toggling
- Clear separation of state transition and output logic
- Same priority handling and timing characteristics
