Here's a refactored version that maintains the same functionality but with these structural changes:

1. Use binary encoding for states to reduce register bits from 3 to 2
2. Implement the state machine with a single always block for both state transitions and output generation (Mealy-style)
3. Use continuous assignments for outputs to maintain clarity
4. Simplify the state encoding while preserving the priority logic
5. Combine next-state and output logic for more compact implementation

Key benefits:
- Reduced area from fewer state bits
- Clear separation of combinational and sequential logic
- Maintains same priority behavior and timing characteristics
- More efficient power consumption due to reduced state encoding
