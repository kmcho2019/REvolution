Refactored design with these key changes:

1. State Encoding: Changed to one-hot encoding for potentially better timing and simpler output logic
2. State Transitions: Restructured using parallel if-else instead of nested ternary for clearer priority handling
3. Output Logic: Simplified by directly mapping one-hot states to outputs
4. Reset Logic: Maintained synchronous active-low reset
5. Structure: Used separate always blocks for state transitions and output logic for better modularity

Key benefits:
- One-hot encoding makes output logic trivial (direct state bit mapping)
- Parallel if-else structure improves readability of priority scheme
- Maintains same functionality while potentially improving timing
- Clear separation between combinational next-state logic and sequential state register
