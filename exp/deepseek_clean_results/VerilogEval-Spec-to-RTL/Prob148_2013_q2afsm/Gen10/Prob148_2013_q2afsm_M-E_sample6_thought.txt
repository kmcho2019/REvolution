Here's a novel approach using a priority encoder combined with state tracking:

1. Instead of separate states for each grant, we'll use a single state register to track which device currently has the grant (0=none)
2. Implement a priority encoder that always selects the highest priority active request
3. Use a simple state machine that:
   - Resets to idle state (no grants)
   - When idle, grants to the highest priority request
   - While granted, maintains grant as long as request is active
   - Returns to idle when request drops
4. Outputs are generated combinatorially based on current grant state
5. This reduces the state space to just tracking the active grant (3 bits) rather than separate states

The key innovation is combining the priority resolution and state tracking into a single compact representation, eliminating the need for complex state transitions while maintaining all functionality.
