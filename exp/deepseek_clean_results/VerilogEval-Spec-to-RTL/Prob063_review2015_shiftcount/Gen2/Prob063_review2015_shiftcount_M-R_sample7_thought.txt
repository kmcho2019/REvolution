The refactored design will maintain the same functionality but optimize the implementation by:
1. Separating the combinational logic from sequential elements
2. Using a continuous assignment for the next state logic
3. Making the register update more explicit

Key changes:
- Use an always block only for the sequential update
- Compute the next state value using continuous assignment
- This structure may help synthesis tools optimize better by clearly separating combinational and sequential logic
- The priority between shift and count remains undefined as per requirements
