Refactored approach using continuous assignments and combinational logic:
1. Replace the sequential always block with a combinational next-state logic
2. Use a separate always block just for the register update
3. Compute the next state value using ternary operators in continuous assignments
4. This separates the combinational logic from sequential elements, which can help with synthesis and timing analysis
5. The structure makes it clearer what the next state computation is independent of the clock

Key benefits:
- Clear separation of combinational and sequential logic
- Easier to add additional combinational logic if needed
- More explicit about the next state computation
- Maintains the same functionality while being more modular
