Here's a novel approach using a rotating shift register with conditional direction control:

1. Instead of a traditional shift register, we'll implement a circular shift register that can rotate left or right.
2. The direction is controlled by the operation type:
   - For shift operations (shift_ena=1), we rotate right to implement MSB-first shifting
   - For count operations (count_ena=1), we rotate left to implement decrement
3. The data input is inserted at the MSB during shifts
4. This approach minimizes the control logic by unifying both operations under a single rotation mechanism
5. The rotation direction is determined by a simple XOR of the control signals

Benefits:
- Single unified operation (rotation) handles both functions
- Minimal control logic (just direction selection)
- Efficient implementation using concatenation
- Naturally handles the "don't care" case when both enables are active
