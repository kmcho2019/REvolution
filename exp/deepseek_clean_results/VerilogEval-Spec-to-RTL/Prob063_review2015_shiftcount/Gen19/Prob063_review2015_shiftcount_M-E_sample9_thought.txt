Novel Architecture Idea: "Parallel Operation with Final Mux"
1. Instead of conditional operations, compute both shift and count operations in parallel
2. Use a final multiplexer to select between:
   - Shifted value (when shift_ena is active)
   - Decremented value (when count_ena is active)
   - Original value (when neither is active)
3. Benefits:
   - Parallel computation reduces critical path delay
   - Clear separation of operations improves readability
   - Final mux provides explicit priority handling
   - Easier to modify priority if requirements change
4. Implementation:
   - Calculate shifted value separately
   - Calculate decremented value separately
   - Use a case statement for clean final selection
