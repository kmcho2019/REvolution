Novel architectural idea: "Operation Pipeline with State Tracking"
1. Instead of computing both operations in parallel, we pipeline the operations based on their type
2. Maintain a 2-bit state to track the current operation mode (shift/count/idle)
3. Advantages:
   - Reduced combinational logic by serializing operations
   - Explicit state tracking makes behavior more predictable
   - Easier to extend for more operations
   - Potentially lower power since only one operation path is active at a time
4. The state machine naturally handles priority (shift takes precedence)
5. Uses a single operation path that's dynamically configured
