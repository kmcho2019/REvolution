Novel architectural idea: Parallel Processing with Operation Selection
1. Instead of sequential if-else, compute both operations in parallel
2. Use a multiplexer to select between shift and count results
3. This approach:
   - Eliminates priority logic by computing both paths simultaneously
   - Potentially improves timing by parallelizing operations
   - Reduces critical path by separating shift and count logic
   - Uses bitwise operations for efficient counting
4. Key features:
   - Shift path: Standard shift register implementation
   - Count path: Conditional decrement using bitwise XOR for toggle logic
   - Final selection based on shift_ena signal
5. Expected benefits:
   - Better timing from parallel computation
   - Lower power from reduced switching in unused paths
   - More balanced logic distribution
