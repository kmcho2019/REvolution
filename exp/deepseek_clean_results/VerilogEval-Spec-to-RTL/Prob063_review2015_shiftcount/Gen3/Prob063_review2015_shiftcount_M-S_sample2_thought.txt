The original solution is already quite simple, but we can make minor optimizations:
1. Remove the else-if structure since priority doesn't matter - this simplifies control logic
2. Combine the enable conditions into a single expression to potentially reduce gate count
3. Maintain the same functionality where shift has priority over count when both are active (though this doesn't affect correctness)

The simplified version will use a single always block with parallel conditions rather than nested if-else, which may lead to slightly better synthesis results in some tools.
