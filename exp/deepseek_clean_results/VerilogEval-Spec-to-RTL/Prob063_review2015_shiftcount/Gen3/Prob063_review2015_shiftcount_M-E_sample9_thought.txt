Here's a novel approach using a parallel load architecture with priority encoding:

1. Instead of using a single multiplexer chain, we'll implement parallel data paths for shift and count operations
2. The shift operation will use a dedicated 4-bit shifter structure
3. The count operation will use a dedicated decrementer
4. A priority encoder will select between these operations based on the enable signals
5. This parallel structure should improve timing by reducing the critical path through the multiplexer chain
6. The design maintains the same functionality but with potentially better performance characteristics
