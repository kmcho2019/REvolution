Here's a refactored version that maintains the same functionality but uses continuous assignments and a different control structure:

1. Instead of using an always block with if-else, we'll:
   - Use a ternary operator for the control logic
   - Keep the parallel computation of next states
   - Implement the selection as a continuous assignment
2. The register update remains edge-triggered
3. Benefits of this approach:
   - More concise code with fewer lines
   - Clearer expression of the selection logic
   - Potentially better synthesis optimization as the mux is explicitly defined
   - Maintains all original functionality and timing characteristics
4. The shift and decrement operations remain identical in behavior
5. Priority remains the same (shift over count when both are active)
