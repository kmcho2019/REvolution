Here's a novel approach using a rotating pointer architecture:

1. Instead of a traditional shift register, we'll implement a circular buffer with a pointer
2. The pointer indicates the current "head" position where new data enters
3. For shift operations: 
   - Data is written at the pointer position
   - Pointer rotates left (MSB first)
4. For count operations:
   - The entire buffer is treated as a number and decremented
   - Pointer remains unchanged
5. Benefits:
   - Eliminates the need for concatenation operations
   - More efficient implementation in hardware
   - Clear separation between shift and count operations
   - Easier to extend to larger widths
6. The pointer itself is implemented as a one-hot encoded register for efficiency
