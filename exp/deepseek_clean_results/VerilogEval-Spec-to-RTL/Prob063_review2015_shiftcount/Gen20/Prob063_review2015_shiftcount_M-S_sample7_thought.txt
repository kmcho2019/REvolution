Simplification approach:
1. Combine the combinational and sequential logic into a single always block
2. Use if-else priority structure based on enable signals
3. Remove intermediate wire since we can directly assign to the register
4. Maintain same functionality with fewer lines of code
5. Still respect clock edge triggering for all operations

Key benefits:
- Reduced code complexity by eliminating separate combinational block
- Fewer signals/wires in the design
- Same functionality with simpler structure
- Still clear operation priority (shift over count when both enabled)
