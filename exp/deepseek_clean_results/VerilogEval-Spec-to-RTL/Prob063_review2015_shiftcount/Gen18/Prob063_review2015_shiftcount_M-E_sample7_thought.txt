Novel Architecture Idea: Parallel Processing with Operation Selection
1. Instead of using conditional operations, implement parallel shift and count operations simultaneously
2. Use a multiplexer to select between the results based on control signals
3. Advantages:
   - Eliminates conditional logic in the datapath, potentially improving timing
   - Both operations can be optimized independently
   - Clear separation of functionality makes synthesis more predictable
4. Implementation:
   - Calculate shifted value in parallel with decremented value
   - Use shift_ena to select between them (count_ena is implied by shift_ena being low)
   - Default to maintaining current value when neither operation is active
