Instead of using separate shift and count logic, we can implement a unified rotating counter that:
1. Uses a single 4-bit register with circular shift capability
2. For shift operations: Rotates left while injecting new data at LSB
3. For count operations: Rotates right (effectively decrementing by 1 in a circular fashion)
4. This approach reduces the logic complexity by reusing the same rotation hardware for both operations
5. The circular nature provides interesting properties like automatic wrap-around
