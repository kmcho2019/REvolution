Refactoring approach:
1. Replace the always block with continuous assignments using combinational logic
2. Use a multiplexer structure to select between shift, count, or hold operations
3. The mux will be controlled by the enable signals (shift_ena and count_ena)
4. Register the output using a separate always block for the sequential element
5. This separates the combinational logic from sequential elements, which can help with synthesis and timing analysis

Key benefits:
- Clear separation of combinational and sequential logic
- More explicit about the selection between operations
- Easier to modify individual operations independently
- Maintains the same functionality while using a different structural approach
