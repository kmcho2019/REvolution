This solution uses a single operation that combines both shift and count functionality through clever bit manipulation:
1. Instead of separate shift and count paths, we create a unified operation
2. For shift: We perform a left shift by 1 and insert the new data bit
3. For count: We subtract 1 using two's complement arithmetic
4. The key insight is that both operations can be expressed as bitwise operations on the register value
5. We use a ternary operator to select between operations, making the implementation more concise
6. This reduces the control logic while maintaining all functionality
