Instead of using a standard shift register with separate counting logic, we can implement a rotating counter that inherently supports both operations:
1. Use a 4-bit register that can rotate right (for shifting) or decrement (for counting)
2. For shift operations: rotate right while inserting new data at the MSB
3. For count operations: use standard decrement logic
4. This approach minimizes the control logic since rotation and decrement can share some circuitry
5. The design naturally handles the case where neither enable is active by maintaining state
6. Since rotation and decrement are both simple operations, this should yield good PPA characteristics
