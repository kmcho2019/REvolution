To optimize the design for better PPA metrics while maintaining functionality:

1. **Timing Improvement**:
   - Simplify the control logic by using a priority encoder structure
   - Remove the implicit priority (shift over count) and make it explicit
   - Combine operations to reduce mux complexity

2. **Power Optimization**:
   - Add clock gating when neither operation is active
   - Use a more efficient decrementer implementation

3. **Area Reduction**:
   - Share common logic between shift and count operations
   - Use a more compact adder structure for the decrement operation

Key changes:
- Explicit priority encoding
- Clock gating for power savings
- Optimized decrement logic
- Cleaner control structure
