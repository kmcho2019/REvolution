The module needs to implement a 4-bit register that can perform two operations:
1. Shift operation: When shift_ena is high, shift in new data from 'data' input MSB first (right shift)
2. Count operation: When count_ena is high, decrement the current value by 1
The operations are mutually exclusive in normal operation, so priority doesn't matter.
We'll use a single always block triggered on posedge clk to handle both operations.
