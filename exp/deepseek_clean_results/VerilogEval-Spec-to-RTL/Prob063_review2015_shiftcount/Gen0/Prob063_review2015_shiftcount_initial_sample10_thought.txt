The module needs to implement a 4-bit register that can operate in two modes:
1. Shift mode (when shift_ena=1): Data is shifted in MSB first, with each bit moving right on each clock edge.
2. Count mode (when count_ena=1): The current value is decremented by 1.

Since the two enable signals are never active simultaneously, we can handle them with simple conditional logic. The register will update on the positive clock edge based on which enable signal is active.
