The module needs to implement a 4-bit register that can operate in two modes:
1. Shift mode (when shift_ena=1): Data is shifted in MSB first, with each bit moving to the right on each clock edge.
2. Count mode (when count_ena=1): The current value is decremented by 1 on each clock edge.

Since the requirements state that shift_ena and count_ena won't be active simultaneously, we don't need to prioritize one over the other. We'll use a simple always block triggered on the positive clock edge to handle both operations.
