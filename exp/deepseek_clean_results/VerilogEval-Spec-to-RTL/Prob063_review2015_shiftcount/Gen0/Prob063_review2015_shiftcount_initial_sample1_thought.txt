The module needs to implement a 4-bit register that can operate in two modes:
1. Shift mode (when shift_ena=1): Data is shifted in MSB first (left shift) with new bit coming from 'data' input
2. Count mode (when count_ena=1): The current value is decremented by 1

The implementation will use a 4-bit register to store the value. On each clock edge:
- If shift_ena is active, perform left shift and insert new bit at LSB
- Else if count_ena is active, decrement the current value
- Otherwise maintain current value
