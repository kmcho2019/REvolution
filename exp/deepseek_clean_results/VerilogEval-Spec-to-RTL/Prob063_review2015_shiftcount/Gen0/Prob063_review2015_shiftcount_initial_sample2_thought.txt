The module needs to implement a 4-bit register that can operate in two modes:
1. Shift mode (when shift_ena=1): Data is shifted in MSB first, with each bit moving to the right
2. Count mode (when count_ena=1): The current value is decremented by 1

Since the control signals are never active simultaneously, we don't need to prioritize one over the other. We'll use a single always block triggered on the positive clock edge to handle both operations. The shift operation will concatenate the input data with the upper 3 bits of the current value. The count operation will simply subtract 1 from the current value.
