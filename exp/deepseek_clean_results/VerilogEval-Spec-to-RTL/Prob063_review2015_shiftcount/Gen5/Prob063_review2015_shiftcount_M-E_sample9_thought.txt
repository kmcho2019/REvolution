Here's a novel approach using a parallel load architecture with operation multiplexing:

1. Instead of modifying the register directly, we'll compute both possible next states (shift and decrement) in parallel
2. Use a single multiplexer to select between these computed values based on the control signals
3. This approach:
   - Reduces critical path by computing both operations in parallel
   - Simplifies timing analysis with clear operation separation
   - Potentially improves power by only activating one computation path
   - Makes the design more scalable for wider registers
4. The shift operation maintains MSB-first behavior
5. The decrement uses simple arithmetic
6. Default case holds value when no operation is requested
