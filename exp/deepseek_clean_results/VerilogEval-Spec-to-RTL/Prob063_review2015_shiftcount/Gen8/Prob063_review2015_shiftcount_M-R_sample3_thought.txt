Refactoring approach:
1. Use continuous assignments (assign) instead of always blocks for combinational logic
2. Separate the next state logic into explicit combinational and sequential parts
3. Create a wire for the next state value
4. Use a single always block for the sequential element (flip-flop)
5. Maintain the same functionality and priority (shift over count)

Key changes:
- Explicit separation of combinational and sequential logic
- Use of continuous assignment for next state calculation
- Single always block for the register update
- Same behavior and priority as original
