This novel design implements a time-multiplexed shift-counter architecture with the following key features:
1. Uses a single arithmetic logic unit (ALU) that performs either shift or count operation each cycle
2. Implements operation selection via a 2:1 multiplexer at the ALU input
3. Employs a priority encoder to resolve simultaneous enable signals (though spec allows any behavior)
4. Features a power-optimized design by disabling ALU when no operation is requested
5. Uses registered outputs for better timing closure

Key innovations:
- ALU-style centralized processing unit instead of separate shift/count paths
- Explicit operation selection logic for cleaner design hierarchy
- Registered outputs improve timing at minimal area cost
- Power gating concept through enable-aware computation
- More scalable architecture for wider implementations
