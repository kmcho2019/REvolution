This implementation uses a finite state machine (FSM) approach combined with parallel computation:

1. Instead of continuous assignments, we'll use a state machine with explicit states for:
   - IDLE (no operation)
   - SHIFT (shift operation active)
   - COUNT (count operation active)
2. The FSM will control which operation gets performed
3. All possible next values are precomputed in parallel:
   - Shifted value
   - Decremented value
   - Current value (hold)
4. The FSM output selects which precomputed value to use
5. Benefits:
   - More explicit control flow
   - Easier to extend with additional operations
   - Clear separation of control and datapath
   - Potentially better for synthesis optimization
6. The FSM naturally handles the "don't care" case when both signals are active
