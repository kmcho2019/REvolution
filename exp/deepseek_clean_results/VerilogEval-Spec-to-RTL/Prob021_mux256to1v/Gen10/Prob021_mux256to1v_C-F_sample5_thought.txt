The fusion strategy combines the strengths of both examples while addressing their weaknesses:

2. From Example 2: Incorporate the default assignment pattern (though optimized) for better simulation safety
3. Optimization: Remove the arithmetic operation (sel*4) by using a more direct bit selection approach
4. Power optimization: Use a case statement instead of if-else chain for potentially better power characteristics
5. Area optimization: Let the synthesis tool choose the best mux implementation by providing clear intent

- Uses a single always block for clear procedural intent
- Employs direct bit selection without multiplication
- Includes a default assignment (though all cases are covered)

- Provides good balance between readability and performance
