Instead of a two-level hierarchy, implement a logarithmic-depth binary tree of 2:1 multiplexers:
1. Create 4 parallel trees (one for each output bit)
2. Each tree has 8 levels (log2(256))
3. At each level, the number of signals is halved
4. The select bits are used progressively at each level
This approach provides balanced timing and scales well for large multiplexers
