Instead of using a single large multiplexer with arithmetic for bit selection, we can implement a two-level hierarchical multiplexer. The first level divides the 1024-bit input into 16 groups of 64 bits (16x 4-bit outputs). The second level then selects between these 16 groups. This reduces the fan-in at each level and may improve timing. The selector is split into two parts: upper 4 bits select the group, lower 4 bits select within the group.
