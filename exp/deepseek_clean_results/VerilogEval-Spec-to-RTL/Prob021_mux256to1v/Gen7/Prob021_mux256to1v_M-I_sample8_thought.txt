To further optimize the PPA metrics, I'll implement a single-level multiplexer with direct indexing. This approach:
1. Eliminates the intermediate array completely, reducing area and power
2. Uses a single calculation for the output selection, improving timing
3. Directly computes the 4-bit slice from the 1024-bit input using sel*4 as the starting index
4. Maintains functionality while simplifying the implementation

The key insight is that we can calculate the exact bit position as (sel * 4) and select the next 4 bits from that position. This removes the need for hierarchical muxing and intermediate storage.
