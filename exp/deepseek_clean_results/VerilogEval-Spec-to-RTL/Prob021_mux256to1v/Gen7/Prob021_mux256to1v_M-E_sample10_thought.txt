Instead of using a hierarchical or direct part-select approach, we can leverage a bitwise selection technique using a loop-based combinatorial logic. The idea is to generate all possible 4-bit outputs in parallel and then use the sel input to enable only the correct output. This approach uses a single always block with a for-loop to compare each possible sel value and assign the corresponding 4-bit slice of 'in' to 'out'. While this may seem less efficient at first glance, modern synthesis tools can optimize this into an efficient multiplexer structure.
