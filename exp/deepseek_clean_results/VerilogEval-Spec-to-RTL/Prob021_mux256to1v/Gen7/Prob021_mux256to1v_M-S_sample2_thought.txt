To simplify the implementation while maintaining functionality, I'll use a direct indexing approach without hierarchical multiplexing. The key observation is that each 4-bit output can be selected by calculating its position in the 1024-bit input vector using the 8-bit selector. 

The position can be calculated as: 
output_bits = in[(sel * 4) +: 4]

This eliminates the need for intermediate wires and generate blocks, resulting in a more straightforward and compact implementation. The calculation is done in a single step, which should also be efficient for synthesis.
