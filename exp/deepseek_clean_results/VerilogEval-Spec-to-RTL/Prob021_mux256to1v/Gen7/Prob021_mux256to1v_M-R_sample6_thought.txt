The original solution uses a hierarchical approach with an intermediate array, which is good for PPA. I'll refactor it to:
1. Eliminate the intermediate array by directly computing the output index
2. Use a single continuous assignment with proper bit selection
3. Maintain the same hierarchical concept but implement it more concisely
4. Use a single mathematical expression to calculate the selected bits

The key insight is that we can compute the exact bit range needed using sel*4 as the starting point, since each 4-bit group is contiguous in the input vector. This removes the need for intermediate storage while keeping the same functionality.
