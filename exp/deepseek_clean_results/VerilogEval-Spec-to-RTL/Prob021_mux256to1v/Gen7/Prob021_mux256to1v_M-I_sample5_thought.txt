To further optimize the PPA metrics, I'll implement a single-level multiplexer with direct indexing. This approach:
1. Eliminates the intermediate array completely, reducing area and power
2. Uses a single calculation for the output selection, improving timing
3. Directly computes the output using bit selection with a concatenated index
4. Reduces switching activity by avoiding unnecessary intermediate storage
5. Simplifies the design to a single assignment statement

The key insight is that we can calculate the exact bit range needed using the sel input multiplied by 4 (since each selection is 4 bits). This gives us the starting index, and we simply take the next 4 bits from that position.
