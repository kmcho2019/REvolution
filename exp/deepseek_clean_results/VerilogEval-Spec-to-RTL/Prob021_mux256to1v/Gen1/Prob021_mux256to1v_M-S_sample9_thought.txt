To simplify the implementation while maintaining functionality, we can:
1. Replace the multiplication (sel*4) with a left shift (sel << 2) which is more hardware-efficient
2. Keep the part-select operation but now using the shifted value
3. Maintain the same interface and functionality but with potentially better PPA characteristics

The shift operation is simpler than multiplication in hardware, and the part-select with constant width (+:4) remains clean and readable.
