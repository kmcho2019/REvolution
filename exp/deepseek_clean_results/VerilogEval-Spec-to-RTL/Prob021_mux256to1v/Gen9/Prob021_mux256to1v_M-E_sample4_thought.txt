Here's a novel approach using a hierarchical decoder-based multiplexer:
1. First decode the 8-bit sel into 256 one-hot select lines
2. Then use AND-OR logic to select the appropriate 4-bit output
3. The AND-OR logic will perform bitwise AND between each 4-bit input chunk and its select line, then OR all results together
4. This approach eliminates arithmetic operations and uses parallel selection logic
5. The one-hot decoding ensures only one path is active at a time, potentially improving power characteristics
