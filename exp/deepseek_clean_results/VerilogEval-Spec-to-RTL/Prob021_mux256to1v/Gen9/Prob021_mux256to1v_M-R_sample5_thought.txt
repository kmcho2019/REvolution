The original solution uses a two-level hierarchical approach with intermediate wire arrays. We can simplify this by directly computing the output selection in a single continuous assignment. This eliminates the need for intermediate wire arrays and reduces the logic depth to just one level. The key insight is that we can calculate the exact bit position by multiplying the selector by 4 (since each selection is 4 bits wide) and then use the part-select operator to grab the correct 4-bit chunk.
