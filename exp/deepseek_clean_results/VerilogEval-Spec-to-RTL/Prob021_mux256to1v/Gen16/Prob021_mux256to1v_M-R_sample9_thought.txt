The current implementation uses a hierarchical approach with 16 groups of 16 4-bit inputs. While effective, we can simplify this further by:
1. Eliminating the intermediate wire array and generate block
2. Using a single direct selection calculation
3. Maintaining the same hierarchical concept but with simpler syntax
4. The key insight is that we can compute the exact bit position directly from sel without intermediate steps
5. This reduces the number of wires and makes the code more concise while preserving the same functionality
