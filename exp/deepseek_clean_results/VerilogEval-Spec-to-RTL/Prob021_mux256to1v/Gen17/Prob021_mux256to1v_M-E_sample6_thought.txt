Instead of using multiplexers, we can implement the selection using a barrel shifter approach:
1. Treat the 1024-bit input as a single vector
2. Calculate the starting position of the desired 4-bit output based on sel
3. Use a right shift operation to align the desired bits to the LSB positions
4. Extract the 4 LSBs as the output
This approach leverages bit manipulation operations which can be efficiently implemented in hardware and may offer better PPA characteristics in some technologies
