To simplify the implementation while maintaining functionality, we can use a direct indexing approach without hierarchical multiplexing. The key observation is that each 4-bit output can be selected by calculating its position directly from the sel input. 

The formula for the starting bit position is: sel * 4
This gives us the exact 4-bit slice we need from the 1024-bit input vector. We can use Verilog's bit-slicing operation to select these 4 bits directly.

This approach:
1. Eliminates the intermediate array and generate block
2. Uses a single calculation for the output selection
3. Reduces the logic to a simple bit selection operation
4. Maintains the same functionality with cleaner code
