The current implementation is already quite simple and efficient, but we can make it even more straightforward by:

1. Eliminating the multiplication operation and replacing it with a simple shift operation (sel << 2), which is equivalent to multiplying by 4 but is more fundamental in hardware
2. Using direct bit selection with the shifted value to pick the 4-bit output
3. Maintaining the same functionality while making the code slightly more readable and potentially more efficient in some synthesis tools

This simplification:
- Removes the multiplication operation
- Uses basic bit manipulation
- Keeps the same clean single-line assignment
- Preserves all functionality
