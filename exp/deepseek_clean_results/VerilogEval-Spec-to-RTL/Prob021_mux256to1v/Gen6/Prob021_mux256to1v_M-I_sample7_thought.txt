To further optimize the PPA metrics, I'll implement a single-level multiplexer with direct indexing. This approach:
1. Eliminates the intermediate array completely, reducing area and power
2. Uses a single calculation for the output selection, improving timing
3. Leverages Verilog's bit selection capabilities more efficiently
4. Reduces switching activity by removing unnecessary intermediate signals

The key insight is that we can calculate the exact bit range needed using the sel input directly, without hierarchical decomposition. The formula for the selected bits is:
out = in[(sel * 4) +: 4]

This single operation performs the same function more efficiently.
