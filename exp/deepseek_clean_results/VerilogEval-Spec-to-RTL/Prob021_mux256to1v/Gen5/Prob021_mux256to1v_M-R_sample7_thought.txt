The original solution uses a two-stage hierarchical approach with intermediate wires for grouping. We can simplify this by directly calculating the output using a single assignment with bit-slicing, while maintaining the same functionality. This eliminates the need for the intermediate `group` array and reduces the number of assignments, potentially improving power and area. The key insight is that the 4-bit output can be directly selected from the 1024-bit input by treating `sel` as an index that points to the starting bit of the desired 4-bit chunk (calculated as `sel*4`).
