The previous solution uses a two-level hierarchical approach which adds unnecessary complexity. We can simplify this by directly computing the output selection in a single step using bit selection with the sel input. Since each 4-bit output is selected by multiplying the sel value by 4, we can simply use the sel input as an index and select the appropriate 4-bit slice from the 1024-bit input. This eliminates all intermediate wires and reduces the logic to a single continuous assignment.
