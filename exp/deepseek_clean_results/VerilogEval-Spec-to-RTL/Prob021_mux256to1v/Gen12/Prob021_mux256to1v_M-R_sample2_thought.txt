The core idea remains hierarchical multiplexing, but we can optimize the implementation by:
1. Eliminating the intermediate array to reduce area
2. Using a single calculation for the output selection
3. Maintaining the same two-level selection logic but combining it into a direct assignment

The key insight is that we can compute the final 4-bit selection directly from the input vector by calculating the appropriate bit range based on the concatenation of sel[7:4] and sel[3:0]. This avoids the need for intermediate storage while keeping the same logical structure.
