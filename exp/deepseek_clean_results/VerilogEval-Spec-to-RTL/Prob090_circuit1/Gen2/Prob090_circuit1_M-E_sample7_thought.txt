Instead of using a direct AND gate implementation, let's create a more interesting solution using a multiplexer-based approach. The idea is to use input 'b' as the select line for a 2:1 mux, where:
- When b=0, the output q is always 0 (regardless of a)
- When b=1, the output q follows input a

This effectively implements the same AND functionality but through a different architectural approach, demonstrating how the same logic can be achieved through different circuit structures.
