The original implementation is already optimal for a simple AND gate function. However, we can make one minor improvement by using a continuous assignment instead of an always block. This change:
1. Makes the code slightly more concise
2. Eliminates the need for a reg type output (uses wire instead)
3. May result in marginally better synthesis in some tools as it directly represents the gate-level operation
4. Maintains exactly the same functionality while being more idiomatic for simple combinational logic
