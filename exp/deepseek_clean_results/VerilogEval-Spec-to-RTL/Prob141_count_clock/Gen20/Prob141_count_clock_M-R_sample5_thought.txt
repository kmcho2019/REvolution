Refactoring Strategy:
1. State Machine Approach:
   - Replace parallel counters with a unified state machine that tracks time progression
   - Use enumerated states for clearer state transitions
   - Combine all timekeeping logic into a single always block

2. Output Generation:
   - Move BCD conversion to continuous assignments for cleaner separation
   - Simplify hour representation by using a single 4-bit register (1-12)

3. PM Indicator:
   - Implement as a simple toggle on the 11->12 transition
   - Keep combinational output assignment

Key Benefits:
- More maintainable state machine structure
- Clearer state transition logic
- Reduced dependency chains between counters
- Better separation between timekeeping and output formatting
