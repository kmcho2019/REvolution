Novel approach: Unified Counter with Time Decoding
1. Use a single 32-bit counter to track total seconds since reset
2. Implement time decoding logic to convert seconds to hh:mm:ss format
3. Advantages:
   - Single counter simplifies state management
   - Eliminates cascaded counter dependencies
   - Easier to implement additional features (like alarms)
   - More efficient for long-term timekeeping
4. Time decoding:
   - Seconds = total_seconds % 60
   - Minutes = (total_seconds / 60) % 60
   - Hours = ((total_seconds / 3600) % 12) + 1
5. PM detection based on whether we're in the second half of the 24-hour cycle
6. Reset forces counter to 0 (12:00 AM)
7. BCD conversion done in combinational logic
