Refactoring Strategy:
1. Convert sequential logic to combinational where possible:
   - Move BCD conversion logic to continuous assignments
   - Simplify PM toggle logic using XOR

2. Restructure counters:
   - Split BCD counters into separate tens/units registers
   - Use parallel rollover detection with cleaner structure

3. Optimize state updates:
   - Combine related operations in single always blocks
   - Use clearer increment/rollover conditions

Key Improvements:
- More combinational logic reduces sequential elements
- Split BCD digits improve readability and timing
- Simplified PM toggle logic (XOR instead of conditional)
- Clearer rollover conditions with parallel detection
- Maintain same functionality with cleaner structure
