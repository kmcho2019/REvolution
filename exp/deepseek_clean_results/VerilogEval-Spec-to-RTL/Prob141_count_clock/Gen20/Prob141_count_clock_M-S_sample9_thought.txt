Simplified design approach:
1. Use single always block for all counters to reduce complexity (while maintaining functionality)
2. Combine hour digit registers into a single 5-bit register (1-bit for 10s, 4-bit for 1s)
3. Simplify PM logic by toggling only at 11:59:59 -> 12:00:00 transition
4. Remove intermediate rollover signals and compute directly in counter logic
5. Use simple BCD counting with automatic rollover
6. Maintain clear reset priority and enable conditions

Key simplifications:
- Single always block reduces state machine complexity
- Combined hour register simplifies hour counting
- Direct PM toggle at specific time point
- Eliminated redundant rollover signals
- Simplified BCD counting logic
