Refactoring Strategy:
1. Convert sequential logic to combinational where possible:
   - Move PM indicator to combinational logic based on current hour
   - Simplify hour counter by making it pure BCD (eliminates conversion logic)

2. Optimize enable conditions:
   - Use nested if-else structure to prioritize reset and minimize logic depth
   - Combine related conditions to reduce redundant evaluations

3. Improve PPA by:
   - Reducing critical path through simpler hour counter logic
   - Eliminating BCD conversion overhead by using direct BCD counters
   - Simplifying PM indicator to depend only on current hour value

Key Changes:
- Direct BCD implementation for all counters (simpler than binary+conversion)
- PM indicator becomes purely combinational function of hour value
- Single always block for all counters with priority-ordered conditions
- Simplified hour rollover logic by treating as pure BCD counter
