Novel Architecture:
1. State Machine Approach:
   - Use a 4-state FSM to track clock progression (IDLE, SEC, MIN, HOUR)
   - Each state handles its respective counter update with optimized conditions
   - Reduces combinatorial logic depth by separating concerns

2. Parallel BCD Arithmetic:
   - Implement custom BCD incrementers for each digit pair
   - Use pre-computed carry signals to minimize critical path
   - Special handling for 12-hour rollover

3. Optimized PM Logic:
   - Track AM/PM state separately with minimal transitions
   - Only update during hour transitions to reduce power

4. Unified Reset Logic:
   - Single reset handling block that feeds all counters
   - Minimizes redundant reset paths

Key Benefits:
- Reduced critical path through state-based processing
- Lower power consumption via minimized transitions
- Simplified verification due to clear state separation
- Better scalability for future modifications
