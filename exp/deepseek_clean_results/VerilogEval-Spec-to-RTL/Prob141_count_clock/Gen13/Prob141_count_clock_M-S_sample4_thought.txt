Simplification Strategy:
1. Combine all counters into a single always block for better synchronization and simpler control flow
2. Remove intermediate rollover signals and compute conditions directly in the counter logic
3. Simplify hour counter by using a single 4-bit register (1-12) with direct BCD conversion
4. Make PM indicator purely combinational based on hour value for simpler logic
5. Maintain packed BCD format for minutes and seconds but handle rollover more directly

Key Improvements:
- Single always block for all sequential logic
- Direct rollover handling without intermediate signals
- Combinational PM output based on hour value
- Simplified hour counter with direct BCD conversion
- Reduced control logic complexity
