Novel architectural approach:
1. Use a single unified 32-bit counter that increments every enabled clock cycle
2. Extract time components (ss, mm, hh) through division/modulo operations
3. Implement AM/PM tracking via a separate state bit that toggles at noon/midnight
4. Use combinational logic to convert the counter value to BCD outputs
5. Reset synchronizes the counter to 12:00 AM position
6. Enable gates the counter increment

Key advantages:
- Single counter reduces register count
- Division/modulo operations simplify state transitions
- AM/PM tracking becomes trivial with counter-based approach
- Output conversion is purely combinational
- Easier to extend for future features (alarms, etc.)
