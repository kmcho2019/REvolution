Refactoring Strategy:
1. Convert all counters to use explicit increment signals for better timing control
2. Implement hour counter as a state machine with explicit transitions
3. Use combinational logic for all rollover conditions to simplify sequential blocks
4. Move PM indicator logic to be purely combinational based on hour state
5. Use continuous assignments for all outputs to reduce register usage
6. Centralize reset logic for better maintainability

Key Improvements:
- Simplified sequential blocks by moving complex logic to combinational
- More explicit state transitions for hour counter
- Reduced clock-to-Q delay by minimizing logic in sequential blocks
- Clearer separation between control and datapath logic
