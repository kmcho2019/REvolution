Refactoring Strategy:
1. Split the monolithic counter logic into separate always blocks for each time unit (seconds, minutes, hours) to improve readability and reduce critical path
2. Use simpler BCD increment logic with helper signals for rollover conditions
3. Move PM toggle logic to a separate always block triggered by hour changes
4. Simplify output assignments by removing unnecessary conditional operators
5. Use clearer signal names for intermediate rollover conditions
6. Maintain synchronous reset priority while making the structure more modular

Key Improvements:
- Reduced critical path by parallelizing counter logic
- Clearer separation of concerns between different time units
- More maintainable code structure
- Same functionality with better timing characteristics
