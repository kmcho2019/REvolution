Refactoring Strategy:
1. State Machine Restructuring:
   - Convert the hour counter into an explicit state machine with 12 states
   - Use one-hot encoding for the hour states to simplify PM toggling logic
   - Combine all counter logic into a single always block for better synthesis optimization

2. Output Generation:
   - Replace combinational hr_tens/hr_ones with registered outputs
   - Move all output assignments to registers to reduce combinational paths

3. Timing Optimization:
   - Register the rollover signals to break long combinational paths
   - Simplify hour increment logic by using state transitions

Key Changes:
- Single always block for all sequential logic
- One-hot hour state encoding
- Registered outputs and rollover signals
- Simplified PM toggle using state transitions
