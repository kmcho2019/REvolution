Novel Architectural Idea: "Decoupled Time Unit Counters with State Machine Control"

Key Innovations:
1. Decoupled counters for each time unit (hours, minutes, seconds) with independent enable signals
2. Finite State Machine (FSM) to coordinate counter increments and rollovers
3. Unified BCD increment logic shared across all counters
4. PM indicator integrated into hour counter state
5. Preemptive rollover prediction to minimize combinatorial paths

Advantages:
- Clear separation of concerns between time units
- Reduced combinatorial logic through state-based control
- Shared BCD increment logic reduces area
- Predictable timing behavior from FSM
- Easier to extend/modify (e.g., add alarm functionality)
