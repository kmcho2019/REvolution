Novel Architecture: Unified Counter with Time Decoding
1. Single Counter Approach:
   - Use one large counter (32-bit) to track total seconds since reset
   - Eliminates multiple cascaded counters and their synchronization logic
   - Simplifies reset and enable handling

2. Time Decoding Logic:
   - Convert total seconds to hours, minutes, seconds via division/modulo
   - Implement efficient BCD conversion using parallel operations
   - Generate AM/PM signal based on decoded hour value

3. Key Advantages:
   - Reduced state elements (only one main counter)
   - Simplified control logic (no cascaded rollovers)
   - Easier timing closure with single critical path
   - More flexible for future extensions (e.g., date tracking)
