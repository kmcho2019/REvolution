Refactoring Strategy:
1. Replace sequential logic with combinational where possible:
   - Use continuous assignments for rollover signals
   - Make BCD conversions fully combinational
   - Simplify state transitions using ternary operators

2. Optimize timing paths:
   - Pre-calculate rollover conditions to reduce critical path
   - Register intermediate rollover signals to break long combinational paths

3. Power optimizations:
   - Gate all counter logic with 'ena' to prevent unnecessary toggling
   - Use registered outputs for stable signals

4. Structural changes:
   - Replace some always blocks with assign statements
   - Use more modular expressions for clarity
   - Combine related operations where possible

Key Improvements:
- Reduced combinational path length through registered rollovers
- More efficient BCD conversion logic
- Clearer separation of combinational and sequential logic
- Better power gating through ena usage
