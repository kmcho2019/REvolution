Optimization Strategy:
1. Timing Improvement: Simplify the hour counter logic by using a single 4-bit hour counter (1-12) and decode to BCD format, reducing comparison complexity
2. Power Optimization: Gate the rollover logic with 'ena' to prevent unnecessary switching when disabled
3. Area Reduction: Share common BCD increment logic between seconds, minutes, and hours
4. PM Detection: Move PM toggle to a separate always block triggered only on hour changes
5. Critical Path: Flatten the counter hierarchy by separating second/minute/hour increments into parallel processes

Key Changes:
- Single hour counter with BCD decoding
- Gated rollover signals
- Shared BCD increment logic
- Isolated PM detection
- Parallel counter updates
