Instead of using separate BCD counters, this design employs:
1. A single 17-bit counter that tracks total seconds since midnight (0-43199)
2. A state machine to decode this into hours, minutes, seconds
3. Time calculations done in binary then converted to BCD at output
4. PM detection via simple comparison
Benefits:
- Reduced logic depth (no cascaded BCD counters)
- Single counter simplifies rollover logic
- Binary arithmetic is more efficient than BCD
- Output conversion happens only when needed
- Easier to extend for future features (alarms, etc.)
