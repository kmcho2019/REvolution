1. Timing Optimization:

   - Move the PM toggle logic to a separate always block triggered by hour rollover
   - Use simpler comparison logic for hour counter transitions

2. Power Optimization:

   - Simplify BCD increment logic to reduce bit toggling
   - Use direct assignments for all outputs

3. Area Optimization:
   - Combine digit registers into packed arrays
   - Share comparison logic between hour counter and PM indicator
   - Simplify the hour counter state machine

- Separate always blocks for each counter (seconds, minutes, hours)
