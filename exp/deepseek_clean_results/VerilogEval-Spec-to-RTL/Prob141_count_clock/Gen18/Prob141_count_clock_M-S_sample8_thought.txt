Simplified 12-hour clock design approach:
1. Use single always block for all counters to maintain synchronization
2. Implement seconds and minutes as simple BCD counters (00-59)
3. Simplify hour counter by treating it as 1-12 directly (no 24-hour conversion)
4. Toggle PM indicator when hours go from 11 to 12
5. Reset to 12:00:00 AM synchronously
6. Only update counters when enabled (ena)

Key simplifications:
- Combined all counter logic into one always block
- Reduced hour counter complexity by directly handling 1-12 range
- Simplified PM logic to single toggle condition
- Maintained clear priority: reset > ena > counting
- Used straightforward BCD counting for all digits
