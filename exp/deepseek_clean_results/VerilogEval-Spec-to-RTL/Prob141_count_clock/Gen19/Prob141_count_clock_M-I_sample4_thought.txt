Improvement Strategy:
1. Timing Optimization:
   - Break down the cascaded if-else into parallel conditions for each counter
   - Simplify hour counter logic by using separate always blocks
   - Use pre-calculated rollover signals to reduce critical path

2. Power Optimization:
   - Add enable conditions for each register to prevent unnecessary updates
   - Only update PM indicator when it actually changes (once per 12 hours)

3. Area Optimization:
   - Combine BCD digits into single registers where possible
   - Use minimum required bit widths for all counters
   - Simplify comparison logic for hour transitions

Key Changes:
- Separate always blocks for each counter with their own enable signals
- Simplified hour counter with clear state transitions
- Optimized BCD digit storage
- Reduced logic complexity for better timing
