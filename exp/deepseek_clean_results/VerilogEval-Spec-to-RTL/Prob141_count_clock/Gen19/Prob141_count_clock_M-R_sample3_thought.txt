Refactored design approach:
1. Use separate always blocks for each digit (ss_lo, ss_hi, mm_lo, mm_hi) to flatten logic hierarchy
2. Implement hour counter as two separate BCD digits (1-9 and 0-1) to eliminate BCD conversion logic
3. Use explicit carry signals between counters for better timing
4. Register all outputs to improve timing closure
5. Simplify PM logic by toggling only at 11->12 transition
6. Optimize register sizes to exactly match needs (4-bit for digits 0-9, 3-bit for digits 0-5)

Key improvements:
- Flattened logic structure reduces critical path
- Pre-computed BCD digits eliminate conversion logic
- Registered outputs improve timing
- Smaller register sizes save area
- Explicit carry signals make timing more predictable
