Refactored design approach:
1. Split counters into separate always blocks for better timing
2. Use explicit rollover signals between counters
3. Simplify hour counter logic by treating it as a 4-bit value (1-12)
4. Use combinational logic for PM indicator based on hour value
5. Maintain same BCD encoding but with cleaner separation
6. Keep reset priority but make enable logic more modular

Key improvements:
- Separated counter logic reduces critical path
- Clearer rollover signaling between counters
- Simplified hour counter with direct 1-12 range
- PM indicator as combinational function of hours
- More modular structure while maintaining same functionality
