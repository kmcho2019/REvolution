Simplification Strategy:
1. Merge BCD digit handling: Combine tens and units digit updates into single operations for seconds and minutes
2. Simplify hour counter: Use direct BCD encoding (4 bits per digit) to eliminate conversion logic
3. Optimize PM logic: Make it dependent only on hour changes, not intermediate values
4. Reduce conditionals: Use simpler rollover detection and increment logic
5. Maintain same interface and functionality while reducing internal complexity

Key Improvements:
- Fewer registers by using direct BCD encoding
- Simplified control logic with less conditional branching
- Maintained same timing characteristics with cleaner structure
- Reduced area by eliminating conversion logic
