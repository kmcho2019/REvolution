Novel architectural approach using a unified counter with state encoding:
1. Represent the entire clock state (hh, mm, ss, pm) as a single encoded value
2. Use a large counter that increments by 1 each second (ena)
3. Decode this counter value to extract all outputs
4. Implement rollover logic at 12:59:59 PM → 01:00:00 AM
5. Use BCD encoding only at the output stage

Key advantages:
- Single always block simplifies control logic
- Encoded state reduces condition checks
- Output decoding happens in parallel
- Easier to extend/modify timing constraints
- More efficient for synthesis/optimization
