Simplification Strategy:
1. Unified Counter Logic:
   - Use a single always block for all counters to reduce redundant logic
   - Eliminate intermediate rollover flags by checking conditions directly

2. Simplified BCD Handling:
   - Keep BCD encoding but simplify digit handling
   - Remove separate binary hour counter by using BCD throughout

3. Reduced State Elements:
   - Combine PM and hour handling into single logic
   - Remove pre-computed BCD digits by handling them directly in counter

Key Simplifications:
- Single always block for all counters
- Direct BCD handling without intermediate conversions
- Simplified rollover logic by checking conditions directly
- Fewer state elements and less combinatorial logic
