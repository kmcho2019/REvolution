Instead of nested if-else structures, we'll implement a finite state machine that controls the clock increments. The key innovations are:
1. Separate counters for each digit (hour tens, hour ones, minute tens, etc.)
2. A state machine that coordinates the rollover between digits
3. Pre-computed next values for each digit to simplify the logic
4. Special handling for the 12-hour wrap and AM/PM toggle
5. All digit counters use BCD encoding and roll over appropriately
6. The state machine ensures correct sequencing of increments
