To simplify the clock implementation while maintaining functionality:
1. Use direct BCD counters for seconds and minutes to eliminate binary-to-BCD conversion
2. Simplify hour counting by tracking 1-12 directly with a separate AM/PM flag
3. Combine all counter logic into a single always block for better readability
4. Remove intermediate binary counters and conversion functions
5. Maintain synchronous reset with highest priority
6. Keep the same interface and 12-hour AM/PM functionality

The simplified design will:
- Use BCD counters directly for seconds and minutes (two 4-bit digits each)
- Track hours as BCD digits (01-12) with a simple PM flag
- Increment counters only when enabled
- Reset to 12:00 AM when reset is asserted
