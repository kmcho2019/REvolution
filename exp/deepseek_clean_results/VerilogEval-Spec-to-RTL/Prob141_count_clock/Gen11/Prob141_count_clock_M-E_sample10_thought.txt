Novel Architectural Idea: Hierarchical State Machine with Parallel Counters

Key Innovations:
1. Decoupled counting logic using parallel always blocks for each time unit (hours, minutes, seconds) to improve timing
2. State machine approach for hour counting with explicit AM/PM states
3. Pre-computed rollover signals to minimize critical path
4. Optimized BCD counting using parameterized helper functions
5. Power gating through enable signal propagation

Advantages:
- Parallel processing reduces critical path length
- Explicit state machine makes hour transitions clearer
- Modular design allows for easier timing constraints
- Reduced switching activity through conditional updates
- Better clock gating opportunities for power savings
