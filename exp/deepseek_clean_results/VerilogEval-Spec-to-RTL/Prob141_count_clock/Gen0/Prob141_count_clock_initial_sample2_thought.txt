To implement a 12-hour clock with AM/PM indicator, we need to create three counters for hours, minutes, and seconds. Each counter will be in BCD format (two digits per counter). The design will:
1. Use synchronous reset (highest priority)
2. Increment counters only when enabled (ena)
3. Handle BCD rollover correctly for each counter:
   - Seconds: 00-59
   - Minutes: 00-59
   - Hours: 01-12 with AM/PM toggle at 12
4. Output the current time in BCD format with PM indicator
