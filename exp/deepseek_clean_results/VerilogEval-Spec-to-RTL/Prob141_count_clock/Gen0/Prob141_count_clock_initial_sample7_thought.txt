To implement a 12-hour clock with AM/PM indicator, we need to create three counters for hours, minutes, and seconds. Each counter should be in BCD format (two digits per counter). The design will:
1. Use synchronous reset (highest priority) to set time to 12:00 AM
2. Increment seconds when ena is high, rolling over to minutes when seconds reach 59
3. Increment minutes when seconds roll over, rolling over to hours when minutes reach 59
4. Increment hours when minutes roll over, handling the 12-hour format and AM/PM toggle
5. Output the current time in BCD format along with PM indicator
