To implement a 12-hour clock with AM/PM indicator, we need to create three main counters for hours, minutes, and seconds. Each counter needs to handle BCD values (0-9 for each digit) and proper rollover behavior:

1. Seconds counter (ss): Counts from 00 to 59, then rolls over to 00 and increments minutes
2. Minutes counter (mm): Counts from 00 to 59, then rolls over to 00 and increments hours
3. Hours counter (hh): Counts from 01 to 12, then toggles AM/PM and resets to 01

The design will use synchronous reset (highest priority) and enable signals. All counters will be implemented using BCD digits (4 bits per digit) with proper carry logic between digits.
