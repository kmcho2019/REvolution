To implement a 12-hour clock with AM/PM indicator, we need to create three counters for hours, minutes, and seconds. Each counter should be in BCD format (two 4-bit digits per counter). The design will:
1. Use synchronous reset (highest priority) to initialize to 12:00 AM
2. Increment seconds when enabled, rolling over to minutes at 59
3. Increment minutes when seconds roll over, rolling over to hours at 59
4. Increment hours when minutes roll over, handling 12-hour format with AM/PM toggle
5. Generate PM signal based on hour counter (PM when hours >= 12)
6. Output BCD values for hh, mm, ss
