To improve the design, I'll refactor with these optimizations:
1. Separate counters into individual always blocks with cascaded enables to break long timing paths
2. Simplify hour counting by using a 4-bit binary counter (1-12) and convert to BCD at output
3. Move PM indicator to separate logic that only updates on hour changes
4. Use cleaner BCD increment logic with helper signals for rollover conditions
5. Make reset values more explicit with parameters
This maintains the same functionality while improving timing and readability.
