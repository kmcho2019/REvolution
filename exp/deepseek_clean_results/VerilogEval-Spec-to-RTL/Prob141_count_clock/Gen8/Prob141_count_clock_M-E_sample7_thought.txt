Instead of nested counters, we'll implement a finite state machine that controls three separate BCD counter modules (for hours, minutes, seconds). The key innovations are:
1. Modular design with separate counter instances for better hierarchy
2. State machine to coordinate counter increments and rollovers
3. Simplified hour handling using a 4-bit binary counter (1-12) converted to BCD
4. Dedicated rollover detection logic for cleaner timing paths
5. PM indicator derived directly from hour count comparison
