Innovative approach features:
1. Unified time counter: Store entire time in a single 32-bit register (seconds since midnight) for simpler arithmetic
2. Time decoding: Convert from seconds to BCD format only when needed (output stage)
3. State machine: Use explicit states for AM/PM transitions to simplify logic
4. Lazy evaluation: Only update time register when enabled, reducing power
5. Optimized BCD conversion: Pre-compute digit splits using division/modulus

Key advantages:
- Single time register reduces sequential elements
- State machine makes AM/PM transitions explicit and clear
- Output conversion happens in parallel with counting
- Easier to extend/modify (e.g., for 24-hour format)
- Reduced combinatorial paths by separating counting and display logic
