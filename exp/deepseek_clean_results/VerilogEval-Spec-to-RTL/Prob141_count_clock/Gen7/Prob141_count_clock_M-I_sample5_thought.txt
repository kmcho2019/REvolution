Improvement Strategy:
1. Timing Optimization:
   - Flatten the nested if-else structure by separating counters into parallel always blocks
   - Move PM toggle logic to a separate condition check to reduce critical path
   - Use simpler comparison logic for hour transitions

2. Power Optimization:
   - Remove conditional output assignments that cause unnecessary switching
   - Simplify BCD increment logic to reduce transitions
   - Combine digit registers into packed arrays for better power characteristics

3. Area Optimization:
   - Use packed arrays for BCD digits to reduce routing overhead
   - Share comparison logic between hour counter and PM indicator
   - Simplify the hour counter state machine

Key Changes:
- Separate always blocks for each counter (sec, min, hour)
- Simplified hour counter with direct BCD arithmetic
- Combined digit registers into packed arrays
- Removed conditional output assignments
- Optimized PM toggle logic
