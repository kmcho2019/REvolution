Novel Architecture: State Machine with Unified Counter Logic
1. Unified Counter Approach:
   - Use a single 32-bit counter to track total seconds since reset
   - Eliminate separate digit counters and rollover logic
   - Convert to time format only when needed (output stage)

2. Smart BCD Conversion:
   - Implement optimized division/modulo operations for time conversion
   - Use arithmetic tricks for efficient BCD conversion
   - Only perform conversions when outputs are read

3. State Machine Control:
   - Different states for AM/PM tracking
   - Special handling for 12-hour rollover
   - Reset state handles initialization cleanly

Key Advantages:
- Reduced logic complexity by eliminating intermediate rollover signals
- Lower power consumption since most logic is only active during output
- Simplified timing paths with centralized counter
- Easier to modify for different time formats
