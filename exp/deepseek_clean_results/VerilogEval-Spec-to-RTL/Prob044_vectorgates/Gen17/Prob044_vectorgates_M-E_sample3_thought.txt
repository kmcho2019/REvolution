Novel Hierarchical Architecture:
1. Break down operations into dedicated sub-modules for better isolation and optimization potential
2. Use a bit-serial approach for logical OR to minimize hardware (though width is small, demonstrates scalability)
3. Implement NOT operations using dedicated inverters for clarity
4. Use explicit wire declarations for better readability and debugging
5. Separate the vector concatenation into its own logical unit
6. Key innovations:
   - Dedicated OR module that can be optimized separately
   - Bit-serial logical OR computation (scalable to wider vectors)
   - Explicit NOT gates for educational clarity
   - Clean signal routing between modules
   - Potential for individual clock gating of each operation block
