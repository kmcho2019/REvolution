Novel Architectural Idea: "Parallel Processing with Shared Logic"

1. Key Innovations:
   - Eliminates separate modules by using direct parallel processing
   - Implements all operations in a single always block for potential synthesis optimization
   - Uses concatenation for NOT operations to minimize logic duplication
   - Logical OR is computed from the bitwise OR result (shared logic)

2. Advantages:
   - Reduced hierarchy overhead by flattening operations
   - Potential area savings by reusing intermediate results
   - Simplified verification with all operations visible in one block
   - Clear data flow from inputs to outputs

3. Implementation Details:
   - Bitwise OR computed directly
   - Logical OR derived from bitwise result (efficient reduction)
   - NOT operations combined through concatenation
   - Explicit width declarations for clarity
   - Minimal gate delay path for all operations
