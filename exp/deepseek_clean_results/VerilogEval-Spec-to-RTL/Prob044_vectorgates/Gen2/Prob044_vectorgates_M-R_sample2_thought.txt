I'll refactor the solution to use continuous assignments (assign statements) instead of explicit gate instantiations while maintaining the same functionality. This approach:

1. Uses Verilog bitwise operators for the OR operations
2. Employs reduction OR for the logical OR

Benefits of this refactoring:
- More concise and readable code
- Lets synthesis tools optimize the implementation
- Maintains identical functionality
- Reduces explicit gate count in RTL
- Potentially better for technology mapping
