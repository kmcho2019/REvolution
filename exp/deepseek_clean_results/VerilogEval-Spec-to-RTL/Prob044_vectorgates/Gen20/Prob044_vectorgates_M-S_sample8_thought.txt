Simplification Strategy:
1. Eliminate submodules - Implement all operations directly in TopModule since they're simple enough
2. Remove parameterization - Use fixed 3-bit widths as specified in requirements
3. Direct assignments - Use simple continuous assignments for all operations
4. Maintain same functionality - Keep the exact same output behavior as original
5. Reduce hierarchy - Single module implementation reduces overhead

Key Benefits:
- Fewer lines of code
- No module instantiation overhead
- Easier to read and maintain
- Same functionality with less complexity
