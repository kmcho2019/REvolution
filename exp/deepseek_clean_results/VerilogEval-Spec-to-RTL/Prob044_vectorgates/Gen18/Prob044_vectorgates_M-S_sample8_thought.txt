Simplified Design Approach:
1. Eliminate submodules since operations are simple enough to implement directly in the main module
2. Perform all operations using continuous assignments:
   - Bitwise OR: Direct 3-bit OR operation
   - Logical OR: OR-reduce both inputs and combine with logical OR
   - Vector NOT: Concatenate inverted b and a vectors
3. This reduces hierarchy overhead while maintaining clear, readable code
4. All operations remain purely combinational with minimal logic depth
