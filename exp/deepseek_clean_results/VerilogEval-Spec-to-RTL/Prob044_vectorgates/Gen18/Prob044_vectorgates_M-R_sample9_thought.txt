Refactoring Approach: Direct Combinational Implementation
1. Instead of using sub-modules, implement all operations directly in the TopModule using continuous assignments
2. This reduces hierarchy overhead while maintaining the same functionality
3. Key changes:
   - Remove all sub-modules and implement logic directly in TopModule
   - Use simple assign statements for each operation
   - Maintain the same bit ordering for NOT operations
4. Benefits:
   - Reduced module hierarchy for potentially better synthesis results
   - More compact implementation while keeping the same logical behavior
   - Easier to see all operations at once in a small module
5. Trade-offs:
   - Less modular than original solution
   - Harder to reuse individual operations in other contexts
