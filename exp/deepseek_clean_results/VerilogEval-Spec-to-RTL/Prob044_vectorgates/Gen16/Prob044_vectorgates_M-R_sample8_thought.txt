Refactoring Approach: Flattened Combinational Logic
1. Instead of using submodules, implement all operations directly in the TopModule using continuous assignments
2. Maintain the same functionality but simplify the hierarchy
3. Benefits:
   - Reduced module instantiation overhead
   - More straightforward to read for simple operations
   - Easier to see all operations at once
4. Trade-offs:
   - Less modular than original solution
   - Harder to reuse individual operations in other contexts
5. Key changes:
   - Replace submodules with direct assign statements
   - Keep same bit ordering for NOT operations
   - Simplify logical OR to use a single reduction OR
