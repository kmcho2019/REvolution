The original implementation uses a single continuous assignment with XOR operations. We can refactor this by:
1. Breaking down the XOR operations into intermediate wires for better readability
2. Using separate assign statements for each XOR operation
3. Maintaining the same logical functionality while making the structure more explicit

This refactoring doesn't change the core logic but makes the implementation more modular and easier to understand/debug. The intermediate wires clearly show the progression from inputs to output.
