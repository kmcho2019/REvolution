Here's a novel approach using a lookup table (LUT) implemented as a case statement. Instead of using XOR operations, we'll treat the 4-bit input combination as an address to select the correct output value from the truth table. This method is more explicit about mapping each input combination to its output, making the design intent very clear. While it uses more gates than the XOR solution, it demonstrates an alternative implementation strategy that could be useful in more complex scenarios where patterns aren't as easily reducible to simple logic operations.
