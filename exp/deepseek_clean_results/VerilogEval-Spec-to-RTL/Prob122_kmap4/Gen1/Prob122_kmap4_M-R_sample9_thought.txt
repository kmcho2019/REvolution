The original implementation efficiently uses XOR operations to implement the K-map pattern. For refactoring, I'll maintain the same logical function but express it differently by:
1. Breaking down the XOR operations into intermediate wires for better readability
2. Using explicit XOR gates instead of the ^ operator
3. Keeping the same logical structure but making the implementation more modular

This approach maintains the same functionality while potentially making the design more maintainable and easier to modify if needed.
