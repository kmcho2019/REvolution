Here's a novel approach using a state machine implementation with explicit state encoding. Instead of using combinational logic for the next state, we'll:
1. Enumerate all possible states (Qold values) and input combinations
2. Use a case statement for clear state transition mapping
3. Implement the flip-flop behavior through explicit state transitions
4. Use one-hot encoding for potential power optimization in larger designs

Key advantages:
- More explicit state representation makes the design more readable
- Easier to modify or extend for additional features
- Better for formal verification due to explicit state transitions
- Potential for power optimization through state encoding choices
