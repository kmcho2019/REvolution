A novel approach to implement the JK flip-flop using multiplexers for state selection. This design:
1. Uses a 4:1 multiplexer to select the next state based on all possible J/K combinations
2. The multiplexer inputs directly implement the truth table cases:
   - 00: Qold (hold state)
   - 01: 0 (reset)
   - 10: 1 (set)
   - 11: ~Qold (toggle)
3. The select lines are simply the J and K inputs
4. Uses a standard D flip-flop for the state storage

Advantages:
- Very clear mapping from truth table to implementation
- Easy to understand and modify
- No complex logic expressions needed
- Each case is explicitly handled
- Good for synthesis as muxes are fundamental cells
