To make the JK flip-flop more synthesis-friendly while maintaining identical functionality, we'll restructure the implementation to:

1. Use a continuous assignment with a ternary operator for the next state logic
2. Separate the combinational next-state logic from the sequential element
3. Create an explicit 'next_Q' signal that calculates the next state based on current inputs and state
4. Use a simple D flip-flop to store the state

This approach:
- Makes the feedback path more explicit and easier for synthesis tools to handle
- Clearly separates combinational and sequential logic
- Maintains identical functionality to the original truth table
- Should be more reliably synthesizable across different tools
