To implement a JK flip-flop, we need to create a sequential circuit that updates its output Q on every positive clock edge based on the current inputs J and K. The truth table specifies four cases:
1. J=0, K=0: Maintain previous state (Qold)
2. J=0, K=1: Reset Q to 0
3. J=1, K=0: Set Q to 1
4. J=1, K=1: Toggle Q (invert Qold)

We'll use a simple always block triggered on the positive edge of clk to implement this behavior.
