Here's a refactored version that maintains the same functionality but uses a different structural approach:

1. Instead of using a separate combinational block for next_state, we'll merge the logic directly into the always block
2. Replace the ternary operators with a case statement for clearer state transition logic
3. This eliminates the intermediate wire and combines the logic into a single always block
4. The case statement makes the truth table more explicit and easier to verify
5. This approach may offer better synthesis results as it reduces logic depth and eliminates an unnecessary signal

Advantages:
- More compact implementation (single always block)
- Clearer representation of the truth table
- Potentially better timing due to reduced logic depth
- Easier to add synchronous reset or other features
