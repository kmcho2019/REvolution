Instead of using a case statement, we can implement the JK flip-flop using conditional expressions that directly map to the truth table. The key insight is that we can express the next state Q_next as a combination of the current inputs and the previous state, then register this value on the clock edge. This approach uses Boolean logic to compute the next state explicitly, which might be more synthesis-friendly.

The logic can be broken down as:
1. When J=1 and K=1, toggle Q (Q_next = ~Q)
2. When J=1, set Q (Q_next = 1)
3. When K=1, reset Q (Q_next = 0)
4. Otherwise, maintain Q (Q_next = Q)

This can be implemented using a combination of ternary operators or if-else statements.
