Novel Approach: State Machine Implementation
1. Instead of using a traditional DFF-based approach, implement the JK flip-flop as a finite state machine
2. Use a state register to store the current output value
3. Create a combinational next-state logic that directly implements the JK truth table
4. Update the state only on positive clock edges
5. This approach makes the state transitions explicit and could be more readable for some designers

Advantages:
- Explicit state machine representation makes behavior very clear
- No intermediate signals needed (like next_Q)
- Direct mapping from truth table to implementation
- Easier to extend if additional states or functionality are needed
