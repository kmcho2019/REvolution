Here's a novel approach using a shift register instead of a traditional counter:
1. Instead of a binary counter, use a 1024-bit shift register (since 2^10 = 1024)
2. Initialize with a single '1' at the loaded position (data value determines position)
3. Each clock cycle, the '1' shifts right one position
4. When the '1' reaches the LSB (position 0), tc is asserted
5. Loading new data moves the '1' to the new position
This approach:
- Eliminates arithmetic operations (no decrementer needed)
- Naturally stops at zero (no extra logic needed)
- Uses distributed storage instead of a counter
- Only one bit changes per cycle (potentially lower power)
