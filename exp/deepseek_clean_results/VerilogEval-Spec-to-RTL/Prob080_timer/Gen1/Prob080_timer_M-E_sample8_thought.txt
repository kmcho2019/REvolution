Instead of using a conventional down-counter, we can implement the timer using a shift register with priority encoding. The key ideas are:
1. Use a 10-bit shift register where '1's represent remaining time
2. Initialize with data value (each '1' bit = 1 clock cycle)
3. Right-shift the register each cycle (equivalent to counting down)
4. The MSB indicates when time has expired
5. Loading new data resets the shift register pattern
This approach has potential advantages in power and area since shifting is simpler than arithmetic operations.
