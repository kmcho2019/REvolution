Novel architectural idea: Zero-skip counter with pre-decrement
1. Instead of checking for zero after decrement, pre-calculate if next value would be zero
2. Use a "zero_next" signal that combines with load signal to control counter update
3. Eliminate the need for a separate zero detection comparator in the critical path
4. Counter stops naturally at zero without extra logic by using the zero_next signal
5. More efficient implementation with fewer logic levels in the critical path

Key advantages:
- Reduced critical path by combining decrement and zero detection
- Simpler control logic with direct zero anticipation
- Maintains same functionality with potentially better timing
- More power efficient as it avoids unnecessary comparisons
