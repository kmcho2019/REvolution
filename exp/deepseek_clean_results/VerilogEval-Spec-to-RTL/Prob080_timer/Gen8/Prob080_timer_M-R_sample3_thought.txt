Refactoring approach:
1. Replace the always block with continuous assignments using ternary operators
2. Use a wire for the next counter value calculation
3. Maintain the same functionality but express it through combinational logic
4. Keep the D flip-flop for sequential element (counter register)
5. The tc signal remains a simple combinational comparison

Benefits:
- More explicit data flow through continuous assignments
- Eliminates the need for an always block while maintaining same behavior
- Makes the combinational logic more visible in the code structure
- Still synthesizes to the same basic structure (register + decrement logic)
