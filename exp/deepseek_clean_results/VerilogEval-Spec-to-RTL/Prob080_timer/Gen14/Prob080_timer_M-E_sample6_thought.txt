Novel architectural idea: Instead of using a conventional down-counter, implement a shift register-based timer that counts down by shifting zeros from the left. This approach:
1. Uses a 10-bit shift register initialized with all 1s when loaded
2. Shifts in a 0 from the left each clock cycle when not loading
3. Detects timeout when the register becomes all zeros
4. Eliminates the need for explicit decrement logic
5. Reduces power by minimizing bit transitions (only one bit changes per cycle)
6. Simplifies zero detection (just check if all bits are 0)
7. Maintains single D flip-flop requirement
