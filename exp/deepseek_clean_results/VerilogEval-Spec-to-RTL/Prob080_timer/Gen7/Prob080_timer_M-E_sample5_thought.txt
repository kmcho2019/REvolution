Instead of using a conventional down-counter, implement the timer using a shift register with parallel load. The key idea:
1. Use a 10-bit shift register where each bit represents a clock cycle
2. Initialize with '1's shifted left by the data value (creating a thermometer code)
3. Each clock cycle, right-shift the register (with 0 fill)
4. The terminal count (tc) is simply the LSB of the register
5. Loading new data converts it to the thermometer code pattern

Advantages:
- Eliminates the need for a comparator (tc is direct register output)
- Simpler arithmetic (just shifting)
- Naturally stops counting when reaching 0
- Interesting alternative to traditional counter approach
