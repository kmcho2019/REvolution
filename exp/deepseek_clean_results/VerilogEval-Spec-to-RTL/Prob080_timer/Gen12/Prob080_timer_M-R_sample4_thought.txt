Refactored approach:
1. Separate the counter logic into two parts: loading and decrementing
2. Use continuous assignments for the counter next-state logic instead of procedural blocks
3. Create a dedicated signal for the decrement condition to make the logic more explicit
4. Maintain the same functionality while potentially improving synthesis results
5. The terminal count (tc) remains a simple combinational check of the counter value

Key improvements:
- More explicit logic structure
- Potential for better synthesis optimization
- Clear separation of load and decrement operations
- Maintains single D flip-flop requirement
