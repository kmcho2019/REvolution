Novel approach using parallel load and count logic:
1. Instead of using a single counter with conditional logic, implement separate load and count registers
2. Use a state machine to track when we're actively counting vs. idle
3. The count register only decrements when in active counting state
4. Load register captures new values immediately when load is asserted
5. State transitions:
   - Load operation moves to active counting state
   - Count reaches zero moves to idle state
6. Terminal count is simply the idle state indicator

Advantages:
- Clean separation of load and count operations
- Reduced switching activity when idle
- Simpler decrement logic (no zero check needed during counting)
- Better timing path separation between load and count operations
