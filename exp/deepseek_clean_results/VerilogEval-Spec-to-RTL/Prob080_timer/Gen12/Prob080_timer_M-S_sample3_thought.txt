To simplify the solution while maintaining functionality, I'll focus on:
1. Eliminating the separate next_counter wire by moving the logic directly into the always block
2. Keeping the efficient reduction OR for terminal count detection
3. Maintaining the single DFF requirement
4. Simplifying the decrement logic by letting it naturally wrap around to all 1's when at 0, but we'll prevent this by checking load first

The key simplification is combining the combinational and sequential logic into a single always block, reducing the number of signals and making the code more compact while preserving the same behavior.
