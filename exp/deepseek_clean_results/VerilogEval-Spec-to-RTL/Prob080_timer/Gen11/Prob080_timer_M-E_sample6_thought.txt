Novel architectural idea: Shift Register Timer
Instead of using a conventional down-counter, implement the timer using a shift register approach. The key idea is:
1. Use a 10-bit shift register where each bit represents a time unit
2. Initialize the register with '1's equal to the loaded data value (right-aligned)
3. On each clock cycle, shift left and bring in a '0' from the right
4. The terminal count is detected when the register becomes all zeros
5. Loading new data simply replaces the shift register contents

Advantages:
- Eliminates the need for decrementer logic
- Simple terminal count detection (all zeros)
- Naturally stops counting when empty
- Potentially better power characteristics since only one bit changes per cycle
