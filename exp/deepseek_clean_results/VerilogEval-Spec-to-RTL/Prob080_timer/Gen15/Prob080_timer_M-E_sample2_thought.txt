Novel Architecture Idea: Pre-decrement Load Counter
1. Instead of loading the data directly, we'll pre-decrement it by 1 when loading
2. This eliminates the need for an extra decrement operation in the countdown path
3. The counter will now reach -1 (all 1's) when timing out, detected by checking all bits set
4. This approach reduces the critical path by moving the -1 operation to the load phase
5. The terminal count (tc) is generated by checking if all counter bits are 1 (indicating -1 in 2's complement)

Key Advantages:
- Eliminates the decrementer from the critical path during countdown
- Only requires a simple all-ones check for terminal count
- Maintains same functionality with potentially better timing
- Still allows for mid-count reloads
