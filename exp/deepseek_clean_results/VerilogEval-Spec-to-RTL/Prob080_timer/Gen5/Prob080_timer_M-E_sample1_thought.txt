Here's a novel approach using a shift register instead of a traditional counter:
1. Instead of a down-counter, use a 10-bit shift register initialized with '1's
2. On each clock cycle, right-shift the register (inserting 0 from left)
3. The terminal count (tc) is the MSB of the shift register
4. Loading new data converts the input value into an equivalent shift pattern by left-shifting a '1' by data positions
This approach eliminates the subtraction operation and replaces it with simpler shift operations.
