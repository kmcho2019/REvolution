To optimize the design for better PPA (Power, Performance, Area), I'll implement the following improvements:

1. Timing Optimization:
   - Eliminate redundant zero comparison by reusing the tc signal in the counter logic
   - Simplify the next_counter logic to reduce critical path

2. Power Optimization:
   - Add clock gating when counter reaches zero to prevent unnecessary switching
   - Use a registered tc output to reduce glitches

3. Area Optimization:
   - Simplify the counter update logic to use fewer multiplexers
   - Combine related operations to reduce logic duplication

The key changes are:
- Use tc to control counter updates (when tc=1, counter stays at 0)
- Register tc output for better timing
- Simplify next_counter logic to single mux operation
- Add clock gating when counter is zero
