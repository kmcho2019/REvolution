Here's a novel approach using a shift register instead of a traditional counter:
1. Instead of a binary counter, use a 10-bit shift register with a single '1' that shifts right each cycle
2. The position of the '1' represents the remaining count (when '1' reaches LSB, time is up)
3. Loading new data converts it to a one-hot format where the '1' is at the MSB position of the loaded value
4. This eliminates the need for a subtractor, potentially reducing critical path
5. Terminal count is simply checking if the LSB is '1'
