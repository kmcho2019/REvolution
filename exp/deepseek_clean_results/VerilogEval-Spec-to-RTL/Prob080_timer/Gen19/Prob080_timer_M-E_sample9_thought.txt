Novel Architectural Idea: State Machine with Implicit Counter
Instead of using a traditional down-counter, implement a finite state machine that implicitly tracks the count through state transitions. The key innovation is using the state encoding itself to represent the count value, eliminating the need for a separate counter register. This approach can potentially reduce area by combining state storage and counting logic.

Key Features:
1. Use a one-hot encoding scheme where each state represents a specific count value
2. Implement a shift register-like behavior for the countdown operation
3. Load operation becomes parallel loading of the state register
4. Terminal count is simply the state where the LSB is set (representing count=0)
5. Only requires a single always block for both state transitions and output generation
