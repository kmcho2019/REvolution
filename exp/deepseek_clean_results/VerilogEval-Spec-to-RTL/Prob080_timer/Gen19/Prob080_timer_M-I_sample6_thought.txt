Optimization Strategy:
1. Timing Improvement:
   - Break down the combinational logic into two stages to reduce critical path
   - First check load condition, then handle counter decrement logic separately
   - This reduces the depth of logic in the mux chain

2. Power Optimization:
   - Add an enable signal to prevent unnecessary counter updates when counter=0
   - This reduces dynamic power by minimizing switching activity

3. Area Optimization:
   - Simplify the decrement operation by using a dedicated decrementer instead of subtractor
   - Share the zero comparison logic between counter and tc generation

Key Changes:
- Separate load and decrement logic paths
- Add enable signal for power savings
- Optimized decrement operation
- Shared zero comparison logic
