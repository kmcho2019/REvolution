Here's an alternative approach using a shift register implementation instead of a traditional down-counter:
1. Use a 10-bit shift register initialized to all 1s when loaded
2. Right-shift the register each cycle (inserting 0 from left)
3. The terminal count (tc) is the NOR of all bits
4. Loading new data converts it to a thermometer code (1s followed by 0s)
5. This eliminates the need for a subtractor, potentially improving timing
6. The shift operation is simpler than decrementing, which may reduce power
