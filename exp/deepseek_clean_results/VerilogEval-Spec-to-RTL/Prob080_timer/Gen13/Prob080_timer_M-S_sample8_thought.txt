To simplify the solution while maintaining functionality, I'll focus on:
1. Removing the separate next_counter calculation to reduce logic complexity
2. Directly updating the counter register in the always block
3. Using the same efficient terminal count detection (~|counter)
4. Maintaining single DFF requirement
5. Simplifying the decrement logic by letting it naturally underflow to zero
