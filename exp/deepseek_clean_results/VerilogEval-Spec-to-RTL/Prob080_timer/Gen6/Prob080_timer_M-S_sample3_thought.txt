The current implementation can be simplified by recognizing that the counter will naturally stay at 0 when it reaches zero (due to underflow behavior). We can eliminate the explicit check for tc in the decrement logic since decrementing from 0 will result in 10'b1111111111, but we can prevent this by only decrementing when the counter is non-zero. This can be achieved by combining the load and decrement conditions more efficiently. The tc signal can simply be the zero-detection of the counter.
