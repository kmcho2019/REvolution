Here's a novel approach using a shift register instead of a traditional counter:
1. Instead of a binary counter, use a 10-bit shift register initialized with '1's
2. On each clock cycle, right-shift the register (inserting 0 from left)
3. The terminal count (tc) is asserted when the register becomes all 0's
4. Loading new data converts the input value into a thermometer-like pattern where the number of 1's equals the count value
5. This eliminates the need for decrement logic and simplifies the terminal count detection to just checking if all bits are 0
