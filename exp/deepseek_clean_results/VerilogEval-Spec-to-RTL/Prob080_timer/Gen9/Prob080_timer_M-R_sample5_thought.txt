To refactor the solution while maintaining the same functionality:
1. Move the counter logic to combinational always block
2. Use a separate sequential always block for the flip-flop
3. This separates the combinational and sequential logic clearly
4. The terminal count (tc) remains a simple combinational assignment
5. The counter update logic is now split into two parts:
   - Combinational next state logic
   - Sequential state update

Key changes:
- Explicit separation of combinational and sequential logic
- Potentially better for synthesis and timing analysis
- Same single DFF requirement maintained
- More modular structure
