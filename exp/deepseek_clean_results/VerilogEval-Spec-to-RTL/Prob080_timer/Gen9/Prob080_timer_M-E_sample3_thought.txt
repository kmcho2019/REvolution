Novel architectural idea: Shift Register Timer
Instead of using a traditional down-counter, implement the timer using a shift register approach:
1. Use a 10-bit shift register where each bit represents a clock cycle
2. Initialize the shift register with '1' in the MSB and '0's elsewhere when loaded
3. On each clock cycle, right-shift the register (moving the '1' towards LSB)
4. The terminal count (tc) is simply the LSB of the shift register
5. Loading new data sets the shift register to have '1' at position [data-1]

Advantages:
- Eliminates arithmetic operations (subtraction) which can be timing-critical
- Simple shift operation is generally faster than arithmetic
- tc generation is trivial (just checking LSB)
- Power efficient since only one bit changes per cycle
- Area may be comparable since we're still using 10 flip-flops
