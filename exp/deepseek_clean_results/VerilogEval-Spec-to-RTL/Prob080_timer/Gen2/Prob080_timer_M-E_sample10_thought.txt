Instead of a conventional binary down counter, we can implement a thermometer-coded shift register approach:
1. Use a 10-bit shift register where each bit represents one count cycle
2. Initialize with '1's equal to the data input value when loaded
3. Right-shift the register each cycle (effectively counting down)
4. The tc signal is simply the LSB of the shift register
5. This eliminates the need for a subtractor and comparator
6. The counter naturally stops at 0 (all zeros) until reloaded
7. This approach has better timing for the decrement operation (just a shift)
8. Power is reduced since only one bit toggles per cycle
