The original solution uses bitwise operations with masks for each selection case. We can refactor this to use a more direct multiplexer approach with conditional operators. The key improvements are:

1. Simplify the default case check to just compare if c > 3
2. Use nested conditional operators to create a priority-encoded mux
3. Eliminate the separate mask generation logic by directly selecting inputs
4. Make the default case (c > 3) the outermost condition for better readability

This approach maintains the same functionality but with cleaner and potentially more optimized logic structure.
