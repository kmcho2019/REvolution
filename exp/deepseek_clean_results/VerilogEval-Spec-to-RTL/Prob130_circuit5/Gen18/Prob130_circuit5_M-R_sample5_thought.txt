Refactoring Strategy: Simplified Multiplexer Structure with Optimized Default Case Handling

1. **Key Changes**:
   - Replace the parallel masking approach with a cleaner 4:1 multiplexer structure
   - Simplify invalid case detection by checking only c[2] (since c >=4 when c[2] is 1 for 4-bit values)
   - Use direct assignment for the multiplexer selection
   - Eliminate redundant masking operations

2. **Improvements**:
   - More readable and maintainable code structure
   - Reduced logic complexity by using a straightforward mux
   - More efficient default case handling (single bit check)
   - Better timing characteristics due to simpler selection logic

3. **Implementation**:
   - Use a case statement for the mux (implemented with assign)
   - Simplify invalid case detection to just c[2]
   - Directly assign output based on selection or default
