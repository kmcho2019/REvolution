Refactoring Approach: Case Statement with Default
1. **Simplification**: Replace the bitwise masking approach with a more straightforward case statement, which is the natural way to implement a multiplexer in Verilog.
2. **Readability**: The case statement makes the selection logic more explicit and easier to understand at a glance.
3. **Optimization**: The synthesis tool can better optimize a case statement into efficient multiplexer structures, potentially reducing area and power.
4. **Default Handling**: Use the default case to handle all values of c not explicitly listed (4-15), setting output to all 1's (4'b1111).
5. **Maintained Functionality**: The behavior remains identical to the original implementation, just expressed differently.
