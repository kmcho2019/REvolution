Here's a refactored version that maintains the same functionality but uses a different structural approach:

1. Key changes from original:
   - Replaced the parallel masking with a single conditional assignment using nested ternary operators
   - Eliminated intermediate wires for enable signals and masking
   - Simplified the default case handling by making it part of the conditional chain
   - Used direct bit comparisons instead of equality checks for better readability

2. Advantages of this approach:
   - More compact code with fewer intermediate signals
   - Clearer mapping between conditions and outputs
   - Still maintains parallel evaluation (synthesizes to similar hardware)
   - Easier to modify/extend the condition list
   - Reduced wire count in the design

3. Implementation details:
   - Single assign statement with nested conditions
   - Each condition checks c directly
   - Default case (c > 3) handled by final else clause
   - No separate masking operations needed
