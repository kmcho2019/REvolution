Novel Architecture: Decoder-Based Selection with Early Termination

1. **Core Idea**: 
   - Use a decoder to directly translate the 2 LSBs of 'c' into one-hot selection signals
   - Implement early termination for invalid cases (c >= 4) using the MSBs of 'c'
   - Combine these signals with input data in a single stage for minimal delay

2. **Key Innovations**:
   - Eliminates sequential priority logic by using parallel decoder
   - Early termination prevents unnecessary switching in the data path
   - Single-stage selection reduces critical path compared to nested conditionals
   - Optimized for both valid and invalid cases

3. **Advantages**:
   - Lower latency due to single-stage selection
   - Reduced power consumption from minimized switching activity
   - Compact implementation using decoder and simple AND-OR logic
   - Balanced timing across all output bits
   - Clear separation of control and data paths

4. **Implementation**:
   - 2-to-4 decoder for valid selection cases
   - OR reduction of c[3:2] for default case detection
   - Parallel AND gates for input selection
   - Final OR stage combines valid selections with default value
