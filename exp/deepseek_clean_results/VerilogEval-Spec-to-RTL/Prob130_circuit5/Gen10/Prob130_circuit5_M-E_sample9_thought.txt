Novel Architectural Idea: Bitwise Conditional Selection
1. **Parallel Processing**: Instead of using a traditional multiplexer, implement a bitwise conditional selection where each output bit is independently determined based on the control input.
2. **Mask Generation**: Create a 4-bit mask for each possible selection (b, e, a, d) based on the value of c. When c is outside 0-3, generate an all-ones mask.
3. **Bitwise AND-OR**: For each output bit, perform a bitwise AND between each input and its corresponding mask, then OR all results together to get the final output bit.
4. **Advantages**:
   - Fully parallel implementation with no multiplexer hierarchy
   - Equal delay for all bits (balanced timing)
   - Potential for better power efficiency as only active masks contribute to switching
   - Easily scalable to wider buses
