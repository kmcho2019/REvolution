Here's an alternative approach using a bitwise operation implementation instead of a case statement. The key observation is that the output selection can be viewed as a bitwise operation where we:
1. Create a mask for each possible selection (b, e, a, d)
2. AND each input with its corresponding mask
3. OR all the results together
4. For the default case (c >= 4), we'll use a separate condition to force all bits high

This approach might be more efficient in some technologies as it can leverage parallel bitwise operations rather than sequential case evaluation.
