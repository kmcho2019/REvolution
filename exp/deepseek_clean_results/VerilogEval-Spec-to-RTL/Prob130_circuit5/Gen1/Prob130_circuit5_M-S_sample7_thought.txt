The original solution uses a case statement with 16 cases (for 4-bit c), but only 4 cases are actually needed (c=0-3). We can simplify this by:
1. Only checking the 2 LSBs of c (c[1:0]) since that's all we need to distinguish between the 4 valid cases
2. Using a simpler conditional assignment structure with if-else statements
3. Maintaining the same default behavior (all 1's) for invalid cases

This reduces the complexity from checking all 16 possible values of c to just checking 4 cases via the 2 LSBs.
