Here's a novel approach using a lookup table (LUT) implemented with a case statement. The key differences from the previous solution are:
1. Uses a case statement for clearer multiplexer implementation
2. Implements the selection logic as a proper 4:1 mux with default case
3. More readable and maintainable structure
4. Potentially better synthesis results as case statements often map well to FPGA/ASIC mux resources
5. Explicitly handles all specified cases (0-3) and defaults others to 'f'
