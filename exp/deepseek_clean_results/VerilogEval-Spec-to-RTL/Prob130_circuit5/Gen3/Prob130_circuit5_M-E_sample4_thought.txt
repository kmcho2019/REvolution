Here's a novel approach using a lookup table (LUT) implemented with a case statement. The key differences from the original solution are:
1. Uses a case statement instead of ternary operators for better readability and potential synthesis optimization
2. Implements the selection logic as a proper multiplexer with explicit cases
3. Groups the default cases (4-15) together for cleaner code
4. The case statement may synthesize to a more optimized multiplexer structure in some tools
