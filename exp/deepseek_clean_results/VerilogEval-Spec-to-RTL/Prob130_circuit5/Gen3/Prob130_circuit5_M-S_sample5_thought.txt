The key observation is that the output 'q' simply selects one of the inputs (b, e, a, d) based on the value of 'c' when c is between 0-3, and outputs all 1's otherwise. We can simplify this to:
1. Use a simple case statement for values 0-3 of 'c'
2. Default to all 1's for any other value of 'c'
3. Eliminate all the mask generation and complex bitwise operations
This approach is more straightforward and easier to understand while maintaining the same functionality.
