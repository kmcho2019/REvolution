Here's a novel approach using a lookup table (LUT) style implementation with a decoder:
1. Use the lower 2 bits of 'c' as a selector since only values 0-3 have defined outputs
2. For values 0-3, decode these 2 bits to select between a, b, d, e
3. For all other values (when c[3:2] != 0), output all 1's
4. This reduces the comparison logic to just checking the upper bits of c
5. The 2-bit decoder creates a more balanced selection structure
