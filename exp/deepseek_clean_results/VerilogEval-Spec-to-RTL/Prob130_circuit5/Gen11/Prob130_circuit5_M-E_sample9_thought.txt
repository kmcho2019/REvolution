Here's a novel approach using a priority encoder style implementation with bitwise masking:

1. Instead of using a multiplexer or shift operation, we'll implement a priority-based selection:
   - Each possible value of c (0-3) will have a dedicated AND mask
   - The masks will be combined using OR operations
   - Values of c > 3 will automatically result in 0xF output due to the mask structure

2. Key features of this approach:
   - No shift operations needed (better timing)
   - Parallel evaluation of all cases
   - Simple bitwise operations only
   - Natural priority handling (lower c values take precedence)
   - Efficient implementation using only AND/OR gates

3. Implementation details:
   - Create enable signals for each valid c value (0-3)
   - Mask each input with its corresponding enable
   - OR all masked results together
   - Default to 0xF when c is out of range (handled by the enable logic)
