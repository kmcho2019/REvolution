Here's a novel approach using a lookup table (LUT) implemented with a ROM-style pattern. Instead of using traditional multiplexing logic, we'll:
1. Treat the lower 2 bits of 'c' as an address (since we only care about values 0-3)
2. Create a 4-entry ROM where each entry corresponds to one of the input selections
3. Use the ROM output to control a set of tri-state buffers
4. For values of 'c' greater than 3, we'll force all output bits high through a separate condition

This approach is interesting because:
- It uses tri-state buffers instead of traditional logic gates
- The ROM implementation can be optimized in some technologies
- The selection logic becomes very straightforward
- The default case handling is cleanly separated
