Here's a novel approach using a lookup table (LUT) implemented with a memory-style structure. Instead of traditional multiplexing logic, we'll:
1. Use the lower 2 bits of 'c' as an index (since we only care about values 0-3)
2. Create a 4-entry memory where each entry stores one of the input signals
3. Use the index to select the appropriate output
4. Handle the default case (when c > 3) by forcing all bits high

This approach is interesting because:
- It conceptually separates the storage and selection logic
- It can be efficiently implemented in FPGAs that have built-in LUT resources
- The default case handling is cleanly separated from the normal operation
- The implementation scales well if more selection cases are needed
