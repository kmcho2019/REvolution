Novel Architecture: Bitwise Conditional Selection with Priority Encoding

1. **Core Idea**:
   - Implement a priority-based selection mechanism that checks conditions in a specific order
   - Use bitwise operations to efficiently combine the selection logic
   - Leverage Verilog's conditional operator for compact implementation

2. **Key Innovations**:
   - Eliminates explicit decoder logic by using cascaded conditionals
   - Optimized for typical case where c values are small (0-3)
   - Uses parallel bitwise operations for efficient hardware mapping
   - Simple and clean implementation with minimal gates

3. **Advantages**:
   - No unnecessary decoding logic when c is invalid (>=4)
   - Straightforward timing path with clear priority
   - Efficient implementation using Verilog's built-in operators
   - Easy to understand and modify selection priorities

4. **Implementation**:
   - Priority check from most common case (c=0) to least
   - Default case (invalid c) handled by final else clause
   - Uses ternary operators for compact selection
   - No intermediate signals needed
