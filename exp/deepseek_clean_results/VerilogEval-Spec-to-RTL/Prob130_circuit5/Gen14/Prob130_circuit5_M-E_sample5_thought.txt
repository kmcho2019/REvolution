Novel Architecture: Bitwise Conditional Selection with Priority Masking

1. **Core Idea**:
   - Implement a bitwise selection mechanism where each output bit is computed independently
   - Use priority masking to handle the selection cases without explicit decoding
   - Leverage bitwise operations for efficient hardware implementation

2. **Key Innovations**:
   - Eliminates explicit decoder by using arithmetic comparisons
   - Each output bit is computed in parallel for maximum speed
   - Priority masking ensures correct selection without nested conditionals
   - Optimized for minimal gate count and balanced timing

3. **Advantages**:
   - No explicit decoder reduces area overhead
   - Parallel bit computation improves timing
   - Simple arithmetic comparisons are hardware-friendly
   - Clear and maintainable implementation
   - Scales well to wider data paths

4. **Implementation**:
   - Use equality comparisons to detect each valid case
   - Apply priority masking to handle selection precedence
   - Combine results using bitwise operations
   - Default to all 1's for invalid cases
