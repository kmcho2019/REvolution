Refactored approach using a priority-encoded multiplexer structure:

1. **Key Changes**:
   - Replaced the mask-and-combine approach with a priority-encoded multiplexer
   - Used a single assign statement with nested conditional operators
   - Eliminated intermediate mask generation wires
   - Simplified the 'f' output condition by checking c[3:2] first

2. **Improvements**:
   - Reduced gate count by using direct selection logic
   - More readable and maintainable code structure
   - Better power efficiency as only the selected path is evaluated
   - Maintains the same functionality while being more area-efficient
   - The priority check for 'f' output is now the first condition, potentially saving power

3. **Maintained Advantages**:
   - Still purely combinational
   - No comparators needed (uses equality checks)
   - All operations remain parallel
   - Easy to understand and modify
