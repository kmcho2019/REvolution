To implement a 32-bit Galois LFSR with specified taps:
1. Use a 32-bit register to hold the current state (q)
2. On each clock edge:
   - If reset is high, load the register with 32'h1
   - Else:
     - The LSB (q[0]) becomes the new feedback bit
     - For tap positions (32,22,2,1), XOR their current value with q[0] to get their next value
     - All other bits simply shift right (q[i] <= q[i+1])
3. Note that since Verilog uses 0-based indexing, tap positions in code will be 31,21,1,0
4. The new MSB (q[31]) is the XOR of the old q[31] and q[0]
