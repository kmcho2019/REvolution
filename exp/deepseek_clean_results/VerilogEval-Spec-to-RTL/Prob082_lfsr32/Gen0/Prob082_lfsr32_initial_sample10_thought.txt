To implement a 32-bit Galois LFSR with specified taps:
1. Use a 32-bit register to hold the current state (q)
2. On each clock edge:
   - If reset is high, load 32'h1 into the register
   - Otherwise:
     - The LSB (q[0]) becomes the feedback bit
     - For each tap position (32,22,2,1), XOR the current bit with the feedback bit
     - All other bits simply shift right
     - The MSB (q[31]) is set to the feedback bit
3. The output q is always the current state of the register
