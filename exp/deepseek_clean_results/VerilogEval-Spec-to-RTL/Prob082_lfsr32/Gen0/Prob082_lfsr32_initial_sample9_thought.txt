To implement a 32-bit Galois LFSR with specified taps:
1. Use a 32-bit register 'q' to store the current state
2. On each clock edge:
   - If reset is high, load 32'h1 into the register
   - Else:
     a. Right shift the register by 1 (q >> 1)
     b. XOR the tap positions (32,22,2,1) with the LSB (q[0])
     c. Note that bit position 32 is actually q[31] in 0-based indexing
3. The taps are implemented by XORing q[31], q[21], q[1], and q[0] with q[0]
4. The MSB (new bit) comes from the XOR of all tap bits with q[0]
