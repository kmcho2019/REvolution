To correctly implement a 32-bit Galois LFSR with specified taps:
1. Use a 32-bit register 'q' to store the current state
2. On each clock edge:
   - If reset is high, load 32'h1 into the register
   - Else:
     a. Right shift the register by 1 (q >> 1)
     b. XOR the tap positions (31,21,1,0) with the LSB (q[0])
     c. Note that bit positions are 0-based (32 becomes 31, 22 becomes 21)
3. The taps are implemented by XORing each individual tap position with q[0]
4. The MSB comes from q[0], and tapped bits get q[0] XORed with their current value
