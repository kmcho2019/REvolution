Instead of using Boolean algebra simplification, we can implement the function using a 2:1 multiplexer where:
- The select line is x
- When x=0, output is 0 (since anything ANDed with 0 is 0)
- When x=1, output is ~y (since (1^y) & 1 = ~y)
This approach showcases how multiplexers can be used to implement arbitrary logic functions, which is particularly useful in FPGA implementations where MUX resources are abundant.
