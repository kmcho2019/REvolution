Here's a novel approach using a lookup table (LUT) implemented with a case statement. While this is overkill for such a simple function, it demonstrates a different architectural approach that could be useful for more complex functions or when the logic might need to be dynamically reconfigured.

Key ideas:
1. Represent the truth table explicitly using a case statement
2. Combine inputs into a 2-bit selector
3. Map each input combination to the correct output
4. This approach makes the logic extremely explicit and could be easily modified if requirements change

While this uses more lines of code, it has identical PPA characteristics after synthesis since modern tools will optimize it to the same gate-level implementation as the direct boolean expression.
