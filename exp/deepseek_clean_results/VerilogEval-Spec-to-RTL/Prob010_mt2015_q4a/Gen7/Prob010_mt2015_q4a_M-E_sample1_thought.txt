Let's implement the boolean function z = (x^y) & x using a lookup table (LUT) approach. This method:
1. Uses a 4-bit LUT to directly encode all possible input combinations
2. Demonstrates how small combinational logic can be implemented as truth tables
3. Provides a different implementation style that might be more suitable for certain FPGA architectures
4. Shows how to think about logic functions in terms of their complete truth table

The LUT will store the output for all 4 possible input combinations of x and y (00, 01, 10, 11). The output z will be selected based on the current input combination.
