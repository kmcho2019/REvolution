The original solution uses a ternary operator which effectively creates a 2:1 multiplexer. We can refactor this to use explicit boolean operations that directly implement the logic function z = (x^y) & x. Breaking this down:
1. (x^y) is the XOR operation between x and y
2. Then AND the result with x
This approach uses fundamental boolean operations and may result in slightly better PPA since it avoids the implicit multiplexer structure of the ternary operator.
