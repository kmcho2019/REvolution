Let's implement the same boolean function using a multiplexer-based approach. The idea is to use y as the select line for a 2:1 mux. When y=0, we pass x through (resulting in x), and when y=1, we pass 0. This effectively implements z = x & ~y, which is equivalent to the original function z = (x^y) & x. This approach demonstrates how the same logic can be implemented using different digital building blocks.
