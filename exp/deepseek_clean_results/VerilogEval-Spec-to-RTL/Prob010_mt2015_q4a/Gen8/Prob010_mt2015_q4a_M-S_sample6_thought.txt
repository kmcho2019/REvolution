The original function z = (x^y) & x can be simplified using boolean algebra. Let's expand and simplify:
z = (x^y) & x
   = (x&~y | ~x&y) & x
   = x&~y & x | ~x&y & x
   = x&~y | 0
   = x & ~y

This shows the function is equivalent to x AND NOT y. We can implement this directly with a single AND gate using x and the negation of y, which is simpler than the mux approach.
