Novel Approach: Bitwise Mux Implementation
1. Concept: Implement the function using a multiplexer (mux) structure where the output is selected based on the value of x.
2. Logic Breakdown:
   - When x=0: Output z must be 0 regardless of y (since AND with 0 is 0)
   - When x=1: Output z equals ~y (since (1^y)&1 = ~y)
3. Advantages:
   - Demonstrates an alternative implementation using selection logic
   - Shows how the same function can be realized with different hardware structures
   - Provides a template that could be extended to more complex functions
4. Implementation: Use a ternary operator to create the mux behavior
