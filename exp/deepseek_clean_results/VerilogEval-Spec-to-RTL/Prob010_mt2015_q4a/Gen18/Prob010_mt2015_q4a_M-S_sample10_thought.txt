The original function z = (x^y) & x can be simplified using boolean algebra:
1. Expand XOR: (x^y) = x&~y + ~x&y
2. Multiply by x: x&(x&~y + ~x&y) = x&x&~y + x&~x&y = x&~y + 0 = x&~y
3. The simplified form is z = x & ~y

This matches the original implementation, but we can make it even simpler by:
1. Using a single continuous assignment
2. Eliminating intermediate wires
3. Using bitwise operators for direct implementation
4. This reduces gate count and improves PPA metrics
