To create a novel D latch implementation, I'll use a structural approach with basic logic gates instead of behavioral constructs. This offers several advantages:

1. **Explicit Structure**: By building the latch from NAND gates (the fundamental building block of latches), we make the implementation more transparent and educational.

2. **Better Control**: The gate-level implementation gives more direct control over the transistor-level behavior, which can be beneficial for custom ASIC designs.

3. **Alternative Optimization Path**: Synthesis tools might optimize this structure differently than behavioral code, potentially leading to better PPA in some technologies.

The design uses two cross-coupled NAND gates to form the basic latch, with additional NAND gates for input control. When enable is high, the input propagates through; when low, the latch maintains its state through feedback.
