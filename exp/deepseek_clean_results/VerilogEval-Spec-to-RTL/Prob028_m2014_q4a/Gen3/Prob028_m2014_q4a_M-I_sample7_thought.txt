The current implementation using a continuous assignment works correctly but may not be optimal for power and area. To improve PPA:

1. **Power Optimization**: Use `always_latch` instead of continuous assignment to make the latch behavior more explicit to synthesis tools, potentially reducing unnecessary switching activity.

2. **Area Optimization**: The current area is already good (2.0 um²), but we can ensure minimal implementation by using the most straightforward latch description.

3. **Clarity**: Using `always_latch` clearly communicates design intent, which helps both synthesis tools and other engineers reading the code.

The improved version will use `always_latch` with proper sensitivity list while maintaining the same functionality.
