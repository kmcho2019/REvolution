To refactor the D latch implementation while maintaining the same functionality:
1. Use continuous assignment with ternary operator instead of always block
2. This approach is more concise and directly expresses the latch behavior
3. The ternary operator acts as a mux: when ena is high, q follows d; when low, q keeps its value
4. This style may have better synthesis compatibility with some tools
5. Note that this still infers a latch since there's no else clause for the feedback path
