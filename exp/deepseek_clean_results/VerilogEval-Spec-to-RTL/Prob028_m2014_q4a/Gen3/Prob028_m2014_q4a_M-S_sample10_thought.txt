The simplest implementation of a D latch uses an always block with level-sensitive control:
1. The always block triggers whenever 'd' or 'ena' changes
2. When 'ena' is high, the output 'q' follows input 'd'
3. When 'ena' is low, 'q' retains its previous value (latch behavior)
4. This is the most straightforward and readable implementation of a D latch
