Novel Approach: Using a Transmission Gate Based Latch Implementation
1. Instead of using continuous assignment, implement the D latch using transmission gate logic
2. Use an always block with sensitivity to both ena and d to model the transmission gate behavior
3. When ena is high, the input d is transparently passed to q (like a transmission gate being on)
4. When ena is low, the output q retains its previous value (like a transmission gate being off)
5. This approach more closely mimics actual transistor-level latch implementations while still being RTL-friendly
6. The implementation will use non-blocking assignments to properly model the latch behavior
