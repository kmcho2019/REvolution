Refactoring approach:
1. Use continuous assignments for both state transition logic and output
2. Eliminate explicit state registers by using clocked logic directly
3. Implement state transitions with ternary operators
4. Maintain synchronous reset functionality
5. Simplify the structure by combining state and output logic

Benefits:
- More compact code with same functionality
- Eliminates separate next_state variable
- Uses simpler continuous assignment style
- Still maintains clear Moore machine behavior
- Output remains purely combinational function of state
