Innovative Approach: Shift Register with Edge Detection

1. Core Idea:
   - Replace traditional state encoding with a shift register that tracks state transitions
   - Use edge detection on inputs to trigger state changes
   - Implement as a self-clocked system within the main clock domain

2. Key Features:
   - State is represented by the position of a '1' in a 2-bit shift register
   - Input edges (j rising for OFF→ON, k rising for ON→OFF) trigger shifts
   - Reset forces the shift register to initial position
   - Output is simply the MSB of the shift register

3. Advantages:
   - Eliminates explicit state transition logic
   - Naturally handles glitch-free transitions
   - Easily extensible to more states by widening the shift register
   - Demonstrates alternative state machine implementation
   - Built-in debouncing effect due to edge detection
