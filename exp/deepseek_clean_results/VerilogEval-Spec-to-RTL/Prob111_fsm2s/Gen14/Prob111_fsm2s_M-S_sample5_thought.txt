Simplification approach:
1. **State Representation**: Since we only have two states, we can eliminate the localparam definitions and use the state register directly as a binary value
2. **Next State Logic**: Combine the reset and transition logic into a single always block for more compact code
3. **Output Assignment**: Since output is directly the state, we can declare it as a wire and assign it continuously
4. **Reduction**: Remove the intermediate next_state wire by computing the next state directly in the always block

Key simplifications:
- Eliminate parameter definitions since binary states are self-explanatory
- Merge next state computation into the sequential block
- Remove redundant wire declaration
- Maintain same functionality with fewer lines of code
