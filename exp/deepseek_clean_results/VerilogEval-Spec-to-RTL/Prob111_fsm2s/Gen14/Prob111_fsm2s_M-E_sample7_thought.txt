Instead of using a traditional binary state register, we can implement the state machine using a toggle flip-flop concept where:
1. The state is represented by a single flip-flop that toggles based on conditions
2. The transition logic combines j and k inputs in a way that:
   - j=1 always sets the state to ON (1)
   - k=1 always sets the state to OFF (0)
   - When both are 0, state remains unchanged
   - When both are 1, priority goes to k (OFF)
3. This creates a more direct mapping between inputs and state transitions
4. The output remains a direct assignment from the state flip-flop
