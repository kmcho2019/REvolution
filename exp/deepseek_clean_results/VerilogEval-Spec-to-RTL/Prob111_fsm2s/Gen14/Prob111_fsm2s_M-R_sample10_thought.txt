Refactoring Approach:

1. State Representation:
   - Keep the same state encoding but represent it as a wire instead of reg
   - Use continuous assignments for state transitions

2. State Transition Logic:
   - Replace the always block with combinational logic using ternary operators
   - Create a next_state signal that computes the state transition

3. State Register:
   - Use a single D-flip-flop primitive with synchronous reset
   - This makes the state storage explicit and separates it from transition logic

4. Output Logic:
   - Maintain the direct state-to-output assignment (Moore property)
   - Keep as continuous assignment for clarity

Key Benefits:
- More explicit separation of combinational and sequential logic
- Shows alternative implementation using basic digital components
- Demonstrates how to build a state machine without procedural blocks
- Maintains identical functionality while showing different coding style
