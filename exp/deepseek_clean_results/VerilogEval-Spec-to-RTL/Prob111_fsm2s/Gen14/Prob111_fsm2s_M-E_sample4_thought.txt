Innovative approach:
1. Use a 2-bit shift register to represent states, where only one bit is '1' at any time (one-hot like but with wrap-around)
2. State transitions become simple shift operations based on inputs
3. OFF state = "01", ON state = "10"
4. Reset initializes to "01" (OFF)
5. Output is simply the MSB of the state register

Advantages:
- Eliminates combinational next-state logic entirely
- State transitions become simple shift operations
- Naturally glitch-resistant due to minimal combinational paths
- Easily extensible to more states if needed
- Power-efficient as only one bit flips per transition
