Here's a novel approach using a shift register implementation instead of a traditional state machine. The key idea is:
1. Represent the two states using a 2-bit shift register
2. The current state is always the LSB of the register
3. State transitions are implemented by shifting in new values based on inputs
4. OFF state is represented by '01' and ON state by '10'
5. Reset initializes the shift register to '01' (OFF state)
6. Output is directly the LSB of the register

This approach eliminates explicit state transition logic and instead uses shift operations, which can be more efficient in some FPGA architectures. The state encoding ensures only one bit changes at a time (Gray code like).
