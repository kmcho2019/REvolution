The original solution uses a T-flipflop with conditional toggling, which adds unnecessary complexity for this simple state machine. We can simplify by:
1. Using direct state transitions with clear conditions
2. Eliminating the intermediate toggle_enable logic
3. Making the state transitions more explicit and straightforward

The simplified approach:
- Use a single state register
- Directly implement the state transitions from the specification
- Output is simply the state bit
- Reset forces state to OFF (0)

This removes the combinational logic path and makes the design more straightforward while maintaining identical functionality.
