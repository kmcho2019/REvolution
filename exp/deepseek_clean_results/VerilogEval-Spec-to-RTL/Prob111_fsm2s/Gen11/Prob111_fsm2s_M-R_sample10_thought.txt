Refactoring approach:
1. Replace the sequential always block with continuous assignments for state transitions
2. Use a combinational always block for next state logic
3. Maintain synchronous reset with a separate always block
4. Keep the direct state-to-output assignment
5. This separates the combinational and sequential logic more clearly

Benefits:
- More explicit separation of combinational and sequential logic
- Easier to add debug signals for next state
- Potentially better synthesis optimization for some tools
- Same functionality with different implementation style
