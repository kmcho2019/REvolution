The original solution is already optimal for this simple 2-state Moore machine, but we can make a few minor improvements:

2. Combine the state register and output register since they're identical in a Moore machine
3. Use a localparam instead of parameter since these constants are only used within the module
4. Add comments to clarify the state transition conditions
