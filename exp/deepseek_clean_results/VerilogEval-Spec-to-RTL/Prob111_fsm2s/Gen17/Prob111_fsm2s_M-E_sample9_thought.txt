Novel Shift Register with Edge Detection Approach:

1. Core Idea:
   - Implement the state machine using a 2-bit shift register instead of explicit states
   - Use edge detection on inputs to control state transitions
   - Leverage the shift register's natural sequential behavior

2. Key Features:
   - The shift register bits represent state history (current and previous states)
   - Rising edges on j/k inputs trigger state changes
   - Output is derived from the most recent shift register bit
   - Reset clears the shift register to represent OFF state

3. Advantages:
   - Eliminates explicit state variables and transition logic
   - Uses physical properties of shift registers for state storage
   - Edge detection makes the design responsive to input changes
   - Naturally glitch-resistant due to shift register behavior

4. Implementation Details:
   - 2-bit shift register (SR) stores state information
   - SR[0] is current state, SR[1] is previous state
   - Edge detectors create single-cycle pulses for transitions
   - Output directly follows SR[0]
