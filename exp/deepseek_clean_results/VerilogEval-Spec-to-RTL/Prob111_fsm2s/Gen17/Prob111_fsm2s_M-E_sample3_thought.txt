Novel approach: One-hot encoding with implicit state transitions
1. Use one-hot encoding for states (even though there are only two states)
2. Implement state transitions using bitwise operations instead of muxes
3. Leverage the properties of one-hot encoding for simpler transition logic
4. Use parallel always blocks for state updates (demonstrating alternative coding style)
5. Maintain synchronous reset but implement it differently

Advantages:
- Demonstrates one-hot encoding pattern that scales well to larger state machines
- Uses bitwise operations which can be more efficient in some technologies
- Shows alternative coding style with parallel always blocks
- Still maintains clear Moore machine semantics
- Output remains purely combinational function of state
