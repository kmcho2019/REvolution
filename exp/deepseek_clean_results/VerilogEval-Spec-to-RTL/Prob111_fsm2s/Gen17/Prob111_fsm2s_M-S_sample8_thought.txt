Simplification approach:
1. Since the output is directly equal to the state (Moore machine), we can eliminate the state parameter definitions and output assignment
2. The state register itself can serve as both state storage and output
3. The transition logic can be written directly in the always block without intermediate parameters
4. Maintain synchronous reset to initialize state to 0 (OFF)

Key simplifications:
- Removed redundant parameter definitions
- Eliminated separate output assignment
- Simplified state transition logic expression
- Reduced lines of code while maintaining identical functionality
