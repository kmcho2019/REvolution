Here's a novel approach using a one-hot encoding scheme with explicit state transition logic:

1. Use two flip-flops to represent the states in one-hot encoding (01 for OFF, 10 for ON)
2. Implement the state transitions using parallel combinatorial logic for each state
3. Generate the next state by OR-ing the transition conditions from all possible current states
4. The output is simply the ON state flip-flop value
5. Maintain synchronous reset functionality to initialize to OFF state

This approach provides:
- Clear separation of transition conditions for each state
- Potential for better timing as each state's transitions are evaluated independently
- Easy extensibility if more states are needed later
