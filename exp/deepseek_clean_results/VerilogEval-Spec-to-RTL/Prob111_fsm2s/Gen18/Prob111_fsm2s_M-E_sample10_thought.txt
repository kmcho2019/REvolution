Novel approach using edge detection:
1. Instead of tracking state directly, we'll track transitions between states
2. Use edge detection on j and k inputs to trigger state changes
3. Positive edge of j moves from OFF to ON
4. Positive edge of k moves from ON to OFF
5. This creates a more event-driven design that only updates state on relevant input changes
6. Still maintains Moore machine properties with output derived from state
7. Synchronous reset initializes to OFF state (out=0)

Key advantages:
- More efficient power usage as state only changes on relevant input edges
- Potentially better noise immunity as it ignores input glitches between clock edges
- Clear mapping between input events and state transitions
