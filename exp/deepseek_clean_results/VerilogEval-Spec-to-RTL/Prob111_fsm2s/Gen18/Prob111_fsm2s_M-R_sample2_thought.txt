Refactoring approach:
1. Use a parameterized state encoding for better readability
2. Separate the state transition logic into a combinational always block
3. Keep the state register update in a sequential always block
4. Make the output assignment continuous from the state register
5. Use explicit state names (OFF/ON) instead of binary values for better code clarity

Benefits:
- More readable state definitions
- Clear separation between combinational and sequential logic
- Easier to modify state encoding if needed
- Explicit state names make the code more self-documenting
- Maintains same functionality while being more maintainable
