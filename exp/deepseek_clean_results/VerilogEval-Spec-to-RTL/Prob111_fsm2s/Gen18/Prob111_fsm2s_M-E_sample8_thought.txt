I'll implement a novel solution using a shift register approach instead of a traditional state machine. The key ideas are:
1. Use a 2-bit shift register where the MSB represents the current state
2. The LSB will be calculated based on current state and inputs (j/k)
3. On each clock edge, the register shifts left, making the calculated bit the new state
4. Reset initializes the shift register to '00' (OFF state)
5. The output is simply the MSB of the register

This approach eliminates explicit state transitions and instead uses bit manipulation and shifting to achieve the same behavior.
