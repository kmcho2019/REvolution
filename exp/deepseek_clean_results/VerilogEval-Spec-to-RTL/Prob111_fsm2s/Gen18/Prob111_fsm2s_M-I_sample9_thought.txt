Optimization strategy:
1. Maintain the existing efficient state encoding (1-bit binary)
2. Optimize the combinational logic for state transitions to potentially reduce critical path
3. Consider output gating during reset to save power (though minimal impact for 1-bit)
4. Keep synchronous reset for consistent timing behavior
5. Use blocking assignments for simulation consistency (though synthesis will handle either)

Key improvements:
- Simplified state transition logic to a single expression
- Maintained minimal area footprint
- Kept clean synchronous design style
- Output remains directly tied to state (Moore machine property)
