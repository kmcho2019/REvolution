Refactoring approach:
1. Use a one-hot encoding style for state representation
2. Implement state transitions using combinational logic with assign statements
3. Maintain synchronous behavior by using a single always block for state updates
4. Keep output purely combinational based on current state
5. Simplify state transition logic by using bitwise operations

Benefits:
- More explicit state representation (each state has its own bit)
- Easier to extend if more states are added later
- Clear separation between combinational and sequential logic
- Maintains same functionality while using different coding style
