This solution implements the state machine using edge detection and a toggle mechanism:
1. Instead of tracking state explicitly, we detect rising edges on j and k inputs
2. A toggle flip-flop changes state only on detected edges:
   - Rising edge of j when output is 0 sets output to 1
   - Rising edge of k when output is 1 sets output to 0
3. Edge detection is done by comparing current input with delayed version
4. This approach minimizes state transitions to only necessary clock cycles
5. The design naturally filters out glitches on j/k inputs
6. Reset forces the output to 0 (OFF state)
