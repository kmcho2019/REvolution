I'll refactor the state machine to use explicit next-state logic with continuous assignments (assign statements) instead of procedural blocks. This approach:
1. Separates the combinational next-state logic from the sequential state register
2. Uses explicit wire declarations for better visibility
3. Maintains the same Moore machine behavior where output is directly tied to state
4. Still uses binary encoding for the states (OFF=0, ON=1)
5. Keeps synchronous reset functionality

The advantage is clearer separation of combinational and sequential logic, which some designers prefer for readability and potential optimization opportunities.
