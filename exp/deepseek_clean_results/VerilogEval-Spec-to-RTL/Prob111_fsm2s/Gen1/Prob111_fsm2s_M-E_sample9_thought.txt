Instead of using a traditional state register, we can implement this as a toggle flip-flop with enable logic. The key insight is that:
1. The output toggles only under specific conditions:
   - From OFF to ON when j=1
   - From ON to OFF when k=1
2. We can model this behavior using a single flip-flop that toggles when:
   (current_state is OFF AND j=1) OR (current_state is ON AND k=1)
This approach eliminates explicit state encoding and combines the transition logic into a single expression.
