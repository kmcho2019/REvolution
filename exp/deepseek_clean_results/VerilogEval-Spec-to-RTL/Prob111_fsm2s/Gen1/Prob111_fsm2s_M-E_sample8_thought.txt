Here's a novel approach using a toggle-based implementation rather than explicit state transitions. The key idea is to treat the state as a toggle flip-flop where:
- j=1 toggles the state from OFF to ON (like a set)
- k=1 toggles the state from ON to OFF (like a reset)
This eliminates the need for case statements and implements the state machine as a modified T flip-flop with synchronous reset.

The output remains directly tied to the state bit as in a Moore machine. This approach reduces the control logic to simple combinational equations while maintaining the same functionality.
