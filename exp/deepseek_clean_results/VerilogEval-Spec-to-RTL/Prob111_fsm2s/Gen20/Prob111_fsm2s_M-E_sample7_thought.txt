Novel approach using edge detection:
1. Instead of a traditional state machine, implement a toggle mechanism that changes state on specific input edges
2. Use j's rising edge to transition from OFF to ON (like a set)
3. Use k's rising edge to transition from ON to OFF (like a reset)
4. This creates a more event-driven design while maintaining Moore machine properties
5. Still maintain synchronous reset functionality

Key advantages:
- More responsive to input changes
- Only reacts to actual transitions rather than level-sensitive inputs
- Potentially lower power as it only toggles on input edges
- Different architectural approach while meeting same spec
