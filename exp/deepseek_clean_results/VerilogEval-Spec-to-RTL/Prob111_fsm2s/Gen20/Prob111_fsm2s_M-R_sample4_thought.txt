Refactoring Strategy:

1. Structural Changes:
   - Replace the procedural always blocks with continuous assignments
   - Use a parameterized state encoding for better readability
   - Implement the state transitions using combinational logic with ternary operators

2. Advantages:
   - More concise implementation using continuous assignments
   - Explicit state names improve code readability
   - Same functionality but with different coding style
   - Maintains Moore machine properties (output depends only on state)

3. Key Differences:
   - State transitions expressed directly in assignments
   - No need for separate next_state variable
   - Output remains directly tied to current state
   - Reset condition handled in the same assignment
