Simplification Strategy:

1. State Representation:
   - Eliminate separate next_state register since we can directly compute and assign the next state
   - Use a single always block for both sequential and combinational logic

2. Logic Reduction:
   - Remove the case statement since we only have two states (can use simple if-else)
   - Directly assign output from state register (maintains Moore property)

3. Reset Handling:
   - Keep synchronous reset but handle it first in the always block
   - Simplify state transition logic to minimal expressions

Key Changes:
- Single always block for both state transition and update
- Minimal conditional logic for state transitions
- Maintains all functional requirements
- Reduced register usage by eliminating next_state
