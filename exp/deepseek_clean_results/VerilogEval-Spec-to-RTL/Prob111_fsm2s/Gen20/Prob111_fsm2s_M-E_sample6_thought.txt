Novel approach using edge detection:
1. Instead of a traditional state machine, implement a toggle flip-flop with enable
2. Use edge detection on input 'j' to trigger transition from OFF to ON
3. Use edge detection on input 'k' to trigger transition from ON to OFF
4. Maintain synchronous reset functionality
5. Output directly reflects the internal flip-flop state (Moore behavior)

Key advantages:
- Eliminates explicit state machine logic
- Uses edge detection for state transitions
- More efficient for certain input patterns
- Maintains same functional behavior as specification
