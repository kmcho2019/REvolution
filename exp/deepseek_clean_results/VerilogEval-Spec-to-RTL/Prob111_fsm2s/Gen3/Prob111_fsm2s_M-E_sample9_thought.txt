Here's a novel approach using a toggle-based implementation rather than explicit state transitions. The key idea is to treat the state as a toggle flip-flop where:
- j=1 acts as a set signal (forces state to 1)
- k=1 acts as a reset signal (forces state to 0)
- When neither is active, the state holds its value

This eliminates the need for explicit state transition logic and reduces the control logic to simple OR conditions. The output remains directly tied to the state bit as in a Moore machine.
