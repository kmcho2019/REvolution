Here's a novel approach using a dual-edge triggered design that combines both Moore and Mealy characteristics:
1. Use both rising and falling edges of the clock to potentially reduce latency
2. Implement the state transitions as a combinational function of current state and inputs
3. Use a shadow register to store the next state, updated on falling edge
4. Main state register updates on rising edge from shadow register
5. Output remains purely Moore-style (only depends on state)
This creates a pipeline-like behavior that could improve timing by spreading logic across both clock phases while maintaining synchronous behavior.
