The original solution is already optimal for a simple 2-state Moore machine, but we can make minor improvements:

1. Use an enum for states instead of parameters for better readability
2. Combine the state register and output into a single always block for potential synthesis optimization
3. Use blocking assignments for combinational logic (though in this case it's just the output)
4. Remove redundant parameter declarations since we're using enum

These changes maintain the same functionality while potentially helping synthesis tools optimize further.
