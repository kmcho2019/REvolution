Here's a novel approach using a toggle-based implementation instead of a traditional state machine:
1. Instead of explicit states, we'll use a toggle mechanism where:
   - j=1 toggles the output from 0 to 1
   - k=1 toggles the output from 1 to 0
2. This eliminates the need for state encoding and simplifies the transition logic
3. The output register serves as both state storage and output
4. Reset forces the output to 0 (OFF state)
5. This approach reduces logic complexity and should improve timing
