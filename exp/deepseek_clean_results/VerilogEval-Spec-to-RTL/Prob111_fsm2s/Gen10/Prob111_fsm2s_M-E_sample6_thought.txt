Here's a novel approach using a one-hot encoding scheme with explicit state transition logic. While this is slightly more complex for a 2-state machine, it demonstrates a scalable pattern that could be extended to larger state machines:

1. Use one-hot encoding (2 bits) for the states, though only 2 states are needed
2. Implement explicit state transition equations for each state
3. Use parallel AND-OR logic for next state computation
4. Maintain synchronous reset to OFF state (01)
5. Output is simply the ON state bit

This approach shows how we could scale to more states while keeping the transition logic clean and modular. The output remains purely combinational from the state bits (Moore machine).
