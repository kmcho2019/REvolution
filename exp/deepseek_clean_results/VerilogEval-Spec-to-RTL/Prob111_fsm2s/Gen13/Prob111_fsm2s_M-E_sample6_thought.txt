Here's a novel approach using a T-flipflop-based implementation with gated clocking:

1. **Key Insight**: 
   - The state transitions resemble a T-flipflop behavior where:
     - In OFF state: J acts as toggle enable (transition to ON when J=1)
     - In ON state: K acts as toggle enable (transition to OFF when K=1)

2. **Innovative Implementation**:
   - Use a single T-flipflop as the state storage element
   - Create a gated clock signal that only toggles when:
     - In OFF state and J=1, or
     - In ON state and K=1
   - The output is simply the flipflop's Q output
   - Reset forces Q to 0 (OFF state)

3. **Advantages**:
   - More hardware-efficient than traditional FSM implementation
   - Reduced power consumption due to clock gating
   - Simpler combinatorial logic
   - Naturally maps to standard cell libraries
