The problem requires implementing a Moore state machine with two states (OFF and ON) that transitions based on inputs j and k. The output 'out' is directly tied to the current state (0 for OFF, 1 for ON). The state transitions are:
- From OFF: stay if j=0, move to ON if j=1
- From ON: stay if k=0, move to OFF if k=1
Reset synchronously sets the state to OFF.
