The problem requires implementing a Moore state machine with two states (OFF and ON) and two inputs (j and k). The state transitions are:
- From OFF: stay OFF if j=0, go to ON if j=1
- From ON: stay ON if k=0, go to OFF if k=1
The output 'out' is 0 in OFF state and 1 in ON state. We'll use binary encoding for states (0=OFF, 1=ON) and implement synchronous reset to OFF state.

The design approach is:
1. Define states as parameters
2. Create state register
3. Implement combinational next state logic
4. Implement output logic (Moore style - output depends only on current state)
5. Handle synchronous reset
