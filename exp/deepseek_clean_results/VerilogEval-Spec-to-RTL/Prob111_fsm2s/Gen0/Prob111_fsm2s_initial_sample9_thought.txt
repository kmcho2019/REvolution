The problem requires implementing a Moore state machine with two states (OFF and ON) and synchronous reset. The state transitions are:
1. In OFF state (output=0):
   - If j=0, stay in OFF
   - If j=1, transition to ON
2. In ON state (output=1):
   - If k=0, stay in ON
   - If k=1, transition to OFF
Reset (active high) sets the state to OFF. We'll use binary encoding for the states (0=OFF, 1=ON) and implement the state transitions synchronously with the clock.
