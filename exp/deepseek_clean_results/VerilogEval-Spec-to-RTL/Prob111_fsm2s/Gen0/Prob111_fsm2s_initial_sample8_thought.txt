The problem requires implementing a Moore state machine with two states (OFF and ON) that transitions based on inputs j and k. The output (out) is determined by the current state. The state transitions are:
- From OFF: stays OFF if j=0, goes to ON if j=1
- From ON: stays ON if k=0, goes to OFF if k=1
Reset synchronously sets the state to OFF. We'll use binary encoding for the states (0=OFF, 1=ON) and implement the state transitions and output logic accordingly.
