The problem requires implementing a Moore state machine with two states (OFF and ON), two inputs (j and k), and one output (out). The state transitions are:
1. In OFF state (out=0):
   - If j=0, stay in OFF
   - If j=1, transition to ON
2. In ON state (out=1):
   - If k=0, stay in ON
   - If k=1, transition to OFF
The reset is synchronous and active-high, initializing the state to OFF.

I'll use binary encoding for the states (0=OFF, 1=ON) and implement the state transitions with a case statement. The output is directly tied to the current state.
