The problem requires implementing a Moore state machine with two states (OFF and ON) and two inputs (j and k). The state transitions are:
- From OFF state (output 0): stays in OFF if j=0, moves to ON if j=1
- From ON state (output 1): stays in ON if k=0, moves to OFF if k=1
The reset is synchronous and active-high, initializing the state to OFF.

I'll use a simple state register with two states, and combinational logic for next state and output. The output is directly derived from the current state (Moore machine characteristic).
