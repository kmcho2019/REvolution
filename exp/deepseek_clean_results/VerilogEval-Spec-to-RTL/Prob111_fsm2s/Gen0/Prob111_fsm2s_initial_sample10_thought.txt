The problem requires implementing a Moore state machine with two states (OFF and ON) that transitions based on inputs j and k. The output (out) depends solely on the current state. The state transitions are:
1. In OFF state (out=0): stays OFF if j=0, transitions to ON if j=1
2. In ON state (out=1): stays ON if k=0, transitions to OFF if k=1
The reset is synchronous and active-high, initializing the state to OFF.

I'll use a single state register with binary encoding (0=OFF, 1=ON) and implement the state transitions and output logic accordingly.
