Here's a refactored version that maintains the same behavior but uses a different implementation approach:
1. Instead of using explicit state registers and combinational logic, we'll implement the state machine using continuous assignments only
2. We'll model the state storage using a clocked assignment in an always block
3. The state transitions will be implemented directly in the always block
4. The output will be a simple continuous assignment from the state bit
5. This makes the code more compact while maintaining the same functionality

Key changes:
- Eliminate the separate next_state logic by moving it directly into the always block
- Keep the state encoding simple (0=OFF, 1=ON)
- Maintain synchronous reset behavior
- Output remains purely combinational
