Refactoring approach:
1. Eliminate the sequential always block by implementing the state machine purely with combinational logic and a single register
2. Use continuous assignments for both state transitions and output
3. Maintain the same synchronous reset behavior
4. Keep the binary state encoding for minimal hardware
5. The state register will still be updated on clock edges, but the next state logic will be moved to combinational assignments

Benefits:
- More compact code structure
- Clear separation of sequential (register) and combinational logic
- Easier to see the direct relationship between inputs and next state
- Maintains same functionality while potentially offering better synthesis optimization opportunities
