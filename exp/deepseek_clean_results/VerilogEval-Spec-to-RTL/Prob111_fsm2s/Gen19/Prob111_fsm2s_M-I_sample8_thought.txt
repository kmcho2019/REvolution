Optimization Strategy:
1. Maintain the existing efficient binary state encoding (OFF/ON)
2. Simplify the state transition logic by recognizing that:
   - When in OFF state, only j input matters
   - When in ON state, only k input matters
3. Use direct assignment for output to maintain Moore machine properties
4. Keep synchronous reset functionality
5. Optimize combinational logic to reduce gate count while maintaining same behavior

Key Improvements:
- More straightforward state transition logic
- Slightly reduced logic depth (from 2-input mux to direct AND/OR)
- Maintains all PPA advantages while being more readable
- Still uses minimal resources (single flip-flop)
