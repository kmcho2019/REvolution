I'll refactor the code to use binary state encoding instead of one-hot encoding, which will reduce the number of flip-flops needed. The key changes are:
1. Use a single bit state register (0=OFF, 1=ON)
2. Implement the state transitions with a simple case statement
3. Maintain the same Moore machine behavior where output depends only on current state
4. Keep synchronous reset functionality but simplify the state representation

This approach reduces area by using fewer flip-flops while maintaining the same functionality. The state transitions are now expressed more compactly in the always block.
