Here's a novel approach using a shift register implementation for the state machine:
1. Instead of traditional state encoding, use a 2-bit shift register where the current state is represented by the MSB
2. The shift register will circularly shift left on each clock cycle
3. State transitions are controlled by modifying the shift input based on current state and inputs
4. Output is directly the MSB of the shift register
5. Reset initializes the shift register to '01' (OFF state)

Key innovations:
- Eliminates explicit state transition logic by leveraging shift register behavior
- State transitions become simple bit manipulation of the shift input
- Maintains Moore machine properties with output only dependent on current state
- Uses minimal hardware (just a 2-bit register and simple combinational logic)
