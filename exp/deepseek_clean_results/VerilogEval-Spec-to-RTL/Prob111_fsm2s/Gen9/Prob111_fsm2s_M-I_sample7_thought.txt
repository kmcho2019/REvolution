To optimize the PPA metrics while maintaining functionality, I'll implement these improvements:

1. Switch from one-hot to binary encoding to reduce flip-flop count (area optimization)
2. Combine state transition logic into the always block to reduce combinational paths (performance optimization)
3. Maintain the same Moore machine behavior with synchronous reset
4. Use a single state register (1-bit) instead of two, reducing power consumption

The binary encoding will be:
- 0: OFF state
- 1: ON state

This reduces:
- Area by eliminating one flip-flop
- Power by reducing clock toggles
- Maintains the same timing characteristics since the logic is equally simple
