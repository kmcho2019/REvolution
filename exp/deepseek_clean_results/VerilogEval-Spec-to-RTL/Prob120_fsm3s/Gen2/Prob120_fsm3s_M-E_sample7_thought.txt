Instead of using explicit state encoding, we can implement the FSM using a saturating counter that represents the state implicitly. The key insights are:
1. States A, B, C, D can be represented by counter values 0, 1, 2, 3 respectively
2. The counter increments or decrements based on input conditions
3. Output is simply the MSB of the counter when counter is 3 (state D)
4. Reset sets counter to 0 (state A)
This approach reduces the state transition logic to simple arithmetic operations and eliminates the need for a case statement.
