Refactored design with these key changes:
1. Replaced combinational always blocks with continuous assignments (assign) for next_state and output logic
2. Used explicit state comparisons for output logic instead of bitwise operations
3. Maintained Gray code state encoding for optimal transitions
4. Kept synchronous reset and positive-edge triggered behavior
5. Simplified the structure by removing procedural blocks where possible

The advantages of this refactoring are:
- More concise code with continuous assignments
- Clearer state comparisons in output logic
- Maintains same PPA benefits of original implementation
- Easier to read and modify state transitions
