Instead of using traditional state encoding, I'll implement the FSM using a shift register approach where:
1. Each state is represented by a unique bit position in a 4-bit register
2. State transitions are implemented as controlled shifts
3. The output is directly derived from the MSB of the shift register
4. Reset initializes to '0001' (state A)

This approach has several advantages:
- Eliminates combinational next-state logic (just shift operations)
- Naturally implements one-hot encoding (only one bit active at a time)
- Output logic becomes trivial (just check the MSB)
- Potentially better timing as there's no complex state decoding
- Reset is still synchronous and simple to implement
