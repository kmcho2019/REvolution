Instead of using traditional state encoding, I'll implement the FSM using a circular shift register with thermometer encoding. This approach offers several advantages:
1. State transitions become simple shift operations
2. Output logic is simplified to detecting a specific pattern
3. Reduced combinational logic complexity
4. Natural one-hot encoding benefits (only one bit changes per transition)
5. Easily scalable to more states

The implementation will use a 4-bit shift register where each bit represents a state (A=1000, B=0100, C=0010, D=0001). The shift direction is controlled by the input 'in'. Reset initializes to state A (1000). The output is simply the D state bit.
