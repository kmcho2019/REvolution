To simplify the Moore FSM implementation while maintaining functionality, I'll make these optimizations:

1. Remove the separate next_state register and combine state transition logic directly in the sequential block
2. Use a single always block for both state transitions and register updates
3. Keep the same state encoding (A=00, B=01, C=10, D=11) for consistency
4. Maintain synchronous active-high reset functionality
5. Simplify output logic to be a direct assignment based on state bits

This reduces the design to just one always block and one continuous assignment, minimizing complexity while preserving all functionality. The state transitions are now handled directly in the clocked block, eliminating the combinational next_state logic.
