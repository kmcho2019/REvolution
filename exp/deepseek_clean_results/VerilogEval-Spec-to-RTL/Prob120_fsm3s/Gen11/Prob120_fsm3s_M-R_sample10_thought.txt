I'll implement the Moore FSM using a different approach that:
1. Uses one-hot encoding for the states instead of binary encoding
2. Maintains the same state transitions and output behavior
3. Uses separate always blocks for state transitions and output logic
4. Keeps the synchronous active-high reset functionality

Key differences from the original:
- One-hot encoding (4 bits) instead of binary (2 bits) for states
- Separate always blocks for combinational next-state logic and sequential state update
- Explicit state transition conditions using if-else statements
- Output remains combinational based on current state (Moore style)

This approach may offer better timing characteristics in some synthesis tools due to simpler decoding logic for each state.
