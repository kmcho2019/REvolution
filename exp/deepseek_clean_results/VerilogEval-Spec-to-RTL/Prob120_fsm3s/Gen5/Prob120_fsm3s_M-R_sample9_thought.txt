Refactored design with these key changes:
1. Replace the combinational always blocks with continuous assignments using 'assign' statements
2. Use a single always block for sequential logic (state register updates)
3. Keep the same Gray code state encoding for optimal transitions
4. Maintain identical functionality with synchronous reset
5. The output logic becomes a simple continuous assignment checking for state D

This approach reduces the number of always blocks while keeping the same state machine behavior. The continuous assignments may lead to slightly simpler synthesis results in some tools.
