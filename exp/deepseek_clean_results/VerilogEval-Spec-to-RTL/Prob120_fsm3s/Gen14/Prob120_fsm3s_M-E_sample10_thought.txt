I'll implement the FSM using a 2-bit binary counter where:
- State A = 00, B = 01, C = 10, D = 11
- The counter increments or decrements based on input conditions
- Special cases handle the non-linear transitions
- Output is directly decoded from the state value
- Reset initializes counter to 00 (state A)

This approach leverages arithmetic operations for state transitions which can be more efficient in some implementations. The key insight is that most transitions follow a counting pattern except for a few special cases that can be handled with simple logic.
