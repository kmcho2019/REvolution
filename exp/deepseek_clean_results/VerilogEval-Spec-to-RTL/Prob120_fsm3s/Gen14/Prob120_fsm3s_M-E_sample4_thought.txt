I'll implement a novel "parallel state evaluation" approach where:
1. Each state has its own dedicated next-state calculation logic
2. The current state acts as a multiplexer selecting the correct next state
3. State transitions are calculated in parallel rather than sequentially
4. Output is generated directly from state bits without comparison
5. Uses one-hot encoding for potentially better timing (each state has its own flip-flop)

Key advantages:
- Parallel state transition evaluation may improve timing
- One-hot encoding simplifies state decoding
- Each state's logic is independent and clearly visible
- Output is simply the MSB of the state (since D is state 1000)
