Refactored design with these optimizations:
1. Use one-hot encoding instead of Gray code for simpler output logic and potentially better timing
2. Replace combinational always blocks with continuous assignments (assign)
3. Simplify state transitions using direct assignments
4. Maintain same Moore machine behavior and synchronous reset
5. One-hot encoding: A=0001, B=0010, C=0100, D=1000 for simpler output logic (output is just state[3])

Key benefits:
- Output logic becomes trivial (just one bit)
- State transitions may be simpler for synthesis tools to optimize
- Maintains same functionality while potentially improving timing
