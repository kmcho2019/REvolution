To simplify the Moore FSM implementation while maintaining functionality:

1. Remove the separate next_state register since we can directly update the state register based on current state and input
2. Combine the state transition logic and state update into a single always block
3. Keep the same state encoding (A=00, B=01, C=10, D=11) for consistency
4. Maintain synchronous active-high reset functionality
5. Simplify output logic to be a direct function of the state bits
6. Eliminate unnecessary intermediate signals (next_state)

This reduces the design to its minimal essential components while preserving the exact same behavior. The single always block approach is cleaner and more straightforward for this small FSM.
