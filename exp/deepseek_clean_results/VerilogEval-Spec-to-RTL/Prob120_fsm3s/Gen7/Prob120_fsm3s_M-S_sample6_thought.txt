To simplify the Moore FSM implementation while maintaining functionality:

1. Remove the separate next_state register since we can directly compute the next state in the sequential block
2. Combine the state transition logic and state update into a single always block
3. Keep the same state encoding (A=00, B=01, C=10, D=11)
4. Maintain synchronous reset functionality
5. Simplify output logic to be a direct function of the state bits

This reduces the design to just one always block and one assign statement, eliminating the combinational next-state logic block while preserving the exact same behavior. The output remains purely combinational derived from the current state.
