Novel approach: Implement the state machine using a shift register with parallel load:
1. Represent each state as a one-hot encoded bit in a 4-bit shift register
2. Use a combination of shift operations and parallel loads for state transitions
3. The shift register naturally implements the state transitions through its shifting capability
4. Output is simply the MSB of the shift register (state D)
5. This approach leverages the physical characteristics of shift registers which can be more efficient in certain FPGA architectures
6. Reset initializes to state A (0001)
