Instead of a traditional state machine implementation, I'll use a shift register approach where:
1. Each state is represented by a unique 4-bit one-hot pattern (A=0001, B=0010, C=0100, D=1000)
2. State transitions are implemented through a rotating shift operation combined with input-dependent masking
3. The output is simply the MSB of the state register
4. Reset initializes to state A (0001)

This approach eliminates combinational next-state logic by using arithmetic shift operations that are input-dependent. The shift operations implement the state transitions directly through bit manipulation.
