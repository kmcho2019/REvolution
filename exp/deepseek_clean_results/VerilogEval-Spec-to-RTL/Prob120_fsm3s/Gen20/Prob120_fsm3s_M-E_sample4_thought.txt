Instead of using traditional state encoding, I'll implement the FSM using a circular shift register with one-hot encoding. This approach offers several advantages:
1. Faster state transitions (single bit shift operations)
2. Simpler output logic (directly tap the D state bit)
3. Lower dynamic power consumption (only one bit changes per transition)
4. Natural one-hot encoding ensures glitch-free outputs

The implementation will:
- Use a 4-bit shift register for states (A=0001, B=0010, C=0100, D=1000)
- Implement state transitions through conditional shifting
- Maintain synchronous reset functionality
- Output is simply the MSB of the shift register (state D)
