Innovative shift register-based FSM implementation:
1. Instead of traditional state encoding, use a 4-bit shift register where only one bit is high at any time (one-cold encoding)
2. Each state corresponds to a specific bit position in the shift register
3. State transitions are implemented by shifting left/right based on input
4. Output is simply the MSB of the shift register
5. Benefits:
   - Eliminates complex next-state logic - just shift operations
   - Output logic becomes trivial (just one bit)
   - Naturally glitch-free outputs
   - Very low power since only one bit flips per transition
   - Constant-time state transitions regardless of current state
