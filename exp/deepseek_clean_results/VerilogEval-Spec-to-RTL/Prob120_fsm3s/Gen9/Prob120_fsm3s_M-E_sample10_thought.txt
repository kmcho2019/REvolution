Innovative shift register-based FSM implementation:
1. Instead of traditional state encoding, use a circulating shift register where each state is represented by a unique bit position
2. Only one flip-flop is active (1) at any time, creating a "one-cold" encoding (inverse of one-hot)
3. State transitions are implemented by shifting left or right based on input
4. Output is simply the last bit of the shift register
5. Benefits:
   - Extremely simple next-state logic (just shift operations)
   - No complex decoding needed for output
   - Naturally glitch-free outputs
   - Very low power as only one bit changes per transition
   - Minimal combinational logic
