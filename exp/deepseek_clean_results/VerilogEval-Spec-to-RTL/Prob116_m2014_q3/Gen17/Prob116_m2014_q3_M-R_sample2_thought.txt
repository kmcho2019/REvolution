The original implementation uses a single continuous assignment with a logical OR of two AND terms. While efficient, we can refactor this to:

1. Use intermediate wires to break down the logic, which may improve readability and potentially help synthesis tools with optimization
2. Explicitly name the logical components to make the design intent clearer
3. Maintain the same functionality while presenting the logic in a more modular fashion

The refactored version will:
- Create two named wires for the AND terms
- Then combine them with an OR operation
- Keep the same input mapping (x[3:0] representing x[4:1] in the K-map)
- Result in identical functionality but with clearer structure
