Instead of using traditional AND-OR logic, I'll implement the function using a 4:1 multiplexer where the select lines are x[1] and x[2] (the inner K-map variables). The data inputs will be determined by x[3] and x[4] (the outer K-map variables). This approach:

1. Directly maps the K-map structure to hardware
2. Explicitly shows the decision-making hierarchy
3. May offer better timing characteristics as it uses a single level of multiplexing
4. Makes the don't-care optimization more visible in the code
