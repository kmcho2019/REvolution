The current implementation uses a ternary operator for the logic, which is clean and efficient. I'll refactor it to use explicit assign statements with logical operators, while maintaining the same functionality. This approach:

1. Makes the logic more explicit and easier to understand at a glance
2. Potentially helps synthesis tools optimize better by showing the exact logic structure
3. Maintains the same minimal gate count (1 AND and 1 OR operation)
4. Still leverages don't-care conditions effectively

The refactored version will use two separate assign statements to show the logical components clearly, then combine them with an OR operation.
