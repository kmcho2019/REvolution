Instead of using standard logic gates, we can implement the function using a configurable LUT-based approach. This method:
1. Creates a 3-input truth table (8 possible combinations)
2. Uses a parameterized mask to select the correct output pattern
3. Implements the logic by indexing into the precomputed truth table
4. Offers flexibility to change the logic function by just modifying the mask
5. Demonstrates an alternative FPGA-style implementation approach

Advantages:
- Easily reconfigurable for different logic functions
- Shows a different architectural style than standard gate implementations
- Illustrates how more complex functions could be built using this pattern
- Maintains the same functionality while using a different implementation strategy
