I'll implement a novel solution using a lookup table (LUT) approach with a case statement. This method:
1. Treats all input combinations as a 3-bit address (in1,in2,in3)
2. Uses a case statement to directly map each input combination to the correct output
3. Explicitly lists all 8 possible input combinations for clarity
4. Provides a truth-table style implementation that's easy to verify
5. Could potentially offer better synthesis results in some FPGA architectures that optimize LUTs

The key advantages are:
- Explicit truth table makes functionality immediately verifiable
- No intermediate signals needed
- Easily extensible if logic needs to change
- Potential for better optimization in LUT-based FPGAs
