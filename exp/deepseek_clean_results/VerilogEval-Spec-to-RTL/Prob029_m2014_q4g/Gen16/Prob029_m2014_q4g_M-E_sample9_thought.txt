Here's a novel approach using a lookup table (LUT) implementation with a 4-input MUX. The idea is to:
1. Treat the three inputs (in1, in2, in3) as a 3-bit address
2. Pre-compute all possible output values (8 cases) based on the truth table
3. Use a multiplexer to select the correct output based on the input combination
4. This approach demonstrates an alternative implementation style that might be useful in FPGA designs where LUTs are primitive elements

While this isn't necessarily more efficient for this simple function, it shows a different architectural approach that could be beneficial for more complex functions or in certain technologies.
