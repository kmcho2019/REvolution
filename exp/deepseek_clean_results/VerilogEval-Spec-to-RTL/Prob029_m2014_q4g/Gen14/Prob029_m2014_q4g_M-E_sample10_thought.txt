Here's a novel approach using a lookup table (LUT) based implementation with configurable logic:

1. **LUT Concept**: Implement the logic using a 3-input LUT where the truth table is programmed to match the desired function. This approach is more flexible and can be easily modified if requirements change.

2. **Parameterized Design**: Use parameters to define the LUT contents, making the module more maintainable and adaptable.

3. **Bitwise Operation**: Instead of chaining XNOR and XOR, we'll precompute all possible input combinations (8 cases for 3 inputs) and select the correct output using concatenated inputs as an index.

Advantages:
- More flexible for future modifications
- Potentially better for FPGA implementations where LUTs are native resources
- Clear mapping between truth table and implementation
- Easier to verify correctness by inspection
