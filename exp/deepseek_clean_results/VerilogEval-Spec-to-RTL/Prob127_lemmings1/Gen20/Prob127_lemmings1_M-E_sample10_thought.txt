Here's a novel approach using a toggle-based state machine instead of explicit state encoding:

1. Instead of maintaining separate states for left/right, we'll use a single toggle bit that flips when a bump occurs
2. The direction is determined by the current toggle value (0=left, 1=right)
3. Bump events on either side will toggle the direction
4. This reduces the state transition logic to a simple XOR operation
5. The asynchronous reset initializes the toggle to 0 (walk left)
6. This approach minimizes the combinational logic to just an XOR gate for next state calculation

Benefits:
- Simpler state transition logic (just XOR)
- More compact implementation
- Still maintains all required functionality
- Potentially better timing due to reduced logic depth
