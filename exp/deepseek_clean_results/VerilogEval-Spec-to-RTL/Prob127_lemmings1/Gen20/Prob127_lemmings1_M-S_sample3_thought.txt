The current solution is already quite minimal, but we can simplify it further by:
1. Eliminating the explicit state register and instead using direct output registers
2. Combining the state transitions and output logic into a single always block
3. Using the outputs themselves as state representation (since they're mutually exclusive)
4. Maintaining the same Moore machine behavior with fewer lines of code

This approach removes the separate state variable and directly uses the outputs to represent the state, making the implementation more compact while preserving functionality.
