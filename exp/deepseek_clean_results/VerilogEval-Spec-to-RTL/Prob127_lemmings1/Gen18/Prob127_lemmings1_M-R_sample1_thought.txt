Refactoring Approach:
1. State Representation: Keep the same 1-bit state encoding but represent it as a wire instead of reg
2. Next State Logic: Implement the state transition using continuous assignments only (no always blocks)
3. Output Logic: Maintain direct assignments but simplify using bitwise operations
4. Reset Handling: Use a conditional assignment for the reset state
5. Optimization: Eliminate the intermediate next_state wire by computing directly in the state assignment

Key Changes:
- Fully combinational implementation using only assign statements
- State is now a wire driven by a conditional expression
- More compact representation while maintaining same functionality
- Removes sequential always block while keeping same Moore machine behavior
- Uses ternary operators for compact state transitions
