Novel Architectural Idea: State Machine with Direction Toggle
1. Instead of using traditional state transitions, implement a "direction toggle" approach where the state simply flips when any bump occurs
2. Use a single-bit state register to represent direction (0=left, 1=right)
3. Any bump input (left or right) will toggle the current direction
4. This approach simplifies the transition logic to a single XOR operation combining all bump inputs
5. Outputs are directly derived from the state bit
6. Asynchronous reset initializes to left direction (0)

Key Advantages:
- Simplifies transition logic to a single XOR gate
- Handles simultaneous bumps naturally (they cancel out)
- Reduces logic complexity compared to traditional FSM implementations
- Maintains all required functionality with minimal hardware
