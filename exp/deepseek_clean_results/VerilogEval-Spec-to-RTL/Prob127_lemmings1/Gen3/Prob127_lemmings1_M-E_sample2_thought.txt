Here's a novel approach that uses a different state encoding and transition logic style:

1. Instead of using binary state encoding, we'll represent the state as a direction bit (0=left, 1=right) combined with a toggle bit that flips when a bump occurs. This creates a more event-driven design.

2. The state machine will use the bump inputs to directly compute the next direction, eliminating the need for a separate next_state variable. The direction flips when either bump is active.

3. We'll implement the state register to store just the current direction, making the design more compact.

4. The output logic remains simple Moore-style outputs from the state bit.

This approach reduces the state transition logic to a simple XOR operation, potentially improving timing and area while maintaining the same functionality.
