The current implementation is already quite optimal in terms of PPA metrics. However, we can make a few minor improvements:

1. Remove the intermediate next_state wire and directly compute the next state in the always block to reduce one level of logic
2. Use localparam instead of parameter since these constants are only used within this module
3. Simplify the state transition logic by using XOR-style toggling when bumped, which better matches the problem's requirement of switching directions when bumped

These changes will:
- Slightly reduce combinational logic (eliminating one mux level)
- Maintain the same functionality
- Potentially improve timing slightly by reducing logic depth
- Keep the same area and power characteristics
