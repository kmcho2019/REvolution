To optimize this design for better PPA (Power, Performance, Area), I'll implement the following improvements:

1. State Encoding Optimization:
   - Use one-hot encoding (2 bits) instead of binary encoding (1 bit) to potentially reduce combinational logic complexity
   - This may allow simpler output logic and better timing

2. Combinational Logic Simplification:
   - Replace the ternary operators with direct boolean expressions
   - Use XOR for state transition logic which is more area-efficient

3. Output Logic Optimization:
   - Directly assign outputs from state bits without inversion
   - This eliminates the need for separate inverters

4. Clock Gating Consideration:
   - While not implemented here (due to minimal benefit), the structure allows easy addition of clock gating if needed
