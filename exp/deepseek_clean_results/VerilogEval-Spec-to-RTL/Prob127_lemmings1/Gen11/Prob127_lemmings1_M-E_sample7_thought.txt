Here's a novel approach using a toggle-based state machine with edge detection:
1. Instead of tracking direction explicitly, we'll use a toggle bit that flips when any bump occurs
2. We'll detect rising edges on bump signals to trigger state changes
3. The walk direction is determined by the toggle bit's value
4. This approach minimizes state transitions (only toggles when needed) and simplifies the logic
5. The edge detection ensures we only respond to new bumps, not sustained ones
