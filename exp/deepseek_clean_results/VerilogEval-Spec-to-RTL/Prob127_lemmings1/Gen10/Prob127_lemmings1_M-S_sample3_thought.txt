The state machine can be simplified further by:
1. Removing the localparam definitions since we're only dealing with two states that can be represented by a single bit
2. Directly using the state bit to represent direction (0=left, 1=right)
3. Simplifying the state transition logic by observing that:
   - When in left state, only bump_left matters
   - When in right state, only bump_right matters
   - Bumps on both sides simultaneously will still cause direction switch
4. Outputs can directly mirror the state bit and its inverse
This reduces the logic to its minimal form while maintaining identical functionality.
