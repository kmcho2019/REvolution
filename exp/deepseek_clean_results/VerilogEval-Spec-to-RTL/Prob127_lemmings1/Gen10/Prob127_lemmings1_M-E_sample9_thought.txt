Novel Approach: Direction Flipping with Edge Detection

Instead of using a traditional state machine with explicit states, we can model the behavior as a direction flip-flop where:
1. The direction is represented by a single bit (0=left, 1=right)
2. Any bump event (left or right) flips the direction
3. Simultaneous bumps still cause a flip (equivalent behavior)
4. Reset initializes to left

Key innovations:
- Uses edge detection on bump signals to trigger direction flips
- Implements the state as a simple toggle flip-flop
- Reduces next-state logic to a simple XOR operation
- Maintains identical external behavior but with potentially simpler internal logic
- May offer better PPA in some technologies due to reduced logic complexity
