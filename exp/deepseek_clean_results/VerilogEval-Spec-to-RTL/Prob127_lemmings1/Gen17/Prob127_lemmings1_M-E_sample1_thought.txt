Instead of a traditional state machine, we can implement a toggle mechanism where:
1. The direction is toggled whenever a valid bump event occurs (rising edge of bump signals)
2. Edge detection is used to ensure each bump only triggers one state change
3. Priority is given to simultaneous bumps by treating them as a single toggle event
4. The design uses fewer gates overall by eliminating explicit state comparison logic

This approach reduces the state transition logic to a simple XOR operation while maintaining correct functionality. The edge detection ensures clean transitions without glitches from prolonged bump signals.
