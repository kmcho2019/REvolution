Novel Architectural Idea: Dual-Edge Triggered State Machine with Direction Priority

1. Dual-Edge Triggering: Utilize both clock edges to potentially improve timing margins by spreading logic across edges
2. Direction Priority: Implement explicit priority logic for simultaneous bumps (right over left)
3. State Encoding: Use Gray coding for state representation to minimize transitions
4. Output Generation: Derive outputs directly from state bits without additional logic
5. Reset Handling: Maintain asynchronous reset but with explicit state initialization

Key Innovations:
- Uses both clock edges to potentially reduce critical path
- Explicit priority handling for simultaneous bumps
- Gray coding for reduced switching power
- Direct output mapping from state register
- Maintains same functionality with potential PPA improvements
