Here's an alternative approach using a single-bit state register and combinational logic for outputs:
1. Instead of explicit state parameters, use the state bit directly to represent direction (0=left, 1=right)
2. The state transitions can be expressed as:
   - If current state is left (0) and bump_left occurs, switch to right (1)
   - If current state is right (1) and bump_right occurs, switch to left (0)
3. Outputs are simply the state bit and its inverse
4. Reset forces state to 0 (left)
This approach eliminates the need for a separate next_state calculation by directly computing the next state in the sequential block, making the implementation more compact.
