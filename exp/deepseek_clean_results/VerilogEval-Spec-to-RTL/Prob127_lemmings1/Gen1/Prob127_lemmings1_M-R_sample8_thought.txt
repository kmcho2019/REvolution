The refactored solution maintains the same Moore state machine behavior but implements it with a more concise structure:
1. Use a single always block for both state transition and register (eliminating next_state reg)
2. Simplify output assignments by directly using the state bit
3. Remove the parameter declarations since we're using simple binary states
4. The state transition logic remains identical, just more compactly expressed
This approach reduces the number of always blocks while maintaining the same functionality.
