Here's a novel approach using a toggle-based state machine:
1. Instead of explicit state encoding, we'll use a single flip-flop that toggles direction
2. The flip-flop value directly represents the walking direction (0=left, 1=right)
3. Any bump (left or right) will toggle the direction
4. Simultaneous bumps will still toggle the direction (same as spec)
5. This reduces the state machine to a simple toggle flip-flop with bump detection
6. Outputs are directly derived from the flip-flop value
7. Maintains asynchronous reset functionality

Key advantages:
- Simpler implementation with fewer logic gates
- Single flip-flop instead of state register
- Natural handling of simultaneous bumps
- Same behavior but with different internal representation
