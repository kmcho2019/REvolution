The current implementation is already quite optimal for PPA, but we can make a few minor improvements:

1. State Encoding: Keep the binary encoding (1-bit) as it's most efficient for 2 states.

2. Next State Logic: Simplify the ternary operator by using XOR logic for direction change, which reduces gate count slightly.

3. Output Logic: Keep direct assignments but use implicit state checks for minimal logic.

4. Reset Handling: Maintain asynchronous reset for clean initialization.

Key optimizations:
- Replace ternary with XOR-based direction change logic (saves 1 gate)
- Use implicit state checks for outputs (same efficiency but cleaner)
- Maintain same reset behavior
- Results in slightly better area/power with identical timing
