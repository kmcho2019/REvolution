The problem requires implementing a Moore state machine with two states (WALK_LEFT and WALK_RIGHT) for a Lemming that changes direction when it bumps into obstacles. The state transitions are:
1. From WALK_LEFT to WALK_RIGHT when bump_left is 1
2. From WALK_RIGHT to WALK_LEFT when bump_right is 1
3. If both bumps occur simultaneously, the Lemming should switch direction (priority doesn't matter since it's a toggle)
The outputs (walk_left and walk_right) are directly derived from the current state. The machine should asynchronously reset to WALK_LEFT state when areset is 1.
