The problem requires implementing a Moore state machine with two states (WALK_LEFT and WALK_RIGHT) that controls a Lemming's movement direction. The state transitions are:
1. When in WALK_LEFT state:
   - If bump_left is asserted, transition to WALK_RIGHT
   - Otherwise, stay in WALK_LEFT
2. When in WALK_RIGHT state:
   - If bump_right is asserted, transition to WALK_LEFT
   - Otherwise, stay in WALK_RIGHT
The outputs (walk_left and walk_right) are directly derived from the current state. An asynchronous reset (areset) initializes the state to WALK_LEFT.
