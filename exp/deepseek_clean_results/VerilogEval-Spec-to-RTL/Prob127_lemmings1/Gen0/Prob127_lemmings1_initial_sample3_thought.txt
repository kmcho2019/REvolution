The problem requires implementing a Moore state machine with two states (walking left and walking right) for a Lemming. The state transitions are triggered by bump signals (bump_left and bump_right) which cause the Lemming to change direction. The machine should reset to walking left when areset is high. 

Key points:
1. Two states: LEFT (walking left) and RIGHT (walking right)
2. State transitions:
   - If in LEFT state and bump_left is 1, move to RIGHT
   - If in RIGHT state and bump_right is 1, move to LEFT
   - If both bumps occur simultaneously, switch direction (priority doesn't matter since both bumps cause direction switch)
3. Outputs:
   - walk_left is 1 when in LEFT state
   - walk_right is 1 when in RIGHT state
4. Asynchronous reset (areset) sets state to LEFT
