The problem requires implementing a Moore state machine with two states (LEFT and RIGHT) to model the Lemming's behavior. The state transitions are:
1. When in LEFT state and bump_left is asserted, transition to RIGHT
2. When in RIGHT state and bump_right is asserted, transition to LEFT
3. If both bumps occur simultaneously, the Lemming should still switch directions
The outputs (walk_left and walk_right) are purely dependent on the current state. The reset (areset) asynchronously sets the initial state to LEFT.

The implementation will use:
- A state register to hold current state (LEFT or RIGHT)
- Combinational logic for next state based on current state and inputs
- Output logic based solely on current state
