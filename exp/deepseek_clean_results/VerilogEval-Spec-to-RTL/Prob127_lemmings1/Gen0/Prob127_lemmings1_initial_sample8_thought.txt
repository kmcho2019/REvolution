The problem requires implementing a Moore state machine with two states (WALK_LEFT and WALK_RIGHT) to model the behavior of a Lemming. The state transitions are:
1. If in WALK_LEFT state and bump_left is asserted, transition to WALK_RIGHT
2. If in WALK_RIGHT state and bump_right is asserted, transition to WALK_LEFT
3. If both bumps occur simultaneously, the Lemming should still switch directions
The outputs (walk_left and walk_right) are directly derived from the current state. The asynchronous reset (areset) forces the machine into WALK_LEFT state.
