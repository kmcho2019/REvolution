The problem requires implementing a Moore state machine with two states (WALK_LEFT and WALK_RIGHT) that controls a Lemming's movement. The state transitions are:
1. If in WALK_LEFT state and bump_left is asserted, transition to WALK_RIGHT
2. If in WALK_RIGHT state and bump_right is asserted, transition to WALK_LEFT
The outputs (walk_left and walk_right) are directly derived from the current state. The machine should reset to WALK_LEFT state when areset is asserted.
