To implement the Lemmings game behavior, we need a Moore state machine with two states: LEFT and RIGHT. The state transitions are determined by the bump inputs:
1. When in LEFT state, if bump_left is 1, transition to RIGHT
2. When in RIGHT state, if bump_right is 1, transition to LEFT
3. If both bumps occur simultaneously in any state, transition to the opposite state
The outputs walk_left and walk_right are directly derived from the current state.
The areset signal will asynchronously reset the state to LEFT.
