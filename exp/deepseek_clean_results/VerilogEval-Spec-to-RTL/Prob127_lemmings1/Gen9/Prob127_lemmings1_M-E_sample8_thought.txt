Novel Architecture Idea:
Instead of using a single state bit, let's implement a "momentum-based" state machine where the direction change has a slight delay. This creates a more realistic behavior where the lemming doesn't instantly reverse direction but has a brief transition period. We'll use two state bits to represent four states: LEFT, RIGHT, TURNING_LEFT, and TURNING_RIGHT. The turning states act as buffers between direction changes.

Key Features:
1. More realistic movement with turning states
2. Still maintains all functional requirements
3. Handles simultaneous bumps gracefully
4. Uses edge detection for bump inputs to prevent glitches
5. Asynchronous reset still initializes to left state

Advantages:
- More realistic behavior simulation
- Glitch-free operation with edge detection
- Clear state transitions
- Maintains Moore machine properties
