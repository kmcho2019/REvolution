Here's a novel approach using a toggle-based state machine instead of explicit states:
1. Instead of maintaining separate states, we'll use a single flip-flop to represent direction (0=left, 1=right)
2. The flip-flop will toggle when either bump input is active (XOR behavior)
3. Simultaneous bumps will still toggle the direction (since 1 XOR 1 = 0)
4. This reduces the state machine to a simple toggle flip-flop with bump inputs as the toggle condition
5. Outputs are derived directly from the flip-flop value
This approach minimizes logic and state representation while maintaining correct behavior.
