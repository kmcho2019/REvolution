Here's an alternative approach using a toggle-based state machine instead of explicit state encoding. The key idea is to represent the direction as a single bit that toggles when a bump is detected. This eliminates the need for explicit state parameters and simplifies the transition logic.

Key features:
1. Single direction bit (dir) represents current state:
   - 0: walking left
   - 1: walking right
2. Transition occurs when either bump is detected (XOR operation)
3. Same asynchronous reset behavior
4. Outputs derived directly from the direction bit

Advantages:
- More compact state representation
- Simpler transition logic (single XOR gate)
- Same functionality with potentially fewer gates
