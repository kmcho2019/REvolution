The current implementation is already quite efficient, but we can make some minor optimizations:

1. Remove the intermediate next_state wire and directly compute the next state in the always block to reduce routing resources
2. Use a single output wire with encoding (left=0, right=1) to potentially save one output buffer
3. Simplify the state transition logic by recognizing that simultaneous bumps just toggle the state
4. Maintain the same Moore machine behavior but with slightly reduced logic depth

These changes should marginally improve area and power while maintaining the same timing characteristics.
