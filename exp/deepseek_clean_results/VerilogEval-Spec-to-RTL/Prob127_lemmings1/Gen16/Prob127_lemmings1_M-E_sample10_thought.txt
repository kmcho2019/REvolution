Here's a novel approach using a toggle-based state machine with edge detection:
1. Instead of explicit states, we'll use a single toggle bit that flips on direction changes
2. Implement edge detection on bump signals to ensure clean transitions
3. Use XOR-based logic for direction determination which is more area-efficient
4. Maintain the same Moore machine behavior but with a different implementation style
5. The design will be more resilient to glitches on bump inputs due to the edge detection

This approach reduces the state machine complexity while maintaining the same functionality, and the edge detection makes it more robust to input noise.
