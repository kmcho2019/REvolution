Instead of using traditional state encoding, we can implement a toggle-based state machine that flips direction on any bump. This approach:
1. Uses a single bit state register to represent direction (0=left, 1=right)
2. Combines bump signals into a single toggle signal (any bump causes direction change)
3. Eliminates the need for case statements by using XOR-based toggling
4. Maintains Moore machine properties with outputs directly derived from state
5. Reduces logic complexity by treating left/right bumps uniformly
6. Still properly handles simultaneous bumps (will toggle direction)
7. Uses asynchronous reset to initialize to left direction
This approach minimizes logic while maintaining all specified behavior.
