Novel Architectural Idea: State Encoding with Implicit Direction
Instead of using a traditional binary state encoding, we'll leverage the output signals themselves as the state representation. This eliminates the need for a separate state register and reduces the logic depth. The key insights are:
1. The outputs (walk_left and walk_right) are mutually exclusive and can directly represent the state
2. We can use combinational logic to determine the next output state based on current outputs and bumps
3. The outputs are registered, making it a Moore machine
4. Reset initializes the outputs directly
This approach saves area by eliminating the state register and reduces power by minimizing switching activity.

Advantages:
- No explicit state variable needed
- Direct output-to-next-state mapping
- Fewer registers and simpler logic
- Maintains clean Moore machine behavior
