Novel Architectural Idea: State Encoding with Direction Flip-Flop

Instead of using a traditional state register, we'll implement the direction as a flip-flop that toggles based on bump inputs. This approach:
1. Uses a single flip-flop to represent direction (0=left, 1=right)
2. Implements bump detection as a toggle condition:
   - Any bump (left or right) toggles the direction
   - Simultaneous bumps also toggle (equivalent to single bump)
3. Maintains Moore machine outputs directly from the flip-flop
4. Uses asynchronous reset to initialize to left direction

Advantages:
- Simpler state transition logic (just XOR operation)
- More intuitive mapping between physical direction and state
- Reduced gate count for next state logic
- Maintains all required functionality
