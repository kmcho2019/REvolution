Here's a novel approach using a toggle-based state machine with edge detection:
1. Instead of tracking direction states, we'll track direction changes using a toggle bit
2. Use edge detection on bump signals to trigger direction changes
3. Implement a 'toggle' mechanism where each valid bump event flips the direction
4. This approach reduces state transitions to only when needed (on bump events)
5. The outputs are derived directly from the toggle bit state

This method is more event-driven and minimizes unnecessary state updates while maintaining the same functionality.
