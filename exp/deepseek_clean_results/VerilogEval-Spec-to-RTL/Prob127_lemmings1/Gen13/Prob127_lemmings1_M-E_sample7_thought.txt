Here's a novel approach using a toggle-based state machine with direction priority:

1. Instead of tracking direction with a state bit, we'll use a toggle register that flips when any bump occurs
2. The actual walking direction is determined by both the toggle state and which bump was detected
3. Priority is given to simultaneous bumps - we'll treat them as right bumps to ensure deterministic behavior
4. This approach reduces the state transition logic to a simple XOR while maintaining all functionality
5. The output logic becomes slightly more complex but remains combinational
6. Asynchronous reset initializes the toggle to 0 (left walk)

Key advantages:
- Single-bit storage like original solution
- More uniform state transitions (always toggles on any bump)
- Clear priority handling for simultaneous bumps
- Potential for better timing as state transition logic is simpler
