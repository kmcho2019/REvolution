Novel Approach: State Encoding with Direction Toggle
1. Instead of using separate states for left/right, use a single state bit that toggles direction
2. The state bit directly represents the current walking direction (0=left, 1=right)
3. Bump inputs act as toggle signals - any bump causes direction to flip
4. This eliminates the need for case statements, simplifying the logic
5. Reset initializes to left (0) as required
6. Outputs are simply the state bit and its inverse

Key Advantages:
- More compact state representation
- Single always block with simple toggle logic
- Eliminates conditional branching in next state logic
- Output logic becomes trivial
- Maintains same functionality with potentially better PPA
