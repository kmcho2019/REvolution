Here's a novel approach using a toggle-based state machine instead of explicit state encoding:

1. Instead of maintaining separate states, we'll use a single toggle bit that flips direction on any bump
2. When a bump occurs (left or right), we simply invert the current direction
3. This eliminates the need for separate state transition logic for left and right bumps
4. The output is directly derived from the toggle bit (0=left, 1=right)
5. This approach reduces the state transition logic to a single XOR operation, potentially improving timing
6. Maintains the same Moore machine behavior with simpler combinational logic
