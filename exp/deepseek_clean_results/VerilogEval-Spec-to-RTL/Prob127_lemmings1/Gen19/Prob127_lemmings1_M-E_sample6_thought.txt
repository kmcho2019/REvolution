Here's a novel approach using a toggle-based state machine with edge detection:
1. Instead of tracking direction with a state bit, we'll use a toggle flip-flop that changes state on any bump
2. We'll detect rising edges on bump signals to trigger state changes
3. The direction is determined by the current toggle state
4. This approach minimizes state transitions and handles simultaneous bumps naturally
5. We'll use a single register for the toggle state and simple combinational logic for edge detection

This implementation is more event-driven and may be more power-efficient since it only toggles state when bumps occur, rather than evaluating conditions every cycle.
