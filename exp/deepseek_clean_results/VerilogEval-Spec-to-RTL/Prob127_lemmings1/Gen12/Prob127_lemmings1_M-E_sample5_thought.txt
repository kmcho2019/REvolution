Here's a novel approach using a toggle-based state machine with edge detection:

1. Instead of tracking direction states, we'll use a single toggle bit that flips on any bump.
2. We'll detect rising edges on bump signals to trigger state changes.
3. The current direction is determined by the toggle bit's state.
4. This approach reduces state transitions to simple toggles and eliminates complex conditionals.
5. Edge detection ensures we only respond to new bumps, not sustained signals.
6. Asynchronous reset initializes the toggle to 0 (walk left).

Advantages:
- Simpler transition logic (just XOR operations)
- More robust to sustained bump signals
- Fewer conditional statements
- Maintains same functionality with different implementation
