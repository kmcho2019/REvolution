Simplification Strategy:
1. State Encoding: Keep the minimal 1-bit state encoding (0=left, 1=right)
2. Next State Logic: Simplify to a single XOR operation that captures all transition cases:
   - XOR between current state and any bump signal (left or right)
   - This handles all cases (single bumps, both bumps) with minimal logic
3. Output Logic: Maintain direct state assignment for outputs
4. Reset Handling: Keep simple asynchronous reset to left state

Key Improvements:
- Next state logic reduced to just one XOR operation
- Maintains all functionality while being more minimal
- Still clearly shows state transitions
- Preserves all PPA advantages
