Here's a novel approach using a toggle-based state machine instead of explicit state encoding:

1. Instead of tracking LEFT/RIGHT states explicitly, we'll use a single bit that toggles direction on any bump
2. The current direction is represented by the state bit's value (0=left, 1=right)
3. Any bump (left or right) will toggle the direction
4. This reduces the state transition logic to a simple XOR operation with the bump signals
5. The outputs are derived directly from the state bit without comparison
6. Maintains asynchronous reset functionality

Benefits:
- Simpler transition logic (single XOR gate)
- Fewer logic levels for potentially better timing
- More compact implementation
- Still maintains clear Moore machine behavior
