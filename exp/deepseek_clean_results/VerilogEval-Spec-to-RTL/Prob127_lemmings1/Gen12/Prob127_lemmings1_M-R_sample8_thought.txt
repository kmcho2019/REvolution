Refactored design using continuous assignments for the entire state machine:

1. State Representation: Keep binary encoding (0=left, 1=right) but implement as a wire instead of reg
2. State Transition: Use continuous assignment for next state logic
3. State Storage: Implement the flip-flop using a clocked continuous assignment
4. Output Logic: Maintain direct continuous assignments
5. Reset Handling: Use ternary operator for async reset in the state assignment

Key changes:
- Eliminated procedural blocks (always) in favor of continuous assignments
- State storage implemented with clock-gated assignment
- Same functionality but more dataflow-oriented style
- Slightly more compact representation
- Maintains identical timing characteristics
