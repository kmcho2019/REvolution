Here's a novel approach using a toggle-based state machine with direction flipping:

1. Instead of tracking absolute direction states, we'll track direction changes (flips)
2. Each bump event (left or right) will toggle a flip direction signal
3. The current walking direction is determined by counting the number of flips (even=left, odd=right)
4. This creates a more event-driven design that naturally handles simultaneous bumps
5. The state is simply the flip count parity (1 bit)
6. Outputs are derived directly from the flip count parity

Advantages:
- More intuitive handling of simultaneous bumps (they cancel out)
- Simpler transition logic (just XOR operations)
- Naturally handles any combination of bump events
- Easily extensible if more states are needed later
