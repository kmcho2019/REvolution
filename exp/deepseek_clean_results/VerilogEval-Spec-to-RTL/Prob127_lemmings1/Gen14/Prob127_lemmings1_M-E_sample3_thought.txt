Novel Architectural Idea: Dual-Edge Triggered State Machine with Direction Prediction

Instead of using a traditional single-edge triggered state machine, this design employs a dual-edge triggered approach (both rising and falling clock edges) to potentially reduce latency in direction changes. The state machine also includes a simple prediction mechanism where if both bump signals are active simultaneously, it toggles the direction rather than choosing arbitrarily. This creates more natural-looking behavior when collisions happen from both sides.

Key Features:
1. Dual-edge triggering for faster response to bump signals
2. Predictive toggling when both bumps occur simultaneously
3. Maintains Moore machine properties (outputs depend only on state)
4. Still uses minimal state encoding (single bit)
5. Asynchronous reset remains on positive edge for consistency
