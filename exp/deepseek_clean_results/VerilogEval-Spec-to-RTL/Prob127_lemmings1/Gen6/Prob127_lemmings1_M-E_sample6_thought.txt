I'll implement a solution that:
1. Uses one-hot encoding for states (though only two states are needed)
2. Implements state transitions using bitwise operations instead of conditionals
3. Combines bump signals into a single control signal
4. Uses XOR-based state transition logic for compact implementation

The key innovation is treating the state transition as a toggling operation when bumps occur, which simplifies the logic. The one-hot encoding (though not strictly necessary for 2 states) makes the design more scalable if more states are added later.
