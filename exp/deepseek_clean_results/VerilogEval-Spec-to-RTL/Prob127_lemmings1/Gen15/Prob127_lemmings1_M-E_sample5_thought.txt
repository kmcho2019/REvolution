Here's a novel approach using a priority-based state machine with explicit state transitions:

1. Instead of using XOR logic, implement explicit state transition conditions with priority:
   - Highest priority: simultaneous bumps (switch direction)
   - Medium priority: single bump (switch to opposite direction)
   - Lowest priority: no bumps (maintain current state)

2. Use a separate combinational block for next state logic to improve readability and potential timing optimization.

3. Implement outputs directly derived from state with no additional logic, maintaining clean Moore machine properties.

This approach:
- Makes the state transitions more explicit and readable
- Potentially improves timing by separating combinational logic from sequential
- Maintains the same functionality while being more maintainable
- Could be easier to extend for future state additions
