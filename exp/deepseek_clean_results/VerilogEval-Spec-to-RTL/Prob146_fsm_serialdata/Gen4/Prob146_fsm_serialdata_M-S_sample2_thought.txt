Here's a simplified approach focusing on the core requirements:

1. Use a basic state machine with clear states: IDLE, DATA, STOP
2. Eliminate complex timing logic - sample bits on clock edges
3. Track bit position with a simple counter
4. Shift in data bits LSB first during DATA state
5. Validate stop bit before asserting done
6. Return to IDLE only after valid stop bit or reset
7. Keep synchronous reset and registered outputs

Key simplifications:
- Removed midpoint sampling timer
- Simplified state machine to 3 states
- Direct bit sampling without edge detection
- Clear sequential logic for data collection
- Maintains all protocol requirements
