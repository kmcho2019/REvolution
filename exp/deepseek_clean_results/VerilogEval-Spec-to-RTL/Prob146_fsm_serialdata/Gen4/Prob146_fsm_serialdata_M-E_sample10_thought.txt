Here's a novel approach using a shift register with parallel load and a bit counter with early termination detection:

1. Instead of a traditional FSM, we'll use a data-driven approach where the shift register itself controls the state transitions.
2. We'll implement a 10-bit shift register (1 start + 8 data + 1 stop) that captures the entire frame.
3. A counter will track the number of bits received, and we'll use the counter value to determine when to validate the frame.
4. The start bit detection will initiate the reception, and the counter will automatically handle the timing.
5. When the counter reaches 9 (all bits received), we'll check if the first bit is 0 (start) and last bit is 1 (stop).
6. This approach eliminates explicit state transitions and reduces control logic complexity.
7. The done signal will pulse for one cycle when a valid frame is detected.
8. Invalid frames (missing stop bit) will automatically reset the counter when the line returns to idle (1).
