To refactor the solution while maintaining the same core functionality, I'll make these structural changes:

1. State Machine Restructuring:
   - Use one-hot encoding for states instead of binary
   - Move next-state logic to combinational always block
   - Separate state registers from data path

2. Output Generation:
   - Use continuous assignments (assign) for outputs where possible
   - Make done signal purely combinational based on current state

3. Bit Counting:
   - Use a separate counter module with clear signal
   - Implement explicit bit counting logic

4. Shift Register:
   - Keep the right-shift implementation but make it more explicit
   - Separate the data path from control logic

The key improvements are:
- Clear separation of combinational and sequential logic
- One-hot state encoding for potentially better timing
- More modular structure while maintaining same protocol behavior
