Instead of using a traditional FSM with separate states for each phase, we'll implement a counter-based approach with parallel bit sampling. The key innovations are:
1. Use a 4-bit counter to track both the current bit position and state
2. Implement early stop bit detection by checking the line condition during reception
3. Use a circular buffer for data collection to simplify the shift operation
4. Combine state tracking and bit counting into a single counter variable

The counter interpretation:
- 0: IDLE state (waiting for start bit)
- 1-8: Receiving data bits (LSB first)
- 9: Checking stop bit
- 10-15: Error recovery (waiting for stop bit)

This approach reduces state transitions and combines multiple operations into simpler logic.
