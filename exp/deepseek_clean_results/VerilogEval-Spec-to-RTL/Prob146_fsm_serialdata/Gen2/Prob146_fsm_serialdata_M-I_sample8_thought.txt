To optimize the design for better PPA (Power, Performance, Area), I'll implement the following improvements:

1. Performance:
   - Change shift direction to left-shift to reduce critical path
   - Register next_state logic to break timing paths
   - Simplify state machine by merging ERROR state into IDLE (error recovery happens naturally)

2. Power:
   - Add enable signals to reduce unnecessary register toggles
   - Make done signal a single-cycle pulse
   - Optimize state encoding to one-hot for potentially better synthesis

3. Area:
   - Reduce state machine to 3 states (IDLE, RECEIVE, STOP)
   - Simplify bit counter logic
   - Remove redundant registers

The improved FSM will:
- Use left-shifting for data collection (simpler critical path)
- Generate done as a single-cycle pulse
- Have cleaner state transitions
- Maintain all required functionality while being more efficient
