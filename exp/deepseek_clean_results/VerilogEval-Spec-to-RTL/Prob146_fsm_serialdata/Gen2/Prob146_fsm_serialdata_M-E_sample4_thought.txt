Here's a novel approach using a shift register with integrated state tracking:

1. Instead of a traditional FSM with separate state variables, we'll use the shift register's position to implicitly track state:
   - Bit 9: Stop bit validation
   - Bits 8-1: Data bits (with LSB first)
   - Bit 0: Start bit detection

2. The shift register will grow from 1 to 10 bits as we receive the frame:
   - When idle, we look for start bit (0) to begin shifting
   - Each clock shifts in a new bit until we have all 10 bits
   - The 10th bit (stop bit) must be 1 to validate

3. Advantages:
   - Simplified state tracking (implicit in shift register)
   - Clear timing for done signal (when full frame received)
   - Easy reset behavior (clear shift register)

4. Outputs:
   - out_byte is valid when done is high
   - done asserts for one cycle when valid stop bit received
   - Automatically handles invalid stop bits by continuing to shift
