Novel Architecture Idea:
1. Combined Shift-State Register: Instead of separate state and data registers, use a single 11-bit register that tracks both the received bits and the current state position. Bits [10:1] store the incoming data (start + 8 data bits), while bit [0] acts as a state marker.

2. Early Stop Bit Checking: Begin checking for the stop bit condition as soon as we have 9 bits (start + 8 data), allowing immediate transition to done state if valid.

3. Implicit State Encoding: The position of the '1' in the lower bits indicates our state:
   - Single '1' in bit 0: IDLE
   - '1' in bit 1: Receiving start bit
   - '1' in bits 2-9: Receiving data bits
   - '1' in bit 10: Checking stop bit

4. Efficient Reset: The register naturally resets to idle state (1'b1 in LSB) when cleared.

This approach reduces:
- State machine complexity (no explicit state variables)
- Comparator logic (simple shift operations)
- Power consumption (fewer transitions)
