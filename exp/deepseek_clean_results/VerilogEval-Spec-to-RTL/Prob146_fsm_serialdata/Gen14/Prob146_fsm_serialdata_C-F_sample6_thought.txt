Fusion Strategy:
1. State Encoding: Use minimal 2-bit encoding (IDLE, RECEIVE, STOP) since ERROR state is redundant - we can handle invalid stop bits by staying in STOP state until valid.
2. Shift Register: Keep efficient right-shift implementation for LSB-first reception.
3. Done Signal: Generate only in STOP state when valid stop bit is detected, with immediate deassertion on next cycle.
4. Optimizations:
   - Remove ERROR state to simplify FSM
   - Combine reset handling cleanly
   - Use parallel comparison for bit_count (3'b111)
   - Simplify state transitions
   - Reduce unnecessary signal updates

Key Improvements:
- Fewer states (3 vs 4) reduces area and complexity
- Clearer state transitions
- More efficient done signal generation
- Reduced power consumption by minimizing unnecessary updates
- Maintains all required functionality
