Novel Architecture:
1. Shift Register with Parallel Load: Instead of shifting bits one by one, we'll use a parallel load when the start bit is detected, then shift in remaining bits. This reduces the critical path.
2. Predictive State Machine: The FSM predicts the next state based on current input to minimize transition delays.
3. Early Stop Bit Detection: Check for stop bit validity while receiving the last data bit to overlap operations.
4. Optimized Counter: Use a 3-bit down counter instead of up counter for simpler comparison logic (compare to 0).
5. State Encoding: Use Gray coding for state transitions to minimize switching power.
6. Output Register: Only update out_byte when a valid stop bit is detected, reducing unnecessary toggling.
