To optimize the design, I'll make these key changes:
1. Simplify the state machine to 3 states (IDLE, RECEIVE, STOP) by handling error recovery within the STOP state
2. Use left-shifting for data collection which is more natural for LSB-first reception
3. Make done a combinational output that pulses for one cycle
4. Use assign statements for combinational outputs where possible
5. Optimize bit counting by using a 3-bit counter that resets after 8 bits

The improved FSM flow:
- IDLE: Wait for start bit (0)
- RECEIVE: Collect 8 data bits (left shift)
- STOP: Check stop bit, return to IDLE (with error recovery)
- Done pulses high for one cycle when stop bit is valid
