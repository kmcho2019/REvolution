Refactoring Strategy:
1. State Machine Restructuring: Convert the FSM to use one-hot encoding for better timing performance and simpler state transitions.
2. Combinational Outputs: Move 'done' signal generation to combinational logic to reduce critical path.
3. Shift Register Optimization: Use a more explicit shift operation with enable control to reduce unnecessary transitions.
4. Bit Counter Simplification: Replace the 3-bit counter with a simple comparison against 8 cycles.
5. Error Handling: Simplify error state by merging it with IDLE when waiting for stop bit.

Key Improvements:
1. One-hot encoding reduces state decoding logic
2. Combinational done signal removes it from critical path
3. Explicit shift enable reduces power consumption
4. Simplified counter logic improves timing
5. Merged error handling reduces state transitions
