To simplify the serial communication receiver, we can:
1. Reduce the FSM to just 3 states (IDLE, RECEIVE, STOP) by eliminating the ERROR state
2. Combine state transition and data processing into a single always block
3. Use a simpler bit counter that automatically wraps after 8 bits
4. Directly assign the shift register to output when stop bit is valid
5. Use non-blocking assignments consistently for all registers

The simplified FSM will:
- Stay in IDLE until start bit (0) is detected
- Collect 8 bits in RECEIVE state (LSB first)
- Verify stop bit in STOP state, then return to IDLE
- If stop bit is invalid, stay in STOP until valid stop bit is found
- Assert done only when valid stop bit is detected
