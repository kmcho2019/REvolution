To simplify the serial receiver FSM while maintaining functionality:
1. Reduce states from 4 to 3 by eliminating ERROR state - just wait in STOP until stop bit is found
2. Use left-shift for data accumulation (more natural for LSB-first)
3. Simplify state encoding to 2 states (IDLE and ACTIVE)
4. Combine state transition and data logic into single always block
5. Use bit_count to track both receive progress and state transitions
6. Only update shift register when actually receiving data bits
7. Generate done as a single-cycle pulse when stop bit is valid

Key simplifications:
- Fewer states (3 → 2)
- Combined always blocks
- More efficient shift operation
- Conditional shift register updates
- Pulse-style done signal
