Here's a refactored version using explicit state encoding and combinational logic for outputs:

1. State Machine Approach:
   - Use explicit states (IDLE, RECEIVING, VALIDATE) for clearer control flow
   - Separate the bit counter from the state logic
   - Use combinational assigns for outputs where possible

2. Key Improvements:
   - Clear state transitions based on protocol requirements
   - Proper bit counting aligned with state transitions
   - Outputs generated combinationally when possible
   - Explicit handling of the stop bit validation

3. Structure:
   - State register tracks current phase of reception
   - Shift register accumulates bits
   - Bit counter tracks progress
   - Outputs derived from current state and shift register
   - Done pulses only after valid stop bit
