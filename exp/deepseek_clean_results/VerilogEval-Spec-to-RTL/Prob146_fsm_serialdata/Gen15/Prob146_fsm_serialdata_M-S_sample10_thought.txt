Simplified Design Approach:
1. State Machine: Reduce to 3 states (IDLE, RECEIVE, STOP) by eliminating ERROR state - treat invalid stop bit as staying in STOP state until next start bit
2. Bit Counting: Use simple 3-bit counter with direct comparison (==7) for clarity
3. Shift Register: Maintain efficient right-shift for LSB-first reception
4. Done Signal: Generate only in STOP state when valid stop bit is detected
5. Reset Logic: Keep synchronous reset for all registers
6. State Transitions:
   - IDLE -> RECEIVE on start bit (0)
   - RECEIVE -> STOP after 8 bits
   - STOP -> IDLE on valid stop bit (1), else wait
7. Output: Update out_byte only when valid stop bit is detected

Optimizations:
1. Fewer states (3 vs 4) reduces logic complexity
2. Eliminates separate error handling state
3. Maintains same functionality with simpler control flow
4. Reduced area and power from fewer state transitions
