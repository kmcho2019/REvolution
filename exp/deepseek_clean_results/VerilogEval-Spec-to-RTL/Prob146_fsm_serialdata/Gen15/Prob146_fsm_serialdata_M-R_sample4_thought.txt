Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding (4 bits) for potentially better timing at the cost of slightly more area, as it reduces decode logic in next-state transitions.
2. Shift Register: Keep the efficient right-shift but move it to a separate always block for clarity.
3. Done Signal: Generate it combinationally from the current state and input to improve timing.
4. State Machine: Restructure to use a single always block for both state transitions and output logic (Mealy machine style).
5. Optimization:
   - Remove ERROR state by handling invalid stop bits within STOP state
   - Use explicit default assignments before case statement
   - Combine bit counter increment with state transition logic

Key improvements:
- One-hot encoding simplifies next-state logic
- Combinational done signal reduces critical path
- Simplified state machine with only 3 states
- Clear separation of shift register logic
