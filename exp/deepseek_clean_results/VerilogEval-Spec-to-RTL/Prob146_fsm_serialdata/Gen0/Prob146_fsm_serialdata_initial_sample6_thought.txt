To implement a serial byte receiver with start/stop bits, we'll need a finite state machine (FSM) with the following states:
1. IDLE - waiting for start bit (0)
2. RECEIVE - collecting 8 data bits (LSB first)
3. STOP - checking for stop bit (1)
4. ERROR - waiting for stop bit after failed reception

The FSM will:
- Transition from IDLE to RECEIVE when start bit (0) is detected
- Collect 8 bits in RECEIVE state
- Check for stop bit (1) in STOP state
- Output the byte and done signal when stop bit is valid
- Handle reset synchronously
- Go to ERROR state if stop bit is missing and wait for next stop bit
