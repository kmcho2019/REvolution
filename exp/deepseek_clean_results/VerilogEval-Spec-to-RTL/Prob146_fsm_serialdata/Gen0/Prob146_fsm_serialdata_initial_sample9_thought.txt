To implement this serial communication receiver, we need a finite state machine (FSM) with the following states:
1. IDLE: Wait for start bit (0)
2. RECEIVE: Shift in 8 data bits (LSB first)
3. STOP: Check for stop bit (1)
4. ERROR: Wait for stop bit if not found

The FSM transitions:
- From IDLE to RECEIVE when start bit (0) is detected
- From RECEIVE to STOP after 8 bits are received
- From STOP to IDLE if stop bit is correct (1), else to ERROR
- From ERROR to IDLE when stop bit is finally detected

We'll use a 3-bit counter to track received bits and an 8-bit shift register to accumulate data. The 'done' signal is asserted when we successfully receive a stop bit.
