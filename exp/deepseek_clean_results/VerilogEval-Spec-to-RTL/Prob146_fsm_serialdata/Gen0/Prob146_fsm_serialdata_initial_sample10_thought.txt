To implement this serial communication receiver, we'll need a finite state machine (FSM) with the following states:
1. IDLE - waiting for start bit (0)
2. RECEIVE - collecting 8 data bits (LSB first)
3. STOP - checking for stop bit (1)
4. ERROR - waiting for stop bit after incorrect transmission

The FSM will:
- Transition from IDLE to RECEIVE when start bit (0) is detected
- Collect 8 bits in RECEIVE state, then transition to STOP
- If stop bit is 1, output the byte and assert done, then return to IDLE
- If stop bit is 0, go to ERROR state until a 1 is found, then return to IDLE
- Reset synchronously to IDLE state
- Shift in bits LSB first during RECEIVE state
