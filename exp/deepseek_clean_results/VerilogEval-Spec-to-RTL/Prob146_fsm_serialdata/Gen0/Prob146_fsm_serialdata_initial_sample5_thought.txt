To implement a serial receiver module that follows the start-bit (0), 8 data bits, stop-bit (1) protocol, we'll need a finite state machine (FSM) with the following states:
1. IDLE: Wait for start bit (0)
2. RECEIVE: Shift in 8 data bits (LSB first)
3. STOP: Check for stop bit (1)
4. ERROR: Wait for stop bit if not found

The FSM transitions:
- From IDLE to RECEIVE when start bit detected
- After 8 bits received, move to STOP
- If stop bit is valid (1), go back to IDLE and assert done
- If stop bit invalid (0), go to ERROR state until stop bit found

We'll use a 3-bit counter to track received bits and an 8-bit shift register to accumulate data. The done signal is asserted only when valid stop bit is detected.
