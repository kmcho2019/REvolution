To implement this serial communication receiver, we need a finite state machine (FSM) that can:
1. Detect the start bit (0)
2. Collect 8 data bits (LSB first)
3. Verify the stop bit (1)
4. Output the received byte and assert 'done' when successful
5. Handle reset and error cases (missing stop bit)

The FSM will have these states:
- IDLE: Waiting for start bit
- RECEIVE: Collecting 8 data bits
- STOP: Checking stop bit
- ERROR: Waiting for stop bit after error

We'll use a counter to track which data bit we're receiving, and a shift register to accumulate the bits.
