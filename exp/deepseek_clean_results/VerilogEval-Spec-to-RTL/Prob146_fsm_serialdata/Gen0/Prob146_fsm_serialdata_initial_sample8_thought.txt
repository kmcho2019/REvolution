To implement a serial byte receiver with start and stop bits, we'll need a finite state machine (FSM) with the following states:
1. IDLE - waiting for start bit (0)
2. RECEIVE - collecting 8 data bits
3. STOP - checking for stop bit (1)

The FSM transitions:
- From IDLE to RECEIVE when start bit (0) is detected
- After collecting 8 bits in RECEIVE state, moves to STOP
- If stop bit is valid (1), returns to IDLE and asserts done
- If stop bit is invalid, stays in STOP until 1 is seen

We'll use a 3-bit counter to track received bits and an 8-bit shift register to accumulate data bits (LSB first). The done signal is asserted only when a valid stop bit is detected.
