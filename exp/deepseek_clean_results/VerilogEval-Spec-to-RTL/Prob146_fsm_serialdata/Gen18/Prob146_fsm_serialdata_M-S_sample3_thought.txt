To simplify the serial receiver FSM while maintaining functionality:
1. Reduce states to just 3: IDLE, RECEIVE, and STOP (merge ERROR into STOP)
2. Use a single always block for both state transition and output logic
3. Eliminate separate next_state logic by making transitions directly
4. Simplify bit counting by using a 3-bit counter that automatically wraps
5. Combine stop bit checking with data collection in RECEIVE state
6. Only update outputs when needed (done and out_byte)

Key simplifications:
- Merge ERROR state into STOP by having STOP wait for '1' before returning to IDLE
- Remove next_state logic by directly assigning state transitions
- Simplify bit counting by checking MSB of counter instead of full comparison
- Combine shift register and output register updates
