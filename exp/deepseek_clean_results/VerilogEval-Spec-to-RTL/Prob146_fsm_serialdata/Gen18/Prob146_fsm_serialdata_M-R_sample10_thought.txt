Refactoring Strategy:
1. State Encoding: Keep 2-bit encoding but use one-hot for better timing (though uses more flops)
2. Shift Register: Use combinational assignment for shift register to reduce clock load
3. Done Signal: Generate combinationally from state and input to reduce timing path
4. Error Handling: Merge ERROR with IDLE to simplify state machine
5. Bit Counting: Use a registered comparison to break timing path
6. Output Logic: Move out_byte assignment to combinational block to reduce clock domain crossings

Key Changes:
1. One-hot state encoding for better timing at cost of area
2. Combinational shift register reduces clock load
3. Simplified state machine by merging ERROR into IDLE
4. Registered bit_count comparison improves timing
5. Combinational output logic reduces clock domain crossings
