To simplify the FSM while maintaining functionality:
1. Reduce states from 4 to 3 by merging ERROR into IDLE (since both wait for start bit)
2. Remove separate bit counter by using shift register's position
3. Make done a one-cycle pulse instead of maintained signal
4. Simplify state encoding to 2 bits
5. Combine state transition and data logic into single always block

Key changes:
- Only IDLE, RECEIVE, STOP states needed
- Track progress using shift register's fill level
- Generate done as pulse when valid stop bit detected
- Reset clears all registers synchronously
