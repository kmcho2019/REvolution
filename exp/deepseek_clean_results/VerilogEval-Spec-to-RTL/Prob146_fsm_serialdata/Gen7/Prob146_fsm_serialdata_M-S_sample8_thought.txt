To simplify the serial communication receiver FSM, we can:
1. Reduce the number of states by combining ERROR with IDLE (since both wait for start bit)
2. Use a single always block for both state transition and output logic
3. Eliminate separate next_state logic by computing transitions directly
4. Use a simple counter to track received bits
5. Maintain the same functionality with fewer registers and simpler logic

The simplified FSM will have just 3 states:
1. IDLE: Wait for start bit (0)
2. RECEIVE: Collect 8 data bits (LSB first)
3. STOP: Check for stop bit (1)

Transitions:
- IDLE -> RECEIVE when start bit detected
- RECEIVE -> STOP after 8 bits
- STOP -> IDLE if stop bit valid, else stay in STOP
