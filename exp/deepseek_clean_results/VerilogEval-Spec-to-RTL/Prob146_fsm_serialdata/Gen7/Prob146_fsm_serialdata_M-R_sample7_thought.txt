Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding for potentially better timing at the cost of slightly more area (4 flip-flops instead of 2).
2. Output Logic: Move done signal to continuous assignment for cleaner separation of combinational and sequential logic.
3. Shift Register: Keep the shift operation in the always block but simplify the bit counting logic.
4. State Transitions: Break into separate always blocks for state transitions and data path for better synthesis optimization.
5. Error Handling: Merge ERROR state functionality into STOP state to reduce area and simplify transitions.
