To optimize the design, I'll make these key changes:
1. Use one-hot encoding for FSM states to potentially improve timing
2. Separate combinational and sequential logic more clearly
3. Use left-shifting for the data register to reduce critical path
4. Implement done as a one-cycle pulse
5. Simplify the ERROR state by merging it with IDLE since we can handle invalid stop bits in the STOP state itself

- Use continuous assignments for next_state logic where possible
- Make the shift register operation more timing-friendly
- Generate done as a pulse when valid stop bit is detected
- Maintain the same functionality but with better timing characteristics
