To simplify the serial receiver FSM while maintaining functionality:
1. Reduce states from 4 to 3 by merging ERROR into IDLE (since both wait for start bit)
2. Use left-shifting for data collection (more natural for LSB-first)
3. Combine state transition and data logic into single always block
4. Remove redundant registers and simplify control signals
5. Make done a one-cycle pulse instead of maintained signal

Key simplifications:
- Merge ERROR state into IDLE (just wait for stop bit when needed)
- Single always block for cleaner implementation
- Left-shift register with simpler control
- Pulse done only when valid byte received
