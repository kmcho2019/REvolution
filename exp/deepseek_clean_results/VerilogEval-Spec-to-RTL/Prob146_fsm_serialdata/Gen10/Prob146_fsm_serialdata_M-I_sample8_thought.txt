To optimize the design for better PPA (Power, Performance, Area), I'll implement the following improvements:

1. Performance:
- Change shift direction to left-shift to reduce critical path
- Register next_state logic to break timing paths
- Simplify state machine by merging ERROR state into IDLE (since behavior is similar)

2. Power:
- Add enable signals to reduce unnecessary switching
- Make done signal a single-cycle pulse
- Use one-hot encoding for potentially better synthesis

3. Area:
- Reduce state encoding to 3 states (IDLE, RECEIVE, STOP)
- Optimize bit counter to count up to 7 (3 bits still needed)
- Simplify shift register control logic

The improved FSM will:
- Use left-shifting for data collection (still LSB first)
- Generate done as a single-cycle pulse
- Combine error handling with idle state
- Register next_state for better timing
