Novel Architecture Idea:
1. Shift Register with Parallel Load: Instead of shifting bits one by one, we'll use a 9-bit shift register (start + 8 data bits) and load the entire byte when complete. This reduces the number of state transitions.
2. Simplified State Machine: Only 2 states (IDLE and RECEIVE) with a counter tracking the bit position.
3. Early Stop Bit Detection: Check for stop bit during the last data bit reception to overlap operations.
4. Edge Detection: Use edge detection on the input to trigger state transitions more efficiently.
5. Output Register: Separate register for out_byte that only updates when done is asserted.

Key Advantages:
- Reduced state transitions (only 2 states)
- Parallel processing of stop bit detection
- Fewer register updates (power savings)
- Simpler control logic (better timing)
- Edge detection makes it more robust to noise
