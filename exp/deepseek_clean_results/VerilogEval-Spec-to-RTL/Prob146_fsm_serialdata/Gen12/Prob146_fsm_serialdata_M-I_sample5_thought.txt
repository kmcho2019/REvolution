To optimize the design for better PPA (Power, Performance, Area), I'll implement the following improvements:

1. Performance:
   - Change shift direction to left-shift to reduce critical path
   - Register next_state logic to break timing paths
   - Reduce combinational logic in state transitions

2. Power:
   - Add enable signals to reduce unnecessary register updates
   - Make done signal a one-cycle pulse instead of maintained high
   - Only update shift register when receiving valid bits

3. Area:
   - Simplify state machine by merging ERROR state into IDLE
   - Use more efficient state encoding (binary instead of one-hot)
   - Optimize bit counter to use 3 bits but with simpler logic

The improved FSM will:
- Use left-shift for simpler critical path
- Have registered next_state for better timing
- Generate done as a pulse
- Combine error handling into IDLE state
- Only update registers when needed
