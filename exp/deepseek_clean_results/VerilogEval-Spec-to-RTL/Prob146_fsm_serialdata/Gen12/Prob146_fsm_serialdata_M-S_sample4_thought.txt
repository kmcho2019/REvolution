Simplification Strategy:
1. State Reduction: Combine ERROR state with IDLE since both wait for a stop bit (1)
2. Counter Optimization: Use 3-bit down counter that starts at 7 (matches 8 data bits)
3. Shift Register: Maintain efficient right-shift for LSB-first reception
4. Done Signal: Only assert when valid stop bit is detected
5. Reset Handling: Clear all registers synchronously
6. Default Assignments: Remove default 'done' assignment to reduce toggles

Key Simplifications:
- Reduced from 4 to 3 states (IDLE, RECEIVE, STOP)
- ERROR state merged into IDLE functionality
- Simpler state transitions
- Fewer registers and logic operations
- Maintains same protocol functionality
