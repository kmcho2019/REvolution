To optimize the design for better PPA (Power, Performance, Area), I'll implement these improvements:

1. Performance:
- Change shift direction to left-shift to reduce critical path
- Register next_state logic to break timing paths
- Simplify state machine by merging ERROR state into IDLE (redundant)

2. Power:
- Add enable signals for shift register to reduce unnecessary toggling
- Make done signal a single-cycle pulse instead of maintained high

3. Area:
- Reduce state encoding to 2 states (IDLE and RECEIVE)
- Simplify bit counter logic by counting to 7 instead of 8
- Remove redundant ERROR state

The improved FSM will:
- Use IDLE state to wait for start bit and handle stop bit verification
- Use RECEIVE state to collect 8 data bits
- Generate done as a single-cycle pulse when stop bit is valid
- Immediately return to IDLE if stop bit is invalid (no separate ERROR state)
