To simplify the serial receiver FSM while maintaining functionality:
1. Reduce states from 4 to 3 by merging ERROR into IDLE (since both wait for start bit)
2. Remove separate bit counter by using shift register's position
3. Simplify done signal to be a one-cycle pulse
4. Use left-shifting for the data register to reduce critical path
5. Combine state transition and data logic into single always block

Key changes:
- Only 3 states: IDLE, RECEIVE, STOP
- Track progress using shift register's empty bits
- Pulse done only when valid stop bit is detected
- Reset clears all registers synchronously
