Novel Architecture Idea:
1. Parallel Capture: Instead of shifting bits serially, use a counter to track position and capture bits directly into their correct byte positions. This eliminates the shift operation overhead.
2. Early Stop Detection: Check for stop bit validity as soon as the 8th data bit is received, allowing immediate transition to IDLE if valid.
3. Simplified State Machine: Reduce to just 2 states (IDLE and ACTIVE) by using the counter value to implicitly track progress.
4. Predictive Error Handling: If stop bit is invalid, immediately go to IDLE (assuming noise) rather than waiting for next stop bit.
5. One-Hot Encoding: Use one-hot state encoding for potentially better timing at minimal area cost (only 2 states).

Key Benefits:
- Eliminates shift operation (reduces critical path)
- Parallel assignment reduces switching activity
- Simpler state machine with implicit progress tracking
- Faster error recovery
- Done signal generated combinatorially for better timing
