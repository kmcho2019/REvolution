Here's a novel approach using a shift register with parallel load and a bit counter with early termination detection:

1. Instead of a traditional FSM, we'll use a counter-driven approach with two main states (IDLE and ACTIVE)
2. The ACTIVE state handles both data reception and stop bit verification
3. We'll use a 9-bit shift register to capture both data and stop bit
4. The counter counts up to 9 (8 data bits + stop bit)
5. When counter reaches 9, we check if:
   - First bit (start bit) was 0
   - Last bit (stop bit) was 1
6. If both conditions are met, we parallel load the middle 8 bits to out_byte
7. This approach eliminates separate states for receive/stop/error, simplifying control logic
8. The counter automatically resets when we detect a new start bit during ACTIVE state
9. Done signal pulses when valid byte is detected
