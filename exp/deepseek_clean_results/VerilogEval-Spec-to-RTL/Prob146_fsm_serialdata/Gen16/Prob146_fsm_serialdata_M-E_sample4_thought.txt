Instead of using a traditional FSM with separate states for each phase, we'll implement a continuous sampling approach with these key features:
1. A sliding window detector that continuously looks for the start bit pattern (1->0 transition)
2. A free-running counter that tracks bit positions relative to the start bit
3. Early stop bit checking - we verify the stop bit position immediately after receiving the 8 data bits
4. Parallel data capture using the counter to directly index into the output register

This approach eliminates explicit state transitions and reduces control logic by:
- Using the counter value to implicitly determine the current phase
- Performing continuous validity checking
- Implementing early termination if stop bit is invalid
- Using bit-position awareness to handle error recovery
