Here's a novel approach using a shift register with integrated state tracking and a parallel load mechanism:

1. **Integrated State Tracking**: Instead of separate state registers, we'll use the shift register's MSB as a state indicator (0 for receiving, 1 for idle/stop). This reduces register count.

2. **Parallel Load Detection**: When we've received 8 bits, we'll parallel load them into the output register if the next bit is a valid stop bit (1).

3. **Edge-Based Start Detection**: Use the falling edge of 'in' (start bit transition from 1 to 0) to initiate reception, making it more robust to noise.

4. **Single-Cycle Done Assertion**: The 'done' signal pulses high for exactly one cycle when a valid byte is received, then returns low.

5. **Minimal State Machine**: Only two states needed - IDLE and RECEIVING, with transitions controlled by the start/stop bits and bit counter.

This approach minimizes hardware while maintaining protocol correctness, and is particularly efficient for FPGA implementations.
