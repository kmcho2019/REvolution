To simplify the design while maintaining functionality, I'll make these key changes:

1. **State Reduction**: Use only 3 essential states (IDLE, RECEIVE, STOP) since error handling can be merged into STOP state.

2. **Simpler Counter**: Use a 3-bit counter to track all 8 data bits directly, eliminating complex counting logic.

3. **Remove Shift Enable**: The shift register can always shift during RECEIVE state, removing unnecessary control logic.

4. **Direct Output Assignment**: Assign out_byte directly from shift register when stop bit is valid, eliminating intermediate registers.

5. **Simpler Reset Logic**: All registers reset to known values in one block.

The simplified FSM will:
- Wait in IDLE for start bit (0)
- Shift in 8 bits during RECEIVE state
- Verify stop bit (1) in STOP state
- Output the byte and assert done only when stop bit is valid
- Handle missing stop bits by waiting in STOP state
