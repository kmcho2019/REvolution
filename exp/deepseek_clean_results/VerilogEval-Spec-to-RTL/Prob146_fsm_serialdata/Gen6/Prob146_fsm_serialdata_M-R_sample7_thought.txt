Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding (4 bits) for better timing at the cost of slightly more area. This reduces the fanout of state signals.
2. Shift Logic: Move shift register logic to combinational block to reduce sequential elements.
3. Done Signal: Make it combinational to avoid unnecessary flops and reduce latency.
4. Error Handling: Remove explicit ERROR state since we can handle invalid stop bits in STOP state itself.
5. Counter Optimization: Use simpler equality check for bit_count (compare directly to 7).
6. Output Logic: Make out_byte update only when done is asserted to reduce unnecessary switching.

Key Improvements:
- Better timing through one-hot encoding
- Reduced sequential elements by moving logic to combinational
- Cleaner state transitions
- More efficient counter comparison
- Reduced power through selective updates
