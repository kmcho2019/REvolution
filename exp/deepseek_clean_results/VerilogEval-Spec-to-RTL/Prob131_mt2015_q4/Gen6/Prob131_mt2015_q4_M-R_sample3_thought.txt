Refactoring approach:
1. Replace module instantiations with direct logic expressions since all submodules share the same inputs
2. Compute the intermediate signals (a1_out, a2_out, b1_out, b2_out) as wire expressions
3. Combine the logic operations directly without separate module instances
4. This reduces hierarchy while maintaining identical functionality
5. The implementation becomes more compact and potentially more efficient as it eliminates module boundaries
