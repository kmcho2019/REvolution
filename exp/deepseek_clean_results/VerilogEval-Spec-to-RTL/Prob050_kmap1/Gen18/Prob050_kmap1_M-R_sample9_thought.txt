The original implementation uses a simple continuous assignment with a 3-input OR gate. We can refactor this while maintaining the same logic function by:

1. Using an always block with a case statement that explicitly lists all input combinations
2. This approach makes the truth table more visually apparent in the code
3. The implementation remains combinational and functionally identical
4. While less concise, this style might be preferred for documentation purposes or when the truth table needs to be explicitly visible

The case statement will cover all 8 possible input combinations (3 inputs), but we can optimize it by:
- Listing the single case where output is 0 (a=0,b=0,c=0)
- Using default for all other cases (output=1)
