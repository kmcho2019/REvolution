Here's a novel approach using a multiplexer-based implementation that achieves the same functionality while demonstrating an alternative architectural style:

1. Observation: The output is always 1 except when a=0, b=0, c=0
2. Key Insight: We can use 'a' as the select line for a mux
3. Implementation Strategy:
   - When a=1: Output is always 1 (top row of K-map)
   - When a=0: Output is b|c (left column of K-map)
4. Benefits:
   - Shows mux-based logic implementation
   - Demonstrates hierarchical thinking
   - Provides same functionality with different structure
   - Could be more efficient in certain technology libraries
5. Trade-offs:
   - Slightly more complex than simple OR
   - May have different timing characteristics
   - Shows alternative implementation approach
