Here's a novel approach using a lookup table (LUT) implemented with a case statement. While this might seem unconventional for such a simple function, it demonstrates an alternative architectural style that could be useful for more complex functions or when we want to make the truth table explicitly visible in the code.

The key ideas are:
1. Represent the truth table explicitly using a case statement
2. Concatenate inputs to form the case selector
3. Map each input combination to its corresponding output value
4. This approach makes the truth table immediately visible in the code

While functionally equivalent to the OR solution, this implementation:
- Makes the mapping from inputs to output completely explicit
- Could be more maintainable if the truth table needs to change
- Shows an alternative architectural pattern
- Demonstrates how to implement a small LUT in Verilog
