An alternative approach is to recognize that the output is 0 only when all inputs are 0. Instead of using a straightforward OR operation, we can implement this using a NAND-NAND logic structure. First, we NAND each input with itself (which effectively inverts them), then NAND all these inverted signals together. The final output is the inversion of this result, which gives us the same functionality as the original OR operation but with a different gate-level implementation.
