The Karnaugh map shows the output is 0 only when all inputs are 0 (a=0, b=0, c=0), and 1 otherwise. This is equivalent to a 3-input OR function. We can implement this directly with a single OR gate for optimal PPA:

1. **Performance:** Single gate delay (OR gate) is faster than the original solution's inverter chain + NAND
2. **Power:** Only one gate switching reduces dynamic power
3. **Area:** Single gate implementation uses minimal area

This is the most efficient implementation for the given truth table.
