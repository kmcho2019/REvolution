Here's a novel approach using a multiplexer-based implementation:

1. Observing the Karnaugh map, the output is always 1 except when all inputs are 0
2. We can implement this using a 2:1 multiplexer where:
   - The select line is a OR b (if either is 1, we select 1)
   - The data inputs are:
     - 0 input: c (since when a=0 and b=0, output equals c)
     - 1 input: constant 1 (since when a OR b is 1, output is always 1)
3. This implementation is logically equivalent but uses a different architectural approach
4. The advantage is that it clearly separates the two cases (all zeros vs. any one) in the hardware
5. While it uses slightly more gates (1 OR + 1 MUX), it demonstrates an alternative way to think about the problem
6. In some technologies, this might offer better testability or different power characteristics
