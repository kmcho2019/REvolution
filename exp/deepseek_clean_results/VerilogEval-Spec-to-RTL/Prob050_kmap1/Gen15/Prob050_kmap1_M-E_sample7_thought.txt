Here's an innovative approach using a priority encoder concept:

1. Observe that the output is only 0 when all inputs are 0 (a=0, b=0, c=0)
2. Instead of checking all possible combinations, we can implement this as:
   - A "zero detector" that checks if all inputs are 0
   - Invert the zero detector's output to get the desired function
3. The zero detector can be implemented using a NOR tree:
   - First NOR a and b
   - Then NOR that result with c
   - This creates a compact 3-input zero detector
4. This approach is optimal because:
   - Uses minimal gates (only 2 NOR gates)
   - Has a shallow logic depth (2 levels)
   - Naturally handles the "all zeros" case we want to detect
   - Scales well to more inputs if needed
