Here's a novel approach using a look-up table (LUT) style implementation with a decoder and OR gates:

1. The Karnaugh map shows output is 0 only when a=0, b=0, c=0 (000)
2. We can treat this as a 3-input LUT where all input combinations except 000 should output 1
3. Implement this by:
   - Decoding all possible input combinations (8 possibilities)
   - Using an 8-input OR gate where 7 inputs are connected to decoded patterns (all except 000)
   - This approach demonstrates how complex logic can be implemented using decoders and OR gates
4. While less efficient for this simple case, this method scales well for more complex functions
