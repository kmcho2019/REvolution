The Karnaugh map shows the output is only 0 when all inputs are 0 (a=0, b=0, c=0). Instead of a simple OR gate, we can implement this using a NAND gate structure. We'll first NAND each input with itself (which effectively inverts them), then NAND all the inverted inputs together. This creates the same logical function but with a different gate-level implementation that might have different PPA characteristics in certain technologies.
