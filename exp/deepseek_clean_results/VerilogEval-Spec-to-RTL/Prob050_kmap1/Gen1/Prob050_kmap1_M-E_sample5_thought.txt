An alternative approach is to recognize that the output is only 0 when all inputs are 0, and 1 otherwise. This can be implemented using a NAND gate structure. First, we create a signal that is 0 only when all inputs are 0 by using a 3-input NAND gate with inverted inputs (effectively creating an AND-OR-Invert structure). Then we invert this signal to get the desired output. This implementation uses De Morgan's laws to transform the original OR logic into a NAND-based implementation.
