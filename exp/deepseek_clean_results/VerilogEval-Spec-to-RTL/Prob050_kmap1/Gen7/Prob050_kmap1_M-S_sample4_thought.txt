The Karnaugh map shows the output is 0 only when a=0, b=0, and c=0 (all inputs are 0). In all other cases, the output is 1. This can be implemented simply by OR-ing all three inputs together. If any input is 1, the output will be 1. Only when all inputs are 0 will the output be 0. This is the most straightforward and efficient implementation.
