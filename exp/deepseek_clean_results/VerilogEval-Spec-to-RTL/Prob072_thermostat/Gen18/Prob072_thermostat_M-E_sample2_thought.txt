Here's a novel approach using a finite state machine (FSM) to manage the thermostat states explicitly. While this is more complex than the direct combinational solution, it offers better extensibility for future features like:
1. State-dependent timing controls
2. Debouncing of input signals
3. Additional operating modes
4. Power-on sequencing

The FSM will have 4 states:
- IDLE: No active temperature control
- HEATING: Heater is on
- COOLING: Aircon is on
- FAN_ONLY: Only fan is active by user request

State transitions will be based on mode, temperature, and fan requests.
