This solution implements a finite state machine (FSM) approach to make the control logic more explicit and extensible. The FSM has 4 states representing all possible operating conditions. While this is slightly more complex than the direct combinational approach, it offers:
1. Clear separation of operating modes and conditions
2. Easier debugging with explicit state transitions
3. Better scalability for future enhancements (like adding more modes or safety features)
4. More maintainable code with named states instead of implicit logic
