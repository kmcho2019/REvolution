The original solution already uses minimal logic operations, but we can simplify further by:
1. Removing the always block since we don't need procedural assignment for this simple combinational logic
2. Using continuous assignments directly for each output
3. Maintaining the same logical relationships:
   - heater = mode AND too_cold
   - aircon = NOT mode AND too_hot
   - fan = (heater OR aircon) OR fan_on
This reduces the code to just three simple assignment statements while preserving all functionality.
