Instead of pure combinational logic, we can implement a simple state machine that explicitly tracks the current operation mode. This provides several advantages:
1. More explicit control flow that's easier to extend/modify
2. Potential for adding hysteresis or timing controls in future
3. Clear separation between mode selection and temperature response
4. Fan control becomes a simple OR of all possible activation sources

The state machine has just 4 states (IDLE, HEATING, COOLING, FAN_ONLY) and transitions based on mode and temperature inputs. This makes the behavior more explicit while maintaining the same functionality.
