Instead of pure combinational logic, we can implement this as a simple state machine with 4 states:
1. IDLE: No heating/cooling needed
2. HEATING: Heater is active
3. COOLING: Aircon is active
4. FAN_ONLY: Only fan is active by user request

This approach makes the behavior more explicit and could be easier to modify/extend later (e.g., adding timing controls or hysteresis). The state transitions are determined by the input signals, and outputs are purely based on the current state.
