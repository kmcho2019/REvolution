A novel approach would be to implement the thermostat controller using a finite state machine (FSM) with explicit states for each operating mode. This provides better scalability for future enhancements and makes the design more maintainable. The FSM will have two main states (HEATING and COOLING) and will transition between them based on the mode input. Outputs will be generated based on both the current state and temperature inputs. The fan control remains combinational to ensure immediate response to user requests.
