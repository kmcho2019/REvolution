Here's a novel approach using a finite state machine (FSM) architecture with explicit state encoding. While the problem can be solved with simple combinational logic, using an FSM provides several advantages:

1. Explicit state representation makes the design more maintainable and extensible
2. Clear separation of mode and temperature conditions
3. Easier to add future features (like hysteresis or timing controls)
4. More robust against glitches due to explicit state transitions

The FSM has 4 states:
- IDLE: No active temperature control
- HEATING: Heater is active
- COOLING: Aircon is active
- FAN_ONLY: Only fan is active by user request

State transitions are controlled by mode, temperature conditions, and fan_on signals. Outputs are purely combinational based on current state.
