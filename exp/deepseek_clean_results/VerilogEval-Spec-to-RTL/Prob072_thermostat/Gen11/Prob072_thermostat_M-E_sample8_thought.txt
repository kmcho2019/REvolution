Here's a novel state machine-based approach that introduces hysteresis behavior to prevent rapid toggling of outputs when temperature is near threshold:

1. Use a simple state machine with 4 states: IDLE, HEATING, COOLING, FAN_ONLY
2. State transitions are controlled by mode and temperature inputs
3. Outputs are directly derived from current state
4. Fan control is prioritized based on state (active temperature control overrides manual fan request)
5. Hysteresis is implemented by requiring temperature to cross threshold before changing state

Benefits:
- More stable control by preventing rapid state changes
- Clear separation of operational modes
- Easier to extend with additional features (like timers or safety checks)
- Explicit state representation makes debugging easier
