A novel approach would be to implement the thermostat controller using priority-encoded output logic. This design treats the fan as the highest priority output (since user request should override temperature control), followed by cooling/heating needs. The key innovation is using a priority encoder to resolve conflicting conditions and ensure only one temperature control device (heater or aircon) is active at any time, even if both too_cold and too_hot are somehow asserted simultaneously. This makes the system more robust against sensor errors.
