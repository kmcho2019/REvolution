Instead of using purely combinational logic, we'll implement a simple state machine that provides more explicit control over the outputs. This approach:
1. Uses a state register to track the current mode (heating/cooling)
2. Implements priority encoding where fan_on has highest priority
3. Explicitly separates the control logic for each output
4. Provides better scalability for future enhancements (like adding more modes)
5. Makes the control flow more visible in the code

The state machine approach is slightly more verbose but offers better maintainability and clearer separation of concerns. It also makes it easier to add features like minimum on/off times or hysteresis in future versions.
