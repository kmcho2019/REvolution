A novel approach would be to implement the thermostat control using a finite state machine (FSM) with explicit states for each operating mode. This provides several advantages:
1. Clear separation of heating and cooling modes
2. Easier to extend with additional states (like idle, error handling)
3. More maintainable for complex future requirements
4. Explicit state transitions make behavior more visible

The FSM will have 4 states:
- IDLE: No active temperature control
- HEATING: Heater is active
- COOLING: Aircon is active
- FAN_ONLY: Only fan is active by user request

State transitions will be based on:
- Mode signal
- Temperature sensors
- Fan request
