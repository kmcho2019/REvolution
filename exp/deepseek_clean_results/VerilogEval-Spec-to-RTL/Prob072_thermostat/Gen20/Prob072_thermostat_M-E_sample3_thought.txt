Here's a novel approach using a priority-encoded state machine with explicit state transitions and output logic. The key differences from the previous solution are:
1. Uses a 3-state FSM (IDLE, HEAT, COOL) instead of combinational outputs
2. Implements priority encoding where manual fan request has lowest priority
3. Includes state transition conditions explicitly in an always block
4. Separates output generation into a dedicated combinational block
5. Uses parameters for state encoding readability
6. Adds a small power optimization by gating the fan output with the current state

This approach provides better control flow visibility and could be more easily extended with additional features like timers or hysteresis.
