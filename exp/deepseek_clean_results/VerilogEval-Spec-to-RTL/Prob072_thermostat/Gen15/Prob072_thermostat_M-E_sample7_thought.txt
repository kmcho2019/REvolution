Here's a novel approach using a state machine implementation instead of pure combinational logic. The idea is:
1. Create 4 distinct states representing all possible operating modes
2. Use mode and temperature inputs to transition between states
3. Outputs are determined by the current state
4. This approach makes the control logic more explicit and potentially more scalable for future enhancements

The states are:
- IDLE: No heating/cooling needed
- HEATING: Heater is on
- COOLING: Aircon is on
- FAN_ONLY: Only fan is requested

This state machine approach provides better visibility into the system's behavior and could be easier to modify for additional features.
