Here's a novel approach using a state machine implementation:
1. Instead of pure combinational logic, implement a simple state machine with 4 states (IDLE, HEATING, COOLING, FAN_ONLY)
2. This allows for more explicit control of the outputs and potential future expansion
3. The state transitions are based on the input conditions
4. Outputs are determined by the current state
5. This approach provides better visibility into the system's operation and makes it easier to add features like minimum on/off times in the future
