To optimize the design for better PPA (Power, Performance, Area), I'll implement these improvements:

1. Combine heater/aircon logic into a single multiplexer structure to reduce area and power:
   - Use mode to select between too_cold (heating) and too_hot (cooling)
   - Generate both heater and aircon signals from this shared logic

2. Optimize fan logic to minimize switching:
   - Make the fan_on input directly control the fan output when active
   - Only evaluate heater/aircon conditions when fan_on is inactive

3. Use continuous assignments instead of always_comb:
   - For this simple logic, continuous assigns can be more area-efficient
   - Removes the need for reg declarations and always block overhead

These changes should maintain the same functionality while reducing area and power consumption by:
- Eliminating redundant logic evaluations
- Minimizing gate count
- Reducing unnecessary switching activity
