Instead of pure combinational logic, implement a state machine with four distinct states:
1. IDLE - No active temperature control
2. HEATING - Heater is active
3. COOLING - Aircon is active
4. FAN_ONLY - Only fan is active by user request

This approach:
- Makes the operational modes explicit and easily debuggable
- Provides better scalability for adding more features (like timers, safety checks)
- Separates the control logic cleanly
- Can be easily extended to sequential logic if needed
- Provides better visibility into system state
