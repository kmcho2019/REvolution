Instead of a state machine, we'll implement a priority-based control system where the mode input acts as the highest priority selector. The key innovation is treating the thermostat as a multiplexer with mode-dependent conditions, combined with parallel evaluation of all control signals. This approach eliminates state registers while maintaining clear priority rules:
1. Mode determines primary operation (heating/cooling)
2. Temperature conditions act as secondary enables
3. Fan control remains independent but combines all activation sources
This results in a purely combinational design with minimal logic depth and no state elements, optimizing for both area and power.
