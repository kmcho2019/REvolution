The thermostat controller needs to operate in two distinct modes (heating and cooling) based on the 'mode' input. In heating mode, the heater should activate when it's too cold, while in cooling mode, the aircon should activate when it's too hot. The fan should turn on whenever either the heater or aircon is active, or when explicitly requested by the fan_on signal. The key is to properly decode the mode and temperature inputs to control the outputs without conflicting heater/aircon activation.

The implementation will use combinational logic to:
1. Set heater output based on mode and too_cold
2. Set aircon output based on mode and too_hot
3. Set fan output when either heater, aircon, or fan_on is active
