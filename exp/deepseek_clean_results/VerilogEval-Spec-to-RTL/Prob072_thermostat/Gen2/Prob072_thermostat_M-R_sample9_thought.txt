The original solution uses simple combinational assignments, which is efficient and correct. For refactoring, I'll implement the same logic using an always block with case statements to demonstrate an alternative structural approach. The key changes are:
1. Replace continuous assignments with procedural assignments
2. Use a case statement for mode selection to make the mode-dependent behavior more explicit
3. Group all outputs in a single always block for clarity
4. Maintain the same logical functionality while changing only the implementation style

This approach makes the mode selection more visually prominent while keeping the same efficient logic. The fan control remains a simple OR of conditions.
