Here's a novel approach using a finite state machine (FSM) implementation. While the original problem can be solved with simple combinational logic, using an FSM provides several advantages:
1. More explicit representation of the system states
2. Easier to extend with additional features (like timing delays, safety checks)
3. Better match for potential future requirements (like different fan speeds)
4. Clear separation between mode selection and temperature control logic

The FSM will have 4 states:
- IDLE: No active temperature control
- HEATING: Heater is on
- COOLING: Aircon is on
- FAN_ONLY: Only fan is requested

The transitions between states will be controlled by the input signals while maintaining all the original requirements.
