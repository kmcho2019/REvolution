Here's a novel approach using a state machine implementation for the thermostat controller. While the problem can be solved with simple combinational logic, using a state machine provides several advantages:
1. Explicit representation of system states makes the design more maintainable
2. Easier to extend with additional features (like debouncing, hysteresis)
3. More robust against glitches in input signals
4. Clear separation of mode logic and temperature control

The state machine will have 4 states:
- IDLE: No active temperature control
- HEATING: Heater is active
- COOLING: Aircon is active
- FAN_ONLY: Only fan is active by user request

Transitions between states depend on mode, temperature sensors, and fan request.
