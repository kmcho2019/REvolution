I'll refactor the solution using an always block with combinational logic instead of continuous assignments. This approach:
1. Groups all output logic together in a single procedural block
2. Makes the control flow more explicit through if-else statements
3. Maintains identical functionality while offering better readability
4. Still produces the same optimal gate-level implementation (as synthesis tools will optimize equivalently)

The key advantages are:
- Clearer sequential logic flow that matches human thinking
- Easier to modify/extend with additional conditions
