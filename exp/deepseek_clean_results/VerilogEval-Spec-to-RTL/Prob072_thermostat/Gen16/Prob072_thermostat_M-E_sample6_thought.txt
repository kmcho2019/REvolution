Here's a novel approach using a finite state machine (FSM) to manage the thermostat states explicitly. While this is more complex than the direct combinational solution, it offers several advantages:
1. Explicit state representation makes the design more maintainable and extensible
2. Easier to add new features or states in the future
3. More robust against glitches since outputs are registered
4. Clear separation of mode logic and temperature control

The FSM will have 4 states:
- IDLE: No heating/cooling needed
- HEATING: Heater is active
- COOLING: Aircon is active
- FAN_ONLY: Only fan is active by user request

State transitions will be based on mode, temperature inputs, and fan request.
