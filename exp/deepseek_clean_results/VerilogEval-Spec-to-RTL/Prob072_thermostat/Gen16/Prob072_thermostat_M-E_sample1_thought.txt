Instead of using purely combinational logic, we can implement a simple state machine that explicitly tracks the current operating mode (heating/cooling) and makes control decisions based on that. This approach:
1. Makes the control flow more explicit and easier to modify
2. Provides better documentation of intended behavior through state encoding
3. Could be extended more easily for future features (like a safety timer)
4. Separates the mode logic from temperature sensing logic
The state machine has just 2 states (HEATING and COOLING) and transitions between them based on the mode input.
