Here's a novel approach using a state machine implementation instead of pure combinational logic. The idea is:
1. Define 4 distinct states: IDLE, HEATING, COOLING, FAN_ONLY
2. Transition between states based on inputs (mode, too_cold, too_hot, fan_on)
3. Outputs are determined by the current state
4. This provides more explicit control flow and could be easier to modify/extend
5. The state machine makes the behavior more explicit and debuggable
