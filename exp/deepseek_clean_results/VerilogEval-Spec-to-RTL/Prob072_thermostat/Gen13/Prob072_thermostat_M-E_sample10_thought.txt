Here's a novel approach using a state machine implementation with explicit states for heating, cooling, and idle modes. While functionally equivalent to the combinational solution, this approach:
1. Makes the operational modes more explicit and easier to modify/extend
2. Provides better visibility into the current operating state
3. Could be more power-efficient in scenarios where temperature changes are infrequent
4. Offers a foundation for adding more complex control logic in the future

The state machine will have three states:
- IDLE: Neither heating nor cooling
- HEATING: Heater is active
- COOLING: Aircon is active
Transitions between states are based on mode and temperature inputs.
