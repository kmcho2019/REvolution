Implement the thermostat controller as a finite state machine (FSM) with four distinct states:
1. IDLE - No heating/cooling active
2. HEATING - Heater is on
3. COOLING - Aircon is on
4. FAN_ONLY - Only fan is active by user request

This approach:
1. Makes the system behavior more explicit and easier to modify
2. Provides better visibility into current operating mode
3. Allows for easier addition of timing constraints or delays in future
4. Enables more complex control logic if requirements expand
5. Still maintains all current functionality while being more structured
