Here's a novel approach using a priority-encoded state machine with explicit state variables. This design:

1. Uses a 2-bit state register to explicitly track the system state (IDLE, HEATING, COOLING)
2. Implements priority encoding where user fan request takes precedence over temperature control
3. Separates the mode selection and fan control into distinct always blocks for modularity
4. Uses a more formal state machine approach that could be easily extended for more complex behaviors
5. Makes the control flow more explicit and potentially more maintainable

Key innovations:
- Explicit state representation instead of purely combinational logic
- Clear separation of fan control logic
- Priority encoding makes behavior more deterministic
- More scalable architecture for future enhancements
