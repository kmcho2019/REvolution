Based on the PPA metrics and feedback, here's an optimized version with the following improvements:

1. **Simplified Fan Logic**: Replace XOR with OR since heater and aircon are mutually exclusive (mode ensures only one can be active). This reduces gate count and power.

2. **Direct Mode Usage**: Eliminate the not_mode wire by directly using ~mode in the aircon assignment, saving one inverter.

3. **Combined Output Conditions**: Use single-level logic expressions for each output to potentially reduce routing complexity and improve timing.

4. **Explicit Output Gating**: Maintain clear conditions for each output to prevent any potential glitches.

These changes should reduce area and power while maintaining or improving timing performance.
