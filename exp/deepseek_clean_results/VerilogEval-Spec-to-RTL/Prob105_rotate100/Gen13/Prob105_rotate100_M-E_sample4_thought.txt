Instead of physically shifting bits, we can implement a virtual rotation using a pointer-based approach:
1. Maintain a 100-bit register and a 7-bit rotation offset (since log2(100)=7)
2. The offset tracks the virtual rotation position (0-99)
3. For load: reset offset to 0 and store data
4. For rotation: increment/decrement offset modulo 100
5. Output is generated by selecting bits based on current offset using a barrel shifter
This reduces the physical bit movement and may offer better PPA for large registers
