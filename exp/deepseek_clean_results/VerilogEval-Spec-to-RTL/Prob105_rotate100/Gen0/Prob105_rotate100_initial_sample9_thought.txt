To implement a 100-bit rotator with synchronous load and enable controls:
1. Use a 100-bit register to store the current value (q)
2. On each positive clock edge:
   - If load is high, load data[99:0] into the register
   - Else if ena is 2'b01, perform right rotation (LSB moves to MSB)
   - Else if ena is 2'b10, perform left rotation (MSB moves to LSB)
   - For other ena values (2'b00 or 2'b11), maintain current value
3. Right rotation is done by concatenating q[0] with q[99:1]
4. Left rotation is done by concatenating q[98:0] with q[99]
