Instead of physically shifting bits, we can implement a virtual rotation using a pointer-based approach:
1. Maintain a 100-bit register (storage) that never moves
2. Use a 7-bit pointer (since 100 needs 7 bits) to track the "start" position
3. For rotation operations, simply adjust the pointer:
   - Right rotate: decrement pointer (with wrap-around)
   - Left rotate: increment pointer (with wrap-around)
4. The output q is generated by selecting 100 consecutive bits from the circular buffer formed by {storage, storage}
5. Load operation resets the pointer to 0 and updates storage
This approach reduces the physical bit movement and may improve timing for large registers
