Novel Barrel Rotation Architecture:
1. Instead of using a case statement, pre-compute all possible rotation outcomes in parallel
2. Use a 4:1 multiplexer to select between:
   - No rotation (hold current value)
   - Right rotation
   - Left rotation
   - Load value
3. The rotation operations are computed combinatorially in parallel
4. The multiplexer selection is determined by {load, ena} combined into a single control signal
5. Benefits:
   - Potentially better timing as all paths are balanced
   - Clear separation of computation and selection
   - Easier to pipeline if needed
   - More scalable for larger bit widths
