Novel Architectural Idea: 
1. Instead of using a single large register, implement the rotator as two separate 50-bit registers that can be swapped and rotated independently. This reduces the critical path for rotation operations.
2. Use a hierarchical rotation approach:
   - First level: Swap upper and lower 50-bit halves when rotating across the midpoint
   - Second level: Perform local rotation within each 50-bit half
3. Implement rotation direction control through a single XOR operation on the swap signal, reducing control logic complexity
4. Maintain synchronous load functionality by loading both halves in parallel

Benefits:
- Potentially better timing due to reduced fanout on rotation paths
- More balanced load distribution across the design
- Interesting trade-off between area and performance
