Instead of physically shifting bits, we can implement a virtual rotation using a read pointer:
1. Maintain a 100-bit storage register and a 7-bit pointer (since 100 needs 7 bits)
2. The pointer indicates the current "start" position of the rotated data
3. For right rotation: decrement pointer (with wrap-around)
4. For left rotation: increment pointer (with wrap-around)
5. The output q is generated by reading the circular buffer starting at pointer position
6. Load operation resets both the storage and pointer to 0
This approach reduces the physical bit movement and muxing complexity compared to the traditional shift implementation.
