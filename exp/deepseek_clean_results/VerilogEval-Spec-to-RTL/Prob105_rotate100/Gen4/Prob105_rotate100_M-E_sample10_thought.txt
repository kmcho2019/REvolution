Novel Architectural Idea:
1. Instead of using separate left/right rotation logic, implement a unified barrel rotator that can handle both directions with a single multiplexer stage
2. Use a pre-computed rotation amount (1 bit) and direction flag to select the appropriate rotation
3. Implement the rotation using a parameterized circular shift operation
4. Add clock gating for the rotation logic when not active to save power
5. Use a single always block with clear priority for load over rotation operations

Key Benefits:
- Unified rotation logic reduces area compared to separate left/right paths
- Parameterized approach makes it scalable to different bit widths
- Clock gating reduces dynamic power when not rotating
- Single multiplexer stage improves timing
