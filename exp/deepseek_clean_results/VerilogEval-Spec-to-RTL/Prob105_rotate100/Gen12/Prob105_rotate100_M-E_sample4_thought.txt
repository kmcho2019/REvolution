Dynamic Barrel Rotation with Shift Calculation:
1. Instead of pre-computing all rotation directions, calculate the effective shift amount dynamically
2. Use a single shift operation controlled by a calculated shift value:
   - Right rotation: shift = -1 (equivalent to 99 in modulo 100)
   - Left rotation: shift = +1
   - No rotation: shift = 0
3. Implement a barrel shifter that can handle both left and right rotations using modulo arithmetic
4. The load operation bypasses the rotation logic entirely when active
5. Key advantages:
   - Single rotation path instead of parallel paths reduces area
   - Dynamic shift calculation eliminates redundant logic
   - Modular arithmetic handles wrap-around naturally
   - More efficient for variable shift amounts if extended
