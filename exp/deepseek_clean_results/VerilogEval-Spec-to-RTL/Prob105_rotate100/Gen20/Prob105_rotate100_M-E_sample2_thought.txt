Novel Architecture Idea: Pointer-Based Circular Buffer Rotation
1. Instead of physically shifting bits, implement a virtual rotation using pointer arithmetic
2. Maintain a base pointer (6 bits for 100 positions) that indicates the current "start" of the circular buffer
3. Key advantages:
   - Eliminates the need for large multiplexers or barrel shifters
   - Only requires pointer arithmetic logic (small adder/subtractor)
   - Physical storage remains static - only pointer changes during rotation
   - Extremely efficient for large bit widths
4. Implementation approach:
   - Store data in a fixed register
   - Use pointer to virtually rotate by selecting different start points
   - Output is generated by concatenating two segments around the pointer
   - Synchronous load resets the pointer to zero
