Novel Barrel Shifter Architecture:
1. Instead of separate left/right rotation logic, implement a unified barrel shifter that can handle both directions
2. Pre-compute all possible rotation patterns (100 variations) and store them in a ROM-like structure
3. Use the ena input to select the appropriate rotation pattern (including no-rotation)
4. The load operation still takes priority and bypasses the rotation logic
5. Benefits:
   - Single-cycle rotation for any amount (though we only need ±1)
   - Symmetrical timing for left/right rotations
   - Potential area savings from shared rotation logic
   - Easily extensible to support larger rotation amounts
   - Clean critical path with just one large mux
