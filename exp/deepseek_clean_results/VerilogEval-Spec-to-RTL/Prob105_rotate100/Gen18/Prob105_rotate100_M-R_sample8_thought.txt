Refactoring Approach: Combinational Logic with Continuous Assignment
1. Move the rotation logic to combinational always block or continuous assignment
2. Use a wire to compute the next state value based on current state and control signals
3. Register the computed value on clock edge
4. Benefits:
   - Clear separation of combinational and sequential logic
   - Easier timing analysis (setup/hold checks only on the register)
   - More explicit data flow
   - Potentially better synthesis results as tools can optimize combinational and sequential parts separately
5. Maintains same functionality while improving code structure
