Instead of physically shifting bits, we can implement a virtual rotation using a pointer-based approach:
1. Maintain a 100-bit register for storage and a 7-bit pointer (since 100 needs 7 bits)
2. The pointer tracks the "start" position of the circular buffer
3. For right rotation: decrement pointer (with wrap-around)
4. For left rotation: increment pointer (with wrap-around)
5. The output is generated by reading the circular buffer starting at the pointer position
6. Load operation resets the pointer to 0 and loads new data
This approach reduces the physical bit shifting operations to simple pointer arithmetic.
