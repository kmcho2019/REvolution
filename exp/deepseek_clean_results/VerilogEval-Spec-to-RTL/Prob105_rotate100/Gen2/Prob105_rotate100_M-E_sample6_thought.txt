Instead of physically rotating bits, we can implement a virtual rotation using a pointer-based approach:
1. Maintain a 100-bit register and a 7-bit rotation pointer (since 100 needs 7 bits)
2. The pointer tracks the current rotation offset (0-99)
3. For load: reset pointer to 0 and store data
4. For rotation:
   - Right rotation (ena=01): decrement pointer (with wrap-around)
   - Left rotation (ena=10): increment pointer (with wrap-around)
5. The output q is generated by virtually rotating the stored data based on pointer value
This approach reduces the physical bit movement and may offer better timing for large registers.
