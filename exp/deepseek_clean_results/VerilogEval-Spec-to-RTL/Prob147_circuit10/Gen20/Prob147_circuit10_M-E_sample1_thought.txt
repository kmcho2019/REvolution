Here's a novel approach using a state machine with edge detection:
1. Instead of directly computing the next state from inputs, we'll detect rising/falling edges on inputs
2. The state will toggle only when we detect specific edge patterns (a rising while b is high)
3. The output q will be a function of both current inputs and the detected edge state
4. This approach provides better noise immunity and can be extended for more complex patterns

Key differences from original:
- Uses edge detection for state transitions
- State changes only on specific input patterns
- Output logic combines edge information with current inputs
- More robust to input glitches between clock edges
