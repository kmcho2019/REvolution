Based on the feedback, here's an optimized approach:
1. Remove the submodule hierarchy since it's overkill for this simple function and adds unnecessary overhead
2. Implement both muxes directly in the TopModule
3. For the always block, assign directly to the output wire to avoid the intermediate register
4. Keep the shared select logic (AND of sel_b1 and sel_b2) for both implementations
5. This reduces area by eliminating the submodule and register while maintaining the same functionality
6. The simplified structure should also marginally improve timing and power
