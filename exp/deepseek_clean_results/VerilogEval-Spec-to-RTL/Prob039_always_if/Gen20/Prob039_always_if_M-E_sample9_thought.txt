To implement a 2-to-1 multiplexer with a novel approach, we can:
1. Use a single continuous assignment with a clever logical expression that combines the selection signals
2. For the always-block version, implement it as a lookup table using a case statement
3. This approach demonstrates alternative ways to implement selection logic while maintaining the same functionality
4. The case statement version shows how we can think of the selection as a 2-bit encoded value
