Here's a novel approach using a hierarchical design with a submodule:
1. Create a separate Mux2to1 module that implements the basic 2-to-1 mux functionality
2. The top module will instantiate two instances of this mux - one for each output type
3. The selection logic (AND of sel_b1 and sel_b2) is computed once and shared between both mux instances
4. This promotes code reuse and makes the design more modular
5. The mux implementation can be easily changed in one place if needed
