Here's a novel approach using a different architectural style:
1. Instead of using ternary operators or if statements, we'll implement the selection logic using basic gates
2. Create an AND gate for the selection condition (sel_b1 & sel_b2)
3. Use this signal to control two AND gates and one OR gate to form the mux
4. For the procedural version, we'll use a case statement with concatenated select signals for variety
5. This approach demonstrates alternative ways to implement the same functionality while maintaining the same logical behavior
