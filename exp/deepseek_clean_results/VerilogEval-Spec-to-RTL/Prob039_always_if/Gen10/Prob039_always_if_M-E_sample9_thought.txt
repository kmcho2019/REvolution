Here's a novel approach using a priority encoder concept:
1. Instead of using a direct AND of sel_b1 and sel_b2, we'll treat the select signals as a 2-bit priority code
2. The output will select 'b' only when both select bits are high (11 case)
3. For all other combinations (00, 01, 10), we'll select 'a'
4. This implementation uses a case statement for the always block and a similar logic for the continuous assignment
5. The approach makes it easier to extend to more select signals if needed
