To implement a 2-to-1 multiplexer with the given conditions, we need to:
1. For the assign version (out_assign): Use a continuous assignment with a conditional operator that checks if both sel_b1 and sel_b2 are true (logical AND). If true, output b; otherwise, output a.
2. For the procedural version (out_always): Use an always block with an if statement that checks the same condition (sel_b1 AND sel_b2). The output is registered, so we should declare it as a reg type.
