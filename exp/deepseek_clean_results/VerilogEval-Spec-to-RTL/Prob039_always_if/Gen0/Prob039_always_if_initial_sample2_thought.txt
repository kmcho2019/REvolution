To implement a 2-to-1 multiplexer with the given conditions, we need to:
1. For the assign version: Create a continuous assignment where 'out_assign' is assigned to 'b' only when both sel_b1 and sel_b2 are true (logical AND), otherwise assign it to 'a'.
