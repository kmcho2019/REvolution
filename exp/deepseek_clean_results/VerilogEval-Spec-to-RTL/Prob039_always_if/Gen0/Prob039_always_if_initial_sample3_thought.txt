To implement a 2-to-1 multiplexer with the given conditions, we need to:
1. For the assign version (out_assign): Use a continuous assignment where the output is b when both sel_b1 and sel_b2 are true, otherwise a.
2. For the procedural version (out_always): Use an always block with an if statement to check if both sel_b1 and sel_b2 are true, then assign b to output, else assign a.
