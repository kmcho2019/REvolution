Here's a novel approach that uses a lookup table (LUT) style implementation:
1. Instead of traditional mux logic, we'll encode all possible input combinations into a 4-bit LUT
2. The LUT will be constructed based on the truth table of the desired function
3. For the assign version, we'll use a concatenation-based lookup
4. For the always version, we'll implement a case statement that mimics LUT behavior
5. This approach demonstrates an alternative way to think about combinational logic that might be more scalable for more complex functions
