Here's a novel approach using a hierarchical priority encoder style implementation:

1. **Key Idea**: Instead of using traditional mux logic, implement a priority-based selection where the selection signals (sel_b1, sel_b2) form a 2-bit priority code.
2. **Innovation**:
   - Treat the selection as a 2-bit vector where [sel_b2, sel_b1] forms a priority code
   - Use bitwise operations to determine the output selection
   - Implement both outputs using different but equivalent logical expressions
3. **Advantages**:
   - Demonstrates alternative logic implementation without using ternary or if-else
   - Shows how the same functionality can be achieved through different logical expressions
   - Potentially better for certain synthesis targets due to different gate-level implementation
4. **Implementation**:
   - out_assign: Uses OR of AND conditions
   - out_always: Uses XOR-based selection logic
   - Both functionally equivalent but structurally different
