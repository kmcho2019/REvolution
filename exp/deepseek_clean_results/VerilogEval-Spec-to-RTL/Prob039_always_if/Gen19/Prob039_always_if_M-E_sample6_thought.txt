Here's a novel approach using a priority encoder style implementation:
1. Instead of using a direct AND gate for selection, implement a priority scheme
2. Create a 2-bit selection vector combining both sel_b1 and sel_b2
3. Use this vector to index into a small lookup table implemented via case statements
4. For the assign version, use a bitwise OR of masked inputs
5. This approach provides better scalability if selection logic becomes more complex
6. The case statement implementation is more readable and maintainable
7. The bitwise approach demonstrates alternative logic implementation
