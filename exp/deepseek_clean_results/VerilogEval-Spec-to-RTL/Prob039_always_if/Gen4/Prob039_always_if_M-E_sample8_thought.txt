Novel approach using bitwise operations and parameterized selection:
1. Instead of using direct conditional operators or if-else, implement the mux using bitwise operations for potential optimization in synthesis
2. Create a combined select signal by OR-ing sel_b1 and sel_b2, then use this to control the mux
3. For the always block, use a case statement with concatenated select signals for readability
4. This approach demonstrates alternative ways to implement the same logic that might be more efficient in certain synthesis scenarios
