To implement a 2-to-1 mux with a different approach, we can:
1. Use a single module with both implementations (assign and always) without sub-modules
2. Create a combined select signal that is the AND of sel_b1 and sel_b2
3. Use this combined signal for both mux implementations
4. This approach reduces hierarchy while maintaining clear separation of the two implementation styles
5. The combined select signal calculation is shared between both mux implementations
