Here's an innovative approach using bitwise operations and parameterized selection:
1. Instead of using traditional if-else or ternary operators, we'll use bitwise operations to implement the mux
2. The selection logic is computed as a mask where all bits are 1 when both sel_b1 and sel_b2 are true
3. We then use this mask to select between a and b through bitwise AND and OR operations
4. This approach eliminates branching (both in assign and always blocks) which can be beneficial for timing
5. The same technique is applied to both output implementations for consistency
