The original solution uses a LUT-style approach which is unnecessarily complex for this simple 2-to-1 mux. We can simplify by:
1. Directly using the logical AND of sel_b1 and sel_b2 as the selection condition
2. For the assign version: use a simple ternary operator with the AND condition
3. For the always version: use a simple if-else statement with the AND condition
4. This reduces the logic complexity while maintaining identical functionality
