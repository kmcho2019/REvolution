The previous solution is already quite minimal, but we can simplify it further by:
1. Removing the explicit initialization (let synthesis handle default initial state)
2. Using a continuous assignment for the mux instead of putting it in the always block
3. Making the flip-flop behavior more straightforward

This reduces the code to its most essential elements while maintaining identical functionality. The mux selection happens combinationally, and the flip-flop captures the result on clock edges.
