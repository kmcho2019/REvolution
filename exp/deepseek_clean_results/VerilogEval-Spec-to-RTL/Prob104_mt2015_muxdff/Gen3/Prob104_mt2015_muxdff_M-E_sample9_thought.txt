Here's an alternative approach using a different architectural style:
1. Instead of using continuous assignment for the mux, implement it within the always block
2. This combines the mux and flip-flop logic in a single sequential block
3. The mux selection happens synchronously with the clock edge
4. This approach reduces the number of signals/wires needed
5. The functionality remains the same but with a more compact implementation
6. The design is still modular and can be instantiated three times in the full_module
