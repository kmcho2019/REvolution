To implement the TopModule, we need to create a basic building block that can be instantiated three times in the full_module. Each TopModule should represent one bit of the 3-bit register with load capability. The module needs:
1. A D flip-flop to store one bit of state
2. A 2:1 mux to select between loading a new value (r_in) or using the feedback path from the other flip-flops (q_in)
3. The mux select will be controlled by the L input
4. The flip-flop should be clocked by clk

The TopModule will take q_in and r_in as inputs (for feedback and load values respectively), L as the load control, and clk as the clock. It will output the current Q value.
