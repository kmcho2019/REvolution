To implement TopModule, we need to create a basic building block that can be instantiated three times in full_module. Each instance will represent one bit of the 3-bit register. The module should:
1. Include a D flip-flop that stores one bit of state (q_out)
2. Use a 2:1 mux to select between:
   - Loading new value (r_in) when L is high
   - Feedback value (q_in) when L is low
3. The selected value is clocked into the flip-flop on the positive edge of clk
4. The flip-flop output (Q) is directly connected to the output port
