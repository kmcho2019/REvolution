Instead of using a traditional FSM, I'll implement a shift register that stores the last 4 bits of input. The solution will:
1. Use a 4-bit shift register to track the last 4 input bits
2. Compare the register contents with the target pattern (1101) each cycle
3. Set a latch when the pattern is detected
4. The latch remains set until reset
5. This approach eliminates explicit state transitions and reduces control logic

Benefits:
- Simpler implementation with just a shift register and comparator
- Easily scalable to longer patterns by increasing register size
- Clear separation between pattern storage and detection logic
