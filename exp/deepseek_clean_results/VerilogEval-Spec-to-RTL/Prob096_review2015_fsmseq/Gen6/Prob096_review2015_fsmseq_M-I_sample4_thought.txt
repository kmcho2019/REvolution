Optimization strategy based on PPA metrics:
1. Timing: Replace shift register with explicit state machine to reduce comparator complexity and critical path
2. Power: Add clock gating for state registers when pattern is found
3. Area: Use minimal state encoding (4 states) and combine output register with state logic

The improved design uses a Moore FSM with 4 states representing the progress in matching the sequence. This eliminates the 4-bit shift register and reduces the comparison logic to simple state transitions. The start_shifting output is directly derived from the state, removing a separate register. Clock gating is implemented to freeze state transitions after pattern detection.
