Refactoring Strategy:
1. State Representation: Use one-hot encoding (5 bits) instead of binary encoding for potentially better timing and simpler decoding logic.
2. State Transitions: Implement the FSM using continuous assignments (assign) instead of an always block for a more combinational approach.
3. Output Logic: Keep the simple combinational assign for start_shifting.
4. Reset Handling: Maintain synchronous reset behavior but implement it through register updates in a separate always block.
5. State Update: Split the logic into next-state computation (combinational) and state register update (sequential).

Key Changes:
- One-hot encoding makes state transitions more explicit
- Combinational next-state logic using assign statements
- Separate sequential state register update
- Maintains same functionality but with different implementation style
