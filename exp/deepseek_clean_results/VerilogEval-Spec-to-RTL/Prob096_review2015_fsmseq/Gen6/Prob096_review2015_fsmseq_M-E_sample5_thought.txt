Instead of using a traditional FSM, we can implement the sequence detector using a 4-bit shift register that stores the last 4 input bits. The sequence detection becomes a simple pattern match on the shift register contents. This approach:
1. Uses a 4-bit shift register to track the last 4 bits of input
2. Compares the register contents with the target pattern (4'b1101)
3. Sets start_shifting when a match is found and holds it until reset
4. Has simpler control logic than an FSM since it's just shifting and comparing
5. Still meets all timing requirements as the critical path is just the comparison
