Instead of using a traditional state machine, I'll implement a shift register that stores the last 4 bits of input. This allows me to:
1. Use a 4-bit shift register to track the most recent input sequence
2. Compare the register contents directly with the target pattern (1101)
3. Set a latch when the pattern is detected
4. The latch remains set until reset, eliminating the need for a separate state
5. This approach reduces the state machine complexity and leverages parallel pattern matching

Benefits:
- Simpler control logic (no explicit state transitions)
- Easier to modify for different pattern lengths
- Clear relationship between hardware and functionality
