Novel Approach: Shift Register + Combinational Matching
1. Instead of using a traditional FSM, implement a 4-bit shift register to store the last 4 input bits.
2. Use combinational logic to detect the pattern "1101" in the shift register.
3. Once detected, set a latch that keeps start_shifting high until reset.
4. This approach reduces the state machine complexity to just tracking whether we've found the pattern or not.
5. Benefits:
   - Eliminates explicit state transitions
   - Simple pattern matching logic
   - Naturally handles overlapping sequences
   - Easily scalable to longer patterns
