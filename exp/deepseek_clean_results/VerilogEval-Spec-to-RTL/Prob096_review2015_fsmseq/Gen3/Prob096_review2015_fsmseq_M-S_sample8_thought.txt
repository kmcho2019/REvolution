To simplify the sequence detector while maintaining functionality:
1. Reduce the state encoding from 3 bits to 2 bits since we only need 5 states (can be represented with 3 bits, but 2 bits is sufficient for 4 states and we can combine some states)
2. Combine the output logic with the state transition logic to eliminate a separate combinational block
3. Use simpler state transitions by merging the S2 and S3 states when possible
4. Keep the same fundamental behavior: detect "1101" and hold start_shifting until reset
