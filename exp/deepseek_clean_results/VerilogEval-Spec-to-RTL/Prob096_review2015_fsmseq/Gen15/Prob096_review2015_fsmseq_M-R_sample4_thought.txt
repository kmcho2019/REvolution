Refactoring Strategy:
1. State Machine Approach:
   - Replace shift register with explicit state transitions
   - Use one-hot encoding for states to simplify comparison logic
   - Each state represents progress in the sequence detection

2. Simplified Logic:
   - Combine pattern matching into state transitions
   - Eliminate separate comparison logic
   - Directly encode the sequence detection in state transitions

3. Output Logic:
   - Make output purely combinational based on current state
   - Remove explicit 'found' register since the final state serves this purpose

4. Reset Handling:
   - Maintain synchronous reset for all state registers
   - Initialize to IDLE state on reset

Key Benefits:
- More explicit state representation
- Reduced logic levels (direct state transitions)
- Maintains same functionality with cleaner structure
- Easier to modify for different sequences
