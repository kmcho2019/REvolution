Here's a novel approach using a state machine with explicit states for each bit of the sequence:
1. Instead of using a shift register, implement a Moore FSM with states representing partial matches
2. Each state corresponds to how much of the sequence (1101) has been matched so far
3. The FSM transitions between states based on the input data bit
4. Once the full sequence is matched (state S4), it stays in that state until reset
5. This approach eliminates the need for a shift register and reduces the comparison logic to simple state transitions

Benefits:
- More explicit state representation
- Potentially better timing as each state transition depends only on current state and input
- Clear separation of matching logic
- Lower power when in S4 state as no shifting occurs
