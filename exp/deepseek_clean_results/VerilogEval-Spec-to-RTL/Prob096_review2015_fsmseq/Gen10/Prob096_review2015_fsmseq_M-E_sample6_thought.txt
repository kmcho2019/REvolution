Novel Architecture: Binary Decision Tree with Early Termination
1. Instead of using a shift register, implement a binary decision tree that tracks partial matches
2. Each level of the tree represents progress through the sequence (1, 11, 110, 1101)
3. Use parallel comparators at each level to detect matches
4. Early termination: once the full sequence is detected, disable all comparison logic
5. State tracking uses minimal registers (just the found flag)
6. Power optimization: comparison logic is only active when needed (not found yet)
7. Area efficiency: eliminates shift register in favor of direct pattern matching
8. Timing advantage: parallel comparisons can potentially reduce critical path
