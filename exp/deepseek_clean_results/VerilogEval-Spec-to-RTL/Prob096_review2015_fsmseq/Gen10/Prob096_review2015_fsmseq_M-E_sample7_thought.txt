Novel Approach: Binary Decision Tree State Machine
1. Instead of using a shift register, implement a compact state machine that tracks partial matches
2. Each state represents how much of the pattern (1101) has been matched so far
3. States transition only when the next expected bit is received
4. Eliminates the need for a shift register, reducing area
5. Explicit state transitions make timing paths predictable
6. Power efficient as only relevant state transitions occur

Key Advantages:
- No shift register means lower area (only 4 states needed)
- Clear state transitions for better timing analysis
- Only activates next state logic when pattern matching progresses
- Naturally stops state transitions after full match is found
