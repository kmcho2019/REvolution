Novel Architecture Idea: State Machine with History Tracking
1. Instead of using a shift register, implement a state machine that tracks progress through the sequence
2. Each state represents how much of the sequence has been matched so far
3. State transitions occur based on whether the current input matches the next expected bit
4. Add a terminal state that latches the output permanently once the full sequence is detected
5. Benefits:
   - More explicit representation of the sequence matching process
   - No unnecessary shifting of bits after detection
   - Clear state transitions make the design more maintainable
   - Potentially better timing as comparison is done incrementally rather than all at once
