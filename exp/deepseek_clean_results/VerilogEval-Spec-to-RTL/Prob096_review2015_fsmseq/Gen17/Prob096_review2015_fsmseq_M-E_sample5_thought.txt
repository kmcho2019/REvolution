Novel Approach: State Machine with Explicit States
1. Instead of using a shift register, implement an explicit state machine with states representing partial matches
2. Each state corresponds to how much of the sequence (1101) has been matched so far
3. State transitions occur based on whether the current input bit matches the next expected bit in the sequence
4. When the full sequence is matched (state S4), the output is asserted and remains high until reset
5. This approach eliminates the need for a shift register, potentially saving area
6. The state encoding is simple and intuitive, making the design easy to understand and verify
