Simplification Strategy:
1. State Reduction:
   - Use a 4-state FSM instead of shift register + comparator
   - Each state represents progress in sequence detection (0-3 bits matched)

2. Logic Simplification:
   - Eliminate the 4-bit comparator by using state transitions
   - Reduce combinational logic to simple state transition conditions

3. Maintain Functionality:
   - Still detects exact sequence 1101
   - Output remains asserted until reset
   - Synchronous reset behavior preserved

4. Hardware Savings:
   - Replace 3-bit shift register with 2-bit state register
   - Eliminate comparator logic
   - Single-bit output register maintained

Key Benefits:
- Fewer registers (2 bits vs original 3+1)
- Simpler combinational logic
- Same functionality with reduced complexity
