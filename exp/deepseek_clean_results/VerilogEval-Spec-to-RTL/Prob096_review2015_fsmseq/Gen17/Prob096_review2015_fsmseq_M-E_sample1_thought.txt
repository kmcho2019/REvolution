Novel Approach: State Machine with Early Termination
1. Instead of using a shift register, implement a Moore FSM with states representing partial matches
2. States: IDLE, S1 (1), S11 (11), S110 (110), FOUND (1101 detected)
3. Key innovation: Add early termination by checking current input in each state transition
4. Output becomes 1 and stays 1 once FOUND state is reached
5. Reset synchronously returns to IDLE state
6. More power efficient than shift register approach as only state transitions consume power
7. Potentially smaller area as it eliminates shift register hardware
