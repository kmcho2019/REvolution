Here's a novel approach using a state machine with explicit states for partial sequence matching:
1. Instead of using a shift register, implement explicit states representing progress in matching the sequence
2. States represent how many bits of the sequence have been matched so far (0 to 4)
3. Transition between states based on current state and input bit
4. Only reach the final state when full sequence is matched
5. Once in final state, stay there until reset
6. This approach is more scalable for longer sequences and makes the matching logic very explicit

The states are:
- S0: No bits matched
- S1: '1' matched
- S2: '11' matched
- S3: '110' matched
- S4: '1101' matched (final state)
