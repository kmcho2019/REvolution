Refactoring Approach:
1. Replace the shift register with explicit state encoding using a 4-state FSM
2. Use combinational always block for next state logic and sequential for state registers
3. Maintain the same detection logic (1101 sequence) but express it through state transitions
4. Keep the synchronous reset and output behavior identical
5. The FSM approach makes the sequence matching more explicit and may offer better synthesis optimization in some tools
6. Power optimization is maintained by freezing state transitions after detection
