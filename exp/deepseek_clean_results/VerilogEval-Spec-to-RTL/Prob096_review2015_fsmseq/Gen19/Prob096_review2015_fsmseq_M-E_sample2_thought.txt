Here's a novel approach using a binary counter to track the sequence match progress:
1. Instead of a shift register, use a 2-bit counter to track how many consecutive correct bits we've seen
2. The counter increments when the current bit matches the expected next bit in the sequence (1,1,0,1)
3. When the counter reaches 3 (meaning we've seen 110) and the current bit is 1, we've found the full sequence
4. This approach reduces storage requirements (2 bits vs 3 in shift register) and has simpler comparison logic
5. The found flag behavior remains the same - stays high until reset
