Here's a simplified approach that maintains functionality while reducing complexity:
1. Use a 2-bit shift register to track the last two bits (plus current input)
2. Implement a state machine with 4 states to track progress towards the sequence
3. Each state represents how much of the sequence we've matched so far
4. Transition between states based on current input bit
5. Set output when reaching the final state and maintain until reset

This approach reduces register usage while keeping the logic simple and clear. The state machine explicitly shows the sequence matching progress.
