Novel Architectural Idea:
1. Use a Mealy-style finite state machine (FSM) with minimal states (4 states) to track the sequence progress
2. Implement a "sliding window" approach where each state represents the number of correct consecutive bits matched
3. Eliminate the need for a shift register by using state transitions based on the current input bit
4. Optimize power by:
   - Only transitioning states when actively searching (not in final found state)
   - Using minimal state encoding (2 bits)
5. Improve timing by:
   - Reducing combinational logic depth (simple state transitions)
   - Having registered outputs
6. Key advantages:
   - Lower area than shift register approach (only 2 flip-flops for state)
   - Faster detection (state transitions happen in parallel with comparison)
   - Clear state diagram representation of the sequence matching
