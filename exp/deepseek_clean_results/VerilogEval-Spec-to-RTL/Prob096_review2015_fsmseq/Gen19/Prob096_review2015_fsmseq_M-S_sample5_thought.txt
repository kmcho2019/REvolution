Simplification Strategy:
1. Reduce state tracking to just the necessary bits - we only need to remember the sequence progress
2. Use a simple 4-state FSM to track pattern matching progress:
   - State 0: No bits matched
   - State 1: First '1' matched
   - State 2: '11' matched
   - State 3: '110' matched
3. Output goes high when we reach state 3 and see a '1'
4. Reset returns to initial state
5. Output remains high once set until reset

Key Benefits:
- Clear, minimal state representation
- Simple progression logic
- No complex shift registers or parallel comparisons
- Maintains all functionality with reduced complexity
