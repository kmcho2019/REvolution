Counter-Based Sequence Detection:
1. Instead of a traditional shift register or FSM, use a 2-bit counter to track partial matches
2. The counter increments when current input matches expected next bit in sequence
3. Reset counter on mismatch, advance on match
4. When counter reaches 3 (indicating 3 correct consecutive matches) and next bit completes sequence, trigger detection
5. Advantages:
   - Reduced comparison logic (only need to check current bit against expected value)
   - Fewer state transitions (only counter increments/resets)
   - Lower power as only counter updates after initial matches
   - Scales well for longer sequences
