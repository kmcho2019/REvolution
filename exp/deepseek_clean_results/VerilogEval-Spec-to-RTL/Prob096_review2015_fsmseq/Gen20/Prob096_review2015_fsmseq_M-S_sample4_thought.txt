Simplified Design Approach:
1. State Tracking:
   - Use a 3-bit shift register to track the last 3 bits received
   - Eliminate separate 'found' register by using shift_reg as both storage and detection state

2. Detection Logic:
   - Directly compare the concatenation of shift_reg and current data with 4'b1101
   - When matched, set output permanently until reset

3. Optimization:
   - Remove redundant parallel comparison logic
   - Use simple pattern matching on the shift register + input
   - Output is just the MSB of the shift register (acts as found flag)

Key Benefits:
- Fewer registers (no separate found flag)
- Simpler comparison logic
- Maintains same functionality with less hardware
- Still freezes state after detection
