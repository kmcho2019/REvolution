Simplification Strategy:
1. State Reduction:
   - Eliminate separate 'found' register by using shift register value as state
   - When sequence is found (shift_reg == 3'b110 and data == 1), lock output high

2. Direct Comparison:
   - Compare only when we have 3 previous bits (shift_reg) plus current data
   - This forms the complete 4-bit sequence to match (1101)

3. Reset Handling:
   - Maintain synchronous reset that clears the shift register
   - Output naturally goes low on reset since shift register is cleared

4. Output Logic:
   - Output is simply whether we've seen the complete sequence
   - Once sequence is found, output stays high until reset

Key Benefits:
- Fewer registers (no separate 'found' flag)
- Same functionality with simpler logic
- Clear direct mapping between state and output
- Maintains all original requirements
