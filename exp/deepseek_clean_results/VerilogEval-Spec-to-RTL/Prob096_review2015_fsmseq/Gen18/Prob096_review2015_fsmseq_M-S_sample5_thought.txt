Simplification Strategy:
1. State Reduction:
   - Eliminate separate 'found' register by using shift register's value as state
   - When sequence is detected, lock shift_reg to 4'b1101 (pattern itself becomes the state)

2. Logic Simplification:
   - Single always block handles both shift and detection
   - Output directly tied to shift_reg matching the pattern

3. Reset Handling:
   - Maintain synchronous reset behavior
   - Clear shift register on reset

Key Benefits:
- Eliminates one register (found flag)
- Simpler state representation
- Maintains identical functionality
- Reduced logic complexity
