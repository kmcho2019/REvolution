Simplified Design Approach:
1. State Tracking:
   - Use a 3-bit shift register to track the last 3 bits of input
   - Eliminate separate 'found' register by making output directly dependent on detection

2. Detection Logic:
   - Compare current state (shift_reg + new data) against target pattern 1101
   - Use simple bit-wise comparison for clarity and efficiency

3. Output Logic:
   - Output is simply the detection result, latched until reset
   - No need for separate state tracking since output persists after detection

Key Simplifications:
- Removed redundant 'found' register by directly using shift register state
- Simplified comparison logic to single expression
- Reduced total registers from 4 bits (3+1) to just 3 bits
- Maintains same functionality with less hardware
