Here's a novel approach using a state machine with overlapping sequence detection:
1. Instead of using a shift register, implement a Moore FSM with states representing partial matches
2. Each state represents how much of the sequence (1101) has been matched so far
3. The FSM transitions between states based on the current input bit
4. When the full sequence is detected, transition to a "found" state that persists until reset
5. This approach eliminates the need for a shift register and directly encodes the sequence matching logic in state transitions

Advantages:
- More explicit state representation of the matching process
- Potentially better timing as it avoids the shift register's propagation delay
- Clear state transition diagram that directly maps to the sequence detection
- Lower power when in "found" state as no shifting occurs
