Here's a novel approach using a state machine with explicit states for pattern matching:
1. Instead of using a shift register, implement a Mealy FSM with states representing partial matches
2. Each state represents how much of the sequence (1101) has been matched so far
3. Transition between states based on current state and input data
4. Output becomes 1 when reaching the final state and stays there until reset
5. This approach eliminates the need for a shift register and directly encodes the matching logic in state transitions

Advantages:
- More explicit state representation of pattern matching progress
- Potentially better timing as it avoids the shift register chain
- Clear state transition diagram makes behavior more understandable
- Easier to modify for different pattern lengths
