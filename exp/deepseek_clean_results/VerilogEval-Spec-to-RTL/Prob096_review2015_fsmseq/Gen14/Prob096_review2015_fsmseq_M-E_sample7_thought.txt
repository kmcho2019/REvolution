This solution implements a novel "delayed comparison" approach that:
1. Uses a 3-bit shift register to store the last 3 bits (110)
2. Only checks for the final '1' when the first 3 bits match 110
3. Uses a state bit to remember when we're in "expecting last 1" state
4. Reduces comparison logic by splitting the pattern matching
5. Minimizes switching activity by only updating the state bit when needed
6. Maintains the same functionality with potentially better PPA metrics
