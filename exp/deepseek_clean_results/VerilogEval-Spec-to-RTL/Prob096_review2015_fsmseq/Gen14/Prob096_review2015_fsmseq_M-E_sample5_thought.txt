This solution implements a hierarchical binary decision tree for sequence detection:
1. Instead of a shift register, we use a tree of state machines where each level checks part of the sequence
2. First level checks for '1', second for '1' following a '1', third for '0' following '11', etc.
3. Each level only activates when the previous level was matched
4. The final output latches when the full sequence is detected
5. This approach minimizes unnecessary comparisons and reduces switching activity

Benefits:
- Only active comparators when previous sequence segments match
- Naturally stops evaluating after sequence is found
- Modular structure that could be extended to longer sequences
- Lower power consumption as only necessary logic is active
