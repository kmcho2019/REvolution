Optimization strategy based on PPA metrics:
1. Reduce critical path by converting to explicit FSM with one-hot encoding - this eliminates the shift register comparison logic
2. Minimize power by adding clock gating for the state registers when start_shifting is active
3. Simplify area by merging the start_shifting output with the final state
4. Maintain the same functionality while improving timing (reduce wns/tns) and power

The improved design uses a 4-state one-hot FSM:
- States represent the number of matching bits in sequence (0-3)
- Transition to final state (S_DONE) when full sequence is detected
- S_DONE state directly drives start_shifting and stops further transitions
- Clock gating implemented via enable signal
