Optimization strategy based on PPA metrics:
1. Timing: Replace shift register with explicit state machine to reduce comparator complexity
2. Power: Add clock gating for state registers when pattern is found
3. Area: Use minimal 4-state encoding (2 bits) and combine output register with state logic

The improved design uses a Moore FSM with 4 states representing pattern progression. This eliminates the 4-bit shift register and reduces the comparison logic to simple state transitions. The start_shifting output is directly derived from the state, eliminating a separate register. Clock gating is implemented to freeze state updates after pattern detection.
