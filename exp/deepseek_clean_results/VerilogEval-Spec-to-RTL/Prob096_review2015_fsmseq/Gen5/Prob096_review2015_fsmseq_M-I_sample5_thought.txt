Optimization strategy based on PPA metrics:
1. Performance: Replace shift register with explicit state machine to reduce critical path (comparing 3 bits + current data vs state transitions)
2. Power: Add clock gating for the state registers when start_shifting is high
3. Area: Use minimal state encoding (5 states instead of 4-bit shift register)

The improved design uses a Moore FSM with these states:
- IDLE: Initial state
- S1: Received '1'
- S2: Received '11'
- S3: Received '110'
- MATCH: Found '1101' sequence

This reduces the comparison logic to simple state transitions while maintaining the same functionality. Clock gating is implemented for power savings.
