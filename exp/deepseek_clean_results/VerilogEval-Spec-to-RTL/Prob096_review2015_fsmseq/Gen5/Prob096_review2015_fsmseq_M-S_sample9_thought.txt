To simplify the sequence detector for "1101", we can reduce the number of states by combining some states and using binary encoding:
1. IDLE (00) - waiting for first '1'
2. GOT1 (01) - received first '1'
3. GOT11 (10) - received "11"
4. FOUND (11) - received "1101"

We can track the "110" sequence within the GOT11 state by checking the current input. This reduces the state machine from 5 to 4 states while maintaining the same functionality. The output remains high only in the FOUND state.
