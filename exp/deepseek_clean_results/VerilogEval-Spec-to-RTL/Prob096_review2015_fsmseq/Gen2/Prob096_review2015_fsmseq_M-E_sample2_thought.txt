Instead of a traditional FSM, we can use a 4-bit shift register to store the last 4 input bits. The sequence detection becomes simple combinational logic checking if the register contains "1101". This approach:
1. Uses a shift register to track history
2. Compares register contents to target sequence
3. Latch the output once sequence is found
4. Reset clears both the register and output

Advantages:
- Simpler state management (just the shift register)
- Easier to modify for different sequence lengths
- Clear separation of sequential and combinational logic
