Here's a novel approach using a shift register and pattern matching:
1. Instead of a traditional FSM, use a 4-bit shift register to store the last 4 input bits
2. Continuously compare the shift register contents with the target pattern (1101)
3. When a match is found, set a latch that keeps start_shifting high until reset
4. This approach eliminates explicit state transitions and reduces the logic to a simple pattern match

Advantages:
- More compact implementation (no explicit state machine)
- Easier to modify for different pattern lengths
- Parallel pattern matching (no sequential state transitions)
- Lower power when not matching (only shift register updates)
