Here's a novel approach using a shift register and pattern matching:
1. Instead of a traditional FSM, we'll use a 4-bit shift register to store the last 4 input bits
2. The shift register will update on each clock cycle, pushing new bits in from the right
3. We'll compare the shift register contents with the target pattern (1101) in parallel
4. When a match is found, we'll set a latch that keeps start_shifting high until reset
5. This approach eliminates state transitions and reduces control logic complexity
6. The synchronous reset clears both the shift register and the output latch
