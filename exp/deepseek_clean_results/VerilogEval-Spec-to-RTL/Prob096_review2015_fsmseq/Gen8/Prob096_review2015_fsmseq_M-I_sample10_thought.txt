To optimize the design for better PPA metrics while maintaining functionality, I propose the following improvements:

1. State Machine Optimization:
   - Replace shift register with a one-hot encoded FSM (5 states) to reduce logic depth
   - This simplifies the pattern matching logic to simple state transitions
   - Reduces critical path by eliminating the 4-bit comparison

2. Power Optimization:
   - Add state machine freeze when pattern is detected (start_shifting=1)
   - This prevents unnecessary state transitions after detection

3. Area Optimization:
   - One-hot encoding uses fewer gates than shift register comparison
   - Simplified output logic (direct state to output mapping)

4. Timing Improvement:
   - Reduced combinational logic depth between registers
   - State transitions depend only on current state and input bit

The improved design should achieve:
- Better timing (reduced negative slack)
- Lower power (reduced switching activity)
- Comparable or better area (simpler logic)
