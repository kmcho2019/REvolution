Simplified Approach: Minimal State Machine
1. Reduce the design to just 3 states (IDLE, S1, S11) tracking the progress of matching the sequence
2. Eliminate the shift register since we only need to track partial matches
3. State transitions directly check the input bit against expected values
4. When reaching the final match (1101), set a permanent flag until reset
5. Benefits:
   - Fewer registers (only 2 state bits instead of 4-bit shift register)
   - Simpler combinational logic
   - Clear state progression makes behavior obvious
   - Still handles overlapping sequences naturally
