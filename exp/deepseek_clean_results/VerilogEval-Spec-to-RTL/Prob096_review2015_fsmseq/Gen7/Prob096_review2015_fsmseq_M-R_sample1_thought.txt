Refactoring Strategy:
1. State Representation: Use binary encoding (3 bits) instead of one-hot to reduce area while maintaining functionality.
2. State Transitions: Implement the FSM using a single always block for both state transitions and output logic for better readability.
3. Output Logic: Make the output directly dependent on the current state.
4. Reset Handling: Keep synchronous reset behavior within the always block.
5. State Update: Combine next-state logic and state register updates in one always block for a more compact implementation.

Key Changes:
- Binary encoding reduces flip-flop usage
- Single always block for both state transitions and output
- Maintains same functionality with more compact code
- More traditional FSM implementation style
