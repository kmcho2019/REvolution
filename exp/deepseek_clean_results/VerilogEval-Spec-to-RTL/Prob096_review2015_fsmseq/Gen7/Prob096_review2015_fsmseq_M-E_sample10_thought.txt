Novel Approach: Binary Decision Tree with State Compression
1. Instead of tracking all possible states, implement a binary decision tree that tracks partial matches.
2. Use a 3-bit state register to encode the progress of matching:
   - 000: No match
   - 001: First '1' matched
   - 011: '11' matched
   - 110: '110' matched
3. The state transitions are determined by both current state and input bit.
4. When in state 110 and receiving '1', transition to a terminal state (111) that asserts start_shifting.
5. Benefits:
   - Reduced state encoding (3 bits instead of 4)
   - Explicit tracking of partial matches
   - Clear state transition logic
   - Easily verifiable state progression
