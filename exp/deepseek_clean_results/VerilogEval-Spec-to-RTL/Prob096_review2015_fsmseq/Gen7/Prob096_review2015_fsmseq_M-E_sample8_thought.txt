Here's a novel approach using a shift register combined with combinational matching logic:
1. Instead of a traditional FSM, use a 4-bit shift register to store the last 4 input bits
2. Compare the shift register contents directly with the target pattern (1101)
3. Use a found flag that gets set when the pattern matches and stays set until reset
4. The shift register automatically handles the sequence detection by maintaining a sliding window of input bits

This approach eliminates explicit state transitions and reduces the logic to simple shifting and pattern matching. The tradeoff is slightly more storage (4 bits vs 3 for states) but simpler control logic.
