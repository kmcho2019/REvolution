Simplified approach using minimal state tracking:
Instead of storing all 4 bits, we'll track just the necessary matching progress (how many consecutive correct bits we've seen). We'll use a 2-bit state register to track partial matches (0-3 correct bits). When we reach state 3 (meaning we've seen "110") and the next bit is '1', we set start_shifting. This reduces storage from 4 bits to 2 bits and simplifies comparison logic.
