Here's a novel approach using a shift register and pattern matching:
1. Instead of a traditional FSM, use a 4-bit shift register to store the last 4 input bits
2. Compare the shift register contents with the target pattern (1101) in parallel
3. Use a found flag that gets set when the pattern is detected and remains set until reset
4. This approach eliminates explicit state transitions and reduces the logic to a simple shift and compare operation

Advantages:
- More compact implementation (no explicit state machine)
- Easier to modify for different pattern lengths
- Parallel comparison reduces critical path
- Clear separation of data storage and pattern matching
