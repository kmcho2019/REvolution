Simplification Strategy:
1. State Reduction: Instead of using a 4-bit shift register, track just the necessary state to detect the sequence 1101.
2. Direct Comparison: Compare incoming bits directly with expected sequence values at each state.
3. Minimal State Machine: Implement a 4-state FSM where each state represents progress in matching the sequence.
4. Output Logic: Set output permanently once sequence is detected until reset.

Key Benefits:
- Eliminates shift register overhead
- Reduces comparison logic to simple state transitions
- Maintains same functionality with fewer resources
