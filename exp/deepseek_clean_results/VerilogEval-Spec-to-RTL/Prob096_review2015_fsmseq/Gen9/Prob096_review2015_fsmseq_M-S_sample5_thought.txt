To simplify the solution while maintaining functionality, I'll:
1. Use binary state encoding (2 bits) since we only need 4 active states (IDLE, GOT1, GOT11, GOT110) plus the FOUND state
2. Combine the state transition logic into a single always block
3. Make the output directly dependent on reaching the FOUND state
4. Remove unnecessary default case since all states are covered
5. Use simpler state names that reflect their purpose

This reduces the state encoding bits while keeping the same sequence detection behavior. The FOUND state remains sticky until reset.
