Novel Architecture Idea: State Machine with Lookahead
1. Instead of using a shift register, implement a Moore FSM with 5 states representing the progress of sequence detection
2. States: IDLE (0), GOT1 (1), GOT11 (2), GOT110 (3), DETECTED (4)
3. Add lookahead logic to check the next bit while in GOT110 state
4. State transitions occur on clock edges with synchronous reset
5. Output is high only in DETECTED state
6. Advantages:
   - No shift register needed, saving area
   - Clear state progression makes debugging easier
   - Lookahead enables early detection (can react in same cycle when last bit arrives)
   - Power efficient as no unnecessary shifting occurs
