Here's a simplified approach that maintains the same functionality with less complexity:
1. Use a single 4-bit shift register to track the last 4 bits
2. Directly compare the shift register contents to detect the sequence 1101
3. Use a single found flag that latches once the sequence is detected
4. The shift register stops updating once the sequence is found to save power
5. All logic is synchronous with reset handling

This reduces the number of intermediate wires and registers while keeping the same behavior. The sequence detection is now done directly on the shift register contents rather than partial comparisons.
