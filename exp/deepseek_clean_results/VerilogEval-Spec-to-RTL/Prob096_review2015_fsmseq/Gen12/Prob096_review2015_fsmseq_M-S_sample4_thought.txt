Here's a simplified approach that maintains the same functionality with less complexity:
1. Use a 3-bit shift register instead of 4-bit since we only need to track the last 3 bits (plus current input)
2. Combine the shift and compare operations in a single always block
3. The detection logic becomes a simple equality check against "110" in the shift register and '1' as current input
4. The found flag remains set until reset, same as before

This reduces the storage by 1 bit while keeping the same detection capability. The comparison logic remains simple but now operates on fewer bits.
