Novel Architecture Idea: State Machine with Early Termination
1. Instead of using a shift register, implement a Moore FSM with 5 states:
   - IDLE: Initial state
   - S1: First '1' detected
   - S2: Second '1' detected (after first '1')
   - S3: '0' detected (after '11')
   - FOUND: Final '1' detected (complete '1101' pattern)
2. The FSM transitions based on current state and input data
3. Key innovation: Each state represents progress in pattern matching
4. Output (start_shifting) is directly tied to FOUND state
5. Reset returns FSM to IDLE state
6. More power efficient than shift register approach as it only tracks progress rather than storing all bits
7. Potentially better timing as comparison logic is distributed across states
