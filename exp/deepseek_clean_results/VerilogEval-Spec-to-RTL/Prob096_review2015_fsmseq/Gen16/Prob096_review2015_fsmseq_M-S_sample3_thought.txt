Simplified Design Approach:
1. State Representation:
   - Use a 4-bit shift register to directly store the last 4 bits of input
   - This eliminates complex comparison logic by enabling direct pattern matching

2. Detection Logic:
   - Simply compare the shift register contents with the target pattern (4'b1101)
   - No need for parallel comparisons or intermediate state tracking

3. Output Control:
   - Latch the output high when pattern is detected
   - Maintain this state until reset

4. Simplifications:
   - Single always block for sequential logic
   - Direct pattern comparison reduces logic complexity
   - Fewer conditional statements than previous solution
   - Clear, straightforward implementation
