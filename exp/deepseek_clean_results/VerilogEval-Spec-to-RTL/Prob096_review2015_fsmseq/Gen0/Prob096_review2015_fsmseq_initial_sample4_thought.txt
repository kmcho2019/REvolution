To implement a sequence detector for "1101", we'll use a Moore finite state machine (FSM) with 5 states:
1. IDLE - initial state, no matching
2. S1 - first '1' detected
3. S2 - "11" detected
4. S3 - "110" detected
5. FOUND - "1101" detected (sets start_shifting permanently)

The FSM transitions between states based on the current state and input data. Once in FOUND state, it stays there until reset. The output start_shifting is only high in FOUND state.
