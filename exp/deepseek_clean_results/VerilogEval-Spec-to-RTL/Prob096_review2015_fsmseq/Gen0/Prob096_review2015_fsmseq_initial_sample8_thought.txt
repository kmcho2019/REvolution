To implement a sequence detector for "1101", we'll use a Moore FSM with 5 states:
1. IDLE - waiting for first '1'
2. GOT1 - received first '1'
3. GOT11 - received "11"
4. GOT110 - received "110"
5. FOUND - received "1101" (output start_shifting goes high)

The FSM transitions between states based on the input data bit. When in FOUND state, it stays there until reset. All state transitions happen on positive clock edges with synchronous reset.
