To implement a sequence detector for "1101", we need a finite state machine (FSM) with 5 states:
1. IDLE - initial state, waiting for first '1'
2. GOT1 - received first '1'
3. GOT11 - received "11"
4. GOT110 - received "110"
5. FOUND - received "1101"

The FSM transitions between these states based on the input data bit. When in FOUND state, start_shifting remains high until reset. All transitions occur on positive clock edges with synchronous reset.
