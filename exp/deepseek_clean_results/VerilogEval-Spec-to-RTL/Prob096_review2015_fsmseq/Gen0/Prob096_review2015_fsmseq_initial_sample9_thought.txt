To implement a sequence detector for "1101", we need a finite state machine (FSM) with 5 states:
1. IDLE - waiting for first '1'
2. GOT1 - received first '1'
3. GOT11 - received "11"
4. GOT110 - received "110"
5. FOUND - sequence "1101" detected

The FSM transitions between states based on the input data bit. When in FOUND state, start_shifting remains high until reset. All transitions happen on positive clock edges with synchronous reset.
