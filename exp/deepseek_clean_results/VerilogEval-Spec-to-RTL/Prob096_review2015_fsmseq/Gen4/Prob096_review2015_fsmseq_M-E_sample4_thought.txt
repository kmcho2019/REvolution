Instead of using a traditional FSM, we can implement a shift register that stores the last 4 bits of input data. The sequence detection is then performed by comparing the shift register contents with the target pattern "1101" in parallel. This approach:
1. Uses a 4-bit shift register to track recent inputs
2. Compares the register value with the target pattern (4'b1101) each cycle
3. Sets a latch when the pattern is found, which remains set until reset
4. Eliminates explicit state transitions, reducing control logic
