Instead of using a traditional FSM, I'll implement a shift register that stores the last 4 bits of input data. The pattern matching becomes simple combinatorial logic that checks when the register contains "1101". This approach:
1. Uses a 4-bit shift register to track recent inputs
2. Compares the register contents to the target pattern
3. Sets a latch when the pattern is found
4. The latch remains set until reset
This eliminates state transitions after detection and simplifies the pattern matching logic. The shift register approach is more scalable for longer patterns and easier to modify for different sequences.
