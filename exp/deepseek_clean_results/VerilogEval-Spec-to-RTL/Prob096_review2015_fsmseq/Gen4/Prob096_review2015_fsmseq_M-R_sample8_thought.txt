I'll refactor the solution using a one-hot encoded state machine with continuous assignments (assign statements) instead of procedural blocks. The key changes are:
1. Use one-hot encoding for states (5 bits for 5 states)
2. Replace procedural next-state logic with continuous assignments
3. Use a single always block for state registers
4. Make output assignment continuous

Benefits:
- One-hot encoding simplifies state decoding (each state is a single bit)
- Continuous assignments make the logic more explicit
- Potentially better timing as each state has its own dedicated logic
- Maintains same functionality while being more readable
