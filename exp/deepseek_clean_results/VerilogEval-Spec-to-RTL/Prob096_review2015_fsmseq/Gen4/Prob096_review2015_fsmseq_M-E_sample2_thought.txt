Instead of a traditional FSM, we can use a 4-bit shift register to store the last 4 input bits. The sequence detection becomes a simple pattern match against the shift register contents. This approach:
1. Uses a shift register to maintain history
2. Compares the register contents with target pattern (4'b1101)
3. Sets start_shifting when pattern is found and holds it until reset
4. Eliminates explicit state transitions while achieving same functionality
This method trades FSM complexity for simpler shift-and-compare logic.
