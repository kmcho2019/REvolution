Instead of using a traditional FSM, I'll implement a shift register that stores the last 4 bits of input data. The solution will:
1. Use a 4-bit shift register to track the most recent input bits
2. Compare the register contents with the target pattern (1101) each cycle
3. Set a latch when the pattern is detected
4. The latch remains set until reset
5. This approach eliminates explicit state transitions and reduces control logic

Benefits:
- Simpler implementation with fewer states (just a register and comparator)
- Easily modifiable for different pattern lengths
- Clear separation of data storage and pattern matching
- Lower power since only the shift register toggles regularly
