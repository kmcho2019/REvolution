Here's a novel approach using a shift register implementation instead of traditional state encoding:
1. Represent the state machine using a 2-bit shift register where only one bit is active at a time
2. The left bit represents state A (01), right bit represents state B (10)
3. State transitions are implemented by shifting the active bit left or right based on input
4. Reset initializes to state B (10)
5. Output is simply the MSB of the shift register

Benefits:
- Eliminates combinational logic for state transitions (just shifting)
- Potentially better timing as shifts are simpler than arbitrary logic
- Still maintains clear state representation
- Output is directly tapped from register with no additional logic
