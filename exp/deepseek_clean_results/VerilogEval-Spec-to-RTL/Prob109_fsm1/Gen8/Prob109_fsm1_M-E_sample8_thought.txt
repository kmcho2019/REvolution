Instead of using a traditional state register, we can implement this Moore machine using:
1. A toggle flip-flop concept where the state toggles only under specific conditions
2. The output is simply the state bit itself
3. The state toggles when:
   - Current state is A and input is 0 (A→B)
   - Current state is B and input is 1 (B→A)
4. Asynchronous reset forces the state to B
This approach eliminates the need for a case statement and uses direct combinatorial logic for state transitions.
