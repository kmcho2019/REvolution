I'll implement a novel "dual-register" state machine approach that:
1. Uses two registers to represent the current and next state simultaneously
2. Eliminates combinational next-state logic by computing transitions in parallel
3. Implements state transitions through register swapping
4. Maintains asynchronous reset capability
5. Reduces critical path by removing combinational logic between state registers

Key advantages:
- Parallel state transition evaluation
- No combinational path between state registers
- Single-cycle state updates without timing dependencies
- Output remains purely combinational based on state
