Here's a novel approach using a binary counter to represent the state machine:
1. Instead of traditional state encoding, we'll use a 1-bit counter where:
   - Count = 0 represents state A
   - Count = 1 represents state B
2. The counter will increment/decrement based on state transitions:
   - From A (0): 0→1 when input=0, stays 0 when input=1
   - From B (1): stays 1 when input=1, 1→0 when input=0
3. Asynchronous reset sets counter to 1 (state B)
4. Output is simply the counter value (1 for B, 0 for A)
This approach leverages arithmetic operations for state transitions rather than pure logic, which might yield better PPA in some technologies.
