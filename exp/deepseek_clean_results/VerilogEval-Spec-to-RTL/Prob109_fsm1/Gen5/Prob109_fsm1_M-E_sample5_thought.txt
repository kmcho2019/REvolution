Here's a novel approach using a shift register implementation for the Moore machine:
1. Instead of traditional state encoding, represent states as patterns in a 2-bit shift register
2. State B is represented as '11' and state A as '00'
3. The shift register naturally handles state transitions by shifting in new bits
4. Asynchronous reset initializes to '11' (state B)
5. Output is simply the MSB of the shift register

Key advantages:
- Eliminates explicit state comparison logic
- Transitions become simple shift operations
- Output is directly tapped from the register
- Still maintains clear Moore machine behavior
