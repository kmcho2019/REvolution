Simplification strategy:
1. Recognize that the state transition logic can be expressed more simply as state <= in when in current state A (0), and state <= state when in current state B (1)
2. This reduces the logic to a simple mux operation instead of XOR
3. Maintain the same state encoding (0=A, 1=B) and asynchronous reset to B
4. Output remains directly tied to state bit (Moore machine)
5. This simplification reduces logic complexity while maintaining identical functionality
