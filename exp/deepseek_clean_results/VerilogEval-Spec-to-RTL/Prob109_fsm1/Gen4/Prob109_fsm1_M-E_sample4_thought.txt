Novel architectural approach using a T flip-flop with enable:
1. Use a T flip-flop as the state storage element where:
   - Toggle occurs when state should change (input pattern matches transition condition)
   - Enable signal prevents unnecessary toggles
2. Implement enable logic that combines current state and input to determine when to toggle
3. Directly map state to output (Moore machine)
4. Asynchronous reset initializes to state B (1)
5. Advantages:
   - Potentially lower power since flip-flop only toggles when needed
   - Simple combinational logic for enable generation
   - Clear correspondence between state transitions and hardware behavior
