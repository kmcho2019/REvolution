Refactoring idea:
1. Replace the sequential always block with continuous assignments for state transitions
2. Use a combinational always block to calculate next state
3. Separate the state register into its own always block
4. Maintain same functionality but with clearer separation of combinational and sequential logic
5. This approach makes the state machine structure more explicit and potentially easier to modify
