Alternative approach using a T-flipflop with enable:
1. Observe that the state toggles only when input is 0 (from state diagram)
2. Implement state as a T-flipflop where:
   - Toggle occurs when (current_state ^ in) is 1
   - Reset forces state to 1 (B state)
3. Output is simply the state bit (Moore output)
This eliminates the need for explicit state decoding and uses a more compact logic implementation.
