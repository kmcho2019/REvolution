Refactoring approach:
1. Replace the sequential always block with continuous assignments for state transitions
2. Use a combinational always block for state updates
3. Maintain the same Moore machine behavior and asynchronous reset
4. Separate the state transition logic from the state storage
5. Keep the direct state-to-output assignment for efficiency

Key changes:
- State transitions are now expressed as combinational logic
- State storage is handled by a separate always block
- Same functionality but different implementation style
- Still maintains optimal 1-bit state encoding
