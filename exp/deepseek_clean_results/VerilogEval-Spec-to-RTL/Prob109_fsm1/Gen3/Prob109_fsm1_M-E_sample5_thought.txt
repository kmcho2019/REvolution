Here's a novel approach using a toggle flip-flop with enable:
1. We'll use a single flip-flop to represent the state (0=A, 1=B)
2. The state transitions are implemented as a controlled toggle:
   - When in state A (0), toggle on input 0 (to state B)
   - When in state B (1), toggle on input 1 (to state A)
3. This creates an elegant symmetry in the state transition logic
4. The output is directly the state bit (Moore machine)
5. Asynchronous reset initializes to state B (1)
