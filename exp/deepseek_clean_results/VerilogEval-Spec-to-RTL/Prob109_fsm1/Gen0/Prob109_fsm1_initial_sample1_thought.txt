The problem requires implementing a Moore FSM with two states (A and B) where:
1. State B outputs 1 and transitions to A on input 0, stays on B on input 1
2. State A outputs 0 and transitions to B on input 0, stays on A on input 1
3. Asynchronous reset forces the FSM to state B

We'll use a single state register to represent the current state (0 for A, 1 for B) and implement the state transitions and output logic accordingly.
