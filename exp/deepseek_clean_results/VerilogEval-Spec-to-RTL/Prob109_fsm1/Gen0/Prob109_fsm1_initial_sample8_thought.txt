The problem requires implementing a Moore FSM with two states (A and B) where:
- State B outputs 1 and transitions to A on input 0, stays in B on input 1
- State A outputs 0 and transitions to B on input 0, stays in A on input 1
- Asynchronous reset forces the FSM to state B

We'll use a single state register to represent the current state (0 for A, 1 for B), with combinational logic for next state and output.
