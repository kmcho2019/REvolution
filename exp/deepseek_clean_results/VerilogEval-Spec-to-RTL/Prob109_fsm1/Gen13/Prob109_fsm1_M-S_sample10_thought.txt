To simplify the Moore machine implementation:
1. Remove the intermediate next_state wire since it's not necessary for this simple state machine
2. Directly compute the next state in the always block using simple logic expressions
3. Maintain the same state encoding (A=0, B=1) and output logic
4. Keep the asynchronous reset functionality
5. The state transitions can be expressed more concisely using XOR and AND operations

This reduces:
- One wire declaration
- One continuous assignment
- The complexity of nested ternary operators
While maintaining identical functionality
