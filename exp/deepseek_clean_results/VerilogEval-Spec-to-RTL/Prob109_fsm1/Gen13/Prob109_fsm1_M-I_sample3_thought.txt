2. Merge the output logic into the state register assignment to eliminate the separate combinational output path
3. Optimize the reset logic by removing redundant reset handling in the combinational path
4. Use a more compact state transition expression
5. Maintain the same Moore machine behavior with asynchronous reset to state B

- Reduced logic complexity by eliminating parameter definitions
- Single always block for both state transition and output

- More compact state transition logic
