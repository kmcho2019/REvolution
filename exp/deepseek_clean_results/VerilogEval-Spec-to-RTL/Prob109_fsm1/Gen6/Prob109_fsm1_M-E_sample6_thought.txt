Here's a novel approach using a one-hot encoding scheme with two flip-flops, even though we only have two states. This provides:
1. Explicit state representation that's more readable and maintainable
2. Potential for easier timing closure as each state has its own dedicated flip-flop
3. Clear separation between state transition logic and output logic
4. While using more registers than strictly necessary, this approach demonstrates an alternative design pattern that scales better for more complex FSMs
