Here's a novel approach using a shift register implementation:
1. Instead of explicit state encoding, use a 2-bit shift register where the MSB represents the current state
2. The shift register will rotate based on input conditions
3. Reset initializes the register to '11' (state B)
4. The output is simply the MSB of the register
5. This eliminates explicit state comparison logic and reduces combinational path

Key advantages:
- No explicit state variables or parameters needed
- Shift register naturally implements the state transitions
- Output is directly tapped from the register
- Potentially better timing due to simpler combinational logic
