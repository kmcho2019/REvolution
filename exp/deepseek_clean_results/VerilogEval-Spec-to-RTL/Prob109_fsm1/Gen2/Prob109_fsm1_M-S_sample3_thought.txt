The original solution is already quite minimal, but we can simplify it further by:
1. Eliminating the parameter definitions since we only have two states that can be represented by a single bit
2. Removing the case statement since the state transitions are simple enough to express with ternary operators
3. Maintaining the same asynchronous reset and Moore output behavior
4. Using the state bit directly as output since state B=1 is exactly the output we want
