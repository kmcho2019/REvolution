Instead of using a traditional state register, we can implement this FSM using a toggle flip-flop approach:
1. Use the input 'in' as a conditional toggle signal
2. The output will be the current state of the flip-flop
3. When reset, force the flip-flop to 1 (state B)
4. The state toggles only when input is 0 (from the state diagram)
5. This eliminates explicit state encoding and case statements
