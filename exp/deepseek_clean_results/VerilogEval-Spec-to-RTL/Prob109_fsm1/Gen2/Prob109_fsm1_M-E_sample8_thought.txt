Here's a novel approach using a shift register implementation:
1. Instead of explicit state variables, we'll use a 2-bit shift register to represent state transitions
2. The current state is encoded in the LSB of the shift register
3. The next state is determined by shifting in the appropriate bit based on current state and input
4. This approach leverages the inherent sequential nature of shift registers to implement the state machine
5. Asynchronous reset initializes the shift register to represent state B
