This solution introduces a parallel pattern matching approach with these key innovations:

1. Sliding Window Detector: Uses a 4-bit shift register that continuously checks for the 1101 pattern in parallel, eliminating the need for sequential pattern matching.

2. Explicit State Encoding: Uses one-hot encoding for states to make the FSM more readable and reduce glitches in output signals.

3. Dedicated Shift Counter: Implements a 2-bit counter with synchronous clear for precise 4-cycle shift control.

4. Output Pipeline: Registers outputs to ensure clean transitions and avoid glitches.

5. Early Pattern Clear: Clears the pattern register immediately after detection to prevent false re-triggering.

The architecture separates the pattern detection (combinational) from state control (sequential) for better timing and reliability.
