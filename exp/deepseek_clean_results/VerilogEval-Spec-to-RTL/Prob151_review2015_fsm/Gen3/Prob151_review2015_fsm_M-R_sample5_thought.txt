Here's a refactored version with these key changes:

1. Simplified State Encoding:
   - Use binary encoding instead of one-hot for more compact state representation
   - Eliminate the special COMPLETE state by merging it into COUNTING

2. Combinational Outputs:
   - Use continuous assignments (assign) for outputs instead of registered outputs
   - This makes the outputs immediately responsive to state changes

3. Streamlined Shift Counter:
   - Use a separate always block just for the shift counter
   - Clearer countdown logic with explicit terminal count check

4. Improved Pattern Detection:
   - Maintain the parallel detection but simplify the state transition logic
   - Remove the data_history register since we can track the pattern directly

The refactoring maintains the same core functionality but with cleaner code structure and more straightforward state transitions.
