The simplified FSM will:
1. Use minimal states (IDLE, SHIFT, COUNT, DONE)
2. Remove separate pattern register - detect 1101 directly in IDLE state
3. Use a simple counter for shift cycles
4. Make outputs directly dependent on current state
5. Clear state transitions with no redundant logic

Key improvements:
- Single always block for state and counter
- Direct output assignments based on state
- Minimal registers (only state and shift counter needed)
- Clear reset behavior
- Pattern detection happens in real-time without storing history
