Simplified Design Strategy:

1. Pattern Detection:
- Use a 4-bit shift register that only shifts when in IDLE state
- This ensures we only detect the pattern when actively searching
- Clear pattern register on reset and when leaving IDLE state

2. State Machine:
- Reduce to 4 essential states: IDLE, SHIFT, COUNT, DONE
- Transition to SHIFT only when exact pattern "1101" is detected
- Use a 2-bit counter for precise 4-cycle shift duration
- Move to COUNT after exactly 4 shifts
- Transition to DONE only when counting completes
- Return to IDLE on acknowledgment

3. Output Logic:
- Direct combinatorial assignments from current state
- shift_ena active only during SHIFT state
- counting active only during COUNT state
- done active only during DONE state

Key Simplifications:
- Pattern register only shifts when needed (in IDLE)
- Removed unnecessary intermediate registers
- Clear, minimal state transitions
- Outputs directly tied to states
