Novel architectural approach using a shift register with integrated pattern matching and state control:

1. **Integrated Pattern Matching**:
   - Combine pattern detection and state control into a single shift register
   - Use a 4-bit shift register that continuously monitors for 1101 pattern
   - Clear pattern register only when entering SHIFT state

2. **State Encoding**:
   - Use Gray coding for state transitions to minimize glitches
   - Implement 4 states: IDLE, SHIFT, COUNT, DONE

3. **Smart Shift Control**:
   - Automatically count 4 shifts using the pattern register's natural shifting
   - Eliminate separate shift counter by using pattern register bits as shift counter

4. **Output Generation**:
   - Derive outputs directly from state transitions
   - Use registered outputs for clean timing

Key innovations:
- Eliminates separate pattern matching logic
- Uses shift register for both pattern detection and shift counting
- Gray coding ensures smooth state transitions
- More compact implementation with fewer registers
