Fixed Design Strategy:

1. Pattern Detection:
- Maintain pattern register continuously, not just in IDLE state
- Only reset pattern register on actual reset
- Detect pattern at any time (not state-dependent)

2. Shift Counter:
- Count exactly 4 cycles (0 to 3) during SHIFT state
- Clear counter only on reset or when leaving SHIFT state

3. State Machine:
- Keep same states but fix transition conditions
- Move to SHIFT immediately when pattern detected
- Stay in SHIFT for exactly 4 cycles
- Transition to COUNT only after full shift

4. Output Logic:
- Make outputs combinatorial from current state
- Remove output registers to match expected timing
- Ensure outputs are asserted exactly when needed

Key Fixes:
- Continuous pattern detection
- Precise 4-cycle shift operation
- Immediate state transitions
- Correct combinatorial outputs
