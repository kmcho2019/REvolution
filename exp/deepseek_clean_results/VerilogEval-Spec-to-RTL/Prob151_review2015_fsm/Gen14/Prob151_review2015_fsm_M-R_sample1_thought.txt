Refactoring Strategy:

1. State Encoding:
- Switch from one-hot to binary encoding for simpler state management
- Use explicit state parameters for better readability

2. Pattern Detection:
- Move pattern detection to a separate always block
- Keep pattern register until shift is complete

3. Shift Control:
- Use a dedicated counter for shift cycles
- Make shift_ena purely state-based

4. Output Logic:
- Simplify output assignments using continuous assignments
- Make outputs directly dependent on current state

5. Reset Handling:
- Clear all registers synchronously
- Ensure proper initialization

Key Changes:
- Binary state encoding reduces complexity
- Clear separation of pattern detection and shift control
- Simplified output logic
- More straightforward state transitions
- Maintains same functionality but with cleaner structure
