Novel architectural idea: "Pattern-Activated Shift Counter FSM"

Key innovations:
1. Dual-purpose shift register: Combines pattern detection and duration capture
2. Explicit cycle counting: Uses a dedicated 2-bit counter for precise 4-cycle shift control
3. State encoding optimization: Minimizes states while maintaining clear sequencing
4. Output pipelining: Ensures outputs align perfectly with state transitions
5. Early pattern reset: Immediately resets pattern detection on any mismatch

Implementation approach:
- IDLE state: Searches for 1101 pattern, resets on mismatch
- SHIFT_DURATION state: Precisely counts 4 cycles for duration capture
- WAIT_COUNT state: Holds until counting completes
- NOTIFY state: Waits for acknowledgment
- All transitions are clock-synchronized with clear conditions
