Refactoring strategy:
1. Use one-hot encoding for states instead of binary for clearer state representation
2. Separate combinational and sequential logic blocks for better readability
3. Make pattern detection explicit with a dedicated comparator
4. Use a separate shift counter with clear terminal count condition
5. Implement outputs as direct state decodes for clarity

Key improvements:
- One-hot state encoding (4 bits) makes state transitions more explicit
- Combinational next-state logic separated from state register
- Pattern detection only occurs in IDLE state
- Shift counter clearly counts 4 cycles (0 to 3)
- Outputs directly derived from state bits
