Novel approach using a shift register for pattern detection and explicit state transitions:
1. Use a 4-bit shift register to directly detect the 1101 pattern
2. Implement a separate 3-bit counter for shift cycles (0-3) to ensure precise 4-cycle shift_ena
3. Add explicit state transition checks for all conditions
4. Use one-hot encoding for states to simplify output logic and improve timing
5. Implement Moore machine style outputs for clean state-dependent behavior

Key innovations:
- Direct pattern matching using full 4-bit register
- Explicit cycle counting with clear terminal condition
- One-hot state encoding for better timing and readability
- Separate pattern detection and shift counting logic
