The key improvements in this refactored version are:

1. Separate pattern detection from shift counting using distinct registers:
   - pattern_reg (4-bit) exclusively for detecting 1101 sequence
   - shift_counter (2-bit) to count exactly 4 shift cycles

2. Simplified state transitions with explicit conditions:
   - Move to SHIFT state only when full pattern is detected
   - Move to COUNT state after exactly 4 shifts (counter reaches 3)
   - Clear pattern register after detection to prevent false matches

3. Output logic remains combinational but with more precise conditions:
   - shift_ena active only during SHIFT state
   - counting active only during COUNT state
   - done active only during DONE state

4. Better reset handling that clears all control registers
