The key simplifications are:
1. Reduce to 4 clear states: IDLE (pattern detection), SHIFT (4-bit duration capture), COUNT (wait for timer), DONE (wait for ack)
2. Use a 3-bit shift register for pattern detection (stores last 3 bits + current data)
3. Simple counter for the 4-cycle shift period
4. Outputs directly tied to state (no complex logic)
5. Reset clears everything and returns to IDLE

The simplified version will:
- Use minimal states needed
- Efficient pattern detection with shift register
- Clear counter for shift period
- Direct output assignments
- Properly handle reset and state transitions
