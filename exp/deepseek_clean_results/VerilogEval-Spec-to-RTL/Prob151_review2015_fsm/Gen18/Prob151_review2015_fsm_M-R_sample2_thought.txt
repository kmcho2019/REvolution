Refactored design approach:

1. **State Machine Structure**:
   - Use explicit state encoding with meaningful names
   - Separate pattern detection from shift control
   - Add explicit shift counter for precise 4-cycle control

2. **Pattern Detection**:
   - Maintain 4-bit shift register only in IDLE state
   - Clear pattern register when leaving IDLE state

3. **Shift Control**:
   - Use dedicated 2-bit counter for 4-cycle shift
   - Clear counter when entering SHIFT state

4. **Output Logic**:
   - Keep outputs directly mapped to states
   - Add explicit output for pattern detection state

Key improvements:
- Clear separation of pattern detection and shift control
- Precise 4-cycle shift using dedicated counter
- Better state transition conditions
- Maintains same functionality but with more reliable timing
