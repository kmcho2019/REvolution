Novel Design Strategy:

1. Parallel Pattern Detection:
- Use a 4-bit shift register that continuously monitors incoming data
- Compare against target pattern in parallel rather than sequentially
- More efficient than sequential checking

2. State Duration Control:
- Use a separate cycle counter for each state's duration
- Explicitly track how long to stay in each state
- More precise timing control than nested counters

3. State Machine Optimization:
- Simplified state transitions with clear conditions
- Separate control for pattern detection and timing
- Early exit from SHIFT state if reset occurs

4. Output Management:
- Direct combinatorial outputs based on current state
- Clear separation between control and data path
- Minimized glitching potential
