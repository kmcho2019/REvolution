Novel Architecture Approach:

1. Parallel Pattern Detection:
- Use a 4-bit shift register that continuously tracks incoming data
- Implement pattern matching as a combinational check on the register
- This avoids state-dependent pattern detection issues

2. Explicit State Control:
- Use one-hot encoding for clearer state transitions
- Separate states for each phase (IDLE, SHIFT, COUNT, DONE)
- Explicit counter for shift cycles with clear termination condition

3. Synchronized Control Signals:
- Generate outputs directly from state bits
- Ensure outputs are only active in their designated states
- Strict synchronization with clock edges

4. Robust Reset Handling:
- Clear all registers and counters on reset
- Guarantee clean startup in IDLE state

Key Innovations:
- Continuous pattern detection independent of state
- Precise shift cycle counting using dedicated counter
- Clear state boundaries with one-hot encoding
- Fail-safe reset behavior
