Simplification Strategy:
1. State Encoding:
   - Replace one-hot with binary encoding (only 4 states needed)
   - Reduces register width from 4 bits to 2 bits

2. Counter Elimination:
   - Remove separate 2-bit counter
   - Use state duration for shift counting (SHIFT state lasts exactly 4 cycles)

3. Pattern Detection:
   - Keep 3-bit shift register (sufficient for 1101 detection)
   - Simplify pattern match logic by removing pipeline

4. Output Logic:
   - Directly derive outputs from state (no complex decoding needed)
   - Maintain same functionality with simpler implementation

Key Changes:
- Binary state encoding (00,01,10,11)
- No separate counter - implicit counting in SHIFT state
- Simplified pattern matching
- Reduced register usage
- Same interface and functionality
