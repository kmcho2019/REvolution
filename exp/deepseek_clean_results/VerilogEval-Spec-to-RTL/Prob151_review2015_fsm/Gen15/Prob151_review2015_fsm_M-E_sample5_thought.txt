Novel architectural approach using a shift register and counter-based state machine:

1. Dual-Purpose Shift Register:
- Use a 4-bit shift register that serves both for pattern detection and duration capture
- Continuously shifts data in all states except DONE
- Clears on reset and after successful pattern detection

2. Smart State Transition:
- IDLE state: Monitors shift register for 1101 pattern
- CAPTURE state: Activates for exactly 4 cycles to get duration bits
- COUNT state: Waits for done_counting signal
- NOTIFY state: Asserts done until ack is received

3. Cycle-Counting Mechanism:
- Use a 2-bit counter to precisely control the 4-cycle CAPTURE duration
- Counter starts at 0 when entering CAPTURE state
- Advances each cycle until reaching 3 (4 cycles total)

4. Output Generation:
- Direct mapping of outputs to state machine states
- shift_ena active only during CAPTURE
- counting active only during COUNT
- done active only during NOTIFY

Key advantages:
- More efficient use of hardware (shared shift register)
- Clear separation of pattern detection and duration capture
- Precise cycle counting for shift enable
- Clean state transitions with no overlap
