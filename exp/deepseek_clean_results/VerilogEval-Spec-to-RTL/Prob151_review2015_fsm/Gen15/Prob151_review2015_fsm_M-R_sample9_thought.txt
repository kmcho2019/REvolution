Refactoring strategy:
1. Replace the always block state machine with assign-based combinational logic for state transitions
2. Use a separate register for state and counter to make the design more modular
3. Simplify the pattern detection logic by breaking it into steps
4. Use a 2-bit counter instead of 3-bit since we only need to count to 4
5. Make the state transitions more explicit with clear conditions

Key improvements:
- Combinational next-state logic improves readability
- Reduced counter width saves area
- Explicit state transition conditions make the design more maintainable
- Separated state and counter logic for better modularity
