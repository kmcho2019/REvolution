Refactored design approach with improved structure:

1. **State Machine Restructuring**:
   - Use one-hot encoding for states (4 bits) instead of binary encoding
   - Separate combinational and sequential logic blocks for clarity
   - Explicit next-state logic in combinational block

2. **Pattern Detection Improvement**:
   - Only update pattern register in IDLE state
   - Clear pattern after successful detection (1101)
   - Ensure proper serial shifting of data into pattern

3. **Shift Counter Enhancement**:
   - Use separate combinational logic for shift counter
   - Clear counter when leaving SHIFT state
   - Maintain shift_ena for exactly 4 cycles (0-3 count)

4. **Output Generation**:
   - Generate outputs directly from state bits
   - Ensure outputs are only active in their respective states

Key improvements:
- Clear separation of combinational and sequential logic
- More explicit state transitions
- Better pattern detection timing
- Precise output control
