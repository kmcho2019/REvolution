Novel Architecture Idea:
1. Use a 4-bit shift register for pattern detection (1101) instead of counting bits
2. Implement a 2-bit shift counter using the same register for both pattern detection and shift counting
3. Combine SHIFT and COUNTING states into a single active state to reduce state transitions
4. Use edge detection on done_counting to minimize state machine complexity
5. Implement a "lazy reset" feature where the state machine only resets after acknowledgement

Key Innovations:
- Shift register enables simpler pattern matching (direct comparison)
- Shared counter reduces register usage
- Combined active states minimize transitions
- Edge detection simplifies waiting conditions
- Lazy reset reduces unnecessary state changes
