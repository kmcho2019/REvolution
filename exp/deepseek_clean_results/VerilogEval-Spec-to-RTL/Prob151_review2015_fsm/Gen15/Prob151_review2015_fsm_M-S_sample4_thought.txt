Simplified Design Strategy:

1. Pattern Detection:
- Use a 4-bit shift register to track incoming data
- Detect pattern "1101" continuously (not state-dependent)
- Reset pattern register only on system reset

2. State Machine:
- Reduce to 4 clear states: IDLE, SHIFT, COUNT, DONE
- Transition to SHIFT immediately when pattern detected
- Stay in SHIFT for exactly 4 cycles using a simple counter
- Move to COUNT after shifting, then to DONE when counting completes
- Return to IDLE on acknowledgment

3. Output Logic:
- Direct combinatorial assignments from current state
- No output registers for immediate response
- Clear mapping: SHIFT->shift_ena, COUNT->counting, DONE->done

Key Simplifications:
- Removed unnecessary intermediate registers
- Simplified state transitions with clear conditions
- Eliminated redundant logic while maintaining functionality
