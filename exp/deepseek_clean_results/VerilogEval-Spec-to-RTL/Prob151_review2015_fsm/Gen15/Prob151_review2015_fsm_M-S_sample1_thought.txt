Simplified design approach:
1. Use a 4-bit shift register for clear pattern detection (1101)
2. Eliminate separate counter by using state duration for shift cycles
3. Reduce states to only essential ones (IDLE, SHIFT, COUNT, DONE)
4. Directly derive outputs from current state
5. Clear reset behavior that initializes all state elements
6. Simplified pattern detection by checking full 4-bit pattern

Key improvements:
- Removed counter logic by using fixed state duration
- Clear 4-bit pattern matching
- Minimal state transitions
- Outputs directly tied to states
- More straightforward pattern detection
