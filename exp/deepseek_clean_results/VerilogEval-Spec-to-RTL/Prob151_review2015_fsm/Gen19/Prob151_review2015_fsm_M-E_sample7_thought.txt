Novel Design Idea:
1. Use a hierarchical FSM approach with two layers: pattern detection and timer control
2. Implement pattern detection using a sliding window technique with a 4-bit shift register
3. Use a separate counter for the 4-bit duration capture phase
4. Introduce explicit state variables for each operational phase
5. Implement output generation with minimal combinatorial logic for better timing

Key Innovations:
- Hierarchical state machine improves modularity
- Sliding window pattern detection ensures continuous monitoring
- Explicit phase counters provide precise timing control
- Outputs are directly derived from state variables for clarity
- Reset behavior strictly follows specifications
