Refactoring strategy:
1. Use one-hot encoding for the state machine to simplify state transition logic
2. Separate the pattern detection logic into a dedicated shift register
3. Use continuous assignments for outputs to reduce sequential logic
4. Make state transitions more explicit with dedicated next_state logic
5. Simplify counter logic by using a dedicated 2-bit shift counter

Key improvements:
- One-hot encoding makes state transitions simpler and more readable
- Separate pattern register improves modularity
- Continuous assignments for outputs reduce sequential complexity
- Explicit next_state logic makes the design more maintainable
- Reduced counter width to exactly what's needed (2 bits)
