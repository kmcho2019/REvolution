1. Pattern Detection: Use a 4-bit shift register to continuously monitor for the "1101" pattern. Only transition to SHIFT state when the exact pattern is detected.

2. Shift Control: Implement a 2-bit counter to precisely control the 4-cycle shift period. The counter starts at 0 and counts up to 3, ensuring exactly 4 cycles of shift_ena.

3. State Machine: Use a 4-state machine with clear transitions:
   - IDLE: Wait for pattern
   - SHIFT: Enable shifting for 4 cycles
   - COUNT: Wait for counter completion
   - DONE: Signal completion and wait for ack

4. Output Logic: Make outputs purely combinational functions of the current state for clarity.

5. Reset Handling: Clear all registers on reset and ensure clean startup.

- Precise pattern matching

- Clear state transitions
