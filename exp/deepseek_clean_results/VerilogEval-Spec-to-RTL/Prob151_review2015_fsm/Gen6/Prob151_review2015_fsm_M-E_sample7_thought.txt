Here's a novel approach using a shift register with parallel pattern matching and a dedicated timer control FSM:

1. Use a 4-bit shift register that continuously shifts in data, allowing pattern detection at any time without state dependencies
2. Implement pattern matching with combinatorial logic comparing the shift register to 1101
3. Use a separate 2-bit counter to track the 4 shift cycles after pattern detection
4. The FSM has only 4 states (IDLE, SHIFT, COUNT, DONE) with clear transitions
5. Outputs are directly driven by state and counter values
6. Reset synchronously initializes everything and clears the shift register

Key innovations:
- Continuous pattern detection independent of FSM state
- Explicit shift cycle counter ensures exactly 4 shift_ena pulses
- Minimal state transitions with clear conditions
- All registers updated synchronously on clock edges
- Output logic is purely combinatorial
