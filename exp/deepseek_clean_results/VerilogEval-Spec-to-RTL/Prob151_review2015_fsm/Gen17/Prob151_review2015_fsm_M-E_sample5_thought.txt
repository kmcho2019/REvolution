Novel architectural idea:
1. Use a sliding window approach with a 4-bit register for pattern detection (1101)
2. Implement a hierarchical state machine with sub-states for precise control
3. Use a dedicated shift counter with early termination detection
4. Add output registers for clean signal transitions
5. Implement a watchdog timer to handle unexpected states

Key innovations:
- Sliding window pattern detection (more robust than shift register)
- Hierarchical states for better timing control
- Registered outputs for glitch-free operation
- Watchdog feature for reliability
- Explicit state encoding for readability
