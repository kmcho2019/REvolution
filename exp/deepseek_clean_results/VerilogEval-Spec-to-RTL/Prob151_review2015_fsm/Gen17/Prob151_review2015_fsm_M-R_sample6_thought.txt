   - Separate pattern detection from state transitions
   - Add explicit shift counter for precise 4-cycle shift_ena control

2. **Output Generation**:
   - Move to continuous assignments for outputs (assign statements)
   - Derive outputs directly from current state for clarity

3. **Pattern Detection**:
   - Maintain separate 4-bit shift register for pattern matching
   - Clear pattern register only when necessary (not in SHIFT state)

4. **Shift Counting**:

- Clear separation between pattern detection and state control
