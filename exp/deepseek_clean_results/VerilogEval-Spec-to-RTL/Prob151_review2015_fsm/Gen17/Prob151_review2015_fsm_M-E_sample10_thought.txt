Novel Architecture Idea:
1. Use a 4-bit shift register for pattern detection (1101) which eliminates the need for separate pattern matching logic
2. Implement a Moore FSM with one-hot encoding for simpler state transitions and better timing
3. Combine the shift counter functionality into the state machine itself by using state duration
4. Use a "delayed done" state to ensure proper handshaking with minimal logic
5. Optimize for power by gating the shift register when not in pattern detection mode

Key Advantages:
- Shift register approach simplifies pattern matching logic
- One-hot encoding improves timing and reduces decoding logic
- State duration counting eliminates separate counter
- Better handshaking with delayed done state
- Power-efficient design through conditional activation
