The design requires a finite state machine (FSM) with the following states:
1. IDLE: Waiting for the 1101 pattern
2. SHIFT: Shifting in 4 bits for duration (assert shift_ena)
3. COUNT: Waiting for counters to finish (assert counting)
4. DONE: Timer finished (assert done), waiting for ack

The FSM transitions:
- IDLE -> SHIFT when 1101 pattern detected
- SHIFT -> COUNT after 4 cycles
- COUNT -> DONE when done_counting is high
- DONE -> IDLE when ack is high
- Any state -> IDLE when reset is high
