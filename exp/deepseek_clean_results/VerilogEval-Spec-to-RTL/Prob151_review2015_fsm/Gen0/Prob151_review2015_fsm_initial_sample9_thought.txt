To implement the finite-state machine (FSM) for the timer controller, we need to design a state machine with the following states:
1. IDLE: Waits for the pattern 1101 to be detected
2. SHIFT: After pattern detection, enables shifting for 4 cycles
3. COUNT: Waits for the counters to finish (done_counting)
4. DONE: Notifies user and waits for acknowledgment (ack)

The FSM transitions between these states based on the current state and inputs. The outputs (shift_ena, counting, done) are generated based on the current state.
