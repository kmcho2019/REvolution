The problem requires implementing a finite state machine (FSM) that controls a timer based on specific input patterns and conditions. The FSM will have the following states:
1. IDLE: Waiting for the start pattern (1101)
2. SHIFT: After detecting the pattern, enable shifting for 4 cycles
3. COUNT: Wait for the counter to finish (done_counting)
4. DONE: Notify user and wait for acknowledgment (ack)

The FSM transitions between these states based on input conditions and maintains the required outputs in each state. The reset signal initializes the FSM to the IDLE state.
