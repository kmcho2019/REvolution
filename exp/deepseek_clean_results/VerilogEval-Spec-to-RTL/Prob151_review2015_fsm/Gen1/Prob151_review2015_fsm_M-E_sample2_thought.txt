Here's a novel approach using a shift register and counter-based state machine with the following key features:
1. Pattern detection uses a 4-bit shift register that continuously monitors incoming data
2. A separate 2-bit counter controls the 4-cycle shift enable period
3. Explicit state encoding with one-hot encoding for clearer state transitions
4. Outputs are registered to ensure clean glitch-free signals
5. The counting phase begins immediately after the 4-bit shift period ends

The state machine has these states:
- IDLE: Waiting for 1101 pattern
- SHIFT: Shifting in 4 duration bits
- COUNT: Waiting for counter completion
- NOTIFY: Asserting done until ack received
