Refactoring strategy:
1. Convert the state machine to a one-hot encoding for clearer state representation
2. Move all sequential logic to a single always block for better readability
3. Use explicit pattern matching with a shift register that resets when leaving IDLE state
4. Implement shift counter as a separate register with clear reset conditions
5. Make all outputs purely combinational based on current state
6. Simplify state transitions by removing unnecessary intermediate variables

Key improvements:
- One-hot encoding makes state transitions more explicit
- Single always block reduces potential for timing mismatches
- Clear pattern register management
- Explicit shift counter handling
- Maintains same functionality but with cleaner structure
