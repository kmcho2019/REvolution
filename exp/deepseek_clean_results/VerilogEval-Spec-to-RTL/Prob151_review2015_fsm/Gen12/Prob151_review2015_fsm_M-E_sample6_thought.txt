Novel Approach: Pattern Detection with Lookahead

Instead of using a traditional shift register for pattern detection, we'll implement a lookahead approach that detects the 1101 pattern immediately as the last bit arrives. This eliminates the 1-cycle detection delay. 

Key innovations:
1. Immediate pattern detection by checking current and previous 3 bits in parallel
2. State machine with explicit WAIT state after pattern detection to ensure clean transition
3. Precise shift counter using a down-counter for clearer cycle counting
4. Output generation directly tied to state transitions for better timing

The state machine now has:
- IDLE: Waits for pattern
- WAIT: Single-cycle buffer after pattern detection
- SHIFT: Active for exactly 4 cycles
- COUNT: Waits for done_counting
- DONE: Waits for ack

This architecture ensures:
- Zero-cycle pattern detection latency
- Precise 4-cycle shift enable
- Clean handshaking between states
- Clear output assertions
