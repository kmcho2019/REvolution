Revised design addressing all feedback points:

1. Clear Separation of Pattern Detection and Duration Shifting:
- Maintain two separate shift registers: one for pattern detection (4 bits) and one for duration (4 bits)
- Only transition to SHIFT state after full 1101 pattern is detected in IDLE state

2. Precise Shift Counting:
- Use a 2-bit counter (shift_cnt) to track exactly 4 shift cycles
- Clear counter when entering SHIFT state and increment each cycle
- Only transition to COUNT state after exactly 4 shifts (shift_cnt == 3)

3. Correct State Sequencing:
- IDLE: Detect 1101 pattern before any shifting
- SHIFT: Shift exactly 4 duration bits
- COUNT: Wait for done_counting signal
- DONE: Wait for ack before returning to IDLE

4. Proper Output Timing:
- shift_ena active only during SHIFT state
- counting active only during COUNT state
- done active only during DONE state

5. Reset Handling:
- Clear all registers and return to IDLE state on reset
- Ensure clean transitions between states
