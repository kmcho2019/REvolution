The current implementation is already quite optimized, but we can make a few minor improvements:

1. Remove the explicit 1'b0 assignments for unused bits (out_both[3] and out_any[0]) since Verilog will automatically zero-extend if needed, making the code slightly more concise.

2. For out_different, we can use a more explicit circular shift approach that might be slightly more readable while maintaining the same efficiency.

3. Combine all output assignments into a single block for better code organization.

These changes maintain the same functionality while potentially improving readability and maintainability with no impact on PPA metrics since the underlying logic remains identical.
