Novel Architecture Idea: Bit-Serial Processing with Shift Register

Instead of processing all bits in parallel, we can use a serial approach with a shift register to:
1. Process bits sequentially to reduce area
2. Reuse logic operations across bits
3. Implement wrap-around naturally using shift register feedback
4. Use a simple FSM to control the processing sequence

Key Features:
- 4-cycle sequential processing using a shift register
- Single shared AND/OR/XOR logic block
- Natural wrap-around via shift register feedback
- Reduced area through logic reuse
- Explicit cycle counter for control

Trade-offs:
- Slower than parallel implementation (4 cycles vs 1)
- Requires a clock signal (added as input)
- But significantly reduces area and power
