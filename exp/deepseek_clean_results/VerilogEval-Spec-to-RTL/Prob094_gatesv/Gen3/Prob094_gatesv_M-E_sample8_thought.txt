Instead of handling each bit position individually, we can use vector operations and shifts to implement the neighbor relationships more elegantly:

1. For out_both: Shift the input left by 1 (discarding MSB) and AND with original input. This automatically creates the AND pairs we need.

2. For out_any: Shift the input right by 1 (discarding LSB) and OR with original input. This creates the OR pairs we need.

3. For out_different: Create a circular left shift of the input and XOR with original. This handles the wrap-around requirement naturally.

This approach is more scalable (works for any bus width with minimal changes) and uses fewer explicit bit assignments.
