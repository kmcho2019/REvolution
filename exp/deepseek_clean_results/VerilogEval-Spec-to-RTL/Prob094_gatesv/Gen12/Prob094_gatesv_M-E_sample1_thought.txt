Instead of treating each output calculation separately, I'll implement a unified processing approach that:
1. Uses a circular shift register to create neighbor relationships
2. Processes all three conditions in parallel using this shifted data

- Single unified processing block handles all three output conditions

- Explicit handling of edge cases through masking
- Optimized for both area and power by minimizing logic duplication
