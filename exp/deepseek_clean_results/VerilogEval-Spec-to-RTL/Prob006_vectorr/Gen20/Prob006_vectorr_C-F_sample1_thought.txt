Fusion Strategy:
1. Prioritize simplicity and direct bit assignments for the 8-bit case (from Example 1) as it provides the cleanest and most efficient implementation
2. Maintain parameterization capability (from Example 2) but only as a fallback for non-8-bit cases
3. Use a single combinational always block for consistent coding style
4. Remove unnecessary complexity (conditional compilation, initial blocks) while keeping core functionality
5. Keep the hierarchical TopModule wrapper for interface consistency
6. Optimize for both readability and synthesis efficiency by using the most straightforward approach for the 8-bit case

Key features:
- Direct bit assignments for 8-bit case (optimal for PPA)
- Parameterized for-loop fallback for other widths
- Pure combinational logic
- Clean and minimal implementation
- No simulation-only constructs
