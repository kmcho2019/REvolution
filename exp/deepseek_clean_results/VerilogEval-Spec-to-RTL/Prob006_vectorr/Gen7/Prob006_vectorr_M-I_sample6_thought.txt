The current implementation is already optimal for PPA metrics, but we can make it more maintainable and scalable by using a generate loop. This approach:
1. Maintains the same excellent timing characteristics (wns/tns = 0)
2. Keeps the same minimal power consumption
3. Preserves the small area footprint
4. Makes the code more readable and adaptable to different bit widths
5. Uses a for-loop that will unroll during synthesis to produce identical hardware
