Refactoring approach:
1. Replace individual DFF instantiations with a single always block using a vector register
2. Use a 4-bit shift register vector instead of separate wires
3. Maintain the same synchronous active-low reset functionality
4. Output the last bit of the shift register directly
5. Benefits:
   - More compact code with fewer lines
   - Easier to parameterize if we want to change the shift register length
   - Still maintains the same timing characteristics since it's the same underlying structure
   - More readable as the shift operation is clearly visible in one block
