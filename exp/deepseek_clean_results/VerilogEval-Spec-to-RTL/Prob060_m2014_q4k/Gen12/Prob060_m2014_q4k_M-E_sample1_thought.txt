Novel approach using a circular shift register with parallel load capability:
1. Implement a 4-bit circular shift register that can also parallel load
2. Use a state machine to control operation modes (shift vs load)
3. Add an extra bit to track the 'head' position of the circular buffer
4. Output is always the oldest bit in the buffer
5. Benefits:
   - More flexible than simple linear shift register
   - Can be extended to support additional features
   - Maintains same functionality as required
   - Interesting alternative architecture
6. Reset initializes all bits and sets head position to 0
