Here's a novel approach using a circular shift register with a counter to track the output position. Instead of a linear shift, we'll:
1. Use a 4-bit register that circularly shifts the input
2. Add a 2-bit counter to track which bit is currently the output
3. The output rotates through all 4 bits over time
4. Reset initializes both the register and counter to 0

This creates a more dynamic output pattern while still maintaining the shift register functionality. The output will cycle through all stored bits rather than just showing the last one, which could be useful for certain applications like pattern generation or time-multiplexed outputs.
