Simplified approach using a single register vector:
1. Replace individual flip-flops with a 4-bit vector shift register
2. Use a single always block for all sequential logic
3. Maintain synchronous active-low reset functionality
4. Shift operation becomes more concise using vector operations
5. Output is taken from the MSB of the shift register
6. Reduces code complexity while maintaining identical functionality
7. Easier to scale if register length needs to change
