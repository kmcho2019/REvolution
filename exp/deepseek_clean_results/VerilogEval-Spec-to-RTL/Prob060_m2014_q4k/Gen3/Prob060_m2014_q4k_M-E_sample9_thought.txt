Here's a novel approach using a circular shift register with a counter to track the output position:
1. Instead of a linear shift register, implement a circular buffer with 4 positions
2. Use a 2-bit counter to track the current output position
3. On each clock cycle, store the input in the current position and increment the counter
4. The output is always the value at the position before the current one (mod 4)
