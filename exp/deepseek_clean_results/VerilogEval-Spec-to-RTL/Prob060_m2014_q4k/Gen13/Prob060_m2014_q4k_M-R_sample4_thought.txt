Refactoring approach:
1. Use a single always block with a 4-bit vector to represent the shift register
2. Implement the shift operation using concatenation for more compact code
3. Maintain synchronous active-low reset functionality
4. Assign the output to the MSB of the shift register
5. This approach reduces the number of lines while maintaining the same functionality
6. The vectorized implementation may be more readable and easier to modify for different register lengths
