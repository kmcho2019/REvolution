To implement a 4-bit shift register with synchronous active-low reset, we'll need:
1. Four D flip-flops connected in series
2. Synchronous reset functionality (when resetn is low)
3. Each flip-flop should capture its input on the positive clock edge
4. The input 'in' feeds the first flip-flop, and each subsequent flip-flop takes input from the previous one
5. The output 'out' comes from the last flip-flop in the chain
