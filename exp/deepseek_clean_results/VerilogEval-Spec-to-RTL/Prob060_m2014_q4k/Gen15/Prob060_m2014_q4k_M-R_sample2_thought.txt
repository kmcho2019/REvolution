Refactoring approach:
1. Instead of using separate DFF modules, implement the shift register using a single always block with a vector register
2. This reduces module instantiation overhead and makes the code more compact
3. Maintain the same synchronous active-low reset functionality
4. Use a 4-bit vector to store the shift register state, making the shift operation more explicit
5. The output is simply the last bit of the shift register vector
6. This approach should maintain the same PPA characteristics while being more concise
