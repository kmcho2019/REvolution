Instead of a traditional linear shift register, I'll implement a circular buffer approach with a position counter. This offers:
1. Reduced switching activity (power savings) since bits aren't physically shifted
2. Same functionality but with different physical implementation
3. Potential area savings in some technologies due to simpler routing
4. Interesting trade-off between counter logic and shift logic
5. Maintains the same synchronous reset behavior

The design uses a 4-bit storage register and a 2-bit counter to track the "head" position. The output is selected via a multiplexer based on the counter value. This approach minimizes physical bit shifts while maintaining the same logical behavior.
