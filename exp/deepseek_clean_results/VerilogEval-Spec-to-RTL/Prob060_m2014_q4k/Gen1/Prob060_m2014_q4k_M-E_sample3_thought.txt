Instead of a traditional linear shift register, implement a circular shift register with parallel load capability:
1. Use a 4-bit register that can operate in two modes:
   - Shift mode: Circular right shift (out feeds back to in)
   - Load mode: Parallel load from input 'in' to all bits
2. Mode selection is controlled by the 'in' signal stability:
   - If 'in' changes, switch to load mode (capture new value)
   - If 'in' is stable, operate in shift mode
3. This provides both shift register functionality and the ability to quickly load new patterns
4. Reset still clears all bits synchronously
5. Output is taken from the LSB (creates different behavior than linear shift)
