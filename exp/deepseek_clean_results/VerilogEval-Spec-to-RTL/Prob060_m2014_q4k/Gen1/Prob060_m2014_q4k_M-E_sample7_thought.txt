Alternative approach using a circular shift register with load control:
1. Implement a 4-bit register with both shift and parallel load capabilities
2. Use a control signal to choose between shifting or loading all bits
3. In shift mode, it behaves as a standard shift register
4. In load mode, it can parallel load all bits (though not used in this interface)
5. The circular nature allows for potential future expansion to create rotating patterns
6. Maintains synchronous active-low reset functionality
7. Output is still taken from the last bit position
