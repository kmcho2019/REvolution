Instead of a traditional linear shift register, we can implement a circular buffer with:
1. A 4-bit register to store values
2. A 2-bit counter to track the current output position
3. On each clock cycle:
   - With reset: clear all bits and reset counter
   - Otherwise: 
     * Store input in current position
     * Increment counter (circularly)
4. Output is always the bit at the current counter position
This approach provides different timing characteristics and could be useful in certain applications where random access to the stored bits is needed.
