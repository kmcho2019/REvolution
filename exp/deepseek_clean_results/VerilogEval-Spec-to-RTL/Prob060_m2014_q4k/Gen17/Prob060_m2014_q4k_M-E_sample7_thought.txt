Novel approach: Circular Shift Register with Parallel Load Shadow
1. Implement a 4-bit circular shift register that can also parallel load
2. Use the 'in' signal as both serial input and load trigger
3. When 'in' is high for 4 consecutive cycles, it loads the shift register contents back into itself (circular)
4. Maintains same interface but adds hidden functionality
5. Benefits:
   - Same area as basic shift register (4 DFFs)
   - Adds parallel load capability without extra ports
   - Power efficient since no additional combinational logic
   - Interesting side effect: can detect and react to input patterns
6. Reset behavior remains identical to requirements
