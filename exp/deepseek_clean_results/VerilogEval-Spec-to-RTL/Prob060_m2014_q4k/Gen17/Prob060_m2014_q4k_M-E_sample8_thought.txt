Novel approach using a circular shift register with parallel load capability:
1. Implement a 4-bit circular shift register that can also parallel load
2. Use a control signal (load) to switch between shift and parallel load modes
3. When not in load mode, it behaves as a standard shift register
4. The parallel load feature allows for quick initialization of the register state
5. Maintain synchronous active-low reset functionality
6. This provides more flexibility than a simple shift register while maintaining similar PPA characteristics
