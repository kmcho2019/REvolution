Refactored approach using a single always block for all flip-flops:
1. Replace individual D flip-flop instantiations with a single always block
2. Use a 4-bit shift register implemented as a packed array
3. Maintain synchronous active-low reset behavior
4. Shift operation is done in one clock cycle for all stages
5. Output is taken from the most significant bit of the register
6. More compact representation while maintaining same functionality
7. Easier to scale to different shift register lengths
8. Potentially better for synthesis optimization
