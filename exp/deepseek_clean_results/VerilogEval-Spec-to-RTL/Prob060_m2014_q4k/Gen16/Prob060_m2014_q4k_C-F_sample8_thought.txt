Fusion Strategy:
1. Combine the explicit DFF instantiation approach from Example 1 with the vectorized register approach from Example 2
2. Maintain the simple shift register functionality without unused features (remove mode control)
3. Use a vectorized always block for compact implementation while keeping clear shift register structure
4. Preserve synchronous active-low reset behavior
5. Optimize for both readability and PPA:
   - Vectorized approach reduces routing overhead vs individual DFFs
   - Single always block is more area-efficient
   - Clear shift operation shows data flow
   - No unused logic to minimize power

The fused solution provides:
- Better timing than Example 2 by removing unnecessary mode logic
- More compact implementation than Example 1 while maintaining clarity
- Lower power than both by eliminating unused features
- Same area efficiency as both examples
