Novel approach: Implement a circular shift register with parallel load capability
1. Use a 4-bit register with both serial and parallel access
2. Implement a circular shift pattern where the output wraps around to the input
3. Add a control signal to choose between normal shift and circular shift modes
4. Maintain synchronous active-low reset functionality
5. Output the MSB of the register as the serial output
6. This approach provides more flexibility than a standard shift register while maintaining simplicity

Benefits:
- Enables both standard and circular shifting operations
- Potential for future expansion with parallel load
- Same area/power as basic implementation but more functionality
- Maintains clean synchronous design practices
