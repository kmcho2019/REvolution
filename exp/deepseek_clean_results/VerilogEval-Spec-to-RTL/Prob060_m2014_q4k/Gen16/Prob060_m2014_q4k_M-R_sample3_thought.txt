Refactoring approach:
1. Replace individual DFF instances with a single always block using a vector register
2. Maintain the same synchronous active-low reset functionality
3. Use a 4-bit shift register vector to simplify the implementation
4. Keep the same chaining behavior where input propagates through each flip-flop
5. Output remains the last bit of the shift register
6. Benefits:
   - More compact code with fewer lines
   - Easier to scale for larger shift registers
   - Clearer visualization of the shift register as a single entity
   - Maintains same timing characteristics since synthesis will infer same flops
