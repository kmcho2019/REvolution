Refactored approach using individual flip-flop instantiations:
1. Instead of using a single always block with a vector, implement each D flip-flop separately
2. This makes the design more modular and easier to understand for small shift registers
3. Maintain the same functionality with synchronous active-low reset
4. Directly connect each flip-flop's output to the next one's input
5. The output is still taken from the last flip-flop in the chain
6. This approach provides better visibility into each stage of the shift register
7. While slightly more verbose, it can be beneficial for debugging and formal verification
