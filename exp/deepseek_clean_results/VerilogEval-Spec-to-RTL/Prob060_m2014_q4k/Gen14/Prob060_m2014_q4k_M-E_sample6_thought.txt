Here's a novel approach using a circular shift register with enable logic:
1. Instead of a traditional linear shift register, implement a circular buffer that rotates bits
2. Add an enable signal that only shifts when new input differs from current output
3. This reduces power consumption by minimizing unnecessary toggles
4. Still maintains 4-bit storage and synchronous active-low reset
5. Output is taken from the MSB of the circular buffer
6. The design automatically stops shifting when input matches output, saving dynamic power
