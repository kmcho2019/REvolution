Here's a novel approach using a multiplexer-based design with priority encoding:
1. Instead of using if-else statements, implement the logic using a priority-encoded multiplexer
2. The priority is: Load (L) > Shift (E) > Hold
3. This approach may offer better synthesis optimization potential as it's more explicit about the priority
4. The design still maintains all required functionality while presenting a different structural implementation
5. The output is registered on the positive clock edge as required
