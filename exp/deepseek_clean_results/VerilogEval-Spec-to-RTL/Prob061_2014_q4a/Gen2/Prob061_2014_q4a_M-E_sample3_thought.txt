Here's a novel approach using a multiplexer-based design with explicit state retention:
1. Use a continuous assignment for the output Q to make it combinational
2. Implement the state storage in a separate always block
3. Use a 3-way multiplexer to select between:
   - Maintain current state (default)
   - Shift input (w) when E is high
   - Load input (R) when L is high
4. This separates the combinational logic from sequential elements, potentially improving synthesis optimization
