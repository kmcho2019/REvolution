Instead of using simple multiplexer logic, I'll implement this as a tiny state machine with explicit states for HOLD, SHIFT, and LOAD operations. This approach:

1. Uses a 2-bit state register to track the current operation mode
2. Explicitly decodes the control signals (E and L) into states
3. Makes the state transitions and output logic more visible in the code
4. Could potentially offer better power gating opportunities in larger designs
5. Provides a more structured approach that might be easier to extend with additional features
6. Still maintains the same functionality but with a different internal implementation

The states are:
- HOLD (00): Maintain current value
- SHIFT (01): Shift in value from previous stage
- LOAD (10): Load new value from R input
