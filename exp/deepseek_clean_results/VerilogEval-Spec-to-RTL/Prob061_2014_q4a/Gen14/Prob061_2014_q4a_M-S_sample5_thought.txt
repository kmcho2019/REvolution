The existing solution is already quite simple, but we can make it slightly more straightforward by:
1. Removing the intermediate wire declaration since it's only used once
2. Moving the mux logic directly into the always block
3. Maintaining the same priority (L > E > hold)
4. Keeping the positive edge-triggered flip-flop behavior
5. This eliminates one line of code while preserving identical functionality

The simplified version will have the same PPA characteristics as the original since synthesis tools will optimize both versions to the same hardware.
