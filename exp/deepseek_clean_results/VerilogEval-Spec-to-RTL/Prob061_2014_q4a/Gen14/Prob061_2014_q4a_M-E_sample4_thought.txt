Instead of using direct mux logic, I'll implement this as a tiny state machine with explicit state transitions. The key ideas are:
1. Treat the register as having two operational modes: SHIFT and LOAD
2. Use the control signals to determine the next mode
3. Implement mode-specific behavior for data selection
4. This approach makes the control flow more explicit and could be easier to extend with additional modes
5. The state encoding is trivial (just two states) but demonstrates a different architectural approach
