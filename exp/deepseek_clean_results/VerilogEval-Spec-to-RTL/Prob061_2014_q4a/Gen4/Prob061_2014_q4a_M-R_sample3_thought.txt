Refactoring Approach:
1. Replace the always block with continuous assignment for combinational logic
2. Use a separate register block for sequential elements
3. Split the logic into two parts:
   - Combinational next-state logic using assign
   - Sequential state update in always block
4. This makes the design more modular and explicit about what's combinational vs sequential
5. May help with timing by separating the mux logic from the register

Benefits:
- Clear separation of combinational and sequential logic
- Potentially better for synthesis tools to optimize
- More explicit about the design intent
- Maintains same functionality and priority (L > E > hold)
