To refactor this code while maintaining the same functionality, I'll implement it using continuous assignments (assign statements) instead of an always block. This approach:

1. Uses combinational logic with the register implemented separately
2. Clearly separates the combinational next-state logic from the sequential element
3. Maintains the same priority order (load > shift > hold)
4. Uses a wire for the next state value before it's registered
5. May offer better readability for some designers by making the mux logic explicit

The functionality remains identical - on each positive clock edge:
- If L is high, load R
- Else if E is high, shift in w
- Else maintain current state
