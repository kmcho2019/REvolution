I'll implement a novel approach using a hierarchical state machine that separates the control and data paths. The key innovations are:
1. Explicit state encoding for the three modes (hold, shift, load)
2. Separate next-state logic and output logic
3. Registered outputs for better timing closure
4. One-hot encoding for the state machine to optimize power and performance

This approach provides:
- Clear separation of concerns between control and data
- Better timing predictability due to registered outputs
- Potential for power optimization through state encoding
- Easier verification due to explicit state representation
