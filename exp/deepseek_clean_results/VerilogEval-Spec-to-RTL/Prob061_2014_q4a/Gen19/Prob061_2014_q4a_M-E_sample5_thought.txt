This solution implements the shift register stage as a simple state machine with explicit state transitions. The key differences from the conventional approach are:

1. Uses a state variable to explicitly track the operation mode (hold, shift, load)
2. Separates the control logic (state transitions) from data path
3. Makes the priority scheme more visible through state transitions
4. Benefits:
   - More explicit representation of the control flow
   - Easier to extend with additional states/operations
   - Clear separation of concerns
   - More maintainable for complex variations
5. Tradeoffs:
   - Slightly more verbose
   - Uses more registers (though synthesis may optimize)
   - May have marginally different timing characteristics

The state machine has three states corresponding to the three operations, with load having highest priority.
