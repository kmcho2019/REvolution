This solution introduces two key innovations:
1. A pre-computed multiplexer select signal that combines the L and E inputs in a way that minimizes switching activity
2. Explicit clock gating using the enable conditions to reduce dynamic power when the register doesn't need to update

The design:
- Creates a combined enable signal (do_update) that triggers only when needed
- Uses a 2:1 mux with priority encoded select (load has priority over shift)
- Implements clock gating when neither load nor shift is active
- Maintains the same functionality while potentially improving power efficiency
