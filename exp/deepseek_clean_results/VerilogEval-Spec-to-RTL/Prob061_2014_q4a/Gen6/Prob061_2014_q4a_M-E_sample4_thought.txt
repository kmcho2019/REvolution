Here's a novel approach using a state machine implementation with explicit state encoding. This design:

1. Uses a 2-bit state register to explicitly track the operation mode (IDLE, SHIFT, LOAD)
2. Implements next-state logic based on control inputs (E, L)
3. Separates control path and data path for better modularity
4. Provides potential for easier debugging with observable states
5. Could be extended with additional states for more complex operations

Benefits:
- More explicit control flow
- Easier to add new features or states
- Clear separation of concerns
- Better visibility into internal operation
- Potential for power optimization by clock gating in IDLE state
