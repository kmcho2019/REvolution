The TopModule needs to implement a single stage of a shift register with load capability. The design requires:
1. A D flip-flop to store the current value (Q)
2. A multiplexer to select between:
   - Shift mode (when E=1): take input from previous stage (w)
   - Load mode (when L=1): take the load value (R)
   - Hold mode (when both E and L are 0): maintain current value
The flip-flop updates on the positive clock edge based on the selected input.
