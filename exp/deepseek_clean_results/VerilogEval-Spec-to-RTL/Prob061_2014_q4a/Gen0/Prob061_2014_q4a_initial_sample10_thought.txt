The TopModule needs to implement a single stage of a shift register with parallel load capability. The design should:
1. On each positive clock edge:
   - If L (load) is high, load R into the flip-flop
   - Else if E (enable) is high, shift in the value from w (previous stage)
   - Otherwise, maintain current state
2. Output Q should always reflect the current stored value
This can be implemented with a simple always block that checks L and E signals in priority order.
