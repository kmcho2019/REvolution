The TopModule needs to implement a single stage of a shift register with parallel load capability. The design should:
1. On each positive clock edge:
   - If L (load) is asserted, load the value from R into the flip-flop
   - Else if E (enable) is asserted, shift in the value from w (previous stage)
   - Otherwise, maintain the current value
2. Output Q should always reflect the current flip-flop value
This creates a basic shift register stage with parallel load functionality.
