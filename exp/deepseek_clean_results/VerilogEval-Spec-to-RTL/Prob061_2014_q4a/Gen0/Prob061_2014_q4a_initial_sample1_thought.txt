The TopModule needs to implement a single stage of a shift register with parallel load capability. The design requires:
1. A D flip-flop to store the current state (Q)
2. A multiplexer to select between:
   - Shift mode (E=1): take input from previous stage (w)
   - Load mode (L=1): take parallel input (R)
   - Hold mode: maintain current value
The flip-flop updates on the positive clock edge.
