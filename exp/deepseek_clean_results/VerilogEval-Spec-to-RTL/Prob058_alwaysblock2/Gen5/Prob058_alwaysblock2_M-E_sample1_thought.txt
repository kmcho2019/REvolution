Instead of implementing three separate XOR operations, we can create a more sophisticated module that:
1. Uses a single XOR operation shared between all outputs to reduce logic duplication
2. Implements a configurable delay line for the sequential output (default 1 cycle)
3. Adds an optional output mux that can select between immediate and delayed results
4. Uses parameterization to make the delay length configurable
This approach demonstrates resource sharing while maintaining the required functionality and adding flexibility.
