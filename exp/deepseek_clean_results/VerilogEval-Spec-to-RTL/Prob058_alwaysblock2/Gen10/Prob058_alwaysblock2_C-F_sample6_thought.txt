Fusion strategy combining the best of both examples:
1. Structural clarity from Example 1:
   - Explicit wire/reg declarations for all outputs
   - Clear separation of combinational and sequential blocks
2. Code simplicity from Example 2:
   - Minimal syntax while maintaining readability
   - Self-documenting code without redundant comments
3. Optimizations:
   - Use continuous assignment for all combinational logic (more efficient than always_comb)
   - Keep sequential block simple with direct XOR implementation
4. Benefits:
   - Combines the structural clarity of Example 1 with the simplicity of Example 2
   - More efficient than both by using single assign for combinational outputs
   - Maintains identical functionality while being more synthesis-friendly
