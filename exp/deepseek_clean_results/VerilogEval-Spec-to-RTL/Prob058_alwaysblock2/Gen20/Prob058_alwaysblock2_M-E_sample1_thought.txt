Novel Architecture Idea:
1. Hierarchical XOR implementation with a submodule for core logic
2. Conditional clock gating for the sequential output to reduce power
3. Use of parameters for potential future configurability
4. Explicit reset handling (though not required in spec, adds robustness)
5. Separate clock domain for the sequential logic to demonstrate isolation

Key Innovations:
- Modular design with XOR core in a submodule
- Clock gating based on input change detection
- Optional reset capability (disabled by default)
- Demonstration of clock domain separation
- Parameterized design for potential scaling
