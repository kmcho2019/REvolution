To simplify the Moore state machine implementation while maintaining functionality:

1. **Minimal State Representation**: Since there are only 2 states, we can use a single bit register (0/1) without explicit parameters
2. **Direct State Transitions**: Express state transitions as simple if-else conditions based on current state and input
3. **Output Logic**: The output is simply the inverse of the state bit (since B=0 outputs 1 and A=1 outputs 0 in this encoding)
4. **Synchronous Reset**: Maintain the specified synchronous reset behavior

This simplification removes unnecessary parameter definitions and case statements while keeping the same functionality.
