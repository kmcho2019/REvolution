Here's a novel approach using a shift register implementation for the state machine:
1. Instead of a traditional state register, use a 2-bit shift register where only one bit is active at a time
2. The active bit position represents the current state (bit 0 = B, bit 1 = A)
3. State transitions are implemented by shifting left or right based on input
4. Output is directly the LSB of the shift register
5. Reset initializes the shift register to '01' (B state)

This approach has these advantages:
- Simple shift operations for state transitions
- Output is directly tapped from the state representation
- Potential for better power characteristics as only one bit changes per transition
- Easily extensible to more states if needed
