To simplify the solution while maintaining functionality, I'll make these key changes:

1. **Single Always Block**: Combine the state transition and state register logic into one sequential always block, eliminating the need for separate combinational logic.

2. **Direct State Encoding**: Use simple binary states without parameters since there are only two states, making the code more compact.

3. **Implicit Output Logic**: Since the output is directly tied to the current state (1 for state 0, 0 for state 1), we can make this relationship more implicit.

This simplification reduces the code by:
- Removing the next_state register and associated combinational logic
- Eliminating parameter definitions
- Making the state behavior more immediately visible in the sequential block
