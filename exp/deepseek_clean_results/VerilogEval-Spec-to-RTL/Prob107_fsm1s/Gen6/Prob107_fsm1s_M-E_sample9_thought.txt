Here's a novel approach using a shift register implementation with edge detection:

1. **Shift Register Concept**: Instead of traditional state encoding, we'll use a 2-bit shift register where the pattern represents the current state. This allows us to detect state transitions through bit patterns.

2. **Edge Detection**: We'll use the shift register to detect when we need to transition states based on input patterns. The rightmost bit will represent the current state (0 for A, 1 for B).

3. **Output Logic**: The output is simply the complement of the rightmost bit (since B=1, A=0). This eliminates the need for explicit state comparison.

This approach is unconventional for a simple FSM but demonstrates how shift registers can be creatively used for state management. It may offer better timing characteristics in some technologies due to the simple shift operation.
