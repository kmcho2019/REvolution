The simplest implementation would:
1. Use a single bit state register (0=A, 1=B) since there are only two states
2. Combine state transition and output logic in one always block
3. Make output directly equal to the state bit (since B=1, A=0 matches the output requirements)
4. Use simple if-else for state transitions based on the input
This eliminates unnecessary logic and makes the state machine explicit while being minimal.
