Refactoring approach:
1. Use a single always block for both state transition and output logic to reduce area
2. Eliminate the next_state register since the state transitions are simple
3. Make the output directly dependent on the current state (Moore machine)
4. Keep synchronous reset and clocking behavior
This approach reduces the number of registers and simplifies the logic while maintaining identical functionality. The single always block makes the state transitions and output more tightly coupled, which is acceptable for such a small state machine.
