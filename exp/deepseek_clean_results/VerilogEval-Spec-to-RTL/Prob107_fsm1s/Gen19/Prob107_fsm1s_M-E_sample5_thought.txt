Instead of using traditional state registers, I'll implement the state machine using a shift register approach with clever initialization. This creates a unique implementation where:

1. **Shift Register Concept**: Use a 2-bit shift register where the current state is represented by the LSB
2. **Transition Logic**: The next state is determined by shifting in either '0' or '1' based on input
3. **Reset Handling**: Initialize the shift register to '11' (binary 3) which represents state B
4. **Output Logic**: The output is simply the inverted MSB of the shift register
5. **Advantages**:
   - Eliminates explicit state comparisons
   - Uses simple shift operations for state transitions
   - Naturally handles the reset condition
   - Provides potential for easier pipelining if expanded
   - Interesting alternative to traditional FSM implementations
