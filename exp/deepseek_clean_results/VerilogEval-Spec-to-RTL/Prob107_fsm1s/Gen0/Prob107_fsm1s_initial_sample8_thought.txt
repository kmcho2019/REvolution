To implement the specified Moore state machine, we need:
1. Two states (A and B) represented by a state register
2. Synchronous reset to initialize the state to B
3. Next state logic based on current state and input
4. Output logic based solely on current state (Moore machine characteristic)

The state transitions are:
- From B: stays in B if input=1, goes to A if input=0
- From A: stays in A if input=1, goes to B if input=0
