To implement the specified Moore state machine with two states (A and B), we need:
1. A state register to hold current state (B is reset state)
2. Combinational logic for next state transitions based on current state and input
3. Output logic based solely on current state (Moore machine)
The state transitions follow:
- In state B: stays in B if in=1, moves to A if in=0
- In state A: stays in A if in=1, moves to B if in=0
Output is 1 in state B and 0 in state A
