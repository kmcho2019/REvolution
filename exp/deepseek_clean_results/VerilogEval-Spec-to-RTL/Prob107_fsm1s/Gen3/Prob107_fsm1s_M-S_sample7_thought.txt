The simplest implementation for this 2-state Moore machine would be:
1. Use a single bit state register (0=B, 1=A)
2. Directly derive output from state (out = ~state)
3. Implement state transitions with minimal logic:
   - From B: stay if in=1, else go to A
   - From A: stay if in=1, else go to B
4. Reset synchronously to state B (0)
This eliminates any unnecessary complexity while maintaining full functionality.
