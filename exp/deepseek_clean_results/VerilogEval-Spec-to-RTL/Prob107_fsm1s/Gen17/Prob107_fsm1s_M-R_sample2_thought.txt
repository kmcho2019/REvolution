I'll refactor the state machine implementation by:
1. Using a single always block for both state transition and output logic (Mealy-Moore hybrid style)
2. Eliminating the separate next_state register by directly assigning to state
3. Using an enumerated type for states for better readability
4. Keeping the output as a continuous assignment but deriving it directly from the state

This approach reduces the number of always blocks while maintaining clear state machine behavior. The synchronous reset and Moore output characteristics are preserved. The state transitions become more immediately visible in the code.
