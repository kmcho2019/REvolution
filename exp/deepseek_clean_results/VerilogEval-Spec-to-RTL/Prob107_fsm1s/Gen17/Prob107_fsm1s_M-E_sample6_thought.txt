Novel Architecture Idea: Shift Register State Machine

Instead of using traditional state registers and combinational logic, we can implement this 2-state machine using a shift register approach:

1. **Concept**: Treat the state machine as a pattern generator where the next state is determined by shifting in the appropriate bit based on current state and input
2. **Implementation**:
   - Use a 2-bit shift register where the MSB represents the current state
   - The LSB is always 0 (since we only need to track one state bit)
   - State transitions are implemented by shifting in the appropriate next state bit
3. **Advantages**:
   - Eliminates explicit state transition logic
   - Simple shift operation determines next state
   - Naturally handles the reset condition
   - Output is directly the MSB of the shift register
4. **Operation**:
   - State B (1) shifts in 1 when input is 1, or 0 when input is 0
   - State A (0) shifts in 1 when input is 0, or 0 when input is 1
5. **Reset**: Initializes shift register to '10' (representing state B)
