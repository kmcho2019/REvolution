Here's a novel approach using a shift register implementation for the state machine:

1. **Shift Register Concept**: Instead of traditional state encoding, use a 2-bit shift register where the current state is represented by the MSB.
2. **State Representation**: 
   - 'B' state: 01 (MSB=0)
   - 'A' state: 10 (MSB=1)
3. **Transition Logic**: 
   - For state B (01): 
     - in=0 shifts to 10 (A)
     - in=1 maintains 01 (B)
   - For state A (10):
     - in=0 shifts to 01 (B)
     - in=1 maintains 10 (A)
4. **Output Logic**: Simply use the MSB (inverted) as output
5. **Advantages**:
   - Eliminates combinational logic for next state calculation
   - Uses simple shift operations
   - Naturally prevents invalid states (00 and 11 never occur)
   - Output is directly derived from state representation
