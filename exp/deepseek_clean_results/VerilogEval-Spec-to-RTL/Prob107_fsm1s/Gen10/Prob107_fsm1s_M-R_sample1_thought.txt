I'll refactor the state machine implementation while maintaining the same functionality. The key changes will be:

1. **Single Always Block**: Instead of separating combinational and sequential logic, I'll use a single always block for both state transitions and output assignment. This reduces the number of processes while keeping the same behavior.

2. **Direct State Encoding**: I'll use binary state encoding directly in the state transitions rather than parameters, since there are only two states. This simplifies the code while maintaining clarity.

3. **Registered Output**: I'll make the output a registered output (still Moore machine) to potentially improve timing by removing the combinational path from state to output.

This refactoring makes the code more compact while preserving the exact same state machine behavior, and the registered output might help with timing closure in some synthesis scenarios.
