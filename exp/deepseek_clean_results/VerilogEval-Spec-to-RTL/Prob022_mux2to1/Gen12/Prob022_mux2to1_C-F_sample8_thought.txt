Fusion Strategy:
1. Combine the clarity and conciseness of the ternary operator approach with the explicit gate-level understanding
2. Use a single continuous assignment for optimal synthesis while maintaining clear mux functionality
3. Implement the mux using Boolean operations that directly map to hardware (AND/OR gates)
4. Key benefits:
   - Single-line implementation for clean, readable code
   - Explicitly shows the mux selection logic (a when sel=0, b when sel=1)
   - Optimal for synthesis (same as ternary operator)
   - Clearly conveys the hardware intent
   - Maintains excellent PPA characteristics

Optimizations:
- Uses minimal logic operations (1 AND, 1 OR, 1 NOT)
- Single assignment statement ensures synthesis tools can optimize
- Direct mapping to standard cells
- Balanced critical path (equal delay for both input paths)
