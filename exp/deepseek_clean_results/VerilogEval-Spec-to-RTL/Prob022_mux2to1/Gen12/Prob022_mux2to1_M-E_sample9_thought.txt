Novel Approach: Transmission Gate Multiplexer
1. Instead of using traditional logic gates, implement the mux using transmission gates
2. Key advantages:
   - Reduced transistor count (only 2 pass transistors needed)
   - Potentially lower power consumption since only one path is active at a time
   - Symmetrical rise/fall times
3. Implementation details:
   - Use PMOS for sel=0 path (better for passing '1')
   - Use NMOS for sel=1 path (better for passing '0')
   - Invert sel signal to control PMOS gate
4. This approach is more representative of actual CMOS implementation while maintaining functionality
