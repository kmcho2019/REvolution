Here's a novel approach using a look-up table (LUT) implementation with a case statement. This method:
1. Treats the sel input as an index into a 2-element array
2. Uses a case statement to explicitly map each possible sel value to its corresponding output
3. Provides a different architectural perspective while maintaining the same functionality
4. Could potentially offer better synthesis optimization in some FPGA architectures where LUTs are the fundamental building blocks
5. Makes the selection logic extremely explicit and readable
