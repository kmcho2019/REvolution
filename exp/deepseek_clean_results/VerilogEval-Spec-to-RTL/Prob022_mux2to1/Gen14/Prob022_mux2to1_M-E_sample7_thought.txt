Here's a novel approach using a bitwise operator implementation of the multiplexer. Instead of using conditional statements or ternary operators, we can implement the mux using pure Boolean logic:

1. The key insight is that a 2:1 mux can be expressed as: out = (a & ~sel) | (b & sel)
2. This directly implements the mux truth table using AND and OR operations
3. The advantage is it's a purely combinational implementation without any procedural blocks
4. It clearly shows the gate-level implementation (two AND gates and one OR gate)
5. This approach is particularly interesting for educational purposes as it demonstrates the actual Boolean logic behind a mux
6. It's also easily extendable to wider data paths by just replicating the same logic for each bit
