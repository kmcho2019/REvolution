The original implementation using an always block is correct but can be optimized for better PPA (Power, Performance, Area) metrics. Here's the improvement strategy:

1. **Use continuous assignment instead of procedural block**: 
   - Continuous assignments typically synthesize to more optimal hardware for simple combinational logic like multiplexers
   - Removes the need for a register declaration (output reg)
   - Eliminates the always block overhead

2. **Direct ternary operator implementation**:
   - The ternary operator (?:) maps directly to a multiplexer in hardware
   - Results in cleaner, more concise code
   - Typically synthesizes to the most efficient implementation for this simple case

3. **PPA Benefits**:
   - Same functionality but potentially better synthesis results
   - Slightly reduced area (no procedural block overhead)
   - Same timing characteristics (single mux delay)
   - Possibly lower power due to simpler implementation
