Refactored Approach: Conditional Operator Mux
1. Maintain the same logical functionality but express it using Verilog's conditional operator
2. The conditional operator (?:) is more readable and directly expresses the multiplexer behavior
3. Benefits:
   - More intuitive representation of the mux selection logic
   - Cleaner code with fewer operators
   - Still synthesizes to the same basic logic gates
   - Easier to understand and maintain
   - Natural extension to wider buses
   - Consistent with common Verilog coding practices
