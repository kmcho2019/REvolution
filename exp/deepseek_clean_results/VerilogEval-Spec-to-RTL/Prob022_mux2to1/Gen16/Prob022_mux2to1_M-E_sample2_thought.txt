Novel Approach: Bitwise Operation Implementation
1. Instead of using a ternary operator, implement the mux using bitwise operations
2. Leverage the property that (a & ~sel) | (b & sel) gives the same result as a mux
3. This approach demonstrates alternative logic implementation
4. Uses fundamental AND/OR operations which might map differently to hardware
5. Maintains same functionality while showing different implementation style

Key Features:
- Uses explicit bitwise AND/OR operations
- No conditional operators
- Shows mathematical relationship between mux and basic logic gates
- May have different synthesis characteristics in some technologies
- Demonstrates equivalent logic using different primitives
