Refactoring Approach for 2:1 Multiplexer:

1. **Alternative Implementation Strategy**:
   - Instead of using the ternary operator, implement using basic logic gates (AND, OR, NOT)
   - This demonstrates the gate-level construction of a multiplexer
   - Shows the underlying hardware implementation that the ternary operator would synthesize to

2. **Key Benefits**:
   - Explicitly shows the boolean logic equation: out = (a & ~sel) | (b & sel)
   - Helps understand the fundamental digital logic behind multiplexers
   - Still maintains optimal PPA characteristics as it's the canonical implementation

3. **Implementation Details**:
   - Use continuous assignment with bitwise operators
   - First term: a AND NOT sel (selects a when sel=0)
   - Second term: b AND sel (selects b when sel=1)
   - OR the two terms together to get the final output
   - This is exactly how synthesis would implement the ternary operator version

4. **PPA Considerations**:
   - Same area and timing as ternary version (2 gates + 1 OR)
   - Identical power characteristics
   - May be preferred in educational contexts to show gate-level implementation
