Here's a novel approach using a look-up table (LUT) implementation with a 2-bit memory element. The idea is:
1. Store both input bits (a and b) in a 2-bit register
2. Use the sel signal to index into this register
3. This approach demonstrates an alternative implementation that doesn't use the traditional multiplexer logic

Advantages:
- Shows a different architectural approach
- Could be useful in FPGA implementations where LUTs are primitive elements
- Demonstrates how the same functionality can be achieved through memory addressing

Note: While this isn't necessarily better for PPA in ASIC implementations, it provides an interesting alternative perspective on implementing multiplexers.
