The original implementation uses an always block with if-else to implement the 2:1 mux. We can refactor this to use a continuous assignment with a ternary operator instead. This approach:
1. Eliminates the need for procedural blocks
2. Makes the code more concise
3. Maintains identical functionality
4. Potentially improves readability for simple multiplexing cases
5. Still results in the same synthesized hardware (a 2:1 mux)
