Novel Approach: Bitwise Logic Implementation
Instead of using the conventional ternary operator or if-else structure, we can implement the multiplexer using pure bitwise logic operations. The key insight is that:
1. When sel=0: out = a & ~sel (since ~sel=1)
2. When sel=1: out = b & sel
3. Then OR these two results together

This approach:
- Uses only basic AND/OR gates which are fundamental building blocks
- Demonstrates how multiplexers can be built from first principles
- May offer different synthesis optimization paths
- Provides identical functionality while showing an alternative implementation
- Maintains the same PPA characteristics as the standard implementation
