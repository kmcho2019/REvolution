The original implementation uses a ternary operator in a continuous assignment. For refactoring, we can implement the same 2-to-1 multiplexer logic using:
1. A continuous assignment with explicit AND-OR logic instead of a ternary operator
2. This approach shows the underlying gate-level implementation more clearly while maintaining the same functionality
3. The sel signal controls which input (a or b) gets propagated to the output through AND gates, with the results OR'ed together
