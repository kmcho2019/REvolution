Novel Implementation Idea:
1. Use a lookup table (LUT) approach implemented with a case statement
2. Treat the {sel, a, b} combination as a 3-bit index into a truth table
3. The case statement explicitly lists all possible input combinations
4. This approach makes the functionality extremely explicit and verifiable
5. While functionally equivalent, it demonstrates an alternative way to think about the mux operation

Advantages:
- Makes all possible input combinations immediately visible
- Easy to verify correctness by inspection
- Shows a different conceptual approach to the same problem
- Can be easily extended to more complex selection logic
- Demonstrates case statement usage for combinational logic
