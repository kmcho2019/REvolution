Refactoring Approach: Using Continuous Assignment with Logical Operators
1. Original solution uses ternary operator which is clean but we can explore alternative implementations
2. This refactoring uses basic logical operators (AND, OR) to construct the mux
3. Benefits of this approach:
   - Demonstrates the fundamental gate-level implementation of a mux
   - Shows how higher-level constructs (like ternary operator) map to hardware
   - Useful for educational purposes to understand mux internals
   - Maintains same functionality while showing different coding style
4. Implementation logic:
   - AND a with inverted sel (sel=0 selects a)
   - AND b with sel (sel=1 selects b)
   - OR the results to get the final output
5. Expected results:
   - Identical functionality to original
   - Same PPA characteristics after synthesis
   - More verbose but pedagogically valuable
