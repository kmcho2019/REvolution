Refactored Implementation Idea:
1. Use an always block with sensitivity to all inputs (a, b, sel)
2. Implement the mux logic using a case statement for clarity
3. This shows an alternative procedural approach while maintaining identical functionality
4. The case statement makes the selection logic very explicit
5. Still synthesizes to the same basic 2-to-1 mux hardware

Advantages:
- Demonstrates procedural style implementation
- Case statement makes selection criteria very visible
- Easy to extend if more selection cases were needed
- Maintains same performance characteristics as original
