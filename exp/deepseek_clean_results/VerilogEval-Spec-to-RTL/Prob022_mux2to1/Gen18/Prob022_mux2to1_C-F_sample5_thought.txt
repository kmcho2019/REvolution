Fusion Strategy:
1. Combine the readability of the ternary operator (Example 1) with the hardware-awareness of the bitwise implementation (Example 2)
2. Maintain the concise single-line assignment from Example 1 while ensuring it maps optimally to hardware
3. The ternary operator is preferred because:
   - It's more readable and directly expresses the mux functionality
   - Modern synthesis tools optimize it to the same hardware as the bitwise version
   - It's more maintainable and scalable for wider buses
4. This approach gives us:
   - Identical PPA to both examples (since they synthesize to same hardware)
   - Better code clarity than the bitwise version
   - Same synthesis flexibility as the bitwise version
5. Verification benefits:
   - Clearer intent makes formal verification easier
   - Less prone to coding errors than manual bitwise operations
