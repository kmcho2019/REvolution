Fusion Strategy:
1. Combine the clarity of structural implementation (Example 1) with the conciseness of continuous assignment (Example 2)
2. Use bitwise operations like Example 2 but implement them directly in a single continuous assignment
3. Eliminate intermediate wires to reduce area and power while maintaining readability
4. The solution will use the fundamental mux logic (a & ~sel) | (b & sel) but implement it more efficiently

Advantages:
- Single continuous assignment reduces gate delays (better timing)
- No intermediate wires reduce area and power
- Still clearly shows the underlying mux logic
- More likely to map to optimal MUX primitive in synthesis
- Cleaner code while maintaining hardware transparency
