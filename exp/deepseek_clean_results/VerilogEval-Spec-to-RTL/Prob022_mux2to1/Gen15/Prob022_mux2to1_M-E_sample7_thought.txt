Novel Approach: Bitwise Operation Mux
1. Instead of using traditional conditional logic, implement the mux using bitwise operations
2. Leverage the fact that sel can be used as a mask: (a & ~sel) | (b & sel)
3. This approach uses pure combinatorial logic without any procedural blocks
4. The implementation will be:
   - When sel=0: (a & 1) | (b & 0) = a
   - When sel=1: (a & 0) | (b & 1) = b
5. Benefits:
   - Single continuous assignment
   - No procedural blocks needed
   - Potentially better synthesis optimization in some tools
   - Clear mathematical representation of the mux function
6. Maintains identical functionality while showing a different implementation style
