Novel Approach: Bitwise Operation Mux
1. Instead of using a ternary operator or gate-level logic, implement the mux using bitwise operations
2. The key insight: (a & ~sel) | (b & sel) performs the same function as a 2:1 mux
3. Benefits:
   - Shows an alternative mathematical representation of multiplexing
   - Demonstrates how basic Boolean operations can build complex functions
   - Still synthesizes efficiently to standard cells
   - Provides same PPA characteristics as traditional implementations
   - Offers a different perspective on mux implementation
   - Can be easily extended to wider buses
