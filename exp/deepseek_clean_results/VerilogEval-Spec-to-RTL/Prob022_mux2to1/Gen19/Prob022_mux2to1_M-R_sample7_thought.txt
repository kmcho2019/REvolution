Refactoring Approach:
1. Maintain the same 2-to-1 mux functionality but express it using bitwise operations instead of ternary operator
2. Use continuous assignment but show the underlying Boolean logic explicitly
3. This makes the hardware implementation more transparent while maintaining efficiency
4. The formula (a & ~sel) | (b & sel) directly represents the mux's gate-level implementation

Advantages:
- More explicit about the hardware implementation
- Still synthesizes to the same optimal MUX primitive
- May be preferred in some design styles for clarity of Boolean operations
- Maintains all PPA benefits of the original solution
