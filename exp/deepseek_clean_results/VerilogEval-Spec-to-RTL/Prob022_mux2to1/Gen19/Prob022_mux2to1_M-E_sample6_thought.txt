Novel Implementation Idea:
1. Use a lookup table (LUT) approach implemented with a case statement
2. Treat the sel and input bits as an address to select the output
3. Combine all inputs into a 3-bit vector that serves as the case selector
4. This approach demonstrates how a mux can be viewed as a memory lookup operation
5. While functionally equivalent, this shows a different conceptual model of the mux

Advantages:
- Demonstrates an alternative architectural perspective
- Easily extendable to larger muxes by just adding more case items
- Shows how combinational logic can be modeled as memory operations
- Maintains readability while being architecturally different
