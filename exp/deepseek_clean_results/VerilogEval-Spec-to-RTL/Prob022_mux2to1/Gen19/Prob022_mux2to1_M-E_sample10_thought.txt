Novel Architectural Idea:
1. Instead of using the standard ternary operator, implement the mux using a lookup table approach with a case statement
2. Create a 2-bit concatenated input that combines both sel and the data inputs
3. Use this combined input to index into possible output values
4. This approach demonstrates an alternative way to think about multiplexers as truth table implementations
5. While functionally equivalent, this method showcases different Verilog coding styles

Key Features:
- Uses concatenation to create a control+data vector
- Implements logic via exhaustive case statement
- Shows how multiplexers can be viewed as truth tables
- Maintains same functionality while using different syntax
