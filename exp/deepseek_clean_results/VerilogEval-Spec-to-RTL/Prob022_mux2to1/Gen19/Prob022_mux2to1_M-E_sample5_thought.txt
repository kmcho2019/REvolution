Novel Implementation Idea:
1. Implement the 2-to-1 mux using gate-level primitives only
2. Use AND-OR logic to construct the mux function: out = (¬sel ∧ a) ∨ (sel ∧ b)
3. This approach demonstrates the fundamental logic gates that make up a mux
4. Shows how higher-level constructs decompose to basic gates
5. Provides insight into the actual hardware implementation

Advantages:
- Reveals the underlying gate-level implementation
- No behavioral constructs used (pure structural)
- Demonstrates how to build functionality from basic components
- Easily maps to standard cell libraries
- Good for educational purposes to understand mux internals
