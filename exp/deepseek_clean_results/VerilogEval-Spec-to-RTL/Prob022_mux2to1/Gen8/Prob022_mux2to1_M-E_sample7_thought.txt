Novel Approach: Gate-Level Implementation Using Basic Logic Gates
1. Instead of using procedural blocks or continuous assignment, implement the mux using fundamental logic gates
2. The mux functionality can be expressed as: out = (a & ~sel) | (b & sel)
3. This approach demonstrates the underlying gate-level implementation of a mux
4. Benefits:
   - Shows the actual hardware realization of a mux
   - Explicitly visible gate-level structure
   - No procedural blocks needed
   - Same functionality but different implementation style
   - Useful for educational purposes to understand mux internals
