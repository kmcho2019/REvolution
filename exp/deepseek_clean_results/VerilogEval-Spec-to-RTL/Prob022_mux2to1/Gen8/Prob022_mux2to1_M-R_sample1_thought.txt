Refactoring Approach:
1. Maintain the same logical functionality (2-to-1 mux) but implement using a single continuous assignment
2. Eliminate intermediate wires by using a conditional operator
3. This reduces the code to one line while keeping the same gate-level implementation
4. The conditional operator will synthesize to the same AND-OR structure but is more concise
5. Benefits:
   - More compact code
   - Clearer expression of the multiplexer's purpose
   - Still maintains optimal PPA characteristics
   - More readable as it directly maps to the mux specification
