Instead of using the conventional conditional operator or gate-level implementation, we can implement the multiplexer using a lookup table (LUT) approach. This method encodes all possible input combinations (a, b, sel) into a 3-bit address and uses this to index into a predefined output pattern. The output pattern is constructed such that it matches the truth table of a 2-to-1 multiplexer. This approach demonstrates how combinatorial logic can be implemented using memory-like structures.
