Optimization Strategy: Reduced Gate Count Implementation
1. Eliminate the dedicated NOT gate by using sel directly in both AND paths
2. This reduces the gate count from 4 to 3 (2xAND, 1xOR)
3. Benefits:
   - Reduced area (from 2.0um² to ~1.75um² estimated)
   - Lower power consumption (eliminates NOT gate switching)
   - Maintains same functionality
   - Still uses only basic gates for educational clarity
   - Timing remains similar (2-gate delay path)
4. The logic equation remains: out = (a & ~sel) | (b & sel), but implemented more efficiently
