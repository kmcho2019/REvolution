Refactoring Approach:
1. Maintain the same 2-to-1 multiplexer functionality but implement it using a conditional operator in continuous assignment
2. Benefits of this approach:
   - More concise and readable code
   - Directly expresses the multiplexer behavior without explicit Boolean operations
   - Still synthesizes to the same basic logic structure (AND-OR gates)
   - Matches common Verilog coding style for simple multiplexers
3. The conditional operator (?:) is perfect for this case as it:
   - Clearly shows the selection condition (sel)
   - Explicitly shows the two possible outputs (a and b)
   - Results in identical hardware implementation as the original
4. This refactoring improves readability while maintaining all PPA characteristics
