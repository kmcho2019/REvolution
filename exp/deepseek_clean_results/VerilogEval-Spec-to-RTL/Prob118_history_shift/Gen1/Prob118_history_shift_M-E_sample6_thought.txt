Instead of using a traditional shift register, we can implement the history buffer as a circular buffer with a write pointer. This approach:
1. Uses a 32-bit buffer and a 5-bit pointer to track the current position
2. On reset, clears the buffer and resets pointer
3. For mispredictions: 
   - Loads the buffer with train_history
   - Writes train_taken at the next position
   - Resets pointer to 0 (simulating a shift)
4. For predictions:
   - Writes predict_taken at current pointer position
   - Increments pointer (wrapping around)
5. Output is generated by reading the buffer from pointer-1 to pointer-32 (mod 32)

Advantages:
- Eliminates the 32-bit shift operation, reducing combinational logic
- More power efficient as only one bit changes per write
- Easier to pipeline if needed
