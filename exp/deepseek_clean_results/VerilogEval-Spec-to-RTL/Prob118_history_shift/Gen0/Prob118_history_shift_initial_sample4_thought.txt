To implement the 32-bit global history shift register with rollback capability, we need to:
1. Handle asynchronous reset (areset) which clears the history register
2. Prioritize misprediction handling over prediction when both occur simultaneously
3. For mispredictions: concatenate train_history with train_taken (train_history << 1 | train_taken)
4. For normal predictions: shift in predict_taken from LSB (history << 1 | predict_taken)
5. Output the current history register value as predict_history
6. All updates occur on positive clock edges
