The design requires a 32-bit shift register to track branch history. The key operations are:
1. On reset, clear the history register
2. When a misprediction occurs, load the history with {train_history[30:0], train_taken} (rollback)
3. When a prediction occurs (and no misprediction), shift in predict_taken from LSB
4. Output the current history register value continuously

Priority handling:
- Reset has highest priority
- Misprediction has next priority over normal prediction updates
- Normal prediction updates occur when neither reset nor misprediction is active
