Refactoring Strategy: "Explicit State Machine with Parallel Update Logic"

Key Changes:
1. Replace the implicit priority logic with an explicit state machine
2. Use continuous assignments for the shift operations
3. Separate the update logic into parallel paths
4. Maintain same functionality but with clearer control flow
5. Use a single always block for sequential elements

Benefits:
- More explicit control flow improves readability
- Parallel update paths may help synthesis tools optimize better
- Clear separation of combinational and sequential logic
- Same functionality with potentially better PPA characteristics
- Easier to modify or extend in the future
