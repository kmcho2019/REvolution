Refactoring Approach:
1. Replace the always block with continuous assignments for combinational logic
2. Use a separate clocked always block just for the register update
3. Pre-compute the next state values to simplify the clocked logic
4. Maintain the same priority scheme (misprediction > prediction)
5. Keep the asynchronous reset functionality

Key Benefits:
- Separates combinational and sequential logic clearly
- Makes the priority logic more explicit in the combinational part
- Potentially improves timing by breaking up the critical path
- Maintains identical functionality while being more modular
