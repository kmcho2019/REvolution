Novel Architectural Idea:
1. Dual-Register Approach: Maintain two separate history registers - one for speculative updates (during prediction) and one for committed state (after branch resolution)
2. Parallel Update Paths: Eliminate the need for a large mux by having dedicated update logic for each register
3. Early Misprediction Resolution: Handle mispredictions immediately by swapping to the committed register, avoiding complex rollback logic
4. Reduced Critical Path: By separating prediction and training paths, we minimize the combinatorial logic in each path
5. Power Optimization: Only update the speculative register when needed, and keep the committed register stable during normal operation

Key Features:
- Speculative register tracks in-flight predictions
- Committed register holds verified history
- Simple swap operation on misprediction
- Asynchronous reset clears both registers
