Optimization strategy based on PPA metrics:
1. Eliminate shadow_history register to reduce area and power:
   - Instead of storing pre-prediction state, compute rollback value directly from current_history
   - For mispredictions, we can reconstruct the correct history by:
     a) Right-shifting current_history once (undo last prediction)
     b) Concatenating with train_taken
2. Simplify priority logic:
   - Use parallel assignment with ternary conditions
   - Remove cascaded if-else structure
3. Maintain same functionality:
   - Misprediction still takes precedence
   - Reset clears history
   - Output reflects current state

Key improvements:
- 50% reduction in register area (single 32-bit reg instead of two)
- Reduced power from eliminating shadow register updates
- Simplified control logic improves timing
