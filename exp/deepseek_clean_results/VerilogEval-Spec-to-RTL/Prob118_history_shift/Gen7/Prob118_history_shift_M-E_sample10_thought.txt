Novel Circular Buffer Architecture:

1. Key Idea:
   - Replace the traditional shift register with a circular buffer and head pointer
   - Use pointer arithmetic to simulate shifts without physical data movement
   - Maintain a separate "base" pointer for misprediction rollbacks

2. Advantages:
   - Eliminates the 32-bit shift operation (reduces critical path)
   - Only updates one bit per prediction (lower power)
   - Rollback becomes a simple pointer assignment (faster recovery)

3. Implementation Details:
   - 32-bit buffer stores history bits statically
   - Head pointer (5 bits) tracks current position (like a circular queue)
   - On prediction: increment head and write new bit
   - On misprediction: reset head based on train_history and append train_taken
   - Output is generated by reading 32 bits starting from head+1 (wrapped)

4. Benefits:
   - Faster updates (no shifting)
   - Lower power (only modified bits change)
   - Same functionality with better timing characteristics
