Novel Architectural Idea: 
1. Implement a dual-buffer approach where we maintain both the current history and a backup history for misprediction recovery
2. The backup history is updated only during valid predictions, storing the pre-prediction state
3. On misprediction, we can instantly recover the correct history by combining the backup with the actual branch outcome
4. This eliminates the need for a wide 32-bit mux in the critical path during normal operation
5. The shift operation becomes simpler as we only need to handle the current prediction case
6. Reset clears both buffers synchronously

Key Advantages:
- Reduced critical path during normal operation (only 1-bit shift)
- Misprediction recovery is still single-cycle but doesn't affect normal operation timing
- Clear separation of prediction and recovery paths
- Better timing closure potential
