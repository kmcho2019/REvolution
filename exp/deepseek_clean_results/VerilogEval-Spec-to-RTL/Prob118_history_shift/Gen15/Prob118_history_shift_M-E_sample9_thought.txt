Novel Dual-Buffer Architecture with Speculative Updates:

1. Key Idea:
   - Maintain two history buffers: one for committed state (safe_history) and one for speculative updates (spec_history)
   - This allows parallel processing of predictions and mispredictions without priority logic
   - Speculative updates can be discarded cleanly on misprediction

2. Advantages:
   - Eliminates the need for complex priority logic between predict/mispredict
   - Reduces critical path by separating speculative and committed paths
   - Enables simpler clock gating for power savings
   - More closely matches actual pipeline behavior with speculative execution

3. Operation:
   - Always update spec_history with predictions
   - On misprediction, overwrite both buffers with correct history
   - Committed buffer (safe_history) only updates on misprediction
   - Output comes from spec_history for predictions, safe_history for mispredictions
