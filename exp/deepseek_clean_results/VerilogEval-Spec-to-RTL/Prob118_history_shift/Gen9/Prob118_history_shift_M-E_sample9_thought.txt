Instead of using a traditional shift register, implement a circular buffer with:
1. A write pointer to track the current insertion point
2. A read pointer offset by 32 positions for predict_history
3. On misprediction, directly load the buffer contents from train_history and append train_taken
4. This reduces the physical shifting operations to pointer increments
5. Reset initializes both pointers to 0 and clears the buffer
6. Misprediction takes precedence by checking it first in the always block
