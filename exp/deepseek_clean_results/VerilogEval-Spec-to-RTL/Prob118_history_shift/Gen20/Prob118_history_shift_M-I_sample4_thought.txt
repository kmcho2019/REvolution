Optimization Strategy:

1. Single Register Approach:
   - Eliminate the dual-register structure to reduce area
   - Use a single history register with priority-based updates
   - Maintain correct rollback behavior through careful update sequencing

2. Power Optimization:
   - Simplify enable logic to reduce unnecessary switching
   - Remove redundant updates by making reset handling more efficient

3. Timing Improvement:
   - Streamline the critical path by reducing multiplexer complexity
   - Implement clear priority order (reset > misprediction > prediction)
   - Use direct bit manipulation for shift operations

4. Area Reduction:
   - Remove duplicate concatenation logic
   - Simplify control logic by combining conditions

Key Changes:
- Single 32-bit register replaces dual registers
- Clear priority encoding reduces logic depth
- More efficient reset handling
- Simplified update conditions
