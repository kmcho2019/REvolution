Refactoring Approach:

1. Single Register Optimization:
   - Replace dual registers with a single history register
   - Use combinational logic to calculate next state based on priority conditions
   - This reduces area and eliminates redundant updates

2. Priority-Based Next State Logic:
   - Implement clear priority: reset > misprediction > prediction
   - Use ternary operators for concise priority encoding
   - Calculate next state in combinational block before clocked update

3. Output Simplification:
   - Directly assign output from register (no additional logic needed)
   - Maintain clean separation between combinational and sequential logic

4. Power Efficiency:
   - Only update register when needed (predict_valid or train_mispredicted)
   - Avoid unnecessary toggling by using precise enable conditions

Key Benefits:
- Reduced area by eliminating duplicate register
- Clearer priority handling with combinational next-state logic
- Maintains all functionality while being more efficient
- Simpler timing path with direct priority encoding
