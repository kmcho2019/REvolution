Simplified Design Approach:
1. Maintain single 32-bit register for history tracking
2. Prioritize misprediction handling over prediction updates (clear precedence)
3. Simplify shift operations:
   - Misprediction: Direct load of {train_history[30:0], train_taken}
   - Prediction: Simple 1-bit shift with predict_taken as new LSB
4. Remove unnecessary logic by:
   - Using only essential conditions (reset > misprediction > prediction)
   - Eliminating redundant control signals
5. Keep clean reset functionality
6. Optimize power by only updating register when needed (predict_valid or train_mispredicted)

Key Simplifications:
- Reduced control logic complexity
- Minimal multiplexer structure
- Clear priority handling with if-else cascade
- Single always block for all operations
