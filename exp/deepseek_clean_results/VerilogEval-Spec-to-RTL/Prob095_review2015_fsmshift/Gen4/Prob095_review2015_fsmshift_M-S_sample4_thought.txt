Simplified solution approach:
1. Use a 2-bit counter (values 0-3) since we only need to count 4 cycles
2. Initialize counter to 0 on reset (active high synchronous)
3. Assert shift_ena while counter is active (values 0-3)
4. Stop counting after reaching 3 (2'b11) to maintain shift_ena at 0
5. This ensures exactly 4 cycles of shift_ena (counts 0,1,2,3) after reset

Benefits:
- Reduced counter width from 3 to 2 bits
- Clear 4-cycle count (0-3 is exactly 4 cycles)
- Simple comparison for shift_ena
- Maintains all required functionality
