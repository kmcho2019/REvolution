Here's a simplified approach using a minimal counter and clear state logic:

1. Use a 2-bit counter that counts from 0 to 3 (4 cycles total)
2. On reset, initialize counter to 0 and shift_ena to 1
3. Each clock cycle, increment counter while it's < 3
4. shift_ena stays high until counter reaches 3, then goes low permanently
5. No need for parallel load - simple increment suffices
6. Only 2-bit counter and simple comparison needed

Key simplifications:
- Eliminates parallel load logic
- Uses simpler increment instead of decrement
- Clearer state progression (0→3 instead of 3→0)
- Same functionality with fewer operations
