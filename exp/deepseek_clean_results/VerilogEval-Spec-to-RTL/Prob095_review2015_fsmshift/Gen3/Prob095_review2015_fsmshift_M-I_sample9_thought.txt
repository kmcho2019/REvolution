To correctly implement the 4-cycle shift enable with synchronous reset:
1. Use a 3-bit counter to properly count 4 cycles (0 to 3)
2. Reset the counter to 0 on reset and increment until reaching 3
3. Create a registered shift_ena output that's high only when counter is between 0 and 3
4. Ensure all logic is synchronous with the clock edge
5. The shift_ena should be asserted for exactly 4 cycles after reset, then stay low

- Correct cycle count (4 cycles)
- Proper synchronous reset behavior
- Clean registered output
- Minimal hardware usage
