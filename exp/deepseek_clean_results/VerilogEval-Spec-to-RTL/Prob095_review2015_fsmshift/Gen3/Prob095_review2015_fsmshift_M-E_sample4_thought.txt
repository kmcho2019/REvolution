Here's a novel state machine approach using a one-hot encoding scheme:

1. Use a 4-bit one-hot register to represent the 4 active cycles
2. Each bit corresponds to one of the 4 cycles where shift_ena should be high
3. On reset, initialize to '0001' (first cycle active)
4. Each clock cycle, rotate the '1' left (0001→0010→0100→1000)
5. After reaching '1000', the register stays in this state until next reset
6. shift_ena is the OR of all register bits (high during any active cycle)

This approach:
- Clearly shows the 4-cycle requirement in the state encoding
- Eliminates any counter overflow issues
- Makes the timing behavior visually apparent in the state representation
- Uses simple shift operations for state transitions
