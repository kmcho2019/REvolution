To simplify while maintaining correct functionality, I'll use a 2-bit counter with a done flag:

1. Use a 2-bit counter to count 4 cycles (0-3)
2. Add a done flag that gets set after 4 cycles
3. shift_ena is active when counter is counting (not done)
4. Reset clears both counter and done flag
5. After reaching count 3, set done flag which stops counting

This ensures exactly 4 cycles of shift_ena (counts 0,1,2,3) and then stays off until next reset.
