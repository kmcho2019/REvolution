Refactored solution to meet exact 4-cycle enable requirement immediately after reset:
1. Key changes:
   - Eliminate INIT state since we want immediate enable after reset
   - Start directly with CYCLE1 on reset
   - Use a counter-based approach instead of explicit states
2. New approach:
   - 2-bit counter to track 0-3 (4 cycles)
   - Reset sets counter to 0 and enables shift_ena
   - Counter increments each cycle until reaching 3
   - After 4 cycles (0-3), shift_ena stays low
3. Benefits:
   - More compact implementation
   - Immediate enable on first clock after reset
   - Exactly 4 cycles of shift_ena
   - Clear termination condition
4. Implementation:
   - Use a 2-bit register for cycle count
   - shift_ena is high when counter < 4
   - Reset synchronously clears counter
