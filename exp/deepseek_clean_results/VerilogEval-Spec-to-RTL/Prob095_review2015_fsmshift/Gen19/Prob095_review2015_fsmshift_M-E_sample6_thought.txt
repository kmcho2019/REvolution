Novel approach using a state machine with explicit cycle counting:
1. Instead of a simple counter, implement a 4-state one-hot FSM
2. Each state represents one of the 4 active cycles
3. Reset initializes to first state (S0) and progresses through S1, S2, S3
4. After S3, transitions to IDLE state where shift_ena remains low
5. One-hot encoding ensures:
   - Clear state progression
   - Exactly 4 cycles of shift_ena
   - Simple reset handling
   - Glitch-free output
6. Benefits over counter approach:
   - Explicit state tracking
   - Easier to modify if cycle count changes
   - More readable state transitions
