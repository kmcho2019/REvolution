Improved solution to meet exact 4-cycle enable requirement immediately after reset:
1. Key changes:
   - Remove INIT state to eliminate 1-cycle delay
   - Start directly in CYCLE1 state upon reset
   - Maintain same 4-cycle enable pattern
2. State sequence:
   - CYCLE1: First enabled cycle (entered immediately on reset)
   - CYCLE2: Second enabled cycle
   - CYCLE3: Third enabled cycle
   - CYCLE4: Fourth enabled cycle
   - DONE: Final state (shift_ena = 0)
3. Reset behavior:
   - Immediately enters CYCLE1 state (shift_ena high)
   - Progresses through CYCLE2-4 (shift_ena remains high)
   - Locks in DONE state until next reset
4. Benefits:
   - Exactly 4 cycles of shift_ena starting immediately after reset
   - More efficient state encoding (one less state)
   - Clear and simple state transitions
5. Implementation notes:
   - Uses 3-bit state encoding (though only 3 states needed)
   - Output logic remains simple combinatorial
   - Synchronous reset properly handled
