Improved solution with correct state encoding and cycle counting:
1. Use a 2-bit counter instead of one-hot encoding for simpler implementation
2. Counter will count from 0 to 3 (4 cycles) after reset
3. shift_ena is asserted when counter is active (0-3)
4. After reaching 3, counter stops and shift_ena remains low
5. Reset synchronously initializes counter to 0
6. Advantages:
   - More compact than FSM (2 bits vs 4)
   - Clear cycle counting
   - Exactly matches specification
   - Easier to verify and maintain
   - Better PPA (smaller area, lower power)
