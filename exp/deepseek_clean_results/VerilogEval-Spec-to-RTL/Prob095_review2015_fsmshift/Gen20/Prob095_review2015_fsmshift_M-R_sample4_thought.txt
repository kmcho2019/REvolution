Refactoring strategy:
1. Maintain the same core functionality (4-cycle shift_ena after reset)
2. Simplify the implementation by:
   - Using a 3-bit counter to avoid truncation issues
   - Making shift_ena purely combinational
   - Removing the need for explicit counter stop logic
3. Key improvements:
   - 3-bit counter naturally counts 0-7 (but we only need 0-3)
   - shift_ena is simply (counter < 4) - no width mismatch
   - Counter will automatically roll over after 7, but shift_ena will stay low
   - Reset behavior remains identical (4 cycles from 0-3)
4. Benefits:
   - More robust against counter width issues
   - Clearer intent in the code
   - Same hardware footprint (still minimal flip-flops)
