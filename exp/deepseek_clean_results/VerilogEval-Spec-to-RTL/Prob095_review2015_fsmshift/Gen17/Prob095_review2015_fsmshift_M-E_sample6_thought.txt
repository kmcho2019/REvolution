Novel approach using a down counter with explicit state tracking:
1. Use a 2-bit down counter initialized to 3 (binary '11') on reset
2. Decrement the counter each clock cycle while it's not zero
3. Track an 'active' state that determines when counting is happening
4. Benefits:
   - Explicit state machine makes timing clear
   - Counter naturally counts down from 3 to 0 (4 cycles)
   - State tracking prevents any accidental re-enabling
   - Easy to modify for different cycle counts
   - Clear separation between counting and output logic
5. Reset behavior:
   - Initialize counter to 3 and set active state
   - Count down each cycle while active
   - Once counter reaches 0, stay inactive until next reset
   - shift_ena is high only when counter is not zero
