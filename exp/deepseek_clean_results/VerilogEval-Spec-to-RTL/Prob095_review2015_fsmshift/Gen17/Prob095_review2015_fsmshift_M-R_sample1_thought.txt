Refactored approach maintaining the same core concept:
1. Keep the 4-bit shift register concept but implement it using continuous assignments
2. Use a combinational next-state logic with an assign statement
3. The shift register update is now done through a wire assignment rather than procedural blocks
4. Benefits:
   - Same clear 4-cycle behavior as original
   - Demonstrates alternative implementation style
   - All logic becomes continuous assignments
   - Reset still initializes to '1111'
   - Shift operation remains identical in effect
5. Structure:
   - shift_reg is now a wire (output of mux)
   - Next state is either reset value or shifted version
   - shift_ena still comes from MSB of register
