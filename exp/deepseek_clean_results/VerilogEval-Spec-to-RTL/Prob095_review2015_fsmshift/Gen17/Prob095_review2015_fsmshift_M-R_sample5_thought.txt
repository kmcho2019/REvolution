Refactored approach using the same shift register concept but with different implementation style:
1. Maintain the 4-bit shift register concept but implement it using continuous assignments
2. Use a combinational next-state logic with an assign statement
3. The sequential element (register) is kept simple with just the clocked update
4. Key differences from original:
   - Separates combinational and sequential logic explicitly
   - Uses an intermediate wire for next state
   - More verbose but potentially clearer data flow
   - Same functional behavior (4 cycles of shift_ena after reset)
5. Benefits:
   - Clear separation of next-state logic and state storage
   - Easier to modify next-state logic independently
   - Still maintains the simplicity of the shift register approach
