Improved solution using a 3-state approach:
1. Use a 2-bit counter to precisely count 4 cycles (0-3)
2. Add a 'done' flag to track when we've completed the 4 cycles
3. Reset behavior:
   - On reset, clear counter and done flag
   - shift_ena goes high
4. Normal operation:
   - Increment counter each cycle until reaching 3
   - When counter reaches 3, set done flag
5. Output logic:
   - shift_ena is high only when counter is active (0-3) and not done
   - After 4 cycles, done flag prevents further shifting
6. Advantages:
   - Precisely meets timing requirements
   - Clean reset handling
   - Minimal hardware overhead
   - Clear state transitions
