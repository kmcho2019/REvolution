Simplification approach:
1. Use a 2-bit counter that naturally counts 0-3 (4 cycles)
2. Make shift_ena active when counter is counting (0-3)
3. Stop counting after reaching 3 (counter stays at 3 until next reset)
4. Reset synchronously sets counter to 0
5. Simple combinational logic for shift_ena based on counter value

Key simplifications:
- Single always block for counter
- Direct counter value comparison for shift_ena
- No need for reset in output logic since counter handles timing
- Minimal state tracking (just 4 cycles)
