Refactored solution approach:
1. Maintain the 2-bit counter concept but fix the counting logic
2. Use an additional register to track when counting is complete
3. Reset both counter and completion flag on synchronous reset
4. Counter increments only when not completed (count < 3)
5. Set completion flag when counter reaches 3
6. shift_ena is asserted when either:
   - Reset is active (immediate assertion)
   - Counter is active and not yet completed (count < 3)

Key improvements:
- Properly limits shift_ena to exactly 4 cycles
- Prevents counter overflow
- Clear state tracking with completion flag
- Maintains synchronous reset behavior
- Uses both combinational and sequential logic effectively
