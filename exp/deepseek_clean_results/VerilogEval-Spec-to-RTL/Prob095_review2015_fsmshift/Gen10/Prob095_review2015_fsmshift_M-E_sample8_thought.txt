Here's a novel approach using a finite state machine (FSM) with explicit states rather than a counter:

1. Create a 4-state FSM (IDLE, S1, S2, S3) to track the 4 cycles
2. Reset transitions directly to S1 (first active cycle)
3. Each state transition advances to next state on clock edge
4. S3 loops back to itself (maintaining shift_ena=0)
5. shift_ena is active in all states except S3
6. Synchronous reset forces immediate transition to S1

Advantages:
- Explicit state representation makes timing clear
- No need for counter arithmetic
- Easily extensible if timing requirements change
- Clear state transitions match specification
