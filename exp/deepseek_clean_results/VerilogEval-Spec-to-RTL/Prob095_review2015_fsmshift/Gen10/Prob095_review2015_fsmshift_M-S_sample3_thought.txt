Simplified approach using a 2-bit counter:
1. Use a 2-bit counter to track the 4 cycles needed for shift_ena
2. On reset, initialize counter to 0 and enable shift_ena
3. Increment counter each clock cycle while not at max value (3)
4. shift_ena is active when counter value is less than 4 (0-3)
5. After 4 cycles, counter stops incrementing and shift_ena stays low
6. More compact than FSM approach while maintaining same functionality

Advantages:
- Fewer states (just a counter)
- Same cycle-accurate behavior
- Less code while equally clear
- Still maintains synchronous reset behavior
