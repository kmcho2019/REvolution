Novel approach using a down counter with load:
1. Instead of a state machine, use a 2-bit down counter initialized to 3 (binary 11)
2. On reset, load the counter with 3
3. Each clock cycle, decrement the counter while it's not zero
4. shift_ena is asserted when counter value is >= 0 (i.e., counter hasn't underflowed)
5. After 4 cycles (3→2→1→0), counter stays at 0 and shift_ena remains low
6. Simple implementation with minimal logic and no explicit state machine

Key advantages:
- Eliminates need for explicit state machine
- Counter directly controls the shift_ena timing
- Naturally counts exactly 4 cycles (values 3,2,1,0)
- More compact implementation
- Clear relationship between counter value and enable timing
