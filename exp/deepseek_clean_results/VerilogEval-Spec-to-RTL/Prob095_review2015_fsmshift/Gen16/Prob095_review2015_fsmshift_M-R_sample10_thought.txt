Refactored approach using a counter-based state machine:
1. Use a 2-bit counter to track the 4 cycles explicitly (0 to 3)
2. Add a 'done' flag to indicate when 4 cycles are complete
3. On reset, initialize counter to 0 and clear done flag
4. Each clock cycle, increment counter until it reaches 3
5. After 4 cycles (counter=3), set done flag and freeze counter
6. shift_ena is active when counter is running (done=0)
7. Benefits:
   - More compact than one-hot (only 2 bits for counter + 1 for done)
   - Explicit cycle counting matches requirements precisely
   - Clear state transitions based on counter value
   - Easy to verify timing (4 cycles exactly)
   - Maintains same functionality with simpler structure
