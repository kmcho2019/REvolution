Improved solution using a 2-bit counter with corrected cycle counting:
1. Use a 2-bit counter to count exactly 4 cycles (0-3)
2. Reset behavior:
   - On reset, clear counter and set shift_ena
   - shift_ena remains high for counter values 0,1,2
3. Output logic:
   - shift_ena is high when counter is 0,1,2 (first 3 cycles)
   - Plus the implicit cycle when counter is reset (total 4 cycles)
4. After 4 cycles:
   - Counter saturates at 3
   - shift_ena remains permanently low
5. Key improvements:
   - Correct 4-cycle count by including reset cycle
   - Simple comparison for shift_ena
   - Minimal hardware (only 2-bit counter)
   - Clear state progression
