Novel design approach:
1. Use a 3-bit counter (0-7) to count cycles, providing extra headroom
2. Implement a state machine with two states: ACTIVE (counting) and IDLE
3. Transition to ACTIVE on reset and count exactly 4 cycles
4. Use the counter to track cycles and state to control shift_ena
5. Clear counter and enter IDLE state after 4 cycles
6. Only exit IDLE state when reset occurs again

Key advantages:
- Explicit state machine makes behavior clearer
- 3-bit counter prevents overflow issues
- Strict 4-cycle count guaranteed by state transitions
- Clean separation between counting and control logic
