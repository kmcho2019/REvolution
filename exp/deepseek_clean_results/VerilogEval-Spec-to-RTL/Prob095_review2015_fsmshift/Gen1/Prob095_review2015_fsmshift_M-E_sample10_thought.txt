Here's a novel approach using a down counter instead of a traditional FSM:
1. Use a 2-bit down counter initialized to 3 (binary 11) on reset
2. The counter decrements each clock cycle while not zero
3. shift_ena is asserted when counter value is greater than 0
4. After reaching 0, the counter stays at 0 until next reset
This eliminates the need for explicit state variables while maintaining the same functionality in a more compact implementation.
