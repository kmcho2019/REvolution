To simplify the solution, we can use a 2-bit counter instead of an FSM with multiple states. The counter will:
1. Initialize to 0 on reset
2. Count up to 3 (4 cycles total) while asserting shift_ena
3. Stay at 3 (with shift_ena=0) until next reset

This approach eliminates the need for explicit state definitions and reduces the logic to a simple counter with comparison. The counter value directly represents how many cycles we've been asserting shift_ena.
