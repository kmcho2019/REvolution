Novel approach using a state machine with explicit cycle counting:
1. Instead of a simple counter, implement a 4-state FSM that tracks the shift enable duration
2. States represent each of the 4 active cycles plus a final "done" state
3. Reset forces transition to first active state
4. Each clock cycle progresses through states until reaching "done"
5. shift_ena is only active in the first 4 states
6. More explicit than counter approach, clearly shows 4-cycle requirement

Advantages:
- Clearly shows the 4-cycle requirement in state encoding
- Easier to modify if timing requirements change
- More self-documenting than counter approach
- Still maintains synchronous reset behavior
