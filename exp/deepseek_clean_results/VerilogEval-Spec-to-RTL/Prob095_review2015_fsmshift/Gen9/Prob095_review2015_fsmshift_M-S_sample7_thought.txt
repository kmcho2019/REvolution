Here's a simplified approach that maintains the exact same functionality:

1. Use a 2-bit counter (instead of 3-bit) since we only need to count 4 cycles (0-3)
2. Initialize counter to 0 on reset (simpler than loading a specific value)
3. Increment counter each cycle until it reaches 3 (4 cycles total)
4. shift_ena is simply the counter value < 3 (active for 4 cycles)
5. Counter stops incrementing after reaching 3 (holds value until next reset)

Key simplifications:
- Smaller counter (2 bits instead of 3)
- Simpler reset initialization (0 instead of 4)
- Increment instead of decrement (more intuitive counting)
- Same cycle count (4 cycles) with simpler logic
