To simplify the solution while maintaining functionality:
1. Use a 2-bit counter to track the 4 cycles (values 0-3)
2. Reset initializes the counter to 0
3. The counter increments each cycle until it reaches 3
4. shift_ena is asserted only when counter is less than 4 (values 0-3)
5. After 4 cycles, shift_ena stays 0 until next reset

This achieves the same functionality with simpler logic:
- No need for complex state encoding
- Single counter tracks both timing and output
- Reset properly initializes the counter
- Output is directly derived from counter value
