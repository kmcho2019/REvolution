To implement this module, we need a finite state machine (FSM) that asserts shift_ena for exactly 4 clock cycles after reset. The FSM will have 5 states:
1. RESET state (initial state) - asserts shift_ena and transitions to COUNT1
2. COUNT1 state - asserts shift_ena and transitions to COUNT2
3. COUNT2 state - asserts shift_ena and transitions to COUNT3
4. COUNT3 state - asserts shift_ena and transitions to IDLE
5. IDLE state - keeps shift_ena low until next reset

The FSM will use synchronous reset and positive edge triggered clock. The shift_ena output will be high only in RESET, COUNT1, COUNT2, and COUNT3 states.
