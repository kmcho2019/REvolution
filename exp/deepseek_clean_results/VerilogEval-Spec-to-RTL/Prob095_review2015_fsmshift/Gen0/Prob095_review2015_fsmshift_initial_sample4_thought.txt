To implement this module, we need a finite state machine (FSM) that asserts shift_ena for exactly 4 clock cycles after reset is asserted. The FSM will have 5 states:
1. RESET state (initial state) where shift_ena is asserted
2. COUNT1 state where shift_ena is asserted
3. COUNT2 state where shift_ena is asserted
4. COUNT3 state where shift_ena is asserted
5. DONE state where shift_ena remains 0 until next reset

The FSM transitions through these states sequentially on each clock cycle when reset is active. Once in DONE state, it stays there until reset is asserted again.
