To implement this module, we need a finite state machine (FSM) that controls the shift_ena signal. The FSM will have two states:
1. ACTIVE: where shift_ena is asserted for exactly 4 clock cycles after reset
2. IDLE: where shift_ena remains 0 until next reset

We'll use a 2-bit counter to count the 4 cycles in ACTIVE state before transitioning to IDLE. The counter resets to 0 when the FSM is reset.
