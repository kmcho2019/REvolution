To implement this module, we need a finite state machine (FSM) that asserts shift_ena for exactly 4 clock cycles after reset is asserted. The FSM will have 5 states:
1. RESET state (initial state) - shift_ena is 1
2. COUNT1 state - shift_ena is 1
3. COUNT2 state - shift_ena is 1
4. COUNT3 state - shift_ena is 1
5. DONE state - shift_ena is 0 (stays here until next reset)

The FSM transitions through these states sequentially on each clock edge when reset is not active. When reset is active, it goes back to the RESET state.
