Simplified solution using a 2-bit counter:
1. Use a 2-bit counter to count exactly 4 cycles (0-3)
2. Reset behavior:
   - On reset, clear counter
   - shift_ena goes high (first cycle)
3. Normal operation:
   - Increment counter each cycle while it's less than 3
4. Output logic:
   - shift_ena is high when counter hasn't reached 3 yet
   - Automatically stops after 4 cycles (counts 0,1,2,3)
5. Simplifications:
   - Removed done flag - counter value alone determines shift_ena
   - Cleaner reset handling
   - Fewer states and simpler logic
