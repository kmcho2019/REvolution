Simplified design approach:
1. Use a 2-bit counter (0-3) since we only need to count 4 cycles
2. shift_ena is high when counter is counting (0-3) and reset is not active
3. After reaching count 3, counter stops and shift_ena stays low
4. Reset synchronously restarts the counter at 0
5. No need for additional flags - counter value alone determines shift_ena

Key simplifications:
- Eliminated separate output logic condition
- Directly use counter value for shift_ena
- Maintains all functional requirements with minimal logic
