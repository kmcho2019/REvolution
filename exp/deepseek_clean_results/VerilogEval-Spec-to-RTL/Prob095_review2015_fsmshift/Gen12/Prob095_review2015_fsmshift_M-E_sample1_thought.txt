Novel approach using a down-counter with load:
1. Instead of using a state machine, implement a simple down-counter
2. Initialize counter to 4 on reset (active high synchronous)
3. Decrement counter each clock cycle while not zero
4. shift_ena is asserted whenever counter is non-zero
5. Automatically stops after exactly 4 cycles (4->3->2->1->0)
6. More compact implementation without explicit state machine
7. Naturally handles the 4-cycle requirement with simpler logic
8. Clear reset behavior: loads 4 and starts counting down immediately
