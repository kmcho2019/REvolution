Here's a novel approach using a down counter instead of a traditional state machine:

1. Instead of using state transitions, we'll use a 2-bit counter to count down from 3 to 0
2. The counter is loaded with 3 on reset (giving us 4 cycles: 3, 2, 1, 0)
3. shift_ena is simply the NOR of all counter bits (active when counter != 0)
4. This approach is more compact than a state machine and naturally counts exactly 4 cycles
5. The counter stops at 0 until next reset, keeping shift_ena low
6. All logic is synchronous to the positive clock edge

Advantages:
- Fewer registers needed (2-bit counter vs 5-bit state)
- Simpler combinational logic for shift_ena
- More intuitive counting behavior
- Easily extensible if cycle count needs to change
