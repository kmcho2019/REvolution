Instead of using a direct combinational logic implementation, we can create a more robust solution that:
1. Uses sequential elements for better noise immunity
2. Implements a pseudo-dynamic logic style for potential power savings
3. Provides built-in testability with a scan flip-flop approach
4. Includes optional output buffering for better drive strength

The implementation will:
- Use a D flip-flop to sample the NOR result
- Include a clear signal for initialization
- Have an optional output buffer (commented out by default)
- Maintain the same interface while offering these additional features
