The original implementation uses a gate-level primitive (`nor`). We can refactor this to use a continuous assignment with the logical NOR operator (`|`). This approach:

1. Maintains identical functionality while using a different coding style
2. Makes the code more consistent with modern RTL practices where continuous assignments are preferred over gate-level primitives
3. Potentially improves readability for designers more familiar with operator-based expressions
4. Still synthesizes to the same basic gate structure (NOR) in any modern synthesis tool

The refactored version will use an `assign` statement with the logical OR operator followed by negation, which is equivalent to a NOR operation.
