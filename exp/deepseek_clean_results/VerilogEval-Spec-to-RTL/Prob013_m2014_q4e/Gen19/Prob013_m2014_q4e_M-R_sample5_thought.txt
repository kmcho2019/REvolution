Refactored approach using direct NOR operation:

1. Instead of using nested ternary operators, implement the NOR gate using a single logical operation
2. This is more efficient because:
   - It directly represents the NOR function (NOT OR)
   - Uses only one logical operation instead of conditional evaluations
   - Maps directly to standard cell libraries
   - Reduces logic levels for better timing
3. The implementation is functionally identical but more optimal for PPA
4. Benefits:
   - Clearer intent (directly shows NOR operation)
   - Better timing (single operation)
   - Lower power (less switching activity)
   - Smaller area (single gate implementation)
