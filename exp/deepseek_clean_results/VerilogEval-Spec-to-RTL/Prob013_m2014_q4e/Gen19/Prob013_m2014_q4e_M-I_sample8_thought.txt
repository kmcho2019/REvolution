Optimization strategy for better PPA metrics:
1. **Direct Gate Implementation**: Replace LUT-style case statement with a single NOR operation to reduce logic levels and improve timing.
2. **Simpler Logic**: Use continuous assignment for combinational logic instead of procedural blocks to enable more straightforward synthesis.
3. **Remove Redundancy**: Eliminate the default case since all input combinations are covered by the NOR operation.
4. **Power Efficiency**: Single operation reduces switching activity compared to multiplexer-based implementation.
5. **Area Reduction**: NOR operation requires fewer gates than a 4:1 mux implementation.

This approach will:
- Improve timing by reducing critical path length
- Reduce power consumption through simpler logic
- Minimize area by using fewer logic elements
- Maintain identical functionality while being more efficient
