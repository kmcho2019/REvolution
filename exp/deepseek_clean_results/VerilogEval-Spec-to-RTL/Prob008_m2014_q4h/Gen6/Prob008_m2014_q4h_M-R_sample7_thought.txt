The original solution uses a continuous assignment (assign statement) which is already optimal for this simple combinational logic. For refactoring purposes, I'll demonstrate an alternative implementation using:
1. An always block with sensitivity to the input
2. A reg type for the output (though functionally equivalent to wire in this case)
3. Explicit procedural assignment

This shows a different coding style while maintaining identical functionality. The refactored version demonstrates:
- Procedural assignment instead of continuous assignment
- Use of always block sensitivity list
- Different but equivalent output declaration
The PPA metrics remain identical since synthesis will produce the same hardware.
