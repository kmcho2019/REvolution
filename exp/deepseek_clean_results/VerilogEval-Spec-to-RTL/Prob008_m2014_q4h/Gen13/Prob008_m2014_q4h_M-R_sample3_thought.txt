The original implementation is already optimal, but we can demonstrate alternative Verilog coding styles that achieve the same functionality. Here are three equivalent implementations:

1. Using continuous assignment (original)
2. Using procedural assignment in an always block
3. Using gate-level instantiation (though this would be overkill)

The second approach using always block is functionally identical but uses different Verilog syntax. Key differences:
- Uses procedural assignment (=) instead of continuous assignment
- Requires sensitivity list
- Still combinational (no registers)
- Same PPA characteristics
- More verbose for this simple case
