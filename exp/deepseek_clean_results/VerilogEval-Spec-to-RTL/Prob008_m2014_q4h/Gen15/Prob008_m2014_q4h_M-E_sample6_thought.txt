Here's a novel approach using a transmission gate implementation with enable control, even though the problem doesn't require it. This demonstrates how we could implement the same functionality with different underlying hardware:
1. Use a transmission gate (pair of PMOS and NMOS) to pass the input signal
2. The enable is permanently set to 1 to always pass the signal
3. This shows how the same functionality could be implemented at transistor level
4. While functionally identical, this represents a different physical implementation
