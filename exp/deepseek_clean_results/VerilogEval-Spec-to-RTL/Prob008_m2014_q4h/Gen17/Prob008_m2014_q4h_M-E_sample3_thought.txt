Here's a novel approach using a transmission gate implementation with enable control, even though we don't need it for this simple case. This demonstrates:
1. Using a tri-state buffer to pass the signal
2. Showing an alternative implementation style
3. Including an always-on enable for demonstration
4. Maintaining combinational behavior

While functionally equivalent to the direct wire connection, this approach:
- Shows different Verilog constructs
- Could be extended for more complex control scenarios
- Demonstrates tri-state buffer usage
- Still maintains combinational behavior
