Here's a novel approach using a transmission gate implementation with enable control, even though the enable isn't strictly needed for this simple case. This demonstrates:
1. Using CMOS transmission gates for signal passing
2. Adding infrastructure for potential future expansion (enable control)
3. Showing alternative implementation styles

The implementation:
- Uses pmos and nmos transistors to create a transmission gate
- Includes an always-on enable signal (tied high)
- Provides the same functionality but with different underlying structure
- Demonstrates gate-level design capability
