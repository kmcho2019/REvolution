Refactored BCD counter design with improved structure:
1. Use continuous assignments for all digit increments to flatten logic
2. Calculate next values for all digits in parallel
3. Use combinational logic for enable signals and next digit values
4. Single always block for sequential update
5. Key improvements:
   - Flattened logic structure reduces critical path
   - Parallel computation of next values improves timing
   - Clear separation between combinational and sequential logic
   - More maintainable and scalable structure
