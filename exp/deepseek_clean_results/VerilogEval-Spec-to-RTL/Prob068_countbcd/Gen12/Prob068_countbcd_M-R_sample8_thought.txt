Refactored design approach:
1. Use a single 16-bit register for all digits instead of separate 4-bit registers
2. Implement increment logic using arithmetic operations with overflow detection
3. Generate enable signals using combinational logic on the current counter value
4. Maintain synchronous reset functionality
Key improvements:
- Reduced area by using a single register
- Simplified increment logic using arithmetic
- More concise code structure
- Maintain same functionality while being more efficient
