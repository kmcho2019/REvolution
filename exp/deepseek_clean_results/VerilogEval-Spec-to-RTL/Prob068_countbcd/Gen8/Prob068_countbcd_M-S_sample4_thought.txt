Simplified BCD counter design:
1. Use a single 16-bit register for all digits (more compact)
2. Generate enable signals directly from digit values without chaining
3. Implement digit increment logic in a cleaner way:
   - Always increment ones digit
   - Higher digits only increment when lower digits are 9 and being cleared
4. Reset clears all digits simultaneously
5. Enable signals are simply when lower digits equal 9 (no chained dependencies)
Key improvements:
- Eliminates chained enable logic for better timing
- Simpler increment conditions
- More straightforward enable generation
- Maintains same functionality with less logic
