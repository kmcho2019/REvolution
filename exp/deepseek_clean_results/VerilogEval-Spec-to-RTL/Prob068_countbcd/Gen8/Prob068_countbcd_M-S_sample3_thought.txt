To simplify the 4-digit BCD counter:
1. Use a single 16-bit register for all digits instead of separate registers
2. Implement digit-wise increment with overflow handling:
   - Increment ones digit (q[3:0]) each cycle
   - When a digit reaches 10, reset it to 0 and increment next higher digit
3. Generate enable signals by detecting when each digit is 9 and all lower digits are 9
4. Maintain synchronous reset functionality
This reduces register count and simplifies the control logic while preserving the same behavior.
