Simplified BCD counter design:
1. Use a single 16-bit register for all digits (more compact)
2. Generate enable signals based on current digit values only
3. Implement digit increment logic in a cascaded fashion:
   - Always increment ones digit
   - Higher digits increment only when lower digits roll over
4. Reset clears all digits simultaneously
5. Enable signals are simply the rollover conditions of each digit
Key simplifications:
- Remove chained enable dependencies (ena[1] no longer depends on ena[0])
- Simpler combinational logic for enable generation
- More straightforward increment logic
- Same functionality with reduced complexity
