Novel pipelined BCD counter design:
1. Use separate registers for each digit to enable parallel processing
2. Implement a 2-stage pipeline to break the critical path:
   - Stage 1: Calculate current digit values and rollover conditions
   - Stage 2: Update digit values based on rollovers
3. Generate enable signals in parallel using current digit values
4. Use synchronous reset for all digit registers
Key advantages:
- Pipelining improves timing by breaking the long combinational path
- Parallel enable generation reduces dependency chains
- Separate registers allow for better power gating opportunities
- More scalable for higher digit counts
