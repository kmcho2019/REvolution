Novel approach using a hierarchical counter structure:
1. Implement each BCD digit as a separate 4-bit counter module
2. Use a ripple-carry enable scheme between digits
3. Each digit module handles its own rollover and generates its own enable
4. Main module instantiates and connects the digit modules hierarchically
5. This modular approach improves readability and allows for easier scaling
6. Synchronous reset propagates through all digit modules
