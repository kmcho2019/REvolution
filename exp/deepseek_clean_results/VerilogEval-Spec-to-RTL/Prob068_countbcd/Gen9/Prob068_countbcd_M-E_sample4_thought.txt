Novel approach using a hierarchical counter structure:
1. Implement a 16-bit counter as four separate 4-bit BCD counters (digits)
2. Use a ripple-carry approach between digits for simpler logic
3. Generate enable signals based on current digit values and carry-in
4. Each digit has its own increment logic with rollover
5. Synchronous reset clears all digits simultaneously
6. Optimized for minimal logic depth between digits
