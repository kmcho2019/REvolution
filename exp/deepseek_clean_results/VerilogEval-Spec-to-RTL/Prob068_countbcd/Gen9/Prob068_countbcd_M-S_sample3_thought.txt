Simplified approach focusing on sequential carry propagation:
1. Implement a basic 4-bit BCD counter for each digit (ones, tens, hundreds, thousands)
2. Use simple overflow detection (digit == 9) for each counter
3. Generate enable signals sequentially - each higher digit only increments when lower digits overflow
4. Reset all digits synchronously to 0
5. Combine all digits into the 16-bit output
6. This approach reduces logic complexity by using sequential enable generation rather than parallel
