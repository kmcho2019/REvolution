Novel architectural approach: Hierarchical Counter with Pre-computed Rollover
1. Instead of cascading enable signals, implement independent counters for each digit with pre-computed rollover conditions
2. Use a lookahead technique to determine when each digit should increment in parallel
3. Implement a synchronous reset that clears all counters simultaneously
4. Generate enable signals based on the current digit values and their rollover status
5. This approach reduces dependency chains and improves timing by evaluating conditions in parallel

Key benefits:
- Parallel evaluation eliminates cascaded enable logic critical path
- Each digit's increment condition is computed independently
- Clear separation between digit counting and enable generation
- More scalable for wider counters
