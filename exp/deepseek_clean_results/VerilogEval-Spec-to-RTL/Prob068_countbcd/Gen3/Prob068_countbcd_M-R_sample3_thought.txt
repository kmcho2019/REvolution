Refactoring Strategy:
1. Replace the sequential always blocks with combinational logic for digit updates using assign statements
2. Use a single 16-bit register to store all digits, reducing area overhead
3. Implement enable signals with parallel evaluation to break the ripple dependency
4. Maintain synchronous reset functionality
5. Optimize the increment logic by using bitwise operations and ternary operators

Key Improvements:
- Single register reduces area
- Parallel enable evaluation improves timing
- Combinational logic for updates simplifies the design
- Clear separation between register and update logic
- Maintains same functionality with better PPA characteristics
