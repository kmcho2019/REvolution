Simplified BCD counter design:
1. Maintain same 4-digit BCD structure but optimize enable logic
2. Instead of cascaded ANDs for enable signals, compute each enable independently based on digit values
3. Keep synchronous reset but simplify increment logic
4. Each digit increments when previous digit rolls over (==9)
5. Enable signals are simply the rollover conditions of previous digits
6. Combine digit updates into single always block for cleaner code
