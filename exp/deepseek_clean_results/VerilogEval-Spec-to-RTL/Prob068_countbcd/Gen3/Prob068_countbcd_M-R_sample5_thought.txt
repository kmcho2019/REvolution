Refactored design approach:
1. Use a single 16-bit register for all digits instead of separate registers
2. Implement BCD increment as a combinational function operating on the entire 16-bit value
3. Generate enable signals by detecting when each digit reaches 9
4. Use a single always block for synchronous operations
5. Key improvements:
   - Reduced register count (single 16-bit vs four 4-bit)
   - Parallel digit increment logic
   - More compact enable signal generation
   - Clearer separation between combinational and sequential logic
