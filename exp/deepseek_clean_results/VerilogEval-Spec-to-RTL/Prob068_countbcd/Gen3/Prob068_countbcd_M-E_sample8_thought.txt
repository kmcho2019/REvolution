Novel approach using parallel digit processing and state machine:
1. Implement a finite state machine that tracks which digits need incrementing
2. Process all digits in parallel rather than cascading
3. Use a 'carry' vector to propagate rollovers between digits
4. Generate enable signals based on current digit values and carry conditions
5. Optimize timing by breaking the long combinational path of cascaded enables
6. Reduce power by only updating digits that actually need to change
