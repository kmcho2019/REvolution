Refactored design approach:
1. Use a single 16-bit register for all digits instead of separate 4-bit registers
2. Implement digit increment logic using arithmetic operations with overflow detection
3. Generate enable signals by detecting when each digit reaches 9 (before increment)
4. Use continuous assignments for cleaner combinational logic
5. Maintain synchronous reset functionality

Key improvements:
- Single register reduces area
- Arithmetic-based overflow detection simplifies logic
- Continuous assignments make timing more predictable
- Reduced nesting improves readability and timing
