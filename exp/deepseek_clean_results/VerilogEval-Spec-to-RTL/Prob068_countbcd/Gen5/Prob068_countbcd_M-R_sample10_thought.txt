Refactored design with these improvements:
1. Use a single 16-bit register for all digits instead of separate 4-bit registers
2. Simplify the increment logic using arithmetic operations with overflow detection
3. Generate enable signals using combinational logic based on current count value
4. Maintain synchronous reset functionality
5. The key optimization is using arithmetic comparison for overflow detection rather than nested if-else

Benefits:
- Reduced area by using single register
- Simplified control logic
- More maintainable code structure
- Better timing due to flattened logic
