To simplify the 4-digit BCD counter:
1. Use a single 16-bit register for all digits instead of separate registers
2. Implement digit increment logic sequentially:
   - Always increment ones digit
   - Check and handle overflow for each digit in sequence
3. Generate enable signals based on current digit values:
   - ena[0] when ones digit is 9
   - ena[1] when both ones and tens digits are 9
   - ena[2] when ones, tens, and hundreds digits are 9
4. Maintain synchronous reset functionality
This reduces register count and simplifies the control logic while keeping the same behavior.
