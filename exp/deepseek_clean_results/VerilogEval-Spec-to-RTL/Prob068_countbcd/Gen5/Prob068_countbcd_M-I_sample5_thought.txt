Improvement Strategy:
1. Timing Optimization:
   - Parallelize enable signal generation by computing each digit's rollover independently
   - Use direct comparison for enable signals rather than cascaded ANDs
   - Break critical path by registering intermediate enable signals

2. Area Optimization:
   - Share common increment logic across digits
   - Use parameterized width for consistent digit handling
   - Simplify reset logic

3. Power Optimization:
   - Only update digits when their enable is active
   - Use clock gating for stable digits (not shown in this RTL)

Key Changes:
- Separate rollover detection from enable generation
- Unified digit increment logic
- Registered enable signals to break timing path
