Refactored design approach:

2. Use a single expression for each digit's next value to reduce logic levels
3. Simplify enable signal generation by directly using the rollover conditions
4. Maintain the same synchronous reset behavior but implement it purely with assignments

- Combined the reset and increment logic into single expressions per digit
- Simplified the enable signal logic by removing intermediate wires
- Maintained the same functionality while potentially reducing logic levels
