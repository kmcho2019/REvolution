Novel approach using parallel digit processing with carry lookahead:
1. Implement each BCD digit as a separate 4-bit counter with individual enable signals
2. Use a carry lookahead technique to precompute all digit enables in parallel
3. Generate next counter values using simple 4-bit incrementers with overflow detection
4. This approach:
   - Eliminates nested if-else chains for better timing
   - Processes all digits in parallel for higher performance
   - Makes enable signals purely combinational from current state
   - Maintains clean synchronous reset
5. The enable signals are generated by checking each digit's max value independently
