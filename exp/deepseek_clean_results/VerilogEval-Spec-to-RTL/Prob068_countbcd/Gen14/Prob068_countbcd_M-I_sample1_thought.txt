Improvement strategy for better PPA:
1. Timing Optimization:
   - Break the chained enable logic to reduce critical path
   - Use parallel comparison for each digit's rollover condition
   - Implement pipelined enable signals to relax timing constraints

2. Power Optimization:
   - Add clock gating for higher digits when not incrementing
   - Only evaluate digit increments when needed (conditional logic)

3. Area Optimization:
   - Share comparator logic between digits
   - Use a single adder with multiplexing for digit increments

Key changes:
- Parallel enable generation instead of chained
- Clock gating for higher digits
- Shared comparator logic
- Simplified increment logic structure
