Novel approach using a finite state machine (FSM) with state encoding optimization:
1. Represent the counter as an FSM with 10,000 states (0000-9999)
2. Use one-hot encoding for each BCD digit to simplify comparison logic
3. Implement parallel digit increment logic using priority encoders
4. Use a shared incrementer for all digits to reduce area
5. Generate enable signals by detecting digit transitions from 9 to 0
6. Optimize reset handling by using a dedicated reset state
