Novel approach using separate digit counters with ripple-carry enables:
1. Implement four independent 4-bit BCD counters for each digit
2. Use cascaded enable signals between digits (ones->tens->hundreds->thousands)
3. Generate output enable signals based on digit values and carry propagation
4. This architecture provides:
   - Clear separation between digit counters
   - Natural ripple-carry behavior
   - Reduced combinatorial logic depth
   - Easier timing closure
   - Better power gating opportunities
5. The synchronous reset clears all digit counters simultaneously
