3. Generate enable signals combinatorially based on digit values
4. Key improvements:

   - Reduces hierarchical boundaries for better synthesis
   - Makes enable logic more explicit and centralized
   - Maintains same functionality with cleaner structure
5. Still maintains synchronous reset and positive-edge triggered behavior
