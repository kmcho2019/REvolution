Innovative single-counter architecture with digit extraction:
1. Use a single 16-bit binary counter instead of separate BCD counters
2. Extract BCD digits mathematically from the binary value
3. Generate enable signals by comparing current and previous digit values
4. Advantages:
   - Eliminates cascaded enable paths (better timing)
   - Single counter reduces area
   - Mathematical digit extraction simplifies logic
   - Enable generation only when digits actually change
5. Key features:
   - Synchronous reset
   - Edge detection for enable signals
   - Efficient digit extraction using modulus
   - Only updates digit values when they change
