Optimization strategy for better PPA:
1. Pipeline the enable signals to break the critical path (improves timing)
2. Implement clock gating for enable signals to reduce power consumption
3. Use shared adder logic with multiplexers to reduce area
4. Add register retiming to balance pipeline stages
5. Optimize the reset logic to minimize fanout
6. Use hierarchical carry logic for the counter to improve timing
7. Implement conditional increment logic to reduce switching activity

Key improvements:
- Registered enable signals break the combinational path
- Clock gating reduces power when digits aren't changing
- Shared adder reduces area
- Balanced pipeline improves timing slack
- Conditional updates reduce power
