Simplified BCD counter design:
1. Use a single 16-bit register for all digits (more compact than separate registers)
2. Generate enable signals directly from digit values without cascading
3. Implement digit increment logic in parallel for better timing
4. Reset clears all digits simultaneously
5. Enable signals are simply when lower digit equals 9 (rollover condition)

Key simplifications:
- Remove cascaded enable logic (ena[1] no longer depends on ena[0], etc.)
- Parallel digit increment logic
- Clear, straightforward conditions for each digit
- Maintain same functionality with less logic
