Novel pipelined BCD counter design:
1. Use separate 4-bit registers for each digit to enable parallel processing
2. Implement a 2-stage pipeline to break the critical path:
   - Stage 1: Calculate current digit values and rollover conditions
   - Stage 2: Update digit values based on rollovers
3. Generate enable signals in parallel using current digit values
4. Use a state machine approach for clean digit updates
5. Advantages:
   - Better timing due to pipeline stages
   - Parallel enable generation reduces combinational path
   - Clear separation of calculation and update phases
   - Easier to scale to more digits
