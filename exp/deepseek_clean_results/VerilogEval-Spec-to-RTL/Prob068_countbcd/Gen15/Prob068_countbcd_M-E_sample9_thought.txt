Novel architectural idea: "Parallel Precompute with Lookahead Enable"
1. Instead of ripple-carry or sequential enable generation, precompute all digit increments in parallel
2. Use lookahead logic to determine which digits will roll over in the next cycle
3. Implement a unified comparison block that checks all digit conditions simultaneously
4. Use multiplexers to select between increment or reset values for each digit
5. Maintain synchronous reset behavior while optimizing for timing and area

Key advantages:
- All digit updates computed in parallel for better timing
- Enable signals generated through direct combinatorial logic
- No ripple-carry delay between digits
- Clean separation of combinational and sequential logic
- Easily scalable to more digits
