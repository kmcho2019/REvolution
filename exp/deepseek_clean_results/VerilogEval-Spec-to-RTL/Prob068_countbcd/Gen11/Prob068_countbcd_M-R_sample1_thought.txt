Refactored design approach:
1. Split the counter into separate 4-bit registers for each digit to simplify increment logic
2. Use a cascaded enable structure where each digit enables the next higher digit
3. Generate enable signals directly from digit overflow conditions
4. Implement synchronous reset for all digits
5. This structure reduces nesting complexity and makes the digit relationships more explicit
6. Each digit's increment logic is independent but controlled by its enable signal
