Refactored design approach:
1. Use a single 16-bit register for all digits instead of separate 4-bit registers
2. Implement increment logic using arithmetic operations with overflow detection
3. Generate enable signals through combinatorial logic detecting digit boundaries (9->0 transitions)
4. Use continuous assignments for outputs to simplify the design
5. Maintain synchronous reset functionality

Key improvements:
- Single register reduces area
- Arithmetic-based increment simplifies rollover logic
- Combinatorial enable generation reduces critical path
- Clean separation of sequential and combinational logic
