Instead of using nested if-else for digit overflow, implement:
1. A state machine that tracks which digits need incrementing
2. Parallel increment logic for all digits
3. Use a single 16-bit register for all digits
4. Generate enable signals based on current digit values and increment conditions
5. Optimize power by only updating digits that actually change

Key innovations:
- State machine reduces combinatorial path depth
- Parallel increment eliminates cascading delays
- Single register reduces area
- Conditional updates save power
