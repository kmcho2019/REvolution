Novel architectural idea: Shift Register Based BCD Counter with Parallel Enable

Key innovations:
1. Uses a shift register approach where each digit's state is stored in a 4-bit register
2. Implements parallel enable generation using combinational logic that looks at all lower digits simultaneously
3. Employs a unified comparison block that generates all enable signals in one cycle
4. Uses a single always block for all digit updates to minimize sequential logic overhead
5. Optimizes power by only updating digits when their specific enable is active
6. Reduces area by eliminating separate module instantiations and sharing comparison logic

Advantages:
- More compact implementation with fewer registers
- All enable signals generated in parallel from current state
- Single clocked process simplifies timing analysis
- Reduced interconnect between modules
- Better scalability for larger BCD counters
