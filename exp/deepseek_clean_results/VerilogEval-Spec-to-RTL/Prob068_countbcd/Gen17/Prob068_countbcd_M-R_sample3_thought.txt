Refactored design approach:
1. Use a single 16-bit register for all digits (more compact than separate registers)
2. Implement digit increment logic using arithmetic operations instead of nested if-else
3. Generate enable signals using combinational logic based on current digit values
4. Split the logic into:
   - Current value storage (sequential)
   - Next value calculation (combinational)
   - Overflow detection (combinational)
5. Benefits:
   - Flatter logic structure improves timing
   - Single register reduces area
   - Clear separation of combinational and sequential logic
