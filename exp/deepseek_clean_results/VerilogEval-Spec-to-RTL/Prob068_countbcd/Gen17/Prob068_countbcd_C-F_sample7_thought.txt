Optimized BCD counter design combining the best of both approaches:
1. Modular design from Example 2 for better readability and scalability
2. Parallel enable generation from Example 1 to eliminate ripple-carry delay
3. Shared comparison logic to reduce area while maintaining parallel enables
4. Optimized power by only updating digits when needed
5. Simplified thousands digit implementation since it doesn't need rollover
6. Clean hierarchical structure with clear separation of concerns

Key improvements:
- Parallel enable computation avoids critical path from ripple-carry
- Shared comparison logic reduces area while keeping enables parallel
- Modular design maintains readability and scalability
- Power optimization by gating higher digit updates
- Clean interface with proper enable outputs
