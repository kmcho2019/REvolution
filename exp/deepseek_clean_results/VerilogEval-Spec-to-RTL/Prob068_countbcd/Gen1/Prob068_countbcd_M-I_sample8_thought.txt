To optimize the BCD counter for better PPA (Power, Performance, Area):

1. Performance Improvement:
   - Replace cascaded enable conditions with parallel comparison logic to reduce critical path
   - Use separate comparison logic for each digit's rollover condition instead of chaining enables

2. Power Optimization:
   - Maintain the current structure as power is already better than reference
   - Avoid adding complex clock gating which might hurt timing

3. Area Reduction:
   - Share common comparison terms between digit conditions
   - Use more efficient encoding for the enable signals

Key changes:
- Compute each digit's rollover condition independently
- Share the "digit == 9" comparisons between enable and increment logic
- Keep synchronous reset for clean timing
