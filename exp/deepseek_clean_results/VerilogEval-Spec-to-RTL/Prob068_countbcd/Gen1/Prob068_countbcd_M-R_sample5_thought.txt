Refactored design approach:
1. Use a single 16-bit register for all digits instead of separate 4-bit registers to reduce area
2. Implement digit increment logic using combinational assignments for better clarity
3. Generate enable signals using simple rollover detection (digit == 9)
4. Use hierarchical increment logic where higher digits only increment when lower digits roll over
5. Maintain synchronous reset functionality
6. The key optimization is using a unified register and simplifying the enable logic while maintaining the same behavior

Key improvements:
- Reduced area by using single register
- Simplified enable logic by removing cascaded AND gates
- Clearer separation between combinational and sequential logic
- More efficient reset implementation
