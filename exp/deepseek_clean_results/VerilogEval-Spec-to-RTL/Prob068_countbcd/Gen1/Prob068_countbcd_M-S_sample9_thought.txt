To simplify the 4-digit BCD counter:
1. Use a single 16-bit register for all digits instead of separate 4-bit registers
2. Implement synchronous reset that clears the entire register
3. Generate enable signals by checking digit rollovers directly from the register
4. Increment logic:
   - Always increment ones digit (q[3:0])
   - Increment higher digits only when lower digits roll over from 9 to 0
5. Each digit rolls over independently when reaching 9
6. Enable signals are generated combinationally from current digit values

Key simplifications:
- Single register instead of four separate ones
- Direct digit access from register bits
- Simplified enable logic without cascaded dependencies
- More compact code structure
