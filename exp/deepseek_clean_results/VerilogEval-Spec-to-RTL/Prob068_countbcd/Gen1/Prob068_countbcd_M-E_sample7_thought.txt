Novel approach using shift register and state machine:
1. Use a 16-bit shift register to store all digits, with each 4-bit segment representing a digit
2. Implement a state machine with 4 states (IDLE, INC_ONES, INC_TENS, INC_HUNDREDS)
3. The state machine controls when to increment each digit and handles the ripple carry
4. Use a counter to track when to increment the ones digit (instead of every cycle)
5. Generate enable signals based on state transitions
6. Implement synchronous reset that clears all state

Advantages:
- More control over increment timing
- Reduced combinational logic paths
- Easier to pipeline if needed
- Clear separation of digit increment logic
