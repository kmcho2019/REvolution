To implement a 4-digit BCD counter:
1. Use a 16-bit register (q) to store the 4 BCD digits (4 bits each)
2. Implement BCD counting logic for each digit (0-9 rollover)
3. Generate enable signals (ena) for upper digits when lower digits roll over
4. Synchronous reset should clear all digits to 0
5. On each clock edge:
   - If reset is high, clear all digits
   - Else increment the counter with proper BCD rollover logic
   - Generate enable signals when lower digits reach 9 and are about to roll over
