To implement a 4-digit BCD counter:
1. Use a 16-bit register (q) to store the 4 BCD digits (4 bits each)
2. Implement synchronous reset that clears all digits to 0 when reset is high
3. For each digit, increment when:
   - For ones digit (q[3:0]): every clock cycle when not reset
   - For tens digit (q[7:4]): when ones digit rolls over from 9 to 0
   - For hundreds digit (q[11:8]): when tens digit rolls over from 9 to 0
   - For thousands digit (q[15:12]): when hundreds digit rolls over from 9 to 0
4. Generate enable signals (ena) for the upper three digits based on rollover conditions:
   - ena[0] (tens enable) when ones digit rolls over
   - ena[1] (hundreds enable) when tens digit rolls over
   - ena[2] (thousands enable) when hundreds digit rolls over
5. Handle BCD rollover for each digit (reset to 0 after 9 and carry over)
