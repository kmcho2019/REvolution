To implement a 4-digit BCD counter:
1. Use a 16-bit register (q) to store the 4 BCD digits (4 bits each)
2. On each clock edge:
   - If reset is high, clear all digits to 0
   - Else increment the ones digit (q[3:0])
   - If a digit reaches 9, reset it to 0 and generate an enable signal for the next higher digit
   - The enable signals (ena) indicate when tens, hundreds, and thousands digits should increment
3. The ena outputs are combinational logic based on current digit values
