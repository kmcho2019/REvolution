To implement a 4-digit BCD counter with enable signals:
1. Use a 16-bit register (q) to store the 4 BCD digits (4 bits each)
2. For each digit, implement BCD counting logic (0-9 rollover)
3. Generate enable signals (ena) for upper digits when lower digits roll over
4. The ones digit increments every clock cycle (ena[0] always 1)
5. The tens digit increments when ones digit rolls over from 9 to 0 (ena[1])
6. The hundreds digit increments when tens digit rolls over (ena[2])
7. Reset synchronously sets all digits to 0
