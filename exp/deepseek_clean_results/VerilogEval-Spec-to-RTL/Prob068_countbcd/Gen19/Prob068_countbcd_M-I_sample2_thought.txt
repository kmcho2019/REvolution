Optimization strategy for better PPA:
1. Performance: Eliminate ripple effect by making all digit increments synchronous and conditionally enabled
2. Power: Reduce unnecessary switching by only enabling digit increments when needed
3. Area: Consolidate logic into a single always block to share comparison resources
4. Key improvements:
   - Single always block for all digits with conditional increments
   - Shared comparison logic for all digits
   - Synchronous enable signals to avoid ripple timing
   - Reduced redundant switching by only updating digits when needed
   - Simplified thousands digit logic since it never rolls over
