Simplified Design Approach:
1. Use a single always block to handle all digit increments for better readability and reduced module hierarchy
2. Generate enable signals directly within the counter logic without separate modules
3. Each digit increments only when all lower digits are at 9 (BCD max value)
4. Reset all digits to 0 synchronously
5. The enable outputs (ena) simply indicate when each digit is about to roll over
6. This approach reduces module hierarchy while maintaining clear functionality
