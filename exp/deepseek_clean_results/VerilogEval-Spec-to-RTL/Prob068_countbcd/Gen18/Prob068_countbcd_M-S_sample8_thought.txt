Simplified BCD counter design with direct implementation:
1. Eliminate separate digit modules and implement all logic in a single module
2. Use a single always block for all digit updates
3. Generate enable signals directly from digit values
4. Advantages:
   - Reduced module hierarchy improves readability
   - Fewer internal signals and connections
   - More compact implementation
5. Maintain same functionality with synchronous reset
6. Output concatenation remains straightforward
Key simplifications:
- Single always block handles all digit updates
- Enable signals generated directly from digit comparisons
- No intermediate rollover signals needed
