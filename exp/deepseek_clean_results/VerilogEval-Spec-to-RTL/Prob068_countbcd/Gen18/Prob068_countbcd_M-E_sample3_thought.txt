Novel approach using a unified counter with digit extraction:
1. Use a single 16-bit counter instead of separate digit counters
2. Implement BCD behavior by detecting and correcting invalid states (A-F)
3. Extract individual digits through bit manipulation
4. Generate enable signals by comparing current and next digit values
5. This approach reduces area by eliminating redundant digit counters
6. Simplifies timing paths by removing ripple-carry dependencies
7. Uses synchronous reset for all flip-flops
8. Digit extraction and enable generation done in parallel
