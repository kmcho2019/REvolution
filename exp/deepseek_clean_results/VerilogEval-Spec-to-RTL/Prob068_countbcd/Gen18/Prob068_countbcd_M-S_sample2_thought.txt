Simplified BCD counter design with these optimizations:
1. Eliminate separate BCD_Digit module and implement all logic in TopModule
2. Use direct register updates instead of hierarchical enables
3. Simplify enable generation by using sequential logic
4. Maintain parallel comparison logic for critical path
5. Reduce area by removing module instantiation overhead
6. Keep synchronous reset and positive-edge triggered behavior

Key simplifications:
- Single module implementation removes hierarchy
- Direct register updates are more straightforward
- Sequential enable generation is simpler than parallel
- Still maintains correct BCD counting behavior
- Reduced area from fewer modules and simpler logic
