Simplified BCD counter design with direct implementation:
1. Remove hierarchical modules and implement all logic directly in TopModule
2. Use a single always block for all digit counters to reduce overhead
3. Generate enable signals directly from digit values instead of separate rollover logic
4. Maintain same functionality with:
   - Synchronous reset
   - Cascaded digit increments
   - Correct BCD counting (0-9 per digit)
5. Advantages:
   - Reduced module hierarchy improves synthesis
   - Single always block is more compact
   - Eliminates intermediate signals and module instantiations
6. Tradeoffs:
   - Slightly less modular
   - All digit logic in one block
   - Still maintains clear functionality
