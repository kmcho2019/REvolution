The original implementation uses a chain of ternary operators which can create a long critical path. We can improve this by:
1. Using a case statement inside an always block for better readability
2. Making the mapping more explicit and maintainable
3. Potentially allowing synthesis tools to optimize better
4. Still maintaining combinational behavior
5. Using default assignment to handle undefined cases

This approach will:
- Make the code more readable and maintainable
- Allow easier modification of the mapping table
- Potentially improve synthesis results as case statements are well-optimized in most tools
- Still produce purely combinational logic
