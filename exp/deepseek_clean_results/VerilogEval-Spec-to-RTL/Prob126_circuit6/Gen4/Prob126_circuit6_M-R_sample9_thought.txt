The current implementation uses a priority-encoded ternary operator chain. We can optimize this by:
1. Using a case statement inside an always block for better readability and potentially more optimal synthesis
2. Making it explicitly combinational by using always_comb (SystemVerilog)
3. Grouping related constants for better maintainability
4. Removing any priority encoding by using parallel case evaluation

This approach should maintain the same functionality while potentially improving synthesis results and readability.
