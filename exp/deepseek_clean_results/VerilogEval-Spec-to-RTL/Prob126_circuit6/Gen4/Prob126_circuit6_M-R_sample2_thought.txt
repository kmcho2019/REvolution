The current implementation uses a priority-encoded ternary operator chain. We can optimize this by:

1. Using a case statement in an always block for better readability and potentially more efficient synthesis
2. Making all case items explicit (0-7) for clarity
3. Using hexadecimal constants directly in the case items
4. Adding a default case for safety (though theoretically unreachable)

This approach may yield better synthesis results as case statements are often optimized into balanced multiplexer trees rather than priority encoders.
