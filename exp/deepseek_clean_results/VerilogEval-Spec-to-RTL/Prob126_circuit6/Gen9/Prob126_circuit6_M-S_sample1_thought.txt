The current implementation uses a chain of ternary operators which creates a long critical path. We can simplify this by using a case statement inside an always block, which is more readable and typically synthesizes to more efficient logic. The case statement will directly map each input value to its corresponding output value without chaining conditions. This approach:
1. Makes the mapping clearer and more maintainable
2. Potentially improves synthesis results as case statements are well-optimized in synthesis tools
3. Maintains the same combinational behavior
4. Reduces the logical depth compared to the ternary operator chain
