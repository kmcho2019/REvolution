The current implementation uses a chain of ternary operators which creates a priority-encoded structure. We can improve this by:

1. Using a case statement inside an always block for better readability and potentially more optimal synthesis (many tools recognize case statements for LUT implementations)
2. Making all case items explicit (0-7) for clarity
3. Using hexadecimal constants directly in the case items
4. Adding a default case for completeness (though theoretically unreachable for 3-bit input)

This maintains the same functionality while potentially allowing the synthesis tool to implement a more balanced multiplexer structure.
