The simplest implementation would be to use a direct lookup table approach with a case statement inside an always block. This is more readable and maintainable than nested ternary operators, and synthesis tools can optimize it efficiently. The case statement clearly shows all input-output mappings in one place, and the default case handles any unexpected inputs (though with 3-bit inputs, this shouldn't occur).

Key simplifications:
1. Single always block with case statement
2. Clear mapping of all input-output pairs
3. Default case for completeness
4. No complex nested conditional operators
