The current implementation already shows good PPA metrics, but we can potentially improve it further by:

1. Using a case statement instead of nested ternary operators - synthesis tools often optimize case statements more efficiently
2. Removing the default case since the input is a 3-bit signal (0-7) and all cases are covered
3. Using hexadecimal constants directly in the case statement for better readability
4. This approach may lead to:
   - Slightly better power efficiency by reducing comparison logic
   - More consistent synthesis results across different tools
   - Better readability while maintaining the same functionality
