Refactoring Strategy:
1. The current implementation uses nested ternary operators which creates a long multiplexer chain
2. We can improve timing by using a parallel case statement approach with 'assign'
3. This will:
   - Make the code more readable and maintainable
   - Potentially improve timing by allowing parallel evaluation of conditions
   - Still maintain the same combinational behavior
4. The case statement will be implemented using bitwise masking and OR operations
5. Each case will generate a mask that selects the appropriate constant when the input matches
6. The default case is implicitly handled by the final OR operation
