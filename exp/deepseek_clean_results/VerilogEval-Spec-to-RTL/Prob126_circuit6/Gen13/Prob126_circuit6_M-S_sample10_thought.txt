The current implementation uses a chain of ternary operators which creates a long critical path. We can simplify this by using a case statement inside an always block, which is more readable and typically synthesizes to more efficient logic. This approach:
1. Clearly maps each input value to its corresponding output
2. Uses a single always block for all assignments
3. Eliminates the long chain of conditional operators
4. Maintains the same combinational behavior
5. Is more maintainable and easier to modify
