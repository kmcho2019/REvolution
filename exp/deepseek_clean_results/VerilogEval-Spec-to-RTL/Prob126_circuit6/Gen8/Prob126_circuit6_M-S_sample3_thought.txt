The simplest and most efficient way to implement this is to use a direct lookup table since the input-output mapping is fixed and doesn't follow an obvious mathematical pattern. A case statement is cleaner and more readable than a chain of ternary operators, and will synthesize efficiently to a multiplexer or ROM structure.

Key simplifications:
1. Replace ternary operator chain with a case statement
2. Remove unused/commented code
3. Keep only the essential functionality
4. Default case handles undefined inputs (though 3-bit input covers all cases)
