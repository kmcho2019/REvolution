The current solution uses a series of ternary operators which creates a multiplexer structure. We can simplify this by using a direct lookup table approach with a single case statement. This approach:
1. Is more readable and maintainable
2. Clearly shows the input-output mapping
3. Uses fewer logical operations
4. Will synthesize to the same functionality but with potentially better optimization
5. Eliminates the need for a default case since all 3-bit inputs are covered
