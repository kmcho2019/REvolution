To refactor while maintaining the same functionality, I'll implement a ROM-style lookup table approach using a packed array. This offers several advantages:

1. More concise and readable code with all mappings in one place
2. Potential for better synthesis optimization as a ROM structure
3. Clear separation of data (mappings) from logic (lookup)
4. Eliminates the need for default case since input is fully covered
5. Maintains combinational nature while being more maintainable

The approach uses:
- A packed array to store all possible output values
- Simple continuous assignment for the lookup
- No conditional logic needed
- All mappings visible at a glance
