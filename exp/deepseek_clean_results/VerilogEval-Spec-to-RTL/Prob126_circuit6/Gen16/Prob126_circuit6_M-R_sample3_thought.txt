Refactoring Strategy:
1. Replace nested ternary operators with a parallel case statement using 'assign' with bitwise operations for better timing and power characteristics
2. Use bitwise AND with a mask pattern to create a one-hot-like selection of output values
3. Maintain the same functionality while improving:
   - Timing: Parallel evaluation of all cases
   - Power: Only the selected output bits will switch
   - Area: Potentially more efficient synthesis as a parallel mux structure

The new implementation will:
- Use bitwise AND between each possible output and a selector mask
- OR all these masked values together to form the final output
- Be fully combinational with the same input-output mapping
- Have better synthesis characteristics due to parallel evaluation
