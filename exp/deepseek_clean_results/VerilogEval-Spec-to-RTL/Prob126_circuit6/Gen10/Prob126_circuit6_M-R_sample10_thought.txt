The current implementation uses a chain of ternary operators which can create a long critical path. We can refactor this to use a case statement inside an always block, which typically synthesizes to a more balanced multiplexer structure. This approach will:
1. Improve timing by potentially creating a more balanced logic tree
2. Maintain the same combinational behavior
3. Make the mapping more explicit and readable
4. Allow synthesis tools to potentially optimize better for area and power
