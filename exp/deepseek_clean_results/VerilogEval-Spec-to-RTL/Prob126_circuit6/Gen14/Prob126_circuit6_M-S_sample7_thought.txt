Simplification Strategy:
1. The current solution is already quite minimal, using a single continuous assignment with nested ternary operators.
2. To further simplify, we can recognize that this is essentially a lookup table with 8 fixed outputs.
3. The most straightforward implementation would be to use a case statement in an always_comb block, which:
   - Is more readable than nested ternary operators
   - Has equivalent hardware implementation
   - Explicitly shows all cases
   - Is easier to modify if needed
4. This maintains all functionality while improving readability and maintainability.
