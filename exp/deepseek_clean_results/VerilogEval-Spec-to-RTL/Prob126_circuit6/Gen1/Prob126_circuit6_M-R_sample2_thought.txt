The original implementation uses an always block with a case statement. We can refactor this to use continuous assignments with a conditional operator (?:) for each bit of the output. This approach will:
1. Eliminate the need for a procedural block
2. Make each output bit's dependence on the input explicit
3. Potentially improve readability by showing the direct mapping
4. Still maintain the same combinational behavior
