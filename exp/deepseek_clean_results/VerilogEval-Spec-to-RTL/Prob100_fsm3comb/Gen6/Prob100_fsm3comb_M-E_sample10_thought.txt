Here's a novel approach using a lookup table (LUT) style implementation:
1. Pre-compute all possible next_state values based on current state and input
2. Store these in a 4x2 array (4 states x 2 input possibilities)
3. Use the current state and input to index into this array
4. For output, implement a simple decoder that checks for state D (11)

This approach:
- Uses array indexing instead of case statements
- Makes the state transition logic more table-like and potentially more readable
- Could be more efficient in some synthesis scenarios as it directly maps to LUT structures in FPGAs
- Separates the transition logic cleanly from output logic
