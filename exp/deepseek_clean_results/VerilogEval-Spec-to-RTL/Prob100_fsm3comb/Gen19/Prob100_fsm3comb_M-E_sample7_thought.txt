Novel Architectural Idea: 
Instead of using a traditional case statement for state transitions, implement a lookup table (LUT) approach using concatenation and bit masking. This method:
1. Encodes the entire state transition table into a 16-bit LUT (4 states × 2 input conditions × 2 bits per state)
2. Uses the current state and input as an index to select the next state
3. Maintains the same output logic (state == D)
4. Offers potential advantages:
   - More compact representation of the state machine logic
   - Easier modification of state transitions (just change the LUT value)
   - Possible area savings in some synthesis tools
   - Interesting alternative to traditional FSM coding styles
