Refactoring approach:
1. Replace the case statement with parallel ternary operators for next_state logic
2. Maintain the same Moore output logic (simple state comparison)
3. Use continuous assignments for all outputs (both next_state and out)
4. Keep the same state encoding and transition behavior
5. Benefits of this approach:
   - Eliminates the always block, making it purely combinational
   - Parallel assignments may be more synthesis-friendly in some tools
   - Each state transition is explicitly visible in the code
   - Maintains the same PPA characteristics as original

Key changes:
- next_state[1] and next_state[0] are computed separately
- Each bit's logic is derived from the truth table
- Output logic remains identical
