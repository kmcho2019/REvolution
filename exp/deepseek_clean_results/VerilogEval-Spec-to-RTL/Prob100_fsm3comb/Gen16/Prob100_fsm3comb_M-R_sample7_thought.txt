Refactoring Strategy:
1. **Output Logic**: Keep the same continuous assignment since it's efficient for this simple condition (output high only in state D).
2. **State Transition**: Replace the always block with continuous assignments using ternary operators. This eliminates the need for a procedural block while maintaining the same logic.
3. **Direct Encoding**: Use the state encoding directly in the expressions for clarity.
4. **Parallel Logic**: Express next_state bits separately using Boolean expressions derived from the truth table of state transitions.

Benefits:
- Fully combinational implementation without procedural blocks
- More explicit bit-level operations
- Same functionality with different implementation style
- Potentially better synthesis optimization in some tools
