I'll refactor the solution to use continuous assignments (assign statements) instead of an always block. This approach:
1. Eliminates the need for procedural blocks by using pure combinational logic
2. Makes each state transition and output calculation explicit through separate assign statements
3. Maintains the same state encoding and logic functionality
4. Potentially improves readability by showing the direct mapping for each state
5. Uses ternary operators for compact next state logic
6. Keeps the output logic simple with a direct comparison
