To simplify the Moore state machine combinational logic further:
1. The output logic can be reduced to a simple equality check (state == D)
2. The next_state logic can be expressed more concisely by:
   - Using a single always block for both outputs
   - Removing the reg declarations since we can use continuous assignments
   - Using a more compact case statement format
3. The state encoding remains the same (A=00, B=01, C=10, D=11)
4. All cases are explicitly covered, so no default needed
