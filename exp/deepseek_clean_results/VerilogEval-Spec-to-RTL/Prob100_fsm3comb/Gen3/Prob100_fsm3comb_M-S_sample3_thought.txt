The original solution uses a case statement with nested if-else for each state, which is clear but can be simplified. Since the output depends only on the current state (Moore machine), we can separate the output logic from the next state logic. The next state logic can be simplified using a single case statement that combines both state and input bits, treating them as a single 3-bit value (2 state bits + 1 input bit). This reduces the logic depth and makes the code more compact.

1. Combine state and input into a single 3-bit value for case statement
2. Use this combined value to directly determine next_state
3. Separate output logic that only depends on current state
4. Remove redundant default cases since all states are covered
