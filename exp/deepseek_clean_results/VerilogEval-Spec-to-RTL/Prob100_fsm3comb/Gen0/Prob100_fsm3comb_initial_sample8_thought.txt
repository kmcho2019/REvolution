To implement the Moore state machine's combinational logic portion, we need to:
1. Create a case statement that checks the current state (2-bit input 'state')
2. For each state (A, B, C, D), determine the next state based on the input 'in'
3. Assign the output 'out' based solely on the current state (Moore machine property)
4. Use the given state encodings: A=00, B=01, C=10, D=11
5. The output is 1 only when in state D (11), 0 otherwise
