To implement the Moore state machine's combinational logic portion, we need to:
1. Decode the current state (2-bit 'state' input)
2. Determine the next state based on both current state and input 'in'
3. Generate the output based solely on the current state (Moore machine characteristic)
4. Use a case statement to handle each state (A, B, C, D) and nested if-else for input 'in'
5. Assign outputs 'next_state' and 'out' based on the state transition table
