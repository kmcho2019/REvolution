Novel approach using arithmetic operations for state transitions:
1. Instead of case statements, use arithmetic operations to compute next_state
2. Observe that state transitions can be expressed as mathematical functions of current state and input
3. For in=0: next_state = (state + 2'b10) % 4 (rotate left by 1 for states A,B,C)
4. For in=1: next_state = (state == 2'b11) ? 2'b01 : (state | 2'b01) (special handling for state D)
5. Output remains simple: 1 only in state D
6. Benefits include potentially smaller area and unique implementation style
