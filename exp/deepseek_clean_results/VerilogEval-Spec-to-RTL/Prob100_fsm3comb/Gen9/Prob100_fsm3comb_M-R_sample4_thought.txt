Refactoring approach:
1. Use a case statement inside an assign statement to make the state transitions more readable and maintainable
2. Create a helper function (using Verilog's function feature) to compute next_state based on current state and input
3. Keep the output logic simple with a direct assignment as before
4. This approach improves readability by clearly showing state transitions in a table-like format while maintaining combinational logic
5. The function encapsulation makes the state transition logic more modular and easier to modify
