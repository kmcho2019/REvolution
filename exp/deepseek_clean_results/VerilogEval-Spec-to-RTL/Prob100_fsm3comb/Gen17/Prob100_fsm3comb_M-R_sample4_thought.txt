Refactoring approach:
1. Replace the case statement with continuous assignments using ternary operators
2. Break down the next_state logic into individual bit assignments for better readability
3. Maintain the same state encoding and transition logic
4. Keep the output assignment simple as before
5. Advantages of this approach:
   - Eliminates the need for procedural blocks (always)
   - Makes each bit's logic more explicit and potentially easier to optimize
   - Still maintains the same combinational behavior
   - May offer better synthesis results in some tools due to simpler structure
