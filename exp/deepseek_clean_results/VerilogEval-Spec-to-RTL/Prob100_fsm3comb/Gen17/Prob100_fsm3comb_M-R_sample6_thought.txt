Refactoring Approach:
1. **State Transition Logic**: Replace the always block with continuous assignments using ternary operators for each state bit. This makes the state transitions more explicit and potentially more optimization-friendly for synthesis tools.
2. **Output Logic**: Keep the simple continuous assignment for the output since it's already optimal.
3. **State Encoding**: Maintain the same parameterized state encoding for clarity.
4. **Bit-wise Logic**: Express next_state[1] and next_state[0] separately based on current state and input, which can sometimes lead to better optimization.

- Eliminates procedural block in favor of continuous assignments
- Explicitly shows how each next_state bit is calculated
- Maintains identical functionality
- May offer better synthesis optimization opportunities
