Here's a novel approach using a lookup table (LUT) style implementation for the state machine:

1. **LUT-based State Transition**: Instead of cascaded conditionals, we'll use the current state and input to index into a pre-computed next state table. This creates a direct mapping from (state, input) pairs to next states.

2. **Concatenated Indexing**: We'll concatenate the 2-bit state and 1-bit input to form a 3-bit index, allowing us to cover all 8 possible (state, input) combinations.

3. **Output as LUT Entry**: We'll extend the LUT to include the output value, making the output computation part of the same lookup operation.

4. **Parallel Logic**: Both next_state and output are derived from the same lookup operation, potentially reducing logic depth.

Advantages:
- More uniform logic structure
- Easier to modify if state transitions change
- Potentially better synthesis results for some technologies
- Clear separation between control and data
