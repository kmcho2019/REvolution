Novel approach using hierarchical decoding:
1. First decode the current state into individual state signals (is_A, is_B, etc.)
2. Use these decoded signals to create more readable and modular transition logic
3. Compute next_state by OR-ing contributions from each current state
4. This approach makes the state transition rules more explicit and easier to modify
5. Output logic remains simple but now uses the decoded state signals
6. Benefits include better readability and easier debugging of state transitions
