Refactoring Approach:
1. **Use Continuous Assignments**: Replace the always block with direct assign statements for both output and next_state logic. This makes the combinational nature more explicit.
2. **Ternary Operators**: Implement state transitions using nested ternary operators for a more compact representation.
3. **Maintain Readability**: Keep the state parameter definitions and add comments to explain the transition logic.
4. **Remove Default Case**: Since we're using continuous assignments, undefined states will naturally resolve to some value (though in practice, this should be handled in a real design).

Benefits:
- More concise implementation
- Clearly shows the combinational nature of the logic
- Eliminates the need for procedural blocks for simple combinational logic
- Maintains same functionality as original
