Refactoring approach:
1. Replace the case statement with continuous assignments using ternary operators
2. Break down the next_state logic into individual bit calculations
3. Maintain the same state encoding and transition behavior
4. Keep the output logic simple with direct assignment
5. Benefits of this approach:
   - Eliminates the need for procedural blocks (always)
   - Makes each state transition explicit through bit-level logic
   - Potentially better for synthesis as it's purely combinational
   - Easier to see the direct relationship between inputs and outputs
