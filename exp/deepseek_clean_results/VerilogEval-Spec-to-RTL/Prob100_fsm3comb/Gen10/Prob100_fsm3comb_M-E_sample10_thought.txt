Novel approach using arithmetic operations for state transitions:
1. Instead of case statements, use arithmetic operations to compute next_state
2. Observe that state transitions can be expressed as mathematical functions of current state and input
3. For each state, derive a formula that produces the correct next_state based on input
4. Output logic remains simple (state D detection)
5. Benefits include potential area savings from shared arithmetic units and different optimization opportunities
6. This approach leverages the numeric nature of state encodings

Mathematical observations:
- When in=0: A->A (0), B->C (2), C->A (0), D->C (2)
- When in=1: A->B (1), B->B (1), C->D (3), D->B (1)
- Can be expressed as: next_state = (state & {in, ~in}) + ({in, in} & state)
