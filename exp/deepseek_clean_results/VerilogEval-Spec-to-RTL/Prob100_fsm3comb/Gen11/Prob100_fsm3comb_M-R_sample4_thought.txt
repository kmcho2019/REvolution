Refactoring approach:
1. Instead of separate assign statements for each next_state bit, use a single case statement for clearer state transition logic
2. Maintain the same output logic (1 only in state D)
3. Group all state transitions in a case statement that considers both current state and input
4. Use default assignments to ensure all cases are covered
5. This approach makes the state transitions more explicit and easier to verify against the specification
6. The case statement will be more readable and maintainable than the previous AND-OR structure
