Refactoring strategy:
1. Switch from explicit state decoding to a more concise case statement approach for next_state logic
2. Maintain the Moore machine property (output depends only on current state)
3. Use parallel case structure to ensure all states are explicitly covered
4. Keep the output logic minimal (just check for state D)
5. Use continuous assignments for both next_state and output to maintain combinational nature

Key improvements:
- More readable state transition logic using case statement
- Explicit handling of all state transitions in one place
- Reduced intermediate wires (no need for is_A, is_B, etc.)
- Maintains same functionality while being more maintainable
- Synthesis tools can optimize case statements effectively
