Novel approach using a lookup table (LUT) style implementation:
1. Instead of case statements, use a 4-bit concatenation of state and input as an index
2. Create a packed array that encodes all possible state transitions
3. Use bit slicing to extract the next state from the LUT
4. Output remains simple combinational logic based on current state
5. Benefits:
   - More scalable for larger state machines
   - Potentially more area-efficient in some technologies
   - Clear separation of transition rules from control logic
   - Easier to modify transition table if requirements change
6. Implementation uses a parameter for the LUT to make it more maintainable
