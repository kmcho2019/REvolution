Refactoring Strategy:
1. Move combinational logic outside the always block to separate concerns
2. Use continuous assignments for the shift operation
3. Maintain the same priority structure (reset > load > ena)
4. Use a separate always block just for the sequential elements
5. Create intermediate wires for the next state logic

Key Changes:
- Shift operation implemented via assign statement
- Next state logic calculated before the clocked assignment
- Clear separation between combinational and sequential logic
- Same functionality but with potentially better synthesis results

Benefits:
- More modular design with clear separation of combinational and sequential logic
- Potential for better optimization during synthesis
- Easier to modify individual components
- Maintains all original requirements and priorities
