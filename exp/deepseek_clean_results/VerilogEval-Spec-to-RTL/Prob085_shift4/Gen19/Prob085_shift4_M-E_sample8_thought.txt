Novel Pointer-Based Shift Register Architecture:
1. Instead of physically shifting bits, maintain a fixed register and track the "start" position with a pointer
2. Use a 2-bit pointer to indicate where the current q[0] position is in the physical register
3. Physical register remains static during shifts - only the pointer moves
4. Load operations write to all physical registers and reset the pointer
5. Benefits:
   - Eliminates the need for shift operations (no barrel shifter)
   - Only pointer increments during shifts (simpler logic)
   - Physical register only changes during load/reset (lower power)
   - Same functionality but different implementation approach
6. Output is generated by selecting bits based on pointer position
