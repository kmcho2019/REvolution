The design requires a 4-bit shift register with three control signals:
1. Asynchronous reset (areset) to clear the register
2. Synchronous load (load) to parallel load data
3. Synchronous enable (ena) to perform right shift

Priority is given to reset > load > enable. The implementation will use:
- An always block sensitive to posedge clk or posedge areset for sequential logic
- Conditional statements to implement the priority order
- For shift operation, we'll concatenate 1'b0 with the upper 3 bits of current value
