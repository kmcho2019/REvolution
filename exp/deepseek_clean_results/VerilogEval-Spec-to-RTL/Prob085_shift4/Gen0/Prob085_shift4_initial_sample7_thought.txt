To implement a 4-bit shift register with the specified functionality, we need to consider the following:
1. Asynchronous reset (areset) that clears the register to 0 when asserted.
2. Synchronous load operation that takes priority over shift when both load and ena are asserted.
3. Synchronous shift right operation when ena is asserted (without load).
4. The shift operation fills the MSB (q[3]) with 0 and discards the LSB (q[0]).

The design will use an always block triggered by posedge clk or posedge areset. Inside:
- First handle areset (highest priority)
- Then check load condition
- Then check ena condition
- Otherwise maintain current state
