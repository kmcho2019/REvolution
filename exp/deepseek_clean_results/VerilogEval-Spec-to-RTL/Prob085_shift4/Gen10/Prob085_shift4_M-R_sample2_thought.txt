Refactoring Approach:
1. Use continuous assignments (assign) instead of procedural blocks to implement the shift register logic
2. Create combinational logic for next state calculation
3. Use a separate always block just for the register update
4. This separates the combinational and sequential logic clearly
5. The priority logic (reset > load > ena) is implemented in the combinational part

Benefits:
- Clear separation of combinational and sequential logic
- Easier to add additional combinational logic if needed
- Same functionality but with different coding style
- May help with synthesis optimization in some tools
