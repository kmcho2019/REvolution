Refactoring Approach:
1. Use continuous assignments (assign) for combinational logic instead of procedural blocks
2. Separate the synchronous and asynchronous logic into distinct always blocks
3. Create an intermediate next_state signal to clearly show the register's next value
4. Maintain the same priority order (reset > load > ena) but make it more explicit in the logic

Benefits:
- Clear separation of combinational and sequential logic
- More transparent data flow through the next_state signal
- Easier to modify or extend the priority logic if needed
- Maintains same functionality while providing alternative implementation style
