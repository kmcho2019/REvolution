Refactoring Strategy:
1. Use continuous assignments for combinational logic instead of procedural blocks
2. Separate the next-state logic from the register storage
3. Create explicit intermediate signals for next state calculation
4. Maintain same functionality with different implementation style

Key Changes:
- Next state logic moved to continuous assignments
- Register update remains in always block
- Priority handling implemented through conditional operators
- Clear separation between combinational and sequential logic

Benefits:
- More explicit data flow
- Easier to add additional combinational logic if needed
- Potential for better synthesis optimization in some tools
- Maintains same timing/power characteristics
