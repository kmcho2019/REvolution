This refactoring maintains the same functionality but restructures the implementation to:
1. Use continuous assignments for the next-state logic instead of procedural blocks
2. Explicitly show the priority hierarchy through logical conditions
3. Eliminate the intermediate 'sel' wire by directly using the control signals
4. Keep the same reset behavior but express the shift operation more directly
5. Potentially improve timing by reducing logic levels in the critical path

The key changes are:
- Using a wire for the next state value
- Expressing the priority logic as a series of ternary conditions
- Maintaining the same reset and clocking behavior
- The shift operation is now more explicitly shown as a concatenation
