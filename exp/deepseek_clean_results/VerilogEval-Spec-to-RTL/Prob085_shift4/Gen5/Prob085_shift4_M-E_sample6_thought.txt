This solution implements the shift register using a finite state machine approach with explicit state encoding. The key innovations are:
1. Uses a 3-state FSM (IDLE, LOAD, SHIFT) to manage operations
2. Explicit state transitions make the priority rules very clear
3. The FSM naturally handles the priority order (reset > load > ena)
4. Each operation has its own dedicated state for cleaner implementation
5. The shift operation is implemented using arithmetic right shift with zero fill
6. The FSM approach may offer better timing characteristics as it breaks down the control logic into discrete steps

This method provides a more structured control flow and could potentially offer better timing closure in some synthesis scenarios.
