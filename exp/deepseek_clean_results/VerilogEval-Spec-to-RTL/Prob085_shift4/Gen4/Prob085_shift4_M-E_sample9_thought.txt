This solution implements the shift register using a single multiplexer structure that explicitly encodes the priority rules. The key innovations are:
1. Uses a 4:1 multiplexer with priority-encoded select lines
2. The select logic combines inputs to create mutually exclusive cases
3. Implements the priority order (reset > load > ena) through logical combinations
4. The shift operation is implemented using concatenation with zero-fill
5. Maintains the same functionality while potentially offering better synthesis optimization opportunities

The approach eliminates nested conditionals and may result in more balanced timing paths.
