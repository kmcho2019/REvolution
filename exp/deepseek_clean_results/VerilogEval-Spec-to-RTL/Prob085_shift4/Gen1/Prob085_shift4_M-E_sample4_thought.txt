Instead of physically shifting bits, we can implement a circular buffer with a pointer that tracks the "start" position. This approach:
1. Uses a 4-bit register to store values and a 2-bit pointer to track the virtual start position
2. For load operations: resets pointer to 0 and loads data normally
3. For shift operations: increments the pointer (with wrap-around) and clears the new "end" position
4. Output is generated by rotating the register contents based on the pointer
5. Asynchronous reset clears both register and pointer

Benefits:
- No physical shifting of bits (only pointer increment)
- Constant-time shift operation regardless of width
- Potential power savings since only one bit changes per shift
