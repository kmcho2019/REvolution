Instead of using direct sequential logic with priority conditions, we can implement the shift register as a finite state machine with explicit state transitions. This approach:
1. Uses a 2-bit state register to track the current operation (idle, load, shift)
2. Separates the control logic from the data path
3. Makes the priority handling more explicit through state transitions
4. Could potentially offer better timing characteristics by breaking down the critical path

The state machine will have these transitions:
- Reset always takes priority and goes to idle state
- Load has higher priority than enable when both are active
- Enable only triggers shift when in idle state
