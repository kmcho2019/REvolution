Refactoring Strategy:
1. Separate combinational and sequential logic for clearer structure
2. Use continuous assignments for the next-state logic
3. Keep the same priority scheme (reset > load > ena) but implement it through explicit combinational logic
4. Use a dedicated always block just for the sequential element (flip-flops)
5. Maintain all original functionality while potentially improving readability

Key Changes:
- Next-state logic moved to continuous assignments
- Flip-flop implementation isolated in its own always block
- Same priority scheme preserved through combinational logic
- Shift operation still implemented efficiently with bit concatenation

Benefits:
- Clear separation of combinational and sequential logic
- Easier to modify control logic independently
- Same timing characteristics (since synthesis will produce similar hardware)
- More modular structure
