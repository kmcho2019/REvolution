Simplification Strategy:
1. Remove intermediate control signals (shift_enable, ctrl) and directly use input signals in the logic
2. Implement priority handling through if-else cascade instead of case statement
3. Maintain same functionality with simpler structure:
   - Async reset has highest priority
   - Load has priority over enable
   - Shift operation when enabled
   - Default hold state

Key Benefits:
- Eliminates unnecessary wire declarations
- Simpler control flow that's easier to understand
- Reduced gate count by removing intermediate logic
- Maintains all original functionality
