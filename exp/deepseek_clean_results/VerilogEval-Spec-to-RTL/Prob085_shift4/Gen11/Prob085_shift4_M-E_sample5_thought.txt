Instead of using traditional shift operations, I'll implement a circular buffer with a write pointer. This approach offers several advantages:
1. Eliminates the need for shifting operations, reducing combinational logic
2. Uses pointer arithmetic which can be more efficient in some architectures
3. Provides a foundation for potential future extensions (like variable shift amounts)
4. The load operation becomes a simple parallel write to all positions

The design will:
- Maintain a 4-bit register and a 2-bit pointer (since log2(4) = 2)
- On reset: Clear both register and pointer
- On load: Overwrite all register bits and reset pointer
- On enable: Just increment the pointer (wrapping around) without shifting data
- The output is selected based on the pointer position
