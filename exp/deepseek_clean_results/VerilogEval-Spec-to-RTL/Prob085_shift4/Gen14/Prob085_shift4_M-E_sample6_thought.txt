Novel Architecture Idea:

2. Implement the shift operation using a barrel shifter approach for potential area optimization
3. Separate the control logic from the data path for better synthesis optimization
4. Use a case statement for clear priority handling
5. Optimize the shift operation by pre-computing all possible next states

- Barrel-shifter inspired right shift implementation
- Separation of control and data path
