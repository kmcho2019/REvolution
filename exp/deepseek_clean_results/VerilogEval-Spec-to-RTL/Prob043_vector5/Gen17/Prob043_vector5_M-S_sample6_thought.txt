The original solution uses a concatenation of all 25 pairwise comparisons, which is already quite compact. However, we can simplify it further by:
1. Recognizing that the XNOR operation is commutative (a~^b == b~^a)
2. Observing that the self-comparisons (a~^a, b~^b, etc.) always evaluate to 1
3. Using a more systematic naming pattern for the comparisons

This allows us to reduce the number of explicit comparisons while maintaining the same functionality. The self-comparisons can be hardcoded as 1's, and we only need to compute each unique pair once.
