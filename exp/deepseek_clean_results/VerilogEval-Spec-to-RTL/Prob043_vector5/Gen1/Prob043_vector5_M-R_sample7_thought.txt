The original implementation uses 25 separate assign statements for each pairwise comparison. While correct, we can make the code more compact and maintainable by using a generate block with nested loops to create all the comparisons programmatically. This approach:
1. Uses two nested loops to iterate through all pairs of inputs
2. Creates a flattened index for the output vector
3. Maintains the exact same functionality while reducing code duplication
4. Makes it easier to modify if the number of inputs changes
5. Still synthesizes to the same hardware structure
