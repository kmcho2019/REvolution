The original solution uses 25 separate assignments for each pairwise comparison. We can simplify this by:
1. Recognizing that the comparisons follow a predictable pattern (each input compared with all inputs in order)
2. Using a more compact representation with concatenation and replication
3. Grouping the comparisons by the first operand to make the pattern clearer
4. Using the XNOR operator directly instead of ~^ for better readability
This reduces the code size while maintaining the same functionality.
