The original solution uses nested concatenation with explicit XNOR operations. We can refactor this by:
1. Using a generate-for loop to systematically create all 25 comparisons
2. Creating an array of the input signals for easier indexing
3. Using two nested loops to generate the row-column pattern of comparisons
4. Maintaining the same order of outputs (a-a to a-e, then b-a to b-e, etc.)
This approach makes the pattern more explicit and scalable, while producing identical functionality.
