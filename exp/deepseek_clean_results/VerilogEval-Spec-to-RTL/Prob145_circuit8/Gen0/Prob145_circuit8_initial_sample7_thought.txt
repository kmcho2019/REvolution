From analyzing the waveform, we can observe the following behavior:
1. Output p is the value of input 'a' when clock is high (sampled on rising edge)
2. Output q is the previous value of p (delayed by one clock cycle)
3. Both outputs are only updated on rising clock edges
4. When clock is low, outputs maintain their previous values

This suggests we need:
1. A flip-flop to sample 'a' on rising clock edge for p
2. Another flip-flop to store previous p value for q
3. Both outputs should only update on rising clock edges
