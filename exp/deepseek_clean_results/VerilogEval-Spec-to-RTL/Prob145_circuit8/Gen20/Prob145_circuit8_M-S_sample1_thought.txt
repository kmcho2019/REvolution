Key observations:
1. p is high only when both clock is high and a has toggled since last clock cycle
2. q acts as a latch that captures p's value when clock goes low
3. No explicit reset needed as per waveform

Simplified approach:
- p is combinational: high when clock is high AND a is different from last a seen on clock edge
- q is sequential: captures p's value when clock falls
- Only need to store previous a value and current q state
