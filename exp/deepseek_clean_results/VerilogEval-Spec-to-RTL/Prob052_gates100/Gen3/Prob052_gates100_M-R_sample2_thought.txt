To improve the timing performance while maintaining the same functionality, I'll implement a tree structure for the logic operations instead of the linear chain. This will:
1. Reduce the critical path depth from O(n) to O(log n)
2. Maintain the same combinational behavior
3. Use a balanced binary tree approach for each operation
4. Keep the implementation purely structural using generate blocks

The tree structure will process inputs in layers, with each layer combining pairs of results from the previous layer. This approach significantly improves timing while keeping the area and power efficient.
