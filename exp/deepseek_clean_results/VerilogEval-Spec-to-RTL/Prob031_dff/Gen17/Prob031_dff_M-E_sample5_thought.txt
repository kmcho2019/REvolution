Here's a novel approach using a clock-gated D flip-flop with an integrated enable signal. The key idea is:
1. Create a DFF with an additional internal enable signal
2. The enable is generated by XORing the current output (q) with input (d)
3. This means the flip-flop only toggles when the input changes, reducing power consumption
4. Still maintains positive edge-triggered behavior
5. The enable logic prevents unnecessary state changes when input is stable
