This solution implements the D flip-flop using two latches in a master-slave configuration, but with explicit clock gating control. The key innovations are:
1. Uses level-sensitive latches instead of edge-triggered flip-flops
2. Explicitly creates inverted clock signals for the master-slave control
3. Implements the clock gating through direct assignment rather than always blocks
4. The design is functionally equivalent but shows an alternative structural implementation

This approach demonstrates how edge-triggered behavior can be constructed from level-sensitive elements, which might be useful in certain low-power or custom cell design scenarios.
