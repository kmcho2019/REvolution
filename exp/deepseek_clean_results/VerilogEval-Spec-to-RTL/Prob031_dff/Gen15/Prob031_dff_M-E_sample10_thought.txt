Here's a novel approach: implement the D flip-flop using a master-slave latch configuration with explicit internal nodes. This provides:
1. More transparent operation by showing the intermediate latch stages
2. Potential for better timing analysis visibility
3. A different structural implementation that achieves the same functionality

The design uses two level-sensitive latches:
- Master latch (negative level) captures input when clock is low
- Slave latch (positive level) passes value when clock is high
This creates the edge-triggered behavior through the latch interaction.
