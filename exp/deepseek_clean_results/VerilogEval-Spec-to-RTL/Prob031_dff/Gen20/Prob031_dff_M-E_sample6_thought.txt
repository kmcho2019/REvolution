Novel Approach: Using a Clock-Gated D Flip-Flop Implementation
1. Instead of a standard DFF, implement a clock-gated version where the flip-flop only updates when both clock and data change
2. Use an internal enable signal that combines clock and data transitions
3. This creates a power-optimized design that reduces unnecessary toggles
4. The flip-flop still maintains positive edge-triggered behavior but with conditional updates
5. This approach demonstrates how to add basic power optimization to a simple sequential element

Key Features:
- Reduces power consumption by minimizing clock activity
- Still maintains correct DFF functionality
- Shows an alternative implementation with power-awareness
- Demonstrates conditional clocking technique
