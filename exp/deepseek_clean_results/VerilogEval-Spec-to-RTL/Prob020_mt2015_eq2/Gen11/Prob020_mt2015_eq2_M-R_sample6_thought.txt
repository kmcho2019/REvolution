The refactored solution maintains the same functionality but implements it more efficiently by:
1. Using direct bit-wise comparison with XNOR gates for equality checking
2. Combining the results with an AND gate to produce the final output
3. Eliminating the intermediate selector wire and cascaded comparisons
4. Using a single continuous assignment for cleaner code

This approach reduces area and power consumption while improving timing by:
- Removing the 4-bit concatenation and associated routing
- Replacing multiple comparators with simple XNOR gates
- Eliminating the priority-encoded structure
- Using minimal logic gates (2 XNOR + 1 AND)
