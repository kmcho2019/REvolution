Here's a novel approach using a lookup table (LUT) implemented via a case statement. This method:
1. Treats the concatenated {A,B} as a 4-bit address into a truth table
2. Uses a case statement to implement the equality function as a LUT
3. Provides potential benefits:
   - More scalable for wider comparisons (though not needed here)
   - Clear mapping of all input combinations to outputs
   - Easier to modify for more complex comparison functions
   - May offer better synthesis optimization in some tools
4. Maintains the same functionality while presenting a different implementation perspective
