Simplified Approach: Direct Equality Comparison
1. The simplest way to compare two 2-bit values is to use direct equality comparison (== operator)
2. This approach:
   - Uses built-in Verilog equality operator which synthesizes efficiently
   - Results in cleaner, more readable code
   - Typically synthesizes to the same basic logic (XNOR gates) as the original solution
   - Maintains identical functionality while reducing code complexity
3. The implementation becomes a single line of code that clearly expresses the design intent
