Here's a novel approach using a multiplexer-based implementation:
1. Instead of using XNOR gates, we'll use the inputs to select between 1 and 0 outputs
2. We'll create a 4-to-1 mux where the select lines are the concatenation of A and B
3. The mux data inputs will be hardwired to output 1 only when A equals B (select patterns 00 or 05 or 10 or 15 in binary)
4. This approach demonstrates how equality comparison can be implemented using selection logic rather than direct comparison

The key insight is that we can treat the input combination as an address to select the correct output value, mapping only equal input patterns to 1.
