The original implementation uses a simple continuous assignment for the equality comparison. We can refactor this to use an always block with combinational logic instead. This approach:
1. Maintains identical functionality (2-bit equality comparison)
2. Uses procedural assignment instead of continuous assignment
3. Demonstrates an alternative coding style that some designers prefer for readability
4. Still synthesizes to the same efficient hardware (XNOR + AND gates)
5. Explicitly lists all inputs in the sensitivity list for clarity
