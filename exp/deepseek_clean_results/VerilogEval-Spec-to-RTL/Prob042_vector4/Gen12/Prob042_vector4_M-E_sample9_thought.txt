Instead of using direct bit replication, we can implement a more flexible solution using a lookup table approach. This method:
1. Uses the sign bit to select between two pre-computed extension patterns
2. Stores the 24-bit extension patterns (all 0s for positive, all 1s for negative)
3. Concatenates the selected pattern with the input
4. Offers potential advantages in certain FPGA architectures where LUTs are abundant
5. Could be extended to support different extension widths without changing the core logic
