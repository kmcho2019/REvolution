The original solution is already optimal in terms of PPA metrics, but we can refactor it to demonstrate alternative implementations while maintaining the same functionality. Here are two alternative approaches:

1. Using an always block with combinational logic:
   - This shows procedural assignment style
   - Functionally identical to continuous assignment
   - Might be preferred in more complex designs where procedural blocks are needed

2. Using a function call:
   - Encapsulates the sign-extension logic
   - Makes the operation reusable
   - Slightly more verbose but demonstrates modularity

Both alternatives will have identical PPA characteristics since synthesis tools will optimize them to the same underlying hardware.
