The original implementation is already optimal for PPA metrics (0ns timing violations, minimal power and area). However, we can make one micro-optimization by:
1. Using a continuous assignment instead of procedural block to save a tiny bit of simulation overhead
2. Making the output wire type instead of reg since we're using continuous assignment
3. Keeping the same efficient sign-extension logic with replication operator

This change maintains identical PPA characteristics while being slightly more idiomatic for pure combinational logic. The continuous assignment is the most direct way to express this simple combinational function.
