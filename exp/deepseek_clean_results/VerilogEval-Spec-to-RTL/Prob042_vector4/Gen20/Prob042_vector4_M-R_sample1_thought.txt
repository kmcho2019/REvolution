The original solution uses a continuous assignment with concatenation and replication, which is already optimal. However, we can refactor it to demonstrate an alternative approach using an always block with a case statement for educational purposes. This shows how the same functionality can be implemented procedurally while maintaining identical hardware characteristics.

Key changes:
1. Use an always block with a case statement to select between positive and negative extension
2. Maintain the same sign-extension behavior by checking the MSB
3. Keep all outputs as reg types when using procedural assignment
4. The synthesis result will be identical since the replication operation maps to the same hardware

This refactoring demonstrates procedural implementation while maintaining the same PPA characteristics.
