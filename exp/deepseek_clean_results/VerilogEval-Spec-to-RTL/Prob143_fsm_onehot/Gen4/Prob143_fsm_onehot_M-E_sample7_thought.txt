New architectural idea:
1. Instead of processing each state bit separately, use a priority encoder to identify the highest priority active state (since multiple states can be active). This reduces the logic complexity.
2. Implement the state transitions using a compact lookup table approach for the next state.
3. For outputs, use a separate combinational logic that only activates when in specific states (S7-S9), making it independent of the state transition logic.
4. This approach reduces the combinatorial logic complexity by:
   - Using priority encoding to handle multiple active states
   - Centralizing the transition logic
   - Separating output generation from state transition logic
