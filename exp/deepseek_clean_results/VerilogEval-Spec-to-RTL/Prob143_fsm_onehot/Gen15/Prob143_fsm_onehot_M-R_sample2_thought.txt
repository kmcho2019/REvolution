I'll refactor the solution using continuous assignments (assign statements) instead of the always block for next_state generation. This approach:

1. Maintains the same state transition logic but expresses it through continuous assignments
2. Uses bitwise operations to combine similar state transitions
3. Keeps the output logic identical since it's already optimal
4. Benefits:
   - More explicit wiring of logic
   - Eliminates the need for a procedural block
   - Potentially better synthesis for some tools
   - Clearer dataflow representation

The key changes are:
- Convert each next_state bit to a continuous assignment
- Use OR operations to combine transition conditions
- Maintain the same grouping strategy for similar states
- Keep output logic unchanged
