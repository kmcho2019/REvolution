Instead of using traditional one-hot encoding, I'll implement a hybrid approach that:
1. Uses a priority-encoded state representation for S0-S6 (3 bits)
2. Maintains one-hot encoding only for the output-generating states (S7-S9)
3. Uses arithmetic operations for state transitions where possible
4. Implements a compact output decoder

This reduces the state transition logic complexity while maintaining the same functionality. The key innovations are:
- Arithmetic increment for S1-S4 progression
- Special handling for S5/S6 branches
- Minimal one-hot encoding only where needed for outputs
- Efficient output decoding using bit patterns
