I'll implement a novel solution using a hierarchical priority encoder approach that:
1. Processes active states in priority order (S9 highest, S0 lowest)
2. Uses a cascaded structure to determine the highest priority active state
3. Only evaluates transitions for the highest priority active state
4. Implements outputs based on the highest priority state

Key advantages:
- Reduced logic complexity by only considering one state transition at a time
- Natural handling of multiple active states through priority resolution
- Clear separation of concerns between state priority and transition logic
- Potential power savings by not evaluating all possible transitions
