The key innovation in this solution is to:
1. Group states with similar transition patterns to reduce logic redundancy
2. Use priority encoding to handle multiple active states efficiently
3. Implement output logic using state grouping to minimize gate count

The states can be divided into three groups:
- Group 1 (S0-S4): Simple linear progression with reset on 0
- Group 2 (S5-S6): Branching behavior
- Group 3 (S7-S9): Special states with non-zero outputs

This grouping allows us to:
- Share common transition logic within groups
- Reduce the number of OR operations needed
- Simplify output generation by checking group membership
- Maintain one-hot properties while optimizing the implementation
