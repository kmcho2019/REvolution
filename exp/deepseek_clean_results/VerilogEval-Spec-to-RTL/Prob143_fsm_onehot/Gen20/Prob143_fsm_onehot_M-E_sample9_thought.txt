Here's a novel approach using a priority encoder style implementation that:
1. Uses a hierarchical decision structure to prioritize state transitions
2. Implements a more compact state transition logic using casez
3. Optimizes the output logic using bitwise operations
4. Reduces redundant computations by sharing common terms
5. Uses a more systematic approach to handle multiple active states

- Hierarchical state transition logic that naturally handles multiple active states
- More compact encoding of transition rules
- Reduced logic depth through smarter organization
- Better utilization of Verilog's casez statement for one-hot decoding
