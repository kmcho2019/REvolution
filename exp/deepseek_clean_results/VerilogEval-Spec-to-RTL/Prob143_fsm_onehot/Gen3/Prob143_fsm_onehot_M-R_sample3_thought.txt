I'll refactor the code to use continuous assignments instead of procedural blocks for the state transition logic. This approach has several advantages:

1. **More Parallel Logic**: Using continuous assignments makes all logic evaluate in parallel rather than sequentially through if-statements.
2. **Clearer Structure**: The state transitions become more explicit and easier to follow.
3. **Potential PPA Benefits**: The synthesis tool may have more optimization opportunities with this style.

The key changes are:
- Convert the always block to continuous assignments for next_state
- Maintain the same output logic (already optimal)
- Express each state transition as a separate condition
- Use bitwise operations to combine similar transitions
- Keep the one-hot encoding properties

This maintains the exact same functionality but presents it in a different structural form that may yield better synthesis results.
