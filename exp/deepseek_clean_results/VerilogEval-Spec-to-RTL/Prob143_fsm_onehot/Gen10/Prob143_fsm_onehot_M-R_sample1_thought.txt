I'll refactor the code to use continuous assignments (assign statements) instead of an always block for the next_state logic. This approach:
1. Makes each state transition explicit with individual assign statements
2. Maintains the parallel evaluation of all possible transitions
3. Keeps the one-hot encoding scheme
4. Preserves the same output logic
5. Potentially improves readability by showing each transition path clearly

The key changes are:
- Replace the always block with direct assignments to next_state bits
- Each next_state bit gets its own assignment based on current state and input
- The output logic remains the same as it's already optimal
