Instead of using pure one-hot encoding, we can implement a hybrid encoding scheme that:
1. Uses priority encoding for states S0-S6 (since they have linear progression)
2. Maintains one-hot for states S7-S9 (since they have special outputs)
3. Implements output generation using a shared decoder
4. Uses a unified transition logic block that combines priority and one-hot advantages

Key innovations:
- Reduced combinational logic for state transitions S0-S6
- Shared output decoder logic
- More efficient state encoding that still maintains one-hot benefits for critical states
- Pre-decoding of input conditions to minimize redundant logic
