Fusion strategy combining the best aspects of both solutions:
1. Maintain the scalability of the generate loop approach (Example 1)
2. Adopt the concise single-assignment style of Example 2
3. Use a parameterized width for maximum flexibility
4. Combine readability with maintainability
5. Ensure identical synthesized hardware to both approaches

Key improvements:
- Parameterized width allows easy modification for different bit widths
- Single generate block maintains clean code structure
- No manual bit enumeration reduces error potential
- Still synthesizes to optimal wire connections
