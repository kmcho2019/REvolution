A more scalable and maintainable approach is to use a generate loop with a parameterized width. This approach:
1. Uses a for-loop inside a generate block to reverse the bits
2. Makes the code more maintainable and easier to modify for different bit widths
3. Still results in the same hardware as direct concatenation after synthesis
4. Avoids the verbosity of listing all 100 bits explicitly
5. Can be easily adapted for different vector sizes by changing the parameter
