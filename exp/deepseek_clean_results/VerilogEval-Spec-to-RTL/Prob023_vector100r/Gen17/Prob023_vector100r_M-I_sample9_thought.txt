To optimize the PPA metrics while maintaining functionality, I propose the following improvements:

1. **Performance:** Use a generate loop instead of direct concatenation to make the design more scalable and potentially reduce routing complexity. This gives synthesis tools more flexibility in optimization.

2. **Power:** The generate loop approach shouldn't significantly impact power since it's still combinational, but the cleaner implementation might allow for better power optimization during synthesis.

3. **Area:** The generate loop should synthesize to the same basic structure (wire connections) but with cleaner RTL that tools can better optimize. We'll also use a more compact loop syntax.

The key benefits are:
- More scalable for different bit widths
- Cleaner RTL that's easier to maintain
- Potential for better tool optimization
- Same functionality with possibly better PPA
