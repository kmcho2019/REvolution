Instead of using generate blocks or direct concatenation, we can:
1. Create a local function within the module to handle the bit reversal
2. Make the design more flexible by parameterizing the width
3. Use a for-loop inside the function to reverse the bits
4. This approach offers better readability and maintainability
5. The function-based solution is more elegant and can be reused elsewhere
6. The synthesis result should be identical to the generate approach since functions are inlined during synthesis
