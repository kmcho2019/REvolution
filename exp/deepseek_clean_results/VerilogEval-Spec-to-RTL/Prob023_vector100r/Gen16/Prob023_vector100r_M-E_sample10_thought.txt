Here's a novel approach using a parameterized for-loop within an always_comb block to reverse the bits. This solution:

1. Uses SystemVerilog's always_comb for better readability and automatic sensitivity
2. Implements the reversal through a loop that runs at compile-time
3. Maintains the same functionality but with more concise code
4. Scales easily if the bit width needs to change
5. Uses a temporary variable to store the reversed result before assignment
6. Provides the same zero-delay characteristic as the original solution
7. Is more maintainable as it doesn't require manually listing all 100 bits
