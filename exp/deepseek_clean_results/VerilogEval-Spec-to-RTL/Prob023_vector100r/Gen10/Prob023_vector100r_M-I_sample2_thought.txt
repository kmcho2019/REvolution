To optimize the solution while maintaining functionality, I propose the following improvements:

1. **Code Maintainability**: Replace the manual concatenation with a generate-for loop to make the code more scalable and easier to maintain, especially for large bit widths.

2. **PPA Optimization**: 
   - The generate loop approach allows the synthesizer to potentially optimize the implementation better than explicit concatenation.
   - While maintaining the same combinational logic structure, this makes the code more readable and maintainable without sacrificing PPA metrics.
   - The actual hardware implementation should remain identical to the original solution since both describe the same wiring pattern.

3. **Scalability**: This approach easily adapts to different vector sizes by simply changing the parameter, making the code more reusable.
