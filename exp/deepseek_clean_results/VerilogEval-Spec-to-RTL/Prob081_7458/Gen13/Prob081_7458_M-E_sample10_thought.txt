Novel approach using hierarchical design:
1. Instead of flat implementation, create submodules for different logical blocks
2. First create a parameterized AND gate module that can handle 2 or 3 inputs
3. Then create an OR gate module
4. Instantiate these submodules to build the complete circuit
5. Benefits:
   - More modular and reusable design
   - Easier to modify individual gate types later
   - Clearer hierarchy in larger designs
   - Parameters allow flexibility in input counts
   - Better for team collaboration as different engineers can work on different submodules
6. Tradeoff: Slightly more verbose but more maintainable
