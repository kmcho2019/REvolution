To optimize the PPA (Power, Performance, Area) metrics, we'll implement a flat design using direct assign statements instead of hierarchical modules. This approach:
1. Eliminates module hierarchy overhead, improving timing (Performance)
2. Reduces switching activity by removing intermediate wires, lowering power
3. Minimizes area by removing module boundaries and unused ports
4. Maintains the same logical functionality while being more efficient

The improved design will:
- Combine all logic into a single module
- Use direct assign statements for outputs
- Eliminate intermediate wire declarations
- Keep the same AND-OR structure but in a more compact form
