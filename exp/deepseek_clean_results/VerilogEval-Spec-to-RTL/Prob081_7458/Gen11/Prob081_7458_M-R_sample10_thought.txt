The original solution uses direct assign statements for the outputs. We can refactor this by:
1. Using intermediate wires for the AND gate outputs to make the structure more explicit
2. Grouping related logic together for better readability
3. Keeping the same logical functionality while making the gate-level structure more visible

This approach doesn't change the functionality but makes the design more modular and easier to modify if needed. The PPA metrics should remain identical since this is just a structural change.
