To optimize the counter for better PPA (Power, Performance, Area), I'll implement these improvements:

1. **Performance:** Use a simple +1 increment operation instead of bitwise toggling. This:
   - Eliminates the ripple effect of the current implementation
   - Allows synthesis tools to use optimized adder structures
   - Reduces critical path by making all bit updates parallel

2. **Power:** The unified increment operation will:
   - Reduce glitching power by updating all bits simultaneously
   - Minimize unnecessary intermediate transitions

3. **Area:** The arithmetic approach typically:
   - Uses fewer gates than cascaded conditional logic
   - Benefits from synthesis tool optimizations for arithmetic operations
   - Enables better resource sharing

The synchronous reset functionality remains unchanged, maintaining the same behavior on reset.
