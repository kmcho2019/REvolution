The simplest and most efficient way to implement a 4-bit binary counter is to use a standard increment operation (q <= q + 1). This approach:
1. Uses minimal logic (just a simple adder)
2. Has a clean critical path (single operation)
3. Naturally handles the rollover from 15 to 0
4. Maintains synchronous reset functionality
5. Will likely yield better PPA metrics than the bitwise conditional approach
