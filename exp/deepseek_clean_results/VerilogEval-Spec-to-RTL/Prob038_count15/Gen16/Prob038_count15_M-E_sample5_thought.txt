Novel architectural idea: Gray code counter with binary conversion
1. Implement a 4-bit Gray code counter which changes only one bit per count transition
2. Convert the Gray code output to binary for the final output
3. Benefits:
   - Reduced switching activity (power savings) since only one bit changes per count
   - Simple increment logic for the Gray code counter
   - Conversion to binary happens in combinational logic
   - Maintains synchronous reset functionality
4. The Gray code sequence will wrap around after 16 counts (0000 to 1000 and back)
5. Binary conversion uses XOR gates in a cascaded fashion
