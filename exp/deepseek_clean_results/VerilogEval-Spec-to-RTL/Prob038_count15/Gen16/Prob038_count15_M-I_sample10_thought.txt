To optimize the counter for better PPA (Power, Performance, Area), I'll implement these improvements:
1. Use a simple +1 increment operation instead of bitwise toggling logic to:
   - Reduce critical path (all bits update simultaneously from a single adder)
   - Minimize area by using built-in arithmetic operators
   - Reduce power by eliminating unnecessary intermediate logic
2. Maintain the same synchronous reset functionality
3. Keep the same counting behavior (0-15 with period of 16)
4. The unified adder approach will:
   - Improve timing by eliminating the ripple dependency
   - Reduce area through operator sharing
   - Lower power by reducing glitching
