To implement a 4-bit binary counter with a period of 16, we'll use a 4-bit register to store the current count value. On each positive clock edge:
1. If reset is active, we'll set the count to 0
2. Otherwise, we'll increment the count by 1
The counter will naturally wrap around from 15 (4'b1111) back to 0 (4'b0000) due to the 4-bit width limitation.
