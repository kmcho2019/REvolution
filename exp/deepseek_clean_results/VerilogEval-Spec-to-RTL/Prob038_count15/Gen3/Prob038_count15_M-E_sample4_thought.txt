Instead of a traditional binary counter, implement a 4-bit maximal-length LFSR that cycles through all 16 states (0-15). This approach:
1. Uses a 4-bit register with XOR feedback
2. The feedback taps are chosen to create a maximal-length sequence (taps at bits 3 and 2)
3. The sequence will cover all 16 possible 4-bit values before repeating
4. Synchronous reset initializes to 0
5. The output is taken directly from the register
This provides the same counting functionality but with different internal implementation.
