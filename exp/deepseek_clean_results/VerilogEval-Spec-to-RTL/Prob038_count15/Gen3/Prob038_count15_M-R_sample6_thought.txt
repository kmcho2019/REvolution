I'll refactor the counter to use a simpler increment operation while maintaining the same functionality. Instead of the bitwise conditional logic, we'll use a straightforward +1 increment operation. This approach:
1. Simplifies the logic by using a single arithmetic operation
2. Reduces the number of conditional checks
3. Maintains the same synchronous reset behavior
4. Still counts through all 16 states (0-15) in binary order
The implementation will be more readable and likely more efficient in terms of PPA metrics.
