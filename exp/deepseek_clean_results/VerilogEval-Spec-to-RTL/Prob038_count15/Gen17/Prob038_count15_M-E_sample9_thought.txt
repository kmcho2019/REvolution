Novel approach: Gray code counter with binary conversion
1. Implement a 4-bit Gray code counter that naturally has only one bit changing per count
2. Convert the Gray code to binary for the output
3. Benefits:
   - Reduced switching activity compared to binary counter (lower power)
   - Maintains simple combinational logic for conversion
   - Still achieves the required counting sequence
   - Synchronous reset maintains same functionality
4. Gray code counter is implemented using XOR feedback
5. Binary conversion uses simple XOR cascade
