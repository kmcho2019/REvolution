Novel approach: Gray code counter with synchronous reset
1. Implement a 4-bit Gray code counter instead of binary for reduced switching activity
2. Gray code changes only one bit per count, reducing power consumption
3. Use a binary-to-Gray conversion for the output to maintain standard binary counting sequence
4. Internal counter is standard binary for simpler implementation
5. Synchronous reset forces counter to 0 (binary) which converts to Gray code 0000

Advantages:
- Reduced switching power due to single-bit transitions between counts
- Maintains same counting sequence (0-15) at the output
- Simple implementation using standard binary counter internally
- Output conversion to Gray code is combinational and fast
- Better EMI characteristics due to reduced simultaneous switching
