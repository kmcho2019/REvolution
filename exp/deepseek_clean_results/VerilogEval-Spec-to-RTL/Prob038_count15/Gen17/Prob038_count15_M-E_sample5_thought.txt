Novel approach: Implement a 4-bit counter using a ring counter with parallel load. This approach:
1. Uses a circular shift register as the base structure
2. Implements parallel loading when the count reaches maximum value
3. Combines the benefits of shift registers and binary counters
4. Provides potential power savings since only one bit changes per clock (except during wrap-around)
5. Uses simpler combinational logic than arithmetic counters

Key features:
- Shift operation for normal counting (only one bit toggles per cycle)
- Parallel load when wrapping from 15 to 0
- Synchronous reset functionality
- Minimal combinational logic between flip-flops
