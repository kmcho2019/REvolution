Novel approach: Gray code counter with synchronous reset
1. Implement a 4-bit Gray code counter instead of binary for reduced switching activity
2. Gray code changes only one bit per count, reducing power consumption
3. Use a binary-to-Gray conversion for the output to maintain binary count sequence
4. Internal counter remains binary for easy increment logic
5. Synchronous reset forces counter to 0 (binary) which converts to Gray code 0000

Advantages:
- Reduced power due to minimal bit toggling (only 1 bit changes per clock)
- Maintains same external behavior (binary count sequence on q output)
- Simple increment logic internally
- No combinational critical path between bits
- Easy to extend to wider counters
