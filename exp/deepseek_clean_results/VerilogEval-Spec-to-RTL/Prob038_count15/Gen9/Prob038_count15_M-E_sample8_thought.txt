Novel Architectural Idea:
Instead of using a standard binary counter, implement a linear feedback shift register (LFSR) based counter that cycles through all 16 states (0-15). This approach:
1. Uses an LFSR with maximal-length polynomial (x^4 + x^3 + 1) to generate all 4-bit values
2. Includes a mapping ROM to convert LFSR states to binary counts
3. Provides inherent glitch reduction due to single-bit changes between states
4. Offers potential power savings from reduced switching activity
5. Maintains same functionality but with different internal implementation
