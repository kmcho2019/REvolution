Novel Approach: Using a Linear Feedback Shift Register (LFSR) Counter
1. Instead of a traditional binary counter, implement a 4-bit LFSR counter
2. LFSRs are more area-efficient and can run at higher frequencies
3. Use a maximal-length LFSR (15 states) with proper feedback taps
4. Map the LFSR states to binary counts through combinational logic
5. Maintain synchronous reset functionality
6. The LFSR will cycle through all 15 non-zero states before repeating

Benefits:
- Potentially better timing due to simpler feedback logic
- Lower power consumption from reduced switching activity
- More compact implementation
- Interesting alternative to standard binary counters
