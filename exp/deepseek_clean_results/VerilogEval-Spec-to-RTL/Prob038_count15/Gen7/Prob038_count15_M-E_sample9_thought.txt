Novel Approach: LFSR-based Counter with Binary Conversion
1. Instead of a traditional binary counter, use a 4-bit Linear Feedback Shift Register (LFSR) for state storage
2. The LFSR will cycle through all 15 non-zero states (1-15) before repeating
3. Add logic to detect the all-zeros state and force it to the LFSR's seed value (0001)
4. Convert the LFSR state to binary count output using a small lookup table
5. Benefits:
   - Reduced switching activity compared to binary counter (only one bit changes per cycle)
   - Potential power savings due to simpler feedback logic
   - Interesting alternative implementation that meets the same functional requirements
