Here's a novel approach using a shift register with feedback to implement the counter. This design:

1. Uses a 4-bit shift register where the feedback is the XOR of specific bits
2. Implements a maximum-length LFSR (Linear Feedback Shift Register) pattern that cycles through all 15 non-zero states
3. Adds special handling for the zero state (reset condition)
4. Combines the LFSR pattern with a zero-detection circuit
5. Uses the reset signal to force the zero state
6. Provides the same counting sequence but with different internal implementation

The advantages are:
- Reduced switching activity compared to binary counter (only 1 bit changes per cycle)
- Interesting alternative implementation that might have better power characteristics
- Demonstrates a different way to achieve the same functionality
