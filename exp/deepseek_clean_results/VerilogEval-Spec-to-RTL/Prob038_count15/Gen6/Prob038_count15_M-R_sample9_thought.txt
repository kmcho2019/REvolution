I'll refactor the counter implementation while maintaining the same functionality. The key changes will be:

1. Separate the combinational next-state logic from sequential state storage using continuous assignment (assign) for the increment operation.

2. Use a wire for the next state value and a register for the current state.

3. This approach makes the design more modular by clearly separating:
   - The combinational logic (increment operation)
   - The sequential elements (register with synchronous reset)

The benefits of this approach are:
- Clear separation of combinational and sequential logic
- Easier to modify the increment logic independently
- More flexible for future extensions (like adding enable signals)
- Maintains the same PPA characteristics as the original
