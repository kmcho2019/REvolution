Refactoring Strategy:
1. Separate combinational and sequential logic for better modularity
2. Use an always block only for sequential elements (flip-flops)
3. Move the increment logic to combinational block using assign
4. Maintain synchronous reset functionality
5. Use an intermediate next_q signal to represent the next state

The refactored solution will:
- Clearly separate state storage from next-state logic
- Make the design more modular and easier to modify
- Keep the same functionality but with cleaner structure
- Potentially improve synthesis results by separating concerns
