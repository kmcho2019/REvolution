Refactoring Approach:
1. Maintain same functionality (4-bit counter with synchronous reset)
2. Alternative implementation using:
   - Combinational logic for increment operation
   - Separate register block for state storage
3. Key changes:
   - Split combinational and sequential logic
   - Use assign statement for increment logic
   - Explicit next-state register
4. Benefits:
   - Clear separation of combinational and sequential logic
   - Easier to pipeline if needed
   - More flexible for future modifications
5. Trade-offs:
   - Slightly more verbose
   - Same functionality and similar synthesis results
