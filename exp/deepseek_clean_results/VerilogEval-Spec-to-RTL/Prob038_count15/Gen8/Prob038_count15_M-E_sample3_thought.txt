Here's a novel approach using a linear feedback shift register (LFSR) style implementation with explicit state tracking to create a binary counter:
1. Use individual flip-flops for each bit to enable bit-specific control
2. Implement ripple-carry logic explicitly to demonstrate the counter's internal operation
3. Use XOR gates to generate the carry propagation between bits
4. Maintain synchronous reset functionality
5. This approach showcases the fundamental building blocks of a counter rather than using arithmetic operators

The advantage is better visibility into the counter's internal operation and potential for custom carry logic modifications. It's less efficient than the arithmetic version but demonstrates the underlying principles.
