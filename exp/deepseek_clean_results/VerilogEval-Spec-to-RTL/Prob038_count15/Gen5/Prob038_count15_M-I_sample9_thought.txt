The current implementation uses a modified LFSR approach which, while functional, creates unnecessary complexity in the combinatorial logic. We can optimize PPA by:
1. Simplifying to a standard binary counter (q <= q + 1) which will:
   - Reduce critical path (improve performance)
   - Minimize switching activity (reduce power)
   - Use fewer gates (reduce area)
2. Maintaining synchronous reset functionality
3. Ensuring the counter still cycles through all 16 states (0-15)
This approach will be more efficient while maintaining identical functionality.
