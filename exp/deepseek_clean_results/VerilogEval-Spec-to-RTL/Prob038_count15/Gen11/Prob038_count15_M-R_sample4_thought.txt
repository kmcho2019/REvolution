Refactoring Strategy:
1. Separate the combinational and sequential logic for better modularity
2. Use an always block for sequential elements (flip-flops) only
3. Move the increment logic to a continuous assignment
4. Maintain the same synchronous reset functionality
5. This approach:
   - Makes the design more explicit about what's combinational vs sequential
   - Could potentially improve synthesis optimization by clearly separating the adder logic
   - Makes timing analysis more straightforward
   - Maintains the same PPA characteristics while offering better debug visibility
