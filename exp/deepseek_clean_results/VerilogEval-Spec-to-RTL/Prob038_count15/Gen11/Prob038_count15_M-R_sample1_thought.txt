Refactoring Strategy:
1. Maintain the same 4-bit counter functionality with synchronous reset
2. Separate the combinational and sequential logic for clarity
3. Use an always block for sequential elements (flip-flops)
4. Move the increment logic to a continuous assignment (assign statement)
5. Benefits of this approach:
   - Clear separation of combinational and sequential logic
   - Potential for better synthesis optimization as the adder is explicitly combinational
   - Easier to modify the increment logic independently
   - Maintains synchronous design principles
   - Still results in efficient PPA characteristics

Key Changes:
- q_next is now a wire calculated by combinational logic
- Flip-flop behavior remains in always block
- Reset functionality unchanged
