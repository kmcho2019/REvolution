To simplify the counter implementation while maintaining functionality, I'll:

1. Replace the individual bit-wise toggling logic with a simple +1 increment operation
2. Keep the synchronous reset functionality
3. Use a single always block for both reset and counting
4. Directly assign the register output to q
5. This approach reduces complexity by:
   - Eliminating separate combinational logic for each bit
   - Using a single arithmetic operation instead of multiple conditional toggles
   - Reducing the number of intermediate signals

The design will be functionally equivalent but more straightforward and likely more efficient in terms of PPA metrics.
