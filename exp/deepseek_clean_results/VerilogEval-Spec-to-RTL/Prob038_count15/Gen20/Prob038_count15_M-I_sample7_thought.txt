To optimize the counter for better PPA (Power, Performance, Area), I'll implement the following improvements:

1. Performance: Replace the cascaded conditional toggling with a simple increment operation (count + 1). This will:
   - Eliminate the ripple effect in the current implementation
   - Allow for better timing as all bits update simultaneously
   - Typically synthesize to more balanced logic paths

2. Power: The increment operation will naturally reduce switching activity since:
   - Higher bits toggle less frequently (only when all lower bits are 1)
   - No additional conditional logic gates that cause unnecessary switching

3. Area: A simple 4-bit adder is more compact than individual bit-level logic:
   - Requires fewer logic gates overall
   - Modern synthesis tools can optimize adder structures efficiently
   - Eliminates the need for separate toggle conditions for each bit

The synchronous reset functionality will be maintained for correct operation.
