Here's a novel approach using a linear feedback shift register (LFSR) style counter with additional logic to ensure it counts in binary sequence from 0 to 15. This provides several advantages:

1. LFSR-style implementation offers potential power and area savings
2. The feedback logic is modified to create a binary counting sequence
3. Each bit's next state depends only on itself and the LSB, reducing critical path
4. The design maintains synchronous reset functionality
5. The counting sequence is guaranteed by the feedback polynomial

The key innovation is using a modified LFSR structure where:
- Bit 0 toggles every cycle (like a normal counter)
- Bit 1 toggles when bit 0 is 1
- Bit 2 toggles when bits 1 and 0 are 1
- Bit 3 toggles when bits 2, 1 and 0 are 1
- This creates the binary counting sequence naturally
