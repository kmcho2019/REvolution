To simplify the counter implementation while maintaining functionality:
1. Replace the bitwise toggle logic with a simple increment operation (q + 1)
2. This reduces the combinational logic complexity significantly
3. The synchronous reset remains the same
4. The counter will naturally roll over from 15 to 0
5. This approach is more readable and typically synthesizes to more efficient hardware
6. No need for separate next_q wires since the increment can be done directly in the always block
