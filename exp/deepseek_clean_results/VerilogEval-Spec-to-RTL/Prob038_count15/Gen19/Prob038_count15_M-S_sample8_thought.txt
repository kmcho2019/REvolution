To simplify the counter implementation while maintaining functionality:
1. Use a standard 4-bit binary counter with arithmetic increment
2. Implement synchronous reset to clear the counter
3. The counter will naturally roll over from 15 to 0
4. This approach eliminates the hybrid logic and provides:
   - Uniform timing across all bits
   - Simpler and more readable code
   - Potentially better area utilization
   - Consistent power characteristics
5. The arithmetic increment (+1) is straightforward and well-optimized in synthesis tools
