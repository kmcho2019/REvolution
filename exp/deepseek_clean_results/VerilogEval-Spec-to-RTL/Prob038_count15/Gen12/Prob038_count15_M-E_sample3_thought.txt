Here's a novel approach using a linear feedback shift register (LFSR) style counter with additional logic to ensure it counts in binary sequence from 0 to 15. This implementation offers several advantages:

1. The LFSR-style structure provides excellent timing characteristics since each bit only depends on the previous state and one other bit.

2. By carefully designing the feedback logic, we can transform the pseudo-random sequence of a traditional LFSR into a binary counting sequence.

3. The implementation uses minimal logic operations per bit, reducing both area and power consumption.

4. The synchronous reset is preserved, and the counter maintains its period of 16 cycles.

5. The design is scalable - the same pattern could be extended to wider counters if needed.

The key insight is that we can create the binary counting sequence by:
- Toggling bit 0 every cycle (LSB)
- Toggling bit 1 when bit 0 is 1
- Toggling bit 2 when bits [1:0] are both 1
- Toggling bit 3 when bits [2:0] are all 1
This pattern is implemented efficiently using XOR gates with carefully selected inputs.
