Here's a novel approach using a ring counter with decoding logic to implement the 4-bit binary counter. The key ideas are:
1. Use a 16-bit ring counter (one-hot) that rotates a single '1' through 16 positions
2. Add decoding logic to convert the one-hot state to binary output
3. This approach provides glitch-free outputs since only one bit changes at a time
4. The reset initializes to 0000000000000001 (one-hot 0)
5. The rotation creates the counting sequence naturally

Advantages:
- Simple state transition logic (just rotate right)
- Glitch-free binary outputs due to one-hot encoding
- Easy to extend to larger counters
- Clear relationship between state and count value
