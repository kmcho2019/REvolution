Here's a simplified approach for the 4-bit binary counter:
1. Use a single 4-bit register to store the counter value
2. Implement simple increment operation (count + 1) instead of explicit carry logic
3. Reset synchronously to 0 when reset is high
4. Let the counter naturally roll over from 15 to 0
5. This approach is more concise, easier to understand, and likely more efficient in terms of timing and area

The simplification comes from:
- Removing complex explicit carry logic
- Using arithmetic operation instead of bitwise manipulation
- Consolidating all reset logic into one statement
- Maintaining the same functionality with cleaner code
