Here's a novel approach using a linear feedback shift register (LFSR) style counter with custom feedback logic to create a binary counting sequence. This implementation offers several advantages:

1. Uses a shift-register-like structure with feedback for counting
2. Implements custom feedback logic to ensure binary counting sequence (0-15)
3. Maintains synchronous reset functionality
4. All flip-flops update simultaneously (no ripple effect)
5. Interesting alternative to traditional binary counters

The feedback logic is designed to:
- Toggle the LSB every cycle
- Propagate carries correctly through the bits
- Maintain proper binary counting sequence
- Reset cleanly to 0
