Let's implement a state machine approach that tracks the history of inputs to determine the output. The idea is to create a simple sequential logic that remembers the previous state of inputs and makes decisions based on both current and past values. This will demonstrate an alternative implementation that doesn't rely purely on combinational logic.

Key features:
1. Use a clock (implicitly derived from input changes in this case)
2. Maintain a state register
3. Output depends on both current inputs and previous state
4. The state transitions are designed to match the given waveform exactly

This approach shows how sequential logic can be used even for simple functions, providing a different perspective on the problem while maintaining the same functionality.
