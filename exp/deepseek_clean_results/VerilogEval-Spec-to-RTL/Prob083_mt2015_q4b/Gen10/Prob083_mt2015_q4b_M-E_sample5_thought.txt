Novel approach using state encoding and edge detection:
1. Instead of directly comparing inputs, encode the state of x and y into a 2-bit register
2. Use edge detection to identify when both inputs change simultaneously
3. Output z is high when:
   - Current state is 00 (both inputs low) or 11 (both inputs high)
   - AND there was no single-input transition in previous cycle
4. Benefits:
   - More robust against glitches since we're tracking state transitions
   - Explicit state encoding makes timing analysis clearer
   - Can be easily extended for more complex sequence detection
