To correctly implement Rule 110 cellular automaton with 512 cells:
1. Need to handle parallel updates properly by using a temporary register for next state
2. Current implementation has a race condition because it updates q in place
3. Solution is to:
   - Compute all next states in parallel based on current q values
   - Store these in a temporary register
   - Update q with the temporary values at the clock edge
4. Maintain the same boundary conditions (0 for out-of-bounds neighbors)
5. Keep the load functionality unchanged
6. The rule110 function implementation is correct and can be kept as is
