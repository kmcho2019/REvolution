To correctly implement Rule 110 with synchronous updates, we need to:
1. Separate the next state computation from the current state storage
2. Compute all next states in parallel based on current state
3. Use a temporary register to store next states before updating
4. Handle boundary conditions by treating out-of-bounds neighbors as 0
5. Use combinational logic for next state computation
6. Use sequential logic only for state storage and loading

Key improvements:
- Avoid read-modify-write race conditions by computing next state separately
- Maintain true parallel computation of all cell states
- Clear separation between combinational and sequential logic
- Proper handling of boundary conditions
