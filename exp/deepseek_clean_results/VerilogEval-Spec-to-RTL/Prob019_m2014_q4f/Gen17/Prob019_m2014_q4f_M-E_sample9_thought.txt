Here's a novel approach using a multiplexer-based implementation instead of direct logic gates. The idea is to:
1. Treat in2 as a selector for a multiplexer
2. When in2 is 0, output in1 (AND with inverted in2)
3. When in2 is 1, output 0 (since AND with inverted in2 would be 0)
This achieves the same functionality but through a different architectural approach using a 2:1 mux.
