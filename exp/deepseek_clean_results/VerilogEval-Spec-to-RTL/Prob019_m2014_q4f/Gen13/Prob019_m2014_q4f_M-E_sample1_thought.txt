This solution implements the logic function using a multiplexer with a creative control scheme:
1. Instead of traditional logic gates, we use a 2:1 mux as the core building block
2. The mux selection is controlled by in1 (treating it as the selector)
3. The data inputs are cleverly chosen constants and inverted in2 to achieve the desired function
4. This demonstrates how muxes can be used as universal logic elements
5. The approach is easily scalable to more complex functions by expanding the mux width
6. Shows an alternative way to think about logic implementation beyond standard gates
