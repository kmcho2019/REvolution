Let's implement this using a multiplexer-based approach that dynamically selects between constant values based on the input conditions. This method:
1. Uses in1 as the selector for a 2:1 mux
2. When in1 is 0, output is always 0 (AND condition fails)
3. When in1 is 1, output is the inverse of in2 (AND with bubble on in2)
4. Demonstrates how simple logic can be implemented using multiplexers
5. Shows an alternative way to think about logic gates as selection operations
