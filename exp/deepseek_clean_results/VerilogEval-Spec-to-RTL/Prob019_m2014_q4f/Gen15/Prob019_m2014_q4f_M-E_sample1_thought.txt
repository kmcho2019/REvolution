Here's a novel approach using a multiplexer-based implementation instead of direct logic gates. The idea is to use in2 as a selector for a mux that chooses between 0 and in1. This effectively implements the same logic (in1 AND NOT in2) but through a different architectural approach. The mux will select:
- 0 when in2 is high (bubble effect)
- in1 when in2 is low
This provides the same functionality while demonstrating an alternative implementation strategy.
