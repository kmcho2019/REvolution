The original implementation uses a continuous assignment with the AND operation and inversion combined in one line. We can refactor this by:

1. Separating the inversion operation into its own intermediate wire
2. Then performing the AND operation separately
3. This makes the logic more explicit and modular, though functionally identical
4. The PPA impact will be negligible since synthesis tools will optimize this back to the same implementation
5. This style might be preferable in more complex designs where intermediate signals need to be observed or reused
