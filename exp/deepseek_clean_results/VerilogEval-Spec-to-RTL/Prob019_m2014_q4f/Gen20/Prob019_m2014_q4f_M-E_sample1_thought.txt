Here's a novel approach using a look-up table (LUT) implemented via a case statement. The idea is to:
1. Treat the combination of in1 and in2 as a 2-bit address
2. Use a case statement to implement the truth table of the function
3. This approach is more scalable for complex functions and demonstrates how simple logic can be implemented using LUT-style coding
4. The case statement clearly shows all possible input combinations and their corresponding outputs
