This solution implements the same logic function (in1 AND NOT in2) but uses a 2:1 multiplexer instead of an AND gate with inverted input. The idea is:
1. The multiplexer selects between 0 and in1 based on in2
2. When in2 is 0 (bubble is active), we pass in1 (equivalent to AND with 1)
3. When in2 is 1, we output 0 (equivalent to AND with 0)
This approach demonstrates how the same logic can be implemented using different architectural choices, which might have different PPA characteristics depending on the target technology library.
