Instead of using discrete gates (inverter + AND), we can implement the logic using a lookup table (LUT) approach. This method:
1. Treats the 2-input function as a truth table
2. Directly maps the desired output pattern (01 for in1=1, in2=0)
3. Uses a 4-to-1 multiplexer to select the correct output based on input combinations
4. This approach is more scalable for complex functions and matches well with FPGA architectures
