Novel Architecture Idea:
1. Instead of individual flip-flops or a monolithic register, implement two 8-bit registers (one per byte)
2. Use clock gating at the byte level to reduce power consumption when bytes aren't being written
3. Implement the clock gating using AND gates with byteena signals as enables
4. Create gated clocks for each byte segment
5. Benefits:
   - Reduced dynamic power when only one byte is being written
   - Clear physical separation of byte boundaries in layout
   - Potential for better clock tree synthesis
   - Maintains same functionality while optimizing power
