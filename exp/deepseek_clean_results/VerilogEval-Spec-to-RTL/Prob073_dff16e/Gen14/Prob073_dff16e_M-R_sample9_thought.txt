Refactoring Approach:
1. Maintain the same byte-level enable functionality but implement it using a single always block for both bytes
2. Use conditional assignments within the always block to handle byte enables
3. Keep the synchronous reset and positive edge triggering
4. Benefits of this approach:
   - More compact code with a single always block
   - Clear visibility of all register operations in one place
   - Still maintains byte-level granularity for synthesis optimization
   - Easier to modify if additional control signals are needed later
5. The functionality remains identical to the original solution, just organized differently
