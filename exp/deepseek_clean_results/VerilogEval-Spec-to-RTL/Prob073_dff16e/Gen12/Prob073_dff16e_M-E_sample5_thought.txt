Novel Approach: Shift-Register Inspired Implementation
1. Instead of individual DFFs, use two 8-bit registers (one per byte)
2. Implement byte-level write enable through masking:
   - When byteena[1] is high, update upper byte
   - When byteena[0] is high, update lower byte
3. Use synchronous reset that clears all bits
4. Key advantages:
   - More compact implementation using vector registers
   - Better utilization of Verilog's vector operations
   - Easier to extend to larger word sizes
   - More efficient synthesis as it allows better optimization of the register structure
5. The design maintains the same functionality but with a cleaner implementation
