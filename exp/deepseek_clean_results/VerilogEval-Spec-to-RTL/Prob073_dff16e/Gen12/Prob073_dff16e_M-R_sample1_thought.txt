Refactoring Approach:
1. Maintain the same byte-level organization but implement it using continuous assignments with multiplexers
2. Replace the procedural always block with combinational logic for the register update
3. Use a ternary operator for the reset and enable conditions
4. Benefits:
   - More explicit data flow visualization
   - Potential for better synthesis optimization in some tools
   - Elimination of procedural blocks makes the behavior more immediately visible
   - Easier to add additional combinational logic if needed
5. The core functionality remains identical - two byte-wide registers with independent enables
