To implement this module, we'll create 16 D flip-flops grouped into two bytes (upper and lower). The byteena signal will control which bytes get updated:
1. Use synchronous active-low reset (resetn) to clear all flip-flops
2. For each flip-flop:
   - Upper byte (bits 15:8) updates only when byteena[1] is high
   - Lower byte (bits 7:0) updates only when byteena[0] is high
3. Each flip-flop is triggered on positive clock edge
4. When byteena bits are low, the corresponding flip-flops maintain their current values
