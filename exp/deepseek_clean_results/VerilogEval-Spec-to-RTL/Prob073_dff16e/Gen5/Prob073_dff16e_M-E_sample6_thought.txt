This new implementation uses a single always block with conditional bit-wise updates, offering:
1. Unified register implementation without hierarchy boundaries for better synthesis optimization
2. Bit-level granularity for potential power gating (though still byte-controlled)
3. More compact code while maintaining the same functionality
4. Direct mapping of byte enables to corresponding data bits
5. Clear visibility of all operations in one block for easier verification

The key innovation is using the byte enables to generate a 16-bit write mask, then applying this mask in a single operation. This approach:
- Reduces hierarchical overhead
- Makes the byte-enable-to-data-bit mapping explicit
- Allows potential future extension to individual bit enables
- Maintains clean synchronous reset behavior
