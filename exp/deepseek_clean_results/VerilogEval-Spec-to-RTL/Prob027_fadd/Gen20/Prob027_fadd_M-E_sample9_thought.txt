Here's a novel approach using majority and parity functions:

1. **Majority Function for Carry-out:** The carry-out is 1 when at least two of the three inputs are 1. This can be implemented using a majority function which is more intuitive for carry generation.
2. **Parity Function for Sum:** The sum is simply the odd parity (XOR) of all three inputs, which remains unchanged from the standard implementation.
3. **Structural Implementation:** We'll use explicit gate-level instantiation to make the majority function clear, showing a different way to think about the carry generation.

This approach emphasizes the conceptual symmetry of the full adder - the carry is about majority while the sum is about parity. The gate count remains the same but the implementation is conceptually different.
