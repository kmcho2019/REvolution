Instead of using traditional XOR/AND/OR gates, we can implement the full adder using multiplexers (MUX) which can be more efficient in certain FPGA architectures. The sum output can be seen as a selection between inverted and non-inverted versions of inputs based on the carry-in. Similarly, the carry-out can be implemented as a MUX selecting between (a OR b) and (a AND b) based on the intermediate sum. This approach might be more area-efficient in technologies where MUXes are fundamental building blocks.
