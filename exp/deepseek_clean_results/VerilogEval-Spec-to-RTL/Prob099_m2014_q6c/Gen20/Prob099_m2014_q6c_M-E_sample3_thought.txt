Novel design approach:
1. Implement a state transition decoder that generates all next-state signals (Y1-Y6) internally
2. Only expose the required outputs (Y1 and Y3) at the module interface
3. Use a more systematic approach by:
   - Creating a truth table for all state transitions
   - Generating each next-state bit independently
   - Optimizing only the required outputs
4. This approach makes the design more maintainable and extensible
5. The internal decoder can be easily modified if more outputs are needed later

Key advantages:
- Clear separation between state transition logic and output selection
- Easier to verify each state transition independently
- More scalable if additional outputs are needed in future
