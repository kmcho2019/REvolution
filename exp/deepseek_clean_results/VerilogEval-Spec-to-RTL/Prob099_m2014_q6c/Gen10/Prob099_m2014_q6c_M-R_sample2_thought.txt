1. We need to implement next-state signals Y2 (y[1]) and Y4 (y[3])
2. From the state machine:
   - Y2 (next y[1]) is active when:
     * Current state is A (y[0]) and w=0 (transition to B)
   - Y4 (next y[3]) is active when:
     * Current state is B (y[1]) and w=1 (transition to D)
     * Current state is C (y[2]) and w=1 (transition to D)
     * Current state is D (y[3]) and w=1 (transition to A)
     * Current state is E (y[4]) and w=1 (transition to D)
     * Current state is F (y[5]) and w=1 (transition to D)
3. Using one-hot encoding, we can derive these directly from current state and input
4. All other transitions keep Y2/Y4 at 0
