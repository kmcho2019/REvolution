Novel approach: State transition matrix decoder
1. Instead of deriving individual equations for each output, implement a complete state transition matrix
2. Create a truth table that maps current state (y) and input (w) to next state (Y)
3. Use a priority encoder approach where each state transition is explicitly defined
4. This method makes the state machine more maintainable and easier to verify
5. The outputs Y2 (next y[1]) and Y4 (next y[3]) are derived from the full transition logic

Key advantages:
- Explicitly shows all possible transitions
- Easier to modify if state machine changes
- Clear mapping between current state and next state
- Handles all edge cases explicitly
