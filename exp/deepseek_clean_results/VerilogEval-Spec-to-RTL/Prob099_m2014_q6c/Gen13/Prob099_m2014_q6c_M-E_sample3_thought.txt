Novel architectural idea:
1. Instead of directly implementing the next-state logic, use a lookup table approach that encodes all state transitions
2. Create a 6-bit next state vector where each bit represents a potential next state
3. Implement Y1 and Y3 as bits 1 and 3 of this next state vector
4. The lookup table approach makes the design more modular and easier to modify if state transitions change
5. For each current state, encode the possible next states based on input w
6. This method scales better for larger state machines and makes the transition rules more explicit
