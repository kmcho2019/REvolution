Instead of using separate assign statements for each output, let's implement a more compact solution using a case statement that considers the current state and input to determine the next state. This approach:

1. Uses a case statement to handle all state transitions in one place
2. Takes advantage of the one-hot encoding to simplify the case conditions
3. Directly computes the next state vector in one operation
4. Then extracts the specific bits (Y1 and Y3) from this next state vector

This method is more maintainable and easier to verify since all transitions are clearly listed in one place. The case statement acts as a truth table for the state machine.
