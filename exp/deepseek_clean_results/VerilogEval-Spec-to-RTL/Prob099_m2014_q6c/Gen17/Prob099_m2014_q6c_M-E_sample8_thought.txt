Novel architectural idea:
1. Instead of direct combinational logic, use a lookup table approach with a case statement
2. Leverage the one-hot encoding property to simplify state transitions
3. Implement the next-state logic by examining each possible current state
4. For each state, determine the next state based on input w
5. Extract only the required bits (Y1 and Y3) from the full next state

Advantages:
- More readable and maintainable state transition logic
- Easier to modify if state machine changes
- Clear mapping between states and transitions
- Efficient implementation using casez for one-hot decoding
