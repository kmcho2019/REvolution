Novel architectural idea:
1. Instead of using a case statement, implement the next-state logic directly using combinational logic equations
2. Leverage the one-hot encoding to create minimal logic for each state transition
3. Compute each next state bit independently based on current state and input
4. Focus only on the required outputs (Y1 and Y3) to minimize logic
5. Use parallel AND-OR structure for efficient implementation

Advantages:
- More efficient hardware implementation
- No need for full next-state computation (only required bits)
- Direct mapping from state diagram to logic equations
- Lower power consumption by computing only needed outputs
