Simplified Design Approach:
1. State Machine: Keep simple 3-state FSM (IDLE, BYTE1, BYTE2) with binary encoding
2. Data Storage: Directly store bytes into their respective positions in out_bytes when received
3. Output Control: Only update out_bytes when necessary (in relevant states) to reduce power
4. Reset Handling: Clear state and outputs synchronously on reset
5. Done Signal: Assert only after third byte is received, then return to IDLE

Key Simplifications:
- Remove unnecessary intermediate registers
- Eliminate redundant default assignments
- Simplify state transitions to minimal necessary logic
- Maintain don't-care outputs when not done
- Single always block for cleaner implementation
