Improvement Strategy:
1. State Encoding Optimization: Switch to one-hot encoding (3 states) to potentially improve timing by reducing combinational logic depth
2. Power Reduction: Add enable signals to only update registers when necessary
3. Area Optimization: Split output register into byte-wise components that are only enabled when needed
4. Timing Improvement: Pipeline the done signal generation to break critical path
5. Reset Optimization: Make reset more efficient by only clearing essential bits

Key Changes:
- One-hot state encoding (IDLE=001, BYTE1=010, BYTE2=100)
- Separate byte registers with individual enables
- Pre-compute done signal one cycle early
- Reduced register updates during idle periods
