Improvement Strategy:
1. Timing Optimization:
   - Switch from one-hot to binary state encoding (2 bits for 3 states) to reduce flip-flop count and combinatorial logic
   - Make 'done' signal combinational to break critical path through state register

2. Power Optimization:
   - Only update output registers when needed (during state transitions)
   - Use binary state encoding to reduce unnecessary toggling

3. Area Optimization:
   - Reduce state machine to 2 flip-flops (binary encoding)
   - Remove unnecessary reset of out_bytes (don't-care when not done)
   - Simplify output assignments to occur only during state transitions

Key Changes:
- Binary state encoding (00=IDLE, 01=BYTE2, 10=BYTE3)
- Combinational done signal for better timing
- Conditional output register updates
- Simplified state machine with minimal logic
