Improvement Strategy:
1. Timing Optimization: Switch from binary to one-hot encoding for state machine to reduce fan-out and improve timing closure
2. Power Optimization: 
   - Only update 'done' when actually transitioning to completion state
   - Minimize register updates by using a shift register approach
3. Area Optimization:
   - Replace separate byte registers with a shift register
   - Remove redundant default case
4. Functional Enhancement:
   - Ensure out_bytes is only updated when valid data is available
   - Clear output registers on reset

Key Changes:
- One-hot encoded state machine (4 states)
- Shift register for output bytes
- Conditional updates for 'done' signal
- Reduced register updates
- Cleaner reset handling
