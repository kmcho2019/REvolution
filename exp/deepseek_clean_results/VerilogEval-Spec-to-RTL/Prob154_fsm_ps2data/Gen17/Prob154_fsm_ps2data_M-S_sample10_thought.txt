Simplified Design Approach:
1. State Encoding: Use binary encoding (2 bits) instead of one-hot to reduce area and power
2. State Machine: Keep only 3 states (IDLE, BYTE1, BYTE2) with clear transitions
3. Data Storage: Store bytes directly into the output register during each state transition
4. Output Logic: Only update 'done' when transitioning from BYTE2 to IDLE
5. Reset Behavior: Clear all registers synchronously on reset

Key Simplifications:
- Removed unnecessary default assignments
- Reduced state encoding from 3 bits to 2 bits
- Eliminated redundant register updates
- Simplified state transition logic
- Maintained same functionality with fewer resources
