Novel Approach: Shift Register with Delayed Done
1. Instead of using explicit states, implement a shift register that captures bytes when in[3]=1 is detected
2. Use a counter to track the number of bytes received after the start condition
3. The shift register naturally aligns the bytes in the correct order (first byte in MSB)
4. Done signal is generated combinatorially when counter reaches 3, ensuring it's asserted in the cycle after the third byte
5. Reset clears both the shift register and counter
6. This approach minimizes state transitions and reduces control logic complexity
