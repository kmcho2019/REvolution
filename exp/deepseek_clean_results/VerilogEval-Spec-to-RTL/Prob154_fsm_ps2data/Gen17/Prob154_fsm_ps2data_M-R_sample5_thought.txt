Refactoring Strategy:
1. State Machine Restructuring: Replace one-hot encoding with binary encoding to reduce area and power
2. Output Handling: Use continuous assignments for outputs where possible
3. Byte Collection: Implement as a shift register for more compact representation
4. Control Logic: Separate state transitions from data path operations
5. Done Signal: Generate combinatorially for immediate response

Key Changes:
- Binary encoded state machine (2 bits) instead of one-hot
- Shift register for byte collection (simpler update logic)
- Combinatorial done signal generation
- Separate always blocks for state and data registers
- Maintains identical functionality with improved efficiency
