Simplified Design Approach:
1. State Encoding: Use binary encoding (2 bits) instead of one-hot to reduce area and power
2. State Transitions: Remove default assignments and only update state/output when needed
3. Data Storage: Store bytes directly in the appropriate position when received
4. Output Logic: Only update out_bytes when all 3 bytes are received (in BYTE2 state)
5. Reset Handling: Clear state and outputs synchronously on reset

Key Simplifications:
- Reduced state encoding from 3 bits to 2 bits
- Eliminated unnecessary default assignments
- Only update registers when data is actually being stored
- Simplified state transition logic
- Maintains same functionality with less hardware
