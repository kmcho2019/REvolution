Refactoring Strategy:
1. State Machine Restructuring: Convert the one-hot encoded state machine to a binary encoded one to reduce area and power
2. Output Logic Separation: Move output assignments to combinational logic using assign statements
3. Shift Register Implementation: Use a shift register approach for byte collection to simplify the datapath
4. Reset Handling: Maintain synchronous reset but simplify state transitions
5. Done Signal Generation: Generate done purely combinationally based on state

Key Changes:
- Binary encoded state machine (2 bits) instead of one-hot
- Combinational output assignments
- Shift register for byte collection
- Simplified state transition logic
- Maintains identical functionality with improved PPA metrics
