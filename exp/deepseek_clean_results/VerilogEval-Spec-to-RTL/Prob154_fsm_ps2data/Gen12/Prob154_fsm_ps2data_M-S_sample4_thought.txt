Simplified Design Approach:
1. State Encoding: Use binary encoding (2 bits) instead of one-hot to reduce area and power
2. State Transitions: Directly transition between states without default assignments
3. Data Storage: Only update relevant byte segments in each state
4. Output Control: Set 'done' only when third byte is received
5. Reset Handling: Clear all registers on reset

Key Simplifications:
- Reduced state encoding from 3 bits to 2 bits
- Removed unnecessary default assignments
- Simplified state transition logic
- Maintained same functionality with less hardware
