Novel Architecture Idea:
1. Shift Register Approach: Instead of storing bytes in separate registers, use a 24-bit shift register that shifts in new bytes from the left. This reduces register count and simplifies data movement.
2. Counter-Based State Machine: Use a 2-bit counter to track byte positions (0-2) instead of explicit states, reducing state decoding logic.
3. Early Done Detection: Generate the done signal combinatorially when the counter reaches 2, allowing it to be valid in the same cycle as the third byte.
4. Reset Optimization: Only reset the counter, not the shift register, since out_bytes is don't-care when not done.
5. Power Gating: The shift register only updates when valid bytes are being collected, reducing unnecessary switching.

Advantages:
- Reduced area from shift register implementation
- Simplified state machine with counter
- Faster done signal generation
- Lower power from gated updates
- Maintains clean timing with synchronous reset
