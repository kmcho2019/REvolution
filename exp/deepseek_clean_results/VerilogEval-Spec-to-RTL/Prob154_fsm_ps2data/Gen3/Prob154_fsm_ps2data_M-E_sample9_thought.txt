Novel Architecture:
1. Shift Register Approach: Instead of storing bytes separately, use a 24-bit shift register to accumulate bytes. This reduces register usage and simplifies data movement.
2. Optimized State Machine: Implement a 3-state machine (IDLE, COLLECTING, DONE) with minimal transitions for better timing.
3. Early Done Signal: Generate the done signal combinatorially based on state and counter to reduce latency.
4. Power Gating: Only update the shift register when actively collecting bytes to minimize power consumption.
5. Reset Optimization: Clear only necessary bits on reset to reduce fanout.

Key Advantages:
- Reduced area by eliminating separate byte registers
- Lower power consumption through conditional updates
- Faster timing with simpler state transitions
- Cleaner data path with shift register
