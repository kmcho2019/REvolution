The problem requires implementing a finite state machine (FSM) that processes an 8-bit input byte stream to detect 3-byte messages. The FSM should:
1. Wait for a start byte where in[3] is 1 (this is byte 1 of the message)
2. Collect the next two bytes (bytes 2 and 3)
3. Output the 3-byte message (24 bits) and assert 'done' in the cycle after receiving the third byte
4. Reset the process when 'reset' is high

We'll use a 3-state FSM:
- IDLE: Waiting for start byte (in[3]=1)
- BYTE2: Received first byte, waiting for second byte
- BYTE3: Received second byte, waiting for third byte

We'll need:
1. A state register to track current state
2. A shift register to accumulate the 3 bytes
3. Counter to track how many bytes we've received
4. Output registers for out_bytes and done
