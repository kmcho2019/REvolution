The design requires a finite state machine (FSM) with three states:
1. IDLE: Waiting for the start byte (in[3] = 1)
2. BYTE1: First byte received, waiting for second byte
3. BYTE2: Second byte received, waiting for third byte

When in BYTE2 state and receiving the third byte, we:
1. Output all three bytes (out_bytes)
2. Assert done
3. Return to IDLE to wait for next message

The FSM transitions are:
- IDLE -> BYTE1 when in[3] is 1
- BYTE1 -> BYTE2 on any byte
- BYTE2 -> IDLE on any byte (while outputting the message)

We'll need:
1. A state register (3 states)
2. A shift register to store the 3 bytes (24 bits)
3. Control logic for state transitions and output generation
