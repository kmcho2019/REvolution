The design requires a finite state machine (FSM) to detect message boundaries in a byte stream. The FSM will have three states:
1. IDLE: Waiting for the first byte with in[3]=1
2. BYTE2: First byte received, waiting for second byte
3. BYTE3: Second byte received, waiting for third byte

When in state BYTE3 and a new byte arrives, we:
- Output all 3 bytes (24 bits)
- Assert 'done' for one cycle
- Return to IDLE to search for next message

The datapath will store the incoming bytes in a shift register (24 bits) that shifts left by 8 bits for each new byte. When done is asserted, the shift register contains the complete message.
