The design requires a finite state machine (FSM) to detect message boundaries in a byte stream. The FSM will have three states:
1. IDLE: Waiting for the start byte (in[3] = 1)
2. BYTE1: First byte received, waiting for second byte
3. BYTE2: Second byte received, waiting for third byte

When in BYTE2 state and receiving the third byte, the FSM will:
- Output the 3-byte message (24 bits) by concatenating the stored bytes
- Assert 'done' for one cycle
- Return to IDLE state to wait for next message

The FSM will use registers to store the received bytes and a counter to track which byte is being received. Synchronous reset will initialize all registers and return to IDLE state.
