To implement this module, we need a finite state machine (FSM) with three states:
1. IDLE: Waiting for the first byte with in[3]=1
2. BYTE1: First byte received, waiting for second byte
3. BYTE2: Second byte received, waiting for third byte

The FSM transitions:
- From IDLE to BYTE1 when in[3]=1
- From BYTE1 to BYTE2 unconditionally on next byte
- From BYTE2 to IDLE unconditionally on next byte (and asserts done)

We'll need:
- A 2-bit state register
- A 24-bit shift register to store the 3-byte message
- A counter to track received bytes (0-2)
- Synchronous reset logic
- Output logic for done and out_bytes

The out_bytes should be valid only when done is asserted (after third byte).
