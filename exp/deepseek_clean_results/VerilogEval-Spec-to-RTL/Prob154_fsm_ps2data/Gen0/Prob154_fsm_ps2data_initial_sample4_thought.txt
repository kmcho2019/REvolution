The design requires a finite state machine (FSM) to detect message boundaries in a byte stream. The FSM will have three states:
1. IDLE: Waiting for the first byte with in[3]=1
2. BYTE2: Received first byte, waiting for second byte
3. BYTE3: Received second byte, waiting for third byte

When in state BYTE3 and receiving the third byte, the FSM will:
- Output the 24-bit message (3 bytes concatenated)
- Assert 'done' for one cycle
- Return to IDLE state to look for next message

The datapath will store incoming bytes in a shift register. On reset, all state is cleared.
