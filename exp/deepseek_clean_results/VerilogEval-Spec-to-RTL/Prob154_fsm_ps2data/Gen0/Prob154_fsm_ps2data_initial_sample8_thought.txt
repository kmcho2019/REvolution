The problem requires implementing a finite state machine (FSM) that:
1. Searches for message boundaries by looking for a byte with in[3]=1
2. Once found, collects the next 2 bytes to form a 3-byte message
3. Outputs the 24-bit message and asserts 'done' in the cycle after the third byte is received

We'll need:
- A 3-state FSM: IDLE (waiting for start byte), BYTE2 (received first byte), BYTE3 (received second byte)
- A shift register to store the 3-byte message
- A counter to track how many bytes we've received in the current message
- Synchronous reset functionality

The FSM transitions:
- IDLE -> BYTE2 when in[3]=1
- BYTE2 -> BYTE3 after next byte
- BYTE3 -> IDLE after next byte (and assert done)
- Any state -> IDLE on reset
