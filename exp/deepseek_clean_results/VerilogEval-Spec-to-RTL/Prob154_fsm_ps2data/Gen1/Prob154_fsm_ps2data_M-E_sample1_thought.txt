Instead of using a conventional FSM with explicit states, we can implement this using:
1. A 24-bit shift register that collects bytes sequentially
2. A 2-bit counter to track how many bytes we've collected
3. A 'valid' flag indicating when we're in message collection mode

Key differences from FSM approach:
- Uses counter instead of state machine for simpler control logic
- Shift register automatically handles byte ordering
- Valid flag acts as implicit state (0=searching, 1=collecting)
- Reset clears both counter and shift register

Operation:
- When in[3]=1 and not collecting (valid=0), start collection
- For each subsequent byte, shift into register and increment counter
- After 3 bytes, output result and reset collection
- Done signal is simply counter reaching 2 (third byte)
