Refactoring Strategy:
1. State Machine Restructuring: Use binary encoding instead of one-hot to reduce area and power
2. Output Handling: Move output assignments to combinational logic using assign statements
3. Byte Collection: Implement a shift register approach for more compact byte storage
4. Reset Logic: Keep synchronous reset but simplify the state transitions
5. Done Signal: Generate it combinationally based on state and input conditions

Key Changes:
- Binary encoded state machine (2 bits) for better area/power
- Combinational output assignments for clearer timing
- Shift register for byte collection (more efficient storage)
- Simplified state transition logic
- Maintains identical functionality with improved PPA metrics
