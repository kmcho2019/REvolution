Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding for potentially better timing and simpler state transitions
2. Output Logic: Use continuous assignments for out_bytes and done to separate combinational logic from sequential
3. Data Storage: Maintain separate registers for each byte to improve readability and potential synthesis optimization
4. Reset Handling: Keep synchronous reset but initialize all registers clearly
5. State Transitions: Simplify by removing nested conditionals and making each state transition explicit

Key Improvements:
- One-hot encoding may help timing closure in some synthesis tools
- Separating combinational and sequential logic can improve synthesis results
- Clearer byte storage with individual registers improves maintainability
- Explicit state transitions make the FSM behavior more obvious
- Continuous assignments for outputs may reduce logic levels
