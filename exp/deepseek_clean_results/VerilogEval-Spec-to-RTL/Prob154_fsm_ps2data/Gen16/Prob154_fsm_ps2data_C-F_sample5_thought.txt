Optimized Fusion Strategy:
1. State Encoding: Use binary encoding (2 bits) for minimal area/power while maintaining good timing
2. Data Collection: Implement direct byte storage with conditional updates to minimize power
3. Output Logic: Keep output valid only when done is asserted (don't-care otherwise)
4. Power Optimization: Only update registers when needed (no default assignments)
5. Timing Optimization: Simplified state transitions with minimal combinational logic
6. Reset Handling: Clear all registers synchronously

Key Improvements:
- Binary state encoding reduces area/power vs one-hot
- Conditional register updates eliminate unnecessary switching
- Output remains don't-care when not done
- No redundant default assignments
- Minimal state transitions for better timing
- Clear separation of state machine and data path
