Improvement Strategy:
1. State Machine Optimization: Use one-hot encoding for faster state transitions (better timing)
2. Power Reduction: Add enable signals to only update registers when needed
3. Area Optimization: Split output register into byte-wise registers that are only enabled during collection
4. Timing Improvement: Pipeline the done signal generation to break critical path
5. Reset Handling: Maintain synchronous reset but optimize register updates

Key Changes:
- One-hot state encoding (3 states)
- Byte-wise output register with enable signals
- Separate done generation logic
- Reduced unnecessary register updates
- Maintain same functionality while improving PPA
