Improvement Strategy:
1. Timing Optimization:
   - Switch from one-hot to binary state encoding (2 bits for 3 states) to reduce flip-flop count and combinatorial logic
   - Make 'done' signal combinational to break critical path through state register

2. Power Optimization:
   - Only update out_bytes when needed (during state transitions)
   - Remove unnecessary state bit toggling with binary encoding

3. Area Optimization:
   - Reduce state register from 3 bits to 2 bits
   - Remove redundant default state assignment
   - Simplify output assignments by making them conditional

Key Changes:
- Binary state encoding (00, 01, 10)
- Combinational done signal
- Conditional output assignments
- Simplified state transitions
