Improvement Strategy:
1. State Encoding: Switch from one-hot to binary encoding (2 bits) for the 3-state FSM to reduce flip-flop usage and simplify decoding logic.
2. Power Optimization:
   - Gate the 'done' signal to only update when transitioning from BYTE3 to IDLE
   - Implement byte-wise enable signals for out_bytes to reduce unnecessary switching
3. Timing Optimization:
   - Remove default case since all states are explicitly handled
   - Simplify state transition logic
4. Area Optimization:
   - Reduce state register width from 3 bits to 2 bits
   - Remove redundant reset logic for out_bytes since it only needs to be valid when done is asserted

Key Changes:
- Binary state encoding (2 bits) for better area efficiency
- Gated control signals for lower power
- Simplified state machine logic
- More efficient output handling
