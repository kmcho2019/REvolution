Novel Architecture:
1. Shift Register Approach: Instead of storing each byte separately, use a 24-bit shift register to accumulate the message bytes. This reduces register usage and simplifies data movement.
2. Counter-Based State Machine: Use a 2-bit counter to track message progress instead of explicit states. This reduces state decoding logic.
3. Early Done Detection: The done signal can be generated combinatorially when the counter reaches 2 (third byte), making it immediately responsive.
4. Reset Optimization: Only reset essential control signals (counter) and leave the shift register unreset for power/area savings.
5. Conditional Capture: Only shift in new bytes when in message collection mode (counter > 0 or start condition met).

Key Advantages:
- Reduced area from shift register implementation
- Simpler control logic with counter-based approach
- Immediate done signal response
- Lower power from conditional data movement
- Clean reset strategy
