Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding for potentially better timing in some synthesis tools
2. Output Logic: Use continuous assignments for out_bytes and done to separate combinational logic from sequential
3. Data Storage: Implement byte storage as a shift register to reduce area
4. Reset Handling: Keep synchronous reset but simplify the reset logic
5. Power Optimization: Only update storage registers when needed (during valid byte collection)

Key Changes:
- One-hot state encoding (3 bits) for potentially better timing
- Separate combinational and sequential logic blocks
- Shift register implementation for out_bytes storage
- Done signal generated combinationally from state
- Clear separation of state transitions and data storage
