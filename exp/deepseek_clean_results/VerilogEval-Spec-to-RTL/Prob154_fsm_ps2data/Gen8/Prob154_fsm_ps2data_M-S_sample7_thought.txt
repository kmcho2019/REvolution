Simplification Strategy:
1. State Reduction: Use a simple 2-bit counter instead of explicit states (IDLE, BYTE1, etc.)
2. Direct Storage: Store incoming bytes directly into the output register when valid
3. Minimal Logic: Only update done signal when third byte is received
4. Reset Handling: Keep synchronous reset for all registers
5. Output Handling: Let out_bytes be don't-care when not done (as specified)

Key Improvements:
- Eliminates explicit state machine encoding
- Reduces control logic complexity
- Maintains same functionality with fewer registers
- Simplifies byte collection logic
- Still meets all timing and functional requirements
