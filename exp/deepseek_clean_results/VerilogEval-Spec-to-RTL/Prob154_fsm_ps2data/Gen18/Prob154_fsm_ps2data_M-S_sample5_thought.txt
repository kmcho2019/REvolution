Simplified Design Approach:
1. State Machine: Keep binary encoding (2 bits) for minimal states (IDLE, BYTE1, BYTE2)
2. Data Storage: Only update output registers when needed (during state transitions)
3. Output Control: Set done only when third byte is received
4. Reset Handling: Maintain synchronous reset for consistency
5. Simplifications:
   - Remove default assignments since all cases are covered
   - Directly assign bytes to their positions without shifting
   - Clear done signal immediately after reset
   - Output don't-care when not done (implicit in register behavior)

Key Benefits:
- Reduced logic complexity by removing unnecessary assignments
- Maintains same functionality with cleaner state transitions
- Lower power by only updating registers when needed
- Minimal area with binary state encoding
