Refactoring Strategy:
1. State Machine Restructuring: Use binary encoding instead of one-hot to reduce area and power
2. Output Handling: Move output assignments to combinational logic using 'assign' statements
3. Byte Collection: Implement as a shift register for more compact representation
4. Done Signal: Generate it combinationally based on state
5. Reset Handling: Keep synchronous reset but simplify state transitions

Key Changes:
- Binary encoded state machine (2 bits) for better area/power
- Combinational output assignments
- Shift register for byte collection
- Clear separation of sequential and combinational logic
- Maintains identical functionality with improved PPA metrics
