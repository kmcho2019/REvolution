Simplified Design Approach:
1. State Machine: Use a simple 2-bit counter to track byte positions (0=waiting, 1=first byte, 2=second byte, 3=third byte)
2. Data Capture: Store incoming bytes in a shift register, shifting left by 8 bits each time a new byte is captured
3. Output Control: Only update the output registers when all 3 bytes are received (state=3)
4. Reset: Synchronous reset clears all registers
5. Power Optimization: Only update registers when necessary (during state transitions)

Key Simplifications:
- Eliminated separate state names in favor of simple counter
- Combined byte storage into a single shift operation
- Reduced logic by directly using counter for state tracking
- Minimized register updates to only when needed
