Novel Design Approach:
1. Shift Register: Use a 24-bit shift register to accumulate bytes sequentially
2. Counter Control: Track valid bytes received with a 2-bit counter instead of explicit states
3. Boundary Detection: Use combinational logic to detect the start condition (in[3]=1)
4. Output Management: Only update output when counter reaches 3 (full message)
5. Reset Handling: Synchronous reset clears all registers and counters

Key Innovations:
- Eliminates traditional state machine in favor of counter-based control
- Shift register naturally handles byte ordering (no need for separate storage)
- Combines boundary detection and byte counting in one mechanism
- More compact implementation with fewer registers
- Reduced control logic complexity
