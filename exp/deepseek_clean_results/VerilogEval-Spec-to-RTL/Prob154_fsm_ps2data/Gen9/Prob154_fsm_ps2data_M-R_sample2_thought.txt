Refactored Design Approach:
1. State Encoding: Use one-hot encoding for the state machine (3 states) to potentially improve timing
2. Output Logic: Move done signal to combinational logic to reduce register load
3. Data Storage: Keep byte storage sequential but optimize register updates
4. Reset Handling: Maintain synchronous reset but simplify output initialization
5. Power Optimization: Only update out_bytes when in non-IDLE states

Key Changes:
- One-hot state encoding for potentially better timing
- Combinational done signal reduces register usage
- Explicit state transitions for clarity
- Separate always blocks for state and data storage
- Cleaner reset handling
