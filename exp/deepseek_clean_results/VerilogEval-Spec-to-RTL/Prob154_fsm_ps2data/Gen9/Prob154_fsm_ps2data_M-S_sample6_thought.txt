Simplified Design Approach:
1. State Machine: Keep only 3 states (IDLE, BYTE1, BYTE2) with binary encoding for minimal area
2. Data Storage: Directly store each byte in its correct position when received
3. Output Control: Only update output registers when needed (during state transitions)
4. Reset Handling: Clear state and outputs synchronously
5. Done Signal: Assert only when all 3 bytes are collected (in BYTE2 state)

Key Simplifications:
- Removed unnecessary default assignments
- Simplified state transitions with direct conditions
- Eliminated redundant logic by combining storage and state transitions
- Maintained minimal control logic while preserving functionality
