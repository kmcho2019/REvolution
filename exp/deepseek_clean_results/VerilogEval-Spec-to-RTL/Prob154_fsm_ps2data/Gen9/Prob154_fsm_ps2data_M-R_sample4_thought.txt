Refactoring Strategy:
1. State Machine Restructuring: Convert the sequential always block to combinational logic for next state and output generation, separating state register into its own always block. This improves timing analysis and makes the FSM structure more explicit.
2. Output Logic Simplification: Use continuous assignments for outputs where possible to reduce register usage and simplify the code.
3. Byte Storage Optimization: Keep byte storage in sequential logic but only update when needed, reducing unnecessary switching activity.
4. Reset Handling: Maintain synchronous reset but make it more explicit in the state transitions.
5. Done Signal Generation: Make done purely combinational based on state, eliminating its register.

Key Changes:
- Split FSM into combinational next-state logic and sequential state register
- Use continuous assignment for done signal
- Keep byte storage in sequential block but only update during valid states
- Clearer separation of combinational and sequential logic
