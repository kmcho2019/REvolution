Novel Design Approach:
1. Shift Register: Use a 24-bit shift register to accumulate bytes, eliminating separate storage for each byte
2. Counter-Based State: Replace explicit FSM states with a 2-bit counter to track byte positions
3. Early Boundary Detection: Check in[3] only when counter is 0 (first byte), allowing simpler logic
4. Power Optimization: Only update shift register when valid data is being collected
5. Output Control: Directly use shift register for output, with done signal synchronized to counter wrap

Key Innovations:
- Eliminates traditional state machine in favor of counter-based tracking
- Shift register naturally handles byte ordering without explicit position management
- Reduced logic complexity by only checking boundary condition at counter=0
- Minimized register updates by only shifting when collecting valid bytes
