2. Power Optimization: Add register enables to only update out_bytes when necessary (during byte capture)
3. Area Optimization: Keep binary state encoding (minimal bits) but optimize the output register updates
4. Critical Path: Break the byte storage into separate always blocks to reduce fanout on the state signals
5. Output Logic: Make 'done' combinational to save a flip-flop while meeting timing

- One-hot state encoding for faster state transitions
- Separate always blocks for state and data registers
- Conditional updates for out_bytes to reduce switching power
