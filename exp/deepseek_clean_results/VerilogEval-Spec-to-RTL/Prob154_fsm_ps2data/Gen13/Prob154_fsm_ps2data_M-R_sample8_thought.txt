Refactoring Strategy:
1. State Encoding: Switch from binary to one-hot encoding for better timing (reduces fan-out)
2. Power Optimization: Make 'done' signal purely combinational to reduce unnecessary register updates
3. Area Reduction: Use a shift register approach for out_bytes instead of separate byte storage
4. Output Handling: Keep output as don't-care when not done, but implement with cleaner combinational logic
5. Reset Logic: Maintain synchronous reset but simplify default assignments

Key Changes:
- One-hot state encoding (4 states: IDLE, BYTE1, BYTE2, BYTE3)
- Shift register for out_bytes (reduces area)
- Combinational done signal (reduces power)
- Cleaner state transitions with explicit next_state logic
