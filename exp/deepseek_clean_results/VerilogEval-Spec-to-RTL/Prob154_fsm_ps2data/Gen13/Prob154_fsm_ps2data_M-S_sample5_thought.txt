Simplified Design Approach:
1. State Encoding: Use binary encoding (2 bits) since we only need 3 states - more efficient than one-hot for small FSMs
2. State Transitions: Directly transition between states without default assignments to reduce logic
3. Data Storage: Store bytes as they arrive in the appropriate position of out_bytes
4. Output Control: Only update done when we've received all 3 bytes
5. Reset Handling: Clear all registers synchronously on reset

Key Simplifications:
- Reduced state encoding from 3 bits to 2 bits
- Removed unnecessary default assignments
- Simplified state transition logic
- Maintained same functionality with less hardware
