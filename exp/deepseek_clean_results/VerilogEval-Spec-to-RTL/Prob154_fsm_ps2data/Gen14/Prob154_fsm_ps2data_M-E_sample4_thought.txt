Novel Architecture Idea:
1. Shift Register Approach: Instead of storing bytes in separate registers, use a 24-bit shift register to capture incoming bytes sequentially. This reduces register count and simplifies data movement.
2. Simplified State Machine: Use a 2-state machine (IDLE and COLLECT) with a byte counter, eliminating the need for multiple state transitions.
3. Early Done Calculation: Compute the done signal combinatorially based on the current state and byte count, allowing it to be asserted immediately after the third byte.
4. Power Optimization: Only shift in new data when in COLLECT state, reducing unnecessary switching activity.
5. Reset Handling: Clear all registers synchronously on reset, including the shift register.

Key Advantages:
- Reduced register count by using a shift register
- Simpler state machine with fewer transitions
- Combinatorial done signal for immediate assertion
- Lower power consumption by minimizing unnecessary operations
- Clean reset behavior
