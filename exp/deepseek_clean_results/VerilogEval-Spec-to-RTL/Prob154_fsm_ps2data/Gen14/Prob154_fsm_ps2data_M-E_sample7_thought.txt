Novel Architecture Idea:
1. Shift Register Approach: Instead of storing bytes in separate registers, use a 24-bit shift register that shifts in new bytes from the left. This reduces register count and simplifies byte concatenation.
2. Simplified State Machine: Use a 2-state machine (IDLE and COLLECT) with a 2-bit counter to track byte positions. This reduces state transitions and logic complexity.
3. Early Done Detection: Generate the 'done' signal combinatorially based on the counter value, eliminating one clock cycle delay.
4. Power Optimization: Only shift in new data when in COLLECT state, reducing unnecessary switching activity.
5. Reset Handling: Clear all registers synchronously on reset, including the shift register.

Key Advantages:
- Reduced register count (single 24-bit shift register vs three 8-bit registers)
- Simpler state machine with fewer transitions
- Combinatorial done signal for immediate response
- Lower power consumption due to reduced switching
- More compact implementation
