Simplification Strategy:
1. State Reduction: Use a simple 2-bit counter to track byte position (0=waiting, 1=first byte, 2=second byte, 3=third byte)
2. Direct Assignment: Assign input bytes directly to output positions as they arrive
3. Single Always Block: Handle all logic in one synchronous block for clarity
4. Minimal Control Logic: Only reset and increment state, with simple done condition
5. Power Optimization: Only update output registers when collecting bytes (not in idle state)

Key Improvements:
- Eliminates separate state names in favor of simple counter
- Reduces control logic to just incrementing counter
- Maintains same functionality with fewer lines of code
- Still meets all timing and functional requirements
