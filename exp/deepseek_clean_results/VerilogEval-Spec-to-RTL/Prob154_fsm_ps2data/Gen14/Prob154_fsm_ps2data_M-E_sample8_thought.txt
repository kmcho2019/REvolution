Novel Architecture Idea: Shift Register with State Tracking
1. Instead of using separate states for each byte, use a shift register approach combined with a counter
2. Implement a 24-bit shift register that shifts in new bytes when valid (in[3]=1)
3. Use a 2-bit counter to track how many bytes have been received (0-3)
4. When counter reaches 3, assert done and output the accumulated bytes
5. Reset counter and shift register when done is asserted or when reset occurs
6. This approach minimizes state transitions and reduces control logic complexity

Advantages:
- Fewer state transitions compared to FSM approach
- More compact implementation with counter
- Easier to extend for variable-length messages if needed
- Reduced control logic complexity
- Better timing due to simpler state tracking
