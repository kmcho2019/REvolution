Optimization Strategy:
1. Timing Improvement:
   - Replace sequential state machine with one-hot encoding (trades area for timing)
   - Generate 'done' combinationally to break critical path
   - Simplify output register updates to reduce fanout

2. Power Reduction:
   - Implement clock gating for output registers
   - Only update output registers when needed
   - Minimize state transitions

3. Area Optimization:
   - Use shift register approach for output bytes
   - Reduce state encoding to minimal bits (2 bits)
   - Remove unnecessary registers

Key Changes:
- One-hot state encoding for better timing
- Shift register implementation for output bytes
- Combinational done generation
- Gated register updates
- Simplified state transitions
