Novel Architecture Idea:
1. Shift Register Storage: Instead of separate byte storage, use a 24-bit shift register that automatically aligns bytes as they arrive. This reduces control logic and area.
2. Counter-Based State: Replace explicit FSM states with a 2-bit counter to track byte positions (0=waiting, 1=first byte, 2=second byte, 3=third byte).
3. Early Detection: Check in[3] only when counter is 0 (waiting state) to reduce switching activity.
4. Power Optimization: Only shift/update the register when actually storing a byte (counter > 0).
5. Output Control: Use combinational logic for done signal based on counter value to avoid extra flops.

Advantages:
- Eliminates explicit state machine logic
- Shift register naturally handles byte ordering
- Counter implementation is more compact than FSM
- Reduced power consumption from minimized register updates
