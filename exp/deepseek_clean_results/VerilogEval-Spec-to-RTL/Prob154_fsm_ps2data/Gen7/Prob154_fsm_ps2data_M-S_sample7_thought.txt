Simplified Design Approach:
1. State Management: Keep binary encoding (2 bits) for minimal state representation
2. Data Collection: Store bytes directly into their respective positions in out_bytes when received
3. Output Logic: Only update out_bytes when necessary (during BYTE1 and BYTE2 states)
4. Reset Handling: Clear state and done signal on reset, leave out_bytes as don't-care
5. Timing: Remove unnecessary logic by making state transitions and assignments straightforward
6. Power: Minimize register updates by only storing bytes when in the correct state

Key Simplifications:
- Remove redundant default assignments
- Direct state transitions without intermediate steps
- Only update out_bytes when actually storing a byte
- Clear done signal immediately after assertion
- Minimal state machine with just 3 states
