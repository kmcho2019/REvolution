Fusion Strategy:
1. State Encoding: Use binary encoding (2 bits) for optimal area efficiency while maintaining good timing
2. Data Collection: Implement direct byte storage with conditional updates to minimize power
3. Output Logic: Keep output valid only when done is asserted, with don't-care values otherwise
4. Power Optimization: Only update registers when needed (during state transitions)
5. Timing Optimization: Simplify state transitions and remove default assignments where possible
6. Reset Handling: Maintain synchronous reset for predictable behavior

Key Improvements:
- Binary state encoding reduces flip-flop usage compared to one-hot
- Conditional register updates minimize power consumption
- Clean state transitions with no redundant logic
- Output remains don't-care when not done to save power
- Minimal combinational logic for better timing
- No unnecessary register updates
- Clear separation of state transition logic and data path
