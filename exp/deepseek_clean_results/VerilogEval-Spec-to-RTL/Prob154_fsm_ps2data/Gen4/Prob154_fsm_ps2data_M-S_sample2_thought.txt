Simplification Strategy:
1. State Encoding: Use binary encoding (2 bits) instead of one-hot for 3 states - more efficient for small FSMs
2. Output Handling: Only update out_bytes when needed (during state transitions)
3. Done Signal: Simplify logic by only setting it in BYTE3 state
4. Reset Logic: Keep minimal reset requirements (only state and done need reset)
5. Remove Default Case: Not needed since all states are explicitly handled

- Binary state encoding reduces flip-flop usage
- Simplified state transitions
- Cleaner output handling
- More efficient done signal generation
- Removed unnecessary logic
