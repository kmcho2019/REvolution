Refactoring Strategy:
1. State Machine Restructuring: Replace the case-based state machine with a counter-based approach for simpler logic and better timing.
2. Output Logic: Use continuous assignments for outputs to reduce register usage and improve timing.
3. Power Optimization: Only update the output registers when needed (during valid byte reception).
4. Reset Handling: Simplify reset logic by only resetting essential control signals.
5. Done Signal: Generate done combinatorially to reduce register usage.

Key Changes:
- Counter-based state tracking instead of explicit state machine
- Combinational done signal generation
- Direct output assignments without intermediate registers
- Reduced register updates to only when needed
