Simplification Strategy:
1. State Reduction: Use a simple 2-bit counter to track byte position instead of explicit states
2. Data Collection: Shift bytes directly into output register when valid (in[3]=1)
3. Output Control: Only update output registers when needed (when collecting bytes)
4. Reset Handling: Maintain synchronous reset for all registers
5. Power Optimization: Minimize register updates by only storing bytes when in collection mode

Key Improvements:
- Eliminate explicit state machine in favor of counter-based approach
- Reduce logic complexity by using counter to track progress
- Maintain clean output handling with don't-care when not done
- Minimize area by using counter instead of state machine
- Reduce power by only updating registers when collecting bytes
