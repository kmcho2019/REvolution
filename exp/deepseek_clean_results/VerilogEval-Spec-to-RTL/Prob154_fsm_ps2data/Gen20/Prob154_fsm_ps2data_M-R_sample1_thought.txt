Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding for potentially better synthesis optimization
2. Output Logic: Move done signal to combinational logic for immediate assertion
3. Data Storage: Use shift register approach for more compact byte storage
4. Reset Handling: Keep synchronous reset but simplify default assignments
5. Power Optimization: Only update registers when needed (byte storage)

- One-hot state encoding (3 bits) for potentially better timing
- Combinational done signal for immediate assertion
- Shift register for byte storage (reduces area)
- Simplified state transitions with explicit conditions
- Clear separation of sequential and combinational logic
