Refactoring Strategy:
1. State Machine Optimization:
   - Switch from one-hot to binary encoding (2 bits for 3 states) to reduce flip-flop count
   - Make state transitions more explicit with next_state logic

2. Output Handling:
   - Use combinational logic for 'done' signal to improve timing
   - Implement byte capture as sequential writes to different portions of out_bytes

3. Reset Handling:
   - Only reset essential control signals (state) since out_bytes is don't-care when not done

Key Improvements:
- Binary state encoding reduces area and power
- Combinational done signal removes one clock cycle delay
- Clear separation of state transition logic and output logic
- Reduced register updates by only writing relevant byte positions
