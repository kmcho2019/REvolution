Novel Architecture: Shift Register with One-Hot State Encoding
1. State Encoding: Use one-hot encoding (3 bits) for better timing and simpler decoding
2. Data Collection: Implement a circular shift register for the 3-byte buffer
3. Power Optimization: Only shift/update registers when needed (gated clock enable)
4. Output Logic: Parallel output from shift register when done
5. Reset Handling: Clear only necessary bits on reset

Key Innovations:
- Circular shift register minimizes area by reusing storage
- One-hot state encoding improves timing (better for small FSMs)
- Gated updates reduce power consumption
- Clear separation between control and data path
- Optimized reset to only clear active registers
