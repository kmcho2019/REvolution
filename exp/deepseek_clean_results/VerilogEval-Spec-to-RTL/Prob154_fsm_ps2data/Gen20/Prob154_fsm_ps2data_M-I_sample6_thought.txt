Improvement Strategy:
1. Timing Optimization:
   - Reduce critical path by simplifying state transitions to only 2 states (IDLE and COLLECT)
   - Use a 2-bit counter within COLLECT state to track byte position
   - Eliminate intermediate state transitions between bytes

2. Power Optimization:
   - Only update output registers when actually collecting bytes
   - Gate the done signal generation to only evaluate in the final cycle
   - Minimize register updates during IDLE state

3. Area Optimization:
   - Reduce state encoding to 1 bit (IDLE/COLLECT)
   - Use byte position counter instead of separate states
   - Simplify output register assignments

Key Changes:
- Combine all collection states into single COLLECT state with counter
- Only update registers when in COLLECT state
- Generate done signal combinatorially in final cycle
- Optimize state machine for faster transitions
