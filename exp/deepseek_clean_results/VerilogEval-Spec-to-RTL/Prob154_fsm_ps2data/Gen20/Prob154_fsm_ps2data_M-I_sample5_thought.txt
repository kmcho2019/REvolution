Improvement Strategy:
1. State Encoding: Switch from one-hot to binary encoding to reduce area and power while maintaining acceptable timing
2. Output Handling: Use a shift register for byte collection to minimize register usage
3. Power Optimization: Only update registers when state changes occur
4. Timing Optimization: Break critical path by separating state transitions from output assignments
5. Reset Efficiency: Maintain synchronous reset but simplify reset conditions

Key Changes:
- Binary encoded state machine (2 bits) for reduced area and power
- Shift-register implementation for byte collection (3x8 bits)
- Conditional updates to reduce switching activity
- Simplified control logic
- Maintains same functionality while improving PPA metrics
