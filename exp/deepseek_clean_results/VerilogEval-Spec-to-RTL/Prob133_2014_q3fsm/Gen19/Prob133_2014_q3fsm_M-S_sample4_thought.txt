Simplified approach:
1. Reduce state machine to just 2 states (A and B) since that's all we need
2. Use a 2-bit counter to track the 3-cycle window in state B
3. Instead of storing all 3 w values, just count how many 1's we've seen in current window
4. Generate z output when counter wraps around (cycle_count == 2'b10)
5. Reset everything when in state A or when reset is active

Key simplifications:
- Eliminated w_samples shift register (saves 3 bits)
- Replaced 3-bit adder with simple increment/decrement
- Output z directly when window completes (no extra cycle delay)
- Fewer registers overall while maintaining same functionality
