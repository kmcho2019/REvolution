Novel Architecture Idea: Shift Register with Pattern Matching
Instead of using counters, we can implement a 3-bit shift register to track the last 3 values of w. This allows us to:
1. Directly observe the window of interest
2. Use combinational logic to detect the "exactly two 1's" pattern
3. Eliminate the need for separate cycle counting
4. Reduce state transitions by making output purely dependent on shift register contents

Key Features:
- 3-bit shift register captures the moving window
- Pattern matching detects 011, 101, or 110 patterns (exactly two 1's)
- State machine remains minimal (just A and B states)
- Output generation is simple combinational logic
- No arithmetic operations needed (no adders/counters)
- Lower power as shift register only updates in state B
