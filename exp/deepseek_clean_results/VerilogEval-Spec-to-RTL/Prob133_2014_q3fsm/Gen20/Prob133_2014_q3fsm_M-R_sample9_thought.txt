Refactoring Approach:
1. State Machine Restructuring: Convert the sequential state transition logic to combinational assign statements for clarity
2. Counter Logic: Move the counter updates to separate always blocks for better modularity
3. Output Logic: Keep combinational but simplify the condition by pre-computing window completion
4. Reset Handling: Maintain synchronous reset but make it more explicit in each always block
5. Code Organization: Group related logic together (state, counters, output) for better readability

Key Changes:
- State transition is now purely combinational using assign
- Counter updates are separated into dedicated always blocks
- Output logic remains combinational but with clearer window boundary detection
- Maintains same functionality while improving code structure
