To implement this FSM, we need:
1. Two main states: A (reset state) and B (counting state)
2. In state A, wait for s=1 to transition to B
3. In state B, we need to track w over 3 cycles and count how many times w=1
4. After 3 cycles, output z=1 if exactly two w=1 were seen, else z=0
5. Use a 2-bit counter to track cycles in state B and another counter for w=1 occurrences
6. Reset all counters when returning to state A

The FSM will have:
- State A: Initial state, waits for s=1
- State B: Counts w over 3 cycles, then evaluates and resets counters
