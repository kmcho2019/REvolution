To implement this FSM, we need:
1. Two main states: A (reset state) and B (counting state)
2. In state A, wait for s=1 to transition to B
3. In state B, we need to track w over 3 cycles and count how many times w=1
4. After 3 cycles, output z=1 if exactly two w=1s occurred, else z=0
5. Use a 2-bit counter to track cycles in state B (0-2)
6. Use another 2-bit counter to count w=1 occurrences
7. Reset counters when starting new 3-cycle window
8. Output z is registered and only set after the 3rd cycle
