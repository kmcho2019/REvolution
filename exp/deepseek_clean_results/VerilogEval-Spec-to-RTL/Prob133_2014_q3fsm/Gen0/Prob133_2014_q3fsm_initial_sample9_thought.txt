To implement this FSM, we'll need:
1. Two main states: A (initial state) and B (counting state)
2. A 2-bit counter to track the number of clock cycles in state B (0-2)
3. A 2-bit accumulator to count how many times w=1 in each 3-cycle window
4. Logic to:
   - Transition from A to B when s=1
   - Count w=1 occurrences during each 3-cycle window in state B
   - Set z=1 in the cycle after a window completes if exactly two w=1 occurred
   - Reset counters when moving between states or completing a window

The FSM will use synchronous reset and positive edge-triggered logic.
