To implement this FSM, we need:
1. Two main states: A (initial state) and B (counting state)
2. In state A: wait for s=1 to transition to B
3. In state B: 
   - Count the number of w=1 occurrences over 3 cycles
   - After 3 cycles, set z=1 if exactly 2 w=1 occurred
   - Reset the counter and repeat
4. Use a 2-bit counter to track cycles in state B (0-2)
5. Use another 2-bit counter to count w=1 occurrences
6. Synchronous reset returns to state A and clears all counters
