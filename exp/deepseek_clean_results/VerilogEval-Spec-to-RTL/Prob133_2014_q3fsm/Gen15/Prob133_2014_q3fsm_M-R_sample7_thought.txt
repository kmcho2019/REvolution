Refactoring Approach:
1. Convert the sequential state machine to a purely combinational next-state logic using assign statements
2. Replace the phase counter with a modulo-3 counter implemented via arithmetic
3. Maintain the shift register but implement it with concatenation in a single line
4. Move all combinational logic to continuous assignments
5. Keep the same state encoding and output conditions
6. Simplify the reset logic by merging it with the main always block

Key Changes:
- State transitions and phase counting are now purely combinational
- Shift register update is more concise
- All combinational calculations are outside always blocks
- Reduced number of lines while maintaining same functionality
- Improved readability through consistent assignment style
