Novel Approach: "Lazy Evaluation with State Compression"
1. State Encoding: Use 3 states (A, B_WAIT, B_EVAL) to clearly separate waiting and evaluation phases
2. Counting Mechanism: Instead of storing all 3 w values, maintain a running count of 1's in the current window
3. Evaluation Timing: Perform evaluation only at the window boundary (every 3rd cycle)
4. Optimization:
   - Eliminates shift register storage
   - Reduces adder usage to just increment/decrement
   - Clear separation of phases improves timing
5. Key Features:
   - State B_WAIT collects w values
   - State B_EVAL performs the 2-of-3 check
   - Output z is registered for clean timing
   - Minimal storage (only need count and cycle counter)
