Refactoring Approach:
1. Replace the always block with continuous assignments for state and phase updates
2. Use a ternary operator for state transition logic instead of if-else
3. Implement the shift register using concatenation in an assign statement
4. Move all sequential logic to clocked assignments while keeping combinational logic in assigns
5. Simplify the phase counter by using modular arithmetic (phase = (phase + 1) % 3)
6. Maintain the same state encoding and popcount logic but express more functionally

Key Benefits:
- More functional programming style while maintaining same behavior
- Clear separation of combinational and sequential logic
- Reduced procedural code in favor of declarative assignments
- Same minimal state machine but expressed differently
- Maintains all original functionality and timing characteristics
