Refactoring Strategy:
1. State Machine Restructuring: Convert the sequential state transition logic to combinational assign statements for clarity
2. Counter Optimization: Replace the modulo-3 counter with a simpler terminal count detection
3. Shift Register Simplification: Use explicit bit assignments instead of concatenation for better readability
4. Output Timing Adjustment: Maintain the same evaluation timing but express the condition more clearly
5. Reset Logic: Keep synchronous reset but make it more explicit in the assignments

Key Changes:
- All sequential logic moved to a single always block
- State transitions expressed as continuous assignments
- Counter logic simplified with direct comparison
- Shift register updates made more explicit
- Output condition broken down for better readability
