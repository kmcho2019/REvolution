Novel Architecture Idea:
1. Instead of using counters, implement a 3-bit shift register to track the last 3 values of w
2. Use a single state bit (A/B) and a 2-bit phase counter to track position in the 3-cycle window
3. Implement a combinational popcount circuit that counts 1s in the shift register
4. Output z is generated when:
   - In state B
   - At the end of each 3-cycle window (phase=0)
   - Exactly two 1s are present in the shift register
5. Reset clears all registers and returns to state A

Key Advantages:
- Shift register provides direct visibility into the 3-cycle window
- Popcount is purely combinational, simplifying timing analysis
- Phase counter is simpler than full cycle counting
- Minimal state transitions
- Easy to extend to different window sizes
