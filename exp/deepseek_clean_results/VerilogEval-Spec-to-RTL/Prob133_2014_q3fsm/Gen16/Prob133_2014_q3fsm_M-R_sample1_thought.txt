Refactoring Approach:
1. State Machine Restructuring: Convert the procedural state machine to a continuous assignment style using ternary operators
2. Counter Logic: Move counter updates to continuous assignments while maintaining the same functionality
3. Output Logic: Keep combinational but simplify the condition checking
4. Reset Handling: Implement synchronous reset through assignment conditions
5. Key Changes:
   - Replace always blocks with assign statements for state and counters
   - Use ternary operators for all sequential logic
   - Maintain same state encoding and counting mechanism
   - Simplify output logic by pre-computing window completion signal
   - Make all transitions explicit in the continuous assignments

Benefits:
- More concise implementation
- All logic becomes visible at module level
- Easier to see all transitions and conditions
- Maintains same functionality with identical state behavior
