Novel Approach: Shift Register with Parallel Detection
1. Instead of counters, use a 3-bit shift register to store the last 3 values of w
2. Detect when exactly two bits are 1 using combinational logic (XOR-based)
3. State machine remains minimal (just A/B states)
4. Output z is asserted one cycle after the 3-bit window is filled
5. Advantages:
   - Eliminates arithmetic operations (no adders)
   - Parallel detection of the "exactly two 1's" condition
   - Simple state machine with clear separation of concerns
   - No need for cycle counting - shift register implicitly tracks window
