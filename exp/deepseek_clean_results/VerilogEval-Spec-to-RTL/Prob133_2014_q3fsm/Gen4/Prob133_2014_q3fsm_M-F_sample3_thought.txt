   - Covers all 3 possible combinations (011, 101, 110)

3. **Output Timing Fix**:

   - Maintains its value between evaluations (no glitching)
   - Clear only on reset

4. **Simplified Logic**:
   - Removed redundant eval_now signal
   - Directly use window_done for timing control
   - More efficient bit counting implementation
