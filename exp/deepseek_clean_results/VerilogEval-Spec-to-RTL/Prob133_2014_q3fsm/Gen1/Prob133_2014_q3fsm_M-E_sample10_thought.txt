Instead of using counters, we can:
1. Use a 3-bit shift register to track the last 3 values of w
2. In state B, continuously shift in w values
3. Every cycle, count the number of 1's in the shift register in parallel
4. When the shift register is full (after 3 cycles), set z based on the count
5. This eliminates the need for cycle counting and simplifies the state machine
6. The shift register naturally handles the 3-cycle window without explicit counting
