To simplify the FSM implementation:
1. Keep just two states: A (wait for s=1) and B (counting state)
2. In state B, use a 2-bit shift register to track last 3 w values
3. After each cycle in B, check if exactly two of the last 3 w values were 1
4. Output z=1 in the next cycle when the condition is met
5. Eliminate separate counters by using the shift register for both storage and counting
6. Reset the shift register when entering state B
7. Make output z purely combinational based on shift register contents
