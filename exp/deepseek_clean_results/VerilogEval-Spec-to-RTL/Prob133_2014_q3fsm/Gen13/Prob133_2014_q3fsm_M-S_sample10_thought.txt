Simplified approach:
1. Maintain the 2-state FSM (A and B) with same state transitions
2. Instead of storing all 3 w values, use a counter to track the number of 1's in the current 3-cycle window
3. Use a 2-bit position counter to track window position (0-2)
4. Evaluate the 1's count when the position counter wraps (after 3 cycles)
5. Generate output z one cycle after evaluation
6. Reset all counters when in state A

Key simplifications:
- Eliminated w_history shift register by using a rolling counter
- Reduced storage requirements (3 bits -> 2 bits)
- Simplified output logic by directly using the counter value
- Maintained same evaluation timing (z updates one cycle after window completes)
