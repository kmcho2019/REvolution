Simplified Design Idea:
1. State Representation: Keep minimal 2 states (A/B) with 1-bit encoding
2. Counting Approach: Instead of storing all 3 w values, maintain a 2-bit counter for number of 1's in current window
3. Window Tracking: Use a 2-bit cycle counter to track position in 3-cycle window
4. Output Logic: Set z=1 when window completes (cycle_count=2) and exactly two 1's were counted
5. Optimizations:
   - Eliminate pattern storage and matching logic
   - Reduce register usage (2-bit counter instead of 3-bit pattern)
   - Simpler comparison logic (count == 2)
   - Maintain same functionality with less hardware
