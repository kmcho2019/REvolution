Simplified approach:
1. Reduce state machine to just 2 states (A and B) since that's all we need
2. Instead of storing all 3 w samples, just count how many 1's we've seen in current window
3. Use a 2-bit counter to track both the cycle count and the number of 1's seen
4. Generate z output when cycle count wraps around (every 3 cycles)
5. Reset counters when in state A or when reset is active

Key optimizations:
- Eliminated the 3-bit shift register by counting 1's on the fly
- Combined cycle count and ones count into a single 2-bit counter
- Simplified output logic to just check the count at window boundaries
- Reduced total register bits from 6 (1+2+3) to just 3 (1+2)
