Novel Architecture Idea:
1. State Compression: Instead of tracking cycles, use a 2-bit counter to directly count 'w' occurrences
2. Immediate Evaluation: Calculate the 2-of-3 condition in real-time without storing history
3. Smart Reset: Reset counter only when leaving state B or on system reset
4. Output Pipelining: Register the output for clean timing
5. Key Innovations:
   - Eliminates shift register entirely
   - Uses minimal state encoding (1-bit)
   - Combines cycle counting and w evaluation in single counter
   - Output is registered for better timing closure
   - More power efficient as fewer registers toggle
