Novel Architecture Idea:
1. Use a 3-bit shift register to capture the last 3 values of w in state B
2. Implement pattern matching on the shift register contents to detect exactly two 1's
3. Use a modulo-3 counter to track when to evaluate the shift register
4. Output z is simply the pattern match result when the counter wraps
5. State transitions remain simple (A/B) but now we leverage parallel pattern matching

Advantages:
- Eliminates arithmetic operations (no adders needed)
- Parallel pattern matching can be more timing-friendly
- Shift register naturally captures the 3-cycle window
- Clear separation between data capture and evaluation phases
- Easily extensible to other pattern matching requirements
