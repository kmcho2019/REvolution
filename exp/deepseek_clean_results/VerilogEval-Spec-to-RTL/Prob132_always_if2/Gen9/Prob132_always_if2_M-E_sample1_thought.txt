Here's a novel approach using hierarchical state encoding and explicit default assignments:

1. Instead of simple combinational logic, we'll use a state encoding scheme that represents all possible input combinations
2. Create explicit default assignments for all outputs at the beginning of the always block
3. Use a priority-encoded structure that clearly shows the decision hierarchy
4. Add a "safe mode" state that could be expanded for future functionality

Key innovations:
- Explicit default assignments prevent latch inference
- Priority encoding makes the control flow clearer
- State encoding provides a framework for future expansion
- Maintains the same functionality while being more maintainable
