Instead of using separate always blocks with default assignments, we can implement this as a purely combinational logic module using continuous assignments. This approach:
1. Eliminates the need for procedural blocks entirely
2. Makes the design more concise and easier to understand
3. Still prevents latch inference since all outputs are continuously driven
4. Explicitly shows the logic relationships between inputs and outputs
5. Potentially reduces power consumption by avoiding unnecessary default assignments
6. May lead to better synthesis results as the logic is more direct and explicit
