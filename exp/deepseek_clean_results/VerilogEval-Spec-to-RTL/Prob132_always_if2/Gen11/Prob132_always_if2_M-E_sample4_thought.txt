This solution implements a priority-encoded state machine approach that:
1. Uses a centralized control logic block that evaluates all inputs simultaneously
2. Implements explicit priority handling (safety first - overheating takes precedence)
3. Makes the logic more extensible for future modifications
4. Uses a parameterized approach for easy scaling
5. Includes explicit default assignments to prevent latch inference
6. The logic prioritizes:
   - Safety (cpu_overheated) as highest priority
   - Then operational status (arrived/gas_tank_empty)
This approach provides better maintainability and clearer priority handling while remaining combinational.
