Novel Approach: State-Based Output Control
1. Instead of pure combinational logic, implement a simple state machine that tracks the system status
2. Use a 2-bit state register to encode four possible states (normal, overheated, arrived, empty)
3. Outputs are determined by current state rather than direct input conditions
4. This provides better scalability for future enhancements and more explicit state representation
5. While slightly more complex, this approach better models real-world system behavior where outputs depend on system state rather than just instantaneous inputs

Key Advantages:
- More maintainable and extensible design
- Clear separation between state tracking and output generation
- Easier to add new conditions or states in future
- More robust against input glitches
- Better matches how physical systems often behave
