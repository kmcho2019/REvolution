The current implementation uses an always block with default assignments, which is good for avoiding latches but creates redundant logic. We can optimize this by:
1. Using continuous assignments (assign) for both outputs since they are simple combinational logic
2. Eliminating the procedural block entirely
3. Making the logic more direct and explicit
This approach will:
- Remove unnecessary default assignments
- Make the code more concise
- Potentially reduce power by eliminating the always block sensitivity list
- Maintain exactly the same functionality
