Instead of pure combinational logic, we can implement this as a simple state machine with two states (NORMAL and EMERGENCY). This provides several advantages:
1. Better control over signal transitions (can add debouncing if needed)
2. Clear separation of emergency vs normal operation modes
3. Easier to extend with additional conditions or timed behaviors
4. More explicit representation of the system's operational states

The state machine will:
- Immediately enter EMERGENCY state on cpu_overheated
- In NORMAL state, handle the driving logic
- All outputs are registered, reducing potential glitches
