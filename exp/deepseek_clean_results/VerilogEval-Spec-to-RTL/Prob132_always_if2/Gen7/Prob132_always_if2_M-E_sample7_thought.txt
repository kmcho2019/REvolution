Instead of using continuous assignments or combinational always blocks, we can implement this as a finite state machine (FSM) with two independent state machines running in parallel. While this is overkill for such simple logic, it demonstrates how we could:
1. Make the design more extensible for future state-dependent behaviors
2. Separate concerns into distinct state machines
3. Provide a template for more complex control logic
4. Allow for potential clock gating optimizations in a larger system

The two state machines will be:
- Power Control FSM: Handles computer shutdown
- Driving Control FSM: Manages driving behavior

Each has just 2 states but shows how we could scale the design.
