The current solution is already optimal in terms of PPA metrics, but we can make it more robust by:
1. Adding default assignments to avoid latch inference
2. Using blocking assignments consistently in always blocks
3. Grouping related signals in the same always block for better readability
4. Maintaining the same efficient combinational logic structure

These changes won't affect the PPA metrics (which are already excellent) but will make the code more maintainable and less prone to simulation mismatches.
