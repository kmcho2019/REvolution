An alternative approach would be to implement the logic using a multiplexer-based design. This provides a different architectural perspective while maintaining the same functionality. The multiplexer approach explicitly shows the selection between different output states based on the input conditions. For the shut_off_computer output, we'll use a 2:1 mux selecting between 1 (when cpu_overheated) and 0 (otherwise). For keep_driving, we'll use a 2:1 mux selecting between the gas tank state (when not arrived) and 0 (when arrived).
