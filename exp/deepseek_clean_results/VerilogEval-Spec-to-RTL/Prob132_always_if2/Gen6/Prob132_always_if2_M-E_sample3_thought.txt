Here's a novel approach using a priority-encoded control scheme with a single always block:

1. Architectural Innovation:
   - Consolidate all control logic into a single always block for better synchronization
   - Implement priority encoding where CPU overheating takes precedence over driving logic
   - Use explicit default values for all outputs to avoid latches
   - Include a "system_state" variable to make the control flow more readable

2. Benefits:
   - Single control point for all outputs improves maintainability
   - Clear priority scheme (safety first - CPU shutdown overrides driving)
   - Explicit defaults make the design more robust
   - The state variable makes the logic more self-documenting

3. Novel Aspects:
   - Unified control structure instead of separate always blocks
   - Priority-based decision making
   - Internal state representation for clarity
   - Future-proof for potential additional conditions
