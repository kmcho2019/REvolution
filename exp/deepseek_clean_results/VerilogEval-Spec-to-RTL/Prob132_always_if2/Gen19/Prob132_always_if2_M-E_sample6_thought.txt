Stateful Observer Pattern Implementation:
1. **State Tracking**: Introduce state registers to track system conditions over time
2. **Edge Detection**: Use edge detection for the cpu_overheated signal to trigger shutdown
3. **Debouncing Logic**: Add simple debouncing for the arrived signal to prevent rapid toggling
4. **Energy-Saving Mode**: Implement a conservative driving policy that maintains state until explicit reset
5. **Explicit Defaults**: Clearly define all output states in all conditions

Key Innovations:
- Stateful behavior instead of pure combinational logic
- Edge-sensitive shutdown trigger (only reacts to overheating events)
- Debounced arrival detection
- Conservative keep_driving policy that remembers empty tank condition
- Complete specification of all output cases
