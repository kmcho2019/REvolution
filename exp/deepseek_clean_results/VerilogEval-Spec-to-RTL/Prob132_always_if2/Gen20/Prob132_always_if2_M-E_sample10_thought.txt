Novel Approach: State-Based Conditional Outputs
1. **State Encoding**: Use a 2-bit state encoding to represent all possible conditions
2. **Centralized Logic**: Consolidate all conditions into a single state variable for better optimization
3. **Output Decoding**: Derive outputs from the state variable using simple decoding logic
4. **Benefits**:
   - More scalable for additional conditions
   - Easier to add new outputs or conditions
   - Clear separation between condition evaluation and output generation
   - Potentially better for synthesis optimization
5. **Implementation**:
   - State 00: Normal operation
   - State 01: CPU overheated
   - State 10: Not arrived with gas
   - State 11: Not arrived without gas
