Here's a novel architectural approach that introduces stateful behavior while maintaining the same functionality:

1. Instead of pure combinational logic, implement a simple state machine for the driving logic
2. Use edge-triggered flip-flops to make the outputs more stable and glitch-resistant
3. Add a reset mechanism for initialization
4. For the CPU overheating case, maintain immediate response but with registered output
5. This approach provides better noise immunity and synchronous behavior while keeping the same logical functionality

The trade-off is slightly increased area/power for improved reliability and timing characteristics.
