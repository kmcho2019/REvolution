Novel Architectural Idea:
1. Instead of using continuous assignments, we'll implement the logic using a single always block with case statements
2. This approach groups all outputs together and makes their relationships more explicit
3. We'll use a case statement to handle all possible input combinations, making the design more readable and maintainable
4. Default values are explicitly set at the beginning of the always block to avoid latches
5. This style is particularly useful when the design might need to be extended with more complex logic in the future
6. The case statement makes it easier to visualize all possible input combinations and their corresponding outputs
