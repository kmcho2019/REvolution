State-Enabled Control Architecture:
1. **State Separation**: Divide control into two independent state machines (thermal control and driving control)
2. **Explicit Enable Signals**: Add enable signals for each subsystem to prevent undefined states
3. **Default Values**: Ensure all outputs have defined values in all conditions
4. **Modular Structure**: Prepare for future expansion by separating concerns

Key Innovations:
- Uses hierarchical state control instead of direct combinational logic
- Implements explicit enable conditions for each output
- Provides clear default states when conditions aren't met
- More scalable for additional future conditions
- Better matches real-world system behavior where these would be separate subsystems
