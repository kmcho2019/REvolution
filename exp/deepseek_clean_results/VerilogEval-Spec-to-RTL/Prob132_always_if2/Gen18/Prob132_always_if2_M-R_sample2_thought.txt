Refactored Design Approach:
1. **Direct Wire Assignments**: Replace always blocks with continuous assignments since the logic is simple enough
2. **Immediate Evaluation**: Leverage the nature of continuous assignments to simplify the logic
3. **Reduced Overhead**: Eliminate procedural blocks to potentially reduce synthesis overhead
4. **Clearer Intent**: Express the logic more directly as combinational equations
5. **Maintained Functionality**: Keep the exact same behavior as the original solution

Key Changes:
- Uses assign statements instead of always blocks
- More concise representation of the same logic
- Removes the need for default value assignments
- Potentially more efficient synthesis for simple combinational logic
- Maintains complete separation of the two independent output signals
