Here's a novel approach using a priority-encoded control scheme that treats the inputs as a unified control vector:

1. Combine all inputs into a 3-bit control vector (cpu_overheated, arrived, gas_tank_empty)
2. Use a priority encoder to determine the highest priority condition:
   - Priority 1: CPU overheating (immediate shutdown)
   - Priority 2: Arrival status and gas level
3. Implement with a case statement for clear priority handling
4. Use explicit default assignments for all outputs
5. This approach makes the priority ordering extremely clear and could easily scale to more conditions

Benefits:
- Explicit priority ordering
- Easily extensible for more conditions
- Clear mapping of input combinations to outputs
- Maintains good PPA while improving code structure
