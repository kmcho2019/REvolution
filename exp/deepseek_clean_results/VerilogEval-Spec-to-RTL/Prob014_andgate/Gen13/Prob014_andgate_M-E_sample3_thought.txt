Here's a novel approach using a lookup table (LUT) implemented with a case statement to emulate the AND gate behavior. This method:
1. Treats the input combination as a 2-bit address
2. Uses a case statement to explicitly define the output for each input combination
3. Demonstrates how more complex logic can be built using this pattern
4. Shows an alternative way to think about combinational logic
5. Maintains the exact same functionality as a standard AND gate
