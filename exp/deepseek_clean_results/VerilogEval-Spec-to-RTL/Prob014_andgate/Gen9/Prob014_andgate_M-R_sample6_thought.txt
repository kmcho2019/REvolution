Let's refactor the LUT-based AND gate implementation to make it more concise while maintaining the same core concept. Instead of using a reg and initial block to store the truth table, we'll:
1. Use a wire and continuous assignment to create the LUT
2. Implement the truth table directly in the assignment
3. Keep the same indexing mechanism ({a,b}) to select the output
4. This eliminates the need for initialization while preserving the LUT concept

The refactored version is functionally identical but more compact and eliminates the initialization step. It still demonstrates how combinational logic can be implemented via memory-like structures.
