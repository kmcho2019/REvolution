Let's implement the 2-input AND gate using a multiplexer-based approach. The idea is:
1. Use input 'a' as the select line for a 2:1 mux
2. When a=0, output is 0 (AND property: 0 AND anything is 0)
3. When a=1, output equals b (AND property: 1 AND b is b)

This approach demonstrates how basic logic gates can be constructed using multiplexers, which might be beneficial in certain FPGA architectures where muxes are abundant. The implementation uses the ternary operator as a compact way to describe the mux behavior.
