The original implementation uses an always block with a case statement. We can refactor this to use a continuous assignment with a conditional operator (?:) chain. This approach will:
1. Eliminate the need for a procedural block
2. Use a more compact syntax while maintaining the same functionality
3. Still clearly express the priority of selection (data0 has highest priority when sel=0)
4. Maintain the same default behavior for invalid sel values
The conditional operator chain will evaluate sequentially, checking each sel value in order.
