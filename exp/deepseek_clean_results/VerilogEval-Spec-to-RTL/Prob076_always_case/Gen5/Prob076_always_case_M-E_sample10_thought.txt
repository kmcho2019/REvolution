Novel Architectural Idea: Bitwise Parallel Selection
1. Instead of using a traditional case statement or if-else chain, implement the multiplexer using bitwise operations
2. For each output bit, compute a weighted sum of the corresponding input bits based on the selection
3. Each data input contributes to the output only when its selection condition is met
4. Invalid selections (sel > 5) naturally result in 0 output due to the selection logic
5. This approach leverages parallel bit operations and may offer better synthesis optimization potential

Advantages:
- Fully parallel implementation without priority encoding
- No explicit enable signal needed
- Clean mathematical formulation
- Potential for better timing on wide multiplexers
- Naturally handles invalid selections
