The existing solution is already quite simple and efficient, using a case statement for the multiplexer. However, we can make it slightly more concise by:
1. Removing the explicit reg declaration for the output since it's implied by the always block
2. Using a simpler case statement format without the 3'b prefix for the cases (since sel is already declared as 3 bits)
3. Keeping the default case for invalid selections
This maintains all functionality while being slightly more readable and concise.
