Novel Approach: Bitwise Parallel Processing with Masking
1. Instead of using a traditional case statement, implement the multiplexer using bitwise operations
2. Create a selection mask for each input based on the sel value
3. For each bit position, compute the output by OR-ing all masked input bits
4. This approach leverages parallel bit processing and may offer better synthesis optimization in some technologies
5. The masking operation naturally handles the default case (sel > 5) by producing all zeros
6. This method might be more efficient for certain FPGA architectures that optimize bitwise operations

Key Advantages:
- Eliminates sequential case statement logic
- Fully parallel bit processing
- Natural handling of invalid selections
- Potential for better synthesis optimization in some technologies
