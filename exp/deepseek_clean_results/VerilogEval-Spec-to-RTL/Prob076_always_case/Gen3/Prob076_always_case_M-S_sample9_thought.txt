The original solution uses a case statement which is clear but can be simplified using a more concise approach. Since the selection is based on a 3-bit signal and we only need to handle 6 cases (0-5), we can use an if-else chain that checks for valid sel values first, then defaults to 0. This reduces the verbosity of listing all case items while maintaining the same functionality. The synthesis tool will optimize this to the same multiplexer structure as the case statement version.
