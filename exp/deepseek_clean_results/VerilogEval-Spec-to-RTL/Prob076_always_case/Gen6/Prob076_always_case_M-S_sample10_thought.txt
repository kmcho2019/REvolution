The previous solution uses both an if statement and a case statement, which adds unnecessary complexity. We can simplify this by:
1. Using only a case statement to handle all possible sel values (0-7)
2. Mapping sel values 0-5 directly to corresponding data inputs
3. Using the default case to handle all invalid selections (6-7)
4. Removing the redundant if check since the case statement can handle everything
This approach maintains full functionality while being simpler and more straightforward.
