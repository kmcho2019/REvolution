Here's a novel approach using a bitwise selection technique combined with a mask generation scheme:

1. Instead of using a traditional case statement or if-else chain, we'll:
   - Generate a 6-bit one-hot mask from the 3-bit sel input
   - Use bitwise AND operations between each data input and its corresponding mask bit
   - OR all the results together to get the final output

2. Key advantages:
   - Parallel processing of all selection paths
   - Potentially better timing characteristics as all paths are equal length
   - Easier to pipeline if needed
   - Clear separation of selection logic from data routing

3. For invalid selections (sel > 5):
   - The mask will be all zeros, resulting in zero output
   - No need for explicit default case handling

This approach may offer better performance in some synthesis tools and could be more amenable to certain optimization techniques.
