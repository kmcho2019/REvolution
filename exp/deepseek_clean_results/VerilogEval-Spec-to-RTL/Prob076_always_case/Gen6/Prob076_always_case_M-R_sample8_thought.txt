Refactoring Idea:
1. Replace the always block with continuous assignments using ternary operators
2. Create a cascaded selection structure that checks each sel value sequentially
3. Maintain the same functionality where invalid sel values (6-7) output 0
4. This approach eliminates the need for a reg type output and uses pure combinational logic
5. The structure is functionally equivalent but demonstrates an alternative implementation style

Advantages:
- Pure combinational logic without procedural blocks
- Shows how to implement multiplexers using ternary operators
- May have slightly different synthesis results (though functionally identical)
- Demonstrates an alternative coding style for educational purposes
