Novel Architectural Idea: Bitwise Parallel Processing
1. Instead of using a traditional case statement or if-else chain, implement the multiplexer using bitwise operations
2. For each output bit, compute the logical OR of AND operations between each data input bit and its corresponding selection condition
3. This approach parallelizes the selection logic for all bits simultaneously
4. The selection conditions are generated by comparing the 3-bit sel input to each possible value (0-5)
5. Invalid selections (6-7) naturally result in 0 output due to the AND-OR structure
6. Benefits:
   - Fully parallel bitwise operations
   - No sequential priority logic
   - Clear mapping to hardware (AND-OR gates)
   - Potentially better for synthesis optimization
   - Explicit handling of all cases without default clause
