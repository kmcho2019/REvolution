Here's a novel approach using a bitwise operation-based multiplexer instead of the traditional case statement. The key idea is:

1. Create a 6-bit one-hot encoded selection signal from the 3-bit sel input
2. Use bitwise AND operations to mask each data input with its corresponding selection bit
3. Combine all masked inputs using OR operations to get the final output
4. Handle invalid selections by masking the one-hot encoding generation

This approach has several advantages:
- Eliminates the need for a case statement
- Uses parallel bitwise operations that can be efficiently synthesized
- The one-hot encoding can potentially lead to better timing characteristics
- Invalid selection handling is integrated into the one-hot generation
