Novel Architectural Idea: Bitwise Parallel Processing
Instead of using a traditional case statement, we can implement the multiplexer using bitwise operations in parallel for each output bit. This approach:
1. Processes all 4 output bits simultaneously
2. Uses a bitmask technique to select the appropriate input
3. Implements selection logic using AND-OR operations
4. Handles invalid selections by masking with the valid range
5. Potentially offers better timing for wide data paths as each bit is processed independently

The key insight is that we can treat each bit position independently and compute the output bit as a logical combination of all input bits at that position, masked by the selection condition.
