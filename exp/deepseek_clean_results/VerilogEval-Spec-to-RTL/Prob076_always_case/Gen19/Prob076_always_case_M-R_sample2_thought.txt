Refactoring Strategy:
1. Replace the always block with continuous assignments using ternary operators
2. Create a cascaded selection structure that evaluates sel in priority order
3. Maintain the same functionality where invalid sel values (6-7) output 0
4. This approach eliminates the need for a procedural block while keeping the same behavior
5. The structure is more concise and may synthesize similarly to the case statement version

Key points:
- Each level checks one sel value and passes through to next check if not matched
- Final default case handles all invalid selections
- No registers needed since it's pure combinational logic
- Same clean handling of all input cases as original
