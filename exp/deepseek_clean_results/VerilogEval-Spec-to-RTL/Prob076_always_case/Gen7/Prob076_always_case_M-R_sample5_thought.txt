Refactoring Strategy:
1. Replace the always block with continuous assignments using ternary operators
2. Maintain the same functionality but implement as a pure combinational logic expression
3. Use a cascaded ternary operator structure to prioritize selection from sel=0 to sel=5
4. Keep the default case (output 0) as the final else clause
5. This approach eliminates the need for a reg type output since we're using direct assignment

Benefits:
- More concise implementation (single assign statement)
- No procedural block needed
- Output can be wire type instead of reg
- Same functionality and timing characteristics
- Potentially more readable for simple mux cases
