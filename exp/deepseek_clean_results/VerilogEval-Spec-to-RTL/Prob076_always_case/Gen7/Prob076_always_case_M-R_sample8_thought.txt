The original solution uses a case statement inside an always block. We can refactor this to:
1. Use a continuous assignment with a conditional operator (?:) chain
2. This approach eliminates the need for a procedural block
3. The conditional operator chain will naturally handle the priority of selection
4. Default to 0 when sel is out of range (6-7)
This maintains the same functionality while being more concise and potentially more efficient in synthesis.
