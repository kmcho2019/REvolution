Novel Architectural Idea: Bitwise Parallel Processing
1. Instead of using a traditional case statement or if-else chain, implement the multiplexer using bitwise operations
2. For each output bit, calculate its value based on the selection bits and input data bits
3. Use a parallel structure where each output bit is computed independently
4. This approach may offer better synthesis optimization opportunities as it exposes more parallelism to the tool
5. Invalid selections still result in 0 output by masking with the valid selection range
6. The implementation uses only basic logic gates which may lead to better area/power tradeoffs
