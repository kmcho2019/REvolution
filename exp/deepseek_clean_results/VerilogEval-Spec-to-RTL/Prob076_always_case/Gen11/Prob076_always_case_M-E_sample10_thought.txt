Instead of using a traditional case statement, we can implement the multiplexer using a bitwise selection approach combined with a priority encoder concept. The key ideas are:

1. Create a 6-bit one-hot encoded signal from the 3-bit sel input
2. Use bitwise AND operations between each data input and its corresponding one-hot bit
3. OR all the results together to get the final output
4. For invalid sel values (6-7), the one-hot encoding will be all zeros, resulting in 0 output

This approach has several advantages:
- More parallel implementation than the case statement
- Potentially better timing as the critical path is through one AND-OR chain
- Clear separation of selection logic from data path
- Easily scalable to more inputs if needed
