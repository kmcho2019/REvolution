To refactor the code while maintaining the same functionality, we'll switch from using an always block with case statement to a pure combinational logic approach using assign statements with conditional operators. This approach:

1. Eliminates the need for a procedural block (always)
2. Uses ternary operators for direct selection logic
3. Maintains the same selection behavior (output 0 for invalid sel)
4. Potentially reduces area by simplifying the control logic
5. Keeps the same clear mapping between sel values and data inputs

The refactored version will be functionally identical but expressed differently, using continuous assignments that may synthesize to slightly more optimized hardware in some cases.
