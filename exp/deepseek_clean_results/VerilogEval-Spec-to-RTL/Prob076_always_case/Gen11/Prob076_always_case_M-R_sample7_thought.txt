Refactoring Strategy:
1. Replace the always block with continuous assignments using ternary operators
2. This approach will:
   - Maintain the same functionality (6-to-1 mux with default 0 output)
   - Eliminate the need for a register (output can now be wire)
   - Potentially reduce power by removing the default assignment
   - Create a more parallel implementation structure
3. The ternary operator chain will evaluate the select signals in order, matching the priority of the original case statement
4. Invalid sel values (6-7) will naturally fall through to the default 0 output
