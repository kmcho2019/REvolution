Refactoring Strategy:
1. Replace the always block with continuous assignments using ternary operators
2. Create a cascaded selection structure that evaluates sel in priority order
3. Each level checks one sel value and either selects the corresponding data or falls through to next level
4. Final default case handles invalid selections (sel > 5) by outputting 0
5. Benefits: 
   - Pure combinational logic without procedural blocks
   - Clear priority structure that may map well to FPGA LUTs
   - Same functionality with different implementation style
