The original solution uses a case statement with all 8 possible sel values explicitly listed. We can simplify this by:
1. Using a default assignment of 0 at the beginning to cover all invalid cases (sel > 5)
2. Only explicitly handling the valid cases (0-5) in the case statement
3. This reduces the number of case items while maintaining the same functionality
4. The default assignment ensures invalid sel values output 0 without needing explicit cases
