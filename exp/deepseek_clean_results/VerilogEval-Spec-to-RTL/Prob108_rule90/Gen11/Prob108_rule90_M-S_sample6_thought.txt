To simplify the Rule 90 implementation while maintaining functionality:

1. Remove the generate block and use direct bitwise operations for cleaner code
2. Handle boundary conditions by:
   - Left-shifting q with a 0 at LSB for left neighbors
   - Right-shifting q with a 0 at MSB for right neighbors
3. Perform the XOR operation between these shifted versions to get next_state
4. This approach:
   - Eliminates the need for 512 individual XOR instances
   - Uses simple shift operations for neighbor access
   - Maintains the same boundary behavior (q[-1] and q[512] as 0)
   - Reduces code complexity while keeping identical functionality
5. Keep the same clocked register update with load functionality
