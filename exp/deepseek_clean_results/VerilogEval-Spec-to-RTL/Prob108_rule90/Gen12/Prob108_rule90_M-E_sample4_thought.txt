Here's a novel approach using a circular buffer technique to implement Rule 90:

1. Instead of using shift operations, implement a circular buffer that tracks left and right neighbors for each cell
2. Use a 3-bit window (left, center, right) that moves through the array
3. For boundary conditions, explicitly handle the first and last bits separately
4. The main computation uses a for-loop to iterate through each bit position
5. Advantages:
   - More explicit neighbor handling
   - Clear boundary condition implementation
   - Potentially better synthesis results due to structured iteration
   - Easier to modify for different boundary conditions
6. Still maintains the same functionality with load capability
