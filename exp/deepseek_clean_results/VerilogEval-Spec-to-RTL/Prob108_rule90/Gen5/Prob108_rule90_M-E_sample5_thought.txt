Novel approach using shift registers and parallel XOR:
1. Instead of calculating each cell's next state individually, use shift operations to align neighbors
2. Create left-shifted and right-shifted versions of the current state
3. XOR these shifted versions to implement Rule 90 in parallel
4. Boundary conditions are handled by padding with zeros during shifts
5. This reduces the control logic complexity compared to the for-loop approach
6. The shift-and-XOR operation naturally implements the Rule 90 behavior
