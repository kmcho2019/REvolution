To implement Rule 90 cellular automaton with 512 cells, we need to:
1. Create a 512-bit register to hold the current state
2. On each clock edge:
   - If load is high, load the data into the register
   - Otherwise, compute the next state by XORing each cell's left and right neighbors
3. Handle boundary conditions by treating q[-1] and q[512] as 0
4. The next state for each cell i is q[i-1] ^ q[i+1], with special handling for the first and last cells
