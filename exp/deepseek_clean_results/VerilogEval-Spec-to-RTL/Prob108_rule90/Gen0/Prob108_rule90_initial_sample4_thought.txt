To implement Rule 90 cellular automaton with 512 cells:
1. Create a 512-bit register to store the current state (q)
2. On each clock edge:
   - If load is high, load data into the register
   - Else, compute next state using Rule 90:
     - For each bit, next state is XOR of left and right neighbors
     - Handle boundary conditions (left of q[0] and right of q[511] are 0)
3. Use non-blocking assignments for sequential logic
4. Generate next state in combinational logic before clock edge
