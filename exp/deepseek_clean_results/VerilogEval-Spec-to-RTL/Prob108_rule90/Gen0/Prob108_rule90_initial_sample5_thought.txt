To implement Rule 90 cellular automaton with 512 cells, we need to:
1. Create a 512-bit register to hold the current state (q)
2. On each clock edge:
   - If load is high, load data into q
   - Else, compute next state by XORing left and right neighbors for each cell
3. Handle boundary conditions by treating q[-1] and q[512] as 0
4. For each cell, next state is q[i-1] ^ q[i+1] (with boundary conditions)
