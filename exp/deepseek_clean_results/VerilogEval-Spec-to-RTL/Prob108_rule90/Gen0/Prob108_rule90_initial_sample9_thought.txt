To implement Rule 90 cellular automaton:
1. Create a 512-bit register to store the current state (q)
2. On each clock edge:
   - If load=1, load data into q
   - Else, compute next state by XORing left and right neighbors for each bit
3. Handle boundary conditions by treating q[-1] and q[512] as 0
4. For each bit q[i], next state is q[i-1] ^ q[i+1] (with boundary bits as 0)
