To implement Rule 90 cellular automaton, we need to:
1. Create a 512-bit register to store the current state (q)
2. On each clock edge:
   - If load is high, load data into q
   - Otherwise, compute next state by XORing left and right neighbors for each bit
3. Handle boundary conditions by treating q[-1] and q[512] as 0
4. For each bit position i, next state is q[i] = q[i-1] ^ q[i+1], with special cases for i=0 and i=511
