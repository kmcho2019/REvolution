To address the synthesis challenges while maintaining correct functionality, we'll:
1. Keep the same fundamental Rule 90 logic (XOR of neighbors)
2. Maintain the boundary conditions (0 for out-of-bounds cells)
3. Optimize the implementation by:
   - Using a single always block for both combinational and sequential logic
   - Reducing the number of parallel XOR operations by computing next state sequentially
   - Still maintaining the parallel update nature required by cellular automata
4. The load functionality remains synchronous
5. This approach should:
   - Reduce fan-out issues by not having separate assign statements
   - Potentially help synthesis tools better optimize the logic
   - Maintain the same cycle-accurate behavior
