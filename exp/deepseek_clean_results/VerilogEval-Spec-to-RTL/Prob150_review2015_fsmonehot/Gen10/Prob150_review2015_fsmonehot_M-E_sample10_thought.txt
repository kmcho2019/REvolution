This solution introduces two key innovations:
1. Priority-Encoded State Transitions: Instead of pure one-hot logic, we use priority encoding for the sequence states (B0-B3) to reduce combinatorial logic depth. The B-states form a linear sequence where each state simply enables the next in line.

2. Output Pre-Computation: We compute shift_ena one cycle early by looking at the next state rather than current state. This allows better timing closure since the output isn't dependent on the full state decode.

Key benefits:
- Reduced critical path by simplifying B-state transitions
- Output timing improvement via early computation
- Maintains strict one-hot encoding as specified
- Clear separation between sequence states (B0-B3) and decision states
- More efficient OR-tree structures for next-state logic
