Instead of treating each state independently, we can categorize them into groups with similar behavior:
1. Sequence detection states (S, S1, S11, S110)
2. Bit processing states (B0-B3)
3. Counting state
4. Wait state

This allows us to:
1. Simplify next-state logic by first determining which group we're in
2. Use priority encoders for sequence detection
3. Implement bit processing as a simple shift register
4. Handle counting/wait states separately

The key innovation is using hierarchical state grouping to reduce logic complexity while maintaining the same functionality.
