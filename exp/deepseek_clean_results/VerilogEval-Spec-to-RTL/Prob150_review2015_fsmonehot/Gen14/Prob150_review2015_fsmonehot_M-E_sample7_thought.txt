Novel Architecture Idea:
1. Hierarchical State Encoding:
   - Instead of pure one-hot, use a hybrid encoding where sequential states (B0-B3) share common prefix bits
   - This reduces the combinational logic complexity for state transitions between these states

2. Output Pre-computation:
   - Compute outputs one cycle early when possible (especially for shift_ena)
   - This allows better timing by moving output logic off the critical path

3. State Grouping:
   - Group states with similar transition conditions to minimize decode logic
   - Use intermediate signals that capture common transition patterns

4. Early Transition Evaluation:
   - For states with simple transitions (like B0-B3), evaluate next state immediately
   - Only complex transitions use full condition evaluation

This approach reduces fan-out on critical paths and enables better synthesis optimization.
