This solution takes a unique approach by:
1. Using a priority-encoded next-state selection rather than traditional state transitions
2. Implementing a "next-state matrix" that directly maps current state and inputs to next states
3. Using bitwise operations for efficient one-hot state transitions
4. Separating the state transition logic into clear, independent components

The key innovation is treating the state machine as a matrix transformation problem where each next state is computed independently based on a weighted combination of current state and inputs. This approach offers better scalability and clearer mapping to hardware.
