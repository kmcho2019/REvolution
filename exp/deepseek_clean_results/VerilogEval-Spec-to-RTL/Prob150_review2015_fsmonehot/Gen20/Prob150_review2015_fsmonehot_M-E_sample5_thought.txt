Instead of pure one-hot encoding, I'll implement a hybrid encoding scheme that:
1. Groups related states together (sequence detection vs. operation states)
2. Uses a 2-level encoding:
   - Upper 2 bits identify state groups (00: sequence, 01: shift, 10: count/wait)
   - Lower bits use one-hot within each group
3. Benefits:
   - Reduces switching activity by minimizing state bit changes
   - Maintains simple output logic similar to one-hot
   - Potentially reduces power consumption
4. Implementation:
   - Custom encoding for state representation
   - Modified next-state logic that leverages the grouping
   - Same output logic since outputs depend only on current state
