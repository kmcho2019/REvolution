The original solution is already quite efficient, but we can simplify it further by:

1. Removing redundant conditions in next-state logic where possible
2. Leveraging the one-hot encoding property that only one state bit is active at a time
3. Simplifying output logic by directly using state bits where appropriate
4. Combining related conditions for better readability

Key simplifications:
- S_next can be simplified by combining all transitions to S state
- S1_next only needs the S->S1 transition
- B3_next is simply the B2 state (since it always transitions to B3)
- Count_next can be expressed more clearly
- Output logic becomes trivial due to one-hot encoding
