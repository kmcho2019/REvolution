I'll refactor the priority encoder using continuous assignments (assign statements) with conditional operators. This approach:

1. Uses purely combinational logic without procedural blocks
2. Maintains the same priority encoding behavior (LSB has highest priority)
3. Still handles the all-zeros case by defaulting to 00
4. May offer slightly better synthesis results in some tools as it's a direct combinational mapping
5. The structure shows the priority more explicitly through nested conditional operators

The logic checks bits from highest priority (bit 0) to lowest (bit 3), outputting the position of the first high bit found.
