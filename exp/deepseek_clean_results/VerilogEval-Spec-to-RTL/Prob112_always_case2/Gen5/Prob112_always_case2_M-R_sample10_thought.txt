To improve the PPA metrics while maintaining the same functionality, I'll refactor the code to use a case statement inside an always block. This approach offers several advantages:

1. Better readability and maintainability
2. Allows synthesis tools to potentially optimize the logic more effectively
3. Eliminates the cascaded ternary operator chain which can create longer critical paths
4. Still maintains combinational behavior through always @(*)
5. Preserves the same priority encoding (LSB first) and zero output for all-zero input

The case statement will check each bit in priority order (bit 0 first) and assign the corresponding position value. The default case handles the all-zero input scenario.
