I'll refactor the priority encoder using a case statement inside an always block instead of the ternary operator chain. This approach:

1. Improves readability by making the priority order more explicit
2. May offer better synthesis results in some tools as case statements can be optimized more effectively
3. Maintains identical functionality (LSB priority, same output encoding)
4. Still handles the all-zeros case properly
5. Uses blocking assignments since it's combinational logic

The case statement will check each bit in priority order (bit 0 first) and assign the corresponding position value.
