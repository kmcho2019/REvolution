Instead of using conventional priority encoding logic, we can:
1. First create a thermometer code from the input by OR-ing all higher bits with each bit
2. This converts the priority encoding problem into a simple thermometer code decoding
3. Then use a compact thermometer-to-binary encoder to get the position
4. The approach minimizes logic depth and provides good timing characteristics
5. The OR-chain naturally implements the priority behavior by propagating the highest priority bit
