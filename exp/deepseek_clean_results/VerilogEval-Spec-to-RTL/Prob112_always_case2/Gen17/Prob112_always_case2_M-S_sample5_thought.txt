To simplify the priority encoder implementation while maintaining functionality, I'll use a direct combinational logic approach with a priority-encoded if-else ladder. This approach:

1. Removes the need for a case statement by using simple if-else conditions
2. Explicitly checks bits in priority order (from bit 0 to bit 3)
3. Defaults to 0 when no bits are set (all zeros case)
4. Uses blocking assignments for combinational logic
5. Results in cleaner and more straightforward code
