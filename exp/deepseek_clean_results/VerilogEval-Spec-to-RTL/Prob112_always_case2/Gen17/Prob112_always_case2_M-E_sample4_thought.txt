Here's a novel approach using a tree-structured priority encoder:
1. Divide the 4-bit input into two 2-bit chunks (upper and lower)
2. First check if any bit in the lower chunk is set - if yes, encode its position
3. Only if lower chunk is all zeros, check the upper chunk
4. This hierarchical approach reduces the critical path by parallelizing some comparisons
5. Uses simple OR gates to detect presence of 1s in each chunk
6. Implements priority through the conditional structure rather than bit manipulation
