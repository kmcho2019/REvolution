Here's a novel approach using a binary tree structure for the priority encoder:
1. Instead of isolating the rightmost 1-bit, we'll implement a hierarchical decision tree
2. First check the most significant bits (top-down approach)
3. If any bit in the upper half is set, we can ignore the lower half
4. This creates a logarithmic depth decision path (better for timing)
5. The structure naturally prioritizes higher bits without needing bit manipulation operations
6. Still maintains the all-zero case handling
