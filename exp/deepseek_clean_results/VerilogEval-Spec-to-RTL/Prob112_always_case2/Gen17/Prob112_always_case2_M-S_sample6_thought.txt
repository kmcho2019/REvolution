Simplified Design Approach:
1. Use a single always block with a case statement to handle all 16 input combinations directly
2. Eliminate intermediate masking and grouping logic by directly checking input bits
3. Implement priority by checking bits from LSB to MSB in the case statement
4. Default to 0 when no bits are set (input is zero)
5. This approach reduces logic complexity by removing intermediate computations and registers

Key Benefits:
- Single case statement is more readable and maintainable
- No intermediate computations or registers needed
- Direct mapping from input patterns to output positions
- Maintains correct priority encoding behavior
- Reduced power consumption from simpler logic structure
