Here's a novel approach using a thermometer code style priority encoder:
1. Instead of isolating the rightmost 1-bit, we'll create a cascading priority structure
2. Each output bit is determined by whether there's a higher-priority 1 in the input
3. For pos[1]: True if there's a 1 in bits [3:2]
4. For pos[0]: True if there's a 1 in bit [3] OR (bit[1] AND no 1 in bits [3:2])
5. This creates a more direct mapping from input patterns to output positions
6. The structure naturally handles the all-zero case by default
