I'll refactor the priority encoder using a continuous assignment (assign statement) with nested conditional operators. This approach:

1. Maintains the same functionality and priority order (LSB first)
2. Uses purely combinational logic without procedural blocks
3. Provides a more compact representation for this simple case
4. Still handles the all-zeros input case properly
5. May result in slightly different synthesis patterns compared to the case statement version

The nested ternary operators will check each bit in priority order, similar to the original case statement but expressed differently.
