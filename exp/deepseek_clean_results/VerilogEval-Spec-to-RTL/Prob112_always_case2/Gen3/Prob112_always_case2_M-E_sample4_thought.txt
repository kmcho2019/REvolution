Instead of using a casez statement, we can implement the priority encoder using a structural approach with chained conditional assignments. The key idea is to:
1. Check bits from MSB to LSB (priority order)
2. Assign position based on the first high bit found
3. Use a default assignment of 0 when no bits are high
4. Represent positions as: 3→11, 2→10, 1→01, 0→00, and no bits→00

This approach is more explicit about the priority ordering and avoids potential casez pattern matching ambiguities. The chained conditional assignments naturally implement the priority behavior by checking higher bits first.
