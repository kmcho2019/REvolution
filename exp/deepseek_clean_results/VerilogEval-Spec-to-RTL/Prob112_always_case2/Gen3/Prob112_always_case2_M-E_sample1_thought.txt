A novel approach is to use a thermometer-style priority encoder that leverages the inherent priority in the input bits. Instead of traditional if-else or case statements, we'll use a bitwise masking technique:
1. Create masks that progressively enable lower priority bits only if higher priority bits are zero
2. For each bit position, generate a condition that checks if it's the first set bit by masking out higher priority bits
3. Combine these conditions using OR reduction to determine the final position
This method is efficient in hardware as it naturally captures the priority order through the masking operation and requires minimal logic levels.
