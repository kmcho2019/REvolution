Novel Approach: Hierarchical Priority Tree with Early Termination
1. Instead of processing all bits simultaneously, implement a binary tree structure that checks bits in pairs
2. Each level of the tree determines if there's a '1' in the upper or lower pair
3. If a '1' is found in the upper pair, we can ignore the lower pair (early termination)
4. This approach reduces switching activity and power consumption by minimizing unnecessary bit checks
5. The structure naturally implements priority encoding by checking higher bits first
6. Uses simple logical operations without arithmetic for better power and area characteristics
