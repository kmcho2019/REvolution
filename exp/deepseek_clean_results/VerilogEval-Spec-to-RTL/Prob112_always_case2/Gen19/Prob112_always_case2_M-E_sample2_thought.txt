Here's a novel approach using a hierarchical priority tree structure:
1. Instead of using bit manipulation or case statements, we'll implement a tree of priority selectors
2. First level checks the two MSBs (bits 3 and 2) - if either is set, we know the answer is in upper half
3. Second level checks the remaining bits only if upper bits are zero
4. This creates a natural priority flow from MSB to LSB
5. The structure is more scalable for larger encoders and may have better timing characteristics
6. Explicit handling of all-zero case remains simple
