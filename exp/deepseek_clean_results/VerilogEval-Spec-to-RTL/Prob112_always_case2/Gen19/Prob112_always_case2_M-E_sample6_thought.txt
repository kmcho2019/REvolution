Here's a novel approach using a tree-based priority encoder structure:
1. Instead of using bitwise operations, we'll implement a hierarchical decision tree
2. First check the most significant bit (in[3])
3. If it's 1, output position 3 (2'b11)
4. Else, check the next significant bit (in[2]) and so on
5. This creates a natural priority from MSB to LSB
6. The structure is easily extensible to wider inputs
7. Uses only simple comparisons and multiplexing
8. No arithmetic operations needed
9. Clear priority ordering without intermediate calculations
10. Efficient implementation with 2:1 muxes
