Here's a novel approach using a binary tree structure for the priority encoder. This method breaks down the 4-bit input into pairs and processes them hierarchically:

1. First level: Compare adjacent bit pairs (bits 1-0 and bits 3-2)
2. Second level: Combine results from first level to determine final position
3. Special handling for all-zero case

This tree structure offers potential advantages:
- More balanced logic path compared to cascaded if-else
- Potentially better timing characteristics
- Clear hierarchical structure that might scale better for larger encoders
- Explicit handling of the zero case without priority logic
