Here's a novel approach using a hierarchical priority encoder structure:

1. Divide the 4-bit input into two 2-bit segments (upper and lower)
2. First check if there are any 1s in the upper segment (bits [3:2])
3. If found, encode their position with priority (bit 3 over bit 2)
4. If no 1s in upper segment, check lower segment (bits [1:0])
5. This creates a two-level priority check that reduces logic depth
6. The output is calculated by combining the segment selection with the position within the segment

Advantages:
- Clear hierarchical structure that's easy to understand
- Potentially better timing due to reduced logic depth
- Modular design that could scale to larger encoders
- Explicit priority ordering in the code structure
