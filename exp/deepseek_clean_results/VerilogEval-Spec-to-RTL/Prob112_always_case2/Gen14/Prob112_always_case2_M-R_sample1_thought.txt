I'll refactor the priority encoder using a continuous assignment (assign statement) with nested conditional operators. This approach:

1. Uses purely combinational logic without procedural blocks
2. Maintains the same priority encoding behavior (LSB first)
3. Still handles the all-zeros case properly by defaulting to 00
4. May offer slightly better synthesis results in some tools as it's a direct combinational expression
5. The nested ternary operators naturally implement the priority order from LSB to MSB

The structure will be a chain of conditional checks starting from the highest priority (bit 0) down to the lowest (bit 3).
