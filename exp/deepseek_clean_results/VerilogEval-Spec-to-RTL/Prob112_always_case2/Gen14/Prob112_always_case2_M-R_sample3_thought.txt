I'll refactor the priority encoder to use continuous assignments (assign statements) instead of an always block. This approach has several advantages:

1. Simplicity: The combinational logic is expressed directly without procedural blocks.
2. Readability: The priority encoding is clearly visible in the conditional expressions.
3. Potential Synthesis Benefits: Some synthesis tools may optimize continuous assignments differently.

The refactored version will use nested ternary operators to implement the same priority encoding logic. The outermost condition checks for all zeros, then each subsequent condition checks for the highest priority '1' bit. This maintains the exact same functionality but with a different implementation style.
