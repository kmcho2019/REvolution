My novel approach uses a hierarchical priority encoding scheme that breaks down the 4-bit input into two 2-bit groups. This reduces the logic depth while maintaining clear priority encoding. The design works as follows:

1. First, we check the upper 2 bits (in[3:2]):
   - If either bit is high, we encode their position with priority (bit 3 over bit 2)
   - If both are low, we then check the lower 2 bits (in[1:0])

2. For each 2-bit group, we use simple combinational logic to determine:
   - If the MSB of the pair is set (highest priority)
   - Else if the LSB is set
   - Else neither is set

3. The final output combines results from both groups with proper priority:
   - Upper group results take precedence
   - Lower group results are only considered if upper group is all zeros

This approach reduces the critical path by parallelizing the 2-bit encodings and then combining results, rather than checking all 4 bits sequentially.
