The current implementation is already quite efficient, but we can make a few micro-optimizations:

1. Remove the 'reg' keyword for the output since we're using continuous assignment
2. Use a more direct case statement that checks the input bits directly
3. Eliminate the default case since we want to output 0 when all inputs are 0, and the case structure naturally does this
4. Use blocking assignments for combinational logic

This should maintain the same functionality while potentially reducing area slightly by simplifying the case statement structure. The priority encoding remains the same (LSB has highest priority).
