Instead of using sequential if-else statements, we can implement the priority encoder using a parallel approach with bitwise operations. The key idea is to:
1. Generate a mask that clears all bits after the first '1' from the right (LSB)
2. Use this masked value to determine the position through a lookup table
3. This approach leverages bitwise operations for parallel processing and eliminates priority-dependent logic
4. The zero case is handled naturally as the mask will be all zeros
