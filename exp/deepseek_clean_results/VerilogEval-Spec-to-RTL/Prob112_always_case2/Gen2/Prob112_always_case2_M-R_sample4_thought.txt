To refactor the priority encoder, we'll use continuous assignments (assign statements) instead of an always block. This approach is more concise for combinational logic. We'll create a series of conditional assignments that check the input bits from MSB to LSB (priority order), assigning the corresponding 2-bit position value when a '1' is found. The last assignment will handle the all-zeros case. This method eliminates the need for reg declaration and case statements while maintaining the same priority encoding logic.
