I'll refactor the priority encoder to use continuous assignments (assign statements) instead of an always block. This approach:

1. Makes the code more concise by eliminating the always block
2. Uses a cascaded ternary operator structure to maintain the same priority encoding behavior
3. Still properly handles the all-zero input case by defaulting to zero
4. May result in slightly different synthesis outcomes while maintaining identical functionality
5. Preserves the same interface and bit widths

The ternary operators will check each bit in priority order (from LSB to MSB) and assign the corresponding position value. The final default case (all zeros) will output zero.
