To simplify the priority encoder, we can use a direct if-else chain that checks for the highest priority '1' from left to right (MSB to LSB). This approach is more straightforward than casez and achieves the same functionality with potentially simpler logic. We'll check each bit in order of priority (bit 3 down to bit 0) and assign the corresponding position when we find the first '1'. If no bits are set, we default to 0.
