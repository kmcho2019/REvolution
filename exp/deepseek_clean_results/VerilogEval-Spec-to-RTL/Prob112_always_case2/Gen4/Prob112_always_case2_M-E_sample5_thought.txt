Instead of using traditional conditional logic or bit isolation, we'll implement a parallel prefix network that propagates the highest priority '1' through the bits. This approach:
1. Creates a thermometer-style mask where all bits below the first '1' are set
2. Uses XOR operations to isolate the transition point
3. Encodes the position in parallel rather than sequentially
4. Handles the all-zero case naturally through the same logic flow
This method offers better timing characteristics for larger encoders and more regular structure for synthesis.
