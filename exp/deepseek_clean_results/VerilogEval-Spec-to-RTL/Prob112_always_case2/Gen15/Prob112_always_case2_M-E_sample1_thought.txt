Here's a novel approach using a thermometer-to-binary encoder concept combined with priority masking:

1. First create a thermometer-like mask where all bits to the right of the first '1' are set to '1'
2. Then count the number of '1's in this mask to determine the position
3. This approach leverages parallel bit operations and population count logic
4. The key innovation is using bitwise OR reduction with shifting to create the priority mask
5. The position is then derived from the population count of this mask
