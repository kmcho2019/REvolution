To optimize the priority encoder for better PPA (Power, Performance, Area), I'll implement the following improvements:

1. Performance:
   - Replace cascaded ternary operators with a single case statement for each 2-bit encoder to reduce critical path
   - Eliminate redundant 'active' signals by directly using the input bits in the final selection

2. Power:
   - Remove separate 'active' signal computations to reduce switching activity
   - Simplify the output selection logic to only evaluate necessary paths

3. Area:
   - Merge the position encoding and activity detection into a single case statement
   - Remove redundant default assignments
   - Simplify the final output selection to a single conditional expression

The new design will:
- Use case statements for cleaner and more efficient synthesis
- Directly encode positions without intermediate signals
- Maintain the same functionality while reducing logic levels
- Be more synthesis-friendly for better PPA results
