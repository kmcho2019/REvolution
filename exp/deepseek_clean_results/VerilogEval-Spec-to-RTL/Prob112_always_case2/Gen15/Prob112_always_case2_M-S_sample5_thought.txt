The original solution uses a cascaded if-else structure which works but can be simplified. Since this is a small 4-bit priority encoder, we can use a more straightforward approach with a single casez statement that inherently implements the priority encoding behavior. This reduces the logic complexity while maintaining the same functionality. The casez statement will match the first '1' from right to left (LSB to MSB) and output its position, defaulting to 00 when all inputs are 0.
