To simplify the priority encoder while maintaining functionality, we can:

1. Use a case statement which is more readable and directly expresses the priority encoding behavior
2. Eliminate complex bitwise operations by checking each input bit in priority order
3. Default to 0 when no bits are set (input is zero)
4. The case statement will naturally implement the priority encoding by checking bits from highest to lowest priority (bit 3 down to bit 0)
5. This approach is more maintainable and clearly shows the priority order
