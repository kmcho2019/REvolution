I'll implement the priority encoder using a case statement inside an always block. This approach:
1. Explicitly lists all possible input patterns
2. Directly maps each pattern to its corresponding output position
3. Handles the all-zero case explicitly
4. Uses combinational logic with always @(*)

Advantages:
- More readable and maintainable
- Explicit priority encoding (top bits have higher priority)
- No need for intermediate bit manipulation operations
- Clear mapping between input patterns and outputs
