Instead of using a case statement, we'll implement the priority encoder using a series of nested conditional (if-else) statements. This approach explicitly checks each bit from highest to lowest priority, making the priority order very clear in the code. The output will be assigned based on the first '1' encountered in this priority order. This method is more verbose but can be easier to understand and modify for different priority schemes.
