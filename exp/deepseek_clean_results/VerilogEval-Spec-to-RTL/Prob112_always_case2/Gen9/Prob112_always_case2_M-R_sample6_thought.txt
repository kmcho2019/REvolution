I'll refactor the priority encoder to use continuous assignments (assign statements) instead of an always block. This approach:

1. Makes the code more concise by eliminating the need for an always block
2. Still maintains the same priority encoding behavior (LSB first)
3. Uses nested ternary operators to implement the priority logic
4. Preserves the zero output for all-zero input case
5. Results in pure combinational logic without any procedural blocks

The ternary operators will check each bit in priority order (bit 0 first) and assign the corresponding position value. The nested structure ensures proper priority encoding.
