A novel approach using a tree-structured priority encoder that processes the input bits in parallel stages:
1. First stage checks the most significant bit (bit 3) - if set, output is immediately 3 (binary 11)
2. If not, second stage checks bit 2 - if set, output is 2 (binary 10)
3. If not, third stage checks bit 1 - if set, output is 1 (binary 01)
4. Finally, if none of the above, check bit 0 - if set, output is 0 (binary 00)
5. If all bits are zero, output remains 0
This hierarchical approach reduces the average case delay by prioritizing higher bits and exiting early when a '1' is found
