This implementation uses a novel "thermometer-style" priority encoding approach that:
1. Creates a thermometer code where all bits after the first '1' are masked
2. Converts this masked pattern directly to binary position
3. Uses a single level of logic gates for efficient implementation
4. Eliminates the need for cascaded conditionals or separate upper/lower processing
5. Provides a more direct mapping from input to output

The key innovation is generating a modified thermometer code where we:
- Keep the first '1' and all following '0's
- Mask all bits after the first '1'
This creates a unique pattern for each priority position that can be directly converted to binary.
