This implementation uses a novel "bit-scan" approach with parallel processing:
1. Instead of traditional priority encoding, we use parallel comparators to detect the first '1'
2. Each bit position has its own detection logic that checks if:
   - The current bit is '1'
   - All lower bits are '0'
3. The outputs of these parallel detectors are then encoded into binary
4. This approach provides:
   - Uniform delay for all input patterns
   - No cascaded logic dependencies
   - Better scalability for larger encoders
   - Clear separation between detection and encoding phases
