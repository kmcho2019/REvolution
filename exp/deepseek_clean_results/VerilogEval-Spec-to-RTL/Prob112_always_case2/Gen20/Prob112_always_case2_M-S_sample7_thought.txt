The previous solution uses a mask generation step followed by a case statement, which adds unnecessary complexity for a 4-bit encoder. We can simplify this by:
1. Directly checking the input bits in priority order (from MSB to LSB)
2. Using a simple if-else cascade that naturally implements the priority encoding
3. The first '1' found in the cascade determines the output
4. Default to 0 if no bits are set
This approach eliminates the intermediate mask generation and case statement, resulting in simpler and more direct logic.
