Here's a novel approach using a thermometer-to-binary encoder style implementation:

1. **Parallel Priority Detection**: Instead of checking bits sequentially or using arithmetic operations, we'll create parallel logic that directly encodes the highest priority set bit.

2. **Mask Generation**: Generate masks where each bit position indicates "this bit is set AND no higher bit is set". This creates a one-hot representation of the highest priority bit.

3. **Binary Encoding**: Convert the one-hot mask directly to binary using simple OR operations, which is efficient in hardware.

4. **Zero Handling**: Explicitly handle the all-zero case by making it part of the encoding logic.

Key advantages:
- Pure combinational logic with minimal logic levels
- No arithmetic operations (no negation or addition)
- Parallel evaluation of all bit positions
- Scales well to larger encoders
- Clear relationship between input patterns and output encoding
