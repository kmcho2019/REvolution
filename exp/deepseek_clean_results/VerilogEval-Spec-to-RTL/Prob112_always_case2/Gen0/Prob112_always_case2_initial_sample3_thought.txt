The output should be a 2-bit value representing the position (0 to 3). If all input bits are '0', the output should be '00'. 

The priority order is as follows:
- in[3] has highest priority (position 3)
- in[2] next (position 2)
- in[1] next (position 1)
- in[0] lowest priority (position 0)

We can implement this using a series of nested conditional statements (if-else) to check the bits in priority order.
