I'll refactor the priority encoder using a continuous assignment (assign statement) with conditional operators. This approach:

1. Uses purely combinational logic without procedural blocks
2. Maintains the same priority encoding behavior (LSB first)
3. Still handles the all-zeros case properly by defaulting to 00
4. May offer slightly better synthesis results in some tools as it's a direct combinational mapping
5. The nested conditional operators naturally implement the priority order

The structure will be:
- Check in[0] first, if true output 00
- Else check in[1], if true output 01
- Else check in[2], if true output 10
- Else check in[3], if true output 11
- Else (all zeros) output 00
