Novel Architecture: Hybrid Carry-Select Adder with Early Overflow Detection
1. Split the 8-bit addition into two 4-bit chunks processed in parallel
2. For each chunk, compute both possible sums (assuming carry-in=0 and carry-in=1)
3. Use the actual carry-out from the lower chunk to select the correct upper chunk result
4. Early overflow detection by comparing MSB carry scenarios:
   - If both possible carry-outs (c7_0 and c7_1) agree, no overflow
   - If they differ, check which scenario matches the actual carry-in
5. Benefits:
   - Parallel computation of both carry scenarios reduces critical path
   - Early overflow determination simplifies final logic
   - Modular structure scales well to wider adders
   - Power-efficient by computing only necessary carry chains
