To implement an 8-bit signed adder with overflow detection:
1. Perform regular 8-bit addition of inputs a and b
2. For signed overflow detection in 2's complement:
   - Overflow occurs if both inputs are positive (MSB=0) and result is negative (MSB=1)
   - Or if both inputs are negative (MSB=1) and result is positive (MSB=0)
3. The overflow flag should be set when either of these conditions is true
4. The sum output is simply the 8-bit result of the addition
