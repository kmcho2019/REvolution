To implement an 8-bit signed adder with overflow detection:
1. Perform regular binary addition of a and b to get the sum s
2. For signed overflow detection in 2's complement:
   - Overflow occurs if both inputs are positive (MSB=0) and sum is negative (MSB=1)
   - Or if both inputs are negative (MSB=1) and sum is positive (MSB=0)
3. The overflow flag should be set when either of these conditions is true
