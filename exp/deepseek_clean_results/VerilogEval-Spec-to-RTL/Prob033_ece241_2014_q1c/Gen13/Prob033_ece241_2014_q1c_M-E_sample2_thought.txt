Novel Architecture: Speculative Carry-Select Adder with Early Overflow Detection
1. Split the 8-bit addition into two 4-bit segments processed in parallel
2. For the upper 4 bits, compute both possible sums (assuming carry-in=0 and carry-in=1)
3. Use the actual carry-out from lower 4 bits to select the correct upper sum
4. Compute overflow speculatively for both carry cases and select the correct one
5. Benefits:
   - Parallel computation of both carry cases reduces critical path
   - Early overflow detection overlaps with sum computation
   - Balanced logic depth between sum and overflow paths
   - Efficient multiplexing reduces final selection delay
