To simplify the signed adder with overflow detection:
1. Remove the sign extension since we only need the 8-bit sum result
2. Perform direct 8-bit addition which is sufficient for the sum output
3. For overflow detection, use the standard signed overflow condition:
   - Overflow occurs when both inputs have same sign but result has opposite sign
   - This can be checked with just two XOR operations and one AND operation
4. This approach eliminates the 9-bit adder while maintaining correct functionality
