To simplify the 8-bit signed adder with overflow detection:
1. Perform direct 8-bit addition without sign extension since we only need the 8-bit result
2. Compute overflow by checking if the carry-in and carry-out of the MSB differ
3. This eliminates separate sign bit comparisons and reduces logic complexity
4. The overflow condition is: carry_in[MSB] XOR carry_out[MSB]
