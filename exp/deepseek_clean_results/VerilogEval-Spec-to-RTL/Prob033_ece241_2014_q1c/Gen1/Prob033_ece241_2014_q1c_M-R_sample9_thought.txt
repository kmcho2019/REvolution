To refactor the implementation while maintaining the same functionality:
1. Instead of computing the sum separately, we'll combine the addition and overflow detection in a single expression
2. Use the carry bits from the addition to detect overflow more efficiently
3. The key insight is that for signed numbers, overflow occurs when the carry into the MSB differs from the carry out of the MSB
4. This approach reduces the number of operations needed for overflow detection
5. The sum calculation remains the same but is now directly assigned to the output
