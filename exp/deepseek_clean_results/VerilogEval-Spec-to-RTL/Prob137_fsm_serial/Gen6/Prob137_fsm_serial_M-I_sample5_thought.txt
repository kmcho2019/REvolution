To optimize the design for better PPA (Power, Performance, Area), I'll implement these improvements:

1. Performance:
   - Register the next_state logic to break the critical path
   - Simplify the bit counter logic by using a 3-bit counter with synchronous clear

2. Power:
   - Add clock gating for the data_shift register when in IDLE state
   - Use one-hot state encoding for simpler decoding logic

3. Area:
   - Remove redundant registers by combining control signals
   - Optimize state encoding to minimize logic gates

- One-hot state encoding (4 bits) for simpler decoding
- Registered next_state to improve timing
- Clock gating for data_shift register
- Simplified counter logic with synchronous clear
