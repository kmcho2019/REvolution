Instead of using a traditional FSM with multiple states, I'll implement a counter-based design that leverages the shift register itself to track progress. The key innovations are:
1. Use a 10-bit shift register to capture the entire frame (start + 8 data + stop bits)
2. Implement edge detection for the start bit to initiate reception
3. Use a single counter to track bit positions, eliminating separate state transitions
4. Validate the frame when complete by checking start and stop bits
5. Implement a "lockout" mechanism after frame detection to prevent false triggers

This approach reduces state transitions and combines frame validation into a single check at the end, potentially improving timing and reducing power consumption.
