Novel Architecture: "Shift-and-Check" with Embedded State
1. Unified Shift Register: Combine data storage and state tracking into a single 10-bit shift register
   - Bit 9: Current state (0=receiving, 1=idle/stop)
   - Bits 8:1: Data bits
   - Bit 0: Stop bit verification flag
2. Early Stop Detection: Check for stop bit validity while shifting in data
3. Implicit State Machine: State transitions are encoded in the shift register's MSB
4. Minimal Control Logic: Only a simple bit counter is needed
5. Power Optimization: No unnecessary register toggles during idle periods

Key Advantages:
- Reduced state machine complexity by embedding state in shift register
- Early stop bit detection improves error handling
- Minimal control logic reduces area and power
- Single always block simplifies timing analysis
- Natural handling of LSB-first reception through shifting
