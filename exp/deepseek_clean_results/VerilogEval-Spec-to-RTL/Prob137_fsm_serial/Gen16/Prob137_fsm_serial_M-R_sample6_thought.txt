Refactoring Strategy:
1. State Machine Restructuring: Convert the always-block state machine to a continuous assignment style using ternary operators for next-state logic
2. Output Generation: Move done signal generation to a continuous assignment based on current state and input
3. Counter Logic: Implement bit counter as a separate continuous assignment with reset
4. Shift Enable: Simplify shift enable logic using direct assignment from state condition
5. Data Register: Keep sequential always block but make it more compact

Key Changes:
- Eliminated next_state register by computing next state directly
- Simplified control signals to pure combinational logic
- Reduced sequential elements by moving logic to continuous assignments
- Maintained same functionality with more concise structure
- Improved readability by separating different logic components
