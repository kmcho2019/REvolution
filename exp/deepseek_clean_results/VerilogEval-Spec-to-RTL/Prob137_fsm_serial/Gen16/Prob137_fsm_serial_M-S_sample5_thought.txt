Simplification Strategy:
1. State Reduction: Combine STOP and WAIT states into a single STOP_WAIT state since they serve similar purposes (waiting for stop bit)
2. Counter Optimization: Use a 3-bit counter but compare only the MSB (bit_count[2]) to detect when 8 bits are received
3. Shift Logic: Simplify by removing explicit shift_enable signal and using state-based shifting
4. Done Signal: Generate directly from combinational logic to reduce registers
5. Reset Handling: Keep synchronous reset but simplify initialization

Key Changes:
- Reduced from 4 to 3 states (IDLE, RECEIVE, STOP_WAIT)
- Simplified counter comparison logic
- Removed shift_enable control signal
- Direct done signal generation
- Fewer state transitions overall
