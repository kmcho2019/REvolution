To simplify the serial byte receiver FSM while maintaining functionality:
1. Reduce state encoding from 4 to 3 states by merging ERROR with STOP
2. Use one-hot encoding for better timing
3. Simplify shift operation and bit counting
4. Optimize done signal generation to only update when needed
5. Remove redundant register updates

Key changes:
- Merge ERROR into STOP state (wait for stop bit in same state)
- Use one-hot encoding (3 bits) for better timing
- Simplify shift operation to direct assignment
- Only update done_reg when a valid byte is received
- Remove unnecessary register updates
