Refactoring Strategy:
1. State Encoding: Keep binary encoding but simplify to 3 states (IDLE/RECEIVE/WAIT) by merging STOP into WAIT
2. Data Handling: Use continuous assignment for shift register to reduce sequential logic
3. Control Logic: Move done signal generation to combinational logic with registered output
4. Counter Logic: Simplify to 2-bit counter by checking stop condition one cycle early
5. Error Handling: Maintain robust WAIT state but make it more efficient
6. Structure: Use separate always blocks for state and counter, with combinational logic for other signals

Key Changes:
- Reduced state machine complexity by merging STOP into WAIT
- Simplified counter logic by checking stop condition early
- Moved shift register to continuous assignment
- Maintained synchronous reset and registered outputs
- Improved timing by reducing combinational logic depth
