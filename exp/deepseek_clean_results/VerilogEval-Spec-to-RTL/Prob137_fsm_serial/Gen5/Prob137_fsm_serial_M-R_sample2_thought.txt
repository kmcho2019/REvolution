Refactoring Strategy:
1. State Machine: Convert to a one-hot encoded state machine for potentially better timing (easier to decode)
2. Combinational Logic: Move all next-state logic to continuous assignments (assign statements) for clarity
3. Bit Counting: Use a simpler terminal condition (bit_count == 3'd7) for readability
4. Shift Register: Keep the same LSB-first approach but make the assignment more explicit
5. Done Signal: Generate directly from the state and input condition without a separate register
6. Reset Handling: Maintain synchronous reset but simplify the reset assignments

Key Changes:
- One-hot state encoding (4 bits for 4 states)
- All next-state logic implemented with assign statements
- Explicit state transitions in continuous assignments
- Direct done signal generation from STOP state and input
- Simplified bit counter comparison
