Refactored design with these improvements:
1. One-hot encoded FSM for better timing (4 states = 4 bits)
2. Combined STOP and ERROR states to reduce state count
3. Simplified shift operation using direct assignment
4. Reduced bit counter to 2 bits (since we count 0-7)
5. Optimized done signal generation to only set when needed
6. Used continuous assignments for next_state logic where possible

Key changes:
- Merged STOP and ERROR states into STOP_WAIT
- One-hot encoding reduces combinational logic depth
- Simplified shift operation with direct bit assignment
- More efficient done signal generation
