Novel Architecture: "Shift-and-Check" with Embedded State Tracking
1. Unified Data and State Tracking: Combine the shift register and state tracking into a single 10-bit register (1 start + 8 data + 1 stop)
2. Bit Position as State: Use the shift register's fill level to implicitly track progress through the protocol
3. Early Stop Bit Detection: Check for stop bit validity as soon as the 9th bit is shifted in
4. Minimal State Machine: Only 2 explicit states needed (IDLE and ACTIVE) since shift position tracks progress
5. Efficient Done Generation: Done pulses when the full pattern is valid (start=0, stop=1) without extra registers
6. Power Optimization: Only shift when in ACTIVE state and stop checking when pattern is invalid

Key Advantages:
- Eliminates separate bit counter
- Reduces state machine complexity
- Combines data storage and protocol tracking
- Naturally handles stop bit wait condition
- More compact implementation
