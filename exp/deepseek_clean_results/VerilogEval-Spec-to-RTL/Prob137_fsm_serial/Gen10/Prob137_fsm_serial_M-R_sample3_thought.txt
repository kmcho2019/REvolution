Refactoring Strategy:
1. State Encoding: Keep the same state machine logic but implement it using continuous assignments instead of procedural blocks
2. Data Path: Maintain the same LSB-first shifting but express it with combinational logic
3. Control Logic: Convert state transitions to assign statements with ternary operators
4. Done Signal: Generate it directly from the current state and input
5. Optimization:
   - Remove intermediate registers where possible
   - Use continuous assignments for clearer data flow
   - Simplify the bit counter logic
   - Maintain synchronous reset for all sequential elements

Key Changes:
- State machine implemented with assign statements
- Data shifting expressed as combinational logic
- Done signal generated without an extra register
- More explicit data flow through continuous assignments
- Reduced register usage while maintaining same functionality
