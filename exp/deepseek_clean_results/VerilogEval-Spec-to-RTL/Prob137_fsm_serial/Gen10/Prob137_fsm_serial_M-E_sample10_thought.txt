Novel Architecture Idea:
1. Combined Shift-State Register: Instead of separate state and data registers, use a single 11-bit register that tracks both the received bits and protocol state implicitly
2. Early Stop Detection: Check for stop bit validity as soon as the 9th bit arrives (after 8 data bits)
3. Implicit State Encoding: The register pattern itself indicates the state:
   - All 1's: IDLE state
   - 0 followed by 8 bits: RECEIVING state
   - Last bit 1: Valid STOP
   - Last bit 0: ERROR state
4. Reduced Logic: Eliminates explicit state machine and bit counter, using pattern matching instead

Advantages:
- Fewer registers (11 bits vs separate state+data+count)
- Simpler combinational logic
- Early termination on protocol errors
- Natural handling of LSB-first reception
