Novel Architecture Idea:
1. Counter-Based State Tracking: Instead of explicit state registers, use a 4-bit counter to track progress through the protocol (0-10 bits)
2. Parallel Data Capture: Store incoming bits directly into their correct positions in the data register
3. Early Stop Bit Detection: Check for stop bit validity immediately when expected (bit position 9)
4. Idle Detection: Monitor for start bit during idle periods
5. Efficient Done Generation: Generate done signal combinatorially when valid stop bit is detected

Key Advantages:
- Eliminates traditional state machine logic, reducing control overhead
- Parallel data capture avoids shift operations
- Early stop bit checking reduces latency
- Simpler control flow with just counter management
- Reduced register usage compared to FSM approach
