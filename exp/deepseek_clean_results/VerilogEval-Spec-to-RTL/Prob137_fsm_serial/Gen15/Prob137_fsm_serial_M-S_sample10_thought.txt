Simplification Strategy:
1. State Reduction: Combine STOP and WAIT states into a single STOP_WAIT state since their behavior is similar (both wait for stop bit)
2. Counter Optimization: Use a 3-bit counter for tracking received bits (0-7) and eliminate separate shift enable signal
3. Data Handling: Shift register updates directly in RECEIVE state without enable signal
4. Done Logic: Generate done signal directly from combinational logic without intermediate register
5. Reset Handling: Maintain synchronous reset for all registers

Key Improvements:
- Reduced state machine complexity (3 states instead of 4)
- Eliminated shift_enable control signal
- Simplified counter and data register updates
- Direct done signal generation
- Maintains all original functionality
- Better timing due to reduced logic levels
