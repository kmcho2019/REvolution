Refactoring Strategy:
1. State Encoding: Keep binary encoding but simplify to 3 states (IDLE, RECEIVE, WAIT) by merging STOP into WAIT logic
2. Output Logic: Move done signal generation to continuous assignment for simpler timing
3. Counter Logic: Use separate always block for counter to improve clarity
4. Shift Register: Implement with explicit enable condition to reduce unnecessary transitions
5. State Transitions: Simplify conditions by combining stop bit checks with WAIT state
6. Reset Handling: Maintain synchronous reset but streamline the reset assignments

Key Changes:
- Reduced state machine complexity by merging STOP into WAIT
- Continuous assignment for done signal improves timing
- Separate always blocks for different functions improves readability
- Explicit shift enable condition reduces power consumption
- Simplified state transition logic
