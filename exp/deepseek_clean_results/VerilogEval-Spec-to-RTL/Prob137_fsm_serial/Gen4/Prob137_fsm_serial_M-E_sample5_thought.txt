Novel Windowed Detection Approach:
1. Instead of using a separate bit counter, we'll use the shift register's position to track progress
2. The MSB of the shift register will indicate when we've collected all 8 bits (when it becomes 1)
3. This eliminates the need for a separate counter, reducing area and power
4. We'll use a "window" concept where the start bit opens the window and the stop bit closes it
5. Error recovery is handled by monitoring the line state during the expected stop bit period

Key Advantages:
- No explicit bit counter needed (area savings)
- Natural detection of byte completion via shift register MSB
- Clear window-based protocol interpretation
- Efficient error recovery by watching line state
