Simplification Strategy:
1. Reduce States: Combine STOP and WAIT states into a single DONE state since their behavior is similar (both wait for 'in' to go high)
2. Simplify Counting: Use a 3-bit counter that auto-resets, eliminating separate reset logic
3. Optimize Data Capture: Shift register updates only when in RECEIVE state
4. Clean Done Logic: Generate done signal combinationally from state and input
5. Minimize Registers: Remove done_reg since done can be derived directly

Key Benefits:
- Fewer states (3 instead of 4) reduces control logic
- Simpler state transitions with clearer conditions
- Reduced register usage (no done_reg needed)
- Maintains all original functionality
