To optimize the design for better PPA (Power, Performance, Area), I'll implement these improvements:

1. State Encoding:
   - Switch from one-hot to binary encoding (2 bits) for the FSM to reduce area and power
   - This reduces the number of flip-flops needed for state storage

2. Timing Optimization:
   - Merge WAIT and STOP states to simplify state transitions
   - Remove pipelining of done signal to reduce latency
   - Combine state and counter logic to reduce critical path

3. Power Optimization:
   - Remove unnecessary clock gating (shift register is small)
   - Simplify control logic to reduce switching activity

4. Area Optimization:
   - Reduce state register width from 4 bits to 2 bits
   - Simplify next-state logic by merging similar states

Key changes:
- Binary FSM encoding (2 bits)
- Merged STOP/WAIT states
- Direct done signal generation
- Simplified control logic
