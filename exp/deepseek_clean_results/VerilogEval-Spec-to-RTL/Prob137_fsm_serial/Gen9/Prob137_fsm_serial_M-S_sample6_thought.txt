To simplify the design while maintaining functionality, I'll make these key changes:

1. State Encoding: Switch from one-hot to binary encoding (2 bits) for the 4 states to reduce area and power.

2. State Reduction: Merge the WAIT state into STOP state by adding a counter to track invalid stop bits, eliminating a separate state.

3. Control Logic: Combine state transitions and data handling into simpler sequential logic, removing the need for separate always blocks.

4. Done Signal: Generate it directly in the state machine without pipelining to reduce latency.

The simplified design will:
- Use only 2 bits for state encoding
- Have 3 states instead of 4 (IDLE, RECEIVE, STOP)
- Generate done signal immediately when valid stop bit is detected
- Maintain all required functionality with less complexity
