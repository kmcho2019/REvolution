Instead of using explicit state transitions, we can implement a counter-based approach that:
1. Uses a 4-bit counter to track the current bit position (0-10: start + 8 data + stop)
2. Captures data bits in parallel when counter is in data range
3. Validates start/stop conditions based on counter value
4. Uses combinational logic to determine 'done' when proper sequence is detected
5. Automatically resynchronizes on invalid stop bit by waiting for line to return high

Key advantages:
- Eliminates explicit state machine logic
- More compact implementation
- Easier to extend for different frame sizes
- Parallel data capture reduces critical path
