To simplify the byte receiver FSM while maintaining functionality:
1. Remove the separate WAIT state - we can handle missing stop bits by staying in STOP state until we see a 1
2. Combine state transition and data logic into a single always block for clarity
3. Use simpler state encoding with fewer states
4. Eliminate unnecessary registers and simplify control logic
5. Maintain same functionality: detect start bit, receive 8 bits, check stop bit, and signal done

The simplified FSM will have these states:
- IDLE: waiting for start bit
- RECEIVE: receiving 8 data bits
- STOP: checking stop bit (also handles missing stop bit case)
