Here's a novel approach using a shift register with integrated state tracking and a parallel validity check:

1. Instead of a traditional FSM, we'll use a 10-bit shift register to capture the entire frame (start + 8 data + stop bits)
2. The shift register acts as a circular buffer that continuously shifts in new bits
3. We'll use combinational logic to check the frame validity when the register is full:
   - First bit (oldest) must be 0 (start bit)
   - Last bit (newest) must be 1 (stop bit)
4. A counter tracks when we have 10 valid bits to check
5. The 'done' signal pulses high for one cycle when a valid frame is detected
6. Reset clears everything synchronously

Advantages:
- Eliminates explicit state machine logic
- Parallel validity checking simplifies control flow
- Naturally handles error cases by continuously shifting
- More compact implementation
