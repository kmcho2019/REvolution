Refactoring Strategy:
1. State Machine Restructuring: Convert the always-block based state machine to a more combinational approach using assign statements for next_state logic
2. Output Logic Simplification: Move done signal generation directly to combinational logic
3. Shift Register Optimization: Keep the sequential shift register but simplify its control logic
4. Counter Integration: Combine bit counter logic with state transitions for better timing
5. Key Changes:
   - Use continuous assignments for next_state logic
   - Eliminate separate shift_enable signal by integrating it into state conditions
   - Simplify done signal generation
   - Maintain same state encoding and functionality
   - Keep synchronous reset behavior

Benefits:
- More transparent state transitions
- Reduced sequential logic complexity
- Potentially better timing due to simplified control paths
- Maintains same functionality while being more readable
