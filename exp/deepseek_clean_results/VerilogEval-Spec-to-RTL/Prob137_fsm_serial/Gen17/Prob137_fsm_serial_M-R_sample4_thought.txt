Refactoring Strategy:
1. State Encoding: Switch to one-hot encoding (4 bits) for potentially better timing at the expense of slightly more area
2. Data Handling: Move shift register to continuous assignment with enable gating
3. State Transitions: Implement next state logic using assign statements for clearer combinational logic
4. Counter Logic: Simplify bit_count comparison by using a separate wire for count complete
5. Done Signal: Keep single-cycle pulse but implement with direct assignment
6. Reset: Maintain synchronous reset but simplify the reset logic

Key Changes:
- One-hot state encoding for potentially better timing
- Continuous assignments for next state logic
- Simplified counter comparison
- Clear separation of combinational and sequential logic
- More explicit state transitions
