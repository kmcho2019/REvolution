Simplification Strategy:
1. State Reduction: Combine STOP and WAIT states into a single STOP_WAIT state since they both wait for stop bit (1)
2. Counter Optimization: Use simpler 3-bit counter without separate enable signal
3. Shift Register: Remove clock gating and shift unconditionally in RECEIVE state
4. Output Logic: Generate done signal directly from combinational logic
5. Reset Handling: Keep synchronous reset but simplify register updates

Key Benefits:
- Fewer states (3 instead of 4)
- No separate shift enable signal
- Simpler counter implementation
- Direct done signal generation
- Maintains all required functionality
