3. Error Handling: Maintain robust WAIT state to handle missing stop bits
4. Done Logic: Use single-cycle done signal assertion when valid stop bit is detected
5. Reset: Synchronous reset as specified
6. Optimizations:
   - Combine state transitions and data handling in single always block for cleaner code
   - Use bit_count comparison directly in state transitions
   - Minimize unnecessary signal toggling by only updating registers when needed
   - Clear separation of sequential and combinational logic for better synthesis
   - Clock-gated shift register for power efficiency
