I'll implement a shift-register centric design with these key features:
1. Edge detection for start bit to improve noise immunity
2. A timeout counter to handle missing stop bits gracefully
3. Parallel data capture instead of bit-by-bit counting
4. State machine simplified to just 3 states
5. Done signal generated combinatorially from state and conditions

The design uses the shift register both for data storage and protocol validation. The timeout mechanism ensures robustness against missing stop bits without complex state transitions. Edge detection on the start bit makes it more reliable in noisy environments.
