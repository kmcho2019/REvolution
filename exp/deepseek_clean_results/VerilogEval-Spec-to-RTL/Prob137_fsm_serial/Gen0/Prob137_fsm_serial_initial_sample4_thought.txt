To implement a serial byte receiver FSM, we need to:
1. Detect the start bit (0) after idle state (1)
2. Shift in 8 data bits (LSB first)
3. Verify stop bit (1)
4. Handle reset and error cases

The FSM will have these states:
- IDLE: waiting for start bit
- RECEIVE: shifting in 8 data bits
- STOP: checking stop bit
- ERROR: waiting for stop bit after error

The 'done' signal pulses high for one cycle when a complete byte is successfully received.
