To implement this serial byte receiver, we'll need a finite state machine (FSM) with the following states:
1. IDLE: Waiting for start bit (0)
2. RECEIVE: Collecting 8 data bits (LSB first)
3. STOP: Verifying stop bit (1)
4. ERROR: Waiting for stop bit when it's missing

The FSM transitions:
- From IDLE to RECEIVE when start bit (0) is detected
- After 8 bits in RECEIVE, moves to STOP to check stop bit
- If stop bit is correct (1), goes back to IDLE and asserts done
- If stop bit is missing (0), enters ERROR state until a 1 is seen
- Reset brings FSM back to IDLE

We'll use a 3-bit counter to track received bits and a shift register to accumulate data bits.
