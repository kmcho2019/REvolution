To implement a byte receiver FSM for a serial communication protocol with start bit (0), 8 data bits, and stop bit (1), we need to:
1. Create states for IDLE (waiting for start bit), RECEIVE (collecting 8 data bits), and STOP (verifying stop bit)
2. Use a counter to track how many data bits have been received
3. Transition between states based on the input bit and current state
4. Output 'done' when a complete byte is successfully received (correct stop bit)
5. Handle reset synchronously to return to IDLE state
6. The FSM should stay in STOP state until a 1 is seen (correct stop bit or idle)
