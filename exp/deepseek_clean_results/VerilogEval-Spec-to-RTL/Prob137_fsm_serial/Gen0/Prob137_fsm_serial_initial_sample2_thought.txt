To implement a byte receiver FSM for a serial communication protocol with start bit (0), 8 data bits, and stop bit (1), we need to design a finite state machine with the following states:
1. IDLE: Waiting for start bit (line=1)
2. START: Start bit detected (line=0)
3. DATA: Receiving 8 data bits (LSB first)
4. STOP: Verifying stop bit (line=1)
5. ERROR: If stop bit is not detected, wait until line=1

The FSM transitions:
- From IDLE to START when line=0
- From START to DATA (reset bit counter)
- In DATA state, count 8 bits then go to STOP
- From STOP to IDLE if line=1 (valid stop), else stay in STOP until line=1
- Reset synchronously returns to IDLE state

The 'done' output is asserted when a complete valid byte is received (after valid stop bit).
