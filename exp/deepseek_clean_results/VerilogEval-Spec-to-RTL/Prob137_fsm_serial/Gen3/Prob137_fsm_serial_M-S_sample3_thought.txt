To simplify the serial byte receiver FSM while maintaining functionality:
1. Reduce state encoding from 4 states to 3 states by merging ERROR with STOP
2. Use one-hot encoding for better timing
3. Simplify bit counting by using a 3-bit counter that naturally wraps
4. Combine state transition and storage into a single always block
5. Only update shift register when receiving data
6. Only clear done_reg when needed (on reset or after asserting done)

Key optimizations:
- Merge ERROR into STOP state (wait for 1 in both cases)
- Use one-hot state encoding (better timing)
- Remove separate next_state logic by using single always block
- Simplify counter logic
- Reduce unnecessary register updates
