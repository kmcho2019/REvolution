To optimize the design for better PPA (Power, Performance, Area), I'll implement these improvements:

1. Timing Optimization:
   - Separate the shift register and counter logic from state transitions to reduce critical path
   - Use one-hot encoding for FSM states to simplify state transition logic
   - Pipeline the done signal generation to break timing paths

2. Power Optimization:
   - Add clock gating for the shift register when not in RECEIVE state
   - Minimize unnecessary state transitions

3. Area Optimization:
   - Simplify the bit counter to use 3 bits (already optimal)
   - Keep compact state encoding (one-hot is slightly larger but better for timing)

Key changes:
- One-hot FSM encoding (4 bits) for faster state transitions
- Separate always blocks for state, data, and output logic
- Clock gating for shift register
- Early termination of WAIT state when line returns to idle
