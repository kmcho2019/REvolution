Refactoring Strategy:
1. State Machine Restructuring: Convert the always-block based FSM to a single always block with combined state transition and output logic for better clarity and timing.
2. Bit Counter Optimization: Use a 3-bit counter but compare only the MSB to detect when all 8 bits are received (bit_count[3]).
3. Shift Register: Keep the LSB-first approach but simplify the assignment.
4. Done Signal: Generate it directly from the state machine logic without an intermediate register.
5. Reset Handling: Keep synchronous reset but consolidate the initialization.

Key Changes:
- Single always block for both state transitions and register updates
- Simplified bit counter comparison
- Direct done signal generation
- Cleaner state transitions with immediate assignments
