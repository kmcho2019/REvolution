Simplification Strategy:
1. State Reduction: Combine STOP and ERROR states into a single WAIT_STOP state since both wait for stop bit (1)
2. Bit Counting: Use a 3-bit counter but simplify comparison logic by counting down instead of up
3. Data Shift: Keep efficient LSB-first shift but remove redundant register assignments
4. Done Logic: Directly assign from combinational logic to reduce registers
5. Reset Handling: Maintain synchronous reset but simplify state transitions

Key Optimizations:
- Reduced from 4 to 3 states (IDLE, RECEIVE, WAIT_STOP)
- Simplified state transition logic
- Removed done_reg since done can be combinational
- More efficient bit counting with countdown
- Fewer register updates in always block
