Novel Approach: LFSR-based Counter with Binary Conversion
1. Use a 10-bit Linear Feedback Shift Register (LFSR) as the base counter
2. The LFSR will cycle through 1023 states (2^10-1) but we'll constrain it to 1000 states
3. Add a binary conversion block to transform the LFSR state to a binary count
4. Benefits:
   - LFSRs are area-efficient and have fast propagation
   - The pseudo-random pattern can help with EMI reduction
   - Conversion to binary gives us the desired output format
5. Implement synchronous reset that initializes to a known LFSR state
6. Add early termination logic when count reaches 999
7. The conversion uses a lookup table approach for simplicity
