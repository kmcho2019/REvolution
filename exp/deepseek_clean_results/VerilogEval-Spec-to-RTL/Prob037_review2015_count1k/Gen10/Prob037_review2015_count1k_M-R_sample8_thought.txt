Refactoring Approach:
1. Move the counter logic to a continuous assignment (assign) for the next state value
2. Keep the sequential element (register) for the current state
3. Simplify terminal count detection with a direct comparison to 10'd999
4. Use a ternary operator for cleaner reset/rollover logic
5. Benefits:
   - Clear separation of combinational and sequential logic
   - More straightforward terminal count detection
   - Reduced critical path by eliminating the separate upper/lower bit comparison
   - Maintains same functionality with potentially better timing
   - More concise code structure
