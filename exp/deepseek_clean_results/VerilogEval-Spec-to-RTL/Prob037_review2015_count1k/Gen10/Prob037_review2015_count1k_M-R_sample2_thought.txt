Refactoring Approach:
1. Move the counter logic to a continuous assignment (assign) instead of always block
2. Use a combinational next-state logic with a register for the counter
3. Implement the terminal count as a direct comparison (10'd999) for simplicity
4. Maintain synchronous reset functionality
5. Benefits:
   - Clear separation of combinational and sequential logic
   - Simplified terminal count detection
   - More explicit data flow
   - Easier timing analysis due to separated logic
   - Maintains same functionality while improving readability

The implementation will still count 0-999 with 1000-cycle period, resetting on active high or terminal count, but with cleaner structure.
