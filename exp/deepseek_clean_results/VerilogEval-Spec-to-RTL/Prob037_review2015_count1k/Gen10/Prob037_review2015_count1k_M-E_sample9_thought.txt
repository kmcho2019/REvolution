Instead of using a standard binary counter, I'll implement a BCD counter that counts each digit separately. This approach:
1. Uses three 4-bit counters for hundreds, tens, and units digits
2. Each digit rolls over independently (units at 9, tens at 9, hundreds at 9)
3. Simplifies comparison logic since we only need to compare each digit to 9
4. Reduces logic complexity for the wrap-around condition
5. Makes the counter output more human-readable in simulation/debug
6. Still maintains the same overall counting behavior (0-999)

The design will have:
- Three 4-bit registers for each digit
- Simple increment and carry logic between digits
- Synchronous reset that clears all digits
- Output formed by concatenating the three digits
