Refactoring Approach:
1. Move the counter logic to a continuous assignment (assign) instead of an always block
2. Use a ternary operator for the counter update logic
3. Keep the same terminal count detection logic but express it more concisely
4. Maintain synchronous reset functionality by registering the output
5. Benefits:
   - More compact code structure
   - Clearer expression of the counter's behavior
   - Same functionality with potentially better readability
   - Maintains all original timing characteristics
   - Still synthesizes to efficient hardware

The implementation will use a registered output with continuous assignment for the next-state logic.
