Refactoring Strategy:
1. Move the counter logic to a continuous assignment (assign) instead of an always block
2. Use a ternary operator for the counter update logic
3. Keep the same efficient terminal count detection but express it more concisely
4. Maintain synchronous reset functionality through proper clocked assignment
5. Benefits:
   - More compact code structure
   - Clearer expression of the counter's next-state logic
   - Same functionality with potentially better readability
   - Maintains all original PPA characteristics
   - Easier to modify for different counter ranges

The implementation will still count 0-999 with 1000-cycle period, but with a more declarative style.
