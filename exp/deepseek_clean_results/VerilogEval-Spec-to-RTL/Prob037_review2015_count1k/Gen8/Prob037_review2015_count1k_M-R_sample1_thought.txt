Refactoring the counter using a continuous assignment (assign) with a combinational next-state logic and a separate sequential element. This approach:
1. Separates combinational and sequential logic explicitly
2. Uses an always block only for the register (q)
3. Computes the next state (next_q) combinationally
4. Makes the reset and wrap-around logic more visible in the combinational part
The functionality remains identical but the structure is clearer.
