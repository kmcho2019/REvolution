Instead of a traditional binary counter, we can implement a pseudo-random counter that's constrained to count sequentially. The key ideas are:
1. Use an LFSR structure for efficient counting (better PPA characteristics)
2. Add logic to detect terminal count (999) and reset
3. Include a correction mechanism to ensure sequential counting when the LFSR would normally skip values
4. This approach can potentially reduce power consumption due to fewer bit toggles per cycle compared to a binary counter
