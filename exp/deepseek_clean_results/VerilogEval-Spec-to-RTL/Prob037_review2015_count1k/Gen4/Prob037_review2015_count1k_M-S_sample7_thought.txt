To simplify the counter implementation, I'll combine the combinational and sequential logic into a single always block. This reduces the number of signals and logic blocks while maintaining the same functionality. The counter will:
1. Reset to 0 when reset is high
2. Increment by 1 each cycle, wrapping around to 0 after 999
3. Use a single always block for both reset and counting logic
This approach eliminates the need for a separate next_q signal and combinational logic block.
