1. Pre-compute the terminal count (999) comparison to reduce critical path
2. Use a registered terminal count signal to break the comparison logic from the increment path
3. Maintain synchronous reset functionality
4. Keep the simple increment operation for area efficiency

This should improve timing by reducing the combinational path while keeping area and power similar.
