Simplified Approach: Single Counter with Direct Comparison
1. Use a single 10-bit counter instead of split counters to reduce complexity
2. Count from 0 to 999 directly, resetting to 0 when reaching 999
3. Use simple equality comparison for terminal count (count == 10'd999)
4. Benefits:
   - Eliminates split counter logic and combination
   - Single comparison is simpler than multiple max detectors
   - Easier to understand and verify
   - Reduced area from eliminating intermediate registers
5. Maintain synchronous reset functionality
6. Output is simply the counter value
