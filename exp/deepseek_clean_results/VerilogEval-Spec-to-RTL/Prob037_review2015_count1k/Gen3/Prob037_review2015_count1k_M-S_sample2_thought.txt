The original solution is already quite simple and efficient for a 10-bit counter. However, we can simplify it slightly by:
1. Removing the explicit comparison with 999 since the counter will naturally wrap around when it reaches 1023 (but we need to force wrap at 999)
2. Using a simpler increment and conditional wrap-around logic
3. Maintaining the same synchronous reset functionality

The key observation is that we can use modular arithmetic to automatically wrap around at 1000 by checking if the next value would exceed 999, rather than comparing with 999 directly.
