I'll refactor the counter using a combination of continuous assignments and an always block. The key changes are:
1. Split the counter logic into combinational next-state and sequential state update
2. Use `assign` for the next-state logic
3. Keep the sequential part in an always block
4. This separation makes the design more modular and can help with synthesis optimizations

The functionality remains identical - a 10-bit counter that counts from 0 to 999 with synchronous reset.
