To implement a counter that counts from 0 to 999 with a period of 1000 cycles, we need a 10-bit register (since 2^10 = 1024 > 1000) that increments on every clock cycle. The counter should reset to 0 when the reset signal is active (synchronous reset) or when it reaches 999 (to wrap around). The output q will be the current value of this counter.
