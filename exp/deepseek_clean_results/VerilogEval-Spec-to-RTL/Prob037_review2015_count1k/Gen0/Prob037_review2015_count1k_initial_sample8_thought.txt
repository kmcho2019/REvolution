To implement a counter that counts from 0 to 999 with a period of 1000 cycles, we need a 10-bit register (since 2^10 = 1024 > 1000) that increments on every clock cycle. The counter should reset to 0 when either:
1. The reset signal is active (high)
2. The counter reaches 999 (we detect this and wrap around to 0)

The implementation will use synchronous reset logic and a comparator to detect when the count reaches 999 (binary 1111100111).
