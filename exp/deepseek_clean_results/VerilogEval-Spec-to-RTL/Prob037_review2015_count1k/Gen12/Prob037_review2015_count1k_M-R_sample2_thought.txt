To refactor the counter implementation while maintaining the same functionality:
1. Use combinational logic for next-state calculation with assign statements
2. Separate the next-state logic from the sequential state update
3. Create a wire for the next counter value
4. Use a continuous assignment to calculate the next value based on current state
5. Keep the synchronous reset and clocking behavior in the always block

This approach:
- Makes the next-state logic more explicit
- Separates combinational and sequential logic clearly
- Maintains the same counting behavior and reset functionality
- Potentially improves readability by showing the state transition logic separately
