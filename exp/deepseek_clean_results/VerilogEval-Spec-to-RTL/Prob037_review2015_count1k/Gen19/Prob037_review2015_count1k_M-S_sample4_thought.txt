Simplified Approach: Single Counter with Direct Comparison
1. Use a single 10-bit counter instead of split counters to reduce complexity
2. Count from 0 to 999 directly, resetting to 0 when reaching 999
3. Simple terminal count detection by comparing against 10'd999
4. Benefits:
   - Eliminates split counter coordination logic
   - Reduces area by removing intermediate registers and combinational logic
   - Simplifies verification with straightforward counting behavior
5. Maintain synchronous reset functionality
6. The output is simply the counter value itself
