Novel Architecture Idea: Binary to BCD Conversion Counter
1. Instead of using a pure binary counter, implement a BCD (Binary Coded Decimal) counter that counts from 000 to 999
2. Use three 4-bit BCD counters (one for each digit) that roll over at 9
3. The hundreds digit increments when the tens digit rolls over from 9 to 0
4. The tens digit increments when the units digit rolls over from 9 to 0
5. This approach:
   - Naturally handles decimal counting
   - Simplifies terminal count detection (just check if all digits are 9)
   - May offer better power characteristics due to reduced bit toggles
   - Provides direct access to decimal digits if needed for display
6. Reset synchronously sets all digits to 0
