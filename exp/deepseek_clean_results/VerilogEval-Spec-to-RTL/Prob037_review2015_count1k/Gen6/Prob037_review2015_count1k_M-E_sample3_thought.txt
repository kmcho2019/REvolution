Novel BCD counter architecture:
1. Instead of a single 10-bit binary counter, use three separate BCD counters (hundreds, tens, ones)
2. Each digit counts from 0-9 and rolls over independently
3. The hundreds digit increments only when tens rolls over from 9 to 0
4. The tens digit increments only when ones rolls over from 9 to 0
5. This reduces comparison logic since we only need to compare against 9 for each digit
6. The output is reconstructed by concatenating the three digits
7. Reset synchronously clears all three counters
