Instead of a conventional binary counter, we can implement a pseudo-random counter that's forced to count sequentially. This approach:
1. Uses an LFSR for its efficient implementation and low switching activity
2. Adds correction logic to transform the pseudo-random sequence into a linear count
3. Maintains the same reset behavior and count range
4. Potentially reduces power consumption due to fewer bit toggles per cycle
5. Uses a terminal count detection to reset the sequence after 999
