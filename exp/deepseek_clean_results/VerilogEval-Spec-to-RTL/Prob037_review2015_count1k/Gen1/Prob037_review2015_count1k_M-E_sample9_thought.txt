Instead of using a single 10-bit counter, we can implement a hierarchical counter structure using three separate counters for hundreds, tens, and units digits (each 4 bits). This approach reduces the comparison complexity since we only need to check when each digit rolls over. The hundreds counter increments when tens rolls over from 9 to 0, and similarly for tens and units. This reduces the critical path by breaking down the large comparison into smaller, parallel comparisons.
