The original solution is already quite simple, but we can make it slightly more concise by:
1. Removing the explicit else-if structure for the counter wrap-around
2. Using a single conditional assignment for both reset and normal operation
3. Letting the counter naturally overflow from 999 to 0 (since 999+1 = 1000, which is 1111101000 in binary, but we only keep the lower 10 bits which becomes 0)
This reduces the logic while maintaining identical functionality.
