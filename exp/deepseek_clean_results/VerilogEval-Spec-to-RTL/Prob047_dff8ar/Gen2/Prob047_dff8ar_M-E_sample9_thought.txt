Instead of using a behavioral always block, we'll implement the 8-bit register structurally by:
1. Instantiating 8 individual DFF primitives (fdpe) from Xilinx library
2. Each DFF has:
   - Clock (C) connected to clk
   - Asynchronous preset (PRE) connected to areset
   - Data input (D) connected to respective d bit
   - Output (Q) connected to respective q bit
3. Using fdpe primitives which are positive-edge triggered DFFs with async preset
4. The preset will initialize outputs to 1, so we invert the reset logic to achieve active-high reset to 0
