To implement an 8-bit register with asynchronous reset, we'll use 8 D flip-flops in parallel. Each flip-flop will have:
1. Positive edge clock trigger
2. Active high asynchronous reset (reset to 0 when areset is high)
3. Data input from corresponding bit of d[7:0]
4. Data output to corresponding bit of q[7:0]
The reset will override the normal operation when asserted.
