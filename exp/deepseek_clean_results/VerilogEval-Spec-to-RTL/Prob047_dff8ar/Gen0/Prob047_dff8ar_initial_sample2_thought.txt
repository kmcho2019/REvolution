To implement an 8-bit register with asynchronous reset, we'll use 8 D flip-flops in parallel. Each flip-flop will:
1. Be triggered on the positive edge of clk
2. Have an active high asynchronous reset (areset) that sets the output to 0
3. Pass the input d bits to corresponding q bits when not in reset
The module will bundle these 8 flip-flops together with a common clock and reset.
