To implement an 8-bit register with asynchronous reset, we'll need 8 D flip-flops working in parallel. Each flip-flop will have:
1. Positive-edge clock triggering
2. Active high asynchronous reset (areset)
3. Data input from corresponding bit of 'd'
4. Output to corresponding bit of 'q'
When areset is high, all flip-flops should reset to 0. Otherwise, on each positive clock edge, the input 'd' should be captured and output on 'q'.
