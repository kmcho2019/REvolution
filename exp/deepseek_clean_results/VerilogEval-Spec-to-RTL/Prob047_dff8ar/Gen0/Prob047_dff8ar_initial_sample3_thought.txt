To implement an 8-bit register with asynchronous reset, we'll need 8 D flip-flops connected in parallel. Each flip-flop will have:
1. A clock input connected to 'clk' (positive edge triggered)
2. An asynchronous reset input connected to 'areset' (active high)
3. A data input connected to the corresponding bit of 'd'
4. An output connected to the corresponding bit of 'q'
When reset is active (areset=1), all flip-flops should output 0. Otherwise, on each positive clock edge, they should capture and output their input values.
