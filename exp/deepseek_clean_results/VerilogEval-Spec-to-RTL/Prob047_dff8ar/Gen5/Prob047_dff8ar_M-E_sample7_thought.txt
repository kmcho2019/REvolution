Instead of using a single always block for all 8 flip-flops, we can implement them individually using generate blocks. This approach:
1. Provides more explicit control over each flip-flop
2. Makes the design more modular and scalable
3. Allows for potential future customization of individual flip-flops
4. Still maintains the same functionality of asynchronous reset and positive edge triggering
Each flip-flop is instantiated in a loop with its own bit from the input and output buses.
