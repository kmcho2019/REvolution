Here's a novel approach using a shift register-like structure with a twist:
1. Instead of independent DFFs, we'll implement a circular buffer of 8 flip-flops
2. The reset operation will clear all flip-flops simultaneously
3. We'll use a counter to track which flip-flop should capture input data each cycle
4. The output will be a parallel read of all flip-flop states
5. This creates a pseudo-random access memory effect while still using simple DFFs
