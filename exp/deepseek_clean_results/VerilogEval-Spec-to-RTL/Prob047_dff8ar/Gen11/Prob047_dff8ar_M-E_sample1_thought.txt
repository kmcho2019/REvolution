Novel approach using a register-based implementation with parameterized width:
1. Instead of instantiating individual flip-flops, implement the 8-bit register as a single always block
2. Use vector operations to handle all 8 bits simultaneously
3. Maintain asynchronous reset functionality but simplify the hierarchy
4. Parameterize the width to make the design more flexible and reusable
5. This approach reduces module hierarchy overhead while maintaining clear functionality
6. The single always block may allow for better synthesis optimization in some tools
