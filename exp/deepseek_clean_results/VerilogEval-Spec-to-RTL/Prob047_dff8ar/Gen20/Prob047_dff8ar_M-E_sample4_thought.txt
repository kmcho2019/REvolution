Novel architectural idea:
1. Instead of instantiating 8 separate DFFs, implement all 8 bits in a single always block
2. Use vector operations to handle all bits simultaneously
3. Maintain the same functionality as individual DFFs (positive edge triggered, async reset)
4. Benefits:
   - More compact code
   - Potential for better synthesis optimization as one unified block
   - Easier to modify bit width (just change the vector size)
   - Clearer representation of the parallel nature of the operation
5. Tradeoffs:
   - Less modular than individual DFFs
   - Harder to isolate individual bits for debugging
   - Still synthesizes to same basic DFF cells, but with cleaner RTL
