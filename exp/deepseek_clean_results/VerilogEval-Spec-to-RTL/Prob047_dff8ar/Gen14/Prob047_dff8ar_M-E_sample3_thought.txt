Here's an innovative approach using a parameterized generate block:
1. Instead of manually instantiating each DFF, we'll use a generate loop to create all 8 flip-flops
2. This makes the code more scalable and maintainable - can easily change the bus width by modifying a parameter
3. We'll use a localparam to define the width, making it easy to modify if needed
4. The generate block creates individual always blocks for each bit, which may help with synthesis optimization
5. This approach reduces code duplication while maintaining the same functionality
