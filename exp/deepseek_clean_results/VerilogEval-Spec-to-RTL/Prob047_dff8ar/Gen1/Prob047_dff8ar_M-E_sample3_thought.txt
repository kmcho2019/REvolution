Instead of using a single always block with a vector register, we can implement the 8-bit register using individual D flip-flop instantiations. This approach:
1. Explicitly instantiates 8 DFF primitives (FDRE from Xilinx library)
2. Each DFF has its own input/output connection
3. Shares common clock and reset signals
4. Provides better visibility and control at the individual flip-flop level
5. May offer better optimization opportunities for synthesis tools
6. Makes the design more modular and explicit
