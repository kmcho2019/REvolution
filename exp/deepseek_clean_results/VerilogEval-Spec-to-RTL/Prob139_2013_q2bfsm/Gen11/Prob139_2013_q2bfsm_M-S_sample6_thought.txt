Here's a simplified approach that maintains all required functionality:

1. **State Reduction**: Combine permanent states (E and F) into one state (D) with a registered g_perm signal that locks the output.

2. **Simpler Sequence Detection**: Use a 2-bit shift register for x inputs instead of separate registers, making the 1-0-1 pattern detection clearer.

3. **Direct Timeout Handling**: Instead of a separate counter, use the state itself to track the 2-cycle timeout in state D.

4. **Output Logic**: Make outputs purely combinational based on current state and registered signals.

Key simplifications:
- Fewer states (4 instead of 6)
- No separate timeout counter
- Clearer sequence detection
- Same functionality with less code
