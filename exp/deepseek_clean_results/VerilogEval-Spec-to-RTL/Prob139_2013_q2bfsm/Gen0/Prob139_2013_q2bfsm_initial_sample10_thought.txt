To implement this FSM, we'll need:
1. A state machine with states: A (initial), B (after reset), C (waiting for 101 pattern), D (g=1, waiting for y=1 in 2 cycles), E (g=1 permanently), and F (g=0 permanently)
2. A 3-bit shift register to detect the 101 pattern on x
3. Counters to track the 2-cycle window after g=1
4. Output logic for f and g based on current state

The state transitions will be:
- A→B on resetn=1 (output f=1 for one cycle)
- B→C after one cycle (f returns to 0)
- C→D when 101 pattern is detected (g=1)
- D→E if y=1 within 2 cycles (g stays 1 permanently)
- D→F if y≠1 after 2 cycles (g=0 permanently)
- All states return to A on resetn=0
