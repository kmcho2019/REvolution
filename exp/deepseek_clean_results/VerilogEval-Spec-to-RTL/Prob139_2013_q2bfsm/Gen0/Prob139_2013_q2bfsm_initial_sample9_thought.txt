To implement this FSM, we'll need to:
1. Define states (A, F_ON, MONITOR_X, G_ON, CHECK_Y)
2. Use sequential logic for state transitions
3. Use combinational logic for outputs
4. Implement pattern detection for x (1,0,1 sequence)
5. Implement timeout counter for y detection (2 cycles)

State transitions:
- A: Initial state, waits for resetn deassertion
- F_ON: Activates f=1 for one cycle after reset
- MONITOR_X: Looks for 1,0,1 pattern on x
- G_ON: Activates g=1 and starts y monitoring
- CHECK_Y: Checks y within 2 cycles, then locks g permanently
