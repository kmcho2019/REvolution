Here's a simplified approach that maintains all functionality:

1. **State Machine**: Use just 3 states (IDLE, MONITOR, FINAL) since we can handle the f pulse directly in the transition from IDLE
2. **Pattern Detection**: 
   - Use a 3-bit shift register to track last 3 x values
   - Detect '101' pattern when shift register matches this value
3. **Timeout Logic**: 
   - Use a 2-bit counter to track cycles after pattern detection
   - Set g permanently based on whether y=1 occurs within 2 cycles
4. **Output Logic**:
   - f is combinatorial for one-cycle pulse after reset
   - g is set when pattern is detected and maintained based on y condition

Key simplifications:
- Fewer states (3 vs 4)
- Clear pattern detection with shift register
- Proper timeout counting (2 cycles)
- Simpler output logic
- Maintains all required functionality
