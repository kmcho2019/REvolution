   - ACTIVE: Handle both pattern matching and y monitoring

3. **Timeout Handling**: Instead of a counter, use a 2-bit flag to track the two-cycle timeout for y.

4. **Output Logic**: Simplify output generation by:
   - f is high only in the cycle after reset
   - g is set when pattern is matched and remains based on y condition
