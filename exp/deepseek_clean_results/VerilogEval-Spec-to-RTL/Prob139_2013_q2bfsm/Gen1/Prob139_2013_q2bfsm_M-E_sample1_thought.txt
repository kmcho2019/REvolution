Here's a novel approach using a combination of a state machine and pattern matching counters:

1. Instead of using a traditional state machine with many states, we'll use a minimal state machine with just 3 states: IDLE, PATTERN_MATCH, and DECISION.
2. We'll use dedicated counters to track:
   - A one-shot counter for the initial f=1 pulse
   - A 3-bit shift register for the 101 pattern detection
   - A 2-bit timeout counter for the y input monitoring
3. Outputs will be generated combinatorially based on state and counter values
4. The design will be more compact and potentially more efficient by separating the timing and pattern matching logic from the state transitions

Key differences from the previous solution:
- Fewer states (3 vs 6)
- More emphasis on counters and shift registers
- Combinatorial output generation
- Clear separation of timing and decision logic
