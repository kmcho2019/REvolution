Here's a simplified approach that clearly separates the FSM states and reduces complexity:

1. **Clear State Definition**:
   - A: Initial/reset state
   - B: f pulse state (one cycle)
   - C: Monitoring for '101' pattern
   - D: Monitoring y input (2-cycle window)
   - E: g permanently 1
   - F: g permanently 0

2. **Pattern Detection**:
   - Simple 3-bit shift register tracks last 3 x values
   - Direct comparison checks for '101' pattern

3. **Timeout Handling**:
   - Single cycle counter for the 2-cycle y monitoring window
   - Clear transitions to permanent states

4. **Output Control**:
   - f is purely combinatorial based on state
   - g uses registered output with clear conditions

Key simplifications:
- Eliminated hybrid register/state approach
- Clear, separate states for each phase
- Simple pattern detection with shift register
- Minimal control logic for outputs
