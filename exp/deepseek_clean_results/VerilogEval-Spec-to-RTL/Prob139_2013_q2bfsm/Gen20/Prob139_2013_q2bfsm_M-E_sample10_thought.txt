1. **Two-Phase State Machine**:
   - Phase 1: Pattern detection (101 sequence) using a shift register
   - Phase 2: Timeout monitoring with cycle counting

2. **Smart Pattern Matching**:
   - Use a 3-bit shift register for x inputs with edge detection
   - Only advance pattern matching when valid transitions occur

3. **Precise Timeout Control**:
   - Implement a 2-cycle timeout counter for y monitoring
   - Clear counter when y=1 is detected within timeout period

4. **Output Control**:
   - f is pulsed high exactly one cycle after reset deassertion
   - g behavior is precisely controlled by timeout logic
   - Permanent output states are explicitly maintained

5. **State Encoding**:
   - Minimal states (only 3 needed) with clear transitions
   - Separate control for each operational phase
