This solution implements a novel two-phase architecture:

1. **Pattern Detector Phase**:
   - Uses a 3-stage shift register to detect the "101" sequence
   - Outputs a pulse when pattern is found
   - Resets detection if interrupted

2. **Timeout Controller Phase**:
   - Starts when pattern is detected
   - Implements a 2-cycle timeout window
   - Uses a simple state machine to track y observation
   - Locks the final output based on y detection

Key innovations:
- Separates pattern detection from response logic
- Uses explicit enable signals between components
- Implements timeout with a simple counter
- Clear state transitions for each phase
- Minimal states while maintaining all functionality
