Improved Design Strategy:

1. **State Machine Optimization**: Simplify to 4 states with clear transitions:
   - RESET: Initial state (active during reset)
   - PULSE_F: Generates single-cycle f pulse
   - MONITOR_X: Watches for 1-0-1 pattern on x
   - MONITOR_Y: Handles y input with timeout

2. **Pattern Detection**: Use efficient 3-bit shift register for x pattern matching (101)

3. **Timeout Handling**: Implement clean 2-cycle timeout counter with automatic reset

4. **Output Control**: 
   - f is purely combinational based on state
   - g uses registered output with permanent latch
   - Clear separation of sequential and combinational logic

Key Improvements:
- Simplified state transitions
- More efficient pattern detection
- Clear timeout mechanism
- Proper handling of permanent g output
- Better reset behavior
