To simplify the solution while maintaining functionality, I'll:

1. Use only 4 states (A, B, C, D) to cover all required behaviors
2. Eliminate the y_timeout register by using state transitions to track the 2-cycle timeout
3. Make outputs directly dependent on state
4. Use a simple 3-bit shift register for x pattern detection (101)
5. Add a permanent state (D) that holds g's final value until reset

Key states:
- A: Reset state (f=0, g=0)
- B: f pulse state (f=1, g=0) for one cycle
- C: Monitoring x for 101 pattern (f=0, g=0)
- D: Final state (f=0, g=permanent value)

The pattern detection uses a shift register, and y monitoring is done with state transitions in state D.
