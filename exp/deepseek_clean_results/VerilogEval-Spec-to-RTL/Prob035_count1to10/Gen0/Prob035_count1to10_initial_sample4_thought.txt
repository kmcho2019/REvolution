To implement a decade counter that counts from 1 to 10, we'll use a 4-bit register to store the current count value. The counter will increment on each positive clock edge, wrapping around to 1 after reaching 10. A synchronous reset will force the counter back to 1. The key points are:
1. Use a 4-bit register to store the count
2. Increment count on each clock edge, unless it's 10 (then reset to 1)
3. Handle synchronous reset to set count to 1
4. Output the current count value
