To implement a decade counter that counts from 1 to 10, we'll use a 4-bit register to store the current count value. The counter will increment on each positive clock edge, wrapping around to 1 after reaching 10. A synchronous reset will force the counter to 1. The key points are:
1. Use a 4-bit register (count) to store the current value
2. On each clock edge:
   - If reset is high, set count to 1
   - Else if count is 10, set count to 1
   - Else increment count by 1
3. Output the count value
