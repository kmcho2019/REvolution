To implement a decade counter that counts from 1 to 10, we'll need a 4-bit register to store the current count value. The counter should increment on each positive clock edge, wrapping around to 1 after reaching 10. A synchronous reset should initialize the counter to 1. The key steps are:
1. Create a 4-bit register for the counter
2. Implement increment logic that wraps around from 10 to 1
3. Handle synchronous reset condition
4. Output the current count value
