To implement a decade counter that counts from 1 to 10, we'll use a 4-bit register to store the current count value. The counter will increment on each positive clock edge, wrapping around from 10 back to 1. A synchronous reset will force the counter to 1 when active. The key points are:
1. Use a 4-bit register for the counter state
2. Increment the counter each clock cycle
3. Handle wrap-around from 10 (1010) to 1 (0001)
4. Implement synchronous reset to 1
5. Output the current count value
