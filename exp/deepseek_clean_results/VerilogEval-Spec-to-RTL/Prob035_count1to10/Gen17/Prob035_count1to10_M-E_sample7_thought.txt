Novel Approach: State Machine with Explicit Encoding
1. Instead of a simple counter, implement as a state machine with 10 distinct states
2. Use one-hot encoding for states to potentially improve timing (each state change only flips 2 bits)
3. Implement a dedicated state transition logic that cycles through states 1-10
4. Include a synchronous reset that maps to the initial state (1)
5. Use a separate combinational block to convert state to output
6. Benefits:
   - More explicit state representation
   - Potential timing benefits from one-hot encoding
   - Easier to modify if counting sequence needs to change
   - Clear separation between state management and output
