Refactoring Approach:
1. Use continuous assignments for both combinational logic and output
2. Eliminate the always block by using a wire with clock-to-q delay
3. Implement the counter using a single assign statement with ternary conditions
4. Maintain the same synchronous reset behavior using clock edge detection
5. Use a temporary register to hold the next state value
6. This creates a more compact implementation while preserving functionality

Key Changes:
- Entire logic implemented in continuous assignments
- Uses implicit clock-to-q delay through non-blocking assignment in assign
- Combines reset and increment logic in a single expression
