Simplification Strategy:
1. Direct Value Comparison:
   - Replace the bitwise terminal detection (q[3] & q[1]) with direct comparison to 4'b1010 (10 in decimal)
   - This makes the code more readable and maintainable while maintaining the same functionality

2. Single Always Block:
   - Keep the synchronous reset and counting logic in one always block for simplicity
   - No need for separate combinational logic blocks

3. Minimal Logic:
   - Use simple if-else structure
   - Direct assignment of next state based on current state
   - No intermediate signals or parameters needed

Key Benefits:
- More intuitive and readable code
- Maintains all functional requirements
- Still achieves good PPA metrics
- Easier to modify if counting range needs to change
