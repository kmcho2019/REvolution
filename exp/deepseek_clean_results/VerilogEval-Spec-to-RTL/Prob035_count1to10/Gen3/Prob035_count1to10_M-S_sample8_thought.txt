Simplification Strategy:
1. Direct Value Comparison:
   - Instead of bitwise operation (q[3] & q[1]), use direct value comparison (q == 10) for clarity
   - Modern synthesis tools will optimize this efficiently

2. Minimal Control Flow:
   - Use simple if-else structure with clear priority:
     1. Reset condition first
     2. Wrap condition next
     3. Default increment

3. Reduced Logic:
   - Eliminate any intermediate signals
   - Single always block for all sequential logic

Key Benefits:
- More readable and maintainable code
- Clear intent (direct comparison with 10)
- Maintains same functionality (counts 1-10, synchronous reset)
- Still efficient for synthesis
