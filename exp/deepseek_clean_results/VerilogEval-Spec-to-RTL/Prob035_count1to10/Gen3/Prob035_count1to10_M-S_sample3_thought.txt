To simplify the decade counter implementation:
1. Use a 4-bit register to store the count value
2. Implement synchronous reset to 1 (4'b0001)
3. For normal operation, increment until 10 (4'b1010) then wrap around to 1
4. Instead of using a comparator (q == 4'd10), we can use the fact that after 10, the next value should be 1
5. This maintains the same functionality with simpler logic since we don't need a full 4-bit comparator
