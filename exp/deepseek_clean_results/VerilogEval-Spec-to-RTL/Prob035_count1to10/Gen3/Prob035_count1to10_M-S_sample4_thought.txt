To simplify the decade counter implementation while maintaining functionality:
1. Use a single always block for both sequential logic and reset handling
2. Eliminate the separate combinational logic for next state calculation
3. Directly implement the counting logic within the always block
4. Keep synchronous reset that sets counter to 1
5. Implement wrap-around from 10 back to 1

This approach reduces the design to its essential components while maintaining the same behavior. The simplification comes from:
- Removing the intermediate wire and assign statement
- Combining all logic into one always block
- Using straightforward conditional statements
