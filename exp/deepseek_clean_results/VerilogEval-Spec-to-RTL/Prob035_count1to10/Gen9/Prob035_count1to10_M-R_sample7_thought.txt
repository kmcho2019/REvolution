Refactoring Approach:
1. Separate the combinational next-state logic from the sequential state storage
2. Use an assign statement for the combinational logic to calculate next_q
3. Keep the sequential part simple with just the clocked register update
4. Maintain the same optimized terminal condition (q[3] & q[1]) for detecting count=10
5. Use continuous assignment for cleaner combinational logic
6. Keep synchronous reset functionality identical

Benefits:
- Clear separation of combinational and sequential logic
- Easier to modify the count logic independently
- Potentially better for synthesis as combinational and sequential parts are distinct
- Maintains all original optimizations while improving code structure
