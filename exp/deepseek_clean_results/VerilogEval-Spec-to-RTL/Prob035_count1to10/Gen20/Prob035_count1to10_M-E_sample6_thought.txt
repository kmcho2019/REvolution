Novel Approach: State Machine with One-Hot Encoding
1. Use one-hot encoding for states 1-10 (10 states) for potentially better timing
2. Implement as a circular shift register with controlled rotation
3. Reset initializes to state 1 (0000000001)
4. Each clock cycle rotates left by 1 position, with special handling for state 10 (1000000000) to wrap back to state 1
5. Output q encodes the position of the '1' in the shift register

Advantages:
- One-hot encoding eliminates binary decoding logic
- Simple shift operation for state transitions
- Output encoding is straightforward position mapping
- Potentially better timing due to simpler state transitions
