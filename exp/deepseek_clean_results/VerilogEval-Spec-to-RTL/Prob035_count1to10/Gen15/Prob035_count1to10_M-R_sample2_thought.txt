Refactoring approach:
1. Use a single always block for both combinational and sequential logic to reduce overhead
2. Directly compute the next state within the sequential block
3. Maintain the same synchronous reset behavior and counting sequence
4. Simplify the wrap-around condition by checking for exact value (4'b1010)
5. This approach reduces the need for intermediate wires and combines logic more efficiently

Key benefits:
- Fewer lines of code while maintaining same functionality
- Eliminates the need for separate combinational logic block
- More direct expression of the state transition logic
- Still maintains clear synchronous reset behavior
