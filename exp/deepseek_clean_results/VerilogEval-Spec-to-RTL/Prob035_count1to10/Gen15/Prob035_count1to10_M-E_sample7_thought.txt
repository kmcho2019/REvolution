Novel Architecture Idea: State Encoding Optimization
1. Instead of using binary counting, implement a one-hot encoded state machine for the counter
2. Use 10 distinct states (1-10) with one-hot encoding (10 bits)
3. Benefits:
   - Simplified terminal condition detection (just check state 10)
   - Faster state transitions (single bit change between states)
   - Lower power for adjacent state transitions
   - More efficient wrap-around logic
4. Trade-offs:
   - Slightly larger area due to wider state register
   - Simple decode logic for output (priority encoder)
5. Reset initializes to state 1 (0000000001)
6. State transitions follow a circular shift pattern
