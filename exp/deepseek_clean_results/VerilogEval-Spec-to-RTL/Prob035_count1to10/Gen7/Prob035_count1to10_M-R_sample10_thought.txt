Refactoring the decade counter using continuous assignment and combinational logic:
1. Maintain the same functionality (count 1-10 with synchronous reset)
2. Replace the always block with:
   - A register (flip-flop) instantiation for the counter state
   - Continuous assignment for the next state logic
3. The next state logic will:
   - Reset to 1 when reset is high
   - Increment by 1 when counting normally
   - Wrap to 1 when reaching 10 (detected by q[3] && q[1])
4. This approach separates the sequential and combinational logic explicitly
5. The functionality remains identical but demonstrates an alternative coding style
