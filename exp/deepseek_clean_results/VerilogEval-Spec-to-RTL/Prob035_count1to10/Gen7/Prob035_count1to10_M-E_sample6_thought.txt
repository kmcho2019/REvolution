Novel Approach: State Machine with Precomputed Next States
1. Instead of using a traditional counter with increment logic, implement a state machine that directly transitions between the required values (1-10)
2. Store all possible states (1-10) in a case statement for explicit state transitions
3. Use synchronous reset to initialize to state 1 (4'b0001)
4. On each clock edge, transition to the next state in sequence, wrapping around from 10 back to 1
5. This approach eliminates arithmetic logic and replaces it with direct state transitions, which may offer better timing in some implementations

Advantages:
- No arithmetic operations (no adders needed)
- Clear, explicit state transitions
- Easily modifiable for non-sequential patterns if requirements change
- Potential for better timing as each transition is direct rather than computed
