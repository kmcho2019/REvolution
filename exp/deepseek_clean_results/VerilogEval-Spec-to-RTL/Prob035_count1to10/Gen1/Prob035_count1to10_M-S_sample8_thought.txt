To simplify the decade counter implementation while maintaining functionality:
1. Remove the explicit comparison with 10 (4'b1010) by using modulo arithmetic
2. Use a simpler wrap-around condition: when count reaches 11 (4'b1011), reset to 1
3. This eliminates the need for a full 4-bit comparator, reducing logic complexity
4. Maintain synchronous reset functionality
5. The counter will naturally count 1-10 because:
   - After 10 (1010), next is 11 (1011) which triggers reset to 1
   - This reduces comparison logic to just checking the 4th bit (8) and 2nd bit (2)
