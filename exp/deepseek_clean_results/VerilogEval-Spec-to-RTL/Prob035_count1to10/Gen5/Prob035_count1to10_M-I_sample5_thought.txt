To optimize the decade counter for better PPA metrics, I'll implement the following improvements:

1. **Area Reduction**:
   - Replace one-hot encoding with 4-bit binary counter (reduces flip-flops from 10 to 4)
   - Eliminate the output conversion logic by directly using the counter value

2. **Power Optimization**:
   - Binary encoding reduces switching activity compared to one-hot
   - Simplified logic reduces unnecessary toggling

3. **Timing Improvement**:
   - Smaller state register (4 bits vs 10 bits) reduces routing complexity
   - Direct output connection eliminates combinational logic delay

The design will:
- Use a 4-bit binary counter that counts from 1 to 10
- Reset to 1 synchronously
- Output the counter value directly
- Wrap around from 10 back to 1 automatically
