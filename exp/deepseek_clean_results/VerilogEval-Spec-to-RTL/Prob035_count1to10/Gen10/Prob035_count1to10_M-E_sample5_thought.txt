Novel Approach: State Machine with One-Hot Encoding
1. Use a one-hot encoded state machine for the decade counter (10 states)
2. Each state represents a count value from 1 to 10
3. Implement synchronous reset that sets the counter to state 1
4. Transition between states on each clock edge
5. Use a decoder to convert the one-hot state to 4-bit binary output
6. Advantages:
   - Simple state transitions (just shift left with wrap-around)
   - Fast comparison for wrap-around (just check MSB)
   - Potential for lower power in some technologies due to reduced switching
   - Clear state representation in hardware
