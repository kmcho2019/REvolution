Instead of using a binary counter, we can implement the decade counter as a one-hot encoded state machine. This approach:
1. Uses 10 flip-flops (one for each count value)
2. Each state represents one count value (1-10)
3. State transitions occur in sequence
4. Advantages:
   - Simple state transition logic (just shift left with wrap-around)
   - No comparators needed for wrap-around detection
   - Constant-time state transitions regardless of count value
5. Reset initializes to the first state (count=1)
6. Output encoding converts one-hot to binary
