To simplify the decade counter implementation while maintaining functionality:
1. Remove the separate next_q wire and combine the logic directly in the always block
2. Keep the synchronous reset that sets q to 1
3. Use simple if-else conditions for the counting logic:
   - If reset is active, set to 1
   - If count reaches 10, wrap around to 1
   - Otherwise, increment by 1
4. This reduces the number of assignments and eliminates the intermediate wire
5. The functionality remains identical but with fewer lines of code and simpler structure
