Novel Approach: State Machine with One-Hot Encoding
1. One-Hot Encoding Benefits:
   - Uses 10 flip-flops to represent states 1-10 directly
   - Eliminates combinational logic for state decoding
   - Each state is represented by a single bit, making state transitions simple

2. Efficient State Transitions:
   - Next state is simply a left shift of current state
   - Wrap-around handled by detecting the 10th state (bit position) and resetting to 1st state
   - No arithmetic operations needed

3. Reset Handling:
   - Synchronous reset directly sets the first state bit
   - No need for value comparison during reset

Key Advantages:
- Faster timing (no arithmetic or comparison in critical path)
- Simpler state transition logic
- Easily scalable to larger counters
- Clear relationship between state bits and counter values
