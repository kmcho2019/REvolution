To simplify the decade counter while maintaining functionality:
1. Remove the explicit comparison for 10 (1010) since we can rely on natural overflow behavior
2. Use a simple increment with conditional reset when count reaches 11 (1011)
3. This eliminates the need for any bitwise comparisons while still correctly counting 1-10
4. The reset condition remains the same (synchronous reset to 1)
5. This approach uses fewer logic gates and simplifies the control flow
