Refactoring Strategy:
1. Structural Change:
   - Replace the always block with continuous assignments using ternary operators
   - Move the counter logic to a combinational block and register separately
   - This separates the combinational and sequential logic clearly

2. Optimization:
   - Keep the efficient wrap-around detection (q[3] & ~q[2] & q[1])
   - Simplify the enable logic by incorporating it directly into the next state calculation
   - Maintain synchronous reset functionality

Key Benefits:
- Clear separation of combinational and sequential logic
- More explicit data flow
- Maintains same performance characteristics while being more modular
- Easier to modify individual components (counter logic vs. state storage)
