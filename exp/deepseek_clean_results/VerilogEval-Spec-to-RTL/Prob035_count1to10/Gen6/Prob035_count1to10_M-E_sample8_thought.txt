Novel Approach: State Machine with One-Hot Encoding
1. Instead of a binary counter, implement a one-hot encoded state machine for the decade counter
2. Each state (1-10) is represented by a single bit in a 10-bit register
3. State transitions are simple shift operations with wrap-around
4. Reset initializes to state 1 (0000000001)
5. Output encoding converts one-hot state to binary (4-bit)
6. Advantages:
   - Simple state transition logic (just shifting)
   - Glitch-free outputs during state transitions
   - Easy to decode individual states
   - Potentially better timing for certain applications
