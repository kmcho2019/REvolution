Novel Approach: State Machine with Explicit State Encoding
1. Instead of a simple counter, implement a finite state machine with 10 distinct states
2. Use one-hot encoding for states to potentially improve timing and simplify state transitions
3. Each state directly represents a count value (1-10)
4. Implement synchronous reset that transitions to state 1
5. State transitions are simple shifts in the one-hot encoding
6. Output is generated by priority encoding the one-hot state to binary

Advantages:
- One-hot encoding may improve timing in some synthesis tools
- Explicit state representation makes behavior very clear
- Easy to modify for non-sequential counting patterns if needed
- Reset logic becomes very simple (just set first state)
