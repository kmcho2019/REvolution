I'll implement a decade counter using a state machine approach with one-hot encoding. This method offers several advantages:
1. One-hot encoding simplifies state transitions (only one bit changes at a time)
2. The wrap-around logic becomes trivial - just transition from state 10 to state 1
3. Reset condition is easily implemented by setting the first state
4. The output can be directly derived from the state encoding
5. This approach may offer better timing characteristics since each state transition is simple

The state machine will have 10 states (1-10), each represented by a unique bit in a 10-bit register. The output will be a binary encoding of the current state.
