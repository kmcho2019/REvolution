Novel approach using a shift register with feedback:
1. Instead of a conventional binary counter, implement a circular shift register that cycles through values 1-10
2. Use a 10-bit shift register where only one bit is high at any time (one-hot encoding)
3. The 'hot' bit position represents the current count value (bit 0 = 1, bit 1 = 2, etc.)
4. Special handling for the 10th position (bit 9) to wrap around to bit 0 (value 1)
5. Synchronous reset initializes to bit 0 (value 1)
6. Output encoding converts the one-hot representation to 4-bit binary

Advantages:
- Eliminates adder logic, potentially improving timing
- One-hot encoding simplifies wrap-around logic
- Power-efficient since only one bit toggles per cycle
- Reset logic becomes trivial (single bit set)
- Output encoding can be optimized as a simple priority encoder
