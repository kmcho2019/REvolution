Novel architectural idea:
1. Implement the decade counter using a circular shift register with feedback
2. Use a 10-bit shift register where only one bit is '1' at any time (one-hot encoding)
3. The '1' circulates through the register to represent counts 1-10
4. Reset initializes the first bit to '1' (count=1)
5. Feedback logic detects when the '1' reaches the 10th position and wraps around
6. Output encoder converts the one-hot state to 4-bit binary count

Advantages:
- Simple sequential logic (just shifting)
- Glitch-free outputs since only one bit changes at a time
- Power efficient due to minimal switching activity
- Easy to extend to other counter ranges
- Clear physical meaning of each state
