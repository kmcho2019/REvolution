Refactoring Approach:
1. Structural Change:
   - Replace the always block with continuous assignments using combinational logic
   - Use a ternary operator chain to implement the priority logic (reset > wrap > increment)

2. Optimization Benefits:
   - Eliminates the always block overhead
   - Makes the control flow more explicit in the code
   - Potentially reduces synthesis overhead by using pure combinational logic

3. Functional Preservation:
   - Maintains identical behavior (counts 1-10, synchronous reset)
   - Same efficient terminal count detection (q[3] & q[1])
   - Still uses non-blocking assignments for proper synchronous behavior

Key Differences:
- All logic is now in continuous assignments
- Next state calculation is explicit before the register
- Reset and wrap conditions are clearly prioritized in the assignment chain
