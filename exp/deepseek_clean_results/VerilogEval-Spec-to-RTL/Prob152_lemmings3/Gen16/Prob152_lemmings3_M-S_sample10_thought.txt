To simplify the Lemming state machine further while maintaining all functionality:
1. Reduce to just 2 states (WALK and FALL) since DIG can be handled within WALK state
2. Track direction with a single bit (0=left, 1=right)
3. Use a separate register to track digging status
4. Implement priority handling:
   - Fall has highest priority (ground=0)
   - Dig has middle priority (when ground=1 and not falling)
   - Bumps have lowest priority (only when walking on ground)
5. Simplify output logic by making it purely combinatorial
6. Use asynchronous reset for initialization
7. Remove redundant state transitions by combining DIG into WALK state
