1. Hierarchical State Design:
   - Split into two layers: Movement State (WALK/FALL/DIG) and Direction State (LEFT/RIGHT)
   - This separates concerns and simplifies transition logic

2. Explicit Priority Encoder:
   - Use a dedicated always block to compute next state based on explicit priority
   - Fall > Dig > Bump with clear precedence

3. Direction Persistence:
   - Maintain direction separately and only update when relevant
   - Preserve direction during falls and digs

4. Output Generation:
   - Generate outputs based on current movement state and direction
   - Use simple combinational logic for clarity

5. Edge Case Handling:
   - Explicitly handle all special cases in priority order
   - Ensure clean state transitions on all conditions
