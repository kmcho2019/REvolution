My novel approach uses:
1. Hierarchical state machine with two levels:
   - Top level: Movement state (WALKING, FALLING, DIGGING)
   - Sub level: Direction state (LEFT, RIGHT)

2. Edge detection for ground transitions:
   - Detects falling edge of ground to trigger FALLING state
   - Detects rising edge of ground to exit FALLING state

3. Optimized bump handling:
   - Only processes bumps in WALKING state
   - Uses priority encoder for simultaneous bumps

4. Power-saving features:
   - State-dependent clock gating for direction register
   - Minimal state transitions

Key innovations:
- Separate movement and direction concerns
- Edge-based ground detection for precise timing
- Reduced switching activity through conditional updates
- Clear separation of concerns in state hierarchy
