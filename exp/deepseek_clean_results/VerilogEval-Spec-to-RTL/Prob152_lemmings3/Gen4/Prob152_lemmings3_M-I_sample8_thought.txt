To optimize the Lemmings state machine for better PPA metrics, I'll implement these improvements:

1. State Encoding Optimization:
   - Use a 2-bit state register instead of three separate registers
   - 00: Walking left
   - 01: Walking right  
   - 10: Falling
   - 11: Digging

2. Transition Logic Optimization:
   - Parallelize condition checks to reduce critical path
   - Use priority encoder for fall > dig > bump handling
   - Simplify simultaneous bump handling

3. Output Logic Optimization:
   - Derive outputs directly from state bits
   - Minimize logic gates by sharing common terms

Key benefits:
- Reduced area from fewer registers and simpler logic
- Lower power from reduced switching activity
- Better timing from parallel evaluation and shorter critical path
