This solution introduces a hierarchical state machine architecture:
1. Main states (WALK, FALL, DIG) handle the primary behaviors
2. Sub-states (LEFT, RIGHT) within WALK state manage direction
3. Direction changes are isolated to WALK state only
4. Priority logic is implemented through state hierarchy:
   - FALL has highest priority (checked first)
   - DIG only considered in WALK state
   - Direction changes only when in WALK state and no higher priority
5. Outputs are directly derived from state encoding for minimal logic
6. Uses one-hot encoding for faster decoding and simpler transitions
