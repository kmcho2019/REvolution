Here's a novel approach using a hierarchical state machine with direction tracking:

1. Use a two-level state hierarchy: primary states (WALK, FALL, DIG) and secondary direction states (LEFT, RIGHT)
2. Implement direction as a separate state rather than a register
3. Use a priority encoder for input handling (fall > dig > bump)
4. Combine state and direction into a single 3-bit state register for compact encoding
5. Use parallel state transition logic for better timing
6. Implement outputs as direct decodes of the current state

This approach reduces register count by combining state and direction, simplifies transitions through explicit encoding, and improves timing by making state transitions more parallel.
