2. Priority Handling: Implement strict priority (fall > dig > bump) using nested if-else in the WALK state, but evaluate conditions in parallel where possible to reduce critical path.

3. Output Logic: Use registered outputs to reduce glitching power while maintaining Moore machine properties. Outputs are purely state/direction dependent.

4. Transition Logic: Optimize by:
   - Only evaluating direction changes in WALK state
   - Using state-specific conditions to minimize unnecessary logic evaluation
   - Combining state and direction updates in single always block
