To simplify the solution while maintaining functionality, we can:
1. Remove the separate direction register and encode direction directly in the state
2. Use only 4 states: WALK_LEFT, WALK_RIGHT, FALL, DIG
3. This eliminates the need for direction tracking logic and reduces state transitions
4. Maintain the same priority order: fall > dig > bump
5. Outputs become direct state decodes

This reduces the state machine complexity by removing the direction register and associated logic while keeping all functionality intact. The state transitions become more straightforward with direction embedded in the walking states.
