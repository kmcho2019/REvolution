Refactoring approach:
1. Convert the state machine to use one-hot encoding for better timing and power characteristics
2. Separate the direction logic into its own always block to potentially improve timing
3. Use continuous assignments for state transitions to make the priority logic more explicit
4. Keep outputs combinatorial but express them directly from state bits
5. Maintain the same functionality and priority order (fall > dig > bump)

Key changes:
- One-hot states (3 bits) instead of binary encoded
- Direction logic separated from state transitions
- Transition logic expressed as continuous assignments
- Same Moore machine outputs based purely on state
