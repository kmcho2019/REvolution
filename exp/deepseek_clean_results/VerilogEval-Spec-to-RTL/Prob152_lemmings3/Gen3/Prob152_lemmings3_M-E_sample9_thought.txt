Novel Architecture Idea: "Direction-Preserving State Machine with Event Queue"

Key Concepts:
1. Direction Preservation: Instead of tracking direction separately, encode it directly in the state (4 states: WALK_LEFT, WALK_RIGHT, FALL, DIG)
2. Event Queue: Use a 2-bit register to remember bump events that occur during non-walking states
3. Priority Resolution: Implement priority through state transition ordering rather than nested conditionals
4. State Compression: Use Gray coding for state transitions to minimize glitches

Advantages:
- Eliminates separate direction register
- Handles bump events during non-walking states gracefully
- More efficient output logic (direct state decoding)
- Reduced combinatorial logic complexity
