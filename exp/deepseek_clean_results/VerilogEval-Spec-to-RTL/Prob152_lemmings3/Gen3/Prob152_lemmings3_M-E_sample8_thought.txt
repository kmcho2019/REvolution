Here's a novel approach using a hierarchical state machine with separate direction tracking:

1. Main State Machine: Tracks the primary actions (walking, falling, digging) with explicit states.
2. Direction Sub-State: Uses a separate register to track walking direction independently.
3. Priority Encoder: Implements input priority (fall > dig > bump) in a dedicated combinational block.
4. Edge Detection: Uses edge detection on ground signal to precisely handle falling transitions.
5. Output Gating: Outputs are gated based on both state and direction to ensure correct behavior.

Key innovations:
- Separates action state from direction state for cleaner transitions
- Uses explicit priority encoding before state transitions
- Implements edge detection for precise falling transitions
- Optimizes output logic with minimal gates
