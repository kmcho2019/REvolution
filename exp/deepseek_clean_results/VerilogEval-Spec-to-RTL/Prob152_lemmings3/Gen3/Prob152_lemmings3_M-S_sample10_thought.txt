To simplify the Lemming state machine, we can reduce the number of states by:
1. Combining left/right states into single states with a direction flag
2. Using only 4 states instead of 6:
   - WALK (with direction)
   - FALL (with direction)
   - DIG (with direction)
3. The direction can be tracked with a separate register
4. Priority handling remains: fall > dig > bump
5. Outputs are determined by current state and direction

This reduces state encoding bits and simplifies transition logic while maintaining all functionality.
