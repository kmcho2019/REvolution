To implement the Lemming behavior, we need a Moore state machine with multiple states and transitions. The key states are:
1. WALK_LEFT: Lemming walks left until bumped or ground disappears
2. WALK_RIGHT: Lemming walks right until bumped or ground disappears
3. FALL_LEFT: Lemming falls while previously walking left
4. FALL_RIGHT: Lemming falls while previously walking right
5. DIG_LEFT: Lemming digs while previously walking left
6. DIG_RIGHT: Lemming digs while previously walking right

The state transitions follow these rules:
- Falling has highest priority when ground=0
- Digging comes next when dig=1 and ground=1
- Bumping changes direction only if not falling or digging
- Resetting always returns to WALK_LEFT
- Falling continues until ground=1, then returns to previous walking state
- Digging continues until ground=0, then transitions to falling

The outputs are purely based on the current state.
