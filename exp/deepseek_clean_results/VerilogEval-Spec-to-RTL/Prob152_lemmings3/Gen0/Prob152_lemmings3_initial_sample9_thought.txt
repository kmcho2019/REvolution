To implement the Lemming's behavior, we need a Moore state machine with the following states:
1. WALK_LEFT: Walking left (default state after reset)
2. WALK_RIGHT: Walking right
3. FALL_LEFT: Falling while previously walking left
4. FALL_RIGHT: Falling while previously walking right
5. DIG_LEFT: Digging while previously walking left
6. DIG_RIGHT: Digging while previously walking right

The state transitions are as follows:
- From WALK_LEFT:
  - If ground=0: go to FALL_LEFT (highest priority)
  - Else if dig=1: go to DIG_LEFT
  - Else if bump_left=1: go to WALK_RIGHT
  - Else stay in WALK_LEFT

- From WALK_RIGHT:
  - If ground=0: go to FALL_RIGHT (highest priority)
  - Else if dig=1: go to DIG_RIGHT
  - Else if bump_right=1: go to WALK_LEFT
  - Else stay in WALK_RIGHT

- From FALL_LEFT/FALL_RIGHT:
  - If ground=1: return to previous walking state
  - Else stay in falling state

- From DIG_LEFT/DIG_RIGHT:
  - If ground=0: go to corresponding falling state
  - Else stay in digging state

Outputs are determined by the current state:
- walk_left: in WALK_LEFT or DIG_LEFT
- walk_right: in WALK_RIGHT or DIG_RIGHT
- aaah: in FALL_LEFT or FALL_RIGHT
- digging: in DIG_LEFT or DIG_RIGHT
