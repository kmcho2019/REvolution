Here's a simplified approach that maintains functionality while reducing complexity:

1. Combine state and direction into a single state register with 3 states (LEFT, RIGHT, FALL) plus digging status
2. Eliminate separate direction tracking by encoding direction in the state itself
3. Simplify priority logic by checking conditions in order (fall > dig > bump)
4. Remove edge detection since we can directly use ground signal in state transitions
5. Reduce output logic to simple state decoding

Key simplifications:
- Fewer state bits (3 states instead of 4)
- No separate direction register
- No edge detection logic
- Simpler output decoding
- Same behavior with less hardware
