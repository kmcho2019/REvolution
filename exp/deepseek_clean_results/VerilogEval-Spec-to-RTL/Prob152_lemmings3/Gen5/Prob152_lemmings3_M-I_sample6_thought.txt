To optimize the Lemming state machine for better PPA metrics, I'll implement these improvements:

1. State Encoding Optimization:
   - Use Gray coding for state transitions to minimize switching power
   - Combine direction with state to reduce register count
   - Eliminate unused state by using 2 bits for 3 states (00,01,11)

2. Critical Path Reduction:
   - Restructure conditions to evaluate fall/dig/bump in parallel
   - Pre-compute transition conditions to reduce logic depth

3. Power Optimization:
   - Register outputs to reduce glitching
   - Use state-specific enables for direction updates

4. Area Reduction:
   - Combine state and direction into single register
   - Share common logic between walk_left/walk_right outputs

The improved design will maintain the same functionality while achieving better timing, power, and area.
