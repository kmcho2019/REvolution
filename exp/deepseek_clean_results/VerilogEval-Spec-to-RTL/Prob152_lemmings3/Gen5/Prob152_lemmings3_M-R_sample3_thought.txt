Refactoring Strategy:
1. State Encoding: Use one-hot encoding for states (4 bits) to potentially simplify output logic and improve timing.
2. Direction Handling: Encode direction directly into walking states (WALK_LEFT and WALK_RIGHT) to eliminate separate direction register.
3. Transition Logic: Implement using continuous assignments (assign) for next_state logic where possible, reducing sequential blocks.
4. Output Logic: Simplify by making outputs direct functions of current state.
5. Priority Handling: Maintain strict priority (fall > dig > bump) but express as nested ternary operators in assign statements.

Key Changes:
- One-hot state encoding (4 states)
- Direction embedded in walking states
- More combinational logic using assign
- Same behavior but different implementation style
