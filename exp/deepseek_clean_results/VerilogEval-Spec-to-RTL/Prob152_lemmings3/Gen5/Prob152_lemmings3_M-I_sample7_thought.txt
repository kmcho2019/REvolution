To optimize the Lemmings state machine for better PPA metrics, I'll implement these improvements:

1. State Encoding Optimization:
   - Use a 2-bit state register instead of three separate registers
   - 00: WALK_LEFT
   - 01: WALK_RIGHT
   - 10: FALLING
   - 11: DIGGING

2. Transition Logic Optimization:
   - Parallel evaluation of all possible next states
   - Priority selection through a single multiplexer
   - Combine bump detection logic into a single expression

3. Output Logic Optimization:
   - Derive outputs directly from state bits
   - Share common terms between walk_left and walk_right

Key benefits:
- Reduced area by using compact state encoding
- Improved timing by simplifying transition logic
- Lower power by minimizing unnecessary state transitions
