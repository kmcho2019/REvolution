To simplify the Lemming state machine, we can:
1. Use a 2-bit state encoding to represent all possible states (walking left/right, falling, digging)
2. Eliminate separate direction tracking by incorporating it into the state encoding
3. Prioritize state transitions clearly: falling > digging > bump handling
4. Use simpler output logic that directly maps from state
5. Handle all transitions in a single always block with clear priority order

Key simplifications:
- Reduced state representation to 2 bits
- Combined direction and action into unified state
- Simplified output logic with direct state mapping
- Clear priority ordering in transition logic
