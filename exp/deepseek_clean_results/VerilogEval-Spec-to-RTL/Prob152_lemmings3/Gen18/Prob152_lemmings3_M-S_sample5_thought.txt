To simplify the Lemming state machine, we can:
1. Use only 3 states: LEFT, RIGHT, and FALLING
2. Track digging as a separate flag since it's mutually exclusive with falling
3. Handle state transitions with clear priority: falling > digging > bump
4. Use Moore outputs derived directly from state and flags
5. Simplify direction switching logic by combining bump conditions

Key improvements:
- Reduced state encoding (3 states instead of separate direction+status)
- Clearer transition priorities
- More straightforward output logic
- Fewer registers needed
