This solution implements a hierarchical FSM with two parallel state tracks:
1. Movement state (walking/falling/digging)
2. Direction state (left/right)

Key innovations:
- Separates movement and direction into independent state machines
- Uses a "next_direction" register to buffer direction changes during walking
- Implements priority handling through state hierarchy
- Uses minimal combinatorial logic for outputs
- Optimizes for power by only updating direction when needed

Benefits:
- Clear separation of concerns between movement and direction
- Reduced switching activity (direction only updates when walking)
- Simpler state transitions with explicit priority handling
- Easier to extend with additional behaviors
