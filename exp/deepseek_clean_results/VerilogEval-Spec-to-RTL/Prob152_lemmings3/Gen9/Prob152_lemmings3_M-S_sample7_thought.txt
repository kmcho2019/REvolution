To simplify the solution while maintaining functionality, we can:
1. Eliminate the separate direction register by encoding direction in the state itself
2. Reduce the state machine to 4 states: LEFT, RIGHT, FALLING, DIGGING
3. Handle direction changes directly in the LEFT/RIGHT states
4. Maintain the same priority order (fall > dig > bump)
5. Simplify output logic by directly mapping states to outputs

This approach reduces register usage by combining direction into the state encoding, while keeping the same behavior. The state transitions become more straightforward since direction is implicit in the state.
