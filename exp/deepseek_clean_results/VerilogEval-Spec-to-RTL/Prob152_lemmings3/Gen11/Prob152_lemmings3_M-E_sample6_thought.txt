New architectural approach:
1. Hierarchical state machine with two levels:
   - Top level: GROUNDED (walking/digging) vs FALLING
   - Sub-states for walking direction and digging
2. Edge detection for ground signal to precisely capture falling transitions
3. Direction tracking with explicit history to maintain direction after falls
4. Dedicated bump handling logic that only processes bumps when valid
5. Output encoding optimization to reduce logic gates
6. State encoding uses one-hot for faster transitions
7. Asynchronous reset initializes to walking left state

Key innovations:
- Hierarchical states reduce transition complexity
- Edge detection prevents glitches during ground transitions
- Explicit direction history simplifies state recovery
- One-hot encoding improves timing
- Separate bump handling logic reduces critical path
