To simplify the solution while maintaining functionality, we can:
1. Reduce the state encoding to just 3 states (WALK, FALL, DIG) without a separate direction bit
2. Combine direction into the state encoding (WALK_LEFT and WALK_RIGHT)
3. Use a single always block for state transitions
4. Simplify output logic by directly mapping states to outputs
5. Maintain the same priority order (fall > dig > bump)

This reduces the number of registers needed while keeping the same behavior.
