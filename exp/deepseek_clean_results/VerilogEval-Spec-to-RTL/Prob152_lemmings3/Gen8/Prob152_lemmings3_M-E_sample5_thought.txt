My novel approach uses a hierarchical state machine with these key innovations:
1. Direction tracking is embedded within the state encoding itself, eliminating the need for a separate direction register
2. State history is maintained to remember the pre-fall/dig state for proper recovery
3. Priority logic is implemented through nested if-else structure for optimal timing
4. Outputs are directly derived from state bits for minimal logic depth

The state encoding combines:
- Primary state (walk/fall/dig) in bits [1:0]
- Direction (left/right) in bit [2]
- Previous state history in bit [3] (for recovery after fall)

This approach reduces register count while maintaining clear state transitions and proper priority handling.
