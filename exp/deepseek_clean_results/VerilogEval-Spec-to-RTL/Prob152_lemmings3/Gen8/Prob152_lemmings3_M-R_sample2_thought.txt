To refactor the Lemming state machine, we'll:
1. Use one-hot encoding for states (3 bits) instead of binary encoding
2. Combine state and direction into a single register
3. Use continuous assignments for next-state logic instead of always blocks
4. Move output logic to continuous assignments
5. Maintain the same priority order: fall > dig > bump

Benefits:
- One-hot encoding simplifies state transitions (each bit changes independently)
- Combined state/direction register reduces register count
- Continuous assignments may lead to simpler synthesized logic
- Same functionality with potentially better timing
