This solution introduces a hierarchical state machine that separates movement direction from actions (walking/falling/digging). Key innovations:
1. Direction tracking is maintained separately from action states, reducing state transitions
2. Uses a "pending_direction" register to buffer direction changes during non-walking states
3. Implements priority handling through state hierarchy rather than nested if-else
4. Action states are mutually exclusive while direction persists across states
5. Optimized output logic using state and direction directly
