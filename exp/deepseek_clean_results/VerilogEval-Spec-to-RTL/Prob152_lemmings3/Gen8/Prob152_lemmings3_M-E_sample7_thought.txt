The key innovation is splitting the state machine into two parallel FSMs:
1. Direction FSM: Tracks left/right walking direction independently
2. Action FSM: Handles walking/falling/digging states

This separation provides:
- Clearer state transitions as direction and action are orthogonal concerns
- Reduced combinatorial complexity since each FSM has simpler logic
- Better timing as critical paths are split between the two FSMs
- More maintainable code with explicit separation of concerns

The direction FSM only updates when in WALKING state and bumped, while the action FSM handles all other transitions. This matches the problem's natural division of behavior.
