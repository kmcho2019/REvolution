To simplify the solution while maintaining functionality, we can:
1. Remove the separate direction register and encode direction directly in the state
2. Use only 4 states: WALK_LEFT, WALK_RIGHT, FALL, DIG
3. Eliminate the next_direction logic by handling direction changes in state transitions
4. Maintain the same priority order (fall > dig > bump)
5. Simplify output logic by directly mapping states to outputs
