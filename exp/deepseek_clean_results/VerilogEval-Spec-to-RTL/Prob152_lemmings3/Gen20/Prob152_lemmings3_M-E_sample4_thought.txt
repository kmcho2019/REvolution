Novel Architectural Idea:
1. State Encoding: Use a 3-bit one-hot encoding for states (WALK_LEFT, WALK_RIGHT, FALL, DIG_LEFT, DIG_RIGHT) to simplify state transitions and output logic
2. Direction Handling: Eliminate separate direction register by encoding direction directly in state
3. Priority Logic: Implement fall/dig/bump priorities using nested if-else in combinational next-state logic
4. Output Generation: Derive outputs directly from state bits for minimal logic
5. Reset: Maintain asynchronous reset to WALK_LEFT state

Key Advantages:
- One-hot encoding reduces next-state logic complexity
- Direction embedded in state eliminates need for separate register
- Outputs are direct state decodes for minimal logic
- Clear separation of state transition conditions
- Maintains all specified behavior requirements
