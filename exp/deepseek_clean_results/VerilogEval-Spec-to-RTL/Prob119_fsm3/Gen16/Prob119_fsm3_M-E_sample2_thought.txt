Novel approach: Implement the state machine using a one-hot encoding scheme with explicit state transition equations. This offers:
1. Potentially faster state transitions as each state has its own flip-flop
2. Simpler combinatorial logic for next state calculation
3. More power-efficient transitions (only two bits change per transition)
4. Clear separation between state transition logic and output logic
5. Maintains asynchronous reset functionality while optimizing for readability
