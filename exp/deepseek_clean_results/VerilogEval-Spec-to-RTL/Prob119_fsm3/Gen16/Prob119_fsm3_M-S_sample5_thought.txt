Simplified Design Idea:
1. Remove parallel state prediction to reduce logic complexity
2. Use direct state transition logic in a single always block
3. Maintain same state encoding and Moore output behavior
4. Keep positive edge triggered flip-flops with async reset
5. Combine next state logic and state register into a more compact form

Key Simplifications:
- Eliminate separate next state prediction wires
- Remove intermediate next_state register
- Directly compute transitions in state update block
- Fewer lines of code while maintaining same functionality
- Simpler to understand and verify
