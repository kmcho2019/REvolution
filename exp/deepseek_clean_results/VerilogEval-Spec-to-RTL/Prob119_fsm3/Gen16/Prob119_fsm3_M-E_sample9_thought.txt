Novel Architectural Idea: "Parallel State Prediction"

Instead of using a traditional sequential state machine, this design employs a parallel prediction approach that:
1. Uses combinational logic to predict next states for both input conditions (0 and 1)
2. Maintains current state in a register
3. Selects the appropriate next state based on actual input
4. Implements output as a direct function of the current state

Key Advantages:
- Potentially better timing as next state calculation happens in parallel
- Clear separation of state transition logic
- Easier to pipeline if needed
- More transparent state transition behavior
- Maintains Moore machine properties (output depends only on state)
