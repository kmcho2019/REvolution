Refactoring Approach:
1. Replace the sequential always block with continuous assignments for state transitions
2. Use a combinational always block to calculate next state
3. Separate the state register into its own always block
4. Maintain the same parameterized states and Moore output logic
5. This approach makes the state transition logic more explicit and separates combinational/sequential elements

Key Benefits:
- Clear separation of combinational next-state logic from sequential state storage
- Easier to modify state transition logic independently
- More flexible for synthesis optimizations
- Maintains same functionality while showing alternative implementation style
