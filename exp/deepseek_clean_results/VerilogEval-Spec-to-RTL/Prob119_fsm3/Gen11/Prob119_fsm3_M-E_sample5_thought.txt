Novel architectural idea: One-hot encoded state machine with parallel transition logic

Key features:
1. One-hot state encoding (4 bits for 4 states) for potentially faster state decoding
2. Parallel next-state computation using continuous assignments instead of case statements
3. Explicit state bit definitions for better readability
4. Output directly tied to state D bit (no comparator needed)
5. Maintains same asynchronous reset functionality

Advantages:
- One-hot encoding simplifies state decoding (each state is a single bit)
- Parallel transition logic may reduce combinational path delays
- No need for case statement or state parameter definitions
- Output is simply a wire from the state D bit
- More scalable for additional states if needed
