Innovative approach using one-hot encoding with registered outputs:
1. One-hot encoding (4 bits for 4 states) for potentially better timing in some technologies
2. Registered output to break critical path (output flop directly driven by state)
3. Combinational next-state logic separated from state registers
4. Explicit state transition equations for clarity
5. Asynchronous reset initializes to state A (0001)
6. Output is simply the D state bit (no extra logic)

Key advantages:
- One-hot can be faster in some FPGA architectures
- Registered output improves timing closure
- Clear separation of combinational and sequential logic
- Each state transition is explicitly calculated
- No case statement needed for state transitions
