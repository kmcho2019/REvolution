To implement the Moore state machine with the given specifications:
1. Define four states (A, B, C, D) using a 2-bit register.
2. Create combinational logic for next state transitions based on current state and input.
3. Create combinational logic for output based solely on current state (Moore machine property).
4. Use positive edge-triggered clock with asynchronous reset to state A.
5. The output is 1 only when in state D, 0 otherwise.
