This solution uses one-hot encoding for the state machine, which can offer better timing in some cases. Key features:
1. One-hot encoding (4 bits) for the four states
2. Separate combinational blocks for next state logic and output
3. Explicit state transitions without case statements
4. Asynchronous reset forces state to A (0001)
5. Output is simply the D state bit
This approach may have better timing characteristics in some technologies due to simpler decoding logic.
