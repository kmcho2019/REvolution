To simplify the Moore state machine implementation:
1. Keep the same state encoding (A=00, B=01, C=10, D=11) as it's minimal for 4 states
2. Combine the state transition and output logic into a single always block
3. Remove the default case since all states are explicitly covered
4. Directly assign the output in the always block to eliminate the separate combinational logic
5. Maintain the same asynchronous reset functionality
