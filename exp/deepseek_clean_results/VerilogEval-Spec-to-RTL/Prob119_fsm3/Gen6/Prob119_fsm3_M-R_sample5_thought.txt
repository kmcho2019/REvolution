Refactoring approach:
1. Maintain the same Moore FSM behavior but implement with separate combinational and sequential blocks
2. Use explicit next_state logic with continuous assignments (assign statements)
3. Keep the same state encoding and output logic
4. Split the design into:
   - Combinational logic for next state calculation
   - Sequential logic for state transition
   - Simple output assignment
5. Benefits of this approach:
   - Clear separation of combinational and sequential logic
   - Easier to debug and modify state transitions
   - More explicit data flow
   - Maintains same PPA characteristics as original
