Novel approach using one-hot encoding and direct state transitions:
1. Use one-hot encoding for states (4 flip-flops) which can simplify next-state logic
2. Implement next-state logic as direct assignments to each state bit
3. Eliminate the need for a separate next_state variable by computing transitions directly
4. Output is simply the D state bit
5. Benefits:
   - One-hot encoding typically results in faster state transitions
   - Each state's transition logic is independent and simpler
   - No need for binary encoding/decoding
   - Output is directly available from state register
   - Potentially better timing due to simpler next-state logic
