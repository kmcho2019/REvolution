To simplify the solution while maintaining functionality, I'll focus on:
1. Using basic binary encoding (00,01,10,11) instead of Gray code since the power savings are minimal for this small FSM
2. Keeping the single always block for state transitions and output
3. Removing the parameter declarations since the state values are only used internally
4. Simplifying the output logic to be part of the always block
5. Maintaining the same asynchronous reset functionality

This reduces the code complexity while keeping all required functionality intact.
