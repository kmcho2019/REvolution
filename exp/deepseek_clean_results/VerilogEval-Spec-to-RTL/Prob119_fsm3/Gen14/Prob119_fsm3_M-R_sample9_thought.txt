Refactoring Approach:
1. Convert the state machine to use explicit next-state logic with continuous assignments
2. Maintain the same state encoding and transitions but express them through combinational logic
3. Keep the output assignment as a simple combinational function of the current state
4. Use a separate always block only for the state register update
5. This approach separates the combinational and sequential logic more clearly, which can sometimes lead to better synthesis results
