Refactoring approach:
1. Use continuous assignments (assign statements) for both next-state logic and output logic
2. Eliminate the combinational always block by expressing next-state directly with ternary operators
3. Keep the sequential state register in an always block for proper flip-flop inference
4. This makes the state transition logic more compact and visible at a glance
5. The output remains purely combinational based on current state
6. Maintains identical functionality while reducing lines of code
