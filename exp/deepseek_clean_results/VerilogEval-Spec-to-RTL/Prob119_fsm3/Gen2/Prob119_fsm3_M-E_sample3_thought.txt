Here's a novel approach using a shift register implementation for the state machine:
1. Instead of traditional state encoding, use a 4-bit shift register where only one bit is high at any time
2. Each state corresponds to a specific bit position in the shift register
3. The shift operation is controlled by the input 'in'
4. Output is simply the MSB of the shift register
5. This approach eliminates combinational next-state logic and reduces critical path
6. Reset initializes the shift register to 0001 (state A)
