Refactoring idea:
1. Use a one-hot encoding scheme for the states to potentially improve timing and power characteristics
2. Separate the state transition logic into combinational always blocks and sequential state registers
3. Use continuous assignments for the output logic
4. Maintain the same Moore machine behavior with asynchronous reset

Key changes:
- One-hot encoding (4 bits) instead of binary (2 bits)
- Explicit next_state computation in combinational logic
- Separate state register update
- Output remains purely combinational
