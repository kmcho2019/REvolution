Novel one-hot parallel state machine approach:
1. Use one-hot encoding (4 bits) for states to simplify next-state logic
2. Implement parallel state transition equations instead of case statements
3. Each state bit has its own combinational logic based on current state and input
4. Output is simply the D state bit
5. Benefits:
   - Potentially better timing as each state transition is independent
   - Simpler output logic (direct state bit)
   - Clear physical meaning of each flip-flop (represents a state)
   - Easier to add/remove states
