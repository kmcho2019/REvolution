Novel Architectural Idea: One-Hot Encoding with Parallel State Logic

Key Features:
1. Uses one-hot state encoding (0001, 0010, 0100, 1000) for potentially better timing in larger FSMs
2. Implements next-state logic in parallel using combinational assignments
3. Separates state transition logic from output logic for clarity
4. Maintains asynchronous reset functionality
5. Uses named parameters for better code readability
6. Optimized for potential power savings by minimizing state transitions

Advantages:
- One-hot encoding can improve timing in larger FSMs
- Parallel logic may reduce critical path delays
- Clear separation of state transition and output logic
- More readable with named states
- Easier to modify or extend
