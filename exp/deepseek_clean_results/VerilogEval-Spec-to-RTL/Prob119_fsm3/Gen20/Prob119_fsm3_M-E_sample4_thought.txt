Novel approach using one-hot encoding with registered outputs:

1. State Encoding:
   - Use one-hot encoding (0001, 0010, 0100, 1000) for better timing and simpler decode logic
   - Each state corresponds to a single bit in a 4-bit register

2. Implementation:
   - Separate always blocks for state transitions and output register
   - Registered output for better timing closure
   - Explicit next-state logic calculation before assignment

3. Advantages:
   - One-hot encoding simplifies state transition logic (each bit can be computed independently)
   - Registered output improves timing by breaking critical paths
   - Clear separation of combinational and sequential logic

4. Optimizations:
   - Next-state logic uses direct bitwise operations based on current state
   - Output register eliminates glitches and provides clean timing
   - Asynchronous reset initializes to state A (0001)
