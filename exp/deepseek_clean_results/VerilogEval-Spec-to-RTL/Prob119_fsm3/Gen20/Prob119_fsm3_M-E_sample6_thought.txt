Novel Architectural Idea: One-Hot Encoded State Machine with Explicit Next-State Logic

Key Features:
1. One-hot state encoding for potentially better timing and simpler decoding
2. Separate combinational next-state logic from sequential state register
3. Explicit state transition equations for clarity
4. Maintains Moore machine properties (output depends only on current state)
5. Asynchronous reset still implemented

Advantages:
- One-hot encoding can improve timing in some technologies
- Separating combinational logic makes the design more modular
- Explicit equations make state transitions very clear
- Easier to modify individual state transitions
- Still maintains clean synchronous design practices
