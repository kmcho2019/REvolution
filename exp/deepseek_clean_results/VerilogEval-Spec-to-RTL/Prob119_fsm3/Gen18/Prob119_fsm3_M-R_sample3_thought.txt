Refactoring Strategy:
1. Maintain the same Moore state machine behavior and Gray code encoding
2. Split the state transition logic into combinational and sequential parts for clarity
3. Use an always block for sequential state updates only
4. Implement next-state logic with continuous assignments (assign statements)
5. Keep output assignment simple and combinational
6. This approach separates concerns and may improve synthesis optimization
