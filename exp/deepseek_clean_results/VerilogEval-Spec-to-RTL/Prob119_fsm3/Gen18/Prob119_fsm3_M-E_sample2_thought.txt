Here's a novel approach using a shift register-based state machine implementation with parallel output decoding:

1. Instead of traditional state encoding, use a 4-bit shift register where only one bit is active (1) at a time, representing the current state
2. The shift register naturally implements one-hot encoding without explicit state variables
3. State transitions are implemented through controlled shifting patterns
4. Output is simply the MSB of the shift register (since D is state 4)
5. Reset initializes to '0001' (state A)
6. Benefits:
   - Eliminates complex state decoding logic
   - Simple shift operations for state transitions
   - Output is directly available from the register
   - Naturally glitch-free outputs
   - Easily scalable to more states
