Refactoring Strategy:
1. Replace the always block with continuous assignments for state transitions
2. Use a combinational logic approach with ternary operators for next state logic
3. Maintain the same state encoding and Moore output behavior
4. Keep the asynchronous reset functionality but implement it differently
5. Use a separate register for state storage with clocked updates

Key Changes:
- State transitions are now expressed as combinational logic
- Next state is calculated in parallel and registered on clock edges
- Reset is handled in the same always block as state updates
- Output remains purely combinational based on current state
- More explicit separation of combinational and sequential logic
