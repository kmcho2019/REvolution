Novel Architecture Idea:
1. Instead of traditional state encoding, use a shift register approach where each state is represented by a unique bit position in a 4-bit register
2. This creates a "one-hot-like" encoding but with sequential transitions
3. The output can be directly tapped from the appropriate bit
4. State transitions are implemented using simple shift operations with conditional wrapping
5. Reset initializes to '0001' (state A)
6. This approach minimizes combinational logic and leverages simple shift operations

Advantages:
- Eliminates need for explicit state decoding
- Output is directly available from a register bit
- State transitions become simple shift operations
- Potentially better timing due to reduced logic depth
