Refactoring approach:
1. Maintain the same logical functionality but implement using an always block instead of continuous assignments
2. Use reg types for the outputs since they'll be assigned in procedural blocks
3. Keep the same intermediate signals but declare them as regs
4. Combine all logic operations into a single always block for potential synthesis optimization
5. Preserve the same interface and behavior while changing only the implementation style

Key changes:
- Switched from continuous assignments to procedural assignments
- Uses always @(*) block for combinational logic
- Outputs changed to reg type (required for procedural assignment)
- Same logical operations but expressed procedurally
- Maintains identical functionality and interface
