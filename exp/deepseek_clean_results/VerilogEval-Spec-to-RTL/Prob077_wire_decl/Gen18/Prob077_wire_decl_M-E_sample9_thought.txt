Instead of using traditional gate-level modeling, let's implement this using a lookup table (LUT) approach that's common in FPGA designs. This method:
1. Combines all logic into a single 4-input LUT (truth table)
2. Computes both outputs (out and out_n) simultaneously
3. Uses a case statement to implement the logic function
4. Eliminates intermediate wires by computing everything in one step
