Instead of using separate continuous assignments for each gate, we can implement the logic using a single procedural block (always @*) that combines all operations. This approach:
1. Groups all logic operations together in one block for better readability
2. Uses temporary variables (and1, and2) within the procedural block instead of explicit wires
3. Still maintains the same logical structure but presents it differently
4. The inverted output is generated directly from the procedural block
