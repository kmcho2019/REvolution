The original implementation is already quite optimal, but we can refactor it to demonstrate an alternative approach using continuous assignments with direct expressions rather than intermediate wires. This approach:
1. Eliminates the explicit wire declarations by combining the logic into direct assignments
2. Maintains the same two-layer logic structure but expresses it more compactly
3. Still preserves the clear separation between the AND and OR layers in the expressions
4. Results in identical functionality and similar PPA characteristics
The refactored version trades some readability (by removing named intermediate signals) for slightly more compact code, while keeping all the same logical operations.
