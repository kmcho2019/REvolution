Let's refactor the LUT-based implementation to be more efficient while maintaining the same logical function. Instead of using a full 4-input truth table, we'll:
1. Keep the LUT concept but reduce it to only the necessary cases
2. Use continuous assignments (assign statements) instead of an always block
3. Implement the truth table as a parameterized lookup
4. Remove the redundant default case
5. Still generate both true and inverted outputs from the LUT output
This maintains the LUT approach but makes it more area-efficient by eliminating unnecessary cases and using simpler syntax.
