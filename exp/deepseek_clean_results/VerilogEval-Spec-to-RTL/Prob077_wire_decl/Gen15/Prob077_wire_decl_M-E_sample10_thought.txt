Novel approach using ternary operator for compact logic:
1. Instead of using separate AND and OR gates, implement the entire logic in a single expression using nested ternary operators
2. This approach reduces the need for intermediate wires while maintaining the same functionality
3. The ternary operations will be optimized by synthesis tools into equivalent gate-level logic
4. The inverted output is still generated separately for clarity
5. This method demonstrates an alternative way to express combinational logic concisely

Key features:
- Single continuous assignment for the main logic path
- Elimination of explicit intermediate wires
- Same logical function but expressed differently
- Maintains clean output inversion
