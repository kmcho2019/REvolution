The original solution uses continuous assignments (assign statements) which is perfectly valid. For refactoring, I'll implement the same logic using an always block with a sensitivity list. This demonstrates an alternative procedural approach while maintaining identical functionality. The key differences are:
1. Using procedural assignments (=) instead of continuous assignments
2. Grouping all logic in a combinational always block
3. Declaring 'out' as a reg type since it's assigned procedurally
The intermediate wires remain the same, just assigned differently.
