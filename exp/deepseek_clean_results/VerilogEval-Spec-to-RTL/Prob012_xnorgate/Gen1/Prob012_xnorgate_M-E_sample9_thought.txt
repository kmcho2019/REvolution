Instead of using the direct XNOR operator, we can implement the XNOR functionality using a 2:1 multiplexer. The mux will select between the inverted and non-inverted versions of input 'b' based on input 'a'. When 'a' is 0, we output 'b' (equivalent to NOT XNOR when a=0). When 'a' is 1, we output NOT 'b' (equivalent to XNOR when a=1). This approach demonstrates how basic logic can be constructed using multiplexers.
