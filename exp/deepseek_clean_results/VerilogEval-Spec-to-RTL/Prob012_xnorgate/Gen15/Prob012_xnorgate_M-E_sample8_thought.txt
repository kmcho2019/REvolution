This implementation uses a 2-input lookup table approach where we explicitly enumerate all possible input combinations and their corresponding outputs. The key differences from the standard solution are:
1. Uses a case statement instead of a direct operator
2. Explicitly shows the truth table mapping
3. Can be easily extended to more complex functions
4. Demonstrates an alternative implementation style that might be useful for more complex combinational logic
5. The synthesis tool will still optimize this to the same gate-level implementation, but the RTL representation is different
