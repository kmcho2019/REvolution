Here's a refactored version that maintains the same lookup table concept but implements it using a continuous assignment with a concatenation-based selection. The key changes are:

1. Replace the procedural always block with a continuous assign statement
2. Use a nested conditional operator (?:) to implement the same truth table
3. This approach is more concise while maintaining the same functionality
4. The conditional operator will synthesize similarly to the case statement in most tools
5. Removes the need for an output register (reg) since we're using continuous assignment
6. The structure remains easily modifiable for other truth tables by changing the conditions
