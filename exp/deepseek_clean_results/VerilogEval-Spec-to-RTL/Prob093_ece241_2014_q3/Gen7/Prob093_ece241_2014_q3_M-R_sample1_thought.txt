The correct approach is to implement each mux_in bit as a function of c and d according to the K-map:

1. mux_in[0] (ab=00): Output is 1 only when cd=10
2. mux_in[1] (ab=01): Output is 1 only when cd=00
3. mux_in[2] (ab=11): Output is 1 when cd=00 or cd=11
4. mux_in[3] (ab=10): Output is 1 when cd=00,11,10

We can implement each output using 2-to-1 muxes by:
1. For mux_in[0]: Select 1 when cd=10 (c=1,d=0), else 0
2. For mux_in[1]: Select 1 when cd=00 (c=0,d=0), else 0
3. For mux_in[2]: Select 1 when c=d (cd=00 or 11), else 0
4. For mux_in[3]: Select 1 when cd≠01, else 0

Total mux count: 4 (one per output)
