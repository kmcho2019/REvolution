Here's a novel approach that uses the 4-to-1 mux more effectively by recognizing patterns in the K-map:

1. Observe that for ab=00 and ab=10, the outputs are similar (both have 1 in cd=00 and cd=10 cases)
2. For ab=00, output is 1 when cd=00,01,11,10 (but not all)
3. For ab=11, output is simply c & d
4. For ab=01, output is always 0
5. For ab=10, output is 1 when cd=00,10,11

We can implement this by:
- mux_in[0]: Use a 2-to-1 mux to select between d (when c=1) and ~c (when c=0)
- mux_in[1]: Hardwire to 0
- mux_in[2]: Directly use c & d
- mux_in[3]: Use a 2-to-1 mux to select between 1 (when d=0) and c (when d=1)

This approach uses only two 2-to-1 muxes plus the required 4-to-1 mux, and correctly implements all K-map cases.
