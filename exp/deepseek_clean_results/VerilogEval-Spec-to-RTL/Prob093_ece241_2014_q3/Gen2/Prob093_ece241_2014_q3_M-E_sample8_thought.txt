Here's a novel approach that leverages the inherent properties of multiplexers to implement the K-map more efficiently:

1. Key Insight: The 4-to-1 mux selector inputs (a,b) correspond to the columns of the K-map, while (c,d) correspond to the rows.
2. Observation: For each column (ab combination), the output depends only on (c,d) inputs.
3. Innovative Approach: Instead of computing each mux_in bit separately, we can view the problem as implementing four separate 2-to-1 functions (one for each ab combination).
4. Implementation Strategy:
   - mux_in[0] (ab=00): Output is 1 for cd=01,11,10 → can be implemented as ~(c & ~d)
   - mux_in[1] (ab=01): Always 0 → constant
   - mux_in[2] (ab=11): Output is 1 only when cd=11 → c & d
   - mux_in[3] (ab=10): Output is 1 for cd=00,11,10 → ~d | (c & d)
5. Optimization: We can implement these functions using just two 2-to-1 muxes by sharing common terms:
   - First mux computes c & d (shared by mux_in[0] and mux_in[2])
   - Second mux computes ~d (used in mux_in[3])
   - Other terms are simple constants or direct inputs
6. This approach uses only two 2-to-1 muxes, which is more efficient than previous solutions.
