Novel Approach: Using CD Inputs to Drive Each Mux Input Independently

1. Key Insight:
   - Each mux_in[x] corresponds to a column in the K-map (for ab=x)
   - We can treat each mux_in bit as an independent function of cd
   - Instead of trying to share logic between outputs, optimize each one separately

2. Implementation Strategy:
   - mux_in[0]: 1 when cd=01,11,10 → Implement as OR of these cases
   - mux_in[1]: Always 0 → Hardwired
   - mux_in[2]: 1 only when cd=11 → Direct AND of c and d
   - mux_in[3]: 1 when cd=00,11,10 → Implement as OR of these cases

3. Optimization:
   - Use minimal 2-to-1 muxes where needed
   - For mux_in[0], use a mux to select between d and 1 based on c
   - For mux_in[3], use a mux to select between ~d and 1 based on c
   - Total: 2 2-to-1 muxes and 1 AND gate
