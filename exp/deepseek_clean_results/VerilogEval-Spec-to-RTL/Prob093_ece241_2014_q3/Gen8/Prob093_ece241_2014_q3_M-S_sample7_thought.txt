To implement the K-map using only multiplexers, we'll analyze each mux_in output and implement them using 2-to-1 muxes:

1. mux_in[0] (ab=00):
   - Output is 1 when cd=01,11,10 (c OR d)
   - Can be implemented with a 2-to-1 mux selecting between d (when c=1) and 1 (when c=0)

2. mux_in[1] (ab=01):
   - Always 0 (constant)

3. mux_in[2] (ab=11):
   - Output is 1 only when cd=11 (c AND d)
   - Can be implemented with a 2-to-1 mux selecting between 0 (when c=0) and d (when c=1)

4. mux_in[3] (ab=10):
   - Output is 1 when cd=00,11,10 (c OR ~d)
   - Can be implemented with a 2-to-1 mux selecting between ~d (when c=0) and 1 (when c=1)

Each output requires just one 2-to-1 mux except mux_in[1] which is constant.
