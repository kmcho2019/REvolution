   - K-map shows: 0 (cd=00), 1 (cd=01), 1 (cd=11), 1 (cd=10)
   - This is equivalent to ~(~c & ~d) or (c | d)
   - Can be implemented directly with an OR operation

2. For mux_in[1] (ab=01):
   - Always 0 as per K-map (no change needed)

3. For mux_in[2] (ab=11):
   - K-map shows: 0 (cd=00), 0 (cd=01), 1 (cd=11), 0 (cd=10)
   - This is exactly c AND d (correct implementation)

4. For mux_in[3] (ab=10):
   - K-map shows: 1 (cd=00), 0 (cd=01), 1 (cd=11), 1 (cd=10)
   - This is equivalent to ~d | (c & d) or simply ~d | c
   - Can be implemented with an OR of ~d and c
