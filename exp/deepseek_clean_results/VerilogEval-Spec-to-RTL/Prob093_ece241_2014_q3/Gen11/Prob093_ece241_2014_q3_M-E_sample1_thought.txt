New approach using multiplexers to implement the K-map:

1. Key insight: Each mux_in output corresponds to a column in the K-map (for ab values 00,01,11,10)
2. For each mux_in, we can use c and d as select lines for 2-to-1 muxes to implement the required function
3. Novel architecture:
   - mux_in[0] (ab=00): 0,1,1,1 pattern can be implemented by ORing c and d
   - mux_in[1] (ab=01): Always 0 (no mux needed)
   - mux_in[2] (ab=11): 0,0,1,1 pattern matches c (no mux needed)
   - mux_in[3] (ab=10): 1,0,1,1 pattern can be implemented by selecting between 1 and c based on d

4. Implementation:
   - mux_in[0]: c OR d (using 2-to-1 mux with c as selector and d as one input)
   - mux_in[1]: Hardwired to 0
   - mux_in[2]: Directly connect to c
   - mux_in[3]: Use d to select between 1 (when d=0) and c (when d=1)

5. Verification:
   - mux_in[0] matches all cases (0 for cd=00, 1 for others)
   - mux_in[1] always 0
   - mux_in[2] matches (0 for cd=00,01; 1 for cd=11,10)
   - mux_in[3] matches (1 for cd=00,10,11; 0 for cd=01)
