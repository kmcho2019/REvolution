To refactor the code while maintaining the same functionality, I'll make the following changes:

1. State Encoding: Keep the Gray code encoding for power efficiency but represent it as a parameterized enum for better readability.

2. State Transition: Convert the combinational always block to a continuous assignment with a function that implements the state transition logic. This makes the state transition more explicit and potentially reduces synthesis overhead.

3. Output Logic: Keep the efficient bit-select method but move it to a separate assign statement for clarity.

4. Reset Handling: Maintain synchronous reset but express it more concisely.

Key improvements:
- Function-based state transition makes the logic more modular
- Enum-style state definition improves readability
- Maintains all PPA benefits of original solution
- Cleaner separation of state transition logic
- Same Gray code advantages preserved
