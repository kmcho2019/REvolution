Simplification Strategy:
1. State Encoding: Use simple binary encoding (A=000, B=001, C=010, D=011, E=100, F=101) for straightforward implementation and readability.

2. State Transition Logic: Use a single always block for both state transitions and output logic to reduce code complexity while maintaining functionality.

3. Output Logic: Directly assign z based on state (E or F) since these are the only states where z=1. This can be done with a simple combinational assignment.

4. Reset Handling: Keep synchronous reset behavior as specified.

Key Simplifications:
- Eliminated separate next_state logic by combining state transition and storage in one always block
- Simplified state encoding to sequential binary values
- Direct output assignment based on state values
- Reduced overall code lines while maintaining same functionality
