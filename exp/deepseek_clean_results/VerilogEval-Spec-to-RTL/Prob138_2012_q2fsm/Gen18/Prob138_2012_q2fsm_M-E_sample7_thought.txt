Novel Architecture Idea: Output-Partitioned FSM with Dual-Register State Encoding

1. Key Insight: Instead of traditional state encoding, partition the FSM based on output values (z=0 and z=1 states) and use separate registers for each partition.

2. Implementation:
   - Use two 2-bit registers: one for z=0 states (A,B,C,D) and one for z=1 states (E,F)
   - Only one register is active at any time, reducing switching power
   - Output z is determined by which register is active
   - State transitions within each partition are optimized for minimal bit changes

3. Benefits:
   - Reduced power consumption since only one register bank is active
   - Simplified output logic (just need to know which register is active)
   - Natural isolation between output partitions
   - Potential for clock gating on inactive register bank

4. State Encoding:
   z=0 states (A,B,C,D): 00,01,11,10 (Gray coded)
   z=1 states (E,F): 01,10 (minimal encoding)
