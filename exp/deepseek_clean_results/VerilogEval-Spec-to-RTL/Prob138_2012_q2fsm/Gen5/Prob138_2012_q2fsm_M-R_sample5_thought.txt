Refactoring approach:
1. Split the state machine into three distinct always blocks for better modularity:
   - One for state register (sequential)
   - One for next state logic (combinational)
   - One for output logic (combinational)
2. Use binary state encoding (3 bits) to maintain same encoding efficiency
3. Make output logic explicit in its own always block for clarity
4. Keep synchronous reset functionality
5. Use case statements consistently for state transitions

This separation of concerns makes the FSM structure more explicit and easier to modify/maintain, while maintaining identical functionality.
