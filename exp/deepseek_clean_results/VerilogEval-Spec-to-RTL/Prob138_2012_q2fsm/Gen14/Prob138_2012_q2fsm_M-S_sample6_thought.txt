Simplification Strategy:
1. State Encoding: Use simple binary encoding (A:000, B:001, C:010, D:011, E:100, F:101) for straightforward implementation.

2. State Transition Logic: Use a single always block for both state transitions and output logic to reduce code complexity while maintaining readability.

3. Output Logic: Directly assign z based on state (E or F) since these are the only states where z=1. This eliminates the need for separate output logic.

4. Reset Handling: Keep synchronous reset but implement it in the same always block for compactness.

Key Simplifications:
- Combined state transition and output logic into one always block
- Simplified state encoding to binary sequence
- Direct output assignment based on state values
- Removed unnecessary intermediate signals
