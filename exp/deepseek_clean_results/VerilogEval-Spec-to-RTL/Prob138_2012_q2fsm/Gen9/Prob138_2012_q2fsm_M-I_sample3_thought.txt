To optimize the FSM implementation for better PPA metrics, I'll make the following improvements:

1. State Encoding: Switch to one-hot encoding which typically gives better timing for small FSMs (6 states here) while maintaining reasonable power and area.

2. Output Logic: Keep the direct output assignment from state bits since one-hot encoding naturally maps outputs to specific state bits.

3. State Transition: Simplify the transition logic by using a single always block for both state transition and output, allowing synthesis tools to better optimize the combined logic.

4. Reset Handling: Maintain synchronous reset but express it more efficiently.

Key optimizations:
- One-hot encoding improves timing critical paths
- Combined always block reduces area overhead
- Maintains clear state transition logic
- Output remains directly derived from state bits
- Reduced combinatorial path compared to function-based approach
