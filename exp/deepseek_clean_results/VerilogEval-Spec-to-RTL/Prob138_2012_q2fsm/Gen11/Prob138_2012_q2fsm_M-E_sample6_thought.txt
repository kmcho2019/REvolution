Novel Architecture Idea: "Output-Partitioned State Encoding"
1. State Encoding Strategy: Instead of traditional sequential encoding, partition states based on output value (z) to minimize output switching. States with z=0 (A,B,C,D) use lower 2 bits, while z=1 (E,F) use upper 2 bits.
2. State Transition Logic: Implement as a pure combinational function using case statement for clarity and balanced paths.
3. Output Generation: Directly derived from state bit pattern for minimal delay.
4. Reset Handling: Explicit synchronous reset to state A (000).

Key Innovations:
- Output-aware state encoding reduces output switching power
- Clear separation between state storage and transition logic
- Case statement for balanced combinatorial paths
- Minimal bit transitions between frequently visited states
