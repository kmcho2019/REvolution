Refactoring Strategy:
1. State Encoding: Keep the same efficient Gray-like encoding (A:000, B:001, C:011, D:010, E:110, F:100) for minimal transitions and easy output generation.

2. State Transition Logic: Replace the case statement with parallel ternary operations for more concise code. This makes each state's transitions explicit in a single line.

3. Output Logic: Maintain the simple bit-check (current_state[2]) but implement it via an always block instead of continuous assignment for consistency in style.

4. Reset Handling: Keep synchronous reset but express it more compactly in the state storage always block.

Key Changes:
- Ternary operators replace case statement for more compact state transition logic
- Output logic moved to always block (though functionally equivalent)
- More compact reset expression
- Same state encoding and overall functionality
