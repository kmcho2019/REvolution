Here's a novel approach using a shift register and XOR-based edge detection:

1. Instead of storing just the previous two states, we'll use a 3-bit shift register for each input bit to track more history
2. We'll detect edges by looking for the pattern "001" in the history (0->0->1 transition)
3. This provides more robust edge detection by requiring two consecutive 0s before a 1
4. The implementation uses parallel shift registers and pattern matching logic
5. This method could potentially filter out some glitches while maintaining the same basic functionality
