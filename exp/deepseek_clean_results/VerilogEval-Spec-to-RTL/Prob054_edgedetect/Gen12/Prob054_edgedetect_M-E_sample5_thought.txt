Instead of using shift registers, we can implement a parallel edge detection scheme using XOR and AND gates. The key ideas are:
1. Store only the previous state (1 bit per input) rather than 2 bits
2. Use combinatorial logic to detect the rising edge: current=1 AND previous=0
3. This reduces storage requirements while maintaining the same functionality
4. The parallel nature allows all bits to be processed simultaneously in one clock cycle
5. The design is more hardware-efficient as it uses basic logic gates rather than shift registers

This approach minimizes storage elements while still providing accurate edge detection, potentially improving power and area metrics.
