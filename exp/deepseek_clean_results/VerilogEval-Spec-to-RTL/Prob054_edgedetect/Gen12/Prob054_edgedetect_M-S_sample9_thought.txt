The solution can be further simplified by eliminating the separate register for previous input. Instead, we can directly use the non-blocking assignment property of Verilog to capture the previous value within the same always block. The key insight is that the right-hand side of non-blocking assignments uses the values from before the clock edge, so we can compute the edge detection using the current input and the value that prev_in had before the clock edge, without needing to explicitly store it in a separate register.
