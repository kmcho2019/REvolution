Here's a novel approach using a shift register to track the last two clock cycles of input values. Instead of directly storing the previous input, we'll use a 2-bit shift register for each input bit. This allows us to:
1. Track both current and previous states in a single register per bit
2. Detect edges by comparing the two most recent values (01 pattern)
3. Potentially scale better for more complex edge detection patterns if needed
The shift register approach provides a clean separation between data storage and edge detection logic.
