Instead of storing just the previous state, we can use a 2-bit shift register for each input bit to track the last two states. This allows us to:
1. Detect edges by checking for specific patterns in the shift register (01 for positive edge)
2. Reduce combinational logic complexity by using pattern matching
3. Potentially enable detection of other edge types (negative, both) if needed in future
4. Make the design more scalable for different edge detection requirements
