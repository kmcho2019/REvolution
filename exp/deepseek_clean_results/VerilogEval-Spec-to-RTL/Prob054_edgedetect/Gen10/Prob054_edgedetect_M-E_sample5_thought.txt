Instead of storing just the previous state, we can use a 2-bit shift register for each input bit to track the last two states. This allows us to:
1. Detect the exact 0->1 transition pattern (01 in the shift register)
2. Potentially extend to more complex edge detection patterns if needed
3. Implement a more modular design where each bit's edge detector is independent

The shift register approach provides better isolation between bits and could be more power-efficient since we only update the shift registers that have changing inputs.
