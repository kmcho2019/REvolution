Instead of storing just the previous state, we can use a 2-bit shift register for each input bit to track the last two states. This allows us to:
1. Detect the exact 0->1 transition pattern (01 in the shift register)
2. Potentially scale to detecting longer patterns if needed
3. Make the edge detection logic more explicit and modular
4. Enable future extension to detect other edge types (like negative edges) with minimal changes

The shift register approach also makes the timing more predictable since each bit's history is independently tracked.
