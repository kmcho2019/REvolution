Here's a novel approach using a shift register for edge detection:
1. Instead of storing just the previous value, we'll use a 2-bit shift register for each input bit
2. This allows us to track the current and previous state of each bit
3. The positive edge is detected when the shift register transitions from "01" to "10"
4. This method provides better noise immunity as it requires two consecutive samples to confirm an edge
5. The implementation uses parallel processing for each bit while maintaining a clean synchronous design
