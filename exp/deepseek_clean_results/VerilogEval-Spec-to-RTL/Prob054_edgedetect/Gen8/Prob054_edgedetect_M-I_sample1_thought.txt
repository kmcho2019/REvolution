The current implementation is already quite efficient, but we can make some minor optimizations to further improve PPA:

1. Clock Gating: Add simple clock gating for the prev_in register when inputs are stable to reduce dynamic power
2. Logic Optimization: Use XOR-based edge detection which might be more area-efficient in some technologies
3. Register Splitting: Split the 8-bit register into two 4-bit registers to potentially improve placement and routing
4. Output Register: Keep the pedge output registered for better timing

The improved strategy will:
- Maintain the same functionality
- Reduce power consumption during stable input periods
- Potentially improve area and timing through structural optimizations
- Keep the design simple and readable
