Instead of storing two previous states for each bit, we can use a shift register approach that:
1. Uses a single 8-bit register to store the previous state
2. Detects edges by XORing current and previous states to find changed bits
3. ANDs this with the current input to identify positive edges only
4. This reduces register count by 50% compared to the two-register approach
5. The XOR operation efficiently identifies all changed bits in parallel
6. The final AND gate filters for only 0->1 transitions

This method trades off some timing margin (since we're using current input) for reduced area, while maintaining correct edge detection functionality.
