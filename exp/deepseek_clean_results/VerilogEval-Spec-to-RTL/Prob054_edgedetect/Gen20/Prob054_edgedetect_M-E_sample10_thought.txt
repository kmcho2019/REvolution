Instead of using shift registers, we can implement a more combinatorial approach that:
1. Uses XOR gates to detect changes in each bit
2. Combines this with the current input value to identify rising edges
3. Uses a single register stage to store the previous input values
4. This method reduces register usage while maintaining clear edge detection logic
5. The XOR-based approach may offer better power efficiency for bits that don't change often

The key insight is that a positive edge occurs when (current_bit=1 AND previous_bit=0), which can be expressed as (current_bit XOR previous_bit) AND current_bit.
