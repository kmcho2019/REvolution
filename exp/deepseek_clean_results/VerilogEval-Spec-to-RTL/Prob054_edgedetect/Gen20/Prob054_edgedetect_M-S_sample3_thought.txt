To simplify the solution while maintaining functionality, we can:
1. Eliminate one of the history registers since we only need to compare the current input with its previous value
2. Use a single 8-bit register to store the previous input value
3. Detect edges by comparing the current input with the registered previous value
4. This reduces the number of flip-flops by half while keeping the same edge detection capability

The key insight is that we only need to store one previous state to detect 0->1 transitions (current=1 and previous=0), making the second history register unnecessary.
