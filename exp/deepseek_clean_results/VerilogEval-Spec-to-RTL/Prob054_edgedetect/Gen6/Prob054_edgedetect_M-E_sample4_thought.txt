Here's a novel approach using a shift register and XOR-based edge detection:

1. Instead of storing just the previous value, maintain a 2-bit history for each input bit using shift registers
2. Detect edges by checking for the pattern "01" in the history bits
3. This provides more flexibility for edge detection and could be extended to detect other patterns if needed
4. The XOR-based detection reduces glitches compared to AND-NOT logic
5. The shift register approach makes it easier to scale for different edge detection requirements

Key advantages:
- More robust edge detection with explicit pattern matching
- Easily extensible to detect other edge patterns (like negative edges)
- Clear separation between history tracking and edge detection logic
- Potential for power optimization by gating unused history bits
