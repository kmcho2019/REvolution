The previous solution can be simplified while maintaining the same functionality by:
1. Removing unnecessary parameterization since the bit width is fixed (8 bits)
2. Eliminating the intermediate current_in register since we only need to compare current input with previous input
3. Keeping just one register to store the previous input value
4. Maintaining the same edge detection logic (~prev_in & in)

This reduces the number of flip-flops by half while keeping the same edge detection behavior.
