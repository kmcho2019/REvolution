Here's a novel approach using a shift register and XOR-based edge detection:

1. Instead of storing just the previous state, we'll use a 3-bit shift register for each input bit to track history
2. This allows us to detect edges by looking at transitions over multiple cycles
3. We'll use XOR operations to detect changes between consecutive cycles
4. Then AND with the current input value to ensure we only detect 0->1 transitions
5. The shift register approach provides more flexibility for future enhancements (like glitch filtering)

This method trades off slightly more registers for potential benefits in noise immunity and extensibility.
