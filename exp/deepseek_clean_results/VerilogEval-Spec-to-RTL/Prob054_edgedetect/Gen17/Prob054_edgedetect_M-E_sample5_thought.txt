Here's a novel approach using a shift register and XOR-based edge detection:

1. Instead of storing just the previous two states, use a 3-bit shift register for each input bit to track state transitions over time
2. Detect positive edges by looking for the pattern 001 in the shift register (0->0->1 transition)
3. This provides better noise immunity by requiring the input to be stable for two cycles before the edge
4. The XOR-based detection reduces glitches compared to AND-based approaches
5. Each bit is processed independently, allowing for per-bit timing optimization

Key advantages:
- More robust against single-cycle glitches
- Clear pattern matching (001) for positive edge
- Modular design that scales well for wider buses
- Potential for lower power due to reduced switching activity
