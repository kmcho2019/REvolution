Here's a novel approach using XOR-based edge detection with delayed input registers:
1. Instead of tracking 2-bit history per bit, we'll use a single delayed version of the input
2. Edge detection is done by XORing the current input with the delayed version to find changed bits
3. Then AND with the current input to detect only positive edges (0->1 transitions)
4. This reduces register usage by half (8 bits instead of 16) while maintaining the same functionality
5. The XOR-AND combination is efficient in hardware and often maps well to FPGA/ASIC primitives
