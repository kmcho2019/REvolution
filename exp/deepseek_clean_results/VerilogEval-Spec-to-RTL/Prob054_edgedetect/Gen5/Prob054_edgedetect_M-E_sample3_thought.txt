Instead of storing just the previous state, we can use a 2-bit shift register for each input bit to track the last two states. This allows us to:
1. Detect the exact 0->1 transition pattern (01 in the shift register)
2. Potentially extend to detect more complex patterns if needed in the future
3. Make the edge detection logic more explicit and readable
4. Allow for easier modification to detect other edge types (like negative edges)

The shift register approach also makes it visually clear what pattern we're detecting in the hardware description.
