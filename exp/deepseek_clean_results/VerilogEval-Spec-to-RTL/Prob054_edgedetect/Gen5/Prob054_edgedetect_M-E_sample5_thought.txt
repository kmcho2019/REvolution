Here's a novel approach using shift registers for edge detection:
1. Instead of storing just the previous value, we'll use a 2-bit shift register for each input bit
2. This allows us to track the last two states of each bit
3. A positive edge is detected when the sequence is "01" in the shift register
4. This approach provides more explicit state tracking and could be extended for more complex pattern detection
5. The shift registers are implemented using concatenation for compact code
