Here's a novel approach using a shift register and XOR-based edge detection:

1. Instead of storing just the previous state, we'll use a 3-bit shift register for each input bit to track the last three states
2. We'll detect positive edges by looking for the pattern "001" in the history (two 0s followed by a 1)
3. This provides some filtering against glitches since we require two consecutive 0s before a 1
4. The implementation uses parallel shift registers and pattern matching logic
5. This method could be more robust in noisy environments while maintaining similar PPA characteristics
