I'll implement a different architectural approach that:
1. Uses a 3-stage shift register for each bit to capture the input history
2. Detects edges by looking for specific patterns in the history (001 for positive edge)
3. Employs pattern matching logic using XOR operations
4. Provides glitch-free output by registering the final result

Key advantages:
- More robust against metastability with 3-stage sampling
- Can be extended to detect both rising and falling edges if needed
- Clear pattern matching makes the design intent obvious
- Modular structure that's easy to verify
