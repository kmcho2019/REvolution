To simplify the solution while maintaining functionality, we can:
1. Use only a single 8-bit register to store the previous input value
2. Detect positive edges by comparing current input with previous input directly
3. This reduces the number of registers by half while keeping the same edge detection capability
4. The edge detection will now be immediate (1 cycle latency) rather than delayed by 2 cycles
5. The logic remains simple with just one register and a bitwise operation
