To simplify the solution while maintaining functionality, we can:
1. Reduce the number of registers by only storing the previous state (prev_in) instead of two previous states
2. Detect edges by comparing current input with previous input directly
3. Use a single always block to update the previous state
4. The edge detection is now simply (~prev_in & in), which is more straightforward
5. This reduces area by using fewer registers and simplifies the logic
6. The functionality remains the same - detecting 0->1 transitions on each bit
