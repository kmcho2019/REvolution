Fusion strategy combining the best aspects of both examples:
1. Maintain the clear edge detection logic (in & ~prev_in) which is efficient and easy to understand
2. Use explicit wire declarations (from Example 1) for better code organization and readability
3. Keep the compact always block structure (from Example 2) for conciseness
4. Use non-blocking assignments consistently for sequential logic
5. Maintain the simple parameter-free design since the bit width is fixed

The resulting solution provides:
- Clear separation between combinational (edge detection) and sequential (state update) logic
- Minimal and efficient implementation
- Excellent readability through explicit wire declarations
- Optimal timing characteristics with a short critical path
- Compact code footprint
