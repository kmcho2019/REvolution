Refactoring approach:
1. Maintain the same positive edge detection logic (current & ~previous)
2. Split the sequential and combinational logic into separate blocks for clarity
3. Use continuous assignment (assign) for the combinational edge detection
4. Keep the sequential part (register storage) in an always block
5. This separation makes the design more modular and easier to understand

The refactored version separates the edge detection logic (combinational) from the state storage (sequential), which can be beneficial for synthesis and verification. The functionality remains identical to the original solution.
