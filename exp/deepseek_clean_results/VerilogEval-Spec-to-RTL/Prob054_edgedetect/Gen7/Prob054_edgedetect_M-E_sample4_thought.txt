Here's a novel approach using a shift register-based edge detection method:
1. Instead of storing just the previous value, we'll maintain a 2-bit history for each input bit using shift registers
2. Each shift register will track the current and previous state of its corresponding input bit
3. Positive edge detection is done by checking for "01" pattern in the shift register
4. This approach provides explicit visibility into the transition history and could be extended for more complex pattern detection
5. The shift registers are implemented as packed arrays for compact representation
