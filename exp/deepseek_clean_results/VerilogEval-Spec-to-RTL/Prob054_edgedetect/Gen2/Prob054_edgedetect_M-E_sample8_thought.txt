Alternative approach using shift registers and XOR logic:
1. Instead of storing just the previous value, maintain a 2-bit history for each input bit using shift registers
2. Use XOR between the two history bits to detect any change (both rising and falling edges)
3. AND this with the current bit value to isolate only positive edges
4. This method provides more flexibility if we later want to detect both edge types
5. The shift register approach could potentially scale better for longer history requirements
