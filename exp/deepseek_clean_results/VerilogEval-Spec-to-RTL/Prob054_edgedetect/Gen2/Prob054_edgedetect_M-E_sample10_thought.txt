Here's a novel approach using a shift register and XOR-based edge detection:

1. Instead of storing just the previous value, maintain a 2-bit history for each input bit using a shift register
2. Detect edges by checking the transition pattern (00->01) using XOR operations
3. This provides more robust edge detection that can potentially filter out glitches
4. The shift register approach could be extended to longer histories if needed for more complex edge detection

Key advantages:
- More robust against single-cycle glitches
- Can be easily extended for more complex edge pattern detection
- Still maintains good PPA characteristics
- Clear separation of history tracking and edge detection logic
