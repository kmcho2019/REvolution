Novel Approach: Time-Delayed Edge Detection with History Buffer
1. Instead of just comparing current and previous cycle, maintain a small history buffer (2 cycles) for each bit
2. This allows us to detect edges more robustly by comparing against multiple past values
3. The edge is detected only if the current value differs from both previous values (reducing false positives from glitches)
4. Uses shift registers to maintain the history efficiently
5. Output is still registered for clean timing
