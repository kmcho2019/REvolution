Novel Architecture Idea:
1. Instead of storing just the previous value, maintain a 2-bit history for each input bit using shift registers
2. Compare the two most recent samples to detect edges
3. This approach provides flexibility to potentially detect glitches or metastability if expanded
4. Uses separate always blocks for shift register updates and edge detection for clearer timing separation
5. The shift register approach could be extended to longer history windows if needed
6. Maintains full synchronous operation with registered outputs

Key Advantages:
- More explicit history tracking than simple XOR method
- Clear separation of shift logic and edge detection
- Easily extensible to more complex edge detection (like glitch filtering)
- Still maintains minimal register usage (only 2x8 bits)
- Output is fully registered for clean timing
