Instead of just comparing current and previous values, this solution:
1. Maintains a 2-bit history for each input bit (current and previous state)
2. Uses a state machine approach where:
   - 00: stable low
   - 11: stable high
   - 01: rising edge detected
   - 10: falling edge detected
3. Outputs are registered to ensure clean timing
4. Benefits:
   - Can be extended to detect specific edge types (rising/falling)
   - Provides one-cycle delayed output like original spec
   - More robust against glitches than simple XOR method
   - Clear state representation for debugging
