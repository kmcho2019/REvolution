Instead of storing just the previous value, we can use a 2-bit shift register for each input bit to track the last two states. This allows us to:
1. Detect edges by comparing the two most recent values (bits [1] and [0])
2. Use a shift operation to update history rather than simple assignment
3. Implement the edge detection using purely combinational logic on the shift register outputs
4. This approach could potentially scale better for pipelined implementations and provides more visibility into input history
