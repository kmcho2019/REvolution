To detect any edge (both rising and falling) on each bit of an 8-bit input vector, we need to compare each bit's current value with its previous value. If they differ, we've detected an edge. We'll use flip-flops to store the previous value of each input bit, then XOR each current bit with its stored previous value to detect changes. The XOR result directly indicates an edge occurred (1 means edge detected, 0 means no edge).
