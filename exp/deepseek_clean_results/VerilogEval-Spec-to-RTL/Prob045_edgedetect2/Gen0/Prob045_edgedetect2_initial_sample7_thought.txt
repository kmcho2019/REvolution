To detect any edge (both rising and falling) for each bit in an 8-bit input vector, we can:
1. Store the previous value of the input vector in a register
2. On each clock cycle, compare each bit of the current input with the corresponding bit of the previous input
3. If they differ, set the corresponding output bit to 1, otherwise set it to 0
4. Update the previous value register with the current input for the next cycle
