The original solution uses a two-stage pipeline which introduces an extra cycle delay. To properly detect edges between consecutive cycles, we should:
1. Store only the previous input value (single stage)
2. Use combinational logic to detect changes between current and previous input
3. Register the edge detection result to ensure proper timing

This can be implemented by:
1. Using an always block to store the previous input value
2. Using a continuous assignment (assign) for the edge detection logic
3. Registering the output in another always block for clean timing
This approach maintains the same functionality but with clearer separation of combinational and sequential logic.
