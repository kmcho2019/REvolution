Here's a novel approach using a shift register and comparison logic:
1. Instead of just storing the previous value, maintain a 3-cycle history for each bit
2. Detect edges when the middle value differs from both previous and next values
3. This provides some noise immunity by requiring consistent transitions
4. Output is registered to maintain synchronous behavior
5. The 3-sample window helps filter out glitches while still detecting real edges

Key advantages:
- More robust against single-cycle glitches
- Still maintains single-cycle pulse output for valid edges
- Uses slightly more registers but same combinational logic
