Novel approach using parallel edge detection with history tracking:
1. Instead of just comparing current and previous values, maintain a 2-bit history for each input bit
2. Detect edges when the middle bit differs from either the newest or oldest sample
3. This provides some noise filtering by requiring the edge to persist for at least one clock cycle
4. The design uses shift registers for history tracking and parallel comparators
5. Output is registered for clean timing
6. This method can help filter out glitches while still detecting true edges
