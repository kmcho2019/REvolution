Refactored approach:
1. Use continuous assignment (assign) instead of procedural blocks for the combinational logic
2. Keep the sequential element (register) for storing previous input
3. Split the functionality into:
   - Sequential part: Register to store previous input value (requires always block)
   - Combinational part: XOR operation to detect edges (can use assign)
4. This makes the edge detection logic more explicit and separates concerns between sequential and combinational logic

Key changes:
- Moved XOR operation to continuous assignment
- Kept only the necessary register in the always block
- More explicit separation of sequential and combinational logic
