Here's a novel approach using a two-stage edge detection pipeline:
1. First stage: Capture input values in two consecutive clock cycles (current and previous)
2. Second stage: Compare these values to detect changes
3. Instead of using XOR, we'll explicitly check for both rising and falling edges
4. We'll implement this as a pipelined design to potentially improve timing in larger systems
5. The output will still be registered to ensure clean timing
This method provides more explicit edge detection and could be more readable/maintainable while maintaining the same functionality.
