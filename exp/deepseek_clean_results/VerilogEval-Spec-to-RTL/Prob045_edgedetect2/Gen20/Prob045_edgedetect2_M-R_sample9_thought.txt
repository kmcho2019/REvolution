Refactoring Strategy:
1. Maintain the same edge detection logic (XOR between current and previous input)
2. Move all logic to continuous assignments for a fully combinational approach
3. Use a generate block to instantiate the edge detectors for each bit
4. Benefits:
   - More modular and scalable design
   - Clear bit-wise parallel processing
   - Easier to parameterize for different bus widths
   - Maintains same functionality while being more explicit about parallel operations
