Simplification Strategy:
1. Remove the explicit prev_in register since we can directly use the non-blocking assignment behavior
2. Use a single continuous assignment for edge detection instead of always block
3. Maintain the same edge detection logic (XOR between current and previous input)
4. Output remains registered for clean timing characteristics

Key Benefits:
- Eliminates one register variable (prev_in)
- Uses simpler continuous assignment for combinational logic
- Still maintains registered output for timing
- Reduces code complexity while keeping identical functionality
- Same hardware efficiency (8 flip-flops + 8 XOR gates)
