Refactoring idea:
1. Instead of using an always block with sequential logic, we'll implement the edge detection using continuous assignment
2. We'll still need registers to store the previous input values, so we'll keep the flip-flops for prev_in
3. The edge detection (XOR operation) will be moved outside the always block and implemented with an assign statement
4. This separates the sequential and combinational logic more clearly
5. The functionality remains identical - detecting any transition on each of the 8 bits
