Instead of just comparing current and previous values, I'll implement a 3-cycle history buffer for each bit. This allows detecting edges while also providing some glitch filtering. The edge detection will trigger if:
1. The current value differs from the immediate previous value (standard edge detection)
2. AND the previous two values were stable (helps filter out single-cycle glitches)

This provides more robust edge detection while maintaining low latency (1 cycle delay). The implementation uses shift registers for history tracking and combinational logic for the stability check.
