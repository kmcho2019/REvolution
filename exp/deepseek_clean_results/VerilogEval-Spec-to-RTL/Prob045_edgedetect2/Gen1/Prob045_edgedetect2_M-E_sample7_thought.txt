Instead of using XOR for edge detection, we can implement a two-stage pipeline:
1. First stage stores the input value from two cycles ago (prev_prev_in)
2. Second stage stores the input value from one cycle ago (prev_in)
3. Edge is detected when prev_in differs from prev_prev_in
This ensures the edge detection is properly registered and appears exactly one cycle after the actual edge occurs. The two-stage approach provides better timing characteristics and makes the edge detection more robust against metastability.
