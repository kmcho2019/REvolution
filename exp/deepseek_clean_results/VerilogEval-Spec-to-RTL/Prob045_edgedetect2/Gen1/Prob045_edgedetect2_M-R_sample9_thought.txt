To properly detect edges and generate one-cycle pulses:
1. Store previous input values in flip-flops (sequential logic)
2. Use combinational logic to detect transitions (XOR between current and previous values)
3. Register the transition detection to ensure output changes only on clock edges
4. This ensures each edge produces exactly one clock cycle pulse on the output
