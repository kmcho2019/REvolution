Novel Architectural Idea:
Instead of using XOR-based edge detection, we'll implement a state-based approach where each bit tracks its previous state explicitly. This method:
1. Uses a state register to store the previous value of each bit
2. Compares current and previous states to detect changes
3. Generates the edge signal when states differ
4. Provides better visibility into the transition types (could be extended to detect rising/falling edges separately)
5. May offer better synthesis optimization opportunities for some technologies
6. Uses explicit comparison rather than XOR, which can sometimes be more readable

Key differences from XOR approach:
- More explicit state tracking
- Potentially better for formal verification
- Clearer intent in the code
- Same functionality but different implementation
