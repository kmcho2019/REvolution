Refactoring Approach:
1. Separate combinational and sequential logic for clarity
2. Use continuous assignment (assign) for the edge detection logic (XOR operation)
3. Keep the sequential part (register updates) in a single always block
4. Maintain identical functionality while improving readability
5. Explicitly show the combinational nature of edge detection
6. Keep all the PPA benefits of the original solution

Key Changes:
- Edge detection moved to continuous assignment
- Register updates remain in always block
- Clear separation of combinational vs sequential logic
- Same flip-flop count and XOR operations as original
- Functionally equivalent but structurally different
