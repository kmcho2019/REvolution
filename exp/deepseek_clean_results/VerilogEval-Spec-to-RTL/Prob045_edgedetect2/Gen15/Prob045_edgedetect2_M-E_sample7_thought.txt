Instead of just comparing current and previous values, I'll implement a 3-cycle history buffer for each bit. This allows detecting edges with some additional context. The edge detection will trigger if:
1. The current value differs from the previous value (immediate edge), OR
2. The value changed two cycles ago but remained stable last cycle (filtered edge)

This provides some basic glitch filtering while still detecting all real edges. Each bit has its own 3-bit shift register, and we use combinational logic to detect transitions in this history window.
