Refactoring Approach:
1. Maintain the same XOR-based edge detection logic for correctness
2. Split the sequential and combinational logic into separate blocks for clarity
3. Use continuous assignment (assign) for the combinational XOR operation
4. Keep the sequential storage (prev_in) in a dedicated always block
5. Register the output separately to maintain clean timing
6. This separation makes the design more modular and easier to analyze

Key Changes:
- Combines combinational logic (XOR) with continuous assignment
- Sequential elements remain in always blocks
- Clear separation of concerns between combinational and sequential logic
- Output is registered for better timing characteristics
- Functionally identical to original but with improved modularity
