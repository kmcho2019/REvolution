Refactoring Approach:
1. Maintain the same edge detection logic (XOR between current and previous input)
2. Separate combinational and sequential logic for clarity
3. Use continuous assignment for the combinational XOR operation
4. Keep the sequential part in a single always block for the register updates
5. This makes the design more modular and easier to understand
6. The functionality remains identical to the original solution

Key Changes:
- Moved XOR operation to continuous assignment
- Kept sequential elements in always block
- Clear separation of combinational vs sequential logic
- Same PPA characteristics expected since synthesis will produce identical hardware
- Improved readability by showing the edge detection logic explicitly
