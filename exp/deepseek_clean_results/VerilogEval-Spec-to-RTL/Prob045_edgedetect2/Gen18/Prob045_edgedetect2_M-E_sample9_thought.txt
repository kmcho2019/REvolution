Novel Approach: Shift Register with Activity-Triggered Edge Detection
1. Instead of continuously checking for edges on all bits, use a shift register to track input history
2. Only activate edge detection logic when input changes are detected (reduces power)
3. Implement a "watchdog" mechanism that periodically checks all bits to catch missed transitions
4. Use a priority encoder to identify which bit changed first when multiple edges occur
5. This approach minimizes switching activity while maintaining edge detection accuracy
