Novel Approach: Multi-Cycle Edge Detection with Shift Register
1. Instead of just comparing current and previous cycle, use a 3-cycle shift register for each bit
2. Detect edges when the middle value differs from either neighbor (past or future)
3. This provides a symmetric edge detection window that can catch glitches
4. The shift register approach could be extended to longer windows if needed
5. Output is still registered for clean timing
6. Maintains same interface but with potentially more robust edge detection

Advantages:
- Can detect edges even if they're not stable for a full cycle
- Symmetric detection window (past and future)
- Easily extensible to longer detection windows
- Still maintains single-clock-domain operation
