Novel Architecture Idea:
1. Instead of using XOR for edge detection, implement a delayed comparison approach
2. Use two registers to store input history (current and previous values)
3. Compare current input with both registers to detect edges
4. This provides a more stable detection mechanism with reduced glitches
5. The dual-register approach helps filter out metastability issues
6. Output is only set when both registers disagree with current input, ensuring robust edge detection
7. This method reduces false positives from intermediate transitions
