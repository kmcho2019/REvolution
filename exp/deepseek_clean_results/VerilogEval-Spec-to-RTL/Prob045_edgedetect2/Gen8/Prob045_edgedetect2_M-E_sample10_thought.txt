Here's a novel approach using a shift register for edge detection:
1. Instead of storing just the previous value, we'll store the last 2 clock cycles of input
2. For each bit, we'll detect edges by checking if the current value differs from either of the two previous values
3. This provides some noise immunity while still detecting edges
4. The output is registered to ensure synchronous behavior
This method could potentially filter out very short glitches while still detecting legitimate edges.
