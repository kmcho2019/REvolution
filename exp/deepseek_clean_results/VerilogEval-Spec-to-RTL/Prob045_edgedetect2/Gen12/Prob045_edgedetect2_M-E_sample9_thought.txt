Here's a novel approach using a shift register for edge detection:
1. Instead of storing just the previous value, we'll store the last two values for each bit
2. This creates a 2-bit history window for each input bit
3. An edge is detected when the two stored bits differ (01 or 10 transition)
4. This eliminates the need for XOR operations and instead uses simple comparison logic
5. The implementation uses parallel processing for all 8 bits while maintaining minimal logic
