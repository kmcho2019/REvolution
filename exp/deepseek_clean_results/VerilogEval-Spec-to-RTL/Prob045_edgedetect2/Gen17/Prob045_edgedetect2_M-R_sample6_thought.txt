Refactoring Approach:
1. Separate the combinational and sequential logic for better modularity
2. Use continuous assignment (assign) for the combinational edge detection logic
3. Keep the sequential part in a single always block for clocked operations
4. Maintain the same functionality of detecting any edge transition
5. Improve readability by clearly separating the XOR operation from the register updates

Key Changes:
- Move edge detection to a continuous assignment
- Keep register updates in always block
- This makes the design more modular and easier to understand
- Functionally equivalent to original solution
- Same PPA characteristics expected
