Here's a novel approach using a lookup table implemented via a case statement. Instead of using logical operations, we'll:
1. Treat the 4 inputs as a 4-bit address (d,c,b,a)
2. Use a case statement to directly map each input combination to the correct output
3. This approach is more explicit and makes the truth table directly visible in the code
4. While it may use more gates in synthesis, it's more maintainable and verifiable
