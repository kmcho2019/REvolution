The original implementation uses a two-level XOR tree structure followed by inversion. We can refactor this to use a single continuous assignment that combines all operations, while maintaining the same functionality. This approach:

1. Eliminates intermediate wires by combining all operations in one expression
2. Maintains the same logical behavior (even parity checker with inverted output)
3. Simplifies the code while keeping it equally readable
4. Still results in efficient hardware implementation (same number of XOR operations)

The refactored version will compute the parity directly in one assignment statement.
