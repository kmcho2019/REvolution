Instead of using XOR gates to compute parity, we can implement the function using a lookup table approach with a 4-to-1 multiplexer. The idea is to:
1. Use inputs a and b as select lines for the mux
2. Encode the truth table outputs for each combination of c and d based on the a,b selection
3. This approach may offer better PPA characteristics in some technologies as it replaces XOR gates with simpler logic

The truth table shows q is 1 when:
- a=0,b=0: q = ~(c | d)
- a=0,b=1: q = c ^ d
- a=1,b=0: q = c ^ d
- a=1,b=1: q = ~(c ^ d)
