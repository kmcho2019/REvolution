The original implementation uses a chain of XOR operations to compute even parity. We can refactor this by:
1. Using an explicit sum of the input bits
2. Comparing the sum against the even cases (0, 2, or 4)
3. Implementing this with a single assign statement using bitwise operations

This approach makes the even-parity-checking behavior more explicit while maintaining the same functionality. The refactored version calculates the sum of 1s in the inputs and checks if it's even by looking at the least significant bit of the sum.
