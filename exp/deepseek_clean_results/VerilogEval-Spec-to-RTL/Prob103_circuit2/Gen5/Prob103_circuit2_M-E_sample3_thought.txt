The waveform shows that q is 1 when the number of 1s in the inputs is even (even parity). Instead of using arithmetic operations, we can implement this using a tree of XOR gates, which is the classic digital design approach for parity checking. The XOR operation has the property that it outputs 1 when an odd number of inputs are 1, so we can chain XORs to check for even parity by inverting the final result.
