The original implementation uses a cascaded ternary operator which creates a long chain of comparisons. We can refactor this to use a case statement inside an always block, which:
1. Makes the code more readable and maintainable
2. Potentially allows for better synthesis optimization
3. Still directly implements the truth table specification
4. May result in better timing characteristics as the case statement can be implemented as a balanced tree
5. Maintains the same functional behavior while improving code structure
