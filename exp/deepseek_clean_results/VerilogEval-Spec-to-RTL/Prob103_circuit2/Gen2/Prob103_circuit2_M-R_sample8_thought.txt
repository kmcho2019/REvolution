The original implementation uses a chain of XOR operations to compute even parity. We can refactor this to use a more explicit approach by:
1. First counting the number of 1s in the inputs by summing them
2. Then checking if this sum is even (sum % 2 == 0)
3. This makes the parity check more explicit and readable while maintaining the same functionality

The implementation will use intermediate wires for the sum and parity check, making the logic clearer while still being combinational.
