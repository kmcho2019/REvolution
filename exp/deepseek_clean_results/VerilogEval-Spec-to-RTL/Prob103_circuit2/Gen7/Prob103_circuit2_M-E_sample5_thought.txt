Here's a novel approach using a lookup table implemented with a case statement. This method:
1. Treats the 4-bit input combination as an address to a 16-entry truth table
2. Directly maps each input combination to the corresponding output value
3. Provides explicit visibility into all possible input/output relationships
4. Could be more area-efficient in some FPGA architectures that have built-in LUTs
5. Makes the truth table immediately visible in the code for verification
6. Could potentially be more power-efficient for certain input distributions
