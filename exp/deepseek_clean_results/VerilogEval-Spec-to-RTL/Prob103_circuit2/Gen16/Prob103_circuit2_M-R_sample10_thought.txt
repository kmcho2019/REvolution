The original implementation uses explicit XOR gates and intermediate wires. We can refactor this to:
1. Use a single continuous assignment with nested XOR operations
2. Eliminate the intermediate wire declarations
3. Maintain the same functionality (even parity detection)
4. Make the code more concise while keeping it readable

The refactored version combines all XOR operations in one line and inverts the result directly. This reduces the number of explicit wire declarations while maintaining the same logical behavior.
