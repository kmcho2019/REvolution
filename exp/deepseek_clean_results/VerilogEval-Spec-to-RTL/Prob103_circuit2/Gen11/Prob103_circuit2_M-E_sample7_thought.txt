An alternative approach is to implement the logic using a lookup table (LUT) style implementation. We can concatenate the inputs to form a 4-bit address and use this to index into a precomputed truth table stored in a case statement. This approach is more explicit about the desired functionality and can be more readable for complex truth tables. While it may not be as gate-efficient as the XOR chain, it clearly maps the specification and can be easily modified if requirements change.
