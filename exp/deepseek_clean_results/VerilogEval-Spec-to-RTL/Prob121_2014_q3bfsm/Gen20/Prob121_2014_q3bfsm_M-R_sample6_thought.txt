Refactored design approach:
1. Use a one-hot encoding scheme for state representation to potentially improve timing and power characteristics
2. Implement the state transitions using parallel assign statements for each state bit
3. Separate the state register and next state logic clearly
4. Maintain the same output behavior but compute it directly from state bits
5. Keep synchronous reset functionality

Key changes:
- One-hot encoding (5 bits for 5 states) for potentially better timing
- Next state logic implemented as parallel assignments for each state bit
- Output logic remains simple combinational
- Same state transitions and outputs preserved
- May have better timing characteristics due to simpler decoding logic
