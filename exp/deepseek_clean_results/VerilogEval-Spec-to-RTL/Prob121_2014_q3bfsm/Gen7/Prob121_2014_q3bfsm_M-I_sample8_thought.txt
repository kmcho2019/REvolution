To optimize the FSM for better PPA (Power, Performance, Area) metrics while maintaining functionality:

1. Performance Optimization:
   - Switch to one-hot encoding (5 bits for 5 states) to reduce combinational logic depth
   - This simplifies state decoding and next-state logic

2. Power Optimization:
   - Register the output 'z' to eliminate combinational glitches
   - One-hot encoding naturally reduces switching activity (only 1 bit changes per transition)

3. Area Optimization:
   - Despite using more flip-flops (5 vs 3), one-hot can reduce combinational logic area
   - Simplified next-state logic due to one-hot properties

4. Implementation:
   - Use explicit one-hot state parameters for clarity
   - Maintain synchronous reset
   - Register output to prevent glitches
   - Simplify next-state logic using one-hot properties

Key Benefits:
- Better timing due to simpler state decoding
- Lower dynamic power from reduced switching activity
- Maintainable code with clear state definitions
- Glitch-free registered output
