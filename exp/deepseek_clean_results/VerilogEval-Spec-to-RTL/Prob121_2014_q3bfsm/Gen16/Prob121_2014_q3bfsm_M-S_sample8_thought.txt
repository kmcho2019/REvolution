To simplify the FSM implementation while maintaining functionality:
1. Remove parameterized states since the state encoding is already minimal (3 bits for 5 states)
2. Combine next state and output logic into a single always block for compactness
3. Keep synchronous reset behavior
4. Use direct state assignments (binary) instead of parameters
5. Maintain same output logic but as continuous assignment

This reduces:
- Number of lines of code
- Parameter declarations
- Separate always blocks
While keeping:
- Correct state transitions
- Synchronous reset
- Same output behavior
