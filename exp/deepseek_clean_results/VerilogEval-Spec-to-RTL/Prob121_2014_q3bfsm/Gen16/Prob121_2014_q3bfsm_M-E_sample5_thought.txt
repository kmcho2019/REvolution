I'll implement a novel "parallel state evaluation" approach that:
1. Uses combinatorial logic to evaluate all possible next states simultaneously
2. Employs a priority encoder to select the correct next state based on current state and input
3. Implements output logic using direct state pattern matching
4. Maintains synchronous reset behavior

Key advantages:
- Potentially faster next-state evaluation due to parallel computation
- More scalable for larger state machines
- Clear separation of state transition rules
- Uses bitwise operations for efficient implementation
