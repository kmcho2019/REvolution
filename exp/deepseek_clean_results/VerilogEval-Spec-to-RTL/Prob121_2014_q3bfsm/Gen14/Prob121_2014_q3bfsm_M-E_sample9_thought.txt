Novel approach: Implement the FSM using a ROM-based design where:
1. The current state and input x form a 4-bit address (3 bits state + 1 bit x)
2. A ROM stores the next state and output values
3. The ROM is implemented as a case statement in Verilog
4. Output z is registered to improve timing

Benefits:
- More scalable for larger FSMs
- Clear separation of state transition logic
- Output registration helps meet timing constraints
- Easier to modify state transitions (just update ROM contents)
