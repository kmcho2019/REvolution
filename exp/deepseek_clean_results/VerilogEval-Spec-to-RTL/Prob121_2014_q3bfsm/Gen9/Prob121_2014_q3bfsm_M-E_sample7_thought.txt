Instead of using explicit state encoding, I'll implement the FSM using a counter-based approach where:
1. Each state is represented by a unique count value (0-4)
2. A combinational block maps current count + input to next count
3. Output is generated based on current count value
4. Reset synchronously sets count to 0 (state 000)

Key advantages:
- Eliminates need for explicit state encoding parameters
- Uses simple arithmetic for state transitions
- Output logic becomes trivial count value comparison
- Easily scalable if more states are added later
- Potentially better synthesis results due to simpler logic
