To optimize the FSM implementation for better PPA (Power, Performance, Area) metrics, I'll implement the following improvements:

1. State Encoding: Switch to one-hot encoding (5 bits for 5 states) to improve timing performance by simplifying the next-state logic and reducing fan-out.

2. Output Logic: Maintain the simple combinational output but make it more efficient by directly decoding the one-hot states.

3. Reset Handling: Keep synchronous reset as specified.

4. Power Optimization: One-hot encoding naturally reduces switching activity since only one bit changes per transition.

5. Area Consideration: While one-hot uses more flip-flops, the simpler combinational logic may offset this cost.

Key improvements:
- One-hot encoding for better timing (reduced critical path)
- Direct state decoding simplifies next-state logic
- Reduced switching activity for lower power
- Maintains all original functionality while being more efficient
