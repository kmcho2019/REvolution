To simplify the FSM implementation while maintaining functionality:
1. Keep the same state encoding since it's already minimal (3 bits for 5 states)
2. Remove the redundant default case since all states are explicitly covered
3. Combine the state transition and output logic into a single always block for sequential logic
4. Use direct state comparisons for output 'z' since there are only two states where z=1
5. Eliminate the separate next_state register by computing transitions directly in the sequential block

This reduces:
- One always block (combinational next_state logic)
- The next_state register
- Makes the code more compact while maintaining identical functionality
