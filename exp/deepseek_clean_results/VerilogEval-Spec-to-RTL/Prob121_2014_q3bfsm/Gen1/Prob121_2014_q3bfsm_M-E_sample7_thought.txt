Here's a novel approach using a two-process FSM design with one-hot encoding:
1. Use one-hot encoding for state representation (5 states = 5 bits)
2. Split the design into two always blocks:
   - One for sequential state updates
   - One for combinational next-state and output logic
3. Implement output as a registered signal to improve timing
4. Use parallel case synthesis directive for better optimization
5. Explicitly define all state transitions for clarity
