Novel approach: Implement the FSM using a ROM-based design where:
1. The current state and input x form a combined address to lookup next state and output
2. Use a 32x4 ROM (5-bit address = 3-bit state + 1-bit x, 4-bit output = 3-bit next state + 1-bit z)
3. Synchronous reset initializes state to 000
4. ROM contents directly encode the state transition table
This approach replaces combinational logic with a memory lookup, potentially offering better timing characteristics and more predictable synthesis results.
