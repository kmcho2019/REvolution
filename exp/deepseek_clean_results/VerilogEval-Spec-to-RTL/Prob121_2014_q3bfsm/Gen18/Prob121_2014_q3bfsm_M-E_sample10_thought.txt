Novel approach: Implement the FSM using a ROM-based design where:
1. Current state and input form a combined address to lookup next state and output
2. ROM contents are initialized according to the state transition table
3. Uses synchronous ROM (registered output) for better timing
4. Output z is directly derived from ROM data
5. Reset initializes the state to 000

Benefits:
- More scalable for larger FSMs
- Easier to modify state transitions (just change ROM contents)
- Potentially better timing due to registered ROM output
- Clear separation of control and data path
