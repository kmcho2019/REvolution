To implement the finite-state machine (FSM) described, we'll follow these steps:
1. Define a 3-bit state register (y[2:0]) to store the current state.
2. Use synchronous reset to initialize the state to 000 when reset is high.
3. Create combinational logic to determine the next state based on the current state and input x.
4. Create combinational logic to determine the output z based on the current state.
5. Update the state register on the positive edge of the clock.

The state transitions and output are directly implemented according to the given state-assigned table.
