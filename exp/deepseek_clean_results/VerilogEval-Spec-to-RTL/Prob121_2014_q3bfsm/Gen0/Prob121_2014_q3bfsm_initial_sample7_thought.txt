To implement the finite-state machine (FSM) described, we need to:
1. Define a 3-bit state register to hold the current state (y[2:0])
2. Create combinational logic for the next state based on the current state and input x
3. Implement synchronous reset functionality that sets the state to 000 when reset is high
4. Generate output z based on the current state (combinational output)
5. Update the state register on every positive clock edge

The FSM will have 5 states (000, 001, 010, 011, 100) with transitions and outputs as specified in the state-assigned table.
