Refactored design approach:
1. Separate the state transition logic and output logic into distinct always blocks for better modularity
2. Use a parameterized state encoding for better readability and maintainability
3. Implement next-state logic using continuous assignments (assign statements) instead of a case statement
4. Keep output logic combinational but move it to a separate assign statement
5. Maintain synchronous reset functionality

Key changes:
- State encoding is now parameterized for clarity
- Next-state logic uses assign statements with conditional operators
- Output logic remains combinational but is more explicitly separated
- Same state transitions and outputs preserved
- Potentially better for synthesis optimization due to separated logic blocks
