Instead of using conventional state encoding, I'll implement a counter-based FSM where:
1. Each state is represented by a unique count value (0-4)
2. A decoder converts the count to the required 3-bit state encoding
3. Next state logic is simplified to increment/decrement based on x
4. Output is generated directly from the count value

Benefits:
- Reduced combinational logic complexity in state transitions
- Easier to pipeline if needed
- More scalable for larger state spaces
- Potential power savings from simpler transition logic
