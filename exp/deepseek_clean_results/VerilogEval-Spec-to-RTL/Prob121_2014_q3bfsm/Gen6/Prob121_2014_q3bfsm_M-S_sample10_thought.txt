To simplify the FSM implementation while maintaining functionality:

1. **Remove Parameterization**: Eliminate the state parameters since they add unnecessary abstraction for such a small FSM with direct state encodings.

2. **Direct State Encoding**: Use the raw state values (3'b000, etc.) directly in the logic for clarity and simplicity.

3. **Combine Logic**: Move the next-state logic directly into the sequential block, eliminating the separate combinational assignment. This reduces signal declarations and makes the code more compact.

4. **Simplify Output Logic**: Keep the simple OR-based output logic as it's already minimal.

The simplified version maintains identical functionality while:
- Reducing lines of code
- Eliminating unnecessary intermediate signals
- Making the state transitions more immediately visible
- Keeping the same timing characteristics
