Novel architectural idea: Implement the FSM using a ROM-based approach where:
1. The current state and input form an address to lookup the next state and output
2. Use a combinational ROM (implemented as a case statement) for next state logic
3. Output is directly embedded in the ROM data
4. Advantages:
   - Eliminates complex next-state logic gates
   - Simplifies timing analysis (single lookup operation)
   - Easy to modify state transitions (just update ROM contents)
   - Output logic is merged into state transitions
5. Tradeoffs:
   - Slightly larger area due to wider ROM data
   - But better timing due to reduced logic levels
