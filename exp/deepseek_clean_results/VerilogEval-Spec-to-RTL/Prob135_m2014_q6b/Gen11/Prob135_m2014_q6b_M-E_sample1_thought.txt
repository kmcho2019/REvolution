1. Creates a truth table mapping current state (y) and input (w) to next y[1]
2. Derives minimal Boolean expressions using Karnaugh maps
3. Implements the logic using basic gates for potential area optimization
4. Maintains the direct output assignment for Y1

- y[1] is affected by bits y[2], y[1], y[0] and w
- We can express y1_next as a function of these variables
