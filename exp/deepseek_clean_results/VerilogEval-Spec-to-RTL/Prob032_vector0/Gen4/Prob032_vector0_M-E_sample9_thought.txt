Here's a novel approach using a parameterized generate block to create the individual bit outputs. This method:
1. Uses a generate-for loop to automatically connect each bit of the input vector to its corresponding output
2. Maintains the direct vector assignment for outv
3. Demonstrates how scalable the design could be if we needed to handle larger vectors
4. Shows an alternative structural implementation style while maintaining the same functionality

This approach is particularly interesting because:
- It scales automatically with vector size
- Shows a different coding style (structural with generate)
- Still maintains optimal PPA since it's just wiring
- Demonstrates Verilog's flexibility in implementation choices
