Novel Architectural Idea: Parallel Shadow Register Architecture
1. Implement a shadow register that captures the input vector in parallel
2. Use the shadow register to drive both the vector output and individual bit outputs
3. This creates a clean separation between input capture and output generation
4. The architecture provides potential for adding synchronization or pipelining in future iterations
5. While functionally equivalent to direct wiring, this approach demonstrates register-based design principles
6. The shadow register acts as a single source of truth for all outputs
