Novel Architectural Idea: "Parallel Shadow Register" Approach
1. Instead of direct wiring, implement a shadow register that captures the input vector
2. The shadow register updates on an implicit virtual clock (though no actual clock is needed)
3. Outputs are driven from this shadow register, creating a conceptual pipeline stage
4. This approach mimics real-world systems where inputs might be sampled before processing
5. The architecture provides a clear separation between input capture and output driving
6. While functionally equivalent to direct wiring, this demonstrates good design principles for more complex systems
