The task requires creating a module that takes a 3-bit input vector and produces two types of outputs:
1. A direct 3-bit output of the input vector (outv)
2. Three separate 1-bit outputs (o2, o1, o0) corresponding to each bit of the input vector

The solution involves simple wire connections:
- outv gets assigned the entire input vector
- Each individual output (o2, o1, o0) gets assigned to the corresponding bit of the input vector (vec[2], vec[1], vec[0] respectively)
