The problem requires a module that takes a 3-bit input vector and produces two types of outputs:
1. A direct 3-bit output of the input vector (outv)
2. Three separate 1-bit outputs (o2, o1, o0) corresponding to each bit of the input vector

The solution is straightforward:
- Connect outv directly to the input vec
- Split the input vector into its individual bits and connect them to o2, o1, o0 respectively
- Note that vec[2] is the MSB (position 2) and should connect to o2, while vec[0] is the LSB (position 0) connecting to o0
