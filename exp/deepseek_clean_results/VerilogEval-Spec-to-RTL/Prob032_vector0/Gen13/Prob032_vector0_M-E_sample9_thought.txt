Novel Approach: Structural Implementation with Explicit Wiring
1. Instead of using continuous assignments, we'll implement this using direct port connections in a structural style
2. Create three separate 1-bit wires that connect directly to the input vector bits
3. These wires will drive both the individual outputs and the output vector
4. This approach makes the physical connections more explicit and may be more intuitive for some synthesis tools
5. The structural style could potentially offer better optimization opportunities in complex designs where this module is instantiated multiple times
