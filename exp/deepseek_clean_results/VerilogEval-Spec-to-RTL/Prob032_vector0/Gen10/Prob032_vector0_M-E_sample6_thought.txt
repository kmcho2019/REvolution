Here's a novel approach using a shift register concept to achieve the same functionality in a more interesting way:

1. Instead of direct assignments, we'll use a shift register to temporarily store and then output the bits
2. The input vector will be loaded into a 3-bit register
3. The register contents will be:
   - Output as a whole to outv
   - Shifted out serially to individual outputs
4. This demonstrates an alternative implementation that:
   - Uses sequential logic (though not strictly necessary here)
   - Shows how the same functionality can be achieved differently
   - Could be extended to handle more complex operations if needed
5. While less efficient for this simple case, it illustrates an important design pattern
