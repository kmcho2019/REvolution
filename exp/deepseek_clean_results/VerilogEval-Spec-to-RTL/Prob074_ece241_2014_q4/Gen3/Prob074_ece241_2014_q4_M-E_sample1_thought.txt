Novel approach: Instead of using separate flip-flops for each gate path, we can implement a time-multiplexed architecture that processes each gate's logic sequentially within a single clock cycle. This reduces flip-flop usage while maintaining the same functionality.

Key features:
1. Uses a 2-bit counter to cycle through the three operations (XOR, AND, OR)
2. Implements a single shared flip-flop that stores the result of the current operation
3. Uses combinational logic to compute all three gate outputs in parallel
4. Stores results in a 3-bit shift register that acts as a pipeline
5. Outputs the NOR of the pipelined results

Advantages:
- Reduced flip-flop count (3 → 1 for main logic + 3 for pipeline)
- Sequential processing allows for potential power savings
- Maintains same cycle-accurate behavior as parallel implementation
- Easier to scale for additional operations
