Alternative approach using a ROM-based state transition table:
1. Precompute all 31 possible state transitions (2^5-1) and store them in a ROM
2. The ROM acts as a lookup table where current state is the address and next state is the data
3. This eliminates combinational logic entirely, replacing it with a simple memory lookup
4. Reset still initializes to 1 (5'b00001)
5. Advantages:
   - Predictable timing (single memory access)
   - Easier to modify tap positions by just changing ROM contents
   - No combinational path between registers
