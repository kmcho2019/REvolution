Novel Architecture: Systolic Array with Parallel Processing
1. Organize the grid into processing elements (PEs) that each handle a 4x4 block
2. Implement a systolic data flow where neighbor information propagates between PEs
3. Each PE computes next state for its block while receiving boundary info from adjacent PEs
4. Use a two-phase update process:
   - Phase 1: Compute neighbor counts for internal cells (no boundary dependencies)
   - Phase 2: Compute neighbor counts for boundary cells using propagated info
5. Optimize by:
   - Sharing boundary computations between adjacent PEs
   - Pipelining the systolic data flow
   - Using carry-save adders for efficient neighbor counting
