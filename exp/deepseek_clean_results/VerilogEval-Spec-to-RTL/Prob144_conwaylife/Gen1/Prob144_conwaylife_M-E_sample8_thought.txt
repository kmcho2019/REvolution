Instead of calculating neighbors for each cell independently, we'll implement a systolic array where neighbor information flows through the grid. Each cell will:
1. Store its current state
2. Propagate its state to adjacent cells through shift registers
3. Accumulate neighbor counts over multiple cycles
4. Update its state based on accumulated counts

Key innovations:
- Neighbor information is propagated over 8 cycles (one for each neighbor direction)
- Each cell maintains a running count of live neighbors
- State updates happen only after all neighbor information is collected
- Uses significantly less combinational logic per cell
- More scalable for larger grids
- Better timing characteristics due to pipelined neighbor counting
