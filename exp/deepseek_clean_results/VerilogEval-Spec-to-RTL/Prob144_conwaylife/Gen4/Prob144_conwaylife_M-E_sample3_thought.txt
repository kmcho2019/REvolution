Instead of calculating neighbors for each cell independently, we'll implement a systolic array where each cell propagates its state to adjacent cells through shift registers. This allows neighbor information to be shared efficiently across the grid.

Key innovations:
1. Each cell maintains a 3x3 window of its neighborhood using shift registers
2. Cells are processed in a wavefront manner, propagating state information
3. Toroidal wrapping is handled naturally by the systolic flow
4. Reduced redundant calculations by sharing neighbor information

Advantages:
- More efficient neighbor counting through information sharing
- Natural handling of toroidal topology
- Pipelined operation improves timing
- Reduced switching activity compared to parallel computation
