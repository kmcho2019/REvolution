To implement Conway's Game of Life with the given specifications, we need to:
1. Handle the 16x16 toroidal grid where edges wrap around
2. For each cell, count its 8 neighbors (considering wrap-around)
3. Apply the game rules based on neighbor count
4. Update the state synchronously on clock edges, with load functionality

The key challenges are:
- Efficient neighbor counting with wrap-around
- Parallel processing of all 256 cells
- Clean implementation of the rules

We'll:
1. Create functions to calculate wrapped indices
2. For each cell, calculate neighbor count using these indices
3. Apply rules to determine next state
4. Use a register with load enable to store the state
