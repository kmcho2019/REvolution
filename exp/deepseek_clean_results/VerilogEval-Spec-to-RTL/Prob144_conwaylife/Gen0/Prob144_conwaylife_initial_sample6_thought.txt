To implement Conway's Game of Life with the given specifications, we need to:
1. Handle the synchronous load operation when 'load' is high
2. For normal operation, compute the next state based on neighbor counts:
   - For each cell, count its 8 neighbors (with toroidal wrapping)
   - Apply the rules based on neighbor count
3. Use a combinational block to calculate next state and a sequential block to update the state on clock edges

The key challenge is efficiently calculating neighbor counts with toroidal wrapping. We'll create a function to get any cell's value with automatic wrapping, then use this to count neighbors for each cell.
