To implement Conway's Game of Life on a 16x16 toroidal grid, we need to:
1. Handle the synchronous load operation to initialize the grid
2. For each cell, calculate its next state based on its 8 neighbors (with wrap-around)
3. Implement the neighbor counting logic considering the toroidal topology
4. Apply the game rules based on neighbor count
5. Update the grid state synchronously on each clock edge

The key challenge is efficiently calculating neighbor counts for all 256 cells while handling the toroidal wrap-around. We'll create a function to get the value of any cell (with wrap-around) and use it to count neighbors for each cell.
