To implement Conway's Game of Life on a 16x16 toroidal grid, we need to:
1. Store the current state in a 256-bit register
2. For each cell, calculate its next state based on neighbor counts:
   - Handle toroidal wrapping for edge/corner cells
   - Count live neighbors (8 possible for each cell)
   - Apply rules based on neighbor count
3. Update the state synchronously on clock edges
4. Support synchronous load functionality

Key considerations:
- Need neighbor counting logic for all 256 cells
- Must handle toroidal wrapping when accessing neighbors
- Use combinational logic for next state calculation
- Register update happens on clock edge with load priority
