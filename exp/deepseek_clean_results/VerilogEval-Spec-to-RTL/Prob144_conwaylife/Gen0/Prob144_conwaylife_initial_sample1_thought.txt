To implement Conway's Game of Life with the given rules on a 16x16 toroidal grid, we need to:
1. Handle the load signal to initialize the grid
2. For each cell, calculate its 8 neighbors with wrap-around (toroidal) behavior
3. Count the number of live neighbors for each cell
4. Apply the transition rules based on neighbor count
5. Update the entire grid synchronously on each clock edge

The key challenges are:
- Implementing toroidal neighbor calculation (wrapping around edges)
- Efficiently counting neighbors for all 256 cells
- Applying the rules and updating state synchronously
