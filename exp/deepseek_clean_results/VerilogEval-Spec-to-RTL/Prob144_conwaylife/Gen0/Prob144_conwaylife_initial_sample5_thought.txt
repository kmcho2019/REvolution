To implement Conway's Game of Life with the given rules on a 16x16 toroidal grid, we need to:
1. Handle the load operation to initialize the grid
2. For each cell, compute its next state based on its 8 neighbors (with wrap-around)
3. Update the grid synchronously on each clock edge

The key challenges are:
- Implementing toroidal neighbor calculation (wrapping around edges)
- Efficiently counting live neighbors for each cell
- Applying the game rules to determine next state

We'll:
1. Use a combinational block to calculate next state for all cells
2. For each cell, compute neighbor indices with modulo arithmetic for wrapping
3. Count live neighbors and apply rules
4. Use a sequential block to update state on clock edge (with load priority)
