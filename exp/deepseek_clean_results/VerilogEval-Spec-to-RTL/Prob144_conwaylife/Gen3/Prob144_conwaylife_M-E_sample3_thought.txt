Instead of calculating neighbors for each cell independently, we'll implement a systolic array where each cell passes its state to its neighbors in a coordinated fashion. This reduces redundant calculations and improves timing by:
1. Using shift registers to propagate cell states to neighbors
2. Implementing a 3-stage neighbor counting pipeline
3. Sharing common neighbor calculations between adjacent cells

Key innovations:
- Neighbor state propagation through shift registers
- Pipelined neighbor counting to improve timing
- Shared intermediate results between cells
- Reduced arithmetic operations through bitwise counting
