This novel approach uses a shift register concept to extract the bytes:
1. Instead of direct bit selection, we'll use right-shift operations
2. For the upper byte: Shift right by 8 bits then mask
3. For the lower byte: Simply mask the input
4. Benefits of this approach:
   - Demonstrates an alternative way to think about byte extraction
   - Shows how shift operations can be used for field extraction
   - Maintains combinational nature while using different operations
   - Could be extended to more complex extraction patterns
   - Useful educational example for showing multiple ways to achieve same result
