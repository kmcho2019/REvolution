The original solution is already optimal for PPA (Power, Performance, Area) since:
1. It uses direct bit-slicing which requires no logic gates (minimal area)
2. The combinational path has zero delay (optimal timing)
3. No unnecessary components are present (minimal power)

However, we can make one micro-optimization by:
1. Using explicit wire declarations for outputs to make the design intent clearer
2. Grouping the assignments for better readability
This doesn't change the PPA metrics but improves code maintainability.
