Instead of using direct part-select assignments, we can implement the byte splitting using explicit wire connections between individual bits. This approach:
1. Creates a more structural representation of the circuit
2. Makes each bit connection explicitly visible
3. Could potentially offer better optimization opportunities for synthesis tools
4. Provides a different implementation style that might be preferred in certain design methodologies

The implementation:
- Uses generate-for loops to connect each bit individually
- Maintains the same functionality but with a different structural representation
- Still results in optimal PPA metrics as it's fundamentally the same connections
- Offers better visibility into the bit-level connections
