Here's a novel approach using a parameterized shift-and-mask technique. Instead of direct bit slicing, we'll:
1. Right-shift the input by 8 bits to get the upper byte (out_hi)
2. Mask the lower 8 bits to get out_lo
3. Use a generate block to make the design more flexible for different bit widths
4. Implement the masking using bitwise AND with a parameterized mask value
This approach demonstrates an alternative method to achieve the same functionality while being more explicit about the byte extraction operations.
