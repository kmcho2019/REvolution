Instead of direct bit-slicing, we'll implement a shift-based approach that:
1. Uses right-shift operations to extract the upper byte
2. Masks the lower byte using bitwise AND
3. Demonstrates an alternative way to achieve the same result
4. While functionally equivalent, this shows how the same operation can be implemented differently

This approach is less efficient in terms of PPA metrics but serves as an educational example of alternative implementations. It uses explicit operations instead of direct bit selection.
