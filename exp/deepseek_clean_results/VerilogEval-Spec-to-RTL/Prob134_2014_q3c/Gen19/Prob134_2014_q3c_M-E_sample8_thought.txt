Novel Approach: State Transition Matrix with Parallel Logic

Instead of using cascaded conditionals or case statements, we can implement the FSM using a parallel computation approach that:
1. Creates a 5x2 matrix of possible next states (5 states x 2 input conditions)
2. Uses bitmask matching to select the correct next state
3. Computes outputs through pattern matching

Advantages:
- More scalable for larger state machines
- Potentially better timing due to parallel computation
- Clear separation of state transition logic
- Easier to modify if state table changes

Key Features:
- Pre-computes all possible next states in parallel
- Uses bitwise operations for efficient state matching
- Output logic uses simple pattern matching
