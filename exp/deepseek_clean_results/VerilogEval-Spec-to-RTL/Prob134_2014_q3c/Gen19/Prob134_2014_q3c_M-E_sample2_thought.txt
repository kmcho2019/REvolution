Instead of using cascaded conditional statements, we can implement the FSM using a compact lookup table approach. This offers several advantages:

1. **Uniform Delay Path**: All state transitions will have equal propagation delay since they're all derived from the same LUT access.

2. **Scalability**: Adding more states would only require expanding the LUT, not redesigning the logic.

3. **Area Efficiency**: The LUT can be optimized by sharing common patterns between x=0 and x=1 cases.

4. **Clear State Mapping**: The LUT directly represents the state transition table, making the code more maintainable.

Implementation details:
- Create two 5-entry LUTs (one for x=0, one for x=1) that encode both next state and output
- Use y[2:0] as index into the LUTs
- Multiplex between the two LUTs based on x
- Extract Y0 from the selected next state
- Generate z output based on current state
