This implementation uses a hierarchical multiplexer tree to decode the FSM transitions:
1. Instead of a flat LUT or case statements, we build a decision tree that first checks the current state (y), then the input (x)
2. Each level of the tree is implemented using 2:1 multiplexers
3. The output z is generated in parallel with the next state
4. The design naturally prunes unused states (101-111) by not including them in the decision tree
5. Y0 is extracted directly from the next state computation

Advantages:
- More hardware-efficient than LUT approach
- Naturally optimizes for common cases (states 000-100)
- Clear physical mapping to actual hardware structures
- Better timing characteristics due to balanced decision tree
