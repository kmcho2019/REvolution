To optimize the FSM implementation for better PPA (Power, Performance, Area), I'll make the following improvements:

1. **Replace LUT with direct combinational logic**:
   - Use case statements instead of LUT for more efficient synthesis
   - This reduces area by eliminating the memory structure
   - Improves timing by removing the LUT access delay

2. **Simplify state encoding**:
   - Keep the existing 3-bit encoding but optimize the logic
   - Remove unused states (5-7) from consideration

3. **Combine next state and output logic**:
   - Calculate both next state and output in one pass
   - Use parallel case synthesis pragma for better optimization

4. **Remove initialization block**:
   - Not needed for actual hardware implementation
   - State initialization should be handled by reset if needed

These changes will:
- Reduce area by eliminating the LUT memory
- Improve timing with direct combinational paths
- Maintain the same functionality while being more hardware-efficient
