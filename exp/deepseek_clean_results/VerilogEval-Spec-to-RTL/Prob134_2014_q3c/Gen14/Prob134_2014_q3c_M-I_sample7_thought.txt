The current LUT-based solution works but can be optimized for better PPA. Here's the improvement strategy:

1. **Replace LUT with direct combinational logic**:
   - Use case statements instead of LUT for more efficient synthesis
   - This eliminates the memory array overhead and reduces area

2. **Simplify state encoding**:
   - Keep the same state encoding but implement transitions directly
   - Combine next state and output logic in a single always block

3. **Remove unused states**:
   - Don't implement default cases for unused states (5-7)
   - Let synthesis optimize these cases

4. **Direct assignment**:
   - Assign Y0 directly from the next state bits
   - No need for intermediate wires

Benefits:
- Reduced area by eliminating LUT storage
- Lower power due to simpler combinational logic
- Same or better timing performance
- More standard FSM implementation style
