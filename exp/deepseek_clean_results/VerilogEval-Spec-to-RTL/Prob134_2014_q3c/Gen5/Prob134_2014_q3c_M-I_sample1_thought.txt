To optimize the FSM implementation for better PPA (Power, Performance, Area), I'll make the following improvements:

1. **Replace LUT with direct combinational logic**:
   - Use case statements instead of LUT for more efficient hardware mapping
   - Eliminate unnecessary memory storage and initialization
   - Reduce power consumption by removing unused states

2. **Simplify state encoding**:
   - Keep only the 5 valid states (000-100)
   - Remove default cases since invalid states should never occur

3. **Direct output assignment**:
   - Compute next state and output directly from inputs
   - Avoid intermediate storage/wires where possible

4. **Better timing characteristics**:
   - Combinational logic will have shorter critical path than LUT access
   - No initialization overhead at time 0

The improved version will use parallel case statements for both next state and output logic, which typically synthesizes to more efficient hardware in modern tools.
