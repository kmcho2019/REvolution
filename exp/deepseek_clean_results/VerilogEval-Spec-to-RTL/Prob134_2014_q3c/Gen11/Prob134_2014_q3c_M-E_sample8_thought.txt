Novel Bit-Sliced FSM Architecture:
1. **Parallel Bit Processing**: Instead of treating the state as a monolithic 3-bit value, process each bit position independently in parallel
2. **Individual Bit Logic**: Derive minimal logic equations for each next-state bit based on current state and input
3. **Output Optimization**: Compute outputs directly from bit-level equations to minimize logic depth
4. **No Case Statements**: Avoid case statements entirely for potentially better synthesis results
5. **Bitwise Next-State**: Calculate each next-state bit separately, then combine them

Key Advantages:
- Potentially better synthesis optimization due to bit-level parallelism
- No priority logic from case statements
- Clear separation of bit-level concerns
- Output logic derived directly from minimal equations
