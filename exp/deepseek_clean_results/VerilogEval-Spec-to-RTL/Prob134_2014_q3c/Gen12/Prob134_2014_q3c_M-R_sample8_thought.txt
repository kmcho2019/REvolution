The refactored version will maintain the same FSM behavior but use a different implementation approach:

1. **State Encoding**: Keep the same state encoding (binary 000-100)
2. **Output Logic**: 
   - Use a single always block for combinational logic (next state and outputs)
   - Replace ternary operators with case statements for better readability
3. **Structural Changes**:
   - Separate next state calculation from output generation
   - Use continuous assignments for outputs derived directly from state
4. **Optimizations**:
   - Eliminate redundant logic by recognizing that Y0 is simply Y[0]
   - Simplify z output using state pattern matching

Key improvements:
- More readable case statement structure
- Clear separation of combinational logic
- Direct assignment of Y0 from next state calculation
