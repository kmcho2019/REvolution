Novel approach: Instead of using a conventional case statement for the FSM, we can implement the state transitions using bitwise operations and multiplexing. This approach leverages the observation that the next state bits can be expressed as logical functions of the current state bits and input x.

Key insights:
1. Each bit of the next state can be computed independently using the current state and x
2. Output z is simply a pattern match on the current state (011 or 100)
3. Y0 is just the LSB of the next state

Advantages:
- More compact logic implementation
- Potential for better optimization during synthesis
- Clearer relationship between inputs and outputs
- Avoids large case statement overhead
