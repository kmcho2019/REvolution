Novel Architectural Idea:
1. Implement the FSM using a ROM-based approach where the next state and output are stored in a lookup table
2. Use the current state (y) and input (x) to form an address for the ROM
3. Store both next state and output (z) in a single ROM word
4. Split the ROM output into next state and output signals
5. This approach minimizes combinational logic and leverages memory efficiency

Advantages:
- Predictable timing characteristics (ROM access is uniform)
- Easy to modify FSM behavior by changing ROM contents
- Potentially lower power if ROM is optimized for the application
- Scalable to larger state machines with minimal changes
