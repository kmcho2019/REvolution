Instead of using a case statement for the next state logic, we can implement the FSM using a truth-table inspired approach with parallel multiplexers. This method:
1. Creates individual bit equations for each next state bit (Y[2:0])
2. Uses the current state bits (y[2:0]) to generate minterms
3. Implements the output z directly as a function of the current state
4. Takes advantage of Verilog's bitwise operations for compact implementation

This approach may offer better optimization opportunities for synthesis tools as it breaks down the logic into parallel bit operations rather than a sequential case statement.
