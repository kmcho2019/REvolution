This solution implements the FSM using a binary decision tree structure that:
1. Organizes state transitions as a series of hierarchical decisions
2. Uses nested conditional operators (?:) to form the decision tree
3. Directly computes next state and output without intermediate storage
4. Optimizes for minimal logic depth by prioritizing most common transitions

Key advantages:
- Naturally maps to hardware multiplexers
- Potentially better timing due to balanced logic depth
- No initialization required (pure combinational logic)
- Easily optimizable by synthesis tools
- Explicitly shows the decision hierarchy
