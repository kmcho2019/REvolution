Instead of using combinational logic, implement the FSM using a small ROM (Read-Only Memory) that stores all possible state transitions and outputs. This approach:
1. Uses the current state and input x as an address to look up next state and output
2. Eliminates complex combinational logic paths
3. Can be more area-efficient for small FSMs
4. Provides deterministic timing characteristics
5. Simplifies modifications as the FSM can be changed by just updating the ROM contents
The ROM is implemented as a case statement for synthesis efficiency.
