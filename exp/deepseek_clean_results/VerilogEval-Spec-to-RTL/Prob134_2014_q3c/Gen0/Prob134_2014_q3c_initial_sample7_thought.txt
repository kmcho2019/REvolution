The problem requires implementing a finite state machine (FSM) with specific next-state and output logic based on the given state transition table. The FSM has 5 states (000 to 100) and transitions based on input x. The output Y0 is the least significant bit of the next state, and output z is determined by the current state.

Design approach:
1. Use combinational logic for next state and output generation based on current state and inputs
2. The next state is selected based on the current state and input x
3. Output Y0 is simply Y[0] of the next state
4. Output z is 1 only when current state is 011 or 100, otherwise 0
5. Register the next state to current state on clock edges
