The problem requires implementing a finite state machine (FSM) with specific next-state and output logic based on the given state transition table. The FSM will have:
1. Current state stored in a register (y[2:0])
2. Next state logic (Y[2:0]) that depends on current state and input x
3. Output z determined by current state
4. Y0 output which is simply Y[0] (LSB of next state)

We'll use combinational logic for next state and output, and sequential logic for state transition on clock edges.
