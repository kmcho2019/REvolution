The problem requires implementing a finite state machine (FSM) with specific next-state and output logic based on the given state transition table. The FSM will have 5 states (000 to 100) and transitions based on input x. The output Y0 is the LSB of the next state, and output z is determined by the current state.

Design approach:
1. Use combinational logic for next state and output generation
2. The next state depends on current state (y) and input x
3. Output Y0 is simply Y[0] (LSB of next state)
4. Output z is 1 only when current state is 011 or 100
5. Use a case statement to handle each current state and x input combination
