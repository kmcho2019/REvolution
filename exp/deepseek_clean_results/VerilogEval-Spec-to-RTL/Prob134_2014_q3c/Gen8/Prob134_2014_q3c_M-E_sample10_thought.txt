Novel Architectural Idea: State Transition Matrix
1. Instead of using sequential case statements or nested conditionals, implement the FSM using a compact state transition matrix
2. Encode the next state logic as a lookup table using concatenated present state and input
3. Use bit-slicing to extract the appropriate next state bits based on the input combination
4. Output logic is simplified by recognizing z is only high in states 3'b011 and 3'b100 (binary 3 and 4)
5. This approach minimizes logic depth and maximizes regularity, potentially improving timing and area

Key Advantages:
- Matrix implementation reduces combinatorial logic depth
- Regular structure improves synthesis predictability
- Easy to modify if state table changes
- Output logic uses simple pattern matching
- No sequential elements needed beyond what's required for state storage
