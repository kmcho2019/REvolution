To simplify the FSM implementation while maintaining functionality:
1. Replace the LUT approach with direct combinational logic using case statements
2. Handle next state and output generation in a single always block
3. Eliminate unnecessary initialization and default cases since only 5 states are valid
4. Extract Y0 directly from the next state calculation

Advantages:
- More straightforward implementation
- Eliminates unused LUT entries
- Reduces area by removing the LUT structure
- Maintains clear state transition logic
