To simplify the FSM implementation while maintaining functionality:

1. **Remove redundant registers**: Since we only need combinational logic for next state and output, we can use continuous assignments instead of procedural blocks.

2. **Simplify output logic**: The outputs can be directly derived from the inputs using conditional expressions without needing a case statement.

3. **Minimize state handling**: Only implement the specified states (000-100) since other states are undefined in the problem.

4. **Direct bit assignment**: The Y0 output is simply the LSB of the next state, which can be assigned directly.

This approach reduces the code complexity while maintaining the exact same functionality as the original solution.
