Here's a novel approach using multiplexers instead of standard logic gates:
1. Recognize that the output depends primarily on 'a' and 'c' with 'b' as a conditional selector
2. Implement this as a 2:1 mux where:
   - When a=1, output is always 1 (regardless of other inputs)
   - When a=0, output depends on c and b:
     * If b=0, output follows c
     * If b=1, output is 0 (from K-map analysis)
3. This creates a hierarchical mux structure that directly maps the K-map behavior
4. The advantage is potentially better routing and more regular structure in some technologies
5. Don't-cares are handled by choosing the most convenient mux configuration
