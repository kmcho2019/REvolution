An alternative approach is to recognize that the output is 1 in two main cases: when a is 1 (regardless of other inputs), or when b is 0 and c is 1. This can be implemented using a multiplexer-based architecture where we select between these two conditions. The multiplexer will choose between the output of an AND gate (~b & c) and a constant 1, using a as the select signal. This implementation uses the same logic operations but structures them differently, which might have different PPA characteristics in some technologies.
