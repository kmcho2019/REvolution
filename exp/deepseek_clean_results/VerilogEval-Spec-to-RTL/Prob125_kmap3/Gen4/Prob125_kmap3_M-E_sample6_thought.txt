After carefully re-examining the Karnaugh map, I propose a novel approach using a hierarchical multiplexer structure. The key insights are:

1. The output depends heavily on the 'c' input, so we'll use it as the primary selector for a 2:1 mux.
2. When c=0, we need special handling for ab patterns, which we'll implement with a custom decoder.
3. When c=1, the output is simply the OR of a and b, except when ab=00.
4. We'll optimize don't-care conditions to simplify the c=0 case by treating them as 1 when beneficial.

The architecture will:
- Use c to select between two sub-modules
- One sub-module handles c=0 cases with optimized logic
- Another sub-module handles c=1 cases with simple OR logic
- Combine results with a multiplexer
