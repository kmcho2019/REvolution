Novel approach: State encoding optimization with output pre-calculation
1. Instead of traditional one-hot, use a compact 1-bit state encoding (0=A, 1=B)
2. Pre-calculate the next state and output simultaneously in a single combinational block
3. Use a single register to store the state, reducing flip-flop count
4. Implement output as a registered Mealy output for better timing
5. Maintain asynchronous reset functionality

Key advantages:
- Reduced state register overhead (1 bit instead of 2)
- Combined state and output calculation simplifies logic
- Registered output improves timing closure
- Still maintains clear FSM behavior matching specification
