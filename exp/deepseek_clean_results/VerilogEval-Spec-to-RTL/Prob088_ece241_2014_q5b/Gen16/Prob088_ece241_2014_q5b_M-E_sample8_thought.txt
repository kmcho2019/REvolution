Novel Architecture Idea:
1. Instead of traditional one-hot encoding, use a "dual-phase" state representation where the current state is represented by both the current and previous values of a single flip-flop
2. This reduces the number of state registers needed while maintaining similar timing characteristics
3. The output logic is derived directly from the state transition conditions rather than the current state
4. Reset handling is integrated into the state transition logic for cleaner implementation
5. The design leverages the observation that state B is essentially a "toggle" mode where the output is the inverse of the input

Key Advantages:
- Uses only one state register instead of two (reduced area)
- Output logic is derived from transition conditions (potentially simpler)
- Still maintains clear separation between combinational and sequential logic
- Asynchronous reset is cleanly handled
