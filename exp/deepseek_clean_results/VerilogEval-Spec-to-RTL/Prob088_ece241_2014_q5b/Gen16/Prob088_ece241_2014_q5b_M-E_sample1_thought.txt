Novel approach using edge detection and toggle logic:
1. Instead of traditional FSM states, track the first '1' in the input stream
2. Use a toggle flip-flop that changes state only when the first '1' is detected
3. After the first '1', all subsequent bits are inverted
4. Implement with minimal state (just one flip-flop) and simple combinational logic
5. Maintain asynchronous reset functionality to initialize the state

Key advantages:
- Single state bit instead of two in one-hot
- Simpler output logic (just XOR with state)
- More direct implementation of 2's complement behavior
- Reduced power consumption from fewer state transitions
