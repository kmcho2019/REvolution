Novel approach: State encoding with gray code and output pipelining
1. Use gray code encoding (1-bit) instead of one-hot to reduce state register bits
2. Pipeline the output to improve timing by registering the Mealy output
3. Implement state transitions using a compact combinational logic
4. Maintain asynchronous reset functionality
5. The gray encoding allows simpler state transitions (only 1 bit changes)

Key advantages:
- Reduced state register bits (1 vs 2 in one-hot)
- Pipelined output improves timing closure
- Gray code minimizes switching power during state transitions
- Simpler state transition logic
