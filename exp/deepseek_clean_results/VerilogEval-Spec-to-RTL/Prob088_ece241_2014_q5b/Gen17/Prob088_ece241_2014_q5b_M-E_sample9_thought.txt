Novel Architecture Idea:
1. Shift-Register State Encoding:
   - Instead of traditional one-hot, use a shift register to represent states
   - Current state is represented by which flip-flop is '1' in the shift chain
   - State transitions become simple shift operations

2. Implicit State Transitions:
   - Eliminate explicit next-state logic by using the input to control shifting
   - State B is simply the shifted version of state A

3. Output Generation:
   - Output z is derived directly from the shift pattern and input
   - The shift pattern naturally implements the required output behavior

Key Advantages:
1. Reduced combinational logic (no explicit next-state equations)
2. Natural one-hot property maintained through shift operations
3. Simple, regular structure that scales well to larger state machines
4. Asynchronous reset cleanly initializes to state A
