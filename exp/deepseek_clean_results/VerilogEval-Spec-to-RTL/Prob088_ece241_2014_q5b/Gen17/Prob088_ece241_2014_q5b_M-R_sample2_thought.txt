Refactoring Approach:
1. **State Encoding**: Maintain one-hot encoding but represent states as a 2-bit vector instead of separate registers for better readability and potential optimization.
2. **Combinational Logic**: Move all next-state and output logic to continuous assignments for clearer combinational logic separation.
3. **State Transitions**: Express transitions directly in terms of current state and inputs, making the FSM behavior more explicit.
4. **Reset Handling**: Keep asynchronous reset but initialize the state vector directly.

Key Benefits:
- More compact state representation using a vector
- Clear separation of combinational and sequential logic
- Direct mapping of state transitions to the specification
- Maintains all original functionality while potentially improving synthesis results
