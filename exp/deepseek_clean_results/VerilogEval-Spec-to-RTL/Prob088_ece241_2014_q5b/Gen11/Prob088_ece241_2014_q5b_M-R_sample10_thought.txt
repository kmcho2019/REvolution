Refactoring Strategy:
1. State Representation:
   - Keep one-hot encoding but represent states as a 2-bit vector for better readability
   - Use parameter definitions for state constants
2. Combinational Logic:
   - Move all combinational logic to continuous assignments (assign statements)
   - Simplify state transition logic using bitwise operations
3. Sequential Logic:
   - Maintain async reset functionality but use a single always block
   - Explicitly define state transitions for clarity
4. Output Logic:
   - Express output directly in terms of current state and input

Key Changes:
1. Vectorized state representation with named parameters
2. All combinational logic moved to assign statements
3. Clear separation between state encoding and transition logic
4. Simplified output expression using state bits directly
