Refactoring Strategy:
1. State Representation:
   - Maintain one-hot encoding but represent states as a 2-bit vector for cleaner code
   - Use parameter constants for state definitions
2. Logic Simplification:
   - Combine state transition logic into a single always block
   - Use case statement for clearer state transitions
3. Output Generation:
   - Keep output as combinational logic but express it in terms of current state
4. Reset Handling:
   - Keep asynchronous reset but initialize state vector directly

Key Benefits:
1. More readable state machine structure
2. Clear separation between state encoding and transition logic
3. Easier to extend if more states are needed
4. Maintains same functionality while improving code organization
