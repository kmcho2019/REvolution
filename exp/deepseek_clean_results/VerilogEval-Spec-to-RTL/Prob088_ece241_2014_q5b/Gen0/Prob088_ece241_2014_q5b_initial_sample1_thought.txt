To implement the given Mealy FSM with one-hot encoding, we'll need:
1. Two state registers (A and B) since there are two states
2. Combinational logic for next state transitions based on current state and input x
3. Output z logic based on current state and input x (Mealy machine)
4. Asynchronous reset to initialize to state A (one-hot: A=1, B=0)

The state transitions and outputs are:
- In state A: 
  - x=0: stay in A, z=0
  - x=1: go to B, z=1
- In state B:
  - x=0: stay in B, z=1
  - x=1: stay in B, z=0
