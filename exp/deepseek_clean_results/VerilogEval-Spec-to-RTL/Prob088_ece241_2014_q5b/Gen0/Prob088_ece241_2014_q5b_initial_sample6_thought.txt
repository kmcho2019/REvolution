To implement the given Mealy FSM with one-hot encoding:
1. Use two state registers (state_A and state_B) for the one-hot encoding (A=01, B=10)
2. Implement asynchronous reset to force state to A (01) when areset is high
3. Create next state logic based on current state and input x
4. Output z is a combinational function of current state and input x
5. State transitions occur on positive clock edges
