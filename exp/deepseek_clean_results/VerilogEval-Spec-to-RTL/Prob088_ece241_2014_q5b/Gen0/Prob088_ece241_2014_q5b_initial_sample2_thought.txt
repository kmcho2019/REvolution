To implement the Mealy finite-state machine for a 2's complementer using one-hot encoding:
1. We need two states (A and B) represented as one-hot: A = 01, B = 10
2. The state transitions are:
   - From A: stays in A when x=0 (output z=0), moves to B when x=1 (output z=1)
   - From B: stays in B regardless of x, with output z=~x
3. Asynchronous reset sets the state to A (01)
4. Output z is a combinational function of current state and input x
