To implement the Mealy finite-state machine with one-hot encoding, we'll need:
1. Two state registers (A and B) since there are two states
2. Combinational logic for next state transitions based on current state and input x
3. Output z logic that depends on both current state and input x (Mealy machine characteristic)
4. Asynchronous reset to force state A on areset=1

The one-hot encoding means:
- State A: 01
- State B: 10

The transitions are:
- From A: stay if x=0 (output 0), go to B if x=1 (output 1)
- From B: stay always, output is x's complement (1 when x=0, 0 when x=1)
