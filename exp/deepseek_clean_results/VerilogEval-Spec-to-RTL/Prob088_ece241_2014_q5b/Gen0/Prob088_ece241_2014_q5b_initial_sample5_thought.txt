To implement the Mealy finite-state machine for a 2's complementer with one-hot encoding:
1. Use two states (A and B) represented as one-hot: A=01, B=10
2. Create state registers to hold current state (2 bits for one-hot)
3. Implement asynchronous reset to state A (01)
4. Create next state logic based on current state and input x
5. Implement output z as a combinational function of current state and input x (Mealy machine)
6. Update state registers on positive clock edge
