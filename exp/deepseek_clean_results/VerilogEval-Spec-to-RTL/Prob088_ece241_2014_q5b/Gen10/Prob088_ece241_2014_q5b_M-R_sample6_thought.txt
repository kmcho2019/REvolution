Refactoring Strategy:
1. State Representation:
   - Use a 2-bit one-hot encoding vector instead of separate registers for each state
   - This makes state transitions more explicit and easier to maintain
2. Logic Simplification:
   - Combine next state logic into a single assignment for each state bit
   - Directly derive output from current state and input
3. Structural Changes:
   - Move all combinational logic to continuous assignments
   - Keep only the state update in the sequential block
   - Make state transitions more readable by using explicit conditions

Key Benefits:
1. Clearer state encoding with explicit one-hot vector
2. More compact representation of state transitions
3. Easier to extend if more states are needed
4. Maintains same functionality with potentially better synthesis results
