Refactoring Approach:
1. **State Representation:** 
   - Instead of separate registers for state_A and state_B, use a single 2-bit one-hot state register
   - This makes the state machine more explicit and easier to maintain

2. **Combinational Logic:**
   - Move all next-state logic to continuous assignments (assign statements)
   - Calculate outputs purely combinationally based on current state and inputs

3. **Reset Handling:**
   - Keep asynchronous reset but initialize to state_A (2'b01) explicitly
   - Clear separation between reset and normal operation

Key Benefits:
- More explicit state encoding (easier to read and modify)
- All combinational logic in assign statements (clearer data flow)
- Maintains same functionality with identical PPA characteristics
- Better scalability for adding more states
