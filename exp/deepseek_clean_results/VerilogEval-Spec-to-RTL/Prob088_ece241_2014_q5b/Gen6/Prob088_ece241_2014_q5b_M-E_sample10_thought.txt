Here's a novel approach using a shift register implementation instead of traditional state encoding:

1. Instead of explicit state variables, use a shift register to track the state transitions
2. The shift register will have two positions representing the current and next state
3. The output is generated directly from the shift register contents and input
4. Reset initializes the shift register to represent state A
5. This approach eliminates explicit state transition logic by using physical register shifting

Key advantages:
- No explicit state encoding needed (simplifies design)
- State transitions become simple shift operations
- Output logic remains straightforward
- Potentially better timing as it reduces logic levels between state and output
