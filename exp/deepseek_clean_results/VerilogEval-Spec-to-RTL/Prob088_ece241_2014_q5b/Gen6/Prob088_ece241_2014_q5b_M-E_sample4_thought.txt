Novel architectural idea:
1. Implement true one-hot encoding with two state registers (state_A and state_B)
2. Use parallel state transition logic to exploit one-hot properties
3. Leverage the fact that in one-hot, only one state bit is active at a time
4. Optimize output logic by directly using state bits rather than decoding
5. Asynchronous reset initializes to state_A (01) pattern

Key advantages:
- True one-hot implementation matches specification exactly
- Parallel state transitions simplify next-state logic
- Output logic becomes trivial XOR between state_B and input x
- Clear separation between state encoding and logic
- Easily extensible if more states are added later
