Novel architectural idea:
1. Instead of using traditional state registers, implement the FSM using a shift register approach that inherently enforces one-hot encoding
2. Use two flip-flops (state_A and state_B) where exactly one is always '1'
3. The shift occurs from state_A to state_B when x=1, otherwise stays in current state
4. Output z is derived from the current one-hot state and input x
5. Reset initializes to state_A (10) which is the proper one-hot encoding
6. This approach guarantees true one-hot encoding while maintaining simple logic

Key advantages:
- Strict one-hot encoding compliance
- Simple state transition logic (just shifting when x=1)
- Clear physical meaning of each flip-flop (directly represents a state)
- No need for binary-to-one-hot conversion
- Asynchronous reset properly initializes the one-hot state
