To implement the module TopModule with the given interface and functionality, 
we need to use the logical AND operator in Verilog and apply a logical NOT 
operation (inversion) to the in2 input to account for the bubble. 
The bubble at the in2 input means we need to invert the in2 signal before 
it goes into the AND gate. This can be done using the logical NOT operator (~) 
in Verilog. After inversion, we apply the AND operation with the in1 signal.
