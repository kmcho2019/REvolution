To implement the finite-state machine that searches for the sequence 1101 in an input bit stream, we can design a 4-state machine: idle, seen_1, seen_11, seen_110, and seen_1101. The machine starts in the idle state. When a '1' is seen, it moves to the seen_1 state. From the seen_1 state, if another '1' is seen, it moves to the seen_11 state. From the seen_11 state, if a '0' is seen, it moves to the seen_110 state. From the seen_110 state, if a '1' is seen, it moves to the seen_1101 state. When the seen_1101 state is reached, start_shifting is set to 1 and stays at 1 until reset. Reset is active high synchronous, meaning it only affects the state on the positive edge of the clock when reset is high.
