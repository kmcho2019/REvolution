To implement the TopModule, we need to design a finite-state machine (FSM) that can recognize the sequence 1101 in the input bit stream. The FSM will have states to track the progress of recognizing the sequence. Once the sequence is fully recognized, the FSM will set the start_shifting output to 1 and remain in this state until reset is asserted. We'll use an enumeration of states to make the code more readable. The states will be: IDLE, SEEN_1, SEEN_11, SEEN_110, and SEEN_1101.
