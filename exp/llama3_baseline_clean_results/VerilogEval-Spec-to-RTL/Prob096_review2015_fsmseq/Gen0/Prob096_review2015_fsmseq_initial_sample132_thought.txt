To implement the finite-state machine (FSM) that searches for the sequence 1101 in an input bit stream, we will define four states corresponding to the matched sequence prefix (including the initial state): 
- State 0: Initial state, no prefix matched.
- State 1: Prefix "1" matched.
- State 2: Prefix "11" matched.
- State 3: Prefix "110" matched.
- State 4: Full sequence "1101" matched.

We transition from one state to the next based on the current input bit and the previous state. If the input bit matches the expected next bit in the sequence, we move to the next state. If the sequence is fully matched, we set start_shifting to 1 and stay in that state until reset. Reset is active high synchronous, meaning it resets the FSM to the initial state on the positive edge of the clock when reset is high.
