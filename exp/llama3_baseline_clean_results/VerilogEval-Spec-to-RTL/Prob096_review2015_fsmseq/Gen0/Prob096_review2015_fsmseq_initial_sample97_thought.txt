The finite-state machine can be designed with four states, each corresponding to a prefix of the target sequence 1101. The initial state can be considered as an "idle" state, waiting for the first '1' in the sequence. Once the sequence is fully matched, the state machine transitions to a final state where start_shifting is set to 1. We will use a case statement to define the next state logic and an if statement to define the output logic for start_shifting.
