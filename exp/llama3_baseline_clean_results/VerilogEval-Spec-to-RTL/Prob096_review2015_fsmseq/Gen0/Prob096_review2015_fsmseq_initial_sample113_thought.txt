- Idle: The initial state, waiting for the first '1' in the sequence.
- State1: The first '1' has been found, waiting for the next '1'.
- State2: The first two '1's have been found, waiting for the '0'.
- State3: The '1', '1', '0' have been found, waiting for the final '1'.
- Shift: The entire sequence 1101 has been found, set start_shifting to 1.

We will transition between these states based on the current input data and the current state. When the sequence is found, we will set start_shifting to 1 and remain in the Shift state until reset is asserted.
