To implement the TopModule, we will design a finite-state machine that checks for the sequence 1101 in the input data stream. The FSM will have five states: IDLE, S1, S2, S3, and S4. The IDLE state is the initial state and represents no sequence detected. S1, S2, S3, and S4 represent the detection of the first, second, third, and fourth bits of the sequence, respectively. When the sequence 1101 is detected, the FSM will transition to the S4 state and set start_shifting to 1 forever, until reset is asserted. The FSM will transition back to the IDLE state when reset is asserted. We will use a Mealy machine (output depends on current state and input) to simplify the logic.
