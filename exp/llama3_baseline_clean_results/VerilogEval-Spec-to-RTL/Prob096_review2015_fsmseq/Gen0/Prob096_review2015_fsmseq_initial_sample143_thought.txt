To implement the finite-state machine that searches for the sequence 1101, we will define a series of states that correspond to the detection of each bit in the sequence. The states will be: Idle (looking for the first 1), Found1 (looking for the next 1 after the first 1), Found11 (looking for the next 0 after two 1s), Found110 (looking for the next 1 after the sequence 110), and Final (the sequence 1101 has been found). The state machine will transition between these states based on the input data and will set start_shifting to 1 when it reaches the Final state. The reset will cause the state machine to return to the Idle state.
