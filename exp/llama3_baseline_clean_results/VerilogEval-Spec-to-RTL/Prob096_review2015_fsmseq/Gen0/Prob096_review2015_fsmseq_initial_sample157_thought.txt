To implement the finite-state machine that searches for the sequence 1101 in an input bit stream, we can define a series of states that track the progress of matching the sequence. The states will be:
1. IDLE - initial state, waiting for '1'
2. ONEReceived - received the first '1'
3. ONE_ONEReceived - received the sequence '11'
4. ONE_ONE_ZEROReceived - received the sequence '110'
5. SEQUENCEFound - received the sequence '1101', set start_shifting to 1

We will use a case statement to handle the current state and the input data to decide the next state. If reset is high, we will go back to the IDLE state.
