To implement the TopModule, we will create a finite-state machine (FSM) that checks the input data stream for the sequence 1101. We will define states to track the current sequence of bits seen so far. The FSM will have states to represent seeing '1', '11', '110', and '1101'. Once the sequence '1101' is detected, the start_shifting output will be set to 1 and will remain 1 until a reset is applied. We will use a synchronous reset, meaning the reset will only take effect on the positive edge of the clock.
