To implement the TopModule, we will design a finite-state machine (FSM) with states representing the progress of matching the sequence '1101' in the input data stream. The states can be defined as follows:
- S0: Initial state, no sequence matched
- S1: Matched '1' (first bit of the sequence)
- S2: Matched '11' (first two bits of the sequence)
- S3: Matched '110' (first three bits of the sequence)
- S4: Matched '1101' (entire sequence), set start_shifting to 1 and stay in this state until reset

The FSM will transition between these states based on the current state and the input data. When reset is asserted, the FSM will return to the initial state S0.
