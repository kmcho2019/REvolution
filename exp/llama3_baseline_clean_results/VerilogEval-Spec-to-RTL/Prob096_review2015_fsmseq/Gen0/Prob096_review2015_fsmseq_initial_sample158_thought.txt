The initial state will be idle. When the module is in the idle state, it waits for a '1' to be input. When a '1' is input, it transitions to the got_1 state. Then, it checks for the next '1', and if found, transitions to the got_11 state. From the got_11 state, it checks for the next '0' and if found, transitions to the got_110 state. Finally, from the got_110 state, it checks for the next '1', and if found, transitions to a final state where it sets start_shifting to '1' and remains in this state until reset.
