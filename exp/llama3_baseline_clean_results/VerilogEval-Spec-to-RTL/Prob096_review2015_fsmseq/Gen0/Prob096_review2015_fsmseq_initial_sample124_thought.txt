To implement the finite-state machine in the TopModule, we can define states that correspond to the detection of the sequence 1101 in the input bit stream. We'll use a total of 5 states: IDLE, DETECTED_1, DETECTED_11, DETECTED_110, and DETECTED_1101. The IDLE state is the initial state where we start looking for the sequence. When a '1' is detected in the IDLE state, we move to the DETECTED_1 state. If another '1' is detected in the DETECTED_1 state, we move to the DETECTED_11 state. Then, if a '0' is detected in the DETECTED_11 state, we move to the DETECTED_110 state. Finally, if a '1' is detected in the DETECTED_110 state, we move to the DETECTED_1101 state, where we set start_shifting to 1. We'll also include a reset mechanism that sets the state back to IDLE when reset is high.
