To implement the TopModule, we will use a finite-state machine with multiple states to track the input sequence. We start with an initial state (IDLE) and then transition to other states as we detect each bit of the target sequence (1101). If the input sequence matches the target, we transition to a final state (FOUND) where we set start_shifting to 1. If the input sequence does not match the target at any point, we reset the state machine to the IDLE state. We also implement a reset mechanism that, when asserted, sets start_shifting to 0 and resets the state machine to the IDLE state.
