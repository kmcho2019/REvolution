To implement the finite-state machine, we can use a sequential logic approach where we check each incoming bit and update the state accordingly. We can define four states: IDLE (initial state), S1 (after seeing '1'), S2 (after seeing '11'), S3 (after seeing '110'), and FOUND (after seeing '1101'). We will transition between these states based on the input bit and the current state. When we reach the FOUND state, we set start_shifting to 1 and keep it high until reset is asserted.
