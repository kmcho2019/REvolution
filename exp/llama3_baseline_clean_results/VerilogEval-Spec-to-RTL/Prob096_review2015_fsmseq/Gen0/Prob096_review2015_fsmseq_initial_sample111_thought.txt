The module TopModule will be designed as a finite-state machine with five states: IDLE, SEEN1, SEEN11, SEEN110, and SEEN1101. 
The machine starts in the IDLE state and stays there until it sees the first '1' in the input stream. 
After that, it moves to the SEEN1 state. If it sees another '1' in the SEEN1 state, it moves to the SEEN11 state. 
If it sees a '0' in the SEEN1 state, it returns to the IDLE state. 
This process continues until the machine reaches the SEEN1101 state, at which point it sets start_shifting to 1 and stays in that state until reset. 
The reset signal is active high synchronous, so the machine returns to the IDLE state whenever reset is high.
