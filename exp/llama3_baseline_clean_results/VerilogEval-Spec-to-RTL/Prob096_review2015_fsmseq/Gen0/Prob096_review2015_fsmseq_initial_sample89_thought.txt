To implement the TopModule, we will use a finite-state machine (FSM) with five states: IDLE, S1, S2, S3, and FOUND. The FSM starts in the IDLE state and transitions through the states based on the input data. When the sequence '1101' is detected, the FSM transitions to the FOUND state and sets start_shifting to 1. The FSM remains in the FOUND state until reset is asserted. We will use a Mealy machine model, where the output depends on the current state and the input.
