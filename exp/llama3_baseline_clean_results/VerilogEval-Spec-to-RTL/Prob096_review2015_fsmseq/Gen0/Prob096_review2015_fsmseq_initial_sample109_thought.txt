To implement the finite-state machine, we can design it as a Moore machine, where the output depends solely on the current state. The state machine will have 5 states: 
- IDLE: The initial state, waiting for the first '1' in the sequence.
- S1: The first '1' has been seen.
- S2: The sequence '11' has been seen.
- S3: The sequence '110' has been seen.
- SHIFT: The sequence '1101' has been seen, start shifting.
The state machine will transition between these states based on the input bit stream and reset signal.
