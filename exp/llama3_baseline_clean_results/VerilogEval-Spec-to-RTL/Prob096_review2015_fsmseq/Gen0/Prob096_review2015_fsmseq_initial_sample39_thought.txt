The finite-state machine can be implemented using a series of states that track the current position in the sequence 1101. We will define five states: 
- S0 (initial state): wait for the first '1'
- S1: wait for the second '1' after '1'
- S2: wait for '0' after '11'
- S3: wait for the final '1' after '110'
- S4 (final state): sequence found, set start_shifting to 1

The state machine transitions between these states based on the current input data. If the sequence is found (S4 is reached), start_shifting is set to 1 and stays that way until reset is asserted.
