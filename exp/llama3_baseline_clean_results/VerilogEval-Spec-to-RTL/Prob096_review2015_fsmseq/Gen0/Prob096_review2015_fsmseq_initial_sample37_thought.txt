To implement the TopModule, we will design a finite-state machine (FSM) that searches for the sequence 1101 in the input bit stream. The FSM will have five states: idle, found_1, found_11, found_110, and found_1101. We will use a binary encoded state machine where each state is represented by a binary code. The FSM will transition from one state to another based on the input data and the current state. When the sequence 1101 is found, the FSM will set the start_shifting output to 1 and stay in that state until reset is asserted. We will use a synchronous reset to reset the FSM to the idle state.
