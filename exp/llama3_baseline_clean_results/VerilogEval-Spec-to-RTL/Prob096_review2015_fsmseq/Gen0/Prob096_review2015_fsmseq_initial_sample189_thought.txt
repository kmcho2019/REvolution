To implement the TopModule, we can design a finite-state machine (FSM) with five states: IDLE, SEEN_1, SEEN_11, SEEN_110, and SEEN_1101. The FSM will start in the IDLE state and transition to the next state based on the input data. When the FSM reaches the SEEN_1101 state, it will set start_shifting to 1 and remain in this state until reset. We will use a synchronous reset to reset the FSM to the IDLE state.
