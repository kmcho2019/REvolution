To implement the TopModule, we will design a finite-state machine (FSM) with states that correspond to the partial matches of the target sequence 1101. The FSM will start in an idle state and transition through states as it matches the sequence. Once the full sequence is matched, it will enter a final state where start_shifting is set to 1. The FSM will remain in this state until reset is asserted. We'll use a synchronous reset, which means the reset will only be considered on the positive edge of the clock.
