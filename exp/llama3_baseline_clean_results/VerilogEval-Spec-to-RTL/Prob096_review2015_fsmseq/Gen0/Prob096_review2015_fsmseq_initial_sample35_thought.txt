To implement the TopModule, we'll design a finite-state machine (FSM) that recognizes the sequence 1101 in the input bit stream. The FSM will have five states: IDLE (initial state), S1 (after seeing '1'), S2 (after seeing '1' followed by '1'), S3 (after seeing '1' followed by '1' and then '0'), and FOUND (after seeing the full sequence '1101'). When the FOUND state is reached, the output start_shifting will be set to 1. The FSM will remain in the FOUND state until a reset is applied. We'll use a binary-encoded state representation for simplicity.
