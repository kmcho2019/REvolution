To implement the TopModule, we can use a finite-state machine (FSM) with four states: IDLE, S1, S2, and S3. The FSM starts in the IDLE state and transitions to the next state based on the input data bit. The FSM searches for the sequence 1101 in the input bit stream. When the sequence is found, it sets start_shifting to 1. The FSM remains in this state until reset is asserted. We will use a Mealy machine (output depends on current state and input) for this implementation.
