To solve this problem, we will implement a finite-state machine (FSM) that traverses through states based on the input data. The FSM will have 5 states: Idle, S1, S2, S3, and Shift. The states represent the sequence of bits seen so far. For example, in state S2, we have seen the sequence "11" so far. The FSM will transition between states based on the current state and the input data. When the sequence "1101" is found, the FSM will transition to the Shift state and set start_shifting to 1. The FSM will remain in the Shift state until reset is asserted.
