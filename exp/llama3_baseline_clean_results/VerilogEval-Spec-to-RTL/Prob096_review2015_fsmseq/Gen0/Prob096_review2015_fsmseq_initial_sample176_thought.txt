To implement the TopModule, we will use a finite-state machine (FSM) with five states: IDLE, SEEN_1, SEEN_11, SEEN_110, and SEEN_1101. The FSM will transition between these states based on the input data bit. When the sequence 1101 is detected, the FSM will set the start_shifting output to 1 and remain in the SEEN_1101 state until reset. The reset signal will be used to reset the FSM to the IDLE state.
