To implement the finite-state machine, we can use a Mealy machine with five states: IDLE, GOT_1, GOT_11, GOT_110, and FOUND. The machine starts in the IDLE state. When it receives the input sequence 1101, it transitions to the FOUND state and sets start_shifting to 1. The machine remains in the FOUND state until it is reset. In each state, we check the current input data and transition to the next state accordingly.
