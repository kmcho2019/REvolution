To implement the TopModule, we can design a finite-state machine (FSM) that has five states: IDLE, SEEN1, SEEN11, SEEN110, and FOUND. The FSM starts in the IDLE state and transitions to other states based on the input data. Once the sequence 1101 is found, the FSM moves to the FOUND state and sets start_shifting to 1. The FSM remains in the FOUND state until a reset is applied. We will use a Moore machine, where the output is a function of the current state only, to implement this logic.
