To implement the TopModule, we will design a finite-state machine (FSM) that searches for the sequence 1101 in the input bit stream. The FSM will have five states: Idle, S1, S2, S3, and S4. The FSM starts in the Idle state and transitions to the next state based on the input data. When the sequence 1101 is found, the FSM will set start_shifting to 1 and remain in that state until reset. We will use a synchronous reset to ensure that the FSM resets to the Idle state when the reset signal is high.
