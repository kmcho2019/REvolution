The finite-state machine (FSM) can be implemented with a set of states that represent the current matched sequence. We start with an idle state (S0) and transition to subsequent states (S1, S2, S3, S4) as the sequence 1101 is matched. If the sequence is matched, we transition to a final state (S5) where start_shifting is set to 1. We will use a 3-bit state register to represent the current state and a reset signal to bring the FSM back to the idle state.
