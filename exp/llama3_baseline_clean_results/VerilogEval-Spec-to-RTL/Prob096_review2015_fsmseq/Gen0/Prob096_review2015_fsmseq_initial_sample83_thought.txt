To implement the finite-state machine, we can use a Moore machine approach where the output is determined solely by the current state. The states can represent the partial matches of the target sequence 1101. We start in an idle state (S0) and transition to subsequent states as we match the sequence bit by bit. Once the sequence is fully matched (S4), we set start_shifting to 1. The machine remains in this state (setting start_shifting to 1) until a reset is applied, at which point it returns to the idle state (S0). We use a 2-bit state register to encode the four states (00 - S0, 01 - S1, 10 - S2, 11 - S3, but since we only need 4 states, we can also use 00, 01, 10, and 11 directly without a strict state assignment), and a combinational logic to determine the next state based on the current state and input data.
