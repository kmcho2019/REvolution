To implement the finite-state machine, we can use a state register to keep track of the current state. We will define four states: IDLE, S1, S2, and S3, corresponding to the search for the sequence 1101. When the sequence is found, we transition to the FINAL state, where start_shifting is set to 1. The reset signal will reset the state machine to the IDLE state. We will use a Mealy machine, where the output depends on the current state and input.
