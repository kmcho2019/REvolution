To implement the TopModule, we need to design a finite-state machine (FSM) that searches for the sequence 1101 in the input bit stream. The FSM should have at least five states: Idle, S1, S2, S3, and Found. The Idle state is the initial state. When the FSM is in the Idle state and the input data is 1, it transitions to the S1 state. From the S1 state, if the input data is 1, it transitions to the S2 state. From the S2 state, if the input data is 0, it transitions to the S3 state. From the S3 state, if the input data is 1, it transitions to the Found state. If the sequence is found, the FSM stays in the Found state forever, setting start_shifting to 1, until it is reset. The reset is active high synchronous, so when reset is high, the FSM resets to the Idle state.
