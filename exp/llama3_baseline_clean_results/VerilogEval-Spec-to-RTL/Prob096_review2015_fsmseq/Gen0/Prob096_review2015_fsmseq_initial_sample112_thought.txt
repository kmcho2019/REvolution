To implement the finite-state machine that searches for the sequence 1101 in an input bit stream, we need to design a state machine with five states: IDLE, S1, S2, S3, and FOUND. The state machine transitions through these states based on the input data and the current state. When the sequence 1101 is found, the state machine transitions to the FOUND state and sets start_shifting to 1. The state machine remains in the FOUND state and keeps start_shifting set to 1 until reset is asserted. We use a reset signal to reset the state machine to the IDLE state.
