To implement the TopModule, we can design a finite-state machine with five states: IDLE, GOT_1, GOT_11, GOT_110, and FOUND. 
The machine starts in the IDLE state and transitions to the next state based on the input data. 
If the input data is 1, the machine moves to the GOT_1 state. 
From the GOT_1 state, if the next input data is 1, the machine moves to the GOT_11 state. 
From the GOT_11 state, if the next input data is 0, the machine moves to the GOT_110 state. 
From the GOT_110 state, if the next input data is 1, the machine moves to the FOUND state. 
Once the machine reaches the FOUND state, it sets the start_shifting output to 1 and stays in this state until reset. 
The reset signal is active high and synchronous, meaning it will reset the machine to the IDLE state only on the positive edge of the clock.
