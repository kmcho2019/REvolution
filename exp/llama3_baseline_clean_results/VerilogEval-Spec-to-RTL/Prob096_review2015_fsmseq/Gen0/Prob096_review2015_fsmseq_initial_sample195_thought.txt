The finite-state machine will be implemented with five states: IDLE, SEEN1, SEEN11, SEEN110, and SEEN1101. 
The machine starts in the IDLE state. 
- When in the IDLE state and a 1 is received, the machine transitions to the SEEN1 state.
- When in the SEEN1 state and a 1 is received, the machine transitions to the SEEN11 state.
- When in the SEEN11 state and a 0 is received, the machine transitions to the SEEN110 state.
- When in the SEEN110 state and a 1 is received, the machine transitions to the SEEN1101 state.
- When in the SEEN1101 state, start_shifting is set to 1, and the machine remains in this state until reset.
- If at any point a bit is received that does not match the expected next bit in the sequence, the machine transitions back to the IDLE state, except in the SEEN1101 state.
- The machine also has a reset input that, when high, resets the machine to the IDLE state and clears the start_shifting output.
