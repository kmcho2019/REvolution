To solve this problem, we can design a finite-state machine (FSM) with five states: Idle, One, Ten, OneOne, and OneTenOne. The FSM starts in the Idle state and transitions through the states based on the input data. When the FSM reaches the OneTenOne state, it sets the start_shifting output to 1 and stays in that state until a reset is received. The reset input is active high and synchronous, meaning it only resets the FSM on the positive edge of the clock when reset is high.
