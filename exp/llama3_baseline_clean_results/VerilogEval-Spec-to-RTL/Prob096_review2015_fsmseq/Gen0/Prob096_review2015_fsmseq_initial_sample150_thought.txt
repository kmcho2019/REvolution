To implement the TopModule, we will use a finite-state machine (FSM) with five states: Idle, S1, S2, S3, and Found. 
The FSM starts in the Idle state and moves to the next state based on the input data. 
When the sequence '1101' is detected, the FSM transitions to the Found state and sets start_shifting to 1.
In the Found state, start_shifting remains 1 until the reset signal is asserted.
The FSM is reset to the Idle state when the reset signal is asserted.
