The TopModule will implement a finite-state machine with four states: Idle, Found_1, Found_11, and Found_110. The Idle state is the initial state. When the module is in the Idle state and a 1 is received, it transitions to the Found_1 state. From the Found_1 state, if another 1 is received, it transitions to the Found_11 state. From the Found_11 state, if a 0 is received, it transitions to the Found_110 state. From the Found_110 state, if a 1 is received, it transitions to a Found state where start_shifting is set to 1. If at any point the reset signal is asserted, the module resets to the Idle state.
