To implement the TopModule, we can design a finite-state machine (FSM) with five states: IDLE, STATE1, STATE2, STATE3, and FOUND. The FSM starts in the IDLE state and moves to the next state as it detects the sequence 1101 in the input bit stream. When the sequence is found, the FSM transitions to the FOUND state and sets start_shifting to 1. The FSM stays in the FOUND state until reset is asserted, at which point it returns to the IDLE state. We will use a Moore machine, where the output depends only on the current state.
