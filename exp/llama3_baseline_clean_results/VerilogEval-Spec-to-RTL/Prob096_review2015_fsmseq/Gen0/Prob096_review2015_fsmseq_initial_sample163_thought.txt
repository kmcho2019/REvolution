To implement the TopModule, we will design a finite-state machine (FSM) with five states: IDLE, FOUND_1, FOUND_11, FOUND_110, and FOUND_SEQUENCE. The FSM will start in the IDLE state and transition through the states based on the input data. When the sequence 1101 is found, it will set the start_shifting signal to 1 and remain in that state until reset. We will use a case statement to define the next state based on the current state and input data. The reset signal will be used to asynchronously reset the FSM to the IDLE state.
