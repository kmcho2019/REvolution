To implement the TopModule, we can use a finite-state machine with five states: 
- IDLE: the initial state, waiting for the first '1' in the sequence
- GOT_11: the state after seeing the first '1'
- GOT_110: the state after seeing the first two '1's
- GOT_1101: the state after seeing the first three bits in the sequence
- FOUND: the state after finding the sequence 1101

We will use a simple Moore machine architecture, where the output start_shifting is derived from the current state. 
We will also use a synchronous reset, which means that the reset signal will only be active on the positive edge of the clock.
