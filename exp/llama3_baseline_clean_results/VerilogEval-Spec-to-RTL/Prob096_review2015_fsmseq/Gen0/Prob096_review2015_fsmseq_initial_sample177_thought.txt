To implement the module TopModule, we will design a finite-state machine (FSM) that recognizes the sequence 1101 in the input bit stream. The FSM will have five states: IDLE, S1, S2, S3, and FOUND. In the IDLE state, the FSM will wait for the first '1' to start the sequence. After the first '1', it will move to the S1 state. Then, it will wait for the sequence '101' to complete the sequence 1101. Once the sequence is recognized, the FSM will move to the FOUND state and set the start_shifting signal to 1. The FSM will remain in the FOUND state until a reset is applied. The reset is active high synchronous, meaning it will reset the FSM on the positive edge of the clock when reset is high.
