To implement the decade counter, we will use a 4-bit binary counter and modify it to count from 0 to 9 by using a conditional statement to reset the counter when it reaches 10 (1010 in binary). We will utilize a always block to describe the sequential logic of the counter, and use a non-blocking assignment to update the counter value on the positive edge of the clock. The reset input will be handled synchronously by checking its value within the always block and resetting the counter to 0 when it is high.
