To implement a decade counter, we need to create a 4-bit counter that resets to 0 when it reaches 10 (1010 in binary) and also resets when the reset signal is high. We can achieve this using a finite state machine (FSM) or a simple counter with a conditional reset. Since we're dealing with a small count range (0-9), we can directly implement the counter logic using if-else conditions inside a sequential always block. The counter should be incremented on every positive edge of the clock unless the reset signal is high, in which case it should reset to 0.
