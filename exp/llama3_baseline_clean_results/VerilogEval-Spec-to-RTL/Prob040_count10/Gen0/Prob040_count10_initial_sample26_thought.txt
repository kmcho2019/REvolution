To implement the decade counter, we need to create a counter that counts from 0 to 9 and then resets to 0. This can be achieved by using a 4-bit counter and checking when the count reaches 10 (1000 in binary). When it does, we reset the counter. Since the reset is synchronous and active high, we also need to check for the reset condition within the sequential logic and reset the counter to 0 if it's high. We'll use a reg to hold the current count and update it based on the clock and reset conditions.
