To implement a decade counter, we need to design a 4-bit binary counter that counts from 0 to 9 and then resets to 0. Since the counter should reset to 0 when the reset input is high, we will use a synchronous reset. We can achieve this by using a 4-bit register to store the count value and updating it at each positive clock edge. When the count reaches 10 (1010 in binary), we will reset it to 0. The output q will be the current count value.
