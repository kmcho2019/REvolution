To implement the decade counter, we will use a 4-bit register to store the current count. We will use a synchronous reset to initialize the count to 0 when the reset input is high. On each positive clock edge, we will increment the count by 1, wrapping around to 0 when the count reaches 10 (1010 in binary) since we are only interested in counting from 0 through 9. This can be achieved using an if-else statement or a conditional operator in the always block.
