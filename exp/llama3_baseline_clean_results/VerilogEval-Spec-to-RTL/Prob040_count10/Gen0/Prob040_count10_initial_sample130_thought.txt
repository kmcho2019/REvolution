To implement a decade counter in Verilog, we can use a 4-bit counter and limit its counting range to 0 through 9. We will use an if-else statement inside an always block to check for the reset condition and the count limit. When the reset is high, the counter should reset to 0. When the count reaches 10 (which is 1010 in binary, but since we are only using 4 bits, we will check for the next state, which is when the count is 9 and the next state would be 10, so we will reset the count to 0 at this point), we should reset the counter to 0 on the next clock cycle.
