To implement the decade counter, we can use a 4-bit register to store the current count. On each positive edge of the clock, we will increment the count unless we have reached the maximum value (9) or the reset signal is high. When the count reaches 9, we will reset it to 0 on the next clock edge. The reset signal will be checked on each clock edge, and if it is high, the count will be reset to 0 immediately.
