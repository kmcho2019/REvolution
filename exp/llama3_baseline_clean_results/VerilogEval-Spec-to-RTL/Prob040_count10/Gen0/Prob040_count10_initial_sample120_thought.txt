To implement a decade counter in Verilog, we can use a 4-bit counter and add logic to reset it when it reaches 10. We'll use an always block to describe the sequential behavior of the counter, triggered on the positive edge of the clock. Inside the block, we'll first check for the reset condition. If reset is high, we set q to 0. Otherwise, we check if q is equal to 9 (1001 in binary) and if so, we reset q to 0; otherwise, we increment q by 1.
