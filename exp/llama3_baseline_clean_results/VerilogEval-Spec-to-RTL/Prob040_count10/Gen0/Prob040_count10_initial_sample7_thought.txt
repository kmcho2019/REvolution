To implement a decade counter, we need to create a 4-bit counter that counts from 0 to 9. Since the counter should reset to 0 when the reset input is high, we will use an always block to describe the sequential logic. The counter will increment on every positive clock edge, unless it has reached its maximum value (9), in which case it will wrap around to 0. We will also include a conditional statement to check the reset input and reset the counter if it is high.
