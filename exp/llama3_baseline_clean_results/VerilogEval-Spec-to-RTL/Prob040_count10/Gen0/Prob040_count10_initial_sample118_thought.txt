To implement the decade counter, we will use a 4-bit register to store the current count. We will use a simple if-else statement to check if the current count has reached 9. If it has, we reset the count to 0 on the next clock cycle. If not, we increment the count. The reset input will be used to reset the counter to 0. We will use the always block with the posedge clk to trigger the sequential logic on the positive edge of the clock.
