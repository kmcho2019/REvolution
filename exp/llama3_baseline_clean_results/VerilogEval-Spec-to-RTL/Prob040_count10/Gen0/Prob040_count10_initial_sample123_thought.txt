To implement a decade counter, we need to create a 4-bit counter that counts from 0 to 9 and resets to 0 when it reaches 10. We will use a synchronous reset, which means the reset signal will only be effective on the positive edge of the clock. We can use a 4-bit binary counter and add logic to reset the counter when it reaches 10 (which is 1010 in binary). The output q will be the current count.
