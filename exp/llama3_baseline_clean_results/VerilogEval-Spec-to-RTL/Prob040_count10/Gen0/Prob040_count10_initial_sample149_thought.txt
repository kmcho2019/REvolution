To implement a decade counter that counts from 0 through 9, we can use a 4-bit binary counter and add logic to reset the counter when it reaches 10 (1000 in binary). We will use a always block to handle the sequential logic, triggered on the positive edge of the clock. Inside this block, we will first check if the reset signal is high. If it is, we reset the counter to 0. If not, we increment the counter. We also need to add a condition to stop the counter from counting when it reaches 10.
