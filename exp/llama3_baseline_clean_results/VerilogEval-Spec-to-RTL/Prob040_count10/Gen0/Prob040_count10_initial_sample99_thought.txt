To implement a decade counter, we need to design a sequential logic circuit that increments a 4-bit counter from 0 to 9 on every positive clock edge and resets to 0 when the reset input is high. We can achieve this by using a 4-bit register to hold the current count value, and an always block to define the sequential logic. The always block should check for the reset condition and reset the counter if the reset input is high, otherwise, it should increment the counter and check if it has reached the maximum value of 9. If the counter has reached 9, it should wrap around to 0 on the next clock edge.
