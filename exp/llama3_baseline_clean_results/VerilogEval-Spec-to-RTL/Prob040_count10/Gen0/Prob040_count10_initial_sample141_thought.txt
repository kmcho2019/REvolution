We'll use a 4-bit register to hold the count value since we're counting from 0 to 9, which requires 4 bits (3 bits would be sufficient for counting up to 7, but we need one more bit to represent numbers 8 and 9). The counter will increment on every positive edge of the clock and reset to 0 when the reset signal is high and the clock edge occurs. We'll use a simple if-else statement inside an always block to handle the reset and counting logic. When the count reaches 10 (which in binary is 1010), we'll reset it back to 0 to maintain the counting cycle from 0 to 9.
