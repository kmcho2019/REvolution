To implement the decade counter, we can use a 4-bit register to store the current count. On every positive edge of the clock, we will increment the count unless it has reached 9, in which case we will reset it to 0. The reset input should be checked on every positive edge of the clock, and if it is high, the count should be reset to 0. This logic can be implemented using an always block that is sensitive to the positive edge of the clock.
