To reverse the bit ordering of the input port, we can simply assign each bit of the output port to the corresponding bit of the input port, but in reverse order. For example, bit 0 of the output port should be assigned to bit 7 of the input port, bit 1 of the output port should be assigned to bit 6 of the input port, and so on. This can be achieved using bit-by-bit assignment or using Verilog's bit-reversal syntax.
