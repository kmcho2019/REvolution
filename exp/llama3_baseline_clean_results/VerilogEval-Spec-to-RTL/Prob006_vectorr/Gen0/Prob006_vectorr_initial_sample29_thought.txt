To reverse the bit ordering of the input port, we need to swap the bits in a way that the most significant bit (MSB) becomes the least significant bit (LSB), the second MSB becomes the second LSB, and so on. We can achieve this by assigning each bit of the output port the corresponding bit from the input port, but in reverse order. For example, out[7] should get the value of in[0], out[6] should get the value of in[1], and so on, until out[0] gets the value of in[7].
