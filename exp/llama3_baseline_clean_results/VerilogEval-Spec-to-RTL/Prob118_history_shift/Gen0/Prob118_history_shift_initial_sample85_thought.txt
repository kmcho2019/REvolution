To implement the TopModule, we will use a 32-bit shift register to store the global history. The register will be updated on every positive clock edge. When a branch prediction is made, we will shift the register to the right and insert the predicted taken value at the least significant bit (LSB). When a branch misprediction occurs, we will load the register with the history before the mispredicted branch concatenated with the actual result of the branch. If both a prediction and a misprediction occur at the same time, the misprediction will take precedence. The asynchronous reset (areset) will reset the history register to zero.
