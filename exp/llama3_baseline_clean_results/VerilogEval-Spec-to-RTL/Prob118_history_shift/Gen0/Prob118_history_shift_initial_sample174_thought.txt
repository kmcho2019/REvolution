To implement the TopModule, we will use a 32-bit shift register to store the branch history. We will update this register when a branch prediction is made (predict_valid = 1) by shifting in the predict_taken bit from the LSB side. If a branch misprediction occurs (train_mispredicted = 1), we will load the branch history register with the history after the completion of the mispredicted branch by concatenating the train_history with the train_taken bit. To handle the case where both a prediction and misprediction occur at the same time, we will prioritize the misprediction by checking the train_mispredicted signal first. Finally, we will reset the history counter to zero when the asynchronous reset areset is triggered.
