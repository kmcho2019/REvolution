To implement the TopModule, we will use a 32-bit register to store the branch history. When a prediction is made, we shift in the predicted direction from the LSB side. When a misprediction occurs, we load the branch history register with the history before the mispredicted branch concatenated with the actual result of the branch. We will use a conditional statement to check if a misprediction occurs, and if so, load the new history. If not, we check if a prediction is made and update the history accordingly. We will also implement an asynchronous reset to reset the history counter to zero.
