To implement the TopModule, we will use a 32-bit register to store the branch history. 
On every positive edge of the clock, we will check the input signals. 
If areset is high, we reset the branch history to zero. 
If a branch misprediction occurs (train_mispredicted = 1), we load the branch history with the concatenated value of train_history and train_taken. 
If a prediction is made (predict_valid = 1) and no misprediction occurs, we shift in predict_taken from the LSB side to update the branch history. 
Finally, we will output the current branch history as predict_history.
