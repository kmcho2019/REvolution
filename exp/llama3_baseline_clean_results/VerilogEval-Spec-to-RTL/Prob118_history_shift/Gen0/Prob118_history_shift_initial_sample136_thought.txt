To implement the TopModule, we need to design a 32-bit global history shift register. The register should be updated based on the predict_valid, train_mispredicted, and train_taken signals. 

When predict_valid is high, we shift the predict_taken bit into the least significant bit (LSB) of the history register, effectively updating the branch history for the predicted branch. 

When train_mispredicted is high, we load the branch history register with the history after the completion of the mispredicted branch, which is the train_history concatenated with the actual result of the branch (train_taken). 

If both predict_valid and train_mispredicted are high at the same time, we prioritize the misprediction and load the branch history register accordingly. 

The history register is reset to zero when the areset signal is high. The predict_history output is the current value of the branch history register.
