To implement the TopModule, we need to create a 32-bit global history shift register. 
We will use a 32-bit reg to store the history, and update it based on the input signals. 
When a prediction is made, we shift in the predict_taken from the LSB side. 
When a misprediction occurs, we load the history register with the train_history concatenated with the train_taken. 
We also need to handle the case where both a prediction and a misprediction occur at the same time, 
in which case the misprediction takes precedence. 
We will use areset to reset the history counter to zero.
