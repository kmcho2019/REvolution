To implement the TopModule, we can use a 32-bit register to store the branch history. On every positive clock edge, we check the inputs to determine whether to update the history due to a prediction or a misprediction. If predict_valid is high, we shift in predict_taken from the LSB side to update the branch history for the predicted branch. If train_mispredicted is high, we load the branch history register with the history after the completion of the mispredicted branch, which is train_history concatenated with train_taken. If both predict_valid and train_mispredicted are high, we prioritize the misprediction and load the history register accordingly. We also need to handle the asynchronous reset to reset the history counter to zero.
