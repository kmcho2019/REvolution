To implement the TopModule, we will use a 32-bit shift register to store the branch history. The shift register will be updated when a branch prediction is made, shifting in the predicted branch direction from the least significant bit (LSB) side. When a branch misprediction occurs, the shift register will be loaded with the history after the completion of the mispredicted branch, which is the history before the mispredicted branch concatenated with the actual result of the branch.

The sequential logic will be triggered on the positive edge of the clock. An asynchronous reset will be used to reset the history counter to zero when areset is high.

We will use the following steps to implement the module:
1. Define the module with the given interface.
2. Declare a 32-bit register to store the branch history.
3. Use a clocked always block to update the branch history register based on the input signals.
4. Implement the logic to shift in the predicted branch direction when a branch prediction is made.
5. Implement the logic to load the branch history register with the history after the completion of the mispredicted branch when a branch misprediction occurs.
6. Implement the logic to handle the case when both a prediction and a misprediction occur at the same time.
7. Assign the value of the branch history register to the output predict_history.
