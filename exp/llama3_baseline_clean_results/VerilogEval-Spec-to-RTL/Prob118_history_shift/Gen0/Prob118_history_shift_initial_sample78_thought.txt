The module TopModule will implement a 32-bit global history shift register. 
When a branch prediction is made, it shifts in the predict_taken value from the LSB side to update the branch history for the predicted branch. 
When a branch misprediction occurs, it loads the branch history register with the history after the completion of the mispredicted branch.
In case of both a prediction and misprediction occurring at the same time, the misprediction takes precedence.
The module will be reset to zero when the asynchronous reset areset is triggered.
The logic will be implemented using a positive edge triggered clock.
