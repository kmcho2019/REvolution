To implement the TopModule, we need to consider two primary operations: 
shifting in a predicted branch outcome and rolling back to a previous 
state due to a misprediction. 
1. When a prediction is made (predict_valid = 1), we shift in the 
predicted branch outcome (predict_taken) from the least significant bit 
(LSB) to update the branch history. 
2. When a misprediction occurs (train_mispredicted = 1), we load the 
branch history register with the history before the mispredicted branch 
(train_history) concatenated with the actual result of the branch 
(train_taken). 
The misprediction takes precedence over a prediction if both occur at 
the same time. 
We also need to handle the asynchronous reset (areset) which resets the 
history counter to zero when asserted.
