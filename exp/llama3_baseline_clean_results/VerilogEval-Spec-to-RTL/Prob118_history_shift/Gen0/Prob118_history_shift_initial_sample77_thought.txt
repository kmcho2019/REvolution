The module TopModule will implement a 32-bit global history shift register. It will have two main operations: shifting in the predicted taken bit when a prediction is made and rolling back to a previous state when a misprediction occurs. The misprediction operation will take precedence over the prediction operation if both occur at the same time. The module will also have an asynchronous reset that will reset the history counter to zero. The predict_history output will be the current state of the branch history register.
