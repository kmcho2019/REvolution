To implement the TopModule, we need to create a 32-bit global history shift register. 
The register should be updated based on the predict_valid and train_mispredicted signals. 
When predict_valid is high, we shift in the predict_taken value from the LSB side. 
When train_mispredicted is high, we load the register with the train_history concatenated with train_taken. 
If both predict_valid and train_mispredicted are high at the same time, we prioritize the misprediction. 
We also need to handle the asynchronous reset signal areset to reset the history counter to zero.
