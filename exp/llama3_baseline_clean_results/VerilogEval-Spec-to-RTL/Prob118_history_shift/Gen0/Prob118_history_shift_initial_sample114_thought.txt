To implement the TopModule, we will use a 32-bit shift register to store the branch history. On the positive edge of the clock, we will check for the asynchronous reset (areset) and reset the history to zero if it is asserted. Then, we will check if there is a misprediction (train_mispredicted = 1). If there is a misprediction, we will load the history register with the history after the completion of the mispredicted branch, which is the history before the mispredicted branch (train_history) concatenated with the actual result of the branch (train_taken). If there is no misprediction, we will check if a branch prediction is made (predict_valid = 1). If a prediction is made, we will shift in predict_taken from the LSB side to update the branch history for the predicted branch.
