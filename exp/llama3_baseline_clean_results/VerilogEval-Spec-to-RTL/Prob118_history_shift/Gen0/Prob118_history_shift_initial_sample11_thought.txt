The TopModule should implement a 32-bit global history shift register. 
The register should be updated based on the predict_valid and train_mispredicted signals. 
When predict_valid is high, the register should be shifted left by one bit and the predict_taken signal should be added to the least significant bit. 
When train_mispredicted is high, the register should be loaded with the train_history concatenated with the train_taken signal. 
The misprediction should take precedence when both predict_valid and train_mispredicted are high. 
The module should also have an asynchronous reset that resets the register to zero when areset is high.
