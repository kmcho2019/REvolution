To implement the TopModule, we need to create a 32-bit global history shift register that updates based on branch predictions and mispredictions. We will use a combination of conditional statements and bitwise operations to achieve this. When a prediction is made, we will shift in the predicted taken value from the LSB side. When a misprediction occurs, we will load the register with the history before the mispredicted branch and the actual result of the branch. We will prioritize misprediction over prediction when both occur simultaneously. We will also include an asynchronous reset to reset the history counter to zero.
