The TopModule should implement a 32-bit global history shift register. 
It should update the branch history when a branch prediction is made, 
and load the branch history register with the history after the completion 
of the mispredicted branch when a branch misprediction occurs. 
In case of both prediction and misprediction at the same time, 
the misprediction should take precedence. 
The module should also handle asynchronous reset.
