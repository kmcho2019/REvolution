To implement the TopModule, we need to design a finite state machine (FSM) that can update the branch history register based on the input signals. We will use a 32-bit register to store the branch history. When a prediction is made (predict_valid = 1), we shift in the predict_taken value from the LSB side to update the branch history. When a misprediction occurs (train_mispredicted = 1), we load the branch history register with the train_history concatenated with the train_taken value. If both a prediction and a misprediction occur at the same time, we prioritize the misprediction. We will also include an asynchronous reset (areset) that resets the history register to zero.
