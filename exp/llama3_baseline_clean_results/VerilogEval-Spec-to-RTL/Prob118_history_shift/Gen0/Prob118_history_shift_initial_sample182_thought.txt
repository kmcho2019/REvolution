To implement the TopModule, we will use a 32-bit register to hold the branch history. 
We will use the predict_valid and predict_taken signals to shift in the predicted branch direction when a prediction is made.
When a misprediction occurs (train_mispredicted = 1), we will load the branch history register with the history after the completion of the mispredicted branch.
The history before the mispredicted branch (train_history) will be concatenated with the actual result of the branch (train_taken) to form the new branch history.
We will use an asynchronous reset (areset) to reset the history counter to zero.
The predict_history output will be the current value of the branch history register.
We will use the clock (clk) to trigger all sequential logic.
If both a prediction and a misprediction occur at the same time, the misprediction will take precedence.
