The module TopModule should be designed to update a 32-bit global history shift register based on the input signals. 
It should shift in the predict_taken signal when a branch prediction is made (predict_valid = 1), 
and load the train_history concatenated with train_taken when a branch misprediction occurs (train_mispredicted = 1). 
If both prediction and misprediction occur at the same time, the misprediction should take precedence. 
The module should also handle asynchronous reset when areset is asserted.
