To implement the TopModule, we will use a 32-bit register to store the global history. On the positive edge of the clock, we will check the areset signal and reset the history register to zero if it is high. Otherwise, we will check if a misprediction occurred (train_mispredicted = 1) and load the history register with the train_history concatenated with the actual result of the branch (train_taken) if so. If not, we will check if a prediction is made (predict_valid = 1) and shift in predict_taken from the LSB side to update the branch history for the predicted branch. The updated history will be assigned to predict_history.
