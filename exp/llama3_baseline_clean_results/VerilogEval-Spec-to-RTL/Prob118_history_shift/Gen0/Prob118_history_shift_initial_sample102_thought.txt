To implement the TopModule, we will use a 32-bit shift register to store the branch history. 
When a branch prediction is made, we will shift in the predict_taken value from the LSB side. 
When a branch misprediction occurs, we will load the branch history register with the train_history concatenated with the train_taken value. 
We will also implement the asynchronous reset to clear the branch history register when areset is asserted.
We will use a conditional statement to handle the case where both prediction and misprediction occur at the same time, giving precedence to the misprediction.
