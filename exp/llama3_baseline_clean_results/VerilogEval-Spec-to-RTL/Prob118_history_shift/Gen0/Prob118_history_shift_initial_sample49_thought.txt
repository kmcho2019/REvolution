To implement the TopModule, we need to design a 32-bit global history shift register that updates based on branch predictions and mispredictions. 
The module should have a 32-bit register to hold the branch history. 
On the positive edge of the clock, the module should check the following conditions in order: 
1) If areset is high, reset the branch history register to zero.
2) If train_mispredicted is high, load the branch history register with the train_history concatenated with the train_taken.
3) If predict_valid is high, shift in predict_taken from the LSB side to update the branch history for the predicted branch.
Finally, the module should output the current value of the branch history register as predict_history.
