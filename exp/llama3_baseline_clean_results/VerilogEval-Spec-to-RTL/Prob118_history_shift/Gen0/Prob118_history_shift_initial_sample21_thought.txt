To implement the TopModule, we will use a 32-bit register to store the global history. 
When predict_valid is high, we shift the predict_taken bit into the register from the LSB side.
When train_mispredicted is high, we load the register with the train_history and train_taken bits.
We also need to implement an asynchronous reset, which will reset the register to zero when areset is high.
To ensure that the misprediction takes precedence over the prediction when both occur at the same time, 
we need to check for train_mispredicted before predict_valid in the combinational logic.
