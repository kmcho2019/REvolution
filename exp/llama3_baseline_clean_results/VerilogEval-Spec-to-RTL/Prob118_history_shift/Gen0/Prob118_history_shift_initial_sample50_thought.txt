To implement the TopModule, we need to design a 32-bit global history shift register that supports updates based on branch predictions and mispredictions. The module will have an internal register to store the history. On each clock cycle, we check the inputs to determine whether to update the history based on a prediction, a misprediction, or neither. If a prediction is made, we shift in the prediction result from the least significant bit (LSB) side. If a misprediction occurs, we load the history register with the provided history and the actual branch result. We also need to handle the case where both a prediction and a misprediction happen at the same time, giving precedence to the misprediction. The module will be reset asynchronously by the areset signal, setting the history register to zero.
