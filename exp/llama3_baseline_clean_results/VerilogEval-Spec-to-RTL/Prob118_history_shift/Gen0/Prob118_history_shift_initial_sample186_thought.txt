To implement the TopModule, we need to design a 32-bit global history shift register that updates based on branch predictions and mispredictions. We will use a 32-bit register to store the branch history. When a branch prediction is made (predict_valid = 1), we shift in the predict_taken value from the LSB side to update the branch history. When a branch misprediction occurs (train_mispredicted = 1), we load the branch history register with the history after the completion of the mispredicted branch by concatenating train_history and train_taken. If both a prediction and misprediction occur at the same time, we prioritize the misprediction. We will use areset as an asynchronous reset to reset the history counter to zero. The sequential logic will be triggered on the positive edge of the clock.
