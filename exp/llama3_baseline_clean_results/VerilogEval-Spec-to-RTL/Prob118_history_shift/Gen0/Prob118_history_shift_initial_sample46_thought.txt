To implement the TopModule, we will use a 32-bit register to store the global history shift register. We will use a reset signal (areset) to reset the register to zero asynchronously. On every positive edge of the clock (clk), we will check for the predict_valid signal. If predict_valid is high, we will shift in the predict_taken value from the least significant bit (LSB) side. If train_mispredicted is high, we will load the branch history register with the history after the completion of the mispredicted branch, which is the train_history concatenated with the train_taken. If both predict_valid and train_mispredicted are high at the same time, the misprediction takes precedence.
