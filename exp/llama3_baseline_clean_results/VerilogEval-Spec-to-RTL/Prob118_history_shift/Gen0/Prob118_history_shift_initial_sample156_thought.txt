To implement the TopModule, we need to create a 32-bit global history shift register. We can use a reg variable to store the current state of the history register. The module should handle two main operations: shifting in a new prediction and loading a new history after a misprediction. When a prediction is made (predict_valid = 1), we shift in the predict_taken value from the LSB side. When a misprediction occurs (train_mispredicted = 1), we load the history register with the train_history concatenated with the train_taken value. If both a prediction and misprediction occur at the same time, we give precedence to the misprediction. The module should also handle the asynchronous reset (areset) that resets the history counter to zero.
