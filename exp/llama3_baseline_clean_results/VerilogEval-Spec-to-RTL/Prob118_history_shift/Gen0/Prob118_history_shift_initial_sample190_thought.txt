To implement the TopModule, we will use a 32-bit register to store the branch history. On each clock cycle, we will check the input signals and update the register accordingly. If predict_valid is high, we shift in predict_taken from the LSB side to update the branch history for the predicted branch. If train_mispredicted is high, we load the branch history register with the history after the completion of the mispredicted branch. We will also include an asynchronous reset that resets the history counter to zero when areset is high. If both predict_valid and train_mispredicted are high, we will prioritize the misprediction and load the new history.
