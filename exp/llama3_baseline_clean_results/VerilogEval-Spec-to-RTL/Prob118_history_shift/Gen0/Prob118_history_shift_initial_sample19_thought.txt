To implement the TopModule, we need to create a 32-bit global history shift register. This register will be updated when a branch prediction is made and will be loaded with a new history when a branch misprediction occurs. We will use a variable to store the current history and update it on the positive edge of the clock. If areset is high, we will reset the history to zero. If predict_valid is high, we will shift in predict_taken from the LSB side to update the branch history for the predicted branch. If train_mispredicted is high, we will load the branch history register with the history after the completion of the mispredicted branch. We will use a priority encoder to ensure that misprediction takes precedence over prediction when both occur at the same time.
