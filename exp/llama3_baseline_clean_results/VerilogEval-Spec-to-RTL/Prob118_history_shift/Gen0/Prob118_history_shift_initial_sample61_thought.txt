To implement the TopModule, we'll use a 32-bit register to store the global history shift register. We'll update this register based on the input signals. When a branch prediction is made (predict_valid = 1), we'll shift in the predict_taken bit from the LSB side. When a branch misprediction occurs (train_mispredicted = 1), we'll load the register with the history after the completion of the mispredicted branch, which is the train_history concatenated with the actual result of the branch (train_taken). If both a prediction and a misprediction occur at the same time, we'll prioritize the misprediction. We'll also implement an asynchronous reset to reset the history counter to zero when areset is asserted.
