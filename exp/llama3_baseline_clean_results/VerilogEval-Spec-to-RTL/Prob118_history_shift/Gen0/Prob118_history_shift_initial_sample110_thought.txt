The TopModule should implement a 32-bit global history shift register. 
When a prediction is made, shift in the predict_taken value from the LSB side. 
When a misprediction occurs, load the branch history register with the history 
after the completion of the mispredicted branch. The misprediction takes 
precedence if both a prediction and a misprediction occur at the same time. 
The history counter should reset to zero upon an asynchronous positive edge 
triggered reset. All sequential logic should be triggered on the positive 
edge of the clock.
