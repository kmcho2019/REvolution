To implement the TopModule, we need to design a 32-bit global history shift register that updates based on predictions and mispredictions. 
We will use a synchronous reset to initialize the register to zero when areset is asserted.
When a prediction is made, we shift in the predict_taken value from the LSB side to update the branch history.
When a misprediction occurs, we load the branch history register with the history after the completion of the mispredicted branch.
If both a prediction and misprediction occur at the same time, we prioritize the misprediction by loading the new history.
We will use a 32-bit reg to store the current history and update it based on the input signals.
