To implement the TopModule, we need to design a 32-bit global history shift register that can be updated or rolled back based on branch prediction and misprediction signals. The module should have a synchronous reset (areset) that resets the history register to zero. On every positive edge of the clock, we should check if areset is asserted, and if so, reset the history register to zero. If areset is not asserted, we should check if a branch misprediction has occurred (train_mispredicted = 1), and if so, load the history register with the new history (train_history concatenated with train_taken). If no misprediction has occurred, we should check if a branch prediction is valid (predict_valid = 1), and if so, shift in predict_taken from the LSB side to update the branch history. If neither a misprediction nor a valid prediction has occurred, the history register should remain unchanged.
