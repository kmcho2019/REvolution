To implement the TopModule, we will use a 32-bit shift register to store the branch history. We will update this register based on the predict_valid and train_mispredicted inputs. When predict_valid is high, we shift in the predict_taken value from the LSB side to update the branch history for the predicted branch. When train_mispredicted is high, we load the branch history register with the history after the completion of the mispredicted branch, which is the train_history concatenated with the actual result of the branch (train_taken). If both predict_valid and train_mispredicted are high at the same time, we prioritize the misprediction. We will also include an asynchronous reset (areset) to reset the history counter to zero.
