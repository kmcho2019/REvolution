To implement the TopModule, we will use a 32-bit shift register to store the branch history. We will use the predict_valid and predict_taken signals to update the branch history when a branch prediction is made. When a branch misprediction occurs, we will load the branch history register with the history after the completion of the mispredicted branch. We will use the train_mispredicted and train_history signals to load the new history, and the train_taken signal to append the actual result of the branch to the new history. We will also include an asynchronous reset that resets the history counter to zero when areset is asserted.
