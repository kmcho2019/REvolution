To implement the TopModule, we need to design a 32-bit global history shift register that updates its state based on branch predictions and mispredictions. 
When a branch prediction is made (predict_valid = 1), we shift in the predict_taken value from the least significant bit (LSB) side to update the branch history. 
When a branch misprediction occurs (train_mispredicted = 1), we load the branch history register with the history after the completion of the mispredicted branch, which is the train_history concatenated with the actual result of the branch (train_taken). 
If both a prediction and a misprediction occur at the same time, we prioritize the misprediction because the pipeline flush will also flush out the branch that is currently making a prediction. 
We use areset as an asynchronous reset to reset the history counter to zero. 
We use the positive edge of the clock to trigger all sequential logic.
