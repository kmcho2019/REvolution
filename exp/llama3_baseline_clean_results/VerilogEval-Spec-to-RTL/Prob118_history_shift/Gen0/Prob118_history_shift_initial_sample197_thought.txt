To implement the TopModule, we need to design a 32-bit global history shift register with support for rolling back state in response to a pipeline flush caused by a branch misprediction. The module will have two main operations: shifting in the predicted branch direction when a branch prediction is made, and loading the branch history register with the history after the completion of a mispredicted branch when a misprediction occurs. We will use an if-else statement to prioritize the misprediction over the prediction when both occur at the same time. The module will also have an asynchronous reset that resets the history counter to zero.
