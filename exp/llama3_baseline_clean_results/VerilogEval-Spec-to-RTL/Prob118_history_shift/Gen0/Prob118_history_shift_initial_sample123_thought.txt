To implement the TopModule, we will use a 32-bit register to store the branch history. We will use the predict_valid signal to shift in the predict_taken value from the LSB side when a branch prediction is made. When a branch misprediction occurs, we will load the branch history register with the train_history concatenated with the train_taken value. We will use a priority encoder to ensure that if both a prediction and misprediction occur at the same time, the misprediction takes precedence. The areset signal will be used to asynchronously reset the history counter to zero.
