To implement the TopModule, we need to create a 32-bit global history shift register. 
We will use a flip-flop array to store the branch history, where predict_history[0] is the direction of the youngest branch.
When a branch prediction is made (predict_valid = 1), we will shift in predict_taken from the LSB side to update the branch history.
When a branch misprediction occurs (train_mispredicted = 1), we will load the branch history register with the history after the completion of the mispredicted branch.
We will use areset as an asynchronous reset to reset the history counter to zero.
