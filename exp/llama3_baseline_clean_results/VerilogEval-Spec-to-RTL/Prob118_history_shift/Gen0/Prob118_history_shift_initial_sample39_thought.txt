To implement the TopModule, we need to create a 32-bit global history shift register. 
The register should update its state based on the inputs predict_valid, predict_taken, 
train_mispredicted, train_taken, and train_history. 
When predict_valid is high, we shift in predict_taken from the LSB side to update the branch history. 
When train_mispredicted is high, we load the branch history register with the history after the completion of the mispredicted branch.
We also need to handle the case where both predict_valid and train_mispredicted are high at the same time, 
in which case the misprediction takes precedence.
Finally, we need to reset the history counter to zero when areset is high.
