The TopModule should have a 32-bit register to store the global history shift register. 
On every clock cycle, the module should check for asynchronous reset. If areset is high, 
reset the history register to zero. If not, check for a misprediction (train_mispredicted = 1). 
If there's a misprediction, load the history register with the train_history concatenated with train_taken. 
If not, check for a prediction (predict_valid = 1). If there's a prediction, shift in predict_taken from the LSB side. 
If neither a misprediction nor a prediction occurs, keep the history register unchanged. 
Finally, assign the history register to predict_history.
