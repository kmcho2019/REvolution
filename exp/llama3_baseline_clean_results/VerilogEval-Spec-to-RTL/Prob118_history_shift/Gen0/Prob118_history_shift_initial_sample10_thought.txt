To implement the TopModule, we will first create a 32-bit register to hold the branch history. We will then use the predict_valid and predict_taken signals to shift in the prediction result on each clock cycle when a prediction is made. If a misprediction occurs (train_mispredicted = 1), we will load the branch history register with the history before the mispredicted branch and the actual result of the branch. This will effectively "roll back" the state of the branch history register. We will use the areset signal to reset the branch history register to zero on an asynchronous reset.
