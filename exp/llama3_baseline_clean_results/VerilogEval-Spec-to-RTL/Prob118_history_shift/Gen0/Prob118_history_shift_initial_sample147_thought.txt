To implement the TopModule, we need to design a finite state machine (FSM) that controls a 32-bit shift register. The FSM has two main states: normal operation and rollback. In the normal operation state, when a branch prediction is made (predict_valid = 1), we shift in the predicted direction from the LSB side to update the branch history. When a branch misprediction occurs (train_mispredicted = 1), we load the branch history register with the history after the completion of the mispredicted branch. If both a prediction and a misprediction occur at the same time, the misprediction takes precedence. The FSM also needs to handle the asynchronous reset signal (areset) to reset the history counter to zero.
