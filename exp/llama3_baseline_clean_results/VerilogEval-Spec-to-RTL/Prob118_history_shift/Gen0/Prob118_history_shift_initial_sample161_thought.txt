To implement the TopModule, we need to create a 32-bit global history shift register that updates based on branch predictions and mispredictions. We will use a reg variable to hold the history and update it accordingly. When a branch prediction is made, we shift in the predicted direction from the LSB side. When a misprediction occurs, we load the history register with the history after the mispredicted branch, which is the history before the mispredicted branch concatenated with the actual result of the branch. We will also implement an asynchronous reset to reset the history counter to zero.
