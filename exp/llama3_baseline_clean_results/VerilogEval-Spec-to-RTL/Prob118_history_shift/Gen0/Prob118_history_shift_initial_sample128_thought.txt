To implement the TopModule, we need to create a 32-bit global history shift register. 
When a branch prediction is made (predict_valid = 1), we shift in the predict_taken value from the LSB side to update the branch history.
When a branch misprediction occurs (train_mispredicted = 1), we load the branch history register with the history after the completion of the mispredicted branch, 
which is the train_history concatenated with the actual result of the branch (train_taken).
If both a prediction and misprediction occur at the same time, the misprediction takes precedence.
We will use a register to store the history and update it based on the input signals.
The predict_history output will be the current value of the branch history register.
We will also include an asynchronous reset (areset) that resets the history counter to zero when asserted.
