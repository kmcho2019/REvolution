To implement the TopModule, we need to create a 32-bit global history shift register. 
We will use a reg to store the history and update it based on the input signals.
When predict_valid is 1, we shift in the predict_taken from the LSB side.
When train_mispredicted is 1, we load the train_history concatenated with train_taken into the history register.
If both predict_valid and train_mispredicted are 1, the misprediction takes precedence.
We also need to handle the asynchronous reset when areset is 1.
