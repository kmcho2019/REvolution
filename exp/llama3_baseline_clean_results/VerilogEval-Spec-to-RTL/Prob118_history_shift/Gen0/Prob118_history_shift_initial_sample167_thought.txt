To implement the TopModule, we will use a 32-bit register to store the branch history. We will update this register on every positive clock edge based on the input signals. When a prediction is made, we will shift the current history to the left and insert the predicted direction at the least significant bit (LSB). When a misprediction occurs, we will load the new history by concatenating the train_history with the actual result of the branch (train_taken). If both a prediction and a misprediction occur at the same time, we will prioritize the misprediction. The areset signal will be used to reset the history register asynchronously.
