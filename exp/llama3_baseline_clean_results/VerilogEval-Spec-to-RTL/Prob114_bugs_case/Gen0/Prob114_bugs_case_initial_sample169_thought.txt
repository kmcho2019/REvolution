The TopModule should be implemented as a combinational logic circuit. It can use a series of if-else statements or a case statement to check the 8-bit input code against the predefined scancodes for keys 0 through 9. If the input code matches any of the predefined scancodes, the module should output the corresponding key value on the 4-bit out port and assert the valid signal. If the input code does not match any of the predefined scancodes, the module should output 0 on both the out and valid ports.
