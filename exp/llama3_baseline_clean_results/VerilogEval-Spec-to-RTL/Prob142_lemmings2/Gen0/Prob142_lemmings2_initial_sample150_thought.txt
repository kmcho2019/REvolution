To implement the Lemmings' behavior using a Moore state machine, we need to define the states and transitions based on the given conditions. The states can be represented as follows:
- Walking left (WL)
- Walking right (WR)
- Falling (F)

The transitions between these states are determined by the input signals:
- If the Lemming is walking left (WL) and receives a bump on the left, it will switch to walking right (WR).
- If the Lemming is walking right (WR) and receives a bump on the right, it will switch to walking left (WL).
- If the Lemming is bumped on both sides at the same time, it will still switch directions.
- When the ground disappears (ground=0), the Lemming will fall (F) regardless of its current direction.
- When the ground reappears (ground=1), the Lemming will resume walking in the same direction as before the fall.

We will use a 2-bit register to store the current state and another register to store the previous direction before falling.
