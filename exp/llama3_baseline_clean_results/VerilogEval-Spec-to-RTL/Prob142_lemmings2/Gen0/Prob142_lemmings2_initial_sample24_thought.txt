To implement the Lemming's behavior as a Moore state machine, we need to define the states and transitions based on the given conditions. The states can be defined as follows:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.

The transitions between these states will be based on the input signals bump_left, bump_right, and ground. When the Lemming is walking and hits an obstacle (bump_left or bump_right), it will switch direction. If the ground disappears (ground=0), the Lemming will start falling. When the ground reappears (ground=1), the Lemming will resume walking in the same direction as before the fall.

We will use a-bit state variable to represent the three states. The output signals walk_left, walk_right, and aaah will be determined by the current state.
