To implement the Moore state machine, we first need to define the states and transitions. Let's consider the following states: 
- IDLE_LEFT: The Lemming is walking left and on the ground.
- IDLE_RIGHT: The Lemming is walking right and on the ground.
- FALLING_LEFT: The Lemming is falling and the last walking direction was left.
- FALLING_RIGHT: The Lemming is falling and the last walking direction was right.

The transitions will be as follows:
- If the Lemming is walking left and gets bumped on the left, it will start walking right.
- If the Lemming is walking right and gets bumped on the right, it will start walking left.
- If the Lemming is walking in either direction and loses the ground, it will start falling and remember the last walking direction.
- If the Lemming is falling and the ground reappears, it will resume walking in the last walking direction.

We will use a 2-bit signal 'state' to represent these four states. We can then use a case statement to determine the output based on the current state and inputs.
