To implement the Moore state machine, we will use two states to represent the Lemming's direction: walking left and walking right. We will also add a third state to represent the falling state. The machine will transition between these states based on the input signals. When the ground is 0, the machine will transition to the falling state and output "aaah!". When the ground reappears, the machine will transition back to the previous walking direction state. The bump_left and bump_right signals will cause the machine to switch direction when it is in a walking state. 
The state machine will be implemented using a case statement to handle the different states and a conditional statement to handle the state transitions.
