To implement the Lemmings' behavior as a Moore state machine, we can define four states: WALK_LEFT, WALK_RIGHT, FALL, and RESET. The machine starts in the WALK_LEFT state after reset. When ground is high, the machine switches between WALK_LEFT and WALK_RIGHT based on the bump inputs. If ground is low, the machine transitions to the FALL state, where it stays until ground becomes high again. In the FALL state, the machine ignores bump inputs and outputs "aaah!". When ground becomes high again, the machine returns to its previous walking direction. The state machine will use a simple binary encoding, where each state is represented by a binary number (e.g., WALK_LEFT = 2'b00, WALK_RIGHT = 2'b01, FALL = 2'b10, and RESET = 2'b11).
