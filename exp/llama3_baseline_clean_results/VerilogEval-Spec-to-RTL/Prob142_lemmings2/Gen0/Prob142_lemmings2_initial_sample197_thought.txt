To implement the Lemmings state machine, we will use a Moore state machine with two states: walking left and walking right. We will also consider a third state for falling. We will use two state variables: `direction` to keep track of the current walking direction and `falling` to indicate if the Lemming is falling. The state machine will transition between these states based on the input signals `bump_left`, `bump_right`, and `ground`. The output signals `walk_left`, `walk_right`, and `aaah` will be determined by the current state.
