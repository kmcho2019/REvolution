The Moore state machine should have two states to model the Lemming's walking directions: walking left and walking right. Additionally, it needs to handle the falling state and the bumps while falling. 
The state machine will have the following states:
- Walking Left (WL)
- Walking Right (WR)
- Falling Left (FL)
- Falling Right (FR)

When the Lemming is walking left or right, and it hits an obstacle on the left, it will switch to the walking right state. If it hits an obstacle on the right, it will switch to the walking left state. 
When the ground disappears, it will switch to the falling state, maintaining the same direction it was walking before. 
When the ground reappears, it will switch back to the walking state with the same direction it had before falling. 

To implement this, we will use a case statement to handle the state transitions and the output logic. The state transitions will be based on the current state, the bump inputs, and the ground input.
