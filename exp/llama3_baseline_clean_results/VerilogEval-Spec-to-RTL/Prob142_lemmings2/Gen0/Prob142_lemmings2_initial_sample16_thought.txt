The problem can be solved using a finite state machine (FSM) with four states: walking left, walking right, falling, and idle. The FSM will change its state based on the input signals. The initial state will be walking left. When the Lemming is bumped, it will change its direction. If the ground disappears, the Lemming will start falling and say "aaah!". When the ground reappears, the Lemming will resume walking in the same direction as before the fall. Being bumped while falling does not affect the walking direction. We will use a Moore state machine, where the output is a function of the current state only. We will use two state variables to represent the current state and the previous direction.
