To implement this finite state machine, we can define three main states: 
walking left, walking right, and falling. When the Lemming is walking, 
it will switch directions upon receiving a bump signal. If the ground 
signal is low, the Lemming will fall and say "aaah!". When the ground 
signal returns high, the Lemming will resume walking in the previous 
direction. Being bumped while falling or during the transition to or 
from falling does not affect the walking direction.

We will use two state variables: direction (left or right) and falling 
(yes or no). The outputs walk_left, walk_right, and aaah can be derived 
from these state variables. We will also include an asynchronous reset 
that resets the state machine to walk left.

The next state logic will be based on the current state and the input 
signals. We will use a Moore state machine, meaning the outputs are 
derived from the state variables, not the input signals directly.
