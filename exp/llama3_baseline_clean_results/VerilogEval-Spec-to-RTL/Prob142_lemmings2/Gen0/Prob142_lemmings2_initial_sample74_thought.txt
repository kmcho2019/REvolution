To implement the Lemming's finite state machine, we need to consider the different states it can be in: walking left, walking right, and falling. We'll use a Moore state machine, which means the outputs are a function of the current state only. 

The state machine will have three states: WALK_LEFT, WALK_RIGHT, and FALLING. 

- When in the WALK_LEFT state, if the Lemming is bumped on the left, it will switch to the WALK_RIGHT state. If it's bumped on the right, it will switch to the WALK_LEFT state (no change).
- When in the WALK_RIGHT state, if the Lemming is bumped on the right, it will switch to the WALK_LEFT state. If it's bumped on the left, it will switch to the WALK_RIGHT state (no change).
- When the ground disappears (ground = 0), the Lemming will switch to the FALLING state.
- When the ground reappears (ground = 1), the Lemming will switch back to the previous walking state (WALK_LEFT or WALK_RIGHT).
- Being bumped while falling does not affect the walking direction.
