To implement this Lemming finite state machine, we will create a Moore state machine with three states: walking_left, walking_right, and falling. The state machine will transition between walking_left and walking_right based on the bump_left and bump_right inputs. When ground is 0, the state machine will transition to the falling state and set aaah to 1. When ground becomes 1 again, the state machine will transition back to the previous walking state. The output signals walk_left, walk_right, and aaah will be determined by the current state.
