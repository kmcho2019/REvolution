To implement the Lemmings state machine, we can define two states: walking left and walking right. We can use a Moore state machine, where the outputs are a function of the current state only. We will also keep track of the previous walking direction to resume walking in the same direction after falling. The state machine will transition between the walking states when bumped, and will enter a falling state when the ground disappears. When the ground reappears, the state machine will resume walking in the previous direction.
