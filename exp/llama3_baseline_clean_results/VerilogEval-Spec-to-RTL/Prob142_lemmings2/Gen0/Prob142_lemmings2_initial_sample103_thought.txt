To implement the Lemming machine as a Moore state machine, we will define three states: walking left, walking right, and falling. We will also define the conditions under which the machine transitions between these states. When the machine is in the walking left or walking right state, it will transition to the other state when it is bumped by an obstacle. If the ground disappears (ground=0), the machine will transition to the falling state. When the ground reappears (ground=1), the machine will transition back to the state it was in before the fall, but this transition only occurs when the machine is in the falling state and not in the same cycle as the ground disappearance or appearance. The outputs walk_left and walk_right will be driven by the current state, and the output aaah will be driven by the falling state.
