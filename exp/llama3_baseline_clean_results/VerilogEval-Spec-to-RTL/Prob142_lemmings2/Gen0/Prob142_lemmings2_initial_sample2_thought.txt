To implement the Lemmings' behavior using a finite state machine, we will define four states: walking left, walking right, falling, and idle (which will not be used). The state machine will transition between walking left and walking right based on the bump inputs. When the ground disappears, the state machine will transition to the falling state and output "aaah!". When the ground reappears, the state machine will transition back to the previous walking state. We will use a Moore state machine, where the outputs are determined by the current state.

We will encode the states as follows:
- 2'b00: walking left
- 2'b01: walking right
- 2'b10: falling

The state machine will have the following transitions:
- If the current state is walking left and bump_left is 1, transition to walking right.
- If the current state is walking right and bump_right is 1, transition to walking left.
- If the current state is walking left and bump_left and bump_right are both 1, transition to walking right.
- If the current state is walking right and bump_left and bump_right are both 1, transition to walking left.
- If the current state is walking left or walking right and ground is 0, transition to falling.
- If the current state is falling and ground is 1, transition back to the previous walking state.

We will also use the areset signal to reset the state machine to the walking left state when it is asserted.
