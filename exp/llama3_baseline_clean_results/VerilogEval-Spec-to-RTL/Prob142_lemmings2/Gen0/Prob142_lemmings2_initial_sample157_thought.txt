To implement the Lemmings' behavior as a Moore state machine, we'll define two main states: walking left and walking right. We'll also consider the falling state when the ground disappears. The state machine will switch between these states based on the bump_left, bump_right, and ground inputs. On every clock cycle, the state machine will evaluate these inputs and update its state accordingly. When the Lemming is walking, it will set walk_left or walk_right to 1, and when it's falling, it will set aaah to 1. The asynchronous reset areset will reset the state machine to the walking left state.
