To implement the Lemmings' behavior using a Moore state machine, we first need to define the possible states and transitions. The Lemmings can be in one of three states: walking left, walking right, or falling. The state transitions are as follows:
- If the Lemming is walking left and bumped on the left, it will walk right.
- If the Lemming is walking left and bumped on the right, it will walk left, but since it's already walking left, it will remain in the same state.
- If the Lemming is walking right and bumped on the left, it will walk left.
- If the Lemming is walking right and bumped on the right, it will walk left.
- If the ground is 0, the Lemming will fall regardless of the current state.
- If the ground reappears (ground=1), the Lemming will resume walking in the same direction as before the fall.
