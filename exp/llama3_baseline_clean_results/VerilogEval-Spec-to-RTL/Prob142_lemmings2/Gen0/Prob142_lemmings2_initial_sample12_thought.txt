To implement the Moore state machine that models the Lemmings' behavior, we need to define the states and transitions. The Lemming can be in one of four states: walking left, walking right, falling, or in a idle state that retains the last walking direction when the Lemming is not falling.

We can use two bits to represent the state: 
- The first bit (dir) can be used to represent the direction of the Lemming (0 for left, 1 for right).
- The second bit (falling) can be used to represent whether the Lemming is falling (1) or not (0).

The transitions between the states are as follows:
- If the Lemming is walking and hits an obstacle, it will switch direction.
- If the ground disappears, the Lemming will start falling.
- If the ground reappears while the Lemming is falling, it will stop falling and resume walking in the same direction.
- Being bumped while falling does not affect the walking direction.

We can implement the state machine using a Moore machine, where the outputs are a function of the current state only.
