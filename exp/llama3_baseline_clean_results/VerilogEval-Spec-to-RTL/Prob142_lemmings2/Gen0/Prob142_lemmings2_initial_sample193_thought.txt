To implement the Lemmings state machine, we will use a Moore machine model. This model consists of two states: walking left and walking right. The state transitions will occur based on the input signals (bump_left, bump_right, and ground). When the ground signal is low, the Lemming will fall and say "aaah!", but the walking direction will remain the same. We will use a two-bit state register to store the current state and direction. The state machine will be implemented using a case statement for the state transitions and a separate always block for the output logic.
