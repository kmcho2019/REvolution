To solve this problem, we will create a Moore state machine with the following states:
- LEFT: The Lemming is walking left.
- RIGHT: The Lemming is walking right.
- FALL: The Lemming is falling.
We will use a single always block to handle the state transitions and output logic. 
The state transitions will be determined by the current state and the input values.
If the Lemming is in the LEFT state and is bumped on the left, or if it is in the RIGHT state and is bumped on the right, it will change direction.
If the ground disappears (ground = 0), the Lemming will start falling, regardless of its current state.
When the ground reappears (ground = 1) while the Lemming is falling, it will resume walking in the same direction as before the fall.
Being bumped while falling does not affect the walking direction.
