To implement the required behavior, we can model the Lemming's state machine using a Moore machine, where the outputs are a function of the current state. We will need three states: walking left, walking right, and falling. The state transitions will be triggered by the bump_left, bump_right, and ground signals. We will also need to remember the previous walking direction when the Lemming is falling, so that it can resume walking in the same direction when the ground reappears.
