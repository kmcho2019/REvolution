The problem can be solved by designing a Moore state machine with 4 states: 
walking left, walking right, falling, and a temporary state for handling 
edge cases where ground disappears or reappears at the same time as a bump. 
The state machine will transition between walking left and right when a bump 
is detected, and will transition to falling when the ground disappears. 
When the ground reappears, the state machine will transition back to the 
previous walking direction.

To handle edge cases, the machine will first detect the disappearance or 
reappearance of the ground, and then check for bumps in the next cycle. 
This ensures that bumps are only considered when the Lemming is on the ground.

The state machine can be implemented using a single always block that 
handles the sequential logic.
