To implement the Lemming's behavior using a Moore state machine, we can define four states: 
- State 0: Walking left
- State 1: Walking right
- State 2: Falling
- State 3: Walking left and fallen
- State 4: Walking right and fallen

The state machine will transition between these states based on the input signals. When the Lemming is walking and hits an obstacle, it will switch direction. When the ground disappears (ground=0), the Lemming will start falling. When the ground reappears (ground=1), the Lemming will resume walking in the same direction as before the fall. The output signals walk_left, walk_right, and aaah will be determined based on the current state.

We can use a binary encoding for the states, where each state is represented by a 3-bit binary number. This way, we can easily transition between states and determine the output signals.

The state machine will be reset to the walking left state (State 0) when areset is high.
