To solve this problem, we will design a Moore state machine with the following states:
- LEFT: walking left
- RIGHT: walking right
- FALL: falling and saying "aaah!"

We will have two state registers to track the current state and the previous direction. 
The machine will change state based on the current state, bump_left, bump_right, and ground signals.
If ground is 0, the machine will transition to the FALL state. 
If ground is 1 and the machine is in the FALL state, it will transition back to the previous walking state (LEFT or RIGHT).
If the machine is walking and receives a bump on either side, it will change direction.
If the machine receives a bump on both sides at the same time, it will still change direction.
The machine will be reset to the LEFT state when areset is high.
