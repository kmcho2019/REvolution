To implement the Lemmings' finite state machine, we will define four states: walking left, walking right, falling, and idle (after falling, before ground reappears). The state machine will be a Moore machine, meaning the outputs are a function of the current state only. 

We will use a binary encoding for the states: 
- State 0: Walking left
- State 1: Walking right
- State 2: Falling
- State 3: Idle (after falling)

The next state will be determined by the current state and the inputs. 

- If the current state is walking left or walking right, the next state will be determined by the bump_left and bump_right inputs. If bump_left is high, the next state will be walking right. If bump_right is high, the next state will be walking left. If both bump_left and bump_right are high, the next state will still switch directions.

- If the ground input is low, the next state will be falling.

- If the current state is falling, the next state will still be falling until the ground input is high again.

- When the ground reappears, the state machine will transition from falling or idle to the previous walking direction (left or right).

The outputs will be determined by the current state. 

- If the current state is walking left, walk_left will be high and walk_right will be low.

- If the current state is walking right, walk_right will be high and walk_left will be low.

- If the current state is idle, all outputs will be low.
