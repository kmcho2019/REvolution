To implement the Lemmings finite state machine, we can define four states: 
- walking_left: The Lemming is walking to the left.
- walking_right: The Lemming is walking to the right.
- falling: The Lemming is falling.
We will use a Moore state machine, which means the outputs are a function of the current state only. 
The state transitions will be based on the input signals bump_left, bump_right, and ground. 
When the ground disappears (ground = 0), the Lemming will transition to the falling state, and when the ground reappears (ground = 1), the Lemming will transition back to its previous walking state.
We will use an enum to define the states, and a case statement to handle the state transitions and output logic.
We will also use a variable to keep track of the previous walking direction when the Lemming is falling.
