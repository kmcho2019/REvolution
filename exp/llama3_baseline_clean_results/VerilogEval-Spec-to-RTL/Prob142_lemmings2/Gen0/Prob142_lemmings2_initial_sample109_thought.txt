The finite state machine should have at least three states: walking left, walking right, and falling. 
We need to implement a Moore state machine where the outputs (walk_left, walk_right, aaah) are determined by the current state.
The next state logic should take into account the current state, bump_left, bump_right, and ground.
We can use a 2-bit signal to represent the three states (two bits can represent four states, but we will only use three).
The initial state should be walking left.
When the Lemming is bumped, it should switch direction.
When the ground disappears (ground = 0), the Lemming should fall and say "aaah!".
When the ground reappears (ground = 1), the Lemming should resume walking in the same direction as before the fall.
Being bumped while falling does not affect the walking direction.
