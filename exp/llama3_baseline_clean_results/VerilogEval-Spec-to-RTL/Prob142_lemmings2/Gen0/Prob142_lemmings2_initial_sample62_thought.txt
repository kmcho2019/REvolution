To implement the Lemmings' behavior as a Moore state machine, we need to consider the possible states and transitions. The states are:
- Walking left (WL)
- Walking right (WR)
- Falling (F)

The state transitions are:
- WL to WR when bumped from the left
- WL to F when ground disappears
- WR to WL when bumped from the right
- WR to F when ground disappears
- F to WL when ground reappears and the previous state was WL
- F to WR when ground reappears and the previous state was WR

We can encode these states using two bits (2 states can be encoded with 1 bit, but we have 3 states). We will use the state encoding: WL = 2'b00, WR = 2'b01, F = 2'b10.

In the falling state, the Lemming should say "aaah!" by setting the output aaah to 1. In the walking states, the outputs walk_left and walk_right should be set accordingly.

When the ground reappears, the Lemming should resume walking in the same direction as before the fall. We can achieve this by storing the previous walking direction when the Lemming starts falling.
