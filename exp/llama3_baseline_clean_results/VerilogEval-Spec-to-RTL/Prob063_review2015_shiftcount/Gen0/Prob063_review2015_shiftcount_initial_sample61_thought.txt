The module TopModule should be designed as a finite state machine (FSM) with a four-bit register q. When shift_ena is 1, the FSM shifts the data into the most significant bit of q and shifts the existing bits to the right. When count_ena is 1, the FSM decrements the value of q. Since the full system doesn't use both shift_ena and count_ena at the same time, we can simply use if-else statements to handle these two cases separately. The FSM should be triggered on the positive edge of the clock.
