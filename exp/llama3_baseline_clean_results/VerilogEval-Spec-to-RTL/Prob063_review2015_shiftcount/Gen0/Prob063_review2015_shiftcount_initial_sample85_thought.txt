The TopModule can be implemented using a combination of sequential logic and combinatorial logic. 
We can use a 4-bit register to store the current value of the shift register/counter. 
When shift_ena is 1, we shift in the new data bit and move the existing bits to the right. 
When count_ena is 1, we decrement the value in the register. 
To handle the case when both shift_ena and count_ena are 1, we can simply give priority to one of them, 
for example, giving priority to shift_ena. 
This can be done by checking the shift_ena signal first, and if it is 1, we perform the shift operation. 
If shift_ena is 0, we then check the count_ena signal and perform the decrement operation if it is 1.
