To implement the TopModule, we need to design a four-bit shift register that also acts as a down counter. The register should shift in data most-significant-bit first when shift_ena is high, and decrement the current value when count_ena is high. Since the full system doesn't ever use shift_ena and count_ena together, we can prioritize either case. We'll use a simple if-else statement to check the control inputs and perform the corresponding action. We'll use a reg to store the current value of the shift register.
