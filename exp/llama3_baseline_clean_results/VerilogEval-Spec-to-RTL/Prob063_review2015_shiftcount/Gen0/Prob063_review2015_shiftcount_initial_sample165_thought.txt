To implement the TopModule, we will use a 4-bit register to store the current state of the shift register/counter. We will use an always block to handle the sequential logic triggered by the positive edge of the clock. Inside the always block, we will use if-else statements to check the status of shift_ena and count_ena. If shift_ena is 1, we will shift the data into the most-significant-bit of the register. If count_ena is 1, we will decrement the number in the register.
