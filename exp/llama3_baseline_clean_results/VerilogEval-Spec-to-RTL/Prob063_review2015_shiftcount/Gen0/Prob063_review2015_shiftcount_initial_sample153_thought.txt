The TopModule will be implemented as a four-bit shift register that also functions as a down counter. To achieve this, we need to implement two main operations: shifting and decrementing. When shift_ena is high, we shift in the new data bit from the most significant bit (MSB) to the least significant bit (LSB). When count_ena is high, we decrement the current value in the register. Since the system doesn't use both shift_ena and count_ena simultaneously, we can prioritize either operation. We will use a simple if-else statement to handle these two cases. The shift register will be implemented using a 4-bit reg variable, and we will use the always @(posedge clk) block to capture the positive edge of the clock signal.
