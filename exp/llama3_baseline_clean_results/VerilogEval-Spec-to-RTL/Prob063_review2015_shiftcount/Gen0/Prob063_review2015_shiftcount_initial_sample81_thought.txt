The TopModule should contain a 4-bit register to hold the current state of the shift register/down counter. On every positive clock edge, it should check the values of shift_ena and count_ena. If shift_ena is 1, it should shift the data into the most significant bit of the register and shift the existing bits one position to the right. If count_ena is 1, it should decrement the value in the register. Since the problem statement specifies that shift_ena and count_ena are never used together, we can prioritize one over the other. In this case, we'll give priority to shift_ena. We'll use a non-blocking assignment to update the register to ensure the changes are made in parallel.
