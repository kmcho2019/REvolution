The TopModule will be designed as a four-bit shift register with down counter functionality. It will use a 4-bit reg type to hold the current value in the shift register. The module will check for shift_ena and count_ena on the positive edge of the clock. If shift_ena is high, it will shift in the data bit from the most significant bit to the least significant bit. If count_ena is high, it will decrement the current value in the shift register. Since the system never uses both shift_ena and count_ena together, the priority of either operation does not matter.
