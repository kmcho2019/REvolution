To implement the TopModule, we will use a 4-bit register to store the current state of the shift register/down counter. We will use the shift_ena signal to enable shifting in of data, and the count_ena signal to enable decrementing of the current count. We will use the positive edge of the clock to trigger updates to the register. 
When shift_ena is high, we will shift the data in most-significant-bit first. 
When count_ena is high, we will decrement the current count. 
Since the system does not use shift_ena and count_ena together, we will prioritize the shift operation when both are high.
