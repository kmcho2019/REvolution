The TopModule should have two main functions: shifting in data when shift_ena is 1 and decrementing the current value when count_ena is 1. Since the system never uses both shift_ena and count_ena at the same time, we can implement these two functions separately without worrying about priority. We will use a 4-bit register to store the current value and update it based on the control inputs. When shift_ena is 1, we shift in the data from the most significant bit to the least significant bit. When count_ena is 1, we decrement the current value by 1.
