To implement the TopModule, we need to design a module that can act as both a four-bit shift register and a down counter. The shift register should shift in data most-significant-bit first when shift_ena is high, and the counter should decrement the current value when count_ena is high. Since the control inputs are mutually exclusive, we can use a simple if-else statement to prioritize the operations. We will use a 4-bit register to store the current value of the shift register/counter.
