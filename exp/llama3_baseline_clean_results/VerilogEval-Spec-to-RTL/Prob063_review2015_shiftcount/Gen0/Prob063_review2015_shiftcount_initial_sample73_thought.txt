On each positive clock edge, we will check the shift_ena and count_ena signals. If shift_ena is 1, we will shift in the new data bit from the most significant bit position. If count_ena is 1, we will decrement the current value in the register. If neither signal is 1, the register value will remain unchanged. Since the full system doesn't use shift_ena and count_ena together, we can prioritize either condition, but for simplicity, we will prioritize shift_ena.
