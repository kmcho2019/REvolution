To implement the TopModule, we will use a 4-bit register to store the current value of the shift register/down counter. On each positive edge of the clock, we will check the values of shift_ena and count_ena. If shift_ena is 1, we will shift the data into the register from the most significant bit. If count_ena is 1, we will decrement the value in the register. Since the full system doesn't use shift_ena and count_ena together, we will give priority to shift_ena if both are 1.
