To implement the TopModule, we need to use a combination of shift register and counter logic. We can use a 4-bit register to store the current value. On every positive clock edge, we check the control inputs shift_ena and count_ena. If shift_ena is high, we shift the data into the most-significant-bit of the register and shift out the least-significant-bit. If count_ena is high, we decrement the current value in the register. Since we don't have to handle the case where both shift_ena and count_ena are high, we can prioritize one over the other. In this case, we will prioritize the shift_ena signal. We use a non-blocking assignment to update the register at the positive edge of the clock.
