The TopModule should implement a 4-bit shift register that can shift data in from the most significant bit (MSB) when shift_ena is high, and decrement the current value when count_ena is high. Since the system never uses both shift_ena and count_ena simultaneously, we can implement a simple multiplexer to choose between the shift and decrement operations based on the control inputs. We will use a 4-bit register to store the current value, and update it based on the control inputs on the positive edge of the clock.
