To implement the TopModule, we can use a simple multiplexer design. We can use the sel input to generate an address that can be used to select the correct 4-bit chunk from the in vector. Since sel is 8 bits, it can address 2^8 = 256 different locations, which is exactly what we need. We can then use this address to extract the correct 4-bit chunk from in and assign it to the out output.
