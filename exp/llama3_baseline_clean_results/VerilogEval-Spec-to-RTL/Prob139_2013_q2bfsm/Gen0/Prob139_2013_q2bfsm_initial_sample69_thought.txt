To implement this finite state machine (FSM), we'll break down its behavior into states and transitions based on the given conditions. The FSM will have several states to track the sequence of inputs from x and y, as well as the outputs f and g. We'll use a parameterized state machine with enumerated states to make the code more readable. The states can be broadly categorized into initial states, states for monitoring x, states for setting g based on y, and the final states for g's value based on y's behavior.

The states and transitions are as follows:
1. **Reset State (State A)**: Stay here as long as resetn is low. When resetn goes high, move to the next state on the next clock edge.
2. **Set F State**: Set f to 1 for one clock cycle.
3. **Monitor X State**: Monitor x for the sequence 1, 0, 1. Each value in the sequence moves the FSM to the next state until the sequence is detected.
4. **Set G State**: Set g to 1.
5. **Monitor Y State**: Monitor y for 1 within two clock cycles. If y is 1 within this time, move to a state where g remains 1. If y is not 1 within two cycles, move to a state where g is set back to 0.
6. **G High State and G Low State**: These are final states where g is permanently set to 1 or 0, respectively, until a reset occurs.

We'll implement these states using a parameterized enum, a state register, and combinational logic to determine the next state and output values based on the current state and inputs.
