To solve this problem, we'll design a finite state machine (FSM) with several states to control the motor based on the given conditions. The states will be as follows:
- State A: Initial state when reset is asserted. Outputs f and g are 0.
- State B: After reset is de-asserted, set output f to 1 for one clock cycle.
- State C: Monitor the x input for the sequence 1, 0, 1.
- State D: After detecting the sequence, set output g to 1 and start monitoring y.
- State E: If y becomes 1 within two clock cycles, maintain g = 1 permanently.
- State F: If y does not become 1 within two clock cycles, set g = 0 permanently.
We'll use a parameterized state machine to simplify the design and make it easier to understand and modify.
