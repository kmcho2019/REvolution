To solve this problem, we can design a finite state machine (FSM) with multiple states. The FSM starts in state A and transitions to state B when the reset signal is de-asserted. In state B, it sets output f to 1 for one clock cycle. Then, it transitions to state C, where it monitors the x input. When the x input produces the sequence 1, 0, 1 in three successive clock cycles, the FSM transitions to state D, where it sets output g to 1 and monitors the y input. If y becomes 1 within two clock cycles, the FSM transitions to state E, where it maintains g = 1 permanently. If y does not become 1 within two clock cycles, the FSM transitions to state F, where it sets g = 0 permanently. We can use a counter to keep track of the clock cycles in each state.
