To implement the described finite state machine, we can define several states to represent the different stages of operation. 
1. State A: The initial state where the FSM stays as long as the reset input is asserted.
2. State B: The state after the reset signal is de-asserted, where the output f is set to 1 for one clock cycle.
3. State C: The state where the FSM monitors the x input for the sequence 1, 0, 1.
4. State D: The state where the FSM has detected the sequence 1, 0, 1 and sets g to 1.
5. State E: The state where the FSM monitors the y input for a value of 1 within at most two clock cycles.
6. State F: The state where the FSM has detected y = 1 and maintains g = 1 permanently.
7. State G: The state where the FSM did not detect y = 1 within two clock cycles and sets g = 0 permanently.

We will use a 3-bit binary encoding for the states, which allows us to represent up to 8 states. The next state logic and output logic will be determined based on the current state and input values.
