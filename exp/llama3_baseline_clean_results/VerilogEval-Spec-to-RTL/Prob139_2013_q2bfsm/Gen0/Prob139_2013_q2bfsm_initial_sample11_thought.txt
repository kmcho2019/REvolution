To solve this problem, we need to design a finite state machine (FSM) that meets the given requirements. The FSM will have multiple states to track the sequence of inputs and control the outputs accordingly. We will use a Moore machine model, where the outputs are a function of the current state only. The states will be defined as follows:

- State A: Initial state, reset state
- State B: State after reset is de-asserted, set output f to 1 for one clock cycle
- State C: Monitor x input for the sequence 1, 0, 1
- State D: Set output g to 1 and monitor y input
- State E: Output g remains 1 permanently if y becomes 1 within two clock cycles
- State F: Output g remains 0 permanently if y does not become 1 within two clock cycles

We will use a 3-bit state register to represent these six states.
