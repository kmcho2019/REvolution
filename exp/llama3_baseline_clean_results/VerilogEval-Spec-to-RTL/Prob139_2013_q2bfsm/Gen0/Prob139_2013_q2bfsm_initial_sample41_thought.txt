To implement this finite state machine, we'll use a state-based approach. We can break down the FSM's operation into several states: 
- State A (reset state): Stays in this state as long as reset is asserted. 
- State B: Sets output f to 1 for one clock cycle after reset is de-asserted.
- State C: Monitors input x, waiting for the sequence 1, 0, 1.
- State D: Sets output g to 1 and monitors input y for a maximum of two clock cycles.
- State E: Maintains output g = 1 permanently if y becomes 1 within two clock cycles.
- State F: Sets output g = 0 permanently if y does not become 1 within two clock cycles.
We'll use an enumeration to define these states and a case statement to handle the state transitions and output logic.
