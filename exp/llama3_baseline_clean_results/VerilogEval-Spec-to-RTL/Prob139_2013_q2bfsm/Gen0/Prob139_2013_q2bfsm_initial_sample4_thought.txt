To solve this problem, we will design a finite state machine (FSM) with the following states: 
- State A: Initial state, where the FSM stays when the reset input is asserted. 
- State B: Transitional state where f is set to 1 for one clock cycle after reset is de-asserted.
- State C: Monitoring state where x input is monitored for the sequence 1, 0, 1.
- State D: Transitional state where g is set to 1.
- State E: Monitoring state where y input is monitored for a high value within two clock cycles.
- State F: Permanent state where g remains 1.
- State G: Permanent state where g remains 0.

The FSM will transition between these states based on the input values and internal counters.
