- State B: The state where the FSM sets output f to 1 for one clock cycle after reset is de-asserted.
- State C: The state where the FSM monitors the x input to detect the sequence 1, 0, 1.
- State D: The state where the FSM sets output g to 1 and monitors the y input.
- State E: The state where the FSM maintains output g = 1 permanently if y becomes 1 within two clock cycles.
- State F: The state where the FSM sets output g = 0 permanently if y does not become 1 within two clock cycles.
