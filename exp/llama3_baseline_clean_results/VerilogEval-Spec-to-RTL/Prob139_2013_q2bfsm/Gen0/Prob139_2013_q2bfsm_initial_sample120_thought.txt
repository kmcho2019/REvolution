To implement the described finite state machine, we can define several states:
- State A (initial state): the FSM stays in this state as long as the reset signal is asserted.
- State B: the FSM sets output f to 1 for one clock cycle after reset is de-asserted.
- State C: the FSM monitors the x input for the sequence 1, 0, 1.
- State D: the FSM monitors the y input for a 1 within two clock cycles after the x sequence is detected.
- State E: the FSM sets output g to 1 permanently if y becomes 1 within two clock cycles.
- State F: the FSM sets output g to 0 permanently if y does not become 1 within two clock cycles.

We will use an enum to represent these states and implement the state transitions based on the inputs x, y, and the current state.
