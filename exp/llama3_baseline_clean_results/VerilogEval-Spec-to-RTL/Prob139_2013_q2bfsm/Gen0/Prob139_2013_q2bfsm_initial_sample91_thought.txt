To implement the finite state machine (FSM) as described, we will break down the functionality into distinct states and use a state machine to transition between these states based on the inputs x and y, and the outputs f and g. The states we'll consider are: 
- State A (initial state, reset state): FSM stays here as long as resetn is asserted.
- State B (reset de-asserted, setting f=1): One clock cycle after resetn is de-asserted, set f to 1 for one clock cycle.
- State C (monitoring x for sequence 101): After State B, the FSM waits for the sequence 1, 0, 1 on the x input.
- State D (set g=1, monitoring y): After the sequence is detected, set g to 1 and monitor y.
- State E (g=1 permanently if y=1 within two cycles, otherwise g=0 permanently): Depending on y's value within two cycles, either maintain g=1 or set g=0.

We'll use a counter to track the number of cycles in certain states and flags to track the sequence on x and the presence of y=1.
