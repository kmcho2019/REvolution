To implement this finite state machine (FSM), we will use a combination of state variables and conditional statements to manage the transitions between states based on the input signals x and y. The FSM will start in state A when the reset signal is asserted. Once the reset signal is de-asserted, it will transition to state B where it sets output f to 1 for one clock cycle. Then, it will enter a sequence of states to monitor the x input for the sequence 1, 0, 1. Upon detecting this sequence, it will set output g to 1 and enter a state where it monitors the y input. If y becomes 1 within two clock cycles, g remains 1; otherwise, g is set to 0 permanently until reset. We will use Verilog's enum type to define the states and a case statement to handle state transitions and output logic.
