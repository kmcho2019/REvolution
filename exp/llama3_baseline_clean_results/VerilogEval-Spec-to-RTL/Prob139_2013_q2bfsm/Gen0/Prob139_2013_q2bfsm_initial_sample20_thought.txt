To solve this problem, we can design a finite state machine (FSM) with several states to track the sequence of input values and control the outputs accordingly. 

1. We start in state A when reset is asserted.
2. When reset is de-asserted, we move to state B, where we set output f to 1 for one clock cycle.
3. Then, we move to state C, where we monitor the x input for the sequence 1, 0, 1.
4. Once the sequence is detected, we move to state D, where we set output g to 1 and monitor the y input for a high value within two clock cycles.
5. If y becomes 1 within two clock cycles, we move to state E, where we maintain g = 1 permanently.
6. If y does not become 1 within two clock cycles, we move to state F, where we set g = 0 permanently.
