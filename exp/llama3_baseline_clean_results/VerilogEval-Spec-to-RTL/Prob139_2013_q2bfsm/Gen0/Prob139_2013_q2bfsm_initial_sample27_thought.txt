- State A (initial state, reset): The FSM stays in this state as long as the reset signal is asserted.
- State B: After the reset signal is de-asserted, the FSM moves to this state and sets output f to 1 for one clock cycle.
- State C: The FSM monitors the x input, waiting for the sequence 1, 0, 1 in three successive clock cycles.
- State D: After the sequence 1, 0, 1 is detected, the FSM sets output g to 1 and moves to this state, where it monitors the y input.
- State E: If y becomes 1 within two clock cycles, the FSM moves to this state and maintains g = 1 permanently.
- State F: If y does not become 1 within two clock cycles, the FSM moves to this state and sets g = 0 permanently.
We will use a counter to keep track of the number of clock cycles in States C and D.
