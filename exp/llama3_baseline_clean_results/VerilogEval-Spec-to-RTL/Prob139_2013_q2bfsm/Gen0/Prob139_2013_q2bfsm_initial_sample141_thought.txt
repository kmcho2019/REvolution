To solve this problem, we need to design a finite state machine (FSM) that can keep track of its current state and transition to the next state based on the input values. The FSM will have several states: 
1. State A: The initial state where the FSM stays when the reset signal is asserted.
2. State B: The state where the FSM sets output f to 1 for one clock cycle after the reset signal is de-asserted.
3. State C: The state where the FSM monitors the x input for the sequence 1, 0, 1.
4. State D: The state where the FSM sets output g to 1 and monitors the y input.
5. State E: The state where the FSM maintains g = 1 permanently if y becomes 1 within two clock cycles.
6. State F: The state where the FSM sets g = 0 permanently if y does not become 1 within two clock cycles.

We will use a counter to keep track of the number of clock cycles in states C and D.
