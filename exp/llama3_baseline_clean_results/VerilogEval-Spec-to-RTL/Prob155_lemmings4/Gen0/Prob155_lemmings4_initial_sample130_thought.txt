To implement the Lemmings' finite state machine, we need to define the states and their transitions based on the given conditions. The states can be walking left, walking right, falling, digging, and splattered. We will use a Moore state machine, where the outputs are determined by the current state and the inputs. The state transitions will be based on the input conditions such as bump_left, bump_right, ground, and dig. We will also keep track of the number of clock cycles the Lemming has been falling to determine if it splatters when hitting the ground.
