The problem requires a finite state machine (FSM) with several states to model the behavior of a Lemming in the Lemmings game. The states can be defined as follows:
- Walking left or right: The Lemming can walk in either direction and switch directions when bumped.
- Falling: The Lemming will fall and say "aaah!" when ground=0.
- Digging: The Lemming can dig if it is currently walking on ground and will continue digging until it reaches the other side.
- Splattered: The Lemming will splatter if it falls for more than 20 clock cycles and then hits the ground.

The FSM will transition between these states based on the input signals (bump_left, bump_right, ground, dig). The output signals (walk_left, walk_right, aaah, digging) will be determined by the current state of the FSM.

To implement the FSM, we can use a Moore machine, where the outputs are determined solely by the current state. We will use a counter to track the number of clock cycles the Lemming has been falling.

We will use the following states:
- S_WALK_LEFT: The Lemming is walking left.
- S_WALK_RIGHT: The Lemming is walking right.
- S_FALLING: The Lemming is falling.
- S_DIGGING: The Lemming is digging.
- S_SPLATTERED: The Lemming has splattered.

The transitions between states will be based on the input signals and the current state. For example, if the Lemming is walking left and bump_right is 1, it will transition to S_WALK_RIGHT.
