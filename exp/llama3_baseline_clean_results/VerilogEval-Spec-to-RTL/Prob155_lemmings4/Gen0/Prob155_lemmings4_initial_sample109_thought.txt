To implement the Lemming behavior, we can model the system as a finite state machine with multiple states to track the Lemming's current activity (walking left, walking right, falling, digging, splattered). The state machine will be updated based on the current state and input signals (bump_left, bump_right, ground, dig). 

We can use a Moore machine, where the outputs are a function of the current state. We will need to keep track of the number of clock cycles the Lemming has been falling to check for splattering. 

The states of the machine can be defined as:
- IDLE_LEFT: The Lemming is walking left.
- IDLE_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered.

The state machine will transition between these states based on the input signals and the current state.
