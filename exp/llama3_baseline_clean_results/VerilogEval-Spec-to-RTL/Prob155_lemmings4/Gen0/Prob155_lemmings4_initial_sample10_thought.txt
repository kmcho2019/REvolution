To implement the Lemming's behavior, we'll design a Moore state machine with the following states:
- WALK_LEFT: Walking to the left
- WALK_RIGHT: Walking to the right
- FALLING: Falling due to no ground
- DIGGING: Digging through the ground
- SPLATTERED: Splattered after a long fall

The state machine will transition between these states based on the input signals (bump_left, bump_right, ground, dig) and the current state.

We'll also need to keep track of the number of clock cycles the Lemming has been falling to determine if it should splatter when hitting the ground.

The outputs (walk_left, walk_right, aaah, digging) will be determined by the current state of the state machine.
