To implement the Lemming behavior as a Moore state machine, we need to identify the main states and transitions between them. The main states can be identified as walking left, walking right, falling, and digging. We also need to consider the special case of splattering when the Lemming falls for more than 20 clock cycles and hits the ground. We will use a counter to keep track of the number of clock cycles the Lemming has been falling. We will also use a state machine with the following states: IDLE (initial state), WALK_LEFT, WALK_RIGHT, FALLING, DIGGING, and SPLATTERED.
