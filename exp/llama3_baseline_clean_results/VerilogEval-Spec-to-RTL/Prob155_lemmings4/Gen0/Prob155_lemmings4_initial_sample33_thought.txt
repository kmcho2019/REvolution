The Moore state machine for the Lemming behavior will be implemented using a finite state machine (FSM) with the following states:
- Walking Left (WL)
- Walking Right (WR)
- Falling (F)
- Digging Left (DL)
- Digging Right (DR)
- Splattered (S)

The FSM will be implemented using a 3-bit state register with the following encoding:
- WL: 000
- WR: 001
- F: 010
- DL: 011
- DR: 100
- S: 101

The next state logic will be designed based on the given conditions, and the outputs will be generated based on the current state.

The FSM will also include a counter to track the number of clock cycles the Lemming has been falling, and a flag to track the direction the Lemming was walking before falling or digging.
