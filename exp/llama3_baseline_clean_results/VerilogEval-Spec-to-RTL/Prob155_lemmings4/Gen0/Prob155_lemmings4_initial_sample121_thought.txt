To implement this finite state machine, we need to consider the different states the Lemming can be in: walking left, walking right, falling, digging, and splattered. We'll use a Moore state machine, where the outputs are a function of the current state only. The state transitions will be determined by the inputs (bump_left, bump_right, ground, dig) and the current state.
