To model the behavior of the Lemming, we will design a Moore state machine with the following states:
- Walking Left
- Walking Right
- Falling
- Digging
- Splattered

We will use a single 3-bit state variable to represent these states. The state machine will change its state based on the inputs and the current state.

For the falling state, we need to keep track of the number of clock cycles the Lemming has been falling. We will use a 5-bit counter for this purpose.

We will also use combinational logic to determine the next state and the output values based on the current state, inputs, and the counter value.
