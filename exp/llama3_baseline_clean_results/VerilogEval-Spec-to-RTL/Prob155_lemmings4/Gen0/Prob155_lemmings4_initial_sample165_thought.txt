To implement the Lemmings' behavior using a Moore state machine, we will use the following states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALL: The Lemming is falling.
- DIG: The Lemming is digging.
- SPLAT: The Lemming has splattered and will no longer walk, fall, or dig.

We will use a counter to track the number of clock cycles the Lemming has been falling. When the Lemming hits the ground after falling for more than 20 clock cycles, it will transition to the SPLAT state.

We will use a variable to track the Lemming's previous direction, so that when it resumes walking after falling or digging, it will continue in the same direction.
