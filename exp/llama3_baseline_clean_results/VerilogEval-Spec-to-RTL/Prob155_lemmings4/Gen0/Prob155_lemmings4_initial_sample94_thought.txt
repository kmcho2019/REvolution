To implement the Lemmings behavior as a finite state machine in Verilog, we can define several states:
1. Idle: The initial state, where the Lemming walks left.
2. Walking Left: The Lemming walks to the left.
3. Walking Right: The Lemming walks to the right.
4. Falling: The Lemming falls when it hits a hole (ground = 0).
5. Digging: The Lemming digs when it receives a dig signal.
6. Splattered: The Lemming splatters when it hits the ground after falling for more than 20 clock cycles.

We can use a Moore state machine, where the outputs are determined solely by the current state. We will also use a counter to keep track of the number of clock cycles the Lemming has been falling.

The state machine will transition between states based on the input signals:
- If the Lemming hits an obstacle (bump_left or bump_right), it will switch directions.
- If the Lemming hits a hole (ground = 0), it will fall.
- If the Lemming is told to dig (dig = 1) and it is walking on ground, it will start digging.
- If the Lemming hits the ground after falling for more than 20 clock cycles, it will splatter.

We will use a case statement to determine the next state based on the current state and the input signals.
