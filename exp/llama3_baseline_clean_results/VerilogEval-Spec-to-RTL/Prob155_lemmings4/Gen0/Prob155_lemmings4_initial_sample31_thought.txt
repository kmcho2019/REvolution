To model the behavior of a Lemming using a Moore state machine, we need to define the states and transitions that capture the various actions (walking left, walking right, falling, digging, and splattering) and the conditions that trigger these actions. We can break down the problem into several steps:
1. Define the states: 
   - Walking left
   - Walking right
   - Falling
   - Digging
   - Splattered

2. Determine the transitions between these states based on the given conditions (bumps, ground, dig signal).

3. Implement a counter to track the number of clock cycles a Lemming has been falling to determine if it should splatter upon hitting the ground.

The state machine will transition between these states based on the inputs and will output the corresponding signals (walk_left, walk_right, aaah, digging) based on the current state.
