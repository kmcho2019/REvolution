To implement the Lemmings finite state machine, we can use a Moore state machine. 
We need to define the states of the machine and the transitions between them. 
The states can be: WALKING_LEFT, WALKING_RIGHT, FALLING, DIGGING. 
Additionally, we need to handle the splattering condition, which can be considered as a separate state (SPLATTERED) that the machine enters after falling for more than 20 clock cycles and then hitting the ground.
We also need to keep track of the direction of the Lemming before it starts falling or digging, so that it can resume walking in the same direction when it hits the ground or finishes digging.
We will use a counter to keep track of the number of clock cycles the Lemming has been falling.
The machine will transition between states based on the input signals (bump_left, bump_right, ground, dig).
We will use a reset signal (areset) to reset the machine to the WALKING_LEFT state.
