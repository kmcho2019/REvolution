To implement the Lemmings' behavior, we will design a Moore finite state machine (FSM) with the following states: 
- Walking left
- Walking right
- Falling
- Digging
- Splattered

The FSM will transition between these states based on the input signals (bump_left, bump_right, ground, dig). 
We will use a 3-bit state register to encode these five states, with the two extra states (3 and 4) being unused. 
The FSM will use a 5-bit counter to count the number of clock cycles the Lemming has been falling.

The FSM will start in the walking left state after reset. 
It will transition to the walking right state if it receives a bump on the left or if it receives a bump on both sides. 
It will transition to the walking left state if it receives a bump on the right.

When the ground disappears, the FSM will transition to the falling state. 
In the falling state, the FSM will count the number of clock cycles it has been falling. 
If the ground reappears and the Lemming has been falling for more than 20 clock cycles, the FSM will transition to the splattered state. 
If the ground reappears and the Lemming has been falling for less than or equal to 20 clock cycles, the FSM will transition back to the walking state it was in before falling.

When the dig signal is high, the FSM will transition to the digging state if it is currently in the walking state and there is ground. 
In the digging state, the FSM will continue digging until the ground disappears, at which point it will transition to the falling state.

If the FSM is in the splattered state, it will output 0 on all output signals and will remain in this state until it is reset.
