To implement the Lemming's behavior, we can design a Moore state machine with several states:
- WALKING_LEFT: the Lemming is walking left
- WALKING_RIGHT: the Lemming is walking right
- FALLING: the Lemming is falling
- DIGGING: the Lemming is digging
- SPLATTERED: the Lemming has splattered and is no longer moving

We will use a counter to keep track of the number of clock cycles the Lemming has been falling. If this counter exceeds 20 when the Lemming hits the ground, it will splatter.

We will use combinational logic to determine the next state based on the current state and input signals. We will also use sequential logic to update the current state and outputs on the positive edge of the clock.
