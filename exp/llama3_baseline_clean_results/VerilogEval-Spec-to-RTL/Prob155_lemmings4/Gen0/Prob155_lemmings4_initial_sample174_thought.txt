To implement the Lemmings behavior, we can use a finite state machine with several states to model walking, falling, digging, and splattering. The state machine will have the following states:
- WALK_LEFT: Walking to the left
- WALK_RIGHT: Walking to the right
- FALLING: Falling
- DIGGING: Digging
- SPLATTERED: Splattered (final state)
We will use a counter to track the number of clock cycles spent falling. If the counter exceeds 20 and the Lemming hits the ground, it will splatter. The state machine will be implemented using a Moore model, where the output depends only on the current state.
