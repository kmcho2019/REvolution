To implement the Lemmings' behavior as a Moore state machine, we first need to identify the states that the Lemming can be in. Based on the problem description, we can identify the following states:
- Walking left
- Walking right
- Falling
- Digging
- Splattered

We will also need to keep track of the Lemming's direction and the number of cycles it has been falling.

When the Lemming is walking, it can change direction if it hits an obstacle or start digging if it is told to. When it is falling, it will continue to fall until it hits the ground. If it falls for more than 20 cycles, it will splatter when it hits the ground. When it is digging, it will continue digging until it reaches the other side, then it will fall and eventually hit the ground.

We will use a counter to keep track of the number of cycles the Lemming has been falling. If this counter exceeds 20 when the Lemming hits the ground, it will splatter.
