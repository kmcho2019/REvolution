To implement the Lemmings finite state machine, we will define several states: 
- WALKING_LEFT: The Lemming is walking left.
- WALKING_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and ceased all activity.
We will use a 2-bit state register to represent these states. 
We will also use a 5-bit counter to keep track of the number of clock cycles the Lemming has been falling.
We will define the state transitions based on the input signals and the current state.
The output signals (walk_left, walk_right, aaah, digging) will be determined based on the current state.
We will handle the areset signal by asynchronously resetting the state machine to the WALKING_LEFT state.
