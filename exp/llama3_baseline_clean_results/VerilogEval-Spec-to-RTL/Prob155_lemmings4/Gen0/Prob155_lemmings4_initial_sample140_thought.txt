To model the behavior of the Lemming, we will implement a finite state machine with several states:
- Walking left
- Walking right
- Falling
- Digging
- Splattered

We will use two counters to track the number of cycles the Lemming has been falling and the number of cycles it has been digging.

The state machine will be initialized to the walking left state when the reset signal is high.

We will use a Moore machine, where the outputs are a function of the current state only.

The state transitions will be based on the inputs and the current state. 
For example, when the Lemming is walking left and it hits an obstacle on the left, it will switch to the walking right state.
If the Lemming is walking and there is no ground, it will switch to the falling state.
If the Lemming is walking and it is told to dig, it will switch to the digging state.
If the Lemming has been falling for more than 20 cycles and it hits the ground, it will switch to the splattered state.

In each state, we will set the outputs accordingly. For example, when the Lemming is walking left, the walk_left output will be high.
When the Lemming is falling, the aaah output will be high.
When the Lemming is digging, the digging output will be high.
When the Lemming is splattered, all outputs will be low.
