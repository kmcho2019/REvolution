To implement the Lemming machine as a Moore state machine, we need to define the states and transitions based on the given behavior. The machine has several distinct behaviors: walking left or right, falling, digging, and splattering. 

The states can be defined as follows:
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and is no longer active.

Transitions between these states will be based on the input signals: bump_left, bump_right, ground, and dig. 

When the Lemming is walking and hits an obstacle (bump_left or bump_right), it will switch direction. If the ground disappears (ground=0), the Lemming will start falling. If the Lemming is told to dig (dig=1) while walking on the ground, it will start digging. 

If the Lemming falls for more than 20 clock cycles and then hits the ground, it will splatter. The splattered state is a terminal state, and the machine will remain in this state until it is reset.

The outputs (walk_left, walk_right, aaah, digging) will be determined by the current state of the machine.
