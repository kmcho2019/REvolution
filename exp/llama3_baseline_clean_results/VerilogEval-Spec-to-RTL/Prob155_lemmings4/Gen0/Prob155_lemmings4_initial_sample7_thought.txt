To implement the Lemmings' behavior, we need to design a Moore state machine with the following states:
- WALK_LEFT: walking left
- WALK_RIGHT: walking right
- FALLING: falling
- DIGGING: digging
- SPLATTERED: splattered

The state machine will transition between these states based on the input signals. We will also use a counter to track the number of clock cycles the Lemming has been falling.

The state machine will have the following outputs:
- walk_left: 1 if the Lemming is walking left
- walk_right: 1 if the Lemming is walking right
- aaah: 1 if the Lemming is falling
- digging: 1 if the Lemming is digging

We will use a 5-bit counter to track the number of clock cycles the Lemming has been falling. If the counter exceeds 20, the Lemming will splatter when it hits the ground.
