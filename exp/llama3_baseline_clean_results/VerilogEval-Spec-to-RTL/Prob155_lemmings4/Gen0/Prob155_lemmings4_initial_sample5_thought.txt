To model the behavior of a Lemming, we will implement a Moore state machine with the following states: 
- WALKING_LEFT: The Lemming is walking to the left.
- WALKING_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and is no longer moving.

The state machine will transition between these states based on the input signals. For example, if the Lemming is walking left and receives a bump on the left, it will transition to walking right. If the ground disappears, the Lemming will transition to the falling state. If the Lemming is digging and the ground disappears, it will transition to the falling state. If the Lemming is falling for more than 20 clock cycles and then hits the ground, it will transition to the splattered state.

We will use a counter to keep track of how many clock cycles the Lemming has been falling. If this counter exceeds 20 and the Lemming hits the ground, it will transition to the splattered state.

The output signals will be generated based on the current state of the state machine. For example, if the Lemming is walking left, the walk_left signal will be high. If the Lemming is falling, the aaah signal will be high.
