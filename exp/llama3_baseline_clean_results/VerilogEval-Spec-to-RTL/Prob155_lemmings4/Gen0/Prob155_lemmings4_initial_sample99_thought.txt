To implement this finite state machine, we can define the following states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and is no longer walking, falling, or digging.

The state transitions are as follows:
- If the Lemming is walking and hits an obstacle, it will switch directions.
- If the Lemming is walking and the ground disappears, it will start falling.
- If the Lemming is falling and the ground reappears, it will resume walking in the same direction as before the fall.
- If the Lemming is walking and is told to dig, it will start digging.
- If the Lemming is digging and the ground disappears, it will start falling.
- If the Lemming falls for more than 20 clock cycles and hits the ground, it will splatter.

We will use a counter to keep track of the number of clock cycles the Lemming has been falling.
