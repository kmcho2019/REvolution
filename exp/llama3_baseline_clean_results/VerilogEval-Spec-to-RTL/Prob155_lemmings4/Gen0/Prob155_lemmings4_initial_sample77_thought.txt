The problem can be solved by implementing a finite state machine with the following states:
- WALK_LEFT: Walking left on the ground
- WALK_RIGHT: Walking right on the ground
- FALLING: Falling due to no ground
- DIGGING_LEFT: Digging while walking left
- DIGGING_RIGHT: Digging while walking right
- SPLATTERED: Lemming has splattered and is no longer moving
We will use a counter to track the number of clock cycles the Lemming has been falling.
The next state logic will be determined by the current state and the input signals.
The output logic will be determined by the current state.
