To implement the Lemming state machine, we'll use a Moore machine with several states to model the Lemming's behavior. The states will include walking left, walking right, falling, digging, and splattered. We'll use a counter to track the number of clock cycles the Lemming has been falling to determine if it should splatter when hitting the ground. We'll also use a variable to keep track of the Lemming's walking direction before it falls or starts digging, so it can resume walking in the same direction when the ground reappears or when it finishes digging.
