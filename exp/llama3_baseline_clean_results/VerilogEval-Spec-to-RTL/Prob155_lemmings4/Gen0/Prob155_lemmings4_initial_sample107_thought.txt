To solve this problem, we'll create a Moore state machine with several states: 
1. Walking left
2. Walking right
3. Falling
4. Digging
5. Splattered

The machine will start in the walking left state. It will switch between walking left and right when bumped. 
When the ground disappears, the machine will transition to the falling state. 
When the ground reappears, it will transition back to its previous walking state.
When the dig signal is asserted, the machine will transition to the digging state if it's currently walking on ground.
When the machine falls for more than 20 clock cycles and hits the ground, it will transition to the splattered state.

We'll use a counter to track the number of clock cycles the machine has been falling.
