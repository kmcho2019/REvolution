To implement the Lemmings' behavior as a Moore state machine, we need to define the states and transitions based on the given conditions. The states can be broadly categorized into walking, falling, and digging. Within the walking state, we need to track the direction (left or right). For the falling state, we need to keep track of the number of clock cycles to determine if the Lemming splatters upon hitting the ground. The digging state is a subset of the walking state but with the added condition of the Lemming digging.

We start by defining the states:
- `IDLE_LEFT`: Initial state, walking left.
- `IDLE_RIGHT`: Walking right.
- `FALLING`: Falling, not walking or digging.
- `DIGGING_LEFT`: Digging while walking left.
- `DIGGING_RIGHT`: Digging while walking right.
- `SPLATTERED`: The Lemming has splattered and is no longer active.

Transitions between these states will be based on the input conditions such as `bump_left`, `bump_right`, `ground`, and `dig`. The `areset` signal resets the machine to `IDLE_LEFT`.

Given the complexity of the transitions and the need to keep track of the fall duration, we'll use a counter within the `FALLING` state to monitor the number of clock cycles the Lemming has been falling.
