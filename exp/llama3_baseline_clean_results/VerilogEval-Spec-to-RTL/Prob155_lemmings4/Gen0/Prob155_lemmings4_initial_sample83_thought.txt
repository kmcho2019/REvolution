To implement the Lemmings behavior as a Moore state machine, we need to consider the following states:
- Walking left
- Walking right
- Falling
- Digging
- Splattered
We also need to track the direction the Lemming was walking before it started falling or digging.
The Lemming's state transitions are determined by the input signals (bump_left, bump_right, ground, dig) and the current state.
We will use a 4-bit state variable to represent the current state and the previous walking direction.
We will also use a counter to track the number of clock cycles the Lemming has been falling.
The state machine will be reset to the "Walking left" state when areset is high.
