To implement the Lemmings' behavior as a finite state machine, we will define several states to model its actions: walking left, walking right, falling, and digging. We will use a counter to track how long the Lemming has been falling to determine if it should splatter upon hitting the ground. The machine will start in a walking left state when reset. It will transition between walking states when bumped, fall when ground disappears, and dig when instructed and conditions are met. The state machine will also handle the case where the Lemming splatters upon hitting the ground after a long fall.
