To implement the Lemmings' behavior as a Moore state machine, we'll define the states as follows: 
- idle_left: walking left on ground
- idle_right: walking right on ground
- falling: falling due to no ground
- digging_left: digging while walking left
- digging_right: digging while walking right
- dead: Lemming has splattered
We will then define the transitions between these states based on the given conditions, such as bumps, ground, and dig signals. 
The outputs will be determined by the current state and the current inputs. 
We will use a counter to track the number of clock cycles a Lemming has been falling. 
We will also use a variable to store the previous direction of the Lemming when it starts falling, so that it can resume walking in the same direction when the ground reappears.
