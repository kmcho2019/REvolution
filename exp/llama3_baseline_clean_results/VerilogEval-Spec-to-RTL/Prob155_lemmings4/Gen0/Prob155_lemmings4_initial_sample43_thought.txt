The state transitions will be based on the inputs: bump_left, bump_right, ground, dig, and the current state. If the Lemming has been falling for more than 20 cycles, it will transition to the splattered state.

We will use a combination of sequential logic and combinatorial logic to implement the state machine. The sequential logic will be triggered on the positive edge of the clock, and the combinatorial logic will be used to determine the next state and outputs based on the current state and inputs.
