To model the Lemming's behavior, we will implement a Moore state machine with the following states:
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and will not move again.

We will use a counter to track the number of clock cycles the Lemming has been falling. When this counter exceeds 20, the Lemming will enter the SPLATTERED state if it hits the ground.

We will also use a variable to keep track of the Lemming's direction before it started falling or digging, so that it can resume walking in the same direction when the ground reappears or it finishes digging.
