The problem requires implementing a finite state machine (FSM) to model the behavior of a Lemming in the game Lemmings. The FSM will have several states to track the Lemming's current activity (walking, falling, digging, or splattered) and its direction (left or right). We will use a Moore state machine, which means the outputs will be a function of the current state only. The FSM will have the following states:
- IDLE: Initial state where the Lemming is walking left.
- WALKING_LEFT: State where the Lemming is walking to the left.
- WALKING_RIGHT: State where the Lemming is walking to the right.
- FALLING: State where the Lemming is falling due to no ground.
- DIGGING: State where the Lemming is digging.
- SPLATTERED: State where the Lemming has splattered and is no longer active.
The transitions between states will be based on the input signals (bump_left, bump_right, ground, dig) and the current state.
To implement the state machine, we will use a reg variable to store the current state and a case statement to handle the state transitions and output assignments.
We will also use counters to track the number of clock cycles the Lemming has been falling.
