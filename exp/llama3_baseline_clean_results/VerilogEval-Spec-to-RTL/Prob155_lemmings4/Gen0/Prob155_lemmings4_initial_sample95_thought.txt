To implement the Lemmings' behavior using a finite state machine, we will define the following states:
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALL: The Lemming is falling.
- DIG: The Lemming is digging.
- SPLATTER: The Lemming has splattered and is no longer active.

We will use a counter to keep track of the number of clock cycles the Lemming has been falling. If this counter exceeds 20 when the Lemming hits the ground, it will transition to the SPLATTER state.

The state transitions will be based on the input signals: bump_left, bump_right, ground, and dig. We will also use the current state and the counter value to determine the next state.

The outputs (walk_left, walk_right, aaah, and digging) will be determined by the current state.
