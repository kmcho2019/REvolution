To implement the Lemming behavior as a Moore state machine, we need to define the states and transitions based on the given conditions. We can break down the states into the following:

- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered.

We will use a counter to keep track of the number of clock cycles the Lemming has been falling. If the Lemming hits the ground after falling for more than 20 clock cycles, it will transition to the SPLATTERED state.

We will also use a variable to store the previous walking direction, so that when the Lemming resumes walking after falling or digging, it will continue in the same direction.

The state machine will transition between these states based on the input signals and the current state.
