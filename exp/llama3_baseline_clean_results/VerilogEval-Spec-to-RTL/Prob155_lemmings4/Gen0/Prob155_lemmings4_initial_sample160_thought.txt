To implement the Lemmings behavior, we can design a Moore finite state machine (FSM) with the following states:
- WALK_LEFT: Lemming is walking left
- WALK_RIGHT: Lemming is walking right
- FALLING: Lemming is falling
- DIGGING: Lemming is digging
- SPLATTERED: Lemming has splattered and ceased walking, falling, or digging

The FSM will transition between these states based on the input signals and the current state. We will also keep track of the number of clock cycles the Lemming has been falling to determine if it should splatter.

We can use two counters to keep track of the fall counter and a separate variable to keep track of the current walking direction. We will also use a separate flag to indicate if the Lemming is currently digging or not.
