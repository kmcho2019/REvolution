To solve this problem, we will design a Moore state machine with the following states: 
- WALKING_LEFT: the Lemming is walking left
- WALKING_RIGHT: the Lemming is walking right
- FALLING: the Lemming is falling
- DIGGING: the Lemming is digging
- SPLATTERED: the Lemming has splattered

We will use a counter to keep track of the number of clock cycles the Lemming has been falling. If the Lemming hits the ground after more than 20 clock cycles, it will splatter.

The state machine will transition between these states based on the input signals. For example, if the Lemming is walking and the ground disappears, it will start falling. If the Lemming is falling and the ground reappears, it will resume walking in the same direction.

We will use a 2-bit register to keep track of the current state and another register to keep track of the direction the Lemming was walking before falling or digging.
