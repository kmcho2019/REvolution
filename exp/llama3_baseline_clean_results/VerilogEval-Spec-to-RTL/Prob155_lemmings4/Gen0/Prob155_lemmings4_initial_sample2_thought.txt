The problem can be solved by implementing a finite state machine with the following states: 
- walking_left: The Lemming is currently walking to the left.
- walking_right: The Lemming is currently walking to the right.
- falling: The Lemming is currently falling due to lack of ground.
- digging: The Lemming is currently digging.
- splattered: The Lemming has fallen for more than 20 clock cycles and hit the ground.

The state machine will transition between these states based on the input signals and the current state.

We will use two counters, one to count the number of clock cycles the Lemming has been falling (fall_counter) and another to keep track of the Lemming's walking direction (direction). 

The output signals will be determined by the current state and the input signals.

To implement the state machine, we will use a Moore machine, where the output signals are determined by the current state and not by the input signals.
