To model the Lemming's behavior as a finite state machine, we will use a Moore machine. The states we need to consider are:
- Walking left
- Walking right
- Falling
- Digging
- Splattered

We will use a 3-bit state register to represent these states. The transitions between states will be determined by the input signals. 

For the falling and digging states, we also need to keep track of the number of clock cycles spent in those states to determine when the Lemming should splatter or stop digging. 

We will also need to remember the direction the Lemming was walking before it started falling or digging, so it can resume walking in the same direction when it hits the ground again.
