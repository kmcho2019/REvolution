The problem can be solved by implementing a Moore state machine with the following states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and is no longer active.

The state machine will transition between these states based on the input signals.
When the Lemming is walking, it will switch directions if it hits an obstacle.
If the ground disappears, the Lemming will fall and say "aaah!".
When the ground reappears, the Lemming will resume walking in the same direction as before the fall.
If the Lemming is told to dig and is currently walking on ground, it will start digging and continue until it reaches the other side.
If the Lemming falls for more than 20 clock cycles and then hits the ground, it will splatter and cease walking, falling, or digging.

The state machine will be implemented using a single always block with a case statement to handle the different states.
The current state and next state will be stored in two separate registers.
The outputs will be determined based on the current state.
