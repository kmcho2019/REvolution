To implement the Lemmings finite state machine, we will design a Moore state machine with several states: walking left, walking right, falling, and digging. The machine will switch between these states based on the inputs: bump_left, bump_right, ground, and dig.

We will use a binary counter to count the number of clock cycles the Lemming has been falling. If the Lemming falls for more than 20 clock cycles and then hits the ground, it will splatter and cease all activities.

We will also use a current direction register to keep track of the Lemming's walking direction before it falls or starts digging, so that it can resume walking in the same direction after it hits the ground again or finishes digging.

The state machine will have the following states:
- IDLE_LEFT: The Lemming is walking left.
- IDLE_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and ceased all activities.

The state machine will transition between these states based on the inputs and the current state.
