To model the behavior of the Lemming machine, we will design a Moore state machine with the following states: 
- WALKING_LEFT: The Lemming is walking left.
- WALKING_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- DEAD: The Lemming has splattered.

The state transitions will be based on the current state and the input signals. We will also use a counter to keep track of the number of clock cycles the Lemming has been falling. If this counter exceeds 20, the Lemming will splatter when it hits the ground.

We will use a separate counter to keep track of the original walking direction when the Lemming is falling or digging, so that it can resume walking in the same direction when the ground reappears or when it finishes digging.
