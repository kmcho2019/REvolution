To implement the TopModule, we can define a Moore state machine with the following states:
- WALK_LEFT: Walking left
- WALK_RIGHT: Walking right
- FALL: Falling
- DIG_LEFT: Digging while walking left
- DIG_RIGHT: Digging while walking right
- SPLATTER: Splattered (ceased all activity)
We will use two counters: 
- fall_counter to track the number of clock cycles since the Lemming started falling
- dig_counter to track the number of clock cycles since the Lemming started digging
The state machine will transition between these states based on the inputs and the current state.
