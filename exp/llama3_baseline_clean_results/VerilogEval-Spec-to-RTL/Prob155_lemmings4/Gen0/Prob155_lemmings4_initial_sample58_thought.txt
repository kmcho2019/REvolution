We will implement this FSM as a Moore state machine, where the outputs are determined by the current state. The states we need to consider are: walking left, walking right, falling, digging, and splattered. 

To implement the FSM, we will use a combination of state registers, counters, and combinational logic. We will also need to handle the asynchronous reset signal areset.

The state register will hold the current state of the FSM, and the counter will keep track of the number of clock cycles the Lemming has been falling. 

When the FSM is in the walking state, it will check for bumps, digging commands, and ground presence to determine the next state. 

When the FSM is in the falling state, it will check if the Lemming has fallen for more than 20 clock cycles. If so, it will transition to the splattered state. 

When the FSM is in the digging state, it will continue digging until the ground disappears, at which point it will transition to the falling state.

The outputs of the FSM will be determined by the current state and will be set accordingly.
