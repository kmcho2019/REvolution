To implement the Lemming's behavior, we need to design a Moore state machine that can keep track of the Lemming's current state (walking left, walking right, falling, or digging) and the number of clock cycles it has been falling. The machine should also be able to handle the various inputs (bump_left, bump_right, ground, dig) and determine the next state based on the current state and inputs.

The state machine will have several states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and is no longer moving.

The state machine will use a counter to keep track of the number of clock cycles it has been falling. If the counter exceeds 20 and the Lemming hits the ground, it will transition to the SPLATTERED state.

The machine will also need to handle the case where the ground reappears while the Lemming is still falling, and the case where the Lemming is told to dig while walking on the ground.
