To implement the TopModule, we'll create a finite state machine (FSM) with states that represent the Lemming's current activity (walking, falling, digging, or splattered). We'll use a Moore machine, where the outputs are determined solely by the current state. The states will be:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING_LEFT: The Lemming is digging while walking left.
- DIGGING_RIGHT: The Lemming is digging while walking right.
- SPLATTERED: The Lemming has splattered.

We'll use a counter to keep track of the number of clock cycles the Lemming has been falling. If this counter exceeds 20, the Lemming will splatter when it hits the ground.

The state transitions will be based on the inputs (bump_left, bump_right, ground, dig) and the current state. For example, if the Lemming is walking left and bump_left is high, it will switch to walking right.

The outputs (walk_left, walk_right, aaah, digging) will be determined by the current state. For example, if the Lemming is walking left, walk_left will be high.
