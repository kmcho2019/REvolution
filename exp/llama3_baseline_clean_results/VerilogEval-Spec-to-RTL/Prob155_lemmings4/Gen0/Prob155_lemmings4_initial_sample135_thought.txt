To implement the Lemming machine as a Moore state machine, we will define states for walking left, walking right, falling, digging, and splattered. The machine will transition between these states based on the input signals. We will use a counter to track the number of clock cycles the Lemming has been falling. The machine will also keep track of the direction the Lemming was walking before it fell or started digging, so it can resume walking in the same direction when it hits the ground again. We will use a separate signal to indicate whether the Lemming is currently digging, and another signal to indicate whether it has splattered.
