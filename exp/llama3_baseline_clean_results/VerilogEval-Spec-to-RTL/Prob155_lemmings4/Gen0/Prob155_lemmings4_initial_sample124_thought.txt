To model the behavior of the Lemming, we will use a Moore state machine. The states can be broken down into the following:
- Walking Left
- Walking Right
- Falling
- Digging
- Splattered

We will use an enumeration to represent these states. The state transitions will be based on the input conditions such as bump_left, bump_right, ground, and dig.

When the Lemming is in the walking state, it will switch directions if it hits an obstacle (bump_left or bump_right). If the ground disappears, it will start falling. If it's told to dig, it will start digging.

When the Lemming is falling, it will continue to fall until it hits the ground. If it falls for more than 20 clock cycles, it will splatter when it hits the ground.

When the Lemming is digging, it will continue digging until it reaches the other side. At that point, it will start falling.

The state machine will be implemented using a case statement to handle the different states and their corresponding next states.

The counters for falling and digging will be implemented using separate counters.
