To implement the Lemmings finite state machine, we can identify several states: walking left, walking right, falling, digging, and splattered. We will use an enumeration to represent these states. We will also use a counter to keep track of the number of clock cycles the Lemming has been falling.

The next state logic will be determined by the current state and the input signals. For example, if the Lemming is walking left and bump_left is 1, it will switch to walking right. If the Lemming is falling and ground becomes 1, it will check if it has been falling for more than 20 clock cycles and either splatter or resume walking.

The output logic will be determined by the current state. For example, if the Lemming is walking left, walk_left will be 1. If the Lemming is falling, aaah will be 1.
