To implement the Moore state machine, we first identify the states that a Lemming can be in. We can define the states as follows:
- Walking left
- Walking right
- Falling
- Digging
- Splattered

We need to define the transitions between these states and the outputs for each state. The transition from one state to another will be based on the input signals. 

We also need to keep track of the number of clock cycles a Lemming has been falling for, to determine if it should splatter when hitting the ground.

The state machine will be implemented using a case statement inside an always block, with the current state and inputs determining the next state and outputs.
