To implement the Lemmings' behavior as a Moore state machine, we will define states for walking left, walking right, falling, digging, and splattered. We'll use two counters to track the number of cycles spent falling and to remember the original walking direction when digging. The state machine will transition between states based on the input signals (bump_left, bump_right, ground, dig) and the current state. We'll also implement a reset mechanism to reset the state machine to walking left when areset is asserted.
