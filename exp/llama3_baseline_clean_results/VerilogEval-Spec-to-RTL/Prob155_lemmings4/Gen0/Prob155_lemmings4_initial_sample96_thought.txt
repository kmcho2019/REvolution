To implement the Lemming's behavior as a Moore state machine, we can break down the state machine into several states:
1. Walking left
2. Walking right
3. Falling
4. Digging
5. Splattered

We will use a 3-bit state register to encode these states (2^3 = 8, which is more than enough for our 5 states).

The next state logic will be determined based on the current state and the input signals.

When the Lemming is walking, it will switch directions if it hits an obstacle (bump_left or bump_right).
When the Lemming is walking and ground=0, it will fall.
When the Lemming is walking and dig=1, it will start digging if ground=1.
When the Lemming is falling, it will continue falling until ground=1, at which point it will resume walking in the original direction if it hasn't splattered.
When the Lemming is digging, it will continue digging until ground=0, at which point it will fall and then resume walking in the original direction when it hits ground again.

To detect if the Lemming has fallen for more than 20 clock cycles, we can use a 5-bit counter that increments every clock cycle when the Lemming is falling. If the counter exceeds 20 when the Lemming hits the ground, it will splatter.

The output logic will be determined based on the current state.

In the Verilog implementation, we will use a case statement to handle the next state logic and output logic.
