To implement the Lemmings' finite state machine, we can identify several states: walking left, walking right, falling, and digging. We will also need to track the number of cycles the Lemming has been falling to detect splattering. The state machine will be implemented using a Moore model, where the outputs are determined by the current state. We will use a reset signal to initialize the state machine to walk left.

The states and transitions are as follows:
- Walking left: transition to walking right if bumped on the left, transition to falling if ground disappears
- Walking right: transition to walking left if bumped on the right, transition to falling if ground disappears
- Falling: transition to walking left or right (depending on the previous direction) if ground reappears and the Lemming hasn't splattered, stay in falling state otherwise
- Digging: transition to falling if ground disappears, stay in digging state otherwise

We will use two registers to keep track of the current state and the number of cycles the Lemming has been falling. We will also use two variables to keep track of the previous walking direction and whether the Lemming has splattered.
