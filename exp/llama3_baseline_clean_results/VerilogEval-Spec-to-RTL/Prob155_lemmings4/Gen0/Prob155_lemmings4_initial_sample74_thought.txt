The solution involves designing a Moore state machine that models the behavior of the Lemming. The state machine will have several states: walking left, walking right, falling, digging, and splattered. The state machine will transition between these states based on the input signals. The outputs will be determined by the current state of the state machine. We will use a counter to track the number of clock cycles the Lemming has been falling.

The states can be defined as follows:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and ceased all activity.

The state machine will transition between these states based on the input signals. For example, if the Lemming is walking left and hits an obstacle on the left, it will transition to the WALK_RIGHT state. If the Lemming is walking and the ground disappears, it will transition to the FALLING state. If the Lemming has been falling for more than 20 clock cycles and hits the ground, it will transition to the SPLATTERED state.
