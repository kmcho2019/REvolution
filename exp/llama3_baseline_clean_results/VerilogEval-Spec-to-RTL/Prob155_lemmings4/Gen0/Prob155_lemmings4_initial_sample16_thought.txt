To implement the Lemming behavior, we will use a finite state machine (FSM) with the following states: 
1. Walking Left
2. Walking Right
3. Falling
4. Digging
5. Splattered

We will use a counter to keep track of how long the Lemming has been falling. If the counter exceeds 20 clock cycles and the Lemming hits the ground, it will splatter.

The state transitions will be as follows:
- From Walking Left or Walking Right, transition to Falling when ground=0.
- From Walking Left or Walking Right, transition to Digging when dig=1 and ground=1.
- From Falling, transition to Walking Left or Walking Right (depending on the previous walking direction) when ground=1, unless the Lemming has been falling for more than 20 clock cycles, in which case it will transition to Splattered.
- From Digging, transition to Falling when ground=0.

The output logic will be as follows:
- walk_left and walk_right will be set based on the current state (Walking Left or Walking Right).
- aaah will be set when the Lemming is Falling.
- digging will be set when the Lemming is Digging.
- All outputs will be cleared when the Lemming is Splattered.
