To implement the Lemming's behavior, we will design a Moore state machine with states representing the Lemming's current activity (walking, falling, digging, or splattered) and its walking direction. The machine will transition between these states based on the inputs (bump_left, bump_right, ground, dig) and maintain counters to track the number of cycles spent falling. We will use an enum to define the states and a case statement to handle the transitions between states. The outputs will be determined by the current state.
