To implement the Lemmings' behavior as a Moore state machine, we need to identify the different states that the Lemming can be in and the conditions under which it transitions between these states. 

We can define the following states:
- IDLE_LEFT: Walking left on the ground.
- IDLE_RIGHT: Walking right on the ground.
- FALLING: Falling due to lack of ground.
- DIGGING_LEFT: Digging while walking left.
- DIGGING_RIGHT: Digging while walking right.
- SPLATTERED: The Lemming has splattered and ceased all activity.

We will use a 3-bit state variable to represent these states. The state transitions are determined by the inputs (bump_left, bump_right, ground, dig) and the current state. The outputs (walk_left, walk_right, aaah, digging) are determined by the current state.

To implement the splatter condition, we need a counter to keep track of the number of clock cycles that the Lemming has been falling. If this counter exceeds 20 when the ground reappears, the Lemming will splatter.
