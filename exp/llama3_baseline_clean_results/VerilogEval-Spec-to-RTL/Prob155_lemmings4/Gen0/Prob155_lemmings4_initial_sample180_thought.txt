To model the behavior of a Lemming, we will implement a finite state machine (FSM) in Verilog. The FSM will have several states: walking left, walking right, falling, digging, and splattered. It will transition between these states based on the inputs (bump_left, bump_right, ground, dig). We will use a Moore state machine, where the outputs are a function of the current state only. The FSM will also keep track of the number of clock cycles spent falling to determine if it should splatter when hitting the ground.
