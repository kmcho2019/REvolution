To implement the described behavior, we need a finite state machine with states to represent walking left, walking right, falling, digging, and dead (splattered) states. The machine will also need to track the number of clock cycles the Lemming has been falling to determine if it should splatter upon hitting the ground.

The states can be defined as follows:
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is currently falling.
- DIGGING: The Lemming is digging.
- DEAD: The Lemming has splattered and will not move anymore.

We'll use a counter to keep track of the fall duration. If the Lemming falls for more than 20 clock cycles and hits the ground, it will transition to the DEAD state.

The next state logic will depend on the current state and inputs. For example, if the Lemming is walking and the ground disappears, it will start falling. If it's falling and the ground reappears, it will resume walking in the same direction as before the fall.

We'll use a Moore state machine, meaning the outputs are a function of the current state only.
