To implement the Lemmings' behavior, we need to model a finite state machine with the following states:
- Walking Left
- Walking Right
- Falling
- Digging
- Dead (splattered)

We will also keep track of the direction the Lemming was walking before falling or digging, so it can resume walking in that direction when it hits the ground or finishes digging.

The state transitions will be based on the inputs (bump_left, bump_right, ground, dig) and the current state. We will also use a counter to keep track of how long the Lemming has been falling, to determine if it should splatter when hitting the ground.

The state machine will be implemented using a Moore machine, where the outputs are determined by the current state.
