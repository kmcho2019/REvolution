To implement the Lemming's behavior as a Moore state machine, we can define the following states: 
- IDLE_LEFT: The Lemming is walking left on the ground.
- IDLE_RIGHT: The Lemming is walking right on the ground.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered.

The machine starts in the IDLE_LEFT state. If the ground disappears (ground=0), it transitions to the FALLING state. 
If the Lemming is told to dig (dig=1) while in the IDLE_LEFT or IDLE_RIGHT state, it transitions to the DIGGING state. 
If a bump is detected while in the IDLE_LEFT state, it transitions to the IDLE_RIGHT state. 
If a bump is detected while in the IDLE_RIGHT state, it transitions to the IDLE_LEFT state. 
If the Lemming falls for more than 20 clock cycles and hits the ground, it transitions to the SPLATTERED state.

The outputs are determined by the current state:
- walk_left: 1 if the Lemming is in the IDLE_LEFT state, 0 otherwise.
- walk_right: 1 if the Lemming is in the IDLE_RIGHT state, 0 otherwise.
- aaah: 1 if the Lemming is in the FALLING state, 0 otherwise.
- digging: 1 if the Lemming is in the DIGGING state, 0 otherwise.
