To implement this behavior, we can design a Moore state machine with the following states: 
- Walking Left
- Walking Right
- Falling
- Digging
- Splattered

The state machine starts in the Walking Left state. 
The state machine transitions between the states based on the input signals (bump_left, bump_right, ground, dig) and current state. 
For the Falling state, we need to count the number of clock cycles the Lemming has been falling to check if it has been falling for more than 20 clock cycles. 
If the Lemming hits the ground after falling for more than 20 clock cycles, it transitions to the Splattered state. 
In the Splattered state, all outputs are 0 and the state machine remains in this state until the areset signal is asserted.

We also need to consider the priority of the actions: falling has higher precedence than digging, which has higher precedence than switching directions.
