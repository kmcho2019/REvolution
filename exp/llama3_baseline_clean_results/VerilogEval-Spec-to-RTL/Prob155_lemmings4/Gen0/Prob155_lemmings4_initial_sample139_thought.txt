To implement the Lemming's behavior as a Moore state machine, we can define the following states:
- WALKING_LEFT: Lemming is walking left on the ground.
- WALKING_RIGHT: Lemming is walking right on the ground.
- FALLING: Lemming is falling.
- DIGGING: Lemming is digging.
- SPLATTERED: Lemming has splattered and is no longer moving.

The state machine transitions between these states based on the input signals:
- bump_left and bump_right: Switch the walking direction.
- ground: If 0, transition from walking to falling. If 1, transition from falling to walking.
- dig: If 1, transition from walking to digging. If 0, transition from digging to falling.

We also need to keep track of the number of clock cycles the Lemming has been falling to determine if it splatters when hitting the ground.

We can use a 4-bit counter to count the number of clock cycles the Lemming has been falling.
If the counter exceeds 20, the Lemming splatters when hitting the ground.

The output signals are determined by the current state:
- walk_left: 1 if the current state is WALKING_LEFT, 0 otherwise.
- walk_right: 1 if the current state is WALKING_RIGHT, 0 otherwise.
- aaah: 1 if the current state is FALLING, 0 otherwise.
- digging: 1 if the current state is DIGGING, 0 otherwise.
