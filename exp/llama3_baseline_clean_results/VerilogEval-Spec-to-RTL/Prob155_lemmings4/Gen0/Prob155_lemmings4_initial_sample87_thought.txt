To implement the TopModule, we need to create a finite state machine that models the behavior of a Lemming. The Lemming can be in one of several states: walking left, walking right, falling, digging, or splattered. We will use a Moore state machine, where the outputs are determined solely by the current state.

The states will be:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered.

We will use a counter to keep track of the number of clock cycles the Lemming has been falling. If the Lemming hits the ground after falling for more than 20 clock cycles, it will splatter.

The state machine will transition between states based on the input signals. For example, if the Lemming is walking left and receives a bump on the left, it will transition to the walking right state.

We will also need to handle the case where the Lemming is digging and the ground disappears. In this case, the Lemming will transition to the falling state and then to the walking state when it hits the ground again.
