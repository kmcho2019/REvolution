To implement the Lemmings' finite state machine, we can define several states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALL: The Lemming is falling.
- DIG: The Lemming is digging.
- SPLATTER: The Lemming has splattered and is no longer moving.

We'll also need to keep track of the direction the Lemming was walking before it started falling or digging, so it can resume walking in that direction when it hits the ground or finishes digging.

We'll use a counter to keep track of the number of clock cycles the Lemming has been falling, and if it exceeds 20 cycles when it hits the ground, it will splatter.

We'll use a case statement to handle the different states and determine the next state based on the current state and inputs.
