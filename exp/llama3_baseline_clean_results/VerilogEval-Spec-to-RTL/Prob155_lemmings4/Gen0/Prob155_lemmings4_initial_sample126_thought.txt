To implement the Lemming behavior, we can design a Moore state machine with several states:
- IDLE: Initial state where the Lemming is walking left or right.
- FALLING: State where the Lemming is falling due to loss of ground.
- DIGGING: State where the Lemming is digging.
- SPLATTERED: State where the Lemming has splattered after falling for too long.
We will use a 2-bit state variable to represent these four states.
We will also use a counter to track the number of clock cycles the Lemming has been falling.
We will use another state variable to remember the direction the Lemming was walking before falling or digging.
The state machine will transition between states based on the input signals and the current state.
