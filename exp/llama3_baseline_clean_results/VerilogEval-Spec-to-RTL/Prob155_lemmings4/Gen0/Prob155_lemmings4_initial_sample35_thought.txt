To implement the Lemming's behavior, we will create a Moore state machine with states representing walking left, walking right, falling, digging, and splattered. The machine will transition between these states based on the input signals (bump_left, bump_right, ground, dig). We will also keep track of the number of clock cycles the Lemming has been falling to determine if it should splatter when hitting the ground. The state machine will be reset to the walking left state when the areset signal is asserted.
