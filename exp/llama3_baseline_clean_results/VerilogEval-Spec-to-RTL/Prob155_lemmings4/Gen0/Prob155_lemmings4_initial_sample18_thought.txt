To model the Lemming's behavior, we need to implement a Moore state machine with several states to keep track of the Lemming's current activity (walking left, walking right, falling, digging, or splattered). We will use an enumeration of states to make the code more readable. 

The state machine will have the following states:
- IDLE_LEFT: initial state, walking left
- WALKING_LEFT: walking left
- WALKING_RIGHT: walking right
- FALLING: falling
- DIGGING: digging
- SPLATTERED: Lemming has splattered and ceased all activities

We will use a counter to keep track of the number of clock cycles the Lemming has been falling. If this counter exceeds 20 when the Lemming hits the ground, it will transition to the SPLATTERED state.

We will also use a variable to keep track of the Lemming's direction before it starts falling or digging, so it can resume walking in the same direction when it hits the ground again or finishes digging.
