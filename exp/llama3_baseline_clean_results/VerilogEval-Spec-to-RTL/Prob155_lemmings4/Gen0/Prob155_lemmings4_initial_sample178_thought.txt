To model the behavior of a Lemming in the game Lemmings using a finite state machine, we need to consider all possible states and transitions as per the given requirements. The states can be broadly classified into walking left, walking right, falling, and digging. We also need to keep track of the number of clock cycles the Lemming has been falling to check if it splatters when hitting the ground.

The state machine will have the following states:
- walking left
- walking right
- falling
- digging left
- digging right

The transitions between these states will be based on the input signals, such as bump_left, bump_right, ground, dig, and the current state.

We will use a 4-bit binary number to represent the states, and a 5-bit binary number to count the number of clock cycles the Lemming has been falling.

The state machine will be implemented using a Moore model, where the output is a function of the current state only.
