To model the Lemming's behavior, we can use a finite state machine with several states:
- Walking left
- Walking right
- Falling
- Digging
- Splattered

The transitions between these states will be determined by the inputs to the module.
When the Lemming is walking, it can switch direction if it hits an obstacle, start digging if it receives the dig signal, or start falling if the ground disappears.
When the Lemming is falling, it can resume walking if the ground reappears, or start digging if the ground reappears and it was previously digging. However, if it falls for more than 20 clock cycles, it will splatter when it hits the ground.
When the Lemming is digging, it will continue digging until the ground disappears, at which point it will start falling.

We will use a counter to track how long the Lemming has been falling, and use this counter to determine if the Lemming should splatter when it hits the ground.
