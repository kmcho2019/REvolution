To implement the Lemming state machine, we'll use a Moore state machine with the following states: 
1. Idle: This is the initial state where the Lemming can walk left or right.
2. Walking: The Lemming walks in a particular direction.
3. Falling: The Lemming falls when there's no ground.
4. Digging: The Lemming digs when instructed to do so.
5. Splattered: The Lemming has splattered and will not move anymore.

The state machine will transition between these states based on the input conditions. For instance, if the Lemming is walking and hits an obstacle, it will switch direction. If the Lemming is walking and there's no ground, it will start falling.

We will use a counter to keep track of how long the Lemming has been falling. If the counter exceeds 20 clock cycles when the Lemming hits the ground, it will splatter.

We'll use a series of if-else statements to determine the next state based on the current state and the input conditions.
