To implement the TopModule, we need to create a finite state machine that models the behavior of a Lemming in the game. The machine should have several states to account for walking left, walking right, falling, digging, and splattering. We will use a Moore state machine, where the outputs are determined by the current state. 

The states of the machine can be defined as follows:

- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered.

We will use a counter to keep track of the number of clock cycles the Lemming has been falling, to determine if it should splatter when it hits the ground.

The state machine will transition between states based on the inputs, following the rules specified in the problem.
