To implement the Lemmings finite state machine, we need to define the states and their transitions based on the given conditions. We can identify the following states:
- Walking left (WL)
- Walking right (WR)
- Falling (F)
- Digging (D)
- Splattered (S)

We will use a counter to count the number of clock cycles the Lemming has been falling. If the counter exceeds 20 and the Lemming hits the ground, it will transition to the Splattered state.

We will also use a variable to store the previous walking direction to resume walking in the same direction after falling or digging.

The state machine will transition between these states based on the input signals (bump_left, bump_right, ground, dig) and the current state.
