The Lemmings' behavior can be modeled using a Moore state machine with the following states:
- IDLE_LEFT: Lemming is walking left on ground.
- IDLE_RIGHT: Lemming is walking right on ground.
- FALLING: Lemming is falling.
- DIGGING: Lemming is digging.
- SPLATTERED: Lemming has splattered and ceased walking, falling, or digging.

The state machine will transition between these states based on the input signals. 
The output signals will be determined by the current state of the state machine.

To implement the state machine, we will use a parameterized module that takes the state as a parameter.
The current state will be stored in a register, and the next state will be determined by the current state and the input signals.

We will also use a counter to keep track of the number of clock cycles the Lemming has been falling, to determine when it should splatter.
