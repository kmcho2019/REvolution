To implement this finite state machine, we need to identify all the states and transitions. The Lemming can be in one of several states: walking left, walking right, falling, digging, or dead. We can model these states using an enumeration.

The state transitions are as follows:
- From walking left or right, if the Lemming hits an obstacle, it switches direction.
- From walking left or right, if the ground disappears, the Lemming starts falling.
- While falling, if the ground reappears, the Lemming stops falling and resumes walking in the same direction as before the fall.
- From walking left or right, if the Lemming is told to dig and the ground is present, it starts digging.
- While digging, if the ground disappears, the Lemming stops digging and starts falling.
- If the Lemming falls for more than 20 clock cycles and then hits the ground, it splatters and ceases walking, falling, or digging.

We need to implement these state transitions using a Moore state machine in Verilog.
