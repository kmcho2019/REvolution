- If the Lemming is walking and it is told to dig, it will start digging.
- If the Lemming is falling and the ground reappears, it will start walking again in the same direction as before.
- If the Lemming is digging and the ground disappears, it will fall.
- If the Lemming has been falling for more than 20 clock cycles and hits the ground, it will splatter.
