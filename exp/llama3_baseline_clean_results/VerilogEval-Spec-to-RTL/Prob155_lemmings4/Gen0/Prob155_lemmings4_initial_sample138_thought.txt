To implement the Moore state machine, we need to define the states and their transitions. The states can be: WALK_LEFT, WALK_RIGHT, FALLING, DIGGING, and SPLATTER. We also need to keep track of the number of clock cycles the Lemming has been falling. When the Lemming is bumped, we need to switch its direction. When the ground disappears, the Lemming starts falling. When the Lemming hits the ground after falling, we need to check if it has fallen for more than 20 clock cycles. If it has, the Lemming splatters. We also need to implement the digging functionality, which stops when the ground disappears.
