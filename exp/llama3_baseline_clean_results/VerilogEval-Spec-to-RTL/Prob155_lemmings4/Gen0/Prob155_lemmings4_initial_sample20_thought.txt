The problem can be solved by implementing a Moore state machine with the following states:
- IDLE: Initial state, Lemming is walking left or right
- FALL: Lemming is falling
- DIG: Lemming is digging
- SPLATTER: Lemming has splattered and will not move or fall anymore

The state machine transitions between these states based on the input signals:
- If the Lemming is walking (in IDLE state) and ground=0, it transitions to FALL state.
- If the Lemming is walking (in IDLE state) and dig=1, it transitions to DIG state.
- If the Lemming is walking (in IDLE state) and bump_left=1 or bump_right=1, it changes direction.
- If the Lemming is falling (in FALL state) and ground=1, it transitions back to IDLE state if it hasn't fallen for more than 20 clock cycles. Otherwise, it transitions to SPLATTER state.
- If the Lemming is digging (in DIG state) and ground=0, it transitions to FALL state.
- If the Lemming is in SPLATTER state, it stays in that state forever until reset.

The outputs are determined by the current state and direction of the Lemming:
- walk_left and walk_right are 1 when the Lemming is walking in the corresponding direction.
- aaah is 1 when the Lemming is falling.
- digging is 1 when the Lemming is digging.
