To implement the Lemmings' behavior as a Moore state machine, we need to identify the states and transitions. The Lemming can be in one of the following states: walking left, walking right, falling, digging, or splattered. 

We can represent these states using a 3-bit state register. The state transitions will be based on the input signals and the current state. 

The next state will be determined by the current state and the input signals (bump_left, bump_right, ground, dig). We will also keep track of the number of clock cycles the Lemming has been falling to check for splattering. 

The output signals (walk_left, walk_right, aaah, digging) will be determined by the current state.
