The problem can be solved by implementing a finite state machine (FSM) that models the behavior of the Lemming. The FSM will have several states: walking left, walking right, falling, digging, and splattered. The state transitions will be based on the input signals and the current state of the FSM. 

The states can be represented as follows:
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and is no longer walking, falling, or digging.

The state transitions will be based on the input signals:
- If the Lemming is walking and the ground disappears, it will start falling.
- If the Lemming is walking and it is bumped, it will change direction.
- If the Lemming is walking and it is told to dig, it will start digging.
- If the Lemming is falling and the ground reappears, it will start walking in the same direction as before the fall.
- If the Lemming is falling for more than 20 clock cycles and the ground reappears, it will splatter.
- If the Lemming is digging and the ground disappears, it will start falling.

The FSM can be implemented using a Moore state machine, where the output is a function of the current state only.
