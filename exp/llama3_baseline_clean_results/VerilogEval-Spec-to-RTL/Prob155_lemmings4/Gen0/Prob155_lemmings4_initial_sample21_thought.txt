To implement the Lemming machine as a Moore state machine, we need to identify the states and transitions. The states can be: WALKING_LEFT, WALKING_RIGHT, FALLING, DIGGING, and SPLATTERED. 

The state transitions will be based on the input signals. If the Lemming is walking and hits an obstacle, it will switch direction. If the ground disappears, the Lemming will start falling. If the Lemming is told to dig while walking on the ground, it will start digging. If the Lemming falls for more than 20 clock cycles and hits the ground, it will splatter.

We will use a counter to keep track of the number of clock cycles the Lemming has been falling. If this counter exceeds 20 and the ground reappears, the Lemming will splatter.

We will also use a variable to keep track of the original direction of the Lemming before it started falling or digging. This will allow us to resume walking in the same direction when the ground reappears or the Lemming reaches the other side.

The outputs will be generated based on the current state of the Lemming.
