To implement the Lemming machine, we need a finite state machine with several states:
- idle (initial state, walking left)
- walking_left
- walking_right
- falling
- digging
- splattered

The state machine transitions between these states based on the input signals.
We will also need counters to track the number of clock cycles spent falling and digging.
We will use a reset signal to return the state machine to its initial state.
The outputs of the state machine will be determined by the current state.
