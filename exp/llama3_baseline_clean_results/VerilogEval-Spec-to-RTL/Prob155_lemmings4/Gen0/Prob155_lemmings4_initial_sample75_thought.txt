To implement the Lemmings state machine, we'll define several states: 
walking_left, walking_right, falling, digging_left, and digging_right. 
Additionally, we'll need a state to track if the Lemming has splattered. 
The states walking_left and walking_right will have transitions based on 
the bump_left, bump_right, ground, and dig inputs. 
The state falling will have transitions based on the ground input and the 
number of clock cycles the Lemming has been falling. 
The states digging_left and digging_right will have transitions based on 
the ground input. 
The state splattered will be reached if the Lemming falls for more than 
20 clock cycles before hitting the ground, and will have no transitions 
out of this state.

The next state logic will be designed as a Moore machine, where the 
outputs are a function of the current state only. The current state will 
be updated on the positive edge of the clock, and will be reset to the 
walking_left state on the positive edge of the asynchronous reset 
signal areset.

The implementation will involve several always blocks: one for the next 
state logic, one for the output logic, and possibly one for the counter 
logic that tracks the number of clock cycles the Lemming has been 
falling. We will use parameters to define the number of clock cycles 
before the Lemming splatters.
