To solve this problem, we can design a finite state machine with several states to model the Lemming's behavior. The states can be: 
- WALKING: This is the default state where the Lemming is walking left or right.
- FALLING: In this state, the Lemming is falling and says "aaah!".
- DIGGING: In this state, the Lemming is digging and will continue until it reaches the other side.
- SPLATTERED: This is a terminal state where the Lemming has splattered and ceased all activities.
We will use a Moore state machine, meaning that the output is determined solely by the current state. 
We will also use a counter to count the number of clock cycles the Lemming has been falling, to determine if it should splatter when hitting the ground.
