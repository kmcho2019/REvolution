To implement the Lemmings' behavior, we can model it using a finite state machine with the following states:
- Walking Left
- Walking Right
- Falling
- Digging
- Splattered
We'll use a Moore state machine, where the outputs are a function of the current state only. We'll also keep track of the number of clock cycles the Lemming has been falling.

When the Lemming is walking, it will change direction when bumped. If the ground disappears, it will fall. If it's told to dig, it will start digging.

When the Lemming is falling, it will continue falling until it hits the ground. If it's been falling for more than 20 clock cycles, it will splatter. Otherwise, it will resume walking in the same direction as before.

When the Lemming is digging, it will continue digging until it reaches the other side. At that point, it will fall, and then continue walking in its original direction once it hits the ground again.

We'll use a counter to keep track of the number of clock cycles the Lemming has been falling. If this counter exceeds 20, the Lemming will splatter.
