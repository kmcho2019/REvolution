To implement the counter, we can use a 10-bit register to store the count value. The register will be incremented at each positive clock edge unless the reset signal is high, in which case it will be reset to 0. When the count value reaches 999, it should wrap around to 0. This can be achieved by checking if the current count is equal to 999 and if so, setting the next state to 0. Otherwise, the next state will be the current count plus 1.
