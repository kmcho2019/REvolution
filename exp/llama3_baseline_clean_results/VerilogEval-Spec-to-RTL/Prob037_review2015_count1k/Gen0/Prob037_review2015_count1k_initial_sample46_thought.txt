To implement the counter, we will use a 10-bit register to store the count. 
Since the counter counts from 0 to 999, we need 10 bits to represent the count, 
because 2^10 (1024) is greater than 1000. We will use an always block to 
describe the sequential behavior of the counter, triggered on the positive edge 
of the clock. Inside the always block, we will first check if the reset signal 
is high. If it is, we will reset the count to 0. If not, we will increment the 
count by 1 if it is not already at its maximum value (999).
