To implement the counter module, we will use a 10-bit register to store the current count. Since the counter needs to count from 0 to 999, a 10-bit register is sufficient as 2^10 = 1024, which is greater than 1000. We will use a synchronous reset, so when the reset input is high, the counter will reset to 0 on the next positive clock edge. The counter will increment on every positive clock edge when the reset input is low.
