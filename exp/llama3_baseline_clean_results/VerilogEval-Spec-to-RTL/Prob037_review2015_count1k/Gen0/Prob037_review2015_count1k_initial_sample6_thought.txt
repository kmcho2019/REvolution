To implement the required functionality, we can design a synchronous counter that increments its count on every positive clock edge unless the reset signal is high. The counter should have a width of 10 bits to be able to count up to 999 (since 2^10 = 1024, which is greater than 1000). When the count reaches 999, on the next clock cycle, it should wrap around to 0. The reset signal should be checked on every clock edge, and if it's high, the counter should reset to 0 regardless of its current value.
