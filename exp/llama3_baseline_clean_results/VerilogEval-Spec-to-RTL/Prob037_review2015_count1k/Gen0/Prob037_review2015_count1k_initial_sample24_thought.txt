To implement the counter, we can use a 10-bit register to store the current count. We will use a 10-bit register because 2^10 (1024) is the smallest power of 2 that is greater than 1000. On every positive clock edge, we will increment the count unless the reset is high. When the reset is high, we will reset the count to 0. Since the counter needs to wrap around after reaching 999, we will check if the current count is 999 and if so, reset it to 0 on the next clock cycle.
