To implement the TopModule as described, we will use a simple counter that increments on every positive clock edge. Since we are counting from 0 to 999, we will need a 10-bit counter (2^10 = 1024, which is the smallest power of 2 that can represent 1000 distinct states). We'll use a reg to hold the count and increment it on each clock cycle unless the reset signal is high, in which case we reset the count to 0. The output q will simply be assigned the current value of the counter.
