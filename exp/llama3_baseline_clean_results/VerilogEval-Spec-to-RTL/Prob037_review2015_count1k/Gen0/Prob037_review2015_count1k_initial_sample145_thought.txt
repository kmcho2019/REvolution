To implement the TopModule as specified, we need to design a counter that increments every clock cycle and resets when the reset signal is high. The counter should count from 0 to 999 and then wrap around back to 0. This can be achieved using a 10-bit register to store the count value. We will use a binary counter, which naturally wraps around after reaching its maximum value. The reset input is synchronous, meaning it only affects the counter on the positive edge of the clock when the reset signal is high.
