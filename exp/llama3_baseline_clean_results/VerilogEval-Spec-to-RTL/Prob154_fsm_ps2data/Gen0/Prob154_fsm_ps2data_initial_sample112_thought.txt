The TopModule will be implemented as a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. 
In the IDLE state, the module will continuously check for the start of a message (in[3] = 1) and discard bytes until it finds one.
Once the start of a message is detected, the module will transition to the BYTE1 state and store the current byte.
In the BYTE1 state, the module will wait for the next byte and store it.
The module will then transition to the BYTE2 state and wait for the third byte of the message.
Once the third byte is received, the module will transition back to the IDLE state, signal that a message has been received (done = 1), and output the 24-bit message.
The reset signal will be used to asynchronously reset the FSM to the IDLE state.
