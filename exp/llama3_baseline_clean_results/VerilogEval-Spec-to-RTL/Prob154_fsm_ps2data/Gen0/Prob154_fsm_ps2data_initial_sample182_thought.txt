To solve this problem, we can design a finite state machine (FSM) that has four states: IDLE, BYTE1, BYTE2, and BYTE3. 
The FSM will start in the IDLE state and stay there until it sees an input byte with in[3]=1. 
When this condition is met, the FSM will move to the BYTE1 state and store the current input byte. 
Then, it will move to the BYTE2 state and store the next input byte. 
After that, it will move to the BYTE3 state and store the next input byte. 
Finally, it will signal done and move back to the IDLE state.
