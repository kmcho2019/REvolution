To implement the TopModule, we need to design a finite state machine that searches for message boundaries in the input byte stream. We will use a 3-state FSM: IDLE, BYTE1, and BYTE2. The FSM starts in the IDLE state, where it discards bytes until it sees one with in[3]=1. When such a byte is seen, it transitions to the BYTE1 state, assuming this is byte 1 of a message. It then proceeds to the BYTE2 state to collect the next two bytes. After collecting all three bytes, it signals the receipt of a message (done) and returns to the IDLE state. The datapath module will output the 24-bit message (out_bytes) whenever a packet is received.
