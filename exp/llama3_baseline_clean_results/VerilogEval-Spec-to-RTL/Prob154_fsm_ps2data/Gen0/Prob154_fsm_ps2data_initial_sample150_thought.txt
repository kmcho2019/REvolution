The TopModule will be implemented as a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and DONE. The FSM will start in the IDLE state. In the IDLE state, it will wait for an input byte with in[3]=1. When such a byte is received, it will transition to the BYTE1 state and store the byte as the first byte of the message. In the BYTE1 state, it will wait for the next input byte and store it as the second byte of the message, then transition to the BYTE2 state. In the BYTE2 state, it will wait for the next input byte, store it as the third byte of the message, and transition to the DONE state. In the DONE state, it will assert the done signal and output the 24-bit message. After one clock cycle in the DONE state, it will reset to the IDLE state. The reset signal will be used to reset the FSM to the IDLE state.
