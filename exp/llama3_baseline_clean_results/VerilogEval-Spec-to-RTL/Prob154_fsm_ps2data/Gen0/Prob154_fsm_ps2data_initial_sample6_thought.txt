The TopModule can be implemented using a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. The FSM starts in the IDLE state and transitions to the BYTE1 state when a byte with in[3]=1 is received. It then transitions to the BYTE2 state after receiving the second byte, and finally signals done and returns to the IDLE state after receiving the third byte. The datapath will store the received bytes in registers and output them as a 24-bit message whenever the done signal is asserted.
