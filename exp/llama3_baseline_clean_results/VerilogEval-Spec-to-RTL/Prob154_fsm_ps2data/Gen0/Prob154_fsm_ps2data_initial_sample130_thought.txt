The design involves creating a finite state machine (FSM) with states to track the reception of bytes in a message. The FSM will have states for searching for the start of a message (IDLE), and states for receiving the first, second, and third bytes of a message (BYTE1, BYTE2, BYTE3). In the IDLE state, the FSM will check each incoming byte to see if it is the start of a message (i.e., in[3] = 1). If so, it will transition to the BYTE1 state and start storing the bytes in the out_bytes register. Once three bytes have been received, the FSM will transition back to the IDLE state and assert the done signal for one cycle. The FSM will also reset to the IDLE state if the reset signal is asserted.
