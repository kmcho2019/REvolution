To implement the TopModule, we need to design a finite state machine (FSM) that can identify the start of a message and then collect the next two bytes to form a 24-bit message. We will use three states: IDLE, BYTE1, and BYTE2. In the IDLE state, we will discard bytes until we see one with in[3]=1, then we transition to the BYTE1 state and start collecting bytes. In the BYTE1 and BYTE2 states, we will collect the next two bytes and then transition back to the IDLE state, signaling the receipt of a message. We will also need to implement a datapath to output the 24-bit message whenever a packet is received.
