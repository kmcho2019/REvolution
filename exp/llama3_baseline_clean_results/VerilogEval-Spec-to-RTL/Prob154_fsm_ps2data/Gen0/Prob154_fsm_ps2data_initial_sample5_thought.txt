To implement the TopModule, we'll design a finite state machine (FSM) with three states: IDLE, BYTE_1, and BYTE_2. In the IDLE state, the FSM will discard input bytes until it sees one with in[3] = 1. Once it sees such a byte, it will transition to the BYTE_1 state and store the byte in the out_bytes register. In the BYTE_1 state, the FSM will wait for the next input byte and store it in the out_bytes register. It will then transition to the BYTE_2 state. In the BYTE_2 state, the FSM will wait for the next input byte, store it in the out_bytes register, and assert the done signal. The FSM will then transition back to the IDLE state. The reset signal will be used to reset the FSM to the IDLE state and clear the out_bytes register.
