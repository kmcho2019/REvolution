The module TopModule will implement a finite state machine with three states: idle, first_byte, and second_byte. It will start in the idle state and stay there until it receives a byte with in[3] = 1. Then, it will transition to the first_byte state and store the current byte in the most significant 8 bits of out_bytes. In the first_byte state, it will wait for the next byte and store it in the middle 8 bits of out_bytes, then transition to the second_byte state. In the second_byte state, it will wait for the next byte, store it in the least significant 8 bits of out_bytes, and assert the done signal. After asserting the done signal, it will return to the idle state. The reset signal will be used to reset the finite state machine to the idle state.
