The TopModule will implement a finite state machine with the following states:
1. Idle: This state will be the initial state where the module will wait for the input byte stream.
2. Byte1: This state will be entered when a byte with in[3] = 1 is detected, and it will store this byte as the first byte of the message.
3. Byte2: This state will be entered after the first byte has been stored, and it will store the next byte as the second byte of the message.
4. Byte3: This state will be entered after the second byte has been stored, and it will store the next byte as the third byte of the message and signal done.

The datapath will be implemented using registers to store the input bytes and a multiplexer to select the output bytes.
