To implement the TopModule, we need to design a finite state machine that searches for message boundaries in the input byte stream. The FSM should have four states: idle, byte1, byte2, and done. In the idle state, the FSM discards bytes until it sees one with in[3] = 1. When this condition is met, it transitions to the byte1 state and stores the byte. In the byte1 and byte2 states, the FSM stores the subsequent bytes. After storing the third byte, it transitions to the done state and signals the receipt of a message. The datapath module should output the 24-bit message whenever a packet is received.

We will use a counter to keep track of the current state and a register to store the received bytes. The output will be generated based on the received bytes and the current state.
