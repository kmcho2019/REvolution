To implement the finite state machine (FSM) that searches for message boundaries, we can use a simple state machine with a counter to keep track of the bytes received. We start in an idle state, and when we receive a byte with in[3]=1, we transition to a state where we start counting the bytes. Once we have received three bytes, we transition to a state where we signal the receipt of a message (done) and output the 24-bit message (out_bytes). The reset signal resets the FSM to the idle state. We use a 2-bit state register to encode the states: 0 - idle, 1 - receiving byte 1, 2 - receiving byte 2, and 3 - receiving byte 3.
