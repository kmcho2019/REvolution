To implement the TopModule, we can design a finite state machine with 4 states: 
1) IDLE: The initial state where we discard bytes until we see one with in[3]=1.
2) BYTE1: After seeing the first byte, we move to this state and store the byte.
3) BYTE2: After seeing the second byte, we move to this state and store the byte.
4) BYTE3: After seeing the third byte, we move to this state and store the byte, 
then signal done and output the 24-bit message.

We will also use three 8-bit registers to store the three bytes of the message.
