To implement the TopModule, we'll use a finite state machine (FSM) to control the flow of data. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. 

- IDLE state: This is the initial state of the FSM. In this state, we discard bytes until we see one with in[3] = 1. Once we see a byte with in[3] = 1, we transition to the BYTE1 state.
- BYTE1 state: In this state, we store the current byte as the first byte of the message and transition to the BYTE2 state.
- BYTE2 state: In this state, we store the current byte as the second byte of the message and transition to the BYTE3 state.
- BYTE3 state: In this state, we store the current byte as the third byte of the message, signal done, and transition back to the IDLE state.

We'll use a counter to keep track of the current byte number and a register to store the bytes of the message.
