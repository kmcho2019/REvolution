To solve this problem, we need to design a finite state machine (FSM) that can recognize the start of a message and capture the subsequent bytes. The FSM should have the following states:
- Idle: This is the initial state. In this state, the FSM checks each incoming byte to see if it has the start bit (in[3] = 1) set. If it does, the FSM transitions to the Byte1 state.
- Byte1: In this state, the FSM captures the current byte as the first byte of the message and transitions to the Byte2 state.
- Byte2: In this state, the FSM captures the current byte as the second byte of the message and transitions to the Byte3 state.
- Byte3: In this state, the FSM captures the current byte as the third byte of the message and transitions to the Done state.
- Done: In this state, the FSM sets the done signal high, indicating that a message has been received, and outputs the captured bytes.

The FSM should also be able to reset to the Idle state when the reset signal is high.

We will use a 2-bit state variable to encode the four states (Idle, Byte1, Byte2, Byte3). The Done state will be a temporary state that is only active for one clock cycle.
