To solve this problem, we need to design a finite state machine (FSM) that can identify the start of a message and then capture the subsequent bytes. The FSM should have at least three states: IDLE, BYTE1, and BYTE2. In the IDLE state, it waits for a byte with in[3] = 1, which indicates the start of a message. Once this condition is met, it moves to the BYTE1 state and captures this byte. It then waits for the next two bytes and captures them in the BYTE2 and DONE states respectively. After capturing the third byte, it signals done in the cycle immediately after and outputs the captured bytes as out_bytes.
