The TopModule should implement a finite state machine with three states: 
- IDLE: Discard input bytes until a byte with in[3]=1 is seen. 
- BYTE1: Capture the first byte of the message.
- BYTE2: Capture the second byte of the message.
- BYTE3: Capture the third byte of the message and signal done.
The module should also implement a datapath to store the received bytes and output them as a 24-bit message.
