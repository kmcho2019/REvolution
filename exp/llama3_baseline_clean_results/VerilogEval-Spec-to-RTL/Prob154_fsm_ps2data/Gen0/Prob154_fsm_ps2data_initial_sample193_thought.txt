To solve this problem, we will design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM will start in the IDLE state and transition to BYTE1 when it sees a byte with in[3] = 1. Then it will transition to BYTE2 and BYTE3 as it receives the next two bytes. After receiving the third byte, it will signal done in the next clock cycle. The datapath will store the received bytes in a 24-bit register and output them whenever the done signal is asserted.

The states and their transitions are as follows:
- IDLE: Check if in[3] = 1. If yes, transition to BYTE1.
- BYTE1: Transition to BYTE2.
- BYTE2: Transition to BYTE3.
- BYTE3: Signal done in the next clock cycle and transition back to IDLE.

The datapath will have a 24-bit register to store the received bytes. The register will be updated in each state as follows:
- IDLE: Do nothing.
- BYTE1: Store the received byte in out_bytes[23:16].
- BYTE2: Store the received byte in out_bytes[15:8].
- BYTE3: Store the received byte in out_bytes[7:0].

The reset signal will be used to reset the FSM to the IDLE state and clear the 24-bit register.
