To implement the required finite state machine, we can use a simple state machine with 4 states: IDLE, BYTE1, BYTE2, and BYTE3. 
The state machine will stay in the IDLE state until it sees an input byte with in[3]=1, then it will move to the BYTE1 state. 
It will then stay in the BYTE1 state for one cycle and move to the BYTE2 state, regardless of the input. 
It will then stay in the BYTE2 state for one cycle and move to the BYTE3 state, regardless of the input. 
Once in the BYTE3 state, it will signal done in the next cycle, regardless of the input, and then return to the IDLE state. 
We also need to store the input bytes in a register and concatenate them to form the 24-bit output.
