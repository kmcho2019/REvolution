To implement the finite state machine, we will use a 3-state approach: 
IDLE, BYTE1, and BYTE2. In the IDLE state, we discard bytes until we 
find one with in[3]=1, then we move to the BYTE1 state. In the BYTE1 
state, we store the current byte and move to the BYTE2 state. In the 
BYTE2 state, we store the current byte and the previous two bytes in 
the out_bytes signal, and signal done. We also reset the FSM to the 
IDLE state. The FSM should be reset to the IDLE state whenever the 
reset signal is active high. The out_bytes signal should be valid 
whenever the done signal is asserted.
