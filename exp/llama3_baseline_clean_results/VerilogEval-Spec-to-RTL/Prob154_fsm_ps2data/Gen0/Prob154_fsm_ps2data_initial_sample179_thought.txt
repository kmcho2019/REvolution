To implement the TopModule, we can use a finite state machine (FSM) with three states: 
- IDLE: The initial state, where we wait for the first byte with in[3]=1.
- BYTE_2: After receiving the first byte, we wait for the second byte.
- BYTE_3: After receiving the second byte, we wait for the third byte and then signal done.

We also need to store the received bytes in a register to output them when the done signal is asserted. 
We will use a 24-bit register to store the three bytes, with the first byte at bits 23-16, the second byte at bits 15-8, and the third byte at bits 7-0.

We will also need a counter to keep track of the current state of the FSM.
