To implement the finite state machine, we will use a simple state machine with three states: IDLE, BYTE1, and BYTE2. 
The machine starts in the IDLE state and stays there until it receives an input byte with in[3] = 1. 
Once it sees this byte, it transitions to the BYTE1 state and stores this byte as the first byte of the message. 
Then it waits for two more bytes and stores them as the second and third bytes of the message. 
After receiving the third byte, it transitions back to the IDLE state and signals done for one cycle. 
The out_bytes signal is set to the three bytes of the message when the done signal is asserted.
