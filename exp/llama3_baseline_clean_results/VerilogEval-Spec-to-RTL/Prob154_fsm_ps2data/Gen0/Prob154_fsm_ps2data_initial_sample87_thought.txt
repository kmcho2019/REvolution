The module TopModule can be implemented as a finite state machine with four states: Idle, Byte1, Byte2, and Done. 
- In the Idle state, the module discards incoming bytes until it finds one with in[3]=1, then transitions to Byte1 state.
- In the Byte1 state, the module stores the current byte and transitions to Byte2 state.
- In the Byte2 state, the module stores the current byte and transitions to Done state.
- In the Done state, the module outputs the stored 3 bytes and asserts the done signal.
The module uses registers to store the current state, the stored bytes, and the output bytes.
The reset signal is used to reset the state and stored bytes.
The datapath is designed to output the 24-bit message whenever the done signal is asserted.
