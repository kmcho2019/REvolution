To implement the TopModule, we need to design a finite state machine (FSM) that can search for message boundaries in the input byte stream. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. 

- In the IDLE state, the FSM will discard bytes until it sees one with in[3]=1.
- Once it sees a byte with in[3]=1, it will transition to the BYTE1 state.
- In the BYTE1, BYTE2, and BYTE3 states, the FSM will capture the current byte and transition to the next state.
- After capturing the third byte, the FSM will assert the done signal and output the 24-bit message.

The datapath module will be responsible for outputting the 24-bit message whenever a packet is received. It will store the three bytes of the message in a 24-bit register, with out_bytes[23:16] as the first byte, out_bytes[15:8] as the second byte, and out_bytes[7:0] as the third byte.
