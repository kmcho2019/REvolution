To implement the TopModule, we need to design a finite state machine (FSM) that searches for message boundaries in the input byte stream. The FSM will have three states: IDLE, BYTE1, and BYTE2. In the IDLE state, the FSM will discard bytes until it sees one with in[3]=1. When this condition is met, the FSM will transition to the BYTE1 state and store the current byte as the first byte of the message. In the BYTE1 state, the FSM will store the next byte as the second byte of the message and transition to the BYTE2 state. In the BYTE2 state, the FSM will store the next byte as the third byte of the message and transition back to the IDLE state, signaling the receipt of a message by asserting the done signal. The out_bytes output will be set to the 24-bit message whenever the done signal is asserted.
