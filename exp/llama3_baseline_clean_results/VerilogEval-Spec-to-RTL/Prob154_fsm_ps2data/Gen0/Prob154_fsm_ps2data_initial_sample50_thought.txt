To implement the finite state machine that searches for message boundaries, we will use a simple 3-state machine. 

- State 0: This is the initial state where we discard bytes until we see one with in[3]=1. 
- State 1: This is the second byte state where we have seen the first byte of the message and are waiting for the second byte.
- State 2: This is the third byte state where we have seen the first two bytes of the message and are waiting for the third byte.

When the FSM reaches state 2, it sets the done signal and outputs the 24-bit message. 

We will use a 2-bit register to keep track of the current state. We will also use three 8-bit registers to store the three bytes of the message.
