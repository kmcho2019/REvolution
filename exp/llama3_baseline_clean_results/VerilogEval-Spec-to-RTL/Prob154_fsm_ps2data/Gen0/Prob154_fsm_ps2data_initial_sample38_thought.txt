The problem can be solved by designing a finite state machine (FSM) with 4 states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, the FSM waits for a byte with in[3] = 1, which indicates the start of a message. 
Once such a byte is received, the FSM transitions to the BYTE1 state and stores the byte as the first byte of the message.
In the BYTE1 state, the FSM waits for the next byte and stores it as the second byte of the message, then transitions to the BYTE2 state.
In the BYTE2 state, the FSM waits for the next byte, stores it as the third byte of the message, and then transitions to the BYTE3 state.
In the BYTE3 state, the FSM sets the done signal to 1, indicating that a message has been received, and outputs the 24-bit message.
The FSM then resets to the IDLE state.
