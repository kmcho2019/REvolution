To solve this problem, I will design a finite state machine (FSM) with four states: 
1. IDLE: This is the initial state where the FSM waits for the first byte of the message (i.e., the byte with in[3]=1).
2. BYTE1: This state is entered when the first byte of the message is received. The FSM then waits for the second byte.
3. BYTE2: This state is entered when the second byte of the message is received. The FSM then waits for the third byte.
4. DONE: This state is entered when the third byte of the message is received. In this state, the FSM sets the 'done' signal high and outputs the 24-bit message.

I will use a counter to keep track of the current state. When the FSM is in the DONE state, it will output the 24-bit message and set the 'done' signal high. The FSM will then transition back to the IDLE state.

The FSM will be implemented using a case statement in the Verilog code, and the state will be stored in a reg variable.
