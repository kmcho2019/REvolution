To implement the module TopModule, we need to create a finite state machine (FSM) that can search for message boundaries in the input byte stream. The FSM should have the following states:
- IDLE: This is the initial state where the FSM waits for a byte with in[3]=1.
- BYTE1: This state is reached when a byte with in[3]=1 is received. The FSM then stores this byte as the first byte of the message.
- BYTE2: This state is reached after the first byte has been received. The FSM then stores the next byte as the second byte of the message.
- BYTE3: This state is reached after the second byte has been received. The FSM then stores the next byte as the third byte of the message and signals done in the next clock cycle.
- DONE: This is a temporary state that is used to signal done in the clock cycle immediately after the third byte of each message was successfully received.

The FSM will reset to the IDLE state when the reset signal is high.

The datapath module will be implemented using a shift register to store the received bytes. The output out_bytes will be valid whenever the done signal is asserted.
