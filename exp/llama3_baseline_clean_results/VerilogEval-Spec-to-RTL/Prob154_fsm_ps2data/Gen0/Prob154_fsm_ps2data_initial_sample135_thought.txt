To implement the TopModule, we can use a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. The FSM starts in the IDLE state, where it checks if the current input byte has the bit in[3] set to 1. If it does, the FSM moves to the BYTE1 state, where it stores the current input byte. In the BYTE1 state, the FSM waits for the next input byte and stores it in the BYTE2 state. Once in the BYTE2 state, the FSM waits for the next input byte and then moves back to the IDLE state, signaling that a message has been received (done = 1) and outputting the 24-bit message. The reset signal is used to reset the FSM to the IDLE state. The out_bytes output is valid only when the done signal is asserted.
