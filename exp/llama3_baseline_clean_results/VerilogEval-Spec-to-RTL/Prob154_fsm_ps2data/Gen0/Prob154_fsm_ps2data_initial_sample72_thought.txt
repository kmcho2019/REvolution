To implement the TopModule, we will create a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. The FSM will start in the IDLE state and wait for an input byte with in[3]=1. When such a byte is received, the FSM will transition to the BYTE1 state and store the byte. Then, it will transition to the BYTE2 state and store the next two bytes. Once all three bytes are received, the FSM will signal the receipt of a message by asserting the done signal and output the 24-bit message. The reset signal will be used to reset the FSM to the IDLE state.
