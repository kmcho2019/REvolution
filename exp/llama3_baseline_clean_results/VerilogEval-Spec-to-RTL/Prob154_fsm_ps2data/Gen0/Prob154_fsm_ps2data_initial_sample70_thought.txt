To implement the TopModule, we need a finite state machine that can track the state of the incoming byte stream and signal the receipt of a message when three bytes have been received. The states of the FSM can be: 
- IDLE: This is the initial state where the FSM waits for the first byte of a message.
- BYTE1: In this state, the FSM has received the first byte and is waiting for the next two bytes.
- BYTE2: In this state, the FSM has received the first two bytes and is waiting for the third byte.
- DONE: In this state, the FSM has received all three bytes and signals the receipt of a message.

We will use a counter to keep track of the current byte being received. When the counter is 0, we are in the IDLE state. When the counter is 1, 2, or 3, we are in the BYTE1, BYTE2, or DONE state respectively.

We will use a 24-bit register to store the received bytes. When the FSM is in the BYTE1 state, the first byte is stored in the most significant 8 bits of the register. When the FSM is in the BYTE2 state, the second byte is stored in the middle 8 bits of the register. When the FSM is in the DONE state, the third byte is stored in the least significant 8 bits of the register.

The reset signal is active high synchronous, meaning that when the reset signal is high, the FSM will be reset to the IDLE state and the counter and register will be reset.
