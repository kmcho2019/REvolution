condition is met, it assumes the byte as the first byte of a message and 
waits for two more bytes to complete the message. After receiving the 
third byte, it signals the receipt of a message (done) and outputs the 
24-bit message (out_bytes). 

To solve this problem, we can use a 3-state FSM: 
- State 0 (IDLE): Waits for a byte with in[3] = 1.
- State 1 (MSG1): Waits for the second byte of the message.
- State 2 (MSG2): Waits for the third byte of the message.

and output them when the message is complete.

does, we transition to the MSG1 state and store the byte as the first 
byte of the message. 

In the MSG1 state, we store the current byte as the second byte of the 
message and transition to the MSG2 state.

In the MSG2 state, we store the current byte as the third byte of the
