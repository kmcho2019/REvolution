To implement the finite state machine, we can use a simple state transition diagram with three states: IDLE, BYTE1, and BYTE2. 

- IDLE state: In this state, the FSM waits for a byte with in[3]=1. If it receives such a byte, it transitions to the BYTE1 state. 
- BYTE1 state: In this state, the FSM has received the first byte of the message. It stores this byte and waits for the next byte. Once it receives the next byte, it transitions to the BYTE2 state.
- BYTE2 state: In this state, the FSM has received the second byte of the message. It stores this byte and waits for the third byte. Once it receives the third byte, it transitions back to the IDLE state and asserts the done signal.

To implement the datapath, we need to store the three bytes of the message. We can use three registers: byte1, byte2, and byte3, to store these bytes. 

We also need to implement the logic to concatenate these bytes to form the 24-bit output signal out_bytes.
