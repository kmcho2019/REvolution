To implement the TopModule, we will create a finite state machine with 4 states: Idle, Byte1, Byte2, and Done. The Idle state will discard bytes until we see one with in[3] = 1. Once such a byte is received, we transition to the Byte1 state and start storing the bytes. After receiving the first byte, we transition to the Byte2 state and store the second byte. Once the second byte is received, we transition to the Done state and store the third byte. In the Done state, we assert the done signal and output the 24-bit message. We use a 2-bit counter to keep track of the current state. We will use a 24-bit register to store the message bytes. The reset signal is used to reset the finite state machine and the message register.
