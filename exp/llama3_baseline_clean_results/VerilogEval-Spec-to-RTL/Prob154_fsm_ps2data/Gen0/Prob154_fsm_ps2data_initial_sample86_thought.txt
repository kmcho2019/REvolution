To solve this problem, we will implement a finite state machine (FSM) in Verilog. The FSM will have four states: 
1. RESET - This is the initial state where all variables are reset.
2. IDLE - This is the state where we wait for the first byte of the message (the byte with in[3]=1).
3. BYTE2 - This is the state where we receive the second byte of the message.
4. BYTE3 - This is the state where we receive the third byte of the message.

We will use two 8-bit registers, byte2 and byte3, to store the second and third bytes of the message, respectively. When the third byte is received, we will assert the done signal and output the 24-bit message in the out_bytes port.

In each state, we will check for the reset condition and if it's active, we will move to the RESET state and reset all variables.

We will use two always blocks: one for the combinational logic and one for the sequential logic.
