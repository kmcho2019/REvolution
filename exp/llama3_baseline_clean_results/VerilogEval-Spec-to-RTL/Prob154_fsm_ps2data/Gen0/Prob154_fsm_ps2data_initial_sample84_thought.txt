To implement the TopModule, we will design a finite state machine with the following states: IDLE, BYTE1, BYTE2, and DONE. The FSM will start in the IDLE state and stay there until it receives a byte with in[3]=1. When it receives such a byte, it will move to the BYTE1 state, storing the byte in the first byte of out_bytes. It will then move to the BYTE2 state, storing the next byte in the second byte of out_bytes. After receiving the second byte, it will move to the DONE state, storing the third byte in the third byte of out_bytes and asserting the done signal. The done signal will be asserted in the cycle immediately after the third byte of each message was successfully received. On the next clock cycle, the FSM will return to the IDLE state. The reset signal will be used to reset the FSM to the IDLE state.
