To implement the finite state machine (FSM) in Verilog, we will use a simple state machine with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
- The IDLE state will be the initial state where the machine will stay until it encounters a byte with in[3] = 1.
- When such a byte is encountered, the machine will transition to the BYTE1 state, storing this byte in the out_bytes[23:16].
- In the BYTE1 state, it will wait for the next byte and then transition to the BYTE2 state, storing this byte in out_bytes[15:8].
- Similarly, in the BYTE2 state, it will wait for the next byte and then transition to the BYTE3 state, storing this byte in out_bytes[7:0].
- In the BYTE3 state, it will assert the done signal for one clock cycle and then transition back to the IDLE state, waiting for the next message.
- The reset signal will be used to reset the FSM to the IDLE state and clear the out_bytes and done signals.
