The TopModule will be designed as a finite state machine with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, the FSM will continuously check for the input byte with in[3]=1. 
Once this condition is met, the FSM will move to the BYTE1 state and store the input byte as the first byte of the message.
In the BYTE1 state, the FSM will store the next input byte as the second byte of the message and move to the BYTE2 state.
In the BYTE2 state, the FSM will store the next input byte as the third byte of the message and move to the BYTE3 state.
In the BYTE3 state, the FSM will signal done and output the 24-bit message. 
The FSM will then move back to the IDLE state to search for the next message.
The reset signal will be used to reset the FSM to the IDLE state.
