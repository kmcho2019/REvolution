To implement the TopModule, we'll create a finite state machine (FSM) with the following states:
- IDLE: The initial state where we wait for the first byte of the message (in[3] = 1).
- BYTE1: The state after receiving the first byte of the message.
- BYTE2: The state after receiving the second byte of the message.
- DONE: The state after receiving the third byte of the message, where we assert the done signal.

We'll use a counter to keep track of the current state and a register to store the received bytes. When the done signal is asserted, we'll output the 24-bit message (out_bytes).
