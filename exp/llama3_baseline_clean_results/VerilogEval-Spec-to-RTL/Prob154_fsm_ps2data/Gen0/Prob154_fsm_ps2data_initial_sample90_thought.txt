The module TopModule should implement a finite state machine (FSM) with two main states: 
1. Searching for the start of a message (i.e., a byte with in[3]=1), and 
2. Receiving the rest of the message (two more bytes). 
The FSM should also handle the reset condition, where it should reset to the initial state.
The datapath should store the received bytes in a register and output them as a 24-bit signal out_bytes when the done signal is asserted.
