The problem can be solved by implementing a finite state machine (FSM) that keeps track of the current state and the bytes received so far. The FSM should have four states: 
- IDLE: The initial state where the FSM waits for a byte with in[3] = 1.
- BYTE1: The state where the first byte of the message has been received.
- BYTE2: The state where the second byte of the message has been received.
- BYTE3: The state where the third byte of the message has been received.

The FSM will transition from one state to another based on the input byte and the current state. When the FSM reaches the BYTE3 state, it will assert the done signal and output the 24-bit message.

The datapath module will store the received bytes in a 24-bit register and output the register value when the done signal is asserted.
