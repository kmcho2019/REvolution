The finite state machine will be implemented using a sequential logic design. 
It will have four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, it will wait for the input byte with in[3]=1. 
Once it receives this byte, it will transition to the BYTE1 state and start storing the byte. 
Then, it will transition to the BYTE2 state and store the next byte. 
Finally, it will transition to the BYTE3 state, store the third byte, and assert the done signal in the next clock cycle. 
The reset signal will be used to return the FSM to the IDLE state. 
The datapath will be designed to output the 24-bit message whenever the done signal is asserted.
