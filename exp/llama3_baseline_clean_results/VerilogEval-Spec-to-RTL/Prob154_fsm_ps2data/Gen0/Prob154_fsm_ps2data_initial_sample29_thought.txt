The TopModule can be designed using a finite state machine (FSM) that has three states: IDLE, BYTE1, and BYTE2. In the IDLE state, the FSM discards bytes until it finds one with in[3]=1, which marks the start of a message. Once a message start is detected, the FSM transitions to the BYTE1 state, where it captures the first byte of the message. In the BYTE2 state, it captures the second byte. After capturing the third byte, the FSM signals done and outputs the 24-bit message.

The datapath can be implemented using registers to store the bytes of the message. The out_bytes output can be driven by the captured bytes when the done signal is asserted.
