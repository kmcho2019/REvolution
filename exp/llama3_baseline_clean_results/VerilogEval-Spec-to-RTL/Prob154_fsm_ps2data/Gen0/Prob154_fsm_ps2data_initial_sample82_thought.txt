To solve this problem, we can design a finite state machine (FSM) that transitions through different states to search for the message boundaries. The states can be defined as follows:
- IDLE: The initial state where the FSM waits for the input byte stream and discards bytes until it sees one with in[3] = 1.
- BYTE1: The state where the FSM has seen the first byte of the message (in[3] = 1) and stores it.
- BYTE2: The state where the FSM has received the second byte of the message and stores it.
- BYTE3: The state where the FSM has received the third byte of the message, stores it, and signals the receipt of a message by asserting the done signal.
We can use a counter or a separate signal to keep track of the current state and transition between these states based on the input byte stream. Additionally, we need to implement a datapath to output the 24-bit message whenever a packet is received.
