To implement the finite state machine in the TopModule, we'll define four states: IDLE, BYTE1, BYTE2, and DONE. The IDLE state is the initial state where we discard bytes until we see one with in[3]=1. Once we find such a byte, we move to the BYTE1 state and start storing the bytes. In the BYTE1 and BYTE2 states, we store the bytes in the out_bytes register and move to the next state until we've received three bytes. After receiving the third byte, we move to the DONE state and assert the done signal. The out_bytes register is updated with the new bytes in each cycle. We also need to handle the reset signal, which will reset the state machine to the IDLE state and clear the out_bytes register.
