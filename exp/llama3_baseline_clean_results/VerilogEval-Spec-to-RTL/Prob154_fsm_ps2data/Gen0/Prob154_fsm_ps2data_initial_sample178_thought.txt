To implement the TopModule, we can use a finite state machine (FSM) with three states: 
1. Idle: This is the initial state where the module waits for the start of a message (in[3]=1).
2. ReceiveByte1: After the start of a message is detected, the module enters this state and stores the current byte as the first byte of the message.
3. ReceiveByte2: The module then moves to this state, where it stores the next byte as the second byte of the message.
4. ReceiveByte3: Finally, the module enters this state, where it stores the next byte as the third byte of the message and signals that a message has been received (done=1).

We will also use registers to store the three bytes of the message. The out_bytes output will be connected to these registers.

The reset signal will be used to reset the FSM to the Idle state and clear the registers.
