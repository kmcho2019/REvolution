To solve this problem, we will implement a finite state machine (FSM) in Verilog. The FSM will have four states: idle, byte1, byte2, and done. It will start in the idle state and wait for a byte with in[3] = 1. Once it receives such a byte, it will transition to the byte1 state and store the byte. In the byte1 state, it will wait for the next byte and store it when received. Then, it will transition to the byte2 state and wait for the next byte. When the next byte is received, it will transition to the done state and signal done. In the done state, it will output the three bytes (out_bytes) and then transition back to the idle state. The FSM will also handle the reset signal, which will reset the FSM to the idle state when asserted.
