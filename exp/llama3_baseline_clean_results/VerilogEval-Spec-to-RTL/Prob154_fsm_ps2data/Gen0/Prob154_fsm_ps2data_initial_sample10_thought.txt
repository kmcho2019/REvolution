To implement the TopModule, we need to create a finite state machine that can keep track of the current state and transition to the next state based on the input. The states can be defined as follows: 
- IDLE: Initial state where the module waits for the first byte with in[3]=1.
- BYTE1: State after receiving the first byte with in[3]=1.
- BYTE2: State after receiving the second byte.
- BYTE3: State after receiving the third byte.

When the module is in the BYTE3 state and a new input is received, it transitions back to the IDLE state and asserts the done signal.

We will also need to implement a datapath module to store the received bytes and output them as a 24-bit signal (out_bytes) when a packet is received.

The module will use a 2-bit state register to keep track of the current state, and a 24-bit register to store the received bytes.
