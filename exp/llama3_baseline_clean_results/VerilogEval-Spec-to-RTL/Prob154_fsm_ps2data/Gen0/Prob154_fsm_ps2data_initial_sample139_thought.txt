To implement the finite state machine (FSM) that searches for message boundaries, we will use a simple state machine with four states: 
- idle: This is the initial state where the FSM waits for the start of a message.
- byte1: Once a byte with in[3] = 1 is received, the FSM moves to this state and stores the byte.
- byte2: The FSM then waits for the second byte and stores it.
- done: After receiving the third byte, the FSM signals done in the next cycle and outputs the 24-bit message.

We will use a counter to keep track of the current state and a register to store the received bytes. The out_bytes output will be driven by the stored bytes.
