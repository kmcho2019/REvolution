The problem requires implementing a finite state machine (FSM) to search for message boundaries in an input byte stream. The FSM should discard bytes until it sees one with in[3]=1, then assume this is byte 1 of a message, and signal the receipt of a message once all 3 bytes have been received. The FSM will have states for idle, receiving byte 1, receiving byte 2, and receiving byte 3. It will transition between these states based on the input byte and the current state. When the third byte is received, it will assert the done signal and output the 24-bit message.
