The finite state machine (FSM) will have four states: IDLE, BYTE1, BYTE2, and DONE. 
In the IDLE state, the FSM will check if the input byte has its 3rd bit set. 
If it does, the FSM will transition to the BYTE1 state and store the input byte.
In the BYTE1 and BYTE2 states, the FSM will store the subsequent input bytes.
After the third byte is received, the FSM will transition to the DONE state, 
where it will assert the done signal and output the 24-bit message.
The FSM will then return to the IDLE state.
The reset signal will reset the FSM to the IDLE state.
