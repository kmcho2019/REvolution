To solve this problem, we will design a finite state machine (FSM) that searches for message boundaries in the input byte stream. The FSM will have four states: IDLE, BYTE1, BYTE2, and DONE. In the IDLE state, the FSM will discard bytes until it sees one with in[3]=1, which is the start of a message. Then, it will move to the BYTE1 state and store the byte. In the BYTE1 and BYTE2 states, the FSM will store the subsequent bytes and move to the next state. Once the third byte is received, the FSM will move to the DONE state and assert the done signal. The datapath will output the 24-bit message (out_bytes) whenever the done signal is asserted. The reset signal will reset the FSM to the IDLE state and clear the output.
