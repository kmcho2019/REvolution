The TopModule should be implemented as a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state. It stays in the IDLE state until it receives a byte with in[3] = 1. Once this condition is met, it transitions to the BYTE1 state and captures the current byte. Then, it transitions to the BYTE2 state and captures the next byte. Finally, it transitions to the BYTE3 state, captures the third byte, and signals done in the next cycle. The out_bytes output should be valid whenever the done signal is asserted, with the first byte in out_bytes[23:16], the second byte in out_bytes[15:8], and the third byte in out_bytes[7:0]. 
The FSM should also handle the reset signal. When the reset signal is active high, the FSM should return to the IDLE state, and all outputs should be reset to their initial values.
