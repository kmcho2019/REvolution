To implement the TopModule, we will design a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. 
The IDLE state will discard bytes until a byte with in[3]=1 is received. 
The BYTE1 state will capture the first byte of the message and transition to the BYTE2 state.
The BYTE2 state will capture the second and third bytes of the message and then transition back to the IDLE state, 
signaling that a message has been received (done) in the process.

The datapath will be implemented using registers to store the bytes of the message. 
out_bytes will be assigned the value of the message whenever the done signal is asserted.
