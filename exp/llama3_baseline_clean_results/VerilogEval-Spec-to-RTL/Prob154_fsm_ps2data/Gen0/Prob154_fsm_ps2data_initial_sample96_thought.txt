The problem requires implementing a finite state machine (FSM) in Verilog to search for message boundaries in a given input byte stream. The FSM should discard bytes until it sees one with in[3]=1 and then assume that this is byte 1 of a message. It should signal the receipt of a message once all 3 bytes have been received. We can achieve this by using a 2-state FSM (one state for waiting for the start of a message and another state for receiving the rest of the message) and using a counter to keep track of the number of bytes received. The FSM should also output the 24-bit message whenever a packet is received.
