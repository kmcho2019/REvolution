To implement the required finite state machine, we'll use a simple state machine with 4 states: 
- idle: The initial state, waiting for the first byte of the message.
- byte1: After receiving the first byte, waiting for the second byte.
- byte2: After receiving the second byte, waiting for the third byte.
- done_state: The final state, signaling that a message has been received.
The state machine will transition between these states based on the input byte stream.
We will use a 24-bit register to hold the received message bytes.
The `done` signal will be asserted in the cycle immediately after the third byte of each message is received.
