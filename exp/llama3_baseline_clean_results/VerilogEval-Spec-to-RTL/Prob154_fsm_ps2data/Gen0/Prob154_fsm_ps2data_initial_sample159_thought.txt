To implement the TopModule, we need to design a finite state machine (FSM) that searches for message boundaries in an input byte stream. The FSM should discard bytes until it sees one with in[3]=1, then assume this is byte 1 of a message, and signal the receipt of a message once all 3 bytes have been received. We will use a 2-bit state variable to represent the states of the FSM: idle (00), byte1 (01), byte2 (10), and byte3 (11). The FSM will transition from idle to byte1 when it sees a byte with in[3]=1, then transition from byte1 to byte2, from byte2 to byte3, and finally from byte3 back to idle after signaling the receipt of a message. We will also use a 24-bit register to store the received message bytes.
