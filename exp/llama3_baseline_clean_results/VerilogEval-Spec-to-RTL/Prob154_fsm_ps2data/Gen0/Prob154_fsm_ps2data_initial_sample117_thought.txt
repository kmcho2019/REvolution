The problem can be solved by implementing a finite state machine with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, the FSM will continuously check for a byte with in[3] = 1, and upon finding it, transition to BYTE1 state. 
In the BYTE1, BYTE2, and BYTE3 states, the FSM will store the incoming bytes in a register, and transition to the next state after each byte is stored.
Once all three bytes have been stored, the FSM will transition back to the IDLE state, and assert the done signal in the same cycle.
To implement the datapath module, we will use a register to store the incoming bytes and output them when the done signal is asserted.
We will also use a counter to keep track of the current state and the number of bytes stored.
