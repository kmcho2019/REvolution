To implement the TopModule, we need to design a finite state machine (FSM) that can identify message boundaries based on the given algorithm. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM will start in the IDLE state and transition to BYTE1 when it encounters a byte with in[3]=1. It will then move to BYTE2 and BYTE3 after receiving the second and third bytes, respectively. The FSM will signal 'done' in the cycle immediately after the third byte of each message is successfully received.

We will use a counter to keep track of the current byte and a register to store the received bytes. The datapath module will output the 24-bit message whenever a packet is received.
