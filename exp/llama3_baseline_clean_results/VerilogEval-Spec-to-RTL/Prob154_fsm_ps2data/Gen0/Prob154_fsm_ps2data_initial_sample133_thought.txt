To implement the TopModule, we need to design a finite state machine (FSM) that searches for message boundaries in the input byte stream. The FSM should have at least three states: Idle, Byte1, and Byte2. The Idle state is the initial state where the FSM waits for a byte with in[3]=1. Once such a byte is received, the FSM transitions to the Byte1 state and captures the first byte. Then, it transitions to the Byte2 state to capture the second byte, and finally, it captures the third byte and signals the receipt of a message (done). The datapath module will output the 24-bit (3 byte) message whenever a packet is received. We will use a counter to keep track of the number of bytes received.
