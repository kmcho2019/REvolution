The TopModule will be implemented as a finite state machine (FSM) with four states: idle, byte1, byte2, and byte3. The FSM will transition between states based on the value of the input byte. When the FSM is in the idle state and it receives a byte with in[3] = 1, it will transition to the byte1 state and store the byte in the out_bytes register. In the byte1 state, the FSM will wait for the next byte and store it in the out_bytes register, then transition to the byte2 state. In the byte2 state, the FSM will wait for the next byte, store it in the out_bytes register, and then transition to the byte3 state. When the FSM is in the byte3 state, it will assert the done signal and remain in this state until the next byte is received. If the FSM is in the byte1, byte2, or byte3 state and it receives a byte with in[3] = 1, it will reset to the byte1 state and start a new message. The reset signal will be used to reset the FSM to the idle state.
