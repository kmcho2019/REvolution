To solve this problem, we can implement a finite state machine with three states: 
1. IDLE: This is the initial state of the FSM where it waits for a byte with in[3]=1. 
2. BYTE_1: Once the FSM encounters a byte with in[3]=1, it transitions to this state where it stores the byte as the first byte of the message and waits for the next two bytes.
3. BYTE_2 and BYTE_3: After receiving the first byte, the FSM transitions through these two states, storing each subsequent byte as the second and third bytes of the message.
When the FSM receives the third byte, it signals done in the next cycle and outputs the 24-bit message.

We can use a counter to keep track of the current state and the bytes received. 
The datapath module will output the 24-bit message whenever a packet is received.
