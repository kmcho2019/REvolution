The module TopModule will be implemented using a finite state machine (FSM) with the following states: 
- Idle: This is the initial state. In this state, the FSM waits for the byte with in[3]=1 to arrive.
- Byte1: Once the byte with in[3]=1 arrives, the FSM transitions to this state. It stores this byte as the first byte of the message.
- Byte2: The FSM then waits for the second byte of the message. Once it arrives, it stores this byte as the second byte of the message.
- Byte3: The FSM then waits for the third byte of the message. Once it arrives, it stores this byte as the third byte of the message and asserts the done signal.

The datapath module will consist of registers to store the three bytes of the message and a multiplexer to output the 24-bit message.
