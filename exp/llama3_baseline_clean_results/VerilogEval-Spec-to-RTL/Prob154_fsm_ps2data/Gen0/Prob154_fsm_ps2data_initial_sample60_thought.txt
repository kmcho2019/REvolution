To implement the TopModule, we need to design a finite state machine (FSM) that searches for message boundaries in the input byte stream. The FSM should have at least four states: 
1. IDLE: waiting for the first byte of a message (in[3] = 1)
2. BYTE1: received the first byte, waiting for the second byte
3. BYTE2: received the second byte, waiting for the third byte
4. DONE: received the third byte, signal done and output the message

We also need to implement a datapath module to output the 24-bit message whenever a packet is received. The datapath module should store the received bytes in a register and output them when the done signal is asserted.

The reset signal is active high synchronous, so we need to reset the FSM and the datapath module when the reset signal is high.
