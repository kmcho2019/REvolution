To implement the TopModule, we'll use a finite state machine (FSM) with three states: IDLE, BYTE_1, and BYTE_2. In the IDLE state, we'll check if the input byte has the most significant bit set (in[7] = 1). If it does, we'll transition to the BYTE_1 state. In the BYTE_1 state, we'll capture the input byte and transition to the BYTE_2 state. In the BYTE_2 state, we'll capture the second byte and transition back to the IDLE state, signaling done. We'll use a 24-bit register to store the three bytes and output it whenever the done signal is asserted.
