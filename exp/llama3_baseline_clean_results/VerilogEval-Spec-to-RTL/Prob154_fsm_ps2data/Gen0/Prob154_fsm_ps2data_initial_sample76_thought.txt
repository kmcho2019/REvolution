To implement the TopModule, we will create a finite state machine (FSM) with two main states: WAIT_FOR_BYTE_1 and RECEIVE_MESSAGE. The WAIT_FOR_BYTE_1 state will discard incoming bytes until it finds one with in[3]=1. Once this condition is met, the FSM will transition to the RECEIVE_MESSAGE state, where it will collect the next two bytes. After collecting all three bytes, the FSM will assert the done signal in the next clock cycle.

We will use three registers to store the bytes of the message: byte_1, byte_2, and byte_3. These registers will be updated in the RECEIVE_MESSAGE state.

In addition to the FSM and the byte registers, we will also need a counter to keep track of the current byte being received. This counter will be reset when the FSM transitions back to the WAIT_FOR_BYTE_1 state.

The output out_bytes will be generated by concatenating the three byte registers: out_bytes[23:16] = byte_1, out_bytes[15:8] = byte_2, out_bytes[7:0] = byte_3.
