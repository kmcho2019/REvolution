To implement the TopModule with the specified interface, we will create a finite state machine (FSM) that goes through the following states:
1. IDLE: This is the initial state where the FSM waits for the first byte with in[3]=1. When this condition is met, the FSM moves to the BYTE1 state.
2. BYTE1: In this state, the FSM receives the first byte of the message and moves to the BYTE2 state.
3. BYTE2: The FSM receives the second byte of the message and moves to the BYTE3 state.
4. BYTE3: The FSM receives the third byte of the message and moves back to the IDLE state, signaling done.

We will use a 2-bit state variable to represent these four states (IDLE = 2'b00, BYTE1 = 2'b01, BYTE2 = 2'b10, BYTE3 = 2'b11). 
We will also use three 8-bit registers (byte1, byte2, byte3) to store the received bytes of the message.

The output out_bytes will be the concatenation of the three bytes, with byte1 as the most significant byte.

The done signal will be asserted in the cycle after the third byte of the message has been received.
