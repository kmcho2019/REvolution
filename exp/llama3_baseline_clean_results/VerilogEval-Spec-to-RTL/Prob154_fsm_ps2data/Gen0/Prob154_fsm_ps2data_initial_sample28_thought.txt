To solve this problem, we can implement a finite state machine with three states: idle, byte1, and byte2. The idle state is the initial state, where we wait for a byte with in[3]=1. Once we see such a byte, we transition to the byte1 state, where we store the byte and wait for the next byte. We then transition to the byte2 state, where we store the next byte and wait for the third byte. After receiving the third byte, we signal done and output the 24-bit message.

We can use a counter to keep track of the current state and the number of bytes received. We can also use registers to store the received bytes.

The reset signal is active high synchronous, so we need to reset the state machine and the registers when the reset signal is high.

We can output the 24-bit message whenever the done signal is asserted, and output anything at other times.
