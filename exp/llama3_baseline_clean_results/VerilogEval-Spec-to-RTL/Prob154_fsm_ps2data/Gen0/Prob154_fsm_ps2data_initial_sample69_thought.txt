To implement the finite state machine (FSM) described, we can define four states: IDLE, BYTE1, BYTE2, and BYTE3. 

- IDLE state: Wait for a byte with in[3]=1. When such a byte is received, transition to BYTE1 state.
- BYTE1 state: Store the received byte as the first byte of the message. Transition to BYTE2 state.
- BYTE2 state: Store the received byte as the second byte of the message. Transition to BYTE3 state.
- BYTE3 state: Store the received byte as the third byte of the message, and signal done in the next cycle.

The reset signal will reset the FSM to the IDLE state. The datapath will be implemented to output the 24-bit message (out_bytes) when the done signal is asserted.
