To solve this problem, we will implement a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM will start in the IDLE state and remain there until it sees a byte with in[3]=1. Once this condition is met, the FSM will move to the BYTE1 state, where it will capture the first byte of the message. The FSM will then move to the BYTE2 and BYTE3 states, capturing the second and third bytes of the message, respectively. After the third byte has been captured, the FSM will signal done in the next cycle. The out_bytes output will be valid whenever the done signal is asserted. We will use a counter to keep track of the current byte number and a register to store the captured bytes.
