To implement the finite state machine that searches for message boundaries in the input byte stream, we can use a simple 2-state machine: IDLE and RECV. The machine starts in the IDLE state, where it discards bytes until it sees one with in[3]=1. Once it sees this byte, it transitions to the RECV state and assumes this is byte 1 of a message. It then receives the next two bytes and signals done in the cycle immediately after the third byte of each message was successfully received. We also need a counter to keep track of the current byte number. We will use the counter to determine when we have received all 3 bytes of a message.

The datapath module will output the 24-bit (3 byte) message whenever a packet is received. We can use a shift register to store the received bytes and output them when the done signal is asserted.
