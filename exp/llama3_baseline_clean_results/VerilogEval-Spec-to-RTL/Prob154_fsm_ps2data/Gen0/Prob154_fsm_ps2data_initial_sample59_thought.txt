The TopModule will implement a finite state machine (FSM) with the following states:
- IDLE: discard bytes until a byte with in[3] = 1 is found
- BYTE1: store the current byte as the first byte of the message
- BYTE2: store the current byte as the second byte of the message
- BYTE3: store the current byte as the third byte of the message and signal done

The FSM will transition from IDLE to BYTE1 when a byte with in[3] = 1 is found.
It will then transition from BYTE1 to BYTE2, from BYTE2 to BYTE3, and from BYTE3 back to IDLE, signaling done in the cycle after the third byte is received.

The datapath will store the three bytes of the message in a 24-bit register and output this register as out_bytes whenever done is asserted.
