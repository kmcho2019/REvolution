The finite state machine (FSM) should have three states: IDLE, BYTE1, and BYTE2. The FSM starts in the IDLE state. When in the IDLE state, it checks each input byte to see if the 4th bit is 1. If it is, the FSM moves to the BYTE1 state and stores the input byte as the first byte of the message. In the BYTE1 state, the FSM waits for one clock cycle, then moves to the BYTE2 state and stores the current input byte as the second byte of the message. In the BYTE2 state, the FSM waits for one clock cycle, then moves back to the IDLE state, but first, it signals the done signal and outputs the message.

To implement the datapath, we need three registers to store the three bytes of the message. The output out_bytes should be a concatenation of these three registers. When the FSM is in the IDLE state, the registers should be reset. When the FSM moves from IDLE to BYTE1, the first register should be loaded with the current input byte. When the FSM moves from BYTE1 to BYTE2, the second register should be loaded with the current input byte. When the FSM moves from BYTE2 to IDLE, the third register should be loaded with the current input byte.

The done signal should be asserted when the FSM is in the BYTE2 state and the next clock cycle is about to start.
