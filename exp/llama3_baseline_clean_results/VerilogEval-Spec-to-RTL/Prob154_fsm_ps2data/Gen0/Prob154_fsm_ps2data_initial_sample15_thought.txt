The module TopModule can be implemented using a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and DONE. The FSM starts in the IDLE state, where it discards bytes until it sees one with in[3]=1. When this condition is met, it transitions to the BYTE1 state and stores the current byte. Then, it transitions to the BYTE2 state, stores the next byte, and finally transitions to the DONE state, stores the third byte, and signals the receipt of a message by asserting the done signal. The FSM resets to the IDLE state when the reset signal is asserted or after it has signaled the receipt of a message.
