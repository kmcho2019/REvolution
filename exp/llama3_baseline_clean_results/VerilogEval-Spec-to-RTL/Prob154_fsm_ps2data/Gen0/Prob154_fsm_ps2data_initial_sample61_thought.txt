To implement the finite state machine that searches for message boundaries, 
we need to design a module that has the following states:
- IDLE: Discard bytes until in[3] = 1.
- BYTE1: Assume the current byte is the first byte of a message and wait for the next byte.
- BYTE2: The current byte is the second byte of a message and wait for the next byte.
- DONE: All three bytes have been received, signal done and output the message.

The module should also implement a datapath to output the 24-bit message 
whenever a packet is received. The reset signal should be active high synchronous, 
meaning that the module should reset to its initial state when reset is high.

We will use a counter to keep track of the current state and a register to store 
the received bytes. When a message is received, we will output the stored bytes.
