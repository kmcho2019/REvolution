The TopModule should implement a finite state machine (FSM) to search for message boundaries. The FSM has two states: IDLE and MSG_RECEIVE. In the IDLE state, it discards bytes until a byte with in[3] = 1 is received. After receiving this byte, it transitions to the MSG_RECEIVE state and starts collecting bytes. Once three bytes are received, it signals done and returns to the IDLE state. We will use a counter to keep track of the number of bytes received. We also need to store the received bytes in a register and output them when the done signal is asserted.
