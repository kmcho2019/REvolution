To implement the TopModule, we will use a finite state machine (FSM) with four states: 
1. IDLE: This is the initial state where the FSM waits for the first byte of the message.
2. BYTE1: After receiving the first byte, the FSM enters this state and waits for the second byte.
3. BYTE2: After receiving the second byte, the FSM enters this state and waits for the third byte.
4. DONE: After receiving the third byte, the FSM enters this state and signals the receipt of the message.

The FSM will also have a counter to keep track of the current byte being received. 
We will use a 24-bit register to store the received message bytes and a done signal to indicate when a message is received.
