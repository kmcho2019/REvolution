To implement the TopModule, we will use a finite state machine with 4 states: IDLE, BYTE1, BYTE2, and BYTE3. The IDLE state will be the initial state where the module waits for the input byte stream to have in[3] = 1. Once this condition is met, the module will transition to the BYTE1 state and capture the current input byte. The module will then transition to the BYTE2 state and capture the next input byte. Finally, the module will transition to the BYTE3 state, capture the last byte, and then signal done in the next cycle. The out_bytes will be updated with the captured bytes in the correct order (out_bytes[23:16] is the first byte, out_bytes[15:8] is the second byte, etc.).
