To solve this problem, we need to implement a finite state machine (FSM) with the following states: 
- IDLE: This is the initial state where we wait for the first byte of a message. We discard bytes until we see one with in[3]=1.
- BYTE1: After receiving the first byte, we enter this state and wait for the second byte.
- BYTE2: After receiving the second byte, we enter this state and wait for the third byte.
- DONE: After receiving the third byte, we enter this state and signal done in the next cycle.

We also need to implement a datapath to store the three bytes of the message. The datapath will output the 24-bit message whenever a packet is received.

The FSM will be implemented using a 2-bit state variable. The datapath will be implemented using three 8-bit registers to store the three bytes of the message.
