To implement the TopModule, we need to design a finite state machine (FSM) that can search for message boundaries in an input byte stream. The FSM will have four states: idle, byte1, byte2, and byte3. In the idle state, the FSM will discard bytes until it sees one with in[3]=1. Once it sees such a byte, it will transition to the byte1 state and store the byte. Then, it will transition to the byte2 state, store the next byte, and then to the byte3 state, store the next byte. After storing the third byte, it will signal done in the next cycle and transition back to the idle state.

The datapath module will be responsible for outputting the 24-bit (3 byte) message whenever a packet is received. The out_bytes signal will be valid whenever the done signal is asserted.

We will use a 2-bit state register to implement the FSM. The state register will be reset to the idle state (00) when the reset signal is high. We will also use three 8-bit registers to store the bytes of the message.

The FSM will have the following transitions:
- idle (00) -> byte1 (01) when in[3] = 1
- byte1 (01) -> byte2 (10)
- byte2 (10) -> byte3 (11)
- byte3 (11) -> idle (00) when done is asserted

The datapath module will output the 24-bit message by concatenating the three bytes stored in the registers.
