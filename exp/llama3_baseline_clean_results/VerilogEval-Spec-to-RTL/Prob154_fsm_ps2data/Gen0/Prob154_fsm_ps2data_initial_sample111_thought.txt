To implement the TopModule, we will use a finite state machine (FSM) to keep track of the state of the input byte stream. The FSM will have four states: 
- IDLE: The initial state, where the module waits for a byte with in[3]=1 to arrive.
- BYTE1: The state after the first byte of a message is received.
- BYTE2: The state after the second byte of a message is received.
- BYTE3: The state after the third byte of a message is received.

We will also use three 8-bit registers to store the received bytes. When the FSM is in the BYTE3 state, it will assert the done signal and output the stored bytes as out_bytes.
