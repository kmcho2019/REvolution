The finite state machine (FSM) will be designed with three states: 
1. IDLE: In this state, the module discards bytes until it sees one with in[3]=1, then it moves to the BYTE_1 state.
2. BYTE_1: In this state, it stores the current byte as the first byte of the message and moves to the BYTE_2 state.
3. BYTE_2: In this state, it stores the current byte as the second byte of the message and moves to the BYTE_3 state.
4. BYTE_3: In this state, it stores the current byte as the third byte of the message, outputs the message, and signals done.

The FSM will be implemented using a state register and a next state logic.
The datapath will be implemented using registers to store the bytes of the message.

The reset signal is active high synchronous, meaning it resets the FSM and the datapath when it is high. 
The out_bytes needs to be valid whenever the done signal is asserted, so the datapath should output the message when the FSM is in the BYTE_3 state.
