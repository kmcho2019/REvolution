The problem requires designing a finite state machine (FSM) that searches for message boundaries in an input byte stream. The FSM should discard bytes until it sees one with in[3]=1, then assume that byte as the first byte of a message, and signal the receipt of a message once all 3 bytes have been received. The FSM will be implemented using a 4-state machine: idle, byte1, byte2, and done. In each state, the FSM checks the input byte and moves to the next state accordingly. The datapath module will output the 24-bit (3 byte) message whenever a packet is received.
