To implement the finite state machine, we will use a state variable with 4 possible states: idle, byte1, byte2, and done. Initially, the FSM is in the idle state. It will stay in the idle state until it sees a byte with in[3]=1, then it will move to the byte1 state. In the byte1 state, it will store the input byte and move to the byte2 state. In the byte2 state, it will store the input byte and move to the done state. In the done state, it will signal the receipt of a message by asserting the done signal and output the 3-byte message, then it will move back to the idle state. The FSM will also be reset to the idle state when the reset signal is asserted.
