To implement the finite state machine that searches for message boundaries, we will use a simple state machine with three states: idle, byte1, and byte2. 
- In the idle state, we discard bytes until we see one with in[3]=1.
- When we see a byte with in[3]=1, we transition to the byte1 state and store the byte.
- In the byte1 state, we store the next byte and transition to the byte2 state.
- In the byte2 state, we store the next byte and signal done in the cycle immediately after the third byte of each message was successfully received.
We will use a 24-bit register to store the 3-byte message and output it whenever the done signal is asserted.
