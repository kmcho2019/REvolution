To implement the TopModule, we will use 8 instances of a D flip-flop (DFF) since we need to store 8 bits of data. Each DFF will have an input (d) and an output (q), along with a clock (clk) and a reset (reset) signal. The DFFs will be triggered on the positive edge of the clk and will have an active high synchronous reset, setting the output (q) to zero when the reset is high. We can use the built-in Verilog primitive DFF (D flip-flop) or define our own using a reg and an always block.
