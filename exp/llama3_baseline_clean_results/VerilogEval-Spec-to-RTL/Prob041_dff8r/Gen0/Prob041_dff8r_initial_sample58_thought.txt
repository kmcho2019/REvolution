To implement the TopModule, we can create a module that contains 8 D flip-flops (DFFs). Each DFF should have an input (d), an output (q), a clock input (clk), and a synchronous reset input (reset). When the reset signal is high, the output of each DFF should be set to zero. Otherwise, on the positive edge of the clock, the input (d) should be stored in the DFF and output on (q). We will use the Verilog non-blocking assignment operator (<=) to model the behavior of the DFFs.
