To implement the TopModule, we will create a module that contains 8 D flip-flops. Each D flip-flop will have an 8-bit input 'd' and an 8-bit output 'q'. The D flip-flops will be triggered by the positive edge of the clock signal 'clk' and will have an active high synchronous reset. When 'reset' is high, the outputs 'q' will be set to zero.
