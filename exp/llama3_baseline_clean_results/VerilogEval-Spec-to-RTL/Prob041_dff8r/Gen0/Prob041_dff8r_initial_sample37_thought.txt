To implement the TopModule, we need to create a module that includes 8 D flip-flops. Each D flip-flop will have a data input (d), a clock input (clk), and a reset input (reset). The reset input will be active high and synchronous, meaning it will reset the output to zero on the positive edge of the clock when reset is high. We will use the built-in Verilog D flip-flop syntax to define each flip-flop.
