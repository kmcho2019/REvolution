To implement the TopModule with the specified interface, we need to design a module that contains 8 D flip-flops. Each D flip-flop will have a data input (d), a clock input (clk), and an active high synchronous reset input (reset). On the positive edge of the clock and when reset is low, the output of each D flip-flop (q) should be the same as its data input. If the reset is high, the output of each D flip-flop should be set to 0, regardless of the clock edge. We will use the non-blocking assignment operator (<=) to assign values to the outputs, which is suitable for sequential logic.
