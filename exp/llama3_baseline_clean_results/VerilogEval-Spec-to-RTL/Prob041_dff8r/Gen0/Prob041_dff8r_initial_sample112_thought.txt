To implement the TopModule, we need to create a module that includes 8 D flip-flops. Each D flip-flop should be triggered by the positive edge of the clk signal and have an active high synchronous reset. The input d is an 8-bit signal that will be used to set the output of each D flip-flop. The output q will also be an 8-bit signal that reflects the current state of the D flip-flops.
