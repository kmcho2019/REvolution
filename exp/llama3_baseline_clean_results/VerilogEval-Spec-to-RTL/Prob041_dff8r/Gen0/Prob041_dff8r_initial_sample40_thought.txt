To implement the TopModule, we need to create a module that includes 8 D flip-flops (DFFs) with active high synchronous reset. Each DFF should be triggered by the positive edge of the clock signal (clk). The reset signal should be active high, meaning that when it is high, the outputs of all DFFs should be set to zero. We will use the non-blocking assignment operator (<=) to assign values to the outputs of the DFFs, ensuring that the assignments are scheduled to occur at the same time.
