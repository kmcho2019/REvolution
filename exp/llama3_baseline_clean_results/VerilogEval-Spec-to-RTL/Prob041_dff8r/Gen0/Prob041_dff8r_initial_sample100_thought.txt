To implement the TopModule, we need to create a module with the specified interface. Inside the module, we will use 8 D flip-flops (DFFs) to store the input data d. The DFFs will be triggered by the positive edge of the clock signal clk and will have an active high synchronous reset. When the reset signal is high, all DFFs will be reset to zero. We will use Verilog's built-in reg type to declare the output q and assign it the value of the DFFs. We will use a procedural block (always) to describe the behavior of the DFFs.
