To implement the TopModule, we will use 8 D flip-flops (DFFs) to store the input data d. Each DFF will be triggered by the positive edge of the clock signal clk, and will have an active high synchronous reset. This means that when the reset signal is high, the output of all DFFs will be set to zero, regardless of the current clock state. We will use the non-blocking assignment operator (<=) in Verilog to assign the input d to the DFFs.
