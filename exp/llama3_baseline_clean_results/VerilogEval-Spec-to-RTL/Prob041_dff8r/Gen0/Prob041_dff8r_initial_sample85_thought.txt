To implement the TopModule, we need to create a module that includes 8 D flip-flops. Each D flip-flop will be triggered by the positive edge of the clock (clk) and will have an active high synchronous reset. When the reset signal is high, the output of each D flip-flop will be set to zero. Otherwise, the output of each D flip-flop will be the value of its corresponding input (d) at the previous positive edge of the clock. We will use Verilog's built-in always block and the posedge keyword to implement this behavior.
