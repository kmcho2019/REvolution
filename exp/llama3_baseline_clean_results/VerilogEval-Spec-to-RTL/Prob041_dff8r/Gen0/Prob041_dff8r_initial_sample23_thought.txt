To design the TopModule, we will instantiate 8 D flip-flops (DFFs) within the module. Each DFF will have a data input (d), a clock input (clk), and a reset input (reset). The reset will be synchronous and active high, meaning that when reset is high and there is a positive edge on the clock, the output (q) will be reset to zero. All DFFs will be triggered by the positive edge of the clock. We will use the built-in Verilog syntax for describing the DFFs.
