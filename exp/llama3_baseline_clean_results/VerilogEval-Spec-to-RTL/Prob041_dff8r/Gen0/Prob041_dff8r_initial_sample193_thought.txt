To implement the TopModule, we need to create a module that includes 8 D flip-flops. Each flip-flop should have a data input (d), a clock input (clk), an active high synchronous reset input (reset), and a data output (q). The reset should be synchronous, meaning it only resets the flip-flops on the positive edge of the clock. We will use a single process (always block) to describe the behavior of all 8 flip-flops. This process will be triggered by the positive edge of the clock and will include the reset condition.
