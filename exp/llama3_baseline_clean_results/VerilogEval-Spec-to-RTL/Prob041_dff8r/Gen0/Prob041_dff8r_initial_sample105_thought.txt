To implement the TopModule, we will use a single module that contains 8 D flip-flops, each with an active high synchronous reset. The D flip-flops will be triggered by the positive edge of the clk signal. We will use the always block in Verilog to create a sensitivity list and check for the positive edge of the clock signal. The reset signal will be checked inside the always block to reset the D flip-flops when it is high.
