To implement an XNOR gate, we need to use the logical equality operator. 
The XNOR gate produces an output of 1 only when both inputs are the same, 
either both 0 or both 1. This can be achieved in Verilog using the 
equivalence operator (===) or by using the XOR operator (^) and inverting 
its output, as an XNOR gate is essentially the inverse of an XOR gate.
