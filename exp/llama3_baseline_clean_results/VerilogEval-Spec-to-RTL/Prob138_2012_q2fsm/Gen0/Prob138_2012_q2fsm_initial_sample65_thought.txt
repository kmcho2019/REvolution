To implement the state machine described, we first need to assign binary codes to each state. Since there are 6 states (A, B, C, D, E, F), we can use 3 bits to represent each state. 

Let's assign the following state codes:
- A: 000
- B: 001
- C: 002
- D: 003
- E: 004
- F: 005

We'll use two always blocks: one for the state flip-flops (to update the current state based on the next state) and another for the state table (to determine the next state based on the current state and input w). 

We'll use another always block or continuous assignment to describe the FSM output z, based on the current state.

Given the synchronous reset is active-high, we'll make sure to include the reset logic in our state flip-flops always block.
