The next state logic can be implemented using an always block that is sensitive to the positive edge of the clock and the reset signal. The current state and the input w are used to determine the next state.

For the state flip-flops, another always block will be used to update the current state based on the next state.

The output z can be determined by the current state. Based on the state machine diagram, we can see that z should be 1 when the state machine is in states E or F, and 0 otherwise.
