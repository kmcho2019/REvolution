To implement the Lemmings game using a Moore finite state machine, we can define two states: STATE_WALK_LEFT and STATE_WALK_RIGHT. We will use a 1-bit state variable to represent these states. The next state logic will be based on the current state and the input signals bump_left and bump_right. If the Lemming is bumped on either side, it will switch directions. The output logic will directly depend on the current state. We will use areset to asynchronously reset the state machine to STATE_WALK_LEFT.
