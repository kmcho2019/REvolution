To implement the Lemmings game as a finite state machine, we can define two states: WALK_LEFT and WALK_RIGHT. We will use an enumeration to represent these states. The state machine will transition between these two states based on the bump_left and bump_right inputs. If the Lemming is bumped on the left, it will switch to the WALK_RIGHT state. If it's bumped on the right, it will switch to the WALK_LEFT state. We will use a Moore state machine, where the output (walk_left and walk_right) is a function of the current state. The module will be implemented with a reset input (areset) that resets the state machine to the WALK_LEFT state.
