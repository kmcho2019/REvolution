To implement the Lemmings game module, we'll design a Moore state machine with two states: walking left and walking right. We'll use two bits to represent the current state (state_left and state_right). The next state logic will be implemented based on the current state and the bump_left and bump_right inputs. We'll use a positive edge triggered asynchronous reset to initialize the state machine to walking left. The output logic will be a simple assignment of the current state to the walk_left and walk_right outputs.
