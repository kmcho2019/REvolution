To implement the TopModule, we will design a Moore state machine with two states: walking left and walking right. The state machine will have two inputs: bump_left and bump_right. The current state will determine the output of the state machine, which is the direction the Lemming is walking. We will use a 2-state encoding to represent the states. The next state logic will be designed such that if the current state is walking left and bump_left is 1, the next state will be walking right, and if the current state is walking right and bump_right is 1, the next state will be walking left. If both bump_left and bump_right are 1, the next state will still switch directions. We will use areset to asynchronously reset the state machine to the walking left state.
