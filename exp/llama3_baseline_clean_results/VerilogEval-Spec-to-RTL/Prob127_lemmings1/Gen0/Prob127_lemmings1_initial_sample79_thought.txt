The module TopModule will implement a Moore state machine with two states: walking left (STATE_LEFT) and walking right (STATE_RIGHT). The state machine will have two inputs: bump_left and bump_right, which will determine the next state based on the current state. If the Lemming is walking left and bump_left is 1, it will switch to walking right, and if it's walking right and bump_right is 1, it will switch to walking left. If both bump_left and bump_right are 1, it will still switch directions. The areset input will asynchronously reset the state machine to walking left. We will use a 2-bit internal signal, state, to represent the current state of the Lemming.
