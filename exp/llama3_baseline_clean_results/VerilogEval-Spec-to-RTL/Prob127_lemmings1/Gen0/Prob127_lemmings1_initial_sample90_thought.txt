The TopModule should be implemented as a Moore state machine with two states: walking left and walking right. We can define two states, STATE_WALK_LEFT and STATE_WALK_RIGHT, and use a state variable to keep track of the current state. The state machine should transition to the opposite state when a bump is detected on either side. The walk_left and walk_right outputs should be driven by the current state of the state machine. The areset input should asynchronously reset the state machine to the STATE_WALK_LEFT state.
