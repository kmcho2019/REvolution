To implement the Lemmings game using a finite state machine in Verilog, we will define a Moore state machine with two states: walking left and walking right. We will use an enum to represent these states. The state machine will have two inputs, bump_left and bump_right, and one internal output that determines the direction of the Lemming. The state machine will transition from walking left to walking right when bumped on the left and from walking right to walking left when bumped on the right. We will also implement an asynchronous reset that resets the state machine to walking left when areset is high.
