To implement the Lemmings game using a Moore state machine, we first define the two states: walking left and walking right. We will use an enumeration to represent these states. The next state logic will be determined based on the current state and the input bump signals. If the Lemming is walking left and gets bumped on the left, it will switch to walking right, and vice versa. If it gets bumped on both sides, it will still switch directions. The output logic will directly depend on the current state. The module will also include an asynchronous reset that resets the Lemming to walking left.
