To implement the Lemmings game using a Moore state machine, we will define two states: LEFT and RIGHT. The machine will start in the LEFT state and switch to the RIGHT state when it receives a bump_left signal. Conversely, it will switch to the LEFT state when it receives a bump_right signal. If both bump_left and bump_right signals are received at the same time, the machine will still switch directions.

The state machine will have two inputs: bump_left and bump_right, and one output: direction (internal to the module). The direction output will determine the values of the walk_left and walk_right output ports.

We will use a case statement to define the next state logic, and a separate case statement to define the output logic.

In the output logic, when the current state is LEFT, walk_left will be 1 and walk_right will be 0. When the current state is RIGHT, walk_left will be 0 and walk_right will be 1.

We will also include a reset mechanism that resets the state machine to the LEFT state when the areset signal is 1.
