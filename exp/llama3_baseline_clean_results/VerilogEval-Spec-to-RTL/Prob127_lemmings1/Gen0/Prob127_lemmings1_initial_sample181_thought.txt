To implement the Lemmings game, we will design a Moore state machine with two states: walking left and walking right. The state machine will have two inputs, bump_left and bump_right, and two outputs, walk_left and walk_right. We will use a 1-bit internal signal, 'state', to represent the current state of the Lemmings, where 'state' = 0 represents walking left and 'state' = 1 represents walking right. The state machine will switch directions when it hits an obstacle, i.e., when bump_left or bump_right is 1. If both bump_left and bump_right are 1, the state machine will still switch directions. The areset signal will reset the state machine to the walking left state asynchronously.
