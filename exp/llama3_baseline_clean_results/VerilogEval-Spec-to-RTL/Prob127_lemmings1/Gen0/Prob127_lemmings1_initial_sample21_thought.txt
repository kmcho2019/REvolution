To implement the Lemmings game as a Moore state machine, we will define two states: WALK_LEFT and WALK_RIGHT. The machine starts in the WALK_LEFT state and transitions to the WALK_RIGHT state when it receives a bump on the left. It transitions back to the WALK_LEFT state when it receives a bump on the right. If it's bumped on both sides, it will still switch directions. We will use a parameterized enum to define the states and a always block to implement the state transition logic and output logic. We will also use an always block to handle the asynchronous reset.
