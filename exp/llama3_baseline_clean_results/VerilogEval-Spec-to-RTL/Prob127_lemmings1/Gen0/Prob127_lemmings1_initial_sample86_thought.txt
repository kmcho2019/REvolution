To implement the TopModule, we will use a finite state machine (FSM) with two states: walking left and walking right. We can use a 1-bit state variable to represent these two states. The next state logic will be based on the current state and the input signals bump_left and bump_right. If the Lemming is walking left and receives a bump_left, it will switch to walking right. Similarly, if it's walking right and receives a bump_right, it will switch to walking left. The output walk_left and walk_right will be generated based on the current state. We will use a Moore machine, so the outputs will be synchronous to the clock. The areset signal will be used to asynchronously reset the FSM to the walking left state.
