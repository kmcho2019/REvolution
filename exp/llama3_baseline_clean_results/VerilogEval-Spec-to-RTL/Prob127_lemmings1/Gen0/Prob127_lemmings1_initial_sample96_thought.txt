The TopModule will implement a simple Moore state machine with two states: walking left and walking right. The state machine has two inputs: bump_left and bump_right, which are used to determine the next state. The output of the state machine will be used to control the walk_left and walk_right outputs. The state machine will be implemented using a binary-encoded state variable. On the positive edge of the clock, the state machine will check the current state and inputs to determine the next state. If areset is high, the state machine will be reset to the walking left state regardless of the clock edge.
