The problem requires implementing a Moore finite state machine within the TopModule to model the behavior of Lemmings. The state machine should have two states: walking left and walking right. The next state and output should be determined based on the current state and the inputs bump_left and bump_right. If the Lemming is bumped on the left, it should switch to walking right, and if it's bumped on the right, it should switch to walking left. If it's bumped on both sides simultaneously, it should still switch directions. The module should also have an asynchronous reset to set the Lemming to walk left.
