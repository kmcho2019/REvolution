The design idea is to create a Moore state machine with two states: walking left and walking right. The state machine will have two inputs, bump_left and bump_right, and two outputs, walk_left and walk_right. The state machine will transition from one state to the other based on the bump inputs. If areset is asserted, the state machine will reset to the walking left state. The state machine will be implemented using a sequential logic circuit that uses the positive edge of the clock to trigger state transitions.
