To implement the Lemmings game using a finite state machine, we will design a Moore state machine with two states: walking left and walking right. We will use two inputs, bump_left and bump_right, to determine when the Lemming should switch directions. If either bump_left or bump_right is high, the Lemming will switch directions. We will use a reset signal, areset, to asynchronously reset the state machine to the walking left state. We will implement the state machine using a binary encoding, where 0 represents the walking left state and 1 represents the walking right state.
