To implement the Lemmings game using a finite state machine, we can define two states: walking left and walking right. We will use a Moore state machine with two inputs (bump_left and bump_right) and one output (direction) that models this behavior. The state machine will switch directions when it hits an obstacle (bump_left or bump_right is 1). If it's bumped on both sides at the same time, it will still switch directions. We will use a 1-bit signal to represent the current state (0 for walking left and 1 for walking right). The next state logic will be based on the current state and the input values. The module will also have an asynchronous reset input (areset) that resets the state machine to walking left.
