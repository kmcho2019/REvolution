To implement the Lemmings game logic using a finite state machine, we will create a Moore state machine with two states: walking left and walking right. The state machine will have two inputs (bump_left and bump_right) and an internal output that determines the current walking direction. When the Lemming is bumped on either side, it will switch directions. We will use a 2-bit state variable to represent the current state, where 0 represents walking left and 1 represents walking right. We will use a reset signal (areset) to asynchronously reset the state machine to the walking left state. The outputs (walk_left and walk_right) will be determined based on the current state.
