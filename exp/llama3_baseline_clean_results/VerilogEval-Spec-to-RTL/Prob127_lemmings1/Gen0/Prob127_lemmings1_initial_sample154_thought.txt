To solve this problem, we will implement a Moore state machine in the TopModule. The state machine will have two states: walking left and walking right. The inputs to the state machine will be bump_left and bump_right. The output of the state machine will be the direction the Lemming is walking. We will use a two-bit register to store the current state and a combinational logic block to determine the next state. When areset is high, the state machine will be reset to the walking left state. On every positive edge of the clock, the state machine will update its state based on the current state and the input values.
