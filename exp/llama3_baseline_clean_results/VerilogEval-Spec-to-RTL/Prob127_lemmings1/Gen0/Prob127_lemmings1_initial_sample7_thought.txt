To implement the Lemmings game logic as a finite state machine, we can define two states: WALK_LEFT and WALK_RIGHT. The initial state should be WALK_LEFT. We will use a Moore state machine, where the output depends only on the current state. The next state will be determined by the current state and the inputs (bump_left and bump_right). If the Lemming is walking left and bump_left is asserted, it will switch to walking right. If it's walking right and bump_right is asserted, it will switch to walking left. If both bump_left and bump_right are asserted, it will still switch directions. The areset signal will asynchronously reset the state machine to WALK_LEFT.
