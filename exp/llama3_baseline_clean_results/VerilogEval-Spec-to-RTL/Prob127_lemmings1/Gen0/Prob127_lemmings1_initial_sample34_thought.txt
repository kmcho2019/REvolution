To implement the Lemmings game, we will create a Moore state machine with two states: walking left and walking right. The state machine will have two inputs: bump_left and bump_right. Based on these inputs, the state machine will transition between the two states. If the Lemming is bumped on the left, it will transition to the walking right state. If it's bumped on the right, it will transition to the walking left state. If it's bumped on both sides, it will still switch directions. We will use areset as an asynchronous reset to reset the state machine to the walking left state.
