To implement the Lemmings game using a Moore state machine, we can define two states: WALK_LEFT and WALK_RIGHT. The state machine will start in the WALK_LEFT state. When the state machine is in the WALK_LEFT state, it will set walk_left to 1 and walk_right to 0. Conversely, when the state machine is in the WALK_RIGHT state, it will set walk_left to 0 and walk_right to 1. The state machine will transition from WALK_LEFT to WALK_RIGHT when it receives a bump_left signal, and from WALK_RIGHT to WALK_LEFT when it receives a bump_right signal. If both bump_left and bump_right are asserted at the same time, the state machine will still switch directions. The state machine will also have an asynchronous reset input, areset, which will reset the state machine to the WALK_LEFT state when asserted.
