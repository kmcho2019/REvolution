To implement the Lemmings game using a Moore state machine, we can define two states: WALK_LEFT and WALK_RIGHT. The machine will start in the WALK_LEFT state and switch to WALK_RIGHT when bumped on the left, and switch to WALK_LEFT when bumped on the right. We will use two variables to keep track of the current state and the next state. The next state will be determined based on the current state and the input signals bump_left and bump_right. The outputs walk_left and walk_right will be determined based on the current state.
