To implement the Lemmings game using a finite state machine, we will design a Moore state machine with two states: walking left and walking right. The state machine will have two inputs (bump_left and bump_right) and two outputs (walk_left and walk_right). The state machine will transition from one state to another based on the inputs and reset to the walking left state when areset is asserted. We will use a two-process design, one for the combinational logic and one for the sequential logic.
