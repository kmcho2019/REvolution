To implement the Lemmings game, we will design a Moore state machine with two states: walking left (state 0) and walking right (state 1). We will use two inputs, bump_left and bump_right, to determine when to switch states. The state machine will be reset to the walking left state when areset is asserted. We will use a two-bit internal signal, current_state, to store the current state of the machine and update it based on the current state and input values.
