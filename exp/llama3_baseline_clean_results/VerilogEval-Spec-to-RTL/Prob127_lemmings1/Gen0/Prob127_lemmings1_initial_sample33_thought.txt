To implement the Lemmings game using a finite state machine, we can define two states: walking left (STATE_LEFT) and walking right (STATE_RIGHT). The machine will switch between these two states based on the bump_left and bump_right inputs. We can use a Moore state machine, where the output (walking direction) is determined solely by the current state. The state machine will have two inputs (bump_left and bump_right) and one output (internal to the module). We will use a case statement to handle the state transitions based on the inputs. The areset input will be used to asynchronously reset the state machine to the STATE_LEFT state.
