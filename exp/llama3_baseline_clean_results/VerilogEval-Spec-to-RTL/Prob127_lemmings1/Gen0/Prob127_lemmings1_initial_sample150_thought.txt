To implement the Lemmings game using a finite state machine, we can define two states: walking left (LEFT) and walking right (RIGHT). We will use a Moore state machine, where the output is a function of the current state only. The state machine will have two inputs (bump_left and bump_right) and will switch states when either of these inputs is high. If both inputs are high at the same time, it will still switch states. The areset input will reset the machine to the LEFT state on a positive edge. We will use an always block to handle the combinational logic and another always block to handle the sequential logic.
