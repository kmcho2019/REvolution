To implement the TopModule with the specified interface, we can design a Moore state machine with two states: walking left and walking right. The machine will have two inputs: bump_left and bump_right. We can use a 1-bit state register to store the current state of the machine. On the positive edge of the clock, if bump_left or bump_right is high, the machine will switch its state. If both bump_left and bump_right are high, the machine will still switch its state. The output of the machine (walk_left and walk_right) will be determined by the current state. We will use areset to asynchronously reset the state machine to the walking left state.
