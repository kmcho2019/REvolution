To implement the Lemmings game using a finite state machine, we can define two states: WALK_LEFT and WALK_RIGHT. We will use a Moore state machine, where the output is a function of the current state only. The state machine will have two inputs: bump_left and bump_right. When the Lemming is in the WALK_LEFT state and receives a bump_left signal, it will switch to the WALK_RIGHT state. Similarly, when the Lemming is in the WALK_RIGHT state and receives a bump_right signal, it will switch to the WALK_LEFT state. If both bump_left and bump_right signals are received at the same time, the Lemming will still switch directions. The areset signal will asynchronously reset the state machine to the WALK_LEFT state.
