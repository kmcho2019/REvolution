The problem can be solved by designing a Moore state machine with two states (walking left and walking right) and two inputs (bump_left and bump_right). 
The state machine should have two states: 
- State 0: walking left
- State 1: walking right
The state machine should change its state based on the inputs: 
- If bump_left is 1, it should change to state 1 (walking right).
- If bump_right is 1, it should change to state 0 (walking left).
- If both bump_left and bump_right are 1, it should still change its state.
The walk_left and walk_right outputs can be directly derived from the current state.
An asynchronous reset (areset) should also be implemented to reset the state machine to the initial state (walking left) whenever it is asserted.
