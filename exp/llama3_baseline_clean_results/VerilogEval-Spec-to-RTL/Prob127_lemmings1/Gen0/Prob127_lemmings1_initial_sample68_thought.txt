To implement the Lemmings game using a Moore state machine, we can define two states: WALK_LEFT and WALK_RIGHT. The state machine will start in the WALK_LEFT state and transition to WALK_RIGHT when it receives a bump on the left (bump_left = 1) or when it is currently walking right and receives a bump on the right (bump_right = 1). We can use a two-bit internal signal 'state' to represent the current state, where state = 0 represents WALK_LEFT and state = 1 represents WALK_RIGHT. We will use a case statement to determine the next state based on the current state and the input signals (bump_left, bump_right).
