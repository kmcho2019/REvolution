To implement the Lemmings' finite state machine, we'll use a Moore state machine with two states: walking left and walking right. We can model these states using an enumeration (for clarity) and implement the state transition logic based on the input signals bump_left and bump_right. When areset is asserted high, the machine will asynchronously reset to the walk_left state. We'll use a 1-bit signal (state) to encode the current state of the machine and update this signal on the positive edge of the clock. The walk_left and walk_right outputs will be driven directly by the current state.
