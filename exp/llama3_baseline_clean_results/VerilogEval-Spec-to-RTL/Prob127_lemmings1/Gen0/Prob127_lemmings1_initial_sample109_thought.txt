We will use a Moore state machine, which means the output is a function of the current state only. The next state will be determined by the current state and the inputs (bump_left and bump_right). If the Lemming is bumped on either side, it will switch directions. We can use a case statement to handle the different possible input combinations. We will use a 2-bit signal, state, to represent the two states, and we will use a parameter to define the state values.
