The TopModule will be designed as a Moore state machine with two states: walking left (STATE_LEFT) and walking right (STATE_RIGHT). The machine will have two inputs: bump_left and bump_right. The outputs of the machine are walk_left and walk_right, which will be high when the Lemming is in the corresponding state. The state machine will switch states whenever it receives a bump on either side. If it's bumped on both sides at the same time, it will still switch directions. The state machine will be reset to STATE_LEFT when areset is high. The state machine will use a two-bit internal signal (current_state) to keep track of its current state, and will use a two-bit internal signal (next_state) to calculate its next state based on the current state and inputs.
