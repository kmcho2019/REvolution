To implement the Lemmings game using a finite state machine, we need to define the states and the transition logic between them. The two states are walking left (WALK_LEFT) and walking right (WALK_RIGHT). The transition logic is as follows:
- If the Lemming is walking left and it receives a bump on the left, it should switch to walking right.
- If the Lemming is walking left and it receives a bump on the right, it should switch to walking right.
- If the Lemming is walking right and it receives a bump on the left, it should switch to walking left.
- If the Lemming is walking right and it receives a bump on the right, it should switch to walking left.
- If both bump_left and bump_right are asserted, the Lemming should still switch directions.
The Moore state machine outputs (walk_left and walk_right) are a function of the current state.
