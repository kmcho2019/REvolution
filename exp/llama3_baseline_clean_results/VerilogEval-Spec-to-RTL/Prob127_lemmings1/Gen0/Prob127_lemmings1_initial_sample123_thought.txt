To implement the Lemmings game using a finite state machine, we will use a Moore state machine. The state machine will have two states: walking left and walking right. We will use two bits to represent the state: state[1] will not be used, and state[0] will be 0 for walking left and 1 for walking right.

We will use the bump_left and bump_right inputs to determine when to switch directions. If the Lemming is walking left and bump_left is 1, or if the Lemming is walking right and bump_right is 1, or if both bump_left and bump_right are 1, we will switch directions.

The module will have an internal output, next_state, that will be used to determine the next state of the state machine. The next_state will be assigned based on the current state and the bump_left and bump_right inputs.

The walk_left and walk_right outputs will be assigned based on the current state of the state machine. If the state is walking left, walk_left will be 1 and walk_right will be 0. If the state is walking right, walk_left will be 0 and walk_right will be 1.

The areset input will be used to asynchronously reset the state machine to the walking left state.
