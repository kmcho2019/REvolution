To implement the Lemmings game using a finite state machine, we can define two states: WALK_LEFT and WALK_RIGHT. The initial state will be WALK_LEFT. We will use a Moore state machine where the output is determined by the current state. The next state will be determined by the current state and the input (bump_left and bump_right). If the Lemming is walking left and it hits an obstacle on the left, it will switch to walking right. If it's walking right and it hits an obstacle on the right, it will switch to walking left. If it's hit on both sides, it will still switch directions. We will use a binary encoded state variable (1 bit) to represent the two states.
