To implement the Lemmings game, we need to design a finite state machine (FSM) that can model the two states: walking left and walking right. Since it's a Moore state machine, the outputs are a function of the current state only. We will use a 1-bit signal to represent the state, where 0 can represent walking left and 1 can represent walking right. The next state will be determined by the current state and the input signals (bump_left and bump_right). If the Lemming is bumped on either side, it will switch directions. We will use a simple conditional statement to determine the next state based on the current state and inputs. The areset signal will asynchronously reset the FSM to the initial state (walking left).
