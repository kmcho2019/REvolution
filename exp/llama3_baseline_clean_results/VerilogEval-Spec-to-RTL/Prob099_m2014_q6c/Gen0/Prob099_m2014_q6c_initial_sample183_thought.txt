To implement the next-state signals Y1 and Y3 corresponding to signals y[0] and y[2] are not required, 
we will focus on y[1] and y[3] for next state Y2 and Y4 respectively. 
Since one-hot encoding is used, only one bit of the state register is set to '1' at any given time.
The next-state signals can be derived by inspecting the state machine transitions.
Y2 will be '1' if the next state is B, D, or F (y[1] = 1), 
and Y4 will be '1' if the next state is D or E (y[3] = 1).
