Since Y1 corresponds to y[0], it will be '1' only when the next state is A. From the state machine, we can see that the next state will be A when the current state is D and w = 1.

Similarly, since Y3 corresponds to y[2], it will be '1' only when the next state is C. From the state machine, we can see that the next state will be C when the current state is B and w = 0, or when the current state is F and w = 0.

So, the logic equations for Y1 and Y3 are:
Y1 = y[3] & w
Y3 = (y[1] & ~w) | (y[5] & ~w)
