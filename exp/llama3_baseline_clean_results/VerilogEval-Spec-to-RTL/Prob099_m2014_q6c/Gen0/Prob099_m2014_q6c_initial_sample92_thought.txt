To implement the next-state signals Y1 and Y3, we need to analyze the state machine diagram. We can see that Y1 (corresponding to y[0]) will be 1 in the next state when the current state is B, C, or E and the input w is 0, or when the current state is F and the input w is 1. Similarly, Y3 (corresponding to y[2]) will be 1 in the next state when the current state is D or E. We will use the one-hot encoding to derive the logic equations by inspection.
