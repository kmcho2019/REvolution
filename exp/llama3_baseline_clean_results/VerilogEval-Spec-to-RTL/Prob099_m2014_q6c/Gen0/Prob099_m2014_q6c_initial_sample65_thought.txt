To implement the next-state signals Y1 and Y3 corresponding to signals y[0] and y[2] is not required. Instead, we are asked for y[1] and y[3]. So we need to derive the logic equations for Y2 and Y4. 
First, let's identify when the next state will have y[1] = 1 (state B) and y[3] = 1 (state D). 
The next state will be B (y[1] = 1) if we are in state A and w = 0. 
The next state will be D (y[3] = 1) if we are in states B, C, E, or F and w = 1. 
For state B (y[1]), we can write the equation as Y2 = y[0] & ~w. 
For state D (y[3]), we can write the equation as Y4 = (y[1] | y[2] | y[4] | y[5]) & w.
