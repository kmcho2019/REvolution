To implement a D latch using an always block in Verilog, we will use the sensitivity list to trigger the always block whenever the enable signal 'ena' or the data input 'd' changes. Inside the always block, we will use an if-else statement to check the state of 'ena'. If 'ena' is high, the output 'q' will be assigned the value of 'd'. If 'ena' is low, 'q' will retain its previous value, thus acting like a latch.
