To implement a D latch using an always block in Verilog, we need to consider the enable signal 'ena' and the input 'd'. The D latch captures the input 'd' when 'ena' is high and holds the value of 'd' at the output 'q' when 'ena' is low. This behavior can be implemented using an if statement inside an always block to check the value of 'ena' and update 'q' accordingly.
