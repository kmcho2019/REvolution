To implement a D latch, we need to capture the input value `d` and store it in the output `q` when the enable signal `ena` is high. This can be achieved using an always block in Verilog. We will check the value of `ena` and update `q` accordingly. If `ena` is high, we assign the value of `d` to `q`. If `ena` is low, the value of `q` remains unchanged.
