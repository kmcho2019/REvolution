To implement a D latch, we need to use an always block that is sensitive to the clock (in this case, the enable signal 'ena') and the input data 'd'. When 'ena' is high, the output 'q' should be assigned the value of 'd'. When 'ena' is low, the output 'q' should retain its previous value. This can be achieved using a non-blocking assignment to 'q' within the always block.
