To implement a D latch using an always block in Verilog, we will use a conditional statement to check the enable signal (ena). When ena is high, the output q should be assigned the value of the input d. When ena is low, the output q should retain its previous value. This behavior can be achieved by using a non-blocking assignment (=) inside the always block to update the output q when ena is high, and by doing nothing (i.e., not updating q) when ena is low, thus implicitly retaining the previous value of q.
