To implement a D latch, we can use an always block in Verilog that is sensitive to the enable signal 'ena' and the input 'd'. When 'ena' is high, the output 'q' should be assigned the value of 'd'. When 'ena' is low, the output 'q' should hold its previous value, which is the characteristic of a latch. This can be achieved by using a non-blocking assignment to 'q' within the always block.
