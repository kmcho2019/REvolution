To implement a D latch, we need to understand its behavior. A D latch captures the input `d` when `ena` is high and holds it until `ena` goes low. This means we need to use an `always` block to continuously check the state of `ena`. If `ena` is high, we assign the value of `d` to the output `q`. When `ena` goes low, `q` should retain its last value. In Verilog, we can achieve this by using a non-blocking assignment (`<=`) inside the `always` block, which is sensitive to the `d` and `ena` inputs.
