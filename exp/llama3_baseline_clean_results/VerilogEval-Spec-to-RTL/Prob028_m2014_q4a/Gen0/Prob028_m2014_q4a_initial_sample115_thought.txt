To implement a D latch using an always block in Verilog, we need to use the sensitivity list to monitor changes in the enable signal 'ena'. When 'ena' is high, the output 'q' should follow the input 'd', and when 'ena' is low, 'q' should hold its previous value. This behavior can be achieved using a non-blocking assignment inside the always block to update the output 'q' based on the current state of 'ena' and 'd'.
