To implement a D latch, we need to capture the input 'd' when the enable 'ena' is high and hold the captured value when 'ena' is low. This can be achieved using an always block that is sensitive to both 'd' and 'ena'. When 'ena' is high, we assign the value of 'd' to 'q', and when 'ena' is low, we don't change 'q', effectively holding its current value.
