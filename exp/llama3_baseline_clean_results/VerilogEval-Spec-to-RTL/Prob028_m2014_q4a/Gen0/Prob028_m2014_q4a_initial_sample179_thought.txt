To implement a D latch using an always block in Verilog, we can use the enable (ena) signal to control when the input (d) is stored in the latch. When ena is high (1), the output (q) should follow the input (d). When ena is low (0), the output (q) should hold its previous value. This behavior can be achieved by using a non-blocking assignment to q within the always block, which is sensitive to changes in both d and ena.
