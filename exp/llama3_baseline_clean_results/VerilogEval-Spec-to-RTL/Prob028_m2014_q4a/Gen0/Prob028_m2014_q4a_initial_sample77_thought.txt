To implement a D latch using an always block in Verilog, we need to capture the input 'd' when 'ena' is high and hold the value when 'ena' is low. This can be achieved by using an if statement inside the always block to check the 'ena' signal and then assign the value of 'd' to the output 'q' accordingly. When 'ena' is low, the value of 'q' should remain the same, effectively latching the previous value of 'd'.
