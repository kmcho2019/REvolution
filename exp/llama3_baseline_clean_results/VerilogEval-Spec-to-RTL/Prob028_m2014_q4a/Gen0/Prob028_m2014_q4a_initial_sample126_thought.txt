To implement a D latch using an always block in Verilog, we need to understand the basic functionality of a D latch. A D latch is a type of sequential logic circuit that captures the input signal (d) when the enable signal (ena) is high and holds the captured value when the enable signal goes low. We will use a non-blocking assignment to update the output (q) inside the always block, which will be sensitive to the enable signal (ena) and the clock edge (in this case, we are using level-sensitive enable).
