The D latch is a type of sequential logic circuit that captures the input value when the enable signal (ena) is high and holds the value when the enable signal is low. This behavior can be achieved using a simple if-else statement inside an always block, which is sensitive to changes in both the input (d) and the enable signal (ena). When ena is high, the output (q) should follow the input (d), and when ena is low, the output should hold its previous value.
