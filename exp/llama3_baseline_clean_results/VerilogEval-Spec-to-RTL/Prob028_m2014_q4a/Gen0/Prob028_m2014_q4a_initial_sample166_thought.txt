To implement a D latch using an always block in Verilog, we will use a single always block that is sensitive to changes in the 'ena' signal and the 'd' input. When 'ena' is high (1), the output 'q' should follow the 'd' input. When 'ena' is low (0), the output 'q' should remain at its current value, effectively "latching" the previous value of 'd'. This behavior is typical of a D latch, where the output is updated when the enable signal is active and retains its value when the enable signal is inactive.
