To implement a D latch, we need to capture the input data (d) when the enable signal (ena) is high and hold it when the enable signal is low. We can use an always block in Verilog to describe this behavior. The always block will be sensitive to the enable signal and the input data. When the enable signal is high, the output (q) will be assigned the value of the input data. When the enable signal is low, the output will hold its previous value.
