To implement a D latch using an always block in Verilog, we will use a sensitivity list that includes the enable signal (ena) and the data input (d). When the enable signal is high, the output (q) will be assigned the value of the data input (d). When the enable signal is low, the output will retain its previous value. This behavior is characteristic of a D latch, which captures the input data when enabled and holds it when disabled.
