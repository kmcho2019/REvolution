To implement a D latch using an always block in Verilog, we need to capture the input value 'd' when the enable signal 'ena' is high and hold the captured value when 'ena' goes low. This can be achieved by using a conditional statement inside the always block to check the value of 'ena' and update the output 'q' accordingly. If 'ena' is high, 'q' should be assigned the value of 'd'; otherwise, 'q' should retain its previous value.
