To implement a D latch, we need to design a module that captures the input data (d) when the enable signal (ena) is high. This can be achieved by using an always block in Verilog, which is sensitive to the enable signal and the input data. When the enable signal is high, the output (q) should be updated with the current value of the input data. If the enable signal is low, the output should retain its previous value, effectively "latching" the last captured data.
