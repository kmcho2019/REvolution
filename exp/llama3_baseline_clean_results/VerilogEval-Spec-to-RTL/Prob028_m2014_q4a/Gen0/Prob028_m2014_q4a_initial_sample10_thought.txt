To implement a D latch, we need to understand its behavior: when the enable signal (ena) is high, the output (q) follows the input (d), and when ena is low, q holds its previous value. This can be achieved using an always block in Verilog, which is sensitive to the changes in the enable signal and the input data. When ena is high, we assign the value of d to q inside the always block. If ena is low, the value of q does not change because we do not assign a new value to it, effectively making it hold its previous value.
