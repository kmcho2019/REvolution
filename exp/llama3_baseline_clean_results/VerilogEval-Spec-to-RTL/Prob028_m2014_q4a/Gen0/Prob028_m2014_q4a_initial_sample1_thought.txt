To implement a D latch, we need to capture the input 'd' when 'ena' is high and hold it when 'ena' is low. This can be achieved using an always block in Verilog. The always block will be sensitive to 'ena' and 'd'. When 'ena' is high, the output 'q' should be assigned the value of 'd'. When 'ena' is low, 'q' should retain its previous value.
