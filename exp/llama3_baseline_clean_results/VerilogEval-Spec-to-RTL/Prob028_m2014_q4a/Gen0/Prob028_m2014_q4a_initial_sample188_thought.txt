To implement a D latch, we need to remember that a D latch is a sequential logic circuit that captures the input (d) when the enable signal (ena) is high and holds the captured value when the enable signal is low. This behavior can be achieved using an always block in Verilog, where we update the output (q) with the input (d) whenever the enable signal (ena) is high. When the enable signal is low, the output (q) should retain its previous value.
