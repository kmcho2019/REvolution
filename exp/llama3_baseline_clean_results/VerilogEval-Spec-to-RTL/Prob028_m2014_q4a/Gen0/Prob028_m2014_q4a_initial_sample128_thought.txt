To implement a D latch using an always block in Verilog, we need to consider the behavior of a latch. A D latch captures the input value (d) when the enable signal (ena) is high and holds that value even after the enable signal goes low. This can be achieved by using an if statement inside the always block to check the value of ena. When ena is high, the output q should be assigned the value of d. When ena is low, the output q should retain its previous value.
