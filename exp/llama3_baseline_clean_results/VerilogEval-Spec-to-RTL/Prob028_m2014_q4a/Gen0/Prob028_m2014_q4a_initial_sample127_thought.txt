To implement a D latch using an always block in Verilog, we need to consider the functionality of a D latch. A D latch captures the input data (d) when the enable signal (ena) is high and holds the captured data even after the enable signal goes low. We can achieve this by checking the enable signal inside the always block and updating the output (q) only when the enable signal is high. If the enable signal is low, the output should remain the same.
