To implement a D latch using an always block in Verilog, we need to consider the functionality of a latch. A D latch is a type of flip-flop that captures its input (D) when the enable signal (ena) is high and holds that value when the enable signal is low. The output (q) will be the same as the input D when ena is high and will retain the last captured value when ena is low. We will use a non-blocking assignment (=) to update the output q inside the always block because we are dealing with sequential logic.
