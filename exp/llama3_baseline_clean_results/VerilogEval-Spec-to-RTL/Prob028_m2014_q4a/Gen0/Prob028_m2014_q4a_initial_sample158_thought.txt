To implement a D latch using an always block in Verilog, we need to understand the basic functionality of a D latch. A D latch captures the input data (d) when the enable signal (ena) is high and holds the captured data when the enable signal is low. This behavior can be implemented using an if-else statement within the always block that is sensitive to the enable signal and the clock (in this case, we assume the latch is level-sensitive and not edge-sensitive since no clock is provided).
