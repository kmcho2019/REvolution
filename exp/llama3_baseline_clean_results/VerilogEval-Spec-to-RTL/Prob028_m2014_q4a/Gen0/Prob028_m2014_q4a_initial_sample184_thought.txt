To implement a D latch, we need to store the value of the input 'd' when the enable signal 'ena' is high. We can achieve this using an always block that checks for the enable signal and updates the output 'q' accordingly. The always block will be sensitive to the 'ena' and 'd' signals. When 'ena' is high, 'q' will be assigned the value of 'd', and when 'ena' is low, 'q' will retain its previous value.
