To implement a D latch using an always block in Verilog, we need to check the enable signal (ena) and the input data (d). When ena is high, the output (q) should be the same as the input (d). When ena is low, the output (q) should retain its previous value. This behavior can be achieved by using a non-blocking assignment to q within an if statement inside an always block that is sensitive to changes in both d and ena.
