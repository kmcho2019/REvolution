To implement a D latch, we need to create a module that captures the input data (d) when the enable signal (ena) is high and holds that data even when the enable signal goes low. This can be achieved using an always block in Verilog. The always block will continuously monitor the enable signal. When the enable signal is high, it will update the output (q) with the input data. When the enable signal is low, it will keep the output (q) unchanged, effectively "latching" the previous value.
