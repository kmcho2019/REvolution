To implement a D latch using an always block in Verilog, we can utilize the sensitivity list to trigger the execution of the always block when either the input 'd' or the enable signal 'ena' changes. Inside the always block, we can use an if-else statement to control the output 'q' based on the value of 'ena'. If 'ena' is high, 'q' should be assigned the value of 'd'; otherwise, 'q' should retain its current value, thus acting as a latch.
