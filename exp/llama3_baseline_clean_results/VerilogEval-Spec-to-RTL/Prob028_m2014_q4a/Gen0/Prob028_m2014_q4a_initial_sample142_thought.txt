To implement a D latch, we need to use an always block to continuously monitor the enable signal 'ena'. When 'ena' is high, the output 'q' should follow the input 'd'. When 'ena' is low, the output 'q' should hold its previous value. This can be achieved by using a non-blocking assignment to update the value of 'q' when 'ena' is high and keeping the previous value when 'ena' is low.
