To implement a D latch using an always block in Verilog, we can use a sensitivity list to monitor the 'ena' signal. When 'ena' is high, the output 'q' should be assigned the value of 'd'. This is because in a D latch, the data at the 'd' input is stored in the latch when the enable signal 'ena' is asserted (high). When 'ena' is low, the output 'q' should retain its previous value, which is the behavior of a latch.
