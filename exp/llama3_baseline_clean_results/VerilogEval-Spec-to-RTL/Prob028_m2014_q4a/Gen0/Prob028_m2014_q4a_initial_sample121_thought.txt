To implement a D latch using an always block in Verilog, we can use a sensitivity list to trigger the always block whenever there is a change in the enable signal (ena) or the input data (d). Inside the always block, we can use an if statement to check if the enable signal is high. If it is, we assign the input data to the output (q). This way, the output will follow the input when the enable signal is high, and it will hold its previous value when the enable signal is low.
