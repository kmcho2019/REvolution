To implement a D latch, we need to understand its behavior: when the enable signal (ena) is high, the output (q) follows the input (d), and when the enable signal is low, the output retains its previous value. This can be achieved using an always block in Verilog, which executes the statements inside it whenever any of the signals in the sensitivity list change. For a D latch, the sensitivity list should include both the input (d) and the enable signal (ena). Inside the always block, we'll use an if statement to check the state of the enable signal. If it's high, we assign the input value to the output; otherwise, we keep the output unchanged.
