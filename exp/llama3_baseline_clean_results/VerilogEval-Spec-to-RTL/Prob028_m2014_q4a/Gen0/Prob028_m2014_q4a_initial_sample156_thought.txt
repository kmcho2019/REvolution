To implement a D latch, we need to capture the input data (d) when the enable signal (ena) is high, and hold the data when the enable signal is low. We can use an always block to describe this behavior. The always block will be sensitive to changes in both the input data (d) and the enable signal (ena). When ena is high, the output (q) will be assigned the value of d. When ena is low, the output (q) will retain its previous value.
