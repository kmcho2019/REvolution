To implement a D latch, we need to use an always block that is sensitive to the positive edge of the clock (ena) or to the ena signal itself. However, since we don't have a separate clock signal, we'll use the ena signal to control when the input (d) is latched to the output (q). When ena is high, the output q should follow the input d. When ena is low, the output q should retain its previous value, effectively latching the last value of d when ena was high.
