To implement a simple D flip flop with an active high synchronous reset, we need to create a module that takes in a clock signal (clk), data input (d), and a reset signal (r). When the reset signal is high and the clock signal is asserted (rising edge), the output (q) should be reset to 0. At the rising edge of the clock when the reset signal is low, the output should take the value of the data input. This behavior can be achieved using a simple if-else statement inside a always block that is sensitive to the positive edge of the clock signal.
