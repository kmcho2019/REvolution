To implement a simple D flip flop with active high synchronous reset, we will use a module that has a clock input (clk), a data input (d), a reset input (r), and a data output (q). The module will be sensitive to the positive edge of the clock signal. On every positive edge of the clock, the module will check the reset signal. If the reset signal is high, it will reset the output to 0. If the reset signal is low, it will load the data input into the output. This can be achieved using an always block in Verilog that is sensitive to the positive edge of the clock.
