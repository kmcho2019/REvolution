To implement a simple D flip flop with active high synchronous reset, we need to use the input 'd' as the data input and 'clk' as the clock input. The output 'q' should be updated with the value of 'd' on every rising edge of the clock 'clk' when the reset 'r' is low. If 'r' is high, the output 'q' should be reset to 0 on the rising edge of the clock. This can be achieved using a simple sequential logic description in Verilog.
