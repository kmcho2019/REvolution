To implement a D flip flop with active high synchronous reset, we will use a basic sequential logic approach. The D flip flop will have two main components: the data input (d) which is the value to be stored when the clock (clk) rises, and the reset (r) which when high will reset the output (q) to 0 regardless of the clock. This is achieved by using an if-else statement within an always block that is sensitive to the positive edge of the clock. If the reset (r) is high, the output (q) is set to 0. Otherwise, the output (q) is set to the input (d) when the clock rises.
