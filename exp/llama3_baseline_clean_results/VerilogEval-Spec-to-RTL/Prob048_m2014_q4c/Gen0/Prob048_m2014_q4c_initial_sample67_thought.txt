To implement a simple D flip flop with active high synchronous reset, we need to use a D flip flop's characteristic to store the input value on the rising edge of the clock signal when the reset signal is low. If the reset signal is high at the rising edge of the clock signal, the output should be reset to 0. This can be achieved using a always block in Verilog, which is sensitive to the clock signal and the reset signal. Inside the always block, we check for the rising edge of the clock signal and the state of the reset signal to determine the output.
