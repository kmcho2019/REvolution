To implement a D flip flop with active high synchronous reset, we need to consider the following: 
- On every positive edge of the clock (clk), the output (q) should be updated to the value of the input (d) if the reset signal (r) is low.
- If the reset signal (r) is high at the positive edge of the clock, the output (q) should be reset to 0 regardless of the input (d).
We will use a reg variable to hold the output value and an always block to describe the behavior at every positive edge of the clock.
