To implement a D flip flop with active high synchronous reset, we need to consider the following: 
1. The flip flop should capture the input 'd' on the rising edge of the clock 'clk'.
2. If the reset 'r' is high, the output 'q' should be reset to 0 regardless of the input 'd' or the clock 'clk'.
We can use the following approach:
- Use a reg to hold the state of the flip flop.
- Use a posedge clock to trigger the update of the state.
- Use an if statement to check the reset 'r'. If 'r' is high, reset the state to 0.
- Otherwise, update the state with the input 'd'.
- Use an always block to implement the sequential logic.
