To implement a D flip flop with active high synchronous reset, we will use the following approach:
- The module will have a reg variable to hold the state of the flip flop.
- The D flip flop will be designed such that on every rising edge of the clock, the state of the flip flop will be updated to the value of the input 'd' unless the reset signal 'r' is high, in which case the state will be reset to 0.
- The state of the flip flop will be assigned to the output 'q'.
- We will use a always block with a posedge sensitivity list to capture the rising edge of the clock.
- We will use a non-blocking assignment to update the state of the flip flop.
