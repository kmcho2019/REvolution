To implement a D flip-flop with active high synchronous reset, we can use a simple sequential logic circuit. The module should capture the input 'd' on every rising edge of the clock 'clk' and assign it to the output 'q', unless the reset signal 'r' is high, in which case the output 'q' should be reset to 0. We can achieve this using a combination of conditional statements and a non-blocking assignment in a Verilog always block.
