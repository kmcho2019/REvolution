To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic element. The D flip flop will have an input 'd' which will be assigned to the output 'q' on every rising edge of the clock 'clk', unless the reset 'r' is high, in which case the output 'q' should be reset to 0. This behavior can be implemented using a reg to store the output 'q' and a always block to handle the clock and reset conditions.
