To implement a simple D flip flop with active high synchronous reset, we will use a basic sequential logic element. The D flip flop will have a clock input (clk), a data input (d), a reset input (r), and a data output (q). When the reset input (r) is high and the clock rises, the output (q) will be reset to 0. Otherwise, on the rising edge of the clock, the output (q) will be set to the value of the data input (d).
