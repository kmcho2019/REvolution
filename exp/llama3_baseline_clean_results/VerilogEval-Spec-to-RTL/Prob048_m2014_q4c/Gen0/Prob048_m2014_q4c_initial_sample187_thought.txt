To implement a simple D flip flop with active high synchronous reset, we need to design a module that captures the input 'd' at the rising edge of the clock 'clk' and assigns it to the output 'q', unless the reset 'r' is high, in which case the output 'q' should be reset to 0. This behavior can be achieved using a simple if-else statement inside a clocked always block in Verilog.
