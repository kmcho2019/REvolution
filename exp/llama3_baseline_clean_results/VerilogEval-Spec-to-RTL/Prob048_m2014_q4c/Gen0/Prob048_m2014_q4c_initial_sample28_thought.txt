To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic design. The D flip flop will have an input 'd' which will be sampled on the rising edge of the clock 'clk' and assigned to the output 'q' if the reset 'r' is low. If the reset 'r' is high, the output 'q' will be reset to 0 on the next rising edge of the clock 'clk'. This behavior can be achieved using a reg variable to store the output value and an always block that is triggered on the rising edge of the clock 'clk'. Inside the always block, we first check if the reset 'r' is high, and if so, we reset the output 'q' to 0. Otherwise, we simply assign the input 'd' to the output 'q'.
