To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic approach. The D flip flop will store the input 'd' on every rising edge of the clock 'clk'. If the reset 'r' is high at the same time as the rising edge of 'clk', the output 'q' should be reset to 0, regardless of the input 'd'. Otherwise, 'q' should follow 'd' on every clock cycle when 'r' is low. This can be achieved using a Verilog always block that checks for the rising edge of the clock and implements the reset and data storage logic accordingly.
