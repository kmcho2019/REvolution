To implement a D flip flop with active high synchronous reset, we need to use a clocked always block in Verilog. Inside this block, we check if the reset signal 'r' is high. If it is, we reset the output 'q' to 0. If not, we assign the input 'd' to the output 'q' at the positive edge of the clock 'clk'. This way, the output 'q' will follow the input 'd' only when the reset 'r' is low, and will be reset to 0 when 'r' is high, all at the rising edge of 'clk'.
