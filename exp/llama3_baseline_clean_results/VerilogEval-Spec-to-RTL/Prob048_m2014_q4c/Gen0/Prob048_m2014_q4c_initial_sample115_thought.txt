To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic design. The D flip flop will store the input data 'd' on the rising edge of the clock 'clk'. If the reset 'r' is high at the same time as the clock rising edge, the output 'q' will be reset to 0. Otherwise, the output 'q' will take the value of 'd' from the previous clock cycle.
