To implement a D flip flop with active high synchronous reset, we can use a simple Verilog module with an always block that checks for the rising edge of the clock signal and updates the output accordingly. When the reset signal 'r' is high, the output 'q' should be reset to 0, regardless of the input 'd'. Otherwise, when the clock signal 'clk' rises and 'r' is low, 'q' should be updated with the value of 'd'.
