To implement a simple D flip flop with active high synchronous reset, we need to consider two main conditions: 
1) When the reset signal 'r' is high, the output 'q' should be reset to 0, regardless of the input 'd' or the clock 'clk'. 
2) When the reset signal 'r' is low, the D flip flop should capture the input 'd' on the rising edge of the clock 'clk' and assign it to the output 'q'.

This can be achieved by using an if-else statement within a always block that is sensitive to the positive edge of the clock and the reset signal.
