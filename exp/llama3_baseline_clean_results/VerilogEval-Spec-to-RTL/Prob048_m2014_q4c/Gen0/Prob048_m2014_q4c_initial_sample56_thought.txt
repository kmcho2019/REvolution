To implement a simple D flip flop with active high synchronous reset, we will use a always block that is sensitive to the positive edge of the clock signal. Inside the always block, we will first check if the reset signal is high. If it is, we will reset the output q to 0. If not, we will assign the input d to the output q. This way, when the reset signal is high, the output q will be reset to 0, regardless of the value of d.
