To implement a simple D flip flop with active high synchronous reset, we need to create a module that captures the input data 'd' on the rising edge of the clock 'clk' and assigns it to the output 'q', unless the reset 'r' is high. If 'r' is high at the rising edge of 'clk', the output 'q' should be reset to 0. This can be achieved using a single always block that is sensitive to the clock edge and reset.
