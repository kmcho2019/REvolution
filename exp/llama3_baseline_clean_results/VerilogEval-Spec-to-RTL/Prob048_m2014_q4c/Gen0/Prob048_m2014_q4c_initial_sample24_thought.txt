To implement a simple D flip flop with active high synchronous reset, we will use a basic sequential logic circuit. The D flip flop will capture the input value 'd' on the rising edge of the clock 'clk' and store it in the output 'q' unless the reset signal 'r' is high, in which case it will reset the output 'q' to 0 on the next rising edge of 'clk'. This means the reset is synchronous, meaning it only takes effect on clock edges, not immediately.
