To implement a D flip flop with synchronous reset, we need to use a sequential always block that is triggered by the positive edge of the clock signal. Inside this block, we first check if the reset signal is high. If it is, we set the output q to 0. Otherwise, we assign the value of the input d to q. This ensures that the reset takes priority over the input d when the reset signal is high, and when the reset signal is low, the D flip flop behaves normally, capturing the value of d at the positive edge of the clock signal.
