To implement a D flip flop with active high synchronous reset, we need to consider the following:
- The D flip flop should capture the input data (d) on the rising edge of the clock (clk) and store it in the output (q) until the next clock edge.
- When the reset (r) is high, the output (q) should be reset to 0, but only on the rising edge of the clock (clk), as this is a synchronous reset.
- When the reset (r) is low, the normal operation of the D flip flop should resume.

We can achieve this using a simple always block in Verilog, which will handle both the data capture and the reset functionality based on the clock edge.
