To implement a simple D flip flop with active high synchronous reset, we can use the following logic:
- On every rising edge of the clock, if the reset signal is low, the output q should be updated with the value of input d.
- If the reset signal is high, the output q should be reset to 0, regardless of the value of input d.
We will use a non-blocking assignment (<=) to update the output q, because this is a sequential logic circuit and we want to avoid race conditions.
