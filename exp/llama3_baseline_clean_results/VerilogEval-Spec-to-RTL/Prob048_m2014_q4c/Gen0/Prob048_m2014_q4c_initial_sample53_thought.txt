To implement a simple D flip flop with active high synchronous reset, we need to consider the following:
- On every rising edge of the clock signal (clk), the current input value (d) should be stored in the flip flop's output (q) if reset (r) is not asserted.
- When reset (r) is asserted and there's a rising edge of the clock (clk), the output (q) should be reset to 0 regardless of the input (d).
We can achieve this using an if-else statement inside an always block that is sensitive to the positive edge of the clock signal.
