To implement a simple D flip flop with active high synchronous reset, we need to use a clocked always block in Verilog. Inside this block, we will check if the reset signal 'r' is high. If it is, we will reset the output 'q' to 0. If the reset signal is not high, we will assign the input 'd' to the output 'q' at the positive edge of the clock 'clk'.
