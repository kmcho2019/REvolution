To implement a simple D flip flop with active high synchronous reset, we will use the following approach:
- On every rising edge of the clock, check if the reset signal 'r' is high.
- If 'r' is high, set the output 'q' to 0.
- If 'r' is low, assign the input 'd' to the output 'q'.
This behavior is consistent with the definition of a D flip flop with synchronous reset.
