To implement a simple D flip flop with active high synchronous reset, we need to consider the following conditions: 
- When the reset signal 'r' is high and the clock 'clk' rises, the output 'q' should be reset to 0.
- When the reset signal 'r' is low and the clock 'clk' rises, the output 'q' should be updated with the input 'd'.
We can achieve this by using a D flip flop with a reset input and a clock enable input.
