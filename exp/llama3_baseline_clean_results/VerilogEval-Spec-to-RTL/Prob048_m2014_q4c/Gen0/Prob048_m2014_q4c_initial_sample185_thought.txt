To implement a simple D flip flop with active high synchronous reset, we need to create a module that captures the input data (d) at the rising edge of the clock (clk) if the reset (r) is not high. If the reset (r) is high, the output (q) should be set to 0 regardless of the clock or data input. This behavior can be achieved using an if-else statement inside an always block that is sensitive to the clock edge.
