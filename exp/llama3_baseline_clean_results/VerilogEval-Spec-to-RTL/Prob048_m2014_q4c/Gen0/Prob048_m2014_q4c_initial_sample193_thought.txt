To implement a simple D flip flop with active high synchronous reset, we need to consider the following: 
- When the reset signal 'r' is high, the output 'q' should be immediately reset to 0, regardless of the current clock state.
- When 'r' is low, the D flip flop should work as expected: on the rising edge of the clock 'clk', the output 'q' should be updated to the value of the input 'd'.
This can be achieved using a single process in Verilog, which will handle both the reset condition and the clock edge condition.
