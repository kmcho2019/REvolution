To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic design. The D flip flop will have a clock input (clk), a data input (d), a reset input (r), and a data output (q). When the reset input is high and the clock is rising, the output q will be reset to 0. Otherwise, when the clock is rising, the output q will be updated to the value of the data input d.
