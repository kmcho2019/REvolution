To implement a simple D flip-flop with an active high synchronous reset, we need to use a clocked always block in Verilog. The D flip-flop should store the input 'd' when the clock 'clk' is high, and reset the output 'q' to 0 when the reset 'r' is high, both actions being synchronous with the clock. This means that the reset should only take effect on the rising edge of the clock when 'r' is high.
