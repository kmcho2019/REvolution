To implement a simple D flip flop with active high synchronous reset, we need to design a module that captures the input 'd' and transfers it to the output 'q' on the rising edge of the clock 'clk' and also resets the output 'q' to 0 when the reset 'r' is high. This can be achieved using a reg to store the output 'q' and always block to capture the input 'd' on the rising edge of 'clk' and apply the reset 'r'.
