To implement a simple D flip-flop with an active high synchronous reset, we will use a always block in Verilog that is sensitive to the positive edge of the clock signal. Inside this block, we will check for the reset condition. If the reset is high, we will set the output q to 0. Otherwise, we will assign the value of the input d to q. This ensures that the output q follows the input d on the rising edge of the clock unless the reset is asserted, in which case q is reset to 0 regardless of d.
