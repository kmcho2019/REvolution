To implement a D flip flop with active high synchronous reset in Verilog, we need to use the clk signal to trigger the flip flop on every rising edge. The input d will be sampled at each rising edge of the clk and its value will be assigned to the output q, unless the reset signal r is high, in which case the output q should be reset to 0. This behavior can be implemented using an always block that is sensitive to the clk and the reset signal.
