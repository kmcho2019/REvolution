To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic element in Verilog. The D flip flop captures the input 'd' on the rising edge of the clock 'clk' and assigns it to the output 'q'. If the reset 'r' is high at the same time as a rising edge of 'clk', the output 'q' should be reset to 0. We will use the 'always' block with the 'posedge' of 'clk' and 'r' as sensitivity list elements to achieve this functionality.
