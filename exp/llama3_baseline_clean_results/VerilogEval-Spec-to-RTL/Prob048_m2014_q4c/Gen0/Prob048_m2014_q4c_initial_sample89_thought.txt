To implement a simple D flip flop with active high synchronous reset, we will use a basic sequential logic approach. The D flip flop will have a clock input (clk), a data input (d), a reset input (r), and a output (q). On every positive edge of the clock, the flip flop will either latch the value of 'd' onto 'q' if 'r' is low or reset 'q' to 0 if 'r' is high.
