To implement a simple D flip flop with active high synchronous reset, we need to use a basic sequential logic element. The D flip flop will capture the input 'd' on the rising edge of the clock 'clk' and store it in the output 'q' unless the reset 'r' is high, in which case the output 'q' will be reset to 0. This behavior can be achieved using a reg variable to store the output 'q' and a procedural block to handle the clock and reset conditions.
