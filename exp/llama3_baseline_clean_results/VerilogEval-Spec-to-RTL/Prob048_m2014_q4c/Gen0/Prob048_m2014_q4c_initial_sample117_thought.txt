To implement a D flip flop with active high synchronous reset in Verilog, we will use a basic always block that is sensitive to the positive edge of the clock signal. Inside this always block, we will first check if the reset signal 'r' is high. If it is, we will set the output 'q' to 0, effectively resetting the flip flop. If 'r' is low, we will assign the input 'd' to 'q', thus implementing the basic functionality of a D flip flop.
