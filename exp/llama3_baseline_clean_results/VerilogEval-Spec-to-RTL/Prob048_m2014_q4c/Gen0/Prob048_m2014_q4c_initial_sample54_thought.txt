To implement a simple D flip flop with active high synchronous reset, we need to design a module that captures the input data 'd' on the rising edge of the clock 'clk' and sets the output 'q' to the captured data. The module should also have a reset input 'r' that resets the output 'q' to 0 on the rising edge of the clock when 'r' is high. This can be achieved using an always block in Verilog that checks for the rising edge of the clock and the state of the reset signal.
