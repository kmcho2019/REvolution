To implement a simple D flip flop with active high synchronous reset, we need to create a module that takes in a clock signal (clk), a data signal (d), and a reset signal (r). The module will have one output signal (q). The D flip flop will store the value of 'd' at the rising edge of 'clk' and output it on 'q'. If 'r' is high at the rising edge of 'clk', the output 'q' will be reset to 0.
