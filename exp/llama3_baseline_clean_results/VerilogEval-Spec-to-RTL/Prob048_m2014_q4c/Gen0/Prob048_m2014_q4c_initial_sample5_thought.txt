To implement a D flip flop with active high synchronous reset, we need to capture the input data (d) on the rising edge of the clock (clk) and reset the output (q) to 0 when the reset signal (r) is high. This can be achieved using a reg to store the output and an always block to describe the flip flop's behavior. The always block will be sensitive to the clock's rising edge and will check the reset condition. If reset is high, it will reset the output to 0; otherwise, it will capture the input data.
