To implement a simple D flip-flop with an active high synchronous reset, we need to create a module that captures the input data 'd' on the rising edge of the clock 'clk' and assigns it to the output 'q' unless the reset 'r' is high, in which case 'q' should be reset to 0. This behavior can be achieved using a single always block in Verilog, sensitive to the clock edge. Inside the block, we first check if the reset is high; if so, we assign 0 to 'q'. Otherwise, we assign the value of 'd' to 'q'.
