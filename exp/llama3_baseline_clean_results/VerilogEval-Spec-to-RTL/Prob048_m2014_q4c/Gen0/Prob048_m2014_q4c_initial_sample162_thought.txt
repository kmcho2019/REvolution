To implement a D flip flop with active high synchronous reset, we need to use a clocked always block in Verilog. The block should be sensitive to the positive edge of the clock signal (clk). Inside the block, we check if the reset signal (r) is high. If it is, we set the output (q) to 0. If the reset signal is low, we assign the value of the input (d) to the output (q) on the next clock cycle.
