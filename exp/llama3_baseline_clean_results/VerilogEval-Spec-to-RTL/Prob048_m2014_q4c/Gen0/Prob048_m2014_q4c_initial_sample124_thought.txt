To implement a D flip flop with active high synchronous reset, we can use a single always block that is sensitive to the positive edge of the clock. Inside the block, we first check if the reset is high. If it is, we reset the output q to 0. If the reset is not high, we assign the input d to the output q. This ensures that the flip flop captures the input d on the rising edge of the clock and resets to 0 when the reset is high.
