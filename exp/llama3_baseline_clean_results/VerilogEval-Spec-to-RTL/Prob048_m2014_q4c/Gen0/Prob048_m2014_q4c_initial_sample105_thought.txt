To implement a simple D flip flop with active high synchronous reset, we need to consider the clock signal, the data input, and the reset signal. The D flip flop should store the value of the data input 'd' on the rising edge of the clock signal 'clk' when the reset signal 'r' is low. If the reset signal 'r' is high, the output 'q' should be reset to 0 on the rising edge of the clock signal 'clk'. This can be achieved using a sequential always block in Verilog.
