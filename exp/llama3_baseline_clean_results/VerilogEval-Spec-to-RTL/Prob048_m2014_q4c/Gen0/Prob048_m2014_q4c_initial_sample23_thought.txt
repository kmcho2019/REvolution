To implement a simple D flip flop with active high synchronous reset, we need to create a module that takes in a clock signal (clk), a data input (d), a reset signal (r), and outputs the stored data (q). The module should update its output (q) on the rising edge of the clock signal (clk) if the reset signal (r) is not active high. If the reset signal (r) is active high, the module should reset its output (q) to 0 regardless of the data input (d) and clock signal (clk). This can be achieved using a reg variable to store the output (q) and an always block to update it based on the clock signal (clk) and reset signal (r).
