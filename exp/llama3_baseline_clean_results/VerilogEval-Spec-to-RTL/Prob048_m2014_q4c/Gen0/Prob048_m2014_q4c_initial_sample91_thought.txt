To implement a simple D flip flop with active high synchronous reset, we will use a basic sequential logic approach. The module will have a clock input (clk), a data input (d), a reset input (r), and a data output (q). The reset will be active high and synchronous, meaning it will reset the output (q) to 0 on the rising edge of the clock when the reset input (r) is high. When the reset input is low, the module will behave like a standard D flip flop, capturing the input data (d) on the rising edge of the clock and presenting it at the output (q).
