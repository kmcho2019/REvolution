To implement a simple D flip flop with active high synchronous reset, we need to create a module that captures the input 'd' on the rising edge of the clock 'clk' and assigns it to the output 'q'. If the reset 'r' is high at the same time the clock 'clk' is rising, the output 'q' should be reset to 0. This can be achieved using a reg to store the value of 'q' and an always block that is sensitive to the clock edge.
