To implement a simple D flip flop with active high synchronous reset, we need to use a reg variable to store the output value 'q'. We will then use a clocked always block to update the value of 'q' at every positive edge of the clock 'clk'. If the reset signal 'r' is high, 'q' will be reset to 0, otherwise 'q' will be assigned the value of the input 'd'.
