To implement a simple D flip-flop with active high synchronous reset, we can use a basic sequential logic circuit. The D flip-flop will store the value of input 'd' on every rising edge of the clock 'clk' when 'r' (reset) is not high. If 'r' is high during a rising edge of 'clk', the output 'q' will be reset to 0. This is achieved by using an if-else statement inside an always block that is sensitive to the positive edge of 'clk'.
