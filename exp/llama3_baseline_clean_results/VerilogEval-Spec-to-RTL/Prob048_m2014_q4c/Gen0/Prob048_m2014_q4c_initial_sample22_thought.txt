To implement a simple D flip flop with active high synchronous reset, we will use a reg variable to store the output q. On every positive edge of the clock, we will check if the reset signal r is high. If it is, we will reset q to 0. If it is not, we will assign the value of d to q. This ensures that the reset is synchronous, meaning it only occurs on the positive edge of the clock, and it is active high, meaning it is triggered by a high value of r.
