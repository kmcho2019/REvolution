To implement a simple D flip flop with active high synchronous reset, we can use the following approach: 
- When the reset signal (r) is high and the clock (clk) is rising, the output (q) should be reset to 0.
- When the reset signal (r) is low, the output (q) should be updated with the input (d) at the rising edge of the clock (clk).
We will use a reg variable to store the output, and an always block with a posedge clock condition to describe this behavior in Verilog.
