To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic design approach. The D flip flop will capture the input 'd' on the rising edge of the clock 'clk' and store it in the output 'q'. When the reset 'r' is high and the clock 'clk' rises, the output 'q' will be reset to 0. This can be achieved using a reg type to store the output value and an always block to handle the clock edge and reset conditions.
