To implement a simple D flip flop with active high synchronous reset, we can use a Verilog module that utilizes the always block to describe the sequential behavior. The D flip flop will have an input 'd' and an output 'q'. On the rising edge of the clock 'clk', the output 'q' will be assigned the value of 'd' unless the reset 'r' is high, in which case 'q' will be reset to 0. This reset operation will occur synchronously with the clock 'clk', meaning it will only take effect on the rising edge of the clock when 'r' is high.
