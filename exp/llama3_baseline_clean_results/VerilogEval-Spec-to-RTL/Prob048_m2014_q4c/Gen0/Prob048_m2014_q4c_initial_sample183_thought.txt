To implement a simple D flip flop with active high synchronous reset, we need to use a sequential always block that is sensitive to the positive edge of the clock signal. Inside the block, we check if the reset signal 'r' is high. If 'r' is high, the output 'q' should be reset to 0. If 'r' is low, we simply assign the input 'd' to the output 'q' on the next clock cycle.
