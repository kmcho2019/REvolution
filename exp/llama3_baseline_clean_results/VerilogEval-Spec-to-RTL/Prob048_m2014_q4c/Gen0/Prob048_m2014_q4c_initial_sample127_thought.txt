To implement a simple D flip flop with active high synchronous reset, we will use a Verilog module named TopModule. This module will have an input clock (clk), an input data bit (d), an input reset signal (r), and an output data bit (q). On every rising edge of the clock, if the reset signal is not asserted, the output q will take the value of the input data bit d. If the reset signal is asserted on a rising edge of the clock, the output q will be reset to 0. We will use a reg type to declare the output q and a posedge clock to trigger the assignment of d to q.
