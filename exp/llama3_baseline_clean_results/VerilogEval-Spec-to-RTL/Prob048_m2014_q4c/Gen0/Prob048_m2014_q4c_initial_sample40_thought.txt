To implement a simple D flip-flop with active high synchronous reset, we will use a basic sequential logic design. The D flip-flop will have an input 'd' which will be stored in the flip-flop on the rising edge of the clock 'clk'. The 'r' input will serve as the reset signal. When 'r' is high and there is a rising edge of 'clk', the output 'q' will be reset to 0. Otherwise, the output 'q' will follow the input 'd' on the rising edge of 'clk'. We can achieve this behavior using an always block in Verilog, which is sensitive to the clock and reset signals.
