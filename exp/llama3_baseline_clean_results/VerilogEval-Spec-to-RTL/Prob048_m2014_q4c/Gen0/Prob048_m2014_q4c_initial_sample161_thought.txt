To implement a D flip flop with active high synchronous reset in Verilog, we will use a simple always block that checks for the rising edge of the clock signal (clk). At each rising edge of clk, if the reset signal (r) is high, the output (q) should be reset to 0. If the reset signal is low, the output (q) should be updated with the current value of the input (d). This ensures that the reset operation is synchronous, meaning it only occurs at the clock edges, which helps in preventing metastability issues in the design.
