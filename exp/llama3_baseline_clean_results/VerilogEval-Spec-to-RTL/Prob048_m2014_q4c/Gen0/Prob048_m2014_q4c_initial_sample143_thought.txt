To implement a simple D flip flop with active high synchronous reset, we need to design a module that stores the input value 'd' in its internal state 'q' on every rising edge of the clock 'clk', unless the reset signal 'r' is high. When 'r' is high, the module should reset its output 'q' to 0, regardless of the value of 'd'. This behavior is achieved using an if-else statement inside an always block that is sensitive to the positive edge of the clock.
