To implement a D flip flop with active high synchronous reset, we will use a clocked always block in Verilog. This block will be triggered on the positive edge of the clock (clk). Inside the block, we will first check if the reset (r) is high. If it is, we will reset the output (q) to 0. If the reset is not high, we will assign the input (d) to the output (q). This ensures that the output is updated only on the positive edge of the clock and is reset to 0 when the reset is high.
