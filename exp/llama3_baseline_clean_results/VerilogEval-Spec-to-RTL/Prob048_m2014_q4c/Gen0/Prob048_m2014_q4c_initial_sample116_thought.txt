To implement a D flip flop with active high synchronous reset, we need to consider two main conditions: 
1) When the reset signal 'r' is high, the output 'q' should be reset to 0, regardless of the clock or input 'd'. 
2) When the reset signal 'r' is low, the output 'q' should be updated with the input 'd' on the rising edge of the clock 'clk'. 
This can be achieved by using a single always block that checks for the reset condition and the rising edge of the clock.
