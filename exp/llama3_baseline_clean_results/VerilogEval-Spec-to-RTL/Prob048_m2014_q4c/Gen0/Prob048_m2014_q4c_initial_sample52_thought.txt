To implement a simple D flip-flop with active high synchronous reset, we will use a basic sequential logic design. The D flip-flop will store the input 'd' on every rising edge of the clock 'clk' unless 'r' (reset) is high, in which case it will reset the output 'q' to 0. This is a classic example of a resettable D flip-flop, where the reset 'r' is synchronous, meaning it only affects the flip-flop on a clock edge.
