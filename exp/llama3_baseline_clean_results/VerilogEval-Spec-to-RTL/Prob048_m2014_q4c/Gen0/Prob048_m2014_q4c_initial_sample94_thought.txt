To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic approach. The module will have a clock input (clk), a data input (d), a reset input (r), and a data output (q). When the reset input (r) is high and the clock input (clk) is rising, the output (q) will be reset to 0. Otherwise, on the rising edge of the clock input (clk), the output (q) will be updated to the value of the data input (d).
