To implement a simple D flip flop with an active high synchronous reset, we can use a basic sequential logic approach. The D flip flop will have an input 'd' which represents the data to be stored, an input 'clk' which is the clock signal, and an input 'r' which is the reset signal. When 'r' is high and the clock rises, the output 'q' will reset to 0. Otherwise, when 'r' is low, on the rising edge of the clock, the output 'q' will take the value of the input 'd'. This functionality can be achieved using an always block in Verilog, sensitive to the positive edge of the clock and the reset signal.
