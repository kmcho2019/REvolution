To implement a simple D flip flop with active high synchronous reset, we need to create a module that captures the input data (d) on the rising edge of the clock (clk) and sets the output (q) to the captured value. However, if the reset (r) is high during the rising edge of the clock, the output (q) should be reset to 0, regardless of the input data. This can be achieved using a sequential logic block that checks for the clock edge and the reset condition.
