To implement a simple D flip flop with active high synchronous reset, we need to consider the following:
- The D flip flop should capture the input data 'd' on the rising edge of the clock 'clk'.
- The captured data should be output at 'q'.
- If the reset signal 'r' is high during a clock cycle, the output 'q' should be reset to 0 regardless of the input 'd'.

This can be achieved using a single process in Verilog that checks for the rising edge of the clock and the state of the reset signal.
