To implement a simple D flip flop with an active high synchronous reset, we can use a sequential always block in Verilog. This block will be sensitive to the positive edge of the clock (clk) and will check for the reset condition. If the reset (r) is high, it will assign 0 to the output (q), otherwise, it will assign the value of the input (d) to the output (q). This behavior captures the functionality of a D flip flop with synchronous reset.
