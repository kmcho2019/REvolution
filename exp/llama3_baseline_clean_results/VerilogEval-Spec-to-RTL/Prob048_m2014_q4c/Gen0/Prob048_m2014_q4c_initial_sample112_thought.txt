To implement a simple D flip flop with active high synchronous reset, we need to consider the clock signal (clk) as the primary control for updating the output. The input data (d) should be captured at the positive edge of the clock. When the reset signal (r) is high at the positive edge of the clock, the output (q) should be reset to 0. We can achieve this by using a reg variable to hold the output value and an always block to handle the clock and reset conditions.
