To implement a simple D flip flop with active high synchronous reset, we need to create a module that captures the input data (d) on the rising edge of the clock (clk) and resets the output (q) to 0 when the reset signal (r) is high. This can be achieved using a simple if-else statement inside an always block that is sensitive to the positive edge of the clock. If the reset signal is high, the output is reset to 0; otherwise, the output is assigned the value of the input data.
