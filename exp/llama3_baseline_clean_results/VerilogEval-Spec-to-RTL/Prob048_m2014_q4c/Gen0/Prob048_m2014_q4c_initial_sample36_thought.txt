To implement a D flip flop with active high synchronous reset, we need to use the clk signal as the clock, d as the input data, r as the active high reset, and q as the output. We can use the always block in Verilog to describe the sequential behavior of the flip flop. When the reset signal is high and the clock signal rises, the output q should be reset to 0. Otherwise, when the clock signal rises, the output q should be set to the current value of d.
