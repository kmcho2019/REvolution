To implement a simple D flip flop with active high synchronous reset, we can use the following logic:
- When the reset signal 'r' is high, the output 'q' should be set to 0, regardless of the clock or input 'd'.
- When the reset signal 'r' is low, the output 'q' should be updated on the rising edge of the clock 'clk' with the value of the input 'd'.
This can be achieved using a simple if-else statement in the always block, with the sensitivity list including the clock and reset signals.
