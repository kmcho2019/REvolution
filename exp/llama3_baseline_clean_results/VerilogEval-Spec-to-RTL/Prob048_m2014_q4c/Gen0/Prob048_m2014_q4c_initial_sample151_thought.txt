To implement a simple D flip flop with active high synchronous reset, we can use a Verilog module with the specified interface. The D flip flop will store the value of the input 'd' on the rising edge of the clock 'clk' and reset its output 'q' to 0 when the reset input 'r' is high. This can be achieved using a reg variable to store the output and an always block to describe the flip flop's behavior.
