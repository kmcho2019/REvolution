To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic circuit. The D flip flop will have a data input (d), a clock input (clk), a reset input (r), and a data output (q). When the reset input is high and the clock is rising, the output q will be reset to 0. Otherwise, on the rising edge of the clock, the output q will be set to the current value of the input d.
