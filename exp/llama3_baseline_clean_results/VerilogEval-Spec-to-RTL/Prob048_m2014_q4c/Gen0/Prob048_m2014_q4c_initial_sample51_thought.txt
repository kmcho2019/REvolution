To implement a simple D flip flop with active high synchronous reset, we need to consider the following:
- On every rising edge of the clock (clk), the output (q) should be updated with the current input (d).
- If the reset signal (r) is high at the rising edge of the clock, the output (q) should be reset to 0, regardless of the input (d).
We will use a Verilog always block with a sensitivity to the clock edge to capture this behavior, ensuring that the output (q) is updated synchronously.
