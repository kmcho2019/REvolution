To implement a simple D flip-flop with an active high synchronous reset, we can use a basic sequential logic design. The D flip-flop should capture the input data (d) on the rising edge of the clock (clk) and set the output (q) to this value. Additionally, if the reset (r) is high at the same time as the rising edge of the clock, the output (q) should be reset to 0 regardless of the input data. This behavior can be achieved using a Verilog always block that is sensitive to the clock edge and the reset condition.
