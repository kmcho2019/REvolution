To implement a simple D flip-flop with active high synchronous reset, we will use a basic sequential logic circuit. The D flip-flop will store the value of the input 'd' on the rising edge of the clock 'clk' if the reset 'r' is low. If the reset 'r' is high, the output 'q' will be reset to 0 on the rising edge of the clock, regardless of the value of 'd'. This will be achieved using a single always block in Verilog.
