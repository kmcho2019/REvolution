To implement a D flip flop with active high synchronous reset, we need to use a sequential logic element that can store a bit of information. In Verilog, this can be achieved using a reg data type. We will use a reg to store the output q, and update its value based on the input d and the reset signal r at every positive edge of the clock signal clk. If the reset signal r is high, the output q will be set to 0. Otherwise, the output q will be updated with the value of the input d.
