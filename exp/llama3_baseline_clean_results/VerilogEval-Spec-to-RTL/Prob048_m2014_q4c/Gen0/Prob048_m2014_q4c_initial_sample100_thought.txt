To implement a simple D flip flop with active high synchronous reset, we can use a Verilog module with a clocked always block. The always block should be sensitive to the positive edge of the clock signal (clk) and should check for the reset signal (r). If the reset signal is high, the output (q) should be reset to 0. If the reset signal is low, the output should be updated with the input (d) on the positive edge of the clock signal.
