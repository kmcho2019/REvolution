To implement a D flip flop with active high synchronous reset, we need to use a sequential always block in Verilog that is sensitive to the clock (clk) edge. We will also include a conditional statement to check for the reset (r) signal. When the reset is high, the output (q) should be set to 0, regardless of the input (d). Otherwise, on the rising edge of the clock, the output (q) should be updated with the current value of the input (d).
