To implement the finite-state machine, we can break down the functionality into several states: 
- IDLE: Waiting for the start sequence (1101) to be detected.
- SHIFT: Shifting in the 4 additional bits to determine the duration.
- COUNT: Waiting for the counters to finish counting.
- DONE: Notifying the user that the timer has timed out.
- RESET: Resetting the state machine to its initial state.

We will use a Moore machine, where the output depends solely on the current state. 
The state machine will transition between these states based on the input signals and the current state.
