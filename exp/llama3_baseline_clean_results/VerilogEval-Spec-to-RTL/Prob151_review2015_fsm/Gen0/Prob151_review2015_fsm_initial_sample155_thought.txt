The finite-state machine can be designed with the following states:
- IDLE: The initial state where the machine searches for the start pattern (1101).
- SHIFT: After detecting the start pattern, the machine shifts in 4 more bits to determine the duration.
- COUNTING: The machine waits for the counters to finish counting.
- DONE: The machine notifies the user that the timer has timed out and waits for acknowledgment.

The state transitions are as follows:
- IDLE -> SHIFT: When the start pattern (1101) is detected.
- SHIFT -> COUNTING: After 4 clock cycles of shifting.
- COUNTING -> DONE: When the counters finish counting (done_counting is high).
- DONE -> IDLE: When the user acknowledges the timer (ack is high) and the reset is not asserted.

We will use a counter to keep track of the number of clock cycles in the SHIFT state.
