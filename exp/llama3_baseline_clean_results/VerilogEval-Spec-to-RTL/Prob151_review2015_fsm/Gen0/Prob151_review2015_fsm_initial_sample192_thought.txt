To implement the finite-state machine that controls the timer, we will use a Moore machine with the following states:
- IDLE: Search for the start pattern (1101)
- SHIFT: Shift in 4 more bits after the start pattern is detected
- COUNT: Wait for the counters to finish counting
- DONE: Notify the user and wait for acknowledgement

We will use a 2-bit state variable to represent these 4 states. 
In the IDLE state, we check for the start pattern (1101) on the data input.
Once the start pattern is detected, we transition to the SHIFT state and assert shift_ena for 4 clock cycles.
After the SHIFT state, we transition to the COUNT state and assert counting.
In the COUNT state, we wait for done_counting to be high.
Once done_counting is high, we transition to the DONE state and assert done.
In the DONE state, we wait for ack to be high, then transition back to the IDLE state.
A synchronous reset is used to reset the state machine to the IDLE state.
