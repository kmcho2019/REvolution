To implement the finite-state machine that controls the timer, we can use a 5-state state machine: 
- IDLE: waiting for the start sequence (1101)
- SHIFT: shifting in the 4 bits for the duration
- COUNT: waiting for the counters to finish counting
- DONE: notifying the user that the timer has timed out
- ACK: waiting for the user to acknowledge the timer

We will use a counter to keep track of the number of bits shifted in the SHIFT state. 
The state machine will transition between these states based on the current state, inputs (data, done_counting, ack, reset), and the counter value.
