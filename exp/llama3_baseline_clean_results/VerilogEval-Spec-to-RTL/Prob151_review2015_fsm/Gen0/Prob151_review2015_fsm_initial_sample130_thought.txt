To implement the finite-state machine that controls the timer, we will define a series of states that correspond to the different stages of the timer's operation. These states will be:
- IDLE: The initial state where the FSM searches for the pattern 1101.
- SHIFT: After detecting the pattern, the FSM shifts in 4 more bits.
- COUNT: The FSM waits for the counters to finish counting.
- DONE: The FSM notifies the user and waits for acknowledgement.

We will use a counter to keep track of the number of clock cycles during the SHIFT state. The state transitions will be based on the current state, the input values, and the counter value.
