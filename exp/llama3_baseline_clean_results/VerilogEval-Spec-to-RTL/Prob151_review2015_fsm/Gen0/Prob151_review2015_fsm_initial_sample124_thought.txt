To implement the finite-state machine that controls the timer, we can define several states to represent the different stages of operation. The states can be:
- IDLE: Initial state where the state machine searches for the pattern 1101.
- SHIFT: State where the state machine shifts in 4 more bits to determine the duration to delay.
- COUNT: State where the state machine waits for the counters to finish counting.
- DONE: State where the state machine notifies the user and waits for the user to acknowledge the timer.
We can use a 3-bit state variable to represent these 5 states (one of the states will be the initial idle state and the shift state will be divided into 4 sub-states), and implement the state transitions based on the input signals and the current state.
