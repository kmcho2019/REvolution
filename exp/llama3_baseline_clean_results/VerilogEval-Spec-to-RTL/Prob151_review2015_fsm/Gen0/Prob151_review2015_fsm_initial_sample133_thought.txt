The problem can be solved by implementing a finite-state machine (FSM) with the following states:
- IDLE: The initial state where the FSM waits for the pattern 1101.
- SHIFT: After detecting the pattern, the FSM shifts in 4 more bits to determine the duration.
- COUNTING: The FSM waits for the counters to finish counting.
- DONE: The FSM notifies the user that the timer has timed out and waits for acknowledgment.
The FSM transitions between these states based on the input signals and internal counters.
