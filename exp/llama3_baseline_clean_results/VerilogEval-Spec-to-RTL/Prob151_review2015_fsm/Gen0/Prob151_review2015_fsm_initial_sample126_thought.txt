To implement the finite-state machine that controls the timer, we will design a state machine with several states to handle the different stages of the timer operation. The states will be:
- IDLE: The initial state where the state machine searches for the pattern 1101.
- SHIFT: After detecting the pattern, the state machine will shift in 4 more bits.
- COUNT: After shifting the 4 bits, the state machine will wait for the counters to finish counting.
- DONE: After the counters finish counting, the state machine will notify the user and wait for the user's acknowledgement.
We will use a counter to keep track of the number of bits shifted in the SHIFT state.

The state machine will transition from one state to another based on the current state and the inputs. The outputs will be generated based on the current state.

The state machine will be implemented using a parameterized enum for the states and a case statement to handle the transitions between states.
