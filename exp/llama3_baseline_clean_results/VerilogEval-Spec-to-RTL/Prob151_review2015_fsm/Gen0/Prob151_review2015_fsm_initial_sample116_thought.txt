To implement the finite-state machine that controls the timer, we need to identify the different states the machine can be in and the transitions between these states based on the given conditions. The states can be identified as follows:
- IDLE: The initial state where the machine starts looking for the pattern 1101.
- SHIFT: After detecting the pattern, the machine shifts in 4 more bits.
- COUNTING: The machine waits for the counters to finish counting.
- DONE: The machine notifies the user and waits for acknowledgement.

The transitions between these states are as follows:
- From IDLE to SHIFT when the pattern 1101 is detected.
- From SHIFT to COUNTING after 4 clock cycles of asserting shift_ena.
- From COUNTING to DONE when done_counting is high.
- From DONE to IDLE when ack is high.

We will use a parameterized enum to define the states and a case statement to handle the state transitions.
