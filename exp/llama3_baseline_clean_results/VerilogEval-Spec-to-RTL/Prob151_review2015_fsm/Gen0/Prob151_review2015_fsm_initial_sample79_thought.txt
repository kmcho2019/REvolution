To implement the finite-state machine that controls the timer, we will define several states to represent the different stages of the timer's operation. 

1. **IDLE**: This is the initial state where the FSM waits for the pattern 1101 to be detected on the data input.
2. **PATTERN_DETECTED**: Once the pattern 1101 is detected, the FSM moves to this state and asserts shift_ena for 4 clock cycles to shift in the duration bits.
3. **SHIFTING**: In this state, the FSM is shifting in the duration bits.
4. **COUNTING**: After shifting, the FSM moves to this state and asserts counting until the counters finish counting (done_counting goes high).
5. **DONE**: Once the counters are done, the FSM asserts done to notify the user and waits for the acknowledgement (ack) from the user.

We will use a counter to keep track of the number of clock cycles during the shifting phase.
