To implement the finite-state machine that controls the timer, we will define a set of states that correspond to the different steps in the timer's operation. The states will be: IDLE (waiting for the start pattern), SHIFT (shifting in the duration), COUNT (waiting for the counters to finish), and DONE (notifying the user and waiting for acknowledgement). We will use a 2-bit state variable to represent these four states. The state machine will transition between these states based on the current state and the input signals. The output signals (shift_ena, counting, and done) will be driven by the current state and the input signals. We will use a counter to keep track of the number of clock cycles during the SHIFT state.
