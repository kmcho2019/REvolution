The TopModule can be designed using a finite-state machine (FSM) with five states: IDLE, WAIT_SHIFT, SHIFT, COUNT, and DONE. 
The IDLE state searches for the pattern 1101 on the input data. 
When the pattern is detected, the state machine moves to the WAIT_SHIFT state, where it asserts shift_ena for exactly 4 clock cycles. 
Then, it transitions to the COUNT state, where it asserts counting and waits for done_counting to be high. 
After that, it moves to the DONE state, where it asserts done and waits for ack to be high before returning to the IDLE state.
