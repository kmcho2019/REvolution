The finite-state machine (FSM) will have several states to control the timer: 
- Idle: initial state, looking for the pattern 1101
- Shift: after detecting the pattern, shifting in 4 more bits
- Count: waiting for the counters to finish counting
- Done: waiting for the user to acknowledge the timer
The FSM will transition between these states based on the input signals and its current state.
To detect the pattern, we can use a simple serial pattern detector that checks the incoming bits one by one.
The state machine will also keep track of the number of bits shifted so far.
