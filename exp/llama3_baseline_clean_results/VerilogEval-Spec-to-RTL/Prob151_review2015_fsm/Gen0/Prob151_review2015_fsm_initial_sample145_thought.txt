The design involves implementing a finite-state machine (FSM) that controls the timer. The FSM has several states: 
- Idle: searching for the pattern 1101, 
- Shift: shifting in 4 more bits after detecting the pattern, 
- Count: waiting for the counters to finish counting, 
- Done: notifying the user that the timer has timed out, and 
- Ack: waiting for the user to acknowledge the timer.

We will use a state variable to keep track of the current state. In each state, we will check for the conditions to move to the next state. 
We will also assert the outputs (shift_ena, counting, done) based on the current state.
