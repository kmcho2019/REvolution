The state machine can be designed with five main states: 
- IDLE: searching for the pattern 1101
- SHIFT: shifting in the 4-bit duration after the pattern is detected
- COUNT: waiting for the counters to finish counting
- DONE: notifying the user that the timer has timed out
- ACK: waiting for the user's acknowledgement

We will use a counter to count the number of bits shifted in during the SHIFT state. 
The state machine will transition from one state to the next based on the current state and the input values.
