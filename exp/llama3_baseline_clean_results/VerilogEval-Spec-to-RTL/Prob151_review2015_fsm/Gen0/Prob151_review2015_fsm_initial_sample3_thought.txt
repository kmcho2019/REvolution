The finite-state machine can be designed with the following states:
- IDLE: The initial state where the FSM looks for the pattern 1101.
- SHIFT: The state where the FSM shifts in 4 more bits to determine the duration to delay.
- COUNT: The state where the FSM waits for the counters to finish counting.
- DONE: The state where the FSM notifies the user and waits for the acknowledgement.

The FSM will transition between these states based on the current state, input data, and control signals (done_counting and ack). 
We will use a 4-bit shift register to store the incoming data to detect the pattern 1101. 
The FSM will assert shift_ena for exactly 4 clock cycles in the SHIFT state to shift in the duration bits.
The counting output will be asserted in the COUNT state to indicate that the FSM is waiting for the counters to finish.
The done output will be asserted in the DONE state to notify the user that the timer has timed out.
The FSM will wait for the ack signal to be high before transitioning back to the IDLE state.
