To implement the finite-state machine that controls the timer, we need to define a set of states and their corresponding transitions. The states are: 
1. IDLE - searching for the pattern 1101
2. SHIFT - shifting in 4 more bits to determine the duration
3. COUNT - waiting for the counters to finish counting
4. DONE - notifying the user and waiting for the acknowledgment
We use a finite-state machine to control the flow between these states. The state transitions are triggered by the detection of the pattern, the completion of shifting, the finish of counting, and the acknowledgment from the user.
