The finite-state machine can be designed with five states: IDLE, DETECT, SHIFT, COUNT, and DONE. 
- The IDLE state is the initial state where the machine waits for the pattern 1101 to be detected.
- The DETECT state is used to detect the pattern 1101. Once the pattern is detected, the machine moves to the SHIFT state.
- In the SHIFT state, the machine asserts shift_ena for exactly 4 clock cycles to shift in the duration bits.
- The COUNT state is used to wait for the counters to finish counting. The machine asserts counting in this state.
- The DONE state is used to notify the user that the timer has timed out. The machine asserts done in this state and waits for the ack input to be high before moving back to the IDLE state.
