To implement the finite-state machine for the timer, we will use a Moore machine with six states: IDLE, DETECT_PATTERN1, DETECT_PATTERN2, DETECT_PATTERN3, DETECT_PATTERN4, SHIFT, COUNT, DONE. The IDLE state is the initial state and the machine transitions to DETECT_PATTERN1 when a '1' is detected on the data input. The machine continues to DETECT_PATTERN2, DETECT_PATTERN3, and DETECT_PATTERN4 to detect the pattern 1101. After detecting the pattern, the machine enters the SHIFT state and asserts shift_ena for 4 clock cycles to shift in the duration. Then it enters the COUNT state, asserting counting and waiting for done_counting. After done_counting is asserted, the machine enters the DONE state, asserting done and waiting for ack. Once ack is asserted, the machine resets to the IDLE state.
