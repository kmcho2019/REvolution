The state machine can be implemented with a finite state machine (FSM) that goes through several states: IDLE (searching for the pattern), SHIFT (shifting in the duration), COUNT (waiting for the counters to finish), DONE (notifying the user), and ACK (waiting for the user's acknowledgement). We will use an enumeration to define these states and a register to keep track of the current state. We will also use a counter to count the number of shifts.

In the IDLE state, we check for the pattern (1101) and move to the SHIFT state when it is detected. In the SHIFT state, we assert shift_ena and count the number of shifts. After 4 shifts, we move to the COUNT state. In the COUNT state, we assert counting and wait until done_counting is high. Then, we move to the DONE state. In the DONE state, we assert done and wait until ack is high. Finally, we move to the IDLE state.

We will also implement a synchronous reset that resets the state machine to the IDLE state when the reset signal is high.
