The finite-state machine (FSM) can be designed with six states: 
- idle: the initial state where it looks for the start sequence (1101) 
- shift1, shift2, shift3, shift4: states to shift in the 4 bits after the start sequence is detected
- count: the state where it waits for the counters to finish counting
- done: the state where it notifies the user the timer has timed out and waits for acknowledgement

The FSM will use a combination of the current state, the input data, done_counting, and ack to determine the next state and the output values.
