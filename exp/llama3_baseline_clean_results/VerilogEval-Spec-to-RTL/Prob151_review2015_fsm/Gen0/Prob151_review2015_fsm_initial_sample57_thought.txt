To implement the finite-state machine (FSM) that controls the timer, we can break down the problem into several states: 
- Idle: Search for the pattern 1101.
- Shift: Shift in 4 more bits to determine the duration to delay.
- Count: Wait for the counters to finish counting.
- Done: Notify the user and wait for the user to acknowledge the timer.
We can use a 4-state FSM to implement these states. The FSM transitions between states based on the current state and the inputs. 
We can use a register to store the current state and another register to store the bits of the pattern and the duration.
