To implement the finite-state machine that controls the timer, we can define a state machine with the following states:
- IDLE: The initial state where the machine waits for the pattern 1101.
- SHIFT: The state where the machine shifts in 4 more bits to determine the duration to delay.
- COUNT: The state where the machine waits for the counters to finish counting.
- DONE: The state where the machine notifies the user that the timer has timed out and waits for the user to acknowledge.
We will use a 4-bit shift register to store the input pattern and a counter to keep track of the number of shifts. The state machine will transition between these states based on the input pattern, the counter, and the done_counting and ack signals.
