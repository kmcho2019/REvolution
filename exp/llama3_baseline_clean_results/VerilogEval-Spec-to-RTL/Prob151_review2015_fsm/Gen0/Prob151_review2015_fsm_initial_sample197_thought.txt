To implement the finite-state machine (FSM) that controls the timer, we will design a Moore machine with the following states: 
- IDLE: The initial state where the FSM looks for the pattern 1101.
- SHIFT: After the pattern is detected, the FSM shifts in 4 more bits to determine the duration to delay.
- COUNT: The FSM waits for the counters to finish counting.
- DONE: The FSM notifies the user and waits for the user to acknowledge the timer.
We will use a 4-bit shift register to store the input data. The FSM will transition between these states based on the current state, input data, and control signals.
