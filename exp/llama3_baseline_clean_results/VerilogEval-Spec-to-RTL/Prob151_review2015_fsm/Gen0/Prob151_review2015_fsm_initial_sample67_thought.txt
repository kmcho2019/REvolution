To implement the finite-state machine (FSM) for the timer, we need to consider the following states:
- Idle: Initial state where the FSM waits for the start pattern (1101).
- Shift: After detecting the pattern, the FSM shifts in 4 more bits to determine the duration.
- Counting: FSM waits for the counters to finish counting.
- Done: After the counters finish, the FSM notifies the user and waits for an acknowledgment.
We will use a 4-state FSM with the mentioned states. The FSM transitions between states based on the current state and the inputs (data, done_counting, ack, reset).

State transitions:
- Idle -> Shift: when the pattern 1101 is detected.
- Shift -> Shift: for 4 clock cycles after pattern detection.
- Shift -> Counting: after 4 clock cycles of shifting.
- Counting -> Done: when done_counting is high.
- Done -> Idle: when ack is high.
