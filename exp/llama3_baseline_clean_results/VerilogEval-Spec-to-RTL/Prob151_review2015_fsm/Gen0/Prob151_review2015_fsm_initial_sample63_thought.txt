To implement the finite-state machine that controls the timer, we can define a state machine with five states:
- IDLE: waiting for the start pattern (1101) to be detected
- SHIFT: shifting in 4 more bits to determine the duration to delay
- COUNT: waiting for the counters to finish counting
- DONE: notifying the user that the timer has timed out
- ACK: waiting for the user to acknowledge the timer
The state machine will transition between these states based on the input signals and the current state.
