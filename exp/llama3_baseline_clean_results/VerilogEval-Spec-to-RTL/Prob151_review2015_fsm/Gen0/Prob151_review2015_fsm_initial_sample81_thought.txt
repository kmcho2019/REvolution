The finite state machine (FSM) can be designed with five states: IDLE, SHIFT, COUNT, DONE, and ACK. 
- In the IDLE state, the FSM waits for the pattern 1101 to be detected on the data input. 
- Once the pattern is detected, the FSM transitions to the SHIFT state and asserts shift_ena for exactly 4 clock cycles to shift in the duration bits. 
- After shifting the duration bits, the FSM transitions to the COUNT state and asserts counting to indicate that it is waiting for the counters to finish counting. 
- When the counters finish counting (done_counting is high), the FSM transitions to the DONE state and asserts done to notify the user that the timer has timed out. 
- The FSM stays in the DONE state until the user acknowledges the timer by setting ack to high, at which point it transitions to the ACK state and then back to the IDLE state.
