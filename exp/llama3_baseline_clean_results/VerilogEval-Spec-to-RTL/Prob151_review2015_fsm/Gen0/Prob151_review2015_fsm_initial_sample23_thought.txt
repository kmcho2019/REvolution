To implement the finite-state machine (FSM) for the timer controller, we can define several states that correspond to the different stages of the timer's operation. These states are: 
1. IDLE - the initial state where the FSM is searching for the start pattern (1101).
2. SHIFT - after detecting the start pattern, the FSM shifts in 4 more bits to determine the duration.
3. COUNT - the FSM waits for the counters to finish counting.
4. DONE - the FSM notifies the user that the timer has timed out and waits for acknowledgement.
We will use a counter to keep track of the number of clock cycles during the SHIFT state.
