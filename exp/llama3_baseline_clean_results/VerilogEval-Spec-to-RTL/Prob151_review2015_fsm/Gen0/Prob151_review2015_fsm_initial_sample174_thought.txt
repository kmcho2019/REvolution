To implement the finite-state machine that controls the timer, we will design a module with several states:
- IDLE: The initial state where the FSM waits for the pattern 1101 to be detected on the data input pin.
- SHIFT: After detecting the pattern, the FSM shifts in 4 more bits to determine the duration to delay.
- COUNT: The FSM waits for the counters to finish counting.
- DONE: The FSM notifies the user and waits for the user to acknowledge the timer.

We will use a parameterized enum to define the states and implement the state transitions based on the input signals.
