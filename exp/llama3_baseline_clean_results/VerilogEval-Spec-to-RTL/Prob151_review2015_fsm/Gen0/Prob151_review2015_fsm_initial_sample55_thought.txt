To solve this problem, I will design a finite-state machine (FSM) with the following states:
- IDLE: The initial state where the FSM looks for the pattern 1101.
- SHIFT: The state where the FSM asserts shift_ena to shift in 4 more bits to determine the duration.
- COUNT: The state where the FSM asserts counting to indicate it is waiting for the counters.
- DONE: The state where the FSM asserts done to notify the user the timer has timed out.
- ACK: The state where the FSM waits for the user to acknowledge the timer.

The FSM will transition between these states based on the input signals and the current state. I will use a counter to keep track of the number of clock cycles in the SHIFT state.

The FSM will be implemented using a case statement to handle the different states and transitions.
