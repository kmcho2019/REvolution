To implement the finite-state machine that controls the timer, we will design a Moore machine with the following states:
- IDLE: Initial state, looking for the pattern (1101) on the input data.
- SHIFT1, SHIFT2, SHIFT3, SHIFT4: States where the machine shifts in 4 more bits to determine the duration to delay after detecting the pattern (1101).
- COUNT: State where the machine waits for the counters to finish counting.
- DONE: State where the machine notifies the user that the timer has timed out and waits for acknowledgement.

We will use a 4-bit shift register to detect the pattern (1101) and a 2-bit counter to keep track of the number of bits shifted.
