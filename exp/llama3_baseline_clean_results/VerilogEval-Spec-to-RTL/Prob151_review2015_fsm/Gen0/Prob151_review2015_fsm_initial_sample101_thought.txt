To implement the finite-state machine for the timer, we will use a Moore machine, where the outputs are dependent on the current state only. The states we will have are: IDLE (searching for the pattern), SHIFT (shifting in the duration), COUNTING (waiting for the counters to finish), DONE (notifying the user and waiting for acknowledgement), and RESET (resetting the machine). We will use a counter to keep track of the number of bits shifted in during the SHIFT state. The state machine will transition from one state to another based on the input signals and the current state.
