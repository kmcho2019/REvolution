To implement the finite-state machine that controls the timer, we will use a Mealy machine with states for each of the conditions described in the problem. The states are as follows: 
- IDLE: This is the starting state, where the machine waits for the input sequence 1101.
- SHIFT: In this state, the machine asserts the shift_ena output and shifts in 4 more bits.
- COUNT: The machine asserts the counting output and waits for the counters to finish counting.
- WAIT_FOR_ACK: The machine asserts the done output and waits for the user to acknowledge.
We will use a 2-bit or 3-bit state register to keep track of the current state. We will then use combinational logic to generate the next state and outputs based on the current state and inputs.
