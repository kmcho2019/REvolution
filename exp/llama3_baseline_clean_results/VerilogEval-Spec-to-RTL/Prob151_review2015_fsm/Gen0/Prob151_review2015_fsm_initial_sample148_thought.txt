To implement the finite-state machine that controls the timer, we can use a Moore machine or a Mealy machine. Here, we will use a Moore machine where the output is a function of the current state only. The states can be defined as follows:
- IDLE: Waiting for the pattern 1101 to start the timer.
- SHIFT: Shifting in the duration bits.
- COUNTING: Waiting for the counters to finish counting.
- DONE: Notifying the user that the timer has timed out and waiting for acknowledgement.
We will use a 4-bit register to store the current state of the pattern detection and a counter to keep track of the number of bits shifted.
