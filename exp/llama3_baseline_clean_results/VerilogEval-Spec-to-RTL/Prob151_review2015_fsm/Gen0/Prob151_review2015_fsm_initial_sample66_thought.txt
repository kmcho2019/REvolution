The finite-state machine (FSM) for the timer will have the following states:
- IDLE: The initial state, where the FSM waits for the pattern 1101 to be detected.
- SHIFT: After the pattern is detected, the FSM asserts shift_ena for 4 clock cycles to shift in the duration bits.
- COUNT: After the duration bits are shifted in, the FSM asserts counting and waits for the counters to finish counting.
- DONE: After the counters finish counting, the FSM asserts done to notify the user and waits for the acknowledgement (ack) before resetting to IDLE.

The state transitions will be based on the input signals and the current state.
