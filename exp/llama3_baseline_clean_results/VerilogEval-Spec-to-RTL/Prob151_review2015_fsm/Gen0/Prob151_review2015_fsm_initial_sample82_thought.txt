To implement the finite-state machine that controls the timer, we need to design a state machine with several states: IDLE (searching for the pattern 1101), SHIFT (shifting in 4 more bits to determine the duration), COUNT (waiting for the counters to finish counting), and DONE (notifying the user and waiting for the user to acknowledge the timer). The state machine will transition between these states based on the input signals and internal counters. We will use a 4-state machine to implement this functionality.
