To implement the finite-state machine (FSM) that controls the timer, we can define several states:
- IDLE: The initial state where the FSM is searching for the pattern 1101.
- DETECTED: The state where the pattern 1101 is detected, and the FSM is shifting in 4 more bits.
- SHIFTING: The state where the FSM is shifting in the 4 bits.
- COUNTING: The state where the FSM is waiting for the counters to finish counting.
- DONE: The state where the timer has timed out and the FSM is notifying the user.
- ACK_WAIT: The state where the FSM is waiting for the user to acknowledge the timer.

The FSM will transition between these states based on the inputs and the current state. We will use a counter to keep track of the number of clock cycles during the SHIFTING state.
