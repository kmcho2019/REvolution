To implement the finite-state machine that controls the timer, we will define five states: 
1. IDLE: Initial state where the machine is searching for the pattern 1101.
2. SHIFT: State where the machine is shifting in 4 more bits to determine the duration to delay.
3. COUNT: State where the machine is waiting for the counters to finish counting.
4. DONE: State where the machine notifies the user that the timer has timed out and waits for the user to acknowledge.
5. RESET: Not a state, but we will use the reset input to transition back to the IDLE state from any state.

We will use a variable to keep track of the current state and another variable to keep track of the number of bits shifted. 
We will also have a variable to keep track of the pattern received so far.
