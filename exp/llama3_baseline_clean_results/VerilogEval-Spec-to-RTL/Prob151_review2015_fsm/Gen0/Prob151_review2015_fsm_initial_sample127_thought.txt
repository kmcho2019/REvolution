To implement the finite-state machine that controls the timer, we can define several states:
- IDLE: Searching for the pattern 1101
- SHIFT: Shifting in 4 more bits after pattern detection
- COUNT: Waiting for counters to finish counting
- DONE: Notifying the user of timer timeout and waiting for acknowledgement
We will use a counter to keep track of the number of bits shifted in during the SHIFT state.
The state machine will transition between these states based on the current state and input conditions.
