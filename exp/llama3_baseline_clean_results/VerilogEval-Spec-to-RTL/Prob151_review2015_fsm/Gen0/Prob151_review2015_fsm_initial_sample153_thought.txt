To implement the finite-state machine (FSM) that controls the timer, we can define a state machine with several states: 
- Idle: searching for the pattern 1101
- Shift: shifting in 4 more bits to determine the duration
- Counting: waiting for the counters to finish counting
- Done: notifying the user and waiting for acknowledgement

We will use a parameterized enum to define these states and a variable of type state to keep track of the current state.

The FSM will transition from one state to another based on certain conditions. 
- From Idle to Shift: when the pattern 1101 is detected
- From Shift to Counting: after 4 clock cycles of asserting shift_ena
- From Counting to Done: when done_counting is high
- From Done to Idle: when ack is high

We will use a counter to keep track of the number of clock cycles in the Shift state.
