The TopModule can be implemented as a finite-state machine (FSM) with several states:
- IDLE: initial state where the FSM is searching for the start pattern (1101)
- SHIFT: state where the FSM shifts in 4 more bits after detecting the start pattern
- COUNTING: state where the FSM waits for the counters to finish counting
- DONE: state where the FSM notifies the user and waits for the user's acknowledgement
The FSM will transition between these states based on the input signals and its current state.

To implement this, we will use a state register to store the current state of the FSM and a next_state logic to determine the next state based on the current state and the input signals.
We will also use a counter to keep track of the number of clock cycles the FSM has been in the SHIFT state.
