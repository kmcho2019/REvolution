To implement the finite-state machine that controls the timer, we need to design a state machine with multiple states to handle the different stages of the timer operation. 

The states can be defined as follows:
- IDLE: The initial state where the state machine searches for the start sequence (1101).
- SHIFT: The state where the state machine shifts in 4 more bits to determine the duration to delay.
- COUNTING: The state where the state machine waits for the counters to finish counting.
- DONE: The state where the state machine notifies the user and waits for the user to acknowledge the timer.

We will use a Mealy machine (the output depends on both the current state and the input) to implement the state machine. The next state will be determined by the current state and the inputs.

We will use a 2-bit or 3-bit or 4-bit state encoding depending on the number of states. In this case, we have 4 states, so we will use a 2-bit state encoding.
