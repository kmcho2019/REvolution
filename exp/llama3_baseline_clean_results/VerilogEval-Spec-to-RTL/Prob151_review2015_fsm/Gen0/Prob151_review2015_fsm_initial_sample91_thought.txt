To implement the finite-state machine for the timer, we can break down the functionality into several states. 
1. An initial state (IDLE) where the machine searches for the pattern (1101).
2. After detecting the pattern, it enters a state (SHIFT) where it shifts in 4 more bits.
3. Following the shift operation, it enters a state (COUNT) where it waits for the counters to finish counting.
4. Once counting is done, it enters a state (DONE) where it notifies the user and waits for acknowledgment.

The state machine transitions between these states based on the input signals (data, done_counting, ack) and the internal state of the machine. 
The shift_ena signal is asserted for exactly 4 clock cycles after detecting the pattern, and the counting signal is asserted while waiting for the counters to finish. 
The done signal is asserted after counting is done and remains asserted until the user acknowledges it.

We will use a simple, non-encoded state machine for clarity and ease of understanding.
