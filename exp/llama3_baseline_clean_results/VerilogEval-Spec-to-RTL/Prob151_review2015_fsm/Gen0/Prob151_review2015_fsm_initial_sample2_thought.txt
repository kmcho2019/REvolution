To implement the finite-state machine that controls the timer, we can use a state machine with several states: IDLE (waiting for the pattern 1101), SHIFT (shifting in 4 more bits to determine the duration), COUNT (waiting for the counters to finish counting), and DONE (notifying the user and waiting for acknowledgement).
