The finite-state machine can be designed with five states: 
IDLE, 
START_SEQ1, 
START_SEQ2, 
START_SEQ3, 
SHIFT, 
COUNT, 
DONE. 
In the IDLE state, the machine waits for the pattern 1101. 
Once the pattern is detected, it enters the SHIFT state and asserts shift_ena for 4 clock cycles to shift in the duration bits. 
After that, it enters the COUNT state, asserts counting, and waits for the done_counting signal. 
When done_counting is high, it enters the DONE state, asserts done, and waits for the ack signal. 
Upon receiving ack, it returns to the IDLE state. 
The reset signal will always set the state to IDLE, where it starts searching for the pattern 1101.
