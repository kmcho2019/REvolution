To solve this problem, we will design a finite-state machine with the following states:
- IDLE: Initial state where the machine searches for the start pattern (1101).
- SHIFT: State where the machine shifts in 4 more bits to determine the duration.
- COUNT: State where the machine waits for the counters to finish counting.
- DONE: State where the machine notifies the user that the timer has timed out and waits for acknowledgement.

The state machine will transition between these states based on the input signals and will use a counter to keep track of the number of clock cycles in the SHIFT state.
