The finite-state machine will be designed with the following states:
- IDLE: The initial state, waiting for the pattern 1101.
- SHIFT: After detecting the pattern, shift in 4 more bits.
- COUNT: Wait for the counters to finish counting.
- DONE: Notify the user and wait for acknowledgement.

The state machine will use a 4-state FSM to implement the above states.
The state transitions will be controlled by the input data, done_counting, and ack signals.
The output signals shift_ena, counting, and done will be asserted based on the current state.
The state machine will be reset to the IDLE state when the reset signal is high.
