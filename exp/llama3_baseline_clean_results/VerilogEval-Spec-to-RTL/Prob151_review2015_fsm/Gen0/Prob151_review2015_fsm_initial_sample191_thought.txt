To implement the finite-state machine that controls the timer, we will define a series of states that correspond to the different stages of the timer's operation. 

1. Idle state: The state machine starts in this state, searching for the pattern 1101.
2. Shift state: After detecting the pattern, the state machine shifts in 4 more bits to determine the duration to delay.
3. Counting state: The state machine then waits for the counters to finish counting.
4. Done state: Once the counters are done, the state machine notifies the user and waits for an acknowledgment.

We will use a state register to keep track of the current state and a counter to count the number of clock cycles in the Shift state.

The next state logic will be based on the current state and the input signals (data, done_counting, ack, and reset).
