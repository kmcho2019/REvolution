To implement the finite-state machine (FSM) for controlling the timer, we can define states for each step of the process: searching for the pattern, shifting in the duration, counting, and notifying the user. We'll use a Mealy machine approach, where the outputs are a function of both the current state and the inputs. The states can be defined as follows:
- S_IDLE: The initial state, where the FSM searches for the pattern 1101.
- S_SHIFT: After detecting the pattern, the FSM shifts in 4 more bits to determine the duration.
- S_COUNT: The FSM waits for the counters to finish counting.
- S_DONE: The FSM notifies the user and waits for acknowledgement.
We'll use a counter to keep track of the number of bits shifted during the S_SHIFT state.
