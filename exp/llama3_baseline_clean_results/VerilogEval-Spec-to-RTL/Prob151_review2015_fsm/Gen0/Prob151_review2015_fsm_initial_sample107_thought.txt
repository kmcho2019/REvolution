To implement the finite-state machine that controls the timer, we will define a set of states that correspond to each step of the timer's operation. We will use a state machine with the following states:
- IDLE: initial state, searching for the pattern 1101
- SHIFT: shift in 4 bits after pattern detection
- COUNT: wait for counters to finish counting
- DONE: notify the user and wait for acknowledgement
We will use a counter to keep track of the number of bits shifted in during the SHIFT state.
The next state logic will be determined based on the current state and the input signals.
The output signals (shift_ena, counting, done) will be asserted or deasserted based on the current state.
