To implement the finite-state machine that controls the timer, we need to define the different states it can be in and the transitions between these states based on the input conditions. The states can be: 
- IDLE: Looking for the pattern 1101 on the data input.
- SHIFT: After the pattern 1101 is detected, shift in 4 more bits to determine the duration.
- COUNTING: Wait for the counters to finish counting.
- DONE: Notify the user that the timer has timed out and wait for acknowledgment.
We can use a 4-state or more state machine (depending on how we implement the SHIFF state, either as a single state that lasts 4 cycles or as four distinct states) to keep track of the current state and control the outputs accordingly.
We will use a single SHIFF state that counts the number of shifts, simplifying the design.
The state machine transitions as follows:
- From IDLE to SHIFT when the pattern 1101 is detected.
- From SHIFT to COUNTING after 4 shifts.
- From COUNTING to DONE when done_counting is high.
- From DONE to IDLE when ack is high.
