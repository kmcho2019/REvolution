To implement the finite-state machine that controls the timer, we can use a Moore machine with six states: 
1. IDLE - searching for the pattern 1101
2. SHIFT1 - after receiving the first bit of the pattern (1)
3. SHIFT2 - after receiving the first two bits of the pattern (11)
4. SHIFT3 - after receiving the first three bits of the pattern (110)
5. SHIFT4 - after receiving the pattern (1101), start shifting in 4 more bits
6. COUNT - waiting for the counters to finish counting
7. DONE - waiting for the user to acknowledge the timer

The state transitions will be based on the current state and the input values. We will also use a counter to keep track of the number of bits shifted after the pattern is detected.

We will also define a separate counter to count the number of bits that have been shifted.
