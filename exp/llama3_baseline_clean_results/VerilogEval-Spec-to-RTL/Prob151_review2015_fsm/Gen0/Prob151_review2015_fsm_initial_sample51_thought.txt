To implement the finite-state machine that controls the timer, we will define a series of states that correspond to each step of the timer's operation. The states can be:
- IDLE: Looking for the pattern 1101 in the input data.
- SHIFT: Shifting in the next 4 bits to determine the duration.
- COUNT: Waiting for the counters to finish counting.
- DONE: Notifying the user and waiting for acknowledgement.

The state machine will transition between these states based on the current state, input values (data, done_counting, ack), and the reset signal. We'll use a counter to keep track of the number of clock cycles in the SHIFT state.
