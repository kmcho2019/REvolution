The finite-state machine (FSM) can be implemented with five states: 
IDLE, DETECT_PATTERN, SHIFT_IN_DURATION, WAIT_FOR_COUNTING, and WAIT_FOR_ACK. 
The FSM starts in the IDLE state, where it searches for the pattern 1101. 
Once the pattern is detected, it transitions to the SHIFT_IN_DURATION state, 
where it shifts in the duration for exactly 4 clock cycles. 
After that, it transitions to the WAIT_FOR_COUNTING state, where it waits for the counters to finish. 
Once the counters are done, it transitions to the WAIT_FOR_ACK state, 
where it asserts the done output and waits for the ack input to be high. 
When the ack input is high, the FSM resets to the IDLE state. 
The FSM also has a synchronous reset input that resets the FSM to the IDLE state.
