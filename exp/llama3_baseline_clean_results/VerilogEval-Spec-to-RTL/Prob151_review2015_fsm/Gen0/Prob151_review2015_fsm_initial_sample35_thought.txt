To implement the finite-state machine that controls the timer, we can use a state machine with five states: IDLE, SHIFT, COUNT, DONE, and WAIT_ACK. The IDLE state is the initial state where the state machine waits for the pattern 1101. Once the pattern is detected, the state machine moves to the SHIFT state and asserts shift_ena for 4 clock cycles to shift in the duration. After that, it moves to the COUNT state and asserts counting to indicate it is waiting for the counters. Once done_counting is high, it moves to the DONE state and asserts done to notify the user. Finally, it moves to the WAIT_ACK state and waits until ack is 1 before resetting to the IDLE state.
