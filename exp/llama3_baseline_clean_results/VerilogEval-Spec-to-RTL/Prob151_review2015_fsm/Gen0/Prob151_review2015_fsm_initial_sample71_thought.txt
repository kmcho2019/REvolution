To implement the finite-state machine that controls the timer, we will define several states to represent the different stages of the timer's operation. The states will be as follows:

- IDLE: The initial state where the state machine searches for the pattern 1101.
- SHIFT: After the pattern is detected, the state machine enters this state to shift in 4 more bits.
- COUNTING: The state machine enters this state after shifting in the 4 bits and waits for the counters to finish counting.
- DONE: The state machine enters this state after the counters have finished counting and notifies the user.
- ACK: The state machine enters this state after notifying the user and waits for acknowledgement.

The state machine will transition between these states based on the inputs and internal conditions. We will use a counter to keep track of the number of bits shifted during the SHIFT state.
