The finite state machine (FSM) will be implemented using a sequential logic design with an enumeration of states to control the timer's operation. The states will be defined as follows:
- IDLE: Initial state where the FSM searches for the pattern '1101' on the input data stream.
- SHIFT: State where the FSM asserts shift_ena for 4 clock cycles to shift in the duration bits.
- COUNT: State where the FSM asserts counting and waits for the counters to finish.
- DONE: State where the FSM asserts done to notify the user and waits for acknowledgement.

The FSM will transition between these states based on the current state, input signals, and the received pattern.
