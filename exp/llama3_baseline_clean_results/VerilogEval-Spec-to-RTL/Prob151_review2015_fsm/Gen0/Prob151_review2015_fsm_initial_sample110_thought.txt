To solve this problem, we need to design a finite state machine (FSM) that goes through several states to implement the timer functionality. The states can be: IDLE (searching for the pattern), SHIFT (shifting in the duration bits), COUNT (waiting for the counters to finish), DONE (notifying the user), and WAIT_ACK (waiting for user acknowledgement). The state machine will transition between these states based on the current state, input signals, and internal counters. 
We can use a case statement to implement the state machine and use if-else statements for conditional statements. 
Internal signals or variables will be used to keep track of the state, the shift counter, and other necessary flags.
