To implement the finite-state machine that controls the timer, we can define several states to represent each step of the timer's operation. The states are:
- IDLE: The initial state where the machine searches for the pattern 1101.
- SHIFT: After detecting the pattern, the machine shifts in 4 more bits to determine the duration to delay.
- COUNT: The machine waits for the counters to finish counting.
- DONE: The machine notifies the user and waits for the user to acknowledge the timer.

We use a counter to keep track of the number of bits shifted in during the SHIFT state. The state machine transitions between states based on the current state and input signals. The output signals (shift_ena, counting, done) are determined by the current state.
