To implement the finite-state machine for the timer, we'll use a Moore machine, where the outputs are determined solely by the current state. The states will be: 
- IDLE: searching for the start pattern (1101)
- SHIFT: shifting in 4 bits for the duration
- COUNT: waiting for the counters to finish
- DONE: notifying the user and waiting for acknowledgement
- RESET: resetting the state machine

We'll use a 4-state variable to represent these states and a 4-bit shift register to store the incoming bits. When in the IDLE state, we'll check for the start pattern. If detected, we'll transition to the SHIFT state and assert shift_ena for 4 clock cycles. After that, we'll transition to the COUNT state and assert counting until done_counting is high. Then, we'll transition to the DONE state, assert done, and wait for ack. Once ack is high, we'll reset to the IDLE state.
