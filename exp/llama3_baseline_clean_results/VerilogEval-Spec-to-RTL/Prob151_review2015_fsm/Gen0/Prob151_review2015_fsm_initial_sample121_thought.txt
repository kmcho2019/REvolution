The problem requires designing a finite-state machine (FSM) to control a timer. The FSM should start when a specific pattern (1101) is detected on the data input, shift in 4 more bits, wait for the counters to finish counting, notify the user, and then wait for acknowledgment. 

We will implement the FSM with five states: 
1. IDLE: The initial state where the FSM searches for the pattern (1101).
2. SHIFT: After detecting the pattern, the FSM shifts in 4 more bits to determine the duration.
3. COUNTING: The FSM waits for the counters to finish counting.
4. DONE: The FSM notifies the user that the timer has timed out.
5. ACK: The FSM waits for the user's acknowledgment before resetting.

The FSM transitions between these states based on the input signals (data, done_counting, ack, and reset).
