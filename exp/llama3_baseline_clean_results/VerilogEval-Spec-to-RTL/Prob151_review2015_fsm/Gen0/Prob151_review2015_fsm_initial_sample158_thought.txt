To implement the finite-state machine that controls the timer, we can use a Mealy machine with the following states: 
- IDLE: the initial state where we start searching for the pattern 1101
- PATTERN_DETECTED: after the pattern 1101 is detected, we transition to this state
- SHIFTING: in this state, we shift in 4 more bits to determine the duration to delay
- COUNTING: after shifting, we transition to this state to wait for the counters to finish counting
- TIMEOUT: after the counters finish counting, we transition to this state to notify the user and wait for acknowledgment

We use a counter to count the number of bits shifted in the SHIFTING state. We also use a flag to track whether the pattern 1101 has been detected.

In the IDLE state, we check the input data to see if the pattern 1101 is detected. If it is, we transition to the PATTERN_DETECTED state.

In the PATTERN_DETECTED state, we assert shift_ena to shift in 4 more bits.

In the SHIFTING state, we keep track of the number of bits shifted and transition to the COUNTING state after 4 bits have been shifted.

In the COUNTING state, we assert counting and wait until done_counting is high.

In the TIMEOUT state, we assert done to notify the user and wait until ack is 1 before transitioning back to the IDLE state.
