To implement the TopModule, we will use a 10-bit down-counter to store the number of clock cycles to count before timing out. We will also use a 1-bit output signal tc to indicate when the counter reaches 0. The load signal will be used to load the internal counter with the 10-bit data. On each positive edge of the clock, if load is 1, the internal counter will be loaded with the data. If load is 0, the internal counter will decrement by 1. When the internal counter reaches 0, it will stop decrementing until it is loaded again, and the tc signal will be asserted to indicate the terminal count.
