To implement the TopModule, we will use a 10-bit down-counter. The counter will be loaded with the 10-bit data when the load signal is high. When the load signal is low, the counter will decrement by 1 at each positive clock edge. The tc (terminal count) signal will be asserted when the counter reaches 0 and will remain asserted until the counter is reloaded. This can be implemented using a single D flip-flop for each bit of the counter.
