To implement the TopModule, we will use a single 10-bit down-counter register. On each positive clock edge, we will check the value of the load signal. If load is 1, we will load the counter with the 10-bit data. If load is 0, we will decrement the counter by 1, unless the counter is already 0, in which case we will keep it at 0. The tc signal will be asserted when the counter reaches 0.
