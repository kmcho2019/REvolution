To implement the TopModule, we will use a 10-bit down-counter that can be loaded with the input data when the load signal is high. On each positive edge of the clock, if the load signal is low, the counter will decrement by 1. The terminal count signal (tc) will be asserted when the counter reaches 0. To ensure the counter stops counting once it reaches 0, we will only decrement the counter when it is not already 0.
