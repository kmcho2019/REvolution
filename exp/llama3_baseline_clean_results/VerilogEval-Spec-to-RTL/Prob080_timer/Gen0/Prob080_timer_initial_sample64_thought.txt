To implement the TopModule, we'll use a down-counter that can be loaded with a new value at any time. The module will have an internal 10-bit counter that is decremented at each clock cycle when load is 0. When the counter reaches 0, it will assert the tc signal. The counter can be loaded with the 10-bit data at any time by setting load to 1. This will overwrite the current count and restart the timer. We'll use a single D flip-flop to store the current count.
