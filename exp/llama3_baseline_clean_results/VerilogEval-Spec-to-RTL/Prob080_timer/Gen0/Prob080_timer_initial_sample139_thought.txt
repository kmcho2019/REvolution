To implement the TopModule, we can use a 10-bit down-counter that can be loaded with the data input when the load signal is high. When the load signal is low, the counter should decrement by 1 at each positive edge of the clock. The terminal count (tc) signal should be asserted when the counter reaches 0 and should remain asserted until the counter is reloaded. We will use a single D flip-flop for the counter, but since it's a 10-bit counter, we'll use 10 D flip-flops in parallel.
