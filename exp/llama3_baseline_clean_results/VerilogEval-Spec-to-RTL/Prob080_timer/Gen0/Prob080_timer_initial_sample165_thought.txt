To implement the TopModule, we need to design a down-counter that can be loaded with a 10-bit value when the 'load' signal is high. On the positive edge of the clock, if 'load' is low, the counter should decrement by 1 until it reaches 0. Once the counter reaches 0, it should stop decrementing and stay at 0 until the 'load' signal is asserted again. We can achieve this by using a single D flip-flop with some combinational logic to control the counter. We will also need to implement the 'tc' output signal to indicate when the counter has reached 0.
