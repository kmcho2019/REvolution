To implement the TopModule, we will use a 10-bit down-counter that loads its value from the input 'data' when 'load' is high. When 'load' is low, the counter decrements on each positive clock edge until it reaches zero. The output 'tc' will be asserted when the counter reaches zero. We will also use a single D flip-flop to capture the 'tc' signal. This implementation meets the requirements of loading the counter at any time and stopping the counter once it reaches zero.
