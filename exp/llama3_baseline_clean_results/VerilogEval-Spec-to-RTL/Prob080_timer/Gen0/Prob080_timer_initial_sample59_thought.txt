The TopModule will utilize a single D flip-flop to implement the down-counter. The load signal will be used to load the internal counter with the 10-bit data when it is high. When the load signal is low, the counter will decrement by 1 at each positive clock edge. The terminal count (tc) signal will be asserted when the counter reaches 0. To prevent the counter from counting below 0, we will add a condition to check if the counter is already 0 before decrementing it.
