To implement the TopModule, we will use a down-counter with a load enable. 
When load is high, the counter will be loaded with the 10-bit data. 
When load is low, the counter will decrement by 1 on each positive clock edge. 
The output tc will be asserted when the counter reaches 0. 
We will use a single D flip-flop to store the counter value and implement 
the sequential logic. 
The module will have a synchronous reset, which is not explicitly mentioned 
in the problem, but it's good practice to include it. 
However, for simplicity, the problem statement does not require a reset, 
so we'll implement it without a reset.
