The TopModule should have a 10-bit down-counter that can be loaded with a new value at any time. 
The counter should decrement on each clock cycle when load is 0, and when it reaches 0, it should stop counting until a new value is loaded.
A single output signal, tc, will be used to indicate when the counter reaches 0.
To implement this, we will use a 10-bit register to store the counter value, and a D flip-flop to handle the sequential logic.
On each positive edge of the clock, we will check the load signal. If load is 1, we will load the counter with the new value. If load is 0, we will decrement the counter if it is not already 0.
The tc signal will be asserted when the counter reaches 0.
