To implement a 5-bit maximal-length Galois LFSR, we need to design a shift register that shifts right and has XOR gates at bit positions 5 and 3. These XOR gates will produce the next state of the shift register by XORing the current state of the tapped bits with the LSB output bit (q[0]). The LFSR should be reset to 1 on the active-high synchronous reset. We can use a register to store the current state of the LFSR and update it on the positive edge of the clock.
