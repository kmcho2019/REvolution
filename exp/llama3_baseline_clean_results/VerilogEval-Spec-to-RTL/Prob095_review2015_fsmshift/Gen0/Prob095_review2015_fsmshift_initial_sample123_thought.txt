To implement the TopModule, we can use a finite state machine (FSM) with two states: IDLE and SHIFT_ENA. The FSM will start in the IDLE state. When the reset signal is asserted, the FSM will transition to the SHIFT_ENA state and stay there for 4 clock cycles, then return to the IDLE state. The shift_ena signal will be asserted when the FSM is in the SHIFT_ENA state. We will use a counter to keep track of the number of clock cycles in the SHIFT_ENA state.
