To implement the TopModule, we will use a finite state machine (FSM) that can be in one of two states: an idle state and a shifting state. When the FSM is in the idle state, shift_ena will be 0. When reset is asserted, the FSM will transition to the shifting state and assert shift_ena for exactly 4 clock cycles. We will use a counter to keep track of the number of clock cycles that shift_ena has been asserted.
