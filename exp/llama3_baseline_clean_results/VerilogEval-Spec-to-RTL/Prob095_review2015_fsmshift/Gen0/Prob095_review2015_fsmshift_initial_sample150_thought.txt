To implement the TopModule, we can use a finite state machine (FSM) with two states: IDLE and SHIFT_ENABLE. Initially, when the module is reset, it should enter the SHIFT_ENABLE state and assert shift_ena for 4 clock cycles. After 4 cycles, it should enter the IDLE state and keep shift_ena low until the next reset. We can use a counter to keep track of the number of clock cycles in the SHIFT_ENABLE state. When the counter reaches 4, we transition back to the IDLE state. The reset signal should be active high synchronous, meaning it only affects the state on the positive edge of the clock.
