To implement the TopModule, we will use a finite state machine (FSM) with two states: Idle and ShiftEnable. The FSM will start in the Idle state. When reset is high, the FSM will transition to the ShiftEnable state and assert shift_ena for 4 clock cycles. After the 4 cycles, it will return to the Idle state and deassert shift_ena. The FSM will remain in the Idle state until reset is asserted again. We will use a counter to keep track of the number of clock cycles that shift_ena has been asserted.
