To implement the TopModule, we will use a finite state machine (FSM) with two states: IDLE and SHIFT. When the module is reset, it will start in the IDLE state and assert shift_ena for 4 clock cycles. After the 4 cycles, it will stay in the IDLE state with shift_ena deasserted until the next reset. We can use a counter to keep track of the number of clock cycles that shift_ena has been asserted.
