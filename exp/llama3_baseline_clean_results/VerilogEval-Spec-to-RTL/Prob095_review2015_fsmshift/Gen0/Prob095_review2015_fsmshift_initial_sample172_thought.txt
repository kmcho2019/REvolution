The TopModule can be implemented as a finite state machine (FSM) with two states: an idle state and a shifting state. The idle state will be the default state, and when the reset signal is asserted, the FSM will transition into the shifting state for exactly 4 clock cycles, during which shift_ena will be asserted. After 4 cycles, the FSM will return to the idle state, and shift_ena will be de-asserted until the next reset. A counter can be used to keep track of the number of clock cycles that have passed since the FSM entered the shifting state.
