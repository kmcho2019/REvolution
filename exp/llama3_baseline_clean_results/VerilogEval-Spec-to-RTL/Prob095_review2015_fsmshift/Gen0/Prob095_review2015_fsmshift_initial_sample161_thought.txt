To implement the TopModule, we can use a Finite State Machine (FSM) with two states: IDLE and SHIFT. The module starts in the IDLE state. When reset is asserted, the module transitions to the SHIFT state and stays there for 4 clock cycles, asserting shift_ena. After 4 cycles, it returns to the IDLE state and deasserts shift_ena. The FSM should also have a counter to keep track of the number of cycles in the SHIFT state. Since reset is active high synchronous, we can use it to reset the FSM and the counter on the positive edge of the clock.
