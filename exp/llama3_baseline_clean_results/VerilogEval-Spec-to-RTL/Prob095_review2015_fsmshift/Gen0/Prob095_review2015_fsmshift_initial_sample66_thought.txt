To implement the TopModule, we can use a finite state machine (FSM) with two states: IDLE and SHIFT. The IDLE state will be the initial state and will remain in this state until reset is asserted. When reset is asserted, the FSM will transition to the SHIFT state and assert shift_ena for 4 clock cycles. After the 4 cycles, it will return to the IDLE state and deassert shift_ena. We will use a counter to keep track of the 4 clock cycles. Since reset is active high synchronous, we need to make sure that the reset is only considered when the clock is high.
