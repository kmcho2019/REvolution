To implement the TopModule, we can use a finite state machine (FSM) that has two main states: an IDLE state and a SHIFT state. When the module is reset, it enters the SHIFT state and asserts the shift_ena signal for exactly 4 clock cycles. After these 4 cycles, it transitions to the IDLE state and keeps the shift_ena signal deasserted until the next reset. 
We will use a counter to keep track of the number of clock cycles in the SHIFT state. The counter will be reset when the FSM transitions back to the IDLE state.
