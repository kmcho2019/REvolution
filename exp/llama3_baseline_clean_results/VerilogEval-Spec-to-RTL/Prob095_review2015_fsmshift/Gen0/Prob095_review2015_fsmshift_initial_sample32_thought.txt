To solve this problem, we can use a finite state machine (FSM) with two main states: an IDLE state where the shift register is disabled, and a SHIFT state where the shift register is enabled. The FSM starts in the IDLE state and remains there until reset is asserted. When reset is asserted, the FSM transitions to the SHIFT state and stays there for exactly 4 clock cycles, then returns to the IDLE state and remains there until the next reset. We can use a counter to keep track of the number of clock cycles in the SHIFT state.
