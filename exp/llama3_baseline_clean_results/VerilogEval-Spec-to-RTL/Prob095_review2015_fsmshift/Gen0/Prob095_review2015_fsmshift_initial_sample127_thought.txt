To implement the TopModule, we will create a finite state machine (FSM) that has two states: an idle state and a shifting state. When the FSM is in the idle state and reset is high, it will transition to the shifting state and start a 4-clock cycle counter. During these 4 clock cycles, shift_ena will be asserted. After the 4 clock cycles, shift_ena will be de-asserted. The FSM will remain in the idle state with shift_ena de-asserted until reset is asserted again.
