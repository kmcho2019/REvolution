To implement the TopModule, we can use a finite state machine (FSM) with two states: IDLE and SHIFT. When the module is in the IDLE state, it will assert shift_ena for 4 clock cycles whenever reset is high. Once the 4 cycles are completed, the module will transition to a state where shift_ena remains low until the next reset. We will use a counter to keep track of the number of clock cycles for which shift_ena has been high.
