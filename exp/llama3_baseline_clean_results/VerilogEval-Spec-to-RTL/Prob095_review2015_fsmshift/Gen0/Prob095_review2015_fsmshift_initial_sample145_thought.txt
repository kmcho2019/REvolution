To implement the TopModule, we can use a finite state machine (FSM) with two main states: an idle state and a shifting state. When the module is reset, it transitions into the shifting state and stays there for exactly 4 clock cycles, asserting shift_ena during this time. After the 4 clock cycles, it transitions back into the idle state where shift_ena remains deasserted until the next reset. The FSM will use a counter to keep track of the number of clock cycles in the shifting state.
