To solve this problem, we can use a finite state machine (FSM) with a counter. 
The FSM will have two main states: IDLE and SHIFT_ENABLE. In the IDLE state, 
the shift_ena signal is 0. When the reset signal is asserted, the FSM moves 
to the SHIFT_ENABLE state, where the shift_ena signal is 1 for exactly 4 
clock cycles, after which it returns to the IDLE state. 
We will use a counter to keep track of the number of clock cycles that 
the shift_ena signal has been asserted. The counter will reset to 0 when 
the FSM transitions from the SHIFT_ENABLE state to the IDLE state.
