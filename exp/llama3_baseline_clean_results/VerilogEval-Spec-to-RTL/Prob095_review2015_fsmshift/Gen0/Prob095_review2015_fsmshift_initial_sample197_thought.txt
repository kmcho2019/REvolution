To implement the TopModule, we will use a finite state machine (FSM) with two states: IDLE and SHIFT_ENABLE. When reset is asserted, the module will enter the SHIFT_ENABLE state for exactly 4 clock cycles and then stay in the IDLE state until reset is asserted again. The shift_ena signal will be asserted during the SHIFT_ENABLE state. We will use a counter to keep track of the number of clock cycles the module has been in the SHIFT_ENABLE state.
