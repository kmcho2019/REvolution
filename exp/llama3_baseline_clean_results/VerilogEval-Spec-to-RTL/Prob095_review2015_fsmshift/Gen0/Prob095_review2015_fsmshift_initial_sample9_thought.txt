To implement the TopModule, we will use a finite state machine (FSM) with a counter to keep track of the number of clock cycles for which shift_ena is asserted. When the FSM is reset, it will enter a state where shift_ena is asserted for exactly 4 clock cycles. After the 4 cycles, it will enter a state where shift_ena is deasserted.
