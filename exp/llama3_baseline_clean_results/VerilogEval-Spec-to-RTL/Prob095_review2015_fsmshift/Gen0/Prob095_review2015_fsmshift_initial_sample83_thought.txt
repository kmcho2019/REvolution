To implement the TopModule, we will use a finite state machine (FSM) with two main states: an idle state and a shifting state. The FSM will start in the idle state. When the reset signal is asserted, the FSM will transition to the shifting state and assert the shift_ena signal for exactly 4 clock cycles. After 4 cycles, the FSM will transition back to the idle state and deassert the shift_ena signal. The FSM will remain in the idle state until the reset signal is asserted again. We can use a counter to keep track of the number of clock cycles in the shifting state.
