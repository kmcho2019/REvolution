To implement the TopModule, we need a finite state machine (FSM) that can keep track of the number of clock cycles for which shift_ena should be asserted. Since reset is active high synchronous, we will have a reset state and then four states to assert shift_ena for exactly 4 clock cycles after reset. We can use a counter to keep track of the number of cycles. The module will start in an idle state and when reset is asserted, it will transition to a state where shift_ena is asserted for 4 clock cycles, after which it will go back to an idle state where shift_ena remains 0.
