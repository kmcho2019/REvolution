To implement the TopModule, we can use a finite state machine (FSM) with two states: IDLE and SHIFT. In the IDLE state, the shift_ena signal is deasserted. When the reset signal is asserted, the FSM transitions to the SHIFT state and stays there for exactly 4 clock cycles, during which the shift_ena signal is asserted. After 4 clock cycles, the FSM returns to the IDLE state. We can use a counter to keep track of the number of clock cycles in the SHIFT state. The FSM will also have a reset state that will override all other states when the reset input is asserted.
