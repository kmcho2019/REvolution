To implement the Moore state machine, we first need to encode the states. Since there are four states, we can use two bits to represent them. We will use the states A = 2'b00, B = 2'b01, C = 2'b10, and D = 2'b11. 

We then need to create a state register that holds the current state and is updated based on the next state logic. The next state logic is determined by the current state and the input 'in'. 

The output is determined by the current state. In this case, the output is 1 only when the current state is D.

We will also implement a positive edge triggered asynchronous reset that resets the FSM to state A.
