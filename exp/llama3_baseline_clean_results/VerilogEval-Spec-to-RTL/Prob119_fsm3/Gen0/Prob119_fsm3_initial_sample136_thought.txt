To implement the Moore state machine, we first need to define the states as enumerations. Since we have four states (A, B, C, D), we can use 2 bits to represent these states. The next step is to create a state register that holds the current state and can be updated on the positive edge of the clock. We will also include a positive edge triggered asynchronous reset that resets the FSM to state A. The output of the state machine will be determined solely by the current state, which is the definition of a Moore machine. We will use a case statement to determine the next state based on the current state and input.
