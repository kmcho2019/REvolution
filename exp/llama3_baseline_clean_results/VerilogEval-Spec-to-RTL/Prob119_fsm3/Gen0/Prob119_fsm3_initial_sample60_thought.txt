To implement the Moore state machine, we will use a 2-bit state register to store the current state since there are four states (A, B, C, D). We can represent each state using two bits (00, 01, 10, 11). 

We will use a case statement to determine the next state based on the current state and the input 'in'. The output will be determined solely by the current state. 

On the positive edge of the asynchronous reset (areset), we will reset the state register to the initial state 'A' (00). 

On the positive edge of the clock (clk), we will update the state register to the next state determined by the current state and the input 'in'.
