To implement the Moore state machine described in the state transition table, we need to follow these steps:
1. Define the states and assign them to unique binary values.
2. Create a state register to store the current state of the state machine.
3. Implement the state transition logic based on the current state and the input `in`.
4. Implement the output logic based on the current state.
5. Add a positive edge triggered asynchronous reset that resets the state machine to state A.

We can use an enum to represent the states in the code. Since there are four states, we can use 2-bit binary values to represent them.
