To implement the 7420 chip's functionality, which contains two 4-input NAND gates, we need to create a module that takes eight 1-bit inputs (p1a, p1b, p1c, p1d for the first gate and p2a, p2b, p2c, p2d for the second gate) and produces two 1-bit outputs (p1y and p2y). Each output should be the result of a NAND operation on its respective four inputs. The NAND operation returns 1 only if at least one of the inputs is 0.
