The 7420 chip has two 4-input NAND gates. To implement this functionality in the TopModule, we can create two separate 4-input NAND gates, one for p1y and one for p2y. Each NAND gate will take four input signals (p1a, p1b, p1c, p1d for the first gate and p2a, p2b, p2c, p2d for the second gate) and produce an output signal (p1y and p2y respectively). The output of a NAND gate is 1 only if none of the input signals are 1, otherwise it is 0. In Verilog, this can be implemented using the logical NAND operator (~&).
