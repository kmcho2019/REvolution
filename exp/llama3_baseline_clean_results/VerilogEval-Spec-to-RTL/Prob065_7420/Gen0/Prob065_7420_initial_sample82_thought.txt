To implement the functionality of the 7420 chip, which contains two 4-input NAND gates, we need to create a module (TopModule) that takes eight input bits (p1a, p1b, p1c, p1d, p2a, p2b, p2c, p2d) and produces two output bits (p1y, p2y). The first 4-input NAND gate should take inputs p1a, p1b, p1c, p1d and produce output p1y. The second 4-input NAND gate should take inputs p2a, p2b, p2c, p2d and produce output p2y. A 4-input NAND gate produces an output of 1 only if all inputs are 0, otherwise it produces an output of 0.
