The 7420 chip contains two 4-input NAND gates. To implement the same functionality, we need to create two separate 4-input NAND gates within the TopModule. Each NAND gate will take four input signals and produce an output that is the logical NAND of these inputs. The first gate will produce the output p1y based on inputs p1a, p1b, p1c, and p1d. The second gate will produce the output p2y based on inputs p2a, p2b, p2c, and p2d.
