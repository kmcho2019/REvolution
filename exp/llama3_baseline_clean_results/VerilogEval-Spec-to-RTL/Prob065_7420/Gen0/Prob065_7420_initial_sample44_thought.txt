The 7420 chip has two 4-input NAND gates. To implement the same functionality, we need to design a module TopModule that has two 4-input NAND gates. Each gate will take four inputs (p1a, p1b, p1c, p1d for the first gate and p2a, p2b, p2c, p2d for the second gate) and produce one output (p1y for the first gate and p2y for the second gate). The output of a NAND gate is 0 only if all inputs are 1; otherwise, it is 1.
