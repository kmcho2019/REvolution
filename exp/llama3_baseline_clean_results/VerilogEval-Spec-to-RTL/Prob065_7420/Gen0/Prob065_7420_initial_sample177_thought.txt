To implement the functionality of the 7420 chip, we need to create two 4-input NAND gates. Each gate will take four inputs (p1a, p1b, p1c, p1d for the first gate and p2a, p2b, p2c, p2d for the second gate) and produce one output (p1y and p2y respectively). The output of a NAND gate is 1 only if all the inputs are 0. We can implement this using the logical AND operator and then inverting the result.
