The problem can be solved by designing a finite state machine (FSM) with the following states:
- IDLE: The initial state where the line is idle (high).
- START: The state where the start bit (0) is detected.
- DATA: The state where the 8 data bits are being received.
- STOP: The state where the stop bit (1) is expected.
- DONE: The state where the stop bit is verified and the data byte is output.

The FSM transitions between these states based on the input signal 'in'. 
In the IDLE state, when 'in' is 0, the FSM transitions to the START state.
In the START state, the FSM waits for one clock cycle and then transitions to the DATA state.
In the DATA state, the FSM receives the 8 data bits, storing them in 'out_byte'. 
After receiving all 8 data bits, the FSM transitions to the STOP state.
In the STOP state, the FSM checks the stop bit. If it is 1, the FSM transitions to the DONE state, where it asserts 'done' and outputs the received data byte. 
If the stop bit is not 1, the FSM stays in the STOP state until it detects a stop bit (1).
The FSM also includes an active-high synchronous reset, which resets the FSM to the IDLE state when 'reset' is high.
