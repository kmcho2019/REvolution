To implement the serial byte receiver, we can design a finite state machine (FSM) with the following states: 
1. IDLE: This is the initial state where the FSM waits for a start bit.
2. START_BIT_RECEIVED: After receiving a start bit, the FSM transitions to this state and starts collecting the 8 data bits.
3. DATA_BITS_COLLECTED: Once all 8 data bits have been collected, the FSM transitions to this state and checks for the stop bit.
4. STOP_BIT_ERROR: If the stop bit is not correctly received, the FSM transitions to this state and waits until it finds a stop bit before going back to the IDLE state.

The FSM will also have a shift register to collect the 8 data bits, and an output register to hold the received byte.

The 'done' signal will be asserted when the FSM is in the DATA_BITS_COLLECTED state and the stop bit is correctly received.
