To solve this problem, we will design a finite state machine (FSM) with the following states:
- IDLE: The initial state where the FSM waits for the start bit.
- START: The state where the FSM has detected the start bit and is waiting for the data bits.
- DATA: The state where the FSM is receiving the data bits.
- STOP: The state where the FSM is waiting for the stop bit.
- ERROR: The state where the FSM has detected an error in the stop bit and is waiting for a stop bit before going back to IDLE.
We will use a counter to keep track of the number of data bits received and a shift register to store the data bits.
