To solve this problem, we'll design a finite state machine (FSM) with the following states: 
1. IDLE: The initial state where the FSM waits for a start bit.
2. START_BIT: After detecting a start bit, the FSM moves to this state.
3. DATA_BITS: In this state, the FSM collects the 8 data bits.
4. STOP_BIT: After collecting all data bits, the FSM checks for a stop bit.
The FSM will also have a counter to keep track of the number of data bits received. 
When the stop bit is verified, the FSM will output the received byte and assert the 'done' signal. 
If the stop bit is not received as expected, the FSM will wait for a stop bit before attempting to receive the next byte.
