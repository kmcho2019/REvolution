To solve this problem, we can design a finite state machine (FSM) with the following states: 
- IDLE: waiting for a start bit
- START: start bit received, waiting for data bits
- DATA: receiving data bits
- STOP: waiting for a stop bit
- DONE: stop bit received, outputting the data byte

The FSM will transition between these states based on the input serial bit stream. 
When the FSM is in the IDLE state, it will transition to the START state when it receives a start bit (0). 
Then it will transition to the DATA state and shift in the 8 data bits. 
After receiving the data bits, it will transition to the STOP state and wait for a stop bit (1). 
If the stop bit is correct, it will transition to the DONE state, output the data byte, and assert the done signal. 
If the stop bit is incorrect, it will wait until it receives a stop bit before transitioning back to the IDLE state. 
The FSM will also have a synchronous reset to reset it to the IDLE state.
