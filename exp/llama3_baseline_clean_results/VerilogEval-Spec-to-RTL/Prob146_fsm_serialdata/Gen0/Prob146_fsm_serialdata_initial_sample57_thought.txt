When a start bit is detected, the FSM transitions to the START_BIT state and then to the DATA_BITS state, where it collects 8 data bits. If the stop bit is not correct, the FSM remains in the STOP_BIT state until a stop bit is detected. The FSM then returns to the IDLE state to wait for the next start bit.
