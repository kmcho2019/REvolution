To solve this problem, we will design a finite state machine (FSM) with the following states:
- IDLE: The initial state where the FSM waits for a start bit (0).
- START: The state after a start bit has been detected.
- DATA: The state where the FSM collects the 8 data bits.
- STOP: The state where the FSM checks for the stop bit (1).
- ERROR: A temporary state that is entered when an incorrect stop bit is detected.

The FSM will transition between these states based on the input bit and the current state. 
In the DATA state, the FSM will shift the input bit into the output byte, starting from the least significant bit.
Once the FSM reaches the STOP state and verifies the stop bit, it will assert the 'done' signal and output the received byte.
If the stop bit is incorrect, the FSM will remain in the ERROR state until it detects a stop bit, at which point it will transition back to the IDLE state.
