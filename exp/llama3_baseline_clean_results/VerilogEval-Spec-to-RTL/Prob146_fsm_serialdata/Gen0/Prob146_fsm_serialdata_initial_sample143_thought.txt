To solve this problem, we will design a finite state machine (FSM) with the following states:
1. IDLE: The FSM starts in this state and waits for a start bit (0).
2. DATA: Once a start bit is detected, the FSM enters this state and shifts in the 8 data bits.
3. STOP: After all 8 data bits have been received, the FSM enters this state and checks for the stop bit (1).
If the stop bit is not detected, the FSM will remain in this state until a stop bit is received.

We will use a counter to keep track of the number of data bits received, and a shift register to store the received data bits.

The `done` signal will be asserted when the FSM is in the STOP state and a stop bit is detected.

The FSM will also be reset to the IDLE state when the `reset` signal is asserted.
