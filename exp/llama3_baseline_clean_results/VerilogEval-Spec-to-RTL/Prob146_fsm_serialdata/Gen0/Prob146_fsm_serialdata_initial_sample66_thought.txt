To solve this problem, we will implement a finite state machine (FSM) with the following states:
1. IDLE: This is the initial state where the FSM waits for the start bit (0) to begin receiving a byte.
2. START: After detecting the start bit, the FSM moves to this state and waits for 8 data bits.
3. DATA: In this state, the FSM collects the 8 data bits. 
4. STOP: After collecting the 8 data bits, the FSM moves to this state to verify the stop bit (1).

We will use a counter to keep track of the number of data bits received and a shift register to store the data bits. The FSM will also use a variable to store the current state.

When the FSM is in the DATA state, it will shift the incoming data bit into the shift register and increment the counter. When the counter reaches 8, the FSM will move to the STOP state. If the stop bit is 1, the FSM will assert the done signal and move back to the IDLE state. If the stop bit is not 1, the FSM will wait until it finds a stop bit before moving back to the IDLE state.

The reset signal will be used to reset the FSM to the IDLE state and clear the counter and shift register.
