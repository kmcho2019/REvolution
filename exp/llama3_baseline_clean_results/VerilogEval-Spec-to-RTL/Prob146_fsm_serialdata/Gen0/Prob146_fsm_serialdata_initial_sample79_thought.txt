The design idea is to create a finite state machine (FSM) with several states: 
- IDLE: waiting for the start bit
- START_BIT: checking if the start bit is correct (0)
- DATA_BITS: collecting the 8 data bits
- STOP_BIT: checking if the stop bit is correct (1)
- DONE: asserting the done signal when a stop bit is received

We will use a counter to keep track of the current data bit being received.
When the FSM is in the DATA_BITS state, it will shift the input bit into 
the out_byte register, with the least significant bit being received first.
If the stop bit does not appear when expected, the FSM will stay in the 
STOP_BIT state until it finds a stop bit. Once a stop bit is received, 
the FSM will assert the done signal and move back to the IDLE state.
