To design the finite state machine (FSM) that identifies correctly received bytes from a stream of bits, we can break down the process into several states:
1. Idle: The initial state where the line is at logic 1 and no byte is being received.
2. Start: The state where a start bit (0) is detected, indicating the beginning of a byte.
3. Data: The state where the 8 data bits are received. We'll use a counter to keep track of the bits received.
4. Stop: The state where the stop bit (1) is expected. If the stop bit is not 1, the FSM will wait until it sees a stop bit before attempting to receive the next byte.
We'll use a counter to keep track of the number of data bits received. When the stop bit is detected, we'll assert the `done` signal and output the received byte on `out_byte`.
