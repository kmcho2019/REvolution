To implement the TopModule, we can use a finite state machine (FSM) with the following states:
1. IDLE: This is the initial state where the FSM waits for the start bit.
2. START_BIT: This state checks for the start bit (0).
3. DATA_BITS: This state collects the 8 data bits.
4. STOP_BIT: This state checks for the stop bit (1) and outputs the received byte if the stop bit is correct.
5. ERROR: This state is entered if the stop bit is not correct. It waits for a stop bit before going back to the IDLE state.

We will use a counter to keep track of the number of data bits received. We will also use a shift register to collect the data bits. The out_byte will be updated with the received byte when the stop bit is correct and the done signal will be asserted.
