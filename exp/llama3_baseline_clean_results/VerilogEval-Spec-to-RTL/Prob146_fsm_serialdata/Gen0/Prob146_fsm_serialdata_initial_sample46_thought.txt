To solve this problem, we need to design a finite state machine (FSM) with the following states:
1. IDLE: The initial state where the line is idle and waiting for a start bit.
2. START: The state after a start bit has been detected.
3. DATA: The state where the FSM is receiving the data bits.
4. STOP: The state where the FSM is waiting for the stop bit.

When the FSM is in the IDLE state, it checks for the start bit (0) on the input line. If the start bit is detected, it moves to the START state.

In the START state, the FSM sets the current bit index to 0 and moves to the DATA state.

In the DATA state, the FSM shifts in the current bit from the input line into the out_byte register, increments the bit index, and stays in the DATA state until all 8 bits have been received.

After receiving all 8 bits, the FSM moves to the STOP state and checks for the stop bit (1) on the input line. If the stop bit is correct, it asserts the done signal and moves back to the IDLE state. If the stop bit is incorrect, it stays in the STOP state and waits for a stop bit (1) before moving back to the IDLE state.

We also need to handle the active-high synchronous reset. When the reset signal is high, the FSM resets to the IDLE state and the out_byte register is cleared.
