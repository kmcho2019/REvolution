To solve this problem, we'll design a finite state machine (FSM) that can identify the start bit, wait for the 8 data bits, and verify the stop bit. The FSM will have the following states:
1. Idle: Wait for the start bit.
2. Start: Found the start bit, start shifting in data bits.
3. Data: Shift in the data bits.
4. Stop: Check if the stop bit is correct.
We'll use a counter to keep track of the number of data bits received and a shift register to store the received data bits.
