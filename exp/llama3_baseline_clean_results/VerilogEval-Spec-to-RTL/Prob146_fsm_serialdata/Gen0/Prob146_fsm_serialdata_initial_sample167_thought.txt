The TopModule should have a finite state machine (FSM) that detects the start bit, waits for 8 data bits, and then checks for the stop bit. The FSM will have the following states:
- IDLE: Wait for the start bit (0).
- START: Received the start bit, wait for the data bits.
- DATA: Collect the 8 data bits.
- STOP: Check the stop bit.
- INVALID_STOP: If the stop bit is not 1, wait for a stop bit (1) before returning to the IDLE state.

When in the DATA state, we shift the input bit into the out_byte register from the least significant bit (LSB) to the most significant bit (MSB).
When we receive a valid stop bit, we assert the done signal and go back to the IDLE state.

The module should also have an active-high synchronous reset that resets the FSM to the IDLE state and clears the out_byte register.
