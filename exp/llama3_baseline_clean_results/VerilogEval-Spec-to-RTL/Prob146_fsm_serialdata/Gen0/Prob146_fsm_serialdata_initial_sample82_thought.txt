To implement the serial byte receiver, we can use a finite state machine (FSM) with the following states:
1. IDLE: Wait for the start bit (0) to initiate byte reception.
2. RECEIVE: Receive the 8 data bits.
3. STOP: Verify the stop bit (1) and assert the done signal.
The FSM will also use a counter to keep track of the number of data bits received.

We will use a 4-state FSM: IDLE, START, RECEIVE, and STOP. In the IDLE state, the FSM waits for the start bit. Once the start bit is detected, it transitions to the START state. Then it transitions to the RECEIVE state and starts receiving the data bits. After receiving all 8 data bits, it transitions to the STOP state to verify the stop bit. If the stop bit is correct, it asserts the done signal and returns to the IDLE state. If the stop bit is incorrect, it remains in the STOP state until a stop bit is detected.

The out_byte output will be updated with the received data byte when the FSM is in the STOP state. The done output will be asserted when the FSM is in the STOP state and the stop bit is correct.
