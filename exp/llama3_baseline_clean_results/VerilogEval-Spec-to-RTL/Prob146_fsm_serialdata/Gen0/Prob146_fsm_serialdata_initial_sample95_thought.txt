To solve this problem, we can design a finite state machine (FSM) that has the following states: 
- IDLE: waiting for a start bit (0)
- START: found start bit, waiting for data bits
- DATA: receiving data bits
- STOP: waiting for stop bit (1)
- ERROR: waiting for a stop bit after incorrect stop bit

The FSM will transition between these states based on the current state, the input 'in', and the number of bits received. 
When in the DATA state, we will shift the input bits into a register to form the received byte. 
Once we receive the stop bit, we will assert 'done' and output the received byte. 
If we don't receive the stop bit when expected, we will wait for a stop bit before attempting to receive the next byte.
