To solve this problem, we need to design a finite state machine (FSM) that can identify the start bit, wait for all 8 data bits, verify the stop bit, and output the correctly received data byte. The FSM should have the following states: 
- IDLE: The initial state, waiting for the start bit.
- START: The state after a start bit is detected.
- DATA: The state where the FSM is receiving the data bits.
- STOP: The state where the FSM is waiting for the stop bit.
- ERROR: The state where the FSM is waiting for a stop bit after a bad stop bit.

The FSM will transition between these states based on the input bit and the current state. We will also use a counter to keep track of the number of data bits received.
