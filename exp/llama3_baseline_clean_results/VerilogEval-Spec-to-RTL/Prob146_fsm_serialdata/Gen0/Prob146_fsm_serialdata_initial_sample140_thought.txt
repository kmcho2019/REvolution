The TopModule can be implemented as a finite state machine (FSM) with the following states:
- IDLE: Wait for the start bit (0) to initiate the reception of a byte.
- START: Check if a start bit has been detected.
- DATA: Receive 8 data bits, with the least significant bit first.
- STOP: Verify the stop bit (1) and output the received byte if correct.
The FSM will transition between these states based on the input 'in' and the current state.
When a byte is correctly received, the FSM will assert 'done' and output the byte on 'out_byte'.
If the stop bit is not received, the FSM will wait in the STOP state until a stop bit is detected.
The FSM will also have an active-high synchronous reset to reset the module to the IDLE state.
