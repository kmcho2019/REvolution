To solve this problem, we will design a finite state machine (FSM) with the following states:
1. IDLE: Initial state, waiting for a start bit (0).
2. START: Received a start bit, now waiting for the 8 data bits.
3. DATA: Receiving the 8 data bits, bit by bit, starting from the least significant bit.
4. STOP: Received all 8 data bits, now waiting for the stop bit (1).
5. ERROR: Stop bit did not appear as expected, waiting for a stop bit before attempting to receive the next byte.

We will use a counter to keep track of the number of data bits received and a shift register to store the received data bits.
