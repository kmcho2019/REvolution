To solve this problem, we will design a finite state machine (FSM) with the following states: 
- Idle: Wait for the start bit (0).
- Start: Check if the current bit is the start bit.
- Data: Receive the 8 data bits.
- Stop: Verify the stop bit (1) and output the received byte.
We will also use a counter to keep track of the number of data bits received.
The FSM will be reset to the Idle state when the reset signal is high.
The out_byte will be updated with the received data byte when the FSM is in the Stop state, and the done signal will be asserted when a stop bit is detected.
