To solve this problem, we will design a finite state machine (FSM) with the following states: 
- Idle: This is the initial state where the FSM waits for a start bit (0) to begin receiving a byte.
- Receive: In this state, the FSM receives the 8 data bits one by one. 
- VerifyStop: After receiving all 8 data bits, the FSM waits for a stop bit (1) to verify that the byte was received correctly.

The FSM will have a counter to keep track of the number of bits received. 
When the FSM is in the Receive state, it will shift the received bits into the out_byte register. 
When the FSM is in the VerifyStop state, it will check if the current bit is a stop bit (1). 
If it is, the FSM will assert the done signal and go back to the Idle state. 
If it is not, the FSM will stay in the VerifyStop state until it finds a stop bit.

The module will also have an active-high synchronous reset. 
When the reset signal is high, the FSM will reset to the Idle state, and all registers will be cleared.
