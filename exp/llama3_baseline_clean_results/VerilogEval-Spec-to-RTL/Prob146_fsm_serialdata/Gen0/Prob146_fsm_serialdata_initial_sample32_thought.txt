To solve this problem, we will design a finite state machine (FSM) with the following states: 
- IDLE: waiting for the start bit
- START: waiting for the data bits
- DATA: receiving the data bits
- STOP: verifying the stop bit
The FSM will transition from one state to another based on the current state and the input bit.
In the IDLE state, if the input bit is 0, the FSM will transition to the START state.
In the START state, the FSM will transition to the DATA state.
In the DATA state, the FSM will receive the data bits and shift them into a register. After 8 data bits, the FSM will transition to the STOP state.
In the STOP state, if the input bit is 1, the FSM will assert the done signal and transition back to the IDLE state.
If the stop bit does not appear when expected, the FSM will wait in the STOP state until a stop bit is received.
We will also implement a synchronous reset that resets the FSM to the IDLE state when asserted.
