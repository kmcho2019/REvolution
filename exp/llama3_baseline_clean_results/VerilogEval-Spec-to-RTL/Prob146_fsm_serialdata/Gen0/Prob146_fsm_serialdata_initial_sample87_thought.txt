To solve this problem, we can design a finite state machine (FSM) with the following states:
- IDLE: The initial state, where the FSM waits for the start bit.
- START: The state where the FSM checks if the start bit is 0.
- DATA: The state where the FSM collects the 8 data bits.
- STOP: The state where the FSM checks if the stop bit is 1 and outputs the data byte if correct.
The FSM transitions between these states based on the current state and the input bit. If the stop bit is not 1, the FSM will go back to the IDLE state after a stop bit is detected.
We will use a counter to keep track of the current bit position and a register to store the data byte.
The `done` signal will be asserted when the FSM is in the STOP state and the stop bit is 1.
