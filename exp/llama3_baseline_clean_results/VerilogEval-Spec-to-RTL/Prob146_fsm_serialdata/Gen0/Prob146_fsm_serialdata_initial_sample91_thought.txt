The problem requires designing a finite state machine (FSM) to identify bytes received through a serial communication protocol. The FSM should recognize the start bit, wait for the 8 data bits, and verify the stop bit. We will implement this using a 5-state FSM: IDLE, START, DATA, STOP_WAIT, and STOP_VALID.

1. **IDLE State**: Wait for the start bit (0) to be received. Once the start bit is detected, move to the START state.

2. **START State**: The start bit has been received. Begin collecting the data bits in this state. Shift in the data bits and move to the DATA state to collect the remaining 7 bits.

3. **DATA State**: Collect the remaining 7 data bits. After all 8 bits are collected, move to the STOP_WAIT state to wait for the stop bit.

4. **STOP_WAIT State**: Wait for the stop bit (1) to be received. If the stop bit is not received, stay in this state until it is.

5. **STOP_VALID State**: The stop bit has been received, and a valid byte has been detected. Assert the done signal and move back to the IDLE state to wait for the next byte.

The serial protocol sends the least significant bit first, so we should construct the out_byte from the least significant bit to the most significant bit as we receive the bits.
