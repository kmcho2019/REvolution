The TopModule will be implemented as a finite state machine (FSM) with several states. 
The states are: IDLE (waiting for a start bit), RECEIVE (receiving the 8 data bits), 
VERIFY_STOP (checking for the stop bit after receiving all data bits), and INVALID (waiting 
for a stop bit when the stop bit is expected but not received). When the FSM is in the IDLE 
state, it will check for the start bit on each clock cycle. If the start bit is detected, it 
will transition to the RECEIVE state. In the RECEIVE state, it will shift the received bits 
into the out_byte register, least significant bit first. After receiving all 8 data bits, it 
will transition to the VERIFY_STOP state. If the stop bit is correct in the VERIFY_STOP state, 
it will assert the done signal and transition back to the IDLE state. If the stop bit is not 
correct in the VERIFY_STOP state, it will transition to the INVALID state. In the INVALID 
state, it will wait until a stop bit is detected before transitioning back to the IDLE state. 
The FSM will also have a synchronous reset that will reset the FSM to the IDLE state when 
asserted.
