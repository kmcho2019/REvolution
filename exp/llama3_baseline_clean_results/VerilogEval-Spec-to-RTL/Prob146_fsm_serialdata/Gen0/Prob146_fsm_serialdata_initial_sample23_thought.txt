To implement the serial byte receiver, we can design a finite state machine (FSM) that transitions through several states based on the input stream. The states can be: IDLE (waiting for a start bit), START_BIT (receiving the start bit), DATA_BITS (receiving the data bits), STOP_BIT (waiting for the stop bit), and ERROR (when the stop bit is not received as expected). We will also need a counter to keep track of the current data bit being received and a register to store the received data byte. The `out_byte` will be updated when the stop bit is correctly received, and the `done` signal will be asserted at this time as well.
