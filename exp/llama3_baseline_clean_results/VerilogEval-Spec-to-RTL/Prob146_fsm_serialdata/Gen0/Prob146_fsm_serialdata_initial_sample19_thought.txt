To solve this problem, we can design a finite state machine (FSM) with the following states: IDLE, START, DATA, and STOP. The FSM will start in the IDLE state, waiting for the start bit. When the start bit is detected, the FSM will transition to the START state. Then, it will wait for 8 data bits, shifting them into the out_byte register, and transition to the DATA state. After receiving all 8 data bits, the FSM will wait for the stop bit and transition to the STOP state. If the stop bit is correct, the FSM will assert the done signal and transition back to the IDLE state. If the stop bit is not correct, the FSM will wait until it finds a stop bit before transitioning back to the IDLE state. We will use a counter to keep track of the number of data bits received.
