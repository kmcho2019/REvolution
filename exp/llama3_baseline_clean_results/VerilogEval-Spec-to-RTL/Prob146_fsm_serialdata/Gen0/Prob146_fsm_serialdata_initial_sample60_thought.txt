To implement the TopModule, we'll design a finite state machine (FSM) with the following states:
- IDLE: The initial state where the module waits for a start bit (0) on the input line.
- START: After detecting the start bit, the module moves to this state and starts counting the data bits.
- DATA: In this state, the module collects the 8 data bits and stores them in the out_byte register.
- STOP: After collecting all 8 data bits, the module moves to this state and checks for the stop bit (1).
- INVALID: If the stop bit is not detected when expected, the module moves to this state and waits until it finds a stop bit before returning to the IDLE state.

The FSM will use a counter to keep track of the number of data bits collected and a register to store the out_byte value. The done signal will be asserted when the module is in the STOP state and the stop bit is valid.

The module will be designed with a synchronous reset, which means that the reset signal will be active-high and will reset the module on the positive edge of the clock.
