To implement the TopModule, we can use a finite state machine (FSM) that goes through the following states: 
- IDLE: waiting for the start bit
- START: start bit detected, waiting for data bits
- DATA: receiving data bits
- STOP: waiting for the stop bit
- ERROR: invalid stop bit, waiting for a stop bit before going back to IDLE

We will use a counter to keep track of the current bit position in the byte. When the FSM is in the DATA state, we will shift the input bit into the out_byte register from the least significant bit to the most significant bit.

Once we reach the STOP state, we will check if the stop bit is correct. If it is, we will assert the done signal and update the out_byte register. If not, we will go to the ERROR state and wait for a stop bit before going back to the IDLE state.

We will also include an active-high synchronous reset to reset the FSM and the out_byte register.
