To solve this problem, I will design a finite state machine (FSM) that has four main states: IDLE, START, DATA, and STOP. The FSM starts in the IDLE state, waiting for a start bit (0) to be detected. Once a start bit is detected, it transitions to the START state. Then it shifts the input bits into a byte variable for 8 clock cycles in the DATA state. After the 8 bits are received, it transitions to the STOP state to verify the stop bit (1). If the stop bit is valid, it outputs the received byte and asserts the done signal. If the stop bit is not valid, it remains in the STOP state until a stop bit is detected before transitioning back to the IDLE state to receive the next byte.
