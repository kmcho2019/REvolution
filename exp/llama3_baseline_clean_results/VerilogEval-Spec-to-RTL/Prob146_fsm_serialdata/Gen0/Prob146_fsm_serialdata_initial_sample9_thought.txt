The design of the TopModule will be based on a finite state machine (FSM) with the following states:
- IDLE: Waiting for the start bit (0) to be received.
- RECEIVE_DATA: Receiving the 8 data bits. 
- STOP: Waiting for the stop bit (1) to be received.
- DONE: Asserting the done signal and outputting the received byte.

The FSM will transition from IDLE to RECEIVE_DATA when a start bit is received. 
It will then receive the 8 data bits in the RECEIVE_DATA state, shifting them into the output byte register. 
After receiving all 8 data bits, it will transition to the STOP state to wait for the stop bit. 
If the stop bit is correctly received, it will transition to the DONE state, where it will assert the done signal and output the received byte. 
If the stop bit is not correctly received, it will stay in the STOP state until a stop bit is received, then transition to the DONE state. 
After asserting the done signal, it will transition back to the IDLE state to wait for the next start bit.
The FSM will also be reset to the IDLE state when the reset signal is high.
