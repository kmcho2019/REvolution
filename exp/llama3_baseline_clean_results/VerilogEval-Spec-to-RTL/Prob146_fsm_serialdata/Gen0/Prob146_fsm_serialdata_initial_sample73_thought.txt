The TopModule will be designed as a finite state machine (FSM) with several states to manage the receipt of bytes from the serial stream. The states are: IDLE (waiting for a start bit), START (start bit detected), DATA (receiving the 8 data bits), STOP (waiting for the stop bit), and ERROR (handling incorrect stop bit). When the module is in the IDLE state, it checks for a start bit (0) on the input stream. If a start bit is detected, it transitions to the START state. Then, it waits for 8 clock cycles to receive the 8 data bits in the DATA state, storing them in a register. After receiving the data bits, it transitions to the STOP state to wait for the stop bit (1). If the stop bit is correct, it transitions back to the IDLE state and asserts the done signal, outputting the received byte on out_byte. If the stop bit is incorrect, it stays in the ERROR state until a stop bit (1) is detected, then transitions back to the IDLE state.
