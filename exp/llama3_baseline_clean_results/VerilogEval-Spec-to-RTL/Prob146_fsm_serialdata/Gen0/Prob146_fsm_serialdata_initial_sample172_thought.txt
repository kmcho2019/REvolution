To solve this problem, we can design a finite state machine (FSM) with the following states:
1. IDLE: The initial state where the FSM waits for the start bit (0) to be received.
2. RECEIVE: After receiving the start bit, the FSM enters this state and starts receiving the data bits.
3. STOP: After receiving all 8 data bits, the FSM enters this state to check the stop bit.
We will use a counter to keep track of the number of bits received and a register to store the received data byte.
When the FSM is in the RECEIVE state, it will shift the received bit into the data register and increment the counter.
Once the stop bit is verified, the FSM will assert the done signal and output the received data byte.
If the stop bit does not appear when expected, the FSM will wait until it finds a stop bit before attempting to receive the next byte.
We will use an active-high synchronous reset to reset the FSM to the IDLE state.
