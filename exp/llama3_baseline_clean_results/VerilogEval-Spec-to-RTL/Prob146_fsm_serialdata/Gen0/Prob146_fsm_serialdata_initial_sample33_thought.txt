To solve this problem, we will design a finite state machine (FSM) with the following states:
1. IDLE: This is the initial state, where the FSM waits for a start bit.
2. RECEIVE_BYTE: In this state, the FSM receives the 8 data bits of the byte.
3. VERIFY_STOP: After receiving the 8 data bits, the FSM checks if the stop bit is correct.
The FSM will transition from IDLE to RECEIVE_BYTE when a start bit (0) is detected.
It will then receive the 8 data bits, shifting them into the output byte register.
After receiving the 8 data bits, it will transition to VERIFY_STOP to check the stop bit.
If the stop bit is correct (1), the FSM will assert the done signal and transition back to IDLE.
If the stop bit is incorrect, the FSM will wait until it finds a stop bit before transitioning back to IDLE.
The FSM will also include an active-high synchronous reset, which will reset the FSM to the IDLE state when asserted.
