To implement this serial byte receiver module, we need a finite state machine (FSM) that can track the different stages of receiving a byte: idle, start bit detection, data bit collection, and stop bit verification. The FSM should be designed to handle errors such as missing stop bits and should only output a valid byte when a complete transmission has been successfully received. 

The module will have the following states:
- Idle: Wait for a start bit (0) on the input stream.
- Start: Check if the input is 0, then move to collect data bits.
- Collect: Shift in each incoming bit into a byte register for 8 cycles.
- Verify: Check if the stop bit is 1 after the data bits, if so, output the byte and assert done.

A counter will be needed to track how many bits have been collected during the Collect state. If at any point the expected stop bit does not appear, the FSM should return to the idle state, waiting for a new start bit, but only after it encounters a stop bit (1) to ensure proper synchronization.

The FSM will also have to deal with the synchronous reset, which will return the FSM to the idle state and clear any currently being collected byte when activated.
