To implement the required finite state machine (FSM), we'll define states to track the reception of the start bit, data bits, and stop bit. The FSM will transition between these states based on the input 'in' and will assert 'done' when a complete byte is received. We'll use a counter to keep track of the bit position within the byte. When 'reset' is high, the FSM should reset to its initial state. The 'out_byte' will be updated with the received data byte when 'done' is asserted.
