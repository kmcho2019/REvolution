The FSM will start in the idle state and transition to the start state when it detects a start bit (0). Then, it will transition to the data state and wait for 8 bits, during which it will store the bits in a register. After receiving all 8 bits, it will transition to the stop state and verify that the stop bit is correct (1). If the stop bit is correct, it will assert the done signal and output the received byte. If the stop bit is not correct, it will stay in the stop state until it receives a stop bit (1) and then transition back to the idle state. The FSM will also have a reset state that will reset the FSM to the idle state when the reset signal is high.
