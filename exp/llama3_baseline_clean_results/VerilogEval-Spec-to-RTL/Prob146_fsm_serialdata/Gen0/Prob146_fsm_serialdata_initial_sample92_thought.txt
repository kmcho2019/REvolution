To solve this problem, we will implement a finite state machine with the following states:
1. IDLE: Waiting for the start bit (0).
2. START: Found the start bit, waiting for the 8 data bits.
3. DATA: Collecting the 8 data bits.
4. STOP: Waiting for the stop bit (1).
We will use a counter to count the number of data bits received and a shift register to store the received data bits.
When the stop bit is found, we will assert the done signal and output the received data byte.
If the stop bit does not appear when expected, the FSM will wait until it finds a stop bit before attempting to receive the next byte.
