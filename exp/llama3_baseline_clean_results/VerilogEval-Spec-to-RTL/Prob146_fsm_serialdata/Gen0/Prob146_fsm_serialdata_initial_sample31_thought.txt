To solve this problem, we can design a finite state machine (FSM) with several states to track the reception of the start bit, data bits, and stop bit. The FSM should have the following states:
- Idle: Wait for the start bit (0) to be received.
- Start: Received the start bit, now wait for the 8 data bits.
- Data: Receive the 8 data bits, shifting the received bits into the out_byte register from the least significant bit to the most significant bit.
- Stop: Received the 8 data bits, now wait for the stop bit (1) to be received.
- Done: Received the stop bit, now output the received data byte and assert the done signal.

The FSM should also handle the case where the stop bit does not appear when expected. In this case, the FSM should remain in the Stop state until a stop bit is received, at which point it should transition to the Done state and then back to the Idle state.

We will use a counter to keep track of the number of data bits received, and a register to store the received data byte. The done signal will be asserted when the FSM is in the Done state.
