To solve this problem, we need to design a finite state machine (FSM) that can identify the start bit, receive 8 data bits, and verify the stop bit. The FSM should have the following states:
- Idle: Wait for the start bit (0) to be received.
- Receive: Receive 8 data bits and store them in the out_byte register. The bits are received least significant bit first.
- Stop: Verify that the stop bit (1) is received. If it is not received, the FSM should wait until a stop bit is received before returning to the idle state.
- Done: Assert the done signal when a stop bit is received, and output the received data byte.

We will use a 2-bit state register to encode these four states. The FSM will transition from one state to another based on the current state and the input bits.
