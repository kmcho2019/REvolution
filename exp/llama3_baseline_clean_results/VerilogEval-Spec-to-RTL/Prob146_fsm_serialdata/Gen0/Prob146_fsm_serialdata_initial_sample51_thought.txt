To implement the TopModule, we will use a finite state machine with the following states: 
- IDLE: The initial state where the module waits for a start bit (0).
- DATA: The state where the module receives the 8 data bits.
- STOP: The state where the module verifies the stop bit (1) and asserts the done signal.
The module will use a counter to keep track of the number of data bits received. 
When a start bit is detected, the module transitions to the DATA state and starts receiving data bits. 
When all 8 data bits are received, the module transitions to the STOP state and verifies the stop bit. 
If the stop bit is correct, the module asserts the done signal and transitions back to the IDLE state. 
If the stop bit is not correct, the module waits for a stop bit (1) before transitioning back to the IDLE state.
