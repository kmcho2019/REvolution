To solve this problem, we can design a finite state machine (FSM) with four states: IDLE, START, DATA, and STOP. 

- The IDLE state waits for the start bit (0) to be detected. 
- Once the start bit is detected, the FSM transitions to the START state, where it waits for one clock cycle before transitioning to the DATA state.
- In the DATA state, the FSM collects 8 data bits (least significant bit first) and stores them in the `out_byte` register.
- After collecting all 8 data bits, the FSM transitions to the STOP state, where it checks the stop bit. 
- If the stop bit is correct (1), the FSM asserts the `done` signal and transitions back to the IDLE state. 
- If the stop bit is incorrect (0), the FSM stays in the STOP state until it detects a stop bit (1), then transitions back to the IDLE state.

We will use a counter to keep track of the number of data bits collected and a register to store the received data byte.
