To solve this problem, we will design a finite state machine (FSM) with the following states:
- IDLE: This is the initial state where the FSM waits for a start bit.
- RECEIVE_DATA: In this state, the FSM receives the 8 data bits.
- VERIFY_STOP: After receiving the 8 data bits, the FSM verifies the stop bit.

We will use a counter to keep track of the number of data bits received and a shift register to store the received data bits.
When the stop bit is verified, the FSM asserts the done signal and outputs the received data byte.
If the stop bit is not verified, the FSM remains in the VERIFY_STOP state until it receives a stop bit, at which point it transitions back to the IDLE state.
We will also include an active-high synchronous reset to reset the FSM to the IDLE state.
