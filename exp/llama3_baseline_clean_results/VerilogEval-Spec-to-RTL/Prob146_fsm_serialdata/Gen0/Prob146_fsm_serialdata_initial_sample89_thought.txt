To implement the TopModule, we can design a finite state machine (FSM) with the following states:
- IDLE: waiting for the start bit
- START: waiting for the data bits
- DATA: shifting in the data bits
- STOP: waiting for the stop bit
- DONE: outputting the received byte and asserting done

We will use a counter to keep track of the number of data bits received and a shift register to store the received byte. The FSM will transition between states based on the input bit and the current state. The done signal will be asserted when the stop bit is received correctly.

We will also include an active-high synchronous reset to reset the FSM to the IDLE state when reset is high.
