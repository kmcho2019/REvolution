To implement the TopModule with the given interface and requirements, 
we can design a finite state machine (FSM) with the following states:
- IDLE: Wait for the start bit (0) to initiate the reception of a byte.
- RECEIVE_BYTE: Shift in the 8 data bits.
- VERIFY_STOP: Verify the stop bit (1) after receiving the 8 data bits.
The FSM will transition between these states based on the input 'in' and 
will output the received byte and assert 'done' when a stop bit is 
received. The module will also include an active-high synchronous reset.
