The FSM will transition from the idle state to the start state when it detects a start bit (0). It will then transition to the data state and wait for 8 clock cycles to collect all the data bits. After collecting all the data bits, it will transition to the stop state and verify the stop bit. If the stop bit is correct, it will assert the done signal and output the received data byte. If the stop bit is incorrect, it will wait until it detects a stop bit before transitioning back to the idle state. We will use a counter to keep track of the number of data bits collected.
