To solve this problem, we will design a finite state machine (FSM) with the following states: 
1. Idle: The initial state where the FSM waits for a start bit (0) to appear on the input stream.
2. Receiving Byte: Once a start bit is detected, the FSM transitions to this state and starts receiving the data bits.
3. Check Stop Bit: After receiving all 8 data bits, the FSM checks if the stop bit (1) is present.
If the stop bit is correct, the FSM asserts the done signal and outputs the received byte.
If the stop bit is incorrect, the FSM waits for a stop bit before transitioning back to the idle state.

We will use a counter to keep track of the number of bits received so far.
The FSM will also handle the synchronous reset by resetting the state, counter, and output signals when the reset signal is high.
