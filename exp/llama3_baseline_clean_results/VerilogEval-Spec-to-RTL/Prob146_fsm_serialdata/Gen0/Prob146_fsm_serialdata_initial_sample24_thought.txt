To solve this problem, we can design a finite state machine (FSM) that goes through several states to detect the start bit, receive the 8 data bits, and verify the stop bit. The FSM will have the following states:
- IDLE: Wait for the start bit (0) to be received.
- START: The start bit has been detected, wait for the first data bit.
- DATA: Receive the 8 data bits.
- STOP: Verify the stop bit (1) is received after the data bits.
- DONE: Assert done and output the received data byte.

We will use a counter to keep track of the number of data bits received and a shift register to store the received data bits. When the FSM is in the DATA state, we will shift the received data bit into the shift register. When the stop bit is verified, we will assert done and output the received data byte.
