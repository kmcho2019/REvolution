To implement the TopModule, we will create a finite state machine (FSM) that has several states: Idle, Start, Data, and Stop. 
The FSM starts in the Idle state, waiting for the start bit (0). When the start bit is detected, it transitions to the Start state, 
then to the Data state where it shifts in the 8 data bits, and finally to the Stop state where it checks the stop bit. 
If the stop bit is correct (1), it asserts the done signal and outputs the received byte. 
If the stop bit is incorrect, it waits until it finds a stop bit before attempting to receive the next byte. 
The FSM will also be reset to the Idle state when the reset signal is asserted.
