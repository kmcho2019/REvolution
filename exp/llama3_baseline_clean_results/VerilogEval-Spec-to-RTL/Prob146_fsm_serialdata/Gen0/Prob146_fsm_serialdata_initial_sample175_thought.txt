To solve this problem, we can design a finite state machine (FSM) with the following states: 
- Idle: waiting for a start bit
- Receive: receiving the 8 data bits
- Verify: verifying the stop bit
The FSM starts in the Idle state. When it detects a start bit (in = 0), it transitions to the Receive state. 
In the Receive state, it shifts the received bits into a register and waits for 8 bits. 
After receiving 8 bits, it transitions to the Verify state to check the stop bit. 
If the stop bit is correct (in = 1), it asserts the done signal and outputs the received byte. 
If the stop bit is not correct, it remains in the Verify state until it detects a stop bit. 
A synchronous reset is used to reset the FSM to the Idle state.
