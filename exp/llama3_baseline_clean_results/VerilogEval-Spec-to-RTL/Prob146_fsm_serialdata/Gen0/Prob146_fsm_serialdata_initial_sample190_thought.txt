To solve this problem, we need to design a finite state machine (FSM) that can identify the start bit, wait for the data bits, and verify the stop bit. The FSM should have the following states: 
- IDLE: Waiting for the start bit.
- START: Found the start bit, waiting for data bits.
- DATA: Receiving data bits.
- STOP: Waiting for the stop bit.
- DONE: Found the stop bit, assert done and output the received byte.

We will use a counter to keep track of the number of data bits received. When the counter reaches 8, we transition to the STOP state. If the stop bit is not found in the STOP state, we transition back to the IDLE state. The FSM should also be able to handle the synchronous reset.
