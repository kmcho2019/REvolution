To implement a 4-bit binary counter in Verilog, we can use a register to store the current count and a variable to hold the next count. The counter should increment on every positive edge of the clock, wrapping around from 15 back to 0 after reaching the maximum count. When the reset signal is high, the counter should be reset to 0 synchronously with the clock. This means we check for the reset condition at the same time we're checking for the clock edge, ensuring the reset occurs in the same clock cycle if both conditions are met.
