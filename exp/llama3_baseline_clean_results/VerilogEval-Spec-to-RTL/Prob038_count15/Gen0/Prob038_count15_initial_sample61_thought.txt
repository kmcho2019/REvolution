The TopModule should implement a 4-bit binary counter. This means it should have a register to hold the current count value. On every positive edge of the clock, the counter should increment its value unless it's already at the maximum value (15), in which case it should wrap around to 0. Additionally, if the reset input is high, the counter should reset to 0 on the next positive edge of the clock. This can be achieved using a 4-bit register and a conditional increment statement. The output q should always reflect the current value of the counter.
