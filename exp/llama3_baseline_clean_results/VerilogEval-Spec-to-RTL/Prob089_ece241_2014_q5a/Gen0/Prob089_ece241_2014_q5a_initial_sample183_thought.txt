To implement a one-input one-output serial 2's complementer Moore state machine, 
we need to design a finite state machine (FSM) that can accept a series of bits 
and produce the 2's complement of the input. The FSM will have two states: 
Idle and Running. In the Idle state, the machine waits for the reset signal 
to be released. Once the reset is released, the machine moves to the Running 
state, where it starts accepting input bits and generating the output. The 
machine will use a register to store the current output and update it 
accordingly based on the input. When the reset is asserted again, the machine 
will move back to the Idle state and reset the output.
