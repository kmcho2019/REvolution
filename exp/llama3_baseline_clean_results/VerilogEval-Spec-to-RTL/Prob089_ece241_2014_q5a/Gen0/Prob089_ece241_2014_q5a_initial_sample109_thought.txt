To implement the 2's complementer Moore state machine, we need to keep track of the current state (normal or invert) and the accumulated sum of the input bits. We start in the normal state and accumulate the bits until we encounter a '1' which would indicate we need to invert the rest of the bits. Once we are in the invert state, we invert each incoming bit and output it. We use an asynchronous reset to reset the state and the sum when the reset is asserted.
