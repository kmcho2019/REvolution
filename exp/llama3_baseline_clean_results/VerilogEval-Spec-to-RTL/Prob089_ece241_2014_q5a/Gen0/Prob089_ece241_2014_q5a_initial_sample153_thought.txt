To implement a one-input one-output serial 2's complementer Moore state machine, we need to design a finite state machine that can process the input bits one by one, calculate the 2's complement, and output the result. 

The 2's complement of a binary number can be obtained by inverting all bits and then adding 1. 

We can implement this using two states: 'IDLE' and 'COMPLEMENT'. 

When reset is released, the machine moves from 'IDLE' state to 'COMPLEMENT' state and starts processing the input bits. 

In the 'COMPLEMENT' state, the machine inverts each input bit and adds it to a running sum (which initially contains the carry from the previous bit, if any). If the current bit is the least significant bit (i.e., the first bit), the machine sets a carry flag to 1 if the input bit is 1 (for the 2's complement addition). 

The machine stays in the 'COMPLEMENT' state as long as the reset is not asserted. When the reset is asserted, the machine returns to the 'IDLE' state.

The output is the complement of the input if we are in 'COMPLEMENT' state and the reset is not asserted, otherwise, it is 0.

To handle numbers of arbitrary length, the machine does not have a fixed number of states, but rather, it stays in the 'COMPLEMENT' state until reset is asserted.
