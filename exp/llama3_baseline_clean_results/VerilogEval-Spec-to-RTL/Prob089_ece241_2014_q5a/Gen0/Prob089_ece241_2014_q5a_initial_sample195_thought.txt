To design a one-input one-output serial 2's complementer Moore state machine, we need to implement the following states and transitions:
- An initial state (IDLE) that waits for the reset signal to be released.
- A state ( OnesComplement ) where the machine reads the input bits and accumulates their 1's complement.
- A state (TwosComplement) where the machine outputs the accumulated 1's complement and then waits for the next reset signal.
However, a Moore machine's output is dependent on the current state only, and to implement the described functionality we must create an additional internal state that signifies the start of the conversion. Hence we use the following states:
- IDLE: Initial state, machine waits for reset to be released.
- OnesComplement: Machine accumulates the 1's complement of the input bits.
- TwosComplement: Outputs the 2's complement of the input bits.

We need to use a sequential logic to store the accumulated bits, and a conditional statement to determine the next state.
Additionally, to detect the end of the input sequence, we can't rely on a specific length, hence we will consider the sequence to end when the reset is asserted again.
