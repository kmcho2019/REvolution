The TopModule can be designed as a Moore state machine with two states: idle and convert. 
When areset is high, the module is in reset state and does nothing. 
When areset goes low, the module starts accepting input bits and begins the conversion. 
We will use a register to store the accumulated input bits and another register to store the sign bit (most significant bit) of the input number.
We will also use a flag to track whether the most significant bit has been encountered yet.
The 2's complement is generated by inverting the bits and adding 1 when the most significant bit is 1.
