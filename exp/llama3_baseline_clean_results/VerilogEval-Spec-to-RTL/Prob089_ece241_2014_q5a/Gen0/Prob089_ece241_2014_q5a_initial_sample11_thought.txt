To implement a serial 2's complementer Moore state machine, we can use a finite state machine (FSM) with two states: idle and complementing. When the reset is released, the machine starts in the idle state. In this state, it waits for input bits. Once it receives a '1' (indicating the start of the 2's complement operation), it transitions to the complementing state. In the complementing state, it outputs the inverse of the input bits until it encounters a '0', at which point it transitions back to the idle state and outputs '0's. However, this description would result in a Mealy machine, so we will adjust our approach to fit a Moore machine.

For a Moore machine, the outputs are determined solely by the state. Thus, we can think of our machine as having states that remember whether we are currently complementing the input (and have seen a '1') or not, and an additional register to keep track of the carry bit for the 2's complement operation.

We initialize our machine in an idle state with the carry bit set to '0'. Upon receiving a '1' on the input while in the idle state, we transition to the complementing state and set our output to '1' because the 2's complement of any number starts with a '1' if the input number is not zero. We maintain the complementing state as long as we are receiving '1's on the input, with each '1' inverting the current carry bit and setting our output based on this inverted carry. If we receive a '0', we simply output the inverted carry without changing the state, effectively treating the '0' as part of the number being complemented and continuing the complement operation.

However, a simpler approach to achieve a Moore machine that implements a serial 2's complementer involves using a single flip-flop to remember whether we are in the process of computing the 2's complement (i.e., we've seen at least one '1'), and another flip-flop to keep track of the carry bit for the 2's complement operation.

When reset is asserted, both flip-flops are reset to '0'. When the reset is released, and we receive '1' on the input, the flip-flop indicating we are in the complementing process is set to '1'. From then on, for every input '1', we simply invert the carry flip-flop and output its inverted value (which represents the 2's complement of the input number up to that point), and for every '0', we also invert the carry and output its value but do not change the state, because in 2's complement, a '0' simply means we continue with the operation without changing the state but do change the output based on the carry.
