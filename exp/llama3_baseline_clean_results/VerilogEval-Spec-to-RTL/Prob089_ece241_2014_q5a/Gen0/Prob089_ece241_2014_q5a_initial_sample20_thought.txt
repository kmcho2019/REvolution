The TopModule will implement a Moore state machine with two states: an idle state and a running state. 
In the idle state, the machine waits for the release of the asynchronous reset signal (areset). 
Once the reset is released, the machine transitions to the running state and starts accepting input bits. 
It accumulates the input bits to form a binary number, and then produces the 2's complement of this number 
at the output (z). 
The 2's complement of a binary number can be obtained by flipping all the bits of the number and adding 1. 
However, since the input is provided one bit per clock cycle, starting from the least significant bit, 
the machine will have to accumulate the input bits and flip them as it accumulates them, 
and then add 1 to get the final 2's complement. 
The machine will have a flip-flop to store the carry from the addition. 
The machine will remain in the running state until the reset signal (areset) is asserted again.
