To implement the serial 2's complementer Moore state machine, we need to consider the following steps:
1. The machine starts in a reset state and waits for the reset to be released.
2. Once the reset is released, it enters the "accumulate" state where it accumulates the bits of the input number.
3. When a bit is input, it is added to the current sum.
4. If the most significant bit (MSB) is 1, then the machine enters the "complement" state, where it calculates the 2's complement of the accumulated number by flipping all the bits and adding 1.
5. The machine then outputs the 2's complement bit by bit from MSB to LSB.
6. The conversion stops when the reset is asserted.

However, since the machine needs to handle numbers of arbitrary length, it must keep track of when to stop accumulating bits and start complementing and outputting. 
One approach is to wait for the reset to be asserted to stop the conversion and start over.

We can use a finite state machine with three states: reset, accumulate, and output.
We will use a register to accumulate the input number and another register to store the 2's complement.
