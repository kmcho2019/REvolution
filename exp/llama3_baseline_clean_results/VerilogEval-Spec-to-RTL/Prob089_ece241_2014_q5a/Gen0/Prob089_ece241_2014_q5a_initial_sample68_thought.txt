To implement the one-input one-output serial 2's complementer Moore state machine, we need to design a finite state machine (FSM) with the following states:
- IDLE: Initial state, waits for reset to be released.
- SIGN: Checks the most significant bit of the input number to determine if it's negative.
- COUNT: Counts the number of bits until the most significant bit (MSB) is encountered, then starts inverting the bits.
- OUTPUT: Outputs the inverted bits after the MSB is encountered.

We will use two registers to store the current state and the output value.
