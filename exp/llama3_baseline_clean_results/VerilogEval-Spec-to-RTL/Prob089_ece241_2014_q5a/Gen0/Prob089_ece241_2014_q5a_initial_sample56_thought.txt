The 2's complement of a binary number can be obtained by flipping all the bits of the number and then adding 1. We can achieve this by maintaining a running sum of the input bits. When the reset is released, we start accepting input bits and calculate the 2's complement. We maintain a flip flag to track whether we have seen the first 1 in the input. If we have, we start flipping the bits. After the first 1, we also start adding 1 to the running sum for each subsequent 1 in the input. The output is the current bit of the running sum. When the reset is asserted, we stop the conversion and reset the state machine.
