The Moore state machine will have two states: idle and convert. The machine starts in the idle state and transitions to the convert state when reset is released. In the convert state, it accumulates the input bits, inverting the most significant bits if the first bit is 1 (indicating a negative number in 2's complement representation), and outputting the 2's complement bits. When reset is asserted, it returns to the idle state. We will use a register to store the accumulated bits and another register to store the output bits.
