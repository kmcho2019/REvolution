The design idea is to implement a Moore state machine with two states: IDLE and RUNNING. The machine starts in the IDLE state when reset is asserted. When reset is de-asserted, the machine transitions to the RUNNING state and starts accepting input bits. In the RUNNING state, the machine will complement the input bits and store them in a shift register. When reset is asserted again, the machine will return to the IDLE state and clear the output. The output will be the 2's complement of the input, which is obtained by inverting all bits and adding 1. This can be achieved by adding 1 to the inverted input bits when the machine returns to the IDLE state.
