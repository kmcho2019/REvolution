To implement a serial 2's complementer Moore state machine, we need to consider two states: one for accumulating the input bits and another for inverting and adding 1 to get the 2's complement. Since the input numbers can be of arbitrary length, we will keep track of whether we are currently inverting or adding. The circuit starts in an idle state and begins accumulating input bits when reset is released. When reset is asserted again, the circuit stops and returns to the idle state. The output will be the current bit of the 2's complemented number in each clock cycle after the conversion starts.
