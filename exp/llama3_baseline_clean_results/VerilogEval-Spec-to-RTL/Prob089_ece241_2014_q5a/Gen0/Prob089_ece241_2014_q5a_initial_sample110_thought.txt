To implement the 2's complementer Moore state machine, we will use two states: Idle and Running. In the Idle state, the machine waits for the reset to be released and the first input bit to arrive. Once in the Running state, the machine accumulates the input bits to form the binary number, and when the reset is asserted again, it enters the Idle state and outputs the 2's complement of the accumulated number. However, the Moore machine will output the 2's complement bit-by-bit as it receives the input bits. We will maintain a running sum of the input bits and at each clock cycle, output the inverse of the input bit if the running sum is odd (indicating a '1' in the 2's complement representation), otherwise output the input bit itself.

A key point to note here is that for a Moore machine, the output is a function of the current state only, but in our implementation, we need to maintain a running sum (which is a function of the previous inputs and the current state), hence we will need to maintain an internal register to store this sum.
