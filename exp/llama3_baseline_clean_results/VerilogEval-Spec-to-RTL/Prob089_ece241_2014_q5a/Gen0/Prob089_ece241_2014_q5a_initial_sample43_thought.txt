To implement a serial 2's complementer Moore state machine, we can follow these steps:
1. Initialize the machine with a reset signal to ensure it starts in a known state.
2. Detect the first '1' input after the reset, which indicates the start of the number.
3. Invert all the bits that follow until the next reset.
4. Output the inverted bits, starting from the least significant bit.
5. To ensure the 2's complement, after the first '1' is detected, the machine should output the inverted bits and remember the sign of the input (i.e., whether it's negative or positive) to correctly calculate the 2's complement.

We will use two states: 'idle' (waiting for the first '1' after reset) and 'run' (converting the input number).
