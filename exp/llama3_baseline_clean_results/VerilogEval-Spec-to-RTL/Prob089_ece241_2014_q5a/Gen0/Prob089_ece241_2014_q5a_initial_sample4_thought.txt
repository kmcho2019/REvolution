The TopModule will be implemented as a Moore state machine with two states: idle and convert. 
When the reset is released, the machine transitions to the convert state and starts 
accepting input bits. The machine will invert all input bits and add 1 to the result 
to obtain the 2's complement. The conversion process continues until the reset is asserted 
again. The output (z) will be the 2's complement of the input (x) for each clock cycle 
once the conversion is complete for that bit position. We will use a register to store 
the result and update it at each clock cycle.
