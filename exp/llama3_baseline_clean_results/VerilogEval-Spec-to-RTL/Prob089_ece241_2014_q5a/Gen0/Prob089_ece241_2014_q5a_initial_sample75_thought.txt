To implement the Moore state machine, we need to track the current state of the machine, which is either idle (waiting for the reset to be released), or in the process of converting the input number. The state machine will have two main states: IDLE and CONVERT. In the IDLE state, the machine will wait for the reset to be released, and once released, it will transition to the CONVERT state. In the CONVERT state, the machine will keep track of the bits it has seen so far and their inversion, and it will output the 2's complement of the input number. We will use a flip-flop to store the current state and the bits seen so far. When the reset is asserted, the machine will transition back to the IDLE state, and the output will be reset. The conversion will stop when the reset is asserted.
