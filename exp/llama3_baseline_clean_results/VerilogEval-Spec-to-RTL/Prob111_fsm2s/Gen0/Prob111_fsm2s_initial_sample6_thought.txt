The Moore state machine has two states: OFF and ON. It starts in the OFF state and moves to the ON state when j = 1. Once in the ON state, it stays there as long as k = 0, and moves back to the OFF state when k = 1. The reset input should be used to synchronously reset the state machine to the OFF state. We can use a 1-bit register to represent the current state, with 0 corresponding to the OFF state and 1 corresponding to the ON state. The next state logic can be implemented using a simple conditional statement.
