To implement the Moore state machine as described, we first define the states and the corresponding output values. We then describe the state transitions based on the input values j and k. The reset signal is used to synchronize the state machine to the OFF state when it is high. We can use a two-state variable (e.g., 1-bit reg) to keep track of the current state. The next state logic is derived from the state transition diagram, and the output is determined solely by the current state.
