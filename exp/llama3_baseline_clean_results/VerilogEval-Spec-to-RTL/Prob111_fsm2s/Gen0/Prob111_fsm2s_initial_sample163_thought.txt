To implement the Moore state machine as described, we need to follow these steps:
1. Define the states (OFF and ON) and assign them binary values.
2. Use a case statement or if-else conditions to determine the next state based on the current state and input values.
3. Use a case statement or if-else conditions to determine the output value based on the current state.
4. Implement a synchronous reset to reset the state machine to the OFF state when the reset signal is high.

We will use a reg to hold the current state and another reg to hold the next state. The current state will be updated at every positive edge of the clock.
