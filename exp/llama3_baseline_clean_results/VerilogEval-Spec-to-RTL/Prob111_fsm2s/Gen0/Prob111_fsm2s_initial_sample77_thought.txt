To implement the Moore state machine as described, we first need to define the states (OFF and ON) and then use a switch statement in the always block to determine the next state and output based on the current state and inputs. We will use an enum to define the states for clarity and readability. The reset will be handled as a synchronous reset by adding it as a condition in the always block. The output will be determined solely by the current state, as this is a characteristic of a Moore state machine.
