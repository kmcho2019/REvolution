To implement the Moore state machine as described, we need to follow these steps:
1. Define the states (OFF and ON) and their corresponding output values.
2. Use a case statement inside a combinatorial logic block to determine the next state based on the current state and inputs.
3. Use a sequential logic block (always block) to update the current state based on the next state.
4. Assign the output based on the current state.
5. Handle the reset condition to set the state to OFF when reset is high.

We will use two parameters, OFF and ON, to represent the states and a reg variable to hold the current state.
