To implement the Moore state machine as described, we will first define the states and then use a combinational logic to determine the next state and the output based on the current state and the inputs. The two states will be represented by two bit binary numbers, OFF (00) and ON (01). The reset signal will be used to reset the state machine to the OFF state when it is high. 
We will use a case statement inside an always block to handle the state transitions and output based on the current state and inputs. 
For the state transition, we check the current state and the values of j and k to determine the next state.
For the output, since it is a Moore machine, the output only depends on the current state.
