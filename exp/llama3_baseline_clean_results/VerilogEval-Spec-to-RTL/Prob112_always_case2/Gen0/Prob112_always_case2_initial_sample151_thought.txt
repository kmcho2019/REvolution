To implement a 4-bit priority encoder, we can use a combination of logical operations and conditional statements. The idea is to check each bit of the input from left to right (most significant bit to least significant bit) and output the position of the first bit that is high. If none of the bits are high, output 0.

We can use the following logic:
- Check if the most significant bit (in[3]) is high, if so, output 11 (3 in binary).
- If the most significant bit is not high, check the next bit (in[2]), if it's high, output 10 (2 in binary).
- If neither of the above bits is high, check the next bit (in[1]), if it's high, output 01 (1 in binary).
- If none of the above bits is high, check the least significant bit (in[0]), if it's high, output 00 (0 in binary).
- If none of the bits are high, output 00 (0 in binary).
