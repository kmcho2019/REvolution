To implement a 4-bit priority encoder, we need to compare each bit of the input vector from most significant bit to least significant bit. As soon as we encounter a 1, we output its position. We can use a series of if-else statements to achieve this. We will use a 2-bit output (pos) to represent the position of the first 1 bit, with pos[1] being the most significant bit. The position is 0-indexed, meaning the most significant bit corresponds to position 0 and the least significant bit corresponds to position 3. If no 1 bit is found, the output will be 2'b00.
