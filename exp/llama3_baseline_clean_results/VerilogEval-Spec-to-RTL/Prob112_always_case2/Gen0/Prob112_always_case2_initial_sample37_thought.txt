To implement a 4-bit priority encoder, we can use a simple combinatorial logic. The idea is to check each bit of the input from most significant to least significant and output the position of the first bit that is 1. If none of the bits are 1, the output should be 0. This can be achieved using a series of if-else statements or a cascaded logic. We will use the if-else approach for simplicity. We assign the output `pos` to 0 initially and then check each bit of the input `in`. If the most significant bit is 1, we assign `pos` to 3. If not, we check the next bit and assign `pos` to 2 if it's 1, and so on. If none of the bits are 1, `pos` remains 0.
