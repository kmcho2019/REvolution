To implement a 4-bit priority encoder, we can use a series of conditional statements to check each bit of the input from most significant to least significant. As soon as we find a bit that is high (1), we output its position. If none of the bits are high, we output 0. This can be achieved using a simple if-else statement structure in Verilog.

We assign the position based on the index of the bit in the input vector, starting from 0 for the least significant bit. Since we need to output a 2-bit value to represent positions 0 to 3, we can directly use the index of the bit as the output value when a 1 is found.

Here's a step-by-step approach:
1. Check the most significant bit (in[3]). If it's 1, output 2'b11 (3 in decimal).
2. If not, check the next bit (in[2]). If it's 1, output 2'b10 (2 in decimal).
3. Continue this process for the remaining bits.
4. If none of the bits are 1, output 2'b00 (0 in decimal).

This approach ensures that the first 1 bit encountered from the most significant bit to the least significant bit determines the output, which is the essence of a priority encoder.
