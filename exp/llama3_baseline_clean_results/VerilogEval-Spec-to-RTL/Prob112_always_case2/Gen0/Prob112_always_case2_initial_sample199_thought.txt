The idea is to assign the highest priority to the most significant bit (MSB) and then check if it's '1'. If it's '1', we output its position. If not, we move to the next bit with the next highest priority. This process continues until we find a bit that is '1' or we've checked all bits. If all bits are '0', we output '0' as per the problem statement.

In Verilog, this logic can be implemented using if-else statements or a case statement. However, for simplicity and readability, we'll use if-else statements to prioritize each bit position.
