1. Check the most significant bit (in[3]). If it's 1, output 2'b11 (3).
2. If in[3] is 0, check the next bit (in[2]). If it's 1, output 2'b10 (2).
3. If in[2] is 0, check the next bit (in[1]). If it's 1, output 2'b01 (1).
4. If in[1] is 0, check the least significant bit (in[0]). If it's 1, output 2'b00 (0).
5. If none of the bits are 1, output 2'b00 (0).
