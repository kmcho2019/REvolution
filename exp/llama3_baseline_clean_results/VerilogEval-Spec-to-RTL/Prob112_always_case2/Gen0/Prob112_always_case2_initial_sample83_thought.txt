To implement a 4-bit priority encoder, we need to check the input bits from left to right (most significant bit to least significant bit) and output the position of the first 1 bit encountered. If no 1 bits are found, the output should be 0. We can use a simple combinational logic to achieve this. The position of the bits can be numbered as follows: in[3] = position 3, in[2] = position 2, in[1] = position 1, and in[0] = position 0. We can use Verilog's conditional operator to check each bit and assign the corresponding position to the output 'pos'.
