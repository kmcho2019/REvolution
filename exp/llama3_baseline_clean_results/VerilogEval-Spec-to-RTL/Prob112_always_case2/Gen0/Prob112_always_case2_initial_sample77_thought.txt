2. If in[3] is 0, check the next bit (in[2]). If it is 1, output 2'b10, representing position 2.
3. If in[2] is 0, check the next bit (in[1]). If it is 1, output 2'b01, representing position 1.
4. If in[1] is 0, check the least significant bit (in[0]). If it is 1, output 2'b00, representing position 0.
