- Check if the most significant bit (MSB) is 1, if so, output 11.
- If the MSB is 0, check the next bit, if it is 1, output 10.
- If the first two bits are 0, check the next bit, if it is 1, output 01.
- If the first three bits are 0, check the last bit, if it is 1, output 00.
- If all bits are 0, output 00.
