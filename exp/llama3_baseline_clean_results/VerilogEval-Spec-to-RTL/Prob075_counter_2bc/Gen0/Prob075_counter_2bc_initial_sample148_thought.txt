To implement the TopModule, we need to create a two-bit saturating counter. 
We will use a combinational logic to determine the next state of the counter 
based on the current state and the input signals. The counter will be 
incremented when train_valid and train_taken are both high, decremented when 
train_valid is high and train_taken is low, and remain unchanged when 
train_valid is low. The areset signal will asynchronously reset the counter 
to 2'b01 on its positive edge. 
We will use a two-bit reg to store the counter value and update it on each 
positive edge of the clock.
