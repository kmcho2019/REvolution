The module TopModule will implement a two-bit saturating counter. The counter will be controlled by the train_valid and train_taken inputs. When train_valid is high, the counter will either increment or decrement based on the value of train_taken. The counter will have a maximum value of 3 and a minimum value of 0. The areset input will be used to reset the counter to a value of 2'b01 (weakly not-taken) asynchronously. The state of the counter will be output on the state port. This will be achieved using a sequential logic circuit that is triggered on the positive edge of the clock.
