To implement the TopModule, we will use a two-bit register to store the counter value. On every positive edge of the clock, we will check the value of train_valid. If it is high, we will either increment or decrement the counter based on the value of train_taken. We will use a saturating counter, meaning the counter will not go below 0 or above 3. We will also implement an asynchronous reset to reset the counter to 2'b01 when areset is high.
