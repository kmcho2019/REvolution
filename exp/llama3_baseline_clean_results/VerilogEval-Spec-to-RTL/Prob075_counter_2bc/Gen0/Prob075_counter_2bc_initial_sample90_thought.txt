To implement the TopModule, we need to create a two-bit saturating counter. The counter should increment when train_valid and train_taken are both high, and decrement when train_valid is high but train_taken is low. When train_valid is low, the counter should remain unchanged. We will use an asynchronous reset to initialize the counter to a value of 1 (2'b01). We will use a register to store the current state of the counter and update it on the positive edge of the clock.
