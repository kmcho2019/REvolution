The problem can be solved by implementing a combinational circuit that uses the value of input c to select the output q from inputs a, b, d, or e. When c is 0, q should be b; when c is 1, q should be e; when c is 2, q should be a; when c is 3, q should be d; for any other value of c, q should be f (which is a don't care in this case but we can assign it to be the same as any of the inputs). 
We can achieve this using a case statement in Verilog.
