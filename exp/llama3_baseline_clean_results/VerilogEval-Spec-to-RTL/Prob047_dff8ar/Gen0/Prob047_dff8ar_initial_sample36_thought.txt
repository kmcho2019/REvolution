To implement the TopModule, we will use 8 D flip-flops (DFFs) with active high asynchronous reset. Each DFF will have a data input (d), a clock input (clk), an asynchronous reset input (areset), and a data output (q). The asynchronous reset will be used to reset the output (q) to 0. The DFFs will be triggered by the positive edge of the clock (clk). We will use the always_ff block in Verilog to implement the DFFs, which is suitable for describing sequential logic.
