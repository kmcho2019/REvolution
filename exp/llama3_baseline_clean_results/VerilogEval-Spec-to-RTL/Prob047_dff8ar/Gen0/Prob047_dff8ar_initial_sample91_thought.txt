To design the TopModule, we need to create a module that includes 8 D flip-flops, each with an active high asynchronous reset. The D flip-flops should be triggered by the positive edge of the clock (clk) and should reset the output to 0 when the asynchronous reset (areset) is high. We can achieve this by using the always_ff block in Verilog, which is specifically designed for sequential logic.
