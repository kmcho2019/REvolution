To implement the TopModule, we need to create 8 D flip-flops (DFFs) with active high asynchronous reset. Each DFF should be triggered by the positive edge of the clock signal (clk). The input data d is an 8-bit vector, and the output q should also be an 8-bit vector. When the asynchronous reset signal (areset) is high, the output q should be reset to all zeros. 
We will use the always_ff statement to model the sequential behavior of the DFFs, and the posedge clk to specify the clock trigger.
