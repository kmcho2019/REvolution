To implement the TopModule, we can use 8 D flip-flops (DFFs) in parallel, each with an active high asynchronous reset. The input data d will be connected to the D inputs of the DFFs, the clk will be connected to the clock input of each DFF, and the areset will be connected to the asynchronous reset input of each DFF. The outputs of the DFFs will be connected to the output q.
