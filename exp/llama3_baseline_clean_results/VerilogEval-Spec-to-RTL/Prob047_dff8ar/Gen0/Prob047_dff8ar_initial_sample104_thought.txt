To implement the TopModule, we need to create a module that includes 8 D flip-flops (DFFs) with active high asynchronous reset. Each DFF should be triggered by the positive edge of the clk signal. The input d is an 8-bit vector that will be used as the input to the DFFs, and the output q is also an 8-bit vector that will hold the current state of the DFFs. When the areset signal is high, all DFFs should be reset to 0, regardless of the current state of the clk signal.
