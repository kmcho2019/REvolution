To implement the TopModule, we need to create a module that includes 8 D flip-flops. Each D flip-flop should have an active high asynchronous reset, meaning when the reset signal (areset) is high, the output of the flip-flop should immediately be set to 0, regardless of the clock signal. The D flip-flops should be triggered by the positive edge of the clock signal (clk), updating their output with the value of their input (d) at that time.
