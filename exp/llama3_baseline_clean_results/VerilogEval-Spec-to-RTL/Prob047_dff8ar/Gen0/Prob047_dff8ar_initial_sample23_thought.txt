To implement the TopModule, we need to create 8 D flip-flops (DFFs) that are triggered by the positive edge of the clock signal (clk). Each DFF should have an asynchronous active-high reset, which means when the reset signal (areset) is high, the output of the DFF should be reset to 0, regardless of the clock signal. We can achieve this by using the reg data type to store the output of each DFF and using a always block to describe the behavior of the DFFs.
