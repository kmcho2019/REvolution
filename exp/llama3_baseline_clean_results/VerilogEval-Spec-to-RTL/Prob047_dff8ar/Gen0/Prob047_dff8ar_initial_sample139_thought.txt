To implement the TopModule, we need to create a module that contains 8 D flip-flops (DFFs) with active high asynchronous reset. Each DFF should be triggered by the positive edge of the clk signal. The output of each DFF will be connected to the corresponding output bit of the q port, and the input of each DFF will be connected to the corresponding input bit of the d port. We will use the always_ff block to describe the DFFs, and we will also use the posedge keyword to specify the positive edge of the clk signal as the trigger.
