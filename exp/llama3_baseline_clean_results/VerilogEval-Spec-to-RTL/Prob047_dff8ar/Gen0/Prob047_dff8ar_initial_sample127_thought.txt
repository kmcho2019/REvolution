To implement the TopModule, we can use 8 D flip-flops with asynchronous reset. 
Each D flip-flop will be connected to the input data 'd' and will have the 
output 'q'. The asynchronous reset will be connected to 'areset'. All DFFs 
will be triggered by the positive edge of the clock 'clk'. We will use the 
always_ff block to describe the sequential behavior of the D flip-flops.
