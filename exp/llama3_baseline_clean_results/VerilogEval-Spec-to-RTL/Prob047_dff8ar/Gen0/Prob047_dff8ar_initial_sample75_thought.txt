To implement the TopModule, we will use 8 D flip-flops (DFFs) with active high asynchronous reset. Each DFF will be triggered by the positive edge of the clock signal (clk) and will reset to 0 when the asynchronous reset signal (areset) is high. We will use the Verilog built-in DFF construct to create these flip-flops and assign the input data (d) to the input of the DFFs and the output of the DFFs to the output (q).
