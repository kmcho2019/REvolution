To implement the TopModule as specified, we need to create a module that includes 8 D flip-flops (DFFs) with active high asynchronous reset. Each DFF will have a data input (d), a clock input (clk), an asynchronous reset input (areset), and a data output (q). The DFFs should be triggered on the positive edge of the clock (clk) and should reset to 0 when the asynchronous reset (areset) is high. We will use the Verilog's built-in DFF module or create our own using a always block to describe this behavior.
