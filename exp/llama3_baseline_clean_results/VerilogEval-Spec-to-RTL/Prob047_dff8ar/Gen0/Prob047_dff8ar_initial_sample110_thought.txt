To implement the TopModule, we need to create 8 D flip-flops (DFFs) that are triggered by the positive edge of the clock (clk) and have an active high asynchronous reset. The output of each DFF should be reset to 0 when the areset signal is high. We will use the always_ff statement in Verilog to model the DFFs. The always_ff statement is used to describe sequential logic and is sensitive to the positive edge of the clock.
