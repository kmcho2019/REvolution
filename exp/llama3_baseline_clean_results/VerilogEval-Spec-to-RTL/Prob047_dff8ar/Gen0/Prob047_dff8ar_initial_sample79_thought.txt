To implement the TopModule, we need to create a module that includes 8 D flip-flops (DFFs) with asynchronous active high reset. Each DFF should take in one bit of the 8-bit input 'd' and output one bit of the 8-bit output 'q'. The DFFs should be triggered by the positive edge of the clock signal 'clk' and reset to 0 when the asynchronous reset 'areset' is high.
