To implement the TopModule, we will use 8 D flip-flops with active high asynchronous reset. Each D flip-flop will be triggered by the positive edge of the clk signal, and its output will be reset to 0 when the areset signal is high. We will use the always @(posedge clk or posedge areset) block to describe the behavior of each D flip-flop. Inside this block, we will first check if the areset signal is high. If it is, we will reset the output of each D flip-flop to 0. If the areset signal is not high, we will check if the clk signal has a positive edge. If it does, we will update the output of each D flip-flop with the corresponding input bit.
