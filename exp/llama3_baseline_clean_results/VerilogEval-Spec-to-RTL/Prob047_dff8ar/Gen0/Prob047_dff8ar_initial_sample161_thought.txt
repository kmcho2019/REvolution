To implement the TopModule, we can use a single 8-bit D flip-flop with active high asynchronous reset. The D flip-flop will be triggered by the positive edge of the clk signal. When the areset signal is high, the output q will be reset to 0, regardless of the current state of the d input. We will use a for loop to instantiate 8 D flip-flops, each with the same characteristics.
