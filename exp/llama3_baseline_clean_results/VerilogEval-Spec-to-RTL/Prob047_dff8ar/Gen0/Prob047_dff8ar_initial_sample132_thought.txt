To implement the TopModule, we will use 8 D flip-flops (DFFs) to store the input data `d`. Each DFF will have an active high asynchronous reset, meaning that when `areset` is high, the output `q` will be reset to 0, regardless of the clock. The DFFs will be triggered by the positive edge of the clock `clk`, so the input `d` will be captured and stored in the DFFs when `clk` rises. We will use the Verilog syntax to describe the DFFs and their connections.
