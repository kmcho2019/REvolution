To implement the TopModule, we will create a module with the specified interface. Inside the module, we will use 8 D flip-flops (DFFs) to store the input data. Each DFF will have an active high asynchronous reset, meaning when the areset signal is high, the output of the DFF will be reset to 0. The DFFs will be triggered by the positive edge of the clk signal. We will use the Verilog built-in `always` block and the `posedge` keyword to achieve this.
