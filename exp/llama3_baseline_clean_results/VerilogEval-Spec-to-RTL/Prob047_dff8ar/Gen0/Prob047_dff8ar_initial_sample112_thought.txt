To design the TopModule, we will use 8 D flip-flops (DFFs) to store the input data. Each DFF will have an active high asynchronous reset, meaning that when the areset signal is high, the output of the DFF will be reset to 0, regardless of the clock edge. The DFFs will be triggered by the positive edge of the clk signal, and the output of each DFF will be the stored value of the corresponding input bit when the clk signal rises. We can use the always_ff block in Verilog to describe the behavior of the DFFs and handle the asynchronous reset.
