To implement the TopModule, we need to instantiate 8 D flip-flops with asynchronous reset. Each D flip-flop should have its input connected to the corresponding bit of the input d, and its output connected to the corresponding bit of the output q. The reset input of all D flip-flops should be connected to the areset input, and the clock input should be connected to the clk input. We will use the posedge of the clk to trigger the D flip-flops.
