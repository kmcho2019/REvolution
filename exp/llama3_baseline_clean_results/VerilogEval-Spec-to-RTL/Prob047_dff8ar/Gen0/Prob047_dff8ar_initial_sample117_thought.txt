To implement the TopModule, we will use 8 D flip-flops (DFFs) to store the input data d. The DFFs will be triggered by the positive edge of the clock signal clk and will have an active high asynchronous reset areset. When areset is high, the output q should be reset to 0, regardless of the current state of the clock. This means we will use the reset pin on the DFF to asynchronously reset the output q to 0.
