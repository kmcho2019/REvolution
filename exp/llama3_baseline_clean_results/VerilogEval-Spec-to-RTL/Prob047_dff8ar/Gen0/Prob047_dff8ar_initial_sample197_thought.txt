To implement the TopModule, we need to create a module that includes 8 D flip-flops. Each D flip-flop should have an asynchronous active-high reset, meaning that when the areset signal is high, the output of the flip-flop should be reset to 0, regardless of the clock signal. The D flip-flops should be triggered by the positive edge of the clk signal. We can achieve this by using the always block in Verilog, which is sensitive to the positive edge of the clock and the areset signal.
