To implement the TopModule with the specified interface, we need to design a module that contains 8 D flip-flops (DFFs) with active high asynchronous reset. Each DFF should be triggered by the positive edge of the clock signal 'clk'. When the asynchronous reset signal 'areset' is high, all DFFs should reset their outputs to 0, regardless of the current clock signal. The input data 'd' should be latched by the DFFs on the positive edge of 'clk' when 'areset' is low.
