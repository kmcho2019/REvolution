To implement the TopModule, we will use 8 D flip-flops with active high asynchronous reset. Each D flip-flop will be triggered by the positive edge of the clk signal. The reset signal, areset, will reset all the D flip-flops to 0 asynchronously, regardless of the state of the clk signal. We will use the Verilog built-in D flip-flop module or its equivalent logic to implement each D flip-flop.
