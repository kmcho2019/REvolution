To implement the TopModule, we need to design a module that includes 8 D flip-flops (DFFs) with active high asynchronous reset. Each DFF should be triggered by the positive edge of the clock signal (clk) and should reset to 0 when the asynchronous reset signal (areset) is high. The input data (d) is 8 bits wide, and the output (q) should also be 8 bits wide, with each bit corresponding to the output of each DFF.
