To control the cellphone's ringer and vibration motor, we can use a simple combinational logic circuit. The circuit should check the 'ring' input and the 'vibrate_mode' input. If the phone is ringing and in vibrate mode, the motor should be turned on. If the phone is ringing and not in vibrate mode, the ringer should be turned on. We can achieve this using a multiplexer-like logic, where the 'vibrate_mode' input selects between the ringer and the motor.
