To control the cellphone's ringer and vibration motor, we need to implement a simple digital circuit that takes into account the phone's mode (vibrate or ring) and the incoming call signal. The circuit should have two inputs, 'ring' and 'vibrate_mode', and two outputs, 'ringer' and 'motor'. When 'vibrate_mode' is 1, the 'motor' should be turned on when there's an incoming call ('ring' is 1). When 'vibrate_mode' is 0, the 'ringer' should be turned on when there's an incoming call. This logic can be implemented using basic logical operations.
