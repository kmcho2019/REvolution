To implement the TopModule, we need to consider the water level and the previous level to determine the flow rate. 
We can use the 3-bit input s to determine the current water level and use a state machine to keep track of the previous level. 
When the water level is above the highest sensor, all flow rate outputs should be zero. 
When the level is below the lowest sensor, all flow rate outputs should be maximum (both Nominal flow valve and Supplemental flow valve opened). 
For levels between the upper and lower sensors, we use the table provided to determine the nominal flow rate and check the sensor change to decide whether to open the Supplemental flow valve. 
We also need to implement an active-high synchronous reset that resets the state machine to a state equivalent to if the water level had been low for a long time.
