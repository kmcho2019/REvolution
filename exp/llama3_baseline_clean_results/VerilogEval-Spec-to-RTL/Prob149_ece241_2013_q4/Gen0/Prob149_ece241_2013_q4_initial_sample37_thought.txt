To solve this problem, we can use a simple state machine with a few states 
that correspond to the different water levels. We will use a combination of 
the current water level and the previous water level to determine the 
flow rate. The previous water level will be stored in a register, and 
updated at each clock cycle. 

The main states are:
- Above all sensors (s[2] is high)
- Between s[2] and s[1] (s[1] is high, s[2] is low)
- Between s[1] and s[0] (s[0] is high, s[1] is low)
- Below all sensors (none are high)

The flow rate will be determined based on the current state and the 
previous state. If the previous state was lower than the current state, 
the supplemental flow valve (dfr) will be opened.

We will also include an active-high synchronous reset that resets the 
state machine to a state equivalent to if the water level had been low 
for a long time (no sensors asserted, and all four outputs asserted).
