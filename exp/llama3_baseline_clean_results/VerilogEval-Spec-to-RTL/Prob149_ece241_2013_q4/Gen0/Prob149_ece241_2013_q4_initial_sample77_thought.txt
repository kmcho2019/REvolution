The problem can be solved by implementing a finite state machine (FSM) that reacts to the current sensor values and the previous sensor values. The FSM will have four states based on the sensor values: above the highest sensor, between the highest and middle sensors, between the middle and lowest sensors, and below the lowest sensor. The output flow rates will be determined based on the current state and the previous state. 

We can use a register to keep track of the previous sensor values. On every clock cycle, the current sensor values will be compared with the previous sensor values to determine if the water level has increased, decreased, or remained the same.

The nominal flow rates will be asserted based on the current sensor values, and the supplemental flow rate will be asserted if the water level has increased.
