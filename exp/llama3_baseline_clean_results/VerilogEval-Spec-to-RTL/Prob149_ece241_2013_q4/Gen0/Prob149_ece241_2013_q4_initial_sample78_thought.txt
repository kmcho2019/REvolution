The problem can be solved by implementing a finite state machine in Verilog. 
The state machine should have four states corresponding to the four conditions 
described in the problem: above the highest sensor, between the highest and 
middle sensors, between the middle and lowest sensors, and below the lowest 
sensor. The state machine should also keep track of the previous sensor state 
to determine whether to increase the flow rate by opening the supplemental 
flow valve. 
We will use a binary encoded state machine with four states (s0, s1, s2, s3) 
corresponding to the four conditions. 
The state machine will be reset to state s3 (below the lowest sensor) when 
the reset signal is asserted.
