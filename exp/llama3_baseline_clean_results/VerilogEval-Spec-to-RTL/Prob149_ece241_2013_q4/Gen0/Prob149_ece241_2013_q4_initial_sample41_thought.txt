The module can be implemented as a finite state machine (FSM) that tracks the current state of the sensors and adjusts the flow rate accordingly. The FSM will have four main states: one for each of the water level ranges (above s[2], between s[2] and s[1], between s[1] and s[0], and below s[0]). The state machine will also track the previous sensor state to determine if the water level is rising or falling. This information will be used to adjust the flow rate by opening or closing the supplemental flow valve. An active-high synchronous reset will be implemented to reset the state machine to a state equivalent to a low water level.
