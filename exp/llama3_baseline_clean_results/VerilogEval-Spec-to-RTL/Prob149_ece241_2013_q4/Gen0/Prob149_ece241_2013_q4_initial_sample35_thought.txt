To implement the TopModule, we will use a state machine approach. The state machine will have two main states: the current water level state and the previous water level state. We will use the current water level state to determine the nominal flow rate and the previous water level state to determine if the Supplemental flow valve should be opened. We will use a 3-bit input `s` to determine the current water level state and a 3-bit internal signal `prev_s` to store the previous water level state. We will also use an active-high synchronous reset to reset the state machine to the initial state when the water level is low.

The state machine will have the following states:
- Above s[2]: no sensors asserted, no flow rate
- Between s[2] and s[1]: s[0] and s[1] asserted, fr0 asserted
- Between s[1] and s[0]: s[0] asserted, fr0 and fr1 asserted
- Below s[0]: no sensors asserted, fr0, fr1, and fr2 asserted

We will use a clock `clk` to update the state machine and a reset `reset` to reset the state machine to the initial state.
