The FSM should have four states corresponding to the water levels: above the highest sensor, between the highest and middle sensors, between the middle and lowest sensors, and below the lowest sensor. The next state is determined by the current state and the sensor inputs. The output flow rate is determined by the current state and the previous state (to determine if the water level is rising or falling).

We will use a 2-bit state variable to encode the four states. The state will be reset to the state equivalent to the water level being low for a long time. The FSM will use the sensor inputs to determine the next state and the output flow rates.

We will use a 3-bit variable to store the previous sensor values. This will allow us to determine if the water level is rising or falling.
