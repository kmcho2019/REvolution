To implement the TopModule, we will use a finite state machine (FSM) that changes its state based on the current and previous sensor values. We will use two variables, current_state and previous_state, to keep track of the current and previous sensor values. We will use the current_state to determine the nominal flow rate and the previous_state to determine if the supplemental flow valve should be opened. The FSM will have four states: above_s2, between_s2_s1, between_s1_s0, and below_s0. The outputs will be determined based on the current state. The module will also have an active-high synchronous reset that resets the state machine to the state equivalent to a low water level.
