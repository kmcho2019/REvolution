To solve this problem, we need to design a finite state machine (FSM) that can track the current water level and the previous level. The FSM should have four states: above the highest sensor, between the highest and middle sensors, between the middle and lowest sensors, and below the lowest sensor. Based on the current state and the previous state, the FSM should determine the flow rate. We can use a 2-bit variable to store the previous state and a 2-bit variable to store the current state. The FSM should also have an active-high synchronous reset that resets the state machine to a state equivalent to if the water level had been low for a long time.
