The problem can be solved by implementing a state machine in the TopModule. 
The state machine should have states to represent the current water level 
(rising or falling) and the previous water level. We will use the input 
sensors to determine the current water level and update the state 
accordingly. Based on the current state, we can determine the nominal 
flow rate and whether to assert the supplemental flow valve. 
We will use a combinational logic to determine the flow rate based on 
the current state. The state machine should also have an active-high 
synchronous reset to reset the state machine to a state equivalent to if 
the water level had been low for a long time.
