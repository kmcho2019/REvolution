To solve this problem, we can design a finite state machine (FSM) with different states representing the water level. The FSM will have an active-high synchronous reset. The states can be defined as follows:
- State 0: All sensors are deasserted (water level is below s[0])
- State 1: Only s[0] is asserted (water level is between s[0] and s[1])
- State 2: s[0] and s[1] are asserted (water level is between s[1] and s[2])
- State 3: All sensors are asserted (water level is above s[2])
We will use a 2-bit register to store the current state. The next state will be determined by the current state and the inputs. The outputs will also be determined by the current state and the previous state.

We need to consider two factors to determine the flow rate: the water level and the level previous to the last sensor change. To achieve this, we can use a separate register to store the previous state.

When the reset is high, the state machine will be reset to State 0.
