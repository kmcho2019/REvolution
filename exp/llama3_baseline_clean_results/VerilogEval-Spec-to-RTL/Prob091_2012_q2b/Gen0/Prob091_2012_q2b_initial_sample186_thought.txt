We can determine the output signals Y1 and Y3 based on the current state 
and the input signal w.

This happens when the current state is A (000001) and w is 0, 
or when the current state is B (000010) and w is 0, 
or when the current state is C (000100) and w is 0, 
or when the current state is E (010000) and w is 0.

This happens when the current state is B (000010) and w is 0, 
or when the current state is C (000100) and w is 0, 
or when the current state is E (010000) and w is 0,
