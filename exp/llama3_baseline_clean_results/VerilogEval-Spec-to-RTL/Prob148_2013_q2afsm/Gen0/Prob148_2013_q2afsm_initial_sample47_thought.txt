To implement the given FSM, we need to define the states and the next state logic. 
We can use four states: A, B, C, and D. However, based on the state diagram, 
state D is not reachable because there is no transition to state D from any other state.
We can assign the following state codes: A = 2'b00, B = 2'b01, C = 2'b10, and 
we won't use state D.

The next state logic is based on the current state and the input r.
From state A, we go to state B if r0 = 1, to state C if r0 = 0 and r1 = 1, 
and stay in state A if r0 = 0 and r1 = 0 and r2 = 1.
From state B, we stay in state B if r0 = 1 and go to state A if r0 = 0.
From state C, we stay in state C if r1 = 1 and go to state A if r1 = 0.

The output g is determined by the current state.
In state B, g0 = 1. In state C, g1 = 1. 
In state A, all outputs are 0.

We will use a separate always block for the state table and the state flip-flops.
We will also use continuous assignment for the output g.
