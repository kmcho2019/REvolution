To implement the given Finite State Machine (FSM), we need to define the states and their corresponding transitions. The states are A, B, C, and D. State A is the initial state and also the state where the FSM stays when there are no requests. State B represents the grant for device 0, state C represents the grant for device 1, and state D represents the grant for device 2. We will use the following state encoding: A = 2'b00, B = 2'b01, C = 2'b10, D = 2'b11. The transitions between states will be based on the current state and the input signals r[0], r[1], and r[2]. We will use a separate always block for the state table and another for the state flip-flops. The outputs g[0], g[1], and g[2] will be defined using continuous assignment statements.
