To implement this module, I will use a Moore machine model, which is a finite state machine where the outputs are a function of the current state only. I'll use separate always blocks for the state table and the state flip-flops. I will also use an always block for the state flip-flops, which will be triggered on the positive edge of the clock. The output signals g will be described using continuous assignment statements, since they are a direct function of the current state.
