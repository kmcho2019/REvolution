The design approach here involves creating a finite state machine (FSM) with states A, B, C, and D. The states B, C, and D will correspond to granting access to devices 0, 1, and 2, respectively. State A will be the idle state where no device is granted access. The transitions between states will be based on the input signals r[2:0] and the current state. 

For the state encoding, we can use 2 bits to represent the 4 states (A, B, C, D). Let's assign the encoding as follows: A = 00, B = 01, C = 10, D = 11.

To handle the state transitions, we'll use an always block that is sensitive to the positive edge of the clock and the resetn signal. 

Another always block will be used to determine the next state based on the current state and the input signals r[2:0].

Finally, we'll use continuous assignment statements to generate the output signals g[2:0] based on the current state.
