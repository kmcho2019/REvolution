To implement the given FSM, we can define four states: A, B, C, and D. 
State A will be the idle state where no device has access to the resource. 
States B and C will be used to grant access to devices 0 and 1, respectively, 
and will maintain their grant as long as the corresponding request is active.
State D will be used to grant access to device 2, but it is not necessary 
in this case as the same behavior can be achieved by staying in state A 
and checking for the request from device 2. 
The state transitions will be based on the current state and the input requests.
The outputs g will be determined by the current state.
We will use two always blocks: one for the combinational logic to determine 
the next state, and one for the sequential logic to update the current state.
We will use continuous assignment statements to determine the outputs g.
