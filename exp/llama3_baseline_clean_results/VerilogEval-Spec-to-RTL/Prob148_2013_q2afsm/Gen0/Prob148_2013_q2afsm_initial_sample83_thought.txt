The FSM can be implemented using two always blocks: one for the state flip-flops and one for the next state logic. The outputs g[0], g[1], and g[2] can be described using continuous assignment statements. We can assign state codes as follows: A = 2'b00, B = 2'b01, C = 2'b10, D = 2'b11. However, since state D is not actually needed based on the given state diagram (transition to D is based on r0=0, r1=0, r2=0, which doesn't make sense as it's already in state A), we can simplify our state machine by removing state D.
