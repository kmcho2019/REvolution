To implement the given FSM, we can use a two-process approach: one for the state flip-flops and another for the combinational logic that determines the next state. We can use enumerated states to make the code more readable. We will use parameterized names for the states (A, B, C, D) for clarity. The FSM outputs (g) can be described using continuous assignment statements, as they directly depend on the current state.

We will assign the following state codes for simplicity:
- State A: 2'b00
- State B: 2'b01
- State C: 2'b10
