To implement the given FSM in Verilog, we will first define the states and their corresponding binary representations. We can use 2 bits to represent the 4 states (A, B, C, and D). Let's assign the following state codes: 
- A: 00
- B: 01
- C: 10
- D: 11

The state table can be implemented using an always block. We will use another always block to update the state flip-flops.

For the outputs, we will use an always block to describe the FSM outputs, g[i], based on the current state.

The resetn signal is an active-low synchronous reset, so we will use it to reset the state flip-flops to state A when it is low.
