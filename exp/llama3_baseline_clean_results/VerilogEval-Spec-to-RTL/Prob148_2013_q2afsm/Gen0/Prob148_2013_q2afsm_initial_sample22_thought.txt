The problem describes a finite state machine (FSM) with four states: A, B, C, and D. The FSM has three inputs (r[0], r[1], r[2]) and three outputs (g[0], g[1], g[2]). The FSM prioritizes device 0 over device 1, and device 1 over device 2. When a request is made by one or more devices, the FSM transitions to a state that grants the resource to the highest-priority requesting device. The grant remains active as long as the request is active. 

To implement this FSM, we can use two always blocks: one for the state table (next state logic) and one for the state flip-flops (current state logic). We will use a 2-bit state code, with state A = 00, B = 01, C = 10, and D = 11 (although state D will not be used in this implementation as the state diagram shows no transitions to state D, it can still be included for completeness). 

The state table will determine the next state based on the current state and input values. The state flip-flops will update the current state on the positive edge of the clock.

The output g[0], g[1], and g[2] can be described using continuous assignment statements, as they are solely dependent on the current state.
