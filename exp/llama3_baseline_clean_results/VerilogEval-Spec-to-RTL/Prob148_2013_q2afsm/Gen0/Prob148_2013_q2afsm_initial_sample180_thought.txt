The FSM can be implemented with a 2-bit state variable, allowing for four possible states (A, B, C, D). Since we only need to keep track of the current state and the next state, we can use separate always blocks for the state table (combinational logic) and the state flip-flops (sequential logic). The state table will determine the next state based on the current state and the input signals r[0], r[1], and r[2]. The state flip-flops will update the current state at the positive edge of the clock.

To implement the priority system, we can use the following state assignment:
- State A: 2'b00
- State B: 2'b01 (g0 = 1)
- State C: 2'b10 (g1 = 1)
- State D: 2'b11 (not needed, but can be used for g2 = 1 if needed in the future)

The output signals g[0], g[1], and g[2] can be assigned using continuous assignment statements based on the current state.
