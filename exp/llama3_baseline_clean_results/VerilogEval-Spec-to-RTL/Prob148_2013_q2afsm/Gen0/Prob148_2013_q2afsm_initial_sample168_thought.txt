To implement the given FSM in Verilog, we will define the states as A, B, C, and D. 
We'll use an enum to assign state codes. Since there are 4 states, we can represent 
them using 2 bits. The state A will be the reset state. We'll use two always blocks, 
one for the state table (next state logic) and one for the state flip-flops. 
The outputs g will be assigned using continuous assignment for simplicity.
