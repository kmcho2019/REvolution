To implement the given Finite State Machine (FSM), we first need to define the states and their corresponding next states based on the input conditions. Since the FSM has four states (A, B, C, D), we can assign state codes using two bits. However, based on the problem description, state D is only reachable when r0=0, r1=0, and r2=0, which seems to be a contradiction as state A is also reachable with the same conditions. For simplicity, let's consider state D as an unreachable state or a don't care condition for our implementation.

We will use an always block for the combinational logic to determine the next state based on the current state and inputs. Another always block will be used for the sequential logic to update the current state. We will use continuous assignment statements to define the outputs g[2:0] based on the current state.

The states can be encoded as follows:
- State A: 2'b00
- State B: 2'b01
- State C: 2'b10
- State D: Not considered in the implementation due to the seeming contradiction.

For state B, g[0] should be 1, and for state C, g[1] should be 1. All other outputs should be 0.
