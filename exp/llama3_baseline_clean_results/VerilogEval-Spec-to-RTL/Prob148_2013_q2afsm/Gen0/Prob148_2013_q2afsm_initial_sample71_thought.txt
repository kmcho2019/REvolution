To implement this FSM, we will use a modular approach with separate always blocks for the state table and the state flip-flops. The state table will determine the next state based on the current state and the input values. The state flip-flops will update the current state based on the next state and the clock signal.

We will use a 2-bit state code to represent the four states A, B, C, and D. The state codes will be as follows: A = 2'b00, B = 2'b01, C = 2'b10, and D = 2'b11.

The state table will be implemented as a case statement inside an always block. The always block will be triggered by the positive edge of the clock signal and will check the current state and the input values to determine the next state.

The state flip-flops will be implemented as a separate always block that will update the current state based on the next state and the clock signal.

The FSM outputs, g[i], will be assigned based on the current state using continuous assignment statements.
