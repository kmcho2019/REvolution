To implement the Moore state machine as described, we will first define an enumeration for the states. We will use two states: OFF and ON. The output of the state machine is determined solely by the current state. We will use a case statement inside a combinational always block to determine the next state based on the current state and the inputs. We will also use an initial value for the state and an asynchronous reset to handle the reset condition. We will synchronize the state transition with the rising edge of the clock signal.
