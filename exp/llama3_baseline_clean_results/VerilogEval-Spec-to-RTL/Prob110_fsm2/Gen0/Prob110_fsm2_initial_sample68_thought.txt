To implement the Moore state machine as described, we can use a two-state finite state machine (FSM) with two inputs (j and k) and one output (out). We'll define an enumeration for the states and use a clocked always block to handle the state transitions. The state transitions are as follows: 
- If the current state is OFF and j is 1, transition to ON. 
- If the current state is ON and k is 1, transition to OFF. 
- Otherwise, stay in the current state. 
We also need to handle the asynchronous reset, which sets the state to OFF when areset is high.
