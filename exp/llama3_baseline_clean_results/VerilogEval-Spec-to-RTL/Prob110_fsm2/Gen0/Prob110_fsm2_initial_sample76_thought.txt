To implement the Moore state machine described, we will define two states, OFF and ON, and use a case statement within a combinatorial always block to determine the next state based on the current state and input values. We will use a separate always block to handle the synchronous update of the current state based on the next state and the clock. The output out will be defined based on the current state.

We'll use two parameters or localparams to define the states, and a reg variable to hold the current state. The next state will be determined based on the inputs j and k and the current state.

For the asynchronous reset, we will set the initial value of the current state to OFF when areset is high.
