To implement the Moore state machine as described, we need to define two states (OFF and ON) and handle transitions based on the inputs j and k. Since it's a Moore machine, the output is determined solely by the current state. The reset is asynchronous and active-high, meaning when areset is high, the state machine immediately resets to the OFF state regardless of the current clock state.

1. Define the states.
2. Create a state register to hold the current state.
3. Implement the state transition logic based on the current state and inputs.
4. Define the output logic based on the current state.
5. Handle the asynchronous reset.

In Verilog, we can use an always block for the combinational logic to determine the next state and another always block for the sequential logic to update the current state. We'll use a case statement to simplify the state transition logic.
