To implement the Moore state machine as described, we need to consider the state transitions based on the inputs j and k. The state machine has two states: OFF and ON. The output 'out' is determined solely by the current state. The state transitions are as follows:
- When in state OFF, if j = 1, the machine transitions to state ON. If j = 0, it remains in OFF.
- When in state ON, if k = 1, the machine transitions back to state OFF. If k = 0, it remains in ON.
Given that 'areset' is an active-high asynchronous reset, whenever 'areset' is high, the machine should immediately reset to the OFF state, regardless of the current state or the values of j and k.

We will use a 1-bit signal to represent the current state (0 for OFF, 1 for ON) and update it based on the current state and inputs j and k at each clock edge. The output 'out' will directly reflect the current state.
