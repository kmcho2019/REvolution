To implement the Moore state machine as described, we'll define two states (OFF and ON) and use a finite state machine (FSM) to transition between these states based on the inputs j and k. The output out will be determined by the current state. We'll use an enum to define the states for clarity. The FSM will be implemented using a always_ff block for the state register and combinational logic for the next state. The asynchronous reset will be handled by the initial condition of the state register.
