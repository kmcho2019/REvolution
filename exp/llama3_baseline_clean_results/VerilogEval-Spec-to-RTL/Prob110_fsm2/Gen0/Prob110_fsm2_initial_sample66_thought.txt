To implement the Moore state machine as described, we need to follow these steps:
1. Define the states (OFF and ON) using parameters or enums.
2. Use a reg to hold the current state and initialize it to the reset state (OFF).
3. Implement the state transition logic based on the current state and inputs (j, k).
4. Define the output (out) based on the current state.

Since the reset is asynchronous and active-high, we use an asynchronous reset in the always block that handles the state transitions.
