To implement the digital system, we first need to identify the conditions under which the output should be logic-1. The inputs are treated as a binary number, with 'a' as the most significant bit and 'd' as the least significant bit. The binary numbers corresponding to 2, 7, and 15 are 0010, 0111, and 1111, respectively. 

For the sum-of-products (SOP) form, we need to find the minimum SOP expression that covers all the required minterms (2, 7, and 15). The SOP expression is obtained by ORing the minterms corresponding to each of these numbers.

For the product-of-sums (POS) form, we need to find the minimum POS expression that covers all the required maxterms (0, 1, 4, 5, 6, 9, 10, 13, and 14). The POS expression is obtained by ANDing the maxterms corresponding to each of these numbers.

We then use these expressions to derive the Verilog implementation of the TopModule.
