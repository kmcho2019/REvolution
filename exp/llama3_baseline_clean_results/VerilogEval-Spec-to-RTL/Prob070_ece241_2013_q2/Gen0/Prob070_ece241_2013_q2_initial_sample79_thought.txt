To find the minimum sum-of-products (SOP) and product-of-sums (POS) forms for the given conditions, we need to first identify the minterms and maxterms. The system generates a logic-1 for the inputs corresponding to 2, 7, and 15. In binary, these are 0010, 0111, and 1111 respectively. Since the inputs a, b, c, and d correspond to the 4-bit binary number from least significant bit to most significant bit, we can express these as (a, b, c, d) = (0, 1, 0, 0), (0, 1, 1, 1), and (1, 1, 1, 1) respectively. For SOP, we will look for minterms, which are the products of literals that represent the conditions for a logic-1 output.

For the SOP form, the minterms are:
- For 2 (0010): \(\overline{a} \cdot b \cdot \overline{c} \cdot \overline{d}\)
- For 7 (0111): \(\overline{a} \cdot b \cdot c \cdot d\)
- For 15 (1111): \(a \cdot b \cdot c \cdot d\)

The SOP expression is the sum of these minterms.

For the POS form, we need to consider the maxterms, which are the sums of literals that represent the conditions for a logic-0 output. However, given the inputs for logic-0 conditions, we can find the maxterms by inverting the bits of each number that leads to a logic-0 output and then taking the sum of the corresponding literals.

Given the numbers 0, 1, 4, 5, 6, 9, 10, 13, 14 lead to a logic-0, we first express these in binary and then find the inverted maxterms:
- 0: 0000, Inverted maxterm: \(a + b + c + d\)
- 1: 0001, Inverted maxterm: \(a + b + c + \overline{d}\)
- 4: 0100, Inverted maxterm: \(a + \overline{b} + c + d\)
- 5: 0101, Inverted maxterm: \(a + \overline{b} + c + \overline{d}\)
- 6: 0110, Inverted maxterm: \(a + \overline{b} + \overline{c} + d\)
- 9: 1001, Inverted maxterm: \(\overline{a} + b + c + \overline{d}\)
- 10: 1010, Inverted maxterm: \(\overline{a} + b + \overline{c} + d\)
- 13: 1101, Inverted maxterm: \(\overline{a} + \overline{b} + c + \overline{d}\)
- 14: 1110, Inverted maxterm: \(\overline{a} + \overline{b} + \overline{c} + d\)

The POS expression is the product of these maxterms.
