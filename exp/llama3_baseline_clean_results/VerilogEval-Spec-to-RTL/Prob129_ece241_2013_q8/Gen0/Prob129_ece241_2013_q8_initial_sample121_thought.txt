To implement the Mealy-type finite state machine that recognizes the sequence "101", we will design a 3-state FSM. The states will be: IDLE (initial state, waiting for '1'), GOT_1 (got the first '1'), and GOT_10 (got '10'). The output z will be asserted when the FSM is in the GOT_10 state and the current input x is '1'. The FSM will also have a negative edge triggered asynchronous reset, which will reset the FSM to the IDLE state when aresetn is '0'.
