To implement the Mealy-type finite state machine in Verilog, we'll define three states: IDLE, S1, and S2. 
The machine starts in the IDLE state. 
When in the IDLE state and 'x' is '1', it transitions to the S1 state. 
When in the S1 state and 'x' is '0', it transitions to the S2 state. 
When in the S2 state and 'x' is '1', it transitions back to the S1 state and asserts the output 'z'. 
In all other cases, the machine either stays in its current state or transitions back to the IDLE state. 
We will also implement an asynchronous reset that resets the machine to the IDLE state when 'aresetn' is '0'.
