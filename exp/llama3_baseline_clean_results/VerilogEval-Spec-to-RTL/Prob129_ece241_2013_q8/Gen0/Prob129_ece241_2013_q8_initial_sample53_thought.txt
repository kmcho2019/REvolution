To solve this problem, I will design a Mealy-type finite state machine (FSM) with three states: S0 (initial state), S1, and S2. The FSM will recognize the sequence "101" on the input signal x and assert the output signal z to logic-1 when the sequence is detected. The FSM will have a negative edge triggered asynchronous reset. 

The states will be defined as follows:
- S0: Initial state, waiting for the first '1' in the sequence.
- S1: First '1' detected, waiting for the '0'.
- S2: '0' detected, waiting for the second '1'.

The state transitions will be defined based on the current state and the input x. The output z will be asserted to logic-1 when the FSM is in state S2 and the input x is '1'. 

Since the FSM should recognize overlapping sequences, it will be designed to return to the initial state or the first state after detecting the sequence.
