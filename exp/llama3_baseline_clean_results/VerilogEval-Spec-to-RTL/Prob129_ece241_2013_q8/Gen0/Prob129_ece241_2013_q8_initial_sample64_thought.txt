To implement the Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we need to design a state machine with three states. The states can be defined as follows: 
- State 0 (RESET): Initial state where the sequence recognition starts.
- State 1 (ONE_DETECTED): State reached when a '1' is detected at the input x.
- State 2 (ZERO_DETECTED_AFTER_ONE): State reached when a '0' is detected after a '1' in State 1.

The machine starts at State 0 and transitions to State 1 when a '1' is detected. If another '1' is detected in State 1, it stays in State 1. If a '0' is detected in State 1, it transitions to State 2. From State 2, if a '1' is detected, the sequence "101" is recognized, and the output z is asserted. Then it transitions back to State 1.

The asynchronous reset is implemented using the aresetn input. When aresetn is low, the FSM resets to State 0.

The state transitions are as follows:
- From State 0: '1' -> State 1, '0' -> State 0
- From State 1: '1' -> State 1, '0' -> State 2
- From State 2: '1' -> State 1 and assert z, '0' -> State 0
