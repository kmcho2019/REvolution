To implement the Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can design a state machine with three states: Idle, Seen1, and Seen10. The state machine starts in the Idle state. When the input x is '1' in the Idle state, the state machine transitions to the Seen1 state. If x is '0' in the Seen1 state, the state machine transitions back to the Idle state. If x is '1' in the Seen1 state, the state machine remains in the Seen1 state. When x is '0' in the Seen1 state, the state machine transitions to the Seen10 state. When x is '1' in the Seen10 state, the state machine transitions back to the Seen1 state and asserts the output z to '1'. The state machine also has a negative edge triggered asynchronous reset that resets the state machine to the Idle state when aresetn is '0'.
