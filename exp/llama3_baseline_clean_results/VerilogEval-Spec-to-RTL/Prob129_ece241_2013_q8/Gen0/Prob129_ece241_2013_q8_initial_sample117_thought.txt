To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we will define three states: Idle, Seen1, and Seen101. The Idle state is the initial state where the FSM waits for the first '1' in the sequence. Once a '1' is detected, it transitions to the Seen1 state. In the Seen1 state, if a '0' is detected, it transitions to the Seen101 state. Finally, in the Seen101 state, if a '1' is detected, it asserts the output z to logic-1 and transitions back to the Seen1 state because we are looking for overlapping sequences. The FSM also includes an asynchronous reset that resets the state to Idle when the reset signal aresetn is low.

The state transitions can be summarized as follows:
- Idle: 
  - x = 1, go to Seen1
  - x = 0, stay in Idle
- Seen1: 
  - x = 1, stay in Seen1 (don't transition to Seen101)
  - x = 0, go to Seen101
- Seen101: 
  - x = 1, go to Seen1 and set z = 1
  - x = 0, go back to Idle

Given the Mealy machine nature, the output z is a function of both the current state and the input x. In this case, z will be 1 when the FSM is in the Seen101 state and x is 1.

We will use a parameterized enum for the states to improve code readability. The next state logic and output logic will be implemented using always_comb blocks for combinational logic and always_ff blocks for sequential logic.
