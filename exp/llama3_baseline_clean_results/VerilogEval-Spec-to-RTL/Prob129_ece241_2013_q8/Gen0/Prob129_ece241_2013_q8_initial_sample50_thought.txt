To implement the Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we need to design a state machine with three states. The states will represent the current sequence recognized so far. 
State 1 (initial state): No sequence recognized yet
State 2: "1" recognized
State 3: "10" recognized

When the state machine is in State 1 and it sees a "1" on the input x, it transitions to State 2. 
When the state machine is in State 2 and it sees a "0" on the input x, it transitions to State 3. 
When the state machine is in State 3 and it sees a "1" on the input x, it asserts the output z to logic-1 because it has recognized the "101" sequence.

We will also implement an asynchronous reset to reset the state machine to State 1 when aresetn is low.

To recognize overlapping sequences, we will allow the state machine to transition back to previous states based on the input x. For example, when the state machine is in State 2 and it sees a "1" on the input x, it stays in State 2. Similarly, when the state machine is in State 3 and it sees a "1" on the input x, it resets to State 2.

The output z is asserted only when the state machine is in State 3 and it sees a "1" on the input x.
