To solve this problem, we can design a Mealy-type finite state machine (FSM) with three states: IDLE, SEEN_1, and SEEN_10. The FSM starts in the IDLE state. When the input 'x' is '1', it moves to the SEEN_1 state. From the SEEN_1 state, if 'x' is '0', it moves to the SEEN_10 state. From the SEEN_10 state, if 'x' is '1', it asserts the output 'z' to '1' and remains in the SEEN_10 state, since we want to recognize overlapping sequences. We also need to implement an asynchronous reset that resets the FSM to the IDLE state when 'aresetn' is '0'. The output 'z' should be '1' only when the sequence "101" is detected.
