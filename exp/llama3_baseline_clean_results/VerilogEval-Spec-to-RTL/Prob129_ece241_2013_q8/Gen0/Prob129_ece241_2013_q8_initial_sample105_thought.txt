To solve this problem, we will design a Mealy-type finite state machine (FSM) with 3 states that recognizes the sequence "101" on the input signal x. The FSM will have an output signal z that is asserted to logic-1 when the "101" sequence is detected. We will use a negative edge triggered asynchronous reset. The states will be: 
- S0: Initial state
- S1: State after detecting "1"
- S2: State after detecting "0" after "1"

When the FSM is in S0 and x is 1, it will transition to S1. When it is in S1 and x is 0, it will transition to S2. When it is in S2 and x is 1, it will transition back to S1 and assert z to 1. In all other cases, it will either stay in the same state or transition back to S0. This way, the FSM will recognize overlapping sequences of "101".
