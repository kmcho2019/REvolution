To implement the Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we will use three states: S0, S1, and S2. The state machine starts in S0. When in S0, if x is 1, it moves to S1. When in S1, if x is 0, it moves to S2. When in S2, if x is 1, it returns to S1 and asserts the output z to 1, because the sequence "101" has been detected. We will use a negative edge triggered asynchronous reset to reset the state machine to S0. The state machine will recognize overlapping sequences because it only checks for the current and next states, not the entire sequence.
