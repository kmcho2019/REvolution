To implement the Mealy-type finite state machine, we can define three states: IDLE, SEEN_1, and SEEN_10. The IDLE state is the initial state. When the input x is '1' in the IDLE state, we move to the SEEN_1 state. In the SEEN_1 state, if x is '0', we move to the SEEN_10 state. From the SEEN_10 state, if x is '1', we assert the output z to '1' and move back to the SEEN_1 state, because we have recognized the sequence "101". We also need to handle the asynchronous reset, which should reset the state machine to the IDLE state when aresetn is '0'. Overlapping sequences can be recognized by allowing the state machine to move back to the SEEN_1 state after detecting the sequence "101".
