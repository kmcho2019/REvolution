To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we will define three states: S0 (initial state), S1, and S2. The state machine transitions from S0 to S1 when the input x is 1, from S1 to S2 when the input x is 0, and from S2 back to S1 when the input x is 1. The output z is asserted to logic-1 when the state machine is in state S2 and the input x is 1, indicating the recognition of the sequence "101". We will use a negative edge triggered asynchronous reset to reset the state machine to the initial state S0.
