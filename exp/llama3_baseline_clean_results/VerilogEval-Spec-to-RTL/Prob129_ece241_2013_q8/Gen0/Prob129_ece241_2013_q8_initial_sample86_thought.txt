We will use a negative edge triggered asynchronous reset to reset the FSM.

- From S0, if x is 1, move to S1, otherwise stay in S0.
- From S1, if x is 0, move to S2, otherwise move back to S0 if x is 1 (to handle overlapping sequences).
- From S2, if x is 1, assert z to 1 and move back to S1 (since we have seen the "101" sequence), otherwise move back to S0.
