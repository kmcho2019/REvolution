To implement the Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we need to design a state machine with three states. The states can be defined as follows:
- State 0 (S0): The initial state where no sequence has been detected.
- State 1 (S1): The state where the sequence "1" has been detected.
- State 2 (S2): The state where the sequence "10" has been detected.

The state machine will transition between these states based on the input signal x. The output signal z will be asserted to logic-1 when the sequence "101" is detected. 

We will use a negative edge triggered asynchronous reset to reset the state machine to its initial state. All sequential logic will be triggered on the positive edge of the clock.
