To implement the Mealy-type finite state machine, we will define three states: S0 (initial state), S1, and S2. In state S0, we will check for the first '1' in the sequence. If a '1' is detected, we will transition to state S1. In state S1, we will check for the '0' in the sequence. If a '0' is detected, we will transition to state S2. In state S2, we will check for the last '1' in the sequence. If a '1' is detected, we will assert the output signal z to logic-1 and transition back to state S1 to recognize overlapping sequences. If the input sequence does not match the expected sequence, we will transition back to the previous state or the initial state. The negative edge triggered asynchronous reset will reset the FSM to the initial state S0.
