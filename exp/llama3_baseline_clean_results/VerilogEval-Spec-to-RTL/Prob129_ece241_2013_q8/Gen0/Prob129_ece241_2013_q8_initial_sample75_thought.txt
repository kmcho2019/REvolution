To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can define three states: Idle, S1, and S2. 
The Idle state is the initial state where we start looking for the sequence.
When we detect a '1' on the input x in the Idle state, we move to the S1 state.
In the S1 state, if we detect a '0' on the input x, we move to the S2 state.
In the S2 state, if we detect a '1' on the input x, we assert the output z to '1' (indicating the sequence "101" has been detected) and then move back to the Idle state.
The state machine should also be reset asynchronously on the negative edge of aresetn.
The output z is only asserted to '1' when the sequence "101" is detected; otherwise, it remains '0'.
