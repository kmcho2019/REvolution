To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can define three states: Idle, Seen_1, and Seen_10. The machine starts in the Idle state. When the input x is 1 in the Idle state, it transitions to the Seen_1 state. In the Seen_1 state, if x is 0, it stays in the Seen_1 state. If x is 1 in the Seen_1 state, it transitions to the Seen_10 state. In the Seen_10 state, if x is 1, it transitions back to the Seen_1 state. If x is 0 in the Seen_10 state, it stays in the Seen_10 state, but this is where we recognize the "101" sequence, so we set the output z to 1. The machine resets to the Idle state on the negative edge of the aresetn signal. We use a 2-bit signal, state, to represent the current state of the machine.
