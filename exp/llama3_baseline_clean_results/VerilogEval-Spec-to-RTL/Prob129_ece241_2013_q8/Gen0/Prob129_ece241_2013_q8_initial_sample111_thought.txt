To implement the Mealy-type finite state machine (FSM) that recognizes the sequence "101" on the input signal x, we need to design a state machine with three states. The states can be defined as follows:
- State 0 (IDLE): The initial state where the FSM waits for the first '1' in the sequence.
- State 1 (ONE_DETECTED): The state where the FSM has detected the first '1' and waits for the '0' in the sequence.
- State 2 (ZERO_DETECTED): The state where the FSM has detected the '0' after the first '1' and waits for the second '1' to complete the sequence.
The output z should be asserted to logic-1 when the FSM is in the State 2 and the input x is '1', indicating the recognition of the sequence "101". The FSM should also have a negative edge triggered asynchronous reset.
