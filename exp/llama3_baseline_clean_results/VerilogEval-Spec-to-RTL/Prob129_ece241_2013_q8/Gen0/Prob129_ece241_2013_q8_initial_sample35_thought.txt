To solve this problem, we can design a Mealy-type finite state machine with three states: S0 (initial state), S1 (after detecting '1'), and S2 (after detecting '01'). The state machine will transition from S0 to S1 when it detects '1' on input x, from S1 to S2 when it detects '0' on input x, and from S2 to S0 when it detects anything other than '1' on input x, or to S1 when it detects '1' on input x (overlapping sequence detection). The output signal z will be asserted when the state machine is in S2 and detects '1' on input x. We will use a negative edge triggered asynchronous reset to reset the state machine to S0.
