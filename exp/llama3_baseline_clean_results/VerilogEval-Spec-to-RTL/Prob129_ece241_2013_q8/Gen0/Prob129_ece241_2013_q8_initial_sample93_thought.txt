To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can define three states: S0 (initial state), S1 (state after seeing the first '1'), and S2 (state after seeing the '0' after the first '1'). We start in S0 and transition to S1 when we see a '1' in S0. Then, in S1, we transition to S2 when we see a '0'. Finally, in S2, we transition back to S1 when we see a '1', because this is where we can potentially see the "101" sequence again, and we assert the output z to '1'. If we see a '1' in S0, we transition to S1. If we see anything other than the '1' in S2, or anything other than a '0' in S1, we stay in the same state or go back to the initial state as necessary. We use an asynchronous reset to reset the state machine to S0 when the reset signal is asserted low.
