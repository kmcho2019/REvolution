To implement the Mealy-type finite state machine, we will define three states: IDLE, SEQ1, and SEQ2. The IDLE state will be the initial state where the FSM waits for the first '1' in the sequence. When the first '1' is detected, the FSM will transition to SEQ1. In the SEQ1 state, if a '0' is detected, the FSM will transition to SEQ2. In the SEQ2 state, if a '1' is detected, the FSM will assert the output z to logic-1. We will also implement an asynchronous reset that resets the FSM to the IDLE state when aresetn is low.
