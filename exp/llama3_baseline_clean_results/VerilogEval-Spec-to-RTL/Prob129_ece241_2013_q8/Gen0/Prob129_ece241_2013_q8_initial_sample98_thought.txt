To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we will define three states: Idle, Seen1, and Seen10. The Idle state is the initial state where the FSM waits for the first '1' in the sequence. When a '1' is detected, the FSM transitions to the Seen1 state. In the Seen1 state, the FSM waits for the '0' in the sequence. When a '0' is detected, the FSM transitions to the Seen10 state. In the Seen10 state, the FSM waits for the final '1' in the sequence. When the final '1' is detected, the output signal z is asserted to logic-1 for one clock cycle. The FSM then transitions back to the Seen1 state to recognize overlapping sequences. The FSM will also have a negative edge triggered asynchronous reset, which will reset the FSM to the Idle state when the reset signal aresetn is low.
