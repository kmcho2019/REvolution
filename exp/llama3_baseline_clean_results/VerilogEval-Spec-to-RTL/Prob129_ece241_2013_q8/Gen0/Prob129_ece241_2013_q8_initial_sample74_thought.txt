To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can define three states: 
- S0: Initial state, waiting for '1'
- S1: '1' received, waiting for '0'
- S2: '0' received after '1', waiting for the next '1' to trigger the output

The output z will be asserted when the state machine is in S2 and receives the '1' input on x.

We will use a case statement to handle the state transitions and output logic. 

The state machine will have an asynchronous reset on the negative edge of aresetn to ensure it resets to S0 immediately when reset is asserted.
