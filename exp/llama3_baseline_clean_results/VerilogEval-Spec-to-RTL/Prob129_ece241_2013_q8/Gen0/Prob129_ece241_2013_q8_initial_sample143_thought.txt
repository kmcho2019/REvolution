To implement a Mealy-type finite state machine (FSM) that recognizes the sequence "101" on the input signal x, we will define three states: Idle, Seen1, and Seen10. The FSM will start in the Idle state and transition to Seen1 when it sees a '1' on the input x. From the Seen1 state, if it sees a '0' on the input x, it will transition to the Seen10 state. Finally, from the Seen10 state, if it sees a '1' on the input x, it will assert the output z to logic-1 and remain in the Seen10 state because we want to recognize overlapping sequences. If at any point the input x does not match the next expected value in the sequence, the FSM will return to the Idle state. The FSM will have an asynchronous reset (aresetn) that resets the FSM to the Idle state when it is low.
