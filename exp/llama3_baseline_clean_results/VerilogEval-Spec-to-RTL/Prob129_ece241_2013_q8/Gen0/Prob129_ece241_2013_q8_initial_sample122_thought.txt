To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can define three states: IDLE, SEQ_1, and SEQ_10. The machine starts in the IDLE state. When the input x is 1, it transitions to the SEQ_1 state. If it receives a 0 in the SEQ_1 state, it transitions to the SEQ_10 state. If it then receives a 1 in the SEQ_10 state, it asserts the output z and transitions back to the SEQ_1 state. If at any point it receives an input that does not match the expected sequence, it transitions back to the IDLE state. The output z is asserted to logic-1 when the sequence "101" is detected. The machine also has a negative edge triggered asynchronous reset, which means it resets to the IDLE state when the aresetn signal is low.
