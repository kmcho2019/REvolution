To solve this problem, we will design a Mealy-type finite state machine (FSM) with 3 states. The FSM will recognize the sequence "101" on the input signal x and assert the output signal z to logic-1 when the sequence is detected. The states can be defined as follows: 
- State 0 (S0): Initial state, no sequence detected
- State 1 (S1): '1' detected
- State 2 (S2): '01' detected

The state transitions and output values will be as follows:
- From S0: if x = 1, move to S1; otherwise, stay in S0
- From S1: if x = 0, move to S2; if x = 1, stay in S1; output z is 0
- From S2: if x = 1, move to S1 and assert z to 1; if x = 0, move to S0

The FSM will have a negative edge triggered asynchronous reset, which means that when the reset signal aresetn is 0, the FSM will reset to the initial state S0, regardless of the current state or clock value.
