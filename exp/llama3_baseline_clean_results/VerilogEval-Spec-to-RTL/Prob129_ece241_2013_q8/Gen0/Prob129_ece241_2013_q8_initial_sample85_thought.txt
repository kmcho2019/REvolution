To implement the Mealy-type finite state machine, we can define three states: 
State 0 (S0) as the initial state or the state where no sequence has been detected yet, 
State 1 (S1) as the state where the first '1' of the sequence has been detected, 
and State 2 (S2) as the state where the '0' of the sequence has been detected after the first '1'. 
The state machine will transition from S0 to S1 when it encounters a '1', 
from S1 to S2 when it encounters a '0' after a '1', and from S2 to S0 when it encounters a '1' again (which means the sequence "101" has been detected). 
The output signal z will be asserted to logic-1 when the state machine is in the transition from S2 to S0. 
We will also implement an asynchronous reset that will reset the state machine to S0 when aresetn is low.
