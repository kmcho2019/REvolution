To implement the Mealy-type finite state machine, we will define three states: IDLE, ONE_DETECTED, and ZERO_ONE_DETECTED. 
The machine starts in the IDLE state. 
When in the IDLE state and the input x is 1, the machine transitions to the ONE_DETECTED state and the output z is 0. 
When in the ONE_DETECTED state and the input x is 0, the machine transitions to the ZERO_ONE_DETECTED state and the output z is 0. 
When in the ZERO_ONE_DETECTED state and the input x is 1, the machine transitions back to the ONE_DETECTED state and the output z is asserted to 1. 
If at any state the input x does not match the expected input, the machine transitions back to the IDLE state if necessary and the output z is 0. 
The machine also has a negative edge triggered asynchronous reset, which resets the machine to the IDLE state when aresetn is 0.
