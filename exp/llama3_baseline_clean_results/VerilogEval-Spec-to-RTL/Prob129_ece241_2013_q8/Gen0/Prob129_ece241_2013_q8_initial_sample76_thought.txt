To implement a Mealy-type finite state machine (FSM) that recognizes the sequence "101" on an input signal x, we can define three states: 
- State 0: Initial state where no sequence has been detected yet.
- State 1: State where the first '1' of the sequence has been detected.
- State 2: State where the '0' of the sequence has been detected after the first '1'.

The FSM transitions between these states based on the input signal x. 
- From State 0 to State 1 when x is '1'.
- From State 1 to State 2 when x is '0'.
- From State 2 back to State 0 when x is not '1', and to State 1 when x is '1', because the sequence "101" is detected and the FSM should be ready to detect overlapping sequences.

The output signal z is asserted to '1' when the FSM is in State 2 and the input signal x is '1', indicating the detection of the sequence "101". 

To implement the asynchronous reset, we use the aresetn signal, which resets the FSM to State 0 whenever it is '0'.
