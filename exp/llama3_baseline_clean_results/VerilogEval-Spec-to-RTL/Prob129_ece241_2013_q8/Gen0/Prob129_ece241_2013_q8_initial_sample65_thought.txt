To implement the Mealy-type finite state machine, we can define three states: 
IDLE, SEEN_1, and SEEN_10. The IDLE state is the initial state where we start 
looking for the sequence "101". When we see a '1' in the IDLE state, we move 
to the SEEN_1 state. If we see a '0' in the SEEN_1 state, we move to the SEEN_10 
state. If we see a '1' in the SEEN_10 state, we recognize the sequence "101" and 
assert the output z to '1'. If we see a '0' in the IDLE or SEEN_10 state, or a '0' 
in the SEEN_1 state, we stay in or move back to the IDLE state. The asynchronous 
reset will reset the state to IDLE when aresetn is '0'.
