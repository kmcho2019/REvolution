To solve this problem, we need to design a Mealy-type finite state machine (FSM) that recognizes the sequence "101" on the input signal x. We will have 3 states: IDLE, SEEN_1, and SEEN_10. The FSM starts in the IDLE state and transitions to the SEEN_1 state when it sees a '1' on the input x. From the SEEN_1 state, it transitions to the SEEN_10 state when it sees a '0' on the input x. From the SEEN_10 state, it transitions back to the SEEN_1 state when it sees a '1' on the input x and asserts the output z to '1'. If the FSM is in the IDLE or SEEN_10 state and sees a '0' on the input x, it stays in the same state. If the FSM is in the SEEN_1 state and sees a '0' on the input x, it transitions to the SEEN_10 state. We will also implement an asynchronous reset that resets the FSM to the IDLE state when the reset signal aresetn is '0'. The output z will be asserted to '1' when the FSM is in the SEEN_10 state and sees a '1' on the input x.
