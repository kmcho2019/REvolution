To implement the Mealy-type finite state machine, we will define three states: S0 (initial state), S1 (state after '1' is received), and S2 (state after '0' is received after '1'). We will use a Mealy machine because the output depends on the current state and the input. The machine will recognize the sequence "101" and assert the output 'z' when this sequence is detected. The states will be encoded using 2 bits. The machine will have an asynchronous reset that will reset the state machine to the initial state S0 when the reset signal 'aresetn' is low. The state machine will recognize overlapping sequences.
