To implement the Mealy-type finite state machine (FSM) in Verilog, we'll define three states: Idle (waiting for the first '1'), GotOne (waiting for the '0' after the first '1'), and GotZero (waiting for the second '1' after the '0'). The FSM will transition between these states based on the input signal x and will assert the output z to logic-1 when the "101" sequence is detected. We'll use an enum to define the states, and a case statement within a always_ff block to implement the state transitions and output logic. The aresetn signal will be used to asynchronously reset the FSM to the Idle state on its negative edge.
