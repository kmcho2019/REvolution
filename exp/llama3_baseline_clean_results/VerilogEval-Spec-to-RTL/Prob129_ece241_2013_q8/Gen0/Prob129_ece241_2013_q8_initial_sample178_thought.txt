To implement the Mealy-type finite state machine (FSM) that recognizes the sequence "101", we can define three states: S0 (initial state), S1 (after seeing '1'), and S2 (after seeing '0' following '1'). The FSM will transition between these states based on the input signal x. When the sequence "101" is detected, the output signal z will be asserted to logic-1. We will use a negative edge triggered asynchronous reset to reset the FSM to the initial state S0. The sequential logic will be triggered on the positive edge of the clock.
