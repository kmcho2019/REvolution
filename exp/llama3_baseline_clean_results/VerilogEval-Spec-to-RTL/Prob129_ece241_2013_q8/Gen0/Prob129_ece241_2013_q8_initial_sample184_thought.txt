To implement the Mealy-type finite state machine that recognizes the sequence "101", we can define three states: idle (waiting for the first '1'), got_1 (after seeing the first '1', waiting for '0'), and got_10 (after seeing '10', waiting for the final '1'). The state machine starts in the idle state. When the sequence is detected, the output z is asserted. The machine is reset to the idle state on the negative edge of the aresetn signal. We will use a case statement to handle the different states and the corresponding next states based on the input x.
