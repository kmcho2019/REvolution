To implement the Mealy-type finite state machine, we will use three states: IDLE, ONE, and ZERO_ONE. The IDLE state will be the initial state. When the input signal x is '1', the FSM will transition to the ONE state. From the ONE state, if x is '0', it will transition to the ZERO_ONE state. If x is '1' from the ZERO_ONE state, the FSM will assert the output signal z to '1' and remain in the ZERO_ONE state to recognize overlapping sequences. If x is '0' from the ZERO_ONE state, the FSM will transition back to the IDLE state. The FSM will have an asynchronous reset, aresetn, which will reset the FSM to the IDLE state when it is '0'. The output signal z will be '1' only when the sequence "101" is detected.
