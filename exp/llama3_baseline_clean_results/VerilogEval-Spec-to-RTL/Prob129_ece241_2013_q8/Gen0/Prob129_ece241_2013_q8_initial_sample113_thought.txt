To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can define three states: Idle, Seen_1, and Seen_10. The FSM starts in the Idle state. When the FSM is in the Idle state and the input x is 1, it transitions to the Seen_1 state. If the FSM is in the Seen_1 state and the input x is 0, it transitions to the Seen_10 state. If the FSM is in the Seen_10 state and the input x is 1, it asserts the output z and remains in the Seen_10 state to recognize overlapping sequences. If the input x is not 1 in the Seen_10 state, it transitions back to the Seen_1 state if x is 0 and back to the Idle state if x is 1. The FSM also includes an asynchronous reset that sets the FSM to the Idle state when the aresetn signal is low. The output z is asserted to logic-1 when the "101" sequence is detected and is otherwise 0.
