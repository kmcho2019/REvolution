To implement the Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can define three states: S0 (initial state), S1 (seen '1'), and S2 (seen '10'). We start in S0 and move to S1 when we see a '1' on x. From S1, if we see a '0' on x, we move to S2. From S2, if we see a '1' on x, we assert the output z to '1' and move back to S1 because we are looking for overlapping sequences. If we are in any state and see an input that does not match the next expected input in the sequence, we return to S0. The negative edge triggered asynchronous reset will be used to reset the state machine to S0.
