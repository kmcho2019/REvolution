To implement the Mealy-type finite state machine, we will define three states: S0 (initial state), S1 (after detecting '1'), and S2 (after detecting '0' following '1'). We start at S0. When '1' is detected, we move to S1. From S1, if '0' is detected, we move to S2. From S2, if '1' is detected, we move back to S1 and set the output z to '1' because the sequence '101' has been detected. We will also include an asynchronous reset to reset the state machine to S0 when the reset signal is asserted. The output z will be set to '0' in all states except when the sequence '101' is detected.
