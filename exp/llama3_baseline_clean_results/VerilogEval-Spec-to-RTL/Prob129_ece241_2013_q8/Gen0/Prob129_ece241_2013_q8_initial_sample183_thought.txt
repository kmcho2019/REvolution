To implement the Mealy-type finite state machine (FSM) that recognizes the sequence "101" on the input signal x, we can use three states: S0 (initial state), S1 (after seeing '1'), and S2 (after seeing '01'). The FSM transitions between these states based on the current input x and the current state. The output z is asserted to logic-1 when the sequence "101" is detected. We will use a negative edge triggered asynchronous reset to reset the FSM to its initial state S0 when aresetn is low. The sequential logic is triggered on the positive edge of the clock clk.
