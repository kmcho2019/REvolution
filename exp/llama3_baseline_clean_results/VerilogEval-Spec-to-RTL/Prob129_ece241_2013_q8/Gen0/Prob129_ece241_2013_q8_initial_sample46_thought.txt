To implement a Mealy-type finite state machine in Verilog that recognizes the sequence "101" on the input signal x, we will define three states: IDLE, GOT_1, and GOT_10. The FSM starts in the IDLE state. When the input x is 1 in the IDLE state, the FSM transitions to the GOT_1 state. If the input x is 0 in the GOT_1 state, the FSM transitions to the GOT_10 state. If the input x is 1 in the GOT_10 state, the FSM asserts the output z to 1 and transitions back to the GOT_1 state. If the input x is 0 in the GOT_10 state or if the FSM is in the IDLE or GOT_1 states and the input x does not match the expected sequence, the FSM transitions accordingly to either stay in the same state or move to the next state based on the input. We will also implement an asynchronous reset that resets the FSM to the IDLE state when asserted low.
