To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can define three states: IDLE, S1, and S2. The IDLE state is the initial state where we wait for the first '1' to appear on the input signal x. Once we see the first '1', we transition to the S1 state. If we see a '0' on the input signal x in the S1 state, we transition to the S2 state. If we see a '1' on the input signal x in the S2 state, we assert the output signal z to logic-1, indicating that we have detected the sequence "101". We also need to handle the case where the sequence "101" is detected and a '1' is still present on the input signal x, in this case, we should still be able to detect overlapping sequences. We use a negative edge triggered asynchronous reset to reset the FSM to the IDLE state.
