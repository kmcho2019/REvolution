To solve this problem, we can design a 3-state Mealy-type finite state machine. The states can be named as follows: 
- S0 (initial state): No sequence detected yet.
- S1: '1' detected, waiting for '0'.
- S2: '10' detected, waiting for '1'.
When the FSM is in state S2 and it detects '1', it asserts the output z to logic-1. 
The asynchronous reset will be used to reset the FSM back to S0 when aresetn goes low. 
All state transitions will be triggered on the positive edge of the clock.
