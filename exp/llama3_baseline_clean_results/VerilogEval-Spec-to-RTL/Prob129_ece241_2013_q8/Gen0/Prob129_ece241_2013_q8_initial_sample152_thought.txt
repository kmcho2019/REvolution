To implement the Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we need to design a state machine with three states: Idle, Seen1, and Seen10. The machine starts in the Idle state and transitions to the Seen1 state when it sees a '1' on the input x. From the Seen1 state, it transitions to the Seen10 state when it sees a '0' on the input x. From the Seen10 state, it transitions back to the Idle state when it sees a '1' on the input x, asserting the output z to '1' at the same time. If at any point it sees an input that does not match the expected sequence, it transitions back to the Idle state. The state machine should also have an asynchronous reset that clears all states and outputs when asserted low.
