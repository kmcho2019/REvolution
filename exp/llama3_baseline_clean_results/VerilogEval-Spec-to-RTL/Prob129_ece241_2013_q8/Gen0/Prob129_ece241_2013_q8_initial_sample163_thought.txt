To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we will define three states: S0, S1, and S2. The machine starts in S0. When the machine is in S0 and x is 1, it transitions to S1. When the machine is in S1 and x is 0, it transitions to S2. When the machine is in S2 and x is 1, the sequence "101" is detected and z is asserted. The machine resets to S0 on the negative edge of the aresetn signal. The state machine can also recognize overlapping sequences by transitioning back to S1 when x is 1 in state S2, or back to S0 when x is 0 in state S1.
