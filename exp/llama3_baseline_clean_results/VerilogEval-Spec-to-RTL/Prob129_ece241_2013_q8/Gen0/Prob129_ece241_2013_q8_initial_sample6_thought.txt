To implement the Mealy-type finite state machine, we can define three states: 
IDLE (initial state), GOT_1, and GOT_10. We will start in the IDLE state and 
transition to GOT_1 when we see the first '1' in the sequence, then to GOT_10 
when we see a '0' after a '1', and finally, we will assert the output 'z' when 
we see another '1' after a '0' following a '1'. We will also reset to the IDLE 
state whenever the asynchronous reset 'aresetn' is low or when a sequence other 
than "101" is detected. 
The output 'z' will be asserted high only when the FSM is in the GOT_10 state 
and the input 'x' is high. 
We will use a case statement inside a always_ff block to model the next state 
logic and a case statement inside a always_comb block to model the output logic.
