To implement a Mealy-type finite state machine that recognizes the sequence "101" on the input signal x, we can define three states: Idle, Seen1, and Seen10. The FSM starts in the Idle state. When the input x is '1' in the Idle state, it transitions to the Seen1 state. If x is '0' in the Seen1 state, it transitions to the Seen10 state. If x is '1' in the Seen10 state, it asserts the output z to '1' (indicating the sequence "101" has been detected) and stays in the Seen10 state because we're allowing overlapping sequences. For any other input combinations, it either stays in its current state or resets to the Idle state as needed. The asynchronous reset input aresetn is used to reset the FSM to its initial state (Idle) on its negative edge.
