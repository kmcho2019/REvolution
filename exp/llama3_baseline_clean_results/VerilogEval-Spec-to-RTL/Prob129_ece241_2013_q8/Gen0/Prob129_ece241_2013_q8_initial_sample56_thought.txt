To implement the Mealy-type finite state machine, we will use three states: 
IDLE, ONE_DETECTED, and ZERO_DETECTED. The machine starts in the IDLE state. 
When the input x is '1', it transitions to the ONE_DETECTED state. 
When the input x is '0' and the current state is ONE_DETECTED, it transitions to the ZERO_DETECTED state. 
When the input x is '1' and the current state is ZERO_DETECTED, it asserts the output z to '1' and transitions back to the ONE_DETECTED state. 
If aresetn is '0', the machine resets to the IDLE state asynchronously.

We will use a 2-bit state register, with the encoding: IDLE (2'b00), ONE_DETECTED (2'b01), and ZERO_DETECTED (2'b10).
