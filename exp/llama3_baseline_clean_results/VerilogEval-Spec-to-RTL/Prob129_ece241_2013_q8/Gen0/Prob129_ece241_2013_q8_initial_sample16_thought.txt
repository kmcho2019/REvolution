To implement the Mealy-type finite state machine, we will define three states: IDLE, S1, and S2. 
The IDLE state is the initial state, S1 is the state after detecting a '1' in the input sequence, 
and S2 is the state after detecting a '0' following the '1'. The output signal z is asserted 
to logic-1 when we are in state S2 and the current input x is '1'. The FSM should recognize 
overlapping sequences, meaning that once the sequence "101" is detected, the FSM should 
immediately start looking for the next occurrence of "1" in the input sequence. 
The FSM will have an asynchronous reset, so when the reset signal aresetn is low, 
the FSM will be reset to the IDLE state, regardless of the current state or clock edge.
