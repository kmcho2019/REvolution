To implement the thermostat controller, we can use a simple combinational logic circuit. We will first determine if the heater or air conditioner should be turned on based on the mode and the temperature. Then, we will determine if the fan should be turned on based on whether the heater or air conditioner is on, or if the user has requested the fan to be turned on. 
We will use the following logic:
- If the mode is 1 (heating), then the heater is on if it is too cold, and the air conditioner is off.
- If the mode is 0 (cooling), then the air conditioner is on if it is too hot, and the heater is off.
- The fan is on if the heater is on, the air conditioner is on, or the user has requested the fan to be turned on.
