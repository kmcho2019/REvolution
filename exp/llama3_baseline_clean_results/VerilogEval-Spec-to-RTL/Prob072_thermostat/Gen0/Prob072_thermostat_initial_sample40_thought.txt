The TopModule should implement a simple state machine based on the input mode. 
In heating mode (mode = 1), the module should check the too_cold signal and turn on the heater if it's high. 
In cooling mode (mode = 0), the module should check the too_hot signal and turn on the air conditioner if it's high. 
The fan should be turned on whenever the heater or air conditioner is on, or when the fan_on signal is high. 
This logic can be implemented using basic combinational logic in Verilog.
