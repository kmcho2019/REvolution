The TopModule can be implemented using a simple combinational logic. 
First, we need to check the mode of the thermostat. 
If the mode is 1 (heating), we check if it's too cold, and if so, turn on the heater and the fan. 
If the mode is 0 (cooling), we check if it's too hot, and if so, turn on the air conditioner and the fan. 
Regardless of the mode, if the fan is requested to be on, we turn it on. 
We can use simple logical operations (AND, OR) to implement this logic.
