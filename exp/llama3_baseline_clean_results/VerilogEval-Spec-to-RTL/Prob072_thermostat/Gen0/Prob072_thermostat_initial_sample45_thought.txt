The thermostat controller can be implemented using a simple combinational logic. The heater is turned on when the mode is 1 (heating mode) and it is too cold. The air conditioner is turned on when the mode is 0 (cooling mode) and it is too hot. The fan is turned on when either the heater or air conditioner is on, or when the user requests it to be on. This can be achieved using a combination of logical AND and OR operations.
