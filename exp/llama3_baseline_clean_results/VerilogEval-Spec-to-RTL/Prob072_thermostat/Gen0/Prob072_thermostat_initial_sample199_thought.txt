The TopModule can be implemented using a simple combinational logic approach. 
We will use the mode input to determine whether we are in heating or cooling mode. 
In heating mode, the heater will be turned on if it is too cold, and in cooling mode, 
the air conditioner will be turned on if it is too hot. The fan will be turned on 
whenever the heater or air conditioner is on, or if the fan_on input is high. 
This logic can be implemented using basic logical operators in Verilog.
