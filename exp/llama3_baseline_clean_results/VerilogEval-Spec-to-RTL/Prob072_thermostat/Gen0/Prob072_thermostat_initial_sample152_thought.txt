The TopModule can be designed using simple conditional logic to control the outputs based on the inputs. 
In heating mode (mode = 1), the heater should be turned on when it's too cold (too_cold = 1) and the air conditioner should be off. 
In cooling mode (mode = 0), the air conditioner should be turned on when it's too hot (too_hot = 1) and the heater should be off. 
The fan should be turned on when either the heater or air conditioner is on, or when the user requests it (fan_on = 1).
This logic can be implemented using Verilog's conditional statements (if-else) and logical operators (&&, ||).
