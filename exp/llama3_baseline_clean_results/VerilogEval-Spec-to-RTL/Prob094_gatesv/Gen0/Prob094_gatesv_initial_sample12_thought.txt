The module TopModule can be implemented by using bitwise logical operations. 
For out_both, we need to perform a bitwise AND operation between each bit and its neighbour to the left. 
For out_any, we need to perform a bitwise OR operation between each bit and its neighbour to the right. 
For out_different, we need to perform a bitwise XOR operation between each bit and its neighbour to the left, considering the vector as wrapping around.
