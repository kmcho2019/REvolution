To reverse the byte order of a 32-bit vector, we need to swap the bytes in the following manner: 
byte 0 with byte 3, byte 1 with byte 2. 
This can be achieved using Verilog's bit-slicing feature. 
The new byte 0 will be the original byte 3, 
the new byte 1 will be the original byte 2, 
the new byte 2 will be the original byte 1, 
and the new byte 3 will be the original byte 0.
