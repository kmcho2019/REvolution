To reverse the byte order of a 32-bit vector, we can simply rearrange the bytes. Since a byte is 8 bits, we can divide the 32-bit input into four bytes. Then, we can output these bytes in reverse order. For example, if the input is {byte3, byte2, byte1, byte0}, the output will be {byte0, byte1, byte2, byte3}. This can be achieved using Verilog's bit slicing and concatenation features.
