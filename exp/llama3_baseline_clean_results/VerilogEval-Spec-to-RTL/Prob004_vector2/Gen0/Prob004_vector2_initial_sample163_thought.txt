To reverse the byte order of a 32-bit vector, we can simply rearrange the bytes. A 32-bit vector consists of 4 bytes, each 8 bits long. If the input vector is in the order B3 B2 B1 B0 (where B3 is the most significant byte and B0 is the least significant byte), we want the output to be in the order B0 B1 B2 B3. This can be achieved by assigning the least significant byte of the input to the most significant byte of the output, the next byte of the input to the next most significant byte of the output, and so on.
