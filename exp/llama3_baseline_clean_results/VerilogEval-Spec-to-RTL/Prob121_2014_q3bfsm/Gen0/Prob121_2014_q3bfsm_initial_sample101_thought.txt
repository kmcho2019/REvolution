To implement the TopModule, we will first define the state encoding for each state in the state-assigned table. Then, we will use a always_ff block to describe the sequential logic of the finite-state machine (FSM). Inside the always_ff block, we will implement the synchronous active-high reset functionality and the state transitions based on the current state and input x. We will also use an always_comb block to describe the combinational logic for the output z based on the current state.
