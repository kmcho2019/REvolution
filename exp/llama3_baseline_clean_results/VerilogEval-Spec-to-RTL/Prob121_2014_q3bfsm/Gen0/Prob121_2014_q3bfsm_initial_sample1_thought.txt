To implement the finite-state machine described, we need to follow these steps:
1. Define the states of the machine: We can use a 3-bit signal to represent the states (y[2:0]) as there are a total of 5 states mentioned (not all 2^3=8 possible states are used).
2. Create a state transition table: This is already given. It describes the next state of the machine based on its current state and the input x.
3. Implement the state transition logic: This involves writing Verilog code to implement the state transitions.
4. Implement the output logic: The output z is also determined by the current state.
5. Add the reset logic: The machine should reset to state 000 when the reset input is high.

We will use a case statement to implement the state transition logic. For the output logic, we will use another case statement that checks the current state to determine the output z.
