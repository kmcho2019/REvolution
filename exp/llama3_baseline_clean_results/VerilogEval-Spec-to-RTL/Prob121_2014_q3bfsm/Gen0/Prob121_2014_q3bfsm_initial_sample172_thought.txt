To implement the TopModule with the given finite-state machine (FSM) specifications, we will first encode the states as binary numbers and then use a state machine description in Verilog to describe the next state logic and the output logic. We will use a 3-bit vector to represent the current state (y) and next state (next_y) since there are eight possible states in the FSM. The output z will be determined based on the current state. We will also include a synchronous active-high reset to reset the FSM to state 000 when reset is high.
