To implement the finite-state machine (FSM) as described, we'll follow these steps:
1. Define the states: We have 8 possible states from 000 to 111, but not all are used in the state transition table. We will define an enumeration for the used states for clarity.
2. Implement the state transition logic: Based on the current state and the input `x`, we will determine the next state.
3. Implement the output logic: The output `z` is determined by the current state.
4. Use a register to store the current state and update it on the positive edge of the clock, with synchronous reset to state 000 when `reset` is high.
