To implement the finite-state machine (FSM) in Verilog, we need to follow these steps:
1. Define the states of the FSM and their corresponding binary representations.
2. Create a state register to store the current state of the FSM.
3. Determine the next state of the FSM based on the current state and the input x.
4. Generate the output z based on the current state and the input x.
5. Implement a synchronous reset to reset the FSM to the initial state when the reset signal is high.

We can use a 3-bit vector to represent the states of the FSM. We will use a case statement to determine the next state and the output z based on the current state and the input x.
