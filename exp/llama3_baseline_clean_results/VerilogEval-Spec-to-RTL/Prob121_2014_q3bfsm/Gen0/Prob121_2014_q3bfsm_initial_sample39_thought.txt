To implement the finite-state machine (FSM) in Verilog, we first define the states as an enumeration within a parameterized module. Then, we use a synchronous reset to set the initial state to 000 when reset is high. Next, we use a case statement inside a always block to determine the next state based on the current state and input x. We then use another case statement to determine the output z based on the current state. Finally, we update the current state with the next state at the positive edge of the clock.
