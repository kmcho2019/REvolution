The TopModule should be implemented as a finite-state machine (FSM) with a synchronous reset. The FSM has 8 states (from 000 to 111), but only the states listed in the table are used. The module should have a 3-bit state register to hold the current state, and combinational logic to determine the next state and output based on the current state and input. The state register should be reset to 000 on the positive edge of the clock when the reset signal is high.
