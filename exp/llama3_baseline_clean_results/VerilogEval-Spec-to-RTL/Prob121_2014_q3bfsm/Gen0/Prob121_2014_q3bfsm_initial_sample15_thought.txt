The TopModule will be designed as a finite-state machine (FSM) with 8 possible states (from 000 to 111), but the state table only specifies 5 of them. The unspecified states will be treated as don't care conditions. We will use a 3-bit vector to represent the current state and a case statement to implement the state transition logic. The output z will be determined by the current state. On every positive edge of the clock, if reset is high, the state will be reset to 000. Otherwise, the next state will be determined by the current state and the input x.
