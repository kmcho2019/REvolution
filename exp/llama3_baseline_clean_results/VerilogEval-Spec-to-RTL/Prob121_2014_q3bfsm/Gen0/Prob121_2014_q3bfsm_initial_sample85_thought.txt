To implement the finite-state machine (FSM) as described, we will use a combinational logic block to determine the next state and the output based on the current state and input x, and a sequential logic block (a register) to hold the current state and update it based on the next state at each clock edge. The FSM will be reset to state '000' when the reset signal is high. We'll use a case statement to define the state transitions and output values according to the given state table.
