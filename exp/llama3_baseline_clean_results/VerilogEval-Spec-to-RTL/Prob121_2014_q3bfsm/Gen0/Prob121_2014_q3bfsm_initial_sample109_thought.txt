To implement the given finite-state machine (FSM), we need to follow these steps:
1. Define the states: We have a total of 5 states as specified in the state-assigned table (000, 001, 010, 011, 100).
2. Create the state register: Since we have 3 bits to represent the states, we need a 3-bit register to store the current state.
3. Implement the state transition logic: Based on the current state and input x, we need to determine the next state.
4. Implement the output logic: Based on the current state, we need to determine the output z.
5. Handle the synchronous active high reset: When the reset signal is high, the FSM should reset to state 000.

We will use a case statement to implement the state transition logic and the output logic.
