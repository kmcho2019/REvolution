To implement the finite-state machine (FSM) described, we'll use a combination of always blocks in Verilog to handle both the combinational logic (next state and output) and the sequential logic (state transition). The FSM has 8 possible states (000 to 111), but only the states 000, 001, 010, 011, and 100 are utilized in the state table. We'll encode these states using a 3-bit vector y. The next state logic will be determined based on the current state (y) and the input (x). The output z will also depend on the current state. We'll use a case statement to simplify the description of the next state logic.
