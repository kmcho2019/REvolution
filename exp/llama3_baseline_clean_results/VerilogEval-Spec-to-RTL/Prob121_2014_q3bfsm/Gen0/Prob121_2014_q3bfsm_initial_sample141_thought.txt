To implement the finite-state machine described, we will use a combination of sequential logic to store the current state and combinational logic to determine the next state based on the current state and input x. The state will be stored in a 3-bit register y. On every positive clock edge, if the reset signal is high, the state will be reset to 000. Otherwise, the next state will be determined according to the state table and loaded into the state register. The output z will be determined based on the current state.
