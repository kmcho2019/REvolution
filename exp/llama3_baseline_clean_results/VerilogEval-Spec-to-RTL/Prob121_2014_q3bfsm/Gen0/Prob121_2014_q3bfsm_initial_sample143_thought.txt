To implement the finite-state machine (FSM) in the TopModule, we need to define the states, transitions, and outputs according to the provided state-assigned table. We'll use a 3-bit vector to represent the states (y[2:0]) and encode them as follows: 
- State 000: 3'b000
- State 001: 3'b001
- State 010: 3'b010
- State 011: 3'b011
- State 100: 3'b100

The module will have a synchronous reset. We will use a case statement to implement the state transitions and the output logic.
