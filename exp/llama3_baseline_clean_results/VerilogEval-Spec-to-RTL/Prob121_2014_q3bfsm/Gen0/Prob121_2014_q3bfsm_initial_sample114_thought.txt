To implement the TopModule, we first need to define the finite-state machine (FSM) using the provided state-assigned table. Since the table specifies both the next states and the output z for each current state and input x, we can directly map this into a Verilog module.

The module will have three states (y[2:0]), each corresponding to a binary value from 000 to 100 (0 to 4 in decimal). We will use a case statement to handle the different states and their transitions based on the input x.

To handle the synchronous reset, we will check if reset is high and set the current state to 000. Otherwise, we will proceed with the state transition logic based on the current state and input x.

The output z will be determined by the current state and the input x according to the provided table.
