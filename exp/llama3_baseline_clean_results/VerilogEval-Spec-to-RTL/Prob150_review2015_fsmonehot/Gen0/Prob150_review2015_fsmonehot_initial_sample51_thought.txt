The Moore state machine has 10 states (S, S1, S11, S110, B0, B1, B2, B3, Count, Wait) and 3 inputs (d, done_counting, ack). To derive the next-state logic and output logic equations, we will use the one-hot encoding. The state machine starts in state "S" at reset.

The next-state logic equations are derived based on the current state and the inputs. For example, if the current state is S and d = 1, the next state is S1.

The output logic equations are derived based on the current state. For example, the output shift_ena is 1 when the current state is B0, B1, B2, or B3.
