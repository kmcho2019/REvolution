To implement the state machine, we need to first identify the current state and then determine the next state based on the inputs. We can use the one-hot encoding to simplify the process. 

For each state, we can write a conditional statement to check if it's the current state and then determine the next state based on the inputs. We can also use the same approach to determine the output logic.

We will use the following steps:
- Determine the current state using the one-hot encoding.
- Use conditional statements to determine the next state and output logic.
- Assign the next state and output signals based on the conditions.
