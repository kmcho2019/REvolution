To implement the state machine, we first need to decode the current state and then apply the state transition logic based on the inputs d, done_counting, and ack. The next-state logic is determined by the current state and the inputs. The output logic for shift_ena, counting, and done is also determined by the current state. We use the one-hot encoding to simplify the logic equations.

We can break down the implementation into two parts: 
1. Next-state logic: Determine the next state based on the current state and inputs.
2. Output logic: Determine the outputs shift_ena, counting, and done based on the current state.

We will use Verilog's bitwise operators to simplify the implementation of the next-state logic and output logic.
