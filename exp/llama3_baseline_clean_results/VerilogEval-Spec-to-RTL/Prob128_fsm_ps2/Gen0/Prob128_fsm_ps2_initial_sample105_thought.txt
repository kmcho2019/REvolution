To solve this problem, we can implement a finite state machine (FSM) with the following states:
- IDLE: Wait for the first byte of a message (in[3] = 1).
- BYTE1: Receive the first byte of the message.
- BYTE2: Receive the second byte of the message.
- BYTE3: Receive the third byte of the message and signal done.
The FSM will transition between these states based on the input byte stream and signal done when all 3 bytes have been received.
