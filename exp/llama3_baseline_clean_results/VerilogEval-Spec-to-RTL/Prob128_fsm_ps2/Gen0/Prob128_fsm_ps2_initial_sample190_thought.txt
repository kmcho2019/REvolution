To solve this problem, we can design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state and waits for a byte with in[3]=1 to arrive. Once such a byte is received, it transitions to the BYTE1 state and counts the subsequent two bytes. After receiving all three bytes, it signals done in the cycle immediately after the third byte and then transitions back to the IDLE state. The reset signal should be able to reset the FSM to the IDLE state at any time.
