To implement the TopModule, we'll design a finite state machine (FSM) that checks the input byte stream for the message boundary. The FSM will have four states: Idle, Byte1, Byte2, and Byte3. In the Idle state, the FSM will discard bytes until it finds one with in[3]=1, at which point it will transition to the Byte1 state. The FSM will then stay in Byte1, Byte2, and Byte3 states for one clock cycle each, and signal done in the cycle immediately after the third byte of each message was successfully received.
