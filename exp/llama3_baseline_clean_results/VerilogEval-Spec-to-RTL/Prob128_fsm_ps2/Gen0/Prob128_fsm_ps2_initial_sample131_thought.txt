To implement the TopModule, we can use a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM will start in the IDLE state and stay there until it encounters a byte with in[3]=1. Once it finds such a byte, it will transition to the BYTE1 state and start counting the number of bytes received. After receiving the second byte, it will transition to the BYTE2 state, and after receiving the third byte, it will transition to the BYTE3 state. In the BYTE3 state, the FSM will assert the done signal to indicate that a complete message has been received. The FSM will then reset to the IDLE state to search for the next message. The FSM will also be reset to the IDLE state when the reset signal is high.
