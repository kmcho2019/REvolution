To implement the TopModule, we will use a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state and waits for a byte with in[3]=1. Once such a byte is received, it transitions to the BYTE1 state and counts the subsequent bytes. After receiving three bytes, it signals done in the next clock cycle and then transitions back to the IDLE state. The FSM will also reset to the IDLE state when the reset signal is high.
