To solve this problem, we can implement a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. The FSM starts in the IDLE state, where it discards bytes until it sees one with in[3]=1. When such a byte is seen, it transitions to the BYTE1 state, assuming the current byte is the first byte of a message. Then, it transitions to the BYTE2 state after receiving the second byte, regardless of its value. Finally, after receiving the third byte, it signals the receipt of a message by asserting the done signal and transitions back to the IDLE state. We will use a 2-bit counter to keep track of the current byte in the message. The reset signal will be used to reset the FSM to the IDLE state.
