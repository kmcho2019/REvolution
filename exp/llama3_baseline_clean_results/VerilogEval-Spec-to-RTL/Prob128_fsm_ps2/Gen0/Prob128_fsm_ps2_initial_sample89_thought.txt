The TopModule will be implemented as a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, the module waits for the first byte with in[3]=1 to arrive. 
Once such a byte is detected, it transitions to the BYTE1 state. 
In the BYTE1 state, the module waits for the second byte of the message, then transitions to the BYTE2 state. 
In the BYTE2 state, the module waits for the third byte of the message, then transitions to the BYTE3 state. 
In the BYTE3 state, the module sets the done signal high for one clock cycle, then returns to the IDLE state.
The reset signal is used to asynchronously set the FSM back to the IDLE state.
