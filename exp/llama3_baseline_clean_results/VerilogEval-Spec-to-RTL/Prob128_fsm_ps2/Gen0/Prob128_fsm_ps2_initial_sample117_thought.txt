To implement the TopModule, we will design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, we will continuously check the input byte stream for a byte with in[3]=1, which indicates the start of a message. 
Once we find such a byte, we will transition to the BYTE1 state and start counting the bytes. 
We will then transition to the BYTE2 and BYTE3 states after receiving the subsequent bytes. 
In the BYTE3 state, we will signal the receipt of a message by asserting the done signal in the next clock cycle.
We will also handle the reset signal, which will reset the FSM to the IDLE state when asserted.
