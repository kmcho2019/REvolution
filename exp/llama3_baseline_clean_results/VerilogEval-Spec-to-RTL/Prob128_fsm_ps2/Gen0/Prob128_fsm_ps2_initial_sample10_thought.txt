To solve this problem, we'll create a finite state machine (FSM) with states representing the current position in the message reception process. The states will be: IDLE (waiting for a byte with in[3]=1), BYTE1 (first byte of the message received), BYTE2 (second byte received), and BYTE3 (third byte received, ready to signal done). The FSM will transition between these states based on the value of in[3] and the current state. We'll use a counter to keep track of the current state and a flag to indicate when a message is complete.
