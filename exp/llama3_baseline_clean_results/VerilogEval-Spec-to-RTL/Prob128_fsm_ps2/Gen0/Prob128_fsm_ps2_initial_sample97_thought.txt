To solve this problem, we can design a finite state machine (FSM) with the following states: 
- Idle: The initial state where we wait for a byte with in[3] = 1 to arrive. 
- Byte1: After we've received a byte with in[3] = 1, we move to this state and wait for the next two bytes. 
- Byte2: After receiving the second byte, we move to this state and wait for the third byte.
- Byte3: After receiving the third byte, we move to this state and assert the done signal.

We'll use a counter to keep track of the current byte in the message and reset it when we reach the end of a message or when the reset signal is asserted.
