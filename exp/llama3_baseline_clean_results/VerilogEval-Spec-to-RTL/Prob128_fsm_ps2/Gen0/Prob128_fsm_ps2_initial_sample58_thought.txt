To implement the finite state machine in the TopModule, we need to consider the following states: 
1. Idle: Wait for a byte with in[3] = 1 to start a new message.
2. Byte1: First byte of the message has been received, wait for the second byte.
3. Byte2: Second byte of the message has been received, wait for the third byte.
4. Done: All three bytes of the message have been received, signal done.

We will use a 2-bit state variable to represent these four states. 
We'll also use a counter to keep track of the bytes received. 
The done signal will be asserted in the cycle immediately after the third byte of each message was successfully received.
