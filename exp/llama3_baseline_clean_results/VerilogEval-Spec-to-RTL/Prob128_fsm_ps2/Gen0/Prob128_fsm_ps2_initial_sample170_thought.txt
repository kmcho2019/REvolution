To solve this problem, we'll implement a finite state machine (FSM) in the TopModule that can identify message boundaries in a continuous byte stream. The FSM will have states for searching for the first byte of a message (where in[3] = 1), and then for receiving the subsequent two bytes. Once all three bytes of a message are received, the FSM will signal 'done'. The module will also be resettable via a synchronous active-high reset signal.
