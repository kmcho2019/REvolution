To solve this problem, we need to implement a finite state machine (FSM) in Verilog. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. In the IDLE state, the FSM will discard bytes until it sees one with in[3]=1. Once this condition is met, it will transition to the BYTE1 state. The FSM will then wait for two more bytes, transitioning to BYTE2 and then BYTE3. After receiving the third byte, the FSM will signal the receipt of a message by asserting the done signal and then return to the IDLE state. The reset signal will be used to reset the FSM to the IDLE state.
