To solve this problem, we will implement a finite state machine (FSM) with two states: IDLE and RECEIVING_MESSAGE. In the IDLE state, we discard incoming bytes until we find one with in[3]=1, which we assume to be the first byte of a message. We then transition to the RECEIVING_MESSAGE state and start counting the number of bytes received. Once we have received three bytes, we signal done in the next cycle and transition back to the IDLE state. If reset is asserted, we transition back to the IDLE state. We will use a counter to keep track of the number of bytes received in the RECEIVING_MESSAGE state.
