The module TopModule will implement a finite state machine to detect PS/2 mouse protocol messages in a byte stream. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. It starts in the IDLE state, where it waits for a byte with in[3] = 1. Once such a byte is received, it transitions to the BYTE1 state and starts counting the bytes. After receiving the next two bytes, it transitions to the BYTE3 state and signals the receipt of a message by asserting the done output. If a byte with in[3] = 1 is received while not in the IDLE state, the FSM resets to the IDLE state. The FSM will also reset to the IDLE state when the reset input is asserted.
