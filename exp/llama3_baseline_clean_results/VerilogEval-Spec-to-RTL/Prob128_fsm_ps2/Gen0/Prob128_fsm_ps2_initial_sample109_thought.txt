To implement the TopModule, we can design a finite state machine (FSM) with four states: 
1. IDLE: This state is the initial state and also the state when we are waiting for the first byte of the message (in[3] = 1).
2. BYTE1: After receiving the first byte of the message, we transition to this state and expect the second byte.
3. BYTE2: After receiving the second byte, we transition to this state and expect the third byte.
4. DONE: After receiving the third byte, we transition to this state and signal 'done' in the next cycle.

We will also have a counter to keep track of the current state and reset the FSM when 'reset' is high. 
When 'reset' is low, the FSM will continue to run and search for the message boundaries.
