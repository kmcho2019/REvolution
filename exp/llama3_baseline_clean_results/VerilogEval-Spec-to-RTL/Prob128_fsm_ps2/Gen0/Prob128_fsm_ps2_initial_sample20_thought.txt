To solve this problem, we will implement a finite state machine (FSM) in the TopModule that can be in one of four states: 
- IDLE: the initial state, where the module waits for the first byte with in[3]=1.
- BYTE1: after receiving the first byte with in[3]=1, the module moves to this state and waits for the second byte.
- BYTE2: after receiving the second byte, the module moves to this state and waits for the third byte.
- DONE: after receiving the third byte, the module moves to this state and signals done in the same cycle. 
In the next cycle, it goes back to IDLE if the new byte does not have in[3]=1, otherwise it goes to BYTE1.

The FSM will be reset to IDLE when the reset signal is high.
