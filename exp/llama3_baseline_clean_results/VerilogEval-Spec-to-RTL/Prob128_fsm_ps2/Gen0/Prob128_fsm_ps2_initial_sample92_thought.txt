To solve this problem, we can use a finite state machine (FSM) with four states: 
- IDLE: Initial state where the FSM waits for a byte with in[3]=1 to start a message.
- BYTE_1: After receiving a byte with in[3]=1, the FSM moves to this state, 
          expecting the second byte of the message.
- BYTE_2: After receiving the second byte, the FSM moves to this state, 
          expecting the third byte of the message.
- DONE: After receiving the third byte, the FSM moves to this state and signals 'done'.

The FSM will reset to IDLE when the reset signal is high. 
In each state, we check the input byte to determine the next state.
