To implement the TopModule, we can design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state and waits for a byte with in[3]=1 to arrive. Once such a byte is received, the FSM transitions to the BYTE1 state and waits for the next two bytes. After receiving all three bytes, the FSM signals done and returns to the IDLE state. The FSM also resets to the IDLE state when the reset signal is high. We will use a counter to keep track of the current state and a flag to indicate when the done signal should be asserted.
