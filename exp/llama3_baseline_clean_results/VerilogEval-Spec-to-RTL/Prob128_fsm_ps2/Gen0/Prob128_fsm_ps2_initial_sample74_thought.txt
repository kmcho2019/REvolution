To solve this problem, we will design a finite state machine (FSM) with the following states:
- IDLE: Wait for a byte with in[3]=1, discard all other bytes.
- BYTE1: Received the first byte of the message, wait for the next two bytes.
- BYTE2: Received the second byte of the message, wait for the third byte.
- DONE: Received the third byte of the message, signal done in the next cycle.

The FSM will transition between these states based on the input byte stream and the current state. We will use a counter to keep track of the number of bytes received in the BYTE1 and BYTE2 states.
