To implement the TopModule, we will use a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state, where it discards input bytes until it finds one with in[3]=1. Once such a byte is found, the FSM transitions to the BYTE1 state and starts counting the bytes. It then transitions to BYTE2 and BYTE3, respectively, after each byte is received. When the third byte is received, the FSM signals done in the next clock cycle and returns to the IDLE state. The FSM also has a reset input that resets it to the IDLE state when asserted.
