To solve this problem, I will design a finite state machine (FSM) with the following states: IDLE, BYTE1, BYTE2, and BYTE3. In the IDLE state, the FSM will discard bytes until it sees one with in[3]=1, then it will transition to the BYTE1 state. In the BYTE1, BYTE2, and BYTE3 states, the FSM will count the number of bytes received and transition to the next state after each byte. Once the FSM reaches the BYTE3 state, it will signal done in the next cycle and then return to the IDLE state. The FSM will also have a reset state that will be triggered by the reset input and will return the FSM to the IDLE state.
