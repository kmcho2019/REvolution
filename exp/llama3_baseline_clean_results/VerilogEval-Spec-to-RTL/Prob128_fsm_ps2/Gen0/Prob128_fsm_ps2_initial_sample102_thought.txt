The TopModule should be designed as a finite state machine (FSM) that operates in four states: 
1) IDLE: This is the initial state where the FSM waits for a byte with in[3]=1 to indicate the start of a message.
2) BYTE1: After receiving the first byte, the FSM transitions to this state and waits for the next byte.
3) BYTE2: After receiving the second byte, the FSM transitions to this state and waits for the third byte.
4) DONE: After receiving the third byte, the FSM transitions to this state and signals done in the next cycle.
The FSM should reset to IDLE when reset is high.
