To solve this problem, I will implement a finite state machine (FSM) in the TopModule that transitions through different states based on the input byte stream. The FSM will initially be in an idle state, where it waits for a byte with in[3] = 1 to arrive. Once such a byte is detected, the FSM will transition to a state that assumes the current byte is the first byte of a message. It will then count the next two bytes and signal 'done' in the cycle after the third byte is received. If at any point a byte with in[3] = 1 is received before the third byte of the current message, the FSM will restart and assume the new byte is the first byte of a new message. The FSM will also be reset to the idle state when the reset signal is high.
