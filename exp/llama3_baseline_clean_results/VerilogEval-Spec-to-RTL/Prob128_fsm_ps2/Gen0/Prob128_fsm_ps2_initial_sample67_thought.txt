To solve this problem, we will implement a finite state machine (FSM) in Verilog that searches for message boundaries in a continuous byte stream. The FSM will be designed to discard bytes until it finds one with in[3] = 1, which is assumed to be the first byte of a message. It will then wait for two more bytes to complete the message and signal the receipt of a message by asserting the 'done' output. The FSM will have states to track the receipt of each byte in the message.
