To implement the module TopModule, we'll design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state and stays there until it encounters a byte with in[3]=1, which is considered as the first byte of a message. It then transitions to the BYTE1 state and expects two more bytes to complete the message. Once all three bytes are received, it signals done in the next cycle. The FSM resets to the IDLE state when the reset signal is high.
