To solve this problem, we will design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM will start in the IDLE state and wait for a byte with in[3]=1 to arrive. Once such a byte is received, the FSM will transition to the BYTE1 state. Then, it will wait for two more bytes to arrive, transitioning to BYTE2 and BYTE3 states respectively. After receiving the third byte, the FSM will signal done in the next clock cycle and then return to the IDLE state to search for the next message boundary. The FSM will also have a reset input that will synchronously reset it to the IDLE state when high.
