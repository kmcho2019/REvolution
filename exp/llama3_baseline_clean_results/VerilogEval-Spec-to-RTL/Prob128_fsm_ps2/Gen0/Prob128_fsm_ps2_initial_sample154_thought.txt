To implement the TopModule, we need to design a finite state machine (FSM) that can detect message boundaries in the input byte stream. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. In the IDLE state, the module will discard bytes until it finds one with in[3]=1, which will then transition to the BYTE1 state. The module will then expect two more bytes and transition to BYTE2 and BYTE3 states, respectively. After receiving the third byte, the module will signal done in the next clock cycle and return to the IDLE state. The reset signal will be used to reset the FSM to the IDLE state. We will use a counter to keep track of the current state and the bytes received.
