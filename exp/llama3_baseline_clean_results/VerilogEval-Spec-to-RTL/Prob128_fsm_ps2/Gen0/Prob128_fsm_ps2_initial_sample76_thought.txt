To solve this problem, we can implement a finite state machine (FSM) in Verilog. The FSM will have three main states: 
1. IDLE: This is the initial state where the FSM waits for the first byte with in[3] = 1.
2. BYTE1: After receiving the first byte with in[3] = 1, the FSM transitions to this state and waits for the second byte.
3. BYTE2: After receiving the second byte, the FSM transitions to this state and waits for the third byte. 
When the third byte is received, the FSM signals 'done' in the next clock cycle and then transitions back to the IDLE state to search for the next message.
