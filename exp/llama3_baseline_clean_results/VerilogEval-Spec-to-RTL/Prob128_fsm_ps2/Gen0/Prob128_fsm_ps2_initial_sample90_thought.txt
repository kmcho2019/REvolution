To implement the finite state machine (FSM) as described, we can follow these steps:
1. Initialize the FSM to a reset state where it waits for the first byte with in[3] = 1.
2. Upon detecting a byte with in[3] = 1, transition to a state that counts the bytes received, assuming the first byte as the start of a message.
3. Count the bytes until three bytes have been received.
4. Once three bytes have been received, signal that a message has been received (done) on the next clock cycle.
5. If a reset occurs, return to the initial state.

This can be achieved using a simple FSM with states for idle (waiting for the first byte of a message), receiving the message, and signaling done.
