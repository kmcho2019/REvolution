The module TopModule will implement a finite state machine (FSM) to detect message boundaries in a continuous PS/2 mouse protocol byte stream. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. It will start in the IDLE state and remain there until it encounters a byte with in[3]=1. At this point, it will transition to the BYTE1 state, assuming this byte is the first byte of a message. The FSM will then transition to BYTE2 and BYTE3 states as it receives the subsequent two bytes. Once it has received the third byte, it will signal done in the next cycle. If reset is asserted, the FSM will return to the IDLE state.
