To solve this problem, we can implement a finite state machine (FSM) in Verilog that transitions between states based on the input byte stream. The FSM will start in an idle state and transition to a receiving state when it encounters a byte with in[3] = 1. It will then receive two more bytes and signal done after receiving the third byte. If a byte with in[3] = 1 is encountered before receiving three bytes, the FSM will reset and start over. We will use a counter to keep track of the number of bytes received. The done signal will be asserted in the cycle immediately after the third byte of each message was successfully received.
