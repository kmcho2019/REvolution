To implement the TopModule, we can design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state, where it discards incoming bytes until it finds one with in[3]=1. When such a byte is found, it transitions to the BYTE1 state. In the BYTE1, BYTE2, and BYTE3 states, the FSM waits for two more bytes to complete the message. After receiving the third byte, it signals done in the next cycle and returns to the IDLE state. The FSM also needs to handle the reset signal, which should bring it back to the IDLE state.
