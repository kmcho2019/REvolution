The TopModule can be designed as a finite state machine with four states: 
- IDLE: The initial state where the module waits for the first byte of the message (in[3]=1).
- BYTE1: The state after receiving the first byte of the message.
- BYTE2: The state after receiving the second byte of the message.
- BYTE3: The state after receiving the third byte of the message, where the module signals 'done'.

The module will transition from one state to the next upon receiving a new byte. The done signal is asserted in the cycle immediately after the third byte of each message was successfully received.
