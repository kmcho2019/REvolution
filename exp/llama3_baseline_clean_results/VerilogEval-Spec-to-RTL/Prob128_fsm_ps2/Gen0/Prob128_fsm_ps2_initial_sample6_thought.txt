The TopModule can be implemented as a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state and stays there until it receives a byte with in[3]=1. When such a byte is received, the FSM transitions to the BYTE1 state. In the BYTE1 state, the FSM waits for the next byte and transitions to the BYTE2 state. Similarly, in the BYTE2 state, the FSM waits for the next byte and transitions to the BYTE3 state. In the BYTE3 state, the FSM signals the receipt of a message by asserting the done signal and then transitions back to the IDLE state. If the FSM is in any state other than IDLE and receives a byte with in[3]=1, it should transition back to the BYTE1 state, as this indicates the start of a new message. The FSM should also have a reset mechanism to reset the FSM to the IDLE state when the reset signal is high.
