The TopModule will implement a finite state machine with three states: IDLE, BYTE1, and BYTE2. In the IDLE state, the module will continuously check for a byte with in[3]=1. Once such a byte is found, the module will transition to the BYTE1 state and start counting the bytes. In the BYTE1 state, the module will wait for the next byte and then transition to the BYTE2 state. In the BYTE2 state, the module will wait for the third byte and then signal done in the next cycle. The module will also handle the reset signal, which will reset the state machine to the IDLE state.
