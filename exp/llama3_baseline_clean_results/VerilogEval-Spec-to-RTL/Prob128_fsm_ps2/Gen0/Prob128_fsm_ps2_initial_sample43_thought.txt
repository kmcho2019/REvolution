To solve this problem, we will design a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. 
The FSM starts in the IDLE state and remains there until it encounters a byte with in[3]=1. 
Once this byte is found, the FSM moves to the BYTE1 state, then to the BYTE2 state after receiving the next byte, 
and finally signals done in the cycle immediately after the third byte of each message was successfully received, 
then moves back to the IDLE state to search for the next message. 
The FSM will reset to the IDLE state when the reset signal is high.
