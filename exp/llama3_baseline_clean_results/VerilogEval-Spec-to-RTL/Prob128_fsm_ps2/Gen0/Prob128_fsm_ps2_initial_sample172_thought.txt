To implement the TopModule, we will use a finite state machine (FSM) that has four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, we will continuously check the input byte for the condition in[3]=1. 
Once this condition is met, we will transition to the BYTE1 state and start counting the bytes. 
We will then transition to BYTE2 and BYTE3 states after receiving each subsequent byte, and signal done after receiving the third byte.
We will use a counter to keep track of the number of bytes received and reset the FSM when the reset signal is high.
