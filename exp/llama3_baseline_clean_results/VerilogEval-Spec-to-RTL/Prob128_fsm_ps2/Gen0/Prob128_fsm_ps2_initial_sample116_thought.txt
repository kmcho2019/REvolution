To implement the TopModule, we can design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state, where it waits for a byte with in[3]=1. Once such a byte is detected, it transitions to the BYTE1 state. It then counts the remaining two bytes and signals done in the cycle immediately after the third byte is received. The FSM resets to the IDLE state when reset is high. We'll use a counter to keep track of the current byte position in the message.
