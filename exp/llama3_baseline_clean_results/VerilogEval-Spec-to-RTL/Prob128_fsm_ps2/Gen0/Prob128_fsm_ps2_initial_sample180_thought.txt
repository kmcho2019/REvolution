To solve this problem, we can implement a finite state machine (FSM) in the TopModule that transitions through states based on the input byte stream. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. In the IDLE state, the module will discard incoming bytes until it encounters one with in[3]=1. Once this condition is met, the FSM will transition to BYTE1 and start counting the bytes. After three bytes have been received, the FSM will assert the done signal in the next cycle and then transition back to the IDLE state. The reset signal will be used to asynchronously reset the FSM to the IDLE state. We will use a counter to keep track of the current byte position within the message.
