To solve this problem, we will implement a finite state machine (FSM) with the following states: 
- IDLE: This is the initial state where the FSM waits for a byte with in[3] = 1 to start a new message.
- BYTE1: After receiving the first byte of a message, the FSM moves to this state and waits for the second byte.
- BYTE2: After receiving the second byte, the FSM moves to this state and waits for the third byte.
- DONE: After receiving the third byte, the FSM moves to this state and signals 'done' in the next cycle.

We will use a counter to keep track of the current byte in the message and check the value of in[3] to determine the start of a new message.
The FSM will reset to the IDLE state when the reset signal is high.
