The module TopModule will implement a finite state machine with four states: 
IDLE, BYTE1, BYTE2, and BYTE3. In the IDLE state, it waits for a byte with in[3]=1. 
Once such a byte is received, it transitions to the BYTE1 state and starts 
counting the bytes. It then transitions through the BYTE2 and BYTE3 states 
as it receives the subsequent bytes. After receiving the third byte, it 
transitions back to the IDLE state and signals done. The module will reset 
to the IDLE state when the reset signal is high.
