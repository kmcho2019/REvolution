The TopModule will implement a finite state machine with four states: IDLE, BYTE1, BYTE2, and BYTE3. In the IDLE state, the module will continuously check the input byte stream for a byte with in[3]=1. Once such a byte is found, the module will transition to the BYTE1 state. In the BYTE1, BYTE2, and BYTE3 states, the module will count the number of bytes received and transition to the next state after each byte. After the third byte, the module will signal done and transition back to the IDLE state. The module will also have a reset state that will reset the FSM to the IDLE state when the reset signal is high.
