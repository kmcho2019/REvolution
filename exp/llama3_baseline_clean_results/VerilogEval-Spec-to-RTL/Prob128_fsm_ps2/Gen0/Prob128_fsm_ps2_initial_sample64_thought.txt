To solve this problem, we can implement a finite state machine (FSM) with the following states:
- IDLE: Initial state, discard bytes until a byte with in[3]=1 is received
- BYTE1: State after receiving the first byte of a message
- BYTE2: State after receiving the second byte of a message
- BYTE3: State after receiving the third byte of a message, signal done

The FSM will transition from IDLE to BYTE1 when a byte with in[3]=1 is received. 
It will then transition from BYTE1 to BYTE2, and from BYTE2 to BYTE3, after each subsequent byte.
When in state BYTE3, the FSM will signal done in the next cycle.
The FSM will reset to the IDLE state when reset is high.
