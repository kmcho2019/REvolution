To implement the TopModule, we will use a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
The IDLE state will be the initial state where the FSM waits for a byte with in[3]=1. 
Once such a byte is found, it transitions to the BYTE1 state, then to BYTE2, and finally to BYTE3. 
When the FSM is in the BYTE3 state, it checks for the third byte of the message and then signals done in the next cycle. 
The FSM will reset to the IDLE state when the reset signal is high.
