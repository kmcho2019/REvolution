To solve this problem, we can implement a finite state machine (FSM) in the TopModule. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. The module will start in the IDLE state, where it will discard all incoming bytes until it receives one with in[3]=1. Once such a byte is received, the module will transition to the BYTE1 state, and then to BYTE2 and BYTE3 states after receiving the next two bytes, respectively. The done signal will be asserted in the cycle immediately after the third byte of each message is received. We will use a counter to keep track of the current state and a flag to indicate when the done signal should be asserted.
