To implement the TopModule, we can design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state, where it waits for a byte with in[3]=1. Once it finds such a byte, it transitions to the BYTE1 state. Then, it counts the next two bytes, transitioning to BYTE2 and BYTE3, respectively. In the BYTE3 state, it sets the done signal high and then resets to the IDLE state to search for the next message boundary. The FSM also has a reset state that resets the FSM to the IDLE state when the reset signal is high.
