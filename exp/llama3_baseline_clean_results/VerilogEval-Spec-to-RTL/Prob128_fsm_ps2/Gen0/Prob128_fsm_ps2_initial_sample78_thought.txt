To solve this problem, we can design a finite state machine (FSM) with four states: 
1. IDLE: This is the initial state where we wait for the first byte with in[3]=1.
2. BYTE1: After receiving the first byte with in[3]=1, we move to this state and wait for the second byte.
3. BYTE2: After receiving the second byte, we move to this state and wait for the third byte.
4. DONE: After receiving the third byte, we move to this state and signal done in the next cycle.

We will use a counter to keep track of the current byte position in the message.
When reset is high, we will reset the FSM to the IDLE state.
