To implement the finite state machine in the TopModule, we will use a simple state machine with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, the module will continuously check for the first byte of a message (in[3]=1) and discard all other bytes. 
Once the first byte of a message is detected, the module will transition to the BYTE1 state and start counting the number of bytes received. 
The module will then transition to the BYTE2 and BYTE3 states after receiving the second and third bytes, respectively. 
After receiving the third byte, the module will signal the receipt of a message by asserting the done signal for one cycle. 
The reset signal will be used to reset the state machine to the IDLE state.
