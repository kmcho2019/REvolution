To solve this problem, we will implement a finite state machine (FSM) in the TopModule. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. In the IDLE state, the module will continuously check the input byte stream for a byte with in[3]=1, indicating the start of a message. Once such a byte is found, the FSM will transition to the BYTE1 state and start counting the bytes. The FSM will then transition to BYTE2 and BYTE3, respectively, for each subsequent byte received. After receiving the third byte, the FSM will signal the receipt of a message by setting the done output to 1 for one clock cycle. The FSM will then reset to the IDLE state, ready to search for the next message.
