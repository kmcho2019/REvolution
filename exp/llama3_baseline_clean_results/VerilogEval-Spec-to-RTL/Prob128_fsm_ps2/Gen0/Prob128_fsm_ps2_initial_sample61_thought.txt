To implement the module TopModule, we will use a finite state machine (FSM) with four states: 
- IDLE: The initial state where the module waits for a byte with in[3]=1.
- BYTE1: The state after receiving the first byte of a message (in[3]=1).
- BYTE2: The state after receiving the second byte of a message.
- BYTE3: The state after receiving the third byte of a message, where the done signal is asserted.
The FSM will transition between these states based on the input byte stream and the value of in[3].
