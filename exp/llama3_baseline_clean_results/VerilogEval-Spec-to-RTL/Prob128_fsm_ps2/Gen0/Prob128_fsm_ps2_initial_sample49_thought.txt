To solve this problem, we will design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM will start in the IDLE state and wait for a byte with in[3]=1. When such a byte is received, the FSM will transition to the BYTE1 state and start counting the remaining bytes. After receiving the second and third bytes, the FSM will transition to the BYTE2 and BYTE3 states, respectively. In the BYTE3 state, the FSM will assert the done signal in the next clock cycle. The FSM will also have a reset input that will reset it to the IDLE state when asserted.
