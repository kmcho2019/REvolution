To implement the TopModule, we need to design a finite state machine (FSM) that can search for message boundaries in a continuous byte stream. The FSM should have four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state and transitions to the BYTE1 state when it encounters a byte with in[3]=1. It then transitions to the BYTE2 and BYTE3 states after receiving the next two bytes, respectively. Once it reaches the BYTE3 state, it signals done in the next clock cycle and then transitions back to the IDLE state to search for the next message. The FSM should also have a reset mechanism to reset it to the IDLE state when the reset signal is high.
