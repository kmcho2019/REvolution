The module TopModule should implement a finite state machine that detects the start of a message by checking the fourth bit (in[3]) of each incoming byte. Once a byte with in[3]=1 is detected, it should count the next two bytes and then signal done. The FSM will have four states: idle (discarding bytes), byte1 (first byte of a message), byte2 (second byte of a message), and byte3 (third byte of a message). The state will be idle initially and after the done signal is asserted. On reset, the FSM should return to the idle state.
