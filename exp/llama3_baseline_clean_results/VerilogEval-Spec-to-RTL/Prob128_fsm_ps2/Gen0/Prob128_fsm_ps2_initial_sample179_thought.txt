To implement the TopModule, we can use a finite state machine (FSM) that keeps track of the current state and the bytes received. From there, we transition to BYTE_2 and then BYTE_3 states as we receive subsequent bytes. When we're in the BYTE_3 state and receive a byte, we signal done in the next cycle and transition back to the IDLE state. We also need to handle the reset signal, which should transition the FSM back to the IDLE state.
