To solve this problem, we will implement a finite state machine (FSM) in the TopModule. The FSM will have four states: 
- IDLE: The initial state where the module waits for a byte with in[3] = 1.
- BYTE1: The state after the first byte with in[3] = 1 has been received, waiting for the second byte of the message.
- BYTE2: The state after the second byte of the message has been received, waiting for the third byte of the message.
- DONE: The state after the third byte of the message has been received, where the module signals that a message has been received.

The FSM will transition between states based on the input byte stream and the current state. The 'done' signal will be asserted in the cycle immediately after the third byte of each message was successfully received.
