To solve this problem, I will implement a finite state machine (FSM) with the following states:
- IDLE: Initial state, waiting for a byte with in[3]=1 to start a message.
- BYTE1: First byte of the message received, waiting for the second byte.
- BYTE2: Second byte of the message received, waiting for the third byte.
- DONE: Third byte of the message received, signal done in this state.

The FSM will transition between these states based on the value of in[3] and the current state. When reset is asserted, the FSM will return to the IDLE state. The done signal will be asserted in the DONE state.
