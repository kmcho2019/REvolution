To solve this problem, we can implement a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state and stays there until it receives a byte with in[3] = 1, at which point it transitions to BYTE1. It then stays in BYTE1, BYTE2, and BYTE3 for one clock cycle each, regardless of the input, and signals done in the cycle after receiving the third byte. We will use a counter to keep track of the current byte and a flag to track the value of in[3] for the first byte. The FSM will be reset to the IDLE state when reset is high.
