To solve this problem, we can implement a finite state machine with three main states: IDLE, BYTE1, and BYTE2. The IDLE state is the initial state where we discard bytes until we find one with in[3]=1. Once we find such a byte, we transition to the BYTE1 state and assume it's the first byte of a message. Then, we wait for two more bytes and transition through the BYTE2 state to signal the receipt of a message. We use a counter to keep track of the bytes received and reset it when we start a new message.
