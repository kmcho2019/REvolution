The problem can be solved by implementing a finite state machine (FSM) in the TopModule. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, the module will discard bytes until it encounters a byte with in[3]=1, at which point it will transition to the BYTE1 state. 
In the BYTE1 state, it will wait for the next byte, then transition to the BYTE2 state. 
In the BYTE2 state, it will wait for the next byte, then transition to the BYTE3 state. 
In the BYTE3 state, it will assert the done signal and then return to the IDLE state, searching for the next message boundary.
The reset signal will be used to return the FSM to the IDLE state when it is asserted.
