To solve this problem, we can design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state, where it waits for a byte with in[3]=1. Once such a byte is found, it transitions to the BYTE1 state. Then, it waits for two more bytes, transitioning to BYTE2 and BYTE3 states, respectively. After receiving the third byte, it signals done in the next cycle and returns to the IDLE state. The FSM should also handle the reset signal, which resets it to the IDLE state when high.
