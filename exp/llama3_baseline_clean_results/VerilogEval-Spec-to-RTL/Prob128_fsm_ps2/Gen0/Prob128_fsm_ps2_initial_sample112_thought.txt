To implement the TopModule, we'll create a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM will start in the IDLE state, where it will discard incoming bytes until it encounters a byte with in[3] = 1. Once such a byte is found, the FSM will transition to the BYTE1 state, indicating that the first byte of a potential message has been received. It will then move to BYTE2 and BYTE3 states as it receives the subsequent bytes. After receiving the third byte, the FSM will assert the done signal in the next clock cycle and then transition back to the IDLE state. The FSM will also have a reset input, which will synchronously reset the FSM to the IDLE state when asserted.
