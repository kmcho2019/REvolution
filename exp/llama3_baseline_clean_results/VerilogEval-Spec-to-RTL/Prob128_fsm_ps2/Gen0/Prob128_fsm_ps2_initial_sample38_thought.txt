To implement the TopModule, we can design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state, where it discards incoming bytes until it finds one with in[3]=1. Once it finds such a byte, it transitions to the BYTE1 state. In the BYTE1, BYTE2, and BYTE3 states, the FSM receives the remaining bytes of the message. After receiving the third byte (i.e., when it is in the BYTE3 state), the FSM signals the receipt of the message by asserting the done signal in the next clock cycle. If a reset occurs, the FSM returns to the IDLE state.
