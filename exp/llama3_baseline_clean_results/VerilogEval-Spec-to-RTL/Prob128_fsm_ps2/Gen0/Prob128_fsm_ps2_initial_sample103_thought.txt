To implement the required module, we can design a finite state machine (FSM) with the following states: 
- IDLE: Initial state where the FSM waits for the first byte of a message.
- BYTE_1: State after receiving the first byte of a message.
- BYTE_2: State after receiving the second byte of a message.
- BYTE_3: State after receiving the third byte of a message, and then immediately transitioning back to IDLE and signaling done.
The FSM will transition between these states based on the value of the input byte and the current state.
In the IDLE state, the FSM checks if the current input byte has in[3]=1. If it does, it transitions to BYTE_1. Otherwise, it stays in IDLE.
In the BYTE_1, BYTE_2 states, the FSM always transitions to the next state.
In the BYTE_3 state, the FSM signals done in the next cycle and then transitions back to IDLE.
Reset should be handled by setting the FSM back to the IDLE state whenever reset is high.
