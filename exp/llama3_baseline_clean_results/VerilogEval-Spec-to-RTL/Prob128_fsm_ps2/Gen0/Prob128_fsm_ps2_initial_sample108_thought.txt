To solve this problem, we will implement a finite state machine (FSM) with the following states:
- IDLE: Initial state where we wait for a byte with in[3]=1 to start a new message.
- BYTE1: After finding the first byte of a message (in[3]=1), we move to this state and expect the second byte.
- BYTE2: After receiving the second byte, we move to this state and expect the third byte.
- DONE: Once the third byte is received, we signal 'done' and reset back to IDLE to look for the next message.

The module will have a reset port to restart the FSM to the IDLE state. All state transitions will be synchronous with the positive edge of the clock.
