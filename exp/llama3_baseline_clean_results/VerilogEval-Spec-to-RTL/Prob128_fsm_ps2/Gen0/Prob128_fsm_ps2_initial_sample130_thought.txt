To solve this problem, we will design a finite state machine (FSM) that can identify the boundaries of PS/2 mouse messages in a continuous byte stream. The FSM will start in an IDLE state and transition to a MESSAGE state when it encounters a byte with in[3]=1, assuming this byte as the first byte of the message. It will then wait for two more bytes, and after receiving the third byte, it will assert the 'done' signal in the next clock cycle. The FSM will reset to the IDLE state upon receiving a reset signal or after asserting the 'done' signal.
