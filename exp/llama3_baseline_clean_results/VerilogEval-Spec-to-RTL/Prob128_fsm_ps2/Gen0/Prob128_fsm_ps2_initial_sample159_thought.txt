To implement the finite state machine, we can define three states: IDLE, BYTE1, and BYTE2. In the IDLE state, we discard incoming bytes until we see one with in[3]=1, at which point we transition to BYTE1. In the BYTE1 state, we wait for the next two bytes to arrive, transitioning to BYTE2 after the second byte. Once in the BYTE2 state, we wait for the third byte to arrive, then signal done in the next cycle and return to the IDLE state. We use a counter to keep track of the number of bytes received after seeing a byte with in[3]=1.
