To implement the module TopModule, we will use a finite state machine (FSM) that can be in one of four states: IDLE, BYTE1, BYTE2, and BYTE3. 
The FSM starts in the IDLE state, where it waits for an input byte with in[3]=1. 
Once such a byte is received, it transitions to the BYTE1 state, and then sequentially to BYTE2 and BYTE3 states for each subsequent byte received. 
After the BYTE3 state, it returns to the IDLE state and sets the done signal high for one clock cycle to indicate that a message has been received. 
The FSM should also handle the reset signal, which when high, resets the FSM to the IDLE state and clears the done signal.
