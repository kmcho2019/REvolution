To implement the TopModule, we can design a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. The FSM starts in the IDLE state, where it discards incoming bytes until it finds one with in[3]=1. Once such a byte is found, the FSM transitions to the BYTE1 state. From the BYTE1 state, it transitions to the BYTE2 state after receiving the next byte. Finally, after receiving the third byte, it transitions back to the IDLE state and signals 'done' in the same cycle. The FSM also includes a reset mechanism that returns it to the IDLE state when reset is high.
