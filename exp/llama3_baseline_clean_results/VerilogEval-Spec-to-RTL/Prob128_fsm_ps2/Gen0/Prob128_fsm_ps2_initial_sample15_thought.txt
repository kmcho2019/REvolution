To implement the TopModule, we'll use a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. The FSM will start in the IDLE state and transition to BYTE1 when it encounters a byte with in[3]=1. It will then transition to BYTE2 after receiving the second byte and finally signal 'done' after receiving the third byte. The FSM will reset to the IDLE state when 'reset' is asserted. We'll use a counter to keep track of the number of bytes received since the last byte with in[3]=1.
