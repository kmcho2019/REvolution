To solve this problem, we'll design a finite state machine (FSM) that has four states: idle, byte1, byte2, and byte3. The FSM will start in the idle state and transition to byte1 when it receives a byte with in[3] = 1. It will then transition to byte2 and byte3 after receiving the subsequent bytes, regardless of their values. Once in the byte3 state, it will set the done signal high for one cycle and then transition back to the idle state to look for the next message boundary. We'll use a counter to keep track of the bytes received. The FSM will be implemented using a case statement in Verilog.
