The problem can be solved by implementing a finite state machine (FSM) that searches for the start of a message (indicated by in[3]=1) and then counts the bytes until three have been received. The FSM will have states for idle (searching for start of message), byte1, byte2, and done. When the FSM is in the idle state, it will discard bytes until it finds one with in[3]=1. Once the start of a message is found, it will transition to the byte1 state and start counting the bytes. After three bytes have been received, it will signal done in the next cycle. The FSM will be reset to the idle state when the reset signal is high.
