To implement the TopModule, we can use a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, we discard incoming bytes until we find one with in[3] = 1, then we transition to the BYTE1 state. 
In the BYTE1 state, we wait for the next byte and transition to the BYTE2 state. 
In the BYTE2 state, we wait for the next byte and transition to the BYTE3 state. 
In the BYTE3 state, we signal done and transition back to the IDLE state if the next byte has in[3] = 1, or directly to the BYTE1 state. 
We also need to handle the reset signal to reset the FSM to the IDLE state.
