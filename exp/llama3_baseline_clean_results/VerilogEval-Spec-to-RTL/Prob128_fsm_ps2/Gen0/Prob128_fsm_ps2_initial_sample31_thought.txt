To solve this problem, we can design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM starts in the IDLE state, where it waits for a byte with in[3]=1. Once such a byte is received, it transitions to the BYTE1 state. In the BYTE1, BYTE2, and BYTE3 states, it waits for the next byte, and once all three bytes have been received, it signals done and returns to the IDLE state. The reset signal will be used to reset the FSM to the IDLE state.
