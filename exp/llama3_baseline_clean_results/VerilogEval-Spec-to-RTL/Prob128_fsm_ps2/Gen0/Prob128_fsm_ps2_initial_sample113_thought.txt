To solve this problem, we can implement a finite state machine (FSM) with four states: 
- Idle state: The initial state where the FSM waits for a byte with in[3] = 1.
- Byte1 state: After a byte with in[3] = 1 is received, the FSM enters this state, 
               expecting to receive the second byte of the message.
- Byte2 state: After the second byte is received, the FSM enters this state, 
               expecting to receive the third byte of the message.
- Done state: After the third byte is received, the FSM enters this state and 
              signals 'done' in the next cycle.

The FSM will transition from one state to another based on the input byte stream. 
The 'reset' signal will be used to reset the FSM to the Idle state.

We will use a counter to count the number of bytes received after the FSM 
enters the Byte1 state. When the counter reaches 3, it means all 3 bytes 
of the message have been received, and the FSM will signal 'done'.

The 'done' signal will be asserted in the cycle immediately after the 
third byte of each message is successfully received.
