To solve this problem, we can design a finite state machine (FSM) with the following states:
1. IDLE: The initial state where the FSM waits for the first byte with in[3]=1.
2. BYTE1: The state after receiving the first byte of a message.
3. BYTE2: The state after receiving the second byte of a message.
4. BYTE3: The state after receiving the third byte of a message, where the done signal is asserted.

The FSM transitions from one state to another based on the value of in[3] and the current state. If reset is asserted, the FSM goes back to the IDLE state.
