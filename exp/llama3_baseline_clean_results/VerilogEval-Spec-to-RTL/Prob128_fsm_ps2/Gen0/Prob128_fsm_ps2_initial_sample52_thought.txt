To solve this problem, we can implement a finite state machine (FSM) in the TopModule. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. The IDLE state will be the initial state where the module discards bytes until it sees one with in[3]=1. Once such a byte is found, the FSM transitions to the BYTE1 state. From there, it will transition to BYTE2 and then BYTE3 after receiving each subsequent byte, regardless of the value of in[3]. After reaching the BYTE3 state, the FSM will signal 'done' and then immediately transition back to the IDLE state, ready to start searching for the next message boundary. The reset input will be used to synchronously reset the FSM to the IDLE state.
