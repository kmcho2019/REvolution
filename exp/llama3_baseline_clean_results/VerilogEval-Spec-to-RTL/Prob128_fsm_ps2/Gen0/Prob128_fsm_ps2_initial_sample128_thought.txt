To implement the TopModule, we need to design a finite state machine (FSM) that can detect message boundaries in the input byte stream. The FSM will have states to represent the search for the first byte of a message (with in[3]=1) and the subsequent reception of the next two bytes. We'll use a counter to keep track of the number of bytes received after the first byte. The FSM will signal done when the third byte is received. The reset signal will be used to reset the FSM to its initial state.
