To implement the TopModule, we will create a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. The FSM will start in the IDLE state and search for the first byte with in[3]=1. Once this byte is found, the FSM will transition to the BYTE1 state and then proceed to BYTE2 and BYTE3 states as each subsequent byte is received. The done signal will be asserted in the cycle immediately after the third byte of each message was successfully received. We will also include a reset mechanism that will return the FSM to the IDLE state when reset is asserted.
