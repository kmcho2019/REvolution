To implement the module, we need to design a finite state machine (FSM) that can identify the boundaries of PS/2 mouse messages in a continuous byte stream. The FSM will have four states: 
- IDLE: initial state, waiting for the first byte with in[3]=1
- BYTE1: first byte of the message received
- BYTE2: second byte of the message received
- BYTE3: third byte of the message received

The FSM will transition between these states based on the value of in[3] and the current state. When the FSM is in the BYTE3 state, it will signal 'done' in the next cycle, indicating that a complete message has been received.
