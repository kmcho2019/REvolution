To implement the TopModule, we need to design a finite state machine (FSM) that can detect the message boundaries in the PS/2 mouse protocol byte stream. The FSM will have four states: IDLE, BYTE1, BYTE2, and BYTE3. 

- In the IDLE state, the FSM will discard incoming bytes until it finds one with in[3]=1.
- Once a byte with in[3]=1 is found, the FSM will transition to the BYTE1 state.
- In the BYTE1 state, the FSM will wait for the next byte, and then transition to the BYTE2 state.
- In the BYTE2 state, the FSM will wait for the next byte, and then transition to the BYTE3 state.
- In the BYTE3 state, the FSM will signal done in the same cycle and then transition back to the IDLE state to start searching for the next message boundary.

The FSM will be reset to the IDLE state when the reset signal is high.
