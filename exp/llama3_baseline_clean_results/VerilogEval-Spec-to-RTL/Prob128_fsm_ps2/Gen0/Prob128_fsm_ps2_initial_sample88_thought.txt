To implement the TopModule, we'll design a finite state machine with four states: 
- IDLE: the initial state, waiting for a byte with in[3]=1
- BYTE1: the first byte of the message has been received
- BYTE2: the second byte of the message has been received
- DONE: signal done in the cycle after the third byte of the message has been received

The FSM will transition between these states based on the current state and the input value of in[3].
When reset is high, the FSM will transition back to the IDLE state.
The done signal will be asserted in the state immediately after the third byte of the message has been received.
