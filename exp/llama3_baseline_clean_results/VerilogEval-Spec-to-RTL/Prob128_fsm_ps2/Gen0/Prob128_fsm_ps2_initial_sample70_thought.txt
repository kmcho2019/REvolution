To implement the TopModule, we will design a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
- In the IDLE state, the FSM will discard input bytes until it encounters one with in[3]=1, at which point it will transition to the BYTE1 state.
- The FSM will remain in the BYTE1, BYTE2, and BYTE3 states for one clock cycle each, advancing to the next state after each cycle.
- Once the FSM reaches the BYTE3 state, it will assert the done signal in the next clock cycle, indicating that a message has been received.
- The FSM will reset to the IDLE state when the reset signal is high.
