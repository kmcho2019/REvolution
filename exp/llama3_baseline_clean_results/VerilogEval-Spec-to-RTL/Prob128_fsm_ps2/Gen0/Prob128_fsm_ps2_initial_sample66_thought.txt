The TopModule can be designed as a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. 
In the IDLE state, the module discards incoming bytes until it finds one with in[3]=1, at which point it transitions to the BYTE1 state.
In the BYTE1 state, it waits for the next byte and then transitions to the BYTE2 state.
In the BYTE2 state, it waits for the next byte and then transitions back to the IDLE state, signaling done in the same cycle.
The FSM should be reset to the IDLE state when reset is high.
