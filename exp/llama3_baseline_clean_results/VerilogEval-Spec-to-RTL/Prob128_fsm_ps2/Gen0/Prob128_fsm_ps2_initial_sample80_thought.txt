To solve this problem, we can implement a finite state machine (FSM) that has four states: idle, byte1, byte2, and byte3. The FSM starts in the idle state, where it discards bytes until it sees one with in[3]=1. When it sees such a byte, it transitions to the byte1 state. It then stays in the byte1, byte2, and byte3 states for one clock cycle each, signaling the receipt of a message in the cycle immediately after the third byte was successfully received. If reset is asserted, the FSM returns to the idle state. We will use a counter to keep track of the current state.
