The TopModule will implement a finite state machine (FSM) with four states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, the module discards input bytes until it sees one with in[3]=1. 
Once this condition is met, it transitions to the BYTE1 state and starts counting the bytes. 
The module then transitions through the BYTE2 and BYTE3 states as it receives each byte. 
After receiving the third byte, it signals the receipt of a message by asserting the done output. 
The FSM resets to the IDLE state when the reset input is high. 
The module will also handle the reset condition to return to the IDLE state when reset is asserted.
