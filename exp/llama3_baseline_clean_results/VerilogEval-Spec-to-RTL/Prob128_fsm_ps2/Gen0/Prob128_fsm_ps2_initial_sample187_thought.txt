To implement the TopModule, we need to design a finite state machine (FSM) that can detect the message boundaries in the PS/2 mouse protocol. The FSM should have at least three states: an initial state where it discards bytes until it finds one with in[3]=1, a second state where it receives the second byte of the message, and a third state where it receives the third byte of the message and signals the receipt of a message. The FSM should also have a reset state to handle the active high synchronous reset signal. We will use a counter to keep track of the number of bytes received in a message.
