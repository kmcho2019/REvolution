To implement a single D flip-flop in Verilog, we can use a simple always block that is sensitive to the positive edge of the clock. Inside the always block, we assign the value of the input 'd' to the output 'q' when the clock is high. This is the basic functionality of a D flip-flop: on the rising edge of the clock, the current value of 'd' is captured and stored as the new value of 'q'. We will also declare 'q' as a reg to hold its value between clock edges.
