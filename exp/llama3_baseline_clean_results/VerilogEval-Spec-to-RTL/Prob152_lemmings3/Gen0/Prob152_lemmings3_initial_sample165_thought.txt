To implement the Lemmings' behavior as a Moore state machine, we need to define the states and transitions. The possible states are: walking left, walking right, falling, and digging. The state machine will transition between these states based on the input signals.

We can represent the states using an enumeration:
- Walking left (WALK_LEFT)
- Walking right (WALK_RIGHT)
- Falling (FALLING)
- Digging (DIGGING)

The state machine will start in the WALK_LEFT state. When the ground disappears, it will transition to the FALLING state. When the ground reappears, it will transition back to the WALK_LEFT or WALK_RIGHT state depending on the previous walking direction.

When the dig signal is high and the Lemming is walking on the ground, it will transition to the DIGGING state. It will continue digging until the ground disappears, at which point it will transition to the FALLING state.

When the bump_left or bump_right signals are high, the state machine will transition to the opposite walking direction, unless the Lemming is falling or digging.

We will use a case statement to implement the state machine, with the current state and input signals determining the next state.
