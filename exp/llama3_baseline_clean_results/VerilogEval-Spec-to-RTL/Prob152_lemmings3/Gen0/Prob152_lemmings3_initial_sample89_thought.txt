To implement the Lemmings behavior as a Moore state machine, we need to identify the possible states and transitions between them. The Lemming can be in one of four states: walking left, walking right, digging, and falling. The transitions between these states are determined by the input signals. 

We will use the following states:
- S_WALK_LEFT: The Lemming is walking left.
- S_WALK_RIGHT: The Lemming is walking right.
- S_DIGGING: The Lemming is digging.
- S_FALLING: The Lemming is falling.

The state transitions are as follows:
- If the Lemming is walking and the ground disappears, it starts falling.
- If the Lemming is walking and it receives a dig signal, it starts digging.
- If the Lemming is digging and the ground disappears, it starts falling.
- If the Lemming is falling and the ground reappears, it resumes walking in the original direction.
- If the Lemming is walking and it is bumped, it switches direction.

We will use a Moore state machine, where the output is a function of the current state only.
