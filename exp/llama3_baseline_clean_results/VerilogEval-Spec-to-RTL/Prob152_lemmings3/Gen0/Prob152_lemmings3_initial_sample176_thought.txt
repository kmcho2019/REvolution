To implement the TopModule, we need to design a Moore state machine with the following states: 
- WALK_LEFT: walking left
- WALK_RIGHT: walking right
- FALLING: falling
- DIGGING_LEFT: digging left
- DIGGING_RIGHT: digging right

We'll use a case statement to handle the state transitions and output logic. The state machine will transition between states based on the input signals (bump_left, bump_right, ground, dig) and the current state.

When the Lemming is walking and ground disappears, it will transition to the FALLING state. 
When the Lemming is falling and ground reappears, it will transition back to the walking state it was in before falling.
When the Lemming is walking and dig is asserted, it will transition to the DIGGING state.
When the Lemming is digging and ground disappears, it will transition to the FALLING state.

We'll also need to handle the asynchronous reset signal (areset) to reset the state machine to the WALK_LEFT state when asserted.
