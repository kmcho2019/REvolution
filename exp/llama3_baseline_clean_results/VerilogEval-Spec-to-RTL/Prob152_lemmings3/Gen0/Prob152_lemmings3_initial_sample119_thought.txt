To implement the Lemming's behavior, we will design a Moore state machine with the following states:
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling due to the absence of ground.
- DIGGING: The Lemming is digging.

The state machine will have the following transitions:
- From WALK_LEFT or WALK_RIGHT to FALLING: When ground=0.
- From FALLING to WALK_LEFT or WALK_RIGHT: When ground=1.
- From WALK_LEFT or WALK_RIGHT to DIGGING: When dig=1 and ground=1.
- From DIGGING to FALLING: When ground=0.
- From WALK_LEFT to WALK_RIGHT: When bump_left=1.
- From WALK_RIGHT to WALK_LEFT: When bump_right=1.

We will use two state variables, state and next_state, to implement the state machine. The state variable will hold the current state, and the next_state variable will hold the next state based on the current state and inputs. The outputs will be determined by the current state.
