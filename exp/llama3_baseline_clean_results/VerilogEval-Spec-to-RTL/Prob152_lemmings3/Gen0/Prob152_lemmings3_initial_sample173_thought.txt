To implement the Lemmings' behavior as a Moore state machine, we need to define the possible states and transitions between them. 
The states are:
- walking_left: The Lemming is walking left.
- walking_right: The Lemming is walking right.
- falling: The Lemming has lost ground and is falling.
- digging: The Lemming is digging.

The transitions between these states are determined by the input signals:
- If the Lemming is walking and bumps into an obstacle, it switches direction.
- If the Lemming loses ground, it starts falling.
- If the Lemming is walking and receives a dig signal, it starts digging.
- If the Lemming is digging and loses ground, it stops digging and starts falling.
- If the Lemming is falling and regains ground, it resumes its previous walking direction.

We will implement this state machine using a Moore machine, where the outputs are a function of the current state.
