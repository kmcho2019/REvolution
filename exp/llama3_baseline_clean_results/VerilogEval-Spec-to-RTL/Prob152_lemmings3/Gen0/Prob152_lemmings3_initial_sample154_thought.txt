To implement the Lemmings behavior, we will model it as a finite state machine. The states will be: idle, walking_left, walking_right, falling, and digging. 

The idle state will be the initial state after reset, where the Lemming starts walking left. 

When the Lemming is in the walking_left or walking_right state, it will switch directions if it hits an obstacle (bump_left or bump_right). 

If the ground disappears (ground = 0), the Lemming will transition to the falling state and say "aaah!". 

If the Lemming is told to dig (dig = 1) while it is walking, it will transition to the digging state and continue digging until it reaches the other side (ground = 0), at which point it will fall. 

The state machine will be implemented using a Moore machine, where the output is determined solely by the current state.
