To implement the Lemming machine as a Moore state machine, we will need to identify the possible states and their transitions based on the given inputs and behaviors. 

The possible states are: 
- Walking Left (WL)
- Walking Right (WR)
- Falling (F)
- Digging (D)

Transitions between these states will be based on the input signals: 
- bump_left and bump_right for changing walking direction
- ground for falling and stopping falling
- dig for starting and stopping digging

Since being bumped while falling or digging has no effect, and being told to dig when falling or with no ground is ignored, the transitions related to bumping and digging will only occur when the Lemming is walking on the ground.

Given the conditions and priorities (falling > digging > switching directions), we will handle each input condition separately, considering the current state of the Lemming.

We will use Verilog to describe this state machine, utilizing the `always` block for sequential logic and conditional statements for handling state transitions.
