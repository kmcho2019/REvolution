The problem describes a finite state machine with the following states:
- walking left
- walking right
- falling
- digging

The machine starts in the walking left state and changes direction when bumped. 
If the ground disappears, the Lemming falls. 
If the Lemming is told to dig and is on the ground, it starts digging. 
Digging continues until the ground disappears, at which point the Lemming falls. 
The Lemming resumes walking in the same direction when the ground reappears. 

The state machine can be implemented as a Moore machine, where the output is a function of the current state. 
The states can be encoded as follows:
- 2'b00: walking left
- 2'b01: walking right
- 2'b10: falling
- 2'b11: digging

The next state logic can be derived from the given conditions and implemented using a case statement. 
The outputs can be assigned based on the current state.
