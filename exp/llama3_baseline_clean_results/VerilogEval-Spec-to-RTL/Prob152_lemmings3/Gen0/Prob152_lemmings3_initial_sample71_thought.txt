To implement the Lemming machine as a Moore state machine, we need to define the states and transitions based on the given behavior. The states can be defined as follows:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling due to no ground or digging through the ground.
- DIGGING: The Lemming is digging.

The transitions between states are based on the input signals and current state. When the ground disappears (ground=0), the Lemming should transition to the FALLING state. When the ground reappears (ground=1), the Lemming should resume walking in the same direction as before the fall.

When the dig signal is high (dig=1) and the Lemming is on the ground (ground=1), it should start digging. The Lemming should continue digging until it reaches the other side (ground=0), at which point it should fall.

Being bumped on the left or right side should cause the Lemming to switch directions. However, being bumped while falling or digging should not affect the walking direction.

We will use a Moore state machine to implement this behavior, where the outputs are a function of the current state only.
