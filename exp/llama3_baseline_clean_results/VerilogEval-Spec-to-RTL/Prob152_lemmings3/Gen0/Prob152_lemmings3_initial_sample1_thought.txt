The problem can be solved by designing a Moore state machine with four states: WALK_LEFT, WALK_RIGHT, FALLING, and DIGGING. The initial state will be WALK_LEFT. We will use two variables to keep track of the current state and the previous direction. The state machine will transition between these states based on the input signals. If the ground signal is 0, the state machine will transition to the FALLING state. If the dig signal is 1 and the ground signal is 1, the state machine will transition to the DIGGING state. If the bump_left or bump_right signal is 1, the state machine will switch direction. We will also need to consider the priority of the conditions, with falling having the highest priority, followed by digging, and then switching directions.
