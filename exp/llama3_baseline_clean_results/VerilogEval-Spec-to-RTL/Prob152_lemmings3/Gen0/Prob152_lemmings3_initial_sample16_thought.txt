To implement the TopModule, we need to design a finite state machine that models the behavior of a Lemming. The machine has three main states: walking, falling, and digging. We will use a Moore state machine, where the outputs are determined solely by the current state. The machine will transition between states based on the input signals. We will use two state variables: one to track the direction of the Lemming (left or right) and another to track the current state (walking, falling, or digging).
