To implement the described behavior, we will create a Moore state machine with the following states:
- IDLE_LEFT: walking left
- IDLE_RIGHT: walking right
- FALLING: falling and saying "aaah!"
- DIGGING_LEFT: digging while walking left
- DIGGING_RIGHT: digging while walking right

Transitions between states will occur based on the inputs and current state. We'll use a positive edge-triggered asynchronous reset to reset the machine to walk left.

The state machine will be implemented using a case statement to handle the different states and their corresponding next states. The outputs will be assigned based on the current state.
