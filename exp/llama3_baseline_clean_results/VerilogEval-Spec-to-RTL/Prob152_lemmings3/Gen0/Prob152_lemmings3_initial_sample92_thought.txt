To implement the Lemmings' behavior as a Moore state machine, we need to define the states and the transitions between them. The states can be: walking left, walking right, falling, and digging. The transitions between these states will be based on the input signals (bump_left, bump_right, ground, dig) and the current state. 

We will use an enumeration to define the states and a case statement to handle the transitions. The outputs (walk_left, walk_right, aaah, digging) will be assigned based on the current state.

We will also need to handle the asynchronous reset (areset) to reset the state machine to the walking left state.
