To model the Lemmings' behavior, we will design a finite state machine (FSM) with the following states: 
1. Walking Left (WL)
2. Walking Right (WR)
3. Falling (F)
4. Digging Left (DL)
5. Digging Right (DR)

The FSM will start in the Walking Left state. The next state will be determined by the current state and inputs. If the ground disappears, the FSM will transition to the Falling state. If the Lemming is bumped while walking, it will switch directions. If the dig signal is high while the Lemming is walking on ground, it will start digging. If the ground reappears while the Lemming is falling, it will resume walking in the same direction as before. If the Lemming reaches the other side while digging, it will fall and then continue walking in its original direction once it hits ground again.

We will use a Moore state machine, where the outputs are determined by the current state.
