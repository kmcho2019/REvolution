The problem can be solved by implementing a Moore state machine with the following states: WALK_LEFT, WALK_RIGHT, FALL, and DIG. 
- WALK_LEFT and WALK_RIGHT states represent the Lemming walking in the respective directions.
- FALL state represents the Lemming falling when there is no ground.
- DIG state represents the Lemming digging when the dig signal is high.

The state machine should have the following transitions:
- From WALK_LEFT/WALK_RIGHT to FALL: when ground is 0.
- From WALK_LEFT to WALK_RIGHT: when bump_left is 1.
- From WALK_RIGHT to WALK_LEFT: when bump_right is 1.
- From WALK_LEFT/WALK_RIGHT to DIG: when dig is 1 and ground is 1.
- From FALL to WALK_LEFT/WALK_RIGHT: when ground is 1 and the previous direction was left/right.
- From DIG to FALL: when ground is 0.
- From DIG to WALK_LEFT/WALK_RIGHT: when ground is 0 and the Lemming starts falling.

The state machine should also consider the following conditions:
- If the Lemming is bumped while falling, it should not change direction.
- If the Lemming is told to dig when falling, it should be ignored.
- If the Lemming is bumped while digging, it should not change direction.
- If the ground reappears while the Lemming is falling, it should resume walking in the same direction as before the fall.
