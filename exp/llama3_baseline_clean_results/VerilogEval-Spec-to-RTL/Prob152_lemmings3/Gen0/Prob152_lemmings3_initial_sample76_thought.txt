To implement the Lemming behavior, we will use a Moore state machine. The states will be: walking_left, walking_right, falling, and digging. 
We will use two registers: one for the current state and another for the direction (left or right). 
We will update the current state and direction based on the input signals (bump_left, bump_right, ground, dig) and the current state. 
The output signals (walk_left, walk_right, aaah, digging) will be determined by the current state. 
We will handle the priority of the conditions (falling, digging, switching directions) by checking them in order.
