To model the behavior of the Lemming, we can use a Moore state machine with three states: walking, falling, and digging. The state machine will have the following transitions:

- When in the walking state and the ground disappears, the state machine will transition to the falling state.
- When in the falling state and the ground reappears, the state machine will transition back to the walking state, maintaining its previous walking direction.
- When in the walking state and the dig signal is high, the state machine will transition to the digging state.
- When in the digging state and the ground disappears, the state machine will transition to the falling state, and then to the walking state when the ground reappears, maintaining its previous walking direction.
- When in the walking state and a bump signal is high, the state machine will switch its walking direction.

We can also keep track of the walking direction using a separate variable.
