To implement the Lemming behavior as a Moore state machine, we will define the following states:
- IDLE_LEFT: The Lemming is walking left and waiting for the next event.
- IDLE_RIGHT: The Lemming is walking right and waiting for the next event.
- FALLING: The Lemming has lost ground and is falling.
- DIGGING: The Lemming is digging and waiting for the ground to disappear.

We will use a case statement to determine the next state based on the current state and inputs.
The output will be determined by the current state.

We will use an enumeration to represent the states, making the code easier to read and maintain.
We will handle the asynchronous reset in the initial block and on every positive edge of the clock, ensuring that the state machine resets correctly.
