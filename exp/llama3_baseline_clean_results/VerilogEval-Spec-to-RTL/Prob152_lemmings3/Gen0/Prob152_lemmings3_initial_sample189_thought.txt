To implement the Lemmings' behavior as a Moore state machine, we first identify the states and transitions based on the given conditions. The key states are walking left, walking right, falling, and digging. We will use a 2-bit state variable to represent these states. The transitions will be based on the input signals bump_left, bump_right, ground, and dig. When the ground disappears, the Lemming will transition to the falling state, and when the ground reappears, it will resume its previous walking direction. The dig signal will trigger the Lemming to start digging if it is currently walking on the ground. We will use combinational logic to determine the next state and output values based on the current state and input signals.
