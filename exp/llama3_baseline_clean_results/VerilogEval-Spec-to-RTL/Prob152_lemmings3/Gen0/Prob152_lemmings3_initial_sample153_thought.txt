To implement the Lemmings finite state machine, we can define a Moore state machine with states representing the different modes of the Lemming, such as walking left, walking right, falling, and digging. We will use a variable to store the current state and another variable to store the previous direction of the Lemming. We will update these variables based on the input signals and the current state. The output signals will be determined by the current state and the previous direction.

The states can be defined as follows:
- WALK_LEFT: Lemming is walking left
- WALK_RIGHT: Lemming is walking right
- FALLING: Lemming is falling
- DIGGING: Lemming is digging

The state machine will transition between these states based on the input signals. If the ground is not present (ground = 0), the Lemming will transition to the FALLING state. If the Lemming is digging and the ground becomes not present, it will transition to the FALLING state. If the Lemming is bumped while walking, it will switch direction. If the Lemming is told to dig while walking, it will transition to the DIGGING state.

We will use a reset signal (areset) to reset the state machine to the WALK_LEFT state when it is asserted.
