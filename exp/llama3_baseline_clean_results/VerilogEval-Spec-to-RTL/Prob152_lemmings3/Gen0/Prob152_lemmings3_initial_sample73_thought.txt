The problem can be solved by designing a finite state machine (FSM) with the following states: 
- walking_left
- walking_right
- falling
- digging_left
- digging_right

We will use a Moore state machine, meaning the outputs are determined by the current state only.

The state transitions will be determined based on the inputs. 
- If the Lemming is walking and hits an obstacle, it will switch directions.
- If the Lemming is walking and the ground disappears, it will fall.
- If the Lemming is falling and the ground reappears, it will resume walking in the same direction.
- If the Lemming is walking and told to dig, it will start digging.
- If the Lemming is digging and reaches the other side, it will fall.

We will also need to consider the precedence of the conditions: fall has higher precedence than dig, which has higher precedence than switching directions.
