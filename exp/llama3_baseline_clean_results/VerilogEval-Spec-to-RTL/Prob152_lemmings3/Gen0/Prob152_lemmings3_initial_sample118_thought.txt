To implement the Lemming behavior, we will create a Moore state machine that tracks the current state of the Lemming (walking left, walking right, falling, or digging). The state machine will have four states: WALK_LEFT, WALK_RIGHT, FALLING, and DIGGING. 

We will use a case statement to handle the current state and the input signals to determine the next state and the output signals. 

When the Lemming is walking and the ground disappears, it will transition to the FALLING state. When the Lemming is falling and the ground reappears, it will transition back to the previous walking state. 

When the Lemming is walking and the dig signal is asserted, it will transition to the DIGGING state. When the Lemming is digging and the ground disappears, it will transition to the FALLING state, and then to the previous walking state when the ground reappears.
