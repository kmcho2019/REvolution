To implement the Lemmings' behavior using a Moore state machine, we can define the following states: 
- WALK_LEFT: Lemming is walking to the left.
- WALK_RIGHT: Lemming is walking to the right.
- FALLING: Lemming is falling.
- DIGGING: Lemming is digging.
We can then define the state transitions based on the inputs. The state machine will be reset to WALK_LEFT when areset is asserted. 
The output signals walk_left, walk_right, aaah, and digging will be determined by the current state.
