To implement the described behavior of the Lemming as a Moore state machine, we can identify the following states: 
1. Walking Left (WL), 
2. Walking Right (WR), 
3. Falling (F), and 
4. Digging (D).

The state transitions will depend on the input signals. If the Lemming is walking and hits an obstacle, it switches direction. 
When ground=0, the Lemming will fall. 
When the ground reappears, it resumes walking in the same direction. 
If the Lemming is told to dig (dig=1) while walking on the ground, it will continue digging until it reaches the other side, then fall.

We can use a Moore state machine to model these behaviors and transitions. The outputs (walk_left, walk_right, aaah, digging) will be determined by the current state.

The implementation will involve a state register that stores the current state and a combinational logic block that determines the next state based on the current state and inputs.
