To implement the Lemming's behavior as a Moore state machine, we need to define the states and transitions based on the given conditions. We can identify four main states: walking left, walking right, falling, and digging. The state machine will transition between these states based on the inputs (bump_left, bump_right, ground, and dig). 

The state machine will start in the walking left state when reset. If the Lemming is walking and ground is 0, it will fall. If it's walking and dig is 1, it will start digging. If it's digging and ground is 0, it will fall. If it's falling, it will stay in that state until ground is 1 again, at which point it will resume walking in its previous direction. If the Lemming is bumped while walking, it will switch direction. 

We will use a binary encoding for the states: 00 for walking left, 01 for walking right, 10 for falling, and 11 for digging. We will also keep track of the previous direction (left or right) while the Lemming is falling or digging.
