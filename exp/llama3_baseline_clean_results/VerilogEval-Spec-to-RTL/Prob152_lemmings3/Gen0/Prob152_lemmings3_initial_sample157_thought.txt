To implement the Lemmings behavior using a Moore state machine, we will define the following states:
- IDLE_LEFT: walking left on ground
- IDLE_RIGHT: walking right on ground
- FALLING: falling due to no ground
- DIGGING_LEFT: digging while walking left on ground
- DIGGING_RIGHT: digging while walking right on ground

We will use the current state and input signals to determine the next state and output signals.

When the ground is available (ground=1), the Lemming can walk left or right, and can switch directions if bumped. If dig=1, the Lemming will start digging.

When the ground is not available (ground=0), the Lemming will fall and say "aaah!". The Lemming will resume walking in the same direction as before the fall when the ground reappears.

We will use areset to reset the state machine to the IDLE_LEFT state.

The output signals will be determined based on the current state.
