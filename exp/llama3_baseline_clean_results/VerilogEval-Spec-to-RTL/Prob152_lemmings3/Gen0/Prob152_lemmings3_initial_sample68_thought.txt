The Lemming's behavior can be modeled using a Moore state machine with three states: walking left, walking right, and digging. The state machine will transition between these states based on the input signals. We will also use a separate variable to keep track of the Lemming's direction before it falls, so it can resume walking in the same direction when the ground reappears. 
The state machine will prioritize the input signals as follows: 
1. ground: If the ground is 0, the Lemming will fall and say "aaah!".
2. dig: If the Lemming is walking on ground and it receives the dig signal, it will start digging.
3. bump_left and bump_right: If the Lemming is walking and it receives a bump signal, it will switch directions.
