To model the Lemmings' behavior, we need to design a Moore state machine that handles the different states (walking left, walking right, falling, and digging) and the various transitions between these states based on the input signals. The states can be defined as follows:
- walking_left: The Lemming is walking to the left.
- walking_right: The Lemming is walking to the right.
- falling: The Lemming has lost ground and is falling.
- digging: The Lemming is digging.

The state machine should transition between these states based on the input signals:
- If the Lemming is bumped on the left while walking, it should transition to walking right.
- If the Lemming is bumped on the right while walking, it should transition to walking left.
- If there is no ground (ground=0), the Lemming should transition to falling, regardless of the current state.
- If the Lemming is told to dig (dig=1) while walking on ground, it should transition to digging.
- If the Lemming is digging and loses ground, it should transition to falling.
- If the Lemming is falling and regains ground, it should transition back to walking in the same direction as before the fall.
- The areset signal should reset the state machine to walking left.

We will use two variables to keep track of the current state and the previous walking direction. The walking direction will be used to determine the state after falling or digging.
