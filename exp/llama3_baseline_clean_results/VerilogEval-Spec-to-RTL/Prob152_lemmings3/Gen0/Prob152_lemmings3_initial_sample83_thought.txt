To implement the Lemming behavior as a Moore state machine, we need to identify the states and transitions. The states are: walking left, walking right, falling, and digging. 

- When walking left or right, the Lemming can switch direction if bumped, start falling if the ground disappears, or start digging if the dig signal is high.
- When falling, the Lemming will continue falling until it hits the ground, at which point it will resume walking in the original direction.
- When digging, the Lemming will continue digging until it reaches the other side, at which point it will fall and then resume walking in the original direction.

We will use a 4-state state machine with states: WALK_LEFT, WALK_RIGHT, FALLING, and DIGGING. The state machine will have an initial state of WALK_LEFT, and it will transition between states based on the input signals.
