To implement the Lemming machine as a Moore state machine, we need to define the states and the transitions between them. The states will be: walking left, walking right, falling, and digging. We will also need to keep track of the direction the Lemming was walking before falling or digging, so it can resume walking in the same direction when it hits the ground again.

The state machine will have the following states:
- IDLE_LEFT: the initial state, where the Lemming is walking left
- IDLE_RIGHT: the state where the Lemming is walking right
- FALLING: the state where the Lemming is falling
- DIGGING: the state where the Lemming is digging

The transitions between the states will be based on the input signals: bump_left, bump_right, ground, and dig.

When the Lemming is walking (in either IDLE_LEFT or IDLE_RIGHT state), it will switch direction if it is bumped. If the ground disappears, it will start falling. If it is told to dig, it will start digging.

When the Lemming is falling, it will continue falling until it hits the ground again. When it hits the ground, it will resume walking in the same direction as before it started falling.

When the Lemming is digging, it will continue digging until it reaches the other side (ground=0). At that point, it will start falling. When it hits the ground again, it will resume walking in the same direction as before it started digging.
