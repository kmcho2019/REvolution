To implement the Lemming state machine, we'll use a Moore state machine. The state machine has four states: WALK_LEFT, WALK_RIGHT, FALLING, and DIGGING. We'll use a case statement to determine the next state based on the current state and inputs. The output signals will be assigned based on the current state. We'll also use a flag to keep track of the previous direction of the Lemming.

The state machine will work as follows:

- If the current state is WALK_LEFT or WALK_RIGHT, the Lemming will switch direction if it hits an obstacle (bump_left or bump_right).
- If the current state is WALK_LEFT or WALK_RIGHT and ground is 0, the Lemming will fall.
- If the current state is WALK_LEFT or WALK_RIGHT and dig is 1, the Lemming will start digging.
- If the current state is FALLING, the Lemming will continue falling until it hits the ground.
- If the current state is DIGGING, the Lemming will continue digging until it reaches the other side (ground is 0).
- The output signals will be assigned based on the current state.
