To implement the Lemming's behavior, we need to define a finite state machine with the following states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling due to no ground.
- DIGGING: The Lemming is digging.

We'll use a Moore state machine, where the outputs are a function of the current state.

The state transitions will be as follows:
- If the Lemming is walking and there's no ground, it will start falling.
- If the Lemming is walking and told to dig, it will start digging.
- If the Lemming is walking and bumped, it will switch directions.
- If the Lemming is falling and ground reappears, it will resume walking in the previous direction.
- If the Lemming is digging and there's no ground, it will start falling.

We'll use two state variables: one to track the direction (left or right) and another to track the current state (walking, falling, or digging).
