To implement the Lemming's behavior, we can define a Moore state machine with the following states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALL: The Lemming is falling.
- DIG: The Lemming is digging.

The state machine will transition between these states based on the input signals. The output signals will be determined by the current state.

When the Lemming is walking (WALK_LEFT or WALK_RIGHT), it will switch directions if bumped. If the ground disappears, it will transition to the FALL state. If it is told to dig and the ground is present, it will transition to the DIG state.

When the Lemming is falling (FALL), it will transition back to the previous walking state when the ground reappears.

When the Lemming is digging (DIG), it will continue digging until the ground disappears, at which point it will transition to the FALL state. When the ground reappears, it will transition back to the original walking state.
