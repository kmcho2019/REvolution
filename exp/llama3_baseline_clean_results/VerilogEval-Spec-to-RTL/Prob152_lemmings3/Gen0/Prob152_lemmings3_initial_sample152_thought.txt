To implement the Lemming's behavior, we can use a finite state machine (FSM) with the following states: 
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling due to no ground.
- DIGGING: The Lemming is digging.

We will use a Moore machine, where the outputs are a function of the current state only. The next state will be determined by the current state and the inputs.

We will prioritize the conditions as follows:
- If there is no ground, the Lemming will fall.
- If the Lemming is told to dig and it is walking on ground, it will start digging.
- If the Lemming is bumped, it will change direction.
