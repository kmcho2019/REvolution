To implement the Lemming's behavior, we'll create a Moore state machine with the following states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALL: The Lemming is falling.
- DIG: The Lemming is digging.

The state machine will transition between these states based on the inputs and current state.

- If the Lemming is walking and the ground disappears, it will transition to the FALL state.
- If the Lemming is walking and it's bumped, it will switch direction.
- If the Lemming is walking and it's told to dig, it will start digging.
- If the Lemming is digging and the ground disappears, it will transition to the FALL state.
- If the Lemming is falling and the ground reappears, it will resume walking in its original direction.

We'll use a case statement to handle the different states and transition logic.
