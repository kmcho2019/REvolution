To implement the Lemming's behavior, we will create a finite state machine with the following states: 
- Walking Left (WL)
- Walking Right (WR)
- Falling (F)
- Digging Left (DL)
- Digging Right (DR)

We will use a Moore state machine, where the outputs are determined solely by the current state.

The state machine will have the following transitions:
- From WL or WR, if ground=0, transition to F
- From WL or WR, if dig=1 and ground=1, transition to DL or DR respectively
- From WL or WR, if bump_left=1, transition to WR
- From WL or WR, if bump_right=1, transition to WL
- From DL or DR, if ground=0, transition to F
- From F, if ground=1, transition to WL or WR, depending on the previous walking direction

The outputs will be determined as follows:
- walk_left = 1 if the current state is WL or DL
- walk_right = 1 if the current state is WR or DR
- aaah = 1 if the current state is F
- digging = 1 if the current state is DL or DR
