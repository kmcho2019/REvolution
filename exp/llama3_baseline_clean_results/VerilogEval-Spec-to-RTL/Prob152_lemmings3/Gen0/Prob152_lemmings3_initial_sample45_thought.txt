The problem can be solved by designing a Moore finite state machine with states representing the Lemming's walking direction and its current action (walking, falling, or digging). The state machine will be triggered by the positive edge of the clock and will have an asynchronous reset. The next state will be determined by the current state and the input signals. The output signals will be determined by the current state.

We can define the following states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALL: The Lemming is falling.
- DIG_LEFT: The Lemming is digging while walking left.
- DIG_RIGHT: The Lemming is digging while walking right.

The next state logic will be based on the current state and the input signals. For example, if the current state is WALK_LEFT and the Lemming is bumped on the left, the next state will be WALK_RIGHT.

The output signals will be determined by the current state. For example, if the current state is WALK_LEFT, the walk_left output signal will be 1, and the walk_right output signal will be 0.
