To implement the TopModule, we can use a Moore state machine with states representing walking left, walking right, falling, and digging. We will use a reset to initialize the state machine to walk left. We will then use the inputs to determine the next state and output. If the ground is 0, the Lemming will fall. If the Lemming is told to dig and is currently on the ground, it will start digging. If the Lemming is bumped, it will switch directions.
