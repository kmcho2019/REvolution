To implement the Lemming's behavior, we can use a Moore state machine with the following states:
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling due to lack of ground.
- DIGGING: The Lemming is digging.

We will use the inputs to determine the next state and the outputs. The areset signal will reset the state machine to WALK_LEFT.

When the Lemming is walking, it will switch directions if it hits an obstacle. If the ground disappears, it will start falling. If it is told to dig and the ground is present, it will start digging.

When the Lemming is falling, it will continue falling until the ground reappears, at which point it will resume walking in the same direction as before.

When the Lemming is digging, it will continue digging until the ground disappears, at which point it will start falling. Once the ground reappears, it will resume walking in the original direction.
