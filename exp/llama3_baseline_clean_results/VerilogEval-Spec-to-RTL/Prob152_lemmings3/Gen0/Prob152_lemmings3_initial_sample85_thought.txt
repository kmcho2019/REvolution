To implement this finite state machine, we can define the states as follows:
- WALKING_LEFT: The Lemming is walking left.
- WALKING_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.

The state transitions will be based on the input signals: bump_left, bump_right, ground, and dig. We need to prioritize the transitions based on the problem description. If the ground disappears (ground=0), the Lemming will fall, regardless of the other inputs. If the Lemming is walking and dig=1, it will start digging. If the Lemming is walking and it hits an obstacle (bump_left=1 or bump_right=1), it will switch directions.

We can use a Moore state machine, where the outputs are a function of the current state only. This means that we need to keep track of the previous walking direction when the Lemming is falling or digging.
