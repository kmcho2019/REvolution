To model the behavior of the Lemming using a Moore state machine, we will define the states as walking left, walking right, falling, and digging. We will also use a reset state for initialization. The state transitions will be based on the inputs (bump_left, bump_right, ground, dig) and the current state. We will use a single process to handle all the state transitions and output assignments. The process will be triggered on the positive edge of the clock.
