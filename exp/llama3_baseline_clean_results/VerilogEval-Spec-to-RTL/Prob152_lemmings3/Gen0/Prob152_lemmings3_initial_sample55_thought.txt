The solution involves designing a Moore state machine with four states: walking_left, walking_right, falling, and digging. The state machine will transition between these states based on the input signals. 

When the Lemming is walking, it can change direction when bumped, start digging when told to do so, or start falling when the ground disappears. 

When the Lemming is falling, it will resume walking in the same direction as before when the ground reappears. 

When the Lemming is digging, it will continue digging until it reaches the other side, at which point it will fall and then resume walking in its original direction when it hits the ground again.

The state machine will also have to handle asynchronous reset, where the Lemming resets to walking left when the areset signal is asserted.
