To implement the Lemmings' behavior as a finite state machine, we can define the following states: 
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming has fallen and is saying "aaah!".
- DIGGING: The Lemming is digging.
We will use a Moore state machine, where the outputs are determined solely by the current state. 
The state transitions will be based on the input signals and the current state. 
We will also use a separate variable to keep track of the Lemming's direction before it starts falling or digging, so it can resume walking in the same direction when it hits the ground again.
