To implement the Lemming's behavior as a Moore state machine, we can define the following states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.

We can use a binary encoded state machine with 2 bits to represent the 4 states. The next state logic will be determined based on the current state and the input signals.

When the Lemming is walking, it can switch direction if it hits an obstacle (bump_left or bump_right). If it's bumped on both sides at the same time, it will still switch directions.

When the ground disappears (ground=0), the Lemming will fall. Being bumped while falling does not affect the walking direction.

The Lemming can dig if it is currently walking on ground (ground=1) and not falling. It will continue digging until it reaches the other side (ground=0). At that point, since there is no ground, it will fall.

The output signals (walk_left, walk_right, aaah, digging) will be determined based on the current state.
