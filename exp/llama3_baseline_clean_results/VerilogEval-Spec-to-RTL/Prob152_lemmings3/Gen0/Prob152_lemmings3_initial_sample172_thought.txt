To implement the Lemming's behavior as a Moore state machine, we need to define the states and their transitions. The states can be: 
- Walking Left (WL)
- Walking Right (WR)
- Falling (F)
- Digging (D)

The transitions between these states will be based on the input signals: 
- bump_left and bump_right for changing direction
- ground for falling and resuming walking
- dig for starting to dig

We will use an enum to represent the states and a case statement to handle the state transitions.

Since we need to remember the direction the Lemming was walking in before it started falling or digging, we can add an additional signal to keep track of the direction.
