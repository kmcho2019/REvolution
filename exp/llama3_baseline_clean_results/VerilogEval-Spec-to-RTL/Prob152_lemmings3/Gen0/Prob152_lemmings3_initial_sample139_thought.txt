To implement the Lemming state machine, we can use a Moore machine with the following states: 
- idle_left (initial state, walking left)
- idle_right (walking right)
- falling (Lemming is falling)
- digging_left (Lemming is digging while walking left)
- digging_right (Lemming is digging while walking right)
The next state logic is determined by the current state and the inputs. We need to consider all possible combinations of inputs and their effects on the next state.

For the output logic, we need to generate the walk_left, walk_right, aaah, and digging signals based on the current state.
