To implement the Lemmings' behavior as a finite state machine, we can define four states: 
- Walking Left (WL)
- Walking Right (WR)
- Falling (F)
- Digging (D)

The state transitions are as follows:
- From WL and WR, if ground=0, the Lemming will transition to F.
- From F, if ground=1, the Lemming will transition back to its previous walking state.
- From WL and WR, if dig=1 and ground=1, the Lemming will transition to D.
- From D, if ground=0, the Lemming will transition to F.

To switch directions when bumped, we can use conditional statements to set the next state based on the current state and the bump inputs.

We can use two flip-flops to encode the four states. 
We will also need to keep track of the previous walking direction when the Lemming is falling or digging, so that it can resume walking in the same direction when the ground reappears or when it finishes digging.
