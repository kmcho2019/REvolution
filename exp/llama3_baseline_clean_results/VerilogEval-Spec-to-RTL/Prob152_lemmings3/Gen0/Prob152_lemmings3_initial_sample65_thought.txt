To implement the Lemmings finite state machine, we need to define the states and transitions based on the given conditions. The states can be: walking_left, walking_right, falling, and digging. The transitions between these states are determined by the input signals. 

We will use a Moore state machine, where the output is a function of the current state only. The state will be updated based on the current state and the input signals. 

The state machine will start in the walking_left state after reset. 

When ground=0, the state machine will transition to the falling state, regardless of the current state. 

When the Lemming is walking and receives a bump signal, it will switch directions. 

When the Lemming is walking and receives a dig signal, it will start digging if there is ground. 

When the Lemming is digging and there is no ground, it will start falling. 

When the Lemming is falling and there is ground, it will resume walking in the previous direction.
