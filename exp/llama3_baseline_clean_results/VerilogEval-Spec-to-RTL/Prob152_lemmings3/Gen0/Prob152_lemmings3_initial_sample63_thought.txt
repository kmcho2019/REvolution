To implement the Lemming's behavior as a finite state machine, we need to identify the possible states and transitions. 
The states can be:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
The transitions between these states can be based on the input conditions:
- bump_left or bump_right: Change walking direction.
- ground: If ground is 0, transition to FALLING. If ground is 1, transition to WALK_LEFT or WALK_RIGHT depending on the previous walking direction.
- dig: If ground is 1 and the Lemming is walking, transition to DIGGING.

We will implement a Moore state machine, where the output is a function of the current state only.
The state machine will be implemented using a case statement and a combinational logic for the next state calculation.
The state will be stored in a register and updated on the positive edge of the clock.
The areset will asynchronously reset the state to WALK_LEFT.
