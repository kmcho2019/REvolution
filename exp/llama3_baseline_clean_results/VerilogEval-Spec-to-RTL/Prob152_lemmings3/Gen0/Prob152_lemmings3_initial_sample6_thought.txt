The problem describes a finite state machine that models the behavior of a Lemming in the game Lemmings. The state machine has several states: walking left, walking right, falling, and digging. It responds to various inputs such as bumps on the left and right, ground presence, and a signal to dig. The state machine also has priorities for its actions, with falling having higher precedence than digging, which has higher precedence than switching directions.

To implement this state machine in Verilog, we can use a Moore state machine, which means that the output is a function of the current state only. We can define the states as follows:
- S_WALK_LEFT: The Lemming is walking left.
- S_WALK_RIGHT: The Lemming is walking right.
- S_FALL: The Lemming is falling.
- S_DIG: The Lemming is digging.

We will use a parameterized state machine with the above states to implement the behavior. The state machine will transition between these states based on the input signals.

We will also use a variable to keep track of the direction the Lemming was walking before it started falling or digging, so that we can resume walking in the same direction when the Lemming hits the ground again.
