To implement the Lemmings' behavior as a finite state machine, we can identify the following states: 
- walking left
- walking right
- falling
- digging
We will use a Moore state machine where the outputs are a function of the current state. 
The state transitions will be triggered by the inputs (bump_left, bump_right, ground, dig) and the current state.
We will use an enum to define the states and a case statement to handle the state transitions and output logic.
The sequential logic will be triggered on the positive edge of the clock.
