To model the behavior of the Lemming, we need to design a Moore finite state machine. The states of the machine will be:
- WALKING_LEFT: The Lemming is walking left.
- WALKING_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.

We will use a Mealy approach for some of the output logic, specifically for the aaah and digging outputs, which depend on the current state and the input values. The next state logic will be based on the current state and input values.

The initial state will be WALKING_LEFT, and the state will change based on the inputs. The outputs will be determined by the current state and input values.
