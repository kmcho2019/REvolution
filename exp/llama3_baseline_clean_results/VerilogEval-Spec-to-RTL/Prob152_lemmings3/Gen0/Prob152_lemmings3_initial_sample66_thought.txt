To implement the Lemming behavior, we need to define a finite state machine with the following states:
- IDLE_LEFT: walking left on the ground
- IDLE_RIGHT: walking right on the ground
- FALLING: falling due to no ground
- DIGGING_LEFT: digging while walking left
- DIGGING_RIGHT: digging while walking right

The machine will transition between these states based on the inputs (bump_left, bump_right, ground, dig). 

When the machine is in the IDLE states, it will switch direction if it hits an obstacle. If ground=0, it will transition to the FALLING state. If dig=1, it will transition to the DIGGING states. 

When the machine is in the FALLING state, it will say "aaah!" and continue falling until ground reappears. At that point, it will resume walking in the same direction as before the fall. 

When the machine is in the DIGGING states, it will continue digging until it reaches the other side (ground=0). At that point, it will transition to the FALLING state. Once it hits ground again, it will resume walking in its original direction.
