To implement the Lemmings' finite state machine, we need to identify all the possible states and transitions. 
The states are: walking left, walking right, falling, and digging. 
The transitions are based on the input signals: bump_left, bump_right, ground, and dig.
We will use a Moore state machine, which means the outputs are a function of the current state only.
We will use an enum to define the states and a case statement to handle the transitions.
We will also use a separate signal to keep track of the previous direction, so that when the Lemming falls or digs, it can resume walking in the same direction.
