To implement this Lemmings finite state machine, we need to identify the states and transitions based on the given conditions. The states can be: walking left, walking right, falling, and digging. We'll use a Moore state machine, where the outputs are a function of the current state only. We'll also use a binary encoding for the states to keep the implementation simple. The transitions will be based on the input signals (bump_left, bump_right, ground, dig) and the current state. 
We'll handle the asynchronous reset (areset) to initialize the state machine to the walking left state. 
We'll use two flip-flops to represent the current state (00 for walking left, 01 for walking right, 10 for falling, and 11 for digging).
