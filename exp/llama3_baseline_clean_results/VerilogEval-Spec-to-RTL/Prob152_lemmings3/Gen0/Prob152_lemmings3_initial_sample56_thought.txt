To implement the Lemmings state machine, we will use a Moore state machine with several states: walking left, walking right, falling, and digging. We will use a state register to keep track of the current state and update it based on the inputs. We will also use a direction register to keep track of the direction the Lemming was walking before it fell or started digging.

- S_WALK_LEFT: the Lemming is walking left
- S_WALK_RIGHT: the Lemming is walking right
- S_FALL: the Lemming is falling
- S_DIG: the Lemming is digging

- walk_left: 1 if the Lemming is walking left
- walk_right: 1 if the Lemming is walking right
- aaah: 1 if the Lemming is falling
- digging: 1 if the Lemming is digging

- If the reset signal is asserted, the state machine will reset to S_WALK_LEFT.
- If the Lemming is walking and the ground disappears, it will start falling.
- If the Lemming is falling and the ground reappears, it will resume walking in the same direction as before it fell.
- If the Lemming is walking and it is told to dig, it will start digging.
- If the Lemming is digging and the ground disappears, it will start falling.
- If the Lemming is walking and it is bumped, it will switch directions.

- walk_left and walk_right will be 1 if the Lemming is walking left or right, respectively.
