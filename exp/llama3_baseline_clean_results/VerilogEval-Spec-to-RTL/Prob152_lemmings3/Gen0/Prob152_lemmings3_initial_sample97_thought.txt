To implement the Lemming machine as a Moore state machine, we need to define the states and transitions based on the given behavior. The states will represent the current activity of the Lemming: walking left, walking right, falling, or digging. We will use a combination of these states and the input signals to determine the next state and output values.

The states can be defined as follows:
- WALK_LEFT: The Lemming is walking to the left.
- WALK_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling due to no ground or has finished digging and there's no ground.
- DIGGING: The Lemming is digging.

The transitions between these states will be determined by the input signals: bump_left, bump_right, ground, and dig.

When the Lemming is walking and encounters an obstacle (bump_left or bump_right), it will switch direction.
If the ground disappears (ground=0), the Lemming will start falling, regardless of its previous state (walking or digging).
If the Lemming is walking and is told to dig (dig=1), it will start digging.
Once the Lemming finishes digging (ground=0), it will fall.
When the ground reappears (ground=1) while the Lemming is falling, it will resume walking in the same direction as before it started falling.

We'll use areset to reset the machine to the WALK_LEFT state.

The output signals walk_left, walk_right, aaah, and digging will be determined by the current state of the machine.
