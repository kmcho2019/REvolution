To implement the Lemmings behavior as a Moore state machine, we need to define the states and the transitions between them. The states can be: WALK_LEFT, WALK_RIGHT, FALL, and DIG. We will use a current state and next state to manage the transitions. When the ground is 0, the Lemming will transition to the FALL state. When the ground reappears, it will transition back to its previous walking direction. When the dig signal is 1, the Lemming will transition to the DIG state if it is currently walking on ground. The Lemming will transition to the opposite walking direction when it is bumped. We will also need to manage the output signals according to the current state.
