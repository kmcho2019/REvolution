To reverse the bit ordering of the input, we can simply assign each bit of the output to the corresponding bit of the input but in reverse order. Since both the input and output are 100 bits wide, we can directly assign out[99:0] to in[99:0] in reverse order, which translates to out[0] being assigned the value of in[99], out[1] being assigned the value of in[98], and so on, until out[99] being assigned the value of in[0]. This can be achieved using a simple loop in Verilog or directly using bit manipulation and assignment.
