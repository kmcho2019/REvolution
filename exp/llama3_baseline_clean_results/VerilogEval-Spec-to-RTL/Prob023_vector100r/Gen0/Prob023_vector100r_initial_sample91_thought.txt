To reverse the bit ordering of the input, we can use a simple assignment statement in Verilog, taking advantage of the fact that we can access individual bits of a vector using their index. We will assign each bit of the output to the corresponding bit of the input, but from the opposite end. This way, the first bit of the input becomes the last bit of the output, the second bit of the input becomes the second to last bit of the output, and so on.
