To reverse the bit ordering of the input, we can assign each bit of the output to the corresponding bit of the input, but from the end of the input vector to the beginning. This can be achieved using Verilog's bit indexing feature, where we assign out[i] to in[99-i] for i = 0 to 99. This way, the first bit of the output will be assigned the last bit of the input, the second bit of the output will be assigned the second last bit of the input, and so on.
