To reverse the bit ordering of the input, we can use Verilog's bit indexing feature to assign each bit of the output to the corresponding bit of the input from the opposite end. This means that the first bit of the output (out[0]) will be assigned the value of the last bit of the input (in[99]), the second bit of the output (out[1]) will be assigned the value of the second-to-last bit of the input (in[98]), and so on. We will use a for loop in the always block to assign the bits.
