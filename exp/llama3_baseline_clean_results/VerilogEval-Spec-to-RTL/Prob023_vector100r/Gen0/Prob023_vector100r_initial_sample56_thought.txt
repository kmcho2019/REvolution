To reverse the bit ordering of the input, we can use Verilog's indexing and concatenation features. Since the input and output are 100 bits each, we can assign each bit of the output to the corresponding bit of the input, but from the end. This means output[0] gets the value of input[99], output[1] gets the value of input[98], and so on, until output[99] gets the value of input[0].
