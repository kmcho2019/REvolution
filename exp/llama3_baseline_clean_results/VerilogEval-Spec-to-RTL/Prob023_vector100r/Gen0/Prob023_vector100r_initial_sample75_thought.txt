To reverse the bit ordering of the input and write to the output, we can use a simple assignment statement in Verilog. The idea is to assign each bit of the output to the corresponding bit of the input from the opposite end. For example, the 0th bit of the output should be assigned the 99th bit of the input, the 1st bit of the output should be assigned the 98th bit of the input, and so on. This can be achieved using a simple loop or by using the built-in bit indexing feature of Verilog.
