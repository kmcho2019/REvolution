The TopModule will be implemented using a finite state machine (FSM) with several states:
- IDLE: The initial state where the FSM searches for the input pattern 1101.
- SHIFT: The state where the FSM shifts in the next 4 bits to determine the duration of the timer delay.
- COUNT: The state where the FSM counts for exactly (delay[3:0] + 1) * 1000 clock cycles.
- DONE: The state where the FSM asserts the done output and waits for the ack input to be 1.
The FSM will use a counter to count the remaining time and a register to store the delay value.
