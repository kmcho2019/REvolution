To implement the TopModule, we will design a finite state machine (FSM) with the following states:
- IDLE: searching for the input pattern 1101
- SHIFT: shifting in the next 4 bits to determine the delay
- COUNT: counting down from (delay + 1) * 1000 clock cycles
- DONE: asserting done and waiting for the ack signal
- RESET: resetting the state machine

We will use a counter to count down from (delay + 1) * 1000 clock cycles and another counter to count the remaining time.
