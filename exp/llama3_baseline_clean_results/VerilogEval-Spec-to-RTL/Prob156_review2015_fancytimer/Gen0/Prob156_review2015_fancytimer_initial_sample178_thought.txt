To implement the TopModule, we will use a finite state machine (FSM) to manage the different states of the timer. The FSM will have the following states: 
- Idle: searching for the start pattern (1101)
- Shift: shifting in the delay bits
- Counting: counting down the delay
- Done: notifying the user and waiting for acknowledgement

We will use a counter to count the number of clock cycles and a register to store the delay value. 
The count output will be updated every 1000 clock cycles.
