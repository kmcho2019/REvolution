To implement the TopModule, we'll use a finite state machine (FSM) with several states: 
- IDLE: searching for the input pattern 1101
- SHIFT: shifting in the next 4 bits to determine the duration of the timer delay
- COUNTING: counting for exactly (delay[3:0] + 1) * 1000 clock cycles
- DONE: waiting for the user to acknowledge the timer
- RESET: resetting the module when the ack input is 1

We'll use a counter to count the remaining time and another counter to count the number of clock cycles. 
The module will output the current remaining time on the count[3:0] output when it is counting, 
and assert done to notify the user the timer has timed out.
