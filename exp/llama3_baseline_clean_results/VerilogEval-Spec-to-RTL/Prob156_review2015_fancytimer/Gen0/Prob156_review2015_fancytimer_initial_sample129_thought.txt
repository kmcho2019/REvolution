To implement the TopModule, we will use a finite state machine (FSM) with several states: 
- IDLE: searching for the input pattern 1101
- SHIFT_DELAY: shifting in the next 4 bits to determine the duration of the timer delay
- COUNTING: counting for exactly (delay + 1) * 1000 clock cycles
- DONE: asserting done to notify the user and waiting for the ack signal

We will use a 4-bit counter to count the remaining time and a 12-bit counter to count the total clock cycles. The FSM will transition between states based on the current state and the input signals. 
We will also use a 4-bit register to store the delay value.
