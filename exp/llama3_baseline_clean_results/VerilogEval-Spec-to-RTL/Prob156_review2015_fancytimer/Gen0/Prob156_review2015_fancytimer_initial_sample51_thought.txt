To solve this problem, we'll design a finite state machine (FSM) with several states:
- Idle: Searching for the input pattern 1101.
- PatternFound: Shifting in the 4-bit delay after the pattern is found.
- Counting: Counting down from the specified delay.
- Done: Asserting the done output and waiting for the ack input.
We'll use a counter to keep track of the current delay and the number of clock cycles elapsed.
