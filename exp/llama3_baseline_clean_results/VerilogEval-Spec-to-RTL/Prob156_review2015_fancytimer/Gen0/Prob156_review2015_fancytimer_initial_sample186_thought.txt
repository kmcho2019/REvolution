To solve this problem, we will use a Finite State Machine (FSM) approach with multiple states:
- IDLE: searching for the input pattern 1101
- GET_DELAY: shifting in the next 4 bits to determine the delay
- COUNTING: counting for the specified number of clock cycles
- DONE: waiting for the user to acknowledge the timer
We will also use counters to keep track of the current delay and count values.
The counting output will be asserted during the COUNTING state.
The done output will be asserted during the DONE state.
The circuit will reset to the IDLE state when the reset signal is high or when the user acknowledges the timer.
