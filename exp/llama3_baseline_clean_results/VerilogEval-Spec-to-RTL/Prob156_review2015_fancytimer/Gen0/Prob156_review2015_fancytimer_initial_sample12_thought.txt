To solve this problem, we need to create a finite state machine (FSM) with several states:
- IDLE: searching for the input pattern 1101
- READ_DELAY: reading the 4-bit delay value
- COUNTING: counting down the delay value
- DONE: notifying the user and waiting for acknowledgement

We will use a counter to keep track of the current count and a shift register to read the delay value. The FSM will transition between states based on the current state and input values.

In the COUNTING state, we will use a counter to count down the delay value, and output the current remaining time. When the count reaches 0, we transition to the DONE state.

In the DONE state, we assert the done signal and wait for the ack signal to be 1 before transitioning back to the IDLE state.
