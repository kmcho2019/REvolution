To implement the TopModule, we need to create a finite state machine (FSM) with the following states:
- IDLE: Wait for the pattern 1101 to be detected.
- SHIFT: Shift in the next 4 bits to determine the duration of the timer delay.
- COUNT: Count for (delay[3:0] + 1) * 1000 clock cycles and output the current remaining time.
- DONE: Assert done to notify the user the timer has timed out and wait for the ack signal.

We will use a counter to keep track of the remaining time and a shift register to shift in the delay bits.

The state machine will transition between states based on the current state and the input signals.
