To solve this problem, we can design a finite state machine (FSM) with multiple states to handle the different phases of the timer. The states can be: 
- IDLE: The initial state, where the FSM is searching for the input pattern 1101.
- SHIFT: After the pattern is detected, the FSM shifts in the next 4 bits to determine the delay duration.
- COUNT: The FSM counts for the specified duration and outputs the remaining time.
- DONE: The FSM asserts the done signal and waits for the ack signal to reset.
We will use a counter to count the clock cycles and a register to store the delay value.
