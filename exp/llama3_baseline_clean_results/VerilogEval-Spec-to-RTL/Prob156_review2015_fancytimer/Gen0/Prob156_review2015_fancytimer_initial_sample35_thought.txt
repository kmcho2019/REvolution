The design will be implemented as a finite state machine (FSM) that transitions through different states based on the input pattern and the current state of the timer. The states can be: 
- IDLE: searching for the input pattern 1101
- SHIFT: shifting in the next 4 bits to determine the delay
- COUNT: counting for the specified number of clock cycles
- DONE: waiting for the user to acknowledge the timer

The FSM will use counters and registers to store the current state, the delay, and the remaining time. The counting output will be asserted during the COUNT state, and the done output will be asserted during the DONE state. The ack input will be used to transition from the DONE state back to the IDLE state.
