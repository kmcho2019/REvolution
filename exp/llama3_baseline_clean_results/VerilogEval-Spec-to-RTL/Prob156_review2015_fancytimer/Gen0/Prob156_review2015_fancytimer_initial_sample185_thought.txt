To implement the timer module, we will use a finite state machine (FSM) with several states: 
- IDLE: The initial state where the FSM searches for the input pattern 1101.
- SHIFT: After detecting the pattern, the FSM shifts in 4 more bits to determine the delay duration.
- COUNT: The FSM counts down the delay for the specified number of clock cycles.
- DONE: The FSM asserts the done signal and waits for the ack signal to reset.
We will use a counter to keep track of the remaining time and another counter to count the clock cycles.
