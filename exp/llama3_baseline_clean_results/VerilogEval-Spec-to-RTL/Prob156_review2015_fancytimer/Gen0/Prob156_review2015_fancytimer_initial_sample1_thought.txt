To implement the TopModule, we can use a finite state machine (FSM) with several states: 
- Idle: searching for the pattern 1101
- Shift: shifting in the next 4 bits after the pattern is detected
- Counting: counting down the timer
- Done: waiting for the acknowledgement from the user
We will use a counter to count the clock cycles during the counting phase. 
The delay[3:0] value will determine the number of times we need to count 1000 cycles.
We will also output the current remaining time by shifting the delay[3:0] value during the counting phase.
