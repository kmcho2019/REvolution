To solve this problem, we need to implement a finite state machine (FSM) with several states: IDLE, PATTERN_DETECT, SHIFT, COUNT, and DONE. 
The IDLE state is the initial state, where the FSM searches for the pattern 1101.
Once the pattern is detected, the FSM transitions to the PATTERN_DETECT state, 
which then shifts into the SHIFT state to read the next 4 bits.
After reading the delay, the FSM enters the COUNT state, where it counts down 
from (delay + 1) * 1000 clock cycles.
When the count reaches 0, the FSM transitions to the DONE state, 
where it asserts the done output and waits for the ack input to be 1 before 
transitioning back to the IDLE state.
We will also use a counter to keep track of the remaining time and 
output it on the count port.
