To solve this problem, we will implement a finite state machine (FSM) with the following states:
1. IDLE: In this state, the FSM searches for the input pattern 1101.
2. DELAY shifting: Once the pattern is detected, the FSM shifts in the next 4 bits to determine the duration of the timer delay.
3. COUNTING: The FSM counts for (delay + 1) * 1000 clock cycles, outputting the remaining time.
4. DONE: After the counting is finished, the FSM asserts the done output and waits for the ack input to be 1.
5. RESET: The FSM resets to the IDLE state when the reset signal is high or the ack input is 1 after the DONE state.

We will use a 4-bit shift register to store the delay value, a 4-bit counter to output the remaining time, and a 12-bit counter to count the total number of clock cycles.
