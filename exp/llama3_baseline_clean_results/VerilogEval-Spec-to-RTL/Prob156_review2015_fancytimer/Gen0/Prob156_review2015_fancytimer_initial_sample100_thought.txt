To solve this problem, we'll design a finite state machine (FSM) with the following states:
- IDLE: search for the pattern 1101
- SHIFT: shift in the next 4 bits to determine the delay
- COUNT: count for (delay + 1) * 1000 clock cycles
- DONE: assert done and wait for ack
- RESET: reset the FSM

We'll use a 4-bit shift register to store the delay value and a 20-bit counter to count the clock cycles. The current remaining time will be displayed on the count output.
