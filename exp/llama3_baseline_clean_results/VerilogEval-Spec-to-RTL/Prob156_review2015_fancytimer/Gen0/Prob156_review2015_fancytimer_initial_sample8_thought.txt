To solve this problem, we can design a finite state machine (FSM) with the following states:
- IDLE: This state is responsible for searching for the input pattern 1101.
- DELAY_READ: After detecting the 1101 pattern, this state shifts in the next 4 bits to determine the delay duration.
- COUNTING: This state asserts the counting output and counts down the delay duration.
- DONE: After the counting is finished, this state asserts the done output and waits for the ack input to be 1.
We will use a counter to count the delay duration and a separate counter to keep track of the remaining time.

We will also need to use a shift register to shift in the delay bits after the 1101 pattern is detected.

The output 'count' will be used to display the remaining time.
