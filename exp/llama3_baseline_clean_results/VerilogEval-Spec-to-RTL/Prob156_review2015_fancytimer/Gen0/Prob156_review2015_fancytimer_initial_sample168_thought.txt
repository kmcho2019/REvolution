The module TopModule will be implemented using a finite state machine (FSM) with several states:
- Idle: searching for the start sequence (1101)
- Shift: shifting in the next 4 bits to determine the duration
- Counting: counting for the specified duration
- Done: notifying the user that the timer has timed out and waiting for acknowledgment
The FSM will transition between these states based on the input pattern, the current state, and the acknowledgment signal.

To implement the counting functionality, a counter will be used to keep track of the remaining time. The counter will be decremented every clock cycle, and when it reaches zero, the counting state will be exited.

The done signal will be asserted when the counting is finished, and the FSM will wait for the acknowledgment signal (ack) to be high before resetting to the idle state.
