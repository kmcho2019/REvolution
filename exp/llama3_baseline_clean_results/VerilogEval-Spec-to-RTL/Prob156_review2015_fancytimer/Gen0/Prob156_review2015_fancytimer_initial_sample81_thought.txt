The TopModule should implement a finite state machine with several states: 
IDLE, SHIFT_PATTERN, SHIFT_DELAY, COUNTING, and DONE. 
In the IDLE state, the module searches for the input pattern 1101. 
Once the pattern is detected, it transitions to the SHIFT_DELAY state, 
where it shifts in the next 4 bits to determine the duration of the timer delay. 
After that, it transitions to the COUNTING state, where it counts for exactly 
(delay[3:0] + 1) * 1000 clock cycles. 
Once the counting is finished, it transitions to the DONE state, 
where it asserts the done output and waits for the user to acknowledge the timer. 
The module can be reset to the IDLE state at any time using the reset signal.
The current remaining time should be output on the count output during the COUNTING state.
