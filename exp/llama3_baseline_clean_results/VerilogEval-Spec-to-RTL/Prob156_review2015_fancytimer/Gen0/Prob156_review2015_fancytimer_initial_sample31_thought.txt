To implement the TopModule, we will use a finite state machine (FSM) with several states:
- IDLE: searching for the input pattern 1101
- SHIFT_DELAY: shifting in the 4-bit delay value after detecting the pattern
- COUNTING: counting down the specified delay
- DONE: waiting for the ack signal after the timer has timed out

We will use a counter to keep track of the remaining time and a register to store the delay value.
The FSM will transition between states based on the input pattern, delay value, and ack signal.
The counting output will be asserted during the COUNTING state, and the done output will be asserted during the DONE state.
The count output will display the remaining time during the COUNTING state.
