The TopModule will be implemented using a finite state machine (FSM) with several states: 
- IDLE: searching for the pattern 1101
- SHIFT: shifting in the 4 bits for the delay after detecting the pattern
- COUNT: counting down the delay
- DONE: notifying the user that the timer has timed out and waiting for acknowledgement
The state machine will transition between these states based on the current state and input signals.
We will use a 4-bit register to store the delay and a 12-bit counter to count the total number of clock cycles.
The count output will be generated based on the current delay.
