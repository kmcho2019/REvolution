The module TopModule will implement a finite state machine to control the timer. The states are: idle, start_sequence, shifting, counting, and done. In the idle state, the module checks for the start sequence (1101) on the data input. Once the sequence is detected, it transitions to the start_sequence state. In this state, it shifts in the next 4 bits to determine the duration of the timer delay. After shifting, it transitions to the counting state. In the counting state, it counts for exactly (delay[3:0] + 1) * 1000 clock cycles and outputs the current remaining time. Once the count is finished, it transitions to the done state. In the done state, it asserts the done signal and waits for the ack signal to be asserted before transitioning back to the idle state.
