To implement the TopModule, we need to design a finite state machine (FSM) that can detect the input pattern 1101, shift in the duration bits, count down the delay, and notify the user when the timer is done. The FSM will have several states: IDLE (searching for the input pattern), SHIFT (shifting in the duration bits), COUNTING (counting down the delay), and DONE (notifying the user and waiting for acknowledgement). We will use a counter to count down the delay, and a separate counter to keep track of the current remaining time.
