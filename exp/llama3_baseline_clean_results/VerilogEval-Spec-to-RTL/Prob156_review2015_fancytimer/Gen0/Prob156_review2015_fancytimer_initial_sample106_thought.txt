The design will be implemented as a finite state machine (FSM) with several states: IDLE, SHIFT, COUNTING, and DONE. The IDLE state is responsible for detecting the pattern '1101' and transitioning to the SHIFT state. The SHIFT state shifts in 4 more bits to determine the duration of the timer delay. The COUNTING state counts for exactly (delay[3:0] + 1) * 1000 clock cycles and asserts the counting output. The DONE state asserts the done output and waits for the ack input to be asserted before transitioning back to the IDLE state. A counter will be used to keep track of the remaining time.
