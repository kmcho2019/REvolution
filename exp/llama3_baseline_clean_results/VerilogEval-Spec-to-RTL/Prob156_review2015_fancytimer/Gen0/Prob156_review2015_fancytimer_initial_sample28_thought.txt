To solve this problem, we need to design a finite state machine (FSM) with the following states:
- Idle: Search for the input pattern 1101.
- Shift: Shift in the next 4 bits to determine the delay duration.
- Counting: Count for (delay + 1) * 1000 clock cycles.
- Done: Assert done signal and wait for ack.
We will use a counter to keep track of the remaining time and a register to store the delay value.
We will also use a 4-bit counter to output the current remaining time.
