To implement a 2-1 multiplexer in Verilog, we can use a conditional statement to assign the output 'out' based on the value of the select line 'sel'. If 'sel' is 0, we assign 'a' to 'out', and if 'sel' is 1, we assign 'b' to 'out'. This can be achieved using the ternary operator or an if-else statement.
