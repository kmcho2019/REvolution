To implement a 2-1 multiplexer in Verilog, we can use the conditional operator to select between the two input signals 'a' and 'b' based on the 'sel' signal. The output 'out' will be assigned the value of 'a' when 'sel' is 0, and the value of 'b' when 'sel' is 1. This can be done bit-wise for the 100-bit wide inputs.
