To implement a 2-1 multiplexer in Verilog, we can use the ternary operator (?:) which allows for a compact conditional assignment based on the value of 'sel'. The idea is to assign the value of 'a' to 'out' when 'sel' is 0, and the value of 'b' to 'out' when 'sel' is 1. This can be achieved with a single statement using the ternary operator, making the code concise and easy to understand.
