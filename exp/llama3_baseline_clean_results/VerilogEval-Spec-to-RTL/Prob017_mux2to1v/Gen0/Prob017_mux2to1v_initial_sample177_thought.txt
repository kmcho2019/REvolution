To implement a 2-1 multiplexer in Verilog, we can use a simple conditional statement based on the value of the select line (sel). If sel is 0, we assign the value of input 'a' to the output 'out'. If sel is 1, we assign the value of input 'b' to the output 'out'. This can be achieved using the ternary operator in Verilog, which is a shorthand for if-else statements. The ternary operator syntax is `condition ? true_value : false_value`.
