The TopModule will be designed with a 4-bit shift register. It will have an asynchronous reset (areset) that resets the shift register to zero. The module will have two synchronous inputs: load and ena. If load is high, the shift register will be loaded with the data input. If ena is high, the shift register will shift right, with q[3] becoming zero and q[0] being shifted out. The load input will have priority over the ena input. This means that if both load and ena are high, the shift register will be loaded with the data input instead of shifting.
