To implement the TopModule as described, we need to consider the asynchronous reset (areset), the load functionality, and the shift functionality. The asynchronous reset should clear the shift register to zero immediately upon assertion, regardless of the clock. The load functionality should update the shift register with the provided data when the load signal is high at the positive edge of the clock. The shift functionality should shift the contents of the register to the right when the enable signal is high at the positive edge of the clock. If both load and enable are asserted at the same time, the load operation should take priority. This can be achieved by using an if-else statement in the always block that checks for the load condition first. The shift operation should move each bit one position to the right, filling the leftmost position with a zero.
