The TopModule should implement a 4-bit shift register with the specified interface. 
The module will have the following functionality: 
- The shift register should be reset to zero when the areset signal is asserted.
- When the load signal is asserted, the shift register should be loaded with the data[3:0] instead of shifting.
- When the ena signal is asserted, the shift register should shift right, with q[3] becoming zero, and q[0] being shifted out.
- The load input should have higher priority than the ena input when both are asserted.
This functionality can be achieved using an always block in Verilog, which should be sensitive to the positive edge of the clock signal.
