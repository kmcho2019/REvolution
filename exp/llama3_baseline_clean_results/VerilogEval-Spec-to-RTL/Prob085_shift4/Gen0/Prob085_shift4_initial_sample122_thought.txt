The shift register should be able to reset asynchronously, load data synchronously, and shift data to the right synchronously. We will use a combination of conditional statements and always blocks to achieve the desired behavior. When areset is asserted, the shift register should reset to zero immediately. When load is asserted, the shift register should load the data from the input port. When ena is asserted and load is not asserted, the shift register should shift the data to the right.
