The TopModule will contain a 4-bit shift register with asynchronous reset. 
The load input will have priority over the enable input. 
The shift register will be implemented using a 4-bit reg type in Verilog.
To achieve the desired functionality, we will use an always block with 
an if-else condition that checks the load and enable inputs. If the load 
input is high, the shift register will be loaded with the data input. 
If the load input is low and the enable input is high, the shift register 
will be shifted right by one bit, with the leftmost bit becoming zero and 
the rightmost bit being discarded.
