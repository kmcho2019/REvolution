To implement the TopModule, we will use a 4-bit reg type to store the shift register's state. 
We will first check for the asynchronous reset condition. 
Inside the always block, we will check for the load signal. 
If load is high, we will load the data into the shift register. 
If load is low and ena is high, we will perform the shift right operation. 
If neither load nor ena is high, the shift register will retain its previous state.
