To implement the TopModule, we need to factor out the common functionality of a flip-flop with a 2:1 multiplexer from the full_module. The flip-flop should store the input q_in when the clock clk is high, and the 2:1 multiplexer should select between the input r_in and the output of the flip-flop based on the load signal L. The output Q of the TopModule should be the output of the flip-flop.
