To factor the full_module into a hierarchical design, we need to create a submodule "TopModule" that can be instantiated three times. This submodule should contain a flip-flop and a 2:1 multiplexer. The flip-flop should be capable of being loaded from an input when a load signal is asserted, and the multiplexer should select between the loaded input and the output of the flip-flop when the load signal is not asserted. The multiplexer's second input will come from the next submodule's output, so we need to provide an output port for it as well.
