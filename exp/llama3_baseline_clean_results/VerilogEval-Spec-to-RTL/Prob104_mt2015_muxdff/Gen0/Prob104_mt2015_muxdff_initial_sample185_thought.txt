The "full_module" has three flip-flops that can be loaded from "r" when "L" is asserted. 
When "L" is not asserted, the flip-flops are updated based on their current values. 
We can achieve this by creating a "TopModule" that contains a 2:1 multiplexer and a flip-flop.
The 2:1 multiplexer will select either the input "q_in" or the input "r_in" based on the load signal "L".

The output "Q" will be the current value of the flip-flop.
