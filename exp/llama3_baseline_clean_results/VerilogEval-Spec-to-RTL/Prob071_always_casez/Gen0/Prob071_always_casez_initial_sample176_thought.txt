To implement the priority encoder, we can use a simple and efficient approach by using a for loop to iterate through the input bits from least significant to most significant. As soon as we encounter a bit that is high (1), we immediately assign the corresponding position to the output and break out of the loop. If no bits are high, the output will default to 0. We can use the $clog2 function to determine the number of bits required to represent the output, which in this case is 3.
