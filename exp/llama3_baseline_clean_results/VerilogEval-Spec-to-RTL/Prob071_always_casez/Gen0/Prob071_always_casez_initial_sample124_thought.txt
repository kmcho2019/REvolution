To solve this problem, we can use a priority encoder design. The idea is to check each bit of the input vector from least significant bit (LSB) to most significant bit (MSB) and output the position of the first bit that is high. If no bit is high, output 0. We can achieve this using a series of if-else statements or a case statement in Verilog. However, a more efficient approach would be to use a loop to check each bit and output the position as soon as a high bit is found.
