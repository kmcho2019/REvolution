The priority encoder can be implemented using a simple combinational logic. We will iterate over the input bits from the least significant bit (LSB) to the most significant bit (MSB). As soon as we find a bit that is high, we will output the corresponding position. If no bit is found to be high, we will output 0.

We can use a loop to iterate over the input bits and use a conditional statement to check if a bit is high. If a bit is high, we will set the output to the corresponding position and break out of the loop.

We can use the $display function to print the output for testing purposes, but for a real design, this would be connected to the pos output port.
