The idea is to check the input bits from least significant to most significant and output the position of the first bit that is high. We can achieve this using a series of conditional statements or using a loop to iterate over the input bits. The output will be a 3-bit vector representing the position of the first high bit, with the least significant bit (LSB) being the first bit checked.
