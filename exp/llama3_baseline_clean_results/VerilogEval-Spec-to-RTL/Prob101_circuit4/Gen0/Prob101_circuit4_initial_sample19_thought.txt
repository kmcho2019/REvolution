The module TopModule implements a combinational circuit that outputs 1 
when either b or c (or both) are 1, regardless of the values of a and d. 
However, when a is 1 and both b and c are 0, the circuit should output 1 
if and only if d is 0, but this condition is never met in the given 
simulation waveforms because q is 0 when a is 1 and both b and c are 0. 
Hence, we can simplify this to just check when a, b, or c are 1.
