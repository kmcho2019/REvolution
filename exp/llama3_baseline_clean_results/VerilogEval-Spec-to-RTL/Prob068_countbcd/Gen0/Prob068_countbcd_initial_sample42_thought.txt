To implement the 4-digit BCD counter, we will create a 16-bit register `q` to store the current count. We will also create a 3-bit register `ena` to store the enable signals for the upper three digits. On each positive clock edge, we will check if the current count has reached the maximum value for each digit (9 for the lower three digits, 9 for the upper digit as well but it will wrap around after reaching 9). If it has, we will increment the next digit and reset the current digit to 0. We will also set the corresponding enable signal to 1. If the current count is not at the maximum value, we will simply increment the current digit. We will also implement a synchronous active-high reset that will reset all registers to 0 when `reset` is high.
