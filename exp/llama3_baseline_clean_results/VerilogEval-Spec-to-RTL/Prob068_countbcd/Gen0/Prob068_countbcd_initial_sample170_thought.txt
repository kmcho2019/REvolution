To implement the 4-digit BCD counter, we can use a hierarchical approach where each digit is a separate 4-bit BCD counter. We will start by designing a single 4-bit BCD counter. This counter should be able to count from 0 to 9, wrapping around to 0 when it reaches 10. 

For the TopModule, we will instantiate four of these counters, connecting their outputs to the q output. The enable signals for each digit will be generated based on whether the current digit needs to be incremented or not.

When the ones digit reaches 9 and the next clock cycle occurs, we need to reset the ones digit to 0 and enable the tens digit to be incremented. This process continues for the hundreds and thousands digits.

We will also implement a synchronous active-high reset to reset the counters to 0 when the reset signal is high.
