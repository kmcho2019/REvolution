To implement a 4-digit BCD counter, we can use four 4-bit counters in series. 
Each counter will be incremented when it reaches its maximum value (9 in BCD) 
and the next counter in the sequence will be enabled to increment. 
We will use a 3-bit enable signal to indicate which of the upper three digits 
should be incremented. 
The ones digit will be incremented on every clock cycle. 
When the ones digit reaches 9, it will wrap around to 0 and the tens digit 
will be incremented. This process will continue for the hundreds and thousands 
digits. 
We will use a synchronous active-high reset to clear the counter to 0 when reset is high.
