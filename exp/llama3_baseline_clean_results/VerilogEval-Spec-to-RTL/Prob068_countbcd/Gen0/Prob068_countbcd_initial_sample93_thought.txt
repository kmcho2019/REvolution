To implement a 4-digit BCD counter, we first need to design a basic BCD counter for a single digit, which counts from 0 to 9. Then, we can expand this to four digits. The enable signal for each digit will be asserted when the current digit rolls over (i.e., goes from 9 back to 0), which is the condition for the next digit to be incremented. For the ones place, we always enable the counter on every clock cycle. For the higher digits, the enable signal will propagate from the lower digits.

We will use a synchronous reset to reset the counter to 0 when the reset signal is high. All logic will be triggered on the positive edge of the clock, which means we will use non-blocking assignments (`<=`) to update the state of our counters and enable signals.
