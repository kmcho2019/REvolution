The TopModule should contain a 4-digit BCD counter with enable signals for each upper digit. We'll implement the counter using four 4-bit registers, each representing a decimal digit. The ones digit (q[3:0]) will be incremented on every clock cycle, and when it overflows (i.e., reaches 9), it will trigger the enable signal for the tens digit (ena[0]). The same logic will apply to the tens, hundreds, and thousands digits. We'll also include a synchronous active-high reset to clear the counter and enable signals.
