To implement the 4-digit BCD counter, we can use separate counters for each digit. The ones digit will be incremented on every clock cycle, while the tens, hundreds, and thousands digits will only be incremented when the previous digit wraps around from 9 to 0. We can generate the enable signals for the upper three digits by checking when the current digit is equal to 9. The synchronous active-high reset will be used to reset all digits to 0 when the reset signal is high.
