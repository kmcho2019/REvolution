The TopModule will implement a 4-digit BCD counter. We will use a combination of sequential logic and combinational logic to generate the output enable signals for the upper three digits. On each positive edge of the clock, we will check if the current digit needs to be incremented or wrapped around to 0. If the ones digit overflows, we will set the enable signal for the tens digit and so on. We will use a synchronous active-high reset to reset the counter to 0 when the reset signal is high.
