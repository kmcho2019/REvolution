To implement a 4-digit BCD counter, we will need to keep track of each digit individually and increment them accordingly. We can do this by using a separate 4-bit register for each digit. When the ones digit reaches 9, it should reset to 0 and the tens digit should be incremented. This process should continue for each digit. The enable signals for the upper three digits will be asserted when the corresponding digit should be incremented. The counter should also have a synchronous active-high reset that resets all digits to 0.
