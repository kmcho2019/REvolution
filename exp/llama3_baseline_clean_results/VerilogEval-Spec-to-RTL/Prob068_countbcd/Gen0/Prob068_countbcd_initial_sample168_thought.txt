To implement the TopModule, we need to design a 4-digit BCD counter. 
The counter should have four 4-bit segments: ones, tens, hundreds, and thousands. 
Each segment should be able to count from 0 to 9. When a segment reaches 10, it should reset to 0 and the next segment should be incremented.
We will use a synchronous active-high reset to reset the counter to 0 when the reset signal is high.
We will also output an enable signal for each of the upper three digits to indicate when they should be incremented.
