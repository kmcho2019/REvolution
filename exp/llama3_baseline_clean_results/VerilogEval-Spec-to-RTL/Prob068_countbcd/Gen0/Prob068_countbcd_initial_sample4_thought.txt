We'll use a 4-stage counter, with each stage representing a digit in the BCD number. For the ones digit, we'll count from 0 to 9. When the ones digit reaches 9, it should reset to 0 and the tens digit should increment. This pattern continues for the hundreds and thousands digits.

The enable signals (ena) are used to indicate when each of the upper three digits should be incremented. The logic for these signals can be derived from the values of the digits. For example, the tens digit should increment when the ones digit wraps around from 9 to 0, which happens when q[3:0] is 9.
