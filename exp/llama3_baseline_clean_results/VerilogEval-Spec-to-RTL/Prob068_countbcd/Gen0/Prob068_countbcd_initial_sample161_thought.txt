To implement the 4-digit BCD counter, we will use four separate counters for each digit. 
Each counter will be a 4-bit binary counter, and we will implement the logic to handle the 
BCD rollover from 9 to 0 for each digit. We will also generate the enable signals based on 
the count of the lower digits. When the ones digit is 9, we generate an enable signal for 
the tens digit. Similarly, when the tens digit is 9 and the ones digit is 9, we generate an 
enable signal for the hundreds digit, and so on. We will use a synchronous active-high reset 
to reset all the counters and enable signals to zero.
