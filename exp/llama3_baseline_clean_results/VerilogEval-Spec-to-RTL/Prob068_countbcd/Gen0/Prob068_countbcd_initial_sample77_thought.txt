To implement the 4-digit BCD counter, we can use a hierarchical approach. 
We'll create a module for a single BCD digit (0-9) and then instantiate 
four of these modules in the TopModule. Each BCD digit module will have 
an enable input, a clock input, a reset input, and a 4-bit output. 
When the enable input is high, the digit will increment on the next 
positive clock edge if the current value is less than 9; otherwise, it 
will reset to 0. In the TopModule, we'll have a single enable signal 
that is always high for the ones digit and is only high for the upper 
digits when the current value of the digit below it overflows (i.e., 
when the ones digit reaches 9, the tens digit should increment, and so 
on). The ena output will be used to indicate when each upper digit 
should be incremented. 
We'll also include a synchronous active-high reset to reset all digits 
to 0 when reset is asserted high.
