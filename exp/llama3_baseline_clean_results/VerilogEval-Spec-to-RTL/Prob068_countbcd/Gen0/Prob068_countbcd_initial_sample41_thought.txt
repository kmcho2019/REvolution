We will use four 4-bit counters for each digit. 
When the ones digit (q[3:0]) reaches 9, it should be reset to 0 and the tens digit (q[7:4]) should be incremented. 
Similarly, when the tens digit reaches 9, it should be reset to 0 and the hundreds digit (q[11:8]) should be incremented. 
The same applies to the thousands digit (q[15:12]). 
We will use enable signals (ena[2:0]) to control when each of the upper three digits should be incremented.
The module should also have a synchronous active-high reset that resets all counters to 0 when asserted.
