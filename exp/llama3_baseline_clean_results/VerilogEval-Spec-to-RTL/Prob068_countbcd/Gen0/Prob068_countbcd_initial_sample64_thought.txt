To implement a 4-digit BCD counter, we first need to define the counter logic. The counter should increment the ones digit (q[3:0]) every clock cycle. When the ones digit reaches 9, it should reset to 0 and increment the tens digit (q[7:4]). Similarly, when the tens digit reaches 9, it should reset to 0 and increment the hundreds digit (q[11:8]), and so on for the thousands digit (q[15:12]).

We also need to generate the enable signals (ena) for the upper three digits. The enable signal for each digit should be high when the digit should be incremented, which is when the lower digits have reached 9.

Finally, we need to implement the synchronous active-high reset. When the reset signal is high, the counter should reset to 0, and the enable signals should be set to 0.
