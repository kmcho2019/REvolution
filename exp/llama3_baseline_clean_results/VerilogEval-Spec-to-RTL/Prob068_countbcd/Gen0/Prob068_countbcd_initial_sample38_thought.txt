To implement a 4-digit BCD counter, we first need to understand how BCD counting works. Each digit is encoded in 4 bits, representing values from 0 to 9. We will use a separate 4-bit register for each of the four digits. 

The counting process starts from the ones digit. When the ones digit reaches 9, it resets to 0 and the tens digit is incremented. The same process applies to the hundreds and thousands digits. 

To implement the enable signals for the upper three digits, we need to identify when each digit should be incremented. This happens when the lower digits have reached 9.

The synchronous active-high reset will reset all digits to 0 when asserted.

In Verilog, we can implement this using a combination of if-else statements to handle the counting logic and the enable signals. We will use non-blocking assignments to update the register values.
