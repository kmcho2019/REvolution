To implement the 4-digit BCD counter, we need to use a sequential logic approach with an active-high reset. We will initialize the counter values to zero on reset. On each positive clock edge, we will check the current value of each digit. If any digit is less than 9, it should be incremented. If any digit is equal to 9, it should wrap around to 0 and enable the next digit to be incremented. The enable signals for each digit (ena[2:0]) will be set to 1 when the corresponding digit should be incremented, and 0 otherwise. The ones digit (q[3:0]) will always be incremented unless the entire counter has reached its maximum value (9999).
