To implement the 4-digit BCD counter, we will use four 4-bit counters in a hierarchical structure. Each counter will be responsible for a different decimal digit (ones, tens, hundreds, thousands). 
The enable signals for the upper three digits will be generated based on the current state of the lower digits. 
For example, the tens digit should be incremented when the ones digit wraps around from 9 to 0, which can be detected by checking the ones digit's current value and the enable signal of the ones digit.
We will also include a synchronous active-high reset to reset the counter to its initial state (all zeros).
All sequential logic will be triggered on the positive edge of the clock.
