The TopModule should contain four 4-bit BCD counters, one for each digit. 
Each counter should be reset to 0 on the active-high reset signal. 
The counters should be incremented on the positive edge of the clock signal. 
For the ones digit, it should be incremented every clock cycle. 
For the tens, hundreds, and thousands digits, they should be incremented 
when the lower digits overflow (i.e., when the ones digit reaches 9, 
the tens digit should be incremented and the ones digit reset to 0, 
and so on). 
The enable signals for the upper three digits should be asserted 
when the corresponding digit is incremented. 
This can be achieved by using a combination of counters, comparators, 
and logic gates.
