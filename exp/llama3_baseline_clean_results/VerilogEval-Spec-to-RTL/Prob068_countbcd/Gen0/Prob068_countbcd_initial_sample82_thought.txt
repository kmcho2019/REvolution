To implement the 4-digit BCD counter, we can use four 4-bit binary counters, 
each representing a decimal digit. We need to enable the increment of each 
digit based on the value of the previous digits. The ones digit should 
always be incremented on every clock cycle. When the ones digit reaches 9, 
it should wrap around to 0 and the tens digit should be incremented. This 
logic should be applied to all digits. The enable signals for each digit 
should be set based on the current value of the previous digits. A 
synchronous active-high reset should be implemented to reset the counter to 
0. The output q should be a 16-bit bus, with each 4-bit group representing 
a decimal digit. The output ena should be a 3-bit bus, with each bit 
representing the enable signal for the tens, hundreds, and thousands digits.
