To implement the 4-digit BCD counter, we will use four 4-bit binary counters. 
We will implement the counter using a set of always blocks that increment 
the counters based on a set of conditional statements. 
The ones digit will increment on every clock cycle. 
The tens digit will increment when the ones digit wraps around to zero.
The hundreds digit will increment when the tens and ones digits both wrap around to zero.
The thousands digit will increment when the hundreds, tens, and ones digits all wrap around to zero.
The enable signals for the upper three digits will be asserted when the current digit is zero and the previous digit is also zero.
