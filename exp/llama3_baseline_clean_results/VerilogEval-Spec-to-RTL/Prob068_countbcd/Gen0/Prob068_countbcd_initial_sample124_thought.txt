To implement the 4-digit BCD counter, we will use four 4-bit counters. 
Each counter will represent one decimal digit (ones, tens, hundreds, thousands). 
We'll use a separate counter for each digit and enable the next digit's 
counter only when the current digit's counter reaches 9 (since BCD counts 
from 0 to 9). The enable signals for the upper three digits will be set 
when the corresponding lower digit counter reaches 9. When the reset is 
asserted, all counters will be reset to 0.
