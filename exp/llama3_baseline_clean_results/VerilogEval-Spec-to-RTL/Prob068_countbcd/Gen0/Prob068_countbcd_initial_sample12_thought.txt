To implement a 4-digit BCD counter, we can use four 4-bit counters to represent each digit. We'll use a single enable signal to increment the ones digit, and then use the carry-out of each digit to enable the next digit to increment. We'll also include a synchronous active-high reset to clear the counters to zero when reset is asserted. The enable signals for the upper three digits will be generated based on the carry-out of the previous digit.
