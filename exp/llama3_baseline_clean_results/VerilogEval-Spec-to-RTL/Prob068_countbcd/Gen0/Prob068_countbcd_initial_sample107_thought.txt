To implement the 4-digit BCD counter, we can use four 4-bit counters to represent each digit. We'll start with the ones digit and then use the enable signal to increment the tens, hundreds, and thousands digits when necessary. The enable signal for each digit will be asserted when the current digit reaches 9 (the maximum BCD value) and the next clock cycle occurs. When the reset signal is asserted, all counters will be reset to 0. We'll use a synchronous reset to ensure that the reset occurs on the positive edge of the clock.
