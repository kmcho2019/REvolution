To implement the TopModule, we will use 8 D flip-flops (DFFs) since we have 8-bit input and output. Each DFF will be triggered by the positive edge of the clock signal. We can use the built-in Verilog DFF module, but in this case, we will define it using the behavioral modeling style for better understanding. The input d will be connected to the D inputs of the DFFs and the outputs of the DFFs will be connected to the output q.
