The TopModule will be designed as a 100-bit left/right rotator with synchronous load and enable. The module will have a 100-bit register to hold the current state of the rotator. On every clock cycle, the module will check the load signal. If the load signal is high, the module will load the data into the register. If the load signal is low, the module will check the ena signal to determine the direction of rotation. If ena is 2'b01, the module will rotate the register to the right by one bit. If ena is 2'b10, the module will rotate the register to the left by one bit. If ena is 2'b00 or 2'b11, the module will not rotate the register.
