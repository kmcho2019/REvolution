To implement the 100-bit left/right rotator, we need to create a module that can perform the following operations:
- Load the input data into the rotator when the load signal is high.
- Rotate the bits in the rotator to the right by one position when ena[1:0] is 2'b01.
- Rotate the bits in the rotator to the left by one position when ena[1:0] is 2'b10.
- Do not rotate the bits when ena[1:0] is 2'b00 or 2'b11.
We will use a 100-bit reg to store the current state of the rotator, and use always blocks to handle the loading and rotation operations.
