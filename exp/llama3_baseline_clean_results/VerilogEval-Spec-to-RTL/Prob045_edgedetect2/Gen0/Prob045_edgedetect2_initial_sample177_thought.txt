To detect any edge (both rising and falling) on an input signal, we can store the previous value of the input signal and compare it with the current value. If the current value is different from the previous value, we have detected an edge. We will implement this logic for each bit of the 8-bit input vector.

We will use a D flip-flop to store the previous value of the input signal. On the positive edge of the clock, the D flip-flop will capture the current value of the input signal. Then, we can compare the captured value (previous value) with the current value of the input signal to detect any edge.

The detection of an edge will be done using an XOR operation between the current and previous values of the input signal. If the XOR result is 1, it means an edge has been detected, and we will set the corresponding output bit to 1.
