To detect any edge (0 to 1 or 1 to 0 transition) in an 8-bit input vector, 
we can use a simple sequential logic approach. For each bit in the input 
vector, we will store its previous state in a register. On every positive 
edge of the clock, we will compare the current state of the bit with its 
previous state. If the current state is different from the previous state, 
we set the corresponding output bit to 1. Otherwise, we set it to 0. 
This comparison and output assignment will be done in the next clock cycle 
after the transition occurs.

edge detection logic for each bit. Since the problem statement asks for
