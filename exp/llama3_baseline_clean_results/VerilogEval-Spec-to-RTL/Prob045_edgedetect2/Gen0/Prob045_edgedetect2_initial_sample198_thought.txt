To detect any edge in an 8-bit input vector, we can use a simple sequential logic approach. We will store the previous value of the input vector in a register, and on each clock cycle, compare it with the current value of the input vector. If any bit has changed, we set the corresponding output bit to 1. We use a register to store the previous value because we are working with sequential logic that is triggered on the positive edge of the clock, allowing us to capture the state of the input vector at the previous clock cycle.
