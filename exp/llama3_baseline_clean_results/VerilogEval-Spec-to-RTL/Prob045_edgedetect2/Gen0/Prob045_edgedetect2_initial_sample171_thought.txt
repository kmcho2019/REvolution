To detect any edge in an 8-bit input vector, we need to compare each bit of the current input vector with the corresponding bit of the previous input vector. If a bit has changed (either from 0 to 1 or 1 to 0), we set the corresponding output bit to 1. This requires us to store the previous input vector. We can do this using a register. The new output will be calculated based on the current input and the stored previous input, and then the current input will be stored for the next clock cycle.
