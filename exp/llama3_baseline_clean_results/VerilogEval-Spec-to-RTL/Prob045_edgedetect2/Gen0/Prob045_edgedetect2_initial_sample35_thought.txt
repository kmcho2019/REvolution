To detect any edge in the input signal, we need to store the previous value of the input signal and compare it with the current value. We can use a register to store the previous value, which will be updated on each positive edge of the clock. We then compare the previous value with the current value to detect any transition (0 to 1 or 1 to 0). If a transition is detected, we set the corresponding output bit to 1. We use a simple combinational logic (XOR operation) to detect the transition.
