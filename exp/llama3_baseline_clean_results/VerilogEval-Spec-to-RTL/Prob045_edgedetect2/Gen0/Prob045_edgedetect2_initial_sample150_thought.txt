To detect any edge (0 to 1 or 1 to 0 transition) for each bit in the input vector, we need to store the previous state of the input vector and compare it with the current state on every clock cycle. We can use a flip-flop to store the previous state. For each bit, we then use an XOR operation to detect a transition between the current and previous state, as XOR returns 1 when its inputs are different (i.e., a transition has occurred). This detection is performed within a combinatorial logic block and its output is then registered to be updated at the next clock cycle, thus setting the output bit to 1 the cycle after the transition occurs.
