To implement the TopModule, we will use a simple edge detection mechanism. 
We will store the previous state of the input signal in a register, and 
then compare it with the current state. If the current state is different 
from the previous state, we will set the corresponding output bit to 1. 
This will be done for each bit of the 8-bit input vector.

We will use a always block to describe the sequential logic. Inside the 
always block, we will first store the current state of the input signal 
in a register. Then we will compare the current state with the previous 
state, and set the output bits accordingly.

We will also use a reg variable to store the previous state of the input 
signal. This reg variable will be updated at the end of the always block, 
so that it can store the current state for the next clock cycle.
