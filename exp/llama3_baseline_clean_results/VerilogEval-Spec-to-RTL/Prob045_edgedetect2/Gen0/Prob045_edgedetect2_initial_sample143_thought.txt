To detect any edge in the input signal, we need to compare the current input with the previous input. This can be achieved by storing the previous input in a register and then comparing it with the current input. We will use a flip-flop to store the previous input. In the next clock cycle, we compare the current input with the stored previous input. If there is a difference, we set the corresponding output bit to 1. This way, we can detect both 0 to 1 and 1 to 0 transitions.
