To detect any edge in the input signal, we need to store the previous value of the input signal and compare it with the current value. We can achieve this by using a register to hold the previous input value. On the positive edge of the clock, we will update the register with the current input value, and at the same time, compare the current input value with the previous value stored in the register. If a difference is detected, it means an edge has occurred, and we will set the corresponding output bit to 1.
