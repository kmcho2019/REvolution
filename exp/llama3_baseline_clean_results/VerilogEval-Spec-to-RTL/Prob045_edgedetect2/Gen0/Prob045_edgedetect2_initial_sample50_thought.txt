To implement the TopModule, we need to keep track of the previous state of each input bit. We can do this by using 8 D-flip flops to store the previous state of each input bit. On each positive edge of the clock, we compare the current input bit with its previous state. If there's a change, we set the corresponding output bit to 1, otherwise, we set it to 0. We can use a simple XOR operation to detect the change.
