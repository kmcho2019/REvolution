To detect any edge (either rising or falling) in the input vector, we can use a simple D flip-flop to store the previous state of the input and then compare it with the current state. If the two states are different, we set the corresponding output bit to 1. We will use a reg type to store the previous state of the input. The comparison can be done using an XOR operation since XOR of two bits is 1 only when they are different.
