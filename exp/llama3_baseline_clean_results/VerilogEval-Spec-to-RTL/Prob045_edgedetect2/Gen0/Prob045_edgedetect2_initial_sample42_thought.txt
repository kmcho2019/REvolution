To detect any edge in the input signal, we need to store the previous state of the input signal and compare it with the current state. We can use a register to store the previous state. On the rising edge of the clock, we update the register with the current state of the input signal. Then, we compare the current state of the input signal with the previous state stored in the register. If they are different, we set the corresponding output bit to 1. Otherwise, we set it to 0.
