To detect any edge (0 to 1 or 1 to 0 transition) for each bit in the 8-bit input vector, we will use a combination of sequential logic (to store the previous state of the input) and combinational logic (to compare the current and previous states). We will use a D Flip-Flop (DFF) to store the previous state of each bit of the input. The current state of each bit will be compared with the previous state, and if there is a difference, it means an edge has occurred, so we set the corresponding output bit to 1. This comparison and setting of the output will be done using combinational logic. Since the output should be set the cycle after the edge occurs, the detected edge will be registered by another DFF before being output.
