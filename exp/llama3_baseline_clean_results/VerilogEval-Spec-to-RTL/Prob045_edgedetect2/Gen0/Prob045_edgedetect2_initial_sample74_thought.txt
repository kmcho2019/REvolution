To detect any edge on an 8-bit input vector, we can use a simple sequential logic. 
We will store the previous state of the input vector in a register. 
At each clock cycle, we compare the current input vector with the previous state. 
If a bit in the current input vector is different from the corresponding bit in the previous state, 
we set the corresponding bit in the output vector to 1. 
We then update the previous state register with the current input vector for the next clock cycle.
