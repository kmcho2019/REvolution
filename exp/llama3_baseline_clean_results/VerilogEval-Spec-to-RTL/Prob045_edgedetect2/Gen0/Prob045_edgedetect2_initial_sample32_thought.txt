To detect any edge in the input signal, we need to store the previous value of the input signal and compare it with the current value. We can use a register to store the previous value of the input signal. At each clock cycle, we compare the current input signal with the previous input signal stored in the register. If the current input signal is different from the previous input signal, we set the corresponding output bit to 1. After the comparison, we update the register with the current input signal. This process is repeated for each bit of the 8-bit input vector.
