To detect any edge on an 8-bit input vector, we need to compare the current input with the previous input. This comparison can be done by storing the previous input in a register and then performing a bitwise XOR operation between the current input and the stored previous input. The XOR operation will set a bit to 1 whenever there's a transition (0 to 1 or 1 to 0) in the corresponding input bit. This result can then be registered to produce the output in the next clock cycle.
