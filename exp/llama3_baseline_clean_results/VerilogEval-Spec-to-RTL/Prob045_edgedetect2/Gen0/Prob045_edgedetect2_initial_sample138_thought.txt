To detect any edge on the input signal, we need to store the previous value of the input signal and compare it with the current value. If the current value is different from the previous value, it means an edge has occurred. We can use a register to store the previous value of the input signal and update it on every clock cycle. Then, we compare the current input with the stored previous value to detect edges.

Here is the step-by-step approach:
1. Declare a register to store the previous value of the input signal.
2. On every clock cycle, update the register with the current input value (but delayed by one cycle).
3. Compare the current input with the stored previous value to detect edges.
4. If an edge is detected, set the corresponding output bit to 1.
