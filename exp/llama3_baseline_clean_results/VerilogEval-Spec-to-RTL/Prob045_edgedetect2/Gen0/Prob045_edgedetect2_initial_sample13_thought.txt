To detect any edge transition for each bit in the 8-bit input vector, 
we need to store the previous state of the input vector and compare it 
with the current state. If a bit has changed, we set the corresponding 
bit in the output vector to 1 in the next clock cycle. This can be 
achieved using a sequential logic circuit that captures the previous 
state of the input on the positive edge of the clock and compares it 
with the current input on the next positive edge of the clock.
