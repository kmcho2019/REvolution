To implement the decade counter, we will use a 4-bit register to store the current count. We will use a combinational logic block to determine the next state of the counter based on the current state. The counter will start at 1 and count up to 10, then wrap around back to 1. We will use the reset input to reset the counter to 1 when it is high. The counter will only change state on the positive edge of the clock.
