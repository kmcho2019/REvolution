To implement a decade counter in Verilog, we first need to define the counter's state machine. The counter should count from 1 to 10, so it will require 4 bits to represent its current state (since 2^4 = 16, which is more than enough to represent 10 states). We can use a 4-bit register to store the current count. We will also need to define a reset condition that sets the counter back to 1. Since the reset is synchronous and active high, it will be checked on the positive edge of the clock along with the condition to increment the counter. When the counter reaches 10, the next state should loop back to 1 instead of continuing to increment.
