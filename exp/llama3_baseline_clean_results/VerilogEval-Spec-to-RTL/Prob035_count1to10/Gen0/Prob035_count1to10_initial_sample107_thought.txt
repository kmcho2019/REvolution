To implement the decade counter, we need to create a 4-bit counter that counts from 1 to 10. Since we are counting from 1, we don't need to use the typical 0 to 9 range of a 4-bit binary counter. We can use a 4-bit register to hold the current count value. On each positive clock edge, we increment the count until it reaches 10 (binary 1010), then reset it back to 1 (binary 0001) on the next clock edge. The reset input should be checked on each positive clock edge, and if it is high, the counter should be reset to 1.
