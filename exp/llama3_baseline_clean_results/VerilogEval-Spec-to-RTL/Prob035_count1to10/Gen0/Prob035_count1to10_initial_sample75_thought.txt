To implement the decade counter, we will use a finite state machine (FSM) that counts from 1 to 10. We will use a 4-bit register to store the current count. The counter will increment on every positive clock edge until it reaches 10, at which point it will wrap around to 1. The reset input will be used to reset the counter to 1 on the positive clock edge when it is high. We will use a case statement to handle the wrapping around of the counter.
