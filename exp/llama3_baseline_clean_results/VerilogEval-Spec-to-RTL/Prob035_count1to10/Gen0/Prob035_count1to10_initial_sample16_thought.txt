To implement the decade counter, we can use a 4-bit register to store the count value. We will use a synchronous reset to reset the counter to 1 when the reset signal is high. On each positive clock edge, we will increment the count value if it is less than 10. If the count value is already 10, we will wrap it around to 1 on the next clock edge. This ensures that the counter counts from 1 to 10 inclusively.
