To implement the decade counter, we can use a 4-bit binary counter, 
but we need to modify it to count from 1 to 10 instead of the usual 0 to 15. 
We can achieve this by adding a reset value of 1 and using a conditional 
statement to stop the counter when it reaches 10 (binary 1010). 
We will use a variable, let's call it 'count', to store the current count value. 
On every positive edge of the clock, we will increment the 'count' variable 
unless it has reached 10. When the reset signal is high, the 'count' variable 
will be reset to 1.
