To implement the decade counter, we will use a 4-bit binary counter that counts from 1 to 10. Since the counter is 4 bits, it can count from 0 to 15. However, we only want to count from 1 to 10. We will use a 4-bit register to store the current count. On every positive edge of the clock, the current count will be incremented by 1, unless it reaches 10, in which case it will be reset to 1. We also need to handle the reset input, which should reset the counter to 1 when it is active high. We will use a synchronous reset, meaning the reset will only be applied on the positive edge of the clock.
