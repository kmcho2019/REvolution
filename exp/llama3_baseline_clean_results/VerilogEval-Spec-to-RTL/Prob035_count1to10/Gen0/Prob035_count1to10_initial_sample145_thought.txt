To implement a decade counter, we need to design a sequential logic circuit that can count from 1 to 10. We will use a 4-bit register to store the current count. On the positive edge of the clock, we will increment the count if it's less than 10. If the count reaches 10, we will reset it to 1 on the next clock edge. We will also implement a synchronous reset that resets the counter to 1 when the reset input is high.
