To implement a decade counter in Verilog, we will use a 4-bit register to store the count value, and a counter control logic to handle the counting and resetting. The counter will increment on each positive clock edge unless it has reached 10, in which case it will wrap around to 1 when the next clock edge occurs. The reset input will be active high synchronous, meaning it will reset the counter to 1 on the next positive clock edge after the reset signal is asserted.
