To implement a decade counter in Verilog, we will use a 4-bit binary counter and add logic to reset it when it reaches 11 (1011 in binary) and also handle the reset input. The counter should count from 1 to 10, so we need to ensure it wraps around correctly. We can achieve this by checking for the maximum value (1010 in binary for 10) and resetting to 1 when we hit 11. The reset input will be used to reset the counter to 1 on the next clock cycle.
