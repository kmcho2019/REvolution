To implement a decade counter in Verilog, we need to create a counter that counts from 1 to 10. We can use a 4-bit register to store the count value. We will use an always block to update the count on the positive edge of the clock. Inside the always block, we will check if the reset is high. If it is, we reset the count to 1. Otherwise, we increment the count if it's less than 10. If the count reaches 10, we keep it at 10.
