To implement the decade counter, we need to create a finite state machine that counts from 1 to 10 and then wraps around. Since we are counting up to 10, we will need a 4-bit counter (2^4 = 16, which is greater than 10). We will use a synchronous reset to reset the counter to 1. We will use an if-else statement to check the current count and decide what the next count should be.
