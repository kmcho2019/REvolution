To implement a decade counter in Verilog, we need to design a 4-bit counter that counts from 1 to 10. We can use a finite state machine or a simple counter with a conditional statement to reset the count when it exceeds 10. Since the reset is active high synchronous, we need to include it in the sequential logic. We will use a 4-bit register to store the current count and update it on the positive edge of the clock. When the reset signal is high, the counter will be reset to 1.
