To implement a decade counter, we need to create a sequential logic circuit that increments a 4-bit counter from 1 to 10 (binary: 0001 to 1010) and then wraps around back to 1. This requires a finite state machine or a counter with a specific condition to reset the count. Since the reset is active high and synchronous, we need to incorporate this into our state machine to reset the counter to 1 when reset is high on a positive clock edge. We can achieve this using a 4-bit binary counter and adding logic to handle the specific counting and reset conditions.
