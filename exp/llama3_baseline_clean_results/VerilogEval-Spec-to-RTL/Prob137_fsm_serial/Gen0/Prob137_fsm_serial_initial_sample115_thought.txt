To solve this problem, we will design a finite state machine (FSM) with the following states:
- IDLE: The initial state where the FSM waits for the start bit (0).
- START_BIT: The state where the FSM has detected the start bit and waits for the data bits.
- DATA_BITS: The state where the FSM collects the 8 data bits.
- STOP_BIT: The state where the FSM checks for the stop bit (1) and verifies the completion of a byte.
- INVALID: The state where the FSM waits for a stop bit if the expected stop bit is not received.
The FSM will use counters to track the number of data bits received and the state of the serial protocol.
