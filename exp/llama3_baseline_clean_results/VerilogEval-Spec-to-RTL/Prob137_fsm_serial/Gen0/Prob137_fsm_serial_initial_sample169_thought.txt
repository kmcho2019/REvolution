To solve this problem, we will implement a finite state machine (FSM) with several states: 
- Idle: wait for the start bit (0) to arrive.
- Start: verify the start bit and move to the data receiving state.
- Data: receive the 8 data bits, shifting them into a register. 
- Stop: verify the stop bit (1) after receiving the 8 data bits. 
If the stop bit does not appear when expected, the FSM will go back to the idle state after encountering a stop bit.
We will use a counter to keep track of the number of data bits received and a shift register to store the data bits.
