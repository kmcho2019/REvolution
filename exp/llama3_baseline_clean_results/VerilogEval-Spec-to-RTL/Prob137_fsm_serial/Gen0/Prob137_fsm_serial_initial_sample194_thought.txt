The finite state machine (FSM) will be designed with four main states: IDLE, START, DATA, and STOP. The IDLE state waits for the start bit (0), the START state acknowledges the start bit and moves to DATA state, the DATA state collects the 8 data bits, and the STOP state checks the stop bit (1). If the stop bit is correct, the FSM returns to IDLE state and asserts the done signal. If the stop bit is incorrect, the FSM remains in the current state until a stop bit (1) is detected, then it returns to IDLE state. A counter will be used to keep track of the number of data bits received.
