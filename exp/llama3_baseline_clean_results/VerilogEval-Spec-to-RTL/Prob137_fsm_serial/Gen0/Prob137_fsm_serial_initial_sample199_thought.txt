To implement the finite state machine, we can define several states: 
1. Idle: The initial state, waiting for the start bit.
2. Receiving: Receiving the data bits after detecting the start bit.
3. Stop: Checking the stop bit after receiving the data bits.
The FSM will transit between these states based on the input 'in' and the current state. 
When a complete byte is received correctly, the 'done' signal will be asserted for one clock cycle.
We will use a counter to keep track of the number of data bits received.
