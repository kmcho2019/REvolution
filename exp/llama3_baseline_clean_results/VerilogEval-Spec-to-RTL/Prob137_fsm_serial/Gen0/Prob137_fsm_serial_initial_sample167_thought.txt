To implement the finite state machine, we can define several states: 
- IDLE: The initial state where we wait for a start bit (0).
- DATA: The state where we receive the 8 data bits.
- STOP: The state where we verify the stop bit (1).
We use a counter to count the number of data bits received. When the counter reaches 8, we move to the STOP state. If the stop bit is not received, we go back to the IDLE state and wait for a new start bit.
