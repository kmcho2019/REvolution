To solve this problem, we will design a finite state machine (FSM) with the following states:
1. IDLE: Wait for the start bit (0) on the input line.
2. START: Verify that the input is 0 (start bit).
3. DATA: Shift in 8 data bits (least significant bit first).
4. STOP: Verify that the input is 1 (stop bit).
If the stop bit does not appear when expected, we will remain in the STOP state until it does.

We will use a counter to keep track of the number of data bits received and a register to store the received data.
When the FSM correctly receives a byte (start bit, 8 data bits, and stop bit), it will assert the 'done' output for one clock cycle.
We will also include a synchronous reset to reset the FSM to the IDLE state.
