To solve this problem, we will implement a finite state machine (FSM) in the TopModule. The FSM will have four main states: IDLE, START, DATA, and STOP. 
- In the IDLE state, the FSM waits for a start bit (0) to be received on the input 'in'.
- Once a start bit is detected, the FSM moves to the START state and waits for one clock cycle to ensure the start bit was not a glitch.
- Then it moves to the DATA state, where it receives the 8 data bits. It uses a counter to keep track of the number of data bits received so far.
- After receiving all 8 data bits, the FSM moves to the STOP state, where it checks for the stop bit (1). If the stop bit is correct, it sets the 'done' output high for one clock cycle and then moves back to the IDLE state.
- If the stop bit is not received when expected, the FSM stays in the STOP state and waits until it finds a stop bit before moving back to the IDLE state.
- An active-high synchronous reset is used to reset the FSM to the IDLE state when the 'reset' input is high.
