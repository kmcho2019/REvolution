To implement the finite state machine, we can define four main states: 
- IDLE: The initial state where the FSM waits for a start bit (0).
- START: The state after detecting a start bit, where the FSM is ready to receive the data bits.
- DATA: The state where the FSM receives the 8 data bits.
- STOP: The state where the FSM checks for the stop bit after receiving the data bits.
We will use a counter to keep track of the number of data bits received and a register to store the received data bits.
