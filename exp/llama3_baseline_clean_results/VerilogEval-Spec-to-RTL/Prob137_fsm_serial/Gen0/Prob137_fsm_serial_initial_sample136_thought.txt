To solve this problem, we will implement a finite state machine (FSM) with the following states: 
1. IDLE: The initial state, waiting for a start bit.
2. START: Found a start bit, now waiting for data bits.
3. DATA: Collecting data bits.
4. STOP: Waiting for the stop bit.
5. DONE: Successfully received a byte, signal done for one clock cycle.

The FSM will transition between these states based on the input 'in' and the current state. When in the DONE state, the 'done' output will be set high for one clock cycle.
