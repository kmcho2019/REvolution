The finite state machine will have several states to identify the start bit, receive the data bits, and verify the stop bit. The states will be: IDLE, START, DATA, and STOP. 

- In the IDLE state, the FSM will wait for the start bit (0) to be received.
- Once the start bit is detected, the FSM will move to the DATA state and receive the 8 data bits.
- After receiving the 8 data bits, the FSM will move to the STOP state and verify the stop bit (1).
- If the stop bit is correct, the FSM will move back to the IDLE state and indicate that a byte has been received by setting the 'done' signal high for one clock cycle.
- If the stop bit is not correct, the FSM will wait in the STOP state until a stop bit (1) is received before moving back to the IDLE state.

The FSM will also have a reset state that will reset all the state variables and the 'done' signal when the reset input is high.
