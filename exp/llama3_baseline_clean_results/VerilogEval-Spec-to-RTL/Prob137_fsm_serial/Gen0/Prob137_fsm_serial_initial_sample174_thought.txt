To implement the finite state machine (FSM) for receiving bytes in the serial communication protocol, we will design a Moore machine with the following states:
1. IDLE: Wait for the start bit (0) in the input stream.
2. START: Found the start bit, now start counting the data bits.
3. DATA: Count the 8 data bits.
4. STOP: Check the stop bit (1).

We'll use a counter to keep track of the number of data bits received and a register to store the received byte. We'll also use a variable to track the current state of the FSM.

The FSM will transition between states based on the current state, the input bit, and the counter value. The output 'done' will be asserted when a byte is correctly received.
