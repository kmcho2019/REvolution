To solve this problem, we will design a finite state machine (FSM) with the following states:
1. IDLE: The initial state where the FSM waits for the start bit.
2. START_BIT: The state where the FSM verifies the start bit.
3. DATA_BITS: The state where the FSM waits for the 8 data bits.
4. STOP_BIT: The state where the FSM verifies the stop bit.
5. ERROR: The state where the FSM waits for a stop bit if the stop bit verification fails.

The FSM will transition between these states based on the input 'in' and will assert 'done' when a byte is correctly received.

We will use a counter to keep track of the number of data bits received.

The FSM will also have a synchronous reset that will return it to the IDLE state when 'reset' is high.
