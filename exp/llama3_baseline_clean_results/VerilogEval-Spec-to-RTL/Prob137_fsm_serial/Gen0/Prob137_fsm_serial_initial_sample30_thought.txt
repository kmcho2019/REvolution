To solve this problem, we will design a finite state machine (FSM) with four states: IDLE, START, DATA, and STOP. The FSM will be in the IDLE state initially, waiting for the start bit. When the start bit is detected, it will transition to the START state. Then, it will transition to the DATA state and wait for 8 clock cycles to collect the 8 data bits. After collecting the data bits, it will transition to the STOP state to verify the stop bit. If the stop bit is correct, it will assert the done signal and transition back to the IDLE state. If the stop bit is incorrect, it will wait until it finds a stop bit before transitioning back to the IDLE state.
