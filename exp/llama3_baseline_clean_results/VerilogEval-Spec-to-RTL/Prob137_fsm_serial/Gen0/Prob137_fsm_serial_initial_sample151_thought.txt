To solve this problem, I'll design a finite state machine (FSM) with the following states:
1. IDLE: Wait for the start bit (0).
2. RECEIVE_DATA: Shift in the 8 data bits.
3. WAIT_STOP: Verify the stop bit (1).
The FSM will transition between these states based on the input 'in' and the current state. 
The FSM will be reset to the IDLE state when the reset signal is high. 
The 'done' signal will be asserted when a complete byte has been correctly received.
