To solve this problem, we will design a finite state machine (FSM) that transitions through the following states: 
- IDLE: waiting for the start bit
- START: start bit received, waiting for data bits
- DATA: receiving data bits
- STOP: waiting for the stop bit
- DONE: a complete byte has been received

The FSM will transition from one state to the next based on the current state and the input 'in'. 
In the DATA state, we will use a counter to keep track of the number of data bits received. 
If the stop bit is not received when expected, the FSM will remain in the STOP state until a stop bit is received, then transition back to the IDLE state.
