To solve this problem, we'll design a finite state machine (FSM) with the following states:
- IDLE: initial state, waiting for a start bit
- START: received a start bit, preparing to receive data bits
- DATA: receiving data bits
- STOP: waiting for a stop bit
- DONE: received a valid stop bit, byte received correctly

The FSM will transition between these states based on the current state and the input signal 'in'. If at any point the stop bit is not received when expected, the FSM will wait for a stop bit before transitioning back to the IDLE state. 
We'll use a counter to keep track of the number of data bits received.
The output 'done' will be set high for one clock cycle when a valid byte is received.
