To implement the finite state machine, we can define four states: IDLE, START_BIT, DATA_BITS, and STOP_BIT. The FSM starts in the IDLE state, waiting for the start bit. When the start bit is detected, it transitions to the START_BIT state. Then, it enters the DATA_BITS state to count the 8 data bits. After the data bits, it transitions to the STOP_BIT state to verify the stop bit. If the stop bit is correct, it returns to the IDLE state. If the stop bit is incorrect, it remains in the STOP_BIT state until a stop bit is detected. We will use a counter to keep track of the data bits and a shift register to store the received byte.
