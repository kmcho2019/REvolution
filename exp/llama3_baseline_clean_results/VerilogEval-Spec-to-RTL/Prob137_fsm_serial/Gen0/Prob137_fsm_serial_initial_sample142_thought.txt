To implement the finite state machine, we can define several states: 
1) IDLE: The initial state where the FSM waits for a start bit (0) on the input 'in' line. 
2) RECEIVE_DATA: After detecting the start bit, the FSM enters this state where it counts the 8 data bits.
3) VERIFY_STOP: After receiving the 8 data bits, the FSM enters this state to check the stop bit.
If the stop bit is correctly received (1), the FSM transitions back to the IDLE state and sets the 'done' output to 1 for one clock cycle. 
If the stop bit is not received, the FSM stays in this state until a stop bit is detected, then transitions back to the IDLE state.

We use a counter to keep track of the number of data bits received and a shift register to store the received data bits.
