To implement the desired finite state machine, we can use a modular approach with three main states: IDLE, RECEIVING, and VERIFY_STOP. The IDLE state waits for the start bit, RECEIVING state accumulates the 8 data bits, and VERIFY_STOP checks the stop bit. If the stop bit is incorrect, we stay in a loop until a stop bit is detected before returning to IDLE. We will use a counter to track the number of bits received and a register to store the received data.
