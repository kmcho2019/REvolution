To solve this problem, we need to design a finite state machine (FSM) with the following states:
1. IDLE: The initial state where the FSM waits for the start bit (0).
2. DATA: After detecting the start bit, the FSM enters this state and waits for the 8 data bits.
3. STOP: After receiving the 8 data bits, the FSM enters this state to verify the stop bit (1).
We will use a counter to keep track of the number of data bits received and a register to store the received data.
The FSM will also have a done signal that will be asserted when a byte is correctly received.
We will use a synchronous reset to reset the FSM to the IDLE state.
