To solve this problem, we can design a finite state machine (FSM) with the following states: 
- Idle: This is the initial state where the FSM waits for a start bit (0) to begin receiving a byte.
- Receive: In this state, the FSM receives the 8 data bits of the byte. We'll use a counter to keep track of the number of bits received so far.
- VerifyStop: After receiving 8 data bits, the FSM moves to this state to verify the stop bit (1). If the stop bit is not 1, it will stay in this state until it sees a 1 (which could be the stop bit of the current byte or the stop bit of a subsequent byte).
- Done: Once the stop bit is verified, the FSM moves to this state and sets the 'done' signal high for one clock cycle to indicate that a byte has been successfully received.
We'll use a counter to count the number of bits received in the Receive state.
