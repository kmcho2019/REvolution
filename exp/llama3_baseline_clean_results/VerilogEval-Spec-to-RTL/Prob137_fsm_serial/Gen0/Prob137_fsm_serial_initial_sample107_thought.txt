To solve this problem, we will implement a finite state machine (FSM) with the following states:
1. Idle: This is the initial state where the FSM waits for the start bit.
2. Receive_data: In this state, the FSM waits for the 8 data bits.
3. Stop_bit: This state checks if the stop bit is correct.

The FSM will transition between these states based on the input 'in' and the current state. We will use a counter to keep track of the number of data bits received. The 'done' signal will be asserted when a byte is correctly received.

We will also implement a synchronous reset to reset the FSM to the idle state when 'reset' is high.
