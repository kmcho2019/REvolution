To solve this problem, we will design a finite state machine (FSM) with several states: Idle, Start, Data, and Stop. The FSM starts in the Idle state, waiting for a start bit (0) to appear on the input. When a start bit is detected, the FSM moves to the Start state and starts counting the data bits. After 8 data bits have been received, the FSM moves to the Stop state to verify the stop bit. If the stop bit is valid (1), the FSM moves back to the Idle state, signaling that a byte has been received correctly by asserting the done signal. If the stop bit is not valid, the FSM remains in the Stop state until a valid stop bit is received. We will use a counter to keep track of the number of data bits received and a register to store the received data bits.
