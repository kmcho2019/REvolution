To solve this problem, we will implement a finite state machine (FSM) with the following states: 
- IDLE: wait for a start bit (0)
- DATA: wait for 8 data bits
- STOP: verify the stop bit (1)
- ERROR: wait for a stop bit (1) if the previous stop bit verification failed
We will use a 4-state FSM to achieve this. The FSM will be implemented using a parameterized state type and a case statement to handle the different states. 
We will also use a counter to count the number of data bits received.
