To implement this finite state machine, we will use a state machine with several states: IDLE, START, DATA, and STOP. 
In the IDLE state, the FSM waits for the start bit (0) to arrive. 
Once the start bit is detected, the FSM transitions to the START state and waits for the next clock cycle. 
Then, it transitions to the DATA state where it collects the 8 data bits. 
After collecting all 8 data bits, it transitions to the STOP state where it checks for the stop bit (1). 
If the stop bit is not 1, the FSM goes back to the IDLE state and waits for the next stop bit. 
If the stop bit is 1, the FSM transitions back to the IDLE state after setting the done signal high for one clock cycle.
