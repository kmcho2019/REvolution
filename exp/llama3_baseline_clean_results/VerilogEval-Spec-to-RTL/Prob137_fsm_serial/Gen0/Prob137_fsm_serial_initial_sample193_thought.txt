To implement the serial byte receiver, we'll design a finite state machine (FSM) with the following states: 
1. Idle: Waiting for the start bit (0).
2. ReceiveBit: Receiving the 8 data bits.
3. VerifyStop: Verifying the stop bit (1).
The FSM will transition between these states based on the current input bit and the current state. 
We'll use a counter to keep track of the number of bits received in the ReceiveBit state. 
When the FSM successfully receives a byte, it will assert the done signal for one clock cycle.
