To solve this problem, we will implement a finite state machine (FSM) with the following states:
1. IDLE: The initial state where the FSM waits for the start bit.
2. START: The state where the FSM checks if the start bit is 0.
3. DATA: The state where the FSM collects the 8 data bits.
4. STOP: The state where the FSM checks if the stop bit is 1.
The FSM will also have a counter to keep track of the data bits collected.
When the FSM reaches the STOP state and the stop bit is 1, it will set the done signal high for one clock cycle.
We will use a 4-state FSM to handle the different states and a counter to keep track of the data bits.
