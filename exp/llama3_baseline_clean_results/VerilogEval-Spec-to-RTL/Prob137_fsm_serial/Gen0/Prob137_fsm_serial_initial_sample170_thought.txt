To solve this problem, we'll design a finite state machine (FSM) with the following states:
1. IDLE: Waiting for the start bit (0) to begin a new byte reception.
2. START: Start bit detected, waiting for the 8 data bits.
3. DATA: Receiving the 8 data bits.
4. STOP: Expecting the stop bit (1) after the data bits.
The FSM will transition between these states based on the current input bit and the current state.
We will use a counter to keep track of the number of data bits received.
When a complete byte is received correctly, the 'done' signal will be asserted for one clock cycle.
