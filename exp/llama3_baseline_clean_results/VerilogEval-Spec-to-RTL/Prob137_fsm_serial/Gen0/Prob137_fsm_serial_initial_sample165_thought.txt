To solve this problem, we can implement a finite state machine (FSM) with the following states: 
- IDLE: Initial state where the FSM waits for a start bit.
- START_BIT: State where the FSM checks if the start bit is 0.
- DATA_BITS: State where the FSM collects the 8 data bits.
- STOP_BIT: State where the FSM checks if the stop bit is 1.
- ERROR: State where the FSM waits for a stop bit before returning to IDLE.
The FSM will transition between these states based on the input 'in' and the current state. The 'done' signal will be asserted when a byte is correctly received.
