To solve this problem, we'll design a finite state machine (FSM) with the following states:
- IDLE: waiting for a start bit (0)
- DATA: receiving the 8 data bits
- STOP: waiting for the stop bit (1)
- DONE: byte received successfully

The FSM will transition between these states based on the input 'in' and the current state.
We'll use a counter to keep track of the current data bit being received.
When a byte is received successfully, the 'done' output will be set high for one clock cycle.
We'll also implement an active-high synchronous reset to reset the FSM to the IDLE state.
