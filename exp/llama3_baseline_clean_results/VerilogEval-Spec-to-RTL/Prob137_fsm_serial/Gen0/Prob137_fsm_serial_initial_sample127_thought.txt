To implement the finite state machine (FSM) described, we can break down the task into several states: 
1. Idle: Waiting for a start bit (0) on the input line.
2. Receiving: Collecting the 8 data bits after the start bit.
3. Verify Stop: Checking if the stop bit is 1 after receiving the data bits.

We'll use a counter to keep track of the number of data bits received and a register to store the received data. When a start bit is detected, the FSM moves from Idle to Receiving. During the Receiving state, it counts the number of data bits until it reaches 8, then moves to Verify Stop. If the stop bit is correct (1), it signals done and resets to Idle. If the stop bit is incorrect, it waits for the line to go idle (1) before returning to Idle. We'll also implement an active-high synchronous reset to reset the FSM to its initial state.
