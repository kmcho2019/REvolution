The design will utilize a finite state machine (FSM) to track the state of the serial communication protocol. The FSM will have the following states: 
- Idle: Waiting for the start bit to be received.
- Start: Start bit has been received, waiting for the data bits.
- Data: Receiving the 8 data bits.
- Stop: Waiting for the stop bit.
- Done: A byte has been successfully received.
The FSM will transition between these states based on the current state and the input bits. The FSM will also utilize a counter to keep track of the number of data bits received. The 'done' signal will be asserted when a byte is successfully received.
