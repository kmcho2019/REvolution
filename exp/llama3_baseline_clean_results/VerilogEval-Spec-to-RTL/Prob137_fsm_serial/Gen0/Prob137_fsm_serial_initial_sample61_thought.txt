To solve this problem, we will implement a finite state machine (FSM) that will go through several states to identify the start bit, receive the 8 data bits, and verify the stop bit. The states can be defined as follows:
- Idle: Wait for the start bit (0) to arrive.
- Start: Received the start bit, now waiting for the 8 data bits.
- Data: Receiving the data bits (8 bits).
- Stop: Received the 8 data bits, now waiting for the stop bit (1).
- Error: Stop bit not received as expected, wait for a stop bit (1) before going back to idle.
The FSM will transition between these states based on the current state and the input bit. If the FSM successfully receives a byte, it will set the 'done' output high for one clock cycle.
