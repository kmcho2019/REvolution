To implement this finite state machine, we can use a four-state approach: Idle, Start, Data, and Stop. The Idle state waits for a start bit (0), the Start state waits for the data bits, the Data state shifts in the data bits, and the Stop state verifies the stop bit. If the stop bit is not seen when expected, we will wait in the Stop state until a stop bit is seen, then reset to the Idle state. The FSM will use a counter to track the number of data bits received. We will also include a synchronous reset to reset the FSM to the Idle state.
