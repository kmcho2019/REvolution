To implement the finite state machine (FSM) as specified, we'll need to define the states for idle, start bit detection, data bit collection, and stop bit verification. We'll use a counter to keep track of the current data bit being collected. The FSM will transition from idle to start detection upon encountering a '0' (start bit). Then, it will transition to data collection and keep collecting data bits until all 8 are collected. After that, it checks for the stop bit. If the stop bit is correct (1), it outputs 'done' and returns to idle. If the stop bit is incorrect, it waits for a '1' (stop bit) to appear before going back to idle. The FSM includes an active-high synchronous reset to reset all states and counters.
