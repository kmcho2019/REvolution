To solve this problem, we can implement a finite state machine (FSM) with the following states:
- IDLE: The initial state where the FSM waits for a start bit.
- DATA: The state where the FSM receives the data bits.
- STOP: The state where the FSM verifies the stop bit.

The FSM will transition between these states based on the input signal 'in' and the current state. We will also use a counter to keep track of the number of data bits received.

When the FSM is in the IDLE state and 'in' is 0 (start bit), it transitions to the DATA state and starts counting the data bits. When it receives 8 data bits, it transitions to the STOP state. If the stop bit is 1, it outputs 'done' and returns to the IDLE state. If the stop bit is 0, it remains in the STOP state and waits for a stop bit.

We will also implement a synchronous reset to reset the FSM to the IDLE state when 'reset' is high.
