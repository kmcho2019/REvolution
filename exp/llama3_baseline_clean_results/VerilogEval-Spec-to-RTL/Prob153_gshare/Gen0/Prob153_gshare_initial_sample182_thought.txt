The TopModule will implement a gshare branch predictor. It will have two interfaces: one for making predictions and one for training. 
The prediction interface will use the current pc and global branch history to index into a 128-entry table of two-bit saturating counters.
The training interface will update the pattern history table (PHT) and recover the branch history register if a misprediction occurs.
The module will prioritize training over prediction when both occur in the same cycle.
All sequential logic will be triggered on the positive edge of the clock.
