To implement the TopModule, we need to create a gshare branch predictor that uses a 7-bit pc and 7-bit global history, hashed into a 7-bit index to access a 128-entry table of two-bit saturating counters. We will use two interfaces: one for predictions and one for training. The prediction interface will produce the predicted branch direction and state of the branch history register used to make the prediction, and then update the branch history register at the next positive clock edge. The training interface will update the pattern history table (PHT) to train the branch predictor to predict the branch more accurately next time, and recover the branch history register to the state immediately after the mispredicting branch completes execution if the branch being trained is mispredicted. We will use a 7-bit global branch history register and ensure that training takes precedence over prediction when both occur in the same cycle.
