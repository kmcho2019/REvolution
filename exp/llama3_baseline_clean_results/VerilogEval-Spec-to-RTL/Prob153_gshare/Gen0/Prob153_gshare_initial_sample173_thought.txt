The TopModule should be designed as a finite state machine that responds to the predict_valid and train_valid signals. It should maintain a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. When predict_valid is high, the module should hash the predict_pc and current global history register using XOR to index into the pattern history table (PHT), retrieve the corresponding counter value, and output the predicted branch direction and the current global history register. The global history register should be updated at the next positive clock edge based on the predicted branch direction.

When train_valid is high, the module should hash the train_pc and train_history using XOR to index into the PHT, retrieve the corresponding counter value, and update the counter value based on the actual branch outcome. If the branch was mispredicted, the global history register should be recovered to the state immediately after the mispredicting branch completes execution.

The module should prioritize training over prediction when both occur in the same cycle, and it should maintain the correct timing relationship between training and prediction requests.
