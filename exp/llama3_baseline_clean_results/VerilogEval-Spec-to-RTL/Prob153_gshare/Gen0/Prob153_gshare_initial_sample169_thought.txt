To implement the TopModule with the given interface, we need to design a gshare branch predictor that meets the specified requirements. The predictor will use a 7-bit global history register and a 128-entry table of two-bit saturating counters. 

The design will consist of the following components:
1. A 7-bit global branch history register that is updated based on prediction and training requests.
2. A 128-entry table of two-bit saturating counters, indexed by the hashed (using xor) 7-bit pc and 7-bit global history.
3. Combinational logic to generate the predicted branch direction based on the current state of the PHT entry.
4. Sequential logic to update the PHT entry based on training requests.
5. Logic to handle the case where a prediction and a training request for the same PHT entry occur in the same cycle.

The predictor will be designed using Verilog, with the given interface and functionality.
