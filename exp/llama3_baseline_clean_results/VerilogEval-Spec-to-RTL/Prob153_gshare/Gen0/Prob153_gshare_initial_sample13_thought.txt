To implement the TopModule, we need to follow these steps:
1. Design the global branch history register to store the 7-bit history.
2. Implement the 128-entry table of two-bit saturating counters, which will be used as the pattern history table (PHT).
3. Create a hash function that takes the 7-bit pc and 7-bit global history and produces a 7-bit index to access the PHT.
4. Implement the prediction logic, which uses the PHT to make branch direction predictions when predict_valid is high.
5. Implement the training logic, which updates the PHT and the global branch history register when train_valid is high.
6. Ensure that training takes precedence over prediction when both occur in the same cycle.
7. Implement the asynchronous active-high reset logic to reset the module when areset is high.

The hash function will be implemented using an XOR operation between the pc and the global history.
The PHT will be updated based on the actual branch outcome and whether the branch was a misprediction.
The global branch history register will be updated at the next positive clock edge after a prediction is made.
If a misprediction occurs during training, the global branch history register will be recovered to its state immediately after the mispredicting branch completes execution.
