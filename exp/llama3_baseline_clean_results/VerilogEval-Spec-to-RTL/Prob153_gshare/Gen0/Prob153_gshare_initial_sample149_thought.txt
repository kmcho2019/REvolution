To implement the gshare branch predictor, we first need to define the 
internal signals and registers. The module has a 7-bit global branch 
history register and a 128-entry table of two-bit saturating counters.
The index into the table is generated by hashing the 7-bit pc and 7-bit 
global history using xor. When a prediction is requested, the predicted 
branch direction is determined by the state of the corresponding saturating 
counter. The branch history register is updated at the next positive clock 
edge based on the predicted branch direction. When training is requested, 
the saturating counter is updated at the next positive clock edge based on 
the actual branch outcome and whether the branch was a misprediction. If 
the branch was a misprediction, the branch history register is recovered 
to the state immediately after the mispredicting branch completes execution.
