The TopModule implements a gshare branch predictor with a 7-bit pc and 7-bit global history. 
To achieve this, we need to design a module that can handle two separate interfaces: 
one for predictions and one for training. The prediction interface uses the current 
pc and global history to produce a predicted branch direction, while the training 
interface updates the global history and pattern history table (PHT) based on the 
actual branch outcome. We will use a 7-bit global branch history register and a 
128-entry table of two-bit saturating counters for the PHT. The index into the PHT 
will be generated by hashing the pc and global history using XOR.

For the prediction interface, when a prediction is requested, we will use the current 
pc and global history to generate the index into the PHT, retrieve the corresponding 
counter value, and produce the predicted branch direction. The global history register 
will then be updated at the next positive clock edge for the predicted branch.

For the training interface, when a training request is made, we will update the PHT 
based on the actual branch outcome and whether the branch was a misprediction. If the 
branch was a misprediction, we will also recover the global history register to the state 
immediately after the mispredicting branch completes execution.

To handle the case where training and prediction of the same PHT entry occur at the same 
time, we will ensure that the prediction sees the PHT state before training, which only 
modifies the PHT at the next positive clock edge. If training and prediction both want to 
modify the global history register in the same cycle, training will take precedence.

Finally, we will implement the reset logic to handle the asynchronous active-high reset.
