To implement the gshare branch predictor, we need to create a module that has two interfaces: one for prediction and one for training. The prediction interface will use the current pc and global branch history to index into a pattern history table (PHT) and produce a branch direction prediction. The branch history register will then be updated based on the predicted branch direction. The training interface will update the PHT entry corresponding to the pc and branch history register value for the branch being trained, based on the actual branch outcome and whether it was a misprediction. We will also need to recover the branch history register if the branch being trained was a misprediction.

We will use a 7-bit global branch history register and a 128-entry PHT, where each entry is a 2-bit saturating counter. The index into the PHT will be generated by hashing the 7-bit pc and 7-bit global branch history using XOR.

We will also need to handle the case where training and prediction of the same PHT entry happen at the same time. In this case, the prediction will see the PHT state before training.

To handle reset, we will use an asynchronous active-high reset signal.
