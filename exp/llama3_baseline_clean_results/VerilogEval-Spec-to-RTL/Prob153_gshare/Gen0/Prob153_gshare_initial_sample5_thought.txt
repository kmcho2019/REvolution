To implement the TopModule, we need to create a module that meets the specified requirements. 
We will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. 
When a prediction is requested, we will use the current PC and global branch history to index into the table, 
and then produce the predicted branch direction and the state of the branch history register used to make the prediction. 
We will then update the branch history register at the next positive clock edge. 
When training is requested, we will update the pattern history table (PHT) to train the branch predictor to predict the branch more accurately next time. 
If the branch being trained is mispredicted, we will also recover the branch history register to the state immediately after the mispredicting branch completes execution.
We will use Verilog to implement the module, using registers to store the global branch history and the PHT, and combinational logic to generate the predicted branch direction and the updated branch history.
