The module TopModule will implement a gshare branch predictor. It will have two main components: 
1) A global branch history register to keep track of the branch history.
2) A pattern history table (PHT) with 128 entries of two-bit saturating counters.

When a prediction is requested, the module will use the current pc and branch history to index into the PHT, 
and output the predicted branch direction and the current state of the branch history register. 
The branch history register will then be updated at the next positive clock edge.

When a training request is made, the module will update the corresponding entry in the PHT based on the actual branch outcome.
If the branch was mispredicted, the branch history register will be recovered to the state immediately after the mispredicting branch completes execution.

The module will also handle the case where a training request and a prediction request occur in the same cycle.
In this case, the training request will take precedence, and the prediction will see the PHT state before the training request is applied.
