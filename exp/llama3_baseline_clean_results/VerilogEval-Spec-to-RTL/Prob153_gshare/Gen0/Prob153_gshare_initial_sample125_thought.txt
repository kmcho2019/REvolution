To implement the TopModule with the given interface, we will create a gshare branch predictor. 
The predictor will have a global branch history register and a pattern history table (PHT) with 128 entries, each containing a two-bit saturating counter. 
The index into the PHT will be calculated by hashing the 7-bit PC and 7-bit global branch history using XOR. 
When a prediction is requested, the predictor will use the current index to access the corresponding PHT entry, determine the predicted branch direction, and update the global branch history register. 
When training is requested, the predictor will update the PHT entry based on the actual branch outcome and recover the global branch history register if the branch was mispredicted.
