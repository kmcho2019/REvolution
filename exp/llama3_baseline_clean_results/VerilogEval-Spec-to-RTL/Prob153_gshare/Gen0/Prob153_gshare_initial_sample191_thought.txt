The TopModule will contain a 7-bit global branch history register, a 128-entry table of two-bit saturating counters, and logic for handling prediction and training requests.
The module will use a 7-bit pc and 7-bit global history, hashed (using xor) into a 7-bit index to access the pattern history table (PHT).
When a branch prediction is requested, the module will produce the predicted branch direction and state of the branch history register used to make the prediction.
When training for a branch is requested, the module will update the PHT to train the branch predictor to predict this branch more accurately next time.
If the branch being trained is mispredicted, the module will also recover the branch history register to the state immediately after the mispredicting branch completes execution.
The module will handle cases where training and prediction of the same PHT entry happen at the same time, with prediction seeing the PHT state before training.
Asynchronous active-high reset will be used to reset the module.
