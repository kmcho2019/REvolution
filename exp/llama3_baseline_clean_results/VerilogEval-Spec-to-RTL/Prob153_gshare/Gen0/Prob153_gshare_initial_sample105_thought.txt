The TopModule should implement a gshare branch predictor with a 7-bit pc and 7-bit global history, 
hashed into a 7-bit index to access a 128-entry table of two-bit saturating counters. 
It should contain a 7-bit global branch history register. 
The module should have two interfaces: one for prediction and one for training. 
When a prediction is requested, the module should produce the predicted branch direction and the state of 
the branch history register used to make the prediction, and then update the branch history register for the 
predicted branch. When training is requested, the module should update the pattern history table (PHT) to train 
the branch predictor to predict the branch more accurately next time, and recover the branch history register 
if the branch being trained is mispredicted.
