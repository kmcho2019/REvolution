To implement the gshare branch predictor, we need to follow these steps:
1. Design the global branch history register and update its value based on the predicted branch direction.
2. Implement the pattern history table (PHT) with 128 entries of two-bit saturating counters.
3. Calculate the index to access the PHT using the XOR of the 7-bit PC and the 7-bit global branch history.
4. Update the PHT entry based on the training inputs (train_valid, train_taken, train_mispredicted).
5. Generate the predicted branch direction based on the PHT entry value.
6. Handle the case when training and prediction occur at the same time, giving precedence to training.
7. Reset the predictor asynchronously when areset is high.

We will use Verilog's reg and wire data types to declare the signals, and always blocks to describe the combinational and sequential logic.
