To implement the gshare branch predictor module, we need to follow these steps:

1. Create a 7-bit global branch history register to store the history of branches.
2. Implement a 128-entry table of two-bit saturating counters to store the prediction outcomes.
3. Use the 7-bit pc and 7-bit global history, hashed (using xor) into a 7-bit index, to access the prediction table.
4. When a prediction is requested, use the current global history to make a prediction and update the global history register for the predicted branch.
5. When training is requested, update the pattern history table (PHT) based on the actual branch outcome and the misprediction flag.
6. If a misprediction occurs, recover the branch history register to the state immediately after the mispredicting branch completes execution.
7. Handle the case where training and prediction of the same PHT entry happen at the same time, with training taking precedence.

We will use Verilog's reg and wire data types to implement the registers and wires, and always and initial blocks to describe the combinational and sequential logic.
