To implement the gshare branch predictor, we need to design a module that can handle both prediction and training operations. The predictor uses a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The index for accessing the table is generated by hashing the 7-bit pc and 7-bit global history using XOR. The prediction interface takes in the current pc and produces the predicted branch direction and the state of the branch history register. The training interface updates the pattern history table based on the actual branch outcome and updates the branch history register if a misprediction occurs.

The design will consist of the following components:

- A 7-bit global branch history register
- A 128-entry table of two-bit saturating counters (Pattern History Table, PHT)
- Combinational logic to generate the index for accessing the PHT
- Combinational logic to predict the branch direction based on the PHT entry
- Sequential logic to update the PHT and the global branch history register based on the training inputs

We will use Verilog's reg type to define the sequential elements and wire type to define the combinational logic.
