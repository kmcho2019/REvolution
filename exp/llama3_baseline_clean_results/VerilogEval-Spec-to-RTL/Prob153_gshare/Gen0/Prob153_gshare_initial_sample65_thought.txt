To implement the gshare branch predictor module, we will use the following steps:
1. Create a 7-bit global branch history register and a 128-entry table of two-bit saturating counters.
2. When a prediction is requested, use the input pc and the current branch history register value to generate a 7-bit index by hashing (using xor) the pc and the global history register. This index will be used to access the pattern history table (PHT) and get the predicted branch direction.
3. Update the branch history register at the next positive clock edge for the predicted branch.
4. When training is requested, update the PHT to train the branch predictor to predict the branch more accurately next time. Also, if the branch being trained is mispredicted, recover the branch history register to the state immediately after the mispredicting branch completes execution.
5. Ensure that training takes precedence over prediction when both occur in the same cycle.
6. Implement asynchronous active-high reset to reset the module.

We will use Verilog's reg data type to declare registers and wires to declare combinational logic signals. We will also use always blocks to describe sequential and combinational logic.
