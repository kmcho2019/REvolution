To implement the gshare branch predictor, we need to follow these steps:
1. Create a 7-bit global branch history register to keep track of the branch outcomes.
2. Implement a 128-entry table of two-bit saturating counters, where each counter corresponds to a unique 7-bit index generated by hashing the 7-bit pc and 7-bit global history using xor.
3. When a prediction is requested, use the current pc and global history to generate the index and access the corresponding counter in the table. The predicted branch direction is determined by the state of the counter (0 or 1 for not taken, 2 or 3 for taken).
4. Update the global branch history register based on the predicted branch direction.
5. When training is requested, use the provided pc and branch history to generate the index and access the corresponding counter in the table. Update the counter based on the actual branch outcome and whether the branch was mispredicted.
6. If the branch being trained is mispredicted, recover the global branch history register to the state immediately after the mispredicting branch completes execution.
7. Ensure that training takes precedence over prediction when both occur in the same cycle.
8. Implement asynchronous active-high reset to reset the global branch history register and the pattern history table.
