To implement the TopModule with a gshare branch predictor, we first need to create a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The 7-bit pc and 7-bit global history are hashed (using xor) into a 7-bit index to access the table. The prediction interface will produce the predicted branch direction and state of the branch history register used to make the prediction. The training interface will update the pattern history table (PHT) to train the branch predictor to predict branches more accurately next time. We will use a case statement to update the saturating counters. If the branch being trained is mispredicted, the branch history register will be recovered to the state immediately after the mispredicting branch completes execution. When training for a misprediction and a prediction (for a different instruction) occurs in the same cycle, training will take precedence.
