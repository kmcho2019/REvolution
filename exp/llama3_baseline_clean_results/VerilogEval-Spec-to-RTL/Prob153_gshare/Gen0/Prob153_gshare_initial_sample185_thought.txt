To implement the gshare branch predictor, we'll first create a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. We'll use the XOR of the 7-bit pc and the 7-bit global history to index into the table. The prediction interface will use the current state of the branch history register and the PHT entry to make predictions. When training, we'll update the PHT entry and recover the branch history register if a misprediction occurs. We'll use a clocked process to update the branch history register and the PHT entries.
