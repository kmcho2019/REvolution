To implement the TopModule, we will first define the internal signals and registers required for the gshare branch predictor. We will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The index to access the table will be generated by hashing the 7-bit pc and 7-bit global history using xor. We will then implement the logic for prediction and training. For prediction, we will use the current global branch history to generate the index, access the table, and produce the predicted branch direction. For training, we will update the pattern history table (PHT) based on the actual branch outcome and whether it was a misprediction. If the branch was mispredicted, we will also recover the branch history register to the state immediately after the mispredicting branch completes execution. We will use the positive edge of the clock to trigger all sequential logic.
