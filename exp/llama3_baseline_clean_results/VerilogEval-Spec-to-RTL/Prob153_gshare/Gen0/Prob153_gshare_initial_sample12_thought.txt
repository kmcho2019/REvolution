2. Implement the prediction logic: when predict_valid is high, use the current pc and branch history to index into the PHT, read the corresponding counter value, and predict the branch direction based on the counter value.
3. Implement the training logic: when train_valid is high, use the train_pc and train_history to index into the PHT, update the corresponding counter value based on the train_taken and train_mispredicted signals, and recover the branch history register if the branch was mispredicted.
4. Update the branch history register at the next positive clock edge based on the predicted branch direction.
5. Handle the case where training and prediction occur in the same cycle, giving precedence to training.
6. Implement asynchronous active-high reset to clear the branch history register and the PHT when areset is high.
