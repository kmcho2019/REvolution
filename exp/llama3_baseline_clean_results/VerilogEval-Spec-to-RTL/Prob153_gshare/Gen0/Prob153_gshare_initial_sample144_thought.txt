To implement the gshare branch predictor, we will first design a module that can handle the prediction and training interfaces. We will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The prediction interface will use the current pc and global history to index into the table and make a prediction. The training interface will update the table based on the actual branch outcome and whether the branch was a misprediction. We will also need to handle the case where a training and prediction request occur in the same cycle, giving precedence to the training request. We will use a clock edge triggered sequential logic to update the branch history register and the pattern history table (PHT).
