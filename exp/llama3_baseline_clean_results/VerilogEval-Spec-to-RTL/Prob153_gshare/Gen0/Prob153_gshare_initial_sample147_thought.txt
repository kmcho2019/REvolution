To implement the TopModule with the specified interface, we need to follow these steps:

1. Create a 7-bit global branch history register that is updated when a prediction is made.
2. Implement a 128-entry table of two-bit saturating counters to store the prediction history.
3. Hash the 7-bit PC and 7-bit global branch history into a 7-bit index using XOR.
4. Use this index to access the prediction history table and make predictions.
5. Update the prediction history table when a training request is received.
6. Handle the case where a prediction and training request occur in the same cycle.
7. Handle the asynchronous active-high reset.

We will use a combination of always blocks and combinational logic to implement the required functionality.
