To implement the gshare branch predictor module named TopModule, we need to consider the following steps:
1. Create a 7-bit global branch history register to keep track of the branch history.
2. Implement a 128-entry table of two-bit saturating counters to store the branch prediction outcomes.
3. When a prediction request is made (predict_valid = 1), use the current PC and global branch history to generate an index for the prediction table. The index is generated by hashing (using xor) the 7-bit pc and 7-bit global history into a 7-bit index.
4. Use the generated index to access the prediction table and determine the predicted branch direction.
5. Update the global branch history register at the next positive clock edge based on the predicted branch direction.
6. When a training request is made (train_valid = 1), use the provided PC and global branch history to generate an index for the prediction table.
7. Update the corresponding entry in the prediction table based on the actual branch outcome and whether the branch was a misprediction.
8. If the branch being trained is mispredicted, recover the global branch history register to the state immediately after the mispredicting branch completes execution.
9. Handle the case where both training and prediction requests occur in the same cycle, giving precedence to the training request.
10. Implement asynchronous active-high reset to clear the global branch history register and the prediction table when the reset signal is asserted.

The prediction table will be implemented as an array of 2-bit saturating counters, where each counter can take on values from 0 to 3. The predicted branch direction is determined by the value of the counter: 0 and 1 indicate a not-taken prediction, while 2 and 3 indicate a taken prediction.
