The TopModule will implement a GShare branch predictor with a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The module will have two interfaces: one for predictions and one for training. The prediction interface will use the current PC and global history to index into the table and produce a prediction. The training interface will update the table based on the actual branch outcome and whether the branch was a misprediction. If a misprediction occurs, the global history register will be recovered to the state immediately after the mispredicting branch completes execution. The module will prioritize training over prediction when both occur in the same cycle.
