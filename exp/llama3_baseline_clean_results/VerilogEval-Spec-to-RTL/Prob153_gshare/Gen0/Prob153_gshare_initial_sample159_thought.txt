To implement the gshare branch predictor, we need to create a module named TopModule with the given interface. The module should have the following components:
- A 7-bit global branch history register (ghr) that stores the history of the last 7 branches.
- A 128-entry table of two-bit saturating counters (PHT) that stores the prediction outcomes.
- Logic to hash the 7-bit pc and 7-bit global history into a 7-bit index using xor.
- Logic to access the PHT using the index and update the prediction.
- Logic to train the branch predictor based on the actual branch outcomes and mispredictions.
- Asynchronous reset logic to reset the module when areset is high.

We will use always blocks to implement the sequential logic and combinational logic blocks to implement the prediction and training logic.
