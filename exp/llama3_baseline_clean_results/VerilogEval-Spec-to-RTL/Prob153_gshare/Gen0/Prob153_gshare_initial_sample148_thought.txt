To implement the TopModule, we need to create a gshare branch predictor with a 7-bit pc and 7-bit global history, hashed into a 7-bit index that accesses a 128-entry table of two-bit saturating counters. We will use a 7-bit global branch history register to store the current branch history.

The module will have two interfaces: one for predictions and one for training. When a prediction is requested, the module will produce the predicted branch direction and state of the branch history register used to make the prediction, and then update the branch history register for the predicted branch.

When training is requested, the module will update the pattern history table (PHT) to train the branch predictor to predict the branch more accurately next time. If the branch being trained is a misprediction, the module will also recover the branch history register to the state immediately after the mispredicting branch completes execution.

We will use Verilog to implement the module, using a combination of combinational and sequential logic to implement the predictor and the PHT.
