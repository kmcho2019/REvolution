To implement the TopModule with the given interface, we need to design a gshare branch predictor. The predictor will have a 7-bit global branch history register, and it will use this history along with the 7-bit pc to index into a 128-entry table of two-bit saturating counters. The prediction interface will be used to make branch direction predictions and update the global branch history register. The training interface will be used to update the pattern history table (PHT) based on the actual branch outcomes. 

We need to handle the cases where a prediction and a training request occur in the same cycle, with training taking precedence over prediction. We also need to ensure that the prediction sees the PHT state before training, even if a training request for the same PHT entry is made in the same cycle.

The module will be designed using sequential logic, with all state updates occurring on the positive edge of the clock. Asynchronous active-high reset will be implemented to clear all state when the areset signal is high.
