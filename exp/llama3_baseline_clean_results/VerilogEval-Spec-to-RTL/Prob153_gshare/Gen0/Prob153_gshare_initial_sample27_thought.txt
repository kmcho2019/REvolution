The TopModule should be designed to implement a gshare branch predictor. 
It should contain a 7-bit global branch history register and a 128-entry 
table of two-bit saturating counters. The index into the table is generated 
by hashing the pc and global history using xor. The module should have two 
interfaces: one for predictions and one for training. When a prediction is 
requested, the module should produce the predicted branch direction and 
state of the branch history register, and then update the branch history 
register at the next positive clock edge. When training is requested, the 
module should update the pattern history table (PHT) to train the branch 
predictor to predict the branch more accurately next time, and also recover 
the branch history register to the state immediately after the mispredicting 
branch completes execution if the branch was a misprediction. If both 
training and prediction occur in the same cycle, training takes precedence.
