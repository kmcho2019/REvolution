To implement the TopModule, we need to create a module with the specified interface. 
The module will contain a 7-bit global branch history register and a 128-entry table of two-bit saturating counters.
When a branch prediction is requested, the module will produce the predicted branch direction and state of the branch history register used to make the prediction.
When training for a branch is requested, the module will update the pattern history table (PHT) to train the branch predictor to predict this branch more accurately next time.
If training for a misprediction occurs, the module will recover the branch history register to the state immediately after the mispredicting branch completes execution.
We will use a 7-bit index, hashed from the 7-bit pc and 7-bit global history using xor, to access the 128-entry table of two-bit saturating counters.
