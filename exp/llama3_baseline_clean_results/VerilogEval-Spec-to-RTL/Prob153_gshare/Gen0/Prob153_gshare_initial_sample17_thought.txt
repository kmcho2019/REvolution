To implement the TopModule, we need to follow these steps:
1. Create a 128-entry table of two-bit saturating counters to store the branch prediction history.
2. Implement a 7-bit global branch history register to store the current branch history.
3. When a prediction is requested, hash the 7-bit pc and 7-bit global history using XOR to get a 7-bit index, and use this index to access the table and get the predicted branch direction.
4. Update the global branch history register based on the predicted branch direction.
5. When training is requested, update the pattern history table (PHT) to train the branch predictor to predict the branch more accurately next time.
6. If the branch being trained is a misprediction, recover the branch history register to the state immediately after the mispredicting branch completes execution.
7. Handle the case where training and prediction of the same PHT entry happen at the same time, ensuring that the prediction sees the PHT state before training.
8. Implement asynchronous active-high reset to clear the branch history register and the PHT.
