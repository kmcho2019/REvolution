To implement the gshare branch predictor, we will first define a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The index into the table will be generated by hashing the 7-bit pc and the 7-bit global history using XOR. We will then implement the prediction and training logic. During prediction, we will use the current global branch history to generate the index, read the corresponding saturating counter, and predict the branch direction based on the counter value. We will then update the global branch history register at the next positive clock edge. During training, we will update the saturating counter corresponding to the index generated by the provided pc and branch history, and update the global branch history register if the branch was mispredicted.
