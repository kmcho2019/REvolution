To implement the gshare branch predictor with a 7-bit pc and 7-bit global history, 
we can use a 128-entry table of two-bit saturating counters. The global history 
register will be updated at the next positive clock edge for the predicted branch. 
The training interface will update the pattern history table (PHT) at the next 
positive clock edge to train the branch predictor to predict the branch more 
accurately next time. If the branch being trained is mispredicted, the branch 
history register will be recovered to the state immediately after the mispredicting 
branch completes execution.

The design will have the following components:
- A 7-bit global branch history register.
- A 128-entry table of two-bit saturating counters (PHT).
- Logic to compute the index into the PHT based on the pc and global history.
- Logic to update the PHT based on the training inputs.
- Logic to update the global history register based on the prediction and training inputs.

The module will have two sets of interfaces: one for predictions and one for training.
The prediction interface will produce the predicted branch direction and state of the 
branch history register used to make the prediction. The training interface will update 
the PHT to train the branch predictor to predict the branch more accurately next time.
