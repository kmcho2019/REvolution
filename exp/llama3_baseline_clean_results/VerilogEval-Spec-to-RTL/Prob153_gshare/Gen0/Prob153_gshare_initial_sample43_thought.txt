To implement the TopModule, we need to design a gshare branch predictor 
with a 7-bit PC and 7-bit global history. We will use a 7-bit global 
branch history register and a 128-entry table of two-bit saturating 
counters. The predictor will have two interfaces: one for making 
predictions and one for training. When a prediction is requested, the 
predictor will produce the predicted branch direction and state of the 
branch history register used to make the prediction. When training is 
requested, the predictor will update the pattern history table (PHT) to 
train the branch predictor to predict the branch more accurately next 
time. If the branch being trained is a misprediction, the predictor will 
also recover the branch history register to the state immediately after 
the mispredicting branch completes execution. We will use Verilog to 
implement the TopModule, utilizing registers to store the state of the 
branch history register and the PHT entries.
