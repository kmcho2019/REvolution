To implement the TopModule, we need to follow these steps:
1. Create a 7-bit global branch history register to store the branch history.
2. Implement a 128-entry table of two-bit saturating counters to store the prediction history.
3. Use the 7-bit pc and 7-bit global history, hashed (using xor) into a 7-bit index to access the prediction history table.
4. Update the global branch history register based on the prediction outcome.
5. Update the prediction history table based on the training outcome.
6. Handle the case when training and prediction of the same PHT entry happen at the same time.
7. Handle the case when training for a misprediction and a prediction (for a different, younger instruction) occurs in the same cycle.
8. Implement asynchronous active-high reset.

The module will have two main parts: one for prediction and one for training. 
The prediction part will use the current state of the global branch history register and the prediction history table to make a prediction. 
The training part will update the prediction history table and the global branch history register based on the training outcome.
