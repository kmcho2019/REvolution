To implement the TopModule with the specified gshare branch predictor, we need to follow these steps:
- Create a 7-bit global branch history register and initialize it to 0.
- Implement a 128-entry table of two-bit saturating counters to store the branch prediction history.
- When a branch prediction is requested, use the 7-bit pc and global branch history to generate a 7-bit index for the pattern history table (PHT).
- Use the index to access the PHT and get the predicted branch direction.
- Update the global branch history register based on the predicted branch direction.
- When training is requested, use the provided pc and branch history to generate an index for the PHT.
- Update the PHT based on the actual branch outcome and whether it was a misprediction.
- If it was a misprediction, recover the global branch history register to the state after the mispredicting branch completes execution.
- Handle the case where training and prediction occur in the same cycle, giving precedence to training.

We will use Verilog's always_ff and always_comb blocks to implement the sequential and combinational logic, respectively.
