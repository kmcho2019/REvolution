To implement the TopModule, we will create a 128-entry table to store the two-bit saturating counters and a 7-bit global branch history register. When a prediction is requested, we will use the current PC and branch history to index into the table and produce a prediction. We will then update the branch history register at the next positive clock edge. When training is requested, we will update the corresponding entry in the table based on the actual branch outcome and whether it was a misprediction. If the branch was a misprediction, we will also recover the branch history register to its state after the mispredicting branch. We will use a case statement to handle the different states of the two-bit saturating counters.
