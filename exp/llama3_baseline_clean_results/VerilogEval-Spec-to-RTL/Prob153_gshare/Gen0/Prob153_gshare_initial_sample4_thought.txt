To implement the gshare branch predictor, we first need to define the interface of the module as specified. Then, we need to implement the following components: 
1. A 7-bit global branch history register to keep track of the recent branch outcomes.
2. A 128-entry table of two-bit saturating counters (Pattern History Table, PHT) to store the prediction history.
3. A prediction logic that uses the global branch history and the PC to index into the PHT and make predictions.
4. An update logic that updates the PHT and the global branch history register based on the training inputs.

We also need to consider the priority of training over prediction when both occur in the same cycle, and ensure that the prediction sees the PHT state before training when both access the same PHT entry at the same time.
