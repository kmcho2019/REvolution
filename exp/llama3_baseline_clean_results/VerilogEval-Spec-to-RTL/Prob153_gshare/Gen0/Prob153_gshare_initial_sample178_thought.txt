To implement the TopModule, we need to follow these steps:
1. Create a 128-entry table of two-bit saturating counters to store the branch prediction history.
2. Implement a 7-bit global branch history register to keep track of the branch history.
3. Use the predict interface to make branch predictions by indexing into the table using the hashed pc and global history, and update the branch history register accordingly.
4. Use the train interface to update the pattern history table (PHT) based on the actual branch outcome and whether the branch was a misprediction.
5. Handle the case where training and prediction occur in the same cycle, giving precedence to training.
6. Reset the module asynchronously when areset is high.
