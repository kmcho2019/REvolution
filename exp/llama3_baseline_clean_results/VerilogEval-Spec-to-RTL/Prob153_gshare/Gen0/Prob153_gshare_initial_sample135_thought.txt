To implement the TopModule with the specified interface, we will create a module with two main components: a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The module will handle prediction and training requests separately. For prediction, it will use the current global branch history and PC to index into the table, retrieve the counter value, and predict the branch direction. For training, it will update the table entry based on the actual branch outcome and whether the branch was a misprediction. The module will also handle the case where training and prediction requests occur in the same cycle, giving precedence to training. The module will be reset asynchronously when areset is high.
