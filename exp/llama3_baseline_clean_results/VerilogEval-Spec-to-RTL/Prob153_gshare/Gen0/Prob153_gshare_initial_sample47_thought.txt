To implement the TopModule, we will design a gshare branch predictor with a 7-bit pc and 7-bit global history. The 7-bit pc and 7-bit global history will be hashed (using xor) into a 7-bit index, which will access a 128-entry table of two-bit saturating counters. We will use two separate interfaces for prediction and training. The prediction interface will use the current state of the branch history register to make predictions, and then update the branch history register for the predicted branch. The training interface will update the pattern history table (PHT) based on the actual branch outcome and whether the branch was a misprediction. If the branch being trained is mispredicted, we will also recover the branch history register to the state immediately after the mispredicting branch completes execution.
