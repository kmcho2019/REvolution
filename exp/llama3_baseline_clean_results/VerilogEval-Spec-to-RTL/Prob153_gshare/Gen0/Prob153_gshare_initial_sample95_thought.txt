To implement the TopModule with the specified interface and functionality, we need to follow these steps:
1. Define the module with the given interface.
2. Implement a 7-bit global branch history register and update it based on the prediction outcome.
3. Implement a 128-entry table of two-bit saturating counters (Pattern History Table, PHT) and update it based on the training inputs.
4. Use the PC and global branch history to generate a 7-bit index for the PHT by hashing (using xor) the 7-bit pc and 7-bit global history.
5. Implement the prediction logic to output the predicted branch direction and state of the branch history register used to make the prediction.
6. Implement the training logic to update the PHT and recover the branch history register if a misprediction occurs.
7. Handle the case when training and prediction of the same PHT entry happen at the same time, ensuring that the prediction sees the PHT state before training.
8. Add an asynchronous active-high reset to reset the module.
