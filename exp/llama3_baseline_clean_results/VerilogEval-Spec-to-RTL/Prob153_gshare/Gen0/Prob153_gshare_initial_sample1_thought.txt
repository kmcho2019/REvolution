To implement the TopModule with the specified interface and functionality, we need to break down the problem into several key components:
1. A 7-bit global branch history register to keep track of the branch history.
2. A 128-entry table of two-bit saturating counters (Pattern History Table, PHT) to store the branch prediction history.
3. A prediction logic to make branch direction predictions based on the current PC and branch history.
4. A training logic to update the PHT based on the actual branch outcomes.
5. A recovery mechanism to restore the branch history register to its previous state when a misprediction occurs.

The module should handle both prediction and training requests concurrently, with training taking precedence over prediction when a misprediction occurs.
