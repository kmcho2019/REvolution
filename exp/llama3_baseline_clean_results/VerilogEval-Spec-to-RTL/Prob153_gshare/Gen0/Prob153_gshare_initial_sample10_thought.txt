To implement the TopModule, we need to create a module that incorporates the following components:
1. A 7-bit global branch history register to store the history of taken branches.
2. A 128-entry table of two-bit saturating counters to store the branch prediction outcomes.
3. A prediction logic that takes the current PC and global branch history to predict the branch direction.
4. A training logic that updates the branch prediction table based on the actual branch outcome and misprediction status.
5. A recovery mechanism to restore the branch history register in case of misprediction.

The module should be sensitive to the positive edge of the clock and asynchronous active-high reset.
