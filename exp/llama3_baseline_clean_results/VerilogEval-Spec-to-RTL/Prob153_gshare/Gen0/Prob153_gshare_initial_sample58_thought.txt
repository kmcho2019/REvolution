To implement the TopModule with a gshare branch predictor, we first need to define the module interface with all the specified input and output ports. Then, we implement the internal logic of the branch predictor, including the 7-bit global branch history register and the 128-entry pattern history table (PHT). The PHT will use 7-bit pc and 7-bit global history hashed into a 7-bit index using XOR. The branch predictor will have two sets of interfaces for prediction and training. When a prediction is requested, the predictor will produce the predicted branch direction and update the branch history register at the next positive clock edge. When training is requested, the predictor will update the PHT and recover the branch history register if a misprediction occurred.
