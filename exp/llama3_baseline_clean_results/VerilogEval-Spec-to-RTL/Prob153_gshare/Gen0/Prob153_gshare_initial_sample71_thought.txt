To implement the TopModule with the specified interface, we need to design a gshare branch predictor with a 7-bit pc and 7-bit global history, hashed into a 7-bit index. The predictor uses a 128-entry table of two-bit saturating counters. The global branch history register is updated based on the predicted branch direction, and the pattern history table (PHT) is updated during training. When a misprediction occurs, the branch history register is recovered to the state after the mispredicting branch completes execution. The predictor takes precedence over prediction when training and prediction occur simultaneously.
