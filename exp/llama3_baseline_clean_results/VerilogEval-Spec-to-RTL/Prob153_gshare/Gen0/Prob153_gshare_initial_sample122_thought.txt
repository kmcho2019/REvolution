To implement the TopModule with the specified interface, we will create a module that contains the following components:
1. A 7-bit global branch history register to store the history of branch predictions.
2. A 128-entry table of two-bit saturating counters, indexed by the XOR of the 7-bit pc and the 7-bit global history.
3. Logic to handle prediction requests, which includes calculating the index into the table, reading the counter value, and determining the predicted branch direction.
4. Logic to handle training requests, which includes updating the counter value in the table and recovering the branch history register if the branch was mispredicted.
5. Asynchronous reset logic to clear the module's state when the reset signal is high.

We will use Verilog's always_ff and always_comb blocks to implement the sequential and combinational logic, respectively.
