We'll use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The index for the table will be generated by hashing the 7-bit pc and 7-bit global history using xor. We'll use two sets of interfaces for prediction and training. When a prediction is requested, we'll use the current branch history register to make the prediction and update the branch history register for the predicted branch. When training is requested, we'll update the pattern history table (PHT) based on the actual branch outcome and recover the branch history register if the branch was mispredicted.
