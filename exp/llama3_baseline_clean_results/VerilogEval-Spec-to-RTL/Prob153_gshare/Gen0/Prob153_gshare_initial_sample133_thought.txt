To implement the gshare branch predictor, we need to follow these steps:
- Create a 7-bit global branch history register to keep track of the branch history.
- Implement a 128-entry table of two-bit saturating counters to store the branch prediction history.
- When a prediction is requested, use the current PC and global branch history to generate an index into the prediction history table.
- Update the global branch history register based on the predicted branch direction.
- When training is requested, update the prediction history table entry corresponding to the given PC and branch history.
- If the branch being trained is a misprediction, recover the branch history register to the state immediately after the mispredicting branch completes execution.
- Ensure that training takes precedence over prediction when both occur in the same cycle.

We will use Verilog's always block to handle the sequential logic and assign statements for combinational logic.
