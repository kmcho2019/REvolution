To implement the TopModule, we will use a finite state machine (FSM) approach. We will have two main states: idle and predicting/training. When predict_valid is high, we enter the predicting state and use the given pc and global branch history to generate a prediction and update the global branch history register. When train_valid is high, we enter the training state and update the pattern history table (PHT) and recover the branch history register if the branch was mispredicted. We will also use combinational logic to handle the hashing of the pc and global branch history into a 7-bit index and the updating of the PHT.

We will use a 128-entry table of two-bit saturating counters to implement the PHT. Each entry in the table will correspond to a unique index generated by the hashing of the pc and global branch history.

To handle the case where training and prediction occur at the same time, we will give precedence to the training operation. This means that if a training operation is occurring in the same cycle as a prediction operation, the training operation will take precedence and update the branch history register.

We will also implement asynchronous active-high reset to reset the module when areset is high.
