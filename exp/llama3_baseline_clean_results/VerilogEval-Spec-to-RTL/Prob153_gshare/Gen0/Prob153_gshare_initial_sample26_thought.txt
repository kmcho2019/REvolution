The TopModule will be implemented as a finite state machine that responds to the predict and train interfaces. It will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters to store the branch prediction history. The module will perform the following operations:

1. On the predict interface, the module will use the 7-bit PC and global branch history to index into the prediction history table (PHT) using an XOR hash function. It will then output the predicted branch direction and the current state of the branch history register. The branch history register will be updated at the next positive clock edge for the predicted branch.

2. On the train interface, the module will update the PHT entry corresponding to the given PC and branch history register value. If the branch being trained was a misprediction, the branch history register will be recovered to the state immediately after the mispredicting branch completes execution.

3. If a prediction and a training operation occur in the same cycle, the training operation will take precedence and the branch history register will be updated accordingly.

4. If a prediction and a training operation occur for the same PHT entry in the same cycle, the prediction will see the PHT state before training, and the training operation will modify the PHT state at the next positive clock edge.

The module will also handle asynchronous active-high reset.
