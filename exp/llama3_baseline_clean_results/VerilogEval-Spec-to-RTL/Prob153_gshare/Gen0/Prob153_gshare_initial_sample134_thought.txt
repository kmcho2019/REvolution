To implement the TopModule, we need to design a gshare branch predictor with a 7-bit global history register and a 128-entry table of two-bit saturating counters. We will use the input ports to receive the prediction and training requests, and output the predicted branch direction and state of the branch history register. We will also update the pattern history table (PHT) based on the training requests. The branch history register will be updated at the next positive clock edge for the predicted branch, and recovered to the state immediately after the mispredicting branch completes execution if the branch being trained is mispredicted. We will also ensure that training takes precedence over prediction when both operations occur in the same cycle.
