To implement the gshare branch predictor, we will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The 7-bit pc and 7-bit global history are hashed (using xor) into a 7-bit index to access the table. We will have two sets of interfaces: one for doing predictions and one for doing training. The prediction interface will produce the predicted branch direction and the state of the branch history register used to make the prediction. The training interface will update the pattern history table (PHT) to train the branch predictor to predict the branch more accurately next time. If a misprediction occurs, the branch history register will be recovered to the state immediately after the mispredicting branch completes execution. We will also handle the case where training for a misprediction and a prediction for a different instruction occur in the same cycle, giving precedence to training.
