To implement the gshare branch predictor, we need to create a module with the specified interface. The module should have a 7-bit global branch history register, a 128-entry table of two-bit saturating counters, and logic to handle prediction and training requests. The prediction logic will use the current pc and global history to index into the table, retrieve the counter value, and predict the branch direction. The training logic will update the counter value based on the actual branch outcome and whether it was a misprediction. The module should also handle the case where training and prediction occur in the same cycle, giving precedence to training. Finally, the module should be reset asynchronously when areset is high.
