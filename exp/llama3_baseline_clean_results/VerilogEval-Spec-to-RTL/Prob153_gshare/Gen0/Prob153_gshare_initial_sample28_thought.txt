The TopModule will implement a gshare branch predictor with a 7-bit PC and 7-bit global history. 
The module will have two interfaces: one for predictions and one for training. 
When a prediction is requested, the module will produce the predicted branch direction and the state of the branch history register. 
The branch history register will then be updated at the next positive clock edge for the predicted branch. 
When training for a branch is requested, the module will update the pattern history table (PHT) to train the branch predictor to predict the branch more accurately next time. 
If the branch being trained is mispredicted, the module will recover the branch history register to the state immediately after the mispredicting branch completes execution. 
Training will take precedence over prediction if both operations occur in the same cycle.
