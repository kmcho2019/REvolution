To implement the TopModule, we need to follow these steps:

1. Define the module with the specified interface, including input and output ports.
2. Create a 7-bit global branch history register (ghr) to store the history of branch outcomes.
3. Implement the prediction logic: when predict_valid is high, calculate the index into the pattern history table (PHT) by hashing the pc and ghr using xor. Use this index to access the corresponding PHT entry and produce the predicted branch direction.
4. Update the ghr for the predicted branch at the next positive clock edge.
5. Implement the training logic: when train_valid is high, update the PHT entry corresponding to the train_pc and train_history. If the branch was mispredicted, recover the ghr to the state immediately after the mispredicting branch completes execution.
6. Handle the case where training and prediction of the same PHT entry occur in the same cycle, ensuring that training takes precedence.

We will use a 128-entry table of two-bit saturating counters to implement the PHT.
