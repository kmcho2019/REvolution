The TopModule should implement a gshare branch predictor with a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. 
The module should have two interfaces: one for predictions and one for training. 
When a prediction is requested, the module should produce the predicted branch direction and update the branch history register at the next positive clock edge. 
When training is requested, the module should update the pattern history table (PHT) to train the branch predictor and recover the branch history register if the branch was mispredicted. 
The module should handle cases where training and prediction occur in the same cycle, with training taking precedence. 
The module should also handle cases where training and prediction occur for the same PHT entry, with the prediction seeing the PHT state before training. 
The module should be reset asynchronously with an active-high reset signal.
