To implement the TopModule with the given interface, we will first create a 7-bit global branch history register. 
This register will be updated at each positive clock edge when a prediction is requested (predict_valid = 1) for a given pc.
The predicted branch direction and state of the branch history register used to make the prediction will be produced when a branch prediction is requested.
We will use a 128-entry table of two-bit saturating counters to store the branch prediction history.
When training for a branch is requested (train_valid = 1), the branch predictor will be told the pc and branch history register value for the branch that is being trained, 
as well as the actual branch outcome and whether the branch was a misprediction.
We will update the pattern history table (PHT) at the next positive clock edge to train the branch predictor to predict this branch more accurately next time.
If the branch being trained is mispredicted, we will also recover the branch history register to the state immediately after the mispredicting branch completes execution.
If training for a misprediction and a prediction (for a different, younger instruction) occurs in the same cycle, 
both operations will want to modify the branch history register, and training will take precedence.
We will handle the case where training and prediction of the same PHT entry happen at the same time by making the prediction see the PHT state before training.
All sequential logic will be triggered on the positive edge of the clock.
We will use asynchronous active-high reset.
