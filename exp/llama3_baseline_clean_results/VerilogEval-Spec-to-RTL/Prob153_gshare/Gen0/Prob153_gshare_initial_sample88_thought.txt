The gshare branch predictor module, TopModule, will have two main components: a global branch history register and a pattern history table (PHT). The global branch history register will keep track of the recent branch outcomes, and the PHT will store the saturating counters that are used to predict the branch direction. When a prediction is requested, the module will use the current pc and global branch history to index into the PHT and retrieve the corresponding saturating counter. The branch predictor will then update the global branch history register for the predicted branch. When training is requested, the module will use the provided pc and branch history to index into the PHT and update the corresponding saturating counter based on the actual branch outcome. If the branch was mispredicted, the module will recover the global branch history register to the state immediately after the mispredicting branch completes execution.
