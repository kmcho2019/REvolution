The branch predictor module will be implemented using a finite state machine (FSM) with two main states: prediction and training. During prediction, it uses the current global branch history and the given PC to generate a prediction and update the global branch history. During training, it uses the provided PC and branch history to update the pattern history table (PHT) based on the actual branch outcome and misprediction status. It also recovers the branch history register if a misprediction occurred.

The PHT will be implemented as a 128-entry table of two-bit saturating counters. Each entry will be accessed using a 7-bit index generated by hashing (XORing) the global branch history and the PC.

The module will prioritize training over prediction when both occur in the same cycle, ensuring that the branch history register is correctly recovered in case of a misprediction.

Asynchronous reset will be handled by resetting all internal registers and the PHT to their initial state when the areset signal is high.
