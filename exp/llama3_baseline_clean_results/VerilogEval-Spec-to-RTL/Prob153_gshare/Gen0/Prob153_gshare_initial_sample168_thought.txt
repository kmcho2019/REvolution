To implement the gshare branch predictor, we first need to create a 7-bit global branch history register. When a prediction is requested, we use the current PC and global branch history to create a 7-bit index by XORing them. This index is used to access a 128-entry table of two-bit saturating counters. The counter value at this index determines the predicted branch direction.

When training is requested, we update the pattern history table (PHT) based on the actual branch outcome and whether the branch was a misprediction. If the branch was mispredicted, we also recover the branch history register to its state immediately after the mispredicting branch completes execution.

To handle the case where training and prediction occur in the same cycle, we give precedence to training. This means that if a misprediction occurs, the branch history register is recovered first, and then the prediction is made.

We will use Verilog's asynchronous reset to reset all registers to their initial values when areset is high.
