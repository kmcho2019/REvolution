To implement the gshare branch predictor, we need to create a module named TopModule with the specified interface. The module will contain a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The predictor will use the pc and global history to generate a 7-bit index, which will access the table of counters. When a prediction is requested, the module will produce the predicted branch direction and the state of the branch history register used to make the prediction. The branch history register will be updated at the next positive clock edge for the predicted branch. When training for a branch is requested, the module will update the pattern history table (PHT) to train the branch predictor to predict the branch more accurately next time. If the branch being trained is mispredicted, the module will also recover the branch history register to the state immediately after the mispredicting branch completes execution.
