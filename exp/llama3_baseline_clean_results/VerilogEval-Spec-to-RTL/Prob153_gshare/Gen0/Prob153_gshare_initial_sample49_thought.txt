To implement the TopModule with the gshare branch predictor, we'll follow these steps:
1. Create a 7-bit global branch history register to keep track of the branch history.
2. Create a 128-entry table of two-bit saturating counters, indexed by a 7-bit index hashed from the pc and global history using xor.
3. When a prediction is requested (predict_valid = 1), use the current pc and global history to index into the table, read the counter value, and predict the branch direction based on the counter value. If the counter value is 2 or 3, predict taken. Otherwise, predict not taken.
4. Update the global branch history register at the next positive clock edge based on the predicted branch direction.
5. When training for a branch is requested (train_valid = 1), update the corresponding counter in the table based on the actual branch outcome and whether the branch was a misprediction.
6. If the branch being trained is mispredicted, recover the global branch history register to the state immediately after the mispredicting branch completes execution.
7. Handle the case where training and prediction of the same PHT entry happen at the same time, ensuring that the prediction sees the PHT state before training.
8. Implement asynchronous active-high reset to clear all registers and counters.
