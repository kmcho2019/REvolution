To implement the gshare branch predictor, we will first create a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. We will use the 7-bit pc and 7-bit global history, hashed (using xor) into a 7-bit index to access the table. When a prediction is requested, we will use the current global history register value and the given pc to generate the index, and then use the corresponding saturating counter value to determine the predicted branch direction. If the predicted branch direction is taken, we will update the global history register at the next positive clock edge. When training for a branch is requested, we will update the corresponding saturating counter value based on the actual branch outcome and whether the branch was a misprediction. If the branch being trained is mispredicted, we will also recover the global history register to the state immediately after the mispredicting branch completes execution. We will ensure that training takes precedence over prediction when both occur in the same cycle.
