To implement the gshare branch predictor, we'll first define a 7-bit global branch history register to track the branch outcomes. We'll use a 128-entry table of two-bit saturating counters to store the branch prediction history. When a prediction is requested, we'll use the current pc and global history to index into the table, and then update the history register with the predicted branch direction. When training is requested, we'll update the corresponding entry in the table based on the actual branch outcome and misprediction status, and recover the branch history register if the branch was mispredicted. We'll handle the case where training and prediction occur simultaneously by giving precedence to training.
