The TopModule will implement a gshare branch predictor with a 7-bit pc and 7-bit global history. 
It will hash the pc and global history into a 7-bit index using xor, which accesses a 128-entry table of two-bit saturating counters. 
The module will contain a 7-bit global branch history register. 
For predictions, the module will produce the predicted branch direction and the state of the branch history register used to make the prediction. 
The branch history register will be updated at the next positive clock edge for the predicted branch. 
For training, the module will be told the pc and branch history register value for the branch being trained, as well as the actual branch outcome and whether the branch was a misprediction. 
The pattern history table (PHT) will be updated to train the branch predictor to predict this branch more accurately next time. 
If the branch being trained is mispredicted, the branch history register will be recovered to the state immediately after the mispredicting branch completes execution. 
If training for a misprediction and a prediction occur in the same cycle, training will take precedence.
