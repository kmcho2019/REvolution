To implement the TopModule with the gshare branch predictor, we need to consider the following key components:

1. Global Branch History Register (GBHR): A 7-bit register that stores the history of recent branch outcomes.
2. Pattern History Table (PHT): A 128-entry table of two-bit saturating counters that stores the prediction outcomes for each index.
3. Hash Function: The index is calculated by hashing the 7-bit PC and 7-bit global history using XOR.
4. Prediction Interface: When predict_valid is high, the module produces the predicted branch direction and state of the GBHR used to make the prediction.
5. Training Interface: When train_valid is high, the module updates the PHT and GBHR based on the actual branch outcome and whether it was a misprediction.

The sequential logic is triggered on the positive edge of the clock, and the reset is asynchronous active-high.
