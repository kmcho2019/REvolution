To implement the gshare branch predictor, we need to design a module that incorporates a 7-bit global branch history register, a 128-entry table of two-bit saturating counters (pattern history table), and logic to handle predictions and training. The prediction interface should produce the predicted branch direction and state of the branch history register, while the training interface should update the pattern history table and recover the branch history register if a misprediction occurs. We will use a combination of sequential and combinatorial logic to achieve this. The sequential logic will be triggered on the positive edge of the clock, and the reset will be asynchronous active-high.
