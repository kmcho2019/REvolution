To implement the TopModule, we need to follow these steps:

1. Define the interface of the module according to the given specification.
2. Implement the global branch history register and its update logic.
3. Implement the pattern history table (PHT) and its update logic.
4. Implement the prediction logic to produce the predicted branch direction and state of the branch history register.
5. Implement the training logic to update the PHT and recover the branch history register if the branch is mispredicted.

We will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters for the PHT. The index for the PHT will be calculated by hashing the 7-bit pc and 7-bit global history using xor.

To handle the case where training and prediction of the same PHT entry happen at the same time, we will make sure that the prediction sees the PHT state before training.
