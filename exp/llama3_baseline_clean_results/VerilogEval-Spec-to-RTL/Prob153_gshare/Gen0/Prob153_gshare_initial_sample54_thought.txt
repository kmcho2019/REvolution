To implement the TopModule, we need to design a gshare branch predictor with a 7-bit pc and 7-bit global history, hashed into a 7-bit index. This index accesses a 128-entry table of two-bit saturating counters. The branch predictor will contain a 7-bit global branch history register. The module will have two sets of interfaces: one for doing predictions and one for doing training.

The prediction interface will be used to ask the branch predictor for branch direction predictions for the instructions being fetched. The branch history register will be updated at the next positive clock edge for the predicted branch.

The training interface will be used to train the branch predictor using the actual branch direction outcomes. The pattern history table (PHT) will be updated to train the branch predictor to predict this branch more accurately next time. If the branch being trained is mispredicted, the branch history register will be recovered to the state immediately after the mispredicting branch completes execution.

To handle the case where training for a misprediction and a prediction (for a different, younger instruction) occurs in the same cycle, training will take precedence, because the branch being predicted will be discarded anyway.

The PHT entry state will be updated at the next positive clock edge, so if training and prediction of the same PHT entry happen at the same time, the prediction will see the PHT state before training.

We will use a reg array to implement the PHT, and a reg to implement the global branch history register. We will use the always @(posedge clk) block to update the PHT and the global branch history register.
