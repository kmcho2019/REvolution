To implement the TopModule, we need to follow these steps:
- Create a 7-bit global branch history register and update it based on the predicted branch direction and training information.
- Design a 128-entry table of two-bit saturating counters, indexed by the hashed PC and global history.
- Implement the prediction logic to produce the predicted branch direction and state of the branch history register.
- Implement the training logic to update the pattern history table (PHT) and recover the branch history register if necessary.

We will use a combination of combinational and sequential logic to achieve this.
