To implement the gshare branch predictor, we will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The 7-bit pc and 7-bit global history will be hashed using xor into a 7-bit index to access the table. We will use two interfaces, one for prediction and one for training. The prediction interface will produce the predicted branch direction and state of the branch history register used to make the prediction. The training interface will update the pattern history table (PHT) to train the branch predictor to predict the branch more accurately next time. We will also recover the branch history register to the state immediately after the mispredicting branch completes execution if the branch being trained is mispredicted.
