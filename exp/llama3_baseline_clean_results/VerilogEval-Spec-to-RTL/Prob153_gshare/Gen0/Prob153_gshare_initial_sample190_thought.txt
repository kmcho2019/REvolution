To implement the TopModule with the given specifications, we need to create a module that contains the following components:
1. A 7-bit global branch history register.
2. A 128-entry table of two-bit saturating counters (Pattern History Table, PHT).
3. A prediction interface that takes in the pc, generates a prediction, and updates the global branch history register.
4. A training interface that updates the PHT and recovers the global branch history register in case of a misprediction.
We will use Verilog to implement the module, using a combination of combinational and sequential logic to meet the specified requirements.
