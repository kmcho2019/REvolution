To implement the TopModule, we will first declare the inputs and outputs as specified. We will then implement the gshare branch predictor using a 128-entry table of two-bit saturating counters. The global branch history register will be implemented as a 7-bit register. We will use two separate processes: one for prediction and one for training. The prediction process will produce the predicted branch direction and state of the branch history register used to make the prediction. The training process will update the pattern history table (PHT) based on the actual branch outcome and whether the branch was a misprediction. We will also handle the case where training for a misprediction and a prediction occur in the same cycle, giving precedence to training. Finally, we will reset the module asynchronously on the high level of the areset signal.
