The TopModule will implement a gshare branch predictor that uses a 7-bit global history register and a 128-entry table of two-bit saturating counters. When a prediction is requested, the module will produce the predicted branch direction and update the global history register at the next positive clock edge. When training is requested, the module will update the pattern history table (PHT) to train the branch predictor to predict the branch more accurately next time. If a misprediction occurs, the module will recover the global history register to the state immediately after the mispredicting branch completes execution. The module will handle cases where training and prediction occur in the same cycle, with training taking precedence over prediction.
