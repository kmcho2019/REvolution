To implement the TopModule, we will first define the internal signals and registers required for the gshare branch predictor. We will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The index for the table will be calculated by hashing the 7-bit pc and 7-bit global history using XOR. We will then implement the prediction and training logic according to the given specifications. The prediction logic will produce the predicted branch direction and update the branch history register. The training logic will update the pattern history table (PHT) and recover the branch history register if a misprediction occurs. We will also handle the cases where training and prediction occur in the same cycle.
