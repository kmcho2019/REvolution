To implement the gshare branch predictor, we need to create a module with the specified interface. The predictor will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters, indexed by the hashed PC and global history. When a prediction is requested, the predictor will use the current global history and PC to index into the table and produce a prediction. The global history will then be updated for the predicted branch. When a training request is received, the predictor will update the corresponding table entry based on the actual branch outcome and recover the global history if the branch was mispredicted.
