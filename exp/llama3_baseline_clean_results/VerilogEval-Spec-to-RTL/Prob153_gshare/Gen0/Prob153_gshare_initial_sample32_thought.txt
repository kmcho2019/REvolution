The TopModule should implement a gshare branch predictor with the given specifications. 
It will have two main interfaces: prediction and training. 
The prediction interface will be used to make branch predictions, while the training interface will be used to update the predictor based on the actual branch outcomes.
The predictor will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters to make predictions.
When a prediction is requested, the predictor will use the current global history and the pc to index into the table and make a prediction.
The global history will be updated at the next positive clock edge based on the predicted branch direction.
When training is requested, the predictor will update the table entry corresponding to the pc and global history of the branch being trained.
If the branch was mispredicted, the global history will be recovered to the state immediately after the mispredicting branch completes execution.
The predictor will also handle cases where training and prediction occur in the same cycle, with training taking precedence.
The module will be reset asynchronously with the areset signal.
