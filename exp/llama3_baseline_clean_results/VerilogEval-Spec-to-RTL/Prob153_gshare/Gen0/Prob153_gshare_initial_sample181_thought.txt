To implement the TopModule with a gshare branch predictor, we will need to create the following components:
1. A 7-bit global branch history register (ghr) to keep track of the branch history.
2. A 128-entry table of two-bit saturating counters (PHT) to store the branch prediction outcomes.
3. A hashing function to map the 7-bit pc and 7-bit global history into a 7-bit index for the PHT.
4. Logic to handle prediction requests, including updating the ghr and producing the predicted branch direction.
5. Logic to handle training requests, including updating the PHT and recovering the ghr if the branch was a misprediction.

The module will be implemented using Verilog, with the specified input and output ports. The design will be sensitive to the positive edge of the clock and will handle asynchronous active-high reset.
