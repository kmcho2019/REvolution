To implement the TopModule, we will first define the internal signals and registers needed for the gshare branch predictor. We will use a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The index for the table will be generated by hashing the 7-bit pc and 7-bit global history using xor.

The prediction interface will use the current state of the branch history register and the pattern history table (PHT) to make predictions. When a prediction is requested, the branch predictor will produce the predicted branch direction and the state of the branch history register used to make the prediction.

The training interface will update the PHT and the branch history register based on the actual branch outcome and whether the branch was a misprediction. If the branch being trained is mispredicted, the branch history register will be recovered to the state immediately after the mispredicting branch completes execution.

We will use asynchronous reset to clear the internal registers when areset is high.
