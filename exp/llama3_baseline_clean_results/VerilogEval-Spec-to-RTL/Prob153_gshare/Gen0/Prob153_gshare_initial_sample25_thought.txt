To implement the TopModule, we will use a finite state machine (FSM) that interacts with a pattern history table (PHT). The PHT is a 128-entry table where each entry contains a 2-bit saturating counter. The FSM will handle the prediction and training interfaces. For prediction, it will use the provided PC and global branch history to generate an index into the PHT, and then use the value from the PHT to determine the branch prediction. After prediction, the global branch history will be updated based on the prediction. For training, the FSM will update the corresponding entry in the PHT based on the actual branch outcome and whether the branch was a misprediction. If a misprediction occurred, the global branch history will be recovered to its state immediately after the mispredicting branch completed execution. The FSM will also handle the case where training and prediction occur in the same cycle, ensuring that training takes precedence.
