To implement the gshare branch predictor, we will use a 128-entry table of two-bit saturating counters, where each entry is indexed by a 7-bit index generated by hashing the 7-bit pc and 7-bit global branch history using xor. The predictor has two main components: prediction and training. 

For prediction, when a request is made (predict_valid = 1), the predictor generates the predicted branch direction based on the current state of the PHT entry and the global branch history register, and updates the global branch history register for the predicted branch at the next positive clock edge.

For training, when a request is made (train_valid = 1), the predictor updates the corresponding PHT entry based on the actual branch outcome and whether the branch was mispredicted. If the branch was mispredicted, the predictor also recovers the global branch history register to the state immediately after the mispredicting branch completes execution.

To handle cases where training and prediction occur in the same cycle, we give precedence to training operations and ensure that the prediction sees the PHT state before training. We use asynchronous reset to initialize all registers and the PHT table.
