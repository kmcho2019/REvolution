To implement the TopModule, we need to follow these steps:
1. Define the module interface and ports.
2. Create a 7-bit global branch history register.
3. Implement the 128-entry table of two-bit saturating counters (Pattern History Table, PHT).
4. Define the logic for hashing the 7-bit PC and 7-bit global history into a 7-bit index using XOR.
5. Implement the prediction logic, which uses the hashed index to access the PHT and make a prediction based on the counter value.
6. Implement the training logic, which updates the PHT based on the actual branch outcome and whether the branch was a misprediction.
7. Handle the case where a misprediction is being trained and a prediction is requested in the same cycle, giving precedence to the training operation.
8. Handle the reset logic to reset the PHT and global branch history register when the asynchronous active-high reset is asserted.
