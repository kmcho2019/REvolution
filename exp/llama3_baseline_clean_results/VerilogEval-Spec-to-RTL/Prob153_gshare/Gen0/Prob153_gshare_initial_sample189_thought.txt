The TopModule will implement a GShare branch predictor. It will have a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. The module will use the input predict_valid to determine when to make a prediction, and the input train_valid to determine when to train the branch predictor. The prediction interface will use the input predict_pc and the current global branch history to index into the pattern history table (PHT) and make a prediction. The branch history register will then be updated at the next positive clock edge for the predicted branch. The training interface will use the input train_pc, train_history, train_taken, and train_mispredicted to update the PHT entry at the next positive clock edge. If the branch being trained was mispredicted, the branch history register will be recovered to the state immediately after the mispredicting branch completes execution.
