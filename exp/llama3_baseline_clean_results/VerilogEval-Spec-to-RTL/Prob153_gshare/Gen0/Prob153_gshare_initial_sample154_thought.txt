To implement the TopModule, we need to design a gshare branch predictor with 7-bit pc and 7-bit global history. We'll use a 128-entry table of two-bit saturating counters, accessed by a 7-bit index hashed (using xor) from the pc and global history. The predictor will have two interfaces: one for predictions and one for training. The prediction interface will produce the predicted branch direction and state of the branch history register, while the training interface will update the pattern history table (PHT) based on the actual branch outcome. We'll use a 7-bit global branch history register and ensure that training takes precedence over prediction when both occur in the same cycle.
