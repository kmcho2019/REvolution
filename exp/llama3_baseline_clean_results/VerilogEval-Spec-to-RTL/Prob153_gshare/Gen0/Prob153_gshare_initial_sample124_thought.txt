To implement the TopModule with a gshare branch predictor, we'll need to follow these steps:
- Implement a global branch history register (ghr) to store the 7-bit global branch history.
- Calculate the index for the pattern history table (PHT) by hashing the pc and ghr using XOR.
- Implement the PHT as a 128-entry table of two-bit saturating counters.
- Update the PHT and ghr based on prediction and training requests.
- Handle the case where training and prediction occur in the same cycle.
- Implement asynchronous reset for all sequential logic.

The module will have two main components: prediction and training. 
For prediction, we'll use the current pc and ghr to calculate the PHT index, read the corresponding PHT entry, and produce the predicted branch direction.
For training, we'll update the PHT entry based on the actual branch outcome and update the ghr if the branch was mispredicted.
