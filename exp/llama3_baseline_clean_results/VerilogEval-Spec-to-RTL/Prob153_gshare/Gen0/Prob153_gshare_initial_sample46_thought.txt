To implement the TopModule, we need to follow these steps:
1. Create a 128-entry table (Pattern History Table, PHT) of two-bit saturating counters.
2. Implement a 7-bit global branch history register.
3. Handle the prediction interface:
   - When a branch prediction is requested, use the PC and global branch history to generate the index for the PHT.
   - Use the index to access the corresponding counter in the PHT and produce the predicted branch direction.
   - Update the global branch history register at the next positive clock edge for the predicted branch.
4. Handle the training interface:
   - When training for a branch is requested, use the PC and branch history to generate the index for the PHT.
   - Update the corresponding counter in the PHT based on the actual branch outcome and whether the branch was a misprediction.
   - If the branch being trained is a misprediction, recover the global branch history register to the state immediately after the mispredicting branch completes execution.
5. Ensure that training takes precedence over prediction when both occur in the same cycle.
6. Implement asynchronous active-high reset.
