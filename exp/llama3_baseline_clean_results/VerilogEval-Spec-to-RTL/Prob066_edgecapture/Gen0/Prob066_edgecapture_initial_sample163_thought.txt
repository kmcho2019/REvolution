To solve this problem, we can use a 32-bit register to store the output and a 32-bit register to store the previous input. On every clock cycle, we compare the current input with the previous input. If any bit in the current input is 0 and the corresponding bit in the previous input is 1, we set the corresponding bit in the output register to 1. The output register is only reset when the reset signal is high. This approach ensures that once a transition from 1 to 0 is detected, the corresponding output bit remains 1 until the register is reset.
