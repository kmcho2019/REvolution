The TopModule should have a 32-bit register to store the captured bits. 
It should also have a 32-bit register to store the previous input values. 
On every positive edge of the clock, it should compare the current input 
with the previous input to check for transitions from 1 to 0, and if such 
a transition is found, it should set the corresponding bit in the output 
register. The output register should be reset when the reset signal is high.
