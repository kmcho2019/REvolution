The module TopModule should have a 32-bit register to store the output, and another 32-bit register to store the previous state of the input. On every clock cycle, it should compare the current input with the previous state. If the current input is 0 and the previous state is 1, it should set the corresponding bit in the output register to 1. The output register should remain unchanged until the reset signal is asserted high. On reset, the output register should be reset to zero.
