The TopModule should have a 32-bit register to store the captured output. 
On every positive edge of the clock, the module should check each bit of the input 
and compare it with the corresponding bit in the previous input. 
If the bit in the previous input is 1 and the current bit is 0, the module 
should set the corresponding bit in the output register to 1. 
The output register should remain unchanged until a reset is applied.
To keep track of the previous input, another 32-bit register is needed.
