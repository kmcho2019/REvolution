The TopModule will have an internal 32-bit register to store the captured bits. 
On each positive edge of the clock, it will check the input bits and compare them 
with the previous bits (which can be obtained by using another internal register 
to store the previous input). If a bit has changed from 1 to 0, the corresponding 
bit in the output register will be set to 1. If the reset signal is asserted, the 
output register will be reset to 0. The output of the module will be the output 
register itself.
