The TopModule should have a register to hold the current and previous state of the input vector. On each clock cycle, it should compare the current input vector with the previous one to detect any change from 1 to 0. If a change is detected, it should set the corresponding bit in the output register to 1. The output register should remain unchanged until a reset is applied. We will use two 32-bit registers to store the current and previous input vectors, and a 32-bit register to store the output.
