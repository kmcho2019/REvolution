The module TopModule should have a register to hold the output value. On each positive clock edge, we compare the current input value with the previous input value (which can be stored in a separate register). If the previous input value is 1 and the current input value is 0, we set the output register to 1. If the reset signal is high, we clear the output register to 0. We can use two always blocks, one for the input register and one for the output logic.
