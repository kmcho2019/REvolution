To implement the TopModule with a shift register, we will use four D flip-flops. Each D flip-flop will have a data input (in) and a clock input (clk), and the output of one flip-flop will be connected to the data input of the next flip-flop. The resetn input will be used to reset the flip-flops. The reset will be synchronous, meaning it will only be applied on the positive edge of the clock.
