To implement a 4-stage shift register with D flops in Verilog, we can use a single always block that updates the state of the register on every positive edge of the clock signal. We will also handle the synchronous reset condition by checking the resetn signal within the always block. If resetn is low, we reset the state of the register to zero. Otherwise, on every clock edge, we shift the input into the first stage and propagate the previous stage's output to the next stage.
