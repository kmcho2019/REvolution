To implement a shift register with four D flops, we need to design a module with a chain of four D flip-flops. Each D flip-flop will have a data input, a clock input, and a reset input. The data output of each flip-flop will be connected to the data input of the next flip-flop in the chain, effectively creating a shift register. The reset input will be used to clear the contents of all flip-flops when the reset signal is asserted low. We will use the built-in Verilog `always` block to describe the sequential behavior of the flip-flops.
