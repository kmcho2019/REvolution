To implement the TopModule, we will design a shift register with four D flip-flops. The module will have a positive edge triggered clock, an active-low synchronous reset, and one-bit input and output ports. The shift register will shift the input data one position to the right on each positive edge of the clock, and the output will be the value of the last flip-flop in the chain. We will use the always @(posedge clk) block to model the sequential behavior of the flip-flops, and we will use non-blocking assignments to update the state of the flip-flops.
