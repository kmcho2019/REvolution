To implement a 4-stage shift register using D flops with a synchronous active-low reset, we can instantiate four D flip-flops in series. The input to each D flop (except the first one) will be the output of the previous flop, and the output of the last flop will be the final output of the shift register. Each flop should be triggered on the positive edge of the clock and should reset when the resetn signal is low. This ensures that when resetn is low, all flops reset to 0, effectively clearing the shift register.
