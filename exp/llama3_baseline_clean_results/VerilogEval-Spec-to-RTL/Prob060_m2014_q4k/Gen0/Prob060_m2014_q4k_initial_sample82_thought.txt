To implement the shift register, we will use four D flip-flops connected in series. Each D flip-flop will have a data input, a clock input, and a reset input. The clock input will be connected to the positive edge of the clock signal, and the reset input will be connected to the active-low reset signal. The data input of the first flip-flop will be connected to the input signal, and the data input of each subsequent flip-flop will be connected to the output of the previous flip-flop. The output of the module will be the output of the last flip-flop.
