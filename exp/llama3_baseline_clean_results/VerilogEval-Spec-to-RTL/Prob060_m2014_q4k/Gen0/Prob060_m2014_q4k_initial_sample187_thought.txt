We'll use four D flip-flops, each with a synchronous active-low reset. The data input (in) will be connected to the D input of the first flip-flop. The Q output of each flip-flop will be connected to the D input of the next flip-flop, effectively creating a shift register. The output (out) will be the Q output of the last flip-flop.
