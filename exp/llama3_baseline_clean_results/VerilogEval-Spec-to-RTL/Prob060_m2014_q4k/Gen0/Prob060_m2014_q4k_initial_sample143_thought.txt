To implement the TopModule with the specified interface, we need to design a shift register using four D flip-flops (DFFs) that are triggered on the positive edge of the clock. The module will have an active-low synchronous reset. When resetn is low, the output of all DFFs should be reset to 0. When resetn is high, the input 'in' should be shifted through the four DFFs on each positive clock edge. The output 'out' should be the value of the last DFF.
