To implement a shift register with four D flops, we can use a chain of four D flip-flops. Each flip-flop will have a data input (D), a clock input (clk), and an active-low reset input (resetn). The data input of the first flip-flop will be connected to the input port (in), and the data output of the fourth flip-flop will be connected to the output port (out). The clock and reset inputs of all flip-flops will be connected to the clk and resetn ports, respectively. On the positive edge of the clock, each flip-flop will capture its input data and shift it to the next flip-flop, effectively creating a shift register. The synchronous reset will reset all flip-flops to zero when resetn is low.
