To implement the TopModule with the specified interface, we will create a module that contains four D flip-flops connected in series, forming a shift register. Each D flip-flop will be triggered on the positive edge of the clock (clk) and will have a synchronous active-low reset (resetn). The input (in) will be connected to the first D flip-flop, and the output (out) will be connected to the last D flip-flop. The data will shift from the input to the output through the flip-flops on each positive clock edge when the resetn is high.
