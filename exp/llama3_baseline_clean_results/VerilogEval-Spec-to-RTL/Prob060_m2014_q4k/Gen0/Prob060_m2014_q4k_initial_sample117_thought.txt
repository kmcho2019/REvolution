To implement the TopModule as described, we need to create a module with the specified inputs and outputs. We will use four D-flip flops connected in series to create the shift register. Each D-flip flop will be triggered on the positive edge of the clock and will have a synchronous active-low reset. When the reset signal is asserted (i.e., resetn is 0), all the flip flops will reset to 0, effectively clearing the shift register. The input in will be shifted through the register on each clock cycle, with the output out being the value of the last flip flop in the chain.
