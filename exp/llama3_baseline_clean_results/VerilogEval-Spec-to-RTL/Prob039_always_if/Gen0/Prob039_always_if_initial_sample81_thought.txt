To implement the 2-to-1 multiplexer as required, we can use two different approaches in the same module: 
1. Continuous assignment (using `assign` statement) to create `out_assign`. 
2. Procedural assignment (using `always` block and `if` statement) to create `out_always`.

For the `assign` statement, we can directly use a conditional operator (`?:`) to choose between `a` and `b` based on the conditions provided by `sel_b1` and `sel_b2`.

For the `always` block, we will use an `if` statement to check the conditions and assign the value to `out_always` accordingly.
