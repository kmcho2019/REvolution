To implement the 2-to-1 mux, we need to use both continuous assignment and a procedural assignment. 
For the continuous assignment, we can use the ternary operator to choose between a and b based on the select signals. 
For the procedural assignment, we can use an if statement inside an always block to make the same choice. 
In both cases, we will choose b if both sel_b1 and sel_b2 are true, and choose a otherwise.
