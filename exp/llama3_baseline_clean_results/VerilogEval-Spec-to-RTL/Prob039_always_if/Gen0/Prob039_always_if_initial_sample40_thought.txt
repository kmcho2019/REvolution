To implement the 2-to-1 mux, we will use two different methods as required. 
Firstly, we'll use the assign statement for continuous assignment, which is 
more concise and efficient for combinational logic. This will drive the 
out_assign output.
Secondly, we'll use an always block with a procedural if statement to 
achieve the same result. This will drive the out_always output.
In both cases, the logic will be based on the selection inputs sel_b1 and 
sel_b2, choosing 'b' when both are true and 'a' otherwise.
