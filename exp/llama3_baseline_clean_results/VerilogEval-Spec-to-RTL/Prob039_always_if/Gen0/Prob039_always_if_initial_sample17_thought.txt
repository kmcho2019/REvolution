The TopModule can be implemented with two separate methods for creating a 2-to-1 multiplexer. 
First, we use the assign statement to continuously evaluate the conditions and assign the value to out_assign. 
This will be done by using the ternary operator to choose between 'a' and 'b' based on the conditions of sel_b1 and sel_b2. 
Second, we use an always block to implement the same functionality procedurally. 
Inside the always block, we will use an if statement to check the conditions and assign the value to out_always.
