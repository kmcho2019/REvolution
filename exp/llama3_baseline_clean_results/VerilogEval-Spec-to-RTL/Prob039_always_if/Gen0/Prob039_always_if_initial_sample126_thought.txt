To implement the 2-to-1 mux, we will use the provided select signals (sel_b1 and sel_b2) to control the output of the multiplexer. If both sel_b1 and sel_b2 are true, the multiplexer will output 'b'; otherwise, it will output 'a'. We will implement this logic twice: once using continuous assignment and once using a procedural assignment within an always block.
