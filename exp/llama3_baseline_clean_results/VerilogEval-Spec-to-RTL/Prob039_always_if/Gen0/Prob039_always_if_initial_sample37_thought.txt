To implement the 2-to-1 mux using assign statements, we can utilize the ternary operator in Verilog. This operator allows for a concise way to express conditional logic. The expression `sel_b1 && sel_b2 ? b : a` directly implements the required logic, choosing `b` when both `sel_b1` and `sel_b2` are true and `a` otherwise.

For the implementation using a procedural if statement, we'll use an always block. Inside this block, we'll check the condition of `sel_b1` and `sel_b2`, and then assign the value of either `a` or `b` to the output based on the condition.
