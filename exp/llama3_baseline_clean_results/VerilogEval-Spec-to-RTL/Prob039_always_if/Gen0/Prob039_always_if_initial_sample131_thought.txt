To implement the 2-to-1 mux, we will first use continuous assignment statements to implement the combinational logic. The `out_assign` will be assigned the value of `a` when either `sel_b1` or `sel_b2` is false. Otherwise, it will be assigned the value of `b`.

For the procedural implementation, we will use an `always` block to implement the same logic using a procedural `if` statement. The `out_always` will be assigned the value of `a` or `b` based on the same conditions as before.
