The module TopModule will be implemented with two separate methods to achieve the 2-to-1 multiplexer functionality. 
The first method uses a continuous assign statement to implement the multiplexer logic. 
The second method uses a procedural if statement within an always block to achieve the same functionality. 
In both cases, the output will be 'b' if both sel_b1 and sel_b2 are true, and 'a' otherwise.
