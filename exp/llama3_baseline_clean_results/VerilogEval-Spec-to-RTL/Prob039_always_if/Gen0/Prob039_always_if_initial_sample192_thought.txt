To implement the TopModule as described, we'll use two separate approaches: one using continuous assignment with logic operators, and the other using a procedural block within an always statement.

For the assign statement approach, we can directly implement the logic using the ternary operator, which checks the conditions and assigns the output accordingly. 

For the always block approach, we'll use an if statement inside an always block to achieve the same logic. The always block is sensitive to changes in any of the input signals (a, b, sel_b1, sel_b2) to ensure the output is updated whenever necessary.
