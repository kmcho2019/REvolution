To implement the 2-to-1 mux using assign statements, we can use a conditional operator (also known as a ternary operator) to choose between a and b based on the values of sel_b1 and sel_b2.

For the procedural if statement, we can use an always block to continuously evaluate the inputs and update the output accordingly. We will use an if statement inside the always block to make the choice between a and b based on the conditions.

We will implement both methods in the same module, TopModule, with separate outputs for each method: out_assign for the assign statement method and out_always for the procedural if statement method.
