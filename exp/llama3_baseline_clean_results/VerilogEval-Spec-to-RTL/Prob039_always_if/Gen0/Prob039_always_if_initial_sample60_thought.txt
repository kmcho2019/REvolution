To solve this problem, we can implement a 2-to-1 multiplexer (mux) using both continuous assignment and a procedural block. The mux will choose between inputs 'a' and 'b' based on the values of 'sel_b1' and 'sel_b2'. If both 'sel_b1' and 'sel_b2' are true (1), the mux should output 'b'; otherwise, it should output 'a'. We will use an assign statement for continuous assignment and an always block for the procedural approach.
