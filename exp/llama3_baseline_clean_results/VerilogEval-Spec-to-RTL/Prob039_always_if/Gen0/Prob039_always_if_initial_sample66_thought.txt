To implement the 2-to-1 mux as specified, we will use two separate methods: 
1. Continuous assignment using the assign statement.
2. Procedural assignment using an always block with an if statement.
In both cases, the mux will choose input 'a' unless both sel_b1 and sel_b2 are true, in which case it will choose input 'b'.
For the continuous assignment, we will use the ternary operator to directly assign the output based on the condition.
For the procedural assignment, we will use an if statement inside an always block to assign the output based on the condition.
