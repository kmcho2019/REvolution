To implement the 2-to-1 multiplexer (mux) as described, we can use both continuous assignment and procedural assignment in Verilog. 
For the continuous assignment, we'll use an assign statement with a conditional operator (?:) to choose between inputs a and b based on the select lines sel_b1 and sel_b2.
For the procedural assignment, we'll use an always block with an if statement to achieve the same logic but with a different syntax. 
The output of both implementations should be the same, where 'b' is chosen when both select lines are high, and 'a' is chosen otherwise.
