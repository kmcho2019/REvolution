The TopModule will be implemented with two different approaches: 
1. Using continuous assignment statements: We will use the ternary operator 
to implement the 2-to-1 mux. This will directly assign the value of 'a' or 'b' 
to the output 'out_assign' based on the conditions.

2. Using a procedural if statement: This will involve using an always block 
and an if statement to check the conditions. If both 'sel_b1' and 'sel_b2' 
are true, then 'b' will be assigned to 'out_always'. Otherwise, 'a' will be 
assigned to 'out_always'.
