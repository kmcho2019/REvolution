To implement the 2-to-1 multiplexer using both `assign` statements and a procedural `if` statement in Verilog, we first need to understand the logic of a 2-to-1 multiplexer. The multiplexer chooses between two input lines (in this case, `a` and `b`) based on a select input. Here, we have two select inputs, `sel_b1` and `sel_b2`, and we choose `b` if both are true; otherwise, we choose `a`.

For the combinational logic (using `assign`), we can express this logic directly with a conditional operator. This is straightforward and directly implements the multiplexer's logic in a continuous assignment.

For the procedural logic (using `always` block with `if` statement), we need to specify the sensitivity list and then use an `if` statement inside the block to implement the same logic. The `if` statement will check the conditions based on `sel_b1` and `sel_b2` and assign the appropriate value to `out_always`.
