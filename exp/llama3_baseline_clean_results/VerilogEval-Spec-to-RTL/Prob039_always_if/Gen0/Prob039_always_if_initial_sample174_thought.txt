To implement the 2-to-1 mux using assign statements, we can use the conditional operator to directly assign the value of 'a' or 'b' to 'out_assign' based on the values of 'sel_b1' and 'sel_b2'. For the procedural if statement, we can use an always block to continuously evaluate the condition and assign the appropriate value to 'out_always'. We will use a non-blocking assignment to assign the value to 'out_always' in the always block to prevent race conditions.
