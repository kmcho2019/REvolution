To implement the required 2-to-1 multiplexer, we will first use the continuous assignment statement to directly express the condition for choosing between inputs 'a' and 'b' based on the select lines 'sel_b1' and 'sel_b2'. For the procedural implementation, we will use an 'always' block with an 'if' statement to achieve the same logic.
