To implement the 2-to-1 mux, we can use the assign statement with a conditional operator to directly assign the value of 'a' or 'b' to the output 'out_assign' based on the selection signals 'sel_b1' and 'sel_b2'. For the procedural if statement, we can use an always block to continuously evaluate the condition and assign the corresponding value to 'out_always'. In both cases, we choose 'b' if both 'sel_b1' and 'sel_b2' are true; otherwise, we choose 'a'.
