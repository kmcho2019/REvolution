To implement the required 2-to-1 mux functionality, we will use both continuous assignment and procedural assignment. The continuous assignment will directly drive the output `out_assign` based on the condition that checks `sel_b1` and `sel_b2`. If both are high, `b` is chosen; otherwise, `a` is chosen. For the procedural assignment, we will use an `always` block with a conditional statement to drive `out_always` based on the same logic.
