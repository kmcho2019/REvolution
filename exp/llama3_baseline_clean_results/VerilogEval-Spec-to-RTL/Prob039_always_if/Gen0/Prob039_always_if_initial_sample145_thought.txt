To implement the 2-to-1 mux as described, we will use two methods: 
1. Continuous assignment using the assign statement, where the output is 
   directly assigned based on the inputs and control signals. 
2. Procedural assignment using an always block, where an if statement 
   controls the output based on the conditions provided.

For both methods, the condition to choose 'b' is when both sel_b1 and sel_b2 
are true (i.e., sel_b1 && sel_b2). If this condition is not met, 'a' is chosen.
