The TopModule will implement a finite state machine with three D flip-flops, each connected to a different two-input gate (XOR, AND, OR). The outputs of these gates are connected to the inputs of the D flip-flops, and the outputs of the D flip-flops are connected to a three-input NOR gate. The second inputs of the XOR, AND, and OR gates will be the current state of the corresponding flip-flops. The NOR gate will produce the output Z. 
We will use Verilog's reg data type to declare the flip-flop outputs and the outputs of the gates. We will use the always block to define the combinational logic and the sequential logic. The sequential logic will be triggered on the positive edge of the clock using the posedge keyword.
