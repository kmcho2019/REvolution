The TopModule should be implemented as a finite state machine with three D flip-flops. Each D flip-flop is connected to a different two-input gate (XOR, AND, and OR). The second input of each gate is connected to the output of its corresponding D flip-flop, with the OR and AND gates using the complemented output. The outputs of the three D flip-flops are connected to a three-input NOR gate, which produces the output z. The module should be triggered on the positive edge of the clock.
