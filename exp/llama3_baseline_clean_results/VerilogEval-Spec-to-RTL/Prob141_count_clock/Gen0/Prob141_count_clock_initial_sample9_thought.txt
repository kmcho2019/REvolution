To implement the 12-hour clock module, we will use separate counters for hours, minutes, and seconds. Each counter will be responsible for tracking its respective time unit. The seconds counter will increment once per second when ena is high. When the seconds counter reaches 59, it will wrap around to 0 and the minutes counter will increment. Similarly, when the minutes counter reaches 59, it will wrap around to 0 and the hours counter will increment. The hours counter will also handle AM/PM logic. If the hours counter exceeds 12, we will set pm high. When reset is asserted, all counters will be reset to their initial values (hours = 12, minutes = 0, seconds = 0, and pm = 0 for AM).
