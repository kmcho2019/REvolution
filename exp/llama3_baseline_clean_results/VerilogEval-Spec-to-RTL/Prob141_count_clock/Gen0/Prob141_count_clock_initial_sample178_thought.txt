To implement the 12-hour clock module (TopModule), we will use a set of counters for hours, minutes, and seconds. 
These counters will be incremented based on the enable signal (ena), which pulses once per second. 
The clock will be reset to "12:00 AM" when the reset signal is asserted. 
The hours, minutes, and seconds counters will be implemented as BCD counters with the appropriate range limits (01-12 for hours, 00-59 for minutes and seconds).
We will use a separate signal to track whether the clock is in AM or PM mode.
