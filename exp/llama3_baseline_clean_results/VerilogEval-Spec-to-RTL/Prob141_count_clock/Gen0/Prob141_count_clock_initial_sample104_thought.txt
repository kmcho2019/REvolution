To implement the TopModule for a 12-hour clock, we'll create separate counters for hours, minutes, and seconds. Each counter will be designed to wrap around at its maximum value (12 for hours, 59 for minutes and seconds). We'll also implement the AM/PM indicator based on the hour value. The counters will be clocked by the fast-running clk signal and will only increment when the ena signal is high. The reset signal will be used to reset the clock to "12:00 AM" whenever it's asserted. We'll use the always_ff statement to describe the sequential logic triggered on the positive edge of the clock.
