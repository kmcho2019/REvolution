To implement the 12-hour clock, we'll create separate counters for hours, minutes, and seconds. Each counter will be able to handle BCD (Binary-Coded Decimal) digits. We'll use the enable signal (ena) to increment the counters once per second. The clock will be reset to "12:00 AM" when the reset signal is high. We'll also include logic to determine whether the clock should display AM or PM based on the hour.
