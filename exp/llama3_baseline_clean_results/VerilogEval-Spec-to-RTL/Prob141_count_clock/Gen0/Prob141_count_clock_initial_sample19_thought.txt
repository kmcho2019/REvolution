To implement a 12-hour clock, we need to design a set of counters for hours, minutes, and seconds. 
We will use two BCD digits for each counter. 
When the 'ena' signal is asserted, we will increment the seconds counter. 
If the seconds counter reaches 59, we reset it to 00 and increment the minutes counter. 
If the minutes counter reaches 59, we reset it to 00 and increment the hours counter. 
If the hours counter reaches 12, we reset it to 01 and toggle the 'pm' signal. 
The 'reset' signal will reset all counters to their initial values when asserted.
