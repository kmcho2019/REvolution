To implement the 12-hour clock with am/pm indicator, we'll create separate counters for hours, minutes, and seconds. Each counter will be designed to handle Binary-Coded Decimal (BCD) digits. The seconds counter will increment every time ena is high, and when it reaches 59, it will reset and increment the minutes counter. Similarly, when the minutes counter reaches 59, it will reset and increment the hours counter. The hours counter will handle the 12-hour cycle and update the pm indicator accordingly. The reset signal will asynchronously reset all counters to their initial states. We'll use always blocks to define the sequential logic for the counters and the pm indicator.
