To implement a 12-hour clock with counters for hours, minutes, and seconds, we need to create three counters and a mechanism to increment them at the correct times. The seconds counter should increment once per second, the minutes counter should increment once per minute, and the hours counter should increment once per hour. We also need to handle the AM/PM indicator based on the hour. The counters should be reset to "12:00 AM" when the reset signal is high. We will use if-else statements to handle the reset and enable logic.
