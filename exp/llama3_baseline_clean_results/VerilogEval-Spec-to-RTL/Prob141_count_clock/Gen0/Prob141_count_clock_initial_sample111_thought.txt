To implement the 12-hour clock, we need to design three counters: one for hours, minutes, and seconds. The counters should be able to wrap around their respective maximum values (12 for hours, 59 for minutes and seconds). We also need to implement the am/pm indicator, which is determined by the hour. We will use a single 8-bit register for each counter, representing the BCD digits. The enable signal will be used to increment the counters, and the reset signal will be used to reset the counters to their initial values.
