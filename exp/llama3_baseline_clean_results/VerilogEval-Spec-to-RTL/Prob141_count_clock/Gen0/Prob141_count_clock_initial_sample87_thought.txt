To implement the 12-hour clock, we can use three counters for hours, minutes, and seconds. 
Each counter should be BCD (Binary-Coded Decimal) and handle the 12-hour clock format.
We'll use the enable signal to increment the counters every second, and the reset signal 
to reset the clock to "12:00 AM" whenever it's asserted. We'll also need to handle the 
pm/am indicator based on the hour. 
We'll implement the counters as separate modules to improve readability and maintainability.
We'll also handle the case where the seconds, minutes, or hours overflow, 
by resetting them to their initial values and propagating the carry to the next counter.
