To create a 12-hour clock module, we can use three counters for hours, minutes, and seconds. We will implement these counters as binary-coded decimal (BCD) counters to directly output the time in the desired format. Each counter will be able to wrap around to 0 after reaching its maximum value (12 for hours, 59 for minutes and seconds). The pm indicator will be set based on the hour value. We will also include a reset mechanism that sets the clock to "12:00 AM" when asserted. The counters will only increment when both the enable signal is high and the clock edge is positive.
