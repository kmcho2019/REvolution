To implement a 12-hour clock with hours, minutes, and seconds counters, along with an AM/PM indicator, we need to create separate counters for each time unit. Each counter should be able to count up to its maximum value and then reset to zero. For the hours counter, it should count from 1 to 12. For minutes and seconds counters, they should count from 0 to 59.

The counters should be clocked by the fast-running clk and only increment when ena is high, which occurs once per second. The reset signal should be able to reset all counters and the AM/PM indicator to their initial states at any time.

Since the output ports (hh, mm, ss) are 8 bits each and we are working with BCD, each time unit (hours, minutes, seconds) can be represented by two BCD digits, allowing values from 00 to 99, which is sufficient for our needs.

To handle the AM/PM indicator, we can use a simple flip-flop that toggles whenever the hours counter wraps around from 12 back to 1 (which indicates a move from PM to AM or vice versa).
