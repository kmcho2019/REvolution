To implement the 12-hour clock, we can use three counters for hours, minutes, and seconds. Each counter should be able to count up to the maximum value (12 for hours, 59 for minutes and seconds) and then wrap around to the minimum value (01 for hours, 00 for minutes and seconds). We will also need to handle the AM/PM indicator, which should be toggled whenever the hour counter wraps around from 12 to 01. 
The counters will be clocked by the fast-running clk signal and will only increment when the ena signal is asserted. 
The reset signal will be used to reset the clock to 12:00 AM whenever it is asserted. 
We will use the BCD (Binary-Coded Decimal) representation for the counters, with two digits for each counter.
