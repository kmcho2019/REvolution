The TopModule can be designed using three counters for hours, minutes, and seconds. 
Each counter will be 8 bits (2 BCD digits) to represent the time. 
The counters will be incremented by the enable signal, which will be used to 
simulate a clock that increments once per second. 
We will use a 12-hour clock with an AM/PM indicator, which can be 
implemented using the hours counter. 
We will also use a reset signal to reset the clock to 12:00 AM when it is asserted.
The clock will have higher priority than the enable signal and will reset the 
counters even when the enable signal is not asserted.
