To implement the 12-hour clock with AM/PM indicator, we need to create a set of counters for hours, minutes, and seconds. Each counter should be able to handle Binary-Coded Decimal (BCD) values. The seconds counter should increment every time 'ena' is asserted, and when it reaches 59, it should reset to 0 and increment the minutes counter. The minutes counter should work similarly, resetting to 0 and incrementing the hours counter when it reaches 59. The hours counter should reset to 1 (for 1 o'clock) when it reaches 12. The 'pm' signal should be asserted when the hours counter is greater than or equal to 12. When 'reset' is asserted, all counters should reset to their initial values (12:00 AM).
