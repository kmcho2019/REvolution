To implement the 12-hour clock module, we can design three separate counters for hours, minutes, and seconds. Each counter should be capable of counting in BCD (Binary-Coded Decimal) format. The counters should be incremented once per second, which is indicated by the enable signal (ena). The module should also include logic to determine whether the current time is AM or PM. When the reset signal is asserted, all counters should reset to their initial values, and the AM/PM indicator should be set to AM.
