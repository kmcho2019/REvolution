To implement the 12-hour clock, we need to create three counters: one for seconds, one for minutes, and one for hours. Each counter should be capable of counting up to 59 for seconds and minutes, and up to 12 for hours, wrapping around to 0 when reaching their maximum value. The counters should only increment when the 'ena' signal is high, indicating that one second has passed. The 'pm' signal should be set based on the hour counter, and the 'reset' signal should reset all counters and the 'pm' signal to their initial values when high. We will use Binary-Coded Decimal (BCD) representation for the counters, which allows us to directly display the time in a two-digit format for hours, minutes, and seconds.
