To implement the 12-hour clock, we can use three counters for hours, minutes, and seconds. 
Each counter can be implemented as a BCD counter, with the seconds counter counting from 0 to 59, 
the minutes counter counting from 0 to 59, and the hours counter counting from 1 to 12. 
We'll use the enable signal to increment the counters once per second. 
The pm signal will be set based on the current hour, with hours 1-11 being AM and hours 12 being PM.
