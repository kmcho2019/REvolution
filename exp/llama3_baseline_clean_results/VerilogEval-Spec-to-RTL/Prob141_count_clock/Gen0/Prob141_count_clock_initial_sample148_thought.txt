To implement the 12-hour clock, we can use three separate counters for hours, minutes, and seconds. Each counter will need to be able to wrap around to zero when it reaches its maximum value. The hour counter needs to toggle the pm signal when it reaches 12. The reset signal will need to be checked at every clock cycle, and if it is high, the clock should reset to "12:00 AM". We will also need to use a counter to slow down the fast-running clk to produce a pulse on ena once per second.
