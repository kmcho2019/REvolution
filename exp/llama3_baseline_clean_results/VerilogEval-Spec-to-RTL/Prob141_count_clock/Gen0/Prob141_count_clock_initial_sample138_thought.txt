To implement the 12-hour clock module, we need to design a set of counters for hours, minutes, and seconds. Each counter should be able to count up to its maximum value (12 for hours, 59 for minutes and seconds) and then wrap around to 0. We also need to implement a mechanism to switch between AM and PM. The counters should be clocked by the fast-running clk and should increment only when the ena signal is asserted. The reset signal should be able to reset the clock to "12:00 AM" at any time.
