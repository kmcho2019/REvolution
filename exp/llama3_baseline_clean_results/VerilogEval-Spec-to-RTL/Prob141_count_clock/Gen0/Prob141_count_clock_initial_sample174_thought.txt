To implement the 12-hour clock, we can use three separate counters for hours, minutes, and seconds. Each counter will have a range suitable for a 12-hour clock (01-12 for hours, 00-59 for minutes and seconds). We will use the ena signal to increment the counters once per second. The pm signal will be determined by the value of the hour counter. When the reset signal is asserted, all counters will reset to their initial values. We will use the positive edge of the clk signal to trigger all sequential logic.
