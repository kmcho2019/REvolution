To implement a 12-hour clock with counters for hours, minutes, and seconds, 
we'll design a module named TopModule. The clock will increment once per second, 
controlled by the ena signal. When the reset signal is high, the clock will reset 
to "12:00 AM". The pm signal will be asserted when the clock is in PM mode. 
We'll use Binary-Coded Decimal (BCD) digits for hours, minutes, and seconds. 
To achieve this, we'll create separate counters for seconds, minutes, and hours. 
When the seconds counter reaches 60, it will reset and the minutes counter will increment. 
Similarly, when the minutes counter reaches 60, it will reset and the hours counter will increment. 
We'll also implement logic to handle the 12-hour clock and am/pm indication.
