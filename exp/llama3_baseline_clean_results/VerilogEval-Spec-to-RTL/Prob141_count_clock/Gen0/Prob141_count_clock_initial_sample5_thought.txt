To implement the 12-hour clock, we need to create counters for hours, minutes, and seconds. Each counter should be able to hold values from 0 to 59 for minutes and seconds, and from 1 to 12 for hours. We will use BCD (Binary-Coded Decimal) representation for these counters, where each digit is represented by 4 bits. The 'pm' signal will be determined based on the hour value. When 'reset' is asserted, all counters should reset to their initial values (12:00 AM). The counters should increment only when 'ena' is asserted, which happens once per second. 
We can achieve this by using separate counters for hours, minutes, and seconds, and implementing the logic for incrementing and resetting these counters based on the input signals.
