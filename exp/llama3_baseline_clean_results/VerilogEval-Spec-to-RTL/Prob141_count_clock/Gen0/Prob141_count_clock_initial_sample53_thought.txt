To implement the 12-hour clock, we need to design a set of counters for hours, minutes, and seconds. Each counter should be able to wrap around to zero after reaching its maximum value (12 for hours, 59 for minutes and seconds). We also need to maintain an am/pm indicator, which can be toggled when the hour counter reaches 12. The enable signal will be used to increment the counters once per second. The reset signal should reset the counters to their initial values (12:00 AM) whenever it is asserted. This can be achieved by using a combination of sequential logic (always blocks) and conditional statements in Verilog.
