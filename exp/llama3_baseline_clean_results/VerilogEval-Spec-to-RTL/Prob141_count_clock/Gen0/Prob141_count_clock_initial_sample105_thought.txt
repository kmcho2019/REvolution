To design the TopModule, we need to implement a set of counters for hours, minutes, and seconds. 
We'll use a hierarchical approach, starting from the seconds counter, then the minutes counter, and finally the hours counter. 
Each counter should be resettable and have the capability to carry over to the next counter when it overflows. 
For example, when the seconds counter reaches 60 (which is 1001100 in BCD, but we are counting from 00 to 59), it should reset to 00 and increment the minutes counter. 
When the minutes counter reaches 60, it should reset to 00 and increment the hours counter. 
The hours counter should handle AM/PM logic, resetting to 01 when it reaches 13 and flipping the AM/PM indicator when it reaches 12. 
We will also use the ena signal to ensure that the counters only increment once per second.
