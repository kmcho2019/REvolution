To implement the 12-hour clock module, we need to design a set of counters for hours, minutes, and seconds. Each counter should be able to store values in BCD format. The counters should increment once per second based on the ena signal. The reset signal should reset the clock to "12:00 AM" and have higher priority than the enable signal. We can use separate counters for hours, minutes, and seconds, and use conditional statements to handle the wrapping around of the counters (e.g., from 59 seconds to 0 seconds, from 59 minutes to 0 minutes, etc.). The pm signal will be determined based on the hour value.
