To implement the 12-hour clock module, we need to create counters for hours, minutes, and seconds. The seconds counter should increment every time the enable signal (ena) is asserted, and when it reaches 60 (i.e., 0x3C), it should reset to 0 and trigger the minutes counter to increment. Similarly, when the minutes counter reaches 60, it should reset to 0 and trigger the hours counter to increment. The hours counter should reset to 1 (not 0) when it reaches 13 (since the clock is 12-hour based), and toggle the am/pm indicator (pm) whenever it crosses from 12 to 1 or vice versa. All counters should reset to their initial values when the reset signal is asserted. 
The counters should use Binary-Coded Decimal (BCD) to represent hours, minutes, and seconds as two digits each.
