To implement the 12-hour clock module, we need to design a set of counters for hours, minutes, and seconds that are incremented at a rate of once per second. This can be achieved by using counters that count up to a certain value and then reset, with the enable signal (ena) controlling when the counters are incremented. The hours counter should wrap around from 12 to 1 and have an am/pm indicator. The minutes and seconds counters should wrap around from 59 to 0. The reset signal should have higher priority than the enable signal and should reset the clock to 12:00 AM.
