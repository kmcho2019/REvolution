The TopModule should have three counters for hours, minutes, and seconds. 
Each counter should be able to handle BCD (Binary-Coded Decimal) values. 
The hours counter should count from 1 to 12, the minutes and seconds counters 
should count from 0 to 59. The module should also have an am/pm indicator 
that is asserted when the hours counter is greater than or equal to 12. 
The counters should be reset to 12:00 AM when the reset signal is high. 
The counters should only increment when the enable signal is high. 
We can use separate counters for the tens and ones digits of each time component.
