To implement a 12-hour clock with am/pm indicator, we need to create counters for hours, minutes, and seconds. Each counter should be able to store two BCD digits. The hours counter should wrap around from 12 to 1 when it reaches 13, and the minutes and seconds counters should wrap around from 59 to 0 when they reach 60. We also need to handle the am/pm indicator, which should toggle when the hours counter wraps around. The clock should increment once per second, triggered by the ena signal, and reset to 12:00 AM when the reset signal is asserted.
