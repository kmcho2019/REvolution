To implement a 12-hour clock with hours, minutes, and seconds counters, 
we need to create a module that takes into account the enable signal, 
which pulses once per second. This enable signal will trigger the 
increment of the counters. We should also implement a reset mechanism 
that resets the clock to "12:00 AM" when activated.

The counters for hours, minutes, and seconds will need to wrap around 
at their respective maximum values (12 for hours, 59 for minutes and 
seconds). To achieve this, we can use conditional statements to check 
when the counters reach their maximum values and reset them accordingly.

Additionally, we need to generate the pm signal based on the hour value.
If the hour value is greater than or equal to 12, the pm signal should 
be asserted; otherwise, it should be deasserted.
