To implement a 12-hour clock with the specified interface, we can create three counters for hours, minutes, and seconds. These counters should be incremented based on the enable signal, which is asserted once per second. We also need to handle the pm indicator and ensure the clock resets to "12:00 AM" when the reset signal is asserted.
