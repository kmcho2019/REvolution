To implement the given Moore state machine, we can use a two-state FSM (Finite State Machine) with an active-high synchronous reset. The current state and the next state can be represented using a two-bit register. The next state logic and the output logic can be derived from the given state transition and output table. 

The state transition table is as follows:
- State B (out=1): If in=0, next state is A, if in=1, next state is B
- State A (out=0): If in=0, next state is B, if in=1, next state is A

The output out is determined by the current state: 
- If the current state is B, out=1
- If the current state is A, out=0

We will use two always blocks: one for the next state logic and the other for the output logic.
