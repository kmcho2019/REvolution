The Moore state machine has two states, A and B. It starts in state B when reset is high. 
In state B, the output is 1. If the input is 0, it moves to state A. If the input is 1, it stays in state B. 
In state A, the output is 0. If the input is 0, it moves to state B. If the input is 1, it stays in state A. 
We can use a variable to store the current state and use a case statement to determine the next state based on the current state and input.
We also need to handle the reset condition, where the state machine resets to state B when reset is high.
