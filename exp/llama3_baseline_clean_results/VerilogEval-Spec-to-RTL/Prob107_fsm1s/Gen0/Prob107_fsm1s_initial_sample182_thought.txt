The Moore state machine has two states: A and B. The output is determined by the current state. We can use a 1-bit state variable to represent these two states. The next state is determined by the current state and the input. We will use a case statement inside a always block to implement the state transition logic. The output will be assigned based on the current state. The reset is active-high synchronous, meaning that when the reset signal is high, the state machine will be reset to state B on the next clock cycle.
