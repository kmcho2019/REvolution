To implement the Moore state machine, we need to define the states and transitions based on the given specification. Since we have two states (A and B), we can use a single bit to represent the state. We will use a register to store the current state and update it on every clock cycle based on the current state and input. The output will be determined by the current state. The reset will be active-high synchronous, meaning that when reset is high, the state will be set to B.
