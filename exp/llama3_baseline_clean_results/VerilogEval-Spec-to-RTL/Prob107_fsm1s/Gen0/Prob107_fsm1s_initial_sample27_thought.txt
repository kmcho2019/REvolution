To implement the given Moore state machine, we need to define the states and their transitions based on the input 'in'. The state machine has two states, A and B. We will use two-bit binary encoding for the states, where '00' represents state A and '01' represents state B. The initial state (reset state) is B.

In the Moore state machine, the output is a function of the current state only. So, we will assign out = 1 when the state is B and out = 0 when the state is A.

The state transition table is as follows:
- Current State: B, Input: 0, Next State: A
- Current State: B, Input: 1, Next State: B
- Current State: A, Input: 0, Next State: B
- Current State: A, Input: 1, Next State: A

We will implement this using Verilog's always block for the state transition and another always block for the output logic.
