To implement the Moore state machine, we first define an enumeration of the states. We use a parameterized module to define the state type and the number of states. We then declare the current and next state variables. The state machine's next state is determined by the current state and the input. The output is determined by the current state. We use a always_ff block for the state register and a always_comb block for the combinational logic. The reset is synchronous and active-high, meaning that when reset is high, the state machine goes to the reset state (B).
