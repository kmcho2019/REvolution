To solve this problem, we will design a Moore-type finite state machine (FSM) in Verilog. The FSM will have states to track the sequence of 1s and 0s in the input stream. We will use a counter to keep track of the number of consecutive 1s. The FSM will transition between states based on the current input and the counter value. When a flag or error condition is detected, the corresponding output signal will be asserted for one clock cycle. The FSM will be reset to a state that behaves as though the previous input were 0 when the reset signal is active high.
