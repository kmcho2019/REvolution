To implement the Moore-type finite state machine, we can design a state machine with states that track the number of consecutive 1s received and whether the previous input was a 0 or not. The machine will have states for reset (initial state), states to track the number of consecutive 1s (up to 6), and an error state. When the machine sees a sequence of 6 consecutive 1s followed by a 0, it will assert the disc output. When it sees the sequence 01111110, it will assert the flag output. If it sees 7 or more consecutive 1s, it will assert the err output. We'll use a synchronous reset to bring the machine to its initial state upon reset.
