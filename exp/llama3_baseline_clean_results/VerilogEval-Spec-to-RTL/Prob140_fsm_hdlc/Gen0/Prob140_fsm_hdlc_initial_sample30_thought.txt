To solve this problem, we need to design a Moore-type finite state machine (FSM) that recognizes the specified sequences. The FSM will have states to track the number of consecutive 1s seen so far. We will use a 3-bit counter to keep track of the number of consecutive 1s. The states will be as follows:
- State 0: No consecutive 1s or just one 1 (initial state after reset)
- State 1-5: 1-5 consecutive 1s
- State 6: 6 consecutive 1s (discarding state)
- State 7: 7 consecutive 1s (error state)

The next state logic will depend on the current state and the input bit. We will also generate the output signals (disc, flag, and err) based on the current state.
