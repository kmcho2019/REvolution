The problem can be solved by designing a Moore-type finite state machine (FSM) in Verilog. The FSM will have several states to track the sequence of bits. 

1. State 0: Initial state. 
2. State 1-5: Counter states to track consecutive 1s.
3. State 6: State to detect the flag sequence (01111110).
4. State 7: State to detect the error sequence (7 or more consecutive 1s).

The FSM will transition between these states based on the input 'in' and the current state. The outputs 'disc', 'flag', and 'err' will be asserted based on the current state.

We will also use a separate state to signal when a bit needs to be discarded (disc) when the sequence 0111110 is detected. 

The FSM will be reset to State 0 when the reset signal is high.
