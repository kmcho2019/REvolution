To solve this problem, we can design a Moore-type finite state machine (FSM) with states that track the number of consecutive 1s and 0s seen in the input stream. The FSM should have states for the idle condition (i.e., no consecutive 1s), states for tracking consecutive 1s (up to 6), and an error state for 7 or more consecutive 1s. The FSM transitions between these states based on the input bit and resets to the idle state when the reset signal is high. The outputs (disc, flag, err) are determined by the current state and the input bit.
