To solve this problem, we can design a Moore-type finite state machine (FSM) that recognizes the specified sequences. The FSM will have several states to track the number of consecutive 1s and to distinguish between the desired sequences. 

1. We start by defining the states of the FSM. 
   - S0: Initial state or after a 0 is encountered.
   - S1 to S6: States to count consecutive 1s.
   - S_ERR: Error state for 7 or more consecutive 1s.

2. The transitions between states are based on the current state and the input bit.
   - From S0, we move to S1 if the input is 1, and stay in S0 if the input is 0.
   - From S1 to S5, we move to the next state if the input is 1 and reset to S0 if the input is 0.
   - From S5, if the input is 1, we move to S6 (potential flag), otherwise we move to S_ERR.
   - From S6, if the input is 0, we assert the flag output and reset to S0. If the input is 1, we move to S_ERR.

3. To signal that a bit needs to be discarded (disc), we assert this output in state S6 when the input is 1, because this means we've seen 6 consecutive 1s followed by another 1, which is the signal for a bit to be discarded.

4. For the error condition, once we reach S_ERR, we assert the error output (err) and stay in this state until the input is 0, at which point we reset to S0.

5. Finally, we need to handle the reset signal. On a positive edge of the clock and the reset signal being high, we reset the FSM to S0.
