To implement the required Moore-type finite state machine, we can design a state machine with the following states: 
- Idle: The initial state, waiting for the start of a potential flag sequence.
- Ones: A state to count the number of consecutive ones seen so far.
- Flag: A state to signal the start/end of a frame.
- Disc: A state to signal that a bit needs to be discarded.
- Err: A state to signal an error if 7 or more consecutive ones are seen.

The state machine transitions based on the current state and the input bit. The outputs are determined solely by the current state. The FSM asserts the disc output when it detects the sequence 0111110, the flag output when it detects the sequence 01111110, and the err output when it detects 7 or more consecutive ones.

We will use a 4-bit counter to keep track of the number of consecutive ones seen so far. The state machine will reset the counter when a zero is encountered and will only transition to the flag or disc states when the counter reaches 5 or 6, respectively.

The FSM will also include a reset signal that resets the state machine to the idle state and resets the counter.
