To implement the Moore-type finite state machine as described, we first need to identify the states required to recognize the specified sequences. 
We'll have states to track the number of consecutive 1s seen so far and to handle the conditions for discarding a bit, signaling a flag, and error detection.
The FSM will start in a reset state that assumes the previous input was 0, and it will transition through states based on the current input and its current state.
Given inputs and outputs, the Verilog code will be designed to implement these state transitions and output signals accordingly.
