To solve this problem, we will implement a Moore-type finite state machine (FSM) in Verilog. The FSM will have states to track the number of consecutive 1s received and to identify the patterns of 01111110 (flag), 0111110 (discard), and 7 or more consecutive 1s (error). The FSM will be reset to a state that assumes the previous input was 0 when the reset signal is high. The outputs disc, flag, and err will be asserted for one clock cycle after their respective conditions are met. We'll use a parameterized state machine to make the code readable and maintainable.
