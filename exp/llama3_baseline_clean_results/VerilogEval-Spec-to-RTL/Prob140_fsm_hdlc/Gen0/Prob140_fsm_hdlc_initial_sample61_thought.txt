To solve this problem, we can design a Moore-type finite state machine (FSM) that keeps track of the consecutive number of 1s in the input stream. The FSM should have states to handle the normal operation, flag detection, discard detection, and error detection. The reset signal should transition the FSM to a state that behaves as though the previous input were 0. We will use a 3-bit counter to keep track of the consecutive 1s. The FSM will have the following states: 
- S0: Initial state (reset state), assumes previous input was 0
- S1: One consecutive 1
- S2: Two consecutive 1s
- S3: Three consecutive 1s
- S4: Four consecutive 1s
- S5: Five consecutive 1s, discard next bit
- S6: Six consecutive 1s, check next bit for flag or error
- S7: Seven consecutive 1s, error state

We will use the next state logic and output logic to determine the next state and output values based on the current state and input.
