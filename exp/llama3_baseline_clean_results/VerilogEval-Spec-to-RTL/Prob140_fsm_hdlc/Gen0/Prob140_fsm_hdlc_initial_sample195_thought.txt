To implement the Moore-type finite state machine, we first need to define the states for recognizing the sequences. We can use the following states:
- IDLE: The initial state where the FSM is waiting for the sequence to start.
- ONE: The state after seeing one '1'.
- TWO_TO_FIVE: The states after seeing 2 to 5 consecutive '1's.
- SIX: The state after seeing exactly 6 consecutive '1's.
- SEVEN_OR_MORE: The state after seeing 7 or more consecutive '1's.
- DISCARD: The state after seeing 5 consecutive '1's and then a '0' to discard.

The next state and output logic can be determined based on the current state and the input bit. We will use a case statement to handle each state and generate the output signals accordingly. The outputs will be asserted for a complete cycle after the condition occurs.
