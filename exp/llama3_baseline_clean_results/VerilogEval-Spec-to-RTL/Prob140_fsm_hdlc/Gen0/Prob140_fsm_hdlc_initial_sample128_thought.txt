To implement the HDLC framing module, we will design a Moore-type finite state machine. The FSM will have states to track the number of consecutive ones and the detection of the flag sequence. We will use an enumeration of states to simplify the state transitions. We will assert the output signals based on the current state and the input. The reset will put the FSM in a state that assumes the previous input was 0, which means the FSM should start in a state that expects a 0. We will use a case statement to handle the state transitions and output signal assignments.
