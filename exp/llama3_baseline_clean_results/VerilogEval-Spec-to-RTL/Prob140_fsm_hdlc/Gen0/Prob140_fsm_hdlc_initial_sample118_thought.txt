To solve this problem, we will design a Moore-type finite state machine (FSM) that recognizes the specified sequences. The FSM will have states to track the number of consecutive 1s and 0s. We will use a 4-state FSM to track the consecutive 1s and a single state for reset condition (as the previous input was 0). The states will be: 
- S0: Initial state or previous input was 0
- S1: One consecutive 1
- S2: Two consecutive 1s
- S3: Three consecutive 1s
- S4: Four consecutive 1s
- S5: Five consecutive 1s
- S6: Six consecutive 1s
- S7: Seven consecutive 1s (error state)

The FSM will transition between these states based on the current input. When the FSM is in state S6 and receives a 0, it will assert the flag output. When the FSM is in state S5 and receives a 1, it will assert the disc output. The FSM will assert the err output when it is in state S7.
