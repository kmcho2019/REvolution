2. We transition from the reset state to a count state when a 1 is seen.
3. We increment the count for each consecutive 1 seen.
4. If we see 5 consecutive 1s, we transition to a state that checks for an extra 1 to determine if it's a flag or an error.
5. If we see exactly 6 consecutive 1s, we flag the beginning/end of a frame.
6. If we see 7 or more consecutive 1s, we signal an error.
7. If we see a 0 after 5 consecutive 1s, we discard the next bit.
