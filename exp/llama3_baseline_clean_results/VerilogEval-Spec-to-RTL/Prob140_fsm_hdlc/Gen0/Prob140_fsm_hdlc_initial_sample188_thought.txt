To solve this problem, we will design a Moore-type finite state machine (FSM) that recognizes the specified sequences. The FSM will have states to track the number of consecutive 1s seen and to handle the specific sequences of interest. We will use a six-state FSM: 
- S0: Initial state or less than 5 consecutive 1s seen
- S1: 5 consecutive 1s seen, expecting a 0 to discard
- S2: 6 consecutive 1s seen (flag condition)
- S3: Error state for 7 or more consecutive 1s
- S4: Flag seen, expecting a new sequence
- S5: Discard bit seen, expecting a new sequence

The state transitions will be based on the current state and the input bit. The outputs will be determined solely by the current state. We'll ensure the FSM resets to S0 upon the active-high reset signal.
