To implement the HDLC framing decoder as a Moore-type finite state machine, we can design a state machine that keeps track of the number of consecutive 1s seen so far. We need to reset the state machine when the reset signal is high. The state machine should have states to track the number of consecutive 1s and should signal the outputs accordingly. We will have an idle state where the state machine waits for the input to be 1. When the input is 1, the state machine moves to the next state. If the state machine sees 5 consecutive 1s, it checks the next input. If the next input is 0, it discards the bit. If the next input is 1, it checks the next input again. If the next input is 0, it flags the beginning/end of a frame. If the next input is 1, it signals an error. We will use a 3-bit counter to count the number of consecutive 1s and a 2-bit state register to manage the state of the state machine.
