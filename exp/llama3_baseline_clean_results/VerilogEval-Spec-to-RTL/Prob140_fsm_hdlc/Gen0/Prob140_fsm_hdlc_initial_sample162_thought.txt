- State 1: One 1 has been seen.

- State 6: 6 consecutive 1s have been seen, and we're checking for the next bit to decide between flag and error.
- State 7: 7 or more consecutive 1s have been seen, indicating an error.

We will also define output signals disc, flag, and err based on the current state and the next input bit.

- From State 0: If the input is 1, move to State 1. If the input is 0, stay in State 0.

- From State 6: If the input is 0, move to State 0 and assert flag. If the input is 1, move to State 7 and assert err.
