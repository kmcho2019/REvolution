To implement the required Moore-type finite state machine, we can use a state machine with a total of 8 states: 
- One state for the initial state (RESET), 
- Five states (S0 to S5) to detect 5 consecutive 1s, 
- One state to signal a bit needs to be discarded (DISC), 
- One state to flag the beginning/end of a frame (FLAG).

We will use a counter to keep track of the number of consecutive 1s. The disc signal will be asserted when we encounter 6 consecutive 1s after a zero, the flag signal will be asserted when we encounter 7 consecutive 1s after a zero, and the err signal will be asserted when we encounter 8 or more consecutive 1s. 

The next state will be determined based on the current state and the input bit. If the input is 1, we increment the counter; if the input is 0, we reset the counter. We will also check for the conditions to assert the disc, flag, and err signals.
