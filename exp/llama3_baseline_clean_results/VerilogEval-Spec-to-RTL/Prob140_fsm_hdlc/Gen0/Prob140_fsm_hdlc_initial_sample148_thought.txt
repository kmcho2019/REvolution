To solve this problem, we need to design a Moore-type finite state machine (FSM) that recognizes the specified sequences. We can break down the problem into several states:
- A reset state that initializes the FSM after the reset signal is asserted.
- A state to track the number of consecutive 1s seen in the input stream.
- A state to detect the "flag" pattern (01111110).
- A state to signal an error when 7 or more consecutive 1s are seen.
- A state to signal a bit needs to be discarded when 6 consecutive 1s are followed by a 0.
We will use the next state logic to transition between these states based on the current state and the input.
The FSM will assert the disc, flag, or err signals when the corresponding conditions are met.
