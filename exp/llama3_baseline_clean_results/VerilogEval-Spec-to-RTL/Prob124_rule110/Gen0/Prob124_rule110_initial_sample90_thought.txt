The TopModule will have an internal 512-bit register to store the state of the cells. On each clock cycle, the next state of each cell will be calculated based on the current state of itself and its two neighbors, according to the Rule 110 table. The load input will be used to load the initial state of the system from the data input. We can use a large case statement to implement the Rule 110 table, or we can use a combination of logical operations to simplify the implementation.
