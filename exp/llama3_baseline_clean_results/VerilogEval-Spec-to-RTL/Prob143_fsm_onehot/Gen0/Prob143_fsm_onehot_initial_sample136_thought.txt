The state machine uses one-hot encoding, so each state is represented by a single bit. 
However, the input state can be a combination of multiple states. 
We will implement the next state logic and output logic using combinational logic. 
For each possible input state, we will calculate the next state based on the input in and the current state. 
The outputs out1 and out2 will be calculated based on the current state.

We will use case statements to handle each state separately, and for each state, 
we will check the input in and determine the next state and outputs accordingly.

Since the input state can be a combination of multiple states, we will use bitwise OR operations 
to determine if a particular state is present in the input state.
