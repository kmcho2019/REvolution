The next state `next_state` will be determined based on the current state and the input `in`. The outputs `out1` and `out2` will be determined based on the current state.

We will use a case statement inside a generate statement to check for each possible current state. For each state, we will use an if statement to check the value of the input `in` and determine the next state accordingly.

We will also use assign statements to set the outputs `out1` and `out2` based on the current state.
