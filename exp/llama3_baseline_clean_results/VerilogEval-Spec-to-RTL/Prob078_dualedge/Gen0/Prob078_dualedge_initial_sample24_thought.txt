To implement a dual-edge triggered flip-flop without using the always @(posedge clk or negedge clk) sensitivity list, we can use two single-edge triggered flip-flops and an XOR gate to generate an internal clock signal that can be used to drive the flip-flops. This internal clock signal will have a pulse on both the rising and falling edges of the input clock signal. We can then use this internal clock signal to drive a single flip-flop to store the input data.
