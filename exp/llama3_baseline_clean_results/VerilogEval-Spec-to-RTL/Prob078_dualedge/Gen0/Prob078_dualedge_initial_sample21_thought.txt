To implement a dual-edge triggered flip-flop, we can use two single-edge triggered flip-flops and a clock edge detector. The clock edge detector can identify whether the clock signal has a rising or falling edge. We can then use this edge information to trigger the flip-flops to latch the input data on both the rising and falling edges of the clock. This can be achieved by creating an enable signal that is high for one clock cycle after each edge is detected, allowing the flip-flops to capture the input data.
