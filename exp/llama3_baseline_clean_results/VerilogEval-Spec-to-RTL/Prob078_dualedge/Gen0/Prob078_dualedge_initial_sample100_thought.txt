To implement a dual-edge triggered flip-flop, we can use two single-edge triggered flip-flops (one for positive edge and one for negative edge) along with some combinational logic to resolve the output. The idea is to have one flip-flop capture data on the positive edge of the clock and the other on the negative edge. Then, we use a multiplexer to select which flip-flop's output to use based on the current edge of the clock. However, a simpler approach can be to use the fact that a dual-edge triggered flip-flop essentially acts as if it captures data on every transition of the clock.
