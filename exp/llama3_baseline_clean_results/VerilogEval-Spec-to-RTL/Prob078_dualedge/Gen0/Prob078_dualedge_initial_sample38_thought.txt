However, since we are looking to emulate a dual-edge triggered behavior, we need to ensure that the data is captured on both edges of the clock. This can be achieved by using a different approach: 
- We can use an internal clock enable signal that gets asserted on every edge of the clock (both rising and falling edges).
- We then use this enable signal within a single always block to sample the input data and update the output.
