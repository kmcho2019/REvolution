To implement a dual-edge triggered flip-flop, we can use two regular edge-triggered flip-flops. The first flip-flop is triggered on the rising edge of the clock and captures the input data at this edge. The second flip-flop is triggered on the falling edge of the clock and captures the input data at this edge. However, to avoid using an always @(posedge clk or negedge clk) sensitivity list, we can use a single always block that is sensitive to both edges of the clock by using a variable to track the clock edge.
