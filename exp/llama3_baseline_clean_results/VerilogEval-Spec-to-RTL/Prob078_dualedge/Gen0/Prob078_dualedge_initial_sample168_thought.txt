To implement a dual-edge triggered flip-flop without directly using an always @(posedge clk or negedge clk) sensitivity list, we can use two single-edge triggered flip-flops. One will be triggered on the positive edge of the clock, and the other will be triggered on the negative edge. The output of the dual-edge triggered flip-flop can be determined by the output of the two single-edge triggered flip-flops. However, the exact implementation needs to ensure that the output changes only once per clock period, regardless of whether the change occurs on the rising or falling edge of the clock. A more elegant solution involves using a single clock and generating an internal clock that is twice the frequency of the input clock. This way, we can effectively capture the input data on both edges of the original clock by treating each edge as a separate clock cycle in the internal domain.
