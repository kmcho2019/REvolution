To create a dual-edge triggered flip-flop without using an always block sensitive to both positive and negative clock edges, we can use two single-edge triggered flip-flops and some combinational logic. The idea is to capture the input data on both the rising and falling edges of the clock by using one flip-flop for the rising edge and another for the falling edge. Then, use a multiplexer to select which flip-flop's output to use based on the current clock edge.
