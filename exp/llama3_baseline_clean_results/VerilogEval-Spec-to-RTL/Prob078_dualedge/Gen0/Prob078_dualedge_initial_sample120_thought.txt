To implement a dual-edge triggered flip-flop using only single-edge triggered flip-flops, we can use two flip-flops with complementary clock edges. One flip-flop is triggered on the rising edge of the clock, and the other on the falling edge. Both flip-flops will have the same input (d), and their outputs will be combined with a multiplexer (or similar logic) to produce the final output (q). However, to minimize the complexity and simply the design, we can exploit the fact that the output (q) of a dual-edge triggered flip-flop essentially changes state on every edge of the clock. We can achieve this functionality by detecting the clock edge transitions (rising or falling) and using these transitions to capture the input (d) into a single flip-flop.
