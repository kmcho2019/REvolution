To implement a dual-edge triggered flip-flop without using the always @(posedge clk or negedge clk) sensitivity list, we can use two single-edge triggered flip-flops. The idea is to use one flip-flop triggered on the rising edge of the clock and another flip-flop triggered on the falling edge of the clock. Then, we can use an OR gate to combine the outputs of these two flip-flops. However, to ensure that the output is updated on both edges of the clock, we need to use a multiplexer to select between the current output and the new input, based on the clock edge. But a simpler way to think about it is to just use two D flip-flops and an AND gate and an inverter to implement the logic of a dual-edge triggered flip-flop.
