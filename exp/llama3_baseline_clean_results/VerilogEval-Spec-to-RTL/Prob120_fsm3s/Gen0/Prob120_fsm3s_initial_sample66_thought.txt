To implement the Moore state machine as described, we first need to define an enumeration for the states (A, B, C, D) and then use a case statement to determine the next state based on the current state and the input 'in'. The output will be determined solely by the current state. We'll use a parameterized module for clarity and ease of modification. The reset will be handled by checking the 'reset' signal at the beginning of the always block and setting the current state to A if it's high. The state transition logic will be triggered on the positive edge of the clock 'clk'.
