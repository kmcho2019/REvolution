To implement the Moore state machine described, we first need to encode the states. Since there are four states, we can use 2 bits to represent each state (A, B, C, D). We will then use a synchronous reset to initialize the state machine to state A when the reset signal is high. The next state logic will be determined based on the current state and the input 'in'. The output will be determined solely by the current state. 
We will use a case statement to handle the next state logic and output logic for each state. 
For the encoding of states, let's use the following: A = 2'b00, B = 2'b01, C = 2'b10, D = 2'b11.
