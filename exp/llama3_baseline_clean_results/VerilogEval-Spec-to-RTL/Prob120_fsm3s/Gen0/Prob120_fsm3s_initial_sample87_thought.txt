To implement the Moore state machine as described, we'll first define an enumeration for the states (A, B, C, D) and use a variable of this type to keep track of the current state. We will then use a case statement inside a combinational always block to determine the next state based on the current state and the input 'in'. The output 'out' will be determined solely by the current state. We'll use a sequential always block to update the current state on the positive edge of the clock, including the synchronous active high reset.
