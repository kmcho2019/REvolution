To implement the Moore state machine, we first need to define the states. Since there are four states, we can use two bits to represent them. We will use an enumeration to make the code more readable. We will then use a case statement inside a always_ff block to implement the state transition table. The output will be determined by the current state. Since it's a Moore machine, the output only depends on the current state, not the input. We will also include a synchronous active high reset that resets the FSM to state A when reset is high.
