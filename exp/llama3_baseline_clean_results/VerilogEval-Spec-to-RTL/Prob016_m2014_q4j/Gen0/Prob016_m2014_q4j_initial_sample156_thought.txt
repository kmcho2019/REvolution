To implement a 4-bit adder, we can use four full adders connected in a chain. 
Each full adder takes two input bits (x and y) and a carry input from the previous full adder, 
and produces a sum output and a carry output. 
We start with a carry input of 0 for the first full adder, and the carry output of each full adder 
is connected to the carry input of the next full adder. 
The sum output of each full adder is a bit in the final sum, from least significant to most significant. 
The carry output of the last full adder is the overflow bit.
