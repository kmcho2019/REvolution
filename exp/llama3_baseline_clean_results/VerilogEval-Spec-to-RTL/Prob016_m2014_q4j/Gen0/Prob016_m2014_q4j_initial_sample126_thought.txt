To implement a 4-bit adder with full adders, we'll create a TopModule that instantiates four FullAdder modules. Each FullAdder module will perform the addition of two corresponding bits from the input x and y, along with a carry-in bit. The carry-in bit for the first FullAdder will be 0, and for the subsequent FullAdders, it will be the carry-out bit from the previous FullAdder. The sum bits from each FullAdder will form the sum output, and the carry-out bit from the last FullAdder will be the overflow bit.
