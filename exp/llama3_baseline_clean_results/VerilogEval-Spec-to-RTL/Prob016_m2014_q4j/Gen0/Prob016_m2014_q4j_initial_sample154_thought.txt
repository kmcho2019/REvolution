To implement a 4-bit adder, we will use four full adder modules. Each full adder will take one bit from the input x, one bit from the input y, and a carry bit from the previous full adder (or a default 0 for the first full adder). The sum and carry output of each full adder will be used to calculate the final sum and carry. We will chain the full adders together, with each full adder's carry output becoming the carry input for the next full adder.
