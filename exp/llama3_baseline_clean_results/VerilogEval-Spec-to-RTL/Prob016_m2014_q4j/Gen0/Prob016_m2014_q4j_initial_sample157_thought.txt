To implement a 4-bit adder with full adders, we will create a hierarchical design. 
First, we will define a FullAdder module that adds three input bits (two data bits and one carry bit) and produces a sum bit and a carry bit. 
Then, we will use four instances of the FullAdder module in the TopModule to add the corresponding bits of the 4-bit inputs x and y, 
propagating the carry from one full adder to the next. 
The final carry output will serve as the overflow bit in the 5-bit sum.
