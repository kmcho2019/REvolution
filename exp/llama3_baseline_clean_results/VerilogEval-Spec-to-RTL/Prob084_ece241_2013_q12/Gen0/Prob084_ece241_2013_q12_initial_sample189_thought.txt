To implement the required module, we need to design an 8x1 memory with shift-in capability and random access read. We start by creating an 8-bit shift register using 8 D-type flip-flops. The shift register is enabled by the synchronous active high enable input. We then use 3 additional inputs A, B, and C to select which bit of the shift register to output on Z. This is achieved by using a multiplexer that selects one of the 8 bits of the shift register based on the value of ABC.
