To implement the TopModule, we will first design an 8-bit shift register using 8 D-type flip-flops. The shift register will have a synchronous active high enable input. Then, we will use 3-to-8 line multiplexers to implement the random access functionality. The 3 inputs A, B, and C will be used as the select lines for the multiplexer. The output of the multiplexer will be connected to the output Z. This way, when ABC is 000, the output of the first flip-flop (Q[0]) will be selected and passed to Z, when ABC is 001, the output of the second flip-flop (Q[1]) will be selected, and so on.
