The TopModule will contain an 8-bit shift register implemented using 8 D-type flip-flops. 
The shift register will have a synchronous active high enable input to control the shifting. 
Three additional inputs A, B, and C will be used as select lines for a multiplexer to select one of the flip-flop outputs as the output Z. 
When ABC equals a binary number from 000 to 111, the corresponding flip-flop output Q[0] to Q[7] will be selected as the output Z.
This can be achieved using an 8-to-1 multiplexer with A, B, and C as the select lines.
