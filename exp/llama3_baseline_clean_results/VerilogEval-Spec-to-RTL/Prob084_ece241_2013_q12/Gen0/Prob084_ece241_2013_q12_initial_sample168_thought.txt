To solve this problem, we will first create an 8-bit shift register using 8 D-type flip-flops. The shift register input is S and it will feed the input of Q[0] (MSB is shifted in first). We will then use a 3-to-8 decoder (implemented as a multiplexer) to select one of the 8 outputs of the shift register based on the 3-bit address inputs A, B, and C. The selected output will be assigned to Z. We will use the enable input to control whether the shift register shifts on the positive edge of the clock.
