To solve this problem, we will first create an 8-bit shift register using D-type flip-flops. The shift register will have a synchronous active high enable input and will shift the bits when enabled. We will then use multiplexers to implement the random access functionality. The multiplexers will take the 3-bit address (A, B, C) as the select lines and the outputs of the shift register (Q[0] to Q[7]) as the data lines. The output of the multiplexer will be connected to the output Z. This way, when the address ABC is 000, the output Z will be Q[0], when ABC is 001, Z will be Q[1], and so on.
