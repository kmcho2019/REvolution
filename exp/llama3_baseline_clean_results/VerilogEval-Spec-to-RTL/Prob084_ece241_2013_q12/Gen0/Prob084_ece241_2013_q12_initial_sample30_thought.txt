To implement the TopModule, we will first design an 8-bit shift register with 8 D-type flip-flops. The shift register will have a synchronous active high enable input that controls whether to shift. Then, we will use 3 additional inputs A, B, and C to create a 3-to-8 decoder that will be used to select one of the 8 flip-flop outputs to be sent to the output Z. We will use a multiplexer to achieve this. The multiplexer will have 8 data inputs (Q[0]...Q[7]), 3 select lines (A, B, C), and 1 output (Z). When the select lines (A, B, C) are 000, the multiplexer will select Q[0], when they are 001, it will select Q[1], and so on.
