To implement the given Mealy finite-state machine using a one-hot encoding, we first define the states as one-hot vectors. We have two states (A and B), so we need two bits to represent them. We will use the following encoding: A = 2'b01 and B = 2'b10. 

The next state logic is determined based on the current state and the input x. For the output z, it is directly determined by the current state and the input x. 

The module will be designed with an asynchronous active-high reset. When the reset is high, the module will reset to state A, which is 2'b01.
