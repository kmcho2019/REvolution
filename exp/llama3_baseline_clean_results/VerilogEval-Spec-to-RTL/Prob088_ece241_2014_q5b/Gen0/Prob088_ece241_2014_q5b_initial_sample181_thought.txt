To implement the given Mealy finite-state machine using one-hot encoding, we first define the states. Let's use A and B as the state names for simplicity. In one-hot encoding, each state is represented by a unique binary number where only one bit is '1' and the rest are '0'. We can represent state A as '01' and state B as '10' since we only have two states.

Next, we need to implement the state transition logic according to the given transitions and output logic. The machine resets into state A, which means on reset, both bits of our state vector should become '0' and '1' respectively to represent state A ('01'). 

The output z is determined by the current state and the input x. According to the transitions:
- In state A and x=0, z=0 and stay in A.
- In state A and x=1, z=1 and move to B.
- In state B and x=0, z=1 and stay in B.
- In state B and x=1, z=0 and stay in B.

We implement these transitions and output logic using combinational logic and then use sequential logic (registers) to store the current state and update it according to the next state logic on the positive edge of the clock.

For one-hot encoding, we use two flip-flops to represent the two states. The reset is asynchronous and active-high, meaning that whenever the reset signal is high, the circuit resets to state A, regardless of the clock.
