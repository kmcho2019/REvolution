To implement the given Mealy finite-state machine using one-hot encoding, we first identify the states (A and B) and their transitions based on the input 'x'. We assign a unique binary code to each state (for one-hot, it's simpler since each state is represented by a single '1' in a different position). For this case, A can be '10' and B can be '01', but since we are using one-hot encoding, we can simplify this to A being '1 and B being '01' where only one bit is ever '1' in the state vector.

Given the transitions:
- From A to A if x=0, output z=0
- From A to B if x=1, output z=1
- From B to B if x=0, output z=1
- From B to B if x=1, output z=0

We can implement this using a combination of combinational logic for the next state and output logic, and sequential logic (flip-flops) to store the current state. The asynchronous reset will be used to initialize the state to A upon reset.

The combinational logic for the next state and output can be derived from the given transitions and the current state.
