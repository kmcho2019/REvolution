To implement the given Mealy finite-state machine using one-hot encoding, we first identify the states (A and B) and assign a unique bit to each state. The states will be encoded as follows: A = 2'b01 and B = 2'b10 (note the use of one-hot encoding where only one bit is '1' at any time, but here we only have two states so it resembles binary encoding). 

We will then implement the state machine's transitions and output logic based on the current state and input. Since it's a Mealy machine, the output (z) is a function of both the current state and the input (x). 

The reset is asynchronous and active-high, meaning the state machine resets to state A regardless of the clock whenever 'areset' is high. 

We'll use Verilog's always @(posedge clk or posedge areset) block to handle both the clock and reset conditions for sequential logic.
