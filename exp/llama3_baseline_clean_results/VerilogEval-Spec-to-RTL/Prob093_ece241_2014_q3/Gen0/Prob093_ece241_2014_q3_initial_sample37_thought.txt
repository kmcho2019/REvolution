The Karnaugh map can be simplified by focusing on the required outputs for each combination of 'ab' (the selector inputs of the 4-to-1 multiplexer). 
For ab = 00, the output is c'd' = d'c' = c'd, so we need a 2-to-1 multiplexer with 'c' as the selector and 'd' and 1 (for c'd') as inputs.
For ab = 01, the output is c'd' = d'c' = 0 (because there's no 1 in the K-map for any combination of cd when ab=01), so the output can be directly connected to 0.
For ab = 11, the output is cd = c, so we need a 2-to-1 multiplexer with 'd' as the selector and 0 (for d'c) and c (for cd) as inputs.
For ab = 10, the output is c + d' = c + d', so we need a 2-to-1 multiplexer with 'd' as the selector and c (for d'c) and 1 (for dc') as inputs.
