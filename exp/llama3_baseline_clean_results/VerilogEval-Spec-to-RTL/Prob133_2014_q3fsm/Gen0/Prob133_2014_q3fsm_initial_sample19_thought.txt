3. To minimize the number of states, we can use a counter to track the number of w = 1 occurrences within the three clock cycles in state B.
4. The output z should be set to 1 if the counter reaches 2 at the end of the three clock cycles; otherwise, z should be 0.
5. After setting z, the FSM should continue checking w for the next three clock cycles.
