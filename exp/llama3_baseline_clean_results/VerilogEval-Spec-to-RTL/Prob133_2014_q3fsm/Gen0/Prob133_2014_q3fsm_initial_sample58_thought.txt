To implement the finite state machine (FSM) as described, we will use a simple state machine with four states: A (reset state), B (checking w), and two intermediate states (B1, B2) to track the number of times w = 1 in the three clock cycles after transitioning from A to B. 

1. In state A, the FSM stays in A if s = 0 and moves to state B if s = 1.
2. In state B, the FSM starts counting the number of w = 1 in the next three clock cycles, transitioning through states B1 and B2 to keep track of this count.
3. After three cycles in B (or its sub-states), the FSM checks the count: if exactly two w = 1, then set z = 1 in the next cycle; otherwise, z = 0. Then, it transitions back to state B to continue checking w in the next three cycles.
4. The FSM also needs to handle the reset condition, where if reset is high, it transitions back to state A regardless of its current state.

Given these requirements, we can minimize the states and use counters or flags within the states to keep track of the counts and conditions.
