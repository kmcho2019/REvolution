To implement the finite state machine described, we can use a simple state machine with two main states: A and B. State A is the reset state, and the machine remains in this state as long as s = 0. When s = 1, the machine transitions to state B. In state B, we need to count the number of clock cycles where w = 1 over a window of three clock cycles. We can use a counter to keep track of the number of w = 1 occurrences. If the count is exactly 2 after three clock cycles, we set the output z to 1 in the next clock cycle. Otherwise, z remains 0. We can use a separate counter to keep track of the current clock cycle within the three-cycle window. 
We will also need a variable to hold the value of z until it is time to output it. 
We will use two always blocks: one for the sequential logic (triggered on the positive edge of the clock) and another for the combinational logic.
