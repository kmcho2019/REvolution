To implement the finite state machine (FSM) as described, we can use a total of two states: A and B. 
State A is the initial state and the reset state, where the FSM stays as long as s = 0. 
When s = 1, the FSM transitions to state B. In state B, we need to keep track of the number of clock cycles 
where w = 1 over the next three cycles to determine the output z in the following cycle. 
This can be achieved using a counter to count the number of w = 1 instances and another counter to keep track of the current cycle within the three-cycle window. 
The output z should be set to 1 if the count of w = 1 is exactly 2 over the three cycles, and 0 otherwise.
We reset the count and cycle counters at the end of each three-cycle window, regardless of the output z.
