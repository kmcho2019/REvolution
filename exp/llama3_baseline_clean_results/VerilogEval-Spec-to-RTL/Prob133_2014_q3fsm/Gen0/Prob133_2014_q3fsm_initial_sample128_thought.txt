The FSM starts in state A and remains there as long as s = 0. 
When s = 1, it moves to state B. In state B, it examines the input w for the next three clock cycles. 
To keep track of the number of w = 1 in these three cycles, we can use a counter.
We will use two states: A and B. 
State B will have two sub-states: B1 (for the first cycle), B2 (for the second cycle), and B3 (for the third cycle).
The FSM will transition from B1 to B2, B2 to B3, and then back to B1.
We will use a counter to count the number of w = 1 in these three cycles.
