To solve this problem, we can design a finite state machine with four states: A, B, C, and D. State A is the reset state. When s = 1, the FSM transitions from state A to state B. In state B, we start counting the number of times w = 1 over the next three clock cycles. We can use two additional states, C and D, to track the count of w = 1. If w = 1 exactly twice during these three cycles, we set the output z to 1 in the next cycle. Otherwise, z remains 0. We will use a counter to keep track of the number of clock cycles since the FSM entered state B and a separate counter to count the number of times w = 1.
