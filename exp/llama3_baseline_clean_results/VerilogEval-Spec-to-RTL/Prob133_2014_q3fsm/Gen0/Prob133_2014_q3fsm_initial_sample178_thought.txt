To implement the finite state machine described, we can use a Moore machine approach. The FSM starts in state A and remains there until s = 1, at which point it transitions to state B. Once in state B, it examines the input w over the next three clock cycles. We can use a counter to keep track of the number of clock cycles since entering state B and another counter to count the number of times w = 1 during this period. After three clock cycles, if the count of w = 1 is exactly 2, we set the output z to 1; otherwise, we set it to 0. This process repeats indefinitely.

We will use the following states:
- State A: The initial state, where the FSM waits for s = 1 to transition to state B.
- State B: The state where the FSM counts the number of w = 1 over three clock cycles.

We will use two counters:
- A 2-bit counter to count the clock cycles since entering state B (0 to 3).
- A 2-bit counter to count the number of times w = 1 during the three clock cycles.

The output z is determined by the value of the w counter when the clock cycle counter reaches 3.
