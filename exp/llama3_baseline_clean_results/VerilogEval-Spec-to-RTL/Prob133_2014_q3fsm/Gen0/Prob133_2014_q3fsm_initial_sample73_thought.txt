To implement the required finite state machine (FSM), we will use three states: A, B, and B_ext (extended B state to count w = 1 occurrences). We start in state A and transition to state B when s = 1. Once in state B, we count the occurrences of w = 1 for the next three clock cycles. We can achieve this by using two counters: one for the clock cycles and another for the w = 1 occurrences. After three clock cycles, we check the occurrences counter and set the output z accordingly. We then reset the counters and repeat the process.
