To implement the TopModule, we need to create 8 D flip-flops with active high synchronous reset. Each flip-flop will have an 8-bit input d and an 8-bit output q. The reset value will be 0x34 (which is 52 in decimal). The flip-flops will be triggered by the negative edge of the clock signal clk. We will use a for loop in Verilog to instantiate the flip-flops and simplify the code.
