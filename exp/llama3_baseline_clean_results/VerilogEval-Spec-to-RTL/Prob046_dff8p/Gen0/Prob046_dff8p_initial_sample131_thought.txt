To implement the TopModule, we will use 8 D flip-flops with active high synchronous reset. Each flip-flop will be connected to the corresponding bit of the input d, and the output q will be connected to the outputs of the flip-flops. The reset input will be connected to the reset input of each flip-flop, and the clock input will be connected to the clock input of each flip-flop, but inverted to achieve the negative edge trigger. The reset value will be set to 0x34.
