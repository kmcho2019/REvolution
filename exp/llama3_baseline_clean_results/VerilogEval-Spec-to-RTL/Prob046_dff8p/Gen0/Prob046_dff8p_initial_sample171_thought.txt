To implement the TopModule, we will use 8 D flip-flops with active high synchronous reset. Each flip-flop will be triggered by the negative edge of the clk signal. The reset value will be 0x34 instead of the typical 0x00. We can use the initial value to set the default value of the flip-flops when they are reset. We will use the always_ff block to describe the sequential behavior of the flip-flops.
