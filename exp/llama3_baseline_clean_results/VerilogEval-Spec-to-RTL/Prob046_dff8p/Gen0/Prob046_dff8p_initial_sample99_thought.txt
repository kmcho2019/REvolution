To implement the TopModule, we will use 8 D flip-flops (DFFs) that are triggered by the negative edge of the clk signal and have an active high synchronous reset. The reset value will be 0x34 instead of the typical zero. We will define a reset vector as a parameter within the module to easily set the initial values of the DFFs. The module will have one 8-bit input d, which will be connected to the input of each DFF, and one 8-bit output q, which will be connected to the output of each DFF.
