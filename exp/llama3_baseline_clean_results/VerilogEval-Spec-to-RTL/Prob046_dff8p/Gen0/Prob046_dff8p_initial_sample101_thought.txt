To implement the TopModule, we need to create a module that includes 8 D flip-flops. 
Each D flip-flop should have an active high synchronous reset, meaning it will reset 
only on the negative edge of the clock when reset is high. The reset value for the 
D flip-flops should be 0x34 instead of the typical 0x00. We can achieve this by 
using the initial value of the flip-flops and a conditional reset assignment. 
However, in Verilog, using the initial value for flip-flops is not synthesizable, 
so we should use a different approach. We will use a parameter to define the reset 
value and use it in the reset logic. Since the DFFs should be triggered by the 
negative edge of clk, we will use the negedge keyword in the always block.
