To implement the TopModule, we need to create a module that includes 8 D flip-flops. Each D flip-flop will have an active high synchronous reset, meaning that when the reset signal is high, the flip-flop will reset to the specified value. In this case, the flip-flops will reset to 0x34. The D flip-flops will be triggered by the negative edge of the clock signal (clk). This can be achieved by using the negedge keyword in the sensitivity list of the always block that describes the behavior of the D flip-flops. We will use a for loop to instantiate the 8 D flip-flops and assign the reset value of 0x34.
