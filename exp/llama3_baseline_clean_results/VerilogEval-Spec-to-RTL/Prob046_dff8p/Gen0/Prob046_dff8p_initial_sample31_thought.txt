To implement the TopModule, we need to create 8 D flip-flops that are triggered by the negative edge of the clock signal. Each flip-flop should have an active high synchronous reset. However, instead of resetting to zero, we want them to reset to the value 0x34. This requires us to specify the reset value for each flip-flop individually. We'll use the always block in Verilog to describe the behavior of the flip-flops, and we'll utilize the @(negedge clk or posedge reset) sensitivity list to ensure the flip-flops are triggered at the correct times.
