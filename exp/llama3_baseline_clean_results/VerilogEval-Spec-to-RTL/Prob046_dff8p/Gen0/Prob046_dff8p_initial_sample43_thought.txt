To implement the TopModule, we will create a module that includes 8 D flip-flops, each with an active high synchronous reset. Since the reset value is 0x34, we will use this value to initialize the flip-flops when reset is high. The D flip-flops will be triggered by the negative edge of the clock signal clk. We will use the non-blocking assignment operator (<=) to assign the values to the output q inside a always block that is sensitive to the negative edge of clk and the reset signal.
