To implement the TopModule, we need to create a module that includes 8 D flip-flops. Each flip-flop should have an active high synchronous reset and should reset to a value of 0x34. Since the reset value is not zero, we cannot simply use a reset value of 8'b0, but instead need to specify the exact value of 0x34. We will also use the negative edge of the clock signal to trigger the flip-flops.
