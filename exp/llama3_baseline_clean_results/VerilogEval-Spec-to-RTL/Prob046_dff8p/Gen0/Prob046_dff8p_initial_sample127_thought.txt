To implement the TopModule, we need to create a module that includes 8 D flip-flops. 
Each flip-flop should have an active high synchronous reset, meaning the reset should 
only be applied on the negative edge of the clock when the reset signal is high. 
We will use the initial reset value 0x34, which in binary is 00110100. 
The D flip-flops should be triggered by the negative edge of the clock, 
meaning they should capture the input data on the falling edge of the clock.
