To implement the TopModule, we will use 8 instances of D flip-flops with active high synchronous reset. Since the reset value is not the usual zero, we need to explicitly set the reset value to 0x34 for each flip-flop. We will use the negedge of the clk to trigger the flip-flops. The d input will be connected to the D input of each flip-flop, and the q output will be connected to the Q output of each flip-flop.
