To implement the TopModule, we will create a module that contains 8 D flip-flops with active high synchronous reset. Each D flip-flop will be triggered by the negative edge of the clock (clk). Since we need to reset the flip-flops to 0x34 instead of zero, we will hardcode the reset value inside the module. The reset signal (reset) will be active high and synchronous, meaning it will reset the flip-flops on the negative edge of clk when reset is high.
