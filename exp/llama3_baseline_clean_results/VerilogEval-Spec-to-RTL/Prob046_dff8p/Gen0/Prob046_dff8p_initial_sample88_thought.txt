To implement the TopModule, we need to create a module that includes 8 D flip-flops. Each D flip-flop will have an active high synchronous reset, meaning the reset will occur on the positive edge of the clock. However, since we want the DFFs to be triggered by the negative edge of clk, we will use the inverted clk signal. The reset value for all DFFs will be set to 0x34. We can use a for loop in Verilog to generate the 8 DFFs, making the code more concise.
