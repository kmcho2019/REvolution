To implement the TopModule, we need to create 8 D flip-flops (DFFs) with active high synchronous reset. Each DFF should be triggered by the negative edge of the clock signal clk. We will use Verilog's built-in always block to define the behavior of each DFF. The reset value for all DFFs will be set to 0x34 (00110100 in binary) instead of the traditional reset value of zero.
