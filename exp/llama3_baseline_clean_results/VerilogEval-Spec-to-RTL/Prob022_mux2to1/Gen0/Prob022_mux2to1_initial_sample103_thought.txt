To implement a 2-to-1 multiplexer, we can use a conditional statement to assign the value of either input 'a' or input 'b' to the output 'out' based on the select signal 'sel'. This can be achieved using a simple if-else statement in Verilog, where 'out' is assigned the value of 'a' when 'sel' is 0 and the value of 'b' when 'sel' is 1.
