To implement a 2-to-1 multiplexer, we can use a simple if-else statement or a conditional operator (ternary operator) in Verilog. The idea is to check the value of the select line 'sel'. If 'sel' is 0, the output 'out' should be assigned the value of 'a', and if 'sel' is 1, the output 'out' should be assigned the value of 'b'. This can be achieved using a continuous assignment with a conditional operator, making the module combinational.
