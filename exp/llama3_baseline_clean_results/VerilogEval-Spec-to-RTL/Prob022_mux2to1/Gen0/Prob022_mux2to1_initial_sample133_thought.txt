To implement a 2-to-1 multiplexer, we need to use a conditional statement to select between inputs 'a' and 'b' based on the value of 'sel'. In Verilog, this can be achieved using the ternary operator or an if-else statement. Here, we will use the ternary operator to assign the value of 'out' based on the value of 'sel'.
