To implement a 2-to-1 multiplexer, we can use a simple if-else statement or a ternary operator in Verilog. The multiplexer will select either input 'a' or 'b' based on the 'sel' input. When 'sel' is 0, 'a' will be selected, and when 'sel' is 1, 'b' will be selected. This can be implemented using a conditional assignment statement.
