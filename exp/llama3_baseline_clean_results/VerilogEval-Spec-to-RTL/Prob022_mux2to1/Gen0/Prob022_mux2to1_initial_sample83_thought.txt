To implement a 2-to-1 multiplexer, we can use a simple conditional statement in Verilog that checks the value of the select line (sel). If sel is 0, we assign the value of input 'a' to the output 'out'. If sel is 1, we assign the value of input 'b' to the output 'out'. This can be achieved using a ternary operator or an if-else statement. However, for simplicity and clarity, the ternary operator is preferred.
