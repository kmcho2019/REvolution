To implement a 2-to-1 multiplexer, we can use a conditional statement to select between inputs 'a' and 'b' based on the 'sel' input. In Verilog, this can be achieved using the ternary operator or an if-else statement. However, for a simple multiplexer, the ternary operator is more concise and efficient. The idea is to assign the value of 'a' to 'out' when 'sel' is 0, and the value of 'b' to 'out' when 'sel' is 1.
