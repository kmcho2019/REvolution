To implement the TopModule, we can directly assign the input vec to the output outv since it requires the same 3-bit vector. For the separate 1-bit outputs (o2, o1, o0), we can use bit slicing to extract each bit from the input vec and assign it to the corresponding output. The bit slicing will be based on the position of the bit in the vec, starting from the most significant bit (MSB) as position 2 and the least significant bit (LSB) as position 0.
