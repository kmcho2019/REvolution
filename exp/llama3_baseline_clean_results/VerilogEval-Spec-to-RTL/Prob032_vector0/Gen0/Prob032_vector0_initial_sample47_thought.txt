To implement the TopModule, we can use simple continuous assignments in Verilog. 
The module will have one input vector of 3 bits (vec) and four output ports: 
outv (3 bits) which will be a direct copy of the input vector, and o2, o1, o0 
(each 1 bit) which will be connected to the corresponding bit positions of the 
input vector vec. We can use bit-slicing to assign the individual bits of the 
input vector to the output ports o2, o1, and o0.
