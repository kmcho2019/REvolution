The TopModule will take a 3-bit input vector and output it as a 3-bit vector outv. Additionally, it will split the input vector into three separate 1-bit outputs, where o0 corresponds to the least significant bit (position 0) of the input vector, o1 corresponds to the next bit (position 1), and o2 corresponds to the most significant bit (position 2). This can be achieved by simple assignment statements in Verilog.
