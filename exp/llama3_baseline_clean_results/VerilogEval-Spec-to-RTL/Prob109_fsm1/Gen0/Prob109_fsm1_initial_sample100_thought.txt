To implement the Moore machine, we will use two states (A and B) and 
design a state machine with two possible states. The output will be 
1 when the state machine is in state B and 0 when it is in state A. 
The state machine will transition from B to A when the input is 0, 
from A to B when the input is 0, and will stay in B when the input is 
1. An asynchronous reset will be used to reset the state machine into 
state B whenever the areset signal is high.
