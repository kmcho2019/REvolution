The Moore machine has two states: A and B. The next state and output logic can be implemented using a simple state machine. We will use a 1-bit variable to store the current state, with 0 representing state A and 1 representing state B. We will also use a 1-bit variable for the output. The next state logic will be based on the current state and input. When areset is high, the state machine will asynchronously reset to state B.
