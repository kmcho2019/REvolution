The Moore machine described has two states, A and B. We can represent these states using a single bit variable, where state A is represented by '0' and state B by '1'. Based on the transition diagram, when the current state is A (0) and the input is '0', we should transition to state B (1). If the current state is A (0) and the input is '1', we stay in state A (0). If the current state is B (1) and the input is '0', we transition to state A (0). If the current state is B (1) and the input is '1', we stay in state B (1). The output out is determined by the current state. According to the state diagram, when the state is B (1), the output is 1, and when the state is A (0), the output is 0. This means the output directly follows the state. We will use an asynchronous reset to reset the state to B (1) when areset is high.
