To implement the Moore machine as described, we need to first define the states A and B and their corresponding outputs. 
The state transitions are as follows: 
- When in state B and input 'in' is 0, move to state A. 
- When in state B and input 'in' is 1, stay in state B. 
- When in state A and input 'in' is 0, move to state B. 
- When in state A and input 'in' is 1, stay in state A. 
The output 'out' corresponds to the current state, where state A has an output of 0 and state B has an output of 1. 
The reset 'areset' should asynchronously reset the state to B.
