To implement the Moore machine, we first need to identify the states and their corresponding transitions. The states are A and B. The state transitions are as follows:
- If the current state is B, on a 0 input, move to state A, and on a 1 input, stay in state B.
- If the current state is A, on a 0 input, move to state B, and on a 1 input, stay in state A.
We will use an enumeration to define the states and a case statement to handle the state transitions.
The output 'out' should be the current state of the Moore machine.
The module should asynchronously reset into state B when 'areset' is high.
