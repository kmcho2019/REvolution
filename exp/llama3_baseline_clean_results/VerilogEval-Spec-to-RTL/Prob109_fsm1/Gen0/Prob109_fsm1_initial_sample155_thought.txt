We can represent these states using a 1-bit signal, where state A is represented by 0 and state B is represented by 1. The output of the machine is the current state.

We will use a simple if-else statement inside an always block to describe the state transition logic. The always block should be sensitive to the clock and the asynchronous reset signal.

However, since we are designing a synchronous digital circuit, it is more common to use the areset signal in the always block.
