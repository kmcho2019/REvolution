To implement the Moore machine described, we need to first identify the states and transitions. The machine has two states: A and B. The transitions are as follows: 
- From state B, on input 0, it transitions to state A, and on input 1, it stays in state B.
- From state A, on input 0, it transitions to state B, and on input 1, it stays in state A.
We will use an always block to handle the asynchronous reset and the state transitions. 
The output 'out' will be determined by the current state, as the machine is a Moore machine, meaning the output is a function of the state only. 
In this case, state B will correspond to output 1, and state A will correspond to output 0.
