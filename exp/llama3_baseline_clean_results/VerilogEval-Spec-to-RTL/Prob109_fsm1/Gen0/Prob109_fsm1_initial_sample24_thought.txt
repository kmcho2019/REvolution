The module TopModule should be implemented as a Moore machine with two states: A and B. The state transitions are as follows: from state B, if the input 'in' is 0, the next state is A; if 'in' is 1, the next state remains B. From state A, if 'in' is 0, the next state is B; if 'in' is 1, the next state remains A. The output 'out' should be the current state of the machine, with state A corresponding to output 1 and state B corresponding to output 0. We will use a 1-bit reg variable to store the current state. We will also implement an asynchronous reset to ensure the machine resets to state B when 'areset' is high.
