The current module has a bug where the `shut_off_computer` and `keep_driving` signals are not being handled correctly when the conditions are not met. For `shut_off_computer`, it should be set to 0 when `cpu_overheated` is not high. For `keep_driving`, it should be set to 0 when `arrived` is high or `gas_tank_empty` is high. We need to modify the always blocks to handle these conditions.
