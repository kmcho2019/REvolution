To implement the TopModule, we need to sign-extend an 8-bit number to 32 bits. 
This can be done by replicating the sign bit (most significant bit) of the 8-bit number 
24 times to the left and then concatenating it with the original 8-bit number. 
In Verilog, we can achieve this by using the replication operator ({}) and the 
concatenation operator ({}) as well. 
We will replicate the sign bit (in[7]) 24 times and then concatenate it with the 
8-bit input (in).
