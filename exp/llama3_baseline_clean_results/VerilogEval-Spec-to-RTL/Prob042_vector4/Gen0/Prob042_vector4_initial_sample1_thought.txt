To implement the TopModule, we will use the replication operator to sign-extend the 8-bit input number to 32 bits. This involves concatenating 24 copies of the sign bit (most significant bit) with the original 8-bit number. We can achieve this by using Verilog's replication operator ({}) and concatenation operator ({ }). The sign bit can be accessed as in[7] (since Verilog uses 0-based indexing).
