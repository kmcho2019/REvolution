To sign-extend the 8-bit input to 32 bits, we first need to determine the sign bit of the input number. The sign bit is the most significant bit of the input number, which is bit[7]. Then, we replicate this sign bit 24 times to create the most significant 24 bits of the output. The least significant 8 bits of the output will be the input number itself. This can be achieved using Verilog's concatenation operator and replication operator.
