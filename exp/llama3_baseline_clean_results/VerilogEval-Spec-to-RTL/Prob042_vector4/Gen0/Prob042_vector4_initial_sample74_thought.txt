To sign-extend an 8-bit number to 32 bits, we need to replicate the sign bit (most significant bit, MSB) of the 8-bit number 24 times and concatenate it with the original 8-bit number. This will ensure that the signed value is preserved during the extension. In Verilog, we can achieve this by using the replication operator to create a 24-bit vector of the sign bit and then concatenating it with the 8-bit input using the concatenation operator.
