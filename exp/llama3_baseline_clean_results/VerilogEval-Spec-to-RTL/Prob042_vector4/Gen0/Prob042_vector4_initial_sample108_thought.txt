The module TopModule will take an 8-bit input and sign-extend it to 32 bits. This can be achieved by checking the most significant bit (MSB) of the input, which determines whether the number is positive or negative. If the number is negative (MSB is 1), we will replicate the MSB 24 times to the left of the input number. If the number is positive (MSB is 0), we will replicate 0 24 times to the left of the input number. This can be implemented in Verilog using the replication operator and concatenation.
