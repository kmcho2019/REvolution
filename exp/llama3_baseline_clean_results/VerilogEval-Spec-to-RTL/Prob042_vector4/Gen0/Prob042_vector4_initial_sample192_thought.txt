To implement the TopModule, we can use the concatenation operator in Verilog to sign-extend the 8-bit input number to 32 bits. The sign bit of the 8-bit number (i.e., the most significant bit, in[7]) will be replicated 24 times to the left, and then concatenated with the original 8-bit number. This is achieved using the replication operator ({24{in[7]}}) and the concatenation operator ({...,...}).
