To sign-extend an 8-bit number to 32 bits, we need to replicate the sign bit (most significant bit) 24 times and concatenate it with the original 8-bit number. This can be achieved in Verilog using a concatenation operator and a replication operator. The replication operator `{N{bit}}` creates a new bit vector by repeating `bit` `N` times. The concatenation operator `{a, b}` combines two bit vectors `a` and `b` to form a new vector. We can use these operators to sign-extend the input 8-bit number.
