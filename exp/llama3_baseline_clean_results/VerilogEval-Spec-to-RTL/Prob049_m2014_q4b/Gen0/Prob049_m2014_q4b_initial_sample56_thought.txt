To implement a D flip flop with an asynchronous reset, we need to use a reg to store the state and assign the output q to this reg. The reg will be updated on the positive edge of the clock if the asynchronous reset is not active. If the asynchronous reset is active, the reg will be reset to 0 regardless of the clock. We will use the always @(posedge clk or posedge ar) block to capture the positive edge of both the clock and the asynchronous reset.
