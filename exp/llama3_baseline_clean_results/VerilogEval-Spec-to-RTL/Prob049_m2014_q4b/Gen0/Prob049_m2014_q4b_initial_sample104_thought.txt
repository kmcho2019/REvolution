To implement a D flip flop with an asynchronous reset, we can use the following logic: 
when the asynchronous reset 'ar' is high, the output 'q' should immediately go low, 
regardless of the current state of the clock or data input 'd'. 
When 'ar' is low, the flip flop should behave as a standard D flip flop, 
capturing the value of 'd' on the positive edge of the clock 'clk' and holding that value until the next positive edge.
We will use a reg to hold the current state of the flip flop and an initial block to set the initial value of 'q' to 0.
The asynchronous reset will be implemented using a separate if condition outside of the clock edge condition.
