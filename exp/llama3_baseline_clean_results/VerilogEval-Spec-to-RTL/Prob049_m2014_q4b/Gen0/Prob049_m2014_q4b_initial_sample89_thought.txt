- When the asynchronous reset 'ar' is high, the output 'q' should be reset to 0, regardless of the clock or input 'd'.
- When the asynchronous reset 'ar' is low, the D flip flop should behave as a standard positive edge triggered flip flop, where the output 'q' takes the value of the input 'd' at the rising edge of the clock 'clk'.
This can be achieved using a simple if-else statement in Verilog, where we first check the asynchronous reset condition and then the clock edge condition.
