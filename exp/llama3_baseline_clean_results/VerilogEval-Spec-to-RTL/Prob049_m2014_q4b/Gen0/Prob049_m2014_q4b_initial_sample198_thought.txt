To implement a D flip flop with an asynchronous reset, we can use a single always block in Verilog. The always block should be sensitive to the positive edge of the clock signal "clk" and to the asynchronous reset signal "ar". When "ar" is high, the output "q" should be reset to 0 regardless of the clock. When "ar" is low and the clock signal "clk" is on its rising edge, the output "q" should be updated to the value of the input "d".
