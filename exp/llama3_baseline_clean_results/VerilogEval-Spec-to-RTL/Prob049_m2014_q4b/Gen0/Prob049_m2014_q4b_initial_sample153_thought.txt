To implement a D flip flop with asynchronous reset, we will use a reg to store the output q and initialize it to 0. We will then use an always block that is sensitive to the positive edge of the clock (posedge clk) or the asynchronous reset (ar). If ar is high, q will be reset to 0. If ar is low, on the positive edge of the clock, q will be assigned the value of the input d.
