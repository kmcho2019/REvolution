To implement a D flip flop with an asynchronous reset, we will use a reg to hold the state of the flip flop. The reg will be assigned a new value on the positive edge of the clock (clk) if the asynchronous reset (ar) is not asserted. If ar is asserted, the reg will be reset to 0, regardless of the clock. This can be achieved using a conditional statement inside an always block that is sensitive to the clock and the asynchronous reset.
