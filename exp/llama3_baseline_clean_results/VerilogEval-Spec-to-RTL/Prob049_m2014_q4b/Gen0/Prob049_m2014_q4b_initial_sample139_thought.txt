To implement a D flip flop with an asynchronous reset, we need to use a reg variable to store the current state of the flip flop. We will use an always block that is sensitive to the positive edge of the clock (clk) and to the asynchronous reset (ar). If ar is high, the flip flop will be reset regardless of the clock. If ar is low, the flip flop will latch the input d on the positive edge of clk.
