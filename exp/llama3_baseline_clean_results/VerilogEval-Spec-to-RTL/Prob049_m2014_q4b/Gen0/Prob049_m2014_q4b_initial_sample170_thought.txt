To implement a D flip flop with an asynchronous reset, we need to consider two main conditions: 
1. When the asynchronous reset 'ar' is high, the output 'q' should be immediately reset to 0, regardless of the current state of the clock 'clk' or the input 'd'. 
2. When 'ar' is low, the module should behave as a standard positive edge triggered D flip flop. This means that on the rising edge of 'clk', the output 'q' should be updated to the current value of the input 'd'. 
We can achieve this using a simple if-else statement within an always block in Verilog, checking the condition of 'ar' first, since it's asynchronous and should take precedence over the synchronous operation based on 'clk'.
