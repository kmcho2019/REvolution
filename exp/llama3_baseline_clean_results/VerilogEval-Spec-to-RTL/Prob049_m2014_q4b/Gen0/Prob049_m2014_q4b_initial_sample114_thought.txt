To implement a D flip flop with an asynchronous reset, we need to use a reg to store the state of the flip flop. The reg will be assigned the value of the input 'd' when the clock 'clk' rises (positive edge) and there is no reset ('ar' is low). If 'ar' is high, the flip flop should reset immediately, regardless of the clock state. We can achieve this using an always block with a posedge condition for the clock and an if condition for the reset.
