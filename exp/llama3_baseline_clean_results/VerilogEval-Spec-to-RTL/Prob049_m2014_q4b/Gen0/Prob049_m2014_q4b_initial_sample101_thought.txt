To implement a D flip flop with an asynchronous reset, we need to use a reg to store the state of the flip flop. The reg will be assigned the value of the input 'd' when the clock 'clk' rises (positive edge) and there is no reset. If the asynchronous reset 'ar' is high, the reg should be reset to 0 immediately, regardless of the clock. This can be achieved using a single always block that checks for the reset condition first and then for the clock edge.
