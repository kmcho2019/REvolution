- The D flip flop should have a positive edge triggered clock input (clk) and an asynchronous active-low reset input (ar).

- If the asynchronous reset (ar) is active (i.e., ar = 0), the D flip flop should immediately reset its output (q) to 0, regardless of the clock or input (d).
