To implement a D flip flop with an asynchronous reset, we can use a reg to store the value of the flip flop. The value of the flip flop should be updated on the positive edge of the clock if the asynchronous reset is not active. If the asynchronous reset is active, the value of the flip flop should be reset to 0 immediately. We can use the always@(posedge clk or posedge ar) block to capture both the clock edge and the asynchronous reset. Inside this block, we first check if the asynchronous reset is active. If it is, we reset the value of the flip flop. If not, we check if the clock has just risen (i.e., the current clock value is 1 and the previous clock value was 0), and if so, we update the value of the flip flop with the value of the input d.
