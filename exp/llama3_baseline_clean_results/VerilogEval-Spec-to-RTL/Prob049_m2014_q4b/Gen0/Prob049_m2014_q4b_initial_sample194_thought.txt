To implement a D flip flop with an asynchronous reset, we need to use a reg to hold the current state of the flip flop. The reg should be assigned a new value based on the input 'd' when the clock 'clk' goes high, and reset to 0 when 'ar' goes high. We will use a non-blocking assignment to assign the new value to the reg, and use the 'posedge' keyword to trigger the assignment on the positive edge of the clock.
