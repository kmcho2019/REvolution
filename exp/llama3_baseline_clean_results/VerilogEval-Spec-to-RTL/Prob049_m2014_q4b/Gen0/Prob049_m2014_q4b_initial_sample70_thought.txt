To implement a D flip flop with an asynchronous reset, we need to consider two main conditions: 
1) When the asynchronous reset (ar) is high, the output q should be immediately reset to 0 regardless of the clock or input d.
2) When the asynchronous reset (ar) is low, the D flip flop should behave as a standard positive edge triggered flip flop, where the output q takes the value of input d at every positive edge of the clock (clk).
We will use an if-else statement within a always block to capture these conditions and assign the output accordingly.
