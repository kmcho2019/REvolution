To implement the TopModule, we will create a module with the specified interface. 
We will use an assign statement to implement a continuous assignment XOR gate for out_assign.
We will use a combinational always block to implement an XOR gate for out_always_comb.
We will use a clocked always block to implement an XOR gate with a flip-flop for out_always_ff, 
which will delay the output by one clock cycle due to the sequential logic.
