The TopModule should contain three separate implementations of an XOR gate. 
The first implementation will use a continuous assignment statement, which 
will immediately reflect any changes in inputs a and b. The second 
implementation will use a combinational always block, which also reflects 
any changes in inputs a and b without any delay. The third implementation 
will use a clocked always block, which will only update the output 
(out_always_ff) at the positive edge of the clock, thus introducing a delay 
compared to the first two implementations.
