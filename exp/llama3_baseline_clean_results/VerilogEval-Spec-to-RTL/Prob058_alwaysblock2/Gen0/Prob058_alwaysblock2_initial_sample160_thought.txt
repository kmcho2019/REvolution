1. Using an assign statement for continuous assignment, which will directly reflect the output of the XOR operation between inputs 'a' and 'b'. 
2. Using a combinational always block, which will also directly reflect the output of the XOR operation between 'a' and 'b' but provides more flexibility for complex combinational logic.
3. Using a clocked always block, which introduces a flip-flop to delay the output of the XOR operation by one clock cycle, capturing the result on the positive edge of 'clk'.
