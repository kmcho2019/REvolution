The module TopModule will be implemented with three separate methods to create an XOR gate. 
First, an assign statement will be used to continuously assign the XOR of inputs a and b to output out_assign. 
Second, a combinational always block will be used to assign the XOR of inputs a and b to output out_always_comb whenever either input changes.
Lastly, a clocked always block will be used to create a flip-flop, where on each positive edge of the clock, the XOR of inputs a and b will be assigned to output out_always_ff, effectively delaying the output by one clock cycle.
