To implement the TopModule, we will use three different methods to create an XOR gate: 
1. Continuous assignment: This will be used to create the out_assign output.
2. Combinational always block: This will be used to create the out_always_comb output.
3. Clocked always block: This will be used to create the out_always_ff output. 
   This will involve a flip-flop to delay the output, effectively creating a register.
