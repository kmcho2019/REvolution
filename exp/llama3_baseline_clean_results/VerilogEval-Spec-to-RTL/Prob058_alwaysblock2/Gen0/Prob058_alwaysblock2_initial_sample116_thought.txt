The TopModule should contain three separate implementations of an XOR gate: 
1. Using a continuous assign statement for out_assign, which will perform the XOR operation directly on inputs a and b.
2. Using an always_comb block for out_always_comb, which will also perform the XOR operation on inputs a and b but allows for more complex combinational logic if needed.
3. Using an always_ff block for out_always_ff, which will introduce a flip-flop and thus a delay in the output, requiring the XOR operation to be performed on the current or previous inputs and the result to be stored until the next positive clock edge.
