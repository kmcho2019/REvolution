The TopModule will be implemented with three different methods to create an XOR gate. 
The first method uses an assign statement, which is a continuous assignment that drives the output out_assign with the XOR of inputs a and b. 
The second method uses an always_comb block, which is a combinational logic block that drives the output out_always_comb with the XOR of inputs a and b. 
The third method uses an always_ff block, which is a sequential logic block that drives the output out_always_ff with the XOR of inputs a and b on the positive edge of the clock. 
This will introduce a delay of one clock cycle in the output out_always_ff compared to the other two methods.
