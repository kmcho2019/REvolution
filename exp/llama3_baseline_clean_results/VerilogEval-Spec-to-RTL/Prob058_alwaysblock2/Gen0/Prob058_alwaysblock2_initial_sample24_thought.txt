The module TopModule will implement an XOR gate three ways: 
1. Using an assign statement for continuous assignment, 
2. Using a combinational always block for procedural continuous assignment, 
3. Using a clocked always block to create a sequential logic circuit with a flip-flop.

The assign statement will continuously update out_assign with the result of a XOR operation between inputs a and b.
The combinational always block will update out_always_comb with the result of a XOR operation between inputs a and b whenever either input changes.
The clocked always block will update out_always_ff with the result of a XOR operation between inputs a and b on every positive edge of the clock, effectively creating a flip-flop that delays the output.
