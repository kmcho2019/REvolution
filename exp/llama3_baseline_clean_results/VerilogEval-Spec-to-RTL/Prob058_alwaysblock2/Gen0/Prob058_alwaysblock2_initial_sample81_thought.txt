To implement the TopModule, we need to create three different XOR gates: 
one using an assign statement for a continuous assignment, 
one using a combinational always block, and 
one using a clocked always block for a sequential logic implementation.

The assign statement and the combinational always block will produce the same result, 
which is the XOR of inputs a and b.
The clocked always block, however, will implement a flip-flop that captures the XOR result 
on the positive edge of the clock, causing the output to be delayed by one clock cycle.
