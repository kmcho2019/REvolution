To implement the TopModule, we need to use three different methods to create an XOR gate. 
The first method uses an assign statement to continuously assign the XOR of inputs a and b to out_assign.
The second method uses a combinational always block to achieve the same result and assign it to out_always_comb.
The third method uses a clocked always block to create a flip-flop, which will delay the output by one clock cycle and assign it to out_always_ff.
We will use the XOR operator (^) to perform the XOR operation.
