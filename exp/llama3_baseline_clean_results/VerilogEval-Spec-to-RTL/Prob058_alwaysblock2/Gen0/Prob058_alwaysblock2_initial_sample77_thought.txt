To implement the TopModule, we will use three different methods to create an XOR gate. 
First, we will use a continuous assign statement to create a combinational XOR gate, 
which will be assigned to the out_assign output. 
Next, we will use an always_comb block to create another combinational XOR gate, 
which will be assigned to the out_always_comb output. 
Finally, we will use an always_ff block to create a sequential XOR gate with a flip-flop, 
which will be assigned to the out_always_ff output. 
The sequential XOR gate will be triggered on the positive edge of the clock, 
resulting in a delayed output compared to the combinational XOR gates.
