The module TopModule can be implemented by using three different methods to create an XOR gate. 
Firstly, an assign statement can be used to continuously assign the XOR of inputs a and b to out_assign. 
Secondly, an always_comb block can be used to create a combinational logic that XORs inputs a and b and assigns the result to out_always_comb. 
Lastly, an always_ff block can be used to create a sequential logic that XORs inputs a and b and assigns the result to out_always_ff on every positive edge of the clock, thus introducing a delay.
