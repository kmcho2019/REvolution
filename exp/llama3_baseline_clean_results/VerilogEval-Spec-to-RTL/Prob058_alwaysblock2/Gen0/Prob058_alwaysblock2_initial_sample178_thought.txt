To implement the TopModule, we need to use three different methods to create an XOR gate: 
1. Continuous assignment using the assign statement. 
2. Combinational always block that will be executed whenever either of the inputs changes. 
3. Sequential always block (always_ff in SystemVerilog or always with a clock and reset in Verilog) to create a flip-flop that will be triggered on the positive edge of the clock. 
This way, we ensure that the output out_assign and out_always_comb will have the same value as the XOR of inputs a and b, while out_always_ff will have the value of the XOR of inputs a and b from the previous clock cycle.
