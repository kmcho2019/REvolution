To implement the TopModule, we will use three different methods to achieve the XOR operation: 
1. Continuous assignment using the assign statement, which directly assigns the result of the XOR operation between inputs a and b to the output out_assign.
2. Combinational always block, which uses the always_comb keyword (or always @(*) for older Verilog versions) to continuously evaluate the XOR expression and assign the result to out_always_comb.
3. Clocked always block (always_ff in SystemVerilog, or always @(posedge clk) in Verilog), which uses a flip-flop to register the result of the XOR operation. The output out_always_ff will be delayed by one clock cycle compared to the other two outputs.
