To implement the TopModule, we need to follow these steps:
1. Design a sequential logic that updates the game state every clock cycle.
2. Use the load signal to load the initial state into the game grid at the next clock edge.
3. Calculate the next state of each cell based on the number of its neighbors.
4. Use a toroidal approach to calculate the neighbors of each cell, wrapping around the grid when necessary.

We will use a 256-bit vector to represent the 16x16 grid, with each row of 16 cells represented by a sub-vector.
