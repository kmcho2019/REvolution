To implement the TopModule, we need to follow these steps:
- Create a 16x16 grid representation using a 256-bit vector.
- Implement the load functionality, which loads the data into the grid at the next clock edge.
- Calculate the number of neighbours for each cell.
- Update the state of each cell based on the number of neighbours.
- Repeat the process for every clock cycle.

We will use a combination of always blocks, for loops, and if-else statements to achieve this.
