To implement the TopModule, we need to generate the three output vectors based on the input vector in. 
For out_both, we compare each bit of the input vector with its neighbour to the left, starting from the most significant bit (MSB) and moving to the least significant bit (LSB). 
For out_any, we compare each bit of the input vector with its neighbour to the right, starting from the MSB and moving to the LSB. 
For out_different, we compare each bit of the input vector with its neighbour to the left, wrapping around the vector so that the neighbour of the MSB is the LSB.

To achieve this, we can use a for loop to iterate over the input vector and calculate each bit of the output vectors accordingly.
