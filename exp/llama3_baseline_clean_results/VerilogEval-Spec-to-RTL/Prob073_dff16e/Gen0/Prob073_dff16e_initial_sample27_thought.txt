To implement the TopModule, we will create a module that includes 16 D flip-flops. 
We'll use two byte-enable inputs (byteena) to control whether each byte of the 
16 registers should be written to on that cycle. We will use a synchronous reset 
(resetn) and the positive edge of the clock (clk) to trigger the D flip-flops. 
The data input (d) will be divided into two bytes, with byteena[1] controlling 
the upper byte and byteena[0] controlling the lower byte. 
The output (q) will be the current state of the 16 flip-flops.
