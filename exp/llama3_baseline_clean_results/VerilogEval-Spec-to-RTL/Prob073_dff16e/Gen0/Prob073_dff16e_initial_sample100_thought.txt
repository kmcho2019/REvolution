To implement the TopModule, we will use 16 D flip-flops. We will control the writing of each byte of the registers using the byteena inputs. If byteena[1] is high, we write to the upper byte (d[15:8]), and if byteena[0] is high, we write to the lower byte (d[7:0]). The resetn input is used to reset all the flip-flops synchronously when it is low. We will use the posedge of the clk to trigger the D flip-flops. We will use Verilog's procedural assignment within an always block to describe the behavior of the flip-flops.
