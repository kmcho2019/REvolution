To implement the TopModule, we will create 16 D flip-flops. The byteena inputs will be used to control whether each byte of the DFFs should be written to on that cycle. We will use the byteena[1] to control the upper byte (d[15:8]) and byteena[0] to control the lower byte (d[7:0]). The resetn input will be used as a synchronous, active-low reset, which means when resetn is low, all DFFs will be reset to 0. The DFFs will be triggered by the positive edge of the clk input. 
We will use two always blocks: one to handle the reset and the other to handle the DFFs' update logic.
