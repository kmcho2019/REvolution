To implement the TopModule, we can use 16 D flip-flops. Each D flip-flop should be triggered by the positive edge of the clk signal. The resetn signal should asynchronously reset all D flip-flops when it goes low. The byteena signal will control whether each byte of the registers should be written to on that cycle. We will use the byteena[1] to control the upper byte (d[15:8]) and byteena[0] to control the lower byte (d[7:0]).
