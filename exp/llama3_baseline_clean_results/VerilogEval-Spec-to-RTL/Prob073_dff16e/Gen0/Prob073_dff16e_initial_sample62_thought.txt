To implement the TopModule, we will use 16 D flip-flops. The byte-enable inputs (byteena) will be used to control whether each byte of the 16 registers should be written to on that cycle. We can use the byteena inputs to enable or disable the loading of data into the D flip-flops. We will use the synchronous reset (resetn) to clear all the D flip-flops when resetn is low.
