To implement the TopModule, we need to create a module that contains 16 D flip-flops. We will use the byte-enable inputs to control whether each byte of the registers should be written to on each cycle. We can achieve this by using the byte-enable signals to gate the data for each byte. The resetn signal will be used to reset the flip-flops synchronously. The clock signal clk will be used to trigger the flip-flops on the positive edge.
