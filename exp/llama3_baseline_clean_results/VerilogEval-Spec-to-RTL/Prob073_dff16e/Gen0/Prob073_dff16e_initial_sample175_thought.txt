The TopModule should contain 16 D flip-flops to store the 16-bit data. 
To control the byte-wise write, we can use conditional statements to 
determine whether to update each byte of the flip-flops based on the 
byteena inputs. The reset should be applied synchronously to all flip-flops.
We can achieve this by using Verilog's built-in reg type and always 
blocks to describe the behavior of the D flip-flops.
