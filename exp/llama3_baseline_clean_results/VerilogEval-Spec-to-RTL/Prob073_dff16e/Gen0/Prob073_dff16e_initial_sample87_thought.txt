To implement the TopModule, we need to create a module that contains 16 D flip-flops. Each byte (8 bits) of the 16-bit output q should be controlled by the corresponding byteena input. When byteena[1] or byteena[0] is high, the corresponding byte of q should be updated with the new value from d on the positive edge of clk. If resetn is low, all flip-flops should be reset to 0 on the positive edge of clk, regardless of the byteena inputs. We will use two conditional statements (if-else) inside an always block to achieve this functionality.
