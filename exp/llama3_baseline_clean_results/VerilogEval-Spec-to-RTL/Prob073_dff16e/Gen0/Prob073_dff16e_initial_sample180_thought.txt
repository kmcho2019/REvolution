To implement the TopModule, we can use 16 D flip-flops, which can be divided into two bytes: the upper byte (d[15:8]) and the lower byte (d[7:0]). The byteena input will control whether each byte is written to on a given cycle. We will use a synchronous, active-low reset (resetn) and trigger the DFFs on the positive edge of the clock (clk). The output q will be the current state of the 16 D flip-flops.
