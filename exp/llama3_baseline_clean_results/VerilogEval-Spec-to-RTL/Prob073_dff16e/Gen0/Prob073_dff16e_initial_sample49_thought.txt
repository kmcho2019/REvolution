To implement the TopModule, we'll use 16 D flip-flops, with each flip-flop storing one bit of the 16-bit output q. We'll use the byteena input to control whether each byte of the D flip-flops is updated on a given clock cycle. The resetn input will be used to reset all D flip-flops to 0 on the next positive clock edge when it's low. The d input will be used as the data input to the D flip-flops.
