To implement the TopModule, we will use 16 D flip-flops to store the data. We will use the byte-enable inputs (byteena) to control whether each byte of the 16 registers should be written to on that cycle. The resetn input will be used to reset the D flip-flops synchronously on the negative edge of resetn when it goes high. We will use Verilog's procedural assignment to describe the behavior of the D flip-flops and the conditional statements to handle the byte-enable inputs and the reset signal.
