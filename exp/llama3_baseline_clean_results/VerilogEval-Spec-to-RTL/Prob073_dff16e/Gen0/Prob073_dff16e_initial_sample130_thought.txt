The TopModule will contain 16 D flip-flops, divided into two bytes. The byteena input will determine which byte to write to. When byteena[1] is high, the upper byte (d[15:8]) will be written to the corresponding flip-flops. When byteena[0] is high, the lower byte (d[7:0]) will be written to the corresponding flip-flops. The resetn input will be used to reset all flip-flops when it is low. The clk input will be used as the clock signal, and all flip-flops will be triggered on the positive edge.
