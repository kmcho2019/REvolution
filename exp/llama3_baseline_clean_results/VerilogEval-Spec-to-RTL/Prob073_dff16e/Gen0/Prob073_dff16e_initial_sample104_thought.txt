To implement the TopModule, we will use 16 D flip-flops (DFFs) to store the output q. The input byteena will control whether each byte of the 16 registers should be written to on that cycle. We will use bitwise operations to achieve this functionality. We'll use a case statement to handle the different byteena combinations. The resetn input is synchronous and active-low, meaning the DFFs will reset when resetn is 0, and the clk input will trigger the DFFs on its positive edge.
