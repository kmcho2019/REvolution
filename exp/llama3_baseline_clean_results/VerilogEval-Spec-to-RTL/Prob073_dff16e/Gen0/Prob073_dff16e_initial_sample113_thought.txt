We will split the 16-bit data input d into two 8-bit bytes and assign them to the corresponding DFFs based on the byteena signals. The resetn signal will be used to reset all the DFFs synchronously. 
The module will have a clock input clk and all DFFs will be triggered on its positive edge. 
To implement the byte-enable functionality, we will use the byteena signals to control whether each byte of the 16-bit data is written to the corresponding DFFs.
