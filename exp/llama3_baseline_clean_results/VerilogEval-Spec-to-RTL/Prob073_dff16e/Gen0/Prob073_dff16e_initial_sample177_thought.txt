To implement the TopModule, we'll use 16 D flip-flops to store the input data d. The byte-enable inputs (byteena) will control whether each byte of the 16 registers should be written to on that cycle. We'll use a synchronous reset (resetn) to clear all the flip-flops. We'll use Verilog's always block and non-blocking assignment operator (<=) to implement the D flip-flops and the byte-enable logic.
