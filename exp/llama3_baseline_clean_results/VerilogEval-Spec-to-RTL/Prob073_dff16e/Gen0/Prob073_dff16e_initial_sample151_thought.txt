To implement the TopModule, we need to create a module that contains 16 D flip-flops and is controlled by the provided interface. The D flip-flops should be triggered by the positive edge of the clk signal. The byte-enable inputs (byteena) should control whether each byte of the 16 registers is written to on that cycle. We will use a synchronous, active-low reset (resetn) to reset the D flip-flops. 
We will use a case statement to check the byteena inputs and only update the corresponding bytes of the output q when the enable signals are high. If the resetn signal is low, we will reset all D flip-flops to zero.
