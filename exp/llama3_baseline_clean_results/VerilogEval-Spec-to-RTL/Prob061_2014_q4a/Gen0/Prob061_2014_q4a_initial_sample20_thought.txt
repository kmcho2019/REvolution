The TopModule will be a basic sequential logic block that can either load a new value or shift in a value from the previous stage based on the control inputs. On the positive edge of the clock, if the load signal (L) is asserted, the module will load the value from input R. If the load signal is not asserted but the enable shift signal (E) is asserted, the module will shift in the value from the previous stage (w). The output Q will reflect the current state of the module.
