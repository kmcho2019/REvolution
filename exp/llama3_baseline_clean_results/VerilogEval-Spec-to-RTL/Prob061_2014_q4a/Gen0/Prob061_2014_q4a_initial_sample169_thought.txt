To implement the TopModule, we will use a D flip-flop with an asynchronous load input. The load input (L) will override the shift enable (E) and input (w) to load the value from (R) into the flip-flop. When L is not asserted, the flip-flop will shift in the value from the previous stage (w) if the shift enable (E) is asserted. We will use the posedge of the clock (clk) to trigger the state change of the flip-flop.
