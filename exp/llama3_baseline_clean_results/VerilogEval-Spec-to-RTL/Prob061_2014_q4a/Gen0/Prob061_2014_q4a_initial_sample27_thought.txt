To implement the TopModule, we will use a D flip-flop to store the current state. 
The D flip-flop will have an input for the value from the previous stage (w) and 
a value to load (R) when L is asserted. We will also include an enable (E) to 
determine whether the input from the previous stage (w) or the current state should 
be used. When L is asserted, the D flip-flop should load the value from R. 
Otherwise, when E is asserted, the D flip-flop should shift in the value from the 
previous stage (w). We will use a conditional statement to determine the next state.
