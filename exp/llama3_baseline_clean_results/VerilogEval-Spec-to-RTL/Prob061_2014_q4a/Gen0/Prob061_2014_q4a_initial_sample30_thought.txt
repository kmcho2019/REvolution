The module TopModule will be a one-bit stage of a larger shift register. 
It should have the capability to shift its input from the previous stage 
(w) or load a value (R) when load (L) is asserted, and the shift should 
be enabled by the enable signal (E). The output of this stage will be Q. 
This module can be implemented using a D flip-flop, with some combinational 
logic to handle the shift and load operations.
