The TopModule can be designed as a sequential logic circuit with a D flip-flop. 
When the load signal L is asserted, the module should load the value from input R. 
Otherwise, it should shift the value from the previous stage w into the current stage 
if the enable shift signal E is asserted. 
The module should update its output Q on the positive edge of the clock clk. 
We can achieve this by using an if-else statement inside an always block 
that is triggered on the positive edge of the clock.
