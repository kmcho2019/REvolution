The TopModule should be designed as a sequential logic circuit that can load a value or shift in a value from the previous stage, depending on the control inputs. On the positive edge of the clock, if the load signal L is high, the module should load the value R. If the enable shift signal E is high, the module should shift in the value from the previous stage, w. The output Q should reflect the current state of the module. We can use a D flip-flop with a mux to achieve this functionality.
