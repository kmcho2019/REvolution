The module TopModule will be designed as a sequential logic circuit that operates on the positive edge of the clock. It will have two main modes of operation: shifting and loading. When the load signal L is asserted, the module will load the value from input R. When L is not asserted and the enable signal E is asserted, the module will shift in the value from the previous stage of the shift register through input w. The output Q will reflect the current value stored in the module.
