To design a Read-Only Memory (ROM) module in Verilog, we will first define the module with its input and output ports. We'll use a reg array to model the ROM, where each location can store a 16-bit value. The initial block will be used to preload the ROM with specific data at certain memory locations. The always @(*) block will be utilized to continuously output the data stored at the address specified by the input addr. This way, whenever the address changes, the output will automatically update to reflect the data stored at the new address.
