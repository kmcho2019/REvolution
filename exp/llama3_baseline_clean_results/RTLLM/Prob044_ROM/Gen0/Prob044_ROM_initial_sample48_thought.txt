To design a Read-Only Memory (ROM) module in Verilog, we will define a module named ROM with an 8-bit address input port (addr) and a 16-bit output port (dout). The ROM will have 256 locations, each 16 bits wide, defined by the memory array mem. An initial block will be used to pre-load the ROM with fixed data at specific addresses. The always @(*) block will be used to continuously output the data stored in the ROM at the memory location specified by the addr input. This way, the ROM module will provide a simple way to access predefined data based on the address input.
