To design the ROM module, we will use a parameterizable approach, but in this case, the size is fixed as per the problem statement. We define a reg type memory array `mem` with a size of 256 locations, each 16 bits wide. The `initial` block is used to preload the ROM with fixed data. We then use an `always` block with a sensitivity list to continuously output the data stored in the ROM at the address specified by the input `addr`.
