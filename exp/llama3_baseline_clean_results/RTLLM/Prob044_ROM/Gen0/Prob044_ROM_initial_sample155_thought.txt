To create a Read-Only Memory (ROM) module in Verilog, we need to define the module with an 8-bit address input and a 16-bit output. The ROM will have 256 locations, each 16 bits wide, to store predefined data. We will use an initial block to pre-load specific data into the first four memory locations and an always block to continuously output the data at the specified address. This implementation will provide read-only access to the ROM's contents.
