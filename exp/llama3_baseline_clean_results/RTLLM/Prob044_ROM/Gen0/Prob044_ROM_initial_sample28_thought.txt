To design a Read-Only Memory (ROM) module in Verilog, we'll define a module named ROM with an 8-bit address input port (addr) and a 16-bit output port (dout). The ROM will have 256 locations, each 16 bits wide, defined by the memory array 'mem'. We will use an initial block to preload the ROM with fixed data at specific memory locations. The always @(*) block will be used to continuously output the data stored in the ROM at the address specified by 'addr'. This approach ensures that the ROM module provides read-only access to the predefined data.
