To create the ROM module, we will use a Verilog module declaration with input and output ports as specified. We will define a memory array `mem` to store the data, and use an initial block to pre-load the ROM with fixed data. An always block with sensitivity to all inputs (`@(*)`) will be used to continuously output the data stored in the ROM at the specified address. Since this is a read-only memory, we will only implement a read operation based on the input address.
