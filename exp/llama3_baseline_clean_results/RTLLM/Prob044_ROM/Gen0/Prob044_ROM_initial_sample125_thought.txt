To design a Read-Only Memory (ROM) module in Verilog, we first define the module's name, input, and output ports. We use an 8-bit address input to select the data location in memory and provide a 16-bit output to deliver the data stored in the ROM at the specified address. The ROM is implemented using a memory array, which is pre-loaded with fixed data using an initial block. The always @(*) block continuously outputs the data stored in the ROM at the memory location specified by the address input.
