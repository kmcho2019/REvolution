The LIFObuffer module will utilize a stack memory array (stack_mem) to store 4-bit data entries. A stack pointer (SP) will track the current position within the stack, enabling push and pop operations. The module will process data based on the RW signal, EN signal, and the current state of the buffer (empty or full). On the rising edge of the clock, the module will execute the following logic: 
- If Rst is high, reset the stack by clearing the stack memory and setting the stack pointer to 4, indicating an empty buffer.
- If Rst is low, check the buffer status and perform the corresponding operation:
  - If RW is low (write) and the buffer is not full, push data from dataIn onto the stack and decrement the stack pointer.
  - If RW is high (read) and the buffer is not empty, pop data from the stack into dataOut, clear the corresponding stack memory, and increment the stack pointer.
The EMPTY and FULL flags will be updated based on the stack pointer's value, indicating the buffer's status.
