The LIFObuffer module will utilize a stack memory array (stack_mem) to store the input data. A stack pointer (SP) will be used to track the current position in the stack. The module will perform the following operations based on the RW, EN, and Rst signals: 
- On reset, clear the stack, initialize the stack pointer, and set EMPTY flag high.
- On write operation, push data from dataIn onto the stack, decrement the stack pointer, and update the EMPTY and FULL flags.
- On read operation, pop data from the stack into dataOut, increment the stack pointer, and update the EMPTY and FULL flags.
The flags for EMPTY and FULL will be updated based on the stack pointer status, and the output data will be retrieved from the stack memory based on the stack pointer.
