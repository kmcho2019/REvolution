To implement the parallel-to-serial conversion module, we will utilize a finite state machine (FSM) with two main states: idle and shifting. In the idle state, the module waits for the next parallel input data. When valid data is available, the module shifts the data one bit at a time to the output while setting the valid_out signal accordingly. The counter (cnt) will be used to track the current bit being output. We will use a 4-bit register (data) to store the parallel input and shift its bits to the output.
