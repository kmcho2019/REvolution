The parallel2serial module will be designed as a finite state machine (FSM) with two main states: idle and serial_out. In the idle state, the module waits for the valid input data. Once the valid input data is available, it moves to the serial_out state, where it shifts out the data bits one by one from MSB to LSB. The module uses a counter (cnt) to keep track of the current bit being shifted out. The valid_out signal is set to 1 when the first bit of the parallel input is available at the serial output.
