To implement the parallel-to-serial conversion module, we need to consider the following steps:
1. Create a counter (cnt) to track the bit position of the parallel input data being converted to serial output.
2. Use a data register (data) to store the parallel input data and shift it left on each clock cycle to output the next bit.
3. Implement the logic to update the data register with the new parallel input when the counter reaches 3, indicating the last bit of the previous input has been output.
4. Set the valid_out signal to 1 when the data register is updated with new input, and set it to 0 otherwise.
5. Use the reset signal (rst_n) to reset the counter, data register, and valid signal when the module is reset.

The design involves using a finite state machine (FSM) or a simple counter-based approach. In this case, a counter-based approach is sufficient to implement the parallel-to-serial conversion logic. We will use the counter to keep track of the bit position and update the data register accordingly.
