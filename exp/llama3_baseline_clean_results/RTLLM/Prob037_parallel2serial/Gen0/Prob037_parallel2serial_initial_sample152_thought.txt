To implement the parallel-to-serial conversion module, we will use a finite state machine (FSM) approach with a counter to keep track of the number of bits that have been output. The FSM will have two main states: idle and output. In the idle state, the module waits for new parallel input data. In the output state, the module outputs the serial data bit by bit. We will use a counter (cnt) to keep track of the number of bits that have been output. When the counter reaches 3, we update the data register with the new parallel input data and reset the counter. On each clock cycle, if the counter is not equal to 3, we increment the counter, shift the data register one bit to the right, and set the valid signal to 1 if the counter is greater than 0. The serial output (dout) will be assigned the most significant bit of the data register. We will also use a reset signal (rst_n) to reset the module when it is low.
