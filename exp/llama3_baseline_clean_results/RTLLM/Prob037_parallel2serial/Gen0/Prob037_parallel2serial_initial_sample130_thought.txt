The module parallel2serial will be designed as a finite state machine (FSM) with a counter to keep track of the current bit being transmitted. The module will have two main states: idle and transmitting. In the idle state, the module waits for the parallel input data to be ready and the counter to reach 3, at which point it updates the data register with the new parallel input and resets the counter. In the transmitting state, the module shifts the data register one bit to the left and increments the counter until all 4 bits have been transmitted. The valid_out signal is set to 1 when the module is in the transmitting state, indicating that the serial output is valid. The dout output is assigned the most significant bit of the data register.
