To implement the parallel-to-serial conversion module, we need to follow these steps:
1. Define the module name and input/output ports as specified in the problem.
2. Initialize a counter register (cnt) to track the number of bits that have been output.
3. Initialize a data register (data) to store the parallel input (d).
4. Create a valid signal (valid) to indicate the availability of valid serial output.
5. At each clock cycle, check the counter value. If it's 3 (indicating the last bit), update the data register with the new parallel input, reset the counter to 0, and set the valid signal to 1.
6. Otherwise, increment the counter, set the valid signal to 0, and shift the data register one bit to the right (with the MSB shifted to the LSB is incorrect, instead, we should keep the MSB intact and shift the rest 3 bits one position to the right).
7. Use the least significant bit of the data register as the serial output (dout).
8. Assign the valid signal to the output port valid_out.
We also need to consider the reset signal (rst_n) to reset the counter and data registers when it's low.
