To implement a 64-bit Johnson counter, we need to design a module that updates its state based on the current value of the counter and the input signals. The counter should have a 64-bit output port Q, and two input ports: clk for the clock signal and rst_n for the active-low reset signal. On every rising edge of the clock signal or the falling edge of the reset signal, the counter value should be updated according to the specified rules. If the reset signal is low, the counter value should be reset to 0. Otherwise, the counter should increment or decrement based on the value of the least significant bit of the current count.
