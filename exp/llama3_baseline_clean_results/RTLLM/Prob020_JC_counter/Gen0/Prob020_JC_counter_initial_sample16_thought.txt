It involves shifting the current value of the counter to the right and either appending a 1 or a 0 at the most significant bit position, depending on the value of the least significant bit (LSB). If the LSB is 0, we append a 1; if the LSB is 1, we append a 0. The counter should also handle the reset condition, where the counter value is set to 0 when the reset signal is low.
