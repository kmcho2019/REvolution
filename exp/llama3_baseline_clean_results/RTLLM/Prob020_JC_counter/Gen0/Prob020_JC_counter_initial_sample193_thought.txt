The Johnson counter (torsional ring counter) can be implemented using a 64-bit register and a simple state machine. We start with an initial value of all zeros. On every clock edge, we check the least significant bit (Q[0]) and update the counter value accordingly. If Q[0] is 0, we append a 1 at the most significant bit position (Q[63]) and shift the rest of the bits to the right. If Q[0] is 1, we append a 0 at the most significant bit position and shift the rest of the bits to the right. We use the active-low reset signal to initialize the counter to 0 when it is low.
