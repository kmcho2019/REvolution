We will then use an if-else statement within a clocked block to check the least significant bit (Q[0]) and update the counter value accordingly. If Q[0] is 0, we shift the current value (Q[63:1]) to the right and append a 1 at the most significant bit position. If Q[0] is 1, we shift the current value (Q[63:1]) to the right and append a 0 at the most significant bit position.
