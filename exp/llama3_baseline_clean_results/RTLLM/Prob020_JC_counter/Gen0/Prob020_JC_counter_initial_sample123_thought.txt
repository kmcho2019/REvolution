The Johnson counter, also known as a torsional ring counter, can be implemented in Verilog by utilizing the shift operator to update the counter value on every rising edge of the clock signal or the falling edge of the reset signal. 
We start by declaring the module and input/output ports according to the problem description.
Inside the module, we use a reg variable to hold the current count value.
The always block is used to describe the sequential behavior of the counter, where the counter value is updated based on the least significant bit and the state of the reset signal.
If the reset signal is low, the counter value is reset to 0. Otherwise, if the least significant bit is 0, the counter increments; if the least significant bit is 1, the counter decrements.
The counter value is updated using the shift operator to shift the current value to the right and append a new bit at the most significant bit position.
The output port Q is assigned the current count value.
