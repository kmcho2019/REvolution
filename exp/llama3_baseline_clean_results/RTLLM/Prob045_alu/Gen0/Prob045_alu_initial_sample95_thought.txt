The ALU (Arithmetic Logic Unit) is the core component of a CPU that performs arithmetic and logical operations. In this design, we will create an ALU that supports various operations defined by the MIPS-ISA (Instruction Set Architecture). The ALU takes two operands "a" and "b" and an opcode "aluc" as inputs and produces a result "r", along with several status flags: "zero", "carry", "negative", "overflow", and "flag". We will use Verilog to implement the ALU, utilizing parameters to define the control signals for various operations and an always block with a case statement to perform the operations based on the opcode.
