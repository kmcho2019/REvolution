To implement an ALU for a 32-bit MIPS-ISA CPU, we can use a parameterized module to define the control signals for various operations. We will use a case statement inside an always block to perform the appropriate operation based on the control signal. For each operation, we will assign the result to the output register and update the flag outputs accordingly. We will also handle shift operations and the LUI operation separately.

The design should handle the following operations:
- Arithmetic operations: ADD, ADDU, SUB, SUBU
- Logical operations: AND, OR, XOR, NOR
- Shift operations: SLL, SRL, SRA, SLLV, SRLV, SRAV
- Comparison operations: SLT, SLTU
- Load Upper Immediate operation: LUI

For each operation, we will check for zero, carry, negative, and overflow conditions and update the corresponding flag outputs.
