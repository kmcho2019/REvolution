The comparator_4bit module will be designed using combinational logic, where the inputs A and B are 4-bit binary numbers to be compared. 
The comparison will be performed by subtracting B from A. 
If the result of the subtraction is negative (i.e., a borrow occurs), then A is less than B, and A_less will be set to 1. 
If the result of the subtraction is non-zero and positive (i.e., no borrow occurs), then A is greater than B, and A_greater will be set to 1. 
If the result of the subtraction is zero, then A is equal to B, and A_equal will be set to 1.
To implement this logic, we will use full subtractors and compare the result to determine the outputs.
