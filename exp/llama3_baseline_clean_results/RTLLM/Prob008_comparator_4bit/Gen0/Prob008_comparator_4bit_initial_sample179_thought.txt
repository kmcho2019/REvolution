The comparator_4bit module will be designed using combinational logic, implementing a subtraction operation between the two input operands A and B. This subtraction operation will be performed bit by bit, generating carries (borrows) as necessary. The result of this subtraction will help determine the relationship between A and B. 
- If a borrow occurs during the subtraction, it indicates that A is less than B.
- If no borrow occurs and the result of subtraction is non-zero, it indicates that A is greater than B.
- If the result of subtraction is zero, it indicates that A is equal to B.
To implement this logic, we can utilize full subtractor circuits for each bit, accounting for the borrow from the previous bit. 
The outputs A_greater, A_equal, and A_less will be generated based on the result of the subtraction operation and the occurrence of borrows.
