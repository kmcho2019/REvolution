To implement a 4-bit comparator using combinational logic, we'll first perform a subtraction operation A - B. We will then analyze the result and any borrow generated during the subtraction to determine if A is greater than, equal to, or less than B. 
- If a borrow occurs during the subtraction, it indicates that A is less than B.
- If no borrow occurs and the result of subtraction is non-zero, it means A is greater than B.
- If the result of subtraction is zero, then A is equal to B.
We will use these conditions to generate the output signals A_greater, A_equal, and A_less. The outputs will be mutually exclusive, ensuring only one of them is high at any given time.
