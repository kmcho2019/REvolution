The series-parallel conversion circuit can be designed using a synchronous approach. We will utilize a 4-bit counter to keep track of the number of serial input data bits received. The input din_serial is a single-bit data and when the module receives 8 input data, the output dout_parallel outputs the 8-bit data. The output dout_parallel will be generated by shifting the din_serial into the most significant bit position, and then shifting the existing bits to the right. The dout_valid signal is set to 1 when all 8 serial data bits have been received. We will use a reset signal (rst_n) to reset the counter and the output when the circuit is reset.
