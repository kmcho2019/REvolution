The serial2parallel module will be designed using a synchronous approach, operating on the rising edge of the clock signal "clk". It will utilize a 4-bit counter (cnt) to track the number of serial input data bits received. A 8-bit shift register will be used to store the serial input data. When the counter reaches 8 (i.e., all 8 serial data bits have been received), the parallel output data will be set to the contents of the shift register, and the valid output signal will be set to 1. The module will also include a reset signal "rst_n" to reset the counter, shift register, and output signals.
