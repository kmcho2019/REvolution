The serial2parallel module will utilize a 4-bit counter to track the number of serial input data bits received. On every eighth input, the module will output the 8-bit parallel data and set the dout_valid signal to 1. This will be achieved using a synchronous design, operating on the rising edge of the clock signal. 
We will also use a register to store the incoming serial data bits and shift them as new data arrives, effectively converting the serial input to parallel output.
The module will be reset when the rst_n signal is low, which will clear the counter and the output register.
