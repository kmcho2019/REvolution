To implement the series-parallel conversion circuit, we will use a synchronous design with a 4-bit counter to keep track of the number of serial input data bits received. On every rising edge of the clock signal, we will check the validity of the input data and shift the serial input data into a register. Once we have received 8 serial input data bits, we will set the output dout_parallel and the validity signal dout_valid. We will reset the counter and the output data whenever the reset signal rst_n is low. The serial input data will be placed in the dout_parallel from the most significant bit to the least significant bit.
