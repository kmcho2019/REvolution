The serial2parallel module will be designed as a synchronous circuit, using the rising edge of the clock signal "clk" to trigger the operations. A 3-bit counter (cnt) will be used to keep track of the number of serial input data bits received. Every eight din_serial input, dout_parallel will output. The counter will be reset when the reset signal "rst_n" is low. The output dout_parallel will be updated on the rising edge of the clock, and the dout_valid signal will be set to 1 when all 8 bits have been received and the din_valid signal is high. The shift register will be used to store the serial input data.
