The series-parallel conversion circuit can be designed using a finite state machine (FSM) approach. We can utilize a 3-bit counter to keep track of the number of serial input data bits received. At every rising edge of the clock, we check if the input data is valid. If it is, we shift the current parallel output left by one bit and add the new serial input data to the least significant bit. Once we have received 8 input data bits, we set the valid output signal to 1 and output the parallel data. If the reset signal is asserted, we reset the counter, parallel output, and valid output signal.
