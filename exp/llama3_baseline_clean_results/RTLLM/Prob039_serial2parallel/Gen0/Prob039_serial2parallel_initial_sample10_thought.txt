The module serial2parallel will be designed using a synchronous approach, operating on the rising edge of the clock signal "clk". It utilizes a 4-bit counter (cnt) to track the number of serial input data bits received. The serial input signal "din_serial" is shifted into the 8-bit parallel output "dout_parallel" from the most significant bit to the least significant bit. When all 8 serial data bits have been received, the valid output signal "dout_valid" is set to 1, indicating that the parallel output data is valid. Otherwise, "dout_valid" is set to 0, indicating that the parallel output data is not valid. The module will be reset when the reset signal "rst_n" is low.
