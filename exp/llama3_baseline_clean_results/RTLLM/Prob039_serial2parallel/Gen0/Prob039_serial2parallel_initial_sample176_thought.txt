The serial2parallel module will be designed as a synchronous circuit that operates on the rising edge of the clock signal. A 4-bit counter will be used to keep track of the number of serial input data bits received. The module will use a 8-bit shift register to store the serial input data bits. When all 8 serial data bits have been received, the parallel output data will be assigned to the dout_parallel port, and the dout_valid signal will be set to 1. Otherwise, the dout_valid signal will be set to 0. The module will also have a reset input (rst_n) to reset the circuit to its initial state when rst_n is 0.
