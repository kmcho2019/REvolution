The serial2parallel module will be designed as a synchronous digital circuit, utilizing a 4-bit counter to track the number of serial input bits received. When eight bits have been received, the parallel output will be generated, and the dout_valid signal will be set to 1. On the rising edge of the clock signal, the module will either shift in a new bit or reset the counter and output if it has reached the maximum count. The din_valid signal will be used to control when the input data is valid and should be processed.
