When 8 serial data bits have been received, the parallel output data will be output, and the valid output signal will be set to 1. Otherwise, the valid output signal will be set to 0.

2. Initialize an 8-bit register (dout_parallel) to store the parallel output data.
3. On the rising edge of the clock signal, check if the reset signal is low. If it is, reset the counter and the output data.
