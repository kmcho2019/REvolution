To implement the multi-bit MUX-based synchronizer, we need to design the following components:
1. Data Register: Store the input data signal, data_in.
2. Enable Data Register: Store the input enable signal, data_en.
3. Enable Control Registers: Control the selection of the input data using two registers, en_clap_one and en_clap_two.
4. Output Assignment: Assign the output data value based on the control signal (en_clap_two) and the data register (data_reg).

The data register and enable data register are updated on the positive edge of clock signal A (clk_a) or the falling edge of reset signal A (arstn).
The enable control registers and output assignment are updated on the positive edge of clock signal B (clk_b) or the falling edge of reset signal B (brstn).

We will use two always blocks to update the registers and assign the output value.
