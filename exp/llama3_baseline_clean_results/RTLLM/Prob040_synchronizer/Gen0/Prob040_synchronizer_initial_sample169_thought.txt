To solve this problem, we need to design a multi-bit MUX-based synchronizer with a data register, enable data register, and two enable control registers. The data register and enable data register will be updated based on clock signal A (clk_a) and reset signal A (arstn). The enable control registers will be updated based on clock signal B (clk_b) and reset signal B (brstn). The output data value will be assigned based on the value of the enable control registers and the data register. This implementation will ensure that the input data signal (data_in) is synchronized with clock signal B (clk_b) while considering the enable signal (data_en) and reset signals (arstn and brstn).
