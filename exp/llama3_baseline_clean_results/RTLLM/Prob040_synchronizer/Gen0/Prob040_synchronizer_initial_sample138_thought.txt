The synchronizer module should have two separate clock domains, one for input data and enable signal (clk_a) and one for output data and control (clk_b). The enable signal (data_en) delayed by two cycles of clk_b using two D flip-flops (en_clap_one and en_clap_two). The output data (dataout) is updated when en_clap_two is high.
