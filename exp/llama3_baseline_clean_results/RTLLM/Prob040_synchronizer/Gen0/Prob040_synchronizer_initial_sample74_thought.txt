The multi-bit MUX-based synchronizer can be implemented using a combination of data registers, enable data registers, and enable control registers. The data register (data_reg) stores the input data signal (data_in) and is updated on the positive edge of clock signal A (clk_a) or the falling edge of reset signal A (arstn). The enable data register (en_data_reg) stores the input enable signal (data_en) and is updated on the positive edge of clock signal A (clk_a) or the falling edge of reset signal A (arstn). The enable control registers (en_clap_one and en_clap_two) control the selection of the input data and are updated on the positive edge of clock signal B (clk_b) or the falling edge of reset signal B (brstn). The output data (dataout) is assigned the value of the data register (data_reg) when the control signal (en_clap_two) is active, otherwise it retains its previous value.
