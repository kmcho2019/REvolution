To design a 16-bit full adder, we will first create an 8-bit full adder module. This 8-bit full adder will be instantiated twice in the 16-bit full adder module to add the higher and lower 8 bits of the 16-bit input operands separately. The carry-out from the lower 8-bit adder will be used as the carry-in for the higher 8-bit adder. 
The 8-bit full adder itself can be designed using basic combinational logic components such as half adders or full adders. For simplicity and modularity, we can use the built-in addition operator in Verilog for the 8-bit adder, but for educational purposes, we will define a basic 1-bit full adder and use it to build the 8-bit adder.
