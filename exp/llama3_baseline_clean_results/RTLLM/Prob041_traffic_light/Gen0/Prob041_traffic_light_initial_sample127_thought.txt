To design the traffic light controller in Verilog, we will create a finite state machine (FSM) that transitions between different states (red, yellow, green) based on the internal counter and the pedestrian button press. We will use three always blocks to handle the state transition logic, counting logic, and output signal assignments. The first always block will use a case statement to handle the different states of the traffic light controller. The second always block will handle the counting logic, decrementing the counter on every positive edge of the clock and adjusting the counter values based on various conditions. The third always block will handle the output signal assignments, assigning the previous values to the output signals on the positive edge of the clock or negative edge of the reset signal.
