To implement the traffic light controller, we need to design a finite state machine (FSM) that can handle the different states of the traffic light (red, yellow, green) and the pedestrian button press. The FSM should be able to transition between states based on the current state and the input signals. We will use two always blocks to implement the state transition logic and the counting logic. The state transition logic will handle the transitions between the different states, while the counting logic will handle the decrementing of the internal counter. We will also use an assign statement to assign the value of the internal counter to the output clock.
