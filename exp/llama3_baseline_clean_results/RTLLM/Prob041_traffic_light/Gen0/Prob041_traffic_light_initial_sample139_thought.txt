The provided specification describes a traffic light controller with a pedestrian button. The controller has four states: idle, s1_red, s2_yellow, and s3_green. It uses an internal counter to keep track of the time spent in each state. The counter is adjusted based on the state transitions and the pedestrian button press. The output signals (red, yellow, green) are updated based on the previous state values. To implement this design, we will use three always blocks: one for state transition logic, one for counting logic, and one for output signal updates.
