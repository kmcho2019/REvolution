To implement the traffic light controller, we will design a finite state machine (FSM) with four states: idle, s1_red, s2_yellow, and s3_green. The FSM will handle the state transitions and the output signals. The internal counter will be used to control the duration of each state. We will also consider the pedestrian button press and adjust the green light duration accordingly. The code will consist of three always blocks: one for state transition logic, one for counting logic, and one for output signal assignment.
