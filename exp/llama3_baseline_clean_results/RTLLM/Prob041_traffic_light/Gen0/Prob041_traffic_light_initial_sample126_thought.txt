The traffic light controller can be designed using three always blocks in Verilog. The first always block handles the state transition logic, the second always block handles the counting logic of the internal counter, and the third always block handles the output signals. The state transition logic uses a case statement to handle different states, and the counting logic adjusts the counter values based on various conditions. The output signals are assigned the previous values on the positive edge of the clock or negative edge of the reset signal.
