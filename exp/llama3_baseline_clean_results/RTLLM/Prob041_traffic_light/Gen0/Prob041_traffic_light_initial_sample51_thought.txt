To implement the traffic light controller, we need to design a finite state machine (FSM) that handles the state transitions based on the input signals and the internal counter. We will use an 8-bit counter to keep track of the time spent in each state. The pass_request signal will be used to adjust the counter value when the pedestrian button is pressed. The output signals (red, yellow, green) will be assigned based on the current state of the FSM. We will also use a separate always block to handle the counting logic and another always block to handle the output signals.
