To design the traffic light controller, we need to consider the different states it can be in and how it transitions between those states. The states are: idle, red, yellow, and green. The transitions between states depend on the current state, the internal counter value, and the pass_request signal. We will use a finite state machine (FSM) to implement the state transition logic. The internal counter will be used to keep track of the time spent in each state. We will also need to handle the output signals (red, yellow, green) and the clock output.
