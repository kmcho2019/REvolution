The traffic light controller can be designed using a finite state machine with three states: idle, red, yellow, and green. The controller uses a counter to time the duration of each state. When the pedestrian button is pressed, the green light duration is shortened to 10 clocks if the remaining time is greater than 10 clocks. The lane light and sidewalk light are paired, with the sidewalk light being green when the lane light is red and red when the lane light is green or yellow. 
We'll implement this using three always blocks: one for state transition logic, one for counting logic, and one for output signal assignment. 
The state transition logic will handle the different states of the traffic light controller, the counting logic will handle the internal counter, and the output signal assignment will handle the output signals based on the current state.
