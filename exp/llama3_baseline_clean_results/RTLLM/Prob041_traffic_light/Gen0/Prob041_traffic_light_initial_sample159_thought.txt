The code should follow a Finite State Machine (FSM) approach with specific states for each traffic light phase. The states are: idle, s1_red, s2_yellow, and s3_green. We will also incorporate a counter to handle the timing for each state. When the pedestrian button is pressed, we need to adjust the counter value based on the current state and the remaining green time. The output signals (red, yellow, green) should be updated based on the current state and the counter value.
