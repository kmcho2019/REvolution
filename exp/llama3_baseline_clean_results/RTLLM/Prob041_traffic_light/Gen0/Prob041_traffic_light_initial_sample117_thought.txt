To implement the traffic light controller, we will use a finite state machine (FSM) to manage the different states of the traffic light. The states will be idle, red, yellow, and green. We will also use a counter to keep track of the time spent in each state. The counter will be decremented on every clock cycle, and when it reaches 0, the state will change. The pedestrian button press will be handled by adjusting the counter value when the green light is active.

The design will consist of three always blocks: one for the state transition logic, one for the counting logic, and one for the output signals. The state transition logic will use a case statement to handle the different states. The counting logic will decrement the counter on every clock cycle and adjust the counter value based on the current state and the pedestrian button press. The output signals will be assigned the previous values on the positive edge of the clock or negative edge of the reset signal.

The code will be written in Verilog, and it will include the necessary registers, wires, and parameters. The module name will be traffic_light, and it will have the specified inputs and outputs.
