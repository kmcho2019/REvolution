To implement the traffic light controller, we will create a finite state machine (FSM) with four states: idle, s1_red, s2_yellow, and s3_green. The state transitions will be controlled by a counter that is decremented on every clock cycle. When the pedestrian button is pressed, the counter will be adjusted to ensure the green light duration is shortened to 10 clock cycles if necessary. The output signals (red, yellow, green) will be assigned based on the current state of the FSM. We will use two always blocks to handle the state transition logic and the counting logic, and a third always block to handle the output signals. The assign statement will be used to output the value of the internal counter.
