To implement the traffic light controller, we'll use a finite state machine (FSM) with four states: idle, s1_red, s2_yellow, and s3_green. We'll also use an internal counter to manage the timing of each state. When the pedestrian button is pressed, we'll adjust the counter value based on the current state and the remaining time in the green state. The output signals (red, yellow, green) will be assigned based on the current state and the previous values of the signals.
