To implement the traffic light controller, we need to design a finite state machine (FSM) that transitions between different states (idle, s1_red, s2_yellow, s3_green) based on the current state and the internal counter value. The internal counter is used to control the duration of each state. We also need to handle the pedestrian button press by adjusting the counter value accordingly. The output signals (red, yellow, green) are determined by the current state and the previous state values. The clock output is assigned the value of the internal counter.
