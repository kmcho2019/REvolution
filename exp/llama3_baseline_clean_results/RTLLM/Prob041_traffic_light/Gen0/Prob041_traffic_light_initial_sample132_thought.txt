To implement the traffic light controller, we will use a finite state machine (FSM) with four states: idle, s1_red, s2_yellow, and s3_green. The FSM will transition between these states based on the current state and the count value of the internal counter. We will use two always blocks to handle the state transition logic and the counting logic of the internal counter, and a final always block to handle the output signals. The assign statement will be used to assign the value of the internal counter to the output clock.
