To implement the traffic light controller, we will follow the recommended design track. We will first define the states of the traffic light controller as an enumeration. Then, we will create an always block to handle the state transition logic, another always block for the counting logic, and finally, an always block to handle the output signals. We will use a case statement to handle the different states and conditions in the always blocks. Additionally, we will use assign statements to connect the internal counter to the output clock and the previous signal values to the output signals.
