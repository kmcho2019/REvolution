To implement the traffic light controller, we can use a finite state machine (FSM) approach. The FSM will have four states: idle, s1_red, s2_yellow, and s3_green. The idle state is the initial state where all signals are set to 0, and it transitions to the s1_red state immediately. The s1_red state sets the red signal to 1 and waits for a count of 10 before transitioning to the s3_green state. The s2_yellow state sets the yellow signal to 1 and waits for a count of 5 before transitioning to the s1_red state. The s3_green state sets the green signal to 1 and waits for a count of 60 before transitioning to the s2_yellow state. However, if the pedestrian button is pressed and the remaining green time is greater than 10 clocks, it is shortened to 10 clocks. We can use an 8-bit register (cnt) as an internal counter for timing purposes. The state transition logic will be handled in the first always block, the counting logic will be handled in the second always block, and the output signals will be handled in the final always block.
