The design involves creating a finite state machine (FSM) to manage the traffic light states and a counter to control the duration of each state. We will use three always blocks: one for state transition logic, one for counting logic, and one for output signal updates. The state transition logic block will handle the transition between different states based on the current state and the count value. The counting logic block will manage the internal counter and adjust its value according to the current state and input signals. The output signal update block will assign the previous state values to the output signals.
