The traffic light controller should have multiple states to control the sequence of the traffic lights. The states are idle, red, yellow, and green. Each state should have a specific counter value. The counter value should be decremented on every clock cycle. When the counter reaches zero, the state should change to the next state. The pass_request signal should be used to adjust the counter value when the green light is on. The counter value should be assigned to the output clock. The output signals (red, yellow, green) should be assigned based on the current state.
