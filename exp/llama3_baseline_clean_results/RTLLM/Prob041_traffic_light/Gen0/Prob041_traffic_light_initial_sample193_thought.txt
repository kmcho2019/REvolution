The traffic light controller can be implemented using a finite state machine (FSM) with four states: idle, s1_red, s2_yellow, and s3_green. The state transition logic will be handled in the first always block, while the counting logic will be handled in the second always block. The output signals will be updated in the third always block.

To implement the pedestrian button functionality, we need to adjust the counter value when the pass_request signal is active and the green signal is active. If the remaining green time is greater than 10 clocks, we set the counter to 10. Otherwise, we leave the counter unchanged.

We will also use assign statements to assign the value of the internal counter (cnt) to the output clock and to assign the previous values (p_red, p_yellow, p_green) to the output signals (red, yellow, green).
