To implement the traffic light controller in Verilog, we'll create a finite state machine (FSM) that transitions between four states: idle, s1_red, s2_yellow, and s3_green. The FSM will be controlled by a counter that decrements every clock cycle. Based on the current state and the counter value, the FSM will transition to the next state and set the corresponding output signals (red, yellow, green). The pass_request signal will be used to adjust the counter value when the pedestrian button is pressed.
