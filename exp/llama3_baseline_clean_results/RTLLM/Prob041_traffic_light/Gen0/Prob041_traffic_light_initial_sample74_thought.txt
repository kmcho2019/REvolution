To implement the traffic light controller, we will use a finite state machine with four states: idle, s1_red, s2_yellow, and s3_green. The state transitions will be based on the current state and the count value of the internal counter. The counter will be decremented on every clock cycle, and its value will be adjusted based on the current state and the pass_request signal. The output signals will be assigned based on the current state. We will use three always blocks to implement the state transition logic, the counting logic, and the output signal assignment.
