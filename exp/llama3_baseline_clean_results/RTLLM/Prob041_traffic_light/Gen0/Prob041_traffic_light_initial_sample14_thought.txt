To implement the traffic light controller, we can use a Finite State Machine (FSM) to handle the different states of the traffic lights and a counter to manage the timing. The state transition logic and counting logic can be implemented in separate always blocks. The state transition logic will handle the different states (idle, s1_red, s2_yellow, s3_green) based on the current state and the count value of the internal counter. The counting logic will manage the internal counter (cnt) based on the current state and the pass_request signal.
