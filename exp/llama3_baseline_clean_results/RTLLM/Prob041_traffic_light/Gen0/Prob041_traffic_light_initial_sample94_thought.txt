To solve this problem, we will create a finite state machine (FSM) that controls the traffic light. The FSM will have four states: idle, s1_red, s2_yellow, and s3_green. Each state will have a specific duration and will transition to the next state after a certain number of clock cycles. The pedestrian button press will be handled by adjusting the counter value when the green signal is active. The output signals (red, yellow, green) will be assigned based on the current state of the FSM. We will use two always blocks to handle the state transition logic and the counting logic, and an assign statement to assign the value of the internal counter to the output clock. The final always block will handle the output signals.
