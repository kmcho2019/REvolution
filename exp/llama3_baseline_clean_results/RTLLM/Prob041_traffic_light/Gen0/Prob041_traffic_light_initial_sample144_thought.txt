To implement the traffic light controller, we will use a finite state machine (FSM) with four states: idle, s1_red, s2_yellow, and s3_green. The controller will transition between these states based on the current state and the count value of the internal counter. The counter will be used to time the duration of each state. When the pedestrian button is pressed, the controller will adjust the green time accordingly. We will use a case statement to handle the different states and conditional statements to handle the counting logic and output signals.
