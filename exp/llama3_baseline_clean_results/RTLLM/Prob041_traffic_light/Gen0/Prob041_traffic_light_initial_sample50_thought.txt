To implement the traffic light controller in Verilog, we will create a finite state machine that handles the different states of the traffic light (red, yellow, and green) and updates the internal counter accordingly. We will use three always blocks: one for the state transition logic, one for the counting logic, and one for the output signals. The state transition logic will be based on a case statement that checks the current state and updates it accordingly. The counting logic will handle the internal counter (cnt) and update it based on various conditions. The output signals will be assigned the previous values (p_red, p_yellow, p_green) on the positive edge of the clock or negative edge of the reset signal.
