To implement the traffic light controller, we can use a finite state machine (FSM) with four states: idle, s1_red, s2_yellow, and s3_green. The FSM transitions between these states based on the current state and the count value. The internal counter (cnt) is used to keep track of the time spent in each state. The pass_request signal is used to shorten the green light time to 10 clocks if it is pressed when the green light is active. The output signals (red, yellow, green) are assigned based on the current state of the FSM.
