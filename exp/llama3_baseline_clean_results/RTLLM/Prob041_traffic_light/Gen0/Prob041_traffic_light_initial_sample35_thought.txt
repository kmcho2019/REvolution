The design should be implemented using finite state machine (FSM) principles, with separate blocks handling state transitions, counting logic, and output signal assignments. The state transition logic should be responsible for transitioning between different states (idle, s1_red, s2_yellow, s3_green) based on the current state and counter values. The counting logic should handle the internal counter (cnt) and adjust its values based on various conditions such as pass_request signal, green signal, yellow signal, and red signal. The output signal assignments should update the output signals (red, yellow, green) based on the previous values (p_red, p_yellow, p_green) on the positive edge of the clock or negative edge of the reset signal.
