To implement the traffic light controller, we need to define the state transition logic, counting logic, and output signal handling. 
We will use an enumeration to represent different states of the traffic light controller. 
The state transition logic will be handled by a case statement in the first always block, where each state will set the corresponding signal and wait for a specific count before transitioning to the next state.
The counting logic will be handled by the second always block, where the internal counter will be decremented or set based on various conditions.
The output signals will be handled by the final always block, where the previous values will be assigned to the output signals on the positive edge of the clock or negative edge of the reset signal.
