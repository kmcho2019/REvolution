To implement the dual-port RAM, we will use two separate always blocks: one for handling the write operation and the other for handling the read operation. 
The write operation will be performed on the positive edge of the clock signal or when the reset signal is inactive. 
The read operation will be performed on the positive edge of the clock signal or when the reset signal is inactive.
We will use a register array to store the data, with the array size defined by the parameters WIDTH and DEPTH.
