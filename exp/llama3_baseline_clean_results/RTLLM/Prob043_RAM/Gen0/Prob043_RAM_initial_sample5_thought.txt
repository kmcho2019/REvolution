The dual-port RAM can be implemented using two always blocks: one for handling the write operation and the other for handling the read operation. The write operation should be triggered by the positive edge of the clock signal and the write enable signal. The read operation should also be triggered by the positive edge of the clock signal and the read enable signal. 
We use a reg array to represent the RAM. On reset, we initialize all memory locations to 0. When the write enable signal is active, we write the data to the RAM at the specified address. 
When the read enable signal is active, we read the data from the RAM at the specified address and output it. 
If the read enable signal is not active, the read_data register should be cleared to 0 to avoid any unwanted data output.
