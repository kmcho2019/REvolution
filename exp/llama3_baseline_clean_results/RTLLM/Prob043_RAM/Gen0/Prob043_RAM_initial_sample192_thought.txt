The RAM module will be designed with two always blocks, one for handling the write operation and the other for handling the read operation. 
The write operation will be performed when the write_en signal is active, and the data will be written to the RAM array at the specified address. 
The read operation will be performed when the read_en signal is active, and the data at the specified address in the RAM array will be assigned to the read_data register.
We will define the parameters WIDTH and DEPTH for better flexibility and maintainability of the code.
The RAM array will be defined as a reg type, allowing for synchronous read and write operations.
