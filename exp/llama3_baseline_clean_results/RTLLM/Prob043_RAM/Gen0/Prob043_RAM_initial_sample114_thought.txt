To implement a dual-port RAM in Verilog, we can utilize two always blocks. The first always block will handle the write operation and reset. It will trigger on the positive edge of the clock signal or the negative edge of the reset signal. The second always block will handle the read operation and reset. It will also trigger on the positive edge of the clock signal or the negative edge of the reset signal. 
We define a parameterized module 'RAM' that takes in the required ports and uses the parameters WIDTH and DEPTH to define the RAM array.
The RAM array is a 2D array of registers, with the number of elements determined by the DEPTH parameter and the width of each element determined by the WIDTH parameter.
The write operation checks the write enable signal and writes the data to the specified address in the RAM array.
The read operation checks the read enable signal and assigns the data at the specified address in the RAM array to the read_data register.
