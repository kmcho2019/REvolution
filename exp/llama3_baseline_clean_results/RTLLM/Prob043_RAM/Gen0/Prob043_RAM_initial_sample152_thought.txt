To implement a dual-port RAM with the specified requirements, we will define a Verilog module named RAM. This module will include two main components: an internal register array to store the data and two always blocks to handle the write and read operations. The first always block will handle the reset operation and the write operation based on the write enable signal. The second always block will handle the read operation based on the read enable signal. The RAM array will be initialized with all data set to 000000.
