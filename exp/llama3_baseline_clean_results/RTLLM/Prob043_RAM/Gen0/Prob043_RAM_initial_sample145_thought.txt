To implement the dual-port RAM, we will use two always blocks to handle the write and read operations separately. The first always block will handle the write operation and the reset condition. It will trigger on the positive edge of the clock signal or the negative edge of the reset signal. The second always block will handle the read operation. It will also trigger on the positive edge of the clock signal or the negative edge of the reset signal. We will use a reg array to store the data and assign the read_data register based on the read enable signal and the address.
