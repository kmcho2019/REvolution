To implement the dual-port RAM, we will use two always blocks: one for writing data and one for reading data. The write operation will be synchronized with the clock signal and will write data to the specified address when the write enable signal is active. The read operation will also be synchronized with the clock signal and will read data from the specified address when the read enable signal is active. 
The RAM array will be declared as a 2D array of reg type with a size of [DEPTH-1:0] and a width of [WIDTH-1:0]. 
The reset operation will clear all the memory locations in the RAM array and the read_data register.
