To implement a dual-port RAM with the specified requirements, we need to design a module that includes a register array to store data and two separate always blocks to handle write and read operations. The write operation is triggered by the write enable signal and updates the RAM array at the specified address. The read operation is triggered by the read enable signal and assigns the data at the specified address in the RAM array to the read_data register. Both operations are synchronized with the clock signal and are reset when the reset signal is active low.
