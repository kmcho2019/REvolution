In the first always block, we perform the write operation by checking the write enable signal and writing the data to the specified address in the RAM array on the positive edge of the clock. We also handle the reset operation by clearing all memory locations when the reset signal is active.

In the second always block, we perform the read operation by checking the read enable signal and assigning the data from the specified address in the RAM array to the read_data register on the positive edge of the clock.
