To implement a dual-port RAM with the specified requirements, we first need to define the module and its ports. The RAM array will be declared as a register with a specified width and depth. The write operation will be performed in one always block that triggers on the positive edge of the clock or the negative edge of the reset. The read operation will be performed in another always block that also triggers on the positive edge of the clock or the negative edge of the reset. We will use non-blocking assignments for the read and write operations to ensure that the changes are visible after the current clock cycle.
