To implement the dual-port RAM, we will first define the module with the given input and output ports, as well as the parameters WIDTH and DEPTH. We will then define the RAM array as a register array. The write operation will be implemented using an always block that triggers on the positive edge of the clock signal or the negative edge of the reset signal. Inside this block, we will check for the reset condition and clear the RAM array if necessary. We will also check for the write enable signal and write the data to the RAM array at the specified address. The read operation will be implemented using another always block that triggers on the positive edge of the clock signal or the negative edge of the reset signal. Inside this block, we will check for the reset condition and clear the read_data register if necessary. We will also check for the read enable signal and assign the data at the specified address in the RAM array to the read_data register. If the read enable signal is not active, we will clear the read_data register to 0.
