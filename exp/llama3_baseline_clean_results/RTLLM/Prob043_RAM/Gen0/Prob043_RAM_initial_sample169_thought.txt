To design the dual-port RAM, we will use two always blocks to handle write and read operations separately. The first always block will be responsible for writing data to the RAM array when the write enable signal is active. The second always block will handle reading data from the RAM array when the read enable signal is active. Both blocks will also handle the reset condition to clear the RAM array and the read_data register. We will define the RAM array as a 2D array of registers, with the size determined by the DEPTH and WIDTH parameters.
