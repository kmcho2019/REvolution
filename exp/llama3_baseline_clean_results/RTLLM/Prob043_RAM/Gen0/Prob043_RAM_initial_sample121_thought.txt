The module will be implemented with two always blocks. The first always block handles the reset and write operation. It will reset the RAM array when the reset signal is active-low, and write data to the specified address in the RAM array when the write enable signal is active. The second always block handles the read operation. It will clear the read_data register when the reset signal is active-low, and assign the data at the specified address in the RAM array to the read_data register when the read enable signal is active.
