The dual-port RAM module can be implemented using two always blocks to handle write and read operations separately. 
The first always block will handle the write operation and reset, ensuring data is written to the correct address when the write enable signal is active, and all memory locations are cleared on reset.
The second always block will handle the read operation and reset, ensuring the correct data is output when the read enable signal is active, and the output is cleared on reset.
We will define the RAM array as a reg type with the specified depth and width.
