To implement the dual-port RAM, we first define the module and its parameters, including the width and depth of the RAM. We then declare the input and output ports as specified. For the RAM array, we use a 2D array of registers to store the data. The write operation is performed in the first always block, where we check for the write enable signal and write the data to the specified address. The read operation is performed in the second always block, where we check for the read enable signal and read the data from the specified address. We also handle the reset signal to clear the RAM array and the read_data register.
