To implement the dual-port RAM, we first define the parameters WIDTH and DEPTH to determine the size of the RAM array. Then, we declare the RAM array as a two-dimensional array of registers, where each element is a 6-bit register. We use two always blocks to handle the write and read operations, respectively. The first always block is triggered by the positive edge of the clock signal or the negative edge of the reset signal. It initializes the RAM array to all zeros when the reset signal is active, and writes data to the RAM array at the specified address when the write enable signal is active. The second always block also triggers on the positive edge of the clock signal or the negative edge of the reset signal, and it assigns the data at the specified address in the RAM array to the read_data register when the read enable signal is active.
