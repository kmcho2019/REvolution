To implement a dual-port RAM, we'll use two always blocks: one for writing data to the RAM and another for reading data from the RAM. 
We'll define the RAM array as a 2D array of registers, where each register represents a memory location with a specified width. 
The write operation will be triggered on the positive edge of the clock signal and when the write enable signal is active. 
The read operation will also be triggered on the positive edge of the clock signal and when the read enable signal is active. 
We'll use a reset signal to clear the RAM array and the read_data register.
