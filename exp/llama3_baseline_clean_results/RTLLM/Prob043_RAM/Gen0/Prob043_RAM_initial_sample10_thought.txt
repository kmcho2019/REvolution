To implement a dual-port RAM with the specified requirements, we need to create a Verilog module named RAM. This module will have two main sections: one for writing data into the RAM and another for reading data from the RAM. Both operations can occur simultaneously, and they are controlled by their respective enable signals (write_en and read_en). We will use two always blocks: one for handling the write operation and the reset condition, and another for handling the read operation and the reset condition. The RAM array will be defined as a register with a size based on the parameters WIDTH and DEPTH.
