The dual-port RAM can be implemented using two always blocks: one for the write operation and another for the read operation. 
The first always block will handle the write operation, writing data to the RAM array when the write enable signal is active.
The second always block will handle the read operation, reading data from the RAM array when the read enable signal is active.
To enable concurrent read and write operations, both always blocks should be triggered by the same clock signal (posedge clk) and the same reset signal (negedge rst_n).
We also need to define the RAM array with the specified depth and width.
