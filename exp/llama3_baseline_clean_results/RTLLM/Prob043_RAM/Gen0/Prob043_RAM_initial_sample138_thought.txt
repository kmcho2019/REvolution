To design the dual-port RAM as per the specifications, we first define the module with the given input and output ports. We then declare the RAM array with the specified depth and width. The write operation is implemented using an always block that triggers on the positive edge of the clock or the negative edge of the reset signal. Inside this block, we handle the reset condition and the write enable condition. For the read operation, another always block is used, which also triggers on the positive edge of the clock or the negative edge of the reset signal. This block handles the reset condition and the read enable condition, assigning the read data to the output register accordingly.
