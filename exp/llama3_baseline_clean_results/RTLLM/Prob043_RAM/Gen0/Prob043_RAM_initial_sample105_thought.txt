The RAM will be implemented using a register array, where each location can store data of a specified width. Two always blocks will be used: one for handling write operations and reset, and the other for handling read operations and reset. 
The write operation will check the write enable signal and, if active, will write the provided data to the specified address in the RAM array on the positive edge of the clock signal. 
The read operation will check the read enable signal and, if active, will read the data from the specified address in the RAM array and assign it to the read_data register on the positive edge of the clock signal.
