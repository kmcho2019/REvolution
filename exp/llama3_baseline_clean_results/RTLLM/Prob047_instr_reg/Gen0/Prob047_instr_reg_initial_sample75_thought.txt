To design the instruction register module, we'll create a Verilog module named `instr_reg` with the specified input and output ports. We'll use two 8-bit registers, `ins_p1` and `ins_p2`, to store instructions from different sources. The module will be controlled by the `clk` and `rst` signals. Based on the `fetch` signal, we'll determine which register to update with the incoming `data`. We'll then derive the outputs `ins`, `ad1`, and `ad2` from the stored instructions.
