To implement the instruction register module (instr_reg), we need to focus on the following key aspects:
1. **Register Reset**: On the rising edge of the clock (clk), if the reset signal (rst) is low, both registers (ins_p1 and ins_p2) should be initialized to zero.
2. **Instruction Fetch**: Based on the fetch signal, instructions are captured from the data input and stored in either ins_p1 or ins_p2.
3. **Output Generation**: The outputs ins, ad1, and ad2 are derived from the stored instructions in ins_p1 and ins_p2.
We will use Verilog's always block to describe the behavior of the registers and output logic, and utilize the assign statement for continuous assignment of the outputs based on the register values.
