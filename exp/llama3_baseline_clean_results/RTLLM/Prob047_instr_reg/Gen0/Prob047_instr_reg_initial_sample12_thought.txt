To design the instruction register module, we'll use two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources. The module will have a clock input (clk) for synchronization, an active low reset signal (rst) to initialize the registers, a 2-bit control signal (fetch) to determine the source of the instruction, and an 8-bit data input (data) representing the instruction to be fetched. The module will output the high 3 bits of the instruction (ins), the low 5 bits of the instruction (ad1), and the full 8-bit data from the second source (ad2). We'll use a case statement to handle the different fetch signal values and assign the corresponding values to the output ports.
