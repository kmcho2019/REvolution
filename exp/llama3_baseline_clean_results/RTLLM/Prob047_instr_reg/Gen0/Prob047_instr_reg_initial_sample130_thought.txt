To design the instruction register module (instr_reg), we need to implement a module that can capture and process incoming instructions based on the control signal 'fetch'. The module should have two internal 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources. The outputs 'ins', 'ad1', and 'ad2' will be derived from these stored instructions. The module should also handle reset and synchronization based on the 'rst' and 'clk' signals respectively.
