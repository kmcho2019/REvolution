To implement the instruction register module, we need to consider the following steps:
- Initialize two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources.
- Use the rising edge of the clock signal (clk) to trigger the storage of instructions into the registers based on the fetch control signal.
- Implement the logic to derive the output ports (ins, ad1, ad2) from the stored instructions in the registers.
- Handle the reset (rst) signal to initialize both registers to zero when it is active low.
- Ensure that the registers retain their previous values if the fetch signal does not match the conditions for updating ins_p1 or ins_p2.
