To design the instruction register module (instr_reg), we need to implement two 8-bit registers, ins_p1 and ins_p2, to store instructions from different sources. The module will have input ports for the clock signal (clk), active low reset signal (rst), control signal (fetch), and 8-bit data input (data). The outputs will include the high 3 bits of the instruction (ins), the low 5 bits of the instruction (ad1), and the full 8-bit data from the second source (ad2). We will use the fetch signal to determine which register to update with the incoming data on the rising edge of the clock, while also considering the reset condition. The outputs will be derived based on the values stored in these registers.
