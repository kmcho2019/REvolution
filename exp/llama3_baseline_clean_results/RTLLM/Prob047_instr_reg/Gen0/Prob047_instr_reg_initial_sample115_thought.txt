The instruction register module, named instr_reg, will be designed with two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources. It will have input ports for the clock signal (clk), an active low reset signal (rst), a control signal (fetch) indicating the source of the instruction, and an 8-bit data input (data). The module will have output ports for the opcode or operation (ins), the register address (ad1), and the full 8-bit data from the second source (ad2). The module will use a synchronous reset and the instruction will be captured on the rising edge of the clock. The fetch signal will control which register is updated with the incoming instruction.
