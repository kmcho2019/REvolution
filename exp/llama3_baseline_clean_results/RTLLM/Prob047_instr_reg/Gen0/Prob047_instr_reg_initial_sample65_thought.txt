To design the instruction register module (instr_reg), we'll first declare the input and output ports according to the given specifications. Then, we'll define two 8-bit registers, ins_p1 and ins_p2, to store instructions from different sources. We'll use an always block to handle the clock signal and reset. Inside this block, we'll check the reset signal and, if low, initialize both registers to zero. Otherwise, we'll use the fetch signal to determine which register to update with the incoming data. Finally, we'll assign the outputs (ins, ad1, ad2) based on the stored instructions in ins_p1 and ins_p2. We'll use bit-slicing to extract the required bits for each output.
