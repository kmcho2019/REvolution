The instruction register module, instr_reg, will be designed with two 8-bit registers, ins_p1 and ins_p2, to hold instructions from different sources. The module will be sensitive to the rising edge of the clock signal and will perform the following operations based on the fetch control signal: 
- If fetch is 2'b01, it will store the data input into ins_p1.
- If fetch is 2'b10, it will store the data input into ins_p2.
- If neither condition is met, it will retain the previous values in both registers.
The outputs ins, ad1, and ad2 will be derived from the stored instructions.
The module will also have an active low reset signal to initialize both registers to zero when the reset signal is low.
