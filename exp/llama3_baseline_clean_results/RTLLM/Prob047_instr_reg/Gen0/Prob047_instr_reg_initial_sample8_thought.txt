To design the instruction register module (instr_reg), we need to consider the functionality and the signals involved. The module should have two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources. The reset (rst) signal will be used to initialize both registers to zero when it is low. Based on the fetch signal, we will decide which register to update with the incoming instruction from the data input. The outputs ins, ad1, and ad2 will be derived from the stored instructions. We will use always blocks to handle the synchronous reset and the updating of the registers based on the fetch signal.
