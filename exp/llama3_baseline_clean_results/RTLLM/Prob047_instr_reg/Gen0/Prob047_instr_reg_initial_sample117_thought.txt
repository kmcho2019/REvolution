The instruction register module (instr_reg) will be designed using two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources. The module will capture incoming instructions based on the control signal (fetch) and synchronize the process with the clock signal (clk). It will also reset the registers to zero when the active low reset signal (rst) is asserted. The outputs (ins, ad1, and ad2) will be derived from the stored instructions. To implement this, we will use a clocked always block to handle the clock and reset, and a case statement to handle the different fetch conditions.
