To design the instruction register module (instr_reg), we need to implement two 8-bit registers (ins_p1 and ins_p2) that can capture instructions from the data input based on the fetch control signal. The registers should be initialized to zero when the reset signal is low. The outputs ins, ad1, and ad2 are derived from the stored instructions. We will use if-else statements inside an always block to implement the logic for updating the registers based on the fetch signal and reset condition. Additionally, we will use bit-slicing to extract the required fields for the output signals.
