To implement the instruction register module (instr_reg), we need to follow these steps:
1. Define the module with the specified input and output ports.
2. Declare two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources.
3. Use the rising edge of the clock signal (clk) to trigger the update of these registers based on the reset (rst) and fetch signals.
4. Based on the value of the fetch signal, update the corresponding register with the data input.
5. Derive the output signals (ins, ad1, ad2) from the stored instructions in ins_p1 and ins_p2.
