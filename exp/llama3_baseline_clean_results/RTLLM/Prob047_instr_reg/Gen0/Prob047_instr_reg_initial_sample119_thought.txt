To implement the instruction register module, we'll first declare the module with its input and output ports. Then, we'll define two 8-bit registers, ins_p1 and ins_p2, to store instructions from different sources. We'll use a clocked always block to handle the rising edge of the clock and the reset signal. Based on the fetch signal, we'll update the corresponding register with the incoming instruction. Finally, we'll derive the outputs ins, ad1, and ad2 from the stored instructions.
