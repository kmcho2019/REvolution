To design the instruction register module (instr_reg), we will follow these steps:
1. Declare the module with its input and output ports as specified.
2. Initialize two internal 8-bit registers (ins_p1 and ins_p2) to store instructions.
3. Create a clocked always block to synchronize with the clk signal.
4. Within the always block, check for the reset condition and initialize both registers to zero if the reset signal (rst) is low.
5. Based on the fetch signal, update the corresponding register (ins_p1 or ins_p2) with the data input.
6. Assign the outputs (ins, ad1, and ad2) based on the values stored in the registers.
7. Use bit manipulation to extract the required fields for the outputs (ins, ad1, and ad2).
