To design the instruction register module (instr_reg), we'll first declare the input and output ports as specified. We'll use two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources. The module will be synchronized with the clock signal (clk) and will have an active low reset signal (rst) to initialize the registers. Based on the fetch signal, the module will capture instructions from the data input into the corresponding registers. The outputs will be derived from the stored instructions. We'll use a case statement to handle the different conditions of the fetch signal and assign the outputs accordingly.
