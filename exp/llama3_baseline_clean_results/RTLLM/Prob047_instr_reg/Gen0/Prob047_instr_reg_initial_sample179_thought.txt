To design the instruction register module 'instr_reg', we need to implement two 8-bit registers, ins_p1 and ins_p2, to store instructions from different sources. The module should have input ports for clock, reset, control signal 'fetch', and data input 'data'. Based on the 'fetch' signal, the module should capture the instruction from the 'data' input and store it in either ins_p1 or ins_p2. The outputs 'ins', 'ad1', and 'ad2' will be derived from the stored instructions. We will use Verilog's always block to describe the sequential behavior of the module.
