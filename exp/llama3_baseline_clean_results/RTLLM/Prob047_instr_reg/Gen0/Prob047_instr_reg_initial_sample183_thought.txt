The instruction register module (instr_reg) is designed to capture and process incoming CPU instructions. It will have two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources. The module will use a clock signal (clk) for synchronization and an active low reset signal (rst) to initialize the registers. The fetch signal will determine which register to update with the incoming instruction. The module will then output the opcode (ins), register address (ad1), and the full 8-bit data from the second source (ad2) based on the stored instructions.
