The instruction register module (instr_reg) is designed to capture and process CPU instructions from various sources. To implement this, we will create a module with two 8-bit registers (ins_p1 and ins_p2) to store instructions. Based on the fetch signal, we will determine which register to update with the incoming instruction. The outputs will be derived from the stored instructions. We will use a clock signal (clk) for synchronization and a reset signal (rst) to initialize the registers. The module will have input ports for the clock, reset, fetch signal, and data, as well as output ports for the opcode, register address, and the full 8-bit data.
