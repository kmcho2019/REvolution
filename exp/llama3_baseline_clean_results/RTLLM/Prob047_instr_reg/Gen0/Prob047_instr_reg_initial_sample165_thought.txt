To implement the instruction register module, we'll use two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources. The module will have a clock signal for synchronization, a reset signal to initialize the registers, a control signal to determine the source of the instruction, and an 8-bit data input representing the instruction. The output ports will be derived from the stored instructions in the registers.

We'll use if-else statements to handle the different conditions based on the fetch signal and update the registers accordingly. We'll also use bit manipulation to extract the required fields from the stored instructions for the output ports.
