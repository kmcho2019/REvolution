To implement the instruction register module, we first need to define the module with the specified input and output ports. We then use two 8-bit registers (ins_p1 and ins_p2) to store instructions from different sources. The module should reset both registers to zero when the reset signal (rst) is low. On the rising edge of the clock (clk), the module should check the fetch signal to determine which register to update with the incoming instruction. Finally, the module should derive the output signals ins, ad1, and ad2 from the stored instructions.
