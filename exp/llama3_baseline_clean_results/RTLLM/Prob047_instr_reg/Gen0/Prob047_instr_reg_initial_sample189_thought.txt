To implement the instruction register module, we need to consider the following key points:
- The module should have two 8-bit registers, ins_p1 and ins_p2, to store instructions from different sources.
- On the rising edge of the clock signal (clk), if the reset signal (rst) is low, both registers should be initialized to zero.
- The fetch signal should control which register is updated with the incoming data.
- The outputs ins, ad1, and ad2 should be derived from the stored instructions in ins_p1.
We can use Verilog's always block to implement the sequential logic for the registers and the combinational logic for the outputs.
We'll use if-else statements inside the always block to handle the reset and fetch conditions.
For the output logic, we can directly assign the required bits from the ins_p1 register to the output ports ins, ad1, and assign the full data from ins_p2 to ad2.
