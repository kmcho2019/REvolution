To implement a 3-bit comparator, we can use simple combinational logic. The comparator module will have three output signals: A_greater, A_equal, and A_less. 
We can determine the values of these signals by comparing the input operands A and B bit by bit from most significant bit (MSB) to least significant bit (LSB).
If A is greater than B, we set A_greater to 1. If A is equal to B, we set A_equal to 1. If A is less than B, we set A_less to 1.
Since the outputs are mutually exclusive, we will use if-else statements to assign the values to the output signals.
