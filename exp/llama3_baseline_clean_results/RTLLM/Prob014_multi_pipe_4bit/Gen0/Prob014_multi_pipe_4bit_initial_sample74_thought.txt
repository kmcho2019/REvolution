The 4-bit unsigned number pipeline multiplier will be implemented using a generate block to perform multiplication for each bit position of the multiplier (mul_b) and generate the partial products. 
The module will use two levels of registers to store the intermediate sum values. 
The first register will store the sum of the partial products after the first clock cycle, and the second register will store the final product after the second clock cycle. 
The module will also handle the reset condition, where the registers and output will be set to 0 when the reset signal (rst_n) is low.
The extension of input signals will be done by adding "size" number of zero bits at the most significant bit positions.
