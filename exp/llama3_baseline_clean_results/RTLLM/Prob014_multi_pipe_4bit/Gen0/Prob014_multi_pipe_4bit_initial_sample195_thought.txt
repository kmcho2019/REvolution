To implement the 4-bit unsigned pipeline multiplier, we will follow these steps:
- Create a module named `multi_pipe_4bit` with the specified input and output ports.
- Extend the input signals `mul_a` and `mul_b` by adding "size" number of zero bits at the most significant bit positions.
- Use a generate block to perform multiplication for each bit position of the multiplier `mul_b` and generate the partial products.
- Store the intermediate sum values in registers and perform add operations on the positive edge of the clock signal `clk` or the falling edge of the reset signal `rst_n`.
- Calculate the final product on the positive edge of the clock signal `clk` or the falling edge of the reset signal `rst_n` and update the product output `mul_out`.
