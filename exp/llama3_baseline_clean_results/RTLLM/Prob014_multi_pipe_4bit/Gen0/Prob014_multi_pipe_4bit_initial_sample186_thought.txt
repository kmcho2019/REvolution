To implement a 4-bit unsigned number pipeline multiplier, we will design a module named 'multi_pipe_4bit'. The module will have two levels of registers to store intermediate values and control the multiplication process. 

1. The input signals 'mul_a' and 'mul_b' will be extended by adding "size" number of zero bits at the most significant bit positions.
2. A generate block will be used to perform multiplication for each bit position of the multiplier 'mul_b' and generate the partial products.
3. For each bit position 'i' from 0 to size-1, the partial product will be calculated based on whether the corresponding bit in the multiplier is 1 or 0.
4. Registers will be used to store the intermediate sum values. On the positive edge of the clock signal 'clk' or the falling edge of the reset signal 'rst_n', the module will perform add operations.
5. If the reset signal 'rst_n' is low, the registers and product output will be set to 0. If the reset signal 'rst_n' is high, the registers will be updated with the sum of the corresponding partial products and the product output will be updated with the sum of registers.
