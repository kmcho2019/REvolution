2.  Multiplication operation: We use a generate block to perform multiplication for each bit position of the multiplier (`mul_b`) and generate the partial products. For each bit position `i` from 0 to `size-1`, the partial product is calculated as follows:
    *   If the corresponding bit in the multiplier is 1, the multiplicand is left-shifted by `i` positions.
    *   If the corresponding bit in the multiplier is 0, the partial product is set to 0.
3.  Addition of partial products: We use registers to store the intermediate sum values.
