The 4-bit unsigned number pipeline multiplier can be designed using two levels of registers to store intermediate values and control the multiplication process. 
The input signals (mul_a and mul_b) are first extended by adding "size" number of zero bits at the most significant bit positions.
Then, the module uses a generate block to perform multiplication for each bit position of the multiplier (mul_b) and generate the partial products.
The partial products are added together using registers to store the intermediate sum values.
The final product is calculated by summing up the values in the registers.
This design can be implemented in Verilog using a combination of combinational logic and sequential logic.
