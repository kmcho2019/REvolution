To implement the 4-bit unsigned number pipeline multiplier, we will follow these steps:
1. Define the module multi_pipe_4bit with the specified input and output ports.
2. Extend the input signals (mul_a and mul_b) by adding "size" number of zero bits at the most significant bit positions.
3. Use a generate block to perform multiplication for each bit position of the multiplier (mul_b) and generate the partial products.
4. Implement the add operation for partial products using registers to store intermediate sum values.
5. Calculate the final product by summing up the registers on the positive edge of the clock signal (clk) or the falling edge of the reset signal (rst_n).
