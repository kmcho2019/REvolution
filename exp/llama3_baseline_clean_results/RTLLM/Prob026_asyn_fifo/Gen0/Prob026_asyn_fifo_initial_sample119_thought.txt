The asynchronous FIFO will be designed with a dual-port RAM as the data storage unit. The data write controller and data read controller will manage the write and read operations, respectively. The read pointer synchronizer and write pointer synchronizer will be used to collect the read and write pointers and output them to the data write controller and data read controller, respectively. The empty and full judgment will be done by comparing the Gray code of the read and write pointers. The Gray code will be converted to a binary number to access the RAM. The FIFO will be considered full when the write pointer has one more cycle RAM than the read pointer, and the highest and second-highest bits of the read and write pointer are opposite, while the remaining bits are the same. The FIFO will be considered empty when the read and write pointers are equal.
