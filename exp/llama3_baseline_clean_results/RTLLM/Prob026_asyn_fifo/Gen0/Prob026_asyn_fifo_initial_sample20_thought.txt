To implement the asynchronous FIFO, we will create a Verilog module named `asyn_fifo` that includes the following components:
1. Dual-port RAM for data storage.
2. Data write controller to manage write operations.
3. Data read controller to manage read operations.
4. Read pointer synchronizer to collect the read pointer and output it to the data write controller.
5. Write pointer synchronizer to collect the write pointer and output it to the data read controller.
The module will have the following input and output ports:
- Input ports: wclk, rclk, wrstn, rrstn, winc, rinc, wdata.
- Output ports: wfull, rempty, rdata.
We will use parameters to configure the FIFO bit width (WIDTH) and depth (DEPTH).
The module will use Gray code conversion for the write and read pointers to reduce glitches and ensure proper synchronization.
