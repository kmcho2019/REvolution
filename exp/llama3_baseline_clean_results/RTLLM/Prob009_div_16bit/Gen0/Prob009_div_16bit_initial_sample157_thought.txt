To implement the 16-bit divider module in combinational logic, we need to follow a step-by-step process:
1. Extract the higher bits of the dividend (A) to match the bit width of the divisor (B), which is 8 bits.
2. Compare these extracted bits with the divisor (B). If the extracted bits are greater, set the quotient bit to 1; otherwise, set it to 0.
3. Calculate the difference between the extracted bits and the divisor (if the quotient bit is 1) or use the extracted bits as is (if the quotient bit is 0).
4. Concatenate this difference with the next bit of the dividend (A), and repeat the process until all bits of the dividend have been processed.
This process effectively performs a division operation by iteratively subtracting the divisor from the dividend and keeping track of the remainders and quotients.
The module will use two always blocks: one to update the internal registers with the input values, and another to perform the division operation based on the updated values.
