To implement the radix-2 divider, we need to create a finite state machine (FSM) that handles the division process. The FSM will have two main states: idle and division. In the idle state, the module waits for a valid operation request (opn_valid is high and res_valid is low). Once a request is received, the module transitions to the division state and starts the division process. The division process involves shifting the dividend left, subtracting the divisor, and updating the quotient and remainder accordingly. We will use a counter to keep track of the number of iterations, and once the counter reaches 8, the division is complete. We will also handle the reset signal to initialize the module and the sign bit to support both signed and unsigned division operations.
