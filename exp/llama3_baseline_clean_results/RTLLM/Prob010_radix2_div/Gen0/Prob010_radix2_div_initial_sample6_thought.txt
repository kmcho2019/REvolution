To implement the radix-2 divider, I will design a finite state machine (FSM) that controls the division process. The FSM will have two main states: idle and division. When the operation is valid and the result is not, the FSM transitions to the division state. In this state, it performs the division process by shifting the dividend, subtracting the divisor, and updating the quotient and remainder. The division process is repeated 8 times, and then the FSM transitions back to the idle state and sets the result valid signal.
The subtraction result will be used to update the shift register SR, which stores the remainder and quotient. The NEG_DIVISOR will be used to determine the subtraction result. A multiplexer will be used to select the appropriate result based on the carry-out of the subtraction.
The design will also include a counter to keep track of the number of iterations and a flag to indicate whether the division process has started.
The result will be a 16-bit value, with the upper 8 bits representing the remainder and the lower 8 bits representing the quotient.
