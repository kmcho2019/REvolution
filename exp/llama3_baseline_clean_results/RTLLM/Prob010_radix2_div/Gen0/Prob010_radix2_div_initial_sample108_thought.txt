To implement the simplified radix-2 divider, we will use a combination of combinational and sequential logic. The division process is started when opn_valid is high and res_valid is low. We will save the inputs dividend and divisor, initialize the shift register SR with the absolute value of the dividend shifted left by one bit, set NEG_DIVISOR to the negated absolute value of the divisor, and set the counter cnt to 1 and start_cnt to 1. Then, the division process will be performed based on the subtraction result, updating the shift register SR and the counter cnt accordingly. Once the division is complete, we will update the result and set res_valid to high.
