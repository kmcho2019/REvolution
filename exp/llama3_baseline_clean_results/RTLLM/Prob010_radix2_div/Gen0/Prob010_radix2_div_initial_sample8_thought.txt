To implement the radix-2 divider, we will use a finite state machine (FSM) with two main states: idle and division. In the idle state, the module waits for a valid operation request (opn_valid high and res_valid low). Once the request is received, the module transitions to the division state where it performs the division process. The division process involves updating the shift register SR based on the subtraction result and the carry-out. The process continues until the counter cnt reaches 8, indicating the completion of the division. The result is then made valid by setting res_valid high. We will also handle the reset signal to initialize or reset the module.
