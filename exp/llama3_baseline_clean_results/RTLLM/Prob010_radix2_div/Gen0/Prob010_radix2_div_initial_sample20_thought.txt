The radix2_div module will be implemented as a finite state machine with two main states: idle and division. 
In the idle state, it waits for a valid operation request (opn_valid high and res_valid low). 
Once a valid request is detected, it transitions to the division state and initializes the necessary registers. 
In the division state, it performs the radix-2 division algorithm, updating the shift register and counter accordingly. 
After 8 iterations, the division is complete, and the module updates the result and sets res_valid high. 
The result is valid until it is consumed (i.e., res_valid is high), at which point the module resets and waits for the next valid operation request.
