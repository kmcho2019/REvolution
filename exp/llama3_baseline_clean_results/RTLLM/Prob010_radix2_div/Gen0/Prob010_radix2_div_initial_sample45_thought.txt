The radix2_div module will be implemented as a finite state machine with two main states: idle and division. 
In the idle state, the module waits for a valid operation request (opn_valid high and res_valid low). 
Once the operation request is received, the module transitions to the division state where it performs the radix-2 division. 
The division process involves shifting the dividend, subtracting the divisor, and updating the quotient and remainder accordingly. 
The module will also handle signed and unsigned division operations based on the sign input.
