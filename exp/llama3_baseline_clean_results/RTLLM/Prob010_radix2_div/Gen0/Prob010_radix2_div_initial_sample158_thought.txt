The radix2_div module will be designed as a finite state machine (FSM) that performs a simplified radix-2 division on 8-bit signed or unsigned integers. The FSM will have two main states: idle and division. In the idle state, the module waits for a valid operation request (opn_valid high and res_valid low). When a valid request is detected, the module transitions to the division state, where it saves the inputs, initializes the shift register SR, and starts the division process. The division process involves shifting the shift register SR, subtracting the NEG_DIVISOR, and updating the SR based on the subtraction result. The division process continues until the counter cnt reaches 8, at which point the module updates the result and transitions back to the idle state.
