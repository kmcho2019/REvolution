The radix2_div module will be designed as a finite state machine (FSM) with two main states: idle and division. The idle state waits for a valid operation request (opn_valid high and res_valid low) to start the division process. In the division state, the module performs the radix-2 division algorithm. The algorithm uses a shift register (SR) to store the current remainder and quotient, and a counter (cnt) to keep track of the division steps. The NEG_DIVISOR is computed as the negated absolute value of the divisor. The result is updated based on the carry-out of the subtraction operation. The res_valid signal is managed to indicate when the result is ready and valid.
