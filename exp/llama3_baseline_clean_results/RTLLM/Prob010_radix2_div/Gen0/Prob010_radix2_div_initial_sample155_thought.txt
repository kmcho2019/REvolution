To implement the simplified radix-2 divider, we will use a finite state machine (FSM) to manage the division process. The FSM will have two main states: idle and division. In the idle state, the module waits for a valid operation request (opn_valid high and res_valid low). Once a valid request is received, the module transitions to the division state and starts the division process. The division process involves shifting the dividend left by one bit, subtracting the divisor, and updating the shift register based on the subtraction result. The process continues until the counter reaches 8, indicating the completion of the division. The result is then updated, and the res_valid signal is set high to indicate that the result is valid and ready.
