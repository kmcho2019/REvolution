To implement the radix-2 divider, we will first handle the initialization of the operation based on the opn_valid and res_valid signals. We then perform the division process, which involves a series of subtractions and updates to the shift register. We use a counter to keep track of the number of division steps and manage the validity of the result based on the reset signal, counter, and consumption of the result.
The main components of the design include:
1. Input handling: Save the inputs dividend and divisor when opn_valid is high and res_valid is low.
2. Initialization: Initialize the shift register SR with the absolute value of the dividend shifted left by one bit and set NEG_DIVISOR to the negated absolute value of the divisor.
3. Division process: Perform the division steps, updating the shift register and counter as necessary.
4. Result validity: Manage res_valid based on the reset signal, counter, and consumption of the result.
We will implement this using Verilog, utilizing non-blocking assignments for sequential logic and focusing on proper signal management to ensure correct operation.
