- Create a module `radix2_div` with the specified ports.
- Initialize variables to store the dividend, divisor, and their absolute values.
- Implement the logic to start the division process when `opn_valid` is high and `res_valid` is low.
- Develop the division process, including updating the shift register `SR`, the counter `cnt`, and managing the `start_cnt` signal.
- Use a multiplexer to select the result based on the carry-out of the subtraction.
