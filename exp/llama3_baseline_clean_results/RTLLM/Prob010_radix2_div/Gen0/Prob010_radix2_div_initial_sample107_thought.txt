To implement the simplified radix-2 divider, we'll follow these steps:
- Create a module named `radix2_div` with the specified input and output ports.
- Use a finite state machine (FSM) or a combinational logic approach to manage the division process, which includes handling the operation start, division steps, and result validity.
- Implement the initial step of saving inputs and initializing the shift register `SR`, `NEG_DIVISOR`, and counters `cnt` and `start_cnt` when `opn_valid` is high and `res_valid` is low.
- Develop the division process logic, which increments the counter, computes the subtraction, uses a multiplexer for selecting the result based on the carry-out, and updates the shift register `SR` accordingly.
- Manage the `res_valid` signal based on the reset, counter, and result consumption.
- Ensure the module handles both signed and unsigned division operations based on the `sign` input.
