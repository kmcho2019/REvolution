To implement a radix-2 divider, we will design a finite state machine (FSM) with two main states: idle and division. In the idle state, we wait for a valid operation request (opn_valid) and save the inputs. When the division process starts, we initialize the shift register with the absolute value of the dividend and the negated absolute value of the divisor. We then iteratively update the shift register based on the subtraction result and the carry-out. The division process continues until the counter reaches 8, at which point we update the result and set res_valid high.
