To implement the simplified radix-2 divider, we will design a finite state machine (FSM) that orchestrates the division process. The FSM will have two main states: idle and division. In the idle state, the module waits for a valid operation request (opn_valid) and saves the inputs when received. In the division state, the module performs the radix-2 division algorithm, updating the shift register and counter accordingly. The result validity is managed based on the reset signal, the counter, and whether the result has been consumed. We will use a combination of sequential and combinational logic to implement the radix-2 divider.
