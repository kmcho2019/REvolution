To design the square_wave module, we will follow these steps:
1. Initialize the count register to 0 and the wave_out signal to 0.
2. On each rising edge of the clk, check if the count has reached (freq - 1).
3. If the count equals (freq - 1), reset count to 0 and toggle the wave_out signal.
4. If the count does not equal (freq - 1), increment the count by 1.

This approach ensures that the square wave output toggles at the rate specified by the freq input.
