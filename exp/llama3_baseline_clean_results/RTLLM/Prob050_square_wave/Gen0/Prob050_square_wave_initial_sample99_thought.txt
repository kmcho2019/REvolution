To create the square_wave module, we will use a counter-based approach. We'll utilize the clk signal to drive the module and the freq input to determine when to toggle the wave_out signal. The count register will keep track of the number of cycles since the last toggle. When the count reaches the value specified by freq, we'll reset the count and flip the wave_out signal. This process will continue indefinitely, producing a square wave signal at the desired frequency.
