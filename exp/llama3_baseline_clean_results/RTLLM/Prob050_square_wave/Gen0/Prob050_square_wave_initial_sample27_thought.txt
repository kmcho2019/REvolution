The square_wave module will utilize a counter to track cycles between toggles of the square wave output. On each rising edge of the clk signal, the counter will increment. When the counter reaches the value specified by the freq input minus one, it will reset to zero and toggle the wave_out signal. This will effectively produce a square wave with a frequency controlled by the freq input. The counter and the wave_out signal will be implemented using internal registers. The higher the freq value, the slower the square wave will toggle, and vice versa.
