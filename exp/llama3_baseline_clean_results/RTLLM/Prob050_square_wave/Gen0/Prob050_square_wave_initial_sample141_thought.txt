To design the square_wave module, we will utilize a counter to track the number of clock cycles between each toggle of the wave_out signal. This counter, named count, will increment on every rising edge of the clk signal. When the count register reaches the value specified by the freq input minus one, the count is reset to 0, and the wave_out signal is toggled. The wave_out signal will thus toggle at a frequency determined by the freq input. The implementation will be based on a simple if-else statement within a always @(posedge clk) block to handle the count and wave_out updates.
