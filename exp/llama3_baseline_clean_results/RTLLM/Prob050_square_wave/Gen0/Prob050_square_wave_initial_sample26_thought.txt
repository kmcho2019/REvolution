The square_wave module will utilize a counter register to keep track of the number of clock cycles between wave toggles. On each rising edge of the input clock signal, the counter will be incremented until it reaches the specified frequency minus one, at which point it will be reset to zero and the output square wave signal will be toggled. This design ensures that the output frequency of the square wave is directly proportional to the input frequency value. 
To implement this, we'll use a simple if-else statement within a clocked always block to control the counter and output signal based on the frequency value. We'll also use a non-blocking assignment to ensure that the output signal is updated correctly.
