To create the square_wave module, we need to implement a counter that increments on each rising edge of the input clock signal (clk) and resets to 0 when it reaches the specified frequency value minus one (freq - 1). At this point, we also need to toggle the output square wave signal (wave_out). This toggle operation can be achieved by using a separate register to keep track of the current state of the output wave and flipping its value each time the counter resets.
