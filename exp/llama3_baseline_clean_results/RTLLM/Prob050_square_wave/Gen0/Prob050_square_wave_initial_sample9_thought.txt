The square_wave module will utilize a counter register to track the number of cycles between each toggle of the wave_out signal. On each rising edge of the input clock signal (clk), the counter will increment. When the counter reaches the value specified by the frequency input (freq - 1), the counter will reset and the wave_out signal will toggle. This approach ensures that the square wave output toggles at a frequency determined by the input freq value.
