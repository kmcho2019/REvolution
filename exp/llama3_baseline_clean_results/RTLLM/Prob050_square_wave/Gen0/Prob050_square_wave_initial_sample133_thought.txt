To design the square_wave module, we will implement a counter-based approach. We will use an internal counter register, 'count', to keep track of the clock cycles. This counter will increment on each rising edge of the input clock signal 'clk'. When the counter reaches the value specified by the 'freq' input minus one, it will reset to zero and toggle the 'wave_out' signal. This way, the 'wave_out' signal will produce a square wave that toggles at the frequency specified by the 'freq' input. The higher the 'freq' value, the slower the square wave will toggle, and vice versa.
