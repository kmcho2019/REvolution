To design the square_wave module, we need to implement a counter that increments on each rising edge of the input clock signal. The counter will be reset to 0 when it reaches the frequency value minus 1, and at the same time, the wave_out signal will be toggled. This will effectively produce a square wave signal with a frequency determined by the freq input. We will use an always block to capture the rising edge of the clock signal and perform the necessary operations.
