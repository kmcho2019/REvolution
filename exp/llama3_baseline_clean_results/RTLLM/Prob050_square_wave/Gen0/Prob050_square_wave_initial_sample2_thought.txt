To create the square_wave module, we will implement a counter-based approach. The module will have an 8-bit counter register (count) that increments on every rising edge of the input clock (clk). When the count reaches the specified frequency value minus one (freq - 1), the count is reset to 0 and the output square wave signal (wave_out) is toggled. This will effectively produce a square wave that toggles at a rate determined by the input frequency value. We will use a simple if-else statement to handle the counter reset and the wave_out toggle operation.
