The module square_wave can be implemented using a simple counter-based approach. The counter, named count, increments on each rising edge of the clk signal. When the count reaches the specified frequency (freq), it is reset to 0 and the wave_out signal is toggled. The wave_out signal is initially set to 0 and flips its value every time the count reaches the specified frequency. This approach ensures that the square wave output frequency is controlled by the input frequency value. The higher the frequency value, the slower the square wave toggles, and vice versa.
