To create the square_wave module, we will use a counter register (count) to track the cycles between wave toggles. On each rising edge of the clk, the count register will increment. When count reaches the value specified by freq - 1, the count register will reset to 0 and the wave_out signal will toggle. The frequency of the square wave will be determined by the freq input, with higher freq values resulting in a lower output frequency and vice versa. We will use an always block to implement this logic, and we will also use a non-blocking assignment to ensure that the count register and wave_out signal are updated correctly.
