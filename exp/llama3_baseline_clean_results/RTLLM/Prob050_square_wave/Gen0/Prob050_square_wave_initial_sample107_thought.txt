The square_wave module is designed to generate a square wave signal at a variable frequency. It uses a counter to track the number of clock cycles and toggles the output wave_out when the counter reaches the specified frequency. The module will be implemented using a simple always block that increments the counter on each rising edge of the clock and resets it when it reaches the frequency value, toggling the output at that point. The square wave generation will be achieved by flipping the wave_out signal at the rate determined by the freq input.
