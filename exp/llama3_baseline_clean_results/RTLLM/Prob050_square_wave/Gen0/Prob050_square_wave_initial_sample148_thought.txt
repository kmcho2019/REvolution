The square_wave module will utilize a counter to track the number of clock cycles between wave toggles. On each rising edge of the input clock signal, the counter will increment. When the counter reaches the specified frequency value minus one, it will reset and toggle the output square wave signal. This approach allows the module to produce a square wave with a frequency determined by the input frequency value. The counter will be implemented as an 8-bit register to match the input frequency value's bit width.
