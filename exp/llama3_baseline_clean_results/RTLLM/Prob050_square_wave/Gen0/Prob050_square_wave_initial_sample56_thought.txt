The square_wave module will be designed using a counter-based approach. The module will have an internal 8-bit counter (count) that increments on every rising edge of the input clock signal (clk). When the counter reaches the specified frequency value minus one, the counter will reset and the square wave output (wave_out) will toggle. This way, the module can generate a square wave signal with a frequency determined by the input frequency value (freq). To achieve this, we will use always blocks in Verilog to describe the sequential behavior of the module.
