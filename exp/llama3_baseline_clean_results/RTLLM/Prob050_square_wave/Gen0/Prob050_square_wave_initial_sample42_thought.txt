The module 'square_wave' will utilize a counter to track clock cycles and toggle the 'wave_out' signal at the specified frequency. 
The counter 'count' will increment on each rising edge of the input clock 'clk'. 
When 'count' reaches the value of 'freq - 1', it will reset to 0 and toggle the 'wave_out' signal. 
This process effectively generates a square wave with a frequency determined by the 'freq' input.
The relationship between the input frequency and the output frequency of the square wave is inversely proportional, meaning a higher 'freq' value results in a lower output frequency and vice versa.
