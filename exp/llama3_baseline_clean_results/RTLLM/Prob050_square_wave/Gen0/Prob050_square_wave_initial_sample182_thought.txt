The square_wave module will utilize a counter register to track the number of clock cycles. On each rising edge of the clock, the counter will increment. When the counter reaches the value specified by the freq input minus one, the counter will reset to 0 and the wave_out signal will toggle. This effectively produces a square wave signal where the frequency of the wave is inversely proportional to the value of freq. We will use a conditional statement to check if the count has reached the desired value and toggle the wave_out accordingly.
