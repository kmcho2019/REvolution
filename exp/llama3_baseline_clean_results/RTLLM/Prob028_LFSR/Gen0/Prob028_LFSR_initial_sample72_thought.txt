To design the 4-bit Linear Feedback Shift Register (LFSR), we will follow these steps:
1. Define the module LFSR with the specified input and output ports.
2. Use a reg declaration to define the internal 4-bit register.
3. Implement the reset logic to initialize the register to zero when the reset signal (rst) is high.
4. Apply the LFSR feedback mechanism by calculating the XOR of the most significant bit (out[3]) and the second most significant bit (out[2]), then inverting the result to produce the feedback signal.
5. Use a procedural assignment to shift the bits in the register left and insert the new feedback value at the least significant bit (LSB) on the rising edge of the clock (clk).
6. Assign the current state of the internal register to the output port (out).
