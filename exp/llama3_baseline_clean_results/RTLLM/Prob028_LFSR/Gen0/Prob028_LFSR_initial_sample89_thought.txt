To design a 4-bit Linear Feedback Shift Register (LFSR), we will use a Verilog module named LFSR. The module will have two input ports: clk for the clock signal and rst for the active high reset signal. The output port will be a 4-bit out vector. The feedback mechanism will involve XORing the most significant bit (out[3]) and the second most significant bit (out[2]), inverting the result, and using this as the new least significant bit on each clock cycle, unless the reset signal is high, in which case the register will be reset to zero.
