To implement the 4-bit Linear Feedback Shift Register (LFSR), we need to design a module that can perform the following operations: 
1. Initialize the register to zero when the active high reset signal (rst) is asserted.
2. On the rising edge of the clock signal (clk), shift the bits in the register one position to the left.
3. Calculate the feedback signal by XORing the most significant bit (MSB) and the second most significant bit, and then inverting the result.
4. Insert the feedback signal at the least significant bit (LSB) position after shifting.

The module will have a clock signal (clk) and an active high reset signal (rst) as inputs, and a 4-bit output (out) representing the current state of the LFSR.
We will use a reg type to declare the internal state of the LFSR and always block to describe the sequential behavior.
