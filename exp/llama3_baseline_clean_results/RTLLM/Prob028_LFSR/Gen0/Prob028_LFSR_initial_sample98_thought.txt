To implement the 4-bit Linear Feedback Shift Register (LFSR), we need to follow these steps:
1. Initialize the LFSR with a reset value when the reset signal (rst) is high.
2. On the rising edge of the clock signal (clk), check if the reset signal is high. If it is, reset the LFSR to zero. Otherwise, calculate the feedback signal by XORing the most significant bit (out[3]) and the second most significant bit (out[2]), then invert the result.
3. Shift the bits in the LFSR to the left, inserting the new feedback value at the least significant bit (LSB) position.
We will use a reg data type to store the current state of the LFSR, and wire for the output.
