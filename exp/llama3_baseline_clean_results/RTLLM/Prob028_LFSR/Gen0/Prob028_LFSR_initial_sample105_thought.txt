To implement the 4-bit Linear Feedback Shift Register (LFSR), we need to follow these steps:
1. Initialize the LFSR with a reset signal (rst) that, when active high, sets all bits of the LFSR to zero.
2. Calculate the feedback signal by XORing the most significant bit (MSB) and the second most significant bit, then inverting the result.
3. On the rising edge of the clock signal (clk), shift the bits in the LFSR one position to the left.
4. Insert the new feedback value at the least significant bit (LSB) position after shifting.
5. Ensure that the output (out) always represents the current state of the LFSR.
We will use Verilog's non-blocking assignment (<=) to update the register value at each clock edge to avoid race conditions.
