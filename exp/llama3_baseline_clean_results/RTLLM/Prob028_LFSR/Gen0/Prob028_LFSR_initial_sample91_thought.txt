To implement the 4-bit Linear Feedback Shift Register (LFSR), we'll follow these steps:
1. Define the module `LFSR` with the specified input and output ports.
2. Initialize the internal 4-bit register (`out`) to zero when the reset signal (`rst`) is high.
3. On the rising edge of the clock (`clk`), shift the bits in the register one position to the left.
4. Calculate the feedback signal by XORing the most significant bit (`out[3]`) and the second most significant bit (`out[2]`), then inverting the result.
5. Insert the new feedback value at the least significant bit (LSB) position of the register.
This process will generate a pseudo-random sequence of bits based on the LFSR's feedback mechanism.
