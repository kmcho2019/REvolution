To implement the LFSR module, we need to follow these steps:
- On the rising edge of the clock signal (clk), check if the reset signal (rst) is high.
- If rst is high, reset the register to zero.
- If rst is low, calculate the feedback signal by XORing the most significant bit (out[3]) and the second most significant bit (out[2]), then invert the result.
- Shift the bits in the register to the left and insert the new feedback value at the least significant bit (LSB).
- Assign the updated register value to the output port (out [3:0]).
