To implement the LFSR module, we need to follow these steps:
1. Define the module with the given input and output ports.
2. Initialize the output register (out) with a 4-bit width to hold the current state of the LFSR.
3. Calculate the feedback signal by XORing the most significant bit (out[3]) and the second most significant bit (out[2]), then inverting the result.
4. Use a clocked always block to synchronize the shifting operation with the rising edge of the clock signal (clk).
5. Within the clocked always block, implement the reset logic: if the reset signal (rst) is high, reset the register to zero; otherwise, shift the bits left and insert the new feedback value at the least significant bit (LSB).
