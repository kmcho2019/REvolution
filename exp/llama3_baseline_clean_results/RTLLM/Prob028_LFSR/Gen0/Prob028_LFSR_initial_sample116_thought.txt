To implement the 4-bit Linear Feedback Shift Register (LFSR), we need to follow these steps:
1. Define the module with the specified input and output ports.
2. Initialize the output register `out` with a default value.
3. Use a always block to handle the clock and reset signals.
4. Inside the always block, check for the rising edge of the clock and reset signal.
5. If the reset signal is high, initialize the output register `out` to zero.
6. Otherwise, calculate the feedback value by XORing the most significant bit (out[3]) and the second most significant bit (out[2]), then inverting the result.
7. Shift the bits in the register left and insert the new feedback value at the least significant bit (LSB).
