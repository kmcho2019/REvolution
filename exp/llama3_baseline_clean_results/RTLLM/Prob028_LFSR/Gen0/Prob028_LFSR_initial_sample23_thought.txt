To implement the 4-bit Linear Feedback Shift Register (LFSR), we need to follow these steps:
1. Define the module LFSR with the specified input and output ports.
2. Initialize the 4-bit register with a default value.
3. On the rising edge of the clock, check the reset signal. If it's high, reset the register to zero.
4. If the reset signal is low, calculate the feedback signal by XORing the most significant bit and the second most significant bit, and then inverting the result.
5. Shift the bits in the register to the left and insert the new feedback value at the least significant bit.
6. Update the output port with the current state of the register.

We'll use a reg type to hold the current state of the LFSR and a always block to define the behavior on the rising edge of the clock.
