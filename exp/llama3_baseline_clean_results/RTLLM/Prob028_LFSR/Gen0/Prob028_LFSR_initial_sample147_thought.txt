To design the 4-bit Linear Feedback Shift Register (LFSR), we will follow these steps:
1. Initialize the register with all zeros when the reset signal is high.
2. On the rising edge of the clock, check if the reset signal is high. If it is, reset the register to zero.
3. If the reset signal is low, calculate the feedback by XORing the most significant bit (MSB) and the second most significant bit (second MSB) of the current state, then invert the result.
4. Shift the bits in the register to the left and insert the new feedback value at the least significant bit (LSB).
5. Use a 4-bit vector to represent the current state of the LFSR and assign it to the output port.
