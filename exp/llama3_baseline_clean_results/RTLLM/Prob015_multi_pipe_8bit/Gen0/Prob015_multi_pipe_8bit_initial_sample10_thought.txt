The design will utilize a 3-stage pipeline architecture: 
- Stage 1: Input Control and Input Registers 
- Stage 2: Partial Product Generation and Partial Sum Calculation 
- Stage 3: Final Product Calculation and Output Assignment
Each stage is separated by registers to store intermediate results, which are updated on the positive edge of the clock signal.
For the input control, we use a register to sample the input enable signal.
The input registers store the input multiplicand and multiplier when the input enable signal is active.
The partial product generation stage uses bitwise operations between the multiplicand and the individual bits of the multiplier.
The partial sum calculation stage adds up the partial products using a set of registers.
The final product calculation stage sums up all the partial sums to obtain the final product.
The output assignment stage assigns the output product value based on the output enable signal.
