The design will utilize a pipelined architecture to improve performance. It consists of several key components: 
1. Input Control: This part controls the multiplication operation based on the input enable signal, mul_en_in. 
2. Input Registers: These store the input multiplicand and multiplier.
3. Partial Product Generation: This involves generating partial products by performing bitwise operations between the multiplicand and the individual bits of the multiplier.
4. Partial Sum Calculation: This calculates the partial sums by adding the partial products.
5. Final Product Calculation: This sums up all the partial sums to obtain the final product.
6. Output Assignment: This assigns the output product value based on the output enable signal and the value in the final product register.
