To implement the unsigned 8-bit multiplier using a pipelined architecture, we will design a module named multi_pipe_8bit. The module will have a clock signal (clk), an active-low reset signal (rst_n), an input enable signal (mul_en_in), and provide an output enable signal (mul_en_out) along with the product output (mul_out) of size 16 bits.

The design will involve several stages: input control, input registers, partial product generation, partial sum calculation, and final product calculation. 

We will utilize registers to store the input multiplicand and multiplier, and wires to store the partial products. The partial sums will be calculated using a set of registers, and the final product will be obtained by summing up all the partial sums.

The output product value will be assigned based on the output enable signal and the value in the final product register.
