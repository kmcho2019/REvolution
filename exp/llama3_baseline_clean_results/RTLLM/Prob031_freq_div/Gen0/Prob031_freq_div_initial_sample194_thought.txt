To implement the frequency divider module `freq_div`, we need to create three counters to divide the input clock frequency and generate the desired output clock frequencies. 
We will use three separate counters, one for each output clock frequency. 
The counters will be reset when the reset signal `RST` is active.

For `CLK_10`, we will use a counter `cnt_10` that increments on every positive edge of `CLK_in` and toggles `CLK_10` when it reaches a value of 4. 
Similarly, for `CLK_1`, we will use a counter `cnt_100` that increments on every positive edge of `CLK_in` and toggles `CLK_1` when it reaches a value of 49.
