The frequency divider module, freq_div, will be implemented with three counters to divide the input clock frequency and generate the desired output clock frequencies. 
The counters will be used to keep track of the number of clock cycles required to generate each output clock frequency. 
For the 50MHz clock, the counter will simply toggle the output clock on every positive edge of the input clock. 
For the 10MHz clock, a counter will be used to count up to 4 (10MHz = 100MHz / 10 = 100MHz / 2 * 2 * 5, so divide the 50MHz signal by 5), and then the output clock will be toggled. 
For the 1MHz clock, a counter will be used to count up to 49 (1MHz = 100MHz / 100 = 100MHz / 2 * 50, so divide the 50MHz signal by 50), and then the output clock will be toggled. 
If the reset signal is active, all the counters and output clocks will be reset to their initial values.
