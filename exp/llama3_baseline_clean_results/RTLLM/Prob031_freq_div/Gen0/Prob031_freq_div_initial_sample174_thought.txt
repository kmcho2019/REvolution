To implement the frequency divider module, we need to design three separate clock dividers within a single module. 
The module will have an input clock (CLK_in) and a reset signal (RST). 
It will generate three output clocks: CLK_50, CLK_10, and CLK_1. 
We will use counters to achieve the required division factors of 2, 10, and 100 for the respective output clocks.
The reset signal will be used to initialize the clocks and counters when it is active.
