To design the frequency divider module 'freq_div', we will implement the required logic using three counters to divide the input clock frequency. 
The input clock signal CLK_in and reset signal RST will be used to generate three output clock signals: CLK_50, CLK_10, and CLK_1. 
The generation of these output clocks will be based on the given conditions and will be implemented using counters cnt_10 and cnt_100.
We will use always blocks to describe the behavior of the module.
