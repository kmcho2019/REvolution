To implement a frequency divider, we need to use counters to keep track of the number of clock cycles and then toggle the output clock signals accordingly. 
For the 50MHz clock, we simply need to toggle the signal on every positive edge of the input clock.
For the 10MHz clock, we need to toggle the signal every 10 cycles of the input clock, which means we need a counter that counts up to 9 (since the counter starts at 0).
For the 1MHz clock, we need to toggle the signal every 100 cycles of the input clock, which means we need a counter that counts up to 99.
We will use three counters: one for each of the output clock frequencies. 
When the reset signal is active, we reset all the counters and output clock signals to their initial values.
