To implement the frequency divider, we'll create a Verilog module named freq_div that takes in a 100MHz clock signal (CLK_in) and a reset signal (RST). The module will generate three output clock signals: CLK_50, CLK_10, and CLK_1, which are the input clock frequency divided by 2, 10, and 100, respectively. We'll use counters to achieve the desired frequency divisions. The counters will be reset when the reset signal is active. We'll also toggle the output clock signals based on the counter values.
