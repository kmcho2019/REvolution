To implement the frequency divider module freq_div, we will utilize three counters to divide the input clock frequency. 
For CLK_50, we will toggle the signal on every positive edge of the input clock. 
For CLK_10 and CLK_1, we will use counters cnt_10 and cnt_100 to keep track of the number of input clock cycles and toggle the corresponding clock signals when the counters reach their respective thresholds.
The reset signal RST will be used to reset all the counters and output clock signals when it is active.
This approach ensures that the output clock frequencies are accurately divided from the input clock frequency.
