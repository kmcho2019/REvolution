To implement the frequency divider module, we will use three counters to divide the input clock frequency. 
The module will have an input clock signal CLK_in and a reset signal RST. 
The outputs will be three clock signals: CLK_50, CLK_10, and CLK_1, which are the input clock frequency divided by 2, 10, and 100, respectively. 
We will use always blocks to describe the behavior of the module. 
For CLK_50 generation, we will use a simple toggle logic on every positive edge of CLK_in or RST. 
For CLK_10 and CLK_1 generation, we will use counters to keep track of the number of cycles and toggle the output when the counter reaches the desired value.
