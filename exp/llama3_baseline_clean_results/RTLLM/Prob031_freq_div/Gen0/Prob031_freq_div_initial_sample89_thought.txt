To design the frequency divider module `freq_div`, we will use three separate counters to generate the desired output frequencies. 
The first counter will be used to generate the 50MHz clock signal by simply inverting the current value of `CLK_50` on every positive edge of `CLK_in`. 
The second counter `cnt_10` will be used to generate the 10MHz clock signal by toggling `CLK_10` when the counter reaches a value of 4, effectively dividing the input clock frequency by 10. 
The third counter `cnt_100` will be used to generate the 1MHz clock signal by toggling `CLK_1` when the counter reaches a value of 49, effectively dividing the input clock frequency by 100. 
All counters and output signals will be reset to 0 when the `RST` signal is active.
