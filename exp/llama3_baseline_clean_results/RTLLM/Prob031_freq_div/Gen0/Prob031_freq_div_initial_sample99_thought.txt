To implement the frequency divider module named 'freq_div', we will utilize a Verilog module with the specified input and output ports. The module will contain three counters to divide the input clock frequency, generating output clock signals at 50MHz, 10MHz, and 1MHz. 
For CLK_50 generation, we simply toggle its value on every positive edge of CLK_in. 
For CLK_10 and CLK_1 generation, we use counters cnt_10 and cnt_100 respectively, to keep track of the number of CLK_in cycles. 
When the counters reach the desired values (4 for cnt_10 and 49 for cnt_100), the corresponding output clock signal is toggled, and the counter is reset to 0. 
The reset signal RST is used to reset all output clock signals and counters to their initial values.
