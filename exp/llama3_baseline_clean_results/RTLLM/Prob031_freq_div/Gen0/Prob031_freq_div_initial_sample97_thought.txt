The frequency divider module 'freq_div' will use three counters to divide the input clock frequency. For CLK_50 generation, we will use a simple toggle logic. For CLK_10 and CLK_1 generation, we will use counters 'cnt_10' and 'cnt_100' respectively. The counters will be incremented on every positive edge of the input clock 'CLK_in'. When the counters reach the specified values, the corresponding output clocks will be toggled. The module will also have a reset functionality to set the output clocks to 0 and reset the counters when the 'RST' signal is active.
