To implement the frequency divider module 'freq_div', we will use three counters to divide the input clock frequency. 
The CLK_50 will be generated by simply toggling its value on every positive edge of the input clock.
For CLK_10, we will use a counter 'cnt_10' to keep track of the number of cycles. When the counter reaches 4, we toggle CLK_10 and reset the counter.
Similarly, for CLK_1, we will use a counter 'cnt_100' to keep track of the number of cycles. When the counter reaches 49, we toggle CLK_1 and reset the counter.
All the counters and clock signals will be reset when the RST signal is active.
