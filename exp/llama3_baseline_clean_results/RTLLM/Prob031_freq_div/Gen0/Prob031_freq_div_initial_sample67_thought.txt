To implement the frequency divider module 'freq_div', we need to design a module that takes an input clock signal 'CLK_in' and a reset signal 'RST', and generates three output clock signals 'CLK_50', 'CLK_10', and 'CLK_1' with frequencies divided by 2, 10, and 100 respectively. We will use three counters to achieve this: one for each output clock signal. The counters will be reset when the reset signal 'RST' is active. Otherwise, they will count the input clock edges and toggle the output clock signals accordingly.
