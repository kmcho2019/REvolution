To implement a frequency divider in Verilog, we need to create a module named freq_div that takes an input clock signal CLK_in and a reset signal RST, and generates three output clock signals: CLK_50, CLK_10, and CLK_1, with frequencies divided by 2, 10, and 100 respectively. We can use counters to achieve this division. For CLK_50, we simply toggle the signal on every positive edge of CLK_in. For CLK_10 and CLK_1, we use counters cnt_10 and cnt_100 to count the number of cycles and toggle the signals when the counters reach specific values (4 and 49 respectively).
