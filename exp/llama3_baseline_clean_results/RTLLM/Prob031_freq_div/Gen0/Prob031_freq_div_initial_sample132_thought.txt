The frequency divider module, freq_div, will be implemented with three separate counters to generate the desired output clock frequencies. 
The first counter will be used to generate the 50MHz clock signal by simply inverting the signal on every rising edge of the input clock, effectively dividing the frequency by 2. 
The second counter will be used to generate the 10MHz clock signal by counting up to 9 (since 100MHz / 10MHz = 10, and we're counting the number of input clock cycles between output clock cycles, which is one less than the division factor) and then inverting the signal. 
The third counter will be used to generate the 1MHz clock signal by counting up to 99 (since 100MHz / 1MHz = 100, and we're counting the number of input clock cycles between output clock cycles, which is one less than the division factor) and then inverting the signal. 
We will use Verilog's always @(posedge) block to capture the rising edge of the input clock and reset signal.
