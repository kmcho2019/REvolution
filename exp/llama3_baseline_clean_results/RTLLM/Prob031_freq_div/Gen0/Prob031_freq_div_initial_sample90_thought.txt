To implement the frequency divider, we will use a single always block to handle the positive edges of the input clock and the reset signal. We will use three counters: one for each output clock frequency. For CLK_50, we simply toggle its value on every positive edge of the input clock. For CLK_10 and CLK_1, we use counters to keep track of the number of input clock cycles and toggle their values when the counters reach the desired values.
