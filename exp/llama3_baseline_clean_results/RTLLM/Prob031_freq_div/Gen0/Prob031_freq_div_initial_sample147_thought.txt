To implement the frequency divider, we will create a Verilog module named freq_div with input ports CLK_in and RST, and output ports CLK_50, CLK_10, and CLK_1. We will use three counters to divide the input clock frequency. For CLK_50, we will simply toggle its value on every positive edge of CLK_in. For CLK_10 and CLK_1, we will use counters cnt_10 and cnt_100 to keep track of the number of cycles and toggle the output when the counter reaches the desired value. We will also implement the reset functionality to set the output clocks and counters to their initial values when RST is active.
