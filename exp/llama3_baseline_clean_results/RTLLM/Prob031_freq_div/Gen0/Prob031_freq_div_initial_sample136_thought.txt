To implement a frequency divider, we need to design a module that can divide the input clock frequency into three different frequencies: 50MHz, 10MHz, and 1MHz. The module will use three counters to achieve this. The first counter will be used to divide the clock frequency by 2 to get 50MHz. The second counter will divide the clock frequency by 10 to get 10MHz. The third counter will divide the clock frequency by 100 to get 1MHz. We will use a reset signal to reset the counters and the output clocks. On every positive edge of the input clock or reset, if the reset is active, all the output clocks will be set to 0, and the counters will be reset to 0. Otherwise, the counters will be incremented or the output clocks will be toggled based on the counter values.
