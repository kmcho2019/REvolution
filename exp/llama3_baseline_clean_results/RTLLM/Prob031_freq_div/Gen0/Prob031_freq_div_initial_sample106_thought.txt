To implement the frequency divider, we will use a single always block in Verilog to generate the three output clock signals (CLK_50, CLK_10, CLK_1) based on the input clock signal (CLK_in) and the reset signal (RST). We will use three counters (cnt_2, cnt_10, cnt_100) to keep track of the number of input clock cycles and generate the output clock signals accordingly. 
The always block will check for the positive edge of the input clock signal or the active reset signal. 
For CLK_50 generation, we simply invert the current value of CLK_50. 
For CLK_10 generation, we use a counter (cnt_10) that increments every clock cycle. When the counter reaches a value of 9 (not 4 as stated in the problem since we need to divide by 10), we invert the current value of CLK_10 and reset the counter to 0. 
For CLK_1 generation, we use a counter (cnt_100) that increments every clock cycle. When the counter reaches a value of 99 (not 49 as stated in the problem since we need to divide by 100), we invert the current value of CLK_1 and reset the counter to 0.
