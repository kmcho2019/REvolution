To implement the frequency divider module 'freq_div', we will use three counters to divide the input clock frequency. 
We'll have three separate counter modules for generating the 50MHz, 10MHz, and 1MHz clock signals. 
For the 50MHz signal, we can simply toggle the output on every positive edge of the input clock.
For the 10MHz and 1MHz signals, we will use counters to count up to a certain value and then toggle the output.
The counters will be reset when the reset signal 'RST' is active.
We will use non-blocking assignments to avoid race conditions in the always block.
