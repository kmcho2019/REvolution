To design the frequency divider module, we need to create a Verilog module named freq_div with input ports CLK_in and RST, and output ports CLK_50, CLK_10, and CLK_1. The module should use counters to divide the input clock frequency. For CLK_50, we can simply toggle its value on every positive edge of CLK_in. For CLK_10, we need a counter cnt_10 that increments on every positive edge of CLK_in and resets when it reaches 9 (because 100MHz / 10MHz = 10, so we divide by 10, and we need to count 5 positive and 5 negative edges, but since we are only checking on positive edges, we will use 10 as our divisor but it should be 5 for a full cycle). For CLK_1, we need a counter cnt_100 that increments on every positive edge of CLK_in and resets when it reaches 99 (because 100MHz / 1MHz = 100, so we divide by 100). When each counter reaches its threshold, we toggle the corresponding clock signal. We should also handle the reset logic to ensure all clocks are set to 0 and counters are reset when RST is active.
