To implement the frequency divider, we need to design a module 'freq_div' that takes in a 100MHz clock signal 'CLK_in' and a reset signal 'RST'. The module will generate three output clock signals: 'CLK_50' (50MHz), 'CLK_10' (10MHz), and 'CLK_1' (1MHz). We will use three counters to divide the input clock frequency accordingly. The counters will be reset when the reset signal 'RST' is active. We will use always blocks to handle the edge detection and counter operations.
