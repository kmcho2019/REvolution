The module freq_div will utilize three separate counters to generate the desired output frequencies from the input clock signal. 
The first counter will be used to generate the 50MHz clock signal by toggling its value every clock cycle. 
The second counter will generate the 10MHz clock signal by toggling its value every 10 clock cycles. 
The third counter will generate the 1MHz clock signal by toggling its value every 100 clock cycles. 
In each case, the counter will be reset to zero when the reset signal is active.
We'll use always blocks in Verilog to describe the desired behavior of each counter and output clock signal.
