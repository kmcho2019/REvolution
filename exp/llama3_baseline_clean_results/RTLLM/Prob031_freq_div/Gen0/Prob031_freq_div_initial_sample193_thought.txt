The freq_div module will utilize a reset signal to initialize all output clocks and counters. We'll create a separate counter for each output clock (CLK_50, CLK_10, CLK_1) to divide the input clock frequency accordingly. The counters will be used to determine when to toggle the output clocks. Specifically, the counters cnt_10 and cnt_100 will be used to generate the CLK_10 and CLK_1 signals, respectively, by comparing their values to the desired division factors.
