To implement a frequency divider that generates output clock signals of 50MHz, 10MHz, and 1MHz from an input clock signal of 100MHz, we can utilize counters to divide the input clock frequency. The module will have three counters: one for each output clock frequency. The counters will be updated on every positive edge of the input clock signal or reset. The output clock signals will be toggled when their respective counters reach specific values. For the 50MHz clock, we simply toggle the signal on every positive edge of the input clock. For the 10MHz clock, we use a counter that resets when it reaches 4, and for the 1MHz clock, we use a counter that resets when it reaches 49.
