The frequency divider module, freq_div, takes an input clock signal CLK_in and a reset signal RST. It generates three output clock signals: CLK_50, CLK_10, and CLK_1, with frequencies of 50MHz, 10MHz, and 1MHz, respectively. This is achieved by using counters to divide the input clock frequency. The counters are reset when the RST signal is active. 
The module uses three counters: 
- A simple toggle for CLK_50 
- A 5-bit counter (0-4) for CLK_10 
- A 6-bit counter (0-49) for CLK_1 
The counters are implemented using if-else statements within a single always block, with the positive edge of the input clock or reset signal as the sensitivity list.
