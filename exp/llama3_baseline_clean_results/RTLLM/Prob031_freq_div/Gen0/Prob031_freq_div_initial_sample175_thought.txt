To implement the frequency divider, we will use three counters to divide the input clock frequency. The module will have four ports: CLK_in for the input clock signal, RST for the reset signal, and three output ports (CLK_50, CLK_10, CLK_1) for the divided clock frequencies. We will use a separate counter for each output frequency. The counters will be incremented on every positive edge of the input clock, and when a counter reaches its target value, the corresponding output clock will be toggled and the counter will be reset. The reset signal will reset all counters and output clocks.
