To implement the frequency divider module freq_div, we need to design a circuit that takes the input clock signal CLK_in and produces three output clock signals: CLK_50, CLK_10, and CLK_1. 
We can use counters to divide the input clock frequency. 
For CLK_50, we can simply toggle the signal on every positive edge of CLK_in, effectively dividing the frequency by 2. 
For CLK_10 and CLK_1, we use counters cnt_10 and cnt_100 respectively, to divide the frequency by 10 and 100. 
When the counter reaches the desired value (4 for cnt_10 and 49 for cnt_100), we toggle the corresponding output signal and reset the counter. 
We also need to include a reset signal RST to reset all output signals and counters when it is active.
