To implement the frequency divider, we can use three counters to divide the input clock frequency. 
For the 50MHz clock generation, we simply need to toggle the output clock on every positive edge of the input clock. 
For the 10MHz clock generation, we need to count up to 4 before toggling the output clock. 
For the 1MHz clock generation, we need to count up to 49 before toggling the output clock. 
In all cases, if the reset signal is active, the output clocks and counters should be reset.
