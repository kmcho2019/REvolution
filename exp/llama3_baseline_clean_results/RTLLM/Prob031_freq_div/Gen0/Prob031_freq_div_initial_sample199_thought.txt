To implement the frequency divider module `freq_div`, we'll use three counters to divide the input clock frequency of 100MHz to generate output clock signals of 50MHz, 10MHz, and 1MHz. We will utilize the rising edge of the input clock `CLK_in` and the reset signal `RST` to update the counters and the output clock signals accordingly. 
The output clock signal `CLK_50` will be toggled on every rising edge of `CLK_in`, effectively dividing the input clock frequency by 2. 
The output clock signal `CLK_10` will be toggled every 5 rising edges of `CLK_in` (100MHz / 10MHz = 10, but since we are toggling, it's 10 / 2 = 5), effectively dividing the input clock frequency by 10. 
The output clock signal `CLK_1` will be toggled every 50 rising edges of `CLK_in` (100MHz / 1MHz = 100, but since we are toggling, it's 100 / 2 = 50), effectively dividing the input clock frequency by 100.
We will also include a reset mechanism to set the output clock signals to 0 and reset the counters when `RST` is active.
