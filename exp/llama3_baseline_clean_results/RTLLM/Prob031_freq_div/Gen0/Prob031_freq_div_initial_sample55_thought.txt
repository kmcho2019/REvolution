To implement the frequency divider module 'freq_div', we need to design a digital circuit that takes a 100MHz input clock signal and generates three output clock signals with frequencies of 50MHz, 10MHz, and 1MHz. This can be achieved by using three counters to divide the input clock frequency. For each output clock, we will use a counter to keep track of the number of input clock cycles and toggle the output clock signal accordingly. The counters will be reset when the reset signal 'RST' is active.
