To implement the frequency divider, we can use a single module named freq_div with the specified input and output ports. 
We will use three counters to divide the input clock frequency. 
The module will have three separate logic blocks for generating the 50MHz, 10MHz, and 1MHz clock signals.
For CLK_50, we can simply toggle its value on every positive edge of CLK_in, as dividing the frequency by 2 is equivalent to inverting the signal every other clock cycle.
For CLK_10 and CLK_1, we will use counters cnt_10 and cnt_100 to keep track of the number of clock cycles. 
When the counter reaches the specified value (4 for 10MHz and 49 for 1MHz, since 100/10=10 and 100/1=100, and the counter starts at 0, 
it will invert the corresponding clock signal and reset the counter.
We will also include a reset logic that sets all clock signals to 0 and resets the counters when the RST signal is active.
