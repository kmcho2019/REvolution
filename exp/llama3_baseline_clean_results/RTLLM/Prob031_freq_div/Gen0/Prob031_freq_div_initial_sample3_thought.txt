The frequency divider module, freq_div, takes an input clock signal, CLK_in, and a reset signal, RST, to generate three output clock signals: CLK_50, CLK_10, and CLK_1, with frequencies of 50MHz, 10MHz, and 1MHz respectively. This is achieved by using three counters to divide the input clock frequency. 
CLK_50 is generated by toggling its value on every positive edge of CLK_in. 
CLK_10 is generated by toggling its value every 5th positive edge of CLK_in (since 100/10 = 10 and 10/2 = 5). 
CLK_1 is generated by toggling its value every 50th positive edge of CLK_in (since 100/1 = 100 and 100/2 = 50). 
We will implement these counters and clock generation logic using Verilog HDL.
