To implement the frequency divider, we will create a Verilog module named freq_div. This module will take in an input clock signal CLK_in and a reset signal RST. It will then generate three output clock signals: CLK_50, CLK_10, and CLK_1, each with frequencies divided by 2, 10, and 100 respectively.

We will use counters to divide the input clock frequency. For CLK_50, we will simply toggle the signal on every positive edge of CLK_in. For CLK_10, we will use a counter cnt_10 that increments on every positive edge of CLK_in, and when it reaches 4, we will toggle CLK_10 and reset cnt_10. For CLK_1, we will use a counter cnt_100 that increments on every positive edge of CLK_in, and when it reaches 49, we will toggle CLK_1 and reset cnt_100.

We will also handle the reset condition, where if RST is active, all output clocks will be set to 0, and all counters will be reset to 0.
