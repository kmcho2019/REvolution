To implement the frequency divider module `freq_div`, we need to use three counters to divide the input clock frequency. 
For CLK_50, we can simply toggle its value on every positive edge of CLK_in.
For CLK_10, we need a counter `cnt_10` that increments on every positive edge of CLK_in and resets to 0 when it reaches 4, at which point we toggle CLK_10.
For CLK_1, we need a counter `cnt_100` that increments on every positive edge of CLK_in and resets to 0 when it reaches 49, at which point we toggle CLK_1.
We also need to consider the reset signal RST, which should reset all the counters and output signals to 0 when active.
