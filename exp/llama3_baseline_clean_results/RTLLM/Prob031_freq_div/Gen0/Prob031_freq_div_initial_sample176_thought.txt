To implement the frequency divider, we need to create a module named `freq_div` with input ports `CLK_in` and `RST`, and output ports `CLK_50`, `CLK_10`, and `CLK_1`. The module will use three counters to divide the input clock frequency. 
For `CLK_50`, it will toggle its value on every positive edge of `CLK_in` or `RST` when `RST` is inactive. 
For `CLK_10` and `CLK_1`, counters `cnt_10` and `cnt_100` will be used to divide the frequency by 10 and 100, respectively. When the counters reach their target values (4 for `cnt_10` and 49 for `cnt_100`), the corresponding output clock signals will be toggled.
We will use always blocks to handle the sequential logic and assign the values to the output ports.
