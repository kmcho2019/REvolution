To implement the frequency divider module 'freq_div', we need to create three counters to divide the input clock frequency. The counters will be used to generate the output clock signals CLK_50, CLK_10, and CLK_1. 
- For CLK_50, a simple toggle counter is used, which inverts its current value on every positive edge of CLK_in. 
- For CLK_10, a counter 'cnt_10' is used, which increments on every positive edge of CLK_in. When 'cnt_10' reaches 4, CLK_10 is toggled and 'cnt_10' is reset to 0.
- For CLK_1, a counter 'cnt_100' is used, which increments on every positive edge of CLK_in. When 'cnt_100' reaches 49, CLK_1 is toggled and 'cnt_100' is reset to 0.
The reset signal 'RST' is used to reset all counters and output clock signals to their initial states.
