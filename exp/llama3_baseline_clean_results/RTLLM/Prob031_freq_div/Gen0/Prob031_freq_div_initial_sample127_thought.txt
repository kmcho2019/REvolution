To implement the frequency divider, we will use a single module named `freq_div` that takes the input clock signal `CLK_in` and reset signal `RST` as inputs, and generates three output clock signals `CLK_50`, `CLK_10`, and `CLK_1` with frequencies divided by 2, 10, and 100 respectively. We will use three counters to keep track of the number of input clock cycles for each output clock signal. On every positive edge of `CLK_in` or `RST`, we will check if `RST` is active and reset the counters and output clock signals accordingly. Otherwise, we will increment the counters and toggle the output clock signals when the counters reach the desired values.
