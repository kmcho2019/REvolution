To implement the frequency divider module `freq_div`, we need to create three counters to divide the input clock frequency. We will use a simple counter for each output clock signal. The counter for `CLK_50` will simply toggle its value on every positive edge of the input clock. The counters for `CLK_10` and `CLK_1` will increment on every positive edge of the input clock and reset when they reach their respective threshold values (4 for `CLK_10` and 49 for `CLK_1`), toggling their output clock signals at that point. 
We will also include an asynchronous reset to set the output clock signals to 0 and reset the counters when the `RST` signal is active.
