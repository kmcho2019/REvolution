To implement the frequency divider module 'freq_div', we need to design a Verilog module that takes an input clock signal 'CLK_in' and a reset signal 'RST', and generates three output clock signals 'CLK_50', 'CLK_10', and 'CLK_1' with frequencies divided by 2, 10, and 100 respectively. The module will use counters to keep track of the clock cycles and toggle the output clocks at the desired frequencies. We will use always blocks to handle the sequential logic and edge detection for the reset and clock signals.
