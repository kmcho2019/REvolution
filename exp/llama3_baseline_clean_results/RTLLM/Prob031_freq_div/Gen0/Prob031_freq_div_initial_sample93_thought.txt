To implement the frequency divider module 'freq_div', we need to use three counters to divide the input clock frequency. We will use the 'always' block in Verilog to handle the edge detection and the counter logic. For each output clock signal (CLK_50, CLK_10, CLK_1), we will use a separate counter (none, cnt_10, cnt_100) to keep track of when to toggle the output. The counters will be reset when the reset signal RST is active.
