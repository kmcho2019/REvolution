To implement the frequency divider module, we can use three counters to divide the input clock frequency. 
For CLK_50 generation, we simply toggle the value of CLK_50 on every positive edge of CLK_in.
For CLK_10 generation, we use a counter cnt_10 to count the number of cycles of CLK_in and toggle the value of CLK_10 when cnt_10 reaches 4.
For CLK_1 generation, we use another counter cnt_100 to count the number of cycles of CLK_in and toggle the value of CLK_1 when cnt_100 reaches 49.
We also need to handle the reset condition to set the output clocks to 0 and reset the counters when RST is active.
