We can use three counters to achieve this. The first counter will be used to generate the 50MHz clock signal by toggling its value on every positive edge of the input clock. The second counter will be used to generate the 10MHz clock signal by toggling its value every 10th positive edge of the input clock. The third counter will be used to generate the 1MHz clock signal by toggling its value every 100th positive edge of the input clock. We also need to consider the reset signal, which should reset all the counters and clock signals to their initial values.
