To implement the frequency divider, we need to create a module named 'freq_div' with input ports 'CLK_in' and 'RST', and output ports 'CLK_50', 'CLK_10', and 'CLK_1'. 
Inside the module, we will use three counters to divide the input clock frequency. 
For 'CLK_50', we simply need to toggle its value on every positive edge of 'CLK_in'. 
For 'CLK_10' and 'CLK_1', we will use counters 'cnt_10' and 'cnt_100' to keep track of the clock cycles and toggle the output clocks when the counters reach the desired values. 
We will also include a reset mechanism to set all output clocks to 0 and reset the counters when 'RST' is active.
