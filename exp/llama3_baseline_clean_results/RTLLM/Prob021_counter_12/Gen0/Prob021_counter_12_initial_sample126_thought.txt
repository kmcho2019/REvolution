To implement the counter_12 module, we will use a 4-bit output register (out) to store the current count value. The counting process will be controlled by the input signal valid_count. On each clock cycle, if valid_count is 1, the counter will check its current value and either wrap around to 0 if it has reached the maximum count (4'd11) or increment the count. If valid_count is 0, the counter will hold its current value. The reset signal (rst_n) will asynchronously reset the counter to 0 when it is active (low).
