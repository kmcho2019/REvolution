The counter_12 module will be designed as a synchronous counter with an enable signal (valid_count) to control the counting process. The counter will reset to 0 when the reset signal (rst_n) is active low. The counting process will be handled by an always block that checks the current state of the valid_count signal and the reset signal. If the reset signal is active, the counter resets to 0. If the valid_count signal is high, the counter increments on each clock cycle, and if it reaches the maximum count value (4'd11), it wraps around to 0.
