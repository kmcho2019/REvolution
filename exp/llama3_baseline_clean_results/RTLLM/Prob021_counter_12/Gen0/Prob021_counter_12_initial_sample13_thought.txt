To design the counter_12 module, we will use a 4-bit register to store the current count value. The counter will be reset to 0 when the reset signal (rst_n) is active low. On each clock cycle, if the valid_count signal is high, the counter will check if it has reached the maximum count value (4'd11). If it has, the counter will wrap around to 0; otherwise, it will increment by 1. If the valid_count signal is low, the counter will pause, and the current count value will remain unchanged.
