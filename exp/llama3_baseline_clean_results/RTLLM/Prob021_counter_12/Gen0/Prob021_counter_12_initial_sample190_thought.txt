The counter_12 module will be designed as a synchronous sequential circuit with a reset signal (rst_n), a clock signal (clk), and a control signal (valid_count). It will use a 4-bit output register (out) to store the current count value. The counter will increment on each clock cycle when valid_count is 1, and it will reset to 0 when the reset signal is active. The counting will pause when valid_count is 0. The counter will wrap around to 0 when it reaches the maximum count value (4'd11).
