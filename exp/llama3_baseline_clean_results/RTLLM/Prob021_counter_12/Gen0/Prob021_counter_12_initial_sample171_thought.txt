- Use an always block to handle the counting process on the positive edge of the clock signal (clk).
- Within the always block, check if the reset signal (rst_n) is active. If it is, reset the output register (out) to 0.
- If the reset signal is not active, check if the valid_count signal is 1. If it is, increment the output register (out) by 1.
- Before incrementing, check if the current count value (out) is equal to 4'd11. If it is, reset the output register (out) to 0 to wrap around.
