The counter_12 module can be implemented using a simple finite state machine with an output register (out) that stores the current count value. The counting process is controlled by the valid_count signal, and the counter resets when the reset signal (rst_n) is active. We will use a always_ff block to describe the sequential logic for the counter. The if-else statement inside the always_ff block will handle the reset and counting logic. When the reset signal is active, the counter resets to 0. When the valid_count signal is 1, the counter increments, and if it reaches the maximum count value (4'd11), it wraps around to 0.
