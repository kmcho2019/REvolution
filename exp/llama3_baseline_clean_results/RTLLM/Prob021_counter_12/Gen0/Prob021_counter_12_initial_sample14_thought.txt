The counter_12 module will be designed using a sequential logic approach. It will have an output register (out) to store the current count value. The counter will reset to 0 when the reset signal (rst_n) is active low. When the valid_count signal is high, the counter will increment on each clock cycle until it reaches the maximum count value (4'd11), at which point it will wrap around and reset to 0. If the valid_count signal is low, the counter will pause, and the output register will remain unchanged.
