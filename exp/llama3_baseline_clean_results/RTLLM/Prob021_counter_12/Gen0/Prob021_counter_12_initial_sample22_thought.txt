To implement the counter_12 module, we will use a 4-bit output register (out) to store the current count value. The counter will be controlled by the valid_count signal, which enables the counting when set to 1. When the reset signal (rst_n) is active low (!rst_n), the counter will be reset to 0. On each clock cycle, if valid_count is 1, the counter will check if it has reached the maximum count value (4'd11). If it has, the counter will wrap around to 0; otherwise, it will increment by 1. If valid_count is 0, the counter will pause, and the output register (out) will remain unchanged.
