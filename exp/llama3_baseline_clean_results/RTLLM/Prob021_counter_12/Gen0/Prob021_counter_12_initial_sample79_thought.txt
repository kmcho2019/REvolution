To implement the counter_12 module, we need to design a 4-bit counter that can be controlled by the valid_count signal. The counter should reset to 0 when the reset signal (rst_n) is active low. When the valid_count signal is active (1), the counter should increment on each clock cycle until it reaches the maximum count value (4'd11), at which point it should wrap around to 0. If the valid_count signal is inactive (0), the counter should pause and hold its current value. This can be achieved using a combination of conditional statements and a 4-bit output register (out) in Verilog.
