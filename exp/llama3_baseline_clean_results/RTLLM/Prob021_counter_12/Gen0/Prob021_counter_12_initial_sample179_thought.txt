To implement the counter_12 module, we need to follow these steps:
1. Create a 4-bit output register (out) to store the count value.
2. Use the reset signal (rst_n) to reset the counter to 0 when it is active.
3. Use the valid_count signal to control the counting process. If valid_count is 1, the counter increments on each clock cycle.
4. Check if the current count value has reached the maximum count value (4'd11). If it has, reset the counter to 0.
5. If valid_count is 0, the counter stops, and the output register remains unchanged.
We will use an always block to implement the above logic and handle the synchronous reset and the counting process.
