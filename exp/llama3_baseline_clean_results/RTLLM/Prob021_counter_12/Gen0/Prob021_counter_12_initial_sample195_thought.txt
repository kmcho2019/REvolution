The counter_12 module is designed to count from 4'b0000 to 4'd11 with a controllable input signal valid_count. The counter should reset to 0 when the reset signal (rst_n) is active low. The counter will increment on each clock cycle when valid_count is high and remain paused when valid_count is low. 
We can use a 4-bit reg to hold the count value and an if-else statement inside an always block to implement the desired behavior. The always block will be sensitive to the posedge of the clock signal (clk) to ensure that the counter only changes on rising clock edges.
Inside the always block, we first check if the reset signal is active low. If so, we reset the counter to 0. Otherwise, we check the valid_count signal. If valid_count is high, we check if the current count is equal to the maximum count (4'd11). If it is, we reset the counter to 0. Otherwise, we increment the counter by 1.
If valid_count is low, the counter remains unchanged.
