To implement the counter_12 module, we need to use a 4-bit output register (out) to store the current count value. The counter will be designed to reset to 0 when the reset signal (rst_n) is active low. On each clock cycle, if the valid_count signal is active high, the counter will check its current value and either wrap around to 0 if it reaches the maximum count value (4'd11) or increment by 1. The counter will remain paused if the valid_count signal is 0. We will use a always block with a non-blocking assignment to update the output register (out) on each clock cycle.
