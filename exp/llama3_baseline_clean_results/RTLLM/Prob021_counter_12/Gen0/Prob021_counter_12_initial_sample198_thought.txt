The counter_12 module will be designed using a sequential always block that is sensitive to the positive edge of the clock signal (clk) and the reset signal (rst_n). The counter will have an internal register to store the current count value. If the reset signal is active, the internal register will be reset to 0. If the valid_count signal is active, the counter will increment on each clock cycle until it reaches the maximum count value (4'd11), at which point it will wrap around and reset to 0. If the valid_count signal is inactive, the counter will pause and the current count value will remain unchanged.
