The counter_12 module will be designed as a synchronous reset, edge-triggered counter. It will have an output register 'out' to hold the current count value. The counter will be implemented using a always block that is sensitive to the clock signal 'clk' and the reset signal 'rst_n'. When the reset signal 'rst_n' is low, the counter will reset to 0. When the 'valid_count' signal is high, the counter will increment on each rising edge of the clock signal 'clk'. If the current count value equals the maximum count value (4'd11), the counter will wrap around to 0.
