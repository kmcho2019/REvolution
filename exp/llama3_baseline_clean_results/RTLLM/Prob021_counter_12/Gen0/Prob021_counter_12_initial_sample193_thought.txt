The counter_12 module will be designed with an always block that checks for the reset condition and valid_count signal on every clock cycle. Inside the always block, we will first check if the reset signal is active. If it is, we will reset the counter to 0. Then, we will check if the valid_count signal is active. If it is, we will check the current count value and either wrap around to 0 if it's at the maximum count or increment it by 1. If the valid_count signal is not active, the counter will remain unchanged.
