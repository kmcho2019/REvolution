To implement the counter_12 module, we need to follow these steps:
1. Initialize the output register (out) with a value of 4'b0000 when the reset signal (rst_n) is active low.
2. On each positive edge of the clock signal (clk), check the value of the valid_count signal.
3. If valid_count is 1, check the current count value (out) and compare it to the maximum count value (4'd11).
4. If out equals 4'd11, wrap the counter around by assigning 4'b0000 to the output register (out).
5. Otherwise, increment the output register (out) by 1.
6. If valid_count is 0, the counter should pause and the output register (out) should remain unchanged.
We will implement this logic using Verilog's always block and if-else statements to handle the different conditions.
