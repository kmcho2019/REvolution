1. Check if the reset signal (rst_n) is active. If it is, reset the counter to 0. 
2. If the valid_count signal is 1, increment the counter. 
3. Check if the counter has reached its maximum value (4'd11). If it has, wrap the counter around to 0. 
4. If the valid_count signal is 0, do not change the counter value.
