To design the accu module, we can use a finite state machine (FSM) that keeps track of the number of valid data inputs received. The FSM will have two main states: an idle state and an accumulate state. In the idle state, the module waits for the valid_in signal to be set to 1, indicating that a new sequence of data is starting. Once in the accumulate state, the module will accumulate four valid data inputs and then output the sum. We will use a counter to keep track of the number of valid data inputs received. The data_out will be calculated by adding the four valid data_in values together. The valid_out signal will be set to 1 for one cycle when the data_out outputs the accumulated sum.
