To solve this problem, we'll design a Verilog module named 'accu' that accumulates 4 valid input data values and outputs their sum. The module will have a counter to keep track of the number of valid data inputs received. When the counter reaches 4, the module will output the accumulated sum and set the valid_out signal to 1 for one cycle. We will use a register to store the accumulated sum and another register to store the output data. The module will be reset by the active-low reset signal rst_n.
