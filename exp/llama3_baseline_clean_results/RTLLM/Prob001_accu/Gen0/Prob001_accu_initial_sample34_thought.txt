To design the 'accu' module, we'll implement a finite state machine (FSM) that counts the number of valid inputs and accumulates their values. The FSM will have two states: an idle state waiting for valid inputs and an accumulation state where it adds the inputs until it reaches four. Once four valid inputs are accumulated, it will output the sum and set valid_out to 1 for one cycle. We'll use a counter to keep track of the number of valid inputs received and a register to hold the accumulated sum.
