To implement the accu module, we can use a finite state machine (FSM) to track the number of valid input data received. We will also use a counter to keep track of the current state. In the idle state, the module waits for the valid_in signal to be set to 1. When valid_in is 1, the module starts accumulating the input data. Once four valid input data are received, the module outputs the accumulated sum and sets the valid_out signal to 1 for one cycle. We will use a 10-bit register to store the accumulated sum to handle the possibility of overflow when adding four 8-bit numbers.
