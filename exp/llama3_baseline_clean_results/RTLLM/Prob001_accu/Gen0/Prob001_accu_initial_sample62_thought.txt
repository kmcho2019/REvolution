To implement the accu module, we will use a finite state machine (FSM) with two states: idle and accumulating. When the module is in the idle state, it waits for the valid_in signal to be asserted. Once valid_in is asserted, the module transitions to the accumulating state and starts counting the number of valid input data. The module accumulates the input data and outputs the accumulated sum when four valid input data have been received. The valid_out signal is asserted for one cycle when the output data is valid. We will use a counter to keep track of the number of valid input data and a register to store the accumulated sum.
