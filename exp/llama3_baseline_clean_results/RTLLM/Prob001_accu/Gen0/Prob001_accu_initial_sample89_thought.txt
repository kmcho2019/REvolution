To implement the accu module, we can utilize a finite state machine (FSM) to track the number of valid input data received and accumulate the sum. The FSM will have two states: IDLE and ACCUMULATING. In the IDLE state, the module waits for the valid_in signal to be set to 1. Once valid_in is set, the module transitions to the ACCUMULATING state and starts accumulating the input data. The module will remain in the ACCUMULATING state until four valid input data have been received, at which point it will output the accumulated sum and set valid_out to 1 for one cycle. We will use a counter to keep track of the number of valid input data received and a register to store the accumulated sum.
