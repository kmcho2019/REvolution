To implement the accu module, we can utilize a finite state machine (FSM) with two states: idle and accumulate. The idle state waits for the valid_in signal to be asserted, indicating the start of data accumulation. Once in the accumulate state, the module counts the number of valid data inputs and accumulates their values. After four valid data inputs are received, the accumulated sum is outputted, and the valid_out signal is asserted for one clock cycle. The module then resets to the idle state. 
We will use a counter to keep track of the number of accumulated data and a register to store the accumulated sum.
