To design the accu module, we will utilize a finite state machine (FSM) to track the number of valid data inputs received and accumulate the data accordingly. The FSM will have two main states: an idle state and an accumulation state. When valid_in is asserted, the FSM will transition to the accumulation state and start counting the number of valid data inputs. Once four valid data inputs are received, the FSM will calculate the accumulated sum and assert the valid_out signal for one cycle. We will use a counter to keep track of the number of valid inputs and a register to store the accumulated sum. The data_out will be assigned the accumulated sum when valid_out is asserted.
