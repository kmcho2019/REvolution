To implement the accu module, we will use a Finite State Machine (FSM) to track the number of valid input data received and a register to accumulate the sum of these data. The module will have two states: an idle state and an accumulation state. In the idle state, the module waits for the valid_in signal to be asserted. Once the valid_in signal is asserted, the module transitions to the accumulation state and starts counting the number of valid input data received. When four valid input data are received, the module calculates the output data_out by adding these four values together and sets the valid_out signal to 1 for one cycle.
