To implement the accu module, we will utilize a Finite State Machine (FSM) that keeps track of the number of valid input data received and accumulates these values. The FSM will have two main states: an idle state waiting for the first valid input and an accumulation state where it counts and sums the valid inputs. Once four valid inputs are received, the FSM will output the accumulated sum and set valid_out to 1 for one clock cycle, then reset back to the idle state. We will use a counter to keep track of the number of valid inputs and a register to hold the accumulated sum.
