To design the `accu` module, we need to follow these steps: 
1. Initialize a counter to keep track of the number of valid input data received.
2. Use a register to accumulate the sum of the input data.
3. When the counter reaches 4, output the accumulated sum and set `valid_out` to 1.
4. Reset the counter and the accumulated sum after outputting the result.
5. Use an active-low reset signal `rst_n` to reset the module when it is 0.

We will use a 10-bit output to accommodate the sum of four 8-bit numbers, which can be up to 1020 (4 * 255).
