To solve this problem, we can implement a finite state machine (FSM) in Verilog that keeps track of the number of valid input data received and accumulates these data. The FSM should have two states: an idle state and an accumulating state. When valid_in is 1, the FSM transitions from the idle state to the accumulating state and starts counting the number of valid inputs and accumulating the input data. Once four valid inputs have been received, the FSM outputs the accumulated data and sets valid_out to 1 for one cycle. The FSM then resets to the idle state. We also need to handle the case where the module is reset, in which case all internal variables should be reset to their initial values.
