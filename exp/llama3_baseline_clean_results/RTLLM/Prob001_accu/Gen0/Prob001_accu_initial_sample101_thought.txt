To implement the accu module, we can use a counter to keep track of the number of valid input data received. When the counter reaches 4, we accumulate the 4 data values and set valid_out to 1 for one cycle. We will use a 10-bit register to store the accumulated sum to handle potential overflows since the maximum sum of 4 8-bit numbers is 1020 (255*4), which exceeds 8 bits.
