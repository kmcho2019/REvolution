To implement the serial input data accumulation module, we need to follow these steps:
- Initialize the accumulator and a counter to track the number of input data received.
- On every clock cycle, check if valid_in is set to 1, indicating new data is available.
- If valid_in is 1, accumulate the data_in into a running sum and increment the counter.
- Once four valid data inputs have been accumulated (counter reaches 4), output the accumulated sum through data_out and set valid_out to 1 for one cycle.
- After outputting the accumulated sum, reset the accumulator and the counter.
- If at any time rst_n goes low, reset all internal states (accumulator, counter, valid_out) to their initial values.
