To implement the accu module, we need to design a finite state machine (FSM) that accumulates four valid input data values and calculates the output data_out by adding these four values together. The FSM should have two states: an idle state where it waits for valid input data and an accumulation state where it accumulates the input data. The valid_out signal should be set to 1 when the data_out outputs the 4 received data accumulation results. We will use a counter to keep track of the number of valid input data received. 
When the counter reaches 4, we calculate the output data_out and set the valid_out signal to 1 for one cycle. 
The module should also have an active-low reset signal (rst_n) to reset the FSM and the counter when it is asserted low.
