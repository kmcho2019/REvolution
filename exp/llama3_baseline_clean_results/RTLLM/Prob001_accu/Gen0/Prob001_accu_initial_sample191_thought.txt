1. Initialize a counter to track the number of valid input data received.
2. Create a register to accumulate the sum of the input data.
3. When the counter reaches 4, output the accumulated sum and set `valid_out` to 1.
4. Reset the counter and accumulator after outputting the sum.
5. Use the `valid_in` signal to determine when to accumulate new input data.
6. Handle the reset condition by clearing the accumulator, counter, and `valid_out` when `rst_n` is 0.
