The fixed_point_subtractor module will be designed with parameterized values for Q (number of fractional bits) and N (total number of bits). It will take two N-bit fixed-point inputs, a and b, and produce an N-bit output, c, representing the result of the fixed-point subtraction. To handle same sign subtraction and different sign subtraction, the module will examine the signs of the input operands and perform the subtraction accordingly. The result will be stored in an internal register, res, before being assigned to the output port, c. The module will also handle the zero result case by explicitly setting the sign bit to 0.
