The barrel shifter will be implemented using a series of 2-to-1 multiplexers that select between the shifted input and the original input. Each stage of multiplexers performs the shift by 4, 2, or 1 position as controlled by `ctrl[2]`, `ctrl[1]`, and `ctrl[0]` respectively. We will define a submodule `mux2X1` to select between two input values based on the `sel` signal. The `barrel_shifter` module will then use these multiplexers in stages to perform the required shifting.
