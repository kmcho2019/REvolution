The barrel shifter module can be designed using a hierarchical approach where the shifting is done in multiple stages, each stage responsible for a specific shift amount. The 3-bit control signal `ctrl` will be used to select the shift amount at each stage. The shifting will be achieved using multiplexers (`mux2X1`) that select between the shifted input and the original input. We will define the `mux2X1` submodule first, and then use it in the `barrel_shifter` module to implement the shifting logic.
