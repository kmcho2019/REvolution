To implement the barrel shifter, we will design a hierarchical structure where each stage of shifting is achieved using 2-to-1 multiplexers. The control signals `ctrl[2]`, `ctrl[1]`, and `ctrl[0]` will determine which multiplexers are used in each stage, effectively shifting the input by the desired amount. We start by defining the `mux2X1` submodule, which will be used throughout the design to select between two input values based on a select signal. Then, we implement the main `barrel_shifter` module, which utilizes the `mux2X1` submodule in a series of stages to achieve the desired shifting effect.
