To implement the barrel shifter module, we first define the submodule `mux2X1` that selects between two input values based on the `sel` signal. Then, we use this submodule in the main `barrel_shifter` module to achieve the shifting in stages. The shifting is done by using the control signal `ctrl` to select between the original input and the shifted input at each stage. The output of each stage is then passed to the next stage for further shifting if required.
