To implement the barrel shifter, we need to design a series of 2-to-1 multiplexers (`mux2X1`) that can shift the input by 1, 2, or 4 positions based on the control signal `ctrl`. The control signal `ctrl[2:0]` will be used to determine the amount of shift at each stage. We'll first create the `mux2X1` submodule and then use it to implement the barrel shifter in the `barrel_shifter` module. The shifting will be achieved by selecting between the shifted input and the original input at each stage of multiplexers.
