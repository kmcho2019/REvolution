To implement the barrel shifter, we will break down the shifting process into stages. Each stage will utilize 2-to-1 multiplexers (`mux2X1`) to select between the original input and the shifted input. The control signal `ctrl` will dictate which multiplexers are used at each stage, effectively determining the amount of shift.

We will first define the `mux2X1` submodule, which takes two 8-bit inputs (`a` and `b`) and a select signal (`sel`). Based on `sel`, it outputs either `a` or `b`.

Then, we will implement the `barrel_shifter` module. It will have three stages of multiplexers. Each stage will correspond to a bit in the control signal (`ctrl[2]`, `ctrl[1]`, and `ctrl[0]`), and the multiplexers will be used to shift the input by 4, 2, or 1 positions, respectively.

In the first stage, if `ctrl[2]` is high, the input is shifted by 4 positions. This is achieved by connecting the original input and its 4-position shifted version to the multiplexers and selecting the shifted version when `ctrl[2]` is high.

The second stage shifts the result from the first stage by 2 positions if `ctrl[1]` is high. Similarly, the third stage shifts the result from the second stage by 1 position if `ctrl[0]` is high.

By cascading these stages, we can efficiently achieve any shift amount specified by the 3-bit control signal.
