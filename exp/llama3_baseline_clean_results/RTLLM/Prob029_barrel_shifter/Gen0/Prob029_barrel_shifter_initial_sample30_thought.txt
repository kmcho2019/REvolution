To design the barrel_shifter module, we will use a series of 2-to-1 multiplexers to shift the input bits based on the control signal. Each stage of the multiplexers will perform a shift by 4, 2, or 1 position, controlled by the corresponding bit of the control signal. The module will have three stages of multiplexers, each handling a different shift amount. The 2-to-1 multiplexer (mux2X1) submodule will be used to select between the shifted input and the original input at each stage.

- Stage 1: Shift by 4 positions if ctrl[2] is high.
- Stage 2: Shift by 2 positions if ctrl[1] is high.
- Stage 3: Shift by 1 position if ctrl[0] is high.

Each stage will use the mux2X1 submodule to select between the shifted input and the original input, based on the corresponding control bit.
