To implement the barrel shifter, we will design a hierarchical structure with multiple stages of 2-to-1 multiplexers (`mux2X1`) to achieve the shifting. Each stage will be responsible for shifting the input by a certain number of positions based on the control signal. The control signal `ctrl` will be used to select the appropriate shifted input at each stage, allowing the barrel shifter to efficiently rotate the bits of the input `in`. We will start by defining the `mux2X1` submodule, followed by the main `barrel_shifter` module.
