To design the barrel shifter, we can create a series of multiplexers that perform the shifting based on the control signals. The shifting is achieved in stages: the first stage shifts by 4 positions if `ctrl[2]` is high, the second stage shifts the result by 2 positions if `ctrl[1]` is high, and the third stage shifts the result by 1 position if `ctrl[0]` is high. We'll define the `mux2X1` submodule for 2-to-1 multiplexing. This submodule will select between two input values based on the `sel` signal, determining which bit is used in the shifted output at each stage.
