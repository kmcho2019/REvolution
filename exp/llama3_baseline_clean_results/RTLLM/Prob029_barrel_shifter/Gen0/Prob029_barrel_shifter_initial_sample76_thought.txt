We'll use a series of 2-to-1 multiplexers (`mux2X1`) to shift the input based on the control signal. The shifting will happen in stages, where each stage corresponds to a shift of 4, 2, or 1 positions, as determined by `ctrl[2]`, `ctrl[1]`, and `ctrl[0]`, respectively. Each stage's output will be passed to the next stage for further shifting if required. We'll use the `mux2X1` submodule to select between the shifted input and the original input at each stage.
