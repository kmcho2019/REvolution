To implement the barrel shifter, we will first define a submodule `mux2X1` that performs the 2-to-1 multiplexing operation based on a select signal. This multiplexer submodule will be used in each stage of the barrel shifter to select between the original input and the shifted input. We will then use these multiplexers in three stages, each corresponding to a different bit of the control signal (ctrl[2], ctrl[1], ctrl[0]), allowing for shifts by 4, 2, or 1 positions, respectively.
