The barrel shifter will be implemented as a series of 2-to-1 multiplexers that select between the shifted input and the original input. Each stage of multiplexers performs the shift, and the result is passed to the next stage for further shifting if required. We will create a submodule `mux2X1` to perform the selection between two input values based on the `sel` signal. Then, we will use this submodule in the main module `barrel_shifter` to create the shifting logic.
