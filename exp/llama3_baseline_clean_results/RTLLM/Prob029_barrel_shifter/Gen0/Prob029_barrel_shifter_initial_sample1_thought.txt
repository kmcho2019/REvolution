The barrel shifter module will be designed using a hierarchical approach, with the top module `barrel_shifter` containing three stages of shifting. Each stage uses a series of 2-to-1 multiplexers (`mux2X1`) to select between the shifted input and the original input. The control signal `ctrl` determines the amount of shift at each stage. 
We will use a separate module for the `mux2X1` to simplify the design and improve readability.
The shifting will be performed in stages, with each stage corresponding to a specific bit in the `ctrl` signal. The output of each stage will be the input to the next stage.
We will define the `mux2X1` module first and then use it in the `barrel_shifter` module to implement the barrel shifter.
The `mux2X1` module takes two 8-bit inputs (`a` and `b`) and a select signal (`sel`), and outputs an 8-bit result that is either `a` or `b` based on the value of `sel`.
