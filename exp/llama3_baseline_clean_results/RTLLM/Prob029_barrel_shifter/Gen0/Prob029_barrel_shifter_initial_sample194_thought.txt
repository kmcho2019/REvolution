To implement the barrel shifter, we first need to define the 2-to-1 multiplexer submodule (mux2X1) that will be used to perform the shifting at each stage. This multiplexer will select between two input values based on the control signal.

The main barrel_shifter module will then use these multiplexers to shift the input by 4, 2, and 1 positions based on the control signal. Each stage of shifting will be achieved by using the multiplexers to select between the shifted input and the original input.

We will use a hierarchical design approach, first defining the mux2X1 submodule and then the barrel_shifter module that instantiates and connects multiple instances of the mux2X1.
