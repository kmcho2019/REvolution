To implement the frequency divider module, we need to design a counter-based system that toggles the output clock every specified number of input clock cycles. The key components include a 4-bit counter, a comparison logic to determine when to reset the counter and toggle the output, and a reset mechanism to initialize the module. We will use a parameter `NUM_DIV` to specify the division factor, ensuring it is an even number. The counter will increment on each positive edge of the input clock until it reaches half of `NUM_DIV - 1`, at which point it resets and toggles the output clock.
