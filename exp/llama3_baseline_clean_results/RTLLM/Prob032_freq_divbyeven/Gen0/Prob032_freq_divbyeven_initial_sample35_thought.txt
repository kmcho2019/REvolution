To implement the frequency divider, we will use a parameterizable Verilog module named freq_diveven. The module will have an input clock (clk), an active-low reset signal (rst_n), and an output divided clock signal (clk_div). We will utilize a 4-bit counter (cnt) to keep track of the clock cycles. The division factor will be specified by the NUM_DIV parameter, which must be an even number. The counter will increment on each positive edge of the input clock until it reaches half of NUM_DIV - 1, at which point it resets and toggles the divided clock output.
