To implement the freq_diveven module, we need to design a counter-based frequency divider that can divide the input clock frequency by even numbers. The module should have an input clock (clk), an active-low reset signal (rst_n), and a divided clock output (clk_div). The division factor will be specified by the NUM_DIV parameter. The counter (cnt) will be used to track the number of clock cycles and will reset to zero when it reaches half of NUM_DIV - 1, effectively dividing the input clock frequency by NUM_DIV. The divided clock signal (clk_div) will be toggled every time the counter resets.
