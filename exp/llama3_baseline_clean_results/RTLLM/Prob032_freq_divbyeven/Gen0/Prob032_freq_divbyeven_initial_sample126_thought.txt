The freq_diveven module will be designed using a parameterized Verilog module to allow flexibility in specifying the division factor (NUM_DIV). The module will contain a counter (cnt) and a divided clock output (clk_div). The counter will be reset to zero when the active-low reset signal (rst_n) is low. On each positive edge of the input clock (clk), the counter will be incremented until it reaches half of NUM_DIV - 1, at which point it will reset to zero and toggle the divided clock output (clk_div). This effectively divides the input clock frequency by the even number specified by NUM_DIV.
