To implement the frequency divider module, we need to follow these steps: 
1. Define the module with the given input and output ports.
2. Declare the `NUM_DIV` parameter to specify the division factor.
3. Initialize a 4-bit counter (`cnt`) to track the number of clock cycles.
4. Implement the logic for the counter and the divided clock signal (`clk_div`) based on the given conditions.
5. Use the counter to generate the divided clock signal by toggling its output every specified number of input clock cycles.
