To design the frequency divider module `freq_diveven`, we will utilize a 4-bit counter (`cnt`) to track the number of input clock cycles. The `NUM_DIV` parameter will determine the division factor, which must be an even number. We will implement the logic such that on each positive edge of the input clock (`clk`), the counter increments until it reaches half of `NUM_DIV - 1`, then resets and toggles the divided clock output (`clk_div`). This will effectively divide the input clock frequency by the specified even number. We will also include an active-low reset signal (`rst_n`) to initialize the module.
