To design the frequency divider module (freq_diveven), we will implement a counter-based approach. The module will take an input clock (clk) and an active-low reset signal (rst_n), and produce a divided clock output (clk_div). The division factor will be determined by the parameter NUM_DIV, which must be an even number. The counter (cnt) will be a 4-bit register that increments on each positive edge of the input clock until it reaches the specified limit, then resets to zero and toggles the divided clock output. This effectively divides the input clock frequency by the specified even number.
