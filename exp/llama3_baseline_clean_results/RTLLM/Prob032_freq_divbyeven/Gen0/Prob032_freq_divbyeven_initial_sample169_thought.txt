To implement the frequency divider, we will create a Verilog module named `freq_diveven` that takes an input clock signal (`clk`) and an active-low reset signal (`rst_n`), and generates a divided clock output signal (`clk_div`). The division factor will be determined by the `NUM_DIV` parameter, which must be an even number. We will use a 4-bit counter (`cnt`) to track the number of clock cycles. On each positive edge of the input clock, we will increment the counter if it is less than half of `NUM_DIV - 1`, and reset the counter and toggle the divided clock output when the counter reaches the specified limit.
