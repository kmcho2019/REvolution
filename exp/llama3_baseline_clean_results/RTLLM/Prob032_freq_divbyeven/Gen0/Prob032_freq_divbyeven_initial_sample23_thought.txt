To implement the frequency divider module, we'll define a parameter `NUM_DIV` to specify the division factor. Since the division factor must be even, we'll ensure that `NUM_DIV` is a power of 2 or any even number that can be represented by a 4-bit or larger counter. We'll use a 4-bit counter (`cnt`) to track the number of clock cycles. On each positive edge of the input clock (`clk`), we'll check the counter value and either increment it or reset it and toggle the divided clock output (`clk_div`). The reset signal (`rst_n`) will be used to initialize the counter and the divided clock output.
