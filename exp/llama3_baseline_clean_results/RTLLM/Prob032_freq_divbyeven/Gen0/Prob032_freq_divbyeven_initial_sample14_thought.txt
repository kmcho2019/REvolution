To implement the frequency divider, we will use a parameterizable module named freq_diveven with input ports clk and rst_n, and output port clk_div. The module will utilize a 4-bit counter (cnt) to track the number of clock cycles. The division factor will be specified by the parameter NUM_DIV, which must be an even number. The counter will be incremented on each positive edge of the input clock until it reaches half of NUM_DIV - 1, at which point it resets and toggles the divided clock output (clk_div). This effectively divides the frequency of the input clock by the even number specified by NUM_DIV.
