To implement the frequency divider module `freq_diveven`, we'll define a parameter `NUM_DIV` to specify the division factor. The module will include a 4-bit counter (`cnt`) to track the number of clock cycles. On each positive edge of the input clock (`clk`), the counter will increment until it reaches half of `NUM_DIV - 1`, then reset to zero and toggle the divided clock output (`clk_div`). The active-low reset signal (`rst_n`) will initialize the counter and divided clock signal when low.
