To implement the frequency divider module (freq_diveven), we need to consider the following:
1. Define the module with input ports for the clock signal (clk) and the active-low reset signal (rst_n), and an output port for the divided clock signal (clk_div).
2. Include a parameter (NUM_DIV) to specify the division factor, which must be an even number.
3. Use a counter (cnt) that increments on each positive edge of the input clock (clk) until it reaches the specified limit, which is half of NUM_DIV - 1.
4. Once the counter reaches the limit, reset it to zero and toggle the divided clock output signal (clk_div) to achieve the frequency division.
5. Handle the active-low reset signal (rst_n) to initialize the counter and the divided clock signal when the reset is asserted (low).
We will use a 4-bit register for the counter (cnt) and implement the logic using always blocks for both the counter and the divided clock signal.
