To design the frequency divider module `freq_diveven`, we need to implement a counter that increments on each positive edge of the input clock and toggles the divided clock output when it reaches the specified limit. The `NUM_DIV` parameter determines the division factor, which should be an even number. We'll use a 4-bit register `cnt` to count the clock cycles. The divided clock signal `clk_div` will be toggled when the counter reaches half of `NUM_DIV - 1`.
