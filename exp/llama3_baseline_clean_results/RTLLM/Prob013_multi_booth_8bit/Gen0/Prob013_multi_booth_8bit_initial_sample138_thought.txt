The Booth multiplier is a well-known algorithm for fast multiplication. In the context of an 8-bit Radix-4 Booth multiplier, we need to perform the following steps:
1.  Extend the inputs (a and b) to 16 bits, where 'a' is sign-extended to 16 bits and 'b' is zero-extended to 16 bits.
2.  Initialize the product register (p) to zero.
3.  Use a counter (ctr) to keep track of the current bit position.
4.  Iterate over each bit of the multiplier (b) and perform the Booth multiplication operation, shifting the multiplicand (a) one bit to the left at each iteration.
5.  If the current bit of the multiplier is 1, add the multiplicand to the product.
6.  Once all 16 bits have been processed, set the ready signal (rdy) to indicate the completion of the multiplication process.

To implement the 8-bit Radix-4 Booth multiplier, we need to write a Verilog module that takes the inputs (clk, reset, a, b) and produces the outputs (p, rdy) according to the described operation.
