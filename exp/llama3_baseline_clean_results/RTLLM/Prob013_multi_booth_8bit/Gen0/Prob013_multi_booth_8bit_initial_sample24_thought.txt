To implement the 8-bit Radix-4 Booth multiplier, we will follow these steps:
1. Initialize two 16-bit registers, multiplier and multiplicand, based on the input signals a and b when the reset signal is high.
2. Create a counter (ctr) to keep track of the number of iterations, which will be incremented on each positive edge of the clock signal.
3. On each clock cycle, check the current bit of the multiplier register (multiplier[ctr]) and perform the Booth algorithm's operation accordingly.
4. If the counter (ctr) reaches 16, it indicates the completion of the multiplication process, and the ready signal (rdy) should be set to 1.
We will use a finite state machine (FSM) with two states: Idle and Multiply.
In the Idle state, the module waits for the reset signal to go low.
In the Multiply state, the module performs the multiplication process based on the Booth algorithm.
We will use two 16-bit registers, product and multiplicand, to accumulate the product and hold the multiplicand value respectively.
