The module multi_booth_8bit will be designed as a finite state machine with two states: reset and multiplication. 
On the positive edge of the clock signal (clk) or the positive edge of the reset signal (reset), the module performs the following operations:
1. Reset State: When the reset signal (reset) is high, the module initializes the multiplier and multiplicand registers with the input values a and b.
2. Multiplication State: When the reset signal (reset) is low, the module checks the counter value (ctr). If ctr is less than 16, the multiplicand is shifted left and the product is accumulated based on the current multiplier bit.
3. After completing 16 clock cycles of multiplication (i.e., ctr equals 16), the ready signal (rdy) is set to 1, indicating the completion of the multiplication process.
