To implement the 8-bit Radix-4 Booth multiplier, we will use a finite state machine (FSM) to control the multiplication process. The FSM will have two states: idle and multiply. In the idle state, the module waits for the reset signal to be deasserted and the counter to be zero. In the multiply state, the module performs the multiplication process by shifting the multiplicand, checking the current bit of the multiplier, and accumulating the product. We will use a 5-bit counter to keep track of the number of iterations. The ready signal will be set to 1 when the counter reaches 16.
