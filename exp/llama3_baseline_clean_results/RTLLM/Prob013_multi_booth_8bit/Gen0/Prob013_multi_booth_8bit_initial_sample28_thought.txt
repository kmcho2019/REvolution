To implement the 8-bit Radix-4 Booth multiplier, we need to follow these steps:
1. Initialize two 16-bit registers, multiplier and multiplicand, with the input values a and b when the reset signal is high.
2. On the positive edge of the clock signal, check if the counter (ctr) is less than 16.
3. If the counter is less than 16, left-shift the multiplicand register by 1 bit to simulate the Booth algorithm's shifting operation.
4. If the current bit of the multiplier register is 1, accumulate the value of the multiplicand register in the product register (p).
5. Increment the counter by 1.
6. Once the counter reaches 16, set the ready signal (rdy) to 1 to indicate the completion of the multiplication process.
We will use a finite state machine (FSM) to control the flow of the multiplication process.
