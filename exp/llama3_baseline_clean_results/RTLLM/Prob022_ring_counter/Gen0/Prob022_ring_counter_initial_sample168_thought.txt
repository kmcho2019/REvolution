The 1 shifts to the next bit with each clock pulse, wrapping around to the least significant bit (LSB) after reaching the most significant bit (MSB). When the reset signal is high, the counter is initialized to its starting state. This behavior can be achieved using a combination of sequential logic (to handle the state transitions) and combinational logic (for the reset condition). We will use a reg type to hold the current state of the counter and update it on the rising edge of the clock signal. The output of the counter will be a 1-hot encoded vector, where only one bit is set high at any time.
