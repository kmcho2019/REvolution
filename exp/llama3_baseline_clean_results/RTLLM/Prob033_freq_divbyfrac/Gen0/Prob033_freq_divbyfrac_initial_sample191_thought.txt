To achieve fractional frequency division, we need to create a module that can divide the input clock frequency by 3.5. This is done by dividing the clock into two uneven periods, one with 4 source clock cycles and another with 3 source clock cycles, and then phase-shifting these periods to generate a smooth fractional clock output. We use a counter to track the clock cycles and generate the intermediate divided clock signals. The double-edge clocking technique is used to achieve half-integer division. The final fractional divided clock output is generated by logically OR-ing the two intermediate clocks.
