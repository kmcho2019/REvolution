To implement the frequency divider that divides the input clock frequency by fractional values, we will use the double-edge clocking technique to achieve half-integer division. The module will count clock cycles and generate an intermediate divided clock signal. For 3.5x division, it will cycle through 7 clock cycles and produce two uneven clock periods. Then, phase-shifted versions of the divided clock will be generated and logically OR-ed to produce the final fractional divided clock output.

The Verilog implementation will include the following components:
- A counter to keep track of the clock cycles.
- A finite state machine to manage the generation of the uneven clock periods and phase-shifted clocks.
- A logical OR gate to combine the phase-shifted clocks.

The `freq_divbyfrac` module will be designed with input ports `clk` and `rst_n`, and an output port `clk_div`.
