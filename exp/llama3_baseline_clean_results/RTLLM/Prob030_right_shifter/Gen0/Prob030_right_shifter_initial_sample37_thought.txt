The right_shifter module will be designed as a synchronous sequential circuit, where the input signal d is right-shifted into an 8-bit register q on each rising edge of the clock signal clk. To achieve this, we will use a reg type to declare the register q and initialize it to 0. We will then use the always block to describe the sequential behavior, where the value of q is right-shifted by 1 bit and the most significant bit is assigned the value of the input signal d.
