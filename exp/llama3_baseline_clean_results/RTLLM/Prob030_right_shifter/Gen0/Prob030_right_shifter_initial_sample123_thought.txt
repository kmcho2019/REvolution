The right shifter module is designed to perform a right shift operation on an 8-bit register. The module takes a 1-bit input signal d and a clock signal clk. On each rising edge of the clock, the module shifts the contents of the register to the right by one bit and inserts the new input bit d into the most significant position of the register. This operation is achieved by using a non-blocking assignment to update the register value. The initial value of the register is set to 0 using the initial statement. 
The module can be implemented using a always block that is sensitive to the positive edge of the clock signal. Inside the always block, the value of the register q is right-shifted by 1 bit and the most significant bit is assigned the value of the input signal d. 
To ensure the output is correct, the module should also handle the initialization of the register when the module is powered on or reset.
