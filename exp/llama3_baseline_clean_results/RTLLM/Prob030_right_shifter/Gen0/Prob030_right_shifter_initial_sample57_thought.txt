To implement a right shifter in Verilog, we need to define a module named right_shifter with the specified input and output ports. The module will have an internal register q that is initialized to 0. On each rising edge of the clock, the module will shift the contents of q to the right by one bit and insert the new input bit d into the most significant position of the register. This can be achieved using a non-blocking assignment to q in a always block that is triggered by the positive edge of the clock signal.
