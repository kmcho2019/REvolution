To implement the right shifter, we'll use a Verilog module that includes an 8-bit register q. The module will have a clock input clk and a 1-bit input d. On each rising edge of the clock, the module will right-shift the register q by one bit and insert the new input bit d into the most significant position of the register. We will achieve this using a non-blocking assignment to update the register value synchronously with the clock. The most significant bit of the register will be directly assigned the value of the input signal d.
