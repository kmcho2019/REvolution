To implement the right shifter module in Verilog, we need to follow these steps: 
1. Define the module with the given name and ports.
2. Declare the q register and initialize it to 0.
3. Use the always block to capture the rising edge of the clock signal.
4. Inside the always block, right shift the q register by 1 bit and insert the new input bit d into the most significant position of the register.
However, in Verilog, we cannot directly assign a value to a part of a reg in a non-blocking assignment. 
So, we first right shift the q register and then assign the new input bit d to the most significant bit of the q register.
