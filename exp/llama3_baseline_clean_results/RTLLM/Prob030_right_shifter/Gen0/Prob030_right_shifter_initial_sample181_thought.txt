To design the right_shifter module, we need to follow these steps:
1. Define the module with input ports clk and d, and output port q.
2. Initialize an 8-bit register q to 0 using the initial statement.
3. On each rising edge of the clock, shift the contents of the q register to the right by one bit using the >> operator.
4. Insert the new input bit d into the most significant position of the register q.
We will use a procedural block (always @posedge) to describe the synchronous behavior of the module.
