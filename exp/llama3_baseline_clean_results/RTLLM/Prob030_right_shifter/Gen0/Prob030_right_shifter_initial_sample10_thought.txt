To implement the right shifter module, we first need to define the module and its ports. The module name will be right_shifter, with input ports clk and d, and output port q. We will use the initial statement to initialize the q register to 0. On each rising edge of the clock, we will shift the contents of the q register to the right by one bit using the >> operator and insert the new input bit d into the most significant position of the register. We can achieve this by using a non-blocking assignment to update the value of q and then assigning the value of d to the most significant bit of q.
