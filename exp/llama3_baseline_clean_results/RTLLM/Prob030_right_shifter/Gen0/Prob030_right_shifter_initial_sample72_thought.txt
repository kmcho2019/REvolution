The right_shifter module will be designed using a register q to store the current state of the shift operation. The module will have a synchronous reset to initialize the register q to 0. On each rising edge of the clock, the module will shift the contents of the q register to the right by one bit and insert the new input bit d into the most significant position of the register. This can be achieved by using the always block with the posedge of the clock signal. Inside the always block, we will first shift the register q to the right by one bit and then assign the most significant bit of the register q to the input signal d.
