To implement the right shifter module, we will use a register (q) to store the current state of the shift operation. On each rising edge of the clock, we will perform the right shift operation by shifting the current value of q to the right by one bit and inserting the new input bit (d) into the most significant position of the register. This will be achieved using a non-blocking assignment within a always block that is sensitive to the positive edge of the clock signal. The initial value of the q register will be set to 0.
