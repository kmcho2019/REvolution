The design idea is to create a right shifter module that shifts an 8-bit register to the right by one bit on each rising edge of the clock and inserts the new input bit into the most significant position of the register. This is achieved by using a reg [7:0] to store the current state of the shifter and using a always block to update the state on each clock edge. Inside the always block, we first assign the input bit to the most significant position of the register, and then shift the rest of the bits to the right.
