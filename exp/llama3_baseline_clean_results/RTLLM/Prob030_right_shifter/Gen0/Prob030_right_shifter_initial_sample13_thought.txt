The right shifter module should be designed as a sequential circuit, using a register to store the current state of the shift operation. The register q will be initialized to 0, and on each rising edge of the clock, the value of q will be right-shifted by one bit and the new input bit d will be inserted into the most significant position of the register. This can be achieved using the always block in Verilog, which will be sensitive to the positive edge of the clock signal. Inside the always block, we will use the non-blocking assignment operator (<=) to update the value of q.
