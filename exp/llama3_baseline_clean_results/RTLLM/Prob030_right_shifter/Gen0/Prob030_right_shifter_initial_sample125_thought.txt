The right_shifter module will be implemented as a sequential circuit with a clock signal, allowing it to operate synchronously. The q register will be initialized to 0 and will be updated on each rising edge of the clock. The update operation involves shifting the current value of q one bit to the right and then assigning the most significant bit of q the value of the input signal d. This will be achieved using a non-blocking assignment to q within a always block that is sensitive to the rising edge of the clock.
