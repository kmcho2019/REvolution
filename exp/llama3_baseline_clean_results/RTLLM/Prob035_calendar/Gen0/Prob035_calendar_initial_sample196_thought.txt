The perpetual calendar module will be designed using three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. Each always block will trigger on the positive edge of the clock signal or the positive edge of the reset signal, allowing for either the clock signal or the reset signal to update the values. The seconds value will be updated first, followed by the minutes value, and then the hours value. The reset signal will set all values to 0 when active. The seconds value will wrap around to 0 when it reaches 59, the minutes value will wrap around to 0 when it reaches 59 and the seconds value is 59, and the hours value will wrap around to 0 when it reaches 23 and both the minutes and seconds values are 59.
