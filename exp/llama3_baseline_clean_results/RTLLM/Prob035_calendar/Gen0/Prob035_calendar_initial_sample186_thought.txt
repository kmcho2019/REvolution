To implement a perpetual calendar module in Verilog, we need to design a module that takes a clock signal and a reset signal as inputs and outputs the current hours, minutes, and seconds. The module will use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. The seconds value will loop continuously from 0 to 59, and when it reaches 59, the minutes value will increment by 1. Similarly, when both the minutes and seconds values reach 59, the hours value will increment by 1, looping from 0 to 23. We will use non-blocking assignments to update the values of seconds, minutes, and hours to avoid race conditions.
