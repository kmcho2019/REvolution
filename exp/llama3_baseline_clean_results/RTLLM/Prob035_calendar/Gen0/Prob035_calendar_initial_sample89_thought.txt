To implement a perpetual calendar module in Verilog, we need to design a module that can keep track of time (Hours, Mins, Secs) and reset it when the RST signal is active high. The module should use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. Each always block should trigger on the positive edge of the clock signal or the positive edge of the reset signal. 
We will use non-blocking assignments to update the values of seconds, minutes, and hours.
