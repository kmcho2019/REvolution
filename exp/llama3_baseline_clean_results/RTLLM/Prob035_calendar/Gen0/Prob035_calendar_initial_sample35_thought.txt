To implement a perpetual calendar module in Verilog, we can use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. 
The first always block will handle the seconds value, the second always block will handle the minutes value, and the third always block will handle the hours value.
Each block will trigger on the positive edge of the clock signal or the positive edge of the reset signal.
We will use conditional statements to check the current values of seconds, minutes, and hours, and update them accordingly.
If the reset signal is active, we will set the current values to 0.
We will use non-blocking assignments (<=) to update the values of seconds, minutes, and hours.
