To design a perpetual calendar module, we need to implement three always blocks that update the values of seconds, minutes, and hours based on the clock signal and reset signal. The first always block will handle the seconds value, the second always block will handle the minutes value, and the third always block will handle the hours value. Each always block will check for the reset signal and update the corresponding value accordingly. 
We'll use the posedge of the clock signal to trigger the always blocks and update the values. If the reset signal is active, all values will be reset to 0. Otherwise, the values will be updated based on their current values and the conditions specified in the problem.
