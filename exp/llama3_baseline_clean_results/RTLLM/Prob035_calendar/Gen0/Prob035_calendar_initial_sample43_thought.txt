The perpetual calendar module can be implemented using three always blocks in Verilog. Each block will handle the update of seconds, minutes, and hours respectively. The module will have a clock input (CLK) and an active high reset signal (RST). The seconds, minutes, and hours will be updated based on the clock signal and reset signal. If the reset signal is active, all values will be set to 0. The seconds value will wrap around to 0 when it reaches 59, and the minutes value will increment by 1. Similarly, when the minutes value reaches 59 and the seconds value is 59, the hours value will increment by 1 and wrap around to 0 when it reaches 23.
