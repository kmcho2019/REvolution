To implement a perpetual calendar module in Verilog, we'll create a module named "calendar" with input ports for the clock signal (CLK) and an active high reset signal (RST), and output ports for the current hours, minutes, and seconds. The module will use three always blocks to update these time values based on the clock signal and reset signal. The seconds value will wrap around from 59 to 0, incrementing the minutes value when this happens. Similarly, the minutes value will wrap around from 59 to 0 when it reaches 59 and the seconds value wraps around, which in turn will increment the hours value. The hours value will wrap around from 23 to 0 when all three time values reach their maximum.
