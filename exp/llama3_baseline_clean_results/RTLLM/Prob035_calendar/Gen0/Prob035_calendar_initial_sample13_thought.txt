The perpetual calendar module is designed using three always blocks in Verilog. 
The first always block updates the seconds value based on the clock and reset signals.
The second always block updates the minutes value based on the seconds value and the clock and reset signals.
The third always block updates the hours value based on the minutes and seconds values, and the clock and reset signals.
The reset signal has priority over the clock signal, so when the reset signal is active, all values are reset to 0.
When the seconds value reaches 59, it wraps around to 0 and increments the minutes value.
When the minutes value reaches 59 and the seconds value is 59, it wraps around to 0 and increments the hours value.
When the hours value reaches 23, the minutes and seconds values are both 59, it wraps around to 0.
