To implement the perpetual calendar module, we'll use three always blocks in Verilog, each triggered by the positive edge of the clock signal or the positive edge of the reset signal. 
The first always block updates the seconds value (Secs), which wraps around to 0 when it reaches 59. 
The second always block updates the minutes value (Mins), which increments by 1 when the seconds value wraps around to 0 and resets to 0 when it reaches 59 and the seconds value is 59. 
The third always block updates the hours value (Hours), which increments by 1 when both minutes and seconds values wrap around to 0 and resets to 0 when it reaches 23 and both minutes and seconds values are 59.
