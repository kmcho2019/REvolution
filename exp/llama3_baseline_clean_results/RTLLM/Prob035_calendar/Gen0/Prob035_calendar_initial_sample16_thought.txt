To create a perpetual calendar module in Verilog, we need to design a module that can keep track of time in hours, minutes, and seconds. The module should have three output ports for hours, minutes, and seconds, and two input ports for the clock signal and the reset signal. The module should update the values of seconds, minutes, and hours based on the clock signal and reset signal. We will use three always blocks to achieve this. The first always block will update the seconds value, the second always block will update the minutes value, and the third always block will update the hours value. We will use if-else statements to check for the conditions and update the values accordingly.
