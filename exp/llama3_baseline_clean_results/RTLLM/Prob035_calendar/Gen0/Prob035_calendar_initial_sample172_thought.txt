The perpetual calendar module should update the seconds, minutes, and hours values based on the clock signal and reset signal. 
When the reset signal is active, all values should be reset to 0. 
The seconds value should loop from 0 to 59, and when it reaches 59, the minutes value should be incremented by 1.
The minutes value should also loop from 0 to 59, and when it reaches 59 and the seconds value is 59, the hours value should be incremented by 1.
The hours value should loop from 0 to 23, and when it reaches 23 and the minutes and seconds values are both 59, it should wrap around to 0.
We will use three always blocks to update these values based on the clock signal and reset signal.
