To design a perpetual calendar module in Verilog, we need to consider the requirements for the seconds, minutes, and hours counters. Each counter has specific wrap-around conditions and increments based on the values of the other counters. The module should respond to a clock signal (CLK) and a reset signal (RST), updating the counters accordingly. The counters should be implemented using always blocks that are sensitive to the positive edges of the clock and reset signals.

We will start by defining the module name, input ports, and output ports according to the problem statement. Then, we will implement the logic for each counter (seconds, minutes, and hours) in separate always blocks, ensuring that the counters update correctly based on the clock signal, reset signal, and the wrap-around conditions.

The seconds counter (Secs) will be incremented by 1 every clock cycle unless it reaches 59, at which point it wraps around to 0. The minutes counter (Mins) will be incremented by 1 when Secs reaches 59 and wraps around. Similarly, the hours counter (Hours) will increment when both Mins and Secs reach their maximum values (59) and wrap around.

We will use if-else statements within the always blocks to implement the logic for updating each counter based on the current values of the counters and the state of the reset signal.
