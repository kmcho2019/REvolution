The perpetual calendar module can be implemented using three always blocks in Verilog. The first always block will update the seconds value based on the clock signal and reset signal. The second always block will update the minutes value based on the clock signal, reset signal, and the current seconds value. The third always block will update the hours value based on the clock signal, reset signal, and the current minutes and seconds values. 
We use non-blocking assignments (<=) for all signal updates to avoid race conditions and ensure that the output values are updated correctly.
To handle the wrap-around for seconds, minutes, and hours, we use conditional statements to check their current values and update them accordingly.
