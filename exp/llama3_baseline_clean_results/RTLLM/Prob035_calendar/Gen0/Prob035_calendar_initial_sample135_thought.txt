The perpetual calendar module will utilize three always blocks to manage the seconds, minutes, and hours. 
The seconds will be incremented every clock cycle unless the reset signal is active, at which point it will be reset to 0. 
When the seconds value reaches 59, it will wrap around to 0 and trigger the minutes block. 
The minutes block will increment the minutes value by 1 when the seconds value wraps around, unless the reset signal is active. 
When the minutes value reaches 59 and the seconds value wraps around, it will trigger the hours block. 
The hours block will increment the hours value by 1 when the minutes and seconds values both wrap around, unless the reset signal is active. 
If the hours value reaches 23 and the minutes and seconds values both wrap around, it will wrap around to 0.
