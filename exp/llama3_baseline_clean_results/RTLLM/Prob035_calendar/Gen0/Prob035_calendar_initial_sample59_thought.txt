To implement a perpetual calendar module in Verilog, we can use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. The first always block updates the seconds value (Secs) by checking if the reset signal is active or if the seconds value has reached its maximum (59). The second always block updates the minutes value (Mins) by checking if the reset signal is active, if the minutes and seconds values are at their maximum, or if the seconds value has reached its maximum. The third always block updates the hours value (Hours) by checking if the reset signal is active, if the hours, minutes, and seconds values are at their maximum, or if the minutes and seconds values are at their maximum.
