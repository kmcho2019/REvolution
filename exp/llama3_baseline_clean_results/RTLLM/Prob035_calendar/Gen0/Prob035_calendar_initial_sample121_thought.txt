To design the perpetual calendar module in Verilog, we need to create a module that updates the seconds, minutes, and hours based on the clock signal and reset signal. The module will have three always blocks to handle the seconds, minutes, and hours values separately. The first always block will update the seconds value, the second always block will update the minutes value based on the seconds value, and the third always block will update the hours value based on the minutes and seconds values. The reset signal will be used to reset all the values to 0.
