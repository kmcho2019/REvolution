The perpetual calendar module will be implemented using three always blocks to handle the seconds, minutes, and hours. Each always block will be triggered on the positive edge of the clock signal or the positive edge of the reset signal. The seconds, minutes, and hours values will be updated based on the current values and the reset signal. The seconds and minutes will loop continuously from 0 to 59, and the hours will loop from 0 to 23. The reset signal will be used to reset the values to 0.
