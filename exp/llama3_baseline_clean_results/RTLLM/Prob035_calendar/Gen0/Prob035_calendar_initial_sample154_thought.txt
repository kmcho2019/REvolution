To implement the perpetual calendar module in Verilog, we will use three always blocks that trigger on the positive edge of the clock signal or the positive edge of the reset signal. The first block updates the seconds value based on the current seconds value and the reset signal. The second block updates the minutes value based on the current minutes and seconds values, as well as the reset signal. The third block updates the hours value based on the current hours, minutes, and seconds values, as well as the reset signal.
