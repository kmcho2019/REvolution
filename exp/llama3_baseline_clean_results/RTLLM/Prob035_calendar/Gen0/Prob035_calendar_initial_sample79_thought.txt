The perpetual calendar module can be implemented using three always blocks in Verilog, where each block handles the seconds, minutes, and hours values separately. The first always block handles the seconds value, which increments by 1 every clock cycle unless it reaches 59, at which point it wraps around to 0. The second always block handles the minutes value, which increments by 1 when the seconds value reaches 59, unless the minutes value itself reaches 59, at which point it also wraps around to 0. The third always block handles the hours value, which increments by 1 when both the minutes and seconds values reach 59, unless the hours value itself reaches 23, at which point it wraps around to 0.
