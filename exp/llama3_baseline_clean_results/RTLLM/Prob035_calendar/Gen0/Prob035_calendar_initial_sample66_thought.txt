To implement a perpetual calendar module in Verilog, we need to design three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. The first always block will handle the seconds value, incrementing it every clock cycle and wrapping it around to 0 when it reaches 59. The second always block will handle the minutes value, incrementing it every 60 clock cycles (when the seconds value wraps around) and wrapping it around to 0 when it reaches 59. The third always block will handle the hours value, incrementing it every 3600 clock cycles (when the minutes and seconds values wrap around) and wrapping it around to 0 when it reaches 23.
