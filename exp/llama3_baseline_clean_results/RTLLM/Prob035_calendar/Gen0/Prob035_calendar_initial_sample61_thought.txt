To implement the perpetual calendar module, we will use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. The seconds value will be incremented every clock cycle and will wrap around to 0 when it reaches 59. The minutes value will be incremented when the seconds value wraps around and will also wrap around to 0 when it reaches 59. The hours value will be incremented when both the minutes and seconds values wrap around and will wrap around to 0 when it reaches 23. The reset signal will reset all values to 0.
