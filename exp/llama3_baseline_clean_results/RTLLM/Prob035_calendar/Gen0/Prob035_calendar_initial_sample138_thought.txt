To design the perpetual calendar module, we need to consider the timing and conditional logic for updating the seconds, minutes, and hours values based on the clock and reset signals. 
The module should have three always blocks to update the seconds, minutes, and hours values separately. 
Each always block should check for the reset condition and update the respective value based on the current state of the clock and the previous values of seconds, minutes, and hours. 
The seconds value should wrap around from 59 to 0, and the minutes value should increment when the seconds value wraps around. 
Similarly, the hours value should wrap around from 23 to 0 when the minutes and seconds values are both at their maximum.
