To design a perpetual calendar module in Verilog, we will create a module named "calendar" with input ports for clock (CLK) and reset (RST), and output ports for hours, minutes, and seconds. The module will utilize three always blocks to update the time values based on the clock signal and reset signal. Each always block will handle the seconds, minutes, and hours respectively, ensuring proper wrapping around when the maximum value is reached for each unit of time.
