The calendar module is designed with three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. We use non-blocking assignments to update the values. We use 6-bit variables to represent hours, minutes, and seconds. We first reset the values when the reset signal is high, then we update the values based on their current values and the conditions provided. We use conditional statements (if-else) to handle different cases for updating the values.
