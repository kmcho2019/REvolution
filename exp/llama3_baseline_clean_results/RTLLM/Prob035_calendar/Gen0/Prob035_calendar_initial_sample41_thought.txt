The perpetual calendar module will be implemented using three always blocks in Verilog. The first always block will update the seconds value (Secs) based on the clock signal and reset signal. The second always block will update the minutes value (Mins) based on the seconds value and the clock signal. The third always block will update the hours value (Hours) based on the minutes and seconds values and the clock signal. The reset signal will be used to initialize all values to 0. The clock signal will be used to increment the values at each positive edge.
