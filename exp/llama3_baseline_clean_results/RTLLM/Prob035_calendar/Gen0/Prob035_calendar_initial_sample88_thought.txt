To implement the perpetual calendar module, we need to design three always blocks that trigger on the positive edge of the clock signal or the positive edge of the reset signal. The first always block updates the seconds value, the second always block updates the minutes value based on the seconds value, and the third always block updates the hours value based on the minutes and seconds values. We will use if-else statements to check the conditions for updating the values and to handle the wrap-around cases. The module will have three output ports: Hours, Mins, and Secs, which will represent the current hours, minutes, and seconds respectively.
