The perpetual calendar module will be implemented using three always blocks in Verilog. Each block will handle the seconds, minutes, and hours, respectively. The blocks will trigger on the positive edge of the clock signal or the positive edge of the reset signal. The seconds value will increment by 1 every clock cycle unless it reaches 59, at which point it will wrap around to 0 and increment the minutes value. Similarly, the minutes value will increment by 1 every time the seconds value wraps around, unless it reaches 59, at which point it will wrap around to 0 and increment the hours value. The hours value will increment by 1 every time the minutes and seconds values both wrap around, unless it reaches 23, at which point it will wrap around to 0.
