To implement the perpetual calendar module, we need to create a Verilog module named 'calendar' that takes two input ports, CLK and RST, and produces three output ports, Hours, Mins, and Secs. The module should use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. Each always block should check for the reset condition and handle the wrapping and incrementing of the seconds, minutes, and hours accordingly. We will use non-blocking assignments (<=) to update the output values to avoid race conditions.
