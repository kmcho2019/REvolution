To implement a perpetual calendar module in Verilog, we need to design a digital circuit that can count seconds, minutes, and hours. The counter for seconds and minutes should reset to 0 after reaching 59, while the hour counter should reset to 0 after reaching 23. The module should have a clock input (CLK) and an active-high reset signal (RST). The current values of hours, minutes, and seconds should be outputted as 6-bit signals. We will use three always blocks to handle the updates of seconds, minutes, and hours based on the clock and reset signals. The updates will be done on the positive edge of the clock signal.
