To implement the perpetual calendar module, we need to consider the reset and clock signals to update the seconds, minutes, and hours values accordingly. We will use three always blocks, each handling the seconds, minutes, and hours values based on the conditions provided. The seconds value will loop from 0 to 59, and when it reaches 59, the minutes value will be incremented. Similarly, when both seconds and minutes values reach 59, the hours value will be incremented. The hours value will loop from 0 to 23. If the reset signal is active, all values will be reset to 0.
