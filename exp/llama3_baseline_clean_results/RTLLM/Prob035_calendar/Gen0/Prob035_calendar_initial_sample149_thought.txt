To implement a perpetual calendar module in Verilog, we need to create a design that accurately represents the continuous flow of time, with hours, minutes, and seconds updating correctly based on the clock signal and reset signal. The module should have three outputs: Hours, Mins, and Secs, each representing the current hour, minute, and second, respectively. We will use three always blocks to update these values based on the clock signal and reset signal. Each block will check for the reset condition and handle the wrap-around of seconds, minutes, and hours as necessary.
