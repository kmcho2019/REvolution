The perpetual calendar module will be implemented using three always blocks in Verilog. Each block will handle the update of seconds, minutes, and hours, respectively. The update logic will be based on the clock signal and reset signal. If the reset signal is active, all values will be reset to 0. The seconds value will increment every clock cycle and wrap around to 0 when it reaches 59. The minutes value will increment when the seconds value wraps around and will also wrap around to 0 when it reaches 59. The hours value will increment when both minutes and seconds values wrap around and will wrap around to 0 when it reaches 23.
