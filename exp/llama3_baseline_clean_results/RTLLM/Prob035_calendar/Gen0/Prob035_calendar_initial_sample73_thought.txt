To implement the perpetual calendar module in Verilog, we need to design three always blocks that update the values of seconds, minutes, and hours based on the clock signal and reset signal. 
The first always block will handle the seconds value, incrementing it by 1 at each clock cycle and wrapping it around to 0 when it reaches 59. 
The second always block will handle the minutes value, incrementing it by 1 when the seconds value wraps around and wrapping it around to 0 when it reaches 59 and the seconds value also wraps around. 
The third always block will handle the hours value, incrementing it by 1 when the minutes and seconds values both wrap around and wrapping it around to 0 when it reaches 23 and the minutes and seconds values both wrap around.
We will also include a reset mechanism to set all values to 0 when the reset signal is active.
