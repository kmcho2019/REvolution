The perpetual calendar module will utilize three always blocks to manage the seconds, minutes, and hours values based on the clock signal and reset signal. Each always block will be triggered by the positive edge of the clock signal or the positive edge of the reset signal. The first block will handle the seconds value, the second block will handle the minutes value, and the third block will handle the hours value. The reset signal will be used to reset all values to 0. The seconds value will wrap around to 0 when it reaches 59, and it will also cause the minutes value to increment when it wraps around. Similarly, when both the minutes and seconds values are 59, the hours value will increment. The hours value will wrap around to 0 when it reaches 23 and both the minutes and seconds values are 59.
