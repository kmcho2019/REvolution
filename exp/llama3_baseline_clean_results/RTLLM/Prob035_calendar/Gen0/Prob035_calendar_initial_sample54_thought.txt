To implement the perpetual calendar module, we need to design three always blocks that update the seconds, minutes, and hours values based on the clock signal and reset signal. The first always block will handle the seconds value, the second always block will handle the minutes value, and the third always block will handle the hours value. Each always block will check the reset signal and update the corresponding value accordingly. The seconds and minutes values will wrap around to 0 after reaching 59, and the hours value will wrap around to 0 after reaching 23. The minutes and hours values will be incremented when the seconds value reaches 59 and the minutes value reaches 59, respectively.
