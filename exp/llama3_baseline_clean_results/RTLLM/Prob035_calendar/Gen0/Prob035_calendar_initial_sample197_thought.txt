The perpetual calendar module can be implemented using three always blocks in Verilog. Each block is responsible for updating the values of seconds, minutes, and hours based on the clock signal and reset signal. The seconds block increments the seconds value every clock cycle, wrapping around to 0 when it reaches 59. The minutes block increments the minutes value when the seconds value wraps around, and the hours block increments the hours value when both the minutes and seconds values wrap around. The reset signal is used to reset all values to 0 when active.
