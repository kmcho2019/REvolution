The perpetual calendar module is implemented using three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. The first always block handles the seconds value, the second always block handles the minutes value, and the third always block handles the hours value. Each block checks for the reset signal and updates the corresponding value accordingly. The values of seconds and minutes wrap around from 59 to 0, and the hours value wraps around from 23 to 0 when all three values reach their maximum.
