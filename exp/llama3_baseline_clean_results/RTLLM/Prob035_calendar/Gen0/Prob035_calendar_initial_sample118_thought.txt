To create a perpetual calendar module in Verilog, we will design a digital circuit that simulates a clock. The circuit will have three main components: hours, minutes, and seconds, each represented by a 6-bit binary number. The values of these components will be updated based on a clock signal and a reset signal. When the reset signal is active, all components will be reset to 0. Otherwise, the seconds value will increment every clock cycle, the minutes value will increment when the seconds value wraps around, and the hours value will increment when both the minutes and seconds values wrap around. We will use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal.
