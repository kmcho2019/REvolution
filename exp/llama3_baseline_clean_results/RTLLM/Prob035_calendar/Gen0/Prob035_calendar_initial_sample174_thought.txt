The perpetual calendar module can be implemented using three always blocks to update the values of seconds, minutes, and hours. 
Each always block should trigger on the positive edge of the clock signal or the positive edge of the reset signal, 
and update the corresponding value based on the current values of seconds, minutes, and hours, as well as the reset signal.
The seconds value should loop continuously from 0 to 59, the minutes value should loop continuously from 0 to 59, 
and the hours value should loop continuously from 0 to 23.
When the seconds value reaches 59, the minutes value should increment by 1 at the next cycle, 
and when the minutes and seconds values both reach 59, the hours value should increment by 1 at the next cycle.
The reset signal should reset all values to 0.
