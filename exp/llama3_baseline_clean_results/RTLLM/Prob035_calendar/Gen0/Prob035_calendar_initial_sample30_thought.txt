To implement the perpetual calendar module, we will use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. Each block will handle the wrapping around and incrementing of the respective time unit. The seconds value will be incremented by 1 on each positive edge of the clock signal, unless it has reached 59, in which case it will wrap around to 0. The minutes value will be incremented by 1 when the seconds value wraps around, unless the minutes value has also reached 59, in which case it will wrap around to 0. The hours value will be incremented by 1 when both the minutes and seconds values wrap around, unless the hours value has reached 23, in which case it will wrap around to 0. The reset signal will set all time units to 0 when it is active.
