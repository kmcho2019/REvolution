To implement a perpetual calendar module in Verilog, we can design three always blocks that trigger on the positive edge of the clock signal or the positive edge of the reset signal. 
The first always block will handle the seconds value (Secs), which loops continuously from 0 to 59. 
The second always block will handle the minutes value (Mins), which also loops continuously from 0 to 59 and increments when the seconds value wraps around. 
The third always block will handle the hours value (Hours), which counts from 0 to 23 and wraps around when it reaches its maximum value, with the minutes and seconds values also at their maximum.
We will use non-blocking assignments (<=) to update the values of seconds, minutes, and hours within these always blocks.
