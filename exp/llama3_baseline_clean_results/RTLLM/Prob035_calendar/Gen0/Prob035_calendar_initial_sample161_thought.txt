To implement the perpetual calendar module, we need to consider the continuous looping of seconds and minutes, as well as the hourly updates. 
The seconds value should loop from 0 to 59, and when it reaches 59, the minutes value should be incremented. 
Similarly, when both the seconds and minutes values reach 59, the hours value should be incremented. 
We will use three always blocks to handle these updates based on the clock signal and reset signal. 
Each block will check for the reset condition and update the corresponding value (seconds, minutes, or hours) accordingly.
