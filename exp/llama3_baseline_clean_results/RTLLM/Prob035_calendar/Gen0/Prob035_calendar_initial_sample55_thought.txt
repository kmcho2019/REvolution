The perpetual calendar module can be implemented using three always blocks in Verilog. The first always block will handle the seconds value, the second always block will handle the minutes value, and the third always block will handle the hours value. Each always block will check for the reset signal and update the corresponding value based on the clock signal. The seconds value will wrap around to 0 when it reaches 59, the minutes value will wrap around to 0 when it reaches 59 and the seconds value is 59, and the hours value will wrap around to 0 when it reaches 23 and the minutes and seconds values are both 59.
