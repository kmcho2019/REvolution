To design a perpetual calendar module in Verilog, we need to create a module that updates the values of seconds, minutes, and hours based on the clock signal and reset signal. The seconds value should loop continuously from 0 to 59, the minutes value should also loop from 0 to 59, and the hours value should loop from 0 to 23. When the seconds value reaches 59, the minutes value should increment by 1 at the next cycle, and when both minutes and seconds values are 59, the hours value should increment by 1 at the next cycle. We will use three always blocks to update the values of seconds, minutes, and hours.
