The perpetual calendar module can be designed using three always blocks in Verilog. Each always block is used to update the values of seconds, minutes, and hours based on the clock signal and reset signal. The blocks are triggered on the positive edge of the clock signal or the positive edge of the reset signal. This allows the module to reset the values when the reset signal is active and update the values based on the clock signal when the reset signal is inactive. The minutes and hours values are updated only when the seconds value reaches its maximum value, and the hours value is updated only when both the minutes and seconds values reach their maximum values.
