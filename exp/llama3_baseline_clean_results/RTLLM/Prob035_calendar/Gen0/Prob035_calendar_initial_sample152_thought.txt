To implement a perpetual calendar module in Verilog, we can design three always blocks that update the values of seconds, minutes, and hours based on the clock signal and reset signal. The first always block updates the seconds value, the second always block updates the minutes value based on the seconds value, and the third always block updates the hours value based on the minutes and seconds values. We use non-blocking assignments (<=) to update the values in the always blocks to avoid race conditions. We also use the posedge of the clock signal to trigger the updates, ensuring that the values are updated synchronously with the clock.
