To design the perpetual calendar module, we will create a digital clock system that updates the seconds, minutes, and hours based on the clock signal and reset signal. We will use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. The first always block will handle the seconds value, the second always block will handle the minutes value, and the third always block will handle the hours value. Each block will check for the reset signal and update the corresponding value accordingly. The seconds value will wrap around from 59 to 0, the minutes value will wrap around from 59 to 0 when the seconds value is 59, and the hours value will wrap around from 23 to 0 when the minutes and seconds values are both 59.
