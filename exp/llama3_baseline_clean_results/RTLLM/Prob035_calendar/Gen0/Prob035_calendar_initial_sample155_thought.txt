To implement a perpetual calendar module in Verilog, we will create a module named 'calendar' with input ports 'CLK' and 'RST', and output ports 'Hours', 'Mins', and 'Secs'. The module will use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal. We will use the posedge of the clock signal and the reset signal to trigger these blocks. Inside the blocks, we will implement the logic to increment and wrap around the values of seconds, minutes, and hours as per the problem requirements.
