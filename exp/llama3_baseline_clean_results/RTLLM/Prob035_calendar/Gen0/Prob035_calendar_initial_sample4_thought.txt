To implement the perpetual calendar module, we need to design a digital circuit that can keep track of seconds, minutes, and hours. The circuit should be able to reset the values of seconds, minutes, and hours to 0 when the reset signal is active. When the reset signal is inactive, the circuit should increment the seconds value by 1 on every clock cycle. When the seconds value reaches 59, it should wrap around to 0 and increment the minutes value by 1. Similarly, when the minutes value reaches 59 and the seconds value is 59, it should wrap around to 0 and increment the hours value by 1. The hours value should also wrap around to 0 when it reaches 24. We can use three always blocks to update the values of seconds, minutes, and hours based on the clock signal and reset signal.
