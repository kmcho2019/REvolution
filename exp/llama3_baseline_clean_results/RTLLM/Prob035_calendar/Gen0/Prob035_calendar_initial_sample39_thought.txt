The perpetual calendar module will be implemented with three always blocks in Verilog. Each block will handle the seconds, minutes, and hours values, respectively. The seconds value will be updated every clock cycle, wrapping around from 59 to 0. The minutes value will be updated when the seconds value wraps around, and the hours value will be updated when both the minutes and seconds values wrap around. The reset signal will be used to reset all values to 0.
