The module will use two registers, data_lock and data_out, to temporarily store the input data and the converted output data, respectively. A flag signal will be used to track whether the first valid data has been stored. On reset, the data_out register and the flag signal will be cleared. When the first valid data arrives, it will be stored in the data_lock register, and the flag will be set. The data_out register will be updated with the concatenated data on the next clock cycle.
