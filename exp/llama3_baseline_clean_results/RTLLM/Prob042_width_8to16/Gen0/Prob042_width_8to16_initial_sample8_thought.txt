Once the second data arrives, the module concatenates the stored first data with the newly arrived second data and generates the output. The output is generated in the next clock cycle after both input data have arrived.

The module should have a reset mechanism to clear the internal registers when the reset signal is active. The output validity signal (valid_out) should be asserted only when both input data have arrived and the output data is valid.
