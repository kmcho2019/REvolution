To implement the data width conversion circuit, we need to design a module that takes 8-bit input data and converts it to 16-bit output data. The module should have a flag to track whether the first 8-bit data has been received. When the first 8-bit data arrives, it should be stored in a temporary register. Once the second 8-bit data arrives, the module should concatenate the stored data with the new data and generate the 16-bit output. The output should be generated in the next clock cycle after the second data input. The module should also have a reset mechanism to clear the registers and flag when the reset signal is active.

The module will use the following signals:
- clk: Clock signal for synchronous operation
- rst_n: Active-low reset signal
- valid_in: Input signal indicating the validity of the input data
- data_in: 8-bit input data to be converted
- valid_out: Output signal indicating the validity of the output data
- data_out: 16-bit output data resulting from the width conversion
- data_lock: Internal register to store the first 8-bit data
- flag: Internal flag to track whether the first 8-bit data has been received

The module's operation can be broken down into the following steps:
1. On reset, clear all registers and the flag.
2. If the input data is valid and the flag is not set, store the input data in the data_lock register and set the flag.
3. If the input data is valid and the flag is set, concatenate the data_lock register with the input data to form the 16-bit output and generate the valid_out signal.
4. On the next clock cycle, update the data_out register with the concatenated data.
