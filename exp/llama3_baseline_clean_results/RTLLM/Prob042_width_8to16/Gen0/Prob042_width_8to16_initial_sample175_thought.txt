To implement the data width conversion circuit, we can use a combination of registers and a flag signal to track the arrival of the two 8-bit data inputs. The design involves the following key components:
1. A flag signal (data_lock_valid) to track whether the first 8-bit data has been received.
2. A register (data_lock) to store the first 8-bit data.
3. A register (data_out) to store the concatenated 16-bit output data.
4. A combinational logic to concatenate the stored 8-bit data and the new 8-bit input data when both are valid.
5. The valid_out signal is asserted when the data_out register is updated with valid data.
We will use a synchronous reset (rst_n) to clear the registers and flag signal on reset.
