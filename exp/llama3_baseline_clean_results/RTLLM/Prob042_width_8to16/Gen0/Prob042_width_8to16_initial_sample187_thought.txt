To implement the data width conversion circuit, we will use a finite state machine (FSM) approach with two states: idle and waiting. Initially, the FSM is in the idle state. When valid input data arrives, the FSM moves to the waiting state and stores the input data. In the waiting state, when the next valid input data arrives, the FSM concatenates the stored data with the new input data, generates valid output, and moves back to the idle state. We will use two registers to store the input data: one for the current input data and another for the locked data that will be concatenated with the next input data.
