The width conversion circuit can be designed as a finite state machine (FSM) with two main states: idle and concatenating. The idle state waits for the first valid input data, while the concatenating state waits for the second valid input data to complete the concatenation. The data_out register is updated when both valid input data are received. We will use a flag signal to track the reception of the first valid data. The data_in register will store the first valid data temporarily until the second valid data arrives.
