To implement the pulse detection module, we will use a finite state machine (FSM) to track the current state of the pulse detection process. The states will be defined as follows: 
- IDLE: Initial state, waiting for the first 1 in the pulse.
- RISING: State after detecting the first 1, waiting for the 0 that follows the 1.
- FALLING: State after detecting the 0 that follows the 1, waiting for the next 0 to confirm the pulse.
We will use a register state to keep track of the current state. The data_out signal will be set to 1 only when the current state is FALLING and data_in is 0, indicating the end of a pulse.
