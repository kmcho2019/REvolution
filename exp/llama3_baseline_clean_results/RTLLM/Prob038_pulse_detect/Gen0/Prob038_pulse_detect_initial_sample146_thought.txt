To implement the pulse detection module, we can use a finite state machine (FSM) with three states: IDLE, RISING, and FALLING. The IDLE state is the initial state where we wait for the rising edge of the pulse. When a rising edge is detected (data_in goes from 0 to 1), we transition to the RISING state. We then wait for the pulse to go back down (data_in goes from 1 to 0), at which point we transition to the FALLING state. If we are in the FALLING state and data_in is still 0, we know that the pulse has ended, so we set data_out to 1 and then return to the IDLE state. This way, data_out will only be 1 for one clock cycle at the end of each pulse.
