To implement the pulse detection module, we will use a finite state machine (FSM) with three states: IDLE, RISING, and FALLING. The IDLE state represents the initial state where we wait for a rising edge (0 to 1) in the data_in signal. The RISING state represents the state where we have seen a rising edge and are waiting for a falling edge (1 to 0). The FALLING state represents the state where we have seen a falling edge and need to assert the data_out signal. We will use a register 'state' to keep track of the current state. The data_out signal will be asserted only when we are in the FALLING state and will be deasserted otherwise. We will also include a reset condition to initialize the state and data_out when the rst_n signal is low.
