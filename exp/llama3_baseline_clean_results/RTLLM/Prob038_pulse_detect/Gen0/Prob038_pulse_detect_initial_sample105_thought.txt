To implement the pulse detection module, we need to design a finite state machine (FSM) that tracks the changes in the input signal "data_in". The FSM should have three states: idle (state 0), rising edge detected (state 1), and falling edge detected (state 2). Initially, the FSM is in the idle state. When the input signal "data_in" rises from 0 to 1, the FSM transitions to the rising edge detected state. If the input signal remains high for one cycle and then falls to 0, the FSM transitions to the falling edge detected state. In this state, if the input signal remains low, the FSM sets the output signal "data_out" to 1, indicating the end of a pulse, and then returns to the idle state. We will use a 2-bit register "state" to keep track of the current state of the FSM.
