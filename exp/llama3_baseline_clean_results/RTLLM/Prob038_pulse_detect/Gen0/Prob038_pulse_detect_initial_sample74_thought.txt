The FSM will have three states: idle, rising, and falling. The idle state represents the initial state where no pulse has been detected. The rising state represents the state where the input signal data_in has risen from 0 to 1. The falling state represents the state where the input signal data_in has fallen from 1 to 0 after a rising edge. We will use a register state to keep track of the current state. If the current state is rising and data_in is 0, we will transition to the falling state.
