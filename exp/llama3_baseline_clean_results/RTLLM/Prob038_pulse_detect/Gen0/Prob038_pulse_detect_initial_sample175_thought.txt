To implement the pulse detection module, we need to design a finite state machine (FSM) that can track the changes in the input signal data_in and identify when a "pulse" occurs. The FSM should have at least three states: IDLE (waiting for the start of a pulse), RISING (detecting the rising edge of a pulse), and FALLING (detecting the falling edge of a pulse). When a pulse is detected (i.e., data_in changes from 0 to 1 and then back to 0), the FSM should set the output data_out to 1 for one clock cycle and then return to 0. We will use a register to keep track of the current state and another register for the output.
