To solve this problem, we can use a finite state machine (FSM) to track the current state of the pulse detection process. The FSM will have three states: IDLE, PULSE_START, and PULSE_END. The IDLE state is the initial state where we wait for the pulse to start. When data_in transitions from 0 to 1, we move to the PULSE_START state. If data_in remains 1 in the next cycle, we stay in the PULSE_START state. If data_in transitions from 1 to 0 in the next cycle, we move to the PULSE_END state and set data_out to 1. After that, we return to the IDLE state. If the reset signal rst_n is asserted, we reset the state to IDLE and set data_out to 0. This approach ensures that data_out is 1 only at the end cycle of a "pulse".
