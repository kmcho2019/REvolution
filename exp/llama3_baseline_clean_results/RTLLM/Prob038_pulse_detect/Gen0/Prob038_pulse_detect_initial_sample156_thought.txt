The module pulse_detect will be designed as a finite state machine (FSM) with three states: IDLE, RISING, and FALLING. The FSM will transition between these states based on the value of data_in. The IDLE state is the initial state where the module waits for data_in to rise (go from 0 to 1). Once data_in rises, the FSM transitions to the RISING state. The FSM stays in the RISING state for one clock cycle, then transitions to the FALLING state if data_in stays high for one clock cycle. If data_in falls (goes from 1 to 0) in the FALLING state, the FSM transitions back to the IDLE state and sets data_out to 1 for one clock cycle to indicate the detection of a pulse. If data_in stays high in the FALLING state, the FSM will transition back to the IDLE state without setting data_out to 1. In the reset condition, the FSM resets to the IDLE state and data_out is set to 0.
