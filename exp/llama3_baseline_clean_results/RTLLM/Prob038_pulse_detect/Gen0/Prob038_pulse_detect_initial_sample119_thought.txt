In the RISING state, the module waits for the input signal to fall, and when it does, it transitions to the FALLING state. In the FALLING state, if the input signal is 0, the module sets the output signal data_out to 1, indicating the end of a pulse, and then transitions back to the IDLE state. If the input signal is not 0 in the FALLING state, the module stays in the FALLING state until the input signal falls to 0. The output signal data_out will be 1 only in the state where the pulse is detected, which is the FALLING state when data_in is 0.
