To implement the pulse detection module, we need to design a finite state machine (FSM) that can track the state of the input signal data_in and detect when a pulse occurs. The FSM should have at least three states: an idle state, a rising edge state, and a falling edge state. When data_in changes from 0 to 1, the FSM should transition from the idle state to the rising edge state. When data_in changes from 1 to 0, the FSM should transition from the rising edge state to the falling edge state. If the FSM is in the falling edge state and data_in is still 0, it should transition back to the idle state and output a pulse detection signal. We will use a 2-bit register to represent the state of the FSM.
