To implement the pulse detection module, we need to design a finite state machine (FSM) that can recognize the sequence of "0 to 1 to 0" in the input signal data_in. The FSM will have three main states: IDLE, PULSE_STARTED, and PULSE_ENDED. The IDLE state is the initial state, where the FSM waits for the rising edge of data_in. When data_in rises, the FSM transitions to the PULSE_STARTED state. In the PULSE_STARTED state, the FSM waits for the falling edge of data_in. When data_in falls, the FSM transitions to the PULSE_ENDED state and sets the output data_out to 1. After one clock cycle, the FSM returns to the IDLE state. We use a register state to keep track of the current state of the FSM.
