To implement the pulse detection module, we need to design a finite state machine (FSM) that tracks the state of the input signal data_in and outputs a pulse indication when the signal changes from 0 to 1 to 0 within three clock cycles. The FSM should have at least three states: IDLE (initial state), PULSE_START (when data_in goes from 0 to 1), and PULSE_MIDDLE (after data_in has been 1 for one clock cycle). When data_in goes from 1 to 0, if the FSM is in the PULSE_MIDDLE state, it should set data_out to 1, indicating the end of a pulse, and then return to the IDLE state. In all other cases, data_out should be 0. The FSM should also reset to the IDLE state when rst_n is 0.
