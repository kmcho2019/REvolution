To implement a pulse detection module in Verilog, we need to design a finite state machine (FSM) that tracks the changes in the input signal "data_in" over three consecutive clock cycles. The states of the FSM can be defined as follows: 
- S0 (initial state): Wait for the rising edge of "data_in".
- S1: Check if "data_in" is high.
- S2: Check if "data_in" is low, which indicates the end of a pulse.
The output signal "data_out" should be set to 1 only when a complete pulse is detected (i.e., when the FSM is in state S2 and "data_in" is 0), and 0 otherwise.
The FSM should also handle the reset condition, where it resets to the initial state S0 when the reset signal "rst_n" is low.
