To implement the pulse detection module, we will use a finite state machine (FSM) with three states: IDLE, PULSE_STARTED, and PULSE_END. The FSM will transition between these states based on the input signal data_in. When data_in changes from 0 to 1, the FSM will move from IDLE to PULSE_STARTED. When data_in changes from 1 to 0, the FSM will move from PULSE_STARTED to PULSE_END. At the PULSE_END state, the output signal data_out will be set to 1, indicating the end of a pulse. The FSM will then return to the IDLE state, waiting for the next pulse. The reset signal rst_n will be used to initialize the FSM to the IDLE state.
