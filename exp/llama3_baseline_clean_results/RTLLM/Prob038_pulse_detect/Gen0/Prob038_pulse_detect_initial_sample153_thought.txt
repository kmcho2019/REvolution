To implement the pulse detection module, we will use a finite state machine (FSM) approach. The FSM will have multiple states to track the pulse detection process. The initial state will be IDLE, where the module waits for the rising edge of the input signal data_in. After the rising edge, the module will transition to the RISING state, and then to the FALLING state after the input signal data_in goes high and then falls. The FALLING state will be the last state of a "pulse" and will set the output signal data_out to 1. After the FALLING state, the module will return to the IDLE state, resetting the pulse detection process. We will use a 2-bit register to encode the states, with the following state encoding: IDLE (2'b00), RISING (2'b01), FALLING (2'b10), and PULSE_END (2'b11). However, since we are only checking for 3 cycles (low-high-low), we can simplify the states to IDLE, RISING, and FALLING.
