To implement the pulse detection module, we need to define a finite state machine (FSM) that tracks the state of the input signal data_in. The FSM should have at least three states: idle, rising, and falling. The idle state is the initial state, and the FSM transitions to the rising state when data_in rises from 0 to 1. The FSM then transitions to the falling state when data_in falls from 1 to 0. If the FSM is in the falling state and data_in is 0, it sets the data_out signal to 1, indicating the end of a pulse, and then returns to the idle state. If the FSM is in any state and the reset signal rst_n is low, it resets to the idle state and sets data_out to 0.
