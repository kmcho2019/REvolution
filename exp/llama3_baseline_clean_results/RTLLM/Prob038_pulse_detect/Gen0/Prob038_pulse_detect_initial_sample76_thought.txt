To implement the pulse detection module, we need to track the state of the input signal data_in and identify when it changes from 0 to 1 to 0 within three cycles. We can achieve this by using a finite state machine (FSM) with three states: IDLE, PULSE_RISING, and PULSE_FALLING. The IDLE state is the initial state, and we transition to PULSE_RISING when data_in goes high. We then transition to PULSE_FALLING when data_in goes low after being high, and finally, we set the output data_out to 1 and return to the IDLE state. If the sequence is not completed, we return to the IDLE state. The FSM will be implemented using an always block sensitive to the positive edge of the clk signal and the negative edge of the rst_n signal.
