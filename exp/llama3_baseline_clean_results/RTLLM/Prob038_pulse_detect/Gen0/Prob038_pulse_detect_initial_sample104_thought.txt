The pulse detection module will utilize a finite state machine (FSM) to track the state of the input signal data_in. The FSM will have four states: IDLE (initial state), RISING (data_in changes from 0 to 1), HIGH (data_in remains 1), and FALLING (data_in changes from 1 to 0). The data_out signal will be set to 1 only when the FSM is in the FALLING state, indicating the end of a pulse. The FSM will reset to the IDLE state when rst_n is low.
