To implement the pulse detection module, we will design a finite state machine (FSM) that tracks the current state of the pulse detection process. The FSM will have three states: IDLE (initial state), PULSE_START (state after a rising edge is detected), and PULSE_MIDDLE (state after a pulse has been detected and we are waiting for the falling edge). The state machine will transition between these states based on the value of the data_in signal. When a pulse is detected (i.e., the FSM reaches the end of the pulse), the data_out signal will be set to 1 for one clock cycle, indicating the presence of a pulse.
