To implement the pulse detection module, we need to create a finite state machine (FSM) that can track the changes in the input signal data_in and identify the pattern 0-1-0, which represents a pulse. The FSM should have at least three states to detect this pattern: an initial state ( idle ), a state to detect the rising edge ( rising ), and a state to detect the falling edge ( falling ). When the pattern is detected, the output data_out should be set to 1 at the end of the pulse (i.e., when the falling edge is detected), and then reset to 0 in the next clock cycle. The reset signal rst_n should reset the FSM to its initial state and set data_out to 0.
