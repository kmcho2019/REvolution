The pulse detection module will be designed as a finite state machine (FSM) with four states: IDLE, RISING, HIGH, and FALLING. 
- IDLE: The initial state where we wait for the input signal to rise.
- RISING: The state where we check if the input signal has risen (from 0 to 1).
- HIGH: The state where we check if the input signal remains high.
- FALLING: The state where we check if the input signal falls (from 1 to 0), indicating the end of a pulse.
We use a register state to keep track of the current state and an output signal data_out to indicate the presence of pulses.
Inside the always block, we implement the logic for pulse detection and output generation based on the current state and the value of data_in.
We also handle the reset condition by setting the state register to the initial state (IDLE) and data_out to 0 when the reset signal rst_n is low.
