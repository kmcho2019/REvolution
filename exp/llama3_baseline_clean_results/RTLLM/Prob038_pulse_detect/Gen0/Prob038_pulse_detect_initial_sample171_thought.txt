To implement the pulse detection module, we need to design a finite state machine (FSM) that can track the sequence of input signals and identify a pulse. The FSM will have four states: IDLE (initial state), RISING (data_in rises from 0 to 1), HIGH (data_in remains high), and FALLING (data_in falls from 1 to 0). The output signal data_out will be set to 1 only when the FSM is in the FALLING state and data_in is 0, indicating the end of a pulse. We will use a 2-bit register to represent the current state and another register to store the output signal. The FSM will transition between states based on the current state and the value of data_in.
