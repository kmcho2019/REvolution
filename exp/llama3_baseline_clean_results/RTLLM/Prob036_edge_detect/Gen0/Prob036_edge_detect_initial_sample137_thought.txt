To implement the edge_detect module, we will use a simple finite state machine that keeps track of the current state of the input signal 'a' and the previous state. The current state of 'a' is compared with its previous state to detect rising and falling edges. When a rising edge is detected (i.e., the previous state of 'a' is 0 and the current state is 1), the 'rise' output is set to 1 on the next clock cycle. Similarly, when a falling edge is detected (i.e., the previous state of 'a' is 1 and the current state is 0), the 'down' output is set to 1. The 'rise' and 'down' outputs are reset to 0 after being set to 1 for one clock cycle. The module also includes a reset input 'rst_n' to reset the internal state when it goes low.
