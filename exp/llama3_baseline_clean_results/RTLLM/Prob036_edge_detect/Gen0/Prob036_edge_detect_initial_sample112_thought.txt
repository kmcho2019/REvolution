To implement the edge_detect module, we need to use a simple state machine that keeps track of the current state of the input signal 'a' and checks for changes at each clock cycle. We will use a flip-flop to store the previous state of 'a'. On each rising edge of the clock, we compare the current state of 'a' with its previous state to determine if there's a rising or falling edge. Based on this comparison, we set the 'rise' or 'down' output signals accordingly. The reset signal 'rst_n' will be used to initialize the module.
