To implement the edge_detect module, we need to track the current and previous states of the input signal a. We can use a simple state machine that stores the previous value of a and compares it with the current value on each rising edge of the clock. If the current value is 1 and the previous value was 0, a rising edge is detected and the rise output is set to 1. If the current value is 0 and the previous value was 1, a falling edge is detected and the down output is set to 1. Otherwise, both outputs remain 0. The previous value of a is updated at the end of each clock cycle. We will also include a reset mechanism to reset the module when the rst_n signal is low.
