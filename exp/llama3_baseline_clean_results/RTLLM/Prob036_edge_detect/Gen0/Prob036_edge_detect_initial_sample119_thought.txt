To implement the edge_detect module, we need to keep track of the previous state of the input signal a and compare it with the current state. When the input signal changes from 0 to 1, we detect a rising edge and set the rise output signal to 1. Similarly, when the input signal changes from 1 to 0, we detect a falling edge and set the down output signal to 1. We will use a flip-flop to store the previous state of the input signal a. The edge detection logic will be implemented using combinational logic. The rise and down output signals will be set to 1 on the next clock cycle after the corresponding edge is detected and will remain set to 1 until the corresponding edge appears again. We will also include a reset mechanism to initialize the module when the reset signal rst_n is low.
