The output enable signal (o_en) is updated based on the pipeline stages and is synchronized with the clock (clk) and reset (rst_n) signals.

1. Input stage: Store the input operands (adda and addb) and the input enable signal (i_en) in registers.
2. Addition stage: Perform the 64-bit addition of the input operands and store the result in a register.
3. Output stage: Store the final result and update the output enable signal (o_en).
