Each stage will consist of a full adder that adds the corresponding bits of the input operands and the carry from the previous stage. The output of each stage will be registered to create a pipeline. The input enable signal (i_en) will also be pipelined to synchronize it with the output enable signal (o_en). The output enable signal will be updated based on the pipeline stages and will be synchronized with the clock (clk) and reset (rst_n) signals.
