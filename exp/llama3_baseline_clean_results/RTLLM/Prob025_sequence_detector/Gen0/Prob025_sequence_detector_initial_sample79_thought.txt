The sequence detector will be designed as a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input data_in and the current state. When the sequence 1001 is detected, the output sequence_detected will be asserted high. The FSM will have a reset input reset_n, which when low, will reset the FSM to the IDLE state. The detector will check the input data_in on each clock cycle to determine the next state.
