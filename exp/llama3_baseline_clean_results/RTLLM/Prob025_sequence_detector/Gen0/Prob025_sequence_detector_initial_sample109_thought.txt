To implement the sequence detector, we will use a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input bitstream data_in. On each clock cycle, the detector will check for a match of the specific sequence. When the complete sequence is detected, the output sequence_detected will be set high. The reset signal will return the state machine to the IDLE state when it is asserted. 
The state transitions will be as follows: 
- From IDLE, if data_in is 1, transition to S1. Otherwise, stay in IDLE.
- From S1, if data_in is 0, transition to S2. Otherwise, go back to IDLE.
- From S2, if data_in is 0, transition to S3. Otherwise, go back to IDLE.
- From S3, if data_in is 1, transition to S4. Otherwise, go back to IDLE.
- From S4, assert sequence_detected and go back to IDLE.
