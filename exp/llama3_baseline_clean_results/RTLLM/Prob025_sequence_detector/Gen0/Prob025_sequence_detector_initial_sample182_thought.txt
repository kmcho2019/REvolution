To design the sequence detector module, we will use a finite state machine (FSM) with four states: IDLE, S1, S2, S3, and S4. The FSM transitions through these states based on the input data_in. The sequence_detected output is set high when the FSM reaches the S4 state, indicating that the specific 4-bit binary sequence 1001 has been detected. The reset_n signal is used to reset the FSM to the IDLE state. We will use a parameterized enum to define the states and a always block to implement the FSM logic.
