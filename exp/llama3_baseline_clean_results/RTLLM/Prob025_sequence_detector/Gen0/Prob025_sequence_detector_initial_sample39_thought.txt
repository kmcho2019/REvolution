To implement the sequence detector, we'll design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. We'll use a case statement to handle the state transitions and output logic. The detector will check the input data_in on each clock cycle and transition to the next state if a match is found. Once the complete sequence is detected, the output sequence_detected will be asserted high. The reset signal reset_n will be used to return the state machine to the IDLE state when it's high.
