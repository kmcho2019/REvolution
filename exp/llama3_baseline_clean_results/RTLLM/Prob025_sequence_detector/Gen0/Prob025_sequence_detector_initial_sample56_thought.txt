To implement the sequence detector, we will design a finite state machine (FSM) that transitions through states based on the input bitstream data_in. The FSM will have five states: IDLE, S1, S2, S3, and S4. The detector will check for a match of the specific sequence 1001 and assert sequence_detected when the complete sequence is detected. The FSM will be implemented using a always_ff block in Verilog, which is sensitive to the clock signal clk and the reset signal reset_n. We will use a case statement to handle the state transitions and assign the next state based on the current state and the input data_in.
