To implement the sequence detector module, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input data_in. The sequence detection process starts at the IDLE state, and on each clock cycle, the detector checks for a match of the specific sequence. When a match is found, the sequence_detected output is set high. The reset_n signal is used to initialize the state machine to the IDLE state. 
The state transitions are as follows:
- IDLE: If data_in is 1, transition to S1. Otherwise, stay in IDLE.
- S1: If data_in is 0, transition to S2. Otherwise, go back to IDLE.
- S2: If data_in is 0, transition to S3. Otherwise, go back to IDLE.
- S3: If data_in is 1, transition to S4. Otherwise, go back to IDLE.
- S4: If data_in is 1, set sequence_detected high and stay in S4. Otherwise, go back to IDLE.
When reset_n is low, the state machine resets to the IDLE state.
