To implement the sequence detector, we will use a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. The detector will start in the IDLE state and move through the states as it detects the corresponding bits of the desired sequence (1001). When the complete sequence is detected, the output sequence_detected will be set high. We will use Verilog's enum type to define the states and a case statement to handle the state transitions. The FSM will be reset to the IDLE state when the reset_n signal is low.
