The sequence detector will be implemented as a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between states based on the input bitstream data_in. The sequence detection process starts at the IDLE state, waiting for the first bit of the sequence (1) to arrive. Upon receiving the first '1', the FSM moves to the S1 state. Then, it checks for the next bits in the sequence: '0' for S2, '0' for S3, and finally '1' for S4. If the sequence is detected (S4 state), the sequence_detected output is asserted. If at any point the input bit does not match the expected sequence, the FSM returns to the IDLE state, except when reset is asserted, in which case it resets to the IDLE state immediately. The FSM uses a clock signal clk for synchronization and a reset signal reset_n to return to the initial state.
