To design the sequence detector module, we will implement a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input data_in. The detector will start in the IDLE state, waiting for the first bit of the desired sequence. When the first bit '1' is detected, the FSM will transition to S1. Then, for each subsequent bit, it will transition to the next state if the bit matches the desired sequence. If a bit does not match the sequence, the FSM will return to the IDLE state. Once the complete sequence 1001 is detected, the output sequence_detected will be asserted. The reset signal reset_n will be used to initialize the state machine to the IDLE state.
