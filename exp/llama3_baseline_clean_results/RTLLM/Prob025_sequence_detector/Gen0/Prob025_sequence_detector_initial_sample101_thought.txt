To implement the sequence detector, we can design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM transitions between these states based on the input data_in and the current state. We will use a Moore machine approach, where the output sequence_detected is a function of the current state. The FSM will transition as follows:
- From IDLE to S1 when data_in is 1.
- From S1 to S2 when data_in is 0.
- From S2 to S3 when data_in is 0.
- From S3 to S4 when data_in is 1.
- From S4 to IDLE and assert sequence_detected when data_in is 1 (sequence detected).
- From any state to IDLE when reset_n is low.
