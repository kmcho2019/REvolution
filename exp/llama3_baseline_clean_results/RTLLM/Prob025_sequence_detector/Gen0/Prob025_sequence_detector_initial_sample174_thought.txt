To implement the sequence detector, we'll design a finite state machine (FSM) that transitions through four states (IDLE, S1, S2, S3, and S4) based on the input bitstream data_in. On each clock cycle, the FSM checks for a match of the specific 4-bit sequence 1001. If a match is found, the output sequence_detected is asserted high. We'll use a parameterized enum to define the states and a case statement to handle state transitions. The reset_n signal will be used to initialize the state machine to the IDLE state.
