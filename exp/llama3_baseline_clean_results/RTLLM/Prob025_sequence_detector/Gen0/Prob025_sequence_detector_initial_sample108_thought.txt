To design the sequence detector, we can implement a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. The detector will check for a match of the specific sequence 1001 on each clock cycle. When the complete sequence is detected, the output sequence_detected will be asserted high. The reset signal reset_n will be used to return the state machine to the IDLE state when it is high, resetting the detection process.
