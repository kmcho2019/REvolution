To implement the sequence detector, we will use a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. The detector starts in the IDLE state and waits for the first bit of the sequence (1) to transition to S1. If the next bit is 0, it moves to S2. Then, it checks for the next bit being 0 and moves to S3. Finally, it checks for the last bit being 1 and moves to S4, where it asserts the sequence_detected signal. If at any point the input bit does not match the expected sequence, the FSM will return to the IDLE state. The reset_n signal will be used to reset the FSM to the IDLE state.
