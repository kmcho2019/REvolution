To implement the sequence detector, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The state machine will transition between these states based on the input data_in signal. The FSM will be implemented using a parameterized enum for the states and a always_ff block for the state transition and output logic. We will also include an always_comb block for the next state logic. The sequence_detected output will be asserted when the state machine reaches the S4 state. The reset_n signal will be used to reset the state machine to the IDLE state.
