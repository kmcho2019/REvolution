To design a sequence detector for a specific 4-bit binary sequence 1001, we need to implement a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. 
The FSM starts in the IDLE state and transitions between states based on the input data_in. 
The detector checks the input data_in and transitions to the next state if the input matches the expected bit in the sequence. 
If the input does not match, the FSM returns to the IDLE state. 
Once the complete sequence is detected, the output sequence_detected is asserted high. 
The detector also includes a reset signal reset_n to initialize the state machine to the IDLE state when it is asserted low.
