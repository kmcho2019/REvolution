To implement the sequence detector module, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between states based on the input bitstream data_in. We will use a case statement to define the next state logic, and a separate case statement to define the output logic. The reset signal reset_n will be used to initialize the FSM to the IDLE state. The sequence_detected output will be set high when the FSM reaches the S4 state.
