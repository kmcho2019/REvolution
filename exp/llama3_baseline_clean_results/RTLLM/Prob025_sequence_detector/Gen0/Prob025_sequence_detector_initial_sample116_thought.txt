To implement the sequence detector module, we can design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM transitions between these states based on the input data_in. We start in the IDLE state and transition to S1 when we see the first '1' in the sequence. Then, we transition to S2 when we see '0' in S1, to S3 when we see '0' in S2, and finally to S4 when we see '1' in S3. In the S4 state, we assert the sequence_detected output. If at any point we see a bit that does not match the next expected bit in the sequence, we return to the IDLE state. The reset_n signal is used to reset the FSM to the IDLE state.
