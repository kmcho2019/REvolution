To design the sequence detector module, we'll implement a finite state machine (FSM) with the specified states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input data_in and the current state. The sequence_detector module will have the following characteristics:

- The module will have input ports for the clock signal (clk), reset signal (reset_n), and the binary input signal (data_in).
- The module will have an output port (sequence_detected) that will be set high when the specific sequence 1001 is detected.
- The state machine will start in the IDLE state, waiting for the first bit of the sequence (1).
- When the first bit of the sequence is detected, the FSM will transition to the S1 state.
- Then, for each subsequent bit in the sequence, the FSM will transition to the next state if the bit matches the expected bit in the sequence.
- If a bit does not match the expected bit, the FSM will return to the IDLE state.
- Once the complete sequence is detected (reaching the S4 state), the output sequence_detected will be asserted high.
- When the reset signal is high, the state machine will return to the IDLE state, resetting the detection process.
