To implement the sequence detector module, we will use a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The state machine will transition between these states based on the input data_in. On each clock cycle, the detector will check for a match of the specific sequence 1001. If the sequence is detected, the output sequence_detected will be set high. The reset signal reset_n will be used to return the state machine to the IDLE state when it is high. We will use a case statement to implement the state machine and a always block to handle the clock and reset signals.
