To implement the sequence detector module, we'll design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. We'll use a case statement to handle the state transitions and assign the next state based on the current state and input data. When the final state S4 is reached, we'll assert the sequence_detected output signal. The FSM will also be reset to the IDLE state when the reset_n signal is low.
