To implement the sequence detector module, I will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between states based on the input data_in and the current state. The sequence detection will be performed by checking the input data_in on each clock cycle and transitioning to the next state if the input matches the expected bit in the sequence. When the complete sequence is detected, the output sequence_detected will be asserted high. The reset behavior will be implemented by returning the state machine to the IDLE state when reset_n is low.
