To implement the sequence detector, I will design a finite state machine (FSM) that transitions through states based on the input bitstream. The FSM will have five states: IDLE, S1, S2, S3, and S4. The sequence detector will check the input data_in on each clock cycle and transition between states accordingly. When the complete sequence 1001 is detected, the output sequence_detected will be set high. The FSM will also be reset to the IDLE state when the reset signal is high.
