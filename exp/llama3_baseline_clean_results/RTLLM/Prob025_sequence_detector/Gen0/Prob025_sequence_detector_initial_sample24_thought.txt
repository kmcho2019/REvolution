To implement the sequence detector module, we will design a finite state machine (FSM) with four states: IDLE, S1, S2, S3, and S4. The FSM transitions between these states based on the input bitstream data_in. On each clock cycle, the detector checks for a match of the specific sequence 1001. When the complete sequence is detected, the output sequence_detected is asserted. The reset_n signal is used to initialize the state machine to the IDLE state. We will use a case statement to handle the transitions between states and assign the next state based on the current state and input data_in.
