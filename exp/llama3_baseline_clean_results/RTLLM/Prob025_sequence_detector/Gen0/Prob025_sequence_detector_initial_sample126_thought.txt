To implement the sequence detector, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input data_in and the current state. We will use a Moore machine approach, where the output sequence_detected is determined solely by the current state. The FSM will be implemented using a combinational logic block to determine the next state and a sequential logic block to store the current state.

We will define the states as follows:
- IDLE: Initial state, waiting for the start of the sequence (00).
- S1: First bit of the sequence detected (10).
- S2: Second bit of the sequence detected (00).
- S3: Third bit of the sequence detected (01).
- S4: Fourth and final bit of the sequence detected (11).

The state machine will transition as follows:
- IDLE to S1: data_in = 1.
- S1 to S2: data_in = 0.
- S2 to S3: data_in = 0.
- S3 to S4: data_in = 1.
- S4 to IDLE: sequence_detected is asserted, and the state machine resets to IDLE.
- Any other input will cause the state machine to return to IDLE.

We will use a 2-bit binary encoding for the states to minimize the number of states and simplify the combinational logic.
