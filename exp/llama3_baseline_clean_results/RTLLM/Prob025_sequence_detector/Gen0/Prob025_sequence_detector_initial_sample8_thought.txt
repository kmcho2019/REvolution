To implement the sequence detector, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input data_in. We will use a case statement to handle the state transitions and a conditional statement to assert the sequence_detected output when the complete sequence is detected. The reset_n signal will be used to reset the FSM to the IDLE state.
