To design the sequence detector module, we will implement a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in and the current state. The sequence detection is performed by checking the input data_in at each clock cycle and transitioning to the next state if the input matches the expected bit in the sequence. When the complete sequence 1001 is detected, the output sequence_detected will be set high. The module will also include a reset functionality to return the state machine to the IDLE state when reset_n is low.
