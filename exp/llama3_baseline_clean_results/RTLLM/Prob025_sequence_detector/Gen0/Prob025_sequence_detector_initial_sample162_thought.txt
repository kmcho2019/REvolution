To design the sequence detector, we'll use a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The detector starts in the IDLE state and transitions through the states based on the input bitstream data_in. When the complete sequence 1001 is detected, the output sequence_detected is set high. We'll use a binary encoding for the states to simplify the state machine implementation. The state transitions will be controlled by the current state and the input data_in.
