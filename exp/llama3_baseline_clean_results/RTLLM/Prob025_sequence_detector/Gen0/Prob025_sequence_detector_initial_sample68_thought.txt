To implement the sequence detector module, we'll design a finite state machine (FSM) with the specified states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input bitstream data_in. On each clock cycle, the detector will check for a match of the specific sequence 1001. When the complete sequence is detected, the output sequence_detected will be asserted high. The FSM will also be reset to the IDLE state when the reset signal reset_n is high. We'll use a parameterized approach for the state encoding to make the code more readable and maintainable.
