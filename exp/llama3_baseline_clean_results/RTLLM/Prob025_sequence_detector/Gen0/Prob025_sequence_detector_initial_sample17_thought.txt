To design the sequence detector, we'll implement a finite state machine (FSM) with the specified states: IDLE, S1, S2, S3, and S4. The FSM transitions between these states based on the input data_in. We'll use a parameterized approach to define the states and the corresponding state transitions. The sequence detection is performed by checking the input data_in on each clock cycle and transitioning between states accordingly. When the complete sequence is detected, the output sequence_detected is asserted. The reset signal reset_n is used to initialize the state machine to the IDLE state.
