To implement the sequence detector module, we will use a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. On each clock cycle, the detector will check for a match of the specific sequence 1001. When the complete sequence is detected, the output sequence_detected will be asserted high. The reset signal reset_n will be used to return the state machine to the IDLE state when it is high. We will use a parameterized approach to define the states and sequence.
