To implement the sequence detector module, we will design a finite state machine (FSM) that transitions through four states (IDLE, S1, S2, S3, S4) based on the input bitstream data_in. The FSM will be implemented using a parameterized enum to define the states. The next state logic will be based on the current state and the input data_in. The output sequence_detected will be asserted when the FSM reaches the final state S4, indicating that the specific sequence 1001 has been detected.
