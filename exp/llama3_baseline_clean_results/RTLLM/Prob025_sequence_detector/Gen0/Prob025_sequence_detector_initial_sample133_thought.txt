To implement the sequence detector module, I will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between states based on the input data_in. The module will have a reset_n input to reset the state machine to the IDLE state. The sequence_detected output will be asserted when the complete sequence 1001 is detected.

The state machine transitions will be as follows:
- From IDLE, if data_in is 1, transition to S1. Otherwise, stay in IDLE.
- From S1, if data_in is 0, transition to S2. Otherwise, go back to IDLE.
- From S2, if data_in is 0, transition to S3. Otherwise, go back to IDLE.
- From S3, if data_in is 1, transition to S4. Otherwise, go back to IDLE.
- From S4, the sequence is detected, and sequence_detected is asserted. Then, go back to IDLE.

The module will be implemented using a Verilog always block to describe the state machine behavior and the output logic.
