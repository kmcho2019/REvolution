To implement the sequence detector, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between states based on the input data_in. In the IDLE state, the detector waits for the first bit of the sequence (1) to arrive. Upon detection, it moves to the S1 state. In the S1 state, it waits for the second bit (0), and so on. Once the detector reaches the S4 state, it asserts the sequence_detected output and then resets to the IDLE state. A reset_n signal is used to reset the FSM to the IDLE state when it is asserted low.
