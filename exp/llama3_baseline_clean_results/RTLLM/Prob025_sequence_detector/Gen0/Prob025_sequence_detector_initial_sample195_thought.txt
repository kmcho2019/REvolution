To design the sequence detector module, we will implement a finite state machine (FSM) that transitions through states based on the input bitstream. The FSM will have five states: IDLE, S1, S2, S3, and S4, representing the detection of the 4-bit binary sequence 1001. On each clock cycle, the detector will check the input data_in and transition to the next state if it matches the expected bit in the sequence. When the complete sequence is detected, the output sequence_detected will be set high. The reset signal will be used to return the state machine to the IDLE state, resetting the detection process.
