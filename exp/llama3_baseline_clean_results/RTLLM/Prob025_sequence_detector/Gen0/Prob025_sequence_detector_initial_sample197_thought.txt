To implement the sequence detector, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input bitstream data_in. The sequence_detected signal will be asserted when the FSM reaches the S4 state, indicating that the specific sequence 1001 has been detected. The reset_n signal will be used to reset the FSM to the IDLE state when it is high. We will use a parameterized enum to define the states and a case statement to handle the state transitions.
