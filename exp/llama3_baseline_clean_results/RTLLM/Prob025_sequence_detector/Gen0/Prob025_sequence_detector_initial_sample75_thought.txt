The sequence detector module will be designed using a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The state machine will transition between states based on the input data_in. We will use a case statement to handle the state transitions and assign the next state based on the current state and input data. The output sequence_detected will be set high when the state machine reaches the S4 state. The reset_n signal will be used to initialize the state machine to the IDLE state. 
The state machine's state transitions will be as follows: 
- From IDLE state to S1 state when data_in is 1, 
- From S1 state to S2 state when data_in is 0, 
- From S2 state to S3 state when data_in is 0, 
- From S3 state to S4 state when data_in is 1, 
- From S4 state to IDLE state (asserting sequence_detected) when data_in is 1. 
In all other cases, the state machine will remain in the IDLE state.
The output sequence_detected will be asserted when the state machine is in the S4 state and data_in is 1.
