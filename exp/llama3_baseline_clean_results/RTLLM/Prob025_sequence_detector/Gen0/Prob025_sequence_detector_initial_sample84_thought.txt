The sequence detector module will utilize a finite state machine (FSM) with four states to detect the specific 4-bit binary sequence 1001. The FSM will transition between these states based on the input data_in. The state transitions will be as follows:
- From IDLE to S1 when the input is 1.
- From S1 to S2 when the input is 0.
- From S2 to S3 when the input is 0.
- From S3 to S4 when the input is 1.
- From S4 to IDLE and assert sequence_detected when the input is 1.
- If the input does not match the expected sequence, the FSM will reset to IDLE.
The reset_n signal will be used to initialize the state machine to IDLE when it is low.
