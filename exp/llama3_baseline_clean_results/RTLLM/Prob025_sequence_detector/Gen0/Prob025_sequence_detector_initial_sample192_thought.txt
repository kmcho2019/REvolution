To implement the sequence detector, we can design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. The detector will start in the IDLE state and transition to S1 when it encounters the first '1' in the sequence. It will then transition to S2 when it encounters the next '0', followed by S3 when it encounters the next '0', and finally S4 when it encounters the last '1' in the sequence. Once the complete sequence is detected, the output sequence_detected will be set high. The FSM will return to the IDLE state when the reset signal reset_n is low.
