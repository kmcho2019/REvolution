To implement the sequence detector, we'll design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input data_in and the current state. When the sequence '1001' is detected, the output sequence_detected will be set high. The FSM will be reset to the IDLE state when reset_n is low. 
The states and transitions will be implemented using a parameterized enum and a case statement inside an always_comb block for combinational logic, and an always_ff block for sequential logic.
