To implement the sequence detector module, we will design a finite state machine (FSM) with four states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input data_in. We will use a Moore machine approach, where the output sequence_detected is determined solely by the current state (S4). On each clock cycle, the detector will check the input data_in and transition to the next state if the sequence matches. The FSM will also have a reset input reset_n to initialize the state machine to the IDLE state when reset is high. We will use a case statement to handle the different states and their corresponding next states.
