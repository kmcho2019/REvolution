To implement the sequence detector, we can design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input bitstream data_in. At each state, we will check for a match with the desired sequence (1001). When the complete sequence is detected, we will assert the output sequence_detected. The reset signal reset_n will be used to return the FSM to the IDLE state when it is high.
