To implement the sequence detector module, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input data_in and clock signal clk. When the specific sequence 1001 is detected, the output sequence_detected will be set high. The reset signal reset_n will be used to return the state machine to the IDLE state. We will use a parameterized enum to define the states and a case statement to handle the state transitions.
