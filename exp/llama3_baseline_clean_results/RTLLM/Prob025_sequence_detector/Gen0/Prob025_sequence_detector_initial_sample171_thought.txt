To implement the sequence detector module, I will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. The detector will check for the specific 4-bit binary sequence 1001 and assert the sequence_detected output when the sequence is detected. The reset_n signal will be used to reset the state machine to the IDLE state. I will use a parameterized enum to define the states and a always_ff block to describe the sequential behavior of the FSM.
