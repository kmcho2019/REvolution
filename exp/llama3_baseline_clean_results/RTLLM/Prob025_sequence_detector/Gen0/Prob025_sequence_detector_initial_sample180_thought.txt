To implement the sequence detector module, we can use a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM transitions between these states based on the input bitstream data_in. On each clock cycle, the detector checks for a match of the specific sequence 1001. If a match is found, the output sequence_detected is set high. The reset signal reset_n is used to reset the state machine to the IDLE state when it is high. We will use a parameterized approach to define the states and their transitions.
