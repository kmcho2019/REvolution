To implement the sequence detector, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM transitions between these states based on the input bitstream data_in. On each clock cycle, the detector checks for a match of the specific sequence 1001. When the complete sequence is detected, the output sequence_detected is asserted. The state machine is also designed to reset to the IDLE state when the reset signal reset_n is asserted low.
