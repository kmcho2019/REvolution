To implement the sequence detector, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input data_in and the current state. We will use a parameterized enumeration for the states to improve readability and maintainability of the code. The FSM will be implemented using a always block that is sensitive to the positive edge of the clock and the negation of the reset_n signal. When the FSM reaches the S4 state, it will assert the sequence_detected output. The FSM will reset to the IDLE state when reset_n is low.
