To implement the sequence detector module, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. On each clock cycle, the detector will check for a match of the specific sequence 1001. If the sequence is detected, the output sequence_detected will be set high. The module will also have a reset functionality, where the state machine returns to the IDLE state when reset_n is low.
