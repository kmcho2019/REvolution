- S0: Initial state or reset state
- S1: State after receiving the first '1'
- S2: State after receiving the first '0' after S1
- S3: State after receiving the second '0' after S2
- S4: State after receiving the first '1' after S3
- S5: State after receiving the second '1' after S4, which is the match state
