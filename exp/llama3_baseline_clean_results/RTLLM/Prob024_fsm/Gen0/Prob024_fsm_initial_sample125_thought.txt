- S0 is the initial state where the FSM waits for the first '1' in the sequence.
- When a '1' is detected, the FSM moves to S1.
- In S1, if a '0' is detected, the FSM moves to S2. If another '1' is detected, the FSM resets to S1 because the sequence is not valid.
- In S2, if a '0' is detected, the FSM moves to S3. If a '1' is detected, the FSM resets to S1.
- In S3, if a '1' is detected, the FSM moves to S4. If a '0' is detected, the FSM resets to S1.
- In S4, if a '1' is detected, the FSM moves to S5 and sets the output MATCH to '1'. If a '0' is detected, the FSM resets to S1.
- In S5, the FSM sets the output MATCH to '1' for one clock cycle and then resets to S1.
