To implement the Mealy FSM detection circuit, we'll design a finite state machine that transitions through states based on the input sequence. The FSM will have six states: S0 (initial state), S1, S2, S3, S4, and S5. The state transitions will be as follows:
- From S0 to S1 when IN = 1
- From S1 to S2 when IN = 0
- From S2 to S3 when IN = 0
- From S3 to S4 when IN = 1
- From S4 to S5 when IN = 1
- From S5 to S0 when any input other than the sequence 1, 0, 0, 1, 1 is detected
The output MATCH will be set to 1 in state S5 and 0 in all other states.
