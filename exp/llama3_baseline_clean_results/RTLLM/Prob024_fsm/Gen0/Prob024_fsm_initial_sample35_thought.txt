To solve this problem, we will design a Mealy Finite State Machine (FSM) that detects a specific sequence of input bits. The FSM will have states corresponding to each position in the sequence and transition between states based on the current input and current state. When the FSM reaches the final state (i.e., it has seen the entire sequence), it will output a '1' for one clock cycle. The FSM will also reset to its initial state when the reset signal is active. We will use a parameterized approach to make the code flexible and modular.
