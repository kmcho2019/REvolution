The FSM will also support continuous input and loop detection.

We will initialize the FSM with the RST signal. When RST is active, the FSM will reset to the initial state (S0) and set the MATCH signal to 0. 

The state transitions will be as follows:
- S0: If IN is 1, move to S1; otherwise, stay in S0.
- S1: If IN is 0, move to S2; otherwise, move back to S0.
- S2: If IN is 0, move to S3; otherwise, move back to S0.
- S3: If IN is 1, move to S4; otherwise, move back to S0.
- S4: If IN is 1, move to S5 and set MATCH to 1; otherwise, move back to S0.
