To solve this problem, we'll design a Mealy Finite State Machine (FSM) that transitions through states based on the input sequence IN. The FSM will have states corresponding to the detected sequence (1, 0, 0, 1, 1). We'll use a parameterized approach to define the states and transitions for better readability and maintainability. The MATCH signal will be set to 1 when the FSM reaches the final state of the sequence and reset to 0 otherwise. The design will be implemented using Verilog's always block for combinational logic and sequential logic.
