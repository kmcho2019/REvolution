- S1: First '1' detected
- S2: '0' detected after '1'
- S3: Second '0' detected
- S4: '1' detected after two '0's
- S5: Final '1' detected, match found

The transitions between states will be based on the current state and the input signal IN. When the FSM reaches state S5, it will output MATCH = 1. In all other cases, MATCH will be 0.

We will use a parameterized case statement to define the next state logic, which will allow us to easily modify or extend the FSM if needed.
