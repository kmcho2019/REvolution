To implement the Mealy FSM detection circuit, we need to design a finite state machine that can detect the sequence 10011 in a continuous input stream. The FSM should have states that correspond to the detected sequence. 

The states can be defined as follows:
- S0: Initial state or reset state
- S1: State after detecting the first '1'
- S2: State after detecting the first '0' after S1
- S3: State after detecting the second '0' after S2
- S4: State after detecting the first '1' after S3
- S5: State after detecting the second '1' after S4, which is the final state to trigger the MATCH signal

The MATCH signal should be set to 1 when the FSM reaches the final state (S5) and stays in that state as long as the input sequence continues to match the pattern. If the input sequence deviates from the pattern, the FSM should reset to the appropriate state.

The FSM should also handle the reset condition where if RST is active, the MATCH signal is set to 0 and the FSM resets to the initial state.
