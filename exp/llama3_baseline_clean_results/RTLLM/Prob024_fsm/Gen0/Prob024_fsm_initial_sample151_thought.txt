- S0: Initial state
- S1: After detecting the first '1'
- S2: After detecting the '0' after the first '1'
- S3: After detecting the second '0'
- S4: After detecting the '1' after the second '0'
- S5: After detecting the final '1'

We will use a case statement to handle the current state and next state logic. The current state will be updated based on the next state logic.

The circuit will be designed using a synchronous reset, so when the RST signal is high, the current state will be reset to S0.
