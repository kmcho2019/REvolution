To implement the Mealy FSM detection circuit, we will define the states for the FSM based on the input sequence 10011. We will have six states: IDLE (initial state), S1, S2, S3, S4, and S5. The transition between these states will depend on the input signal IN. When the FSM reaches state S5, it means the input sequence 10011 has been detected, and the output signal MATCH will be set to 1. In all other cases, MATCH will be 0. The FSM will reset to the IDLE state when the reset signal RST is active.

The state transitions can be described as follows:
- IDLE state: If IN is 1, move to S1 state.
- S1 state: If IN is 0, move to S2 state.
- S2 state: If IN is 0, move to S3 state.
- S3 state: If IN is 1, move to S4 state.
- S4 state: If IN is 1, move to S5 state and set MATCH to 1.
- S5 state: This is a temporary state to set MATCH to 1. After setting MATCH, move back to IDLE state regardless of the input.

We will implement this FSM using a finite state machine with a synchronous reset.
