To implement an 8-bit adder module using multiple bit-level adders in combinational logic, we will create a hierarchical design. The top-level module, `adder_8bit`, will instantiate eight instances of a full adder module, `full_adder`. Each full adder will perform the addition of corresponding bits from the input operands `a` and `b`, along with a carry input. The carry output of one full adder will be connected to the carry input of the next full adder. This way, the carry chain will propagate through all bits, enabling the addition of the two 8-bit numbers. The `full_adder` module will be designed using basic logic gates, implementing the addition and carry logic.
