To implement a 32-bit floating-point multiplier for the IEEE-754 standard single-precision arithmetic, we will follow these steps: 
1. Extract the mantissa, exponent, and sign bits from the input operands.
2. Handle special cases like NaN and infinity.
3. Normalize the mantissas if necessary.
4. Multiply the mantissas, adjusting the exponents and signs accordingly.
5. Round the result and adjust the exponent.
6. Format the final result in IEEE 754 standard, handling overflow and underflow scenarios.
