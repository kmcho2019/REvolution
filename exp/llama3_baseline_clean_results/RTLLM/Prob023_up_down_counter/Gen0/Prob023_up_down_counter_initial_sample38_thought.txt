To implement the up_down_counter module, we'll use a synchronous process triggered by the rising edge of the clock signal. Inside this process, we'll first check if the reset signal is active. If it is, we reset the counter to zero. Otherwise, we check the up_down control signal. If it's high, we increment the counter; if it's low, we decrement it. We'll use a 16-bit reg to store the counter value and assign it to the count output.
