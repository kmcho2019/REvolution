The up_down_counter module should be designed with a synchronous process that uses the rising edge of the clock signal (`clk`) as its trigger. This process will check for the reset condition first. If `up_down` is high (1), the counter will increment by 1 on each clock cycle. If `up_down` is low (0), the counter will decrement by 1 on each clock cycle.
