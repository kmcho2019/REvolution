The up_down_counter module will be designed as a synchronous sequential circuit. It will use a single always block that is triggered by the rising edge of the clock signal (`clk`). Inside the always block, we will first check if the reset signal is active. If it is, we will reset the counter to zero. Otherwise, we will check the `up_down` control signal to determine whether to increment or decrement the counter. The counter value will be stored in a 16-bit register, and its value will be assigned to the `count` output port.
