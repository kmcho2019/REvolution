To design the up_down_counter module, we will use a synchronous process triggered by the rising edge of the clock signal (clk). Inside this process, we will first check if the reset signal is active. If it is, we will reset the counter to zero. Otherwise, we will check the up_down control signal to determine whether to increment or decrement the counter. We will use a reg variable to hold the current counter value and assign it to the output port (count) after the counter has been updated.
