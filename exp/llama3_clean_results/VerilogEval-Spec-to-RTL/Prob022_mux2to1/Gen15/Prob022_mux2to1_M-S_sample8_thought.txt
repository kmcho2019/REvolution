The existing solution using a ternary operator is already quite concise and directly implements the 2-to-1 multiplexer logic. However, we can consider an alternative approach using basic logical operations to achieve the same functionality, potentially simplifying the expression further or making it more intuitive for certain audiences. One such method involves using AND-OR logic, where the output is a combination of the selected inputs based on the select line. This can be expressed as (a AND NOT sel) OR (b AND sel), which directly implements the multiplexer's behavior.
