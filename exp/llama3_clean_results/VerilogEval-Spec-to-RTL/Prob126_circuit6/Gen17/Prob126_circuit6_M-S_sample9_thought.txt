The current solution uses a long chain of conditional operators to implement the lookup table. This approach can be simplified by using a case statement, which is more concise and easier to read. The case statement directly maps the input values to the corresponding output values, eliminating the need for multiple conditional checks.

This approach reduces the complexity of the code while maintaining its functionality. It is also more scalable, as adding new input-output pairs would be straightforward with a case statement compared to extending the chain of conditional operators.
