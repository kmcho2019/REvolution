To implement the given Moore state machine, we first define the states as enumerated constants in Verilog. We use a parameterized approach for defining the states to make the code more readable and maintainable. Then, we use a case statement within a always block to implement the state transition table based on the current state and the input 'in'. The output 'out' is determined by the current state. The state register is updated on the positive edge of the clock. Additionally, an asynchronous reset 'areset' is implemented to reset the FSM to state A when asserted.
