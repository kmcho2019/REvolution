To implement this Moore state machine, we first define an enumeration of the four states A, B, C, and D. We use a parameter to define the number of states for the purpose of determining the size of the state register. We then implement a state register that is updated on the positive edge of the clock. The next state logic is implemented using a combinational logic block that takes the current state and the input 'in' as inputs. The output is determined solely by the current state. The FSM also includes an asynchronous reset that resets the state to A when 'areset' is high.
