To implement the Lemming's behavior, we will design a Moore state machine with the following states: WALK_LEFT, WALK_RIGHT, FALLING, and DIGGING. We will use a state register to store the current state and a next state logic to determine the next state based on the current state and the inputs. We will also use a register to store the previous direction (left or right) when the Lemming is falling or digging, so that it can resume walking in the same direction when it hits the ground again.
