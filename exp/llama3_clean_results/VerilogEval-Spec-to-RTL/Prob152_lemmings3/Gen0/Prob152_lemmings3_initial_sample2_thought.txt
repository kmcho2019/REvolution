To implement the Lemmings' behavior as a Moore state machine, we need to define the states and transitions based on the given conditions. The states can be defined as follows:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.

The transitions between these states will be based on the input signals (bump_left, bump_right, ground, dig). We will use areset to reset the state machine to the WALK_LEFT state.

We will also need to keep track of the previous walking direction when the Lemming is falling or digging, so it can resume walking in the same direction when it hits the ground again.
