To implement the Lemming behavior, we need to design a Moore state machine with the following states: 
- walking_left
- walking_right
- falling
- digging

The state machine will have transitions based on the input signals: bump_left, bump_right, ground, and dig. 
- When the Lemming is walking and hits an obstacle, it will switch directions.
- When the ground disappears, the Lemming will fall.
- When the Lemming is walking and dig is asserted, it will start digging.
- When the Lemming is digging and the ground disappears, it will fall and then resume walking in its original direction.

We will use a parameterized enum to define the states and a case statement to implement the state machine's combinational logic.
