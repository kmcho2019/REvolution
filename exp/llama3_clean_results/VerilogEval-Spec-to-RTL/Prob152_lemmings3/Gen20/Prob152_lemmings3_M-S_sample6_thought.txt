To simplify the solution, we'll focus on reducing the number of states and the complexity of the combinational logic. We'll use a single state machine that encodes both the state and direction, eliminating the need for separate enums and variables. We'll also simplify the output logic by directly assigning the output values based on the state and direction, reducing the number of combinational logic gates.

The simplified state machine will have the following states:
- WALK_LEFT: Walking left
- WALK_RIGHT: Walking right
- FALLING: Falling
- DIGGING_LEFT: Digging left
- DIGGING_RIGHT: Digging right

We'll use a single `always_ff` block to handle the sequential logic and a single `always_comb` block to determine the next state and output values.
