The novel architectural idea involves implementing the Lemming's behavior using a hierarchical finite state machine (HFSM). The HFSM consists of two main levels: the top-level state machine and the sub-state machines. The top-level state machine manages the overall states of the Lemming, such as walking, falling, and digging. The sub-state machines handle the specific behaviors within each state, like walking direction and digging status.

This approach allows for a more modular and scalable design, making it easier to add or modify behaviors without affecting the entire system. Additionally, the HFSM enables a more efficient use of resources, as each sub-state machine can be optimized independently.

The top-level state machine will have three main states: walking, falling, and digging. The walking state will have two sub-states: walking left and walking right. The falling state will have one sub-state: falling. The digging state will have one sub-state: digging.

The sub-state machines will handle the specific behaviors, such as changing walking direction when bumped, starting to dig when the dig signal is high, and falling when the ground signal is low.

This hierarchical approach will simplify the design, reduce the number of transitions, and improve the overall efficiency of the system.
