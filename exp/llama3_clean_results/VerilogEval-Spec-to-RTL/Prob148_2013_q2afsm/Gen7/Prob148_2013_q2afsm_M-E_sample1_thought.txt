The goal is to implement a Finite State Machine (FSM) that acts as an arbiter circuit, controlling access to a resource for three requesting devices. The FSM should prioritize device 0 over device 1 and device 1 over device 2. To simplify the design, we can use a priority encoder to determine the next state directly based on the input requests. This approach eliminates the need for explicit case statements for each state, reducing the complexity of the combinational logic.

The proposed architecture consists of a priority encoder that generates the next state based on the input requests, a state register to store the current state, and a set of continuous assignments to generate the output grants. The priority encoder will set the next state to the highest-priority requesting device. If a device is already granted access, it will continue to receive the grant as long as it maintains its request.

This design minimizes the number of logic gates and reduces unnecessary switching activity, which can help improve the power and area metrics.
