To implement the TopModule, we need to design a down-counter that can be loaded with a 10-bit value. The counter should decrement on every clock cycle unless it is being loaded. The loading of the counter should take priority over the decrement operation. When the counter reaches zero, it should stop counting and assert the tc signal until it is loaded again.

We will use a single 10-bit register to store the count value. The register will be loaded with the data input when the load signal is high. When the load signal is low, the register will decrement its value by 1 on each positive clock edge.

We will also use a single D flip-flop to store the terminal count (tc) signal. The tc signal will be set high when the count value reaches zero and will remain high until the counter is loaded again.
