To implement a countdown timer, we can utilize a finite state machine (FSM) approach that encapsulates the functionality of loading the counter and decrementing it. The FSM will have two main states: an idle state where the timer is loaded with the specified duration, and a counting state where the timer decrements until it reaches zero. The FSM will ensure that the counter is loaded only when the `load` signal is high and will start decrementing the counter when `load` is low. Once the counter reaches zero, it will remain in that state until the `load` signal is asserted again, loading a new duration into the counter.

This approach allows for a more centralized control over the timer's operation, potentially simplifying the logic and reducing area consumption. The use of an FSM also makes it easier to visualize and manage the different states and transitions of the timer, improving maintainability.

The key components of this design will include:
1. A state register to keep track of the current state (idle or counting).
2. A counter register to hold the current countdown value.
3. Logic to control the transition between states based on the `load` signal.
4. Logic to decrement the counter when in the counting state.

By organizing the design around an FSM, we can create a coherent and efficient countdown timer that meets the specified requirements while potentially offering improvements in terms of area and power consumption compared to other approaches.
