To implement the TopModule, we need to design a state machine that tracks the current water level and the previous level to determine the flow rate. The state machine will have four possible states corresponding to the four regions of the water level: above s[2], between s[2] and s[1], between s[1] and s[0], and below s[0]. The state machine will also track the previous state to determine if the water level is rising or falling. Based on the current state and the previous state, the state machine will assert the corresponding flow rate outputs. 
We will use a Moore machine state machine where the outputs are a function of the current state only.
We will also implement an active-high synchronous reset that resets the state machine to a state equivalent to if the water level had been low for a long time.
