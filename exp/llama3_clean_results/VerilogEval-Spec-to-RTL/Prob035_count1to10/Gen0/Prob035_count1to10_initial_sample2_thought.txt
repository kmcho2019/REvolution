To implement a decade counter, we need to design a sequential logic circuit that counts from 1 to 10. This can be achieved using a 4-bit register to store the current count. We'll use a synchronous reset to reset the counter to 1 when the reset signal is active high. On each positive clock edge, we'll increment the counter by 1, wrapping around to 1 after reaching 10. This requires a conditional statement to handle the wrap-around logic.
