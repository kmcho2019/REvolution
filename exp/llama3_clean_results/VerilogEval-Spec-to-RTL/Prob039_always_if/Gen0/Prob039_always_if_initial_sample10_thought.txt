The TopModule will have two 2-to-1 multiplexers implemented in different ways. 
The first multiplexer will use continuous assignment to select between inputs a and b based on the values of sel_b1 and sel_b2. 
The second multiplexer will use a procedural if statement within an always block to achieve the same functionality. 
In both cases, the multiplexer will choose input b only if both sel_b1 and sel_b2 are true; otherwise, it will choose input a.
