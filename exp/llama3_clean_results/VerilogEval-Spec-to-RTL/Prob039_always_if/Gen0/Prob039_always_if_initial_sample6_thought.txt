To implement the 2-to-1 mux, we need to use the sel_b1 and sel_b2 signals to control the selection between a and b. When both sel_b1 and sel_b2 are true (i.e., sel_b1 && sel_b2), we should choose b; otherwise, we should choose a. We will achieve this using both continuous assignment and a procedural if statement in an always block.
