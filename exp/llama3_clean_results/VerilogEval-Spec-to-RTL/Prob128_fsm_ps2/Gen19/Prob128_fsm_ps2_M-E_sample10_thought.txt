One novel architectural idea is to use a shift register to store the last three bytes received from the input stream. This approach allows us to easily check if the first byte of the current message has in[3]=1 and to signal done when the third byte of the message is received. The shift register will be updated on every clock cycle, shifting the current byte into the register and discarding the oldest byte. We can then use combinational logic to check if the first byte in the register has in[3]=1 and if we have received three bytes since then. If both conditions are met, we can assert the done signal.
