The new approach involves designing a finite state machine (FSM) with a counter to track the number of bytes received since the last message boundary was detected. The FSM starts in an idle state, searching for a byte with in[3] = 1, which indicates the start of a message. Once this byte is found, the FSM transitions to a counting state, where it increments the counter for each subsequent byte received. When the counter reaches 3, indicating that all three bytes of the message have been received, the FSM signals 'done' in the next cycle and resets the counter to search for the next message boundary. The FSM also includes a reset state, where it returns to the idle state upon receiving a reset signal.
