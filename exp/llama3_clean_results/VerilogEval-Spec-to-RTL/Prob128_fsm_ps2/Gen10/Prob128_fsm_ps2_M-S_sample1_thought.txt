The second state will be the message reception state, where we count the bytes received after the start byte.

Here's a simplified thought process:

1.  **Initialize State:** Start in the idle state, waiting for a byte with in[3]=1.
2.  **Detect Start Byte:** When a byte with in[3]=1 is received, transition to the message reception state and initialize a byte counter to 1.
3.  **Count Bytes:** In the message reception state, increment the byte counter for each byte received.
4.  **Signal Done:** When the byte counter reaches 3, signal 'done' high for one clock cycle and then reset to the idle state, ready to detect the start of the next message.
5.  **Reset:** If the reset signal is asserted, immediately return to the idle state.
