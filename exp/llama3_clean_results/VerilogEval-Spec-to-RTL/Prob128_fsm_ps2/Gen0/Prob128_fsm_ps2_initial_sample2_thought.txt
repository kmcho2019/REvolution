To implement the TopModule, we will create a finite state machine (FSM) that can be in one of four states: IDLE, BYTE1, BYTE2, or BYTE3. The FSM will start in the IDLE state and transition to BYTE1 when it receives a byte with in[3]=1. It will then transition to BYTE2 and BYTE3 as it receives the next two bytes. After receiving the third byte, it will signal 'done' and return to the IDLE state, ready to search for the next message. The FSM will also be reset to the IDLE state when the 'reset' signal is high.
