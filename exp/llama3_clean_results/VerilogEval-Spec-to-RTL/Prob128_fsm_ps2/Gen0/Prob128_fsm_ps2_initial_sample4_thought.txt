To solve this problem, we can design a finite state machine (FSM) with four states: 
- IDLE: The initial state where we discard bytes until we see one with in[3]=1.
- BYTE1: The state after we have received the first byte of a message.
- BYTE2: The state after we have received the second byte of a message.
- DONE: The state where we signal the receipt of a message once all 3 bytes have been received.

We will use a counter to keep track of the current byte and transition between states accordingly. 
When reset is high, the FSM will return to the IDLE state and the done signal will be deasserted.
