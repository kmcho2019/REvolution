To implement the required functionality, we'll create a finite state machine (FSM) within the TopModule. The FSM will have states to track the receipt of bytes in a message. We'll initialize to a state where we're searching for the first byte of a message (in[3]=1). Once this byte is found, we'll transition through states to receive the second and third bytes, finally signaling 'done' when all three bytes are received. We'll handle the reset condition to restart this process.
