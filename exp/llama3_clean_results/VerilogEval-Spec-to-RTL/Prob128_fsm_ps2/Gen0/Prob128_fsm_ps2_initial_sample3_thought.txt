The TopModule will be designed as a finite state machine (FSM) that operates on the principle of searching for message boundaries within a continuous byte stream. The FSM will start in an idle state, discarding bytes until it encounters a byte with in[3] = 1, which it assumes to be the start of a message (byte 1). It will then transition through states representing the receipt of byte 2 and byte 3 of the message. Once it has received all three bytes, it will signal done in the next cycle and reset its state to search for the next message boundary. The FSM will also have a reset state, where upon receiving a reset signal (active high), it will return to its initial idle state, discarding any partially received messages.
