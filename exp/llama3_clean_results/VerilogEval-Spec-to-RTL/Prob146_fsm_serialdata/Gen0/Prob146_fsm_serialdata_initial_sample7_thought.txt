To solve this problem, we will implement a finite state machine (FSM) in Verilog. The FSM will have the following states:
- IDLE: The initial state where the FSM waits for a start bit (0).
- START: The state after a start bit has been detected, where the FSM prepares to receive the data bits.
- DATA: The state where the FSM receives the 8 data bits. It will shift the received bits into a register and wait for all 8 bits to be received.
- STOP: The state where the FSM checks if the stop bit is correct. If it is, the FSM outputs the received byte and asserts the done signal. If not, the FSM goes back to the IDLE state to wait for a stop bit.
- WAIT_FOR_STOP: The state where the FSM waits for a stop bit before going back to the IDLE state.

The FSM will be implemented using a case statement to handle the different states and a register to store the current state. The received byte will be stored in a separate register. The FSM will be reset to the IDLE state when the reset signal is asserted.
