To model the Lemmings' behavior, we will implement a Moore state machine with three states: walking left, walking right, and falling. The state machine will transition between walking left and right based on the bump_left and bump_right inputs. If the ground input is 0, the state machine will enter the falling state and assert the aaah output. The state machine will reset to the walking left state when the areset input is asserted. 
We will use two bits to represent the three states. 
- State 0 (00) represents the walking left state.
- State 1 (01) represents the walking right state.
- State 2 (10) represents the falling state.
- State 3 (11) is an unused state.

The next state logic will be based on the current state and the bump_left, bump_right, and ground inputs. The output logic will be based on the current state and the ground input.

When the ground input is 1, the state machine will transition between walking left and right based on the bump_left and bump_right inputs. When the ground input is 0, the state machine will enter the falling state.

When the state machine is in the falling state, it will remain in this state until the ground input becomes 1, at which point it will transition back to the previous walking state.
