To implement a decade counter, we can use a 4-bit counter since we need to count from 0 to 9. We will use a synchronous reset to reset the counter to 0 when the reset signal is high. We will compare the count value to 9 and when it reaches 10 (in binary, this is when we go from 9 to 10, the count will roll over from 1001 to 1010), we reset it back to 0 (in binary 0000). However, since the reset is active high synchronous and is used to reset the counter, it should take precedence over the normal counting operation, and reset the counter to 0 when asserted.
