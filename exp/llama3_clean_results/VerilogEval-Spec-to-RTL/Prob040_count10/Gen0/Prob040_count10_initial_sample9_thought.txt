To implement a decade counter, we need to keep track of the current count and increment it on each clock cycle until we reach the maximum count of 9. When the count reaches 9, it should wrap around to 0 on the next clock cycle. We can use a 4-bit register to store the current count, as we only need to count up to 9. The reset signal should be used to asynchronously reset the counter to 0. However, since the reset is specified as synchronous, we will use the reset signal in conjunction with the clock signal to reset the counter.
