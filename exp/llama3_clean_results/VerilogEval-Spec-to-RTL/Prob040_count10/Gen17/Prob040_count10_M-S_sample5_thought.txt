To simplify the decade counter, we can maintain the same basic approach of using a binary up-counter but reduce the conditional checks. The current implementation checks for the reset condition and then for the counter reaching its maximum value (9) separately. We can simplify this by directly checking if the counter should be reset (either due to the reset signal or reaching 9) and then incrementing it otherwise.
