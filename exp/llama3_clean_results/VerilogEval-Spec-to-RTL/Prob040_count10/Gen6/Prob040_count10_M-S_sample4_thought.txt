When the count reaches 10 (which is 4'b1010 in binary), it wraps around to 0. The reset input can be used to reset the count to 0 synchronously.

This approach reduces the complexity of the original solution by eliminating the need for a case statement with multiple conditions. Instead, it uses a simple arithmetic operation to increment the count and a conditional statement to wrap around to 0 when necessary.
