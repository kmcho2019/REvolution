To create a novel solution, we will utilize a Look-Up Table (LUT) based approach. This involves treating the inputs as an address to a memory location that stores the corresponding output. In this case, since we have three inputs (a, b, c), we can use a 2^3 = 8-entry LUT. Each entry in the LUT will correspond to one of the possible combinations of a, b, and c, and will store the output value for that combination as determined by the Karnaugh map. This approach can be particularly efficient in FPGAs, where LUTs are a fundamental component.

By using a LUT, we essentially 'hardcode' the truth table into the hardware, allowing for fast and straightforward implementation of the logic. This method can be beneficial when the logic is complex or when the design needs to be implemented on a specific type of hardware that favors LUT-based implementations.
