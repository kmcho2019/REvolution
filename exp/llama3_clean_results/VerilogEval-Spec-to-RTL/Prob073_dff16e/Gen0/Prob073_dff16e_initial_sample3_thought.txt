To implement the TopModule, we will use 16 D flip-flops to store the 16-bit input data d. We will use the byteena inputs to control whether each byte of the 16 registers should be written to on that cycle. If byteena[0] is high, we will update the lower byte of the registers (q[7:0]) with the lower byte of the input data (d[7:0]). If byteena[1] is high, we will update the upper byte of the registers (q[15:8]) with the upper byte of the input data (d[15:8]). The resetn input will be used to reset all the flip-flops synchronously when it is low. All DFFs will be triggered by the positive edge of clk.
