A novel architectural idea for reversing the bit ordering of a 100-bit input vector is to utilize a shift register approach. The concept involves shifting the input bits into a series of flip-flops arranged in a line, and then shifting the bits out in reverse order to produce the output. This can be achieved by using two shift registers: one for loading the input bits and another for shifting out the bits in reverse order. However, a more efficient approach would be to use a single shift register and shift the bits in a circular manner, effectively reversing the order of the bits. This idea minimizes the number of components required and can be implemented using a single clock signal.
