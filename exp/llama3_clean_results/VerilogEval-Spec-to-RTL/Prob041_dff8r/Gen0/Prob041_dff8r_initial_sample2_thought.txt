To implement the TopModule, we need to create a module that contains 8 D flip-flops (DFFs). Each DFF should have a data input (d), a clock input (clk), and an active high synchronous reset input (reset). The output of each DFF will be a part of the 8-bit output vector (q). When the reset signal is high, all DFFs should be reset to zero on the next positive edge of the clock. We can achieve this using Verilog's built-in always block to describe the behavior of the DFFs and the reset logic.
