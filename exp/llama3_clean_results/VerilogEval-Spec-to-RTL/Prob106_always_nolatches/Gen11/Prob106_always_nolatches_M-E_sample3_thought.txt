Moreover, to further improve the design, we can leverage parameterized modules to reduce code duplication. Each arrow key module can be an instance of a generic "scancode_checker" module, which takes the target scancode as a parameter. This approach minimizes the amount of code that needs to be written and maintained, making the design more efficient and easier to understand.
