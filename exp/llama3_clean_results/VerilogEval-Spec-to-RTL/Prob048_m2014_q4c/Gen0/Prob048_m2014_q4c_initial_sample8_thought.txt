To implement a simple D flip flop with active high synchronous reset, we need to use a sequential always block that is sensitive to the clock edge and the reset signal. Inside the block, we check if the reset signal is high, and if so, we reset the output q to 0. If the reset signal is not high, we assign the input d to the output q on the rising edge of the clock. This ensures that the output q follows the input d when the reset signal is not active.
