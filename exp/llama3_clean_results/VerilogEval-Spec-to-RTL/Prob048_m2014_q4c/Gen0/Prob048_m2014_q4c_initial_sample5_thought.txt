To implement a D flip flop with active high synchronous reset, we will use the following approach: 
1. Use a reg variable to store the output of the flip flop.
2. On every positive clock edge (posedge clk), check if the reset signal (r) is high.
3. If the reset signal is high, reset the output (q) to 0. 
4. If the reset signal is low, update the output (q) with the input (d).
This way, the output will only be updated on the positive clock edge and the reset will be synchronous.
