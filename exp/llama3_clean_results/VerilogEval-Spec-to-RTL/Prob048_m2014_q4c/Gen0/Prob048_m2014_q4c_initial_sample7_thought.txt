To implement a simple D flip-flop with active high synchronous reset, we will use a basic flip-flop structure where the output (q) is updated on the rising edge of the clock (clk) based on the current value of the input (d) and the reset signal (r). If the reset signal (r) is high, the output (q) should be reset to 0 regardless of the input (d) and the previous state. This can be achieved using a non-blocking assignment inside a clocked always block in Verilog.
