This can be achieved using an always block in Verilog that is sensitive to the clock 'clk' and the reset 'r'. Inside the always block, we first check if the reset 'r' is high, and if so, we set 'q' to 0. If 'r' is not high, we then check if there is a rising edge on 'clk', and if so, we set 'q' to the current value of 'd'.
