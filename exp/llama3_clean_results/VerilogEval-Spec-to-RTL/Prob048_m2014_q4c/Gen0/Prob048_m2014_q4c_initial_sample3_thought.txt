To implement a simple D flip flop with active high synchronous reset, we can use a basic sequential logic design. The D flip flop will store the input value 'd' on the rising edge of the clock 'clk' if the reset 'r' is not active. If the reset 'r' is active, the output 'q' will be reset to 0 on the next rising edge of the clock 'clk', regardless of the value of 'd'.
