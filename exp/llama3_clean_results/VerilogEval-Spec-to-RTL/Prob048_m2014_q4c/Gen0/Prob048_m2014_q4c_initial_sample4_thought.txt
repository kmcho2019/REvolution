To implement a simple D flip flop with active high synchronous reset, we will use a single always block in Verilog that is sensitive to the clock edge. Inside this block, we will first check if the reset signal 'r' is high. If it is, we will reset the output 'q' to 0. If 'r' is low, we will update the output 'q' with the input 'd' at the positive edge of the clock.
