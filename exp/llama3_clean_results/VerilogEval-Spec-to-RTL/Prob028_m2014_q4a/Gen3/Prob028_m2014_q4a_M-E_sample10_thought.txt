To implement a D latch using an `always` block, we can leverage the concept of a Level-Sensitive Latch. The idea is to use the `always` block to continuously monitor the `ena` signal and update the output `q` accordingly. When `ena` is high, the latch is transparent, and the output `q` follows the input `d`. When `ena` is low, the latch retains its previous value. This can be achieved by using a non-blocking assignment (`<=`) inside the `always` block to update the output `q` based on the current value of `ena` and `d`.
