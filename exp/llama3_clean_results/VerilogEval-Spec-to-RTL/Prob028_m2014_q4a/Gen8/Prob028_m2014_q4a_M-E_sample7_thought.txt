To implement a D latch using an always block, we can utilize a simple sequential logic approach. The idea is to use the always block to continuously monitor the enable signal `ena` and the input `d`. When `ena` is high, the output `q` should follow the input `d`. When `ena` is low, the output `q` should retain its previous value. This behavior can be achieved by using a non-blocking assignment (`<=`) within the always block to update the output `q` only when `ena` is high.
