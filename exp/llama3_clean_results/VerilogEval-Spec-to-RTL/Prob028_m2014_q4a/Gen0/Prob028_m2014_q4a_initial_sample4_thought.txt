To implement a D latch using an always block in Verilog, we need to check the enable signal (ena) and only update the output (q) when ena is high. When ena is low, the output should retain its previous value. This behavior can be achieved by using a conditional statement within the always block to assign the input (d) to the output (q) when ena is high, and to assign the current value of q back to q when ena is low, effectively holding the previous state.
