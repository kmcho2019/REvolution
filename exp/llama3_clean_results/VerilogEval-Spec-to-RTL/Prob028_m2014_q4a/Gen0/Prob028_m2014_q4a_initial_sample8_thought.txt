To implement a D latch, we need to use an always block that is sensitive to the clock (in this case, the 'ena' signal) and the input 'd'. When 'ena' is high, the output 'q' should be updated with the value of 'd'. When 'ena' is low, the output 'q' should retain its previous value. This can be achieved by using a non-blocking assignment to 'q' when 'ena' is high.
