To implement a D latch using an always block in Verilog, we need to use the sensitivity list to trigger the block when either the 'd' input or the 'ena' (enable) input changes. When 'ena' is high, the output 'q' should follow the input 'd'. When 'ena' is low, the output 'q' should retain its previous value. This can be achieved by using a conditional statement within the always block to assign the value of 'd' to 'q' when 'ena' is high, and to keep 'q' unchanged when 'ena' is low.
