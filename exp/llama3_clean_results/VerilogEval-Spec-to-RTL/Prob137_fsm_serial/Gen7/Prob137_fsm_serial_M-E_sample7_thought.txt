1. Start Bit Detector (SBD): This module will detect the start bit and trigger the accumulation of the incoming bits.

3. Stop Bit Verifier (SBV): This module will verify the stop bit and generate the 'done' signal if the stop bit is correct.
4. Programmable Delay Line (PDL): This module will align the incoming bits with the expected start and stop bits.
