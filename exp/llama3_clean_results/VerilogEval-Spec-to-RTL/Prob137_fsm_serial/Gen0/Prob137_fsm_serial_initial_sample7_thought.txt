To implement the serial byte receiver, we can design a finite state machine (FSM) with the following states:
1. IDLE: The initial state where the FSM waits for the start bit (0) to initiate the reception of a byte.
2. START_BIT: After detecting the start bit, the FSM transitions to this state and starts counting the 8 data bits.
3. DATA_BITS: In this state, the FSM collects the 8 data bits. It does not store the bits but rather checks for the stop bit after the 8th bit.
4. STOP_BIT: After receiving the 8 data bits, the FSM transitions to this state and checks for the stop bit (1).
If the stop bit is correct, it goes back to the IDLE state and sets the 'done' signal high for one clock cycle to indicate the successful reception of a byte.
If the stop bit is incorrect, it goes back to the IDLE state and waits for the next start bit.
We will use two counters, one for the data bits and one to handle the case when the stop bit does not appear when expected.

The FSM will be designed using a Moore machine style where the outputs are a function of the state only.
