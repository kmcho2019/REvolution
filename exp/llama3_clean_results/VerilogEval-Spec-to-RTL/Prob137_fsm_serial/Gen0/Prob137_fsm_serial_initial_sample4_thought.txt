To implement the required finite state machine (FSM), we can break it down into several states:
1. IDLE: This is the initial state where the FSM waits for a start bit (0).
2. START: Once a start bit is detected, the FSM moves to this state and waits for 8 clock cycles to receive the data bits.
3. STOP: After receiving the 8 data bits, the FSM moves to this state to verify the stop bit (1). If the stop bit is not received, it will loop back to the IDLE state until a stop bit is found.
We will also need to handle the reset condition, which should bring the FSM back to the IDLE state.
The 'done' signal will be asserted when a complete byte is successfully received.
