To implement the finite state machine for the serial communication protocol, 
we'll define several states: IDLE, START_BIT, DATA_BITS, and STOP_BIT. 
In the IDLE state, the FSM waits for the start bit (0). 
Once the start bit is detected, it transitions to the START_BIT state, 
then waits for 8 data bits in the DATA_BITS state. 
After receiving all 8 data bits, it checks for the stop bit (1) in the STOP_BIT state. 
If the stop bit is correct, it signals that a byte has been received (done) 
and returns to the IDLE state. 
If the stop bit is incorrect, it waits until a stop bit is detected before returning to the IDLE state.
We'll use a counter to keep track of the number of data bits received.
