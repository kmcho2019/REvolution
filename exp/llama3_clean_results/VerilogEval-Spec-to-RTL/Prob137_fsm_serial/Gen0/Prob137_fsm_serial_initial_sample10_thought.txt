1. The IDLE state will be the initial state where the FSM waits for the start bit (0) to begin receiving a byte.
2. The START state will be entered when a start bit is detected. The FSM will then wait for 8 clock cycles to receive the 8 data bits.
3. The DATA state will be entered after the start bit and will count down the 8 clock cycles for receiving the data bits. The received data bits will be stored in a register.
4. The STOP state will be entered after receiving the 8 data bits. The FSM will then check the stop bit. If the stop bit is correct (1), the FSM will assert the done signal and return to the IDLE state. If the stop bit is incorrect (0), the FSM will wait until a stop bit (1) is detected before returning to the IDLE state.
