The IDLE state will wait for the start bit, the START state will ensure the start bit is correct, the RECEIVE state will collect the incoming data bits, and the STOP state will verify the stop bit. 

To optimize the design, the counter will be reset only when a start bit is detected, and the shift register will be updated only in the RECEIVE state. 

Additionally, to reduce power consumption, the design will use a single always block and minimize unnecessary updates to the shift register and counter.

The DONE signal will be asserted only when the stop bit is correct and the byte has been fully received.
