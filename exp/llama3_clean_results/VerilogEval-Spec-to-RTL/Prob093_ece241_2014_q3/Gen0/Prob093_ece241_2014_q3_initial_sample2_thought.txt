The Karnaugh map can be simplified by creating four separate functions for each possible value of the 'ab' inputs. Each of these functions can be derived from the corresponding row in the Karnaugh map and implemented using a 2-to-1 multiplexer if necessary. 
For ab=00, the function is d'. 
For ab=01, the function is d + c'. 
However, to implement this expression using a 2-to-1 multiplexer, we can use 'c' as the select line and 'd' and 0 as the two inputs. 
For ab=10, the function is d + c. 
Similarly, this can be implemented using 'c' as the select line and 'd' and 1 as the two inputs. 
For ab=11, the function is d'.
This is also straightforward, using 'c' as the select line is not necessary in this case.
