A novel architectural approach to detect any edge in an 8-bit input vector involves utilizing a shift register to track the previous state of the input. This method allows for a more distributed and potentially area-efficient design. Instead of directly comparing the current input with the previous one, we can use a shift register to shift the current input into the register at each clock cycle, effectively creating a history of the input's previous state. Then, we compare each bit of the current input with its corresponding bit in the shifted register to detect any edge.

This approach simplifies the logic required for edge detection, as it eliminates the need for explicit storage of the previous input state. It also distributes the computation across multiple clock cycles, potentially leading to better timing and area efficiency in certain technologies.

However, the main challenge with this approach is ensuring that the shift register is properly initialized and that the edge detection logic correctly interprets the shifted bits. The use of a shift register adds complexity in terms of managing the register's state but can offer advantages in specific implementation contexts.

Our novel idea involves designing a module that uses a shift register to track the input history and then uses this history to detect any edges in the input signal. This method could potentially offer better PPA metrics than traditional approaches, especially in technologies where shift registers are efficiently implemented.
