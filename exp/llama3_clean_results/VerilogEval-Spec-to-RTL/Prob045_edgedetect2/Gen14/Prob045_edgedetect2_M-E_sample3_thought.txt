The novel architectural idea for the edge detection module involves utilizing a shift register to store the previous state of the input vector. This approach eliminates the need for separate registers to store the current and previous states, reducing the area consumption. The shift register is updated at each positive edge of the clock, shifting the current state one position to the right and inserting the new input at the leftmost position. The edge detection is then performed by comparing the new input with the rightmost bit of the shift register, which represents the previous state. This comparison is done using an XOR operation, and the result is used to generate the output.

This approach not only reduces the area consumption but also simplifies the sequential logic, making it more efficient and easier to implement. The use of a shift register also allows for a more straightforward and intuitive implementation of the edge detection functionality.
