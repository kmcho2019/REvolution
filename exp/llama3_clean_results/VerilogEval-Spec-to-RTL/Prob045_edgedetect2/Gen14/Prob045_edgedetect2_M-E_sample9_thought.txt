To implement a novel edge detection module, we can utilize a different architectural approach that focuses on leveraging the benefits of shift registers to capture the previous state of the input vector. This method eliminates the need for explicit registers to store the current and previous states, instead using a shift register to naturally capture the history of the input signal.

The key idea involves creating an 8-bit shift register that shifts in the new input value at each clock cycle, effectively storing the previous state of the input vector within the shift register. Then, we perform a bitwise XOR operation between the current input and the output of the shift register (which represents the previous state) to detect edges. This approach simplifies the logic and potentially reduces the area and power consumption compared to traditional methods that require explicit registers for storing previous states.
