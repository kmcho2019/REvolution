To detect any edge (0 to 1 or 1 to 0 transition) on each bit of the 8-bit input vector, we can store the previous state of the input vector in a register and compare it with the current state at each clock cycle. We can use the XOR operation to compare the current and previous states. If the result of the XOR operation is 1 for any bit, it means that there is a transition (either 0 to 1 or 1 to 0) on that bit. We will then set the corresponding output bit in the anyedge vector to 1.
