To simplify the existing solution, we can directly use the input `in` and the stored previous state `prev_state` to detect any edge, eliminating the need for the intermediate `curr_state` register. This approach reduces the number of registers and the complexity of the design without compromising its functionality. By directly comparing the current input with the previous state, we can detect any edge (transition from 0 to 1 or 1 to 0) and update the `anyedge` output accordingly.
