To simplify the existing solution, we can eliminate the need for an explicit register to store the previous value of each bit. Instead, we can use the fact that the output of the XOR gate is registered and presented as the output of the stage, effectively providing the previous value for the next clock cycle. By directly using the current input and the registered output from the previous cycle, we can detect any edge without needing a separate register for each bit. This approach reduces the complexity of the design and should improve the overall Power, Performance, and Area (PPA) metrics.
