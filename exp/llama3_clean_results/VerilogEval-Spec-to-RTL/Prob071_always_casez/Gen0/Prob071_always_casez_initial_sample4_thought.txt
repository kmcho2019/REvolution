To implement a priority encoder for an 8-bit input, we need to find the first bit that is '1' from the least significant bit. We can do this by checking each bit from the least significant bit to the most significant bit. If a '1' is found, we immediately output its position. If no '1' is found, we output 0.

We can use a simple iterative approach to check each bit and generate the output based on the position of the first '1' encountered.
