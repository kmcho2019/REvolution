The existing implementation uses the equality operator (`==`) to achieve the XNOR functionality. To simplify this solution, we can leverage basic logical operators to directly express the XNOR operation without using the equality operator. The XNOR operation between two bits `a` and `b` can be expressed as `!(a ^ b)`, where `^` represents the XOR operation and `!` represents the logical NOT operation. By using this expression, we can maintain the functionality while potentially reducing complexity.
