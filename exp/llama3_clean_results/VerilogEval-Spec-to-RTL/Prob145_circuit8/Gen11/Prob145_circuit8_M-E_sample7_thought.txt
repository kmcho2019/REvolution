Transitions between these states can be triggered by the rising edge of the clock and the value of the input a. This way, we can precisely control the output behavior based on the input and the clock signal, ensuring that the module functions as specified in the simulation waveforms.

By using an FSM, we can also simplify the logic for updating p and q, as the transitions between states dictate the output values.
