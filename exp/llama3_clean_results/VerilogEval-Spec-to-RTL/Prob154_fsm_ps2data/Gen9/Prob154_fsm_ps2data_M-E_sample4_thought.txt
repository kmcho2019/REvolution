To develop a novel architectural idea, we will consider a different approach to the finite state machine (FSM) implementation. Instead of using a traditional FSM with explicit states, we can utilize a counter-based approach. This method involves using a counter to keep track of the number of bytes received and a register to store the current message.

The main components of this architecture will be:

1. A counter (`byte_counter`) to keep track of the number of bytes received.
2. A register (`message_register`) to store the current message.
3. A control logic to manage the counter, register, and output signals.

The control logic will be responsible for checking the input byte, incrementing the counter, and updating the message register accordingly. When the counter reaches 3, it will assert the `done` signal and output the message.

This approach simplifies the FSM logic and reduces the number of states, making it more efficient and easier to implement.
