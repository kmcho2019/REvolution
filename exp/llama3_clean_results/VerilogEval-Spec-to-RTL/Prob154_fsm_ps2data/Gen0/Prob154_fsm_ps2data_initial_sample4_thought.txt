To implement the finite state machine for the TopModule, we need to design a state machine with four states: Idle, Byte1, Byte2, and Done. 
1. In the Idle state, the machine waits for a byte with in[3] = 1 and stays in this state until it finds one. 
2. Once it finds a byte with in[3] = 1, it moves to the Byte1 state and stores the byte.
3. In the Byte1 state, the machine waits for the next byte and moves to the Byte2 state, storing this byte.
4. In the Byte2 state, the machine waits for the next byte and moves to the Done state, storing this byte and signaling that a message has been received (done = 1).
5. The machine then moves back to the Idle state, ready to receive the next message.
6. The out_bytes output should be updated in the Done state with the three received bytes.
