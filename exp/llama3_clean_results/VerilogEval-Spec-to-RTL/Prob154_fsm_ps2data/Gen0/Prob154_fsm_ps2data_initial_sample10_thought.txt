To implement the finite state machine in the TopModule, we can define three states: IDLE, RECV_BYTE1, and RECV_BYTE2. 
In the IDLE state, the module will continuously check the input byte stream for a byte with in[3]=1. 
Once such a byte is received, it will transition to the RECV_BYTE1 state and store this byte. 
Then, it will transition to the RECV_BYTE2 state, store the next byte, and finally store the third byte. 
After receiving the third byte, it will signal done in the next clock cycle and output the 24-bit message.
We will use two 8-bit registers, byte1 and byte2, to store the first two bytes of the message, and a 24-bit register, out_bytes_reg, to store the complete 24-bit message.
The reset signal will reset all registers and the state to IDLE.
