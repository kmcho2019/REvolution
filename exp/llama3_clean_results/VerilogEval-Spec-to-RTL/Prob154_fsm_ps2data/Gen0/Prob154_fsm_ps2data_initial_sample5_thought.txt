The module TopModule will be implemented as a finite state machine with four states: IDLE, BYTE1, BYTE2, and DONE. The IDLE state will be the initial state, where the module waits for a byte with in[3]=1. Once such a byte is received, the module will transition to the BYTE1 state and store the received byte. In the BYTE1 state, the module will wait for the next byte and store it. The module will then transition to the BYTE2 state. In the BYTE2 state, the module will wait for the next byte and store it. Once the third byte is received, the module will transition to the DONE state and assert the done signal. The module will then return to the IDLE state and wait for the next byte with in[3]=1.

The datapath module will be implemented using three registers to store the three bytes of the message. The out_bytes output will be driven by these registers.
