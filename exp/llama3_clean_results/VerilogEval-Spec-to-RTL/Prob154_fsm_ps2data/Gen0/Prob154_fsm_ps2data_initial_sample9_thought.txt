To solve this problem, we will design a finite state machine (FSM) with three states: IDLE, BYTE1, and BYTE2. The FSM will start in the IDLE state and stay there until it sees an input byte with in[3]=1. Once this condition is met, it will transition to the BYTE1 state and store the current byte. Then, it will transition to the BYTE2 state and store the next two bytes. After storing the third byte, it will signal done in the next cycle and output the 24-bit message (out_bytes). We will use registers to store the current state, the input bytes, and the output message.
