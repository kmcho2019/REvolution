To implement a shift register with four D flops, we will create a module named TopModule that includes four sequential D flip-flops. Each D flip-flop will have a synchronous, active-low reset. When the resetn signal is low, all flip-flops will reset to zero on the next positive clock edge. Otherwise, the input to each flip-flop will be the output of the previous flip-flop (except for the first flip-flop, which will be the external input in). The output of the TopModule will be the output of the last flip-flop.
