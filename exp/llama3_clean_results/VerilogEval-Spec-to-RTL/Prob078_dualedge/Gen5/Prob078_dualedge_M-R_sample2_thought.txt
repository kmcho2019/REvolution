The core idea of implementing a dual-edge triggered flip-flop using two single-edge triggered flip-flops remains the same. However, to refactor the code, we can leverage the fact that in a dual-edge triggered flip-flop, the output changes on both edges of the clock. This means we can use a single always block to capture the changes on both edges and assign the output accordingly. Instead of using separate flip-flops for positive and negative edges and then selecting the output based on the clock edge, we can directly update the output register based on the current clock edge and the input value. This approach simplifies the design and reduces the need for additional combinational logic.
