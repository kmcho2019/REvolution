A novel approach to implement a dual-edge triggered flip-flop is to utilize a single D-type flip-flop triggered on the rising edge of the clock, but with the input data being dynamically controlled based on the edge of the clock. This can be achieved by using an additional signal that indicates whether the previous clock edge was a rising or falling edge. This signal can then be used to select either the current input data or the previous input data to be used as the input for the flip-flop.
