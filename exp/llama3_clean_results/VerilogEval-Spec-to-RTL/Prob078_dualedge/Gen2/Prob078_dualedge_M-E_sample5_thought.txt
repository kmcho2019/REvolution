To create a novel architectural solution for a dual-edge triggered flip-flop, we can leverage the concept of clock edge detection and asynchronous set/reset functionality in a single flip-flop. The idea is to use a single flip-flop with asynchronous set and reset signals, where the set and reset signals are generated based on the input data and the clock edge. This approach allows for a more compact and efficient implementation compared to using two separate flip-flops for positive and negative edge triggering.

The main idea is to detect the rising and falling edges of the clock signal and use these edge detections to generate the asynchronous set and reset signals for the flip-flop. By doing so, the flip-flop can be triggered on both edges of the clock, effectively behaving like a dual-edge triggered flip-flop.

This approach has the potential to improve PPA metrics by reducing the number of flip-flops required, thus minimizing area usage and potentially lowering power consumption. Additionally, the use of asynchronous set/reset functionality can provide more flexibility in the design, allowing for easier integration with other components that may require similar functionality.
