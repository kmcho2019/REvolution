A novel approach to implement a dual-edge triggered flip-flop is to use a single flip-flop and a clock signal conditioner. The clock signal conditioner would generate a new clock signal that captures the input data on both edges of the original clock signal. This can be achieved by using an XOR gate with the original clock signal and its inverted version, and then using this conditioned signal to clock a single flip-flop. The XOR gate produces a pulse on both edges of the original clock signal, allowing the flip-flop to capture the input data on both rising and falling edges. This approach simplifies the design, reduces the number of flip-flops required, and minimizes additional logic.
