To simplify the implementation of a D flip flop that is positive edge triggered with an asynchronous reset, we can use a more straightforward approach:
1. Use a reg to hold the value of the flip flop (q).
2. In the always block, check for the asynchronous reset condition. If ar is high, immediately reset q to 0.
3. If ar is low, check for the positive edge of the clock (clk). If a rising edge is detected, update q with the current value of d.
However, instead of using a complex sensitivity list, we can use a separate reset condition to handle the asynchronous reset and then handle the clock edge inside the always block. 
We will use a non-blocking assignment to update the reg q.
