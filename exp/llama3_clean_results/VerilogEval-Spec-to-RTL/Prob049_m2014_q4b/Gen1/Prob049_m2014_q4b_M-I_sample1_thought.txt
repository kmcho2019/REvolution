The key is to understand that the `posedge` keyword is only used in the sensitivity list to specify when the block should be triggered, not within conditional statements inside the block. The asynchronous reset `ar` should directly set the state to 0 without checking for any clock edge, while the input `d` should be captured and assigned to the state only on the positive edge of the clock `clk`. This ensures that the flip-flop behaves as intended: it resets asynchronously to `ar` and captures `d` on the rising edge of `clk`.
