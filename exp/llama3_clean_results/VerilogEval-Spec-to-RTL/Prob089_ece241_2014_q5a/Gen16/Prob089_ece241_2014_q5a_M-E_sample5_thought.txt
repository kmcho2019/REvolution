Once the first '1' is detected, the machine starts shifting the bits out, inverting them as they are shifted out to produce the 2's complement.

To manage the dynamic shifting, we can employ a counter that increments with each new input bit until the first '1' is seen. After this point, the counter remains constant, indicating the length of the input number. This counter value determines when to stop shifting bits out, ensuring the correct 2's complement is generated for the input number.

This approach simplifies the logic by focusing on the primary operations: shifting, inverting, and counting. It maintains a straightforward and efficient implementation while handling input numbers of any length.
