To implement a one-input one-output serial 2's complementer Moore state machine, 
we first need to understand the steps involved in 2's complement conversion, 
which involves inverting the bits and then adding 1. 

Since this is a Moore state machine, the output depends only on the current state. 
We can design the state machine to have three states: Idle, Invert, and AddOne. 
In the Idle state, the machine waits for the reset to be released. 
Once the reset is released, it starts accepting input bits and inverts them. 
After all bits have been inverted, the machine adds 1 to the result.

However, because the machine accepts input numbers of arbitrary length and 
the conversion stops when Reset is asserted, we need a different approach. 
The machine can keep track of whether it's in the process of converting a number 
and output the inverted bits. When the machine detects that the input has stopped 
(for example, by receiving a high reset signal), it can then add 1 to the inverted 
number and output the final result. 

But a simpler approach would be to use a sequential circuit with two registers, 
one for the inverted bits and another for the final result. We start by inverting 
each input bit and storing it in the first register. After each bit is inverted, 
we check if the reset signal has been asserted. If it has, we add 1 to the inverted 
number in the second register and output the final result.

A more straightforward implementation would involve using a simple counter and 
two flip-flops. The counter keeps track of the number of bits received, the first 
flip-flop stores the inverted bits, and the second flip-flop stores the carry bit. 
On each clock cycle, the input bit is inverted and stored in the first flip-flop, 
and the carry bit is propagated to the next bit position.

The machine will need a reset signal to clear the registers when a new conversion 
is started. We'll use a positive edge triggered asynchronous reset.
