To simplify the existing solution, we can remove the explicit check for the count reaching its maximum value (999) and instead use the property of unsigned integers in Verilog, which wrap around to 0 when they exceed their maximum value. This means if we use an if statement only for the reset condition, and otherwise simply increment the count, the count will automatically wrap around to 0 when it exceeds 999 due to the properties of the binary representation and the specific width of the count register (10 bits).
