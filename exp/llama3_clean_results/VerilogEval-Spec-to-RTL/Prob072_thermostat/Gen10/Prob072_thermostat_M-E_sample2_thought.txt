The novel architectural idea here is to implement a finite state machine (FSM) to control the thermostat. The FSM will have four states: IDLE, HEATING, COOLING, and FAN_ONLY. The state transitions will be based on the input signals (mode, too_cold, too_hot, fan_on). This approach allows for a more structured and scalable design, making it easier to add new features or modify the existing behavior. The FSM will be implemented using a combination of `always` blocks for the combinational logic and a single `reg` to store the current state.
