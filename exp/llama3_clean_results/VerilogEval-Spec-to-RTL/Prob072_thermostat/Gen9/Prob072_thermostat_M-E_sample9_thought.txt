To create a novel solution, we can approach the problem from a finite state machine (FSM) perspective. The thermostat controller can be viewed as a simple FSM with two main states: heating and cooling. Within these states, it responds to conditions such as `too_cold`, `too_hot`, and `fan_on`. By structuring the logic around states and transitions, we can potentially simplify the control logic and make it more intuitive to manage complex scenarios.

The FSM will have two main states: `HEATING` and `COOLING`, determined by the `mode` input. Within each state, the outputs (`heater`, `aircon`, `fan`) are controlled based on the current state and input conditions. For example, in the `HEATING` state, if `too_cold` is true, the `heater` and `fan` should be on. In the `COOLING` state, if `too_hot` is true, the `aircon` and `fan` should be on. The `fan_on` input can override the fan's state in any condition.

This approach allows for easy expansion to more complex thermostat behaviors, such as adding more states for maintenance or energy-saving modes, and can be more modular and maintainable than a purely combinatorial approach.
