The idea is to pre-compute all possible next states for each current state and input combination, and store them in a LUT. By using a LUT, we can reduce the complexity of the combinational logic, which can lead to improved performance and area efficiency. Additionally, the LUT can be optimized for power consumption by minimizing the number of bits required to represent the next state.
