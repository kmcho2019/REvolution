To implement the TopModule, we will use a combinational logic block to calculate the next state of each cell based on the current state of itself and its two neighbors. We will use a synchronous reset (load) to initialize the system state. Since all sequential logic is triggered on the positive edge of the clock, we will use a D flip-flop to store the current state of each cell. The next state of each cell will be calculated using the Rule 110 table.
