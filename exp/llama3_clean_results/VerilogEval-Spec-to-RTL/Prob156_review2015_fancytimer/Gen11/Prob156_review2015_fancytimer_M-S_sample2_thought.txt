To simplify the solution, we can reorganize the finite state machine (FSM) to have fewer states and eliminate the unnecessary state transitions. The sequence detection and delay registration can be combined into a single state, and the counting and done states can be managed using a single counter. 

The counter can be loaded with the delay value multiplied by 1000, and then decremented every clock cycle. The remaining delay can be calculated by dividing the counter value by 1000. 

The output assignments can be simplified by directly assigning the 'count' output the value of the remaining delay, and the 'counting' and 'done' outputs based on the state of the counter.

The FSM can be simplified to have only three states: IDLE, COUNTING, and DONE. The IDLE state will detect the sequence and register the delay, the COUNTING state will decrement the counter and calculate the remaining delay, and the DONE state will wait for the ack signal to reset the FSM.
