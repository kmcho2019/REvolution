To solve this problem, I will design a finite state machine (FSM) with the following states:
- IDLE: initial state where the FSM waits for the pattern 1101
- SHIFT: state where the FSM shifts in the 4-bit delay value
- COUNT: state where the FSM counts for the specified delay
- DONE: state where the FSM asserts the done signal and waits for the ack signal

The FSM will use a counter to keep track of the remaining time and a shift register to store the delay value. The FSM will also use a flag to indicate whether it is currently counting or not.

In the IDLE state, the FSM will check for the pattern 1101 on the data input. If the pattern is detected, it will transition to the SHIFT state.

In the SHIFT state, the FSM will shift in the 4-bit delay value and store it in a register. After shifting in all 4 bits, it will transition to the COUNT state.

In the COUNT state, the FSM will count for the specified delay using a counter. The counter will be decremented every 1000 clock cycles. The current remaining time will be output on the count port. When the counter reaches 0, the FSM will transition to the DONE state.

In the DONE state, the FSM will assert the done signal and wait for the ack signal. When the ack signal is asserted, the FSM will reset to the IDLE state.
