To simplify the solution, we can design a finite-state machine with five main states: idle, pattern_detected, shifting, counting, and done. The machine starts in the idle state, where it checks for the pattern 1101 on the data input. Once the pattern is detected, it moves to the pattern_detected state. In this state, it asserts shift_ena for exactly 4 clock cycles to shift in the duration bits. After shifting, it moves to the counting state, where it asserts counting and waits for done_counting to be high. Once done_counting is high, it moves to the done state, where it asserts done and waits for ack to be high before moving back to the idle state.
