To solve this problem, we'll design a finite state machine (FSM) with the following states: 
- Idle: The initial state where the FSM waits for the pattern 1101.
- Shift: After detecting the pattern, the FSM shifts in 4 more bits to determine the duration.
- Counting: The FSM waits for the counters to finish counting.
- Done: The FSM notifies the user and waits for acknowledgement.
We'll use a counter to keep track of the number of clock cycles in the Shift state.

The FSM will transition between states based on the input signals and the current state. 
- From Idle to Shift when the pattern 1101 is detected.
- From Shift to Counting after 4 clock cycles.
- From Counting to Done when done_counting is high.
- From Done to Idle when ack is high.

We'll also use the shift_ena, counting, and done outputs to indicate the current state of the FSM.
