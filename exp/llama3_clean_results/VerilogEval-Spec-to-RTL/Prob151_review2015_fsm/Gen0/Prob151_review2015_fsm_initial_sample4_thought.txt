To implement the finite-state machine for the timer, we can break it down into several states:
- IDLE: The initial state where the FSM waits for the pattern 1101.
- SHIFT: Once the pattern is detected, the FSM shifts in 4 more bits and then waits for the counters to finish.
- COUNTING: The FSM asserts the counting output and waits for the done_counting signal.
- DONE: After counting is done, the FSM asserts the done output and waits for the ack signal.
- RESET: The FSM can be reset to the IDLE state at any time using the reset input.

We can use a state register to keep track of the current state and use a combination of next-state logic and output logic to implement the desired behavior.
