The existing finite-state machine (FSM) can be simplified by reducing the number of states and sub-states, while maintaining its functionality. A more straightforward approach would be to use a 4-state FSM: IDLE, SHIFT, COUNT, and DONE.

After shifting, the FSM transitions to the COUNT state, where it waits for the done_counting input to be high. Once done_counting is high, the FSM transitions to the DONE state, where it asserts the done output and waits for the ack input to be high before returning to the IDLE state.

This simplified approach reduces the complexity of the FSM and makes the code easier to understand and maintain. The output signals can be directly assigned based on the current state, reducing the need for additional logic.
