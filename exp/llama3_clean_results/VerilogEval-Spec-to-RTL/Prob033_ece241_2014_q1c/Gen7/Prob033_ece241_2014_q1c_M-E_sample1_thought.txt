To implement a novel solution, we can design an 8-bit adder using a Wallace tree architecture, which is a fast and efficient method for adding multiple numbers. In this approach, the addition of two numbers is performed by first adding pairs of corresponding bits from the two input numbers, and then adding the resulting partial sums using a tree-like structure of full adders and half adders. This approach allows for a significant reduction in the number of full adders required compared to a ripple-carry adder, resulting in improved performance.

For signed overflow detection, we can observe the most significant bits of the two input numbers and the result. If the signs of the two input numbers are the same and the sign of the result is different, then a signed overflow has occurred. This can be detected using simple logical operations.
