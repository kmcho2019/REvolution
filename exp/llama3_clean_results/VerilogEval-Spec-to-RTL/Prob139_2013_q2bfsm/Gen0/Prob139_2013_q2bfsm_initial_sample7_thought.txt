To implement the described finite state machine, we can define several states:
- State A (reset state): stays in this state as long as resetn is asserted. 
- State B: sets output f to 1 for one clock cycle after reset is de-asserted.
- State C: monitors the x input for the sequence 1, 0, 1.
- State D: sets output g to 1 and monitors the y input for at most two clock cycles.
- State E: maintains g = 1 permanently if y becomes 1 within two clock cycles.
- State F: sets g = 0 permanently if y does not become 1 within two clock cycles.

The state transitions and output values can be determined based on the current state and input values. 
We can use a counter to keep track of the number of clock cycles in state D.
