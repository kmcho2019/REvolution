To implement the required finite state machine (FSM), we can break down the design into several states:
- State A: The initial state, which the FSM stays in as long as the reset input is asserted.
- State B: A transition state where the FSM sets output f to 1 for one clock cycle after the reset signal is de-asserted.
- State C: The FSM monitors the x input for the sequence 1, 0, 1 in three successive clock cycles.
- State D: After detecting the sequence, the FSM sets output g to 1 and monitors the y input.
- State E: If y becomes 1 within two clock cycles, the FSM maintains g = 1 permanently.
- State F: If y does not become 1 within two clock cycles, the FSM sets g = 0 permanently.

We will use an enumeration to represent these states and use a counter to keep track of the number of clock cycles in certain states.
