To implement the finite state machine, we will use a Moore machine model where the outputs are dependent on the current state only. The FSM will have several states: 
1. A (initial state, reset state): In this state, the FSM will wait for the reset signal to be de-asserted. 
2. B (set f to 1): The FSM will set the output f to 1 for one clock cycle after the reset signal is de-asserted.
3. C (monitor x): The FSM will then monitor the x input and wait for the sequence 1, 0, 1 in three successive clock cycles.
4. D (set g to 1): After detecting the sequence, the FSM will set the output g to 1.
5. E (monitor y): While maintaining g = 1, the FSM will monitor the y input. 
6. F (y detected within two cycles): If y has the value 1 within at most two clock cycles, the FSM will maintain g = 1 permanently.
7. G (y not detected within two cycles): If y does not become 1 within two clock cycles, the FSM will set g = 0 permanently.

We will use a case statement to implement the state machine and assign the outputs based on the current state.
