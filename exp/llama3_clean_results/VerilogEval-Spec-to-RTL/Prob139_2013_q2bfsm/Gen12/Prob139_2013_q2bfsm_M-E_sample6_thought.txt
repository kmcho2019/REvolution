This allows for more modular and maintainable code. Additionally, we can use a separate counter for sequence detection and y monitoring to simplify the logic.

The state machine will have four main states: Initialization, Sequence Detection, Y Monitoring, and Final State. In the Sequence Detection state, we will use a counter to detect the sequence 1, 0, 1. Once the sequence is detected, we transition to the Y Monitoring state. In the Y Monitoring state, we use another counter to monitor the y input for up to two clock cycles.
