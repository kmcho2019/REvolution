We then use this comparison to update the corresponding bit in the output `out`. We keep the output bit set once it's been set due to a transition, unless the module is reset. This can be achieved by using a non-blocking assignment (`<=`) in a way that each bit in `out` is updated based on the detected transition without affecting other bits. The use of a temporary variable is not necessary; instead, we can directly calculate the new state of `out` based on the current `out`, `in`, and `prev_state`.
