To simplify the solution, we can eliminate the need for the `d1` and `d2` registers. Instead, we can use the `out_reg` directly to track the state of each bit in the input vector. 

When the input signal transitions from 1 to 0, we can set the corresponding bit in `out_reg` to 1. This approach eliminates the need for the extra registers and the loop within the clocked always block.

Additionally, we can remove the unnecessary `always @(*)` block and directly assign `out_reg` to the output `out`. This simplification reduces the complexity of the design while maintaining the desired functionality.
