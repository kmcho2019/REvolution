The first stage will be responsible for storing the previous input value. The second stage will compare the current input value with the previous input value to detect transitions from 1 to 0. The third stage will update the output bits based on the detected transitions.

To improve the PPA metrics, I will use a combination of sequential and combinatorial logic to minimize the number of operations performed in each clock cycle. The sequential logic will be used to store the previous input value and the output bits, while the combinatorial logic will be used to detect transitions and update the output bits.

The key components of this new architecture will include:
1. A register to store the previous input value.
2. A combinatorial logic block to detect transitions from 1 to 0.
3. A register to store the output bits.
4. A control logic block to update the output bits based on the detected transitions and the reset signal.

This pipelined approach will allow for a more efficient and scalable implementation, especially for larger input sizes. Additionally, the use of sequential and combinatorial logic will help to minimize the power consumption and area requirements of the design.
