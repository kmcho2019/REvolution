The TopModule should have a 32-bit register to store the output. On every positive clock edge, we will iterate over each bit of the input vector. If the current bit of the input is 0 and the previous bit was 1 (which we can track by maintaining a 32-bit internal register to store the previous input), we will set the corresponding bit of the output register to 1. The output register should also be resettable on the positive clock edge when the reset signal is high.
