A novel approach to solve this problem is to use a counter that is controlled by a single-bit state variable. The state variable 'shift_ena' itself serves as an indicator of whether the shift register should be enabled. We initialize this state to 1 when reset is high. Then, on each subsequent clock cycle, if shift_ena is 1, we decrement a counter. When the counter reaches 0, we clear the shift_ena signal. This way, we ensure that shift_ena is asserted for exactly 4 clock cycles after a reset and then remains low until the next reset. This design simplifies the logic and eliminates the need for a complex state machine or multiple counters.
