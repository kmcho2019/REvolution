To simplify the solution, we can use a single counter that is reset when the reset signal is asserted. The shift_ena signal can be asserted when the counter is greater than 0. When the reset signal is asserted, the counter is set to 4. Then, on subsequent clock cycles, the counter decrements until it reaches 0, at which point shift_ena is deasserted. This approach eliminates the need for a separate state machine and the reset_prev signal, reducing complexity while maintaining functionality.
