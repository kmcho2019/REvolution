To simplify the existing solution, we can utilize a single variable to track the number of clock cycles for which the shift register should be enabled after a reset. This variable will act as a counter that decrements every clock cycle. Initially, when reset is asserted, this counter is set to 3 (to enable the shift register for 4 cycles, since the counter will be decremented immediately after being set). On every subsequent clock cycle, if the counter is greater than 0, it decrements by 1. Once the counter reaches 0, it remains 0 until the next reset. The `shift_ena` signal is simply assigned the value of whether the counter is greater than 0, which directly reflects whether the shift register should be enabled or not.
