To simplify the TopModule, we will:
1. Design the global branch history register (GBHR) to keep track of the branch history.
2. Implement the Pattern History Table (PHT) using a 128-entry table of two-bit saturating counters.
3. Develop the hash function to index into the PHT using the 7-bit PC and the 7-bit GBHR.
4. Implement the prediction logic to produce the predicted branch direction and the state of the GBHR used to make the prediction.
5. Implement the training logic to update the PHT and recover the GBHR in case of a misprediction.

We will simplify the code by using a more straightforward approach to update the PHT table and the GBHR. We will also avoid using complex conditional statements and instead use a more modular approach to implement the prediction and training logic.
