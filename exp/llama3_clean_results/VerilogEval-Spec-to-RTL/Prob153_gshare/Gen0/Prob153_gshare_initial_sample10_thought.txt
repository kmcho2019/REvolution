The module will implement a gshare branch predictor with a 7-bit PC and 7-bit global history, hashed into a 7-bit index to access a 128-entry table of two-bit saturating counters. It will have two interfaces, one for prediction and one for training. The prediction interface will produce the predicted branch direction and the state of the branch history register used to make the prediction. The training interface will update the pattern history table (PHT) based on the actual branch outcome and whether the branch was a misprediction. The branch history register will be updated at the next positive clock edge for the predicted branch, and recovered to the state immediately after the mispredicting branch completes execution if the branch being trained is mispredicted. If both training and prediction occur in the same cycle, training takes precedence.
