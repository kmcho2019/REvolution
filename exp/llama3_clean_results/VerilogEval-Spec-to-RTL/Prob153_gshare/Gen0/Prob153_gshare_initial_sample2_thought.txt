To implement the TopModule, we need to create a gshare branch predictor with a 7-bit global branch history register and a 128-entry table of two-bit saturating counters. We will use a separate always block to handle the clock edge and another for combinational logic. 

The branch predictor will be implemented in two stages: prediction and training. The prediction stage will use the current global branch history and the PC to index into the pattern history table (PHT) and predict the branch direction. The training stage will update the PHT based on the actual branch outcome and update the global branch history if the branch was mispredicted.

We will use the `predict_valid` signal to trigger the prediction stage, and the `train_valid` signal to trigger the training stage. The `areset` signal will be used to asynchronously reset the module.

The global branch history will be updated at the next positive clock edge after a prediction is made. If a training request is received for a mispredicted branch, the global branch history will be recovered to the state immediately after the mispredicting branch completes execution.
