To implement the TopModule, we will use a combination of sequential logic and combinational logic. We will use a 7-bit global branch history register (ghr) to keep track of the branch history. This register will be updated at the next positive clock edge for the predicted branch when a branch prediction is requested.

The PHT will be implemented as an array of 2-bit saturating counters. We will use the index to access the corresponding counter in the PHT and output the predicted branch direction and the state of the branch history register used to make the prediction.

For the training interface, we will use the 7-bit PC, the actual branch outcome, and the branch history register value for the branch being trained to update the PHT. If the branch being trained is a misprediction, we will also recover the branch history register to the state immediately after the mispredicting branch completes execution.
