To implement the gshare branch predictor, we need to create a module named TopModule with the specified interface. The module will consist of the following components:
1. A 7-bit global branch history register to store the current branch history.
2. A 128-entry table of two-bit saturating counters (Pattern History Table, PHT) to store the prediction outcomes.
3. A prediction logic block to generate the predicted branch direction and updated branch history based on the current pc and branch history.
4. A training logic block to update the PHT and recover the branch history register when a misprediction occurs.

The prediction logic block will hash the pc and branch history using xor to generate a 7-bit index, which will be used to access the PHT. The predicted branch direction will be determined based on the value of the saturating counter at the indexed location.

The training logic block will update the PHT by incrementing or decrementing the saturating counter based on the actual branch outcome. If a misprediction occurs, the branch history register will be recovered to the state immediately after the mispredicting branch completes execution.

To handle the cases where training and prediction of the same PHT entry happen at the same time, we will ensure that the prediction sees the PHT state before training by using the current PHT state for predictions and updating the PHT at the next positive clock edge.
