To implement a finite-state machine that searches for the sequence 1101 in an input bit stream, I propose a novel approach using a Mealy machine architecture. This architecture will utilize a state register to keep track of the current sequence of bits received and will transition between states based on the current input bit and the current state. The machine will have four states: idle (state 0), seen_1 (state 1), seen_11 (state 2), seen_110 (state 3), and found_sequence (state 4). The machine will start in the idle state and transition to the next state based on the input bit. If the machine is in the idle state and receives a 1, it will transition to the seen_1 state. If it is in the seen_1 state and receives a 1, it will transition to the seen_11 state, and so on. Once the machine reaches the found_sequence state, it will set the start_shifting output to 1. The machine will remain in the found_sequence state until reset is asserted, at which point it will return to the idle state. This approach allows for a clear and concise implementation of the finite-state machine and eliminates the need for a shift register to store the input bits.
