To implement the TopModule, we will design a finite-state machine with five states: idle, saw_1, saw_11, saw_110, and saw_1101. The machine starts in the idle state and transitions to the next state based on the input data. When the sequence 1101 is detected, the machine sets start_shifting to 1 and remains in that state until reset. We will use a counter to keep track of the current state and a variable to store the value of start_shifting.
