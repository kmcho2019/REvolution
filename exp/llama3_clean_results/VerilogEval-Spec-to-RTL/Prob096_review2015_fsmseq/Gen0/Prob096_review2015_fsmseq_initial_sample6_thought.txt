To implement the TopModule, we will design a finite-state machine with five states: 
- Idle: Initial state, waiting for the first '1' in the sequence
- Got_1: First '1' received, waiting for the second '1'
- Got_11: Second '1' received, waiting for '0'
- Got_110: '0' received, waiting for the final '1'
- Found: Sequence found, set start_shifting to 1

We will use a state register to keep track of the current state and update it based on the current state and input data. 
The start_shifting output will be set to 1 when the sequence is found and will remain 1 until the reset signal is asserted.
