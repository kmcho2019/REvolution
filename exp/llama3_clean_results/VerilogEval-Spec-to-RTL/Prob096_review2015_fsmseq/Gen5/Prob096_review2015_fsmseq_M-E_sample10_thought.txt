A novel approach to implementing the finite-state machine for detecting the sequence 1101 in an input bit stream involves using a shift register to track the recent history of input bits, rather than explicitly defining states for each prefix of the target sequence. This method simplifies the logic for state transitions and reduces the number of states needed, potentially leading to improvements in area and power efficiency.

The idea is to shift the incoming data bit into a 4-bit shift register on each clock cycle. After shifting, the contents of the shift register are checked against the target sequence 1101. If a match is found, the `start_shifting` signal is set to 1 and remains so until a reset is asserted.

This approach eliminates the need for explicit state definitions and transition logic, instead relying on the shift register to inherently track the sequence history. It simplifies the design and could potentially improve PPA metrics by reducing the complexity of the combinational logic and the number of state transitions.
