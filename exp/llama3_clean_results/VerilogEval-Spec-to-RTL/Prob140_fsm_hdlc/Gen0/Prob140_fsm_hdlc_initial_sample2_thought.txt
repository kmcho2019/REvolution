The states can be defined as follows:
- IDLE: Initial state, expecting the first bit of the pattern.
- ONE: One '1' has been received.
- TWO: Two '1's have been received.
- THREE: Three '1's have been received.
- FOUR: Four '1's have been received.
- FIVE: Five '1's have been received.
- FLAG: The "flag" pattern has been detected.
- ERR: An error has occurred (7 or more consecutive '1's).
- DISCARD: A bit needs to be discarded.

The FSM will transition between these states based on the current state and the input bit. The output signals will be asserted based on the current state.
