Our novel approach is to design a Moore-type finite state machine (FSM) using a counter-based architecture. Instead of using a traditional state machine with multiple states, we will utilize a counter to track the number of consecutive ones in the input bit stream. This counter-based approach simplifies the state transition logic and reduces the number of states required.

The counter will be reset to zero whenever a zero is encountered in the input bit stream. When the counter reaches a value of 5, it indicates that 5 consecutive ones have been detected, and a discard signal is generated. If the counter reaches a value of 6, it indicates that a flag sequence (01111110) has been detected, and a flag signal is generated. If the counter exceeds a value of 6, an error signal is generated, indicating that 7 or more consecutive ones have been detected.

This counter-based approach reduces the complexity of the state machine and minimizes the number of states required, resulting in improved power, performance, and area (PPA) metrics.
