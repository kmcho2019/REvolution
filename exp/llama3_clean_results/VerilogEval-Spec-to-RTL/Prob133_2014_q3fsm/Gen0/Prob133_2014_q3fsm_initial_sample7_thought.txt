To implement the described finite state machine, we can use a Moore machine model, which is suitable for this type of problem. The FSM starts in state A. When s = 1, it transitions to state B. In state B, it needs to count the number of clock cycles where w = 1 over the next three clock cycles. This can be achieved by using a counter to keep track of the number of w = 1 occurrences and another counter to keep track of the clock cycles. Based on these counters, the FSM decides whether to set the output z to 1 or 0. Given the constraints, we can minimize the number of states by using a single state (B) to handle the w checking logic, as the s input is only relevant for transitioning from A to B.

The states can be defined as follows:
- State A: Reset state, waiting for s = 1 to transition to B.
- State B: Checking state, where the FSM counts w = 1 occurrences over three clock cycles.

The output z is determined based on the count of w = 1 in the previous three cycles when in state B.
