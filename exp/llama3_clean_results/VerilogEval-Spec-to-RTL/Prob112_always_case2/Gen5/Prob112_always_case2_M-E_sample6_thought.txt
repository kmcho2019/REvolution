The idea is to use a case statement to check for the first occurrence of '1' in the input vector from most significant bit to least significant bit. This approach allows us to directly specify the output for each possible position of the first '1' bit in the input vector. We will use a binary encoding for the output, where '2'b00' corresponds to the least significant bit and '2'b11' corresponds to the most significant bit. This approach is straightforward and easy to implement for a small input vector size like 4 bits.
