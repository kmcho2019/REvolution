To implement the 12-hour clock with a set of counters, we'll use separate counters for seconds, minutes, and hours. Each counter will be designed to handle BCD (Binary-Coded Decimal) encoding, meaning each digit can range from 0 to 9. 
The seconds counter will reset at 60, the minutes counter will reset at 60, and the hours counter will reset at 13 (to account for 12 hours plus the need to roll over). 
When the hours counter reaches 12, we need to toggle the am/pm indicator. 
On reset, all counters should reset to their initial values (00 for seconds and minutes, 12 for hours, and am/pm indicator set to AM).
