To create a 12-hour clock with a PM indicator, we will design a set of counters for hours, minutes, and seconds. Each counter will be able to count up to its maximum value and then reset. We'll use a combination of these counters to form the clock. The clock will be incremented once per second, as indicated by the ena signal. When reset is asserted, the clock will reset to "12:00 AM." We'll also use a flag to indicate whether the clock is in PM or AM.

To achieve this, we'll need:
1. A seconds counter that counts from 0 to 59 and then resets.
2. A minutes counter that counts from 0 to 59 and then resets.
3. An hours counter that counts from 1 to 12 and then resets, with a PM indicator flag.
4. Logic to handle the reset condition, setting all counters to their initial state and the PM indicator to AM.
5. Logic to handle the enable condition, incrementing the counters as necessary when ena is asserted.

We'll implement these counters and logic using Verilog, utilizing the clk and ena signals to control their behavior.
