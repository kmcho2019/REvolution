To create a 12-hour clock module, we need to implement counters for hours, minutes, and seconds. The counters should be clocked by the fast-running clk signal and increment whenever the ena signal is high. The reset signal should be able to reset the clock to "12:00 AM" at any time. We will use a set of BCD counters to keep track of the hours, minutes, and seconds. The hours counter will need to wrap around from 12 to 1 when it reaches 13, and the minutes and seconds counters will need to wrap around from 59 to 0 when they reach 60. We will also need to generate the pm signal based on the hour value.
