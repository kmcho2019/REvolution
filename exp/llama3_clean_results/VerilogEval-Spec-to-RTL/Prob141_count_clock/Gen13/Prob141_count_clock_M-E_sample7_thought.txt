This approach involves defining a set of states that the clock can be in, such as seconds incrementing, minutes incrementing, hours incrementing, and resetting. By using a state machine, we can manage the complexity of the clock's behavior and ensure that the AM/PM indicator is correctly updated. Additionally, we will use separate counters for seconds, minutes, and hours, and update them accordingly based on the current state. The state machine will be triggered by the enable signal and will handle the reset condition by transitioning to the initial state when the reset signal is asserted.
