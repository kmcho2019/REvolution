The FSM will have states for each time unit (hours, minutes, seconds) and will transition between these states based on the enable signal and the current state.

2. **BCD Encoding**: We will use a separate module to handle the BCD encoding and decoding of the time units. This will simplify the main clock module and make it easier to manage the BCD conversions.

3. **Counter Modules**: We will create separate modules for each counter (hours, minutes, seconds). Each module will be responsible for incrementing its respective counter and handling the overflow conditions.

4. **PM/AM Flag**: The PM/AM flag will be updated based on the hours counter's value. When the hours counter reaches 12, the PM/AM flag will toggle.

5. **Reset Logic**: The reset logic will be implemented using a separate module that will reset all the counters and the PM/AM flag to their initial values.
