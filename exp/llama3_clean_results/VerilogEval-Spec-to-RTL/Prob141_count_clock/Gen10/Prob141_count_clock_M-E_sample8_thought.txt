To design a 12-hour clock with AM/PM indication, we can break down the problem into smaller components: hours, minutes, and seconds counters. Each of these counters needs to be implemented separately, with specific rules for incrementing and wrapping around.

We will use a modular approach, where each counter is designed as a separate module. This will allow us to test and verify each component individually before integrating them into the final design.

The hours counter will be designed to count from 1 to 12, with an AM/PM indicator that toggles when the hours wrap around. The minutes and seconds counters will count from 0 to 59.

We will use a centralized control module to handle the incrementation of the counters based on the enable signal. This control module will also handle the reset logic, ensuring that the counters are properly reset when the reset signal is asserted.

By breaking down the design into smaller, more manageable components, we can simplify the logic and make it easier to verify and test.
