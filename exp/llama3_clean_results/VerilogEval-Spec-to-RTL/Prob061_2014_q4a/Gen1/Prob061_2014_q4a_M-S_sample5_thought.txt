To simplify the solution, we can directly assign the next state of `q_reg` based on the input conditions without explicitly checking for the condition where neither load nor enable is asserted. This is because, in Verilog, if none of the conditions in an if-else statement are true, the value of the register will retain its current value by default, thanks to the non-blocking assignment (`<=`) used within an always block triggered by the positive edge of the clock.
