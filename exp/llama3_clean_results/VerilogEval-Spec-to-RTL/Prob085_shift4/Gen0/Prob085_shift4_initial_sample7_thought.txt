To implement the TopModule, we need to create a 4-bit shift register that can be reset asynchronously, loaded synchronously, and shifted right synchronously. The module will have a reset input (areset) that resets the register to zero, a load input that loads the register with the data input when asserted, and an enable input (ena) that shifts the register right when asserted. If both load and ena are asserted, the load operation will have higher priority. The register's value will be output on the q port. We will use a non-blocking assignment to update the register's value on the positive edge of the clock.
