To create a novel architectural solution for the Lemmings game, I propose implementing a state machine using a one-hot encoding scheme. This approach involves representing each state as a unique binary code, where only one bit is set (hot) at any given time. The state machine will have two states: walking left and walking right. The one-hot encoding scheme will allow for a simple and efficient implementation of the state transitions based on the input signals (bump_left and bump_right). The design will also incorporate asynchronous reset (areset) to initialize the state machine to the walking left state.
