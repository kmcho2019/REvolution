To implement the TopModule, we'll use a Moore state machine with two states: WALK_LEFT and WALK_RIGHT. We'll use two input signals, bump_left and bump_right, to determine the next state. When the module is in the WALK_LEFT state, it will switch to WALK_RIGHT if bump_left is high. When the module is in the WALK_RIGHT state, it will switch to WALK_LEFT if bump_right is high. If both bump_left and bump_right are high, the module will still switch directions. We'll use areset to asynchronously reset the module to the WALK_LEFT state.
