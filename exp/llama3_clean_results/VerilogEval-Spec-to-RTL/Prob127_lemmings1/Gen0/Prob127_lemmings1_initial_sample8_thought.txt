The TopModule will be implemented as a Moore state machine with two states: WALK_LEFT and WALK_RIGHT. 
The state machine has two inputs, bump_left and bump_right, which trigger a state transition when either input is high. 
The outputs, walk_left and walk_right, will be asserted based on the current state. 
The state machine will also have an asynchronous reset input, areset, which resets the state to WALK_LEFT when it is high. 
The module will use a simple if-else statement to determine the next state based on the current state and the inputs.
