To implement the Lemming behavior as a Moore state machine, we'll define several states: 
- IDLE_LEFT: Lemming is walking left
- IDLE_RIGHT: Lemming is walking right
- FALLING: Lemming is falling
- DIGGING: Lemming is digging
- SPLATTERED: Lemming has splattered

We'll use a counter to keep track of the number of clock cycles the Lemming has been falling, and when it hits 20, the Lemming will splatter if it hits the ground.

We'll use a case statement to define the next state based on the current state and the inputs.

Note that we need to handle the case when both bump_left and bump_right are high separately, to ensure the Lemming switches direction in that case.
