To implement the Lemming's behavior as a Moore state machine, we will use the following states:
- WALK_LEFT: Lemming is walking left
- WALK_RIGHT: Lemming is walking right
- FALL: Lemming is falling
- DIG: Lemming is digging
- SPLAT: Lemming has splattered and ceased all activities

We will use two counters: 
- fall_counter: counts the number of clock cycles the Lemming has been falling
- dig_counter: counts the number of clock cycles the Lemming has been digging

Based on the current state and inputs, we will transition to the next state and update the outputs accordingly.
