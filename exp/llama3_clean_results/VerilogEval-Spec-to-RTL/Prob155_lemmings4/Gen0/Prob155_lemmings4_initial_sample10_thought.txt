To implement this finite state machine, we will first define the states of the Lemming. 
The states can be: walking_left, walking_right, falling, digging_left, digging_right, 
and splattered. Then, we will define the state transitions based on the inputs and the current state.
We will use a counter to count the number of clock cycles the Lemming has been falling.
If the Lemming falls for more than 20 clock cycles and hits the ground, it will splatter.
We will also use a variable to store the direction of the Lemming before it starts falling or digging.
