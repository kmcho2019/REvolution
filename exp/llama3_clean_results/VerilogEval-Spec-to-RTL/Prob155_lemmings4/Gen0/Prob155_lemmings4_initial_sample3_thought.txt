To implement the Lemming behavior as a Moore state machine, we can define the following states:
- WALKING_LEFT: The Lemming is walking left.
- WALKING_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and is no longer active.

We will use a counter to track the number of clock cycles the Lemming has been falling. If the Lemming hits the ground after falling for more than 20 clock cycles, it will transition to the SPLATTERED state.

The state transitions will be based on the input signals and the current state. We will use a case statement to determine the next state and output values based on the current state and input signals.
