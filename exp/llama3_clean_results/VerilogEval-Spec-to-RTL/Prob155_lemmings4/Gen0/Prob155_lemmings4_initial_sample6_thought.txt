To implement the Moore state machine for the Lemming behavior, we need to define the states and transitions based on the given conditions. 

We can start by defining the states:
- WALK_LEFT: The Lemming is walking left.
- WALK_RIGHT: The Lemming is walking right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and is no longer active.

The transitions between these states will depend on the input signals:
- bump_left and bump_right to switch directions.
- ground to check for falling and resuming walking.
- dig to start digging.
- areset to reset the state machine.

We also need to keep track of the number of clock cycles the Lemming has been falling to check for splattering.

Using a Moore state machine, the outputs (walk_left, walk_right, aaah, digging) are determined by the current state.
