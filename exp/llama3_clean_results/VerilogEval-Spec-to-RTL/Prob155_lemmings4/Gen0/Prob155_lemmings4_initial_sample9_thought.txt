To implement the Lemmings' behavior, we can design a Moore state machine with several states. The states can be defined as follows:
- IDLE_LEFT: The Lemming is walking to the left.
- IDLE_RIGHT: The Lemming is walking to the right.
- FALLING: The Lemming is falling.
- DIGGING: The Lemming is digging.
- SPLATTERED: The Lemming has splattered and is no longer active.
We can use a 3-bit state variable to represent these states. 
We will also use a counter to track the number of clock cycles the Lemming has been falling.
The next state logic will be determined by the current state and the input signals.
The output logic will be determined by the current state.
