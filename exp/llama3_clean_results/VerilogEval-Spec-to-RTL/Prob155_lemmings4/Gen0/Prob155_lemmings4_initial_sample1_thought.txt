To implement the Lemming machine as a Moore state machine, we need to identify the different states it can be in. Based on the given behavior, the Lemming can be in one of the following states:
- Walking left
- Walking right
- Falling
- Digging
- Splattered

We will use a 3-bit state variable to represent these states. We will also use a counter to count the number of clock cycles the Lemming has been falling.

The state machine will transition between these states based on the input signals and the current state. For example, if the Lemming is walking and hits an obstacle, it will switch directions. If the Lemming is walking and the ground disappears, it will start falling. If the Lemming is falling and hits the ground after more than 20 clock cycles, it will splatter.

We will also need to handle the asynchronous reset signal, which will reset the Lemming machine to the walking left state.
