To implement the Mealy-type finite state machine (FSM) that recognizes the sequence "101" on the input signal x, we can define three states: S0 (initial state), S1 (after seeing '1'), and S2 (after seeing '0' after '1'). The FSM will transition between these states based on the input x and will assert the output z to logic-1 when the sequence "101" is detected. We will use a negative edge triggered asynchronous reset to reset the FSM to the initial state S0. The output z will be asserted when the FSM is in state S2 and the input x is '1'.
