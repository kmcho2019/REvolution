- From S0: If x = 1, go to S1; otherwise, stay in S0.
- From S1: If x = 0, go to S2; otherwise, stay in S1.
- From S2: If x = 1, assert z to 1 and go back to S1 (since we've seen '101'); otherwise, go back to S0.
