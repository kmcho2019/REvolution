To implement the Mealy-type finite state machine that recognizes the sequence "101", we can define three states: S0 (initial state), S1 (state after detecting '1'), and S2 (state after detecting '0' following '1'). We start in S0 and transition to S1 when we detect '1'. From S1, if we detect '0', we move to S2. From S2, if we detect '1', we have found the sequence "101" and we assert the output z. We then return to S1 because we are looking for overlapping sequences. If from any state we detect a '1' and we are not in S1 or we detect a '0' and we are not in S2, we reset our progress by returning to the appropriate state that corresponds to the detected input. The asynchronous reset will return us to S0.
