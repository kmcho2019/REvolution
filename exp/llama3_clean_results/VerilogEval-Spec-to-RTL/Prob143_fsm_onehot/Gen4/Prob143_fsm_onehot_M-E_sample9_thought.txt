Similarly, states S5 to S9 can be grouped based on their unique transition patterns and output conditions.

Each group can be implemented as a separate module, with its own state decoder, transition logic, and output logic. These modules can then be combined at a higher level to form the complete state machine. This hierarchical approach allows for a more structured and scalable design, making it easier to manage complexity and optimize for PPA metrics.

To further optimize the design, we can use parameterized modules to reduce code duplication and improve maintainability. By using parameters to define the state encoding, transition rules, and output conditions for each group, we can easily modify or extend the state machine without having to rewrite the entire code.
