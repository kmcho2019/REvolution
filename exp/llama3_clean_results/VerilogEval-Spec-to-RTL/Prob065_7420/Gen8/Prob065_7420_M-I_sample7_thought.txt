The current implementation of the 7420 chip using two 4-input NAND gates can be improved for better PPA metrics. The main area of improvement is to reduce the critical path and power consumption. This can be achieved by using logical expressions instead of case statements and optimizing the logic to reduce switching activity. We will implement the NAND gate using a logical expression that directly calculates the output, reducing the critical path. Additionally, we will optimize the logic to minimize the number of transistors used, reducing area and power consumption.
