To create a novel solution, we can leverage the concept of serial-in-parallel-out (SIPO) shift registers. Instead of using 8 separate D flip-flops, we can design a single 8-bit shift register with an active high asynchronous reset. The input data will be shifted into the register on each positive edge of the clock signal, and the reset will clear the register to zero. This approach reduces the number of individual flip-flops needed and simplifies the design.

We will use a single always block to handle the shift register's behavior, including the reset functionality.

The shift register will operate as follows: on each positive edge of the clock signal, the input data will be shifted into the register. If the reset signal is high, the register will be cleared to zero.
