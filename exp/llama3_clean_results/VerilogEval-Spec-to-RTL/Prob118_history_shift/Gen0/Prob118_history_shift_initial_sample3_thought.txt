The module TopModule will contain a 32-bit register to store the global history shift register. On every clock cycle, we check for the asynchronous reset signal (areset) and reset the register to zero if it's high. On the positive edge of the clock, we check if a misprediction has occurred (train_mispredicted = 1). If so, we load the register with the history after the completion of the mispredicted branch by concatenating train_history and train_taken. If no misprediction has occurred, we check if a branch prediction is valid (predict_valid = 1). If so, we shift in predict_taken from the LSB side to update the branch history. Finally, we output the value of the branch history register as predict_history.
