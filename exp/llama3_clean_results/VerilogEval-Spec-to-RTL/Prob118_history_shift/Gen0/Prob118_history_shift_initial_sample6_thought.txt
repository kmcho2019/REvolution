To implement the TopModule, we need to design a 32-bit global history shift register. 
The shift register should be able to shift in the predict_taken value when a prediction is made, 
and load the train_history concatenated with train_taken when a misprediction occurs. 
We will use a flip-flop to store the current state of the shift register and update it on the positive edge of the clock.
We will use areset as an asynchronous reset to reset the shift register to zero.
We will prioritize the misprediction over the prediction when both occur at the same time.
