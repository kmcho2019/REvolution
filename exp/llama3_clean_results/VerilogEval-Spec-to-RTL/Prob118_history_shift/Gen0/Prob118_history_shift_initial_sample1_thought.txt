To implement the TopModule, we need to create a 32-bit global history shift register. 
The module should update the register when a branch prediction is made (predict_valid = 1), 
shift in predict_taken from the LSB side, and when a branch misprediction occurs (train_mispredicted = 1), 
load the branch history register with the history after the completion of the mispredicted branch.
If both a prediction and misprediction occur at the same time, the misprediction takes precedence.
The module should also have an asynchronous reset (areset) to reset the history counter to zero.
We can achieve this by using a combination of if-else statements and bitwise operations to update the branch history register.
