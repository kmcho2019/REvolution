This state machine will have two states: "idle" and "ringing". When the phone is in the idle state and receives an incoming call (input ring = 1), it transitions to the ringing state. In the ringing state, the state machine checks the vibrate mode (input vibrate_mode) and turns on either the ringer or the motor accordingly. This approach allows for a more modular and scalable design, making it easier to add additional features in the future.

The state machine will be implemented using a finite state machine (FSM) with two states: S_IDLE and S_RINGING.
