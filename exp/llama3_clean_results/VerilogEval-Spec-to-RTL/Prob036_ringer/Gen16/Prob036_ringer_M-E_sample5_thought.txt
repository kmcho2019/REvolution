We can implement a state machine that controls the ringer and motor based on the ring and vibrate_mode inputs. The state machine will have two states: IDLE and RINGING. When the ring input is high, the state machine transitions from IDLE to RINGING. In the RINGING state, the state machine checks the vibrate_mode input and turns on either the ringer or the motor accordingly. This approach allows for a more scalable design that can be easily extended to include additional features or modes.
