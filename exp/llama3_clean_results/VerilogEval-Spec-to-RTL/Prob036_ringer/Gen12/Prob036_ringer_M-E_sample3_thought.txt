To introduce a novel architectural idea, we can consider a state machine approach. The state machine will have two states: IDLE and RINGING. When the phone is not ringing, it stays in the IDLE state. Upon receiving a ring signal, it transitions to the RINGING state, where it checks the vibrate_mode. If vibrate_mode is 1, it turns on the motor; otherwise, it turns on the ringer. This approach allows for a more structured and scalable design, potentially making it easier to add more features in the future, such as different ring modes or call handling logic.
