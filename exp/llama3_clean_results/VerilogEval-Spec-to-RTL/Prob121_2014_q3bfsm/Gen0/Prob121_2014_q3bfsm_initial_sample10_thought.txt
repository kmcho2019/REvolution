To implement the finite-state machine (FSM) as described, we will use a Verilog module named TopModule. The FSM will have 8 possible states, but since the state-assigned table only lists 5 states, we will assume that the remaining states are don't cares for this implementation. We will use an enumeration to define the states and then implement the next state logic and output logic according to the provided table. The reset will be synchronous active high, meaning it will reset the FSM to state 000 (y[2:0] = 3'b000) when reset is high. All sequential logic is triggered on the positive edge of the clock.
