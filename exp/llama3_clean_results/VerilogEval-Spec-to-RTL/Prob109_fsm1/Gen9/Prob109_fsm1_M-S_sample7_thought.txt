   - From B (1), stay in B if 'in' is 1, move to A if 'in' is 0.
   - From A (0), stay in A if 'in' is 1, move to B if 'in' is 0.
   This logic can be represented more straightforwardly in the always block.

3. **Asynchronous Reset:** The asynchronous reset will remain, ensuring the state machine resets to state B (1) when 'areset' is high.

4. **Output Logic:** Since the output directly depends on the current state (out = state), no simplification is needed here.
