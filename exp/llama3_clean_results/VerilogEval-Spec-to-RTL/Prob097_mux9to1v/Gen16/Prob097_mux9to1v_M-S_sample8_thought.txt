The existing solution uses an array to store the input signals and then selects the output based on the `sel` value using a conditional operator (`?:`). To simplify this solution, we can directly use a case statement inside an always block or use the conditional operator (`?:`) in a continuous assignment (`assign`) statement without storing the inputs in an array. This approach reduces the complexity by eliminating the need for an array and directly implementing the multiplexer logic.

We will maintain the same functionality for handling unused cases (sel=9 to 15) by setting all output bits to '1' when `sel` is greater than 8. This simplification aims to achieve a more straightforward and possibly more area-efficient implementation without compromising the functionality.
