The existing solution already computes the output directly from the inputs without using an intermediate signal, which is efficient. However, we can simplify the expression by using the properties of XOR and XNOR operations. The XNOR operation (`in1 == in2`) can be expressed as `!(in1 ^ in2)`, and then this result can be XORed with `in3`. This approach maintains the same functionality while potentially simplifying the logic.
