The existing implementation is already quite efficient, utilizing a single line of code to perform the required XNOR and XOR operations. However, we can attempt to further simplify the code by directly utilizing the properties of the XOR operator (`^`) to achieve the same result. The expression `~(in1 ^ in2 ^ in3)` effectively combines the XNOR of `in1` and `in2` with the XOR of the result and `in3`. Given the properties of these bitwise operators, we can maintain the same functionality while ensuring the code remains concise and readable.
