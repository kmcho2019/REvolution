To implement the traffic light system, we can utilize a Finite State Machine (FSM) with a single always block to manage the state transitions and counting logic. The FSM will have four states: idle, red, yellow, and green. The traffic light system will start in the idle state and transition to the red state. It will then cycle through the red, green, and yellow states based on the internal counter values. The pass_request signal will be used to adjust the green state duration. The output signals (red, yellow, green) will be driven by the current state of the FSM. We will use a single always block to handle the FSM logic, counting logic, and output signal assignments.
