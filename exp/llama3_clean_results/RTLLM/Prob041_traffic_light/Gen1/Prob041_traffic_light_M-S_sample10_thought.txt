To simplify the traffic light controller, we can utilize a single always block to handle both the state transition logic and the counting logic. We will use an enumeration to define the states of the traffic light and a case statement to manage the state transitions. The counting logic will be integrated into the state transition logic, allowing us to eliminate redundant code and always blocks. The output signals (red, yellow, green) will be assigned directly based on the current state of the traffic light controller.
