To create a novel solution, we can introduce a more modular and scalable architecture for the traffic light controller. This approach involves breaking down the functionality into smaller, independent modules, each responsible for a specific aspect of the traffic light's behavior.

The proposed architecture consists of three primary modules:

1.  **Traffic Light Controller (TLC):** This module is responsible for managing the overall state of the traffic light, including the transitions between red, yellow, and green states. It will be implemented as a finite state machine (FSM) with clearly defined states and transitions.
2.  **Pedestrian Request Handler (PRH):** This module handles the pedestrian request signal, determining when to shorten the green light duration or keep it unchanged based on the remaining time.
3.  **Counter and Timer (CT):** This module manages the internal counter and timer, responsible for decrementing the counter value and generating the output clock signal.

By separating the functionality into these modules, we can achieve a more modular, maintainable, and scalable design. Each module can be optimized independently, and the overall system can be easily extended or modified if needed.

Additionally, we will implement a clock gating technique to reduce dynamic power consumption by disabling the clock signal to unused modules.
