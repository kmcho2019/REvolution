To simplify the traffic light controller, we can reduce the number of states and use a more efficient encoding scheme. The controller can be simplified into three main states: red, yellow, and green. We can use a counter to keep track of the time spent in each state. When the pedestrian button is pressed, we can adjust the counter accordingly. We can also simplify the output signals by directly assigning them based on the current state.

The simplification strategy involves:

1.  Reducing the number of states to three: red, yellow, and green.
2.  Using a single counter to keep track of the time spent in each state.
3.  Simplifying the output signals by directly assigning them based on the current state.
4.  Minimizing the number of always blocks and combinational logic to reduce complexity.

By applying these simplifications, we can reduce the area, power consumption, and improve the performance of the traffic light controller.
