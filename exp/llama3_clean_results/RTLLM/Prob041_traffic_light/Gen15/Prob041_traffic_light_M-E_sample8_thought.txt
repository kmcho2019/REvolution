To create a novel solution for the traffic light controller, I will introduce a finite state machine (FSM) architecture that utilizes a more modular and scalable approach. The new design will focus on a parameterized state machine, where the timing for each state (red, yellow, green) is controlled by parameters that can be easily adjusted. This will enhance maintainability and flexibility.

The key components of the new architecture include:
1.  **Parameterized State Machine:** Define the states and their corresponding durations as parameters. This allows for easy modification of the traffic light sequence without altering the core logic.
2.  **Modular Counter Logic:** Implement a separate module for the counter logic, making it reusable and reducing code duplication.
3.  **Simplified Output Logic:** Use a single always block to handle the output signals, improving readability and reducing the risk of errors.
4.  **Efficient State Transition:** Utilize a case statement within the always block to manage state transitions, ensuring that the FSM progresses through the states correctly.

By adopting this modular and parameterized approach, the new traffic light controller design will be more efficient, scalable, and easier to maintain than the original implementation.
