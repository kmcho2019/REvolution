The novel architectural idea involves a hybrid approach that combines the benefits of a finite state machine (FSM) with a counter-based implementation. 

The proposed solution, named "traffic_light_controller," features a top-level FSM that manages the overall state of the traffic light, including the red, yellow, and green phases. 

Each state within the FSM is associated with a specific counter value, which determines the duration of that state. The counter is implemented as a separate module, allowing for easy modification or replacement if needed.

To improve PPA metrics, the design incorporates several optimizations:

1.  Reduced switching activity: The counter is only updated when the state changes, minimizing unnecessary switching activity.
2.  Efficient state encoding: The states are encoded using a one-hot scheme, reducing the number of bits required to represent the state and minimizing the complexity of the state transition logic.
3.  Simplified output logic: The output signals (red, yellow, green) are generated using a simple combinational logic block, reducing the area required for output decoding.

Overall, this hybrid approach offers a balanced trade-off between performance, power consumption, and area, making it an attractive solution for the traffic light controller.
