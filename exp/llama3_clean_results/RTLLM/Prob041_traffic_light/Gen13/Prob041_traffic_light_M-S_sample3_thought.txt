To simplify the solution, we will focus on reducing the complexity of the state machine and the counting logic while maintaining the overall functionality. 

1.  **State Machine Simplification:** We will merge the state transition and next state logic into a single always block. This will eliminate the need for the next_state register and simplify the combinational logic.
2.  **Counting Logic Simplification:** We will remove the conditional checks for setting the counter value based on the state and instead use a single variable to keep track of the remaining time for each state.
3.  **Output Signal Assignments:** We will use a more direct approach to assign the output signals based on the current state.
4.  **Reset Logic:** We will simplify the reset logic by removing unnecessary assignments and focusing on initializing the essential registers.

By simplifying the design, we aim to reduce the complexity, area consumption, and power consumption while maintaining the desired functionality.
