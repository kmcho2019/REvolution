To implement the sequence detector module, we will use a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input bitstream data_in. On each clock cycle, the detector will check for a match of the specific sequence 1001. If a match is found, the output sequence_detected will be set high. The reset signal reset_n will be used to initialize the state machine to the IDLE state when it is high.
