To implement the sequence detector module, we will design a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition between these states based on the input bitstream data_in. The sequence detection will be performed by checking the input data_in at each clock cycle and transitioning to the next state if the input matches the expected bit in the sequence. Once the complete sequence 1001 is detected, the output sequence_detected will be asserted high. The reset signal reset_n will be used to reset the state machine to the IDLE state when it is high.
