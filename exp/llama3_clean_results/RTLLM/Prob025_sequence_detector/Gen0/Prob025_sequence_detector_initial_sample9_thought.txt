To implement the sequence detector, we will use a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. The FSM will transition through these states based on the input data_in. On each clock cycle, the detector will check for a match of the specific sequence 1001. If the sequence is detected, the output sequence_detected will be set high. The FSM will be reset to the IDLE state when the reset_n signal is low.
