To simplify the sequence detector module, I will maintain the same functionality but reduce the complexity by using a state machine instead of a shift register. This approach allows for a more straightforward implementation of the sequence detection logic. The main points of the simplification include:

1. **State Machine Design**: Implement a finite state machine (FSM) with five states: IDLE, S1, S2, S3, and S4. Each state represents a step in the sequence detection process.
2. **Sequence Detection Logic**: Use the FSM to transition between states based on the input data_in. When the complete sequence is detected, assert the sequence_detected signal.
3. **Reset Behavior**: Ensure that the state machine resets to the IDLE state when the reset_n signal is low.

By using a state machine, the code becomes more concise and easier to understand, as it directly implements the sequence detection logic without the need for a shift register.
