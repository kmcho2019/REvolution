We can design the sequence detector using a Mealy machine with four states: IDLE, S1, S2, and S3, and S4. Each state corresponds to the detection of a specific bit in the sequence 1001. We use a single bit 'sequence_detected' to indicate when the sequence is detected. The machine starts in the IDLE state and transitions to subsequent states as the input matches the sequence. If the sequence is fully matched (i.e., we reach the final state S4), we set the 'sequence_detected' flag high. The state machine resets to the IDLE state when the reset signal 'reset_n' is low. To improve the detection efficiency, we can also add a shift register to store the last four input bits and check if they match the desired sequence.
