The novel architectural idea is to implement a Last-In-First-Out (LIFO) buffer using a circular queue data structure with two pointers: Head and Tail. The Head pointer tracks the location of the next data to be popped (read), and the Tail pointer tracks the location of the next data to be pushed (written). This approach allows for efficient use of memory and reduces the complexity of managing the buffer's state.

The key components of this design include:

1.  **Buffer Memory (buff_mem):** A 4-bit wide, 4-element deep memory array to store the data.
2.  **Head and Tail Pointers:** Two 2-bit registers (HEAD and TAIL) to keep track of the current head and tail positions in the buffer memory.
3.  **EMPTY and FULL Flags:** Two 1-bit registers to indicate whether the buffer is empty or full, updated based on the relative positions of the Head and Tail pointers.
4.  **RW Control Signal:** A 1-bit input to determine whether a push (write) or pop (read) operation should be performed.

The operations are managed as follows:

*   When the buffer is not full (FULL flag is low) and the RW signal is low (write operation), the Tail pointer is used to write data from the input **dataIn** into the buffer memory at the current Tail position, and then the Tail pointer is incremented in a circular manner (using modulo arithmetic).
*   When the buffer is not empty (EMPTY flag is low) and the RW signal is high (read operation), the Head pointer is used to read data from the buffer memory at the current Head position into the output **dataOut**, and then the Head pointer is incremented in a circular manner.

This circular queue implementation efficiently manages the buffer's state, reducing the complexity of pushing and popping data while minimizing the required memory and logic resources.
