The novel approach to designing the instruction register module involves using a single 8-bit register and implementing a multiplexer-based logic to select the source of the instruction. This approach aims to reduce the area consumption by minimizing the number of registers used. The idea is to use a single register to store the instruction and then use multiplexers to direct the instruction to the correct output ports based on the fetch signal. This design also incorporates a reset mechanism to initialize the register when the reset signal is low. By using a single register and multiplexers, the design aims to achieve better PPA metrics while maintaining the required functionality.
