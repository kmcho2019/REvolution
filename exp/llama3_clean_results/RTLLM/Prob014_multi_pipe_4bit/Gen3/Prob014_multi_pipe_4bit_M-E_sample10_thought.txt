The novel solution for the 4-bit unsigned number pipeline multiplier involves a systolic array architecture. This design utilizes an array of processing elements (PEs) connected in a linear fashion, where each PE is responsible for processing one bit of the multiplier. The multiplicand and multiplier are fed into the array from opposite ends, allowing the multiplication to be performed in a pipelined manner. Each PE will perform a multiplication and addition operation based on the bit of the multiplier it receives and the corresponding shifted version of the multiplicand.

The design consists of three main components: the input stage, the systolic array, and the output stage. The input stage is responsible for preparing the multiplicand and multiplier for processing by the systolic array. The systolic array performs the actual multiplication, with each PE adding its result to the partial product from the previous PE. The output stage collects the final product from the systolic array and presents it as the output of the multiplier.

The systolic array architecture allows for a highly parallel and efficient implementation of the multiplication operation, making it suitable for high-speed applications. By using a pipelined approach, the design can process one multiplication operation per clock cycle, resulting in a high throughput.

The use of a systolic array also simplifies the design and reduces the complexity of the control logic, as each PE performs the same operation and the data flows through the array in a predictable manner. This makes the design more modular and easier to scale for larger multiplier sizes.
