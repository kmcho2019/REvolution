The goal is to simplify the existing solution for a 4-bit comparator while maintaining its functionality. We will focus on reducing the complexity of the combinational logic used for comparison. 

Instead of using conditional statements to determine `A_greater` and `A_less` after checking for equality, we can directly compare `A` and `B` using simple operators. This approach eliminates the need for explicit conditional checks, making the code more concise.

By directly comparing `A` and `B` for equality, greater than, and less than conditions, we can ensure that the outputs (`A_greater`, `A_equal`, `A_less`) remain mutually exclusive, as only one condition can be true at any given time.

This simplified approach should reduce the complexity of the design without compromising its functionality or efficiency, potentially leading to better Power, Performance, and Area (PPA) metrics.
