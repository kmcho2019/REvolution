To implement the 8-bit Radix-4 Booth multiplier, we first need to understand the Booth algorithm and its modifications for Radix-4. The Booth algorithm is a method for multiplying two binary numbers in signed two's complement representation. In the Radix-4 version, we consider two bits of the multiplier at a time, which can reduce the number of additions required compared to the standard Booth algorithm.

We will start by designing a Verilog module named `multi_booth_8bit` that takes in the clock signal `clk`, the reset signal `reset`, the 8-bit multiplicand `a`, the 8-bit multiplier `b`, and produces the 16-bit product `p` along with a ready signal `rdy`.

Upon the positive edge of `clk` or the positive edge of `reset`, we check the state of `reset`. If `reset` is high, we initialize two 16-bit registers: `multiplier` with the sign-extended `a` and `multiplicand` with the sign-extended `b`. If `reset` is low, we proceed with the multiplication process.

We use a 5-bit counter `ctr` to keep track of the current bit position in the multiplier. If `ctr` is less than 16, we perform the following steps:
1. Left-shift the `multiplicand` by 1 bit to simulate the Booth algorithm's shifting operation.
2. Check the current and next bits of the `multiplier`. Based on the Radix-4 Booth encoding rules, we accumulate the value of the `multiplicand` into the product register `p`. The rules are as follows:
   - If the current and next bits are 00, we add 0.
   - If the current and next bits are 01, we add the `multiplicand`.
   - If the current and next bits are 10, we subtract the `multiplicand`.
   - If the current and next bits are 11, we subtract twice the `multiplicand` (which is equivalent to adding the `multiplicand` shifted left by 1).
3. Increment the counter `ctr`.
Once `ctr` reaches 16, we set the ready signal `rdy` to 1 to indicate the completion of the multiplication process.
