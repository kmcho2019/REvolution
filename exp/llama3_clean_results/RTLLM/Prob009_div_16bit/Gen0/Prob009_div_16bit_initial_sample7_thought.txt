To implement the 16-bit divider module, we need to follow these steps:
- Create a combinational logic that extracts the higher bits of the dividend, matching the bit width of the divisor.
- Compare the extracted dividend bits with the divisor to determine the quotient bit (1 if the dividend bits are greater, 0 otherwise).
- Use the difference between the extracted dividend bits and the divisor as the remainder for the next iteration.
- Concatenate the remainder with the highest remaining 1-bit of the dividend and repeat the process until all dividend bits are processed.
We can use two always blocks: the first to update the registers with the input values, and the second to perform the division operation.
We'll use a temporary register to store the intermediate results and update the output ports after all bits have been processed.
