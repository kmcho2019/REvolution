To implement the dual-port RAM, we first define the parameters WIDTH and DEPTH to represent the bit width and depth of the RAM, respectively. We then declare the RAM array as a 2D array of registers. Two always blocks are used to handle the write and read operations. The first always block is sensitive to the positive edge of the clock signal and the negative edge of the reset signal, and it performs the write operation when the write enable signal is active. The second always block is also sensitive to the positive edge of the clock signal and the negative edge of the reset signal, and it performs the read operation when the read enable signal is active.
