The new architecture, dubbed "Dual-Port RAM with Asynchronous Read and Synchronous Write" (DPRAWS), aims to minimize power consumption and optimize area utilization while maintaining performance.

However, the read operation is designed to be asynchronous, allowing the memory array to be read without being clocked. This asynchronous read approach can reduce power consumption by eliminating the need for clock signal distribution to the memory array during read operations.

The clock-gating mechanism will be simplified to reduce timing overhead, and additional power reduction techniques will be applied to minimize power consumption.
