The novel architectural idea is to use a Finite State Machine (FSM) to manage the series-parallel conversion process. The FSM will have two main states: an idle state and a data collection state. In the idle state, the module waits for the input valid signal to go high, indicating the start of a new data transmission. Once in the data collection state, the FSM will use a counter to keep track of the number of bits received and will shift the input bits into the parallel output register. After collecting all 8 bits, the FSM will transition to an output state, where it will set the output valid signal high and then return to the idle state, ready for the next transmission.
