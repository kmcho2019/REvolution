This FSM will have two main states: an idle state and a data collection state. Once the din_valid signal is high, the module transitions to the data collection state, where it collects 8 bits of serial data and constructs the parallel output. The FSM ensures that the module only updates the output when a full byte has been received, minimizing unnecessary switching activity and optimizing power consumption.

However, in this design, we will only utilize two states: idle (state 0) and data collection (state 1-7, where each state corresponds to the number of bits collected so far). The state register will be used to control the shifting of the serial data into the parallel output register and to determine when the output is valid.

This approach allows for a clean separation of the control logic (FSM) and the data processing logic (parallel output construction), making the design more modular and easier to maintain.
