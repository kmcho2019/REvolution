To create the frequency divider module `freq_diveven`, we need to implement a counter that increments on each positive edge of the input clock `clk` until it reaches half of `NUM_DIV - 1`, at which point it resets and toggles the output clock `clk_div`. We'll use a 4-bit register `cnt` for the counter. The `NUM_DIV` parameter will define the division factor, ensuring it's an even number. The module will also respond to an active-low reset signal `rst_n` to initialize both the counter and the divided clock signal `clk_div` to zero.
