To implement the frequency divider module `freq_diveven`, we need to define a parameter `NUM_DIV` to specify the division factor, which must be an even number. We will use a 4-bit counter (`cnt`) to track the number of clock cycles and generate the divided clock signal (`clk_div`). On each positive edge of the input clock (`clk`), we will check the current count and either increment the counter without changing `clk_div` or reset the counter and toggle `clk_div` to achieve the desired frequency division. The `rst_n` signal will be used to reset the module.
