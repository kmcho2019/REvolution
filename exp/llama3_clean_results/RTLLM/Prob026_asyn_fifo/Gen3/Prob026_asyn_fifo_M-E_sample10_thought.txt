1.  **Dual-Port RAM (DPRAM)**: A dual-port RAM module serves as the primary data storage element, allowing for simultaneous read and write operations.
2.  **Asynchronous Write Controller (AWC)**: The AWC is responsible for managing write operations, including generating write addresses, handling write data, and controlling the write clock domain.
3.  **Asynchronous Read Controller (ARC)**: The ARC handles read operations, generating read addresses, handling read data, and controlling the read clock domain.
4.  **Clock Domain Crossing (CDC) Module**: The CDC module ensures safe and reliable data transfer between the asynchronous write and read clock domains.

*   **Dynamic Depth Adjustment**: The FIFO's depth can be dynamically adjusted using a control signal, allowing for efficient use of resources in varying application scenarios.
