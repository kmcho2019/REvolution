To create a novel architectural solution for the fixed-point subtractor, we can implement a modular design that leverages the concept of hybrid arithmetic. This involves separating the integer and fractional parts of the input operands and performing subtraction on each part separately, then combining the results. This approach allows for a more granular control over the subtraction process, enabling accurate handling of same sign and different sign subtractions, as well as the zero result case. Additionally, by utilizing separate modules for integer and fractional part subtraction, we can optimize each component for power, performance, and area (PPA) independently. This modular design also facilitates easier integration of additional features such as rounding or saturation logic in the future. The key idea is to decompose the fixed-point subtraction into manageable components, allowing for a more scalable and maintainable design.
