To detect pulses in the input signal `data_in`, we can use a finite state machine (FSM) that transitions through different states based on the current and previous values of `data_in`. The FSM will have three main states: IDLE, PULSE_START, and PULSE_END. 

The IDLE state represents the initial condition where no pulse is detected. When `data_in` transitions from 0 to 1, the FSM moves to the PULSE_START state. If `data_in` then transitions back to 0, the FSM moves to the PULSE_END state and sets the output `data_out` to 1, indicating the end of a pulse. If `data_in` remains 1 or does not follow the expected pulse pattern, the FSM resets to the IDLE state.

This approach ensures that the pulse detection logic is robust and can handle various input sequences, including multiple pulses and invalid pulse patterns.
