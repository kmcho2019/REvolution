To implement the pulse detection module, we will use a finite state machine (FSM) to track the sequence of input values. The FSM will have three states: IDLE, PULSE_START, and PULSE_END. The IDLE state represents the initial state where we are waiting for a pulse to start. The PULSE_START state is entered when we detect a transition from 0 to 1 on the data_in signal, and the PULSE_END state is entered when we detect a transition from 1 to 0 after being in the PULSE_START state for at least one cycle. We will use a counter to ensure that we are in the PULSE_START state for at least one cycle before transitioning to the PULSE_END state. The data_out signal will be set to 1 when we are in the PULSE_END state, indicating the end of a pulse.
