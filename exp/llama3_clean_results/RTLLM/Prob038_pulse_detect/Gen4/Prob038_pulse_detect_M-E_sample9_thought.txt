A novel architectural approach for pulse detection can be based on a Finite State Machine (FSM) with a memory-based design. This approach, called a Memory-Based Pulse Detector (MBPD), utilizes a FSM to track the state of the input signal and a memory element to store the previous states. 

The MBPD architecture consists of a 3-state FSM: IDLE, RISING, and FALLING. The IDLE state represents the initial state, where the input signal is low. The RISING state is entered when the input signal transitions from low to high, and the FALLING state is entered when the input signal transitions from high to low.

When the FSM is in the RISING state and the input signal goes low, it transitions to the FALLING state. If the FSM is in the FALLING state and the input signal goes low for one clock cycle, it indicates the end of a pulse and the output is set high. Then, the FSM returns to the IDLE state. 

This approach allows for efficient pulse detection and can be easily implemented using digital logic.
