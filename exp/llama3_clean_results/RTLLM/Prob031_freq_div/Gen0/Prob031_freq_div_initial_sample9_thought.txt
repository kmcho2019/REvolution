To implement the frequency divider, we can use three separate counters to divide the input clock frequency. The counters will be used to generate the output clock signals with frequencies of 50MHz, 10MHz, and 1MHz. 
We will utilize the concept of toggle and reset for the output clock signals based on the counters' values. 
For the 50MHz output clock signal, we simply toggle the signal on every positive edge of the input clock. 
For the 10MHz and 1MHz output clock signals, we use counters to count the number of positive edges of the input clock and toggle the signals when the counters reach the desired values (4 for 10MHz and 49 for 1MHz).
