To implement the frequency divider, we can use three counters to divide the input clock frequency. For CLK_50, we can simply toggle its value on every positive edge of CLK_in. For CLK_10 and CLK_1, we can use counters cnt_10 and cnt_100 to keep track of the number of CLK_in cycles, and toggle their values when the counters reach the desired values. We also need to handle the reset logic to reset the counters and output clocks when RST is active.
