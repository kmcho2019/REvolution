To simplify the frequency divider module 'freq_div', we can directly utilize the sequential logic to update the output clocks without the need for additional counters. We can use the input clock signal and reset signal to directly toggle the output clocks with the desired frequency division ratios. For CLK_50, we simply toggle it on every positive edge of CLK_in. For CLK_10 and CLK_1, we use counters to keep track of the number of input clock cycles and toggle the output clocks accordingly. The counters can be reset when the reset signal is active.
