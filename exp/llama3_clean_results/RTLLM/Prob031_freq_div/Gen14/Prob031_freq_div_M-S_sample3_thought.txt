To simplify the frequency divider module, we can maintain the same functionality while reducing complexity by optimizing the counters and the logic for generating the output clocks. 

Since the 50MHz clock is generated by simply toggling the `CLK_50` signal on every positive edge of `CLK_in`, no counter is needed for this. For the 10MHz clock, a 2-bit counter (to count up to 4) is sufficient, and for the 1MHz clock, a 6-bit counter (to count up to 49) is sufficient. 

We can also simplify the reset logic by directly resetting the counters and output clocks in the always block without using separate if conditions for each signal. 

This simplified approach maintains the original functionality while making the code more concise and potentially easier to understand and maintain.
