The existing frequency divider design can be improved by utilizing a more modular and scalable approach. Instead of using separate counters for each output clock, we can design a single clock divider module that can be instantiated multiple times to generate different frequencies. This modular design will simplify the code, reduce duplication, and make it easier to add or remove output clocks in the future.

We will create a parameterized module `clock_divider` that takes the input clock, reset signal, and a divisor as parameters. The module will generate an output clock with a frequency equal to the input clock divided by the divisor. We will then instantiate this module three times with different divisors to generate the 50MHz, 10MHz, and 1MHz output clocks.

This approach will not only simplify the code but also make it more flexible and reusable. If we need to add more output clocks in the future, we can simply instantiate the `clock_divider` module with the desired divisor, without modifying the existing code.
