To implement the barrel shifter module, we first define a submodule for the 2-to-1 multiplexer (`mux2X1`), which is used to select between two input values based on a select signal. Then, we use this submodule to construct the barrel shifter. The barrel shifter shifts the input in stages based on the control signal `ctrl`. Each bit of `ctrl` controls a different stage of shifting: `ctrl[2]` shifts by 4 positions, `ctrl[1]` shifts by 2 positions, and `ctrl[0]` shifts by 1 position. We use a hierarchical approach, first defining the `mux2X1` and then the `barrel_shifter` module.
