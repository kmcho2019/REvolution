To simplify the perpetual calendar module, we can merge the logic for updating the seconds, minutes, and hours values into a single always block. This approach eliminates the need for separate always blocks, reducing complexity. Within this single always block, we can use conditional statements to handle the reset signal and update the time values accordingly. By maintaining the use of non-blocking assignments and a straightforward update logic, we can ensure that the functionality remains the same while improving the overall simplicity and potentially the Power, Performance, and Area (PPA) metrics.
