To implement a perpetual calendar module, we can utilize a novel approach that employs a finite state machine (FSM) to manage the seconds, minutes, and hours counters. This FSM-based design can efficiently handle the counting and wrapping around of the counters while minimizing the complexity of the conditional logic.

The key idea is to define a set of states that represent the current values of the counters and use a next-state logic to determine the updated values based on the current state and the reset signal. This approach enables a clean and efficient design that is easy to understand and maintain.

In this novel solution, we will define six states: S0 (initial state), S1 (normal counting), S2 (minutes wrap-around), S3 (hours wrap-around), S4 (hours and minutes wrap-around), and S5 (reset state). The FSM will transition between these states based on the current values of the counters and the reset signal.

By employing this FSM-based approach, we can create a perpetual calendar module that is both efficient and easy to understand. The use of a finite state machine simplifies the design and reduces the complexity of the conditional logic, making it easier to maintain and modify.

Additionally, this approach allows for easy extension of the design to include additional features, such as alarm functions or timer capabilities, by simply adding new states and transitions to the FSM.
