To implement a perpetual calendar module, we can utilize a counter-based approach. The idea is to use a single counter that increments every clock cycle and then use this counter value to derive the seconds, minutes, and hours. This approach simplifies the logic and reduces the number of always blocks required. We can use a 32-bit counter to ensure that it can handle the maximum number of seconds in a day (86,400 seconds) without wrapping around too frequently. The seconds, minutes, and hours can then be calculated using simple arithmetic operations on the counter value.
