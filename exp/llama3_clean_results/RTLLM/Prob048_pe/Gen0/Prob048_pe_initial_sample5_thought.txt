The MAC (Multiply-Accumulate) operation can be implemented using a single always block in Verilog. We will use a register, c, to store the accumulated result. On every positive edge of the clock signal (clk), the module will update the register. If the reset signal (rst) is high, the register will be reset to 0. Otherwise, it will be updated by adding the product of the input operands (a and b) to its current value. The multiplication operation can be performed using the built-in multiplication operator (*).
