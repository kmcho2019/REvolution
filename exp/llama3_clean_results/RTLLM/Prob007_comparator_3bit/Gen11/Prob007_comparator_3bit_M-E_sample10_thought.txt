To create a novel solution for the 3-bit comparator, we will introduce a hierarchical design approach, where the comparison is performed in stages. This approach is particularly useful for larger comparators but can also be applied to smaller ones like the 3-bit comparator to demonstrate the concept. The idea is to break down the comparison into smaller sub-comparisons, each handling one bit of the input operands.

We will design a module called `bit_comparator` that compares two single bits and produces outputs indicating if the first bit is greater than, equal to, or less than the second bit. Then, we will use instances of this `bit_comparator` module within the `comparator_3bit` module to perform the comparison of the 3-bit numbers. The final outputs will be determined based on the results of these sub-comparisons, following the principles of binary number comparison.

This hierarchical approach allows for easier extension to comparators of larger bit widths, as the same `bit_comparator` module can be reused. It also helps in managing complexity by breaking down the comparison logic into smaller, more manageable pieces.
