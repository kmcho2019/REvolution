The module square_wave can be designed using a finite state machine with a counter. The counter increments on each rising edge of the clk. When the counter reaches the specified frequency value (freq - 1), it resets and toggles the wave_out signal. This effectively produces a square wave with a frequency determined by the input frequency value. 
To implement this, we use an always block to handle the sequential logic of the counter and the output signal wave_out. We also use a non-blocking assignment to avoid race conditions and ensure proper behavior in an event-driven simulation environment.
