To generate a square wave signal with variable frequency, we will utilize a counter register 'count' that increments on each rising edge of the input clock signal 'clk'. When 'count' reaches the specified frequency value 'freq' minus one, we will reset 'count' to zero and toggle the 'wave_out' signal. This way, the frequency of the square wave is controlled by the input 'freq' value. The higher the 'freq' value, the slower the square wave toggles.
