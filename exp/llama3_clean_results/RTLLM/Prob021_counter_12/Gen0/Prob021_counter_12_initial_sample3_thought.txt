The counter_12 module will be implemented using a 4-bit output register (out) that is incremented on each clock cycle when the valid_count signal is active (1). The module will have an asynchronous active-low reset (rst_n) that resets the counter to 0 when asserted. The valid_count signal acts as a gate to control the counting process, pausing the counter when it is 0. To prevent overflow, the counter will wrap around to 0 after reaching the maximum count value (4'd11).
