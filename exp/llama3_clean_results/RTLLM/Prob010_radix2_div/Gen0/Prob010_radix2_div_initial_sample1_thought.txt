To implement a simplified radix-2 divider, we need to design a finite state machine (FSM) that handles the division process. The FSM will have two main states: idle and division. In the idle state, the module waits for a valid operation request (opn_valid is high and res_valid is low) and then saves the inputs dividend and divisor. In the division state, the module performs the division process, which involves shifting the dividend, subtracting the divisor, and updating the quotient and remainder. We will use a counter to keep track of the number of iterations and a flag (start_cnt) to indicate when the division process should start. We will also use a multiplexer to select the appropriate result based on the carry-out of the subtraction.
