To simplify the solution, we can implement a 16-bit full adder using a single instance of a 1-bit full adder, which takes two input bits and a carry-in, and produces an output bit and a carry-out. We will then use a generate block to instantiate 16 instances of the 1-bit adder, connecting the carry-out of each instance to the carry-in of the next instance. This approach eliminates the need for separate 8-bit adder modules and reduces the overall complexity of the design.
