We can achieve this by using a flip-flop to store the previous state of 'a' and then compare it with the current state on the next clock edge. If the current state is different from the previous state, we detect an edge and set the corresponding output signal (rise or down) to 1. We also need to reset the output signals to 0 after they have been set to 1. This can be done by using a reset signal or by resetting them on the next clock edge.
