To implement the up_down_counter module, we need to use a synchronous process triggered by the rising edge of the clock signal (clk). Inside this process, we first check if the reset signal is active. If it is, we reset the counter to zero. Then, we check the up_down control signal. If it is high, we increment the counter; if it is low, we decrement the counter. We use a non-blocking assignment to update the count output in both cases.
