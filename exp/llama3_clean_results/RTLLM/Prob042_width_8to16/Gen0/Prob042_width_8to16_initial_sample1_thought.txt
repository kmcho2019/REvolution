To solve this problem, we will use a Finite State Machine (FSM) with two main states: idle and waiting_for_second_data. When the valid_in signal is asserted and the module is in the idle state, the data_in will be stored in a temporary register (data_lock). Then, the module transitions to the waiting_for_second_data state. In this state, when another valid data_in arrives, the data_lock and data_in will be concatenated and the result will be assigned to the data_out register. The valid_out signal will be asserted in the same clock cycle to indicate that the data_out is valid. 
We also need to handle the reset condition where the module is reset when the rst_n signal is low.
