To implement the 4-bit Linear Feedback Shift Register (LFSR), we'll follow these steps:
1. Define the module with the given input and output ports.
2. Declare a 4-bit internal register to hold the current state of the LFSR.
3. Use a process statement to synchronize the LFSR's operation with the rising edge of the clock signal.
4. Inside the process, check if the reset signal is high. If so, reset the internal register to zero.
5. If the reset signal is not high, calculate the feedback signal by XORing the most significant bit and the second most significant bit, then inverting the result.
6. Shift the bits in the internal register to the left and insert the new feedback value at the least significant bit.
7. Assign the current state of the internal register to the output port.
