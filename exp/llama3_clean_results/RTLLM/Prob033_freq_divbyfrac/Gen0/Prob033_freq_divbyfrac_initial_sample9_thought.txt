To implement a frequency divider that divides the input clock frequency by a fractional value (3.5x), we will employ the double-edge clocking technique. This involves creating an intermediate divided clock signal with uneven clock periods, which are then phase-shifted and logically combined to produce a smooth fractional clock output.

The design will use a counter to track the clock cycles, and based on the count, it will generate two different clock periods: one with 4 source clock cycles and another with 3 source clock cycles. These periods will be used to create phase-shifted versions of the divided clock. Finally, the phase-shifted clocks will be OR-ed together to produce the final fractional divided clock output.

The module will have the following components:
1. A counter to track the clock cycles.
2. Logic to generate the uneven clock periods based on the counter value.
3. Phase-shifting logic to delay and advance the divided clock phases.
4. A logical OR operation to combine the phase-shifted clocks and produce the final output.

- MUL2_DIV_CLK: The number of clock cycles to divide the input clock frequency. For 3.5x division, MUL2_DIV_CLK = 7.
