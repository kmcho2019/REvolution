The primary changes include:

1.  **Simplifying the Digital Frequency Divider**: Instead of using a complex state machine with multiple counters and state registers, I will use a single counter and a more straightforward logic to generate the divided clock signal.
2.  **Implementing Phase-Shifting**: I will implement the phase-shifting logic using a separate counter and a simple logical operation.
3.  **Logical OR-ing**: The final clock output `clk_div` will be generated by logically OR-ing the phase-shifted clock signals.

The refactored code will use `always` blocks for sequential logic and will simplify the state machine structure to reduce the complexity of the code.

*   When `div_counter` is between 0 and 3, `clk_div_4` will be high.
