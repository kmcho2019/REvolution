Implement a 2-bit counter that starts counting from 0 when reset is asserted. On reset, set a 2-bit counter to 3 (to count four cycles: 3,2,1,0). While the counter is not zero, assert shift_ena. Decrement the counter on each clock cycle. When the counter reaches zero, deassert shift_ena and keep it low until the next reset. Since reset is synchronous and active high, implement the counter and shift_ena logic inside a clocked always block.
