To enable shift_ena for exactly 4 clock cycles after reset (which is active high synchronous), we can implement a 2-bit counter that counts from 0 to 3 while shift_ena is asserted. On reset, the counter is reset to 0 and shift_ena is asserted. The counter increments on each clock cycle until it reaches 3, then shift_ena is deasserted. After that, shift_ena remains 0 until the next reset.
