We implement a simple FSM with 4 states: IDLE (waiting for a byte with in[3]=1), BYTE1 (store first byte), BYTE2 (store second byte), BYTE3 (store third byte and assert done). On reset, go to IDLE. In IDLE, ignore input bytes until in[3] == 1, then store as first byte and move to BYTE2. On each byte state, store the input byte in corresponding byte position. After BYTE3 received, assert done for one cycle, output the 24-bit message with byte1 in MSB, byte2 middle, byte3 LSB. Then return to IDLE. The output out_bytes is valid only when done is asserted. The design is synchronous with active-high synchronous reset.
