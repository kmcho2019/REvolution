Implement a 2-bit counter to track the current byte number in the message (0 to 3). On reset, clear the counter and output registers. When not in a message, wait until a byte with in[3] == 1 arrives to start capturing bytes. Once started, shift bytes into a 24-bit register with the first byte in the most significant 8 bits. When the third byte is captured (counter reaches 3), assert done for one cycle and output the full 24-bit message. The done signal is asserted for one cycle immediately after the third byte is received, with out_bytes valid at that time.
