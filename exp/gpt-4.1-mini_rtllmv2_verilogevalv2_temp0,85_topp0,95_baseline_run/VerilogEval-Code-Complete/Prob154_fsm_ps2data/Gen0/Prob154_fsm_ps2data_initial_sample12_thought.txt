Implement a 2-bit counter state machine to track the position within the 3-byte message. On reset, clear the counter and done signal. When not in message (counter==0), wait for input with bit in[3] = 1 to start message reception. Once started, shift in bytes every clock cycle, increment the counter. When the counter reaches 3, assert done for one cycle and output the concatenated 3 bytes stored in a shift register. The 24-bit shift register holds the bytes: the oldest byte is at bits [23:16], newest at [7:0]. The done signal is asserted for one cycle immediately after the third byte is received.
