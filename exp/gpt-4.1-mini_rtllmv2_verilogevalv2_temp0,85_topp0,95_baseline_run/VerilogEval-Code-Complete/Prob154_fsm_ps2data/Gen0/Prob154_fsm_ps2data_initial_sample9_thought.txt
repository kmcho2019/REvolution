We will implement a synchronous FSM with three states: IDLE, BYTE2, BYTE3.
- In IDLE, we wait for a byte with in[3] = 1 to start the message. When found, save it as the first byte and move to BYTE2.
- In BYTE2, save the second byte and move to BYTE3.
- In BYTE3, save the third byte, assert done for one cycle, then return to IDLE.
The 24-bit output concatenates the three bytes, with the first byte in the most significant 8 bits.
done is asserted for exactly one cycle immediately after receiving the third byte.
On synchronous reset, FSM returns to IDLE and output/done are cleared.
