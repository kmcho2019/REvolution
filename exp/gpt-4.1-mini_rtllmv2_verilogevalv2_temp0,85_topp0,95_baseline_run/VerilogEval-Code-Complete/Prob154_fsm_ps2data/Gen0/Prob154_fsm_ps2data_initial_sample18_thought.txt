Implement a three-state FSM with a counter to track how many bytes of the message have been received. Initially, discard bytes until a byte with in[3] = 1 is seen, marking the first byte of a message. Then, shift in bytes on each clock cycle until 3 bytes are collected. After the third byte, assert done for one cycle and output the concatenated 24-bit message. Use synchronous reset to clear state and outputs.
