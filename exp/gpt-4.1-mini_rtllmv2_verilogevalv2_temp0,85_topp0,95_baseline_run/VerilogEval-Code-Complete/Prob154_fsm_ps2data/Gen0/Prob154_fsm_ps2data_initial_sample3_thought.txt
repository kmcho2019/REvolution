We implement a simple FSM with states representing how many bytes of a message have been collected (0,1,2,3). On reset, we start in state 0 (waiting for start byte). We look for a byte where in[3] = 1 to identify the first byte of a message. Once found, we shift the bytes into a 24-bit register as they arrive. After receiving three bytes, we assert done for one cycle, output the collected message, and return to state 0 to look for the next message. The output is updated only when done is asserted, else it can be don't-care. The reset is synchronous active high.
