Implement a simple FSM with three states: IDLE (discard bytes until in[3] is 1), BYTE2 (store second byte), BYTE3 (store third byte). On reset, go to IDLE. On input byte when in IDLE, if in[3] == 1, capture byte as first byte and move to BYTE2. On BYTE2, capture second byte and move to BYTE3. On BYTE3, capture third byte, assert done signal for one cycle, output concatenated 24-bit message, then return to IDLE. The output should only be valid when done is asserted; otherwise, it is don't-care.
