We need a 2-bit counter to track the bytes of the message after detecting the first byte with in[3]=1. Before detecting that, we discard bytes. Once the first byte is accepted, we store it in out_bytes[23:16]. On the next clock cycles, we store subsequent bytes into out_bytes[15:8] and out_bytes[7:0]. When the third byte is stored, the done signal is asserted for one cycle. The output is valid when done is asserted. Reset synchronously resets the FSM and counter.
