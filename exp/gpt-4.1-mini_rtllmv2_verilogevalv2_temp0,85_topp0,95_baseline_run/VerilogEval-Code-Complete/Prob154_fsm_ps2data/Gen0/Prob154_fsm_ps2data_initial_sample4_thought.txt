Implement a simple FSM with three states: IDLE, BYTE2, BYTE3. In IDLE, we wait for a byte where in[3] = 1 to mark the start of a message. When found, store this as the first byte and move to BYTE2. In BYTE2, store the second byte and move to BYTE3. In BYTE3, store the third byte and assert done in the next cycle. The out_bytes output concatenates the three bytes as specified. The reset synchronously resets the FSM and stored bytes. done is asserted for one cycle immediately after the third byte is stored.
