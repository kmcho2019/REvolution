Implement a 2-bit counter to track the message byte position (0 to 2). On reset, clear the counter and output. Wait for a byte with in[3] = 1 to start capturing bytes. When such a byte arrives, treat it as the first byte of a message and save it in out_bytes[23:16]. On subsequent clocks, shift the older bytes down and capture the new bytes into out_bytes[15:8] and out_bytes[7:0]. After the third byte is captured (counter == 2), assert done for that cycle and hold out_bytes valid. After done is asserted, wait for the next byte with in[3] = 1 to start a new message.
