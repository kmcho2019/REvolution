Implement a simple 2-bit state counter that counts the bytes after detecting a start byte (in[3] = 1). On reset, clear the counter and output. When in[3]=1 and the FSM is not counting, start counting from 1 and store the first byte as the highest byte of the message. On next bytes, increment count and shift bytes in. When count reaches 3, assert done and output the 24-bit message formed by the three consecutive bytes. The done signal is high for one cycle immediately after the third byte is received.
