Implement a synchronous FSM with 4 states: IDLE (discarding bytes until in[3]==1), BYTE1 (store first byte), BYTE2 (store second byte), BYTE3 (store third byte and assert done). On reset, return to IDLE. Capture bytes in registers as they arrive. Output done is asserted for one cycle immediately after the third byte is stored, and out_bytes holds the 3-byte message with the first byte in the most significant bits.
