Implement a simple FSM with 4 states: IDLE (discard bytes until in[3] == 1), BYTE1 (store first byte), BYTE2 (store second byte), BYTE3 (store third byte and assert done). On synchronous reset, return to IDLE. The FSM advances on each clock cycle. The output done is asserted only for one clock cycle immediately after receiving the third byte. The out_bytes output holds the concatenation of the 3 bytes in the order first byte [23:16], second byte [15:8], third byte [7:0]. During reset or other times done=0, out_bytes can be don't-care. Use registers to store the bytes and output them at the done cycle.
