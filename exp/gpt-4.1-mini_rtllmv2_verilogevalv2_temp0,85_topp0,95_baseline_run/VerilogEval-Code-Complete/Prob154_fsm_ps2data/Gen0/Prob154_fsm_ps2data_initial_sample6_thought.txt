We implement a synchronous FSM with three states: IDLE, BYTE2, BYTE3. Initially, we discard bytes until we find a byte with bit 3 set (in[3] == 1). That byte is stored as the first byte (out_bytes[23:16]). Then on next cycles, we store the second and third bytes (out_bytes[15:8] and out_bytes[7:0]), advancing the state each cycle. When the third byte is received, we assert done for one cycle and output the 24-bit message assembled from the three bytes. Reset synchronously resets state and outputs.
