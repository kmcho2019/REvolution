Implement a simple FSM with three states to count bytes after detecting a start byte (with in[3]=1). 
When reset is asserted, FSM goes to idle state discarding bytes. 
On detecting in[3]=1, store first byte in the highest byte position of out_bytes, go to state 1. 
Then store next byte in middle byte, go to state 2. 
Store third byte in lowest byte, assert done for one cycle, then return to idle state to look for next message. 
Output out_bytes only when done is asserted.
