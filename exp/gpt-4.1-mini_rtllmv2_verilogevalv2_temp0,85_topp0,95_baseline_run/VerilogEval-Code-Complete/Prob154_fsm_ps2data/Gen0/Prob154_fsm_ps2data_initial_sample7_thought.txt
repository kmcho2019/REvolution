Implement a simple FSM with a 2-bit state counter that tracks the number of bytes stored after detecting the start byte (where in[3] == 1). 
- When reset is asserted, clear the state and outputs.
- If not in a message (state == 0), check if in[3] == 1 to start collecting bytes.
- When collecting bytes, shift the previously stored bytes left by 8 bits and insert the new byte at the LSB side.
- After 3 bytes are collected (state == 3), assert done for one cycle with out_bytes containing the three bytes.
- The done signal is one cycle pulse immediately after the 3rd byte is received.
- The FSM then resets to look for next message.
