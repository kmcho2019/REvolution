Implement a 2-bit state counter to track how many message bytes have been received. On reset, the FSM waits to find a byte with in[3]=1. When such a byte arrives, it is considered the first byte of a message, stored in the upper byte of out_bytes, and the state counter increments. Subsequent bytes are stored in the next byte positions. When the third byte arrives, done is asserted for one cycle (immediately after the third byte was received), and the state counter resets to zero to look for the next message. The output out_bytes is updated synchronously with each byte stored and valid when done is asserted. The reset is synchronous and active high.
