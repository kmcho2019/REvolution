Implement a 4-bit register that on each clock edge either shifts in the input data (MSB first) if shift_ena is high, or decrements the register value by 1 if count_ena is high. Since both control signals are never asserted simultaneously for valid operation, we do not prioritize one over the other and just implement if-else structure. On reset (not specified here), we can initialize q to zero. The shifting should move all bits right, with the new data bit shifted into the MSB position. The counting simply decrements q.
