Implement a 4-bit register `q` that on a rising clock edge either shifts in the input `data` at the MSB if `shift_ena` is asserted, or decrements the current value in `q` if `count_ena` is asserted. Since the problem states the two enable signals won't be high at the same time, we can simply prioritize shift operation when `shift_ena` is high, else do the count operation when `count_ena` is high, else hold the value.
