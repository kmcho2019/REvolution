Implement a 4-bit register that updates on the rising edge of clk. If shift_ena is high, shift in the input data at the MSB position, shifting existing bits right. If count_ena is high (and shift_ena is low), decrement the 4-bit value q by 1. Since both signals are never 1 together in real use, priority can be given arbitrarily; here shift_ena has priority over count_ena.
