The design uses a 4-bit register q that either shifts in the input data at the MSB when shift_ena is high, or decrements the current value by 1 when count_ena is high. Since the two signals are never both high at the same time in usage, no special priority logic is needed; we can check shift_ena first then count_ena. On each rising clock edge, if shift_ena is 1, shift q left by one and insert data at q[3]. Else if count_ena is 1, subtract 1 from q. Otherwise, retain the value.
