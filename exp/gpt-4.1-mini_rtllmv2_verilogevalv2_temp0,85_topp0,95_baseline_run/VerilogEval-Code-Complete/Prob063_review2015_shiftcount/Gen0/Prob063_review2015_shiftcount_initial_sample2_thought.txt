Implement a 4-bit shift register with synchronous logic. On each clock edge, if shift_ena is high, shift the register left by one and shift in the input data at the MSB. If count_ena is high (and shift_ena is low), decrement the value in the register by 1. If both are high, the behavior can be arbitrary; we will prioritize shifting since it matches the order of if-else statements. Initialize the register to zero on reset.
