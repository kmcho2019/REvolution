Implement a 4-bit register q updated on the rising edge of clk. When shift_ena is 1, shift q left by one bit and input the new data at LSB (since MSB is shifted in first, the data goes to q[3]). When count_ena is 1, decrement q by 1. If both are zero, q stays the same. It doesn't matter which has priority if both are 1, so pick either shift or count first in if-else.
