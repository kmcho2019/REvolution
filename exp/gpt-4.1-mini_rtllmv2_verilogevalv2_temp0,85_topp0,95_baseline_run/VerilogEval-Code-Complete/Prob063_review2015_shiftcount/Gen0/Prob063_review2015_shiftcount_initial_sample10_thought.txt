The design is a 4-bit shift register with two modes controlled by shift_ena and count_ena. When shift_ena is high, the register shifts left (MSB first) and shifts in the input data at the LSB. When count_ena is high (and shift_ena is low), the register decrements its value by 1. We implement synchronous logic triggered on the rising edge of clk. The priority between shift_ena and count_ena doesn't matter if both are 1, so we can check shift_ena first and then count_ena.
