The design is a 4-bit register with two modes controlled by shift_ena and count_ena. When shift_ena is high, the register shifts left, shifting in the input data at the MSB. When count_ena is high (and shift_ena is low), the register decrements its value by 1. If both are high simultaneously, the behavior can be arbitrary, so we can prioritize shift_ena over count_ena or vice versa. Here, we will prioritize shift_ena, so shifting happens if shift_ena is 1, else counting happens if count_ena is 1.
