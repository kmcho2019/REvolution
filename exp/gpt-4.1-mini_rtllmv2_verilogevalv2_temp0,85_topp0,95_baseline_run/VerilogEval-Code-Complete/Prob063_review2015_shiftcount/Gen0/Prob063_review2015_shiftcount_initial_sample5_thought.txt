Implement a 4-bit register that either shifts in the input bit at the MSB position when shift_ena is 1, or decrements the register value by 1 when count_ena is 1. Since shift_ena and count_ena are never both 1 in use, we don't prioritize one over the other explicitly. On the rising edge of clk, if shift_ena is high, shift in the new data bit; else if count_ena is high, decrement the value; otherwise, maintain the current value.
