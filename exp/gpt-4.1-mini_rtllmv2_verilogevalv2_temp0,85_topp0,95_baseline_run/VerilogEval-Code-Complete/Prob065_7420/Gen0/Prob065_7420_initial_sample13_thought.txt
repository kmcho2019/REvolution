Implement the 7420 chip functionality by instantiating two 4-input NAND gates. Each NAND gate takes four inputs and produces one output. For the first NAND gate, inputs are p1a, p1b, p1c, p1d, and the output is p1y. For the second NAND gate, inputs are p2a, p2b, p2c, p2d, and the output is p2y.
