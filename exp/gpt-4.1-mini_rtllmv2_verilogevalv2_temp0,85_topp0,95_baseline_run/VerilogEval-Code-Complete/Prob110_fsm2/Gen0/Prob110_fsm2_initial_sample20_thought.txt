Implement a Moore state machine with two states: OFF and ON.
- Use an asynchronous active-high reset to set the state to OFF.
- On each clock edge, update the state according to inputs j and k:
  - From OFF state: if j=1 go to ON; else stay OFF.
  - From ON state: if k=1 go to OFF; else stay ON.
- Output is based solely on the current state: 0 for OFF, 1 for ON.
