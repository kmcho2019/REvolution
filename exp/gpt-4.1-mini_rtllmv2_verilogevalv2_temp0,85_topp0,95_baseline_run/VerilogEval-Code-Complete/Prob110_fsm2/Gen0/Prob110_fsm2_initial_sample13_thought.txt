Implement a Moore state machine with two states: OFF and ON. The output is 0 in OFF and 1 in ON. The asynchronous reset (active-high) sets the state to OFF. On each clock edge, update the state based on the current state and inputs j and k as described: from OFF, j=1 transitions to ON; from ON, k=1 transitions to OFF; otherwise stay in the current state. Output is assigned based on the state.
