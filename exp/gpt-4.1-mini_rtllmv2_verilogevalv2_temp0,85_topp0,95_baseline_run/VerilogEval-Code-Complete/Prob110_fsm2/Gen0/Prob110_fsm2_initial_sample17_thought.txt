Implement a two-state Moore state machine with asynchronous active-high reset.
States: OFF (0) and ON (1).
On reset, state goes to OFF.
Transitions:
- From OFF: if j=0 stay OFF, if j=1 go to ON.
- From ON: if k=0 stay ON, if k=1 go to OFF.
Output is 0 in OFF and 1 in ON.
Use a reg to hold the current state, update it on the positive clock edge or asynchronously reset to OFF.
Output is directly assigned from the state.
