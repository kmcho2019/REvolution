Implement a Moore state machine with two states: OFF and ON. The output depends only on the current state (OFF=0, ON=1). On asynchronous active-high reset, the machine goes to OFF. The transitions are:

- OFF: if j=0 stay OFF; if j=1 go to ON
- ON: if k=0 stay ON; if k=1 go to OFF

Use a sequential always block for the state with asynchronous reset, and a combinational always block or continuous assignment for the output based on the state.
