To implement a Mealy FSM detecting the sequence "101" with overlapping sequences and a negative edge triggered asynchronous reset, we'll define three states representing progress through the sequence:

- S0: Initial state, no match yet.
- S1: Detected a '1'.
- S2: Detected "10".

Transitions:
- From S0:
  - x=1 -> S1, z=0
  - x=0 -> S0, z=0
- From S1:
  - x=0 -> S2, z=0
  - x=1 -> S1, z=0 (stay since another '1' can be start)
- From S2:
  - x=1 -> S1, z=1 (sequence "101" detected)
  - x=0 -> S0, z=0

The output z is asserted when transitioning from S2 on input x=1, as per Mealy machine behavior.

The FSM is negative edge asynchronous reset, so the reset logic triggers on negedge aresetn.

We'll implement state encoding using a 2-bit register for 3 states and ensure output z is combinational with current state and input x.
