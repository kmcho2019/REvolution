To implement a Mealy FSM that detects the sequence "101" with overlapping recognition using only 3 states, define the states as follows:
- S0: Initial state, no part of the sequence detected yet.
- S1: Detected '1' as the first bit of the sequence.
- S2: Detected "10" as the first two bits of the sequence.

Transition logic:
- From S0:
  - If x=1, go to S1.
  - Else stay at S0.
- From S1:
  - If x=0, go to S2.
  - If x=1, stay at S1 (since overlapping sequences can start again).
- From S2:
  - If x=1, output z=1 (sequence "101" detected), then go to S1 (because last bit is '1', could start new sequence).
  - Else go to S0.

The output z is asserted on the transition that completes the sequence, making it Mealy-type (output depends on current state and input).

The FSM uses negative edge triggered asynchronous reset (aresetn), meaning that when aresetn goes low (0), the FSM resets immediately to S0.

Implement the state encoding using an enum or localparam. Use an always block triggered on the positive edge of clk and the negative edge of aresetn for asynchronous reset.

Output z is combinational within the always block based on the transition.
