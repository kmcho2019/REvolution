Implement a 3-state Mealy FSM to detect the sequence "101" with overlapping detection. Use states to track the progress in the sequence: 
- State S0: initial state, waiting for '1' 
- State S1: detected '1', waiting for '0' 
- State S2: detected '10', waiting for '1' to complete sequence.

On negative edge asynchronous reset (aresetn), reset to initial state. The output z is asserted when the last input completes the sequence "101". The FSM is Mealy-type, so output z depends on state and input. Overlapping sequences are handled by careful transitions.

States encoding:
- S0 = 0
- S1 = 1
- S2 = 2

Transitions:
- S0 + x=1 -> S1, z=0
- S0 + x=0 -> S0, z=0
- S1 + x=0 -> S2, z=0
- S1 + x=1 -> S1, z=0 (stay in S1 because input '1' again can start a new sequence)
- S2 + x=1 -> S1, z=1 (sequence "101" detected)
- S2 + x=0 -> S0, z=0

Negative edge async reset is implemented on aresetn.
