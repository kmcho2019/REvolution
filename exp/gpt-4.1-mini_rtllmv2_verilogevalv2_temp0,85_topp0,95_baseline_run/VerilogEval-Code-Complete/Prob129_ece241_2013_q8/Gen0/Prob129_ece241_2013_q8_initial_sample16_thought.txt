To implement a Mealy FSM that detects the sequence "101" with overlapping recognition and only 3 states, we can define states as follows:
- S0: Initial state, no matching bits yet.
- S1: Detected '1' (the first bit of the sequence).
- S2: Detected '10' (the first two bits of the sequence).

Transitions:
- From S0:
  - x=1 → S1, z=0
  - x=0 → S0, z=0
- From S1:
  - x=0 → S2, z=0
  - x=1 → S1, z=0 (stay in S1 because sequence could restart)
- From S2:
  - x=1 → S1, z=1 (sequence "101" detected)
  - x=0 → S0, z=0

Output z is asserted in the transition from S2 to S1 on input x=1 because "101" is completed here.

The FSM uses negative edge asynchronous reset to set the state to S0.

We'll implement this with a state register, combinational logic for next state and output, and asynchronous reset triggered on negedge aresetn.
