Implement a 3-state Mealy FSM to detect the sequence "101" on input x. The states represent how much of the sequence has been matched so far. We assert output z = 1 on the clock cycle when the final '1' of "101" is input, indicating detection. The FSM resets asynchronously on the negative edge of aresetn. The overlapping sequence is handled by the state transitions that consider the current input and next state accordingly.
