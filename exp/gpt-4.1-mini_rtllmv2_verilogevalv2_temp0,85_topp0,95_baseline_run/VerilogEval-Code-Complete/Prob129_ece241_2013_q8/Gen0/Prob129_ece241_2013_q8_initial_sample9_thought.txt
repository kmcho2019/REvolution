To implement a Mealy FSM that recognizes the sequence "101", we need three states representing the progress of the sequence detection:

- S0: Initial state, waiting for '1'.
- S1: Detected '1', waiting for '0'.
- S2: Detected "10", waiting for '1' to complete "101".

Transitions and output z=1 only when the last input completes the sequence "101".

Because it's a Mealy machine, the output z depends on the current state and the input.

The asynchronous reset is active low (aresetn), and triggered on the negative edge of aresetn, so we implement an asynchronous negative edge reset.

We also handle overlapping sequences, so after detecting "101", the FSM must transition appropriately to recognize the next sequences without missing overlapping inputs.

Use a synchronous clocked always block for state transitions and output assignments, and an asynchronous negative edge reset block for resetting the state to S0.

States can be encoded with 2-bit encoding (since only 3 states are needed).
