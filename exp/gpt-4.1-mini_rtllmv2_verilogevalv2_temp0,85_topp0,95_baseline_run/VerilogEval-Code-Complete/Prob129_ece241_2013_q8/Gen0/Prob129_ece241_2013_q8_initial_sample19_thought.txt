Implement a 3-state Mealy FSM to detect the sequence "101" on input x. The states will track the progress of the sequence:
- S0: initial state, no bits matched yet
- S1: matched '1'
- S2: matched "10"

On each clock's positive edge, transition states based on input x. Output z is asserted (1) when the last input completes the sequence "101". The FSM should recognize overlapping sequences, so after detecting "101", it can continue from the appropriate state. The FSM has a negative edge asynchronous reset (aresetn), so on the negative edge of aresetn, state resets to S0 and z to 0.
