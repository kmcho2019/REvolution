Design a 3-state Mealy FSM to detect the sequence "101" on input x. The states represent progress in matching the sequence:
- S0: initial state, waiting for '1'
- S1: saw '1', waiting for '0'
- S2: saw "10", waiting for '1' to complete "101"

Transitions:
- From S0:
  - if x=1, go to S1
  - else stay in S0
- From S1:
  - if x=0, go to S2
  - if x=1, stay in S1 (to handle overlapping)
- From S2:
  - if x=1, output z=1 and go to S1 (since last bit is '1', we can start detecting next sequence)
  - else go to S0, z=0

Use a negative edge asynchronous reset (aresetn). On reset, state = S0, z=0.

Output z is Mealy type, depends on current state and input.

Implement with synchronous clocked always block and asynchronous negative edge reset.
