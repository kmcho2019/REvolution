Implement a 3-state Mealy FSM to detect "101" on input x, asserting output z when the sequence is detected. The FSM supports overlapping sequences and uses a negative edge asynchronous reset (aresetn). State transitions and output are decided on positive clock edges, reset asynchronously on aresetn's negative edge.
States:
S0: initial state, waiting for '1'
S1: received '1', waiting for '0'
S2: received "10", waiting for '1' to complete "101"
When "101" is detected, z=1 for one clock cycle.
