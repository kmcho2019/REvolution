Implement a 3-state Mealy FSM to detect the sequence "101" on input x, asserting output z=1 upon detection. The states will represent partial matches:
- S0: no match or start state
- S1: matched '1'
- S2: matched '10'

On each clock edge, transition based on input x, asserting z=1 when the next input completes "101". The reset is asynchronous and active-low, triggered on the negative edge of aresetn.
