To detect any edge on each bit of the 8-bit input vector, store the previous input value in a register on each clock cycle. Then, compare the current input with the stored previous input. If any bit differs, it means an edge occurred on that bit. Set the output bit for that position in the cycle after the edge is detected, i.e., in the next clock cycle after the change. This can be done by updating the output register with the XOR of current and previous inputs.
