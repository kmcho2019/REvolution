To detect any edge (0->1 or 1->0) on each bit of the 8-bit input vector, we first store the input from the previous clock cycle in a register. Then, on each clock edge, we compare the current input with the stored previous input. If any bit differs, that means an edge occurred for that bit. We then set the corresponding bit of the output `anyedge` in the cycle after the change, i.e., the clock cycle after detecting the edge. This can be implemented by registering the edge detection result.
