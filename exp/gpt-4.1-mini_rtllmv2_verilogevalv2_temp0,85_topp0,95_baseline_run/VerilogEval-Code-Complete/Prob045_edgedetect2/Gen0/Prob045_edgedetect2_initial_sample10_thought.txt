To detect any edge on each bit of the 8-bit input vector, we can store the previous cycle's input in a register. On each clock cycle, compare the current input to the previous input using bitwise XOR. The XOR result will have '1' bits wherever the input bit changed (either 0->1 or 1->0). The output anyedge should be assigned this XOR value, but one cycle delayed, meaning we output the edge detected on the previous clock cycle. We implement this by registering the XOR result and outputting the registered value.
