To detect edges on each bit of the 8-bit input vector, store the previous cycle's input in a register. On each clock cycle, compare the current input with the stored previous input bitwise using XOR. The result will be 1 where any bit changed (0->1 or 1->0). The output anyedge is then set to this XOR value, indicating the bits that changed from the previous cycle. The output is updated every clock cycle based on the previous input state.
