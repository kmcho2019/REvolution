To detect any edge (0->1 or 1->0) on each bit of the 8-bit input vector, we store the previous value of the input in a register. On each clock cycle, we compare the current input to the previous input bitwise. If a bit has changed, we set the corresponding bit in the output `anyedge`. The output is updated in the cycle after the transition, so the output at time t corresponds to changes that happened between t-1 and t.
