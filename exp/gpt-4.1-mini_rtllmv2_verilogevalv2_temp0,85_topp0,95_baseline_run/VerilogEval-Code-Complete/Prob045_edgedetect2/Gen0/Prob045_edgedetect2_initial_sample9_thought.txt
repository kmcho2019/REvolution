To detect any edge (0 to 1 or 1 to 0) on each bit of the input vector, we need to store the previous input value in a register. On each clock cycle, compare the current input with the stored previous input; if they differ, it means an edge occurred on that bit. The output bit for that position should be set in the cycle after the edge is detected, so we assign the detected edge to the output register. Update the stored previous input after detecting the edges.
