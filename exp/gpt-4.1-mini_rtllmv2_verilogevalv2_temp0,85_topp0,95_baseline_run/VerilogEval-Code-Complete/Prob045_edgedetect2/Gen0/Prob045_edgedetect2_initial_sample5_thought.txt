To detect any edge (0->1 or 1->0) on each bit of the 8-bit input vector, we need to store the previous value of the input bits in a register. On each clock cycle, compare the current input bits with the previous bits. If they differ, that indicates an edge occurred on that bit in the previous cycle, so set the output bit. Since the output should be set the cycle after the edge occurs, we register the detection result and output it on the next clock cycle.
