To detect any edge (0 to 1 or 1 to 0) for each bit of the 8-bit input vector, we can register the previous state of the input on each clock cycle. Then, compare the current input with the previous input; any bit that differs indicates an edge occurred at that bit. The output 'anyedge' should be asserted in the cycle after the change, so we simply assign the XOR of current and previous input to 'anyedge' on the clock edge.
