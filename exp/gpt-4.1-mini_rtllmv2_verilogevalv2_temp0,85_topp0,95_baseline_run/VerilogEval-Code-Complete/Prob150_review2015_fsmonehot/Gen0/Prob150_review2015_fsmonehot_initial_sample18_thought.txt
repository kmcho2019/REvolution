We implement combinational logic for next-state signals and output signals based on the given one-hot encoded state machine and input conditions. Each next-state signal is asserted when the next state corresponds to the particular state. For states with multiple input-dependent next states (S, S1, S11, S110, Count, Wait), conditions are derived from the transition table. Outputs are asserted only in the states specified (shift_ena in B0-B3, counting in Count, done in Wait). The logic is derived by inspecting which current states and inputs cause transitions to the target next state.
