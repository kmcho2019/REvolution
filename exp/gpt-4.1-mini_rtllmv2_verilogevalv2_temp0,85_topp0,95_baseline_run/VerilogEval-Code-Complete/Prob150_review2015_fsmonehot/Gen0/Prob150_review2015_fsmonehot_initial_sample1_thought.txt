Implement combinational next-state logic using one-hot encoding by inspecting state transitions and input conditions. Outputs are asserted based on the current state as specified. Next states are determined by current state and inputs (d, done_counting, ack) or unconditional transitions for sequences like B0->B1->B2->B3->Count. Outputs are derived from current states: done=Wait, counting=Count, shift_ena=B0,B1,B2,B3.
