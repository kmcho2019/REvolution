For out_both, each bit i from 0 to 98 indicates if in[i] and in[i+1] are both 1.
For out_any, each bit i from 1 to 99 indicates if in[i] or in[i-1] is 1.
For out_different, each bit i from 0 to 99 indicates if in[i] differs from its left neighbor.
Since left neighbor of in[0] is in[99] (wrap-around), we implement wrap-around for out_different.
