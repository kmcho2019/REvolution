For out_both, each bit from 0 to 98 compares in[i] and in[i+1] (neighbor to the left). 
Since in[99] has no left neighbor, out_both is 99 bits: [98:0].

For out_any, each bit from 1 to 99 compares in[i] and in[i-1] (neighbor to the right). 
Since in[0] has no right neighbor, out_any is bits [99:1].

For out_different, the vector wraps around: in[99]'s left neighbor is in[0]. 
We compare each in[i] with in[(i+1) mod 100]. This results in 100 bits [99:0].

All operations are bitwise AND, OR, or XOR accordingly.
