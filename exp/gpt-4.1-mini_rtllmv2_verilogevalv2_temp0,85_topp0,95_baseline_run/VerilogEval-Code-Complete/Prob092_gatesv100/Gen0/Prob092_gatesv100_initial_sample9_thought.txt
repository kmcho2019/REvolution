For out_both, each bit except the last (99) compares in[i] & in[i+1] (left neighbor is at higher index).
For out_any, each bit except the first (0) compares in[i] | in[i-1] (right neighbor is at lower index).
For out_different, it's a 100-bit output where each bit i compares in[i] with in[(i+1) mod 100], wrapping around.
