For out_both, each bit compares in[i] and in[i+1] for i=0 to 98, output is 1 if both are 1.
For out_any, each bit compares in[i] and in[i-1] for i=1 to 99, output is 1 if either is 1.
For out_different, each bit compares in[i] and its left neighbor with wrap-around:
  For i=0, left neighbor is in[99].
  For i>0, left neighbor is in[i-1].
Output is 1 if bits differ.
Use bitwise AND, OR and XOR operators accordingly.
