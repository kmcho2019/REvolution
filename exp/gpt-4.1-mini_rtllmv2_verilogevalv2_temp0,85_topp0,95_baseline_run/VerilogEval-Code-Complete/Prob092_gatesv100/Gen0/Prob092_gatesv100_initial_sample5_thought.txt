For out_both, each bit [98:0] is 1 if both in[i] and in[i+1] are 1 (neighbor to the left means higher index), so out_both[i] = in[i] & in[i+1]. No output for bit 99 as it has no left neighbor.

For out_any, each bit [99:1] is 1 if either in[i] or in[i-1] is 1 (neighbor to the right means lower index), so out_any[i] = in[i] | in[i-1]. No output for bit 0.

For out_different, wrap-around neighbor to the left means for bit i, neighbor is (i+1)%100. So out_different[i] = in[i] ^ in[(i+1)%100].
