For out_both, we compare each bit from 0 to 98 with its neighbor to the left (bit+1). For example, out_both[98] = in[98] & in[99]. out_both[99] is not needed.

For out_any, each bit from 1 to 99 is set if either the bit or its neighbor to the right (bit-1) is 1. For example, out_any[2] = in[2] | in[1]. out_any[0] is not needed.

For out_different, since the vector wraps around, each bit from 0 to 99 compares itself with its neighbor to the left. For bit 99, neighbor to the left is bit 0. So out_different[i] = in[i] ^ in[(i+1)%100].
