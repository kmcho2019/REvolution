For out_both, each bit (except the last) indicates if both that bit and its left neighbor are 1. We can AND the bits in[98:0] with in[99:1]. For out_any, each bit (from 1 to 99) indicates if either that bit or its right neighbor is 1, so we OR in[99:1] with in[98:0]. For out_different, which is full 100 bits and wraps around, each bit compares the input bit with its left neighbor, and since it wraps, the left neighbor of in[99] is in[0]. So out_different[i] = in[i] ^ in[(i+1) % 100]. We can implement the wrap by concatenating in[0] at the MSB side when shifting.
