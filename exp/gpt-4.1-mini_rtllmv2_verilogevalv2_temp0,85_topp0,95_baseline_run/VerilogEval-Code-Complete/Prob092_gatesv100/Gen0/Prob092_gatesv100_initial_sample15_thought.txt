For out_both: We compare each bit with its left neighbor (higher index), except the top bit 99 which has no left neighbor. So out_both[98:0] = in[98:0] & in[99:1].

For out_any: We compare each bit with its right neighbor (lower index), except bit 0 which has no right neighbor. So out_any[99:1] = in[99:1] | in[98:0].

For out_different: We compare each bit with its left neighbor (higher index) treating the vector as wrapping around. So out_different[i] = in[i] ^ in[(i+1)%100].
