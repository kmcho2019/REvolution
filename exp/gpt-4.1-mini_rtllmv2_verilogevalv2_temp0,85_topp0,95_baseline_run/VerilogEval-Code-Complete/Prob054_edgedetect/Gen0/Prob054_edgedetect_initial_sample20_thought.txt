To detect a 0 to 1 transition on each bit of the input vector, we need to store the previous state of the input bits on each clock edge. Then, for each bit, if the previous value was 0 and the current value is 1, we detect a positive edge. The output bit should be set one cycle after the 0->1 transition, so we register the detected transition on the next clock cycle. We'll use a register to hold the previous input state, and a second register to hold the delayed detection output.
