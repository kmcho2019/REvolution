To detect a 0 to 1 transition (positive edge) on each bit of the 8-bit input vector, store the previous input in a register on every clock cycle. Then, for each bit, compare the previous and current inputs: if the previous bit was 0 and the current bit is 1, it indicates a 0->1 transition. The output bit should be set in the clock cycle after this transition occurs, so assign pedge to the detected transition bits each clock cycle.
