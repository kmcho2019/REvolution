To detect a 0 to 1 transition on each bit of the input vector, we need to store the previous state of the input bits in a register. On each clock cycle, we compare the previous input value to the current input value. If the previous bit was 0 and the current bit is 1, then a 0->1 transition occurred. The output bit for that position will be set to 1 on the cycle after the transition, so we assign the output based on the transition condition detected in the current clock cycle.
