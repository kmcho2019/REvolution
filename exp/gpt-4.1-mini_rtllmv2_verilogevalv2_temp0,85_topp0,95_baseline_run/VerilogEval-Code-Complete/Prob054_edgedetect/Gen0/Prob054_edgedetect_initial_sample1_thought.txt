To detect a 0-to-1 transition on each bit of the input vector, we need to store the previous value of the input and compare it with the current input on each clock edge. When the previous bit is 0 and the current bit is 1, this indicates a positive edge. The output bit should be set the cycle after the transition, so we register the detection in the next clock cycle. We can implement this by first capturing the input in a register, then computing the pedge output as the previous input's complement AND current input, then registering this output to delay it by one cycle.
