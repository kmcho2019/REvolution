To detect a 0-to-1 transition on each bit, we need to compare the current input with the input from the previous clock cycle. We'll store the previous input in a register. The positive edge on a bit is when the previous bit was 0 and the current bit is 1. The output pedge is set in the cycle after this transition, so pedge should be assigned the detected edges from the previous cycle. We can do this by first computing the transition signals and then assigning them to pedge in the next clock cycle.
