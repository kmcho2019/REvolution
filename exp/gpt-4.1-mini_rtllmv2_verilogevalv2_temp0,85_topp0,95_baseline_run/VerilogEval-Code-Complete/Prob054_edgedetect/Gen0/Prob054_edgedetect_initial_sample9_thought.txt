To detect a 0-to-1 transition on each bit of the 8-bit input vector, store the previous value of the input in a register on each clock cycle. Then, compare the current input with the previous input: if the previous bit was 0 and the current bit is 1, it indicates a 0-to-1 transition. The output bit for that position should be set in the next clock cycle, so assign pedge to this transition detection signal registered again on the next clock cycle.
