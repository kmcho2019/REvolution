To detect a 0 to 1 transition for each bit in an 8-bit input vector, store the previous cycle's input in a register. On each clock edge, compare the stored previous input with the current input. For each bit, if the previous bit was 0 and the current bit is 1, then a positive edge (0->1) has occurred. The output 'pedge' should be set in the cycle after the transition, so assign the detected transitions to 'pedge' in the same clock cycle as the stored previous input is updated.
