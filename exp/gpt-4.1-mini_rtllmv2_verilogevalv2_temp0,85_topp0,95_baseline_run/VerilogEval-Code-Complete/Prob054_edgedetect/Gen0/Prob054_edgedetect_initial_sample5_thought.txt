To detect a 0-to-1 transition on each bit of the 8-bit input vector, store the previous cycle's input in a register. On each clock cycle, compare the current input and the previous input: if the previous bit was 0 and the current bit is 1, set the corresponding bit in pedge. Since pedge is to be set the cycle after the 0-to-1 transition, pedge should be updated based on the detected transitions in the previous cycle.
