To detect a 0 to 1 transition on each bit of the input vector, we need to store the previous state of the input bits at every clock cycle. Then, for each bit, we compare the current input with the previous input. If the previous bit was 0 and the current bit is 1, that indicates a 0-to-1 transition. The output pedge should be set to 1 in the cycle after this transition is detected. So, we update pedge as the detected transition from the previous cycle. We'll use a register to store the previous input and update pedge accordingly on each clock cycle.
