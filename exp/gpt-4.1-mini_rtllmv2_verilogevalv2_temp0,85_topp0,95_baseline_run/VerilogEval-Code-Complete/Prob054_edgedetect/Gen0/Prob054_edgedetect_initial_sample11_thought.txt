To detect a 0-to-1 transition on each bit of the input vector, we need to store the previous input value on each clock cycle. Then, compare the previous value and the current input: if the previous bit was 0 and the current bit is 1, this indicates a positive edge. Since the output pedge should be set the cycle after the transition occurs, we will register the detection result on the next clock cycle. This can be done by capturing the transition in a combinational signal and then registering it on the next clock.
