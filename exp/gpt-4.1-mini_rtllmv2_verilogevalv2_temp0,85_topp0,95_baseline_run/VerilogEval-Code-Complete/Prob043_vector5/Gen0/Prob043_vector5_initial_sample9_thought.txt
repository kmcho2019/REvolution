To generate all 25 pairwise comparisons of five 1-bit signals, we can arrange them in a 5x5 matrix where each position (i,j) corresponds to the comparison of the i-th and j-th signals. Since we have five signals: a, b, c, d, and e, we order them as a=0, b=1, c=2, d=3, e=4. We want out[24] to correspond to comparison (0,0), out[23] to (0,1), and so on until out[0] = (4,4), i.e., the output is a flattened 5x5 matrix starting from top-left corner to bottom-right corner in row-major order. Each comparison outputs 1 if the bits are equal, i.e., (xnor) of the two bits. The expression ~x ^ y equals x xnor y, so we can implement each output bit as ~(x ^ y). We'll map these explicitly using concatenation of the comparisons in order.
