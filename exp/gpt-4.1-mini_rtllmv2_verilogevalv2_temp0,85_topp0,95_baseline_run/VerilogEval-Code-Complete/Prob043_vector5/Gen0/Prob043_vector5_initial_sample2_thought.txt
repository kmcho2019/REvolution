To compute all 25 pairwise comparisons between the 5 one-bit inputs, we consider each pair (including a bit compared with itself) and set the output bit to 1 if they are equal. Since equality for bits is (x == y), which can be implemented as ~(x ^ y), or equivalently ~(x ^ y). Using bitwise operators, this is the logical XNOR operation.
