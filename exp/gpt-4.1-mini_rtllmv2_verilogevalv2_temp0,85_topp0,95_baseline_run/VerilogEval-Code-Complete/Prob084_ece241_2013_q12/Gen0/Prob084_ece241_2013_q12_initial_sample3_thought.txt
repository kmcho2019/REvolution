Implement an 8-bit shift register with synchronous active-high enable and serial input S. On each rising clock edge, if enable is high, shift the bits in Q[7:0] left, with S shifted into Q[0]. Then use A,B,C as a 3-bit selector to choose one of the Q bits to drive output Z. A multiplexer with inputs Q[0] to Q[7] selected by ABC outputs Z.
