Implement an 8-bit shift register with 8 D flip-flops connected in series. On each clock edge, if enable is high, shift the bit at input S into Q[0], pushing previous bits to the next flip-flop. For reading, use the inputs A, B, and C as a 3-bit address to select one of the 8 bits from Q[0] to Q[7] via a multiplexer and assign it to output Z.
