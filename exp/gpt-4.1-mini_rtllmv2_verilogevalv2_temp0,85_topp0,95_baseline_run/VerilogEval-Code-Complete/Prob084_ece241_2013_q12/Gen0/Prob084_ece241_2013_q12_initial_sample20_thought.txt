Implement an 8-bit shift register using D flip-flops with synchronous active-high enable. The serial input S feeds into Q[0]. On each clock edge with enable high, the bits shift right: Q[1] <= Q[0], Q[2] <= Q[1], ..., Q[7] <= Q[6]. For output Z, use the 3-bit input ABC as an address to a multiplexer selecting one bit from Q[0] to Q[7]. Since Z is a reg output, assign Z in an always block sensitive to ABC or Q. The design uses only the shift register and multiplexers (implemented with a case statement).
