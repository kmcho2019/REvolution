Design an 8-bit shift register with synchronous enable and serial input S feeding Q[0]. On each clock edge, if enable is high, shift the bits right, with Q[0] taking S. Outputs Q[0] to Q[7] represent the stored bits. Use a 3-to-8 decoder from inputs A,B,C to select one bit of Q to output on Z. Since Z is reg, assign it in an always block triggered by clk or inputs A,B,C; or combinational logic. We'll use a combinational always block for Z assignment based on A,B,C and Q. The design consists solely of the shift register and a multiplexer realized via a case statement.
