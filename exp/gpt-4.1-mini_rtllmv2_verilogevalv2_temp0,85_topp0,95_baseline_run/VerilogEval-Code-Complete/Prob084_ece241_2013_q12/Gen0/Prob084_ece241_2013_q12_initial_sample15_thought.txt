Implement an 8-bit shift register with synchronous enable and serial input S. The shift register shifts in S at Q[0] on each clock when enable is high. For random access reading, use the 3 inputs A, B, and C as a 3-bit index to select one of the Q bits via a multiplexer. The selected bit is assigned to output Z. Since Z is a reg, assign it in an always block sensitive to changes in A,B,C or the Q register.
