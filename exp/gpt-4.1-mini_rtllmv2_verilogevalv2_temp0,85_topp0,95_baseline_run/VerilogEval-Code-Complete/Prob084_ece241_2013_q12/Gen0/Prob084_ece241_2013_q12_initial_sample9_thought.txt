Design an 8-bit shift register using 8 D flip-flops connected in series. The input S feeds into Q[0], and on each clock edge, if enable is high, the bits shift right (Q[7] <- Q[6], ..., Q[1] <- Q[0], Q[0] <- S). Then use the inputs A,B,C as a 3-bit address to select one of the Q[0]..Q[7] bits using an 8-to-1 multiplexer to assign to output Z. Since Z is a reg, assign it inside an always block that triggers on the address or the register state.
