Implement an 8-bit shift register using 8 D flip-flops, with input S feeding Q[0]. On every clock edge, if enable is high, shift the bits right (Q[7] <= Q[6], ... Q[1] <= Q[0], Q[0] <= S). For the read, use the 3-bit input ABC as an index to select one of the 8 bits from the shift register outputs Q[0]..Q[7]. This selection can be done using a multiplexer (a case statement). Output Z is assigned the selected bit.
