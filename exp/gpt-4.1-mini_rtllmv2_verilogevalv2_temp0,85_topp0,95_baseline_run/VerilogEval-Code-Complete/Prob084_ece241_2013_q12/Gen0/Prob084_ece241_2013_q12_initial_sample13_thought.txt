Design an 8-bit shift register using 8 D flip-flops chained so that the input S feeds Q[0], and each flip-flop shifts its input from the previous Q. The shifting occurs only when enable is high on the rising clock edge. For reading, implement a 3-to-8 multiplexer using inputs A, B, C as the select lines to choose one of Q[0] to Q[7] and assign it to output Z.
