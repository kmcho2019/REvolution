Implement an 8-bit shift register using D flip-flops with synchronous active-high enable and input S shifting into Q[0]. Outputs are Q[0] to Q[7]. Then use a 3-to-8 multiplexer controlled by inputs A, B, C to select one of Q[0] to Q[7], and output that bit on Z. Since Z is a reg, assign it on the clock edge to the selected Q bit.
