Implement an 8-bit shift register with synchronous enable and serial input S, where Q[0] is the MSB shifted in first. The register shifts on clk edge when enable is high, shifting right from Q[0] to Q[7]. Then use a 3-to-8 decoder from inputs A,B,C to select one of the Q[i] bits using an 8-to-1 multiplexer and assign it to output Z.
