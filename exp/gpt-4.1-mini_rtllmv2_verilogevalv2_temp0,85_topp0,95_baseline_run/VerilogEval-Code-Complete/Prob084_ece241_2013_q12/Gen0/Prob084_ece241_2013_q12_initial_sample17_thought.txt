Implement an 8-bit shift register with synchronous active-high enable shifting in the S input bit into Q[0] on each clock cycle. The shift register outputs are Q[0] to Q[7]. To realize random access read, use a 3-bit input ABC as an address to select one of the 8 flip-flop outputs via an 8-to-1 multiplexer to drive output Z. Since Z is declared reg, update Z in a clocked always block whenever inputs change. The design only uses the shift register and multiplexers as requested.
