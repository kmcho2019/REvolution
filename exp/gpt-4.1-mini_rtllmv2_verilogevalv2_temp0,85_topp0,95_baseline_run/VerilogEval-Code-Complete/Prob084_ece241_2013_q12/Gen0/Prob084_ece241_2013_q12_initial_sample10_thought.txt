Design an 8-bit shift register using 8 D flip-flops connected in series. The input S feeds into Q[0], and on each clock edge with enable high, the bits shift right (Q[i] takes Q[i-1]). For reading, implement an 8-to-1 multiplexer controlled by inputs A,B,C to select one Q[i] output as Z. Since Z is a reg output and updated combinationally from Q and ABC, use an always_comb block to assign Z.
