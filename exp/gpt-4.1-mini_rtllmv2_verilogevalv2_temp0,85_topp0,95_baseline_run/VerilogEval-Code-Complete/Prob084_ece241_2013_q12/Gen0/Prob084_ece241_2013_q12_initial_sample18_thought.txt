Implement an 8-bit shift register with synchronous active-high enable that shifts in the input S on each clock. The outputs Q[0] to Q[7] represent the stored bits (Q[0] is the first shifted in bit, i.e., MSB shifted in first). To implement the random access read, use a 3-to-8 decoder formed by inputs A,B,C to select which Q[i] is output as Z. Since Z is output reg, assign it in an always block sensitive to changes in A,B,C or Q. The circuit only uses the shift register and multiplexers (implemented as a case statement or combinational logic).
