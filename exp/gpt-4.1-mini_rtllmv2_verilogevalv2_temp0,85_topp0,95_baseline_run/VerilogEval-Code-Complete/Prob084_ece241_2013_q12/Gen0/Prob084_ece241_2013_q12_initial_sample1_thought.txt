Design an 8-bit shift register composed of 8 D flip-flops connected serially, with input S feeding Q[0]. On each clock edge, if enable is high, shift the bits by one position (Q[i] <= Q[i-1]). Outputs Q[0] to Q[7] store the memory bits. For reading, use the 3-bit input ABC as an index to select one of Q[0]...Q[7] via an 8-to-1 multiplexer to output Z. The multiplexer selects based on ABC and outputs the corresponding Q[i]. This implements the described random access reading and serial write by shifting.
