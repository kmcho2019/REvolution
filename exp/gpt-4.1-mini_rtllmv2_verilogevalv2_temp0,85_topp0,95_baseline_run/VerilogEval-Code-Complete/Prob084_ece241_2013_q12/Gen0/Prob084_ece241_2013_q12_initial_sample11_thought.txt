Implement an 8-bit shift register with synchronous enable to shift in the bit S on each clock. The flip-flops Q[0] to Q[7] store the shifted bits, with Q[0] being the MSB shifted in first. To read from this memory randomly, use the 3-bit input ABC as an address to select one of Q[0] to Q[7] via an 8-to-1 multiplexer. Assign the selected bit to output Z.
