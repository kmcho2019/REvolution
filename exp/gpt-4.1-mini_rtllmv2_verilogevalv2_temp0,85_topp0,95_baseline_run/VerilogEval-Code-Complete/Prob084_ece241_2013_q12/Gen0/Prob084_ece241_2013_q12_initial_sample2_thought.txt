Implement an 8-bit shift register using 8 D flip-flops, shifting in the bit S on each clock when enable is high. The flip-flops outputs are Q[0] to Q[7], with Q[0] being the first shifted in (MSB shifted in first). Then use the inputs A, B, and C as a 3-bit address to select one of the Q bits through a multiplexer to drive output Z. The output Z is combinationally selected from Q based on ABC.
