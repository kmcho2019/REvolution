Design a synchronous state machine that tracks the water level based on the sensor inputs s[3:1]. The state machine should remember the previous water level range to determine if the water level is rising (previous lower than current) or falling. On each clock, decode the current water level range from sensor inputs, then update outputs (fr1, fr2, fr3, dfr) accordingly. The flow rates correspond to water level ranges as defined:

- Above s[3]: all sensors asserted (s[3:1] == 3'b111), no flow valves opened (all outputs 0).
- Between s[3] and s[2]: s[3:1] == 3'b110, nominal flow fr1.
- Between s[2] and s[1]: s[3:1] == 3'b100, nominal flow fr1 and fr2.
- Below s[1]: s[3:1] == 3'b000, all flow valves fr1, fr2, fr3 opened.

Additionally, if the water level is rising (previous level was lower), open the supplemental valve dfr.

Use an enumerated state or variable to represent the current water level range. On reset, initialize to the lowest level (below s[1], no sensors asserted), with all flow valves and dfr asserted.

Implement synchronous reset and update outputs in the clocked always block.
