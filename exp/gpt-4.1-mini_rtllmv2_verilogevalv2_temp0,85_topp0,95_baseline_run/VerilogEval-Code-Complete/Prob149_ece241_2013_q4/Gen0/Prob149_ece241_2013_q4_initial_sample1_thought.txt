Design a synchronous FSM that tracks water level states based on sensors s[3:1]. The states correspond to the water level ranges: Below s[1], Between s[2] and s[1], Between s[3] and s[2], and Above s[3]. On reset, initialize to the "Below s[1]" state (no sensors asserted, all outputs on). On every clock, determine current level from sensors, update outputs accordingly. To decide if supplemental flow valve (dfr) should be on, compare current state with previous: if level is rising (state moving up), dfr is asserted. Outputs are assigned as per table for each state. The FSM keeps track of previous and current level states to implement this logic synchronously.
