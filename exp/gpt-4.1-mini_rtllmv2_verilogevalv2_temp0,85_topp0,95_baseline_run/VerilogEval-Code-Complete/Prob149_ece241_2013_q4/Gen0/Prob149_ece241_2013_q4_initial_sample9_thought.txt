Implement a synchronous FSM that tracks the previous water level state based on sensor inputs s[3:1]. The water level states correspond to sensor assertions: 
- ABOVE (all three sensors asserted)
- MID_HIGH (s[1], s[2] asserted only)
- MID_LOW (only s[1] asserted)
- BELOW (none asserted)

On reset, the FSM state initializes to BELOW (lowest level, all valves open). At each clock cycle, determine the current water level from sensors and update the FSM state accordingly. Compare current and previous states to determine if the water level has risen. Based on the current state, assert nominal flow rates (fr1, fr2, fr3) and if the water level increased, also assert the supplemental flow valve dfr.

Mapping:
- ABOVE (s[3],s[2],s[1]) = 3'b111 => no flow (fr1=0, fr2=0, fr3=0, dfr=0)
- MID_HIGH (s[2], s[1]) = 3'b011 => fr1=1, fr2=0, fr3=0, dfr depends on level rise
- MID_LOW (s[1]) = 3'b001 => fr1=1, fr2=1, fr3=0, dfr depends on level rise
- BELOW (none) = 3'b000 => fr1=1, fr2=1, fr3=1, dfr depends on level rise

Transitions:
- Detect if previous level was lower than current by comparing state order: BELOW < MID_LOW < MID_HIGH < ABOVE.
- dfr asserted if current state > previous state.

This approach ensures the FSM output logic matches the specification and the synchronous reset sets the FSM to the initial low water level with all valves open.

State encoding: 2-bit state
0 = BELOW
1 = MID_LOW
2 = MID_HIGH
3 = ABOVE

Assign flow control signals based on state and dfr.

Implement FSM with synchronous reset, update state, and generate outputs accordingly.
