Implement a synchronous FSM that tracks the water level state based on sensor inputs. The states correspond to the four water level ranges: below s[1], between s[1] and s[2], between s[2] and s[3], and above s[3]. On each clock cycle, determine the current water level state from sensor inputs. Compare with the previous state to identify if the water level is rising (previous state lower than current) or falling/stationary. Set flow rate outputs accordingly: nominal flow valves for the current level, and enable the supplemental flow valve (dfr) if the water level is rising. Include synchronous active-high reset initializing the FSM to the lowest level (below s[1]) with all flow valves open and dfr asserted.
