I will implement a 4-state FSM with states A, B, C, D encoded uniquely. State A is the idle state with no grants; states B, C, and D correspond to granting devices 1, 2, and 3 respectively. The synchronous active-low reset initializes the FSM to state A. The next state logic considers the priority of requests r[1] > r[2] > r[3]. Outputs g[i] reflect the grant signals and are combinationally driven from the current state. The state register is updated on the rising clock edge, synchronous with reset.
