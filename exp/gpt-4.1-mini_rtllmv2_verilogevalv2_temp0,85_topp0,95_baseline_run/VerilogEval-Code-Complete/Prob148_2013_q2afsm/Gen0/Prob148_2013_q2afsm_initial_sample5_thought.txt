Implement a Moore FSM with four states: A (no grant), B (grant to device 1), C (grant to device 2), D (grant to device 3). Use a synchronous active-low reset to state A. On state A, check requests in priority order: if r[1] == 1, go to B; else if r[2] == 1, go to C; else if r[3] == 1, go to D; else stay in A. On B, stay in B if r[1] == 1 else go back to A. On C, stay in C if r[2] == 1 else go back to A. On D, stay in D if r[3] == 1 else go back to A. Output grants are determined by the current state: g[1]=1 in B, g[2]=1 in C, g[3]=1 in D, else 0.
