I will define a 4-state FSM: A (idle), B (grant device 1), C (grant device 2), D (grant device 3). The priority is device 1 > device 2 > device 3. On reset (active low synchronous), state resets to A. From A, if r1=1, go to B; else if r2=1 go to C; else if r3=1 go to D; else stay in A. From B, if r1=1 stay in B else go to A. From C, if r2=1 stay in C else go to A. From D, if r3=1 stay in D else go to A. Outputs g1, g2, g3 are assigned 1 when in states B, C, D respectively, else 0. The state flip-flops and state transition logic are implemented in separate always blocks as per the request.
