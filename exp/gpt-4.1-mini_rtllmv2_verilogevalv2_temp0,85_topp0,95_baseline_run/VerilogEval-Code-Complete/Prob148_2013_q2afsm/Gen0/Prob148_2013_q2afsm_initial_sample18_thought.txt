To implement the described FSM arbiter:

- Define four states: A (idle), B (grant device 1), C (grant device 2), D (grant device 3).
- On synchronous active-low reset, go to state A.
- Priority encoding when in state A: if r[1] = 1 -> B; else if r[2] = 1 -> C; else if r[3] = 1 -> D; else remain in A.
- From B: if r[1] = 1 stay in B, else go to A.
- From C: if r[2] = 1 stay in C, else go to A.
- From D: if r[3] = 1 stay in D, else go to A.
- Outputs: g1=1 in B, g2=1 in C, g3=1 in D; otherwise zero.
- Use separate always blocks for state flip-flops and next state logic.
- Outputs can be assigned continuously from the current state.

We will use a 2-bit encoding for states:
  A = 2'b00
  B = 2'b01
  C = 2'b10
  D = 2'b11
