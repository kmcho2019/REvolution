I will implement the described FSM with 4 states: A, B, C, and D. State A corresponds to no grant (idle), states B, C, and D correspond to granting devices 1, 2, and 3 respectively.

- Use a 2-bit state encoding: 
  A = 2'b00, B = 2'b01, C = 2'b10, D = 2'b11.

- On synchronous active-low reset, state goes to A.

- In state A:
  - If r[1] == 1, go to B.
  - Else if r[2] == 1, go to C.
  - Else if r[3] == 1, go to D.
  - Else stay in A.

- In state B:
  - Grant g1=1.
  - Stay in B if r[1] == 1.
  - Else go to A.

- In state C:
  - Grant g2=1.
  - Stay in C if r[2] == 1.
  - Else go to A.

- In state D:
  - Grant g3=1.
  - Stay in D if r[3] == 1.
  - Else go to A.

Output grants will be combinational based on current state using a continuous assignment.
Separate always blocks for state registers and next state combinational logic will be used.
