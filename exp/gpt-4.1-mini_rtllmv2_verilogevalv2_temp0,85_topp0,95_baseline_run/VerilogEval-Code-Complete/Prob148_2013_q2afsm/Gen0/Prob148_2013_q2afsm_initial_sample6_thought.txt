Implement the FSM with four states: A (idle), B (grant device 1), C (grant device 2), and D (grant device 3). On reset (active low, synchronous), state resets to A. The next state logic prioritizes requests: if r1=1, move to B; else if r2=1, move to C; else if r3=1, move to D; else remain in A. When granted a device (states B, C, or D), stay in that state as long as the respective request is asserted; otherwise, return to A. Outputs g[1], g[2], and g[3] correspond to states B, C, and D respectively. Use separate always blocks for state register and combinational next state logic. Outputs are combinational based on current state.
