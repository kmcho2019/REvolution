I will implement a synchronous active-low reset FSM with four states representing no grant (A) and grants to devices 1 (B), 2 (C), or 3 (D). The FSM transitions on clock edges based on the inputs r[1], r[2], r[3], with priority given to device 1, then 2, then 3. The state flip-flops update the current state. The next state logic is described in a combinational always block. The outputs g[1], g[2], g[3] will be driven based on the current state using continuous assignments.
