Implement the FSM with four states: A (idle, no grant), B (grant to device 1), C (grant to device 2), and D (grant to device 3). Use a synchronous active-low reset that sets state to A. On state A, priority logic chooses grant based on r signals: if r[1] then B, else if r[2] then C, else if r[3] then D, else stay in A. In grant states B, C, or D, the FSM remains in that state as long as the granted request remains asserted; if not, returns to A. Outputs g are assigned based on the current state. Use separate always blocks: one for state register, one for next state logic, and continuous assignment for outputs.
