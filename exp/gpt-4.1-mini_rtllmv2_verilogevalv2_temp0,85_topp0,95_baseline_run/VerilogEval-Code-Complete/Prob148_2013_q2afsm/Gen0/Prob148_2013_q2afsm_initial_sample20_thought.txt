Implement the FSM with 4 states: A (no grant), B (grant device 1), C (grant device 2), D (grant device 3). The state transitions are determined by requests r[1], r[2], r[3] with priority r1 > r2 > r3. On resetn (active low synchronous reset), state goes to A. Outputs g[i] are assigned based on current state. Use one always block for state transitions (combinational), one always block for state registers (sequential on clk and resetn), and continuous assignment for outputs.
