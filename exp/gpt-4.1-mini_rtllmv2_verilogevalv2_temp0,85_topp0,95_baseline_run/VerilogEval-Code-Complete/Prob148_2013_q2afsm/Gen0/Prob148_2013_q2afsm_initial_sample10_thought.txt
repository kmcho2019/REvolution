Implement the FSM with four states (A, B, C, D) encoded as 2-bit states. On reset (active low), go to state A. In state A, check requests r[1], r[2], r[3] in priority order to decide next state: if r[1] then B, else if r[2] then C, else if r[3] then D, else stay in A. In states B, C, D, grant the corresponding device and stay in that state as long as the corresponding request is asserted; otherwise, return to A. The outputs g[1], g[2], g[3] are asserted based on the state. Use two separate always blocks: one for the state register (sequential) and one for the next state logic (combinational). Outputs are assigned combinationally using continuous assignments based on state.
