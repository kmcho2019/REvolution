We will implement the FSM with four states: A, B, C, and D. State A is the idle state with no grants, B grants device 1, C grants device 2, and D grants device 3. Priority is device 1 > device 2 > device 3. On reset, FSM goes to A. In state A, if multiple requests, grant to highest priority. In grant states, the grant continues as long as request is asserted; otherwise return to A. We'll use a synchronous active-low reset. The state encoding can be simple binary with 2 bits. Outputs g[i] are combinational based on the current state.
