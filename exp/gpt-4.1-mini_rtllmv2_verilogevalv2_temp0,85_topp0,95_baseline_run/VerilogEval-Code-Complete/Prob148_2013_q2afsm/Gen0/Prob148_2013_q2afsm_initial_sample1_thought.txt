Implement the FSM with four states: A (idle), B (grant device 1), C (grant device 2), D (grant device 3). On reset, go to state A. In state A, check requests in priority order: if r[1]=1 go to B, else if r[2]=1 go to C, else if r[3]=1 go to D, else remain in A. In states B, C, and D, if the corresponding request remains high, stay in that state, otherwise return to A. Outputs g[1], g[2], g[3] are asserted based on the state. Use separate always blocks for state registers and state transitions, and use a continuous assignment for outputs.
