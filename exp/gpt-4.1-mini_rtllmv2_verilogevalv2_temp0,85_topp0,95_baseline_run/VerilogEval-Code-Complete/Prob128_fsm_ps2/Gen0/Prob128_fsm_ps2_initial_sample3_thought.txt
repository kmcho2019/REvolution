We implement a 2-bit FSM with states: WAIT_FOR_START (0), BYTE_2 (1), BYTE_3 (2).
- In WAIT_FOR_START, discard bytes until in[3] == 1, then move to BYTE_2.
- In BYTE_2, accept one byte, move to BYTE_3.
- In BYTE_3, accept one byte, signal done in next cycle, then return to WAIT_FOR_START.
Reset synchronously sets FSM to WAIT_FOR_START and clears done.
Done is asserted for one clock cycle immediately after third byte is received.
