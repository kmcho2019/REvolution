Implement a 2-bit FSM with states: IDLE (waiting for first byte with in[3]=1), BYTE2 (waiting for second byte), BYTE3 (waiting for third byte). On reset, go to IDLE. In IDLE, only accept bytes where in[3]=1, then move to BYTE2. In BYTE2, accept any byte and move to BYTE3. In BYTE3, accept any byte, then assert done in the next cycle and move back to IDLE to look for next message. The done signal is registered and asserted for one cycle immediately after receiving the third byte.
