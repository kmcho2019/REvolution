Implement a 3-state FSM: IDLE, BYTE2, BYTE3. 
- In IDLE, wait for a byte where in[3] = 1 to identify start of a message.
- On receiving such a byte, move to BYTE2.
- On next byte, move to BYTE3.
- On next byte, signal done, then return to IDLE to look for next message start.
Reset synchronously returns FSM to IDLE and clears done.
done is asserted for one cycle immediately after the 3rd byte is received.
