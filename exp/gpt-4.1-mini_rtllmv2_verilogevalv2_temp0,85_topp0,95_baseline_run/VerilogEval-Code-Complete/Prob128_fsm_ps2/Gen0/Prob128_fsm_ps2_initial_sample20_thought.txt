Design a 2-bit FSM with states: WAIT_FOR_START (waiting for a byte with in[3]=1), BYTE2 (second byte of the message), BYTE3 (third byte of the message). On reset, go to WAIT_FOR_START. When in WAIT_FOR_START, if in[3]=1, go to BYTE2. From BYTE2 go to BYTE3 on next byte, from BYTE3 go back to WAIT_FOR_START and assert done for one cycle indicating message complete. The done signal is asserted for one clock cycle immediately after the third byte is received.
