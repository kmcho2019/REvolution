We design a 2-bit state FSM with states: WAIT_FOR_START, BYTE1, BYTE2.
- Initially, in WAIT_FOR_START state, we check if in[3] is 1; if not, stay in WAIT_FOR_START.
- When in[3] is 1, we consider this the first byte of a message and transition to BYTE1.
- Next cycle, we move to BYTE2 (second byte).
- Next cycle, after receiving the third byte, we assert done for one cycle and return to WAIT_FOR_START.
- done is asserted only for one cycle immediately after the third byte is received.
- Reset is synchronous and active high, putting FSM back to WAIT_FOR_START.
