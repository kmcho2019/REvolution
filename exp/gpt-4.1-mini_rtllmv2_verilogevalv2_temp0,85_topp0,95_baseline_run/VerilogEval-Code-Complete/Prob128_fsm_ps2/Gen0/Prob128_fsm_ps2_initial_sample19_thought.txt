Design an FSM with three states: IDLE, BYTE1, BYTE2.
- In IDLE, discard bytes until a byte with in[3] = 1 arrives, then go to BYTE1.
- In BYTE1, accept the first byte of a message (with in[3]=1), then move to BYTE2.
- In BYTE2, accept the second byte (no condition on in[3]), move to BYTE3.
- In BYTE3, accept the third byte (no condition on in[3]), then assert done signal in the next cycle and return to IDLE to look for the next message start.
Use a synchronous reset to set the FSM to IDLE.
Output 'done' is asserted for one cycle immediately after the third byte is received.
