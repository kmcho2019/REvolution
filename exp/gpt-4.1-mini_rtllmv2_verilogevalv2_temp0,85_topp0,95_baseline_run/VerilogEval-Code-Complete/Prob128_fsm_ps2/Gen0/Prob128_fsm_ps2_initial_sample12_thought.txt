We create a 2-bit state machine with states: WAIT_FOR_START (waiting for a byte with in[3]=1), BYTE_2 (waiting for second byte), BYTE_3 (waiting for third byte). On reset, go to WAIT_FOR_START. In WAIT_FOR_START, if in[3]=1, move to BYTE_2 and capture first byte. In BYTE_2, accept byte and move to BYTE_3. In BYTE_3, accept byte, then signal done and return to WAIT_FOR_START. The done output is a one-cycle pulse after receiving the third byte. We use synchronous reset and state updates on posedge clk.
