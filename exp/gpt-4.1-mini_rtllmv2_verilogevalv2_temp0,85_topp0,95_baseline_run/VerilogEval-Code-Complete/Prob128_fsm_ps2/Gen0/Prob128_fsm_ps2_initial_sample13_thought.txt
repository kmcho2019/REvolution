Design a 3-state FSM: IDLE, BYTE2, BYTE3. 
In IDLE, wait for a byte with in[3]==1 to start a message. 
On receiving the first byte (with in[3]==1), move to BYTE2. 
Then accept two more bytes unconditionally to complete the message. 
After receiving the third byte, assert done for one cycle and return to IDLE. 
Reset synchronously returns FSM to IDLE and clears done.
