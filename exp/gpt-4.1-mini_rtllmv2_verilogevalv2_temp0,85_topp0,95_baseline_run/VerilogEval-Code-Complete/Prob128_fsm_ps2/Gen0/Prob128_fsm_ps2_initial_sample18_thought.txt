We design a simple FSM with states to track the byte count within a message. Initially, the FSM waits for a byte where in[3] = 1, indicating the start of a message (byte 1). Once this byte is detected, the FSM moves to state expecting the second byte, then the third byte. After the third byte is received, the FSM asserts 'done' for one clock cycle and returns to waiting for the start of the next message. Reset is synchronous and active high, returning the FSM to the initial waiting state.
