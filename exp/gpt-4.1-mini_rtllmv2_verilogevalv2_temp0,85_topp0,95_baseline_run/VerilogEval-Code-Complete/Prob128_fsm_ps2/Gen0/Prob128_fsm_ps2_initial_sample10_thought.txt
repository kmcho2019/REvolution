We implement a 2-bit state machine with states: IDLE (waiting for first byte with in[3]=1), BYTE1 (received first byte), BYTE2 (received second byte). On reset, go to IDLE. In IDLE, if in[3] is 1, move to BYTE1; otherwise stay in IDLE. In BYTE1, move to BYTE2 on next byte. In BYTE2, move back to IDLE and assert done signal in the cycle immediately after receiving the third byte. done will be a one-cycle pulse synchronous to clk.
