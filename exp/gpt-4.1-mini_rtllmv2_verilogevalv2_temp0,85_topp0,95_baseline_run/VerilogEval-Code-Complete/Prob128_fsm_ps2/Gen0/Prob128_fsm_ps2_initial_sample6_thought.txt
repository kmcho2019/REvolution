Implement a 3-state FSM: 
- IDLE: Wait for a byte with in[3] = 1 to identify the start of a message.
- BYTE2: Received first byte, now wait for second byte.
- BYTE3: Received second byte, now wait for third byte.

On receiving the third byte, assert done for one cycle and then return to IDLE.

Use synchronous reset to return to IDLE state.
