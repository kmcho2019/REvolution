Implement a simple 2-state FSM: IDLE and RECV. In IDLE state, discard bytes until a byte with in[3] = 1 arrives, which marks the start of a 3-byte message. Transition to RECV state and count bytes received. After receiving the third byte, assert done for one cycle, then return to IDLE to look for the next message. Use a counter to track how many bytes have been received within the message. Synchronous reset sets FSM back to IDLE and clears counters.
