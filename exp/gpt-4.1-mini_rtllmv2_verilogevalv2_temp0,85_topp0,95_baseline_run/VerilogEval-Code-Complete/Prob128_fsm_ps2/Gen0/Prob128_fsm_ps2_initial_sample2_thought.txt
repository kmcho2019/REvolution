We will implement a simple 3-state FSM: 
- IDLE: Wait for a byte with in[3] = 1, indicating the start of a message. Discard all other bytes.
- BYTE2: After receiving the first byte, expect the second byte of the message.
- BYTE3: After receiving the second byte, expect the third byte of the message.
Once the third byte is received, assert done for one clock cycle and return to IDLE.
The done signal is asserted in the cycle immediately after the third byte is received.
We will use a synchronous reset that sets the FSM state back to IDLE.
