Design a 3-state FSM: IDLE, BYTE2, BYTE3.
- IDLE: Wait for a byte where in[3] == 1 to mark start of a message.
- BYTE2: After first byte accepted, wait for second byte.
- BYTE3: After second byte accepted, wait for third byte.
When third byte is received, assert done for one clock cycle, then return to IDLE.
Use a synchronous reset to return to IDLE state.
done is a one-cycle pulse immediately after the third byte is received.
