To implement the combinational logic for the next state and output with one-hot encoding:

- For each next_state bit (A, B, C, D), derive the logic from the state transition table:
  next_state[A] = (state[A] & ~in) | (state[C] & ~in)
  next_state[B] = (state[A] & in) | (state[B] & in) | (state[D] & in)
  next_state[C] = (state[B] & ~in) | (state[D] & ~in)
  next_state[D] = state[C] & in

- Output is 1 only in state D, else 0:
  out = state[D]

This is implemented as combinational logic in always @* block for next_state and a continuous assignment for output.
