The state is one-hot encoded, so each state bit corresponds to one state. The next state logic for each state bit can be derived by considering where the machine moves from each current state depending on input 'in'.

- next_state[0] (A): From A when in=0, from C when in=0
  next_state[0] = (state[A] & ~in) | (state[C] & ~in)

- next_state[1] (B): From A when in=1, from B when in=1, from D when in=1
  next_state[1] = (state[A] & in) | (state[B] & in) | (state[D] & in)

- next_state[2] (C): From B when in=0, from D when in=0
  next_state[2] = (state[B] & ~in) | (state[D] & ~in)

- next_state[3] (D): From C when in=1
  next_state[3] = (state[C] & in)

Output 'out' depends only on state D (4'b1000), so:
out = state[D] = state[3]
