Using one-hot encoding, each state is represented by a single bit set to 1. The next state logic can be derived by inspecting the transitions:
- From A (0001): next_state = A if in=0, B if in=1
- From B (0010): next_state = C if in=0, B if in=1
- From C (0100): next_state = A if in=0, D if in=1
- From D (1000): next_state = C if in=0, B if in=1

For each next_state bit, write the logic as OR of conditions where that bit should be 1.

Output is 1 only in state D (1000), else 0.

Implement combinational logic for next_state and out based on current state and input.
