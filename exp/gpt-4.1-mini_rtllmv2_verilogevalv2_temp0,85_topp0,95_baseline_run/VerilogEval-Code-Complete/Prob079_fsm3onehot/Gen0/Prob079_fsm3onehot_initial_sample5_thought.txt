Use one-hot state encoding to derive next state logic. For each next state bit, define its next value based on current state and input:
- next_state[A] = (state[A] & ~in) | (state[C] & ~in)
- next_state[B] = (state[A] & in) | (state[B] & in) | (state[D] & in)
- next_state[C] = (state[B] & ~in) | (state[D] & ~in)
- next_state[D] = (state[C] & in)
Output is 1 only in state D, so out = state[D].
