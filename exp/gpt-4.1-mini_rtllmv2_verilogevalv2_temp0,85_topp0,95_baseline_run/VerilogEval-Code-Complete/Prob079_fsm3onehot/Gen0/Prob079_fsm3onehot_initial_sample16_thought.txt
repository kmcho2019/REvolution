For one-hot encoded states A=0001, B=0010, C=0100, D=1000, the next state logic can be derived from the table by inspecting which bit is set for next_state depending on input and current state.

- next_state[A] = (state[A] & ~in) | (state[C] & ~in)
- next_state[B] = (state[A] & in) | (state[B] & in) | (state[D] & in)
- next_state[C] = (state[B] & ~in) | (state[D] & ~in)
- next_state[D] = (state[C] & in)

The output is 1 only in state D, so out = state[D].

Implement the combinational logic for next_state and out accordingly.
