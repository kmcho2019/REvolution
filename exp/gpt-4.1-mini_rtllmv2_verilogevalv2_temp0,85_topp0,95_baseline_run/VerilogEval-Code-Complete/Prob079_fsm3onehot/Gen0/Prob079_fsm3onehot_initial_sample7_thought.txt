Since the state encoding is one-hot, each state is represented by a single bit in a 4-bit vector. Next state logic can be derived by examining transitions for each state bit:

- For next_state[0] (A): Active when coming from A (state[0]) and in=0, or from C (state[2]) and in=0
- For next_state[1] (B): Active when coming from A (state[0]) and in=1, or from B (state[1]) and any input=0 or 1, or from D (state[3]) and in=1
- For next_state[2] (C): Active when coming from B (state[1]) and in=0, or from D (state[3]) and in=0
- For next_state[3] (D): Active when coming from C (state[2]) and in=1

Output is 1 only in state D (state[3]) regardless of input; else 0.

Implement the combinational logic for next_state and output as per above.
