The machine uses one-hot encoding for states A, B, C, and D. We derive next_state bits based on current state and input in:

- next_state[0] = A_next = (A & ~in) | (C & ~in)
- next_state[1] = B_next = (A & in) | (B & in) | (D & in)
- next_state[2] = C_next = (B & ~in) | (D & ~in)
- next_state[3] = D_next = (C & in)

Output 'out' is 1 only in state D, otherwise 0.

Implement combinational logic for next_state and output using the above expressions.
