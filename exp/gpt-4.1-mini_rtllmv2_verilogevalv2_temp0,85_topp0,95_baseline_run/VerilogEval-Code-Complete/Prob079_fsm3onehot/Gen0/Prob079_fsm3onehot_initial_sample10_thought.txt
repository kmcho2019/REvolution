Using the one-hot encoding, each state is represented by a 4-bit vector with a single bit high. The next state logic can be implemented by checking the current state bits and input, then setting the appropriate bit in next_state accordingly. The output 'out' depends only on the current state since it's a Moore machine. Given the state transition table, we can derive next_state bits by ORing the conditions for each next state.
