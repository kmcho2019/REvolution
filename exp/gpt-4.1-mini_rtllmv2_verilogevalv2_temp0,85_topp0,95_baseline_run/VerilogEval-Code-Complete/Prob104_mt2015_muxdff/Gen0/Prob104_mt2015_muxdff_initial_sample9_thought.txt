TopModule should implement a single bit flip-flop with a 2:1 multiplexer before it. The multiplexer selects between the load input (r_in) and the feedback input (q_in) based on the load signal L. On each rising clock edge, the flip-flop output Q is updated with the selected input from the multiplexer. This module will be instantiated three times in full_module to build the 3-bit register with feedback logic.
