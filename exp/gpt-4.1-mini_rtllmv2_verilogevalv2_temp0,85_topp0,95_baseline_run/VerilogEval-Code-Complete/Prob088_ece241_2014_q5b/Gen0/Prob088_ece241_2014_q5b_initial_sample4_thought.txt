Implement a Mealy machine with two states (A and B) using one-hot encoding. 
- State A is represented by state_A = 1, state_B = 0
- State B is represented by state_A = 0, state_B = 1
On asynchronous active-high reset, go to state A.
Output z depends on the current state and input x according to the Mealy machine transitions:
- In state A: z = x
- In state B: z = ~x
State transitions:
- From A: if x=0 stay in A, if x=1 go to B
- From B: stay in B regardless of x
