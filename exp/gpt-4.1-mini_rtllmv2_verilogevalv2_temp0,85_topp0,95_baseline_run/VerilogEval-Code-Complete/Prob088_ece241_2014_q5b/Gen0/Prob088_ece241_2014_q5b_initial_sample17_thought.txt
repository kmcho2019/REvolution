Implement the Mealy machine using one-hot encoding for states A and B. 
- Use two flip-flops, one for each state.
- On asynchronous active-high reset, state A is set.
- On each clock edge, state transitions and output z are determined by the current state and input x:
  - From state A: if x=0, stay in A, z=0; if x=1, go to B, z=1
  - From state B: if x=0, stay in B, z=1; if x=1, stay in B, z=0
Output z is combinational based on current state and input x.
