Implement a Mealy machine with two states A and B using one-hot encoding:
- State A: encoded as 2'b01
- State B: encoded as 2'b10

On asynchronous active-high reset, state goes to A (2'b01).

Transitions:
- From A: if x=0, stay in A, z=0; if x=1, go to B, z=1
- From B: regardless of x, stay in B; if x=0, z=1; if x=1, z=0

Implement state register with asynchronous reset, combinational logic for next state and output.
