Implement a Mealy machine for a 2's complementer using one-hot state encoding with two states A and B. The asynchronous active-high reset sets the machine to state A. The output z depends on current state and input x as per the transitions:
- State A: if x=0, z=0 and stay in A; if x=1, z=1 and go to B.
- State B: if x=0, z=1 and stay in B; if x=1, z=0 and stay in B.

We use a 2-bit one-hot state register with:
- state_A = 2'b01
- state_B = 2'b10

The state transitions and output logic are implemented combinationally from current state and input. The state register updates on the rising edge of clk or asynchronously resets to A on areset.

This approach ensures proper one-hot encoding and meets the requirements.
