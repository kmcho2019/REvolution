Implement the Mealy machine with two states A and B using one-hot encoding:
- State A is encoded as 2'b01 (bit0=1)
- State B is encoded as 2'b10 (bit1=1)
On asynchronous active-high reset, state goes to A.
Output z depends on both current state and input x (Mealy output).
State transitions:
- From A: if x=0 stay in A, z=0; if x=1 go to B, z=1
- From B: if x=0 stay in B, z=1; if x=1 stay in B, z=0
