The K-map is a 4-variable function with variables x1, x2 as row inputs and x3, x4 as column inputs. From the K-map, the minterms with value 1 are:
- Row 00 (x1x2=00), columns 00 and 10 (x3x4=00 and 10): minterms m0 and m2
- Row 11 (x1x2=11), columns 00, 01, 11 (x3x4=00, 01, 11): minterms m12, m13, m15
- Row 10 (x1x2=10), columns 00, 01, 10 (x3x4=00, 01, 10): minterms m8, m9, m10

Let's write the minterms explicitly:
m0 = x1' x2' x3' x4'
m2 = x1' x2' x3  x4'
m8 = x1  x2' x3' x4'
m9 = x1  x2' x3' x4
m10= x1  x2' x3  x4'
m12= x1  x2  x3' x4'
m13= x1  x2  x3' x4
m15= x1  x2  x3  x4

Now, group terms to simplify:

Group 1: m0 and m2 share x1'x2' and x4' (because both have x4' = 0), differ in x3
=> x1' x2' x4'

Group 2: m8, m9, m10:
m8 = x1 x2' x3' x4'
m9 = x1 x2' x3' x4
m10= x1 x2' x3  x4'

Group m8 and m9 differ only in x4, so x1 x2' x3'
m8 and m10 differ in x3 and x4, no direct pair, but m9 and m10 differ in x3 and x4, no direct pair.

Group m8 and m9:
x1 x2' x3'

Group m10 alone:
x1 x2' x3 x4'

Group 3: m12, m13, m15
m12= x1 x2 x3' x4'
m13= x1 x2 x3' x4
m15= x1 x2 x3 x4

m12 and m13 differ in x4, so x1 x2 x3'

m13 and m15 differ in x3, so x1 x2 x4

So group m12 and m13: x1 x2 x3'
Group m15 alone: x1 x2 x3 x4

But since m15 is included in x1 x2 x4 (because m15 has x3=1, x4=1), and m13 and m15 differ in x3, the pair x1 x2 x4 covers m13 and m15.

Therefore, the groupings:

f = x1' x2' x4' + x1 x2' x3' + x1 x2' x3 x4' + x1 x2 x3' + x1 x2 x4

We can also check if x1 x2' x3' + x1 x2' x3 x4' can be simplified:
x1 x2' (x3' + x3 x4') = x1 x2' (x3' + x3 x4') 
But no simpler way, so keep as is.

Final expression:
f = x1' x2' x4' + x1 x2' x3' + x1 x2' x3 x4' + x1 x2 x3' + x1 x2 x4
