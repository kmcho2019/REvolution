Implement a synchronous BCD clock counting seconds, minutes, and hours in a 12-hour format with an AM/PM indicator. On reset, set time to 12:00 AM. Each second increment (when ena is high) advances the seconds counter; on seconds overflow (59 -> 00), increment minutes; on minutes overflow (59 -> 00), increment hours; on hours overflow (12 -> 01), toggle the PM indicator. Hours are from 1 to 12, minutes and seconds from 00 to 59. Use BCD arithmetic and careful rollover logic to handle the counters.
