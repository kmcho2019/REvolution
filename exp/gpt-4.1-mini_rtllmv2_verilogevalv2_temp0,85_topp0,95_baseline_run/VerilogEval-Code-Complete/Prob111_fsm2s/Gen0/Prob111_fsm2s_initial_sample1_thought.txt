Implement a Moore state machine with two states: OFF and ON.
- OFF state output = 0, ON state output = 1.
- On reset (active-high synchronous), state goes to OFF.
- Transitions:
  - From OFF: if j=0 stay OFF, if j=1 go to ON.
  - From ON: if k=0 stay ON, if k=1 go to OFF.
Use a state register to hold the current state, and combinational logic to determine next state.
Assign output based on current state.
