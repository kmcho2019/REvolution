Implement a Moore FSM with two states: OFF and ON. The output depends only on the current state: OFF outputs 0, ON outputs 1. Use synchronous reset to set the state to OFF. On each clock edge, update the state based on the current state and inputs j or k:
- If state is OFF, transition to ON if j=1, else stay OFF.
- If state is ON, transition to OFF if k=1, else stay ON.
