Implement a Moore state machine with two states: OFF and ON. Use an enumerated type or localparams to define the states. On each rising clock edge, if reset is asserted, transition to OFF state. Otherwise, transition according to the state transition table:
- From OFF, if j=0 stay OFF; if j=1 go ON.
- From ON, if k=0 stay ON; if k=1 go OFF.
Output 'out' depends only on the current state: 0 for OFF, 1 for ON.
