Implement a Moore state machine with two states: OFF and ON. The output depends only on the current state (OFF=0, ON=1). On reset (active-high synchronous), transition to OFF state. On each clock edge, if reset is not asserted, transition states based on inputs j and k:
- From OFF, if j=1 go to ON; else stay in OFF
- From ON, if k=1 go to OFF; else stay in ON
Output is assigned combinationally based on the state.
