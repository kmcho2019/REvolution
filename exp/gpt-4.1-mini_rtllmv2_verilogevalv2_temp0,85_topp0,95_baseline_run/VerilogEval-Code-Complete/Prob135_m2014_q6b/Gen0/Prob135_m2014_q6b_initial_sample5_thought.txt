The FSM states are encoded as follows:
A=000, B=001, C=010, D=011, E=100, F=101.
We need to implement the next-state logic for y[2] (Y2) based on current state y[3:1] and input w.
We will use a combinational always block with a case statement on y to determine Y2 for each transition.
For each current state and input w, we find the next state and assign Y2 = next state's y[2].
