The FSM has six states coded as y[3:1] with values from 000 to 101 for states A to F respectively. We need to implement the next-state logic for y[2] (Y2) based on the current state y and input w.

To find the logic for Y2 (next state's bit 2), we analyze the transitions and extract y[2] for the next state for each current state and input w:

States coding:
A = 000 (y=3'b000)
B = 001 (3'b001)
C = 010 (3'b010)
D = 011 (3'b011)
E = 100 (3'b100)
F = 101 (3'b101)

  - w=1 → A(000) y[2]=0
- B (001)

  - w=1 → D(011) y[2]=1
- C (010)

  - w=1 → D(011) y[2]=1
- D (011)

- F (101)
