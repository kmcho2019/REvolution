States and codes:

C = 010

We want to find the next value of y[2] given current state y[3:1] and input w.

From the FSM transitions:

For each state (y), depending on input w, determine the next state, then extract bit y2 of that next state.

We'll write combinational logic inside an always @(*) block and assign Y2 accordingly.

Implementation plan:
- Use a case statement on y
- For each state, check input w and assign Y2 = next state's y2 bit.
