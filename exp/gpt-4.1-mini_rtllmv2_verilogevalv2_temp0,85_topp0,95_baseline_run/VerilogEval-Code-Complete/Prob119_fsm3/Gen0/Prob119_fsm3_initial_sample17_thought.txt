Implement a Moore FSM with 4 states encoded as 2-bit values. Use a synchronous state register triggered on the positive edge of clk with an asynchronous active-high reset (areset) to state A (00). On each clock, update the state based on the input 'in' and current state following the given transition table. The output depends only on the state (Moore machine). Assign output=1 only in state D, else 0.
