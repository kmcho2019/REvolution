Design a Moore FSM that detects the sequence 1101. The FSM will have states representing how many bits of the sequence have been matched so far. When the sequence 1101 is found, set start_shifting to 1 and keep it set until reset. The reset is synchronous active high, so at each clock, if reset is high, the FSM goes back to initial state and start_shifting is cleared. Once the sequence is detected, start_shifting stays high regardless of further input.
