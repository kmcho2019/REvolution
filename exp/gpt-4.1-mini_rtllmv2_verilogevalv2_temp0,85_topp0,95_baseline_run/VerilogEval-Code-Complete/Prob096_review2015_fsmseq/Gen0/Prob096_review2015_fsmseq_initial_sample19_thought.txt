Implement a Moore finite-state machine that detects the sequence 1101 on the input bit stream. The FSM has states representing the progress of matching the sequence so far. On detecting the full sequence, the FSM sets start_shifting to 1 and remains in a final state where start_shifting stays high until synchronous reset is asserted. The reset is active high and synchronous, so on reset the FSM returns to the initial state and start_shifting is cleared.
