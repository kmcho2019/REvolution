We design a Moore finite-state machine with 5 states to detect the sequence 1101 on the input stream. The states represent how much of the sequence has been matched so far:
- S0: no match yet
- S1: matched '1'
- S2: matched '11'
- S3: matched '110'
- S4: matched '1101' (sequence found)

Once the sequence is found, we set start_shifting to 1 and keep it asserted forever until a synchronous reset (active high) clears it. On each clock edge, if reset is high, all states and outputs reset. Otherwise, we transition based on input data and current state.

The transitions:
- S0: if data=1 -> S1, else S0
- S1: if data=1 -> S2, else S0
- S2: if data=0 -> S3, else S2 (another 1 continues the sequence)
- S3: if data=1 -> S4 (sequence found), else S0
- S4: remain in S4 forever

Output start_shifting is 1 in S4 and 0 otherwise.
