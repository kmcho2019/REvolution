Design a Moore finite-state machine with states representing how much of the sequence 1101 has been matched so far. The sequence to detect is 1101:
- State S0: no match yet
- State S1: matched '1'
- State S2: matched '11'
- State S3: matched '110'
- State S4: matched '1101' (final detection state)

Once the FSM reaches S4, set start_shifting to 1 and hold it there until reset.

On each clock cycle, transition between states based on the input data bit, considering overlap in the sequence. Use synchronous active-high reset to go back to S0 and clear start_shifting.

Implement start_shifting as a register that is set to 1 on reaching S4 and remains 1 until reset.

The module is synchronous, with no asynchronous resets.

Output start_shifting is combinational from the register.
