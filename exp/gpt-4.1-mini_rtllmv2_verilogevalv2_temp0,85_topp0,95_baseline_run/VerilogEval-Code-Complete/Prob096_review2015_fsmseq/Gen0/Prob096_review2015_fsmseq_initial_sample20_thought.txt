Design a finite state machine with states representing how much of the sequence 1101 has been matched so far. The states will be:

- S0: no bits matched
- S1: matched '1'
- S2: matched '11'
- S3: matched '110'
- S4: matched '1101' (sequence found)

On each clock edge, update the state based on the input data bit, following the sequence logic. Once the sequence is found (entering S4), the output start_shifting is set to 1 and held high until reset. The reset is synchronous and active high, returning the FSM to S0 and start_shifting to 0.

The FSM transitions:
- S0: data=1 -> S1; data=0 -> S0
- S1: data=1 -> S2; data=0 -> S0
- S2: data=0 -> S3; data=1 -> S2 (because '111' can be partial match for '11')
- S3: data=1 -> S4; data=0 -> S0
- S4: stays in S4 (start_shifting=1)

The output start_shifting is asserted when in state S4.

Implement the state machine with synchronous reset and output logic accordingly.
