Design a Moore finite-state machine with states representing the progress of detecting the sequence "1101". The states track how many bits of the sequence have been matched so far. On each clock cycle, the machine transitions based on the input data bit, and when the full sequence is detected, the output start_shifting is set to 1 and remains 1 until reset. Reset is synchronous active high and sets the FSM back to the initial state and start_shifting output to 0.
