Design a finite state machine (FSM) that detects the sequence "1101" in a serial input stream. The FSM transitions through states corresponding to the partial matches of the sequence. When the full sequence "1101" is detected, assert start_shifting output to 1 and keep it latched until a synchronous reset occurs. The reset is synchronous and active high, so on reset we return to the initial state and clear start_shifting. Once start_shifting is set, it remains set regardless of further inputs.
