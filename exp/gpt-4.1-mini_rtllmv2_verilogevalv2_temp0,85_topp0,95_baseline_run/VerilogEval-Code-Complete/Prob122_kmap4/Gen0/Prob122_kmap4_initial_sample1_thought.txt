Analyze the Karnaugh map to find a simplified expression. The map is a 4-variable function (a,b,c,d) arranged as shown. The map is:

     ab
cd  00 01 11 10
00 |0 |1 |0 |1 |
01 |1 |0 |1 |0 |
11 |0 |1 |0 |1 |
10 |1 |0 |1 |0 |

We observe a checkerboard pattern, alternating 0 and 1 in all cells. This pattern matches the XOR of all four variables: out = a ^ b ^ c ^ d.

Therefore, the output is the XOR of the four inputs.

Implement this logic in Verilog. Since the output is combinational, it's better to use always_comb or assign, but as the output is declared reg, we can assign inside an always @(*) block.
