We are given a state machine with one-hot encoded states y[6:1] for states A to F:
A = y[1], B = y[2], C = y[3], D = y[4], E = y[5], F = y[6].

We want to find the next-state signals Y2 and Y4 which correspond to states B (y[2]) and D (y[4]) respectively.

By inspection from the state transitions and using one-hot encoding:

Y2 (next B) is high if:
- Current state A (y[1]) and input w=0 (A --0--> B)
- Current state C (y[3]) and input w=1 (C --1--> D) but this goes to D, not B
- Current state F (y[6]) and input w=0 (F --0--> C), no
- Current state B (y[2]) with input w=0 goes to C, no
- So only A with w=0 leads to B

Y2 = y[1] & ~w

Y4 (next D) is high if:
- From B (y[2]) with w=1 (B --1--> D)
- From C (y[3]) with w=1 (C --1--> D)
- From E (y[5]) with w=1 (E --1--> D)
- From F (y[6]) with w=1 (F --1--> D)

So:

Y4 = (y[2] | y[3] | y[5] | y[6]) & w

This direct mapping follows from the given transitions and one-hot encoding.
