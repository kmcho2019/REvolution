Y2 corresponds to state B (y[2]), and Y4 corresponds to state D (y[4]). We want to write the next-state logic for these bits.

From the state transitions:

- Next state B (y[2]) is active when:
  - From A (y[1]) with input 0: A(0)->B
  - From C (y[3]) with input 1: C(1)->D, so not B
  - From other states no direct transition to B

So Y2 = (y[1] & ~w)

- Next state D (y[4]) is active when:
  - From B (y[2]) with input 1: B(1)->D
  - From C (y[3]) with input 1: C(1)->D
  - From E (y[5]) with input 1: E(1)->D
  - From F (y[6]) with input 1: F(1)->D

So Y4 = (y[2] & w) | (y[3] & w) | (y[5] & w) | (y[6] & w)

Hence, the logic expressions are:
Y2 = y[1] & ~w
Y4 = w & (y[2] | y[3] | y[5] | y[6])
