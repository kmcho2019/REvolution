To find the next-state signals Y2 (for state B) and Y4 (for state D), we inspect the state transitions and the one-hot encoding.

States encoding (y[6:1]):
A = 000001 (y[1])
B = 000010 (y[2])
C = 000100 (y[3])
D = 001000 (y[4])
E = 010000 (y[5])
F = 100000 (y[6])

From the state machine:

Transitions to B (y[2]):
- From A (y[1]) on input 0
So Y2 = y[1] & (~w)

Transitions to D (y[4]):
- From B (y[2]) on input 1
- From C (y[3]) on input 1
- From E (y[5]) on input 1
- From F (y[6]) on input 1
So Y4 = w & (y[2] | y[3] | y[5] | y[6])
