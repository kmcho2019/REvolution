We have a one-hot state encoding for states A-F as y[1] to y[6]. The outputs Y2 and Y4 correspond to y[2] (state B) and y[4] (state D) for the next state signals.

From the state machine, the next state depends on current state and input w. We want to find the next state signals for B (y[2]) and D (y[4]).

By inspection:

Y2 (next B) is active when:
- From A with w=0: A(0) -> B
- From no other transitions go directly to B

So, Y2 = (y[1] & ~w)

Y4 (next D) is active when:
- From B(1): B(1) -> D (B is y[2], input w=1)
- From C(1): C(1) -> D (C is y[3], w=1)
- From E(1): E(1) -> D (E is y[5], w=1)
- From F(1): F(1) -> D (F is y[6], w=1)

So, Y4 = w & (y[2] | y[3] | y[5] | y[6])
