We are given a one-hot encoded state machine with states A to F represented by bits y[1] to y[6] as follows:
A = y[1] = 000001
B = y[2] = 000010
C = y[3] = 000100
D = y[4] = 001000
E = y[5] = 010000
F = y[6] = 100000

We want to find the logic for next-state signals Y2 (corresponding to y[2], state B) and Y4 (corresponding to y[4], state D).

By inspection of the state transitions:

Y2 (next B):
- From A (y[1]) on input 0: next is B => y[1] & ~w
- From no other state transitions go to B.

So, Y2 = y[1] & ~w

Y4 (next D):
- From B (y[2]) on input 1: next D => y[2] & w
- From C (y[3]) on input 1: next D => y[3] & w
- From E (y[5]) on input 1: next D => y[5] & w
- From F (y[6]) on input 1: next D => y[6] & w

So, Y4 = w & (y[2] | y[3] | y[5] | y[6])

We implement these combinational assignments in Verilog.
