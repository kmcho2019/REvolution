Since the states are one-hot encoded as y[1] = A, y[2] = B, y[3] = C, y[4] = D, y[5] = E, y[6] = F, we want to find the next-state logic for y[2] (B) and y[4] (D) based on the current state y and input w.

By inspecting the state transitions:

Next state B (y[2]) occurs from:
- A on input 0: A(0) -> B
- No other transitions to B are given.

So, Y2 = (y[1] & ~w)

Next state D (y[4]) occurs from:
- B on input 1: B(1) -> D
- C on input 1: C(1) -> D
- E on input 1: E(1) -> D
- F on input 1: F(1) -> D

So, Y4 = w & (y[2] | y[3] | y[5] | y[6])
