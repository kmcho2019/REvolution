The states are one-hot encoded as follows: 
A = y[1], B = y[2], C = y[3], D = y[4], E = y[5], F = y[6].

We want to find the next state signals Y2 (B) and Y4 (D) based on current state y and input w.

By inspecting the state transitions:

For Y2 (state B):
- From A (y[1]) on input 0 (w=0), next state is B => y[1] & ~w
- No other transitions go to B, so Y2 = y[1] & ~w

For Y4 (state D):
- From B (y[2]) on input 1 => D => y[2] & w
- From C (y[3]) on input 1 => D => y[3] & w
- From E (y[5]) on input 1 => D => y[5] & w
- From F (y[6]) on input 1 => D => y[6] & w

So Y4 = w & (y[2] | y[3] | y[5] | y[6])

We implement these equations directly in Verilog.
