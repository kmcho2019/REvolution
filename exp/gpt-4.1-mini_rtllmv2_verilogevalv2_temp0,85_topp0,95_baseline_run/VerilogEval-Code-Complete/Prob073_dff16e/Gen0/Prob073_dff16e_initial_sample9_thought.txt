Implement 16 D flip-flops as a 16-bit register q, clocked on the positive edge of clk. On each clock cycle, if resetn is low (active low), synchronously reset q to zero. Otherwise, update q selectively by byte-enable signals: if byteena[1] is high, update the upper byte q[15:8] with d[15:8]; if byteena[0] is high, update the lower byte q[7:0] with d[7:0]. Preserve the parts of q where the corresponding byteena bit is low.
