Implement 16 D flip-flops grouped into two bytes. On each positive clock edge, if resetn is low, synchronously reset q to 0. Otherwise, update each byte selectively according to byteena: if byteena[0] is high, update q[7:0] with d[7:0]; if byteena[1] is high, update q[15:8] with d[15:8]. This allows partial byte-wise writing of the 16-bit register.
