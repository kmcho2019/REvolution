Implement 16 D flip-flops grouped as two bytes (upper and lower). On each positive clock edge, if resetn is low, synchronously reset q to zero. Otherwise, update each byte selectively based on byteena bits: if byteena[0] is high, update the lower byte q[7:0] with d[7:0]; if byteena[1] is high, update the upper byte q[15:8] with d[15:8]. This allows partial updates of the register.
