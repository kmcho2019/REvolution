Implement 16 D flip-flops with synchronous active-low reset. On each positive clock edge, if resetn is low, clear q to zero. Otherwise, update q bytes selectively according to byteena: if byteena[1] is 1, update upper byte q[15:8] from d[15:8]; if byteena[0] is 1, update lower byte q[7:0] from d[7:0]. If a byte-enable bit is 0, keep the previous value of that byte.
