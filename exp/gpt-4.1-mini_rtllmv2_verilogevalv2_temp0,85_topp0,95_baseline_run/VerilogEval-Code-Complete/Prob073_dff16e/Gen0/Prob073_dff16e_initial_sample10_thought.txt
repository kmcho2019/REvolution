Implement 16 D flip-flops as a 16-bit register `q` with synchronous active-low reset. On the rising edge of `clk`, if resetn is low, clear `q` to 0. Otherwise, update only the bytes enabled by `byteena`: if byteena[0] is set, update q[7:0] with d[7:0]; if byteena[1] is set, update q[15:8] with d[15:8]. The other bytes retain their previous values.
