Implement 16 D flip-flops combined into a 16-bit register q. On each positive clock edge, if resetn is low (active-low reset), synchronously reset q to zero. Otherwise, use byteena to control which bytes of q get updated: if byteena[1] is high, update upper byte q[15:8] with d[15:8]; if byteena[0] is high, update lower byte q[7:0] with d[7:0]. If a byte enable is low, keep that byte unchanged.
