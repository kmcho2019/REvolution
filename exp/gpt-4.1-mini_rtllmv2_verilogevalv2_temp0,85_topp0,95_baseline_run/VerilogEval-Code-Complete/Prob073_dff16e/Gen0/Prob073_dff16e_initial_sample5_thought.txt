Implement 16 D flip-flops combined into a 16-bit register q. On each positive clock edge, if resetn is low (synchronously), reset q to 0. Otherwise, update q's bytes selectively based on byteena: if byteena[1] is high, update the upper byte q[15:8] with d[15:8], and if byteena[0] is high, update the lower byte q[7:0] with d[7:0]. If the corresponding byteena bit is low, retain the old value for that byte.
