Implement a 16-bit register using 16 D flip-flops updated on the positive edge of clk. The register resets synchronously when resetn is low. The byte enables control which byte (upper or lower) is updated: if byteena[0] is set, the lower 8 bits are loaded from d[7:0]; if byteena[1] is set, the upper 8 bits are loaded from d[15:8]. If a byte enable bit is not set, the corresponding byte retains its previous value.
