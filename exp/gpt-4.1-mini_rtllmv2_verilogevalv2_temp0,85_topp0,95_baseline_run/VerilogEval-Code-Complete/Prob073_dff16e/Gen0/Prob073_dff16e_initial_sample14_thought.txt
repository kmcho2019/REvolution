Implement a 16-bit register using 16 D flip-flops. On each rising edge of clk, if resetn is low, synchronously reset the entire register to zero. Otherwise, write only the enabled bytes into q based on the byteena signals: if byteena[0] is high, update lower byte q[7:0] with d[7:0]; if byteena[1] is high, update upper byte q[15:8] with d[15:8]. The other bytes retain their previous values.
