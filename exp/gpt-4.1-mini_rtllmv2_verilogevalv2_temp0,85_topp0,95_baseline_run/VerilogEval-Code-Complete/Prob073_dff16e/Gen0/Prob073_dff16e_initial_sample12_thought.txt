Implement 16 D flip-flops grouped as two bytes: upper byte d[15:8] and lower byte d[7:0]. On each positive clock edge, if resetn is low (active-low synchronous reset), reset q to 0. Otherwise, selectively update bytes of q depending on byteena: if byteena[1] is high, update the upper byte q[15:8] with d[15:8]; if byteena[0] is high, update the lower byte q[7:0] with d[7:0]. Both bytes are updated independently based on their respective byteena bits.
