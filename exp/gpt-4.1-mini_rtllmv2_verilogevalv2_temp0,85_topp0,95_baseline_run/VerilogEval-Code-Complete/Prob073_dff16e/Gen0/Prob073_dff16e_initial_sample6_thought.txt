Create a 16-bit register updated on the positive clock edge. On synchronous active-low reset, clear q to zero. On each clock, update only the bytes enabled by byteena: if byteena[1] is set, update upper byte q[15:8] with d[15:8]; if byteena[0] is set, update lower byte q[7:0] with d[7:0]. This can be done using conditional assignments within the always block.
