Implement 16 D flip-flops combined as a 16-bit register. On the positive edge of clk, if resetn is low (active-low reset), synchronously reset all bits to 0. Otherwise, update only the bytes enabled by byteena: if byteena[0] is 1, update the lower byte q[7:0] with d[7:0]; if byteena[1] is 1, update the upper byte q[15:8] with d[15:8]. Unenabled bytes retain their previous value.
