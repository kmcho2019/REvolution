Implement 16 D flip-flops grouped into two bytes (upper and lower). On each positive clock edge, if resetn is low, synchronously reset q to 0. Otherwise, update q according to byteena: if byteena[0] is high, update lower byte q[7:0] from d[7:0]; if byteena[1] is high, update upper byte q[15:8] from d[15:8]. Unenabled bytes retain their previous values.
