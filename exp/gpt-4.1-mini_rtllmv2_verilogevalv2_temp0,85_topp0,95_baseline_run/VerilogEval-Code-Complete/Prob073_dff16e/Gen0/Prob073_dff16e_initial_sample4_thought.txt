Implement a 16-bit register using 16 D flip-flops. On each positive clock edge, check the synchronous active-low reset; if resetn is low, clear the register to 0. Otherwise, selectively update bytes based on byteena: if byteena[1] is set, update upper byte q[15:8] with d[15:8]; if byteena[0] is set, update lower byte q[7:0] with d[7:0]. The other bytes remain unchanged.
