Implement 16 D flip-flops as a 16-bit register q updated on the positive edge of clk. On each clock edge, if resetn is low (0), synchronously reset q to 0. Otherwise, update q in two parts based on byteena: if byteena[0] is high, update lower byte q[7:0] with d[7:0]; if byteena[1] is high, update upper byte q[15:8] with d[15:8]. Bytes not enabled by byteena should retain their previous values.
