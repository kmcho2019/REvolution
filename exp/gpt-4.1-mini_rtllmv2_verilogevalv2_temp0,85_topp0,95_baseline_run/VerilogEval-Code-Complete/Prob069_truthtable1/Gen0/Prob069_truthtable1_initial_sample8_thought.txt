The function f is 1 for the input combinations (x3 x2 x1) = 010, 011, 101, 111. From the truth table, the minterms for f = 1 are:
- x3' x2 x1'
- x3' x2 x1
- x3 x2' x1
- x3 x2 x1

Simplify the function:
f = x2 x1' x3' + x2 x1 x3' + x3 x2' x1 + x3 x2 x1
= x2 x3' (x1' + x1) + x3 x1 (x2' + x2)
= x2 x3' + x3 x1

So the function f = (x2 AND NOT x3) OR (x3 AND x1).
