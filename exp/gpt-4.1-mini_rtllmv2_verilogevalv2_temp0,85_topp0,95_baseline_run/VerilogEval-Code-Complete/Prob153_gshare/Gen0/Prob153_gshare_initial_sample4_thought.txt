Implement a gshare predictor with a 7-bit global history register (GHR) and a 128-entry Pattern History Table (PHT) of 2-bit saturating counters. The 7-bit index into the PHT is computed by XORing the 7-bit PC with the 7-bit history.

There are two interfaces:

1. Prediction interface:
   - When predict_valid is asserted, the predictor outputs the prediction and the current GHR.
   - The GHR is updated on the next clock edge based on the predicted direction.
   - If both training (with misprediction) and prediction happen in the same cycle, training update of GHR takes precedence.

2. Training interface:
   - When train_valid is asserted, update the PHT entry indexed by (train_pc XOR train_history) on the next clock edge, adjusting the 2-bit counter according to train_taken.
   - If train_mispredicted is asserted, restore the GHR to train_history (the known correct history after the mispredicted branch).
   - Training updates have priority over prediction updates for GHR.

Additional points:
- Asynchronous active-high reset clears the GHR to zero and PHT entries to weakly not taken (e.g., 2'b01).
- Prediction outputs the PHT counter's MSB as predicted taken (1 if counter is 2 or 3).
- Prediction outputs the GHR used to index the PHT.
- PHT updates and GHR updates happen on the clock edge following the requests.
- When training and prediction are for the same PHT index in the same cycle, prediction sees PHT state before training because training updates PHT only at clock edge.

Implementation details:
- Use a reg [1:0] array for PHT of size 128.
- Use a reg [6:0] for GHR.
- On reset, initialize GHR and PHT.
- Calculate indices by XORing PC and history.
- On predict_valid, calculate index and output predict_taken and predict_history.
- On the clock edge, update PHT if train_valid; update GHR depending on train_mispredicted or prediction.
- Priority: if train_valid & train_mispredicted, restore GHR; else if predict_valid, update GHR by predicted taken.
