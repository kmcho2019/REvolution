Implement a gshare predictor with a 7-bit global history register (GHR) and a 128-entry pattern history table (PHT) of 2-bit saturating counters indexed by XORing the 7-bit PC with the 7-bit GHR. The predictor supports two interfaces: prediction and training. On prediction, if predict_valid is high, use the current GHR and the provided PC to index into the PHT and output the predicted branch direction (taken if the saturating counter MSB is 1) and the GHR used for prediction. Then update GHR at the next clock edge with the predicted direction (shifted in). On training, if train_valid is high, update the PHT entry indexed by (train_pc XOR train_history) based on the actual outcome (train_taken) by incrementing or decrementing the saturating counter. If the branch was mispredicted, recover the GHR to the train_history (the GHR immediately after the branch), overriding any prediction update in that cycle. When prediction and training happen in the same cycle, training takes precedence for the GHR update; prediction sees the PHT before training update. Implement asynchronous active-high reset to clear the GHR to zero and the PHT entries to weakly taken (e.g., '10'). The module outputs the predicted taken bit and the GHR used for prediction.
