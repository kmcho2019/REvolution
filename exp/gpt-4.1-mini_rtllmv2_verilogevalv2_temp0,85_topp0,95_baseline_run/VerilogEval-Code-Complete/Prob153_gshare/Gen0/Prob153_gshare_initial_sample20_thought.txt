Implement a gshare branch predictor with a 7-bit PC and 7-bit global history register (GHR). The 7-bit index into the pattern history table (PHT) is generated by XORing the PC and the GHR. The PHT is a 128-entry array of 2-bit saturating counters (2 bits per entry). On a prediction request (predict_valid), output the predicted direction (MSB of counter) and current GHR value used for the prediction. Then, at the next clock edge, update the GHR with the predicted bit if no training/mispredict event with priority occurs.

On training (train_valid), update the corresponding PHT entry (using train_pc and train_history XORed) by incrementing or decrementing the 2-bit counter based on actual branch outcome (train_taken). If the branch was mispredicted (train_mispredicted), restore the GHR to the train_history to recover the state after that branch's completion, overriding any prediction-based GHR update in the same cycle.

When training and prediction occur in the same cycle targeting different entries, training modifies PHT and GHR with priority, prediction sees PHT before training update. When they target the same PHT entry, prediction outputs pre-training PHT state, training updates PHT and GHR at next clock edge.

Use asynchronous active-high reset to initialize PHT entries to weakly taken (2'b10) and GHR to zero.

Implement the logic for synchronous update of GHR and PHT, combinational read for prediction outputs, and handle priority of training over prediction on GHR update.
