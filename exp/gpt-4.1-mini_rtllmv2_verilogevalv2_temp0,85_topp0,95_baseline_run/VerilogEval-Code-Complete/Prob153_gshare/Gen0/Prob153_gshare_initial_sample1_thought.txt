Implement a gshare branch predictor with a 128-entry PHT of 2-bit saturating counters indexed by XOR of 7-bit pc and 7-bit global history. The predictor has a 7-bit global history register (GHR). On prediction (predict_valid), index PHT with predict_pc ^ GHR, output the MSB of the counter as predict_taken, and output the GHR used for prediction as predict_history. Update GHR at next clock edge with predicted bit if no training or if training is not mispredicting that cycle; if training with misprediction occurs, restore GHR to train_history instead of updating with prediction. On training (train_valid), update PHT entry indexed by train_pc ^ train_history using train_taken outcome with 2-bit saturating counter update, and if train_mispredicted, restore GHR to train_history. If prediction and training happen in same cycle and training is mispredicted, training takes precedence in GHR update. Prediction sees PHT state before training because training updates PHT at clock edge. Implement asynchronous active-high reset that clears GHR and sets all PHT entries to weakly taken (2'b10). Provide outputs predict_taken and predict_history combinationally. Handle synchronous updates at clock posedge.
