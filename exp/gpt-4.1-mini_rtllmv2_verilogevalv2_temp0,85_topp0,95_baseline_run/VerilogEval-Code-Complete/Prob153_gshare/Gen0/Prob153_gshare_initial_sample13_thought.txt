Implement a gshare branch predictor with a 7-bit PC and 7-bit global history XORed to index into a 128-entry 2-bit saturating counter table (PHT). Maintain a 7-bit global branch history register (GHR) updated each cycle with predicted or trained branch outcomes. Prediction requests produce the predicted taken signal and the GHR used for prediction, then update the GHR with the predicted outcome on the next clock edge. Training requests update the corresponding PHT entry according to the actual outcome, and if a misprediction occurred, restore the GHR to the provided train_history (state after the mispredicted branch). When prediction and training requests occur simultaneously, training takes precedence in updating the GHR. The PHT updates occur on the positive clock edge. The module resets asynchronously with active high. The predict output should reflect the current PHT state before any training updates applied this cycle, complying with the timing diagram.
