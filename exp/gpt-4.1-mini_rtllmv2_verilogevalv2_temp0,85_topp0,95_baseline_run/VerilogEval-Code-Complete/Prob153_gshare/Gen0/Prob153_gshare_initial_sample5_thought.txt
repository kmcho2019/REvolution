Implement a gshare branch predictor with:
- A 7-bit global branch history register (GHR).
- A 128-entry pattern history table (PHT) indexed by XOR of 7-bit PC and 7-bit GHR.
- Each PHT entry is a 2-bit saturating counter.

Prediction interface:
- When predict_valid is high, compute the index as predict_pc XOR current GHR.
- Output the prediction as the MSB of the 2-bit counter at this index.
- Output the current GHR used for this prediction.
- At the next posedge clk, update the GHR by shifting in the predicted bit, unless there is a training misprediction update in the same cycle (training takes precedence).

Training interface:
- When train_valid is high, compute the index as train_pc XOR train_history.
- Update the PHT entry at that index according to the actual branch outcome using saturating counters.
- If train_mispredicted is asserted, restore the GHR to train_history to recover the correct state.
- Training updates (both PHT and GHR) happen at the posedge clk.
- If training and prediction want to update GHR in the same cycle, training update of GHR takes priority.

Handle asynchronous reset (areset):
- Reset GHR and PHT entries to a weakly taken state (e.g., '01' or '10', typically '10' means weakly taken).

Ensure:
- Prediction reads PHT synchronously and outputs prediction and history combinationally.
- Training updates occur at posedge clk.
- Prediction update of GHR also occurs at posedge clk, except when training with mispredict happens.

This gives correct behavior with priority to training updates on GHR and PHT.
