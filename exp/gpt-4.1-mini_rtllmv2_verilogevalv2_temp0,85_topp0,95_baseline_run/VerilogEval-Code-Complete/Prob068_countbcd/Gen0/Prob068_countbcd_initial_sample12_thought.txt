Implement a 4-digit BCD counter where each digit ranges from 0 to 9, stored in 4-bit segments of a 16-bit register q. On each clock edge, if reset is high, reset q to 0. Otherwise, increment the ones digit (q[3:0]). When the ones digit rolls over from 9 to 0, enable the tens digit (q[7:4]) to increment. Similarly, when the tens digit rolls over, enable the hundreds digit (q[11:8]) to increment, and when the hundreds digit rolls over, enable the thousands digit (q[15:12]). Output enable signals ena[3], ena[2], and ena[1] corresponding to the increment enables for digits 3 (thousands), 2 (hundreds), and 1 (tens) respectively.
