Implement a 4-digit BCD counter with digits stored in 4-bit groups within q[15:0]. On each clock cycle, increment the ones digit (q[3:0]). When it rolls over from 9 to 0, enable the tens digit increment (ena[1]) and increment q[7:4]. Similarly, when tens digit rolls over, enable the hundreds digit increment (ena[2]), and when hundreds rolls over, enable the thousands digit increment (ena[3]). Each digit is incremented only when its enable is high. The reset synchronously clears all digits to zero. The ena outputs indicate when the respective digits should be incremented (i.e., when the lower digit rolls over from 9 to 0).
