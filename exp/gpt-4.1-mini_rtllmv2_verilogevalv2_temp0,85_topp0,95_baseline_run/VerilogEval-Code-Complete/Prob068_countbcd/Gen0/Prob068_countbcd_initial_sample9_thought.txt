We need a 4-digit BCD counter where each digit is a 4-bit BCD digit stored in q[3:0] (ones), q[7:4] (tens), q[11:8] (hundreds), q[15:12] (thousands). The counter increments the ones digit on each clock cycle. When a digit reaches 9 and is incremented, it rolls over to 0 and enables the next digit to increment as well. The enable signals ena[1], ena[2], and ena[3] correspond to the increment enables for the tens, hundreds, and thousands digits respectively. The reset is synchronous and active high, resetting the entire counter to 0 and clearing ena.

The logic on each clock cycle is:
- If reset, clear q and ena.
- Else, increment ones digit.
  - If ones rolls over from 9 to 0, ena[1] is set high (to increment tens).
  - If tens rolls over from 9 to 0, ena[2] is set high (to increment hundreds).
  - If hundreds rolls over from 9 to 0, ena[3] is set high (to increment thousands).
  - If thousands rolls over from 9 to 0, just wrap around (enable not needed beyond thousands).
