Implement a 4-digit BCD counter with digits stored in q[3:0] (ones), q[7:4] (tens), q[11:8] (hundreds), and q[15:12] (thousands). The counter increments on each clock cycle. When the ones digit reaches 9, it resets to 0 and enables the tens digit increment; similarly for tens and hundreds digits. The enable signals ena[1], ena[2], and ena[3] indicate when the tens, hundreds, and thousands digits should increment, respectively. Synchronous active-high reset clears all digits and disables all enables.
