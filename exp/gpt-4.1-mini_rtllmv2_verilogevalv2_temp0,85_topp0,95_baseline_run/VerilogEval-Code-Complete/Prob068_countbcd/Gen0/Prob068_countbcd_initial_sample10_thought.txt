Design a 4-digit BCD counter using four 4-bit digits stored in q[3:0], q[7:4], q[11:8], and q[15:12]. Each digit counts from 0 to 9. On every clock tick, the ones digit increments by 1. If it rolls over from 9 to 0, enable the tens digit increment (ena[1]). Similarly, if tens digit rolls over, enable the hundreds digit increment (ena[2]), and if hundreds digit rolls over, enable the thousands digit increment (ena[3]). The ena signals are outputs that go high when the corresponding digit increments, and are 0 otherwise. Include synchronous active-high reset that resets the whole counter to 0 and disables the ena signals.
