Implement a 4-digit BCD counter where each digit is 4 bits. The counter increments the ones digit every clock. When a digit reaches 9 and is incremented, it resets to 0 and enables the next higher digit to increment. We will generate enable signals (ena[3:1]) for the upper three digits to indicate when each should increment. The reset signal synchronously clears all digits to zero. The code will handle the carry logic between digits and update the output accordingly.
