Implement a 4-digit BCD counter, where each digit (4 bits) counts from 0 to 9. The counter increments the ones digit (q[3:0]) on each clock cycle. When a digit reaches 9 and increments, it resets to 0 and enables the next higher digit to increment via the ena signals.

The ena outputs (3 bits) indicate when the upper three digits (tens, hundreds, thousands) should increment. Specifically, ena[1] enables the tens digit, ena[2] the hundreds, and ena[3] the thousands.

The counter resets synchronously on a high reset signal.

Approach:
- On each clock edge:
  - If reset, clear all digits and ena.
  - Else increment the ones digit.
  - If ones digit overflows from 9 to 0, ena[1] is set for tens increment.
  - Similarly, if tens digit overflows, ena[2] is set for hundreds increment.
  - If hundreds digit overflows, ena[3] is set for thousands increment.
- Update digits accordingly.
- Only the upper digits use ena signals to indicate when they should increment.

Note: ena signals are combinational outputs indicating whether the corresponding digit should increment next clock cycle (based on lower digits rolling over).
