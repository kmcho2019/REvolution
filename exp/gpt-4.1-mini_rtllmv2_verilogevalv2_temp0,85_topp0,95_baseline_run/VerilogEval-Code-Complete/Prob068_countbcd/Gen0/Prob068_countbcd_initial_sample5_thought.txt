Design a 4-digit BCD counter with each digit represented by 4 bits (q[3:0] for ones, q[7:4] for tens, q[11:8] for hundreds, q[15:12] for thousands). On each clock, if not reset, increment the ones digit. When a digit reaches 9 and is incremented, it resets to 0 and enables the next digit to increment. Generate enable signals for digits 1 to 3 (tens, hundreds, thousands) based on whether the previous digit rolls over from 9 to 0. The reset synchronously clears the entire counter to zero.

Implement the counter so that the carries propagate correctly and ena[i] is high only when digit i increments on that clock cycle.
