Create a 4-digit BCD counter using a 16-bit register `q` where each 4-bit nibble represents a BCD digit: q[3:0] for ones, q[7:4] for tens, q[11:8] for hundreds, q[15:12] for thousands. On each clock cycle, increment the ones digit. If the ones digit rolls over from 9 to 0, assert ena[1] to enable increment of the tens digit. Similarly, if tens digit rolls over from 9 to 0, assert ena[2] to enable hundreds digit increment, and if hundreds digit rolls over from 9 to 0, assert ena[3] to enable thousands digit increment. Implement synchronous reset that clears q to 0 and disables all ena signals.
