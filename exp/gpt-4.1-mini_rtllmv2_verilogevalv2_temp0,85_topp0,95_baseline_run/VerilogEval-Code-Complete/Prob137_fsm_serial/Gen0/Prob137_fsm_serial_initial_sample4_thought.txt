Design a FSM with these states: IDLE (line idle, waiting for start bit), RECEIVE (count data bits), STOP_WAIT (waiting for stop bit if an error occurred). On reset, go to IDLE. When in IDLE, detect start bit (0). Then receive 8 data bits, counting each clock cycle assuming input is stable each clock. After data bits, expect stop bit (1). If stop bit is correct, assert done for one clock cycle and go back to IDLE. If stop bit is incorrect, move to STOP_WAIT and remain there until a stop bit (1) is observed, then return to IDLE. Use a counter to count the 8 data bits and properly handle the transitions. The done output goes high for one cycle when a byte is correctly received.
