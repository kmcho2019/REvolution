Design a finite state machine with the following states: IDLE, START, DATA, STOP, and WAIT_STOP. The FSM starts in IDLE, waiting for a start bit (0). Upon detecting start bit, move to START to confirm it, then proceed to DATA to shift in 8 bits (LSB first). Then move to STOP to check if the stop bit is 1. If stop bit is correct, assert done for one cycle, then return to IDLE for next byte. If stop bit is incorrect, enter WAIT_STOP state and wait until a 1 bit (stop bit) is detected before going back to IDLE. Use a shift register or counter to track received bits. Use synchronous active-high reset to reset FSM and counters.
