Design an FSM with states: IDLE (waiting for start bit), RECEIVE (counting 8 data bits), STOP (checking stop bit), and WAIT_STOP (if stop bit is incorrect, wait until a stop bit is received). The FSM transitions on the rising clock edge with synchronous active-high reset. When the start bit (0) is detected in IDLE, move to RECEIVE and shift in data bits (though data bits are not stored here, only counting them). After 8 bits, move to STOP and check if stop bit (1) is present. If yes, assert done for one cycle and return to IDLE. If no, move to WAIT_STOP, stay there until a 1 is seen on the input line (stop bit), then return to IDLE to restart. The done signal is a pulse indicating successful byte reception.
