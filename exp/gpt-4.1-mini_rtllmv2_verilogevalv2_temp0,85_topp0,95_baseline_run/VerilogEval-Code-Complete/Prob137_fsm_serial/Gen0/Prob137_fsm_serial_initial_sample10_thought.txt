Design a finite state machine (FSM) with the following states: IDLE, START_BIT, DATA_BITS (counting 8 bits), STOP_BIT, and ERROR_WAIT (waiting for correct stop bit). The FSM begins in IDLE, waiting for a start bit (0). Upon detecting start bit, it moves to DATA_BITS state, shifts in the 8 data bits one by one (LSB first), then moves to STOP_BIT state. If the stop bit is 1, the byte is considered received, output 'done' is asserted for one cycle, and FSM returns to IDLE. If stop bit is not 1, enter ERROR_WAIT state and wait until in=1 (stop bit), then return to IDLE to look for the next start bit. Use a counter to track the number of data bits received. The reset input synchronously resets the FSM to IDLE and clears counters and done.

Note: 'done' is asserted for one clock cycle when a byte is successfully received.
