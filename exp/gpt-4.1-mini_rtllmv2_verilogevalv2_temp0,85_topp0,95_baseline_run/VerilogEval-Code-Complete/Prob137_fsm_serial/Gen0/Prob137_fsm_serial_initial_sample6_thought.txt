Design a FSM with these states: IDLE (line high, waiting for start bit=0), DATA (reading 8 data bits), STOP (expect stop bit=1), WAIT_STOP (if stop bit wrong, wait for line to go high). On reset, go to IDLE. When start bit (0) detected in IDLE, move to DATA and shift in bits LSB first. After 8 bits, check stop bit. If 1, assert done for one cycle and return to IDLE. If not, go to WAIT_STOP until line is 1, then back to IDLE. Done is asserted for one clock cycle when a byte is correctly received.
