Design a FSM with states IDLE, START, DATA, STOP, and ERROR. 
- In IDLE, wait for start bit (in == 0).
- Upon detecting start bit, move to START state to confirm start bit and then shift in 8 data bits LSB first.
- After 8 bits, check stop bit (should be 1).
- If stop bit is correct, output done pulse and return to IDLE.
- If stop bit is incorrect, move to ERROR state and stay there until a stop bit (in == 1) is detected, then return to IDLE.
Use a bit counter to track the 8 data bits.
The 'done' output pulses high for one clk cycle after a successful byte reception.
Reset sets FSM to IDLE.
