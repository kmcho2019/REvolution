Design a finite state machine with the following states: IDLE, START, DATA, STOP, and ERROR. The FSM starts in IDLE, waiting for a start bit (0). Upon detecting a start bit, it moves to START and then DATA states, where it samples and shifts in 8 data bits (LSB first). After receiving 8 data bits, it transitions to STOP state to check for the stop bit (1). If the stop bit is correct, it asserts the 'done' signal for one clock cycle to indicate a valid byte received and returns to IDLE. If the stop bit is incorrect, it goes to ERROR state, where it waits for a stop bit before returning to IDLE. The reset signal synchronously resets the FSM to IDLE. The FSM operates on the rising edge of clk.
