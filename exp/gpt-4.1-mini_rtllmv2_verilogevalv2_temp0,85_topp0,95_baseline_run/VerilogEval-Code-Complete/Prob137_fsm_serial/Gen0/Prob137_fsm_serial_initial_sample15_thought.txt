Design an FSM with states IDLE, START, DATA (counting 8 bits), STOP, and ERROR. 
- In IDLE, wait for a 0 start bit on 'in'.
- Move to START on detecting start bit, then sample 8 data bits in DATA state, LSB first.
- After 8 bits, check stop bit; if it's 1, assert done for one cycle and go back to IDLE.
- If stop bit is 0, go to ERROR state and wait until a stop bit (1) is received on 'in'.
- Once a stop bit is detected in ERROR, return to IDLE to look for next start.
Use a synchronous active-high reset to initialize FSM to IDLE.
