Design a FSM with the following states: IDLE, START, DATA, STOP, and ERROR_WAIT. The line is idle high. The FSM waits for a 0 start bit in IDLE, then samples 8 data bits LSB first in DATA state, shifting them into a register (although the problem only requires detecting byte reception, storing data might be useful). After receiving 8 bits, it checks the stop bit; if stop bit is 1, done is asserted for one cycle and FSM returns to IDLE; if stop bit is not 1, FSM enters ERROR_WAIT state and waits until it detects a stop bit (line is 1) before returning to IDLE. The done output goes high one cycle when a byte has been successfully received. The reset is synchronous active-high and resets FSM to IDLE.
