Design a finite state machine (FSM) with the following states: IDLE (waiting for start bit), DATA (receiving 8 data bits), STOP (checking the stop bit), and WAIT_FOR_STOP (if stop bit is incorrect, wait until line is high). On reset, go to IDLE. On IDLE, wait for a 0 start bit. Then receive 8 bits, shifting them in LSB first (though here data is not stored, only timing matters). After 8 bits, check stop bit: if 1, assert done for one cycle and go back to IDLE; if 0, go to WAIT_FOR_STOP state and stay there until in=1, then return to IDLE. The done signal is a one-clock pulse when a valid stop bit is detected. Synchronize reset and use counters to count received bits.
