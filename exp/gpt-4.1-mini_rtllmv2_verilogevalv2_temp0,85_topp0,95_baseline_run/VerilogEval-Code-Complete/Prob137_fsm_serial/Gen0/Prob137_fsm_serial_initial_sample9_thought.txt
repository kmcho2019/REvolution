Design a finite state machine with the following states: IDLE (waiting for start bit), RECEIVING (receiving 8 data bits), STOP_BIT (checking the stop bit), and WAIT_STOP (waiting for a correct stop bit if an error occurs). The FSM starts in IDLE state, stays there while input is high (idle line). On detecting a 0 start bit, it moves to RECEIVING, sampling one bit per clock cycle and shifting in the data bits LSB first. After 8 bits, it transitions to STOP_BIT state to check if the stop bit is high (1). If yes, asserts 'done' for one cycle and returns to IDLE. If not, enters WAIT_STOP state, which waits until a stop bit (logic 1) is detected to resynchronize, then returns to IDLE. The synchronous reset returns FSM to IDLE. The 'done' signal is high for one clock cycle when a byte is successfully received.
