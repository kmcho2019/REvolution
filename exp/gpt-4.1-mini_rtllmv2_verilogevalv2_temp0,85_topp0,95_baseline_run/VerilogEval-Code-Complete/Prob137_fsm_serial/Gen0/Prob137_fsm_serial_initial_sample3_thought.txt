Design a finite state machine (FSM) with states for idle, start bit detection, receiving 8 data bits, stop bit check, and error recovery. The FSM idles while the line is high. When a 0 is detected, it moves to start bit state. Then it receives 8 data bits, least significant bit first, incrementing a bit counter. After 8 bits, it checks the stop bit (should be 1). If the stop bit is correct, assert done for one clock cycle and return to idle. If incorrect, enter a recovery state that waits until a 1 is seen on the input (stop bit) before returning to idle, to ensure resynchronization. The reset synchronously resets to idle state. The done signal indicates a correctly received byte.
