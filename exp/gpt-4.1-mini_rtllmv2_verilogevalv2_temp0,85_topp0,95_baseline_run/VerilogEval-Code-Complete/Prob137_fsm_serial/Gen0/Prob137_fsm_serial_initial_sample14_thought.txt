The FSM will have several states: IDLE (line idle, waiting for start bit), START (start bit detected), DATA (receiving 8 data bits), STOP (checking stop bit), and WAIT_STOP (waiting for correct stop bit if it was incorrect before). On reset, go to IDLE. While IDLE, wait for a 0 start bit. On detecting start bit, move to DATA state and count 8 bits. LSB first means we just count bits without shifting as we only need to know when all are received, actual data isn't output in this design. After 8 data bits, expect stop bit = 1. If correct, output done = 1 for one cycle and go back to IDLE. If incorrect stop bit, go to WAIT_STOP state, waiting until line is 1 (stop bit) before going back to IDLE. The output 'done' pulses high one cycle when a byte is successfully received with correct stop bit.

We will implement a synchronous FSM with a counter for data bits, and output the 'done' signal accordingly.
