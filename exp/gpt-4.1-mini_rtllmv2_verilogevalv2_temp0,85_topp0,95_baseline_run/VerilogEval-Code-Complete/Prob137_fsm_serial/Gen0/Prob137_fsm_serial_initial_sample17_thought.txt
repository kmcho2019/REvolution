Design a finite state machine with the following states: IDLE, START, DATA, STOP, and ERROR. 
- IDLE: Wait for start bit (0). 
- START: Confirm start bit (should be 0). If not 0, stay in IDLE. If 0, move to DATA. 
- DATA: Receive 8 data bits (least significant bit first). Count bits received. 
- STOP: Check for stop bit (should be 1). If correct, assert done for one clock cycle and go back to IDLE. 
- ERROR: If stop bit not correct, stay in ERROR until a stop bit (1) is detected, then return to IDLE.

Use a shift register or an 8-bit register to store received bits if needed. The 'done' signal is asserted for one cycle when a byte is successfully received and stop bit is verified. The synchronous reset returns FSM to IDLE.

The FSM samples input bits synchronously on rising clock edges.
