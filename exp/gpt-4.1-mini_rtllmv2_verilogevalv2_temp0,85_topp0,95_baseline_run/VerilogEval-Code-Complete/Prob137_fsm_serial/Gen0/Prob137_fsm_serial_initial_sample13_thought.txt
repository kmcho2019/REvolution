Design an FSM with the following states:
- IDLE: line is idle (high). Wait for start bit (0).
- START: start bit detected, prepare to receive data bits.
- DATA: receive 8 data bits, LSB first, counting bits.
- STOP: receive stop bit (1). If stop bit is correct, assert done for one clock cycle and go back to IDLE.
- ERROR: stop bit was incorrect; in this state, wait until a high bit (stop bit) is received before returning to IDLE.

The FSM transitions on each clock cycle, sampling the input bit. The 'done' output is asserted for one clock cycle when a byte is successfully received (after the stop bit is verified).

Use a bit counter to count received data bits (0 to 7). Store bits if needed, but the problem only requires identifying correct reception, so data storage is optional.

Implement a synchronous active-high reset that brings the FSM to IDLE and clears counters and done.

The 'done' signal is asserted only for one clock cycle when a byte is received correctly.

The start bit is detected as a transition from high (idle) to low (start bit).

If the stop bit is incorrect (not 1), FSM moves to ERROR state and waits until it sees a 1 before returning to IDLE.

The module has inputs clk, in (serial bit stream), reset, and output done.
