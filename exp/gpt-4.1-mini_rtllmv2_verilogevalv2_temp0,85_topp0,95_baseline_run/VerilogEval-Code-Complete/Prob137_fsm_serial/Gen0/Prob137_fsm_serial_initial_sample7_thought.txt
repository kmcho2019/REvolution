Design a FSM with states IDLE, START, DATA, STOP, and WAIT_STOP. In IDLE, wait for start bit (in == 0). When detected, move to START. Then sample 8 data bits in DATA state, counting bits received with a counter. After 8 bits, move to STOP state and check if the stop bit is 1. If stop bit is correct, assert done for one cycle and return to IDLE. If stop bit is incorrect (not 1), go to WAIT_STOP state, wait until in == 1 (stop bit detected), then return to IDLE to resynchronize. The done signal is a one-cycle pulse indicating a correct byte received. Reset synchronously to IDLE state.
