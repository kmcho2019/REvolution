Implement the next state logic and output logic using one-hot encoding. Each bit in the state vector corresponds to one state (S0 to S9). For each current state bit and input, determine which next state bit should be set. For outputs, only S7, S8, and S9 have non-zero outputs.

Specifically:
- next_state[0] (S0) is set on input=0 from states S0, S1, S2, S3, S4, S7, S8, and S9.
- next_state[1] (S1) is set on input=1 from states S0, S1, S8, and S9.
- next_state[2] (S2) is set on input=1 from S1.
- next_state[3] (S3) is set on input=1 from S2.
- next_state[4] (S4) is set on input=1 from S3.
- next_state[5] (S5) is set on input=1 from S4.
- next_state[6] (S6) is set on input=1 from S5.
- next_state[7] (S7) is set on input=1 from S6 and input=1 from S7 (self-loop).
- next_state[8] (S8) is set on input=0 from S5.
- next_state[9] (S9) is set on input=0 from S6.

Outputs:
- out1 = 1 when in S8
- out2 = 1 when in S7 or S9

Implement combinational assignments for next_state and outputs.
