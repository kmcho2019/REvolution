Since the state encoding is one-hot with 10 states (state[0] = S0, ..., state[9] = S9), for each state and input bit we derive the next state bit. The outputs are zero except for S7 (0,1), S8 (1,0), and S9 (1,1). Outputs depend only on the current state (one-hot) and can be directly assigned.

For next_state, we examine transitions for each state:
- S0: if in=0 next_state=S0; if in=1 next_state=S1
- S1: in=0->S0; in=1->S2
- S2: in=0->S0; in=1->S3
- S3: in=0->S0; in=1->S4
- S4: in=0->S0; in=1->S5
- S5: in=0->S8; in=1->S6
- S6: in=0->S9; in=1->S7
- S7: in=0->S0; in=1->S7
- S8: in=0->S0; in=1->S1
- S9: in=0->S0; in=1->S1

We write next_state bits as OR of all source states for which transitions lead to that state depending on input.

Outputs:
- out1 = 1 when state=S8 (state[8])
- out2 = 1 when state=S7 (state[7]) or S9 (state[9])

Implement these in combinational logic.
