Design an FSM with these states: IDLE (waiting for start bit=0), RECEIVE (collecting 8 data bits LSB first), WAIT_STOP (expecting stop bit=1), and ERROR (waiting for stop bit=1 if incorrect stop bit detected). On reset, go to IDLE. When in IDLE, if input=0, move to RECEIVE and start capturing bits into a shift register. After 8 bits received, move to WAIT_STOP and check stop bit. If stop bit=1, output done=1 and data; else move to ERROR state. In ERROR, wait until input=1 (stop bit), then go back to IDLE. The done signal pulses high for one clock cycle when a valid stop bit is detected. The out_byte output holds the last successfully received byte and is valid only when done=1.
