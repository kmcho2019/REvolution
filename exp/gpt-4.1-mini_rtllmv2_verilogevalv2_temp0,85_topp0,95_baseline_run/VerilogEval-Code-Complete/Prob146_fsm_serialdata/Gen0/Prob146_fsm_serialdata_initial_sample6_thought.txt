Design an FSM with these states: IDLE (line idle, waiting for start bit), RECEIVE (receiving 8 data bits), STOP_BIT (checking for stop bit). On reset, go to IDLE. When in IDLE and input goes low (start bit detected), move to RECEIVE and start shifting in data bits LSB first on each clock. After 8 bits, move to STOP_BIT and check if in=1 (stop bit). If stop bit correct, assert done=1 for one cycle and output the received byte, then return to IDLE. If stop bit incorrect, stay in STOP_BIT until in=1 (line high), then go back to IDLE to wait for next start bit. done is asserted for one clock cycle when a valid byte is received.
