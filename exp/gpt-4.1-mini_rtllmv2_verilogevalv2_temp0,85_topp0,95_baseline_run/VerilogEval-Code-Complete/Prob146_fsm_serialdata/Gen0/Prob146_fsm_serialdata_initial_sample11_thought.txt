Implement a finite state machine with the following states: IDLE (waiting for start bit), RECEIVE (shifting in 8 data bits LSB first), STOP (checking the stop bit). On reset, go to IDLE. While in IDLE, wait until input is 0 (start bit). Then move to RECEIVE and shift in data bits on each clock. After 8 bits, move to STOP to check stop bit. If stop bit is 1, output the received byte, assert done for one clock cycle, and go back to IDLE. If stop bit is 0 (error), stay in STOP until input becomes 1 (stop bit), then return to IDLE without asserting done. The done signal is asserted for one cycle when a valid stop bit is received.
