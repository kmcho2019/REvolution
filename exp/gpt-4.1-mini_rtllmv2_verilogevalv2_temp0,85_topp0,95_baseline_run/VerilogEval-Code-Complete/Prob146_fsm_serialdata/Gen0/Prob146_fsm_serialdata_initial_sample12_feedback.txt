This usage can cause glitches or incorrect state transitions, leading to the FSM failing to properly progress through states as designed.

This arrangement can cause 'done' to be asserted before 'out_byte' holds the correct data due to non-blocking assignment delays, resulting in the testbench seeing invalid data when 'done' is high.
