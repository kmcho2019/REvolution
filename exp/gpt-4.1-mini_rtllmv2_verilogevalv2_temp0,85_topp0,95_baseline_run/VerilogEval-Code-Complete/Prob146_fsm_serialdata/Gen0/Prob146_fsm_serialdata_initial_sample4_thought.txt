Design a FSM with states: IDLE (line idle, waiting for start bit), RECEIVE (collecting 8 data bits), STOP (checking stop bit). On reset, go to IDLE. In IDLE, wait for in == 0 (start bit). Then move to RECEIVE, shift in bits LSB first each clock cycle, count 8 bits. Then go to STOP, check if in == 1 (stop bit). If yes, output done=1 and out_byte with collected data, then return to IDLE. If stop bit is missing (in == 0), remain in a WAIT_STOP state that waits until in == 1 before returning to IDLE, ignoring incoming bits. done is a one-cycle pulse asserted at the stop bit detection when correct. Use a bit counter for 8 data bits.
