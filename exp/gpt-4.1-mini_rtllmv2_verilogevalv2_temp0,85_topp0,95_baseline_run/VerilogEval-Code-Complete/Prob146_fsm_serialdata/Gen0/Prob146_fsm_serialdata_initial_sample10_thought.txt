The FSM will have the following states: IDLE (waiting for start bit), RECEIVE (reading 8 data bits), STOP (checking stop bit), and WAIT_STOP (waiting for a valid stop bit after an error). On reset, go to IDLE. In IDLE, wait for 'in' to go low (start bit). Then shift in 8 data bits LSB first in RECEIVE state. After 8 bits, check if stop bit is 1. If yes, output data and assert done. If no, go to WAIT_STOP and ignore data until a stop bit (1) is seen. Then go back to IDLE for next byte. done is asserted only for one clock cycle when a stop bit is correctly received. The shift register captures bits LSB first as they arrive. The synchronous reset clears all state and registers.
