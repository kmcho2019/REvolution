The FSM will have the following states: IDLE (waiting for start bit), DATA (receiving 8 data bits), STOP (checking stop bit), and WAIT_STOP (waiting for a stop bit if an invalid stop bit was detected). On reset, return to IDLE. While in IDLE, wait for a start bit (input goes to 0). Upon detecting start bit, move to DATA, collect 8 bits LSB first into a shift register. After 8 bits, move to STOP and check if input is 1 (valid stop bit). If valid, assert done and output the collected byte, then return to IDLE. If invalid, move to WAIT_STOP until input is 1 (stop bit), then return to IDLE. done is asserted only for one clock cycle when a valid stop bit is detected.
