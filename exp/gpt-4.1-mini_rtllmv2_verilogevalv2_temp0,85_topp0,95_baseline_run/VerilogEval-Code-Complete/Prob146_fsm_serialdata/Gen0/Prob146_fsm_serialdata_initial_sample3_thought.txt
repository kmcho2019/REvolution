Design a finite state machine (FSM) with states to detect the start bit, receive 8 data bits (LSB first), and then check the stop bit. The FSM idles waiting for a 0 start bit, then shifts in 8 bits into a register. After receiving 8 bits, it expects a stop bit (1). If the stop bit is correct, output the data byte and assert done. If the stop bit is incorrect, wait until a stop bit (1) is received before resuming the next start bit detection. Use synchronous reset to initialize the FSM and registers. done pulses high for one cycle when a byte is correctly received.
