Implement a finite state machine with these states: IDLE (waiting for start bit), DATA (collecting 8 bits), STOP (checking stop bit), and WAIT_STOP (waiting for stop bit when an error occurred). On reset, go to IDLE. When in IDLE and input is 0, start collecting data bits (LSB first), increment a bit counter each clock, store bits into a shift register. After 8 bits, go to STOP state to check for stop bit (should be 1). If stop bit is correct, output the collected byte, assert done for one cycle, and return to IDLE. If stop bit is incorrect, move to WAIT_STOP state, stay there until a 1 is seen on input (stop bit), then go back to IDLE. Output done is asserted only for one clock cycle after correct stop bit. Use synchronous reset to set FSM state and counters to initial values.
