Design an FSM with states IDLE, START, DATA (8 bits), and STOP. Initially in IDLE, waiting for start bit (0). When start bit detected, move to START, then sample 8 data bits LSB first into a shift register over 8 clock cycles in DATA state. Then go to STOP, verify stop bit is 1. If stop bit correct, output the byte on out_byte, assert done for one cycle, then return to IDLE. If stop bit is incorrect (0), stay in STOP state until a 1 is received on in (stop bit), then assert done and return to IDLE. Use synchronous reset to go to IDLE and clear outputs. The done signal is a one-clock pulse to signal completion.
