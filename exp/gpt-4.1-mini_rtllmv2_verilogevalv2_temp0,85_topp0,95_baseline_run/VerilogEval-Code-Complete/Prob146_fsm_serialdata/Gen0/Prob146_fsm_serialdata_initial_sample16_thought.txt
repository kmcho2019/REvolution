Design an FSM with states: IDLE (waiting for start bit '0'), DATA (receiving 8 data bits), STOP (checking stop bit '1'), and WAIT_STOP (waiting for stop bit after error). On reset, go to IDLE. When in IDLE and input is 0, start receiving data bits LSB first, shift them into a register. After 8 bits, check stop bit: if 1, output data and assert done; if not 1, enter WAIT_STOP state to wait for stop bit before going back to IDLE. Done is asserted for one clock cycle when a correct stop bit is received.
