Design a finite state machine with the following states: IDLE, START, DATA, STOP, and ERROR_WAIT. 

- IDLE: Wait for the start bit (in == 0).
- START: Confirm the start bit; move to DATA.
- DATA: Shift in 8 data bits, least significant bit first.
- STOP: Check if stop bit is 1; if yes, assert done and output data, then return to IDLE.
- ERROR_WAIT: If stop bit is not 1, stay here until a 1 is received (stop bit), then move to IDLE.

A synchronous active-high reset will set the FSM to IDLE and clear the output and done signals.
