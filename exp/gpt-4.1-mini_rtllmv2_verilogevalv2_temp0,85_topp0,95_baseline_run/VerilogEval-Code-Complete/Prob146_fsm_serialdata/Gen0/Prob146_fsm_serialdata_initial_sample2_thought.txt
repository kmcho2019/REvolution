The FSM will have the following states: IDLE (waiting for start bit), DATA (receiving 8 bits), STOP (expecting stop bit), and ERROR (waiting for stop bit if error detected). On reset, go to IDLE. When in IDLE, wait for a 0 start bit. Then read 8 bits LSB first into a shift register. After 8 bits, check the stop bit. If stop bit is 1, output the byte and assert done for one clock cycle, then go back to IDLE. If stop bit is not 1, go to ERROR state and wait until the line is 1 (stop bit) before transitioning back to IDLE to resync. The done signal is asserted for one cycle when a byte has been successfully received.
