Design a FSM with the following states: IDLE, DATA, STOP, WAIT_STOP.
- IDLE: Wait for start bit (in==0).
- DATA: Shift in 8 data bits LSB first.
- STOP: Check stop bit (in==1). If correct, output the byte and assert done.
- WAIT_STOP: If stop bit was incorrect, stay in this state until in==1 (stop bit detected), then return to IDLE.
Use a counter to count 8 data bits.
Synchronously reset all registers on reset.
