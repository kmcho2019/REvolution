Implement a finite state machine with the following states: IDLE (waiting for start bit), RECEIVE (shifting in 8 data bits LSB first), STOP (checking stop bit). The FSM transitions from IDLE to RECEIVE upon detecting a start bit (0). It then collects 8 bits of data on each clock cycle, LSB first. After receiving 8 bits, it goes to STOP to check if the stop bit is 1. If the stop bit is 1, assert done and output the byte; then return to IDLE. If the stop bit is not 1, stay in STOP until a 1 is observed, then return to IDLE. Use a synchronous active-high reset to return FSM to IDLE and clear outputs.
