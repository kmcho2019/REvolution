We design a finite state machine (FSM) with states: IDLE (waiting for start bit 0), DATA (shifting in 8 data bits LSB first), STOP (checking for stop bit 1). On reset, the FSM goes to IDLE. When in IDLE and input is 0, transition to DATA state and start counting bits. In DATA state, shift in bits on each clock until 8 bits received, then go to STOP. In STOP, if input is 1 (stop bit correct), output done=1 and out_byte with the data, then return to IDLE. If stop bit incorrect (input 0), stay in STOP until input becomes 1 (wait for stop bit), and only then go back to IDLE. This ensures we do not start a new frame until the stop bit is correctly found. The output done is asserted for one clock cycle when stop bit is correctly received.
