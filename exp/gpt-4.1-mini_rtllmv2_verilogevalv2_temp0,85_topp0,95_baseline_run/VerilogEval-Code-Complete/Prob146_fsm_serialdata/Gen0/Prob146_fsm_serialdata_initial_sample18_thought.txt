Design an FSM with these states: IDLE (waiting for start bit), DATA (receiving 8 bits), STOP (checking stop bit), and WAIT_STOP (if stop bit incorrect, wait for stop bit before next byte). On reset, go to IDLE. On detecting start bit (in=0) in IDLE, move to DATA and shift in bits LSB first on each clock cycle. After 8 bits, go to STOP, check if in=1 (stop bit). If yes, output byte, assert done, go back to IDLE; else, go to WAIT_STOP and stay there until in=1 is seen, then go back to IDLE. done is asserted for one clock cycle when a stop bit is correctly received.
