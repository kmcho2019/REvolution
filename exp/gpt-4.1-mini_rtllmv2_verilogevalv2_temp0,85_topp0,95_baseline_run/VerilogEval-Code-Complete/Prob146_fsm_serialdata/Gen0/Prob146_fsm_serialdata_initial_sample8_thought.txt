Implement a finite state machine with states IDLE, START, DATA, STOP, and WAIT_STOP to handle the serial data reception. In IDLE, the line is high; when a 0 (start bit) is detected, move to START. Then read 8 data bits LSB first in DATA state, shifting them into a register. After 8 bits, expect a stop bit (1) in STOP state. If the stop bit is correct, output the byte and assert done for one cycle, then return to IDLE. If the stop bit is not correct, go to WAIT_STOP state and wait until a stop bit (1) is detected to synchronize before returning to IDLE. Use a synchronous reset to return to IDLE and clear outputs.
