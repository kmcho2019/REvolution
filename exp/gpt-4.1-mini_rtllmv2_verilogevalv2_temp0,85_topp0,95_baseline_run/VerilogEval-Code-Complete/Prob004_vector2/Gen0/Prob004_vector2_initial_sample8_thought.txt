To reverse the byte order of a 32-bit vector, we need to rearrange its 4 bytes such that the least significant byte becomes the most significant byte, the second least significant byte becomes the second most significant byte, and so forth. Specifically, if the input is divided as {byte3, byte2, byte1, byte0}, the output should be {byte0, byte1, byte2, byte3}. This can be done by slicing the input vector into 8-bit chunks and concatenating them in reverse order.
