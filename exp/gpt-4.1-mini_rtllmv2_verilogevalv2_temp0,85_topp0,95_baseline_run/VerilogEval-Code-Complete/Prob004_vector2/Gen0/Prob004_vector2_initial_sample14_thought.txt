To reverse the byte order of a 32-bit vector, we need to swap the positions of the four bytes. The input is composed of bytes in the order: in[31:24], in[23:16], in[15:8], in[7:0]. Reversing the byte order means the output should be: in[7:0], in[15:8], in[23:16], in[31:24]. We can achieve this by concatenating the bytes in reverse order.
