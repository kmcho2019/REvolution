To reverse the byte order of a 32-bit vector, we need to rearrange the 4 bytes in reverse order. The input is split into four 8-bit bytes: in[31:24], in[23:16], in[15:8], and in[7:0]. The output should place the least significant byte of input at the most significant byte of output and so forth. So the output will be {in[7:0], in[15:8], in[23:16], in[31:24]}.
