Design a Moore FSM that counts consecutive 1s seen after a 0. The FSM starts in state S0 (no previous 1s). On each input bit:

- If input is 0, reset count to zero.
- If input is 1, increment count of consecutive 1s.

The states represent the number of consecutive 1s seen since last zero: S0, S1, S2, S3, S4, S5, S6, S7+.

Transitions:

- S0: on 1 → S1, on 0 → S0
- S1: on 1 → S2, on 0 → S0
- S2: on 1 → S3, on 0 → S0
- S3: on 1 → S4, on 0 → S0
- S4: on 1 → S5, on 0 → S0
- S5: on 1 → S6, on 0 → S0
- S6: on 1 → S7 (error), on 0 → S0
- S7: on 1 → S7 (error), on 0 → S0

Outputs are asserted one cycle after detecting the pattern:

- disc (bit to discard): detected when after seeing five 1s (state S5), the next input is 0 (which means the inserted zero after five ones).

- flag (frame boundary): detected when after seeing six 1s (state S6), the next input is 0 (meaning the 0 closing the flag 01111110).

- err: detected when seven or more consecutive 1s (S7).

Because outputs are Moore, outputs depend on current state only. To output these signals one cycle after, design states so that the output is asserted in the state entered after detecting the pattern.

Implementation:

- Use 4-bit states to encode counts up to 7.
- On reset, go to S0.
- The outputs are combinationally derived from the current state.
- Synchronize reset on rising clock edge.
