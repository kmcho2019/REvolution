Design a Moore FSM that counts consecutive ones after seeing a zero. The states represent the count of consecutive 1s seen (0 to 6). On input '0', transition back to state 0. When state 5 is reached and next input is '0', assert disc output next cycle (indicating a stuffed zero after five 1s). When in state 6 and next input is '0', assert flag output next cycle (indicating flag pattern 01111110). If input is '1' in state 6 or beyond, signal error. Outputs are asserted for one full clock cycle after the pattern is detected, so outputs depend only on current state. Synchronous reset initializes the FSM to state 0 (as if previous input was zero).
