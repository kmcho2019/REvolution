Design a Moore FSM that counts consecutive 1s after a 0. States represent counts from 0 to 6 consecutive 1s. On input 0, reset count to 0. On input 1, increment count. When the count reaches 5 and next input is 0, assert 'disc' next cycle (zero after five 1s). When count reaches 6 and next input is 0, assert 'flag' next cycle (flag pattern). If count reaches 7 or more consecutive 1s, assert 'err'. Use synchronous reset and update outputs based on current state only (Moore machine). Outputs are delayed by one clock cycle as required.
