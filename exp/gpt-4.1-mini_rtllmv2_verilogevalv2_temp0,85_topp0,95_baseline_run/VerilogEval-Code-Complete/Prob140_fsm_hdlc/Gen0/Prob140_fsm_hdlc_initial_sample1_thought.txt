Implement a Moore FSM that counts consecutive 1s after seeing an initial 0. States represent how many consecutive 1s have been seen (0 to 6). On input 0, reset count to 0. When count reaches 5 and next bit is 0, output disc next cycle. When count reaches 6 and next bit is 0, output flag next cycle. When count reaches 6 and next bit is 1, output err next cycle and stay in err state until next 0 resets count. Outputs are based solely on the current state, so we add separate states for disc, flag, and err to assert outputs exactly one cycle after the pattern is detected. The FSM resets synchronously with reset asserted to initial state (count=0).
