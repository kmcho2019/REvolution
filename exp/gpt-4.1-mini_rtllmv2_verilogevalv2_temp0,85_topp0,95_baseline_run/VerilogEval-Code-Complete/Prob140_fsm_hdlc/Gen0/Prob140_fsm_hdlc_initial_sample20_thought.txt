Implement a Moore FSM that counts the number of consecutive 1s after seeing a 0. The states represent how many consecutive 1s have been seen (0 to 6). On input=0, reset count to 0. On input=1, increment count. Detect three conditions:
- After 5 consecutive 1s followed by a 0 (0111110): assert disc on next cycle.
- After 6 consecutive 1s followed by a 0 (01111110): assert flag on next cycle.
- On seeing 7 or more consecutive 1s (01111111...): assert err on next cycle.
Outputs disc, flag, err are Moore outputs assigned based on the current state, so output is asserted one clock cycle after the pattern ends.
Start in state 0 (zero consecutive ones), which models previous input = 0.
