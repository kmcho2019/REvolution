Implement a Moore FSM that counts consecutive ones after a zero or reset. States 0 to 5 represent seeing 0 to 5 consecutive ones. On input zero, reset to state 0. If after 5 ones, a zero follows (state 5 + 0), output disc next cycle. If after 6 ones, a zero follows (state 6 + 0), output flag next cycle. If 7 or more ones, output err. Outputs are assigned based on the current state and input seen at previous clock cycle, thus outputs are registered and asserted for one cycle after the condition is detected. The FSM is synchronous and reset is synchronous active high, which sets the FSM back to initial state (as if previous input zero).
