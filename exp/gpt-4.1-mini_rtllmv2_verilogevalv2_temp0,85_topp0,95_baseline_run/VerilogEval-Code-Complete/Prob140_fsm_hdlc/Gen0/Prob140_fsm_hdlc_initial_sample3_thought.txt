Design a Moore FSM that counts consecutive 1s seen after a 0. The states represent how many consecutive 1s have been seen (0 through 6+). On input 0, the FSM resets the count to 0. When exactly 5 consecutive 1s are followed by a 0, it signals 'disc' (discard the zero after 5 ones). When 6 consecutive 1s are followed by a 0, it signals 'flag' (frame boundary detected). When 7 or more consecutive 1s occur (i.e., after seeing 6 ones, another one arrives), it signals 'err'. Outputs are Moore style, so outputs depend on state only and asserted for one cycle starting after the detected condition. The FSM synchronously resets to state 0 (count=0), treating the previous bit as 0.

States:
S0: count=0 consecutive ones
S1: count=1
S2: count=2
S3: count=3
S4: count=4
S5: count=5
S6: count=6 (potential flag if next is 0, error if next is 1)
S7: count>=7 (error state)

On input:
- If in S0..S4 and input=1, increment count state by 1
- If in S5 and input=0, 'disc' output asserted next cycle, go to S0
- If in S5 and input=1, go to S6
- If in S6 and input=0, 'flag' output asserted next cycle, go to S0
- If in S6 and input=1, go to S7 (error)
- If in S7, remain in S7 and assert 'err'

Outputs for Moore FSM:
- disc asserted in S0 if previous input sequence was 0111110
- flag asserted in S0 if previous input sequence was 01111110
- err asserted in S7

Use next-state logic and a state register updated on clk with synchronous active high reset. Output assigned combinationally based on current state.
