Implement a Moore FSM that counts consecutive 1s in the input bit stream. The states represent how many consecutive 1s have been seen. On receiving a 0, the FSM resets to state 0 (as if the previous input were 0). When exactly 5 consecutive 1s have been seen, if the next input is 0, this corresponds to the pattern 0111110, so the FSM asserts disc on the next clock cycle. If after 5 consecutive 1s we get a 1 (making 6 in total) followed by a 0, this matches the flag pattern 01111110, so the FSM asserts flag on the next cycle. If we get 7 or more consecutive 1s, we assert err on the next cycle. The outputs depend only on the current state (Moore FSM), and we output disc, flag, or err for one full cycle starting one clock cycle after the pattern is detected. The FSM starts in the zero-count state after reset.
