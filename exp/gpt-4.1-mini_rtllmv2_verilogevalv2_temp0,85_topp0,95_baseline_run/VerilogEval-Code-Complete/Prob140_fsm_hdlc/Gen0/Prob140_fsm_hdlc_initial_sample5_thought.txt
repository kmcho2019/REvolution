Design a Moore FSM that counts consecutive 1s after an initial 0. Start in state S0 (representing the previous bit was 0). On input 0, return to S0 since the sequence restarts. On input 1, move through states S1 to S6 representing 1 to 6 consecutive 1s. If a zero appears after five consecutive 1s (state S5), this indicates a disc (discard) event; the FSM transitions to S0 and asserts disc in the next cycle. If a one appears after five consecutive 1s (state S5), transition to S6; if next input is 0 from S6, this signals a flag (01111110). If the FSM sees a seventh 1 (input 1 in S6), go to error state SE and assert err output. Outputs disc, flag, and err are asserted for one full cycle after the event, so outputs are generated from the FSM state in the next clock cycle (Moore type). The FSM is synchronous and reset synchronously to S0.
