Design a Moore FSM with states counting the consecutive number of 1s seen so far. Start in S0 (no consecutive ones). For each input bit:

- On input 0, reset count and output no flags/errors.
- On input 1, move to states S1, S2, ..., S6 representing 1 to 6 consecutive ones.
- At S5 and input 0, detect disc condition (5 ones followed by 0).
- At S6 and input 0, detect flag (6 ones followed by 0).
- At S6 and input 1, error (7 or more ones).
  
Outputs are registered and valid one cycle after detecting the pattern.

The reset is synchronous and active high, initializing the state to S0.

Outputs disc, flag, and err are asserted for exactly one cycle after the pattern occurs.
