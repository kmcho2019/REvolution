Design a Moore FSM that counts consecutive 1s after a 0. States represent the count of consecutive 1s seen (0 to 6+). On input 0, reset count to 0. When reaching 5 ones followed by a 0, output disc next cycle. When reaching 6 ones followed by a 0, output flag next cycle. If input is 1 and count reaches 7 or more, output err next cycle. Outputs are registered and asserted for one cycle after detecting the pattern. Reset state assumes previous input was 0.
