Implement a Moore FSM with states counting consecutive 1s (0 to 6). On each clock, update the state based on input bit: if input=1, advance state; if 0, reset to zero state. Detect conditions:

- After seeing 5 consecutive 1s followed by a 0 (state 5 with input 0), output disc next cycle.
- After seeing 6 consecutive 1s followed by a 0 (state 6 with input 0), output flag next cycle.
- If 7 or more consecutive 1s occur (state 6 and input 1), output err next cycle.

Outputs are registered and asserted one cycle after the condition is detected. The FSM resets synchronously to the zero 1s state.
