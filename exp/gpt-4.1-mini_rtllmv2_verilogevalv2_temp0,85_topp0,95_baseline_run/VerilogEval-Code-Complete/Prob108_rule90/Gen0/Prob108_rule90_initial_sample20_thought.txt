We create a 512-bit register q that holds the current state. On each clock cycle:
- If load is high, we load q with data.
- Otherwise, we update q based on Rule 90:
  For each bit i in 0 to 511, q_next[i] = q[i-1] XOR q[i+1],
  with q[-1] and q[512] considered zero.
We compute q_next combinationally and update q on the clock edge.
