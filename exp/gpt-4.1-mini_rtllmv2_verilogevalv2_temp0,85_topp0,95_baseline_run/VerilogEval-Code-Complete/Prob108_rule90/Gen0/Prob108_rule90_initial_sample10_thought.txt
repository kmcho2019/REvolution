Implement a 512-bit register q to hold the current state of the cellular automaton. On each clock cycle, if load is high, load q with the input data. Otherwise, update each bit of q with the XOR of its left and right neighbors according to Rule 90. For boundary conditions, assume q[-1] = 0 and q[512] = 0. Implement the next state calculation in a combinational block or directly within the always block to update q synchronously.
