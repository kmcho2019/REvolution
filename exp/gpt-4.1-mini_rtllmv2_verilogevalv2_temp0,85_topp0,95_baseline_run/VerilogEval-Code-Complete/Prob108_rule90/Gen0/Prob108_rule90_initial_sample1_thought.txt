Implement the 512-cell Rule 90 cellular automaton with synchronous update on each clock cycle. When load is high, q is loaded with the input data. Otherwise, each bit of q is updated simultaneously according to Rule 90: the next state of cell i is q[i-1] XOR q[i+1], with boundary conditions q[-1] and q[512] assumed 0. To handle boundaries safely, pad the current q with zeros at both ends, then compute the next state for each cell.
