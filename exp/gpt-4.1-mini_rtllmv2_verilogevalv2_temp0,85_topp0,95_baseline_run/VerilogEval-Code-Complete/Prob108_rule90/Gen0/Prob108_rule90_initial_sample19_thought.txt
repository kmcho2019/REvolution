Implement Rule 90 cellular automaton for 512 cells. On each clock cycle, if load is high, load the input data directly into the register q. Otherwise, compute the next state of each cell as the XOR of its left and right neighbors. For the boundary cells (index 0 and 511), treat out-of-bound neighbors as zero. Since q is a 512-bit register, we can compute the next state in a combinational loop inside the always @(posedge clk) block.
