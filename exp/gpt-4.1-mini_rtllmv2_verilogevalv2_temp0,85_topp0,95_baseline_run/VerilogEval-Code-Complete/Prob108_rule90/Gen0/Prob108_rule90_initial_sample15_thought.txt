Implement a 512-bit register q representing the state of the 512 cells. On each clock cycle, if load is high, load q with input data. Otherwise, update q by applying Rule 90: for each cell i, q[i] next state is q[i-1] XOR q[i+1], with boundary cells q[-1] and q[512] treated as zero. Use a combinational XOR of shifted versions of q padded with zeros at boundaries to compute the next state efficiently.
