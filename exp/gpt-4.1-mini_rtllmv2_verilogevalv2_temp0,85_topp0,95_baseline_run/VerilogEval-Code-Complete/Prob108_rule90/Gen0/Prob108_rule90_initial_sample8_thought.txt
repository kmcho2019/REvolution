Implement a synchronous update of a 512-cell array on each clock cycle. When load is high, load q with the input data. Otherwise, compute the next state of each cell as the XOR of its left and right neighbors (with boundary neighbors assumed zero). Since boundaries q[-1] and q[512] are zero, for cell 0, left neighbor is 0, for cell 511, right neighbor is 0. Perform the XOR for each cell and update q on the clock edge.
