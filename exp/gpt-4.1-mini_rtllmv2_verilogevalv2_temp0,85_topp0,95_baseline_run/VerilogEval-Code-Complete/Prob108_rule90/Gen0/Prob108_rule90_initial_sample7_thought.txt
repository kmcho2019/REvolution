Implement the 512-cell Rule 90 cellular automaton using a register q[511:0]. On each clock cycle, if load is asserted, load q with the input data. Otherwise, update each cell q[i] to be the XOR of its left neighbor q[i-1] and right neighbor q[i+1]. For boundary cells, assume neighbors outside the range are zero. This can be done by concatenating zeros on both ends and then XORing adjacent bits to get the next state.
