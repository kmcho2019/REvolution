Implement a 512-bit register q to hold the current state of the cellular automaton. On load signal, synchronously load the input data into q. On each clock cycle (when load is low), update q based on Rule 110 applied to each cell and its two neighbors. For cells at the edges (0 and 511), treat out-of-bound neighbors as zero. Implement the Rule 110 logic using bitwise operations or combinational logic inside the always block, computing the next state of each bit simultaneously and then updating q.
