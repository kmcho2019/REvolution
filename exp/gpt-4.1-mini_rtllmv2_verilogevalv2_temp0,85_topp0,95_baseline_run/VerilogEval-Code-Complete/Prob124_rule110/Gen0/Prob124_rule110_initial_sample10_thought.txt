Implement a 512-cell Rule 110 cellular automaton. On each clock cycle, if load is high, load q with the input data. Otherwise, compute the next state of each cell based on its left, center, and right neighbors using Rule 110. Boundary cells treat out-of-bound neighbors as zero. We can compute the next state combinationally inside an always block by iterating over all 512 cells and applying the rule. The rule can be encoded as a lookup table or by boolean logic corresponding to the table. We'll use the boolean expression for the rule derived from the table for efficiency.
