Implement a 512-cell Rule 110 cellular automaton that updates its state on each clock cycle.
- On load=1, synchronously load q with data input.
- Otherwise, update each cell in q simultaneously using Rule 110 logic.
- Boundary cells have neighbors assumed zero outside the range.
- Use a combinational loop to compute the next state for each cell based on its left, center, right neighbors.
- Since the update is synchronous, compute next state in a temporary register, then assign to q on posedge clk.
