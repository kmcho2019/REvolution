Implement the Rule 110 cellular automaton on a 512-cell array with synchronous load. On each clock cycle, if load is high, load the input data into q. Otherwise, compute the next state of each cell in q according to Rule 110, using zero for the boundary cells outside the array. The next state for cell i depends on q[i+1], q[i], and q[i-1], with q[-1] and q[512] treated as zero. Use a combinational block to compute the next state for all cells simultaneously, then register the updated state on the clock edge.
