We implement the 512-cell Rule 110 cellular automaton. On each clock cycle, if 'load' is high, we load the 512-bit input data into q. Otherwise, we compute the next state of each cell based on itself and its two neighbors according to Rule 110. For boundary cells, neighbors outside the array are considered zero. The next state logic is derived from the rule table, which matches the binary pattern of the three cells to the new state. We'll implement this as combinational logic inside the clocked process for all 512 cells simultaneously.
