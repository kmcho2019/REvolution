Implement the Rule 110 automaton for 512 cells. On each clock edge:
- If load is high, synchronously load q with the input data.
- Otherwise, update each cell based on the Rule 110 update rule applied to its left, center, and right neighbors.
- For boundary conditions, assume cells outside the range are zero.
Implement the update combinationally using a for loop and store the next state in a temporary register before updating q.
