Create a single-stage shift register module with inputs clk, w, R, E, L and output Q.
On each clock edge:
- If L is high, load Q with R.
- Else if E is high, shift Q with input w.
- Else hold the current value of Q.
This requires a 2-level multiplexer before the flip-flop:
- First mux selects between load value R and shifted input w, controlled by L.
- Second mux selects between the mux output and current Q, controlled by E.
Then Q is updated on the rising edge of clk.
