The module should describe a single stage of an n-bit shift register with load capability. On the rising edge of clk, if L (load) is asserted, the flip-flop should load the value R; if not loading and E (enable) is asserted, the flip-flop should shift in the value w; otherwise, it should retain the current value. This requires a multiplexer to select between load, shift, or hold behavior before storing the result in Q.
