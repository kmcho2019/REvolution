Implement a 64-bit register with synchronous load and shift operations. On each clock edge, if load is high, load the input data. Otherwise, if ena is high, shift according to amount: left by 1 or 8 bits, or right arithmetic by 1 or 8 bits. For left shifts, fill with zeros on the right. For right arithmetic shifts, fill vacated bits on the left with the sign bit (most significant bit).
