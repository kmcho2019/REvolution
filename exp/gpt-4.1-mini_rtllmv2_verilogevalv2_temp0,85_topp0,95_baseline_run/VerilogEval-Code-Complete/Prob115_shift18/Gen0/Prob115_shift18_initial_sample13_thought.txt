Implement a synchronous 64-bit shift register with load capability. On each clock edge, if load is high, load the input data directly. Otherwise, if ena is high, shift q according to amount: shift left by 1 or 8 bits, or arithmetic shift right by 1 or 8 bits. For arithmetic right shift, fill shifted-in bits with the sign bit q[63]. If ena is low and load is low, hold the current value.
