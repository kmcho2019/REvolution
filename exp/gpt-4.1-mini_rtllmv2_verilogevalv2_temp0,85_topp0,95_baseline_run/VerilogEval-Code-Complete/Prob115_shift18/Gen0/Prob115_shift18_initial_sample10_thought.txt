Implement a 64-bit shift register with synchronous load and enable. On a clock edge, if load is high, load the input data into the register. Otherwise, if ena is high, shift the register according to the amount signal: left by 1 or 8 bits, or arithmetic right shift by 1 or 8 bits. Arithmetic right shift replicates the sign bit (MSB). If neither load nor ena is asserted, hold the current value.
