Implement a 100-bit register with synchronous load and rotation logic. On each clock edge, if load is high, load the input data directly. Otherwise, check ena to determine the operation: no rotation (ena==00 or ena==11), rotate right by 1 bit (ena==01), or rotate left by 1 bit (ena==10). Rotation is done by taking the bit shifted out from one end and feeding it back to the other end, preserving all bits. Update q accordingly on each clock cycle.
