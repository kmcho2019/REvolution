Implement a 100-bit register that loads synchronously when 'load' is high. When 'load' is low, check 'ena' to decide rotation: if ena==2'b01, rotate right by 1 bit (bit 0 gets bit 1, ..., bit 99 gets bit 0); if ena==2'b10, rotate left by 1 bit (bit 99 gets bit 98, ..., bit 0 gets bit 99). If ena==2'b00 or 2'b11, hold the current value. Perform all operations synchronously on the rising edge of clk.
