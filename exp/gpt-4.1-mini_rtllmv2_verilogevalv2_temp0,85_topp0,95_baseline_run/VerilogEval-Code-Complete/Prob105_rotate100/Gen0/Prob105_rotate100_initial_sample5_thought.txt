Implement a synchronous 100-bit rotator with load and rotation enable signals. On the rising edge of the clock:
- If load is high, synchronously load the input data into the register.
- Else, if ena indicates rotation:
  - For ena==2'b01, rotate right by 1 bit: the LSB moves to MSB, rest shift right.
  - For ena==2'b10, rotate left by 1 bit: the MSB moves to LSB, rest shift left.
- For ena==2'b00 or 2'b11, hold the current state.
The output q is the register content updated accordingly.
