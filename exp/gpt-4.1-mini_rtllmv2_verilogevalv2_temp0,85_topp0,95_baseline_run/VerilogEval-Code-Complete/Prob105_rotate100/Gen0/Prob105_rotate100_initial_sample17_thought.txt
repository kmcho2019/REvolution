Implement a 100-bit register with synchronous load and rotation logic. On the rising edge of clk, if load is high, q is loaded with data. Otherwise, depending on ena: if ena == 2'b01 rotate right by one bit (q[0] takes q[1], ..., q[99] takes q[0]), if ena == 2'b10 rotate left by one bit (q[0] takes q[99], q[1] takes q[0], ...). For ena == 2'b00 or 2'b11, no change. The rotation is circular, so the shifted-out bit is inserted at the opposite end.
