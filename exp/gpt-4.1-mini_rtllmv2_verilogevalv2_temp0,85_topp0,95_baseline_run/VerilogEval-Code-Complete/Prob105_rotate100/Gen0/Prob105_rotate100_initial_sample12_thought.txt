Implement a 100-bit rotate register with synchronous load and enable control. On the rising edge of clk:
- If load is high, load q with data.
- Else if ena indicates a rotate operation, rotate q accordingly:
  - For ena=2'b01, rotate right by 1: q <= {q[0], q[99:1]}.
  - For ena=2'b10, rotate left by 1: q <= {q[98:0], q[99]}.
- Otherwise, hold q unchanged.
Rotation wraps bits around instead of shifting in zeros.
