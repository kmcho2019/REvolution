Implement a 100-bit register with synchronous load and rotation capabilities. On the rising edge of clk, if load is high, load the input data into the register. If load is low, check the ena signal: if ena == 2'b01, rotate right by one bit by moving q[0] to q[99] and shifting others right; if ena == 2'b10, rotate left by one bit by moving q[99] to q[0] and shifting others left; otherwise, keep q unchanged.
