Implement a synchronous 100-bit rotator with a clocked always block. When load is high, load the input data into q. Otherwise, based on ena:
- If ena == 2'b01, rotate right by one: q[0] <= q[1], ..., q[99] <= q[0] (the LSB comes from the MSB).
- If ena == 2'b10, rotate left by one: q[99] <= q[98], ..., q[0] <= q[99] (the MSB comes from the LSB).
- If ena == 2'b00 or 2'b11, do not modify q.
This ensures that rotation is circular and synchronous with load having priority.
