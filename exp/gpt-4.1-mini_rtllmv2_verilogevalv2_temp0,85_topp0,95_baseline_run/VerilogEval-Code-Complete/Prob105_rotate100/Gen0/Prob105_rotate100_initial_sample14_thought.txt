Implement a 100-bit register with synchronous load and rotate capabilities.
On the rising edge of clk:
- If load is high, load data directly into q.
- Else if ena == 2'b01, rotate q right by one bit: q[0] <= q[1], ..., q[99] <= q[0].
- Else if ena == 2'b10, rotate q left by one bit: q[99] <= q[98], ..., q[0] <= q[99].
- Else keep q unchanged.

Rotation means the bit shifted out from one end is shifted in at the other end.
