Implement a 100-bit rotate register with synchronous load and enable. On rising clk edge: 
- If load is high, load q with data.
- Else, if ena is 2'b01, rotate right by 1 bit: q <= {q[0], q[99:1]}.
- Else, if ena is 2'b10, rotate left by 1 bit: q <= {q[98:0], q[99]}.
- Else (ena == 2'b00 or 2'b11), hold q.
