Implement a 100-bit register with synchronous load and rotation controls.
On the rising clock edge:
- If load is high, load data into q.
- Else if ena == 2'b01, rotate right by one bit: q[0] <= q[1], ..., q[99] <= q[0]
- Else if ena == 2'b10, rotate left by one bit: q[0] <= q[99], q[1] <= q[0], ...
- Else (ena == 2'b00 or 2'b11), hold q.
