Implement a 100-bit register with synchronous load and rotation capabilities. On each clock edge, if load is high, load the input data into q. Otherwise, if ena indicates rotate right (2'b01), rotate q one bit right by moving the least significant bit to the most significant position and shifting right. If ena indicates rotate left (2'b10), rotate q one bit left by moving the most significant bit to the least significant position and shifting left. If ena is 2'b00 or 2'b11, keep q unchanged. All operations happen synchronously on the rising clock edge.
