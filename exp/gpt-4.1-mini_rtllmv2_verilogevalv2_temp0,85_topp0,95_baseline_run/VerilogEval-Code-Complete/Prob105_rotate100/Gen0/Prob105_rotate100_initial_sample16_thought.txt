Implement a 100-bit register with synchronous load and rotate functionality. On each clock edge:
- If load is high, load q with data input.
- Else if ena == 2'b01, rotate right by one bit: the LSB moves to MSB position, and other bits shift right.
- Else if ena == 2'b10, rotate left by one bit: the MSB moves to LSB position, and other bits shift left.
- Else (ena == 2'b00 or 2'b11), hold the current value of q.
This ensures correct synchronous operation with clear priority: load > rotate > hold.
