To build a population count for a 255-bit input, we can sum all the bits by first breaking the input into smaller chunks, summing those partial counts in parallel, then adding the partial sums until we get the final count. Since 255 bits fit into 8 bits of output (max count 255), the output is 8 bits. We can use a simple for-loop inside an always block to count the number of set bits by summing them directly.
