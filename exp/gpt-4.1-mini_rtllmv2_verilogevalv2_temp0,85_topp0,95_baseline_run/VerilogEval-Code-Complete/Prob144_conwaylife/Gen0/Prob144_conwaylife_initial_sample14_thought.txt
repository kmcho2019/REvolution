Implement a 16x16 Game of Life variant with the specified rules and toroidal wrap-around. Represent the grid as a 16x16 array internally for easier neighbor calculation, then flatten back to the 256-bit vector for output. On each clock edge, if load is high, load the input data into q. Otherwise, compute the next state by counting the 8 neighbors of each cell with wrap-around (toroid). Apply the rules:
- 0-1 neighbors: cell becomes 0
- 2 neighbors: cell unchanged
- 3 neighbors: cell becomes 1
- 4+ neighbors: cell becomes 0
This logic is fully combinational and updates q every clock cycle.
