Implement the 16x16 toroidal game state update in a synchronous always block. When load is high, load the initial data into q at the next clock edge. Otherwise, compute the next state for each cell based on its 8 neighbors with wrap-around indexing. For each cell, count alive neighbors, then apply the rules: 0-1 neighbors -> 0, 2 neighbors -> same state, 3 neighbors -> 1, 4+ neighbors -> 0. Store the next state in a temporary variable and assign it to q at the clock edge.
