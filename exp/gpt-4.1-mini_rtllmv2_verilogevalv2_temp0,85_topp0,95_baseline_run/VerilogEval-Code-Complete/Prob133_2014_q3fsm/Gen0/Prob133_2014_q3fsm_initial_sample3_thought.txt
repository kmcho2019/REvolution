We have an FSM starting in state A, staying there while s=0, and moving to state B when s=1. After entering B, the FSM counts the number of clock cycles (3 cycles) and how many times w=1 during these cycles. After three cycles, if w=1 exactly twice, output z=1 for one cycle, else z=0. Then repeat the 3-cycle counting process continuously.

To minimize states, use:
- State A for waiting for s=1.
- One state B for counting w over 3 cycles, using an internal 2-bit counter and a 2-bit counter for number of w=1.

We can implement counting inside state B using counters instead of separate states.

Outputs depend on counts after each 3-cycle window.

Synchronous reset resets to state A and clears counters.

Implementation details:
- state: 1-bit (A=0, B=1)
- count_cycles: 2-bit counter for 0 to 2 (3 cycles)
- w_count: 2-bit counter to count w=1 occurrences
- output z set to 1 for one cycle after 3rd cycle if w_count==2 else 0

Repeat counting in state B indefinitely.
