Design an FSM with minimal states by encoding the count of w=1 inputs during the 3-cycle observation window in state B. Use states to represent counting how many times w=1 has occurred (0, 1, 2, or 3) during these three cycles. After three cycles, output z=1 if exactly two w=1's were counted; otherwise z=0. Then restart counting for the next three cycles. State A waits for s=1 to transition to B, then we only track w in B. Use a 2-bit counter to count w=1 occurrences in B and a 2-bit cycle counter to count how many cycles have passed in B. Output z is registered on the cycle after the third observation. Reset is synchronous and active high.

States:
- A: waiting for s=1
- B: counting w inputs over 3 cycles, with counters for w=1 count and cycles

Implementation:
- In state A: if s=1 go to B, else stay
- In state B: increment cycle count each clock, count w=1 occurrences
- When cycle count reaches 3, set z=1 if w_count == 2 else 0, then reset counters for next 3-cycle window
- Remain in B indefinitely after entering it.

Use registers for w_count and cycle_count, and a state register for A or B.
