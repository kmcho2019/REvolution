Design an FSM with states representing the initial state A and a counting sequence in state B over three clock cycles. Start in state A (reset state). Stay in A while s=0; when s=1 move to B. In state B, count how many times w=1 over three cycles using a 2-bit counter. After three cycles, set output z=1 if exactly two w=1's counted, else 0. Then repeat the counting process in B for the next three cycles. Use a small counter to track cycle count and w count, minimizing states by embedding counting logic inside state B.
