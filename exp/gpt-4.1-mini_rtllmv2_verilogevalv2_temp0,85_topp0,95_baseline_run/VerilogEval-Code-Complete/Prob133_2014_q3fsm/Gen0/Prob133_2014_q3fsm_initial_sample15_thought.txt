Design a FSM with minimal states that starts in A (reset state). In state A, wait for s=1 to transition to state B. In state B, count w=1 occurrences over a window of 3 clock cycles. After 3 cycles, output z=1 if exactly two w=1's occurred, else z=0. Then repeat the 3-cycle counting continuously in state B. Use a 2-bit counter for counting w=1 occurrences, a 2-bit cycle counter for counting to 3 cycles, and keep track of state (A or B). Reset synchronously clears everything. Output z is registered and set one cycle after the 3-cycle counting completes.
