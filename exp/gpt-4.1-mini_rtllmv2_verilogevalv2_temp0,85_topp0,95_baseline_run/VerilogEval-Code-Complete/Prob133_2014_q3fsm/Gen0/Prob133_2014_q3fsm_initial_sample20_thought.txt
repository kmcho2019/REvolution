The FSM has two main phases: 
1. In state A, wait for s=1 to move to state B.
2. In state B, count the number of times w=1 in each group of 3 clock cycles, then set z=1 if exactly two of those three w's were 1; else z=0. Then repeat the 3-cycle counting.

To implement this with minimal states, we'll use:
- State A: waiting for s=1.
- State B: counting w's over 3 cycles.

We can embed the counting and cycle counting into registers rather than separate states.

We need:
- A 2-bit counter to track the 3 cycles (0 to 2).
- A 2-bit counter to count how many times w=1 during these 3 cycles.
- z is asserted in the clock cycle immediately after the 3rd cycle, depending on the count.

FSM states:
- A: wait for s=1.
- B: counting cycles of w.

When in B, each clock:
- increment cycle counter (0 to 2)
- if w=1, increment w_count
- after 3 cycles, output z=1 if w_count==2 else 0, then reset cycle and w_count.

Reset is synchronous and active high.
