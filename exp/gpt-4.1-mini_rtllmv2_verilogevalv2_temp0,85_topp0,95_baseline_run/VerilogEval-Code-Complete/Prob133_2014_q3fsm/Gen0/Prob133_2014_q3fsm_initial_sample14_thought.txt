Design an FSM with minimal states:

- State A: Wait for s=1 to transition to B.
- State B: Sample w for exactly three clock cycles, counting the number of times w=1.
- After 3 samples in B, check if exactly two of them were 1.
- Output z=1 in the next cycle if condition met; else z=0.
- Then continue sampling next three w's similarly (no returning to A or using s again).
  
Implementation approach:
- Use a 2-bit counter to count number of w samples (0 to 2).
- Use a 2-bit counter to count number of w=1 in these 3 samples (0 to 3).
- Use a state variable for A and B.
- Output z is registered and updated in the cycle after sampling 3 w's.
- Reset synchronous active high.
