We design an FSM with three main phases: 
- State A: wait for s=1 to move to B
- State B: count w=1 occurrences over three clock cycles, then output z=1 if exactly two ones were counted, else 0, and repeat the counting process.

Since we want to use as few states as possible, instead of separate states for each count, we use a 2-bit counter to keep track of how many times w=1 in the current 3-cycle window and a 2-bit cycle counter for how many cycles have passed (0 to 2). After 3 cycles, we decide z and restart counting.

We encode states minimally:

- State A: waiting for s=1
- State B: counting w for 3 cycles, then producing output z based on count.

We implement this with a simple state variable (A or B), a 2-bit counter for w=1 counts, and a 2-bit cycle counter.

On reset, FSM goes to A, z=0.

In A, if s=1, move to B and start counting w.

In B, increment cycle count and if w=1 increment w count. After 3 cycles, set z=1 if w count==2, else 0, then reset counters and start next cycle.

z is registered output, updated on clock.
