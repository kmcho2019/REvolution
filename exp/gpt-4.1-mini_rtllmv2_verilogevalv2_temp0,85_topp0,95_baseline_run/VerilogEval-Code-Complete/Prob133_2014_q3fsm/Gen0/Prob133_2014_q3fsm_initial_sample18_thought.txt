Design a FSM with minimal states: start in state A, wait for s=1 to move to state B. In B, count the next 3 clock cycles of w to determine if exactly two are 1. Use a 2-bit counter for the number of cycles (0 to 3) and a 2-bit counter to count how many times w=1. After 3 cycles, set z=1 if count of w=1 is exactly 2, else z=0, then restart the 3-cycle counting process. The FSM only needs two main states: A and B, with internal counters in B to track the cycle count and w count. Reset is synchronous, active high.
