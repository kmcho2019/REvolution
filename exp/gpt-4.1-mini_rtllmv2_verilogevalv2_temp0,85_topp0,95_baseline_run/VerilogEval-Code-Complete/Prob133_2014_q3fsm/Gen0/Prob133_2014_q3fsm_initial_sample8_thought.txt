We start in state A where we wait for s=1 to transition to B. In B, we need to count the number of clock cycles (exactly 3) and track how many times w=1 during these cycles. After 3 cycles, if exactly two of them had w=1, output z=1 for one clock cycle; otherwise z=0. Then repeat the counting for the next 3 cycles continuously while staying in B.

To minimize states:
- Use state A for waiting s=1.
- Use state B as the counting state.
- Within state B, use counters and registers to track cycles and number of w=1 occurrences.
- Output z is asserted for one cycle right after counting completes.

We will implement:
- state encoding: A=0, B=1
- a 2-bit counter for counting 3 cycles (0 to 2)
- a 2-bit count for number of w=1 occurrences (max 3)
- at the end of 3 cycles, compare w count == 2 to set z=1 next cycle, then reset counter and w count to start counting next 3 cycles.

All logic is synchronous with reset active high.
