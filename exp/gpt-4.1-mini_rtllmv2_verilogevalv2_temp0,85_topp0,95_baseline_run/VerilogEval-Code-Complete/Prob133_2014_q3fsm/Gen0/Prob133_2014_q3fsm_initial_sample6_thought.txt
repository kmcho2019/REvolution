We start in state A, waiting for s=1 to move to state B. In state B, we count the number of clock cycles (up to 3) and the number of times w=1 during these cycles. After 3 cycles, we assert z=1 if exactly two of the w inputs were 1; otherwise, z=0. Then we reset the count and w-ones counter and repeat. Since s is used only in state A, once we leave A, we ignore s. We implement a counter (0 to 3) for cycles in B, and a counter for w=1 occurrences. We'll use a simple FSM with states A and B, and counters to track the cycles and the number of w=1s. z is asserted only for one cycle after counting 3 w inputs.
