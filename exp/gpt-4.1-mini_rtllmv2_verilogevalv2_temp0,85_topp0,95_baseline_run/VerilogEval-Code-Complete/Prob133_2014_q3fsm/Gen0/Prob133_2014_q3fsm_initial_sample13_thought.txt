The FSM has two main phases: 
1) In state A, waiting for s=1 to move to state B.
2) In state B, count the number of times w=1 in exactly three clock cycles, then output z=1 if exactly two of those were 1, else z=0. Then repeat this counting every three cycles.

To minimize states, in state B we don't need separate states for each count; we can keep a 2-bit counter for the clock cycles (0 to 2) and a 2-bit counter for how many times w=1 occurred in the current window. After three cycles, we set z accordingly for one cycle, then restart counting.

Thus, the FSM states can be:
- A (waiting for s=1)
- B (counting w over 3 cycles)

We use counters inside B state:
- cycle_count: 0 to 2 (3 cycles)
- w_count: counts how many times w=1 in those 3 cycles

Output z is set in the clock cycle after the 3rd cycle ends, according to w_count==2, then we reset counters to start next 3-cycle count.

Reset is synchronous and active high, so on reset we start in A state and clear counters and output.
