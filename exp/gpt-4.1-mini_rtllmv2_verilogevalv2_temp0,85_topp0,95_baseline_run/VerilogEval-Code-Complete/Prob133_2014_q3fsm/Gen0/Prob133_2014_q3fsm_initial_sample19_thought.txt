Design a FSM with the following states: A (reset state, waiting for s=1), and B (counting the next 3 cycles of w). In B, we track the number of cycles counted (0 to 3) and count how many times w=1. After 3 cycles, output z=1 if exactly two of those w's were 1, else z=0. Then restart the counting for the next 3 cycles. Use a small counter (2 bits) for counting cycles and a small register for counting the number of w=1s. Since we only output z one cycle after the three w's are observed, we output z based on the stored count from the previous 3 cycles while starting the new counting phase. Reset synchronously resets state to A and clears counters and output.
