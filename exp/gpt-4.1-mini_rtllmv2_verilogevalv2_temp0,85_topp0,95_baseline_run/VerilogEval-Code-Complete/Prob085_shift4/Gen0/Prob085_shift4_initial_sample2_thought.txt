Implement a 4-bit shift register with asynchronous positive-edge reset (areset) that clears q to zero immediately on areset. On the positive clock edge, if load is high, synchronously load q with data[3:0]. If load is low and ena is high, shift q right by one bit, inserting zero at the MSB. If neither load nor ena is high, hold the current value. Load has priority over ena when both are high.
