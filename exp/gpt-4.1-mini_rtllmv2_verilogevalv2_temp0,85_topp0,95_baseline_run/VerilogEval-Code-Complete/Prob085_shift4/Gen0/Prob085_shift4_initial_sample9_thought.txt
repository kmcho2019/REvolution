Implement a 4-bit shift register with asynchronous positive edge reset. On reset, q is cleared to zero. On the rising edge of clk, if load is high, q is loaded with data. If load is low and ena is high, q is shifted right by one bit with zero shifted into q[3]. If both load and ena are high, load takes priority so shift does not occur. If neither load nor ena is high, q retains its value.
