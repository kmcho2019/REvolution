For out_both, each bit (except the highest) indicates if that bit and its left neighbor are both 1. So out_both[i] = in[i] & in[i+1] for i=0 to 2.

For out_any, each bit (except the lowest) indicates if that bit or its right neighbor is 1. So out_any[i] = in[i] | in[i-1] for i=1 to 3.

For out_different, the vector is considered circular, so each bit compares with its left neighbor with wrap-around: out_different[i] = in[i] ^ in[(i+1) % 4].
