For out_both[2:0], each bit checks if both the current bit and its left neighbor (higher index) are 1. Since in[3] has no left neighbor, out_both[3] is not defined and output is 3 bits wide.

For out_any[3:1], each bit checks if either the current bit or its right neighbor (lower index) is 1. Since in[0] has no right neighbor, out_any[0] is not needed and output is 3 bits wide.

For out_different[3:0], each bit compares the current bit with its left neighbor, but with wrap-around: in[3]'s left neighbor is in[0].
