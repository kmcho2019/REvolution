For out_both[2:0], each bit checks if both in[i] and in[i+1] are 1. Since the left neighbor means higher index, out_both[i] = in[i] & in[i+1], for i=0 to 2.

For out_any[3:1], each bit checks if either in[i] or in[i-1] is 1. Since the neighbor to the right means lower index, out_any[i] = in[i] | in[i-1], for i=1 to 3.

For out_different[3:0], each bit checks if in[i] is different from its left neighbor with wrap-around, so out_different[i] = in[i] ^ in[(i+1)%4].
