For out_both[2:0], each bit is 1 if both the input bit and its left neighbor (higher index) are 1; since in[3] has no left neighbor, out_both[3] is not needed. For out_any[3:1], each bit is 1 if either the input bit or its right neighbor (lower index) is 1; since in[0] has no right neighbor, out_any[0] is not needed. For out_different[3:0], each bit is 1 if the input bit is different from its left neighbor, with wrap-around (i.e., in[3]'s left neighbor is in[0]). We'll implement these relationships using bitwise operations and assign statements.
