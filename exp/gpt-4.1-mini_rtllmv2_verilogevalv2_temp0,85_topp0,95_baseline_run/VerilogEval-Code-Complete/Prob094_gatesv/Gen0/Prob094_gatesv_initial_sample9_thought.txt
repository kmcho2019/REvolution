For out_both[2:0], each bit checks if in[i] and in[i+1] are both 1, except for the highest bit since in[3] has no left neighbor.

For out_any[3:1], each bit checks if in[i] or in[i-1] is 1, except for the lowest bit since in[0] has no right neighbor.

For out_different[3:0], we compare each bit with its left neighbor, where the left neighbor of in[3] is in[0] due to wrap-around.
