For out_both, each bit i (0 to 2) checks if in[i] and in[i+1] are both 1. Since out_both[3] is not needed, the output is 3 bits for indices 0 to 2.
For out_any, each bit i (1 to 3) checks if in[i] or in[i-1] is 1. out_any[0] is not needed, so output is 3 bits for indices 1 to 3.
For out_different, each bit i (0 to 3) checks if in[i] differs from its left neighbor with wrap-around: neighbor of in[0] is in[3].
