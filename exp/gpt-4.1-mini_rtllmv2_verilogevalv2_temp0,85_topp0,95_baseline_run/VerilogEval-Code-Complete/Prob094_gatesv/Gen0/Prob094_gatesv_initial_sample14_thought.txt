For out_both[2:0], each bit checks if both the bit and its neighbor to the left are 1:
- out_both[2] = in[2] & in[3]
- out_both[1] = in[1] & in[2]
- out_both[0] = in[0] & in[1]

For out_any[3:1], each bit checks if either the bit or its neighbor to the right are 1:

- out_any[2] = in[2] | in[1]
- out_any[1] = in[1] | in[0]

For out_different[3:0], each bit compares with the neighbor to the left, wrapping around:

- out_different[2] = in[2] ^ in[3]
- out_different[1] = in[1] ^ in[2]
- out_different[0] = in[0] ^ in[1]
