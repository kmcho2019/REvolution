For out_both[2:0], each bit indicates if both the bit and its left neighbor are 1. Since bit 3 has no left neighbor, out_both is 3 bits wide, indexing bits 2 to 0, where out_both[i] = in[i] & in[i+1].

For out_any[3:1], each bit indicates if either the bit or its right neighbor is 1. Since bit 0 has no right neighbor, out_any is bits 3 to 1, where out_any[i] = in[i] | in[i-1].

For out_different[3:0], wrap-around is considered for left neighbors, so for each bit i, out_different[i] = in[i] ^ in[(i+1)%4].
