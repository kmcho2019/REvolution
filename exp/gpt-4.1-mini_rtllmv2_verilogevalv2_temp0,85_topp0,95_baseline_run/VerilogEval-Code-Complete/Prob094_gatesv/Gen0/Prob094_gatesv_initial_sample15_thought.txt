For out_both[2:0], each bit compares in[i] and in[i+1] and outputs 1 if both are 1. Since in[3] has no left neighbor, out_both[3] is not defined, so out_both is 3 bits.

For out_any[3:1], each bit compares in[i] and in[i-1] and outputs 1 if either is 1. Since in[0] has no right neighbor, out_any[0] is undefined and output is only [3:1].

For out_different[3:0], each bit compares in[i] with its left neighbor, where neighbor of in[3] is in[0] (wrap around). Output 1 if bits differ.

We can implement these combinationally using bitwise operators and indexing.
