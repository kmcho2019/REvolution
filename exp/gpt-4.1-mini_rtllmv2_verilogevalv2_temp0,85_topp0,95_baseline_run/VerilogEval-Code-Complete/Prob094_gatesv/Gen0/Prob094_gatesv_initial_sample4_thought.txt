For out_both[2:0], each bit checks if in[i] and in[i+1] are both 1, ignoring index 3 as it has no left neighbor.
For out_any[3:1], each bit checks if in[i] or in[i-1] are 1, ignoring index 0 as it has no right neighbor.
For out_different[3:0], each bit compares in[i] with its left neighbor, treating in[0]'s left neighbor as in[3] (wrap around).
