We design a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. The output depends solely on the state. On each clock edge, if areset is asserted asynchronously, the FSM resets to WALK_LEFT. Otherwise, if bump_left or bump_right is 1 (or both), the FSM switches directions (toggles state). If no bump, the FSM stays in the current state. Outputs are assigned based on the current state.
