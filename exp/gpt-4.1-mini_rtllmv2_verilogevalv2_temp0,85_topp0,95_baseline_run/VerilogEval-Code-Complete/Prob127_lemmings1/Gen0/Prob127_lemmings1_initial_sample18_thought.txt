Implement a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. The state changes on the rising edge of clk or asynchronously resets on areset. On reset, the state is WALK_LEFT. On each clock cycle, if bump_left or bump_right is 1, switch direction: if walking left, go to walking right; if walking right, go to walking left. The outputs walk_left and walk_right are assigned based on the current state.
