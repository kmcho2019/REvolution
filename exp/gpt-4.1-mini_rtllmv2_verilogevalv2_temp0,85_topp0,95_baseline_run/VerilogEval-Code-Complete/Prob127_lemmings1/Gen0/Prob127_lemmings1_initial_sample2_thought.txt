Implement a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. The FSM starts in WALK_LEFT after asynchronous reset. On each clock edge, if bumped on the left (bump_left=1), transition to WALK_RIGHT; if bumped on the right (bump_right=1), transition to WALK_LEFT. If bumped on both sides, it still switches directions. The output depends only on the current state. Use asynchronous reset to initialize state to WALK_LEFT.
