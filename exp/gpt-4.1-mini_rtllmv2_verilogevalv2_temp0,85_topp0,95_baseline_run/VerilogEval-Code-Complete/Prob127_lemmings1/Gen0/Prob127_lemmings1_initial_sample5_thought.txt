Model the Lemming movement as a two-state Moore FSM: state 0 = walking left, state 1 = walking right. On asynchronous positive edge reset, set state to walking left. On each clock edge, if bump_left or bump_right is asserted (including both simultaneously), toggle the walking direction. Outputs depend solely on the current state: walk_left is high if in state 0, walk_right is high if in state 1.
