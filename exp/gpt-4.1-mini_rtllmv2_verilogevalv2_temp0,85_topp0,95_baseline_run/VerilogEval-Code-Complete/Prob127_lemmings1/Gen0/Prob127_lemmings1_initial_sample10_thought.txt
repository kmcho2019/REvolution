We need a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. The state transitions occur on the clock's rising edge or asynchronously on areset. On reset, the state should be WALK_LEFT. If bumped on the left, the state changes to WALK_RIGHT. If bumped on the right, the state changes to WALK_LEFT. If bumped on both sides, the state also toggles (but the specification says it still switches directions, so same as a single bump). The output depends only on the current state.
