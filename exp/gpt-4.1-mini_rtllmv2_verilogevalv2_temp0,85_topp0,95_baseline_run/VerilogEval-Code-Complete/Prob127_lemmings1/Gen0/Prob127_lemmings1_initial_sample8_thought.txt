Implement a Moore FSM with two states representing the Lemming's direction: WALK_LEFT and WALK_RIGHT.
- On asynchronous positive edge reset (areset), set state to WALK_LEFT.
- On each clock edge, update the state:
  - If bumped on the left or right (bump_left=1 or bump_right=1), switch direction.
  - Else, stay in the current direction.
- Outputs walk_left and walk_right are asserted based on the current state.
