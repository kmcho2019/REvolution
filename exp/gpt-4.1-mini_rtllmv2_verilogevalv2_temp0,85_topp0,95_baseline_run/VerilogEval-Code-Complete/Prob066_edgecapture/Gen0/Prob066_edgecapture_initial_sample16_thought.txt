We want to detect for each bit if it changes from 1 to 0 on a clock edge, and once detected, set the corresponding output bit to 1. The output bit remains set until a synchronous active-high reset is asserted, which clears all bits to 0. We'll store the previous input value in a register to compare on each clock cycle. The detection condition per bit is previous_in_bit == 1 and current_in_bit == 0.
