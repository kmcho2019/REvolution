To detect when each bit in the 32-bit input changes from 1 to 0 on the next clock cycle, we will register the input on each clock cycle and compare the previous value to the current input. For each bit, if the previous value was 1 and the current value is 0, we set the corresponding bit in the output register to 1. This output bit remains set until a synchronous reset is applied, which clears the entire output register.
