To detect a falling edge from 1 to 0 on each bit of the input vector, we need to keep track of the previous state of the input bits. On each clock cycle, we compare the current input to the previous input; if a bit was 1 in the previous cycle and is 0 in the current cycle, we set the corresponding bit in the output register. The output bits remain set until a synchronous reset is asserted, which clears all bits to zero. We'll store the previous input in a register updated every clock cycle.
