The code attempts to do this by using a `prev_in` register to hold the previous cycle's input and performing a bitwise AND between `prev_in` and the bitwise negation of the current `in` (`prev_in & ~in`). This expression correctly identifies bits that changed from 1 to 0. Then it ORs the result with the current `out` value to keep previously latched bits set.

Key code section:
```verilog
      out <= out | (prev_in & ~in);
      prev_in <= in;
```

The synchronous reset resets both `out` and `prev_in` to zero:
```verilog
    if (reset) begin
```
