We need to detect a falling edge on each bit of the input vector, specifically a transition from 1 to 0 between consecutive clock cycles. To do this, we'll store the previous state of the input bits in a register on every clock cycle. Then, we'll compare the previous input and the current input bits: if the previous bit was 1 and the current bit is 0, we set the corresponding bit in the output register to 1. Once set, the output bits remain 1 until the synchronous reset is asserted. The reset will clear the output and previous input registers.
