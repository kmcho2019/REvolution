To detect a falling edge from 1 to 0 on each bit of the 32-bit input, we need to compare the current input with the previous input value stored in a register. For each bit, if the previous value was 1 and the current value is 0, set the corresponding output bit to 1 and latch it until a synchronous reset is asserted. On reset, clear the output. We'll also store the previous input in a register to compare at every clock cycle.
