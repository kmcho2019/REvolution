To detect a 1->0 transition for each bit, we need to compare the current input bit with the previous input bit stored in a register. If a bit was 1 in the previous clock cycle and is 0 in the current cycle, the output bit is set to 1 and remains 1 until a synchronous reset is asserted. On reset, all output bits are cleared to 0. We'll store the previous input in a register to compare on each clock edge.
