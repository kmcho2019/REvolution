Implement a 32-bit shift register updated on the clock's rising edge or asynchronously reset. On asynchronous reset (areset=1), clear the history to zero. On clock edge, if train_mispredicted is 1, load the register with train_history concatenated with train_taken (train_taken as the youngest bit). Else if predict_valid is 1, shift the current history left by one and insert predict_taken at the LSB. If both train_mispredicted and predict_valid are asserted simultaneously, prioritize train_mispredicted as required.
