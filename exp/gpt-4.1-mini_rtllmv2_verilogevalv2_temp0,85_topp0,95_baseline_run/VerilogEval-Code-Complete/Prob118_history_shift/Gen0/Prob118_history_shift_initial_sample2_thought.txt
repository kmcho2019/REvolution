Implement a 32-bit shift register to track branch history, where the LSB (predict_history[0]) is the most recent branch direction. On reset, clear the register. On clock edge, if a misprediction occurs, load the history with train_history concatenated with train_taken at LSB. Else if a prediction is valid, shift in predict_taken at LSB. Otherwise, keep the state unchanged. Misprediction takes precedence over prediction. Use a synchronous process with asynchronous reset.
