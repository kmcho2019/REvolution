Implement a 32-bit shift register to hold the global branch history. On each clock edge, if asynchronous reset is asserted, clear the register to zero. On normal operation: if a misprediction occurs (train_mispredicted=1), load the history with {train_history, train_taken} to rollback the state. Otherwise, if a prediction is valid (predict_valid=1), shift the register left by one bit and insert predict_taken at bit 0 (youngest branch). The misprediction has higher priority over prediction when both occur simultaneously.
