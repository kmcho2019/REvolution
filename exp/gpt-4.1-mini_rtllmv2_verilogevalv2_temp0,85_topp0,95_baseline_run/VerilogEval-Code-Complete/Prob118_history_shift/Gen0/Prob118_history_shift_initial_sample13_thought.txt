Implement a 32-bit shift register with asynchronous reset. On reset, clear history to zero. On each clock edge, if train_mispredicted is high, load the register with {train_history, train_taken} (train_taken as the youngest branch). Else if predict_valid is high, shift in predict_taken at LSB, shifting older history upwards. predict_history is always the current value of the register. Misprediction takes priority over prediction.
