Implement a 32-bit shift register that updates on each clock edge. On reset, clear the history to zero. On a misprediction, load the history with train_history concatenated with train_taken (with train_taken as LSB), effectively rolling back and updating the history. On a prediction (and no misprediction), shift the current history to the left by one and insert predict_taken at the LSB. Misprediction takes priority over prediction if both occur simultaneously. The output predict_history is the current value of the shift register.
