Implement a 32-bit shift register updated on each clock edge. On asynchronous reset, clear the history to zero. On a clock edge, if a misprediction occurs, load the history with train_history concatenated with train_taken (the actual branch result), reflecting the state after the mispredicted branch. Else if a prediction is valid, shift the history left by 1 and insert predict_taken at bit 0 (youngest branch). Output the current history as predict_history. Misprediction takes precedence over prediction.
