Implement a 32-bit shift register that holds branch history with the youngest branch at bit 0. On an asynchronous reset, clear the register. On each clock edge, if a misprediction occurs, load the register with train_history concatenated with train_taken (train_taken as the youngest bit). If no misprediction but a prediction occurs, shift the register right by one and insert predict_taken at bit 0. If neither occurs, hold the current state. Misprediction has priority over prediction.
