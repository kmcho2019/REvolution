Implement a 32-bit shift register that holds branch history with the youngest branch in bit 0. On reset, clear the history. On each clock edge: if train_mispredicted is asserted, load the history with {train_taken, train_history[31:1]} (shift in the actual taken bit and use the older history bits); else if predict_valid is asserted, shift in predict_taken by shifting right and placing predict_taken at bit 0. Misprediction takes priority over prediction when both occur.
