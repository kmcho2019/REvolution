Implement a 32-bit shift register for the branch history that updates on the positive edge of the clock. On asynchronous reset, clear the history to zero. When a misprediction occurs (train_mispredicted = 1), load the history with train_history concatenated with train_taken (train_taken is the youngest branch), overriding any prediction update. When a prediction is valid (predict_valid = 1) and no misprediction, shift in predict_taken at the LSB side, shifting the history left by one bit, so that predict_history[0] is the youngest branch direction. The output predict_history always reflects the current history.
