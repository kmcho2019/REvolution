Implement a 32-bit shift register to hold the global branch history. On asynchronous reset, clear the register to zero. On each clock edge, if a misprediction occurs, load the register with the concatenation of train_history and train_taken (train_taken as LSB). Otherwise, if a prediction is valid, shift the register left by 1 and insert predict_taken at bit 0. The misprediction has priority over prediction if both occur simultaneously. Output the current state as predict_history.
