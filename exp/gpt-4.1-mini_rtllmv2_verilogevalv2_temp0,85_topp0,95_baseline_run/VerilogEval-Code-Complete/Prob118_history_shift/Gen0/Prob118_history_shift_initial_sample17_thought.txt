Implement a 32-bit shift register that holds branch history with the youngest branch direction at bit 0. On positive clock edge, if asynchronous reset is asserted, clear history to zero. If a misprediction occurs (train_mispredicted = 1), load the history with train_history concatenated with train_taken (train_taken as bit 0, train_history shifted left by 1). Else if a prediction is valid (predict_valid = 1), shift the history left by 1 and insert predict_taken at LSB. If neither, keep history unchanged. Misprediction takes precedence over prediction.
