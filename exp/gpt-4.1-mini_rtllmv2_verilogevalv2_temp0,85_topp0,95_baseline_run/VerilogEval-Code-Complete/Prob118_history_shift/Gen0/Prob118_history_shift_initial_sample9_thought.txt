Implement a 32-bit shift register to track branch history. On positive edge of clk or asynchronous reset:
- If reset asserted, clear history to zero.
- Else if train_mispredicted asserted, load history with concatenation of train_history[30:0] and train_taken (since train_history corresponds to history before mispredicted branch, adding actual branch result updates it).
- Else if predict_valid asserted, shift left the history by 1 bit and insert predict_taken at LSB.
- Otherwise, keep history unchanged.

Misprediction update has priority over prediction update. predict_history outputs current history with index 0 as the youngest branch (LSB).
