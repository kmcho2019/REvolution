Implement a 32-bit shift register to hold branch history, updated on clock edges. On asynchronous reset (areset), clear history to zero. On each clock, if a misprediction occurs (train_mispredicted = 1), load the history with train_history concatenated with train_taken (train_taken as LSB). Else if a prediction is valid (predict_valid = 1), shift the current history left by 1 bit and shift in predict_taken at the LSB. Otherwise, hold the current history. The output predict_history reflects the current state of the history register. Misprediction takes precedence over prediction when both occur simultaneously.
