Implement a 32-bit shift register to hold the global branch history. On asynchronous reset, clear the history to zero. On each clock edge, if a misprediction occurs, load the history by concatenating train_history and train_taken to restore the correct state before the mispredicted branch. If no misprediction but a prediction is valid, shift the current history left by 1 bit and insert predict_taken at the least significant bit. Output the current history as predict_history. Give priority to misprediction over prediction as required.
