Implement a 32-bit shift register for branch history with asynchronous reset. On each clock edge, if reset is asserted, clear the history. If a misprediction occurs, load the history with train_history concatenated with train_taken (train_history shifted left by 1 bit plus train_taken as LSB). Otherwise, if a prediction is valid, shift the current history left by 1 bit and insert predict_taken at LSB. predict_history outputs the current history register. The misprediction update has priority over prediction updates.
