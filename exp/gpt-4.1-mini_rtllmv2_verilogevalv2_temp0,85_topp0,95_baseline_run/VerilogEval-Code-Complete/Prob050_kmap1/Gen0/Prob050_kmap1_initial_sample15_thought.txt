The Karnaugh map has inputs a, b, c with the rows representing bc and columns representing a. The output is 0 only when a=0 and bc=00; in all other cases, the output is 1. This means the output is 0 only if (a == 0) and (b == 0) and (c == 0), otherwise 1. Thus, the output can be implemented as the negation of (a' b' c').
