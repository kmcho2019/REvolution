Analyze the Karnaugh map to find the simplified Boolean expression:

Given the K-map (rows bc, columns a):
       a=0  a=1
bc=00 | 0 | 1
bc=01 | 1 | 1
bc=11 | 1 | 1
bc=10 | 1 | 1

From the map:
- When a=0 and bc=00, output=0
- For all other cases, output=1

This means the output is 1 except when a=0, b=0, c=0.

So, the output can be expressed as:
out = a + b + c

Because if any of a, b, or c is 1, output is 1; only when all are 0 (a=0,b=0,c=0), output=0.

Implement the output as out = a | b | c.
