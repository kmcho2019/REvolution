Implement a Moore FSM with 6 states (A-F) encoded as 3-bit values. Use synchronous active-high reset to set state to A. Use one always block for state register (state flip-flops) triggered on posedge clk, and another always block (combinational) for next state logic (state table). The output z is based on the current state: z=1 for states E and F, else 0. Implement output using continuous assignment.
