Implement a Moore FSM with states encoding direction (left or right) and action (walking, falling, digging, splattered). On reset, the Lemming walks left. The FSM priorities are: if ground=0, fall (aaah) regardless of bumps or dig; if ground=1 and dig=1 and currently walking, start digging; if bumped (left or right) and walking, change walking direction; while falling or digging, bumps and dig commands are ignored. Count fall duration in a register; if fall duration > 20 and ground returns, transition to splattered state which disables all outputs until reset. Outputs depend on the current state. Use separate states to encode direction and action. State transitions depend on inputs and current state. Use an asynchronous posedge reset to reset to walk_left state and clear fall count.
