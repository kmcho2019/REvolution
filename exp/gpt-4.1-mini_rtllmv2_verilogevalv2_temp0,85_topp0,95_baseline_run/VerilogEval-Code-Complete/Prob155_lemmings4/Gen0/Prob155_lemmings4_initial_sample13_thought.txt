Design a Moore FSM with states representing walking left, walking right, falling, digging, and splattered. Use outputs determined solely by state. Store walking direction in the state to maintain after falling/digging. Use a counter to track fall duration; if fall time > 20 then upon hitting ground, transition to splattered. Precedence: fall > dig > switch direction. Handle bumps only when walking on ground and not falling/digging. Digging only starts when on ground and walking and dig=1. Falling starts when ground=0 and not already falling or splattered. Once splattered, outputs are all zero forever until reset.

States:
- WALK_LEFT
- WALK_RIGHT
- FALL_LEFT
- FALL_RIGHT
- DIG_LEFT
- DIG_RIGHT
- SPLATTERED

Transitions:
- From WALK_*:
  - if ground=0 => FALL_*
  - else if dig=1 => DIG_*
  - else if bump_left or bump_right => switch walking direction
  - else remain in WALK_*
- From FALL_*:
  - increment fall timer
  - if ground=1
    - if fall timer > 20 => SPLATTERED
    - else WALK_* with same direction
  - else remain in FALL_*
- From DIG_*:
  - if ground=0 => FALL_*
  - else remain in DIG_*
- From SPLATTERED:
  - remain in SPLATTERED until reset

Implement asynchronous reset to WALK_LEFT.

Outputs: only one of walk_left, walk_right, aaah, digging is 1 in each state (except SPLATTERED, all 0).
