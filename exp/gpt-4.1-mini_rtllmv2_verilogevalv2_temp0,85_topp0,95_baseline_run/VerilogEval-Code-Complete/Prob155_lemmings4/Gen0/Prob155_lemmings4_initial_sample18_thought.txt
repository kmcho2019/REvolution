Implement a Moore FSM with states capturing direction and activity: walking left, walking right, falling, digging, and splattered (dead). Use a register to count fall duration. The FSM transitions based on inputs and current state, prioritizing fall > dig > direction switch. Outputs depend solely on state. On reset, set to walking left. When falling ends, check fall count for splatter. Bump inputs only affect walking states, and digging only starts when walking on ground. Once splattered, FSM stays there forever until reset.
