Implement a Moore FSM with states representing walking left, walking right, falling, digging, and splattered. Use separate signals for current direction (left/right) and mode (walking, falling, digging, splattered). On asynchronous reset, start walking left. 

Priority of actions when walking on ground: fall > dig > bump. When falling, count duration; if fall > 20 cycles and ground reappears, splatter. Outputs depend only on states: walk_left/right, aaah (falling), digging. Splattered state disables all outputs.

Use registers for state, fall counter, and direction. Next state logic based on current state and inputs. State encoding can be separate mode and direction for clarity.
