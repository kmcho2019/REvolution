We need to implement a Moore FSM with states reflecting the Lemming's behavior and direction. The Lemming can be walking left, walking right, falling, digging, or splattered. The direction is relevant only when walking or digging, and must be preserved through falling and digging states.

States:
- WALK_LEFT
- WALK_RIGHT
- DIG_LEFT
- DIG_RIGHT
- FALL_LEFT
- FALL_RIGHT
- SPLATTERED (final)

Transitions:
- If splattered, stay splattered.
- If falling and ground = 1:
  - If fall duration > 20 cycles, go to SPLATTERED.
  - Else go back to walking in the same direction.
- If not falling:
  - If ground=0, start falling in the same direction.
  - Else if dig=1 and on ground and currently walking, start digging in current direction.
  - Else if bumped left or right, switch walking direction.
- If digging and ground=0, transition to falling in same direction.

Fall timer increments only when falling.

Outputs depend on states:
- walk_left: walking left or digging left
- walk_right: walking right or digging right
- aaah: falling states
- digging: digging states

On reset, start in WALK_LEFT.

Implement synchronous clocked FSM with asynchronous active-high reset.
