We need a Moore FSM with states representing: walking left, walking right, falling left, falling right, digging left, digging right, and splattered. The walking states respond to bumps (changing direction) and dig commands (start digging if ground=1 and not falling). The falling states start when ground drops to 0, carry the walking direction, and count fall duration. If falling more than 20 cycles when ground returns to 1, transition to splattered. Digging states start when dig=1 on ground and walking, continue digging while ground=1, and fall when ground=0. Bumps and dig commands have no effect while falling or digging. Priority order: falling > digging > switching direction. Outputs depend on state: walking states assert walk_left or walk_right, falling states assert aaah, digging states assert digging, splattered state outputs all 0. On async reset, go to walking left.
