Implement a Moore state machine with two states: A and B. State B outputs 1, and state A outputs 0. On asynchronous reset (areset high), set state to B. On each clock edge, transition between states depending on input as described: from B, input 0 goes to A, input 1 stays in B; from A, input 0 goes to B, input 1 stays in A. Output depends only on the current state.
