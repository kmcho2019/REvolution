Implement a Moore state machine with two states A and B. State B outputs 1, and state A outputs 0. On asynchronous reset high, go to state B. On each clock edge, transition based on the input according to the state diagram:
- From B (output 1): if in=0 go to A, if in=1 stay in B
- From A (output 0): if in=0 go to B, if in=1 stay in A
Output is assigned based on the current state.
