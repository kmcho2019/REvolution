Implement a Moore state machine with two states A and B. State encoding can be 1-bit, for instance, 0 for A and 1 for B. On asynchronous reset (areset high), the machine should go to state B. On clock edge, state transitions occur based on the input 'in' as per the diagram. Output depends only on the current state: output is 1 in state B and 0 in state A.
