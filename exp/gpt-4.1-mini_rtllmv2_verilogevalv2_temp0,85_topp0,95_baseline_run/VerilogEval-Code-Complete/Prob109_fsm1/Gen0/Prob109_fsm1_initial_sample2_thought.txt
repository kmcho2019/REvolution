Implement a Moore machine with two states A and B. State B outputs 1, and state A outputs 0. The state transitions are:
- From B (output 1): input 0 goes to A, input 1 stays in B
- From A (output 0): input 0 goes to B, input 1 stays in A
The machine asynchronously resets to B when areset is high.
Use a register to hold the current state, update on positive clock edge or asynchronously reset, and assign output based on the current state.
