The Moore machine has two states: A and B. 
- State B has output 1; state A has output 0.
- Transitions:
  - From B (output 1): on input 0 go to A, on input 1 stay in B.
  - From A (output 0): on input 0 go to B, on input 1 stay in A.
- Asynchronous reset sets the machine to state B.
I will encode states as a 1-bit register: 0 = A, 1 = B.
The output depends only on the current state.
