Implement a Moore machine with two states A and B. State B outputs 1, and state A outputs 0. The transitions are defined as:
- From B (output 1): if input is 0, go to A; if input is 1, stay in B.
- From A (output 0): if input is 0, go to B; if input is 1, stay in A.
Use asynchronous reset to set the state to B on reset. Output depends only on the current state.
