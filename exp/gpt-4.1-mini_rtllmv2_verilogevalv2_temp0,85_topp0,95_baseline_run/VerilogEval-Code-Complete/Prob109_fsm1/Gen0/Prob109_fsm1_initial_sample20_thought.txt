Implement the Moore machine with two states, A and B. The output depends only on the state: output 0 for A and 1 for B. Use a 1-bit state register with 0 for A and 1 for B. On an asynchronous reset (high), go to state B. On the clock edge, transition according to the input and current state: from B, if input=0 go to A, else stay in B; from A, if input=0 go to B, else stay in A.
