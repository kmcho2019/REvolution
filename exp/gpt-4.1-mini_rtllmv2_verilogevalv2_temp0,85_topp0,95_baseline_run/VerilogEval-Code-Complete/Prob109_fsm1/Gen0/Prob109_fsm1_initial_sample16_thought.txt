Implement a Moore state machine with two states A and B represented by a 1-bit state variable.
State B outputs 1, state A outputs 0.
On asynchronous reset (active high), the machine goes to state B.
On each clock, transition according to input:
From B (1): input=0 -> A(0), input=1 -> B(1)
From A (0): input=0 -> B(1), input=1 -> A(0)
Output is determined solely by the current state.
