Implement the described Moore machine with two states, A and B. Use a 1-bit register to hold the state, encoding B as 1 and A as 0. On an asynchronous reset (areset high), set state to B (1). On each clock edge, update the state based on current state and input according to the given transitions. The output is based solely on the current state: output 1 for state B and 0 for state A.
