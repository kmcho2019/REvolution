Implement a finite state machine with the following states:
- IDLE: searching for the pattern 1101 on the serial data input.
- SHIFT: after detecting the pattern, assert shift_ena for exactly 4 clock cycles to shift in the duration bits.
- COUNT: assert counting and wait for done_counting to go high.
- DONE: assert done and wait for ack to be asserted to return to IDLE.

For pattern detection, keep a 4-bit shift register of recent data bits and detect when it equals 4'b1101.
Use a counter to keep track of the 4 shift cycles in the SHIFT state.

On synchronous reset, return to IDLE and clear outputs.
