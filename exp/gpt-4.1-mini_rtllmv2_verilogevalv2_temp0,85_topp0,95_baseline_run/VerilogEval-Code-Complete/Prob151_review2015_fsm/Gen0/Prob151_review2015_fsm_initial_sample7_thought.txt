Implement a finite state machine with the following states:

- IDLE: Waiting for the start pattern 1101. Use a 4-bit shift register to detect the pattern on each clock cycle.

- SHIFT: After detecting 1101, assert shift_ena for exactly 4 clock cycles to shift in the delay value. Use a 2-bit counter to count these 4 cycles.

- COUNTING: After shifting, assert counting output and wait for done_counting input to become high.

- DONE: When done_counting is high, assert done output and wait for ack input to become high. On ack, return to IDLE state.

All outputs are synchronous with the clock. The FSM resets to IDLE on synchronous active high reset.
