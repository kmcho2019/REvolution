Implement a Moore finite state machine with the following states:
- SEARCH: Look for the pattern 1101 in the serial input data.
- SHIFT: After detecting the pattern, assert shift_ena for exactly 4 cycles to shift in the duration bits.
- COUNT: Assert counting output and wait until done_counting input is high.
- DONE: Assert done output, wait for ack input to be high before returning to SEARCH state.

Pattern detection is done by shifting in bits and checking the last 4 bits against 1101 each clock cycle in SEARCH state.

Synchronous active high reset sets state to SEARCH.

Outputs shift_ena, counting, and done are asserted only in corresponding states.
