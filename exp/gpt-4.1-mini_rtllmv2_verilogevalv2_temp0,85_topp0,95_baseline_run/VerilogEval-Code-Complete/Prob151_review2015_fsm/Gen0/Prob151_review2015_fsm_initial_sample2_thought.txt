Implement a finite state machine with states for searching the 1101 pattern, shifting in 4 bits, counting wait, done notification, and acknowledgment wait. Use a shift register to detect the pattern on the serial data input. On detecting 1101, assert shift_ena for 4 cycles (use a counter), then assert counting until done_counting is high, then assert done until ack is high, then return to searching state. Use synchronous reset to go to initial state.
