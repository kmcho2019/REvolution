We implement a finite state machine with the following states:

- SEARCH: Look for the pattern 1101 in the serial data input. We keep a 4-bit shift register to detect this pattern.
- SHIFT: Once pattern 1101 is detected, assert shift_ena for exactly 4 clock cycles to shift in the duration bits.
- COUNT: Assert counting output, wait until done_counting is high.
- DONE: Assert done output, wait for ack input to be high.
- Then return to SEARCH.

The FSM transitions synchronously on clk and resets synchronously on reset. The 4-bit shift register for pattern detection updates each clock cycle with new data.

Outputs are asserted in corresponding states.
