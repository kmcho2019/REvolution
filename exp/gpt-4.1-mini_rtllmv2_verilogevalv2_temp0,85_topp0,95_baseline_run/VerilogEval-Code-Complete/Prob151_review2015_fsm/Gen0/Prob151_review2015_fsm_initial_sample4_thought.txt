Implement a finite state machine with these states:
- IDLE: looking for the pattern 1101 on serial input 'data'. Use a 4-bit shift register to detect the pattern.
- SHIFT: after detecting 1101, assert shift_ena for exactly 4 cycles to shift in duration bits, counting these cycles.
- COUNT: assert counting and wait for done_counting to go high.
- DONE: assert done to notify the user and wait for ack to be high.
On reset, go back to IDLE. The outputs are asserted in the corresponding states.
