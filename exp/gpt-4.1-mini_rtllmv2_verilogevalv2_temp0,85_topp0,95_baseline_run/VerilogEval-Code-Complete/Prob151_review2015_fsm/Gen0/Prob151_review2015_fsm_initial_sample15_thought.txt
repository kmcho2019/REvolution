Implement a finite state machine with states to:
- Detect the pattern 1101 on the serial input data, using a 4-bit shift register updated every clock.
- When pattern detected, assert shift_ena for exactly 4 clock cycles to shift in the delay bits.
- Then assert counting and wait until done_counting is high.
- Then assert done, and wait until ack is high.
- On ack, return to pattern detection state.
Use synchronous reset to initialize to pattern detection state.
