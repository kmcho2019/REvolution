Design a finite state machine with states to detect the start pattern 1101 by shifting in bits serially. Once detected, assert shift_ena for exactly 4 cycles to shift in the delay bits. Then assert counting and wait for done_counting to go high. After done_counting, assert done and wait for ack to return to the initial state searching for the pattern. The reset initializes the FSM to the pattern searching state. Use a small shift register or counters internally to detect the pattern, but since only the FSM is requested, the pattern detection is done by tracking bits in states or with a shift register variable inside the FSM.
