Implement a finite-state machine with states representing the phases: searching for the pattern 1101, shifting in 4 bits (asserting shift_ena for exactly 4 cycles), then asserting counting until done_counting is asserted, then asserting done until ack is asserted, then returning to the initial state. Use a shift register or equivalent logic to detect the 1101 pattern. The pattern detection shifts in one bit per clock cycle, comparing the last 4 bits. On detecting pattern, move to shift_ena state with a 4-cycle counter. After that, move to counting state waiting for done_counting input. Then move to done state waiting for ack, then back to initial state. All state transitions synchronous and reset synchronous active high.
