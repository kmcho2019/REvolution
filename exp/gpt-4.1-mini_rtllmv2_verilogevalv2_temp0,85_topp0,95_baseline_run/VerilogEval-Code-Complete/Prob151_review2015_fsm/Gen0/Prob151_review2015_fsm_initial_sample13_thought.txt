We design a finite state machine (FSM) with states to detect the 4-bit pattern 1101, then shift in 4 bits with shift_ena asserted for exactly 4 cycles, then assert counting and wait for done_counting input to go high, then assert done and wait for ack input to reset back to pattern detection. The pattern detection can be done by shifting in bits and tracking the last 4 bits or by using states representing partial matches.

For simplicity, use states for pattern detection:
- IDLE: waiting for first bit of pattern (1)
- S1: matched first bit (1)
- S11: matched first two bits (11)
- S110: matched three bits (110)
- S1101_DETECTED: pattern detected, start shift_ena for 4 cycles
- SHIFT_4: assert shift_ena for 4 clock cycles, count shifts with counter
- COUNTING: assert counting and wait for done_counting
- DONE: assert done and wait for ack, then go back to IDLE.

We implement a 4-bit shift counter for shift_ena duration.
Reset is synchronous active high and returns FSM to IDLE.

All outputs are registered and asserted as per state descriptions.
