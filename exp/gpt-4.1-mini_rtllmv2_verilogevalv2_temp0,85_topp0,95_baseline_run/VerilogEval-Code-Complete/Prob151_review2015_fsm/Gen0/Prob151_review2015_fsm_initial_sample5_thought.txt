We will implement a finite state machine (FSM) with the following states:
1. SEARCH: Look for the 4-bit pattern 1101 on the serial data input. We can detect this by shifting the last 4 bits and comparing.
2. SHIFT: Once the pattern is detected, assert shift_ena for exactly 4 clock cycles to shift in the duration bits.
3. COUNT: After shifting duration bits, assert counting and wait until done_counting input is asserted.
4. DONE: Assert done to notify the user and wait for ack input to reset the FSM to SEARCH.

We will use a 4-bit shift register to detect the pattern 1101. The reset is synchronous and active high, so on reset we go back to SEARCH state and clear outputs.

State transitions:
- SEARCH -> SHIFT when pattern detected
- SHIFT -> COUNT after 4 cycles of shift_ena
- COUNT -> DONE when done_counting is asserted
- DONE -> SEARCH when ack is asserted

Outputs are asserted only in their respective states.
