We will implement a finite-state machine with the following states:
- IDLE: searching for the pattern 1101 in the serial input data.
- SHIFT: after detecting 1101, enable shift_ena for exactly 4 clock cycles to shift in the duration bits.
- COUNT: assert counting output and wait for done_counting to go high.
- DONE: assert done output and wait for the user to acknowledge (ack=1).
We will implement a shift register or pattern matching logic to detect 1101 serially. On reset, the FSM goes to IDLE.
