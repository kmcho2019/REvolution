The FSM will have these states: SEARCH (looking for the pattern 1101), SHIFT (shift_ena asserted for 4 cycles), COUNT (counting asserted, waiting for done_counting), DONE (done asserted, waiting for ack). We use a shift register (4 bits) to detect the pattern 1101 on the serial input data. On reset, we go to SEARCH state. In SEARCH, we shift in bits and check if the pattern 1101 is detected; if yes, move to SHIFT. In SHIFT, assert shift_ena for exactly 4 cycles using a counter, then go to COUNT. In COUNT, assert counting and wait for done_counting to be high. Then move to DONE, assert done and wait for ack to return to SEARCH.
