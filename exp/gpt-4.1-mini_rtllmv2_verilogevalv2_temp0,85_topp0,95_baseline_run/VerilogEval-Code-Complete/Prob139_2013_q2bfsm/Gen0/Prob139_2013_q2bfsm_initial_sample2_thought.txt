Design a synchronous FSM with active low synchronous reset that starts in state A. When resetn is deasserted (goes high), on next clock cycle output f=1 for one cycle, then proceed to monitor input x for the sequence 1,0,1 over three consecutive clock cycles. Once sequence detected, output g=1 for one cycle and enter a state monitoring input y for up to two clock cycles. If y=1 occurs within these two cycles, g remains 1 permanently; otherwise, g goes to 0 permanently. Both permanent states hold until next reset. The FSM uses state encoding and counters to track sequence progress and timing of y input, with outputs registered synchronously.
