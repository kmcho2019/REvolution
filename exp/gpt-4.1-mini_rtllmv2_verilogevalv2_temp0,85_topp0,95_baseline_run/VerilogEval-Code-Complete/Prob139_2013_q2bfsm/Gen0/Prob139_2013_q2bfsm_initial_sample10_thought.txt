Implement the FSM with the following states:
- A: initial state on reset, f=0, g=0.
- B: after reset de-asserted, output f=1 for one clock cycle.
- C0, C1, C2: detect the sequence x=1,0,1 in three successive cycles.
- D0, D1, D2: after sequence detected, g=1, monitor y for up to two cycles.
- E: g=1 permanently (y=1 detected within 2 cycles).
- F: g=0 permanently (y not detected in 2 cycles).

Use synchronous active low resetn to initialize FSM to A. Outputs f and g are registered and updated based on states. On resetn low, FSM goes to A with f=0,g=0. Once resetn is high, on next clock cycle go to B to set f=1 for one cycle, then move to C0 to start sequence detection. In C states, track x sequence; if detected, move to D0 to start monitoring y. If y=1 detected within two cycles (D0 or D1), move to E. If not by D2, move to F. E and F are final states until reset.

Encode states using parameters, implement state register and output logic.
