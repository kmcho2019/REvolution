Design a synchronous FSM with states representing the described behavior:

- State A: reset active, FSM stays here, outputs f=0, g=0.
- State B: just after reset is deasserted, output f=1 for one clock cycle.
- States C0, C1, C2: monitor the sequence x=1,0,1 over three clock cycles.
- State D: output g=1 on the cycle after detecting sequence.
- State E0, E1: monitor y input for up to 2 clock cycles to see if y=1.
  - If y=1 within these two cycles, stay in state E1 with g=1 forever.
  - If not, go to state F with g=0 permanently.
- State F: g=0 permanently until reset.

Use a synchronous active-low reset to initialize in state A. Outputs f and g are registered and depend on the current state.

Implement the FSM with one always block for state transitions and one for output logic (Moore machine style).
