Design a synchronous FSM with resetn active low. On reset asserted (resetn=0), stay in state A with outputs f=0, g=0. When resetn deasserted, on next clock edge output f=1 for one cycle, then start monitoring x for the sequence 1,0,1 over consecutive clock cycles. When detected, set g=1 for one cycle and enter state monitoring y for up to two cycles. If y=1 within these two cycles, keep g=1 permanently; otherwise set g=0 permanently. The outputs f and g will be registered signals. Use a state machine to track the phases: IDLE (reset), PULSE_F, MONITOR_X (with subsequence detection), SET_G_HIGH, MONITOR_Y, FINAL_G_HIGH or FINAL_G_LOW. Use counters or flags as needed for timing y monitoring.
