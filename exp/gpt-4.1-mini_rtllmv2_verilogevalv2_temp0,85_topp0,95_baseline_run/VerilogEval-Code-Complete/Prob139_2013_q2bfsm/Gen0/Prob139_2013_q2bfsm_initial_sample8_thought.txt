Design a synchronous FSM with states to represent each phase of the described behavior:
- State A: Initial reset state, outputs f=0, g=0.
- State B: After reset is deasserted, output f=1 for one clock cycle.
- States C0, C1, C2: Monitor the x input to detect the sequence 1,0,1 over successive clock cycles.
- State D0: Set g=1 after detecting x sequence, start monitoring y for up to 2 cycles.
- State D1: If y=1 detected within two cycles, stay in this state with g=1 permanently.
- State D2: If y!=1 after 2 cycles, move to state D3 with g=0 permanently.
- State D3: g=0 permanently until reset.

Outputs f and g are driven based on states:
- f=1 only in State B for one clock cycle.
- g=1 in D0 and D1.
- g=0 otherwise.

Synchronous reset is active low, so when resetn=0, FSM goes to state A.
Use a state machine with encoded states.
