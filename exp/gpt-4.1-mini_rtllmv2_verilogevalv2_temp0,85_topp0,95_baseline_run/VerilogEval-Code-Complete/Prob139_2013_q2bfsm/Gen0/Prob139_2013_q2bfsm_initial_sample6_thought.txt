Design a finite state machine (FSM) with the following states:
- A: Initial state after reset; outputs f=0, g=0. When resetn is de-asserted, move to B.
- B: Output f=1 for one clock cycle, then move to C.
- C: Monitor x input for sequence 1,0,1 over three clock cycles. Use internal counters or states to track this sequence. Once the sequence is detected, move to D and set g=1.
- D: Maintain g=1 and monitor y for up to two clock cycles. If y=1 within these two cycles, stay in D (g=1 permanently). If not, move to E.
- E: g=0 permanently until reset.

Implement synchronous reset (active low). Outputs f and g are driven by FSM states. Use enumerated states and a counter or shift register to detect sequence in state C and a counter for monitoring y in state D.
