Design a synchronous FSM with a synchronous active-low reset. The FSM has several states:
- A: initial state, where reset is asserted, outputs f=0, g=0.
- B: after reset de-asserted, output f=1 for one cycle, then move to C.
- C: monitor x for the sequence 1,0,1 over three consecutive clocks.
- D: after detecting 1,0,1 on x, set g=1 and start monitoring y for up to 2 clocks.
- E: if y=1 within 2 clocks, stay in E with g=1 permanently.
- F: if y!=1 after 2 clocks, go to F with g=0 permanently.

Use a state register and counters as needed. Outputs f and g are registered and updated synchronously. Implement the logic for sequence detection and timing of y.

States encoding can be done with an enum or parameter.

Ensure resetn is synchronous active low: at clk posedge, if resetn=0, go to A.

Outputs f and g are 1-bit reg.

Implement the sequence detection for x by shifting x values and checking the pattern.

The y monitoring after g=1 is done with a 2-cycle timeout: if y=1 before timeout, remain g=1, else g=0 permanently.
