Implement a finite state machine with several states to track the sequence and conditions:

- State A: Initial state, where FSM stays while resetn is low. On resetn de-asserted (high), next clock edge moves to State B.
- State B: Output f=1 for one clock cycle, then transition to State C.
- State C: Monitor input x for the sequence 1,0,1 over three consecutive clock cycles.
  - Use internal counters or flags to track the sequence.
  - If sequence detected, move to State D; else stay in C.
- State D: Set g=1, monitor y for at most two clock cycles.
  - If y=1 within 2 clocks, move to State E (permanent g=1).
  - Else after 2 clocks without y=1, move to State F (permanent g=0).
- State E: Permanent g=1 until reset.
- State F: Permanent g=0 until reset.

Outputs f and g are synchronous to clk.

Use synchronous reset (active low resetn). Use a state register and next_state logic.
