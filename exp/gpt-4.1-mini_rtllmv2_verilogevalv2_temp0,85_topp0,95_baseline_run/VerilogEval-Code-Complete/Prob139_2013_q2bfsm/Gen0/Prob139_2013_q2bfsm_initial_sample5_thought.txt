The FSM has multiple states:
- State A: reset state, where outputs are f=0, g=0. On reset de-assertion, move to state B.
- State B: set output f=1 for one clock cycle, then move to state C.
- State C: monitor x for the pattern 1,0,1 over three successive clock cycles. We can implement a small sequence detector FSM here.
- State D: once pattern 1,0,1 detected, set g=1 and monitor y for two cycles.
- State E: if y=1 within two cycles, maintain g=1 permanently (state F).
- State F: permanent g=1 state until reset.
- State G: if y not 1 within two cycles, set g=0 permanently until reset.

The synchronous reset is active low. When resetn=0, FSM goes to A.

We will use a state encoding for all states. Outputs f and g are registered outputs.

The key parts:
- In state B: f=1 for one cycle.
- In state C: detect x pattern 1,0,1.
- In state D: g=1, wait for y=1 within two cycles, otherwise g=0 permanently.

We keep all logic synchronous to clk and use synchronous resetn.
