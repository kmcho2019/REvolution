I will implement a synchronous FSM with an active-low reset that starts in state A. When resetn is de-asserted, on the next clock cycle f will be set to 1 for one cycle. Then the FSM monitors the x input looking for the sequence 1,0,1 over three consecutive clock cycles. Once this sequence is detected, g will be set to 1 on the following clock cycle and the FSM will monitor y input for up to two clock cycles. If y equals 1 within those two cycles, g remains 1 permanently until reset. If not, g will be set to 0 permanently until reset. The FSM will be implemented using explicit states to track these conditions and counters where necessary.
