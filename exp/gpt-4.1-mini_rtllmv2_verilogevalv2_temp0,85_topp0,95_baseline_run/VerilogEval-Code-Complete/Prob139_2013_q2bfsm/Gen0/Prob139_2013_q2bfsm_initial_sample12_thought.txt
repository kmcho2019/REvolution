We will design a synchronous FSM with states representing the described behavior. Initially, when resetn is low, the FSM stays in state A with outputs f=0, g=0. When resetn goes high, on the next clock edge, output f=1 for one cycle (state B). Then the FSM moves to state C, where it monitors x for the 1,0,1 sequence over three cycles using internal counters or a small state machine to detect the sequence. Once the sequence is detected, move to state D where g=1 is asserted. In state D, start monitoring y for up to 2 clock cycles. If y=1 is detected within these two cycles, stay in state D with g=1 permanently. If y is not 1 in 2 cycles, move to state E where g=0 permanently. In states D and E, maintain outputs until reset is asserted. Outputs f and g are registered outputs. Implement a synchronous reset (active low). The FSM states are encoded using enumerated parameters for clarity.
