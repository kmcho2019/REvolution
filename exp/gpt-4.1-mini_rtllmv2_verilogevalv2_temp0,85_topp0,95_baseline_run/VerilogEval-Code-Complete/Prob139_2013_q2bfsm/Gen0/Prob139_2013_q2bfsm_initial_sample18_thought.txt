Implement an FSM with multiple states to track the described behavior:

- State A: reset state, output f=0, g=0, stay here while resetn=0.
- After resetn=1, next clock edge move to State B, output f=1 for one clock cycle.
- Then move to State C, monitor x input to detect the pattern 1,0,1 in three consecutive clocks.
- When pattern detected, move to State D, output g=1, then monitor y input.
- In State D, if y=1 within two clock cycles, stay in State D with g=1 permanently.
- If y not = 1 within two clock cycles, move to State E, g=0 permanently.
- Both States D and E last until reset.

Use registers for current state and outputs. The synchronous reset (active low) resets FSM to State A with f=0, g=0. Outputs f and g are combinational from the state. Use a counter to track how many clock cycles have passed since pattern detected for y monitoring.

The FSM states:
- A: reset state
- B: output f=1 for one clock cycle after reset
- C: wait for x pattern 1,0,1
- D: g=1, monitor y for max 2 cycles, if y=1 maintain g=1 else move to E
- E: g=0 permanently

Pattern detection will be done using a small shift register or state sequence in C.

The FSM uses non-blocking assignments for synchronous state updates.
