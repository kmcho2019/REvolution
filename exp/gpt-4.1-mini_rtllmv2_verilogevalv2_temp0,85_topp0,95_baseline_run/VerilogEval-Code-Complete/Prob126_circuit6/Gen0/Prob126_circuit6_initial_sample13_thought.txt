The output q is a 16-bit value that depends only on the 3-bit input a. From the waveform, we see that q repeats the same values for the same input a, indicating q is a combinational function of a. The values are unique for each input a, so this is effectively a ROM lookup table from a to q. We can implement this with a case statement inside an always_comb block, mapping each input value to the corresponding output value observed in the waveform.
