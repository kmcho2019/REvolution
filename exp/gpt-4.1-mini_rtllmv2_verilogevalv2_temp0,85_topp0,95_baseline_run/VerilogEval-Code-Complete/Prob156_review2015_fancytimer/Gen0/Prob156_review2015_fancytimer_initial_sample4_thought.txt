Implement a synchronous FSM with the following states: SEARCH (looking for pattern 1101), SHIFT_DELAY (shift in 4 bits for delay), COUNTING (count down the timer in 1000 cycle blocks), and DONE (assert done and wait for ack). Use a 4-bit shift register to detect the pattern 1101 during SEARCH. Once detected, shift in 4 bits (MSB first) to get delay. Then count (delay+1)*1000 cycles with a 10-bit counter for 1000 cycles per count decrement. Output count equals current delay count during counting. When counting finishes, assert done and wait for ack to return to SEARCH. Reset is synchronous active high and returns to SEARCH state.
