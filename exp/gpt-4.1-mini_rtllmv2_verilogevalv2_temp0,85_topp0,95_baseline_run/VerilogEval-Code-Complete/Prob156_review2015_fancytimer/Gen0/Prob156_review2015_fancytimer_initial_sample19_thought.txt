Implement a finite state machine (FSM) with these states: SEARCH for the pattern 1101, READ_DELAY to shift in 4 bits MSB first as delay, COUNT to count down (delay+1)*1000 cycles, DONE to assert done and wait for ack before restarting. Use a 4-bit shift register and a bit counter to detect the start pattern and read delay bits. Use a 10-bit clock cycle counter to count 1000 cycles per delay decrement, and a 4-bit delay counter counting down from delay to 0 with 1000 cycles each. During counting, output current delay value on count and assert counting. When done, assert done and wait for ack to restart.
