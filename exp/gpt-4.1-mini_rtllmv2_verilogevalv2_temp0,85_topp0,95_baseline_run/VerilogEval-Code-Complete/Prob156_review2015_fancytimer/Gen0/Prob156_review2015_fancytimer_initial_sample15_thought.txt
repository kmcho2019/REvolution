We design a finite state machine with these main states:

1. SEARCH: Continuously shift in serial bits to detect the pattern 1101.
2. LOAD_DELAY: Shift in the next 4 bits to form delay[3:0].
3. COUNT: Count (delay+1)*1000 cycles. Use a cycle counter (up to 1000 cycles) and a nibble counter (to track delay down to 0). Output count = current remaining time (starting at delay, decrement every 1000 cycles).
4. DONE: Signal done=1, wait for ack=1 before restarting.

We use a 4-bit shift register to detect the start pattern (1101). After detection, we load delay by shifting in 4 bits MSB first. For counting, we use two counters: a 10-bit cycle counter (counts to 1000) and a 4-bit delay counter starting from delay and counting down to 0. When both are done, we assert done and wait for ack.

All state changes and counters update on the rising edge of clk and synchronous reset.

Outputs:
- count[3:0]: shows remaining delay value during counting; don't care otherwise.
- counting: asserted during counting state.
- done: asserted in DONE state waiting for ack.

This ensures all requirements are met.
