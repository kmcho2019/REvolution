Implement a finite state machine with these states: SEARCH (look for pattern 1101), LOAD_DELAY (shift in 4 bits for delay), COUNT (count down cycles according to delay), DONE (assert done and wait for ack). Use a shift register to detect the 1101 pattern. After detection, shift in delay bits (MSB first). Then count (delay+1)*1000 cycles using a 10-bit cycle counter and a 4-bit delay counter representing remaining counts. Output the current remaining delay count on count[3:0]. When count reaches zero and cycle counter completes 1000, move to DONE state, assert done, wait for ack=1 to reset to SEARCH. Reset synchronously. When not counting, count output is don't care (e.g., zero). counting is asserted only during COUNT state.
