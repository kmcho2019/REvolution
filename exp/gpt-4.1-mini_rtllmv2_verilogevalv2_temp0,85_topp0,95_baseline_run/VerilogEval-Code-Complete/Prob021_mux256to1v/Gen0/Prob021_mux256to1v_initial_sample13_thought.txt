To create a 256-to-1 multiplexer selecting 4-bit chunks from a 1024-bit input vector, we extract the 4 bits corresponding to the selected index. Since sel ranges from 0 to 255, and each selection corresponds to 4 bits, the starting bit index is sel * 4. We can use a variable part-select with the slice in[sel*4 +: 4] to select the appropriate 4 bits.
