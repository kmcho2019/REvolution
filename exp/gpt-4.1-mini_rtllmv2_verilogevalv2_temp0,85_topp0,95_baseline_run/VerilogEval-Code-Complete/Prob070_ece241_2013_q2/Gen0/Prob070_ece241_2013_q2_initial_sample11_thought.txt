First, we list the input combinations for which the output is 1: decimal 2, 7, and 15.

- Decimal 2 = 0010 (a=0,b=0,c=1,d=0)
- Decimal 7 = 0111 (a=0,b=1,c=1,d=1)
- Decimal 15=1111 (a=1,b=1,c=1,d=1)

Output is 0 for the given other numbers, and some inputs are never used.

We derive the SOP by forming minterms for these three inputs and then minimizing the logic.

Minterms:
m2: a'b'c d'
m7: a' b c d
m15: a b c d

We combine terms to minimize SOP:

- m7 and m15 differ only in a (0 and 1), so combine: b c d
- So SOP is: b c d + a' b' c d'

Check if a' b' c d' (m2) can combine with b c d:
No, because b c d requires b=1, but m2 has b=0. So keep m2 separate.

So minimum SOP: out_sop = b c d + a' b' c d'

For POS, output is 0 for 0,1,4,5,6,9,10,13,14.

Convert these decimal numbers into binary and form maxterms:

List of zeros:

0: 0000
1: 0001
4: 0100

Each maxterm is (input variables or their complements) that are 0 in the minterm.

From these zeros, find minimal POS.

Express POS as product of sums for these zeros.

The minimal POS can be obtained from the Karnaugh map or Boolean algebra:

Let's identify the maxterms:

Minterm 0 (0000): (a + b + c + d)
Minterm 1 (0001): (a + b + c + d')
Minterm 4 (0100): (a + b' + c + d)
Minterm 5 (0101): (a + b' + c + d')
Minterm 6 (0110): (a + b' + c' + d)
Minterm 9 (1001): (a' + b + c + d')
Minterm 10(1010): (a' + b + c' + d)
Minterm 13(1101): (a' + b' + c + d')
Minterm 14(1110): (a' + b' + c' + d)

From these, minimal POS can be simplified (using Karnaugh map or Boolean algebra) to:

out_pos = (a + b + d) (a + b' + c') (a' + c + d)

Thus, we provide both outputs as required.
