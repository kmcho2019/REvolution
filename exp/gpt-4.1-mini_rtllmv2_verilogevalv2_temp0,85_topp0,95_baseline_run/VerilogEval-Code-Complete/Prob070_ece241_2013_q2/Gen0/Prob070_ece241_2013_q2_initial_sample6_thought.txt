The inputs a,b,c,d form a 4-bit number with a as the MSB and d as the LSB. 
The output is 1 for numbers 2, 7, and 15 and 0 for 0, 1, 4, 5, 6, 9, 10, 13, 14.
Numbers 3, 8, 11, 12 never occur, so we can treat them as don't cares.

First, write the minterms for output=1: 2(0010), 7(0111), 15(1111).
Write maxterms for output=0: 0,1,4,5,6,9,10,13,14.

Use Karnaugh map to find minimum SOP and POS expressions.

Mapping input bits: a b c d (a=MSB, d=LSB)

Minterms for 1:
- 2: 0010 (a=0,b=0,c=1,d=0)
- 7: 0111 (a=0,b=1,c=1,d=1)
- 15:1111 (a=1,b=1,c=1,d=1)

Don't cares: 3,8,11,12

From K-map simplification:

SOP minimal expression: out_sop = (~a & ~b & c & ~d) + (~a & b & c & d) + (a & b & c & d)

POS minimal expression: 
- Identify maxterms for 0 outputs and combine with don't cares to minimize
- The minimal POS: out_pos = (a + b + ~c + d) & (~a + b + c + d) & (a + ~b + c + d)

Implement both expressions in the Verilog module.
