First, list the minterms for which the output is 1: inputs 2, 7, and 15.

Convert decimal to binary for these numbers:
2  = 0010 (a=0,b=0,c=1,d=0)
7  = 0111 (a=0,b=1,c=1,d=1)
15 = 1111 (a=1,b=1,c=1,d=1)

Use these minterms to get the minimal sum-of-products (SOP) expression.
Then, determine the maxterms for which the output is 0: 0,1,4,5,6,9,10,13,14.
Convert these to binary and use them to find the minimal product-of-sums (POS) expression.

Finally, implement both expressions in Verilog for outputs out_sop and out_pos.
