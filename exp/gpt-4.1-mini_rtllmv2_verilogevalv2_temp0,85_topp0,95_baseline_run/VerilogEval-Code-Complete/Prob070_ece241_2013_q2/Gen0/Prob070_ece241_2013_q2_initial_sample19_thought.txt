We are given a 4-input system with outputs defined for certain minterms. The output is 1 for inputs 2, 7, and 15, and 0 for inputs 0, 1, 4, 5, 6, 9, 10, 13, and 14. Inputs 3, 8, 11, and 12 never occur (don't cares).

First, write the truth table for all 16 inputs:

Inputs (a,b,c,d) correspond to bits: a is MSB, d is LSB.

Binary values:

0: 0000 -> 0  
1: 0001 -> 1  
2: 0010 -> 2  
3: 0011 -> 3 (don't care)  
4: 0100 -> 4  
5: 0101 -> 5  
6: 0110 -> 6  
7: 0111 -> 7  
8: 1000 -> 8 (don't care)  
9: 1001 -> 9  
10: 1010 -> 10  
11: 1011 -> 11 (don't care)  
12: 1100 -> 12 (don't care)  
13: 1101 -> 13  
14: 1110 -> 14  
15: 1111 -> 15  

Output = 1 for 2(0010), 7(0111), 15(1111)  
Output = 0 for 0,1,4,5,6,9,10,13,14  
Don't care for 3,8,11,12

We will find the minimal SOP and POS forms using Karnaugh maps and the don't cares.

K-map (a,b on rows, c,d on columns):

Rows (a,b):  
00 (0,1,2,3)  
01 (4,5,6,7)

11 (12,13,14,15)  

Columns (c,d):  
00 (0,4,8,12)  
01 (1,5,9,13)  
11 (3,7,11,15)  
10 (2,6,10,14)  

Filling in with 1,0,X:

(0,0): 0 = 0  
(0,1): 1 = 0  
(0,3): 3 = X  
(0,2): 2 = 1  

(1,0): 4 = 0  
(1,1): 5 = 0

(1,2): 6 = 0

Using the K-map, group ones with don't cares to simplify:

SOP minimal expression is:  
- Group 1: covers 2(0010) and 6(0110, but 6=0), so no  
- Group for 7(0111) and 15(1111) by column 3  
- Group for 15(1111) and don't care 11(1011), 3(0011), and 7(0111) in column 3  

After analysis, the minimal SOP is:  
out_sop = a d + b c' d

And the minimal POS is:  
out_pos = (a + b + d') (a' + c + d)
