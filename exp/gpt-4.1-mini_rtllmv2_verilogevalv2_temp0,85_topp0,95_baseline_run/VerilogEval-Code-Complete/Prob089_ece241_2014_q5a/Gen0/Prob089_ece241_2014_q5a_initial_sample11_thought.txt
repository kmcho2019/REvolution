The 2's complement operation can be performed by scanning the bits from least-significant to most-significant bit, outputting the same bits until the first '1' bit is found, then outputting the inverted bits thereafter. We can model this as a Moore state machine with two states:

- S0: Before the first '1' bit is detected, output = input bit (x)
- S1: After the first '1' bit detected, output = inverted input bit (~x)

On reset (active high asynchronous), the FSM goes to S0. When reset is released, the FSM processes the input bit-by-bit on every rising clock edge producing output z accordingly.

Because it's a Moore machine, the output depends only on state. However, since output depends on current input in S0 and S1 states, we can implement output as a registered output synchronized to the clock, reflecting the output logic of the current state and input.

Implementation details:
- Use an asynchronous active-high reset to reset to S0.
- On each clock rising edge, update the state based on input x.
- Output z depends on state and input x.
