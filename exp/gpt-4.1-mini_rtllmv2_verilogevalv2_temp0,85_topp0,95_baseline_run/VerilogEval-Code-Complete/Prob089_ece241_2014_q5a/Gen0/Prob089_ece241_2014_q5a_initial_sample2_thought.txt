We need a Moore machine that takes a serial input bit stream representing a number (LSB first) and outputs its 2's complement, bit by bit. The 2's complement is obtained by:
- Copying all the least significant zeros and the first '1' bit as is.
- Then complementing all the remaining bits.

This can be achieved with a two-state Moore machine:
- State S0: Output equals input bit (copying bits until the first '1' is found). Transition to S1 when the input bit is '1'.
- State S1: Output equals inverted input bit (complement the remaining bits).

When reset is asserted, the machine returns to state S0 and stops processing until reset is de-asserted.

Since it is a Moore machine, outputs depend only on state (not on input), so the output Z must be registered and depend on current state. However, since output depends on input and state, we handle output logic accordingly.

Because output depends both on input and state in this case, we can register output on the clock edge after state transition to keep it Moore. The output logic can be assigned based on the current state.

We implement asynchronous active high reset.

Steps:
- On reset, state <= S0, output <= 0
- On posedge clk, if not reset:
    - Update state
    - Update output according to state and input

This satisfies the Moore FSM structure and the required functionality.
