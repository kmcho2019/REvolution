To design a Moore FSM that takes a serial input bit stream (LSB first) and outputs the 2's complement bit stream (LSB first), we need to remember how 2's complement works:

- Starting from LSB, the output bits are the same as input bits until the first '1' is encountered.
- After the first '1', output bits are the bitwise inverse of input bits.

Hence, the FSM has two states:

1. WAIT_FOR_FIRST_ONE: output input bits as-is until the first '1' is seen; when '1' is seen, output '1' and transition to INVERT state.
2. INVERT: output inverted bits of input continuously.

This FSM is Moore, so outputs depend only on the state, not input, but we can manage output by storing output bits in the state transition.

Because output depends on input and current state, but Moore output only depends on state, we can store output in state register along with current state or implement output logic as combinational from state and input.

However, since Moore output depends only on state, and output depends on input in each state, we can encode the output as follows:

- In WAIT_FOR_FIRST_ONE state: output = input
- In INVERT state: output = ~input

We can do this by making output a combinational function of state and input.

Implementation details:

- Use a register to hold current state.
- On reset (active high), set state to WAIT_FOR_FIRST_ONE.
- On each clock edge, update the state depending on input and current state.
- Output is combinational: output = (state == WAIT_FOR_FIRST_ONE) ? input : ~input.

This design accepts an arbitrary length input stream starting LSB first, outputs the 2's complement bits serially.

The asynchronous reset is active high; when asserted, the FSM resets to WAIT_FOR_FIRST_ONE and stops operation.
