To implement a one-input one-output serial 2's complementer as a Moore state machine, we need to process bits one at a time starting from the LSB. The 2's complement process involves copying bits up to (and including) the first '1' bit from the LSB side, then inverting the rest of the bits after that first '1'.

In terms of states, we can design two states:

- S0: "Copy" state where the output z equals the input x (copy bits as they are) until the first '1' is seen.
- S1: "Invert" state where the output z equals inverted x (1's complement of the remaining bits).

Initially, on reset, the state is S0. When reset is released, the machine starts processing input bits serially, outputting 2's complement bits serially. When reset is asserted again, the machine stops and resets to S0.

Output depends only on the current state and input (Moore machine), so output logic is combinational based on state and input.

The main points:

- On reset (areset asserted), state <= S0.
- On each clock edge, if not reset, transition from S0 to S1 when input x is 1 (first 1 encountered).
- Output z = x in S0, output z = ~x in S1.

This design works for arbitrary length input numbers since it processes bits serially with no fixed size.
