To design a Moore state machine for 2's complementing a serial input number starting from the LSB:

1. The 2's complement can be obtained by:
   - Copying bits up to and including the first '1' bit (from LSB side).
   - Then complementing all subsequent bits.

2. This leads to two states:
   - STATE_COPY: output z = x; transition to STATE_COMPLEMENT when x == 1.
   - STATE_COMPLEMENT: output z = ~x; remain in STATE_COMPLEMENT.

3. On asynchronous reset (active high), state returns to STATE_COPY.

4. Output z depends on the state (Moore machine), not on input directly.

5. The machine processes one bit per clock cycle.

We'll implement the FSM with two states, an asynchronous reset, and the output logic accordingly.
