To design a serial 2's complementer as a Moore state machine, we recall that 2's complement is formed by copying bits from the right until the first '1' is encountered, then flipping all the remaining higher bits. Since input bits come LSB first, the machine must:

- Initially, just output the input bits as they are, waiting for the first '1'.
- After the first '1' is encountered, output the inverted bits of the remaining input bits.

This suggests two states:

1. WAIT_ONE: Before the first '1' has been seen, output z = x.
2. FLIP_BITS: After the first '1' is seen, output z = ~x.

On reset, we start in WAIT_ONE. On each clock cycle:

- If in WAIT_ONE and x == 1, move to FLIP_BITS.
- Else stay in WAIT_ONE.
- If in FLIP_BITS, stay in FLIP_BITS.

Output z depends on current state and input x.

The asynchronous reset forces the state to WAIT_ONE.
