The 2's complement of a binary number can be computed by inverting all bits after the first '1' bit from the least significant side and leaving the first '1' bit as is. Since input bits are given starting from LSB, the FSM should wait for the first '1' bit, output it as is, then invert all subsequent bits. This is perfect for a Moore state machine with two states: 
- S0: Waiting for the first '1' bit; output Z = x.
- S1: After first '1' found; output Z = ~x.

Reset asynchronously resets the FSM to S0.

This module will read input bits serially and output the 2's complement bit serially as well.
