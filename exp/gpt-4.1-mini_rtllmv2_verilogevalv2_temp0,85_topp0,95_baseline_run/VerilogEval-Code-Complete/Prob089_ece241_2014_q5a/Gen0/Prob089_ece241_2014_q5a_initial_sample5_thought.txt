To design a one-input one-output serial 2's complementer using a Moore FSM, we process input bits (x) starting from the least significant bit (LSB). The 2's complement operation can be done by copying all bits up to and including the first '1' bit, then inverting all subsequent bits.

Thus, the FSM has two states:
- S0 (Copy): output z = x, stay in S0 until x=1 is found.
- S1 (Invert): output z = ~x, stay in S1 for the rest of the bits.

On reset (active asynchronous low), we go to S0 and start fresh.

Because it's Moore, output depends only on state (and input if output logic combines it).

We will implement a positive edge triggered flip-flop with asynchronous active high reset (areset).

State encoding:
- S0 = 0
- S1 = 1

Output logic:
- In S0: z = x
- In S1: z = ~x

On each clock cycle:
- If in S0 and x=0: stay in S0
- If in S0 and x=1: go to S1
- If in S1: stay in S1

We will implement this in a sequential always block with asynchronous reset.

This FSM accepts bits serially and outputs corresponding bits of the 2's complement number.

The output z is registered (Moore output).

The machine stops processing (reset to S0) when areset is asserted.
