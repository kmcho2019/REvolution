To design a one-input one-output serial 2's complementer as a Moore state machine, the key idea is to detect the least significant '1' bit in the serial input stream and then invert all subsequent bits. The machine will have two states:

1. WAITING: Before the first '1' bit is seen in the input. Output z = x (no inversion).
2. INVERTING: After the first '1' bit is detected, invert subsequent bits.

When reset is asserted asynchronously, the state goes to WAITING. On the positive edge of the clock, if the input bit x is '1' and we are in WAITING, we output '1' and move to INVERTING. After that, each bit is inverted and output.

The output z depends only on the current state and input x, hence it is a Moore machine (output depends only on state).

The implementation uses asynchronous reset, positive edge-triggered clock, and two states encoded as one bit.
