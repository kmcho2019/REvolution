Design a Moore FSM with three states: WALK_LEFT, WALK_RIGHT, and FALLING. On reset, start in WALK_LEFT. When ground=0, transition to FALLING state and set aaah=1. When ground=1 again, return to the previous walking state. While in WALK_LEFT or WALK_RIGHT, if bumped on either side, switch direction. While falling, ignore bumps. The outputs depend only on the current state: walk_left=1 in WALK_LEFT, walk_right=1 in WALK_RIGHT, aaah=1 in FALLING.
