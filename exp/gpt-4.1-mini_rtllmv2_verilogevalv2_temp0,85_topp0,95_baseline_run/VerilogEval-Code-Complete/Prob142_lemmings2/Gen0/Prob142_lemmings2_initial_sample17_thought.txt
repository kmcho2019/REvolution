Design a Moore FSM with three states: WALK_LEFT, WALK_RIGHT, FALLING. 
When on ground (ground=1), the Lemming walks left or right. If bumped on any side, it switches direction. 
When ground=0, it transitions to FALLING and asserts aaah. 
While falling, bump inputs are ignored and direction is remembered. 
When ground returns to 1, return to previous walking direction state without changing direction. 
Asynchronous positive edge reset sets state to WALK_LEFT.
Outputs are determined solely by current state.
