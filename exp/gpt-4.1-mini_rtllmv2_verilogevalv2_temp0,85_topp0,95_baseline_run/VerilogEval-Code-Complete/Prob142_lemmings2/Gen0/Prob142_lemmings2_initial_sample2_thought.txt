Model the Lemming's behavior as a Moore FSM with three states:
- WALK_LEFT: walking left on ground
- WALK_RIGHT: walking right on ground
- FALLING: falling (aaah), remembers previous walking direction

On reset, start in WALK_LEFT.

Transitions:
- From WALK_LEFT or WALK_RIGHT (i.e., on ground):
  - If ground drops to 0, go to FALLING, remembering the current walking direction.
  - Else if bumped on left or right, switch direction accordingly.
- From FALLING:
  - Stay in FALLING while ground=0.
  - When ground returns to 1, go back to the remembered walking direction state.
  - Bumps during FALLING have no effect.

Outputs depend only on state (Moore):
- WALK_LEFT: walk_left=1, walk_right=0, aaah=0
- WALK_RIGHT: walk_left=0, walk_right=1, aaah=0
- FALLING: walk_left and walk_right same as remembered direction, aaah=1

Implement with an asynchronous positive edge reset.
