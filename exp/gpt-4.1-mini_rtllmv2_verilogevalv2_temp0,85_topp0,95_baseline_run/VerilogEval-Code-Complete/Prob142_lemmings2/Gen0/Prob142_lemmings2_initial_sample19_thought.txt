Design a Moore FSM with three states: WALK_LEFT, WALK_RIGHT, and FALLING.
- On reset, state is WALK_LEFT.
- In WALK_LEFT or WALK_RIGHT:
  - If ground=0, transition to FALLING (retain previous direction in a register).
  - If bumped (bump_left or bump_right or both) and ground=1, switch walking direction.
- In FALLING:
  - Ignore bumps.
  - If ground=1, return to the previous walking direction state.
Outputs are derived solely from the current state:
- WALK_LEFT: walk_left=1, walk_right=0, aaah=0
- WALK_RIGHT: walk_left=0, walk_right=1, aaah=0
- FALLING: walk_left and walk_right same as prior walking direction, aaah=1
Store previous direction in a register to restore after falling.
