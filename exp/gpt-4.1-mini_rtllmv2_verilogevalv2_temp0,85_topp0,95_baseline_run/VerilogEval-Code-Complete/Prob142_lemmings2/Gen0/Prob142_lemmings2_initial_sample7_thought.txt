Model the Lemming behavior as a Moore FSM with three states: WALK_LEFT, WALK_RIGHT, and FALLING. The state represents the Lemming's current action. When ground=0, transition to FALLING state and output aaah=1. When ground=1 while falling, return to the previous walking state (WALK_LEFT or WALK_RIGHT) stored in a direction register. Bumps only affect direction if the Lemming is walking (not falling). When bumped on either side (or both), switch walking direction accordingly. Use asynchronous positive edge areset to reset to WALK_LEFT state. Output signals depend solely on the current state.
