Model the Lemming behavior with a Moore FSM having three states: WALK_LEFT, WALK_RIGHT, and FALLING. 

- WALK_LEFT and WALK_RIGHT represent walking directions. 
- On bump_left or bump_right in these states, switch directions.
- If ground drops to 0 while walking, transition to FALLING.
- In FALLING, ignore bumps and output aaah=1.
- When ground returns to 1 while falling, return to the prior walking state.
- Reset asynchronously to WALK_LEFT.

Outputs are derived solely from the current state to ensure Moore behavior.
