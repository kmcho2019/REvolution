First, rewrite the Karnaugh map with the coordinates and values clearly labeled. The rows correspond to cd (00, 01, 11, 10) and columns to ab (01, 00, 10, 11). The K-map values are:

       ab
   cd 01 00 10 11
   00 d  0  1  1
   01 0  0  d  d
   11 0  1  1  1
   10 0  1  1  1

We can assign variables in the order a, b, c, d as inputs, and map accordingly. We need to find minimal logic expression using the ones and don't cares.
