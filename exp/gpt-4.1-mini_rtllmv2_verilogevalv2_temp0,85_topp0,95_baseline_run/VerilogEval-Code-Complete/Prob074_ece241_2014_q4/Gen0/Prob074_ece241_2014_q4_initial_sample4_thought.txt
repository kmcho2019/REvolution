Implement three D flip-flops with asynchronous reset initialized to zero. Each flip-flop's input D is determined by a two-input gate taking the external input x and the flip-flop's current output (or its complement) as the second input:
- DFF0's D input = x XOR Q0
- DFF1's D input = x AND ~Q1
- DFF2's D input = x OR ~Q2
The outputs Q0, Q1, and Q2 feed into a three-input NOR gate producing output Z.
