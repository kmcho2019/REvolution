Implement three D flip-flops, each taking as input the result of a two-input gate with input x and either the flip-flop's output or its complement. Specifically:
- DFF1 input: x XOR Q1
- DFF2 input: x AND ~Q2
- DFF3 input: x OR ~Q3

All flip-flops are reset to 0 initially. The outputs Q1, Q2, Q3 feed into a 3-input NOR gate to produce output z.

Use synchronous reset and update flip-flops on the positive clock edge.
