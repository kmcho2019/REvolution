Implement three D flip-flops, each capturing the output of its respective two-input gate on the rising edge of clk. The inputs to the gates depend on the input x and the current state of each flip-flop. Specifically: 
- DFF1 input = x XOR Q1
- DFF2 input = x AND ~Q2
- DFF3 input = x OR ~Q3
The output z is the NOR of all three Q outputs (Q1, Q2, Q3). All flip-flops are reset synchronously to zero at the start.
