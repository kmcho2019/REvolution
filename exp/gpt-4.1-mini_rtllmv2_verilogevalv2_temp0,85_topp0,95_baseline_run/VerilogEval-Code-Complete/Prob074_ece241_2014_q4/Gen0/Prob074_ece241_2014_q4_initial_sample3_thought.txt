Create three D flip-flops with initial reset to zero. For each flip-flop, compute its next state based on the input x and the current output of that flip-flop: the first flip-flop's D input is x XOR Q, the second's D input is x AND ~Q, and the third's D input is x OR ~Q. On every clock edge, update the flip-flops. The output z is the NOR of all three flip-flops' outputs.
