Implement three D flip-flops with asynchronous reset. Each flip-flop's D input is driven by one of the three gates (XOR, AND, OR) as described. For each gate, the first input is x, and the second input is either the flip-flop output (Q) or its complement (Q_bar), according to the problem statement. Finally, the outputs of the three flip-flops feed a 3-input NOR gate whose output is z.
