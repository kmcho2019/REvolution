The FSM uses three D flip-flops, each storing one bit of state. For each flip-flop, the D input is generated by applying a specific logic gate to the input x and to the flip-flop's current output or complemented output as specified:

- D0 = x XOR Q0
- D1 = x AND ~Q1
- D2 = x OR ~Q2

After the flip-flops update on the rising clock edge, their outputs Q0, Q1, Q2 feed into a 3-input NOR gate to produce output z. The flip-flops are reset to zero initially via a synchronous reset implemented on the first clock cycle or by an explicit reset signal.

The Verilog module will instantiate three D flip-flops with asynchronous reset to zero, compute the D inputs accordingly, and produce z as the NOR of the three Q outputs.
