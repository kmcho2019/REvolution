The outputs p and q depend on the input 'a' and the clock. On the rising clock edge, p is set to the input a, and q is set to the previous value of p. In other words, p follows 'a' synchronously on the clock edge, and q is a delayed version of p by one clock cycle. This behavior is a simple two-stage shift register or delay line. At clock low (when clock = 0), p and q hold their values.
