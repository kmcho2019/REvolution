Implement a positive-edge triggered JK flip-flop using an always block sensitive to the rising edge of the clock. Inside the block, check the values of J and K and update Q according to the truth table: if J=0 and K=0, retain Q (Qold); if J=0 and K=1, set Q=0; if J=1 and K=0, set Q=1; if J=1 and K=1, toggle Q.
