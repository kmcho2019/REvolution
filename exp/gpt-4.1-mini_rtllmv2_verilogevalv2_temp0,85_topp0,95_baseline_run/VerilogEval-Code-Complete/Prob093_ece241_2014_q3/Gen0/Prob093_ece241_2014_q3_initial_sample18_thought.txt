We want to implement the given 4-variable function using one 4-to-1 MUX with selectors a,b and inputs mux_in[3:0], which depend on c,d. The 4-to-1 MUX selects one of mux_in[0..3] based on ab.

The K-map is indexed by ab (columns) and cd (rows):

    ab
cd  00  01  11  10
00 | 0 | 0 | 0 | 1 |
01 | 1 | 0 | 0 | 0 |
11 | 1 | 0 | 1 | 1 |
10 | 1 | 0 | 0 | 1 |

We fix a,b as MUX select inputs and implement mux_in[i] = function of c,d for each ab=i:

- mux_in[0] (ab=00): c d=00->0,01->1,11->1,10->1
  For ab=00, output is 0 at 00, and 1 at 01,11,10.
  mux_in[0] = c + d (since 1 for all except c=0,d=0)
- mux_in[1] (ab=01): c d=00->0,01->0,11->0,10->0
  All zeros, so mux_in[1] = 0
- mux_in[2] (ab=11): c d=00->0,01->0,11->1,10->0
  Only 11 is 1, so mux_in[2] = c & d
- mux_in[3] (ab=10): c d=00->1,01->0,11->1,10->1
  1 for 00,11,10 and 0 for 01
  mux_in[3] = c' d' + c d + c d' = (c' d') + c(d + d') = (c' d') + c*1 = c + d'

So mux_in[3] = c + ~d.

We must implement these outputs using only 2-to-1 multiplexers and no other gates.

Implementing mux_in[0] = c + d: "c + d" = if c=0 then d else 1. Using 2-to-1 mux controlled by c: mux(c, 1, d) = c?1:d = c + d.

Similarly,
mux_in[1] = 0, just connect to 0.

mux_in[2] = c & d: "c & d" = if c=0 then 0 else d = mux(c, 0, d) = c & d.

mux_in[3] = c + ~d: c + ~d = if c=1 then 1 else ~d = mux(c, 1, ~d).

We need to generate ~d using a 2-to-1 mux, since we cannot use NOT gates.

To generate ~d from d using only 2-to-1 muxes:

1) Use a constant 1 or 0 and d as selector to invert.

For example, ~d = mux(d, 0, 1) because when d=0 select 1, when d=1 select 0.

We can implement NOT using a 2-to-1 mux as follows:

not_d = mux(d, 0, 1);

Finally, put all together in top_module, outputting mux_in[3:0] where each bit is implemented with 2-to-1 muxes only.
