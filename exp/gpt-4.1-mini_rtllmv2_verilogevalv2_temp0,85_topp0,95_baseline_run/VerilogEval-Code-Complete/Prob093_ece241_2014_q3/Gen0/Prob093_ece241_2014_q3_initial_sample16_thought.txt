The 4-to-1 MUX uses a,b as selectors, and mux_in[3:0] are inputs for each ab combination:
ab=00 → mux_in[0], ab=01 → mux_in[1], ab=11 → mux_in[2], ab=10 → mux_in[3].

From the K-map:

cd\ab: 
      00 01 11 10
00 |  0 | 0 | 0 | 1 |
01 |  1 | 0 | 0 | 0 |
11 |  1 | 0 | 1 | 1 |
10 |  1 | 0 | 0 | 1 |

For each fixed ab, mux_in[ab] must be a function of c,d:

- For ab=00 (mux_in[0]): values at cd=00,01,11,10 are 0,1,1,1
  So mux_in[0] = 0 if cd=00, else 1 → mux_in[0] = c + d (since c or d = 1 means output 1)

- For ab=01 (mux_in[1]): values are 0,0,0,0 → constant 0

- For ab=11 (mux_in[2]): values are 0,0,1,0
  Only at cd=11 (c=1,d=1) output is 1, else 0 → mux_in[2] = c & d

- For ab=10 (mux_in[3]): values are 1,0,1,1
  At cd=00:1,01:0,11:1,10:1
  This is (not c and not d) OR (c and d) OR (c and not d)
  Simplify: (not c & not d) + (c & d) + (c & not d) = (not c & not d) + c
  So mux_in[3] = c + (~c & ~d) = c + (~d & ~c)

  Actually, this equals c + (~c & ~d) = c + ~d & ~c
  = (c + ~d) & (c + ~c) = (c + ~d) & 1 = c + ~d

So mux_in[3] = c + ~d.

Thus, the outputs are:
mux_in[0] = c | d
mux_in[1] = 0
mux_in[2] = c & d
mux_in[3] = c | (~d)

We implement mux_in as per above using only logic expressible with 2-to-1 MUXes and no other gates.

Since only multiplexers are allowed, we implement the logic with 2-to-1 muxes:

Basic idea: implement OR, AND, NOT using 2-to-1 MUXes.

- NOT x = mux(x,1,0)
- AND(x,y) = mux(x,0,y)
- OR(x,y) = mux(x,1,y)

Let's implement each mux_in[i]:

mux_in[0] = c | d = OR(c,d) = mux(c,1,d)
mux_in[1] = 0 (constant zero)
mux_in[2] = c & d = AND(c,d) = mux(c,0,d)
mux_in[3] = c | (~d) = OR(c, NOT(d))

NOT(d) = mux(d,1,0)
Then OR(c, NOT(d)) = mux(c,1,NOT(d))

We will instantiate the 2-to-1 muxes to generate these expressions for mux_in[0], mux_in[2], mux_in[3], mux_in[1] is 0.

We provide mux_in as output wires.

This satisfies the requirement, using only 2-to-1 muxes to generate the 4 inputs to the 4-to-1 mux, which uses a,b as selectors.

Note: The top_module only generates mux_in. The 4-to-1 mux itself is external.
