The 4-to-1 MUX uses inputs a,b as selectors. Each mux_in[i] corresponds to a fixed ab value and is a function of c,d. From the K-map, for each ab value, mux_in[i] is a function of cd.

Mapping the K-map for each ab:

ab=00 (mux_in[0]): values at cd=00,01,11,10 are 0,1,1,1
ab=01 (mux_in[1]): values at cd=00,01,11,10 are 0,0,0,0
ab=11 (mux_in[3]): values at cd=00,01,11,10 are 0,0,1,0
ab=10 (mux_in[2]): values at cd=00,01,11,10 are 1,0,1,1

For each mux_in[i], express the function as multiplexers using c,d as selectors (2-to-1 MUXes).

Let's do one by one:

1) mux_in[0]: cd=00->0, 01->1, 11->1, 10->1
Using d as selector:
If d=0 (cd=00 or 10): values are 0 (c=0) and 1 (c=1)
If d=1 (cd=01 or 11): values are 1 (c=0), 1(c=1) → always 1

So mux_in[0] = MUX(d, d=0? MUX(c,0,1), d=1? 1) = MUX(d, mux_c, 1), where mux_c = MUX(c,0,1) = c

So mux_in[0] = d ? 1 : c

2) mux_in[1]: all zeros → 0

3) mux_in[2]: values 1,0,1,1 for cd=00,01,11,10
Using d as selector:
d=0 (cd=00 or 10): values 1 (c=0), 1(c=1) → 1
d=1 (cd=01 or 11): values 0 (c=0),1(c=1)

So mux_in[2] = MUX(d, mux_c, 1)
mux_c = MUX(c,0,1) = c

So mux_in[2] = d ? c : 1

4) mux_in[3]: values 0,0,1,0 for cd=00,01,11,10
d=0: cd=00 or 10 → 0 (c=0),0(c=1) → 0
d=1: cd=01 or 11 → 0(c=0),1(c=1)

mux_in[3] = MUX(d, mux_c, 0)
mux_c = MUX(c,0,1) = c

So mux_in[3] = d ? c : 0

mux_in[1] = 0 (constant zero)

Thus, implement mux_in[0], mux_in[2], mux_in[3] using 2-to-1 MUXes with c,d as selectors and as data inputs, and mux_in[1] as zero.

This respects the problem's constraints: no other gates, only 2-to-1 MUXes and a 4-to-1 MUX for the final selection with a,b selectors.
