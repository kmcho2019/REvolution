To implement a dual-edge triggered flip-flop using only single-edge triggered flip-flops, we can use two flip-flops triggered on opposite edges of the clock: one on the rising edge and one on the falling edge. Both sample the input 'd'. Then, we combine their outputs using a simple multiplexer that selects which output to use based on the clock level. This way, on each clock edge, the correct flip-flop output is reflected on 'q', effectively creating a dual-edge triggered flip-flop.
