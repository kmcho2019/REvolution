To build a dual-edge triggered flip-flop using FPGA resources that only have single-edge triggered flip-flops, we can use two single-edge triggered flip-flops: one triggered on the positive edge of the clock and one triggered on the negative edge. Each flip-flop captures the input data 'd' on its respective clock edge. Then, we combine their outputs using a multiplexer that selects which flip-flop's output to use based on the clock level, effectively updating the output 'q' on both edges of the clock.

This approach doubles the effective sampling rate of the input data, mimicking a dual-edge triggered flip-flop.

Implementation details:
- Use two registers: pos_edge_ff and neg_edge_ff.
- pos_edge_ff samples d on posedge clk.
- neg_edge_ff samples d on negedge clk.
- The output q is assigned combinationally as:
  if clk == 1, q = pos_edge_ff
  else q = neg_edge_ff

This ensures q updates on both edges of clk.
