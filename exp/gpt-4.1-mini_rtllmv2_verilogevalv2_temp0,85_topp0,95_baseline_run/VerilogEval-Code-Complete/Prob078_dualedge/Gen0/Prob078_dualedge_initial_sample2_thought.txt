To implement a dual-edge triggered flip-flop using FPGA-friendly constructs, we can use two single-edge triggered flip-flops: one triggered on the positive edge of the clock and the other on the negative edge. Both capture the input `d` on their respective edges. Then, a multiplexer selects which flip-flop output to use based on the current clock level. This way, the output `q` updates on both edges of the clock.
