To create a dual-edge triggered flip-flop using only positive edge triggered flip-flops (which are common in FPGAs), we can use two flip-flops clocked on opposite edges of the clock: one on the positive edge and one on the negative edge. Each captures the input data `d` at their respective clock edges. Then we combine their outputs with a multiplexer that selects the correct output depending on the clock level, effectively producing an output `q` that updates on both edges of `clk`. This method simulates dual-edge triggering by using two single-edge triggered flip-flops and a selector.
