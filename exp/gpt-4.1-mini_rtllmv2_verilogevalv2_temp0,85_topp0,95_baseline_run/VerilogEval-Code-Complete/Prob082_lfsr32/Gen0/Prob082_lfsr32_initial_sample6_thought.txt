Implement a 32-bit Galois LFSR shifting right. The feedback bit is q[0]. For each tap position (32, 22, 2, 1), the bit in the next state is XORed with q[0]. The highest bit (bit 31 in zero-based indexing) is set to q[0] after XORing with taps. The reset is synchronous and active high, setting q to 32'h1 on reset.
