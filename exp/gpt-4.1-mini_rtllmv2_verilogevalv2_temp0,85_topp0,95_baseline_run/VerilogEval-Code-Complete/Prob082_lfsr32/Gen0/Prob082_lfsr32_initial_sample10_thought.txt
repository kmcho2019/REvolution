Implement a 32-bit Galois LFSR with synchronous active-high reset that loads 32'h1 on reset. The LFSR shifts right each clock cycle. The taps are at bits 32, 22, 2, and 1, corresponding to q[31], q[21], q[1], and q[0]. On each shift, the new MSB bit is the XOR of q[0] and the tapped bits. For the Galois configuration, we shift right, and each tapped bit (except the LSB) is XORed with q[0] before being assigned. The LSB is always q[0] shifted out, so the next q[0] is the XOR feedback.

The update rule for each bit i (31 down to 1) is:
  if i is tapped, q[i] <= q[i] ^ q[0]
  else q[i] <= q[i]
and q[0] <= feedback bit (XOR of q[0] and taps at q[31], q[21], q[1])

But in Galois configuration, the feedback is the LSB q[0], which is fed back into the tapped bits by XORing them with q[0]. The new MSB is just q[31] shifted right, which is q[31] before shifting. Hence the MSB bit comes from q[31] shifted right, but after XOR with q[0] if tapped.

To implement, we compute next state by:
- next_q[0] = q[0] shifted out (which in Galois is just the feedback, i.e., the LSB from previous state, so q[0])
- For each bit i > 0:
   if i tapped: next_q[i] = q[i] ^ q[0]
   else: next_q[i] = q[i]

Then shift right:
 next_q = {new MSB, q[31:1] ^ (tapped bits & q[0]) }

The design is synchronous, so we update q on the rising edge of clk if reset is low; if reset is high, q <= 32'h1.
