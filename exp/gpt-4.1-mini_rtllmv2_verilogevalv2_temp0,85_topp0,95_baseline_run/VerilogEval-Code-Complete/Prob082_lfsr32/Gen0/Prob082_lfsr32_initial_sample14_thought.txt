Implement a 32-bit Galois LFSR shifting right. On each clock, if reset is high, set q to 32'h1. Otherwise, shift right by one bit: q[i] gets q[i-1] for non-tap bits; for tap bits (positions 32, 22, 2, 1), q[i] is XOR of q[i-1] and q[0]. Note that in Verilog indexing, bit 0 is LSB and bit 31 is MSB. The taps are at bits 31, 21, 1, 0 (zero-based). On each clock cycle, q[31] = q[30], q[21] = q[20] XOR q[0], q[1] = q[0] XOR q[0], q[0] = q[0]. But since q[0] is output bit, it is used to XOR to the taps. The standard Galois LFSR structure applies the XOR at tap positions with q[0], while other bits shift right directly. Implement this logic in always @(posedge clk) block with synchronous reset.
