Implement a 32-bit Galois LFSR that shifts right on each clock cycle. The taps are on bits 31 (position 32), 21 (position 22), 1 (position 2), and 0 (position 1). On each clock rising edge, if reset is high, set q to 32'h1. Otherwise, shift right by one bit, and for each tapped bit position, XOR q[0] (LSB) with that bit to form the new bit at that position. This is done by conditionally XORing the tap bits with q[0]. The LSB of q is replaced by the feedback bit which is q[0], but in the Galois configuration, the feedback is mixed into the tap positions, and the LSB is just shifted out. The new MSB comes from XOR of q[0] with the taps. The Galois LFSR update formula is: For each bit i, q[i] = q[i+1] ^ (q[0] if tap at i+1 else 0). Since taps are at bits 31, 21, 1, 0, the bits that are affected are those tap positions. Implement this in a synchronous always block.
