Implement a 32-bit Galois LFSR with synchronous active-high reset. On reset, q is set to 32'h1. On each clock cycle, shift q right by one bit. The MSB of q (bit 31) is the output bit that gets XORed with tap positions 21, 1, and 0 (adjusted for zero-based indexing). Each tap bit is conditionally XORed with q[0] (the output bit) to form the new bit value. The feedback is applied as per the Galois LFSR definition.
