Implement a 32-bit Galois LFSR with taps at positions 32, 22, 2, and 1. The shift register shifts right on every clock cycle. The feedback bit is the LSB of the current register value. For each tap position, the next bit is the XOR of the current bit at that position with the feedback bit. The highest bit (bit 31, corresponding to position 32) is set as the XOR of feedback bit with itself (or just feedback). On reset, synchronously set q to 32'h1.
