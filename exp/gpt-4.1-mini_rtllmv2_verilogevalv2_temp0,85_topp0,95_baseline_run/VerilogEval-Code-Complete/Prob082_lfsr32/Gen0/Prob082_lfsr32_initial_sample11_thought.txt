Implement a 32-bit Galois LFSR that shifts right on each clock cycle.
The taps are at bit positions 32, 22, 2, and 1, which correspond to bits 31, 21, 1, and 0 in zero-based indexing.
The feedback bit is the LSB (q[0]). For each tap position, XOR the tap bit with the feedback bit to determine the next bit value.
The shift is such that q[i] <= q[i+1] XOR feedback_bit if tap at i+1, else q[i+1].
On synchronous active-high reset, set q to 32'h1.
