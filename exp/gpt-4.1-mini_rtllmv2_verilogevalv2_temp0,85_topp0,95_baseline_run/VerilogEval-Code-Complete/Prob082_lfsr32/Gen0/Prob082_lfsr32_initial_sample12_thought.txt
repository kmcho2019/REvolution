Implement a 32-bit Galois LFSR with specified taps at bits 32, 22, 2, and 1. On each clock edge, if reset is asserted, synchronously set q to 1. Otherwise, shift q right by one bit. For each tapped bit position, XOR the LSB (q[0]) with that bit to form its next bit. The MSB is generated by XORing q[0] with q[31], and similarly for tapped positions (21,1,0 in zero-based indexing). This implements the Galois LFSR feedback correctly.
