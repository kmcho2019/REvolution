Implement a 32-bit Galois LFSR shifting right on each clock. On synchronous reset, set q to 32'h1. For each bit position with a tap (32, 22, 2, 1), XOR the LSB output bit (q[0]) with that bit to form the next value for that bit. The other bits shift right unchanged from the previous bit. Since bit 32 corresponds to q[31], taps are on q[31], q[21], q[1], and q[0]. The next state calculation uses q[0] as the input bit, and taps flip the incoming bit accordingly.
