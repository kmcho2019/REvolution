Implement a 32-bit Galois LFSR that shifts right on each clock cycle. The taps are at bit positions 32, 22, 2, and 1, which correspond to bits q[31], q[21], q[1], and q[0] in zero-based indexing. The next value for each bit is the previous bit shifted right, except for tapped positions where we XOR with the outgoing bit q[0]. The LSB q[0] is always updated with the XOR of the tapped bits and the outgoing bit. On synchronous reset, set q to 32'h1.
