Implement a 32-bit Galois LFSR with synchronous active-high reset. On reset, q is set to 32'h1. On each clock, calculate the feedback bit as the LSB (q[0]) before shifting. Then shift right by one bit; for each tap position (bits 31, 21, 1, and 0 due to zero indexing), XOR that bit with the feedback bit. Note that taps at positions 32, 22, 2, and 1 correspond to bits 31, 21, 1, and 0 zero-indexed in Verilog. The Galois configuration means taps only affect the bits with taps by XORing them with the feedback bit, others shift right unchanged.
