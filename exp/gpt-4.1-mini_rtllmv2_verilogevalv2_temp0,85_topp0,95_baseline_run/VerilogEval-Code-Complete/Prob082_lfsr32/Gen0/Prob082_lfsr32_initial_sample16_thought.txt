Implement a 32-bit Galois LFSR shifting right on each clock cycle. On each shift, the new MSB bit is the XOR of the current LSB (q[0]) with taps at bits 31 (bit 32), 21 (bit 22), 1 (bit 2), and 0 (bit 1). If reset is asserted, synchronously reset q to 32'h1. Use a synchronous always block triggered on the positive edge of clk.
