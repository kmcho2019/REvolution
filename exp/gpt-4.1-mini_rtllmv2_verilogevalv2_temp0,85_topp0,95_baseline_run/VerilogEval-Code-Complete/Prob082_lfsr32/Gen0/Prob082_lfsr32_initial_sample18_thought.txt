Implement a 32-bit Galois LFSR that shifts right on each clock cycle. The taps are at bits 32, 22, 2, and 1. Since Verilog indexing starts from 0, bit 32 corresponds to q[31], bit 22 to q[21], bit 2 to q[1], and bit 1 to q[0]. The next input bit is computed by XORing q[0] with these tapped bits. On each clock edge, if reset is asserted, q is set to 32'h1 synchronously. Otherwise, shift the register right by one bit, inserting the XOR result at the MSB.
