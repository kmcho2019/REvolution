Implement a 32-bit Galois LFSR with synchronous active-high reset. On reset, q is set to 32'h1. On each clock edge, the register shifts right by one bit. The input bit (q[31]) is updated by XORing q[0] (LSB) with the tapped bits. The taps at bit positions 32, 22, 2, and 1 correspond to q[31], q[21], q[1], and q[0] respectively (0-indexed). In the Galois configuration, only the tapped bits are XORed with the output bit to update their next state, others shift right normally. The LSB is always the previous MSB, so we shift right and apply XOR to tapped bits accordingly.
