Implement a 32-bit Galois LFSR with taps at bits 32, 22, 2, and 1 (corresponding to q[31], q[21], q[1], q[0] in zero-indexed Verilog). On each clock edge, if reset is high, synchronously reset q to 32'h1. Otherwise, shift right by one bit and update tapped bits by XORing with the output bit q[0]. Specifically, the next bit values for tapped positions are q[i] ^ q[0], while non-tapped bits just take the value from q[i-1]. The LSB q[0] is replaced by the XOR of tapped bits and q[0], but in Galois configuration, only the tapped bits are XORed with q[0], and q[0] takes the value of q[1]. Implement this carefully inside a synchronous always block.
