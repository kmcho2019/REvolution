Implement a 32-bit Galois LFSR with synchronous active-high reset initializing q to 32'h1. On each clock edge, if reset is high, set q to 1. Otherwise, shift q right by one bit, updating tapped bits with the XOR of the previous q[0] (LSB) to generate the next state. The taps are at bits 32, 22, 2, and 1 (1-based indexing). Since q is zero-indexed, these correspond to q[31], q[21], q[1], and q[0]. For the Galois configuration, the next state bit at each tapped position is XORed with q[0], while other bits just shift right. We'll implement this logic in a procedural block triggered on the rising edge of clk.
