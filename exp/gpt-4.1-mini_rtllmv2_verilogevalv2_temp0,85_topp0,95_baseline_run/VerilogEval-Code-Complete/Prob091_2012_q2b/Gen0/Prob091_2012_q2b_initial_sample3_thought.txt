To find Y1 (next input to flip-flop y[1] corresponding to state B) and Y3 (for state D), we analyze transitions leading to states B and D, respectively, and express them with one-hot current states and input w.

States encoded as:
A = y[0]
B = y[1]
C = y[2]
D = y[3]
E = y[4]
F = y[5]

For Y1 (state B):
- B is next state from A with input w=1.
So, Y1 = y[0] & w

For Y3 (state D):
- D is next from B with w=0: y[1] & ~w
- D is next from C with w=0: y[2] & ~w
- D is next from E with w=0: y[4] & ~w
- D is next from F with w=0: y[5] & ~w

Y3 = (y[1] + y[2] + y[4] + y[5]) & ~w
