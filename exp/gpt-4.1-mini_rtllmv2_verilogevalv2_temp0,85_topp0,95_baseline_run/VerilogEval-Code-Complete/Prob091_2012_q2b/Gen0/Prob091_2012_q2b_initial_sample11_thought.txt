For one-hot encoding, each state is represented by one bit set high in y[5:0]. We want to find expressions for Y1 and Y3, the next inputs for state flip-flops y[1] (B) and y[3] (D) respectively, based on current states and input w.

From the state transitions:

Y1 (next for B):
B is y[1].
Next state is B when:
- Current state A (y[0]) and input w=1 => A --1--> B
So, Y1 = y[0] & w

Y3 (next for D):
D is y[3].
Next state is D when:
- From B (y[1]) with w=0: B --0--> D
- From C (y[2]) with w=0: C --0--> D
- From E (y[4]) with w=0: E --0--> D
- From F (y[5]) with w=0: F --0--> D

So, Y3 = (y[1] | y[2] | y[4] | y[5]) & ~w
