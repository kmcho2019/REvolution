The state encoding is one-hot:
y[0] = A
y[1] = B
y[2] = C
y[3] = D
y[4] = E
y[5] = F

We need to find the next input (Y1 for y[1]=B and Y3 for y[3]=D) based on the current state and input w.

From the state transitions:

Y1 (next B):
B is y[1], so its input Y1 is 1 when next state is B.
From transitions:
- From A: if w=1, next state = B → Y1 = 1 when y[0]=A and w=1
No other transitions to B.

So: Y1 = y[0] & w

Y3 (next D):
D is y[3], so Y3 is 1 when next state = D.

From transitions:
- From B: if w=0, next = D → y[1] & ~w
- From C: if w=0, next = D → y[2] & ~w
- From E: if w=0, next = D → y[4] & ~w
- From F: if w=0, next = D → y[5] & ~w

Combine all:

Y3 = (y[1] | y[2] | y[4] | y[5]) & ~w

Hence, the output logic for Y1 and Y3 can be directly coded.
