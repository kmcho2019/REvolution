In one-hot encoding, each state corresponds to exactly one bit set in y. The flip-flop input for state B (y[1]) and state D (y[3]) depend on transitions into those states.

From the state machine transitions:

- For Y1 (state B):
  Transitions into B come only from A on input w=1.
  So Y1 = y[0] & w.

- For Y3 (state D):
  Transitions into D come from:
    - B on w=0: y[1] & ~w
    - C on w=0: y[2] & ~w
    - E on w=0: y[4] & ~w
    - F on w=0: y[5] & ~w
  So Y3 = (~w) & (y[1] | y[2] | y[4] | y[5])
