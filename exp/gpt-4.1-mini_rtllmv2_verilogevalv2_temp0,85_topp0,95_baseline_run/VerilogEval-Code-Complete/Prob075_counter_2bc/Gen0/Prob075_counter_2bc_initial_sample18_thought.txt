Implement a 2-bit saturating counter with asynchronous active-high reset. On the positive edge of clk or reset, if reset is asserted, set the counter to 2'b01. Otherwise, if train_valid is high, increment the counter if train_taken is 1 and the counter is less than 3, or decrement the counter if train_taken is 0 and the counter is greater than 0. If train_valid is low, keep the counter unchanged.
