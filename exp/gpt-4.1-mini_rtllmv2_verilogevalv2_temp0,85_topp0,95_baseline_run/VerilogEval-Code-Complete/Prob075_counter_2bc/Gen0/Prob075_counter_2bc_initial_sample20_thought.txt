Implement a 2-bit saturating counter that updates on the rising edge of clk or asynchronously resets on areset. When areset is asserted, the counter is set to 2'b01 (weakly not-taken). On each clock edge, if train_valid is high, increment the counter if train_taken is 1 and the counter is less than 3, or decrement if train_taken is 0 and counter is greater than 0. If train_valid is 0, hold the counter value.
