Implement a two-bit saturating counter with asynchronous active-high reset. On the positive edge of clk or areset, if areset is asserted, reset state to 2'b01 (weakly not-taken). Otherwise, if train_valid is high, increment state if train_taken is 1 and state is less than 3, or decrement if train_taken is 0 and state is greater than 0. If train_valid is 0, hold the current state.
