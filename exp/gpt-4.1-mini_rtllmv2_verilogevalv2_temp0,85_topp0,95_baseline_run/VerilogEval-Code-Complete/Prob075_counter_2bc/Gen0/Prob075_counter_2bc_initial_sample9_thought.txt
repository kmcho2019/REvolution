Implement a two-bit saturating counter with asynchronous positive edge reset. On reset, set the counter state to 2'b01 (weakly not-taken). On each rising clock edge, if train_valid is high, increment the counter by 1 if train_taken is 1 (capped at 3), or decrement by 1 if train_taken is 0 (capped at 0). Otherwise, keep the state unchanged.
