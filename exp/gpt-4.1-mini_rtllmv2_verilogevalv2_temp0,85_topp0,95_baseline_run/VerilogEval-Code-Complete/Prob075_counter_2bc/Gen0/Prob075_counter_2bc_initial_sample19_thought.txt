Implement a 2-bit saturating counter with asynchronous active-high reset. On positive edge of clock or reset, if reset is asserted, set state to 2'b01. Otherwise, if train_valid is high, increment state if train_taken is 1 (but saturate at 3), or decrement state if train_taken is 0 (but saturate at 0). If train_valid is 0, maintain state.
