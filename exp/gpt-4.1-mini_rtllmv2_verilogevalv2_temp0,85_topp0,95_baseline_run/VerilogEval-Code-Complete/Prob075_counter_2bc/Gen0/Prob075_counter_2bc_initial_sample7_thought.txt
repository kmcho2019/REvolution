Implement a 2-bit saturating counter with asynchronous positive-edge reset. On the rising edge of clk, if train_valid is high, increment the counter if train_taken is 1 (up to max 3), else decrement it if train_taken is 0 (down to min 0). If train_valid is 0, hold the current state. On asynchronous positive edge of areset, reset the counter to 2'b01.
