Implement a 5-bit Galois LFSR that shifts right each clock cycle. The taps are on bit positions 5 and 3, which correspond to q[4] and q[2] in zero-based indexing. On each clock edge, the new MSB bit is computed by XORing q[0] (LSB) with the tapped bits q[4] and q[2]. The output shifts right by one bit, with the new MSB inserted. On synchronous reset, q is set to 5'b00001 (decimal 1) as the initial non-zero state. This ensures a maximum-length sequence of 31 states.
