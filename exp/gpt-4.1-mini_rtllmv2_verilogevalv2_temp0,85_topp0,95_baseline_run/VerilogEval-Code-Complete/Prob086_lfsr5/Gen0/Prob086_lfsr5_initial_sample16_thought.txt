Implement a 5-bit Galois LFSR that shifts right on each clock cycle. The taps are at bit positions 5 and 3 (1-based), which correspond to bits q[4] and q[2] in 0-based indexing. The next bit for these tap positions is XOR of the current q[0] (LSB) and the current bit at that position. Other bits shift right unchanged. On reset, set q to 1 (5'b00001). The LFSR output updates on the positive clock edge.
