Implement a 5-bit Galois LFSR with taps at bit positions 5 and 3 (indices 4 and 2 in zero-based indexing).
On each clock edge, if reset is high, set q to 5'b00001.
Otherwise, shift right by one bit.
The new MSB bit (q[4]) is q[0] XOR q[2] (taps at 5 and 3).
Other bits shift right:
- q[3] <= q[4]
- q[2] <= q[3] XOR q[0] if tapped, but in Galois form only tapped bits are XORed with LSB output during update.
In Galois LFSR, only tapped bits are XORed with LSB output, others just shift right.
Hence:
- q[4] <= q[0] ^ q[4] (tap at bit 5)
- q[3] <= q[4]
- q[2] <= q[3] ^ q[0] (tap at bit 3)
- q[1] <= q[2]
- q[0] <= q[1]

But the standard way is: For each bit i (except LSB), if tap at i+1 is set, then q[i] <= q[i+1] ^ q[0], else q[i] <= q[i+1].

The LSB q[0] shifts in the MSB value.

We implement this behavior properly.

Final code will have a synchronous reset and synchronous update of q as described.
