Implement a 5-bit Galois LFSR with taps at positions 5 and 3 (bits 4 and 2 in zero-based indexing). On each clock edge, if reset is high, set the register to 1. Otherwise, shift right by one bit. The new bit shifted into the MSB (bit 4) is the XOR of the LSB (bit 0) and the tap bits (bit 4 and bit 2) after they are XORed with the LSB. According to Galois LFSR, only bits with taps are XORed with the LSB before shifting; other bits just shift right. So, for each bit i (except LSB), q[i] = q[i-1] XOR (q[0] if i is a tap), else q[i] = q[i-1]. The LSB shifts in from MSB side with the XORed feedback. Implement this logic synchronously with reset.
