Implement a 5-bit Galois LFSR with taps at bit positions 5 and 3 (indexing from 1 for clarity). On each clock cycle, if reset is active, set q to 1. Otherwise, shift right by one bit. For bits with taps (bits 5 and 3), XOR the input with q[0]. Specifically, the next state is computed by shifting right, and for tapped bits, the new bit is q[tap] XOR q[0]. Bit 4 (index 5) and bit 2 (index 3) are tapped. The indexing in the code is zero-based, so bit 4 and bit 2 are tapped.
