Implement a 5-bit Galois LFSR with taps at bits 5 and 3, shifting right each clock cycle. On each clock edge, if reset is high, set q to 1. Otherwise, for each bit position, shift right and apply XOR feedback from the LSB to the tap positions (bits 4 and 2, zero-indexed). Specifically, q[4] = q[0] XOR q[4], q[2] = q[0] XOR q[2], and other bits shift right without XOR.
