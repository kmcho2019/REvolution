Implement a 5-bit Galois LFSR with taps at bit positions 5 and 3, which correspond to q[4] and q[2] in zero-based indexing. On each clock edge, if reset is high, set q to 1. Otherwise, shift right by one bit. The new MSB bit (q[4]) is calculated by XORing q[0] (LSB) with the tap bits. Specifically, for tapped bits, their next state is XOR of q[0] and their previous state; untapped bits just shift right. The LSB always takes q[1]. This implementation follows the Galois LFSR structure where only the tapped bits are XORed with q[0].
