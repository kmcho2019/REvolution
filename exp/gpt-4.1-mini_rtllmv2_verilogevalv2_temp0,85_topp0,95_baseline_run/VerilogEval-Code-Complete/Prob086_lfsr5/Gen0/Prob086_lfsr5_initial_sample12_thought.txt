Implement a 5-bit Galois LFSR with taps at bit positions 5 and 3 (bits 4 and 2 in 0-based indexing). On each clock edge, if reset is active, set output q to 5'b00001. Otherwise, shift the register right by one bit. The new highest bit (q[4]) is formed by XORing the output bit q[0] with q[2] (tap at bit 3). Also, because it is a Galois LFSR, only the tapped bits are XORed with q[0], others shift normally. Update tapped bit q[2] accordingly by XORing with q[0], and other bits shift right unchanged.
