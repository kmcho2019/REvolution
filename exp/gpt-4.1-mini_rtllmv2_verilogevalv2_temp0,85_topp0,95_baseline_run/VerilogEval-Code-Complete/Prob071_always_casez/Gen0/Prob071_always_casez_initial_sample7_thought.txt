Implement a priority encoder that scans the input bits from least significant bit (bit 0) to the most significant bit (bit 7). The output is the position of the first bit set to 1 found in this order. If no bits are set, output zero. Since zero is a valid output but also used to indicate no bits set, we must differentiate these cases. Given the requirement, zero should be output if none of the bits are high; otherwise, output the position of the first high bit. We'll use a combinational always block with priority checks from bit 0 to bit 7.
