The output q changes only on the rising edge of clk. Initially, q is unknown. At the first rising edge (15ns) when a=0, q becomes 1. At the next rising edge where a=1 (45ns), q becomes 0 and remains 0 regardless of a afterwards. Thus, on each rising edge, q toggles when a=0 and resets to 0 when a=1. In other words, q is set to 1 on the first 0 input of a, and resets to 0 when a=1. Once reset to 0 by a=1, q remains 0. So q behaves as a latch that sets to 1 when a=0 on rising edge, and resets to 0 when a=1 on rising edge, and stays 0 thereafter.
