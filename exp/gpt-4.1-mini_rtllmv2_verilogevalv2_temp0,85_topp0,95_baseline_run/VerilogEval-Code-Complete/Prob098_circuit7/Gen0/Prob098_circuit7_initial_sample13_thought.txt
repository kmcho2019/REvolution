The circuit is a positive-edge triggered flip-flop with output q. On each rising edge of clk, if input a is 0, q is set to 1 and remains 1 on subsequent rising edges when a=0. If a is 1 on a rising edge, q resets to 0 and remains 0 while a stays 1 on rising edges. Essentially, q latches to 1 when a=0 on the rising edge, and resets to 0 when a=1 on the rising edge.
