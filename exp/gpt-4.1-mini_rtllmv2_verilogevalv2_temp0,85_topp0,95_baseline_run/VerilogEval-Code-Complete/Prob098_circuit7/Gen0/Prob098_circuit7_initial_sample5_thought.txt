From the waveform, 'q' becomes 1 at the clock edge when 'a' is 0 (and stays 1 until 'a' changes to 1 at a clock edge, then 'q' resets to 0). Actually, looking closely, 'q' is set to 1 on the first rising edge when 'a' is 0 and remains 1 as long as 'a' remains 0 on subsequent rising edges; when 'a' becomes 1 on rising edge, 'q' resets to 0 and stays 0 thereafter. So, 'q' is set on the rising edge to the inverse of 'a' only if it was previously 0, or remains the same once set. Actually, more simply, 'q' is set on rising edge to 1 if 'a' is 0, and reset to 0 if 'a' is 1. So the behavior is q <= ~a at rising edge.
