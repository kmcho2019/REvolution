The output q updates only on the rising edge of clk. Initially, q is unknown. At the first rising edge with a=0, q becomes 1. As long as a=0 on rising edges, q remains 1. When a changes to 1 at a rising edge, q becomes 0 and remains 0 for all subsequent rising edges while a=1. In other words, q is set to 1 when a=0 at clk rising edge and reset to 0 when a=1 at clk rising edge. This behavior can be implemented with a flip-flop that loads the inverted value of a (q = ~a) at each rising edge of clk.
