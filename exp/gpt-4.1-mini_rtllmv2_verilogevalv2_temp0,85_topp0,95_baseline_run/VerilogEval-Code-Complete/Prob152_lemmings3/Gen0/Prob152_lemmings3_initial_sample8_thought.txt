Model the Lemming's behavior as a Moore FSM with states representing the Lemming's current action and direction: walking left, walking right, falling, and digging. On reset, start walking left.

Transitions are prioritized:
1. Falling: when ground=0 and currently walking or digging, transition to falling.
2. Digging: if ground=1, not falling, dig=1, and currently walking, transition to digging.
3. Switching direction: if walking and bumped on left or right, switch direction.

While falling or digging, bumps and dig commands are ignored.

When ground returns to 1 while falling, transition back to walking in the same direction as before falling.

When digging and ground=0, transition to falling but keep the original direction to resume walking after falling.

Outputs reflect the current state:
- walk_left and walk_right are mutually exclusive, true only in walking states.
- aaah is true only when falling.
- digging is true only when digging.

Implement asynchronous positive edge reset to walk_left state.
