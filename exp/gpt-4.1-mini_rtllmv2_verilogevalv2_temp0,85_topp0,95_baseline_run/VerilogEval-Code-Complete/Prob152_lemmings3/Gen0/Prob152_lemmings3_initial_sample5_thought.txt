Design a Moore FSM with states encoding the Lemming's current behavior:
- Walking left (walk_left=1)
- Walking right (walk_right=1)
- Falling (aaah=1)
- Digging (digging=1)

State transitions:
1. Reset: walk_left.
2. If falling (aaah):
   - If ground=1, return to previous walking direction.
   - Else stay falling.
3. Else if ground=0 (and not falling or digging), start falling.
4. Else if digging:
   - If ground=0, start falling.
   - Else keep digging.
5. Else if walking:
   - If dig=1 and ground=1, start digging.
   - Else if bumped (left or right or both), switch walking direction.
   - Else stay walking.

Use registers to hold current state and previous walking direction for resuming after fall.

Outputs depend only on current state:
- walk_left or walk_right active for walking states
- aaah active for falling state
- digging active for digging state

Implement the FSM with state encoding and logic accordingly.
