- Falling supersedes digging and bumping.
- Digging supersedes bumping.

The code models states accordingly with WALK_LEFT, WALK_RIGHT, FALLING_LEFT, FALLING_RIGHT, DIGGING_LEFT, and DIGGING_RIGHT.

3. The precedence order is fall > dig > bump, which the code implements in the same order.

4. The problem is likely in the initial state or in transitions where bumps coincide with ground changes or dig signals.

5. The problem description says bumps during falling or digging have no effect, and being bumped in the same cycle as ground disappears or reappears also does not affect direction.

6. The code transitions immediately to FALLING_LEFT or FALLING_RIGHT on ground==0 even if bumped in the same cycle, which is correct.

8. Similarly, when digging ends due to ground==0, it transitions to falling states preserving direction.
