Design a Moore FSM with states representing direction and action: walking left, walking right, falling, and digging. On asynchronous positive edge reset, go to walk_left. Transitions prioritize falling if ground=0, then digging if dig=1 and currently walking on ground, else switching direction if bumped. While falling or digging, bump inputs don't change direction. Store walking direction separately so that when falling or digging ends, the FSM resumes walking in the same direction. Outputs depend only on the current state.
