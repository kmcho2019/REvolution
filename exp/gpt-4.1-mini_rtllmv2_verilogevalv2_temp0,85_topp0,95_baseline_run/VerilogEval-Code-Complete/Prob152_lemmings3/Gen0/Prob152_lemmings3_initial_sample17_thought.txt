Design a Moore FSM with states encoding direction (left/right) and activity (walking, falling, digging). On reset, set state to walking left. In each clock cycle, update state based on inputs and current state with the following priority: if ground=0, go to falling state maintaining direction; else if dig=1 and currently walking on ground, start digging; else if walking and bumped on either side, switch direction; digging ends when ground disappears, causing a transition to falling. Outputs are derived from the current state: walk_left and walk_right reflect direction when walking or digging, aaah indicates falling, digging indicates digging state.
