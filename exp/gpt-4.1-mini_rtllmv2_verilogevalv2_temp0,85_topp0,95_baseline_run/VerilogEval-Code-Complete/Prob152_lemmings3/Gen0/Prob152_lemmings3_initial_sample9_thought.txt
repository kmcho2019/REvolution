We model the Lemming as a Moore FSM with states encoding walking direction and action (walking left, walking right, falling, digging). The states are:

- WALK_LEFT
- WALK_RIGHT
- FALLING_LEFT
- FALLING_RIGHT
- DIGGING_LEFT
- DIGGING_RIGHT

The walking direction is embedded in the state. 

Transitions:

- If ground=0 and not already falling, enter FALLING state preserving direction.
- If digging=1 and ground=1 and currently walking, enter DIGGING state with current direction.
- If bumped on left or right while walking (not falling or digging), switch directions.
- Falling ends when ground=1, returning to walking state with same direction.
- Digging ends when ground=0, going to falling state with same direction.

Bumping has no effect while falling or digging.

Priority: fall > dig > direction switch.

Outputs depend solely on state.

Reset sets the state to WALK_LEFT.

We implement synchronous state transitions with asynchronous active-high reset.

Outputs are combinational from state.
