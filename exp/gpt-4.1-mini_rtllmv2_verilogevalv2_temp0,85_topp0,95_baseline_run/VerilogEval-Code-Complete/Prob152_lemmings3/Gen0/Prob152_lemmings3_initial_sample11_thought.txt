Design a Moore FSM with states encoding walking direction and mode (walking_left, walking_right, falling, digging).
- Walking states: walk_left or walk_right with ground=1 and not digging or falling.
- Falling state: ground=0, "aaah!" output is active.
- Digging state: triggered by dig=1 while walking on ground.
Priority of transitions on each clock:
1. If ground=0 and not falling or digging -> transition to falling (aaah).
2. If currently digging and ground=0 -> transition to falling.
3. If currently falling and ground=1 -> transition back to previous walking direction.
4. If walking and dig=1 and ground=1 -> start digging.
5. If walking and bump detected -> switch direction.
6. Otherwise remain in current state.

Outputs are derived from current state:
- walk_left and walk_right mutually exclusive, based on walking states.
- aaah when falling.
- digging when in digging state.

Implement asynchronous positive edge reset to walk_left state.
