Design a Moore finite state machine with distinct states for walking left, walking right, falling, digging left, and digging right. The outputs depend only on the current state. On reset, the Lemming walks left. 

State transitions are prioritized as:
1. Falling: If ground=0 and not already falling/digging, transition to falling state.
2. Digging: If dig=1, ground=1, and currently walking (not falling or digging), start digging in the current walk direction.
3. Switching direction: If bumped on left or right and currently walking, switch walking direction.
4. Falling from digging: If digging and ground becomes 0, transition to falling state.
5. Recover from falling: If falling and ground=1, return to walking in the previously stored direction.
6. Recover from digging fall: same as from falling.

Bumping or dig commands during falling or digging are ignored.

States encode walking direction and mode. Use one-hot or encoded states and store walking direction when entering falling.

Outputs are set from states:
- walk_left and walk_right for walking states
- aaah for falling state
- digging for digging states
