We will implement a Moore FSM with distinct states representing walking left, walking right, falling, and digging. The outputs depend solely on the current state.

States:
- WALK_LEFT
- WALK_RIGHT
- FALLING (remember previous walking direction)
- DIGGING (remember walking direction)

Transitions and priorities:
1. If ground=0 and not already falling, transition to FALLING state (overrides dig and bump).
2. If digging is commanded (dig=1), ground=1, and currently walking (not falling), transition to DIGGING.
3. If bump on left or right and currently walking, switch walking direction.
4. While falling or digging, bumps and dig commands are ignored.
5. Falling continues until ground=1, then return to previous walking direction.
6. Digging continues until ground=0, then transition to FALLING.

The state memory must remember the walking direction to resume after falling or digging.

Output logic depends on state:
- WALK_LEFT: walk_left=1
- WALK_RIGHT: walk_right=1
- FALLING: aaah=1
- DIGGING: digging=1 and walking direction signal (walk_left or walk_right) asserted

areset asynchronously resets to WALK_LEFT state.

We implement the FSM with one state register and a direction bit (if walking or remembering direction). The state encoding uses one-hot or encoded states for simplicity.
