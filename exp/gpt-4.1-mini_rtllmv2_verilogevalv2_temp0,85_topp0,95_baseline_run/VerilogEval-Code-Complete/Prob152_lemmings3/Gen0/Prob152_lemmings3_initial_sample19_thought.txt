Model the Lemming behaviour as a Moore FSM with four main states: WALK_LEFT, WALK_RIGHT, FALLING, and DIGGING. The state encoding will reflect the walking direction and action (falling or digging). On asynchronous positive edge reset, initialize to WALK_LEFT.

Transitions priority on each clock cycle:
1. If not on ground (ground=0), transition to FALLING, remembering direction before falling.
2. Else if dig=1 and currently walking on ground, transition to DIGGING.
3. Else if bumped (bump_left or bump_right) and walking (not falling or digging), switch walking direction.
4. If currently FALLING and ground=1, return to walking state with saved direction.
5. If DIGGING and ground=0, transition to FALLING with saved direction.

Outputs are derived from the current state:
- walk_left = 1 if in WALK_LEFT, FALLING or DIGGING with left direction.
- walk_right = 1 if in WALK_RIGHT, FALLING or DIGGING with right direction.
- aaah = 1 if in FALLING.
- digging = 1 if in DIGGING.

Bumping or digging inputs are ignored during FALLING or DIGGING states.
The direction during FALLING or DIGGING is saved when entering those states to be restored later.
