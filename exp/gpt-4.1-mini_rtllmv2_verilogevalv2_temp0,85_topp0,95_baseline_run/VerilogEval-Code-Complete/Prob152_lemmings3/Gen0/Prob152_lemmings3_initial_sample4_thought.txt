We need a Moore FSM with states encoding the Lemming's current activity and direction: walking_left, walking_right, falling_left, falling_right, digging_left, digging_right.

Outputs depend solely on the current state.

Transitions:
- On reset, go to walking_left.
- If ground=0 (no ground), Lemming falls, state changes to falling in the current direction.
- If falling and ground=1, revert to walking in the previous direction.
- If walking and dig=1 and ground=1, start digging in current direction.
- If digging and ground=0, start falling in current direction.
- When walking and bumped (bump_left or bump_right), switch walking direction.
- Bumps during falling/digging have no effect.
- fall > dig > bump order of precedence.
  
Outputs:
- walk_left = 1 when walking_left or digging_left.
- walk_right = 1 when walking_right or digging_right.
- aaah = 1 when falling (either direction).
- digging = 1 when digging.

Use a synchronous process triggered on clk and asynchronous active-high reset areset for state updates.
