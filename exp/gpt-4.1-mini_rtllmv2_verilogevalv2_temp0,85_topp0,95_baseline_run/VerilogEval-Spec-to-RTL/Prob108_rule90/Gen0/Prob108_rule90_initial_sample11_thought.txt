Implement a 512-bit register q to hold the current state of the 512 cells. On each clock edge:
- If load is high, load q with the provided 512-bit data input.
- Otherwise, update each bit of q to be the XOR of its left and right neighbors from the previous state.
Boundary conditions q[-1] and q[512] are zero. This can be handled by appending zero bits on both ends when calculating the next state.
