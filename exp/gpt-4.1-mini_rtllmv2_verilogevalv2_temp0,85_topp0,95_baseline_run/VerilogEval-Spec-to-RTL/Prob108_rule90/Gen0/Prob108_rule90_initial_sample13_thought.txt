Implement a 512-bit register q that holds the current state of the cellular automaton. On a positive clock edge, if load is high, load q with the input data. Otherwise, update q according to Rule 90: each bit's next state is the XOR of its left and right neighbors. For boundary bits, assume neighbors outside the range are zero. This can be efficiently done by shifting q left and right, XORing the two results, and assigning it back to q.
