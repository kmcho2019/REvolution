Implement a 512-bit shift register representing the cellular automaton state q. On the positive edge of clk, if load is high, load q with input data. Otherwise, update q according to Rule 90: each bit q[i] is replaced by the XOR of q[i-1] and q[i+1], with the boundary bits q[-1] and q[512] considered zero. This can be done by concatenating zeros at both ends and XORing shifted versions to get the next state.
