Implement a 512-bit shift register representing the cellular automaton state, stored in a register q. On a load signal, load q with the input data. On each clock cycle without load, update each bit of q based on Rule 90: the next state of bit i is the XOR of its left and right neighbors. The boundary bits outside the array are assumed to be zero, so for q[0], left neighbor is 0, for q[511], right neighbor is 0. The update is synchronous on the rising edge of clk.
