Implement a 512-bit register q to hold the current state. On each positive clock edge, if load is high, load q with data input. Otherwise, update q based on Rule 90: each bit q[i] in the next state is the XOR of q[i-1] and q[i+1], with boundary bits q[-1] and q[512] assumed zero. This requires careful handling of the boundary conditions for bits 0 and 511.
