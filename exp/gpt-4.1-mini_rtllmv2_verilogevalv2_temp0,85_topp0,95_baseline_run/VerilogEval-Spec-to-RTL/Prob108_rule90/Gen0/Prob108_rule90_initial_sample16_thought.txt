Implement a 512-bit register to hold the current state `q`. On the positive clock edge, if `load` is high, load the input `data` into `q`. Otherwise, update `q` according to Rule 90: each cell's next state is the XOR of its left and right neighbors, considering boundary neighbors as zero. Specifically, for each bit i in [0..511], `q_next[i] = q[i-1] ^ q[i+1]` with `q[-1] = 0` and `q[512] = 0`.
