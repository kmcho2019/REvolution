Implement a 512-bit register q to hold the current state. On each positive clock edge:
- If load is high, load q with the input data.
- Otherwise, update q according to Rule 90: each bit q[i] gets the XOR of its two neighbors q[i-1] and q[i+1].
- For boundaries, q[-1] and q[512] are zero.
This means q[i]_next = q[i-1] ^ q[i+1], with boundary bits treated as 0.
