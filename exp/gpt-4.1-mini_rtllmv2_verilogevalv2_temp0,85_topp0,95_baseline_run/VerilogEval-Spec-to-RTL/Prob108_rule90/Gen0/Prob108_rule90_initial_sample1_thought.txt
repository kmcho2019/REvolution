Implement a 512-bit register q to hold the current state of the cellular automaton. On each positive clock edge, if load is high, load the input data into q. Otherwise, update q according to Rule 90: for each bit i, q_next[i] = q[i-1] XOR q[i+1], with boundary bits outside the range assumed zero. Implement this by concatenating zeros on both sides of q and shifting to get left and right neighbors for XOR.
