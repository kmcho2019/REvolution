Implement a 512-bit register q to hold the cellular automaton state. On each clock's positive edge, if load is high, load q with the input data. Otherwise, update q according to Rule 90: each bit in the next state is the XOR of its left and right neighbors in the current state, with boundary neighbors assumed zero. Specifically, next_q[i] = q[i-1] ^ q[i+1], where q[-1] and q[512] are zero. Use a combinational logic to compute the next state from current q before updating q at the clock edge.
