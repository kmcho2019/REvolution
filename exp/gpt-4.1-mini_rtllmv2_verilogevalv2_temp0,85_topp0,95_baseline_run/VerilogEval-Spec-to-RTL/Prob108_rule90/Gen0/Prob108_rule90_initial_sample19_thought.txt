Implement a 512-bit register q to hold the current state of the cellular automaton. On each positive clock edge, if load is asserted, load q with the input data. Otherwise, update q using Rule 90: the next state of each cell is the XOR of its left and right neighbors, considering the boundary neighbors as zero. For q[0], the left neighbor is 0 and the right neighbor is q[1]; for q[511], the right neighbor is 0 and the left neighbor is q[510]. For all other cells, next state is q[i-1] ^ q[i+1].
