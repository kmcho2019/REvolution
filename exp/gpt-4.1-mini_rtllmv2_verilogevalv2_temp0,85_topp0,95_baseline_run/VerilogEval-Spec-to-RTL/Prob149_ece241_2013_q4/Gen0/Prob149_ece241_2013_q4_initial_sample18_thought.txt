Implement a state machine that tracks the current water level based on the sensor inputs s[2:0]. On each clock, determine the current water level state based on sensor assertions: 
- Above s[2]: all three sensors asserted (111)
- Between s[2] and s[1]: s[0] and s[1] asserted, s[2] deasserted (011)
- Between s[1] and s[0]: only s[0] asserted (001)
- Below s[0]: none asserted (000)

Keep track of the previous water level state (before the last sensor change) to determine if the level is rising or falling. The "previous to the last sensor change" means we update this previous state only when the sensor input changes to a different water level.

Outputs (fr0, fr1, fr2, dfr) are set according to the current water level state and whether the previous level was lower than the current level (rising). On rising, open the supplemental flow valve dfr; otherwise, dfr=0.

Reset initializes the state to "Below s[0]" condition (no sensors asserted, all outputs asserted).

The logic steps:
1. Decode s to water level state.
2. If water level changed, update previous water level state.
3. Set outputs according to the table and whether level is rising.

Water level state encoding:
0 = Below s[0] (no sensors)
1 = Between s[1] and s[0] (only s[0])
2 = Between s[2] and s[1] (s[0] and s[1])
3 = Above s[2] (all three sensors)

Outputs based on state:
- 3 (Above s[2]): fr0=0, fr1=0, fr2=0, dfr=0
- 2 (Between s[2] and s[1]): fr0=1, fr1=0, fr2=0, dfr depends on rising
- 1 (Between s[1] and s[0]): fr0=1, fr1=1, fr2=0, dfr depends on rising
- 0 (Below s[0]): fr0=1, fr1=1, fr2=1, dfr depends on rising

dfr=1 if level rising (previous level < current level), else 0.

Note: previous level updated only when water level changes.

Implement synchronous reset.
