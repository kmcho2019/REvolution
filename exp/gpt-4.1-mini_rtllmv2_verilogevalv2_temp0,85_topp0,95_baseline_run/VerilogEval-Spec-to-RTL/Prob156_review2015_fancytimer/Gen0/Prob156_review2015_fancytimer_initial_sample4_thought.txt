Implement a finite state machine (FSM) with states: SEARCH (looking for pattern 1101), SHIFT_DELAY (shifting in 4 bits of delay), COUNTING (counting down timer cycles), DONE (asserting done and waiting for ack). Use a 4-bit shift register to detect the pattern and then shift in the delay bits MSB first. After loading delay, start a cycle counter counting (delay+1)*1000 clock cycles, also calculate and output the current remaining time in terms of delay units that decrement every 1000 cycles. When counting finishes, assert done and wait for ack before returning to SEARCH. Synchronous active-high reset initializes to SEARCH state.
