Implement a finite state machine with the following states: SEARCH, READ_DELAY, COUNTING, DONE. 

- In SEARCH state, shift in input bits and detect the pattern 1101 in a 4-bit shift register.
- Upon detecting 1101, transition to READ_DELAY where the next 4 bits are shifted in as delay[3:0], MSB first.
- Then transition to COUNTING where a cycle counter counts (delay+1)*1000 clock cycles, and a 4-bit count output decrements every 1000 cycles from delay down to 0.
- After counting completes, transition to DONE where the done output is asserted, and the module waits for ack=1 to return to SEARCH state.
- The counting output is asserted only during COUNTING state.
- The synchronous reset initializes the state machine and registers.
