Implement a finite state machine with the following states:

1. SEARCH: Shift in serial bits to detect the pattern 1101. Use a 4-bit shift register for comparison.
2. LOAD_DELAY: After detecting 1101, shift in 4 more bits MSB first into delay[3:0].
3. COUNTING: Count down from delay to 0, each count lasting 1000 clock cycles. During each 1000-cycle interval, output current count value on count[3:0]. Assert counting=1.
4. DONE: After counting reaches 0, assert done=1 and wait for ack=1 input before returning to SEARCH.

Use synchronous reset. Use counters to track 1000 clock cycles per unit count. The 'count' output reflects the current remaining delay value during counting; otherwise, it can be any value. Ignore input data while counting and done.

Implement outputs and state transitions accordingly.
