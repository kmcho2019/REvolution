Implement a synchronous FSM with states: SEARCH (looking for pattern 1101), SHIFT_DELAY (shift in 4 bits of delay), COUNTING (count down the timer cycles), DONE (assert done and wait for ack). Use a 4-bit shift register to detect the pattern 1101. Once detected, shift in 4 bits for delay MSB first, then start counting for (delay+1)*1000 cycles. During counting, count cycles and also update the count output to show the current remaining time from delay down to 0, each held for 1000 cycles. After counting, assert done and wait for ack to restart the sequence. The counting output is asserted only during counting; otherwise, done is asserted when waiting for ack, and count is don't care (held at zero here for convenience).
