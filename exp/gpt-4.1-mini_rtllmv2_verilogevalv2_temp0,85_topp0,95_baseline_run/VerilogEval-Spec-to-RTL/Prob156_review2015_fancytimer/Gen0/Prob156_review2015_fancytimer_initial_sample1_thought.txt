Implement a finite state machine with these states: SEARCH (looking for pattern 1101), SHIFT_DELAY (shift in 4 bits of delay), COUNT (counting down the delay * 1000 cycles), DONE (assert done and wait for ack). Use a shift register to detect the pattern 1101 on incoming data. After detecting 1101, shift in 4 delay bits (MSB first). Then start counting down cycles with a counter that counts 1000 clock cycles per delay count. The output count shows the current remaining delay value. When counting finishes, assert done and wait for ack before returning to SEARCH. Use synchronous reset and positive clock edge triggers.
