Implement a synchronous FSM with these states:
- SEARCH: shift in bits to detect pattern 1101 in the last 4 bits.
- READ_DELAY: shift in 4 bits of delay value MSB first.
- COUNTING: count down (delay+1)*1000 cycles, output count = remaining delay value (updated every 1000 cycles), assert counting=1.
- DONE: counting finished, assert done=1, wait for ack=1 to return to SEARCH.

Use a 4-bit shift register to detect pattern 1101. Once detected, transition to READ_DELAY to shift in 4 delay bits. Then load a 20-bit counter to (delay+1)*1000 and count down every clock. Every 1000 cycles decrement the remaining delay count. When count reaches zero, go to DONE. Wait for ack to go back to SEARCH. Outputs are assigned based on state. Synchronous reset resets state and registers.

Because count output is only valid in COUNTING state, assign count = remaining delay counter (0 to delay) during counting, don't care otherwise.

The 1000 cycle timing can be done by a sub-counter counting 0 to 999 clocks to decrement the delay count.

All logic synchronous on posedge clk, with synchronous reset.

This FSM and counters meet the requirements.
