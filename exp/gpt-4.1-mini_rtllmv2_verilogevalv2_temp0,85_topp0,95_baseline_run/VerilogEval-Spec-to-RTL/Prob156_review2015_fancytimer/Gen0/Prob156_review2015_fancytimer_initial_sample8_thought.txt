Implement a finite state machine with these states: SEARCH (look for pattern 1101), LOAD_DELAY (shift in 4 bits MSB first), COUNT (count down the timer), DONE (assert done and wait for ack). Use a 4-bit shift register or a 4-bit pattern detector to find 1101. After detection, shift in the next 4 bits to get delay. Start counting (delay+1)*1000 cycles, decrementing the count output every 1000 cycles. When counting is done, assert done and wait for ack. Reset on reset signal or after ack received to start over.
