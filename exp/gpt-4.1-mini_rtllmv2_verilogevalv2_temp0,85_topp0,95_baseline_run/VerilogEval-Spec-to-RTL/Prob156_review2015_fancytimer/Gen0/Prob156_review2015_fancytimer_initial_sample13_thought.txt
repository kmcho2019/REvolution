Implement a finite state machine with the following states:

- SEARCH: Look for the 1101 pattern by shifting in data bits and comparing.
- LOAD_DELAY: Shift in next 4 bits, MSB first, into delay register.
- COUNTING: Count down from delay to 0, each count lasting 1000 clock cycles. Output counting=1 and current count.
- DONE: Assert done=1, wait for ack=1 to reset and return to SEARCH.

Maintain a 4-bit shift register for pattern detection and a 4-bit delay register. Use a 10-bit cycle counter to count 1000 clock cycles per delay count. The count output shows the current delay count during counting, else don't-care. Synchronous reset initializes all registers and state to SEARCH.

The design is fully synchronous with no asynchronous resets.
