Implement a finite state machine (FSM) with the following states: SEARCH (looking for pattern 1101), SHIFT_DELAY (shift in 4 bits MSB first for delay), COUNTING (count down timer), DONE (assert done and wait for ack). Use a 4-bit shift register to detect the pattern 1101 during SEARCH state. When detected, transition to SHIFT_DELAY to shift in the next 4 bits as delay. Then, in COUNTING state, count down (delay+1)*1000 cycles, decrementing a time counter every 1000 cycles and outputting the current remaining time on count. When countdown finishes, transition to DONE state and assert done output until ack input is high, then reset FSM to SEARCH state. Counting output is asserted only in COUNTING state. Synchronous reset is used to reset all registers and FSM to SEARCH state.
