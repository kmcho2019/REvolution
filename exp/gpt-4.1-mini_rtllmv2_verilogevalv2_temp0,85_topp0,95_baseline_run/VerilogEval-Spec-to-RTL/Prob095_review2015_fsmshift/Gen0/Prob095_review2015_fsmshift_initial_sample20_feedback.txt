```verilog
typedef enum logic [0:0] {
    ACTIVE = 1'b0,
    IDLE   = 1'b1

```

In SystemVerilog, the use of a typedef enum with `logic` and explicit values is valid, but in Verilog-2001 or if the simulator does not fully support SystemVerilog features, this will cause errors during elaboration, especially if the tool expects explicit casts when assigning or comparing between enum variables and logic values.

The error indicates that the line:

```verilog
state <= ACTIVE;
```

or

```verilog
(state == ACTIVE)
```

requires an explicit cast to/from the enum type, which is missing.
