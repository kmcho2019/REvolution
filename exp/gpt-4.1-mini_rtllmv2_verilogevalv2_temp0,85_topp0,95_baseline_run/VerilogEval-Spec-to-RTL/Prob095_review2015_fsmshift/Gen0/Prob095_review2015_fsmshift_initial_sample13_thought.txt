Implement a synchronous resettable FSM with a 2-state approach: upon reset, assert shift_ena for 4 clock cycles, then deassert it forever until next reset. Use a 3-bit counter to count the 4 cycles. The counter increments on each clock when enabled; once it reaches 4, shift_ena is deasserted. Because there is no input for the "proper bit pattern" detection, the module behavior is limited to reset-triggered enablement only.
