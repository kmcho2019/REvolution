Implement a simple FSM with two states: an initial state after reset where shift_ena is asserted for exactly 4 clock cycles, then transitions to an idle state where shift_ena stays low indefinitely. Use a counter to track the 4 clock cycles of shift_ena asserted. Since reset is synchronous and active high, on reset, set the state to initial and counter to 4. Each clock cycle, if in the initial state and counter > 0, keep shift_ena high and decrement counter. When counter reaches 0, move to idle state and keep shift_ena low.
