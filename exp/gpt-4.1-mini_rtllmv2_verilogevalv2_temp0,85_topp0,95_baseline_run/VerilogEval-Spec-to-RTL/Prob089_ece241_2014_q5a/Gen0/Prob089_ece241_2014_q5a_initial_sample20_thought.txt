The 2's complement of a binary number can be computed by scanning from LSB to MSB, copying bits until the first '1' is encountered, then inverting all subsequent bits. We implement this with a Moore FSM with two states: COPY (before first '1'), and INVERT (after first '1'). The input x is processed serially each clock cycle starting from LSB after reset is released. The output z depends only on the current state and input. On areset asserted, we reset to COPY state. When areset is released, we start processing bits. The output z is updated accordingly each cycle. The FSM is clocked on posedge clk with asynchronous posedge reset.
