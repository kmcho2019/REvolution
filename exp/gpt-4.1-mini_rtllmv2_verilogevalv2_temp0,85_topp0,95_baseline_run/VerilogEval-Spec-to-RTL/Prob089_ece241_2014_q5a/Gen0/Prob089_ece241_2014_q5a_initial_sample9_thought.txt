The 2's complement of a binary number is obtained by inverting all bits after the first '1' (from LSB side) and keeping bits unchanged up to and including the first '1'. Since the input bits arrive serially from LSB to MSB, the Moore machine can track whether the first '1' has been seen. Before the first '1' is seen, output the input bit as is. After the first '1' is seen, output the inverted input bits. 

The FSM states can be:
- STATE_NO_ONE: first '1' not yet seen
- STATE_AFTER_ONE: first '1' has been seen

At reset, go to STATE_NO_ONE. On each clock cycle, based on input x and current state, output z accordingly.

Because it's a Moore machine, outputs depend only on the current state, so output logic is defined per state and input. But since output depends on input too, the output can be defined as a function of state and input.

We will implement:
- Asynchronous active-high reset (areset)
- On positive clock edge, update state
- Output combinationally from state and input

This will produce serial 2's complement output bits as input bits stream in from LSB to MSB.
