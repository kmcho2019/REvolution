The 2's complement operation can be implemented by a simple Moore FSM that passes input bits until the first '1' is encountered, and then inverts all subsequent bits. This is because to get the 2's complement, you copy all bits from the LSB up to and including the first '1' unchanged, then invert the remaining bits.

We will design a Moore FSM with two states:

- S0: Haven't seen the first '1' bit yet; output equals input bit (pass-through).
- S1: After seeing the first '1'; output equals inverted input bit.

The transition is from S0 to S1 upon seeing x==1, else remain in S0.

On asynchronous reset (active high), the FSM goes back to S0.

Because it's a Moore machine, output depends only on state (not directly on input). But since the output depends on input in state S0 (output = input) and state S1 (output = ~input), we can implement output as a function of state and input.

The output logic:

- If in S0: output z = x
- If in S1: output z = ~x

Implementation steps:

- Use asynchronous reset to set state to S0.
- On each clock posedge, update state according to x.
- Output z depends on state and input x.
