To implement a one-input one-output serial 2's complementer as a Moore state machine, we use two states: BEFORE_CARRY and AFTER_CARRY. Initially, after reset is released, the FSM waits for the first bit (LSB) of the input number and outputs it directly (since 2's complement starts by copying bits until the first '1' is encountered). Once the first '1' is found, the machine moves to AFTER_CARRY state, where it outputs the inverted bits of the remaining input bits to complete the 2's complement operation. The output depends only on the current state (Moore machine). The machine processes bits serially on each clock cycle, the conversion starts after reset is released and stops when reset is asserted again.

States:
- BEFORE_CARRY: output z = x, transition to AFTER_CARRY on x=1
- AFTER_CARRY: output z = ~x

Reset (asynchronous active high) initializes the FSM to BEFORE_CARRY state and output z=0.
