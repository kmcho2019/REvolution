To design a Moore machine that outputs the 2's complement of an input bitstream, starting from the least significant bit (LSB), we leverage the fact that the 2's complement can be generated by copying bits up to and including the first '1' bit from LSB, then inverting all subsequent bits.

The state machine will have two states:
- S0: Haven't found the first '1' yet; output z = x (copy input).
- S1: Found the first '1'; output z = ~x (invert input).

On reset (areset asserted), the state machine resets to S0.

On each clock cycle:
- If in S0 and x == 1, transition to S1.
- Else remain in the current state.

Output z depends only on the current state and input x, consistent with Moore machine output (output depends on state, but since here output depends on state and input, we can treat output as combinational logic depending on state and input).

Since this is a Moore machine and output should depend only on state, we need to produce output z based solely on the state, which means we must hold input x in a register or delay it by one cycle. However, because the output for the LSB depends on input x, the simplest solution is to treat the output as combinational logic dependent on state and input, given the problem scope (a serial 2's complementer).

Alternatively, we can treat the output as a Moore output if we define the output on transitions accordingly, but the problem explicitly states a Moore machine. So to strictly comply, we can register input x to produce output in the next cycle. This incurs a one cycle delay which is acceptable.

So, we'll implement:

- state register with two states S0 and S1.
- input x register to delay input by one cycle.
- output z depending only on state and the delayed input.

The output logic:
- If state == S0, z = delayed_x (copy input).
- Else (S1), z = ~delayed_x (invert input).

On asynchronous reset (active high areset), state is set to S0.

The conversion runs as long as reset is not asserted, stops when reset asserted.
