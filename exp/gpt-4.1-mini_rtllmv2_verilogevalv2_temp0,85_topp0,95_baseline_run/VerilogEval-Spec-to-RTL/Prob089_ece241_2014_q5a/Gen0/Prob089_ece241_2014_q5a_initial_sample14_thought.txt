The 2's complement of a binary number can be formed by scanning bits from LSB to MSB, copying input bits until the first '1' is seen, then inverting the remaining bits. This suggests a Moore FSM with two states:

- STATE_COPY: before the first '1' is encountered, output z = x (copy input bits).
- STATE_INVERT: after the first '1' is encountered, output z = ~x (invert input bits).

On reset (areset asserted), the FSM resets to STATE_COPY. When reset is released, the FSM begins processing bits serially on each clock edge.

Output depends only on the current state and input (Moore output).

Implementation details:
- Define two states.
- Use synchronous logic with asynchronous reset.
- Output z is registered according to the Moore FSM output logic.

This FSM will accept an arbitrarily long serial input and output the 2's complement bits serially.
