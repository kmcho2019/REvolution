The two's complement of a binary number can be generated by scanning the bits from least significant to most significant bit, copying the bits until the first '1' is encountered, then inverting all subsequent bits. To implement this serially in a Moore FSM, we need two states: BEFORE_ONE (copy input bits as is until the first '1' bit is seen), and AFTER_ONE (invert input bits). On reset (asynchronous, active high), the state machine resets to BEFORE_ONE state. On each clock cycle, output z depends only on the current state and input x. The output is updated on the clock's positive edge, and the reset is asynchronous and active high.
