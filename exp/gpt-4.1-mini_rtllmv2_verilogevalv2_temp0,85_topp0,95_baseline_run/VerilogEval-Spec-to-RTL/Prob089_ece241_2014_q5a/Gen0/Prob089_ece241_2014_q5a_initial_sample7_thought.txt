The task is to design a Moore FSM that takes a serial input number (starting from LSB) and outputs its 2's complement serially. The 2's complement of a binary number can be found by first passing through the bits unchanged until the first '1' is encountered (this '1' is the least significant 1 in the number), then inverting all subsequent bits.

So the FSM will have two states:
- STATE_WAITING: Before we encounter the first '1', output bits are the same as input bits.
- STATE_INVERT: After the first '1' is seen, output bits are inverted.

The FSM resets asynchronously on areset. When areset is asserted, output z=0 and state = STATE_WAITING (ready to process a new number). When areset is deasserted, the FSM begins processing input bits.

Because it's a Moore machine, output depends only on the state (and input for next state logic). But here, output depends on the state and the input bit. So output can be generated by checking the state and input:

- If in STATE_WAITING: output = input x
- If in STATE_INVERT: output = ~x

On each clock, if reset is active, we reset state to STATE_WAITING, else if in STATE_WAITING and input x=1, we move to STATE_INVERT, otherwise remain.

We implement the module with asynchronous reset on positive edge of clock and provide output z accordingly.
