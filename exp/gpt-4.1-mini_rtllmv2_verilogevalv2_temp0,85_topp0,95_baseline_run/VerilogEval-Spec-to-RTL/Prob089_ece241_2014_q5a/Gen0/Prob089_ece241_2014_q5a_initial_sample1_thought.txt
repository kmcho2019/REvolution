The 2's complement of a binary number can be computed by scanning from LSB to MSB: copy input bits unchanged until the first '1' bit is encountered, then invert all subsequent bits. This behavior fits a Moore FSM with two states: BEFORE_ONE (copy input) and AFTER_ONE (invert input). On reset, the FSM goes to BEFORE_ONE state. On each clock cycle, output z depends only on the current state and input x. The FSM stops processing when reset is asserted. The output is registered to be synchronous with the clock.
