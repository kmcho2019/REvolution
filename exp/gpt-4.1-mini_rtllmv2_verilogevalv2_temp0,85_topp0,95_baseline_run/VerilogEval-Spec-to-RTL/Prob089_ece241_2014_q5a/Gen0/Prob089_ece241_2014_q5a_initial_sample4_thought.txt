To implement a 2's complementer for a serial input number (LSB first), we use a Moore machine with two states: before complementing and after complementing. The algorithm for 2's complement is to copy bits until the first '1' is encountered, then invert all following bits. 

States:
- STATE_COPY (before first 1): output bit equals input bit
- STATE_INVERT (after first 1): output bit equals inverted input bit

Transitions:
- Initially in STATE_COPY after reset.
- When x=1 in STATE_COPY, move to STATE_INVERT.
- Otherwise remain in the current state.

On each clock cycle:
- Output is determined by current state and input x.
- If reset is asserted, state returns to STATE_COPY.

This design accepts arbitrarily long input streams starting after reset release, and outputs the 2's complement bits serially.

The module uses asynchronous active-high reset areset.
