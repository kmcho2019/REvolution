The 2's complement of a binary number can be obtained by scanning the bits from the least significant bit (LSB) to the most significant bit (MSB) and copying the bits until the first '1' is encountered; the first '1' is also copied, and all subsequent bits are inverted. 

This behavior naturally fits a Moore state machine with two states:
- STATE_COPY: output z = x, remain in this state until x == 1 (the first '1' bit).
- STATE_INVERT: output z = ~x, once the first '1' has been output, keep in this state.

The state machine starts after reset is deasserted and stops processing when reset is asserted again. The reset is asynchronous and active high.

Implementation details:
- Asynchronous reset: On areset asserted, state resets to STATE_COPY.
- On each positive clock edge and areset deasserted, transition according to input.
- Output z depends only on the current state and input x.

The module continuously processes input bits serially, outputting their 2's complement bit serially.
