Implement a Moore FSM that computes the 2's complement of a serial input stream bit by bit starting from the least significant bit. The 2's complement operation is done by first copying bits until the first '1' bit is encountered, then inverting all subsequent bits. The FSM will have two states: BEFORE_ONES (copying input to output until first '1') and AFTER_ONES (inverting input bits). The output z depends only on the current state and input, making it a Moore machine. On asynchronous reset (areset asserted), the FSM resets to BEFORE_ONES state. When reset is released, the machine starts processing new input bits. The output z is updated on each clock cycle according to the current state and input x.
