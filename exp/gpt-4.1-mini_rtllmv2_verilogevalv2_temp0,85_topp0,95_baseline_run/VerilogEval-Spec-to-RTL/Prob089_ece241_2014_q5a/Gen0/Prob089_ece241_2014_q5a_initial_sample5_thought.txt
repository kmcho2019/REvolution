The 2's complement of a binary number can be obtained by scanning bits from LSB to MSB and flipping bits after the first '1' is encountered. Since input bits come LSB first, we can design a Moore FSM with two states: BEFORE_ONE (haven't seen the first '1') and AFTER_ONE (have seen it). Initially, output equals input until the first '1' is seen, then output bits are inverted. On areset (asynchronous active high reset), the FSM resets to BEFORE_ONE and output zero. The machine processes one input bit per clock cycle and outputs corresponding 2's complement bit accordingly.
