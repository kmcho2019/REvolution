The module implements a Moore FSM for bitwise two's complement on a serial input stream of arbitrary length bits, starting from LSB. The two's complement is obtained by:
1. Copying all bits up to and including the first '1' bit (least significant 1) from input to output.
2. After the first '1' bit is encountered, output the bitwise inverted value of the remaining bits.

The FSM states are:
- IDLE: Waiting for reset to be released.
- COPY: Copying bits until the first '1' is seen.
- INVERT: Inverting bits after the first '1'.

The machine resets asynchronously on areset (active high), and conversion begins when reset is released. While reset is asserted, output z is zero.

The FSM transitions:
- After reset is released, go to COPY state.
- In COPY, if input bit x==1, output 1 and move to INVERT.
- Else, output x and remain in COPY.
- In INVERT, output inverted x.

All outputs depend only on the current state and input (Moore machine output depends only on the state, so output is registered before state transition).

We implement output z registered synchronously on clock with asynchronous reset, output depends on state and input.
