Implement a 2-bit saturating counter with asynchronous positive edge reset. On each positive clock edge, if train_valid is high, increment the counter if train_taken is 1 (but saturate at 3), else decrement if train_taken is 0 (but saturate at 0). If train_valid is 0, hold the current counter value. Asynchronous reset sets the counter to 2'b01 (weakly not-taken).
