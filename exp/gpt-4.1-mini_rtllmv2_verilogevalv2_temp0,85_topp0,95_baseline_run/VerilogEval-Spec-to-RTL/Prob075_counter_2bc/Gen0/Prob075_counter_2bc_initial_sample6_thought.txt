Implement a 2-bit saturating counter with asynchronous positive edge reset. On each positive clock edge, if areset is asserted, reset the counter to 2'b01. Otherwise, if train_valid is 1, increment the counter if train_taken=1 (up to 3), decrement if train_taken=0 (down to 0). If train_valid=0, hold the current value. Output the counter as state.
