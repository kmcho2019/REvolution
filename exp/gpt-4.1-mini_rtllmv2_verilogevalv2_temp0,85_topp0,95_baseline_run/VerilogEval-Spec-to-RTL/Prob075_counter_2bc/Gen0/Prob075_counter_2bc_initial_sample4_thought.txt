Implement a 2-bit saturating counter with asynchronous positive edge reset. On posedge clk, if train_valid=1, increment the counter if train_taken=1 (saturate at 3), else decrement the counter if train_taken=0 (saturate at 0). If train_valid=0, hold the current value. On posedge areset, reset the counter to 2'b01 (weakly not-taken).
