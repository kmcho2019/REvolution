Implement a 2-bit saturating counter with asynchronous positive-edge reset to 2'b01.
On each positive clock edge, if train_valid is asserted, increment the counter if train_taken is 1 (up to 3), decrement if train_taken is 0 (down to 0), else hold the value.
The asynchronous reset triggers on the positive edge of areset and sets counter to 2'b01.
Output the current counter value as state.
