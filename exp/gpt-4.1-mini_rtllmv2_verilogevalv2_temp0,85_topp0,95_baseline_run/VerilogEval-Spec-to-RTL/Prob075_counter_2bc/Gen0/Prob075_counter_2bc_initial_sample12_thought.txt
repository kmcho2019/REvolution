Implement a 2-bit saturating counter with asynchronous active-high reset (areset).
On the positive edge of clk, if areset is asserted, reset the counter to 2'b01 (weakly not-taken).
Otherwise, if train_valid is high, increment the counter if train_taken is 1, saturating at 3,
or decrement if train_taken is 0, saturating at 0. If train_valid is 0, hold the current value.
Output the current counter value on state.
