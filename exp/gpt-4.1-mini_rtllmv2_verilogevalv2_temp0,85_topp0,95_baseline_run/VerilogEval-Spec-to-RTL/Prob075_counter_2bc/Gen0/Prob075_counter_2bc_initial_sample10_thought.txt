Implement a 2-bit saturating counter with asynchronous active-high reset (areset). On the positive edge of clk or areset, if areset is asserted, reset the counter to 2'b01. Otherwise, if train_valid is high, increment the counter if train_taken is 1 (but saturate at 3), or decrement if train_taken is 0 (but saturate at 0). If train_valid is 0, keep the current counter value. Output the current counter value on state.
