Implement a 2-bit saturating counter with asynchronous active-high reset. On the positive edge of clk, if areset is asserted, set the counter to 2'b01. Otherwise, if train_valid is 1, increment the counter if train_taken is 1 (max 3), decrement if train_taken is 0 (min 0), else hold the current value. Output the counter state on state[1:0].
