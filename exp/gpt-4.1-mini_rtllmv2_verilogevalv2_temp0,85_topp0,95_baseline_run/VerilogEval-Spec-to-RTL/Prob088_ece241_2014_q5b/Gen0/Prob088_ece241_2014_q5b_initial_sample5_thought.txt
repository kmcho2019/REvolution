Implement a one-hot encoded Mealy FSM with two states: A and B. The reset (areset) is asynchronous and active-high, forcing the state into A. On each positive clock edge, if not in reset, the FSM transitions and outputs according to the input x. State A is encoded as 2'b01, state B as 2'b10. The output z depends on the current state and input x according to the given transitions.
