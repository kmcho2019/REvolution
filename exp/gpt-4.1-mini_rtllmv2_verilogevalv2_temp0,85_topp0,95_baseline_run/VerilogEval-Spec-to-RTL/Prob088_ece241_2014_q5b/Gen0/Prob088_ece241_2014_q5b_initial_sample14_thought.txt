Implement the Mealy FSM with two states (A and B) encoded one-hot as a 2-bit register: A=2'b01, B=2'b10.
The asynchronous active-high reset sets state to A.
The next state and output logic depend on current state and input x as described.
Sequential logic updates state on posedge clk or async reset.
Output z is combinational, dependent on current state and input x.
