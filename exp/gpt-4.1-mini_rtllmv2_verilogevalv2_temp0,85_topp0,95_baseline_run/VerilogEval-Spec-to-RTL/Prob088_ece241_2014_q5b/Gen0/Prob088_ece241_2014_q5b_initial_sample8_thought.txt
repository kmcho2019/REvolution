Implement a Mealy FSM with two states (A and B) using one-hot encoding (2 bits, each representing a state). On asynchronous active-high reset, the FSM goes to state A. The next state and output z are determined combinationally based on the current state and input x. The sequential block updates the state on the positive clock edge or resets asynchronously. The output z depends on both the current state and input x as specified.
