Implement a one-hot encoded Mealy FSM with two states A and B as follows:
- Use two flip-flops for state encoding: A = 2'b01, B = 2'b10
- Asynchronous active-high reset to state A
- On each positive clock edge, transition states based on input x
- Output z depends on current state and input x as specified
- State transitions:
   A: if x=0 stay A (z=0), if x=1 go to B (z=1)
   B: if x=0 stay B (z=1), if x=1 stay B (z=0)
