The output q is a 16-bit value that depends only on the 3-bit input a. From the given waveform, we can extract the mapping from a to q and implement it as a combinational lookup table. This is essentially a ROM with 8 entries (for a = 0 to 7), each storing a 16-bit value. Unused or unknown values at times before 15ns can be ignored. We will implement the output using a case statement for all 8 possible values of a.
