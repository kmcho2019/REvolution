Implement a Moore FSM with states representing walking left, walking right, falling, and digging. The machine has a direction state (left or right) embedded in the walking and digging states. On reset, the lemming walks left. On each clock edge:
- If ground is 0 and not digging, the lemming falls (aaah=1).
- If digging and ground is still 1, continue digging.
- If digging and ground goes to 0, switch to falling.
- If walking on ground, and dig=1, start digging.
- If walking on ground and bump(s), switch direction.
- Falling ignores bumps and dig signals.
Outputs are assigned based on current state.
Use asynchronous posedge reset to walk left.
