Model the Lemming behavior as a Moore FSM with the following states:
- WALK_LEFT
- WALK_RIGHT
- FALLING
- DIGGING

Transitions on positive clock edge or asynchronous reset (areset):
- On areset, go to WALK_LEFT.
- From WALK states, if ground=0 -> FALLING (highest priority).
- Else if dig=1 and ground=1 -> DIGGING.
- Else if bump_left or bump_right -> switch walking direction.
- From DIGGING, if ground=0 -> FALLING.
- From FALLING, if ground=1 -> return to previous walking state.
- While FALLING or DIGGING, bumps and dig inputs are ignored.
Outputs depend only on state (Moore):
- walk_left=1 in WALK_LEFT
- walk_right=1 in WALK_RIGHT
- aaah=1 in FALLING
- digging=1 in DIGGING

Remember to store the walking direction before falling so we can restore it after.
