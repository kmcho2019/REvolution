Implement a Moore FSM with four states: WALK_LEFT, WALK_RIGHT, FALLING, and DIGGING.

- Reset state is WALK_LEFT.
- While walking left or right (on ground, not falling, not digging):
  - If ground drops (ground=0), transition to FALLING, remember direction.
  - Else if dig=1, start DIGGING in current direction.
  - Else if bumped on left or right, switch walking direction.
- While FALLING:
  - If ground=1, transition back to previous walking direction.
- While DIGGING:
  - If ground=0, transition to FALLING.
  - Else continue DIGGING.
- During FALLING or DIGGING, bumps do not affect direction or state.
- Outputs: walk_left = 1 if in WALK_LEFT, walk_right = 1 if in WALK_RIGHT, aaah = 1 if FALLING, digging = 1 if DIGGING.

State transitions are synchronous on posedge clk, with asynchronous positive edge reset to WALK_LEFT.
