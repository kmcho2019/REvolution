Implement a 16x16 Game of Life on a toroidal grid with synchronous load of the initial state. On each clock edge, if load is high, load the input data into the grid; else compute the next state for each cell based on neighbors. To handle wrapping, calculate neighbors using modular indexing. Represent the grid as a 256-bit vector with rows packed in 16-bit chunks. For each cell, sum its 8 neighbors using wrap-around indices, then apply rules:
- 0 or 1 neighbors: cell becomes 0
- 2 neighbors: cell state unchanged
- 3 neighbors: cell becomes 1
- 4 or more neighbors: cell becomes 0
Update the entire grid in one clock cycle.
