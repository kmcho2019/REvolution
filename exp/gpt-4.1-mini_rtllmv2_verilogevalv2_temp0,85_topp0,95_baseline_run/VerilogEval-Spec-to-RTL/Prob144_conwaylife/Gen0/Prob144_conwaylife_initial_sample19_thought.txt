Implement a 16x16 Game of Life on a toroidal grid using a 256-bit vector to represent the grid.
- On load=1, synchronously load the input data into q.
- On load=0, compute the next state based on neighbors.
- For each cell, count the 8 neighbors using modular wrapping (toroid).
- Apply the rules:
  * 0 or 1 neighbor: next state = 0
  * 2 neighbors: next state = current state
  * 3 neighbors: next state = 1
  * 4+ neighbors: next state = 0
- Use nested loops for clarity in combinational logic to calculate next state.
- Store the next state in a reg and update q on posedge clk.
