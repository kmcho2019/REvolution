Implement a 16x16 Game of Life on a toroidal grid. Use a 256-bit register 'q' to hold the current state. On a rising clock edge, if load is high, load the input data directly into q. Otherwise, compute the next state based on the rules:

For each cell (r,c):
1. Compute the sum of its 8 neighbors with wrap-around addressing.
2. Apply the rules:
   - If neighbors <= 1: cell becomes 0
   - If neighbors == 2: cell stays the same
   - If neighbors == 3: cell becomes 1
   - Else: cell becomes 0

Since this is combinational logic for each cell, implement this by nested loops (generate) for rows and columns. Indexing is done carefully with modulo 16 to wrap around. The data vector layout is q[15:0] = row 0, q[31:16] = row 1, etc., so the bit index is row*16 + col.

After computing the next state for all cells, assign it to q on the next clock edge.

This approach requires some nested generate loops and combinational sum calculation.
