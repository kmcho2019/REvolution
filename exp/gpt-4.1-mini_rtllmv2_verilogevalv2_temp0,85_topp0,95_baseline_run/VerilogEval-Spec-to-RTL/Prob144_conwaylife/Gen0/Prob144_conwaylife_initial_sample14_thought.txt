Implement a 16x16 Game of Life toroidal grid where the state is stored in a 256-bit register `q`. On each clock cycle, if `load` is high, load the input `data` into `q`. Otherwise, compute the next state based on neighbor counts for each cell. Use modular arithmetic for indices to wrap around rows and columns (toroid). For each cell, sum the 8 neighbors, then apply the rules:
- neighbors <=1: cell becomes 0
- neighbors == 2: cell stays the same
- neighbors == 3: cell becomes 1
- neighbors >=4: cell becomes 0
Since we need to process all cells in parallel for the next state, use combinational logic. Because the grid is small, unroll neighbor sums with modular indexing. Finally, update `q` synchronously on clock edge.
