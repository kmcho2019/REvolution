Implement a 16x16 Game of Life on a toroidal grid using a 256-bit register 'q' to store state. On each clock edge:
- If load is high, load input data into q.
- Else, for each cell, count 8 neighbors with wrap-around addressing, apply rules to update cell state.

We'll implement neighbor counting using modular arithmetic for indices with wrap-around. We'll do this combinationally for all cells each clock cycle, then update q synchronously.

The indexing scheme:
- row i: bits [16*(i+1)-1 : 16*i]
- For cell (r,c), neighbors are (r ± 1 mod 16, c ± 1 mod 16), excluding (r,c).

Compute neighbor count for each cell, then apply rules:
- 0-1 neighbors: cell dies (0)
- 2 neighbors: cell keeps state
- 3 neighbors: cell becomes alive (1)
- 4+ neighbors: cell dies (0)

This is implemented in a nested loop in combinational logic. Finally, update q on posedge clk.
