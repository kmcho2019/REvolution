Implement a 16x16 Game of Life on a toroidal grid where the next state is computed every clock cycle. On load, the state is synchronously loaded from the 256-bit input 'data'. Otherwise, compute the next state based on the neighbor count rules. To wrap indices, use modulo 16 arithmetic. Represent the grid as a 2D array internally for clarity, but pack/unpack to 256-bit vector for input/output. Use combinational logic to count neighbors of each cell by examining the 8 neighbors with wrap-around. Then apply the rules to determine the next state of each cell. Update the q register at each clock edge.
