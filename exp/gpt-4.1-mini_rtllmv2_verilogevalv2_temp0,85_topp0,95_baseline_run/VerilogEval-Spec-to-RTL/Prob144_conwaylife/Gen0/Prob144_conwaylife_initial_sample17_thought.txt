Implement a 16x16 Game of Life grid using a 256-bit register. On each clock edge, if load is high, load input data into q. Otherwise, compute next state based on current state q and the neighbor rules with toroidal wrap-around. To compute neighbors for each cell, consider 8 neighbors with wrap-around indexing. For each cell, count the number of alive neighbors (0 to 8), then apply the rules:
- 0 or 1 neighbor: cell becomes 0
- 2 neighbors: cell stays the same
- 3 neighbors: cell becomes 1
- 4 or more neighbors: cell becomes 0
The output q updates every clock cycle with the new state.
