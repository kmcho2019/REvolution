Implement a 16x16 toroidal Game of Life variant using a 256-bit register to store the grid state. On each clock, if load is high, load the input data into q. Otherwise, compute the next state of each cell based on its 8 neighbors (with wrap-around addressing). The neighbor count determines the next cell state by the given rules. To handle wrapping, use modulo arithmetic on indices. The update happens every clock cycle, synchronous with the positive edge.
