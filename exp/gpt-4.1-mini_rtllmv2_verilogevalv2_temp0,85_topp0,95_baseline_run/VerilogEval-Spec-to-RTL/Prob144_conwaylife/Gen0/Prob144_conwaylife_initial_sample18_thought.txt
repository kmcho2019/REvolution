Implement a 16x16 Game of Life on a toroidal grid. The state is stored in a 256-bit register q. On each clock's positive edge, if load is high, load the input data directly into q. Otherwise, calculate the next state for each cell by counting its 8 neighbors on the toroidal grid (wrapping indices around modulo 16). Apply the rules:
- 0-1 neighbors: cell=0
- 2 neighbors: cell stays same
- 3 neighbors: cell=1
- 4+ neighbors: cell=0
This requires careful neighbor indexing with wrap-around. We'll use nested generate loops to create combinational logic for neighbors and next state, then update q sequentially.
