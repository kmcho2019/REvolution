Implement a 16x16 Game of Life on a toroidal grid with synchronous load. 
- Store the current state in a 256-bit register `q`.
- On each clock edge:
  - If load is high, load `data` into `q`.
  - Else compute the next state based on neighbors for each cell.
- To handle toroidal wrapping, use modular arithmetic on row and column indices.
- Extract neighbors by calculating their positions and summing their bits.
- Apply the rules:
  - 0-1 neighbor: cell dies (0)
  - 2 neighbors: cell stays the same
  - 3 neighbors: cell alive (1)
  - >=4 neighbors: cell dies (0)
- Pack the next state for all 256 cells and update `q`.
