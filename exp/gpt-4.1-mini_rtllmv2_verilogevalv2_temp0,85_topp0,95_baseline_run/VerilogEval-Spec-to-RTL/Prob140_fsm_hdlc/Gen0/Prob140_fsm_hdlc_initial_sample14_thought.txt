Implement a Moore FSM with states representing the count of consecutive ones seen so far after a zero or reset. The FSM starts in state S0 (0 consecutive ones). On each clock, it reads the input bit 'in':

- If 'in' is 0, move to S0 (reset consecutive ones count).
- If 'in' is 1, move to next state representing one more consecutive one (S1, S2, ..., S6, S7).

The key states and transitions:

- S5: if next 'in' is 0, this indicates a discard bit (the zero after 5 ones); next cycle disc=1.
- S6: if next 'in' is 0, this indicates a flag (0 after 6 ones, which is 01111110 pattern); next cycle flag=1.
- S7 or more: error condition (7 or more consecutive ones); next cycle err=1.

Outputs are registered and asserted for a full cycle starting one cycle after detecting the condition, so outputs depend on the previous state and input.

We store current state, next state, and output signals disc, flag, err as registered outputs updated on clock.

Reset synchronously sets state to S0 and clears outputs.

This design ensures correct detection of HDLC framing flags, discard bits, and errors.
