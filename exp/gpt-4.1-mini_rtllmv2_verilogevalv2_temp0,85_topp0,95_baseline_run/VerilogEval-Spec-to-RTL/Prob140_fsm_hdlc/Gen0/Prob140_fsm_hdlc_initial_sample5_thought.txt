Implement a Moore FSM with states representing the count of consecutive 1s seen so far (0 to 6). On each clock cycle, the FSM transitions based on the input bit. When a zero is received, it resets the count to 0. The outputs disc, flag, and err are asserted based on the previous state's information about the sequence completed at the current input:

- disc: Asserted one cycle after detecting a zero following exactly five consecutive 1s (i.e., the stuffed zero after 5 ones).
- flag: Asserted one cycle after detecting a zero following exactly six consecutive 1s (the 01111110 flag pattern).
- err: Asserted if seven or more consecutive 1s are detected (state beyond 6 ones).

We treat reset as synchronous and on reset we initialize to state 0 (as if previous input was zero). Outputs are registered (Moore outputs) and asserted for exactly one clock cycle after the condition is detected.

States:

- S0: No consecutive 1s
- S1-S5: 1 to 5 consecutive ones
- S6: 6 consecutive ones
- S7: Error state (7 or more ones)

Transitions:

- From S0:
  - in=0 => stay in S0
  - in=1 => S1
- From S1 to S5:
  - in=0 => S0 (end of consecutive ones)
  - in=1 => next state (S2 to S6)
- From S6:
  - in=0 => S0 (flag detected)
  - in=1 => S7 (error)
- From S7:
  - in=0 => S0
  - in=1 => S7 (stay in error)

Outputs (to be asserted based on the previous state's info and current input):

- disc: asserted if previous state was S5 and current input is 0 (zero after 5 ones)
- flag: asserted if previous state was S6 and current input is 0 (flag)
- err: asserted if previous state was S7 (error state)

Implementation includes a state register and next state logic, with registered outputs updated at clock edge based on previous state and current input.
