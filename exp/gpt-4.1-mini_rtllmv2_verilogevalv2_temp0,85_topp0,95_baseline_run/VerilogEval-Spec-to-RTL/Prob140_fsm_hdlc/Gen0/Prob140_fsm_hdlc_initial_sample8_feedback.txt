The outputs are updated synchronously on the clock edge using the previous state and current input:

```verilog

flag <= (state == S6) && (in == 0);
err <= (state == S_ERR);

Because outputs are registered synchronously and are derived from the current state, err will be asserted only on the next cycle after entering S_ERR.
