Implement a Moore FSM that counts consecutive 1s seen in the input stream. The states represent the number of consecutive 1s seen (0 to 6). When a 0 is seen, the count resets to 0. Key transitions and outputs:

- After seeing exactly five consecutive 1s, if next bit is 0, this zero should be discarded (disc=1 next cycle).
- If after five 1s, we see a 0, then a 1, making 6 consecutive 1s total, that is the flag pattern (flag=1 next cycle).
- If after six 1s, we see another 1 (7 or more 1s), signal error (err=1 next cycle).
- On reset, FSM returns to initial state (count=0).

The outputs disc, flag, and err are one clock cycle delayed from the detecting input pattern (Moore FSM outputs depend on the current state only).

The FSM states encode the count of consecutive ones (0-6), and the outputs are asserted when in states indicating the pattern has been detected.

The main challenge is that the patterns start with a 0 followed by consecutive 1s. Because the FSM is Moore type, outputs depend only on current state (no input). To detect the initial 0, we assume the FSM starts in state 0 as if previous input was 0.

Transition logic:

- If current bit is 1 and count < 6, increment count.
- If current bit is 0 and count == 5, output disc next cycle.
- If current bit is 0 and count < 5, reset count to 0.
- If current bit is 1 and count == 5, go to count=6 (flag state).
- If current bit is 1 and count == 6, go to error state (7+ ones).
- If current bit is 0 and count == 6, reset to 0.

Outputs:

- disc=1 when the previous count was 5 and current input is 0 (indicated by being in the state corresponding to count=0 after discarding zero).
- flag=1 when in count=6 state (detected 6 consecutive ones).
- err=1 when in error state (7 or more ones).

We can add a separate error state to keep err asserted as long as input is 1.

FSM states can be encoded as:

- S0: 0 ones counted
- S1: 1 one
- S2: 2 ones
- S3: 3 ones
- S4: 4 ones
- S5: 5 ones
- S6: 6 ones (flag)
- S7: error (7 or more ones)

The disc output is generated one cycle after seeing a zero after 5 ones, so the FSM moves from S5 + input 0 to S0 with disc=1 output.

All outputs are registered and asserted for exactly one clock cycle as required.
