Implement a Moore FSM to count consecutive 1s in the input stream. The FSM has states from 0 to 6 representing the count of consecutive 1s seen so far. On input 0, the FSM resets to state 0. On input 1, the FSM increments the count state up to 6. If the FSM reaches state 5 and input is 0, it means a zero was inserted after five 1s and that zero should be discarded, so `disc` is asserted for one cycle following that input. If the FSM reaches state 6 and input is 0, it means a flag pattern (01111110) was detected, so assert `flag` for one cycle. If the FSM reaches state 6 and input is 1, it means error (7 or more consecutive ones) occurred, so assert `err` for one cycle. The outputs are Moore-type, so they depend only on the current state. The outputs are delayed by one clock cycle: outputs are asserted on the clock cycle after the condition is detected, so we register outputs after state transition. On reset, FSM starts in state 0, which corresponds to last input zero state. All outputs are single-cycle pulses.
