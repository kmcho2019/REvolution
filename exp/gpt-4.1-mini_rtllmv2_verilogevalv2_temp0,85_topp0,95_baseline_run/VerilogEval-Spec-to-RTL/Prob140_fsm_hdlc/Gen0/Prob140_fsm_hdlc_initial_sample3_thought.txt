Design a Moore FSM that tracks the count of consecutive 1s seen in the input stream. The FSM states represent how many consecutive 1s have been seen (0 to 6), with transitions on input bit values. When a zero is seen after five 1s, the next cycle discards that zero bit (disc=1). When a zero is seen after six 1s, this indicates a flag pattern (flag=1). If a one is seen after six 1s, this indicates an error (err=1). On reset, the FSM starts at state 0 (no previous 1s). All outputs are asserted for one cycle starting on the clock cycle after the condition occurs, consistent with a Moore FSM where outputs depend only on the state. The transition logic will properly detect the patterns described.
