Implement a Moore FSM that tracks the count of consecutive '1's seen in the input stream after a preceding '0'. The states represent the number of consecutive '1's detected (from 0 to 6). On each clock cycle, if the input bit is '1', we move up to the next state (counting consecutive 1s), if '0', we reset to state 0. 

Key points:
- When transitioning from state 5 to state 6 on a '0' input, it means we saw exactly 5 consecutive 1s followed by a '0', so the disc output should be asserted on the next cycle.
- When transitioning from state 6 to state 0 on a '0' input, it means we saw exactly 6 consecutive 1s followed by a '0' (01111110), so the flag output should be asserted on the next cycle.
- If the input is '1' in state 6, this means 7 or more consecutive 1s, so err output should be asserted on the next cycle.
- On reset, the FSM goes to state 0 (as if previous input was 0).

All outputs (disc, flag, err) are asserted for exactly one clock cycle after the corresponding pattern is detected.

The FSM states can be encoded as 3-bit values: 0 to 6 representing consecutive 1s count.
