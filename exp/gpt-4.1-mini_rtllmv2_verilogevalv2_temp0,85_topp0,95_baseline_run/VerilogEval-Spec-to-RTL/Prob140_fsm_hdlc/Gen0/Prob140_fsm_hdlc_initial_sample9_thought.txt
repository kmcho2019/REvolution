Implement a Moore FSM that tracks the count of consecutive 1s seen in the input stream. The states represent how many consecutive 1s have been seen (from 0 to 6). The input 'in' is sampled on each clock cycle. On reset, go to state 0 (as if previous input was 0). When a 0 is seen, reset the count to 0. When 1 is seen, increment the count. The outputs are asserted one clock cycle after the corresponding sequence is detected:

- disc (discard) asserted if the previous input sequence was five consecutive 1s followed by a 0 (i.e., after seeing 0111110). This corresponds to detecting a 0 after 5 consecutive 1s.
- flag asserted if the previous input sequence was six consecutive 1s followed by a 0 (i.e., after seeing 01111110). This corresponds to detecting a 0 after 6 consecutive 1s.
- err asserted if seven or more consecutive 1s are detected (01111111...). This corresponds to state 7 or more consecutive 1s.

We will encode states 0 to 6 to count consecutive ones, and a special error state for 7 or more ones. For Moore FSM, outputs depend only on the current state, so we will output disc, flag, err signals based on previous state and current input, so we hold outputs registered and delay output by one cycle.

To meet the requirement "outputs asserted for one cycle beginning on the clock cycle after the condition occurs", we will keep the outputs registered and update them each clock cycle based on the previous input pattern.

Key points:
- On reset synchronous active high, go to state 0.
- Track count of consecutive ones up to 6, after 7 or more ones go to error state.
- On input 0, outputs can be disc or flag if previous count of consecutive ones was 5 or 6 respectively.
- On input 1, increment state, if state >= 6 and input 1 again, error.
- Outputs disc, flag, err are asserted for one full clock cycle.

Implementation:
- Use a 4-bit state to hold count of consecutive 1s (0-7).
- One extra bit for error state or use state=7 as error state.
- Outputs are registered signals updated each clock cycle from the previous state and input.
