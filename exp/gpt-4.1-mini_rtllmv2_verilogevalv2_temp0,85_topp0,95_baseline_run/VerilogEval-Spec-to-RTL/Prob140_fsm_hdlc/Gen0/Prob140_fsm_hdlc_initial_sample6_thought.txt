Implement a Moore FSM with states representing the count of consecutive 1s seen so far after a leading 0. On reset, start at state 0, indicating the previous bit was 0. Each clock cycle, transition according to the input bit. When we reach 5 consecutive 1s and see a zero next, output disc (discard bit) next cycle. When we reach 6 consecutive 1s and see a zero next, output flag next cycle (flag detected). When we reach 7 or more consecutive 1s, output err next cycle. Outputs are asserted for one full cycle following detection. The FSM only advances on positive clock edge and reset is synchronous and active high.
