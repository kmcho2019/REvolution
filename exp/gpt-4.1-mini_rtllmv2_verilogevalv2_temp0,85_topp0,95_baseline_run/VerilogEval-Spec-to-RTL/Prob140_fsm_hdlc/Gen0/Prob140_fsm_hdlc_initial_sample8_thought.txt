Implement a Moore FSM that counts the number of consecutive 1s seen in the input stream after a leading 0 or reset. The FSM has states representing the count of consecutive 1s (from 0 to 6). On input=0, it resets the count to 0. 

When 5 consecutive 1s are followed by a 0, we assert disc (discard bit). When 6 consecutive 1s are followed by a 0, we assert flag (HDLC frame delimiter). If the count of consecutive 1s reaches 7 or more, assert err. The outputs are asserted for one full clock cycle after the condition occurs, so outputs are registered based on the FSM state and input in the previous cycle.

Reset synchronously resets the FSM to state 0 (no consecutive 1s). All outputs are registered and deasserted by default. The FSM transitions on each input bit.

States 0-6 correspond to counts of consecutive 1s; state 7 is error state. Outputs depend on previous state's count and current input.
