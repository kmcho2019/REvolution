Implement a Moore FSM to count consecutive 1s in the input stream. On each clock cycle, update the state based on the current input bit and the count of consecutive 1s seen so far. The states represent how many consecutive 1s have been detected (from 0 to 6), plus an error state for 7 or more consecutive 1s. 

- On input=0, reset the count to 0.
- On input=1, increment the count of consecutive 1s.
- If after 5 consecutive 1s, a zero is detected, assert disc output on next cycle.
- If after 6 consecutive 1s, a zero is detected (the full flag pattern 01111110), assert flag on next cycle.
- If 7 or more consecutive 1s, assert err on next cycle.
- Outputs are Moore type, so they depend only on the current state (not input), and asserted for one cycle following the event.

On reset, start in state 0 (as if previous input was zero).

The input sequence is continuous, so we track the count continuously.

We will create states representing the count of consecutive 1s: S0 (0 ones), S1 (1 one), ..., S6 (6 ones), and S7_ERR (7 or more ones).

Outputs:
- disc is asserted in state S5 when next input is 0 (means disc bit).
- flag is asserted in state S6 when next input is 0 (flag sequence detected).
- err is asserted in state S7_ERR.

Since outputs are Moore outputs, they depend only on the current state. Therefore, for disc and flag outputs, the FSM must transition to dedicated output states after detecting the zero following 5 or 6 ones to assert outputs for one cycle. To handle this, we add output states for disc and flag, which transition back to S0.

Summary of states:

- S0: zero consecutive 1s
- S1-S6: 1 to 6 consecutive 1s
- S_DISC: disc output asserted for one cycle
- S_FLAG: flag output asserted for one cycle
- S_ERR: err output asserted (stay here until reset)

Transitions:

- From S5: on input=0 -> go to S_DISC (assert disc)
- From S6: on input=0 -> go to S_FLAG (assert flag)
- From S7_ERR: stay (err output)
- On input=1: increment count, on count >6 -> S_ERR

Output signals only depend on the current state.

Implement synchronous reset active high.

This FSM will decode the input stream and assert outputs as specified.
