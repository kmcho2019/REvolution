Implement a Moore FSM that counts the number of consecutive 1s in the input stream. States represent counts of consecutive 1s from 0 to 6+. On each input bit, if it's 1, move to next count state; if 0, reset count to 0. The "disc" signal is asserted one cycle after seeing exactly five consecutive 1s followed by a 0 (i.e., detecting the stuffed zero after 5 ones). The "flag" signal is asserted one cycle after seeing exactly six consecutive 1s followed by a 0, indicating a frame boundary flag (01111110). The "err" signal is asserted one cycle after seeing seven or more consecutive 1s. The FSM resets to state 0, assuming previous input was 0. Outputs are generated based on the current state and the next input in a Moore style, but since outputs must be synchronous and asserted for one cycle after the condition occurs, outputs are registered and updated on clock edge. We will implement state transitions and outputs in synchronous logic triggered on posedge clk and synchronous reset.
