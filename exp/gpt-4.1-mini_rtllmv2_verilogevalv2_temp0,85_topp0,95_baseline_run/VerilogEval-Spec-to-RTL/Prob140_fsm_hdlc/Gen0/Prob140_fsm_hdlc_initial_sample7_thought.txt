Implement a Moore FSM that counts consecutive ones. The state encodes how many consecutive 1s have been seen (0 to 6). On input zero, reset to state 0. On input one, move to next count state.

- At state 5 and input zero: disc=1 on next cycle (means a zero after 5 ones to discard).
- At state 6 and input zero: flag=1 on next cycle (means flag sequence detected: 01111110).
- At state 6 and input one: err=1 on next cycle (7 or more consecutive ones).

All outputs are registered and asserted for one full clock cycle starting the cycle after the condition occurs.

Reset sets state to 0, as if previous input was zero.

Implement the FSM with states representing count of consecutive ones from 0 to 6. Outputs depend only on the current state and current input (Moore outputs depend on states, but for output conditions involving input, outputs are registered in next cycle).

To handle this, outputs are registered signals updated each clock cycle according to the previous cycle's state and input.

This design uses synchronous reset (active high) and positive edge clocking.
