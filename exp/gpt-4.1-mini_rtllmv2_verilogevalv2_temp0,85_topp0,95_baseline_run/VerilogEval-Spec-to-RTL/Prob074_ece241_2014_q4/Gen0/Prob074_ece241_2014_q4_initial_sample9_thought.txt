Implement three D flip-flops each clocked by clk and initially zero. For each flip-flop:
- The D input is computed from x and the flip-flop's current output using the specified gate (XOR, AND, OR) and the second input rule:
  - XOR gate uses the flip-flop's output as second input.
  - AND gate uses the complement of the flip-flop's output as second input.
  - OR gate uses the complement of the flip-flop's output as second input.
After clocking, the outputs of the three flip-flops are fed into a 3-input NOR gate to produce output z.
