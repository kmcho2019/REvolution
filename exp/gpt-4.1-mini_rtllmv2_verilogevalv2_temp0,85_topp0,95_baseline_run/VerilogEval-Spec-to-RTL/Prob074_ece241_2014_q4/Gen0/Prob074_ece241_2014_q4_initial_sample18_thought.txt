The design consists of three D flip-flops, each storing the output of a respective two-input gate (XOR, AND, OR). Each gate takes input x and the corresponding flip-flop output or its complement as specified: XOR takes the flip-flop output, AND and OR take the complement of their flip-flop outputs. On each clock rising edge, the flip-flops capture their inputs. The outputs of the three flip-flops are then fed into a 3-input NOR gate to generate output z. The flip-flops are asynchronously reset to 0 at the start (modeled with initial block for simulation, or a reset signal if desired). Since no reset input is specified, we can use an initial block to set the flip-flops to zero at simulation start.
