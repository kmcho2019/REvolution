Implement three D flip-flops (ff_xor, ff_and, ff_or) each driven by a combinational logic input defined as follows:
- For ff_xor: D = x XOR ff_xor (current state)
- For ff_and: D = x AND ~ff_and (complement of current state)
- For ff_or: D = x OR ~ff_or (complement of current state)

All flip-flops are positive edge triggered and start at zero (using an initial block to reset).

The output z is the NOR of the three flip-flop outputs:
z = ~(ff_xor | ff_and | ff_or)

This structure matches the problem description.
