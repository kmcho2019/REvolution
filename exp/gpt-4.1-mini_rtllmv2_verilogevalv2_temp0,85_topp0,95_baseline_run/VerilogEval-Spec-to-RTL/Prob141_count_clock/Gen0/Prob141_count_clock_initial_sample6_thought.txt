Implement a 12-hour clock with AM/PM indicator using synchronous logic triggered on the positive edge of clk. On reset, set time to 12:00:00 AM. On each ena pulse (once per second), increment seconds. If seconds reach 60, reset to 00 and increment minutes; if minutes reach 60, reset to 00 and increment hours; if hours reach 12 and increment further, toggle AM/PM and roll hours back to 1. All counters are maintained in BCD format (two digits for each hh, mm, ss). pm is 1 for PM, 0 for AM.
