Implement a 12-hour clock with BCD counters for hours, minutes, and seconds. Each time 'ena' pulses (once per second), increment the seconds counter; if seconds roll over, increment minutes; if minutes roll over, increment hours. Hours count from 1 to 12 in BCD. The 'pm' flag toggles at 12:00. On reset, set time to 12:00 AM (hours=12, minutes=0, seconds=0, pm=0). Use synchronous logic triggered by posedge clk and synchronous reset with highest priority.
