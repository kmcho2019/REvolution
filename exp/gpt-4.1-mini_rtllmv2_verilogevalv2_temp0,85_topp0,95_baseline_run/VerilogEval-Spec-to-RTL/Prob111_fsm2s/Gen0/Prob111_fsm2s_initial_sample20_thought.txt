Implement a Moore FSM with two states: OFF and ON. Use a synchronous active-high reset to set the state to OFF. The output depends only on the current state (0 for OFF, 1 for ON). On each clock edge, if reset is asserted, go to OFF. Otherwise, update the state according to the inputs j and k depending on the current state: from OFF, next state is ON if j=1 else OFF; from ON, next state is OFF if k=1 else ON.
