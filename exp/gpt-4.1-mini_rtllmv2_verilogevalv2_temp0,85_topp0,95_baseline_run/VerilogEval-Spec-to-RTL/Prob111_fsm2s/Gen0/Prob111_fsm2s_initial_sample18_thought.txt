Implement a Moore FSM with two states: OFF and ON. 
- Use a synchronous active-high reset to set the state to OFF.
- On each clock edge, if reset is high, go to OFF.
- Otherwise, in OFF state, if j=1 transition to ON; else stay OFF.
- In ON state, if k=1 transition to OFF; else stay ON.
- Output is 0 in OFF state, 1 in ON state.
