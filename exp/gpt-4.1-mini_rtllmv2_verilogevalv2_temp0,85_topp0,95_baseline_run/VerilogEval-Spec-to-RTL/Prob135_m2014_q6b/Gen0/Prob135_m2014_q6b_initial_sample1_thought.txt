Implement a 3-bit state register y representing states A to F with codes 000 to 101. The input w is used for certain transitions. The next state depends on the current state (y) and the input w, according to the given state machine transitions. The output Y1 is simply the middle bit of y (y[1]). Only the next-state logic for y[1] is implemented explicitly; other bits of y are left unchanged (assuming this is desired since only y[1] next state logic is requested).
