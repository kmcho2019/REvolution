Implement a 3-bit state register y representing states A to F with codes 000 to 101. The next-state logic is defined by transitions on input w (1-bit). Only the next state logic for y[1] is implemented, and output Y1 is assigned from y[1]. The FSM updates y on every clock cycle based on w and current y. Since only next-state logic for y[1] is required, y[0] and y[2] remain unchanged.
