The next state logic is computed based on the current state y and input w. Only y[1] next state logic is implemented; y[0] and y[2] flip-flops are updated but their next-state logic can be zero (or held constant) because the problem asks only for y[1] next state logic. The next state of y[1] will be implemented according to the FSM transitions, for each current state and input w.

However, to properly transition between states, we need to implement next state logic for all bits of y, otherwise the FSM won't progress correctly.
