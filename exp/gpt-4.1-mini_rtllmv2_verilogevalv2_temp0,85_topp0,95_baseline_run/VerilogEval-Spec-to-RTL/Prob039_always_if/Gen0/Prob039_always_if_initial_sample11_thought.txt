Implement a 2-to-1 multiplexer that selects between inputs 'a' and 'b'. The output should be 'b' only if both 'sel_b1' and 'sel_b2' are 1; otherwise, output 'a'. This behavior will be implemented twice: once using a continuous assign statement for 'out_assign' and once within an always block with an if statement for 'out_always'.
