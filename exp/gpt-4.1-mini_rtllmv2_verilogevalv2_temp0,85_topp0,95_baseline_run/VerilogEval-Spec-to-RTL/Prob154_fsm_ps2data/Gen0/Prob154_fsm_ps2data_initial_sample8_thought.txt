Implement a simple FSM with three states: WAIT_FOR_START, BYTE_2, BYTE_3. 
- In WAIT_FOR_START, discard input bytes until in[3] is 1, then capture this as first byte and move to BYTE_2.
- In BYTE_2 state, capture the next byte as second byte and move to BYTE_3.
- In BYTE_3 state, capture the third byte, output the full 3-byte message concatenated in out_bytes, assert done for one cycle, then return to WAIT_FOR_START.
Use synchronous reset to initialize the FSM and outputs. The done signal is asserted one cycle immediately after the third byte is stored.
