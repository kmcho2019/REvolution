Implement a synchronous FSM with three states: IDLE (searching for a byte where in[3] = 1), BYTE1 (first byte received), BYTE2 (second byte received). Upon receiving a byte with in[3] = 1 in IDLE, latch it as the first byte and move to BYTE1. Then latch the next two bytes sequentially. After the third byte is received, output the 24-bit message combining the three bytes in order (first byte most significant) and assert done for one cycle. Reset synchronously sets FSM to IDLE. Output done and out_bytes only valid for one cycle after third byte received.
