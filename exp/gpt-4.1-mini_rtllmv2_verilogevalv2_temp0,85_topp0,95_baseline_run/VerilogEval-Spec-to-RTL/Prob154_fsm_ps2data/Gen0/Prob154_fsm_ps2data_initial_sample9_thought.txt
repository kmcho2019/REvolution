Implement a FSM with three states: IDLE (waiting for a byte with in[3] == 1), BYTE1 (received first byte), BYTE2 (received second byte). The FSM samples input byte each clock. In IDLE state, discard bytes until a byte with in[3] == 1 is received, then store it as the first byte and move to BYTE1. In BYTE1 state, store next byte as second byte and move to BYTE2. In BYTE2 state, store next byte as third byte, assert done for one cycle, output the concatenated 3-byte message, then return to IDLE for the next message. Reset synchronously resets FSM to IDLE and clears outputs.
