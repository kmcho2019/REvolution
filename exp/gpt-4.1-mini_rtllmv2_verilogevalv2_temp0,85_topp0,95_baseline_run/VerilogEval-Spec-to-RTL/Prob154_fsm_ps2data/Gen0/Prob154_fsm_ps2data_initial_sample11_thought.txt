Implement a FSM with three states: IDLE, BYTE2, BYTE3. 
In IDLE, discard input bytes until in[3] = 1, which marks the first byte of a message.
Then transition to BYTE2, store byte 1 in out_bytes[23:16].
On next clock, capture byte 2 into out_bytes[15:8], move to BYTE3.
On next clock, capture byte 3 into out_bytes[7:0], assert done for one cycle, then go back to IDLE.
Reset is synchronous and active high.
out_bytes is updated synchronously so it is valid when done is asserted.
