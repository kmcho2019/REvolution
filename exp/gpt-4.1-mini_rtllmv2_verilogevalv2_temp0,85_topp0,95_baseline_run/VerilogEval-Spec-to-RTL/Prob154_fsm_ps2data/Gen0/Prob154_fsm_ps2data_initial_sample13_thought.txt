Implement a synchronous FSM with three states: IDLE, BYTE1, BYTE2. In IDLE, discard bytes until a byte with bit 3 set is found; then latch that byte as the first byte of the message and move to BYTE1. In BYTE1 state, latch the second byte, move to BYTE2. In BYTE2 state, latch the third byte, assert done in the next cycle with out_bytes formed from the three latched bytes (first byte in bits [23:16], second byte [15:8], third byte [7:0]), then return to IDLE to search for next message. The reset is synchronous active-high, which resets state and output signals. done is asserted only for one cycle immediately after the third byte is received.
