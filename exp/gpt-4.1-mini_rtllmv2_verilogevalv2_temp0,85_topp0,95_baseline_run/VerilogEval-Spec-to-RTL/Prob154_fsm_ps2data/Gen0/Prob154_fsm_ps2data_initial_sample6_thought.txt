Implement a 3-state FSM to detect message boundaries: IDLE (waiting for a byte with bit 3 set), BYTE1 and BYTE2 (collecting the 2nd and 3rd bytes). On reset, go to IDLE. When in IDLE, ignore bytes until in[3] is 1, then store that byte as first byte and move to BYTE1. Then store next bytes as BYTE2 and BYTE3. After receiving the third byte, assert done and output the concatenated 24-bit message with the order: first byte in bits [23:16], second byte [15:8], third byte [7:0]. The done signal is asserted only for one cycle immediately after receiving the third byte. Reset is synchronous active high. The output is valid only when done is high.
