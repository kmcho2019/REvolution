Implement an FSM with four states: IDLE (waiting for a byte with in[3]=1), BYTE1 (first byte captured), BYTE2 (second byte captured), BYTE3 (third byte captured). On reset, go to IDLE. When in IDLE, discard bytes until in[3] is 1, then capture that byte as byte1 and move to BYTE1. On BYTE1 and BYTE2, capture next bytes and move to next state. On BYTE3, capture the third byte, assert done on the next cycle, output the concatenated 3 bytes (byte1 as most significant byte, byte2, byte3 as least significant byte), then return to IDLE. The output done is asserted for one clock cycle immediately after the third byte is received. The reset is synchronous, positive edge triggered. out_bytes is valid whenever done is asserted.
