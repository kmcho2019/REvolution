Implement a simple FSM with three states: WAIT_FOR_START, BYTE_2, BYTE_3.
Initially, stay in WAIT_FOR_START until a byte with bit 3 set is received.
Then, start capturing bytes into a 24-bit shift register:
- Byte 1 into bits [23:16]
- Byte 2 into bits [15:8]
- Byte 3 into bits [7:0]

After receiving the third byte, assert done for one cycle and output the collected 24-bit message.
On reset, go back to WAIT_FOR_START and clear outputs.
done is asserted for only one cycle immediately after the third byte is received.
Use synchronous reset and positive edge clocking.
