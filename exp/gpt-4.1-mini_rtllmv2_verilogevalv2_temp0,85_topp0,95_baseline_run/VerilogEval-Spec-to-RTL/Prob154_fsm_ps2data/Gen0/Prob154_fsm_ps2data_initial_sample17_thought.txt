Implement a simple FSM with three states: IDLE (waiting for a byte with in[3]=1), BYTE1 (first byte received), BYTE2 (second byte received). In IDLE, discard bytes until a byte with bit 3 set arrives; then store it as the first byte and move to BYTE1. In BYTE1, store the second byte and move to BYTE2. In BYTE2, store the third byte and assert done for one cycle. Output the concatenation of the three bytes as out_bytes in the done cycle. Use synchronous reset to initialize the state machine and outputs.
