Implement a Moore FSM with two states: OFF and ON. The output depends only on the state (OFF=0, ON=1). Asynchronous active-high reset sets state to OFF. On each clock edge, if not reset, transition according to input signals j and k based on current state:
- In OFF state, if j=1 go to ON, else remain OFF.
- In ON state, if k=1 go to OFF, else remain ON.
