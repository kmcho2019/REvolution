Implement a Moore state machine with two states: OFF and ON. Use a 1-bit state register to represent the states (0 for OFF, 1 for ON). The output depends only on the current state (0 for OFF, 1 for ON). The transitions are:
- From OFF, if j=1, go to ON; else stay OFF.
- From ON, if k=1, go to OFF; else stay ON.
Use asynchronous active-high reset to set the state to OFF.
