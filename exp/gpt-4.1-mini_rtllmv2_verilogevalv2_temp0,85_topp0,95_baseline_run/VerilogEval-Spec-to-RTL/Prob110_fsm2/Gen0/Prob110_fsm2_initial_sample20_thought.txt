Implement a Moore state machine with two states: OFF and ON. The output depends only on the current state. The asynchronous active-high reset (areset) forces the state to OFF. On each clock edge, the state transitions according to the inputs j and k as specified: from OFF to ON if j=1, otherwise stays OFF; from ON to OFF if k=1, otherwise stays ON. The output is 0 in OFF state and 1 in ON state.
