Implement a Moore FSM with two states OFF and ON. The output depends only on the current state. Use asynchronous active-high reset to initialize state to OFF. On each clock edge, transition according to inputs j and k:
- In OFF state (out=0), if j=1 move to ON, else stay OFF.
- In ON state (out=1), if k=1 move to OFF, else stay ON.
Output is assigned based on the current state.
