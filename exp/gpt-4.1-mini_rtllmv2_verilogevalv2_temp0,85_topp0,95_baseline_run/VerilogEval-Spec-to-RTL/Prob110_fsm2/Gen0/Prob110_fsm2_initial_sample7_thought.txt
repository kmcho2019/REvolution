Implement a Moore state machine with two states: OFF and ON. The output depends only on the state (0 for OFF, 1 for ON). The state transitions happen on the rising edge of clk, with an asynchronous active-high reset (areset) that sets the state to OFF. When in OFF, if j=1, move to ON; else stay in OFF. When in ON, if k=1, move to OFF; else stay in ON.
