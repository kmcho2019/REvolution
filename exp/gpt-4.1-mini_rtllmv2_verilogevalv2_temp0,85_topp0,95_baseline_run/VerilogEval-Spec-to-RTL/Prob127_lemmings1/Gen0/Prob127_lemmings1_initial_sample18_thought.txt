Implement a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. The state updates on the positive clock edge or asynchronously resets to WALK_LEFT on areset. On each clock cycle, if bump_left or bump_right (or both) are asserted, the Lemming changes direction accordingly: if bumped on left, switch to WALK_RIGHT; if bumped on right, switch to WALK_LEFT. If both bump_left and bump_right are asserted simultaneously, it still switches directions (we can prioritize one or handle both by switching state, which ends up toggling state). Outputs walk_left and walk_right depend only on the current state.
