Implement a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. On areset (async, posedge), reset state to WALK_LEFT. On each clock posedge, if bumped on the left, set state to WALK_RIGHT. If bumped on the right, set state to WALK_LEFT. If bumped on both sides, switch directions (which can be handled by the two conditions, since both bumps cause a direction change). Outputs reflect the current state: walk_left=1 if in WALK_LEFT, walk_right=1 if in WALK_RIGHT.
