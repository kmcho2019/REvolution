Implement a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. On asynchronous posedge of areset, reset to WALK_LEFT. On every clock posedge, update state: if either bump_left or bump_right is 1, toggle the state (switch directions). Outputs are asserted based on the current state: walk_left=1 if in WALK_LEFT, walk_right=1 if in WALK_RIGHT.
