Implement a Moore FSM with two states: WALK_LEFT and WALK_RIGHT. The output signals walk_left and walk_right will be based solely on the current state. On a positive edge of clock, if areset is asserted, reset the state to WALK_LEFT asynchronously. Otherwise, on each clock cycle, if bump_left or bump_right is asserted (or both), switch the direction: if currently WALK_LEFT and bumped, switch to WALK_RIGHT; if currently WALK_RIGHT and bumped, switch to WALK_LEFT. The outputs are one-hot encoded according to the current state.
