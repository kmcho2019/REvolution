Design a finite state machine with the following states: IDLE (waiting for start bit), RECEIVING (receiving 8 data bits), STOP (checking the stop bit). On reset, go to IDLE. When in IDLE and input is 0 (start bit), move to RECEIVING and start shifting in data bits LSB first into a register. After 8 bits are received, move to STOP state and check if input is 1 (stop bit). If stop bit is correct, output the received byte, assert done for one cycle, then return to IDLE. If stop bit is incorrect, stay in STOP state until input is 1, then go back to IDLE (discard the current byte). done is asserted only for one clock cycle when a valid byte is received. out_byte is valid when done is asserted.
