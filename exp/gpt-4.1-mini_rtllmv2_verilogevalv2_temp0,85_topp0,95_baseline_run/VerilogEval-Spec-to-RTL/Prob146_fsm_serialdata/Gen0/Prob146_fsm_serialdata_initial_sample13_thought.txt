Implement an FSM with four states: IDLE, START, DATA, STOP. In IDLE, wait for start bit (0). On detecting start bit, move to DATA state and shift in the 8 data bits (LSB first). After 8 bits, move to STOP state to check for stop bit (1). If stop bit is valid, assert done and output the received byte. If stop bit is invalid, wait in STOP state until a stop bit (1) is found, ignoring the current byte and starting fresh from the next start bit. Use synchronous active-high reset to return to IDLE state.
