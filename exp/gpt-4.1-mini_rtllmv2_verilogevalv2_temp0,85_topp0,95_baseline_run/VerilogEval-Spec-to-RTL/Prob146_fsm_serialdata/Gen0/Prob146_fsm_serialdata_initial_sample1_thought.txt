Implement a finite state machine with the following states: IDLE (line idle, waiting for start bit), START (verifying start bit is 0), DATA (shifting in 8 data bits LSB first), STOP (verifying stop bit is 1). On reset, go to IDLE. When a start bit (0) is detected from idle, transition to DATA, shift in bits on each clock edge. After 8 bits are received, check stop bit; if 1, output the byte, assert done, then return to IDLE. If stop bit is not 1, wait in a RECOVERY state until stop bit (1) is seen, then go to IDLE to resync. The `done` signal is asserted for one clock cycle when a byte is correctly received with a valid stop bit. The `out_byte` is valid only when `done` is high.
