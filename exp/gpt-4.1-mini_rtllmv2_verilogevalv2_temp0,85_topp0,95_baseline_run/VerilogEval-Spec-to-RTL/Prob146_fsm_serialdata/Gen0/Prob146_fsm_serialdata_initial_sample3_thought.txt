Implement a FSM with states IDLE, START, DATA, STOP, and WAIT_STOP_BIT. 
- In IDLE, wait for start bit (0) when line is idle (1). 
- On detecting start bit, move to DATA to shift in 8 bits LSB first. 
- Then check stop bit. 
- If stop bit is 1, assert done and output received byte. 
- If stop bit is not 1, go to WAIT_STOP_BIT, keep waiting until line becomes 1 (stop bit detected). 
Use synchronous reset and positive edge clocking.
