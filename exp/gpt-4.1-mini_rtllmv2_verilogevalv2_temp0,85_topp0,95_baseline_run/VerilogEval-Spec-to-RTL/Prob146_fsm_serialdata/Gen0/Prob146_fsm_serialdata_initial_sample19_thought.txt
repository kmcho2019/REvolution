Implement a finite state machine with states: IDLE (waiting for start bit), RECEIVE (receiving 8 data bits), STOP (checking stop bit), and WAIT_STOP (waiting for stop bit if incorrect stop bit is found). On reset, go to IDLE. In IDLE, wait for start bit (0). On detecting start bit, move to RECEIVE state and shift in data bits LSB first. After 8 bits received, check stop bit. If stop bit is 1, assert done and output the byte, then go back to IDLE. If stop bit is incorrect (not 1), enter WAIT_STOP state until a stop bit (1) is found, then go back to IDLE without asserting done. done is asserted for one clock cycle when a byte is correctly received.
