Implement a finite state machine with four states: IDLE, START, DATA, STOP.
- IDLE: wait for start bit (0) while line is normally high (1).
- START: on detecting start bit (0), move to DATA state.
- DATA: shift in 8 data bits LSB first into a register.
- STOP: check if stop bit is 1. If yes, assert done and output data byte; then go back to IDLE.
- If stop bit is not 1, stay in STOP state until a stop bit (1) is detected, then return to IDLE without asserting done.
Use a synchronous reset to initialize FSM and registers.
