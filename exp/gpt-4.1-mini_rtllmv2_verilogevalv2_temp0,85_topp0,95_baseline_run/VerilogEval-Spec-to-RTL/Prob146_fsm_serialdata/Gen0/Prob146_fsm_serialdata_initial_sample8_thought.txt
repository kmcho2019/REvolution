I will implement a FSM with the following states: IDLE, START_BIT, DATA_BITS, STOP_BIT, and ERROR_STOP_WAIT. The FSM waits in IDLE while the line is high. When it detects a start bit (0), it moves to DATA_BITS state, shifting in the 8 data bits LSB first on each clock cycle. Then it goes to STOP_BIT state to check if the stop bit is 1. If yes, it asserts done and outputs the byte, then returns to IDLE. If the stop bit is not 1, it goes to ERROR_STOP_WAIT state and waits until the line goes high (stop bit detected) before returning to IDLE. The FSM resets to IDLE on synchronous reset. The done signal is a one-cycle pulse synchronized with the stop bit detection.
