Design a finite state machine with these states: IDLE (waiting for start bit), RECEIVE (shifting in 8 data bits LSB first), STOP (checking stop bit). On reset, go to IDLE. When in IDLE, wait for a start bit (0). Then shift in 8 bits on each clock edge into a shift register. After 8 bits, check the stop bit. If stop bit is 1, output the byte, assert done for one cycle, and return to IDLE. If stop bit is not 1, stay in a WAIT_STOP state, ignoring input until a 1 is seen (valid stop bit) then go back to IDLE. The out_byte is valid only when done is asserted. The FSM is synchronous to clk and reset is synchronous active high.
