Design a finite state machine with these states: IDLE (waiting for start bit), RECEIVE (receiving 8 data bits LSB first), STOP (checking the stop bit). On reset, go to IDLE. When in IDLE and input 'in' goes low (start bit detected), transition to RECEIVE and start shifting in data bits. After 8 bits received, transition to STOP. If stop bit is 1, assert done and output the received byte; if stop bit is 0, do not assert done and stay in STOP until a stop bit (1) is seen on 'in'. Then transition back to IDLE to receive next byte. The output done is a one-clock pulse. The output out_byte is valid only when done is asserted.
