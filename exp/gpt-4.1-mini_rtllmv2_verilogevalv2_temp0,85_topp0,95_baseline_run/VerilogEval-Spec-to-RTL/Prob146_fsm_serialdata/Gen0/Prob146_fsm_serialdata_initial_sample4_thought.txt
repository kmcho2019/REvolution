Design an FSM with states: IDLE (line idle, waiting for start bit), RECEIVE (receiving 8 data bits), STOP (checking stop bit), and WAIT_STOP (waiting for stop bit if invalid). On reset, go to IDLE. When start bit (0) detected, move to RECEIVE and shift in data LSB first on each clock. After 8 bits, check stop bit; if 1, output byte, assert done, and return to IDLE; if 0, go to WAIT_STOP and wait until line is 1, then return to IDLE. done is a one-clock pulse when a byte is received with valid stop bit.
