Implement a finite state machine with four states: IDLE, START, DATA, STOP.
- IDLE: Wait for start bit (in == 0).
- START: On next clock after detecting start bit, start receiving data bits.
- DATA: Shift in 8 data bits LSB first on each clock cycle.
- STOP: Check stop bit (should be 1).
If stop bit is correct, output the received byte on out_byte and assert done for one clock.
If stop bit is not correct (not 1), stay in STOP state until in == 1 (stop bit seen).
After done or correction, go back to IDLE to wait for next start bit.
Reset initializes FSM to IDLE.
