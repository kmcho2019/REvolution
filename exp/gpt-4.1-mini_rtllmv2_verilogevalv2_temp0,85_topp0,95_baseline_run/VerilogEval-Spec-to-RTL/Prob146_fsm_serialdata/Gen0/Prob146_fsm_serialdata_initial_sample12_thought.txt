Implement a finite state machine (FSM) with the following states: IDLE (line idle, waiting for start bit), START (verify start bit is 0), DATA (shift in 8 data bits, LSB first), STOP (check stop bit is 1), and WAIT_STOP (wait until line goes to 1 to resynchronize after stop bit error). On reset, go to IDLE. While in IDLE, wait for a 0 (start bit). Then receive 8 bits serially into a shift register. After receiving the 8 bits, check the stop bit. If stop bit is 1, output done=1 and latch the data byte. If stop bit is not 1, move to WAIT_STOP state and wait until input line goes back to 1 (idle) before returning to IDLE. The done signal should be a one-cycle pulse indicating that a byte has been correctly received. All sequential logic is clocked on posedge clk. The output out_byte is valid only when done=1.
