Design a finite state machine with the following states: IDLE, START, DATA, STOP, and WAIT_STOP. In IDLE, wait for the start bit (0). Once detected, move to DATA state to shift in 8 bits (LSB first) into a byte register. After 8 data bits, move to STOP state and check if stop bit (1) is present. If correct, output the byte, assert done for one cycle, then return to IDLE. If stop bit is incorrect, move to WAIT_STOP state, where the FSM waits until a stop bit (1) is detected to resynchronize, then returns to IDLE. Use synchronous reset to go to IDLE. Output done and out_byte are valid when the stop bit is correctly detected.
