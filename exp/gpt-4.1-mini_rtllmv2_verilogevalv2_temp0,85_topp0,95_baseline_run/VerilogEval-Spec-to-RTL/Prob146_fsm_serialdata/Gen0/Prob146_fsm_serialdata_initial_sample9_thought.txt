We will implement a finite state machine (FSM) with the following states: IDLE (waiting for start bit), DATA (receiving 8 data bits), STOP (checking for stop bit), and WAIT_STOP (waiting for the line to go back to idle state if the stop bit was invalid). On reset, the FSM will go to IDLE. When in IDLE, it waits for a '0' start bit. Once detected, it moves to DATA state and shifts in 8 data bits LSB first on successive clock cycles. After 8 bits, it moves to STOP state to check if the stop bit is '1'. If yes, it asserts done and outputs the received byte. If not, it moves to WAIT_STOP state until the line goes high (stop bit) before returning to IDLE. The done signal is asserted for one cycle right after the stop bit is confirmed. The out_byte is valid only when done is high.
