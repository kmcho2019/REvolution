Implement a finite state machine with the following states: IDLE (line idle, waiting for start bit), START (verify start bit is 0), DATA (shift in 8 data bits LSB first), STOP (check stop bit is 1). On reset, return to IDLE. If stop bit is incorrect, remain in a recovery state waiting for a stop bit before returning to IDLE. When a correct byte is received (stop bit correct), assert done for one clock cycle and output the received byte on out_byte.
