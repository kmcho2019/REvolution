Implement an FSM with states: IDLE (waiting for start bit), RECEIVE (receiving 8 data bits LSB first), STOP (checking stop bit). On reset, go to IDLE. In IDLE, wait for a falling edge (line goes from 1 to 0) to detect start bit. When start bit detected, move to RECEIVE and shift in bits on each clock, counting to 8 bits. Then move to STOP and verify stop bit is 1. If stop bit is correct, assert done and output the byte. If stop bit is incorrect, don't assert done and wait until the line is 1 again before returning to IDLE. done is asserted for one clock cycle when a byte is correctly received.
