Implement a FSM with states: IDLE, START, DATA, STOP, and ERROR_WAIT.
- IDLE: wait for start bit (in == 0).
- START: confirm start bit, then proceed to DATA.
- DATA: shift in 8 bits LSB first.
- STOP: check stop bit (in == 1), if valid assert done and output out_byte, then go to IDLE.
- ERROR_WAIT: wait until in == 1 (stop bit) to resync, then go to IDLE.
Use a bit counter to count data bits. On reset, go to IDLE and clear outputs.
done is asserted only for one clock cycle when a byte is successfully received.
