Design a finite state machine (FSM) with states IDLE, START, DATA, STOP, and ERROR to process the incoming serial bits. The line is idle high. When a 0 is detected in IDLE, it indicates a start bit; move to START state and confirm the bit is indeed 0. Then shift in 8 data bits LSB first in the DATA state. After receiving 8 data bits, expect a stop bit (1) in the STOP state. If the stop bit is correct, assert done and output the assembled byte; then return to IDLE. If the stop bit is incorrect, go to ERROR state and wait until a stop bit (1) is observed to resynchronize, then go back to IDLE. Use a synchronous reset to reset FSM state and outputs.
