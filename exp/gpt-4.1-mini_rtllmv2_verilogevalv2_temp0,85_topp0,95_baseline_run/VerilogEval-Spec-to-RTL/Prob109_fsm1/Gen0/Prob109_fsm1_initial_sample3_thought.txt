Implement a Moore machine with two states: A and B. The output depends only on the current state: output 1 for B and 0 for A. On asynchronous reset (high areset), go to state B. On each clock edge, transition based on input 'in' according to the state diagram:
- From B (output 1): input 0 -> A, input 1 -> B
- From A (output 0): input 0 -> B, input 1 -> A
