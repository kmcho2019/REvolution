Implement a Moore machine with two states A and B represented by a single bit state variable. On async reset (areset high), state is set to B (encoded as 1). On each clock edge, transition according to input in:
- From state B (1): if in=0 go to A (0), else stay in B (1)
- From state A (0): if in=0 go to B (1), else stay in A (0)
The output is state value since it's a Moore machine.
