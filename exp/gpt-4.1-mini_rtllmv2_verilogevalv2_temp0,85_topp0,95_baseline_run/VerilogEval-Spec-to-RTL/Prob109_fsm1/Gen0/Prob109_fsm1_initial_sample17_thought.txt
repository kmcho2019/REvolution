Implement a Moore state machine with two states: A and B. 
- Use a register to hold the current state.
- On asynchronous reset (active high), set the state to B.
- On each clock edge, update the state based on the input 'in' and the transition rules:
  From B (output 1): if in=0 -> A, if in=1 -> B
  From A (output 0): if in=0 -> B, if in=1 -> A
- Output depends only on the current state (Moore machine).
