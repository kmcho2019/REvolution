Implement a Moore state machine with two states A and B, encoded as 0 and 1 respectively. The state transitions are as follows: from B (state 1), input 0 transitions to A (state 0), input 1 stays in B; from A (state 0), input 0 transitions to B (state 1), input 1 stays in A. The output is the current state value (0 or 1). The asynchronous reset sets the state to B (1).
