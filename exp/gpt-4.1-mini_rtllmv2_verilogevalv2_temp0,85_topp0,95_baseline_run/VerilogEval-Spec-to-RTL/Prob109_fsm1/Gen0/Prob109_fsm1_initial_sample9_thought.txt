Implement a Moore state machine with two states, A and B. Use a single bit to encode the states: 0 for A and 1 for B. On asynchronous reset (active high), the state will be set to B (1). On each rising clock edge, transition between states based on the input 'in' according to the given state diagram. The output 'out' depends only on the current state: output 0 for A, output 1 for B.
