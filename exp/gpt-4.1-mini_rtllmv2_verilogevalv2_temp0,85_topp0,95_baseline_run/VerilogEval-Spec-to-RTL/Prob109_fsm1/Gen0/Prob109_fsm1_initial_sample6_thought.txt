Implement a Moore state machine with two states: A and B. The output depends solely on the current state: state A outputs 0, and state B outputs 1. On the asynchronous reset (areset), the machine resets to state B. State transitions happen on the rising edge of clk. The state transition diagram is:

- From B (output 1): input 0 → A, input 1 → B
- From A (output 0): input 0 → B, input 1 → A

Represent states as a one-bit register (e.g., 0 for A, 1 for B).
