Implement a Moore state machine with two states A and B encoded as 0 and 1 respectively. On asynchronous reset, the state is set to B (1). On each clock edge, the state transitions according to the input:
- From B (1): if input is 0, go to A (0); if 1, stay in B (1)
- From A (0): if input is 0, go to B (1); if 1, stay in A (0)
The output is the current state value since it is a Moore machine.
