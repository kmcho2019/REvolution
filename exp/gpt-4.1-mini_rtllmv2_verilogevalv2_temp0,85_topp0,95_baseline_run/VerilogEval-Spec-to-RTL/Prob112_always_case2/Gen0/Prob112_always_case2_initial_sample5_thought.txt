Implement a combinational priority encoder that checks each bit of the 4-bit input starting from the highest index (bit 3) down to the lowest (bit 0). The output is a 2-bit position index of the first high bit found. If no bits are high, output zero. Since the input is 4 bits, the output should represent values from 0 to 3, with 0 meaning either bit 0 is high or no bits are high. We will prioritize higher bits first.
