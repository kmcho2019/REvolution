Implement a 4-bit priority encoder that outputs the position of the first high bit from the MSB to LSB. If no bits are set, output zero. The priority is given such that in input[3:0], bit 3 has highest priority (position 3), then bit 2 (position 2), then bit 1 (position 1), then bit 0 (position 0). The output 'pos' is 2 bits representing the position of the first high bit.
