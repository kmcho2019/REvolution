Implement a 4-bit priority encoder using combinational logic. The encoder checks bits from the highest priority (bit 3) down to the lowest (bit 0). If bit 3 is 1, output 3 (2'b11), else if bit 2 is 1, output 2 (2'b10), else if bit 1 is 1, output 1 (2'b01), else if bit 0 is 1, output 0 (2'b00). If none are 1, output 0.
