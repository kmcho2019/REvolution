Implement a 4-bit priority encoder that outputs the position of the first '1' bit starting from the most significant bit (bit 3) down to the least significant bit (bit 0). If no bits are set, output zero. The output 'pos' is 2 bits, so for bit 3, output 2'b11; for bit 2, 2'b10; for bit 1, 2'b01; for bit 0, 2'b00.
