Implement a 4-bit priority encoder by checking the input bits from the most significant bit to the least significant bit. The output 'pos' will represent the position of the first high bit found. If no bits are high, output zero. Since the input is 4 bits and output is 2 bits, the position will be encoded as 0 to 3, where 0 corresponds to bit 0, 1 to bit 1, etc.
