We have a 4-variable K-map with variables a,b (selectors) and c,d (inputs). The final output F = MUX4(ab, mux_in), where mux_in are functions of c,d only.

From the K-map:

       ab
    cd 00 01 11 10
    00 0  0  0  1
    01 1  0  0  0
    11 1  0  1  1
    10 1  0  0  1

For each fixed ab value, the output F is mux_in[ab] depending on c,d:

- ab=00: output = mux_in[0] = F when ab=00 = F(c,d,00) = for all cd: values are 0,1,1,1 as per rows

Mapping rows for ab=00:

cd=00 -> F=0  
cd=01 -> F=1  
cd=11 -> F=1  
cd=10 -> F=1  

So mux_in[0] = 0 if c=0,d=0 else 1.

- ab=01: output = mux_in[1] = F=0 for all cd. (from the table, all zeroes)

- ab=11: output = mux_in[2] = F=0 0 1 0 for cd=00,01,11,10

From the table:

cd=00 ->0  
cd=01 ->0  
cd=11 ->1  
cd=10 ->0

So mux_in[2] = 1 only for c=1,d=1, else 0.

- ab=10: output = mux_in[3] = F=1 0 1 1 for cd=00,01,11,10

From the table:

cd=00 ->1  
cd=01 ->0  
cd=11 ->1  
cd=10 ->1

So mux_in[3] = 1 when (c,d) in {00,11,10}, 0 when cd=01.

Summary:

mux_in[0] = (c | d)  (1 except c=0,d=0)  
mux_in[1] = 0  
mux_in[2] = (c & d)  
mux_in[3] = (~c & ~d) | (c & d) | (c & ~d) = (~c & ~d) + (c & 1) = (~c & ~d) + c

Simplify mux_in[3]:

(~c & ~d) + c = ?

If c=1 => mux_in[3]=1

If c=0, d=0 => mux_in[3]=1

Else mux_in[3]=0

Implementation:

- mux_in[1] = 0 (constant zero)

- mux_in[0] = c OR d, which we cannot implement directly (no gates allowed).

We need to implement mux_in[0] with multiplexers only.

No logic gates allowed except multiplexers.

We can implement OR, AND, NOT with multiplexers.

Implementations using 2:1 muxes:

- NOT x = MUX(x,0,1) = select input is x, input0=1, input1=0

- AND x,y = MUX(y,0,x)  (select is x: if x=0->0 else y)

- OR x,y = MUX(y,1,x)   (select is x: if x=0->y else 1)

We can use these to build the signals.

Hence:

mux_in[0] = c OR d = MUX(d,1,c) (select input c)

mux_in[1] = 0

mux_in[2] = c AND d = MUX(d,0,c)

mux_in[3] = (~c & ~d) + c

= c + (~c & ~d)

= c OR (~c & ~d)

= c OR (~c AND ~d)

= MUX(~c & ~d,1,c) (OR operation with inputs c and ~c&~d)

But ~c&~d = NOT c AND NOT d = we can implement with muxes:

NOT c = MUX(c,0,1)

NOT d = MUX(d,0,1)

AND of those = MUX(~d,0,~c)

Then final OR with c:

MUX((~c&~d),1,c)

Summary of required mux_in signals:

- mux_in[0] = OR(c,d) = MUX(d,1,c)

- mux_in[1] = 0

- mux_in[2] = AND(c,d) = MUX(d,0,c)

- mux_in[3] = OR(c, AND(NOT c, NOT d)) = MUX((~c & ~d),1,c)

Implementing all NOT and AND signals with 2:1 muxes.

Use the 4-to-1 mux with selector ab, inputs mux_in[3:0] as above.
