The 4-to-1 multiplexer selects one of mux_in[3:0] based on inputs a and b. We must implement mux_in[3:0] as functions of c and d, so that the final output (mux_out) equals the K-map values for inputs a,b,c,d.

Given:
- The final output = mux_in[{a,b}]
- The K-map is indexed by ab (columns) and cd (rows):
  For each ab (00,01,11,10), mux_in[ab] should be a function of cd (c,d) matching the K-map column.

Therefore:
- mux_in[0] (ab=00) outputs the K-map values at column 00: rows 00->0, 01->1, 11->1, 10->1
- mux_in[1] (ab=01): column 01: 00->0, 01->0, 11->0, 10->0
- mux_in[2] (ab=11): column 11: 00->0, 01->0, 11->1, 10->0
- mux_in[3] (ab=10): column 10: 00->1, 01->0, 11->1, 10->1

We only use c and d as inputs for mux_in[3:0].

We implement each mux_in[i] using 2-to-1 multiplexers (MUX2) only.

Define a 2-to-1 mux module Mux2(sel, in0, in1, out).
Then build mux_in[i] from c,d using Mux2s:

Implement the logic for each mux_in[i] as a mux chain, e.g.:

- For mux_in[0]:
  c d: 00=0, 01=1, 11=1, 10=1
  Using d as selector:
    if d=0: c=0->0, c=1->1
    if d=1: output=1
  So mux_in[0] = d ? 1 : c

- mux_in[1]: all 0's
- mux_in[2]: 00=0,01=0,11=1,10=0
  d=0 -> 0; d=1 -> c
  So mux_in[2] = d ? c : 0

- mux_in[3]: 00=1,01=0,11=1,10=1
  d=0: c=0->1, c=1->1
  d=1: c=0->0, c=1->1
  d=0 output=1
  d=1 output=c

  So mux_in[3] = d ? c : 1

We implement the constants '0' and '1' by connecting to 1'b0 or 1'b1.

Finally, the module outputs mux_in[3:0] with those signals.

We use only the 2-to-1 mux module and no other gates.
