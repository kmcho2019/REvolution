Implement a combinational logic block that computes next_state and outputs from the current state and input. Since the state encoding is one-hot, we check each bit of the input state vector and, based on the input, set the corresponding next state bits. The outputs are zero except for S7 (0,1) and S8 (1,0) and S9 (1,1), so we can compute out1 and out2 by OR-ing the corresponding states' output bits. Also, since multiple states can be active in the input, we combine all possible transitions for each state (using OR for next_state bits).
