Implement combinational logic to compute next_state and outputs from current one-hot encoded state and input. For each state bit set in the current state vector, find its next state based on input and set corresponding bit in next_state. Outputs are zero except for states S7 (out2=1) and S8 (out1=1), S9 (both out1=1 and out2=1). Since multiple states can be active, next_state is the OR of all possible next states. The outputs are the OR of outputs associated with all active states.
