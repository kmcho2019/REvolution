Implement the combinational logic of the one-hot encoded state machine using the given transitions. For each possible current state bit set to 1, compute the next state bits according to input 'in'. Because multiple states can be active simultaneously (state vector can have multiple bits set), next_state is the OR of all possible next states from each active current state. Outputs out1 and out2 are zero unless in states S7 (out2=1) or S8 (out1=1) or S9 (out1=1 and out2=1) as specified. Handle output as the OR of outputs from all active states.
