Implement the combinational next state logic and output logic for the given one-hot encoded FSM. For each current state bit set in 'state', apply the transition rules depending on 'in' to determine which next state bits should be set in 'next_state'. The outputs 'out1' and 'out2' are driven by states S7, S8, and S9 only, according to the problem statement. Since multiple states can be active simultaneously, next_state is the OR of all possible next states from all active current states. Outputs are set if any active state contributes to them.
