Design a finite state machine with the following states:
- IDLE: line is idle and high (1), waiting for start bit (0).
- START: start bit detected, begin counting data bits.
- DATA: receiving 8 data bits, shifting them in (though data bits themselves are not required to be stored for this problem).
- STOP: expect stop bit (1). If correct, output done=1 for one clock cycle indicating a correctly received byte.
- ERROR: if stop bit is not 1 when expected, wait here until line goes to 1 (stop bit) before returning to IDLE to look for next byte.

Use a counter to count data bits. The FSM synchronously resets on active high reset.

The output done is asserted for one clock cycle immediately after a valid stop bit is detected.

The input 'in' is the serial bit stream. The least significant bit is sent first, but since we only need to identify correct bytes, we don't need to reconstruct the byte, just detect the correct framing.

All sequential logic triggers on posedge clk.
