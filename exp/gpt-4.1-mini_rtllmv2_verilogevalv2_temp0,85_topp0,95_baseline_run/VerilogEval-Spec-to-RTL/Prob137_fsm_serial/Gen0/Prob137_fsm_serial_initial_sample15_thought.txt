I will implement an FSM with the following states: IDLE (line high), START (detect start bit 0), DATA (receive 8 data bits), STOP (check stop bit 1), and ERROR (waiting for stop bit if wrong). The FSM waits in IDLE until a start bit (0) is detected, then samples 8 data bits on consecutive clock edges, least significant bit first. After data bits, it checks for the stop bit (1). If the stop bit is correct, output done=1 for one cycle and return to IDLE. If stop bit is wrong, go to ERROR state and remain there until a stop bit is seen, then return to IDLE. The reset synchronously resets FSM to IDLE with done=0.
