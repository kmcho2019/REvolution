Implement a finite state machine with states: IDLE (waiting for start bit 0), DATA (counting and receiving 8 data bits), STOP (checking for stop bit 1), and WAIT_STOP (waiting for stop bit if stop bit was wrong). On reset, return to IDLE. The line is idle high (1). When in IDLE, wait for start bit (0). When found, shift in data bits on each clock, counting to 8. Then check stop bit; if it is 1, assert done for one cycle and return to IDLE. If stop bit is 0, enter WAIT_STOP and stay there until stop bit (1) is found, then return to IDLE without asserting done. The done output pulses high for one clock cycle upon successful byte reception.
