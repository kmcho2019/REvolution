Implement an FSM with states IDLE, START, DATA, STOP, and ERROR. In IDLE state, wait for start bit (0). When start bit detected, transition to DATA to receive 8 bits serially, shifting in LSB first. After 8 bits, move to STOP state to check for stop bit (1). If stop bit received correctly, assert done high for one cycle and return to IDLE. If stop bit incorrect, enter ERROR state and wait until line goes to 1 (stop bit), then return to IDLE. Use synchronous reset to initialize FSM to IDLE.
