Implement a finite state machine (FSM) with states: IDLE, START, DATA, STOP, and WAIT_STOP. 
- In IDLE, wait for a 0 start bit. 
- In START, verify start bit still 0, then move to DATA. 
- In DATA, shift in 8 data bits LSB first. 
- In STOP, check for stop bit (1). If correct, assert done for one clock cycle and return to IDLE. 
- If stop bit incorrect, move to WAIT_STOP state, stay there until input is 1 (stop bit), then return to IDLE. 
Use synchronous active-high reset to return to IDLE. 
The output done is asserted for one clock cycle when a byte has been successfully received.
