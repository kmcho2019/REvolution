Implement a finite state machine (FSM) with states for idle, receiving data bits, and waiting for a valid stop bit. The line is idle when 'in' is 1. When a 0 start bit is detected, transition to data bit reception state and count 8 data bits. After receiving 8 bits, check the stop bit. If stop bit is 1, assert done for one clock cycle and return to idle. If stop bit is not 1, enter a wait state until the line returns to 1 (stop bit) before returning to idle. Use a synchronous reset to return to idle state.
