Implement a FSM with states: IDLE (waiting for start bit), DATA (receiving 8 data bits), STOP (checking stop bit), and WAIT_STOP (waiting for stop bit after error). On reset, go to IDLE. When in IDLE and input is 0 (start bit), move to DATA and start counting bits. After 8 bits received, move to STOP state and check if input is 1 (stop bit). If yes, assert done for one cycle and return to IDLE. If not, move to WAIT_STOP state and stay there until input is 1, then return to IDLE. The done signal is high for one clock cycle immediately after a byte is correctly received (correct start, data, and stop bits).
