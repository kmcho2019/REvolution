Design a finite state machine (FSM) with the following states: IDLE (waiting for start bit), DATA (receiving 8 data bits), STOP (checking stop bit), and WAIT_STOP (waiting for stop bit after an error). On reset, go to IDLE. In IDLE, wait for in == 0 (start bit). Then shift in data bits LSB first over 8 clock cycles. Then check for stop bit == 1. If stop bit is 1, assert done high for one clock cycle, then return to IDLE. If stop bit is 0, enter WAIT_STOP and wait until in == 1 (stop bit), then return to IDLE. The done signal is asserted for one clock cycle right after the correct stop bit is detected. This FSM does not output the received data, only indicates when a valid byte is received.
