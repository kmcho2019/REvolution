Implement a finite state machine with states: IDLE, DATA, STOP, and WAIT_STOP. 
- In IDLE, wait for start bit (in == 0).
- In DATA, shift in 8 data bits on each clock cycle.
- After 8 data bits, go to STOP and check if the stop bit (in == 1) is correct.
- If stop bit is correct, assert done for one clock cycle and return to IDLE.
- If stop bit is incorrect, go to WAIT_STOP and wait until in == 1 (stop bit detected), then return to IDLE.
Use a counter to track the number of data bits received. Reset all state and counters synchronously.
