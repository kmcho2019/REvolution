Design a finite state machine with states for idle, receiving data bits, and waiting for the stop bit. The line is idle (logic 1). When a start bit (0) is detected, transition to a state to shift in 8 data bits, counting the bits received. After 8 bits, expect a stop bit (1). If the stop bit is correct, assert done for one clock cycle and return to idle. If the stop bit is incorrect (not 1), stay in a wait-for-stop-bit state until a stop bit (1) is observed, then return to idle. Use a synchronous reset to return to the idle state. The done output is asserted for one clock cycle when a byte is correctly received.
