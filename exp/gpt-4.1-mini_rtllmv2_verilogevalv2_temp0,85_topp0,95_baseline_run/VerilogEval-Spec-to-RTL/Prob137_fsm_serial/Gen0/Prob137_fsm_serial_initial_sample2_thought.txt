Implement an FSM with the following states: IDLE (line is high, waiting for start bit), START (confirm start bit 0), DATA (shift in 8 bits), STOP (check stop bit 1), and WAIT_STOP (if stop bit invalid, wait until line goes high again). The 'done' output is asserted for one clock cycle when a correct byte reception completes (after confirming the stop bit). Use a bit counter to count received data bits. Synchronous reset sets FSM to IDLE. The input 'in' is sampled on each clock to progress through the protocol.
