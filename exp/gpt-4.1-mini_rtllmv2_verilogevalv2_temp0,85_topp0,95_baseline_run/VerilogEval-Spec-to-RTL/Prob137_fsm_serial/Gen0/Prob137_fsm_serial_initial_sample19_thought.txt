Implement an FSM with the following states: IDLE (line idle, waiting for start bit), START (start bit detected), DATA (receiving 8 data bits), STOP_WAIT (waiting for stop bit if incorrect stop bit detected), and DONE (valid byte received). The FSM transitions from IDLE when it detects a start bit (0). Then it collects 8 data bits (LSB first) while counting bits. Next, it checks the stop bit: if it is 1, assert done for one cycle and then return to IDLE. If the stop bit is incorrect (not 1), move to STOP_WAIT and wait until the input line is 1 again (stop bit detected), then return to IDLE. The done signal is asserted only for one clock cycle when a byte has been correctly received (start bit, 8 data bits, stop bit = 1). The reset synchronously resets the FSM to IDLE and clears all counters and done signal.
