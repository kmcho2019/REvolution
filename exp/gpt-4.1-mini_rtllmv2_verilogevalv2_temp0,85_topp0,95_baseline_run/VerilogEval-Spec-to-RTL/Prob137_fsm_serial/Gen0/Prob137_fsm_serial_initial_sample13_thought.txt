Implement a finite state machine with the following states: IDLE (waiting for start bit), RECEIVE (shifting in 8 data bits), STOP (checking for stop bit), and WAIT_STOP (waiting for a valid stop bit if the received stop bit was invalid). On reset, go to IDLE. When the start bit (0) is detected in IDLE, move to RECEIVE and shift in 8 data bits (LSB first) over 8 clock cycles. Then move to STOP and check if the input bit is 1 (valid stop bit). If valid, output done=1 for one clock cycle and then return to IDLE. If invalid, move to WAIT_STOP and keep waiting until a 1 is seen (stop bit), then return to IDLE. The done output is a one-clock pulse indicating a valid byte was received.
