Implement a FSM with these states: IDLE (waiting for start bit), DATA (receiving 8 data bits), STOP (checking stop bit), and WAIT_STOP (waiting for stop bit if wrong stop bit detected). On reset, go to IDLE. When in IDLE, wait for input low (start bit). Then shift in 8 bits on each clock while counting. After 8 bits, check stop bit (should be 1). If stop bit is correct, assert done for one cycle, then go back to IDLE. If stop bit incorrect, go to WAIT_STOP and stay there until input is 1 (stop bit detected), then go to IDLE. done is asserted high for one clock cycle when a byte is correctly received with proper stop bit. The data bits themselves are shifted in but not output or stored externally since the problem doesn't require it.
