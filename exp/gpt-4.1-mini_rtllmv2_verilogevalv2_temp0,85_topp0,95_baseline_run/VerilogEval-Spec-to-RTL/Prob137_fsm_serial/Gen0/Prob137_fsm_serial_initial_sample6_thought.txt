Implement a finite state machine with these states: IDLE (waiting for start bit), RECEIVE (receiving 8 data bits), STOP_WAIT (waiting for stop bit if stop bit was missed), and DONE (signaling successful reception of a byte). On reset, go to IDLE. When in IDLE, wait for start bit (0). When start bit detected, move to RECEIVE and count 8 data bits by shifting them in (though data content is not required, just count bits). After 8 bits, expect stop bit (1). If stop bit is 1, output done = 1 for one clock cycle and return to IDLE. If stop bit is 0, go to STOP_WAIT, which waits until line goes to 1 (stop bit), then return to IDLE. 'done' is asserted high for one clock cycle when a valid byte (start, 8 bits, stop) is received.
