Implement a finite state machine with states IDLE, START, DATA (counting 8 bits), STOP, and WAIT_STOP. 
- IDLE waits for a start bit (0). 
- START confirms start bit and transitions to DATA to receive 8 bits, shifting them in (though data bits aren't output or stored in this problem).
- After 8 bits, move to STOP state where the stop bit (1) is checked. 
- If stop bit is 1, assert done for one clock cycle, then return to IDLE. 
- If stop bit is 0, go to WAIT_STOP and stay there until a 1 is detected (stop bit) before returning to IDLE.
All registers are updated on the positive edge of clk, with synchronous active-high reset.
