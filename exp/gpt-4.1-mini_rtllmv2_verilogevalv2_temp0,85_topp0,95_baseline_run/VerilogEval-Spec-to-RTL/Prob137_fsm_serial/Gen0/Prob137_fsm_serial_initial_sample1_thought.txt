Implement a finite state machine with states: IDLE, START, DATA, STOP, and WAIT_STOP. 
- IDLE: Wait for start bit (0). 
- START: Confirm start bit, then move to DATA. 
- DATA: Shift in 8 data bits, LSB first. 
- STOP: Check stop bit (should be 1). If correct, assert done for one cycle and go to IDLE.
- If stop bit incorrect, go to WAIT_STOP state where we wait until line is 1 again before restarting.

Use a counter to count 8 data bits received. The done signal is asserted for one clock cycle when a byte is correctly received with valid start and stop bits.

Synchronous active-high reset initializes FSM to IDLE.
