Implement a finite state machine with the following states: IDLE, START_BIT, DATA_BITS, STOP_BIT, and WAIT_STOP. The FSM monitors the input bit stream. Initially, it waits in IDLE state with line idle high (1). When it detects a start bit (0), it moves to START_BIT state to confirm start bit. Then it shifts in 8 data bits (least significant bit first) in DATA_BITS state. After receiving 8 bits, it checks the stop bit in STOP_BIT state; if the stop bit is 1, it asserts done for one clock cycle and returns to IDLE. If the stop bit is not 1, it goes to WAIT_STOP state and waits until a 1 is seen on input before returning to IDLE. The done output is asserted high for one clock cycle when a byte is correctly received. The FSM resets synchronously to IDLE and clears done on reset.
