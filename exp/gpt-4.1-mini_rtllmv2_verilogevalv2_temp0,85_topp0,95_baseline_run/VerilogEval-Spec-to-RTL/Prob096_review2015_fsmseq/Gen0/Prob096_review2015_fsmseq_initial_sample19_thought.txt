Implement a finite state machine (FSM) that detects the sequence 1101 on the input stream. The FSM will have states representing the progress through the sequence: 
- S0: no bits matched
- S1: matched '1'
- S2: matched '11'
- S3: matched '110'
- S4: matched '1101' (sequence found)

When the FSM reaches S4, set start_shifting to 1 and keep it set until a synchronous reset occurs. The FSM should transition appropriately on each clock cycle based on the input bit. Reset is synchronous and active high, resetting the FSM to S0 and start_shifting to 0.

The output start_shifting remains 0 until the sequence is detected, then stays 1 forever until reset.
