Implement a finite state machine that detects the sequence 1101 in the serial input 'data'. The FSM will have states representing how much of the sequence has been matched so far. Once the full sequence is detected, the output 'start_shifting' is set to 1 permanently until a synchronous reset is asserted. The FSM transitions and output are updated on the rising edge of 'clk'. On reset, the FSM returns to the initial state and clears 'start_shifting'.
