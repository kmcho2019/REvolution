Implement a finite state machine (FSM) with states representing how much of the sequence "1101" has been matched so far. On each clock cycle, the FSM transitions based on the input bit, searching for the sequence "1101". Once the full sequence is detected, the output start_shifting is set to 1 and remains set until a synchronous reset occurs. Reset clears the FSM back to the initial state and clears start_shifting. The FSM transitions and output are updated on the rising edge of clk.
