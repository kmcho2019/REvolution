To detect a 0-to-1 transition for each bit of an 8-bit input vector, we can register the previous state of the input on each clock cycle. Then, on the next cycle, compare the previous input bit and the current input bit: if the previous bit was 0 and the current bit is 1, it indicates a 0-to-1 transition. The output pedge should be set for that bit during the cycle after the transition is detected, so we produce the pedge output based on this comparison.
