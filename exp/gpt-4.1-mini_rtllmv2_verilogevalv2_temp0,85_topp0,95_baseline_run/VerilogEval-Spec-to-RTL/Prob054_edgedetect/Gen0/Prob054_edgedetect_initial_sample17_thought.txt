To detect a 0-to-1 transition on each bit of the 8-bit input vector, we need to store the previous state of the input bits on each clock cycle. Then, compare the current input with the previous input. For each bit, if the previous state was 0 and the current state is 1, we detect a positive edge. The output pedge bits should be set one clock cycle after the positive edge is detected, which means the output is the registered version of the detected edges.
