To detect a 0-to-1 transition on each bit of the 8-bit input vector, we need to store the previous state of the input bits. On each clock cycle, we compare the previous input bits with the current input bits. If the previous bit was 0 and the current bit is 1, that indicates a positive edge on that bit. The output pedge for that bit should be set in the next cycle. Thus, pedge will be updated with the detected edges from the previous cycle's comparison.
