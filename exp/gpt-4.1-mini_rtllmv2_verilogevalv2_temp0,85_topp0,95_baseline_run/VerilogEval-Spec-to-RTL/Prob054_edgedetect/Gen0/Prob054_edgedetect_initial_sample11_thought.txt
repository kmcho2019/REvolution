To detect a 0-to-1 transition on each bit of an 8-bit input vector, we need to store the previous state of the input bits on each clock cycle. We then compare the stored previous value with the current input. For each bit, if the previous value was 0 and the current value is 1, a rising edge on that bit is detected. The output pedge should be set to 1 the clock cycle after the transition, so we register the detection and output it in the next cycle.
