To detect a 0 to 1 transition on each bit of the 8-bit input, we need to store the previous input state on each clock cycle. Then, for each bit, we check if the previous bit was 0 and the current bit is 1. The output pedge bit for that position will be set in the cycle after the transition occurs, i.e., when the stored previous bit was 0 and the current bit is 1. This means pedge = previous_in == 0 and current_in == 1. We register the input on every clock to have the previous_in.
