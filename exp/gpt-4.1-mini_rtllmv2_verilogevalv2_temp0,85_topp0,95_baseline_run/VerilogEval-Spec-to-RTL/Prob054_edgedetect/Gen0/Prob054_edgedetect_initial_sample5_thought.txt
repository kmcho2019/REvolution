To detect a 0-to-1 transition for each bit in the 8-bit input vector, we need to store the previous cycle's input bits and compare them with the current input bits. For each bit, if the previous input was 0 and the current input is 1, then a positive edge has occurred. The output bits (pedge) should be set in the cycle after this detection, so we register the detection to output in the next clock cycle.
