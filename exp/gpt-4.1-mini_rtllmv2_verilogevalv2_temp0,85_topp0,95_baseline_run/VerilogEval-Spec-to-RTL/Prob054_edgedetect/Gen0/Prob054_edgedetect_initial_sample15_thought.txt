To detect a 0 to 1 transition for each bit in the 8-bit input vector, we store the previous state of the input bits in a register. On each clock cycle, we compare the current input bits with the previous bits. If a bit was 0 in the previous cycle and 1 in the current cycle, we mark a positive edge detected for that bit. The output is registered and updated in the next clock cycle, meaning the pedge output reflects the detection of the 0 to 1 transition from the previous cycle.
