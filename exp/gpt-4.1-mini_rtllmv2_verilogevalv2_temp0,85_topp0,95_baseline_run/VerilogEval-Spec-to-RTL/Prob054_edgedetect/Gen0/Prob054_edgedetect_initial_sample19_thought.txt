To detect a 0-to-1 transition on each bit of the input vector, we can store the previous value of the input in a register on each clock cycle. Then, we compare the previous input and the current input for each bit: if the previous bit was 0 and the current bit is 1, we have detected a positive edge on that bit. Since the output should be set the cycle after the transition occurs, we register the detection result and output it on the next clock cycle.
