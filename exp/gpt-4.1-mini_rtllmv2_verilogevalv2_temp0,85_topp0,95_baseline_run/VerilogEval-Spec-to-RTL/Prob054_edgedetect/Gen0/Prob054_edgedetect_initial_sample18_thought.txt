To detect a 0-to-1 transition on each bit of the 8-bit input vector 'in', we need to store the previous state of 'in' in a register on every clock cycle. Then, compare the previous state and the current state bit-by-bit: if a bit was 0 previously and is now 1, it means a positive edge occurred on that bit. The output 'pedge' should reflect this detection one cycle after the transition, so we can generate 'pedge' as (previous_in == 0) & (current_in == 1).
