Implement a 4-bit right shift register with asynchronous active-high reset (areset), synchronous load and enable signals. On reset, the register is cleared to zero asynchronously. On clock's positive edge, if load is high, load the input data into the register. Otherwise, if ena is high, shift right by one bit with the MSB set to zero. The load signal has priority over ena when both are asserted. Output q reflects the current register contents.
