Implement a 4-bit shift register with asynchronous active-high reset. On reset, output is cleared to zero. On each positive clock edge, if load is high, load the input data directly into the register. Otherwise, if ena is high (and load is low), shift the register right by one bit, inserting zero at the most significant bit. The shift is right, so q[3] is set to 0 on shift. Load has priority over enable.
