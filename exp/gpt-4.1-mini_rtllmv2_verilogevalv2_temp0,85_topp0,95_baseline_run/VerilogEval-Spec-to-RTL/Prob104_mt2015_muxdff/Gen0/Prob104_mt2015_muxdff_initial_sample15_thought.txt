The TopModule should implement a single bit of the three-bit register q in full_module. It has a clock input clk, a load enable input L, and inputs q_in and r_in. When L is asserted on the rising edge of clk, the flip-flop should load r_in; otherwise, it should load q_in. This can be done by using a 2:1 multiplexer to select between q_in and r_in controlled by L, feeding the output to a flip-flop triggered on clk.
