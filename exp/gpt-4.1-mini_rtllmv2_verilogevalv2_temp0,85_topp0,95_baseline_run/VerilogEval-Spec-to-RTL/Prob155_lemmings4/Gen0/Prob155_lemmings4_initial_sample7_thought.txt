We model the Lemming behavior with a Moore FSM and a fall timer.

States:
- WALK_LEFT
- WALK_RIGHT
- FALL_LEFT (falling, original direction left)
- FALL_RIGHT (falling, original direction right)
- DIG_LEFT (digging, original direction left)
- DIG_RIGHT (digging, original direction right)
- SPLAT (dead, no outputs active)

Transitions:
- Reset to WALK_LEFT.

Walking states:
- If ground=0, transition to FALL_x (based on current direction).
- Else if dig=1, transition to DIG_x (same direction).
- Else if bumped on left or right, switch walking direction.
- Else remain.

Falling states:
- Increment fall timer each cycle.
- If ground=1:
  - If fall timer > 20, go to SPLAT.
  - Else go to WALK_x (original direction).
- Else remain falling.

Digging states:
- If ground=0, transition to FALL_x (same direction).
- Else remain digging.

Bumping has no effect when falling or digging.

Outputs depend on state:
- WALK_LEFT: walk_left=1
- WALK_RIGHT: walk_right=1
- FALL_x: aaah=1
- DIG_x: digging=1
- SPLAT: all outputs 0

Implementation:
- Use a 3-bit state encoding.
- Use a 5-bit fall timer to count up to 21.
- Asynchronous posedge reset to WALK_LEFT and reset fall timer.
