Model the Lemming behavior using a Moore FSM with states representing:
- Walking left
- Walking right
- Falling left
- Falling right
- Digging left
- Digging right
- Splattered (terminal state)

The walking states encode the walking direction. Falling states encode falling direction and count the fall duration. Digging states encode digging direction.

Priority of transitions per cycle:
1. If splattered, remain splattered.
2. If falling and ground becomes 1:
   - If fall duration > 20 cycles, transition to splattered.
   - Else resume walking in the same direction.
3. Else if falling (ground=0), continue falling and increment fall counter.
4. Else if walking or digging on ground:
   - If ground=0, start falling (fall counter reset).
   - Else if digging=1 and currently walking on ground, start digging.
   - Else if digging=0 and currently digging on ground, continue digging.
   - Else if bumped (left or right) and walking (not digging), switch direction.
   - Else remain in current walking or digging state.
5. Digging ends immediately when ground=0, switching to falling.

Outputs:
- walk_left = 1 only in walking left state.
- walk_right = 1 only in walking right state.
- aaah = 1 only in any falling state.
- digging = 1 only in any digging state.

areset asynchronously resets FSM to walk_left state, fall counter zero.

The design uses one state register, one fall counter, and combinational logic for next state and outputs.
