Design a Moore FSM with the following states:

- WALK_LEFT: walking left on ground
- WALK_RIGHT: walking right on ground
- FALL_LEFT: falling while last walking left
- FALL_RIGHT: falling while last walking right
- DIG_LEFT: digging while last walking left
- DIG_RIGHT: digging while last walking right
- SPLAT: splattered state (all outputs zero)

On reset, go to WALK_LEFT.

Transitions:

- From WALK_LEFT/RIGHT:
  - If ground==0, go to FALL_LEFT/RIGHT and start fall counter.
  - Else if dig==1, go to DIG_LEFT/RIGHT.
  - Else if bump_left==1 or bump_right==1 (or both):
    - If bump_left, direction becomes walk_right.
    - If bump_right, direction becomes walk_left.
    (If both bump_left and bump_right, direction switches anyway.)
  - Else stay in current walking state.

- From DIG_LEFT/RIGHT:
  - If ground==0, transition to FALL_LEFT/RIGHT and start fall counter.
  - Else continue digging.

- From FALL_LEFT/RIGHT:
  - Increment fall counter each cycle.
  - If ground==1 (landed):
    - If fall counter > 20, go to SPLAT.
    - Else return to WALK_LEFT/RIGHT.
  - Else continue falling.

- SPLAT: remain here forever.

Outputs based on state (Moore):

- WALK_LEFT: walk_left=1, others=0
- WALK_RIGHT: walk_right=1, others=0
- FALL_LEFT/RIGHT: aaah=1, others=0
- DIG_LEFT/RIGHT: digging=1, others=0
- SPLAT: all zero

Implement asynchronous posedge reset to WALK_LEFT state and reset fall counter.
