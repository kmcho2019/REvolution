Implement a 3-state FSM: IDLE, BYTE2, BYTE3. Initially, the FSM is in IDLE, discarding bytes until it sees in[3] == 1, which indicates the start of a message. Once found, it transitions to BYTE2 to receive the second byte, then to BYTE3 for the third byte. After receiving the third byte, it asserts done for one clock cycle, then returns to IDLE to look for the next message start. The done signal is asserted for one cycle immediately after the third byte is received. Reset is synchronous and active high.
