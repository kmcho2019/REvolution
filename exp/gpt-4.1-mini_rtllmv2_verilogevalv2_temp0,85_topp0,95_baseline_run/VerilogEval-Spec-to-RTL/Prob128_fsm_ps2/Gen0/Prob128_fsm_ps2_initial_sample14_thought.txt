Implement a three-state FSM: IDLE, BYTE2, BYTE3. Start in IDLE and ignore bytes until a byte with in[3] = 1 is found, then move to BYTE2. On the next clock cycles, receive the second and third bytes without checking in[3]. After the third byte, assert done for one cycle and return to IDLE, looking for the next message. Use synchronous reset to reset the state and done signal.
