Implement a 2-bit FSM to track the byte count within the 3-byte PS/2 message. The states represent how many bytes of the current message have been received (0, 1, or 2). On reset, go to state 0 (waiting for a start byte). When in state 0, ignore bytes until a byte with in[3]=1 arrives, then move to state 1 (first byte received). Then, on subsequent bytes, increment the state until state 3 (3 bytes received). When the third byte is received, assert done for one clock cycle and return to state 0 to look for the next message start. done is high for exactly one cycle immediately after the third byte of each message is received.
