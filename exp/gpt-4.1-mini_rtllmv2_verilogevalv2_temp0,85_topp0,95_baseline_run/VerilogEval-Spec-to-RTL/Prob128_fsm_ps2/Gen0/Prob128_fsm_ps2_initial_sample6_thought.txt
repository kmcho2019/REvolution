Implement a simple 3-state FSM to track message reception. States:
IDLE: Waiting for a byte with in[3] = 1 to mark the start of a message.
BYTE2: Received first byte, waiting for second byte.
BYTE3: Received second byte, waiting for third byte.
When the third byte is received, assert done for one clock cycle on the next cycle.
Use a counter or state variable to track bytes within a message.
Reset synchronously sets FSM to IDLE and clears done.
done is asserted for one clock cycle immediately after receiving the third byte.
