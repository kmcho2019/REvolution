We implement a 3-state FSM: IDLE, BYTE2, BYTE3. Initially, in IDLE state, the FSM discards bytes until it sees a byte with in[3] == 1, indicating the start of a message. On detecting the first byte, it moves to BYTE2 state to receive the second byte, then to BYTE3 for the third byte. After receiving the third byte, it asserts done for one clock cycle and returns to IDLE to search for the next message. Reset synchronously returns FSM to IDLE and clears done signal.
