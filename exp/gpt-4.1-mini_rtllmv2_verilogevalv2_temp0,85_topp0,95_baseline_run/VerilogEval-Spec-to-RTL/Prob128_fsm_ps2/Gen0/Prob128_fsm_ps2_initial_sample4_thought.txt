Implement a 2-bit state FSM: IDLE, BYTE1, BYTE2. On reset, go to IDLE. While in IDLE, ignore input bytes until a byte with in[3]=1 is detected, then transition to BYTE1. On next clock cycle, move to BYTE2, then after receiving the third byte, assert done for one cycle and return to IDLE to look for the next message. done is asserted one cycle after the third byte is received.
