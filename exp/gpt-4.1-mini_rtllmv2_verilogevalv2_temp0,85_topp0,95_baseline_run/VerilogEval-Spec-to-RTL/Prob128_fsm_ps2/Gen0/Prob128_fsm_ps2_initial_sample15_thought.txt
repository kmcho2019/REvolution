Implement a 4-state FSM: IDLE (searching for first byte with in[3]=1), BYTE1 (first byte received), BYTE2 (second byte received), BYTE3 (third byte received). On reset, go to IDLE. On each clock, if in IDLE and in[3]=1, move to BYTE1; if in BYTE1, move to BYTE2; if in BYTE2, move to BYTE3; if in BYTE3, assert done and then return to IDLE or next message based on in[3]. The done output is asserted for one clock cycle immediately after the third byte is received. If a new first byte appears unexpectedly, restart the counting accordingly.
