Implement an FSM with four states: IDLE (waiting for first byte), BYTE1 (received first byte), BYTE2 (received second byte), and DONE. On reset, state goes to IDLE. In IDLE, discard bytes until a byte with in[3]=1 is received, then go to BYTE1. Next clock cycles transition through BYTE2 and DONE states, counting bytes of the message. Output done is asserted for one clock cycle immediately after the third byte is received (at DONE state), then the FSM returns to IDLE to search for the next message start.
