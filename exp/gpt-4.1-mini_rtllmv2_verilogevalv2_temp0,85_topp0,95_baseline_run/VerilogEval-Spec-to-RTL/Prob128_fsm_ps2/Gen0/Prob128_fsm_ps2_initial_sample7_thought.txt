Implement a simple FSM with four states: IDLE (waiting for first byte), BYTE1 (received first byte), BYTE2 (received second byte), and DONE (signal done after third byte). On reset, go to IDLE. On each clock cycle, if in IDLE and in[3] = 1, move to BYTE1; else stay in IDLE. From BYTE1 move to BYTE2; from BYTE2 move to DONE. In DONE, assert done = 1 for one cycle, then return to IDLE waiting for next message. done is asserted only for one clock cycle immediately after the third byte is received.
