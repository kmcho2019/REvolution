Implement a 2-bit FSM with states: IDLE (waiting for byte with in[3]=1), BYTE2 (second byte received), BYTE3 (third byte received). On reset, go to IDLE. On each clock, if in IDLE and in[3]=1, move to BYTE2; if in BYTE2, move to BYTE3; if in BYTE3, assert done and move back to IDLE. The done signal is asserted for one clock cycle immediately after the third byte is received. If in BYTE2 or BYTE3 and in[3]=1 unexpectedly, treat it as a new message start (reset counting).
