Design a finite state machine with four states: IDLE (waiting for a byte with in[3]=1), BYTE1 (received first byte), BYTE2 (received second byte), BYTE3 (received third byte). On reset, return to IDLE. On each clock cycle, if in[3]=1 and in IDLE, move to BYTE1; else stay in IDLE. When in BYTE1 and a new byte arrives, go to BYTE2; then BYTE3 on the next byte; after BYTE3, assert done for one clock cycle and return to IDLE to look for the next message start. done is asserted only for one clock cycle immediately after the third byte is received.
