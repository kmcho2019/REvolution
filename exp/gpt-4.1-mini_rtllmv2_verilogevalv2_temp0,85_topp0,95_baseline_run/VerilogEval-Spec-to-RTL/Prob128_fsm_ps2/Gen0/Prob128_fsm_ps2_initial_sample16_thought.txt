Implement a 3-state FSM to detect PS/2 mouse message boundaries based on in[3]. The FSM starts in an IDLE state, discarding bytes until it sees a byte with in[3]=1, which marks the start of a message. Then it moves to BYTE2 state after the first byte, then BYTE3 state after the second byte, and after the third byte, it signals done for one cycle and returns to IDLE to look for the next message. The reset is synchronous and active high. The done output is asserted for one clock cycle immediately after the third byte is received.
