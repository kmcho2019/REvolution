Implement a 4-state FSM with states: WAIT_FOR_START, BYTE1_RECEIVED, BYTE2_RECEIVED, BYTE3_RECEIVED. On reset, go to WAIT_FOR_START. On each clock cycle, if in WAIT_FOR_START and input byte's bit 3 is 1, move to BYTE1_RECEIVED; else stay in WAIT_FOR_START. When in BYTE1_RECEIVED, accept next byte and move to BYTE2_RECEIVED; then BYTE3_RECEIVED on next byte. After BYTE3_RECEIVED, assert done for one cycle and return to WAIT_FOR_START to search for the next message. done is synchronous and asserted only for one cycle after the third byte is received. Input bytes are assumed to be presented on every clock cycle.
