The Karnaugh map shows a repeating pattern based on the combination of inputs a,b and c,d. The pattern alternates 0 and 1 in a checkerboard fashion. This corresponds to the XOR operation between the concatenated bits ab and cd. Therefore, the output can be implemented as the XOR of (a,b) and (c,d) interpreted as 2-bit values. In other words, out = (ab) XOR (cd) parity. Since each input is a single bit, the output can be expressed as a⊕b⊕c⊕d.
