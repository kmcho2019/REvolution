The Karnaugh map defines the output for each combination of inputs a,b,c,d where ab and cd form the rows and columns. Observing the pattern, the output is 1 if the parity of the input bits is odd for the specified combinations. More specifically, the output toggles between 0 and 1 depending on the XOR of a, b, c, d. By inspection, the pattern corresponds to output = (a XOR b XOR c XOR d), which matches the alternating pattern in the K-map.
