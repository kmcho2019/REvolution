The given Karnaugh map is a 4-variable map with variables a,b for columns and c,d for rows. 
Looking at the map pattern, the output is 1 when the sum of the number of 1s in (a,b,c,d) is odd.
This corresponds to an odd parity function over inputs a,b,c,d.
Thus, the output can be implemented as the XOR of all inputs: out = a ^ b ^ c ^ d.
