The Karnaugh map is a 4-variable map with inputs a, b, c, d, where 'ab' represents the column and 'cd' represents the row.
The map:
       ab
cd    00 01 11 10
00    0  1  0  1
01    1  0  1  0
11    0  1  0  1
10    1  0  1  0

Observing the pattern, the output is 1 when the number of ones in (a,b,c,d) is odd.
In other words, the output is the XOR of all inputs.
So, out = a ^ b ^ c ^ d.
