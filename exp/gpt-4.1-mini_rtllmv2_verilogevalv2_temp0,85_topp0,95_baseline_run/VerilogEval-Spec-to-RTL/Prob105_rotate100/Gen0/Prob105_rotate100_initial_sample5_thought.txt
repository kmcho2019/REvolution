Implement a 100-bit register that synchronously loads input data when 'load' is high. On each clock cycle, if load is low, check the 2-bit enable input 'ena'. If ena == 2'b01, rotate the register right by one bit; if ena == 2'b10, rotate left by one bit. For ena == 2'b00 or 2'b11, maintain the current value (no rotation). Rotation is circular, meaning the bit shifted out from one end is inserted at the opposite end. Update the register value on the rising edge of clk, and output the register value on q.
