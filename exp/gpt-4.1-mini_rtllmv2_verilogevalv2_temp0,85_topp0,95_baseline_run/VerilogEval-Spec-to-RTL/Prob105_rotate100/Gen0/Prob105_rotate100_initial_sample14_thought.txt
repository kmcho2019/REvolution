Implement a 100-bit shift register with synchronous load and enable signals. On the rising edge of clk:
- If load is high, load the register with the input data.
- Else, based on ena:
  - If ena == 2'b01, rotate right by 1: the least significant bit moves to the most significant bit position.
  - If ena == 2'b10, rotate left by 1: the most significant bit moves to the least significant bit position.
  - If ena == 2'b00 or 2'b11, hold the current value.
Output the register value on q.
