Implement a 100-bit register that updates on the rising edge of clk. When load is high, the register loads the input data. Otherwise, if ena is 2'b01, the register rotates right by one bit (bit 0 becomes bit 99, bits [99:1] shift down by one). If ena is 2'b10, the register rotates left by one bit (bit 99 becomes bit 0, bits [98:0] shift up by one). For other ena values (2'b00 or 2'b11), the register holds its value. Output q continuously reflects the register contents.
