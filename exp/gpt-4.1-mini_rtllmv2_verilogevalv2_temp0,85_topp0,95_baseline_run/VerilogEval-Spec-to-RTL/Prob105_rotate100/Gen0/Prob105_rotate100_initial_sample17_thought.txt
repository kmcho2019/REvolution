Implement a 100-bit register that synchronously loads new data when load is high. On each clock edge when load is low, rotate the register contents either left or right by one bit if ena indicates so (ena=2'b01 for right rotate, ena=2'b10 for left rotate). If ena=2'b00 or 2'b11, hold the current value. Rotation is done by moving the MSB to LSB for left rotate, or LSB to MSB for right rotate. Output q reflects the current register contents.
