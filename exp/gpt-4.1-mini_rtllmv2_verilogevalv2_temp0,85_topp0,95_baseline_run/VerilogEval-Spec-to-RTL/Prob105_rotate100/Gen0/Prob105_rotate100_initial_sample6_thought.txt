Implement a 100-bit register that loads the input data synchronously on load=1.
When load=0, on each clock, if ena=2'b01, rotate right by one bit; if ena=2'b10, rotate left by one bit; if ena=2'b00 or 2'b11, hold the current value.
Rotation means the bit shifted out on one end is shifted in on the other end.
Output q continuously reflects the register contents.
