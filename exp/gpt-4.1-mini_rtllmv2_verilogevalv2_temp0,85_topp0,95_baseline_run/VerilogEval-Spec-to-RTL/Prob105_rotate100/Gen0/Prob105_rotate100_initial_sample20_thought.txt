Implement a 100-bit register updated on the rising edge of clk. If load is high, load the input data directly. Otherwise, check the ena control bits synchronously: if ena is 2'b01, rotate right by 1; if 2'b10, rotate left by 1; else hold the current value. The rotation is circular: the bit shifted out from one end is shifted in at the other. Output q is the current register value.
