Implement a 100-bit register updated on the rising edge of clk. On each clock cycle, if load is high, load the data input into the register. Otherwise, if ena indicates rotation, perform rotation accordingly: if ena == 2'b01, rotate right by 1 bit; if ena == 2'b10, rotate left by 1 bit; if ena == 2'b00 or 2'b11, keep the current value (no rotation). Output q is the current register contents.
