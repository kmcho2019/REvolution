Implement a 100-bit register with synchronous loading and rotation. On the rising edge of clk:
- If load is high, load the data input into the register.
- Else if ena == 2'b01, rotate right by one bit: shift all bits right, with bit 0 replaced by bit 99.
- Else if ena == 2'b10, rotate left by one bit: shift all bits left, with bit 99 replaced by bit 0.
- Else (ena == 2'b00 or 2'b11), hold the current value.
The output q is the current contents of the register.
