Implement a 100-bit register that on each rising clock edge does the following:
- If load is high, load the register with the input data.
- Else if ena indicates rotate right (2'b01), rotate the register bits right by 1.
- Else if ena indicates rotate left (2'b10), rotate the register bits left by 1.
- Else (ena = 2'b00 or 2'b11) do not change the register contents.
Output the current register contents on q.
