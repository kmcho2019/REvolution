Implement a 100-bit shift register with synchronous load and rotate functionality. On each clock edge:
- If load is high, load the data input into the register.
- Else, depending on ena:
  - If ena == 2'b01, rotate right by 1 bit (bit 0 becomes bit 1, ..., bit 99 becomes bit 0).
  - If ena == 2'b10, rotate left by 1 bit (bit 99 becomes bit 98, ..., bit 0 becomes bit 99).
  - Otherwise, hold the current value.
The output q is assigned to the current register value.
