Implement a 100-bit register that on each rising clock edge does the following:
- If load is high, load the input data directly into the register.
- Otherwise, if ena indicates a rotation:
  - If ena == 2'b01, rotate right by 1 bit (lowest bit moves to highest bit position).
  - If ena == 2'b10, rotate left by 1 bit (highest bit moves to lowest bit position).
- For ena == 2'b00 or 2'b11, hold the current value.
Output q continuously reflects the current register value.
