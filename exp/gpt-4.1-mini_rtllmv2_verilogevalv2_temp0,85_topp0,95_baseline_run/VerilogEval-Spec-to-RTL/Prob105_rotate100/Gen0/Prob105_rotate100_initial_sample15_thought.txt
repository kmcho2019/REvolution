Implement a 100-bit shift register with synchronous load and rotate functionality. On each clock edge:
- If load is high, load the 100-bit data into the register.
- Else if ena == 2'b01, rotate right by one bit by taking the LSB and shifting the rest right, placing LSB at MSB.
- Else if ena == 2'b10, rotate left by one bit by taking the MSB and shifting left, placing MSB at LSB.
- Otherwise, maintain the current value.
Output q is the current register value.
