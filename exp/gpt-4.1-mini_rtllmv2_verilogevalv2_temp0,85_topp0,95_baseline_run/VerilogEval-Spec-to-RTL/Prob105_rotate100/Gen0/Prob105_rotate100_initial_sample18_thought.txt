Implement a 100-bit register updated on the rising edge of clk. If load is high, load the register with data. Otherwise, if ena is 2'b01, rotate right by one bit (shift all bits right, with LSB wrapping to MSB). If ena is 2'b10, rotate left by one bit (shift all bits left, with MSB wrapping to LSB). If ena is 2'b00 or 2'b11, hold the register value. Output q is the current register contents.
