Implement a 4-bit register updated on each positive clock edge. If shift_ena is high, shift in the input data bit into the MSB, shifting others right. If count_ena is high (and shift_ena is low), decrement the current 4-bit value by one. Since the case where both are high is don't care, we can prioritize shift_ena over count_ena. Output the current 4-bit register value on q.
