Implement a 4-bit register that updates on the positive edge of clk. When shift_ena is high, shift in the data bit into the MSB, shifting the register right. When count_ena is high (and shift_ena is low), decrement the 4-bit value by 1. The output q is assigned to the current value of the register. If both enables are 1 simultaneously, behavior is unspecified, so priority can be arbitrary (e.g., prioritize shift_ena).
