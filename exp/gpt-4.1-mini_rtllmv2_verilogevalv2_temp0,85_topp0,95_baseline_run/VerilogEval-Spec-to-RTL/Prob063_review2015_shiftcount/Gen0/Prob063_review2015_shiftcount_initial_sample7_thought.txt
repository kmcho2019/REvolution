Implement a 4-bit shift register that either shifts in the input bit to the MSB if shift_ena is high, or decrements the current 4-bit value if count_ena is high, both on the positive edge of clk. When shift_ena is 1, shift the register left by one bit and load data into the MSB. When count_ena is 1 and shift_ena is 0, decrement the 4-bit register by 1. If both are 0, maintain the current value. Since the behavior when both are 1 does not matter, we can prioritize shift_ena over count_ena.
