Implement a 4-bit register that shifts left (MSB first) when shift_ena is high, shifting in the input 'data' at the MSB. When count_ena is high (and shift_ena is low), decrement the register value by 1. If both are high, behavior is unspecified, so we can prioritize either shift or count. Use a synchronous always block triggered on the positive edge of clk to update the register accordingly. Output the current 4-bit register value as q.
