Implement a 4-bit register updated on the positive edge of clk. When shift_ena is 1, shift in the input data into the MSB, shifting existing bits to the right. When count_ena is 1 (and shift_ena is 0), decrement the 4-bit value by 1. If both enables are 1, priority doesn't matter, so we can choose to prioritize shift_ena. Output the 4-bit register value on q.
