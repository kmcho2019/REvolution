Implement a 4-bit shift register with synchronous logic triggered on the positive edge of clk. When shift_ena is high, shift in the input data bit into the MSB, shifting existing bits to the right. When count_ena is high, decrement the 4-bit value by 1. If both shift_ena and count_ena are high, behavior is undefined so we can prioritize shift_ena. Output the current 4-bit register value on q.
