Implement a 4-bit register that on each positive clock edge either shifts in the input bit at the MSB (if shift_ena is high) or decrements the stored 4-bit value by one (if count_ena is high). Since both enables are not active simultaneously, no priority handling is needed beyond a simple if-else. The shift operation will shift left, inserting the new data bit into the MSB. The output q is the current value of this register.
