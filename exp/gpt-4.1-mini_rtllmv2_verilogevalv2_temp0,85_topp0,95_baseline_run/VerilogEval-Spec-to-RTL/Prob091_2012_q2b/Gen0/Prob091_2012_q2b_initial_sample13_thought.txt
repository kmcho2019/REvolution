The FSM has 6 states, each one-hot encoded in y[5:0]. The transitions depend on input w. For each state, we determine the next state, then express Y1 and Y3 as the inputs to the corresponding flip-flops y[1] and y[3].

States and encoding:
A = y[0]
B = y[1]
C = y[2]
D = y[3]
E = y[4]
F = y[5]

Transitions (current state -> next state based on w):

From A (y[0]):
  w=1 -> B (y[1])
  w=0 -> A (y[0])

From B (y[1]):
  w=1 -> C (y[2])
  w=0 -> D (y[3])

From C (y[2]):
  w=1 -> E (y[4])
  w=0 -> D (y[3])

From D (y[3]):
  w=1 -> F (y[5])
  w=0 -> A (y[0])

From E (y[4]):
  w=1 -> E (y[4])
  w=0 -> D (y[3])

From F (y[5]):
  w=1 -> C (y[2])
  w=0 -> D (y[3])

We want to find expressions for Y1 (input to y[1] flip-flop) and Y3 (input to y[3] flip-flop).

Y1 is the input of y[1] (B). B is next state when:
- From A with w=1 (A->B)
No other transitions lead to B.

So:
Y1 = A & w = y[0] & w

Y3 is the input of y[3] (D). D is next state when:
- From B with w=0 (B->D)
- From C with w=0 (C->D)
- From E with w=0 (E->D)
- From F with w=0 (F->D)

So:
Y3 = (B | C | E | F) & ~w
= (y[1] | y[2] | y[4] | y[5]) & ~w

We will implement this combinational logic for outputs Y1 and Y3.
