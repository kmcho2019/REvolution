The FSM uses one-hot encoding for states A to F with y[0] = A, y[1] = B, y[2] = C, y[3] = D, y[4] = E, y[5] = F.

Y1 is the input to flip-flop y[1] (state B), so we derive the logic for next state B. From the transitions:

- From A (y[0]) to B on input 1
- No other transitions lead to B

So,
Y1 = y[0] & w

Y3 is the input to flip-flop y[3] (state D), so next state D is reached from:

- B (y[1]) on 0
- C (y[2]) on 0
- E (y[4]) on 0
- F (y[5]) on 0

Therefore,
Y3 = (~w) & (y[1] | y[2] | y[4] | y[5])

We implement these combinational logic equations directly.
