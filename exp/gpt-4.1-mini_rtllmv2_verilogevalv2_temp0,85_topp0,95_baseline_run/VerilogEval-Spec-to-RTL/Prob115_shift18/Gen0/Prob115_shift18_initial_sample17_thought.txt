Implement a 64-bit shift register with synchronous load. On each rising clock edge, if load is high, load the input data into the register. Otherwise, if ena is high, shift the register according to the amount control signal: shift left by 1 or 8 bits, or shift right by 1 or 8 bits. For right shifts, perform arithmetic shift (i.e., sign-extend by replicating the MSB). Output the current register value on q.
