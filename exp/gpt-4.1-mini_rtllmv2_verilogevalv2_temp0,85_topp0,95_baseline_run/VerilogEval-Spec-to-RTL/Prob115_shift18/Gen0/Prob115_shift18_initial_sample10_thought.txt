Implement a 64-bit arithmetic shift register with synchronous load and enable. On each rising clock edge, if load is high, load the 64-bit data input into the register. Otherwise, if ena is high, perform the shift based on amount:

- For left shifts (2'b00 and 2'b01), shift left by 1 or 8 bits respectively, inserting zeros at the LSB.
- For right shifts (2'b10 and 2'b11), perform an arithmetic right shift by 1 or 8 bits respectively. This means shifting right and filling the MSBs with the sign bit (original MSB) to preserve the sign.

Output q always reflects the current register value.
