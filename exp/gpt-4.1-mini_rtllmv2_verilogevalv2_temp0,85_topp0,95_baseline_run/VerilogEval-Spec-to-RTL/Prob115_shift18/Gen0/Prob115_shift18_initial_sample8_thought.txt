Implement a 64-bit register with synchronous load and shift functionality. On each rising clock edge:
- If load is high, load the 64-bit data input into the register.
- Else if ena is high, shift the register contents according to the amount signal:
  - 2'b00: shift left by 1 bit (fill lower bits with zeros)
  - 2'b01: shift left by 8 bits (fill lower bits with zeros)
  - 2'b10: arithmetic shift right by 1 bit (fill upper bits with the sign bit)
  - 2'b11: arithmetic shift right by 8 bits (fill upper bits with the sign bit)
Output the current register value on q.
