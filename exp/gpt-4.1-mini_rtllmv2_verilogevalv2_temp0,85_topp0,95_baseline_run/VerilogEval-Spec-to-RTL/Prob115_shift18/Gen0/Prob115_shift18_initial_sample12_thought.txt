Implement a 64-bit register that updates on the rising edge of clk. On each clock cycle, if load is high, the register loads the input data directly. Otherwise, if ena is high, it shifts the register contents according to the amount input: left shifts by 1 or 8 bits, or arithmetic right shifts by 1 or 8 bits. For left shifts, zero-fill shifted-in bits; for arithmetic right shifts, fill shifted-in bits with the sign bit (q[63]). Output the current register value on q.
