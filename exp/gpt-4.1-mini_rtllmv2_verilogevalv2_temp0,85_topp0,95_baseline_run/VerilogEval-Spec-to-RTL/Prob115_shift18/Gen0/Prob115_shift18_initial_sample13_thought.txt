Implement a 64-bit register that on the rising edge of clk either loads data if load is high,
or if ena is high performs an arithmetic shift based on amount:
- For left shifts: logical shift left by 1 or 8 bits, filling shifted-in bits with 0.
- For right shifts: arithmetic shift right by 1 or 8 bits, filling shifted-in bits with the sign bit (MSB).
If neither load nor ena are high, retain the current value.
Output q is assigned the current register value.
