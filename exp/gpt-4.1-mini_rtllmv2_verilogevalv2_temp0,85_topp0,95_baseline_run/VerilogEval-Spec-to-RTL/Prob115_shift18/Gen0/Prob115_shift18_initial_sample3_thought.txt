Implement a 64-bit register updated on the rising edge of clk. If load is high, load data into the register. Else if ena is high, perform a shift according to amount:
- 2'b00: shift left by 1 bit (fill LSB with 0)
- 2'b01: shift left by 8 bits (fill LSBs with 0)
- 2'b10: arithmetic shift right by 1 bit (fill MSB with original MSB)
- 2'b11: arithmetic shift right by 8 bits (fill MSBs with original MSB)
Output q is the current register value.
