Implement a population count circuit that counts the number of '1's in a 255-bit input vector. To efficiently implement this, use a hierarchical adder tree approach: split the input into smaller groups, count the number of 1's in each group using built-in Verilog reduction operators or adders, then sum these counts progressively until the total count is obtained. Since the output is 8 bits, it can represent up to 255 (max count). The final output should be the total number of '1's in the 255-bit input.
