Implement combinational logic for the Moore state machine's next state and outputs using one-hot encoding for states. The current state is given by the 10-bit input `state` (one-hot). Based on the inputs `d`, `done_counting`, and `ack`, determine the next state by asserting the respective one-hot bit in next-state signals. Also generate the output signals (`done`, `counting`, `shift_ena`) based on the current state.

The states are encoded as one-hot in a 10-bit vector (bit 0: S, bit 1: S1, bit 2: S11, bit 3: S110, bit 4: B0, bit 5: B1, bit 6: B2, bit 7: B3, bit 8: Count, bit 9: Wait).

From the state diagram and encoding:
- From S (bit0):
  - d=0: next S (bit0)
  - d=1: next S1 (bit1)
- From S1 (bit1):
  - d=0: next S (bit0)
  - d=1: next S11 (bit2)
- From S11 (bit2):
  - d=0: next S110 (bit3)
  - d=1: next S11 (bit2)
- From S110 (bit3):
  - d=0: next S (bit0)
  - d=1: next B0 (bit4)
- From B0 (bit4):
  - next B1 (bit5)
- From B1 (bit5):
  - next B2 (bit6)
- From B2 (bit6):
  - next B3 (bit7)
- From B3 (bit7):
  - next Count (bit8)
- From Count (bit8):
  - done_counting=0: next Count (bit8)
  - done_counting=1: next Wait (bit9)
- From Wait (bit9):
  - ack=0: next Wait (bit9)
  - ack=1: next S (bit0)

Outputs (Moore, depend only on current state):
- shift_ena = 1 in states B0,B1,B2,B3
- counting = 1 in Count
- done = 1 in Wait

We will create combinational logic equations for next states signals and outputs, using the current state and inputs.

Then assign outputs for B3_next, S_next, S1_next, Count_next, Wait_next based on next state bits being asserted.

The module takes inputs:
- d
- done_counting
- ack
- state[9:0]

And outputs one-bit signals listed.

No sequential logic needed here, only combinational next-state and output logic.
