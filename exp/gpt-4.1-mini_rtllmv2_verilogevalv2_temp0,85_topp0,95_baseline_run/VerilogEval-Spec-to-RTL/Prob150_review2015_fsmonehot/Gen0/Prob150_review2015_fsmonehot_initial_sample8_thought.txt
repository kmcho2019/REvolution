Implement combinational next-state logic and output logic for the given Moore state machine, using the specified one-hot state encoding. Inputs are d, done_counting, ack, and the current one-hot state vector 'state' (10 bits). The module outputs signals indicating which state is next (B3_next, S_next, S1_next, Count_next, Wait_next) and the outputs done, counting, and shift_ena based on the current state.

The next state logic is derived by checking the current active state bit and input conditions.

States (one-hot encoding):

S     = 10'b0000000001 = bit 0  
S1    = 10'b0000000010 = bit 1  
S11   = 10'b0000000100 = bit 2  
S110  = 10'b0000001000 = bit 3  
B0    = 10'b0000010000 = bit 4  
B1    = 10'b0000100000 = bit 5  
B2    = 10'b0001000000 = bit 6  
B3    = 10'b0010000000 = bit 7  
Count = 10'b0100000000 = bit 8  
Wait  = 10'b1000000000 = bit 9  

Next state logic:

- S (bit 0):  
  if d=0 -> S (bit 0)  
  if d=1 -> S1 (bit 1)  

- S1 (bit 1):  
  if d=0 -> S (bit 0)  
  if d=1 -> S11 (bit 2)  

- S11 (bit 2):  
  if d=0 -> S110 (bit 3)  
  if d=1 -> S11 (bit 2)  

- S110 (bit 3):  
  if d=0 -> S (bit 0)  
  if d=1 -> B0 (bit 4)  

- B0 (bit 4): next always B1 (bit 5)  

- B1 (bit 5): next always B2 (bit 6)  

- B2 (bit 6): next always B3 (bit 7)  

- B3 (bit 7): next always Count (bit 8)  

- Count (bit 8):  
  if done_counting=0 -> Count (bit 8)  
  if done_counting=1 -> Wait (bit 9)  

- Wait (bit 9):  
  if ack=0 -> Wait (bit 9)  
  if ack=1 -> S (bit 0)  

Outputs (Moore, depend only on current state):  
shift_ena = 1 when state in {B0, B1, B2, B3} (bits 4 to 7)  
counting = 1 when state = Count (bit 8)  
done = 1 when state = Wait (bit 9)  

The outputs B3_next, S_next, S1_next, Count_next, Wait_next are asserted when the next state is that state, based on next-state logic.

The module only implements combinational logic (next state and output logic), so all outputs are combinational functions of inputs and current state vector.
