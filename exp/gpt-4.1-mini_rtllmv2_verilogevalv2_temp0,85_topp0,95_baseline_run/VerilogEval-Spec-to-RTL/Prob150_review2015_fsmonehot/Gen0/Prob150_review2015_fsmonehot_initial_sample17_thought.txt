The state machine uses a 10-bit one-hot encoded state vector named "state". Each bit corresponds to one state in the sequence S (bit 0) through Wait (bit 9).

We have three inputs for the next state transitions: d, done_counting, ack. The transitions for the first 7 states (S through B3) depend on d or are unconditional (always transition to the next one-hot state). The Count state stays in Count while done_counting=0 and transitions to Wait when done_counting=1. Wait loops while ack=0 and transitions to S when ack=1.

We need to implement combinational logic to produce the next-state one-hot signals: B3_next, S_next, S1_next, Count_next, Wait_next based on current state and inputs.

Outputs:
- done = 1 in Wait state only (state bit 9)
- counting = 1 in Count state only (state bit 8)
- shift_ena = 1 in B0 to B3 states only (state bits 4 to 7)

The next state logic is derived by inspecting the state diagram, mapping each current state to the next state depending on inputs:

- S (bit 0): next S (bit 0) if d=0, next S1 (bit 1) if d=1
- S1 (bit 1): next S (bit 0) if d=0, next S11 (bit 2) if d=1
- S11 (bit 2): next S110 (bit 3) if d=0, next S11 (bit 2) if d=1
- S110 (bit 3): next S (bit 0) if d=0, next B0 (bit 4) if d=1
- B0 (bit 4): next B1 (bit 5) unconditionally
- B1 (bit 5): next B2 (bit 6) unconditionally
- B2 (bit 6): next B3 (bit 7) unconditionally
- B3 (bit 7): next Count (bit 8) unconditionally
- Count (bit 8): next Count (bit 8) if done_counting=0, else Wait (bit 9) if done_counting=1
- Wait (bit 9): next Wait (bit 9) if ack=0, else S (bit 0) if ack=1

We can write combinational logic equations for each next-state bit as ORs of AND terms for the current state and input conditions.

Finally, we assign output signals as combinational signals based on the current state bits.

We implement this combinational next-state and output logic in a module that takes current "state" and inputs and produces next-state signals and outputs.
