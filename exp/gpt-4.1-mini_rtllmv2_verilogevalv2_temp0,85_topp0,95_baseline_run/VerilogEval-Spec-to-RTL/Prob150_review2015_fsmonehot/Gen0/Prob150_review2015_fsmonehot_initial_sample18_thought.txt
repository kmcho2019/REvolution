Implement combinational next-state logic and output logic for the described Moore FSM with given one-hot state encoding. Each next-state signal is asserted when the FSM moves to that state on the next cycle. Outputs done, counting, shift_ena are asserted according to the specified states. The inputs are d, done_counting, ack, and current state (10 bits one-hot). The state bits correspond to (S, S1, S11, S110, B0, B1, B2, B3, Count, Wait) in order from LSB to MSB.

Derive next-state signals by mapping each current state and inputs to next states as described, then assign output signals accordingly.

Note: The one-hot encoding is:
S     = 10'b0000000001 (bit 0)
S1    = 10'b0000000010 (bit 1)
S11   = 10'b0000000100 (bit 2)
S110  = 10'b0000001000 (bit 3)
B0    = 10'b0000010000 (bit 4)
B1    = 10'b0000100000 (bit 5)
B2    = 10'b0001000000 (bit 6)
B3    = 10'b0010000000 (bit 7)
Count = 10'b0100000000 (bit 8)
Wait  = 10'b1000000000 (bit 9)

Next-state logic by inspection:

- From S:
  if d=0 then S
  if d=1 then S1

- From S1:
  if d=0 then S
  if d=1 then S11

- From S11:
  if d=0 then S110
  if d=1 then S11

- From S110:
  if d=0 then S
  if d=1 then B0

- From B0:
  always B1

- From B1:
  always B2

- From B2:
  always B3

- From B3:
  always Count

- From Count:
  if done_counting=0 then Count
  if done_counting=1 then Wait

- From Wait:
  if ack=0 then Wait
  if ack=1 then S

Outputs:
- shift_ena = 1 in states B0,B1,B2,B3
- counting = 1 in state Count
- done = 1 in state Wait

The outputs B3_next, S_next, S1_next, Count_next, Wait_next indicate the asserted next state.

Implement combinational logic only.
