Implement combinational next-state logic and outputs for a one-hot encoded Moore FSM with 10 states: S (bit0), S1(bit1), S11(bit2), S110(bit3), B0(bit4), B1(bit5), B2(bit6), B3(bit7), Count(bit8), Wait(bit9).

Next-state logic by inspection:

- S_next: from S on d=0, from S1 on d=0, from S110 on d=0, from Wait on ack=1
- S1_next: from S on d=1
- S11_next: from S1 on d=1, from S11 on d=1
- S110_next: from S11 on d=0
- B0_next: from S110 on d=1
- B1_next: from B0 always
- B2_next: from B1 always
- B3_next: from B2 always
- Count_next: from B3 always, from Count when done_counting=0
- Wait_next: from Count when done_counting=1, from Wait when ack=0

Outputs (Moore):
- shift_ena: asserted in states B0, B1, B2, B3
- counting: asserted in state Count
- done: asserted in state Wait

Inputs are d, done_counting, ack; state is 10-bit one-hot input.

The code will implement combinational logic for these next-state signals and outputs based on current state and inputs.
