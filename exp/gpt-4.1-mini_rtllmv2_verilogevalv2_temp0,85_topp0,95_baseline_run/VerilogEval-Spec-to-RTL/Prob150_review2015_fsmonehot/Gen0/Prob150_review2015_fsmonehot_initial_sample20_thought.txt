Implement the combinational next-state logic and output logic for the given Moore FSM with 10 one-hot encoded states: S, S1, S11, S110, B0, B1, B2, B3, Count, Wait.

Inputs: d, done_counting, ack, and current state vector (10 bits)
Outputs: next-state indication signals for specific states and output signals done, counting, shift_ena.

Approach:
- Each next state is asserted based on the current state and inputs according to the state transition diagram.
- The output signals depend only on the current state (Moore machine).
- Use one-hot encoding for states, so current state signals are bits of input "state".
- Derive the next state signals by inspecting transitions and encode logic accordingly.
- For states B0, B1, B2, B3, transitions occur unconditionally to the next B state.
- For Count and Wait, transitions depend on done_counting and ack.
- Outputs: shift_ena asserted in states B0, B1, B2, B3; counting in Count; done in Wait.
- The next-state outputs (B3_next, S_next, S1_next, Count_next, Wait_next) are asserted when the corresponding state is the next state.

Implement combinational logic block producing these outputs from inputs and current state.
