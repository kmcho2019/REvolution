The 7420 chip contains two independent 4-input NAND gates. Each NAND gate outputs the NAND of its four inputs. For the first NAND gate, inputs are p1a, p1b, p1c, and p1d, output is p1y. For the second NAND gate, inputs are p2a, p2b, p2c, and p2d, output is p2y. Implement these using the nand operator on four inputs.
