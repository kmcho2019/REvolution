Implement an 8-bit shift register with synchronous enable, shifting in S at Q[0] on each clock edge when enable is high. Use the 3 input bits A, B, C as a 3-bit address to select one of the 8 flip-flop outputs Q[0]..Q[7]. The output Z is the selected bit from the shift register. The design uses only D flip-flops and multiplexers as required.
