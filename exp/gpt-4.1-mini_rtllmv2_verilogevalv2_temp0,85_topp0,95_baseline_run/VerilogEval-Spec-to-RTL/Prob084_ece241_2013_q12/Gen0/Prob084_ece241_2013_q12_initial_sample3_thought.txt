Implement an 8-bit shift register with synchronous enable and input S. The shift register output bits are Q[0] (MSB) to Q[7] (LSB). On each positive clock edge, if enable is high, shift in S into Q[0], shifting previous Q[i] to Q[i+1]. Use a 3-to-8 decoder formed by inputs A,B,C to select one of the Q outputs via an 8-to-1 multiplexer, producing output Z.
