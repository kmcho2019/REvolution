Implement an 8-bit shift register with synchronous enable, shifting in the input S on each positive clock edge if enable is high. The shift register outputs are Q[0] to Q[7], where Q[0] is the MSB shifted in first. Then use a 3-bit input (A, B, C) as an index to select one of the 8 bits from the shift register and drive output Z accordingly. The selection is done via a multiplexer controlled by ABC.
