Implement an 8-bit shift register with synchronous enable that shifts in the input S at Q[0] on each rising clock edge when enable is high. Outputs Q[0] to Q[7] store the 8 bits. Use the 3 inputs A, B, C as a 3-bit select signal to a multiplexer that selects one of the Q[i] bits to output on Z. This realizes random access reading of the shift register contents, using only the shift register and multiplexers.
