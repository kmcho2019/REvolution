Implement an 8-bit shift register with synchronous enable and input S. On each positive clock edge, if enable is high, shift the bits right, shifting in S into Q[0]. Then use A, B, C as a 3-bit address to select one of the 8 flip-flop outputs Q[0]..Q[7] via a multiplexer to drive output Z. The entire design contains only the shift register and multiplexers.
