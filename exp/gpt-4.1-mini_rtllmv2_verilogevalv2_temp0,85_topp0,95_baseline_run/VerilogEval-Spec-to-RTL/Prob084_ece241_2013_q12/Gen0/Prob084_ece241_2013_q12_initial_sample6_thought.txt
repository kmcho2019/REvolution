Implement an 8-bit shift register with synchronous enable and positive-edge clock. The shift register input is S, which feeds into Q[0]. On each clock edge, if enable is high, shift the bits: Q[i] <= Q[i-1] for i=1 to 7, and Q[0] <= S. Then use the 3-bit input ABC as a selector for an 8-to-1 multiplexer to select one bit from Q[0] to Q[7] and output it on Z.
