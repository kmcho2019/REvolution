Implement a 3-state Mealy FSM to detect the sequence "101" on input x. The states can represent the progress of the sequence detected so far: 
- S0: No bits detected or waiting for '1' 
- S1: Detected '1' 
- S2: Detected "10"
The output z is asserted when the next input x completes the "101" sequence at state S2 with x=1. The FSM should handle overlapping sequences (e.g., "10101" detects two sequences). The asynchronous reset (active low) resets the state to S0 on the negative edge of aresetn. All sequential logic triggers on the positive clock edge.
