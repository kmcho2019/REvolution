Implement a 3-state Mealy FSM to detect the sequence "101" on input x. The states represent how much of the sequence has been matched so far. On each clock's positive edge, the FSM transitions based on the current state and input x. The output z is asserted when the last input completes the "101" sequence. Use an asynchronous negative-edge reset (active low) to set the FSM to the initial state. Overlapping sequences are handled by transitioning to appropriate states after detection.
