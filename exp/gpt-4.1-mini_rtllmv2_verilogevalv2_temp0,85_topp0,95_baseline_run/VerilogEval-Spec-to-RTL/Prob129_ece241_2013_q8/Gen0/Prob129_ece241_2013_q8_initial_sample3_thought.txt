Implement a 3-state Mealy FSM that detects the sequence "101" on input x. The states represent progress in matching the pattern: S0 (no bits matched), S1 (matched '1'), S2 (matched '10'). On each clock edge, transition states based on x and output z=1 when the sequence "101" is detected (which happens when in state S2 and input x=1). Use a negative edge triggered asynchronous reset to reset the state to S0. The FSM must allow overlapping detection, so after outputting z=1, transition appropriately to allow overlapping sequences.
