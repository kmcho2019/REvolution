Implement a 3-state Mealy FSM to detect the sequence "101" on input x. The states will represent how much of the sequence has been matched so far: S0 (no match), S1 (matched '1'), S2 (matched '10'). On each positive clock edge, transition between states based on the input x. The output z is asserted (1) when the FSM transitions from S2 to S1 with input x=1, meaning the sequence "101" has just been detected. The reset is asynchronous and negative edge triggered (active low), so it resets the FSM state to S0 immediately on aresetn falling edge.
