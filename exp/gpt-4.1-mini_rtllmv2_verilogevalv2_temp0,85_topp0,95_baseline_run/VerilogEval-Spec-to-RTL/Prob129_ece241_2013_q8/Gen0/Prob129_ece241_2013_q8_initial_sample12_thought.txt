Implement a 3-state Mealy FSM to detect the sequence "101" on input x. The states will represent the progress of matching the sequence:
- S0: no match yet
- S1: matched '1'
- S2: matched '10'

On each clock posedge, transition between states based on input x. Output z is asserted when the FSM transitions from S2 to S1 on input x=1 (completing the "101" sequence). The FSM supports overlapping sequences by allowing transitions back to earlier states after partial matches. Use an asynchronous negative-edge reset (aresetn) to reset state to S0. The output z is combinational (Mealy output) depending on state and input.
