Implement a 3-state Mealy FSM to detect the sequence "101" on input x. Use states to represent how much of the sequence has been matched so far: S0 (no match), S1 (matched '1'), S2 (matched '10'). On each clock, transition between states based on x. The output z is asserted (1) when the last input completes the sequence "101", i.e., when in state S2 and input x=1. The asynchronous reset is active low and triggers on the negative edge of aresetn. The FSM is clocked on posedge clk.
