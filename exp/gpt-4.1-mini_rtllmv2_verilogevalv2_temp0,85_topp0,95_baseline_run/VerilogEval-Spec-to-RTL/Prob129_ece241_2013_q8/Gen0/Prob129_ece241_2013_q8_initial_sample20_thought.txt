Implement a 3-state Mealy FSM to detect the sequence "101" on input x, with output z asserted for one clock cycle when the sequence is detected. The states track the progress through the sequence: S0 (no match), S1 (matched '1'), and S2 (matched '10'). The FSM transitions and output depend on the current state and input x. The asynchronous reset is negative edge triggered, so we asynchronously reset the state to S0 when aresetn is deasserted (goes low). The output z is combinational in Mealy style.
