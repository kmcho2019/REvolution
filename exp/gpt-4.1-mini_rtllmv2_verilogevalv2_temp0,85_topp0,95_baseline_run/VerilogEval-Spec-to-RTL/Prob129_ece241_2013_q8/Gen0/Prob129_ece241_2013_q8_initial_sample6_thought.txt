Implement a 3-state Mealy FSM to detect the sequence "101" on input x. The states represent how much of the sequence has been matched so far. On each clock's positive edge, the FSM transitions based on input x. The output z is asserted (logic 1) on the clock cycle when the last bit of the sequence (a '1') is matched. The FSM supports overlapping detection, e.g., after detecting "101", it can detect another sequence starting at the last '1'. The asynchronous reset is triggered on the negative edge of aresetn, which resets the FSM to the initial state. The output z depends on the current state and input (Mealy output).
