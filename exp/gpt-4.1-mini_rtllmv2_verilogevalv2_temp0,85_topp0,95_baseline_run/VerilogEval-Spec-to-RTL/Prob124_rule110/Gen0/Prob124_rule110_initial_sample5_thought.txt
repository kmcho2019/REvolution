Implement a 512-bit register q representing the cellular automaton state. On each clock edge, if load is high, load the data input into q. Otherwise, compute the next state of each bit of q according to Rule 110 based on neighbors and self. The left neighbor of q[i] is q[i+1] (or 0 if i=511), and the right neighbor is q[i-1] (or 0 if i=0). Use combinational logic to compute the next state for all 512 bits simultaneously and update q synchronously.
