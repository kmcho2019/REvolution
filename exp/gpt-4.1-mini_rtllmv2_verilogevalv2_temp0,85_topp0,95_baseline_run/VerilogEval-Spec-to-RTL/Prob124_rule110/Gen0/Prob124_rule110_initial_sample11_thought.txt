Implement a 512-bit register to hold the current state q. On each clock cycle, if load is high, load q with input data. Otherwise, compute the next state for each cell according to Rule 110 using its left, center, and right neighbors. The boundary neighbors outside the array are considered zero. This means for cell i, left neighbor is q[i+1] if i+1 < 512 else 0, right neighbor is q[i-1] if i-1 >= 0 else 0, and center is q[i]. Compute next state by applying the logic from the rule table, then update q synchronously on clock's rising edge.
