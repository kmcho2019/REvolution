Implement a 512-bit register to hold the current state q. On each clock rising edge, if load is high, load q with data. Otherwise, compute the next state of each cell based on the Rule 110 truth table using the three-bit neighborhood consisting of the cell itself and its left and right neighbors. For boundary cells, neighbors outside the range are assumed zero. Use combinational logic to compute the next state for all 512 bits in parallel, then update q synchronously.
