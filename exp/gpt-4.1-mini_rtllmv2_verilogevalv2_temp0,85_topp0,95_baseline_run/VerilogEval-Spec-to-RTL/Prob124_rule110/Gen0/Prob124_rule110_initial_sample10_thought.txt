Implement a 512-bit register q that holds the current state of the cellular automaton. On each positive clock edge, if load is high, load the input data into q. Otherwise, update q based on Rule 110 for each cell. For each cell i, determine the left, center, and right bits (taking 0 at boundaries), then compute the next state using the truth table. Since q is updated synchronously, use a combinational loop over all bits to compute the next state vector, then register it into q on clock edge.
