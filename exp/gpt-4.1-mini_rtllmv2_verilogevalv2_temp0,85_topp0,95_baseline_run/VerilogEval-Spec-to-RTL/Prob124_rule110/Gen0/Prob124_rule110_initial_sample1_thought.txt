Implement a 512-bit register q to hold the current state. On each rising clock edge, if load is high, q is loaded with the input data. Otherwise, q is updated according to Rule 110 applied to each bit, assuming zero boundary conditions at the ends. For each bit i, compute the new value using neighbors q[i+1], q[i], q[i-1], with q[-1] and q[512] = 0.
