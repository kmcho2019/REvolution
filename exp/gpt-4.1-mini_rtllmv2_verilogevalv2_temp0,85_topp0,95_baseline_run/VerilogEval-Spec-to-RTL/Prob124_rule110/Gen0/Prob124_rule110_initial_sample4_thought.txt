Implement a 512-bit register `q` to hold the current state of the cellular automaton. On the positive edge of `clk`, if `load` is high, load `q` with the input `data`. Otherwise, update each bit of `q` according to Rule 110. For the boundary cells (index 0 and 511), assume neighbors outside the range are 0. The update logic for each cell uses the three bits: left neighbor (q[i+1]), center (q[i]), and right neighbor (q[i-1]), applying the given rule table to determine the next state.
