Implement a 512-bit register q to hold the state of the 512 cells. On each positive clock edge, if load is high, load q with the input data. Otherwise, update q according to Rule 110. For each cell i, determine left, center, and right bits from q, assuming zeros for out-of-bound neighbors (left of cell 511 and right of cell 0). Compute the next state of each cell using the Rule 110 truth table. The Rule 110 logic can be implemented combinationally by extracting the three bits and mapping them to the next state with a small combinational function.
