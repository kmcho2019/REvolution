Implement a combinational module TopModule with a 100-bit input vector 'in'. The outputs are:
- out_and: the AND of all 100 input bits
- out_or: the OR of all 100 input bits
- out_xor: the XOR of all 100 input bits

These can be implemented using the reduction operators & (AND), | (OR), and ^ (XOR) in Verilog, applied to the entire input vector.
