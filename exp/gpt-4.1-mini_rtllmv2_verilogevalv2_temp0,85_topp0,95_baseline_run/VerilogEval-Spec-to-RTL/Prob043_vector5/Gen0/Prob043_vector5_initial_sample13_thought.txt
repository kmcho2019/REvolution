We need to create a 25-bit output vector representing all pairwise comparisons between the inputs a, b, c, d, e. Each bit corresponds to a pair of inputs, with bit = 1 if the two inputs are equal, 0 otherwise. The output should be arranged such that out[24] corresponds to comparison of a and a, out[23] to a and b, ..., out[0] to e and e. Since the indices go from 24 down to 0, we can assign the output bits in a nested loop manner over the inputs in order a,b,c,d,e. For each pair (x,y), output bit is (x == y), which can be implemented as ~(x ^ y).
