Implement a Moore FSM with 4 states (A, B, C, D) using an enumerated type or localparams. The FSM has one input 'in' and one output 'out' determined solely by the current state. The state transitions occur on the positive edge of clk, with an asynchronous active-high reset (areset) that sets the state to A. The output is combinationally assigned based on the current state.
