Implement a Moore FSM with 4 states encoded as 2-bit values: A=2'b00, B=2'b01, C=2'b10, D=2'b11. Use an asynchronous active-high reset (areset) to set the state to A on a positive edge of areset. On each positive clock edge, update the state based on the current state and input 'in'. The output is based solely on the current state: output is 1 only in state D, else 0.
