Implement 16 D flip-flops with synchronous active-low reset and byte-enable controls.
On each rising clock edge:
- If resetn is low, reset all flip-flops to 0.
- Otherwise, update each byte of q only if the corresponding byteena bit is set.
This means for bits [7:0], update q[i] with d[i] if byteena[0] is high; else keep q[i].
Similarly for bits [15:8], update q[i] with d[i] if byteena[1] is high; else keep q[i].
