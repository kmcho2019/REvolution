Implement a 16-bit register with synchronous active-low reset and byte-wise write enable. On each positive clock edge, if resetn is low, clear the output q to 0. Otherwise, update q bytes selectively according to byteena: if byteena[1] is set, update upper byte q[15:8] with d[15:8]; if byteena[0] is set, update lower byte q[7:0] with d[7:0]. This requires 16 D flip-flops, grouped as two bytes controlled by byteena.
