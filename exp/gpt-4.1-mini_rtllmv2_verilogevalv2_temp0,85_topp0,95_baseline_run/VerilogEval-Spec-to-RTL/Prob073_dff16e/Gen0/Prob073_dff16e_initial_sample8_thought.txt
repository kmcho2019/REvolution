Implement a 16-bit register with synchronous active-low reset and byte-enable write control. Use a single always block triggered on the positive edge of clk. On resetn==0, clear q to zero. Otherwise, update only the bytes enabled by byteena: if byteena[1] is set, update q[15:8] with d[15:8]; if byteena[0] is set, update q[7:0] with d[7:0]. Unenabled bytes retain their previous values.
