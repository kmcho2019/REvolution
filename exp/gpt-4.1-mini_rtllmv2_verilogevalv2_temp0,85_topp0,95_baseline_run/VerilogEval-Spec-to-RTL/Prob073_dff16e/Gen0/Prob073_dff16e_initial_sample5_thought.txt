Implement a 16-bit register using 16 D flip-flops updated on the positive edge of clk. Use the synchronous, active-low resetn to reset the register to 0 when resetn=0. Use byteena[1] and byteena[0] to selectively update the upper byte (bits 15:8) and lower byte (bits 7:0) respectively. For each bit, if its byte enable is asserted, load d's corresponding bit; otherwise, keep the previous value.
