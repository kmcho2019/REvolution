Implement a 16-bit register made of 16 D flip-flops triggered on the positive edge of clk. On each clock edge, if resetn is low, reset all outputs to 0 synchronously. Otherwise, update the upper byte of the register with d[15:8] only if byteena[1] is high, and update the lower byte with d[7:0] only if byteena[0] is high. Bits are updated individually based on their corresponding byte enables.
