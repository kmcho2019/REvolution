Implement a 16-bit register with synchronous active-low reset. On each positive clock edge, if resetn is low, clear the entire register to zero. Otherwise, update the register only in the bytes enabled by byteena: if byteena[1] is high, update bits [15:8] with d[15:8]; if byteena[0] is high, update bits [7:0] with d[7:0]. This is done using bitwise masking and selective assignment inside an always block.
