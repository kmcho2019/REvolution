Implement 16 D flip-flops with synchronous active-low reset. On each positive clock edge, if resetn is low, reset q to 0. Otherwise, update q selectively based on byteena signals: if byteena[1] is high, update the upper byte q[15:8] with d[15:8]; if byteena[0] is high, update the lower byte q[7:0] with d[7:0]. If a byte enable is low, retain the current value of that byte.
