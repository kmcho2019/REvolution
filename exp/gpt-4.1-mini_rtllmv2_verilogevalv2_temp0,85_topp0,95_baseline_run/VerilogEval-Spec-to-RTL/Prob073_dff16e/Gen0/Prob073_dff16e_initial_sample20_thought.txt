Implement a 16-bit register composed of 16 D flip-flops triggered on the positive clock edge. On each clock cycle, if resetn is low (active-low synchronous reset), set all outputs q to zero. Otherwise, update q selectively based on the byteena control signals: if byteena[1] is high, update the upper byte q[15:8] with d[15:8]; if byteena[0] is high, update the lower byte q[7:0] with d[7:0]. If a byteena bit is low, maintain the previous value of that byte. This achieves byte-wise write enable functionality with synchronous active-low reset.
