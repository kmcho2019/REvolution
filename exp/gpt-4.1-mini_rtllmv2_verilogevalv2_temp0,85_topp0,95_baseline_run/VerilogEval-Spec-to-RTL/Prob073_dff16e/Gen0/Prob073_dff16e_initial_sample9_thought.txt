Implement a 16-bit register using 16 D flip-flops triggered on the positive edge of clk. The register is split into two bytes: upper (bits 15 to 8) and lower (bits 7 to 0). On each clock edge, if resetn is low (synchronous active-low reset), reset q to 0. Otherwise, update only the bytes of q for which the corresponding byteena bit is set; for bytes where byteena bit is 0, retain the previous value.
