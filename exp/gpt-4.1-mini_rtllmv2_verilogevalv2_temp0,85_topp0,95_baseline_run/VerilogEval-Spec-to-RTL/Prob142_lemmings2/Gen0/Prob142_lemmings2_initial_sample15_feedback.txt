```verilog
case (state)

        end
    end

    WALK_RIGHT: begin

            next_state = FALLING;
```

This code switches direction if either bump input is high, which aligns with the problem statement that any bump switches direction. It transitions to FALLING if ground=0, as required.

```verilog
always @(posedge clk or posedge areset) begin
```

This seems correct: when entering FALLING, it stores the walking direction.
