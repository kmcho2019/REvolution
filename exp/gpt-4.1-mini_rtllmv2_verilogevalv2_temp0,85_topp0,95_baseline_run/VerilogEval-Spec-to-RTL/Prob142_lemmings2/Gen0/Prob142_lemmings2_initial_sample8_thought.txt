Implement a Moore FSM with three states: WALK_LEFT, WALK_RIGHT, and FALLING. On reset, state is WALK_LEFT. In WALK_LEFT or WALK_RIGHT, if bump_left or bump_right (or both) are asserted, change direction accordingly. If ground goes low, transition to FALLING state but store the previous walking direction to resume after fall. While FALLING, ignore bumps and output aaah=1. When ground returns to high, go back to the stored walking direction state. Output signals walk_left and walk_right are mutually exclusive and set according to the current walking state; aaah is set only in FALLING state.
