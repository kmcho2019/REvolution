The one-hot states are encoded as: A=000001, B=000010, C=000100, D=001000, E=010000, F=100000 (y[0] is A, y[1] is B, ..., y[5] is F).

The transitions depend on input w and the current state.

We need to derive the next-state signals for y[1] (B) and y[3] (D) by inspection.

Looking at the transitions for B (y[1]):
- From A (y[0]): on input 0 -> B (y[1])
- From C (y[2]): on input 1 -> D (y[3]) (not B)
- From other states, no direct transition to B.

So, next y[1] (B) is 1 if current state is A and w=0.

Similarly for y[3] (D):
- From B (y[1]): on input 1 -> D (y[3])
- From C (y[2]): on input 1 -> D (y[3])
- From E (y[4]): on input 1 -> D (y[3])
- From F (y[5]): on input 1 -> D (y[3])

So next y[3] is 1 if current state is B, C, E, or F and w=1.

Expressed as logic:

Y1 (next y[1]) = y[0] & ~w
Y3 (next y[3]) = (y[1] | y[2] | y[4] | y[5]) & w

We will implement these combinational outputs from the current state y and input w.
