The FSM uses a one-hot encoding of states A to F across y[5:0]. The next state depends on input w. For each bit y[i], we want to derive next state signals Y1 (for y[1], state B) and Y3 (for y[3], state D). Using the state transitions and one-hot encoding, we inspect which states lead to B (y[1]) and D (y[3]) next, given current state and input w. Then we write logic equations for Y1 and Y3 as sums of products of current y bits and w, representing the next state logic for these bits.
