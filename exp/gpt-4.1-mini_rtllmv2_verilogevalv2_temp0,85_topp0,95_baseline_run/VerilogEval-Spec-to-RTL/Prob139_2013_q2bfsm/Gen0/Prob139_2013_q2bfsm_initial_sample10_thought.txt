Implement a synchronous FSM with states representing the problem description:
- State A: reset state; outputs f=0, g=0.
- Upon release of reset (resetn=1), move to State B and output f=1 for one cycle.
- Then move to State C to monitor x for the sequence 1,0,1 across three clock cycles.
  Use internal counters or sub-states to track the sequence.
- Upon detecting the sequence 101 on x, move to State D, where g=1.
- In State D, monitor y for at most two cycles:
  - If y=1 within two cycles, stay in State D with g=1 permanently.
  - Else after two cycles with no y=1, move to State E with g=0 permanently.
- Reset returns FSM to State A, resetting outputs.

All sequential logic triggered on posedge clk, with synchronous active low reset (resetn).
Outputs f and g are registered outputs.
