Implement a synchronous FSM with states representing the described behavior:
- State A: reset state, wait for resetn deassertion.
- State B: output f=1 for one clock cycle after resetn deassertion.
- States C1, C2, C3: detect the sequence x=1,0,1 on consecutive cycles.
- State D: output g=1 after detecting x sequence, monitor y for up to two cycles.
- State E: g=1 permanently because y was 1 within two cycles.
- State F: g=0 permanently because y was not 1 within two cycles.

Use a state register and synchronous logic. Outputs f and g depend on the state. Detect the sequence with states progressing through the x inputs. Track number of cycles in state D to check y input timing.
