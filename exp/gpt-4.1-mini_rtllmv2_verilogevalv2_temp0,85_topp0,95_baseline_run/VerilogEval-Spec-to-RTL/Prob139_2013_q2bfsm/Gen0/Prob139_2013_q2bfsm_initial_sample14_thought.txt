Implement a Moore FSM with the following states:
- A: initial state, f=0, g=0, stay here while resetn=0
- B: after resetn=1, output f=1 for one cycle, then move to C
- C: monitor x input to detect the sequence 1,0,1 in three successive clock cycles; output f=0, g=0
- D: once sequence 101 detected, output g=1, start monitoring y for up to two cycles
- E: if y=1 detected within two cycles, remain in E with g=1 permanently
- F: if y=1 not detected within two cycles, move to F with g=0 permanently

Inputs: clk, resetn, x, y
Outputs: f, g

The FSM resets synchronously on resetn=0 to A.

Sequence detection in C is done by tracking the last 3 x inputs.

While in D, use a 2-cycle counter to check y.

This implementation uses a state register and registers for outputs f and g.
