Design a synchronous FSM with the following states:
- A: Reset state, outputs f=0,g=0. On deassert resetn, move to B.
- B: Output f=1 for one cycle, then move to C.
- C: Monitor x input for the pattern 1,0,1 in three consecutive cycles.
  Use a small pattern detector FSM or shift register to detect the sequence.
  Once pattern detected, move to D.
- D: Set g=1 and monitor y input for up to two cycles.
  If y=1 within two cycles, remain in D with g=1 permanently.
  Otherwise, move to E.
- E: Set g=0 permanently until reset.

Synchronous reset is active low, so on resetn==0, go to A.

Outputs f and g are registered outputs driven based on the current state and conditions.

Implement state transitions and output logic accordingly.
