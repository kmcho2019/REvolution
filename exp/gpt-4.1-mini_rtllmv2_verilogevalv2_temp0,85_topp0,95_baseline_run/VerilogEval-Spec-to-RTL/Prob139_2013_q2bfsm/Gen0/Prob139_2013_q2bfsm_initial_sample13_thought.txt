Implement a synchronous FSM with active-low synchronous reset. The FSM starts in state A on reset. When reset is de-asserted, it outputs f=1 for one cycle, then transitions to a state where it monitors the input x for the sequence 1,0,1 over three consecutive cycles. Once the sequence is detected, the FSM sets g=1 for one cycle and moves to a state where it monitors y for up to two cycles. If y==1 within these two cycles, g remains 1 forever. Otherwise, g is set to 0 forever, until reset. Use state encoding and registers to track progress through the sequence and y monitoring, and update outputs accordingly.
