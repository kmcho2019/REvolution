Implement a synchronous FSM with active-low synchronous reset. Start in state A on reset, where outputs f=0, g=0. When resetn goes high, on next clock output f=1 for one cycle and move to a state to monitor x sequence 1,0,1. Use states to track progress in detecting the x sequence. Once sequence 101 detected, set g=1 and move to a state where y is monitored for up to 2 clock cycles. If y=1 within 2 cycles, g stays 1 permanently. Otherwise, g is cleared permanently. All transitions and outputs are synchronous on clock edges.
