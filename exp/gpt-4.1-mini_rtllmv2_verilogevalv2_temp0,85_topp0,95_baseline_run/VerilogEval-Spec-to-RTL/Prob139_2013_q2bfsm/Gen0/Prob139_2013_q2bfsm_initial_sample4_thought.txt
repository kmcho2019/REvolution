Implement a synchronous FSM with states representing the described behavior:
- State A: reset state, outputs f=0, g=0.
- On deassertion of reset (resetn=1), move to State B to output f=1 for one clock cycle.
- Then move to State C to monitor the input x for the pattern 1,0,1 over three clock cycles.
- On detecting pattern 101, move to State D to set g=1 and start monitoring y for up to two clock cycles.
- If y becomes 1 within two cycles, move to State E where g=1 is maintained indefinitely.
- Otherwise, move to State F where g=0 is maintained indefinitely.
Implement all state transitions and outputs synchronously on the positive clock edge with synchronous active low reset.
