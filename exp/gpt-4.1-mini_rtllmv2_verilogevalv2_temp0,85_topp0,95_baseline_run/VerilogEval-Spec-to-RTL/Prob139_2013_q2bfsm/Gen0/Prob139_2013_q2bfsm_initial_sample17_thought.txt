Design an FSM with states representing the described sequence and conditions. The FSM resets to state A when resetn is low. After resetn goes high, on the next clock, output f is asserted for one cycle. Then the FSM monitors the input x for the pattern 1,0,1 over three clock cycles. When detected, it sets g=1 next cycle and enters a state where it monitors y for up to two cycles. If y=1 within two cycles, it stays in a state with g=1 permanently; otherwise, it moves to a state with g=0 permanently, until reset. Use synchronous reset and outputs driven by FSM state.
