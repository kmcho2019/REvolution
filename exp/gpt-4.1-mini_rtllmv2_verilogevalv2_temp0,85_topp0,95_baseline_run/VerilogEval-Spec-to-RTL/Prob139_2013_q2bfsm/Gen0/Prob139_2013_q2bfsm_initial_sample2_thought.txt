Implement a synchronous FSM with the following states:
- A (initial state, output f=0, g=0)
- B (after reset de-assertion, output f=1 for one cycle)
- C0, C1, C2 (monitoring x sequence 1,0,1)
- D (g=1 asserted after x sequence detected, start monitoring y)
- E (g=1 permanently after y=1 within 2 cycles)
- F (g=0 permanently after y not seen within 2 cycles)

On resetn low, FSM goes to A.
After resetn high, on next clock:
- output f=1 for one cycle in B,
- then monitor x for pattern 1,0,1 through C0->C1->C2 states,
- once detected, set g=1 in D and start monitoring y.
- If y=1 within 2 cycles in D, go to E (g=1 permanent).
- Else go to F (g=0 permanent).

Outputs f and g are combinational signals based on state.
