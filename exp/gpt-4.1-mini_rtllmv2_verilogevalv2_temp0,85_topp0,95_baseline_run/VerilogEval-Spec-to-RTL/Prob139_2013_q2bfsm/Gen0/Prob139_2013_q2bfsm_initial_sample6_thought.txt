Design a synchronous FSM with states encoding the progress through the pattern detection and output generation. Use a synchronous active-low reset to initialize the FSM to state A with outputs f=0 and g=0. On reset deassertion, move to a state that asserts f=1 for one cycle. Then monitor input x for the pattern 1,0,1 using intermediate states. Upon detecting the pattern, assert g=1 and enter a state to monitor y for up to 2 clock cycles. If y=1 within 2 cycles, stay in a "g=1 permanent" state; otherwise, transition to a "g=0 permanent" state. Outputs are combinational based on current state. The FSM state transitions and outputs are fully synchronous on posedge clk.
