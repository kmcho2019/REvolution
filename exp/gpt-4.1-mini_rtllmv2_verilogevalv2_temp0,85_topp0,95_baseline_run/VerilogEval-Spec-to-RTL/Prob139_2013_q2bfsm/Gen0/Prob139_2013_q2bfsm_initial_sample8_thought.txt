Implement a finite state machine (FSM) with synchronous active-low reset. The FSM states are:

- A: Reset state, outputs f=0, g=0. On reset de-assert, move to B.
- B: Output f=1 for one clock cycle, then move to C.
- C: Monitor input x for pattern 1,0,1 in three consecutive clocks.
- D: Once pattern detected, set g=1, start monitoring y for up to two clocks.
- E: If y=1 within two clocks, stay in E with g=1 permanently.
- F: If y not detected in two clocks, move to F with g=0 permanently.

Use a state register and counters as needed. Outputs f and g are registered. Transitions and outputs updated on positive clock edge with synchronous active-low reset.
