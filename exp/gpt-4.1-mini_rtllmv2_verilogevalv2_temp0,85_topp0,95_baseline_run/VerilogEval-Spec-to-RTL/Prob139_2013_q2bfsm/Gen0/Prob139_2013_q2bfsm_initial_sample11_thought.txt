Implement a synchronous FSM with active low synchronous reset. Define states to track the described behavior:

- State A: initial/reset state, f=0, g=0
- State B: after reset is de-asserted, output f=1 for one cycle
- State C: monitor x input sequence for 1,0,1 over three cycles
- State D: on detecting 101, set g=1 and start monitoring y input for up to two cycles
- State E: if y=1 within two cycles, keep g=1 permanently
- State F: if y!=1 within two cycles, set g=0 permanently

At each clock edge, FSM transitions according to inputs x and y and the conditions. Outputs f and g are assigned according to the current state and logic described.

Use a register to count how many clock cycles have passed when monitoring y in state D. Reset is synchronous active low.
