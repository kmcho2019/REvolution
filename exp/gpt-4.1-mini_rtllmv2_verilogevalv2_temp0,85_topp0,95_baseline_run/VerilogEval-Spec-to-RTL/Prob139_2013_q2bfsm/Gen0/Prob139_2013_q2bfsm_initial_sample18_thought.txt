Implement an FSM with states representing the described behavior:

- State A: reset state, outputs f=0, g=0.
- State B: after reset deasserted, output f=1 for one clock cycle.
- State C: monitor x input for sequence 1,0,1 over 3 cycles.
- State D: after detecting 101, set g=1 and monitor y for up to 2 cycles.
- State E: if y=1 within 2 cycles, maintain g=1 permanently.
- State F: if y=0 after 2 cycles, set g=0 permanently.

Use a synchronous active-low reset. Outputs are registered. The FSM transitions at positive clock edges.
