Implement a three-state FSM with states A, B, C, D encoded as needed. On synchronous active-low reset, state resets to A. Inputs are clk, resetn, and 3-bit r. Outputs are 3-bit g. In state A, priority is given to r[0], then r[1], then r[2] to transition to B, C, or D respectively. In states B and C, the grant bit g0 or g1 is asserted respectively, and the FSM stays in that state if the corresponding request remains asserted, else transitions back to A. In state D, no grant output is asserted; stays in D if r[2] remains asserted, else returns to A. The outputs g are combinationally assigned based on the current state. Two always blocks are used: one for state transitions (state table) and one for state flip-flops (sequential). Continuous assignment or always block is used for output logic.
