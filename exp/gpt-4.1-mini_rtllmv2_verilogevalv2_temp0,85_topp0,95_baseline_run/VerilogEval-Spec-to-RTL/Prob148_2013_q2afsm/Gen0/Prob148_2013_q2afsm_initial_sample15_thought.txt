Implement a 4-state FSM with states A, B, C, D encoded as 2-bit values. On synchronous active-low reset, go to state A.

- State A: no grant (g=3'b000). Based on r[2:0], choose which device to grant:
    - if r[0]==1: go to B (grant g0)
    - else if r[1]==1: go to C (grant g1)
    - else if r[2]==1: go to D (grant g2)
    - else stay in A

- State B (g0=1): stay in B if r[0]==1, else go to A
- State C (g1=1): stay in C if r[1]==1, else go to A
- State D (g2=1): stay in D if r[2]==1, else go to A

Use separate always blocks for next-state logic and state register. Output g depends only on current state, so describe with continuous assignment.

Note: The problem description has two transitions from A to A with r=000, one of which should be to D for r=001 (lowest priority). This is handled accordingly.
