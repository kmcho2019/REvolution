Implement a 4-state FSM with states A, B, C, D encoded as 2-bit states. 
State A is the idle state, waiting for requests. On requests, FSM transitions to B if r[0]=1, 
to C if r[0]=0 and r[1]=1, and to D if r[0]=0, r[1]=0, and r[2]=1.
In states B, C, and D, the grant signal g is asserted for the corresponding device.
FSM stays in that state as long as the corresponding request remains asserted; otherwise returns to A.
Use synchronous active-low reset to return to state A.
Separate always blocks for state transitions and state registers.
Output g is assigned combinationally based on current state.
