I will implement a Moore FSM with four states: A, B, C, and D. State A is the idle state with no grants. State B grants device 0 (g[0]=1), state C grants device 1 (g[1]=1), and state D grants device 2 (g[2]=1). On synchronous reset (active low), the FSM goes to state A. Transitions from state A check the requests with priority: device 0, then device 1, then device 2, else stay in A. From B, stay if r[0]=1 else back to A; from C, stay if r[1]=1 else back to A; from D, stay if r[2]=1 else back to A. Output g is determined by the state. I will separate the always blocks for state register and next state logic, and implement output g as a continuous assignment based on state.
