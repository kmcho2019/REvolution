Implement a 4-state FSM (A, B, C, D) with synchronous active-low reset. 
State A is the idle state with no grants. If r[0]=1, transition to B (grant g[0]=1). 
Else if r[1]=1, transition to C (grant g[1]=1). Else if r[2]=1, transition to D (grant g[2]=1). 
If no requests, stay in A. 
In states B, C, and D, stay in the same state if the corresponding request remains asserted; 
otherwise, return to A. Outputs g are 3 bits, indicating which device is granted. 
Use one always block for state transition (combinational), one always block for state register (sequential), 
and continuous assignment for outputs.
