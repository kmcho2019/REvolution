- State C: grant g=010, stay in C if r[1]=1, else go to A
- State D: grant g=100, stay in D if r[2]=1, else go to A

Use synchronous active-low reset to set state to A.

- State register (sequential logic)
- Next state logic (combinational)
- Outputs (combinational, from state)
