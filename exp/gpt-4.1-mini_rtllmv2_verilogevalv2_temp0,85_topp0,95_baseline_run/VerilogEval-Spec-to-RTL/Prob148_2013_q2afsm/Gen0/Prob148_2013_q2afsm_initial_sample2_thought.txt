Implement a 4-state FSM with states A, B, C, and D represented by 2-bit state codes. On synchronous active-low reset, go to state A. The next state logic uses the priority: if r[0] is 1, go to B (grant device 0); else if r[1] is 1, go to C (grant device 1); else if r[2] is 1, go to D (grant device 2); else stay in A. Once in grant state B, stay there as long as r[0] stays 1; else return to A. Similarly for C and r[1]. The problem states outputs g are 3-bit with only one bit set according to the grant. Outputs are assigned combinationally from the current state. Use two always blocks: one for state register and one for next-state logic.
