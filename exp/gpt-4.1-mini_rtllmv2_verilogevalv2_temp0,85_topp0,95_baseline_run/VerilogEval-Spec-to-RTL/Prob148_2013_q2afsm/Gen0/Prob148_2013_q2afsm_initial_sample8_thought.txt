Implement a 4-state FSM with states A, B, C, D encoded as 2-bit values. On synchronous active-low reset, go to state A.
On each clock rising edge, update state based on current state and input r.
State transitions:
- From A:
  - if r[0] == 1, go to B (grant to device 0)
  - else if r[1] == 1, go to C (grant to device 1)
  - else if r[2] == 1, go to D (grant to device 2)
  - else stay in A
- From B:
  - if r[0] == 1, stay in B
  - else go to A
- From C:
  - if r[1] == 1, stay in C
  - else go to A
- From D:
  - if r[2] == 1, stay in D
  - else go to A

Output grants g are combinational and depend only on the current state:
- B => g = 3'b001
- C => g = 3'b010
- D => g = 3'b100
- A => g = 3'b000

Use separate always blocks for state register (sequential) and next state logic (combinational).
