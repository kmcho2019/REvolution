Implement a three-state FSM with states A, B, and C (state D mentioned in the prompt is likely a typo or redundant given the transitions). State A is the idle state with no grant, while B and C grant to device 0 and device 1 respectively. Device 2 has lowest priority and is granted only if both r[0] and r[1] are zero and r[2] = 1, so we add a state D for device 2 grant. The FSM transitions based on current requests, prioritizing r[0], then r[1], then r[2]. The outputs g[2:0] reflect which device is granted. On synchronous active-low reset, FSM returns to state A. We implement the state register in one always block triggered on posedge clk, and the next state logic in a combinational always block. The outputs are assigned combinationally based on the current state.
