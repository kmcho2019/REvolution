Implement a 4-state FSM: A, B, C, D. State A is the idle state where no grant is given. When requests appear, priority decides which grant state to go to: B (grant to device 0), C (grant to device 1), or D (grant to device 2). The FSM stays in the grant state as long as the corresponding request input remains asserted, else it returns to A. Use synchronous active-low reset to go to A. Outputs g reflect the grant signals for the states B, C, and D. Use separate always blocks for state register (sequential logic) and next state logic (combinational logic). Outputs are assigned continuously based on current state.
