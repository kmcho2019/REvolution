Implement a 4-state FSM with states A, B, C, D encoded as 2-bit values. On synchronous active-low reset, go to state A. In state A, check requests with priority: r[0] > r[1] > r[2]. If r[0]=1, transition to B; else if r[1]=1, transition to C; else if r[2]=1, transition to D; else stay in A. In state B, if r[0] remains 1, stay in B; else go to A. Similarly for C and D. Output g[2:0] is one-hot encoded grant signals for states B, C, and D respectively, and zero in A. Use separate always blocks for state flip-flops and combinational next state logic. Use continuous assignment for outputs.
