Implement a 4-state FSM with states A, B, C, and D. State A is the idle state with no grants, and states B, C, and D grant devices 0, 1, and 2 respectively. Priority is device 0 > device 1 > device 2. On reset (active low, synchronous), transition to state A. The state transition is based on the input requests r[2:0]. Outputs g[2:0] reflect the granted device. Use separate always blocks for state flip-flops and next-state logic. Outputs are combinational and depend on the current state.
