Implement a FSM with three main states:
- A: initial state, waits for s=1 to transition to B
- B: collects 3 samples of w over 3 clock cycles, counting how many times w=1
- C: outputs z=1 if count of w=1 was exactly 2, else z=0, then returns to B for next group of 3 cycles

Use a 2-bit counter to count the number of w=1 samples in B and a 2-bit cycle counter to count up to 3 samples. Use synchronous reset to go back to A and clear outputs and counters. The output z is asserted in state C for one clock cycle based on the count from B.

This approach uses only 3 states and minimal counters, matching the problem requirements.
