Implement a FSM with states A and B. 
- In state A, wait for s=1 to transition to state B.
- In state B, track the value of w for the next three clock cycles using a 2-bit counter and a 2-bit accumulator counting how many times w=1.
- After three cycles, output z=1 if exactly two of the three w samples were 1, else z=0.
- Then repeat the process in state B for the next three cycles.
- On reset, go to state A.
Use minimal states: A (waiting for s=1), B (sampling w 3 times), output logic combined in B state by counter and accumulator.
z is registered and updated synchronously one cycle after counting three w samples.
