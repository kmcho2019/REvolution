Implement a FSM with states A (initial), B, and a counter for three cycles in B to count the number of times w=1. 
In state A, wait for s=1 to transition to B.
In B, count the number of w=1 inputs over three cycles.
After three cycles in B, if the count of w=1 equals 2, set z=1 for one cycle; else z=0.
Then restart counting for the next three cycles while remaining in B.
Use a 2-bit counter to track cycles in B and a 2-bit counter to count w=1 occurrences.
Implement output z registered and synchronous reset active high.
