Implement an FSM with three main states: A (reset/waiting for s=1), B (counting w samples), and C (output z decision). In state A, wait for s=1 to go to B. In state B, sample w for 3 clock cycles, counting how many times w=1. After 3 samples, move to state C to output z=1 if exactly two samples were 1, otherwise z=0. Then return to state B to start the next 3-cycle counting window. Use a 2-bit counter to track the 3 samples and a 2-bit counter or register to count the number of w=1s. Reset is synchronous and active high.
