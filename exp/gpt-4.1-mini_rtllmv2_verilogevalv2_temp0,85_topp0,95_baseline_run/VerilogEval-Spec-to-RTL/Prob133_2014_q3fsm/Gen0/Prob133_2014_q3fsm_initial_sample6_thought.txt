The FSM has two main phases: 
- State A: waiting for s=1 to move to state B.
- State B: count exactly three clock cycles, tracking how many times w=1. If exactly two of these three w inputs are 1, then output z=1 in the next clock cycle; otherwise z=0.

To minimize states, in state B we only need to keep track of the count of w=1's in the current 3-cycle window and the cycle count (0 to 2). After three cycles, output z is asserted based on the count and the cycle counters reset for the next window.

Implementation details:
- Use a 2-bit counter (0 to 2) for the three cycle window.
- Use a 2-bit counter to count how many times w=1 in these three cycles.
- After the third cycle, compute z (1 if count_w==2 else 0) in next cycle.
- z is registered and output synchronously.
- On reset, state is A and z=0.
