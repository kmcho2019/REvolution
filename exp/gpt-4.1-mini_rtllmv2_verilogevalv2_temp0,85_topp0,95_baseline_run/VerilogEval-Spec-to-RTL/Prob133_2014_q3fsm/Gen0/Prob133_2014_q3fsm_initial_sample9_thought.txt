Implement a FSM with these states: 
- A (waiting for s=1)
- B0, B1, B2, B3 (B states count the three cycles of w input)

In state A: wait for s=1 to go to B0. 
In states B0-B2: count how many times w=1 in a 3-cycle window using a 2-bit counter.
At B3, check if exactly two w=1's occurred; if yes, set z=1 for one cycle, else 0. Then loop back to B0 for the next 3-cycle window.

z is registered and updated only at the end of the 3-cycle window (B3 to B0 transition).

Use a 2-bit counter to count w=1 occurrences, incrementing it only in states B0-B2.
Reset is synchronous and active high.
