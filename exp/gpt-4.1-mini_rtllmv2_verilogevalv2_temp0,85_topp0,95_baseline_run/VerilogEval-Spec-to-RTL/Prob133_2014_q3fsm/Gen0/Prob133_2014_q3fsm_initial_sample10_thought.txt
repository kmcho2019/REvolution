We will implement an FSM with states A and B, and use a 2-bit counter to count the number of clock cycles in state B and a 2-bit counter to count how many times w=1 has occurred in those three cycles. 

- In state A: wait for s=1 to move to state B.
- In state B: for three clock cycles, count how many times w=1 occurs.
- After three cycles, output z=1 if w=1 exactly twice; otherwise z=0.
- Then continue checking w for the next three cycles in state B.
- Reset is synchronous and active high.
- Use minimum states: just two states (A and B).
- The output z is registered and appears one cycle after the three cycles are completed.

We will use a 2-bit cycle counter (0 to 2) to count cycles in B and a 2-bit w_count to count how many times w=1 occurred.

z is registered and updated only after the three cycles are counted.

Implementation details:
- State encoding: A=0, B=1.
- On reset, state goes to A, counters cleared, z=0.
- In state A: if s=1, move to B and reset counters.
- In state B: increment cycle count, increment w_count if w=1.
- After 3 cycles (cycle count=2), update z accordingly in the next clock cycle.
- Then reset counters and start next 3-cycle window.

This approach uses minimal states and counters, matching the requirements.
