Implement a FSM with three states: A (initial), B0, B1, B2 to track the three w samples. Start in A; stay in A while s=0, move to B0 on s=1. In B states, count how many times w=1 over three cycles using a 2-bit counter. After B2, output z=1 if exactly two w=1's were counted in the previous three cycles, else 0, then move back to B0 to start the next 3-cycle window. Use synchronous reset to return to A and clear counters. Output z is registered and depends on the previous 3-cycle window's count.
