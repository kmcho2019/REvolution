The FSM starts in state A, waiting for s=1 to transition to state B. In state B, it needs to check the value of w for the next three clock cycles and determine if exactly two of those are 1s. Then on the following cycle, output z=1 if exactly two of the last three w's were 1, else z=0.

To use as few states as possible, we can design the FSM with these states:
- A: waiting for s=1
- B0, B1, B2: three states corresponding to the first, second, and third w samples.

We only need 4 states in total.

We also need to keep track of how many times w=1 in these three cycles. Instead of encoding count in states (which would require more states), keep a 2-bit counter (count) that increments if w=1. After the third cycle (state B2), output z=1 if count==2, else 0, on the next cycle. Then reset count and repeat the 3-cycle counting sequence.

Since z is output in the cycle after the third w sample, we can add a small logic to delay the output by one cycle.

The reset input synchronously resets the FSM to state A.

Implementation details:
- Use a 2-bit state encoding for A, B0, B1, B2.
- Use a 2-bit counter for counting w=1.
- z is registered, updated after B2 state.
