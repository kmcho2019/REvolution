We implement a FSM with states A and B. 
- In state A, FSM waits until s=1, then moves to state B.
- In state B, FSM collects w values for 3 clock cycles, counting the number of ones.
- After 3 cycles, if exactly two w's were 1, output z=1 next cycle; otherwise z=0.
- FSM then restarts counting the next batch of 3 w inputs.
- Use a 2-bit counter to count cycles and a 2-bit counter to count w=1 occurrences.
- Output z is registered and updated one cycle after the 3rd w input is processed.
- reset synchronously returns FSM to state A and clears counters and z.
