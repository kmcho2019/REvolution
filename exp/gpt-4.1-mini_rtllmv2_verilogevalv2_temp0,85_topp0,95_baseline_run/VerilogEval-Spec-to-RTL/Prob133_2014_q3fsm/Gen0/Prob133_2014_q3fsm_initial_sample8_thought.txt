Implement a FSM with states representing: A (waiting for s=1), B (collecting 3 w samples), and a state to output z based on the count of w=1 in those 3 cycles. We can store the count of w=1 during the 3 cycles with a small counter. Use a 2-bit counter to count the three cycles, and a 2-bit accumulator to count how many times w=1 occurs. After 3 cycles, check if count of w=1 is exactly 2, then set z=1 for one cycle, else z=0. Then restart counting the next 3 cycles in state B. Reset sets FSM to A, z=0.
