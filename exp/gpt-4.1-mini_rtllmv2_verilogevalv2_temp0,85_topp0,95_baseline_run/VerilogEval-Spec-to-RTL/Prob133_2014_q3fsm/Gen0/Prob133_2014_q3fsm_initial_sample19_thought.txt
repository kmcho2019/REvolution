Use a 3-state FSM: A, B0, and B1. 
- State A: Wait for s=1 to go to B0.
- States B0 and B1 are used to count the three cycles of w and remember how many times w=1.
Use a 2-bit counter to count cycles (0 to 2). Also use a 2-bit counter to count how many times w=1 occurred in these cycles.
After three cycles, check if count of w=1 is exactly 2; if yes, set z=1 in the next cycle, else z=0.
Then start a new 3-cycle count again while in B state.
To minimize states, keep B as one state with counters for cycle count and w count. Use a single state B, and counters.
In reset, go to A, z=0.
Output z is registered and updated on each cycle after counting.
