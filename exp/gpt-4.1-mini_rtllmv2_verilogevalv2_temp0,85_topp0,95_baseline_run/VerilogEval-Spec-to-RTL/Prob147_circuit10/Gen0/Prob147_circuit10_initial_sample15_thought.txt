The circuit has one flip-flop whose output is state. The output q is combinational and depends on a, b, and the current state. Observing the waveform, q seems to be state AND b OR (state NOR a). More specifically, from the waveform, q = (state & b) | (~state & ~a). The flip-flop next state appears to be q. So on each clock edge, state <= q. We initialize state to 0 at start (since at first clock edge state=0). This matches the waveform values.
