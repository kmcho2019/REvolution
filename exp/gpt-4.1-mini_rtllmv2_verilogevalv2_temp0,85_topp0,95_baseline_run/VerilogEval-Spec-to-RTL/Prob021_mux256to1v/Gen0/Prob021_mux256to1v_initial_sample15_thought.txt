Implement a 256-to-1 multiplexer where each input is 4 bits wide. The input vector 'in' has 1024 bits, representing 256 4-bit inputs packed sequentially. The 8-bit select 'sel' chooses which 4-bit chunk to output. We compute the starting bit index as sel * 4 and then slice out the 4-bit segment from 'in' to produce 'out'.
