Implement a 256-to-1 multiplexer with each input being 4 bits wide. The inputs are packed into a single 1024-bit vector. Since each input is 4 bits, and there are 256 such inputs, 256*4=1024 bits in total. The selection index sel (8 bits) selects which 4-bit chunk to output. We calculate the start bit as sel*4 and slice out 4 bits from 'in' starting at that position.
