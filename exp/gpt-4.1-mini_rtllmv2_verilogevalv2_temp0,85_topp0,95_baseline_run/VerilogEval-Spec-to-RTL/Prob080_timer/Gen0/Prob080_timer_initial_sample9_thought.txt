Implement a single 10-bit down-counter with a D flip-flop for each bit. On each clock edge: if load is asserted, load the counter with the input data; if load is not asserted and the counter is not zero, decrement it by one. The terminal count output (tc) is asserted when the counter reaches zero. The counter stops counting at zero until loaded again. To satisfy the requirement of a single D flip-flop, I will implement the entire 10-bit counter as a single register updated each clock cycle, effectively modeling a single register with combinational logic for decrement or load.
