Implement a 10-bit down-counter that is loaded with the input data when load=1 on the positive clock edge. When load=0 and counter is not zero, decrement the counter by 1 each clock cycle. Once the counter reaches zero, it stays zero until reloaded. The output tc is asserted when the counter is zero. The design uses a single D flip-flop for the LSB, and the remaining bits use combinational logic updated on the clock edge.
