Implement a 10-bit down-counter that loads a new value from the data input when load is high at the rising edge of clk. If load is low, the counter decrements by 1 unless it is already zero, in which case it stays zero. The terminal count output tc is asserted when the counter reaches zero. The internal counter is implemented using a single D flip-flop for each bit (register), updated on every clock edge according to the logic described.
