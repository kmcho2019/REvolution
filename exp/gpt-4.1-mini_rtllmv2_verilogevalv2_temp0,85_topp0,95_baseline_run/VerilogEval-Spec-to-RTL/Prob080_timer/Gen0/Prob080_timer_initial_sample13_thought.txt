Implement a 10-bit down-counter with an internal register to hold the count value. On each positive clock edge, if load is asserted, the counter loads the input data. Otherwise, if the counter is not zero, it decrements by one. When the counter reaches zero, it stays there until loaded again. The output tc is asserted when the counter is zero. Use a single 10-bit D flip-flop register to hold the current count state.
