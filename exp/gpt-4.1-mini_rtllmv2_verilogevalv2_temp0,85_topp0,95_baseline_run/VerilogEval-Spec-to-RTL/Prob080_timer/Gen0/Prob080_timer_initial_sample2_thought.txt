Implement a single D flip-flop based down-counter with a 10-bit register for the counter value. When load=1, load the counter with the input data. When load=0 and the counter is not zero, decrement the counter by one on each clock cycle. The terminal count output (tc) is asserted when the counter value is zero. To meet the single D flip-flop requirement, implement the 10-bit counter using a single D flip-flop plus combinational logic to generate the next state of the counter and the output tc. This means the entire 10-bit counter is stored in a single register updated on each clock edge through combinational logic. This is a conceptual constraint; practically, the 10 bits are stored in a single multi-bit register (single D input vector).
