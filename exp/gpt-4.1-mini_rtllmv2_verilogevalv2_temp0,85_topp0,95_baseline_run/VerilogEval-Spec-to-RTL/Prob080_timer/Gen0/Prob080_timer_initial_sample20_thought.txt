Implement a 10-bit down-counter with a terminal count (tc) output. On each positive clock edge, if load is asserted, load the counter with the input data. Otherwise, if the counter is not zero, decrement it by 1. The output tc is asserted when the counter reaches zero. The counter should stop decrementing once it reaches zero until it is loaded again. The single D flip-flop mentioned is interpreted as using one sequential element for the counter (a register for the counter value). The 10-bit counter uses a 10-bit register. The decrement logic and zero detection are combinational within the sequential block.
