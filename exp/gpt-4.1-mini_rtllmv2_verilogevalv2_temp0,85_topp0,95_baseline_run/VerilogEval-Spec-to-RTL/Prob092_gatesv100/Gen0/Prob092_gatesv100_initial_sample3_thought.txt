We need to process a 100-bit input vector and produce three 100-bit outputs based on bitwise comparisons with neighbors.

1. For out_both: For each bit except the highest index (bit 99), check if the bit and its left neighbor (index+1) are both '1'. Set out_both[99] to 0 since it has no left neighbor.

2. For out_any: For each bit except the lowest index (bit 0), check if either the bit or its right neighbor (index-1) is '1'. Set out_any[0] to 0 since it has no right neighbor.

3. For out_different: For each bit, check if it is different from its left neighbor. Here, treat the vector as circular, so the left neighbor of bit 99 is bit 0.

We'll implement this using bitwise operations and shifts, handling boundary conditions explicitly.
