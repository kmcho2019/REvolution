For out_both, each bit except the last compares the input bit and its left neighbor (in[i] & in[i+1]); the last bit is 0.
For out_any, each bit except the first compares the input bit and its right neighbor (in[i] | in[i-1]); the first bit is 0.
For out_different, each bit compares input bit with its left neighbor, with wrap-around (in[i] ^ in[(i+1)%100]).
