For out_both, except the highest bit 99 which is 0, each bit i (0 to 98) is set if both in[i] and in[i+1] are 1.
For out_any, except the lowest bit 0 which is 0, each bit i (1 to 99) is set if either in[i] or in[i-1] is 1.
For out_different, every bit i is set if in[i] differs from its left neighbor, with wrap-around. The left neighbor of in[i] is in[(i+1)%100].
