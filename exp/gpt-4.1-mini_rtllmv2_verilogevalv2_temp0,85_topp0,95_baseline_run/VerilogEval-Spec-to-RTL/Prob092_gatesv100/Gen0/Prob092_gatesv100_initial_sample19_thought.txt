For out_both, each bit i from 0 to 98 will be set to the AND of in[i] and in[i+1], since the "left neighbour" means the bit with the next higher index. For bit 99, set to 0 as per specification.

For out_any, each bit i from 1 to 99 will be set to the OR of in[i] and in[i-1], since the "right neighbour" means the bit with the next lower index. For bit 0, set to 0 as per specification.

For out_different, compare each bit i to its left neighbour, which is (i+1) modulo 100 (wrapping around). So for bit i, out_different[i] = in[i] XOR in[(i+1) % 100].

We'll implement these using bitwise operations and shifts, taking care with boundary bits.
