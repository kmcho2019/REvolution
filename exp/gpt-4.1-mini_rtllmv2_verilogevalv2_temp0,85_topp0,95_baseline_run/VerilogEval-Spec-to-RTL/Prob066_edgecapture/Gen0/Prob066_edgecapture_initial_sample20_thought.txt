We need to detect for each bit when it transitions from 1 to 0 between consecutive clock cycles. To do this, we store the previous input value in a register and compare it with the current input. For bits where the previous value was 1 and the current value is 0, we set the corresponding bit in the output register to 1. The output register holds these detected bits until a synchronous reset is asserted, which clears the output register to zero. On each clock edge, if reset is asserted, we clear the output; otherwise, we update the output bits by OR'ing previous output bits with newly detected falling edges.
