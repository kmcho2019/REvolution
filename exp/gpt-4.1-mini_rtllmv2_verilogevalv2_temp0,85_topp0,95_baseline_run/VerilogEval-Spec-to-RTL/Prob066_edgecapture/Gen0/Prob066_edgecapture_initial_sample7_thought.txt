To detect when a bit in the 32-bit input changes from 1 to 0 between consecutive clock cycles, I will register the input on each clock edge. Then, for each bit position, I check if the previous bit was 1 and the current bit is 0. If that transition is detected, I set the corresponding output bit to 1 and hold it until the synchronous reset is asserted. On reset, all outputs clear to 0.
