To detect a transition from 1 to 0 on each bit of the 32-bit input vector, we need to store the previous value of the input at every clock cycle. By comparing the previous and current input bits, we can identify which bits transitioned from 1 to 0. Once detected, we set the corresponding output bit to 1 and keep it latched until a synchronous reset is asserted. On reset, all output bits are cleared to 0. The design uses synchronous logic triggered on the positive clock edge.
