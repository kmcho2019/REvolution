To detect the transition of each bit from 1 to 0 between consecutive clock cycles, we need to store the previous value of the input vector in a register. On each positive clock edge, we compare the previous value and the current input. If a bit was 1 in the previous cycle and is now 0, we set the corresponding output bit to 1 and keep it latched until a synchronous reset clears the output register. The output register maintains a bitwise OR of detected transitions to ensure that once a bit is set, it remains set until reset.
