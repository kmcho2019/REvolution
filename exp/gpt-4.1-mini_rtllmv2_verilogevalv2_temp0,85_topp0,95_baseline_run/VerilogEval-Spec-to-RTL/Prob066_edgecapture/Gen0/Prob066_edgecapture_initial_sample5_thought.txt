To detect a transition from 1 to 0 on each bit of the 32-bit input vector, we will store the previous input value in a register. On each clock edge, we compare the previous input with the current input; if the previous bit was 1 and the current bit is 0, that indicates a 1-to-0 transition. The output bits are set to 1 when such a transition occurs and remain 1 until reset. The reset is synchronous and active high, so on reset, output is cleared to 0.
