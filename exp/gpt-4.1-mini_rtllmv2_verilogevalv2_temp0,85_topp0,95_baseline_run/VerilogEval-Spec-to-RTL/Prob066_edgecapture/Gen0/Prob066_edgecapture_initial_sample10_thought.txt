To detect when a bit changes from 1 to 0, I will register the previous input value on each clock cycle. Then compare the previous value and the current value: if the previous bit was 1 and the current bit is 0, this indicates a falling edge (1 to 0) on that bit. Once detected, the corresponding bit in the output register will be set to 1 and will remain 1 until a synchronous reset is applied. The reset will clear the output register to zero. All logic will be synchronized on the positive edge of the clock.
