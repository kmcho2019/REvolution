We will create a 32-bit register to hold the output, initialized to zero on reset. On each clock cycle, we will compare the current input vector with the previous input vector (stored in a register). For each bit, if the previous input bit was 1 and the current input bit is 0, we set the corresponding output bit to 1 and keep it latched until reset. On reset, the output register is cleared to zero. We also need to store the current input into a register for the next cycle comparison.
