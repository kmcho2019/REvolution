To detect the falling edge from 1 to 0 for each bit, we need to store the previous input state in a register. On each clock cycle, we compare the previous input bit and the current input bit: if the previous bit was 1 and the current bit is 0, we set the corresponding output bit to 1. The output bits will retain their set state until reset is asserted synchronously. On reset, all output bits are cleared to 0.
