To detect a transition from 1 to 0 on each bit of the 32-bit input, we need to store the previous value of the input in a register. On each clock edge, we compare the previous input bit to the current input bit. If the previous bit was 1 and the current bit is 0, we set the corresponding bit in the output register to 1, and that bit remains set until the synchronous reset is asserted. The output register only resets to 0 when reset is high.
