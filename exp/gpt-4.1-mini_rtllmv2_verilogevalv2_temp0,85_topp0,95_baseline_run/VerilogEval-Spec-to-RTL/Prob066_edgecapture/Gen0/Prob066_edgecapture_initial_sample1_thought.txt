To detect a transition from 1 to 0 on each bit of the input vector, I will register the previous input value on each clock cycle. Then, I compare the previous input bit and current input bit: if previous bit was 1 and current bit is 0, a falling edge is detected for that bit. The output register will set that bit to 1 and remain 1 until reset is asserted. The reset is synchronous and active high, so on reset, the output register clears to zero. All operations happen on the positive clock edge.
