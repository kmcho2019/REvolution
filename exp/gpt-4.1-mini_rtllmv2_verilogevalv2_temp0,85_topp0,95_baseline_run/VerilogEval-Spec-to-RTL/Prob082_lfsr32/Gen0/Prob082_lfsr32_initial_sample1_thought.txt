Implement a 32-bit Galois LFSR shifting right. On each clock edge, if reset is high, set q to 32'h1. Otherwise, update q as follows: shift q right by one bit, and for each tapped bit position (32, 22, 2, 1), XOR the bit shifted in at that position with the LSB of q before shifting. In Galois LFSR, the feedback bit (the output bit before shifting) is XORed with tapped bits to produce the new bits at those positions. The taps correspond to bits q[31], q[21], q[1], and q[0] in zero-based indexing. We'll implement the logic to update q accordingly.
