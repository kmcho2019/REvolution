Implement a 32-bit Galois LFSR shifting right on each positive clock edge. The LFSR taps are at bit positions 32, 22, 2, and 1 (1-based indexing). Because the LFSR shifts right, q[0] is the output bit that influences tapped bits. On each clock edge, for each tap bit, we XOR it with q[0]. Non-tap bits simply take the value of the previous bit (shift right). On synchronous reset, q is set to 32'h1.
