Implement a 32-bit Galois LFSR shifting right. On each clock edge, if reset is active, load q with 32'h1. Otherwise, shift q right by one bit, and XOR the taps positions (bits 31, 21, 1, 0 in zero-based indexing) with the LSB bit q[0] to produce the new bits. Specifically, for each tap bit, its next value is XOR of current bit and q[0]. For other bits, the next value is just the bit to the left. The output q is the current state of the LFSR.
