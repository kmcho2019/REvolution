Implement a 32-bit Galois LFSR with taps at bits 32, 22, 2, and 1, shifting right. At each clock edge, if reset is active (synchronous, active high), set q to 32'h1. Otherwise, compute the new LFSR value by shifting right by 1 bit and XORing the output bit q[0] with the tapped bits. The taps in Galois configuration means that if q[0] is 1, the tapped bits are XORed with 1 to produce the new bits; if q[0] is 0, the register shifts right normally. Implement this logic inside an always block sensitive to posedge clk.
