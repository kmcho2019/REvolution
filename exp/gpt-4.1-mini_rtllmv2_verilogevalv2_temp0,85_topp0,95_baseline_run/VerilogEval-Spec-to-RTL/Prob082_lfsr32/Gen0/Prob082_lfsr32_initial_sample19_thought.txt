Implement a 32-bit Galois LFSR shifting right. On each clock edge, if reset is active, set q to 32'h1. Otherwise, compute the feedback bit as q[0]. For each bit with a tap (bits 31, 21, 1, and 0 in zero-based indexing), next value is q[i+1] XOR feedback, and for other bits, next value is q[i+1]. The MSB (bit 31) is updated as q[0] XOR feedback (tap at bit 32 corresponds to bit 31 zero-based).
