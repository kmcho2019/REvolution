Implement a 32-bit Galois LFSR that shifts right on every positive clock edge. On reset (synchronous, active high), set q to 32'h1. The taps are at positions 32, 22, 2, and 1 (1-based indexing). In Galois LFSR, the output bit q[0] is used to conditionally XOR with tap bits as the bits shift right. Specifically, for each tap bit, if q[0] is 1, that bit is XORed with 1 before shifting into the next position. Bit 0 shifts in as q[31] XOR q[0] if that bit is tapped; other bits shift down accordingly. Implement this logic in a sequential always block triggered by posedge clk.
