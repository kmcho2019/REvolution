Implement a 32-bit Galois LFSR with taps at bits 32, 22, 2, and 1, indexing from 1 to 32 (MSB to LSB).
In Verilog, bits are indexed from 0 to 31, with q[31] as bit 32 and q[0] as bit 1.
On each positive clock edge, if reset is high, set q to 32'h1.
Otherwise, perform the Galois LFSR update:
- Extract the output bit q[0].
- For tapped bits, XOR q[0] with the tapped bit to get the next bit.
- The shift is to the right by one bit.
Implementation steps:
- Calculate the new q as per Galois LFSR logic.
- The bits with taps (31,21,1,0) get updated by XOR with q[0].
- Other bits shift from the bit to their left.
