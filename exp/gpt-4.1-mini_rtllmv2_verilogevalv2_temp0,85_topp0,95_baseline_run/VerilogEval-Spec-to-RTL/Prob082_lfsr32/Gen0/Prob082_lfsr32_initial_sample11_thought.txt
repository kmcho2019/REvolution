Implement a 32-bit Galois LFSR shifting right on each positive clock edge. The taps are at bit positions 32, 22, 2, and 1 (1-based). Since Verilog uses 0-based indexing, these correspond to bits 31, 21, 1, and 0. On each clock, if reset is asserted, set q to 32'h1. Otherwise, calculate the feedback as XOR of q[0] with each tap bit, and shift the register right by one. For bits with taps, XOR q[0] with the bit; for other bits, shift right unchanged.
