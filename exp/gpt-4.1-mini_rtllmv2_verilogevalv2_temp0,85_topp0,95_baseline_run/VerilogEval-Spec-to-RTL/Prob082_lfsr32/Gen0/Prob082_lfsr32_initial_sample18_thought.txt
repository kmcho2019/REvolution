Implement a 32-bit Galois LFSR shifting right. On each clock rising edge, if reset is active, set q to 1. Otherwise, compute the feedback bit as q[0], then update q as follows: q[31] gets q[30], q[21] gets q[21] XOR feedback, q[1] gets q[1] XOR feedback, q[0] gets q[0] XOR feedback, and all other bits shift right normally without XOR. Since it's Galois, taps are implemented by XORing the feedback bit into certain positions during shift.
