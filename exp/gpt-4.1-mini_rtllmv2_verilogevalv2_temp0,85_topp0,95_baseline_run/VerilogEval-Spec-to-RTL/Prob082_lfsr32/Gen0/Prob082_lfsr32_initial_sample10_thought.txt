Implement a 32-bit Galois LFSR with taps at bits 32, 22, 2, and 1. The shift register shifts right on each positive clock edge. If reset is asserted, the register is synchronously set to 32'h1. The feedback bit is the XOR of the tap bits with the output bit q[0]. In Galois form, for each tap position, the bit is XORed with the output bit to produce the next state of that bit. The LSB is replaced by the feedback bit. We'll implement this inside a synchronous always block triggered on the positive edge of clk.
