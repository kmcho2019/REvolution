Implement a 32-bit Galois LFSR that shifts right on each positive clock edge. On reset, synchronously set q to 32'h1. The taps are at bits 32, 22, 2, and 1, which correspond to bit positions q[31], q[21], q[1], q[0] in zero-based indexing. The next input for these tap positions is XORed with q[0] (the LSB). Bits without taps shift right without XOR. The output q is updated synchronously on the clock edge.
