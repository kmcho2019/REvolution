Implement a 32-bit Galois LFSR shifting right. On each clock edge, if reset is high, set q to 32'h1. Otherwise, update the LFSR as follows: take the current LSB (q[0]) as feedback bit. For each tapped bit position (32, 22, 2, 1), XOR that bit with the feedback bit to get the next value of that bit. The bits without taps just shift right unchanged. In Galois LFSR, the feedback bit is XORed into certain positions before shifting right. We'll implement this by shifting q right by 1 bit, and for each tapped bit position (adjusted to zero-indexed), XOR feedback bit into that bit. Note: positions are 1-based, so bit 32 is q[31], bit 22 is q[21], bit 2 is q[1], bit 1 is q[0]. The LSB q[0] is the output bit before shifting. We'll implement the feedback XOR at these taps in the new q value.
