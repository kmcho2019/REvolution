Implement a 32-bit Galois LFSR with taps at bit positions 32, 22, 2, and 1. Since bit positions are typically 1-based, they correspond to q[31], q[21], q[1], and q[0] in zero-based indexing. The feedback bit is taken from q[0]. On each clock rising edge, if reset is high, set q to 32'h1. Otherwise, shift right by one bit. For tapped bits, XOR their next value with the feedback bit; for non-tapped bits, next value is just the previous bit shifted in. The MSB (bit 31) gets the XOR of q[31], q[21], q[1], and q[0] with the feedback bit, but in Galois configuration, only tapped bits XOR the feedback bit with their shifted input. To implement this, loop over bits: for each bit, if it's tapped, next q[i] = q[i+1] ^ feedback, else q[i] = q[i+1]. For the MSB bit (31), q[31] gets feedback bit itself, since q[32] does not exist. Here, the standard approach is: feedback = q[0]; next q[31] = feedback XOR tapped or not? Actually, in Galois LFSR, the feedback bit is fed back into tapped bits during shifting. So, q[0] is shifted out, q[i] = q[i+1] XOR feedback if i is tapped, else q[i] = q[i+1]. For i=31 (MSB), the shifted in bit is feedback only if bit 31 is tapped; otherwise 0. Since bit 32 is tapped, q[31] = q[31] (previous) XOR feedback. For clarity, implement logic accordingly.
