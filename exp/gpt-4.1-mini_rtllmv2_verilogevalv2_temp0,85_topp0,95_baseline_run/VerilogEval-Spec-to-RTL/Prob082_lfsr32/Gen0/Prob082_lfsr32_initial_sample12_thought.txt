Implement a 32-bit Galois LFSR with taps at bits 32, 22, 2, and 1. Since bit positions are 1-based, these correspond to q[31], q[21], q[1], and q[0] in zero-based indexing. On each clock, if reset is high, q resets to 32'h1. Otherwise, the LFSR shifts right by one bit. The new bit entering at the MSB is the XOR of q[0] and the tapped bits' values (as per the Galois LFSR style). In Galois LFSR, the feedback bit is q[0], and tapped bits are XORed with this feedback bit before shifting. The Galois feedback update is done in parallel on each bit: if the bit is tapped, it XORs with q[0], else it just shifts the previous bit. Implement this logic on positive clock edge with synchronous reset.
