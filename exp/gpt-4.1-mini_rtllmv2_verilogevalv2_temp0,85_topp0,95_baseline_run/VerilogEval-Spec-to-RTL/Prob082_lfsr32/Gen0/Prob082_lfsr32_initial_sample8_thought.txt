Implement a 32-bit Galois LFSR shifting right. The taps at bits 32, 22, 2, and 1 correspond to indices 31, 21, 1, and 0 in zero-based indexing. On each clock cycle, if reset is asserted, set q to 1. Otherwise, shift right by one bit, and for bits with taps, XOR the incoming value with the LSB before shifting in. In the Galois configuration, the output bit q[0] is fed back to the tapped bits by XORing with that bit, while other bits just shift the previous bit. Implement this behavior in a synchronous always block.
