Implement a synchronous FSM with the present state represented by a 3-bit register. On each clock edge, update the state according to the input x and the current state y using the provided transition table. Output z is combinationally derived from the present state and input x according to the table. The output Y0 is the least significant bit of the next state (Y[0]). Since the current state is given as input y, the FSM's next state logic depends on y and x, and the output z depends on the current state y and input x.

Note: Since the state is given as input y, the module behaves like a Mealy machine where next state and output depend on current input and state, and the next state is output as Y[2:0]. Here, only Y0 is output. The FSM state registers are not internal but given by input y; the module computes next state and output based on that.

Therefore, the module outputs:
- Y0 = next_state[0]
- z = as per table

We implement combinational logic for next state and output z based on y and x.
