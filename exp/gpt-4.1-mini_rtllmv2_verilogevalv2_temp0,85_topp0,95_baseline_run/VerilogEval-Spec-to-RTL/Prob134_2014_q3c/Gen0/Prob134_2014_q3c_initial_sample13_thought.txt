Implement a synchronous FSM with a 3-bit state register (y). On each clock edge, update the state according to the input x and current state using the provided next state table. Output z is combinationally derived from the present state and input x per the table. Output Y0 is the least significant bit of the next state. Use a combinational always block to compute the next state and z based on the current state and input x, and a sequential always block to update the state register on the rising edge of clk.
