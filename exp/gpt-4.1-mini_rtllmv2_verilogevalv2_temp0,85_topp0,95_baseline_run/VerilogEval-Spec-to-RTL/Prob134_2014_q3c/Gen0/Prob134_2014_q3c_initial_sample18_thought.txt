Implement a synchronous FSM with a 3-bit state register. The current state is held in a register y_state. On each clock edge, based on the input x and current state y_state, the next state Y is determined by the given table. The output z depends on the current state and input x as per the table. The output Y0 is the LSB of the next state Y. We'll implement combinational next-state and output logic, then update the state at the clock edge.
