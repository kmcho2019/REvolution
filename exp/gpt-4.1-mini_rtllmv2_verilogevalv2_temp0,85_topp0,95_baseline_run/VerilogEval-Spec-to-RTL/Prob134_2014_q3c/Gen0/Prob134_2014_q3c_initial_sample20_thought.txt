Implement a synchronous FSM with 3-bit state register Y. The next state logic is determined by the present state (input y) and input x, following the provided state transition table. Output z depends on the current state and input x according to the table. Since y is an input representing present state, the module computes next state Y and output z combinationally from inputs (y and x). Output Y0 is Y[0] of the next state. The module outputs Y0 and z. clk is given but since y is an input and the FSM state is not stored internally, clk is unused in this design. Alternatively, if the FSM state needs to be stored internally, y would be replaced by internal state register. Given the problem statement, we use y as present state input, so we treat it as combinational logic.
