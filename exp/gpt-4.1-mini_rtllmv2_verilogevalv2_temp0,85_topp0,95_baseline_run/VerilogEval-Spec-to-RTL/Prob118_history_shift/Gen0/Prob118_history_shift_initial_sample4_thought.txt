Implement a 32-bit shift register with asynchronous active-high reset. On each positive clock edge, if areset is asserted, reset the history to zero. Else if train_mispredicted is asserted, load the history with {train_history[30:0], train_taken}, representing the rollback state after pipeline flush. Else if predict_valid is asserted, shift the history left by one and insert predict_taken at LSB. If none, keep the history unchanged. Output the current history as predict_history. The misprediction load takes precedence over prediction update.
