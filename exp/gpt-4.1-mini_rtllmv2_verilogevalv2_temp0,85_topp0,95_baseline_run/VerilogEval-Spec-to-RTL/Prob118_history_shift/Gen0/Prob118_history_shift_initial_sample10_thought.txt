Implement a 32-bit shift register to hold the global branch history. On the positive clock edge, asynchronously reset it to zero if areset is asserted. If a misprediction occurs (train_mispredicted=1), load the register with train_history concatenated with train_taken, as this is the corrected history after rollback. If no misprediction but predict_valid=1, shift the history left by one and input predict_taken at LSB, reflecting the predicted branch. If neither, hold the history. Output the current history on predict_history.
