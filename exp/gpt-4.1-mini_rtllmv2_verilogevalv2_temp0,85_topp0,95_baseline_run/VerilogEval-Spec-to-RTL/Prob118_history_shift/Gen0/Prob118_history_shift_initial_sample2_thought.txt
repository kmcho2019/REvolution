Implement a 32-bit shift register updated on the positive edge of clk. On asynchronous positive edge of areset, reset the history to zero. On each clock edge, if train_mispredicted is high, load the history with {train_history, train_taken} as the new 32-bit value (train_history[31:1] concatenated with train_taken as the LSB, as explained: the history before the mispredicted branch plus the actual branch result). Otherwise, if predict_valid is high, shift in predict_taken from the LSB side (history <= {predict_taken, history[31:1]}). The output predict_history is the current history register. Misprediction update has priority over prediction update.
