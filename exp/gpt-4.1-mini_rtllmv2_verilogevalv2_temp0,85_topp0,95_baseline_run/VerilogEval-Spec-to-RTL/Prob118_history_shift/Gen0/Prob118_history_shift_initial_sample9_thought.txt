Implement a 32-bit shift register to hold the global history. On areset, asynchronously reset the register to zero. On the positive edge of the clock, if train_mispredicted is high, load the register with {train_history, train_taken} (train_history is bits [31:1], train_taken is bit 0). Otherwise, if predict_valid is high (and no misprediction), shift the register left by one and insert predict_taken into the LSB. Output predict_history as the current value of the register. Misprediction handling has priority over prediction updates.
