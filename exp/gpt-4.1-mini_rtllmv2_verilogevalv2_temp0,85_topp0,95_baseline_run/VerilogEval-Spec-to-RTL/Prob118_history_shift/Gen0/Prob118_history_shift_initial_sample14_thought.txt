Implement a 32-bit shift register that holds the global branch history. On asynchronous reset, clear the history. On each clock edge, if a misprediction occurs, load the history with {train_history, train_taken}, effectively rolling back to the state before the mispredicted branch plus the actual outcome. If no misprediction but a prediction is valid, shift the current history right by one and shift in predict_taken at bit 0 (youngest branch). The misprediction update takes priority over prediction. Output the current history as predict_history.
