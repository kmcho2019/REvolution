Implement the function f based on the given 4-variable Karnaugh map. 
The inputs x[3:0] correspond to variables x[3], x[2], x[1], x[0]. 
The Karnaugh map is arranged with x[2]x[3] as row and x[0]x[1] as column.
To simplify the implementation, index the Karnaugh map as f[row][column], where:
row = {x[3], x[2]}
col = {x[1], x[0]}

However, the problem states the Karnaugh map as:

         x[0]x[1]
x[2]x[3]  00  01  11  10
 00       1   0   0   1
 01       0   0   0   0
 11       1   1   1   0
 10       1   1   0   1

We must be careful with the indexing of bits.

Given that x is 4 bits input: x[3], x[2], x[1], x[0]

From the table, rows are x[2] x[3], columns are x[0] x[1].

So to get the row index: row = {x[2], x[3]}
To get the column index: col = {x[0], x[1]}

We can combine these to get the input index as: {x[2], x[3], x[0], x[1]}

We can implement the function either by directly encoding the Karnaugh map in a case statement or as a logic expression after simplification.

For clarity, implement the function using a case statement indexed by {x[2], x[3], x[0], x[1]}.

Check the 16 combinations and assign f accordingly.

Note: Because the table's first row corresponds to x[2]x[3]=00, which means x[2]=0 and x[3]=0.

The columns correspond to x[0]x[1] from 00,01,11,10.
