The input x is 4 bits: x[3:0]. The Karnaugh map organizes the inputs as x[2:3] by rows and x[0:1] by columns. We will write the truth table based on the K-map values and then derive the function using a case statement or boolean expressions. Alternatively, we can directly implement the function from the minterms where the output is 1. The minterms correspond to the indices where the map is 1. We can write the function as a sum of minterms.
