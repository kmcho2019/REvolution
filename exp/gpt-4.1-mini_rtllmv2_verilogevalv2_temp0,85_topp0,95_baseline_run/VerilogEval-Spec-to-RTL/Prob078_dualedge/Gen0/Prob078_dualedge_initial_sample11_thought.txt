A dual-edge triggered flip-flop can be implemented by using two single-edge triggered flip-flops: one triggered on the positive edge and one on the negative edge of the clock. We then combine their outputs using a multiplexer controlled by the clock to select which flip-flop's output is currently valid. This way, we effectively get the value updated on both clock edges, simulating a dual-edge triggered flip-flop without using an illegal sensitivity list.
