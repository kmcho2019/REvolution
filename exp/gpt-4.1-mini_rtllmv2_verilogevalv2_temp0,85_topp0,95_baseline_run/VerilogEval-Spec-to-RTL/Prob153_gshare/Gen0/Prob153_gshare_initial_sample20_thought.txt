Implement a gshare branch predictor with a 7-bit global history register and a 128-entry PHT (two-bit saturating counters). The PHT index is computed as XOR of 7-bit PC and 7-bit global history. The predictor supports separate predict and train interfaces.

On prediction (predict_valid), output prediction (taken if counter MSB=1) and the current global history. At the next clock edge, update the global history with the predicted taken bit if there is no mispredict training taking precedence.

On training (train_valid), update the PHT entry indexed by train_pc XOR train_history with increment/decrement of the two-bit counter based on train_taken. If train_mispredicted=1, also restore the global history to train_history value, overriding any prediction update that cycle.

On reset (areset), initialize global history and PHT entries to 0 (weakly not taken).

Handle the case of concurrent prediction and training in the same cycle: training takes precedence on global history update. Prediction reads PHT state before training modifies it.

All sequential logic triggered on posedge clk; reset async active-high.
