Implement a gshare branch predictor with a 7-bit global history register (GHR) and a 128-entry (2^7) pattern history table (PHT) of 2-bit saturating counters. Use XOR of the 7-bit PC and 7-bit GHR to index into PHT.

Prediction path:
- When predict_valid is high, read the PHT entry indexed by (predict_pc ^ ghr).
- Output predict_taken as the MSB of the 2-bit counter (>=2 means taken).
- Output predict_history as current ghr.
- At next clock edge, if no misprediction training, update GHR with the predicted taken bit.

Training path:
- When train_valid is high, update the PHT entry indexed by train_pc ^ train_history using train_taken.
- If train_mispredicted is asserted, restore the GHR to train_history at next clock edge instead of the predicted update.
- If both training (with mispredict) and prediction happen simultaneously, training takes precedence on GHR update.

Reset:
- Asynchronous active-high reset clears GHR to zero and initializes PHT counters to weakly taken (2).

Handle read-before-write behavior: predictions see PHT state before training update in same cycle.

Implement all sequential logic on posedge clk.

This design guarantees correct handling of concurrent prediction and training with priority to training for GHR updates.
