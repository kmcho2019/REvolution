Implement a gshare branch predictor with a 7-bit global history register and a 128-entry pattern history table (PHT) of 2-bit saturating counters indexed by XOR of 7-bit PC and 7-bit global history.

Prediction interface:
- When predict_valid=1, output the prediction (taken if counter MSB=1) and the current global history.
- Update the global history with the predicted outcome at the next clock cycle (if no training mispredict recovery).

Training interface:
- When train_valid=1, update the PHT entry indexed by train_pc XOR train_history using train_taken.
- If train_mispredicted=1, recover the global history to train_history value (history as it was after the mispredicted branch).
- If training and prediction happen in the same cycle, training takes priority on global history update.
- If training and prediction access the same PHT entry in the same cycle, the prediction uses the PHT before training updates.

Reset is asynchronous active-high, reset global history and PHT counters to initial states (global history=0, counters=2'b10 (weakly taken) is common default).

All sequential logic on posedge clk.

Thus, implement:
- Global history register (7 bits).
- PHT: 128 entries of 2-bit saturating counters.
- Prediction logic combinational: index = predict_pc XOR global_history; output prediction and history.
- At posedge clk:
  - If areset, reset global history and PHT.
  - Else if train_valid:
     - Update PHT entry indexed by train_pc XOR train_history with train_taken.
     - If train_mispredicted, restore global history to train_history.
  - Else if predict_valid:
     - Update global history with predicted outcome (taken/not taken).
