Implement a gshare branch predictor with a 7-bit global history register (GHR) and a 128-entry pattern history table (PHT), each entry is a 2-bit saturating counter. The index into the PHT is formed by XOR'ing the 7-bit PC and the 7-bit GHR. On a prediction request (predict_valid), output the prediction (MSB of the saturating counter) and the current GHR used to make the prediction (predict_history). Update the GHR on the next clock edge with the predicted direction unless a training misprediction happens simultaneously, in which case the GHR is restored to the train_history value from the training port, as training takes precedence over prediction. On a training request (train_valid), update the PHT entry indexed by train_pc XOR train_history according to the actual branch outcome. If train_mispredicted is high, restore the GHR to train_history. Prediction outputs use the current PHT and GHR state before any updates. Asynchronous reset clears GHR and PHT entries to weakly taken (2'b10). Proper priority and timing for simultaneous predict/train operations are implemented.
