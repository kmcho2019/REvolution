Implement a 7-bit global history register and a 128-entry pattern history table (PHT) of 2-bit saturating counters. The index into the PHT is obtained by XORing the 7-bit PC with the 7-bit global history.

Prediction interface:
- On predict_valid, output prediction based on PHT indexed by (predict_pc XOR global_history).
- Also output current global_history at prediction time.
- At next clock edge, if no training misprediction occurs, update global_history by shifting in the predicted direction.
- If training misprediction happens simultaneously, training updates global_history to the recovered history, overriding prediction update.

Training interface:
- On train_valid, update the PHT entry indexed by (train_pc XOR train_history) according to train_taken.
- If train_mispredicted is high, restore global_history to train_history (recovered history).
- Training takes priority over prediction for global_history update if both occur in same cycle.

Asynchronous active-high reset resets global_history to 0 and PHT entries to weakly taken (2).

Output predict_taken is MSB of the 2-bit counter (2 or 3 means taken).

Ensure combinational prediction output uses PHT state before any updates on the clock edge.

Implement the described behavior with synchronous sequential logic triggered on posedge clk and asynchronous reset.
