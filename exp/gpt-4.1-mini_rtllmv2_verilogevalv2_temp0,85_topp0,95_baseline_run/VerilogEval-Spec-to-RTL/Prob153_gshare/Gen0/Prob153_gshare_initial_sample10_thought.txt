Implement a gshare predictor with a 7-bit global history register (GHR) and a 128-entry PHT of 2-bit saturating counters. The prediction index is pc xor GHR. On predict_valid, output the prediction and the GHR used, and update a "next GHR" register with the predicted bit. On train_valid, update the PHT entry indexed by train_pc xor train_history using the actual outcome. If mispredicted, restore the GHR to train_history; otherwise, do not change it. If both predict_valid and train_valid happen in the same cycle and train_mispredicted is set, training's GHR update takes precedence. Prediction output uses PHT state before training updates. Asynchronous reset clears GHR and PHT entries to weakly taken (2'b10). Sequential updates occur on posedge clk.
