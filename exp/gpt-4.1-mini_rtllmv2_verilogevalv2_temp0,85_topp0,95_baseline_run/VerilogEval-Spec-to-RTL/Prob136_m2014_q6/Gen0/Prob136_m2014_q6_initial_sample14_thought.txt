Implement a finite state machine with six states (A-F) encoded as a 3-bit register.
On each positive clock edge, the FSM transitions based on the current state and input w according to the given state diagram.
The output z depends on the state and input w as specified:
- Output is 0 in states A-D (since no output mentioned, default to 0)
- Output is 1 in states E and F as shown in the transitions (E and F have output 1)
Reset sets the FSM to state A.
