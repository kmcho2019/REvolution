Implement a Moore FSM with 6 states (A-F). Use a 3-bit state register to encode states uniquely. On synchronous reset (active-high), state resets to A. On each clock rising edge, update state based on current state and input w. Use one always block for state transitions (combinational), one always block for state flip-flops (sequential), and a continuous assignment for output z based on the current state. Output z is 1 only in state E, else 0.
