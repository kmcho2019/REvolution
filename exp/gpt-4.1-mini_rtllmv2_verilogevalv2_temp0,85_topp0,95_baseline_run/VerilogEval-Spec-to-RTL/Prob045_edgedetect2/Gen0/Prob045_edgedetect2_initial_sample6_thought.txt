To detect any edge (rising or falling) on each bit of the 8-bit input vector, we need to store the previous state of the input bits in a register. On each positive clock edge, compare the current input bits to the stored previous input bits. If any bit differs, it means an edge occurred on that bit. The output bit anyedge should be set to 1 on the cycle after the transition, so we assign the output to be the stored previous edge detection from the previous clock cycle. This requires two sets of registers: one to hold the previous input values, and one to hold the detected edges which will be output in the next cycle.
