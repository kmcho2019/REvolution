To detect any edge on each bit of the 8-bit input vector, we store the previous input in a register on each clock cycle. The anyedge output bit for each input bit is set to 1 if the current input bit differs from the stored previous input bit (indicating a transition). Since the output should be set the cycle after the edge occurs, the anyedge output is simply the XOR of the previous input and the current input, registered one cycle later.
