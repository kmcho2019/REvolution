To detect any edge on each bit of the 8-bit input vector, we need to store the previous state of the input bits in a register. On each positive edge of the clock, compare the current input bits to the stored previous bits. If there is a difference (XOR), that indicates an edge occurred. The output anyedge will be set to 1 for bits where edges were detected on the previous clock cycle, thus we register the edge detection result and output it one cycle later.
