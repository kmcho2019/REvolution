To detect any edge for each bit in the 8-bit input vector, we need to store the previous state of the input bits on every clock cycle. Then, on the next clock cycle, we compare the current input with the stored previous input to detect any change (0->1 or 1->0). The output anyedge should be asserted one clock cycle after the edge is detected, so we register the result of the comparison and output it on the next clock cycle.
