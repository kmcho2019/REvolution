To detect any edge (rising or falling) on each bit of an 8-bit input vector, we can store the previous input value in a register on each clock cycle. Then, we compare the current input with the previous input for each bit. If a bit has changed, we set the corresponding bit in the anyedge output to 1 on the next clock cycle. Since the output reflects the edge detection one cycle after the transition, we register the detected changes before assigning to anyedge.
