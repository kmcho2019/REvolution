To detect any edge on each bit of the 8-bit input vector, store the previous cycle's input bits in a register. On each clock's positive edge, compare the current input bits to the stored previous bits. If a bit differs from its previous state, it means an edge occurred. The output anyedge should be set to 1 in the cycle after the edge is detected, so we register the edge detection result. Thus, the output anyedge reflects edges detected on the previous cycle's input transition.
