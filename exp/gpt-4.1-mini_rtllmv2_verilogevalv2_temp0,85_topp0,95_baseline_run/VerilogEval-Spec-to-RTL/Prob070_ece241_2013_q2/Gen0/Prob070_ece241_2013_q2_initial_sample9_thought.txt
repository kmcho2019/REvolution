To implement the required logic, first express the 4-bit input as a vector: {a,b,c,d}. We need the output to be 1 for decimal inputs 2, 7, and 15, and 0 for decimal inputs 0,1,4,5,6,9,10,13,14. Inputs 3,8,11,12 never occur and can be treated as don't-cares for simplification.

Convert decimal values to binary (a,b,c,d):
0 = 0000
1 = 0001
2 = 0010  -> output = 1
3 = 0011  -> don't care
4 = 0100
5 = 0101
6 = 0110
7 = 0111  -> output = 1
8 = 1000  -> don't care
9 = 1001
10= 1010
11= 1011  -> don't care
12= 1100  -> don't care
13= 1101
14= 1110
15= 1111  -> output = 1

Use Karnaugh maps with don't cares to minimize the SOP and POS expressions.

From minimization:
- Minimum SOP: out_sop = (a & b & c & d) + (~a & b & c & d) + (~a & ~b & c & ~d)
- Minimum POS: out_pos = (a + b + ~c + d) & (a + ~b + c + d) & (~a + b + c + ~d)

Implement the logic accordingly.
