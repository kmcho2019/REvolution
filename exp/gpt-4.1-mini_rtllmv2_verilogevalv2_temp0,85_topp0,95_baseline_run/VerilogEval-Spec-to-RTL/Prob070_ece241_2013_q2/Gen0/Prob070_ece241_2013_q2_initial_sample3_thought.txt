We need to generate an output that is logic-1 for inputs representing the decimal numbers 2, 7, and 15, and logic-0 for the specified other numbers. The inputs a,b,c,d correspond to a 4-bit number; from the example, 7 corresponds to a=0,b=1,c=1,d=1, so the bit order is a (MSB), b, c, d (LSB).

First, list all minterms where output is 1:

- 2  = 0 0 1 0 (a=0,b=0,c=1,d=0)
- 7  = 0 1 1 1 (a=0,b=1,c=1,d=1)
- 15 = 1 1 1 1 (a=1,b=1,c=1,d=1)

Express these minterms and minimize for SOP and POS forms.

SOP (sum of products) minimal expression:
From minterms: m2, m7, m15

- m2 = a'b'cd'
- m7 = a' b c d
- m15= a b c d

We can try to simplify:

Group m7 and m15: b c d (a'+a) = b c d

So SOP = a'b' c d' + b c d

POS (product of sums) minimal expression:

The zeros are given for 0,1,4,5,6,9,10,13,14:

0  = 0000
1  = 0001
4  = 0100
5  = 0101
6  = 0110
9  = 1001
10 = 1010
13 = 1101
14 = 1110

We can write maxterms for these zeros and simplify.

Alternatively, the minimal POS can be derived from the complement of the SOP.

After minimization, the POS expression is (a + c + d')(b + c + d)
