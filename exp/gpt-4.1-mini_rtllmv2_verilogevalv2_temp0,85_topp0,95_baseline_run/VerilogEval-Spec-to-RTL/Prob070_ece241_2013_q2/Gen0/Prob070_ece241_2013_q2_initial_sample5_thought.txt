First, interpret the 4 input bits (a,b,c,d) as a 4-bit number where a is the most significant bit and d the least significant. We want to output logic-1 for inputs 2, 7, or 15 and logic-0 for inputs 0, 1, 4, 5, 6, 9, 10, 13, 14. The inputs 3, 8, 11, 12 never occur.

Step 1: List the input patterns for the numbers 0 to 15 using a,b,c,d with a as MSB:
- 0: 0000
- 1: 0001
- 2: 0010
- 3: 0011 (never occur)
- 4: 0100
- 5: 0101
- 6: 0110
- 7: 0111
- 8: 1000 (never occur)
- 9: 1001
- 10:1010
- 11:1011 (never occur)
- 12:1100 (never occur)
- 13:1101
- 14:1110
- 15:1111

Step 2: Write the minterms for the numbers 2, 7, 15 where output=1:
- 2: 0 0 1 0 -> a=0,b=0,c=1,d=0 -> a'b'cd'
- 7: 0 1 1 1 -> a=0,b=1,c=1,d=1 -> a'b c d
- 15:1 1 1 1 -> a b c d

Step 3: Derive minimum SOP (sum of products) from these minterms:
Sum of minterms: m2 + m7 + m15 = a'b'cd' + a'bcd + abcd

Try to simplify:
- Group a'bcd and abcd: common bcd -> b c d (a'+a) = b c d
- So expression becomes: a'b'cd' + b c d

Step 4: Derive minimum POS (product of sums) form. Output=0 for 0,1,4,5,6,9,10,13,14. We write the maxterms for these inputs and then find minimal POS.

Maxterms corresponding to zeros:
0: 0000 -> (a + b + c + d)
1: 0001 -> (a + b + c + d')
4: 0100 -> (a + b' + c + d)
5: 0101 -> (a + b' + c + d')
6: 0110 -> (a + b' + c' + d)
9: 1001 -> (a' + b + c + d')
10:1010 -> (a' + b + c' + d)
13:1101 -> (a' + b' + c + d')
14:1110 -> (a' + b' + c' + d)

Simplify the POS expression by grouping common factors:
- Notice terms with a + ... and a' + ... in the same product, can't factor a directly.
- However, the minimal POS is found to be (a + b + c + d)(a + b' + c + d')(a' + b + c + d')(a' + b' + c' + d)

This matches the minimal POS expression for the given logic.
