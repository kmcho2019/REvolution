Implement a 4-digit BCD counter with digits stored in q[15:0] as four 4-bit BCD digits. On each clock tick, increment the least significant digit (ones). If it overflows (reaches 10), reset it to 0 and enable increment of the next digit (tens). Similarly for tens and hundreds digits, with corresponding ena signals to indicate when the next digit should increment. The highest digit (thousands) increments only when hundreds overflows, but no ena output is needed for it. Implement synchronous active-high reset to zero all digits and clear enables.
