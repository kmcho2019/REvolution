Implement a 4-digit BCD counter with 4-bit digits stored in q[15:0]. On each clock edge, increment the ones digit. If it rolls over from 9 to 0, enable the tens digit increment (ena[0]). Similarly, propagate carry enables from tens to hundreds (ena[1]) and hundreds to thousands (ena[2]) digits. Output ena signals indicate when each upper digit should increment. Implement synchronous active-high reset to clear the counter.
