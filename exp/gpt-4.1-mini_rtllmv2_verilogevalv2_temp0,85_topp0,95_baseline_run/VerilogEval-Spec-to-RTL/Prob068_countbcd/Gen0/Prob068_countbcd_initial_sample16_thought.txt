Implement a 4-digit BCD counter using a 16-bit register 'q' where each 4-bit nibble represents a BCD digit (ones, tens, hundreds, thousands). The counter increments the ones digit every clock cycle unless reset is active. When a digit reaches 9 and increments, it resets to 0 and enables the next digit to increment via the 'ena' output signals (3 bits for digits 3 to 1). The synchronous reset sets all digits and enables to zero.
