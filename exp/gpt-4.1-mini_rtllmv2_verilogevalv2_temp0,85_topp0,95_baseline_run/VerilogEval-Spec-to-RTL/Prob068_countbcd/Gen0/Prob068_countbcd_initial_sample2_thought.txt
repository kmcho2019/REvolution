Implement a 4-digit BCD counter with digits stored in 4-bit groups within a 16-bit output q. The ones digit (q[3:0]) always increments each clock cycle unless reset. Each higher digit increments only when the digit below rolls over from 9 to 0, indicated by an enable signal ena for digits 1 to 3. The ena output is 3 bits, where each bit corresponds to whether the next digit should increment on the current clock cycle. Synchronous active-high reset clears the entire counter to zero.
