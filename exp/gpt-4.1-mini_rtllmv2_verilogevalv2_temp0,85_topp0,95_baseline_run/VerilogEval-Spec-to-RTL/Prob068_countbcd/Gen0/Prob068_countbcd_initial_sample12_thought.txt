Implement a 4-digit BCD counter where each digit is 4 bits representing decimal digits 0-9. The counter increments the ones digit on each clock cycle. When a digit rolls over from 9 to 0, it enables the next digit to increment via the ena signals. The ena output is 3 bits: ena[0] enables incrementing the tens digit, ena[1] the hundreds digit, and ena[2] the thousands digit. Use synchronous reset to clear all digits to zero.
