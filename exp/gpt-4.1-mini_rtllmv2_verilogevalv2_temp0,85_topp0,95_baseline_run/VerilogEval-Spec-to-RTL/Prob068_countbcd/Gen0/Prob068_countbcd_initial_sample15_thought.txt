Implement a 4-digit BCD counter using four 4-bit digits packed in a 16-bit output q. On each clock cycle, increment the ones digit; if it overflows from 9 to 0, enable the tens digit increment, and similarly propagate carries for hundreds and thousands digits using the ena signals. The ena output is 3 bits: ena[0] enables the tens digit increment, ena[1] for hundreds, and ena[2] for thousands. Synchronous active-high reset clears the counter to zero. All logic is in a single always block triggered on the positive edge of clk.
