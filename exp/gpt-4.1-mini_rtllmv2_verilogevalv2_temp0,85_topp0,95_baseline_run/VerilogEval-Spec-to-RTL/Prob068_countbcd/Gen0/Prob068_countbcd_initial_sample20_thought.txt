Implement a 4-digit BCD counter where each digit is 4 bits within q[15:0]. On each clock rising edge, if reset is high, clear the counter to zero. Otherwise, increment the ones digit (q[3:0]). If the ones digit overflows (goes from 9 to 0), enable increment for the tens digit (ena[0]). Similarly, if the tens digit overflows, enable increment for the hundreds digit (ena[1]), and if the hundreds digit overflows, enable increment for the thousands digit (ena[2]). The ena signals indicate when each upper digit should be incremented (i.e., when the lower digit rolls over from 9 to 0). The most significant digit (thousands) does not have an enable output.

The counting logic ensures that digits roll over after 9 back to 0, maintaining a valid BCD count from 0000 to 9999.
