Implement a finite state machine with states representing the phases: searching for the start pattern (1101), shifting in 4 bits, counting, done waiting for ack. Use a shift register to detect the pattern. After reset, FSM starts in SEARCH state. When pattern detected, move to SHIFT state asserting shift_ena for 4 cycles. Then go to COUNT state asserting counting until done_counting is high. Then go to DONE state asserting done until ack is high, then back to SEARCH. All state transitions occur on posedge clk and reset is synchronous active high.
