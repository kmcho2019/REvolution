Implement a synchronous FSM with five states: IDLE (searching for pattern 1101), SHIFT (shifting in 4 bits with shift_ena asserted), COUNT (waiting for done_counting), DONE (assert done and wait for ack). We use a 4-bit shift register to detect the pattern 1101 on the serial input data. On reset, the FSM returns to IDLE. The outputs shift_ena, counting, and done are asserted as per the state descriptions.
