Design a synchronous FSM with states: IDLE (search for pattern), SHIFT (shift 4 bits), COUNT (wait for done_counting), DONE (assert done and wait for ack). Use a 4-bit shift register to detect the start pattern 1101. On detecting 1101, transition to SHIFT state and assert shift_ena for 4 cycles using a counter. Then move to COUNT state and assert counting until done_counting is high. Then move to DONE state, assert done until ack is high, then return to IDLE. Reset synchronously clears the FSM to IDLE.
