Implement a finite state machine with the following states:
- IDLE: Searching for the 4-bit pattern 1101 on the serial data input.
- SHIFT: After detecting the pattern, enable shift_ena for 4 clock cycles to shift in 4 more bits.
- COUNT: After shifting, assert counting until done_counting is high.
- DONE: Assert done until ack is high, then return to IDLE.

Use a shift register of length 4 to detect the pattern 1101. On every clock, shift in the new data bit and check if the pattern matches. Use a counter to count the 4 shift cycles in the SHIFT state. The synchronous reset initializes the state machine to IDLE.

Outputs:
- shift_ena: high only during SHIFT state.
- counting: high only during COUNT state.
- done: high only during DONE state.
