Implement a finite state machine (FSM) with the following states:

- IDLE: Searching for the start pattern 1101 on serial input `data`. Use a 4-bit shift register to track the last 4 bits. When pattern detected, move to SHIFT state.
- SHIFT: Assert shift_ena for exactly 4 clock cycles to shift in 4 more bits (duration). After 4 cycles, move to COUNT state.
- COUNT: Assert counting output, wait for done_counting to go high, then move to DONE state.
- DONE: Assert done output, wait for ack to be high, then return to IDLE to look for next pattern.

Synchronous active-high reset sets state to IDLE and clears all outputs and counters.

The FSM is clocked on the rising edge of clk.

The 4-bit shift register for pattern detection shifts in `data` each clock cycle in IDLE state.

Outputs shift_ena, counting, and done are asserted only in their respective states.

The 4-cycle counter in SHIFT state counts how many shift cycles have passed.

All outputs and internal signals are registered synchronously.
