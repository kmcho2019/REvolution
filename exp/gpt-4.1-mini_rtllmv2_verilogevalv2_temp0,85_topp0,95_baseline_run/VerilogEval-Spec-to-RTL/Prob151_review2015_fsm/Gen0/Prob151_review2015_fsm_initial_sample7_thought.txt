Implement an FSM with the following states:
- IDLE: waiting to detect the pattern 1101 on the serial data input.
- SHIFT: after detecting 1101, shift_ena is asserted for exactly 4 clock cycles to shift in the next 4 bits.
- COUNTING: asserting counting output, waiting for done_counting input to be high.
- DONE: asserting done output, waiting for ack input to be high before returning to IDLE.

To detect the pattern 1101, use a 4-bit shift register to track the last 4 bits of data input. On each clock, shift in data and check if it matches 1101.

Use synchronous reset to reset the state and shift register. All outputs are asserted only in their respective states.

The outputs shift_ena, counting, done are all one-hot signals active in the corresponding states.
