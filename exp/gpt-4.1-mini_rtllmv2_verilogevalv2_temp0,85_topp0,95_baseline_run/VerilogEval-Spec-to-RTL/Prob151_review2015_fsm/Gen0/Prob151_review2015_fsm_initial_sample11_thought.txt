Implement a synchronous FSM with states: IDLE (searching for pattern), SHIFT (shifting in 4 bits), COUNT (waiting for counting done), DONE (waiting for ack). Use a 4-bit shift register to detect pattern 1101 on the data input while in IDLE. Once detected, move to SHIFT state and assert shift_ena for 4 clocks while counting bits shifted in. Then move to COUNT state asserting counting output until done_counting is high. Then move to DONE state asserting done output until ack is high, then return to IDLE. Use synchronous reset to reset state and shift register.
