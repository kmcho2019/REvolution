Implement a finite state machine with the following states: 
- IDLE: Searching for the start sequence 1101 by shifting in the last 4 bits of data.
- SHIFT: After detecting 1101, assert shift_ena for exactly 4 clock cycles to shift in the timer duration bits.
- COUNT: Assert counting and wait for done_counting to go high.
- DONE: Assert done and wait for ack to go high, then return to IDLE.

Use a 4-bit shift register to detect the sequence 1101 in the IDLE state. All outputs are combinational based on state. The synchronous reset sets the FSM back to IDLE.
