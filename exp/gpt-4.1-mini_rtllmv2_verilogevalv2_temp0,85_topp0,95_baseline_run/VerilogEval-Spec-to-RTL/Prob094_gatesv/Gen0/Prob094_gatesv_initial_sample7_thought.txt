Implement the TopModule with a 4-bit input vector. 
- For out_both, each bit i (0 to 2) indicates if in[i] and in[i+1] are both 1; out_both[3] is 0.
- For out_any, each bit i (1 to 3) indicates if in[i] or in[i-1] is 1; out_any[0] is 0.
- For out_different, each bit i (0 to 3) indicates if in[i] is different from in[(i+1)%4], implementing wrap-around.
