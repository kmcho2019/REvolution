Implement a module TopModule with 4-bit input and three 4-bit outputs. For each output:
- out_both[i] = in[i] & in[i+1] for i=0 to 2, and out_both[3] = 0 (no left neighbor for in[3]).
- out_any[i] = in[i] | in[i-1] for i=1 to 3, and out_any[0] = 0 (no right neighbor for in[0]).
- out_different[i] = in[i] ^ in[(i+1)%4], wrapping around so neighbor to left of in[3] is in[0].
Set unused bits to 0 where neighbor doesn't exist.
