Implement the TopModule with a 4-bit input and three 4-bit outputs. For out_both, each bit i (except the highest index) is 1 if both in[i] and in[i+1] are 1; out_both[3] is 0 since in[3] has no left neighbor. For out_any, each bit i (except the lowest index) is 1 if either in[i] or in[i-1] is 1; out_any[0] is 0 since in[0] has no right neighbor. For out_different, each bit i is 1 if in[i] differs from in[(i+1) mod 4], implementing a wrap-around neighbor to the left.
