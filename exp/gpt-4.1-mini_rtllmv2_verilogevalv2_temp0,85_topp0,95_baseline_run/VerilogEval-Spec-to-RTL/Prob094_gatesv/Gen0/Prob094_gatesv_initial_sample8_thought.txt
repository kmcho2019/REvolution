For out_both, for bits 0 to 2, each bit indicates if both the bit and its left neighbour (higher index) are 1; bit 3 is 0 since it has no left neighbour.

For out_any, for bits 1 to 3, each bit indicates if either the bit or its right neighbour (lower index) is 1; bit 0 is 0 since it has no right neighbour.

For out_different, each bit compares the bit with its left neighbour (wrapping around, so bit 3's left neighbour is bit 0) and outputs 1 if they differ.

We'll implement these using simple bitwise operations.
