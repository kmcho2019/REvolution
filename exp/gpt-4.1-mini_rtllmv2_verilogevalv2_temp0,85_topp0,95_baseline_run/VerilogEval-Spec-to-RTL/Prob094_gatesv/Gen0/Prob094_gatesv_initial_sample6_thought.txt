Implement the TopModule with a 4-bit input vector. For each bit of the output vectors:

- out_both[i] = in[i] & in[i+1] for i=0,1,2; out_both[3] = 0 since in[3] has no left neighbor.
- out_any[i] = in[i] | in[i-1] for i=1,2,3; out_any[0] = 0 since in[0] has no right neighbor.
- out_different[i] = in[i] ^ in[(i+1)%4] to wrap around for the left neighbor.

All outputs are 4 bits wide.
