Implement a module with a 4-bit input and three 4-bit outputs. For each output bit:
- out_both[i] = in[i] & in[i+1], for i = 0 to 2; out_both[3] = 0 as no left neighbor for in[3].
- out_any[i] = in[i] | in[i-1], for i = 1 to 3; out_any[0] = 0 as no right neighbor for in[0].
- out_different[i] = in[i] ^ in[(i+1) % 4], wrapping around so neighbor of in[3] is in[0].
