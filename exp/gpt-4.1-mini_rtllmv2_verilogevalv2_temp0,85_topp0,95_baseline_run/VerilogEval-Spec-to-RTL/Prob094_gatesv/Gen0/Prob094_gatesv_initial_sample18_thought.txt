Implement the TopModule with the specified interface. For out_both, each bit (except the highest index) is set if both the current bit and its left neighbor (higher index) are 1. For out_any, each bit (except the lowest index) is set if either the current bit or its right neighbor (lower index) is 1. For out_different, each bit is set if the current bit is different from its left neighbor (higher index), with wrapping around so the left neighbor of bit 3 is bit 0.
