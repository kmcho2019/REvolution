Implement the TopModule with 4-bit input and 4-bit outputs. For each output vector:
- out_both[i] = in[i] & in[i+1], for i = 0 to 2; out_both[3] = 0 since in[3] has no left neighbor.
- out_any[i] = in[i] | in[i-1], for i = 1 to 3; out_any[0] = 0 since in[0] has no right neighbor.
- out_different[i] = in[i] ^ in[(i+1) % 4], wrapping around, so that for i=3 neighbor is in[0].
