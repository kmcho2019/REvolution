From the waveform data, output q depends on input c (4 bits), selecting one of the inputs a,b,d,e, or a fixed value f (4'hF) based on the value of c:

- When c==0, q=b
- When c==1, q=e
- When c==2, q=a
- When c==3, q=d
- When c>=4, q=4'hF

This describes a multiplexer with c as the select signal.

Implement a combinational multiplexer that assigns q accordingly.
