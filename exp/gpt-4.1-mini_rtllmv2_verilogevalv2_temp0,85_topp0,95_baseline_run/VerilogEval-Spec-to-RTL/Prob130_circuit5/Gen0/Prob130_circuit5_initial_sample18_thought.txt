From the waveform, the output q depends only on input c for values 0 to 4, otherwise it is fixed to 4'hF.

Mapping observed:
c=0 -> q = b
c=1 -> q = e
c=2 -> q = a
c=3 -> q = d
c=4..15 -> q = 4'hF

The other inputs a, b, d, e are only used as selected outputs depending on c in 0..3 and 2, and c in 1 and 4. So implement a combinational multiplexer based on c.

For c values 0 to 4, q outputs a, b, d or e accordingly as above; for other c values, q outputs 4'hF.
