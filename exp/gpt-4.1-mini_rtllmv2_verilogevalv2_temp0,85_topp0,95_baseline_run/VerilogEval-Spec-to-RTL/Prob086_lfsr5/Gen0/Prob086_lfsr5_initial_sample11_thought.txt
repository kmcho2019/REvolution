Implement a 5-bit Galois LFSR with taps at bit positions 5 and 3. The LFSR shifts right each clock cycle. The feedback is applied by XORing the bit at position 3 with the output bit q[0], and this result is then used to conditionally toggle the tapped bits during the shift. On reset, the register is set to 1. The module outputs the 5-bit register value.
