Implement a 5-bit Galois LFSR that shifts right on each clock edge. The taps are at bit positions 5 and 3, which correspond to bits q[4] and q[2] in zero-based indexing. On each clock tick, if reset is high, set the register to 1. Otherwise, shift right by one bit. The new bit to be shifted in (the MSB) is computed by XORing the current LSB (q[0]) with the tap bits q[4] and q[2]. This ensures maximum-length sequence.
