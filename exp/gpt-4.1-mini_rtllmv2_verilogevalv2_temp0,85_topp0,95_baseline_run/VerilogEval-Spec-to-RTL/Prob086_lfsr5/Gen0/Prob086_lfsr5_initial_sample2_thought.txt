Implement a 5-bit Galois LFSR with taps at bit positions 5 and 3. The LFSR state is stored in a 5-bit register q. On each clock rising edge, if reset is high, the register is set to 1. Otherwise, the next state is computed as follows: the feedback bit is q[0] (LSB), and bits with taps (5 and 3, corresponding to q[4] and q[2]) are XORed with feedback bit to form their next value, while other bits shift right unchanged. Since we have taps at bit 5 (q[4]) and bit 3 (q[2]), their next value will be q[4] XOR feedback and q[2] XOR feedback respectively. The LFSR shifts right by 1 bit every cycle, with the new MSB set to feedback. This implementation ensures a maximal-length 5-bit Galois LFSR.
