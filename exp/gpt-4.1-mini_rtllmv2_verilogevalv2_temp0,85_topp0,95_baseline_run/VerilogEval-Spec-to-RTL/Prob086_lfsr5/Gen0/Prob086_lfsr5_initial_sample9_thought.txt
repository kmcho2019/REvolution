Implement a 5-bit Galois LFSR shifting right on each positive clock edge. The taps at bit positions 5 and 3 (1-based indexing) correspond to q[4] and q[2] in zero-based indexing. On each clock cycle, if reset is high, set q to 5'b00001. Otherwise, shift right and XOR the tapped bits with the outgoing LSB to produce the new MSB. The output q should be registered and updated synchronously.
