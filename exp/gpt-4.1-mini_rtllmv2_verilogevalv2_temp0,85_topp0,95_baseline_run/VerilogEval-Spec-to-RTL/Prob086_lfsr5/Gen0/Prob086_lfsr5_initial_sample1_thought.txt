Implement a 5-bit Galois LFSR with taps at bit positions 5 and 3 using a right shift. The next state is generated by XORing the LSB output bit with the tap bits to update the corresponding bits. On each positive clock edge, if reset is high, set the output to 1 (00001). Otherwise, shift right by one bit, and for bits with taps (bit 4 and bit 2 in zero-based indexing), XOR their current value with the LSB of the current register before shifting. This configuration ensures maximum length cycle (2^5 - 1 states).
