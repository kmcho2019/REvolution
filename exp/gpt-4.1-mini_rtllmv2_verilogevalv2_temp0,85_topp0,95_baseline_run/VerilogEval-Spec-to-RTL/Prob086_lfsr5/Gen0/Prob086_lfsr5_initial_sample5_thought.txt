Implement a 5-bit Galois LFSR that shifts right on each clock edge. The taps are at bit positions 5 and 3, which correspond to q[4] and q[2] in zero-based indexing. On each clock, if reset is asserted, set q to 5'b00001. Otherwise, update q as follows: the new bit entering at q[4] is q[0] XOR q[4] XOR q[2], and the other bits shift right, with tapped bits XORed with q[0]. Since it's a Galois LFSR, only the tapped bits are XORed with the output bit q[0], and the rest just shift right. The LSB q[0] shifts out. Implement this logic inside a synchronous always block.
