Implement the combinational logic for the next state and output of a Moore machine with one-hot encoding of four states (A, B, C, D). Use the given transition table and output values. The inputs are the current state (4 bits) and input bit 'in', and outputs are next_state (4 bits) and out (1 bit). The logic is derived by inspecting each state's transitions and output. Since the state is one-hot encoded, next_state bits can be derived by OR'ing conditions for each next state.
