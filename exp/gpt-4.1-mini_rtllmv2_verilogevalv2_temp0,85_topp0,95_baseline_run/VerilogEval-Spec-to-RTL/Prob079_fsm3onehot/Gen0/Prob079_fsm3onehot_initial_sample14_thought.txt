Implement a combinational logic module that takes the current one-hot encoded 4-bit state and a 1-bit input, and produces the next state and output based on the given state transition table. The next_state is also one-hot encoded. For each current state (A, B, C, D), define next state for input=0 and input=1 as specified. The output is 1 only when in state D, otherwise 0.
