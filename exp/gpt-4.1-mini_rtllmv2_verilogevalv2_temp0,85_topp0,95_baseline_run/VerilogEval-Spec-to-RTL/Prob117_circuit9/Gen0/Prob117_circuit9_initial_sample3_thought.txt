From the waveforms, on every rising edge of clk:
- When input 'a' is 1, output q remains constant at 4.
- When input 'a' is 0, q increments by 1 on each rising edge of clk, wrapping from 7 to 0.

The initial value of q is unknown (x) but it sets to 4 on the first rising clk with a=1. So:
- If a=1 at rising edge, q is set to 4.
- If a=0 at rising edge, q increments by 1 modulo 8.

Implement this logic with a 3-bit register q, updated on the rising edge of clk.
