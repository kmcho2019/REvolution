Implement a 64-bit Johnson counter where on each clock rising edge (or reset falling edge) the counter updates its 64-bit register Q. On reset (active low), Q is set to 0. Otherwise, if Q[0] == 0, Q shifts right by one bit with a new '1' inserted at the MSB; if Q[0] == 1, Q shifts right by one bit with a new '0' at the MSB. This implements the torsional ring counter behavior as described.
