Implement a 64-bit Johnson counter that updates on the rising edge of clk or falling edge of rst_n.
- On reset (rst_n == 0), set Q to 0.
- Otherwise, check Q[0]:
  - If Q[0] == 0, shift Q right by 1 and set MSB to 1.
  - If Q[0] == 1, shift Q right by 1 and set MSB to 0.
This matches the Johnson counter behavior described.
