Implement a 64-bit Johnson counter (torsional ring counter) that on every rising clock edge or falling reset edge updates its state. When reset is active (rst_n low), set Q to zero. Otherwise, check the LSB of Q: if 0, shift right and insert 1 at MSB; if 1, shift right and insert 0 at MSB. This matches the Johnson counter behavior described and generalizes the 4-bit example to 64 bits.
