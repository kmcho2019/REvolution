Implement a 4-bit comparator by performing a 4-bit subtraction A - B using combinational logic. The subtraction can be done bit-by-bit using full subtractors to produce the difference bits and borrow bits. The final borrow out indicates if A < B. If no borrow out and the difference is non-zero, then A > B. If difference is zero and no borrow, A == B. Outputs are mutually exclusive.
