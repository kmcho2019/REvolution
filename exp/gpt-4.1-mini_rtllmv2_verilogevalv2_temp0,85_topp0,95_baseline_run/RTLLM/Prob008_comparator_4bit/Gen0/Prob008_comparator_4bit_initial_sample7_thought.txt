Implement a 4-bit comparator by performing a 4-bit subtraction A - B using combinational logic. The subtraction will be implemented using full subtractors cascaded for each bit to generate the difference bits and borrow bits. The borrow out from the MSB subtractor indicates if A < B (borrow out = 1 means A < B). If borrow out = 0 and the difference bits are all zero, then A = B. If borrow out = 0 and the difference is non-zero, then A > B. Outputs A_greater, A_equal, and A_less are mutually exclusive and reflect the comparison result.
