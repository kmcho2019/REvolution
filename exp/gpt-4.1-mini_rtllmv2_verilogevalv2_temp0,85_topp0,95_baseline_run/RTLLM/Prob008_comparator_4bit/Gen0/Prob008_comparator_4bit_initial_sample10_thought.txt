Implement a 4-bit comparator using combinational logic by performing a subtraction (A - B) and analyzing the borrow and result to determine the relationship between A and B. Use a 4-bit subtractor built with bit-level subtractors generating borrows between bits. The borrow out of the MSB indicates if A < B. If no borrow out and result is zero, then A == B; if no borrow out and result is non-zero, then A > B. Ensure outputs are mutually exclusive.
