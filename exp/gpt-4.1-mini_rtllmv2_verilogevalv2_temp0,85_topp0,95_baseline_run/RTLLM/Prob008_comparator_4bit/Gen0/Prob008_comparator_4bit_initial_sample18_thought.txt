To implement the 4-bit comparator using combinational logic, I will perform a subtraction A - B and observe the borrow (carry out) and the result of the subtraction. The borrow indicates if A < B. If no borrow and the subtraction result is non-zero, then A > B. If the result is zero, A == B. I will use a 4-bit subtractor with borrow out to detect borrow, then assign outputs accordingly, ensuring mutual exclusivity.
