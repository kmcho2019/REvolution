To implement the 4-bit comparator using combinational logic, I will perform a subtraction A - B and use the borrow and result to determine the outputs. The subtraction will be done bit-by-bit with borrow propagation. If a borrow occurs in the final subtraction, it means A < B. If no borrow and the result is zero, A == B. If no borrow and the result is non-zero, A > B. The outputs are mutually exclusive and combinational.
