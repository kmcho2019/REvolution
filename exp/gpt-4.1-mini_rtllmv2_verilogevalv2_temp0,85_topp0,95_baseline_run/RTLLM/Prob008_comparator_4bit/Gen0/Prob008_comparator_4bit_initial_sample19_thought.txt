Implement a 4-bit comparator by performing a subtraction A - B using bitwise full subtractors. 
Track borrow out from each bit subtraction. If the final borrow out is 1, A < B; if borrow out is 0 and result is zero, A == B; if borrow out is 0 and result non-zero, A > B.
Use combinational logic to build bit-level subtractors and generate final flags accordingly.
