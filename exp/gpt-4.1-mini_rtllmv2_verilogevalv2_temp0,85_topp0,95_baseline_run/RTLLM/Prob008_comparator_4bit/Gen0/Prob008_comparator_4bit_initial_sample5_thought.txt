Implement a 4-bit comparator using a subtractor to find A - B. The subtraction will be done using a 4-bit subtractor with borrow look-ahead using bit-level subtractors. If there is a borrow out at the end, it means A < B. If no borrow and the result is zero, then A == B. Otherwise, A > B. The outputs are mutually exclusive combinational signals derived from the subtraction result and borrow-out.
