Implement the 4-bit comparator by performing a combinational subtraction A - B. Use a 4-bit subtractor with borrow propagation to detect if a borrow occurs at the end. If borrow (final carry out) is 1, A is less than B. If no borrow and result is zero, A equals B. If no borrow and result is non-zero, A is greater than B. Outputs are mutually exclusive.
