To implement the 4-bit comparator using multiple bit-level comparators in combinational logic, perform a 4-bit subtraction A - B and monitor the borrow chain. Each bit subtraction is done with a full subtractor logic using A[i], B[i], and borrow_in, producing difference bit and borrow_out. The final borrow_out indicates if A < B (borrow_out=1 means A < B). If no borrow occurs and the difference bits are all zero, then A = B; else A > B. The three outputs are mutually exclusive by construction.
