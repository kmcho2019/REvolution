Implement a 4-bit comparator using combinational logic by performing a 4-bit subtraction of B from A. The subtraction operation will produce a result and a borrow out. If borrow out is 1, it means A < B; if borrow out is 0 and the result is zero, it means A == B; if borrow out is 0 and the result is non-zero, it means A > B. This logic ensures mutually exclusive outputs. We'll implement a 4-bit subtractor using full subtractors bitwise, tracking borrows between bits.
