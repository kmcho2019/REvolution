Implement a 4-entry 4-bit wide LIFO stack with a stack pointer starting at 4 (empty). On reset, clear all stack entries and set SP=4. On each clock when enabled, if RW=0 and not full, push dataIn onto stack_mem[SP-1], decrement SP. If RW=1 and not empty, pop data from stack_mem[SP], output to dataOut, clear that entry, increment SP. Update EMPTY when SP==4, FULL when SP==0. dataOut holds the popped value or zero if no pop.
