Implement a 4-entry, 4-bit wide LIFO buffer using a stack memory array and a stack pointer (SP) initialized to 4 to represent empty. On reset, clear the stack memory and set SP to 4. On each clock edge when EN is high, perform push if RW=0 and not full, decrement SP; perform pop if RW=1 and not empty, output data and increment SP. Update FULL and EMPTY flags according to SP value.
