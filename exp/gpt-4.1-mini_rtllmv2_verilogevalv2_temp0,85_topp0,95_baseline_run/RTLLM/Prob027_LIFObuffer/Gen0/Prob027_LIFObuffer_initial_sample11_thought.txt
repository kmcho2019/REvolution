Implement a synchronous LIFO buffer of depth 4 and width 4 bits. Use a 4-entry register array as the stack memory and a 3-bit stack pointer (SP) to track the current top of the stack. SP initialized to 4 means empty. On reset, clear memory and set SP to 4. On enable and clock edge, if RW=0 (write) and not full, decrement SP and write dataIn to stack_mem[SP-1]. If RW=1 (read) and not empty, output dataOut from stack_mem[SP], clear that memory, and increment SP. Update FULL and EMPTY flags according to SP value (FULL when SP==0, EMPTY when SP==4).
