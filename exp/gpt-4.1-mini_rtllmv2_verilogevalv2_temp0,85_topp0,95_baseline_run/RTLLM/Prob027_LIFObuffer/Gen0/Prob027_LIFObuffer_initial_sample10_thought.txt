Implement a 4-entry, 4-bit wide LIFO stack with a stack pointer (SP) initialized to 4 (empty). On reset, clear memory and set SP to 4. On each clock edge with EN high and Rst low, perform push if RW=0 and not full (decrement SP, write dataIn), or pop if RW=1 and not empty (read from stack_mem[SP], clear it, increment SP). Update FULL when SP==0 and EMPTY when SP==4.
