Implement a 4-entry 4-bit wide stack with a stack pointer initialized to 4 (empty). On reset, clear stack and set pointer to 4. On clock edge with enable, if RW=0 (write) and not full, decrement pointer and write dataIn. If RW=1 (read) and not empty, output dataOut from current pointer, clear that entry, and increment pointer. Update FULL when pointer is 0, EMPTY when pointer is 4.
