Implement a synchronous LIFO buffer with a 4-entry stack memory and a 4-bit data width. Use a stack pointer (SP) initialized to 4 to indicate empty. On reset, clear the stack and set SP to 4. On enable, if RW=0 (write) and not full, decrement SP and write dataIn into stack_mem[SP-1]. If RW=1 (read) and not empty, read from stack_mem[SP], output to dataOut, clear that location, and increment SP. Update FULL (SP == 0) and EMPTY (SP == 4) flags accordingly.
