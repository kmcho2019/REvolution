Implement a synchronous LIFO buffer with a 4-entry stack using a stack pointer (SP) that starts at 4 indicating empty. On reset, clear the stack and set SP to 4. On each clock cycle with EN high: if RW=0 (write) and not full, decrement SP and write dataIn to stack_mem[SP-1]. If RW=1 (read) and not empty, output data from stack_mem[SP], clear that location, and increment SP. Update FULL and EMPTY flags based on SP value (FULL when SP=0, EMPTY when SP=4).
