Implement a 4-entry 4-bit wide LIFO stack with a 2-bit stack pointer initialized to 4 (empty). On reset, clear all memory and set pointer to 4. On clock rising edge when enabled, if RW=0 and not full, decrement pointer and write dataIn to stack_mem. If RW=1 and not empty, read dataOut from stack_mem at pointer, clear that location, and increment pointer. Update EMPTY and FULL flags based on the pointer value.
