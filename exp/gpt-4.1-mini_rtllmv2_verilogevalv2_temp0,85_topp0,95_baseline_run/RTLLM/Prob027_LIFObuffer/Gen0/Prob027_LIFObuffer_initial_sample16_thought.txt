Implement a 4-entry stack memory with a 4-bit wide data storage. Use a stack pointer (SP) initialized to 4 to indicate an empty stack. On reset, clear the stack and set SP to 4. On each clock edge when enabled, perform push if RW=0 and not full (decrement SP, write data), or pop if RW=1 and not empty (read data, clear memory, increment SP). Update EMPTY (SP==4) and FULL (SP==0) flags accordingly.
