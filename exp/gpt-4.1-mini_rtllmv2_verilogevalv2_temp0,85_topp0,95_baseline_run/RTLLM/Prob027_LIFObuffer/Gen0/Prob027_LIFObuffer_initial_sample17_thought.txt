Implement a synchronous LIFO buffer with a 4-entry stack memory and a stack pointer (SP) that counts from 4 (empty) down to 0 (full). On reset, SP is set to 4 and memory cleared. On write (RW=0) and EN=1, if not full, push dataIn onto the stack by decrementing SP and storing dataIn at stack_mem[SP-1]. On read (RW=1) and EN=1, if not empty, pop data from stack_mem[SP] into dataOut, clear that entry, and increment SP. Update EMPTY flag when SP == 4 and FULL flag when SP == 0.
