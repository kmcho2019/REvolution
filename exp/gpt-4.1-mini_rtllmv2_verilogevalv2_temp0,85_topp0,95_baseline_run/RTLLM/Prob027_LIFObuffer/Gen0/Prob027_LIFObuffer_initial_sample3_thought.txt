Implement a 4-entry stack memory array of 4-bit width with a 3-bit stack pointer initialized to 4 (empty). On reset, clear stack and set SP to 4. On each clock rising edge when enabled, if RW=0 and not full, push dataIn by decrementing SP and storing data. If RW=1 and not empty, pop data from stack_mem[SP] into dataOut, clear that entry, and increment SP. Update FULL when SP=0, EMPTY when SP=4.
