   - On a push (write), the code decrements SP first (`SP <= SP - 1'b1;`), then attempts to write to `stack_mem[SP - 1]`. This is problematic because `SP` is updated non-blocking and its old value is still used in the same clock cycle for the write. The index `SP - 1` uses the old SP value minus one, which will cause an off-by-one or incorrect memory indexing.
