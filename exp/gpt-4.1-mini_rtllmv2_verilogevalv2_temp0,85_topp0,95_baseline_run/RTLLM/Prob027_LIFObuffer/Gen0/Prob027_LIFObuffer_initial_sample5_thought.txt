Implement a synchronous LIFO buffer with a 4-entry stack memory and a stack pointer starting at 4 (empty). On reset, clear memory and set SP to 4. On each clock with EN high, if RW=0 and not full, push dataIn by decrementing SP and storing data. If RW=1 and not empty, pop data by outputting dataOut from current SP and incrementing SP. Update FULL (SP == 0) and EMPTY (SP == 4) flags accordingly.
