Implement a synchronous LIFO buffer with a 4-entry deep stack_mem array, each 4 bits wide. Use a 3-bit stack pointer SP initialized to 4 (empty). On reset, clear stack_mem and set SP to 4. On each clock rising edge when EN is high: if RW=0 (write) and buffer not full, decrement SP and store dataIn; if RW=1 (read) and buffer not empty, output the data at SP and increment SP after clearing the popped location. Update FULL (SP==0) and EMPTY (SP==4) flags accordingly.
