Implement a 4-entry 4-bit-wide stack memory with a stack pointer (SP) initialized to 4 (empty). On reset, clear the stack and set SP=4. On each clock when enabled:
- If RW=0 (write) and not full, decrement SP and write dataIn to stack_mem[SP-1].
- If RW=1 (read) and not empty, read data from stack_mem[SP], output it to dataOut, clear that memory, and increment SP.
Update EMPTY when SP == 4 and FULL when SP == 0.
