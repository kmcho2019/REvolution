Implement a 4-depth stack with 4-bit wide entries using a stack pointer (SP) that starts at 4 (empty). On reset, clear the stack and set SP to 4. On write (RW=0) if not full, decrement SP and store dataIn at stack_mem[SP-1]. On read (RW=1) if not empty, output stack_mem[SP], clear that location, and increment SP. Update EMPTY when SP==4 and FULL when SP==0. Use synchronous logic on rising clock edge with enable.
