Implement a 4-entry stack buffer with 4-bit width. Use a 2-bit stack pointer (SP) initialized to 4 on reset to indicate an empty stack. On write (RW=0), if not full, decrement SP and write dataIn to stack_mem[SP-1]. On read (RW=1), if not empty, read dataOut from stack_mem[SP], clear that location, and increment SP. Update EMPTY (SP==4) and FULL (SP==0) flags accordingly. Use synchronous logic triggered on the rising edge of Clk and gated by EN.
