To implement the fixed-point subtractor, we must consider the sign bits and the magnitude of the operands to handle same-sign and different-sign cases correctly. Both inputs are in two's complement fixed-point format with N bits total and Q fractional bits.

- Extract sign bits from MSB of a and b.
- For same sign inputs, subtract magnitudes (a - b). Result sign is the same as inputs.
- For different sign inputs, add magnitudes (|a| + |b|). The result sign depends on which magnitude is greater.
- Use two's complement arithmetic for subtraction and addition.
- Handle zero result by explicitly setting sign bit to zero.
- Store the result in internal register res and assign it to output c.
- The module parameters Q and N define the fixed-point format.

The implementation uses unsigned arithmetic on magnitudes and applies sign logic manually to ensure correct fixed-point signed subtraction behavior.
