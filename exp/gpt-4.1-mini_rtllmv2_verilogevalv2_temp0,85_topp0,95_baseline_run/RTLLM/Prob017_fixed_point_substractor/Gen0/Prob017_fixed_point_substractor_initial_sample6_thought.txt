Implement a parameterized fixed-point subtractor module with inputs a and b, each N bits wide and Q fractional bits. The subtraction depends on the sign bits of a and b:
- If they have the same sign, subtract their absolute values and keep the input sign.
- If different signs, add their absolute values, and determine the result sign by comparing magnitudes.
We handle zero result by setting sign bit to 0 explicitly.
Intermediate calculations use extended width to avoid overflow. The final result is assigned to a register res and output c.
