Implement a fixed-point subtractor module parameterized by total bit width N and fractional bits Q. The inputs and output are N-bit signed fixed-point numbers. The subtraction considers the sign bits and applies logic:

- When signs are the same, perform straightforward subtraction.
- When signs differ, perform addition of absolute values and set the sign based on comparison.
- Handle zero result by explicitly setting sign bit to 0.
Use a register to store the result before output. All operations are done treating inputs as signed fixed-point numbers.
