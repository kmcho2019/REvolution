Implement a fixed-point subtractor that takes two signed fixed-point inputs a and b, each N bits wide with Q fractional bits. The module handles subtraction according to the sign of inputs:

- If both have the same sign, simply subtract their absolute values and keep the same sign.
- If signs differ, perform addition of absolute values and assign the sign based on which operand has the greater magnitude.
- Use signed arithmetic to simplify operations.
- Explicitly set the sign bit to 0 if the result is zero to handle zero sign edge case.
- Use internal register to store the result before assigning it to output.

This ensures precise subtraction with fixed-point format, keeping fractional bits intact.
