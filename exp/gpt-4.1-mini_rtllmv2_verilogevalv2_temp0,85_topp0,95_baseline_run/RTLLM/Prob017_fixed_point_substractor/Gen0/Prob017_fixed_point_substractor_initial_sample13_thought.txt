The fixed_point_subtractor module performs subtraction of two fixed-point numbers a and b with N bits total and Q fractional bits. The numbers use two's complement representation, so the MSB is the sign bit. The subtraction is implemented by analyzing the signs of a and b. If they have the same sign, subtraction is straightforward: c = a - b. If their signs differ, the operation corresponds to an addition of absolute values with sign determined by which operand has larger magnitude. To determine magnitude and perform sign adjustments, absolute values are computed for the operands when needed. After computation, if the result is zero, the sign bit is explicitly cleared to zero. The result is stored in an internal register before being assigned to output. This method ensures correct sign handling and precision in fixed-point arithmetic.
