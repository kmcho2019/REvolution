Implement a fixed-point subtractor module parameterized by Q and N. Inputs and output are N-bit fixed-point numbers with Q fractional bits. The subtraction depends on the sign bits and magnitudes:

- Extract sign bits of a and b.
- If signs are the same, subtract the magnitudes directly, result sign is the same as inputs.
- If signs differ, add the magnitudes. The sign of the result depends on which input has the greater magnitude.
- Use a register 'res' to hold the result.
- Handle zero result explicitly by setting sign bit to 0.
- Output c is assigned from res.

This approach treats inputs as signed fixed-point numbers in two's complement form, so magnitudes are absolute values. The subtraction/addition is done on magnitudes, and sign is assigned accordingly.
