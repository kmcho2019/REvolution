Implement a 32-bit ALU module for MIPS ISA with inputs a, b, and a 6-bit control signal aluc. The module computes the result r based on the opcode aluc by using a case statement inside an always block. The operations include arithmetic (ADD, SUB, ADDU, SUBU), bitwise logical (AND, OR, XOR, NOR), set-less-than signed/unsigned (SLT, SLTU), shifts (SLL, SRL, SRA, SLLV, SRLV, SRAV), and LUI. The outputs zero, carry, negative, overflow, and flag are set accordingly: zero checks if the result is zero; carry is set from addition/subtraction carry-out; negative from sign bit of result; overflow detects signed overflow for add/sub; flag outputs 1 for SLT and SLTU result conditions, else 'z'. Default result is high impedance 'z' if opcode is unrecognized. Proper signed and unsigned conversions are handled for arithmetic and set operations.
