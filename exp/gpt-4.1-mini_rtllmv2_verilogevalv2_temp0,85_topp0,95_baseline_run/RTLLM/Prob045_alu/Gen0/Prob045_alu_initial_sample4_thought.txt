Implement a combinational ALU module for 32-bit MIPS instructions with a 6-bit opcode input. The module supports arithmetic (ADD, SUB, ADDU, SUBU), logical (AND, OR, XOR, NOR), shift (SLL, SRL, SRA, SLLV, SRLV, SRAV), comparison (SLT, SLTU), and LUI operations. For arithmetic instructions, detect carry and overflow. For SLT and SLTU, output a flag bit. Compute zero and negative flags from the result. Use a case statement on the opcode to select operation. Use signed arithmetic for overflow detection and signed comparisons. For operations not listed, output high impedance (z).
