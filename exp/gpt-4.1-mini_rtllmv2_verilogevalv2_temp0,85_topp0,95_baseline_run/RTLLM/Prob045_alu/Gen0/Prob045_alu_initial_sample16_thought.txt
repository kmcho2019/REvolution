Implement an ALU module with parameters for operation opcodes. Inputs are two 32-bit operands and a 6-bit aluc control. The outputs include a 32-bit result and status flags (zero, carry, negative, overflow, flag). Use a combinational always block with a case statement on aluc to perform the specified operations. For add/sub, handle carry and overflow detection carefully. For shifts, use the appropriate shift amounts. For SLT and SLTU, set the flag output accordingly. Zero flag is set if the result is zero, negative flag is set by the MSB of the result. Carry is set for addition/subtraction when applicable. Overflow is detected for signed add/sub. If opcode is unknown, result is high impedance. Flag output is set to 'z' except for SLT and SLTU operations.
