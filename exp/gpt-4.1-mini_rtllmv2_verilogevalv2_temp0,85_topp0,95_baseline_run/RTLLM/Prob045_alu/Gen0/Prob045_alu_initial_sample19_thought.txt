Implement a parameterized ALU module supporting MIPS-ISA operations based on aluc opcodes. Use a 33-bit register for arithmetic operations to capture carry out. Handle signed overflow detection for ADD and SUB operations. For SLT and SLTU, set the flag output accordingly; flag is high-impedance for other ops. For shift instructions, use either immediate shift amount from a[4:0] or variable shift amount from b[4:0] as specified. LUI loads upper 16 bits of b shifted left by 16. Outputs zero, carry, negative, and overflow are set based on the result of the operation. When opcode is undefined, outputs and result are high-impedance.
