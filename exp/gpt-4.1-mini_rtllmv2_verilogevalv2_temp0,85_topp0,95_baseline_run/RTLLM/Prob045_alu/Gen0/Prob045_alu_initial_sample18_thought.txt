Implement an ALU module with parameters defining the opcode. It takes two 32-bit inputs and a 6-bit opcode, outputs a 32-bit result and flags: zero, carry, negative, overflow, and flag for SLT/SLTU. Signed arithmetic and bitwise operations are performed in an always_comb block using a case statement. Carry and overflow flags are calculated for arithmetic operations. The flag output is set only for SLT and SLTU and high-impedance otherwise. The zero flag is set when the result is zero. Shift operations use the appropriate bits of 'a' as the shift amount. If opcode is unrecognized, output is high-impedance.
