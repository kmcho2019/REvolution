Implement an ALU module with parameters for each operation code. Use an always @(*) block to perform the operation selected by aluc. For arithmetic operations, handle signed addition and subtraction, including detecting carry and overflow. For logical operations, just perform bitwise operations. For shift operations, use appropriate shift operators with shift amounts taken from a[4:0] or b[4:0] depending on the instruction. The flag output is set only for SLT and SLTU instructions according to comparison results. The zero output is set if the result is zero; negative indicates if the result is negative (MSB=1). The carry bit is set for addition and subtraction operations where carry out or borrow occurs. Overflow is detected for signed addition and subtraction. For undefined aluc, output high impedance 'z'.
