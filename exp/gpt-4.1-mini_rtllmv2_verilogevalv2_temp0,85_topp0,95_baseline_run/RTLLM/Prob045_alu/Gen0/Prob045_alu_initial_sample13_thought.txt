Implement a combinational ALU module with parameters defining each opcode. Inputs are 32-bit operands a and b, and a 6-bit aluc for operation selection. Outputs include the 32-bit result r, and flags zero, carry, negative, overflow, and a general flag for SLT and SLTU. Use signed and unsigned casts as needed. Compute the result using a case statement on aluc. For arithmetic operations, detect carry and overflow properly. For logical and shift operations, perform the shifts using appropriate bits of a or a[4:0]. The zero flag is set when the result is zero. The negative flag is the sign bit of the result. The overflow flag is set for signed addition and subtraction overflow. The carry flag is set for unsigned addition and subtraction carry/borrow. The flag output is 1 for SLT and SLTU results and high impedance ('z') otherwise.
