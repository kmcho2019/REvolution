Implement a combinational ALU with operations selected by the 6-bit opcode aluc.
Use signed versions of inputs where necessary for signed arithmetic and comparisons.
Perform addition and subtraction with carry and overflow detection.
For shifts, use the appropriate shift amount from a or a[4:0].
Set the output flags zero, carry, negative, overflow, and flag according to the operation result.
For SLT and SLTU, set flag to 1 if condition is true, else 0; for other operations, flag is high-impedance.
If aluc is not recognized, assign 'z to output.
