Implement an ALU module supporting 32-bit MIPS operations with a 6-bit aluc opcode controlling the operation. The module performs arithmetic, logical, shift, and set operations. The operands are inputs a and b, the output r is the result. Flags zero, carry, negative, overflow, and flag (for SLT and SLTU) are derived accordingly. Shift amounts for variable shifts come from a[4:0]. For arithmetic operations, detect carry and overflow properly. For SLT and SLTU, set the flag output to 1 or 'z' otherwise. Use a case statement for operation selection, and assign 'z' when opcode does not match any. The output zero is asserted when r is zero. The negative flag checks r[31]. Carry is asserted only for addition/subtraction when carry or borrow occurs. Overflow is detected for signed addition and subtraction.
