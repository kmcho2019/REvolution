Implement a 64-bit ripple carry adder with pipeline registers to split the addition into multiple stages. Each stage will compute a portion of the addition and pass the carry and partial sums to the next stage on the next clock cycle. This will result in a pipelined adder where the output becomes valid after the last stage delay. Also, pipeline registers will be used for the inputs and the enable signal to synchronize and align data through the stages. The output enable will be asserted only when the final pipeline stage has valid data.
