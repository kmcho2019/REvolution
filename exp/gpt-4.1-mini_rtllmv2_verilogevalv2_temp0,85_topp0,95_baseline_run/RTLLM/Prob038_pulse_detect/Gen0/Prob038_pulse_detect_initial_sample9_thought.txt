Use a simple finite state machine with three states to detect the pulse pattern 0->1->0. 
Start in IDLE (waiting for data_in=0). When data_in=0, move to WAIT_FOR_HIGH.
In WAIT_FOR_HIGH, when data_in=1, move to WAIT_FOR_LOW.
In WAIT_FOR_LOW, when data_in=0, output pulse (data_out=1) and return to IDLE.
For any unexpected input, go back to IDLE.
On reset, return to IDLE and clear data_out.
Generate data_out=1 only at the last cycle of the pulse detection (when the pattern completes).
