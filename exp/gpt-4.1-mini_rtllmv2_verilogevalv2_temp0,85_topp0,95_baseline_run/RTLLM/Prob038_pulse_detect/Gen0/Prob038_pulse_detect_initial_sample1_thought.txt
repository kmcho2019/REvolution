Use a simple finite state machine (FSM) with states to detect the pattern 0->1->0 on data_in. The FSM states can be IDLE (waiting for 0), S1 (saw first 0, waiting for 1), S2 (saw 0 then 1, waiting for 0 to complete the pulse). When the last 0 is detected in S2, output data_out=1 for one cycle to indicate the pulse detection, then return to IDLE or appropriate state. Reset brings FSM to IDLE and data_out=0.
