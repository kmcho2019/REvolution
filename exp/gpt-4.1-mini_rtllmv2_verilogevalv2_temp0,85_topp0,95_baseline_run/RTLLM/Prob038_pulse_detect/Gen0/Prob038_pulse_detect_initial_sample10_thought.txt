Use a finite state machine (FSM) with states to detect the pattern 0->1->0 over 3 clock cycles.
- State IDLE: waiting for data_in=0 (initial state)
- State S0: data_in=0 detected, waiting for data_in=1
- State S1: data_in=1 detected after 0, waiting for data_in=0 to complete pulse
- When data_in returns to 0 at S1, output data_out=1 for one cycle indicating pulse end, then go back to S0 or IDLE depending on data_in
Reset initializes to IDLE with data_out=0.
