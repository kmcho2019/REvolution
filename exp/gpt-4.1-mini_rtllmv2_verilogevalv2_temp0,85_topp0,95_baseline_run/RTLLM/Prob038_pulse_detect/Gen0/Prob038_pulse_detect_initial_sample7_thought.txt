Use a finite state machine (FSM) to detect the pattern 0 -> 1 -> 0 on data_in over three clock cycles.
States:
  IDLE: waiting for data_in to be 0 (initial state).
  S1: detected first 0, waiting for 1.
  S2: detected 0->1, waiting for 0 to complete pulse.
Transition:
  IDLE: if data_in==0 -> S1; else stay IDLE.
  S1: if data_in==1 -> S2; else if data_in==0 stay S1; else back to IDLE.
  S2: if data_in==0 -> pulse detected, output data_out=1, go back to S1 to detect next pulse; else if data_in==1 stay S2; else IDLE.
On reset, go to IDLE and clear data_out.
data_out is asserted only for one cycle when the pulse is detected at the end of the 0->1->0 pattern.
