Implement a finite state machine (FSM) with four states to detect the pulse pattern 0 -> 1 -> 0 over three clock cycles. The FSM starts in an IDLE state waiting for data_in=0, then moves to a state waiting for data_in=1, then moves to a state waiting for data_in=0 (the last cycle of the pulse). When this last 0 is detected, data_out is asserted for one cycle. The FSM then returns to IDLE to detect subsequent pulses. On reset, state and data_out are cleared.
