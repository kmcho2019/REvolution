Implement a finite state machine with four states representing the expected sequence of data_in values for a pulse (0->1->0). The states are: IDLE (waiting for data_in=0), RISE (waiting for data_in=1), FALL (waiting for data_in=0), and PULSE_END (where data_out=1). At the end of the pulse (after seeing 0 again), output data_out=1 for one clock cycle, then return to IDLE to detect the next pulse. The output data_out is set only in the PULSE_END state, else 0.
