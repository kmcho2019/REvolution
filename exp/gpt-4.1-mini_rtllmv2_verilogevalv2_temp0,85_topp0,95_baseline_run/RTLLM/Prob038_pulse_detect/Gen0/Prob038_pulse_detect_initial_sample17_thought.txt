Use a finite state machine (FSM) with four states to detect the pulse pattern "0 -> 1 -> 0". The states represent: IDLE (waiting for 0), RISING (detected 0, waiting for 1), HIGH (detected 1, waiting for 0), and PULSE_END (pulse detected). On each clock edge, update the state based on data_in transitions. When the pulse pattern completes, assert data_out for one clock cycle, then return to IDLE. Reset initializes the FSM and output.
