Implement a finite state machine (FSM) with four states to detect the pulse pattern 0->1->0 over three clock cycles. The states will be: IDLE (waiting for data_in=0), RISE (data_in changed to 1), FALL (data_in back to 0 indicating pulse end), and possibly an ERROR or WAIT state to handle unexpected inputs. When the FSM reaches the FALL state, output data_out=1 for one clock cycle, then return to IDLE. The FSM resets on rst_n=0.
