Implement a traffic light controller with three states: red, yellow, and green. Use an internal counter to time each state (red = 10, yellow = 5, green = 60). When a pedestrian button (pass_request) is pressed during the green state, if the remaining green time is greater than 10, shorten it to 10. Otherwise, leave it unchanged. The state machine transitions as follows: idle → red → green → yellow → red, with timing controlled by the counter. Outputs red, yellow, green represent the current light, and clock outputs the current count. Use registers p_red, p_yellow, p_green to hold the next state signals, then output them synchronized to clock.
