Implement a finite state machine with four states: idle, s1_red, s2_yellow, s3_green. Use an 8-bit counter to time each state according to given durations (red=10, yellow=5, green=60). On reset, start at idle and then move to s1_red immediately. In s3_green state, if pass_request is asserted and remaining green time is more than 10, shorten it to 10; otherwise, keep it. Update the output signals red, yellow, green according to the current state. Use registered next-state outputs (p_red, p_yellow, p_green) to synchronize output changes with clock. The counter reloads according to state transitions and special conditions, counting down each clock cycle.
