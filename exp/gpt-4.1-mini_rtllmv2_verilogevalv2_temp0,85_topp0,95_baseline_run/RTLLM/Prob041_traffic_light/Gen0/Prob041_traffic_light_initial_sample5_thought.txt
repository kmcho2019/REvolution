Implement a finite state machine with four states: idle, s1_red, s2_yellow, s3_green. Each state corresponds to a traffic light color with a specific count duration (red=10, yellow=5, green=60). The FSM transitions between these states based on the counter reaching zero. The pedestrian button shortens the green time to 10 clocks if remaining green time is more than 10. The counter is managed accordingly. The output signals are updated synchronously, and state transitions occur combinationally. The provided parameters and registers are used as requested.
