Implement a 16-bit divider by an 8-bit divisor using combinational logic.
Use two always blocks:
- The first always block stores input values A and B into registers a_reg and b_reg.
- The second always block performs the division:
   * Initialize remainder and quotient to zero.
   * Iterate 16 times (bit-width of dividend).
   * At each iteration, shift in the next dividend bit to the remainder.
   * Compare the remainder with divisor; if remainder >= divisor:
       - Set quotient bit to 1
       - Subtract divisor from remainder
     else
       - Quotient bit is 0
   * After 16 iterations, quotient contains the division result and remainder contains the division remainder.
Output quotient as 'result' and remainder as 'odd' (remainder).
