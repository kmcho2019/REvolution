Implement a 16-bit divider with an 8-bit divisor using combinational logic. The division follows a shift-subtract algorithm similar to restoring division. The dividend (A) is processed starting from the highest bits matching the divisor width (8 bits). In each step, compare the current remainder portion with the divisor:
- If remainder >= divisor, set quotient bit = 1 and subtract divisor from remainder.
- Otherwise, quotient bit = 0.
Shift in the next bit of dividend to the remainder and repeat for all bits of the dividend.
Use two combinational always blocks:
- First block to latch inputs into internal registers (a_reg, b_reg).
- Second block to perform the division process, producing quotient (result) and remainder (odd).
