Create an instr_reg module with clk and active low rst.
Use two 8-bit registers ins_p1 and ins_p2.
On rising clk edge:
  If rst is low, reset ins_p1 and ins_p2 to zero.
  Else if fetch is 2'b01, load data into ins_p1.
  Else if fetch is 2'b10, load data into ins_p2.
Outputs:
  ins = upper 3 bits of ins_p1
  ad1 = lower 5 bits of ins_p1
  ad2 = full 8 bits of ins_p2
