Implement an instruction register module with two internal 8-bit registers ins_p1 and ins_p2.
On the positive clock edge:
- If reset is active low, clear both registers.
- Else if fetch == 2'b01, load data into ins_p1.
- Else if fetch == 2'b10, load data into ins_p2.
- Otherwise, retain the previous values.
Outputs:
- ins = upper 3 bits of ins_p1.
- ad1 = lower 5 bits of ins_p1.
- ad2 = entire ins_p2.
