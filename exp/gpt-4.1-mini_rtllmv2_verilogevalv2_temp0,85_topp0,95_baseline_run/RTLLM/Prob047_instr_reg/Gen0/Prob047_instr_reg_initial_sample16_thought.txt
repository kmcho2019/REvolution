Implement an instruction register module with two 8-bit registers ins_p1 and ins_p2. On the positive clock edge, if reset (active low) is asserted, clear both registers. Otherwise, update ins_p1 if fetch == 2'b01, update ins_p2 if fetch == 2'b10, else retain current values. Output ins as the upper 3 bits of ins_p1, ad1 as the lower 5 bits of ins_p1, and ad2 as the full 8 bits of ins_p2.
