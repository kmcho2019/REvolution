Create a module named instr_reg with inputs clk, rst, fetch, and data. Use two 8-bit registers ins_p1 and ins_p2 to store instructions from different sources. On the rising edge of clk, if rst is low, reset both registers to zero. If fetch is 2'b01, load data into ins_p1; if fetch is 2'b10, load data into ins_p2; otherwise retain current values. The outputs are derived as follows: ins from the upper 3 bits of ins_p1, ad1 from the lower 5 bits of ins_p1, and ad2 as the full 8 bits of ins_p2.
