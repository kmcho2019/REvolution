Implement a module named instr_reg with clk, rst, fetch, and data inputs. Two 8-bit registers ins_p1 and ins_p2 store instructions based on fetch. On clk rising edge, if rst is low, reset both registers. If fetch is 2'b01, load data into ins_p1; if fetch is 2'b10, load data into ins_p2; else retain values. Outputs ins (high 3 bits of ins_p1), ad1 (low 5 bits of ins_p1), and ad2 (full 8 bits of ins_p2) are continuously assigned from these registers.
