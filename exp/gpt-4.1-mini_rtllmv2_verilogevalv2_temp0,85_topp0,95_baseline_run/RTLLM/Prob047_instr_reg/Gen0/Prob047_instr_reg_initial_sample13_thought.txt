Implement a synchronous instruction register with two 8-bit registers ins_p1 and ins_p2.
On reset (active low), clear both registers.
On each rising clock edge, based on fetch input:
- if fetch == 2'b01, load data into ins_p1.
- if fetch == 2'b10, load data into ins_p2.
- else retain previous values.
Output ins and ad1 are derived from ins_p1 as the high 3 bits and low 5 bits respectively.
Output ad2 is the full 8-bit value from ins_p2.
