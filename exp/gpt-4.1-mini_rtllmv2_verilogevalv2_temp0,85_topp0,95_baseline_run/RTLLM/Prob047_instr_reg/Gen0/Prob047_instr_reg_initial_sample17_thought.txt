Create a module named instr_reg with inputs clk, rst, fetch, and data. Use two 8-bit registers ins_p1 and ins_p2 to store instructions from different sources. On the rising edge of clk, if rst is low, reset both registers to zero. Otherwise, update ins_p1 if fetch == 2'b01, update ins_p2 if fetch == 2'b10, and retain otherwise. The outputs ins (upper 3 bits of ins_p1), ad1 (lower 5 bits of ins_p1), and ad2 (full 8 bits of ins_p2) are assigned accordingly.
