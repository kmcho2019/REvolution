Create a synchronous instruction register module with two 8-bit registers ins_p1 and ins_p2. On reset (active low), clear both registers. On each clock rising edge, if fetch is 2'b01, load data into ins_p1; if fetch is 2'b10, load data into ins_p2; otherwise retain previous values. Output ins as the top 3 bits of ins_p1, ad1 as the lower 5 bits of ins_p1, and ad2 as the full 8-bit ins_p2.
