Implement an 8-bit multiplier using shift-and-add approach in combinational logic. Iterate over each bit of the multiplier B; if the bit is 1, add the multiplicand A shifted left by the bit index to the product. Accumulate these sums into a 16-bit product. This is done using a for loop inside an always_comb block or a continuous assignment with a generate loop or procedural block. The multiplicand is shifted logically by the bit index during addition. The final product is output as a 16-bit value.
