Implement an 8-bit multiplier using shift-and-add method. Initialize a 16-bit product to zero. Iterate over each bit of the multiplier B (from bit 0 to bit 7). For each bit set in B, add the multiplicand A shifted left by the bit position to the product. Finally, output the accumulated product. This can be done combinationally using a for loop inside an always_comb or a generate block with intermediate wire sums.
