Implement an 8-bit multiplier using the classic shift-and-add method:
- Initialize a 16-bit product register to zero.
- Iterate through each bit of the multiplier B (from LSB to MSB).
- For each bit that is set, add the multiplicand A shifted left by the bit index to the product.
- Perform the addition in a combinational manner to produce the final product.
- This can be done using a for-loop inside an always_comb block or as a purely combinational assignment.
