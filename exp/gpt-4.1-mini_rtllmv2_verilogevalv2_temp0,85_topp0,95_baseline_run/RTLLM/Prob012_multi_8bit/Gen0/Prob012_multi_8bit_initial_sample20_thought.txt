Implement a combinational multiplier using shift-and-add approach:
- Initialize a 16-bit product register to zero.
- Iterate over each bit of the multiplier B.
- For each bit i in B:
  - If B[i] is 1, add A shifted left by i bits to the product.
- Assign the final sum to the product output.
This can be done using a for loop inside an always_comb block or a continuous assignment with a generate block.
