Accumulate input data_in values only when valid_in is asserted. Use a counter to count the number of valid inputs received. When the count reaches 4, output the sum of these four values on data_out with valid_out asserted for one cycle. Reset the accumulator and counter after output. The accumulator width is 10 bits to cover the maximum sum of four 8-bit values (max 4*255=1020, fits in 10 bits). Also handle asynchronous reset active low.
