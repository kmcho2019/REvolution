The module accumulates four valid 8-bit input data samples when valid_in is high. We use an internal counter to track how many valid inputs have been received and an accumulator register to sum the inputs. Once four inputs have been accumulated, the result is output on data_out with valid_out asserted for one cycle. The accumulator and counter then reset for the next batch. The output width is 10 bits to accommodate the maximum sum (4*255=1020 < 1024).
