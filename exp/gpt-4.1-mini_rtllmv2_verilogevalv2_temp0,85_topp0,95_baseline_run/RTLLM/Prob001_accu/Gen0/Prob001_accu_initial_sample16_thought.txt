Accumulate the input data_in values only when valid_in is high. Keep a counter to count the number of valid inputs received. Once the count reaches 4, output the accumulated sum on data_out and set valid_out to 1 for one clock cycle, then reset the accumulator and the counter to start next accumulation cycle. Use a 10-bit register for accumulation to avoid overflow of 4*8-bit inputs. Reset accumulator and counter on rst_n deassertion.
