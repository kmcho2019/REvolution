Accumulate incoming 8-bit data values when valid_in is high. Use a counter to track how many valid inputs have been received. Add each valid data_in to a 10-bit accumulator (to avoid overflow since max sum of 4 * 255 = 1020 which fits in 10 bits). When four valid inputs have been accumulated, output the sum on data_out, set valid_out high for one cycle, then reset the accumulator and counter for the next accumulation cycle. Reset asynchronously clears accumulator and counter.
