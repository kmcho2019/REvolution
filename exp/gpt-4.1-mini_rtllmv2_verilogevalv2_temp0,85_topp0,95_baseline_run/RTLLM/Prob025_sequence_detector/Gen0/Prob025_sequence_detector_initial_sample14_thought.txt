Implement a Moore finite state machine with five states (IDLE, S1, S2, S3, S4) to detect the 4-bit sequence "1001". The FSM transitions on the rising edge of clk, checking the input bit data_in each cycle. On reset (active high), the FSM returns to IDLE state. When the sequence is detected in state S4, the output sequence_detected is asserted high for one clock cycle. The FSM transitions are designed to allow overlapping sequences to be detected.
