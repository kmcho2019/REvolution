Implement a Moore FSM with five states: IDLE, S1, S2, S3, and S4. Each state corresponds to how many bits of the sequence "1001" have been matched so far. On each clock edge, depending on input data_in, the FSM transitions to the next appropriate state. When the final bit is matched, set sequence_detected high for one clock cycle. The FSM resets to IDLE on reset_n assertion (active low).
