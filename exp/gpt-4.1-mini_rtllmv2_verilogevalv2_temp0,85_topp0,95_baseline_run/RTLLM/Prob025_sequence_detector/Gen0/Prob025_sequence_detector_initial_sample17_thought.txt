Implement a Moore FSM with five states: IDLE, S1, S2, S3, and S4. The FSM transitions on each clock cycle based on the input bit data_in to detect the sequence "1001". The output sequence_detected is asserted high when the FSM reaches the S4 state, indicating the full sequence has been detected. On reset (active high), the FSM returns to IDLE. The output is registered and synchronous with the clock.
