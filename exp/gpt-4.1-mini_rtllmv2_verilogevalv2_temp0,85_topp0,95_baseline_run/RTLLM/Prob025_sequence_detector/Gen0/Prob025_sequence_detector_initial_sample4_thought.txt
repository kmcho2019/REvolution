Implement a Moore FSM with five states: IDLE, S1, S2, S3, and S4, representing the progress in detecting the sequence 1001. On each clock cycle, the FSM transitions based on the current state and input bit. The output signal sequence_detected is asserted only when the FSM reaches S4, indicating the full sequence has been detected. The reset is active low, so on reset_n deasserted (0), the FSM returns to IDLE. The FSM is synchronous to clk.
