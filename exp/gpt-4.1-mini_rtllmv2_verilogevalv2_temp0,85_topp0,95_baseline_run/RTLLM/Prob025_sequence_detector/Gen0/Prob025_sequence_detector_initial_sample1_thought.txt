Implement a Moore FSM with five states: IDLE, S1, S2, S3, S4 to detect the sequence 1001 on the serial input data_in. On reset_n low, the FSM returns to IDLE. On each clock rising edge, transition states based on input bit and current state. When the final state S4 is reached (indicating full sequence detected), output sequence_detected is asserted. Since this is a Moore machine, sequence_detected is asserted only in state S4.
