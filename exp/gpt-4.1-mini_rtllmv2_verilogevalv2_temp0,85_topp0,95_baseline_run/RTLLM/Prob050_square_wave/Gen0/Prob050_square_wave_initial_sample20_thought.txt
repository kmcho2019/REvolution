Create a module named 'square_wave' with inputs 'clk' and an 8-bit 'freq', and an output 'wave_out'. Use an 8-bit register 'count' to count clock cycles. On each rising edge of 'clk', increment 'count'. When 'count' reaches 'freq - 1', reset 'count' to zero and toggle 'wave_out'. This creates a square wave with a frequency inversely proportional to the 'freq' input.
