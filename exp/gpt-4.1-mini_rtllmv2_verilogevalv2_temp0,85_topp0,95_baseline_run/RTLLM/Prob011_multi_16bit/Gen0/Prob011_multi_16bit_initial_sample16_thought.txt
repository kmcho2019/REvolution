Implement a sequential shift-and-accumulate unsigned multiplier with 16-bit inputs. Use a shift count register i to track the progress; on reset or start inactive, reset i. When start is active and i < 17, increment i each clock. When i=0, load ain and bin into registers areg and breg. For i from 1 to 16, check areg[i-1]; if set, accumulate breg shifted by i-1 into the 32-bit product register. The done flag is asserted when i=16, and cleared when i=17. Reset sets all registers to zero.
