Implement a sequential multiplier that uses a shift-and-accumulate algorithm. Use a 5-bit counter (i) to count up to 17 for control. On reset, clear all registers. On start, load multiplicand and multiplier into registers at count 0. For counts 1 to 16, check each bit of the multiplicand and if set, add the multiplier shifted left by the bit position to the product register. The done flag is set when count reaches 16, cleared at 17. Output yout is the product register value.
