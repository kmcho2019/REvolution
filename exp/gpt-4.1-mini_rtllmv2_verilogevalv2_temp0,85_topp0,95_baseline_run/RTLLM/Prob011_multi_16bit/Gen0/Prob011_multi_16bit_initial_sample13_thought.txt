Implement an unsigned 16-bit multiplier using shift-and-accumulate method. Use a shift count register i to control the number of steps (0 to 16). On reset, clear registers and flags. When start is asserted, load ain and bin into registers at i=0, then for i=1 to 16, check each bit of ain (areg) and if set, accumulate breg shifted by i-1 into yout_r. Generate done flag at i=16, clear at i=17 or reset. Output yout_r as yout.
