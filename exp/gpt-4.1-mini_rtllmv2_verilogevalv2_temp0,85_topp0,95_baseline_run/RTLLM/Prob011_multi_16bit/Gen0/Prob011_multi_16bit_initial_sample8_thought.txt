Implement a sequential unsigned 16-bit multiplier using shift and accumulate method. The multiplier uses a shift count register (i) to track the current bit being processed from the multiplicand. On start, registers are initialized. For each bit of the multiplicand, if the bit is high, the multiplier shifted left by the bit position is added to the product register. The done signal is set when all 16 bits are processed. The process resets properly on rst_n.
