Implement a shift-and-accumulate multiplier for 16-bit unsigned inputs. Use a counter (i) to track the current bit position being processed. On start, load the multiplicand and multiplier into registers. For each bit in the multiplicand (areg), if the bit is 1, add the multiplier shifted left by the bit index to the product accumulator. The done signal is asserted when all bits have been processed. The process is synchronous to clk and asynchronous active-low reset.
