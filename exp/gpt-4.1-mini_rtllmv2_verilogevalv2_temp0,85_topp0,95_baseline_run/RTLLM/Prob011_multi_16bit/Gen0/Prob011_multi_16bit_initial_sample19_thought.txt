Implement a sequential shift-and-accumulate multiplier using a shift count register i. On reset, registers are cleared. When start is asserted, store inputs into registers on i=0, then for each bit of ain (multiplicand), if the bit is 1, accumulate breg shifted left by (i-1) into yout_r. Increment i until 16. The done signal is set when i==16 and reset when i==17. Output yout is assigned from yout_r.
