Implement a sequential 16-bit unsigned multiplier using shift-and-accumulate technique. The process is controlled by a shift count register 'i' that runs from 0 to 16. On start, the multiplicand and multiplier are loaded into registers. For each bit in the multiplicand (areg), if that bit is 1, the multiplier (breg) shifted by the bit index is added to the running product (yout_r). The done flag is set when the operation completes at i=16 and cleared at i=17. All registers reset on active-low reset. Output yout reflects the current product register value.
