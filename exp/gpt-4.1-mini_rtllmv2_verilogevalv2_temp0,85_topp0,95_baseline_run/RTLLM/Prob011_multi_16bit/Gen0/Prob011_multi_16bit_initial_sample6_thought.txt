Implement a sequential multiplier using shift-and-add approach. Use a 5-bit counter i to track the current bit position (0 to 16). On reset, clear all registers. On start, load ain and bin into registers areg and breg. For each bit i from 0 to 15, check areg[i]; if set, add (breg << i) to yout_r. done is asserted when i == 16, cleared at i == 17 or reset. yout is assigned from yout_r.
