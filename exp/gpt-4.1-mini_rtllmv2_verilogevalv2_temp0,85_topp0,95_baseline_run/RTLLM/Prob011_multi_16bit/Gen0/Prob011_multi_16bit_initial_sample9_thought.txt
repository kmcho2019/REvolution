Implement a shift-and-accumulate unsigned 16-bit multiplier using a shift count register (i) to track progress. On reset or when start is inactive, reset registers and counters. When start is asserted, load inputs into registers at i=0. For i=1 to 16, check each bit of the multiplicand (areg) and if set, add the multiplier (breg) shifted by i-1 to the product register (yout_r). Use synchronous logic triggered on clk and asynchronous reset on rst_n. Generate a done signal when multiplication completes at i=16 and clear it at i=17.
