Implement a sequential multiplier using shift and add method. Use a register 'i' to count the shift steps from 0 to 16. On reset, clear all registers. On start, at i=0, load multiplicand and multiplier into registers. For each i from 1 to 16, check bit (i-1) of the multiplicand; if set, add (multiplier << (i-1)) to the product register. A done flag is set when i reaches 16, cleared at 17. Output the 32-bit product from the product register.
