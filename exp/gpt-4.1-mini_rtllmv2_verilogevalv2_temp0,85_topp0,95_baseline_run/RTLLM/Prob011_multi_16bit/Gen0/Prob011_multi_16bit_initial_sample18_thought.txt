Implement a sequential multiplier using a shift-and-accumulate method with control signals for start and done.
Use a shift count register 'i' to control the operation steps from 0 to 16.
On start=1 and i=0, load the multiplicand and multiplier into registers.
For i in 1 to 16, check if the bit (i-1) of multiplicand (areg) is set; if yes, add (breg shifted left by i-1) to the product register.
done flag is asserted when i == 16, and cleared at i == 17.
All registers and flags are reset on rst_n = 0.
The output yout is assigned from the product register.
