Implement a sequential multiplier that uses shift-and-accumulate based on a 16-bit multiplicand and multiplier. Control is managed by a shift count register which increments each clock cycle when start is asserted. The done flag is asserted when the multiplication completes. The multiplicand, multiplier, and product are stored in internal registers, and accumulation is done by checking each bit of the multiplicand and adding the appropriately shifted multiplier to the product. Reset and start control signals are handled per specification.
