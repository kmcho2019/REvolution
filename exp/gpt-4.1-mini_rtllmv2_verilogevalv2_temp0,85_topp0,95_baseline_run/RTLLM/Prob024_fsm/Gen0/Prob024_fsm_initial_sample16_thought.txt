On each clock cycle (with synchronous reset), we read the input bit IN and move between states accordingly. The MATCH output will be asserted when the last input bit completes the sequence "10011". The FSM should allow overlapping matches, so after detecting a match, it should move to the state representing the longest proper suffix of the sequence that is also a prefix, enabling detection of sequences like "100110011".
