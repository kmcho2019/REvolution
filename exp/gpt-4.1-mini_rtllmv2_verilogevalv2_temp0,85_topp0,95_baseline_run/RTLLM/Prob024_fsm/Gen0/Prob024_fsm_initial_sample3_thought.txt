To implement the Mealy FSM for sequence detection "10011", we need states representing the progress through the pattern. On every clock edge, depending on the input bit, the FSM transitions to the next appropriate state or a fallback state to handle overlapping sequences (loop detection). The output MATCH is asserted immediately when the last bit of the sequence is detected (Mealy output). The FSM resets on RST. The input IN is sampled synchronously on CLK, and MATCH is updated accordingly.
