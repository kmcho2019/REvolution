Implement a Mealy FSM that detects the sequence 10011 on a serial input IN. The FSM transitions through states corresponding to how much of the sequence has been matched so far, and the output MATCH is asserted when the last bit of the sequence (the fifth bit) is received. Because it is a Mealy machine, MATCH can be asserted combinationally based on the current state and input. The FSM supports overlapping sequences to continuously detect the pattern. The state transitions reset or fallback appropriately on mismatches to support looping detection. On reset, the FSM goes to the initial state and MATCH is deasserted.
