Implement a Mealy FSM with states representing the progress through the sequence 1-0-0-1-1. On each clock's rising edge, transition the state based on the input bit. When the final state is reached with the correct input, output MATCH=1. Use overlap in the FSM to allow continuous and overlapping detection. Reset clears the state and MATCH output. The FSM updates synchronously on the clock edge, and output MATCH is combinational from the state and current input (Mealy output).
