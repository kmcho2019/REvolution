Implement a Mealy FSM that detects the sequence 1,0,0,1,1 on a serial input IN. The FSM transitions through states representing how much of the sequence has been matched so far. When the final '1' of the sequence is received, MATCH is asserted for one clock cycle. The FSM supports overlapping detection by transitioning to the appropriate state after a match to allow continuous input processing. The FSM uses synchronous reset and clock for state updates, and outputs MATCH as a combinational function of the current state and input (Mealy output).
