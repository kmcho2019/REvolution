Implement a Mealy FSM that detects the sequence 10011 on input IN. The FSM has states representing partial matches of the sequence. On each clock edge, the FSM transitions based on the current IN and previous state, and outputs MATCH=1 when the full sequence is detected at the last input bit of '1'. The FSM supports overlapping detection by proper state transitions that allow looping. RST synchronously resets the FSM state and MATCH output.
