Design a Mealy FSM with states representing the progress of matching the sequence "10011". On each clock edge, input IN is sampled and the state transitions according to the input and current state, enabling overlapping detection (loop detection). When the FSM reaches the final state and the input matches the last bit, MATCH is asserted for that clock cycle. On reset, the FSM returns to the initial state and MATCH is cleared. The FSM is synchronous with CLK and asynchronous with RST, but the output MATCH is driven synchronously according to the FSM state and input.
