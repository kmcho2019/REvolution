Implement a Mealy FSM that detects the sequence 10011 on a serial input IN. The FSM has states representing how much of the sequence has been matched so far. On each clock edge, the FSM transitions based on the current state and input. When the full sequence is matched, MATCH is asserted in the same cycle as the last input bit (the final '1'). The FSM supports overlapping sequences for continuous detection. The reset signal asynchronously clears the state and output.
