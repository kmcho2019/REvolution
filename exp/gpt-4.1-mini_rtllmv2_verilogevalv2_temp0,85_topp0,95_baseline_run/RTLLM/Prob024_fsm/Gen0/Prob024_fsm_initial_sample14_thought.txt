Implement a Mealy FSM with states representing the progress in detecting the sequence 10011.
Each clock cycle, based on the input IN, transition to the next state or reset to a previous partial match state.
The MATCH output is asserted when the final input bit of the sequence (the last '1' in 10011) is detected.
The FSM supports overlapping sequences by transitioning to appropriate states after a match.
On reset, the FSM state and MATCH output reset to zero.
