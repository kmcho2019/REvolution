Implement a Mealy FSM with states representing the progress in detecting the sequence "10011".
The states can be encoded to track how many bits matched so far.
On each clock edge, check the input and move to the next state accordingly.
When the final bit of the sequence is matched, output MATCH=1.
Also, handle overlapping sequences by transitioning to appropriate states that reflect the longest suffix of the detected bits that can start a new sequence.
Reset sets state and output to 0.
This is a synchronous design with asynchronous reset.
