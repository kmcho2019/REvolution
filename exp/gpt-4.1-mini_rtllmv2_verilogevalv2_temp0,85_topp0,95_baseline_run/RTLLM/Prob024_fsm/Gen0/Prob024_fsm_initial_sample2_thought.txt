Implement a Mealy FSM with states representing the progress through the target sequence "10011". On each clock edge, update the state based on input IN. The MATCH output is set to 1 only when the final input (the last '1' in the sequence) is detected, and otherwise 0. The FSM supports overlapping sequences by transitioning to appropriate states for potential new sequences after a match. The FSM is synchronous with CLK and asynchronous reset RST.
