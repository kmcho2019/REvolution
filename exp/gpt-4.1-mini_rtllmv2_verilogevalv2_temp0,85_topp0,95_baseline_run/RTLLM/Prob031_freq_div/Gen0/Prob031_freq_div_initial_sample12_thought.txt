To implement the frequency divider, use three always blocks triggered on the positive edge of CLK_in or when RST is asserted. For each frequency output:

- CLK_50: Toggle output on every clock cycle (divide by 2).
- CLK_10: Use a 3-bit counter counting from 0 to 4, toggle the output at count 4, then reset counter.
- CLK_1: Use a 6-bit counter counting from 0 to 49, toggle the output at count 49, then reset counter.

Reset sets all outputs and counters to zero.
