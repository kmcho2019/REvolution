Implement a frequency divider module named freq_div with inputs CLK_in and RST, and outputs CLK_50, CLK_10, and CLK_1. Use three counters to generate the divided clocks. For CLK_50, simply toggle the output every clock cycle when not in reset. For CLK_10, use a 3-bit counter counting from 0 to 4; toggle the output and reset counter when count reaches 4. For CLK_1, use a 6-bit counter counting from 0 to 49; toggle the output and reset counter when count reaches 49. Ensure synchronous reset for all signals.
