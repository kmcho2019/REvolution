Implement a module freq_div with input clock CLK_in and reset RST. Generate CLK_50 by toggling a flip-flop every clock cycle (divide by 2). For CLK_10, use a 3-bit counter cnt_10 to count from 0 to 4, toggling CLK_10 when cnt_10 reaches 4 and then reset cnt_10. For CLK_1, use a 6-bit counter cnt_100 counting from 0 to 49, toggling CLK_1 and resetting the counter at 49. Reset all outputs and counters synchronously on RST.
