Implement a frequency divider module named freq_div that takes a 100MHz input clock and reset signal. Generate three output clocks at 50MHz, 10MHz, and 1MHz by using counters and toggling the output clocks at the appropriate counts:

- CLK_50: toggled every clock cycle (divide by 2)
- CLK_10: uses a 3-bit counter (cnt_10) counting from 0 to 4, toggling output on count 4 (divide by 10)
- CLK_1: uses a 6-bit counter (cnt_100) counting from 0 to 49, toggling output on count 49 (divide by 100)

Reset asynchronously initializes outputs and counters to zero.
