Implement a frequency divider module that takes a 100MHz input clock and reset signal and produces three output clocks: 50MHz, 10MHz, and 1MHz.  
- For 50MHz output: toggle the output clock on every positive edge of input clock (divide by 2).  
- For 10MHz output: use a 3-bit counter counting from 0 to 4 (total 5 counts), toggle output clock at count 4, then reset counter (divide by 10).  
- For 1MHz output: use a 6-bit counter counting from 0 to 49 (total 50 counts), toggle output clock at count 49, then reset counter (divide by 100).  
Reset logic sets all outputs and counters to zero on active reset.  
All operations are synchronous to the positive edge of the input clock or asynchronous reset.
