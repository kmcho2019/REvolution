Implement a sequential logic module that uses a 2-bit counter (cnt) to track which bit to output from the 4-bit register (data). On reset (rst_n=0), reset cnt and data. When cnt reaches 3, load data with input d, reset cnt to 0, and assert valid_out. Otherwise, increment cnt, deassert valid_out, and rotate data left by one bit so that the next MSB becomes the output bit in the next cycle. The serial output dout is always the MSB of data. This ensures that each 4-bit parallel input is serialized MSB first over 4 clock cycles with valid_out signaling the start of each serialized data.
