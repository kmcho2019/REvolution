Use a 4-bit shift register to hold the parallel input data. On reset or when the last bit (cnt=3) is transmitted, load the shift register with new parallel input data and reset the counter. For each clock cycle, output the MSB of the shift register as dout. If cnt=3, valid_out is set high indicating the first bit of new parallel data is output; otherwise valid_out is low. Shift the register left by one bit each cycle to output the bits from MSB to LSB sequentially. The counter increments each cycle modulo 4 to track which bit is being output.
