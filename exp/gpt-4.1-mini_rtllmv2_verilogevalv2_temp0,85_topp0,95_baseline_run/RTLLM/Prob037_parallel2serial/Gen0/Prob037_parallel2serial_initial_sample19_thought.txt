Implement a module with a 4-bit register to hold the data to be serialized and a 2-bit counter to track the current bit position. On reset, the counter and data register are reset. When the counter reaches 3 (last bit), load the data register with new input and reset the counter to 0, output the MSB, and set valid_out to 1. On other cycles, increment the counter, shift data to bring the next bit to MSB position, output the MSB, and set valid_out to 0.
