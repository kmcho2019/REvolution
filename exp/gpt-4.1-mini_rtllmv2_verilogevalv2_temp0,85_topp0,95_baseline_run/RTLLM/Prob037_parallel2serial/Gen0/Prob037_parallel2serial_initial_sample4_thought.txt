Implement a sequential logic block triggered on the rising edge of clk or the falling edge of rst_n. When reset is active (rst_n = 0), reset the counter, data register, and valid_out signal. Otherwise, on each clock cycle, check if the counter is 3. If yes, load the 4-bit input into the data register, reset the counter to 0, and set valid_out to 1. If not, shift the data register left by 1 bit (MSB to LSB rotation), increment the counter, and set valid_out to 0. The serial output dout is always the MSB of the data register.
