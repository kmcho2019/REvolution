Implement a parallel-to-serial converter that outputs 4 bits serially from MSB to LSB. The module uses a 2-bit counter to track which bit is being output. When the counter reaches 3 (the last bit), it loads new parallel data into a register and asserts valid_out. On other cycles, it shifts the data register left and outputs the MSB. The valid_out is high only when the first bit (MSB) of the new data is being output.
