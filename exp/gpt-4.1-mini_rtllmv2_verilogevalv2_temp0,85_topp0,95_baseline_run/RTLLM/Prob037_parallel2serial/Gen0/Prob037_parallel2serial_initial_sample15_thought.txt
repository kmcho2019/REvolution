Implement a sequential logic with a 2-bit counter cnt to track which bit is being output. Use a 4-bit register data to hold the current parallel input. On reset (rst_n=0), initialize cnt and data to 0 and valid_out to 0. When cnt reaches 3, load data with input d, reset cnt to 0, and set valid_out to 1 (indicating MSB output). Otherwise, shift data left by one bit, increment cnt, and clear valid_out. dout is always assigned to the MSB of data.
