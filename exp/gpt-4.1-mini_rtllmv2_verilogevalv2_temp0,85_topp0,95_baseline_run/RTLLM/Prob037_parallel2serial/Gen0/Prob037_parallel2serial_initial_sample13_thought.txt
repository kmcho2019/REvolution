Implement a 4-bit shift register to hold input data 'd'. On reset, clear the counter and data. On each clock cycle, if counter is 3 (last bit output), load new parallel data into the shift register, reset counter to 0, and set valid_out=1. Otherwise, shift the data register left by one bit (MSB shifted out), increment the counter, and set valid_out=0. The output dout is always the MSB of the data register. The reset is active low (rst_n=0 for reset). Valid_out is asserted only when new parallel data is loaded and the first bit (MSB) is output.
