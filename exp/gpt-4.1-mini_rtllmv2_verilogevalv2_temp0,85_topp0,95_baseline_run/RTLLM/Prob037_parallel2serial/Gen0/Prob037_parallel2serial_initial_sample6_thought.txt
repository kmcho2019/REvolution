Use a 4-bit shift register to hold the data. On reset or after outputting the last bit (when cnt == 3), load the parallel input into the register and reset cnt. On each clock cycle, output the MSB of the register as dout, set valid_out high only when cnt == 0 (indicating the first output bit is valid). Then shift the register left by 1 bit, increment cnt. When cnt == 3, on next cycle reload the register and reset cnt. The valid_out signal is asserted only during the first output bit of each 4-bit data sequence.
