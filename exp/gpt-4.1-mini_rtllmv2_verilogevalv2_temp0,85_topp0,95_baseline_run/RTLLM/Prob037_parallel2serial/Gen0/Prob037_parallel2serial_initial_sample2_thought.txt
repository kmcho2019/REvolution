Implement a sequential logic module with a 2-bit counter to index the bits being output serially from the 4-bit input. On reset (rst_n=0), clear the counter and valid_out. On each clock cycle, if the counter is 3 (last bit), load the data register with the new input d, reset counter to 0, and set valid_out to 1. Otherwise, increment counter, shift data register left by 1 (rotate MSB to LSB), and clear valid_out. Output dout is always the MSB of the data register.
