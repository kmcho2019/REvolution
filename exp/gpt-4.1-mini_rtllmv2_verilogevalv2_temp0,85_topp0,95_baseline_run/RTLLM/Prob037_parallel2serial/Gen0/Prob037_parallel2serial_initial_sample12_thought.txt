Implement a sequential logic module that on reset initializes counter and data registers. On each clock cycle, if the counter is 3 (indicating last bit output), reload the data register with the new 4-bit input, reset counter to 0, and set valid_out to 1. Otherwise, increment the counter, shift the data register left by 1 bit, and clear valid_out. The serial output dout is always the MSB of the data register.
