Implement a parallel-to-serial converter that takes 4-bit parallel input and outputs bits serially from MSB to LSB. On reset, initialize counter and data register. When the counter reaches 3, load new parallel data, reset counter to 0, and set valid_out to 1 to indicate valid output. Otherwise, increment counter, clear valid_out, and shift data left by 1 bit to bring next bit to MSB position. The serial output dout is always the MSB of the data register.
