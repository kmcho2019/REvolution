Use a 4-bit shift register to hold the parallel input data and a 2-bit counter to track the current bit to output. On reset, initialize the counter and load the data register with the input. On each clock cycle, output the MSB of the data register as dout. When the counter is 3 (last bit), load new data, reset counter to 0, and assert valid_out to 1. Otherwise, shift data left by 1 bit (circular shift to put MSB to LSB), increment the counter, and de-assert valid_out.
