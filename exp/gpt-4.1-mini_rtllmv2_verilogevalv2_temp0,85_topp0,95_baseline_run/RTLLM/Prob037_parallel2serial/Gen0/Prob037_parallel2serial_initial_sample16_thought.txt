Implement a parallel-to-serial converter that takes a 4-bit parallel input and outputs it serially from MSB to LSB. A 2-bit counter tracks which bit is being output. When the counter reaches 3, the module loads the new parallel data, resets the counter, and asserts valid_out to indicate valid output. Between these loads, valid_out is 0. The data register shifts left each cycle to bring the next bit to MSB. The output dout is always the MSB of the data register.
