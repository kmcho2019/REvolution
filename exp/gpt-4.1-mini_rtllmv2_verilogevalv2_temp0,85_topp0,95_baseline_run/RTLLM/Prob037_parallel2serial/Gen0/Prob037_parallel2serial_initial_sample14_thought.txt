Implement a parallel-to-serial converter that loads 4-bit input data into a register when all previous bits have been output (counter == 3). The output valid_out is asserted only on the cycle when the MSB of new data is output (counter == 3). On other cycles, valid_out is 0, and the data register shifts left to output the next bit. The counter increments each clock cycle and resets to 0 when new data is loaded. The reset is active low (rst_n). The shifting is circular to wrap the MSB to LSB as per instruction, but this circular shift does not affect the output sequence since bits are output MSB to LSB over 4 cycles.
