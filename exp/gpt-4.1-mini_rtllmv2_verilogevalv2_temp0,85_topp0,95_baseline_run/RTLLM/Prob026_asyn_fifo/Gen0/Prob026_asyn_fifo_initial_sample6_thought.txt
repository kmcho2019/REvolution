Implement an asynchronous FIFO with configurable width and depth using a dual-port RAM submodule for storage. Maintain separate read and write pointers in binary and convert them to Gray code for synchronization between clock domains. Use two-stage synchronizers for crossing the write pointer into the read clock domain and the read pointer into the write clock domain. Generate empty and full signals by comparing synchronized Gray pointers. Addressing RAM using the lower bits of the binary pointers. Write pointer increments on write clock with write enable, read pointer increments on read clock with read enable. Implement the dual-port RAM with independent clocks and separate read and write enables.
