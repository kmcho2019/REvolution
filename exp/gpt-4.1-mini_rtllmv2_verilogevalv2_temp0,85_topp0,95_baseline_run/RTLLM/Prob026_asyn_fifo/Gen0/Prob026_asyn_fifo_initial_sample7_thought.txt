Implement an asynchronous FIFO with parameterized WIDTH and DEPTH using a dual-port RAM submodule for storage. Use binary pointers for write and read address generation, convert them to Gray code for pointer synchronization across clock domains. Synchronize the opposite clock domain's Gray pointer via a two-stage register chain. Determine FIFO full and empty status by comparing Gray-coded pointers according to standard async FIFO rules. Generate write/read enable signals only when FIFO isn't full/empty and the write/read increment signals are asserted. Use Gray code to binary conversion to select RAM addresses and access the dual-port RAM. The dual-port RAM has separate clocks and enables for write/read ports and stores data in a 2D register array. The module will include separate logic blocks for write pointer generation, read pointer generation, pointer synchronization, and full/empty flag generation.
