Implement an asynchronous FIFO with parameterized depth and width.
Use a dual-port RAM submodule for storage.
Manage read and write pointers in binary, convert to Gray code for synchronization.
Synchronize the read pointer to write clock domain and write pointer to read clock domain using 2-stage synchronizers.
Generate full and empty flags based on Gray code pointer comparisons.
Use Gray code's MSBs and LSBs for full condition detection and equality for empty detection.
Address RAM using binary pointers (lower bits of the Gray code converted back to binary).
Control write and read enables based on increment signals and FIFO status.
All reset signals are active-low and asynchronous.
