Implement an asynchronous FIFO with parameterizable width and depth using a dual-port RAM submodule. Use Gray code counters for write and read pointers to avoid metastability and to enable safe cross-clock domain synchronization. The write pointer synchronizes into the read clock domain and the read pointer synchronizes into the write clock domain using two-stage flip-flop synchronizers. The FIFO full and empty conditions are derived by comparing Gray-coded pointers as specified. Write and read pointers are incremented based on write and read increment inputs, gated by full and empty signals respectively. The dual-port RAM supports independent read and write ports clocked by wclk and rclk, respectively. Lower bits of binary pointers serve as RAM addresses. This design ensures asynchronous operation between write and read clocks with proper synchronization and pointer management.
