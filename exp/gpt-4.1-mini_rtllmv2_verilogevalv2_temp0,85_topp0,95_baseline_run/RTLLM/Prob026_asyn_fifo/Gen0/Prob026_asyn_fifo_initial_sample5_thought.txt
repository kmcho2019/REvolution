Implement an asynchronous FIFO with parameterized WIDTH and DEPTH using a dual-port RAM submodule for storage. Manage write and read pointers in binary and convert them to Gray code for pointer synchronization between asynchronous clock domains. Use two-stage synchronizers for crossing pointers between clock domains. Generate full and empty flags based on the Gray-coded pointers, following the specified conditions. The dual-port RAM is instantiated as a separate module with separate clocks and ports for reading and writing. The FIFO read and write controllers increment pointers on valid increments if not full or empty. The Gray-coded pointers are synchronized and converted back to binary for address generation. The output data and flags are updated accordingly.
