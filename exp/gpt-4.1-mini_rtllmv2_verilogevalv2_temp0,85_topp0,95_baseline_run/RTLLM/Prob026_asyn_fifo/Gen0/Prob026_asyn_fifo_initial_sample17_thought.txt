Implement an asynchronous FIFO with parameterizable width and depth using a dual-port RAM submodule. Manage separate read and write pointers in binary and Gray code to avoid metastability issues. Synchronize pointers across clock domains using 2-stage synchronizers. Use Gray code comparison to generate empty and full flags. Convert Gray pointers to binary for RAM addressing. The dual-port RAM is instantiated as a separate module accessed with separate clocks and enables. The main FIFO module handles pointer increments, synchronization, Gray code conversion, full/empty detection, and interfacing with the dual-port RAM.
