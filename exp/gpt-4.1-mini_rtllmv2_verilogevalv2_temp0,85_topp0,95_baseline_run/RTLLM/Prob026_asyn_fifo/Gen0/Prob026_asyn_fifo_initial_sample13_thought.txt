Implement the asynchronous FIFO by dividing the design into five parts: dual-port RAM module, write controller (including binary and gray write pointer generation), read controller (including binary and gray read pointer generation), read pointer synchronizer in write clock domain, and write pointer synchronizer in read clock domain. Use parameterized WIDTH and DEPTH with corresponding address width. Use gray code for pointers and synchronize the opposite domain pointer using two-stage flip-flop synchronizers to avoid metastability. Implement full and empty flags by comparing gray-coded pointers according to the problem statement. Convert gray code pointers to binary to get actual addresses for dual-port RAM access. The dual-port RAM is instantiated as a submodule with separate clocks and enables. Provide complete RTL with synchronous resets and proper enable conditions.
