Implement an asynchronous FIFO with parameterized width and depth using a dual-port RAM module. The FIFO uses separate write and read clocks and resets. Write and read pointers are managed as binary counters, converted to Gray code to prevent metastability when crossing clock domains. Synchronize the Gray-coded read pointer into the write clock domain and the Gray-coded write pointer into the read clock domain using two-stage synchronizers. Use Gray code comparisons to generate full and empty flags. The dual-port RAM is instantiated as a submodule with separate clocks and enables for reading and writing. The address for RAM access is derived from the lower bits of the binary pointer converted from Gray code. Write pointer increments on write enable and not full; read pointer increments on read enable and not empty. The full condition is detected by checking if write pointer is one ahead of read pointer in Gray code with MSBs inverted. The empty condition is when read pointer equals write pointer in Gray code.
