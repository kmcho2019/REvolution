Implement an asynchronous FIFO using a parameterized depth and width. The FIFO uses a dual-port RAM submodule with separate write and read clocks. Write and read pointers are maintained in binary and converted to Gray code for synchronization and full/empty detection. The write pointer is synchronized into the read clock domain and the read pointer synchronized into the write clock domain using two-stage synchronizers. Empty is detected by comparing synchronized pointers for equality; full is detected by a specific Gray code pattern indicating the FIFO is full. The dual-port RAM is accessed using the lower bits of the binary pointers for addressing. The design is modular and uses parameterization for scalability.
