Implement an asynchronous FIFO with parameterizable DEPTH and WIDTH. Use a dual-port RAM submodule for storage with separate clocks for read and write. Manage write and read pointers in binary and convert to Gray code for synchronization. Synchronize pointers across clock domains using two-stage registers. Determine empty/full conditions by comparing Gray-coded pointers. Use the lower bits of the binary pointer for addressing RAM. Provide write enable when FIFO not full and write increment asserted; provide read enable when FIFO not empty and read increment asserted. Reset pointers and synchronizers asynchronously. Output FIFO full and empty flags accordingly.
