Implement an asynchronous FIFO with parameterized width and depth using a dual-port RAM submodule. Use Gray code for read and write pointers to enable asynchronous pointer synchronization and glitch-free full/empty detection. Synchronize read pointer into write clock domain and write pointer into read clock domain via two-stage synchronizers. Use pointers and their Gray code forms to determine empty and full conditions. The dual-port RAM has separate clocks and enables for write and read, indexed by the lower bits of the binary pointer converted from Gray code. The write and read controllers increment pointers on write and read increments when not full/empty. Outputs are the full and empty flags plus the read data output.
