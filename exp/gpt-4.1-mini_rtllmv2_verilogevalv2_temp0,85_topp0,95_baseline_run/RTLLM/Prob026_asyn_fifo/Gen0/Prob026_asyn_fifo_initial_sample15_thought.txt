Implement an asynchronous FIFO with parameterized WIDTH and DEPTH. The FIFO uses a dual-port RAM for storage, with separate read and write clocks. Write and read pointers are binary counters converted to Gray code for synchronization. Pointers are synchronized across clock domains using two-stage registers. The full and empty conditions are determined by comparing Gray-coded pointers according to the specified method. The RAM is accessed using the binary address converted from the lower bits of the Gray code pointers. The module will instantiate a submodule "dual_port_RAM" and implement the write/read controllers and pointer synchronizers as described.
