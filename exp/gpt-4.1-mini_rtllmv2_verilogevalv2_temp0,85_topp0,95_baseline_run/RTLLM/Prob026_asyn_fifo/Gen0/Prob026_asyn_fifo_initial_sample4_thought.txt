Implement an asynchronous FIFO with parameterizable DEPTH and WIDTH. The design uses a dual-port RAM for storage, with separate write and read clocks. Write and read pointers are binary counters converted to Gray code for synchronization. The write pointer is synchronized into the read clock domain, and the read pointer into the write clock domain, both using two-stage synchronizers. The FIFO full and empty flags are generated by comparing Gray-coded pointers with the specified conditions. The dual-port RAM submodule is instantiated and connected using the lower bits of the binary pointers (converted from Gray code) as addresses. Write/read enable signals are generated based on write/read increment requests and full/empty status.
