Implement an asynchronous FIFO with configurable WIDTH and DEPTH using a dual-port RAM module instantiated as a submodule. The dual-port RAM has separate clocks and enables for read and write. The write and read pointers are managed in binary and converted to Gray code for synchronization across clock domains. Two-stage synchronizers are used to pass the pointers across clock domains safely. The FIFO full and empty flags are generated by comparing Gray-coded pointers according to the specified rules. The RAM addresses are derived from the lower bits of the binary pointers. The write pointer increments on wclk and write increment, reset by wrstn. The read pointer increments on rclk and read increment, reset by rrstn. The read data output comes directly from the RAM read data port. The RAM write enable is gated by write increment and FIFO not full. The RAM read enable is gated by read increment and FIFO not empty.
