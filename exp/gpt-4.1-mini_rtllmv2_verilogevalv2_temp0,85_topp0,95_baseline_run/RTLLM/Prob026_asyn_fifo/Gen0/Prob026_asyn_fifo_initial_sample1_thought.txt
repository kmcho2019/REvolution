Implement a parameterized asynchronous FIFO with dual-port RAM submodule for storage. The write and read pointers are managed in binary, converted to Gray code for synchronization across clock domains. Synchronizers capture read pointer in write clock domain and write pointer in read clock domain using two-stage flip-flop chains. Full and empty conditions are detected by comparing Gray-coded pointers with the specified conditions. Addressing into RAM uses binary pointers derived from Gray codes. The design includes proper reset handling and write/read enable control. The RAM module is instantiated as a separate submodule with separate clocks and enables.
