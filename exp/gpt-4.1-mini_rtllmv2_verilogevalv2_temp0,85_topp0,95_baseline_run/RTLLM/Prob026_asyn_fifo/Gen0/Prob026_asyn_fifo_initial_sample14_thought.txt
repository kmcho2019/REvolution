To implement the asynchronous FIFO, the design consists of several key parts:
1. A dual-port RAM module with separate clocks for read and write, parameterizable depth and width.
2. Write and read pointer logic using Gray code to minimize metastability issues when crossing clock domains.
3. Two-stage synchronizers for passing the read pointer into the write clock domain and the write pointer into the read clock domain.
4. Logic to detect full and empty states based on Gray-coded pointers.
5. Address calculations using binary pointers extracted from Gray-coded pointers.
6. The write controller increments the write pointer when the FIFO is not full and winc is asserted.
7. The read controller increments the read pointer when the FIFO is not empty and rinc is asserted.

Key points:
- DEPTH and WIDTH are parameters.
- The FIFO depth is always a power of two; so $clog2(DEPTH) gives the pointer width.
- Gray code conversion: gray = binary ^ (binary >> 1).
- For full detection, check if write pointer has advanced one full cycle ahead of read pointer with the inverted MSBs.
- For empty detection, check if the read pointer equals the synchronized write pointer.
- Dual-port RAM is instantiated as a submodule with separate clocks and enables.
- The outputs wfull and rempty are generated accordingly.
- Reset signals are active-low.
- Synchronization of pointers uses double flip-flop synchronizers.

The final code will include:
- The dual-port RAM module.
- The top-level async FIFO module as per the specification.
