Implement an 8-bit unsigned multiplier using a multi-stage pipeline architecture to improve throughput. The design uses input registers for operands gated by the input enable signal, generates partial products based on the multiplier bits, then accumulates these partial products across pipeline stages using registers. The output enable signal is pipelined along with the data to indicate valid output. The product is outputted only when the output enable is active; otherwise, zero is output. The design resets all registers on active-low reset.
