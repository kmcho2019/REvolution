Implement an 8-bit unsigned multiplier using a pipeline architecture with multiple clock stages to boost throughput. The pipeline will:
- Latch inputs mul_a and mul_b into registers when mul_en_in is asserted.
- Generate partial products by ANDing mul_a bits with each bit of mul_b.
- Use registers to hold intermediate sums, adding partial products stage by stage.
- Use a multi-stage adder pipeline to combine partial products.
- Propagate the enable signal through a shift register to produce mul_en_out.
- Output mul_out when mul_en_out is asserted; otherwise output 0.
- On active-low reset, clear all registers to 0.
This pipeline architecture balances the logic delay across clock cycles, improving the maximum clock frequency.
