Implement an 8-bit unsigned multiplier using a pipeline architecture. The design captures inputs and enable signal on clock edges when mul_en_in is active. Partial products are generated by ANDing the multiplicand with each bit of the multiplier. These partial products are then summed in stages using registers to form partial sums, pipelining the additions over multiple clock cycles to improve throughput. The enable signal is also pipelined through a shift register so that the output enable aligns with the final product. The final product is stored in a register and output when mul_en_out is asserted, otherwise zero is output.
