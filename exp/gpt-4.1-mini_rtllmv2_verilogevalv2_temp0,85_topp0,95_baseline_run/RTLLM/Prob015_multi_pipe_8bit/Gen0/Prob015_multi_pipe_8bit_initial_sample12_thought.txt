Implement an 8-bit unsigned multiplier using a pipelined approach. The pipeline stages are:
1. Input capture: sample inputs and enable signal when mul_en_in is high.
2. Partial product generation: generate partial products based on multiplier bits.
3. Partial sum calculation: add partial products in a multi-cycle pipelined manner.
4. Final sum: sum all partial sums and store the final 16-bit product.
The output enable signal is pipelined along with data to indicate valid output. Reset clears all registers. The output mul_out is zero when output enable is low.
