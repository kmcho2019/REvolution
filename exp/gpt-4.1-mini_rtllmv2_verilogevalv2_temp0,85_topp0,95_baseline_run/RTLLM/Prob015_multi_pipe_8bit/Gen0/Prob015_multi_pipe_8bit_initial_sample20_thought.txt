Implement an 8-bit unsigned multiplier using pipelining to improve throughput. On each clock cycle when mul_en_in is active, sample inputs into registers. Generate partial products by ANDing multiplicand bits with individual multiplier bits. Then pipeline the addition of these partial products across multiple clock cycles using registers to hold intermediate sums. The output enable signal mul_en_out is pipelined from mul_en_in to indicate when output is valid. The final product is stored in a register and output when mul_en_out is active; otherwise, output zero. Active-low reset clears all registers.
