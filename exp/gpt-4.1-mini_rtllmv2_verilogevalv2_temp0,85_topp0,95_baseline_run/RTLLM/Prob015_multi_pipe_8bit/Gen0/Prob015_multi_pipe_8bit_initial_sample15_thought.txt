Implement a pipelined unsigned 8-bit multiplier with input enable, active-low reset, and clocked registers for input operands, partial products, partial sums, and the final product. The pipeline stages capture the multiplier bits to generate partial products, accumulate them in stages, and finally output the 16-bit product with an output enable signal that is pipelined from the input enable. All registers update synchronously on the positive clock edge and reset asynchronously via active-low reset. The output product is valid only when the output enable is asserted.
