Implement a synchronous process triggered by posedge clk or negedge rst_n. On reset (when ~rst_n), clear state and wave to 0. Otherwise, use a case statement on state: when 0, increment wave until it hits 31, then change state to 1; when 1, decrement wave until it hits 0, then change state to 0. This generates a triangle wave cycling between 0 and 31.
