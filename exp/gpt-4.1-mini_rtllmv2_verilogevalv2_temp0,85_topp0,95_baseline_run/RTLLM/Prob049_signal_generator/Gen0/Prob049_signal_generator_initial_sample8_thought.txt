Implement a module named signal_generator with inputs clk and rst_n and a 5-bit output wave. Use two registers: state (1-bit) and wave (5-bit). On reset (active low), clear both to 0. On each posedge clk, if state is 0, increment wave. If wave reaches 31, change state to 1. If state is 1, decrement wave. If wave reaches 0, change state to 0. This creates a triangle wave cycling from 0 up to 31 and down to 0 continuously.
