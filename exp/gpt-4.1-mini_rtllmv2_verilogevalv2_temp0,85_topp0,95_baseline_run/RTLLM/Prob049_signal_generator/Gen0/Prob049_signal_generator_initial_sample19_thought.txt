Implement a signal_generator module with clk and rst_n inputs and a 5-bit wave output.
Use a state register to track whether the wave is incrementing (state=0) or decrementing (state=1).
On reset, clear state and wave to 0.
On each clock edge, update wave and state accordingly:
- If state is 0, increment wave; if wave reaches 31, change state to 1.
- If state is 1, decrement wave; if wave reaches 0, change state to 0.
Use a synchronous always block sensitive to posedge clk and negedge rst_n.
