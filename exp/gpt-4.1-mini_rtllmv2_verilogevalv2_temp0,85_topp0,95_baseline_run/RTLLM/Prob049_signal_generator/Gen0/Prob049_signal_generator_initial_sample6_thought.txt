Implement a synchronous always block triggered by posedge clk and negedge rst_n. Use a state register to toggle between incrementing and decrementing the 5-bit wave register. On reset, clear both state and wave. When state is 0, increment wave until it reaches 31, then change state to 1. When state is 1, decrement wave until it reaches 0, then revert state to 0. Output wave is driven from the wave register.
