Implement a synchronous module with an active-low reset that maintains two registers: a 1-bit state and a 5-bit wave. On reset, both are set to 0. On each clock edge, depending on the state, increment or decrement wave. Transition state from 0 to 1 when wave reaches 31, and from 1 to 0 when wave reaches 0, thus generating a triangle waveform between 0 and 31.
