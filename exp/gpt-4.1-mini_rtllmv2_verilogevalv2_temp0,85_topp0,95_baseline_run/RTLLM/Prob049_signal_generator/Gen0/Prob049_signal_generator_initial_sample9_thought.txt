Implement a synchronous module with asynchronous active-low reset. Use a 1-bit state register to track whether the waveform is incrementing (state=0) or decrementing (state=1). On each clock cycle, update the 5-bit wave register accordingly: increment if state=0, decrement if state=1. Transition state when wave reaches the boundary values (0 or 31). Initialize both state and wave to 0 upon reset.
