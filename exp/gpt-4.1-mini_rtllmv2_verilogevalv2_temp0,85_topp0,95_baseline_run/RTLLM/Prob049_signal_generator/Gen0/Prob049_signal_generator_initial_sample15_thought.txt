Implement a synchronous module with an active-low reset. Use a state register to indicate the direction of the triangle wave (0 for increment, 1 for decrement). On reset, initialize wave and state to 0. On each clock edge, update wave based on state: if state is 0, increment wave until it reaches 31 then switch state to 1; if state is 1, decrement wave until it reaches 0 then switch state to 0.
