Implement a state-controlled triangle wave generator with a 5-bit wave output and a 1-bit state register. On reset, initialize state and wave to 0. On each clock edge, if state is 0, increment wave until it reaches 31, then set state to 1. If state is 1, decrement wave until it reaches 0, then set state to 0. This produces a triangle waveform cycling between 0 and 31.
