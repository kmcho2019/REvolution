Implement a module named signal_generator with inputs clk and rst_n and a 5-bit output wave. Use a 1-bit state register to control waveform direction: 0 means increment wave until 31, then switch state to 1; 1 means decrement wave until 0, then switch state back to 0. On reset (active low), set state and wave to 0. Update state and wave synchronously on posedge clk or negedge rst_n using a case statement.
