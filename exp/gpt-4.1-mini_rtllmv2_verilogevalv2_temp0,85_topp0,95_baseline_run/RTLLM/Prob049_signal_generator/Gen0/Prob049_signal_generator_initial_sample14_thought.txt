Implement a synchronous state machine with two states (0 and 1) to control the triangle wave generation. On reset, both state and wave are cleared to 0. When state is 0, wave increments until it reaches 31, then state changes to 1. When state is 1, wave decrements until it reaches 0, then state returns to 0. The wave output is a 5-bit register updated every clock cycle based on this logic.
