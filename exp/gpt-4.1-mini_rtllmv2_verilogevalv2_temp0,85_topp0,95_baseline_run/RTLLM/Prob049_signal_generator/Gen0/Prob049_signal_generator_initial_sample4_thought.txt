Implement a synchronous process triggered on posedge clk and negedge rst_n. On reset, clear state and wave to 0. Otherwise, use a state register to determine if the wave is incrementing or decrementing. When state is 0, increment wave until it reaches 31, then switch state to 1. When state is 1, decrement wave until it reaches 0, then switch state to 0. This generates a triangular wave cycling from 0 to 31 and back.
