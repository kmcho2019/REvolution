Implement an 8-bit barrel shifter using a 3-stage process corresponding to shifts by 4, 2, and 1 bits. Use a 2-to-1 multiplexer module `mux2X1` to select between the shifted and unshifted inputs at each stage based on the control bits. The shifting is done by rotation (circular shift). At each stage, for each output bit, instantiate a mux2X1 to select the appropriate rotated bit or original bit. Chain the stages so that the output of one stage feeds the next. Finally, assign the output of the last stage to the module output.
