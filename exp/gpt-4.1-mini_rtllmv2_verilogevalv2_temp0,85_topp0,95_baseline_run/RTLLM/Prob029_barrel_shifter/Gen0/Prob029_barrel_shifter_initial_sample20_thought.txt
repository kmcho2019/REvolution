Implement an 8-bit barrel shifter that rotates bits based on a 3-bit control signal. Each bit in `ctrl` corresponds to a shift stage (4, 2, 1 positions). The shifting is done using 2-to-1 multiplexers (`mux2X1`), which choose between the original and shifted inputs at each stage. The output of one stage feeds into the next stage. The final result is assigned to `out`.
