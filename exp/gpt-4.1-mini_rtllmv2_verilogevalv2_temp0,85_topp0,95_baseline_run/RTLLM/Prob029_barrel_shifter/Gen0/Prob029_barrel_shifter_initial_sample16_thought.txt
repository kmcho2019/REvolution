Implement an 8-bit barrel shifter with three stages of shifting (4, 2, 1 bits) controlled by the bits of the 3-bit control signal `ctrl`. Each stage conditionally shifts the data by the corresponding amount using a set of 2-to-1 multiplexers (`mux2X1`), which select between the shifted bit and the original bit depending on the control bit. The output of one stage feeds into the next. The final output is the fully rotated result.

The rotation is to the left (common for barrel shifters) and wraps around the bits. The mux2X1 module is parameterized for 1-bit inputs and selects which bit to output based on the select signal.
