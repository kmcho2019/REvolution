Implement an 8-bit barrel shifter that rotates bits based on a 3-bit control signal. The shifting is done in three stages: shift by 4 if ctrl[2] is set, then shift by 2 if ctrl[1] is set, then shift by 1 if ctrl[0] is set. Each stage uses a 2-to-1 multiplexer to select between shifted and original bits. The mux2X1 module will take two inputs and a select signal to output the selected input. The barrel_shifter module will instantiate mux2X1 modules for each bit at each stage, passing along the intermediate results.
