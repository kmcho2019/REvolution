Design a hierarchical 8-bit barrel shifter that rotates the input bits by 1, 2, or 4 positions using a series of 2-to-1 multiplexers. Each stage corresponds to a bit in the control signal (ctrl[2], ctrl[1], ctrl[0]) and either rotates the current intermediate result by the respective shift amount or passes it through unchanged. Implement a `mux2X1` module to select between shifted and original bits per bit position at each stage. The final output is the 8-bit rotated result after all selected shifts.
