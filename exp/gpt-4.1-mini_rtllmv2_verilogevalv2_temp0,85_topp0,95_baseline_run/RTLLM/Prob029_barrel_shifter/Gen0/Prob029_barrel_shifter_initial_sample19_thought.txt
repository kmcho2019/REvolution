Implement an 8-bit barrel shifter that rotates the input bits to the left by the amount specified in the 3-bit control signal. Use three stages of shifting by 4, 2, and 1 bits respectively, controlled by ctrl[2], ctrl[1], and ctrl[0]. Each stage uses 8 instances of a 2-to-1 multiplexer (mux2X1) that select between the shifted and unshifted bits. The output of each stage feeds into the next stage. The mux2X1 module takes inputs a, b and a select signal sel, outputting a if sel=0, else b. The overall design composes these stages sequentially, rotating bits left.
