Implement an 8-bit barrel shifter by performing shifts in three stages corresponding to ctrl bits 2, 1, and 0. Each stage conditionally shifts the input by 4, 2, or 1 bit(s) respectively using mux2X1 modules as 2-to-1 multiplexers. For each stage, muxes select between the original bit and the bit shifted by the stage amount, wrapping around to achieve rotation. The output of each stage feeds into the next, and the final output is assigned to out.
