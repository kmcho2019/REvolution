Implement a barrel shifter module that rotates an 8-bit input by a number of positions specified by a 3-bit control signal. Each control bit enables a stage that rotates the intermediate input by 4, 2, or 1 bit positions respectively. Use a mux2X1 submodule to select between shifted and original bits for each output bit at every stage. The design uses three stages of multiplexers corresponding to each control bit to achieve the rotation in a combinational manner.
