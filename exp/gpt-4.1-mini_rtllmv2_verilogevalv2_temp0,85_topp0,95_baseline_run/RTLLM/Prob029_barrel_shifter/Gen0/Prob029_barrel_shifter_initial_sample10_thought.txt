Implement an 8-bit barrel shifter that rotates the input bits based on a 3-bit control signal. The shift amount is decomposed into stages (4, 2, and 1 bit shifts). Each stage uses 8 instances of a 2-to-1 multiplexer (mux2X1) to select between the current bit and the bit shifted by the stage amount. The mux selects the shifted bit when the corresponding control bit is set, otherwise it passes through the input unchanged. The output of each stage feeds the next stage, resulting in a rotated output after all shifts are applied.
