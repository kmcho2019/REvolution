Implement a barrel shifter module that rotates an 8-bit input based on a 3-bit control signal. The control bits correspond to shifts by 4, 2, and 1 position respectively, using stages of 2-to-1 multiplexers. Each stage conditionally rotates the intermediate value by the required amount if the corresponding control bit is set. The mux2X1 submodule selects either the original bit or the shifted bit based on the select line.
