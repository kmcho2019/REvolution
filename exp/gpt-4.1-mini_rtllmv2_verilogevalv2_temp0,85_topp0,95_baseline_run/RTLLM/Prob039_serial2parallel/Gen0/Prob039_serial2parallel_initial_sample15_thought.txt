Use a 4-bit counter to count the number of valid serial inputs received. On every rising edge of clk, if rst_n is low, reset the counter and output signals. If din_valid is high, shift the serial input bit into a register from the MSB towards LSB. Once 8 bits have been received (counter reaches 8), output the parallel data and set dout_valid to 1 for one cycle. Otherwise, dout_valid is 0.
