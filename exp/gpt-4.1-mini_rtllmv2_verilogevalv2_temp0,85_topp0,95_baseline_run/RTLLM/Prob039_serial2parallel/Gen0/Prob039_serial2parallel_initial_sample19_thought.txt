Implement a synchronous design that samples the serial input bit din_serial on the rising edge of clk when din_valid is high. Use a 4-bit counter cnt to count the number of bits received. Shift the incoming bits into an 8-bit register from MSB to LSB so that the first received bit is at bit 7 and the last received bit at bit 0. When cnt reaches 8, output the parallel data and set dout_valid high for one clock cycle, then reset dout_valid to 0. Reset logic clears the counter, parallel output, and valid output asynchronously with active low rst_n.
