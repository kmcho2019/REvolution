Use a 4-bit counter to count the number of valid serial inputs received. On each clk rising edge, if rst_n is low, reset the counter, dout_parallel, and dout_valid. If din_valid is high, shift the incoming din_serial bit into dout_parallel from MSB to LSB. When the counter reaches 8, set dout_valid to 1 and output the 8-bit parallel data. Otherwise, dout_valid is 0.
