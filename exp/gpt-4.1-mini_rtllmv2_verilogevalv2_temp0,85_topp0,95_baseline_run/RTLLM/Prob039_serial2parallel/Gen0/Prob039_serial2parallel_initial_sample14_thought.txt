Use a 4-bit counter to count the number of valid serial inputs received. On each rising clock edge, if rst_n is low, reset the counter and output signals. If din_valid is high, shift the incoming din_serial bit into an 8-bit shift register from MSB to LSB position. When 8 bits are received (counter reaches 8), output the 8-bit data on dout_parallel and set dout_valid to 1. Otherwise, dout_valid is 0. The counter counts from 0 to 7 during data reception and resets after 8 bits.
