Use a 4-bit counter to count valid serial inputs. On each rising clock edge, if din_valid is high, shift the incoming din_serial bit into an 8-bit shift register from MSB to LSB. When the count reaches 7 (meaning 8 bits have been received, count from 0 to 7), output the 8-bit register as dout_parallel, set dout_valid high for one cycle, and then reset dout_valid until the next 8 bits are received. Use synchronous reset to clear counter and shift register.
