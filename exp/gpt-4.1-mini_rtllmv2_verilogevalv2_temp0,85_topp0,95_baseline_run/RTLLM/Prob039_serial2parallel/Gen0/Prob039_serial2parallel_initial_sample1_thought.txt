Use a 4-bit counter to count the number of valid serial inputs received. On each rising edge of clk, if din_valid is high, shift the incoming din_serial bit into an 8-bit shift register from MSB to LSB. When the counter reaches 8, output the accumulated 8-bit data on dout_parallel and set dout_valid to 1 for one clock cycle. On reset, clear the counter, shift register, and dout_valid.
