Use a 4-bit counter to count valid serial inputs. On each rising clk edge, if rst_n is low, reset counter, output data, and output valid signal. When din_valid is high, shift the incoming din_serial bit into an 8-bit shift register from MSB to LSB (i.e., shift left and insert new bit at LSB), increment the counter. When counter reaches 8, output the parallel data, set dout_valid high for one clock cycle, then reset counter and dout_valid on next cycle.
