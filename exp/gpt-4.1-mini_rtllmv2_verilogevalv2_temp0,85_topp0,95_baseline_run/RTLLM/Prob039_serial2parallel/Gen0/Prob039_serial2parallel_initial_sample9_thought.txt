Use a 4-bit counter to count the number of valid serial inputs received. On each rising clock edge, if reset is inactive and din_valid is high, shift the incoming din_serial bit into an 8-bit shift register from MSB to LSB. Once 8 bits are collected (counter reaches 8), assign the shift register value to dout_parallel and set dout_valid to 1 for one clock cycle; otherwise dout_valid is 0. Reset counter and shift register on reset.
