Use a 4-bit counter to count the number of valid serial bits received. On each rising clock edge, if rst_n is low, reset the counter, output data and output valid signal. Otherwise, if din_valid is high, shift din_serial into an 8-bit shift register from MSB to LSB (shift left) so that the first received bit goes into the most significant bit of the output. Increment the counter. When the counter reaches 8, output the 8-bit parallel data and set dout_valid high for one cycle. Then reset the counter and dout_valid low until next 8 bits are received.
