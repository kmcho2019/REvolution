Implement a frequency divider module named freq_diveven that divides the input clock frequency by an even number specified by the parameter NUM_DIV. The module uses a 4-bit counter to count clock cycles up to half of NUM_DIV - 1. On each positive clock edge, if reset is active (low), it resets counter and output clock. Otherwise, it increments the counter until reaching the limit, then resets counter and toggles the output clock. This ensures clk_div toggles every NUM_DIV/2 input clock cycles, achieving the desired frequency division by an even number.
