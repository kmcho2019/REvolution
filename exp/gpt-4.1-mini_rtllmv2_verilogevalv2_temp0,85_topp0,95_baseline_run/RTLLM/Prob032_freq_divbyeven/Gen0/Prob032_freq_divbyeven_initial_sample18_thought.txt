Implement a frequency divider module named `freq_diveven` that divides the input clock frequency by an even number `NUM_DIV`. Use a 4-bit counter `cnt` to count input clock cycles up to `NUM_DIV/2 - 1`. On reaching this count, reset the counter and toggle the output clock `clk_div`. Initialize both counter and output clock to zero on active-low reset. This creates a divided clock with a period equal to `NUM_DIV` input clock cycles.
