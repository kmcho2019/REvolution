Implement a frequency divider module named freq_diveven with a parameter NUM_DIV specifying the even division factor. The module uses a 4-bit counter to count clock cycles up to (NUM_DIV/2 - 1). On each input clock rising edge, the counter increments until it reaches this limit, then resets and toggles the output clock. The module asynchronously resets both the counter and output clock to zero when rst_n is low.
