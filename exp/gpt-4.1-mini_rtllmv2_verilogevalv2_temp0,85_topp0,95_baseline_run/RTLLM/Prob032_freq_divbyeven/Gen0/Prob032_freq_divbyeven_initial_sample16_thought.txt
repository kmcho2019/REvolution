Implement a frequency divider module named `freq_diveven` with a parameter `NUM_DIV` specifying the even division factor. A 4-bit counter increments on each positive edge of the input clock. When the counter reaches half of `NUM_DIV - 1`, it resets and toggles the output clock `clk_div`. The active-low reset initializes both the counter and output clock to zero. This way, the output clock frequency is input clock frequency divided by `NUM_DIV`.
