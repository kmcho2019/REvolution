Implement a frequency divider module named freq_diveven with a parameter NUM_DIV specifying the even division factor. Use a 4-bit counter to count clock cycles up to (NUM_DIV/2 - 1). On each positive clock edge, increment the counter if it's less than this limit; otherwise, reset the counter and toggle the output clk_div. On reset (rst_n low), clear the counter and clk_div. This divides the input clock by the even number NUM_DIV.
