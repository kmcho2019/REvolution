Implement a frequency divider module named freq_diveven that divides the input clock frequency by an even number NUM_DIV. Use a 4-bit counter to count up to (NUM_DIV/2 - 1), then reset and toggle the output clock signal clk_div. On reset, initialize counter and clk_div to zero. This approach ensures clk_div toggles every NUM_DIV/2 input clock cycles, effectively dividing the input clock frequency by NUM_DIV.
