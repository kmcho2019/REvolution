Implement a synchronous radix-2 division module that supports both signed and unsigned 8-bit division. The module uses a shift register (SR) initialized with the absolute value of the dividend shifted left by one bit and a negated absolute divisor to perform iterative subtraction and shift steps counting up to 8 cycles. The quotient and remainder are extracted from the SR after division completes. Sign correction for quotient and remainder is done at the end if signed division is selected. The module uses a state machine-like approach with counters and control signals to manage operation start, division iterations, and result validity signaling.
