Implement a sequential radix-2 division algorithm for 8-bit inputs supporting signed and unsigned division. On a valid operation request, the module captures the inputs, calculates absolute values if signed, and initializes a shift register with the dividend shifted left by one bit. It negates the divisor's absolute value for subtraction. A counter steps through 8 division iterations, each time shifting, subtracting, and updating the shift register with quotient bits. When done, the remainder and quotient are corrected for sign if the operation is signed. The output packs remainder in upper 8 bits and quotient in lower 8 bits, with res_valid signaling result readiness.
