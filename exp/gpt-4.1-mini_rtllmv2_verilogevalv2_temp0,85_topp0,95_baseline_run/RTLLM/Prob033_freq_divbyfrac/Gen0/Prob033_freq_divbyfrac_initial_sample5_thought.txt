To implement a fractional frequency divider by 3.5 using double-edge clocking, we count 7 input clock cycles (2*MUL2_DIV_CLK = 7) in total. We split these into two unequal periods: 4 and 3 input clocks, alternating each cycle to create the fractional division. We generate two divided clocks: one toggling on the rising edge (normal clk) and the other toggling on the falling edge (phase shifted by half clock). By OR-ing these two signals, we effectively create a clock with half-integer division (3.5) and a more balanced duty cycle. Reset synchronously initializes counters and outputs.
