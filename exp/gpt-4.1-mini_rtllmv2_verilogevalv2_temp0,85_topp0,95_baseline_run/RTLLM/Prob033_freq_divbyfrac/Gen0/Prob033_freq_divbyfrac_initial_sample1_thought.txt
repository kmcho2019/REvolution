To implement a fractional frequency divider by 3.5 using double-edge clocking, we create a 7-cycle counter (MUL2_DIV_CLK = 7) that generates a divided clock with uneven high/low periods (4 and 3 cycles). We generate two versions of this divided clock: one aligned with the rising edge of the input clock and another aligned with the falling edge, effectively phase-shifted by half a clock period. By OR-ing these two phase-shifted clocks, we achieve a fractional frequency output with a better duty cycle and uniform period. The reset signal asynchronously resets the counter and output.
