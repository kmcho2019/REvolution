To implement a fractional frequency divider by 3.5 using double-edge clocking, we count 7 input clock cycles, splitting them unevenly into periods of 4 and 3 clock cycles. We generate two phase-shifted divided clocks: one aligned with the input clock edges, and another shifted by half a clock cycle (achieved by using the inverted clock). By OR-ing these two intermediate clocks, the output clock achieves an effective division by 3.5 with an improved duty cycle. A counter running from 0 to 6 controls when the intermediate clocks toggle. Reset initializes all registers to ensure a known start state.
