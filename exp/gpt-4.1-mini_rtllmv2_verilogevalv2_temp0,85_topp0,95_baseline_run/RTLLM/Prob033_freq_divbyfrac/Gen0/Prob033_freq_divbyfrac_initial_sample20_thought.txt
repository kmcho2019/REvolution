To implement a fractional frequency divider by 3.5 using double-edge clocking, the idea is to create a divide-by-7 counter since 3.5 * 2 = 7. We generate a clock with a period of 7 input clocks but toggle it unevenly: output high for 4 cycles and low for 3 cycles, then repeat.

To achieve a smoother output and better duty cycle, we also generate a phase-shifted version of the divided clock delayed by half an input clock cycle. This can be done by leveraging both the positive and negative edges of the input clock.

- Use a modulo-7 counter triggered on the positive edge to create the first intermediate clock (clk_int1).
- Use a modulo-7 counter triggered on the negative edge to create the second intermediate clock (clk_int2), effectively shifting the phase by half a clock period.
- Both intermediate clocks have the same 4-high, 3-low pattern but are phase-shifted.
- Finally, OR the two intermediate clocks to get the fractional clock output clk_div, which has a stable 3.5 division and improved duty cycle.

The reset is active low and synchronous to the clk.
