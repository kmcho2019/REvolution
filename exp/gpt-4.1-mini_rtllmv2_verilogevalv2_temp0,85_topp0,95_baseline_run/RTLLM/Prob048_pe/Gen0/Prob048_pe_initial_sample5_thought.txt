Implement a 32-bit multiplying accumulator module named "pe" with synchronous reset and clock. Use a 32-bit register to hold the accumulated sum. On each positive clock edge, if reset is asserted (high), clear the accumulator register to zero; otherwise, multiply inputs a and b and add the product to the accumulator register. Since multiplication of two 32-bit numbers can yield up to 64-bit results, but the output register is defined as 32-bit, the multiplication result will be truncated to 32 bits (the lower 32 bits). The output port c reflects the current value of the accumulator register.
