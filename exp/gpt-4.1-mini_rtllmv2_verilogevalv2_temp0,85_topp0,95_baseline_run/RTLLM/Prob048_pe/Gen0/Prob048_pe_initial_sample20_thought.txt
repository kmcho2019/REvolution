Implement a synchronous multiplying accumulator (MAC) module named "pe". It has inputs clk, rst, and two 32-bit operands a and b. On each rising edge of clk, if rst is high, the accumulator register c is reset to 0. Otherwise, multiply a and b, then add the product to the accumulator c. The output c is the current value of the accumulator. Handle the multiplication result as 64-bit to avoid overflow during accumulation, but since output c is 32-bit, truncate or wrap the result accordingly.
