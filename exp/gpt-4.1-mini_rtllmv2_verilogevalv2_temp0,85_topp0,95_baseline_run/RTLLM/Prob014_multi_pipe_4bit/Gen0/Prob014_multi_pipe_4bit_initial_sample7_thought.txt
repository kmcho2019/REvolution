To implement a 4-bit unsigned pipelined multiplier with two levels of registers for intermediate values, we first extend the inputs by size bits of zeros at the MSB side. Then, using a generate block, we compute partial products for each bit of mul_b by shifting mul_a appropriately or setting zero if the bit is 0. In the first pipeline stage (first set of registers), we sum partial products for the first half bits of mul_b. In the second pipeline stage (second set of registers), we sum partial products for the remaining bits plus the output from the first stage. Finally, in the last always block, the output is updated with the sum from the second stage. All registers reset asynchronously with rst_n active low.
