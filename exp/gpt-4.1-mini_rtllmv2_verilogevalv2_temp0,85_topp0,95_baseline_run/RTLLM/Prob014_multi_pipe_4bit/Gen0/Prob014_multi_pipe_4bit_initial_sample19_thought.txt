Implement a 4-bit unsigned pipeline multiplier with two levels of registers to store intermediate sums and control the multiplication process. First, extend the inputs by size zeros at the MSB side. Then, generate partial products for each bit of the multiplier: if the bit is 1, multiplicand shifted left by i, else zero. Add partial products in two pipeline stages using registers: first stage sums half the partial products, second stage sums the rest plus the first stage result. Finally, output the final product from the second stage register. The design uses synchronous reset and clock. The pipeline stages ensure each addition is done in separate clock cycles.
