Use a register to temporarily store the first 8-bit data input (data_lock) when valid_in is high and no previous data is locked. Use a flag to indicate that data_lock contains a valid first byte. When the second 8-bit data arrives (valid_in high and flag set), concatenate data_lock and the new data_in to form the 16-bit data_out. valid_out is asserted in the next clock cycle after the second data arrives. Reset clears all registers and flags.
