Use a flag register to store the first valid 8-bit input data in data_lock. When the first valid data arrives, store it in data_lock and set the flag. When the second valid data arrives, concatenate data_lock (higher 8 bits) and current data_in (lower 8 bits) to form data_out and assert valid_out in the next clock cycle. After producing data_out, clear the flag and data_lock to prepare for the next pair of inputs. Reset clears all registers.
