Use a flag and a temporary register (data_lock) to store the first 8-bit input data when valid_in is high. When the next valid_in arrives, concatenate the stored data_lock (higher 8 bits) with the new data_in (lower 8 bits) and assign it to data_out in the next clock cycle with valid_out asserted. Reset clears all registers. valid_out and data_out update only one cycle after receiving the second data input.
