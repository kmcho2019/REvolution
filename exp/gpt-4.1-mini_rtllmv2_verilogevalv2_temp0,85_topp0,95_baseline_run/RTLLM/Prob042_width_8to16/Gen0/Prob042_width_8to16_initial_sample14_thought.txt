Use a flag and a temporary register (data_lock) to store the first 8-bit input. When a valid input arrives and the flag is not set, store the data and set the flag. When the next valid input arrives and the flag is set, concatenate the stored data (in the higher 8 bits) with the new data (lower 8 bits) and update data_out. The valid_out will be asserted in the cycle after both inputs are received. Reset clears all registers.
