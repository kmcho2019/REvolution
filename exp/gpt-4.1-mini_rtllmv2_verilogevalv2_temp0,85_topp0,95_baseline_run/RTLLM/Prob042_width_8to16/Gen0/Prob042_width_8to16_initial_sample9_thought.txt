To implement the width conversion from 8-bit input to 16-bit output, I will use a flag to track whether the first 8-bit input has been received and stored in a temporary register (data_lock). Upon arrival of the second valid input, I concatenate the stored first data (in the higher 8 bits) with the new data (in the lower 8 bits) and output the 16-bit data along with a valid signal. The output valid_out and data_out are generated in the cycle after the second input is received to meet the requirement. The design is synchronous with posedge clk and asynchronous active-low reset rst_n. On reset, all registers and flags are cleared.
