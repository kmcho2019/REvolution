Use a flag to indicate whether we have stored the first 8-bit input. When valid_in is high, if the flag is not set, store data_in in data_lock and set the flag. If the flag is set and valid_in is high again, concatenate data_lock and data_in to form the 16-bit data_out, assert valid_out in the next clock cycle, then clear the flag. valid_out and data_out are registered outputs delayed by one clock cycle after the second input data arrives. On reset, clear all registers.
