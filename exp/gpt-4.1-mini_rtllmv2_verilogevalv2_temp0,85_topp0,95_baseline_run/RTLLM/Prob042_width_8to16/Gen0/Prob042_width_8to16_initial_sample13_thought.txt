To implement the 8-bit to 16-bit width conversion, we use a register (data_lock) to temporarily store the first arriving 8-bit data when valid_in is high. A flag register keeps track of whether we have stored one data already (flag=1) or not (flag=0). On each valid_in, if flag is 0, we store data_in into data_lock and set flag=1. When the next valid_in arrives and flag=1, we concatenate data_lock (high 8 bits) with data_in (low 8 bits) and update data_out, setting valid_out in the next clock cycle after the concatenation. We then clear the flag to wait for the next two inputs. The outputs valid_out and data_out are registered and updated on posedge clk or negedge rst_n. On reset, all registers are cleared.
