Use a flag and a temporary register data_lock to store the first 8-bit input when valid_in is high and the flag is not set. When the next valid 8-bit input arrives with flag set, concatenate data_lock (higher 8 bits) and the current data_in (lower 8 bits) to form the 16-bit data_out. The valid_out is asserted in the next clock cycle after this concatenation. On reset, clear all registers. This design ensures the first arriving 8-bit data goes to the higher bits of data_out, and valid_out/data_out are generated only after two data inputs.
