Use an internal register data_lock to store the first valid 8-bit input. Use a flag to indicate if data_lock holds valid data. On each valid input, if flag is not set, store data_in in data_lock and set the flag; if flag is set, concatenate data_lock and data_in to form data_out and assert valid_out. valid_out and data_out are registered outputs, updated one clock cycle after the second valid input. On reset, clear data_lock, data_out, flag, and valid_out.
