To detect edges on a slowly changing 1-bit signal 'a', sample 'a' on each clock cycle and compare it to its previous value. A rising edge occurs when previous 'a' is 0 and current 'a' is 1; a falling edge occurs when previous 'a' is 1 and current 'a' is 0. On detecting an edge, set the corresponding output ('rise' or 'down') to 1 on the next clock cycle and hold it at 1 until the same edge type occurs again, then keep it high again, effectively latching the edge detection. Since the outputs must be set to 1 on the next clock and held until the same edge reappears, we'll implement flip-flops for 'rise' and 'down' outputs that set on edges and are cleared on the next occurrence of the same edge. On reset, outputs are cleared.
