To detect edges on signal a, we will register the previous state of a on each clock cycle. On each positive edge of the clock, we compare the current a with the previous a to detect rising and falling edges. If the previous a was 0 and current a is 1, set rise to 1 for one clock cycle. If previous a was 1 and current a is 0, set down to 1 for one clock cycle. Otherwise, both rise and down are 0. On reset, initialize previous a to 0 and outputs to 0.
