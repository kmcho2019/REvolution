Use a register to store the previous value of input signal 'a'. On each rising clock edge, compare the current value of 'a' with its previous value. If the current is 1 and previous is 0, it means a rising edge occurred and 'rise' is set to 1 for one clock cycle. If the current is 0 and previous is 1, it means a falling edge occurred and 'down' is set to 1 for one clock cycle. Both outputs are synchronized to the clock and reset asynchronously with active low reset 'rst_n'.
