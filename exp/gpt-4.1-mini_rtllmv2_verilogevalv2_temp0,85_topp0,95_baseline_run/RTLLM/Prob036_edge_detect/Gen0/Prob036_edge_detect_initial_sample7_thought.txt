To detect edges on the input signal `a`, sample it on each clock cycle and compare the current sampled value with the previous sampled value. A rising edge is detected when the previous value is 0 and current is 1, and a falling edge when previous is 1 and current is 0. The output signals `rise` and `down` are set to 1 for exactly one clock cycle immediately after the edge is detected, then return to 0 until a new edge occurs. Use synchronous reset to initialize previous state and outputs.
