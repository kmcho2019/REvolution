To detect edges, we need to store the previous value of input 'a' on each clock cycle. On the next clock, compare the previous value with the current 'a' value. If previous 'a' was 0 and current 'a' is 1, it's a rising edge; if previous 'a' was 1 and current 'a' is 0, it's a falling edge. The output signals rise and down will be set to 1 for exactly one clock cycle immediately after the edge is detected and will be 0 otherwise. The signals are reset asynchronously with rst_n.
