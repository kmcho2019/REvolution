To detect edges on a 1-bit signal 'a', store its previous value in a register on each clock cycle. Compare the current value with the previous value to detect rising and falling edges. If 'a' changes from 0 to 1, set 'rise' to 1 on the next clock cycle; if 'a' changes from 1 to 0, set 'down' to 1 on the next clock cycle. Otherwise, keep both outputs at 0. Use synchronous reset to initialize the registers.
