To detect edges on the input signal 'a', store its previous value in a register updated on the clock's positive edge. A rising edge occurs when previous 'a' is 0 and current 'a' is 1; a falling edge occurs when previous 'a' is 1 and current 'a' is 0. The outputs 'rise' and 'down' are set to 1 for one clock cycle following the detection of their respective edges, then return to 0. On reset, registers are cleared.
