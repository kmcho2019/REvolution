To detect edges of a 1-bit signal "a", store its previous value in a register on each clock cycle. Compare the current and previous values of "a" to detect rising (0->1) or falling (1->0) edges. On detecting a rising edge, set the "rise" output to 1 for one clock cycle; similarly for a falling edge, set "down" to 1 for one clock cycle. Both outputs reset to 0 otherwise. The outputs are synchronized with clk and reset by rst_n (active low).
