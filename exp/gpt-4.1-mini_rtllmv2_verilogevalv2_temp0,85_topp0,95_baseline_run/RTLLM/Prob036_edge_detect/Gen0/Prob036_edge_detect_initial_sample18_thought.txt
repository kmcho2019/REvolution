To detect edges of the input signal 'a', we sample 'a' at each clock edge and compare it with its previous value stored in a register. A rising edge is when the previous value was 0 and the current value is 1. A falling edge is when the previous value was 1 and the current value is 0. The output signals 'rise' and 'down' are set to 1 on the clock cycle following the detection of the respective edges, and remain 1 until the same edge occurs again. This means that once set, the outputs hold their value until the particular edge re-occurs, at which point they toggle or reset accordingly. The design uses synchronous reset and is clocked on the positive edge of clk.
