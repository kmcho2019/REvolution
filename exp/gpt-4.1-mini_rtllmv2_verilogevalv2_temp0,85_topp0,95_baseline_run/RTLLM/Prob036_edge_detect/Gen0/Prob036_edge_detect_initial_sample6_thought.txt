To detect rising and falling edges of a 1-bit input signal 'a', I will store the previous value of 'a' in a register. On each positive clock edge, I will compare the current 'a' with the previous value to detect edges. If the previous value was 0 and current 'a' is 1, it's a rising edge; if previous was 1 and current 'a' is 0, it's a falling edge. The outputs 'rise' and 'down' will be set to 1 in the clock cycle immediately after the edge is detected, and will remain 1 until the next corresponding edge is detected, at which point they will again be set to 1. Otherwise, the output remains unchanged. On reset, all registers and outputs will be cleared.
