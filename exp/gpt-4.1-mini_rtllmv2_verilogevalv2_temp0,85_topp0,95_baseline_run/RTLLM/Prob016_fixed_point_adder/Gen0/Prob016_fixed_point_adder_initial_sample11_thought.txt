Implement a parameterized fixed-point adder that handles signed fixed-point numbers in two's complement format. 
The module uses parameters N and Q to define total bits and fractional bits. The MSB is the sign bit.

The addition logic depends on the sign bits of inputs a and b:
- If both signs are equal, add their absolute values (magnitude) and set the output sign to the common sign.
- If signs differ, subtract smaller magnitude from larger magnitude, and set the sign of the result to that of the operand with larger magnitude.
- Magnitude is calculated as the absolute value of the two's complement input.
- After computing magnitude results, convert back to two's complement format with the computed sign.
- Use an internal register 'res' to hold the result.
- Since the result is fixed width N, handle overflow by saturating or wrapping as default two's complement arithmetic (wrapping).
- Output the result as two's complement fixed-point number with the same N bits.

This approach ensures correct fixed-point addition for signed numbers with fractional bits.
