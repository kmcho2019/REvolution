Implement a parameterized fixed-point adder with total bit-width N and fractional bits Q. Since the fixed-point format uses signed representation (MSB as sign bit), the addition should be done considering sign bits and absolute values. For addition: if signs are the same, add absolute values and keep sign. For subtraction (signs differ), subtract smaller absolute value from larger, set the sign accordingly. Use internal registers for intermediate results and assign output accordingly. Overflow is naturally handled by fitting the result within N bits, but care is taken with sign bit setting. The module is fully combinational.
