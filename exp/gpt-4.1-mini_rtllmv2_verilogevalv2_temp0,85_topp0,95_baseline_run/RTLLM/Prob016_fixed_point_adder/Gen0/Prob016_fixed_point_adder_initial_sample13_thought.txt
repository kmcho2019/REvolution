Implement a parameterized fixed-point adder module with inputs a and b of width N, including Q fractional bits.  
Check if sign bits (MSB) of a and b are equal.  
- If equal, add absolute values and keep sign bit.  
- If different, subtract smaller absolute value from larger, assign sign bit accordingly.  
Implement absolute value by zeroing the MSB and treating the rest as magnitude.  
Store result in res register, output res.  
Handle overflow by truncating to N bits; since fixed-point addition with same precision, no special scaling needed.
