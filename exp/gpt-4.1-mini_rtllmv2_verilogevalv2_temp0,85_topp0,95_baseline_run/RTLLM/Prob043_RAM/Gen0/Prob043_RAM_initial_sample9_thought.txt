Implement a dual-port RAM with synchronous reset for both read and write operations. The RAM has a depth of 8 (so address width is 3 bits), each location is 6 bits wide. On reset, clear all RAM contents to zero. Writing occurs when write_en is asserted, writing write_data to write_addr. Reading occurs when read_en is asserted, outputting the contents at read_addr. If read_en is low, read_data is zero. Both read and write can happen simultaneously.
