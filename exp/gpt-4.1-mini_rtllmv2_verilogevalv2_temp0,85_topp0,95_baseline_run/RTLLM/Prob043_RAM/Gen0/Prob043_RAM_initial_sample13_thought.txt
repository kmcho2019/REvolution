Implement a dual-port RAM with separate read and write ports, each controlled by enable signals. The RAM has a depth of 8 and a data width of 6 bits. The RAM is implemented as a reg array of [WIDTH-1:0] with DEPTH entries. On reset, all memory locations are cleared to zero. On write enable, the write_data is stored into RAM at write_addr. On read enable, the data at read_addr is output on read_data; otherwise, read_data is zero. Both operations are synchronous to clk and reset is active-low asynchronous.
