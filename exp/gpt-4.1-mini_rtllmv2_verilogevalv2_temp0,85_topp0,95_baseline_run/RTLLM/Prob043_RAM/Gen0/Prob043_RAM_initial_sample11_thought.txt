Implement a synchronous dual-port RAM with separate read and write ports. On reset, initialize all RAM locations to zero. On each clock edge, if write_en is asserted, write write_data to RAM at write_addr. Simultaneously, if read_en is asserted, output the data from RAM at read_addr to read_data; otherwise, clear read_data to zero. Use parameters WIDTH=6 and DEPTH=8 for data width and memory depth respectively.
