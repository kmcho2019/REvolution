Implement a synchronous dual-port RAM with separate read and write ports. The RAM depth is 8 and width 6 bits. On reset, initialize all RAM contents to zero. Use two always blocks clocked on posedge clk and negedge rst_n for synchronous reset. The first block handles writes when write_en is asserted, writing write_data to write_addr. The second block handles reads when read_en is asserted, outputting data at read_addr; otherwise output zero.
