Implement a dual-port RAM with synchronous write and read operations. On reset, initialize the entire RAM to zeros. On each clock cycle, if write_en is high, write the write_data to the specified write_addr; if read_en is high, read the data from the specified read_addr and output it on read_data, otherwise output zero. The RAM depth is 8, width is 6 bits, and the RAM array is declared as reg [WIDTH-1:0] RAM [DEPTH-1:0]. The reset is active low, and both write and read operations are synchronous.
