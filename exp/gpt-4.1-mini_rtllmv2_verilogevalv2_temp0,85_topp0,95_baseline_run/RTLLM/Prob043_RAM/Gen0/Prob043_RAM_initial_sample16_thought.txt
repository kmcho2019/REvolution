Implement a dual-port RAM with synchronous reset. The RAM has 8 locations (DEPTH=8) each 6 bits wide (WIDTH=6). The RAM array is defined as reg [WIDTH-1:0] RAM [0:DEPTH-1] (depth of 8). On reset (active low), all locations are cleared to zero. Write occurs on posedge clk if write_en is high, writing write_data to write_addr. Read occurs on posedge clk if read_en is high, outputting RAM[read_addr] to read_data; otherwise, read_data is zeroed. Both operations can happen simultaneously.
