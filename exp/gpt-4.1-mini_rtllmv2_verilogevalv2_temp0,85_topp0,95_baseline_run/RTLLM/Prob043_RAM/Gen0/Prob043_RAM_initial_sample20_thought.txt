Implement a dual-port RAM with depth 8 and width 6 bits. Use a register array with 8 entries, each 6 bits wide, initialized to zero on reset. Write operation occurs on clock edge when write_en is high, writing write_data to write_addr. Read operation occurs on clock edge when read_en is high, reading data at read_addr and outputting on read_data; otherwise, read_data is cleared to zero. The reset is active low and synchronous with clock edges.
