Implement a dual-port RAM with depth 8 and width 6 bits, supporting simultaneous read and write. Use synchronous reset (active low) to clear the entire memory array and the read_data output. The RAM array is defined as reg [WIDTH-1:0] RAM [DEPTH-1:0] with initialization to zero on reset. The write operation writes to RAM at write_addr on write_en, and the read operation outputs read_data from RAM at read_addr on read_en, otherwise zero.
