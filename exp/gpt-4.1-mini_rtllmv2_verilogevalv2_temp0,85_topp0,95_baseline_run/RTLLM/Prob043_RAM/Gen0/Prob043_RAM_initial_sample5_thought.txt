Implement a synchronous dual-port RAM with separate read and write ports. The RAM has a depth of 8 and width of 6 bits. On reset, initialize all 8 memory locations to zero. Write operation occurs on the positive clock edge when write_en is high, writing write_data to write_addr. Read operation occurs on the positive clock edge when read_en is high, outputting data at read_addr to read_data; otherwise, read_data is cleared to zero. The module supports simultaneous read and write.
