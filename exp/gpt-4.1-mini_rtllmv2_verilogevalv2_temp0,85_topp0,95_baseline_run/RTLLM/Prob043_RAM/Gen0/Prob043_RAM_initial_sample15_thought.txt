Implement a synchronous dual-port RAM with separate read and write ports. On reset, initialize all 8 locations to zero. Use a reg array of depth 8 and width 6 bits. For write operations, on clk posedge and write_en asserted, write the input data to the RAM at the write address. For read operations, on clk posedge and read_en asserted, output the RAM data at the read address; otherwise output zero. Both read and write happen in the same clock cycle if enabled.
