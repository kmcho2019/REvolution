Implement a synchronous dual-port RAM with separate read and write ports. The RAM has a depth of 8 and a width of 6 bits. On reset, clear all RAM locations and output data. Use two always blocks triggered by clk and rst_n for read and write operations. Write operations occur when write_en is high, writing data at write_addr. Read operations occur when read_en is high, outputting data at read_addr; otherwise, output is cleared.
