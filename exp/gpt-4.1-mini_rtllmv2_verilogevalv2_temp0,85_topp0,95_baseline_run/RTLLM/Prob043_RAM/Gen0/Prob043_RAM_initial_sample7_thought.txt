Implement a synchronous dual-port RAM with separate read and write ports. On reset, initialize all 8 memory locations to zero. The RAM depth is 8 with width 6 bits. The write operation writes data to the RAM on the rising clock edge when write_en is high. The read operation reads data synchronously on the rising clock edge when read_en is high; otherwise, outputs zero. The read and write operations can happen simultaneously. Use two separate always blocks for read and write operations triggered on posedge clk or negedge rst_n.
