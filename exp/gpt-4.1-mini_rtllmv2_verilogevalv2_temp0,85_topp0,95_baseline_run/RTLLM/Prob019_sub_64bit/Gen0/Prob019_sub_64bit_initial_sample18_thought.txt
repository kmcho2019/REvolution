To detect overflow in signed subtraction:  
- Extract the sign bits of A, B, and the result (MSB of each 64-bit vector).  
- Overflow occurs if A is positive, B is negative, but result is negative (positive overflow).  
- Or if A is negative, B is positive, but result is positive (negative overflow).  
Set the overflow output accordingly.  
Output the subtraction result along with the overflow flag.
