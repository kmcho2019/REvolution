Implement a 64-bit subtractor by subtracting B from A. Since A and B represent signed 64-bit integers, overflow occurs if the sign of the result is inconsistent with the signs of the operands under subtraction rules: 
- Positive overflow if A is positive, B is negative, but result is negative
- Negative overflow if A is negative, B is positive, but result is positive
Use the most significant bit (bit 63) to check sign bits of A, B, and result. Set the overflow flag accordingly.
