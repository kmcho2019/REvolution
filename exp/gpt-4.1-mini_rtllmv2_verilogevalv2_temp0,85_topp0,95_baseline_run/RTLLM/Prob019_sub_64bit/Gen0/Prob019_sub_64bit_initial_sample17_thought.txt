Implement a 64-bit subtractor that computes the difference (A - B) and checks for signed overflow. The subtraction is straightforward: result = A - B. For overflow detection in signed subtraction: 
- Positive overflow: A is positive, B is negative, and the result is negative.
- Negative overflow: A is negative, B is positive, and the result is positive.
Use the MSB (sign bit) of A, B, and result to detect these conditions. Output the result and the overflow flag accordingly.
