Implement an 8-bit Radix-4 Booth multiplier as specified. The module uses a 16-bit multiplier and multiplicand registers which are sign-extended from the inputs. On reset, these registers are initialized. A 5-bit counter tracks the number of steps (up to 16). On each clock cycle (if not reset), if ctr<16, the multiplicand is left-shifted by one, and if the current bit of multiplier[ctr] is 1, the product register accumulates multiplicand. The product output is registered and a ready signal is set once multiplication is complete.
