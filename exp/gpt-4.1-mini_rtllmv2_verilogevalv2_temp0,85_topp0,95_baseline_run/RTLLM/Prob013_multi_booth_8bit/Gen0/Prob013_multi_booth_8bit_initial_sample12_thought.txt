Implement a Radix-4 Booth multiplier for 8-bit inputs using a sequential approach. On reset, sign-extend inputs 'a' and 'b' into 16-bit registers 'multiplicand' and 'multiplier'. Use a 5-bit counter to step through the 16-bit multiplication process bit-by-bit. On each clock cycle when not reset and counter < 16, check the current bit of 'multiplier'. If it is 1, add 'multiplicand' to product register 'p'. Shift 'multiplicand' left by 1 to prepare for the next bit. Increment counter. When counter reaches 16, assert 'rdy'. This matches the description given, even though true Radix-4 Booth encoding typically processes 2 bits per cycle; here the operation is done bit-wise as described.
