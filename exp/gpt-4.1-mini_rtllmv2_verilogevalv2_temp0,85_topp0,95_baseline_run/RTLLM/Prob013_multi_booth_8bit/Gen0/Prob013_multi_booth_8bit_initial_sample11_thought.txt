Implement a radix-4 Booth multiplier that uses a 5-bit counter to process up to 16 steps. On reset, extend inputs a and b to 16 bits with sign extension and initialize multiplicand and multiplier registers. On each clock edge, if not reset and counter < 16, shift multiplicand left by 1, and if the current bit of multiplier is 1, add multiplicand to product. Increment counter. When counter reaches 16, set ready signal to 1. The product output is stored in a 16-bit register. This design uses synchronous reset and operates sequentially.
