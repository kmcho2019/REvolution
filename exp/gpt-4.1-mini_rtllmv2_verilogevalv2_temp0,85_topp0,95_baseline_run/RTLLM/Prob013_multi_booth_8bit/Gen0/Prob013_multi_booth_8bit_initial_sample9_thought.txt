Implement a synchronous Radix-4 Booth multiplier for 8-bit inputs. On reset, sign-extend inputs into 16-bit multiplicand and multiplier registers and clear control signals. On each clock cycle, if counter < 16, shift the multiplicand left by 1 and, depending on the current multiplier bit, add the multiplicand to the partial product. Increment counter each cycle. When counter reaches 16, set ready signal to indicate completion. Output the final product. This matches the described control flow and bit widths.
