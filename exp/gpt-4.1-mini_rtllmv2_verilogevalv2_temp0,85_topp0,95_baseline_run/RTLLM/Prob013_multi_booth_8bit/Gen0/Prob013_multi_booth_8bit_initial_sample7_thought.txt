Implement a Radix-4 Booth multiplier for 8-bit inputs using a sequential approach with a clock and reset. The multiplicand and multiplier are sign-extended to 16 bits. A 5-bit counter controls the number of iterations (16 steps to cover the bits). On each clock cycle, if reset is high, initialize the multiplicand and multiplier registers; else if the counter is less than 16, process the current bit of the multiplier: if the bit is 1, add the multiplicand to the product register. Then shift the multiplicand left by 1 and increment the counter. When the counter reaches 16, assert the ready signal. The product is held in a 16-bit register output. Note that the original prompt's Booth algorithm description is simplified and slightly non-standard (Radix-4 typically works on two bits per step), but the implementation follows the prompt's instructions faithfully.
