Implement an 8-bit Radix-4 Booth multiplier using a sequential approach. On reset, sign-extend inputs a and b into 16-bit multiplicand and multiplier registers. Use a 5-bit counter to track progress up to 16 steps, each step processing one bit of the multiplier. On each clock cycle, if counter < 16, check multiplier[ctr]; if it is 1, add multiplicand to the product; then shift multiplicand left by 1 and increment counter. When counter reaches 16, assert the ready signal. The product register accumulates the final 16-bit product output.
