Implement an 8-bit Radix-4 Booth multiplier that multiplies inputs a and b to produce a 16-bit product p. On reset, initialize the multiplicand and multiplier registers with sign-extended inputs. Use a 5-bit counter to control iteration steps. In each clock cycle, if the counter is less than 16, check the current bit of the multiplier; if it is 1, add the multiplicand to the product. Then left shift the multiplicand to align for the next partial product and increment the counter. When the counter reaches 16, set the ready signal high. This approach corresponds to a simplified bit-by-bit Booth multiplication (though the problem statement's radix-4 mention is ambiguous, the detailed instructions guide a bitwise approach).
