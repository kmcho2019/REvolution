Implement an 8-bit Radix-4 Booth multiplier using synchronous logic with a counter to control the multiplication steps. On reset, initialize the multiplicand and multiplier registers (sign-extended 16-bit versions of inputs a and b), the product register p, the counter ctr, and clear the ready signal. On each clock cycle, if ctr < 16, shift the multiplicand left by 1, check the current multiplier bit multiplier[ctr], and if it is 1, add the multiplicand to the product. Increment the counter each cycle. When ctr reaches 16, set rdy to 1 to indicate the operation is complete.
