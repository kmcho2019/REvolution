Implement three D flip-flops with asynchronous reset to zero. Each flip-flop's D input is driven by a two-input gate with input x and the flip-flop's output or complemented output as the second input: 
- DFF1: D = x XOR Q1
- DFF2: D = x AND ~Q2
- DFF3: D = x OR ~Q3

The outputs Q1, Q2, Q3 feed a 3-input NOR gate to produce output z. The flip-flops update on the rising edge of clk and are reset to zero initially.
