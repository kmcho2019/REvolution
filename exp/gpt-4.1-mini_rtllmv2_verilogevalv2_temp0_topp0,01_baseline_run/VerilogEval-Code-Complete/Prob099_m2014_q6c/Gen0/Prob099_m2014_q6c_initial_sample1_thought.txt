We have a one-hot encoded state machine with states A to F assigned to bits y[1] to y[6] as follows:
A = y[1], B = y[2], C = y[3], D = y[4], E = y[5], F = y[6].

We want to find the next-state signals Y2 (for B) and Y4 (for D) based on the current state y and input w.

From the state transitions:

- Next state B (Y2) is active when:
  - From A (y[1]) with input 0: A(0) -> B
  - From no other states to B

So Y2 = (y[1] & ~w)

- Next state D (Y4) is active when:
  - From B (y[2]) with input 1: B(1) -> D
  - From C (y[3]) with input 1: C(1) -> D
  - From E (y[5]) with input 1: E(1) -> D
  - From F (y[6]) with input 1: F(1) -> D

So Y4 = (y[2] & w) | (y[3] & w) | (y[5] & w) | (y[6] & w)
     = w & (y[2] | y[3] | y[5] | y[6])
