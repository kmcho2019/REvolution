Implement a 3-state Mealy FSM to detect the sequence "101" on input x. The states represent how much of the sequence has been matched so far:
- S0: no match yet
- S1: matched '1'
- S2: matched '10'

On each clock's positive edge, transition between states based on input x. Output z is asserted when the sequence "101" is detected, i.e., when in S2 and input x=1. The FSM supports overlapping sequences by transitioning appropriately after detection. The asynchronous reset is active low and triggers on the negative edge of aresetn.
