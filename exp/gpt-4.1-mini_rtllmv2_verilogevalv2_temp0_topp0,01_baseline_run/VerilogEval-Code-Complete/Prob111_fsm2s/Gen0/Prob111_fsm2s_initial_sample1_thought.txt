Implement a Moore state machine with two states: OFF and ON. The output depends only on the current state (OFF=0, ON=1). On synchronous reset (active high), the state goes to OFF. The state transitions are:
- From OFF: if j=0 stay OFF, if j=1 go to ON
- From ON: if k=0 stay ON, if k=1 go to OFF
Use a state register updated on the rising edge of clk and synchronous reset.
