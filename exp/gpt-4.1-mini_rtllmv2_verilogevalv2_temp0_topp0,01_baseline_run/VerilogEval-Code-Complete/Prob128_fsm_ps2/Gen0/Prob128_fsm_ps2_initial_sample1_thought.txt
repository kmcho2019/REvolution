Implement a 2-bit FSM with states: IDLE (waiting for first byte with in[3]=1), BYTE2 (waiting for second byte), BYTE3 (waiting for third byte). On reset, go to IDLE. In IDLE, ignore bytes until in[3]=1, then move to BYTE2. In BYTE2, accept next byte and move to BYTE3. In BYTE3, accept next byte and assert done in the next cycle, then return to IDLE. The done signal is a one-cycle pulse after receiving the third byte.
