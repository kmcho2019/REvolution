Design a synchronous FSM with states representing each step of the sequence and output conditions. Use a synchronous active-low reset to initialize the FSM to state A. After reset is de-asserted, output f=1 for one clock cycle, then monitor x for the sequence 1,0,1. When detected, set g=1 and enter a state monitoring y for up to two clock cycles. If y=1 within two cycles, keep g=1 permanently; otherwise, set g=0 permanently. Outputs f and g are registered and updated on clock edges.
