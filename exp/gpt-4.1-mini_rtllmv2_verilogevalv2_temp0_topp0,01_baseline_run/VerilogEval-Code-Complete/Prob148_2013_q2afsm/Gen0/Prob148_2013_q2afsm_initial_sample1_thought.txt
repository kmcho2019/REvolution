Implement a 4-state FSM with states A, B, C, D encoded as 2-bit values. On synchronous active-low reset, state resets to A. The state transition logic is in a combinational always block, based on current state and inputs r[3:1]. The outputs g[3:1] are assigned based on the current state: g1=1 in B, g2=1 in C, g3=1 in D, else 0. Priority is r1 > r2 > r3 when in state A. When granted, the FSM stays in the grant state as long as the corresponding request is asserted; otherwise, it returns to A.
