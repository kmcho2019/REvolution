We will implement a Moore FSM with states representing the Lemming's behavior and direction:

States:
- WALK_LEFT
- WALK_RIGHT
- FALL_LEFT
- FALL_RIGHT
- DIG_LEFT
- DIG_RIGHT

The direction is encoded in the state. Outputs depend only on the state.

Transitions:
- On reset, go to WALK_LEFT.
- If ground=0, transition from any walking or digging state to FALL state with the same direction.
- If falling and ground=1, transition back to walking state with the same direction.
- If digging and ground=0, transition to falling state with the same direction.
- If walking and dig=1 and ground=1, transition to digging state with the same direction.
- If walking and bumped (bump_left or bump_right), switch direction.
- Bumps and dig commands are ignored while falling or digging.
- Falling has highest priority, then digging, then bump direction changes.

Outputs:
- walk_left = 1 in WALK_LEFT, FALL_LEFT=0, DIG_LEFT=0 (only walking states)
- walk_right = 1 in WALK_RIGHT
- aaah = 1 in FALL_LEFT or FALL_RIGHT
- digging = 1 in DIG_LEFT or DIG_RIGHT

We will implement the FSM with synchronous clock and asynchronous positive edge reset.
