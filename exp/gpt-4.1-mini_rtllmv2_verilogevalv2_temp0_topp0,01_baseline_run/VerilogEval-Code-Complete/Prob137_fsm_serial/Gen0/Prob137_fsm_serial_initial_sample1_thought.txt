Design a finite state machine with the following states: IDLE, START, DATA (8 bits), STOP, and WAIT_STOP. The FSM starts in IDLE, waiting for a start bit (0). Upon detecting a start bit, it moves to START, then samples 8 data bits (LSB first) in DATA state, counting bits received. After 8 bits, it expects a stop bit (1) in STOP state. If the stop bit is correct, it asserts 'done' for one cycle and returns to IDLE. If the stop bit is incorrect, it moves to WAIT_STOP state, where it waits until it sees a stop bit (1) before returning to IDLE. The FSM uses synchronous reset to return to IDLE. The 'done' output is asserted for one clock cycle when a byte is correctly received.
