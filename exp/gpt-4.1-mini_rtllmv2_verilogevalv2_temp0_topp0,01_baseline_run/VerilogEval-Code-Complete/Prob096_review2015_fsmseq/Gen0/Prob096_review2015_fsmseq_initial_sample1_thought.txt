Design a Moore FSM with states representing how much of the sequence 1101 has been matched so far. The states are: S0 (no match), S1 (matched '1'), S2 (matched '11'), S3 (matched '110'), and S4 (matched '1101'). When the FSM reaches S4, set start_shifting to 1 and keep it set until reset. The reset is synchronous and active high. The FSM transitions on each clock cycle based on the input data bit.
