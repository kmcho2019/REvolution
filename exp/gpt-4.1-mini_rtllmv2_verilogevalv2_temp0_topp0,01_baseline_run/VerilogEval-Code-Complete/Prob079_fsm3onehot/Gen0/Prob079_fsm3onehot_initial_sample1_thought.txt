The state machine uses one-hot encoding with states A=0001, B=0010, C=0100, D=1000. For each state and input, the next state is defined. We derive next_state logic by checking which current state bit is set and the input value, then setting the corresponding next_state bit. The output is 1 only in state D, otherwise 0. The combinational logic for next_state and output can be directly written using the given transitions.
