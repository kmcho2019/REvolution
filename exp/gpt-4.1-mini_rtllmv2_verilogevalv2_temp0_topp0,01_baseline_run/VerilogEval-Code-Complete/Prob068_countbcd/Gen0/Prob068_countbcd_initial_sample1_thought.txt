Implement a 4-digit BCD counter with digits stored in q[3:0] (ones), q[7:4] (tens), q[11:8] (hundreds), and q[15:12] (thousands). On each clock cycle, increment the ones digit. If it rolls over from 9 to 0, enable the tens digit increment (ena[1]). Similarly, if tens roll over, enable hundreds (ena[2]), and if hundreds roll over, enable thousands (ena[3]). The ena signals indicate when the corresponding digit should increment. The reset synchronously clears all digits to zero. The counter increments in BCD, so each digit counts from 0 to 9 and then rolls over.
