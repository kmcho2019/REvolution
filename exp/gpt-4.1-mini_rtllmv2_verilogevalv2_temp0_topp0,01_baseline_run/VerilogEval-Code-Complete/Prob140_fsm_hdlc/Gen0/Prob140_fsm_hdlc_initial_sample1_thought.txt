Design a Moore FSM that counts consecutive 1s after a 0. The states represent how many consecutive 1s have been seen (0 to 6). On input 0, reset count to 0. On input 1, increment count. When count reaches 5 and next input is 0, output disc next cycle. When count reaches 6 and next input is 0, output flag next cycle. If count reaches 7 or more consecutive 1s, output err next cycle. Outputs are asserted for one cycle after the condition is detected. The FSM starts in state 0 (as if previous input was 0) on synchronous reset.
