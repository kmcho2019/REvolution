Implement the next state logic and output logic based on the given state transitions and outputs. Since the encoding is one-hot, each state corresponds to one bit in the state vector. For each state, depending on the input, set the corresponding next state bit. Outputs are zero except for states S7 (out2=1), S8 (out1=1), and S9 (out1=1, out2=1). The next_state bits are assigned by ORing the conditions that lead to that state.
