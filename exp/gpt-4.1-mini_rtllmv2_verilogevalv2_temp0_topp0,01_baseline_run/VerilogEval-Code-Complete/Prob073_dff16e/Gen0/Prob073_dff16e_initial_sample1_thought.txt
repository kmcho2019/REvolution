Implement 16 D flip-flops as a 16-bit register with synchronous active-low reset. On each positive clock edge, if resetn is low, clear the register to 0. Otherwise, update only the bytes enabled by byteena: if byteena[1] is set, update the upper byte q[15:8] with d[15:8]; if byteena[0] is set, update the lower byte q[7:0] with d[7:0]. The other bytes retain their previous values.
