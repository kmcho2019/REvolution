Implement a Mealy machine with two states A and B using one-hot encoding. State A is represented as 2'b01 and state B as 2'b10. On asynchronous active-high reset, the machine goes to state A. The output z depends on the current state and input x as per the given transitions. Use a sequential always block for state transitions with asynchronous reset, and a combinational always block or continuous assignment for output z.
