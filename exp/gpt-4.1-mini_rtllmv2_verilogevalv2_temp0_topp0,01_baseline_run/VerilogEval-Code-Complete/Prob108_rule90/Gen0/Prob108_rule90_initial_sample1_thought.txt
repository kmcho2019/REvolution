Implement a 512-bit register q that updates on each clock cycle. When load is high, q is loaded with the input data. Otherwise, q updates according to Rule 90: each bit q[i] is updated to the XOR of its left and right neighbors, with boundary neighbors assumed zero. For i=0, left neighbor is 0; for i=511, right neighbor is 0. This can be efficiently done by shifting q left and right by one bit, padding zeros at boundaries, and XORing the results.
