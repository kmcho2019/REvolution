To design a Moore FSM that computes the 2's complement of a serial input bit stream starting from the LSB, we need to remember the process of 2's complement: copy all the least significant bits until the first '1' is encountered, then invert all subsequent bits.

The FSM will have two states:
- S0: Before the first '1' is seen, output z = x (copy input).
- S1: After the first '1' is seen, output z = ~x (invert input).

On reset (active high asynchronous), the FSM goes to S0. On each clock cycle, the FSM reads input x and outputs z according to the current state. The FSM transitions from S0 to S1 when it sees the first '1' bit.

Because it's a Moore machine, output depends only on the state, so we will store the output logic in the state register or combinational logic based on the state.

The module will implement asynchronous reset, positive edge clock, and output z as per the FSM described.
