Implement a 32-bit shift register to hold the global branch history. On asynchronous reset, clear the history to zero. On each clock edge, if a misprediction occurs, load the history with train_history concatenated with train_taken (train_taken as the youngest bit). Otherwise, if a prediction is valid, shift the current history left by one and insert predict_taken at the LSB. The misprediction update takes precedence over prediction update. The output predict_history reflects the current history state.
