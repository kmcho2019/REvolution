Design a finite state machine with the following states: IDLE (waiting for start bit), RECEIVE (shifting in 8 data bits LSB first), STOP (checking for stop bit). On reset, go to IDLE. When in IDLE, wait for a 0 start bit. Once start bit detected, move to RECEIVE and shift in 8 bits on each clock cycle. After 8 bits received, move to STOP and check if input is 1 (stop bit). If stop bit is correct, output the byte, assert done for one cycle, and return to IDLE. If stop bit is incorrect, stay in STOP until a 1 is seen, then return to IDLE without asserting done. The output done is asserted only for one clock cycle when a valid byte is received. The data is shifted in LSB first, so shift in the input bit at LSB side each cycle.
