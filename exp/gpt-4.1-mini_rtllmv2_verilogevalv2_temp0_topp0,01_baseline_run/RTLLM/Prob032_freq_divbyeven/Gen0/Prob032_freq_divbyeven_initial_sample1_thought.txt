Implement a frequency divider module named freq_diveven that divides the input clock frequency by an even number specified by the parameter NUM_DIV. The module uses a 4-bit counter to count clock cycles up to half of NUM_DIV - 1, then toggles the output clock and resets the counter. The output clock toggles every half period, resulting in a frequency division by NUM_DIV. The module resets asynchronously with an active-low reset signal.
