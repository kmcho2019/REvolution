Implement a dual-port RAM with synchronous read and write operations. The RAM has a depth of 8 and width of 6 bits. On reset, all memory locations are cleared to zero. Write operations occur on the rising edge of clk when write_en is high, writing write_data to write_addr. Read operations occur on the rising edge of clk when read_en is high, reading data from read_addr to read_data. If read_en is low, read_data is cleared to zero. The RAM array is declared as reg [WIDTH-1:0] RAM [0:DEPTH-1] to match the depth and width requirements.
