Implement a dual-port RAM with separate read and write ports, each with its own enable and address signals. The RAM has a depth of 8 and width of 6 bits. On reset, initialize all memory locations to zero. The write operation occurs synchronously on the clock's rising edge when write_en is high. The read operation also occurs synchronously on the clock's rising edge when read_en is high, outputting the data at read_addr; otherwise, output zero. The RAM array is declared as reg [WIDTH-1:0] RAM [0:DEPTH-1].
