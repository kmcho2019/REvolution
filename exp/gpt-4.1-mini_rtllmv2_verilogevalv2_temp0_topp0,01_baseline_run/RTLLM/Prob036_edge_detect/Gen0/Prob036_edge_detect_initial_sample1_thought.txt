To detect edges on the input signal 'a', we need to store its previous value on each clock cycle. By comparing the current and previous values of 'a', we can determine if a rising edge (0 to 1) or falling edge (1 to 0) occurred. The outputs 'rise' and 'down' are set to 1 on the clock cycle immediately after the edge is detected and remain 1 until the next corresponding edge appears. This means we need to latch the output signals and only clear them when the next edge of the same type is detected. The reset signal (active low) initializes the stored previous value and output signals.
