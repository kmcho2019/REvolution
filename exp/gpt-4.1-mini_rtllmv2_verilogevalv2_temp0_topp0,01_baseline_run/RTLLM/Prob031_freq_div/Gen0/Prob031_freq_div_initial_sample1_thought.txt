Implement a frequency divider module named freq_div with input clock CLK_in at 100MHz and reset RST. The module outputs three clocks: CLK_50 (50MHz), CLK_10 (10MHz), and CLK_1 (1MHz). CLK_50 toggles every clock cycle (divide by 2). CLK_10 toggles every 5 clock cycles (divide by 10), using a 3-bit counter cnt_10 counting from 0 to 4. CLK_1 toggles every 50 clock cycles (divide by 100), using a 6-bit counter cnt_100 counting from 0 to 49. On reset, all outputs and counters are cleared.
