Implement a parallel-to-serial converter that takes 4-bit parallel input and outputs one bit per clock cycle starting from the MSB to LSB. Use a 2-bit counter to track which bit is being output. When the counter reaches 3 (last bit), load new parallel data into a shift register and reset the counter. The valid_out signal is high only when the MSB bit is output (counter == 0). On each clock cycle, shift the data left by one bit, rotating the MSB to LSB as described. The reset is active low (rst_n), so on reset, initialize counter and data register to zero.
