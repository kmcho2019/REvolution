Implement a parallel-to-serial converter that takes a 4-bit input and outputs one bit per clock cycle starting from the MSB to LSB. Use a 2-bit counter to track which bit is being output. When the counter reaches 3 (last bit), load new parallel data and reset the counter. The valid_out signal is high only when the MSB bit is output (counter == 0). Shift the data register left each cycle to bring the next bit to MSB position. Reset logic is active low (rst_n).
