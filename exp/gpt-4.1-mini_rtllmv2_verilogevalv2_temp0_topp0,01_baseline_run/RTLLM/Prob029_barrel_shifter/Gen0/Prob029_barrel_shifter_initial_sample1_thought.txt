Implement an 8-bit barrel shifter that rotates bits based on a 3-bit control signal. The shifting is done in three stages corresponding to shifts by 4, 2, and 1 positions. Each stage uses 8 instances of a 2-to-1 multiplexer (mux2X1) to select between the original bit and the bit shifted by the stage amount. The mux2X1 module takes two inputs and a select signal and outputs one of the inputs based on the select. The output of each stage feeds into the next stage. The final output is the rotated 8-bit value after applying all selected shifts.
