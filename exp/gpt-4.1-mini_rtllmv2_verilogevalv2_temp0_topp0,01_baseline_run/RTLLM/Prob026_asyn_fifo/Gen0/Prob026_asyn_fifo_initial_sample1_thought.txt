Implement an asynchronous FIFO with parameterized width and depth using a dual-port RAM submodule. Use binary counters for read and write pointers, convert them to Gray code for synchronization across clock domains, and synchronize the opposite pointer using two-stage flip-flops. Use Gray code comparison to generate full and empty flags. The RAM address is derived from the lower bits of the binary pointer. The dual-port RAM has separate clocks and enables for read and write. The FIFO increments pointers on valid write/read increments if not full/empty. The design includes separate reset signals for read and write domains.
