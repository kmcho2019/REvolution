Implement a parameterized fixed-point adder module with parameters Q (fractional bits) and N (total bits). Inputs a and b are N-bit fixed-point numbers in two's complement format. The addition logic depends on the sign bits (MSB) of a and b:

- If signs are the same, add absolute values and assign the sign bit accordingly.
- If signs differ, subtract the smaller absolute value from the larger one and assign the sign bit based on which operand is larger.

Absolute values are computed by checking the sign bit and conditionally negating the input. The result is stored in an internal register res, and output c is assigned from res. Overflow is implicitly handled by the fixed N-bit width and two's complement arithmetic.

The module uses combinational logic for addition and subtraction, ensuring the output is consistent with fixed-point arithmetic with Q fractional bits.
