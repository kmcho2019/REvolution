Implement a parameterized fixed-point adder module with parameters Q (fractional bits) and N (total bits). Inputs a and b are N-bit fixed-point numbers with sign bit as MSB. The addition logic depends on the sign bits:

- If signs are the same, add absolute values and keep the sign.
- If signs differ, subtract smaller absolute value from larger absolute value and assign sign accordingly.

Absolute value is computed by checking the sign bit and, if negative, taking two's complement. The result is stored in an internal register res and assigned to output c. Overflow is implicitly handled by fixed N-bit width and sign bit.

The module uses combinational logic for addition/subtraction.
