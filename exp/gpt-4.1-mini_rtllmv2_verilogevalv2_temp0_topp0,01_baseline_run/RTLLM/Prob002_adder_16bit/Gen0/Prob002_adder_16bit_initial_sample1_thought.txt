To implement a 16-bit full adder using combinational logic, I will first design an 8-bit adder module that takes two 8-bit inputs and a carry-in, and produces an 8-bit sum and a carry-out. Then, I will instantiate this 8-bit adder twice inside the 16-bit adder module: the first instance will add the lower 8 bits of the inputs with the initial carry-in, and the second instance will add the upper 8 bits along with the carry-out from the first instance. This hierarchical design promotes modularity and reusability.
