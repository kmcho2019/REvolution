Implement a dual-clock domain synchronizer for a 4-bit data input with an enable signal. The data and enable signals are sampled on clk_a domain, then the enable signal is synchronized through two flip-flops on clk_b domain to create a delayed enable signal. When the delayed enable is active, the output data on clk_b domain is updated with the stored data from clk_a domain. Reset signals are asynchronous active low and clear the registers accordingly.
