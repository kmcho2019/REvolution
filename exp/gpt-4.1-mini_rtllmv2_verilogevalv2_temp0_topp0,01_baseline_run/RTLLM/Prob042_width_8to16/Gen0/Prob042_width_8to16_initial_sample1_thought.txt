Use a flag to indicate whether the first 8-bit data has been stored. On each valid input, if the flag is not set, store the input data in a register (data_lock) and set the flag. If the flag is set and a new valid input arrives, concatenate the stored data (higher 8 bits) and the new input (lower 8 bits) to form the 16-bit output. The valid_out signal is asserted in the clock cycle after the second valid input arrives. On reset, clear all registers and flags.
