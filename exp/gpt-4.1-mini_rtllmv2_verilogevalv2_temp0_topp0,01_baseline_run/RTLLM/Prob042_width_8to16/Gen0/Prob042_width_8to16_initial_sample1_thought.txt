Use a flag to indicate whether the first 8-bit data has been stored. On each valid input, if the flag is not set, store the input data in a register (data_lock) and set the flag. If the flag is set, concatenate the stored data_lock (higher 8 bits) and the current data_in (lower 8 bits) to form the 16-bit output data_out, assert valid_out in the next clock cycle, and clear the flag. On reset, clear all registers and flags.
