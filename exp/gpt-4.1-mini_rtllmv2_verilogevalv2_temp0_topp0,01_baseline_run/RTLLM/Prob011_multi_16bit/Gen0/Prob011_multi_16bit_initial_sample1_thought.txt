Implement a sequential 16-bit unsigned multiplier using shift and accumulate method. Use a shift count register (i) to track the current bit being processed. On reset, clear all registers. On start, load inputs into registers and begin processing each bit of the multiplicand (areg). For each bit set in areg, add the appropriately shifted multiplier (breg) to the product register (yout_r). The done flag is asserted when all 16 bits have been processed. The product output is continuously assigned from the product register.
