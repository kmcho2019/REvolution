Implement an 8-bit multiplier using the classic shift-and-add algorithm. Initialize a 16-bit product register to zero. Iterate over each bit of the multiplier B from LSB to MSB. For each bit set to 1, add the multiplicand A shifted left by the bit index to the product. This simulates adding A multiplied by 2^bit_index. After processing all bits, output the final 16-bit product.
