Implement an 8-bit unsigned multiplier using a pipelined architecture. The pipeline stages are:

1. Input registers stage: sample mul_en_in, mul_a, mul_b on clk rising edge when mul_en_in is high.
2. Partial product generation: generate 8 partial products by ANDing mul_a with each bit of mul_b.
3. Partial sum calculation: add partial products in a pipelined manner over several clock cycles to reduce critical path.
4. Final product calculation: accumulate all partial sums into mul_out_reg.
5. Output enable signal mul_en_out is pipelined along with data to indicate valid output.

The pipeline registers for mul_en_out are implemented as a shift register to track the enable signal through the pipeline stages. The output mul_out is valid only when mul_en_out is high; otherwise, it outputs zero.

The design uses synchronous reset (active low) to clear registers.

This approach balances hardware complexity and timing by pipelining the addition of partial products over multiple clock cycles.
