Implement an 8-bit Radix-4 Booth multiplier using synchronous logic. On reset, sign-extend inputs a and b into 16-bit registers multiplier and multiplicand respectively. Use a 5-bit counter to track the number of steps (up to 16). On each clock cycle, if counter < 16, shift multiplicand left by 1, and if the current bit of multiplier is 1, add multiplicand to product p. Increment counter each cycle. When counter reaches 16, set ready signal rdy to 1 indicating completion.
