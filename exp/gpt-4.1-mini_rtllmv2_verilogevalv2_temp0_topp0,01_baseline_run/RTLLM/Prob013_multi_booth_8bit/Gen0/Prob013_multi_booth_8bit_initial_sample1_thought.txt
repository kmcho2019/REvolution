Implement a Radix-4 Booth multiplier for 8-bit inputs using a sequential approach. On reset, sign-extend inputs a and b into 16-bit registers multiplicand and multiplier respectively. Use a 5-bit counter to track the number of steps (16 steps for 16 bits). On each clock cycle, if counter < 16, shift multiplicand left by 1, and if the current bit of multiplier is 1, add multiplicand to the product register p. Increment counter each cycle. When counter reaches 16, set ready signal rdy to 1 indicating completion. The product p is 16-bit output. The design uses synchronous logic with asynchronous reset.
