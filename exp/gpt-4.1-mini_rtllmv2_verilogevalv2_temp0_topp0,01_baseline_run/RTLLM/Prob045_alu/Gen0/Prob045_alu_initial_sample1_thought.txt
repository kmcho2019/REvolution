Implement a 32-bit ALU module with inputs a, b, and aluc. Use parameters for operation codes. Inside an always_comb block, use a case statement on aluc to perform the specified operation. For arithmetic operations, handle signed and unsigned cases, compute carry and overflow flags accordingly. For shift operations, use the appropriate shift amount from a or a[4:0]. For SLT and SLTU, set the flag output accordingly. The zero output is set if the result is zero, negative if the MSB of the result is 1. If aluc is unrecognized, output high impedance. The flag output is '1' for SLT and SLTU, else 'z'.
