Implement a 4-entry stack with 4-bit width using an array and a stack pointer (SP) initialized to 4 (empty). On reset, clear the stack and set SP to 4. On each clock edge with EN high, if RW=0 (write) and not full, decrement SP and write dataIn to stack_mem[SP-1]. If RW=1 (read) and not empty, output dataOut from stack_mem[SP], clear that location, and increment SP. Update EMPTY and FULL flags based on SP value (EMPTY when SP==4, FULL when SP==0).
