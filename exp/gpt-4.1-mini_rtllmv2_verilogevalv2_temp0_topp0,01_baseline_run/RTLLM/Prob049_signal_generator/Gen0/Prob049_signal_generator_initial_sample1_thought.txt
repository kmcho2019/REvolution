Implement a synchronous process triggered on the positive edge of clk or negative edge of rst_n. On reset, clear state and wave to 0. Otherwise, use a case statement on state: if state is 0, increment wave until it reaches 31, then switch state to 1; if state is 1, decrement wave until it reaches 0, then switch state to 0. This will generate a triangle wave cycling between 0 and 31.
