Implement a 16x16 Game of Life on a toroidal grid with synchronous load. The 256-bit input data is loaded into the state register q when load is high at the clock edge. Otherwise, at each clock edge, compute the next state of each cell based on the number of alive neighbors using the given rules. The grid wraps around, so neighbors are computed modulo 16 in both row and column. The 256-bit vector q is organized as 16 rows of 16 bits each, with q[15:0] as row 0, q[31:16] as row 1, etc. The next state is computed combinationally for all cells, then registered on the clock edge.
