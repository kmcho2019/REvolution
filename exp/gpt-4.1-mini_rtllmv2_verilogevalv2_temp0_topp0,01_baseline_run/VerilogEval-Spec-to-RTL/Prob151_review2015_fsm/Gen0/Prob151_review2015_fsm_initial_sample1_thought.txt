Implement a finite state machine with the following states:
- IDLE: searching for the pattern 1101 on the serial data input.
- SHIFT: after detecting 1101, assert shift_ena for exactly 4 clock cycles to shift in 4 bits.
- COUNT: assert counting output and wait for done_counting to go high.
- DONE: assert done output and wait for ack to go high, then return to IDLE.

To detect the pattern 1101, use a 4-bit shift register that shifts in the data bit each clock cycle. When the shift register equals 4'b1101, transition from IDLE to SHIFT.

Use a 2-bit counter to count the 4 shift cycles in SHIFT state.

All outputs are combinational based on the current state.

Synchronous active high reset sets the FSM to IDLE state and clears counters.
