Implement a FSM with three main states: A (reset state), B (counting w inputs), and C (output z). 
- In state A, wait for s=1 to move to B.
- In state B, collect w inputs for 3 clock cycles, counting how many times w=1.
- After 3 cycles, move to state C to output z=1 if exactly two w=1's were counted, else z=0.
- Then return to state B to repeat the 3-cycle counting.
Use a 2-bit counter to count the number of w=1's and a 2-bit cycle counter to count the 3 cycles.
All logic is synchronous with positive edge clock and synchronous reset.
