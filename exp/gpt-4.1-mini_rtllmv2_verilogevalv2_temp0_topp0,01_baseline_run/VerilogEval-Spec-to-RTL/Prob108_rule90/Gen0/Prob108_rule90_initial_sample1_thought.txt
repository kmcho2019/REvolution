Implement a 512-bit register q to hold the current state. On each positive clock edge, if load is high, load q with the input data. Otherwise, update q according to Rule 90: each bit q[i] is updated to the XOR of its left and right neighbors, with boundary neighbors assumed zero. Specifically, q[i] <= q[i-1] ^ q[i+1], with q[-1] = 0 and q[512] = 0.
