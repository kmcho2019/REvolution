Implement a 4-digit BCD counter with digits stored in q[15:0], each digit 4 bits. On each clock cycle, increment the ones digit. When a digit reaches 9 and increments, it resets to 0 and enables the next digit to increment. The ena output is 3 bits, each bit indicating when the corresponding upper digit (tens, hundreds, thousands) should increment. Use synchronous active-high reset to clear all digits and ena signals.
