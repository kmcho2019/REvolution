Implement an 8-bit shift register with synchronous enable and input S. The shift register shifts in S into Q[0] on each clock when enable is high. The outputs Q[0] to Q[7] are stored bits. Use a 3-to-8 decoder from inputs A,B,C to select one of the Q bits to output Z. The selection is done via an 8-to-1 multiplexer controlled by A,B,C.
