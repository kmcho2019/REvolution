Implement a finite state machine with the following states: IDLE, START, DATA, STOP, and WAIT_STOP. The FSM starts in IDLE, waiting for a start bit (0). When a start bit is detected, it moves to DATA state to shift in 8 data bits (LSB first). After receiving 8 bits, it moves to STOP state to check the stop bit (should be 1). If the stop bit is correct, output the received byte, assert done for one clock cycle, and return to IDLE. If the stop bit is incorrect, move to WAIT_STOP state, where it waits until it sees a stop bit (1) before returning to IDLE. The reset synchronously resets the FSM to IDLE and clears outputs. The done signal is asserted for one clock cycle when a valid byte is received.
