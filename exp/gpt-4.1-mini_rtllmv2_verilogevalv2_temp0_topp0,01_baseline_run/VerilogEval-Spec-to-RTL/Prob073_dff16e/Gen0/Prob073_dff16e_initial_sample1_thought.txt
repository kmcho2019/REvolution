Implement 16 D flip-flops with synchronous active-low reset. On each positive clock edge, if resetn is low, clear all flip-flops to 0. Otherwise, update the upper byte q[15:8] with d[15:8] only if byteena[1] is high, and update the lower byte q[7:0] with d[7:0] only if byteena[0] is high. If the corresponding byteena bit is low, retain the previous value of that byte.
