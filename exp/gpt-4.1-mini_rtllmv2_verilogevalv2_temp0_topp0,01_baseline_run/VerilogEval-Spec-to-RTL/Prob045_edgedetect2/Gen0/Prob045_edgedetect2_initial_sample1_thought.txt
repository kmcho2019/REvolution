To detect any edge on each bit of the 8-bit input vector, we need to store the previous value of the input bits in a register on each clock cycle. Then, we compare the current input bits with the stored previous bits. If any bit differs, it means an edge occurred on that bit. The output anyedge should be set to 1 in the cycle after the edge is detected, so we register the edge detection result and output it in the next cycle.
