Implement a finite state machine with the following states: IDLE, START, DATA, STOP, and WAIT_STOP. 
- In IDLE, wait for the start bit (0).
- On detecting start bit, move to START to confirm start bit.
- Then move to DATA to receive 8 data bits, shifting them in LSB first.
- After 8 bits, move to STOP to check for stop bit (1).
- If stop bit is correct, assert done for one cycle and return to IDLE.
- If stop bit is incorrect, move to WAIT_STOP state, waiting for a stop bit (1) before returning to IDLE.
Use synchronous reset to initialize FSM to IDLE.
