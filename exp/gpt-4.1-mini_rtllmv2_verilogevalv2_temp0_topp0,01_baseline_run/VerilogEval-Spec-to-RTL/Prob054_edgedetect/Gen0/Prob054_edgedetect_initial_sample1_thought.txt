To detect a 0-to-1 transition on each bit of the 8-bit input vector, we need to store the previous state of the input bits on each clock cycle. Then, on the next clock cycle, we compare the current input bits with the stored previous bits. If a bit was 0 in the previous cycle and is 1 in the current cycle, it indicates a positive edge on that bit. The output pedge should be set to 1 for that bit in the cycle after the transition, so we register the detection and output it in the next cycle.
