Implement a 32-bit shift register to hold the global branch history. On the positive edge of clk, if areset is asserted, reset the history to zero asynchronously. If train_mispredicted is asserted, load the history with {train_taken, train_history[31:1]} (the history before the mispredicted branch concatenated with the actual branch outcome). Else if predict_valid is asserted, shift in predict_taken at LSB (history <= {history[31:1], predict_taken}). Output predict_history is the current history. Misprediction takes precedence over prediction.
