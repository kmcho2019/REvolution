Implement a 4-state FSM with states A, B, C, D encoded as 2-bit values. On synchronous active-low reset, state resets to A. On each clock edge, state transitions according to the input requests r[2:0] and the priority rules. Outputs g[2:0] are combinationally assigned based on the current state: g0=1 in state B, g1=1 in state C, g2=1 in state D, else 0. Use one always block for state flip-flops (sequential logic) and one always block for next state logic (combinational). Outputs are assigned via continuous assignment.
