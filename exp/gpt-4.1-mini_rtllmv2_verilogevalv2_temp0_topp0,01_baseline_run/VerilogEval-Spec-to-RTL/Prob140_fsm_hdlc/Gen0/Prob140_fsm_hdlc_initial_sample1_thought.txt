Implement a Moore FSM that counts consecutive 1s in the input stream. The states represent how many consecutive 1s have been seen (0 to 6). On input 0, the FSM resets to state 0. On input 1, it moves to the next state counting consecutive 1s. When the FSM reaches state 5 and sees a 0 next, it asserts 'disc' on the next cycle (discard the zero after five 1s). When the FSM reaches state 6 and sees a 0 next, it asserts 'flag' on the next cycle (flag pattern 01111110). If the FSM sees a 1 in state 6 (7 or more consecutive 1s), it asserts 'err' on the next cycle. The outputs are registered and asserted for one cycle after the condition is detected. The FSM resets synchronously to state 0 on reset.
