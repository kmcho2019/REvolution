The issue is in state 4 (State 4 - Sequence Found) of the FSM. When the sequence 1101 is detected and start_shifting is set to 1, the state transitions back to state 0. This causes the FSM to restart the search for the sequence instead of remaining in the 1101 sequence found state. This behavior leads to multiple mismatches in the simulation output as the FSM is not behaving according to the design intent.
