We can implement a finite-state machine with four states: IDLE, STATE1, STATE2, and STATE3. In the IDLE state, we wait for the first '1' in the sequence. Once we find the first '1', we transition to STATE1 and look for the next '1'. If we find '0' instead, we transition back to IDLE. If the second '1' is found, we transition to STATE2 and look for the '0'. Finally, in STATE3, we wait for the last '1' in the sequence. If all conditions are met, we set start_shifting to 1.
