Implement a finite-state machine with reset and the states:
  - IDLE: Waiting for the start pattern '1101'
  - DETECTED: Start pattern '1101' detected, shifting in 4 more bits
  - WAIT_FOR_COUNTERS: Waiting for the done_counting signal
  - TIMED_OUT: Counters finished counting, notify the user
  - WAIT_FOR_ACK: Waiting for user acknowledgment before resetting

In each state, transition based on the current state and input signals.
