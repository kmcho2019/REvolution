The state machine will have 4 states: IDLE, DETECT_PATTERN, SHIFT_DELAY, WAIT_COUNTING_DONE. When in the IDLE state, the machine waits for the start pattern (1101). Once the pattern is detected, it transitions to the DETECT_PATTERN state and starts shifting in 4 bits. After that, it transitions to SHIFT_DELAY state for 4 clock cycles. Next, it goes to WAIT_COUNTING_DONE state where it waits for done_counting before transitioning to the DONE state to notify the user and wait for ack before going back to IDLE state.
