One approach to solve this problem is to design a finite state machine with four states - IDLE, BYTE1, BYTE2, and BYTE3. In the IDLE state, the machine waits for the first byte (in[3]=1) to start processing the message. Once the first byte is received, the machine transitions to the BYTE1 state and waits for the second byte. Similarly, after receiving the second byte, it transitions to the BYTE2 state to wait for the third byte. Once the third byte is received, the machine transitions to the BYTE3 state and asserts the 'done' signal in the next cycle.
