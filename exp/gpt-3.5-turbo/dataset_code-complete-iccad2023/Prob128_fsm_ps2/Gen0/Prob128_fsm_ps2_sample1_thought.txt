We can design a simple 4-state finite state machine (FSM) to search for the message boundary. The states of the FSM will be IDLE, BYTE1, BYTE2, and DONE. In the IDLE state, the machine waits for a byte with in[3]=1. In the BYTE1 state, it waits for the second byte of the message. In the BYTE2 state, it waits for the third byte of the message. Once the third byte is received, it transitions to the DONE state and sets the 'done' output signal.
