The finite state machine (FSM) can have four states - IDLE, BYTE1, BYTE2, and BYTE3. In the IDLE state, the FSM waits for a byte with in[3]=1. Once this byte is received, the FSM transitions to the BYTE1 state. In the BYTE1 state, the FSM waits for the next byte and transitions to the BYTE2 state on its reception. Similarly, in the BYTE2 state, the FSM waits for the third byte and transitions to the BYTE3 state upon reception. In the BYTE3 state, the FSM waits for one more clock cycle before asserting the 'done' signal and transitioning back to the IDLE state.
