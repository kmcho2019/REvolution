We can design a simple finite state machine with 3 states - IDLE, BYTE1, and BYTE23. In the IDLE state, we wait for in[3] to be 1 which signifies the start of a new message. Once in[3] is 1 in the IDLE state, we move to the BYTE1 state to receive the first byte of the message. After receiving the first byte, we transition to the BYTE23 state to receive the next 2 bytes. Once all 3 bytes of the message have been received, we output done in the next cycle. Reset will take us back to the IDLE state.
