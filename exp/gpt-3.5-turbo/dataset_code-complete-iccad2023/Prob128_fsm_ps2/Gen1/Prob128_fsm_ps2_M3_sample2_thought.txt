We can design a simple 3-state finite state machine (FSM) to detect message boundaries in the input byte stream. The states of the FSM will be IDLE, BYTE1, and DONE. In the IDLE state, we wait for the first byte with in[3]=1. Upon finding it, we move to the BYTE1 state to receive the next two bytes of the message. Once we have received all three bytes in sequence, we transition to the DONE state and signal the completion of a message.
