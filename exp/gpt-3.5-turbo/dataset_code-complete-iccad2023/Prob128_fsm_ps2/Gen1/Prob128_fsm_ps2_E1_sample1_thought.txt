We can design a FSM with five states to accurately detect message boundaries: IDLE, START_BYTE, SECOND_BYTE, THIRD_BYTE, and DONE. In the IDLE state, we wait for in[3]=1 to indicate the start of a message. Once we find the start byte, we transition through the states to ensure that we have received all three bytes correctly before moving to the DONE state to signal the completion of a message.
