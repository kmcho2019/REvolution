We can design a modified finite state machine with four states: IDLE, FIRST_BYTE, SECOND_BYTE, and DONE. In the IDLE state, we wait for the first byte with in[3]=1. Once we find it, we move to the FIRST_BYTE state and then transition to the SECOND_BYTE state after receiving the second byte. After receiving the third byte, we move to the DONE state. This approach ensures we only signal the completion of a message after all three bytes have been received.
