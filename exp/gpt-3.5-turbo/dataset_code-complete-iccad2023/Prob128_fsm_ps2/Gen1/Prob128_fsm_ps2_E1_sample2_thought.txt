We can design a FSM with the following states:
1. IDLE state: Wait for the first byte of a message (in[3]=1).
2. FIRST_BYTE state: First byte received, waiting for the second byte or transitioning back to IDLE if in[3]=0.
3. SECOND_BYTE state: Second byte received, waiting for the third byte or transitioning back to IDLE if in[3]=0.
4. THIRD_BYTE state: Third byte received, message complete. Transition back to IDLE state.
