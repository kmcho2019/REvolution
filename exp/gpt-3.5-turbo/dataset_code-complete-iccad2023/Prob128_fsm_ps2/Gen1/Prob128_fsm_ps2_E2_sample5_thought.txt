To effectively identify the boundaries of 3-byte messages in a continuous input byte stream, we need a finite state machine (FSM) that transitions through states based on the input bytes. The FSM should wait for the first byte with in[3]=1, then proceed to capture the second and third bytes. Once all three bytes are received, the FSM should signal the completion of a message. After receiving the third byte, the FSM should transition back to the initial state to search for the start of the next message.
