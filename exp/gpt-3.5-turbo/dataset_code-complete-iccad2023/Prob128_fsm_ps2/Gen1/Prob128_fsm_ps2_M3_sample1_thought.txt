To detect the boundaries of the three-byte messages in the input byte stream, we can implement a finite state machine (FSM) with the following states:
1. IDLE state: Wait for the first byte of a message (in[3]=1).
2. CHECK_SECOND_BYTE state: Check if the second byte has in[3]=1.
3. CHECK_THIRD_BYTE state: Check if the third byte has in[3]=1.
4. DONE state: Message complete, transition back to IDLE state.
