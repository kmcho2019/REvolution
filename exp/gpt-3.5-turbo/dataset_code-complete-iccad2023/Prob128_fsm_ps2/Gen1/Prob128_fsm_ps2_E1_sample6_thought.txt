We can design a FSM with the following states:
1. IDLE state: Wait for the first byte of a message (in[3]=1).
2. SECOND_BYTE state: Wait for the second byte after receiving the first byte.
3. THIRD_BYTE state: Wait for the third byte after receiving the second byte.
4. DONE state: Signal the receipt of a complete message before transitioning back to the IDLE state.
