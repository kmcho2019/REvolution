We can design a FSM that uses a counter to keep track of the number of bytes received in each message. The FSM will have 4 states: IDLE, BYTE1, BYTE2, and DONE. In the IDLE state, the machine waits for a byte with in[3]=1 to start the message reception. Once in[3]=1 is detected, the FSM transitions to the BYTE1 state and increments the byte counter. If in[3]=1 is detected in the BYTE1 or BYTE2 states, the FSM resets the byte counter and goes back to the IDLE state, otherwise, it proceeds to the next state. Once the byte counter reaches 3, the FSM transitions to the DONE state and sets the 'done' output signal.
