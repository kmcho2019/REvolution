Create a 32-bit register to store the previous value of the input vector. On each clock cycle, compare each bit of the current input vector with the previous value. When a bit changes from 1 to 0, set the corresponding bit in the output vector to 1. Reset the register on the rising edge of the reset signal. The correct logic to capture the edge transition from 1 to 0 is to check for the condition where the previous input value was 1 and the current input value is 0.
