The finite state machine can have the following states:
1. IDLE: Waiting for a start bit (0) to be detected.
2. RECEIVE: Reading in the 8 data bits.
3. STOP: Verifying the stop bit (1).
4. WAIT: Waiting for the line to return to idle state.

Transitions:
- IDLE -> RECEIVE on Start bit detection
- RECEIVE -> STOP after reading 8 data bits
- STOP -> IDLE if stop bit is correct, or WAIT if stop bit is incorrect
- WAIT -> IDLE on detecting a new start bit after waiting
