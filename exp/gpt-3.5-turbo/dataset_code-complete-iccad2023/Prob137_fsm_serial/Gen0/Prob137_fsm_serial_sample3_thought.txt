Create a finite state machine with four states - IDLE, START, DATA, and STOP. When in the IDLE state, wait for the input to transition from high to low to detect the start bit. Transition to the DATA state and receive 8 bits of data. Then transition to the STOP state, where the stop bit should be high. If the stop bit is detected, go back to the IDLE state to wait for the start bit of the next byte. If the stop bit is low, remain in the STOP state until it becomes high.
