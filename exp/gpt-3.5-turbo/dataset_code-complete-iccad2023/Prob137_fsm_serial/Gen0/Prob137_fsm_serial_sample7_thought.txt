To design the finite state machine, we can use a 4-state approach:
- IDLE: waiting for the start bit
- RECEIVE: reading in the 8 data bits
- STOP: checking for the stop bit
- WAIT: waiting for the line to return to a logic 1 state after a byte has been received

In each state, we transition to the next state based on the input and the current state. The 'done' output will be asserted when a complete byte has been received.
