We can design a finite state machine with four states: IDLE, START_BIT, DATA_BITS, and STOP_BIT. When in the IDLE state, the FSM waits for the line to transition from 1 to 0 to detect the start bit. Once the start bit is detected, it transitions to the START_BIT state. In the START_BIT state, the FSM waits for the next 8 bits to be received. Once all 8 data bits are received, the FSM transitions to the STOP_BIT state to wait for the stop bit. If the stop bit is correct, the FSM transitions back to the IDLE state and sets the 'done' signal to indicate successful byte reception.

To implement this FSM, we will use a state register to hold the current state and sequential logic to transition between states based on the input bit stream and current state.
