The finite state machine can be designed with three states: IDLE, START_BIT, DATA_BITS. When in the IDLE state, the FSM waits for a start bit (0) to initiate byte reception. Upon detecting the start bit, it transitions to the START_BIT state, then to the DATA_BITS state where it waits to receive 8 data bits. After receiving the 8 data bits, it transitions to the STOP_BIT state and verifies that the stop bit is 1. If the stop bit is correct, it sets the output 'done' high and returns to the IDLE state, else it remains in the STOP_BIT state until the next correct stop bit is received.
