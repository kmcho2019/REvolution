To design this finite state machine, we need to use three states: IDLE, START_BIT, and DATA_BITS. When in the IDLE state, the FSM waits for the start bit to appear. Once the start bit is detected, the FSM transitions to the START_BIT state where it starts counting the 8 data bits. After all the data bits have been received, the FSM transitions to the DATA_BITS state where it verifies the stop bit. If the stop bit is correct, the FSM sets 'done' to 1 and goes back to the IDLE state for the next byte.
