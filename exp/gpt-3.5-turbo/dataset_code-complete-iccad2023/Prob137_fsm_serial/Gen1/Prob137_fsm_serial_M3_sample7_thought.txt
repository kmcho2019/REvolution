The finite state machine can be simplified to three states: IDLE, RECEIVE, and STOP. We transition from IDLE to RECEIVE upon detecting the start bit. In RECEIVE state, we count the 8 data bits. Once the data bits are received, we transition to STOP state to verify the stop bit. If the stop bit is correct, we output 'done' and transition back to IDLE. If the stop bit is incorrect, we stay in STOP until the next start bit is detected.
