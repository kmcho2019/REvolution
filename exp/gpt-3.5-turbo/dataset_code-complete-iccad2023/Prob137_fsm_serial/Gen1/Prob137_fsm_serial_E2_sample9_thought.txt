The finite state machine can be simplified to have 3 states: IDLE, DATA_BITS, and STOP_BIT. When in the IDLE state, the FSM waits for the start bit to appear. Upon detecting the start bit, it transitions to the DATA_BITS state to collect all 8 data bits. After collecting the data bits, the FSM moves to the STOP_BIT state where it verifies the stop bit. If the stop bit is correct, it sets 'done' to 1 and transitions back to the IDLE state for the next byte.
