The finite state machine can have 4 states: IDLE, START_BIT, DATA_BITS, and STOP_BIT. We transition based on the received bits - moving from IDLE to START_BIT upon detecting a start bit, collecting 8 data bits, then checking for the stop bit. If the stop bit is correct, we transition to IDLE and output 'done'. If incorrect, stay in STOP_BIT until the next start bit.
