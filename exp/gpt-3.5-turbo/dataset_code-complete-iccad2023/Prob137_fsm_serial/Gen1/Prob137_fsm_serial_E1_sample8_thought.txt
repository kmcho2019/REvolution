The finite state machine can have 5 states: IDLE, START_BIT, DATA_BIT_0, DATA_BITS_1_6, DATA_BIT_7, and STOP_BIT. We transition from IDLE to START_BIT when we detect an incoming start bit (0). From START_BIT, we transition to DATA_BIT_0, then go through states DATA_BITS_1_6 and DATA_BIT_7 to collect the incoming data bits. After that, we transition to STOP_BIT state where we wait for the stop bit (1). If we receive the stop bit, we transition back to IDLE and output the 'done' signal. If the stop bit is incorrect, we stay in the STOP_BIT state until the next start bit is detected.
