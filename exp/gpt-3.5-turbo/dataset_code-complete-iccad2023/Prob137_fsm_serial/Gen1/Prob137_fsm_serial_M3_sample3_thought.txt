To simplify the FSM design, we can have 4 states: IDLE, START_BIT, DATA_BITS, STOP_BIT. The FSM transitions from IDLE to START_BIT upon detecting a start bit (0). It then moves to DATA_BITS to capture 8 data bits and eventually transitions to STOP_BIT waiting for the stop bit (1). If the stop bit is correct, it goes back to IDLE and sets 'done' high, else remains in STOP_BIT until the next start bit is detected.
