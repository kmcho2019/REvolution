Let's design the finite state machine with 5 states: IDLE, START_BIT, DATA_BITS_0 to DATA_BITS_7, and STOP_BIT. By using separate states for each data bit reception, we can ensure accurate processing of the 8 data bits. Additionally, we introduce a VALID_CHECK state to verify the validity of the received byte after receiving all 8 data bits. This approach allows for clear data bit handling and accurate stop bit verification.
