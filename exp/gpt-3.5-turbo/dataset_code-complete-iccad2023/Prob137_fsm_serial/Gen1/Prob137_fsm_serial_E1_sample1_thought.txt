We can design a finite state machine with four states: IDLE, START_BIT, DATA_BITS, and STOP_BIT. When in the IDLE state, we will wait for the input 'in' to be 0 to detect the start bit. Upon detecting the start bit, we transition to the START_BIT state and count 8 clock cycles to receive the 8 data bits. After receiving the 8 data bits, we transition to the STOP_BIT state where we wait for the stop bit to be 1. If the stop bit is correct, we assert 'done'. If the stop bit is incorrect, we transition back to the IDLE state.
