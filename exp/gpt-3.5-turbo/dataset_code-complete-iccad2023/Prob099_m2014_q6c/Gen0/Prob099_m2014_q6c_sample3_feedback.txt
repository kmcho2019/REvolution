The primary issue in the code is the attempt to assign values to Y4 inside the always block. In Verilog, once a signal is declared as an output in the module declaration, it cannot be directly assigned values within a procedural block like always block. Since Y4 is declared as an output in the module, it cannot be assigned values in this manner.

This is the root cause of all the errors reported in the simulation log. The code violates the basic rules of assigning values to a wire output. Additionally, Y4 has already been declared as an output in the module and should not be redefined within the always block.
