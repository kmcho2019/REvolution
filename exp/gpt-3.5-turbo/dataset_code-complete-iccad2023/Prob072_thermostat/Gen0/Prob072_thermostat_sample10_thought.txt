- In this design, we can prioritize the heater control when in heating mode, air conditioner control when in cooling mode, and fan control based on user input irrespective of heating/cooling mode.
- The heater should be turned on if mode is 1 and too_cold is asserted.
- The air conditioner should be turned on if mode is 0 and too_hot is asserted.
- The fan should be turned on if either the heater, air conditioner, or the fan_on signal is asserted.
