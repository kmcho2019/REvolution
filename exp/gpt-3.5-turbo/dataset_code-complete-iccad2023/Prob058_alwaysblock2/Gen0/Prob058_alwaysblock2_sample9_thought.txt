For the assign statement approach, use a simple assignment of the XOR output based on the inputs a and b.
For the combinational always block approach, use a sensitivity list that includes inputs a and b. Inside the always block, assign the XOR output to the variable out_always_comb.
For the clocked always block approach, use a clocked always block with the positive edge of the clock as the trigger. Inside the always block, assign the XOR output to the registered output variable out_always_ff.
