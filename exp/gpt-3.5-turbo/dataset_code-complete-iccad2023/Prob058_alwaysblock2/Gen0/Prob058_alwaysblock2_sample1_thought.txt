For the assign statement, we directly assign the XOR of inputs 'a' and 'b' to the output 'out_assign'.
For the combinational always block, we use a combination of the 'a' and 'b' inputs directly to assign the value to 'out_always_comb'.
For the clocked always block, we use a flip-flop to store the output value which is the result of the XOR of inputs 'a' and 'b'.
