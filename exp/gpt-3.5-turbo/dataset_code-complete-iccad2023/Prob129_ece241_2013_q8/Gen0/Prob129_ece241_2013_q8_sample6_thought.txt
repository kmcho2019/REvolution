We can implement the Mealy-type finite state machine with 3 states: S0, S1, and S2. The machine transitions between states based on the input signal x. State S0 is the starting state, looking for the first '1' in the sequence. State S1 looks for the '0' after the first '1'. State S2 looks for the second '1' to complete the sequence. The output signal z is asserted to logic-1 only when the sequence "101" is detected.
