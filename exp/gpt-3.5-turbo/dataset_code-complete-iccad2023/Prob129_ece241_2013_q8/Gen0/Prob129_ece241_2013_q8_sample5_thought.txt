One way to implement this Mealy-type finite state machine with only 3 states is to use the current state and the next input to determine the next state and the output. The three states can be 'S0', 'S1', and 'S2', each representing a part of the sequence "101". We transition between states based on the input signal x. When we reach state 'S2' and x is high, we assert the output signal z.
