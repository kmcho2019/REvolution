To implement the described behavior of the Lemmings using a Moore state machine, we can define the following states:
- State 0: Walking Left
- State 1: Walking Right
- State 2: Falling (aaah!)
- State 3: Digging

Each state transition will be determined by the inputs bump_left, bump_right, ground, and dig. The priority order of actions is falling > digging > switching directions. The state transitions will also consider the condition for splattering after falling for more than 20 clock cycles.
