We can model the Lemming behavior using a Moore state machine with the following states:
- STATE_WALK_LEFT: Lemming is walking left.
- STATE_WALK_RIGHT: Lemming is walking right.
- STATE_FALLING: Lemming is falling without ground.
- STATE_DIGGING: Lemming is digging.
We need to design the state transitions based on the inputs and the current state of the Lemming.
