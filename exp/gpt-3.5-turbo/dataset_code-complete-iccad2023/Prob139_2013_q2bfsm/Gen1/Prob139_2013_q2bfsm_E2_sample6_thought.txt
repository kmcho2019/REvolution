We can design the finite state machine with four states: A, B, C, and D. In state A, while resetn is asserted, the FSM remains there. In state B, after resetn de-asserts and the next clock edge occurs, f is set to 1 for one clock cycle. Then, the FSM transitions to state C and monitors the x input for the pattern 1, 0, 1. If the pattern is detected, g is set to 1 on the following clock cycle. In state D, the FSM monitors the y input within two clock cycles. If y becomes 1 within two clock cycles, g is maintained at 1 permanently; otherwise, g is set to 0 permanently.
