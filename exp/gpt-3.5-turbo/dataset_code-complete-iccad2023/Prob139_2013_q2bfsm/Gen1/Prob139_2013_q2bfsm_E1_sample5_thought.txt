We can implement the finite state machine with four states: RESET, SET_F, DETECT_X, and DETECT_Y. The FSM starts in the RESET state where the outputs are initialized. Upon reset de-assertion, the FSM transitions to the SET_F state where f is set to 1 for one clock cycle. Then, the FSM moves to the DETECT_X state to monitor the x input for the pattern 1, 0, 1. If the pattern is detected, the FSM transitions to the DETECT_Y state. In the DETECT_Y state, the FSM monitors the y input. If y becomes 1 within two clock cycles, g remains 1 permanently; otherwise, g is set to 0 permanently.
