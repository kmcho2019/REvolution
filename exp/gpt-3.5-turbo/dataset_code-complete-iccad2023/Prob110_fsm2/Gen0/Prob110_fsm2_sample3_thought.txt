To implement this Moore state machine, we need to define the states OFF and ON. We use a state register to store the current state, and based on the current state and inputs j, k, and areset, we determine the next state and output. We update the state register at the positive edge of the clock. The output is based on the current state. Initially, the state is OFF (out=0), and on reset (areset=1), the state goes back to OFF state.
