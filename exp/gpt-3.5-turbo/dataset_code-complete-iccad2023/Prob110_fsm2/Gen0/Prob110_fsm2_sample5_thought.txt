To implement this Moore state machine, we need two states 'OFF' and 'ON'. We will use a 1-bit state variable to represent the current state. We will have two state registers for storing the current state and the next state. The state transition and output generation logic will be based on the current state and input signals 'j' and 'k'. An asynchronous reset will take the state machine to state 'OFF' with output '0'.
