We can implement this circuit by using a D flip-flop and a 2-input XOR gate. The D input of the flip-flop is connected to the output of the XOR gate, and the clock input of the flip-flop is driven by the clock signal. The output of the flip-flop is fed back to one input of the XOR gate. This way, the output of the flip-flop will be XORed with the input 'in' to produce the next state.
