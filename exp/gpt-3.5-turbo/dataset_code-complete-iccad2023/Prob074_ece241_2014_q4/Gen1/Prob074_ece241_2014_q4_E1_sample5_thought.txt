Instead of directly connecting XOR, AND, and OR gates to D flip-flops, we can use a different approach. We can feed the output of the gates (XOR, AND, OR) into a 3-to-1 multiplexer, and then use the select lines of the multiplexer to control which gate's output is fed into the corresponding D flip-flop. The flip-flop outputs can then be connected to a three-input NOR gate to generate the final output Z.
