One approach to mimic a dual-edge triggered flip-flop is to use a single D flip-flop and a logical XOR gate. The input (D) is connected to both the D input of the flip-flop and one input of the XOR gate. The output of the flip-flop is fed back to the other input of the XOR gate. By XORing the input with the output of the flip-flop, we can achieve functionality similar to a dual-edge triggered flip-flop.
