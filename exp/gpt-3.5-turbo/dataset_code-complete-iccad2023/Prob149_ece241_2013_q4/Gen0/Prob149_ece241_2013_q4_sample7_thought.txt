One approach to tackle this problem is to use a state machine that determines the required flow rates based on the water level and the sensor changes. The state machine will transition between different states based on the sensor inputs and previous state.

The states can be defined as:
0 - No sensors asserted
1 - s[1] asserted
2 - s[2] asserted
3 - s[1] and s[2] asserted
4 - s[3] asserted

The state machine will update the flow rate outputs based on the current state, previous state, and sensor inputs.
