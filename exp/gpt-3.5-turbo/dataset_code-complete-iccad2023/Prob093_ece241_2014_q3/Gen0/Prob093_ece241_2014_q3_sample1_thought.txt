The Karnaugh map can be simplified to:
F = c'd' + cd' + cd + c'd = d + c
To implement this using a 4-to-1 multiplexer and two 2-to-1 multiplexers, we can connect:
- d as a 2-to-1 multiplexer input selected by 'a'
- c as a 2-to-1 multiplexer input selected by 'b'
- The output of the two 2-to-1 multiplexers as the inputs to the 4-to-1 multiplexer
