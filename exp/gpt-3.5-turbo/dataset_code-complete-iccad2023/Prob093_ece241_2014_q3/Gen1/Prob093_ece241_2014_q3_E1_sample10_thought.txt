The Karnaugh map can be simplified to:
F = c'd' + cd' + cd + c'd = d + c
To implement this using a 4-to-1 multiplexer and one 2-to-1 multiplexer, we can use the following approach:
- Connect c directly to the 4-to-1 multiplexer input 3
- Connect d to the 2-to-1 multiplexer input 0 and connect 'a' to the 4-to-1 multiplexer input 1
- Connect d to the 2-to-1 multiplexer input 1 and connect 'a' to the 4-to-1 multiplexer input 0
- The outputs of the 4-to-1 and 2-to-1 multiplexers feed into the 4-to-1 multiplexer output
