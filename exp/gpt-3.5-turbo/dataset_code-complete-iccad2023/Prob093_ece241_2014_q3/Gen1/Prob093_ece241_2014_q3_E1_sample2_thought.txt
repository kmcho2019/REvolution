We can create a 2-to-1 multiplexer using the input 'c' as the selector 'a' and invert 'c' to use as the selector 'b'. Similarly, another 2-to-1 multiplexer can be created using the input 'd' as selector 'a' and inverted 'd' as selector 'b'. The outputs of these two 2-to-1 multiplexers can then be fed into a 4-to-1 multiplexer with inputs {a, b} to realize the Karnaugh map logic efficiently.
