To implement a 32-bit global history shift register with support for rolling back state in response to a pipeline flush caused by a branch misprediction, we need to update the history register accordingly when a prediction or misprediction occurs. We will shift in the predict_taken value when predict_valid is asserted and load the history register with train_history concatenated with train_taken when train_mispredicted is asserted. We also need to handle the case where both predict_valid and train_mispredicted are asserted by giving priority to the misprediction.
