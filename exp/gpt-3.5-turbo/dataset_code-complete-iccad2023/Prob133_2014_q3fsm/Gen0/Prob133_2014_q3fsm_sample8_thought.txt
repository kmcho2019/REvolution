The FSM will have two states: A and B. In state A, the FSM will remain in this state as long as s = 0. If s = 1, the FSM will transition to state B. In state B, the FSM will check the value of input w for the next three clock cycles. If w = 1 in exactly two of these cycles, then it will set the output z to 1 in the following clock cycle. Otherwise, z will be set to 0. After the third cycle, the FSM will return to state A.
