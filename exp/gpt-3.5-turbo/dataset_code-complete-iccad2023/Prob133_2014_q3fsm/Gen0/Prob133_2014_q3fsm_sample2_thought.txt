We can design this FSM using two states - State_A and State_B. In State_A, the FSM remains until s = 1, then transitions to State_B which checks the value of w for the next three clock cycles. If w = 1 in exactly two of these cycles, z is set to 1 in the next cycle and the FSM transitions back to State_A. Otherwise, z is set to 0 and FSM remains in State_B.
