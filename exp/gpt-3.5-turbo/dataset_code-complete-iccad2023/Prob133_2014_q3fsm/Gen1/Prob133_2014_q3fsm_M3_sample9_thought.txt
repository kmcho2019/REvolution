The FSM can be simplified by using just two states: A and B. In state A, the FSM checks the input s and transitions to state B if s = 1. In state B, the FSM counts the occurrences where w = 1 in the next three clock cycles. If exactly two occurrences are detected, it sets the output z to 1 in the following clock cycle. After the third cycle, the FSM returns to state A.
