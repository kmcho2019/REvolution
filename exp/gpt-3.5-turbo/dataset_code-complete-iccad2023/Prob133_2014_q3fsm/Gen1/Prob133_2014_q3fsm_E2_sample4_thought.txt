We can design the FSM using two states: State_A and State_B. In State_A, the FSM remains until s = 1, then transitions to State_B. In State_B, we can keep track of the occurrences when w = 1 in a 3-clock cycle window. If exactly two clock cycles have w = 1, we set z to 1 in the next cycle, else set z to 0.
