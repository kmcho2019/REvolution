One approach to solving the FSM problem is to use three states: A, B, and C. In state A, the FSM waits for s to be equal to 1 and transitions to state B. In state B, the FSM checks the value of w over the next three clock cycles. If w = 1 on exactly two out of those three cycles, it transitions to state C and sets the output z to 1. Otherwise, it goes back to state A. State C is a temporary state to hold the output z for one clock cycle before transitioning back to state A.
