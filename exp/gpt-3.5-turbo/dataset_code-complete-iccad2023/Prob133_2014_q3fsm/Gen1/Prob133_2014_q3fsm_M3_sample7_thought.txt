We can implement this finite state machine with two states: State A and State B. In State A, we check the value of input s to determine whether to transition to State B. In State B, we count the number of times input w is 1 over the next three clock cycles. If w is 1 in exactly two of these clock cycles, we set the output z to 1 in the following clock cycle. We also need to reset the counter when w transitions from 1 to 0 within State B.
