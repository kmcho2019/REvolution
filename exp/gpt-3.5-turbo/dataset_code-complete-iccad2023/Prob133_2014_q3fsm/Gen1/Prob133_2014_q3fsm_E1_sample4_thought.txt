One way to design this FSM is to use three states: A, B, and C. In state A, check the value of input s. If s = 1, transition to state B; otherwise, remain in state A. In state B, count the occurrences of w=1 in the next 3 clock cycles. If exactly two clock cycles have w = 1, transition to state C; otherwise, transition back to state A. In state C, set output z to 1 in the following clock cycle and then transition back to state A.
