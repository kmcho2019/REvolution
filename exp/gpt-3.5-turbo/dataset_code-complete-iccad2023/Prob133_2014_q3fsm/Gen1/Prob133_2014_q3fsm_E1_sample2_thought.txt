To simplify the FSM design, we can use three states: A, B, and C. In state A, we check input s. If s = 1, we move to state B; otherwise, we remain in state A. In state B, we count the occurrences of w = 1 for the next three clock cycles. If w = 1 exactly two times, we transition to state C and set output z to 1 in the following clock cycle. Otherwise, if w = 1 less than two times or more than two times, we return to state A without changing z.
