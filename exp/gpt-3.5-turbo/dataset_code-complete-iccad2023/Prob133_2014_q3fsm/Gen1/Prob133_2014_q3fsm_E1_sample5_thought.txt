The FSM can be designed with three states: A, B, and C. State transitions will be based on the values of s and w. State A checks the value of the input s and transitions to state B if s = 1. State B will count the number of clock cycles where w = 1 out of the next three clock cycles and transition to state C. In state C, the FSM will set the output z to 1 if w was equal to 1 exactly two times in the last three cycles; otherwise, it will set z to 0 and return to state A.
