To implement the shift register that also acts as a down counter, we can use a single always block sensitive to the positive edge of the clock signal. Within the always block, we can first check if count_ena is high. If count_ena is high, we will decrement the current value in the shift register. If count_ena is low and shift_ena is high, we will perform a left logical shift on the shift register by moving each bit to the left and taking in the new data into the least significant bit position.
