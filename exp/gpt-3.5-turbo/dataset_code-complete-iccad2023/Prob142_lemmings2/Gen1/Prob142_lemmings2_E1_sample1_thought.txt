We can model the Lemmings' behavior using a Mealy state machine with four states: WALK_LEFT, WALK_RIGHT, FALLING, and GROUND. The Lemming will have outputs for walking left, walking right, saying "aaah!" while falling, and resuming walking after the fall depending on the inputs and the current state. Employing a Mealy state machine allows for a more direct association between the inputs, state transitions, and outputs.
