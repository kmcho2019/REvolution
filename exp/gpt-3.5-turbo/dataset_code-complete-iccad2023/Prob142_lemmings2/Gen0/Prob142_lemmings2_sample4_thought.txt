- Initialize two states: WALK_LEFT and WALK_RIGHT.
- When in the WALK_LEFT state, check if bump_right is high. If true, transition to the WALK_RIGHT state. Otherwise, check if ground is low and transition to the FALLING state with aaah output high.
- When in the WALK_RIGHT state, check if bump_left is high. If true, transition to the WALK_LEFT state. Otherwise, check if ground is low and transition to the FALLING state with aaah output high.
- In the FALLING state, wait until ground becomes high again and return to the previous walking direction state (WALK_LEFT or WALK_RIGHT).
