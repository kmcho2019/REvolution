To build a 4-digit BCD counter with enable signals for digits [3:1] and a synchronous active-high reset, we can cascade four BCD counters, each representing one decimal digit. We will also implement logic to generate enable signals based on the value of the units digit. When the units digit reaches 9, the tens digit should increment. Similarly, when the tens digit reaches 9, the hundreds digit should increment. The logic for the BCD counters will have to include a reset condition to initialize the counter and a clocked incrementation mechanism.
