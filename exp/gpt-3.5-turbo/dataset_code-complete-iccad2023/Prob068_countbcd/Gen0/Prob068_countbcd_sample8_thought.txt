To implement a 4-digit BCD counter with individual enables for the upper three digits, we can create individual counters for each digit. The counter for the ones digit (q[3:0]) will be incremented on every clock cycle. The counters for the tens, hundreds, and thousands digits will only be incremented when their corresponding enable signals are high. A synchronous active-high reset signal will be used to reset the counters. We will ensure each counter wraps around to 0 after reaching 9.
