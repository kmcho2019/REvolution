To implement a 4-digit BCD counter with enable signals for the upper three digits and a synchronous active-high reset, we can create a BCD counter module that contains the BCD counting logic for one digit. Then, we can instantiate four instances of this module and connect them appropriately. The enable signals for the tens, hundreds, and thousands digits can be derived from the current count value of the corresponding digit. The output BCD counter values should wrap around from 9 to 0 after reaching 9.
