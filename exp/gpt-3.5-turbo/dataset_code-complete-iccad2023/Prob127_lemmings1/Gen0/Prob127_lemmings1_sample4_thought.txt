For this problem, we can implement a simple Moore Finite State Machine with two states: walking left and walking right. The bumps received by the Lemming will determine the state transition.

State 0: walking left
State 1: walking right

State transition:
- State 0 transitions to State 1 on bump_left signal.
- State 1 transitions to State 0 on bump_right signal.
- If both bump_left and bump_right signals are HIGH, the Lemming switches direction.
