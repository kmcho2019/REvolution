The Lemming's behavior can be modeled using a Moore state machine with two states: walking left and walking right. The machine will transition between the states based on the inputs bump_left and bump_right. 

State transition:
- If the current state is walking left and bump_right is high, transition to walking right state.
- If the current state is walking right and bump_left is high, transition to walking left state.
- If both bump_left and bump_right are high, transition to the opposite state.

Output logic:
- Output walk_left should be high when in the walking left state.
- Output walk_right should be high when in the walking right state.

Initialize the state machine to walking left on areset signal.
