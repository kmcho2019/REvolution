To design a one-input one-output serial 2's complementer Moore state machine, we can create a Mealy state machine with three states: INIT, ACCUMULATE, and OUTPUT. In the INIT state, the machine waits for the reset to be released. Once released, it transitions to the ACCUMULATE state where it accumulates the 2's complement of the input by toggling the bits. Finally, in the OUTPUT state, it outputs the 2's complement result.
