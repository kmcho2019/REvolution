The state machine should have 3 states - STATE_IDLE, STATE_CONVERTING, and STATE_DONE. 
In STATE_IDLE, it waits for the release of the asynchronous reset, in STATE_CONVERTING it processes each bit to calculate the 2's complement, and in STATE_DONE it waits for the next conversion cycle or reset. 
The output should be formatted correctly as an 8-bit vector to avoid errors during simulation.
