- The state machine should have two states: WAIT and CONVERT.
- In the WAIT state, the machine waits for the release of the reset signal.
- Once the reset signal is released, the machine transitions to the CONVERT state and starts complementing the input bits.
- When the reset signal is asserted, the machine returns to the WAIT state.
- For each input bit (x), the machine calculates the 2's complement (z) and outputs it in parallel.
