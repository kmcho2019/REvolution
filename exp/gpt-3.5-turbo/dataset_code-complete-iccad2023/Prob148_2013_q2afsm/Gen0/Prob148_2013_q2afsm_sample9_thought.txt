To implement the arbiter FSM described, you can create a Mealy state machine with 4 states (A, B, C, D) and use the inputs r[1], r[2], r[3] along with the current state to determine the next state and the outputs g[1], g[2], g[3]. The priority logic can be implemented in the state transitions to decide which device gets the grant. Separate always blocks can be used for the state transition logic and the Mealy output logic.
