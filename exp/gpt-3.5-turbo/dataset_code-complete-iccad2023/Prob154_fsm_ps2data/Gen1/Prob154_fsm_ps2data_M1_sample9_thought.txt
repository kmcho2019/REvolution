We will design a state machine with 4 states: IDLE, FIRST_BYTE, SECOND_BYTE, and THIRD_BYTE. 
In the IDLE state, we will wait for the input byte with in[3]=1 and then transition to FIRST_BYTE state. 
In each of the FIRST_BYTE, SECOND_BYTE, and THIRD_BYTE states, we will correctly store the received bytes and transition to the next state. 
Once the THIRD_BYTE state is reached, we will set the done signal high and output the 3 bytes. Additionally, we will handle the case where the input stream may not contain a complete message and ensure the FSM resets appropriately in such scenarios.
