We will design an FSM with 5 states: WAIT, RECEIVE_BYTE1, RECEIVE_BYTE2, RECEIVE_BYTE3, and OUTPUT_MESSAGE. In the WAIT state, we will look for the start of a message. When a valid message is detected, we will transition through the RECEIVE_BYTE1, RECEIVE_BYTE2, and RECEIVE_BYTE3 states to capture the 3 bytes. Once all 3 bytes are captured, we will transition to OUTPUT_MESSAGE state to output the message and set the done signal.
