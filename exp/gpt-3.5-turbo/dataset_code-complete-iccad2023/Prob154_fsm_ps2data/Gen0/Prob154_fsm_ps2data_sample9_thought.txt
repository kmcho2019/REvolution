We can implement the FSM with 4 states: IDLE, BYTE1, BYTE2, and BYTE3. 
In the IDLE state, we wait for the input byte in[3] to be high to transition to BYTE1. 
In the BYTE1, BYTE2, and BYTE3 states, we collect the 3 bytes into out_bytes. 
Once BYTE3 state is reached, we signal done and go back to the IDLE state.
