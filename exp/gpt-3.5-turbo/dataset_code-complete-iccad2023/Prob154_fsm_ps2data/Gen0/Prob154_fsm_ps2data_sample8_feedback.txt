The FSM transitions in the code seem to represent the desired behavior as described in the problem statement. However, the issue arises from the way the states are being handled. When transitioning between states, the conditions are not being properly synchronized with the clock edge, leading to incorrect state changes and data capture. This desynchronization causes incorrect message boundaries to be detected, leading to wrong output bytes and done signal being asserted at the incorrect time, hence resulting in the large number of mismatches observed in the simulation log.
