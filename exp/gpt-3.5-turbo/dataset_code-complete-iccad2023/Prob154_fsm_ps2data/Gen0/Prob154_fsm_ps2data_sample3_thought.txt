We can implement a simple finite state machine with three states: WAIT_FOR_START, RECEIVING, and DONE. In the WAIT_FOR_START state, we discard incoming bytes until we see in[3] is high. When in[3] is high, we transition to the RECEIVING state and start collecting the 3 bytes of the message. Once we have collected all 3 bytes, we transition to the DONE state and output the 24-bit message. After one clock cycle in the DONE state, we return to the WAIT_FOR_START state.
