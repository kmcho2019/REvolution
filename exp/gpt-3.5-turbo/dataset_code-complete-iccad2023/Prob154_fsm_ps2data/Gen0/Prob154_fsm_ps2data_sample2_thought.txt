The datapath module needs to keep track of the received bytes and signal when a message is completed. We can do this by implementing a finite state machine with 4 states: IDLE, FIRST_BYTE, SECOND_BYTE, and THIRD_BYTE. In the IDLE state, we wait for the first byte with in[3]=1. Once we detect it, we transition to the FIRST_BYTE state to receive the second byte, and then to the SECOND_BYTE state to receive the third byte. Finally, in the THIRD_BYTE state, we output the 24-bit message and set done signal high.
