To implement the gshare branch predictor with the given specifications, we will:
1. Create a 128-entry 2-bit pattern history table (PHT) to store the saturating counters.
2. Implement a branch history register to store the global branch history.
3. Use the global branch history and program counter (pc) to generate the index for accessing the PHT.
4. Provide separate interfaces for prediction and training, ensuring training takes precedence over prediction when conflicting.
5. Update the PHT and branch history register based on the training outcome.
