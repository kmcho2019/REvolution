To implement the gshare branch predictor, we need to create a Pattern History Table (PHT), which is a table of 128 two-bit saturating counters indexed by a 7-bit hashed address. We also need a 7-bit global history register to keep track of the history of branch outcomes. The predictor should provide predictions based on the history register and update the history register based on the predicted outcome. For training, the predictor should update the PHT based on the actual outcome of the branch.
