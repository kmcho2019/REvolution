To implement the gshare branch predictor with the described interface and functionality, we need to create the necessary components:
1. Branch Predictor module to handle prediction and training based on the gshare algorithm.
2. Pattern History Table (PHT) to store the two-bit saturating counters for each entry.
3. Global History Register to keep track of the global history.
4. Hash function to generate the index for accessing the PHT.

We will update the PHT, predict the branch direction based on the PHT state and global history, and update the global history register according to the prediction and training inputs.
