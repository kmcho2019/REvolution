To implement the gshare branch predictor as described, we need to:
1. Create a 128-entry 2-bit pattern history table (PHT) to store the saturating counters.
2. Maintain a 7-bit global branch history register.
3. Calculate the index for accessing the PHT by hashing the PC and global history and extract the corresponding saturating counter value.
4. Design separate blocks for prediction and training, ensuring training takes precedence over predictions.
5. Update the PHT and global branch history register based on training inputs.
6. Handle conflicting updates correctly to ensure training always takes precedence over prediction modifications in the same cycle.
