We can design a finite state machine with four states: IDLE, START_BIT, DATA, and STOP_BIT. 
- The FSM will transition to START_BIT upon detecting a start bit in the IDLE state.
- In the START_BIT state, it will proceed to DATA state after one clock cycle.
- During the DATA state, it will capture 8 data bits.
- Upon capturing 8 data bits, the FSM will proceed to STOP_BIT state.
- In the STOP_BIT state, it will output the byte and set the done signal if the stop bit is correct, else it will remain in STOP_BIT until the correct stop bit is received.
