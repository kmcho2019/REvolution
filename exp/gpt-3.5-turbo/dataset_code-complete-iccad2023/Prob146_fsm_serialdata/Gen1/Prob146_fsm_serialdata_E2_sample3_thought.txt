We can design a finite state machine with four states: IDLE, START_BIT, DATA, and STOP_BIT. The FSM should wait for the line to be at logic 1 in the IDLE state. It will transition to the START_BIT state upon detecting a start bit (logic 0). The DATA state will capture each incoming data bit until it collects 8 data bits. The STOP_BIT state will wait for the stop bit (logic 1) and indicate when a byte has been correctly received. The FSM should assert done each time it finds a stop bit and then transition back to the IDLE state to wait for the next start bit.
