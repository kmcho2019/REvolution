The finite state machine (FSM) will have 4 states: IDLE, START_BIT, DATA_BITS, and STOP_BIT. Upon detecting a start bit in the IDLE state, the FSM will transition to the START_BIT state. In the START_BIT state, it will collect the next 8 data bits. After capturing all data bits, it will go to the STOP_BIT state to wait for the stop bit. If the correct stop bit is received, it will output the data byte and signal that the byte is ready.
