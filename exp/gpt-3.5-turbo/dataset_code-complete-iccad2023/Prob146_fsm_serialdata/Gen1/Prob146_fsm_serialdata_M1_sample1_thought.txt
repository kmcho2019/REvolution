The finite state machine should have five states: IDLE, DETECT_START_BIT, RECEIVE_DATA_BITS, DETECT_STOP_BIT, WAIT_FOR_IDLE.  The FSM should transition to the WAIT_FOR_IDLE state after receiving the stop bit, where it waits until the input line returns to an idle state (logic 1). This approach ensures accurate byte reception and proper state transitions while considering the start and stop bit conditions.
