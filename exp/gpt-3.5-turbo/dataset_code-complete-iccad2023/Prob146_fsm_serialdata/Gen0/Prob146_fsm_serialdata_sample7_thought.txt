We can design a finite state machine with four states: IDLE, START_BIT, DATA, and STOP_BIT. 

- IDLE state waits for the line to be at logic 1. 
- START_BIT state waits for the start bit (logic 0). 
- DATA state captures each incoming data bit until it collects 8 data bits. 
- STOP_BIT state waits for the stop bit (logic 1). Once the stop bit is received, it indicates that a byte has been correctly received.

When done is asserted, the FSM goes back to the IDLE state to wait for the next start bit.
