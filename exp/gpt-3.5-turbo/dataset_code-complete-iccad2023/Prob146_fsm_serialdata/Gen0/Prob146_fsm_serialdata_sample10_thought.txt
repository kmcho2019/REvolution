The finite state machine can have four states: IDLE, START_BIT, DATA_BITS, STOP_BIT. When in IDLE state, the FSM waits for the input line to go low (start bit). When in START_BIT state, the FSM moves to DATA_BITS state after waiting for one clock cycle. In DATA_BITS state, the FSM collects the 8 data bits. Once all the data bits are collected, the FSM moves to STOP_BIT state and waits for the input line to go high (stop bit). If the stop bit is correct, the output byte is updated with the received data bits.
