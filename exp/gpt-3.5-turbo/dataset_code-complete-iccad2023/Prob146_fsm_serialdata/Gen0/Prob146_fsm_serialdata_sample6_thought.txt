Create a 3-state finite state machine where the states are WAIT_FOR_START, RECEIVE_DATA, and WAIT_FOR_STOP. In the WAIT_FOR_START state, look for a start bit ('0'). Transition to RECEIVE_DATA when the start bit is detected. In RECEIVE_DATA state, read in the next 8 data bits. Transition to WAIT_FOR_STOP when all data bits are received. In WAIT_FOR_STOP state, check for a stop bit ('1'). If stop bit is correct, output the received byte and assert done. If stop bit is incorrect, remain in WAIT_FOR_STOP until a stop bit is found.
