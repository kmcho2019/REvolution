The finite state machine can be designed to have the following states:
- IDLE: The initial state where it waits for a start bit.
- START_BIT: It detects the start bit and transitions to the RECEIVE_DATA state.
- RECEIVE_DATA: It receives and stores the 8 data bits.
- STOP_BIT: It verifies the stop bit before going back to IDLE state and outputting the received byte.

The state machine will transition based on the input bit stream and the clock signal. The output byte will be captured in the RECEIVE_DATA state and output when done is asserted.
