One way to design this finite state machine is to have six states: IDLE, START_BIT, RECEIVE_BITS 0-7, and STOP_BIT. When in the IDLE state, the FSM waits for a start bit. When the start bit is detected, it moves to the START_BIT state and starts a counter to receive the next 8 bits. After receiving all 8 bits, it moves to the STOP_BIT state to check for the stop bit. If the stop bit is correct, the received byte is stored in out_byte and done is asserted.
