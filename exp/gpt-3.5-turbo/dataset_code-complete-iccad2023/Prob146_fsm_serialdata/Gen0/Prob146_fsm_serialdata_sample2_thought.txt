The finite state machine (FSM) will have 5 states: IDLE, START_BIT, DATA_BITS_0-7, and STOP_BIT. Whenever a start bit is detected in the IDLE state, the FSM will transition to the START_BIT state. In the START_BIT state, it will wait for the next 8 clock cycles to read the data bits. After reading all data bits, it will transition to the STOP_BIT state where it will wait for the stop bit. If the correct stop bit is received, it will output the data byte and set done signal.
