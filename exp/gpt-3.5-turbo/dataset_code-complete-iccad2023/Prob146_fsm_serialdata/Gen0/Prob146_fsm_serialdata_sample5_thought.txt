The finite state machine can have the following states:
1. IDLE: Waiting for the line to go low to identify the start bit.
2. RECEIVING: Capturing 8 data bits after the start bit.
3. STOP_BIT: Verifying the stop bit.

The FSM transitions between these states based on the input and the current state. When the stop bit is detected, out_byte is loaded with the received data byte.
