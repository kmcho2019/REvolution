The FSM can have three states: IDLE, ONE, and MORE_ONES. The inputs driving the state transitions are the input bit (in) and reset signal. In the IDLE state, we wait for the first 0 bit after reset. In the ONE state, we detect the pattern 0111. In the MORE_ONES state, we check if there are 6 or more 1 bits to signal 'flag' or 'err', otherwise, we continue to check for more consecutive 1 bits.
