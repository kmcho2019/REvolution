The finite state machine can have 3 states: SEARCH_0111110, SEARCH_01111110 and ERROR. We transition to the next state based on the incoming data. We use a single internal state ('count') to keep track of the number of consecutive 1s seen. If we see 5 consecutive 1s, we output 'disc'. If we see 6 consecutive 1s, we output 'flag'. If we see 7 or more consecutive 1s, we output 'err'.
