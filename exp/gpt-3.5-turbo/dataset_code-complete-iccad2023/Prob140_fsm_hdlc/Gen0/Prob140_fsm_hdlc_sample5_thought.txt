We can design a Moore-type finite state machine with 4 states: IDLE, ONE, TWO, and ERR. In IDLE state, we wait for the first '0'. In ONE state, we check for the next 5 bits to detect the bit to be discarded. In TWO state, we check for the next bit to determine if it's a flag or an error. In ERR state, we stay in this state if we detect 7 or more consecutive 1s.
