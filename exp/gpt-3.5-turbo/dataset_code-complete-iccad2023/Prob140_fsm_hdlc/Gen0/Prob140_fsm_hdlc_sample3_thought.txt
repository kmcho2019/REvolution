The Finite State Machine can have 4 states: IDLE, F1_FOUND, F2_FOUND, ERROR. In the IDLE state, the machine waits for the first '0' after which it transitions to the F1_FOUND state. In F1_FOUND and F2_FOUND states, it looks for the next fewer consecutive ones to determine disc or flag. If there are more than 6 consecutive ones, it transitions to the ERROR state. Each state transition happens on a clock edge.
