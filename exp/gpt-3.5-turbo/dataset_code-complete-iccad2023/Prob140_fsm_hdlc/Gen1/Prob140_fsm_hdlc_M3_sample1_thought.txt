Create a Moore-type finite state machine with three states:
(1) State 0: Looking for the start of a flag sequence (transition to state 1 when 0111110 is detected).
(2) State 1: Looking for the end of a flag sequence - when 01111110 is detected, assert flag.
(3) State 2: Error state - if more than 7 1s are detected, assert err.

Utilize a simple shift register to detect the 0111110 pattern for the disc output. On reaching 5 consecutive 1s, assert disc and reset the shift register.
