Develop a Moore-type finite state machine with three states:
(1) State 0: Initial state where we look for the start of a flag sequence - '0111'.
(2) State 1: Detection state where we look for the continuation of flag sequence or error condition.
(3) State 2: Error state where we detect 7 consecutive 1s.

Implement a shift register mechanism to detect the required bit patterns and update the outputs accordingly. Error detection should be prioritized to trigger before the flag detection.
