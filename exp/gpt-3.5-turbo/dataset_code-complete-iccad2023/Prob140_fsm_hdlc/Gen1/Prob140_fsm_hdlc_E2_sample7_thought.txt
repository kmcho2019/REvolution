Create a 3-state Moore-type finite state machine with the following states:
(1) State 0: Looking for 0111 pattern, transition to state 1 if 0111 is detected.
(2) State 1: Check for subsequent bits to determine disc, flag, or err conditions.
(3) State 2: Error state, transition back to state 0 on the next cycle.
