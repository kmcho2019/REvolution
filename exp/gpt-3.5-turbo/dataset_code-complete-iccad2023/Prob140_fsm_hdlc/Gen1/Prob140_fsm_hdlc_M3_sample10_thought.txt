Implement a Moore-type finite state machine with three states:
(1) State 0: Look for the start of a flag/discard sequence (0111110). Transition to state 1 if 0111110 is detected.
(2) State 1: Look for the end of a flag sequence (01111110) or 7 or more 1s. If 01111110 is detected, assert flag. If 7 or more 1s are detected, assert err. Otherwise, go back to state 0 with discard output.
