Implement a Moore-type finite state machine with 3 states:
- State 0: Looking for the start of a flag sequence (transition to state 1 when 0111110 is detected).
- State 1: Flag found - waiting for the end of the flag sequence (transition to state 2 when 01111110 is detected, otherwise back to state 0).
- State 2: Error state - if 7 or more 1s are detected, assert an error. If 01111110 is detected, return to state 0.
