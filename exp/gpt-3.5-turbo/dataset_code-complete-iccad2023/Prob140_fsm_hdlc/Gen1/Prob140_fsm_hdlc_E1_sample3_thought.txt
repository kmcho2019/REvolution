Create a Mealy-type finite state machine with four states:
(1) State 0: Initial state, looking for the start of a flag sequence.
(2) State 1: Detected 5 consecutive 1s, waiting for the next bit to determine disc or flag.
(3) State 2: Detected 6 consecutive 1s, signal flag.
(4) State 3: Detected 7 or more consecutive 1s, signal error.

Utilize a single shift register to detect the patterns and update outputs based on both input and state transitions.
