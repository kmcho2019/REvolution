One approach to implementing this FSM is to use a Mealy-type machine where the outputs are dependent on both the current state and the input. We can have four states - S0, S1, S2, and S3 to handle the different sequences. In S0, we check for the start of the 0111110 pattern. In S1, we look for the end of the same pattern and assert "disc". In S2, we check for the potential error state of 7 or more consecutive 1s. In S3, we flag the beginning and end of a frame.
