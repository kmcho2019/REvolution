Create a Mealy-type finite state machine with four states:
(1) State 0: Initial state handling post-reset behavior.
(2) State 1: Looking for the start of a flag sequence (transition to state 2 when 0111110 is detected).
(3) State 2: Looking for the end of a flag sequence - when 01111110 is detected, assert flag and move to state 0.
(4) State 3: Error state - if more than 7 1s are detected, assert err and move to state 0.

Implement a single-bit shift register to detect 0111110 pattern for the disc output. Utilize a separate counter to detect the number of consecutive 1s for error detection.
