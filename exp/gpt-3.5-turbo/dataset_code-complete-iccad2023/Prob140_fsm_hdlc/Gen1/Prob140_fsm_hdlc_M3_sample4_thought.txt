To simplify the implementation, I will focus on a Moore-type FSM with three states:
1. State 0: Initial state to look for the start of a flag sequence (0111110).
2. State 1: Transition state after detecting 0111110 to look for the end of a flag sequence (01111110) and set `flag`.
3. State 2: Error state to check for 7 or more consecutive 1s and set `err`.

For the disc output, I will use a 6-bit shift register to detect the 0111110 pattern and assert `disc` when detected.
