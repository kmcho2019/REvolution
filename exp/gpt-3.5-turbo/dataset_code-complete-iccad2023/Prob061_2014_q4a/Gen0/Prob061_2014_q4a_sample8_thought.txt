We can implement the one stage of the shift register circuit with a D flip-flop for storing the current value, and two multiplexers for selecting the input based on the control signals.
The multiplexer connected to the D input of the flip-flop will choose between the input value w and the value stored in the flip-flop based on the E signal. The other multiplexer connected to the D input of the flip-flop will choose between the value on the input R and the output of the first multiplexer based on the load signal L.
