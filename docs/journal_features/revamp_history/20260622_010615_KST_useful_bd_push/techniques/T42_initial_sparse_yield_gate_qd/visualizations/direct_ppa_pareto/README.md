# T42 Direct PPA Viewer

Status: complete and visually inspected.

Files:

- `index.html`
- `metrics.json`
- `screenshot.png`

Open `index.html` in a browser to inspect the straightforward raw area-power
Pareto comparison. The viewer intentionally starts with the same conventional
area-power front used by the primary PNG, then lists per-problem valid-PPA,
method-front, pooled-front, and best-score rows.
