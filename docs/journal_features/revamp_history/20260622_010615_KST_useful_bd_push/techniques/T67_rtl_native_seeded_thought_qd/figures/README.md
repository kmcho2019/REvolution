# T67 Figures

Run figures are stored in `hard_tuning_package/figures/` and copied into
`visualizations/direct_ppa_pareto/` for the reader-facing supplement.

Primary files:

- `visualizations/direct_ppa_pareto/t67_raw_area_power_fronts_seed1001.png`
  is the lower-left-better raw area-power PPA-front panel.
- `hard_tuning_package/figures/t67_metric_delta_summary.png` summarizes
  aggregate deltas.
- `hard_tuning_package/figures/t67_validity_funnel.png` summarizes yield.
- `hard_tuning_package/figures/t67_front_counts.png` shows per-problem
  front-point loss.
- `hard_tuning_package/figures/t67_thought_seed_counters.png` shows thought
  and seeded-code counts with readable horizontal labels.
- `hard_tuning_package/figures/visual_inspection_notes.md` records the
  screenshot inspection.
