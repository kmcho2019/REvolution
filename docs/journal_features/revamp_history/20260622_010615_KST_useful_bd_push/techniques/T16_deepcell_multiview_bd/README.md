# T16 DeepCell Multiview BD

Status: `T0 retrospective_multiview_proxy_not_promoted`.

This package closes the DeepCell-style scaffold with measured proxy evidence
from directed hypergraph, official DeepGate AIG/cone, RF/DeepGate hybrid, and
raw implementation-feature experiments. It does not claim a true DeepCell
reproduction.

## Scope

The original target was a paired post-mapping standard-cell plus AIG multiview
descriptor with optional masked-circuit training. The current branch has
measured adjacent views, but it has not trained a paired DeepCell model.

## Decision

Do not spend on exact deterministic multiview proxy axes. T14 shows that
hypergraph plus implementation features can preserve replay HV signal, but
front hits still trail lexical. T95/T96/T99 then show that live AIG/netlist,
hybrid, and implementation-view archives still trail classic on the frozen
screen.

Reopen only with a true paired cell-view plus AIG-view extraction path, a
masked multiview objective, or a secondary role that improves front creation
without replacing classic exploitation.
