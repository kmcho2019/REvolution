# T65 Tables

| Table | Description |
| --- | --- |
| `secondary_rtl_features.csv` | Candidate-level features extracted from source RTL and assigned problem-local secondary cells. |
| `secondary_cell_metrics.csv` | Aggregate method/profile cell metrics. |
| `secondary_problem_metrics.csv` | Per-problem method/profile cell metrics. |
| `secondary_deltas_vs_classic.csv` | Problem-paired deltas versus Classic. |
| `secondary_delta_summary.csv` | Compact win/loss/tie and mean-delta summary. |

The comparison surface is the direct unique-PPA candidate CSV surface from the
T51, T63, and T64 packages. The viewer datasets are used only to recover code
paths for descriptor extraction.
