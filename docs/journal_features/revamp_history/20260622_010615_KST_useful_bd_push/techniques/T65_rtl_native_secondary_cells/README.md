# T65 RTL-Native Secondary Cells

T65 is a posthoc secondary-cell audit over the T51, T63, and T64 hard/tuning
packages. It uses direct unique-PPA candidate CSVs for the comparison surface
and Phase 03.1 viewer datasets only to recover code paths for source-level
RTLTimer-style descriptor extraction.

Decision: `T0 diagnostic_secondary_cell_not_promoted`.

Start with `results_report.md`, then use `tables/secondary_delta_summary.csv`
and `figures/secondary_cell_delta_summary.png` for the compact result.
