# T69 Figures

`t69_open_yosys_preprocessing_alignment.png` compares open-clean TinyRocket
artifacts against the shipped upstream examples. The bars are ratios, so `1.0`
means the open-source generated artifact exactly matches the shipped count for
that metric.

Visual inspection note: the figure is legible at report scale, uses a dashed
baseline for the shipped artifact, and shows the central conclusion directly:
the open-source MasterRTL graph and RTL-Timer SOG BOG stay close to the
upstream examples.
