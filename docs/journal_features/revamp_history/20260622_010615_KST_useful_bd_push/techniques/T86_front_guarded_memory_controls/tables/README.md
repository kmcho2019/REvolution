# T86 Tables

- `random_memory_aggregate_backend_metrics.csv`: formal smoke aggregate over
  classic, SR-memory FG-QDM, and random-memory FG-QDM.
- `random_memory_backend_problem_metrics.csv`: per-problem Pareto/HV metrics.
- `random_memory_mechanism_summary.csv`: memory-lane generated, valid-PPA, and
  front-add counts for random-memory and SR-memory FG-QDM.

The full generated report tables remain under `analysis/`.
