# T43 Phase 03.1 QD/PPA Viewer

This is the full Phase 03.1-compatible linked archive/PPA viewer for T43.
It is generated by `scripts/export_qd_ppa_visualization.py`, not by the
smaller direct-PPA wrapper.

## Contents

- `index.html`: local browser viewer.
- `manifest.json`: `qd_ppa_viewer.v2` manifest.
- `datasets/*.json`: one problem dataset per frozen T43 screen problem.
- `descriptor_cache.json`: recovered classic descriptor values used for
  posthoc archive projection.
- `validation.{json,md}`: strict validator output.
- `screenshot.png`: inspected 1440-by-1000 Playwright screenshot.

## Source And Projection

The viewer uses `classic` as the visualization key for the baseline. That key
maps to the live `classic_revolution/seed_1001` backend run. The QD key is
`staged_sparse_yield_gate_qd`.

Classic candidates are projected into the T43 QD archive posthoc using the
same descriptor axes as the archive:

- `rtl_cyclomatic_total_log`
- `reconv_sink_ratio`
- `scoap_signal_smoothness`

Projection coverage after export is complete:

| Problem | Classic projected | Classic total |
| --- | ---: | ---: |
| `Prob045_alu` | 35 | 35 |
| `Prob041_traffic_light` | 12 | 12 |
| `Prob015_multi_pipe_8bit` | 14 | 14 |

## Regeneration

The committed source CSVs live in
`../qd_ppa_viewer_source/final_analysis/`. Regenerate the viewer with:

```bash
uv run python scripts/export_qd_ppa_visualization.py \
  --run-root docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T43_staged_sparse_yield_gate_qd/visualizations/qd_ppa_viewer_source \
  --backend_run classic=exp/useful_bd_push/t43_staged_sparse_yield_gate_qd_20260622_102415_UTC/classic_revolution/seed_1001 \
  --backend_run staged_sparse_yield_gate_qd=exp/useful_bd_push/t43_staged_sparse_yield_gate_qd_20260622_102415_UTC/staged_sparse_yield_gate_qd/seed_1001 \
  --archive_source_backend staged_sparse_yield_gate_qd \
  --subset-config docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T43_staged_sparse_yield_gate_qd/tables/live_screen_v0_subset.yaml \
  --output-dir docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T43_staged_sparse_yield_gate_qd/visualizations/qd_ppa_viewer \
  --strict
```

Validate with:

```bash
uv run python scripts/validate_qd_ppa_visualization.py \
  --viewer-root docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T43_staged_sparse_yield_gate_qd/visualizations/qd_ppa_viewer \
  --subset-config docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T43_staged_sparse_yield_gate_qd/tables/live_screen_v0_subset.yaml \
  --strict \
  --playwright
```

## Visual Read

Use `raw A-P front` mode in the PPA pane for the straightforward raw
area-power comparison. Use the archive panes to inspect where classic and T43
samples project into the QD archive over the final timeline snapshot.
