| File | Meaning |
| --- | --- |

| `reference_ppa_metrics.csv` | Reference PPA rows used for normalized metrics. |
| `best_candidate_by_backend_problem.csv` | Best candidate selected by backend and problem. |

All `13` problems have valid reference PPA in this package.
