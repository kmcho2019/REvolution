# T44 Direct PPA Pareto Viewer

This is the reader-facing raw area-power supplement generated by
`scripts/package_t44_t11_runtime_graph_bridge.py`.

- `index.html`: filesystem-openable direct PPA-front view.
- `metrics.json`: problem/method summary used by the HTML table.
- `screenshot.png`: inspected Playwright screenshot.

This supplement is useful for paper-readable raw PPA fronts, but it is not the
full Phase 03.1 linked archive/PPA viewer. Use
`../qd_ppa_viewer/index.html` for timeline, compare mode, archive projection,
coordinate controls, and linked archive/PPA inspection.
