# T44 Phase 03.1 QD/PPA Viewer

This is the full Phase 03.1-compatible linked archive/PPA viewer for T44.
It is generated by `scripts/export_qd_ppa_visualization.py`, not by the
smaller direct-PPA wrapper.

## Contents

- `index.html`: local browser viewer.
- `manifest.json`: `qd_ppa_viewer.v2` manifest.
- `datasets/*.json`: one problem dataset per frozen T44 screen problem.
- `descriptor_cache.json`: recovered classic descriptor values used for
  posthoc archive projection.
- `validation.{json,md}`: strict validator output.
- `screenshot.png`: inspected 1440-by-1000 Playwright screenshot.

## Source And Projection

The viewer uses `classic` as the visualization key for the baseline. That key
maps to the live `classic_revolution/seed_1001` backend run. The QD key is
`t11_runtime_top8_graph_qd`.

Classic candidates are projected into the T44 QD archive posthoc using the
same descriptor axes as the archive:

- `hyper_mean_fanout`
- `edge_per_node`
- `log_edge_count`
- `hyper_directed_edge_count`
- `hyper_fanout_entropy`
- `hyper_driven_net_count`
- `hyper_sink_net_count`
- `log_net_count`

Projection coverage after export is complete:

| Problem | Classic projected | Classic total | T44 projected | T44 total |
| --- | ---: | ---: | ---: | ---: |
| `Prob045_alu` | 35 | 35 | 16 | 16 |
| `Prob041_traffic_light` | 25 | 25 | 7 | 7 |
| `Prob015_multi_pipe_8bit` | 16 | 16 | 13 | 13 |

Strict Playwright validation initially found that high-dimensional occupied
archive cells rendered samples but did not expose filled-cell hover targets.
The viewer now renders occupied cells from actual cell summaries, and the T44
strict validation passes.

## Regeneration

The committed source CSVs live in
`../qd_ppa_viewer_source/final_analysis/`. Regenerate the viewer with:

```bash
RUN_ROOT="exp/useful_bd_push/t44_t11_runtime_graph_bridge_20260622_114838_UTC"
uv run python scripts/export_qd_ppa_visualization.py \
  --run-root docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T44_t11_runtime_graph_bridge/visualizations/qd_ppa_viewer_source \
  --backend_run classic="${RUN_ROOT}/classic_revolution/seed_1001" \
  --backend_run t11_runtime_top8_graph_qd="${RUN_ROOT}/t11_runtime_top8_graph_qd/seed_1001" \
  --archive_source_backend t11_runtime_top8_graph_qd \
  --subset-config docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T44_t11_runtime_graph_bridge/tables/live_screen_v0_subset.yaml \
  --output-dir docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T44_t11_runtime_graph_bridge/visualizations/qd_ppa_viewer \
  --strict
```

Validate with:

```bash
uv run python scripts/validate_qd_ppa_visualization.py \
  --viewer-root docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T44_t11_runtime_graph_bridge/visualizations/qd_ppa_viewer \
  --subset-config docs/journal_features/revamp_history/20260622_010615_KST_useful_bd_push/techniques/T44_t11_runtime_graph_bridge/tables/live_screen_v0_subset.yaml \
  --strict \
  --playwright
```

## Visual Read

Use `raw A-P front` mode in the PPA pane for the straightforward raw
area-power comparison. Use the archive panes to inspect where classic and T44
samples project into the high-dimensional T44 QD archive over the final
timeline snapshot.
