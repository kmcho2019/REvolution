# T70 Tables

- `t70_candidate_manifest.csv`: deterministic candidate sample with hashes and
  synthesis-stratification labels.
- `t70_extractor_results.csv`: per-candidate MasterRTL and RTL-Timer pass/fail
  status plus artifact-size metrics.
- `t70_extractor_summary.csv`: pass-count summary by sample group.
- `t70_extractor_metrics.json`: compact machine-readable summary.

The tables are regenerated by `../tools/run_t70_extractor_smoke.py`.
