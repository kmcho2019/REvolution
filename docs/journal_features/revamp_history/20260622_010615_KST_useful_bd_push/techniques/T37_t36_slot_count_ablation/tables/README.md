# T37 Tables

- `archive_comparison.csv`: main metric table combining replay aggregate
  metrics with direct raw PPA front metrics.
- `ppa_comparison.csv`: replay aggregate metrics before direct-front columns
  are joined.
- `ppa_front_metrics.csv`: selected raw area-power front points, front hits,
  and unique PPA tuples.
- `ppa_front_plot_points.csv`: candidate-level data used by the static raw PPA
  front plots and HTML viewer.
- `selected_candidates.csv`: retained candidate rows for every comparator and
  T37 slot-count arm.
- `replay_rows.csv`: replay-level rows used to aggregate selected PPA metrics.
- `slot_summary.csv`: per-group slot-count configuration and descriptor-cell
  occupancy.
- `feature_manifest.csv`: T11 structural feature list and contrastive weights
  used by the inherited descriptor.
