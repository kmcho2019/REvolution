# T37 Figures

Open the direct raw PPA Pareto figures first:

- `t37_multi_problem_ppa_pareto_fronts.png`: four representative problem
  panels, raw area on x and raw power on y, lower-left is better.
- `t37_raw_area_power_pareto_front.png`: full-range and zoomed raw
  area-power front for the focus problem.

Supporting summaries:

- `t37_hypervolume.png`: selected hypervolume by representation.
- `t37_front_hits.png`: selected all-valid raw area-power front hits by
  representation.

The plotted source data are in `../tables/ppa_front_plot_points.csv`.
