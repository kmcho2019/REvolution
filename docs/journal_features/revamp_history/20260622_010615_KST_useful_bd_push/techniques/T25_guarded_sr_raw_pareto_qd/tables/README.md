# T25 Tables

- `live_screen_v0_subset.yaml`: fixed three-problem development screen shared
  with T24.
- `run_matrix.csv`: pre-registered guarded SR raw command parameters.
- `preflight_models_20260621_210402_UTC.json`: mirrored vLLM `/v1/models`
  response for the T25 run.
- `live_guarded_pareto_validation.json`: raw Pareto archive validation result.
- `live_guarded_pareto_validation.md`: readable Pareto validation summary.
- `live_guarded_vs_t24_controls.csv`: generated comparison against T24
  manual BD, random, unguarded SR raw, and classic reference columns.

`live_guarded_vs_t24_controls.csv` is generated by
`scripts/package_t25_guarded_sr_raw_result.py`.
