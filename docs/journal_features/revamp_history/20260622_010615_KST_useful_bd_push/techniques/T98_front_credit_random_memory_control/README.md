# T98 Front-Credit Random-Memory Control

Status: completed control; not promoted.

T98 reruns T97's stricter front-credit FG-QDM scheduler with the deterministic
`random_hash_3d` descriptor. It tests whether T97's improvement came from the
stricter scheduler alone or from the SR memory descriptor.
