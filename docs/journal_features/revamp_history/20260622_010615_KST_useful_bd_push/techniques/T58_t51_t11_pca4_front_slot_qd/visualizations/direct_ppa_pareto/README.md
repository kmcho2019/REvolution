# T58 Direct PPA Pareto Supplement

Static, reader-facing PPA-front figures for the 13-problem hard/tuning
comparison of classic REvolution and T58.

- `index.html`: compact HTML wrapper for the static figures.
- `metrics.json`: headline aggregate metrics copied from the packaged tables.
- `screenshot.png`: Playwright-rendered screenshot after inspection.
- `t58_*.png`: packaged PPA, validity, front-count, and counter figures.

Use this supplement for paper/report reading. Use `../qd_ppa_viewer/` for the
full Phase 03.1 linked archive/PPA viewer.
