# T46 Frozen T11 PCA Graph Results Report

Status: pre-registered; live screen pending.

Tier: pending.

## Method Summary

T46 replaces T45's direct top-4 T11 graph axes with a frozen four-dimensional
PCA projection of the same top-8 graph feature family used in T44. The
projection is fitted only from non-PPA graph features in the T14 replay
feature table, then used online as ordinary archive coordinates.

The live screen, model, subset, seed, budget, operators, parent selection, and
archive mechanics stay fixed to T45.

## Required Result Evidence

Before assigning a tier, this package must include:

- matched classic and `t11_runtime_pca4_graph_qd` live outputs;
- Pareto-front validation over all three fixed RTLLM problems;
- direct raw area-power PPA-front PNGs and a filesystem-openable HTML
  supplement;
- full Phase 03.1 `visualizations/qd_ppa_viewer/` bundle with strict
  validation and inspected screenshot;
- table-level comparison against T45 top-4, T44 top-8, and T39 one-slot
  references;
- visual inspection notes.

## Current Decision

No result is claimed yet. T46 may advance only if it preserves every
classic-covered design and improves at least one primary QD/PPA metric without
an unreported yield collapse.
