# T46 Tables

- `live_screen_v0_subset.yaml`: fixed three-problem live screen inherited from
  T44 and T45.
- `run_matrix.csv`: pre-registered control, candidate, and frozen-reference
  rows.
- `t46_projection_components.csv`: frozen non-PPA PCA fit used by the runtime
  descriptor profile.
- `preflight_models_20260622_182358_UTC.json`: vLLM model metadata recorded
  before launch.
- `t46_method_manifest.csv`: package-local mapping for classic, T46, T45,
  T44, and T39 comparison rows.
- `t46_candidate_ppa_points.csv`: raw candidate-level area/power points used
  to regenerate the direct PPA figures and HTML supplement.
- `t46_problem_method_summary.csv`: per-method, per-problem counts, best score,
  and pooled-front hit summary.
- `t46_pareto_front_validation.{json,md}`: strict archive validation result for
  the matched T46 run.
