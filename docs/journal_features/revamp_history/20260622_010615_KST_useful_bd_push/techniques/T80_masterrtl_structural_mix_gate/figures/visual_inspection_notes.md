# T80 Visual Inspection Notes

## `figures/t80_masterrtl_structural_mix_gate.png`

The figure is readable and suitable for a method-gate report. The left panel
shows the new descriptor space directly: mux fraction on x, sequential
fraction on y, and xor fraction as color. The right panels make the main
decision clear: raw descriptor rows vary, static cells collapse to four
occupied bins, and quantile cells spread the same candidates across fifteen
occupied cells.

The plot should not be used as a PPA-performance figure. It is a descriptor
variation and archive-geometry figure only.
