# Tables

This directory stores the CSV tables generated by
`scripts/package_useful_bd_validation_matrix.py`.

- `validation_matrix.csv`: joined central replay and local-Pareto metrics for
  classic, manual BD, T22 random, T19 SR ReLU PCA, and T04 SR-RFF PCA.
- `local_pareto_retention.csv`: scalar-cell versus bounded local-Pareto
  retention deltas for the focused methods.
- `comparison_deltas.csv`: method deltas versus classic and T22 random
  descriptor for the headline validation metrics.
