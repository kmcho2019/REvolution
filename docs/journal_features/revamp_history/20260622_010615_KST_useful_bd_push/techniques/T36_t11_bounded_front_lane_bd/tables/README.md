# T36 Tables

- `archive_comparison.csv`: one-row-per-representation aggregate replay
  comparison with HV, front-hit, and unique-PPA deltas.
- `ppa_comparison.csv`: aggregate replay metrics before front-hit merge.
- `ppa_front_metrics.csv`: raw area-power front and all-valid front-hit
  metrics.
- `ppa_front_plot_points.csv`: source points for PNG and HTML PPA-front
  visualizations.
- `lane_summary.csv`: per-group front-lane quota and slot accounting.
- `selected_candidates.csv`: retained candidate rows for every representation.
- `replay_rows.csv`: per-problem replay rows used for aggregate metrics.
- `feature_manifest.csv`: T11 structural feature weights used by T36.
