# T71 Tables

| Table | Purpose |
| --- | --- |
| `t71_source_aligned_feature_table.csv` | Candidate-level raw extractor metrics, derived non-PPA diagnostics, and archive-cell assignment. |
| `t71_archive_cells.csv` | Occupied cell inventory with candidate lists and feature ranges. |
| `t71_feature_summary.csv` | Range and meaning for each diagnostic feature. |
| `t71_metrics.json` | Compact machine-readable metrics, descriptor inputs, and leakage exclusions. |

The feature table is designed to be the input contract for the next
source-aligned RTL-native live QD method.
