# T79 Direct PPA/Pareto Supplement

Open `index.html` for a static reader-facing summary of the T79 PPA/Pareto
results. This supplement is intentionally simpler than the full Phase 03.1
viewer and is meant for quick inspection.

- `metrics.json`: compact matched-shape metrics.
- `screenshot.png`: static screenshot source copied from the mean-HV summary
  figure.
- `index.html`: links to aggregate figures and per-problem Pareto diagnostics.
