# T12 Lineage Repair BD

Status: `T0 retrospective_direct_repair_retired`.

T12 is closed as a retrospective repair-lineage audit. The original idea was
to use parent history, edit class, and repair dynamics as behavior-descriptor
or emitter coordinates. Later live packages already tested the relevant repair
and lineage mechanisms:

- `T31_sr_raw_fail_feedback_repair_qd`: direct fail-pool repair text.
- `T49_thought_k_role_separated_repair_qd`: role-separated thought repair.
- `T51_code_thought_front_slot_qd`: code-individual front-slot recovery base.
- `T59_t51_feedback_front_slot_qd`: short fail-pool feedback on the T51 base.

The direct repair variants are not promoted. T51 remains the useful recovery
base because it restores yield and HV-AUC, but short feedback and direct repair
do not solve the front-breadth blocker.

Future repair work should be materially different: source-level direct-code
repair or front-rescue lanes must log valid-PPA yield, local/global front
additions, and final-front contribution per lane.
