# T52 Phase 03.1 QD/PPA Viewer

Status: completed seed `1001`.

Open `index.html` directly in a browser. The bundle contains 13 datasets for
the hard/tuning screen and uses `code_thought_full_pareto_qd` as the archive
source.

Use this viewer for:

- T52 archive occupancy and local Pareto-cell inspection;
- paired classic/T52 PPA distribution browsing;
- timeline, compare mode, archive projection, and raw area-power front views.

Do not use this viewer to claim honest classic archive occupancy. Classic
candidates were not projected into the SR-PCA archive because no honest
classic descriptor recovery was available for this export.
