# Tables

This directory stores the T15 Yosys-SOG proxy audit tables.

| File | Purpose |
| --- | --- |
| `sog_features.csv` | Candidate-level RTL operator-graph features and assigned SOG cells. |
| `lowering_funnel.csv` | Per-candidate Yosys lowering status. |
| `archive_metrics.csv` | Pooled method-level descriptor-cell summary. |
| `problem_metrics.csv` | Per-problem method-level descriptor-cell summary. |
| `comparison_deltas.csv` | Problem-paired exact-T26 deltas versus classic. |
| `ppa_completeness.csv` | Corrected full-RTLLM reference/candidate completeness table. |
