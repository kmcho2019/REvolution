# T75 Data

- `ppa_candidates.csv`: compact candidate-level PPA rows from the completed
  PPA-distribution section.
- `reference_ppa_metrics.csv`: benchmark reference PPA rows.
- `best_candidate_by_backend_problem.csv`: best candidate summary by backend
  and problem.

These files are sufficient to regenerate the T75 completeness and summary
figures without reading the full run directory.
