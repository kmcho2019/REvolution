# T74 Matched Tables

- `aggregate_backend_metrics.csv`: aggregate Pareto/HV metrics.
- `backend_problem_metrics.csv`: one row per backend/problem.
- `t74_ppa_completeness.csv`: headline completeness status.
- `backend_comparison.md`: final-analysis backend comparison report.
- `pareto_report.md`: final-analysis Pareto report.
- `final_analysis_summary.json`: top-level final-analysis summary.
- `hard_iteration_summary.json`: hard-iteration summary.
- `pareto_summary.json`: Pareto summary.

The headline comparison is reference-complete and uses all 13 problems.
