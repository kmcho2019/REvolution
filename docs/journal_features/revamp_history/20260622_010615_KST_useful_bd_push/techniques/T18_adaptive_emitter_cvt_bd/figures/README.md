# T18 Figures

This package intentionally keeps only the two source figures needed to support
the T18 retirement decision:

- `t18_t57_rebinning_counters.png`: copied from T57. It shows adaptive
  rebinning counters and the zero-rebin outcome.
- `t18_t32_holdout_live_aggregate.png`: copied from T32. It shows the holdout
  aggregate comparison where T32 improves some counts but does not recover the
  T26 quality/HV signal.
- `visual_inspection_notes.md`: manual readability and interpretation notes.

The source packages keep the full direct-PPA and viewer artifacts.
