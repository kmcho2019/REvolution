# Figures

This directory stores the passive local-Pareto audit figures and visual
inspection notes for T17.

- `mome_retention_hypervolume.png`: scalar-cell elite versus bounded local
  Pareto mean HV by method.
- `mome_global_pareto_points.png`: retained global nondominated point count by
  method and retention rule.
- `mome_vs_scalar_deltas.png`: local-Pareto relative deltas versus scalar-cell
  retention.
- `mome_retained_candidates_heatmap.png`: bounded local-Pareto retained
  candidates by method/problem.
