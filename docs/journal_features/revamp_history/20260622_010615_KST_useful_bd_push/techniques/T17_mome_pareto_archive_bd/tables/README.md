# Tables

This directory stores the CSV tables generated by the T17 passive local-Pareto
audit.

- `source_manifest.csv`: read-only source paths and hashes for the old
  standard-result artifacts.
- `aggregate.csv`: method-level scalar-cell versus bounded-local-Pareto summary.
- `deltas.csv`: per-method deltas from scalar-cell retention to local-Pareto
  retention.
- `problem_metrics.csv`: per-problem metrics for each retention rule.
- `retained_candidates.csv`: raw retained candidate rows sufficient to inspect
  which candidates each rule kept.
