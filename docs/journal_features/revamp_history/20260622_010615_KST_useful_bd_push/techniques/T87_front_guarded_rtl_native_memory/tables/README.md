# T87 Tables

- `shape_density_aggregate_backend_metrics.csv`: aggregate HV, Pareto point,
  and reference-beating candidate comparison across classic, SR-memory,
  random-memory, and T87.
- `shape_density_backend_problem_metrics.csv`: per-problem metrics behind the
  aggregate table.
- `shape_density_mechanism_summary.csv`: compact lane-level mechanism summary
  from T87 `qd_metrics.json` files.
