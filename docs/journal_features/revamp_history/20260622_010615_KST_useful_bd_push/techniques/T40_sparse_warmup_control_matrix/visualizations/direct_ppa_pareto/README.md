# T40 Direct PPA Pareto Viewer

Status: complete.

Files:

- `index.html`: filesystem-openable direct PPA comparison viewer.
- `metrics.json`: JSON copy of the per-problem method summary used by the
  viewer.
- `screenshot.png`: Playwright-rendered screenshot used for visual inspection.

The viewer intentionally starts with the direct raw area-power PPA-front
figure, then shows the compact summary table. It is not a substitute for the
committed PNG figure; it is a quick inspection surface for the same data.
