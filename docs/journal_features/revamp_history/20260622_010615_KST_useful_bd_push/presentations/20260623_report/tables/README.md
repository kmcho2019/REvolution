# Tables

Planned tables:

- `claim_gates.md`: gate checklist for any useful-QD claim.
- `planned_metric_schema.csv`: one-row-per-method/problem schema for the
  full RTLLM package.
- `rtllm_problem_method_metrics.csv`: one row per method/problem.
- `rtllm_aggregate_deltas.csv`: paired aggregate deltas and intervals.
- `rtllm_screen_excluded_deltas.csv`: aggregate deltas excluding development
  screen problems used during T26-family selection.
- `validity_gate_table.csv`: valid-PPA and synthesis-valid counts with
  small-n labels.
- `method_lineage_selection.md`: why exact T26 or a T26.1 variant was selected.
- `budget_parity.csv`: evaluation counts, LLM-call counts, and runtime by arm.

Tables must be reproducible from committed scripts or documented commands.
