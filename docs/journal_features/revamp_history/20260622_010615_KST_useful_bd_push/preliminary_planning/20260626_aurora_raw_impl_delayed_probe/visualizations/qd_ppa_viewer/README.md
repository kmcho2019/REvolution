# T99 QD/PPA Viewer

This is the full Phase 03.1 linked archive/PPA viewer for T99.

Files:

- `index.html`: browser-openable viewer.
- `manifest.json`: dataset manifest.
- `datasets/*.json`: per-problem viewer datasets.
- `validation.json`: strict schema validation result.
- `screenshot.png`: inspected compare-mode render.

Classic descriptor recovery is enabled for this viewer because the descriptor
uses synthesis-derived structural metrics that can be recovered from candidate
artifacts. The QD arm remains the archive source.
