# 20260625 Review Bundle

This bundle is a curated third-party review package for the current TCAD
journal-extension effort on QD/MAP-Elites for RTL PPA evolution.

Start here:

1. `briefing/cover_letter_to_reviewer.md`
2. `briefing/executive_summary.md`
3. `briefing/technical_analysis.md`
4. `briefing/reviewer_questions.md`
5. `briefing/suggested_decisive_experiment.md`

Supporting evidence:

- `evidence/current_goal_docs/`: current goal, technique lanes, strategy,
  acceptance rules, and result matrix.
- `evidence/presentation/`: milestone report, slides, glossary, and full
  RTLLM presentation materials.
- `evidence/techniques/`: selected technique packages with method cards,
  results, tables, and commands.
- `evidence/prior_runs/`: older Auto-BD and diversity-retrospective context.
- `evidence/original_context/`: journal-revamp intent and claims contract.
- `source/`: selected implementation and test entry points.
- `figures/`: selected figures and screenshots for fast visual review.
- `references/literature_and_repos.md`: papers, external repos, and how they
  map to the attempted technique lanes.

The package is intentionally curated. It does not include full ignored
experiment directories under `exp/`, large embeddings, raw model caches, or
every generated visualization. The copied reports identify those original
paths when deeper local inspection is needed.
