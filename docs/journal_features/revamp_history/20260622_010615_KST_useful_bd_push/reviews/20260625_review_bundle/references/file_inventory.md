# File Inventory

The bundle contains curated copies of the files most useful for external
review.

## Briefing

- `briefing/cover_letter_to_reviewer.md`
- `briefing/executive_summary.md`
- `briefing/technical_analysis.md`
- `briefing/suggested_decisive_experiment.md`
- `briefing/reviewer_questions.md`

## Evidence

- `evidence/current_goal_docs/`: current goal docs, result matrix, technique
  lanes, strategy, and policies.
- `evidence/original_context/`: journal-revamp intent and accepted narrative
  context.
- `evidence/prior_runs/`: earlier Auto-BD and diversity-check reports.
- `evidence/presentation/`: report/deck/glossary and full RTLLM milestone
  package.
- `evidence/techniques/`: selected T04, T07, T11, T13, T14, T19, T20, T23,
  T24, T26, T33, T35, T36, T58, T72, T75, T76, T77, T79, and T80 reports,
  tables, and command notes.

## Source

- `source/src_revolution/qd/`: core archive, descriptor, engine, scheduler,
  scoring, and Pareto code.
- `source/src_revolution/auto_bd/`: automatic descriptor implementations.
- `source/src_revolution/*descriptor_evaluator.py`: graph, RTL, and
  source-aligned descriptor evaluators.
- `source/scripts/`: selected report, validation, and visualization scripts.
- `source/tests/`: selected tests for archive, descriptors, Pareto analysis,
  source-aligned extraction, and visualization.

## Figures

`figures/` contains selected PNGs and screenshots for fast inspection. Most
technique packages contain additional figures in the original repository tree.
