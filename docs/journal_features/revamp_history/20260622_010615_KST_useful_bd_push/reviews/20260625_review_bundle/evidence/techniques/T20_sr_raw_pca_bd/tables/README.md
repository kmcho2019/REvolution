# Tables

This directory stores the CSV tables generated from the central seed-1001
replay for `sr_raw_pca_qd`.

- `leaderboard_comparison.csv`: aggregate classic/manual/SR raw PCA metrics.
- `metric_deltas_vs_classic.csv`: direct SR raw PCA minus classic deltas.
- `per_problem_deltas_vs_classic.csv`: per-problem fitness and HV outcomes.
- `validity_gate.csv`: functionality, synthesis, and valid-PPA gate checks.
- `validity_funnel.csv`: stage-by-stage candidate counts.
- `archive_metrics.csv`: passive archive metrics.
- `per_problem_ppa_diversity.csv`: per-problem PPA diversity summaries.
- `descriptor_correlations.csv`: descriptor and metric correlation checks.
- `gate_matrix.csv`: coverage and gate status by method.
