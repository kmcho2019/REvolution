Supporting evidence:

- `evidence/current_goal_docs/`: current status, negative-map report,
  selection tables, metrics contract, and validation outcome.
- `evidence/preliminary_planning/`: recent screening packages for MasterRTL,
  DeepGate, RF/DeepGate, AURORA, delayed archive activation, and FG-QDM.
- `evidence/techniques/`: representative method packages and older near-miss
  lineages.
- `evidence/original_context/`: journal-revamp intent and accepted claims
  context.
- `source/`: selected scripts and descriptor implementation entry points.
- `references/file_inventory.txt`: full file list for this review bundle.

The bundle is intentionally curated. It excludes raw `exp/` runs, model caches,
large visualizations, and ignored generated archives. Reports inside the bundle
point to original local paths for deeper inspection.
