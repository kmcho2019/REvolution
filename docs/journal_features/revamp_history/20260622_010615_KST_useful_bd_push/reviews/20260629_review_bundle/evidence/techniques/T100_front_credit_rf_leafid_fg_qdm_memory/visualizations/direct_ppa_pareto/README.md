# T100 Direct PPA Pareto Supplement

This folder is the static reader-facing PPA-front supplement for the T100
smoke. It is not the full Phase 03.1 linked archive viewer.

Files:

- `index.html`: filesystem-openable summary page.
- `metrics.json`: aggregate HV and front metrics for the four compared arms.
- `prob041_gain_power_vs_area.png`: inspected representative PPA-front plot.
- `screenshot.png`: copy of the inspected representative plot.

The complete PPA distribution report and all raw CSVs live under
`../../analysis/ppa_distribution/`.
