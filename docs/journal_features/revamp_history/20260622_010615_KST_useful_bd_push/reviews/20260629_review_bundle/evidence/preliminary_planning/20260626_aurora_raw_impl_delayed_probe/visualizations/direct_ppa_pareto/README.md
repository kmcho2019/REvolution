# T99 Direct PPA Pareto Supplement

This supplement is a reader-friendly index over generated raw PPA-front
figures. It is not the full Phase 03.1 linked archive viewer; use
`../qd_ppa_viewer/index.html` for archive projection, timeline, compare mode,
and validation controls.

Files:

- `index.html`: static index for representative PPA-front figures.
- `metrics.json`: aggregate metric summary.
- `screenshot.png`: inspected representative direct PPA figure.
