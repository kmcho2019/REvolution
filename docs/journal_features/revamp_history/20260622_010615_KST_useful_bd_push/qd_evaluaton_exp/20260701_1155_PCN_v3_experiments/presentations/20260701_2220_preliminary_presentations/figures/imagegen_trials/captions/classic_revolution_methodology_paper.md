## Caption

Classic REvolution is shown as a compact EoH hill-climbing loop. Successful
valid RTL candidates enter the success pool and become parents for the next
generation. Invalid or weak candidates drop out.

## Prompt Summary

Generated with built-in imagegen using the manual flowchart as the style
target: flat academic-paper flowchart, white background, pale blue/gray boxes,
black outlines, straight arrows, no 3D, no futuristic chip art, and exact
method labels.

## Review

- Strength: cleaner and more polished than the deterministic matplotlib
  version while preserving a paper-like flowchart style.
- Weakness: still a raster generated image, so exact label text should be
  checked after regeneration.
- Recommendation: suitable for the appendix methodology overview.
