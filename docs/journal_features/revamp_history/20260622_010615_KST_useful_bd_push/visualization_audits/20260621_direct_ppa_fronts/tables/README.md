# Direct PPA Front Tables

| Table | Purpose |
| --- | --- |
| `candidate_ppa_points.csv` | Candidate-level coordinates, normalized gains, active objectives, front flag, and source code path. |
| `problem_front_counts.csv` | Per-method/per-problem counts for valid-PPA candidates, rank-1 front candidates, and reference-beating candidates. |
| `method_manifest.csv` | Live run root and method path used for every plotted method. |

These tables are generated by
`scripts/package_useful_bd_direct_ppa_fronts.py`.
