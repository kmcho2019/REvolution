# Direct PPA Front Tables

| Table | Purpose |
| --- | --- |
| `candidate_ppa_points.csv` | Candidate-level raw PPA coordinates, normalized gains, active objectives, raw area-power front flag, active-objective front flag, and source code path. |
| `problem_front_counts.csv` | Per-method/per-problem counts for valid-PPA candidates, raw area-power front candidates, active-objective front candidates, and reference-beating candidates. |
| `method_manifest.csv` | Live run root and method path used for every plotted method. |

These tables are generated by
`scripts/package_useful_bd_direct_ppa_fronts.py`.
