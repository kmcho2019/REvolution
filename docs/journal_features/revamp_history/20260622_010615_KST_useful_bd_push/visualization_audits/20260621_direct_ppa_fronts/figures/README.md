# Direct PPA Front Figures

| Figure | Purpose |
| --- | --- |
| `live_key_ppa_fronts_area_power_zoom.png` | Candidate-zoomed raw area-power fronts for Classic, Manual BD, Random, SR raw, and Conservative exploit. |
| `live_key_ppa_fronts_area_power.png` | Same key-method raw view with the reference star included for scale. |
| `live_key_ppa_fronts_improvement.png` | Key-method normalized improvement fronts; up/right is better and reference is `(0, 0)`. |
| `live_all_ppa_fronts_area_power_zoom.png` | Candidate-zoomed raw area-power fronts for all eight live methods. |
| `live_all_ppa_fronts_area_power.png` | All-method raw view with the reference star included for scale. |
| `live_all_ppa_fronts_improvement.png` | All-method normalized improvement fronts. |
| `live_front_count_summary.png` | Raw area-power front counts, active-objective front counts, and reference-beating counts by problem. |

Raw area-power figures use conventional non-inverted axes: lower-left is
better, and open circles mark the raw area-power front. Improvement figures use
normalized gains: up/right is better, and open circles mark the active-objective
front. For `Prob015_multi_pipe_8bit`, clock period is an active third
objective, so the raw area-power front and active-objective front intentionally
differ.
